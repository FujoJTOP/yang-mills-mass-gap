# 第 182 轮：`L_s=3$` 的两条入口 —— 链式模型**无新信息**；三角模型需要 θ-空间的 `M_f$`

---

## A. 链式 `L_s=3$`（`V$` 只耦合 `(1,2)` 与 `(2,3)`）

**`T=T_{12}\otimes K_1$`，`T_{12}$` 是两链模型。**

**⇒ `T$` 的本征值是 `t_i(T_{12})\,t_j(K_1)$`。**

**顶两个：若 `t_2(T_{12})t_0\gt t_1(T_{12})t_1$`（即 `r_{12}\gt \frac{t_1}{t_0}=u$`），则**

$$t_1=t_1(T_{12})t_0,\qquad t_2=t_2(T_{12})t_0\qquad\Longrightarrow\qquad r=\frac{t_2}{t_1}=r_{12}$$

$$\boxed{\ \text{链式 }L_s=3\ \text{的 }r=r_{12}\ \textbf{（无新信息）}\ }$$

**⇒ 链式延拓**不给** `L_s`-依赖；只有**三角**（三个 plaquette 联成环）才可能给。**

## B. 三角 `L_s=3$`

**`V=e^{-\beta_s[(1-q_{12})+(1-q_{23})+(1-q_{31})]}$`，`D=30^3=27000$`。**

**① `K=K_1^{\otimes3}$` 是张量积 ⇒ `Kv$` 用 3 次 `30\times30$` 矩阵乘（`2.4\times10^7$` 次运算，**便宜**）。**

**② `M_f=e^{-\beta_s\sum_P(1-q_P)/2}$` 在 `(j,m,n)$` 基下是**算子**（不是对角）⇒ 应用它要 `\text{Op}_1$` 的三次复合 + 指数。**

**③ 但**在 θ-空间**，`q_P=\cos\theta_P$` 是 `(u,u')$` 的**逐点函数** ⇒ `M_f$` 是**逐点乘**（便宜）。**

**⇒ 便宜的做法：在 θ-空间做 `M_f$`，在 `(j,m,n)$` 基下做 `K$`，两者之间用 **Peter–Weyl 变换**（每链一个 `30\times30$` 的酉阵）。**

**⇒ 实现成本：`3\times27$` 万点的 FFT 型变换 + Lanczos（`k=2$`）。预计 `1`–`10$` 分钟。**

## D. 距离 Clay（诚实清单）

**已证 `[T]$（累积，核心 18 条）：**

1. **`I_1I_3\lt I_2^2\ \forall z\gt0$`（两条独立）**；
2. **`\big(\frac{I_2}{I_1}\big)''\lt0$**；
3. **单链 `(R)$`（固定 `\beta$`）**（8 `[T]$` + 3 `[M]$）；
4. **`D_N$` 闭式对全部 `N$`**；
5. **`-\ln(I_2/I_1)$` 精确渐近级数 + Borel 半径 `\approx2$**`；
6. **余项判据 + `L=1$` 的 `\Phi\equiv0$`、`\Phi=-2\ln(\mu_2/\mu_1)$ + 本质谱**；
7. **`M_f$` 非紧、障碍 3 不是障碍**；
8. **`V\equiv1$ ⇒ `r=I_2/I_1$ 对任意 `L_s$**`；
9. **`c_1=\frac12$`、`\lambda_1=0$`、`\langle e_1,M_1^2e_1\rangle=\frac14$`、`t_j/t_1=u^2$**；
10. **`u=t_{1/2}/t_0$`、`q$` 只触及 `j=\frac12$ 层**；
11. **`L=1$` 完整相图 + 对角线 `1-r\propto\beta^{-0.92}$**；
12. **`V$` 效应峰值 `\beta\approx8$、`c_1/c_2$` 交叉 `6.494927$、`c_1/c_2\to\frac23$**；
13. **block-spin 出族 + 五种加权残差 `\ge0.89$**`；
14. **单链 `r(\beta')$` 单调降**；
15. **本轮：链式 `L_s=3$` 给 `r=r_{12}$（无新信息）**。
