## 2. 新归约：(Q) 沿坐标轴 ⟸ 横向求和的相关函数非负

**(Q)** 要求 `Σ_zΓ(0,z)[1−cos(k·z)] ≥ 0` 对一切 `k`。**逐点 `Γ≥0`（POS）是它的一个充分条件，但太强——数据说 `POS` 逐点失败。**

**取 `k=k_1e_1`（沿坐标轴）。此时 `cos(k·z)=cos(k_1z_1)` 只依赖 `z_1`，可先对横向求和：**

$$\boxed{\ w(z_1)\ :=\ \sum_{z_\perp\in\Lambda_L^3}\Gamma_L\big(0,\ (z_1,z_\perp)\big)\ }$$

$$\widehat C_L(k_1e_1)=\sum_{z_1}w(z_1)\cos(k_1z_1)\ \le\ \sum_{z_1}w(z_1)=\widehat C_L(0)\qquad\text{若 }w\ge0$$

$$\boxed{\ \textbf{(POS-1D)}\qquad w(z_1)\ \ge\ 0\quad\forall z_1\qquad\Longrightarrow\qquad \textbf{(Q)}\ \text{对 }k\parallel e_\mu,\ \mu=1,2,3,4\ }$$

**⭐ 关键：`(POS-1D)` 比 `(POS)` 弱得多。它只要求**横向求和**非负；单个 `Γ(0,z)` 可以为负，只要同一 `z_1` 的横向壳层加起来是正的。**

**⭐ 而且 `w` 有直接的概率意义：**

$$w(z_1)=\mathrm{Cov}_\mu\big(Q_0,\ Q_{z_1}\big),\qquad Q_{x_1}:=\sum_{x_\perp}q_{(x_1,x_\perp)}$$

**⇒ `(POS-1D)` ⟺ 「**墙求和算符 `Q_{x₁}` 沿 `x₁` 的相关函数非负**」。**

## 4. 下一步要证什么（按顺序）

### 目标 1（主攻）：`(POS-1D)`

$$\boxed{\ \textbf{求证：}\quad \mathrm{Cov}_{\mu_{\beta,L}}\big(Q_0,\ Q_{z_1}\big)\ \ge\ 0\qquad\forall z_1,\ L,\ \beta\in[1/48,2.5]\ }$$

**可用的结构：**

1. **`SU(2)` Wilson 作用的反射正性（RP）**：`½tr U_P` 是实表示，作用量实，超立方反射下 RP 成立 ⇒ `⟨FθF⟩≥0`。
   **⚠️ RP 给的是**单侧**正定，即 `ŵ(k_1)≥0`（`ŵ` 是 `w` 的 Fourier 变换）。`(POS-1D)` 是**逐点** `w≥0`，比 `ŵ≥0` **强**。⇒ RP **不能**直接给出 `(POS-1D)`。**
2. **可用的分解**：`w(z_1)=w_{q=0}(z_1)+w_{\rm conn}(z_1)`，其中 `w_{q=0}(z_1)=w(0)\delta_{z_1,0}` 来自 `Var(q)`，**严格正**。
   **⇒ 只需证连通部分的绝对值不超过 `w(0)`。数据：`|w_{\rm conn}(1)|/w(0)=0.155`，`|w_{\rm conn}(2)|/w(0)=0.023`，**逐项远小于 1**。⇒ 只需一个指数界 `|w_{\rm conn}(z_1)|≤Ce^{-m|z_1|}` 且 `C/(1-e^{-m})<w(0)`。**
3. **最弱可行路线**：由上，只需**横向求和后的衰减**：`|w(z_1)|≤C_1e^{-m_1|z_1|}`。这比逐点 `Γ` 的衰减弱（`C_1` 是 `L^3` 项之和，但数据表明 `C_1=w(0)=2.4e-2` 且 `m_1≈-\ln0.15=1.9`）。

**⇒ 建议的证明链：**

$$\text{(RP)}\ \Rightarrow\ \hat w(k_1)\ge0\ \text{（已可得）}\quad\text{加上}\quad w\ \text{的单调性与凸性}\ \Rightarrow\ w\ge0$$

**⭐ 一条具体的 1D 判据（可作为「单调性+凸性 ⇒ 逐点非负」的接口）：若 `w` 在 `z_1≥0` 上非增且凸，则 `w(z_1) ≥ 0` 可由 `w(∞)=0` 与 `w(0)>0` 及凸性给出（凸函数在正半轴上若取负值必须下降且不回头，与 `w(∞)=0` 矛盾）。**

**⚠️ 但 `w` 的凸性在数据上并非处处成立**（`L=10`：`w(4)=1.97e−4 < w(5)=7.51e−4` 上翘；`L=12`：`w(3)=2.67e−4 < w(4)=3.80e−4`）。**⇒ 凸性不可用，必须换论证。**

**⚠️ 更现实的路线**：把 `w(z_1)` 写成 `w(0)\delta_{z_1,0}+w_{\rm conn}(z_1)`，用 **`|w_{\rm conn}(z_1)|` 的指数界（可由 `\hat w` 的解析性 + `ŵ≥0` 得到）** 加一个**单点**估计 `|w_{\rm conn}(z_1)|≤w(0)e^{-m|z_1|}`，并要求 `e^{-m}/(1-e^{-m})<1/2`，即 `m>\ln3≈1.10`。**数据给 `m≈1.9`，余量 `1.7×`。**

### 目标 2：把 `(Q)` 从坐标轴推广到一般 `k`

$$\widehat C(0)-\widehat C(k)=\sum_z\Gamma(z)\Big[1-\prod_{\mu}\cos(k_\mu z_\mu)\Big]$$

**⚠️ `1−Πcos` 不能拆成非负项：`1−Πcos = Σ_μ(1−cos_μ)Π_{ν<μ}\cos_ν`，而 `Πcos_ν` 可变号。**

**⇒ 一般 `k` **不能**只靠四个坐标方向推出。**

**可行的补丁（建议）：**
- 先证 `k` 落在一维子格（`k=(k_1,0,0,0)`）上的情形（目标 1）；
- 再证 `k` 在 `k_μ∈{0,π}` 的 16 个点上（此时 `cos(k·z)=∏(±1)^{z_μ}` 是**带符号乘积**，`Ĉ(k)` 是 `Γ` 的带符号和，可用 `x_μ↦x_μ+L/2` 的平移把符号吸收进 `Γ` 的符号）；
- 最后用 **`Ĉ` 在 `\lambda(k)` 上的单调性插值**。

**⚠️ 而最后一环（`\lambda` 单调）**没有**一般性依据**：反例见第四版 §3（`q_x=c[η_x+aΣ(η_{x+2e_μ}+η_{x−2e_μ})]` 给出 `λ` 小而 `Ĉ` 也小）。**⇒ 这一环必须用模型结构，不能用一般协方差性质。**
