# 第 82 轮：**外推的诚实限度** —— 从 `n=2,3,4$` 到 `n=64$` 是 16 倍外推

---

## A. 外推的跨度（`[T]$`）

**本会话的链数数据：`n=2,3,4$`。**

**物理格点：`L^3=64$`。**

$$\boxed{\ \frac{n_{\rm phys}}{n_{\rm data}}=\frac{64}{4}=16\qquad\textbf{（16 倍外推）}\ }$$

## B. 外推的可靠性

**① 三个点的几何/幂律外推在**短程**（`n$` 变化 1）上是可信的。**

**② 但外推到 `n=64$`（16 倍）**没有任何**理由保持同形式。**

**③ 例如：`r(n)$` 可能在 `n\approx10$` 处改变形状（相变、交叉）。**

**④ ⇒ `r_\infty\approx0.806$`–`0.829$` 的估计**不**能外推到 `n=64$`。**

## C. 所以

**① 「`L\to\infty$` 给 `m a\ge0.188$」是**在 `n=2,3,4$` 的短程外推**下的结论。**

**② 它**不是** `n=64$` 的结论。**

**③ `n=64$` 的 `r$` 可能**更大**（更接近 1）或更小。**

**⚠️ 这是本会话所有 `L`-方向结论的**限度**。**

## D. `\beta_s$`-方向的限度

**① `\beta_s$`-方向的数据：`\beta_s\in[0.25,3]$`（三角）、`[0.25,256]$`（两链）。**

**② 两链的 `\beta_s\to256$` 给 `r\to u=0.507$`（`[T]$`，`ive` 归一化）。**

**③ 所以**两链**的 `\beta_s$`-方向是**可靠的**（`r\to u$`）。**

**④ 三角的 `\beta_s$`-方向只到 `3$`（后面截断）⇒ 不可靠。**
