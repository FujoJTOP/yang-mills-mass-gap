$S^*$ 的值下界项与定号项。正式记录：陈述、推导、读数、障碍。

第 242 轮 · 判词只有 [T] 已证 / [NG] 未证 · 无百分比

在 $S^*$ 里的位置
$$\mathrm{Clay}\ \Longleftarrow\ S^*=\underbrace{A}_{\text{存在性}}\ \wedge\ \underbrace{B}_{\text{值下界}}\ \wedge\ \underbrace{C}_{\text{定号}}$$

本文件只记 B 与 C。$A$ 是另一格（缺件为一个 $N_B$ 的幂，$\mathcal S_q$ 的 $\kappa$ 待算）。$S^*\Rightarrow\mathrm{Clay}$ 是充分，不是等价。

B值下界 $\ \varpi\ge c_0\gt0$

B.1陈述

作用：防止 $S^*$ 退化为空蕴含。它不进 $L3$（$L3$ 只要上界），只进 $S^*$。

$$\exists c_0\gt0:\quad \varpi\ \ge\ c_0\tag{B.1}$$

其中 $\varpi=a_k^4\hat b^4\,\mathrm{Var}_\mu(\textstyle⨏_B\delta\,\mathrm{tr}F^2)$，是块方差的无量纲标度。

B.2分解

$$\varpi=\underbrace{\mathrm{Var}(q)}_{=\,C_q(0)\,\in(0,1]}+O_B,\qquad O_B=\frac{1}{N_B}\sum_{z\ne0}n_B(z)\,C_q(z)\tag{B.2}$$

$q=N_B^{-1}\sum_{x\in B}\delta\,\mathrm{tr}F^2$，$q\in[0,2]$。对角项不花任何输入（Popoviciu），且与 $a,k,L,N$ 全无关。

B.3两颗已证的火药

T  火药一：$O_B$ 的符号
$$C_q(z)=\int d\rho\;\Delta_E,\qquad \rho\ge0,\qquad \Delta_E=\frac{mK_1(m|z|)}{4\pi^2|z|}\gt0$$ $$\Longrightarrow\quad C_q(z)\gt0\quad\forall z\ne0\quad\Longrightarrow\quad O_B\gt0\tag{B.3}$$

$\rho\ge0$ 来自反射正性 $\Rightarrow$ KL 性质；$\Delta_E$ 是正核。**这与自由场同号，而不是 Wick 专属。** 因此强形 $O_B\le0$ 由“自由场反例”升级为 OS 类内不可达，相消通道关闭。

T  火药二：$\mathrm{Var}(q)$ 的严格地板
$$\mathrm{Var}(q)\ \ge\ v(\beta)=\min(a,b)\,(6\beta)\qquad\text{对一切 }a,L,N,\text{b.c.}$$ $$v(2.5)=6.42\times10^{-3}\qquad(a=6.01\times10^{-2},\;b=6.42\times10^{-3})\tag{B.4}$$

来源：总方差 + 单链条件律 + $|\tilde a|\le6$ + von Mises–Fisher 协方差。零额外假设。

B.4拼装

B 格的两行
$$\varpi=\mathrm{Var}(q)+O_B\ \gt\ \mathrm{Var}(q)\ \ge\ v(2.5)=6.42\times10^{-3}\ \gt\ 0$$ $$\boxed{\ c_0=6.42\times10^{-3}\ }\tag{B.5}$$

B.6具名障碍

NG  陈述层的不匹配

$(B.3)$ 的 $[T]$ 是在 OS 类里证的（$\rho\ge0$ 由 RP）。而格点 $\beta=2.5$ 上，RP 单独定不了号：$g_B(0)=N_B-1\gt0$、$g_B(\text{corner})=-1$，两个正谱测度模型给相反号。

所以缺的不是估计，是一个层级对齐：把 $(B.3)$ 从 OS 类搬到格点测度上。

这条障碍的类型要记准：不是“$O_B$ 可能为负”，是“$O_B\gt0$ 的证明目前住在一个不同的测度类里”。 而 $\mathrm{Var}(q)$ 那一半是格点测度上的 $[T]$，没有这个问题。

C定号 $\ \min_\beta\varepsilon\ge w_0$

C.1为什么要写比值形

$f_1^2$ 在 $\beta=\sqrt8$ 处对一切 $(L,a)$ 精确归零（$c=p-q\beta^2/2N^2$ 使 $a_n\equiv0$）。而同一处 $w_1=0.33278$ 仍有限。

$$\boxed{\ \text{靶必须是}\ \min_\beta\ \varepsilon\ \ge\ w_0,\qquad \varepsilon=\frac{f_1^2}{\mathrm{Var}(O)},\qquad w_0=\frac{1}{4N^4}\ }\tag{C.1}$$

绝对形 $\inf f_1^2\ge r_0$ 不成立。$|c|$ 在 $\beta=2.5$ 是 $0.219$，它压 $f_1^2$、不压 $w_1$——两者都是原子权的 0 次齐次量，$c^2$ 只进中间量。

C.2一参数化

$$H=B\big(tX_B+X_E\big),\qquad t=\frac{\beta^2}{2N^2}\qquad\Longrightarrow\qquad \varepsilon=\mathfrak e(t)\tag{C.2}$$

整个 C 格只依赖一个变量。于是

$$\partial_\beta\ln\varepsilon=\frac2\beta\cdot\frac{d\ln\mathfrak e}{d\ln t}\tag{C.3}$$

C.3$t\to\infty$ 的静态极限（这是本轮的关键）

T  由本征矢恒等式推出，不是拟合
$$\langle E_0|H|E_n\rangle=0\quad\Longrightarrow\quad \langle E_0|X_B|E_n\rangle=-t^{-1}\langle E_0|X_E|E_n\rangle$$ $$\langle E_0|X_E|E_n\rangle=E^{0n}+O(1/t)\quad\Longrightarrow\quad \mathfrak e(t)=\mathfrak e_\infty\big(1+O(1/t)\big)$$ $$\mathfrak e_\infty=\frac{|E^{01}|^2}{\sum_n|E^{0n}|^2}\ \gt\ 0\tag{C.4}$$

机检（三个确定性 eigh）：$|\mathfrak e-\mathfrak e_\infty|\cdot t\to 0.032/0.086/0.018$ 常数 ⇒ $t$-指数 $s_t=1$；恒等式残差 $\le1.6\times10^{-15}$。

$$\boxed{\ s_t=1\ \Longleftrightarrow\ s_\beta=2\ }\tag{C.5}$$

C.4整个格塌成静态比值

$$(\mathrm{E})\ \text{塌成}\quad r:=\frac{\sum_{n\ge2}|E^{0n}|^2}{|E^{01}|^2}\ \le\ 4N^4=64\tag{C.6}$$

没有 $\beta$-动力学，没有积分，没有衰减率。 $r$ 是 $X_E$ 在 $X_B$ 本征基里的矩阵元之比——纯谱数据。

C.7具名障碍

NG  只卡数值与 $L$-一致性，不卡指数

$1/t_A=1.28$ ⇒ $\beta=2.5$ 落在渐近区之外，$K_0$ 只是拟合值。渐近起点 $\beta_c$ 与 $L$-一致间隙未定。

可判伪：$\mathfrak e_\infty\approx2.79\,w_0$（固定-$L$）/ $4.49\,w_0$（raw）。若测到 $\varepsilon(6)\lt0.047$，本路即否。

C.8一条要记的否决

$r_0$ 翻倍并不自动把 $s$ 的门槛降到 $\le1$：roleB（锚 $\times2$）给 $s_{\min}=1.085/0.833$，而 roleA（地板变 $2w_0$）给 $1.719/1.319$——要求变紧，与前提反向。要到 $s_{\min}=1$ 需 $\varepsilon_0/w_0=e^{2K_L}=59.1$，即 $21.468\times2.754$，不是 $2\times$。

所以不必问翻倍：结构直接给 $s_\beta=2\ge1.3303$。
