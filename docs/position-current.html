6. 限定

  • 单链 (R) 的 [T] 是在固定 β（主参照 β=2.5）下；β-一致的版本只到 [M]（第 88 轮：三个 β 数值全成立）。
  • 截断秩 N=15 在 β≥10 失效；N_req ≈ 7.8√β。
  • 两链计算上限 J_out = 4（81225 维）；Lanczos 收敛到 7 位。
对 Clay 的诚实陈述：单链 (R) 对固定 β 已证，但它落在 L_s = 2；O1 已判 [F]，即「靠 V ≤ 1 延拓到格点」这条路不通。格点的质量隙需要格点自己的谱估计（Balaban 型 RG 或面模型），不在单链模型里。单链 (R) 不构成 §1.07 意义上的「大型 [T]」。
