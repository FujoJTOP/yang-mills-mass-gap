# 第 15 轮：33% 缺口**解决** —— 我漏了 `I_0''(0)=\frac12$` 与 `2M'KM'$` 项

## A. 错在哪

**第 14 轮我写 `M''(0)=\frac14\mathbf S_2-\frac14E_{00}$`。**漏了 `I_0''(0)$`**：**

$$I_0(\lambda)=1+\frac{\lambda^2}{4}+\cdots\qquad\Longrightarrow\qquad I_0''(0)=\tfrac12$$

**数值验证（`h=10^{-3}$` 有限差分 `M''(0)$` 的前 4×4 块）：**

```
[[0.25,  0,     0.25,  0   ],
 [0,     0.50,  0,     0.25],
 [0.25,  0,     0.50,  0   ],
 [0,     0.25,  0,     0.50]]
```

**⇒ `M''(0)_{00}=0.25$`、`M''(0)_{aa}=0.5$`（`a\ge1$`）、`M''(0)_{ab}=0.25$`（`|a-b|=2$`）。**

$$\boxed{\ M''(0)=\tfrac12 I+\tfrac14\mathbf S_2-\tfrac14E_{00}\ }$$

**（`\frac12I$` 来自 `I_0''$`，`\frac14S_2$` 来自 `I_{|a-b|}''$` 在 `|a-b|=2$`，`-\frac14E_{00}$` 来自 Hankel 项。）**

**`M'(0)=\frac12\mathbf S_1$`**（不变，数值 `0.5000000$` ✓）。

## B. 还漏了 `2M'KM'$` 项

**`T''=M''K+KM''+2M'KM'$。我第 14 轮把 `2M'KM'$` 只算进了微扰和，忘了它的**对角**贡献。**

**`(2M'KM')_{00}=2\sum_cM'_{0c}t_cM'_{c0}=2\cdot\tfrac12t_1\cdot\tfrac12=\tfrac12t_1=0.5106$**

## C. 正确分解与数值吻合

$$t_i''=[M''K+KM'']_{ii}+2[M'KM']_{ii}+2\sum_{j\ne i}\frac{|(T')_{ij}|^2}{t_i-t_j}$$

**`i=0$`：**

$$\underbrace{1.0067}_{t_0/2}+\underbrace{0.5106}_{\frac12t_1}+\underbrace{4.640}_{\frac{(t_0+t_1)^2}{2(t_0-t_1)}}=6.157$$

**⇒ 与有限差分 `6.157699$` 吻合 ✓。**

**`i=1$` 与 `i=2$`（用 60×60 全矩阵直接算）：**

| `i$` | 公式 | 有限差分 |
|---|---|---|
`0$` | `6.1577033011$` | `6.157699$` ✓ |
`1$` | `-0.8941123804$` | `-0.894108$` ✓ |
`2$` | `-0.1375655610$` | — |

$$\boxed{\ t_1''=+6.1577,\quad t_2''=-0.8941,\quad t_3''=-0.1376\ }$$

## D. 于是 `t_1''\gt0\gt t_2''$ 现在是**可写下来的公式**

**`t_i''(0)=\dfrac{t_i}{2}\Big(1-\dfrac{\delta_{i0}}{2}\Big)+\sum_{c}\big(M'(0)_{ic}\big)^2t_c+\sum_{j\ne i}\frac{\big((t_i+t_j)\,\frac{\delta_{|i-j|,1}}{2}\big)^2}{t_i-t_j}$**

**其中 `M'(0)=\frac12\mathbf S_1$。三项都显式。**

**⇒ 符号：`i=0$` 三项全正 ⇒ `t_0''\gt0$` ✓。**
**`i\ge1$`：第三项里 `j=i-1$` 的项是**负**的且绝对值最大 ⇒ `t_i''\lt0$`（在 `\beta=2.5$` 上验到 `i=1,2$`）。**
