# 攻无条件定理 · 战役计划

> 2026-11-23 · 建立在 `docs/gap-ledger.md`（G1 构造 / G2 间隙 / G3 物理 / G4 方法真空）之上。
> 循环：**plan → 派出 → 总结 → 再派出**。

## 诚实前提（不写清楚就不派）

无条件定理 = **G1（严格构造）+ G2（质量间隙，且 ≡ 原问题）+ G3（IN-b，≈ 谱问题）**，三层各自
都是或等价于 Clay 问题的一半。所以本战役**不承诺证出定理**。目标是每层逼出：

- **最锐的真陈述**（把"敞"降为"条件于更弱前提"，或证"这条攻击路死"）；
- **部分进展**（某个子情形/某条引理的严格化）；
- **精确障碍**（说清到底卡在哪、需要什么新工具）。

任何一层被**证伪**（某路走不通）或**证真**（某子目标达成），都是硬结果，进账。

## 两条战线

- **P1 直接兑现**：对 G1 / G2 / G3 各自发起当前最优攻击。
- **P2 正交绕行**：找不经过 crossover 墙（β≈2.47 / Savvidy 49%）的路线——精确极限、可解点
  形变、全息、可积性、新保护对称。

## 波次循环

- **波 1（并行 5 路）**：T1–T5，见下。
- **汇总**：保留有真进展者，写"存活/死亡"台账。
- **波 2**：只在波 1 存活方向上加深；死亡方向记录理由，不再派。
- 停止条件：所有方向要么证死、要么降到"需某新工具"（此时进 `gap-ledger.md` 的翻盘清单）。

## 判定"算进展"的标准

1. 把某个输入从"敞"降为"条件于更弱/更可信前提"；
2. 证明某条攻击路**死**（负结果是进展）；
3. 找到一个此前未记的**新工具候选**，写进翻盘清单。

## 口径

多数方向很可能撞回同一堵墙——如实记录，**不造定理、不粉饰**。本战役的产出是**地图的更精细
刻度**与**可能的部分定理**，不是 Clay 的解。

## 波 3 设计（R1/R2 回来后立即发，趁热打铁）

前提：波 1/2 已把"survey 型"方向摸尽并收敛。波 3 不再铺 survey，改为**在最深的两个具体
攻击点上强攻 + 一支红队**。

- **W3-A 边际规范协变 BPHZ（强攻 G1 的唯一定理）**：直接尝试把边际对数发散反项按**跑动耦合**、
  保 **Ward/BRST** 组织起来，以 W2-2 的"log-critical structure + Polchinski flow inside RS"为起点。
  报出在哪里可证破裂、或有没有立足点。这是 G1 最具体的"缺失定理"，值得一次正面强攻。
- **W3-B 小 S¹ 深潜（门控于 R1/R2）**：按 R1/R2 指出的**可动件**（bion 气体严化 / ℝ⁴ 连续性）深攻；
  若 R1/R2 判"需目标本身"，则跳过，只记死因。
- **W3-C 红队 · 攻破自家 no-go 地图**（价值最高——地图若有洞，那就是突破口）：
  (a) 是否误读某个引用结果；(b) 是否存在一个**严格可构造的 4D 规范理论**（Abelian Higgs / 非对易 /
  SUSY 形变）其技术可移植到纯 YM；(c) "cert ≡ gap" 的等价是否真的无缝。
- **W3-D（可选）创造一条新结构**：propose **one** genuinely new approach，并严格论证它**为何可能**
  绕过墙（不空谈）。

判据同前：降格某输入 / 证死某路 / 找到新工具候选。若波 3 也无存活方向，则本战役到此为止，诚实地
"把新工具清单交出去"。
