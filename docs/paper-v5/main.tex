\begin{statusbox}
\textbf{What this document is.} A \emph{judgement}, not a progress report, and not a proof of the
Clay conjecture (progress on Clay is $0\%$). It records that one route --- the coarse-mode
curvature route, the campaign's own declared ``key'' for several rounds --- is \emph{closed}, with
two independent obstructions at label \LT; then the one strict certificate that route produced
(\S\ref{sec:cert}), which is true and is not a physical statement; then the correct object
(\S\ref{sec:target}). Where the internal corpus contradicts itself, both readings are printed and
it is said which is an identity and which is a measurement.

\smallskip
\textbf{Labels.} Every substantive claim carries one:
\LT{} \emph{theorem / identity} (imported standard results are named);
\LC{} \emph{conditional theorem} (proved from explicitly named hypotheses);
\LN{} \emph{no-go} (the corpus tag \code{[NG]}: a theorem or exact counterexample against a whole
class of approaches); \LM{} \emph{exact missing step} (no slack hidden);
\LE{} \emph{numerical evidence} (measured, not proved). A \LT{} on a \emph{structural} statement
certifies that lemma only; it never certifies Clay, and here it often certifies that a route is
dead.

\smallskip
\textbf{Provenance.} Every number names the file it came from and every displayed identity names
the file containing its proof. No step labelled \LT{} below is labelled \LC{} or \LE{} in its
source, and no number is an average of two sources: disagreements are reported (\S\ref{sec:cert},
\S\ref{sec:errata}).
\end{statusbox}
