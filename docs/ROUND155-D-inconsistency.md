# 第 155 轮：`D$` 的符号化简与直接计算**不一致** —— `D$` 线暂停，先记不一致

---

## A. 符号化简（`[T]$` 级代数，但结果与数值矛盾）

**用 `r=I_1/I_2$`、`I_2'=I_2(r-\frac2z)$`、`I_1'=I_2+\frac{I_1}{z}$`、Riccati `r'=1-r^2+\frac{3r}{z}$`：**

**`P=rI_2^2$`、`P'=I_2^2(r^2-\frac rz+1)$`、`a=2+\frac{2z}{r}$`、`a'=\frac{2}{r}-\frac{2z}{r^2}(1-r^2+\frac{3r}{z})$`。**

**`\texttt{sympy}$` 化简 `D/I_2^2$`：**

$$\frac{D}{I_2^2}\ =\ -\frac{r^2\,(3r^2z-12r-7z)}{z\,(3r+2z)^2}$$

**⇒ 公式说 `D\gt0$` ⟺ `r\lt\frac2z+\sqrt{\frac{4}{z^2}+\frac73}$`。**

**而第 154 轮已证 `r\lt\rho=\frac2z+\sqrt{1+\frac4{z^2}}$`，且 `1\lt\frac73$` ⇒ `\rho\lt` 那个界 ⇒ `D\gt0$` 应该成立。**

## C. 最可能的错处

**`a'$` 的链式法则：`a=\frac{2zI_1'}{I_1}$`，而 `I_1'$` 本身依赖 `z$`。**

**本轮写 `I_1'=I_2+\frac{I_1}{z}$`（用了 `I_0=I_2+\frac{2I_1}{z}$` 和 `I_1'=\frac{I_0+I_2}{2}$`）。**

**核对：`I_1'=\frac{I_0+I_2}{2}=\frac{I_2+\frac{2I_1}{z}+I_2}{2}=I_2+\frac{I_1}{z}$` ✓**

**⇒ 这一步对。但 `a'=\frac{d}{dz}\frac{2zI_1'}{I_1}$` 需要把 `I_1'=I_2+\frac{I_1}{z}$` 的**全导数**算进去（含 `I_2'$` 和 `I_1'$`）。**

**⚠️ 本轮用 `a=2+\frac{2z}{r}$` 再做 `a'$`，形式上等价（因为 `\frac{2zI_1'}{I_1}=\frac{2z(I_2+I_1/z)}{I_1}=\frac{2z}{r}+2$` ✓）。**

**⇒ 但 `\texttt{sympy}$` 化简 `D/I_2^2$` 时用的是 `P'=I_2^2(r^2-\frac rz+1)$` —— 需要核 `P'$`。**

**`P=I_1I_2$`、`P'=I_1'I_2+I_1I_2'$`。**

**`I_1'I_2 = (I_2+\frac{I_1}{z})I_2 = I_2^2+\frac{I_1I_2}{z}=I_2^2(1+\frac rz)$`。**

**`I_1I_2' = I_1·I_2(r-\frac2z) = I_2^2r(r-\frac2z)$`。**

**⇒ `P' = I_2^2[1+\frac rz+r^2-\frac{2r}{z}] = I_2^2[1+r^2-\frac rz]$` ✓ 与 `\texttt{sympy}$` 一致。**

**⇒ `P'$` 对。那错在 `a'$` 或 `D$` 的组装。**
