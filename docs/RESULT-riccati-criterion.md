# 第 23 轮：`\kappa_3\lt0$` 化成一条**干净的 Riccati 判据**，130 点全过

---

## A. 用 Riccati 消去导数

**`R:=I_1/I_0$` 满足（Bessel 恒等式 `I_0'=I_1$`、`I_1'=I_0-\frac{I_1}{z}$`）**

$$\boxed{\ R'=1-\frac Rz-R^2\ },\qquad v=R',\qquad \kappa_3=R''$$

**`R''=-\frac{R'}{z}+\frac{R}{z^2}-2RR'$ ⇒**

$$\kappa_3=\frac{R}{z^2}-R'\Big(\frac1z+2R\Big)$$

**⇒ 乘 `z^2$` 并代入 `R'=1-\frac Rz-R^2$，整理得**

$$\boxed{\ z^2\kappa_3\ =\ R-R'\big(1+2z^2R\big)\ =:\ G\ }$$

**⇒ `\kappa_3\lt0\iff G\lt0$。**

## C. 判据的等价形式

$$G\lt0\iff R\lt R'\big(1+2z^2R\big)\iff \frac{R}{R'}\lt1+2z^2R$$

**（`R,R'\gt0$` 在全部测试点上成立。）**

**⇒ 只需一条：`\frac{R}{R'}` 不超过 `1+2z^2R$`。**

**⚠️ 余量在大 `z$` 处很紧：`z=20$` 时 `759.2$` vs `780.7$`（3%）；`z=100$` 时 `19800$` vs `19899$`（0.5%）。**

**证 `\frac{R}{R'}\lt1+2z^2R$`。因为 `R'=1-\frac Rz-R^2$` 是 `R$` 的显式函数，这条不等式等价于**

$$\frac{R}{1-\frac Rz-R^2}\ \lt\ 1+2z^2R\qquad\Big(\text{即 } 2z^2R^3+3zR^2-2z^2R+2R-z\lt0\Big)$$
