# 一个算子范数估计问题（4D 格点 SU(2) 规范系统）

> 我需要下面这个不等式的证明。它是一道**有界的分析题**：对象、常数、数值证据、以及我已经排除的四条思路都写在里面。请直接给证明思路或反例，不需要背景介绍。

---

## 1. 设定

取四维环面 `Λ_L = {0,…,L−1}⁴`（`L` 偶，`L = 6,8,10,12` 有数值）。

- 每条**有向边** `e` 上一个群元素 `U_e ∈ SU(2)`，`dU_e` 为 Haar 概率测度；
- 记 `U_{e^{-1}} := U_e^{*}`；
- 每个**面**（plaquette）`P = (e_1,e_2,e_3,e_4)` 上，`U_P := U_{e_1}U_{e_2}U_{e_3}U_{e_4} ∈ SU(2)`（沿边界有序乘积）。

作用量与测度：

$$S_{\beta,L}(U) = \beta\sum_{P}\Big(1-\tfrac12\,\mathrm{tr}\,U_P\Big),\qquad d\mu_{\beta,L} = \frac{1}{Z_{\beta,L}}\,e^{-S_{\beta,L}}\prod_e dU_e .$$

`β > 0` 为参数。**我关心的范围是 `β ∈ [1/48, 2.5]`。**

---

## 2. 观测量与目标算子

对每个面 `P`，取其**中心** `x ∈ Λ_L`（定义：`x` 为 `P` 四个顶点坐标之和除以 4 后按 `L` 取整；`L` 偶时无歧义）。定义**标量、规范不变**的观测量

$$\boxed{\ q_x := \tfrac12\,\mathrm{tr}\,U_{P(x)}\ \in[-1,1]\ }$$

以及它的两体协方差

$$\boxed{\ \Gamma_L(x,y) := \mathrm{Cov}_{\mu_{\beta,L}}\big(q_x,\,q_y\big)\ =\ \langle q_xq_y\rangle - \langle q_x\rangle\langle q_y\rangle\ }$$

把 `Γ_L` 看成 `ℓ²(Λ_L) → ℓ²(Λ_L)` 的自伴算子，`‖Γ_L‖_{2→2}` 为其算子范数。

**临界核**：固定

$$\boxed{\ g_c(z) := \big(1+\|z\|_2\big)^{-4},\qquad \Lambda_L := 1+\sup_{x\in\Lambda_L}\sum_{y\in\Lambda_L} g_c(x-y)\ }$$

（`Λ_L = 2π² ln L + O(1)`；若把 `‖·‖₂` 换成 `‖·‖₁`，主系数变为 `8/3`，两者比值 `3π²/4 = 7.402203`。换核等价于换常数，不影响下面的问题。）

---

## 3. 要证的命题

$$\boxed{\ \textbf{求证：}\qquad \|\Gamma_L\|_{2\to2}\ \le\ C\,\Lambda_L\qquad\text{对一切 }L\text{ 与一切 }\beta\in[1/48,\,2.5]\text{ 一致}\ }$$

其中 `C` 为与 `L`、`β` 无关的绝对常数。

**等价地：** 存在 `C` 使

$$\sup_{\|f\|_2\le1}\ \sum_{x,y\in\Lambda_L}\overline{f(x)}\,\Gamma_L(x,y)\,f(y)\ \le\ C\Big(1+\sup_x\sum_y \frac{1}{(1+\|x-y\|_2)^4}\Big).$$

**这就是我要的全部。** 下面是已知信息与已排除的思路。

---

## 4. 数值事实（`L=6,8,10,12`，`β=2.5`）

记 `χ := (1/L⁴)Σ_{x,y}Γ_L(x,y)`（即 `Γ_L` 在常向量上的二次型除以体积）。

| `L` | `χ` |
|---|---|
| 6 | 0.03192553（run A）、0.03059447（run B） |
| 8 | 0.03295298 |
| 10 | 0.03428803 |
| 12 | 0.03269092 |

- **两次独立运行的 seed 散布 `4.26%`**，`L`-增长仅 `3–4%` ⇒ **`ln L` 增长不可分辨**；且 `L=12` 的值**小于** `L=10`。
- **`χ / Λ_L ≈ 0.011`** ⇒ 目标不等式在数值上留有**约 90 倍**的余量。

壳层和（`S_j := Σ_{‖z‖=j}|Γ_L(0,z)|·g_c(z)` 型的量）：

$$\sup_{L,j} S_j \approx 7.43\times10^{-3},\qquad \text{对 }L=6,8,10,12\text{ 的比值 } 1.006,\ 1.010,\ 0.982,\ 0.925$$

⇒ **`S_j` 与 `L` 无关。**（注：`j > L/2` 的壳层受最小镜像污染，必须从拟合中剔除；在干净壳层 `j ≤ L/2` 上，拟合的有效幂次 `p_eff = 4.5`–`5.1`。）

**⇒ 数值上 `Γ_L` 的衰减快于 `g_c`，目标不等式不紧，余量 `90×`。**

## 5. 我已经排除的四条思路（附理由与数）

**（i）用 `Hess(−log Z)` 的最坏情形界**

把 `Γ` 控制为 `β²·(局部振幅)²`、再对慢变量取 `sup`，得到单边系数 `tanh(π²β/4)`；在 `β = 2.5` 时该系数为 `0.9999912273`，行和必然 `>1`。**排除理由：这是 `\sup` 型最坏情形界，与题中的 `2→2` 范数无关。**

**（ii）把协方差的绝对值包络当"传播权重"做路径和**

**已有一个显式反例说明这条路是错的**：取一个快变量 `x ∈ S³` 与两个边界变量 `y₁,y₂ ∈ S³`，

$$H(x;y_1,y_2)=\beta_W\,x^{\sf T}(y_1+y_2),\qquad y_1=y_2=n,\ |n|=1$$

则条件测度为四维 von Mises 分布 `∝ e^{t n^{T}x} dσ(x)`，`t = 2β_W`。定义"单步复制权重"

$$g := \frac{\beta_W^2}{2}\,\mathbb E_{\mu\otimes\mu}\Big[\big|P_{n^\perp}(X-X')\big|^2\Big]$$

精确计算给出

$$g(n,n)=\frac{3\beta_W^2}{t}\cdot\frac{I_2(t)}{I_1(t)}\Big|_{\beta_W=2.5,\ t=5}=3\cdot6.25\cdot0.14386812=2.697527\ \gt\ 1$$

**⇒ 该"权重"不是次临界的，任何以它为边的路径和都会指数增长。**

**病根可精确定位**：`Hess(−log Z)` 精确分裂为两项

$$\underbrace{\beta_W^2F''(t)(\hat h\cdot)(\hat h\cdot)}_{\text{沿 }\hat h\text{（秩一）},\ \beta=2.5\text{ 时 }0.3184}\ +\ \underbrace{\frac{\beta_WF'(t)}{r}\big[I-\hat h\hat h^{\sf T}\big]}_{\text{正交于 }\hat h\text{（秩二）},\ 2.6975}$$

而反例取 `y₁=y₂=n` 时 `h=2n`、`ĥ=n`，切向量恰与 `ĥ` 正交 ⇒ **反例完全落在第二项**。

**⇒ 结论：必须保留协方差的符号与方向结构，不能用绝对值包络。**

**（iii）用反向"祖先"路径的繁殖系数**

设 `θ_r` 为已观察一段路径后、向过去延伸 `r` 步的条件期望路径数。**可以证明 `θ_r ≥ 1` 对一切参数成立**：不一致状态不可能"无来源"地产生，故给定路径后必然至少有一条延伸，条件概率为 `1`。

**⇒ 排除理由：这是因果性造成的结构性不可能，不是估计不够好。**

**（iv）一个相关的向量值响应算子给出接近的阈值，但不是这道题**

对向量值（有方向）的响应算子做同样的分析，可得阈值 `β_* = 2.244977`（`2.5/β_* = 1.11`）。**但那条量测的是横向（角向）响应，与本题的标量 `q_x` 不是同一个对象，其障碍不传递。**

## 6. 另一个已知输入：自由场情形

若把 `q_x` 换成自由无质量标量场的平方型量（`q ∼ (∂φ)²`），则

$$\mathrm{Cov}(q_0,q_z)\ \sim\ g^4\,\|z\|_2^{-8}$$

而 `‖z‖^{-8}` 在 `d=4` 上可积 ⇒ **目标不等式在此情形下成立，且余量很大。**

反面对照：`d=2` 的同类模型上 `q_x` 不传播（协方差恒为 0）⇒ 不等式平凡成立。

**⇒ 这两个模型都满足目标不等式，所以它们**不能**用来检验不等式是否"够强"——这是本题的一个已知弱点。**
