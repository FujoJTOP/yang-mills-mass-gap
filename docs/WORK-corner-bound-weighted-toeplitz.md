# 第 376 轮：corner 界的推导 —— 粗估太松，需要"加权 Toeplitz"版本

---

## A. 先确认基与范数（避免混淆）

**第 354 轮已核：望远镜式 `(M_f)_{ab}=I_{|a-b|}(\lambda)-I_{a+b+2}(\lambda)$ **就是正交基** `\{u_j=\sin((2j+1)\theta)\}$（`L^2([0,\pi],\tfrac{2}{\pi}d\theta)$`）下的矩阵元（对精确 Haar 积分吻合到 `1.1\times10^{-16}$，含半整数 `j$）。**

**⇒ `T=M_fKM_f$` 的普通矩阵本征值就是物理本征值，`\|\cdot\|$` 就是标准算子范数。**（第 349 轮 `\lambda=0$` 时 `T=K$`、`r=I_2/I_1$` 的核验与此一致。）

## B. 粗估走不通

**从 `T_{ab}=\sum_c(M_f)_{ac}t_c(M_f)_{cb}$ 起，用 `|(M_f)_{ac}|\le I_{|a-c|}(\lambda)$ 与 Neumann 卷积：**

$$|T_{ab}|\ \le\ t_0\sum_cI_{|a-c|}(\lambda)I_{|c-b|}(\lambda)=t_0\,I_{|a-b|}(2\lambda)$$

**但 `I_{|a-b|}(2\lambda)$ 的 Toeplitz 算子范数是 `e^{2\lambda}$`（符号是 `e^{2\lambda\cos\theta}$`）——**远大于 `t_0$`**。**

**⇒ 这条界对 corner 完全无用。**

## C. 正确的收紧方向

**`T_{ab}$` 里的 `c$` 被两边同时卡住：`c\approx a$` 且 `c\approx b$`，故 `c^\ast\approx\min(a,b)$`，于是**

$$|T_{ab}|\ \lesssim\ t_{\min(a,b)}\,I_{|a-b|}(2\lambda)$$

**⇒ corner（`a\gt K$` 或 `b\gt K$`）上带权 `t_{\min}$`，而 `t$` 递减 ⇒ 越远离原点越轻。**

**⇒ 真正需要的是「加权 Toeplitz」估计：**

$$\Big\|\big(t_{\min(a,b)}I_{|a-b|}(2\lambda)\big)_{\text{corner}}\Big\|_{\rm op}\ \le\ ?$$

**这正是第 375 轮那个 `2[t_0\tau(d_0)+t_{K-d_0}]$` 的解析来源，但要把 `\tau(d_0)$` 与 `t_{K-d_0}$` 从"带宽/尾"的启发式换成严格的分块估计。**

## D. 一处已经知道的事实（可作分块估计的锚）

**第 374 轮实测：`T[a,a]/T_{00}$` 与 `t_a/t_0$` 的比值稳定在 `1.45$`–`1.6$`（`a=8..32$`），即对角衰减与 `t$` 同步。**

**⇒ `T$` 在"离开原点"方向的衰减由 `t$` 控制，而在"指标差"方向由 `I(2\lambda)$` 控制。分块时应按这两个方向分别切。**
