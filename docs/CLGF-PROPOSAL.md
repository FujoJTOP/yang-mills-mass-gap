## §2 主猜想 · SCE

### 设定

$$L=\frac{\hat b}{a},\quad N_B=L^4,\quad \Lambda_L:=1+\ln L,\quad \beta_0=2.5$$

`q_x`：块内局部观测量，**每条链路只进有限个 `q_x`**，且一致有界。中心化 `q_x°=q_x−Eq_x`。

$$G_{L,n}(x_1,\dots,x_n):=\kappa_{\mu_{\beta_0,L}}\big(q_{x_1},\dots,q_{x_n}\big)$$

### 两个核

**临界核**（四维恰好不可和，但只有对数发散）：

$$g_c(z):=(1+|z|)^{-4},\qquad \|g_c\|_{\ell^1(B_L)}\ \le\ c_0\,(1+\ln L)$$

**短程核**：

$$g_s\ge0,\qquad \|g_s\|_{\ell^1(\mathbb Z^4)}\ \le\ S\lt\infty,\qquad \sup g_s\le1$$

### [G-SCE] 单临界边连通关联树界

$$\boxed{\ |G_{L,n}(x_1,\dots,x_n)|\ \le\ B^n\!\!\sum_{T\in\mathcal T_n}\ \sum_{e_*\in E(T)}\! g_c(x_{i_*}-x_{j_*})\!\!\prod_{\substack{e=(i,j)\in E(T)\\ e\ne e_*}}\!\! g_s(x_i-x_j)\ }\tag{SCE}$$

**读法**：`T_n` = `n` 个标号顶点的全部生成树；每棵树**恰有一条被标记的临界边**，其余 `n−2` 条一致可和。

> **每一个高阶连通关联簇，只允许出现一个不可和的临界方向，其余方向全部可和。**

**⇒ 所以缺口从「猜一个一致解析半径」变成「猜一条结构断论」——可以逐阶反驳。**

## §3 SCE 推出 GF 机器（全部 `[T]`）

### 3.1 树和引理

对任意 `h ∈ ℓ²(B_L)`：

$$\sum_{x_1\cdots x_n}\prod_i|h_{x_i}|\,g_c(x_{i_*}-x_{j_*})\prod_{e\ne e_*}g_s(x_i-x_j)\ \le\ \|g_c\|_1\,\|g_s\|_1^{\,n-2}\,\|h\|_2^n\tag{T}$$

*证明*：以标记的临界边为桥把树分成两半；反复剥叶，每剥一个用 `Σ_x|h_x|g_s(x−y) ≤ ‖h‖₂‖g_s‖₂ ≤ S‖h‖₂`（`sup g_s ≤ 1`）；剩两个端点用 Young `Σ_{x,y}|h_x||h_y|g_c(x−y) ≤ ‖g_c‖₁‖h‖₂²`。∎

### 3.2 组合计数

$$|\mathcal T_n|=n^{n-2}\ (\text{Cayley}),\qquad (n-1)\ \text{种标记},\qquad \frac{(n-1)n^{n-2}}{n!}\sim\frac{e^n}{n}\le C_0^n\ (C_0\gt e)$$

### 3.3 全阶控制

$$\boxed{\ |\kappa_n(\langle h,Q_L\rangle)|\ \le\ n!\,A^n\,\Lambda_L\,\|h\|_2^{\,n}\qquad(n\ge2)\ }\tag{K}$$

**`A` 与 `n, L` 均无关。**

### 3.4 一致解析半径 + 生成泛函界

$$W_L(J)=\sum_{n\ge2}\frac{\kappa_n(\langle J,Q_L\rangle)}{n!}\ \Longrightarrow\ |W_L(J)|\le\Lambda_L\sum_{n\ge2}(A\|J\|)^n$$

取 `r₀ = 1/(2A)`（`A‖J‖ < 1/2`）：

$$\boxed{\ |W_L(J)|\ \le\ 2A^2\Lambda_L\|J\|_2^2,\qquad \|J\|_2\lt r_0\ }\tag{GF-b}$$

### 3.5 **零点自由性是推论，不是猜想**（关键改进）

```
有限体积、q_x 有界 ⇒ M_L(J) 在复源空间上【整】
累积量级数在 ‖J‖<r_0 内收敛 ⇒ 定义全纯 W_L，且 M_L = e^{W_L} 在 0 的邻域
⇒ 恒等定理 ⇒ 在整个球上相等
```

$$\boxed{\ M_L(J)\ne0,\qquad \|J\|_2\lt r_0\ }\tag{GF-a}$$

$$\boxed{\ \textbf{[G-SCE]}\ \Longrightarrow\ \textbf{(GF-a)}+\textbf{(GF-b)}\ }$$

**⇒ 第 250 轮把 `(GF-a)` 当独立猜想是浪费了一个位置。SCE 一并给出。**

### 3.6 二阶项与块平均

$$e_B=N_B^{-1/2}(1,\dots,1)\ \Longrightarrow\ \langle e_B,Q_L\rangle=\sqrt{N_B}Z_L$$

$$\boxed{\ |\kappa_n(Z_L)|\ \le\ n!A^n\,\frac{\Lambda_L}{N_B^{n/2}}\ \le\ n!A^n\frac{\Lambda_L}{N_B}\ }\tag{L3′}$$

$$\boxed{\ \mathrm{Var}(Z_L)\ \le\ 2A^2\,\frac{\Lambda_L}{N_B}\ }\tag{V}$$

**原点矩（Fubini）**：`Σ F_n z^n/n! = 1/(2−e^z)`，奇点 `z=ln2` ⇒

$$|m_n|\ \le\ C_F\,n!\Big(\frac{A}{\ln2}\Big)^n\frac{\Lambda_L}{N_B}\qquad A'=\frac{A}{\ln2}=1.4427A$$

**⚠️ 术语纪律：`|E Z^n|` ≠ `E|Z|^n`。**

### 3.7 与磁化率的等价

$$\mathrm{Var}(Z_L)=\frac{\chi_q}{N_B},\qquad \chi_q:=\sum_{|z|\lt \hat b/a}C_q(z)$$

$$\boxed{\ \textbf{(GF-a)}|_{e_B}\ \Longleftrightarrow\ \chi_q\ \le\ 2K\Lambda_L\ }$$

**⇒ 所以整台机器的二阶内容 = 「磁化率至多对数增长」。**

**而 `(GF-a)` 在其他方向上是**松的**（单点 `h` 给 `Var(q₀) ≤ 2KΛ_L`，真相 `≤1`）⇒ **它不是一个全局谱性质。**

## §4 缺什么（四件，性质不同）

### [Δ-1] `n=2` 的 `p=4`：**非微扰，且来源不明**

$$|C_L(z)|\ \le\ \frac{C}{(1+|z|)^4}\tag{P4}$$

$$p=4\ \Longrightarrow\ \chi_q\le C\Lambda_L\ \checkmark\ (\text{壳和})$$

**而今晚 `qqq1` 判过：`p = (d−2)+γ₀/b₀ = 2+2 = 4` 是**类型错**（`|z|` 幂与 `ln` 幂不同轴）。**

**⇒ 关键事实：**

$$\text{自由有质量}\Rightarrow p=\infty\ (\text{指数});\qquad\text{自由无质量}\Rightarrow p=2$$

$$\boxed{\ p=4\ \text{既非有质量也非无质量自由场——它是【相互作用边际】那一档}$$

**⇒ 好消息：若真，它是真非微扰结论。坏消息：无现成模板。**

**⚠️ 今晚针对 `p>4` 的八条死路**没有一条**针对 `p=4`。**

### [Δ-2] `Λ_L` 系数的**范数一致性**（记账，但必须先做）

**已有三个 `ln`：**

| 来源 | 系数 | 壳范数 |
|---|---|---|
`O_B`（`uuu3` 机检） | `2π²λ` | 欧氏球 |
`(V)` 家族无序化 | `8/3` | `ℓ¹` 壳 |
`g_c`（本文件） | `c₀` | **待定** |

$$\frac{2\pi^2}{8/3}=\frac{3\pi^2}{4}=7.40\times$$

**⇒ `qqq3` 判过：这是**壳范数选择**，形不变。**

**⚠️ 若三者不统一，`n=3` 的检验会在三个尺度上做，结果不可比。**

### [Δ-3] `n=3` 的 `g_c×g_s` 分解（**第一次真检验**）

`T_3` 有 `3` 棵树、每棵 `2` 边 ⇒ SCE 在 `n=3` 是：

$$|G_3(x,y,z)|\ \le\ 2B^3\big[g_c(x-y)g_s(y-z)+g_c(y-z)g_s(z-x)+g_c(z-x)g_s(x-y)\big]$$

**⇒ 即：三点累积量**恰有一条长边、一条短边**。**

**⚠️ 酸测陷阱：**

$$\text{自由场}\ \Longrightarrow\ G_{L,3}\equiv0\ \Longrightarrow\ \text{SCE 平凡成立}$$

**⇒ 所以 SCE 在 `n≥3` 上**也过不了酸测**（对自由场平凡真）。**

**⇒ 这对 `L3` 不是缺陷（`L3` 必须接受自由场），但记账要写清：SCE 是**存在性**结构条件，**不是隙的判别器**。**

### [Δ-4] Minlos 就绪条件（独立）

$$\text{全部有限体积方向估计}\ \ne\ \text{Minlos 的完整条件}$$

$$\boxed{\ \lim_{\delta\downarrow0}\sup_L\sup_{p_s(f)\le\delta}\big|\chi_L(f)-1\big|=0\ }\tag{M}$$

**⚠️ `Λ_L=1+\ln L` 随 `L` 增长 ⇒ `(GF-b)` 不能直接当 Minlos 条件。**

## §5 双差分路：最有希望的 `[Δ-1]` 攻法（但障碍要说准）

**假设有格点恒等式**

$$C_q(z)=\sum_{\mu,\nu}\nabla^*_\mu\nabla_\nu G_{\mu\nu}(z)+R(z)$$

**⚠️ 障碍（必须说准）：**

$$|G(z)|\le C|z|^{-2}\ \not\Longrightarrow\ |\nabla^2G(z)|\le C'|z|^{-4}$$

*反例：`G` 在 `|z|^{-2}` 尺度上振荡，差分可任意大。*

**⇒ 真正需要的是**二阶差分界**，不是值界：**

$$\boxed{\ |\nabla^*_\mu\nabla_\nu G_{\mu\nu}(z)|\ \le\ C(1+|z|)^{-4}\ }$$

**三条可能来源：**

| 来源 | 今晚判过 |
|---|---|
① 谱表示 + 反射正性（差分作用到 `e^{-tH}` 核） | **`[NG]`**：`ρ≥0` 只给下界，方向反 |
② **Ward 恒等式**（一次差分换成一次插入） | **未碰** |
③ **Schwinger–Dyson 递推** | **未碰** |
