## §0 必须先统一的两个 `β` 规范

**这是全文的第一条纪律，因为不统一则所有数都不可比。**

| 规范 | 作用量 | 指数里的 `Re Tr` 系数 |
|---|---|---|
SZZ | `S = N β_SZZ Σ_p Re Tr Q_p` | `N β_SZZ` |

**两者描写同一 Gibbs 测度 ⟺**

$$\boxed{\ \beta_W = N^2\,\beta_{\rm SZZ}\ }$$

**⇒ 对 SU(2)：`β_SZZ < 1/48` ⟺ `β_W < 1/12 = 0.08333`。**

## §1 为什么原来的靶 `Z_a ≤ Ca^{-4}` 是**假**的

**三行推导：**

$$\begin{aligned}
Z_a&=\frac{\varpi}{a^4\hat b^4},\qquad \hat b\ \text{固定}\ &\Longrightarrow\ Z_a\le Ca^{-4}\iff \varpi\le C\hat b^4=\text{const}\\
\varpi&=\mathrm{Var}(q)+O_B&\\
O_B&\asymp 2\pi^2\lambda\ln(\hat b/a)+4.63\lambda\qquad&(\texttt{uuu3}\ \text{机检：}R{=}4/8/16/32\to 14.26/24.55/36.27/48.89)
\end{aligned}$$

**⇒ 若 `λ` 固定（Wilson 理论的默认）：**

$$\varpi\ \longrightarrow\ \infty\qquad\Longrightarrow\qquad \boxed{\ Z_a\le Ca^{-4}\ \text{为假}\ }$$

**⇒ 所以 24 条“死路”其实都在**证一个假命题**——它们不是失败，是靶错了。**

**⇒ 本立项书的全部意义在于换靶。**

## §2 形式猜想（三层）

### 设定

$$L=\frac{\hat b}{a},\qquad N_B=L^4,\qquad \Lambda_L:=1+\ln L,\qquad \beta_0=2.5$$

`q_x`：块内局部可观测量，**每条链路只进有限个 `q_x`**（局部性）。中心化 `q_x° = q_x − E q_x`。

$$Z_L:=\frac1{N_B}\sum_{x\in B_L}q_x^\circ,\qquad
M_L(J):=\mathbb E_{\mu_{\beta_0,L}}\exp\Big(\sum_{x}J_x q_x^\circ\Big),\qquad
W_L:=\log M_L$$

### 第一层 · 主猜想（两个非微扰输入）

**[G-a] 一致零点自由性**

$$\exists R\gt0:\quad M_L(J)\ \ne\ 0\qquad\forall\,\|J\|_2\lt R,\ \forall L\ge L_0$$

（有限维复球单连通 + `M_L(0)=1` ⇒ 存在全纯对数分支，`W_L(0)=0`。）

**[G-a′] 实源对数次高斯性**

$$\exists K\gt0:\quad 0\ \le\ W_L(h)\ \le\ K\Lambda_L\|h\|_2^2\qquad\forall h\in\mathbb R^{N_B},\ \|h\|_2\lt R$$

**下界**：中心化 + Jensen ⇒ `W_L(h) ≥ 0` `[T]`。
**上界**：**这是全部非微扰内容所在。**

### 第二层 · 分析推论（可证）

**[T] 定理（Borel–Carathéodory）**　`[G-a] + [G-a′] ⟹`

$$\boxed{\ |W_L(J)|\ \le\ 16K\,\Lambda_L\,\|J\|_2^2\qquad \|J\|_2\le \frac R4\ }$$

*证明*：`Re W_L(h+ik) ≤ W_L(h) ≤ KΛ_L‖J‖²`（用 `|E e^{⟨h+ik,Q⟩}| ≤ E e^{⟨h,Q⟩}`）。逐方向 `f_{L,u}(z)=W_L(zu)` 在 `|z|<R` 上 `f(0)=f′(0)=0`、`Re f ≤ KΛ_LR²`。Borel–Carathéodory 在 `r=R/2` 给 `|f| ≤ 2KΛ_LR²`；Cauchy 系（`a₀=a₁=0`）在 `|z|≤R/4` 给 `|f| ≤ 16KΛ_L|z|²`。方向任意 ⇒ 结论。∎

### 第三层 · 测度构造（需独立条件）

$$\text{全部有限体积方向估计}\ \ne\ \text{Minlos 的完整条件}$$

**[Δ-M] 就绪条件**（**独立于 [G-a], [G-a′]**）：

1. 一个**固定**的核检验函数空间 `𝒮`（不随 `L` 变）；
2. 把 `ℓ²(B_L)` 源映射到 `𝒮` 的相容嵌入；
3. 特征泛函 `χ_L` 在零点等度连续：

$$\boxed{\ \lim_{\delta\downarrow0}\ \sup_L\ \sup_{p_s(f)\le\delta}\big|\chi_L(f)-1\big|=0\ }$$

**⚠️ `Λ_L = 1+\ln L` 随 `L` 增长 ⇒ 不能把第二层直接当作 Minlos 条件。**

## §3 由第二层推出的全部阶（统一一条链）

令 `r₀ = R/4`，`u_B = N_B^{-1/2}(1,…,1)`，`Y_L := ⟨u_B,Q_L⟩ = √N_B Z_L`。

由 `|W_L(zu_B)| ≤ 16KΛ_L|z|²`（`|z|≤r₀`）与 Cauchy（`ρ=r₀/2`）：

$$|\kappa_n(Y_L)|\ \le\ n!\,C\Lambda_L\,\rho^{\,2-n}\qquad(n\ge2)$$

$$\boxed{\ |\kappa_n(Z_L)|\ \le\ n!\,C\Lambda_L\,\rho^{\,2-n}\,N_B^{-n/2}\ \le\ n!\,A^n C'\frac{\Lambda_L}{N_B}\ }$$

**（末步用 `N_B^{n/2} ≥ N_B`，`n ≥ 2`。）**

**原点矩（Fubini 转换）**：设 `P_L := C'Λ_L/N_B`，`P_L ≤ 1` 对大 `L`。中心化 ⇒ 单元素块的项消失：

$$|m_n|\ \le\ A^nP_L\sum_{\pi\in\mathcal P(n)}\prod_{B\in\pi}|B|!\ =\ A^nP_L\,F_n$$

**有序 Bell 数（Fubini）**：`Σ F_n z^n/n! = 1/(2−e^z)`，最近奇点 `z=\ln2` ⇒

$$F_n\ \le\ C_F\frac{n!}{(\ln 2)^n}$$

$$\boxed{\ |m_n|\ \le\ C_F\,n!\Big(\frac{A}{\ln2}\Big)^n\frac{\Lambda_L}{N_B}\ }$$

**⚠️ 术语纪律：此式给的是 `|E Z_L^n|`，**不自动等于** `E|Z_L|^n`（绝对矩）。**

## §4 二阶项，以及它与磁化率的等价

$$n=2:\qquad \mathrm{Var}(Z_L)=\kappa_2(Z_L)\ \le\ 2K\,\frac{\Lambda_L}{N_B}\qquad\textbf{([V])}$$

**而由平移不变性：**

$$\mathrm{Var}(Z_L)=\frac1{N_B^2}\sum_{x,y}\mathrm{Cov}=\frac{\chi_q}{N_B},\qquad
\chi_q:=\sum_{|z|\lt \hat b/a}C_q(z)$$

$$\boxed{\ \textbf{[G-a′]}\ \text{在方向 }e_B\text{ 上}\ \Longleftrightarrow\ \chi_q\ \le\ 2K(1+\ln L)\ }$$

**⇒ 所以 [G-a′] 的**全部二阶内容**就是一句：**

$$\text{磁化率至多对数增长}$$

**而 [G-a′] 在其他方向上是**松的**：支在单点的 `h` 给 `Var(q_0) ≤ 2KΛ_L`（真相 `≤1`）；支在两点的 `h` 给 `|Cov(q_0,q_z)| ≤ KΛ_L`（无衰减信息）。**

**⇒ 故 [G-a′] **不是** Poincaré、不是指数聚类、不是任何全局谱性质；它是「一个方向、一个二阶矩、带 log」。**

## §5 缺口：`p = 2 → p = 4`

**壳估计是 [G-a′] 的**充分路**（不是并列任务）：**

$$|C_q(z)|\ \le\ C|z|^{-4}\ \Longrightarrow\ \chi_q\ \le\ C\sum_{0\lt |z|\lt L}|z|^{-4}\ =\ C'\,\ln L\ \checkmark$$

*（二进制壳：壳 `j` 有 `O(2^{4j})` 点、`|z|^{-4}=O(2^{-4j})` ⇒ 每壳 `O(1)`；共 `O(\ln L)` 壳。）*

**主系数**：若 `K(x)=|x|^{-4}+O(|x|^{-4-\epsilon})` 则

$$\sum_{0\lt|x|\le L}K(x)=2\pi^2\ln L+O(1)$$

**而与机检相符（`qqq3`：`S₄−2π²\ln R → 4.63`）。**

### 本轮的实质进展：要求从 `p>4` 降到 `p≥4`

| 靶 | 需要 | 可证 |
|---|---|---|
旧靶 `ϖ ≤ C` | **`p > 4`**（`δ>0`，供给 0） | `p = 2` |
**新靶 `ϖ ≤ KΛ_L`** | **`p ≥ 4`（边际）** | `p = 2` |
窗内 `β_W < 1/12` | `p = ∞`（指数聚类） | **`p = ∞`** `[T]` |

$$\boxed{\ \text{那一根 log 不再需要被【杀掉】，只需要被【装下】}\ }$$

**⇒ 而 `δ>0` 那条“供给 0”的死路**不再是必需的**。**

### 仍然差的两幂

可证者只有（KL 表示，`m=0`）：

$$|C_q(z)|\ \le\ \frac{C_q(0)}{4\pi^2|z|^2}\qquad(p=2)$$

**而 `p=2` 给 `χ_q ≍ L²`，太大。**

$$\boxed{\ [\Delta_p]\quad p:\ 2\ \longrightarrow\ 4\qquad\text{本轮唯一的实质缺口} }$$

**⇒ 关键：今晚针对 `p>4` 的八条死路**没有一条**针对 `p=4`。边际情况常有一个 `ln` 的自由度可用。**

5. **不使用 SZZ 窗作为推导起点，不使用 `β` 轴搬运，不使用分段数 `N`。**
