## A. 确认的（`[T]$`）

**① `\langle e_1,M_1^2e_1\rangle = 0.25$`（两种归一化都核过：`0.25000000042$`、`0.25000000292$`）。**

**② `c_J''(0)$`：**

**`c_1 = \frac{2\cdot2I_2(\beta)}{\beta} = \frac{4}{\beta}\Big(\frac{\beta^2}{8}+\frac{\beta^4}{192}\Big) = \frac{\beta}{2}+\frac{\beta^3}{48}$ ⇒ `c_1'(0)=\frac12$`, `c_1''(0)=0$`。**

**`c_2 = \frac{2\cdot3I_3(\beta)}{\beta} = \frac{6}{\beta}\cdot\frac{\beta^3}{48}+\cdots = \frac{\beta^2}{8}+\cdots$ ⇒ `c_2'(0)=0$`, `c_2''(0)=\frac14$`。**

**⇒ `M_2 = \frac14\mathrm{Op}_2 + \ldots$`**

**③ `\langle e_1,\mathrm{Op}_2e_1\rangle = 0$`（`\mathrm{Op}_2$` 把 `|0,0\rangle\otimes|0,0\rangle$` 映到 `j{=}1\otimes j{=}1$`，与 `e_1$` 正交）。**

**⇒ `\langle e_1,M_2e_1\rangle = 0$`。**
