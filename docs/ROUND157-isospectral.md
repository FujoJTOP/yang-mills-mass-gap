$$\boxed{\ W_1,\ W_2,\ W_4\ \text{在}\ j\le jm\ \text{截断空间上}\ \textbf{同谱}\ }$$

## B. 解析原因（`[C]$`，但极强）

### `W_2$` 与单链同谱

**`W_2=\frac12\tr(u_1u_2^{-1})$`。**

**令 `v=u_1u_2^{-1}$`。由于 `u_1,u_2$` 独立且均匀，`v$` 均匀覆盖 SU(2)。**

**⇒ `W_2$` 与 `\frac12\tr(v)$`（单链）**同谱**。**

### `W_4$` 与 `W_2$` 同谱

**`W_4=\frac12\tr(u_1u_2^{-1}u_3u_4^{-1})=\frac12\tr(v_1v_2)$` 其中 `v_1=u_1u_2^{-1}$`、`v_2=u_3u_4^{-1}$`。**

**`v_1,v_2$` 独立且均匀 ⇒ `W_4$` 与 `W_2$` **同谱**。**

$$\boxed{\ \textbf{所有 }W_n\textbf{ 都同谱于单链 }\frac12\tr(u)\ }$$

## C. 单链 `\frac12\tr(u)$` 的谱

**在 `j\le jm$` 的截断空间上：**

$$\mathrm{spec}\Big(\tfrac12\tr(u)\Big)\big|_{j\le jm}\ =\ \Big\{\cos\frac{k\pi}{jm+2}\Big\}_{k=0}^{jm+1}$$

**（`jm+2$` 个值，从 `\cos0=1$` 到 `\cos\frac{(jm+1)\pi}{jm+2}=-\cos\frac{\pi}{jm+2}$。）**

**⚠️ 上表的 `W_{\max}$` 只是**最大**的那个。**

**⇒ `W_{\max}=\cos\frac{\pi}{jm+2}$` 是**次大**值？**

**⚠️ 但数值给 `W_{\max}=\cos\frac{\pi}{jm+2}$`，不是 `\cos0=1$`。**

**⇒ 公式需要核对。**

## D. 核对

**`jm=1$`（`j\in\{0,\frac12\}$`，`dl=5$`）：单链 `\frac12\tr(u)$` 的谱是 `\pm0.5$`。**

**⇒ 只有两个值 `\pm0.5$`，不是 `\{1,\frac12,0,-\frac12,-1\}$`。**

**⚠️ 所以 C 的公式**不对**。**

**正确的谱（`jm=1$`）：`\{\pm0.5\}$`。**

**`jm=2$`：`\{\pm0.7071,\ldots\}$`。**

**⇒ 谱是**对称**的（`\pm$`），且**最大 = `\cos\frac{\pi}{jm+2}$`。**
