# 第 58 轮：**更正** —— 块三对角属于 `Sq$`，**不是** `T$`；高度阶梯 RG 不直接适用

---

## A. 更正（`[T]$`）

**第 55/57 轮把「块三对角」用在了 `T$` 上。这是**错**的。**

**事实：**

**① `Sq=\sum_Pq_P$` 是**精确**块三对角（`q_P$` 只改 `h$` 为 `0,\pm2$`）—— 第 8 轮。**

**② `T=M_fKM_f$` 含 `M_f^2=e^{-\beta_s}e^{\beta_s Sq}$` —— **指数**把 `h$` 混合到所有阶。**

**③ 第 236 轮的数值：`T$` 在 `|Δh|=4,6$` 上有非零块（`0.0205$`、`0.0027$`）。**

$$\boxed{\ \textbf{块三对角属于 } Sq,\ \textbf{不属于}\ T\ }$$

## B. 于是

**① 高度阶梯 RG 的 Schur 补递推（第 57 轮）适用于 **`Sq$`**，不是 `T$`。**

**② 而物理量（`t_1,t_2$`）是 **`T$`** 的本征值。**

**③ `Sq$` 与 `T$` 的谱**没有**简单关系（`T$` 是 `Sq$` 的指数乘以 `K$`）。**

$$\boxed{\ \textbf{高度阶梯 RG 不直接适用于质量隙问题}\ }$$

## D. 这留下了什么

**① `Sq$` 的结构（块三对角 + 低秩）是真的、干净的。**

**② 但它管的是 `Sq$` 的谱，不是 `T$` 的谱。**

**③ 质量隙问的是 `T=M_fKM_f$` 的谱。**

**④ `M_f$` 与 `Sq$` 的关系是指数 —— 这恰好**破坏**了块三对角。**

**⇒ 高度阶梯 RG 需要**重新设计**：不能从 `T$` 的块结构出发，而必须处理 `M_f$` 的**指数**。**

## E. 一个可能的补救

**① `M_f=e^{-\beta_s}e^{\beta_s Sq/2}$`，`Sq$` 块三对角。**

**② 在**每个块内**，`Sq$` 的对角块 `Sq_h$` 是 `N_h\times N_h$`。**

**③ `e^{\beta_s Sq/2}$` 的块结构 = `e^{A}$` 的块结构，`A$` 块三对角 —— 这可以用**块 Lanczos / 连分式**处理。**

**④ 但块维数 `N_h$` 天文数字 ⇒ 仍需低秩近似。**

**⑤ `Sq$` 的块 `\mathcal T_h$` 秩 `\le d^2$` ⇒ 可以用**低秩块指数**的算法（Krylov 在低秩子空间）。**

**⚠️ 这是**新的算法设计**，不是现成的。**
