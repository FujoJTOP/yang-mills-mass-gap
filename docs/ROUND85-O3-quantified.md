## C. 于是 O3 的精确陈述

$$\textbf{(O3)}\qquad \text{任何「秩截断 + Weyl」型的界都需要 } N\gtrsim\sqrt\beta\ \Longrightarrow\ \text{无一致于 }\beta\to\infty\text{ 的界}$$

**⇒ 单链 `(R)$` 对**每个固定 `\beta$`** 成立（`N$` 取 `7.8\sqrt\beta$`），但**不是 `\beta$`-一致**的。**

**⇒ 连续极限（`\beta\to\infty$`）需要一条**不解析尾部**的界。**

## D. 破 O3 需要什么

**要一条 `\beta$`-一致界，必须避开"分辨 `j\lesssim\sqrt\beta$` 的谱"。可选：**

1. **变分界：用 `\beta$`-无关的测试族 `g$` 直接给 `t_2/t_1$` 上界（`t_2\le\max_{\{x,y\}}`-型的 min-max，配固定 `g$`）；**
2. **`\operatorname{tr}(T^2)/t_1^2-1$ 型的界（第 60–66 轮），它**不需要**分辨单个 `t_j$` —— 但要 `t_1$` 的下界，且 Laplace 主项在中等 `\lambda$` 失效（第 73 轮）；**
3. **格点侧的全新谱估计（Balaban 型 RG 或面模型）—— 不在单链模型里。**
