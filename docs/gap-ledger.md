# 距无条件定理的精确缺口清单

> 2026-11-23 · 建立在 `docs/conditional-theorem.md`（`IN-0 … IN-11`）之上。
> 一句话：**条件定理"距离无条件"= 还没解的那半个 Clay 问题本身。** 本清单把这道距离拆成
> 可逐条记账的缺口，每条标注**可攻性**与**所需新工具**。

## 0. 先把"距离"说清

无条件定理 = Clay 陈述 = **（A）严格构造 4D 纯 YM 量子场论** 且 **（B）证明质量间隙**。

我们的条件定理把 (A)、(B) 都写成具名输入 `IN-0 … IN-11`，并**证明"除此之外不需要别的"**
（9 条粘合引理全部机器验证封闭）。所以"距离"**不分布在下一步/下一百步**，而**全部集中在这
12 个输入被逐个兑现**。下面按性质分层。

## 2. 缺口（兑现才能无条件）——四层

### G1 · 构造（Clay 的"存在"半边）
- **输入**：`IN-0, IN-1, IN-2, IN-6, IN-7, IN-8, IN-9`。
- **本质**：4D 纯 YM 的非微扰测度构造 + 连续统极限 + 唯一真空 + RG 一致性。
- **可攻性**：**这就是 Clay 问题 (A) 半本身**，不是更小的子问题。`IN-9`（谱预解收敛）较窄，
  但核心（非微扰 4D 测度 + 连续统）开放，无已知路线。
- **所需新工具**：一个能同时处理**规范 + 非微扰测度**的 4D 构造性 QFT 框架（现无）。
- **波 2 精确定位（W2-2）**：缺的是**边际情形下截断一致、规范协变（保 Ward/BRST）的 BPHZ 定理**；
  2D 已完整构造、3D YM-Higgs 只到局部时间、纯 3D 仍 open；唯一解过的边际 SPDE（4D Φ⁴）平凡。
  判定：**"无已知想法"缺口**（非已证不可能）。

### G2 · 那堵墙（Clay 的"间隙"半边，且 ≡ 原问题）
- **输入**：`IN-3, IN-4`（+ 交叉证书 + `IN-10` `hcert` 量级桥）。
- **本质**：非微扰 4D 交叉。**交叉证书是 gap 的一条充分路线**（`cert+IN-10+IN-11⇒gap`）；但 `cert>0` 本身**严格弱于** gap，**必要性 `gap⇒cert` 未证**（红队 W3-C1）——"卡在 cert ≠ 卡在 gap"，证书外的路线**未被排除**。
  位置是具体的：接缝落在 `λ≈7.3 / β≈2.47`，恰是 Savvidy 负模 ~49%（β=2.5）、单圈图像最失效处。
- **可攻性**：**这就是 Clay 问题 (B) 半本身**。10 方法图的结论：**9 条撞同一堵物理墙**
  （cluster、N-展开、Stein/SLC、Savvidy、4D SPDE、resurgence、有限格 FSS、面积律、DSE），
  1 条（反常/广义对称）是另一扇门，但通向 G4 的方法真空。
- **所需新工具**：控制**强耦合 IR 的符号/振荡权重**（BL-6 signed gas）的东西，或一条**真正
  跨过 Savvidy 点**的新 RG。现无。
- **波 2 精确定位（W2-1/W2-3）**：正性方案**不避开**交叉——裸测度正性 ⇒ 小活度/面展开的收敛界
  是真实的实轴 Pringsheim 屏障，可证半径仅 `1/48`（Shen–Zhu–Zhu 2204.12737），交叉点需
  `β≈2.47`（约 100×），细化只 ~1.3×。**"符号问题" = "小活度墙"：同一障碍、两面。** 最接近的
  小 S¹ bion 可严格化，但 ℝ⁴ 极限所需恰是目标 RG 定理。

### G3 · 物理输入（"证不出来"，只能命名）
- **输入**：`IN-11`（`IN-b`：最轻 bulk 态在 `0⁺⁺/2⁺⁺`）。
- **本质**：格点事实（Morningstar–Peardon：`0⁺⁺` 1710 MeV、`2⁺⁺` 2390 MeV），非对称性保护
  （迹反常不保证最轻态自旋-0）。
- **可攻性**：要从第一原理"证"它，等价于**钉死 YM 低谱的量子数**——又是谱问题，难度 ≈ gap 本身。
  故 G3 **也不比问题小**；现实中只能作为物理前提。
- **所需新工具**：无已知；或造出能锁死低谱量子数的定理（= 另一种 gap 证明）。

### G4 · 方法真空（关掉一条攻击路，不是缺口本身）
- **对象**：DB 路线的 `(iii)`（纯规范 4D CFT ⇒ 自由）。
- **本质**：**不存在 4D CFT 唯一性定理**；SDPB 只给谱空间每点的严格界，**不能**排除连续谱上
  的所有相互作用 CFT。
- **后果**：这条攻击 G2 的路**堵死**；最强只能得**部分排除** `δ_bootstrap`（其上有相互作用窗口存活）。
- **所需新工具**：一条 4D CFT 唯一性定理（现无），或放弃 bootstrap。

## 4. 一句话

**"距无条件定理" = G1 + G2 + G3，而这三层各自都是（或等价于）Clay 问题的一半，不是它的残余。**
因此不存在"完成百分比"。除非出现 G1/G2/G3 中任一所需的**新工具**，否则这条路线的诚实上限就是
**条件定理 + 部分排除**。本清单的价值，是把"差多少"变成"差在哪、需要什么"，而不是包装成"快到了"。

## 5. 唯一能翻盘的清单

- 一个可用的 **4D 非微扰构造性 QFT**（解 G1）。
- 一个控制 **强耦合 IR 符号权重** 的方法（解 G2 的 BL-6）。
- 一条 **4D CFT 唯一性定理**（解 G4，让 bootstrap 真正有用）。
- 或一个全新的外部想法：**精确可解极限 / 可积性 / 带证明的全息对偶**——任一成真，距离的重心就会移动。
