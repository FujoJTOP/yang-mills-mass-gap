## 5. 唯一未闭项

```
a_k σ ≥ 8  ∀k
```

`σ` 固定、`a_k = b^k a → 0` ⇒ 该条件**只对 `k ≤ k_max` 成立**（`k_max` 由 `b^{k} a σ ≥ 8` 定）。

⇒ **构造给出的是 `k ≤ k_max` 的 UVS；`k → ∞` 需要 `σ = σ(k)`，而 `fax` 里 `σ` 固定。**
⇒ 这不是估计问题，是**构造与目标不匹配**（与项目宪章 §5「那台机器尚不存在」同一件事）。

## 6. 引用纪律

1. **任何 `C` / `c*` / `L` 的引用必须带「冻结表 §1」**，禁止逐处取新值。
