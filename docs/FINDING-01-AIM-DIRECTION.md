## §1 事实 A：`G″` 是**上界**，不是谱底

`GM1` 把三件事钉死了（`[T]`）：

1. **`G″|_{k=0} = 1/χ = 1/∫s⁻¹dν` 不是任何谱底。** 它是零能**预解二次型的倒数**。
2. **它是 `m₁²` 的上界**：`λ₁ ≤ 1/χ`（`Q6:132`）；等价的调和平均 ≥ 最小值（`Q6:93`）；**等号 ⟺ 单原子**（`Q6:159–160`）⇒ `G″ ≥ λ₁`。
3. **正确靶算子是 `A := −(1/a)·log T|_{Ω^⊥}`**，靶 = `inf σ(A) ≥ δ`；而 `βS_W` 根本不是算子（它是 `∂_βH` 的比例）。

**后果（这一条最反直觉）**：

```
gap  ⇒  (★)          （因为 λ₁ ≥ δ ⇒ G″ ≥ λ₁ ≥ δ）
¬(★) ⇒  ¬gap         （逆否，**决定性**）
(★)  ⇒  ?            （什么也没有）
```

⇒ **`(★)` 是"证出来没用、证不出来才有用"的量。**
`GX1` 花一整轮把 `(★)` 逐壳层打成五个 `(B)`（`GW4/GC2/GW8/GC3` 的继承），**结论对 Clay 的真假不构成任何证据**——它只说明"用 `G″` 这个量凑不出地板"。这不是 `GX1` 的错，是**瞄准点先错了**。


## §3 两侧都错的示意

```
                更弱 ←──────────────────────────────→ 更强
   (★)  ────────────  gap (Clay)  ────────────────  (Q)
   证出无用              真目标                证出可得但更难
   证伪决定性            （无等价形式）           （只保下界、不保上界）
```

- 左侧：**必要条件**。它假 ⇒ 目标假；它真 ⇒ 什么也不知道。

- 中间：**空**。语料里没有任何一处"既不更强也不更弱"的等价陈述——`GH1a` 已证四版 `H1` **`0/4` 对等价**，`GH1b` 已证 `H1 ↔ gap` **双向皆假**（2D：`Δ_dyn=0` 而 `m>0`；M6：`Δ_dyn=2ω` 而 `m→0`）。
