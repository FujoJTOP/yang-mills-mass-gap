# 第 163 轮：`V\equiv1$` 时 `r=I_2/I_1$` 对**任意 `L_s$` 精确**；`V$` 的领头效应是 `r=\frac{I_2}{I_1}(1+\frac{\beta_s}{2}+O(\beta_s^2))$

---

## A. `V\equiv1$` 的精确性（`[T]$`，`T$` 级）

**`V\equiv1$` ⇒ `T=K_1^{\otimes n}$` ⇒ 本征值是乘积 `t_{j_1}\cdots t_{j_n}$`。**

**顶两个：`t_0^n$` 与 `t_0^{n-1}t_1$`。**

$$\boxed{\ \frac{t_2}{t_1}=\frac{t_1}{t_0}=\frac{I_2(\beta)}{I_1(\beta)}\qquad\textbf{对任意 }n=L_s\text{ 精确}\ }$$

**⇒ `(R)$` 的界在 `V\equiv1$` 时对**任意链数**是**等式**。**

**⇒ 单链 `(R)$` 的「不是格点」这一条（障碍 1），在 `V\equiv1$` 时**消失** —— 链数无关。**

**⇒ 一切 `L_s$`-依赖**只来自 `V$**`。**

## B. `V$` 的领头效应（数值）

$$\boxed{\ \frac{dr}{d\beta_s}\Big|_{\beta_s=0}=\frac12\cdot\frac{I_2}{I_1}\qquad\Longrightarrow\qquad r=\frac{I_2}{I_1}\Big(1+\frac{\beta_s}{2}+O(\beta_s^2)\Big)\ }$$

**（三个 `\beta_t$` 的比值 `0.50000$`、`0.49983$`、`0.49904$` —— 与 `\frac12$` 差 `1.6\times10^{-3}$` 以内，且差值随 `\beta_t$` 略增，像是 `O(\beta_t^{-1})$ 的修正。）**

## C. 这确定了什么

**① `V$` 的**一阶**效应是**抬高** `r$`（缩减隙），系数 `+\frac12$`。**

**② 结合第 111 轮的峰 `r=0.6786$`（`\beta_s\approx2$）：**

$$1-r=0.3214\quad\text{vs}\quad 1-\frac{I_2}{I_1}=0.4928$$

**⇒ `V$` 把隙从 `0.4928$` **压到** `0.3214$`（`\beta_s\approx2$` 处），仍**正**。**

**③ 结合第 130 轮：`\beta_t\to\infty$` 时 `V$` 的效应消失（`r\to I_2/I_1$`，但 `I_2/I_1\to1$）。**

**⇒ 结论：`V$` **总是**抬高 `r$`（缩减隙），从不降低。**
