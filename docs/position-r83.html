5. 限定

  • 数值主参照点 β = 2.5；关键量在 β ∈ {1, 2.5, 4, 10} 上抽查一致。
  • 两链计算上限 J_out ≤ 2（3025 维）；J_out = 3 需 3.1 GB / 19600 维。
  • 单链结果不覆盖格点：V 非逐链乘积（O1 已判 [F]）、两链截断不收敛（O2）、K ~ β 无界（O3）。
对 Clay 的诚实陈述：单链 (R) 即使证完，也不改变 Clay 的可达性——它落在 L_s = 2，而格点需要格点自己的谱估计（Balaban 型 RG 或面模型），那条路当前三条障碍都没过。
