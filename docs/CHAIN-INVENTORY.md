## §0 准入规则（三条，缺一不录）

1. **它是链上某一步的直接输入**（不是「相关」，不是「曾经用过」）。
2. **有可指的锚点**：文件 + 行（本台账全部给出）。
3. **判级写明**：`[T]` / `[C]` / `[U]` / `[E]` / `[M]`；判级冲突的必须标出（见 §6）。

计数单位：
- **机器** = 可独立陈述的证明装置（有输入、有输出、可整体引用或整体替换）；
- **物种** = 方法族（同一类论证的家族，换族 = 换物种）；
- **工具** = 单条引理 / 不等式 / 恒等式（可一行引用）。
