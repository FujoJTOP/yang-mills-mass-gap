# 第 51 轮：`(v,w)$` 解耦的生死点 —— **`K_1(w,w')$` 不是 `\delta$`，解耦不成立**

---

## A. 要查的东西

**在 `(v,w)$` 坐标（`u_1=vw$`、`u_2=w$`）下：**

- **`f(u_1u_2^{-1})=f(v)$` ⇒ `M_f=\hat M_v\otimes I_w$` ✓ 好**
- **`K=K_1\otimes K_1$` ⇒ `K_1(vw,v'w')\,K_1(w,w')$**

**若 `K_1(w,w')\propto\delta(w-w')$，则整个问题在 `w$` 上解耦，两链变「一族单链问题」，O2 消失。**

## B. 答案：**不成立**

**`K_1$` 在特征标基下是对角的，本征值 `t_j=2I_{2j+1}(\beta)/\beta$。⇒ 它是一个**类函数核**：**

$$K_1(w,w')=\sum_jt_j\,(2j+1)\,\chi_j(ww'^{-1})\cdot(\text{归一化})$$

**⇒ 是 `ww'^{-1}$` 的光滑函数（`K_1(I)\neq0$、`K_1(\text{远离单位元})` 小但非零），**不是 `\delta$`**。**

**（对照：第 341 轮那个闭式 `K(\theta,\varphi)=\frac{1}{2\beta}(e^{\beta\cos(\theta-\varphi)}-e^{\beta\cos(\theta+\varphi)})$ 在 `\theta=\varphi$` 处为 `0$`，在 `\theta-\varphi=\pi$` 处负 —— 它连正定都不是，更不是 `\delta$`。）**

$$\boxed{\ \text{⇒ }(v,w)\text{ 解耦不成立，O2 不会被这一招化解}\ }$$
