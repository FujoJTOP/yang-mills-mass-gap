## C. 这解决了第 105 轮的担心

**第 105 轮担心 `r(L)$` 升向 `1$`。**

**⇒ 本轮的曲线说明：`r$` 是 `\beta_s$` 的**有界非单调**函数，两端都回到 `I_2/I_1$`。**

**⇒ **两链模型确实有质量隙**（`1-r\ge0.324$`），不是「趋近 1」。**

## D. 结构解释（为什么两端同值）

**`\beta_s=0$`：空间 plaquette 无约束 ⇒ `T=K=K_1\otimes K_1$` ⇒ `r=\lambda_2/\lambda_1=t_1/t_0=I_2/I_1$` ✓（`[T]$` 级）**

**`\beta_s=\infty$`：空间 plaquette 冻结到 `q_P=1$` ⇒ `u_1=u_2$` ⇒ 有效自由度塌缩到一个 `SU(2)$` ⇒ `r$` 回到单链值。**

**⇒ **两条极限都由单链结构定**，中间由 plaquette 耦合抬高 `r$`（但不越过 `0.68$`）。**

## F. 下一轮

**把 D 节两条极限写成 `[T]$`：**

1. **`\beta_s=0$`：`T=K$` 对角 ⇒ `r=I_2/I_1$` ✓ 已经是 `[T]$`；**
2. **`\beta_s\to\infty$`：需要证「平坦约束 ⇒ 有效单链」。这是 `q_P=1$` 的 delta 约束，`SU(2)$` 的 `q=\frac12\tr(u_1u_2^{-1})=1$ ⟺ `u_1=u_2$`（因 `\tr(g)=2$ ⟺ `g=I$`）✓**

**⇒ `u_1=u_2$` 是**精确**的 ⇒ 有效自由度是一个 `SU(2)$` ⇒ `T$` 限制到 `K_1$`（单链）⇒ `r=I_2/I_1$` ✓ `[T]$` 级。**

**⇒ 两端的 `[T]$` 都成立；中间的峰 `0.676$` 是 `[M]$`。**
