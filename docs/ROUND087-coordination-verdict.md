## 2. `jm$`-收敛（`[T]$`）

**`star k=2$`：`jm=2,3,4$` 给 `0.6835$`、`0.7161$`、`0.7202$`。**

$$\boxed{\ r(k=2,\ jm\to\infty)\ \approx\ 0.721\ }$$

## 3. 4D 格点的外推（`[M]$`）

**用 `jm=2$` 的 `k$`-序列做 `k$`-外推（`k=1..4$`、差比 `0.71,0.78$`）：**

$$r(k=6,\ jm=2)\ \approx\ 0.7564+0.0320\times0.78+0.0320\times0.78^2\ =\ 0.8009$$

**加上 `jm$`-修正（`jm=4$` 的 `k=2$` 是 `0.7202$` vs `jm=2$` 的 `0.6835$` ⇒ `+0.0367$`）：**

$$\boxed{\ r(4D)\ \approx\ 0.8009+0.0367\ =\ 0.8376\qquad m\,a\ \approx\ 0.1773\ }$$

## 4. 定论

**① `r$` 随配位数 `k$` 单调升（`k=1..4$`，两个 `jm$` 都验证）。**

**② `r$` 随 `jm$` **收敛**（`k=2$`、`jm=4$`：`0.7202$`）。**

**③ 4D 格点（`k=6$`、`jm\to\infty$）的外推：`r\approx0.8376$`。**

**④ ⇒ `m a=-\ln r\approx0.1773$。**

**⑤ **仍**远离 0 ⇒ 配位数方向**不**单独给连续标度。**
