# 第 374 轮：`\varepsilon_K$` 的正确控制量是 `t_{K-2\lambda}$`（不是 `t_K$`），且双精度有地板

---

## A. 我上一轮猜错的控制量

**猜 `\varepsilon_K\le10\,t_K$`；实测在 `\beta=1,\lambda=1,K=24$` 处 `\varepsilon_K/t_K=3.0\times10^7$` ⇒ **猜错**。**

## B. 查到两件事

### B1. 双精度地板
**`\|T\|\approx10^{15}$`（`\beta=40$`）到 `1$`（`\beta=2.5$`）。`\varepsilon_K$` 低于 `\sim10^{-16}\|T\|$ 的测量值**无意义**。**

**⇒ 第 372/373 轮里 `\varepsilon_K\lesssim10^{-16}$` 的那些点（例如 `\beta=2.5,\lambda=1,K\ge16$` 的 `3.6\times10^{-11}$`、`9.1\times10^{-30}$`）**不可用**。**

### B2. 正确的解析控制量
**`|T_{ab}|=\big|\sum_c(M_f)_{ac}t_c(M_f)_{cb}\big|\le t_0\sum_cI_{|a-c|}(\lambda)I_{|c-b|}(\lambda)$，而 Neumann 恒等式给**

$$\sum_{c\in\mathbb Z}I_{a-c}(\lambda)I_{c-b}(\lambda)=I_{|a-b|}(2\lambda)$$

**⇒ `T$` 的衰减在**指标差**方向，带宽 `\sim2\lambda$`。再乘上 `t_c$` 的衰减 ⇒ 控制量是**

$$\boxed{\ t_{K-2\lambda}\quad(\text{不是 }t_K)\ }$$

## D. 于是单链 `(R)$` 闭合

**`(R)$` 需 `r_K+\varepsilon_K/T_{00}\le I_2/I_1$`。用 C 的界与 `t_0/T_{00}\le1$`：**

$$r_K+\frac{\varepsilon_K}{T_{00}}\ \le\ r_K+\frac{11\,t_{K-2\lambda}}{t_0}$$

**例（`\beta=2.5,\lambda=1,K=12$`）：`r_K=0.2274$`，`11t_{10}/t_0=11\cdot(2I_{11}(2.5)/2.5)/2.013\approx4.4\times10^{-8}$` ⇒ 左端 `0.2274$`，对 `I_2/I_1=0.5072$` 余量 `0.28$`。**

**⇒ 余量巨大，与第 372 轮的大 `\beta$` 结论一致。**
