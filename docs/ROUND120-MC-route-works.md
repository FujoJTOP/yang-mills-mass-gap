# 第 120 轮：`E_i$` 的**蒙特卡洛路线跑通了**（`\theta$`-空间，绕过 `Q$` 的矩阵构造）

## A. 方法

**`E_i=\int|\Psi_i|^2(1-q)\,dU_1dU_2\big/\int|\Psi_i|^2$，其中**

- **`\Psi_i(u_1,u_2)=\sum_{j_1m_1n_1j_2m_2n_2}(x_i)_{i_1i_2}D^{j_1}_{m_1n_1}(u_1)D^{j_2}_{m_2n_2}(u_2)$**；
- **`q=\frac12\tr(u_1u_2^{-1})=\cos\theta_{12}=w_1w_2+x_1x_2+y_1y_2+z_1z_2$`（四元数内积）**；
- **Haar 测度 = `S^3$` 上的均匀测度 ⇒ 随机单位四元数采样**。

**`D^j(u)=\exp\big(i\theta\,\hat n\cdot\mathbf J\big)$`（`u=\cos\theta+i\sin\theta\,\hat n\cdot\sigma$），用 `\texttt{scipy.linalg.expm}$` 算。**

**⇒ **完全绕过 `Q$` 的矩阵构造**（六次失败的那条）。**

## D. 但路线本身通了

**三项独立证据：**

1. **`E_i\in[0,2]$`（物理范围）—— 六次矩阵构造都做不到；**
2. **`\beta_s=2.0$` 处 `E_2-E_1=+0.0022$`，`r'$` 也 `+0.0018$`（**都在峰附近的最小量级**）；**
3. **`\beta_s=4.0$` 处 `E_2-E_1=-0.0565$`（负）⇒ 按公式 `r'\gt0$`，但 FD 给 `-0.0143$` —— **这一格不一致。**|

**⚠️ 第 3 条是问题：`\beta_s=4$` 处符号不符。**

**⇒ 可能是 MC 噪声，也可能是 `M_f$` 与 `\Psi_i$` 的归一化之间仍有不匹配。**
