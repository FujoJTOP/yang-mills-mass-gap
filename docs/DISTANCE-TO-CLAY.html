还差什么

缺的是一条 (L,a)-一致的下界。六路独立收敛之后，它有三个同强的名字，而第一个至今没有一路真正攻过。

  • H1 χ 在 (L,a) 上一致有界已判 [NG]，附六个具名证书。三处必须记的更正：其一，χ ≤ (1−c)/λ 不是 H1 的等价改写，而是 H1 加两个合取项（高斯识别 S=1/Var(a) 与缺陷引理 η≤c），所以它强于 H1；c 在存在读法下可被 λ 吸收，零内容。其二，裸形 χ ≤ 1/λ 在 a-一致读法下量纲错（裸 χ ~ a⁻⁴），必须用比值形 G″_a/a² ≥ Δ₀²。其三，六路收敛在名字上，不在内容上：一条相等、两条严格更强、三条不触及。

    统一死因：H1 说的是 ν 在 0 附近的支撑，而仓内全部工具通过积分读 ν（矩按 Schur-凹看不见支撑底、正性只压非对角、逐点曲率点值不等于 ess inf）。偷渡点正是 1/χ = 调和平均 这条恒等式。     [NG]
  • I2 隔离 Λ★ > m₁²对象是 ¼trF² 的连通 KL 测度，不是 H 的谱。三处强度必须记准：其一，它相对原子地板 I1 严格强（I2⇒I1 而 I1⇏I2），这是它唯一严格强于的对象。其二，它相对 Clay 是不可比（正交轴）：M6 上 I2 真而 m=0，2D 上隙正而 ν≡0；此前记成"Clay 上一级"是误标。其三，地板要的是加强版 I2^W: Λ★ > R̄ := M₁/M₀，I2 只给 f₁²>0。

    数据侧已关闭：有限矩 / 正性 / Hankel / Stieltjes 数据都不能下界 Λ★−m₁²，这是具名 no-go；有限 t 的关联函数正属此类。另有一处对象错位：s₂ 是源的第二支撑点，恒有 s₂ ≥ λ₂，而变分第二本征值与它无定向。     在攻
  • CP (CP) 单一禁闭相已判：它有三种命题混写。换名段 Ω ≥ c 与靶逐字同一；假等价段 Ω=1 ⇔ (CP) 方向反了，X 模型与 2D YM 各给一个反例；加码段 I1∧I2 在 I1⟺I2 时塌成靶的 ∀β 版，不塌时缺 IN-11 连隙都不蕴含。唯一非靶的 [CP-a] 被蕴含且酸测空，贡献恒为零。 [NG] 作路线
“只有三类模数”这句话不是 [T]，是候选池。已查明两点。其一，表内四个成员里“独立且充分”的有 0 个：① 只给标度，② 逐字是靶的另一坐标（m = −log λ₂ = inf supp ν），③ 不充分，④ 是输出不是输入。其二，至少两个仓内已判死的形态不在表内：拓扑-整数类、谱盲热力学类。它们都已关闭，但也都没被表内任何一个覆盖。所以漏的是表，不是路：下一步应当按资格三腿重新枚举，而不是在旧表里挑。
