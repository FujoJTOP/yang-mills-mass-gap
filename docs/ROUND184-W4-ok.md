## A. `W_4$` 的构造核对（`[T]$`）

**第 113/153 轮的 `W_4$` 构造：**

```python
for (p,q) in idx:
    A=u[(p,q)]                      # (u_1)_{pq}
    for (r,s) in idx:
        Bm=u[(q,r,'c')]             # (u_2^{-1})_{qr}
        C=u[(r,s)]                  # (u_3)_{rs}
        Dm=u[(s,p,'c')]             # (u_4^{-1})_{sp}
        term=kron(kron(kron(A,Bm),C),Dm)
```

**指标链：`p→q→r→s→p$`。**

$$\sum_{p,q,r,s}(u_1)_{pq}(u_2^{-1})_{qr}(u_3)_{rs}(u_4^{-1})_{sp}\ =\ \tr(u_1u_2^{-1}u_3u_4^{-1})$$

**⇒ `W_4$` 的构造**正确**。**

**⇒ `W_2$` 的 bug 是**指标不匹配**；`W_4$` 用的是**正确的链**。**
