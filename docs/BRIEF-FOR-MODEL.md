# 简报：4D 纯 SU(N) Yang–Mills 质量间隙 —— 真正的墙在哪，新想法必须做什么

> 给任何"找方法"的模型：请先读完，再动手。本战役已试 ~110 路、11 个数学物种，**全撞同一墙**；最近 3 个"新物种"还是已存死路的再发现。**别交第 13 个机制名字。**

## 0. 真正有用的任务（三选一，而不是"再想一个机制"）
- **(A) 审计**一个"声称解决"的具体构造，找出它偷偷假设了哪一步（最有价值）。
- **(B) 造一个新工具**，必须满足下面 5 条硬条件、且**对自由无质量场失效**（不是旧不等式的换皮）。
- **(C) 攻一个具体可证伪子目标**（见 §5）。

**输出纪律**：每个结论标注 **真定理 / 条件定理 / no-go / 精确缺失步**。禁止把程序、猜测、数值说成定理。

## 1. 问题精确化
- Clay = **G1 存在** + **G2 谱隙** `spec(H)⊆{0}∪[Δ,∞)`, Δ>0。
- 单算子版：隙 ⟺ KL 谱测度 ν 在 `m₁=inf supp ν` 有原子 `f₁²=ν({m₁²})=|⟨0|trF²|G⟩|²>0`，**且隔离**。
- **必读更正（本战役最后才做对）**：常见的"方差/曲率"量 `G″(k=0)=1/χ`（χ=磁化率）**是逆磁化率、不是隙**；它只 **上界** `m₁²`（squeeze `f₁²/χ ≤ m₁² ≤ M₀/χ`）。真正的隙 = 谱边 `m₁` + 边残数 `f₁²≥r₀` + 隔离 = **H\***。**不要再拿方差/susceptibility 冒充隙。**

## 2. 任何工具必须满足的 5 条（缺一即死）
1. 非微扰；
2. **sign-controlling 下界**（`m_eff²(k→0)≥λ` 或 `f₁²≥r₀`，不是值、不是上界）；
3. 非循环（不预设隙/凝聚/`m_g>0`）；
4. 非 SUSY + **对自由无质量场失效**（自由：`f₁²=0`、`G″=0`，工具必须失效，否则 vacuous）；
5. `(L,a)` 一致下界。

## 4. 别再用"软模直觉/新名字"绕——三条硬结论
- **反局域化**：每个正性/曲率/代数/解析的"补偿"都在"隙不被决定处"最大，在唯一定符号格（**典型场 × k→0**）同时消失。
- **两坐标墙**：正性面 **Schur-凹**（方向错，只能上界原子）；thimble 面 **Schur-凸**（方向对）但付相位/Stokes=凝聚。
- **输运 ≡ 禁闭**：从强耦合（可证）到 β≈交叉的非微扰 RG 输运，若要求"完整有效作用量进入短程/SC 盆地"，这**就是禁闭**（RG 没跑进非平凡 CFT）。**"跨 crossover" 与 "禁闭" 是同一件事的两句话**——任何声称绕开的方案，要么循环（用路径隙去搬隙），要么在偷偷证禁闭。

## 5. 三个具体可证伪子目标（挑一个）
- **T1（最便宜、最硬）**：时间域泛函 `A_m̃(T)=(1/T)∫₀^T e^{m̃t}C(t)dt`。
  可逐字证：**H\* ⟺ ∃(m̃,r₀)：`T↦A_m̃(T)` 单调不增 且 `inf_T A_m̃(T) ≥ r₀`。**
  → 在胶球数据上测这条曲线的单调性/下限；**若 `A_m̃` 非单调（凹/爆），H\* 与"结晶"一起死。** 这是把 H\* 变成可测曲线的关键形式。
- **T2（理论）**：固定 `J` 步的 RG 桥 `𝔄_κ(R^J S_{a,L})<ε_KP`。**问：有没有一个只靠 UV 入口 + 单调/紧量、避免逐尺度估计的收缩/紧性论证？** 没有它，"有限 J"不简化任何事——O2-Bridge 就等于"在 J 步内证一个跨交叉区的非微扰估计"，与禁闭同难。
- **T3（审计）**：2026 论文 Faizal–Shabir，*Reflection-Positive Construction of a 4D SU(N) YM Theory with Mass Gap and Confinement*（**已核实真实但被争议**：arXiv:2606.19362、Fortschr.Phys.74(2026)e70097；独立 Zenodo audit 22840696 指其连续声明条件于未证一致输入 + Part3 归一化反向错误；Clay 未解）§10 的 AF–IR 识别：
  - `Σ_k g_k²` 是否被当收敛（若 `g_k²∼1/k` 则调和发散）；
  - RG 尺度方向是否自洽（`μ↓` 时 AF 耦合应↑，而非↓）；
  - 比较误差 `O(j^{-1})` 是否可和（不可和 ⇒ 端点分别可控 ≠ 中间桥接）；
  - Markov 唯一性定理条件（同层边缘/转移核）是否满足。
  **若第 3 点不成立 = 这篇是很好的反面案例：两端可控 ≠ 轨道已连接。**
