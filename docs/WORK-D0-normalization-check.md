# 工作记录（第 335 轮）：`D_0` 的规范化核对

## A. 一个必须先钉死的一致性问题

**直接估计似乎给 `‖D_0‖²=O(L^4)`（`D_0=dF_0`、`F_0=½𝒮`、每条边的 staple 为 `O(1)`、边数 `4L^4`）。**
**而第 323 轮已证 `‖D_0‖²≤4`。两者矛盾。**

## B. 核对结论：`O(L^4)` 的估计错，`‖D_0‖²=O(1)` 对

**三条独立理由：**

1. **`ℋ=∇^*∇+Ric+Hess S` 的系数一致有界（`‖∇^*∇‖≤8`、`Ric=2`、`‖Hess S‖≤6(1+√2)β`），故 `ℋ` 的谱是 `O(1)`，与 `L` 无关。**
2. **`χ=⟨D_0,ℋ^{-1}D_0⟩`，且 `χ≤1/6`（求和规则）⇒ 若 `ℋ` 谱 `O(1)`，则 `‖D_0‖²=O(1)`。**
3. **`‖D_0‖²≤4` 的证明（第 323 轮）只用 `χ≤1/6`、`dD_0=0`、`‖d‖²≤24`，全部与 `L` 无关。**

**⇒ `‖D_0‖²=O(1)`，且 `≤4`。A 中的 `O(L^4)` 估计错在把 `F_0` 认成总作用量 `½𝒮`——`HS` 恒等式里的 `F_f` 是**规范化过的势**，不是 `f` 的积分。**

## C. 由此钉死的两条

$$\boxed{\ \text{(i)}\ \ \|D_0\|^2=O(1)\ (\text{与 } L \text{ 无关})\qquad\text{(ii)}\ \ \lambda_{\max}(\mathscr H)=O(1)\ }$$

**⇒ `χ=∫λ^{-1}dν_0` 的分子分母都是 `O(1)`，`χ≤1/6` 与之相容。**

## D. 剩余的唯一问题（本轮确认无法推进）

$$\lambda_{\min}(\mathscr H)\ \ge\ ?\qquad\text{（需与 } L,\beta\ \text{无关的下界）}$$

**已知：`λ_min>0` 对每个有限 `(L,β)`（有限维 + `ℋ≥0` 无零模）。**
**已知：`λ_min ≤ ‖ν_0‖/χ ≤ 24`（上界）。**
**缺：下界。**

**⇒ 与第 324 轮的 no-go 一致：`χ`-类量只能给 `λ_min` 的上界。**
