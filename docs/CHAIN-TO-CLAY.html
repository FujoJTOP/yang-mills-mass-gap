这一条是本次总装新增的：此前的靶只写了下界，因此把「平凡极限」误当成「有隙极限」也照样算过关。

§4 两个断点的证明（为什么它们不是「再努力一点」）

4.1 断点一：χ-类界的方向（符号问题，不可修补）

设 ν 是任一非负测度，λ_min = min supp ν，Ĉ = ∫λ⁻¹dν。则

λ_min ≤ ‖ν‖/Ĉ                    （初等不等式，无假设）

要得到隙，需要的是 λ_min ≥ m₀，即需要 Ĉ ≥ ‖ν‖/m₀ —— 一个下界。 而本项目全部 [T] 的 χ-型结果都是上界，且（由 ∫χ dβ = 1/6） χ(β) → 0 于大 β（测度意义下），所以任何 χ ≥ ‖ν‖/m₀ 型的下界在大 β 必失败。

χ → 0（β → ∞）  ⟹  χ-类下界在连续极限那一端结构上失效        [T]

结论（这条路的出口）：χ-类路线的出口是「只能给质量上界 [T]」； 下一手是换到 §3-R3 的 x-空间衰减率类，或反射正性 + 红外界。

4.2 断点二：模型 → 格点的桥（真值问题，已被反例封死）

单链结果延拓到多链需要 V ≤ 1。实测非乘积情形：

r_nonproduct = 0.692   vs   I₂/I₁ = 0.507        ⟹   V ≤ 1 为假   [F]

这不是精度问题：0.692 − 0.507 = 0.185，方向也相反（重叠使谱比升高）。 结论（这条路的出口）：单链 [T] 的出口是「只对单链成立 [F]」； 下一手是找一个不同的比较对象（不是 V ≤ 1），或在 L_s = 2 上直接做。
