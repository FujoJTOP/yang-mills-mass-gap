\section{环 3：$\kappa$、$\kappa/4$ 与可达率 $\delta$}\label{sec:delta}

\subsection{$\kappa=4\ln(1/u)/a$ 里的 $4$ 是壁数，不是熵}

四壁直管每片 4 个 plaquette，每片每壁一个 $c_f$ $\Rightarrow$ $w(B_T)=u^{4T}=e^{-\kappa t}$，$\kappa:=4\ln(1/u)/a$。
同一个 $4$ 亦可读作\textbf{源 plaquette 的四条边 = 四条通量链}（\codep{Y04-AUDITX01.md:11}）；它\textbf{不是} $d=4$、\textbf{不是}面数。
这里\textbf{没有熵项}：零扭折极小\textbf{唯一}（\codep{P3-FOURWALL-DERIVATION.md} \S1.5），故没有 $\mu^T$ 形状的路径熵；
装饰熵已单独记在 $f_{dec}=\varphi_{dec}/a=O(u/a)$ 与 $m_1^{dr}=\kappa-f_{dec}$ 里。\LT
\src{\codep{X01-L1C.md:17}（\S0 表第三行）、\codep{:92}（\S3 第 1--3 行）；\codep{P3-DRESSED-MASS.md:35,:57}（Remark 1.5："no path entropy"）。}

\subsection{$\kappa/4=\ln(1/u)/a$ 是恒等式}

把 $\kappa$ 的定义式除以 4：$\kappa/4=\ln(1/u)/a$，纯代数（$4$ 与 $4$ 相消），\textbf{精确}，无余项。\LT
独立审计逐字同判："那个 $4$ 是源 plaquette 的四条边，不是 $d=4$；零扭折极小唯一 $\Rightarrow$ 无面熵"（\codep{Y04-AUDITX01.md:11,:108,:173}）。
\src{\codep{X01-L1C.md:93}（\S3 第 2 行）；\codep{Y04-AUDITX01.md:11,:173}。}

\subsection{可达率：$\delta=\ln(1/\bar u)/a=\kappa/4-\ln(e\Delta N)/a$}

环 2 给出的率\textbf{不是} $\kappa/4$，而是 $\delta=\ln(1/\bar u)/a$，$\bar u=e\Delta\,N\,u$（$\bar C\equiv N$ 已证，\S\ref{sec:cbar}）。于是
\begin{equation}
\delta=\frac{\ln(1/u)-\ln(e\Delta N)}{a}=\frac{\kappa}{4}-\frac{\ln(e\Delta N)}{a}
\qquad\Longrightarrow\qquad
\frac{\delta}{\kappa}=\frac14\Bigl(1-\frac{\ln(e\Delta N)}{\ln(1/u)}\Bigr),
\label{eq:rate}
\end{equation}
其中 $e\Delta=54.3656365692$、$N=2$（$\Rightarrow e\Delta N=108.73$）。
\LT{}（\eqref{eq:rate} 的两端是恒等变形；$e\Delta$ 已证、$\bar C\equiv N$ 已算，见 \S\ref{sec:l1} 与 \S\ref{sec:cbar}）。
\src{\codep{X01-L1C.md:95--98}（\S3 第 4--7 行）；\codep{F07-ADJCBAR.md} \S1.4、\S4（权重比 $N$ 进 $\bar u$）；\codep{W02-L1.md:42}（上确界读法 $\delta=\kappa/4$）。}

三件事必须同时说清：

\begin{enumerate}[label=(\alph*)]
\item \textbf{$\delta<\kappa/4$ 严格}：可达率比 $\kappa/4$ 少一个簇常数项 $\ln(e\Delta N)/a>0$。字面取 $\delta=\kappa/4$
会把 $(\bar C)^{\,T}$ 留在 $B$ 之外。\LT
\item \textbf{但 $\delta>0$}：只要 $\bar u<1$（即 $\beta<0.018394$）；且 $\beta\to0$ 时 $\ln(e\Delta N)/\ln(1/u)\to0$ $\Rightarrow$ $\delta/\kappa\to\tfrac14$。\LT
\item \textbf{不损 $I2$}：$I2$ 只要\textbf{某个} $\delta>0$，任何正窗口够用；物理的 $\approx0.5m_1$ 窗口不在 $I2$ 的定义里。\LT
\end{enumerate}
\src{\codep{X01-L1C.md:98--101}（\S3 第 6--8 行与结论段）。}
