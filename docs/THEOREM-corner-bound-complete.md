# 第 380 轮：corner 界**严格证明完成**（`ε_K≤2[t_0√(2K+1)e^{−λ}I_{d_0}+t_{K−d_0}]$`）

---

## A. 证明（四步，全部显式）

**`T=M_fKM_f$`，`K=\mathrm{diag}(t_c)$` 递减，`\|M_f\|\le1$（`f\le1$`），`c_J=e^{-\lambda}(I_{2J}-I_{2J+2})\ge0$`。**

**① 拆 `K$`**：`K=K^{(1)}+K^{(2)}$`，`K^{(1)}=\mathrm{diag}(t_c\mathbf 1_{c\le K-d_0})$`。
  **`\|K^{(2)}\|=t_{K-d_0+1}\le t_{K-d_0}$` ⇒ `\|M_fK^{(2)}M_f\|\le t_{K-d_0}$`。**

**② 把 `P_{>K}$` 与 `K^{(1)}$` 结合**：`P_{>K}M_fK^{(1)}=P_{>K}M_fP_{\le K-d_0}K^{(1)}$`。**

**③ 逐个 `\chi_J$`**：正交基 `e_j=\sqrt{2j+1}D^j_{mn}$` 下**

$$\big(M_{\chi_J}\big)_{j'j}=\sqrt{\frac{2j'+1}{2j+1}}\;\langle jm,J0\,|\,j'm\rangle$$

**非零需 `|j'-j|\le J$`；且 `|\langle\cdot|\cdot\rangle|\le1$`、`2j+1\ge1$`、`2j'+1\le 2(j+J)+1\le2K+1$`（因 `j\le\frac{K-d_0}{2}$`, `j'\le K$`-端）⇒**

$$\big\|P_{>K/2}\chi_JP_{\le(K-d_0)/2}\big\|\ \le\ \sqrt{2K+1}$$

**而 `P_{>K}M_fP_{\le K-d_0}$` 只受 `J\gt d_0/2$` 的项影响 ⇒**

$$\big\|P_{>K}T^{(1)}\big\|\ \le\ t_0\sqrt{2K+1}\sum_{J\gt d_0/2}c_J\ =\ t_0\sqrt{2K+1}\,e^{-\lambda}I_{d_0}(\lambda)$$

**（望远镜恒等式 `\sum_{J\ge J_0}c_J=e^{-\lambda}I_{2J_0}(\lambda)$`，第 341 轮。）**

**④ 合起来**：

$$\boxed{\ \varepsilon_K=\|T-P_KTP_K\|_{\rm op}\ \le\ 2\Big[t_0\sqrt{2K+1}\;e^{-\lambda}I_{d_0}(\lambda)\ +\ t_{K-d_0}\Big]\ }$$

**（`2$` 来自 `\|P_{>K}T\|+\|TP_{>K}\|$`。）** $\blacksquare$

**⚠️ 但必须说清：`\beta=40$` 时 `\|T\|\approx10^{15}$`，双精度地板 `\sim10^{-14}$`，所以 `K=80$` 那一档的 `\varepsilon_K$` **测不到真实值**，那一部分核验**是空的**。**
