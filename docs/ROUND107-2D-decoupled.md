# 第 107 轮：**2D 格点的耦合结构** —— 2-链 plaquette 的 2D 格点是**退耦的**

---

## A. 关键观察（`[T]$`）

**2D 环面 `L\times L`：`2L^2$` 条链（水平 `h(x,y)$`、垂直 `v(x,y)$`）。**

**标准 plaquette 耦合：`q_{h(x,y),v(x,y)}$`（一个水平 + 一个垂直）。**

$$\boxed{\ Sq=\sum_{x,y}q_{h(x,y),\,v(x,y)}\qquad\textbf{每对只出现一次}\ }$$

**⇒ `Sq$` 是 `L^2$` 个**独立**的 2-链项的**和**。**

**⇒ 2D 格点（在 2-链 plaquette 模型里）**退耦成 `L^2$` 个独立 plaquette**。**

## B. 于是

**① `T=\prod_{x,y}T_{\rm plaq}$`（张量积）。**

**② `r(2D\ L\times L)=r(\text{单 plaquette})$ —— **`L$`-无关**。**

**③ ⇒ 2D 格点**不**给新的结构。**

## C. 为什么本会话用环

**① 环的相邻 plaquette **共享一条链**（`(0,1)$` 与 `(1,2)$` 共享链 1）。**

**② 共享链 ⇒ `Sq$` 的项**不交换**（`q_{01}$` 与 `q_{12}$` 共享链 1）⇒ 真耦合。**

**③ 4D 格点：每条链属于 `2(d-1)=6$` 个 plaquette ⇒ 强耦合。**

$$\boxed{\ \textbf{耦合来自共享链，不是来自 plaquette 的数量}\ }$$

## D. 所以本会话的环是**正确的**耦合结构

**① 环（`n$` 链、`n$` plaquette、每链属 2 个 plaquette）是 4D 格点的**局部模型**（`z=2$` 而非 `6$`）。**

**② star（中心属 `k$` 个 plaquette、叶子属 1 个）给 `z=k$` 的中心。**

**③ 4D 格点的每个链属 `6$` 个 plaquette ⇒ `k=6$` 的 star 是**最接近**的局部模型。**

**⇒ 本会话的 `k=6$` star 数据（`r\approx0.84$`）是**最有信息量**的。**

## E. 这确定了什么

**① 2D 格点（2-链模型）**退耦** ⇒ 无新结构。**

**② 耦合必须来自**共享链** ⇒ 环与 star 是**对的**模型。**

**③ 4D 格点的 `z=6$` 由 star `k=6$` 捕获。**

**④ 缺的仍是 `L\to\infty$`（均匀 `z=6$` 的无限格点）—— 需要 4D 拓扑。**
