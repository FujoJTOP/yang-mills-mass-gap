# 勘误 35：`(TP)` 与数据的「矛盾」是**观测量不匹配**——审计 301 的结论撤回

> 本文修正 `docs/AUDIT-301-tp-contradiction.md` 的判决。

---

## 1. 根因：`qfield` 不是固定取向的 plaquette

**论文 `§1` 的观测量是**

$$q_x=\tfrac12\operatorname{tr}U_{P(x)},\qquad P(x)=\text{固定取向（12-平面）的 plaquette}$$

**而 Monte Carlo 代码 `research/unconditional/w7/block_mc.py` 第 88–95 行是**

```python
def qfield(U):
    tot = np.zeros((L,L,L,L)); cnt = 0
    for mu in range(4):
        for nu in range(mu+1,4):
            P = ...                       # (mu,nu) 平面的 plaquette
            tot += 1.0 - 0.5*qtr2(P)      # 注意：是 1 - q，不是 q
            cnt += 1
    return tot/cnt
```

$$\boxed{\ q^{\rm data}_x\ =\ \frac16\sum_{0\le\mu\lt\nu\le3}\Big(1-\tfrac12\operatorname{tr}U_{P_{\mu\nu}(x)}\Big)\ =\ 1\ -\ \overline{q}_x\ }$$

**其中 `q̄_x := (1/6)Σ_{μ<ν}½tr U_{P_μν}(x)` 是**六个取向的平均**（clover 型）。**

**⇒ 数据的观测量与论文的观测量**不是同一个对象**：**

| | 论文 `§14` | 数据 |
|---|---|---|
取向 | **固定一个**（12-平面） | **六个全平均** |
`1−` 平移 | 无 | 有（对协方差无影响） |
超立方对称性 | **无**（只保留 12 平面内的对称） | **有**（六个取向等权） |

**⚠️ `1−` 平移对 `Cov` 无影响，所以真正的差别只有一条：**六取向平均 vs 单取向**。**

---

## 2. 为什么这解释了一切

**`(TP)` 的证明要求 `A_κ(t)` 是**单一时间片上的乘法算子**（或单一方向的插入算子）。这只有在观测量是**固定取向**的 plaquette 时才成立：**

- 固定 12-平面、transfer 方向 `μ∈{2,3}` ⇒ `U_0,U_1` 都空间 ⇒ **乘法算子** ⇒ Lemma 14.1；
- 固定 12-平面、transfer 方向 `μ∈{0,1}` ⇒ 跨时间片 ⇒ **单方向插入 `B`** ⇒ Lemma 14.2。

**⇒ 单取向时，两个情形都被证明覆盖。**

**而六取向平均给出**

$$A_\kappa\ =\ A^{\rm spat}_\kappa\ +\ B^{(\mu)}_\kappa$$

**其中 `A^spat` 是三个纯空间平面部分（乘法算子），`B^{(μ)}` 是三个含 `μ` 方向的部分（插入算子）。于是**

$$\langle A_{-\kappa}(0)A_\kappa(n)\rangle=\underbrace{\langle A^s_{-\kappa}A^s_\kappa\rangle}_{\ge0}+\underbrace{\langle B_{-\kappa}B_\kappa\rangle}_{\ge0}+\underbrace{\langle A^s_{-\kappa}B_\kappa\rangle+\langle B_{-\kappa}A^s_\kappa\rangle}_{\textbf{无符号控制}}$$

$$\boxed{\ \text{交叉项没有符号控制}\ \Longrightarrow\ \text{对 clover 观测量，(TP) 既未被证明，也未被否证}\ }$$

## 6. 这对数值工作意味着什么

**⚠️ 全部已有数值（`Cz`、`Ck`、`χ`、`m`、`w(0)`、`Λ_L`、`p_eff`）都是**clover** 观测量的，不是论文 `§14` 定理的对象。**

**⇒ 这不是废掉数据，而是：**

1. **数据与 `(TP)` 无关**（既不能支持也不能否证它）；
2. **数据支持的是 clover 版的 `(Q)`**（`max_kĈ=Ĉ(0)`，`ratio=1.0000000000`，`L=6,8,10,12` 全部）；
3. **而 clover 在**超立方对称性上更好**（六取向等权）——它本来就是文献里常用的胶球算符；**
4. **⇒ 若要检验 `(TP)` 本身，必须**重跑并保存固定取向的 `q^12_x`**。**
