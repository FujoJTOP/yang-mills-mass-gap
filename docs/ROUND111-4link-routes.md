# 第 111 轮：4-链 plaquette 的**实现路线**（三条）

---

## A. 三条路线（`[T]$`/`[U]$`）

### 路线 1：CG 直接构造（`[U]$`）

**`\langle j'm'n'|(u)_{ab}|jmn\rangle$` 是单链的 CG 矩阵元。**

**`W$` 的矩阵元 = `\frac12\sum_{a,b,c,d}(\text{4 个单链 CG})$。**

**维数 `D=d^4$`（`jm=3$` 时 `810000$`）。**

**⚠️ 需要 4 个 CG 的联合收缩 + 逆的宇称因子（`(u^{-1})_{mn}=(-1)^{m-n}(u)_{-n,-m}$`）。**

### 路线 2：`W$` 的特征值分解（`[U]$）

**`W$` 是规范不变的 ⇒ 与 `\mathcal H$` 的规范固定子空间交换。**

**在 `(j,m,n)$` 基下，`W$` 的谱可能有限（SU(2) 的 `\frac12\tr$` 值域 `[-1,1]$`）。**

**⇒ 若 `W$` 的谱可以**解析**求出，则 `f(W)$` 是谱函数的矩阵。**

**⚠️ 未验证。**

### 路线 3：`\beta$`-展开 + 精确对角化（`[\text{可行}]$）

**`\beta$` 小时 `e^{(\beta/2)W}$` 的级数收敛快。**

**⇒ 用截断的 `\beta$`-级数构造 `M_f$`，再 `eigsh`。**

**⚠️ `\beta$` 大时需要高阶级数。**

## B. 与 2-链模型的关系

**2-链模型的 `W_2=\frac12\tr(u_1u_2^{-1})$。**

**4-链 `W_4=\frac12\tr(u_1u_2^{-1}u_3u_4^{-1})$。**

**① 两者都是规范不变。**

**② 但 `W_4$` 的谱**不同**（4 个 SU(2) 矩阵的乘积 vs 2 个）。**

**③ ⇒ 4-链模型的 `V$`-结构**不同**。**
