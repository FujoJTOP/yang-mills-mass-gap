## B. `m a$` 先降后升

**① `\beta_s$` 从 `0.25$` 到 `2$`：`m a$` 从 `0.573$` **降到** `0.412$`。**

**② `\beta_s$` 从 `2$` 到 `8$`：`m a$` 从 `0.412$` **升到** `0.904$`。**

$$\boxed{\ m\,a\ \text{在}\ \beta_s\approx2\ \text{处有最小值}\ 0.412\ }$$

## C. 与 1-链模型对比

**1-链模型（第 205 轮）：`m a$` 从 `0.709$`（`\beta_s=0.25$`）到 `0.789$`（`\beta_s=0.5$`）——单调升（无明显最小值）。**

**2-链模型：**有**最小值 `0.412$`（`\beta_s=2$）。**

**⇒ 两者都是「`m a=O(1)$」，不是指数减小。**

## D. 截断的警告

**`jm=3$` 只在 `\beta_s\lesssim1.5$ 可靠（`j_{\rm conv}=2\beta_s$）。**

**⇒ `\beta_s=4,8$ 的数据是**截断限制**的。**

**但 `\beta_s\le2$ 的数据（`m a` 的最小值）是可靠的。**
