# 第 79 轮：`\lambda\ge0.36$` 段**变干净了** —— Weyl 秩截断，一个 `[T]$ 级恒等式 + 一个显式小量

## A. 分解（不用块分裂，用秩）

$$T=MKM=M\,K_NM\;+\;M\,K_{\rm tail}M$$

- **`K_N=\mathrm{diag}(t_0,\dots,t_N)$` ⇒ `MK_NM$` 是**秩 `N+1$`**算子；**
- **`K_{\rm tail}=\mathrm{diag}(t_{N+1},t_{N+2},\dots)$`，`\|K_{\rm tail}\|=t_{N+1}$`；**
- **`\|M\|_{\rm op}=e^{\lambda}$`（`M$` 在 `\theta$`-空间就是乘 `e^{\lambda\cos\theta}\le e^{\lambda}$`）⇒ `\|MK_{\rm tail}M\|\le e^{2\lambda}t_{N+1}$。**

**⇒ Weyl 不等式：**

$$\boxed{\ t_i(T)\ \le\ t_i\big(K_N^{1/2}M^2K_N^{1/2}\big)\;+\;e^{2\lambda}\,t_{N+1}\ }$$

**其中 `K_N^{1/2}M^2K_N^{1/2}$` 是 `(N{+}1)\times(N{+}1)$` 矩阵（`M^2$` 取 `\le N$` 的子块）。**
