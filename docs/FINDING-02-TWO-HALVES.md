> **主式**：`[窗口地板] ⇒ Clay`（靠**已证**的桥梁 `Δ_cont ≥ liminf_a Δ_a`，`GL2b′` + Lean `gap_ge_liminf`）

## §0 先纠我自己一句（第 16 处自纠）

上一条我给的口径是 `[窗口地板] + [(NEW)] ⇒ Clay`。**方向错了。**

```
左半：∀a: Δ_a ≥ Δ₀>0   ⇒   liminf_a Δ_a ≥ Δ₀
已证：Δ_cont ≥ liminf_a Δ_a                 [T]  glue-b-blocking/REPORT.md:277–279；Lean gap_ge_liminf
⇒     Δ_cont ≥ Δ₀ > 0  ⇒  Clay              ✓   只用左半 + 已证的桥

       它与已证方向合用才给 liminf Δ_a = Δ_cont ⇒ 把 (Q) ⟺ Clay 变成等价。
```

⇒ **`(NEW)` 是"等价性"的钥匙，不是"获胜"的钥匙。** `GN1`–`GN4` 四路攻的是**等价性**，不是 Clay 本身。这个区分必须写在纸面上，否则又会把两条不同性质的义务混成一条。

## §2 右半：`(NEW)`（不是门票，是等价性的钥匙）

```
已证   Δ_cont ≥ liminf_a Δ_a            [T]  REPORT:277–279；Lean gap_ge_liminf
待证   Δ_cont ≤ liminf_a Δ_a            ← (NEW)
反例   liminf Δ_a = 1/2 < 1 = Δ_cont    [T]  REPORT:281（抽象族，非 YM）
定理 W 任何收敛意义都不蕴含 (Q)          [T]  REPORT:283（反例族 T_a=diag(1,e^{−c₁a},e^{−c₂a})）
⇒ (NEW) 不能由收敛性推出，必须由 YM 结构供给
```

**它买到什么**：两条合起来 `liminf Δ_a = Δ_cont` ⇒ `(Q) ⟺ Clay` ⇒ **"证不出地板"才等价于"Clay 仍开"**；没有它，证不出地板**什么也不说明**。

**四条攻法（已派出）**：
- `GN1` **无凹陷定理**：穷举 `liminf < Δ_cont` 的机制（能级交叉 / 态身份改变 / 相变 / `L`-`a` 次序 / 有限体积伪影）逐个排除；
- `GN2` **变分/嵌入**：正视"变分只给上界"，转去把已证方向的**证明结构摊开**看能否反用；
- `GN3` **谱分支收敛**：若 `limsup ≤ Δ_cont ≤ liminf` 两头一夹就得收敛——本路最可能的突破点；
- `GN4` **红队**：试着在 YM 类里造出凹陷（顺带查 **2D 是否已是凹陷的已证实例**：`m=3g²/8` 而 `Δ_dyn=0`）。

## §3 为什么这个拆分是对的

| | 左半 | 右半 |
|---|---|---|
| 性质 | **地板**（正的量） | **桥**（两个量的比较） |
| 拿到它的后果 | **直接得 Clay** | 只把 `⇒` 升级成 `⟺` |
| 失败方式 | 换名 / 数值真空 / 常数 >1 | 抽象反例 / 定理 W |
| 现有工具 | 壳、塔、块流、`ε_b`、曲面和、缺陷比（**全死**） | 谱半连续、Γ-收敛、Attouch（**未试**） |

**两个半句的证据互不重叠、失败方式互不重叠**——这是本文档相对 `FINDING-01` 的增量：01 说"瞄准点在目标两侧"，02 说"**正确的拆法是一个地板加一座桥，而桥已经有一半被证了**"。

## §6 两个半句各自的可证伪条件

- **左半被证伪**：找到 `(β,L,a,v)` 使 `[E_μ(H_vv|ξ=0) − Var_μ]/a² ≤ 0` 且该点落在正确量词内 ⇒ `(Q)` 假。**注意**：`(Q)` 假 ⇒（由已证方向）`Δ_cont` 可能仍正 ⇒ **不直接杀 Clay**；这正是`(NEW)` 缺席时的信息损失。
- **右半被证伪**：在 YM 类里造出 `liminf Δ_a < Δ_cont` ⇒ `(NEW)` 假 ⇒ `(Q)` 只是充分条件、非等价；Clay 仍可开。
- **两者同时成立**：`(Q) ⟺ Clay`，于是"证不出地板"就是"Clay 仍未解"的**等价表述**。
