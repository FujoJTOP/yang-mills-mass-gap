项目：4 维纯 SU(2) Yang–Mills 质量隙（Clay）。进展单位是「轮」。 本轮唯一交付：把全部已证结论按「因为 / 所以」接成一条链，并把 Clay 写成等价的两环形式。

详细链：CHAIN-TO-CLAY.html（本轮的完整件）。

1. 目标链：只剩两环

Clay  ⟺  (A3) ∧ (SCALE)

(A1)     ∃c₁>0 ∀β≥β₀∀L:  m_lat/a ≥ c₁            ← 下界，[U]
(A2)     ∃c₂<∞ ∀β≥β₀∀L:  m_lat/a ≤ c₂            ← 上界，[U]
(SCALE)  (A1) ∧ (A2) :   c₁ ≤ m_lat(β,L)/a(β) ≤ c₂
(A3)     沿 AF 轨迹的 OS 紧性 + Schwinger 函数收敛   ← [U]（Balaban 部分）

其余每一环 [T]：
  格点测度存在 → OS 重构 (H, T, H ≥ 0) → 隙 = 谱定理 = 指数衰减率 → m_phys = m_lat/a
  (C2) ⟸ 下界 c₁ ； (C1) ⟸ 上界 c₂（若 m_lat/a → ∞，极限超局部 ⇒ 平凡）

本轮新增的那一条：上界 c₂。此前靶只写下界，因此「平凡极限」也会被算过关——这正是 ROUND259 的 m·a ≈ 0.618（不趋于 0）应当读成 (C1) 失败、而不是 (C2) 成功的理由。

6. 限定

  • SU(2)、d=4；一般单李群未逐条重跑。
  • 求和规则 / χ^clover ≤ 1/6：一切 β>0，L≥2。(R) 数值核验：β∈[0.2,400]（11 值）。
  • 观测量：固定取向 plaquette 标量道；clover 平均的 (Q) 仍 [U]。
  • 极限次序：先 L→∞ 再 a→0；两个极限不可交换 [T]。
  • 大 β_s 数值必须用 ive 归一化（第 223 轮更正）。
  • 外部输入：OS 重构（1978，标准）；渐近自由（标准）；Balaban RG（部分）；Ginibre 对非 Abel 不可用。

7. 与 Clay 的关系（诚实值）

不以百分比计（CLAUDE.md §2：定理只有「已证 / 未证」，中间没有百分比）。

可报告的三件事：① R1–R2 已 [T]；② 缺 R3、R4、R5； ③ 缺的东西带量词：R3 = ∃c₁∀β∀L 的下界，R4 = ∃c₂∀β∀L 的上界，R5 = 紧性。 Clay 未证。
