# 第 144 轮：**解析论证：`\Phi\to0$`** —— `M_f$` 的连续谱是本质谱，`\mu_1=\mu_2$

---

## A. 核心观察

**`M_f=e^{\beta_s q/2}$`，`q=\frac12\tr(U_P)$ 是**乘法算子**（作用在 `L^2(SU(2)^2)$`）。**

**⇒ `M_f$` 也是乘法算子（乘 `e^{\beta_s q/2}$）。**

**⇒ 它的谱 = 值域的本质闭包 = `\{e^{\beta_s q/2}:q\in[-1,1]\}=[e^{-\beta_s/2},e^{\beta_s/2}]$`。**

$$\boxed{\ \mathrm{spec}(M_f)\ \text{是}\textbf{连续谱};\ \sup=\sup_{\rm ess}=e^{\beta_s/2}\ \text{—— 没有离散本征值}\ }$$

**⇒ 「`\mu_1$`」「`\mu_2$`」在连续谱上**都存在**（都等于 `e^{\beta_s/2}$）⇒**

$$\boxed{\ \Phi=-2\ln\frac{\mu_2}{\mu_1}\ \longrightarrow\ 0\qquad(j_{\max}\to\infty)\ }$$

## B. 为什么数值给 `0.039$`–`0.041$`

**`j\le j_{\max}$` 的截断把 `M_f$` 变成 `D$` 维矩阵 ⇒ 离散本征值 ⇒ Perron–Frobenius 给 `\mu_1\gt\mu_2$`（严格）。**

**⇒ `\Phi\gt0$ 在每个截断里（第 142 轮 `[T]$`），但它的**极限**是 0。**

**已测的 4 点 `\Phi(16)$`：`0.0364, 0.0407, 0.0409, 0.0394$`（`j_{\max}=1.5,2,2.5,3$）—— **不单调**，与"缓慢趋于 0"不矛盾，但不能证实。**

**⚠️ 要证 `\Phi\to0$` 需要 `j_{\max}\to\infty$`，而 `D$` 增长太快（`j_{\max}=3$` 已 `484$` 秒）。**
