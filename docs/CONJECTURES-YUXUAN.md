## Y1 · 双边普适性

### 陈述

**弱形式（主猜想）。** 存在只依赖于 `d = 4` 的常数 `0 < c₁ < c₂ < ∞`，使得对**一切紧单群** `G`、沿各自的渐近自由轨迹、对所有 `β ≥ β₀` 与 `L ≥ L₀`：

$$\frac{m_{0^{++}}(G)}{\sqrt{\sigma(G)}}\ \in\ [c_1,\ c_2] .$$

**强形式。** 该比值与 `G` 无关：存在普适常数 `κ > 0` 使 `m_{0++}(G)/√σ(G) = κ`。

### 动机（来自机制，不是来自数值）

夹逼只用到两样东西：反射正性（谱测度正性 ⇒ 单侧界）与渐近自由标度（格点量 → 物理量）。**两者都不区分群，只区分维数。** 若质量隙的证明必须是两侧的（见 Y2），则两侧的常数应当只由 `d` 决定。

### 否证条件

- 强形式：`SU(3)` 与 `SU(2)` 的 `m_{0++}/√σ` 在误差外分离。
- 弱形式：找不到同时容纳两个群的区间（等价于某一群的比值发散或趋零）。

### 证明它需要什么

`(A1)+(A2)` 的两侧夹逼，且**常数不经过任何群特异量**（Casimir、`N`、中心荷）。

### Clay 证明之后它会变成什么

- 若证明给出「对所有 `G`、常数只依赖 `d`」的两侧界 ⇒ **弱形式是推论 `[T]`**；强形式仍 `[U]`。
- 若证明的常数依赖 `G` ⇒ 弱形式降为 `[U]`（而且这条猜想就被证明的结构反驳了）。

## Y2 · 无单侧证书（屏障猜想）

### 陈述

**形式化到类 `C` 时（`C` = 测度的弱-* 连续泛函族）：已是定理。** 在射线 `ν_h = (1−h)ν + hδ₀` 上，`C` 中每个泛函随 `h` 连续，而 `1_{λ_min>0}` 在 `h=0` 跳变 ⇒ `C` 造不出一致的正下界。`[T]`（= `MG-META` 的 D5）。

**猜想形式（`C` 之外的证书类）。** 不存在只由**有限矩 + 变分商 + 弱-* 连续泛函**这三类元件组成的、在 `β→∞` 上一致有界的证书，能推出 `λ_min ≥ m₀ > 0`。等价地：**任何质量隙的证明都必须含一步「结论不是测度的弱-* 连续泛函」**。

### 动机

`D1`（变分方向反）+ `D2`（循环）+ `D5`（弱-* 盲）+ `D6`（空前提）= 65 条判词里的 40 条，全部是这一个错配的投影。Y2 是把这个统计事实写成一条可判的命题。

### 否证条件

写出一个单侧证明：只用上述三类元件，推出 `λ_min ≥ m₀ > 0` 且 `m₀` 与 `β, L` 无关。

### 弱点（必须记明）

「证书类」没有完全定死。定死到弱-* 连续泛函时它已经是定理；放大到「一切可计算量」时它不可判。**所以 Y2 目前介于定理与猜想之间**——这正是它必须先被形式化的原因。

### Clay 证明之后它会变成什么

- 若证明是**单侧**的 ⇒ Y2 立即 `[F]`。
- 若证明是**两侧**的 ⇒ Y2 **不被证明**，只被支持；屏障本身仍需单独证。
- 若证明含一个非连续元件（例如某个跳变量）⇒ Y2 的猜想形式被支持，且那个元件应被记进链。
