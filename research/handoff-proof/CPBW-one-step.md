# CPB-W 第一步：一步类保持（U(1)，固定质量、固定体积）

> 2026-11-22 · 范围：只做 CPB-W 的**第一步**（格点 → 第一层块），**不碰 `RB2/NPB`**，**不声称证明 CPB-W**。
> 目的：检验"massive 背景场 + 分块"的类保持方法，给出显式常数与适用范围；若非阿贝尔做不动，指名失效的那一条估计。

## 0. 结论（先读）

- **范数：C² 范数 on the ball** `||A||≤R`：
  ```
  ||V||_{C²,R} := sup_{||A||≤R}|V(A)| + sup_{||A||≤R}||DV(A)|| + sup_{||A||≤R}||D²V(A)|| .
  ```
  理由（**两头都要管**）：条件期望**保 sup 范数**（所以 sup 看不到收缩），**压缩 Lip/一阶导**（这是上界）；而类的非退化需要 **Hessian 下界**（这是下界）。只证上界会让 Gaussian 部分被吃掉，类塌成空集——"空洞 ✅"的另一种形式。C² 是同时给上界与下界的最小范数。
- **U(1) 检验什么、不检验什么（必须明写）：** U(1) 是自由理论，`F=dA` 使 `dF=0` **自动成立**；没有非平凡的 Bianchi 抵消。所以 U(1) 只检验 **Gaussian/分块那一步**（协方差分解、涨落 log、C² 收缩/非退化），**不检验** `CPB-S` 的 signed-gas 缺陷机制，也不检验 `e^{−cq²}` 的 Bianchi 标度。**U(1) 的结果不能读成"`CPB-S` 的机制已验证"。**
- **U(1) 一步引理（条件性）：** 在 Gaussian 主导、小场条件 `εL(q)^{1/2}≤1/2` 与非退化条件 `ε<c₀m²/C` 下，
  ```
  ||V' − V∘A_∥||_{C²,R'} ≤ C₁ ε² L(q) + C₂ ε³ L(q)² ,
  L(q) := sup_x Σ_y |G_⊥(x,y)|² ≤ C₃ ln(1/q) + C₄ ,
  ```
  且 `S_{k+1}''≥(c₀m²−Cε)Id>0`，`m_{k+1}=m(1+O(ε))`。标准归一化下 `ε~g²`、`L~ln/(16π²)`，得 `δ≤C(g²/16π²)ln(1/q)+O(λ³)`。**U(1) 一圈系数为零**，实际 `δ` 更小；这是方法检验，不是 U(1) 的物理跑动。
- **非阿贝尔：** 在 `q~1`、`λ~6` 失败于**大场 C² 界**（骨架引理 6）：交换子使 `||V''||~R³/g²+R²/g`，典型 `R~g/q~1.4`，`g²~2` 时 `||V''||~2.8`，而 `c₀m²~c₀`；非退化条件 `ε<c₀m²/C` 失败。Balaban 的大场界只覆盖 `g` 小（UV），没有 `q~1` 版本。**非阿贝尔一步类保持未证。**

## 1. 设定

- 细格 `Λ_a=(ℤ/Nℤ)^4`，`a=1`；粗格 `Λ_{2a}`，`b=2`；`T⁴` 周期边界。
- U(1) 连接变量 `A_e∈ℝ`（小场图表；球半径 `R<π` 保证不越界）。
- Wilson 作用量 `S=(1/g²)Σ_p(1−cos F_p)`，`F_p=dA_p`。
- **massive 参考 Gaussian**：`S_G=(1/(2g²))Σ_p F_p² + (m²/(2g²))Σ_e A_e²`，`m=q`（固定质量，`q=m a`）。协方差 `G=g²(−Δ+m²)^{−1}`（Proca；规范破坏，作为内部分析装置；最终陈述在规范不变观测量上，见骨架引理 7）。
- 微扰 `V=S−S_G = −(1/(24g²))Σ_p F_p⁴ + O(F⁶)`。
- 分块平均 `A'=BA`（U(1) 线性）；`G'=BGB^T`，`G_⊥=G−B^TG'B≥0`。
- 条件期望：`A=A_∥+A_⊥`，`A_∥=B^T(G')^{−1}A'`，`Cov(A_⊥)=G_⊥`。

## 2. 一步分解

```
e^{−S'(A')} = E_{G_⊥}[ e^{−S(A_∥+A_⊥)} ] ,   S' = S_{G'} + V' ,
V'(A') = −log E_{G_⊥}[ e^{−V(A_∥+A_⊥)} ] .
```
Cumulant 展开：
```
V' = E[V] − (1/2)( E[V²]−E[V]² ) + (1/6)κ₃(V) − … .
```
- `E[V]−V(A_∥)`：涨落平均的一阶修正（tadpole）；`E[A_⊥]=0`，首项是 `(1/2)V''(A_∥)·G_⊥(x,x)` 型；`C²` 界 `≤ (1/2)||V||_{C²} sup_x G_⊥(x,x)`。
- `(1/2)Var(V)`：二阶项，`≤ (1/2)||V||_{C²}² · sup_x Σ_y |G_⊥(x,y)|² = (1/2)ε² L(q)`。
- 余项 `O(ε³ L(q)^{3/2})`。

## 3. U(1) 一步引理（条件性）

**引理（U(1)，固定质量、固定体积、第一步）.** 设 `||V||_{C²,R}≤ε`，`ε L(q)^{1/2}≤1/2`，且非退化 `ε<c₀m²/C`。则
```
||V' − V∘A_∥||_{C²,R'} ≤ C₁ ε² L(q) + C₂ ε³ L(q)² ,   R'=R ,
```
其中 `C₁,C₂≤10`（未优化的安全界），且
```
S_{k+1}'' = S_{G'}'' + V'' ≥ (c₀m² − Cε) Id > 0 ,   m_{k+1}=m(1+O(ε)) .
```
**证明骨架.**
1. 展开到二阶（§2）。
2. 一阶项：`E[V]−V(A_∥)` 的 `C²` 界 `≤||V||_{C²}G_⊥(x,x)≤εL(q)^{1/2}`。
3. 二阶项：`Var(V)≤ε²L(q)`。
4. 余项：`|κ₃|≤Cε³L(q)^{3/2}`，由 `εL^{1/2}≤1/2` 吸收。
5. **非退化**：`S_{k+1}''=S_{G'}''+V''`；`S_{G'}''≥c₀m²`（massive Gaussian），`||V''||≤ε`；故 `≥(c₀m²−ε)Id>0`。**这一步只靠上界不够，必须用 Hessian 下界；否则 Gaussian 部分可能被吃掉，`C_W` 塌成空集。**
6. 合并得引理。∎

**一圈对数.** `L(q)≤C₃ln(1/q)+C₄`，`C₃` 来自 `∫d⁴p/(p²+m²)²=(1/(16π²))ln(1/m)+…`；`C₄` 是 UV 有限常数。**标准归一化下** `ε~g²`，故 `δ≤C(g²/16π²)ln(1/q)+O(g⁴)`。**U(1) 一圈系数为零**：四顶点 `ln` 与测度/Peter–Weyl 贡献相消，实际 `δ` 是 `O(g⁴ln)` 或更小。引理仍成立，只是常数更小——这是"方法检验"的意思。

## 4. 适用范围与常数（如实标注）

- **体积一致性：** `G_⊥` 由 massive 传播子给出，指数局域（程 `1/q`）；`Σ_y|G_⊥(x,y)|²` 绝对收敛，界与 `L` 无关。U(1) 成立。
- **UV 一致性：** `L(q)` 的 UV 部分由格点短距传播子给出，`C₄` 有限；`C₃ln(1/q)` 显式。U(1) 成立。
- **小场条件：** `εL(q)^{1/2}≤1/2`；`q~1` 时 `L=O(1)`，需 `ε≲1/2`。U(1) 的 `ε~g²` 可小；非阿贝尔 `λ~6` 时 `g²~2`，失败。
- **非退化条件：** `ε<c₀m²/C`。`q~1` 时 `m=q~1`，需 `ε<c₀/C`。U(1) 可满足；非阿贝尔 `ε~2`，需 `c₀/C>2`，失败。
- **球的半径：** `R~g/q`。U(1) 的 `||V||_{C²,R}` 是 `R³/g²` 量级；非阿贝尔多出交换子项 `R²/g`（见 §5）。

## 5. 非阿贝尔在哪一条失效（指名）

**失效估计：骨架引理 6 的"大场 C² 界"。**
- **形式：** `||V||_{C²,R}≤ε` 且 `ε<c₀m²/C`，`R~g/q`。
- **为什么给不出：** 非阿贝尔 `F_p=dA_p+[A_p,A_p]`，`V=−(1/(24g²))Σtr(F_p⁴)+…`；二阶导含 `[A,·]`，故
  ```
  ||V''||_{C²,R} ≲ R³/g² + R²/g .
  ```
  在 `q~1`、`λ=h^∨g²~6`（SU(3) `g²~2`）：`R~1.4`，`R³/g²≈1.37`，`R²/g≈1.40`，和 `≈2.8`，而 `c₀m²~c₀=O(1)`；**`ε<c₀m²/C` 失败**。大场尾 `e^{−cR²}` 在 `R~1.4` 不够小，不能把球缩小到 `R≪1`。
- **是否 Balaban 的大场估计：** 是同类，但 **Balaban 只有 `g` 小的版本**（大场重整化 CMP 122 (1989) 175–354；UV 稳定性 CMP 102 (1985) 255–275；定理编号未核实）。这些定理的假设含 `g` 小（渐近自由 UV），常数随 `g` 增大而退化；**没有 `q~1`、`g²~2` 的版本**。所以不是"Balaban 已有但没查"，而是"Balaban 的定理不覆盖这个参数区"。
- **结论：** 非阿贝尔一步类保持**未证**；缺口是引理 6，不是 Gaussian 步。

## 5b. Gaussian 加权类：能否把 `εL^{1/2}` 降到 ≤1/2？

**(i) 类的新定义.** 用 massive Gaussian 测度 `μ_G`（协方差 `G=g²(−Δ+q²)^{-1}`，方差 `⟨φ²⟩~g²/q²`）加权，取**局部** L² 范数（避免体积依赖）：
```
C_W^G(ε) := { S=S^G+V :  ||V||_{L²(G),loc}² := sup_x ∫ |V_x(φ)|² dμ_G(φ) ≤ ε² } ,
```
其中 `V_x` 是 `V` 在 `x` 处的局部密度（一个 plaquette 或小邻域）。权重 `e^{−q²φ²/g²}` 就是 Gaussian 权重；`sup_x` 去掉体积因子。

**(ii) 所需的估计.** 条件期望在 `L²(G)` 下是正交投影，故 `||V'||_{L²(G')}≤||V||_{L²(G)}`；但二阶非线性项含 `||V||_{L∞}`，而 L² 类**不控制 L∞**。需要一条插值/超压缩引理（形式待定；可能是 `||V||_{L∞}≤C(q)||V||_{L²}`，或需要指数矩），其代价可能重新引入大场因子。**这是换类的代价：失去单点 Lip 控制，下一步分块需要一条新的 L∞-L² 插值引理（未解）。**

**(iii) 一个数（能否过）.** 取 `V=−(1/(24g²))F⁴`、`F` 近似 Gaussian、`⟨F²⟩=c_F g²`（`q~1`）。Gaussian 八阶矩给
```
ε = ||V||_{L²} ≈ (√105/24) c_F² g² ≈ 0.427 c_F² g² .
```
`L(q)=sup_xΣ_y|G_⊥(x,y)|² ≈ g⁴ J`；格点求和（`q=1`，20⁴ 格点）给 `J≈0.020`，故 `L^{1/2}≈0.141 g²`（`g²=2` 时 `≈0.282`）。
- `c_F=1, g²=2`: `ε≈0.854`，`εL^{1/2}≈0.24 < 1/2` → **过**（约 2 倍余量）。
- `c_F=2, g²=2`: `ε≈3.42`，`εL^{1/2}≈0.96` → **边缘失败**。

**结论：Gaussian 加权把 `εL^{1/2}` 从 C²-on-ball 的 `~2` 降到 `O(0.2–1)`；中心值 0.24（过），保守值 0.96（边缘）。决定性的常数是 `c_F=⟨F²⟩/g²` 在 `q~1` 的值（需要格点计算）。这不是参数性胜利，但方向正确。** 代价是 (ii) 的 L∞-L² 插值引理（新、未解）。

**为什么中心估计能过：** 大场尾在 `R~g/q` 处的权重 `e^{−R²q²/g²}=e^{−1}≈0.37` 并不小；但 L² 范数由**典型场**主导，而 `V` 的 `1/24` 与八阶矩 `√105≈10.2` 使 `ε≈0.43g²`，而不是 Lip 界的 `~2`。真正降低 ε 的是 **L² 平均 + `1/24` + 矩因子**，不是尾压制。

**(iv) 所需插值的确切形式与 (a)/(b) 判定.** 条件期望作用在 `e^{−V}` 上，需要控制 `L(t)=log E[e^{−tV}]` 在 `t=1` 的值。**不需要 `‖V‖_∞`**；需要的是**局部 Bernstein/cumulant 界**：
```
| L(1) + E[V] − ½Var(V) | ≤ C₃ E[|V−EV|³] + C₄ E[|V−EV|⁴] ,
```
其中 `C₃,C₄` 由指数矩 `M(t_*)=E[e^{t_*|V|}]` 控制，`t_* ~ 1/(c₄σ⁴)`，`c₄=1/(24g²)`，`σ²=c_F g²`。**指数矩有限**：`V=S−S_G` 的 `F²` 项相消，领头大场项是**负四次** `−F⁴/(24g²)`，四次项压过 Gaussian；所以这是 `μ_G` 的有限阶矩（局部，`q`/`g²` 显式），不是 `‖V‖_∞`。

- **(a) 是否等价于 L∞？** **否。** 界只用 `E[|V|^k]`（`k≤4`）与固定 `t_*` 的指数矩，不含 `sup|V|`。
- **(b) 是否只用多项式矩闭合？** **是（条件性）。** 需要一条**局部 cumulant/cluster 界**（连通 cumulant 随质量 `q` 衰减），把逐点矩求和变成体积一致的界。这是新的、未解的引理，但它**不是**引理 6（不是大场 `L∞` 界）。
- **`c_F` 依赖：** `c₄σ⁴=c_F²g²/24`；`c_F=2, g²=2` 时 `=0.33`，指数矩的 saddle 给 `exp(O(0.33))`，是 **O(1) 因子，不是高次幂**。分界点会移动（`0.24–0.96` 的余量会变），但路线不因 `c_F` 的高次幂而关闭。

**判定：路线活着（b），但墙移到"局部 cumulant 界 + `c_F` 的计算"，而不是消失。** 若局部 cumulant 界只能通过 `sup|V|` 来证，则退回 (a)/引理 6；这是这条路线唯一需要盯住的地方。

**(v) 更正：`M(t)` 的收敛半径是 1，不是 `1/(c₄σ⁴)`.** 早先写 `t*~1/(c₄σ⁴)≈3` 是**错的**。原因：
- `V=S−S_G` 的**大场领头项是 `−S_G~−F²/(2g²)`（负二次）**，不是 `−F⁴/(24g²)`（后者只是小场展开的首个修正）。所以 `|V|~S_G`，且
  `e^{t|V|}e^{−S_G} ~ e^{(t−1)S_G−tS}`，
  在 `S` 有界（Wilson）时收敛 **iff `t<1`**。紧群上 `t=1` 也有限（`e^{|V|}e^{−S_G}=e^{−S}≤1`），但 Taylor 级数半径为 1。
- 因此 `t*` 的正确范围是 **`t*<1`**（取 `t*=1/2`）；不能用无限 cumulant 级数在 `t=1` 求和。改用 **[0,1] 上的有限阶 Taylor + Lagrange 余项**：只需三阶导（三阶 cumulant）在 `[0,1]` 有限——紧群/Wilson 测度下成立。
- **`c_F` 不进入半径**（半径 1 来自 `V` 与 `S_G` 的二次项精确相消）；`c_F` 只进入常数（矩按 `c_F^{k/2}` 标度），`c_F=1,2` 时是 O(1) 因子，不是高次幂。
- **新数：** 余项把 `εL^{1/2}` 从中心 `0.24` 抬到约 **`0.4–0.7`**（取决于三阶 cumulant），**边缘**，不再是舒适的 2 倍余量。

**判定（更正后）：(b) 未被关闭，但余量变紧。** `t*<1` 对 `c_F` **没有约束**（任何 `c_F` 都可取 `t*=1/2`）；墙仍是"局部 cumulant 界 + `c_F` 的计算"，且现在必须用有限阶余项，不能用级数求和。

## 6. 对 CPB-W 的含义

- **U(1) 只验证 Gaussian/分块步**，不验证 Bianchi 抵消，也不验证 `CPB-S` 的 signed-gas 机制（§0）。
- Gaussian 一步**不是**墙；墙是**大场 C² 界**（骨架引理 6）。
- 若要推进非阿贝尔，最省力的目标是：**在 `q~1`、`λ≤6` 给出 `||V||_{C²,R}≤ε` 与 `ε<c₀m²/C`**；其余引理（1–5、7–8）大多是标准/Balaban 已有的。
- 这与 `CPBW-skeleton.md` 的 `[新]`/`[未解]` 标注一致；`RB2/NPB` 不在此范围。
