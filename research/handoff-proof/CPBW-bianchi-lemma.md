# Bianchi/符号抵消引理：陈述与判定（一页）

> 2026-11-22 · 只写陈述与判定，不证明。
> 这是把 `CPB-W` 的 `C_cum` 与 `CPB-S` 的 `z(q_c)` 合并后的**唯一承重引理**。
> 若它不成立，`CPB-W` 与 `CPB-S` 同时关闭。

## 符号表（先读，防止撞名）

| 符号 | 含义 | 值/范围 |
|---|---|---|
| `κ` | Kotecký–Preiss 常数，在 `z(q)=sup_xΣ|w_q(C)|e^{+κq|C|}` 中 | `κ=1/2` |
| `κ_c` | **带号抵消因子**（B2 的每块因子） | `κ_c<1`，待定 |
| `c₀` | 缺陷作用量每块系数（`|w(C)|~e^{−c₀q|C|}`） | 动力学 |
| `C_cum` | 三阶连通 cumulant 的局部常数（`CPBW-cumulant.md`） | 需 `≤1.6` |
| `γ` | 团簇熵指数（`N(n)≤e^{γn}`） | O(1) |

**不要混用 `κ`（KP，=1/2）与 `κ_c`（抵消，<1）。**

## 0. 结论（先读）

- **`q²` 形式在 `q≈1` 是中性**：`q²≈q`，所以 `e^{−c₀q²|C|}` 与 `e^{−c₀q|C|}` 在交叉点几乎相同。**`q²` 标度不能把 `C_cum` 从 2 降到 1.6，也不能把 `z(1)` 压到 1/2。**
- **真正可能救命的是"带号抵消"**：`dF=0` 使缺陷是闭 2-曲面，求和时不同闭曲面的**符号/权重相消**，可能抵消团簇熵 `e^{γ|C|}`（2D O(N) 的机制）。这把有效 activity 从 `e^{−c₀q|C|+γ|C|}` 降到 `e^{−(c₀q+δ)|C|}`，`δ` 是**每块的符号抵消增益**，`κ_c=e^{−δ}`。
- **判定：** `q²` 形式**不足以**在 `q≈1` 过线；带号抵消是否给出 `δ` 足够大（`κ_c≤0.8` 给 `C_cum≤1.6`，更强给 `z(1)≤1/2`）**未知**。**若带号抵消不存在或 `κ_c≈1`，本引理不成立，`CPB-W` 与 `CPB-S` 同时关闭。**
- **可证伪：** 必须测**带号** activity（signed vs absolute），而不只是 `S_def/|C|`。

## 1. 陈述（目标引理 B）

设 `w(C)` 是 signed-gas 的带号权重，`|C|` 是块数，`q` 是质量（块单位）。

**(B1) `q²` 形式（候选，已知不够）：**
```
|w(C)| ≤ e^{−c₀ q |C| − c₁ q² |C|} .
```
它改进 `q>1` 的衰减，但在 `q≈1` 给 `e^{−(c₀+c₁)|C|}`，与 `q`-线性只差常数 `c₁`；`c₁` 若 O(1) 也不足以把 `C_cum` 降 20%。

**(B2) 带号形式（真正的候选）：**
```
| Σ_{C: ∂C=∂C₀} w(C) | ≤ e^{−c₀ q |C₀|} · κ_c^{|C₀|} ,   κ_c<1 ,
```
即固定边界下不同闭曲面的**带号和**比绝对和小 `κ_c^{|C|}` 倍。等价地，有效 activity 每块多一个 `−ln(1/κ_c)` 的抑制。`κ_c` 是**符号抵消因子**；2D O(N) 的 `κ_c` 由约束/符号结构给出，`κ_c<1` 抵消熵。

**需要的推论（两侧）：**
- **CPB-W（`C_cum`）：** `C_cum` 正比于有效 activity；`C_cum≤1.6` 需要 `κ_c≤0.8`（每块 ~20% 抵消）。
- **CPB-S（`z(q_c)`）：** `z(1)≤1/2` 需要带号 activity 的每块因子 ≤ `e^{−γ}·(1/2)`（`γ` 是团簇熵指数）；这比 `κ_c≤0.8` 更强，通常需要 `κ_c` 更小或 `c₀` 更大。
- **同一 `κ_c` 服务两侧**：CPB-S 是更强的要求；若 CPB-S 过，CPB-W 自动过（同一 activity）。

## 2. 判定

- **`q²` 形式（B1）：不够。** 在 `q≈1`，`q²≈q`，改进是常数级的 `c₁`，不能把 `C_cum` 从 2 降到 1.6，也不能把 `z(1)` 从 O(1) 压到 1/2。**所以"Bianchi 给 q² 标度"本身不是答案。**
- **带号形式（B2）：未知，是唯一希望。** 它要求固定边界下闭曲面的带号和远小于绝对和。2D O(N) 有此机制；4D YM 的 `dF=0` 给出闭 2-曲面结构，但是否产生足够的 `κ_c<0.8` 抵消，**没有估计**。
- **若 B2 不成立（`κ_c≈1`）：** `C_cum` 停在 `≥2`，CPB-W 数值死亡；`z(1)` 停在 O(1)，CPB-S 也死亡。**项目回到"两道墙都无路线"的诚实状态。**
- **若 B2 成立但 `κ_c` 只到 0.8–0.9：** CPB-W 可能边缘过（`C_cum≈1.6–1.8`），CPB-S 仍可能不过（需要更强的 `κ_c`）。两侧不一定同时过；必须逐侧核对。

## 3. 可证伪测试（必须带号）

1. **带号 vs 绝对 activity：** 在 SU(3) `β≈2.6–3.3`（`q≈1`）测 `z_signed(q)=|Σ_C w(C)|` 与 `z_abs(q)=Σ_C|w(C)|` 的比值；`κ_c` 由 `z_signed/z_abs` 的每块衰减估计。若比值 ≈1（无抵消），B2 失败。
2. **`S_def/|C|` 对 `q` 的标度：** 线性 ⇒ B1 都不成立（q-线性）；二次 ⇒ B1 成立但 `q≈1` 中性。这只能区分 B1，不能证明 B2。
3. **闭曲面占比：** 主导团簇是否闭 2-曲面；若体积缺陷/畴壁主导，B2 的结构前提失败。
4. **`C_cum` 直接测量：** 三阶连通 cumulant 的局部密度（`CPBW-cumulant.md`），在 `q≈1` 是否 ≤1.6。

**判定标准：** `z_signed/z_abs` 每块 ≤0.8 ⇒ B2 有希望；≈1 ⇒ B2 失败；介于 ⇒ 需逐侧核对 `C_cum` 与 `z(1)`。

## 4. 与两侧的关系（一句话）

```
CPB-W 需要 C_cum ≲ 1.6  ←  需要 κ_c ≲ 0.8（每块 20% 带号抵消）
CPB-S 需要 z(1) ≤ 1/2   ←  需要更强的 κ_c（或更大的 c₀）
两者共用同一个 κ_c；B1（q²）在 q≈1 中性，救不了任何一侧。
```

**结论：不要把 `q²` 标度当作答案；唯一值得测/证的是带号抵消因子 `κ_c`。若 `κ_c≈1`，两侧同时关闭。**
