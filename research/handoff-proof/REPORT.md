## 0.5 主要交付：RB2（2-loop running bound）

**目标.** 在物理归一化下，证明
```
RB2:  |β(λ) + A λ² + B λ³| ≤ C₃ λ⁴     (0 < λ ≤ 7.3),
```
或单边符号 `β(λ) ≤ −Aλ² − Bλ³`，其中
```
A = 1/C_RG,   B = 51/(121 C_RG²),   C_RG = 24π²/11,
```
且 `C₃` 显式、关于 UV 截断与体积一致。若 `RB2` 成立，则 `t_up(λ) ≤ t_up^{2L}(λ)`，从而
```
q₀ ≥ (m/Λ) exp(−t_up^{2L}(λ)).
```

**已证（纯代数）.** 2 圈截断流的精确解：
```
t_up^{2L}(λ) = C_RG/λ − (51/121) ln(1 + 121 C_RG/(51 λ)).
```
在 `λ=6`（`g²=2`，SU(3)）：`t_up^{2L}=2.639`，`q₀=0.571`（`m/Λ=8`）、`0.286`（`m/Λ=4`）；`q₀=1` 在 `λ≈7.28`（`g²≈2.43`，`α_s≈0.19`）。**这是 2 圈值，不是 3 圈反解。**

**未证（精确缺失的非微扰输入 `NPB`）.** 目前没有对 4D 纯 YM **有效 beta 函数**的 3 圈及更高阶的非微扰界。需要：
```
NPB: 在固定 scheme（block-spin 有效耦合）下，对 0 < λ ≤ 7.3，
     |β(λ) − β_{≤2}(λ)| ≤ C₃ λ⁴（或单边符号），C₃ 显式、UV/体积一致。
```
理由：Balaban 型严格 RG 只控制到 `λ~1`，误差项不足以给出 3 圈界；3 圈系数是微扰 MS-bar 计算（且 scheme 依赖），不是非微扰界；4D YM 的 beta 函数在这些尺度没有严格非微扰定义。**`RB2` 的困难正是这个 `NPB`，而不是 2 圈代数。**

**两个证伪测试（必须保留）.**
1. **数值/格点：** 3 圈或格点在 `g²≈2`（`λ=6`）给出 `t_up > 2.639`，且超出允许的 `Δ`。
2. **精确 `β` 的结构：** `β` 在 `0<λ≤7.3` 出现零点或拐点（非微扰 IR 不动点/相变）。

**定位.** `RB2` 是 `CPB-W` 的定量核心；`CPB-W` 仍是交接架构中**唯一**的缺失估计。本文不引入其他路线。

### 1.2 定理（交接不等式的四种等价形式）

**定理 1.** 设 `m,Λ,g*>0`，`q₁>0`，`1/g²(μ)=B ln(μ/Λ)`，`μ_up := Λ e^{1/(Bg*²)}`。则以下等价：
```
(i)   q₀ := q(μ_up) = m/μ_up ≥ q₁ ;
(ii)  μ_up ≤ μ* , 其中 q(μ*) = q₁ （存在唯一）;
(iii) M := ln(m/Λ) − 24π²/(11λ*) − ln q₁ ≥ 0 ;
(iv)  t* := ln(μ_up/Λ) = 24π²/(11λ*) ≤ t_S := ln(m/Λ) + ln(1/q₁) .
```
**证明.** `q` 严格减，`μ_up = Λ e^{1/(Bg*²)} = Λ e^{24π²/(11λ*)}`。取对数：
`q₀ = (m/Λ)e^{−24π²/(11λ*)}`，故 `q₀≥q₁ ⟺ ln(m/Λ)−24π²/(11λ*) ≥ ln q₁`。`(ii)` 由 `q` 的严格单调与介值定理。`(iv)` 是 `(iii)` 的移项。∎

**几何读法（推荐给主线）：** 在 `(t, ln q)` 平面（`t=ln(μ/Λ)`），物理轨迹是直线 `ln q = t_m − t`（`t_m=ln(m/Λ)`，斜率 −1）。强域是 `t ≤ t_S = t_m + ln(1/q₁)`，弱域是 `t ≥ t*`。**交接 ⟺ 区间 `[t*, t_S]` 非空**，长度 `= M`。三个可独立改进的量：
```
M = [ ln(m/Λ) ] − [ 24π²/(11λ*) ] − [ ln q₁ ]
      ↑ 谱/强侧       ↑ 弱侧射程          ↑ 强侧射程
```
这是本文建议主会话采用的**预算表**：任何一侧的改进都可直接折算进 `M`。

### 1.3c 2-loop running bound（RB2）

物理归一化下的 2 圈流为
```
dλ/dt = −A λ² − B λ³,   A = 1/C_RG,   B = 51/(121 C_RG²),   C_RG = 24π²/11,
```
（**只用 `C_RG`，不手写 π² 系数**）。积分是初等的：
```
t_up^{2L}(λ) = C_RG/λ − (51/121) ln(1 + 121 C_RG/(51 λ)).
```
核对：`t_up^{2L}(λ) = C_RG/λ − (B/A²) ln(1 + A/(Bλ))`，且 `B/A² = 51/121`。

### 1.4 归一化：`24π²` 与 `12π²` 是同一公式的两种坐标

### 3.2 最佳路线：`(a)+(b)` 混合

**判断：最佳路线是 (a) 的类保持框架 + (b) 的 signed-gas/有效密度方法，而不是任何单一路线。**

理由：

1. **`H3` 的困难不是 UV，而是交叉点。** UV 侧 Balaban 已足够（`gluing` 的 GL3/GL6 可复用）；强侧 SZZ/CNS 已足够（至少到 `q₁=O(1)` 的量级，待 (c) 定量）。唯一没有工具的是 `q~1`、`λ~6–12` 的**中间窗口**。
2. **在中间窗口，耦合不是小参数，但质量隙是。** `q=m/μ~1` 意味着每块的传播子被 `e^{−q}` 压制；缺陷团簇的活动度按 `e^{−q|C|}` 衰减。sigma-model 模板的 signed gas 正是把这个衰减变成收敛判据；Balaban 的类保持提供了"有效作用量留在固定类"的语言。
3. **2D O(N) 是最接近的先例：** 它也是渐近自由、也有动力学生成的 mass gap、也用 block spin + signed gas 跨过全耦合。若 4D YM 能移植，`H3` 只是副产品（模板会直接给 MG）。这就是为什么 (b) 的方法比 (a) 的原始展开更可能跨过 O(1)。
4. **为什么不是 (d)：** Bakry–Émery 在弱耦合的负曲率与渐近自由同源；要证明交叉点曲率为正，本质上要证明质量隙已经生成——这是把结论当假设。但它提供了一个**可数值检验的代理量**（Hessian 最低特征值），所以保留为 `CPB-S` 的证伪工具。
5. **为什么不是 (c) 单独：** 强侧即使到 `q₁=0.2`，仍需弱侧 `λ*≈5.8`（SU(3) `g²≈1.95`）；CNS 不解决弱侧。

## 4. 证明尝试：把 `H3` 归约到两侧射程估计

### 4.1 归约定理（本报告的主要逻辑产出）

**设定.** `H1` 是弱侧（Balaban 型）在 `g²≤g*²` 的分析；`H2` 是强侧（signed gas / polymer）在 `q≥q₁` 的分析。把两侧"射程"显式化：

- **W（weak reach）**：存在 `λ_c>0`，使弱侧类保持对全部 `λ≤λ_c` 成立，从而 `H1` 可取 `λ*=λ_c`。
- **S（strong reach）**：存在 `q_c>0`，使强侧 signed-gas 类保持对全部 `q≥q_c` 成立，从而 `H2` 可取 `q₁=q_c`。

**定理 2（条件性）.** 设 W 与 S 成立，常数 `(λ_c,q_c)`，并令 `t_up(λ_c)=ln(μ_up/Λ)` 为真实 RG 时间。则 `H3` 成立 **当且仅当**
```
m/Λ ≥ q_c · exp(t_up(λ_c)) .
```
一圈 `t_up=24π²/(11λ_c)`；数值 3 圈在 `g²≈1.8` 处 `t_up≈2.0`（§1.3b）。
**证明.** 在 `(t,ln q)` 平面，弱域 `t≥t_λ:=t_up(λ_c)`，强域 `t≤t_S:=ln(m/Λ)+ln(1/q_c)`。`H3` ⟺ `t_λ≤t_S`（定理 1(iv)）。移项即得。∎

**要点（必须读）：`H3` 不是"两条展开在某处相遇"的口号，而是一个显式的物理质量下界。** 一圈 `t_up`：取 `λ_c=12, q_c=1`，需 `m/Λ≥e^{1.795}≈6.02`；取 `λ_c=6, q_c=1`，需 `m/Λ≥e^{3.59}≈36`（一圈高估）。数值 3 圈 `t_up≈2.0`（`g²≈1.8`）：`q_c=1` 需 `m/Λ≥e^{2.0}≈7.4`；`q_c=0.5` 需 `m/Λ≥3.7`。**与文献量级 `m/Λ≈4–8` 正面相遇——重叠是边缘可及的，不是显然的。** **W 与 S 是两个独立估计；本报告判断 W 是瓶颈，S 是新对象（§4.2）。** 如果只想要恰好等价于 `H3` 的估计，那就是数值不等式 `M≥0` 本身；定理 2 的价值是把 `M≥0` 拆成"方法射程"（`λ_c,q_c,t_up`）与"物理质量"（`m/Λ`）两个可独立攻的量。

### 4.2 两侧估计的精确陈述

#### W（weak reach，瓶颈）

**Conjecture `CPB-W`（Crossover Preservation, Weak）.** 存在 `λ_c≈7.3`（2 圈，`g²≈2.43`，`α_s≈0.19`；3 圈/数值版 `λ_c≈6`；只用一圈则 `λ_c≈12`）与弱侧类 `C_W(ε_0)`（massive Gaussian + 有界相互作用，相对误差 `ε_0≤1/2`），使有效作用量在全部 `λ≤λ_c` 保持在 `C_W` 中，且一步分块后 `C_W` 不变；**并给出 `t_up(λ_c)` 的 2 圈严格界 `RB2`（§1.3c）**。等价地：massive 背景场展开在 `g²≤λ_c/h^∨`（SU(3): 2 圈版 `g²≤2.43`，`α_s≤0.19`；一圈保守版 `g²≤4`，`α_s≤0.32`）收敛，相对误差 ≤1/2。（**不要**用 3 圈 `t_up` 反解 `λ_c`；见 §1.3b 的转换警告。）

**为什么 W 是瓶颈：** Balaban 的原始展开按构造在 `λ~1` 停；要到 `λ_c~6–12` 必须换成"围绕质量真空"的背景场展开，其小参数是 `(g²/(16π²))·ln(1/q)`——在 `λ_c=6`（`g²=2`）、`q~1` 时约为 `0.0127·O(1)≪1`（`g²~2` 本身不是小参数，但圈因子与质量提供的 IR 截断使它变小；对数至多 `ln(1/q_c)≲2`）。这是 `(a)` 的现代版本；`(b)` 的 signed gas 若能全局工作，也自动给 W。

#### S（strong reach，新对象）

**设定.** 格点 `T⁴_L`、间距 `a`、Wilson 作用量、`β=2N_c/g²`；分块因子 `b=2`；第 `k` 步块尺度 `a_k=2^k a`，有效作用量 `S_k`，有效质量 `m_k = q_k/a_k`（无量纲 `q_k=m a_k`），有效耦合 `λ_k=h^∨g_k²`。把 `S_k` 写成
```
S_k = S_k^G + V_k ,
```
其中 `S_k^G` 是质量 `m_k` 的** massive Gaussian**（协方差 `(−Δ_{a_k}+m_k²)^{−1}`），`V_k` 是相互作用。把 `V_k` 在 signed-gas（polymer）基下展开，权重 `w_k(C)`，`C` 是块格上的连通团簇，`|C|` 是其块数。

**活动度（新对象）.** 对 `q>0` 定义
```
z_k(q) := sup_{x} Σ_{C∋x} |w_{k,q}(C)| · e^{κ q |C|} ,   κ := 1/2 ,
```
其中 `w_{k,q}(C)` 是**质量 `q` 处**的 signed-gas 权重（显式依赖 `q`）。`e^{+κq|C|}` 是标准 Kotecký–Preiss 因子，用来抵消团簇熵；**它不是**质量压制本身。质量压制在 `|w_{k,q}|` 里：若
```
|w_{k,q}(C)| ≤ e^{−c₀ q |C|} ,   c₀ > κ ,
```
则**组合**权重每块为 `e^{−(c₀−κ)q|C|}`；取 `c₀=1, κ=1/2` 即 `e^{−q|C|/2}`（`q=1` 时 0.61，`q=2` 时 0.37）。于是 `z_k(q)` 关于 `q` **单调不增**，最坏点在最小 `q=q_c`——但**这依赖 `c₀>κ` 与 `|w_{k,q}|` 的 `q` 依赖，二者必须显式写出**。

**更正（曾写反/写漏）.** 早先的写法 `Σ|w_k(C)| e^{+κq|C|}` 把 `|w_k|` 当成 `q`-无关，导致 `z` 看似随 `q` **递增**，与"最坏点在 `q_c`、只需证一次"直接冲突。**`+` 号本身是标准 KP 权重，没有错；错在漏写 `|w_{k,q}|` 的 `q` 依赖与 `c₀>κ` 假设。** 若 `c₀≤κ`，单调性失败，"只需在 `q_c` 证一次"不成立，必须逐尺度证。

**类.** `C(z_c,q_c) := { S : z_k(q) ≤ z_c  ∀ q ≥ q_c }`。

**Conjecture `CPB-S`（Crossover Preservation, Strong）.** 存在绝对常数 `q_c ∈ [1, 3/2]`、`z_c = 1/2`、`c₂>0`，使得对每个满足 `q_k ≥ q_c` 的尺度 `k`，若 `S_k ∈ C(z_c,q_c)`，则
```
(a)  z_{k+1}(q_{k+1}) ≤ z_c                     （类保持）
(b)  q_{k+1} = b q_k = 2 q_k                    （运动学：m 固定、块尺度加倍）
(c)  λ_{k+1} = λ_k − c₂ λ_k² + O(λ_k³)          （一圈 running）
(d)  以上常数关于体积 L 与 UV 截断 1/a 一致
```
**注意 (b) 是精确的，不是动力学输入：** `q_k=m a_k`、`a_k=2^k a`，故 `q_{k+1}=2q_k`。于是**在 `c₀>κ` 下** `z_k(q)` 随 `q` **单调不增**（质量压制向 IR 增强），**最坏点在窗口的最小 `q`，即 `q_c`**。因此 `CPB-S` **只需在匹配点证明一次**（依赖 `c₀>κ`；否则必须逐尺度证）。

**单步版本 `CPB-S₁`：** 只需在交叉点 `q=q_c` 处证明一次 `z(q_c)≤1/2`。

**为什么这是"新数学"而不是重述：** Balaban 的类保持是围绕**平凡联络**、用**耦合**作小参数；`CPB-S` 是围绕**质量 `m_k` 的 Gaussian**、用**活动度 `z`**作小参数。在 `λ~10` 处前者没有小参数，后者有（如果 Bianchi 抵消足够强）。2D O(N) 的 signed gas 正是这个机制的先例；4D YM 的移植需要证明 **Bianchi 抵消把缺陷作用量的 `q`-标度从线性推到 `q²`**（§4.4 命题 B）——这是 `CPB-S` 的实质内容。

### 4.3 为什么标准路线在交叉点失效（逐条技术原因）

- **Balaban.** 小场展开围绕 `U=1`；大场区域的活动度由 `e^{−β·action}` 控制，`β=2N_c/g²`。在 `g²=3.5`（SU(3) `β=1.7`）处 `β` 小，大场不被压制；有效作用量离开"小场类"。他的 running 也只到 `λ~1`。**缺的不是误差估计，而是"围绕质量真空"的展开。**
- **强耦合.** 收敛半径由 `β/(2 dim f)` 控制；`q₁~1` 需 `β~2.2`（SU(3)），而严格 cluster expansion 的 `β` 阈值通常远小于此。CNS 的"expanded regimes"是唯一的希望；需核对其确切 `β₀`。
- **Bakry–Émery.** Wilson 作用的 Hessian 含 `−[F,F]` 型负项；`β` 小时负区不稀有；`β` 大时负项被 `β` 放大。**只有质量项 `m²` 能压住它，而 `m` 是未知。**
- **CNS.** 见上；是强侧的 concrete 增量，不是弱侧。
- **群一致性.** 只给归约与常数表；修正指数后小 `h^∨` 更难。

### 4.4 Bianchi 抵消：`e^{−cq}` vs `e^{−cq²}`（独立命题 B）

`z(q)` 是小参数，但**它的 `q`-标度决定 `CPB-S` 是否可用**。关键不在数团簇，而在**单团簇权重 `|w_q(C)|` 对 `q` 的标度**。

**命题 B（Bianchi 标度；条件性）.** 假设：
- (H1) 带号气体缺陷支撑在**闭 2-曲面**上（2-形式 cocycle，`dF=0`）；每个团簇 `C` 是 plaquette 的并，无边界。
- (H2) 缺陷作用量对**面积**广延：`S_def(C)=σ(q)|C|+o(|C|)`，且张力有**下界** `σ(q) ≥ c₀ q²`（4D 中 2-曲面张力维数为 2；`c₀` 是待定的动力学系数）。
- (H3) 团簇熵 `N(n) ≤ e^{γ n}`。

则对 `q² > γ/c₀`（`c₀` 是 `σ≥c₀q²` 的常数），
```
|w_q(C)| ≤ e^{−c₀ q² |C|} ,   z(q) ≤ C e^{−c q²} .
```
**证明.** `|w_q(C)|≤e^{−S_def(C)}≤e^{−c₀q²|C|}`；由 (H3)，
`z(q) ≤ Σ_n e^{γn−c₀q²n} = 1/(1−e^{γ−c₀q²})`，对 `q²>γ/c₀` 有界，且 `z(q)≤C e^{−c q²}`。单调性：`c₀q²>κq` 当 `q>κ/c₀`，故 `z` 递减，"只需在 `q_c` 证一次"成立。∎

**反例/障碍（`q`-线性分支）.** 若放弃 (H1)，允许**3-维畴壁**（domain wall）：作用量对 3-面积广延，张力维数为 1，`σ_3(q)~q`。则 `|w_q|~e^{−c₀q|C|}`，
```
z(q) ~ Σ_n e^{(γ−c₀q)n} = 1/(1−e^{γ−c₀q}) ~ 1/q   (q>γ/c₀),
```
**只有幂律 `1/q`，连 `e^{−cq}` 都不到。** 此时"猜想 A"（`e^{−cq²}`）**不成立**；`q_c` 需大到 `1/q_c<1/2`（`q_c>2`），弱侧射程被推高。（3-体积缺陷给出更强制制 `q⁴`，不是障碍；真正的障碍是畴壁。）

**哪一支是 YM？** `F` 是 2-形式，`dF=0` 使缺陷是 2-cocycle（闭 2-曲面），支持 (H1)。但 (H2) 的 `σ(q)~q²` 是**动力学**陈述：它要求 2-曲面的张力以 `m²=q²` 标度。若张力是 `Λ²`（例如 IR 中心涡旋），则在 `m` 单位下 `σ~(Λ/m)²q²`，`c₀` 可能很小，`q_c=sqrt(γ/c₀)` 被推高。**Bianchi 结构是必要的，但不充分；开放内容正是 `σ(q)~q²` 的系数 `c₀`。**

**证伪测试.**
1. **格点：** 测缺陷作用量 `S_def(C)/|C|` 对 `q` 的标度；若线性（不是二次），命题 B 失败（走 `1/q` 分支）。
2. **拓扑：** 检查主导缺陷团簇是否闭 2-曲面；若体积缺陷/畴壁主导，(H1) 失败。
3. **活动度：** 用正确 KP 因子测 `z(q)`；若只按 `1/q` 衰减，`e^{−cq²}` 不成立。

**对 `q_c`、`λ*` 的后果（2-loop `t_up`，`m/Λ=8`；取前置常数 `C=1`，即 `q_c=sqrt(ln2/c₀)`）.**

| `z` 的标度 | `q_c` | 需要的 `λ*`（2-loop） | `g²` (SU(3)) | `α_s` |
|---|---:|---:|---:|---:|
| `e^{−cq²}`, `c₀=1` | 0.83 | 6.80 | 2.27 | 0.180 |
| `e^{−cq²}`, `c₀=0.5` | 1.18 | 7.78 | 2.59 | 0.206 |
| `e^{−cq²}`, `c₀=0.25` | 1.67 | 9.10 | 3.03 | 0.241 |
| `1/q`（`q`-线性） | ≥2 | 10.02 | 3.34 | 0.266 |

**注意（`q²` 的收益只在 `q≫1`）：** 上表 `e^{−cq²}` 行在 `q≈1` 与 `q`-线性**中性**（`q²≈q`）；表里的 `q_c` 数值来自 activity 常数 `c₀`，不是 `q²` 标度的功劳。`q²` 只在 `q≫1` 改善衰减；交叉点 `q≈1` 无收益。

**结论：** 若 `c₀≳0.5`，`e^{−cq²}` 把 2-loop 目标压到 `λ*≈7.8`（`g²≈2.6`）；若只有 `1/q`，目标升到 `λ*≈10`（`g²≈3.3`）。**当前状态：命题 B 未证；`dF=0` 只给 (H1)，`σ(q)~q²` 的系数 `c₀` 是缺失的动力学输入。**

### 4.5 One-step 类保持（CPB-W 第一步）

详见独立文件 `CPBW-one-step.md`（U(1)、固定质量/体积、第一层块、**C² 范数**）与 `CPBW-skeleton.md`（9 条引理表，每条有陈述/来源/是否即为 CPB-W 或 NPB）。

- **范数：** C² on the ball（sup+Lip+Hessian），不是只用 Lip。条件期望保 sup（无收缩）、压缩 Lip（上界）；**Hessian 下界**用于非退化。只证上界会让 Gaussian 部分被吃掉、类塌成空集。
- **U(1) 检验什么、不检验什么：** U(1) 自由，`F=dA` 使 `dF=0` 自动；**没有 Bianchi 抵消**。U(1) 只检验 Gaussian/分块步（协方差分解、涨落 log、C² 收缩/非退化），**不检验** signed-gas 缺陷机制或 `e^{−cq²}` 的 Bianchi 标度；不能读成"`CPB-S` 已验证"。
- **U(1)：条件性成立。** `δ≤C₁ε²L(q)+C₂ε³L(q)²`，`L(q)≤C₃ln(1/q)+C₄`；小场 `εL^{1/2}≤1/2` 与非退化 `ε<c₀m²/C` 下，`S_{k+1}''≥(c₀m²−Cε)Id>0`，`m_{k+1}=m(1+O(ε))`。得 `δ≤C(g²/16π²)ln(1/q)+O(λ³)`。U(1) 一圈系数为零，实际 `δ` 更小。
- **非阿贝尔：卡在 skeleton 引理 6（大场 C² 界）。** 交换子给 `‖V''‖≲R³/g²+R²/g`；`q~1, g²~2, R~1.4` 时 `≈2.8>c₀`，非退化失败。Balaban 的大场界（CMP 122 (1989) 175–354; UV 稳定性 CMP 102 (1985) 255–275）假设 `g` 小（UV），不覆盖 `q~1`。**非阿贝尔一步类保持未证。** 引理 6 是 CPB-W 的类保持核心，不是 NPB。
- **局部 cumulant 界（一页：`CPBW-cumulant.md`）：** 目标三阶连通 cumulant，`e^{−q·dist}` 衰减，体积/UV 一致；证明经局部 cluster 展开，只需局部 activity 界（紧群），不需全局 `sup|V|`。但 `g²~2` 处标准 `C_cum≥2`；`εL^{1/2}=0.24+C_cum R₃`（`R₃=0.16–0.46`）：`C_cum=1→0.40–0.70`（边缘），`2→0.56–1.16`（不过），`3→0.72–1.62`（不过）。**若只能给 `C_cum≥2`，Gaussian 计权路线数值死亡。**
- **Bianchi/符号抵消引理（一页：`CPBW-bianchi-lemma.md`）：** `q²` 形式在 `q≈1` **中性**（`q²≈q`），救不了 `C_cum` 或 `z(1)`；唯一希望是带号抵消因子 `κ_c<1`（固定边界的闭曲面带号和；注意与 KP 常数 `κ=1/2` 区分）。CPB-W 需 `κ_c≤0.8`；CPB-S 需更强；同一 `κ_c` 服务两侧。**判定：`q²` 单独不够；带号抵消未测；若 `κ_c≈1`，两侧同时关闭。** 证伪：在 `q≈1` 测 `z_signed/z_abs`（不只是 `S_def/|C|`）。
- **不碰 `RB2/NPB`；不声称证明 `CPB-W`。**

### 4.5b 证明状态（诚实）

- **已证（本文）：** 定理 1（等价形式）、定理 2（W+S ⇒ 显式质量下界 `m/Λ ≥ q_c e^{t_up(λ_c)}`）、§1.3 的数表、§1.3b 的数值校准、§1.3c 的 2-loop 公式、§1.4 的归一化澄清。

## 5. 证伪测试

### F1（立即，逻辑）：约定审计

**测试：** 任何 `H3` 的计算/证明必须声明归一化，并满足
```
物理归一化 T(f)=1/2:  t(g²=1) = 24π²/(11 h^∨)   （SU(3): 7.18）
T(adj)=2h^∨ 归一化:   t(g_gu²=1) = 12π²/(11 λ_gu),  g_gu² = g²/2
```
并复现 `numerics/REPORT.md` 的"1 圈 7.18 / 3 圈 5.06"（物理归一化）。**混用**两套归一化会在 `g²=1`、`m/Λ=8` 处把 `q₀` 从 `6.1e−3` 变成 `0.22`（差 36 倍）。
**判定：** 不声明归一化、或混用，即证伪该计算。另查方案不变性：`g²=1` 不是不变量（`Δt=+0.62/−0.76`），任何以它为交接线的论证必须用 `M` 重写。

### F2（数值）：交叉点格点测量

**协议（SU(3)，Wilson）：**
1. 在 **`β=3.3–2.6`（`g²≈1.8–2.3`，物理交接）** 做 Monte Carlo，`L` 取 8–16；再在 `β=2.2`（`g²≈2.7`）与 `β=1.7`（`g²≈3.5`）做保守对照。`ξ/a` 预期 O(1)–O(5)，有限体积可控。
2. 测 `ξ/a`（从 0++ 胶球关联或 Polyakov 关联的指数衰减）⇒ 得到 `q` 在强边界的值。
3. 测 `z(1)` 的代理量：
   - 块变量的连通 4 点函数与 Gaussian 预测之比 `R₄`；
   - 缺陷密度 `ρ`（块曲率超过阈值的比例）；
   - 有效 Hessian 最低特征值 `κ_eff`（在规范不变子空间，用热化构型上的数值微分/Hessian）。
**判定：**
- `CPB-S₁` 通过：`R₄ ≤ O(1)`、`ρ ≤ 0.5`、`κ_eff > 0` 且 `κ_eff ≳ m²`。
- `CPB-S₁` 失败：`R₄ ≫ 1` 或 `ρ ≈ 1` 或 `κ_eff < 0`。此时强侧不能到 `q_c~1`，`H3` 只能靠更强的弱侧（`λ_c≳12`）或格点 `m/Λ` 下界，**交接需新机制**。
**现有数据：** `numerics/REPORT.md` 只有 `β≈6` 的 `q` 与 `Z₂` 的相变数据，**没有** `β≈2.6–3.3` 的 SU(3) `ξ/a` 或 `z` 代理量；需新跑。`Z₂` 数据仅作方法校准。

**`ξ/a` 是数值证据，不是证书：** 证书是严格不等式 `q₁^σ≤0.143`；数值只作可行性/一致性，且若作证据需 **2σ 下界**与 `L/ξ≥4`（`L=12` 在 `ξ≈7` 处饱和到 `ξ/a≈3–4`，不能支撑 `ξ/a≥7`）。**数值不构成证书。**

### F3（逻辑）：空洞性检验

- `H3` 是**单条数值不等式** `M≥0`。任何只证"存在 `g*` 使…"、"对充分大的 `m/Λ`"、"对充分小的 `g*`"的陈述都是**空洞**的（`gluing` C6 的量化纪律同样禁止"对充分大的 N"）。
- **判定：** 若一个"证明"不能给出显式 `(m/Λ, q₁, λ*)` 三元组并代入 `M`，则它不是 `H3` 的证明。
- **群一致性检验：** SU(2) 在 `g²=4.5`（`λ*=9`）应与 SU(3) 在 `g²=3`（`λ*=9`）有相同的 `q₀`（同一 `m/Λ` 下）；只证 SU(3) 不够。G₂（`h^∨=4`）在 `g²=2.25` 与 SU(3) `g²=3` 同 `λ*`。

### F4（边界反例）：必须失败的两端

- `m/Λ→0`（无质量）：`q₀→0`，`H3` 必须失败。任何证明若不实质使用 `m>0` 的定量下界，必错。
- `q₁=∞`（无强侧）：`M→−∞`，失败。
- `λ*→∞`（弱侧永真）：`M→ln(m/Λ)−ln q₁`，此时 `H3` 退化为 `m/Λ≥q₁`——即"质量大于强侧阈值"，仍非平凡。
这三条确保陈述非空洞。

## 6. 什么会改变结论

按"改变 `M` 的量"排序：

1. **`m/Λ` 的真实值。** 本文用 `m/Λ=4–8`（格点/文献量级）。若某个严格或半严格输入给 `m/Λ≥20`，`q₁=1` 只需 `λ*≈7.4`（SU(3) `g²≈2.5`），落在 Balaban 扩张的可及范围边缘。**这是最便宜的翻转。**
2. **强侧 `q₁`。** 若 CNS 或 signed gas 能把严格强耦合推到 `q₁≤0.2`，弱侧只需 `λ*≈5.8`（`g²≈1.95`）。**这是第二便宜的翻转。**
3. **`CPB-S` 成立。** 若 `z(1)≤1/2` 被证（或数值强烈支持），强侧到 `q_c~1` 可行；连同 `CPB-W`（弱侧到 `λ~6–8`，即 `g²~2`，并带 2 圈 `t_up` 界）与 `m/Λ≈7.4`，`H3` 随 `q₁≈1` 成立（定理 2）。
4. **Bianchi-signed gas 的 `e^{−cq²}` 版本（命题 B）。** 若 `σ(q)~q²` 且 `c₀≳0.5`，`q_c≈1.2`，2-loop 只需 `λ*≈7.8`（`g²≈2.6`）；若只有 `1/q`，需 `λ*≈10`（`g²≈3.3`）。见 §4.4。
5. **归一化。** `12π²`（T(adj)=2h^∨，g² 半值）与 `24π²`（T(f)=1/2，物理 g²）各自正确；换归一化需同时换 `g²`。本文固定物理归一化，故 §1.3 的数表用 `24π²`。
6. **16 输入原文。** 若原文的 `RG1–RG5` 已含"到 O(1) 耦合的步进定理"，则 `H3` 归约到该输入（Step 0 翻转）；建议主会话按 §2.4 的字符串核对。
7. **`m/Λ` 的循环性。** 现有数值用 `Δ/Λ∈[4,8]` 作输入来"显示重叠"，这是循环的；任何数值证据必须来自**独立**的 `m/Λ` 计算（如胶球谱的格点外推），否则不能计入 `M`。

## 8. 诚实边界与风险

1. **未证 `H3`。** 本文的定理 2 是条件性的；`CPB-W`、`CPB-S` 是猜想，不是定理。
2. **`CPB-S` 的数值先例缺失。** 2D O(N) 的 signed gas 是定理，但 4D YM 的移植没有先例；`z(1)≤1/2` 可能为假。若为假，本文的"最佳路线"判断需要重估（届时最可能的是强侧 CNS 路线）。
3. **Step 0 是审计级（`research/handoff-audit`），但未重建 Lean 源。** 若 Lean 级复核发现 `RG1–RG5` 含更强的跨尺度命题，结论可能改变。
4. **`m/Λ` 与 `q₁` 的数值是量级输入**，不是严格输出；§1.3 的表是"给定输入下的逻辑后果"，不是物理预言。
5. **归一化已由协调会话确认。** `24π²`（T(f)=1/2，物理 g²）与 `12π²`（T(adj)=2h^∨，g² 半值）是同一公式；本文固定前者，数表与 numerics 的 7.18 一致。引用时声明归一化即可，**不是未决错误**。
6. **`CPB-S` 与 `gluing` 的 GL2b 关系：** `CPB-S` 的类保持是"精确 RT + 截断误差控制"的定量版；它不依赖 RP 的"免费传输"（`gluing` R17 已纠正该方向）。`CPB-S` 若成立，GL2b 的截断控制也随之成立。
7. **更正（`z(q)` 写法）：** 早先把 `z(q)` 写成 q-无关的 `|w_k(C)|e^{+κq|C|}`，使 `z` 看似随 `q` 递增；正确写法含 `|w_{k,q}(C)|` 与 `c₀>κ`。`+` 号是标准 KP 权重，错在漏写 `q` 依赖。已全文统一（§4.2）。
