# 局部 cumulant 引理：过线条件（一页）

> 2026-11-22 · 只写"过线的条件"，不开始证明。对应 `CPBW-one-step.md` §5b(v)。
> 目标：把 `εL^{1/2}` 的 `0.4–0.7` 余量写成显式的 `C_cum` 依赖，判定 Gaussian 计权路线是否在数值上死亡。

## 0. 结论（先读）

- **引理形式：** 三阶**连通** cumulant，指数衰减 `e^{−q·dist}`，对体积 `L` 与 UV 截断 `1/a` 一致。
- **是否等价于全局 `sup|V|`：** **否。** 它只需要**局部 activity 界**（紧群/Wilson 给，局部作用量每 plaquette `≤2/g²`），不需要全局 `sup|V|`；所以逻辑上不是 (a)/引理 6。
- **但常数：** `C_cum` 由 `g²~2` 处的局部 activity 决定；标准 cluster expansion（Kotecký–Preiss/Brydges–Kennedy）在该参数区通常给 `C_cum≥2`。
- **过线条件：** 取 `εL^{1/2}(C_cum) = 0.24 + C_cum·R₃`，`R₃∈[0.16,0.46]`（三阶余项的估计范围）。
  - `C_cum=1`：`0.40–0.70`（**边缘**；仅低端过）
  - `C_cum=2`：`0.56–1.16`（**不过**）
  - `C_cum=3`：`0.72–1.62`（**不过**）
- **判定：若只能给到 `C_cum≥2`，这条 Gaussian 计权路线在数值上死亡。** 逻辑上 (b) 未被关闭，但数值余量（30%）不够。

## 1. 引理陈述（目标）

**设定.** `a=1`，块尺度 `q~1`；`V_x` 是 `x` 处局部扰动密度（一个 plaquette 或 `2⁴` 块）。对 `ξ∈[0,1]`，倾斜测度 `μ_ξ ∝ e^{−ξV}μ_G`（`ξ=0` Gaussian，`ξ=1` Wilson）；`q` 是 `μ_1` 的质量隙（块单位）。

**引理（局部三阶 cumulant 界）.** 存在 `C_cum<∞`，使对所有 `ξ∈[0,1]`、`x,y,z`，
```
|κ₃^ξ(V_x,V_y,V_z)| ≤ C_cum · e^{−q(|x−y|+|y−z|+|z−x|)/2} ,
```
其中 `κ₃^ξ` 是连通三阶 cumulant。等价地，局部密度
```
c₃ := sup_x Σ_{y,z} |κ₃^ξ(V_x,V_y,V_z)| ≤ C_cum · c₀(q,g²) < ∞ ,
```
且 `c₀` 与 `L,1/a` 无关（`μ_1` 在紧群上 UV 有限；衰减使 `y,z` 求和收敛）。

**所需矩：** 只用到 `V` 的三阶连通矩（不是 `sup|V|`）；四阶及更高阶由 Taylor 余项吸收（`t_*=1/2`，见 §5b(v)）。

## 2. 证明路线与 `sup|V|` 问题

**路线：** 对 `μ_ξ` 做 **Mayer/cluster 展开**：
1. 把 `V_x` 写成连通团簇的和；连通 cumulant = 连通团簇的求和。
2. 输入是**局部 activity 界** `|w(C)|≤e^{−c₀ q|C|}`（衰减来自质量隙 `q`）。
3. 由 Kotecký–Preiss/Brydges–Kennedy，`Σ_{C∋x}|w(C)|e^{κq|C|}<∞` 给指数衰减与 `C_cum`。

**关键：** 第 2 步的 activity 界是**局部**的（单团簇），由紧群/Wilson 的 `S∈[0,2/g²]` 逐 plaquette 给出；**不需要全局 `sup_φ|V(φ)|`**。所以它不等于引理 6 的 `sup`-on-ball。逻辑上 (b) 成立。

**但：** 在 `g²~2` 处，Kotecký–Preiss 判据 `Σ|w|e^{κq|C|}<1` 是**边缘**的；标准估计给 `C_cum≥2`（团簇熵 × activity 的常数）。这与 `CPBW-one-step.md` 的 `εL^{1/2}` 余量（30%）正面冲突。

## 3. 常数与过/不过

模型：`εL^{1/2}(C_cum) = 0.24 + C_cum·R₃`，`R₃∈[0.16,0.46]`（`R₃` 是三阶余项在 `C_cum=1` 时的贡献；`0.24` 是二阶中心值）。过线条件：`εL^{1/2} ≤ 1/2`。

| `C_cum` | `εL^{1/2}`（低端 `R₃=0.16`） | `εL^{1/2}`（高端 `R₃=0.46`） | 判定 |
|---:|---:|---:|---|
| 1 | 0.40 | 0.70 | **边缘**（低端过，高端不过） |
| 2 | 0.56 | 1.16 | **不过** |
| 3 | 0.72 | 1.62 | **不过** |

**过线所需：** `C_cum ≤ (0.5−0.24)/0.46 ≈ 0.57`（高端）到 `(0.5−0.24)/0.16 ≈ 1.63`（低端）。即 **`C_cum≲0.6–1.6`** 才过；标准值 2 已经出线。

## 4. 判定

- **逻辑：** (b) 未被关闭；引理只需局部 activity 界，不需全局 `sup|V|`。
- **数值：** 余量只有 30%；`C_cum=2` 给 `0.56–1.16`，**不过**。**若 cluster expansion 只能给 `C_cum≥2`，这条 Gaussian 计权路线在数值上死亡。**
- **唯一活路：** 若能在 `g²~2` 给出 `C_cum≲1` 的**改进 cluster 界**（例如利用符号抵消/Bianchi 使 activity 更小），则 `εL^{1/2}≈0.4`，边缘过。但这正是 `CPB-S` 的 Bianchi 抵消问题，不是 Gaussian 计权本身能提供的。
- **诚实结论：** 不要把 Gaussian 计权当成"绕过引理 6"；它把墙移到 `C_cum`，而标准 `C_cum≥2` 让路线数值死亡。若没有 `C_cum<1.6` 的新界，**回到引理 6**。
