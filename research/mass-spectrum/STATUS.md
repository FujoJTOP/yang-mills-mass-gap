## 一句话状态

**"有质量隙"与"存在孤立单粒子态"是两个不同命题；后者严格更强且 4D YM 未证。可证的核心是二者之间的精确等价（定理 A）与不等价反例（定理 B）；真正的墙是上限隙，其 O(3) 式证明依赖 YM 不具备的 Z₂。**

## 精确目标（定理 D）

设 `μ` 为 4D 纯 `SU(N)` YM 的 OS 测度，`(ℋ,H,Ω)` 为其重构，`O` 为 `0^{++}` 通道规范不变算符。目标：

存在 `m₁>0, Z>0, δ>0`：
`ν_O = Z δ_{m₁} + ν_rest`，`supp ν_rest ⊂ [(1+δ)m₁, ∞)`，且 `m₁ = Δ`。

其中 `ν_O(B) = ⟨AΩ|P_H(B)AΩ⟩`，`A = O − ω(O)`，是两点函数的 KL 谱测度。

**测度来源（GL1 合规）**：A0（`research/gluing/REPORT.md` §1.2；`research/glue-c-gauge-group/REPORT.md` (1.1)–(1.2)）：
`S_W(β) = β Σ_p (1 − (1/N_c) Re tr U_p)`，`β = 2N_c/g²`，`N_c := dim f`，`μ ∝ exp((β/N_c)Σ Re tr U_p)∏dU_e`；唯一组合 `γ = β/N_c = 2/g²`。裸 `exp(β Σ Re tr)` 须 `β = 2/g²`（`SU(3),g²=1 → 2`，不是 6）。

**记号**：`μ` **只**表示 OS 测度；质量一律记 `m`（`m_n, m_ρ^{(n)}, m₁, m₂`）；RG 尺度记 `s`（`Q(s)=√σ(s)/s`，`q(s)=m(s)/s`）。

## 与 O(3) 模板的差距（最关键）

O(3) 的证明支点是 **S2：偶扇区 ≥ 2e**，由自旋翻转 `q→−q` 的 Z₂ + 偶多项式协方差 ≤ 两点函数² 得到。它把"上限隙"变成对称性事实。

**SU(N) YM 的 `0^{++}` 通道没有这样的 Z₂**：C 与 P 都不能分离单胶球（`gg`，C-even）与双胶球（`(gg)(gg)`，也是 C-even）。故 S2 不可移植。

**可用类比（本报告独立观察）**：改取 **C 奇**（或 P 奇）通道，则
- 该通道最轻的单粒子态是 `0^{−+}`（≈2.56 GeV）；所有 C-even 态（含 `0^{++}`）不贡献；
- 任何 C 奇多粒子态至少含一个 C 奇粒子 ⇒ 最轻者是 `0^{−+}`+`0^{++}`，阈值 `≥ m_{0^{−+}} + m_{0^{++}}`（≈4.3 GeV）。
- **上限隙是 Z₂ 保护的**，类比 S2 成立（仍需粒子诠释）。
⇒ **建议第一个攻击目标是 C 奇通道，而不是 `0^{++}`。**

## 障碍（排序）

1. **O1 原子**：MG 只给率；正测度"率 Δ + 无原子"可行（定理 B）。需状态计数（近 `m₁` 态有限）——超出 MG 的新数学输入。**最致命。**
2. **O2 上限隙**：O(3) 的 S2 机制失效。C 奇通道可绕开，但需粒子诠释。
3. **O3 可见性**：需 `O` 与最低态的定量重叠；SU(N) 无 FKG，替代为特征标/聚合物展开（仅强耦合）。
4. **O4 4D 状态计数**：需方盒倍增的配分函数缺陷一致于截断 = RG 输出 = 与 MG 同一堵墙（不更难）。
5. **O5 复合算符重整化**：`tr F²` 需减除/混合；OSforGFF 无复合算符理论。**独立形式化缺口。**
6. **O6 连续统 `J^{PC}`**：`O_h → SO(3)` subduction 未形式化。影响定理 C(d)，不影响定理 D。
7. **O7 有限体积原子不持久**：不能用"有限体积特征值+紧性"直接得 I1；O(3) 用 state-count 绕开。
