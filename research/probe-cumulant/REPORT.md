## 0. 结论（先读）

**判定：`C_cum < 1.6` 在一种读法下可能（逐 plaquette 归一化 + 只要求物理匹配点），在其余所有读法下不可能；最干净的活路是换匹配的 Gaussian reference（α≈0.45）。**

**(1) 主测量。** 对 `V = S − S_G`（`S_G` = Wilson 作用量的二次部分 `tr A_p²/6`；`A_p = −i log U_p`）的逐 plaquette 零分离三阶连通 cumulant：

```
κ₃^plaq(β) = −0.036(2)·β³      (β = 2.2–3.6，偏差 ~10%)
```

即 **β=2.6: −0.64；3.0: −0.96；3.3: −1.24**。在 primary grid 上**全部 < 1.6**，最坏点（β=3.3）余量 **1.29×**。

**(2) 但 β³ 标度在 β > 3.6 崩溃，且先经过一个峰：**

| β | 2.2 | 2.6 | 3.0 | 3.3 | 3.6 | 4.0 | 4.4 | 4.7 | 5.0 | 5.3 | 5.6 | 6.0 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| `κ₃^plaq` | −0.39 | −0.64 | **−0.96** | −1.24 | −1.53 | −1.91 | −2.22 | **−2.35** | −2.29 | −1.91 | −1.01 | −0.36 |

`1.6` 的交叉在 **β ≈ 3.65**，峰在 **β ≈ 4.7**（**2.35 ± 0.01**），到 **β ≈ 5.4** 才回到 1.6 以下。峰值比 1.6 高 **1.47×**、比 2 高 17%。
**若 `C_cum` 要求对 UV 截断一致（`CPBW-cumulant.md` §1 的原话"对体积 L 与 UV 截断 1/a 一致"），测量给出 `C_cum ≥ 2.35` → `C_cum < 1.6` 不可能；标准 KP 的 `≥2` 不是松界，而几乎是真值。**

**(3) 归一化差 6 倍。** 若把 `V = Σ_x V_x` 按 **site**（每 site 6 个 plaquette 之和）分解，同一测量给出

```
κ₃^site = 6.04 × κ₃^plaq        (实测比 6.04–6.13，β=2.2–3.3)
```

β=3.0 时 **−5.81 ± 0.03**（= 6×0.96）。此时任何读法都 `≫1.6`，路线关闭。源文档写"`V_x` 是 x 处局部扰动密度（**一个 plaquette** 或 2⁴ 块）"，故**逐 plaquette 是主读法**；但这是必须由解析侧钉死的约定，差 6 倍就足以翻转判定。

**(4) 局部密度 ≈ 零分离值（primary grid 上无几何增强）。** 在 β ≤ 3.3 场是白的：`C₂(1)/C₂(0) = 0.0003–0.005`，`ξ_V ≤ 0.12–0.19` 格距；三点非对角项 ≤ 对角项的 1%；块均值满足 `κ₃(b=2 mean) = κ₃(b=1 site)/256`（实测比 0.97–1.03）。所以

```
c₀ = c₃ / |κ₃(0,0)| = 0.91–1.04 ≈ 1  ,      c₃ ≈ |κ₃(0,0)|      (β ≤ 3.3)
```

即 `Σ_{y,z}` 没有 `e^{−q·dist}` 的求和增强。**但 β ≳ 4 后关联长度增长**（`C₂(1)/C₂(0)`：0.028@4.7、0.10@5.6；`c₀`：1.6@4.7、3.5@6.0），局部密度升到零分离值的 1.5–3.5 倍——见 §3.4。**这只会让峰处的 `c₃` 更大，不改变判定方向。**

**(5) 最坏组态不改变结论（"sup_x 比平均更差"没有发生）。** 逐 plaquette 的第三矩完全由体贡献：最坏的 1% 组态只占 `κ₃` 的 **1.1%**（正好是均匀份额），最坏 5% 占 5.6%；`max|V_p| = 4.2–10.8`，但取到最大 `|V|` 的组态其 `κ₃` 是典型值。指数矩 `E[e^{|V_p|/2}] = 1.66–1.92`、`E[e^{|V_p|}] = 3.3–5.6`（β=2.2–3.3）——Bernstein 常数在逐 plaquette 归一化下数值安全。逐 site 则 `E[e^{|V|/2}] = 21–51`（有限，印证 `t_* < 1` 而非 `t_*~3`）。

**(6) 独立杠杆：Gaussian reference 是自由的。** `μ_G(α) ∝ e^{−αQ}`、`V(α) = S − αQ`；**任意 α > 0 都给出同一 Wilson 测度** `e^{−V(α)}μ_G(α) = e^{−S}`。实测 `κ₃(α)` 是 α 的**精确三次多项式**；`|κ₃|` 的最小在

```
α* = 0.44–0.46 (β=2.2–3.3) , 0.50–0.60 (β=4–6)
|κ₃^plaq(α=0.5)| = 0.001–0.023   (全 β 区间)
```

方差同时降约 20 倍。**匹配参考测度把常数降 40–270 倍，且不受 β 峰影响。**

**(7) 误差棒。** 统计：`±0.001–0.01`（500–1500 个 `meas=2` 的独立组态，jackknife over 100 blocks；`τ_int(P)=0.5`）。**系统误差主导：归一化 ×6（精确、约定问题）、Gaussian reference ×20–200、`log`/二次参考的约定 ~±10%、阻塞有效作用量未重建（未量化）。** 所以"C_cum 到底是多少"的误差不是统计的，而是约定的。

**(8) 判据对照。**
* `NP-T3b`（"`κ₃` 局部密度在 `q~1` 处 `≳2` ⇒ `C_cum ≤ 1.6` 无望"）：在 **β=3.0（`g²=2`，物理匹配点）不触发**（0.96 < 2）；在 **β≈4.2–5.1 触发**（峰 2.35 ≳ 2）。
* "有希望"（中心值 < 1.6）：**逐 plaquette + 物理点 = 有希望**；其余读法 = 关闭。
* "关闭"（明显 ≥2 且 `sup_x` 比平均更差）：**中心值在 β≈4–5 明显 ≥2，但 `sup_x` 不比平均差**（体效应）——所以关闭的理由是**中心值**，不是尾巴。

## 1. 对象、归一化与判据

### 1.1 `V = S − S_G` 的精确定义

取 `S = β Σ_p (1 − ⅓ Re tr U_p)`，`β = 6/g²`，`A_p = −i log U_p`（主支），

```
S_G = Σ_p tr(A_p²)/6 ,        q_p := tr(A_p²)/6 ∈ [0, π²/2]
V_p = β (1 − ⅓ Re tr U_p − q_p) ,        V_p ≤ 0 数值上逐点（max = 0 在 U_p=1）
```

三件可直接验证的事实：
1. `Σ_{plaquettes} V_p = S − S_G`，即 `V` 是精确的 tilt 密度（`STATUS.md` §T5：`V=S−S_G`，大场领头项是 `−S_G ~ −F²/2g²`）。
2. `V_p ≤ 0`（逐点），所以 `|V_p| = −V_p`；`max|V_p|` 由大角度 plaquette 给出。
3. `S_G` 的选择不是唯一的：`μ_G(α) ∝ e^{−αQ}` 对任意 `α>0` 都给出同一 Wilson 测度，`V(α) = S − αQ`。**α 是构造的自由参数**（§3.3）。

### 1.2 三种归一化与 cumulant 可加性

`V = Σ_x V_x` 的分解方式决定了 `C_cum` 的量纲：

| 归一化 | `V_x` | 与 `κ₃^plaq` 的关系 | β=3.0 实测 |
|---|---|---|---|
| **per plaquette**（源文档"一个 plaquette"） | `V_p` | 1 | **−0.96** |
| per site（`V=Σ_x V_x` 的字面读法） | `Σ_{p∋x} V_p` | ×6.04（可加性，实测） | **−5.81** |
| per b=2 block（密度） | 块均值 | ÷256（白场） | −0.021 |
| per b=2 block（总作用量） | 块和 | ×16×6.04 | ≈ −86 |

**关键**：cumulant 对独立变量可加，`κ₃(Σ_{i=1}^{6} v_i) = Σκ₃(v_i)` 若互不相关。实测 `κ₃^site/κ₃^plaq = 6.04`（不是 `6³=216`），说明同 site 的 6 个 plaquette 在**三阶 cumulant 上近似不相关**。所以 site 与 plaquette 归一化**正好差 6**，这就是判定翻转的全部内容。

### 1.3 零分离下界与局部密度

引理（`CPBW-cumulant.md` §1）：

```
|κ₃^ξ(V_x,V_y,V_z)| ≤ C_cum · e^{−q(|x−y|+|y−z|+|z−x|)/2}
```

令 `x=y=z`（指数 = 1）：

```
C_cum ≥ sup_{ξ,x} |E_ξ[(V_x − E_ξ V_x)³]|           (★)
```

**这是本探针的全部逻辑基础**：在 ξ=1 测出的单点第三中心矩就是 `C_cum` 的一个**严格下界**（在所选 `V_x` 归一化下），与 `q`、`c₀`、几何求和无关。同时

```
c₃ := sup_x Σ_{y,z} |κ₃(V_x,V_y,V_z)| ,        C_cum ≥ c₃ / c₀
```

实测 `c₀ = c₃/|κ₃(0,0)| = 0.91–1.04`（β≤3.3，§3.4），即两者在 primary grid 上给出同一数字；β≳4 时 `c₀` 升到 1.1–3.5，`c₃` 更大。

### 1.4 判据（来自任务）

* **有希望**：`C_cum` 中心值 < 1.6，或 < 2 但误差上界接近 1.6。
* **关闭**：`C_cum` 明显 ≥ 2，且 `sup_x` 比平均更差。

本文把"`C_cum` 明显 ≥2"按 (★) 的实测下界判断；`sup_x` 部分见 §3.5。

## 2. 方法与数值

### 2.1 格点与更新

* Wilson 作用量，`L⁴` 环面，周期边界；`L = 6`（β=2.2–6.0），`L = 8`（β=3.0，体积检查）。
* 更新：`research/lattice-cpb/su3_numba.py` 的 **Cabibbo–Marinari heat bath**（与 `lattice-cpb` REPORT §2 同一代码，已验证）。
* 每个 β：`therm = 1200–1500`，production `1500` 次测量、`meas=2`（即每 2 sweep 一次），Numba **单线程**（本机被其他会话占满，`sweep_par` 多线程反而慢 7×）。
* `τ_int(P) ≈ 0.5`，所以配置近似独立；误差用 **jackknife over 100 个配置块**。
* 平衡检查：`⟨P⟩` 与 `lattice-cpb` 报告一致（β=2.6: 0.17359 vs 0.173670；β=3.0: 0.2050 vs 0.205050；β=3.3: 0.2295 vs 0.229440）。

### 2.2 快速本征相位求解器

每个组态需要 6·L⁴ 个 plaquette 的 `tr(log U)²`。直接 `np.linalg.eigvals` 太慢；本目录用三次方程的闭式解（`probe.eig_angles_batch`），对 `U(3)` 的特征相位与 `np.linalg.eigvals` 相符到 **6×10⁻¹⁵**，快 3.7×。

`q_p` 对 `−1` 本征值附近的 `log` 分支敏感（β=3.0 时 2.5% 的 plaquette 有 |angle| > 2.9 rad）。这是 ~±10% 的约定系统（§6）；α-scan（§3.3）把它的影响也一并覆盖。

### 2.3 三点函数、局部密度与噪声偏置

对 `b=1`（`L⁴` 点）和 `b=2`（`(L/2)⁴` 块均值）：

* `κ₂(d) = ⟨δV(x)δV(x+d)⟩`，`κ₃(d₁,d₂) = ⟨δV(x)δV(x+d₁)δV(x+d₂)⟩`，`δV = V−⟨V⟩`。
* 位移集 `|d|_∞ ≤ 1`（81 个），全部 `81²` 对，用一次矩阵乘 `Sh @ (Sh·δ)ᵀ` 每配置算完。
* 局部密度 `c₃ ≈ Σ_{d₁,d₂}|κ₃|`。**注意**：`Σ|·|` 有正噪声偏置 `√(2/π)Σσ_pair`；本文报告 `c₃_abs`、偏置、`c₃_corr = c₃_abs − bias` 以及 `c₃(>2σ)`。`c₃_corr` 是主估计。
* 最坏组态：逐配置的 `max_x|V|`、逐配置的 `mean_x δ³`、前 1%/5% 组态的贡献份额、逐 site 的 `κ₃` 图（含噪声地板）。

### 2.4 独立交叉验证

`lattice-cpb` 已存 40 个 β=2.6/2.8/3.0/3.3（L=6）与 20 个 β=2.2（L=8）快照（间隔 400 sweep）。用同一分析重算，数值与本文 production 相符到 ~5%：β=3.0 逐 plaquette −0.970（快照）vs −0.962（production）；β=2.6 −0.648 vs −0.642；β=3.3 −1.250 vs −1.237。**误差棒**：快照统计只有 40 组态（±0.02），production 为 ±0.001。

**读法**：
* `κ₃^site = 6.04 × κ₃^plaq` 到 1.5%（β≤3.3），即三阶 cumulant 的可加性成立、同 site 的 plaquette 三阶不相关。
* `max|V_p|` 随 β 增长（β 前因子），但 `top1%` 份额在 β≤4.7 时是 1.1–1.2%，β=5.6/6.0 升到 1.5–1.6%：**第三矩是体效应**（高 β 端开始有尾巴的迹象，但离主导很远）。
* β=6 的 ratio 升到 8.7：弱耦合下 site 内关联变重要（不改变结论）。

### 3.2 β³ 标度律

`κ₃^plaq / β³`：

| β | 2.2 | 2.6 | 2.8 | 3.0 | 3.3 | 3.6 | 4.4 | 5.0 | 6.0 |
|---|---|---|---|---|---|---|---|---|---|
| `κ₃/β³` | −0.0368 | −0.0366 | −0.0362 | −0.0356 | −0.0344 | −0.0327 | −0.0261 | −0.0183 | −0.0016 |

在 β=2.2–3.6 上 `κ₃ = −0.036(2) β³` 成立到 ~10%（`κ₃(V) = β³·κ₃(p−q)`，背后的无量纲三次矩 `κ₃(p−q)≈−0.036` 在强耦合端是常数）。β>3.6 后标度崩溃，`κ₃` 经过 β≈4.7 的峰（2.35）后下降。**这一峰是本次探针最重要的新信息**：`C_cum` 的 sup 不在物理点，而在中间耦合。

### 3.3 α-扫描：Gaussian reference 的杠杆

`V(α) = S − αQ`，`κ₃(α)` 是 α 的精确三次多项式。逐 site 值（β=3.0）：

| α | 0 | 0.25 | 0.5 | 0.6 | 0.75 | 1.0 | 1.25 | 1.5 |
|---|---|---|---|---|---|---|---|---|
| `κ₃^site` | −0.43 | −0.33 | −0.070 | −0.305 | −1.36 | **−5.81** | −15.2 | −31.1 |

三次拟合给出 `α* = 0.459`、`κ₃(α*) = −0.053`、`Var(α*) = 0.207`。
逐 plaquette：`κ₃^plaq(α*=0.5) = −0.006 … −0.023`（β=2.2–6.0 全区间），即 **|κ₃| ≤ 0.023，比 α=1 小 40–270 倍**；`Var` 降 ~20 倍。

**意义**：`1.6` 这个阈值不是硬墙，它是"Gaussian reference 选择"的函数。若构造用匹配参考（`α≈0.45`，等价于把 `μ_G` 的二次系数匹配到实测响应，而不是微扰二次部分），实测三阶 cumulant 在整个 β 区间都 ≤0.023 → `C_cum<1.6` 有巨大余量。**代价**：误差预算 `εL^{1/2} = 0.24 + C_cum R₃` 里的 `R₃`、`ε`、`L(q)`、`c_F` 都要按新参考重算；这是 analytic side 的工作，本报告不声称它能过。

### 3.4 局部密度与衰减（白场）

逐 site 三点函数（β=3.0，`|d|_∞≤1`，`81²` 对）：

* `κ₃(0,0) = −5.807`
* `c₃_abs = 44.51 ± 1.00`，噪声偏置 `39.22` → **`c₃_corr = 5.29`**
* `c₃(>2σ) = 11.14`（313/6561 对；选择偏置，非物理）
* 非对角元：`(0,1)=+1.7e−2`，`(1,1)=−1.4e−2`，… 全部 ≤ diag 的 1%
* `C₂(1)/C₂(0) = 0.00303` → `ξ_V ≤ 0.17` 格距
* `c₀ = c₃_corr/|κ₃(0,0)| = 0.91`

β=2.2/2.6 同样：`c₀ = 0.97 / 1.04`。逐 β 的 `c₀` 与关联长度：

| β | 2.2 | 2.6 | 3.0 | 3.3 | 4.4 | 4.7 | 5.0 | 6.0 |
|---|---|---|---|---|---|---|---|---|
| `C₂(1)/C₂(0)` | 0.0003 | 0.0015 | 0.0030 | 0.0050 | 0.020 | 0.029 | 0.041 | 0.066 |
| `c₀`（逐 site） | 0.97 | 1.04 | 0.91 | 1.00 | 1.11 | 1.57 | 1.93 | 3.52 |

**结论：primary grid（β≤3.3）上 `c₀≈1`，`c₃≈|κ₃(0,0)|`，没有几何增强；β≳4 后 `c₀` 升到 1.1–3.5，局部密度是零分离值的 1–3.5 倍。** L=8（β=3.0）的 `c₃_corr = 5.96` vs L=6 的 5.29（±0.6，噪声偏置/有限体积），但零分离值 `κ₃(0,0)` 在 L=6/8 一致到 0.2%。 零分离下界 (★) 与 `c₀` 无关，是严格的那个；`c₃` 是上界性估计（含噪声偏置与有限体积）。

### 3.5 最坏组态与尾巴

| β | `max|V_p|` | 其组态的 `κ₃` | top1% | top5% | 逐配置 `κ₃` 范围 |
|---|---|---|---|---|---|
| 2.6 | 4.97 | −0.679（平均 −0.642） | 1.1% | 5.5% | [−0.739, −0.542] |
| 3.0 | 5.71 | −0.889（平均 −0.962） | 1.1% | 5.6% | [−1.141, −0.802] |
| 4.0 | 7.64 | — | 1.2% | 5.7% | [−2.331, −1.584] |

**读法**：
* 取到最大 `|V|` 的组态**不是**第三矩最大的组态；`top1%` 份额 = 1.1%（均匀份额）→ **没有稀有组态主导**。
* 逐 site 的 `κ₃(x)` 图：`sup − mean ≈ 5 ×` site-噪声（β=3.0：−5.81 → sup −1.48，std 0.86），与 1296 个 site 的极值统计一致；空间无结构（平移不变环面），无超过统计涨落的局部热点。
* 因此任务里的"`sup_x` 比平均更差"在本格点上**不成立**；`C_cum` 的大小是体效应。

**指数矩**（Bernstein 常数）：

| β | 2.2 | 2.6 | 3.0 | 3.3 | 6.0 |
|---|---|---|---|---|---|
| `E[e^{|V_p|/2}]` | 1.66 | 1.77 | 1.86 | 1.92 | 1.27 |
| `E[e^{|V_p|}]` | 3.3 | 4.0 | 4.9 | 5.6 | 2.1 |
| `E[e^{|V_site|/2}]` | 21.1 | 30.2 | 41.1 | 51.1 | 4.5 |

逐 plaquette 的 `M(1/2) = 1.7–1.9`，数值安全；逐 site 是 21–51（有限但大）。`E[e^{2|V_site|}] ~ 10⁸–10¹¹` 发散迹象明确，**印证 `t_*<1` 且 `t_*=2` 不可用**（`STATUS.md` §T5）。

### 3.6 对照（证明测量是 discriminative 的）

* **场对照**：blocked plaquette 场 `P_b − ⟨P_b⟩` 的 `κ₃`：`3e−5…7e−4`，`R₃ = 0.03–0.11` —— Gaussian。**这正是"不要用场的 Gaussian 尾做代理"的定量版本**：场是 Gaussian，`V = S−S_G` 的三阶 cumulant 不是 Gaussian 的尾巴，而由 `p−q` 的非线性决定。本文只用场作对照，不用它作 `C_cum` 的代理。
* **白噪声标度**：`κ₃(b=2 block mean) = κ₃(b=1 site)/256`（β≤4.7 实测比 0.93–1.08；β=5.0–6.0 升到 1.2–2.4，关联长度增长的信号）——白场的精确预言。
* **各向同性**：β=3.0 六个 plaquette 方向 `κ₃ = −0.952…−0.986`（3% 内）。
* **β=6 控制**：`κ₃^plaq` 降到 −0.36（峰值的 1/6），说明该诊断**能**区分强/弱耦合（不同于 `κ_eff` 的 Savvidy 陷阱）。

## 4. 判定

### 4.1 按读法分类

| `V_x` 归一化 | β=3.0（`g²=2`，物理点） | sup over β（cutoff 一致） | 判定 |
|---|---|---|---|
| **per plaquette，α=1** | **0.96**（余量 1.67×） | **2.35**（超 1.47×） | 物理点：**有希望**；cutoff 一致：**关闭** |
| per site，α=1 | 5.81 | 16.6 | **关闭** |
| per plaquette，α*=0.45 | ≤0.02 | ≤0.02 | **有希望** |
| b=2 block 密度 | ~0.02 | ~0.05 | 有希望（但归一化稀释） |
| b=2 block 总和 | ~86 | ~500 | **关闭** |

### 4.2 对"`C_cum < 1.6` 是否可能"的直接回答

* **在构造自身的规范归一化下（`V=S−S_G`，逐 plaquette，α=1）：物理点 0.96 < 1.6，可能；但 cutoff 一致的 sup 是 2.35，不可能。**
* 标准 KP 的 `≥2` 被测量"证实"：真值在峰处就是 2.35。**它不是松界；`C_cum<1.6` 的缺口在 β≈4.7 是真实的 1.47 倍。**
* 唯一同时逃开"归一化 ×6"和"β 峰"的读法是**匹配 Gaussian reference**（α≈0.45）：实测 `|κ₃| ≤ 0.023` 全 β 区间。

### 4.3 误差预算

| 来源 | 大小 | 说明 |
|---|---|---|
| 统计 | ±0.001（`κ₃^plaq`），±0.03（`κ₃^site`） | jackknife，可忽略 |
| 归一化（plaquette vs site） | **×6.04** | 精确；约定问题，非误差 |
| Gaussian reference α | **×20–200** | 实测；构造的自由参数 |
| log/二次参考约定 | ~±10% | 2.5% 大角度 plaquette 的分支敏感 |
| 阻塞有效作用量 vs 块均值 | 未量化 | 本文的 b=2 是块均值，不是 `S_eff` |
| ξ∈[0,1] 的 ξ<1 | 未测 | 只测 ξ=1（零分离下界仍严格有效） |

**所以"C_cum = X ± Y"里的 Y 不是 ±0.001，而是"约定未定"；真正的不确定度在 ×6（归一化）和 ×2–200（reference）。**

### 4.4 什么会改变判定

* **把归一化钉死为逐 plaquette 并放弃 cutoff 一致** → 有希望（0.96）。
* **要求 cutoff 一致** → 关闭（2.35）。
* **改用匹配参考 α≈0.45 并重做误差预算** → 有希望（≤0.02），这是唯一同时通过两种要求的路线。
* **若 b=2 的阻塞有效作用量（不是块均值）的 κ₃ 也 ~2**（IMC 才能测） → 即使逐 plaquette 也关闭。

## 6. 纪律与局限（必须与结论一起读）

1. **代理 `V` 与真实 `V` 的差距.** 本文测的是**微观** `V = S − S_G`（格点作用量及其二次部分）。`CPB-W` 引理要的是 **q~1 阻塞有效作用量**的扰动。二者不同：b=2 块均值只是微观密度的粗粒化（白场下被稀释 `b⁻⁸`），不是 `S_eff`。重建 `S_eff` 需要 IMC（NP-1）。**因此本文严格证明的是微观归一化下的 `C_cum` 下界；阻塞尺度只有 proxy。**
2. **只测 ξ=1.** 引理要求 `ξ∈[0,1]` 一致。零分离下界 `C_cum ≥ |κ₃^{ξ=1}|` 对任何 ξ-一致常数都成立，所以**不排除** ξ<1 有更大的 excursion；但 ξ=0 是 0、ξ=1 是 0.96，单调插值下 ≤0.96，非单调 excursion 未测。
3. **归一化不是误差而是约定.** ×6 是精确的；`C_cum<1.6` 的真假可能因一句约定而翻转。报告给出两种数字，不单选。
4. **`log` 分支.** 2.5% plaquette 有大角度；`q_p` 的参考（principal log）是约定，~±10%。α-scan 覆盖其影响。
5. **不声称证明.** 本文不给任何 `C_cum` 的上界；给出的是**下界**（严格）和"真值大约多少"（数值）。`C_cum<1.6` 的**充分性**仍需解析的 cluster 界。

## 附录：`κ₃(α)` 的精确三次性

`V(α)=S−αQ`，`κ₃(α)=E[V³]−3E[V²]E[V]+2E[V]³`。`E[V^k]` 是 α 的 k 次多项式，所以 `κ₃(α)` 是**精确三次多项式**，`Var(α)` 是精确二次。本文用 8 个 α 点加权拟合，`α*` 由 `|κ₃(α)|` 的最小值给出（β=3.0: `α*=0.459`）。这是交叉验证，不是拟合自由度。

单分量 quartic-Gaussian 模型（`V=−cF⁴`，`F~N(0,σ_F²)`，`σ_F²=c_F g²`，`c=1/(24g²)`）：

```
κ₃ = −c³E[F¹²] + 3c³E[F⁸]E[F⁴] − 2c³(E[F⁴])³
   = −c³σ_F¹² (10395 − 945 + 54) = −(9504/13824) c_F³ = −0.688 c_F³
```

实测 `κ₃^plaq = −0.64…−1.24` ⇒ `c_F ≈ 1.0–1.2`。（模型依赖，只作量级核对。）
