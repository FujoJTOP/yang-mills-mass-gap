# NA-3-T 可执行规格：Dobrushin / SDPI 收缩系数（非 cluster 估计）

> 2026-11-23 · 给 `lattice-cpb` 的执行规格（**先写后跑**）。`research/bianchi/NEW-ARCHITECTURE.md` §4 的展开。
> 纪律：这是**决策输入**，不是证明。**算的是空间方向聚类（Dobrushin ⟹ Euclidean 关联衰减 = 质量隙），不是虚构时间隙。**

## 0. 目的与"哪个隙"

- **目标：** 测 Euclidean YM 测度的 **heat-bath（Glauber）动力学的 Dobrushin / SDPI 收缩系数 `η`**，在 crossover（`q≈1`）是否 `<1`、且 `−ln η` 是否对 `L,β` 一致。
- **为何不是"虚构时间隙"：** Dobrushin 的 `η<1` 是**空间**聚类定理（`η<1 ⟹ 唯一 + 各方向指数聚类`，由**定理**给出），故给的是 Euclidean 关联衰减 = 质量隙。**不涉及 SQ Langevin 的谱隙。**
- **为何不撞 OB-1（循环障碍）——一句话：** **`η` 是局部系数，`η<1` 由 Dobrushin 定理导出聚类、不假定它；全局 `χ` 才是循环的输入。** 具体地：`η` 是**局部**影响系数的 sup（有限程、逐 link），不是全局磁化率 `χ = Σ_x⟨O O⟩_c`；`η<1` 可不假定隙而成立 ⟹ **不循环**。这正是 NA-3 区别于 BBD 的地方。

## 1. 定义（精确）

格点 `T⁴_L`（或 `L³×T`，周期），`Ω = G^{links}`，Gibbs 测度 `μ_β`（Wilson 作用量 `β`），单 link heat-bath 核 `P`。

- 条件分布：`P_e(·|U_{≠e}) ∝ e^{−β Σ_{p∋e}(1−Re tr U_p)} dU_e`（Haar）。
- **影响：** `I(e,e') := sup_{U,U' 仅在 e' 不同} ‖P_e(·|U) − P_e(·|U')‖_TV`。
- **Dobrushin 系数：** `η := max_e Σ_{e'} I(e,e')`（`e'` 遍历邻域；有限程 ⟹ 和局部）。
- **判据（Dobrushin）：** `η<1 ⟹ 唯一 + 指数聚类，率 ≳ (1−η)/range`。

> 注：在 4D，一个 link 属于 6 个 plaquette，其条件分布依赖至多 ~12 个邻 link，故 `Σ_{e'}` 是**有限小和**，`η` 可逐对精确算。

## 2. 估计量（**明确排除 cluster**）

三种，优先级从高到低：

1. **精确逐对影响（解析）。** 对单个 link 对 `(e,e')`，`P_e` 只通过共享 plaquette 依赖 `e'`；在两 plaquette 上解析算 `‖·‖_TV`（小优化/枚举）。**逐对精确值，无 MC、无 cluster。**
2. **path coupling（Bubley–Dyer）。** 两构型仅差一个 link，跑**一步** heat-bath（**最大耦合 / TV 最优**），量期望距离变化 ⟹ 收缩系数 `λ`；由 path-coupling 定理 `η ≤ λ`。
3. **Efron–Stein / 离散导数影响。** 方差型影响，给 `χ²`/Poincaré 型收缩（martingale），**不是** cluster 和。

> **禁止：** 用 cluster expansion 估 `η`（那是 BL-6）。若**唯一可得的严格上界**来自 cluster，见 §4 判据 **D1**。

## 3. 最小可执行实验

- **群 / 体积（按 `lattice-cpb` 现状：SU(3) 为主）：** **最小版本 = SU(3)、`L = 4`、`β = 2.2/3.0/6.0` 三点**（保守强耦合 / crossover / 弱耦合对照）。若 SU(2) 代码可用，加 `L = 4,6`、`β = 2.0,2.2,2.4` 做体积/β 趋势（可选，非阻塞）。4D 周期。
- **β 网格：** 最小三点 SU(3) `β = 2.2 / 3.0 / 6.0`；加密可选 SU(3) `β = 2.6, 3.3`；若 SU(2) 可用 `β = 2.0, 2.2, 2.4`。`β = 6.0` 是**弱耦合对照**（`η` 应 `→1`）。
- **两个核：** (a) 单 link heat-bath；(b) `b=2` **块** heat-bath（块平均后）。
- **测：**
  - `η`（§2 逐对精确 + path coupling 交叉校核）；
  - heat-bath **谱隙 / 自关联时间 `τ`**（单 link 与块更新）；
  - **时间方向聚类率 `m_eff`**（连通的 `⟨tr F(0) tr F(t)⟩_c` 衰减），作**直接的质量隙代理**，用于对照。
- **判据（活/死见 §4）：** `η<1`？`1−η` 是否 `~ a·m_eff`？`τ` 是否 `O(1)`（格点单位）？`η, 1−η` 随 `L`、`β` 是否稳定。
- **规模：** L=4 SU(2)：`4·4⁴ = 1024` links；影响矩阵 ~1024×邻域；MC 长跑 + 解析逐对。**~0.5 人月。**

## 4. 预注册死亡判据（先登记，后跑）

### 4.0 读数前置规则（R1–R5；**先读，再判 D1–D4**）

- **R1（对照点）：** `β=6.0` 是 `η→1` 的**弱耦合对照**，**永不触发 D3**。4D 单 link 行和有 ~18–24 个邻居项，弱耦合下 `η≥1` 是这套**粗糙充分条件**的通病，不是架构死亡。
- **R2（冗余点）：** `β=2.2` 是 **BL-6 冗余点**——强耦合 `κ_c=1` 已证；那里 `η<1` 只是**数值重导已证区**，**不算新架构存活**。
- **R3（唯一决定点）：** 唯一决定性格点是 **`β=3.0`**。**D3 只在 `β=3.0` 判**；且必须**分开报** path-coupling 严格界 `λ`（`η≤λ`；判死需要它）与逐对点估计 `η̂`（`η̂≥1` 只击穿充分条件，**不是**证明 `η≥1`）。
- **R4（对照≠判死）：** D4 拿 `1−η` 比 `m_eff`（欧氏质量），但 **MCMC 谱隙 ≠ 欧氏质量**；且 Dobrushin 只给**单侧** `m_eff ≳ c(1−η)`（不要求比例）。故 D4 不成立应读 **"对照无信息"**，**不是** "NA-3 死"。
- **R5（全表）：** 报全表 `η(β,L)`（含误差），不得只报单点。

### 4.0b 路径耦合的可判定性不对称（来源：**格点可判定性**，非数学强度）

- `λ = sup_{相邻构型对} E[d(Tx,Ty)]/d(x,y)`；格点采样给 **`λ̂ ≤ λ`**（采样只取到**已见对**的最大值，取不到真 sup）。
- **`λ̂ ≥ 1` ⟹ `λ ≥ 1`（严格）** ⟹ **D3-DEATH**。但**必须落盘见证对**（`witness_*.npz`：两构型 + 被改 link + 单步耦合**严格值**），CSV 记 `cert`。
- **`λ̂ < 1` ⇏ `λ < 1`**：采样给不出"对**所有**对"的界。**严格 `λ<1` 不可能从格点测出**，只能来自解析机制（= NA-2）。CSV 记 `est`。
- **结论：格点只能严格判死（见证对），不能严格判开。** 这是**可判定性**的限制，**不是数学强度**。
- **旁注（Hamming+最大耦合下）**：单 link 差的两构型，最大耦合使 `E[d]` 接近逐对最小（`≈ TV`），故见证对的 `λ≥1` **不是轻易能换耦合绕过的**；但不同度量/耦合仍可能有别，**不做全称断言**。
- **加权救不了（translation-invariant）**：等权行和 = 影响矩阵（Toeplitz 非负）谱半径；Dobrushin 系数在**最优加权度量**下的最小值 = 谱半径。故 `η̂≈8` **不能靠换度量压到 <1**——这是 Dobrushin **框架**的最优系数，不是权重选坏。
- **证书类型提醒：** `λ` 是收缩**上界**（`η` 与 `λ` 的关系是上界型），故 `λ≥1` **不能**当 `η≥1` 的证书；**D3-DEATH 的证书必须是 Dobrushin 行和的直接下界**（§4.1）。

### 4.1 死亡判据

- **D1（塌回 BL-6）：** 若 `η` 的**唯一严格上界**只能由 cluster expansion 给出 ⟹ NA-3 塌为 BL-6，**关闭**。
- **D1′（预注册的塌陷路径）：** 若在 **`β=3.0`** 处**任何非 cluster 工具**（path coupling / disagreement percolation / Efron–Stein）都**认证不了**严格 `λ<1`，而**唯一**能严格控制 Dobrushin 系数的工具是**完整解析性 / cluster**，则 NA-3 **实际塌成 BL-6**（D1 以另一种形式兑现）。**这不是意外，是预登记的塌陷路径。**
- **D2（收缩退化）：** 若数值 `η<1` 但 `−ln η` 随 `L`（4→6）或随 `β`→crossover **→0**（不 `L,β` 一致）⟹ **关闭**。
- **D3（无收缩；**只在 `β=3.0` 判**）——四种结果：**
  - **D3-DEATH（`cert`）：** `β=3.0` 有**严格见证**使 Dobrushin 系数 `≥1`：固定背景构型 `U`，对邻 link `j` 取 `U^j`（仅 `j` 改），精确算 `Σ_j ‖P_e(·|U)−P_e(·|U^j)‖_TV ≥ 1`（因 `η = sup ≥` 任一点的值，**一个确切构型即够**）⟹ **关闭**；触发 §8。**注意：path-coupling `λ` 是收缩上界，`λ≥1` 不推出 `η≥1`——证书用 Dobrushin 行和下界，不用 λ。**
  - **D3-EVIDENCE（`est` 且 `η̂ ≫ 1`）：** 实质已死、**证书待补** ⟹ 入账"**已死（待证）**"；**暂不触发 §8**。*（当前数据即此档：`η̂(β=3.0)=8.07±0.26`，`η_max=12.93`。）*
  - **D3-NO-EVIDENCE（`est` 且 `η̂<1`）：** ⟹ **不关也不开**；移交 NA-2 求解析机制。**不是存活认证。**
  - **D3-NA（数值墙）：** 跑不出 ⟹ **存疑**。
  - **`β=6.0` 不判；`β=2.2` 不算存活；D4 不判死**（见 R1–R4）。
- **D4（对照无信息，非判死）：** `η<1` 但 `1−η` 与 `m_eff` 无比例 ⟹ **对照无信息**（R4），**不据此判死**。
- **通过（认证）条件：** **严格 `λ<1` 只能来自解析机制（NA-2）**，格点**不能**认证；格点 `λ̂<1` 仅 `est`（D3-NO-EVIDENCE）。格点能给的最多是"估计有利"，**不是存活认证**。

## 5. 与 BL-6 / BBD 的区别（一句话）

- **vs BL-6：** `η` 是**局部**条件分布敏感度，不是缺陷权重和；§2 估计量不用 cluster。
- **vs BBD（NA-1）：** BBD 输入是**全局磁化率**（≈ 隙，循环）；`η` 是**局部**系数，`η<1` 由 Dobrushin 定理**导出**聚类、**不假定**它。**故 NA-3 不被 OB-1 击中。**

## 6. 失败模式与解读

- **最可能：D3**（crossover `η≥1`）——强耦合判据在 `q≈1` 失效，符合先验。
- **次可能：D2**（`−ln η` 随 `L` 塌）——有限体积假收缩。
- **若 D1：** 明确"只能 cluster" ⟹ NA-3 = BL-6，按 peer 判定关闭。
