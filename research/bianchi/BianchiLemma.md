# Bianchi 抵消引理：陈述、判定与反例

> 2026-11-22 · 本文件自编号 **BL-1 … BL-5**（不触碰 `gluing` 的 R 号、`handoff` 的 Prop B 编号、`REPORT §4.4` 编号）。
> 定位：把 `research/handoff-proof/CPBW-bianchi-lemma.md`（一页纸，只有判定）升级为**可证 / 可反证**的精确版。
> 纪律：**先判定后证明；只判定，不声称证明 `CPB-W` 或 `CPB-S`。** 负结果合法且同等有价值。

> **符号表（防复用事故，先读）：** `κ = 1/2` = Kotecký–Preiss 因子（`z(q)` 定义里的那个）；**`κ_c`（或写 `ϰ`）= 带号抵消因子 `<1`**，与 `κ` 是两回事。`γ_ent` = 缺陷团簇熵率（**不写裸 `γ`**，裸 `γ=β/N_c` 专指耦合）。`σ(q)` = 作用量密度；`z(q)` = 带号气体活动度；`c₀,c₁` = B1 的指数常数；`c_F := ⟨F²⟩/g²`。**`κ` 与 `κ_c` 不得混用。**

## 0. 结论（先读）

- **`dF=0` 精确等价于「通量 2-余循环」**（对每个立方体 `∏_{p∈∂c} U_p = 1`，线性化即 `dF=0`）。在**阿贝尔 + 量子化通量**的情形它才推出「缺陷 2-链闭合」（`∂C=0`）。这是**拓扑**陈述，**不是作用量**陈述。
- 它给的是**计数 / 熵**的改进：连通 2-链的计数率 `γ_all → γ_cyc`，一个 **`q` 无关的纯数**。它**不改**每块的 `|w_q(C)|`——作用量密度 `σ(q)` 原样不动。
- 因此**可证的最好形式**是
  ```
  z(q) ≤ 1 / (1 − e^{γ_cyc − σ(q) + κq})      （指数为负时）
  ```
  （BL-1 + BL-4），**不是**形如 `e^{−c₀q|C|−c₁q²|C|}` 的权重改进。在提议的加法形式里，**`c₁=0` 可证**；`c₁>0` 等价于 `σ(q) ≥ c₀q + c₁q²`，即 `(H2)`，而 `dF=0` **不蕴含** `(H2)`（BL-3 反例）。
- **更致命（BL-5）：`q_c≈1` 处任何 `q^α`（`α>1`）恒等于 `q`。** 任何「二次标度」改进在**需要它的那个点**上增益**恰为零**。真正的门槛是 **`q=1` 处的绝对效率 `σ(1)`**，不是标度。
- **两侧判定（仅凭 Bianchi）：**
  - **(b) `C_cum ≤ 1.6`：否。** 且有两重否定：`q^α` 在 `q=1` 是空的；`C_cum` 是**局部**量（由小团簇主导），而 Bianchi 的熵增益是**渐近**（大团簇）量，二者不相交。
  - **(c) `z(1) ≤ 1/2`：否。** 单块项即要求 `c₀ ≥ 0.5 + ln2 ≈ 1.19`；全几何级数要求 `c₀ ≥ 0.5 + γ_ent + ln3`（`γ_ent≈1` 时 `≈2.6`）。Bianchi 不给 `c₀`。
- **唯一存活的机制是「带号抵消」 `κ_c<1`（每块）**：它是**权重符号**性质，**不是 `dF=0` 的推论**。`CPB-W` 需 `κ_c ≲ 0.80`；`CPB-S` 需 `κ_c ≲ 0.20`（粗估）。若 `κ_c≈1`，两侧同时关闭。
- **对 B2 的直接判定（`BL-6`，§8.5）：默认 `κ≈1`，无已知路线。** 强耦合 surface 表象里项非负（SU(2) 精确 `κ=1`）、权重局部因子化 ⟹ 符号不随面积振荡、`dF=0` 不提供可加缺陷荷；4D 非阿贝尔纯 YM 无 `2D O(N)` 式约束/指标相消。**故 B1 在 `q≈1` 中性（定理）、B2 默认 `κ≈1`（判定）⟹ 两个下游常数在现有机制下无已知路线。** 这是负结果，不是对 `CPB-W/S` 为假的证明。

> **一句话判定：Bianchi 机制不足。** 它只把「数团簇」的指数率压了一个 `q` 无关的常数，没有把「单块权重」压下去；而两个下游常数都是**在 `q≈1` 处对单块效率的要求**。若要救它，必须要么证明 `σ(1)` 本身很大、要么测出 `κ_c<1`——两者都不是 `dF=0` 能提供的。

## 1. 记号与设定

- `T⁴_L`，细间距 `a=1`，分块因子 `b=2`；第 `k` 步块尺度 `a_k`，`q := m a_k`（块单位的无量纲质量隙）。
- 有效作用量 `S_k = S_k^G + V_k`（massive Gaussian + 相互作用）。把 `V_k` 写成 signed gas，`w_q(C)` 是块格上连通团簇 `C` 的（带号）权重，`|C|` 是块数。
- **缺陷支撑** `D(C) ⊆ {plaquettes}`：`C` 中偏离真空的 plaquette 集合（一个块内若干 plaquette）。
- **作用量密度** `σ(q) := S_def(C)/|C|`（每块的缺陷代价）。`(H2)` 即 `σ(q) ≥ c₀q²`。
- `z(q) := sup_x Σ_{C∋x} |w_q(C)| e^{κq|C|}`，`κ = 1/2`（标准 Kotecký–Preiss 因子）。
- `C_cum`：三阶**连通** cumulant 的局部密度（`research/handoff-proof/CPBW-cumulant.md` §1）。
- **熵率**：`N(n)` = 面积 `n` 的连通 2-链（每 site）计数，`N(n) ≤ e^{γ_ent n}`；`N_cyc(n)` = 闭链计数，`N_cyc(n) ≤ e^{γ_cyc n}`。
- **命名纪律**（沿用 `handoff-proof/STATUS.md`）：`γ_ent`（熵率，**不写裸 `γ`**，裸 `γ=β/N_c` 专指耦合），`κ=1/2`（KP 因子），`κ_c`（**带号抵消因子**）。三者不同，勿混用。

## 2. BL-1（可证）：Bianchi = 通量闭合，不是缺陷支撑闭合

**命题 BL-1（精确）.** 对任意连接组态 `U ∈ G^{E}`，plaquette 2-余链是**余循环**：
```
∀ c :  ∏_{p ∈ ∂c} U_p^{±1} = 1 ,     线性化（小场）即  dF = 0 .
```
**证明.** 每个 link 在 `∂c` 中恰出现两次、取向相反，故 `U` 与 `U^{-1}` 相消；对任意连接组态恒成立。∎

**推论 BL-1′（熵）.** 缺陷作为**通量**是守恒的（无「单极子」源）。在**阿贝尔 + 量子化通量**情形，整数 2-形式闭合 `(dn)_c = 0`，故可对偶为**闭 2-链**；此时 `N_cyc(n) ≤ e^{γ_cyc n}`，`γ_cyc ≤ γ_all`。

> **诚实标注（必须随 BL-1 引用）：** 「缺陷支撑是闭 2-链」在**非阿贝尔不是定理**。`∏U_p=1` 只说 *通量之和* 相消，不说 *支撑集* 闭合；单个大 plaquette 的支撑并不闭合。所以 `(H1)` 本身在非阿贝尔只是**假设**（阿贝尔量子化时才是结论）。这已经削弱了 `(H1)⇒(H2)`——见 §3。

## 3. BL-3（反例）：闭 2-链可以是 **codim-1 平板** ⟹ `(H1) ⇏ (H2)`

**命题 BL-3.** 设 `S := {在切片 x₄=0 内的全部 plaquette}`（类型 12、13、23，`x₄` 固定为 0）。则 `Σ_{p∈S} p` 是**闭 2-链**（`∂S=0`），支撑在**三维**平板上，`|S| = 3L³`。

**证明.** 取任一棱 `e`。

- 若 `e ∉` 切片（含方向 4，或端点 `x₄≠0`）：`e` 不出现在 `S` 的任何 plaquette 中，系数 `0`。
- 若 `e` 在切片内、方向 1（从 `x→x+e₁`，`x₄=0`）：`S` 中含 `e` 的 plaquette 恰为四块，系数为
  ```
  (12)@x: +1 ,  (13)@x: +1 ,  (12)@(x−e₂): −1 ,  (13)@(x−e₃): −1   ⟹  +1+1−1−1 = 0 .
  ```
  方向 2、3 同理（各为 `+1+1−1−1`）。故 `∂(Σ_{p∈S} p) = 0`。∎

**BL-3 的力（针对 `(H1)⇒(H2)`）.** `S` 是闭的、`dF=0` 兼容的，但支撑是 **3 维**（codim 1），不是薄膜（codim 2）。因此「缺陷是闭 2-曲面」**不**蕴含「缺陷是张面（membrane）、张力维数 2」。

**物理可达性（补充）.** 取 `σ₀ ∈ Z(G)`（`σ₀ = e^{2πi/N}`），令 `U_l = σ₀` 对所有**切片内空间方向**的 link、其余 `U_l = 1`。这是**合法连接组态**（Bianchi 自动满足）。切片内 plaquette 值为 `σ₀⁴`（如 `N=3`: `σ₀⁴=σ₀≠1`），逐 plaquette 代价 `β(1−Re σ₀) = O(1/g²)`，**与 `q` 无关**。故存在合法组态，其缺陷支撑是**闭 2-链、codim-1、且逐块代价不随 `q` 增长**——`dF=0` 对「张力必须是 `q²`」**没有任何保护**。

> **结论 BL-3.** `(H2)`（`σ(q) ≥ c₀q²`）是**严格动力学**输入，**不能**从 `dF=0` 推出。命题 B 的假设集 `{H1,H2,H3}` 不能约化为 `{H1,H3}`。

## 4. BL-4（可证）：改进只在熵，不在作用量密度——`c₁ = 0`

**命题 BL-4.** 设 `|w_q(C)| ≤ e^{−σ(q)|C|}`（每块代价，对闭链与非闭链**同一**界）。则
```
z(q) ≤ Σ_{n≥1} N_cyc(n) e^{(−σ(q)+κq)n} ≤ 1 / (1 − e^{γ_cyc − σ(q) + κq})     （指数为负时）.
```
`dF=0` 把 `N → N_cyc`（`γ_all → γ_cyc`），**不改** `|w_q(C)|`。

**推论.** 在提议的加法形式 `|w_q(C)| ≤ e^{−c₀q|C| − c₁q²|C|}` 中：

- **`c₁ = 0` 可证**：`dF=0` 是**计数**约束，作用在团簇的**个数**上，不作用在**单个权重**上。任何 `c₁>0` 等价于 `σ(q) ≥ c₀q + c₁q²`，这是**作用量密度**陈述 `(H2)`，被 BL-3 断掉。
- 「熵」修正 `γ_all → γ_cyc` 进入的是 `z` 的**指数率常数**，要它起作用必须 `γ_all − γ_cyc ≳ ln2`（把 `z` 压一半）。这是一个**纯组合常数**，`q` 无关，可由计数算出/测出，但**不是每块权重改进**，且无法由「更多 Bianchi」改善。

> **对齐一页纸：** `CPBW-bianchi-lemma.md` 的 B1（加法 `q²` 形式）与 B2（带号 `κ_c`）判定不变；本文件的增量是把「`q²` 中性」从一个数值观察**升级为定理（BL-5）+ 反例（BL-3）+ 熵/能量分离（BL-4）**，并指出 `c₁` 的正确身份是「`(H2)` 的动力学系数」，不是「Bianchi 白送的」。

## 5. BL-5（算术）：`q≈1` 处二次标度是空的

- **恒等式.** `q^α`（`α>1`）在 `q=1` 处 `= 1 = q`。写作 `e^{−c₀q²} = e^{−c₀q}·e^{−c₀(q²−q)}`，而 `q²−q|_{q=1}=0`。**在交叉点，二次标度改进恰为零。**
- 因此 `(b)`、`(c)` 都退化为**对绝对值 `σ(1)` 的要求**，与标度无关：

**(b) `C_cum`: 2 → 1.6** 需每块因子 `≤ 0.8`，即 `δ ≥ ln(1.25) = 0.223`。**没有任何 `q^α` 能提供它**（`q=1` 空）；只能来自 `σ(1)` 增大或 `κ_c ≤ 0.80`。而 `C_cum` 是**局部**量（`sup_x Σ_{y,z}|κ₃|`，由近邻小团簇主导），BL-1′ 的熵增益是**渐近（大团簇）**量——**结构上不相交**。

**(c) `z(1) ≤ 1/2`:**

- **单块项：** `z(1) ≥ |w_1({x})| e^{κ}` 恒真；**按 `c₀`-界的尺度**取 `|w_1|=e^{−c₀}`，则单块项 `= e^{−(c₀−0.5)}`（`q²` 形式在 `q=1` 同值）。这是**界尺度**的估计，不是真 `z` 的严格下界；它说明要 `z≤1/2` 至少需界本身在此尺度有效，即：
  ```
  c₀ ≥ 0.5 + ln2 ≈ 1.19 .
  ```
- **全几何级数：** `z(1) ≤ 1/(e^{c₀−0.5−γ_ent}−1)`，要 `≤1/2`：
  ```
  c₀ ≥ 0.5 + γ_ent + ln3 .
  ```
  数表（`κ=0.5`）：
  | `γ_ent` | 需要的 `c₀`（无带号抵消） |
  |---:|---:|
  | 1.0 | 2.60 |
  | 1.5 | 3.10 |
  | 2.0 | 3.60 |

  若用带号抵消把有效熵率降到 `γ_ent − δ`（`δ = ln(1/κ_c)`），则以 `c₀=1, γ_ent=1` 为例需 `δ ≥ ln3 + κ + γ_ent − c₀ = 1.60`，即 **`κ_c ≲ 0.20`**。

> **结论 BL-5.** 两个下游常数是 **`q=1` 处的值判据**，不是标度判据。`dF=0` 既不给 `σ(1)`、也不给 `κ_c`；它只给 `γ`。故仅凭 Bianchi，**(b) 否、(c) 否**。

## 7. 哪一步把改进吃掉（(d)）

若走 `q²` 路线，改进在 **`(H1) closed 2-surface ⇒ (H2) σ ≥ c₀q²`** 这一步被吃掉，原因是三层（任一都致命）：

1. **`(H1)⇏codim 2`**（BL-3）：`x₄=0` 切片是闭 2-链但 codim-1，且逐块代价与 `q` 无关。
2. **熵 ≠ 能量**（BL-4）：`dF=0` 作用在团簇**计数率** `γ` 上，不作用在**单块权重** `|w_q|` 上；加法形式里 `c₁=0`。
3. **`q≈1` 空**（BL-5）：即便 `(H2)` 成立，`q²=q`，增益为零。

若退守「Bianchi 只给熵」，改进在 **「熵率差 `γ_all−γ_cyc` 是 `q` 无关常数、且通常 `< ln2`」** 这一步被吃掉——`C_cum` 根本不吃这个（局部量），`z(1)` 需要它 `≥ln2` 而它给不到。

## 8. 唯一存活机制：带号抵消 `κ_c`（**不是** `dF=0` 的推论）

**候选 B2（一页纸原式，此处重述）.** 对固定边界 `∂C₀ = ∂C`，
```
| Σ_{C: ∂C=∂C₀} w_q(C) | ≤ e^{−c₀q|C₀|} · κ_c^{|C₀|} ,   κ_c < 1 .
```
等价地，每块多一个 `−ln(1/κ_c)` 的抑制。它给两侧的是（§5 的数表）：
```
CPB-W:  κ_c ≤ 0.80          （C_cum: 2→1.6）
CPB-S:  κ_c ≲ 0.20          （z(1)≤1/2, c₀=1, γ_ent=1 的粗估）
```

**为什么 `dF=0` 不给 `κ_c<1`：**

- `dF=0` 是**每个组态**都满足的恒等式，里面没有「符号/可积性」信息——它约束通量守恒，不约束权重符号。
- **U(1) 反证**：U(1) 自由理论 `F=dA` 使 `dF=0` **自动成立**，却**没有**非平凡带号相消（`CPBW-one-step.md` §0 已立此范围声明）。所以 `dF=0` 与 `κ_c<1` 逻辑独立。
- **2D O(N) 先例的 `κ_c` 不来自闭链**：它来自**精确约束 / 拓扑指标**给出的符号结构（signed gas 的可求和性），是**约束方程**级别的机制，不是 `dF=0`。4D YM 要 `κ_c<1` 需一个**类比的可积 / 指标结构**，`dF=0` 本身不提供。

> **判定.** `κ_c` 是**独立、未测、未能由现有结构导出**的量。若要「存活」，必须**直接测**（§9 T1）或**独立证**（从 cumulant 展开的系数符号 + 群迹结构）。

## 8.5 BL-6（对 B2 的判定）：默认 `κ_c≈1`，无已知路线

> peer 已把任务形状锐化为**判定 B2**（B1 在 `q≈1` 中性已由本文件 BL-5 证成定理）。本节判定 B2 本身。

**B2（重述）.** 对固定边界 `∂C₀`，
```
| Σ_{C: ∂C=∂C₀} w_q(C) | ≤ e^{−c₀q|C₀|} · κ_c^{|C₀|} ,   κ_c < 1 .
```
`κ_c` 是**每块（每单位边界面积）的带号抵消因子**。注意它是**权重**因子（不是计数因子），因此**对 `C_cum` 这种局部量也直接有效**——这一点与 §4/BL-4 的「Bianchi 只给熵、与局部 `C_cum` 不相交」不同：**B2 是唯一能碰到 `C_cum` 的对象，这也是 peer 把任务移到这里的原因。**

**BL-6（判定，非定理）.** 在项目现有工具与 4D 非阿贝尔纯 YM 的标准构造中，**没有已知机制给出 `κ_c<1`；默认 `κ_c≈1`。** 三条方向一致的证据：

1. **强耦合 surface/character 表象里 `κ_c=1` 是精确的（可证，带度规 caveat）。** 固定边界的曲面和 `Σ_{∂C=∂C₀} w(C)` 的各项由 character 系数 `c_r(β)` 的乘积构成；SU(2) 的 `c_r(β)=2I_{2r+1}(β)/β>0` 对**所有** `r`、`β>0`，故**所有项非负**，`z_signed=z_abs`，`κ_c=1` 逐块精确（SU(N>2) 的低表示扇区亦为正；高表示可交替，故这是"默认扇区无抵消"的严格证据，不是 `κ_c=1` 的全称证明）。**`κ_c<1` 若要出现，只能是弱耦合/交叉点的现象——而那正是没有来源的地方。**

2. **权重局部因子化 ⟹ 符号不随面积反相。** `w_q(C)` 是局部 activity 相乘再乘 cumulant 符号；相邻曲面 `C,C'` 只差局部移动，权重比是**局部**因子、符号不翻转。要 `κ_c<1` 需 `w(C)` 的符号**随面积反相**（`e^{iπ·拓扑荷}` 型），这要求一个**可加、因子化到每块**的缺陷荷。

3. **`dF=0` 不提供这个荷。** `2D O(N)` 的相消来自**精确约束 + 拓扑指标**（`(−1)^{instanton}` 因子化）；`4D U(1)` 来自**对偶 / Poisson**（单极子流）。**4D 非阿贝尔纯 YM 既无精确约束、也无可加缺陷荷**：瞬子荷密度存在，但 Gaussian polymer 的「缺陷」不是瞬子；纯 YM 的 `θ` 只在 `θ≠0` 给相位（且那是相位的整体平移，不是逐块反相）。故 §8 的「`dF=0` 无符号信息」在此加强为：**没有候选的荷产生逐块相消。**

**两侧分开核（中间区 `κ_c∈(0.2,0.8)`）.** `κ_c` 是每块权重因子，对两侧同一 `w` 生效，但需求不同：

| `κ_c` | `CPB-W`（需 `≤0.80`） | `CPB-S`（需 `≲0.20`，粗估） |
|---|---|---|
| `≈1` | **否** | **否** |
| `0.5` | 过（边缘） | 否 |
| `0.2` | 过 | 边缘 |
| `<0.15` | 过 | 过 |

**直接回答 peer 的「结论先行」：是——B2 也只能预期 `κ_c≈1`。** B1 在 `q≈1` 中性（BL-5，定理），B2 默认 `κ_c≈1`（BL-6，判定）⟹ **`CPB-W` 与 `CPB-S` 的类保持，在现有机制下无已知路线**（`CPB` 架构的两道墙同时关闭）。这是**负结果**，不是对质量隙或 `CPB-W/S` 为假的证明——被否定的是"用 Bianchi / 符号抵消这条机制能证明它们"。**唯一能翻盘的**：`lattice-cpb` 在 `q≈1` 测出 `κ_c<1`，或出现一个新的、可加的符号/指标结构；两者都还不在手。
