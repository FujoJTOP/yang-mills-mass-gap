## 2. NA-1：Euclidean Glauber 动力学的 uniform LSI（输运 / 熵曲率）——**已关闭（不独立，见 §2.5）**

### (0) 先答"算的是哪一个隙"（决定 NA-1 是架构还是对象错配）

- **`Γ_H` 的定义域** = 时间片上**规范不变**可观测（等价地，`𝒜` 上沿规范轨道方向为零的函数的二次型，即"水平"方向）。
- **Markov 过程** = 以**物理 Euclidean YM 测度**为平稳测度的 **heat-bath / Glauber 动力学**（**不是** stochastic quantization 的 Langevin）。
- **时间方向** = 虚构（模拟）时间；**但结论不是该虚构时间过程的隙**，而由 **Zegarlinski 型定理** 连接：Euclidean Gibbs 测度的**一致 LSI ⟹ Euclidean 关联各方向指数衰减 ⟹ 转移矩阵谱隙 = 质量隙**。虚构时间的 LSI 是**工具**，Euclidean 时间的隙是**结论**，二者由**定理**连接，**不是同一对象**。
- **对象错配（必须避免）**：若 `Γ` 取自 **stochastic quantization 的 Langevin 算子**（在 `𝒜/𝒢` 上加一个时间维），其谱隙是 **SQ 隙、不是物理质量隙**。**NA-1 不用那个。**

> **一句话（peer 要的那句）：** NA-1 = "Euclidean Gibbs 测度的 **Glauber** carré du champ 的一致 LSI + Zegarlinski 转换"。若写成"`𝒜/𝒢` 上 Langevin 的 Poincaré 常数 = 质量隙"，就是**对象错配**。**这一句决定它是架构还是错配。**

> **附带解掉非紧性：** 读成**有限格点**上的 Glauber（构型空间 `G^{links}` 紧），就**没有**非紧方向问题；难点变成 **`L,a` 一致**——与 NA-2（连续 `𝒜/𝒢`）的**非紧性**不同。这也解释了为何 NA-2 暂缓而 NA-1 仍可做。

### (1) 核心结构（修正后）

新对象 = Euclidean **Glauber** 的水平 carré du champ `Γ_H(f)=|D_H f|²` 及其 **Erbar–Maas 离散 Ricci 曲率**。要证：**在 `q≈1` 物理窗口，uniform（`L,a` 一致）LSI 成立**；由 Zegarlinski 得隙。

> **与 `κ_eff` 陷阱的区别：** `κ_eff` 是微观坐标 Hessian（Savvidy 负模，弱耦合也负）；NA-1 用 `Γ_H`（水平）+ 熵曲率，另一对象。但**别反推成会成功**（见 (2)(4)）。

### (2) 为何绕开 `q≈1` / 为何不是 BL-6

**不是 BL-6 重述，因为**：要证的是**测度的一条全局 LSI**（一个不等式），不是缺陷权重和；Zegarlinski 的转换是**定理**，不出现 `κ_c`。
**为何可能绕开 `q≈1`**：LSI 是测度的**整体**性质，不必来自小参数。

> **诚实重估（必须读，推翻 v1 的过度乐观）：** 格点模型的一致 LSI **通常**只有两条来路——(a) **cluster 展开**（⟹ BL-6）；(b) **Bakry–Émery**（⟹ YM 因 `−[F,F]` 负曲率失败）。**所以 NA-1 的价值不在"LSI 框架"，而在能否找到第三条证 LSI 的路；找不到，就塌回 BL-6 或塌回已失败的 BE。这是 NA-1 的真实赔率：押一条尚不存在的 LSI 证明技术。**

### (3) 需要的新数学（**第三条** LSI 路线）

- **弱输运-熵不等式（Marton / Gozlan–Roberto–Samson 型）⟹ LSI**：**不经过全局 `CD(K,∞)`**，可能绕开 `−[F,F]` 的负曲率符号问题（transport-cost 与曲率是不同条件）。

### (4) 第一检验（数月）+ 最可能失败

- **检验 `NA-1-T`（修正版）：** 不直接测"Poincaré 常数"（可能含虚构时间量），而测 **Glauber 链的中间量**：小格（Z₂ 精确 / SU(2) 截断）上估 **Glauber 谱隙（自关联时间）/ LSI 常数**（用**耦合 / 影响**估，**不用 cluster**），并对照**时间方向聚类率**（直接测）。判据：(i) Glauber 谱隙是否 `O(1)`（格点单位）穿过 crossover、不塌缩；(ii) 时间方向聚类是否按 `m` 标度、`L,a` 一致。

## 2.5 文献判定：BBD / GOV 是不是"第三条技术" → **否；NA-1 不独立，关闭**

> 纯文献判定（2026-11-23）。结论：**NA-1 是 CPB-W 的 LSI 语言版本，或需要循环输入；不独立，关闭。**

**(A) Bauerschmidt–Bodineau–Dagallier / Bauerschmidt–Dagallier（Polchinski 流 LSI）**
- 主体：Bauerschmidt–Dagallier, *Log-Sobolev inequality for the φ⁴₂ and φ⁴₃ measures*, **CPAM 77 (2024)**, arXiv:2202.02295；一般判据（Polchinski 流上的**多尺度 Bakry–Émery**）见 BBD, *Stochastic dynamics and the Polchinski equation: An Introduction*, **Probab. Surveys 21 (2024)**, arXiv:2307.07619。
- **用超可重整性吗？用（在应用里）。** φ⁴₂（d=2 log）、φ⁴₃（d=3 `ε⁻¹`）是超可重整；流/counterterm 的一致控制靠它。**一般判据**本身不显式写 d<4，但**验证**一个模型要靠流的控制；d=4 是 marginal，无此捷径。
- **是"流收缩 + 逐尺度 LSI"吗？是。** 结构 = 每尺度以 Gaussian 为参考 + **有效耦合**作小参数——**正是 CPB-W 的结构**。差别只在**输出**：CPB-W 要 `C²` 类保持（更强、含导数控制），BBD 要 LSI（更弱、纯标量不等式）。
- **4D 规范的 Polchinski-LSI 结果？没有。** 已知严格工作只到 lattice YM 随机分析 / 2D YM 测度；4D 连续规范 LSI 非已确立。检索到的若干 Zenodo "证明"是**自出版、非同行评议，不作证据**。
- **额外输入 = 循环。** BBD 的 LSI **以"有界磁化率"为前提**（φ⁴_{2,3} 用 skeleton/Ising 不等式在其**高温相**证）。对 4D 规范 `χ = Σ_x⟨F(0)F(x)⟩ ~ 1/m²`——**有界磁化率 ≈（弱形式的）隙**。故"照搬 BBD" = **假定近于隙本身** → 循环。

**(B) Grunewald–Otto–Villani（双尺度）**
- *A two-scale approach to LSI and the hydrodynamic limit*, AIHP **45 (2009)** 302–351。结构 = **粗粒化（block spins）+ 条件（微观）LSI + 宏观 LSI**；宏观 LSI 靠**粗粒化 Hamilton 的严格凸性**（GL/Kawasaki 成立）。
- 对规范：条件 LSI **就是分块一步**（CPB-W 的 blocking）；宏观 LSI 需粗粒化 Hamilton **凸**，而规范因 `−[F,F]` **非凸**。→ 同一 blocking 架构，**卡在凸性**（与 Bakry–Émery 同死法）。

**判定.** 两个候选都塌回**多尺度 RG / blocking**（= CPB-W 的架构）：BBD 的额外输入（有界磁化率）**循环**，GOV 的额外输入（粗粒化凸性）**失败**。**故 NA-1 不独立于 CPB-W，关闭。** 保留价值：BBD 的"Polchinski 流上多尺度 BE"是一个**干净的 LSI 判据**——若哪天真证出 4D 规范交叉点的 LSI，它**就是 CPB-W 那组估计的 LSI 推论**；**两者是同一件事的两种语言**（正是 peer 的猜测）。

## 2.6 OB-1（**一般性障碍**，比 BBD 的局限更广）

> 把 §2.5 的第三条理由抽出为**一般性障碍**，不只针对 BBD。

**OB-1（熵方法的循环障碍）.** 若一个方法证明 LSI / Poincaré / 聚类（或任何"无零质量"结论）的**前提**是
```
χ := Σ_x ⟨O(0)O(x)⟩_c < ∞      （磁化率 / 关联和可积）
```
（`O` 为任一局域算符，如 `F`），则对 4D 规范该前提**本身就是目标**：`χ ~ 1/m²`，`χ<∞ ⟺` 关联可和 `⟺` 无零质量态（弱形式的隙）。故该方法要么 (i) **独立证明** `χ<∞`（≈ 目标，循环），要么 (ii) 只是把目标改写成 `χ<∞`。

- **命中谁：** BBD（Polchinski-LSI 以**有界磁化率**为输入）；任何"熵/输运 + 全局关联可和"的方法。
- **不命中谁：** 若输入是**局部**系数（有限程条件分布敏感度 `η`，见 NA-3），`η<1` 由**定理导出**聚类、**不假定**它——**不循环**。
- **结论：** 这不是"BBD 的局限"，是**该类方法的通病**；NA-3 之所以存活，正因它是**局部**系数。

## 4. NA-3：非微扰信道收缩（信息几何 / 强数据处理）

### (1) 核心结构

把**分块（blocking）或 heat-bath 核**看成一个 **Markov 信道** `T`（`𝒜 → 𝒜_粗`）。质量隙 = **`T` 在某个 divergence 上的指数收缩率**：总变差 `‖Tμ−Tν‖_TV ≤ η·‖μ−ν‖_TV`（`η<1`，Dobrushin 系数 / strong data processing），或 `χ²`/`KL` 版本。新对象 = **条件分布对边界的敏感度（coupling / influence）**与**收缩系数 `η`**。

### (2) 为何绕开 `q≈1` / 为何不是 BL-6

**不是 BL-6 重述，因为**：Dobrushin/`η` 是**条件分布之间的耦合/输运**量，**不是**缺陷权重和；它不给"每个团簇多重"，而给"**块的分布对远处的总敏感度**"。
**为何可能绕开 `q≈1`**：`η` 是**一个数**（可 <1，可 ≥1），问题是"crossover 处是否有**非微扰**收缩"，与 Balaban 的**微扰** RG（A1）和 cluster 的**活动度**（A3/BL-6）是**不同的量**。

> **与 20 条的边界：** A1/A4 是**耦合空间**里的微扰 RG；B3 是反射正性 + IR 界；cluster 是活动度。Dobrushin/强数据处理是**测度空间**里的**非微扰收缩**。
> **诚实警告：** Dobrushin 判据在**许多模型上与 cluster 展开等价**（同样的收敛半径）。这是**三条里最可能"塌回同一堵墙"的**——但它的**第一检验极便宜且决定性**，所以值得先做。

### (3) 需要的新数学

- **强数据处理不等式（SDPI）系数** 与 **Dobrushin–Shlosman 完全解析性**：目标——"crossover 的 blocking 信道 `η<1`，且 `−ln η` 一致地正"。
- **非微扰 coupling / influence 界**（Weitz 型 / 社团影响）在**规范约束**下的适配。
- **`χ²`/KL 收缩 ⟹ 指数聚类**的定量桥（若 `η<1` 给隙）。

### (4) 第一检验（数月）+ 最可能失败

> **估计量（peer 要求，必须显式）：** `η` 的估计**不得**用 cluster 展开（那是 BL-6 变体）。用 **(a) 显式耦合**（两边界条件下的条件分布做 coupling、TV 上界；path coupling / CFTP）或 **(b) martingale / 影响**（Efron–Stein、离散导数）。**若唯一可得的严格界是 cluster 界，则 NA-3 塌为 BL-6**（按 peer 判定）；经验耦合测量只作**决策输入**，不是证明。

- **最可能失败：** crossover 处 `η≥1`（无收缩），或 `η<1` 但 `−ln η→0`（收缩消失、界空洞）；或**只能由 cluster 给出**（塌 BL-6）。**快速死亡（最便宜）：** `η≈1` 在物理窗口，架构死——$0.5$ 人月可判。

> **可执行规格：** 见 `research/bianchi/NA-3-T-spec.md`（估计量=逐对影响/path-coupling/Efron–Stein、**禁 cluster**；最小实验 L=4–6 SU(2)/SU(3)；预注册死亡判据 D1–D4）。

## 7. 诚实边界

- 三个都是**架构（framework）**，不是路线；**不声称**能证质量隙，也不声称比 A1（8–12%）更可能。
- 每个的"绕开 `q≈1`"= **换了一个失败签名**，不是免费午餐：共同的 `L,a`-一致硬点仍在（§5）。
- **"算哪个隙"是本 v2 的核心修正：** NA-1 必须是 **Euclidean Glauber + Zegarlinski**（虚构时间 LSI 作工具→Euclidean 隙作结论，由定理连接），**不是** SQ Langevin 的虚构时间隙。**若读错，NA-1 是对象错配，不是架构。**
- **NA-1 的真实赔率已下调：** 它的价值押在**一条尚不存在的第三条 LSI 证明技术**（弱输运-熵 / 熵局部化）；若只能用 cluster 或 BE，则塌回 BL-6 或已失败的 BE。
- **负结果同等有价值**：`NA-1-T` 若谱隙塌缩、`NA-3-T` 若 `η≈1` 或只能 cluster，则明确告诉项目"输运/信息几何不适用于此机制"；NA-2 死于循环则明确"上同调路线需先有强制性"。
- **不碰** `gluing` R 号、`bianchi` BL 号、`handoff` Prop B、`new-paths` NP 号。
- **待核**：NA-2 的"非紧水平方向本质谱"是否真触 0（它生死的关键）；NA-3 的 Dobrushin 在规范约束下的正确 coupling。
- **NA-1 已关闭（§2.5）：** BBD（Polchinski 流 LSI）与 GOV（双尺度）都**不是第三条技术**——前者是 **CPB-W 的 LSI 语言**且额外要"有界磁化率 ≈ 隙"（循环），后者卡在**粗粒化凸性**（规范非凸）。**NA-1 不独立于 CPB-W。** 这是 v3 的结论。
- **NA-3 实质已死（待证，§4）**：`η̂(β=3.0)=8.07±0.26 ≫ 1`（`η_max=12.93`），充分条件差 8 倍；等权行和=影响矩阵谱半径（translation-invariant），**加权度量救不了**。死法 = **判据太钝**（`τ_P≈0.5` 快混合），**不是塌回 RG**。严格见证（`cert`）待 `lattice-cpb` ~1 天；**证书到前不触发 §8**。
- **OB-1（§2.6）：** "熵/输运 + 全局关联可和（磁化率）"作为输入的方法在 4D 规范**普遍循环**；这是 NA-1 关闭的**一般性**理由，不是 BBD 个案。NA-3 因用**局部**系数 `η` 而不被击中。

## 8. 若三个架构全关：一个结构性结论（**预写**，触发前不发布）

> **触发条件（2026-11-23 更新）：** NA-1 已关（§2.5）、NA-2 无独立路线；**且** `NA-3-T` 取 **D3-DEATH**（`β=3.0` 严格见证使系数 `≥1`，`cert`；见 `NA-3-T-spec.md` §4.1）。**不触发：D3-EVIDENCE（`est` 且 `η̂≫1`，当前状态——实质已死但证书待补）、D3-NO-EVIDENCE、D3-NA、`η̂≥1` 点估计、`β=6.0`、`β=2.2`、D4。** 须是证书事实，不得推测。满足后写：

> **结论措辞（两分，不得混为一谈）：**
> 已知架构**要么塌进同一堵墙**——cluster / Bakry–Émery / 熵·输运（NA-1/BBD 经 OB-1 循环）/ 指标——**都归约为多尺度 RG 与活动度控制**（失败签名：activity / 凸性 / 循环 / 非紧谱）；**要么因缺乏足够锐的仪器而失败**——NA-3 的 Dobrushin 充分条件在物理耦合处 `η≈8–13 ≫ 1`，而链混合极快（`τ_P≈0.5`），故**不是塌进 RG，而是充分条件太钝**。
>
> **一句话：** 现有数学证明技术对质量隙，**或归约为同一多尺度 RG 墙，或卡在不够锐的判据**；**没有一条给出既非 RG、又足够锐的第三条路。**

**必须随结论一起写的边界：**
- 这是"**已知分析法**"的结论，**不是**"质量隙不可证"或"质量隙为假"。
- 它**不否定** `CPB-W/S` 为真，只说明现有数学的**证明技术同源**。
- 触发**必须有证书事实**（`β=3.0` 严格见证，D3-DEATH）；`est`（D3-EVIDENCE）**不触发**，不是先验断言。
- **NA-3 的死法对质量隙本身无信息**（`τ_P≈0.5` 快混合）：它是"判据太钝"，**不得**读成"YM 难"或"隙小"。
- 即使触发，这也是"**已知方法不认证间隙**"的结论，**不是**"`η≥1` 已证"——`λ≥1` 是主工具**未认证收缩**，不是证明了无收缩。
