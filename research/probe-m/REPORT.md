## 0. 结论（≤300 字）

1. **换算数值正确，推理要补一句。** 2 圈 `λ=6`：`t_up=2.639`，`q₀^m=8e^{−2.639}=0.5712`，`1/q₀=1.751`；`q₀^σ=2e^{−2.639}=0.1428`，`1/q₀=7.00`。`ξ/a ≳ 1/q` 的**正确理由**是：格点谱必须覆盖交接窗口的高端 `μ_S=m/q₁`（UV 地板），再加上"胶球至少要被 2–3 个时间片解析"，即 `am≲0.6 ⟺ ξ/a≳1.7`。两条理由给出同一个数。
2. **`m` 门槛可达。** 需要 `ξ/a≈1.75`，即 `β≈6.22`（`β=6.2` 给 `ξ/a=1.70`，`β=6.4` 给 `2.23`）；IR 只需 `L≥4ξ/a≈7`，`L=12–16` 绰绰有余。成本 `10²–10³ h`（纯 NumPy），与任务给出的预算一致。
3. **`σ` 在现工具下不可达，且不是 Clay 所需。** 门槛 `ξ_σ/a≈7`，`L≈28–32`；等精度成本约为 `m` 战役的 **4×10² 倍**（不是 10–50 倍——那个数只算了体积，漏了 `δm/m∝ξ/√N` 的统计标度）。
4. **判定：可以 drop `σ`。** 但**只省数值成本**：去掉的是 `CPB-S^σ` 与 σ 数值战役，**不解决 `W1_1`**（弦扇区边界屏蔽仍是带电扇区的独立解析输入，弱于 `σ>0`），也不改变解析瓶颈 `CPB-W`。非平凡性走 UV 侧 `g_ren≠0`，与 `σ` 无关。

## 1. 重推：`q`、`m`、`ξ`、`a` 的关系

### 1.1 起点（`handoff-proof` §1.5，逐字）

两个 certificate 同构：

```
φ = m/μ :   M_m = ln(m/Λ) − 24π²/(11λ*) − ln q₁^{(m)} ≥ 0
φ = √σ/μ:   M_σ = ln(√σ/Λ) − 24π²/(11λ*) − ln q₁^{(σ)} ≥ 0
```

其中 `q(μ)=m/μ`（物理 `m`，精确单调递减），`λ*=h^∨g*²`，RB2 给
`t_up^{2L}(λ)=24π²/(11λ) − (51/121)ln(1+121·24π²/(51·11λ))`。在 `λ=6`：

| 量 | 数值 |
|---|---:|
| `t_up^{2L}(6)` | `2.6394` |
| `q₀^m=(m/Λ)e^{−t_up}`，`m/Λ=8` | `0.5712` |
| `q₀^σ=(√σ/Λ)e^{−t_up}`，`√σ/Λ=2` | `0.1428` |

（`m/√σ≈3.5–4` ⟹ `√σ/Λ≈2` 与 `m/Λ≈8` 自洽；`q₀^σ/q₀^m=√σ/m≈1/4`。）

### 1.2 两个不能混的门槛

本报告区分两件事，SURVEY §3.3 把它们压在一行里：

| | 内容 | 谁能给 |
|---|---|---|
| **物理门槛** | `H3[m]`：`m/Λ ≥ q₁ e^{t_up}`，即 `M_m≥0` | 证明（`CPB-W` + `CPB-S^m`）；`m/Λ=8` 是文献输入 |
| **数值门槛** | 格点能否支撑对上面的**一致性检验**：`ξ/a ≳ 1/q₁` | 格点（本文核的是这个） |

数值门槛过了，**不等于**物理门槛被证；它只说明"用格点给 `m/Λ` 和 `ξ/a` 做 O(10%) 的旁证是可行的"。证书仍是 `H3[m]`。

### 1.3 一条先要拆掉的误读

`ξ/a = 1/q` **不是恒等式**。它只在 `q` 取在**格点截断尺度**上时成立：

```
q(μ)|_{μ=1/a} = a·m = 1/(ξ/a)      （因为 ξ = 1/m）
```

而 `q₁` 是**阈值**不是尺度。把它当成"要求的关联长度"会丢掉方向。正确的链条是下面这个"窗口覆盖"论证。

### 1.4 窗口覆盖（UV 地板 + IR 地板）

记 `q(μ)=m/μ`。则

- 强侧：`q≥q₁ ⟺ μ≤m/q₁ =: μ_S`；
- 弱侧：`μ≥μ_up =: m/q₀`；
- 交接窗口 `= [μ_up, μ_S]`，非空 `⟺ q₀≥q₁`（就是 `H3`）。

格点在环面上能表示的动量是 `2π/(La) ≤ |p| ≤ π/a`。窗口要落在格点谱范围内，必要条件是

```
(U)  π/a ≥ μ_S = m/q₁   ⟺   ξ/a ≥ 1/(π q₁)          [保守版：截断取 1/a ⟹ ξ/a ≥ 1/q₁]
(I)  2π/(La) ≤ μ_up = m/q₀  ⟺   L ≥ 2π q₀ (ξ/a)
```

代入 `q₁=q₀`（阈值点）：

| certificate | `q₁` | `(U)`，`π/a` | `(U)`，保守 `1/a` | `(I)` |
|---|---:|---:|---:|---:|
| `m` | 0.5712 | `ξ/a ≥ 0.56` | `ξ/a ≥ 1.75` | `L ≥ 6.3` |
| `σ` | 0.1428 | `ξ_σ/a ≥ 2.23` | `ξ_σ/a ≥ 7.00` | `L ≥ 6.3` |

最紧凑的写法：用恒等式 `q(1/a)=am=1/(ξ/a)`，`(U)` 就是说

```
格点截断本身必须落在弱域： q(1/a) ≤ q₁  ⟺  am ≤ q₁  ⟺  ξ/a ≥ 1/q₁ .
```

即整个强域 `q≥q₁` 都要在截断之下。`(U)` 与 `(I)` 一起把窗口 `[μ_up,μ_S]` 放进格点谱范围。

**关键简化：UV 地板与 certificate 无关。** 因为 `q₁/X = (X/Λ)e^{−t_up}/X = e^{−t_up}/Λ`（`X=m` 或 `√σ`），所以两者要求**同一个格距**、同一个 `β`。差别全在 IR：`ξ_σ/ξ_m = m/√σ≈4`，于是同一 `β` 下 `ξ_σ/a` 是 `ξ_m/a` 的 4 倍，`L` 也是 4 倍。**σ 不是因为需要更细的格子才贵，而是因为 `√σ<m` 使同一点阵上的关联长度大 4 倍，进而 `L` 大 4 倍、统计量按 `ξ²` 大 16 倍。**

### 1.5 真正咬合的那条：解析度（与约定无关）

`(U)` 的两种取法差因子 `π`，而 `β=6` 的实测 `ξ/a≈1` 已在 `0.56` 之上、在 `1.75` 之下——单靠 `(U)` 判不了。**独立且更硬的条件**是胶球必须能被 cosh 拟合解析：

```
am(0++) ≲ 0.5–0.6   ⟺   ξ/a = 1/(am) ≳ 1.7–2.0
```

`β=6` 实测 `am≈1`（`ξ/a=0.93(8)`），只有约一个可用时间片，这正是 `lattice-cpb` §4.3 报"operator 系统误差 ±0.3"的原因。`β≈6.3` 使 `am≈0.57`，`t=1,2,3` 落在平台上。

**为什么两条判据给出同一个数**：`(U)` 要求 `am ≤ q₁=0.571`，解析度要求 `am ≲ 0.6`——因为 `q₁^m≈0.57≈0.6`。所以 `ξ/a≳1.75` 对约定（`π/a` 还是 `1/a`）和 operator 细节都稳健；SURVEY 的 `1.75` 数值对、方向对，需要补的是"截断在弱域 + `am≲0.6`"这两句话，而不是"`ξ/a=1/q₁`"这个假恒等式。

> 三个需要顺手改的表述（都不改数值）：
> 1. `q₁^m=0.571` 实为 **`q₀`**（`λ=6, m/Λ=8` 处的弱侧值），是 `q₁` 的**上限**。写成 `q₁^m` 把"预算"误标成"要求"。
> 2. `ξ/a ≳ 1.75` 是**地板**（UV/解析度），不是"要达到的目标值"；越过它没有额外好处，只有成本。
> 3. σ 的 `ξ/a≈7` 同时来自 `(U)` 和 `L≥4ξ_σ/a`，但**约束成本的是后者**（体积），不是前者。

### 2.3 判据检查

- `m`：需要 `ξ/a≈1.75`，IR 下限 `L≥4·1.75=7`。但 §2.2 的 β=6.4、L=8 试点（0.41 fm）显示体积/operator 系统误差很大，**实际要用 `L=12–16`**（0.8–1.1 fm）——正好是任务判据给的范围。任务判据"`L=12–16` 上可测" → **成立**（前提是配 GEVP，见 §2.2）。
- `σ`：需要 `ξ_σ/a≈7`、`L≈28–32`。这是纯 NumPy 核在 `32⁴` 上的成本问题（§3），不是"不支持 L"，但成本高两个量级。任务判据"需要 `L≥24`" → **成立**，即 σ 与 m 的成本不对称是真实的。

## 3. 成本模型：为什么不是 10–50 倍

`lattice-cpb` §10.3 的标度（在 `β=6` 的标定上）：

```
δm/m ∝ ξ/√N_eff        ⟹   N_eff(ξ, δ) = 4000·(ξ/0.93)²·(8.2%/δ)²
L ≥ 4ξ/a               （项目证据标准，handoff §7.2）
```

取 `δ=5%`、`τ_int=10`（`N_sweeps=2τN_eff`）、纯 NumPy `50 µs/site`：

| | `m`（`L=12³×24`, `ξ/a=1.75`） | `σ`（`32⁴`, `ξ_σ/a=7`） | 比值 |
|---|---:|---:|---:|
| `N_eff` | `3.8×10⁴` | `6.1×10⁵` | 16 |
| sweeps | `7.6×10⁵` | `1.2×10⁷` | 16 |
| 体积 (sites) | `4.1×10⁴` | `1.05×10⁶` | 25 |
| NumPy 时数 | `≈440 h` | `≈1.8×10⁵ h` | **≈400** |
| @7× 核 | `≈63 h` | `≈2.5×10⁴ h` | ≈400 |
| @50× 核 | `≈9 h` | `≈3.6×10³ h` | ≈400 |

**SURVEY 的"10–50×"只对应体积比 `(32/12)⁴≈50`（或 `(28/7)⁴=256`），漏了 `ξ²` 的统计标度。** 等精度全成本是 `~4×10²`，若两端都取最小的 `L=4ξ/a` 则到 `~4×10³`。方向不变，量级要改：**σ 至少贵一个量级，通常两个量级**，这让 drop σ 的理由更强。

> 备注：20% 精度下两边的 `N_eff` 都降 16 倍（m≈27 h，σ≈1.1×10⁴ h NumPy），比值不变；但 `lattice-cpb` §9.6/§10 指出 20% 误差要用 2σ 下界去"认证" `ξ/a=7` 时，中心值须到 `≈11.7`，反而更贵。所以 5% 是较优的工作点，比值结论稳健。

## 4. 判定

### 4.1 `m` 门槛可达 → 建议正式 drop `σ`

- 处方：`β=6.2`（`ξ/a≈1.70`）或 `6.3`（`≈1.9`），`L³×T=12³×24`（FSS 用 `8³×16` 作对照），**APE ladder `n=0,8,16,32` + GEVP**（§2.2 显示固定 `n=8` 在 `β≥6.2` 严重不足），`~10⁵–10⁶` sweeps，`10²–10³ h`（NumPy，含 ladder 的 smearing 开销）/`10¹–10² h`（7× 核）。
- 这给出的是 `m/Λ` 与 `ξ/a` 的**数值可行性/一致性**，不是证书。证书仍是 `H3[m]`；数值数据不进 Lean 链（`handoff-proof` §7.2 已写死这一条）。

### 4.2 `σ` 不可达，且 Clay 不需要它

- Clay：存在 + 质量隙 + 非平凡性，**不含禁闭**。σ 是本项目条件定理的第 5 项（bonus）。
- 现工具下 σ 需 `ξ_σ/a≈7`、`L≈28–32`：等精度 `≈1.8×10⁵ h`（NumPy）、`≈2.5×10⁴ h`（7× 核）、`≈3.6×10³ h`（50× 核）。**不可达**，除非换核或换可观测量（torelon），而那两条都未验证。
- 因此把 σ 从**当前里程碑**的关键路径移出，是零风险、省下全项目最大单笔数值成本的决定。

### 4.3 drop σ 的**正确范围**（不要多删）

| 去掉 | 保留 |
|---|---|
| σ 数值战役（`ξ_σ/a→7`，`L=28–32`） | `CPB-W`（唯一解析瓶颈，未变） |
| `CPB-S^σ`（弦扇区强侧 signed gas） | `CPB-S^m`（中性扇区强侧；`q₁^m=0.571` 时"近乎免费"，`glue-d` §0） |
| `I-HANDOFF[σ]` 与 `H3_σ` | `I-HANDOFF[m]` 与 `H3[m]` |
| GL7 的"双交接同一 RT"义务（σ 侧；`GlueD.dual_overlap_iff` 已证，留着无害） | GL7 的 m 侧同一性（若主线仍要 uniqueness 链） |
| — | **`W1_1`（见 4.4）** |

**一句话**：drop σ 把 5 项条件定理降到 4 项，去掉的是"禁闭"及其数值/解析负担；**解析瓶颈 `CPB-W` 一分未减**。

严格说，drop σ 也去掉了 σ 侧的解析义务（`H3_σ`、`CPB-S^σ`、GL7 双 RT），但这些都**不在 Clay 目标的关键路径上**；关键路径上的节省是数值的，而 `CPB-W` 与 `W1_1` 一分未减。这正是纪律条款的分界。

### 4.4 `W1_1` 仍在关键路径（本报告的纪律条款）

`gluing` §2.4 的唯一性契约是 `MIX ∧ BC ∧ W1_0 ∧ W1_1 ∧ TIGHT`，且 **MG 只服务 `W1_0`（中性）**（R19/R22）。因此：

- `W1_1`（弦扇区边界屏蔽，`𝒜_{±1}`）**不被 drop σ 触及**。它弱于 `σ>0`（只要"逐扇区唯一"，不要面积律），但同属带电扇区、共用同一 RG 墙。
- 它是**解析输入**，不是数值战役——所以"drop σ 省数值成本"成立，但"drop σ 就不碰带电扇区"不成立。
- 非平凡性（`research/nontriviality`）走 UV 侧 `g_ren≠0`，**与 σ 解耦**；三项 Clay 目标里没有一项依赖 σ。
- 若 `uniqueness` §5.5.4(b) 的 Wightman/Reeh–Schlieder 路线（中性唯一 ⟹ 弦扇区唯一）能被严格化，`W1_1` 也可省——但那是**未严格化**的另一件事，不能当作 drop σ 的附带收益。

## 5. 会改变判定的输入

| 输入 | 若如此 | 后果 |
|---|---|---|
| `m/Λ` 实际 `<3` | `q₀^m≲0.21`，`ξ/a≳4.7`，`β≳7.3`，`L≳19` | m 战役涨到 `~10³ h`，但仍比 σ 便宜；几乎不影响 drop σ |
| `m/Λ` 实际 `<2` | `ξ/a≳7`，与 σ 同门槛 | **drop σ 的成本理由失效**，需重评 |
| 强侧 `CPB-S^m` 的 `q_c>0.571` | `H3[m]` 因强侧失败，与数值无关 | 数值门槛变成伪问题；瓶颈回到解析 |
| `β=6.2–6.4` 的 `ξ/a` 严重偏离 `a(β)` 预期 | 强 scaling violation | `β≈6.3` 处方作废，需先做 `β` 扫描 |
| `0++` 不是最轻（如 `0−+` 更低） | `ξ/a` 被低估一个 O(1) 因子 | 门槛相应上移，量级不变 |

**证伪线**：若在 `β=6.2–6.4, L=12–16` 上测不到稳定 `ξ/a∈[1.5,2.0]`（例如拟合无平台、或 `ξ/a` 的 `L` 依赖跨过 30%），本报告的"可达"判定作废。
