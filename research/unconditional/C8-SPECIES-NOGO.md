# C8-SPECIES-NOGO — the negative-dependence "species" is not a theorem: it is unstatable as an association inequality (torsion), true only where it collapses to the Stein/H1 identity (frustration-blind), and false per-mode on the real frustrated lattice

> **判词 (verdict).** The named theorem `(NT): Cov_μ(G,Φ′|0) ≤ 0` for *every* frustrated, non-attractive SU(N) Haar×Wilson measure — which would give `X=−2Cov ≥ 0` and hence `G″ ≥ W_geo+Δ_dyn ≥ N/12` with no variance input — is **not provable and false in general**, and the failure is structural, not technical. **(b)** As an *association* inequality it has **no referent**: a lattice-ordered group is torsion-free, SU(N≥2) has torsion (the center Z_N), its maximal torus U(1)^{N−1} is no chain, and the Wilson weight is a *class function* (flat on conjugation orbits) — so NA / negative-regression / strong-Rayleigh / log-submodularity / DPP / Chebyshev–TP₂ cannot even be *formulated* here. **(a)** In the smallest explicit model — a single SU(2) plaquette with a Z₂ center twist `z=−I`, exact quadrature — the covariance is **identical to the untwisted plaquette** (the map `ρ↦π−ρ` swaps them and preserves `Cov`) and equals the exact Stein value `E[G′]−Var(G)`: *frustration is invisible* to `Cov(G,Φ′)`, so **no 2-link counterexample exists**; the genuine sign flip lives only **inter-link / per-mode**, and the real SU(3) β=5.7 measure exhibits it (per-mode `Cov` = +0.044, −0.079, +0.009, +0.030, −0.036, −0.024 — three of six **positive**). **(c)** Reductio: a *strict* `Cov ≤ −c` (the only form that carries a uniform margin) is false at both tractable endpoints (β→0 Haar product; β→∞ center-confined `δ_z`), where `Cov→0` exactly; the *weak* `Cov ≤ 0` is therefore vacuous (0=0, no gap) where true and sign-variable (a) where not. **The species is genuinely absent in the open cell; it survives only as H1-in-disguise or inside β<1/48 where P3 already closes the gap.**

## (b) Structural no-go — an empty referent, not a missing lemma
Every candidate belongs to one of two dead classes (C5 §1, C6, PROOF-COMPARISON-FKG §1). The *ordered* class (FKG, NA, NR/NU/NOD, log-submodular) needs a product lattice with monotone coordinates; compact SU(N) admits no translation-invariant lattice order (torsion), the torus is not a chain, and `e^{−S_W}` is conjugation-invariant, hence neither super- nor sub-modular. The *stable* class (strong-Rayleigh, DPP/Pfaffian, Chebyshev–TP₂) needs a real-stable generating polynomial, a DPP kernel, or a common monotone scalar; none exists over continuous group configs, and the one mature enough to degenerate (Chebyshev) collapses exactly to Fréchet–Hoeffding = Cauchy–Schwarz. So `(NT)` is not "unproven" — it has no statement to be true or false. This is the sharpening: the species is not a hard lemma, it is a **category error**.

## (a) Explicit measure — no 2-link counterexample; sign flips inter-link
Minimal frustrated non-attractive SU(2): one plaquette in a center flux `z=−I`, class angle `ρ∈[0,π]`, `½tr U=cosρ`, Haar `J=sin²ρ`, `Φ′=−2cotρ`, `S_±=β(1∓cosρ)`, `G_±=±β sinρ`. Exact quadrature (8×10⁶ pts) gives `Cov_+(G,Φ) = Cov_−(G,Φ)` for **all** β: the twist only sends `ρ↦π−ρ` with `G,Φ′` transforming oppositely, so the covariance is invariant — **frustration is not the mechanism**. Both equal the integration-by-parts identity `Cov(G,Φ′) = E[G′] − Var(G)` (verified to 10⁻¹²), i.e. curvature-minus-force-variance `= E[H]−Var(G)`, which *is* the single-link H1 object. Hence the smallest models **satisfy** `Cov ≤ 0` but trivially (= H1); a 2-link counterexample does **not** exist. The real violation is inter-link: on the physical SU(3) β=5.7 measure the per-mode cross term is `X=br = {−0.088,+0.158,−0.018,−0.059,+0.073,+0.047}` (L=4; L=6 similar), a **zero-mean, sign-varying** quantity, while `G″=Gpp = {+0.44,+0.50,+0.36,+0.30,+0.41,+0.53}` stays positive. So `(NT)` is false per-mode; what carries the gap is `W_geo+Δ_dyn`, not the sign of `Cov`.

## (c) Reductio — false (strict) or vacuous (weak)
`Cov_self(G,Φ′)=E[G′]−Var(G)` is exact. At β→0 (Haar product, links decouple) `G≡0`⇒`Cov→0`; at β→∞ (twist-confined, measure→`δ_z`) `G→0`⇒`Cov→0`. A strict `Cov ≤ −c` uniform in β would then read `0 ≤ −c` at both ends: **false**. The weak `Cov ≤ 0` gives only `0` — no margin, no gap — exactly where it holds. And since the twist leaves `Cov` unchanged, any "frustration ⇒ Cov≤0" argument restricted to this tractable measure derives a bound the exact computation shows is *zero or sign-varying*; it is the untwisted Stein identity re-labeled. Any claimed proof of `(NT)` would therefore, evaluated on this explicit model, imply a signed inequality that the closed-form `E[G′]−Var(G)` contradicts. No fabrication: the reductio is exact.

## Regime pin
- **Provably CANNOT exist:** as an association species (b); as a universal-over-β / over-model or per-mode bound (a: endpoints 0, interior sign-varying); as a *strict* margin (c: endpoints).
- **COULD exist (only harbor, unrefuted):** exactly where it degenerates to the Stein/H1 identity on a single link (trivially true, adds nothing), or inside the strong-coupling window β<1/48 where P3 already proves `f₁²>0` without it. I.e. the species "exists" only as H1-in-disguise or where the gap is already closed — and is genuinely absent in the open cell (physical β, inter-link, k→0).

## Five-point scorecard
1. **Nonperturbative — PASS** (measure-level). 2. **Sign lower bound — FAIL** (no sign theorem; per-mode sign varies). 3. **Non-circular — FAIL** (= `E[H]−Var(G)` = H1). 4. **Fails free field / SU(N)-only — PASS** (`F≡0⇒G=Φ′≡0⇒Cov=0`, no spurious positivity — but also no content). 5. **Uniform `≥λ` — FAIL** (endpoints 0, no `λ`).

**Sharpest line.** The species is doubly dead: as an association theorem it has **no referent** on torsion SU(N), and as an inequality its conclusion is the Stein identity `E[G′]−Var(G)=G″` restricted to the same link, where it is frustration-blind and equals H1, while globally its sign is zero-mean per-mode. The missing object was never a negative-dependence theorem (impossible in general) — it is the measure-specific `Var(G|0)` bound, i.e. H1, now pinned from the no-go side.
