# C8-SPECIES-NOGO — the negative-dependence theorem is unstatable as an association inequality (torsion), true only as the frustration-blind Stein/H1 identity, and false per-mode on the real frustrated lattice

> **判词 (verdict).** The named theorem `(NT): Cov_μ(G,Φ′|0) ≤ 0` for *every* frustrated, non-attractive SU(N) Haar×Wilson measure — giving `X=−2Cov ≥ 0` and hence `G″ ≥ W_geo+Δ_dyn ≥ N/12` with no variance — is **not provable and false in general**, structurally. **(b)** Unstatable as an association inequality: lattice-ordered groups are torsion-free, SU(N≥2) has torsion (center Z_N), its torus is no chain, the Wilson weight is a class function — so NA / negative-regression / strong-Rayleigh / log-submodularity / DPP / Chebyshev–TP₂ have **no referent** here. **(a)** In the smallest explicit model — one SU(2) plaquette with center twist `z=−I`, exact quadrature — the covariance is **identical to the untwisted plaquette** (`ρ↦π−ρ` swaps them, preserving `Cov`) and equals the exact Stein value `E[G′]−Var(G)`: frustration is *invisible*, so **no 2-link counterexample exists**; the sign flip is inter-link/per-mode — real SU(3) β=5.7 has **3 of 6 modes with `Cov>0`**. **(c)** A *strict* `Cov ≤ −c` fails at both tractable endpoints (β→0 Haar product; β→∞ center `δ_z`), where `Cov→0`; the *weak* `Cov ≤ 0` is vacuous (0=0) where true and sign-variable (a) where not. **The species is absent in the open cell; it survives only as H1-in-disguise or inside β<1/48 where P3 already closes the gap.**

## (b) Empty referent, not a missing lemma
The ordered class (FKG, NA, NR/NU/NOD, log-submodular) needs a product lattice with monotone coordinates; compact SU(N) has no translation-invariant lattice order (torsion), the torus is no chain, `e^{−S_W}` is conjugation-invariant (flat on orbits). The stable class (strong-Rayleigh, DPP, Chebyshev–TP₂) needs a real-stable polynomial, a DPP kernel, or a common monotone scalar — absent on continuous group configs; Chebyshev degenerates to Fréchet–Hoeffding = Cauchy–Schwarz (C5 §1, C6, PROOF-COMPARISON-FKG §1). `(NT)` has no statement to be true of: a category error, not a hard lemma.

## (a) No 2-link counterexample; sign flips inter-link
Minimal frustrated non-attractive SU(2): one plaquette in center flux `z=−I`, `ρ∈[0,π]`, `½tr U=cosρ`, `J=sin²ρ`, `Φ′=−2cotρ`, `S_±=β(1∓cosρ)`, `G_±=±β sinρ`. Exact quadrature gives `Cov_+ = Cov_−` for **all** β — the twist sends `ρ↦π−ρ` with `G,Φ′` transforming oppositely — so frustration is *not* the mechanism. Both equal the integration-by-parts identity `Cov(G,Φ′) = E[G′] − Var(G)` (checked to 10⁻¹²) = `E[H]−Var(G)`, the single-link H1 object. The smallest models thus **satisfy** `Cov≤0` but trivially (= H1); a 2-link counterexample does **not** exist. The real violation is inter-link: on physical SU(3) β=5.7 the per-mode cross term `X=br = {−0.088,+0.158,−0.018,−0.059,+0.073,+0.047}` (L=4) is **zero-mean, sign-varying**, while `G″=Gpp = {+0.44,+0.50,+0.36,+0.30,+0.41,+0.53}` stays positive. `(NT)` is false per-mode; the gap is carried by `W_geo+Δ_dyn`, not by `Cov`'s sign.

## (c) Reductio — false (strict) or vacuous (weak)
`Cov_self(G,Φ′)=E[G′]−Var(G)` is exact. At β→0 (Haar product, links decouple) and β→∞ (twist-confined, measure→`δ_z`), `G→0`⇒`Cov→0`. A strict `Cov ≤ −c` uniform in β reads `0 ≤ −c` at both ends: **false**. The weak `Cov ≤ 0` returns only `0` — no margin, no gap. Since the twist leaves `Cov` unchanged, any "frustration ⇒ Cov≤0" argument here derives a bound the closed form shows is zero or sign-varying — the untwisted Stein identity re-labeled; a proof of `(NT)` would imply a signed inequality the exact `E[G′]−Var(G)` contradicts. No fabrication: the reductio is exact.

## Regime pin
- **Provably CANNOT exist:** as an association species (b); as a universal-over-β/model or per-mode bound (a: endpoints 0, interior sign-varying); as a *strict* margin (c).
- **COULD exist (only harbor):** only where it degenerates to the single-link Stein/H1 identity (adds nothing) or inside β<1/48 where P3 already proves `f₁²>0`. It "exists" only as H1-in-disguise or where the gap is closed — genuinely absent in the open cell (physical β, inter-link, k→0).

## Five-point
1 **Nonperturbative — PASS.** 2 **Sign lower bound — FAIL** (no sign theorem; per-mode sign varies). 3 **Non-circular — FAIL** (= `E[H]−Var(G)` = H1). 4 **Fails free field / SU(N)-only — PASS** (`F≡0⇒Cov=0`, no spurious positivity — but no content). 5 **Uniform `≥λ` — FAIL** (endpoints 0).

**Sharpest line.** The species is doubly dead: as an association theorem it has **no referent** on torsion SU(N); as an inequality its conclusion is the Stein identity `E[G′]−Var(G)=G″` on the same link, frustration-blind and equal to H1, while globally its sign is zero-mean per-mode. The missing object was never a negative-dependence theorem (impossible in general) — it is the measure-specific `Var(G|0)` bound, i.e. H1, now pinned from the no-go side.
