## §1 逻辑缺口——有限 `(a,L)` 给什么、不给什么

### 1.1 记号与"固定点"是什么

Wilson 格点，间距 `a`，边长 `L`（格点单位），`β = 2N/g₀²`。转移矩阵 `T_{a,L} = e^{−aH_{a,L}}` 在**有限格点**上是**有限维**正算子；真空唯一（连通的紧群 + 反射正性），谱离散。设物理能量本征值 `E_n`，则

- **无量纲格点质量** `m_lat(a,L) := a·(E_1 − E_0) = a·ΔE(a,L)`；
- **物理质量** `ΔE(a,L) = m_lat(a,L)/a`；
- `T` 自身的谱隙 `1 − e^{−aΔE} = 1 − e^{−m_lat} ≈ m_lat`（小 `m_lat`）。**[T]（定义/恒等）**

**"有限 `(a,L)` 认证隙"** = 在该单点 `(a₀,L₀)` 上严格证 `m_lat(a₀,L₀) ≥ δ₀ > 0`（或等价，`T` 的谱隙 `≥ 1−e^{−δ₀}`）。这**确实**是一个**有限维**陈述：`T` 是有限矩阵，隙是有限个本征值的差。**[T]（有限维性）**

### 1.2 Clay 要的是什么（三件事 + 一个识别）

Clay 需要（见 BRIEF §1、PROOF-SKELETON §0）：

- **(i) 标度率 / `a→0` 一致**：`m_phys := lim_{a→0} m_lat(a)/a ≥ Δ > 0`，沿临界线、**对 `a` 一致**（比值的正下界，不是固定常数）。
- **(ii) `L→∞` 一致（OS2/聚类/唯一真空）**：无限体积极限存在且隙不退化。
- **(iii) 算子识别**：这是**最轻 `0⁺⁺`** 道的**谱边**，且边上有**原子残数** `f₁² = |⟨0|¼tr F²|G⟩|² ≥ r₀ > 0` **并隔离**（= `H*`，PROOF-SKELETON §1）。不是"某个本征值有隙"，是"**这个**物理道在**这个**位置有原子且被隔开"。
- **(iv) 连续对象（G1）**：隙是**Wightman QFT** 的谱隙，不是一个有限格点矩阵的谱隙。要先有 OS 重构的连续理论（G1），隙才有意义。

### 1.3 精确缺口（逐条，`[O]`）

一个固定 `(a₀,L₀)` 的认证隙**不**给出：

1. **标度率（最关键）**。数据本身说 `m_lat = a·m_phys`；在标度窗内**真实**的格点质量必须 `≈ a·Δ → 0`（随 `a→0` 线性地趋于 0）。一个只证 `m_lat(a₀,L₀) ≥ δ₀` 的证书给了单点数值；连续隙要的是**跨越所有 `a` 的率**：`m_lat(a)/a ≥ Δ`，即 `G″_a ≥ a²Δ²`。**PROOF-SKELETON §0 的量纲更正**正是此点：拿 `G″_a ≥ λ（常数、与 a 无关）` 当隙是量纲错的——它给 `m_phys = √λ/a → +∞`（= 自由盒 UV 尺度 `4π²/L²` 的伪影，不是粒子）。**正确的目标是比值/率，不是常数**。
2. **`a`-一致性**。单点（甚至有限多点）证书不谈 `a∈(0,a₀]` 的**一致**下界；而连续极限恰恰是一致性陈述。
3. **`L`-一致性**。证书在有限 `L₀`；`L→∞` 的一致下界是另一个独立缺口（OS2）。
4. **算子识别**。`T` 的"某个隙"不保证是最轻 `0⁺⁺`、不保证边上有 `f₁²` 原子、不保证隔离；`H*` 需要残数 + 隔离 + (CP) 单相（PROOF-SKELETON §1）。
5. **连续对象**。有限格点隙 ≠ Wightman 谱隙；后者要 G1 先成立。

### 1.4 决定性一步：自由无质量场的**酸测反例** **[T]**

> **引理（自由场漏洞）**：自由无质量标量场在**每个有限 `(a,L)`** 上都有正转移矩阵隙（最低空间模的盒隙：无量纲 `m_lat ≈ 2 sin(π/L) > 0`，物理 `ΔE = m_lat/a > 0`），但它在**无限体积连续极限**下 `m_phys = 0`。

**证明要点**：自由场 `H` 的空间动量最低模的物理能量 `ΔE = 2π/(aL)`，故无量纲格点隙 `m_lat = aΔE ≈ 2 sin(π/L) > 0` 对**每个有限 `L`** 成立（即 `T` 的谱隙 `1−e^{−m_lat}>0`）。取 `L→∞`（使物理体积 `aL→∞`），`|p|_min ≈ 2π/(aL) → 0`，谱边落在 0，`m_phys = lim_L→∞ ΔE = 0`。∎

**推论（酸测判决）**：命题"固定 `(a,L)` 有正隙"**对自由无质量场也成立** ⇒ 作为"YM 有隙"的**判别量**是 **vacuous**（自由场酸测**失败**）。这与本项目一贯的酸测铁律完全一致（BRIEF §2 第 4 条；A5 的"有限 `k` 自由场同样 `G″(k>0)>0`"；TRANSPORT-RIGOROUS-NUMERICS §2.3）。

> **所以**："认证有限 `(a,L)` 隙"若要**非平凡**，必须被**重述**为 1.3(1) 的**率+道+残数**陈述（对自由场失效）。单点"有隙"证书本身**不携带 YM 物理**——物理全在**标度率与两个极限**里。

## §2 一列认证隙能不能给出连续极限？

### 2.1 形式化问题

设对**一列** `a_n→0`、`L_n→∞` 认证 `m_lat(a_n,L_n) ≥ δ_n > 0`。要推 `liminf_{a→0, L→∞} m_lat(a,L)/a ≥ Δ > 0`，**逻辑上**需要三类附加信息：

- **(A) 率**：`δ_n ≥ a_n·Δ`（证书的**衰减率**不能快于线性）。仅有 `δ_n>0`（哪怕每个 `a_n` 都成立）**不够**——`δ_n` 相对 `a_n` 的比值没有下界时，`liminf m_lat/a` 可能是 0。
- **(B) 覆盖**：`a∈(0,a₀]` 的**全部**，不是样本点。点与点之间 `m_lat(a)/a` 可有任意深的凹陷；无模连续/单调/一致界则**无法排除**。
- **(C) `L`-一致**：`L_n→∞` 的极限里谱边不退化。

### 2.2 为什么"一列 + 外推"**不是**定理 **[T]（逻辑）**

> **命题（自由场反例——一列证书不足以推连续隙）**：存在一个格点模型族（自由无质量场），对**每个** `(a_n,L_n)`（任意趋于 0/∞ 的序列）都有**严格正**的认证格点隙 `m_lat(a_n,L_n) ≥ δ_n>0`，但其连续谱边在 0（`m_phys=0`）。

**证明**：§1.4 的自由场对每个有限格点有严格正盒隙 `m_lat(a_n,L_n) = 2 sin(π/L_n) > 0`，等价 `ΔE(a_n,L_n)=m_lat/a_n>0`；这些值都可被（原则上）严格认证（自由场是高斯、可精确算）。但取 `a_n≡a` 固定、`L_n→∞`，则 `ΔE = m_lat/a = 2 sin(π/L_n)/a → 0`，连续谱边落在 0。故任何"每点有正隙 ⇒ 连续有隙"的推理**被这个反例证伪**。∎

**结论**：一列固定点证书**+拟合/外推** = **数值证据 [R-num]，非证明**。要成为定理，`(A)(B)(C)` 中至少 `(A)+(B)` 必须以**证的**形式补上——而那正是**均匀性**，即 L3/H1。

### 2.3 什么样的"附加严格输入"能转换？——三条**已知**候选，全部落墙 `[O]`

要把 `(a_n)` 样本的证书变成沿 `a→0` 的**一致**下界，严谨地只有几条路，各有其墙：

1. **单调性**：若证得 `a ↦ m_lat(a)/a` 沿临界线**单调**（或至少单侧有界），样本点 + 单调 ⇒ 覆盖 `(B)`。**状态**：4D 纯 YM 质量隙对 `β` 的单调性**无定理**；格点伪影使实测 `m_phys(β)` 非单调（有限 `a` 修正可正可负）。**不可用**。
2. **RG 收缩（带一致常数）**：若证得 RG 映射在 `[a₀, a]` 各尺度**一致收缩**、且隙按**精确乘性因子**搬运（本项目 `f₁² = Z_O² f₁²`，PROOF-SKELETON / INVENT-TRANSPORT），则样本隙 + 乘性搬运 ⇒ 一致隙。**状态**：乘性传输**本身**免费/条件于 (CP)；**墙是它乘的跨 crossover 非零种子**——`Z_O²` 好算，种子（`f₁²` 在 `α_s~O(1)` 处 `>0`）正是 H1。**这就是墙**。
3. **紧性/Arzelà–Ascoli**：连续极限的存在用一族理论的一致紧性 + 一致谱下界。**状态**：一致紧 = L3（`sup_a Z_a⁻¹‖H_a‖_D<∞`，PROOF-SKELETON G1.2）；一致谱下界 = H1。紧性论证**假设**了要证的东西。**循环**。

> **因此**：`(a_n)` 列证书**必须**被一个"跨 crossover、对 `(a,L)` 一致"的**解析界**托住；没有它，序列给不出极限（§2.2 反例）。**这个解析界 = L3 ∧ H1 = 那台尚不存在的输运机**（CLAUDE.md §5、TRANSPORT-FIVE-WAY-VERDICT §5）。

### 2.4 `a(β)` 的循环：为什么连"说清楚 `m_lat/a`"都要 L3

物理上 `a→0 ⟺ β→∞`（渐近自由），`a(β)` 由**量纲透射（dimensional transmutation）**定义：`Λ = μ·exp(−∫dg/β(g))`，而 `a(β)` 只通过**跑动耦合/标度设定**才有定义。于是"`m_lat(a)/a ≥ Δ`"本质是"**隙与参考尺度（`Λ` 或某物理量）之比**有正下界"——一个**方案无关**但**要求两个连续量都存在**的陈述。**存在性 = G1 = L3**；`a(β)` 的严谨定义 = 控制跑动 = L3。所以 §2 的桥**第二次**（独立地）撞回 L3。**[J]**

### 3.3 为什么**同一技术**不移植到 4D 纯 YM `[J]`

1. **维度/临界性**：4D 纯 YM 在**上临界维**（`[g]=0`，**边缘**），`β` 函数带对数、量纲透射生成 `Λ`；SPDE/正则结构在这**恰是临界**（3D 的次临界性消失）。2D σ 模型虽也 AF，但 1+1D 的 AF 对数 + 无规范围栏使其 RG **可控**；4D 的 crossover 处 `α_s~O(1)`，**无小参数**（TRANSPORT-FIVE-WAY-VERDICT §2）。
2. **规范冗余/Gribov**：σ 模型是自旋系统（FKG/Simon–Lieb/反射正性齐备）；YM 需规范商、Gribov 副本、度量/符号问题（Savvidy 不定 Hessian）。2D YM 的可解性靠"无横模 + 面积 heat-kernel"，4D 无此。
3. **质量生成机制**：`O(3)` 的隙由 2D 瞬子/θ-真空结构生成（受控）；4D 纯 YM 的隙由**禁闭/crossover**生成，正是墙本身。**"跨 crossover" = "禁闭"**（BRIEF §4）。
4. **3D YM–Higgs ≠ 3D 纯 YM**：CCHS 构造的是**过程**（G1 型），且靠**超可重正**；它**不证隙**、也**不是纯 YM**。3D **纯** YM 的 IR 隙仍开放。

### 3.4 先例的**总判决** **[J]**

> **没有一例**是"先认证一个有限 `(a,L)` 格点隙、再外推/搬运到连续极限"。存在的严谨连续极限（2D YM、3D YM–Higgs 过程、强耦 YM 隙）全部是**解析构造**，其发动机是**小参数/可解性/超可重正**。**"计算机辅助的有限格点隙"从未充当过 AF 理论连续极限的发动机。**（`∀class ≠ ∀possible`：这是**已有一切严谨先例**的判决，不是全局不可能定理。）

## §4 决定性区分：计算问题还是解析一致性墙？

### 4.1 计算的辩护（认真陈述）

- 每个 `(a,L)` 的 4D 纯 YM 是**有限维**模型；隙是**有限本征值差**；用认证区间/TRG 算术，原则可在**许多 `β`** 上逐点严格认证；物理质量 `m_phys(β)` 实测是**光滑、正、单调趋近连续值**的函数。于是——辩护说——墙只是"格子不够大、`a` 不够小、算力不够"；给够算力 + 好的认证算法，逐点证书 + 可控外推"实际就够"。

### 4.2 反驳（为何拒绝）**[T]/[O]**

1. **逐点有限维 ≠ 一致。** §1.4/§2.2 的**自由场反例**是决定性的：每点有正隙、连续无质量。**有限维性在每点成立，恰恰不能排除**"隙以快于 `a` 的速率坍缩"。要排除，需要**率+覆盖**的一致界——解析的。
2. **外推不是定理。** 有限尺寸/连续外推是**拟合**；无**证的**标度律 + 受控余项，外推只给**置信区间**，不给**下界定理**。格点 QCD 的 `a→0` 外推从不是证明。
3. **不是算力问题。** 到给定 `a` 的格点数 `∼a⁻⁴`；但**障碍不在成本**：crossover 处证书常数随 `α_s→O(1)` **退化**，且**没有受控展开**（TRANSPORT-FIVE-WAY-VERDICT：强耦窗 `β<1/48` 与物理 `β≈2.5` 差 ~46×、与 CNS 阈值 `β≤10^{-40}` 差 ~41 个量级）。这是**无小参数**墙，换更强机器不消失。
4. **量纲/归一化本身要 L3**（§2.4）：`m_lat/a` 的严谨含义要求控制 `a(β)` = 控制跑动 = L3。

### 4.3 裁决（rule）**[J]**

> **解析一致性墙（= L3 ∧ H1），不是计算墙。** 认证数值/TRG 路线给出**必要的**有限 `(a,L)` 证据（有独立价值：把 H1 在第三种技术里再量一次），但**不足以**到 Clay；缺的正是**跨 crossover、对 `(a,L)` 一致**的下界。把它当"够大就算完"是**把一致性墙误认作成本墙**——恰是本项目 11 物种反复撞到的同一误判。

## §5 最终裁决 + 精确缺失步

### 5.1 对问题的直接回答

1. **有限 `(a,L)` 认证隙能到 Clay 吗？** **不能。** 它给一个有限维单点陈述；而 Clay 要的是 `(i)` 标度率/`a`-一致、`(ii)` `L`-一致（OS2）、`(iii)` `0⁺⁺` 残数 `f₁²>0` + 隔离、`(iv)` Wightman 谱隙（G1）。**这四个它一个都不给**；且照通常陈述法它**过不了自由场酸测**（自由场每点有盒隙却无质量，§1.4）。
2. **精确桥是什么？** 从"列认证隙"到 `liminf m_lat(a)/a ≥ Δ` 的桥 = **率 `(A)` + 覆盖 `(B)` + `L`-一致 `(C)`**（§2.1），且 `a(β)` 要由跑动定义（§2.4）。**严谨地**，只有"**跨 crossover 一致收缩的 RG + 乘性残数搬运 + 非零种子**"能补 `(A)(B)`——而**非零种子 + 一致收缩 = H1 + L3**。
3. **是否重新引入 L3？** **是，精确地、两次**：`a`-一致（UV，L3）在 §1.3(2)/§2.4/§4.2(4) 出现；`L`-一致 + `k→0` 谱边（IR，H1）在 §1.3(1,3)/§2.3 出现。二者是**同一个单侧方差上界物种**（PROOF-SKELETON §0：UV 面=L3，IR 面=H1）。
4. **计算还是解析？** **解析一致性墙**（§4.3）。
5. **TRG 路线的最好情形给什么？** 一个**真 [T]**：在 `β≈2.5` **单点（或有限点）**的认证有限 `(a,L)` 隙——**若且仅若**它以物理归一化（率+道+残数，§1.3(1)/1.4）陈述，**才**非平凡。但它**仍要求解析连续极限/RG 墙（L3）被跨过**。**它买到的是"用第三技术再测一次 H1"，不是削弱它。**

### 5.2 精确缺失步 `[O]`（一句话，可单独攻）

> **[O] 跨 crossover 的 `(a,L)`-一致下界**：证
> `∀ a∈(0,a₀], L≥L₀ :  m_lat(a,L)/a ≥ Δ > 0`
> ——等价 `G″_a ≥ a²Δ²`（**率，不是常数**），其中 `m_lat` 是**最轻 `0⁺⁺`** 道的谱边、边上有 `f₁²≥r₀>0` 且隔离；等价：**一个认证压缩常数跨 crossover（`α_s~O(1)`）均匀的 RG 映射**（键维-uniform 截断误差界）。在项目坐标里，这**就是 L3（UV）∧ H1（IR）**，**同一个物种**。
>
> **酸测**：自由无质量场的 TRG 是**临界不动点**（不收缩），故"跨 crossover 收缩"对自由场**失败** ⇒ 原则上**过**酸测；但**认证其跨 crossover 均匀收缩**，与现有一切路线**同难**（TRANSPORT-RIGOROUS-NUMERICS §4）。

### 5.3 诚实边界

- **Clay 仍 0%**（PROOF-SKELETON §5）。本文件**没有**把 TRG 路线证成通往 Clay 的路；它**精确地**把 TRG 路线的落点钉到与其余 11 物种相同的坐标（L3/H1），并**再次**说明"有限格点证据 ≠ 连续极限"。
