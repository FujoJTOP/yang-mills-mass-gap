# PROOF-HAMILTONIAN-VARIATIONAL — the binding gap needs the threshold from BELOW; every Hamiltonian route supplies it from ABOVE

> 2026-11-23 · Kogut–Susskind variational attack on the binding gap `B := {2-glueball threshold} − m_{0⁺⁺} ≥ β_bind > 0`. **Verdict: the directions do not close — no Hamiltonian/variational theorem for `β_bind` is obtainable, and the exact obstruction is the INEQ-R3/LEVER second-level regress.** Rayleigh–Ritz bounds `m_{0⁺⁺}` and the threshold both from ABOVE; binding needs the threshold from BELOW. The electric-term positivity — the only rigorous Hamiltonian lower bound — is particle-number- and channel-blind, so it bounds `m_{0⁺⁺}` and `2m_g` equally. Temple needs the level above (feeding it the upper bound is unsound); Weinstein–Kato lower-bounds only what the trial state *sees*, requiring a certified overlap that is itself the regress. And the binding collapses to the mass gap. No fabrication.

**Setup.** `H = (g²/2)Σ_ℓ E²_ℓ + (1/g²)Σ_p(1 − N⁻¹Re tr U_p)` on `T³_L`, Gauss-law projected. Both terms `≥ 0` (`Re tr U_p ≤ N`), so `H ≥ (g²/2)ΣE² ≥ 0`; the flux-free vacuum `|Ω⟩` (all `E=0`) is the ground state at energy `0`. `m_{0⁺⁺}` = lightest `0⁺⁺` excitation; threshold `T` = lowest two-glueball energy `= 2m_g`, `m_g` the lightest glueball. Target `B = T − m_{0⁺⁺} ≥ β_bind > 0`.

**Direction audit.** `B>0` requires `m_{0⁺⁺} ≤ U` (upper) **and** `T ≥ L` (lower). Rayleigh–Ritz supplies `m_{0⁺⁺} ≤ U` — the right, easy leg. It supplies `T ≤ U′` — the *wrong* direction: an upper bound on a higher level certifies nothing underneath it. The complementary pair the prompt names — threshold-from-above with bound-state-from-below — gives only `B ≤ U′ − L`, an *upper* bound on the gap, never `β_bind>0`. So the entire content is one-sided: a **lower bound on the second spectral level**.

**Electric positivity is blind.** `H ≥ (g²/2)ΣE²`, and any flux state has a link with `E² ≥ C₂(fund) = (N²−1)/2N`, giving `m ≥ (g²/2)C₂(fund)` — the strong-coupling mass gap, a genuine lower bound. But it lower-bounds `m_{0⁺⁺}`, `m_g`, and `m_{2g}` by the *same* constant; it cannot order them. The only rigorous Hamiltonian lower bound available is particle-number- and channel-blind.

**Temple / Weinstein run the wrong rung.** Temple lower-bounds a bottom level only from a **lower** bound on the next; substituting the variational *upper* bound violates its hypothesis and returns false too-high values (LEVER §1). Weinstein–Kato, `E_min(φ) ≥ ⟨H⟩_φ − √Var_φ H`, lower-bounds the lowest level the trial state sees; to equate that with the threshold needs certified overlap with the sector ground — and the certificate is Eckart–Löwdin–Shull, which needs the gap above (INEQ-R3 §2). Two trial states fare no better: `R₂ − R₁` compares vertex upper bounds on two different levels, with no sign.

**The collapse.** If `0⁺⁺` is the lightest glueball, `m_g = m_{0⁺⁺}`, so `T = 2m_{0⁺⁺}` and `B = m_{0⁺⁺}`: the binding *is* the mass gap. "Dissolution at `β_c`" — the atom `m₁²` sliding up to the continuum edge `4m_g²` — is `m_{0⁺⁺} → 2m_g ⇒ m_{0⁺⁺} → 0`, gap closure. If instead a lighter `2⁺⁺` exists (leading-order degenerate, PROOF-IN11), `B` is set against `2m_{2⁺⁺}`, itself uncontrolled. Either way no variational certificate crosses: at strong coupling `B` closes as the electric mass gap (PROOF-IN11/P3), and persistence past `β_c` is the transport wall — an atom dissolving at an interior threshold drops `f₁²→0` (PROOF-TRANSPORT-MONOTONE).

**Sharpest line.** A binding gap needs the threshold from BELOW; the Hamiltonian gives it from above, the electric term gives it blind to particle number, and Temple/Weinstein need the level above. So `B = 2m_g − m_{0⁺⁺}` collapses to the mass gap, and the variational route's single missing datum is exactly INEQ-R3's missing rung — the second spectral level; `β_c`'s "dissolution" is indistinguishable from gap closure.
