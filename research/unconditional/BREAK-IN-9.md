# IN-9 (`SPEC-RES`) 攻击：能不能证？——不能，失败点精确定位

**判词.** 未闭合。SPEC-RES 干净地分解为 **(I) 物理识别 `ι_a`** + **(II) 一致矩阵元/谱紧致性**，二者都不是现有输入（IN-0/1、GL3）的推论。核心事实：**(II) 是"极限的 a-导数"对象，而构造只给 C⁰（Schwinger）收敛**——这是结构性障碍，不是技术缺口。补上 (II) 后由 Trotter–Kato 闭合，但 (II) 就是全部内容。

## 1. 证明尝试：Trotter–Kato 路线
对 `H_a=-(1/a)log T_a` 证强预解收敛，需 (a) 共同核心 `D`、(b) 一致预解界 `sup_a‖(Ĥ_a−z)⁻¹‖<∞`、(c) `D` 上收敛。全部挂在一个**重整生成元**上：
`Ĥ_a := Z_a⁻¹·ι_a H_a ι_a⁻¹`（`Z_a`=场强重整，`ι_a`=块自旋插值 + 高斯标度 `A~(1/a)(U−1)`）。

**条件闭合（真，但同义）。** 若 ∃`Z_a>0`、等距 `ι_a`，使 ∀ξ,η∈D：`Z_a⁻¹⟨ι_aξ,H_aι_aη⟩→⟨ξ,Hη⟩` 且 `sup_a Z_a⁻¹‖H_a|_D‖<∞`，则由 Trotter–Kato（Reed–Simon I, Thm VIII.25）得 `Ĥ_a→H` 强预解收敛 ⇒ SPEC-RES。**这是 SPEC-RES 的重整化矩阵元等价刻画，不是证明。**

## 2. 断裂点（逐一）
- **(I) `ι_a` 非典范.** `ℋ_a≇ℋ`，裸柱向量 `e^{iaA}→1`；任意 `ι_a` 改变算子与谱，"`H_a→H`"只在**物理** `ι_a` 下有定义。证 `ι_a` 渐近等距且与生成元一致 = 连续统极限存在性（G1）。
- **(II) 一致界 = 极限的导数，被 C⁰ 抹掉.** 谱测度 `ν_a` 在 `[δΛ,∞)` 上弱收敛需**一致总质量** `C_a(0)=∫dν_a<∞` **且一致一阶矩** `∫λdν_a=⟨ψ_a,H_aψ_a⟩<∞`（∞ 远处紧致）。二者正是 `Z_a⁻¹log T_a` 的 `O(a)` 系数。
  **反例之刃** `T_a=diag(1,e^{−c₁a},e^{−c₂a})`：`T_a→I`（一致），一切裸矩阵元 `→1`；而隙 `c₁` 只活在 `O(a)` 项。**对"恒等于常数的极限"求 a-导数，信息为零**——故任何依赖 `‖T_a−T‖→0`、Schwinger/弱收敛的论证**原理上**给不出 (II)。`c₁` 与 `c₁'` 同一极限、不同隙，正是此点。

## 3. 精确失败
`SPEC-RES ⟺ { ι_a 物理 ; sup_a Z_a⁻¹⟨ψ_a,H_aψ_a⟩ ≤ C 于共同核心 }`。首项构造依赖；次项为一致 Rayleigh/矩阵元界，**独立于且严格强于** OS 连续性。**G2 给支集（`Δ_a≥δΛ`）、G1 给紧致性，互不蕴含**；现有输入只供前者。（注：文档 §5 的单点 `C_a(t_*)` 控制总质量，但对 ∞ 的紧致性要的是 `t_*→0` 导数即矩阵元界。）

## 4. 什么额外重整分离出隙
单一的**一致矩阵元界** `sup_a Z_a⁻¹⟨ψ_a,H_aψ_a⟩<∞`（= `Ĥ_a` 在共同核心上的一致算子界）+ 核心一致。它不是"更强的连续性"而是**定量 UV 界**；反例证明它不能从任何极限型（弱/范数/Schwinger）收敛抽取，因隙对 `a` 是一阶、所有此类收敛是零阶。

**结论.** 未证；`SPEC-RES = G1 的重整生成元一致界`，开放。
