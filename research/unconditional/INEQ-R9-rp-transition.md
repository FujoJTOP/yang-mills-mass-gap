# INEQ-R9 — RP + Perron/Dobrushin strict comparison on the TRANSITION `⟨Ω|O|G⟩`

> 2026-11-23 · Attack on the residue `f₁²=|⟨Ω|O|G⟩|²` through the **off-diagonal transition** `⟨Ω|O|G⟩` (amplitude), not the gap: compare two Gibbs measures by a **strict** Perron/Dobrushin argument instead of the failed upper-bound gap levers. **Verdict: pin — no construction.** No unconditional "positivity ⇒ strict overlap" lemma exists; the strict-comparison machine attaches strictness only to the Perron (ground) object and, to reach `|G⟩`, needs a signed-Peron/order-parameter structure pure YM lacks. Its quantitative form also dies at β≈2.5. It needs Savvidy-type non-convex control (necessary) **and** the missing order parameter (sufficient content), i.e. it collapses onto `f₁²≥r₀` = the gap.

## 1. What strict comparison is a theorem of
Perron–Frobenius **strict monotonicity**: `A≥B≥0`, `A≠B` irreducible ⇒ `ρ(A)>ρ(B)`, Perron vectors strictly ordered. Dobrushin: conditional ordering `μ_{Λ|∂}≤ν_{Λ|∂}` (FKG) ⇒ strict measure order, strict iff the measures differ. Both correct — and both attach strictness to the **top** eigenvalue/eigenvector. The target `⟨Ω|O|G⟩` is an **excited**-vector overlap: PF makes `Ω>0` strictly, but `ψ₁` is `Ω`-orthogonal and sign-changing; PF assigns it no sign, hence no strict bound.

## 2. Reaching `|G⟩` needs a signed Perron vector — absent in YM
A strict overlap needs `O` odd under an involution `σ` for which `|G⟩` is the `σ`-**odd** Perron vector (Ising magnetization, Z₂ Polyakov-odd sector). Then `⟨Ω|O|G⟩` has a definite strict sign. The `0⁺⁺` glueball is `C=P=T=+` and centre-neutral, and pure YM has **no local order parameter** (LEVER §3; confinement is not SSB of a local symmetry). No `σ` ⇒ no signed Perron vector ⇒ the strict machine never touches `|G⟩`. This obstruction is *order-theoretic, not Savvidy*.

## 3. The quantitative comparison collapses at β=2.5
Dobrushin coefficient of the single-link heat-bath: each link sits in `2(d−1)=6` plaquettes, sensitivity `~β`, so `C(β)≈2β(d−1)·O(1)≈15≫1` at β=2.5 ⇒ `1−C<0` — exactly the block-coupling wall of H2-globalization. The log-concavity/Jensen ingredient for eigenvector strictness fails by the Savvidy negative mode. The comparison converges only for β below an `O(1/48)`-type threshold (SZZ), `~10²×` under `β_c`.

## 4. Free-field / selection-rule no-go (rigorous)
RP holds for the free (massless) scalar. Take `O` in a wrong-`C/P` channel, or whose channel's lightest state lies above `O`'s support ⇒ `⟨Ω|O|G⟩=0` with RP intact. Hence `{OS/RP axioms}+gauge-invariance` alone cannot lower-bound `|⟨Ω|O|G⟩|`: strictness must inject dynamics.

## 5. Where it collapses to
A β=2.5 strict comparison would have to certify the sign/coherence of `ψ₁` — equivalently `f₁²=ν({m₁²})≥r₀`, the Schwinger order parameter (RESIDUE-CONDITIONAL). Granting it *is* the edge theorem. So the transition route is not independent of the failed gap routes; it renames `f₁²`. Provable only at strong coupling; extending to β≈2.5 needs Savvidy/UV non-convexity (necessary) **plus** the absent order parameter (sufficient content = the gap).
