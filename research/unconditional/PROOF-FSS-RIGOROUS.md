# PROOF-FSS-RIGOROUS — FSS certifies upper bounds on Δ_∞; the sign-controlled correction it would need *is* the gap

> **Verdict.** FSS is rigorous only in the already-gapped regime and only *given* the clustering rate — the gap. For a gapped, non-critical theory the correction is **exponential, not power-law**: `Δ_L = Δ_∞ + C_L`, `0 ≤ C_L ≤ C e^{−μL}·poly(L)` (`ω=∞`); the ansatz `Δ_L − Δ_∞ ~ L^{−ω}` is *critical* Fisher–Barber/Wegner FSS, the wrong function class at T=0. The one unconditional inequality is `Δ_∞ = inf_L Δ_L ≤ Δ_L`, so `C_L := Δ_L − Δ_∞ ≥ 0` — the **wrong sign** for a lower bound. A lower bound needs the opposite bound `C_L ≤ ε(L)` (`⇔ Δ_∞ ≥ Δ_L − ε`); because `|C_L| = C_L`, a "two-sided magnitude bound" **is** the desired statement, not a route to it, and only volume-uniform exponential clustering at rate `μ>0` — the mass gap — supplies it. The trial-state sandwich `cert_L ≤ Δ_L ≤ R(ψ)` is finite-volume: `R(ψ)` bounds `Δ_∞` only from **above**, and matching it to a lower bound requires `R(ψ) ≤ Δ_∞ + ε`, which is the target. **At β=2.5 FSS gives no lower bound on Δ_∞; the exact missing estimate is a volume-uniform clustering bound at β=2.5 (uniform Poincaré constant 1/m) — the gap, not even known to exist there.**

**1. Direction — the only unconditional fact.** In the physical (unique-vacuum) sector, minimisation over trial states gives `Δ_∞ = inf_L Δ_L ≤ Δ_L` (P4 §2; PROOF-COMPUTER-ASSISTED), so `C_L ∈ [0, Δ_L]`. With a boundary-induced near-degeneracy the sign itself can fail (P4 §2's 2D-Ising caution, F9-1); pure YM at θ=0 has a unique vacuum, so `Δ_L ≥ Δ_∞` is the operative direction.

**2. The rigorous FSS relation — only where the gap is known.** (i) Strong coupling `β<β₀`: cluster expansions (Osterwalder–Seiler; Münster–Weisz; Kotecký–Preiss; Seiler) give volume-uniform exponential clustering at rate `μ(β)>0`, hence `0 ≤ C_L ≤ C(β)e^{−μL}poly(L)`, `ω=∞`; but `Δ_∞ ≥ m(β)>0` is already a theorem there (SZZ, `β<1/48`), so FSS adds nothing. (ii) β=2.5: no cluster expansion (`u≈0.51`, PROOF-BLOCK-RG-GAP); *conditional* on a uniform rate `μ>0` the same exponential bound holds, and `μ,C` are exactly the missing input. (iii) The `L^{−ω}` form needs a critical fixed point (`ω` = correction-to-scaling eigenvalue); a gapped T=0 YM has an isolated lightest state and Lüscher-type exponential volume dependence (CMP 104 (1986) 177). The rate is the lightest exchanged mass = the gap, so controlling the "clustering length" *is* controlling the gap.

**3. Why a magnitude (two-sided) bound is circular.** Since `C_L ≥ 0`, "`|C_L| ≤ ε`" reads "`C_L ≤ ε`" = "`Δ_∞ ≥ Δ_L − ε`", literally the lower bound sought. The free half (`C_L ≥ 0`) is the direction lemma; the costly half (`C_L ≤ ε`) is an upper bound on a nonnegative correction, equivalent to volume-uniform clustering with `ε(L)=Ce^{−μL}`, `μ` the gap. No sign-blind device supplies it: every moment ratio bounds the edge from above (GAP-G2-edge).

**4. The two-sided construction — where it stops.** In principle a construction works: since `Δ_∞ = inf_L Δ_L`, a **volume-uniform** certificate `cert_L ≥ m>0` for *all* L gives `Δ_∞ ≥ m` — but that uniform-in-L bound *is* the gap (= P4 §5's `L*`, = H1/H2). Finite data supply only `cert_L ≤ Δ_L ≤ R(ψ)` at fixed volume (PROOF-COMPUTER-ASSISTED; ATOM-trial-state). `R(ψ)` gives `Δ_∞ ≤ R(ψ)` (upper only); `cert_L` lower-bounds `Δ_L`, not `Δ_∞`. A "matching" needs `R(ψ) ≤ Δ_∞ + ε`, i.e. — with the free `Δ_∞ ≤ R(ψ)` — `|R(ψ) − Δ_∞| ≤ ε`, the lower bound itself. Trial-state sharpness (GAP-IN12) controls `R/Δ_L`, an axis independent of the tail `C_L`.

**5. β=2.5 — exact status and missing estimate.** No FSS lower bound, and no theorem that `Δ_∞>0` at all. (LATTICE-TM-GAP's L=4,6, N_τ=6 numbers are at/above deconfinement `β_c≈2.30/2.43` — thermal screening masses, themselves upper bounds on the T=0 gap, the same wall.) The exact missing estimate:
> **(M)** `∃ μ>0, C<∞` independent of L: for all L and all gauge-invariant local O, `|⟨O(0)O(x)⟩^{conn}_{L}| ≤ C e^{−μ|x|}` at β=2.5 — equivalently a volume-uniform local Poincaré constant `1/m` (P4 §5; H1–H2).

Then and only then `C_L ≤ ε(m,L) < Δ_L`, giving `Δ_∞ ≥ Δ_L − ε`. (M) is not weaker than the gap; it *is* it (IDEA-finite-size: LGP ⇔ gap; PROOF-STEP-SCALING: the marginal/UV side is blind to it).

**Sharpest line.** FSS describes how fast a *known-positive* gap is approached and hides the gap in its rate `μ`; its one unconditional consequence, `Δ_L ≥ Δ_∞`, has the wrong sign, and the bound that flips the sign — an upper bound on the nonnegative correction `C_L` — is identical to the desired `Δ_∞ ≥ Δ_L − ε`, equivalent to volume-uniform exponential clustering. So FSS yields upper bounds only: a lower bound on `Δ_∞` at β=2.5 requires a different input, and the exact one is a volume-uniform clustering/Poincaré constant at β=2.5 — the gap, not yet known there.
