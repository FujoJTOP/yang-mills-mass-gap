> 2026-11-23 · 承接 `ABC2-DUALITY`（A2 把 #5 写成**正定平面谱密度** `ρ_∞`）/ `PROOF-LARGE-N-RIGOROUS`（`m_∞+c/N²`，N=3 无界）/ `FORGE5-SOLVABLE-CORNER`（min–max 反向、`1/N` 余项不可控）。**靶**：把 `S_N:=Σ_n|⟨0|(∇S)_N,v|n⟩_N|²/m_n(N)²≤1/λ` 从 `N=∞` 搬到 `N=3`，得 `m₁(3)≥√λ`。**判词：三通道各自死法不同，同归一堵墙——载体-隙障碍在 N 下逐字不变。** 不存在只靠 N 的转移：N 只改数值（`m₁(N)`、重叠），不改"低-q 谱权重须由有隙载波承载"这一逻辑依赖。

## 0. 精确对象与 't Hooft 约定
固定 `λ=g²N` ⇒ 格点耦合 `β_N=2N/λ` **随 N 变**（固定 λ 调 N 即换 β、换群）。A2 给 `S_∞≤1/λ`（平面 0⁺⁺ 隙 `m₁(∞)≥√λ`、正性自动、符号在 `E[H]−Σ`）。要闭合 #5 须 `S_3≤1/λ`。`G″·Var(a)=1`（精确 Ward，全 β、全 N）: `S_3≤1/λ ⟺ G″_3(0)≥λ`——仍是 `m_eff²(k→0)≥λ`（PROOF-IR-H1）。

## 1. (a) `S_N` 在 N 上单调？——无证明方向，且正性给反号
要 `S_3≤1/λ`，唯一有用的是 `S_N` **非增**于 N（`S_3≤S_∞`）。**无此定理。** 唯一免符号结构是正性：围绕 master field 的量子涨落若正定，则 `S_N=S_∞+(1/N²)(正项)+…` ⇒ `S_N≥S_∞`——**恰是反方向**（帮不了上界 `S_3`）。无 FKG（PROOF-COMPARISON-FKG）⇒ 无 `SU(N)⊂SU(N+1)` 的随机序；`1/N²` 系数 `c` 的符号无定论（`m_∞+c/N²` 只保证渐近，`c/9` 在 N=3 无界）。**（a）败 #5，甚至与所需反号。**

## 2. (b) 1/N² 因子化余项 × 连通 4-点——余项即 H1
`S_3−S_∞=(1/N²)·(连通 4-点)`，N=3 前因子 `1/9≈11%`，而 `S_∞≤1/λ` 可**无松弛**（贴着界），11% 上偏即翻界。关键：该连通 4-点**就是** `Var_μ(⟨v,∇S⟩|0)` 的粗模分量 = 被求上界的对象本身 = H1（PROOF-IR-H1；ABC2-SYNTHESIS §4 Ward）。且 β=2.5 处**无严格 1/N² 展开**——master field 未建（PROOF-LARGE-N-RIGOROUS：严谨者仅 β 小/强耦），余项非受控。Weingarten（格点规范唯一严谨的"正下界"，INEQ-T5）以 Cauchy–Schwarz **自上界质量** `(cross)²≤(same)(same)`、需锚 `m_π`（纯胶无），对**方差**是反方向。**（b）循环：把余项换成了 H1 本身。**

## 3. (c) 't Hooft 强耦标度 / 格点普适——错区 / 循环
固定 `λ` ⇒ `β_N=2N/λ`：大 N ⇒ `β→∞`（弱耦），**不是**强耦。强耦 `β<1/48` 要求 `N<λ/96`；β=2.5、g≈1.5 ⇒ `λ≈7`，需 `N<0.073`——N=3 远离强耦角。故 OS/SZZ 的强耦 't Hooft 隙**到不了** N=3,β=2.5（区不相交）。格点普适只在**连续极限** `a→0` 转移，而其存在且带隙**就是** Clay——循环。**（c）败 #1(可用性)/#3/#5。**

## 4. 结构原因：障碍为何 N-不变
`S_N<∞ ⟺` 与 `(∇S)_v` 耦合的最轻态有隙 `m₁(N)≥√λ`。N 改 `m₁(N)`、重叠——**不改**这一等价。免符号正性只给 `S_N` 的**下界**（`S_N≥S_∞`；Cramér–Rao `I·Var≥1`），而隙要上界。故任何 N-转移都必须供一个**均匀于 N 的 `Var_N(a)` 上界**=`H1` 在 N=3。**载体-隙 = "转移一个值须先有均匀于 N 的下界" = 隙本身**，与 N 无关。

## 5. 五点裁决
1. **非微扰 — 败/仅形式。** (b) 在 β=2.5 需未建 master field；(a) 无定理；(c) 强耦严谨但与 β=2.5 区不相交。
2. **控符号（下界 `m_eff²(0)≥λ`）— 全败。** 正性给 `S_N≥S_∞`（`G″` 反号）；所需 `S_3` 上界即 H1。
3. **非循环 — 全败。** (a) 单调性未证、`c` 号不定；(b) 连通 4-点 = 粗方差 = H1；(c) 普适先设隙、强耦错区。
4. **非-SUSY + 败自由场 — 干净过（皆然）。** 三通道自由场均 `F≡0⇒S_N=∞`、返 `λ=0`、`f₁²=0`，无非空过。但这是**真判别、空产出**：对 YM 亦不给正界。
5. **均匀下界 — 败。** 正是所缺，且恰为 N 不变的那一步。

**最锐一句.** A2 把墙算到最准（正定平面谱密度），N=∞→3 的三种搬法——单调、`1/N²` 因子化余项、强耦标度/普适——全部把"缺什么"搬回原地：单调性无证明且正性反号，`1/N²` 余项逐字是粗方差=H1，强耦与 β=2.5 区不相交、普适先设连续隙。载体-隙障碍**不随 N 变**，因为它不是 N 的函数：它是"低-q 谱权重须由有隙载波承载"，而 N 只换数值。精确缺失一步 = **一个均匀于 N 的 `Var_N(a_{k→0})≤1/λ` 上界** = N=3 的 H1，未动。
