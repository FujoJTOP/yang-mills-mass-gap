# C-BBS-ARRHENIUS — capacity/Dirichlet trap on the thermal shell: the λ-bootstrap closes *iff* the coarse-mode barrier is a non-extensive absolute `O(1)`; the naive `λ^{−1/2}`-shell reading is circular (the self-map contracts to `λ=0`)

> 2026-11-23 · Constructive arm, C-BBS scheme: replace BBS's **Hessian trap** (needs a positive-definite large-field Hessian, which Savvidy `−D²+2adF_B` violates) with a **capacity/Dirichlet trap** (a convex min of the *positive* energy `∫|∇f|²dν` — the sign is free). UV shells `g_j→0` are trapped (cone empty + Prékopa); the **only** `O(1)`-barrier shell is the thermal/IR one. Target: the thermal-shell Arrhenius barrier is `O(1)`, not exponentially large.
>
> **判词 (verdict).** The trap does what it promises on the **sign**: on the coarse mode `a` with marginal `ν=e^{−V̄}da`, `λ_1≥Φ_eq²/4` (Cheeger/Sinclair) and `Var(a)≤1/λ_1` make the positivity a **convex Dirichlet min**, no indefinite operator to sign. The UV stack is genuinely closed: per-shell cone radius `√(2g_j|F_j|)~g_j≪Λ_{j+1}` so the per-shell barrier `H_j≤c g_j²→0`, and barriers **add** along a path ⇒ the cumulative UV barrier `≤cΣg_j²<∞` is `O(1)` (`Σg_j²` is the running-coupling log-sum, `G1-UNIFORM-ZA`). The remaining scalar is the thermal shell, where the measured `G″`-defect is **`0.3`** (`COMPUTE-GPP`) — `O(1)`, **not** the deep-UV bare `−2.8` (also `O(1)`; *neither is extensive*, so *no* Eyring–Kramers suppression). **The bootstrap closes — `λ_0=(1/4)e^{−2H_0}>0`, no seed — if and only if `H_0`, the barrier across one fixed thermal cell, is `O(1)` uniformly in `(L,a)`.** On the literal `λ^{−1/2}` shell the barrier reassembles as `H=κ/λ` and the self-map `T(λ)=(c²/4)e^{−2κ/λ}` obeys `T(λ)/λ≤c²/(8κe)≈0.15` for all `λ` ⇒ **it contracts to `λ=0`, no positive fixed point: that reading is circular and manufactures nothing.** Exact residual: one **fixed-scale, dimension-free, `L`-uniform oscillation bound** on `V̄` — "the coarse mode is localized to a fixed cell, not spread over the box."

## 1 The trap, and where the content actually lives
`G″(0)=V̄″(0)` is a min-eigenvalue of an *indefinite* `PᵀHP`; `Φ_eq=inf_A Cap_ν(A,Aᶜ)/ν(A)`, `Cap=inf{∫|∇f|²:dν}` is a min of a *positive* form. `λ_1≥Φ_eq²/4` turns "sign an indefinite Hessian" into "min a positive energy" — **the sign is free**, and the free-field acid test is non-vacuous (flat mode ⇒ `V̄≡0` ⇒ zero restoring force). But on compact finite `L` positivity is automatic, so **all content is `L`-uniformity** (`POTENTIAL-THEORY-CAPACITY` §2). The C-BBS move is to localize that uniformity: the free mode spreads over the whole box (`Var(a)~L²`, conductance `~1/L²`, "barrier" `~2logL→∞`); a gapped YM coarse mode is pinned to a correlation cell `ξ~1/m` (fixed), so its barrier is a fixed `O(1)`. **The discriminator is extensivity, not the sign.**

## 2 UV shells: additive barrier, convergent
`GAP-G1` §1(i): at weak coupling the Savvidy cone `|k|<√(2g_j|F_j|)` sits below the shell cutoff because `|F_j|=O(g_j)` under the marginal measure ⇒ per-shell barrier `H_j≤c g_j²`. Arrhenius barriers of series escapes **add** (`e^{−ΣH_j}`), and `Σ_j g_j²` is exactly the log-resummed running coupling (`Σg_j⁴<∞`, `G1-UNIFORM-ZA` §2) ⇒ `Σ_j H_j=O(1)`. This is the honest reason "Savvidy lives at every scale" is *not* an extensive wall: the UV contributes a **convergent** `O(1)`.

## 3 Thermal shell — the single scalar
One collective coordinate (`k→0`); measured resolved curvature `0.3` (`+0.307±0.055` SU3, `+0.192±0.058` SU2, `W_geo`-carried, `W_geo` volume-/`k`-stable to `0.5%` at `0.32`), vs bare Savvidy `−2.8`. Both are `O(1)`; the catastrophe would need `H~L^d`, so the measurement says *non-extensive*.

## 4 The λ-bootstrap — two readings, one closes
```
ν=e^{−V̄}da,  cell width w,  H_0=sup_{|a|≤w}|V̄−V̄(0)|;
Φ_eq ≥ c·e^{−H_0},   λ_1 ≥ Φ_eq²/4,   Var(a) ≤ 1/λ_1 ≤ 4e^{2H_0}
   ⟹  m_eff² ≥ λ_0 := (1/4)e^{−2H_0} > 0   [no seed, if H_0=O(1) uniform]
UV:  H_j ≤ c g_j²,  Σ_j H_j < ∞;
λ^{−1/2}-shell reading:  H=κ/λ,  T(λ)=(c²/4)e^{−2κ/λ},  T(λ)/λ ≤ c²/(8κe)<1  ∀λ  ⟹ T→0  [circular]
free field:  V̄≡0 ⇒ cell~L ⇒ Φ_eq~1/L², H_0~2logL→∞  [acid test met]
```
**Closing reading:** if `H_0=O(1)` uniformly, then `Var(a)≤4e^{2H_0}=O(1)` and `m_eff²≥λ_0` — a genuine positive gap, *no circular seed*. **Circular reading:** insisting the shell width is `λ^{−1/2}` folds `λ` back into the exponent (`H=κ/λ`); then `T(λ)/λ≤c²/(8κe)<1` for every `λ`, so iterating `λ↦T(λ)` drains to `0` — it cannot bootstrap a positive `λ` from itself. The whole question is which number sits in the exponent: the **absolute** dip depth (`O(1)`, closes) or the **variance-scaled** width (`κ/λ`, circular).

## 5 Exact residual, honest
Unproven: a uniform-in-`(L,a)` bound `sup_{|a|≤w}|V̄(a)−V̄(0)|≤H_0`, `H_0=O(1)` (**fixed cell `w~ξ`**) — equivalent to **localization of the coarse mode** (= `m>0`, i.e. G2 in capacity costume, but now a *local, fixed-scale* statement, weaker than the global `Var(a)≤1/λ` and than pointwise `Hess⪰λ`). Numerics support it (`W_geo` volume-flat to `0.5%`), do not prove it (single `L=8`, sign-probe, `NUMERICS-AUDIT`). If `H_0` grows with `L` (coarse mode not localized), the floor degrades and the bootstrap is vacuous — exactly the free-field failure mode. **The bootstrap is closable, and the closure is precisely "non-extensive `O(1)` barrier," but that is not yet a theorem.**

**Sharpest line.** The capacity trap buys the *sign* for free and turns the thermal scalar into a **conductance floor** `Φ_eq≥e^{−O(1)}`; the λ-bootstrap closes to `λ_0=(1/4)e^{−2H_0}>0` **iff** the thermal-shell barrier is an **absolute `O(1)` per fixed cell** (non-extensive, `L`-uniform) — in which case no seed is needed. Read on the `λ^{−1/2}` shell it self-destructs (`T(λ)≤λ/7`, contracts to `0`), which is the tell that "barrier `O(1)`" and "`λ=O(1)`" are the **same statement**, not a weakening. The exact residual is one fixed-scale oscillation bound = coarse-mode localization.
