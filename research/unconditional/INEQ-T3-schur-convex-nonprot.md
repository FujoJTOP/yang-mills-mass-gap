# INEQ-T3 — is a Schur-convex coercivity constructible from NON-protected, non-`g`-continuous structure?

> 2026-11-23 · The prescribed escape from the free-field no-go (SCHUR-CONVEX; B1) is a same-channel total `T` that **fails at g=0** and obeys `T ≤ C·f₁²` (total ≤ atom, the Schur-convex coercivity), built from `Λ`, topology, or any nonperturbative object. **Verdict: not constructible.** The obstruction is *not* `g`-continuity — it is exhaustive over the three disjoint classes a same-channel total can occupy, and the one class that evades the free-field no-go cannot host a *Schur-convex* coercivity at all. Honest scope: this is a **theorem** for the positivity-cone class and **locality** for the cross-channel class; it does **not** exclude the open non-positivity edge route (CONVERGENCE-redteam (b)3) as a *class* — only shows no Schur-convex coercivity lives there.

**Setup.** `ν≥0`, `supp⊂[m₁²,∞)`, `f₁²=ν({m₁²})`, `M₀=1`. Coercivity `T(ν)≤C·ν({m₁²})`, required (A) non-vacuous on the physical `ν_*` (`T>0`, forcing `f₁²≥T/C>0`) and (B) proven from YM structure, not by positing the atom. A same-channel total is exactly one of: **(P)** positivity-cone `T=∫φ dν` (φ≥0, moments, Cauchy–Schwarz); **(X)** cross-channel / nonlocal; **(D)** same-channel non-positivity dynamical (dual min–max, spectral-edge theorem). No fourth class.

**Class P — closed, as a theorem.** `φ` is `g`-independent, so `T` is `g`-continuous and defined on the free two-photon cut `ν_free` (support `⊃[m₁²,∞)`, purely a.c., `f₁²=0`). The coercivity, as an RP-structure law, must hold on every admissible pure-continuum cut, so `∫φ dν_free≤0`; if `φ>0` on any positive-measure set of the continuum, `∫φ dν_free>0` — violation. Hence `φ≤0` a.e. above threshold; continuity forces `φ≤0` everywhere (a convex `φ` cannot be `>0` at `m₁²` and `≤0` just above it). Then `T_φ≤0` on *every* `ν`: the inequality holds trivially at `f₁²=0` and never forces an atom. **No class-P Schur-convex coercivity exists** — stronger than the free-field `1≤0`; the pure-continuum cuts make it vacuous, not merely false at one coupling. (`tr F²`'s `M₂=∫s²dν` is also UV-divergent — only the anomaly log-coefficient is scheme-free, a UV number, not a finite IR total.)

**Class X — closed by locality.** `Λ=μe^{−8π²/b₀g²}` (RG scale), `χ_t` (0⁻⁺ instanton moment), 't Hooft flux (nonlocal static), `E(θ)` — all genuinely trivialize at `g=0` (evade the no-go), but none is a functional of the 0⁺⁺ `ν`. A `g`-dependent `φ_Λ` that "uses `Λ`" merely smuggles class X into the test function. Same-channel locality forbids the only bridge to `f₁²`: by the moment lemma (GAP-IN11) `χ_t≥f₁²m₁²` is an *upper* bound in the wrong (`0⁻⁺`) channel; and "`Λ≤C f₁²`" *is* the stable-`0⁺⁺`-glueball statement, i.e. the gap.

**Class D — the honest residual.** This class *can* fail at `g=0` and stay same-channel, so the free-field no-go does not reach it. But Schur-convexity is self-defeating here: a functional Schur-convex in the majorization order is *maximized* by spreading, so proving `T(ν_*)≤C f₁²` on the physical measure — whose continuum is uncontrolled — already asserts `ν_*` is concentrated, i.e. edge dominance, the conclusion. Its one dynamical tool, a dual min–max `E₂` lower bound, yields a *level* gap `E₂−E₁>0`, not a residue `f₁²>0`: a pure continuum above a gap still has `f₁²=0` (residue–level-gap lemma, GAP-G2-edge). The delocalized-edge result (GAP-G2-mass(c)) reinforces this — every local-density functional carries `λ_min→0`, blind to the atom. No construction in class D supplies the atom.

**Sharpest line.** "Fail at `g=0`" ⇔ leave the positivity cone ⇔ class X (locality-blocked) or class D (where Schur-convexity must presuppose the concentration it is meant to prove). RP kills the coercivity inside the cone; same-channel locality kills the bridge outside it; the residual class cannot host a *Schur-convex* object coercive to `f₁²`. The functional is not constructible; pursued from `Λ` or topology it is verbatim `H*(r₀)` — the gap — renamed.
