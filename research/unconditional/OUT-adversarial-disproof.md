# OUT-adversarial — 试图证明 4D 纯 YM 是 GAPLESS（无隙）

**结论（先给）.**
**无隙性未被任何公理或定理否证——它是活的逻辑可能。** 构建层公理（OS0–4 + 反射正性 +
聚类 + 非 Gaussian + 反常）全部被无隙见证满足，**没有一条逼出 `Δ>0`**。但**每条实现它的机制都
结构性失效**，且唯一未被排除的分支 = `(iii)`（4D CFT 唯一性）重述。故：**活，未证；若为真，
它使 Clay 的 `Δ>0` 合取项为假，而非被证。**

## 五条攻击

1. **共形窗口 / IR 不动点.** 微扰 IR 不动点需二圈 β 过零：`−b₀g−b₁g³=0 ⇒ g*²=−b₀/b₁`。
   纯 YM `N_f=0` 给 `b₁=34N²/(3(16π²)²)>0`，与 `b₀>0` **同号** ⇒ **无 Banks–Zaks 零点**。
   非微扰 IR 不动点**未被定理排除**，但**无机制、格点未见**（只见到禁闭）。仅作无约束猜想存活。

2. **Coulomb 相.** 无质量规范玻色子需自发破缺到 U(1)——一个 Higgs/物质扇区。纯 SU(N) 二者皆无
   ⇒ 无秩序参量、无 Coulomb 相。`g=0` 的自由 Maxwell 是唯一"无质量规范"情形，且被非平凡性排除。
   此处 `0∈supp ν` **就是** gap 问题本身，不是独立结构。

3. **θ=π 无隙.** mixed 't Hooft 反常（GKKS 1703.00501）**只**禁"唯一、有隙、保 CP"真空，**允许**
   无隙。但它在 **θ=0 沉默**（Clay 是 θ=0），且一阶跃变（大 N）把 θ=π 与 θ=0 隔开。
   **对 Clay 陈述无关**。

4. **BZ 作 N_f→0.** BZ 窗口**远离** `N_f=0`（`N_f` 略小于 `11N/2`），在到达纯胶前已关闭。
   无法把纯胶连续形变到 IR 不动点。

5. **平凡性 / Λ=0 / 自由塌缩.** 若 `a→0` 极限是 Gaussian（`g_ren→0, Λ=0`），它确实无隙——但随之
   **平凡**，违反 Clay 的"非平凡"合取项。这是"无隙但非 YM"：它否决 Clay 的**存在性**，不产出一个
   无隙的 YM。

## 公理到底逼出什么

- **OS0–4：不逼 gap.** 无质量自由标量是 OS 完备、聚类、规范不变、`0∈supp ν` 的见证（B2 §(a)；
  TWO-ATOMS-REDTEAM）。
- **反射正性：不逼 gap.** RP 是**符号**不等式 `⟨θF,F⟩≥0`，标度协变（自由 Maxwell 即 RP 且无隙）；
  给 `ν≥0`（PSD ⇒ **上界**），从不是 `inf supp ν` 的下界。Osterwalder–Seiler 证 RP，不证隙
  （P4 §1；EDGE-f1sq）。
- **非 Gaussian / `Λ>0`：不逼 gap.** 相互作用 CFT 有 `Λ>0`、`Δ=0`；迹反常逼态**存在**，不逼其**重**
  （B2 §(d)）。
- **θ=π 反常：** 只禁平凡有隙 CP 真空；θ=0 沉默。

于是**每条构建公理都被一个无隙见证满足**；无一条逼 `Δ>0`，RP 甚至看不见 `1−λ₁` 的大小。

## 决定性分岔

`GAP` 是 Clay 的合取项，故无公理"推出"它——其否定同样不可推出。非隙分支恰有二：
(a) 自由 `Λ=0`——作为 **Clay 解**被非平凡性排除（非被任何 gap 公理排除）；
(b) **相互作用 4D CFT 红外**——**无任何定理排除**（无 4D CFT 唯一性；SDPB 只给点态岛，无全局
排除——III-UNIQUENESS），但**纯胶无机制**（BZ 需物质、无 Higgs 即无 Coulomb、θ=π≠θ=0）。
格点（胶球 `0⁺⁺/2⁺⁺`、面积律、scaling）**经验性地**否证无隙，但**非严格**（有限 `a`、外推）。

## 判定

**无隙性是活的逻辑可能——无公理、无定理否证它。** 严格内容仅两句：
`OS ∧ RP ∧ 聚类 ∧ 反常 ⊬ GAP`（见证存在），且 `¬(无隙非平凡 YM) ≡` 一条不存在的 4D CFT 唯一性
定理。每条**实现**无隙的路线都结构性死亡（无 BZ 窗口、无 Coulomb 秩序参量、θ=π≠θ=0、平凡性⇒非
平凡被否）。故：**证明无隙与证明有隙一样缺**——若真发生，它使 Clay 的 `Δ>0` 为**假**，而非被证。
不造定理：所谓"最戏剧性结局"是一个未经否证的分岔，不是一个结果。
