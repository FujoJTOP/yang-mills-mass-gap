# LOC-SUFFICIENCY-CHECK — 逻辑审核：C-BBS-ARRHENIUS 的「固定格 O(1) 振荡 ⇒ 全局电导底 ⇒ 隙」链**不是定理**；两处独立缺口（局部→全局、边缘→支撑），且字面陈述被自由场与双井反例直接证伪

> **2026-11-23 · 判词 (verdict): REFUTE-AS-STATED（作为陈述的链被驳倒）。** 代数部分（Cheeger `λ₁≥Φ²/4`、Poincaré `Var(a)≤1/λ₁`、`λ₁≥e^{−2H₀}/4 ⟹ Var≤4e^{2H₀}`）是**真定理**。但两处推论都不是定理：(G-i) **单格**振荡 `≤H₀` **不能**给出**全域**电导底 `Φ≥e^{−H₀}`——Cheeger 常数是全轴上一切割的 inf，一格形状控制不了别处的瓶颈；(G-ii) 即便拿到全域**边缘** Poincaré 底，也只给 `χ=Var(a)`（H1，必要），**不给** `Δ=inf supp ν`（充分），故末箭 `⟹ m_eff²≥λ₀` 是 C-BBS-SUFFICIENCY 已钉死的「边缘≠支撑」谬误。两处升级各自都**等价于/强于结论本身**。字面命题「`sup_{|a|≤w}|V̄−V̄(0)|≤H₀=O(1)` ⟹ 隙」被**自由场**（`V̄≡0`，任意格 `H₀=0`，却 `Var~L²`）与**双井**（每格 `H₀=O(1)`、井间势垒 `E→∞`）两枚反例证伪。

## §1 各步实际证明了什么
`ν(da)=e^{−V̄}da`，单位 carré du champ `Γ(a)≡1` 给 `E_ν(a)=1`。于是
```
Φ_ν ≥ e^{−H₀}  ⟹  λ₁ ≥ Φ_ν²/4 ≥ e^{−2H₀}/4  ⟹  Var_ν(a) ≤ E_ν(a)/λ₁ = 4e^{2H₀}.   (★ 代数，成立)
```
**唯一有内容的是第一步**：`Φ_ν=inf_A Cap_ν(A,Aᶜ)/ν(A)` 是**全轴**上一切割的极值。`H₀` 只约束 `|a|≤w` 一格。

## §2 (a) 单格 ⇒ 全局？否
一维 Cheeger 常数 = 全轴最小瓶颈（等周剖面在「势垒最贵处」取到）。一格内 `V̄` 振荡 `O(H₀)` 对**别处**的瓶颈一无所知。反例：`V̄` 在 `a=±a₁` 两等深井，每井内一格振荡 `≤H₀`，井间鞍高 `E`；则 `Φ_ν ≲ e^{−E}`、`λ₁ ≲ e^{−2E}`，而**每格** `H₀=O(1)`。若 `E` 随 `L` 增，`Var` 界随 `L` 崩，`H₀` 却不变。要 `Φ≥e^{−H₀}` 须全相关幅域上**无更高势垒** = 全局 tail-coercivity `V̄≥½λa²`（POTENTIAL-THEORY-CAPACITY 的精确判据），远强于「一格 O(1)」。

## §3 (b) `w~ξ` 循环？是
`ξ=1/m` 用的是**未知**关联长度。两难：(i) `w~ξ`（用答案定格宽）⇒「此格内 `V̄` 振荡 `O(1)`」即「粗模局域于一固定格」= 局域化 = `m>0`，把结论当假设；(ii) `w` 取**与答案无关**的固定尺（无量纲格）⇒ 自由场 `V̄≡0` 满足 `H₀=O(1)` 却无隙（§4），蕴含式假。两角皆死。注意 ARRHENIUS §4 酸测行「自由 `H₀~2logL`」只在把 `H₀:=−logΦ_ν`（**全局**量）时成立——这正是**定义偷换**：让酸测失效的真正对象是全局 `−logΦ_ν`（即 `λ₁` 换名），**不是**字面的局部振荡 `H₀`。

## §4 (c) 有隙理论可有大格间变化？是
物理隙 `Δ` 与一模边缘谱隙 `λ₁` 不同源。有隙却 `Δ` 小 ⇒ `χ=∫s⁻¹dν ≤ mass/Δ²` 可**很大** ⇒ `Var(a)` 大 ⇒ 粗模摊到许多格；而 `λ₁≤1/χ` 随之**小**。于是**有隙**理论完全可让单格 `H₀=O(1)`（局部光滑）却 `λ₁→0`（全局摊开）。故固定格 O(1) 对**物理隙既不充分**（多井/摊开即破）**亦非必要**（有隙只需 `Δ>0`，不要求单格形状）——它至多是「模局限于一固定格」这一**更强**性质的局部证书，而该性质本身即结论。

## §5 (d) SZZ 全测度 Poincaré vs 单格/单模
Shen–Zhu–Zhu（CMP 400 (2023) 805）对 `β<1/48` 给**全格点规范测度**（一切规范不变 `f`）的**体积一致** log-Sobolev/Poincaré，故 `Var_μ(f)≤λ⁻¹E(f,f) ∀f ⟺` 连通指数簇聚 `⟺` 隙——**充分**。C-BBS 对象在两层被削弱：(i) **单函数** `a`：Rayleigh 只上界 `λ₁≤1/χ`，不能确证全常数；(ii) **等时单模边缘**：由 Feller，ℝ 上任何概率皆是某 1D 有隙扩散的不变测度，故它**不载**时空谱缘信息。单格 C-BBS `≤` 边缘 H1 `≪` SZZ 全测度（充分）。SZZ 是充分方向但只到 `β<1/48`；C-BBS 欲当搬运机，却每尺度只产 H1。

## §6 精确逻辑缺口 + 缺失的一步
- **(G-i) 局部→全局**：单格振荡 ≠ 全域电导底；缺「全幅域无高势垒 / 限于固定格」= 禁闭 = 结论（否则自由场/双井反例）。直接回答 (a)(b)(c)。
- **(G-ii) 边缘→支撑**：全域**单模边缘** Poincaré 底只给 `χ`（H1），看不见原子/留数；反例 `ν=wδ_ε+(1−w)δ_S`（`χ` 有限、边缘有隙、`inf supp=ε→0`）。这是末箭 `m_eff²≥λ₀` 的致命步，回答 (d)。

**有效条件定理（真）**：若**全规范商测度**具一致 Poincaré `λ≥e^{−2H₀}`（SZZ 型），则 `m²≥e^{−2H₀}>0`。**C-BBS 的单格/局部振荡严格弱于此**，只给有界 `χ`，必要不充分；连其必要形态也需**全局**底，单格给不出。级联：`Cheeger/Poincaré 代数 = 真定理`；`链在全-Poincaré 假设下 = 条件定理`；`字面「局部 O(1) 振荡 ⇒ 隙」= NO-GO（反例）`；**精确缺失步 = 一致全测度 Poincaré 底（= (MS) = H\\*），而非任何固定格局部界。** 结论：不 5/5，Clay 仍 0%；此链是 H1 换装，不是隙的证明。
