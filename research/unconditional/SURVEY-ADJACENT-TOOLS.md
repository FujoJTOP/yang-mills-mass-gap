## 2. Deepest analysis — the most promising: entropic Schrödinger bridge (E)

### 2.1 The object, stated at full strength
Let `R` be the reversible Wiener/path reference measure of the (stochastic-quantization) Langevin dynamics `dX_t=−∇S(X_t)dt+√2 dW_t` with invariant `μ∝e^{−S}`. For two spatial (or block-scale) marginals `μ₀,μ₁`, the **Schrödinger bridge** is
```
   P* = argmin_{P: (e₀)_*P=μ₀, (e₁)_*P=μ₁}  H(P | R) ,
```
the entropic (KL-regularized) optimal transport / dynamic Sinkhorn problem `[R]` (Schrödinger 1931–32; Léonard DCDS-A **34**(4) 1533–1574 (2014), arXiv:1308.0215; Villani *OT Old and New* 2009 §7). Its solution is a **time-reversed diffusion** (a Doob `h`-transform), reached by the Sinkhorn/IPF fixed point; its value has the **Schrödinger-potential dual**
```
   inf_{P} H(P|R) = sup_{f,g} { ∫f dμ₀ + ∫g dμ₁ − log∫ e^{f(x₀)+g(x₁)} dR } ,   (f,g)↔ entropic Kantorovich potentials.
```
The **pitch** for the gap: run the bridge along the **RG scale axis** (`k: UV→IR`), and read the gap as a **contraction per scale** of the bridge cost, hoping the *total* budget is `o(V)`.

4. **The one useful refinement this sweep adds to the death map:** the cleanest *new* statement is that the **entropic Schrödinger bridge is provably the dynamic face of `GIRSANOV`∧`E2`**, and its "additive log budget" — the only possible structural improvement over the extensive `βV` — is **exactly cancelled** by the need for a per-scale SDPI contraction `<1` that equals the gap.
