# W3 — Marginal gauge-covariant BPHZ: a constructive attack

**Verdict: the obstruction is a non-summable log-sum — not an anomaly, not infinitely many operators. No cutoff-uniform absolute BPHZ bound exists; closing it needs an exact gauge-projected flow, unbuilt but not ruled out.**

**(0) Sharpening.** For pure 4D YM the marginal operator space is finite: BRST cohomology (ghost#0, dim 4) leaves only Tr F² (coupling) and Tr F F̃ (θ, total derivative). So "infinitely many counterterms" = log-powers renormalizing *one* coupling. Narrower theorem: a cutoff-uniform flow where one running g(a) tracks the exact beta function while irrelevant directions contract — order-by-order guaranteed by algebraic renormalization (Becchi–Rouet–Stora, Ann. Phys. 98 (1976) 287; Kluberg-Stern–Zuber, PRD 12 (1975); Piguet–Sibold).

**(1) Summing the logs.** Asymptotic freedom gives per-scale marginal weight g_j²=1/(β₀ j)+O(j⁻²) for j≤J~log(1/a). A Kotecký–Preiss/BKAR bound (CMP 103 (1986) 491; Abdesselam–Rivasseau) needs Σ_j g_j²<∞, but here it is ~(1/β₀)log J — harmonic, so no *absolute* expansion. One must intertwine the bound with the exact flow (log-critical/Polchinski, NPB 231 (1984) 269). Template — exactly marginal *and* asymptotically free: 2D Gross–Neveu (Feldman–Magnen–Rivasseau–Sénéor, CMP 103 (1986) 67) and the KT Coulomb gas (Fröhlich–Spencer, CMP 81 (1981) 527) resum Σ g_j² by tracking a (coupling, irrelevant) trapping region — but both are Abelian/fermionic.

**(2) Ward/BRST.** No genuine obstruction for pure YM: the anomaly slot (ghost#1, degree 5) is empty without chiral matter, so marginal counterterms are BRST-exact except Tr F². Gribov/Singer (NPB 139 (1978) 1; CMP 60 (1978) 7) blocks only the *gauge-fixed* route — BRST stays nilpotent, the slice self-intersects. The honest home is the gauge-covariant nonlinear state space (CCHS, arXiv:2201.03487): covariant in law, no marginal BPHZ. Redundancy is preservable; the gap is analytic, not cohomological.

**(3) 3D foothold.** Structure transfers — covariant state space, local renormalized flow, *unique* mass counterterm (Chevyrev–Shen, arXiv:2503.03060). The uniform bound does not: the strict-subcritical degree condition (Hairer, Invent. Math. 198) fails exactly at d=4.

**(4) First break.** The scale-sum Σ_j g_j²~log log(1/a) is where the combinatorial proof stops — not cutoff-uniform. Passing it forces solving the gauge-projected Polchinski flow with a *compact trapping region*: a rigorous nonperturbative beta function plus uniform irrelevant contraction. Unproved; only finitely many beta coefficients are rigorous. Genuine opening: asymptotic freedom makes the UV fixed point Gaussian (unlike 4D Φ⁴ triviality, Aizenman–Duminil-Copin, arXiv:1912.07973), so g_j² shrinks in the UV and log log is slowly varying — a rigorous "Polchinski flow in log-critical RS" is not excluded.
