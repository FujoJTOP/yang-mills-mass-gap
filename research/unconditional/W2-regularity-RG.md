# W2 — Gauge-covariant regularity structures / non-perturbative gauge RG for 4D

## (1) What exists, and exactly where it stops

**2D YM:** fully constructed with OS — Osterwalder–Seiler 1978; Driver; Sengupta; Lévy. Stochastic route: CCHS `2006.04987`; paracontrolled version Bringmann–Cao `2305.07197`; non-Abelian 2D YM–Higgs *measure* via stochastic quantisation, Bringmann–Cao–Hairer–Zhao `2611.03640`. Stops short of 4D because 2D is Gaussian-UV/exactly solvable: no UV renormalisation along the nonlinearity, no propagating gluon.

**3D YM–Higgs:** CCHS `2201.03487` build a nonlinear gauge-orbit state space and *local-in-time* renormalised flow, gauge-covariant in law; Chevyrev–Shen `2503.03060` prove the mass counterterm is unique. They give **no global flow, no invariant measure, no OS, no gap**, and need the Higgs mass m>0. Pure 3D YM is itself open: Cao–Chatterjee `2111.12813` supply only a state space (`2202.13359` states the T³ measure is open; cf. model-building `2605.14616`).

**Why 3D→4D fails:** `[g²]=(4−d)/2`. d=3: `+1/2>0`, subcritical — finitely many trees, Hairer's degree condition (`Invent. Math. 198`), uniform BPHZ. d=4: `0`, marginal — tree weights vanish, infinitely many trees, non-uniform BPHZ; RS and paracontrolled both require strict subcriticality. The only solved marginal SPDE, 4D Φ⁴, is **trivial** (Aizenman–Duminil-Copin `1912.07973`), so no template.

## (2) The single missing theorem

A **cutoff-uniform, gauge-covariant BPHZ theorem in the marginal case**: the 4D stochastic YM flow renormalises with log-divergent counterterms organised by the asymptotically-free running coupling and preserved under Ward/BRST identities. Neither Balaban (CMP 109/116/122) nor RS delivers it.

## (3) Is there a proposal?

**No published one.** Only sketches: absorb the running coupling as a log-correction to tree weights ("log-critical" structure) and replace finite BPHZ by a Polchinski/Wetterich flow inside RS. Would need: (i) log-counterterms close gauge-covariantly; (ii) ℓ-loop log sums dominated by `g²(a)~1/log(1/a)` uniformly; (iii) global-in-time bounds (YM action convex along gradient flow — favourable) giving an invariant measure; then OS on the gauge-invariant algebra.

## (4) Feasibility

The 2D/3D programme is "hard but on the rails." The single marginal theorem is a **"no known idea" gap** — no concrete proposal, and the one solved marginal case yields no template — but not a proven impossibility.
