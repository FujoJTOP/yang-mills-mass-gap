# INVENT-NEW-INDEX — an index / spectral flow that counts glueballs: the exact candidates, and why topological rigidity forbids any that passes the acid test

> 2026-11-23 · 4D pure SU(N) YM, β=2N/g². Target: a topological invariant counting/protecting `0⁺⁺` atoms, which IN-11 left unprotected. **Verdict: no index passes the acid test.** I construct the two sharpest real objects. (1) The **APS spectral-flow index** of a gauge-dressed Dirac probe, `SF(D₃)=Ind D₄[A]=n(A)` — the literal Atiyah–Singer precedent, an exact integer count. It forces a state, but a **chiral fermion zero mode**: pure YM has no spinor, `⟨n⟩=0` by CP, and the only nonzero moment `⟨n²⟩=χ_tV` is the θ/`0⁻⁺` susceptibility — wrong channel, and (IN-11) an *upper* bound, the wrong cone. (2) The **Gribov-orbit FP crossing index** `SF(L_FP)` — the *only* invariant passing the free-vs-interacting acid test (`L_FP=−∂²`, A-independent, flow 0 at g=0; horizon crossings `≠0` for non-abelian YM), yet it counts **gauge copies**, not physical states. A **rigidity no-go** then kills the rest: any discrete, deformation-rigid invariant is constant on the connected coupling space, hence equals its free value, which the acid test fixes at 0 — **an index protecting the `0⁺⁺` must jump at finite β, as β-non-analytic as the gap it would bypass.** No fabricated theorem.

**1. The exact object that exists — and counts the wrong thing.** Couple one adjoint Dirac *probe* to the gauge field; evolve the spatial slice along a Euclidean-time family `A_τ`:
> **APS / Atiyah–Singer flow.** `SF_{D₃(A_τ)} = Ind(D₄[A]) = n(A) = (1/8π²)∫ tr F∧F` (up to sign): the net zero-crossings of the 3-D self-adjoint `D₃(A_τ)` equal the normalizable 4-D zero modes equal the instanton number. The `η`-invariant `η(D₃)` is the same datum: a spectral asymmetry defined only for a spinor operator pure YM lacks.

Exact counts no estimate could give — **of chiral zero modes.** The physical Hilbert space of pure YM is bosonic and positive; deleting the probe deletes the operator the index grades (no grading on `T`). And the surviving moment is the wrong channel: `⟨n⟩=0` (CP), `⟨n²⟩=χ_tV`; via `q=tr F F̃=∂·K`, Källén–Lehmann gives `χ_t=Σf_n²m_n²≥f₁²m₁²`, i.e. `m_{0⁻⁺}²≤χ_t/f₁²` — an **upper** bound (IN-11, C1). The one nonzero topological number is the wrong channel *and* the wrong direction.

**2. The one object that passes the acid test — and still fails.** The Faddeev–Popov operator `L_FP(A)=−D_μD^μ` (adjoint) is a self-adjoint family on the gauge orbit; its spectral flow is a genuine index — the Morse/degree index of the gauge-fixing map, i.e. the count of **Gribov horizon crossings**:
> **FP crossing index.** `SF_{L_FP(A_τ)} = #signed{τ : 0 ∈ spec L_FP(A_τ)} = deg(𝒜 → Lie G)`.
> Free/abelian: `L_FP=−∂²`, A-independent ⇒ **flow 0** (free side ✓). Non-abelian YM: generic `A` meets the horizon ⇒ flow `≠0` (YM side ✓).

It is the sole candidate that bites differently on free vs interacting — the literal acid test *is* passable. **But** it counts the kernel of the gauge slice: Gribov **copies**, a gauge-fixing-dependent, orbit-level object. Physical states are `ker Q_BRST/im Q_BRST`; the FP spectrum is not a cohomological invariant, so it counts the orbit, never the glueball. The acid test is satisfied only by an index whose quantized objects are *not* physical states.

**3. The rigidity no-go (why every state-counting index dies).** Let `I` be a state-counting invariant: (A1) discrete/integer; (A2) locally constant under any continuous, symmetry-preserving deformation. The lattice family `μ_β` is connected and symmetry-preserving on `[β₀,∞]`, with the **free massless theory at `β=∞`** (Gaussian about `U=1`). Hence `I(T_β) = I(T_∞) = I(free) = 0` for all β, the last by the acid test (`f₁²=0`, continuous spectrum). No `I` obeying (A1)+(A2) can force a YM glueball. The only escape is a jump at finite `β*` — but a discrete quantity discontinuous at a regular coupling is not an index; it is built from β-non-analytic data (Λ, confinement, the gap) and *assumes what it counts*. This is SCHUR-CONVEX's "g-continuous ⇒ holds at g=0 ⇒ 0" master obstruction lifted to topology — why NCG, localization, BPS, and the Witten spinor all returned 0 at the free point (H1-T5/T7, PROOF-WITTEN-SPINOR, BPS-SUSY-PROTECTION).

**Acid-test result.** APS `n(A)`: 0 free, `≠0` YM — but fermionic, wrong channel/direction. Gribov `SF(L_FP)`: 0 free, `≠0` YM — but counts gauge copies. State-counting `I`: 0 free, **0 YM by rigidity**. Even granted a crossing, no carrier protects it: `f₁²∈ℝ_{≥0}` has no sign for a ℤ₂ index, and the only gradings `P,C` do not separate `0⁺⁺` from `2⁺⁺` (both `C`-, `P`-even; mass-spectrum/STATUS S2 fails), matching the `f₁²` upper-semicontinuity that lets it drop to 0 at dissolution (PROOF-NO-DISSOLUTION).

**Sharpest line.** The Atiyah–Singer precedent cuts *against* the project: an index is exact **because it is locally constant**, and that very rigidity drags it to its free value — 0 by the acid test — across the whole connected β-line. The glueball is a positive eigenvalue of a bosonic transfer matrix, while indices count kernels and signed crossings of *signed* operators; the sole index that survives the free-vs-interacting test counts the gauge orbit, not the state. Constructing an index that protects the `0⁺⁺` is the gap, renamed.
