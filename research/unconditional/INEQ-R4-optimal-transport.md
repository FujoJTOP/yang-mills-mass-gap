# INEQ-R4-optimal-transport — can Wasserstein / Kantorovich duality lower-bound the edge atom `f₁²` where the pointwise dual (INEQ-T2) only gives upper bounds?

> 2026-11-23 · The OT route, attacked and *constructed* where possible. **Verdict: OT does not evade the usc obstruction; it reduces to it.** "OT's dual is a sup over convex lsc functions, the right class for lower bounds" is true of the **primal benchmark** `(ρ,v)`, not of the **spectral measure** `ν`. As a functional of `ν`, every standard transport cost is *continuous*, hence blind to the atom exactly as the pointwise dual is; applied to `1_{m₁²}`, the lsc dual equals `0` — the same conjugate collapse. The one atom-sensitive cost (TV, i.e. `0/∞`) is not continuous and needs an atom-free reference plus a distance lower bound ⇒ the location `m₁²` and the second level. Marked (theorem) = OT/semicontinuity theory, not YM-specific. No fabricated proof.

**Two duals, same side of the wall.** INEQ-T2: `f₁² = inf{⟨φ,ν⟩ : φ ≥ 1_{m₁²}}`, an infimum of continuous tests ⇒ **upper** bounds; its lower conjugate sup is `0`. Kantorovich: `W_c(μ,ν) = sup{∫φ dμ+∫ψ dν : φ(x)+ψ(y) ≤ c(x,y)}`, a **supremum**. A sup of continuous functionals is lower-semicontinuous (lsc); an inf is upper-semicontinuous (usc). The atom `ν({m₁²})` is **usc** (portmanteau on the closed point, INEQ-T2). OT's dual sits on the opposite semicontinuity side from the bound we want.

**Direct construction — the lsc envelope is 0 (theorem).** For `x≠m₁²` any minorant of `1_{m₁²}` obeys `ψ(x)≤0`; lsc at `m₁²` forces `ψ(m₁²) ≤ liminf_{x→m₁²}ψ(x) ≤ 0`. So `ψ≤0` everywhere and `sup{⟨ψ,ν⟩ : ψ lsc, ψ ≤ 1_{m₁²}} = 0`, identical to T2's conjugate-sup. **Convexity is irrelevant**: a convex minorant of an usc indicator is `≤0` off a dense set, so `≤0` everywhere (convex⇒continuous). The "right class" cannot represent a function of the wrong type.

**Transport cost is continuous in `ν` — blind to the atom (theorem).** For `c` continuous bounded, `W_c(μ,·)` is continuous in the weak topology (Kantorovich–Rubinstein). The atom is a *discontinuity* there: smeared `νₙ ⇒ ν` with atoms `0→f₁²` yet `W_d(νₙ,ν)→0`. A continuous functional cannot separate `ν` from its smearings, so no transport cost lower-bounds the purely usc `f₁²` from spectral data — the same blindness as the moment and pointwise duals. In the Monge–Kantorovich primal the second marginal *is* `ν`, so `∫1_{m₁²}dπ=f₁²` is again a continuous pairing; the coupling adds no pointwise structure.

**Where "convex lsc" actually lives.** In Fenchel–Rockafellar / Benamou–Brenier, convex-lsc is a property of the **kinetic action** `ρ|v|²` on `(ρ,v)`; it guarantees zero duality gap — primal inf = dual sup — i.e. certifies the *cost*, a continuous function of the endpoint measures. Zero gap is not atom-sensitivity. (The extremal Kantorovich potentials are `c`-concave, hence usc; "convex lsc" was never the dual variable.)

**The one atom-sensitive variant, and its price.** Cost `c=0/∞` (equivalently `TV`) is only lsc, and `TV(ν,ν₀)` grows with `f₁²` for atom-free `ν₀`. But it needs (i) an atom-free reference `ν₀` and (ii) a *lower* bound on `TV(ν,ν₀)` — the location `m₁²` and a guaranteed separation. That is exactly the `Λ=E₂` / two-scale datum (GAP-G2-edge; INEQ-T2's location-collapse); the transport bound cannot manufacture it.

**Sharpest line.** OT's dual is a supremum (lsc), the atom is usc, and the "right semicontinuity class" is bought on the velocity benchmark, not on the spectral measure — it does not cross the wall. Every continuous transport cost is blind to the atom; the only atom-sensitive cost smuggles in the location and the second level. OT **confirms** the obstruction; it does not evade it.
