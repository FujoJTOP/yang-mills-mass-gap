# PROVE-H3 — faithful blocking: exact splitting, gradient contraction, soft-mode freeze

**Verdict.** H3 is three claims of unequal status. **(a)** the exact coarse⊕fiber splitting and **(c)** the soft-mode freeze are **structural and hold**; the soft k→0 mode does **not** leak into the fiber, so the *block-local* H2 is **not** reopened — its residual difficulty is block coupling, never a soft mode in ∇_⊥ (H2-globalization; PROVE-H2). But **(b)** the unit-constant gradient contraction is **not** structural: it is exactly Jensen, true only for a U′-independent fiber. The Wilson fiber conditional depends on U′ (mixed coarse–fiber Hessian, PROVE-Gpp §1), leaving a score term the parallel gradient does not bound. So H3 is clean for (a),(c) but **false as stated for (b)** — refuting its billing (CONDITIONAL line 31) as "a structural property of P, not implied by H1–H2."

**P, precisely.** Partition sites into 2⁴-blocks; coarse link $U'_\mu(B)=\mathrm{proj}_G\exp(\sum_e w_e\,\mathrm{Ad}(T_e)\log U_e)$, with $T_e$ parallel transports to the block edge and $w$ a Gaussian kernel at the block scale. Gauge covariance: $U\to gU\Rightarrow U'\to g'U'$, $g'=g(\text{center})$. Linearised at $U=1$, $dP$ is convolution with an even low-pass symbol $p(k)$: $p(0)\neq0$ (DC passed), $p(\pi/a)\to0$ (UV killed), surjective onto coarse DOF.

**(a) Exact splitting — holds.** $dP_U:T_UG^E\to T_{U'}G^{E'}$ surjective $\Rightarrow T_UG^E=\ker dP_U\oplus(\ker dP_U)^\perp$ exactly, orthogonally in the Ad-invariant metric, $(\ker dP_U)^\perp=\mathrm{range}(dP_U^\dagger)$. $\Pi_U=I-dP_U^\dagger(dP_UdP_U^\dagger)^{-1}dP_U$ is a genuine orthogonal projection onto the fiber; $U\mapsto(U',\xi)$ is a local diffeo, so every $F$ is $(U',\xi)$-measurable. Caveat, not failure: $\Pi_U$ is U-dependent and $P$ is nonlinear on $G$ — "projection" holds on tangents, which is all gradients need.

**(b) Gradient contraction — the gap.** Product fiber: $\nabla\varphi=\mathbb E[\nabla_\parallel F|U']$, so $\mathbb E_\nu|\nabla\varphi|^2\le\mathbb E_\mu|\nabla_\parallel F|^2$ is Jensen. Real measure: the exact chain rule gives
$$\nabla\varphi=\mathbb E_{\mu(\cdot|U')}\nabla_\parallel F+\mathrm{Cov}_{\mu(\cdot|U')}\!\big(F,\partial_{U'}\log\mu(\cdot|U')\big),$$
the second term the mixed coarse–fiber Hessian, nonzero since $H_{\rm fib}(\xi;U')$ depends on $U'$. Scalar toy (coarse $a$, fiber $b$): $V=\tfrac12a^2+\tfrac12b^2+ga^2b^2$, $F=b^2\Rightarrow\varphi=\mathbb E[b^2|a]=(1+2ga^2)^{-1}$, $\nabla\varphi\neq0$ (verified $\approx0.79$ at $a{=}\tfrac12,g{=}1$) while $\nabla_\parallel F\equiv0$ — contraction fails. Chain-rule repair: $|\mathrm{Cov}|\le\mathrm{Var}_\mu(F)^{1/2}\mathrm{Var}_\mu(\text{score})^{1/2}$; absorption then needs $\lambda>2\sup\mathrm{Var}_\mu(\text{score})$, *stronger than* H1's bare $\lambda>0$ and **exactly** the block-coupling/globalization content H2-globalization pins open. So (b) carries IR content and is not dischargeable structurally.

**(c) Soft mode — holds, no leak.** $k\to0$ passes the low-pass $\Rightarrow$ soft mode $\in\mathrm{range}(dP^\dagger)=(\ker dP)^\perp$, and $\nabla_\perp$ annihilates it; membership is geometric, μ-independent. The radial symbol commutes with the transverse projector, so gauge covariance preserves it. The massless mode stays coarse; H2's fiber gap never controls it.

**Status.** (a),(c) proved and structural; (b) literally false, its repair carrying the same block-coupling content H2-globalization leaves open. Pin: (b) — the score/mixed-Hessian term, *not* a soft-mode leak.
