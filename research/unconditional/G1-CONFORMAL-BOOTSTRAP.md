- **no continuous internal global symmetry** (pure YM has none; only the **1-form center `Z_N`**);
- the **stress tensor `T`** (spin 2, `Δ=4`), a **0⁺⁺ scalar `ε = tr F²`** (dimension `Δ_ε`, the would-be dilaton/glueball), a possibly CP-odd **0⁻⁺ pseudoscalar `ε′ = tr F F̃`**, and the identity;

Its OPE `ε×ε ⊃ 1 + T + ε + ε′ + …` is what crossing + positivity constrain.

## §2 · The sharpest bootstrap constraints, and why each fails to exclude

1. **Hofman–Maldacena collider bounds `[T]`:** any unitary 4D CFT with a unique stress tensor has
   `1/3 ≤ a/c ≤ 31/18`. This is a **wide band** (0.333–1.722). A pure-glue CFT would sit somewhere inside it;
   the bound is **necessary, not sufficient** — it excludes no candidate. *(witness: band printed; free-field
   `a,c` and Banks–Zaks CFTs all lie inside it.)*

2. **a-theorem `a_UV ≥ a_IR > 0` `[T]`:** a conformal IR has `a_IR>0 < a_UV`; satisfied by *any* CFT. **Excludes
   nothing** (a CFT is exactly the allowed endpoint).

3. **Scale-invariance ⇒ conformal `[C]`** (Polchinski, d=4 — `[C]` not `[T]`, per STAR-LITERATURE): already
   assumed; it does not distinguish a pure-glue CFT from any other.

4. **Single-scalar minimal bootstrap (the "4D Ising") `[V-num]`:** the 4D single-scalar + `T` crossing problem
   has **no interacting unitary solution** — only the free field and the generalized free field (GFF) for
   `Δ_ε` in the GFF range. This is the **strongest evidence against** a minimal non-SUSY interacting CFT.
   **But** a pure-glue CFT has *more* operators (`ε`, `ε′`, and the center-sector defect operators), so the
   minimal single-scalar exclusion **does not extend** to it; a multi-operator SDP (beyond this witness) would
   be needed, and none is known to exclude it.

5. **1-form center anomaly matching `[T]`:** at `θ=0` the `Z_N` 1-form symmetry is **non-anomalous** (the
   anomaly is the mixed `Z_N`–`θ` one). So anomaly matching does **not** exclude a gapless CFT IR at `θ=0`
   (consistent with `STAR-NO-BZ`: no exact identity forbids the fixed point). Unbroken 1-form-symmetric CFTs
   exist (free Maxwell, etc.).

6. **The decisive structural gap:** even if a future bootstrap **excluded** an abstract pure-glue CFT, that
   would not prove (G1) — (G1) is *"pure YM's IR is not this CFT"*, i.e. **"YM does not flow to it."** That is
   a **dynamical RG question**, not a consistency question about the CFT. The bootstrap tests existence of a
   CFT in the abstract; it cannot test the flow. Conversely, a bootstrap that *allowed* a pure-glue CFT would
   not imply YM reaches it. **So the bootstrap is necessary-but-insufficient for (G1) either way.**
