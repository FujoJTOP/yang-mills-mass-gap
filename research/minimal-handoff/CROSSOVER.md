# 交叉点证书：攻击记录

> 2026-11-23 · 在 §8 的单尺度约化之后，唯一还站着的门是"交叉点那一个尺度上的证书"。本文记录对它的攻击：能证什么、证不了什么、严格结果现在到哪。

> **ERRATA（W4，2026-11-23）— 覆盖本文 §0.1 与 §2 的"≡"。** 证书是 gap 的**充分**路线（`cert>0 ∧ IN-10 ∧ IN-11 ⇒ gap`），**不是必要**路线：`cert` 是单侧下界（`IN-10`：`cert ≤ Δ/Λ`），有隙理论完全可以 `cert ≤ 0`；§2(⟸) 把"存在某正下界"（= 把 gap 换个词说）与"特定尺度分析证书"混为一谈。故 `cert>0` **严格弱于** gap，"卡在 cert ⇒ 卡在 gap"**不成立**，证书外路线**未被排除**。下文的"≡"作为**同一工具**的搜索结果仍有效，作为**逻辑等价**为假。详见 `research/unconditional/W4-cert-vs-gap.md`、`docs/gap-ledger.md` G2、`docs/campaign-final.md §6`。

## 0. 结论（先说）

1. **交叉点证书 ≡ 质量隙。** 它不是"比质量隙弱的某个陈述"——任何 `δ>0` 的单尺度证书就是 `Δ>0`。§8 的单尺度约化是**最后一个真正的弱化**；再往下没有了。
2. **严格结果只在强耦合。** 已发表的 4D 严格质量隙都在小 `β`（强耦合，cluster expansion）。交叉点在 `β≈2.5`，**在严格可达区之外**。距离是 `O(1)` 到 `O(10)` 倍，取决于主源的常数（需核原文）。
3. **三条供给各自的确切断点**：W 的引理 6（C² 上界 2.8×）；S 的 BL-6（无可加符号）；pushforward 的 UV 供给（OB-1 循环）。
4. **所以**：本项目的归约链**已经闭合**——它在逻辑上是正确的、机器验证的，但**在难度上没有降低问题**：Clay = 存在 + 隙，归约到最后还是"存在 + 隙"。

## 1. 证书的精确形式

由 §8，最小定理只需：

```
∃ μ₀ > 0 ,  ∃ δ > 0 :   δ ≤ cert μ₀  且  cert μ₀ ≤ Δ/Λ 。
```

`cert μ₀` 是尺度 `μ₀` 的分析给出的、对**固定** `Δ/Λ` 的下界。§8 证明：只需要**一个**尺度、**一侧**（W 或 S）。

**目标（交叉点证书）**：在某 `μ₀` 的交叉点（`λ_G(μ₀)≈7.3`，SU(3) 即 `g²≈2.43`、`β_eff≈2.47`）给出 `δ>0` 的 `cert μ₀`。

---

## 2. 不可约性：证书 ≡ 质量隙

**命题.** "存在 `μ₀, δ>0` 使 `δ ≤ cert μ₀ ≤ Δ/Λ`" 与 "质量隙 `Δ>0`" 等价。

> **⚠ W4 更正：此"等价"为假（见文首 ERRATA）。** `(⟸)` 对"全体下界"取存在量化，等于把 `cert` 重定义为"任何正下界"，从而只是把 `Δ>0` 换词；它**不**说明**特定的**尺度分析证书为正。`cert>0 ∧ IN-10 ∧ IN-11 ⇒ gap` 成立；`gap ⇒ cert>0` 不成立。下方"证明"的 `(⟸)` 即此循环。

**证明.**
- (⟹) `cert μ₀ ≤ Δ/Λ` 且 `δ ≤ cert μ₀` ⟹ `Δ/Λ ≥ δ > 0`。这就是质量隙。
- (⟸) 若 `Δ>0`，取任一尺度 `μ₀` 与证明 `Δ>0` 的那个分析作为 `cert`，即得。∎

**含义**：不存在"比质量隙更弱的交叉点证书"。§8 的"一个尺度、一侧"已经用尽了逻辑弱化。

> **这是本轮最重要的诚实结论。** 项目此前一直在找"更简单的充分条件"（C_cum≤1.6、κ_c≤0.8、z(q_c)≤1/2 等）——那些确实是**更简单**的充分条件，但**不是更弱的目标**：目标始终是 `Δ>0`。简单条件只是换一条到达 `Δ>0` 的路线。

## 3. 严格结果现在到哪（文献核对）

### 3.1 已知的严格质量隙（4D）

| 结果 | 覆盖 | 常数 |
|---|---|---|
| **Osterwalder–Seiler 1978** | 任意紧群、任意维；小 `β`（强耦合） | `β < c_d/N²`（SU(N)） |
| **SZZ23**（Shen–Zhu–Zhu） | SU(N)/SO(N)，3D/4D，动力学/随机分析 | `β < c_d`（**N 无关**） |
| **IJGMP 2026**（"finite-a strong-coupling gap"） | 4D SU(N)，`N≥2`；KP cluster + RP transfer matrix | `0<β<β*(N)`，体积一致 + 面积律 |
| **arXiv 2510.22788**（U(N) 't Hooft regime） | U(N)，小 `β` | cluster + 动力学 |

**共同点：全是强耦合（小 `β`）。** 大 `β` / 连续统区仍开放。

### 3.2 映射到本项目的耦合

```
β = 2N_c/g² ,   λ = h^∨ g²   ⟹   β = 2 N_c h^∨ / λ 。
SU(3):  β = 18 / λ 。
```

| 点 | `λ` | `β` | 在严格区内？ |
|---|---|---|---|
| 交叉点 | 7.3 | **2.47** | **否** |
| 强耦合窗（若 `β_0≈1`） | ≥18 | ≤1 | 是 |
| 连续统 UV | →0 | →∞ | 否（Balaban 只到 `λ~1`，不给质量） |

**交叉点在两个"可处理区"之间的缝里**：比严格强耦合窗（`β≲O(1)`）的 `β` 大，比 Balaban 的 UV 控制区（`λ~1`）的 `λ` 大。这正是项目一直说的"中间耦合区"。

### 3.3 距离的量级

**取决于 `β*(N)` / `c_d` 的具体值**（搜索结果未给全常数，须核原文）。两种情形：

- 若 `β_0 ~ 1`：交叉点 `β=2.47` 超出约 **2.5 倍**；
- 若 `β_0 ~ 0.1`：超出约 **25 倍**。

**无论哪种，交叉点都在严格可达区之外。** "expanded regime" 不是一个能到 `β≈2.5` 的标准术语——CNS25a 是面积律/强耦合；语义上不要把"展开"读成"到交叉点"。

### 3.4 一个必须写下的旁注

搜索里出现了若干**声称**证明了 4D 质量隙的 Zenodo / OSF / 预印本（"for every compact simple group"、"Clay Prize-Ready"）。**未经同行评审，本项目不引用、不背书。** 严格可达区的边界以 OS78 / SZZ23 / IJGMP 2026 这些可核文献为准。

## 4. 三条供给的确切断点

交叉点证书的证明必须从某处**供给** `cert ≥ δ`。三条路，各自的断点：

### 4.1 W（弱侧类保持）：引理 6 的常数

- 需要 `‖V''‖_{C²,R} ≤ ε < c₀m²/C`；
- 现有界 `‖V''‖ ≲ R³/g² + R²/g`（`R = g/q`）在 `q~1, g²~2` 给 **≈2.8**；
- 而 `c₀m² ~ c₀ ~ O(1)`。差 **2.4–3 倍**。
- **断点**：这个 `2.8` 是**粗略范数和的估计**，但它在**第一个分块步**才可算；在交叉点，`V_k` 是迭代后的有效作用量，**不显式**。所以"算得更准"不是自由的计算——它就是类保持本身。**循环。**

### 4.2 S（强侧 signed gas）：BL-6

- 需要 `z_{q_c}(q_c) ≤ 1/2`，`q_c∈[1,3/2]`；
- 需要 `c₀>κ`（质量压制）或 `κ_c<1`（符号相消）；
- **断点**：BL-6——4D 非阿贝尔纯 YM 无可加缺陷荷、强耦合 `κ_c=1`。数值：`κ_c` 不可直接测，代理是 Gaussian 尾。

### 4.3 pushforward（下界单独输运）：供给端

- 输运**真**（§9.1：方差不等式，无上界）；
- **断点**：只走细→粗，供给必须在最细端；最细端的隙是格点隙 `~ma`（指数小），供给它就是原问题；且升到欧氏隙走 Zegarlinski = NA-1，被 OB-1 判循环。

**三条都不通，且不通的原因各自独立**：W 是"有效作用的显式性/上界"，S 是"符号结构"，pushforward 是"供给方向 + 循环"。**这正是一张障碍地图。**

## 5. 若真要动它，唯一的具体子目标

在三条断点里，**W 的断点最"工程化"**：不是"机制不存在"，而是"常数差 3 倍 + `V_k` 不显式"。所以唯一具体的子目标是：

> **找一个不依赖 `V_k` 显式的、对有效作用量 Hessian 的*下界*（不是上界），在交叉点直接成立。**

这可以走两条：

1. **数值 + 严格**：在已有格点数据上，对**分块后**的有效作用量估 Hessian 的下谱（项目已有 `κ_eff` 代理，但那是微观作用量）；若分块后下谱 `< 0` 稀少/被 Gaussian 压住（`R₄` 小、缺陷分数 = Gaussian 尾已经暗示），则下界可能成立。**这是可计算的，但不是证明。**
2. **解析**：用分块映射的**单调性**（§9.1 的 pushforward 是上界方向的反面）：若分块使 Hessian 下界**不降**，则交叉点的下界 = UV 的下界，而 UV 有 Balaban。**但 §9.1 只给了 PI 的输运，没给 Hessian 下界的输运**（Hessian 下界在 marginal 下会降，见 Brascamp–Lieb 的反例：`c → c−1/c`）。所以这条需要新的结构。

**我不声称这两条能成。** 第二条尤其可能与"下界不能单独输运"直接冲突（§9.1 的 `c−1/c` 反例）。第一条是数值，不是证明。

## 6. 诚实的账

**本项目现在有什么：**

- 一个**机器验证**的条件定理（`clay_of_inputs`）；
- 一个**8 条路径 + 3 个架构 + 25 条路径**的障碍地图（每条有判据）；
- 一个**精确的最小目标**（一个尺度、一侧、任何 `δ>0`）。

**本项目没有什么：**

- 没有降低质量隙的难度。**归约链闭合后，剩余的核心就是质量隙本身。**

**一句话：**

> **交叉点证书不是"项目的下一个任务"，它就是 Clay 问题。** 项目能做的、也已经做到的，是把"要证什么"压到最简（§8）、把"为什么每条路都不通"写成可判定的地图（§4）。**再往前，需要的不是更多会话，是一条新的数学。**
