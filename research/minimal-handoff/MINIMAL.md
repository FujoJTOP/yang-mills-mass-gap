## 0. 定理与三处删除

**定理（最小）。** 设 `G` 紧、连通、单连通单李群。若下列成立：

| | 输入 | 内容 |
|---|---|---|
| **M1** | 存在 | 沿 RT 存在测度极限 `μ`，满足 OS0–OS3（正则、平移、`O(4)`、反射正性） |
| **M2** | 非平凡 | `μ` 非高斯，`g_ren/Λ > 0` |
| **M3** | 弱证书 | `∃ μ_w, δ_W>0`：`∀ μ ≥ μ_w`，`cert μ ≥ δ_W` |
| **M4** | 强证书 | `∃ μ_1, δ_S>0`：`∀ μ ≤ μ_1`，`cert μ ≥ δ_S` |
| **M5** | 重叠 | `μ_w ≤ μ_1`（⟺ `q_1 ≤ q_0`） |
| **M6** | 桥 | `∀ μ > 0`，`cert μ ≤ Δ/Λ` |

则 `Δ/Λ ≥ min(δ_W, δ_S) > 0`。

**机器验证**：`YMStatement.Conditional.clay_of_inputs`（[Conditional.lean](../../lean/YMStatement/Conditional.lean)）。注意它**已经是** m-only 版本：`ClayInputs` 里没有 `σ`，唯一性只是 `clay_of_inputs_with_prose` 的**未使用**参数。

**相对现定理删掉了三样：**

1. **σ / 面积律**（R1）——Clay 不要求禁闭；
2. **唯一真空作为输入**（R2）——`Δ>0` 蕴含它；
3. **NPB 的全余项**（R3）——换成一侧符号条件，且证明这是充分的。

**没删掉、也删不掉的：** M3、M4（交叉点）、M6（桥）。

> **§8 的修正（比上面更强）：** M3 与 M4 **不需要同时成立**，也**不需要对所有 `μ` 成立**——**一个尺度上的一个证书就够**。M3/M4 是**二选一**。这不是猜测：`mass_gap_of_certificate` 只在 `μ=1` 取一次 `cert`，`handoff_gap` 在 `μ=1` 只用 W 或 S **之一**。见 §8。

## 2. R2：唯一性不是输入（标准谱论）

**主张**：`Δ>0` ⟹ 真空唯一；故 M1 只需**一个**极限点，不需要"极限唯一"。

**证明.** 设物理 Hilbert 空间 `H`，转移矩阵 `T` 自伴、`0 ≤ T ≤ 1`、`TΩ = Ω`、`‖Ω‖=1`，隙 `Δ>0` 即 `spec(T) ∩ [e^{−Δ}, 1) = ∅`（离散步）。若 `Ω' ⊥ Ω` 也是 `T` 的本征向量且本征值 `1`，则 `1 ∈ spec(T)∩[e^{−Δ},1)`，矛盾。故 `T` 在 `1` 处的本征空间一维，真空唯一。∎

**极限点**：Clay 要"**一个**理论存在"。沿 RT 取一个收敛子列即得一个极限点；不需要所有子列同极限。故 M1 只需存在性，不需要唯一性。

> 诚实注：唯一性在 OS 重构里通常会**跟着** `Δ>0` 一起出现，所以它既不是额外假设，也不需要单独证。把它从输入表里删掉是**记账更干净**，不是数学上的新步骤。

## 3. R3：NPB → 一侧符号条件（真·约化）

### 3.1 陈述

记 `t_up(λ)` 为耦合从 `λ_c` 流到 `λ` 所需的 RG 时间：

```
t_up(λ) = ∫_λ^{λ_c} dλ' / (−β(λ')) ,        0 < λ ≤ λ_c ,   β < 0 .
```

两圈流给出闭式 `t_up^{2L}(λ) = C_RG/λ − (51/121)·ln(1 + 121 C_RG/(51λ))`。

**引理 R3.** 若

```
(SIGN)   β(λ) ≤ β_{2L}(λ) < 0     对一切 0 < λ ≤ λ_c ，
```

则 `t_up(λ) ≤ t_up^{2L}(λ)` 对一切 `0 < λ ≤ λ_c`。

**证明.** 由 `(SIGN)` 得 `−β(λ') ≥ −β_{2L}(λ') > 0`，故

```
1/(−β(λ')) ≤ 1/(−β_{2L}(λ'))     对一切 λ' ∈ [λ, λ_c] 。
```

两边在 `[λ, λ_c]` 上积分即得。∎

（闭式 `t_up^{2L}` 是 `1/(−β_{2L})` 的原函数，这是微积分核对；`Conditional.lean` 的 `tUp2` 已定义该闭式。）

### 3.2 为什么这是"更简单的目标"

现输入 NPB 是**双侧定量界**：`|β − β_{2L}| ≤ C₃λ⁴`。R3 表明**只需一侧**：

```
β ≤ β_{2L}        （"3 圈及更高项只加速流"）
```

- **不要余项常数 `C₃`**；
- **不要精确的 2 圈系数**，只要"真流不慢于 2 圈流"。

这是**目标**的约化（从"估余项"到"定符号"），**不是难度**的消除：`(SIGN)` 仍是未证的非微扰命题——它排除的是 `β` 在 `0<λ≤λ_c` 有零点、拐点或 IR 不动点（[REPORT.md:183](../handoff-proof/REPORT.md:183) 的证伪测试 (ii)）。

**机器化**：`research/minimal-handoff/MinimalHandoff.lean` 的 `rgTime_le_of_beta_le` 证明的正是上面的积分比较（`intervalIntegral.integral_mono_on` + `one_div_le_one_div_of_le`）。

## 4. R4：隙 → 衰减（换表述，不换目标）

### 4.1 陈述

**引理 R4.** 设 `H`、`T`、`Ω` 如上。设 `{O_i}` 是规范不变局部算子的**生成集**（Reeh–Schlieder：`{O_i Ω}` 在 `H` 中稠密）。若存在 `ρ ∈ [0,1)` 与 `C_i ≥ 0`，使对一切 `i`、`n ≥ 0`，

```
| ⟨O_i(0) O_i(n e_t)⟩_c | ≤ C_i ρ^n ,
```

则 `Δ ≥ −ln ρ`。

**证明（谱表示）.** 连通两点函数

```
⟨O(0)O(n e_t)⟩_c = ⟨Ω, O T^n O Ω⟩ − ⟨Ω, O Ω⟩² = ∫ z^n dν_O(z) ,
```

其中 `ν_O` 是 `spec(T) ∩ [0,1]` 上的有限正测度，且 `ν_O({1}) = 0`（连通性减掉了真空）。若 `ν_O` 在 `(ρ,1)` 上有质量，取 `z₀ = sup(supp ν_O) > ρ`；则 `|∫ z^n dν_O| ≳ ν_O(近 z₀ 的块)·z₀^n`，衰减慢于 `ρ^n`，与界矛盾（大 `n`）。故 `supp ν_O ⊂ [0,ρ]`。于是 `O`-通道的隙 `≥ −ln ρ`。

由 `{O_i}` 生成：任一 `ψ ⊥ Ω` 有 `⟨ψ|O_i|Ω⟩ ≠ 0` 对某个 `i`，故其能量 `≥ −ln ρ`。全隙 `Δ ≥ −ln ρ`。∎

### 4.2 为什么这重要

现输入要证的是 `cert μ ≥ δ_W`，而 `cert` 被 `M6` 解释为 **`Δ/Λ` 的下界**。R4 说明：

> **不必直接证隙；证一组可观测量的两点函数一致衰减即可。**

这**不弱化**目标（在 OS 理论里两者等价），但**改变证明义务**：从"控制整个有效作用的范数"变成"控制一组关联函数"。RG / cluster 方法天然产出后者。

**注意**：`ρ` 必须对 `i` **一致**、对格距 **一致**（连续极限）。这是 R4 的真实前提，不是免费的。

## 5. 最小证书目标：下界 vs 上界

这是本轮**唯一的新观察**，也是最能解释"墙在哪"的一条。

### 5.1 证书只需要下界

在尺度 `μ` 的有效作用量 `S_μ` 上，若

```
(H⁻)      S_μ'' ≥ c₀ m_μ²        （Hessian 下界）
```

则传播子被 `(c₀ m_μ²)^{-1}` 控制，两点函数衰减率 `≥ c₀^{1/2} m_μ`，即 `cert μ ≥ c₀^{1/2} q_μ`。

**证书（M3/M4）只需要 `(H⁻)`。**

### 5.2 类保持还需要上界

`skeleton` 的引理 5–6（[CPBW-skeleton.md:15–16](../handoff-proof/CPBW-skeleton.md:15)）要的是**双侧**：

- **下界** `S_{k+1}'' ≥ c₀m² − Cε` —— 给**非退化**（证书）；
- **上界** `‖V''‖_{C²,R} ≤ ε` —— 给**收缩**（叠加、迭代）。

引理 6 的墙（`‖V''‖ ≈ 2.8 > c₀`，`q~1`、`g²~2`）是**上界**侧的墙。

### 5.3 由此得到的新子问题

> **能否只用下界 `(H⁻)` 迭代，而不需要上界？**

若有效作用量在**分块后**（尺度 `μ_w`）是**一致凸**的——曲率 `≥ c₀m²`——则 `(H⁻)` 直接给出证书。项目已有的**数值**（分块后 `R₄` 小、缺陷分数等于 Gaussian 尾，[STATUS.md](../lattice-cpb/STATUS.md)）正是"分块后近 Gaussian、近凸"的**直接证据**，尽管不是证明。

**但这不消除迭代问题**：要到达尺度 `μ_w`，仍需从 UV 走下去，而"走下去"用到了上界。所以 5.3 是一个**真正的子问题**，不是已解。

**可判定的形式**：证明分块映射**保持** `(H⁻)`（下界只增不减或退化可控）。若成立，引理 6 的上界墙**不再挡证书**，只挡"误差估计"。这是本轮能提出的最锐的降墙方向。

## 7. 诚实的账

**减掉了：**
- σ / 面积律（R1，逻辑删除，Clay 不问）；
- 唯一性作为输入（R2，`Δ>0` 的推论）；
- NPB 的全余项（R3，证明符号条件充分）；
- 直接证隙的义务（R4，可改为证一致衰减）。

**没减掉：**
- **交叉点**（M3\*）：无论怎么表述，`λ≈7` 处都要一个非微扰控制；
- **强侧活动度**（M4\*）：BL-6 不变；
- **桥**（M6）：第五条假设不变。

**数字上仍是常数差距：** `C_cum` 2 vs 1.6（25%）；`V''` 2.8 vs `c₀`（约 2–3 倍）。**这是方法差距，不是逻辑差距**——所以"最小定理"能减掉记账，减不掉墙。

**一句话：**

> **最小手递定理把输入从"十件"压到"六件"，删掉的三件不是 Clay 要的；但剩下的三件（M3\*、M4\*、M6）一件都没变轻。项目此前不是"对 W/S 要求过高"，而是"把 Clay 没要的东西也写进了结论"。**

## 8. 真正最小：一个尺度、一侧

### 8.1 定理

**定理（单尺度）。** 设存在 `μ₀ > 0` 与 `δ > 0`，使

```
(S)   δ ≤ cert μ₀      且      cert μ₀ ≤ Δ/Λ 。
```

则 `Δ/Λ ≥ δ > 0`。

**证明.** 传递。`δ ≤ cert μ₀ ≤ Δ/Λ`。∎

### 8.2 为什么现定理强得多

读 `mass_gap_of_certificate`（[Handoff.lean:74–80](../../lean/YMStatement/Handoff.lean:74)）：

```
have h1 : min δ_W δ_S ≤ cert 1 := handoff_gap … 1 zero_lt_one
exact le_trans h1 (hcert 1 zero_lt_one)
```

它只在 **`μ = 1`** 取 `cert`、`hW/hS`、`hcert`。而 `handoff_gap` 在 `μ = 1` 的 `by_cases` 中**只用 W 或 S 之一**。

**所以：**

- `hW` / `hS` 的 `∀ μ` 量化**不需要**——只用其中一个在 `μ = 1` 的值；
- **W 与 S 不需要同时成立**——只看 `μ = 1` 落在哪一侧；
- **重叠 `q₁ ≤ q₀` 也不是必需的**——它只是用来从边界推出 `q₁ ≤ q(μ)`；若在 `μ₀` 直接给定 `q₁ ≤ q(μ₀)`（用 S），或 `gsq μ₀ ≤ gsq μ_up`（用 W），就不需要它。

**机器化**：`MinimalHandoff.lean` 的 `min_le_of_one_certificate` 与 `gap_of_one_certificate`（公理冻结）。

### 8.3 一个必须承认的限定

单尺度证书的 `μ₀` **不能随便选**。证书 `cert μ` 是 `Δ/Λ` 的下界，而 `Δ/Λ` 是**物理**数。在深度 UV（`λ→0`），理论还没有质量尺度，尺度 `μ` 的分析给的是**格点隙 `~1/a`**，不是 `m/Λ`——那会违反 `(M6)`（`cert ≤ Δ/Λ`）。

**有意义证书的尺度**必须落在质量已经被生成的地方：**IR 或交叉点**。所以：

> **§8 减掉的是"对所有尺度的一致覆盖"，不是"交叉点"。** 交叉点仍然要在**某一个**尺度上被攻下。

### 8.4 战略后果

因为只需**一侧**：

- **BL-6 关闭了 S**（无可加缺陷荷）⟹ **S 可以整条放弃**，不必与 W 并列；
- 只剩 **W 在一个尺度上**（交叉点 `λ≈7`）。这就是最小的临界路径。

这直接回答了你最初的问题：**不是"对 W/S 要求过高"，而是"要求 W 和 S *同时*、*对所有尺度*成立"过高——实际只需要**一个**、在**一个**尺度上。

## 9. 子问题的答案：下界单独迭代

**问题**：能否只用 Hessian **下界** `(H⁻)` 迭代，而不需要上界 `‖V''‖ ≤ ε`？

**答案：能，但只对"输运"，不对"供给"。** 分两部分。

### 9.1 输运：pushforward 单调性（真定理，不需要上界）

设细尺度 Gibbs 测度 `μ` 满足 Poincaré 不等式 `PI(c)`：

```
Var_μ(g) ≤ c · E_μ[|∇g|²]          对一切 g 。
```

粗尺度测度 `ν = B_# μ`（分块平均 `B` 的 pushforward，这正是 RG 一步的精确测度）。对粗尺度函数 `f`，取 `g = f∘B`：

```
Var_ν(f) = Var_μ(f∘B) ≤ c · E_μ[|B^T ∇f|²] ≤ c · ‖B^T‖² · E_ν[|∇f|²] 。
```

故 `ν` 满足 `PI(c‖B^T‖²)`。在物理归一化下 `‖B^T‖² = O(1)`（块平均的伴随是保范的，格距账在物理单位里抵消），于是

> **粗尺度的 PI 常数 ≤ 细尺度（乘 O(1) 常数）⟹ 隙不降。**

**关键：全程只用 `c`（下界），没有出现 `‖V''‖` 的上界。** 所以"下界单独输运"**是存在的**，而且是一行方差不等式（Brascamp–Lieb 型）。

### 9.2 供给：不给，且方向错

但 `PI(c)` 必须**在某一端被供给**：

1. **方向**：pushforward 只走**细 → 粗**。所以要供给在最**细**的一端；而最细端的隙是格点隙 `~ma`（指数小），供给它就是原问题。
2. **对象**：被输运的是 **Gibbs 测度的 PI**（虚构时间/Glauber 谱隙）。把它升到**欧氏**质量隙需要 Zegarlinski 型桥——这是项目的 **NA-1**；而 NA-1 的供给被 **OB-1** 判为循环（全局可和性前提 ≈ 目标）。

所以：

> **下界单独迭代 = NA-1 的输运语言。输运免费，供给循环。**

### 9.3 与 §8 合起来

既然 §8 说**一个尺度**就够，pushforward 的"输运"**不是定理必需的**——它只是**证明某个尺度证书**的一种技术。而它把供给推到最细端，恰好是最难的一端。

**所以子问题关闭：**

- **输运存在**（pushforward，真定理，无上界）；
- **供给不给**（方向 + OB-1）；
- **且不需要**（§8 单尺度即可）。

**一句话：引理 6 的上界墙不是"输运墙"，是"供给墙"。换掉输运方式（pushforward）不影响它；换掉供给方式（在交叉点找一个不依赖上界的证书）才是唯一的方向。**
