# 弱→强耦合 RG 交接：控制量的独立判断

> 2026-11-22 · 范围：纯 Yang–Mills₄。存在性已条件化于 16 输入；目标 MG（体积一致、标号一致的指数聚类速率）。

## 0. 结论摘要（≤300 字）

控制交接受 **RG 不变的关联长度比** `q(μ) := m(μ)/μ = a/ξ_phys = 1/(μξ)` 支配，**不是** `g²(μ)`。理由：(i) `g²=O(1)` 的穿越点随 scheme `g'²=g²+cg⁴` 平移 `c`，不是不变量；`q` 是物理尺度之比，scheme-无关。(ii) `q` 是两侧共同的天然参数——弱侧 `q≪1`（`μ≫m`，Balaban 展开），强侧 `q≳1`（`ξ~a`，polymer/Dobrushin 强耦合格点），且 `q` 严格单调、在 `μ=m` 唯一穿越 1。(iii) 交接判据化为**不变量不等式 `q₀ ≥ q₁`**（`q₀ = q` 在弱侧有效域边界之值，`q₁` 为强侧边界），其成立与否正是公开难点。`g²(Δ)~O(1)` 与"交接点 = 质量隙标度 `μ~m~Λ`"在量纲 transmutation 下都对，但**不变量表述是 `q(Δ)=1` 而非 `g²=1`**。有限体积 `Δ(n)` 是 MG 的 certificate / Lean 陈述，不是控制参数。

## 1. 候选逐项评估

| # | 候选 | Scheme 依赖 | 单调性 | 两侧可计算性 | 直接服务 MG？ |

**要点**：候选 1、6 只在弱侧有意义；5 只在强侧/有限体积有意义；只有 **2（等价地 3 的不变比率）跨越两侧且 scheme-无关**。

## 2. 推荐方案与公式

**一圈**（SU(N)，`b₀=11N/(48π²)>0`）：`β(g)=−b₀g³+O(g⁵)`，
`1/g²(μ)=1/g²(μ₀)+2b₀ ln(μ/μ₀)`，即 `g²(μ)=1/(2b₀ ln(μ/Λ))`，`Λ=μ₀e^{−1/(2b₀g²(μ₀))}`。

**Scheme 变换** `g'²=g²+cg⁴+O(g⁶)`：
- `b₀` 不变；`Λ'=Λe^{c/(2b₀)}`（纯乘性 rescale，故 `Λ` 在单 scheme 内 RG-不变、跨 scheme 协变）；
- `g²=1 ⟺ g'²=1+c`，故 **`μ*:g²(μ*)=1` 不是不变量**；而 `m/Λ`、`√σ/Λ`、`q=a/ξ` 不变。

**质量/关联长度**：取 `m(μ):=1/ξ(μ)`（尺度-μ 有效两点函数指数衰减率；纯 YM 无裸质量，这是唯一合法定义）。RG 方程 `μ dm/dμ=−γ_m(g²)m`，质量相关 ⟹ `0<γ_m<2`（物理上 `0<γ_m<1`）。则 `q=m/μ ∝ μ^{−(1+γ_m)} → 0 (μ→∞)`，且 `dq/dμ=−(1+γ_m)m/μ²<0`，**`q` 随 `μ` 减小严格递增**，在 `μ=m` 唯一穿越 1。

**交接判据**：弱侧半径 `g*`（固定小量），`μ_up` 为 `g²(μ_up)=g*²` 之唯一解，
`q₀ := q(μ_up) = m/μ_up = (m/Λ)·e^{−1/(2b₀g*²)}`；强侧 `q≥q₁`（`q₁=O(1)`）。
**重叠 ⟺ `q₀ ≥ q₁`**。`q₀,q₁` 是**逐方法固定的纯数**（scheme 变换下 `e^{±c/(2b₀)}` 与 `m/Λ` 的逆变换相消），与 `g²=1` 之位置不同。

**量纲 transmutation**：唯一标度 `Λ`，`m=c·Λ`（`c` 为 scheme-无关纯数）。于是 `q=1 ⟺ μ=m=cΛ ∥ g²~1` 同址——**"交接点=质量隙标度"成立**。但"`m/Λ` 是否足够大以容下两侧半径"= 「`q₀≥q₁` 是否成立」，这才是**非循环**内容；`q` 本身因含未知 `m` 而回路，故它是**坐标**而非独立自由参数。

## 3. 可形式化陈述草案（交接引理 + MG）

**数据**：`q:(0,∞)→(0,∞)` 连续；`g²:(0,∞)→(0,∞)` 由 `1/g²(μ)=2b₀ln(μ/Λ)` 给出（严格↓，`g²(Λ⁺)=∞`，`g²(∞)=0`）；`cert:(0,∞)→ℝ` 是**无量纲证书函数**：`cert(μ)` 表示"由尺度-μ 分析所证明的、对同一个数 `Δ/Λ`（证书换成弦张力时是 `√σ/Λ`）的下界"，语义上恒有 `cert(μ) ≤ Δ/Λ`。**类型注记（R0）**：`cert(μ)` 不是"尺度 μ 处的物理隙"；后者带量纲、在 `μ→∞` 时按 `Δ/μ→0` 衰减，若写成 `cert(μ)≥δ_W>0` 会与"物理质量固定"矛盾。`μ` 只决定"哪套分析可用"，不改变被下界的那个数。

**假设**
- (H0) `q` 严格递减且 `q(∞)=0`（UV：质量相关，`q→0`）。
- (H1) [weak] `∃ g*,δ_W>0`：`g²(μ)≤g*² ⟹ cert(μ)≥δ_W`。
- (H2) [strong] `∃ q₁,δ_S>0`：`q(μ)≥q₁ ⟹ cert(μ)≥δ_S`（**一直延伸到 IR**，`μ→0`）。
- (H3) [overlap，**待证**] `q₀:=q(μ_up) ≥ q₁`，其中 `μ_up:= (g²)^{-1}(g*²)`。

**结论**（纯实分析，可机器检验）：
1. 弱域 `{μ:g²(μ)≤g*²}=[μ_up,∞)`；强域 `{μ:q(μ)≥q₁}=(0,μ*]`，`μ*:=q^{-1}(q₁)` 存在唯一（IVT + 严格单调）。
2. (H3) ⟺ `μ_up≤μ*`；于是 `[μ_up,∞)∪(0,μ*]=(0,∞)`：**每个尺度都被覆盖**，在重叠 `[μ_up,μ*]` 上两侧同时有效。
3. 故 `∀μ>0: cert(μ) ≥ min(δ_W,δ_S) > 0`，从而 `Δ/Λ ≥ min(δ_W,δ_S) > 0`（无量纲，量纲自洽）。
4. 沿 RG 传输到固定物理盒子，得到与截断无关的下界 `m_*>0`，即 **MG**：`∃m_*>0, ∀L, |⟨O(x)O(y)⟩_L^c| ≤ C e^{−m_*|x−y|}`。

**证书参数化（与 gluing 契约对齐）**：本引理对所有标度比型证书同构——`m→√σ` 即可用于面积律，只需把 `Δ/Λ` 换成 `√σ/Λ`、`q` 换成 `√σ/μ`。`I-HANDOFF[m]` 与 `I-HANDOFF[σ]` 必须共用同一个 RT、同一组 `Λ` 归一，并同时满足各自的 `H3`（gluing 契约 GL7）；否则"胶球有隙"与"弦有张力"会落在不同理论里。

**形式化警示（契约层）**：`cert` 在 Lean 签名中**必须保持为 `μ` 的函数**。若把它塌缩成单个常数 `gapBar : ℝ`（gluing 报告 §2.7 的示意签名如此），则 `H1`/`H2` 各自已经直接给出 `gapBar` 的下界，`H3` 变成不参与结论的空假设，"两域覆盖全尺度"的论证随之消失；再加 `hgapPos : 0 < gapBar` 作假设，则整个定理近似同义反复。正确签名：`cert : ℝ → ℝ`、`H1 : ∀μ, g²(μ)≤g*² → δ_W ≤ cert μ`、`H2 : ∀μ, q₁ ≤ q(μ) → δ_S ≤ cert μ`、结论 `∀μ, min(δ_W,δ_S) ≤ cert μ`，再用证书语义 `∀μ, cert μ ≤ Δ/Λ` 收尾。

**非循环性**：(H0)(H1)(H2) 是各侧分析（Balaban 弱侧误差界；polymer/Dobrushin 强侧）的定量输出；(H3) 是真正缺口，且**scheme-无关**。若 (H3) 反向（`q₀<q₁`）则重叠为空——正是公开难点。

## 4. 文献与风险

**严格 RG 实际用的控制参数**（均为**区域局部**的耦合，无人跨过 O(1)）：
- Balaban 多尺度：逐尺度的 running/effective coupling `g²(μ)`，有效作用量锁在"小场类"；到 UV 稳定即止，**未到 IR、未触 O(1)**。〔"Ultraviolet stability…", CMP 102 (1985) 255–275；"Large field renorm. I", CMP 122 (1989) 175–354；YM 系列 CMP 1984–85，卷号部分未核实〕
- Bauerschmidt–Brydges–Slade / Bauerschmidt–Slade（4D `φ⁴`）：控制=高斯不动点附近跑动四次耦合+质量相关方向，给出对数修正。〔BBS 书 LNM 2242 (2019)，DOI 10.1007/978-981-32-9593-3；arXiv:1403.7424、1403.7422、1403.7268；Bauerschmidt–Slade–Tomberg–Wallace arXiv:1511.02790〕
- Bauerschmidt–Bodineau–Dagallier（Polchinski flow / multiscale Bakry–Émery）：控制=逐尺度有效势/曲率；U(1) `d=4` 格点规范得 uniform LSI（弱耦合）。〔BBD 综述 arXiv:2307.07619, Probab. Surveys 21 (2024)；Bauerschmidt–Dagallier `φ⁴₂/φ⁴₃` arXiv:2202.02295、2210.13487；U(1) 规范文 **arXiv 号未核实**〕
- Chatterjee（Dobrushin 唯一性）：控制=`β` 小（强耦合），得 mass gap；**Dobrushin ceiling 明确到不了弱耦合**。〔Gauge Theory 讲义 Ch.15–16，年份/版本未核实；Osterwalder–Seiler, Ann. Phys. 110 (1978) 440–471〕
- Shen–Zhu–Zhu / Cao–Nissim–Sheffield（Langevin / Bakry–Émery）：控制=`β` 小、't Hooft 区；得 mass gap+面积律，弱耦合开放。〔SZZ arXiv:2204.12737, CMP 400 (2023) 805–851；CNS arXiv:2505.16585、2509.04688；Cao–Park–Sheffield arXiv:2307.06790〕
- 物理方案：gradient-flow 耦合 `g²_GF(t)=4π²/3·t²⟨E⟩`，`μ~1/√(8t)`，非微扰全尺度可定义〔Lüscher arXiv:1006.4518, JHEP 08 (2010) 071〕；`σ/Λ²`、Creutz 为不变比率。

**结论性判断**：文献**实践上**用区域局部的耦合（弱侧 `g²`、强侧 `β`）作控制参数，**从未跨过 O(1)**——这正是开放问题；不变量匹配量（本文的 `q`）在强耦合学派口中就是 `ξ/a`，但尚无严格 crossover。

**风险 / 诚实说明**：
1. `q` 的单调性/`q(∞)=0`（质量相关）**本身是 RG 内容**，须在两侧分别证明，故作为引理假设而非公理。
2. 纯 YM 无裸质量，`m(μ)` 必须用有效关联长度定义；勿与 QCD 夸克跑动质量混淆。
3. 本报告的 `c=m/Λ`、`q₀,q₁` 数值**未给定**——决定 `q₀≥q₁` 需具体展开半径，属未解。
4. 2026 年 hexagonmath / ai.vixra 类预印本（含 2610.00341、2602.0054 已撤回）AI 参与度高、venue 可疑，仅作线索，**不作依据**；`Δ(n)` 模板源自项目 `docs/yang-mills-prior-work.md` §3.2 所述 OpenAI sigma-model 工作。
