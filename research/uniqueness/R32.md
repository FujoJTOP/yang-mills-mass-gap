## 1. 两个陈述（量词结构、强度）

固定：$G=SU(N)$（故 $h^\vee=N_c=\dim f$，两套变量重合；一般 $G$ 的测度用 $N_c$、RT 用 $h^\vee$，见 `REPORT.md` §1.1），$a\downarrow0$ 沿渐近自由轨迹（固定物理点），盒 $\Lambda_p\uparrow\mathbb R^4$（体积指标 $p$）。$\mu^{(p)}$ 为固定 $p$ 的连续极限；$\mu_\infty^{(k)}$ 为子列 $p_k$ 的无限体积弱极限。

### 1.1 U1 = U-FULL（全唯一）

$$
\mathbf{U1}:\quad \forall\ \text{两正规化 } \mathcal R_1,\mathcal R_2\ (\text{格距/作用量/取向/子列}),\quad
\mu_\infty(\mathcal R_1)=\mu_\infty(\mathcal R_2).
$$
等价地（仅子列、固定正规化）：$\forall$ 两严格增体积序列 $p,q$，其子列极限相同；**再**对正规化类取全称。

**注意顺序**：构造只给"固定 $a$ 的 $L_p$ 极限、再沿子列"。故 U1 必须写成
$$
\forall \text{ 子列 } \{p_k\}, \{q_k\}:\ \lim_k \mu^{(p_k)}=\lim_k \mu^{(q_k)}\quad(\text{无论极限是否存在，若存在则相等}),
$$
而不是"极限存在且唯一"（后者更强、需先证收敛）。hexagonmath Thm 6.4 给的是**每个**子列都有极限（Arzelà–Ascoli + 对角抽取），U1 要的是"这些极限全相等"。

### 1.2 U2 = U-ROT（逐极限旋转不变）

$$
\mathbf{U2}:\quad \forall R\in SO(4),\ \forall\ \text{子列极限 } \mu_\infty:\quad R_*\mu_\infty=\mu_\infty.
$$

**观察（关键）**：平移不变已由 L1 给出（$a\mathbb Z^4$ 稠密 + 双极限），点群 $W\subset O(4)$ 已由 L2 给出（有限群、连续作用）。故
$$
\mathbf{U2}\ \Longleftrightarrow\ \text{每个子列极限满足 OS2（}\mathbb R^4\rtimes O(4)\text{ 不变）}.
$$
即 **U2 ≡ OS2-per-limit**。这就是 E1。

### 1.3 强度关系

- **U1 ⇒ U2**（在"旋转格点是合法正规化"的闭包下，R28）：取 $\mathcal R_1=$ 标准格、$\mathcal R_2=R$ 旋转格。R28：旋转格极限 $=R_*\mu_\infty$（自动推前，因 $B a\mathbb Z^4=R(5a\mathbb Z^4)$）。U1 令二者相等 ⇒ $R_*\mu_\infty=\mu_\infty$。∎
- **U2 ⇏ U1**：两个不同的旋转不变相（不同理论、或不同子列落到不同旋转不变极限）都满足 U2，破坏 U1。∎
- 所以 **U2 < U1**（严格）。U2 是 OS2 的**最小**目标；U1 是"唯一理论"的目标。逐步追问的正确最小化：**为 OS2 只需 U2；为 Clay 陈述（唯一理论 + 隙）最终仍需 U1。**

## 2. 2D 的致命步骤（逐条核对 `NPSYM.md` §7.4）

> `NPSYM.md §7.4` 列了 4D 缺失的四处 2D 特性。**os2 已回并给出源码逐字**：Lemma 3.8 = `lem:dense-periods`（"Two scale relations force constancy"），commit `adc7f12…`，`preprints/…-O3-model-October-4-2026/build/sections/uniqueness.tex`。**它是 rigidity（刚性）引理，不是"RG 唯一不动点"。**

**Lemma 3.8 的精确内容（os2 逐字要点）**：$L>1$ 为 2 的幂、$\gamma>0$、$I=(-R,R)$；$\ell:I\to(0,\infty)$ 连续，$s\mapsto G_s$ 为分布层级（对每个 Schwartz 测试连续），$O_\pm$ 为 $\pm\vartheta$ 旋转（$\cos\vartheta=\tfrac35,\sin\vartheta=\tfrac45$）。若两**精确**关系
$$
\underbrace{G_{s-\gamma}=G_s,\ \ \ell(s-\gamma)=L^{-1}\ell(s)}_{\text{eq:uni-depth}},\qquad
\underbrace{G_{s+d}=(O_+^{-1})_*G_s=(O_-^{-1})_*G_s,\ \ \ell(s+d)=5^{-1}\ell(s)}_{\text{eq:uni-incline}}
$$
在偏移均落 $I$ 处成立，且 $2R-|d|>\gamma$，则**每个 $G_s$ 欧氏旋转不变，且 $G_s$ 与 $s$ 无关**。
- **结论是两个合取**（旋转不变 + $s$-无关）；**假设只有**两精确关系 + 连续性 + 重叠 $2R-|d|>\gamma$；**无任何不动点假设**。
- 其"唯一性"是**沿 shape/offset 族的唯一性**，**不是**路线 C 的 U1。**(3.8)（eq:uni-incline）为精确恒等式、无余项**；唯一动力学输入是 Proposition offset-limits（同一 $s+d$ 偏移的倾斜极限 = 普通极限经 $O_\pm^{-1}$ 推前，间距 $L^{-N}/5$、空间嵌入精确）。

2D 骨架：由 (3.8) 两式（$O_+,O_-$）得 $G_s$ 在 $O_+O_-^{-1}=\mathrm{Rot}(2\vartheta)$ 下不变，$\langle\mathrm{Rot}(2\vartheta)\rangle$ 稠密于 $SO(2)$ + 连续性 ⇒ 全 $O(2)$；(eq:uni-depth) + 连续性 ⇒ $s$-无关。

## 3. 收缩路线判定（主 session 任务 3）

### 3.1 RG2–RG4 的原文与它实际给出的东西

- **RG2（源文 Assumption 5.3）**：存在 $\kappa\in(0,1)$、$K>0$、$\eta>0$、$2b_0\log3>K/\eta$，使
  $J_{m+1}\le J_m+K\eta^{m-1}$、$|\lambda_{m+1}-\lambda_m-2b_0\log b_m|\le K\eta^{m-1}$。
  原文解读（第 626–631 行）："**each blocking step contracts irrelevant terms geometrically at one fixed rate $\kappa$**, while the marginal term follows the one-loop logarithmic recursion."
- **RG4（Assumption 5.6，由 RG2+RG3 推出）**：$|C_{N+1,p}(v;f)-C_{N,p}(v;f)|\le A(v,f)\kappa^N$。

**关键判断**：RG2 说"**无关项**按 $\kappa$ 几何收缩"——这是**对的**收缩，但它是**沿一条轨迹把无关项压向 0**（同轨迹，Cauchy），**不是**"两条轨迹的差按 $\kappa$ 收缩"（two-trajectory contractivity）。RG4 是前者的差分级（$C_N$ 与 $C_{N+1}$ 之差），不是后者的 $|C^{(1)}_N-C^{(2)}_N|$。**两者不同：同轨迹 Cauchy 给"每条轨迹收敛"，不给"不同初值收敛到同一点"。** 这正是 hexagonmath §10.5 O1 之所以把"升级"列为缺失输入的原因。

### 3.2 升级判定：能否"两正规化初值差落无关方向 ⟹ 同一极限"？

**结论：这正是 hexagonmath O1(a)，是缺失输入，不在 16 输入内；但结构上最可能，且论文给了 reduction。** 分三步：

- **(a) 前提正确的那一半。** RG2 确实声明"无关项几何收缩"，故**若**能造出一个"两轨迹差"的量并证明它落在无关方向，则 RG2 的收缩确实把它压掉。缺的是"差落在无关方向"这一步。
- **(b) 相关/边缘方向必须匹配。** 两正规化在同一物理点（同 $\Lambda$、同重整化耦合）⇒ 相关/边缘耦合匹配；旋转差位于 dim $\ge6$（§3.3）⇒ 无关。**唯一边缘方向是各向同性耦合，已被匹配。**
- **(c) reduction 已有、可 Lean 化。** 源文 O1："若两体积子列的极限在 **Thm 6.4 的可数指标集** $\mathcal I:=L\sqcup\{K_m\}\sqcup\{\alpha\in\mathbb N_0^4\}$ 上一致，则它们作为核相等（紧集一致连续 + 穷尽）。" 即 U1 的**充分条件**已证、可形式化；缺的只是"在该可数集上一致"这一定量估计。

### 3.3 旋转差是否真的落在无关方向？

**是，但有两处需补，不能只靠 SYM-DIM4。**
- **dim-4：干净。** 标准格与旋转格**都是各向同性**格（旋转不改各向同性），故其有效作用量**无 dim-4 差**。（os2 `SYM-DIM4`：dim-4 $H$-不变对称张量只有 $\propto I$，即各向同性 $\mathrm{tr}F^2$。这比"需避免 dim-4 各向异性"更强：两格根本无 dim-4 差别。）故旋转差从 **dim 6** 起。
- **dim-6 仍需单独分类（主 session 的提醒正确）。** dim-6 **自动无关**（$6>4$），但要把它用作**收缩**，需两点：
  (i) **一致收缩率**：所有由旋转生成的 dim-6 各向异性算符必须落在 RG2 的同一 $\kappa$ 收缩子空间（不能有"慢方向"）；
  (ii) **无 dangerous irrelevant**：dim-6 算符不能通过与 running 边缘耦合（$\lambda_m$ 的对数跑动）混合而获得增强。这需要 dim-6 张量分类（$\ell=4$ 谐波、$D$-$F$ 混合等，`NPSYM §5.3`），而 **SYM-DIM4 只覆盖 dim-4，不覆盖此处**。
- **额外**：旋转差是**形状/取向方向**，需的是 **shape-uniform difference estimate**，与 O1 的 **volume-uniform** 不同——两者是**两条**独立的升级，不是一条。

### 3.4 体积一致在哪一步卡住？

两处，取其一：
- **走收缩路线（RG2 升级）**：卡在**"volume-uniform difference estimate"这一估计本身**——即 $|C^{(1)}_N-C^{(2)}_N|\le A\kappa^N$ 的**两轨迹**版本（RG4 现在只有同轨迹版）。这是 hexagonmath O1 的缺失输入。
- **走 Symanzik 路线（SYM-4D）**：卡在 **SYM-IR**：$a^2$ 系数是 $\int_{\mathbb R^4}d^4x\,\langle O(0);O_k(x)\rangle_c$，其对体积 $L$ 的一致收敛需**一致可积衰减**（指数最好，幂律 $\Delta>2$ 也可，但必须一致）。这是 `NPSYM §5.4` 的 SYM-IR。

**收缩路线比 Symanzik 路线更可能**，因为 RG2 已声明"**uniform in volume**"：若把"收缩无关项"真正做成两轨迹的 volume-uniform 差估计，则**绕过** SYM-IR（直接控制实空间全流，而非只控 $a^2$ 系数）。这正是主 session"最可能的一条"的判断，我认同——但它**仍是缺失输入**（O1(a)），不是 RG2–RG4 的现成推论。
