# 证明杨–米尔斯质量隙的 20 条路径：概率排序

> 2026-11-22 · 与 `SURVEY.md`（8 条，选路用）配套；本文回答"如果目标是**证明**，有哪些路、哪条概率最高"。

---

## 0. 概率标尺（必读，否则表格会被误读）

**P 的定义**：给定一个**专职、有资源、持续十年**的研究计划，该路径在十年内给出 4D 纯 YM 质量隙的**完整证明**的概率。

- 这是**主观判断**，不是统计频率；误差范围很大（每条可上下浮动 2 倍）。
- **没有任何一条接近 80%。** Clay 问题已开放 50 余年，最强的一批人攻过其中的主干路径；任何声称高概率的估计都不诚实。
- 所有路径的 P 之和远大于"任一成功"的概率，因为路径高度相关（共用方法、共用障碍）。
- **"调查单元"（1–4 周能给出确定答案的探针）可以有 >80% 的完成率**——但那是另一回事，见 §4。

---

## 1. 二十条路径

### A. 构造性量子场论 / 重整化群（主线）

**A1. 多尺度 RG + 质量（Balaban 推到 `λ~1` 以外）**
把 Balaban 的 UV 稳定性、大场重整化与小场展开，在**质量真空**而非平凡联络周围重做，使展开参数从耦合变成"耦合 × 对数 × 质量压制"。这是本项目的 `CPB-W`。
`P ≈ 8–12%`。**最高的单条。** 理由：所有结构件都已存在（分块、协方差分解、cluster 界），缺口是**常数**（`C_cum` 差 1.25 倍；`C²` 界差 2.4–3 倍），不是机制。

**A2. Massive 背景场 + Gaussian 计权类（A1 的变体）**
把类从 `C²`-on-ball 换成局部 `L²`（Gaussian 计权），用 `μ_G` 的矩而不是 `sup|V|` 控制非线性项。
`P ≈ 5–8%`。缺口只剩 `C_cum ≤ 1.6` 与一条 `L∞–L²` 插值引理；但标准 cluster 界给 `C_cum ≥ 2`，需要真正的改进。

**A3. 强耦合 signed gas + 精确约束（`CPB-S`）**
把 2D `O(N)` 的"约束 + 指标 ⇒ 符号相消"移植到 4D 非阿贝尔。BL-6 判定：4D 非阿贝尔**没有可加缺陷荷**，中心涡旋作用于带电扇区而质量隙在中性扇区。
`P ≈ 2–3%`。除非发现新荷（见 C11）。

**A4. 函数重整化群 / 精确 RG 不动点**
Wetterich/Polchinski 方程在 4D YM 的近似截断下给出"红外不动点 + 隙"，但没有严格控制；严格化等价于 A1。
`P ≈ 2–3%`。

**A5. 4D 随机量子化**
CCHS 在 3D 成功；4D 的随机量化方程是 marginal（`d=4` 是临界维数），需要先在 4D 构造 UV 极限。
`P ≈ 1–2%`。它先要解决"构造"，而构造本身不低于原问题。

**A6. 双尺度（高/低温）分裂的 cluster 展开**
在高 `β` 用弱耦合类、低 `β` 用 signed gas，在相变点附近用第三种分析拼接。问题：拼接点正是最难的地方。
`P ≈ 1–2%`。

### B. 格点上的严格 / 认证方法

**B1. 有限格点的严格隙 + 严格有限尺寸标度**
在有限 `L` 上用严格界（区间算术、谱方法、转移矩阵）证明隙，再严格外推。障碍：有限格点的隙不蕴含连续统隙，FSS 需要一致控制。
`P ≈ 1–2%`。

**B2. 转移矩阵谱方法（Bachmann–Nachtergaele 型）**
在 1D/2D 有严格下界；4D 的"frustration-free"结构不存在，谱方法的技术前提不满足。
`P ≈ 1–2%`。

**B3. 反射正性 + 红外界（Fröhlich–Israel–Lieb–Simon 型）**
在 2D/3D 有效；4D 中连续对称性的红外界发散（Goldstone），规范理论的中性扇区是否例外未知。
`P ≈ 1–2%`。

**B4. 计算机辅助证明（interval arithmetic + 证明助手）**
把 B1 的每一步做成机器可检验。障碍：需要严格的 FSS 界，而这正是缺的。
`P ≈ 1%`。

### C. 对偶 / 几何

**C1. 随机曲面表示（Cao–Park–Sheffield）+ 曲面张力 ⇒ 隙**
把 YM 写成随机曲面系综；若有正曲面张力且簇展开收敛，可给隙。障碍：4D 非阿贝尔的曲面模型尚未严格建立。
`P ≈ 2%`。

**C2. 中心涡旋 / 对偶超导**
涡旋凝聚给禁闭的唯象图像；严格版本需要涡旋系综的 cluster 展开。
`P ≈ 1%`。

**C3. 规范–弦对偶 / 大 N 弦论**
启发式；无严格定义。
`P ≈ 0.5%`。

**C4. AdS/CFT / 全息**
不严格；且全息给出的是大 N 强耦合的类比，不是 4D YM。
`P ≈ 0.3%`。

**C5. 瞬子液体模型**
唯象；给不出严格的隙。
`P ≈ 0.3%`。

### D. 从其他理论转移

**D1. N=1 超对称 YM → 纯 YM**
Seiberg–Witten 给 N=2 的精确解，N=1 有隙；但转移需要破缺超对称并控制软项。
`P ≈ 2–3%`。

**D2. 大 N 严格结果**
2D 't Hooft 模型可解；4D 大 N 只有形式展开，且物理区与严格大 N 区不相交。
`P ≈ 1%`。

**D3. 3D YM–Higgs（CCHS）→ 4D**
3D 有严格构造；4D 的 marginal 性与各向异性极限是障碍。
`P ≈ 1%`。

### E. 哈密顿量 / 谱 / 其他

**E1. 哈密顿量截断 / 光锥量子化**
数值给谱，但无严格误差控制，且 4D 的截断增长失控。
`P ≈ 0.5%`。

**E2. 张量网络 / MERA（4D 规范）**
无严格结果；4D 的张量网络表示不存在。
`P ≈ 0.5%`。

**E3. Bootstrap / 谱正性 / sum rules**
S-矩阵 bootstrap 给最轻重态的界，但不是证明；且需要假设解析性/多项式有界性，这些在 4D YM 未证。
`P ≈ 1%`。

**E4. 广义对称性 / 反常匹配**
1-形式中心对称性约束相结构，可排除某些无隙相，但不构造有隙相。
`P ≈ 1%`（作为**辅助**手段，不独立）。

## 3. 结论：概率最高的是 A1（及其变体 A2）

**为什么是它：**

1. **它是唯一"所有结构件都存在、只缺常数"的路径。** 分块、协方差分解、cluster 界、Gaussian 参考、Ward 恒等式——全部有。缺口是 `C_cum` 的 1.25 倍与 `C²` 界的 2.4–3 倍，以及一条具名插值引理。
2. **它有最窄的已验证缺口。** `R₄ ≪ 1` 在物理窗口上给出正面证据；`κ_c` 的缺口（W 侧）只有 25%。
3. **它的失败是可诊断的。** 若失败，是因为 `c₀` 太小（张力 `Λ²` 而非 `m²`）或 `C_cum` 真值 ≥2——两者都能用数值判定，不会"不明不白地耗十年"。
4. **其他路径的先验都低一个量级**：对偶路径缺严格模型，转移路径缺 4D 非超对称控制，格点路径缺 FSS 的一致性控制。

**但 8–12% 不是"押它就对了"。** 它意味着：**九成概率，这条路也不通。** 这是这个问题的真实赔率。

## 4. 与"调查单元"的区别（你之前的 >80% 标准）

> **"证明路径"没有 >80%；"调查单元"有。**

| 调查单元 | 完成率 | 它会告诉你什么 |
|---|---|---|
| IMC 单级反演（1 周） | ~90% | 方法是否可行 |
| 中心投影 `z_signed/z_abs`（10² h） | ~85% | `κ_c<1` 是否存在 |
| `m` 阈值 `ξ/a≈1.75` 的验证（10²–10³ h） | ~90% | 能否丢掉 `σ` |
| `κ₃` / 最坏组态（2–4 周） | ~80% | `C_cum` 真值 |

**正确做法不是"选一条 20 条里概率最高的然后猛扎"，而是：先用 3–4 个 >80% 的探针把 A1/A2 的未知数测掉，再决定是否投入 3–18 人月。**

按你之前的标准：**没有一条证明路径满足 >80%，所以"选一条猛扎"本身就是错误策略。** 唯一满足 >80% 的是"探针组合"。
