## 2. GL7 的精确陈述

**GL7（三合一）**：下列三条同时成立。

- **(a) 同一性**：`I-HANDOFF[m]` 与 `I-HANDOFF[σ]` 的证明引用的 `RT` 逐项相同（§1.1 的表）。特别地，两者都陈述在同一个 `μ_{L,a,β(a)}` 上，取同一个子列、同一个极限次序。
- **(b) 数值相交（两次）**：`q₁^m ≤ q₀^m` 与 `q₁^σ ≤ q₀^σ`。
- **(c) 两个证书桥**：`hcert_m`、`hcert_σ`（各为 GL2b 的一个实例），把逐尺度的 `cert_i` 接到同一个物理纯数 `m/Λ`、`√σ/Λ`。

**结论**：在同一个测度 `μ` 上，`Δ/Λ ≥ min(δ_W^m,δ_S^m) > 0` **且** `√σ/Λ ≥ min(δ_W^σ,δ_S^σ) > 0`（配 GL2b 与 GL9/定理 1 后分别为 MG 与面积律）。于是 `I-UNIQ` 的中性扇区隙与 `I-NT/I-CONF` 的弦张力是**同一个理论**的性质。

### 2.1 为什么 (a) 不被 (b) 蕴含

1. (b) 是（每个实例各自的）纯实分析结论；它对"界属于哪个理论"一无所知。两个界若属于不同理论，`min` 无意义（`gluing` §2.7 已指出）。
2. (a) 也不是 GL1 的推论：GL1 说九个接口**引用**同一个 `μ_{L,a,β(a)}`（一个记号/审计条件）；GL7(a) 说两条交接分析**可在这个测度上相容地执行**（同一个 `g²`、同一套误差界、同一子列；契约的强形式还要求同一个 `μ_up`，见 §3.3）。**引用同一个对象 ≠ 在同一条轨迹上可同时证明两个界。**
3. 逻辑上，(b) 对两个**不同** RT 也可以各自成立。此时"胶球有隙"与"弦有张力"分别属于 `T_A`、`T_B`；Clay 只需 `T_A` 的 MG，但契约要求的"整个谱有隙 + 禁闭"会落空，且供给矩阵中 `CONF → NT` 与 `MG → UNIQ` 不再谈同一个测度。

### 2.2 为什么 (a) 不是纯实分析

`SameConstruction` 的每一项都是**关于证明构造的命题**（用了哪个作用量、哪个分块、哪个正则化、哪个子列），不是关于实数的不等式。它只能由两条证明的 §1 逐条核对来证，或（更好）由两者都实例化同一个带参数的构造模板来证。`gluing` §1 的"每个接口必须逐字引用本节"正是为这个设计的。

## 3. 实时分析核心

设 `R_m := m/Λ`、`R_σ := √σ/Λ`。沿 RT，`q₀^i = φ_i(μ_up^i) = R_i e^{-t_up^i}`。

### 3.1 命题 1（塌缩：共用 `μ_up` 时两个 `H3` 合为一条）

**前提**：两个实例共用 `μ_up`（于是共用 `λ*`、共用 `t_up = C_RG/λ*`）、`R_m, R_σ > 0`、`q₁^m, q₁^σ > 0`。

则
```
H3_m ∧ H3_σ   ⟺   R_m ≥ e^{t_up} · max( q₁^m , (m/√σ)·q₁^σ ).
```

**证明**：`H3_i ⟺ R_i ≥ q₁^i e^{t_up}`。第二式除 `R_σ` 并乘 `R_m`，用 `R_m/R_σ = m/√σ`，得 `R_m ≥ (m/√σ)q₁^σ e^{t_up}`。两式合取即取 max。∎

**推论 1.1（σ ⟹ m 的免费条件）**：若 `q₁^m ≤ (m/√σ) q₁^σ`，则 `H3_σ ⟹ H3_m`。物理上 `m/√σ≈3.5–4`，故只要 `q₁^σ ≳ q₁^m/4`，**证出弦张量一侧的 `H3` 就自动得到质量隙一侧的 `H3`**；反向不成立。

**推论 1.2（必要条件，与 `λ*` 无关）**：`q₁^i < R_i` 是 `H3_i` 的必要条件（因为 `q₀^i < R_i`）。若某强侧分析只给 `q₁^σ ≥ √σ/Λ`，则**任何 RT 上 `H3_σ` 都不可能**。

**推论 1.3（前沿形式）**：设两实例共用的弱侧有效域要求 `λ* ≤ λ*_max := min(λ*_max^m, λ*_max^σ)`（`λ*_max^i = h^∨(g_*^i)²`），则**存在共用交接点 ⟺**
```
C_RG / ln( min(R_m/q₁^m, R_σ/q₁^σ) )  ≤  λ*_max,        且  min_i (R_i/q₁^i) > 1.
```
（令 `λ*_req := C_RG / ln(min_i R_i/q₁^i)`；`σ` 是约束方当且仅当 `R_σ/q₁^σ < R_m/q₁^m`，即 `q₁^σ > (√σ/m)q₁^m ≈ q₁^m/4`。等号情形与推论 1.1 一致。）

### 3.2 命题 2（共用弱侧阈值的代价）

若两套弱侧分析的可用半径不同（`g_*^m ≠ g_*^σ`），契约要求同一 `μ_up`，则必须取 `g_* = min(g_*^m, g_*^σ)`，于是 `λ* = h^∨ g_*² = min(λ*_max^m, λ*_max^σ)`，`t_up` 取**两者中较大者**：
```
λ* 减半  ⟹  t_up 加倍  ⟹  e^{t_up} 平方  ⟹  两个 q₀ 同因子缩小.
```
**这是"共用重叠区间"的真实价格**：它不是逻辑必需（见 §3.3），但一旦采用，两个 `H3` 的困难度由较弱的那套弱侧分析决定，且**同向**恶化（`q₀^m/q₀^σ` 仍等于 `m/√σ`，所以 σ 仍更紧）。

### 3.3 接口建议：`SameRT ≠ SameThreshold`

GL7 的**逻辑必需内容**只有 (a)+(b)+(c)。**"共用 `μ_up`" 是充分而更强的形式**，不是必需：

- 若允许 `μ_up^m ≠ μ_up^σ`（各自用各的 `g_*^i`），每个实例仍有自己的覆盖论证 `[μ_up^i,∞) ∪ (0,μ*^i] = (0,∞)`；"同一测度"只要求 (a)，不要求同一阈值。
- 代价是失去命题 1 的塌缩，两个 `H3` 变得**真正独立**（这正是任务所说的"要证两次"）。
- **建议**：契约把 `I-HANDOFF` 的硬性要求写成"同一 RT"，把"同一 `μ_up`"降为**可选的简化假设**（采用时，引入 §3.2 的代价并记录 `λ*_max = min`）。这样 GL7 的陈述不把一个人为的便利条件伪装成数学必需。

## 4. 条件归约：两个证书分别要证什么

### 4.1 义务清单

**(I0) 同一性**（GL7-a）：§1.1 的 11 项逐项相同。**可判定**：核对两报告的 §1 是否逐字引用 `gluing` §1；特别检查 `C`、`Λ` 定义、`β=2N_c/g²`、`C_RG=24π²/11`、分块对齐、极限次序。

对每个 `i ∈ {m,σ}`：

**(I1) H0**：`φ_i : (0,∞)→(0,∞)` 连续、严格减、`φ_i(0⁺)=∞`、`φ_i(∞)=0`。
- `m`：`m/μ` 精确成立（`m` 固定）。
- `σ`：需 `√σ(μ)/μ` 满足同一性质。沿**精确** RT `√σ` 是 RG 不变量（`σ=c_σΛ²`），但"尺度 `μ` 的有效弦张力 `σ(μ)` 的单调性"仍需一句独立的 RG 陈述（`mass-spectrum`/RG 侧）。**这是 `σ` 侧比 `m` 侧多出的一个微小义务。**

**(I2) 弱侧 reach `CPB-W`**：`∃g_*^i, δ_W^i>0`，`g²(μ)≤(g_*^i)² ⟹ cert_i(μ) ≥ δ_W^i`。
- **可共享**：`CPB-W` 的物理内容是"弱侧（有质量背景场）**类保持**"，作用在测度/有效作用量上，与观测量无关。若弱类 `C_W(ε₀)` 同时包含两个观测量（`m`：smear 的 `tr F²`；`σ`：Wilson 环），则**一次 `CPB-W` 给出两个 `δ_W`**。
- **不可共享的部分**：`λ*_max^i` 可能不同（不同观测量的误差传播不同）；以及 R27 要求的 `≥2 圈 t_up` 必须对**两个证书共用的** `λ*` 成立。
- **必须明确的一个接口问题（GL7 的可行性开关）**：`δ_W^σ` 的物理内容只能是"类保持 + `√σ/Λ` 的 RG 不变性"（把 `√σ` 的值搬成尺度 `μ` 的证书），**不能是微扰地计算 `σ`**（微扰 `σ=0`）。若 `CPB-W` 的弱侧构造**以质量隙 `m` 为 IR 截断**、不覆盖弦扇区，则 `δ_W^σ` 不存在，`σ` 证书只能由强侧独自覆盖到 `μ_up`——那就是**完整的连续统面积律**（`confinement` 的 L7/G1，公开）。**故 GL7 可共享弱侧，当且仅当 `CPB-W` 是"观测盲"的类保持定理**；这是要向 `handoff-proof`/`lattice-cpb` 确认的第一件事。

**(I3) 强侧 reach `CPB-S^m`**：`∃q₁^m, δ_S^m>0`，`q_m(μ)≥q₁^m ⟹ cert_m(μ)≥δ_S^m`。
- 在 `q₁^m=1`（即 `ma≥1`、`ξ/a≤1`）处，这是**经典强耦合质量隙**（Osterwalder–Seiler 1978；SZZ 的无限体积版本），`δ_S^m>0` 已有。**`m` 侧的强侧近乎免费。**

**(I4) 强侧 reach `CPB-S^σ`**：`∃q₁^σ, δ_S^σ>0`，`q_σ(μ)≥q₁^σ ⟹ cert_σ(μ)≥δ_S^σ`。
- 在 `q₁^σ=1`（`ξ/a≤1`）处，这是**已证的格点强耦合面积律**（`confinement/PROOF.md` Thm A/B），`σ_lat>0` 已有。
- **但 `H3_σ` 要求的不是 `q₁^σ=1`，而是 `q₁^σ ≲ 0.14`（严格二圈；0.27 是未证乐观值；见 §4.4）**，即强侧控制必须覆盖到 `ξ/a = 7.0`（乐观值对应 3.7）这一跨接手征区。**这才是 `CPB-S` 的"新对象"地位所在**（与 `handoff-proof` STATUS §3 的 `z(q_c)≤1/2` 一致：`z` 随 `q` 增，故更小的 `q_c` 要求更小的活度上界——更难）。

**(I5) 两个 `H3`**：§3 的塌缩命题或两条独立不等式。
**(I6) 两个 `hcert`**：GL2b 的两个实例（`cert_i μ ≤ R_i`）。

### 4.2 合并的条件定理

**定理 GL7（条件）。** 假设
- (I0) `SameConstruction`；(I1) 两个 H0；
- (I2) `CPB-W` 在共用 `λ*` 上成立（含 `≥2 圈 t_up` 上界），给出 `δ_W^m, δ_W^σ` 与 `λ*_max`；
- (I3) `CPB-S^m(q₁^m, δ_S^m)`；(I4) `CPB-S^σ(q₁^σ, δ_S^σ)`；
- (I5) 前沿不等式 `λ*_req ≤ λ*_max`（命题 1.3）；
- (I6) `hcert_m, hcert_σ`。
则在同一测度 `μ` 上：
```
Δ/Λ   ≥ min(δ_W^m, δ_S^m) > 0,
√σ/Λ  ≥ min(δ_W^σ, δ_S^σ) > 0,
```
且两者都是同一个 `μ_{L,a,β(a)}` 的极限（同一子列、同一极限次序）。

**证明**：对每个实例用 `handoff_gap`（两域覆盖）+ `hcert_i`；结论在同一测度上按 (I0) 合并；`σ` 侧与面积律的等同用 I-CONF 的谱表述（`E₀(L)≥σL`）。∎

## 5. 什么会否证"共用 RT"

分两类：否证**同一性**（(a) 失败），或否证**双交接的定量相容**（(b) 在共同 RT 上不可同时成立）。

### 5.1 否证同一性（可由审阅直接判定）

| # | 失配 | 后果 | 检查点 |
|---|---|---|---|
| **F1** | **scheme/`C` 漂移**：一份报告用 `12π²`（`T(adj)=2h^∨`, `g²` 减半）而另一份用 `24π²` | 数值比较错 `e^{3.59}` 级；`λ*` 与 `t_up` 跨惯例混用使 `q₀` 翻转 | 两报告都必须声明 `C_RG=24π²/11` 与 `β=2N_c/g²`（R26/C15） |
| **F2** | **作用量/正则化漂移**：一侧证在 Symanzik/改进作用量上 | 连续统极限可能不同（改进作用量 RP 未证，§1.2） | 两报告 §1 的 `S_W` |
| **F3** | **分块漂移**：块因子 `≠2`、或倾斜分块（不满足 `os3` 的 `θ`-协变判据 `A∈W∩RWR⁻¹`） | 两个粗理论不同，`μ` 轴不可比 | §1.7 约束 1 + §6.2 判据 |

### 5.2 否证双交接的定量相容（在同一 RT 上）

| # | 条件 | 含义 |
|---|---|---|
| **F7** | `min_i R_i/q₁^i ≤ 1`（即某 `q₁^i ≥ R_i`） | 该 `H3` 在**任何** RT 上都不可能（推论 1.2）。例：若 `q₁^σ ≥ √σ/Λ`，弦证书死。 |
| **F8** | `λ*_req > λ*_max`（命题 1.3） | 没有共同的弱侧交接点：弱侧类保持的半径不够，两个有效域无法在一条 RT 上相接。**这是"共用重叠区间"的直接否证**。 |

| **F11** | `CPB-W` 的弱侧构造以 `m` 为专用 IR 截断、只给质量隙证书 | `δ_W^σ` 不存在 ⟹ `σ` 侧无弱域 ⟹ 双交接退化为"强侧覆盖全尺度"= 连续统面积律（公开，`confinement` L7/G1）。**这是 GL7 最可能的失败模式。** |
