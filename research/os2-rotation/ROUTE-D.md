## 0. 结论（判定）

1. **"无矢量序参量"不足以排除破缺。** 纯 YM 的规范不变**单标量** VEV 都是
   `O(4)`-不变的（标量就是数）；`W`-不变性又强迫 `⟨T_{μν}⟩ ∝ δ_{μν}`。所以破缺
   只能表现为**连通关联中的方向依赖**，其领头 `W`-不变结构是 **`ℓ = 4`（秩 4）
   各向异性**，不是矢量。因此 `NoSpacetimeGoldstone` 必须写成关于
   **角动量荷/`ℓ = 4` 通道**的陈述。
2. **证书字段 `sym` 不是冗余的。** `R.Oriented T` 是**有限**旋转协变性；`flux`
   （`StressLaws`）是**无穷小** Ward 恒等式。二者之间有真实间隙：
   `StressLaws` 对任何"对称守恒应力张量"的理论成立（包括各向异性理论），
   `Oriented` 则不然。存在把二者分开的模型（各向异性 Gauss）。所以去掉 `sym`
   推不出 `R.Oriented`；U2 仍是一个真定理目标，不是定义性平凡化。
3. **D 不绕开聚类。** 把局部 Ward 恒等式升级为"角动量荷湮灭真空"（这才是
   `Oriented`）需要对空间无穷远的**边界项衰减**——即 `StressTensorDecay`，这是一个
   聚类型输入。D 的输入比 `SYM-4D` **窄**（只需应力/`ℓ=4` 一个通道，而非全部
   dim-6 算符 + 体积一致），但不是"无聚类"。
   **U2 与 MG 在逻辑上独立**（两个命题互不蕴含），但 D 的**证明**仍消费一个衰减估计。
4. **可用的具体观察（源级）**：`StressLaws.rotation` 取 `B = unit` 时，由
   `Table.Rotation.kills`（`R.lie d g (unit) = 0`）给出 `shellSpin = 0`——
   这是**局部**的角流湮灭，最接近 `sym` 的一条现成事实，但**不是**有限协变性。

**一句话**：D 是"把 U2 归约为单个 `ℓ=4` 通道 + 边界衰减"的路线，不是绕开聚类的路线；
`sym` 字段是真的，不是可删的冗余。

## 2. Ward 恒等式 ⟹ 有限协变？不

`StressLaws.rotation` 是**算符层**的恒等式：角流插入 `shellSpin` 等于场变分
`R.lie B` 的插入。它对任何带对称守恒应力张量的理论成立，**与态是否旋转不变无关**。

`Oriented` 是**态层**陈述：表在旋转后的点上取同值。二者之间的桥是
"角动量荷湮灭真空"：

```
Q_g Ω = 0      （g ∈ so(4)）
```

由 Ward 恒等式 + `[Q_g, φ] = δ_g φ` 才能推出 `⟨δ_g φ⟩ = 0`，进而有限协变。
`StressLaws` 只给 `[Q_g, φ] = δ_g φ` 这一半；`Q_g Ω = 0` 是额外的一半，正是
"无自发破缺"的内容。

**源级旁证**：`Table.Rotation.kills` 说 `R.lie d a (S.unit d) = 0`。代入
`StressLaws.rotation` 取 `B = unit d`：

```
shellSpin T J χ g x q (unit) = S.useAt T x (⟨d, R.lie d g (unit)⟩ :: q) = 0 .
```

这是一个**局部**的角流湮灭（窗口 `χ` 支撑在 `x₀` 附近）。它很接近 `sym`，但
`shellSpin` 是应力张量的一阶矩积分，不是全局荷；从局部恒等式到 `Q_g Ω = 0`
要取 `χ → 1`（或对 Cauchy 面取极限），此时出现**无穷远边界项**。这正是 §4 的缺口。

## 3. 冗余性判定：`sym` 不是冗余字段

**问题**：去掉 `sym` 后，`flux + lengths + still + decomposition + chosen + states +
retains + coordinates + calculus + goes + heat` 能否推出 `R.Oriented`？

**判定：不能（在下面的意义上）**——`flux` 与 `sym` 可被一个模型分离：

取各向异性 Gauss 测度（协方差 `diag(c₁,c₂,c₃,c₄)|x−y|^{−2}` 型，或格点上各向异性
质量）。它

- 有对称、守恒的应力张量，故满足 `StressLaws`（`translation` 与 `rotation` 都是
  算符恒等式，与态的各向异性无关）；
- 但 `useAt` 在旋转后的点上不等，故 **`Oriented` 失败**。

所以 `flux ⇏ sym`。其余字段中没有任何一个提及"把表的点旋转后再比较"，它们分别是
长度/spread 律、室流固定点、分解、接收、层级、null 保持、包含、导数、heat——
都不直接约束旋转协变。**因此 `sym` 承载了独立内容，U2 = 证 `sym` 是真定理。**

**保留**：我没有构造完整的模型来满足其余全部字段（`decomposition`/`heat` 等很强）。
若它们意外地蕴含了 `sym`，冗余性会回来。这是**可在 Lean 里直接试**的开放点：
尝试从 `Certificate` 的其余字段（尤其是 `flux` + `states` + `decomposition`）
推出 `R.Oriented`；若成功，`sym` 可删，U2 变成"构造里 `sym` 冗余"这一更强结论。
本报告只给出"结构上不预期成功"的判断与上面的分离模型。

## 4. `NoSpacetimeGoldstone` 的精确形式

把 §2 的缺口写成可证命题。对每个 `g ∈ so(4)`，令 `Q_g` 为由应力张量角流定义的荷
（在 OS 重构空间上，`Q_g` 是 `R.lie` 的生成元在真空表示中的实现）。定义

```
(NoSpacetimeGoldstone)  ∀ g ∈ so(4):  Q_g Ω = 0 ,
```

等价地：对任意局部可观测量 `O`，`⟨[Q_g, O]⟩ = 0`；等价地：角 Ward 恒等式的
**全局**形式中，空间无穷远边界项为零。

三条等价形式的用途：
- 第一条最接近"无自发破缺"的教科书表述；
- 第二条可直接与 `StressLaws.rotation` 对接（`shellSpin` 的 `χ → 1` 极限）；
- 第三条是**可估计**的形式：边界项 = `lim_{R→∞} ∮_{|x|=R} x_{[a} T_{b]c} n_c` 型
  关联，由 `StressTensorDecay` 控制。

**关键**：第三条表明 `NoSpacetimeGoldstone` **消费 `StressTensorDecay`**，不是纯代数
事实。原因是 `Q_g Ω = 0` 不能由 RP 或正性单独推出：`Q_g` 反 Hermite，
`⟨Ω, Q_g Ω⟩ = 0` 对任何态都成立，不提供信息；真正需要的是 `Q_g Ω` 这个**向量**
为零，只能由边界项/衰减得到。

## 9. `NoSpacetimeGoldstone` 的 ℓ=4 精确形式

### 9.1 为什么是 ℓ=4

设表 `T` 平移不变且 `W`-不变（`W = B₄`，带号置换群）。若 `T` 不 `O(4)`-协变，则存在
某个 `K ∈ O(4)` 与组态 `(x,v)` 使 `useAt T (Points.move K x) (R.label K ∘ v) ≠ useAt T x v`。
取最简单的探测对象：连通两点函数 `C(x−y) = ⟨φ(x)φ(y)⟩_c`（或应力两点函数）。
`W`-不变性给出 `C(wz) = C(z)`；对其 Fourier 变换按 `S³` 上的球谐展开：

```
Ĉ(p) = Σ_ℓ f_ℓ(|p|) Y_ℓ(θ) ,      θ = p/|p| .
```

`W`-不变性迫使 `f_ℓ = 0`，除非 `ℓ` 的球谐空间含 `W`-不变向量。`W` 的不变多项式由
`x₁²+x₂²+x₃²+x₄²`（度 2）与平方的初等对称多项式 `e₂,e₃,e₄`（度 4,6,8）生成；
球面上 `e₁ = 1`，故**第一个非常数不变量是度 4 的 `e₂`**。所以：

```
领头各向异性 = ℓ=4 通道，且 W-不变部分是一维的（由 e₂|_S³ 张成）。
```

这与 `SYM-4D` 里出现的 `ℓ=4` 谐波是**同一个对象**；B 与 D 在此汇合（但用途不同：
B 要它的系数 `O(a²)`，D 要它**为零**）。

**但 `W`-不变通道不止 `ℓ=4`**：`e₂,e₃,e₄` 的乘积给出 `ℓ = 4,6,8,…`。
`ℓ=4` 只是**领头**通道；只杀它不足以推出全 `O(4)` 不变（§9.2）。

### 9.2 定义与领头检验（不是三个等价形式）

**定义（强形式）.**

```
(NG)   ∀ g ∈ so(4):  Q_g Ω = 0 .
```

在 Ward 把 `Q_g` 识别为几何旋转生成元的前提下，`(NG) ⟺ U2`：
`Q_gΩ=0` 对所有 `g` ⟺ 真空在 `SO(4)` 下不变（`O(4)` 的反射部分由 `W` 提供）。

**领头检验（必要，不充分）.**

```
(NG-ℓ4)  对每个 W-不变的 ℓ=4 谐波 h₄ 与每个连通两点函数 C：
             ∫_{S³} h₄(θ) Ĉ(|p|θ) dθ = 0 .
```

`(NG) ⇒ (NG-ℓ4)`，但**逆不成立**。理由：`W`-不变函数在 `S³` 上的不变通道是
`ℓ = 4, 6, 8, …`（由 `e₂,e₃,e₄` 及其乘积生成），杀 `ℓ=4` 不杀 `ℓ≥6`。
所以把 `(NG-ℓ4)` 当作 D 的假设会**弱得推不出 U2**——这是本轮必须钉死的精度点。

**部分补足：应力张量通道.** 对**应力张量**两点函数，每次 `T` 插入是 spin-2，
两次插入的角向内容 `≤ ℓ=4`（`2 ⊗ 2 = 0 ⊕ 1 ⊕ 2 ⊕ 3 ⊕ 4`），故 T–T 关联中
**没有** `ℓ≥6` 通道。于是

```
(NG-ℓ4^T)  T–T 关联的 ℓ=4 分量为零
```

是比 `(NG-ℓ4)` 更锐的检验，且**可能**与 `(NG)` 等价（`Q_g` 由 `T` 构成）。
但这是"可能"，不是"已证"：需要证明"若 `Q_gΩ ≠ 0`，则 T–T 关联必有 `ℓ=4` 分量"。
对一般算符（高阶自旋、`F` 的高次复合）仍可有 `ℓ≥6` 通道，故 `(NG-ℓ4)` 不是 `(NG)`。

**边界形式（与 `(NG)` 等价，且可估计）.**

```
(NG″)  对每个 g，lim_{R→∞} ∮_{|x|=R} (x_{[a}T_{b]c})(x) n_c 的连通插入 = 0 .
```

由 `StressLaws.rotation` 取 `χ → 1`：左边 → `Q_g` 的插入，右边 → 场变分，
差值为无穷远边界项；边界项为零 ⟺ `(NG)`。§13 把它精确为 `(Q-CONS)`。

**层级**：`(NG-ℓ4) ⟸ (NG-ℓ4^T) ⟸? (NG) ⟺ U2`。中间那个 `⟸?` 是开放的；
两侧的 `⟸` 是严格的。

### 9.3### 9.3 可证伪性：各向异性 Gauss 反例

取 Gauss 测度，协方差 `Ĉ(p) = |p|^{−2}(1 + ε h₄(θ))`，`ε ≠ 0`，`h₄ = e₂|_S³` 归一化。
它满足：

- **平移不变**（协方差只依赖 `p`）；
- **`W`-不变**（`h₄` 是 `W`-不变量）；
- **反射正性**（`1 + ε h₄ > 0` 取 `|ε|` 小；Gauss 测度的 RP 由正性给出）；
- **`StressLaws`**（Gauss 理论有对称守恒应力张量；Ward 恒等式是算符恒等式，
  与态的各向异性无关——§2）。

但它**违反** `(NG-ℓ4)`：`f₄ ≠ 0`。所以：

> **判定（修正）**：该反例说明 **`(NG-ℓ4)` 不能**由 {平移不变, `W`-不变, RP,
> `StressLaws`} 推出；它是独立的额外条件。它**不**直接说明 `(NG)` 独立——
> 因为 `(NG-ℓ4)` 只是 `(NG)` 的必要条件。要证 `(NG)` 独立，需要 `ℓ≥6` 的反例，
> 或走 §13 的算子论证（`(Q-CONS)`）。

反例不是"矢量序参量"，而是 **ℓ=4 各向异性 Gauss 态**；它精确地卡在
`(NG-ℓ4)` 这一层，而不是 `(NG)` 这一层。另注意：**二次**各向异性
`Σ c_i p_i²` 不 `W`-不变（`W` 强迫 `c_i` 全等），故合法的各向异性模型必须是
四次/`ℓ=4` 型；其 `StressLaws`/对称应力张量是否成立是 §13.5 的待判定点。

## 13.1 谱定理（无条件正确）

**定理 S.** 设 `ℋ` 为 Hilbert 空间，`H ≥ 0` 自伴，`Ω ∈ ker H`，`‖Ω‖=1`。
设 `Q` 自伴（或反自伴），`QΩ` 有定义，且 `[H,Q]=0`（在含 `Ω` 的域上）。
若 `ker H = ℂΩ`，则 `QΩ = 0`。

*证明.* `H(QΩ) = Q(HΩ) = 0`，故 `QΩ ∈ ker H = ℂΩ`，即 `QΩ = cΩ`。
若 `Q` 反自伴，`c = ⟨Ω,QΩ⟩ = −⟨QΩ,Ω⟩ = −c̄`，故 `Re c = 0`；又 `c ∈ ℂ` 任意？
更直接用反自伴：`⟨Ω,QΩ⟩ = −⟨QΩ,Ω⟩ = −conj⟨Ω,QΩ⟩`，故 `c` 纯虚。要排除纯虚
`c ≠ 0`，用 `Q` 是紧群 `SO(4)` 的生成元：`e^{tQ}Ω = e^{tc}Ω` 对所有 `t` 成立
（`Q` 保持 `ker H`），且 `e^{tQ}` 是正交/酉算子，故 `|e^{tc}|=1`，`c` 纯虚；
再由 `t ↦ e^{tc}` 是 `ℝ` 到 `U(1)` 的连续同态，且 `SO(4)` 的生成元满足
`e^{2πQ}=1`（若 `Q` 是角度的生成元），故 `c ∈ 2πiℤ`；最后 `SO(4)` 半单，
一维不变子空间上的作用必为平凡表示，故 `c=0`。∎

（对每个 `g ∈ so(4)` 分别应用；`Q_g` 反自伴是欧氏 Hilbert 空间上的标准事实。）

## 13.2 三条假设从哪里来

- **(A) `Q_g` 存在且自伴**：由应力张量角流 `∫d³x x_{[i}T_{j]0}` 的截断极限。
  需要边界项在稠密域上收敛。`MG`（指数聚类）给连通关联的衰减，**支持** (A)，
  但严格陈述需要 (A) 本身作为引理。
- **(B) `[H,Q_g]=0`**：由 `∂_μT_{μν}=0` 与 `T` 对称：
  ```
  dQ_g/dt = ∫ x_{[i}∂_0T_{j]0} = −∫ x_{[i}∂_kT_{j]k}
          = ∫ δ_{k[i}T_{j]k} − 边界 = ∫ T_{[ij]} − 边界 = −边界 .
  ```
  所以 `[H,Q_g] = i·边界`。**局部 Ward 恒等式只给到这里的"边界项"**；
  `[H,Q_g]=0` 需要边界项为零。**这是缺口。**
- **(C) `ker H = ℂΩ`**：由 OS4（遍历性）或 `MG`（聚类 ⟹ 唯一真空）。**现成。**

## 13.3 链条与缺口

```
MG ──(聚类)──▶ 连通关联指数衰减
   ──▶ 边界项的矩阵元在局部态之间为零        （可证）
   ──▶ ??? 边界项作为算子在 Ω 上为零          （缺口：Q-CONS）
   ──▶ [H,Q_g]=0                            （由上式）
   ──▶ 定理 S ⟹ Q_gΩ=0   （即 (NG)，不是 (NG-ℓ4)）
   ──▶ U2（Ward 识别 Q_g 为几何生成元）
```

**缺口精确表述：**

```
(Q-CONS)  对每个 g ∈ so(4)，角动量荷的边界算子 B_g := lim_{R→∞} ∮_{|x|=R} x_{[i}T_{j]k} n_k
          在局部算子生成的稠密域上为零（等价地 [H,Q_g]=0 作为算子）。
```

- `(Q-CONS)` **不是**局部 Ward 恒等式的推论：局部恒等式是关于 `∂_μT` 的，
  边界算子是 `T` 在无穷远的积分，二者相差一个不能由局部信息决定的对象。
- `(Q-CONS)` **不是** `MG` 的推论（至少不是显然的）：`MG` 控制**连通**关联；
  边界算子在真空上的作用涉及真空本身（非局部态），不在聚类的直接范围内。
- 若 `(Q-CONS)` 成立，则链条闭合：**`MG + QA + (Q-CONS) ⟹ U2`**，其中 `QA` 是
  应力张量的代数输入（`Conserved` + `StressLaws`）。

**循环检查**：链条用 `MG` 证 `(Q-CONS)`（候选），再用 `(Q-CONS)` 证 `U2`；
`U2` 是否被用于证 `MG`？`MG` 的证明走格点 RG（只用量子群 `W`），不用 `U2`。
**无循环**——前提是 `MG` 的证明确实不引用 `U2`（需在收缩路线里确认）。

## 13.4 判定

- **不是无条件反转。** 正确的条件陈述是
  `MG + QA + (Q-CONS) ⟹ U2`；缺 `(Q-CONS)` 时链条断开。
- **但这是目前最接近"反转"的结构**：如果 `(Q-CONS)` 由 `StressLaws` 或
  `decomposition`/`heat` 给出，则 `MG ⟹ U2` 成立，而且 `sym` 在 `MG` 下冗余。
- 因此下一步应该**直接攻 `(Q-CONS)`**，而不是攻 `NoSpacetimeGoldstone` 或 `(NG-ℓ4)`：
  `(Q-CONS)` 更具体（一个边界算子的消失），且它一旦成立就自动给出 NG-ℓ4。

## 13.5 决定性检验：ℓ=4 massive Gauss

构造：Gauss 测度，协方差
```
Ĉ(p) = 1 / ( p² + m² + (ε/Λ²) Σ_i p_i⁴ ) ,   m > 0 ,  ε ≠ 0 ,
```
取 `Σ_i p_i⁴` 的 `W`-不变组合（`ℓ=4` 谐波 `e₂` 的动量版本）。

它满足：
- **有质量隙** `m`（色散有下界）；
- **`W`-不变**（`Σ p_i⁴` 是 `W`-不变量）；
- **RP**（`Ĉ(p) > 0`，Gauss 测度的反射正性由协方差的正性给出，取 `|ε|` 小）；
- **唯一真空 + 聚类**（massive Gauss）；
- **平移不变**；
- **破坏 U2**（`Ĉ` 非旋转不变）。

**关键问题**：它是否满足 `Conserved.symmetric` + `StressLaws`？
- 若**满足**：它就是 `MG + QA ⇏ U2` 的**反例**，且必违反 `(Q-CONS)`（因为谱定理
  正确而它不 U2）。这直接证明 `(Q-CONS)` 是独立的新输入，`MG ⇏ U2`。
- 若**不满足**（例如高阶导数动能项的 Noether 应力张量不对称）：则它不是合法反例，
  `(Q-CONS)` 仍可能与 `StressLaws` 一致，反转仍可能成立。

这是一个**可计算**的判定（在自由理论里算 `T_{μν}` 的对称性与角流守恒）。
**建议优先做这个计算**：它一次性决定"反转"是否可能。

## 13.6 与 uniqueness "逻辑独立" 的逐点对照

| uniqueness 的说法 | 本报告判定 |
|---|---|
| U2 与 MG 逻辑独立 | **结论支持**；但理由要换 |
| 理由：时空破缺不需无隙激发（时空 Goldstone 定理未证） | **不是最锋利的**：谱论证根本不需要 Goldstone 定理；它只需要 `[H,Q_g]=0` + 唯一真空 |
| 因此"MG ⇏ U2" | **成立**，但真正的缺口是 `(Q-CONS)`（边界算子），不是 Goldstone 模式的存在性 |

换句话说：**若 `(Q-CONS)` 成立，则 `MG ⟹ U2`，uniqueness 的独立判断被推翻**；
若 `(Q-CONS)` 不成立（ℓ=4 Gauss 满足 `StressLaws` 即为证），则独立判断成立，
且理由升级为"聚类不控制边界算子"。两种情况都比"时空 Goldstone 定理未证"更精确。

## 13.7 对 §9.3 的修正

§9.3 用"各向异性 Gauss"作为 `NoSpacetimeGoldstone` 不可推出的反例。该论证需要
该模型满足 `StressLaws`；对**二次**各向异性（`Σc_ip_i²`）它其实**不** `W`-不变

- "NG 不可由 {平移, `W`, RP, 局部 Ward} 推出"——**仍成立**（由 ℓ=4 Gauss，若其

**一句话**：把 D 的核心从 `NoSpacetimeGoldstone` 移到 `(Q-CONS)`；`(Q-CONS)` 是一个

# §14（2026-11-22）：决定性计算 —— ℓ=4 massive Gauss 能否对称化？

## 14.1 设定与 Noether 应力张量

作用量（Euclidean，`λ := ε/Λ²`）：
```
S = ½ ∫ φ P(∂) φ ,    P(∂) = m² − Δ + λ Σ_i ∂_i⁴ ,
L = ½(∂φ)² + ½m²φ² + (λ/2) Σ_i (∂_i²φ)² .
```
二阶导数 Lagrangian 的 Noether 应力张量（标准公式）：
```
T_{μν} = ∂_νφ ∂L/∂φ_{,μ} + ∂_ν∂_αφ ∂L/∂φ_{,μα} − δ_{μν}L − ∂_α(∂L/∂φ_{,μα} ∂_νφ) .
```
代入 `∂L/∂φ_{,μ}=∂_μφ`、`∂L/∂φ_{,μα}=λδ_{μα}φ_{,μμ}`，得
```
T_{μν} = ∂_μφ ∂_νφ − λ ∂_νφ ∂_μ³φ − δ_{μν}L .
```
（第三项是 `λφ_{,μμ}∂_μ∂_νφ` 与 `−λ∂_μ(φ_{,μμ}∂_νφ)` 展开后相消的结果。）

## 14.2 对称性检查

```
A_{μν} := T_{μν} − T_{νμ} = −λ( ∂_νφ ∂_μ³φ − ∂_μφ ∂_ν³φ ) .
```
在动量符号下（`∂_μ → p_μ`，双线性形式）：
```
A_{μν}(p) = −λ( p_ν p_μ³ − p_μ p_ν³ ) = λ p_μp_ν(p_μ² − p_ν²) ≠ 0   （μ≠ν，λ≠0）.
```
**结论：T 不对称**，与"非旋转不变色散 ⟹ 角动量不守恒"一致。

## 14.3 Belinfante 型改进：穷举

改进形式 `T'_{μν} = T_{μν} + ∂_ρ B_{ρμν}`，`B_{ρμν} = −B_{μρν}`（保守恒）。
`A` 是 4 次，故 `B` 为 3 次、双线性。宇称偶（理论宇称偶）的 3 次 rank-3 张量由
`δ` 与 `p` 生成，完全列表：

| 结构 | 在 `ρ↔μ` 下 |
|---|---|
| `p_ρp_μp_ν` | 对称 → 被反对称性杀掉 |
| `δ_{ρμ}p_ν p²` | 对称 → 被反对称性杀掉 |
| `δ_{ρν}p_μ p²` | 与下一项配对 |
| `δ_{μν}p_ρ p²` | 与上一项配对 |
| `ε_{ρμνσ}p_σ p²` | 已反对称 |

故反对称子空间由
```
B^{(1)} = δ_{ρν}p_μ p² − δ_{μν}p_ρ p² ,        B^{(2)} = ε_{ρμνσ}p_σ p²
```
张成。它们的散度：
```
∂_ρ(B^{(1)}_{ρμν} − B^{(1)}_{ρνμ}) = p_νp_μp² − δ_{μν}p²p² − p_μp_νp² + δ_{μν}p²p² = 0 ,
∂_ρ(B^{(2)}_{ρμν} − B^{(2)}_{ρνμ}) = 2 ε_{ρμνσ}p_ρp_σ p² = 0 .
```
**改进像 = {0}。** 而 `A ≠ 0`，故方程 `A = −∂B` 无解。

**精确整数检验**（`check-d14.py`，四个 generic 整数动量，逐分量）：
```
A nonzero: True    div(S2-S3) nonzero: False    div(S5) nonzero: False
```
（`S2-S3 = B^{(1)}`，`S5 = B^{(2)}`。）

## 14.4 判定

**`REVERSAL-OPEN`** —— **无法对称化**。

即：ℓ=4 massive Gauss **不满足** `Conserved.symmetric`，也（由 §2 的分析）不满足
`StressLaws.rotation`（角 Ward 恒等式会多出反对称部分 `T_{[ij]}`）。因此它
**不是** `MG + QA ⇏ U2` 的合法反例。

## 14.5 纪律：负结果不等于证明 (Q-CONS)

必须把两件事分开写：

1. **本计算的结论**：这个特定模型无法对称化 → 它不能用作反例 → **反转未被此模型否定**。
2. **它没有证明的**：`(Q-CONS)`（边界算子为零）。也没有证明 `MG + QA ⟹ U2`。
   它只说明：**反例必须来自"有对称守恒应力张量却破坏 U2"的理论**，而这类理论按
   角动量守恒的逻辑应当产生无隙模（Goldstone），从而与质量隙冲突——这正是反转
   想要的方向，但仍需证明。

## 14.6 对反转的意义（谨慎）

- 计算**缩小**了反例空间：任何非旋转不变的自由标量理论都没有对称守恒应力张量
  （角动量不守恒）。所以"MG + QA + 破坏 U2"的反例不能是自由理论。
- 交互作用的非旋转不变理论若有对称守恒 T，则它有守恒角动量，但态破坏旋转——
  这需要无隙的 Goldstone 模；有质量隙时不可能（谱论证，§13）。所以反转
  `MG + QA + (Q-CONS) ⟹ U2` 仍然可信。
- 但 `(Q-CONS)` 依旧开放：`Conserved.symmetric + StressLaws` 给的是**代数**
  层面的角动量守恒；从代数到算子需要边界项。§13 的缺口不变。

**给协调的一句话**：`REVERSAL-OPEN`；模型对称化失败，反转未被否定；下一步应攻
`(Q-CONS)`，而不是继续找自由理论反例（自由理论已被本计算排除）。
