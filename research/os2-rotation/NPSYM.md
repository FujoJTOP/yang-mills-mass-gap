## 0. 结论（先给判定）

1. **NP-SYM ⟹ O(4) 不成立。** 讨论稿（peer）§3 的生成步骤失败，且有两重独立理由：
   - **代数**：ρ-形变是度规形变 `diag(ρ,ρ,ρ,1)`（对称正矩阵），不是旋转；由它与
     `H(4)` 生成的群由**单项矩阵**（每行每列一个非零元）组成，其与 `O(4)` 的交恰是
     `W = H(4)` 的旋转部分。它生成不了 `SO(4)`。
   - **对称性**：更根本地，NP-SYM 是"不同度规下的极限相等"，它**不增加对称性**。每个
     `μ_{a,ρ}` 的点群是 `B₃ × ℤ₂`（与 ρ 无关），故公共极限只继承 `B₃ × ℤ₂`——
     第 2.1 节的"有限闭群障碍"再次出现。等极限不能把有限群填成连续群。

3. **正确的路线 B 是 `SYM-4D`**：有效作用量中 **O(4)-破坏部分一致 O(a²)**。

5. **4D 已知结果**：**不存在** 4D 纯 YM 的非微扰 Symanzik 定理。缺三件东西（§7.3）。

## 1. 精确陈述

### 1.1 设定

固定轴 `n ∈ {e₁,…,e₄}` 与 `ρ ∈ [1, ρ_max]`。格点

```
Λ_{a,ρ} := (ρa ℤ)³ × (a ℤ)      （3-平面垂直于 n，格距 ρa；沿 n 格距 a）
```

Wilson 作用量（两个耦合，几何面积权重已被吸收进 `β₃, β₄`）：

```
S_{a,ρ}(U) = β₃(a,ρ) Σ_{p ∈ P₃} (1 − (1/N_c) Re tr U_p)
           + β₄(a,ρ) Σ_{p ∈ P₄} (1 − (1/N_c) Re tr U_p) ,
```

`P₃` 为完全落在 3-平面内的 plaquette，`P₄` 为含 n-腿的 plaquette。记
`μ_{a,ρ} = μ_{a,ρ}(β₃,β₄)`。物理点固定：例如固定重整化耦合与
second-moment length（或固定 `Λ`）；这给出 `β₃(a,ρ), β₄(a,ρ)` 的轨迹，且
`β₃(1)=β₄(1)`。

**为什么裸耦合必须依赖 ρ**：ρ-形变改变两类 plaquette 的相对权重，即插入一个
**维数 4 的各向异性算符**（见 §2.1）。维数 4 是 marginal；不调参则物理点随 ρ 漂移，
比较无意义。讨论稿这一点正确。

### 1.2 NP-SYM

**NP-SYM（讨论稿版本）.** 存在常数 `C_O`（只依赖观测量 `O` 的物理支撑与
`(dim G, N_c)`），使对每个有界规范不变观测量 `O`、每个 `ρ ∈ [1,ρ_max]`、每个 `a`：

```
| ⟨O⟩_{a,ρ} − ⟨O⟩_{a,1} |  ≤  C_O · |ρ − 1|² · (a / a_phys)² ,        (NP-SYM)
```

逐点、非微扰、对体积 `L` 一致（`a_phys` 为固定物理标度，如 `1/Λ` 或
second-moment length）。

**形式备注（重要）**：右端的 `|ρ−1|²`（而非 `|ρ−1|`）**预设了一阶响应为零**
（即维数 4 的各向异性方向是 redundant 的，见 §2.2）。若一阶响应不为零，正确的幂次是
`|ρ−1|`。这一点必须写进陈述，否则 NP-SYM 自相矛盾（marginal 算符的一阶响应一般是 O(1)）。

### 1.3 它**不是**什么

NP-SYM 是**两个度规下的极限之比较**，不是有效作用量的渐近展开。二者不同：

- 有效作用量展开比较的是"同一个理论在不同 `a`"，系数是局域算符的 Wilson 系数；
- NP-SYM 比较的是"同一 `a` 下两个度规"，它只探测**一个**方向（比值 ρ）。

这个区别正是 §3 判定的入口。

## 2. NP-SYM 的确切内容：Duhamel 化归（廉价版）

这一节只做**严格的有限维推导**，不涉及任何未证假设。它的结论是：NP-SYM 等价于一个
连通关联的一致界——即讨论稿的"廉价版"，**成立**。

### 2.1 ρ-形变插入什么算符

在 `ρ = 1` 处对 `S_{a,ρ}` 求导。记 `Σ₃` 为完全落在 3-平面内的 plaquette 之和，
`Σ₄` 为含 n-腿的 plaquette 之和（4D 中两类各有每格点 3 个），`Σ_all := Σ₃ + Σ₄`。则

```
∂_ρ S_{a,ρ}|_{ρ=1} = c₃ Σ₃ + c₄ Σ₄ ,        （cᵢ 由 βᵢ'(1) 与几何因子给出）
```

用

```
Σ₃ = ½(Σ_all − D) ,   Σ₄ = ½(Σ_all + D) ,   D := Σ₄ − Σ₃ ,
```

得

```
∂_ρ S|_{ρ=1} = ½(c₃ + c₄) Σ_all + ½(c₄ − c₃) D .
```

`Σ_all` 是 **O(4)-不变**的维数 4 算符（各向同性 `tr F²` 的格点版本）；`D` 是维数 4、
`O(3)×ℤ₂`-不变、`O(4)`-破坏的算符。**`D` 是唯一的 marginal 各向异性方向**；调节
`β(ρ)` 只能消掉 `Σ_all` 一项（一个条件），**不能**消掉 `D`。所以 NP-SYM 的实质是两句话：

- **(R1) redundancy**：`D` 是 redundant（等价于各向异性坐标重标度），故一阶响应
  为零；否则 NP-SYM 的 `|ρ−1|²` 不成立。
- **(R2) 无关性**：消掉 `D` 的 redundant 部分后，残余的 dim-6 各向异性算符效应
  是 `O(a²)` 且体积一致。

### 2.2 Duhamel 恒等式

对有限维格点 Gibbs 测度 `μ_ρ ∝ e^{−S_ρ} dU`，标准求导给出

```
d/dρ ⟨O⟩_ρ = − Cov_ρ( O , ∂_ρ S_ρ ) =: − ⟨O ; ∂_ρ S_ρ⟩_{c,ρ} .
```

故

```
⟨O⟩_{a,ρ} − ⟨O⟩_{a,1} = − ∫₁^ρ ⟨O ; ∂_{ρ'} S_{a,ρ'}⟩_{c,ρ'} dρ' .
```

**这条恒等式是严格且可形式化的**（有限和 / 有限维积分，无未证输入；见 §6.3 的 Lean 备注）。

### 2.3 化归结果

把 §2.1 代入：`⟨O⟩_{a,ρ} − ⟨O⟩_{a,1}` 的 `O(1)` 部分由 `⟨O;D⟩_c` 给出，`O(a²)`
部分由 `⟨O;D₆⟩_c` 给出，其中 `D₆` 是 dim-6、`O(4)`-破坏、`H`-不变的算符（可能不止一个）。
在 (R1) 成立时：

```
(NP-SYM)   ⟺   sup_{ρ', a} | ⟨O ; D₆⟩_{c,ρ'} |  ≤  C_O        （体积一致）。
```

**判定**：这是一个合法、明确、且比全局唯一性弱的目标。它值得作为独立结果去做。
**但它证明的是 NP-SYM，而 NP-SYM 推不出 OS2（§3）。** 所以它不是路线 B。

## 3. 循环性判定：NP-SYM ⇏ O(4)

讨论稿 §3 要求先判定："任意 `R ∈ SO(4)` 是否可由 ρ-形变 + `H(4)` 生成"。**答案是否**，
并且即使答案是是，也不够。给两重理由。

### 3.1 代数理由：ρ-形变 + H(4) 不生成 SO(4)

ρ-形变在坐标上的实现是 `d(ρ) = diag(ρ,ρ,ρ,1)`（或其逆/幂），是**对称正定**矩阵；
`H(4)` 是带号置换矩阵。二者都是**单项矩阵**（每行每列恰一个非零元），故它们生成的群
`G_ρ` 全是单项矩阵，其非零元形如 `±ρ^k`（`k ∈ ℤ`）。一个单项矩阵正交，当且仅当非零元
都是 `±1`，即所有 `ρ`-指数为 0。因此

```
G_ρ ∩ O(4) = W        （W = 带号置换群，384 阶）。
```

于是 `G_ρ` 不含任何无理角旋转，更不含 `SO(4)`。**生成步骤失败。**

（与 R28 的关系：R28 说明"旋转格点"是推前，无信息；本节说明"拉伸格点"是度规形变，
也不是旋转。两者共同刻画了"格点几何操作"能给出什么、不能给出什么。）

### 3.2 对称性理由：等极限不增加对称性

这一条更根本，且不依赖 ρ-形变的具体形式。

`μ_{a,ρ}` 的点群是保持度规 `G_ρ = diag(ρ²,ρ²,ρ²,1)` 的格点自同构：

```
P_ρ = { M ∈ GL(4,ℤ) : Mᵀ G_ρ M = G_ρ } = B₃ × ℤ₂   （ρ ≠ 1；48·2 = 96 阶）。
```

`P_ρ` **与 ρ 无关**。若所有 `μ_{a,ρ}` 收敛到同一个 `μ*`（这正是 NP-SYM 的内容），则
`μ*` 只继承 `P_ρ = B₃ × ℤ₂`。**没有 `O(3)`，更没有 `O(4)`。**

一般原则：一族测度若有公共极限，极限只继承**公共**对称性；每个成员的点群是有限群，
交仍是有限群。**连续对称性永远不会由"格点对称性"产生**（REPORT §2.1 的障碍在
度规形变下的版本）。这就是为什么 R28 之后又重复了同一个教训：
格点几何操作给不出连续群。

### 3.3 原理性反例

设 `μ*` 是一个 `O(3) × ℤ₂`-不变但非 `O(4)`-不变的连续统理论（例如固定"光速比"的
各向异性 YM，或协方差为 `diag(c,c,c,1)` 型的高斯近似）。则"所有 ρ 的极限都等于
`μ*`"与全部格点对称性**相容**——因而 NP-SYM 可以成立而 OS2 失败。是否真的存在这样的
RG 流是动力学问题，但它表明：**NP-SYM 在逻辑上不排除 OS2 的失败**。

**结论**：`NP-SYM ⇏ O(4)`。判定为否，按讨论稿 §3 的指示，路线 B 的**这一形式**
不闭合，应予报告而非继续证明。

## 4. 与 L7 的关系（验证/修正讨论稿 §2）

逐条核对讨论稿的三点：

| 讨论稿 | 判定 | 理由 |
|---|---|---|
| NP-SYM ⟹ ρ 方向极限相等 ⟹ O(4) | **否**（第二箭头） | §3 |
| L7 ⟹ O(4)，不需要 NP-SYM | **是**，但需一个闭包前提 | 见下 |
| NP-SYM 是"单一方向、带速率"的 L7 特例：范围更窄、形式更强 | **半对** | 范围更窄 ✓；"带速率"✓；但**结论更弱**（推不出 O(4)），故不是"更强的 L7" |

**L7 ⟹ O(4) 的精确形式**：设 `L7` 断言"极限与子列、与正规化无关"，且**类在 `O(4)`
下封闭**（包含旋转后的格点正规化）。给定标准格点极限 `μ`，旋转正规化的极限是
`R_*μ`（自动，R28），由 `L7` 它必须等于 `μ`。故 `R_*μ = μ`。∎
闭包前提不可省：若 `L7` 只对"轴对齐格点"成立，则推不出 O(4)。

**L7 ⟹ NP-SYM（仅定性版本）**：各向异性族（调好参）是同一物理理论的合法正规化；
`L7` 说极限唯一，故全都等于 `μ`，于是 NP-SYM 的"极限相等"成立。∎
**但带速率的形式 `C|ρ−1|² a²` 不能由此推出**：定性唯一性不给任何 `a²` 界。要得到
定量 NP-SYM，需要 `L7` 带 rate（或直接证 §2.3 的关联界）。这一点必须写进陈述，
否则偏序表会被误读为"唯一性顺带给出定量 Symanzik"。

**NP-SYM ⇏ L7**：一个族 vs 全体；显然。

**所以三者的偏序是**：

```
L7  ⟹  NP-SYM
L7  ⟹  O(4)
NP-SYM  ⇏  O(4)        （§3）
```

NP-SYM 是 `L7` 的**弱推论**（不是弱化版）。把它当路线，等于用"唯一性"的一个后果去
替代"唯一性"本身——而它偏偏丢掉了唯一性中唯一有用的部分（旋转方向）。

## 5. 正确的路线 B：SYM-4D

### 5.1 陈述

**SYM-4D.** 存在常数 `C`，使对每个有界规范不变观测量 `O`（固定物理支撑）、每个
`H`-不变、维数 `≥ 6`、`O(4)`-破坏的局域算符 `O_k`、每个 `a` 与 `L`：

```
| ⟨O⟩_{a} − ⟨O⟩_{YM} |  ≤  C_O · a² ,          （逐项，且余项一致）
```

其中 `⟨O⟩_a` 是**各向同性** Wilson 格点（`ρ = 1`）的期望，`⟨O⟩_{YM}` 是其
Symanzik 有效作用量取 `O(4)`-不变部分后的期望。等价地：**有效作用量的 `O(4)`-破坏
部分一致为 `O(a²)`**，且其 Wilson 系数为 `O(1)`。

### 5.2 蕴含链（SYM-4D ⟹ OS2）

```
(S1) Symanzik 展开（非微扰、一致）：
       ⟨O⟩_a = ⟨O⟩_YM + Σ_k a^{d_k−4} c_k ⟨O ; O_k⟩_c + o(a²) ,
     O_k 遍历 H-不变局域算符，d_k > 4。
(S2) SYM-DIM4：d = 4 的 H-不变算符只有 O(4)-不变的（§6）。
     故所有 O(4)-破坏项都出现在 d ≥ 6，系数 a^{d−4} = a² 起。
(S3) SYM-4D 的一致界：a² 项的贡献 → 0（a → 0），且与 L 一致。
⟹   lim_a ⟨O⟩_a = ⟨O⟩_YM ，后者 O(4)-不变。
⟹   OS2（loop 形式，或 test-function 形式）。
```

**注意逻辑强度**：SYM-4D ⟹ OS2，但 OS2 ⇏ SYM-4D。所以 SYM-4D 是
**"带 rate 的 OS2"**，比 OS2 **强**。这不是捷径，而是"多证一点以证到"。

### 5.3 与 NP-SYM 的差别

NP-SYM 只控制 `D` 方向（对角/度规型）的 dim-6 组合；SYM-4D 控制整个
`O(4)`-破坏子空间。后者更大，且**不能**由前者推出：`O(4)`-破坏的 dim-6 算符中，
张量结构非对角（例如 `ℓ = 4` 谐波、混合 `D-F` 收缩）的那些不被 ρ-形变探测。

（这一点是判定 NP-SYM 不足的**第三重**理由：即使 §3 不成立，NP-SYM 的覆盖范围也不够。）

### 5.4 SYM-IR：一个常被忽略的要求

(S1) 中 `a²` 的系数是 `∫_{ℝ⁴} d⁴x ⟨O(0); O_k(x)⟩_c`——对全空间的连通关联积分。
- 有质量（指数聚类）⟹ 收敛且 `O(1)`；
- 无质量但幂衰减（如 CFT 型 `|x|^{−2Δ}`，`Δ > 2`）也可收敛；
- 但**体积一致**需要一致衰减率。

所以 **SYM-4D 不是显然独立于 MG 的**：它至少需要一个 IR 输入（指数或足够快的幂衰减）。
这正是 2D O(3) 论文绕开 Symanzik 的原因之一——它用精确分块 RG，不必对全空间积分做估计。

### 5.5 路线 D：RP + Ward 恒等式 ⇒ 无自发破坏

**陈述（D）.** 设每个极限 `μ` 满足 OS3（反射正性）、带有守恒对称的应力张量
`T_{μν}`，且 `T` 的连通关联有足够衰减（例如 `|⟨T(x) T(0)⟩_c| ≤ C|x|^{−p}`，
`p` 足够大）。若再加

```
(NoSpacetimeGoldstone)  在规范不变可观测量代数上，不存在以 `T_{μν}` 的
非标量期望值（或其它非标量序参量）为序参量的自发破坏态，
```

则每个 `μ` 是 `O(4)`-不变的（**U2**）。

**逻辑.** RP ⟹ 重构 Hilbert 空间与正 Hamilton；Ward 恒等式把
`∂_μ⟨T_{μν} O⟩` 写成对 `O` 的平移/旋转变分。若 `μ` 不 `O(4)`-不变，
则存在非零的各向异性应力 `⟨T_{μν}⟩ − (1/4)δ_{μν}⟨T⟩`（或相应的非标量序参量）；
Ward 恒等式 + 衰减把它逼为零。

**缺口（诚实）.** `NoSpacetimeGoldstone` **不是标准定理**。Goldstone 定理对
*内部* 对称性成立；对时空间对称性，破缺不产生通常意义上的无质量粒子，论证必须另起。
可用的结构：(i) 规范不变代数里只有一个标量序参量，没有低维矢量序参量；

## 6. 严格小引理与 Lean 目标

### 6.1 SYM-DIM4：dim-4 无各向异性（完全严格）

**命题 SYM-DIM4.** 设 `W ⊂ O(4)` 为带号置换群，作用在对称矩阵空间 `Sym²(ℝ⁴)` 上：
`(w·A) = w A wᵀ`。则不变子空间 `(Sym²(ℝ⁴))^W = ℝ·I`，维数 1。

*证明.* 平均投影 `P A := (1/|W|) ∑_{w∈W} w A wᵀ` 是到不变子空间上的投影。
先对符号翻转子群 `(ℤ₂)⁴` 平均：`(1/16) ∑_ε ε A ε` 把非对角元全部消掉，得到 `diag(a₁,…,a₄)`
（`a_i = A_{ii}`）。再对置换群 `S₄` 平均：`(1/24) ∑_σ P_σ diag(a) P_σᵀ = diag(ā,…,ā)`，
`ā = (∑ a_i)/4 = tr A / 4`。故 `P A = (tr A / 4) I`。因 `I` 不变，`P` 的像恰为 `ℝI`。∎

**含义（注意精确措辞）**：纯规范、`H`-不变、维数 4 的**算符空间是
`{tr F², tr F̃F}`**（后者 P-odd 但 `O(4)`-不变），并非一维。命题给出的是
"**无各向异性**"，不是"算子空间一维"：各向异性只能来自
`Σ_{μν} c_{μν} tr F_{μν}²` 型算符，其系数张量 `c_{μν}` 是 `W`-不变的对称张量，
由命题必为 `c δ_{μν}`，即该项本身 `O(4)`-不变。故**没有 O(a) 的各向异性**，
领头项从 dim 6 开始；这是"无需 fine-tuning"的严格内容（与 SME 的 dim-4 分类一致）。

**范围（重要）**：Lean 工件只证"系数张量 `= cδ`"。从"系数张量为 `cδ`"到
"有效作用量的 dim-4 部分无各向异性"需要 dim-4 算符分类（`{tr F², tr F̃F}`）；
这是**物理步骤，非 Lean**。不要把 §6.2 的定理读成"Lean 已证 dim-4 算子空间一维"。

### 7.4 2D 证明里真正不可替代的是什么（已按源码更正）

**源码核对**（commit `adc7f1241b42e322a6451854ab7e4b4c146bf78a`，
`sections/uniqueness.tex`）：

- (3.8) `G_{s+d}=(O_+^{-1})_*G_s=(O_-^{-1})_*G_s` 是**精确等式，无余项**。证明用：
  倾斜轨迹的微观间距是 `L^{-N}/5`、空间嵌入是 `O_±^{-1}`，second-moment length
  **恰好**缩小 5 倍，canonical normalization 对场乘子**恰好**协变。没有任何 `O(a²)`。
- Lemma 3.8（标签 `lem:dense-periods`，"Two scale relations force constancy"）的结论有
  **两条**："every `G_s` is Euclidean rotation invariant, **and** `G_s` is independent
  of `s`"。其前提只有 (3.7)(3.8) + 连续性 + 重叠条件 `2R−|d|>γ`，**没有** RG 不动点
  假设。所以它是**刚性引理**，不是"唯一不动点"定理；它的"唯一性"是**沿形状参数族
  的规范化极限唯一**，不是 route C 的 U1。

四项按重要性重排：

1. **精确性（致命）**：Lemma 3.8 的密度论证要求 `d/γ ∉ ℚ` 且 `ℤγ+ℤd` 稠密，
   这依赖 (3.7)(3.8) 是**精确周期**。4D 没有精确分块，`D₆ ≠ 0`，只能得到
   `G_{s+d} = (R^{-1})_*G_s + O(a²)`；稠密性论证退化为"近似周期"，结论只剩
   `O(a²)` 的近似不变性 ⟹ **SYM-4D + SYM-IR**。具体失效的就是
   "`G_{s+d}=(O_±^{-1})_*G_s` 的精确性"这一步。
2. **一维流/超可重整（致命，与 1 配套）**：2D 的流由单个标量函数 `s ↦ G_s` 概括
   （一个耦合，没有需要跟踪的各向异性 marginal 方向），所以 (3.8) 能用"同一裸耦合下
   两条轨迹"精确表述。4D 的流是无穷维的，且有一个 marginal 各向异性方向 `D` 需要
   redundant 化处理——这是 (3.8) 精确性失效的结构原因。
3. **秩/Niven（已被克服）**：`SO(2)` 秩 1，一个无理角足够；4D 由命题 D 用三个
   (3,4,5) 旋转的稠密性解决，不需要 Niven。
4. **形状空间维数（技术乘数，非障碍）**：1 维 vs 9 维只增加参数，不改变论证结构。

**结论**：真正不可替代的是 (1)+(2)——**精确形状关系**。在 4D 它退化为 `O(a²)`，
即 `SYM-4D`，并拖上 `SYM-IR`。
