# OS2：连续统 Yang–Mills 测度的全 O(4) 不变性

> 2026-11-22 · 范围：纯 Yang–Mills₄ 的 Wilson 格点标度极限。
> 问题：格点只保留超立方群 `H = aℤ⁴ ⋊ W`（`W` 为带号置换群，`|W| = 2⁴·4! = 384`），
> 为什么 `a → 0` 的极限要对整个 `O(4)` 不变，以及严格证明需要什么。

---

## 0. 结论摘要

1. **OS2 不能由对称性 + 连续性"免费"得到。** `W` 是 `O(4)` 的**有限闭子群**，
   有限群在连续极限下不会"长大"；极限测度只能继承 `W`。真正需要升级的是
   `O(4)/W` 这部分。平移部分则可以（`aℤ⁴` 在 `ℝ⁴` 中稠密），见 L1。
   因此 OS2 是**动力学陈述**，不是形式陈述：各向异性的格点作用量（不同方向的
   耦合不同）其极限确实不是 `O(4)` 不变的。

2. **路线是 B、C、C′、D；"倾斜分块"是归约，不是路线（gluing R28）**：
   - **A（归约，不是路线）. 稠密子群的归约**：若 `μ` 在三个显式旋转
     `R₁₂, R₁₃, R₂₄` 下不变，则（配合连续性）OS2 成立。本报告给出这三个
     (3,4,5) 旋转与稠密性证明（命题 D，§3.3）。**但这条不变性不能由倾斜格点
     推出**：`B_ij aℤ⁴ = R_ij(5aℤ⁴)`，故倾斜正规化的极限**自动**是
     `(R_ij)_* μ`；"倾斜极限 = μ"与结论等价，是循环的（§1.3 备注）。
     所以 A 只把 O(4) 归约为三个旋转的不变性，不提供证明。
   - **B. Symanzik / 无关算符**（所谓"Weinberg 定理"的真实内容）：需要证明
     `O(4)`-破坏部分在有效作用量中 **O(a²)** 被压制且体积一致。到 dim 4
     为止各向异性被 `H` 完全杀死（§4.2），所以领头项从 dim 6 开始——这解释了

## 1. 精确陈述

### 1.1 格点设定

`G` 紧单群（如 SU(N_c)），`d = 4`，格距 `a > 0`，格点 `aℤ⁴`，环面 `𝕋_{L,a}`
（边长 `L`，`1/a` 为 UV 截断；按 gluing session 的记法约定，`Λ` 保留给 QCD 标度，
本报告不使用 `Λ` 指格点）。`θ = 0`，'t Hooft 通量取平凡。`Ω_a` 为格点规范场空间。
Wilson 测度

```
dμ_{a,β}(U) = Z_{a,β}^{-1} · exp( β Σ_{p∈P(aℤ⁴)} (1 − (1/N_c) Re tr U_p) ) Π_e dU_e ,
β = 2N_c/g₀² ,
```

`P(aℤ⁴)` 为 plaquette 集合，`dU_e` 为 Haar 测度。`μ_{a,β}` 在
`H_a := aℤ⁴ ⋊ W` 下**精确不变**（`W` = 带号置换矩阵 = `O(4) ∩ GL(4,ℤ)`），
其中 `W` 同时含全部置换与全部 16 个符号翻转，故也含宇称与各向同性反射。

**可观测量**取 Wilson 环期望。对分段 `C¹` 的闭环 `γ ⊂ ℝ⁴`，取格点逼近
`γ_a`（顶点在 `aℤ⁴` 上，`γ_a → γ`），定义

```
W_γ(μ_a) := ∫ (1/N) Re tr_□ hol_{γ_a}(U) dμ_a .
```

（等价的"广义联络"表述：`μ` 是 Ashtekar–Isham–Lewandowski 型空间上的测度，
`W_γ` 为柱函数期望。两种表述下 `O(4)` 都连续地作用在观测代数上。）

**约定（RT 与方案常数，GL1 / C3）**：本接口使用与 `A0 §1.4` **相同的重整化轨迹**
与**同一方案常数 `C`**；§1.3 的 `β(a)`（以及 `NPSYM.md` 的 `β(a,ρ)`）都沿这条 RT，
不引入新的方案常数。

### 1.3 主定理（含显式假设）

**定理 1.** 极限按**顺序次序**取：先 `a ↓ 0`（固定 `L`，`β(a)` 沿渐近自由轨迹）
得 `μ_L`，再 `L → ∞` 得 `μ`（子列即可；不做联合极限）。对每个固定 `L` 设：

- **(H1) 极限 + 连续性（`L`-一致）**：对所有 `γ ∈ ℒ`，`W_γ(μ_{L,a}) → W_γ(μ_L)`；
  且 `γ ↦ W_γ(μ_L)` 关于 `C¹`（或 Lipschitz–Hausdorff）拓扑连续，模常数与 `L` 无关
  （只需对紧集内的 `γ`）。
  （test-function 版本：`Z_μ` 在 Schwartz 拓扑下连续——由 OS0+OS1 给出，见 L4'。）
- **(H2) 格点对称**：每个 `μ_a` 在 `H_a` 下不变。（精确成立。）
- **(Γ-INV) 三个旋转的不变性**：`μ` 在 `R₁₂, R₁₃, R₂₄` 下不变（§3.3，
  `B_ij = 5·R_ij ∈ M₄(ℤ)`，`B_ijᵀB_ij = 25 I`）。

则 `μ` 在 `E(4) = ℝ⁴ ⋊ O(4)` 下不变，即 OS2 成立。

**证明结构**：L1（平移）→ L2（`W`）→ L3（命题 D：`⟨R₁₂,R₁₃,R₂₄⟩` 稠密于 `SO(4)`）
→ L4（连续延拓）→ 合并。详见 §6。

**备注（gluing R28：为什么 `Γ-INV` 不能由倾斜格点推出）.** 设 `B_ij = 5R_ij`。
则细格距 `a` 的倾斜格点满足

```
B_ij · aℤ⁴ = 5R_ij aℤ⁴ = R_ij · (5aℤ⁴) ,
```

即"格距 `a` 的倾斜格点"就是"格距 `5a` 的标准格点旋转 `R_ij`"。于是其上 Wilson
测度恰是 `(R_ij)_* μ_{5a}`，其连续极限（`a → 0`）**自动**为 `(R_ij)_* μ`
（假定 `μ_{5a} → μ`）。因此"倾斜正规化的极限等于 `μ`"与"`(R_ij)_* μ = μ`"
**逻辑等价**，后者正是结论。**倾斜正规化不携带任何独立信息**；
`Γ-INV` 必须由 B（无关算符）或 C（唯一性）给出。定理 1 的全部内容是：
要证 OS2，只需证三个特定旋转的不变性（连续性延拓免费）。

（这也解释了一个表面上的悖论：若倾斜正规化的极限"自动"给出旋转不变性，那各向
异性理论的极限也应当旋转不变——但它并不；原因正是上述"自动"只给出
`(R_ij)_* μ`，除非 `μ` 已旋转不变，否则它不等于 `μ`。）

### 1.4 两个变体（说明 OS2 的"刚性"本质）

**定理 1′（C′：唯一不动点形式）.** 设 `𝒞` 为一带 `O(4)` 连续作用的测度类，
`T : 𝒞 → 𝒞` 为 RG 步进映射，满足 `T(E_*ν) = E_*T(ν)`（等变性），且 `μ ∈ 𝒞` 是
`T` 在 `𝒞` 中的**唯一**不动点。则 `μ` 是 `O(4)`-不变的。

> 证明：`T(R_*μ) = R_*T(μ) = R_*μ`，故 `R_*μ` 也是不动点，唯一性给出 `R_*μ = μ`。∎

**定理 1″（Symanzik 形式）.** 若存在 `O(4)`-不变的测度族 `ν_a` 使

```
sup_{γ ∈ ℒ, γ ⊂ K} | W_γ(μ_a) − W_γ(ν_a) |  ≤  C_K · a² ,
```

且 `ν_a → ν`，则 `μ = ν`，故 `μ` 是 `O(4)`-不变的。

> 证明：`|W_γ(μ) − W_γ(ν)| ≤ limsup |W_γ(μ_a) − W_γ(ν_a)| + |W_γ(ν_a) − W_γ(ν)| ≤ 0`。∎

**关系**：定理 1 是**归约**（假设 `Γ-INV`，结论 OS2），不是路线。定理 1″ 是 **B**
（`SYM-4D`）。定理 1′ 是 **C′**：它要求唯一不动点，比 2D 的 Lemma 3.8 强——
**2D 方法不需要唯一性**，只需两条精确关系 + 连续性。2D 的真实机制在 4D 的定量版
是 **C = O1(a)**（两轨迹差估计），它蕴含 **B**；故 `B ⊂ C`，而 C′ 是另一条独立、
更强且不带速率的思路（且 ⇏ B）。

## 2. 为什么这不是形式问题

### 2.1 闭子群障碍

`μ_a` 在每个 `a` 上只有 `H_a` 不变。取极限时：

- **平移**：`aℤ⁴` 随 `a` 变，但趋于稠密；用"双极限"可证极限平移不变（L1）。
- **旋转**：`W` 不随 `a` 变，且 `W` 是 **`O(4)` 的闭子群**。若 `μ_a → μ` 且每个
  `μ_a` 是 `W`-不变，则 `μ` 是 `W`-不变（有限群作用连续）。**仅此而已**。
  没有任何连续性论证能把 `W` 的 384 个元素"填满" `O(4)`：`W` 的闭包就是 `W` 本身。

### 2.2 反例直觉

取各向异性 Wilson 作用量 `β_t Σ_{时间片} Re tr U_p + β_s Σ_{空间片} Re tr U_p`，
`β_t ≠ β_s`。其在 `a → 0` 的极限（若存在）**不是** `O(4)` 不变的——它只有
`O(3) × ℤ₂` 型的子群。所以"格点极限自动恢复连续对称性"**不是**一般定理；
它依赖于各向同性（`β_t = β_s`）+ 重整化群把各向异性当作无关算符压掉。
这正是 OS2 的动力学内容。

### 2.3 因此 OS2 的地位

在 RG 框架里，OS2 **等价于**"连续极限是 `O(4)` 不变的 RG 不动点"；
在格点推前框架里，它**等价于**"极限不记得格点取向"。两者都是**刚性**陈述，
其难度不低于（甚至可以说蕴含于）"极限唯一性"这一公开难题。
**但 OS2 本身不要求质量间隙**：它是关于极限测度的陈述，不是关于谱的陈述。

### 3.2 4D 的困难：秩与交换性

2D 的技巧能用一个生成元，是因为 `SO(2)` 是交换的一维群。4D 不行：

- **循环子群的闭包是交换群**；`SO(4)` 非交换，故稠密子群**至少需要 2 个生成元**。
- `SO(4)` 秩为 2，最大环面 `T²` 是交换的二维群；两个**交换**的平面旋转最多生成
  一个环面，闭包维数 ≤ 2 < 6。故必须有**非交换**的生成元。
- `SO(4) ≅ (SU(2) × SU(2)) / {±1}`：稠密子群必须在两个 `SU(2)` 因子上都投影稠密。

**结论**：4D 需要**多个（至少两个、实用上三个）不同平面内的独立倾斜**，
而不是 2D 的单个倾斜。

### 3.3 命题 D：显式三个 (3,4,5) 倾斜分块稠密于 SO(4)

取 `ϑ ∈ (0,π)`，`cos ϑ = 3/5`，`sin ϑ = 4/5`（故 `ϑ/π ∉ ℚ`，Niven）。
对 `(i,j) ∈ {(1,2),(1,3),(2,4)}`，令 `R_ij(ϑ) ∈ SO(4)` 为 `(ij)` 坐标平面内
旋转 `ϑ`、其余两个坐标不动的旋转。三个分块矩阵

```
B₁₂ = 5·R₁₂ = [[3,−4,0,0],[4,3,0,0],[0,0,5,0],[0,0,0,5]]
B₁₃ = 5·R₁₃ = [[3,0,−4,0],[0,5,0,0],[4,0,3,0],[0,0,0,5]]
B₂₄ = 5·R₂₄ = [[5,0,0,0],[0,3,0,−4],[0,0,5,0],[0,4,0,3]]
```

每个满足 `BᵀB = 25 I`、`B ∈ M₄(ℤ)`、`det B = 5⁴ = 625`。故 `B_ij ℤ⁴ ⊆ ℤ⁴`
是 index 625 的子格，且 `B_ij ℤ⁴ = 5·R_ij ℤ⁴` 是一个**间距 5、旋转了 `ϑ`
的立方格**——即"倾斜"但仍正交的格点。这正是 2D 情形的 4D 类比。

**命题 D.** `Γ := ⟨R₁₂(ϑ), R₁₃(ϑ), R₂₄(ϑ)⟩` 在 `SO(4)` 中稠密。

*证明.* 令 `H = cl(Γ) ⊆ SO(4)`，是紧 Lie 子群，李代数 `h`。记 `X_ij ∈ so(4)`
为平面生成元，`so(4) = span{X_ij}`。因 `ϑ/π ∉ ℚ`，对每个平面存在
`n_ij ∈ ℕ` 使 `g := R_ij(ϑ)^{n_ij}` 落在单位元的对数坐标邻域内且
`log g = c_ij X_ij`，`c_ij ≠ 0`。标准事实：`log(H ∩ U) ⊆ h`（`U` 为小邻域），
故 `X_ij ∈ h`。于是 `h` 在李括号下包含

```
[X₁₂, X₁₃] = −X₂₃ ,   [X₁₂, X₂₄] = X₁₄ ,   [X₁₃, X₁₄] = −X₃₄ ,
```

即全部 6 个基元，`h = so(4)`。于是 `H°` 是 `SO(4)` 中维数 6 的连通 Lie 子群，
从而开于 `SO(4)`，从而 `H° = SO(4)`（`SO(4)` 连通）。又 `H ⊆ SO(4)`
（生成元都在 `SO(4)` 内），故 `H = SO(4)`。∎

**推论 D′.** 因 `W` 含 `det = −1` 的元素（符号翻转），`W · SO(4) = O(4)`；
故 `μ` 若在 `SO(4)` 与 `W` 下不变，则在 `O(4)` 下不变。

**命题 D 的地位（gluing R28 之后）.** 命题 D **只是一个密度引理**，不是 O(4)
证据。它说：若 `μ` 在三个显式旋转下不变，则（配合连续性）在 `SO(4)` 下不变。
它**不能**用来从倾斜正规化推出 OS2——因为倾斜正规化给不出独立信息
（§1.3 备注）：`B_ij aℤ⁴ = R_ij(5aℤ⁴)`，其极限自动是 `(R_ij)_* μ`。
命题 D 的价值在于把"O(4) 不变性"归约为"三个特定旋转的不变性"，把 6 维的
`SO(4)` 换成三个生成元；这仍是有用的归约，但不是证明。

（附注：倾斜格点作为**替代正规化**本身是合法的——`B_ijℤ⁴` 是间距 5 的立方格，
Osterwalder–Seiler / Menotti–Pelissetto 逐字适用，反射正性成立在**它自身的**
坐标系里；但这与 O(4) 无关，也不进入 RP RG。见 §8.3(5)。）

**备注（与 2D 的结构差异）**：
- 2D 需要**一个**无理角（Niven 定理）即可稠密；
- 4D 需要**每个**角 `ϑ_ij/π ∉ ℚ`（保证每个生成元有无穷阶、贡献非零李代数方向），
  但**不需要角度之间任何算术关系**（如有理独立性）——稠密性完全由李代数给出；
- 一个有用的普适事实：紧 Lie 群的闭子群只有可数多个，故
  "`(g₁,g₂)` 生成的子群稠密"是 `G × G` 中的稠密 `G_δ` 集；
  因此**几乎每一对**生成元都拓扑生成 `SO(4)`。选 3-4-5 只是取一个显式的有理点。

### 3.4 4D 没有 (3.8) 的类比

2D 的 (3.8) 若要非平凡，其核心是 Lemma 3.8（规范化极限 `G_s` 与 `s` 无关），
证明用到精确分块结构与反射。4D 没有精确分块 RG，也没有 `G_s` 这一族规范化极限。
因此：

- 若把倾斜关系写成"倾斜正规化的极限 = `μ`"，则它是**恒真的推前**，与结论等价
  （§1.3 备注），不能作为输入。
- 若要有内容，需要 4D 版的"形状参数 + 规范化唯一性"（§8.2 的 P1–P3）；其中
  P3（`G_σ` 与 `σ` 无关）本身就是一个唯一性定理，与路线 C 同级。

**结论**：在 4D，`Γ-INV` 不能由倾斜正规化得到；它必须来自 B（无关算符）或
C（唯一性）。倾斜分块对 4D OS2 的贡献仅限命题 D 这条归约。

（若只有"两个反射倾斜"可用，则只能得到 `R_ij(2ϑ)` 的不变性；
`cos(2ϑ) = −7/25 ∉ {0,±1/2,±1}` 仍给出 `2ϑ/π ∉ ℚ`，命题 D 照常成立。）

### 3.5 连续性引理（L4，可立即形式化）

**引理 L4.** 设 `Z : S(ℝᵈ,ℂ) → ℂ` 连续，`Γ ≤ E(d)` 稠密，且
`∀ g ∈ Γ, ∀ f: Z(g•f) = Z(f)`。则 `∀ g ∈ E(d), ∀ f: Z(g•f) = Z(f)`。

*证明.* 固定 `f`。映射 `φ(g) := Z(g•f)` 是 `E(d)` 上的连续函数
（`g ↦ g•f` 连续，`Z` 连续），在稠密集 `Γ` 上恒等于 `Z(f)`；故 `φ ≡ Z(f)`。∎

Lean 目标（与 YM 无关，使用现有的 `euclidean_action`）：

```lean
theorem os2_of_dense_subgroup
    (Z : SchwartzTestFunctionℂ d → ℂ) (hZ : Continuous Z)
    (Γ : Subgroup (QFT.E d)) (hΓ : Dense (Γ : Set (QFT.E d)))
    (h : ∀ g ∈ Γ, ∀ f, Z (QFT.euclidean_action g f) = Z f) :
    ∀ g : QFT.E d, ∀ f, Z (QFT.euclidean_action g f) = Z f
```

配套需要 **L4′**：`Z_μ := GJGeneratingFunctionalℂ μ` 的连续性。这由 OS0（解析性）
+ OS1（指数界）经 **Zorn 定理**给出（在局部凸空间上逐有限维解析 + 局部有界 ⟹
连续）。这也是一个独立的、可形式化的小引理。

## 4. 工具 B：Symanzik / 无关算符（"Weinberg 定理"的真相）

### 4.1 有效作用量展开

Symanzik 的图像：格点理论的 Schwinger 函数等于一个**连续统**理论的，后者的
作用量为

```
S_eff = S_YM + a Σ_j c_j^{(5)} O_j^{(5)} + a² Σ_j c_j^{(6)} O_j^{(6)} + O(a⁴) ,
```

`O_j^{(p)}` 为 `H`-不变、维数 `p` 的局域算符（`S_YM` 本身已含维数 4 的项，
且各向同性）。关键：**只有 `H`-不变但不 `O(4)`-不变的项产生各向异性**。

### 4.2 维数 4：各向异性被 H 完全杀死

这是整条路线能成立的**第一块基石**，且是一个可以严格检查的有限维表示论事实：

- 纯规范、维数 4、`O(4)`-破坏、`H`-不变的算符，其张量结构在 SME
  （Colladay–Kostelecký）分类中由对称无迹张量 `c_{μν}` 之类刻画。
- `W` 含全部 4! 置换与全部 16 个符号翻转，故 `c_{μν} = c δ_{μν}`，
  即该项退化为 `O(4)`-不变的 `tr F²`。
- 所以**没有** O(a) 的各向异性；领头各向异性从 **dim 6** 开始（纯规范
  规范不变算符维数为偶数：4, 6, 8, …）。

**这就是"无需 fine-tuning"的严格内容**：维数 4 的各向异性被超立方对称性禁止，
不是被动力学压掉的。

### 4.3 维数 6：领头项，需要一致 O(a²) 界

dim-6 的 `H`-不变但非 `O(4)`-不变的算符（如 `tr(D_μF_{νρ})²` 的各向异性组合、
`ℓ = 4` 谐波通道）其系数必须是 `O(1)`，余项 `O(a⁴)`，才能得到定理 1″ 的
`C a²`。两个缺口：

1. **非微扰有效性**：Symanzik 展开一般是微扰结果；非微扰地证明它需要 RG 控制
   有效作用量（Balaban / BBS 型），这本身是 4D 的硬点。
2. **一致性**：`C_K` 必须与体积、与观测量的尺度无关（至少对紧集内的环一致）。
   IR 方向（大尺度）也要控制，因为各向异性算符是**无关的**，其效应随尺度衰减，
   但需要定量的衰减率。

### 4.4 精确的引理形式

即定理 1″：**若 `μ_a` 与某个 `O(4)`-不变族 `ν_a` 在环期望上相差 `O(a²)`（一致），
则极限 `O(4)`-不变。** 注意这**不需要唯一性**——这是路线 B 相对 A/C 的逻辑优势。

### 4.5 Paley–Wiener / 聚类的作用

要把"动量空间色散分析"变成"位置空间一致界"，通常需要 **指数聚类 ⟹ 复动量解析性
（Paley–Wiener）**，从而把 `ℓ = 4` 谐波通道的贡献用解析性 + 色散关系控制为
`O(a²)`。这解释了为何这条路线在**有质量**（或至少有指数聚类）的区域可行，
而纯 YM 的聚类本身正是 MG 的内容——**路线 B 与 MG 有交叠**，但不是同一件事：
OS2 只需要"足够刚性以定义极限"，不需要体积一致的速率。

- 检索未找到任何可信来源把"Weinberg 定理"陈述为关于格点极限恢复 Lorentz 不变性的

## 5. 工具 C：RG 等变 + 不动点唯一性

定理 1′ 已给出三行证明。其价值在于**把 OS2 精确地归约为一个唯一性陈述**：

```
OS2  ⟸  (RG 步进在 O(4) 下等变)  +  (𝒞 中 T 的不动点唯一) .
```

- **等变性**通常是可证的：只要 RG 步进由几何对象（分块核、粗化映射）定义，
  且该几何对象在 `O(4)` 下协变，`T` 就等变。困难在于**把 `T` 定义在一个
  包含旋转后测度的类上**（即类必须是 `O(4)`-不变的）。
- **唯一性**是公开难题的近亲。注意它比"无限体积极限唯一"**弱**：
  只需在一个自然的类 `𝒞` 里唯一，不必对所有子列/所有边界条件唯一。
- 与定理 1 的关系：定理 1 把 OS2 归约为较小的群 `Γ = ⟨R₁₂,R₁₃,R₂₄⟩` 上的不变性，
  但 `Γ-INV` 不能由倾斜正规化得到（§1.3 备注）；所以要落到地上，仍需这里的不动点
  唯一性（或路线 B 的定量估计）。

**这条路线最值得审计的地方**：4D 构造的 `RG1–RG5` 输入是否已经隐含了
"有效作用量类在 `O(4)` 下封闭 + 流收缩各处异性方向"。若没有，需要补一条
"对称性恢复"估计；若有，OS2 可能比预想的近。

## 附录 A：命题 D 的括号计算

约定 `e_ab = E_ab − E_ba`（`a < b`），
`[e_ab, e_cd] = δ_bc e_ad − δ_ac e_bd − δ_bd e_ac + δ_ad e_bc`。

```
[e₁₂, e₁₃] = −e₂₃
[e₁₂, e₂₄] =  e₁₄
[e₁₃, e₁₄] = −e₃₄
```

`span{e₁₂, e₁₃, e₂₄}` 在李括号下生成 `{e₂₃, e₁₄, e₃₄}`，合计 6 个基元，
故生成 `so(4)`。∎
