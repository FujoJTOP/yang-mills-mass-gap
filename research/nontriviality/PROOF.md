## 1. 记号、格点测度 A0 与基本设定

### 1.1 格点测度 A0（九个接口共享，逐字引用）

**所有**结论消费**同一个**有限体积格点测度族 `μ_{L,a,β}`，逐字引用 `research/gluing/REPORT.md` §1（A0）与 `research/glue-c-gauge-group/REPORT.md` (1.1)–(1.2)：

```
μ_{L,a,β}  ∝  exp(−S_W(β)) ∏_e dU_e ,
S_W(β)     =  β Σ_p ( 1 − (1/N_c) Re tr U_p ) ,     β = 2N_c/g² ,     N_c := dim f ,
⟹  μ_{L,a,β}  ∝  exp( (β/N_c) Σ_p Re tr U_p ) ∏_e dU_e   ≡   exp( γ Σ_p Re tr U_p ) ∏_e dU_e ,
   其中  γ := β/N_c  是进入测度的  Σ_p Re tr U_p  系数。
```

- **迹约定**：`tr` 为**未归一化**定义表示迹（`tr_f 1 = N_c`），`N_c := dim f`（不只 `SU(N)` 的 `N`；否则 `β` 在 `SO/Sp/例外群` 上不唯一，破坏 GL1/GL8）。
- **β 与 γ 的区别（防陷阱）**：作用量系数 `β = 2N_c/g²`；进入测度 `exp(·)` 的 `Σ_p Re tr U_p` 的系数是 `γ = β/N_c = 2/g²`。例：`SU(3)`、`g²=1` ⟹ `β=6`、`γ=2`。**不得把 `γ` 记作 `β`**（否则得错误值 `β=2`）。
- **极限顺序（A0 §1.6）**：先 `a→0`（固定物理体积 `L`）、后 `L→∞`；本文非平凡性在固定 `L` 的 UV 极限 + `L→∞` 子列上陈述。
- **轨迹**：沿渐近自由轨迹，`β(a)=2N_c/g₀(a)²`，`g₀(a)²=1/(2b₀ ln(1/(aΛ)))+…`（`b₀=11N/(48π²)`，见 §5）。

### 1.2 其余记号

- 纯 `YM₄`，紧单群 `G`（主例 `SU(N)`）；`μ_a` 即 `μ_{L,a,β(a)}` 在固定 `L` 的 UV 极限下的测度族，`μ` 为 OS **子列** `L→∞` 极限。
- 生成泛函（Euclidean）：`G_μ(J) = ∫ e^{i⟨φ,J⟩} dμ(φ)`，`J ∈ 𝒮(ℝ⁴)`（或规范场配置上的对偶）。OS0/OS1 给出 `G_μ` 在 `J=0` 邻域解析、被其矩唯一确定（OSforGFF 已实现该唯一性）。

## 2. 引理 C：Gaussian ⟺ 高阶累积全零

### 2.1 陈述

> **引理 C.** 设 `μ` 是概率测度且 `G_μ` 在 `0` 邻域解析、被矩唯一确定。则
> `IsGaussianMeasure μ  ↔  ∀ n ≥ 3, ∀ f₁,…,f_n : κ_n(f₁,…,f_n) = 0.`

### 2.2 证明

**(⇒)** `μ` Gaussian ⟹ `G_μ(J) = exp(c + ℓ(J) + q(J))`，`ℓ` 线性、`q` 二次（含零均值时的 `c=0`）。故 `log G_μ = c + ℓ + q` 是关于 `J` 的**次数 ≤2 的多项式**，其所有 `≥3` 阶导数在 `0` 处为零，即 `κ_n = 0`（`n≥3`）。∎

**(⇐)** 假设 `κ_n = 0` 对所有 `n≥3`。由 OS0/OS1，`K(J) := log G_μ(J)` 在 `0` 的某凸邻域 `U` 解析，其 Taylor 级数在 `U` 内收敛。`κ_n` 是 `K` 的 `n` 阶系数，故 `K` 在 `U` 内的 Taylor 级数**只有 ≤2 阶项**，于是 `K(J) = A + L(J) + Q(J)` 对 `J∈U`（`L` 线性、`Q` 二次、`A=K(0)`, `G(0)=1 ⟹ A=0`）。由唯一性延拓，`K ≡ L+Q` 在 `0` 的连通邻域上；又 `G` 解析 ⟹ `G = exp(L+Q)` 全局成立。由 Minlos/Bochner 唯一性（测度由特征函数 `G_μ` 在 `𝒮` 上的值唯一确定），`μ` 是以协方差 `Q` 为二次型、均值由 `L` 给出的（平移）Gaussian 测度，即 `IsGaussianMeasure μ`。∎

> **注 2.1（为何 ⇐ 需要"所有阶"，而非仅 4 阶）**：`K` 是次数 ≤2 的多项式**当且仅当所有 ≥3 阶系数为零**。仅知 `κ₄=0` 只说明 `K` 没有 4 阶项，仍可能有 6、8、… 阶项。下一小节给出反例。

### 2.3 纠正：偶性 + κ₄=0 **不**推出 Gaussian（Lean 已检验）

早先草稿（`REPORT.md` §6.1）曾写"偶性下 `n=4` 一项即可"，**这是错的**。反例：

取 `X ∈ {−1, 0, 1}`，权重 `(1/6, 2/3, 1/6)`。它**偶**（对称），且
```
m₂ = m₄ = m₆ = 1/3,   m₁ = m₃ = m₅ = 0。
κ₄ = m₄ − 3 m₂² = 1/3 − 3·(1/9) = 0,
κ₆ = m₆ − 15 m₄ m₂ − 10 m₃² + 30 m₂³ = 1/3 − 15/9 + 30/27 = −2/9 ≠ 0。
```
即：**偶、`κ₄=0`、但 `κ₆≠0`，故非 Gaussian。** 于是"偶 + 连通 4 点为零 ⟹ Gaussian"为**假**。

`NonTrivialCore.lean` 检验（整数化，`D=6`，`κ₄=K4/D²`、`κ₆=K6/D³`）：
```lean
theorem gauss4_K4_zero : K4 gauss4 = 0 := by decide
theorem gauss4_K6      : K6 gauss4 = -48 := by decide   -- κ₆ = -48/216 = -2/9
theorem four_point_insufficient : K4 gauss4 = 0 ∧ K6 gauss4 ≠ 0 := ⟨…, …⟩
```
`#print axioms four_point_insufficient` → **不依赖任何公理**。

> **结论（修正后）**：非平凡的合格见证必须控制**所有** `n≥3` 阶累积（偶性消去奇数阶，但**每个偶阶 4,6,8,… 都必需**）。**单靠连通 4 点不足**。这正是 §6.3 "为何 `g_ren`（而非某个连通 4 点）是正确定义" 的形式化理由。

### 2.4 与 `Basic.lean` 的接口

`Basic.lean` 的 `ConnectedFourPoint` 是 `κ₄` 的显式展开（`S₄ − S₁₂S₃₄ − S₁₃S₂₄ − S₁₄S₂₃`），`NonTrivial := ¬IsGaussianMeasure`。引理 C 把二者等价化：`¬IsGaussianMeasure ↔ ∃n≥3, κ_n≠0`，即 `NonTrivial ↔` 存在某阶非零连通函数。§2.3 说明**不能**把 `n` 收紧到 4。

## 3. 引理 G：Gaussian ⟹ `g_ren ≡ 0`

### 3.1 `g_ren` 的定义（任意标准物理 scheme）

固定一个**质量无关、规范不变**的重整化 scheme。在动量标度 `p` 处定义归一化耦合
```
g_ren²(p) := [Γ^{(3)}_{phys}(p)]² / [Γ^{(2)}_{phys}(p)]³ ,     归一化到树级值 1 的倍数，
```
其中 `Γ^{(n)}` 是重整化 `n` 点顶角（`n=3` 取三胶子或鬼-胶子顶角的横向部分，`n=2` 取传播子逆）；"phys" 表示规范不变的物理组合（MOM/梯度流/静态力等任一标准定义）。规范依赖在**顶角与传播子的比值中相消**，故 `g_ren(p)` 规范不变。

### 3.2 陈述与证明

> **引理 G.** 若 `μ` 是 Gaussian（准自由联络 `A`），则 `g_ren^μ(p) = 0` 对所有 `p`。等价地（反证用）：`∃p, g_ren^μ(p) ≠ 0 ⟹ ¬IsGaussianMeasure μ`。

**证明.** `μ` Gaussian ⟺ `A` 准自由 ⟺ 由 Wick 定理，`A` 的所有 `n≥3` 阶**连通**关联为零。顶角 `Γ^{(n)}`（`n≥3`）是连通 `n` 点函数的 Fourier 变换，故 `Γ^{(n)}_{phys}(p) = 0` 对所有 `p`。于是分子 `[Γ^{(3)}]² = 0`，`g_ren²(p) = 0/… = 0`（分母 `[Γ^{(2)}]³` 对 Gaussian 非零，取自由传播子）。∎

> **注 3.1**：只需单方向（Gaussian ⟹ 0）。逆命题（`g_ren≡0 ⟹` Gaussian）一般不必真（可能有零 3 点但有零 4 点以上的理论），但我们**不需要**它——见证逻辑只需"`g_ren≠0` ⟹ 非 Gaussian"。

> **注 3.2（§2.3 的呼应）**：引理 G **不用**任何连通 4 点，而用"高阶顶角比值"。这正是因为复合算子的连通 4 点在自由理论中非零（`REPORT §1.2`），而 `g_ren` 的自由值为 0。

## 4. 引理 S：`g=0` 的 scheme-无关性

> **引理 S.** 对质量无关 scheme 变换 `g'² = g² + c g⁴ + O(g⁶)`，有 `g=0 ⟺ g'=0`。故谓词 "`∃p, g_ren(p)≠0`" 与 "连续极限相互作用" 是 **scheme-无关** 的。

**证明.** 令 `g=0` 代入：`g'² = 0 + c·0 + O(0) = 0`；反向同理（变换可逆）。故零耦合轨迹在 scheme 变换下不动，`{g_ren=0}` 与 `{g_ren≠0}` 作为集合均 scheme-不变。∎

> **对照**：`g²=1` 的穿越点**不**不变（`g'²=1+c`，随 `c` 平移）——主 session 的 `numerics/t2_scheme_shift.txt` 已数值确认（`c=±0.1` 时 shift `∓0.62/0.76`）。故**判"非平凡"只能用"≠0"，不能用"=1"**。

## 5. 引理 DT：量纲 transmutation

> **引理 DT.** 沿渐近自由轨迹（一圈，`b₀>0`）：`1/g²(μ) = 1/g²(μ₀) + 2b₀ ln(μ/μ₀)`，定义 `Λ := μ₀ e^{−1/(2b₀ g²(μ₀))}`。则对 `μ>Λ`：
> `g²(μ) = 1/(2b₀ ln(μ/Λ)) > 0`，且
> `Λ>0 ⟺ g²(μ)>0 ∀μ>Λ`；`Λ=0 ⟺ g²≡0`（平凡/Gaussian 轨迹）。

**证明.** 由一圈 RG 方程直接积分。`Λ>0` 当且仅当初始 `g²(μ₀)>0`；若 `g²(μ₀)=0`（`g₀≡0` 平凡轨迹）则 `Λ=0` 且 `g²≡0`。`Λ` 在 scheme 变换下只乘性 rescale（`Λ'=Λe^{c/(2b₀)}`），故 `Λ>0` 的符号 scheme-无关。∎

## 6. 定理 N（非平凡性）——完整证明

### 6.1 两个显式输入

> **(N1)［短程 UV 控制］** 存在规范不变重整化耦合 `g_ren(p)` 与共同定义域 `p∈(p_-,∞)`，使
> `g_ren^{μ}(p) = lim_{a→0} g_ren^{μ_a}(p)` 在紧集上**一致**，且极限匹配一圈：
> `|g_ren²(p) − 1/(2b₀ ln(p/Λ))| ≤ o(1)·g_{1ℓ}²(p)`（`a→0`）。

> **(N2)［非平凡轨迹］** `Λ > 0`（极限沿**非平凡** AF 轨迹；无自由塌缩子列）。

### 6.2 陈述与证明

> **定理 N.** `N1 ∧ N2 ⟹ NonTrivial μ`（即 `¬IsGaussianMeasure μ`）。

**证明.** 由 N2，`Λ>0`。取 `p_* := e·Λ > Λ`，则 `1/(2b₀ ln(p_*/Λ)) = 1/(2b₀) > 0`。由 N1 的一致收敛与 `o(1)` 误差（在 `p_*` 处 `ln(p_*/Λ)=1` 下界固定），
```
g_ren²^{μ}(p_*) = 1/(2b₀) + o(1) > 0   （a→0 时误差 →0，故对充分接近极限成立）。
```
于是 `∃p, g_ren^μ(p) ≠ 0`。由**引理 G 的逆否**，`μ` 非 Gaussian，即 `¬IsGaussianMeasure μ = NonTrivial μ`。∎

（`p_*` 可取任意 `≥ e·Λ` 的固定倍数；`Λ` 有限正故定义域非空。一致性保证误差不把正值压到 0。）

### 6.3 逻辑定性（为何这不是"从 IR 偷结论"）

- 引理 C、G、S、DT：**已证**（C、S、DT 纯代数/测度论；G 由 Wick）。
- **N1 是短程（UV）陈述**：短程归一化顶角是 UV-有限量，其一圈系数为 `b₀`。2026 的 "one-loop running coupling" 输入正是此内容（若以一致收敛形式给出）。
- **N2 是轨迹定义陈述**：`Λ>0` 排除了 `g₀≡0` 平凡轨迹，即"构造的不是自由理论"。
- 二者**都不涉及 IR 长程强耦合区**，故**一旦授予 N2，非平凡性与 MG 解耦**（与主 session 的弱→强交接正交）。

### 6.4 关键细节：为何 "一圈 running" 本身不含非平凡性

若 `Λ=0`（平凡轨迹），"一圈公式"退化：`g²≡0` 是一圈流的不动点，`1/(2b₀ ln(p/Λ))` 无意义/为 0。**因此 N2（`Λ>0`）逻辑上先于"从一圈公式读出非零耦合"**。单有结构性 RG 方程，不能见证非平凡；必须有"轨迹非平凡"这一独立事实。这就是 §7 审计的核心。
