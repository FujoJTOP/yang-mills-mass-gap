# 群一致性：紧单规范群上的统一估计

> 2026-11-22 · 范围：4D 纯 Yang–Mills 的 Wilson 格点正则化；目标是把 MG 的引理链中每个常数对 G 的依赖**显式化**，并判断哪些一致性陈述是可达的、哪些是公开难点。

## 0. 结论摘要

1. **"对所有紧单群一致"这句话有三种强度，必须先分开。** Clay 的字面量词是 `∀G ∃理论 ∃Δ(G)>0`（每个群各自有常数）；一致陈述是 `∃Δ₀>0 ∀G`；两者之间是**每个无穷族内一致 + 有限个例外**。工程上唯一现实的目标是第三种，而它恰好可由"Dynkin 四个无穷族（`A,B,C,D`）+ 五个例外群"的分解承担；估计按三组经典型 SU/SO/Sp 组织（`SO` 同时覆盖 `B` 与 `D`，§1）。
2. **"G 依赖"的一大半是归一化假象。** 全篇用**约定 P**（§2.0，与 `numerics/` 和 `HandoffMargin.lean` 一致）：`tr_f(T^aT^b)=δ^{ab}/2`，`β=2 dim f/g²`，`C₂(adj)=h^∨`，`C₂(f)=dim G/(2 dim f)`。不变量是 `λ_G := h^∨ g²`。β 函数系数 `b₀ = 11h^∨/(48π²)`；但进入 `Λ` 与交接的是 `B := d(1/g²)/d ln μ = 2b₀ = 11h^∨/(24π²)`，故
   `Λ = μ e^{−1/(Bg²)} = μ e^{−24π²/(11h^∨g²)}`，`t_up = 1/(Bg*²) = 24π²/(11λ*)`。**跑动只由 `h^∨` 控制，不含 `dim G`。** 这是本报告最有用的单条结论（§3）。**`b₀` 与 `2b₀` 的因子 2 是唯一会翻转判定的约定陷阱，见 §2.0 / §3.0。**
3. **大 N 与强耦合两个严格区不相交。** 强耦合展开的自然参数是 `β/(2 dim f)`；固定 't Hooft 耦合 `λ_G` 时 `β/(2 dim f) = h^∨/λ_G ∝ N → ∞`，所有严格强耦合结果（Osterwalder–Seiler、Chatterjee）在真正的 't Hooft 极限里全部失效。在固定 `λ_G` 下强耦合只能覆盖 `h^∨ < λ_G`。**这是群一致性问题的结构性主障碍**，且有显式判据（§5.1）。
4. **强度量对 G 的依赖应当是零；广延量正比于 `dim G`。** 自由能密度、熵密度 `∝ dim G`（微扰为 `(d−1)/2·dim G·log`）；而 `m/Λ`、`σ/Λ²`、`m/σ^{1/2}` 应为 O(1) 且只经 `h^∨` 依赖 G。**不分账的界会随 N 变空**（§6）。
5. **中心对称只在对称破缺/拓扑扇区进入。** 禁闭相的整体观测量（强耦合下的 `σ`、`m`）对中心不敏感；`G2, F4, E8, SO(2n+1)` 中心平凡，因此任何依赖中心涡旋的禁闭论证对这些群不成立，但强耦合估计不需要它（§5.4）。
6. **交接判据在平面极限下是单条 N-无关的不等式。** 一圈公式给出 `q₀(G) = (m/Λ)(G)·e^{−c/λ*_G}`；固定 `λ*_G` 时 `q₀` 的首阶与 N 无关，群一致性退化为 `O(1/h^∨)` 修正的估计。**推论（启发式）：最难的群是 `h^∨` 最小的群——SU(2)、SU(3)、G2（h^∨=4）——而不是大 N。** 这与直觉相反，值得主线注意（§9.1）。
7. **形式化现状：** mathlib 已有根系、Weyl 群、Killing 型、Cartan 矩阵（含 G2）、Haar 测度、有限群表示论；**缺** Casimir、Weyl 积分公式、Weyl 特征标/维数公式、紧 Lie 群 Peter–Weyl。2D 精确解与 Casimir scaling 是第一个能同时练到这些缺口的可形式化目标（§7、§9.2）。

## 1. 三种强度：先决定要证什么

| 强度 | 量词 | 是否被 Clay 字面要求 | 难度 | 备注 |
|---|---|---|---|---|
| S1 逐群 | `∀G ∃Δ(G)>0` | **是（充分）** | 未知但最弱 | 允许常数随 G 任意退化 |
| S2 族内一致 | 每个无穷族内 `∃` 与 N 无关的常数 | 否（更强） | 中 | 真正的技术内容所在 |
| S3 全体一致 | `∃Δ₀>0 ∀G` | 否（最强） | 高 | 等价于 S2 + 五个例外群的显式常数 |

**关键观察（可归约性）.** 紧单 Lie 代数（等价地，其单连通紧群形式）的 Dynkin 分类是**四个无穷族 + 五个例外型**：
`A_{N−1} ↔ SU(N)`, `B_n ↔ Spin(2n+1)`, `C_n ↔ Sp(n)`, `D_n ↔ Spin(2n)`；`G2, F4, E6, E7, E8`。因此

> **S3 ⟺（S2 对 `A,B,C,D` 四族）+（五个例外群的显式数值常数）。**

**"族"与"分析分组"不是一回事（这里最容易数错）.** 上面是分类；估计时把 `B_n` 与 `D_n` 合为 `SO(N)`（`h^∨=N−2`、`dim G=N(N−1)/2` 对两种宇称统一），于是分析只分**三组经典型 SU/SO/Sp**。但计数与陈述必须用四族——把 `B`/`D` 并成一组来数，就会得出"三族"，漏掉一个。

**小秩恒等（Lie 代数层面；群层面差一个中心，见 §8 O5）.** `A1=C1`（`SU(2)≅Sp(1)`）、`B1=A1`（`Spin(3)≅SU(2)`）、`B2=C2`（`Spin(5)≅Sp(2)`）、`D3=A3`（`Spin(6)≅SU(4)`）；`D2` 非单（`spin(4)≅su(2)⊕su(2)`）。

**参数范围（`B2=C2` 只能计一次）.** 取 `A_{N−1}` `N≥2`、`B_n` `n≥2`、`C_n` `n≥3`、`D_n` `n≥4`。若把 `B` 与 `C` 都取 `n≥3`，`B2=C2` 会从两边同时被排除，秩 2 就漏掉一个。

**逐秩自检（比文字断言更难再错）.** 秩 1..8 的紧单 Lie 代数个数 = **1, 3, 3, 5, 4, 5, 5, 5**。逐秩复算：秩 2 = `A2, B2(=C2), G2` → 3 ✓；秩 3 = `A3, B3, C3` → 3 ✓；秩 4 = `A4, B4, C4, D4, F4` → 5 ✓；秩 6 = `A6, B6, C6, D6, E6` → 5 ✓。

例外群只需查表并逐项验证，不是分析难点；分析难点全部在四族的 **N-一致** 估计。**建议项目一律把"群一致性"理解为 S2 + 例外表**，不要把 S3 当成一个需要新思想的整体命题。

**另一个必须澄清的点（量词松弛）.** 纯 Yang–Mills 的连续理论只依赖 Lie 代数（场是伴随丛上的联络）；格点理论却依赖**群本身**（`SU(N)` 与 `PSU(N)=SU(N)/ℤ_N` 的中心不同、拓扑扇区不同）。Clay 是存在性陈述，故只需对每个代数取一个群形式给出理论。这意味着：

- 若只求 S1，可在每个代数上**选定**一个方便的形式（例如单连通形式）；
- 但若声称"对任意紧单群"，则须处理 `SU(N)` 与 `PSU(N)` 的格点理论是否给出同一连续极限——这是一个**未被现有 16 输入覆盖**的真实问题（§8，O5）。

## 2. 群数据表

### 2.0 约定 P（全篇唯一，与 `numerics/` 和 `HandoffMargin.lean` 一致）

- 定义表示 `f` 的迹归一化为 `tr_f(T^aT^b) = δ^{ab}/2`（SU(N) 基本表示、SO(N) 矢量、Sp(n) 基本表示）。
- 格点作用量 `S = β Σ_p (1 − (1/dim f) Re tr_f U_p)`，`β = 2 dim f/g²`。
- 由此 `C₂(adj) = h^∨`（所有族），`C₂(f) = dim G/(2 dim f)`，β 函数系数 `b₀ = 11h^∨/(48π²)`。
- **`Λ` 与交接用到的不是 `b₀`，而是 `B := d(1/g²)/d ln μ = 2b₀ = 11h^∨/(24π²)`**（§3.0）。
- **拓扑与格点**：格点取 `Λ_{L,a} = (ℤ/Nℤ)⁴ ≅ T⁴_L`（`L = N·a`，周期边界），固定 **`θ = 0`、平凡 't Hooft 通量扇区**；最终 `L→∞` 给 `ℝ⁴`。与 `A0 §1.1` 同一约定——`S⁴`、开边界、非平凡通量扇区（中心对称破缺）均不在本报告内。
- **RT（重整化轨迹）**：`a ↦ β(a)` 取 **`A0 §1.4` 的同一条 RT、同一个 scheme 常数 `C`**（九个接口共用）。注意 `A0 §1.4` 的 `b₀ = 11N_c/(48π²)` 是 `SU(N)` 写法（`N_c := dim f = N`）；一般 `G` 按 `C₂(adj)` 表达，即本报告的 `b₀ = 11h^∨/(48π²)`（约定 P 下 `C₂(adj) = h^∨`）。`SU(N)` 时两者一致，`SO/Sp` 时不可把 `N_c` 代入 `b₀`。

**因子 2 陷阱（必须避免）.** 若改用矩阵迹约定 M（`T(f)=1`，`⟨X,Y⟩=tr_f(XY)`），则 `C₂` 与 `T` 全部翻倍，`b₀^M = 2b₀^P`，而**同一物理点**的 `g²_M = g²_P/2`。若保留 P 下的数值 `g²` 却套用 M 的 `b₀`（或把 `B` 当 `b₀`），`t_up` 会减半，`q₀` 偏大 `e^{t_up/2}` 倍——SU(3)、`g²=1` 时 `e^{3.589}≈36` 倍（`6.1×10⁻³` 对 `0.22`，取 `m/Λ=8`）。**核对任何外部数字前，先确认其 `b₀` 是否已含 `/2`。**

## 3. 不变量：伴随归一化的 't Hooft 耦合

**定义.** `λ_G := h^∨ g²`（约定 P）。

**3.0 两个不同的系数（因子 2 的唯一来源）.** 约定 P 下
```
β(g)  = −b₀ g³ + O(g⁵),        b₀ = (11/3)h^∨/(16π²) = 11h^∨/(48π²)    （β 函数系数）
d(1/g²)/d ln μ = B = 2b₀ = 11h^∨/(24π²)                              （RG 时间系数）
Λ = μ exp(−1/(B g²(μ))) = μ exp(−24π²/(11 h^∨ g²(μ)))
t_up = 1/(B g*²) = 24π²/(11 λ*_G)
```
**`Λ` 与 `t_up` 用的是 `B=2b₀`，不是 `b₀`。** 把 `B` 当 `b₀` 写入会得到 `12π²`（错），把 `b₀` 当 `B` 会得到 `48π²`（也错）。该常数只在此处定义，别处不再换算。

**数值锚点（与 `numerics/t1_thresholds_SU3.txt` 对齐）.** SU(3)，`h^∨=3`，`g²=1`：`t_up = 24π²/33 = 7.1779`；`m/Λ=8` 时 `q₀ = 8e^{−7.1779} = 6.1×10⁻³`。若误用 `b₀` 代替 `B`，`t_up=3.589`、`q₀=0.22`——判定翻转 36 倍。

**为何 `λ_G` 是正确的不变量.** `b₀` 与 `B` 都只含 `h^∨`，**不含 `dim G`**。且 `h^∨ g²` 恰是一圈下唯一的无量纲组合。对 SU(N) 这与标准 `λ=g²N` 完全一致；对 SO(2n) 是 `g²(2n−2)`，对 Sp(n) 是 `g²(n+1)`——与常用的 `g²N` 只差 `O(1)` 的绝对量（相对差 `O(1/N)`）。因此：

> **在平面极限下 `h^∨g²` 与 `Ng²` 的差别是 `O(1/N)`；但在要求 O(1) 精度的一致性陈述里，必须用 `h^∨g²`。** 二圈系数 `b₁ ∝ h^∨²`，同样不含 `dim G`。

**三组经典型（SU/SO/Sp）的统一性.** `h^∨ = N, N−2, N+1`（SU, SO, Sp；SO 同时覆盖 `B_n` 与 `D_n`），故 `h^∨ = N + O(1)`；而 `dim G = N²−1, N(N−1)/2, N(2N+1)`，即 `dim G = c_fam N² + O(N)`，`c_fam = 1, 1/2, 2`。于是：

- 强度量（`m/Λ`, `σ/Λ²`, `ξ/a`）在固定 `λ_G` 下三组首阶相同（SU(∞) 平面值），组间差异为 `O(1/N)`；
- 广延量（自由能密度）三组同阶 `N²`，系数 `c_fam` 不同（§6）。

这就是"大 N 普适性"的 G-协变陈述：**统一的是标度，不是数值。**

## 4. 一致性陈述的精确定义

**定义（台账 / ledger）.** 设 `𝒢` 为一个群类，`Φ(G)` 为某估计中的常数。称 `Φ` 以台账 `(α,β,γ)` 一致有界，若存在绝对常数 `C`，使
```
Φ(G) ≤ C · (dim G)^α · (h^∨)^β · (dim f)^γ ,   ∀G∈𝒢.
```
称 `Φ` **一致有界**（uniform），若台账为 `(0,0,0)`。

"哪些常数可以依赖 G"于是变成一个**有固定答案格式的问题**：对每条估计，求最小台账并证明之。这比"常数与 G 无关"这种二元说法有用得多，因为大多数正确的界不是 `(0,0,0)` 而是 `(1,0,0)`（广延量）或 `(0,0,−2)`（因子化误差）。

**三条目标陈述.**

**U1（族内强耦合一致，可达）.** 对每组经典型（SU/SO/Sp；`SO` 覆盖 `B_n` 与 `D_n`），存在绝对常数 `β̄>0, c>0`，使对所有 `G`、所有 `0<g²<g²_c`（等价 `β/(2 dim f) ≤ c`）与所有有限格点 `Λ`：
- 强耦合展开收敛，`σ(G) a² ≥ −log(β/(2 dim f)) − C(β/(2 dim f))`，台账 `(0,0,0)`；
- 转移矩阵间隙 `m(G) a ≥ c(−log(β/(2 dim f)) − 1)`，台账 `(0,0,0)`；
- 常数与 `dim G` **无关**（这是强耦合可证的部分）。
状态：SU(N) 为经典结果（Osterwalder–Seiler，Wilson 面积律）；SO(N) 在 Chatterjee 的大 N 工作中被系统化；Sp(N) 预期同法。**这是唯一现成可引用的一致性强耦合定理。**

**U2（'t Hooft 限制，仅 2D 可达）.** 固定 `λ_G`，`N→∞`：
- 2D：由精确解 + 鞍点，`⟨W(C)⟩ = Σ_g N^{−2g} W_g(λ_G,C)`，首项 `W₀` 与 N 无关，`W_g` 族无关；**定理级**（Driver–Lévy–Sengupta 的精确公式 + 鞍点分析，见 §5.1 注）。
- 4D：开放。任何形如"固定 `λ_G` 下 `m a` 有一致正下界"的陈述，目前**无证明**，且与所有严格强耦合结果不相交（§5.1）。

**U3（表示一致 / Casimir 提升）.** 若某 Wilson 环估计对定义表示 `f` 成立且常数为 `C₀`，则对任意不可约表示 `R` 成立且常数为 `C₀·[C₂(R)/C₂(f)]`（或 `dim R/dim f`，视估计而定）。
- 2D：**定理**（精确 Casimir scaling，§5.3）。
- 4D 强耦合首阶：面积律系数与 R 无关，故 U3 在首阶成立但平凡（`C₂` 不出现在首阶）；`C₂` 依赖出现在次阶。
- 4D 连续极限：**未证**，是数值现象（§5.3）。

## 5. 五条主线综述

### 5.1 't Hooft 标度：三个区，互不相交

作用量取 `S = β Σ_p (1 − (1/dim f) Re tr_f U_p)`，`β = 2 dim f/g²`（约定 P）。强耦合展开的自然参数是 `w := β/(2 dim f) = 1/g²`。

| 标度 | `β` | `w=β/(2dim f)` | 强耦合收敛 | 大 N 严格 | 连续极限 | 备注 |
|---|---|---|---|---|---|---|
| 固定 `β` | O(1) | `1/(2dim f)→0` | ✓ | ✓ 但平凡 | ✗ | `σa²=−log w→∞`，环期望→0 |
| 固定 `g²` | `2dim f/g² ∝ N` | `1/g²` | ✓ (`g²>1`) | ✓ 非平凡 | ✗ | **Chatterjee 大 N 极限的正确标度** |
| 固定 `λ_G` | `2(dim f)h^∨/λ_G ∝ N²` | `h^∨/λ_G ∝ N` | ✗ | 仅 2D | ✓ (`a→0`) | 't Hooft / 连续极限 |

**不相容的显式判据.** 强耦合领先面积律 `σa² = −log(β/(2dim f))`。
- 固定 `g²`：`β/(2dim f)=1/g²`，`σa²=log g²`，与 N 无关——非平凡且一致，但 `a` 固定，不是连续理论。
- 固定 `λ_G`：`β/(2dim f)=h^∨/λ_G`，`σa²=log(λ_G/h^∨) < 0` 当 `h^∨>λ_G`。**强耦合公式在 `N > λ_G` 时给出负的弦张力，即已退出适用域。** 所以固定 `λ_G` 与强耦合覆盖 `h^∨<λ_G` 之外不相交。

**结论.** 严格大 N 结果（Chatterjee / Chatterjee–Jafarov）住在"固定 `g²`"区，而物理 't Hooft 极限住在"固定 `λ_G`"区，后者在 4D 无严格控制。**任何声称"对 G 一致"的强耦合往返，都必须在某个 `g²` 上陈述，而不是在 `λ_G` 上。** 这不是技术细节，而是群一致性问题的定位所在。

**对 2D 的注.** 2D 有精确公式（§5.3），可直接在固定 `λ_G` 下做鞍点，因此 2D 的 U2 成立；这是唯一的"固定 λ + 大 N + 严格"例子，也是校准工具。

### 5.2 Makeenko–Migdal

**陈述（'t Hooft 极限下的圈方程）.** 对自交于 `y(s)` 的圈 `C`，
```
∂_μ (δ/δσ_{μν}(x)) ⟨W(C)⟩
  = λ ∫ ds ẏ_ν(s) δ²(x−y(s)) [ ⟨W(C₁)⟩⟨W(C₂)⟩ − (1/dim f²) ⟨W(C)⟩ ] (+ O(1/dim f⁴))
```
其中 `C` 在 `y(s)` 分裂为 `C₁,C₂`。**G-协变化：** `λ → λ_G = h^∨g²`；`1/N² → 1/(dim f)²`（闭指标圈给出 `dim f`，SU(N) 时 `dim f=N`，SO(N) 时 `=N`，Sp(n) 时 `=2n`——同阶）。对例外群没有大参数，"大 N 展开"不适用，只能用有限群的强耦合结果。

**主要误差项的来源.** 右端的乘积**正是大 N 因子化假设**：把 `⟨W(C₁)W(C₂)⟩` 换成 `⟨W(C₁)⟩⟨W(C₂)⟩`，误差恰为连通关联，量级 `O(1/dim f²)`。所以 MM 方程 = 圈方程 + 因子化，二者是同一件事的两面。

**严格状态.**
- 2D：**定理**（平面上的 MM 方程；一般圈；见 §附录待核实项）。原因：2D 的圈导数不产生新的面，方程封闭。
- 4D 强耦合：**部分**。Chatterjee 的 Dobrushin/弦展开给出圈方程的严格版本，但"方程的解 = 面积律"只在强耦合可证。
- 4D 一般：**开放**。没有非微扰证明。

**对群一致性的用处.** MM 给出"因子化误差 `=O(1/dim f²)`"这一条**唯一可写的、G-协变的误差项**，因此它是把大 N 因子化 (U2) 变成定量引理的正确载体。但它是 4D 的障碍清单项（§8, O6）。

### 5.3 Casimir scaling

**2D（定理，精确）.** 在面积 `A` 的曲面上，Wilson 环的 holonomy 期望为热核：
```
⟨χ_R(U_γ)⟩ = dim R · exp(−t C₂(R)),      t = g² A_γ / 2
```
故 `W_R = ⟨χ_R⟩/dim R = exp(−g²A C₂(R)/2)`，弦张力 `σ_R = (g²/2) C₂(R)`，**精确 Casimir scaling**：
```
σ_R / σ_f = C₂(R)/C₂(f),   对所有紧单 G.
```
这是本报告中**唯一一条对任意 G 精确成立、且可直接形式化的表示论-分析交叉定理**。G-依赖完全经由 `C₂(R)`，且 `C₂` 由 §2 的公式给出。

**4D（现状）.** 中间距离上数值成立（SU(3) 静态势的 `C₂` 比例；大 N 格点），源于单胶子交换/胖中心涡旋图像。**但 4D 无证明**；且强耦合首阶的面积律系数与 R 无关（`σ_R=σ_f` 到首阶），`C₂` 依赖是次阶效应。因此：

> **不能把 4D Casimir scaling 作为引理**，只能在 2D 作为定理、在 4D 强耦合作为"首阶平凡 + 次阶待算"。如果引理链需要 4D 表示一致性，必须重写为"首阶 + 误差"的形式。

### 5.4 中心对称

**机制.** 周期性边界条件下，把某个时间片上的全部时间向 link 乘以 `z∈Z(G)`：相邻两个 `t–i` 面 plaquette 分别乘 `z` 与 `z^{−1}`，`Re tr` 不变；Polyakov 环 `P(x)=(1/dim f)tr_f ∏_t U₄(x,t)` 变为 `zP`。故
```
⟨P⟩ = ⟨zP⟩ ∀z∈Z(G)  ⟹  (1−z)⟨P⟩=0  ⟹  ⟨P⟩=0   (z≠1，有限体积，精确).
```
不需要聚类。禁闭 ⟺ 中心对称未破缺；退禁闭 ⟺ 自发破缺。**这是精确的对称性陈述，无条件成立。**

**分类与后果.**

| G | `Z(G)` | Polyakov 序参量 | 中心涡旋禁闭论证 |
|---|---|---|---|
| `SU(N)` | `ℤ_N` | 有 | 可用 |
| `PSU(N)` | 1 | 无 | 不可用 |
| `SO(2n+1)` | 1 | 无 | 不可用 |
| `SO(2n)` | `ℤ₂` | 有 | 可用（`ℤ₂`） |
| `Sp(n)` | `ℤ₂` | 有 | 可用 |
| `G2, F4, E8` | 1 | 无 | 不可用 |
| `E6, E7` | `ℤ₃, ℤ₂` | 有 | 可用 |

**对一致性的含义.** 依赖中心涡旋的禁闭证明对 `G2, F4, E8, SO(2n+1)` **结构性失效**；格点上 `G2` 仍显示禁闭（`SU(3)` 子群/胶球图像），说明禁闭不必须由中心驱动。**但强耦合的体相估计（U1）完全不看中心**（展开只涉及表示与 `dim f`），所以 U1 对全表 G 一致成立，中心只在对称破缺扇区（`⟨P⟩`、退禁闭温度）进入。这条"中心盲"的性质应写进引理链，避免把中心对称误当作全局前提。

### 5.5 大 N 因子化

**陈述.** 对不相交的 `C₁,C₂`，归一化 Wilson 环满足
```
⟨W(C₁)W(C₂)⟩ − ⟨W(C₁)⟩⟨W(C₂)⟩ = O(1/dim f²).
```
更完整地，曲面展开的 genus 展开：
```
⟨W(C)⟩ = Σ_{g≥0} (dim f)^{−2g} W_g(λ, C),
```
`W_g` 与 N 无关（固定 `λ` 时）。这是 't Hooft 1974 的图论计数：闭指标圈给 `dim f`，亏格 `g` 的曲面给 `(dim f)^{2−2g}`，归一化环再除 `dim f`。

**严格状态.**
- SO(N) 强耦合（固定 `g²`）：**定理**，Chatterjee 2020；`1/N` 展开由 Chatterjee–Jafarov。
- SU(N)：**部分/预期同法**，因 `Re tr` 的复相位使符号控制更难；文献中 SU(N) 的大 N 强耦合结果不如 SO(N) 完整。**须核对**（附录）。
- Sp(n)：预期同 SO(N)（同为实/伪实表示，无复相位），未见显式定理。
- 4D 固定 `λ`：**开放**（与 §5.1 同一障碍）。
- 2D 固定 `λ`：**可由精确解 + 鞍点得到**。

**对一致性的用处.** 因子化误差 `O(1/dim f²)` 及其 G-协变形式，是把 U2 写成定量引理的唯一入口；`dim f = N, N, 2n` 使三组经典型误差同阶，因此"大 N 一致"在误差阶上是自然的。

## 8. 障碍

**O1（主障碍：固定 `λ_G` 与强耦合不相交）.** 见 §5.1。固定 `λ_G` 时 `w=h^∨/λ_G→∞`，所有严格强耦合定理（OS、Chatterjee、Cao–Park–Sheffield 的强耦合区间）失效。**任何绕过它的方案必须提供固定 `λ_G` 下的非微扰控制**——目前只有 2D 有（精确解）。这是整个问题真正的墙，不是技术缺口。

**O2（中心平凡群）.** `G2, F4, E8, SO(2n+1), PSU(N)` 无 Polyakov 序参量；依赖中心涡旋的禁闭证明对它们不成立。缓解：U1（强耦合体相）是中心盲的；但退禁闭与"禁闭机制"的陈述必须逐群重写。

**O3（广延 vs 强度不分账）.** 若把自由能界当成强度量界使用，或反之，`dim G ~ N²` 的因子会使界在 `N→∞` 时变空或变假。台账（§6）必须逐条写死。

**O4（4D Casimir scaling 未证）.** 不能作引理。2D 精确；4D 强耦合首阶 R-无关，次阶才是 `C₂`。引理链若要 4D 表示一致，必须写成"首阶 + 误差"。

**O5（群形式改变格点理论）.** `SU(N)` 与 `PSU(N)` 的格点理论不同（中心、拓扑扇区、允许的表示）。Clay 是存在性，可按代数选形式；但"对任意紧单群"的强陈述须证明不同形式给出同一连续极限，或明确限定形式。**现有 16 输入未覆盖这一点。**

**O6（MM/因子化只在 2D 与强耦合可证）.** 4D 固定 `λ_G` 无严格圈方程。

**O7（形式化缺口）.** mathlib 缺 Casimir、Weyl 积分公式、Weyl 特征标/维数公式、紧 Lie 群 Peter–Weyl（已 `grep` 确认：`peter-weyl` 零命中，`Casimir` 零命中）。**L0 的一半、L1、L2、L6 全部受阻于这些缺口。**

**O8（β₀ 与 't Hooft 的相容性）.** 若要同时 `a→0` 与 `N→∞`，须固定 `λ_G`，则 `β∝N²`，超出所有严格结果。要 `β` 有界则 `N` 不能大——两难。

**O9（文献归一化不一致，两层）.** (i) 大量文献写"`β` 足够小且与 N 无关"，实际是 `w=β/(2dim f)` 有界（即固定 `g²`）。**阅读与引用时必须核对 `β` 的定义**，否则会把"固定 g² 的大 N"误读成"固定 β 的大 N"（后者平凡）。本报告 §5.1 的表就是为了消除这个歧义。(ii) **`b₀` vs `B=2b₀`**：`β(g)=−b₀g³` 的 `b₀` 与 `Λ`、`t_up` 中的 `d(1/g²)/dlnμ=2b₀` 相差 2 倍；文献只写"一圈系数"时须确认是哪一个。锚点：SU(3)、`g²=1` 的 `t=7.18` 对应 `B=11·3/(24π²)`。

## 9. 下一步

### 9.1 对主线（弱→强 RG 交接）的直接含义

把 `physics_handoff.md` 的 (H0)–(H3) 逐常数带上 G：

- `q₀(G) = (m/Λ)(G)·exp(−1/(B(G)g*²)) = (m/Λ)(G)·exp(−24π²/(11 λ*_G))`，`λ*_G = h^∨ g*²`，`B=2b₀` 为约定 P 的 RG 时间系数（SU(3), `g²=1`：`t_up=7.1779`，见 §3.0）。
- `q₁(G)` 为强侧 `q` 的阈值，`O(1)`，预期弱依赖 G。
- 交接条件 `q₀(G) ≥ q₁(G)`。

**命题（启发式，由一圈公式导出，未证）.** 若 `m/Λ` 随 `h^∨` 不快速下降（例如 `m/Λ ≥ c h^{−p}`，`p` 有界），则：
1. **固定 `λ*_G`**：`q₀` 的首阶与 N 无关——交接条件是**单条 N-无关不等式**，群一致性退化为 `O(1/h^∨)` 修正；
2. **固定 `g*`**（固定弱耦合半径）：`q₀ → (m/Λ)` 当 `h^∨→∞`，弱侧窗口指数变宽——**大 `h^∨` 使交接更容易**；
3. 因此**最难的群是 `h^∨` 最小的群**：SU(2)（`h^∨=2`）、SO(3)（2）、SU(3)（3）、G2（4）。例外群 `h^∨ = 4,9,12,18,30` 中 G2 是唯一的"小 `h^∨`"硬点。

> **推论：若交接对 SU(2) 或 SU(3) 成立且常数显式，则对全部经典族（在 `m/Λ` 不过度退化的前提下）成立；例外群只需补 G2。** 这与"大 N 最难"的直觉相反，是本次分析最可操作的结论。**须注意 3 依赖 `m/Λ` 的下界假设，而 `m/Λ` 本身未证**——这是该推论的唯一软肋，应作为显式假设写进任何形式化陈述。
