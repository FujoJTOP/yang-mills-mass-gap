## 1 · The proposal, and the correct Portmanteau direction

The target is the edge atom on the Källén–Lehmann measure `ν ≥ 0` on `[0,S]`:
```
f₁² = E(ν) := ν({ m₁² }) = ν({ inf supp ν }) ,      m₁² = inf supp ν .                       (1.1)
```
The proposal: establish **lower semicontinuity** of `ν ↦ ν({m})` (and `E`) in a topology `τ` strictly
finer than the weak-\* = `σ(C(K)*, C(K))` topology of "finite data" (ch09 §topology).

**Portmanteau, first and last word `[T]`.** For `ν_n → ν` weak-\* and a **closed** set `F`,
```
limsup_n ν_n(F)  ≤  ν(F) .                                                                     (1.2)
```
Taking `F = {m}` (closed):
```
limsup_n ν_n({m}) ≤ ν({m})     ⇒   ν↦ν({m}) is weak-* UPPER semicontinuous.                    (1.3)
```
LSC would require the **opposite**: `ν({m}) ≤ liminf_n ν_n({m})`. It is **false**: the bump adversary
(ch09 Lemma 2) spreads the atom into a density,
```
ν_h = w·Unif[m−h, m+h] + (1−w)δ_{s₂}  ⟶  ν = w δ_m + (1−w)δ_{s₂}   weak-*,
ν_h({m}) = 0  for all h>0,   ν({m}) = w > 0     ⇒   liminf_n ν_h({m}) = 0 < w .                 (1.4)
```
Witness **[P]** (`y1_lsc_atom.py`): with `ν = 0.30δ₁+0.70δ₃`, the four bounded-continuous test functions
`e^{-s}, s, cos s, 1/(1+s²)` converge (`0.145215, 2.400000, −0.530904, 0.220000`) while `ν_h({1})≡0`
against `ν({1})=0.30`. The atom **disappears** on a weak-\*-convergent sequence. This is precisely ch09
Lemma 3 / Theorem 4 in the semicontinuity language: `{m}` is a boundary set of positive `ν`-measure
(`ν(∂{m})=w>0`), the one case Portmanteau refuses to control. **[T]**

> **The direction is also wrong for the physics `[T]`.** A finite-volume floor `E(ν_{L,a}) ≥ r₀` is
> carried **to** the limit by **USC** (`E(limit) ≥ limsup E ≥ r₀`), which (1.3) *already supplies* for
> the fixed-point atom — and (proved in §5) `E` itself is weak-\* USC. LSC only carries a lower bound
> the *opposite* (downward) way. The proposal maximizes the wrong modulus of continuity; the free half is
> the one it needs.

## 2 · Adversaries: what every non-circular topology misses

**Split adversary `[T]`.** Keep the reference `ν = w δ_m + (1−w)δ_{s₂}`, and define
```
ν_h = ½w δ_{m−h} + ½w δ_{m+h} + (1−w)δ_{s₂} .                                                  (2.1)
```
For any `φ` **continuous at `m`**: `∫φ dν_h = ½w[φ(m−h)+φ(m+h)] + (1−w)φ(s₂) → wφ(m) + (1−w)φ(s₂) = ∫φ dν`.
So `ν_h → ν` in **every** topology whose test class consists of functions continuous at `m`:
- **weak-\*** (`φ ∈ C(K)`), **moments** (`s^k`), **vague**, and the **SOT/WOT of states on `C(K)`** (all
  generated by `C(K)` — see §4);
- **Wasserstein `W_p` for every `p ∈ [1,∞)`**: the split moves mass `w` by distance `h`, so
  `W_p^p = ½w h^p + ½w h^p = w h^p → 0` (witness **[S]**: `W_1 = 0.30h`, `W_2 = 0.30^{1/2} h`, both `→0`;
  `M_1` equal exactly, `M_2 = 0.30 h²`, `M_3 = 0.90 h²`).
Yet
```
ν_h({m}) = 0  ∀h>0 ,     ν({m}) = w     ⇒    ν↦ν({m}) is NOT LSC in any such topology.          (2.2)
```
Since `W_p` is **strictly finer** than weak-\* (controls the first/`p`-th moment beyond bounded-`C`), and
still fails, "strengthen to a transport topology" does not help. The split is the sharpest adversary: it
defeats even topologies richer than weak-\* as long as their test functions stay continuous at `m`.
**[T]/[NG]**

**Why the split cannot be beaten by "coarser or moderately finer".** The split is `W_p`-null. To exclude
it, `τ` must distinguish measures whose atoms sit at `m−h, m+h` (mass `w` total) from one with an atom at
`m` (mass `w`) — i.e. `τ` must resolve the **exact location of point mass to precision `h`**. Any topology
strong enough to do that **for all split configurations/directions** must contain point-indicator tests —
i.e. it is at least TV (which contains `1_{m}`). There is no "middle" topology: `W_p` and everything
generated by `C(K)` is **below** the split; TV is **above** it (and circular). **[T]**

## 3 · What topology *would* give LSC — and why it is circular (TV / C\*-norm)

The **only** natural topology in which the fixed-point atom is continuous is **total variation**:
```
‖ν − ν'‖_TV = sup{ |∫ f d(ν−ν')| : ‖f‖_∞ ≤ 1 } ,     |ν({m}) − ν'({m})| ≤ ‖ν−ν'‖_TV .          (3.1)
```
`TV` is `C(K)*`'s norm and is **strictly finer** than weak-\*, so it qualifies as "a topology stronger
than weak-\*." Witness **[T]**: the bump is **not** TV-convergent —
```
‖ν_h − ν‖_TV = 2w = 0.60  for every h  (constant; never →0) ;   ν_h({m})=0, ν({m})=0.30 .        (3.2)
```
So TV *excludes* the atom-destroying bumps (that is *why* it "works") — but this is **circular**, on two
readings:

- **Definitional `[T]`.** `{m}` is a Borel set, so `f = 1_{m}` is admissible in the `sup` defining
  `‖·‖_TV`; TV controls `ν({m})` **by definition of TV**, not by an analytic discovery. The topology's
  own test class **contains the atom indicator**, exactly the "defining the topology by the atom"
  circularity flagged in the task.
- **Tautological `[T]`.** By Hahn–Banach, `Λ_m : ν↦ν({m})` is a **bounded** linear functional on
  `M(K)=C(K)*` (`|ν({m})| ≤ ‖ν‖_TV`). "Continuous in the weak topology of a Banach space" is, for
  **linear** functionals, *equivalent to boundedness*. So "the atom is continuous in a strong topology"
  says nothing more than "`ν({m})` is a bounded functional" — the trivial inequality of (3.1). **Zero
  information about whether `f₁² ≥ r₀`.**

**Unattainable `[T]`.** Finite `(L,a)`-data are finitely many bounded-continuous kernels = weak-\*
(ch09 Lemma 1, Thm 4). TV convergence of the physical measures `ν_{L,a}` is **never** supplied — and
indeed (3.2) shows the very atom-destroying sequences are TV-**distant** (`2w`), so one could only *have*
TV convergence by *already knowing* the atom is there. The circularity is physical, not just formal.

## 4 · Operator-algebraic / C\*-seminorm topologies — all collapse

The task asks specifically whether an operator-algebraic or C\*-seminorm topology gives LSC **without
defining the topology by the atom**. Classify the natural candidates on the commutative algebra
`A = C(K)` (measures `=` states), and on its von Neumann completion.

| topology on `M(K)` | what it is | atom: LSC? | why |
|---|---|---|---|
| **weak-\* `σ(A*,A)`** (= SOT = WOT on states) | `∫φ dν_n → ∫φ dν ∀φ∈C(K)` | **NO** (USC only) | §1; bump and split adversaries (2.2) |
| **norm/TV** (`A*`-norm) | `‖ν_n−ν‖_TV → 0` | yes, **circular** | `1_{m}` ∈ test class; `Λ_m` bounded (§3) |
| **`σ(A*, A** )`** (weak topology of the Banach space `A*`) | `⟨ν_n, Λ⟩→⟨ν,Λ⟩ ∀Λ∈A**` | yes, **circular** | `Λ_m ∈ A**` (bounded linear); continuity ⇔ boundedness (§3) |
| **`L^∞(K)` von Neumann, `σ(𝓐*,𝓐)`** | vague again | **NO** | same as weak-\*; atoms are **singular** states, not normal |
| **normal-state topology `σ(𝓐*, L¹)`** | TV on a.c. part | **NO** (blind) | Lebesgue decomposition: the atom is **purely singular**, invisible to `L¹` |
| **pure states / spectral projectors** | extreme points / ranks | **NO for the weight** | only atom **presence** (a rank, integer, **rigid** — R3 (a),(c)); the weight is an **overlap**, not a count |

**Details `[NG]`.**
- **States on `C(K)`.** SOT, WOT, and weak-\* coincide on the state space of a commutative C\*-algebra
  (all generated by evaluation against `C(K)`), so all reduce to `σ(A*,A)` = §1: atom USC, not LSC.
- **States on the von Neumann algebra `L^∞(K,λ)`.** Normal states are `f dλ, f∈L¹` (absolutely
  continuous); the atom `δ_m` is a **singular** (non-normal) state. Weak-\* `σ(𝓐*,𝓐)` is again vague
  (atoms included, USC only); the **normal-state** topology sees only the a.c. part (TV on densities) and
  is **blind** to the atom by the Lebesgue decomposition. Neither gives LSC of the weight.
- **Choquet / extreme-point reading (the sharpest).** `ν = w δ_m + (1−w)ν_c` decomposes the state into
  a **pure state** `δ_m` (an extreme point) and the rest; the atom weight `w` is the **coefficient of an
  extreme point** in the Choquet decomposition. By **Bauer's maximum principle**, an upper-semicontinuous
  convex functional attains its max at extreme points, but the **coefficient map** "mass on a given
  extreme point" is defined by a **discontinuous** decomposition: the pure states are **not weakly
  closed** (their weak-\* closure is all of `M(K)`), and adjoining a small diffuse measure moves `ν` off
  an extreme point without moving `w` continuously. This is exactly ch09 Lemma 3: the atom functional is
  discontinuous *because* the pure-state face structure is. Rigid ranks (multiplicity) are **integers**,
  hence cannot read the real-valued weight `f₁² ∈ [0,M₀]` — R3 (a),(c), `[NG]`.
- **C\*-seminorms.** A seminorm controlling point masses is `≥` the evaluation at some `1_{m}`, hence
  `≥` a multiple of TV on that coordinate → circular as in §3.

**Conclusion `[NG]`.** No operator-algebraic / C\*-seminorm topology gives **non-circular** LSC of the
atom **weight**. The weight is invisible to the spectral/pure-state structure (rigid), invisible to
normal-state convergence (singular), and LSC only in norm/TV where it is tautological.

## 5 · The decisive kill: the physical **edge** atom is discontinuous even in TV

Everything above concerned the **fixed-point** weight `ν({m})`. The physical object is the **edge** atom
`E(ν) = ν({inf supp ν})` (R3's `E = ev ∘ b`, `b(ν)=inf supp ν`). Its continuity needs the **location**,
and the location is discontinuous in the **strongest** standard topology:

**Proposition Y1-E `[T]`.** `E` fails LSC in **total variation** (hence in every topology coarser than
TV, including weak-\*, `W_p`, moments, all C\*-state topologies). Witness **[E]**:
```
ν_ε = (ε/2)δ_ε + (1−ε/2)δ₂  ⟶  δ₂   in TV  (‖ν_ε − δ₂‖_TV = ε → 0) ,
E(ν_ε) = ν_ε({ε}) = ε/2 → 0 ,     E(δ₂) = δ₂({2}) = 1 ,
liminf_{ε↓0} E(ν_ε) = 0  <  1 = E(δ₂)     ⇒   LSC FAILS  (even in TV) .                        (5.1)
```
*Cause.* `b(ν_ε) = ε → 0` while `b(δ₂) = 2`: the **bottom of support jumps**, so the atom is read at a
**different point** in the limit. Witness rows: `(ε, ‖ν_ε−δ₂‖_TV, E(ν_ε), E(δ₂)) =
(0.5,0.5,0.25,1),(0.2,0.2,0.1,1),(0.05,0.05,0.025,1),(0.01,0.01,0.005,1)` — every row `LSC? NO`,
every row `USC? YES`. So `E` is **USC everywhere, and LSC fails at every `ν` with `E(ν)>0`** — by the
bump at a fixed bottom, and by (5.1) at a jumping bottom (consistent with §1: the useful direction, USC,
is the free one). ∎

*Remark (the only variational reading).* LSC is the modulus that guarantees a **minimum** of an energy is
attained (Γ-convergence / Weierstrass). If the atom were an *objective to be minimized* over a constraint
set, LSC would be the relevant tool. The Clay target is not that: it is a **pointwise lower bound on the
specific physical measure's** edge atom, carried from finite volume — which is USC's job, already free.
So even granting the variational framing, LSC is not the gap instrument.

**Why no stronger topology escapes `[T]/[NG]`.** To make `E` LSC one must make `b(ν)=inf supp ν`
continuous — resolve the support bottom to arbitrary precision along sequences that converge even in TV.
That is precisely "locate the edge and isolate it," i.e. the atom-with-isolation target `H*` (R3 §3,
Q6 §1.3). Any topology doing it is **defined by the edge location** = circular at the level of the
physics. The location is **nonlinear** and **unbounded**, so it is not in `M(K)*`; no "all bounded
functionals" (weak, `σ(M,M*)`) topology contains it. Only a hand-built topology that resolves `inf supp`
does — which *is* `H*`. **[O]**

This is the sharpening of R3: the composition `E = ev ∘ b` was known discontinuous in weak-\*; here it is
shown discontinuous in **TV**, so the failure is **not** a weak-\* artifact removable by strengthening —
the **location** obstructs even the strongest standard topology, and the **weight** is only TV-continuous
circularly.

## 6 · Acid test and thin atom: LSC is neither free-vs-YM discriminating nor a floor

- **Free-field acid `[T]`.** In the continuum the free massless field is atomless (`f₁²=0`; R3 `[S2]`
  cut `ρ≡1`, `[V]`). But at **finite `L`** a free field on `T⁴_L` has **discrete spectrum** (compact
  transfer), so its KL measure has atoms with `f₁²>0` at finite `L`, `→0` only as `L→∞`. A topology that
  makes the atom continuous/LSC therefore assigns a **positive** atom to the finite-`L` free field — it
  **does not discriminate free from YM at finite `L`**. The acid test is an `L→∞` statement, exactly where
  no TV/strong convergence is available. So continuity/LSC **does not pass the acid test as a
  discriminator**. **[T]/[NG]**
- **Thin atom `[T]`.** `ν_ε = w δ_ε + (1−w)δ_{s₂}`, `w=ε/2λ`, `s₂=2λ(1−w)`: `χ=1/λ` **exactly for every
  `ε`** while the edge atom `w=ε/2λ → 0` and `m₁=ε → 0` (Q6 §2.1; witness **[C]**). A continuous (or LSC)
  atom reader sees the **true small value** `ε/2λ < r₀` — so it does **not** falsely "certify" the thin
  atom (acid-clean in that narrow sense). **But** the same family shows that atom **continuity is silent
  on a floor**: `sup_ε` of the (continuous) atom over the family is `→ 0`. Continuity ≠ a uniform lower
  bound; LSC gives **no** `r₀`. The thin atom is **not certified**, and cannot be. **[T]**

So LSC (i) is the wrong side for floor transfer (§1), (ii) is not free-vs-YM discriminating on the acid
test, (iii) gives no uniform floor even where continuous (thin atom). It is not the instrument.

## 8 · Sharpest line

**The proposal to prove lower semicontinuity of the atom weight in a stronger-than-weak-\* topology is
dead.** Portmanteau shows the atom is **upper**-semicontinuous (the free, and for the physics the
*useful*, direction); **LSC is false** in weak-\* (the bump makes the fixed-point atom vanish:
`ν_h({m})=0→ν({m})=w`) and in every topology generated by functions continuous at `m` (the split
adversary `½wδ_{m−h}+½wδ_{m+h}` is `W_p`- and moment-null yet kills the atom). LSC holds **only** in
total variation / C\*-norm, where it is **circular** — `{m}` is Borel so `1_m` is in the TV test class,
and "the atom is continuous" says no more than "`ν({m})` is a bounded functional,
`|ν({m})|≤‖ν‖_TV`," the topology **defined by the atom**; and that topology is **unattainable** from
finite `(L,a)`-data (the bump is TV-far, `‖bump−ν‖_TV = 2w`, constant). No operator-algebraic or
C\*-seminorm topology escapes: on `C(K)` they collapse to weak-\* (USC only) or norm (circular); on
`L^∞` the atom is a **singular** state invisible to normal-state convergence; via pure states/projectors
one sees only the **rigid integer** presence, never the real **weight**; via Choquet the weight is the
coefficient of an extreme point, discontinuous because pure states are not weakly closed. And the
**physical edge atom** `E=ν({inf supp ν})` fails LSC **even in TV** — `ν_ε→δ₂` in TV but
`E(ν_ε)=ε/2→0≠1=E(δ₂)` — because the **location** `inf supp` jumps; controlling the location *is* the
atom-with-isolation target `H*`, not a consequence of any topology. The exact missing input is unchanged:
a uniform-in-`(L,a)` **resolution** bound below the isolation `I₂`, i.e. the atom floor **with
