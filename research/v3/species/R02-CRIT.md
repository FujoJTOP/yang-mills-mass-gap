## 1. `⟨w⟩`、`Var(w)` 的解析形式

### 1.1 统一记号（`s=ρ/2`，`Λ=11π`）

```
dν(s) ∝ e^{−β(1−c cos s)}·sin²s/s·ds ,   s∈[0,Λ] ,  w(s)=sin s/(2s) ,   Λ=11π  (ρ=22π)   (1.1)

Z = ∫ e sin²s·s^{−1}ds ,  A := Z⟨w⟩ = ∫ e sin³s·(2s²)^{−1}ds ,  B := Z⟨w²⟩ = ∫ e sin⁴s·(4s³)^{−1}ds   (1.2)
⟨w⟩=A/Z ,  Var(w)=B/Z − (A/Z)²                                                                  (1.3)
```
（`e` 恒指 `e^{−β(1−c cos s)}`；三个积分在 `s→0` 都被 `sin²s/s ~ s` 压住，是正常积分。）

### 1.2 `β=0`：`Cin/Ci` 闭式（`[T]`，与求积差 `≤1.7e−16`）

`X=Λ/2=11π`，`Cin(x)=γ+ln x−Ci(x)`：

```
Z₀ = ½Cin(Λ)
A₀ = ½[ −sin³X/X + (3/4)( ln3 + Ci(X) − Ci(3X) ) ]
B₀ = ¼[ −sin⁴X/(2X²) − 2sin³X·cosX/X + ( ln2 + Ci(2X) − Ci(4X) ) ]        (1.4)
```
推导：`sin²s/s=(1−cos2s)/2s` → `Cin`；`A` 分部一次用 `sin²s cos s=(cos s−cos3s)/4` 及 `∫₀^Λ(cos as−cos bs)/x dx = ln(b/a)+Ci(aΛ)−Ci(bΛ)`；`B` 分部两次用 `sin⁴s=3/8−½cos2s+⅛cos4s`。三者均为 `Ci` 的有限组合——**`h1e` 的 `Cin/Ci` 论断核准**。

**数值（`Λ=22π`）**：`Z₀=2.406598541773237`、`A₀=0.412257197297487`、`B₀=0.173247605007024`；
`⟨w⟩=0.171302853443`、`⟨w²⟩=0.071988577239`、`Var=0.042643909641`。

**`h1e` 窗口核准（`Λ=2π`，即 `ρ≤2π`）**：`⟨w⟩=0.357411353391`（`h1e 0.3574113534`）、`Var=0.011059293773`（`h1e 0.0110592938`）、`h1e` 组合式 `N₂/(4Z)−(N₁/(2Z))²` 逐位相同。**警告（§2.1 窗口纪律）**：`h1e` 的数只属 `ρ≤2π`；本判据的窗口 `ρ≤22π` 把 11 个 `sin²(ρ/2)` 周期全算进来，`⟨w⟩` 从 `0.3574` 掉到 `0.1713`、`Var` 从 `0.01106` 涨到 `0.04264`（`w` 在 `ρ∈(2π,4π)` 等半周期为负）。**两个窗口的数不可互代**。

### 1.3 `β>0`：无 `Ci` 闭式，但有精确级数与可积表示（`[T]`）

```
Z(β,c) = e^{−β} Σ_{k≥0} (βc)^k/k! · M_k ,     M_k = ∫₀^X cos^k x·sin²x/x·dx                (1.5)
```
（等号逐字，`M_k` 是 `Ci` 有限组合。核对：`(β,c)=(1,0.7)/(2.5,0.5)/(0.5,0.99)` 与求积差 `≤1.1e−15`。）
等价 Bessel 形：`e^{βc cos s}=I₀(βc)+2Σ_{n≥1}I_n(βc)cos(ns)`，逐项用 `L(a,b):=ln(b/a)+Ci(aΛ)−Ci(bΛ)`。
**判死线**：`β>0` 的 `⟨w⟩,Var(w)` 属 **incomplete-Bessel (Kemp) 型**，**不是** `Ci` 的有限组合——`h1e` 的 `Ci` 闭式**不可**迁到 `β>0`。判据本身不需要这个闭式（§2 只用符号结构）。

## 2. 核心引理：`2Var(w) ≤ ⟨w⟩` 无条件成立（`[T]`）

**引理 1**（逐点）：`|w(s)|=|\sin s|/(2s) ≤ ½`，`s>0`。
**引理 2**（关键，替代 `Q04 (4.1)` 的 `0≤w≤½`）：

```
A − 2B = ½∫₀^Λ e·sin³s·g(s) ds ,      g(s) := (s − sin s)/s³                     (2.1)

g(s) > 0 且 g'(s) = [−2s − s cos s + 3 sin s]/s⁴ < 0   (∀s>0)                   (2.2)
```

`(2.2)` 证明：`3sin s − s cos s − 2s = −2s·[1 − O(s⁴)] < 0`；一般由 `3sin s ≤ 3` 与 `s(4+cos s) ≥ 3s` 得对 `s>1` 为负、`s∈(0,1)` 用 `s − s³/6 ≤ sin s ≤ s` 得 `≤ −s(1−s²/4) < 0`。

**驼峰镜像配对（`[T]`）**：把 `[0,Λ]` 按 `s` 的 `sin²s` 半周期分块：`P_k=(2πk,2πk+π)`（`sin>0`，`w>0`）与 `N_k=(2πk+π,2πk+2π)`（`sin<0`，`w<0`）。对 `u∈(0,π)` 取镜像对 `s₋=2πk+π−u`、`s₊=2πk+π+u`：

```
cos s₋ = cos s₊ = −cos u      ⇒ e(s₋)=e(s₊)          （指数因子精确相等）
|sin s₋| = |sin s₊| = sin u   ⇒ |sin³| 精确相等
s₋ < s₊ ,  g 严格递降         ⇒ g(s₋) > g(s₊)
⇒ h(s₋)+h(s₊) > 0 ,   h := e·sin³s·g(s)                                        (2.3)
```

`Λ=11π=2π·5+π` 恰落在第 6 块的正半驼峰末端 ⇒ 尾部 `[10π,11π]` 全在 `sin>0` 侧，贡献为正。故

```
∫₀^{11π} h ds > 0   ⇒   A − 2B > 0   ⇒   2⟨w²⟩ ≤ ⟨w⟩   ⇒   2Var(w) ≤ ⟨w⟩        (2.4)
```

**定理（`[T]`）**：对**一切** `β≥0`、`c∈[0,1]`（任意 `θ`）、窗口 `Λ=22π`，
`Var_μ(w) ≤ ½⟨w⟩` 且 `2Var(w) ≤ ⟨w⟩`；`R:=⟨w⟩/Var ≥ 2`。
数值核对（`[C]`，网格 `β∈[0,100]×c∈[0,1]`）：`max 2Var/⟨w⟩ = 0.497877`（在整条 `c=0` 线上取到，与 `β` 无关），`max 2B/A = 0.996792`（`β=100,c=1`）。

**锐性（`[T]` 的极限）**：`β→∞` 时质量集中到 `s→0`，`w→½` ⇒ `2⟨w²⟩/⟨w⟩→1`；`β=0,Λ→∞` 时 `→ (¼ln2)/(⅜ln3)·2 = 0.841240`。故 (2.4) 的常数 `1` **不可再压**（在 `⟨w²⟩` 形式下）；但 `Var` 形式下 `⟨w⟩²` 项留出真实余量（`0.498`）。

**一条必须记下的负结果（`[T]`）**：`E|w| ≤ ⟨w⟩` **假**（`Λ=22π,β=0`：`E|w|/⟨w⟩=1.197947`），因为 `∫|w|` 把配对**相加**而 `∫w` 相减。⇒ 任何 `|w|≤½ ⇒ Var ≤ ¼⟨w⟩`（经 `E|w|`）的路**不通**，必须走 `(2.1)` 的 `g` 核路线。`Q04 (4.1)` 的 `0≤w≤½` 逐点路也只在 `ρ≤2π` 成立，**不能**覆盖 `22π` 窗口。

## 3. 判据本体的证明（`[T]`）

```
2βt²Var(w) ≤ 2βt²·½⟨w⟩ = βt²⟨w⟩ ≤ c⟨w⟩        （用 (2.4)；第二式用 βt² ≤ c）   (3.1)
```
⇒ **`q04` 的充分条件 `β sin²(θ/2) ≤ cos(θ/2)` ⇒ 判据成立，是定理，不是数值事实。**
比 `Q04 §4.2` 更强：那里只在 `ρ≤2π` 上可用 `0≤w≤½`，本式在 `ρ≤22π`（11 个周期、`w` 变号）上成立。

**顺带修一条链**：任务书第 3 步的 `2βt² ≤ 2c` 走法是对的但**更松**；直接用 `2βt²Var ≤ βt²⟨w⟩` 就够（`Var ≤ ½⟨w⟩` 与 `c` 无关）。

## 4. 判据的精确等价式、`β_c(θ)` 与放宽幅度

```
判据  ⟺  2βt²Var ≤ c⟨w⟩  ⟺  β·sin²(θ/2) ≤ ½cos(θ/2)·R(β,θ) ,   R=⟨w⟩/Var      (4.1)
```
* `[T]`：`R≥2` ⇒ (4.1) 被 `βt² ≤ c` 蕴含（= `Q04 (4.2)`，本文件给证明）。
* `[T]` 的放宽写法（任务书 (a) 的式子，逐字）：`βt² ≤ ⟨w⟩/(2Var(w)) = R/2`，其中 `R=R(β,θ)≥2`。
* `[C]`（`Λ=22π`，求积 `epsrel=1e−13`）：`R∈[4.017,∞)`，最小值在 `c=0`（任意 `β`）与 `β→0` 附近取到 ⇒ **判据条件实际可放 ~2 倍以上**。真正的 `β_c(θ)`（`sup{β: (4.1)}`，二分 80 步）：

**但 `c=0`（`θ=π`）不可越过**：`(4.1)` 右端 `=0` 而左端 `2βt²Var>0`（`Var=0.04264`，`Q04 §4.3` 的反例保留）。`β_c(π)=0`。⇒ 放宽只发生在 `c>0` 侧，`θ→π` 时 `β_c→0`，与 `Q04` 的"符号由 `(θ,β)` 定"一致。
**窗口警告**：上表的 `R` 与 `β_c` 全是 `Λ=22π` 的；`Λ` 变大时 `R` 单调下降（`[6]`：`2π/6π/10π/22π/42π/82π → R=32.3/5.57/4.68/4.02/3.71/3.49`，`Λ→∞` 极限 `R→A_∞/(B_∞−0)=0.412/0.173=2.376`）⇒ **`[C]` 的 2 倍放宽随 `Λ` 增长而衰减到 ~1.19 倍，`[T]` 的 `R≥2` 才是 `Λ`-一致的**。

## 5. 判死线归属（逐条）

* **(a) 成立 `[T]`**：`2Var(w) ≤ ⟨w⟩` 无条件真（§2），故判据化为 `βt² ≤ ⟨w⟩/(2Var)=R/2`，`R≥2`；真正的 `β_c(θ)` 是 `(4.1)` 的根（§4 表）。
* **(b) 同时成立 `[T]+[C]`**：`R=⟨w⟩/Var` 有 `β,θ` 依赖；`[T]` `R∈[2,∞)`，`[C]`（`Λ=22π`）`R∈[4.017,∞)`；`R` 随 `β` 增、随 `c` 增、随 `Λ` 减。
* **(c) 部分触发 `[T]`**：`β=0` 有 `Cin/Ci` 闭式；`β>0` **无**初等/`Ci` 闭式，给 `(1.5)` 的 Bessel 级数与 `L(a,b)` 可积表示，及上下界 `2 < R < ∞`（`[T]`）/`[4.017,∞)`（`[C]`）。
* **不许外推**：本文件只证 `a=0`、`Λ=22π`、单 plaquette。`a≠0`（`Q04 §3` 的 `e^{−βt sin(ρ/2)a/ρ}` 因子）与多 link 版本**未做**，`[NG]`。
