> 卡点唯一且可命名：`∂_a` 与 `E_a` 不对易（测度本身随 `a` 变），`Δ_dyn` 因此**不是**单一自由能的曲率，而 `G″` 是。

### 3.2 但"纯形式"确实存在——代价是换测度

```
(NOSUB)  ⟺  Δ_dyn + W_geo = −∂²_a log(ρ_S ρ_J)  ,   即"解耦代理测度"的对数凹常数

(NOSUB)  ⟺   L_S(a) + L_J(a) ≥ λ ,      L_J ≥ (N/12)‖v‖²  [T，命题 N1′]

### 3.3 `[T-here]` 命题 N2（`β²` no-go：本靶不可能是 `β`-一致的）

因 Wilson 型作用量对 `β` 一次齐次：`S = βS₁` ⇒ `H = βH₁`、`G = βG₁`（`H₁,G₁` 与 `β` 无关），故**逐位精确**

W_geo(β) ≤ C_Φ(v,a₀) := ess-sup_slice ⟨v,HessΦ v⟩ < ∞      （命题 N1′ 给的下界是 λ(v)>0）
⇒  NOSUB(β) ≤ β‖H₁‖_∞ + C_Φ − β²·Var_a(G₁|a₀)
⇒  若 v₀ := inf_β Var_a(G₁|a₀) > 0，则  NOSUB(β) < 0 对所有 β > β_max := [C₁+√(C₁²+4v₀C_Φ)]/(2v₀) 。
```
**含义**：本靶的正面项是 `β⁰` 有界的（Haar 地板），负面项是 `β²` 增长的（作用量力方差）⇒ **正负两半的 β 标度是 `0 vs 2`，因此本靶只能是一个"有限 β 窗口"命题，永远不可能 `(L,a,β)`-一致。** 这与"Savvidy 交叉点"是同一个机制，只不过被提前到了 `X` 之外。

**数值印证**（`Δ_dyn/β²`，本应趋常数）：`a₀=0`：`−0.01106` 在 β=2…6 **恒等**（§2.1 的精确性）；`a₀=1`：`−0.0577,−0.0418,−0.0339,−0.0292,−0.0260`（β=2…6）——单调趋稳、始终离零。
