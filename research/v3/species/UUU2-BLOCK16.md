## §2 免费界够不够 `L3`

```
(I)  ϖ = N_B Var(⨏_B q) = C_q(0) + O_B = N_B⁻¹ Σ_z n_B(z) C_q(z)      [T] HZF-COV:29–30
(P)  |C_q(z)| ≤ C_q(0) = Var(q) ≤ 1    （Cauchy–Schwarz＋平移不变；Popoviciu）
(Q)  Σ_z n_B(z) = N_B² = 256 ,   Σ_{z≠0} = N_B(N_B−1) = 240            [T] 机检
⇒ (F)  |O_B| ≤ (N_B−1)Var(q) ⇒  0 ≤ ϖ ≤ 16Var(q) ≤ 16                 [T] II10-L2:14; II1-C4:61
```

**2.1 (c) 与 (b) 同值，且**不需** `C_q≥0`。** 用 (P) 直接得 `Var(⨏_B q)≤Var(q)≤1`（`|Cov|≤√(VarVar)`），于是 `N_B²` 个配对最多给 `N_B²`、`ϖ≤16`；既不是「联合分布」的额外功劳，也不用 `C_q(z)>0`——后者在 `β=2.5` 上本身 `[NG]`（`II6:0.5`·`HZY-C0:1`），而 (F) 根本不消费它。

**2.2 「带错幂」的位置不在 Popoviciu。** `ϖ` 无量纲、`C=16` 的幂是 0，正是靶要的形状；错幂出在换算 `Z_a=a⁻⁴b̂⁻⁴ϖ`（`HZ6:46`，定义恒等）：取 `b̂=2a` 得 `Z_a=ϖ/(16a⁸)`，于是
- 靶 `Z_a≤Ca⁻⁴` ⟺ `ϖ≤16Ca⁴→0`，而 `ϖ≥Var(q)≥v(β)=6.4192e−3`（`HZY-C0:0.7`，`a`-一致）⇒ **pin 上这条不等式为假**（非仅未证）；
- 比值形 `Z_a⁻¹‖H_a‖_D=16a⁴η_a/ϖ→0`（`‖H_k‖_D=a_k⁻⁴η_k`，`HZ6:23`）⇒ 整条 `L3` 对任何测度成立、判别力 0（`HX3:55` 逐字「`a^{-8}` 过冲 ⇒ F2 对自由场与 YM 同真」；同洞 `HU5:0.2`，转引）。

**2.3 故「够不够」分两答。** pin 上够：`C=16` 且 sharp（全相关族），这是那个固定维数问题的完整答案。对 `L3` 不够：**差恰一个 `N_B`（4 个 `a` 幂）**，与 `DDD3-NB:16` 逐字「`a⁻⁴` 与『一个 `N_B`』是同一件事的两个面」同一句；`L3` 的不平凡性恰要求 `b̂` 固定物理、`N_B→∞`（`II1-C4:19`·`II8-WIN:61`），而 pin 把这个生长冻住。
