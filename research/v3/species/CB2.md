## 3 · ★ `f07` 的 `w` 是哪个（本路唯一问题）

`F07-ADJCBAR.md:82–83` 逐字：``|w|^{1/n} = c_f = N·u``、``|w(S)| ≤ ∏_{p∈S}c_f``（引 `Z06-HOLEA:83`、`PROOF 引理 2′`）；`C05-AUDITCBAR:57` 给了算法：`|w|=c_f^n·∏_links mult(1∈f⊗f̄)=c_f^n·1=(Nu)^n`。

⇒ **`w` = tile 权重 `w(S)`**：`Z_dec` 展开里一个**连通 tile 簇**（cube `n=6`、4-壁 tube `n=4T`）的权重，被 `∏c_f` 界取等（`∏mult=1`，每 link 恰 2 片、定向相反）。逐片模 `|w|^{1/n}=c_f`。**既不是 `⟨(1/N)trU⟩^n`，也不是 `⟨trU⟩^n`**——它是 `c_f^n`，而 `c_f` 恰好**数值上**等于 `⟨(1/N)trU_p⟩`（log §1/§5）：

```
|w|^{1/n}/u = c_f/u = 2.0000        （n=4,6,8,12 全 2.0000）
⟨(1/N)trU⟩^n 逐片 /u = 1.99997      （≈ c_f/u，同一个数的精确版）
⟨trU⟩^n     逐片 /u = 3.99994      （=2N，另一个量）
```

**⇒ 任务里那条分支"若 `w=⟨(1/N)trU⟩^n` ⇒ `|w|^{1/n}/u=u/u=1`"是拿读法1 的假定（`⟨(1/N)trU⟩=u`）当代入**；精确 `SU(2)` 给 `⟨(1/N)trU⟩=c_f=2u`，同一条分支算出的是 `2`，不是 `1`。`f07` 的 `w` 落在 **`c_f` 那一节**，不在 `u` 那一节。`[T]`+`[E]`

## 4 · 判死线

* **(a) 触发（数值层，给读法2）**：`f07` 的 `C̄≡N=2` 与读法2 的 `C̄=2` 同值；`f07` 的 `w` 逐片值 `=c_f` 就是读法2 的右端。**`f07` 的 `w` 与三读法的关系**：`=` 读法2 的 `W`（`c_f`）；`=N×` 读法1 的 `W`（`u`）；`=(1/2N)×` 读法3 的 `W`（`β`）。
* **(b) 不触发**：`c_f/u=N` 是精确恒等（`u:=c_f/N`），不是记账错。真正的错在**归名**：读法2 把 `c_f` 归给 `⟨trU⟩`（精确 `⟨trU⟩=2c_f`），该归给 `⟨(1/N)trU⟩`（精确 `=c_f`，`f07:85` 自己核过的那个数）。
* **(c) 触发（主判）**：读法1 与读法2 是**同一式乘 `N`**（`⟨trU⟩=N⟨(1/N)trU⟩`、`c_f=Nu`），只差 `N` 归一；`C̄:1→2` 与 `u` 的 `1/N` 严格同步，但 `Ū` 因此差 `N`（`0.125` vs `0.250`）、窗差 `N`（`0.147152` vs `0.073576`）。**三读法不是三读法，是二读法 + 一个真不同物（读法3，`2N²`）。**
* **`f07` 的论证本身**：`C̄≡N` 对；它能写成 `N` 恰恰因为 `u:=c_f/N` 已把 `1/dim f` 吃进 `u`。`f07` 没有第 28 处错，它的 `C̄` 值（`2`）与读法2 一致；需要改的是**读法2 的恒等式标签**（`⟨trU⟩`→`⟨(1/N)trU⟩`），以及读法1 的 `=u`（应 `=c_f`）。
