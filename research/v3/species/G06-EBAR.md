## 3. 关键：`δ_A` 是**恒等式**，不是近似 ⇒ 严格 `∝ 1/a`

```
κ/4 = ln(1/u)/a                      （X01:127：恒等，无余项）
ē = ū/u  ⇒  ln ē = ln ū − ln u
δ_A = κ/4 − ln(ē)/a = (1/a)[ln(1/u) − ln ē] = ln(1/ū)/a            ← 恒等式 [T]
⇒ δ_A·a = ln(1/ū) = 纯数（= 0.5686159179138452…），与 a 无关
```

**数值核（50 dps，`w7/g06_ebar.log §4`，`u=1/96` 精确）**：

|---|---|---|---|
| 1 | 0.568615917914 | 0.56861591791384524505 | 0 |
| 0.5 | 1.13723183583 | 0.56861591791384524505 | 0 |
| 0.1 | 5.68615917914 | 0.56861591791384524505 | 4e−51 |
| 0.01 | 56.8615917914 | 0.56861591791384524505 | −3e−51 |
| 1e−3 | 568.615917914 | 0.56861591791384524505 | 3e−51 |

偏差量级 `1e−51` = 50 位工作精度的舍入，**不是** `O(a)` 残余。
