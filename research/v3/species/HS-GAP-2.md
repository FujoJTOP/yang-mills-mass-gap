**一句话。** `Δ/ε` 的规格不是"测一个尾矩"，而是"测四个数、算一个差"：`K = w₁ + (N_eff−3)/2`，其中 `w₁`（固定流时上有 `a→0` 极限）、`s₁`、`s₂`（只一个方向易得）、`Ē`（`−d/dt log C|₀`）各有现成读法，而 `Δ` **不进数据模**——它只以闭合残差 `ρ(Λ) ≥ 0` 出现。两个误差源（尾部截断、`s₂` 过报）**同向**把 `K` 读低，故该测量天然只在单向可认证：**正下界可测，趋零只可由定理给出**。若 `K→0` 则 `(G-4)` 退化为靶的换名（两点源上逐字重合）、全部严格性搬到 `④`；若 `K ≥ c` 则 `(G-4)` 是"靶+余量"的保守证书、余量随 UV 尺度增长（自由场是 `L²` 先例）⇒ 它在 YM 上更可能是**不可满足**而不是"更强"。**Clay 0 项；无 QED。**

## §3 两结局各意味着什么

**3.1 结局 A：`K_t → 0`（或一致地 `K ≤ w₁−w₀`）**

1. **它是一句很强的话**：`K=0 ⟺ Δ=0 ⟺ supp ν_w={s₁,s₂}`——源在 `0⁺⁺` 道**恰好两点**。YM 的 `¼trF²` 耦合到双胶球连续截（`QI-BRACKET.md:151–153`：态密度 `∝L³`、`N_eff→∞`），故 A 等于断言"流动算符在第二点以上**一点权重都没有**"。（`[T]`）
2. **逻辑上它是换名**：该类上 `(G-4)_ε ⟺ 靶` 逐字重合（`HQ6-G4.md:199–201`）⇒ 零信息；`{④,(G-4)}` 的严格性全归 `④`（定理 HQ6-A，`HQ6-G4.md:230–237`），而 `④ ⟺ I2` 定量形（`HN3-I2.md:220`）⇒ **靶面回到窗口排除 + 一条已消掉的尾部项**。（`[T]`）
3. **它不含靶的真值，也不能由测量认证**：薄原子上 `K=0` 而靶假（`HQ6:104`）；写 `K→0` 需 `s₂` 下界 + 尾部界，两者都缺（HS2-A），合规写法只有 `K ≤ K̂(s₂^{lo})`。（`[T]`）
- **下一手**：靶面写成 `④` 单独一项、`Δ/ε` 项标"已消"；报 `lead` 一句"预算形退化 ⇒ 靶面 = `④`"。若发生在流动源上，须先验 `ρ(Λ) ≪ w₀`，否则 A 只是截断假象。

**3.2 结局 B：`inf_t K_t ≥ c > 0`**

1. **`(G-4)` 变成"靶+余量"**：`K ≥ c` ⇒ 任何 `(G-4)` 的证明同时给 `w₁ ≥ w₀+c` ⇒ 先证更强的东西，作台阶是负收益。（`[T]`）
2. **失败裕度被定量且不可内插**：`ϑ ≤ w₁`（`QI-1`）+`QI-4` 尖锐（极值测度住在靶类内，`HQ4-ATOMFLOOR.md:230–231`）⇒ 任何"`④`+`L2`"的证明**固定差 `≥ c`**；没有更强的不等式能补，只能补输入。（`[T]`）
3. **它不必要，但是可认证那一侧**：C 族靶真而 `(G-4)` 假 ⇒ 数值失败**不**证伪靶 ⇒ 身份 = 充分而不必要的保守证书；而 `c` 一测（含 `s₂^{hi}`）+ 归档标定即可定。（`[T]`）
4. **若 `c` 随 `(L,t)` 无界**（自由场 `K~cL²` 是先例）⇒ 最强形态不是"更严"而是"**在 YM 上不可满足**"：`(G-4)` 从"更强的命题"降为"空命题"。（`[NG]`：4D 的 `c_t` 未测）
- **下一手**：测 `c_t`（§1.4 格式）；把"尾部预算"从"缺的一步"改登记为"**必须作为输入的界**"；全仓停止把 `(G-4)` 当归约用。

**3.3 两结局不是穷尽的（诚实边界）**：`t` 上 `K_t` 可非单调（A/B 都是逐点陈述），合规二分是 `inf_t K_t ≶ c`；"`K_t` 过零"这一格**未排除也未支持**（`[NG]`：无机制）。⇒ 报告规范形永远是"`t`-点上的 `K` 区间 + `t`-趋势"。
