## §1 把三个对象分开写

### 1.1 三个形（只有一个被消费）

```
(P) 点态形（仓内写法）：   ∃C ∃κ>0 :  |Cov_μ(s_B,s_B′)| ≤ C e^{−κ dist(B,B′)/a}      ∀B,B′, j, U′, a
(F) 行和形（finiteness）： ∃M(L)<∞ :  sup_B Σ_{B′≠B}|Cov_μ(s_B,s_{B′})| ≤ M(L)        ∀j,U′,a
(★dec-P) 边际形（Gershgorin 接口）：  R_B ≤ ½ δ_W                                       ∀B,j,U′,a
```

`(P)` 的两个参数退化成一个等价类（`(P) ⟺ 一致二阶矩界`，§0.1）⇒ 不构成 `L3` 的前提；`(F)` 只有一个数 ⇒ 与 `L3` 同类型（finiteness，`HQ1-L3.md:17`）；`(★dec-P)` 是 `(F)` 加一个**固定阈值**，比 `(F)` 强。

## §2 恒等式：为什么行和界比对角更强（两行）

`Σ_B s_B ≡ 0`（均匀粗移 = block 规范轨道，`S4:96`；`L3-band-decay.md:9`）。对固定 `B`：
`Cov(s_B, Σ_{B′}s_{B′}) = 0` ⇒ `Var(s_B) = −Σ_{B′≠B}Cov(s_B,s_{B′}) ≤ Σ_{B′≠B}|Cov| = R_B`。∎

三条推论（全 `[T]`）：
1. `R_B ≤ ½δ_W` ⇒ `Var(s_B) ≤ ½δ_W`。**行和界 ⇒ 对角方差界，且常数是 `½δ_W` 而不是自由的 `C`。**
2. 代入 `(★)`：`Var ≤ E[H]+W−δ_W` 由 `E[H]+W ≥ (3/2)δ_W` 保证 ⇒ §0.4 的并腿。
3. `S4:175–186` 的 power-law 反例（有界对角、无衰减）只否证**反向** —— 对角界 ⇏ `(F)`（`S4 §3.1`）；它**不**否证 `(F) ⇒ Var` 界（恒等式给的就是这个方向）。

**对 `S4 §8.3` 见证的核**：`C=1, κ=0.8, δ_W=½` ⇒ 行和 `R=8.9943`（`S4:398`），而边际形要求 `R≤0.25` ⇒ 该见证**违反** `(★dec-P)`，只满足空形式 `(P)`。故它不是"`(★dec)⇏(★)`"的见证，而是"`(P)` 与 `(F)` 不是一回事"的见证。

## §3 速率的定量：只剩一个组合

`(P)` 的 `(C,κ)` 只通过 `Cκ^{−d}` 进入行和（`S4:254`：`R ≤ CS_d(κ) ≍ Cc_d/κ^d`，`c_4=12π²≈118`）：小 `κ` 渐近精确；`κ=O(1)` 时形状因子 `1.26–1.41`。⇒ **两参数说一个数**。三个可核的数：
