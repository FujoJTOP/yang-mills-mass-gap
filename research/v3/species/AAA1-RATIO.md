## §1 等价式（两行代数 + 一道约定闸）

**(1.1) `[T]` 恒等式。** 对任意可微 `f`、`β>0`：
```
f(β) − β f'(β) = −β² · d/dβ[ f(β)/β ]
```
两侧同号（`β²>0`），故 `plaq(2.5)−2.5plaq'(2.5) ≥ 0 ⟺ (plaq/β)'(2.5) ≤ 0`。**题面等价式逐字成立，不需纠正。**

**(1.2) 数值同口径。** `G := plaq − βplaq'`：`G(2.5)=0.652402−2.5×0.198972=0.154972`（`L=8`），`g'(2.5)=−G/2.5²=−0.024796`；`L=6` 口径 `G=0.182007`、`g'=−0.029121`。两口径余 `1.31×`／`1.39×`，符号一致。

**(1.3) `[T]` 约定闸（题面必须修）。** `0.6526` 与 `0.26105` 是 `plaq:=½⟨trU_p⟩`；`plaq(0)=1` 是 `q:=1−plaq`。不能同时用：
- **u-读法**：`plaq(0)=0`（Haar `⟨trU⟩=0`）与 `plaq'(0)=1/4`（`χ_q(0)=1/24` 精确 Haar，`𝒮_q=plaq'/6`）给 **`g(0⁺)=1/4`**。题面"`plaq/β → +∞` 当 `β→0`"是 q-读法的残影，u-读法下它**升**（`0.25 → 0.26096`）。
- **q-读法**：`(q/β)' = −(βplaq'+q)/β² < 0` 恒成立（`q>0`、`plaq'>0`）⇒ `(EP)` 是恒等式、零内容。
⇒ **有内容的靶只在 u-读法**；下文全用 u-读法。

## §3 三路

**(a) 两端点值 + `plaq/β` 凸性 —— `[NG]`，且反号。** 凸 ⇒ 右端斜率 ≥ 割线：`g'(2.5) ≥ (0.26096−0.25)/2.5 = +0.004384 > 0` ⇒ **(EP) 假**。实测 `g'(2.5)=−0.024796`，与凸性要求隔 `0.029180`（`5.7×` 所需下界）⇒ **`g` 在 `[0,2.5]` 上非凸，是 `[T]`（读数）**。若硬用题面 `+∞` 端点，凸性给零信息（两端点不可比）。⇒ 这条路不是"更贵"，是**方向相反**：沿它走会把一个真命题证反。**下一手**：把凸性移入"读数闸"，与 `AAA3:0.3` 的切线夹逼并列。

**(b) `1/β` 凸 + `plaq` 凹 —— `[T]` 引理 / `[NG]` 全域。** `G' = −βplaq''`，故 `plaq''<0` ⇒ `G↑` ⇒ **(EP) 沿凹段向右搬运**：
```
(EP)@β₁ ∧ plaq''≤0 on [β₁,β₂]  ⇒  (EP)@β₂ .
```
这是本路唯一的净产出。与 `WW1` 的 `12.8σ`（`χ_q↓ ⟺ plaq''<0`，`D2=+1.509e−3` 达 `10.9σ`）拼出自洽检验：`G(2.40)=0.0644`（`χ_fd`）／`0.0193`（`χ_var`），`G(2.5)=0.1550`，升 `0.0906`，符号与幅度都和 `plaq''<0` 一致。**全域前件为假**：`G(0)≡0`（因 `plaq(0)=0`、`plaq'(0)=1/4` 同阶），而 `g(2.5)>g(0⁺)` 迫使 `G<0` 在内部出现 ⇒ `plaq''` 不可能在 `[0,2.5]` 恒负（与 `AAA3:0.1` 的四点否证同结论，本文件给**第二条独立理由**）。**下一手**：只在 `[2.4,2.5]` 用搬运引理，前提是先有 `(EP)@2.4` 端点读数（`ρ(2.4)=0.969`，余 `1.03×`，薄）。
