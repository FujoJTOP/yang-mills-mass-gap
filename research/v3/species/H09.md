## §2 ★ 重核 thin atom：它到底满不满足 `H1`

```
ν_ε = w δ_ε + (1−w) δ_{s₂} ,   w = ε/(2λ) ,   s₂ = 2λ(1−w)
```

⇒ **`χ = 1/λ` 精确，不是不等式近似、不是弱化版**。`H1`（λ-形）**成立**。`[E]`

### 2.3 但"取等"会招来一个正当的反问 —— 换成**严格余量**版（本文件新增 ①）

**⇒ 对 §0 第 1 问的回答：**

## §3 三个新候选，逐条验 `H1`（不假设，全算）

### ① 薄原子 + `Δ_dyn > 0` —— **成立** `[T]/[E]`

构造见 §2.3。逐项：`M₀ = w+(1−w) = 1` ✓；`χ = 3/(4λ) ≤ 1/λ` ✓（严格）；`G″ = 1/χ = 4λ/3 ≥ λ` ✓；`W_full=0 ⇒ Δ_dyn = G″ = 4λ/3 > 0` ✓（条件 `[C]`：平坦粗坐标）；`m₁² = ε`，`ε` 任意小 ⇒ `m = 0`（极限族）✓。**模型级实现**：两个独立自由场（质量 `√ε` 权重 `w`、`√(2λ)` 权重 `1−w`）之和 = Gaussian 广义自由场，其 KL 测度**恰好**是该 `ν_ε` `[T]`（Gaussian ⇒ 边缘 Gaussian ⇒ `G″χ=1` 精确，`Q6:83–86`）。

### ② 两个**近简并**原子 + 大 `Δ_dyn` —— **失败：`H1` 假** `[T]/[E]`

```
ν = p δ_ε + (1−p) δ_{ε+δ} ,  p=½, δ=ε :  χ = 1/(2ε)+1/(4ε) = 3/(4ε)
ε=1e−1 → 7.5 ; 1e−2 → 75 ; 1e−3 → 750 ; 1e−4 → 7500   （1/λ = 1）  ⇒ H1 4/4 假
一般式 [T]： ν([0,2ε]) ≥ c  ⇒  χ ≥ c/(2ε)   （因为 s⁻¹ ≥ (2ε)⁻¹ on [0,2ε]）
```
⇒ **`H1` 禁止底部近简并的 `O(1)` 残数**。所以②不是反例：它死在 `H1` 上，不是死在 `m>0` 上。**这一条正面支持 `H1` 的可信度**（它对"低端近简并"有真实约束力），但不救 `H1⇒m>0`：见 §4。

### ③ 连续谱 + `Δ_dyn>0`（`m=0`）—— **成立，且最强** `[T]/[E]`

```
dν_α(s) = s^α e^{−s} / Γ(α+1) ds   on (0,∞) ,   α > 0
M₀ = ∫dν = 1 ,  χ = Γ(α)/Γ(α+1) = 1/α ,  G″ = α ,
m₁² = inf supp ν_α = 0 （精确，支撑是开区间） ,  f₁² = ν({0}) = 0 （**无原子**）
H1 ⟺ 1/α ≤ 1/λ ⟺ α ≥ λ   ——  α=2λ 给 χ=1/(2λ)，余量 1/2，严格
```
精确核（`[E]`）：`quad` 复算 `∫s^{α−1}e^{−s}/Γ(α+1)` 与闭式 `1/α` 到 9 位一致（α=0.25/0.5/1/2/4 ⇒ 4.000000000 / 2.000000000 / 1.000000000 / 0.500000000 / 0.250000000）。
- `α=1`：`χ=1=1/λ` 取等 ⇒ `H1` **真**，`m₁²=0`；
- `α=2`：`χ=1/2 < 1`，`G″=2 > 1=λ` ⇒ **`H1` 严格真**，`m₁² = 0` **精确**（不是极限），`f₁² = 0`。
- 机制：`ν([0,ε]) = ∫_0^ε s^αe^{−s}/Γ(α+1) ds ≈ ε^{α+1}/((α+1)Γ(α+1))` ⇒ 底部残数按幂律消失，`H1` 看不见底在哪。
- 模型级：KL 密度 `s²e^{−s}/2` 的 Gaussian 广义自由场 —— 局域（`C(x) ~ |x|^{-6}`，被积 `s` 的指数衰减保证）、无质量壳、**无粒子**、`m=0`。它不是"自由无质量场"（那个是 `ν=δ₀ ⇒ χ=∞ ⇒ H1` 假，酸测完好）`[T]`。

**⇒ §0 第 5 问：①与③同时满足 `H1` 与 `m=0`；③不需要任何极限或薄残数技巧。② 不满足 `H1`。**

## §4 一条 `[T]` 的机制定理（断掉的就是这一环）

```
对任意正测度 ν 与任意 ε>0：
    χ = ∫ s⁻¹dν ≥ (2ε)⁻¹ · ν([0,2ε])      ⇒      ν([0,2ε]) ≤ 2ε χ
⇒ H1（χ ≤ 1/λ）强制： ν([0,2ε]) ≤ 2ε/λ  对每个 ε。
```
读法：**`H1` 钉住的是底部的"残数密度"（必须 `O(ε)` 消失），从不钉底部的"位置"。**
它允许的整个集合 `{ν : χ ≤ 1/λ}` 里，`inf supp ν` 取遍 `[0, ∞)`（①`=ε→0`，③`=0` 精确）。**要把残数天花板换成位置地板，需要额外一件东西：残数地板 `f₁² ≥ r₀`。** 而
```
m₁² ≥ f₁²/χ   （ch02:51–56 逐字 [T]）  ⇒  H1 ∧ (f₁² ≥ r₀) ⇒ m₁² ≥ r₀λ > 0
```
——**这一行就是 `H1` 要到 `m>0` 必须补的那一件**，正是语料的 `I1`/`H*`，**不是 `H1`**。所以 `H1 ⇒ m>0` 死不是因为 `H1` 弱得可笑，而是因为它只有一个坐标（`s⁻¹` 的一阶矩），而 `m` 是另一个坐标（`supp` 的底）。

**机器核对的"天花板从不咬人"**：`ν([0,2ε])` 实测（`λ=1`，`ε=1e−3`）：①`5.0e−4`、①(严格)`2.5e−4`，天花板 `2e−3` ——都不咬；②`1.0000` 远越天花板 ⇒ `H1` 假。`[E]`

## §5 判死线

```
(a) 找到一个反例 ⇒ 逐字构造 + 验证 ⇒ H1 ⇒ m>0 的那一环节断了      ✓（①与③，§2.3/§3③）
(b) 找不到 + thin atom 只满足弱化                                     ✗（不适用：thin atom 逐字满足 λ-形）
(c) 某候选的 H1 验证不清                                              ✗（②是"假"，不是"不清"；①③全算清）
```

**判：`H1 ⇒ m>0` 死了（(a)）。** 而且不是"死在一个病态点上"：
1. 对**每个** `λ>0` 都有反例（③取 `α=2λ`：`χ=1/(2λ)`、余量 `1/2`、`m=0` 精确）⇒ 不存在"选对地板就救活"的可能 `[T]/[E]`。
2. 反例不靠等式退化（①给了严格余量 `χ=3/(4λ)`；③给了 `χ=1/(2λ)`）。
3. 反例不靠"残数恰好消失"这一巧合（③是 `f₁²=0` 但**底部是软连续边**，`ν([0,ε])~ε³`，不是薄原子）。

**唯一不标 `[T]` 的环节（诚实记账，非 (c)）**：
- `Φ≡0 ⇒ W_full=0 ⇒ Δ_dyn=G″` 是 `[T]`，但"存在一个平坦粗坐标的 4D 类模型族，且 `ν` 在 `(L,a)` 上**常值**"这一句是 `[C]`：本文件只在**测度层**（`H1` 被陈述和被 Lean 机检的那一层，`ch02 eq:h1`、`H1Sharpening.lean`）逐条验完 `H1`；**没有**在真格点上把常值 `ν` 族实现出来跑 `(L,a)` 扫描。⇒ 结论的精确范围：**`H1` 作为 `(ν,λ)` 上的谓词蕴含 `m>0`：假 `[T]`；`H1` 若被额外限定为"某个 4D YM 族的 `(L,a)`-一致陈述"，则本文件不触及那半句（也不与之矛盾：那里的 `H1` 仍未证，而它的唯一已知上行路径是 §4 那条要补 `f₁²` 的路）。**
- 若把 `H1` 读成 `H1(δ_curv)` 且所在模型 `W_full>0`：thin atom 只反 (F)/(D)，不反 (P)。**这一半空着**，但 (P) 与 (F) 是同一不等式（恒等移项），而 (F) 已被杀，故 (P) 作为"`H1` 的额外强度"不构成救兵。
