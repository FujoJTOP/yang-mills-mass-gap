**(c) 触发**——**4/5 范式不需要展开**，故不需要跨 120。但**它们也没有"路"**：无展开 ⇒ 不付半径的账，同时拿不到阶的下界（§3）。

## 1 · 第一问：`120` 的分解（逐步，可复算）

`g²=2N/β`（`R1:116`，N=2 ⇒ `g²=4/β`）：

```
g²(β_A=1/48) = 4·48 = 192          [T]
g²(β_W=2.5)  = 4/2.5 = 1.6         [T]
192/1.6      = 120   ⇒ 120 = Z_O^{tree}(β_eff→β_tgt)      [T]  （= R1:116 逐字）
```

同一算术换坐标：`β_W = N²β_A = 4β_A` ⇒ `β_A=1/48 ↔ β_W=1/12` ⇒ `2.5/(1/12)=30`。[T]
两者差 **恰好 `4 = N²`**：`120 = 4 × 30`。**这就是"120 是什么造成的"的完整答案**：
`2.5` 是 `β_W`（Wilson，物理格点，Teper），`1/48` 是 `β_A`（SZZ 归一，`1/(16(d−1))`，N-无关）——
**把两个坐标相除**得的 `48 = 16(d−1)` 不是物理常数，是**单位数**。

> 用户写法 `120 = 2.5·16(d−1)`：**算术对**（`[T]`），但 `16(d−1)` 里没有物理内容——`d=4` 只进
> SZZ 的半径公式，不进任何耦合的物理跑动。**判：(b)。**

## 3 · 第三问：五范式里谁不需要展开（(c) 触发）

## 4 · "本质 vs 技术"的最终分解（本路唯一产出）

```
120  =  4        ×  30
        ↑            ↑
     N² 单位混算   收敛半径/物理耦合（同坐标）
    [技术·记账]     [技术·方法半径]        ← 数值内容 0
                         └── 定性残渣（本质，1 比特）：
                             半径在深强耦合(g²≈48–192) / 目标在 AF 弱耦合(g²=1.6)
                             ⇒ 定半径级数**必败**（微扰级数在该点半径=0）
                             但这是"0 vs ∞"，**不含任何数字**
```

- **本质 = 1 比特 = 0 个数字**：`[T]`（AF + `1/48` 为方法半径，`R5:180`）。
- **技术 = 120（全部）**，其中可再分：`4`（单位）+ `30`（同坐标半径）；且在真窗口径下技术部分膨胀到 `662/1359`。
- **无中间项**：语料里**没有任何**物理量在 `β=1/48` 处变化（`K_S` 只是穿过 0），所以 `120` 里不存在
  "部分是物理交叉"的第三块。**判：(a) 的产出就是这张表；(b) 成立；(c) 成立。**

## 5 · 路径（由上面直接读出）

1. **不要再搬 `β`**：`120×`/`30×`/`662×` 都是同一物理距离的不同记账，搬它不产生定理（`[NG]`，同 `R1:184-209`）。
2. **在 `β=2.5` 就地取精确恒等式**（无展开、无半径）：`G″=S−D`（实测 `D/S≈2%`）＋ Fredholm 行列式恒等式
   ——这是语料里**唯一**同时满足"无半径 / 非空 / 看得见原子"的对象（宪章 §5）。
3. **缺的对象是 `Ω`，不是数**：`f₁²_phys = Z_O²·Ω·f₁²_lat`（`R1:4.1`）。`Z_O`（=120 的那个）只是**值**的搬运；
   **重叠 `Ω` 才是缺的一步**。任何声称"跨过 120"的路线都在解 `Z_O`，而靶是 `Ω`。
4. **判死**：把 `120` 当作路标的一切记账（含 `137×`、`372×`）→ 改口径即可，不构成障碍（`A06:107-109` 已自改 `137→34.2`）。
