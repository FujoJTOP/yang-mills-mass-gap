## 1. 两项的领头阶（问 1）

**记号**（`ch05` `eq:split` 原样）：`V = S_W + Φ`，`Φ = −log J`，`G = ∂_v S_W`，`H = ∂²_v S_W`，
`G″ = E[H+Φ″] − Var(G+Φ′) = Δ_dyn + W_full`，`Δ_dyn = E[H] − Var(G)`，`W_full = E[Φ″]−Var(Φ′) − 2Cov(G,Φ′)`。

| 项 | `u→0` 领头阶 | 理由 |
|---|---|---|
| `W_full` | **`O(u⁰) = O(1)`** | `β=0` 时 `S_W≡0` ⇒ `Var(G)=Cov=0`，`W_full → E[Φ″]−Var(Φ′)` = 纯 Haar/Jacobian 对象，**不含 `β`**。它就是 `H1C` 的 Haar 地板（`1×1` 量级 `0.10–0.11`，`a₀*` 处 `0.205`）。`[T]`（结构性）+`[E]`（数值） |
| `Δ_dyn` | **`O(u¹)`（一次方）** | 见 §2：`Δ_dyn = −β·Faa + O(β²)`。**不是** `O(u²)`，**不是** `0`，**不是**更高阶。`[T]` |

**`O(u²)` 的段落不是领头阶**，它是 `−β²(⟨f_a²|a₀⟩−⟨f_a|a₀⟩²) ≤ 0` 的次领头修正（本轮数值见 `.log` 的 `V2` 列，全负）。

## 2. 为什么是 `O(u)` 而不是 `O(u²)` —— 一个必须先拆的坑（问 2）

**坑（`[T]`，本轮否定掉的一条路线）**：直觉写法 `Δ_dyn =? −d²/da² log W₀(a)`，`W₀ = ∫δ(a−⟨v,ξ⟩)e^{−S}dξ`。实测（`n07_dyn_strong.log` §2/§3）给出 `Δ_dyn = O(1)`（`a=1.5, β=0.01` 时 `0.418`），**与 `β=0` 时 `Δ_dyn≡0` 矛盾**。
**病根**：`W₀` 的**切片截面依赖 `a`**（`√(π²−a²)`），且平坦密度在图表边上**不消失** ⇒ 分部积分多出一个**边界项**，`−d²/da² log W₀ = Δ_dyn + 边界项`。**该恒等式只在密度于图表边消失时成立**（Haar 版 `J` 在 `r=π` 不消失，`J(π)=1/π²≠0`；`|a|→π` 处 `ρ_v→0` 才救得回来）。

**生效写法（`[T]`，`ch05`/G1 的边际曲率恒等式，逐点、无边界项）**：

```
G″(v;a) = E[ ∂²V/∂a² | a ] − Var( ∂V/∂a | a ),        V = S_W + Φ
Δ_dyn(a) = E[ ∂²S_W/∂a² | a ] − Var( ∂S_W/∂a | a )  = −β·Faa(a,θ) + β²·V₂(a,θ) + O(β³)
Faa(a,θ) := E_Haar[ ∂²f/∂a² | a ] ,  V₂ := ⟨f_a|a⟩² − ⟨f_a²|a⟩ ≤ 0
f(x;θ) = cos(r/2)cos(θ/2) − (x₃/r)sin(r/2)sin(θ/2) ,   S_W = β(1−f)
```

**核验（`[E]`，`n07_dyn_strong2.log` §B）**：`θ=π, a=1.5`，`Δ_dyn^(精确)/[−β·Faa] = 1.0000422 / 1.0000845 / 1.0001691 / 1.000423`（`β = 0.01/0.02/0.04/0.1`）⇒ **线性律成立，`O(u)` 领头确认**。

**为什么 `O(u)` 是必然的、不是"算出来才发现的"**：`E[H|a₀] = −β⟨∂²_af|a₀⟩`，而**条件于 `a₀`** 时 `⟨∂²_af⟩` 一般 `≠0`（条件化破坏了 `a`-方向平移不变；`⟨f|a⟩` 本身就不为 0：`.log` 首行 `θ=0` 给 `0.530/0.468/0.283`）。**无条件的** `E[H]` 才 `= O(β²)`；但 `G″` 是**条件**对象，所以领头阶是 `O(u)`。**这是本轮最容易被写错的一处，已锁。**

## 3. 符号：`−sign Faa`，在 `(a₀,θ)` 上变号（问 3）

`Faa(a,θ) = E_Haar[∂²_af | a]`（`SU(2)` 一 plaquette，`|x|≤π` 基本域，`J=(sin(r/2)/r)²`，`∫Jd³x=2π²` = 标准 Haar）：

| `θ` | `a=0.25` | `0.5` | `1.0` | `1.5` | `2.0` | `2.5` |
|---|---|---|---|---|---|---|
| `0` | `−0.2078` | `−0.2031` | `−0.1849` | `−0.1554` | `−0.1162` | `−0.0690` |
| `π/4` | `−0.1812` | `−0.1663` | `−0.1292` | `−0.0837` | `−0.0323` | `+0.0229` |
| `π/2` | `−0.1271` | `−0.1042` | `−0.0538` | `+0.0006` | `+0.0565` | `+0.1114` |
| `3π/4` | `−0.0536` | `−0.0262` | `+0.0297` | `+0.0849` | `+0.1367` | `+0.1829` |
| `π` | `+0.0281` | `+0.0558` | `+0.1088` | `+0.1563` | `+0.1961` | `+0.2265` |

- `θ=0`（对称边界）：`Faa<0` 全区 ⇒ `Δ_dyn>0` `[E]`。
- `θ=π`（最大 holonomy，语料最坏点）：`Faa>0`（`a₀≳0.4`）⇒ `Δ_dyn<0` `[E]`。
- 变号线在 `θ/π ∈ (0.25,0.5)` 之间随 `a₀` 移动（`a=1.5`：`θ≈0.49π`；`a=2.5`：`θ≈0.54π`）。

**判 (b) 的准确说法**：`Δ_dyn>0` 在 `β<β₁` 上**不是**均匀命题 —— 它是 `Faa(a₀,θ)<0` 的等价改写，而在 `SU(N)` 强耦合窗里 **`θ`（边界 plaquette 的 holonomy）是自由的**：`β<1/48` 时 `θ`-依赖没有 `e^{−β·area}` 压制。**所以不能给 `β<β₁` 上的均匀 `Δ_dyn>0`。** 能给的只有**条件版**（`θ ≲ π/2` 且 `a₀` 小）：

> `[C]`：若 `Faa(a₀,θ) < 0` 在 `β<β₁` 上一致，则 `Δ_dyn > 0`，且 `Δ_dyn ≥ |Faa|·β − C β²`。
> `[NG]`：`Faa<0` **不是** `(a₀,θ)` 上的一致事实（上表 `θ=π` 反例）⇒ **这条条件在语料窗内不可能被满足**。

**能否用 `I1`/`I2` 的机器（四壁 + KP + 重求和）证 `Δ_dyn>0`？不能，而且是"原理上打错靶"**：那三件机器证的是**振幅/残数**（`f₁² = a₀D_∞ ≥ ½(2N)^{-2}`，`[T] mod [KL]`），即 `u` 的**零阶**量（`a₀=(2N)^{-2}` 与 `β` 无关，`Z04 §2.3`）。`Δ_dyn` 的 `O(u)` 领头是 `β` 的**一次项**，它的系数 `Faa` 只吃**单 plaquette 的 Haar 条件矩**，与四壁几何、KP 半径、装饰重求和**全不相干**（`.log` 的 `Faa` 是纯 3D 求积，无任何图展开输入）。**⇒ 想证 `Δ_dyn>0` 必须新造一台"holonomy-一致"机器，而不是复用 `I1`/`I2` 的。这是本轮的结构性否决，写清。**

## 4. 数值（问 4）：`β=β₁=1/48`、`N=2`、用 `I1` 的 `a₀=(2N)^{-2}=1/16`

**换算（`[T]`，`X01`）**：`u = β_W/(2N²) = β/8`（`N=2`），`β = 2N²u = u/(2a₀)`（`a₀=(2N)^{-2}=1/(4N²)`）⇒
`Δ_dyn = −β·Faa = −8u·Faa = −(Faa/4)·(u/a₀)`。

| 量 | 值 | 标签 |
|---|---|---|
| `u(β₁) = (1/48)/8` | `2.6042e−3` | `[T]` |
| `Δ_dyn` 单 plaquette，`θ=0, a₀=0.5` | `+4.232e−3` | `[E]` |
| `Δ_dyn` 单 plaquette，`θ=π, a₀=2.0` | `−4.086e−3` | `[E]` |
| `Δ_dyn` **4D 单链模**（`×6` plaquette/链） | `[−0.0245, +0.0254]` | `[E]` |
| `W_full`（同 `a` 量级，`β→0` 地板） | `≈+0.10`（`a=1.5`）；`a₀*` 处 `0.205` | `[E]`+`[T]` |
| 比值 `|Δ_dyn|/W_full` | `≤ 0.25`（`θ=π,a=2,×6`） | `[E]` |

## 5. 对"决战"的直接后果（不许绕过）

1. **`Δ_dyn>0` 在 `β<β₁` 上不能升 `[T]`**（判 (b)）。**它不构成决战第一个据点**：`W_full` 已经独立地把 `G″` 顶在 `≥1/6>0`，`I1`/`I2` 的证书**一处也不经过 `Δ_dyn`**。**"`Δ_dyn` 与 `I1`/`I2` 同级"这个前提是错的**：`I1`/`I2` 是 `O(u⁰)` 量，`Δ_dyn` 是 `O(u¹)` 量。`[T]`
2. **"把 `Δ_dyn>0` 推到 `β=2.5`"这条路线在本轮被判为"窗内无据可推"**：本轮的 `u`-级数在 `β=2.5` 处 `u=0.3125`，线性律给 `Δ_dyn(θ=π,a=1.5) = −8(0.3125)(0.1563) = −0.391`，而 `P02` 实测 `+0.884`（`L=2`、`k=0` 模）⇒ **符号与量级都对不上，级数远在收敛半径外**。**不得把本文件的数外推到 `β=2.5`。** `[E]`+`[M]`
3. **真正的据点在 `W_full` 侧**：窗内 `G″ ≥ W_full ≥ (N/12)‖v‖² > 0` 是 `[T]`（`H1C` `eq:wgeo-quant` + `Φ″ ⪰ 0` 逐点）。`Δ_dyn` 唯一能贡献的是**把地板抬高或压低 `O(u)`**：`θ=0` 侧抬高 `+8u|Faa|`，`θ=π` 侧压低 `−8uFaa`。**"比值地板"该问的是 `W_full` 的 `N`-一致性与 `β=2.5` 的 `D/S`，不是 `Δ_dyn`。**
4. **酸测（自由场）**：自由无质量场 `Φ≡0, S≡0` ⇒ `G=H=0` ⇒ `Δ_dyn≡0`（`β=0` 处精确为零）。`Δ_dyn` **不制造地板**，因此它**不可能**单独承担 `Δ₀>0`——这与 §0 一致。`[T]`
