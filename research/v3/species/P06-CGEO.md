## 1. `C_geo` 的**精确**定义（并核准符号）

从 `o06 §1.1` 的精确式出发，**先把 `β` 剥出来**：

```
S_W = β S_geo ,   S_geo(U) := Σ_p (1 − ½ Re tr U_p)          （β-无关）
H_vv = β · D(v) ,  D(v) := ∂²_s S_geo(U(s))|_{s=0} ,   U_ℓ(s) := exp(X_ℓ + s v_ℓ)   ← o06 的图（chart）
     = β Σ_p [ ½⟨U_p,K_p⟩_Re − ½⟨U_p,W_p'⟩_Re ] ,   K_p = H_p² ⪰ 0 ,  ⟨A,B⟩:=Re tr(AB)
```

**定义**（本文件，即任务所给式子的正部）：

```
D(v)      =  Σ_p ½⟨U_p,K_p⟩ − Σ_p ½⟨U_p,W_p'⟩                    （= H_vv/β，β-无关）
C_geo(v) := (−D(v))^+ = max(0, −D(v)) = [ Σ_p ½⟨U_p,W_p'⟩ − Σ_p ½⟨U_p,K_p⟩ ]^+
⇒  H_vv = β D ≥ −β C_geo        **点态、逐方向、逐组态**，且**尖锐**（D≤0 时取等）
⇒  E[H_vv|0] ≥ −β·E[C_geo|0]
```

**三条核准（`w7/p06_cgeo.log [0]`）**：

| 核准项 | 结果 |
|---|---|
| 分解式 `H_vv = β[½⟨U,K⟩ − ½⟨U,W'⟩]` 的**符号** | 4 link 随机组态、3 个方向：FD `H_vv` vs 分解式，rel `3.1e−6 / 9.1e−6 / 1.3e−5` ⇒ **公式与 `o06` 同号同系数**，`½`、`β`、`Re tr` 位置全对 |
| `K_p ⪰ 0` | `eig(K) = (0.2450,0.2450)/(0.1393,0.1393)/(0.1515,0.1515)` ⇒ 全非负（`SU(2)` 上 `K_p ∝ 1`，标量） |
| 唯一带号者 | `<U_p,K_p>/tr K_p = 0.8707` 随 `X` 变、随 `v` **不变**（三个方向同值）⇒ 符号只由 `U_p` 的对齐决定，与 `o06 §1.1` 读法一致 |

**`C_geo` 与 `o06 §4.4` 的关系（(c) 的正面回答）**：`o06:189` 的 `C_geo^tri := Σ_p[½tr K_p + ½|Re tr(U_pW_p')|]` 满足
`C_geo(v) ≤ |D(v)| ≤ C_geo^tri(v)`（逐点，`(−x)^+ ≤ |x|`；数值 `n=3000` 全过，`log [4]`），
且 `sup C_geo^tri / sup (−D) = 1.97/1.20 = 1.64` ⇒ **大化子只松 1.6 倍，但它不是负部**；`o06` 那条 `β`-线性界用的正是 `C_geo^tri`，所以它比本文件精确式的界**更松**（方向无关的常数倍），**结论方向不变**。

**量纲/归一（沿用 `o06 §3.3`、`AGENTS.md §2.1`）**：`‖v‖² := Σ_ℓ tr(v_ℓ^†v_ℓ)`；本文件**所有方向都归一到 `‖v‖²=1`**，故地板读作 `(N/12)‖v‖² = 1/6`（`N=2`），所有 `E[C_geo]`、`E[D]` 都是"每单位 `‖v‖²`"。`C_geo` 对 `v` **二次齐次**（`C_geo(λv)=λ²C_geo(v)`，因 `D` 是二次型）⇒ 该归一不损失信息。

## 5. 界，与判死线 (a) 的**逐字**推广

### 5.1 数值界

```
E[C_geo|0] ≤ 0.039 ‖v‖²         （单 plaquette，β=2.5，sup over 261 个方向；`log [1]`）
E[C_geo|0] ≤ 0.213 ‖v‖²         （L=2，Haar，rank 1；光滑多 link 方向 0.070；`log [2]`）
E[C_geo|0] ≤ 0.005 ‖v‖²         （L=2，β=2.5，`log [2]`；光滑方向 0 到分辨）
β·E[C_geo|0] ≤ 0.097 ‖v‖² = 0.58·(N/12)‖v‖²      （单 plaq，β=2.5，sup over v）
β·E[C_geo|0] ≤ 0.069 ‖v‖² = 0.41·(N/12)‖v‖²      （单 plaq，β∈[0,10] 上的峰，const-axis 族）
β·E[C_geo|0] = 0 到抽样分辨                    （L=2，β=1/2.5/5）
```

### 5.2 解析界（诚实说明它是废的）

`C_geo ≤ |D| ≤ Σ_p[½tr K_p + ½|Re tr(U_pW_p')|]`，用 `K_p=H_p²`、`‖W_p‖ ≤ Σ_{ℓ∈∂p}‖v_ℓ‖`（`Ad` 保 HS 范数）、每条 link 属 6 个 plaquette：

```
Σ_p ½ tr K_p  ≤  2 Σ_p Σ_{ℓ∈∂p}‖v_ℓ‖²  =  12 ‖v‖²          （d=4）
Σ_p ½|Re tr(U_pW_p')|  ≤  c₂‖v‖² ,  c₂ = O(10²)（‖W_ℓ'‖≤‖v_ℓ‖²、transport 项 ≤6(Σ‖v‖)‖v_ℓ‖ 的粗估）
⇒  C_geo ≤ (12+c₂)‖v‖²  ~  10²‖v‖²    ≫  N/12 = 0.167
```

⇒ **解析路线对 (a) 无用**（常数大 `600×`），判 (a)/(b) 只能靠数值；数值给出 `≤0.039`，**比解析小 2500 倍**，两者不矛盾（解析是三角不等式丢掉的相消）。

### 5.3 (a) 的逐字形式（**这是本文件要交的那句话**）

> **命题 P06（`[C]`，数值；代数部分 `[T]`）**：在 `SU(2)`、`β=2.5`、单 plaquette 与 `L=2` 4D、261/258 个方向（含 Savvidy、rank 1、128 个每 link 随机、128 个常轴）上，
> ```
> E[H_vv + Φ''|0]  ≥  (N/12)‖v‖²  −  β·E[C_geo|0]
>                  ≥  (N/12)‖v‖²  −  0.58·(N/12)‖v‖²
>                  =  0.42·(N/12)‖v‖²  >  0            （单 plaquette，β=2.5，sup over v）
> ```
> 且 `L=2` 的物理测度下第二项为 `0`（`E[C_geo]=0` 到分辨），**更强**。
> ⇒ **多 link 方向的曲率地板成立**；把它与 `O05` 的方差上界 `Var(G_v)≤β²V₀` 一比，"地板 + 方差"这条链**不再只是秩 1 类的定理**，秩 1 的结果可上抬到全部方向（窗口宽度由 `β_c = sqrt(0.42·(N/12)/V₀) = 2.51` 给出，仍覆盖物理点 `β=2.4–2.5`，但余量从 `1.55×` 缩到 `1.00×` ⇒ **窗口边界正好压在物理点上，这是新的定量代价，必须写明**）。

**同时给更强的、不依赖 `C_geo` 的那一条**（同一批数据）：

```
E[H_vv|0] = β·E[D|0] = +0.387 ‖v‖²   （单 plaq，β=2.5）   /   +3.1 ‖v‖² （L=2，β=2.5）
⇒  E[H_vv+Φ''] ≥ (N/12)‖v‖² + βE[D]  =  0.55‖v‖²  /  3.3‖v‖²   ≫ 0
```

⇒ 曲率侧在多 link 方向上**平均为正**，`C_geo` 的负部只是"最坏情形保险"，实际余量比 `0.42(N/12)` 大得多。

## 7. 未闭合（诚实标注）

1. **sup 只在 261/258 个方向上取**（128 随机 + 128 常轴 + Savvidy + rank 1 + 4 个单 link 轴），不是单位球上的真 `sup`。随机族 128 个方向的 `E[C_geo]` 标准差 `0.00036`、常轴族 `0.00003` ⇒ 漏掉的方向把 `sup` 抬过 `0.039`（单 plaq）超过 `2×` 的可能性低，**但没证**。`[C]`
