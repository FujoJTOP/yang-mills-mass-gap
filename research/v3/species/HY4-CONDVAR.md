## §1 一行式（形态、量词、等价性）

```
(VC-pt)  ∃ c>0, c_H>0, c_E>0, j₀ ;  ∀ j∈{j₀,…,J(a)}, ∀ U′∈𝒮_t^coer(j), ∀ v∈(ker P)^⊥, ‖v‖=1 :
             Var( ∂_vV | U′, a₀ )   ≤   (1−c) · E( ∂²_vV | U′, a₀ )          ← 上界 / 相对 / 固定分数
           a₀ = a₀(j,U′,v) 是 ρ_v(·|U′) 的钉点（m(a₀):=−ρ′/ρ=0）；**不是** ∀a₀
           𝒮_t^coer(j) := { U′ : E[H_vv|U′,a₀] ≥ c_H β_j Q_c }              ← 条件强制，不是测度式好集
  (SEED)   Z_j^{-1} E( ∂²_vV | U′,a₀ )  ≥  c_E Q_c                            ← 唯一外生输入
  ⇒ (M2)   Z_j^{-1} G″_cond  ≥  c·c_E·Q_c = c·c_E·c_L ,   G″_cond = E(∂²V|a₀) − Var(∂V|a₀)
```

| 签注 | 取值 | 缺了会怎样 |
|---|---|---|
| **形态** | **上界**（分母 `E[∂²V\|a₀]`，`Θ(β_j)`）；`c` **固定**，不要求 `o(1)`/`1/β_j` 精度 | 写成 Fisher 型**下界**（`Var ≥ 1/Var(a)`）方向就反了：那是平均式，见 0.4 |
| **量词** | `∀U′` 必须换成 `𝒮_t^coer`；`a₀` 是依赖变量 | 在 `E[H\|a₀]=o(β_j)` 处 `Z_j^{-1}E[∂²V\|a₀]→0`，**任何**方差界都给不出 `c·c_L`（0.2） |
| **窗** | 单点 `a=a₀`、`m(a₀)=0`；`{E[H]+E[Φ″]>0}` | 头部 `E[H]+W=−0.03<0` 使 `Var≤E−δ` 无符号（`HU2:42` 转引 `BL2:42`） |

**等价性（两行代数，`[T]`）。** 正向：`Z_j^{-1}G″ = Z_j^{-1}E[∂²V] − Z_j^{-1}Var ≥ c_EQ_c − (1−c)c_EQ_c = c·c_EQ_c`。反向：`(M2)` 给 `Z_j^{-1}Var ≤ Z_j^{-1}E[∂²V] − δ̂` ⇒ `Var ≤ (1−c′)E[∂²V]`，`c′:=δ̂/(c_EQ_c)`。⇒ **`(VC-pt) ⟺ (M2)` 模 `(SEED)`**；`(SEED)` 自由块 `[T]`（`=Q_c+m/β_j`）、交互侧 `[NG]`（`HU5:88` 的 seed 项）。

**两窗（这条把靶**定位**了）。** 一般 `U′`：`E[H|a₀]≈β_jQ_c` ⇒ 预算 `β_jQ_c=25.67`（基壳），要求 `Var ≤ (1−c)·25.67`；**屏障型 `U′`**：`E[H|a₀]→0` ⇒ 归一地板本身给不出（0.2）⇒ 必须由 `𝒮_t^coer` **排除**，不是靠更紧的方差界救。⇒ **绑定窗是屏障附近，不是"大场集"**；在那里唯一的预算是 Haar 项 `E[Φ″]=Θ(1)`。

**酸测（五模型）。** 自由场 `Φ=0`：`Var(∂V|a₀)≡0`、`E[∂²V]=β_jQ_c` ⇒ 靶真且**非空**（UV 面必须过；`V1:273–276` 判"把 H1 酸测搬过来"是类别错误）。IR 零模 `Q_c=0`：预算 `→0` ⇒ 靶必须**败**（H1 面）。2D：`c_L` 同式 ⇒ 判别力 0（`HQ1:134`）。单片 plaquette：`Var(G|a)=0.0691` 是裸 `O(1)` 量（`P22:54`，引文自标 `[V]`），方向对但 `E[H|0]=0` ⇒ 落在屏障窗。M6：无内层可涨落自由度 ⇒ 域外（`P06:27`）。

## §2 三路

**(a) Fisher 平均 + 某个集中不等式 → `[NG]`。**
- 平均式 `[T]`：`E_{a∼ρ_v}[G″] = I(ρ_v) ≥ 1/Var(a)`（`H3-A:262–263`）；移项即 `E_ρ[Var(∂V|a)] ≤ E[∂²V] − 1/Var(a)`——**恰好是靶的平均版**，所以路线形状是对的。
- **`[T]` 关键（本路的新判）**：该平均式在自由块**精确饱和**：`E[∂²V]=β_jQ_c+m`、`I=β_jQ_c+m`、`Var(·|a)≡0`（`V1:48,122`）⇒ **零余量**。⇒ 平均→点 的差距**全部**是交互内容，不是"技术细节"；任何以"平均已足够好"开头的稿子都在这一步把靶丢了。
- `[T]` 反例：两高斯混合上 `G″(0)=−24<0` 而 `I(ρ)>0`（`HU2:72`）⇒ **不存在**"Fisher 预算 ⇒ 点值"的一般不等式。
- **下一手**：只在 `𝒮_t^coer` 上求 `a`-模 `|d_a Var(∂V|a)| ≤ C`（条件 Stein 把它写成三阶/四阶**条件**累积量）；无模的集中不等式必空——`ρ` 自己在 `a₀` 取最大，Chebyshev 型论证没有可利用的尾部。

**(b) Stein 恒等的条件版（是否存在？）→ 存在 `[T]`，但作界 `[NG]`。**
- 存在且精确：`d/da E[f|a] = E[∂_v f|a] − Cov(f,∂_vV|a)`（`P22:37–42`，源 `main.tex:1148–1152`，边界项 `J|_{∂Ω}=0`）。取 `f=∂_vV` ⇒ `G″(a)=d m_F/da`；取 `f=Φ′` ⇒ `W_geo(a):=E[Φ″|a]−Var(Φ′|a)=d/daE[Φ′|a]`。
- 但它是**换名**：未知量 `Var` 与靶 `G″` 同处一侧，没有第二个方程；无条件的闭包靠边界项消失（`G4:95–110`），条件化把边界项变成 score 项、其值**就是**靶（`O01:88` 逐字；`GPP-STRUCT:131`）。
- 加强版是唯一可用形态 `[T]`：条件 Simon–Lieb `Var(∂_nV|a₀) ≤ E[⟨∇_⊥(∂_nV),K^{-1}∇_⊥(∂_nV)⟩|a₀]`，前件 `K⪰γI`（`HN1:187`；`S12:68` 的 `D` = 它的余项；Malliavin/BE-L 面见 `MALLIAVIN-BISMUT:3`，同判："从上方卡 `G″`"）。
- 前件 = Savvidy：`Hess S_W` 不定（`λ_min=−g|B|`，负方向占 `0.21–0.42`）⇒ `[NG]`。唯一 `[T]` 实例：单片 `βVar(∂_t h) ≤ E[∂_t²h]` 对 `θ/π ≤ 0.3882`（`R09:84`）——**形状能赢，但赢的窗在屏障前就停**，与 §1 的两窗同向。
- **下一手**：`K=K₊−K₋` 谱分裂，用 `K₋` 在 `𝒮_t^coer` 上的秩/测度控制，换一条"不定 `K` 的条件 Simon–Lieb"；它同时给 `S12:68` 的 `D` 一个符号来源。

**(c) 反例判无界 → `[NG]`（且"无界"不成立）。**
- **`[T]`：不存在无界。** 块变量在紧群上 ⇒ `|∂_vV| ≤ Cβ_j` ⇒ `Var(∂V|a₀) ≤ O(β_j²)`；预算是 `Θ(β_j)` ⇒ 缺口是**一幂** `β_j`（与 `HU6:27` 的"现有方差界差一个 `β_j` 因子"同一句）。⇒ 本路能证的只有"平凡界差一幂"，不是"无界"。
- `[T]`：反例只杀**错误量词**——`∀a₀`（混合 `−24`，`HU2:72`）、`∀U′` 去掉 `c_H`（屏障处 `E[H|a₀]=0` 使 `G″` 只剩 Haar 项，`P22:86`）。`𝒮_t^coer` 内 **0 个** `[T]` 反例。
- 唯一可能的膨胀机制 = **纤维双峰**（同一 `a₀` 上两条 Gribov 支都有不可忽略权重）：`Var ∼ M²` 而 `E[H|a₀]` 仍 `O(1)`。先兆：`Var(G|a)` 从 `θ=π/2` 的 `0.01524` 涨到 `θ=π` 的 `0.06912`（`4.54×`，`P22:65`，引文自标 `[V]`）——**先兆不是证明**。
- **下一手**：在 `𝒮_t^coer` 内造/否证双峰见证（同一 `a₀`、两 Gribov 支、纤维权重各 `≥ε`）；单片近 `θ=π` 是最近的可算点。若造出：靶 `[NG]` 升级为 `[T]` 假；若否证：`𝒮_t^coer` 上的单峰性就是靶的可用输入。

## §3 "无小参数"能否绕开

| 候选 | 值 / 关系（自算） | 判 | 依据 |

| `g_j²=1/(2β₀j)` | 基壳 `1.5381`（`j=7`）、`1.1963`（`j=9`） | 现状 `[T]` | `HU2:18,63` |

| `1/(β_jQ_c)` | `=g_j²/(2NQ_c)=g_j²/(4π²)=0.038961`（`β_7Q_c=25.6667`） | **同一个参数**（只差 `1/4π²`）；作**单位**必需，作**小参数**不是新的 | `V1:238` 的 `Q_c+m/β_j` |

| `q=ma≫1` | 交叉点 `q≈1` | 不在本链上、未证 | `[NG]` |

**判（两半，必须分开记）。**
1. **作为小参数：绕不开 `[T]`。** 把"缺陷 `≤0.01`"当靶，根是 `j≥27.27→28`（`aΛ≤2^{-28}=3.725e−9`）；而 `g_j²≤0.6` 的根是 `j≥29.9→30`（`aΛ≤9.31e−10`）⇒ 换成 `1/(β_jQ_c)` 只把根挪 `2` 个壳（`aΛ` 上 `4×`）。**不是新参数，是同一根曲线换刻度。**
