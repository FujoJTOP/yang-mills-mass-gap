## §1 引理陈述

**【β-延拓引理 BCL】** 固定 `N`、`a`。在 `𝒞_L=T³_L×ℝ` 上取 `β_c=1/48`、`β_*=2.5`、`Δβ:=β_*−β_c=119/48=2.4791…`、`r₀:=¼(2N)^{-2}`（`N=2` ⇒ `1/64`）。设

> **(i)** `f_L(β_c) ≥ r₀` 对**所有** `L`（端点地板）；
> **(ii)** 存在 `R>2Δβ` 与 `M_R<∞`：`sup_{|z−β_c|≤R} sup_L |f_L(z)| ≤ M_R`（`L`-一致模界）；
> **(iii)** `M_R < R·r₀/(2Δβ)`。

则
```
  ∃δ>0 ∀L ∀β∈[β_c,β_*] :  f₁²_L(β) ≥ δ := r₀³/M_R² > 0 ,
```
即 `inf_{β∈[β_c,β_*]} inf_L f₁²_L(β) ≥ δ`；`δ ≤ r₀`，`N=2` 时 `δ = 3.815e−6/M_R²`，取 `R=2Δβ` 则 (iii) 收成 `M_R ≤ r₀` 且 `δ = r₀`。
`N=2` 读法：**(iii) 就是 `M_R < R/317.33`** —— "残数在半径 `2Δβ` 的复盘里涨不过端点地板的 1 倍"。
**边界（同 P3）**：结论是 **I1 型**（残数/权重地板），**不是** I2 隔离、**不是** `f₁²_∞`、**不是** `a→0`；`L→∞` 从不取。

**证明（三行，全 `[T]`）**：(H2) 整性 ⇒ `f` 在盘内全纯；**(ii)+(iii) 经 Jensen**：`n(r) ≤ log(M_R/r₀)/log(R/r)`，取 `r=R r₀/M_R` 右边 `<1` ⇒ 零自由半径 `≥2Δβ`；零自由后 `log|f|` 在 `B(β_c,2Δβ)` 调和，对非负调和 `log M_R−log|f|` 用 **Harnack**（`ρ=Δβ`、比 `3`）⇒ `log|f| ≥ 3log r₀−2log M_R`。
