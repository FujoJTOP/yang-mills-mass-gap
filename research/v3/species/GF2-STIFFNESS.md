## §1 `curv` 钉死：格点上是什么，最小公式

### 1.1 记号

`C ⊂ Z²` 有限、连通（polyomino；一条格点 plaquette = 一个格）。`n = |C|`。
`k_v := #{C 的格在顶点 v 周围 4 个位置中占几个} ∈ {0,1,2,3,4}`（`v ∈ Z²`，周围 4 格 = `(v−(1,1)), (v−(0,1)), (v−(1,0)), v`）。

### 1.2 三种读法，逐条给公式

| 读法 | 公式 | 性质 | 能当"成本"吗 |
|---|---|---|---|
| **(a) 拓扑 / Gauss–Bonnet** | `χ_v := (4 − k_v)/4`，`Σ_v χ_v = χ(C)`；等价 `Σ_v (4−k_v) = 4χ(C)` | 单连通 ⇒ 恒等于 `1` | **不能**：它是**常数**，`κ·4χ` 只是把权重乘 `e^{−4κ}`，对 `μ`、对 `γ`、对窗**零作用**（§1.3） |
| **(b) 周长（界面面积）** | `p(C) := #{ 边界单位边 } = 4n − 2·(共享边数)`，亦 `= p + (4n−p)/2` 条的相异 link 数 `ℓ = 2n + p/2` | 边界量；对"薄"类广延（`p/n→1.9`），对"胖"类 `p~√n` | 可以，但见 §2：它不含"曲"的信息 |
| **(c) 反角数（reflex corner）** | **`curv(C) := #{v : k_v = 3}`** | 边界量；`0 ≤ curv ≤ p`；`curv(C)=0 ⟺ C` 是矩形（单连通情形） | 可以，这是"曲率"的**唯一非平凡**读法 |

**最小公式（本文件采用的 `curv`）：**

```
curv(C) = #{ v ∈ Z² : #{ cells of C at v } = 3 }        （反角 / 凹角数）
```

它正是"4 个格子占了 3 个"的顶点数，也就是边界在该点向内折 90° 的地方。
三个恒等式（都可逐例核对，见证 §Part 1/§Part 2）：

```
Gauss–Bonnet（polyomino 版）：  c₊ − curv = 4(1 − h)      c₊ := #{v : k_v = 1}, h := 洞数
bargraph（列凸+平底，高度序列 h_1..h_k）：
        p = 2n + 2k,        curv = #{ i : h_i ≠ h_{i+1} }
column-convex（每列是区间 [b_i,t_i]，相邻列相交）：
        p = 2n + 2k − 2·Σ_i |[b_i,t_i] ∩ [b_{i+1},t_{i+1}]|
        curv = Σ_i ( #{ I_i 的端点在 I_{i+1} 内部} + #{ I_{i+1} 的端点在 I_i 内部} )
```

**数值核验**（`gf2_stiffness.log` Part 1/2）：
`h=(1,2,1,3)`：`n=7`、`p=16=2·7+2·4`、`curv=3=#{i: h_i≠h_{i+1}}` ✓；
L-tromino `{(0,0),(1,0),(1,1)}`：`n=3`、`p=8`、`curv=1` ✓。

### 1.3 `[T]` 拓扑读法是空转的

`Σ_v (4 − k_v) = 4χ(C)`。对单连通 `C`（列凸类全部单连通）`χ = 1`，于是

```
cost ≥ σ|C| + κ·(4χ) = σ|C| + 4κ     （对所有单连通 C 同一个常数）
```

这只是把每个簇的权重乘 `e^{−4κ}`，**不改变任何类的增长常数**，也不改变任何形状的相对权重。
⇒ **"curv = 欧拉示性数贡献"这一读法在数学上是空转的**（不是错，是没有信息）。

**这一条很重要**：任务书里"角缺陷数 / 欧拉示性数贡献"两个候选，前者（反角数）是边界量、后者是常数；
**没有第三种**。想用 `curv` 去区分"有悬垂/无悬垂"，只能用反角数或周长，而这两个都不改变 Wilson 的代价（§2）。

## §2 悬垂是否必然增加界面面积？——**否**；且面积项对形状全盲

### 2.1 `[T]` 固定 `|C|` 下，悬垂不增加任何代价

Wilson 作用量逐片可加：

```
S(U) = Σ_{p ∈ 全格} β(1 − (1/N) Re tr U_p) ,   每个 s_p 只依赖 U_p 自己
⇒ 对任何"支撑在 C 上"的组态：cost(C) = Σ_{p∈C} s_p
⇒ 对任何两个 |C| 相同的簇：min cost 相同（= |C| · s_min），与是否悬垂、是否有气泡无关
```

⇒ **"悬垂（在某个方向折回）必然增加界面面积"是假的**，只要比较是在固定 `|C|` 下做的；
而聚合物权重正是按 `|C|` 分级的（`a_n` 是 n 片簇的个数），所以正确系综就是固定 `|C|`。
在固定**跨度**下比较才会"增加面积"，但跨度不是系综变量。

> 这一条正是 `GE2-DEFDIM.md:182–189`（§2.2(b2)）的加强版：那里说"两侧的率相同 ⇒ 压制纯来自广延性"；
> 这里是"**率相同到连形状都不看**"——`s_p` 只依赖 `p` 自己的 holonomy，所以 `cost(C)` 是 `|C|` 的函数。

### 2.2 `[T]` 所以面积项**不可能**压制悬垂（"面积项已压制、不需曲率项"这条路死了）

若面积项能压制悬垂，必须存在一个"悬垂越多、代价越大"的机制；由 2.1，`cost` 与形状无关，
**故这样的机制在 Wilson 作用量里不存在**。压制（若发生）只能来自**计数**：即"悬垂的形状更少"。

§3 的枚举把这件事量化了：`column-convex`（无悬垂格）`μ = 3.2056`，`bargraph`（无悬垂+无气泡）`μ = 2`。
**两者都不悬垂，μ 却差 1.6 倍** ⇒ 决定 μ 的不是悬垂，是气泡（悬浮）。

### 2.3 `κ` 能从哪来？四条候选，逐条判

| # | 候选来源 | 判 | 理由 |
|---|---|---|---|
| (i) | **plaquette 结构（Wilson）** | **`κ = 0` 恒等** `[T]` | 作用量逐片可加；`s_p` 不看邻居。**不等式对 κ>0 直接假**：L-tromino（`n=3, curv=1, cost=3σ`）⇒ 需 `3σ ≥ 3σ+κ` ⇒ `κ≤0` |
| (ii) | **link 共享 / 测度 / 特征标展开** | 只给**边界**型修正 `[C]` | 一个簇的相异 link 数 `ℓ(C) = 2|C| + p(C)/2`（每个格 4 条边、共享边算一次 ⇒ `p+ (4n−p)/2`）。这是**权重上界**里的因子，不是作用量里的代价；而且即便当作代价，它是 `p` 型（§3.5：`ρ_p≈1.9`），不是"曲率" |
| (iii) | **Bianchi 约束** | **是"类的限制"，不是"代价"** `[T]` | 格点 Bianchi = 每个 cube 六面乘积为 1（`BianchiLemma.md:46–52`，`BIANCHI-COAREA.md:107–110` 秩 0）。它约束**哪些 C 允许出现**，不给任何 C 附加能量；`GE2 §1.4` 已证"有代价的集合不是闭链（L≥3）" |
| (iv) | **角落敏感算子**（2×2 "twist"、四片角落项） | 唯一能给出 `curv` 结构的项，但**不在标准作用量里** `[J]` | 一个顶点周围 4 片同时出现在一个算子里才会产生"反角"依赖；Wilson 与 Symanzik（1×2 矩形）都是"每片/每对相邻片"，`#矩形包含给定片 = 4` 与形状无关 ⇒ 仍逐片量 |

⇒ **`[NG]`：曲率项没有来源。** 它不是"弱"，是"不存在"。

### 2.4 `[E]` 若硬加一个 `κ`：定量门槛

设某算子给出 `cost ≥ σ|C| + κ·f(C)`，`f` 是边界量且 `f/n → ρ > 0`。则

```
μ_eff(κ) = lim [ Σ_{C∈C_n} e^{−κ f(C)} ]^{1/n} · e^{−σ} = μ · e^{−κρ}
窗口 ⟺ γ − κρ ≤ 1 ⟺ κρ ≥ ln(μ/e)
```

`column-convex`：`ln(μ/e) = 0.164894`；实测（§3.5）`ρ_p ≈ 1.9`、`ρ_c ≈ 0.51`

```
周长型：κ ≥ 0.164894 / 1.9  ≈ 0.087
反角型：κ ≥ 0.164894 / 0.51 ≈ 0.32
```

**这两个数必须由一个真实存在的算子给出，而不能由"局域性"推出**——局域性给的是逐片可加（κ=0），
恰好是反方向。⇒ 这一条是 `[E]`+`[O]`，不是 `[T]`。

### 3.5 `[E]` `ρ_p`、`ρ_c`：边界量在**这个类**上是广延的（这一点必须说清）

> 本文件的 [NG] 不靠这一条，靠的是 2.1 的**形状盲**（更强、且与类无关）。

## §4 酸测（自由场 / 2D / M6 / 单片 + 本工具专用的一测）

| 模型 | 行为 | 判 |
|---|---|---|
| **自由场**（`β=0`） | `cost = 0`（`s_p = 0`）⇒ `cost ≥ σ|C| + κcurv` 对任何 `σ>0` **直接假**（不是空转，是错）；反过来类的 `μ`、`γ` 与 `β` 无关（`GE2 §4`：`a_n`/`B_n` 与群、`β` 无关）⇒ 这一层对动力学**全盲** | 不等式**不通过**；类结论**无判别力** |
| **2D YM** | 缺陷是点（`codim 2 = dim 0`），无形状、无形状熵 ⇒ `γ=0`、`μ=1 ≤ e` **平凡满足**；但 2D 的隙来自精确解，不来自这条判据 | 满足处与有隙处重合 ⇒ **无判别力** |
| **M6** | 无规范场、无 plaquette 邻接图、无 transfer（`N02:69–74`，经 `GC2-H23:307`）⇒ **无对象** | **无定义** |
| **单片** | 单格：`n=1, p=4, curv=0` ⇒ 不等式**退化成立**（`σ ≥ σ`）；`μ=1` 平凡 | **退化通过，无信息** |
| **★ L-tromino 测**（本工具专用，新增） | `C={(0,0),(1,0),(1,1)}`：`n=3, curv=1, cost=3σ`。任何声称"角落更贵"的作用量必须给它 `>3σ`。Wilson 给**恰好** `3σ` | **Wilson 必然不过**——这就是 §2.1 的实测版 |

**酸测结论**：这一层是**代价侧**的，而代价在 Wilson 里是形状盲的，所以：
- 不等式本身 `[NG]`（不是空转，是假）；
- 类的结论 `[T]` 但**只含计数**，与 `β`、与动力学无关——与 `GE2 §4` 对 `γ_ent` 的判词同构：
  **能进闸门的只能是常数（`γ`），载体仍必须是 `c₀`。**

### 5.3 不得写的话（防下一轮误引）

1. **不得写**「表面刚度 `cost ≥ σ|C| + κ·curv` 是 YM 的一条待证事实」——它在 Wilson 上是**假**的（`κ=0` 恒等，L-tromino 反例）。
2. **不得写**「悬垂必然增加界面面积」——固定 `|C|` 下面积恒为 `|C|`；面积项形状盲。
3. **不得写**「排除悬垂就够」——column-convex（无悬垂格）`μ=3.205569 > e`，超 1.18×。
4. **不得写**「bargraph 的 `μ=2` 是因为它没有曲率」——bargraph 的 `curv = #{i: h_i≠h_{i+1}}` 是 `Θ(n)`，反角**很多**；它过线靠的是**平底（无悬浮）**，不是"光滑"。
5. **不得写**「directed 是排除悬垂的类」——`{(0,0),(0,1),(0,2),(1,0),(1,2)}` 是 directed 且有悬垂格（§3.3）。
6. **不得写**「边界项一律指数不可见」——对 column-convex 是**广延**的（`p/n→1.9`、`curv/n→0.51`）；只在胖类上才不可见。
7. **不得写**「`K=2` 过线」——`μ_2 ≈ 2.7457 > e`（`W` 超 0.0100）；阈值是 **`K≤1`**。
8. **不得写**「拓扑曲率（欧拉示性数）能当刚度用」——单连通类上它是常数 4，空转。
