## 1 · `𝕋₊` / `𝕋₋` 到底是什么簇

### 1.1 原文链条（逐字锚）

- `X01-L1C.md:43`：`ε_T = Σ_{α>T}(α−1−T)A(α)`；`log Z_dec(B_T) = Σ_α (T−α+1)_+A(α) = φ_dec T + log D_∞ + ε_T`。
- `X01-L1C.md:29–35`：`α` = **附着跨度**（attachment span），有限程 ⇒ `α ≤ α_max` 是 `O(1)` 松弛。
- `C03-BYPASS:50` / `F07-ADJCBAR:31`：几何模型 `A(α) = U^{α+1}/(1−U)` ⇒ `ε_T = U^{T+3}/(1−U)³`（`|ε_T|/U^T` 常数、无 `T` 前因子）。
- `P4-OTHER:134`：正横向和 `a₀ = (2N)^{-2}(1/N)(… ) ≥ 1/32`，**全正、无符号抵消**；`:135`：领先类唯一、取等 iff 直管 ⇒ `D_∞` 的"`1`"是**正的那一笔**。
- `RS5.md:194`：`𝕋` 由 Ursell 系数 `φ^U`（交错和）构成 ⇒ `𝕋` 非正 ⇒ 锥不入内部。

### 1.2 两个分裂，必须分开（这是 (c) 的实际内容）

| 分裂 | 切什么 | 出现在哪 | 是不是 `𝕋 = 𝕋₊ − 𝕋₋` |
|---|---|---|---|
| **跨度分裂** | `α ≤ T` / `α > T` | `(L1)` 恒等式：主体 `φT+log D_∞` / 尾部 `ε_T` | **不是** |
| **符号分裂** | `A(α) ≥ 0` / `< 0` | Ursell 交错和 | **是**，且**与 `T` 无关**，是核的结构分裂 |

于是钉死如下（本轮采用，全部下游数依赖它）：

```
𝕋₊ : 核 A_+(α) = max(A(α),0)   ← 正 Ursell 权的簇：直管领先类 + 四壁正横向和（P4:134–135）
𝕋₋ : 核 A_-(α) = max(−A(α),0)  ← 被交错和判负的簇：弯管/嵌套等非直装饰簇
‖𝕋₋‖  := ρ(𝕋₋)                 （逐元非负 ⇒ Perron 根 = 算子范数）
gap(𝕋₊) := 1 − ρ₂(𝕋₊)           （𝕋 已归一到 Perron 根 1）
Kato 判据: ρ(𝕋₋) < 1 − ρ₂(𝕋₊)
```

### 1.3 反例警告（把 `ε_T` 当 `𝕋₋` 会怎样）

若误取 `‖𝕋₋‖ := sup_T|ε_T|`（即"尾部就是负部"），几何模型给 `sup_T|ε_T| = ε_0 = U³/(1−U)³`：`β=0.018394`（`U=0.25`）时 `= 1/27 = 0.037`，`β=2.5`（`U=33.98`）时 `= 33.98³/(32.98)³ = 1.0937` — 两个 β 都 `<1`，会得出**假 (a)**：`β=2.5` 也"收敛"。**这正是 `ū>1` 区里最容易被误判的一步**，故 T2 单独列。

## 3 · 判

### (a) `β = 0.018394`：**成立，但是空的**

比值 `1/3 < 1` ⇒ Kato 判据满足 ⇒ 微扰收敛、`D_∞>0`。但把 `Σ|A| = ū/(1−ū) < 1` 解开：

```
ū/(1−ū) < 1   ⟺   ū < 1/2
```

即**闸门本身**是 `ū < 1/2`，比 `(L1)` 的 `ū < 1`（`P4:159`）**紧 2×**。所以这一支给出的窗口是 `(L1)` 窗口的**真子集**：**路线 P 一点新 `β` 都不进**。（`u=β/8` 口径下 `ū<1/2` 恰是 `β = 2/eΔ = 0.036788`，与 `P4:160` 已有的保守阈值同数 —— 是同一个窗，不是新窗。）
**⇒ (a) 的数可以给（`1/3`、`0.1429`），但它不换任何新东西；`D_∞` 的正性仍只在 `ū<1/2` 内，离 `33.98` 差 136×。**

### (b) `β = 2.5`：**需非微扰**，而且是"判据不可用"级

`ū = 33.9785 > 1` ⇒
1. `Σ_α|A(α)| = +∞` ⇒ 若按绝对和定义，`‖𝕋₋‖ = +∞`，比值 `= +∞`；
2. `gap(𝕋₊) = 1−ū = −32.98 < 0` ⇒ **`𝕋₊` 自身没有谱隙**，拒绝"准紧"前提（`RS5 (H1)`）；
3. 退一步走**带符号条件收敛**（= `rs5` 要的"带符号抵消引理"）：那时 `𝕋₊`、`𝕋₋` 各自无界 ⇒ `𝕋 = 𝕋₊ − 𝕋₋` **不是有界分裂** ⇒ Kato 判据不适用。

**二分法封闭**：绝对 ⇒ `+∞`；条件 ⇒ 判据不适用。**两条路都判 `>1`，且都不需要知道 `A_−` 占 `Σ|A|` 的份额**（份额是语料没定的唯一自由度，见 §4 限定）⇒ 判词对份额稳健。`[T]`

### (c) 定义清不清？

**部分不清、本轮钉死**：语料只有**跨度分裂**（`α≤T` / `α>T`，T2），**没有**符号分裂（T3）。若不钉，`𝕋₋` 有歧义，`β=2.5` 会被误判成"收敛"（§1.3 的 `1.0937 < 1` 假 (a)）。钉死后 `β=2.5` 的判词**与符号份额无关**，故这里不必再加 (c)。
