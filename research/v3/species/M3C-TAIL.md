## §2 `a_c ≥ 2` 为什么给 `m_c ≥ ½ln(1/u)`：**推导**（含对 L3C 写法的修正）

### 2.1 五环 KP 机器交付的**显式余项**（这是本关全部内容的来源）

```

   Δ, C̄ 是 KP 动物常数，**与算符无关**

`PROOF-P3.md:15`（逐字，第二条独立出处）：

```

```

两条说的是同一件事：**非极小聚合物的余项相对极小项是 `O(ū)`，其常数只吃 `(Δ, C̄, e)`**。写成质量的形状就是

```
   m_c ≥ a_c·L − C_eff ,      C_eff := ln(C̄·e·Δ) = ln(2·e·20) = ln(108.7313) = 4.688879        (★)

`[T]`（对 `a_c=1`，`A02:60` 逐字同值）；`[C]`（对 `a_c ≥ 2`：见 §5 限定 3）。

### 2.2 由此推到 `m_c ≥ ½L`——**两条路，只有差式是对的**

**绝对式（L3C §4 用的，会引出一个假靶）**：
```
   a_c ≥ 2  ⇒  m_c ≥ 2L − C_eff ；要 ≥ ½L 需 C_eff ≤ (3/2)L = 8.073（窗边）          [M]
   若再减去 0⁺⁺ 基线（m_c ≥ L − C 的写法）要 ≥ ½L 需 C_eff ≤ ½L = 2.691 ⇒ ✗（4.689 > 2.691）
```

**差式（正确，且更强）**：因为 `C_eff` **是同一个数**（c-盲，§3），相减时**精确对消**：
```
   m_c − m_{0⁺⁺} ≥ (a_c·L − C_eff) − (1·L − C_eff) = (a_c − 1)·L        ← 余项**没了**
   a_c ≥ 2  ⇒  m_c ≥ m_{0⁺⁺} + L ≥ L  >  ½L        （m_{0⁺⁺} ≥ 0 平凡；实际 ≥ δ > 0）  [T]
```
`IN11:13` 逐字已有这个形状：`m_c − m_{0⁺⁺} ≥ (a_c − 1)·ln(1/u) + O(1) → +∞`。本关的**增量**是：**那个 `O(1)` 有显式值 `−C_eff`，且它在两道之间是同一个数 ⇒ 差式里 0 余项**。⇒ `+O(1)` 可删成 `+0`。`[T]`

### 2.3 任务书提示的 `c_r·dim r ≤ β^{|r|}/|r|!e^β` 是哪一件？——**收敛条件，不是率**

语料里有**两个** KP 面，别混（`RATE-UNIFORM §1.1` 是聚合物面，`UC-COMPLETE §1.2` 是特征标面）：

| 面 | 判据 | 它给什么 | 吃 `J^{PC}`？ |
|---|---|---|---|
| **特征标面** | `ρ(a,β) = λ_aΣ_{n≥1}(n+1)(c_n/c₀)e^{an} < 1`；等价闭式 `λ_aΦ(0,β)<1`，`Φ(0,β)=βe^β/(2I₁)−1` | **展开的收敛半径**（`β<0.0182686`，`UC §1.2` 逐字） | **NO**：只有表示指标 `r`、`dim r`、`c_r` |
| **聚合物/动物面** | `S_β(a)=Σ_{X∋x}\|φ(X)\|e^{a\|X\|} ≤ a` | **率**（`r(β)=max{a:S≤a}`，`RATE-UNIFORM §2.3`） | **NO**：只有形状/几何与 `β` |
