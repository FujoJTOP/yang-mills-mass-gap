## §1 · `D3` 的精确陈述（测度、方向、量词）

### §1.1 设置（一个比特都不糊）

```
  T⁴_L 环面，Wilson 作用量，耦合 β，格距 a 固定。
  μ   = Gibbs 测度 on G^E（G = SU(N)），                （有限体积 V = L⁴a⁴）
  P   : G^E → G^{E_c}  粗化映射（低通/块平均，取定一个），U′ = P U，ξ ∈ ker dP
  ν   = P_*μ                                            （粗场边缘，测度一）
  μ(·|U′)                                              （纤维条件分布，测度二，逐 U′ 一个）
  全方差律  Var_μ(F) = E_ν[ Var_{μ(·|U′)}(F) ] + Var_ν( E_μ[F|U′] )      （精确）
  正交分裂  |∇F|² = |∇_∥F|² + |∇_⊥F|² ,  ∇_⊥ = 纤维方向（∂_ξ），∇_∥ = 粗方向（∂_{U′}）
```

### §1.2 三个变体（同一句话的三种量词化；本文件的主要工作是把它们分开）

> **`D3-full`（`R2 §2.3` 写的那个，也是装配真正需要的那个）`[定义]`.** `∃λ_f>0` 使**对每个** `L,a,V`、**对每个** `F∈L²(μ)`（含**依赖 `U′`** 者）：
> ```
>      E_ν[ Var_{μ(·|U′)}(F) ]  ≤  (1/λ_f) · E_μ |∇_⊥F|² ,
> ```
> 且 `λ_f` 与 `U′`、`L`、`a` **无关**（`b` 只需**固定**）。

> **`D3-weak`（只准纤维函数）`[定义]`.** 同式，但 `F = f(ξ)`（**不**依赖 `U′`）。

> **`D2`（`R2` 的逐点版 = 语料的实际用法）`[定义]`.** `∃λ_f>0` 使**对每个** `U′`、**对每个**纤维函数 `f`：
> ```
>      Var_{μ(·|U′)}(f)  ≤  (1/λ_f) · E_{μ(·|U′)} |∇_⊥f|² .
> ```

**四点必须记住的差别**（这四点合起来就是本文的全部内容）：
1. **测度换了**：`ν` ↔ `μ(·|U′)`。两个测度，与 `H1` 不同（`R2 §3.1` 已判：这不是"H1 的全局版"）。
2. **方向换了**：`∇_⊥` 而非 `∇_∥`。`∇_⊥` **湮灭** `U′`-函数。
3. **量词序**：`∃λ_f ∀L ∀a ∀V ∀F`。`λ_f` 必须在 `V` 上一致——这是**唯一**真正的缺步（`R2 §4.2`）。
4. **`F` 的类**：`D3-full` 允许 `U′`-依赖，`D3-weak` 不允许。**这一点决定够不够用**（§1.3），也是 `R2` 没有分开的地方。

### §1.3 为什么装配需要 `D3-full` 而**不是** `D3-weak`（本文件的第一处实质结论）

> **命题 1.3（探测函数）`[T]`.** 取 `A ⊂ {U′}` 可测、`g` 纤维函数，令 `F_A(U′,ξ) := 1_A(U′)\,g(ξ)`。则
> ```
>   Var_{μ(·|U′)}(F_A) = 1_A(U′)·Var_{μ(·|U′)}(g) ,      |∇_⊥F_A|² = 1_A(U′)·|∇_⊥g|²   （精确）
> ```
> 即 **`U′`-局部化对纤维能量免费**。⇒ `D3-full` 等价于**一族集合测试**：
> ```
>   ∫_A Var(g|U′) dν  ≤  (1/λ_f) ∫_A E_{μ(·|U′)}|∇_⊥g|² dν    ∀A, ∀g .      (★)
> ```

*证明*：链式法则 + `∇_⊥1_A = 0`。∎

**推论（够用性的形状）`[T]`**：装配要控制**任意** `F` 的**条件**方差 `E_ν[Var_{μ(·|U′)}(F)]`（见定理 3.1 第 2 步）。`D3-weak` 只控制 `U′`-无关的 `F`，对 `F_A` 无能为力。⇒ **`D3-weak` 不足以装配**，且这不是技术缺口：`[E]` 给出 `E_ν[Var(F_A)]/E|∇_⊥F_A|² = 1001`（`A` 占 `ν` 质量 `p=0.1`，`σ²` 在 `A` 上大 `10³` 倍）而 `D3-weak` 的最优常数只要求 `1/λ_f ≥ 1/E_ν[σ²] = 9.9e−3`——差 **101 倍**。
⇒ **"平均"这件事在装配式里根本没有位置**：能平均的版本不够用，够用的版本不能被平均。

## §2 · 强弱：与逐点版、与 `H1`（含反例方向）

### §2.1 `D2 ⟹ D3-full`（平凡方向）`[T]`
`Var_{μ(·|U′)}(F) ≤ (1/λ_f)E_{μ(·|U′)}|∇_⊥F|²` 逐 `U′` 成立 ⇒ 取 `E_ν` 得 `D3-full`。⇒ **`D2` 严格强（弱化方向成立）。**

### §2.2 反方向：`D3-full ⟹ "`ess-sup` 版 `D2`"`（**本文件的主定理**）`[T]`

> **定理 2.2（集合测试 = 本质上确界）.** 记 `c(U′) := sup_f Var_{μ(·|U′)}(f) / E_{μ(·|U′)}|∇_⊥f|²`（纤维 Poincaré 常数的倒数）。
> 则 `D3-full`（常数 `λ_f`）**⟺** `c(U′) ≤ 1/λ_f` 对 **`ν`-几乎每个** `U′` 成立，即 `ess-sup_ν c ≤ 1/λ_f`。

*证明.*
(⟹) 由 (★) 取 `A` 任意、`g` 任意：`∫_A Var(g|U′)dν ≤ (1/λ_f)∫_A E_{\mu(·|U′)}|∇_⊥g|²dν`。
令 `a(U′)=Var(g|U′)`、`b(U′)=E_{μ(·|U′)}|∇_⊥g|²`（皆 `≥0` 可测）。若 `a > (1/λ_f)b` 在某个正测集 `A₀` 上成立，则 `∫_{A₀}a > (1/λ_f)∫_{A₀}b`，与 (★) 矛盾 ⇒ `a ≤ (1/λ_f)b` `ν`-a.e. ⇒ 逐 `g` 成立。再用**可数稠密族**（纤维紧、`μ(·|U′)` 与 Haar 有界等价 ⇒ 两侧对 `g` 在 `H¹(Haar)` 上连续）promote 到全体 `g`。
(⟸) 若 `c(U′)≤1/λ_f` `ν`-a.e.，则对任意 `F`，把 `g := F(U′,·)` 逐点代入并积分即可。∎

**读法**：`D3` 的"平均"**唯一**换到的东西是 **`sup → ess-sup`**——一个**零测集**上的让步。这正是判死线 (a) 的精确形态。

### §2.3 Gibbs 类内 `ess-sup = sup`，故 **`D3-full ≡ D2`**（判死线 (a) 的执行）`[T]`

> **定理 2.3（坍缩）.** 设 (i) `ν` 在粗构型空间上满支撑（每个非空相对开集有正 `ν`-质量）；(ii) `U′ ↦ c(U′)` **下半连续**。则 `ess-sup_ν c = sup c`。
> 在格点 Gibbs 规格下两条都成立：`ν ≍ Haar`（作用量有界 ⇒ `μ ≍ Haar`，`P` 为连续满同态 ⇒ 推前 Haar 仍是 Haar）；且 `c` 是**连续函数族的上确界**（`C¹` 有限程 ⇒ `U′ ↦ μ(·|U′)` 总变差连续 ⇒ 每个固定 `f` 的比值连续）⇒ `c` 是 `lsc`。
> ⇒ **`D3-full` 与 `D2` 的常数逐体积相等**，故 `{∃λ_f ∀V: D3-full}` **⟺** `{∃λ_f ∀V: D2}`。

*证明*：`lsc` ⇒ `{c>t}` 开；若非空则 `ν`-正测度，与 `ess-sup` 有限矛盾。∎

> **推论 2.3′（判死线 (a) 的裁决）.** `D3-full` **不是**更弱的靶：它在**唯一重要的轴**（`V`-一致性）上与 `D2` 给出**同一个常数序列**。`R2` 的"少一个 `∀U′` 量词"是**真的但无效**：那个量词只在零测集上有内容。
> ⇒ **对"换更弱的靶"这一战略目标：`[NG]`。** 对"把陈述写对"：`[T]`。

## §7 · 结论与路径

**一句话**：`D3`（`ν`-平均纤维 LSI）**恰好够用**（定理 3.1，`[T]`）、**在 Gibbs 类内与逐点版逐字相同**（定理 2.2+2.3：它只是 `D2` 的 `ess-sup` 改写，而 `ess-sup = sup`）、**酸测已死**（自由场上真 ⇒ gap 含量 0）、**与 `H1` 不可比**；唯一真正更弱的版本 `D3-weak` 有实测 `1.50–9.91×` 的增益却**不够装配**（命题 1.3 的探测函数）。三台发动机（Stein/Fisher/BE）**输出天生 `U′`-一致**，因此**看不见这个差别**，全部终止在同一个读数上：`ess-inf Hess_⊥ ≥ λ_f`，而它在 `β=2.5` 是 `−5.000`。⇒ **`D3` 是一个正确的靶，不是一个更弱的靶。判死线 (a) 触发、`[NG]`。**

**路径（按信息量排序）**
- **P1（立即可做，`[T]` 级，零风险）**：把 **E1–E3** 落进 `R2-H2GLOBAL.md §2.4` 与 `LOOP-RUNBOOK §9.1`：把"`D3` 严格弱于逐点版且够用"改成"**`D3-full` 是 `D2` 的 `ess-sup` 改写（Gibbs 类内相等）；严格更弱的是 `D3-weak`，而它不够装配**"。此后任何"平均一下会更好证"的提案，先查定理 2.2–2.3。
- **P2（唯一还有内容的方向）**：**真正的松弛轴是检验函数类，不是 `U′`-量词。** `#3/#4` 实际只需要 `(P_μ)` 在**中性扇区 `k→0` 粗模**的函数上成立（`UC-COMPLETE §4` 的 `e₃` 只消费那一支），而 `D3-full` 要求**全体** `F`。把靶从"全 `F`"收到"中性扇区"，是 `D3` **不能**提供、而 `H1` 轴**可以**提供的那一次下调。⇒ 下一轮该攻的是 **`H1` 的扇区限制版**，不是 `H2` 的任何平均版。
