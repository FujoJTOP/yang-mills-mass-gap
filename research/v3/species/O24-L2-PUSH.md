**判决（逐字，条款 (b)）**：

> **`Δ > 0` 且 `≥5σ` ⇒ 中心值负是统计假象 ⇒ `H1` 在 `L=2` 成立，警报解除。**

- 用**两个独立误差估计**（`σ_jk`、`σ_τ`）**都**越过 `5σ`，且**同号为正**。这是本轮唯一被判的量。
- **`Δ_raw` 与 `Δ_norm` 的判决不可能不同**：`L²=4` 是**同一个常数**同时乘在 `Δ` 与 `σ` 上，故 `Δ/σ` **尺度不变**（`15.3σ`/`6.0σ` 两行完全一致）。**归一化只改数值大小，不改符号，也不改 σ 数。** 之所以要写明：`‖v‖²=1/L` 的因子若只乘分子不乘分母才是错的；本文件两者同乘。
- 条款 (a) **不触发**；条款 (c) **不触发**（已超 `5σ`）。

### 0.1 `Δ` 是否含 `W_full` 与 `a²Δ₀²` —— 明说

`Δ := E[κ|0] − Var(F|0)`，`κ = ∂²_v V`、`F = ∂_v V`、`V = S_W + Φ`、`Φ = −log J`。所以：

- **含 `W_full = W_geo + X` 的 `W_geo` 部分**（`Φ'' = −∂²_v log J` 已进 `κ`），`Φ'` 已进 `F`（实测 `E[F] = +0.03`，`|E[F]| ≪ σ` ⇒ 交叉项 `X` 的 `Cov(G,Φ')` 可忽略，未单独报）。
- **不含 `a²Δ₀²`**：这是**格点单位**、`a→0` 未做、`L=2` 单体积。故本文件报的是 H1 的 `δ` 的**格点裸量**，不是连续极限的 `δ = a²Δ₀² + W_full`。
- ⇒ **本文件的 `+0.394`（raw）/`+1.577`（norm）是「格点上 `G''(0)` 的符号」，不是物理 `δ` 的数值。** 判的是**符号**，符号与 `a²Δ₀²>0` 同向，故 `(b)` 的结论不会被 `a²Δ₀²` 反转。

## 1. `o11` 的 `−0.2209` 为什么翻了：两个采样器缺陷（本轮定位并修掉）

`o11_lat.py` 的链**没有把平坦坐标限制在 `SU(2)` 的基本域**，且本轮的初版还额外引入了「全体链路同向平移」提议。两者都会让链**漂出基本域**，量到的不再是 Haar 测度。

**(F1) 基本域缺失（关键）**。`x_l` 是平坦坐标，`U_l = exp(i x_l·σ/2)`；`x → U` 在球 `|x_l| < 2π` 上是**双射**（`|x|=2π` 整球映到中心元 `−I`），Haar 测度 `dU = J(x)dx`，`J = 4sin²(r/2)/r²`。`|x|>2π` 是**同一群的重复覆盖**：那里的平坦密度 `e^{−S}J ∝ e^{−S}/r²` **几乎不衰减**（`Φ ~ 2log(r/2)`），是一个无回复力的逃逸方向。`o11` 因此让链漂到 `r ≫ 2π`，`Var(F)` 被抬到 `2.14/1.86`；本轮正确限制（`|x_l|<2π` 硬拒绝，拒绝率 `0.58%`）后 `Var(F) = 1.53 ± 0.02`（4 链：`1.536/1.532/1.496/1.577`）。
**`Δ = E[κ] − Var(F)` 的翻号几乎全部来自 `Var(F)`：`2.0 → 1.53`**（`E[κ]` 只从 `1.78 → 1.93`）。

**(F2) 全体平移模式（本轮初版自伤，已删）**。在平坦坐标里模型**没有平移不变性**，把 64 条链路同向平移 `d` 是一个无势能约束的零模；实测它把每条链路压到 `|x|=2π` 壳层上，`κ` 伪影到 `1e5–1e7`（`τ_K→1.5`，四链一致），是本轮过程日志里 `E[κ]≈9e4` 的来源。**删除该提议后 `E[κ]` 立刻回到 `1.92–1.95`**（与 `o11` 的 `1.78` 同量级）。此条只作为故障记录，不进结果。

> 因此 `o11` 的 `−0.2209 ± 0.1198` **不是一个无偏估计的正态涨落，而是被 (F1) 偏置的采样**：它是在**非 Haar 覆盖区**上量的 `Var(F)`。`1.84σ` 的"负号苗头"不成立。

## 2. 采样器与统计量

- **格点**：`L=2` ⇒ 16 位点、64 link、96 plaquette、`β=2.5`；模 **A**（`k=0` 均匀，`v_{l,3}=1/8`，`‖v‖=1`）。
- **切片**：`⟨v,X⟩=0` **精确保持**。模态 A 上 `v_l` 各链相同 ⇒ 用**配对转移**提议 `x_l += w`、`x_{l'} −= w`（`w~U(−ε,ε)³`），既精确保切片、又**无全局串扰**，故维护的 96 个 plaquette 迹**始终精确**（`V0` 不需重算）。对称提议 ⇒ MH 精确。

## 3. 重尾诊断（`κ` 在 `r→2π` 有对数奇点）

机制：`Φ = −2log|sin(r/2)/(r/2)|` 在 `r=2π` 发散，`κ` 的 `Φ''` 项 `~ 2/δ²`（`δ=2π−r`）；当 `δ ≲ h=1e−3` 时 `κ ~ (2/h²)log(h²/δ²) ~ 1e6–1e7`。这是**估计量的重尾**（真实密度 `∝ δ²`，事件概率 `∝δ³`）。

| 诊断 | 结果 | 判读 |
|---|---|---|
| `κ` 分布（`6e4` 样本） | mean `1.9293`、median `1.9193`、MAD `0.1322`、max `18.26`、min `1.182`、std `0.2797` | `max/median = 9.5`，**没有**出现 `1e5` 级卫星点 |
| Hill 尾指数 `α`（上 1% 的 `|κ−median|`） | **`1.97`**（`F`: `8.78`） | `α≈2` ⇒ `Var(κ)` 处于**边缘可积**，`σ` 需按保守值取 |
| **median 版** `Δ = med(κ) − Var(F)` | **`+0.3814`** | 与 `+0.3942` 差 `3%`，**尾部不驱动中心值** |
| winsor `0.1%` / `1%` / `5%` | `+0.3954` / `+0.4437` / `+0.6500` | 砍掉最极端 `0.1%` 后**几乎不变**（`+0.0012`）⇒ 重尾贡献可忽略 |
| 顶部贡献占比 | top `0.01%` 只占 `E[κ]` 的 `0.1%`；top `0.1%` 占 `0.3%` | `E[κ]` **不是**尾部加权出来的 |
| `|κ−med|>10·MAD` 占比 | `0.20%` | 尾部稀薄 |

> **结论**：`κ` 的尾指数 `α≈1.97` 说明 `σ_jk` **原则上**可能偏乐观（这也是为什么同时给 `σ_τ`），但**实测上尾部对 `Δ` 的贡献 `<5%`**，且 `median/winsor` 三个版本与主值同号同量级 ⇒ **本轮 `+0.394` 不是尾伪影**。重尾**不是**瓶颈。

## 4. 还需多少样本 / 瓶颈在哪

- 已达标：`σ_τ` 路线 `+6.03σ`（`1.5e4` sweeps/群，`4` 群）。`5σ` 门槛在 `σ_τ=0.0653` 下已越过。
- 若要把 `σ_τ` 推到 `10σ`：需 `σ ≤ 0.0394` ⇒ 样本 `×(0.0653/0.0394)² = 2.7` ⇒ `4.0e4` sweeps/群，墙钟 `≈ 7 min`/群（本采样器 `2.5 ms/sweep/链`）。
- **瓶颈 = `Var(F)` 的自相关时间**（`τ_F = 22–30` sweeps），**不是重尾**（见 §3），也不是 `E[κ]`（`τ_K = 16–44` 但方差小）。`σ_τ` 里 `Var(F)` 项占 `(0.069/0.070)² ≈ 97%`。
- 想降 `τ_F` 的正路：`F` 是 `V` 的一阶导，耗散在 `k=0` 模 ⇒ 需要**动量型（HMC）**或**多尺度/傅里叶块**提议，而不是继续加 sweeps。本轮 `1.5e4` sweeps 只把 `Neff` 做到 `1898`。

## 5. 诚实标注（未闭合）

1. **单体积、单 `β`**：`L=2`、`β=2.5`、无 `a→0` 标度、无 `L`-扫描。结论**不**外推到 `L=4,6,8`。`Δ/σ` 的**符号**判据只在格点裸量上成立。
2. **只做了模 A**（`k=0` 均匀）。模 B（单链路）本轮未跑：`o11` 给 `+0.0703 ± 0.1448`（`+0.49σ`），在 (F1) 修正后**必须重测**，不能沿用。两模不可混用（`Δ` 与 `‖v‖` 无关但**依赖模方向**）。
3. **`σ_jk` 与 `σ_τ` 差 `2.5×` 未完全闭合**：块长 375 sweeps 的理论独立性在 `τ_F≈30` 下应成立，`σ_jk` 偏小更可能是 `Var(F)` 的 `χ²` 型分布 + jackknife 的向下偏；已按保守 `σ_τ` 判，但**这个分歧本身值得下一轮用 `Var(F)` 的块自助（bootstrap）复核**。
4. **`E[F] = +0.035 ± 0.03`**：与 `X→−X` 对称性要求的 `0` 相容，未发现偏置；但 4 群同号（`+0.051/−0.055/+0.059/+0.084`）值得留意，若真有偏置会进 `Var(F)` 的交叉项。
5. **`a²Δ₀²` 未算**（§0.1）：本文件的 `Δ` 是格点裸量，判的是符号。
6. **`o11` 的 `−0.2209` 应作废**（§1 (F1)）：不是在 Haar 覆盖区上量的。`O11-PHYS.md` 的 §3、§4.1、§7.1 需按本文件回填更正。
