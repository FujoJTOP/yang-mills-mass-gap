## 1. 定义核准：从 `P06` 的式子重推 `D`，确认负部

```
D(v) = d²/ds² S_geo|₀ = −½ Re tr U_p'' = −½ Re tr[(W_p' + W_p²) U_p]
     = ½⟨U_p, H_p²⟩ − ½⟨U_p, W_p'⟩ = ½⟨U_p,K_p⟩ − ½⟨U_p,W_p'⟩ ,   ⟨A,B⟩ := Re tr(AB)
H_vv = β · D(v)                                    （β 精确提出，C_geo 里没有 β）
C_geo(v) := (−D(v))⁺ = max(0, −D(v)) = [½Σ_p⟨U_p,W_p'⟩ − ½Σ_p⟨U_p,K_p⟩]⁺
⇒ H_vv ≥ −β C_geo(v) 点态、逐方向、逐组态（D≤0 时取等）   [T]
```

**数值核准**（`log [0]`）：

## 5. 判决：`2.51` 不是真边界；`1.0×` 余量是**采样假象**

**给 `P06` 的账重记一句**：它的算术**没有内部错**——用它的 `sup=0.038842`（`β=2.5`）跑同一复合判据，得 `2.5056`，正是它写的 `2.51`。**错在 `sup` 这个统计量**：`sup_v` 是**样本极大**，`P06` 用 `128` 个随机方向抽到 `0.038842`，本文件用 `300` 个（新种子）抽到 `0.042900`（`+10.4%`；`605` 方向的 `sup` 仍是 `0.042900`，即 `const-axis` 族 `0.0284` 抢不到 `sup`）。**`sup` 只随方向数变多而变大 ⇒ `β_c` 只随方向数变多而变小**：

```
β_c ≤ 2.2922   （单调方向：方向更多 ⇒ sup 更大 ⇒ 根更小）   ⇒ β_c < 2.5 有单向稳健性
```

`P06 §7.1` 自己写了"`sup` 只在 261 个方向上取…没证"。**这一条不是脚注，它就是判词**：`1.0×` 的余量完全由这个未收敛的 `sup` 撑着，`11%` 的 `sup` 变动就把边界从 `2.51` 打到 `2.29`（`P06 §7.4` 也承认"随机族均值 ⇒ `β_c=2.9`"，即同一个量在 `[2.29, 3.01]` 内随取法漂移，见 (C)/(D)）。

**判死线落点：`(b)`** ——

> 边界 `< 2.5` ⇒ **物理点落在窗口外** ⇒ 「`(N/12) − βE[C_geo] − β²V₀ ≥ 0`」在 `β=2.5` **不成立**（`S=−0.0097`）。**这是坏消息。**

**必须同时写清的限定（否则会读成"曲率地板塌了"，那是误读）**：

1. **地板本身仍然成立**：`(N/12) − βE[C_geo] = +0.0594 = 0.356(N/12) > 0`（`β=2.5`），且 `min_β` 也是 `+0.0575`。`C_geo` 的赤字**从不**吃掉 `N/12`（峰 `0.655(N/12)`）。
2. 失效的是**证书链**「地板 − `β²V₀`」：`β²V₀` 在 `2.5` 已 `0.0691`，比地板余量 `0.0594` 大 `16%`。也就是说，绑死窗口的是**方差项**，不是 `E[C_geo]`。
3. **不是 H1 被否**：`Var ≤ β²V₀` 是**上界**；真 `Var` 可能更小。同批数据里 `E[H_vv] = βE[D] = +0.39…+3.2‖v‖² > 0`（`P06 §5.3` 末、本文件 `E[D]=+0.156` 单 plaq / `+1.253` `L=2`）⇒ 真实曲率侧在物理点**平均为正**。**失效的是这条"地板+方差上界"的证书，不是物理命题。**

**保守窗口（可直接用）**：`S(β)>0 ⟺ β < 2.29`；余量 `≥1.1×` 要求 `β ≤ 2.08`；`≥1.05×` 要求 `β ≤ 2.18`。**建议把窗口写成 `β ≤ 2.2`（`S=+0.0042 = +2.5% of N/12`），并在正文注明物理点 `2.4–2.5` 处该证书为负。** 只要不去压 `sup_v`（把 `E[C_geo]` 的 `sup over v` 真算出来）或改 `Var` 的界，`1.0×` 就不该写进结论。

## 6. 未闭合（诚实标注）
