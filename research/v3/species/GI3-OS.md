  ⇒ **语料里唯一那条"跨扇区序关系"（min-max，`[T]`）在本问题上逐字是恒真式。** 这正是 `AGENTS.md §2.3`「算式对 ≠ 有内容」的第三个实例（前两个：`ε=1/Λ`、`κ_W=0`）。

### 2.3 若 `T` 不可分，最小公式会是什么？（反事实，逐字给出并逐字判死）

语料里**已经有**跨块耦合的唯一公式形态 —— two-block / Feshbach–Schur 引理（`L1B-FESHBACH.md:51–55` 逐字 = `ch05:322–342`、`FORGE-BLIND:18–20` 同文）：

```
Lemma (two-block gap; unconditional, abstract).  A = [[A, B],[B*, C]] on H = H_− ⊕ H_+ ,  C ≥ γI .
Σ := A − B C^{-1} B*  on H_− .   If Σ ≥ μI ,  then
        A ≥ min{ μ/(1+2‖B‖²/γ²) , γ/2 } · I  > 0 .
```

**把它套到本问题上（逐字）**：取 `A := H`、下块 `H_c ≥ γI`（`γ ≤ m_c`）、`B := P_n H P_c = T_nc` 的生成元形式。
- **这个公式确实是"联合约束"的正确形状**：`Σ = H_n − B H_c^{-1}B*` 是**同时消费两块**的对象（`H_c^{-1}` 是带电块的逆），与 `SS-SECTOR §5.2` 的 (ii) 型（"带电×中性的联合/状态层约束"）逐字同型。
- **但它在本问题上双封**：
  1. **前提自含结论**：`B = 0`（§2.1）⇒ `Σ = H_n` ⇒ 前提 `Σ ≥ μI` **逐字就是中性隙本身**。
  2. **`B` 的符号方向也反**：结论界里的因子 `1/(1+2‖B‖²/γ²)` 随 `‖B‖` **增大而变小** —— 跨块耦合**只会削弱**（绝不会加强）任何下界。⇒ 即使 `B ≠ 0` 也不给所需方向。
- **判：`[T]`（公式真）+ `[NG]`（作为本靶的机器）**。它与 `L1B-FESHBACH` 判 `MG-META:107` 的那条同构：**归约 = `H1`**（那里），**归约 = 中性隙**（这里）。

### 2.4 直和 ⇒ 独立：两扇区自由度的**精确**见证（不是"没有理由"，是有理由）

- **一侧自由（中性可任意降、带电不动）**：`[T]`，`SS-SECTOR` 引理 D1（`:127–130`：`D_ch(T⊗N) = D_ch(T)`，三种读数逐字不变）+ 引理 D2（`:131–133`：`H_{T⊗N} = H_T⊗1 + 1⊗H_N` ⇒ `m_n(T⊗N) = min(m_n(T), m_n(N))`，`m_n(N) = 0` 可实现）。⇒ **`D_ch` 一个比特不变，`m_n` 从 `m_n(T)` 连续扫到 `0`**（`SS-SECTOR §4[D]`：`m₀ = 0, 0.5, 1, 1.5` 时中性阈值 `2m_lat = 0, 0.199917, 1.924847, 2.666667`，带电数据逐位相同）。

  - 数值 `[C]`：`gap_inv/gap_full = 1.0000`（`β = 0.25, 0.5, 1, 2.5, 4, 8`，每点差 `< 1e−14`）；`U(1)` 对照 `1.4168 / 0.8066 / 0.2679 / 0.1467`，比值同样 `1`（`R1-BRIDGE.md:179–181`）。

### 2.5 "外部"候选：求和规则 / 热力学恒等式能不能给关系？——**引理 SUM**

任务说：若可分解 ⇒ 联合约束只能来自外部（求和规则/热力学恒等式）。**逐条判，两条都死在类型上。**

> **引理 SUM（求和规则只钉 `max`，即钉"最弱扇区"）`[T]`.**
> 设 `Z(N_t) = Σ_α Z_α(N_t)`，`Z_α ≥ 0`，各扇区由 `T_α` 生成（`Z_α = tr T_α^{N_t}`，`λ_α := ‖T_α‖`）。则
> (i) 每一个求和规则/热力学恒等式只约束**和**（`Z`、`∂_β log Z = ⟨plaquette⟩`、…）；
> (ii) `N_t → ∞` 时 `Z_α ≍ λ_α^{N_t}`（PF/谱半径支配），故和只钉住 **`max_α λ_α`**；
> (iii) `max_α λ_α = ‖T|_{Ω^⊥}‖ = e^{−am}` ⇒ **求和规则钉住的正是"最弱扇区"的隙，即 Clay 靶本身**；
> (iv) 对**单个**扇区它只给 `λ_α ≤ max_α λ_α`，即 `m_α ≥ m` —— 与 §2.2 推论 3 的恒真式**同一个**。
> *证明*：逐条为谱半径的定义 + 有限扇区数的 `max` 交换。∎

**推论（本小节的判决）**：
1. 2D 的求和规则 `Σ_j d_j² c_j(β) = e^{2β}` **确实**给了关系 —— 但它**不是**"和 → `min`"的转换，它是 **Peter–Weyl 完备性** `Σ_R d_R χ_R(U) = δ(U)`（群恒等式）在两扇区上的**同一个乘子族**；它之所以能"给关系"，恰恰因为它给的是**同一个函数**（符号），不是"约束了一个和"。⇒ **"外部求和规则"这条路的成功案例，逐字是 §2.4 的中心算子案例，不是新的机器。**
2. **热力学恒等式一律只给"和/平均"**，而隙是 `inf`/`min` 型对象。**"和"与"inf"是两种类型**，与 `B01-RP.md:12`「类型不匹配，不是松紧问题」是同一条（那里是"符号 vs 大小"，这里是"和 vs 下确界"）。
3. ⇒ **任务给的两条外部候选（求和规则 / 热力学恒等式）都不成立**：一条只在 2D 的特殊结构下退化成"共享符号"，另一条类型不对。

### 3.2 为什么 `‖T‖` 的整体界帮不上：唯一可能的 `f` 是常数

设想要 `λ_n = f(λ_c)`。结构给的约束是 `λ_n, λ_c ∈ [0,1]`（O1O2 的乘积区间）。
- 若 `f` 非平凡且只由 O1O2 推得，则 `f` 必须满足 `f([0,1]) ⊂ [0,1]`，**这是 `f` 的唯一约束** ⇒ 任何单调 `f: [0,1]→[0,1]` 与 O1O2 相容。
- 要**排除**某个 `f`，必须再加一条不等式；`[T]` 库里除 O1–O7 外**没有第八条**（§3.1 是穷举：R1–R5 定量输出只有"`1`"与"`0`"，`B01-RP.md:32` 逐字）。
- ⇒ **结构可推出的 `f` 只有 `f ≡ 1`（即 `m_n ≥ 0`）**，而 `f ≡ 1` 逐字就是 RP 的全部定量内容（`B01-RP.md:12`、`:47`），已被 2D `λ`-族一票否决（`B01-RP.md:73–74`：`m(λ) = 3λ/4` 从 `0` 跑到 `3.75`，RP 恒真）。
- ⇒ **§3 的答案：没有。** 且失败的方式与 RP 失败的方式**逐字相同**（同一个闭环）。

### 3.3 ★方向半空间：结构**只能**给"`m_n` 的上界"（本路主结果）`[T]`

> **命题 GT（方向的半空间）.**
> 设 `𝓒` 是满足 R1–R4 且对**中性装饰** `T ↦ T ⊗ N`（`N` 中性、无规范场、无 1-形式荷、唯一真空、真空能归零）**封闭**的理论类。则
> (i) `D_ch(T⊗N) = D_ch(T)`（`SS-SECTOR.md:127–130`，`[T]`）；
> (ii) `m_n(T⊗N) = min(m_n(T), m_n(N))`，且 `m_n(N)` 在 `(0,∞)` 上可连续扫、可取 `0`（`SS-SECTOR.md:131–133` + `§4[D]` 数值 `[V]`）；
> (iii) ⇒ **任何在 `𝓒` 上成立、形如 `m_n(T) ≥ F(D_ch(T))` 的陈述，必使 `F ≤ 0` 处处成立**；
> (iv) ⇒ 反之，形如 `m_n(T) ≤ Φ(D_ch(T))` 的陈述**不受此限**。
> *证明.* 取 `T₀`，其装饰 `T₀⊗N` 有同一 `D_ch` ⇒ `F(D_ch(T₀)) ≤ m_n(T₀⊗N) = min(m_n(T₀), m_n(N))`；令 `m_n(N) ↓ 0` 得 `F(D_ch(T₀)) ≤ 0`。∎

**与 `SS-SECTOR` 的关系（必须写清，不许夸大）**：命题 GT **不是新定理**，它逐字是定理 SS（`SS-SECTOR.md:278–282`）的**转移矩阵语言转录**：那里的 `F` 是任意集合论函数、被装饰杀掉；这里的 `T`-侧改写把"结构"这个词显式化了 —— **结构 = R1–R4 + 装饰封闭**，而 R1–R4 **逐条对 `T⊗N` 保持**（RP 的乘积仍 RP；1-形式对称不作用于 `N` 的恒等算子；Wilson 环因子化，`SS-SECTOR.md:42–43` 逐字）。
⇒ **本文件对"OS 结构有没有关系"的回答因此是双重的**：
1. **横向**：`T` 是直和 ⇒ 两块独立（§2）。
