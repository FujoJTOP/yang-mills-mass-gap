## §2 判（逐条，为什么、见证在哪）

1. **I1 的部分成功是真的、但只到窗平均。** `NN11-KAPPA:1,11` 的 `∂_β⟨q̄⟩=−κχ_q`、`κ=6` 是**逐 β 等式**，积分给 `∫𝒮_q dβ=(1/6)Δ⟨q̄⟩≤1/6`（`NN11:20`，距实读 `0.0906` 弱 `92×`）。`[T]` 只覆盖"形式 + 常数"，**点值 `[NG]`**：缺 `⟨Q³⟩_c≥0`（`II2-OB:0.4`），实测峰处反号 —— 这一格不是"没算"，是"算出来是负的"。**下一手**：只攻点值化（§3）。
2. **I2 绕不过 ss2，因为维数与重标对易。** `s↦ts` 不改变 `d`，所以任何只吃 `d=4` 的论证仍在 ss2 的封闭类里；更硬的反面：`d=4` 的自由场 `χ_q` **收敛**（`II5:0.6`）⇒ 维数给的是"约束的地址"，不是约束。**下一手**：把 `d=4` 降为记账项（`κ=6`、`|z|^{-8}`），不再当输入。
3. **I3 的逃逸是真的、桥是断的。** `c_j(β)>0` + 全 CG 重数 = 1 给 `d=2` 的 rep-空间 1D 闭合（Migdal 精确）`[T]`；`d=4` 的同一展开要处理 6j 的符号，而连续 `SU(N)` 的 Weingarten 有号 ⇒ Lee–Yang 类定理缺席（`CONTINUUM-CP:3`）⇒ `[NG]`。**下一手**：若要救，只能找"符号在 `j≤1/2` 领头层不出现"的**单 plaquette** 结构，但那正是 I1 的局部格（0.3 判死）。
4. **I4 不算新输入。** RP 在 q-道上的全部产出就是 `ν≥0`（`II6:0.3`），逐字是测度公理；`e^{−√R}` 证明它连指数衰减都不给（`H1B-FIVE:33`）；transfer 的 `k=0` 隙按 `Q6 §2.2` 的 Rayleigh 只管 `gap⇒H1` 一个方向。**下一手**：RP 只当滤器（拒收负谱），不当机床。

**类级判词（0.3）的取舍**：I1/I3 都**绕过** ss2（所以 ss2 不是本轮的墙），但都死在**局部→整体**这一步；I2/I4 连 ss2 都绕不过。⇒ 交付"这一类必败"，见证两条（测度侧 `Unif`、作用量侧 Savvidy），并保留 I1 的窗平均作唯一 `[T]` 正面产物。

## §3 最可能的一条：I1 的「点值化」用法（前 3 步）

**选择理由**：三条里只有 I1 有**逐 β 的精确等式**（不是不等式、不是公理），且它的缺件已被语料点名到一个**具体的符号**（`⟨Q³⟩_c≥0`）；代价已知（`92×` 弱、峰处反号），所以前 3 步能在很低成本下判生死。

- **步 1（零成本，记账）**：把靶**逐字**改写成 `χ_q(2.5) ≤ C ⟺ −∂_β⟨q̄⟩|_{2.5} ≤ 6C`，并把 `κ=6`、`∫𝒮_q dβ≤1/6`、实读 `0.0906/0.0325` 两值并列写进台账。**产出**：确定 `C` 的量级与两读数的互斥（0.5）。**判据**：若 `6C` 落在两读数之间 ⇒ 先裁决 0.5，不进入步 2。
- **步 2（核心，零新 MC）**：把 `−∂_β⟨q̄⟩` 用 `SU(2)` 的**精确单 link 积分**化成**一维、有界、显式**的角变量函数：条件律 = vMF（`|h|≤6β=15`，`θ∈[0,π]`），得 `g(θ,h)`，于是点值界 = 一条**逐 link 的 `E[g]≤6C`**。**判据**：若 `E[g]` 的上界只能经 Popoviciu（`36`）或 `π²N` 回到 `∝V` ⇒ 立刻判 I1 `[NG]`（残差 = "逐 link → 整体"的求和，具名），不再往下投。
- **步 3（酸测 + 预注册）**：同一不等式在 β=0 Haar 上必须给**精确** `3.7198`（`D6 §3.1`），在自由无质量场上必须**只剩 `|z|^{-8}` 的收敛**（`II5:0.6`）——两格都过才算机床；若它在自由场上产出比 `0.04` 更紧的"界"，按 0.2 判空转。**下一手**：步 3 过 ⇒ 投点值化的符号（`⟨Q³⟩_c`）；不过 ⇒ 转 I3 的 `j≤1/2` 单 plaquette 结构，且先过 0.3 两条见证。
