### §1.3 一条必须记的勘误：`REPORT.md:281` 的严格性例**不成立**

**逐字**（`glue-b-blocking/REPORT.md:281`）：

> "**是 `≥`，不是 `=`（严格性可行）。** `H = diag(1,3)`，`H_a = diag(1−ε_a, 3)`，`ε_a ∈ [0, 1/2]` 有一列 `→ 1/2`。则 `‖H_a − H‖ → 0`（强预解必成立），而 `liminf Δ_a = 1/2 < 1 = Δ_cont`。"

**三处不合**（逐条可复核，成本 0）：

1. **`‖H_a − H‖ = ε_a`**。若 `ε_a → 1/2`（哪怕只在稀疏子列上），则 `‖H_a − H‖ ↛ 0`。⇒ **例子里那句"`‖H_a − H‖ → 0`"是假的**。
2. **强预解也不成立**。强预解收敛 ⇒（引理 A）`limsup Δ_a ≤ Δ_cont = 1` 尚可，但**同时**由"`∀λ∈σ(H)` 都是 `σ(H_a)` 的极限点"必有 `σ(H_a)` 在 `1` 的 `ε`-邻域内非空；而例子给 `σ(H_a) = {1−ε_a, 3}`，`ε_a = 1/2` 时距 `σ(H) = {1,3}` 为 `1/2`。⇒ **引理 A 直接排除该例**。
3. **该例里 `ker H = {0}`**，`0` 不是真空能级，`Δ_cont = inf σ(H) = 1` 是"整个谱底"而非"真空之上的第一激发"。⇒ 它与本项目 `Δ := inf{λ∈σ(H): λ>0}`（真空在 0）**不是同一个对象**（对照 `REPORT:267–272` 的设定：`T_a 1 = 1` ⇒ 真空本征值恒为 0）。

**性质**：这是一处**例子的错**，不是**结论的错**。"是 `≥` 不是 `=`"**仍然成立**，但见证要换（§2.6 的软模族）。同一坏见证被 `GM1-KATO.md:21,218` 与 `docs/FINDING-01-AIM-DIRECTION.md:55` 的下游判词引用，**下游结论（`Clay ⇏ (Q)`）不受影响**（软模族同样否掉 `(Q)`）。

## §2 两个不等式的量词核对与夹逼

### §2.1 记号（照抄 `REPORT:267–272`，不另立）

```
H_a := −(1/a)·log T_a   于 1^⊥（谱演算；log 0 := +∞）;  0 ≤ T_a ≤ 1,  T_a 1 = 1
Δ_a   := inf{ λ ∈ σ(H_a) : λ > 0 }        （空集时 := +∞）
Δ_cont := inf{ λ ∈ σ(H)   : λ > 0 }
SPEC-RES : H_a → H 强预解收敛（Reed–Simon I Thm VIII.24(b) 的适用前提）
```

本轮**只用** `SPEC-RES`，不消费紧性、Minlos、`UVS`、RP、PF、`H_a ≥ 0`。`ℋ_a ≇ ℋ` 的识别 `ι_a` 是 `SPEC-RES` 内含的（`BRK9:12`、`A2-scheme-match:14`），本文件不额外消费。

### §2.2 引理 A（**新，本路唯一可证的一支**）`[T]`（条件 `SPEC-RES`）

> **引理 A.** 设 `H_a, H` 自伴、下有界、有共同表示空间（或经 `ι_a` 识别），`H_a → H` 强预解收敛，且 `Δ_cont > 0`（允许 `+∞`）。则
> ```
> limsup_{a→0} Δ_a  ≤  Δ_cont .
> ```

*证（4 行 + 2 行谱演算，就地自证，不引未核正文）。*
取 `0 < ε < Δ_cont` 与 `f ∈ C_c((Δ_cont−ε, Δ_cont+ε))`，`0 ≤ f ≤ 1`，`f(Δ_cont) = 1`。
**(i)** `Δ_cont ∈ σ(H)`（`σ(H)` 闭、`Δ_cont` 是其正部分的下确界）⇒ `‖f(H)‖ ≥ f(Δ_cont) = 1` ⇒ `f(H) ≠ 0`。
**(ii)** 强预解收敛 ⇒ `f(H_a) → f(H)` 强（`f` 有界连续；`BRK9:9` 的 Trotter–Kato 同一族等价）。若某 `a` 有 `f(H_a) = 0`，则对一切 `ψ`，`f(H)ψ = lim_a f(H_a)ψ = 0`，与 (i) 矛盾 ⇒ **`f(H_a) ≠ 0`**。
**(iii)** `f(H_a) ≠ 0` ⇒ `σ(H_a) ∩ supp f ≠ ∅`；取 `λ_a ∈ σ(H_a) ∩ supp f`。`ε < Δ_cont` ⇒ `λ_a > 0` ⇒ 按定义 `Δ_a ≤ λ_a < Δ_cont + ε`。
**(iv)** `ε` 任意 ⇒ `∀ε>0 ∃a₀ ∀a≤a₀ : Δ_a ≤ Δ_cont + ε`，即 `limsup Δ_a ≤ Δ_cont`。∎

**注 1（谁没被用）**：`H_a ≥ 0` 没被用（`(iii)` 只需 `λ_a > 0`，由 `ε < Δ_cont` 保证）；紧性/Minlos/RP/PF 全没被用。⇒ **这不是"机器"给的，是谱演算给的。**

## §3 收敛定理

### §3.1 定理 C（等价链）`[T]`

### §4.4 本路的夹逼"踩了 `W` 哪一步"？——精确回答
