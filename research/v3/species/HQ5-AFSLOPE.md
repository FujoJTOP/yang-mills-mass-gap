### §1.2 标准形（把 `O` 补齐；这一步不是修辞）

```
(AFS_≤)   ∃c>0 ∃C<∞ ∃β₀ ∀L<∞ ∀β≥β₀:      c·x(β) − C·x(β)²  ≤  Δ^lat(L,β)
(AFS±)    ∃c>0 ∃C<∞ ∃β₀ ∀L<∞ ∀β≥β₀:     |Δ^lat(L,β) − c·x(β)|  ≤  C·x(β)²
```

- **量词顺序承重**：`∃C` 必须在 `∀L` 之前。若 `C = C(L)`，则 `AFS_≤` 对每个固定 `L` 只给 `liminf_β Δ^lat/x ≥ c`，而 `β` 的生效点 `β(L)` 可随 `L` 跑掉 ⇒ **`(B)` 的 `∀L` 拿不到**（`CLAY:283–287` 的 (5.4) 正是这一层）。⇒ `HZ7-B:23` 必须按 `HZ7-B:29` 的量化读，否则它不是 (B) 的充分条件。`[T]`
- **`∃c` 自由的后果**：见 §3.1 —— 这正是字面形对 (B) 只是推论的原因。
- **方案协变**：`Λ ↦ θΛ` 给 `x ↦ θx`，则 `c ↦ c/θ`、`C ↦ C/θ²`，两式的**真值不变**；故 `AFS` 是 scheme-无关的**陈述**，而 `(c,C)` 不是 scheme-无关的**数**。`[T]`（一行代入）

### §1.3 四种等价形（含等价性证明）

**(F1) 比值形.** `R ≥ c − C·x`（单侧）／`|R − c| ≤ C·x`（两侧）。除以 `x>0`，恒等。`[T]`

**(F2) 差值形.** `Δ^lat − c·x ≥ −C·x²`（单侧）／`|Δ^lat − c·x| ≤ C·x²`（两侧）。与 (F1) 同式异写。`[T]`

**(F3) 一次差形（严格形式，取代"斜率"）.** 对一切 `β₂ > β₁ ≥ β₀`：

```
Δ^lat(β₂) − Δ^lat(β₁)  ≥  c·[x(β₂) − x(β₁)]  −  C·[x(β₂)² + x(β₁)²]
```

*等价性.* `(⇒)` 令 `e := Δ^lat − cx`，则 `|e| ≤ Cx²` 逐点 ⇒ 相减得 `e₂ − e₁ ≥ −Cx₂² − Cx₁²`。`(⇐)` 取 `β₁ = β₀` 一次差 + 在 `β₀` 的逐点式，得 `e(β) ≥ −2C·x(β)²`（把 `C` 换成 `2C`）。⇒ **两向只差常数 `C → 2C`**，故 (F3) 不是弱化。`[T]`

**(F4) 对数斜率形（形式；严格版须用 (F3)）.**

```
d lnΔ^lat/dβ = −κ(β) + O(aΛ)      ⟺      d lnR/dβ = O(aΛ)
```

*推导（在 (F2) 下）.* `e = Δ^lat − cx`，`|e| ≤ Cx²` ⇒ `|e′| ≤ 2Cx|x′| = 2Cκx²`；故

```
d lnΔ^lat/dβ + κ = [−cκx + e′]/[cx + e] + κ = O(Cκx/c)                                  (F4-1)
```

⇒ `d lnR/dβ = d lnΔ^lat/dβ + κ = O(Cκx/c)`，与 (F4) 同阶。**逆命题须 `λ₂(T_a)` 对 `β` 可微**：`Δ^lat = −log‖T_a|_{Ω^⊥}‖` 是算子范数（`max`）的 log，跨本征值交叉处只有 Lipschitz，**不可微性是结构性的**（`CLAY:157–166` 只给等式，不给光滑性）。⇒ `[NG]`：**(F4) 只能当形式用；严格陈述一律落 (F3)**。

**(F5) 转移矩阵形（与 (6.3) 同格）.** `λ₂(T_a) ≤ exp(−c·x + C·x²)`，两侧形为 `|log λ₂ + c·x| ≤ C·x²`。与 `CLAY-PROOF-CHAIN.html:313–319` 的 `(B) ⟺ ‖T_a|_{Ω^⊥}‖ ≤ exp(−δ aΛ)` 逐字同构（取指数）。`[T]`
