## §2 `H3` 熵计数

### 2.1 逐字、由来

### 2.2 精确命题：`GV2:76` 与 `BianchiLemma.md:39` **不是同一个对象**

| | `BianchiLemma.md:39`（被引的） | `GV2:76`（要用的） |
|---|---|---|
| 对象 | **自由边界**连通 2-链（每 site） | **固定边界** `∂C=∂C₀` 的装饰曲面 |
| 计数 | `N(n)`，面积恰为 `n` | `#{C : ∂C=∂C₀, \|C\|=\|C₀\|+j}`，`j≥0` |
| 量词 | 无 `\|C₀\|` 依赖（自由对象没有 `C₀`） | **对一切 `\|C₀\|` 一致** |
| 常数 | `γ_ent`（可依赖计数归一） | `γ`，**且前置因子必须 = 1** |
| `j=0` | 不涉及 | **`j=0` 的计数必须 ≤ 1**（见下） |

**两条被 `GV2:76` 隐去、但 AS 的常数 `½` 需要的细节：**

1. **`j=0` 格：** `#{C: ∂C=∂C₀, |C|=|C₀|} = 1` 等价于"每个边界有**唯一**极小面"。若并列 ≥2，则 `e^{γ·0}=1` 立刻被违反。**修补：** 把 `A₀` 定义成 `j=0` 的**总和** `A₀ := Σ_{|C|=|C₀|}|w(C)|`，并把 `(iii)` 只对 `j ≥ 1` 要求 —— 这样 `j=0` 不进熵计数，AS 的代数（`GV2:83`）原样成立。**`GV2:75` 的括号（"最小曲面 `C₀` 自身的质量"）默认了唯一性，须改写。**
2. **零前置因子（本文件最硬的一条量化点）：** AS 的结论是 `|Σw| ≥ A₀(1 − ρ/(1−ρ))`，`ρ ≤ 1/3 ⇒ 1 − ρ/(1−ρ) ≥ 1/2`，**等号在 `ρ=1/3` 取到，一点余量都没有**。所以 `(iii)` 若带任何 `|C₀|`-依赖的前置因子 `P>1`，结论退化为 `A₀(1 − Pρ/(1−ρ))`，需要 `ρ ≤ 1/(2P+1)`，即 `c₀q ≥ γ + ln(2P+1)`：`P=2` 要 `ln5=1.609`，比 `ln3=1.099` 多 **`0.5108`** —— 而 CPB-S 窗相对 `H4` 的全部余量恰好是 **`0.5`**（那个 `κ=1/2`）⇒ **差 `0.0108`，`P=2` 刚好把窗吃穿。** `(iii)` 的"无前置因子"不是形式主义，是承重的。

**⇒ `H3` 的干净命题（建议写法，不改文件）：**
```
(H3)  ∃ γ_ent<∞ ∀ 边界 ∂C₀ ∀ |C₀| ∀ j≥1 :  #{C : ∂C=∂C₀, |C|=|C₀|+j} ≤ e^{γ_ent j}
      （无前置因子；j=0 由 A₀ 取总和处理）
```

### 2.3 判：存在性 `[T]`（本轮给显式常数）+ 数值 `[NG]`

**(a) 存在性 —— `[T]`（新，显式常数，粗但有效）。** 4D plaquette 图 `Δ=20`（`GV2:114`）。含 `p₀` 的连通片集 `S`，取生成树后做 DFS：至多 `2j` 步、每步 ≤ `Δ=20` 个邻居 ⇒ 走法 ≤ `20^{2j} = 400^j`，每个 `S` 至少被一种走法生成 ⇒


### 2.4 仓内自己的 `n≤6` 精确计数：`γ ≥ 2.632`（自由对象），不是 `1`

```
count_n  : 1        20       458       11 132     280 175     7 218 768
```

**两支都不支持 `1`。**

**⇒ 等级：`H3` = `[T]`（存在性，自由对象，显式 `γ≤5.991`）+ `[O]`（固定边界无前置因子版的存在性）+ `[NG]`（数值 `γ_ent=1`）。** 对 `GV2` 的用法而言，**数值那一格是断的**。
