## §1 · 变分上界：`m ≥ ?` —— **无输出，且方向是定义级反的**

### 1.1 为什么"变分"必然只给上界（`[T]`）

`m` 的变分身份是 Poincaré 常数（`U09-M6.md:15,158`；与 `U05-DIRECT.md §0 #5` 的 `λ₁` 同一对象，差因子 2）：

```
m = Λ(ρ,∇) := inf_{f} ½∫|∇f|²dρ / Var_ρ(f)          [T]
```

`inf` 的定义 ⇒ 对**任意**试探 `f`：`m ≤ R(f)`。Rayleigh–Ritz / min–max / Cauchy 交错 / GEVP / Temple–Weinstein 全部同向（`WA-ALIGNMENT.md:206–207`、`MG-META.md:53 D1`、`U05-DIRECT.md:74`）。仓内已有定理性结论：

> **RB-2（方向定理）`[T]`**：变分只给本征值**上界**，`sup_V ν_k = ∞`；下界只能来自 `L ≥ L₀`（形式比较）——`RB-RATIO-BOUND.md:170–175`、`:34`、`:461`。

⇒ **§1 的问题形式 `m ≥ ?` 在这条路上无解，不是"技术缺口"。**

### 1.2 对易子/矩版本：`⟨[H,O]⟩` 型界（本轮显式写出，`[T]` 代数）

取规范不变局域 `O`、`⟨Ω|O|Ω⟩=0`、`ν_O` 为其 KL 谱测度（`f₁²=ν_O({E₁})=|⟨Ω|O|𝔾⟩|²`，`ch05-theorems.tex:32,52,60`；`V02 §1`）。定义

```
M₀ := ∫dν = Var_Ω(O) = C(0) ,     M₁ := ∫E dν = ½⟨Ω|[O,[H,O]]|Ω⟩ .
```

则（全部 `[T]`，两行代数）

```
m = inf supp ν ≤ M₁/M₀            (测度均值 ≥ 支撑下端)
m ≤ M₁/f₁²                        (M₁ ≥ E₁·f₁²，**前提 f₁²>0**)
```

两条都是**上界**。第二条正是"用对易子给界"的正确形状，但它**要 `f₁²>0` 才成立**，而 `f₁²>0` 就是要搬的东西 ⇒ **循环**（与 `V02 §3[C]` 的相位陷阱同一死法）。而"有限个矩不能下界 `inf supp`"已是定理性判死（`V01-I2S.md:108`：`R2:130–151` 逐字 `[NG]`；thin-gap 把同一 `(M₀,M₁,M₂)` 从 `9` 打到 `0.01`）。

### 1.3 唯一合法的下界机器（都不是"变分族"）

| 装置 | 机理 | 在 4D YM 可用性 |
|---|---|---|
| 形式比较 `L ≥ L₀` | 二次型逐点占优 + `D(L)⊆D(L₀)` | **无对照算子**（4D 没有已知隙的可比模型）⇒ `[NG]` |

| 指标/谱流、Sturm 型 | 计数/比较 | 已有的 `T15`/`DT` 只给"有/无"，不给常数 ⇒ 与地板无关 |

### 2.1 已证/标准的对偶清单（逐条标"能不能给 4D `SU(N)` 的 `m`"）

### 2.2 ★ 单 plaquette 试金石：Eguchi–Kawai 正是那条"落到无定义"的路

大 `N` 的**精确**约化（Eguchi–Kawai 1982：`d` 维环面上的大 `N` 格点规范理论 ↔ 带 twist 的**单点**矩阵模型，在 planar/loop 方程层面）把 4D 的**时间方向压成一个点**。而 `m` 的定义需要沿时间方向的转移矩阵 ⇒ 约化后**没有 `m`**。这正是四模型试金石第 4 项（"单 plaquette ⇒ 无定义"）：**唯一的精确对偶型约化，落的点恰好是谱无定义的点** ⇒ 对偶路线在试金石上被这一项直接判死（`[NG]`；标签 `[B]`，EK 原文未逐字核）。

**推论（诚实）**：对偶路线若要在 4D 有用，必须给出一个**保留时间方向**的对偶——即对偶侧也要有 Hamiltonian 与谱。现存所有候选（string dual）连"对偶对象是否良定义"都未证，遑论谱。

### 2.3 `μ5` 的反向问题（承接任务第 1 条的括注）

`μ5` 已判：`m>0 ⇒ σ>0`（Chatterjee 2021，CMP，`arXiv:2006.16229` / DOI `10.1007/s00220-021-04086-y`，`[A]` 摘要逐字）；**反向 `σ>0 ⇒ m>0` 无定理**，且缺整层 `L4`（面积律扇区 → 局域算符扇区），并由 Lüscher 项 `O(1/R)` 说明面积律扇区**自带无隙方向**（`MU5-SIGMA-M.md:15,45,84`）。⇒ 即便搬到 `β=2.5` 的 `σ>0`，也换不出 `m>0`；何况 `σ(2.5)>0` 本身也只是 `[M]`。

## §4 · ★ 核心：`m(β)` 对 `β` 单调吗 —— **不递增，是递减；所需不等式为假**

### 4.1 `[T]` 端点判决：`m` 不可能是非降的

固定有限 `L,a`、Wilson 作用、柱面 `𝒞_L`。`β=0` 时 Boltzmann 权 `≡1` ⇒ 转移矩阵

```
T(β=0) = |1⟩⟨1|        （秩一）
⇒ spec T = {1,0,0,…} ⇒ E₁ = −ln λ₂ = +∞ ⇒ m(0⁺) = +∞ .
```

（仓内独立复核：`ACID-BD.md:19,38,50`——"`β=0` 时 `S_W≡0` ⇒ iid Haar ⇒ `ξ=0`、`m=∞`；`T` 秩一 ⇒ `λ₂/λ₁=0`"；`LOOP-RUNBOOK.md:738` 同判。）

而 `m(2.5)` 有限（`[M]`，`O(1)` 量级）。于是

```
m(0⁺) = +∞ > m(2.5)   ⇒   m 在 [0⁺,2.5] 上至少有一处严格下降
⇒ "m(β) 递增/非降" 为假。                                   [T]
```

**这一步不需要任何数值、任何模型**：它是秩一 + 有限的直接比较。任务设想的链条"`m` 递增 ⇒ `m(2.5) ≥ m(1/48) > 0`"因此**在第一步就断**。

### 4.2 `[E]` 精确反例：`m(β) = −ln tanh β`（跨 4 个量级严格递减）

`Z₂` 2+1D、`β_s=0`：`T = ∏_l(1+tσ_x)`、`t=e^{−2β}` ⇒ `λ₂/λ₁=(1−t)/(1+t)` ⇒ 闭式

```
m(β) = −ln tanh β    （L-无关；稠密 T 独立复算 |diff| ≤ 4.4e−15）
```

| `β` | 0.01 | 0.05 | 0.10 | 0.25 | 0.50 | 1.00 | 2.00 | 4.00 |
|---|---|---|---|---|---|---|---|---|
| `m` | 4.6052 | 2.9966 | 2.3059 | 1.4068 | 0.7719 | 0.2723 | 0.0366 | 6.71e−4 |

（数表逐字取自 `ACID-BD.md:43–50`，本轮未重跑。）两端：`β→0` 时 `m→+∞`（`T` 秩一）；`β→∞` 时 `m ≈ 2e^{−2β} → 0`。**严格递减，且 `m>0` 处处。**

⇒ "格点规范理论的 `m(β)` 随 `β` 递增"作为**结构性事实**是假的；自然方向是递减。

### 4.3 `[E]` 2D YM：`m ∝ g²N ∝ 1/β` —— 同样严格递减，且 `f₁²≡0`

2D 纯 YM 精确解：谱 `∝ g²N`（`MU5-SIGMA-M.md:113`；Migdal/Witten/Gross）⇒ 在 `β=2N/g²` 下 `m(β) = c/β`，**严格递减**。同时它 `tr F²=H` 守恒 + 特征标正交 ⇒ **`f₁²≡0`** 而 `m>0`（`T23-TEMPLATE.md:95–98`、`V02 §5(c)`）。
⇒ 2D YM 是"**隙正、单调递减、残数为零**"的精确模型：它同时否证"递增单调性"与"由 `f₁²` 推隙"。

### 4.4 `[C]`/`[M]` 4D：两端同向递减，所需不等式为假

| `β` | `m a` | 依据 |
|---|---|---|

### 4.5 ★ 四模型试金石（`m(β)`-单调性路线）

设工具 `K` = "`m` 单调增 + `m(β₁)>0` ⇒ `m(2.5)>0`"。

| 模型 | 应给 | `K` 给 | 判 |
|---|---|---|---|

| **2D YM（`m>0`、`G″=0`、`f₁²≡0`）** | **`>0`** | **给出"无结论/上界"**：`m` 递减 ⇒ 只能 `m(2.5) ≤ m(β₁)`，**方向反** | **★ 失败（唯一诊断项）** |

**诊断项恰是 2D YM**：那里隙**正**、且**精确**、且**递减**。任何"递增⇒搬运"的工具在唯一能核对正性的模型上给错方向。⇒ **`K` 不过试金石。**

### 4.6 为什么"单调"这个仪器本身是错的（结构性）

设 `m a = a·m_phys`。若存在**一致地板** `m(β) ≥ c > 0` 对所有 `β`（含 `∞`），则 `m_phys = m/a ≥ c/a → ∞` ⇒ 连续极限必然是**质量无穷/平凡**的理论。⇒ **全局地板与"存在非平凡连续极限"不相容**；地板只能**窗口局部**（`[β₁,2.5]`）。
而单调性无法产生窗口局部地板：递减趋势天然把 `β₁` 的大值搬成 `2.5` 的**上界**。⇒ 单调性**结构上**是反向仪器（与 `BN-RESIDUAL.md:19` 在 `L` 方向上的判死同型：`μ₁(L)` 严格非增，"加一层"式的单调性方向反）。
**真正需要的量是 `inf_{β∈[β₁,2.5]} m(β) > 0`**——即 `H1`/一致地板，不是任何单调量。

## §5 · 判死线逐条

### (a) "若 `m(β)` 单调性可证 ⇒ 搬运解决" —— **前提为假，不成**
- `[T]`：非降已在 `β→0` 端点被否（§4.1）。
- `[E]`：两个精确模型（`Z₂` 2+1D、2D YM）都**递减**。
- `[C]`/`[M]`：4D 两端同向递减（§4.4）。
⇒ **不存在"可证的递增单调性"；这条最直接的路是错的，不是缺证明。**

### (b) "若 `m(β)` 非单调（有反例）⇒ 给反例" —— **成立，且比非单调更强：方向反**
