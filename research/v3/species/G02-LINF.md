## 2. 核心：两条轴**结构不对称**（回答"这与 `L` 有关吗"）

题面的物理判断成立，但还不够利：`L` 与 `a` 不只是"两件事"，它们是**两种不同类型的量词**。

| | `L` | `a` |
|---|---|---|
| 固定其余参数时能否自由变动 | **能**（固定 `β,a` 变体积） | **不能**：`u=c_f(β)/N` 无 `a`，`a` 只是**单位**（`F05 §1` #1,#12；`C3-UNIQUENESS:33`：`ma=f(β,L/a,θ;N)`） |
| 要非平凡，必须动什么 | 只动 `L` | 必须动 `β`（沿 `β(a)`，因 AF） |
| 要求的实质 | `∀` 一个**自由参数** | **沿一条曲线**取 `∀` |
| 代价 | 低：机制是**逐面局部**的（KP 判据逐 plaquette，与格点数/形状无关 ⇒ `N_s→∞` 下一致，`F05 §2.3` 引 `P3-FOURWALL:106`） | 高：每个点上是**另一个理论**（不同 cutoff），且必须换到 `Λ` 单位（§3.2） |
| 语料的现状 | `inf_L ≥ ¼(2N)^{-2}` `[T]`（`Z01:203–204`；`F05 §2`） | 矩形 `a`-一致：**平凡**（`F05 §1`）；轨迹 `a`-一致：**缺**（§3.2） |

**⇒ 一句话**：`L`-一致是"对自由参数的 `∀`"（便宜，且 `I1`/`I2` 已经拿到）；`a`-一致**只能是**"对轨迹参数的 `∀`"（贵，且正是缺件）。**"a-一致被 L-一致蕴含"（`F05 §4.2`）只在 `L/a` 那一支成立——只消掉平凡的那一半，不消掉轨迹。**

## 3. 逐字核 `ch13-machine:27–29`：C5 要一致界还是极限

### 3.1 两种读法都能落进这三段

| 读法 | 第 1 段读成 | 第 3 段读成 | 是否需要 `L→∞` 存在 |
|---|---|---|---|
| **(a) 一致界** | `∃λ ∀L ∀a` | "不许钉死" = 要 `∀` | **不需要**（`inf_L` 就够） |
| **(b) 极限存在** | `∃ \lim_{L→∞,a→0}`，其值 `>0` | "钉死的陈述给不出 Clay" = 必须真取极限 | **需要** |

### 3.2 语料内部先例：**本项目自己最好的陈述已经把 "`L→∞`" 落成 `inf_L`**

`F01-TRANSPORTI2.md:16` 口语说 `I2@2.5` 的"量词是 `L→∞`"；但同一文件 `§1.1` 第 3 条给出的**操作形式**是

```
inf_{L} inf_{β∈[2.3,2.7]} ( Λ★_L(β) − m₁²_L(β) ) ≥ δ > 0    ∧    inf_L m₁²_L ≥ c > 0      [F01 §1.1.3]
```

**是 `inf`，不是 `lim`。** 同理 `F01 §0.5` 把 `I2` 的真缺件写成 `inf_L(m₂(L)²−m₀(L)²)>0`。
⇒ **本语料在需要精确时，一律把"`L→∞`"翻译成 `inf_L > 0`。** 这与 C5 第 3 段的排除式完全一致 ⇒ **支持读 (a)**。

### 3.3 但 `inf_L` 比"极限存在"**更强**，方向不能反

- 局部收敛下，若 `∀L: |⟨O(x)O(0)⟩_{L,c}| ≤ C e^{−m|x|}`，则极限满足同界（§4.1）⇒ **极限的率 ≥ `m`**。
- 反之**不成立**：`inf_L m_L > 0` 不能由"极限存在且 `m_∞>0`"推回（除非有体积单调性）。**`SU(N)` YM 没有 FKG**（`D05-FKG.md:92,213`：紧性障碍 `N=2` 就有），所以**没有**体积单调性可借。
- ⇒ 谁若想"先证极限、再免费得 `L`-一致"，顺序是反的：`L`-一致必须**逐个 `L`** 或**结构性地**（逐面 KP）证。`I1` 走的正是结构性那条。

## 4. `(a)` 读法下的账：`L` 侧已完成，剩 `β(a)` 轨迹

### 4.1 一致界 ⇒ 极限：**传递是易向**（两行 `[T]`，标准，不引外文）

设 KL 测度 `ν`、`C(t)=∫e^{−√s t}dν(s)`（`R2-ISOLATION:79–83`；`KL` 由 RP+OS 给，`Osterwalder–Seiler 1978`）。
若 `C(t) ≤ C₀e^{−mt}` 且 `ν([0,m−ε))>0`，则 `C(t) ≥ ν([0,m−ε))·e^{−√(m−ε)t}` 破坏该界 ⇒ **`inf supp ν ≥ m`**。
局部收敛下两点函数逐点收敛 ⇒ 界**原样传给极限**。**⇒ (b) 的难点不在"界能否传递"，而在"极限是否存在"。**

### 4.2 于是 (a) 读法下 `L` 侧的状态（逐条带等级）

## 7. 三条诚实限定（不许省）
