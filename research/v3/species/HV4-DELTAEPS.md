## §1 「距离」的量纲（只重述，不重推）

```
K := Δ/ε = w₁ − ϑ = δ₁/ε − (1−w₁) = w₁ + (N_eff−3)/2 ,   ϑ:=(s₂−Ē)/ε , δ₁:=Ē−s₁ , ε:=s₂−s₁
(G-4)_{w₀}: δ₁ ≤ (1−w₀)ε  ⟺  K ≤ w₁−w₀  ⟺  ε ≥ δ₁/(1−w₀)      [T]（三形等价，段[5]）；靶 T = {w₁ ≥ w₀}，不含 K
⇒ 距离的计价单位是 (w₁−w₀) 而非 s 的单位：K 无量纲，(G-4) ⟺ K/(w₁−w₀) ≤ 1。
一维性：dK/dε = −δ₁/ε² ≤ 0；K=0 ⟺ ε=ε_max；K=w₁−w₀ ⟺ ε=δ₁/(1−w₀)。∎                    [T]
```

## §4 两个结局各意味着什么

**4.1 `K→0`（固定 `t₀` 上一致地 `K ≤ w₁−w₀`）** — **`[T]`**（结构）
1. `K=0 ⟺ Δ=0 ⟺ supp ν_w={s₁,s₂}`：**底部带恰好两能级**，`N_eff=3−2w₁`。
2. 该类上 `(G-4)_{w₀} ⟺ 靶`**逐字重合** ⇒ 预算形退化成换名（ge3 换名格），作台阶的内容为 0。
3. **但它把 YM 归进见证类的形状**：`HN1`（`½δ+½δ`）、`M6`（单原子，`w₁=0.5` 而 `m=0`）、薄原子两点族都 `Δ=0` ⇒ 这一支**不能**把靶推近隙（M6 上靶真而隙假）。
4. 它**可证伪**：`K=0` 预测 `s₂=(Ē−w₁s₁)/(1−w₁)=3.03–3.17`（`1.77–2.05 s₁`，随 `s₁` 取端）。**下一手**：写进 `④` 的 `L`-序列判据（`HZ6 §5.4-1`）；测出 `s₂` 低于该区间即否掉这一支。

**4.2 `K ≥ c>0`** — **`[T]`**（结构）/ **`[NG]`**（作归约）
1. `(G-4)_{w₀}` ⟺ 「靶 + 常数抬高 `c`」：可满足性要求 `c ≤ w₁−w₀` ⇒ **可证裕度封顶 `w₀ ≤ w₁−c`**。
2. 用实测 `w₁=0.3354`（广延载体）：`c ≥ 0.34` ⇒ 对每个 `w₀>0` 都不成立（该形在 YM 上**空**）；操作裕度 `0.2–0.3` 只容 `c ≤ 0.035–0.135`。
3. ⇒ 它是**严格更强的充分条件**，不是入口，`c` 就是价码。**下一手**：把「尾部预算」从「缺的一步」改登记为「**必须作为输入的界**」（同 `HS-GAP-2.md:112`）。

**4.3 两支互斥而不独立**：`K` 递减于 `ε` ⇒「`K` 小」与「`ε` 大」是同一件事。**不许**同时主张「预算好过」与「距离→0」；`(G-4)` 的裕度与 `K` 的价码是**同一根轴的两端**。**下一手**：报 `(w₀, ε, K)` 三点，缺一即退回。

**4.4 认证门槛（可执行判据，`[T]`）**

```
K ≥ c ⟺ ε ≤ δ₁/(1−w₁+c) ⟸（用 Ē 地板）ε ≤ δ₁_lo/(1−w₁+c)
例：c=0.1、w₁=0.34、δ₁_lo=1.01 ⇒ ε ≤ 1.36 ⇒ s₂ ≤ 2.91 ≈ 1.88 s₁        [T]
⇒【正下界】认证 = s₂ 的**上界**（展出一个带正权重的支撑点 = HS2-A 易侧）
  【K→0】 认证 = ε 到顶 = s₂ 的**下界**（窗口排除，方向与一切估计子相反）
```

## §5 距离住在哪里（两句）

**5.1** 精确反例（段 [8]）：`ε` 与 `s₁` 在 `ν↦ν+σδ_{s_UV}` 下不动，而 `K: 0→1666→3332` 与 `w₁: 3/5→3/10→6e−5` 同动 ⇒ **`K` 是（载体，减法）的函数**；靶的 `w₁` 也动 ⇒ 两者同源同向，「距离」整条住在减法里（与 0.9 是同一件事的两个说法）。
