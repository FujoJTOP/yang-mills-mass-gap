## §2 · ★ PS 落在哪一格

### 2.1 PS 的输出清单（逐条，带标准出处）

| # | 输出 | 内容 | 出处 |
|---|---|---|---|
| P1 | **相图 / 相选择** | `(β, 外场)` 平面的相边界、共存；"相稳定" = 每个稳定基态的压力 `P_i` 等于最大值 `P_max` | Pirogov–Sinai 1975/76；Zahradník 1984 |
| P2 | **压力解析性** | 收敛域内 `P(β,h)` 对 `β`、`h` 解析 | 同上 |
| P3 | **指数聚类（H2 型）** | `\|⟨f;g⟩_c\| ≤ C e^{−m·dist}`，`m` 由轮廓活度（表面张力 `τ`）给出：`m ≳ βτ − log(branching)`，或 `m ≈ e^{−βτ}` 型 | Kotecký–Preiss 1986；Adhikari–Cao Thm 1.1 |
| P4 | **表面张力正性** | 共存相之间 `τ>0`（Peierls/轮廓代价） | Pirogov–Sinai; Zahradník |

**不在清单上的（关键）：** 任何 `|⟨Ω|O|n⟩|²` 的**下界**。三条独立理由：

- **(i) 对象错位。** PS 展开的是**配分函数/压力**与**局域函数期望**。矩阵元 `⟨Ω|O|n⟩` 是**转移矩阵谱分解**的数据；它不是压力对任何**局域**外场的导数（局域外场只生成对角关联 `⟨O;O⟩_c`，不生成跃迁矩阵元）。要读出原子，必须把关联**分辨成指数**——PS 只给和的界。
- **(ii) 只给不等式。** PS 的输出是收敛性/上界，不是等式。上界对"哪个态带权重"是盲的（引理 2.3）。
- **(iii) 读出的是 O-可见扇区。** 即便某个 PS 变体能读出领头指数，读出的是 `Δ₁^{(O)} = inf{Δ_n : c_n≠0}`，**不是**全隙 `inf spec`，**更不是** `|c₁|²`（`RS3:131` 同判："只给聚合物振幅，不给谱残数"）。

### 2.3 ★ 引理（残数盲）`[T]`

> **引理 2.3.** 设 `G(t) = ∫_{[0,∞)} e^{−st} dμ(s)`，`μ ≥ 0`（OS 重构给的正谱测度；`Y01-KL:125`），`f₁² := μ({Δ₁})`（最轻态的原子重量）。则
> **(a)** `G(t) ≤ C e^{−λt}`（`∀t≥T`）⇒ `supp μ ⊂ [λ,∞)`（即 **O-可见隙 ≥ λ**），**与各态重量无关**；
> **(b)** 但它对 `μ({Δ₁})`、以及对"是否存在 `Δ₁<λ` 而 O-不可见的态"**一无所知**。
>
> *证 (a).* 若 `μ((0,λ−ε])>0`，则 `G(t) ≥ μ((0,λ−ε]) e^{−(λ−ε)t}`，对大 `t` 超过 `Ce^{−λt}`。∎
> *证 (b).* 见证（同函数类，逐字可算）：自由大质量标量，`O = :φ²:`。`⟨Ω|:φ²:|p⟩ = 0`（奇），故 O-可见谱从 `2m` 起且连续；`G(t) ~ e^{−2mt}` ⇒ **(a) 成立，`λ=2m`**；但 `f₁² = 0`（O-扇区无原子），且**全隙 `= m < 2m`**。∎

**读法（本文件的承重句）：**

```
PS 供给的 = (a) 型上界（H2）
靶要的     = (b) 的原子重量 f₁² ≥ r₀（"最轻态被 O 看见"）
二者独立：自由大质量标量上 (a) 真而 (b) 假。
⇒ 任何只给 (a) 的机器（含 PS 的任何变体）都跨不到 (b)。
```

这条引理同时解释了 `PIROGOV-SINAI.md:6` 为什么把下界拆成 **(a) 指数上界 + (b) 残数下界** 两件事：PS 兑付 (a)，P3 兑付 (b)。**PS + P3 = P3 的窗，不是窗外。**

### 2.4 "相稳定性"本身还给得更少

`P_i = P_max` 是**压力的等式**。它给"哪个相被选中"，**连指数聚类都要另加轮廓收敛**。所以严格按题面问"相稳定性给出什么量"，答案是两级：

```
相稳定性（P_i = P_max）  ⇒  压力相等 + 相选择        （P1）
      + 轮廓收敛（小参量 e^{−βτ}）⇒  指数聚类（H2）   （P3）
```

**两级都不给 `f₁²`。** 把"相稳定性"直接读成"残数下界"是**跨两级跳**——第一跳要轮廓收敛，第二跳要 (b)，而第二跳对**任何**轮廓方法都不存在（引理 2.3）。

### 2.5 PS 的 H2 与仓内 H2 洞的关系（"同源"的精确含义）

`GC2-H23.md:215` 的 H2 是**两侧界 + β-一致 `c₀`**；`:258` 判 `H2 = [NG]（仓内可用陈述）+ [O]（待造对象）`。PS 供给的是：

| 面 | PS 的率 | 是否 β-一致 | 与 H2 洞的关系 |
|---|---|---|---|
| 弱耦合（Adhikari–Cao） | `(β/2)Δ_G` | **否**（`Δ_G=0` ⇒ 0） | 连 H2 都不是；`ξ=2/(βΔ_G)→0` 是冻结相 |
| 强耦合（Peierls/KP） | `σ(β)−c₀` | **否**（`σ(2.5)=0.570 < c₀`） | 只在 `β_A<3.777e−3` 成立 = **已有窗** |
