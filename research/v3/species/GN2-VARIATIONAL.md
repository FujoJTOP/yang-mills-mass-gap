### 0.2 「变分是否封顶」——是，但机制要说准

一个常见的说法是"变分天然给上界，所以只能证反方向"。**这句话在现象上对、在机制上错**，而机制决定有没有救。两个"免费"事实的符号是**相反**的，取决于比较映射的包含方向：

| 免费事实 | 式子 | 给出的方向 | 出处 |
|---|---|---|---|
| (a) 试验态 | `Δ ≤ ⟨ψ,Hψ⟩`（`Δ` 就是下确界，任一容许 `ψ` 都给上界） | `Δ_a ≤ Δ_cont + o(1)` ⇒ **`limsup Δ_a ≤ Δ_cont`（反方向）** | `B06-VAR.md:13` 同型；`U09-M6.md:15` |
| (b) 压缩/min–max | `λ_k(ET E) ≤ λ_k(T)`（`T ≥ 0`，`𝒜_c` 的 `k` 维子空间是子族）；`H` 语言同向：`λ_k(PHP) ≥ λ_k(H)` | `Δ(受限类) ≥ Δ(全类)` ⇒ **目标方向** | `glue-b-blocking/REPORT.md:194–203`（`[T]`）；本文 §6 核 #4 |

⇒ **变分本身没有方向偏好；方向由"格点类是不是连续统类的子族"决定。** 格点谱不是连续统谱的子族（`ℋ_a ⊄ ℋ`，(a)(b) 都不能直接套），只剩 (a) 可用，于是天花板是 `limsup`。

**因此本路的封顶点是精确一句**：`(NEW)` 等价于"格点方案（渐近）Galerkin 相容 / 无谱污染"（§3.4、§4.2），而那是**结构陈述**，不是估计；一旦相容，(b) 直接给目标、连谱理论都不需要；一旦不相容，(a) 只能给反方向。**没有一个中间地带靠"更努力的变分估计"填上。**

## §2 已证方向 `Δ_cont ≥ liminf Δ_a` 的证明结构摊开

### 2.1 四步，每步消费什么（`REPORT:277–279` 逐字对齐）

设定：固定 `L`；`T_a = e^{−aH_a}` 自伴、`0 ≤ T_a ≤ 1`、`T_a 1 = 1`（RP 给，`B01-RP:11`）；`1^⊥` 上 `H_a := −(1/a)log T_a`，`Δ_a := inf{λ ∈ σ(H_a): λ>0}`；连续统 `H`，`Δ_cont := inf{λ ∈ σ(H): λ>0}`。

| 步 | 内容 | **消费的假设** |
|---|---|---|
| S1 | 强预解收敛 ⇒ `σ(H) ⊆ limsup_a σ(H_a)` | **`SPEC-RES`**（`:274–275`）+ Reed–Simon I Thm VIII.24(b)（`:279`，`[std]`） |
| S2 | `{λ ∈ σ(H): λ>0}` 非空时其下确界 `Δ_cont` 属该闭集；空则 `Δ_cont = +∞`，平凡 | **`σ(H)` 闭** + `Δ_cont` 是**下确界**（不是最小值） |
| S3 | 故 ∃ 谱点列 `E_a ∈ σ(H_a)`，`E_a → Δ_cont` | S1（`limsup` 的展开） |
| S4 | `Δ_a ≤ E_a`（`Δ_a` 是 `σ(H_a)` 正部分的**下确界**）⇒ 取 `liminf`：`liminf Δ_a ≤ liminf E_a = Δ_cont` | **`inf ≤ 任一元素`**（序性质，一行） |

### 2.2 它**不**消费什么（这是全篇最重要的一张清单）

```
✗ 紧性 / 列紧 / 一致有界            （S1 是纯谱包含，无紧性）
✗ ι_a 的等距性或典范性              （S1 在抽象 ℋ 上说；桥可以任意）
✗ 归一化 / 场强重整 Z_a             （不看矩阵元，只看谱集）
✗ 任何 a-一致速率 / O(a^k) 项       （liminf 级陈述）
✗ Ω 的唯一性 / 基态简单性           （`Δ_a` 的定义只用 σ∖{0}）
✗ L 的一致性                        （固定 L）
✗ 上界方向（`Δ_a ≤ …`）—— 一点也不用
```

⇒ **已证方向之所以 4 行就能证，是因为它只用了"极限不丢谱"+"下确界 ≤ 元素"两件几乎不花成本的事。** 它是一张**单向**的网：`(NEW)` 要的是**反过来的那张网**（极限不多出谱），而"多出谱"恰恰是**下一节要证的污染现象**——**零成本的那一侧不可能是难的那一侧。**

### 2.3 反向需要的唯一新东西 = 反向谱包含

```
(NEW) ⟺ ¬∃ (a_k, E_k): E_k ∈ σ(H_{a_k}), E_k > 0, E_k → E < Δ_cont
      ⟺ limsup_a σ(H_a) ∩ (−∞, Δ_cont) = ∅
      ⟺ 【反向谱包含 / 无谱污染】
```

（等价性：`Δ_cont ≤ liminf Δ_a` ⟺ "对每个 `ε>0`，最终 `Δ_a ≥ Δ_cont − ε`" ⟺ 不存在低谱点列。`[T]`，纯逻辑。）

**并且这条不能靠"更强的收敛"白拿**：`SPEC-RES-norm` 若成立则白拿（`gap_lipschitz`，`[T]`），但它**不可能成立**（§0.4 H2）。所以必须换成**结构**条件：§3.4 的 `GAL-a`。

### 2.4 反用：单向谱包含 ↔ 单向 form 支配

已证方向的引擎是"**一侧**包含"。它在 form 层的同号孪生是 `(E4)(iii)`：`ι_a^*H_contι_a ≤ H_a + η_a`（在 `Ω_a^⊥` 的低能段）。两点说明：

1. **为什么同号**：`σ` 的包含与 `form` 的支配在**自伴 + 半有界**下互为"影子"（Weyl 单调性：`A ≤ B` ⇒ `λ_k(A) ≤ λ_k(B)`）。已证方向用的 `σ(H) ⊆ limsup σ(H_a)` 是"极限的谱被逼近谱罩住"；`(E4)(iii)` 是"极限的 form 被格点 form 罩住"。**同一个罩，落在不同对象上。**
2. **为什么这不是循环**：`(E4)(iii)` 只需在**低能段**成立，而 `σ(H) ⊆ limsup σ(H_a)` 是**全谱**陈述。二者不可互推。

### 3.2 加性比较的最小公式与证明（`[T]`）

> **命题 GN2-ADD.** 设 `ker H_cont = ℝΩ`（真空唯一，`GL2bPrime.lean:21–25` 的 declared scope），`ι_a: ℋ_a → ℋ` 满足 (i)(ii)(iii)（`(E4)`）于能量段 `⟨ψ,H_aψ⟩ ≤ E₀`，并取 `E₀ ≥ Δ_cont`。则
> ```
> Δ_a ≥ Δ_cont − η_a·(1+Δ_cont)          即  Δ_a ≥ Δ_cont − O(η_a)
> ```
> 特别地 `η_a = c·a^k ⇒ Δ_a ≥ Δ_cont − c(1+Δ_cont)·a^k`，**即题目问的加性比较成立**。

*证明.* 取 `ψ ∈ Ω_a^⊥`，`‖ψ‖=1`。
**情形 A（`⟨ψ,H_aψ⟩ ≤ E₀`）**：由 (ii) `ι_aψ ⊥ Ω`，由 `ker H_cont = ℝΩ` 与 `Δ_cont` 的定义得 `⟨ι_aψ, H_contι_aψ⟩ ≥ Δ_cont‖ι_aψ‖²`。结合 (i)(iii)：
`Δ_cont(1−η_a) ≤ ⟨ι_aψ,H_contι_aψ⟩ ≤ ⟨ψ,H_aψ⟩ + η_a` ⇒ `⟨ψ,H_aψ⟩ ≥ Δ_cont − η_a(1+Δ_cont)`。
**情形 B（`⟨ψ,H_aψ⟩ > E₀`）**：因 `E₀ ≥ Δ_cont ≥ Δ_cont − η_a(1+Δ_cont)`，同一不等式平凡成立。
两种情形合起来对**全部** `Ω_a^⊥` 单位向量成立 ⇒ 取下确界得 `Δ_a ≥ Δ_cont − η_a(1+Δ_cont)`。∎

（注意：`E₀` 只需 `≥ Δ_cont`，**不需要** `Δ_a ≤ E₀`；截断的作用是把"尾部"变成平凡情形，而不是限制 `Δ_a`。）

**三点必须记账：**

1. **`(E4)` 严格弱于 `(E3)`**：`(E3)` 是算子范数比较（双向、全谱），`(E4)` 只要**单侧**、**低能段**、**二次型**。**这就是"能经由算子范数差得到加性比较"那条路的正确弱化形式**——但弱化后它就不再是"`‖H_a − H_cont‖ → 0`"，而正是**无污染**。
2. **`E₀` 截断不可省**（自由场反例，§3.3）：`(iii)` 在全能量段上**为假**，且假得定量（缺陷 `∼ a²p³/12` 随 `p³` 增长）。
3. **这一步不产生任何地板**：`(E4)` 全部是"格点隙 ↔ 连续统隙"的比较，`Δ_cont` 可以 `= 0`，自由场就是 `0 ≤ 0`（§5）。

### 3.3 「`‖H_a − H_cont‖ → 0`」这条路是空的（自由场符号证书，`[T]`）

自由无质量标量（标准 Wilson/Gaussian 格点作用，环面边长 `L`，间距 `a`）：

```
p̂²(a,p) = (2/a²)·Σ_μ(1 − cos(a p_μ))          （格点符号）
H_a 的符号 = ω_a(p) = p̂²(a,p)  ≤ 4d/a²        （有界！）
H_cont 的符号 = |p|²                            （无界）
单粒子色散（精确）：Δ_a = (1/a)·arccosh(1 + a²p̂²/2) = (1/a)·arccosh(2 − cos(ap))
```

- **`Δ_a ≤ Δ_cont` 且严格**（`a>0`）：因为 `1 − cos x ≤ x²/2` ⇒ `p̂ ≤ p`，又 `arccosh(1+y²/2) ≤ y`（`max_x[arccosh(1+x²/2) − x] = 4.4e−11 ≤ 0`，核 #1b）。**`[T]`（模型内）**
- **速率**：`Δ_cont − Δ_a = a²p³/12 + O(a⁴)`（核 #1c：`a=1/128` 时预测 `1.2616e−3` vs 实测 `1.2613e−3`）。**`[T]`（模型内）+ `[C]`（数值）**
- **有界 vs 无界**：`H_a` 有界、`H` 无界 ⇒ 对任何幺正识别，`‖U_aH_aU_a^* − H‖ = ∞`。**⇒ `SPEC-RES-norm` 对自由场为假，识别无关。** `[T]`

**副产物（很重要）**：自由场里 `Δ_a < Δ_cont` **对每个 `a>0` 成立**。⇒ **任何"逐 `a` 证 `Δ_a ≥ Δ_cont`"的方案被自由场直接否证；`(NEW)` 只能是极限级陈述。** 这也正好把题目的预判（"变分给上界"）**升级成一条可核对的模型事实**，而不是一句方法论直觉。

### 3.4 `GAL-a`：`(NEW)` = 渐近 Galerkin 相容

> **定义（GAL-a(η)）.** ∃ 嵌入 `ι_a: ℋ_a → ℋ`（`‖ι_a‖ ≤ 1+η_a`），`ι_a Ω_a = Ω`，使
