## §0 判词（一屏，四句）

1. **它给的定理是"唯一性 + 指数遍历 + LSI/Poincaré + 尾部指数衰减"，四件套，且 mass gap 以 Corollary 1.6 的形式出现** `[T]`。**它的"mass gap"是尾，不是单点**：逐字是 `Cov(f,g) ≤ c₁d(g)e^{−c_N d(Λ_f,Λ_g)}(…)`——**空间距离 → ∞ 上的指数衰减率**；**不给** `m₁²` 的位置、**不给**原子权重 `f₁²`、**不给**简单本征值或隔离 `I₂`。
2. **给的是"常数"，不是纯存在性** `[T]`：`c_N` 有显式可算形式（Remark 4.12 逐字 `c_N ∼ K_S/(d(g)(a_{e,e}+6(d−1)a_{e,ē}))`，自陈 "not necessarily optimal"），且 `K_S` 本身就是 Assumption 1.1 里的**等式**。⇒ **判 (a) 成立（点态、可算）**。
3. **但这个常数依赖 `β`，且在窗边 → 0** `[T]+[E]`：`K_S = N(½−24|β|)`（d=4）⇒ `c_N ∝ (½−24|β|)/|β| → 0` 当 `|β| ↑ 1/48⁻`。⇒ **判 (c) 也成立，且只在边界退化**：窗内任一紧子窗 `[0,β₁]`（`β₁<1/48`）有**一致正**下界；`inf_{|β|<1/48} c_N = 0`。
4. **它给了 (iii) 的哪一段：窗内（`|β|<1/48`）每一固定 `β` 的点态下界；窗 `[1/48, ∞)`（含 `β=2.5` 的 Savvidy 交叉点、整座塔 `[2.5,∞)`）—— 逐字零覆盖，`[NG]` 于源文。** 且在窗内它只给 `a=1` 的**格点**隙（unit lattice spacing），**不取 `a→0`**。

## §1 逐字定理陈述（严格照抄，不转写）

### 1.1 唯一的假设（Assumption 1.1，逐字）`[T]`

> **Assumption 1.1.** Suppose that
> `K_𝒮 :=def { (N+2)/4 − 1 − 8N|β|(d−1) > 0 ,  G = SO(N) ;  (N+2)/2 − 1 − 8N|β|(d−1) > 0 ,  G = SU(N) .`
> Assumption 1.1 is equivalent to the following strong coupling assumption:
> `|β| < { 1/(32(d−1)) − 1/(16N(d−1)) , G = SO(N) ;  1/(16(d−1)) , G = SU(N) .`  **(1.3)**

⇒ **`env2` 的逐字引文核准：`[C]` 正确，SU(N) 分支一字不差** `[T]`。`d=4 ⇒ |β|<1/48`（与 `N` 无关）；`SO(N)` 分支才带 `N`。**附带的两条环境条件也在正文**：`d>1` 任意维；**单位格距 `a=1`**（§1.1 逐字 "unit lattice spacing"）；周期边界（Remark 1.3：换成 Dirichlet 等**不改结论**）。

### 1.2 定理一：唯一性与指数遍历（Theorem 1.2，逐字）`[T]`

> **Theorem 1.2 (Uniqueness and ergodicity).** Under Assumption 1.1 … (1) The invariant measure … is unique. (2) … the whole sequence `{μ_{Λ_L,N,β}}_L` converges to `μ^ym_{N,β}` as `L→∞`. (3) … there exists a constant `a>1` such that for any `ν ∈ P(Q)`
> `W_2^{ρ_{∞,a}}(νP_t, μ^ym_{N,β}) ≤ C(a)e^{−K̃_𝒮 t}, t>0,`
> "for some `K̃_𝒮>0` which only depends on the constant `a`, `d`, `β` and `G` (in particular `N`)."
> Remark（逐字）："`K̃_𝒮` can be explicitly given by (5.15) below"，(5.15) 逐字 `K̃_𝒮 = C_{Ric,N} − (4+4√a)N|β|(d−1) > 0`.

### 1.3 定理二：LSI / Poincaré（Theorem 1.4，逐字）`[T]`

> `μ^ym_{N,β}(F² log F²) ≤ (2/K_S) Σ_{e∈E⁺} μ^ym_{N,β}(|∇_e F|²)`；`μ^ym_{N,β}(F²) ≤ (1/K_S) Σ_e μ^ym_{N,β}(|∇_e F|²) + μ^ym_{N,β}(F)²`.

⇒ **谱隙常数的下界就是 `K_S` 本身（等式定义）**，不是"某个常数"。

### 1.4 定理三：**它就是 "mass gap"（Corollary 1.6，逐字）** `[T]`

> **Corollary 1.6 (Mass gap).** Suppose that Assumption 1.1 holds. Writing Cov for the covariance under the measure `μ^ym_{N,β}` in Theorem 1.2. For `f,g ∈ C^∞_cyl(Q)`, suppose that `Λ_f ∩ Λ_g = ∅`. It holds that
> `Cov(f,g) ≤ c₁d(g) e^{−c_N d(Λ_f,Λ_g)} ( |||f|||_∞ |||g|||_∞ + ‖f‖_{L²(μ^ym)} ‖g‖_{L²(μ^ym)} )`,
> "where `c₁` depends on `|Λ_f|`, `|Λ_g|` and `c_N` depends on `K_S`, `N` and `d`."

§4.3 首句（逐字）："In this section we use the Poincaré inequality to prove the existence of mass gap for lattice Yang–Mills."
摘要（逐字）："…correlations of a large class of observables decay exponentially, namely the infinite volume measure has a strictly positive mass gap."

### 1.5 衰减率的**逐字**给出（Remark 4.12）`[T]`

> **Remark 4.12.** "From the above proof one can see `c_N ∼ K_S / ( d(g)( a_{e,e} + 6(d−1)a_{e,ē} ) )`, but this is not necessarily optimal."

其中（Lemma 4.10 后，逐字）：`a_{e,ē} = N|β|√(d(g))`（`e≠ē`），`a_{e,e} = 2(d−1)N|β|(√(d(g)) + √2 N^{1/2}γ)`；`d(g) = dim_ℝ g`。
机制（(4.26)/(4.29) 两段平衡）：`Cov ≤ c₁d(g)e^{−c·d}|||f|||∞|||g|||∞ + e^{−2tK_S}‖f‖‖g‖`，取 `t ∼ d/B` ⇒ **净指数速率 ≈ `min(c, K_S/B)`**，Remark 4.12 就是把两者对齐的记法。`c` 本身由 `2 − log B + log C₀ + C₀/B ≤ −2c`（`C₀ = d(g)(a_{e,e}+6(d−1)a_{e,ē})`）**隐式**定出——故 `c_N` 是**可算但经一次 `O(1)` 优化的显式量**，不是不可及的存在量。

## §2 尾还是单点：**尾**（decay rate），不是单点

| 对象 | SZZ 给不给 |
|---|---|
| 尾：`Cov` 在距离 `→∞` 的指数衰减率下界（= 真空之上第一个谱点的**下界**）| **给** `[T]`（Cor 1.6） |
| 单点：`m₁² = inf supp ν` 的**位置** | **不给** `[NG]` |
| 原子：`f₁² = ν({m₁²})`（残数/权重）| **不给** `[NG]`（这是 P3 那一半） |
| 简单本征值 / 隔离 `I₂` | **不给** `[NG]` |
| `a→0` 一致（连续极限）| **不给** `[NG]`（格点、`a=1`） |

一句话：**SZZ 的名字叫 mass gap，内容是一条尾的速率**。它与"单点"的关系只是：`m₁² ≥ c_N`（速率下界 ⇒ 位置下界），**位置的上界、权重、隔离都在它之外**。这与仓内既有判词一致（`LIT-ERA-04:324`："OS 1978 / SZZ 2023 prove the gap (decay rate / eigenvalue spacing). P3 proves the residue"）。

## §3 常数还是存在性：**常数**（显式、可算、随 `β` 变）

**(a) 成立** `[T]`：`c_N` 有闭式路线（§1.5），`K_S` 是等式定义；`N`-依赖也是显式的（`K_S = N(½−24|β|)`，d=4）。
把 §1.5 代成 `d=4, SU(N)` 的显式式（自算，见 §4 复算）：

```
c_N(β) ≍ (½ − 24|β|) / ( 6|β| (N²−1) [ 4√(N²−1) + 6√N ] ) ,        d = 4,  |β| < 1/48.     (B12-1)
```

**(b) 不成立（不是纯存在性）**：`K̃_𝒮`、`c`、`c_N` 全部可由文中式子算出；`c₁` 依赖 `|Λ_f|,|Λ_g|`（与 `L` 无关）。

**(c) 成立，且**只在窗边**退化** `[T]+[E]`：

```
∂_β :  c_N(β) ∝ (½ − 24|β|)/|β|  ⇒  c_N(1/48⁻) → 0⁺ ,   c_N(0⁺) → +∞ .                     (B12-2)
```

⇒ 严格表述（不许省）：
- **窗内每一点**：`c_N(β) > 0`，显式；故 "(iii) 在 `|β|<1/48` 内侧已证（点态）"✔。
- **窗上的一致下界**：`inf_{0<|β|<1/48} c_N = 0` ⇒ **没有窗内一致常数**；只有任一**紧子窗** `[0,β₁]`（`β₁<1/48`）上有 `c ≥ c(β₁)>0`。
- **窗外** `|β| ≥ 1/48`：源文**逐字无一字**（`[NG]` 于源文；检索见 §6）。
