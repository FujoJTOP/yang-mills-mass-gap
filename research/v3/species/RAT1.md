# RAT1 · 局部比引理 `a_{n+1} ≤ 48 a_n` ⇒ `λ_* ≤ 48`：边界片数的生死

**靶（`LC5.md:92–93` 逐字）**：
> **局部比引理**：`a_{n+1} ≤ B·a_n`（`B` 显式，由"新片只能挂在已有片上 + 每 link 6 片、片有 8 邻片"的簿记给），则 `a_n ≤ B^{n-1}a_1` ⇒ `λ_* ≤ B`，**不需要 Fekete、不需要次可乘**。观测最大比 `25.7652`，对 `B = 48` 有 **1.863× 松量**…

**对象**：4D plaquette 图（片 = 顶点，共 link = 边），`Δ = 20 = 4·(2(d−1)−1) = 4·5`，`d = 4`；`a_n = #{Γ ∋ p₀, 连通, |Γ| = n}`。
**语料**（逐位复现）：`a_n = 1, 20, 458, 11132, 280175, 7218768`（`UR4:51`、`w7/ur4_enum_n6.log:19–21`、独立码 `species/w7/ur1_enum_n6.log:3–5`）。
**机器**：`py -3.12`，`w7/rat1_bounds.py`→`rat1_bounds.log`（4.7 s）、`w7/rat1_indep.py`→`rat1_indep.log`（10.0 s，**独立编码**，不复用 `ur1_enum` 位域）、`w7/rat1_ldegree.py`→`rat1_ldegree.log`。三者 `exit 0`。

**判决（先给）**：**(b) —— 边界/局部注入这条路死**。理由不是"最坏边界 76 太大"，而是一条**精确的 `[T]` 定理**：`b(Γ) ≤ 14n + 6`（**锐**，链族 n = 1..60 逐位取等），即最坏边界片数是 **`14n + 6`**（`n=1..5`：`20, 34, 48, 62, 76`），**`48` 恰好就是 `n=3` 的最坏值**，`n ≥ 4` 一律超。但引理 `a_{n+1} ≤ 48a_n` **本身未被反驳**（数据最大比 `25.7652`，松 `1.863×`）——它死在"证不出来"，不死在"假"。

## 1 · 组合意义：`a_{n+1}/a_n` 不是"每个 n 片集能加多少"

`b(Γ) := |∂Γ| = #{q ∉ Γ : q 与 Γ 相邻}`（**边界片数 = 生长位置数**）。`LC4` 的恒等式（本轮精确复验 `n ≤ 4`，`[T]`）：

```
Σ_{Γ ∈ A_n} b(Γ)  =  Σ_{Γ' ∈ A_{n+1}} m(Γ'),   m(Γ') := #{p ∈ Γ', p ≠ p₀ : Γ'\{p} 连通}
⇒  a_{n+1}/a_n = E[b(Γ)] / E[m(Γ')]           （"平均生长位置" / "平均父数"）
```

`rat1_bounds.log §2`：

| `n` | `Σ b(A_n)` | `Σ m(A_{n+1})` | `E[m]` | `a_{n+1}/a_n` |
|---|---|---|---|---|
| 1 | 20 | 20 | 1.00000 | 20.0000 |
| 2 | 648 | 648 | 1.41485 | 22.9000 |
| 3 | 20172 | 20172 | 1.81207 | 24.3057 |
| 4 | 616400 | 616400 | 2.20005 | 25.1684 |
| 5 | 18639660 | — | `E[m(A_6)] = 18639660/7218768 = 2.58211` | **25.7652** |

**结论**：`E[b] = 66.53`（`n=5`）远大于比 `25.77`，差的那 `2.58×` 正是"一个 `(n+1)` 片集平均有 `2.58` 个可删片"。所以引理的真实内容是**全局均值不等式** `E[b] ≤ 48·E[m]`（`n=5`：`66.53 ≤ 123.93` ✓），**不是**"每个集的边界 ≤ 48"。

## 2 · `[T]` 边界定理：`b(Γ) ≤ 14n + 6`（锐）

> 设 `Γ` 连通、`|Γ| = n`。取生成树、根 `q₁`，按 BFS 序 `q₁,…,q_n`（`q_i` 的父 `q_j`，`j < i`，共用 link `ℓ_i`）。令 `Γ_i = {q₁,…,q_i}`。
> 加入 `q_i` 时：`q_i` 的 `Δ = 20` 个邻片分成 `{父 q_j}(1) ∪ {ℓ_i 上另 4 片} ∪ {其余 15 片}`；前 5 片都在 `Γ_{i-1} ∪ ∂Γ_{i-1}` 内（都邻 `q_j`），故**新边界 ≤ 15**；又 `q_i ∈ ∂Γ_{i-1}`（邻父）被加入时**离开边界 −1**。
> ⇒ `|∂Γ_i| ≤ |∂Γ_{i-1}| + 14`，`|∂Γ₁| = 20` ⇒ **`b(Γ) ≤ 20 + 14(n−1) = 14n + 6`**，其中 **`14 = Δ − 2(d−1) = 20 − 6`**。

**锐性**：平面 `(0,1)` 内沿 `x₀` 的直链族（`rat1_indep.py (C)`，独立编码无位域）取等 **`n = 1..60` 全部成立**（`b(60) = 846 = 14·60+6`）；`n ≤ 5` 的全枚举最坏值也恰是 `14n+6`（下一节）。
**一般式**（同证明）：`b ≤ (Δ − 2(d−1))n + 2(d−1)`；`d = 3` 给 `Δ = 12`、`b ≤ 8n + 4`。

## 3 · 最坏情形边界片数：**`14n + 6`**（给了数）

`rat1_bounds.log §1` + `rat1_indep.log (B)`（两套独立编码逐位相同），`n = 1..5` **全部** `a_n` 个集精确算：

| `n` | `a_n` | `min b` | `mean b` | **`max b`** | `14n+6` | `#b ≤ 48` | `#b > 48` |
|---|---|---|---|---|---|---|---|
| 1 | 1 | 20 | 20.0000 | **20** | 20 | 1 | 0 |
| 2 | 20 | 32 | 32.4000 | **34** | 34 | 20 | 0 |
| 3 | 458 | 39 | 44.0437 | **48** | 48 | 458 | 0 |
| 4 | 11132 | 46 | 55.3719 | **62** | 62 | **32** | 11100 |
| 5 | 280175 | **49** | 66.5286 | **76** | 76 | **0** | 280175 |

* **`max b = 14n + 6` 逐位取等（差 0）**；`max b/n = 20, 17, 16, 15.5, 15.2 → 14`。
* **`48` 就是 `n=3` 的最坏边界**：`n ≥ 4` 起最坏值 `62, 76, …` 全部 `> 48`。
* **`n = 5` 起连"最好"的集也超**：`min b = 49 > 48`，`#b ≤ 48 = 0/280175`。`n=4` 只有 `32` 个例外，且**全为 `b = 46`**（`n=4` 的低端直方图只有 `b=46: 32` 个，次低 `b = 49: 128` 个）。
* 极值族的形状：**是"链/管"，不是"板"**（`rat1_indep.log (D)`：`k×k` 板 `b/n = 14, 12, 11, 10.4, 10`，`k=2..6`；板因邻片重合反而更小）。`argmax` 集恒为**树**（边数 `= n−1`，`#argmax = 1,4,6,8,10`）。
* `20n` 的粗界也复核过：`max b ≤ 20n` 平凡，但锐界是 `14n+6`，`n=5` 时 `76 < 100`。

## 4 · `48` 够吗？—— 分两种读法，一种假、一种未证

| 读法 | 判 | 证 |
|---|---|---|
| **(B-48)** "每个 `n` 片集的边界片数 `≤ 48`" | **假** `[T]` | `max b = 14n+6`：`n=4 → 62`、`n=5 → 76`；链族给出 `b = 14n+6 → ∞`（`n ≤ 60` 实算）。**`48` 只在 `n ≤ 3` 成立** |
| **(R-48)** "`a_{n+1} ≤ 48 a_n`" | **未反驳、也未证** `[NG]` | 数据 `20, 22.9, 24.31, 25.17, 25.77` 全部 `< 48`（松 `1.863×`）；`n=5` 处 `E[b] = 66.53 ≤ 48·E[m] = 123.93` ✓ |

**关键**：`(B-48)` 假**不**蕴含 `(R-48)` 假——注入 `A_n × ∂ → A_{n+1}` 是**多对一**（`E[m] = 2.58`）。但反过来，**"删一片"式论证能给的常数就是 `E[b]` 本身**（`Σ_{A_n} b = Σ_{A_{n+1}} m ≥ a_{n+1}`）：

```
a_{n+1} ≤ E[b(A_n)]·a_n :   E[b] = 20, 32.4, 44.04, 55.37, 66.53  （n=1..5）
a_{n+1} ≤ max b·a_n     :   20, 34, 48, 62, 76                    （= 14n+6）
```

两条都是 **`Θ(n)`**（`E[b]/n = 20, 16.2, 14.68, 13.84, 13.31`，向 `14` 收敛）⇒ **任何"边界/删一片"论证都只能给出 `B_eff(n) ∝ n`，永远给不出常数 `48`**（`n=5` 处已 `66.53 > 48`）。这是结构性的，不是数据不够。

## 5 · `48 = 8×6` 的结构：`8` 与 `6` 各是什么

* **`8 = 2d`**：**站点的 link 度**（4D 超立方格点有 8 条 link）。
* **`6 = 2(d−1)`**：**每条 link 上的片数**。
* **`Δ = 4·(6−1) = 20`**：片的邻接度 = `4` 条 link × 每 link `5` 个"外来片"。
* ⇒ **`48 = (link/站点) × (片/link)` = 站–link–片 的关联数**，**不是**任何"每片/每集"的计数：片的邻度是 `20`，不是 `8`。
  **更正 `LC5.md:93`**："`48 = 8×6 = 邻片数 × 每 link 片数`" —— **邻片数是 `20 = 4·5`，不是 `8`**；`8` 是站点度。`[T]`
* 真正让 `48` 出现的算术（本轮实测）：
  **`48 = max b(3) = (Δ − 6)·3 + 6 = 14·3 + 6`** —— 即"`3` 片链的边界"，**`6` 是承重的**（`14 = Δ−6` 是极值族每步增量，`6` = 共用 link 上的同族片 + `q` 离开边界 ⇒ `20−5−1 = 14`），**`8` 不承重**。
* 其他巧合（都在 `lc4_growth.log:34–39`）：`48 = 2Δ + 8 = 2.4Δ`；`L_t(18) = 47.5635 < 48 < L_t(19) = 50.2821`（`L_t(D) = D^D/(D−1)^{D−1}`）。

## 6 · 判死线

* **(a) 不存在。** `(B-48)` 是 `[T]` 假（`max b = 14n+6`），所以"边界 ≤ 48 ⇒ 注入 ⇒ `a_{n+1} ≤ 48a_n`"**不能逐字给出**。若只保留 `(R-48)`，它在数据上成立、在 `n ≤ 5` 无违例，但**没有证明**，标 `[NG]`。
* **(b) 这条（局部/边界）路死。** 不是"最坏边界 76 太大"这么弱，而是：**锐界 `b = 14n+6`（`[T]`，链族 `n ≤ 60` 取等）**，故 `(B-48)` 对所有 `n ≥ 4` 假；而"删一片"能给的最好常数 `E[b] ≈ 14n` 无界 ⇒ **`48` 不可能由边界计数得到**。顺带：`(R-48)` 一旦为真就**强于**目标（引理 ⇒ `λ_* ≤ 48`），而目标只需其**尾部**成立（`a_{n+1} ≤ 48a_n, n ≥ n₀` 已足够：`a_n^{1/n} ≤ 48·(a_{n₀}/48^{n₀})^{1/n} → 48`）。
* **(c) 不需要更大 `n`，更大 `n` 也救不了。** `E[b], max b` 的 `Θ(n)` 增长是**结构性的**（`[T]` 的 `14n+6`），枚举到 `n = 7, 8` 只会把 `E[b]` 从 `66.5` 抬到 `~78, ~90`，离 `48` 更远。**`LC5.md:88` 的"需要的不是更大的 `n`"本轮被证实。**

## 7 · 剩下的路（带数）

已证上界只有树包络：`λ_* ≤ eΔ = 54.3656365692 [T]`（`ADJ2:14`），到 `48` 差 **`1.13262×`**。三条候选：

1. **一致 `C` 引理**：证 `a_{m+n} ≤ C a_m a_n`，`C ≤ 1694.277` 即得 `λ_* ≤ 48`（配 `n=6`；配 `n=4` 只需 `C ≤ 476.86`）——`LC5:71–82`。观测 `C ≥ 34.41` 且上升，无一致证据。
2. **有效度定理（本轮新提议）**：`b ≤ 14n+6` 的机制说明"每片的可用方向被共用 link 吃掉 `6` 个"。若能把**树包络的度从 `Δ = 20` 换成 `Δ − 2(d−1) = 14`**（即 `a_n ≤ (1/n)C(14n, n−1)` 型），则 `λ_* ≤ L_t(14) = 36.6884 < 48`（`1.308×` 余量），**窗直接到 `1/48` 且有余**。缺的是"动物 ≤ 14-度树包络"这一步（`[C]`，本轮未证）。
3. **平均父数下界**：由恒等式，`ratio ≤ 48 ⟺ E[b] ≤ 48·E[m]`；用 `E[b] ≤ 14n+6` 得**只需 `E[m(n+1)] ≥ (14n+6)/48`，斜率 `14/48 = 0.29167`**。实测 `E[m]/n = 0.500, 0.4716, 0.4530, 0.4400, 0.4304`（`n=2..6`），比 `0.2917` 高 `1.48×` 且下降很慢 ⇒ 若 `E[m]/n` 有正的下界 `c ≳ 0.3`，则 `λ_* ≤ 14/c ≲ 46.7 < 48`。**这是三条路里最可能先闭合的**。

另附：若 `E[b]/n → 14` 且 `E[m]/n → 0.43`，则 `λ_* → 32.6`（`[C]` 外推，不是界）。
