## §1 单调性（公式 + 判据 + 自算）

### 1.1 两个精确移项（`[T]`）
```
R_j = Var_j/A_j ,   A_j := E_j[H_vv] + W_j ,   G″_j = A_j − Var_j = A_j(1 − R_j)
⇒ (i) R_j = 1 − G″_j/A_j ;   (ii) R_j ≤ 1 ⟺ G″_j ≥ 0   (仅当 A_j>0) ;   A_j≤0 ⇒ R_j≤0<1.
```
`(ii)` 的右半边把 `R`-货币的两条阈值合并：**finiteness `R≤C` 与 `(★)` 的差别全部落在 `A_j` 的符号窗上**。`A_j≤0`（Savvidy 大 holonomy，`BL2:56`）时 `R≤0`，`R` 的上界**自动成立**、且不携带任何关于 `G″` 的信息 —— 这正是 `HS-L3-2.md:0.8②` 说的"`R` 连符号都没意义"。

### 1.2 微分判据（`[T]`）
以 `j` 为变量，`A_j = β_jQ_c + O(1) = cQ_c j + O(1)`（`c:=4Nβ₀`），故 `A′_j=A_j/j`：
```
dR_j/dj = (G″_j·A′_j − G″′_j·A_j)/A_j² ,   A′_j = A_j/j
⇒ sign(dR/dj) = sign( G″_j − j·G″′_j ) .
```
**判据：`R` 沿塔升 ⟺ `G″_j > j·G″′_j`，降 ⟺ 反向。** 两条读法：
- 若 `|dln G″/dln j| ≪ 1`（`G″` 在对数塔上**慢变**，`O(1)` 级），则 `sign(dR_j/dj)=sign(G″_j)` —— **方向 = `G″` 的符号**。
- 若 `G″` 在塔上**过零**，则 `R` 在该点必有**拐点**（`R` 从 `>1` 段进入 `<1` 段），单调性破裂。
- 若 `A_j` 过零（0.4），`R` 有**极点**，`sup_j R_j=+∞`："塔塌到单点"这句话在该窗内无对象。

### 1.3 自由块：唯一能算尽的情形（`[T]`，闭式 + 两处核）
`V1:48–52`：`E[H]=β_jQ_c+o(β_j)`、`E[H]−Var=W_geo=mβ_jQ_c/(β_jQ_c+m)`、`G″=2W_geo→2m=N/6`（SU(2)：`m=N/12=1/6`）。代入：
```
R_j = (β_jQ_c − W_geo)/(β_jQ_c + W_geo) ,   1 − R_j = 2W_geo/(β_jQ_c+W_geo) ≈ 1/(24β₀Q_c j) .
```
自算（`N=2`、`β₀=0.0464385`、`L=2`⇒`Q_c=π²=9.8696`、`β_j=0.37151 j`）：
| `j` | `β_j` | `β_jQ_c` | `W_geo` | `1−R_j` | `R_j` |
|---|---|---|---|---|---|
| 7（= `j*`） | 2.6007 | 25.666 | 0.16559 | **1.282e−2** | 0.98718 |
| 100 | 37.151 | 366.66 | 0.16659 | **9.27e−4** | 0.99907 |
渐近式给 `0.01299`/`9.09e−4`，与精确值差 `O(W_geo/β_jQ_c)` —— 相对差在 `j=100` 为 `2%`，可忽略。**自由块上 `R↑1`、`G″≡N/6`（`j`-一律、`β`-一律）**。注：此处 `G″` 是恒等里的**模型形** `E[H]−Var+W_geo`；带交叉项 `X=−2Cov` 的 `G″_lit` 在自由块上**恒为 0**（`V1:50–51`）—— 两个对象不许互代（`HS-L3-2.md:0.4`）。

### 1.4 极限是什么（`[T]`，条件式）
`R_j → 1 ⟺ G″_j=o(A_j)=o(β_j)`。两条反向可能都**未被排除**：
- `G″_j=Θ(β_j)`（无 equipartition，只有 C-S 的 `Var≤E[G²]∼β_j²`，`PROOF-L3.md:16`）⇒ `R_j→1−θ`，`θ≠0`，端点**不是** `1`；
- `G″_j=o(1)`（`G″→0`）⇒ `R_j→1`，但 `(★)` 的 `δ` 也随之消失。
⇒ **`lim R_j` 不是 `1` 的定理，而是 M2 的改写**（`HQ1:113`）。**下一手**：把"M2 塔版"写成"`G″_j=o(β_j)` 一致、且 `G″_j≥δ_W` 一致"两条分开的句子。

**§2 判词（`[T]` 结构 / `[NG]` 塔）**：三个候选里，前两个给不出界（一个 δ=0、一个发散），第三个给界但**载荷不是 `R`**。所以"塔一致塌成单点"这句话成立，但它的主语必须是 `Ĝ″`、落点是**头** `j*`、价格是 `ĉ` 与 `Σℓ_j`；用 `R` 写它，得到的是 `G″≥0` 这个**已被实测否证**的 δ=0 情形。
