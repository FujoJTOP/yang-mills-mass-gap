## §1 反常量是否含模数（逐字核 `H03-ANOMALY.md` / `INEQ-R10`）

### 1.0 先把"模数"定义成可判的东西

GH1 §2.6 的用法是隐含的（"带模数的输入"），本文件把它写成三条可逐项打勾的判据：

```
定义 MOD.  数 c 是靶 (E) 的模数 ⟺
  (i)   c 在**靶理论层面**有定义：无 a、无 L、无方案/归一选择；
  (ii)  c > 0 **已证**（不是格点经验、不是"预期"）；
  (iii) 存在**已证**蕴含  c ≥ c₀  ⟹  m/Λ ≥ f(c₀) > 0，f 显式。

**为什么要单列 (i)**：`m/Λ ≥ Δ₀` 本身是**方案条件数**——`A8-MASS-LAMBDA:11` 逐字：*"语料没有这个匹配，所以 `c = m/Λ` 不是纯数，是 scheme-条件数"*，且 `m/Λ` 对 `1/g²` 的常数平移按 `e^{δ/(2b₀)}` 放大（`1/(2b₀)=7.18`，`δ=0.5` 就搬 `36×`；`δ=0.894` 搬 `613×`，`A8:11,13`）。所以**任何模数必须至少和靶一样 scheme-协变**，否则 (iii) 不可能对。

## §2 ★ 能否耦合到谱底（本路判决点）

### 2.1 谱底是什么**类型**的对象

```
谱底：m_GI = inf supp ρ_s          ← 端点      （闭条件：∃δ>0, σ(H)∩(0,δ)=∅）
反常给的：⟨s⟩ = ∫ s dρ_s           ← 一阶矩    （开条件的上界）
```
反常在这条链上**唯一**的用处是把 `s` 钉成算符 `T^μ_μ`，从而 `ρ_s ≥ 0`、`m_GI` 良定义（`H03:181` 逐字）。**但 `ρ_s ≥ 0` 就是 `ℋ_struct` 的第 `(iv)` 项**（`GH1:184`：`(iv) RP ⇒ ν≥0（KL）`）—— 而 `ℋ_struct` 是**自由 `U(1)` 也满足**的那一坨（`GH1:186` 的模型级反例）。⇒ 反常的"定义性贡献"落在 `ℋ_struct` 里，**不构成一条新输入**。

> **窗口限定（本文件补，`AGENTS §2.1`）**：这条定义在 `β_YM=0`（自由 `U(1)`）上**退化**（`s ≡ 0`、`ρ_s = δ₀`）。故"`s := T^μ_μ` 良定义"只对 `β≠0` 的非共形理论成立。这与 `H03:181` 不冲突（它写的是 YM），但下游若把 `s` 用到自由场上必须先声明 `g>0`。

### 2.2 把"耦合"写成可判的判据 **COUP**（本文件的可复用产物）

"耦合到谱底"这句话在仓内一直是口语。它必须落成一条**方向正确的蕴含**：

```
判据 COUP.  反常量 A 能耦合到谱底 ⟺ 存在 c>0 与 g:(0,∞)→(0,∞)，g 在紧集上有界、
            g(t)→0 **只当** t→0，使下述之一在某个模型类上已证：
   (COUP-i)   A ≤ c·g(m₁)          （越接近无隙，A 越被压小 ⇒ 反解给 m₁ 的下界）
