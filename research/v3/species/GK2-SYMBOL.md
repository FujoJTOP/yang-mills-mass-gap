## §1 二阶展开与 `c₁, c₂`

### 1.1 记号与精确恒等式（零内容，但把 `a`-依赖归位）

沿用 `GL-B:270–271` / `GR1:84–88` 的设定：`H_a := −(1/a)log T_a`、`Δ_a := inf{λ∈σ(H_a): λ>0}`、`Δ_cont := inf{λ∈σ(H): λ>0}`。固定 `L`（`GR1:82`）。定义 **sinh-mass**：

```
ω_a  :=  (2/a)·sinh(a·Δ_a/2)        （= 谱演算下的 (2/a)·sinh(aH_a/2) 的边缘本征值）      (SM-def)
```

`sinh`/`asinh` 在 `[0,∞)` 上互逆且严格增 ⇒

```
Δ_a  =  (2/a)·asinh(a·ω_a/2)                                                              (SI-1)
```

**(SI-1) 是恒等式**：它对任何 `H_a` 成立，因而**没有内容**；它的用处是把 `Δ_a` 的 `a`-依赖**分成两块**，其中一块是**通用**的（`asinh` 核，显式），另一块是模型的（`ω_a`）：

```
Δ_a  =  ω_a · [ 1 − (aω_a)²/24 + 3(aω_a)⁴/640 − … ]                                        (SI-2)
```

`(SI-2)` 的系数是 `asinh` 的 Taylor 系数（`asinh x = x − x³/6 + 3x⁵/40 − …`，`x = aω_a/2`），**与模型无关**。

**自由场的特殊地位（本轮的结构性事实）**：自由有质量场（`p⃗=0` 扇区）的 `Δ_a` 由 `cosh(aE) = 1 + a²m²/2` 给出（`GR1:234`），即

```
Δ_a^free = (2/a)·asinh(a m/2)   ⇒   ω_a^free = (2/a)·sinh(aΔ_a/2) ≡ m  （精确，与 a 无关）   (1.1)
```

`[E]`：`sinh_mass(a, Δ_free(a,m)) − m` 在 `a ∈ {10⁻³,10⁻⁶}`（`m=1,2`）上 `= 0.000e+00`，在 `a=10⁻¹` 上 `= 2.2e−16`（机器精度）（`gk2sym_check.log [7]`）。
⇒ **自由场里 `Δ_a` 的整个 `a`-依赖都在 `asinh` 核里**；`ω_a` 本身是 `a`-无关的。这一点是下面所有"自由场精确"的来源，也解释了为什么自由场不需要任何展开控制（§2.1）。

### 1.2 `c₁, c₂` 的通用显式式（`[T]`，纯代数）

设 `ω_a = Δ_cont + δ₁a² + δ₂a⁴ + O(a⁶)`。把 `(SI-2)` 展开到 `t = a²` 的第二阶：

```
Δ_a = ω_a − (a²/24)ω_a³ + (3a⁴/640)ω_a⁵ + O(a⁶)
    = Δ_cont + a²[δ₁ − Δ_cont³/24] + a⁴[δ₂ − 3δ₁Δ_cont²/24 + 3Δ_cont⁵/640] + O(a⁶)
```

⇒ 按 `Δ_a = Δ_cont(1 + c₁a² + c₂a⁴ + …)`：

```
c₁  =  δ₁/Δ_cont  −  Δ_cont²/24                                                          (1.2a)
c₂  =  δ₂/Δ_cont  −  δ₁·Δ_cont/8  +  3·Δ_cont⁴/640                                       (1.2b)
```

**核**（`gk2sym_check.log [2]`，`Fraction` 精确、无浮点）：`(D,δ₁,δ₂) = (1,0,0), (1,7/10,−2/5), (3/2,−1/3,5), (5/7,2,−11/3)` 四组，`c₁,c₂` 与 `(1.2)` 逐位相符（例：`D=1,δ₁=0,δ₂=0 ⇒ c₁=−1/24, c₂=3/640`）。`[T]`

**任务书要的就是 (1.2a)(1.2b)**：它们把"`c₁,c₂`"从"某个算子期望"变成"`ω_a` 的 `a`-系数"。剩下的问题全部转移到 `δ₁,δ₂` 上。

### 1.3 自由场：`c₁ = −m²/24`、`c₂ = 3m⁴/640`（精确，且是 (1.2) 的推论）

由 (1.1) `δ₁ = δ₂ = 0`，代入 (1.2)：

```
Δ_cont = m ⇒  c₁ = −m²/24 = −m³/(24Δ_cont)  ✓（任务书给的值）
              c₂ =  3m⁴/640 = 3m⁵/(640Δ_cont)                                             (1.3)
```

**`Fraction` 精确核**（`[1]`）：`m = 1, 2, 3, 1/2` 分别得 `c₁ = −1/24, −1/6, −3/8, −1/96`，`c₂ = 3/640, 3/40, 243/640, 3/10240` —— 与 `−m²/24`、`3m⁴/640` 分数相等（`OK`×8）。`[T]`+`[E]`

**注（自由场里二阶谱和恒为零，原因见 §3.1(c)）**：`(1.3)` 的 `c₂` 全部来自 `⟨K₄⟩₁/Δ_cont`，二阶项 `≡0`。这不是巧合：`K₂ = −ω³/24` 是 `H` 的函数，与 `H` 对易 ⇒ 谱和（§1.4 的 `(1.4c)`）无中间态可去。

### 1.4 算子形式（RS 二阶微扰）：把 `δ₁,δ₂` 写成矩阵元（`[T]`，给定 `H_a = H + a²K₂ + a⁴K₄ + …`）

设（**展开假设 (EXP)**）在公共核上 `H_a = H + a²K₂ + a⁴K₄ + R_a`，`|⟨R_a⟩| ≤ C_R a⁶`，`K₂,K₄` 对称。记 `ψ₁` 为边缘本征向量、`⟨·⟩₁ = ⟨ψ₁|·|ψ₁⟩`。Rayleigh–Schrödinger：

```
c₁  =  ⟨K₂⟩₁ / Δ_cont                                                                     (1.4a)
c₂  =  ⟨K₄⟩₁/Δ_cont  +  Δ_cont^{-1}·Σ_{n≠1} |⟨n|K₂|1⟩|²/(Δ_1 − Δ_n)                       (1.4b)
```

两个立刻可用的推论：

1. **谱和恒 `≤ 0`**（每项分母 `Δ_1−Δ_n < 0`，分子 `≥0`）⇒ 二阶项**只会把 `Δ_a` 往下拉**。用谱定理把它写成**范数**（这是 §3 的关键形式）：
   ```
   Σ_{n≠1}|⟨n|K₂|1⟩|²/(Δ_1−Δ_n)  =  −‖ (H−Δ_1)^{-1/2} K₂ ψ₁ ‖²                            (1.4c)
   ```
2. **(1.4a) 与 (1.2a) 的桥**（把 `K₂` 与 `H³/24` 合并成 sinh-mass）：
   ```
   ω_a = (2/a)sinh(aH_a/2) = H + a²(K₂ + H³/24) + O(a⁴)   ⇒   δ₁ = ⟨K₂⟩₁ + Δ_cont³/24       (1.4d)
   ```
   代回 (1.2a) 得 `c₁ = ⟨K₂⟩₁/Δ_cont + Δ_cont²/24 − Δ_cont²/24` ✓（自洽）。
   **(1.4d) 是本文最有用的一行**：`−Δ_cont²/24` 是 `asinh` 核的**通用**贡献，`δ₁` 是 `K₂` 相对"被 `H³/24` 抵消后"的**残差**。自由场的 `c₁ = −m²/24` 之所以"普适"，是因为自由场里 `K₂ = −H³/24` **逐算子**成立（`K₂ = −ω³/24`，`H = ω`）⇒ `δ₁ ≡ 0`。

### 1.5 与任务书前提的偏差（必须记）：四阶符号差在边缘为零

任务书给 `h(k) = 4Σsin²(k_i/2) = |k|² − a²Σk_i⁴/12 + O(a⁴)`，并说"差的领头项是四阶且与 `Σk_i⁴` 有关"。这句话**对符号成立**，但对 `c₁` **不成立**：

- `𝔟_a(k) := h(k) − |k|²` 是**乘子**；其边缘期望 `= 𝔟_a(0) = h(0) − 0 = 0`（逐位）。⇒ **一阶贡献 `⟨K₂^{sym}⟩₁ = 0`**。这是 `GR1-SPECRES.md:241` 的 Cor-T2-3（`[T]`），本轮独立复算。
- 所以 `c₁` 的来源**不是** `Σk_i⁴`（T2），而是 `asinh` 核（T3/`log-cosh`）：`−Δ²/24`。
- `Σk_i⁴` 的唯一出路是**二阶**：它在 `n=1` 上为零，但在 `n≠1` 上有非零矩阵元，于是进入 `(1.4b)` 的谱和。**这正是 §3.1 发散项的来源**。

⇒ 任务书"把火力压在四阶张量各向异性上"这个指向，在**阈值**（`1−4/π²`，`GR1:229`）上对，在**速率**上错位一格：`c₁` 由 `asinh` 给，`Σk_i⁴` 只支配 `c₂`，而 `c₂` 是发散的那一项。`[T]`

## §2 符号判定

### 2.1 自由场：`c₁ < 0` 是**恒等**，`k=2, C=m²/24` 逐 `a` 成立（`[T]`）

由 (1.1) 与 `asinh x ≤ x`（`x ≥ 0`）：

```
0 ≤ m − Δ_a = m[1 − asinh(x)/x],   x = am/2
```

1. `asinh x ≤ x` ⇒ `m − Δ_a ≥ 0`（`g₂(x) := x − asinh x`，`g₂' = 1 − (1+x²)^{-1/2} ≥ 0`，`g₂(0)=0`）。
2. `asinh x ≥ x − x³/6` ⇒ `m − Δ_a ≤ m x²/6 = a²m³/24`。证：`g(x) := x − x³/6 − asinh x`，`g(0)=0`，`g'(x) = 1 − x²/2 − (1+x²)^{-1/2}`，`g''(x) = x[(1+x²)^{-3/2} − 1] ≤ 0`（`x≥0`）⇒ `g' ≤ g'(0) = 0` ⇒ `g ≤ 0`。∎

⇒ **精确双边**：

```
0  ≤  1 − Δ_a/m  ≤  a²m²/24          （∀a>0, ∀m>0）                                          (2.1)
```

`[E]`：`a ∈ [10⁻¹²,10⁻¹] × m ∈ [10⁻⁴,10⁴]`，108 点，**0 违反**（`Decimal` 200 位；`[3]`）。
⇒ `|Δ_a/Δ_cont − 1| ≤ C a^k` 取 **`k = 2`、`C = m²/24`**，**`(L,a)`-无关**（`L` 根本不出现：边缘是 `k=0` 模）。这是 `QSPEC-C*` 在自由场上的**逐字成立**，而且是 `[T]`（不靠任何余项估计）。`[T]`+`[E]`

### 3.2 sharp Gårding 是否压得住？**判：压不住**（两条独立理由）

**(a) 假设不成立（结构性）。** sharp Gårding 的定式是：`a ∈ S¹`、`Re a ≥ 0`（`|ξ|` 大）⇒ `Re⟨a(x,D)u,u⟩ ≥ −C‖u‖²`（`[R]`，见 §5.1 检索；Fefferman–Phong 给锐化常数，矩阵/系统版见 `[R]`）。而本文要压的对象是 `K₂ + H³/24` 的**符号**：它的 `2adF` 型片**不定**——这正是 Savvidy 的 `Hess = −D² + 2adF_B` 不定（`CLAUDE.md §5`：负模横向磁，规范商后仍在，`W4` 实测 `7.1%` 负）。⇒ **假设在这一片直接失效**，不是"常数不够好"，是"没有可用的 `p ≥ 0`"。

**(b) 假设成立的扇区里，它的输出就是 `2/(m+2)`（结构性的）。** 即便取 `p ≥ 0` 的扇区，sharp Gårding 的输出是 `≥ −C‖u‖²`，`C ~ ‖系数‖_{C¹}`；格点上系数由 `F` 组成，`F ~ a^{-2}`（格点单位）⇒ `C_ε` 随截断按幂增长，写成仓内形式就是 `C_ε ~ ε^{-m}`（`GP9-RB:120`，`m` **未逐字核**，`GR1:434` 记 `[R]`）。代回：

```
取 ε = a^α  ⇒  b(α) = C_ε·a²/ε = C·a^{2−(m+1)α}
指数 = min( α , 2−(m+1)α )  ⇒  最优 α* = 2/(m+2)  ⇒  k ≤ 2/(m+2)                        (3.3)
```

⇒ **Gårding 不是新工具，是 KLMN 前沿的另一个坐标**。`[T]`（代数）+`[R]`（定式与 `C_ε` 增长阶）

**一句总结**：Gårding 的两个常数（`−C` 的 `C`、`ε` 的代价）在 `(3.3)` 里**互相吃掉**，剩下的指数与 KLMN 逐位相同。要跨过 `2/(m+2)`，需要的**不是**更强的伪微分不等式，而是**精确重求和**（自由场的 `asinh` 就是那个重求和）。
