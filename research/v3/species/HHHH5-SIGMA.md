## §2 `k` 的量词

1. **`L3` 本体（固定 `L` 的 UVS）量词串**：`∃a₀(L) ∃{C_n(L)}_{n≤n₀} ∀a∈(0,a₀] ∀n≤n₀ ∀f₁…f_n`
   （`HQ1-L3.md:38`）；同文件 `:48` 逐字「量词 `∀n, ∀f_i, ∀a≤a₀(L)`；**`L` 固定**」；`:49` 逐字「`k` = 检验函数的 `C^k` 阶」。
   ⇒ **块层号 `k` 不在 `L3` 里**。塔由**壳号 `j`** 承载：`j=j*,…,J`、`J∼⌊log(1/aΛ)⌋`（`HQ1-L3.md:75`；`PROOF-L3.md:6`）。
2. **两个 `k`（撞名，非缺口）**：(i) 粗化块层 `a_{k+1}=b a_k`（`fax:22385`），窗为 `σ ≪ a_k ≪ ξ*`（`fax:23759`）；
   (ii) 细化塔 `a_k=b^{-k}a₀ ↓ 0`（`fax:25735`·`29552`），连续极限「`k → ∞`」（`fax:5271`·`26341`·`29553`）。
   同一撞名已被 `ZZZ1-ZO.md:36`（「两处方向并存」）、`GGGG2-SYNC.md:12`（§0.4）登记。
3. **`ι_k` 那处的 `k` 是 (ii) 型的索引，且常数对 `k` 一致**：`fax:26223`「For each `k`, define the embedding `ι_k`」；
   `fax:26248`「`C_{s,O}` **independent of k, L, and T**」；极限沿**子列** `k_j → ∞`（`fax:26341`）。
   ⇒ 走这条路要的正是 `∀k` 的一致界，而构造**已给**（`∀k` 成立，不是「只对小 `k`」）。
4. **【量词结论】** `L3` 对块层 `k` **无**量词；对 `a` 是 `∀a≤a₀`（等价细化侧 `k→∞`），对 `j` 是 `∀j∈[j*,J]`。

## §3 判定：`a_k σ ≥ 8` 是 `∀k` 还是有限范围

1. **它在文本里不是公理，是引理的假设**：`j*` = 「largest integer with `L^{j*}σ ≤ c_* b a_k`」（`fax:22404`），
   其消费者 Lemma 6.3 的树界常数「`A, B` **independent of `k`**」（`fax:22419`）。⇒ 该条件的作用是**换取 `k`-一致性**。
2. **方向**：`a_k = b^k a` 递增 ⇒ `a_kσ` 递增 ⇒ `j*≥0` 是 `k` 的**下界**（`k ≥ k₀`），不是上界。
   `docs` 写「只对 `k ≤ k_max`」把不等号翻了一次；真正的上端来自窗 9.71 的 `a_k ≪ ξ*`（`fax:23759`·`23767`）。
3. **窗深度**：`k ∈ [k₀, k₁]`、`k₁ = log_b(ξ*/a)`（`fax:23767`：`σ` 与 `ξ*` 均 `k`-无关 ⇒ 窗非空只要 `a ≪ ξ*` 初值）。
   ⇒ 「有限个 `k`」为真，但它是**每个 `a` 内的有限塔**，且下端/上端都由**固定物理尺度**（`σ`、`ξ*`）钉住，
   **不需要** `σ = σ(k)` 来维持——`j*` 逐层自行调整就够（`fax:22430`·`22471`）。
4. **即便真想动 `σ`，也不是缺口**：换 cutoff 的稳定性是命题（`fax:18662–18696` Prop 12.4「qualitative spectral properties … independent of the specific cutoff」）、
   对 `σ` 可微（`fax:23783`）、`σ` 在紧集内任取（`fax:28489`）、`σ ↦ T_σ` 强连续（`fax:24185`）。
   ⇒ `σ = σ(k)` 若需要，代价是常数随 `σ` 变（`C(σ)`，`fax:18673`），不是构造存在性。
5. **裁决**：`a_k σ ≥ 8` = **`∀k` 在 9.71 窗内**（`[T]`，算术 + `fax:22419` 的 `k`-一致），不是 `∀k∈ℕ`。
   标它为「`k→∞` 的结构性障碍」= `[NG]`。**障碍消失**（与 `GGGG2-SYNC.md:14` 同向；本轮新增 0.4 的算术勘误与 §2 的量词定位）。
6. **残余（不是障碍）**：`(σ, c_*, B)` 三元组无值（`fax` **0 命中**）；`σ` 的量纲在式 4.12（动量）与 `22327`（长度 `σ^{-1}`）间有抽取层不一致。
