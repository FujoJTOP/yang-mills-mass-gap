## 3 · 为什么上界载重（代数，不是修辞）

窗口定理 `T3-B`（`T3-TP2:211-222`，`[T]`）：

```
Δ := Λ★ − m₁² = μ₂ − μ₁ = (ρ² − 1)·μ₁ ,            (identity, machine-precision)
(i)   [1+c ≤ ρ² ≤ C²] ∧ [Δ ≥ δ]  ⇒  μ₁ ≥ δ/(C²−1) > 0
(iii) ρ² unbounded ⇒ (i) fails: fixed Δ=δ, ρ²→∞ ⇒ μ₁ = δ/(ρ²−1) → 0
```

**双井见证 W4**（`T3-TP2:228-233`，`[T]+[V]`）：`g = 8` → `μ₁=0.119`、`Δ=13.12`、`ρ²=111.2`；
`g = 16` → `μ₁=4.57e−3`（Kramers `~e^{−S}` 塌缩）、`Δ=27.92`、`ρ²=6105`。隔离最强、隙为零。

**载重的准确含义**：`ρ²` 是大是小本身不产生信息；产生信息的是 **"上界 + `Δ` 有地板" ⇒ `μ₁` 有地板**。
即上界挡的是 **分母塌缩**（固定 `Δ` 时 `ρ²→∞ ⇔ μ₁→0`），不是"`Δ` 变大"。

### 3.1 你的两段读法：一句错、一句对

1. **"`ρ²` 大 ⇒ `Δ` 大" —— 方向反了（这是要纠正的那一句）。** `Δ=(ρ²−1)μ₁`：`ρ²` 与 `Δ` 同向只在
   **固定 `μ₁`** 时成立；定理 (iii) 用的是**固定 `Δ`** 的族，那里大 `ρ²` ⇔ **小 `μ₁`**。所以上界不能
   读成"让 `Δ` 更大"，只能读成"**禁止 `ρ²` 跑到 `∞` 去把 `μ₁` 压到 0**"。
2. **"`ρ²` 太大 ⇒ 次一谱点太远 ⇒ 那不是 `0⁺⁺` 的第二态而别的东西" —— 物理指称上对。**
   `C=2` 的阈值读法逐字是 `ρ² ≤ 4 ⟺ √e₂ ≤ 2√e₁ ⟺ m₂ ≤ 2m₁`：**第二 `0⁺⁺` 在两胶子割以下 = 原子**；
   `ρ² > 4 ⇒ m₂ > 2m₁` ⇒ "第二层"落在**连续割**上，不是道内原子（`DT-DIRICHLET:53`；
   `E2-FLIP-KINEMATIC §0/§2`：把割当第二层代入会返回**假的偏高的下界**）。
3. **但逻辑上它仍不是新通道**：`ρ²≤C²` 经 Ky Fan 等价于 `e₁ ≥ t/(1+C²)`（`ch05:171-180`），
   即对 `e₁=μ₁` 的下界 —— 与 H1 同物（见 §4）。
4. **附加构造性事实（`RB-RATIO-BOUND:1`）**：双井的 `ρ²→∞` 是**分母塌缩**；任何"只给分子半上界"的
   机器（rank-2 迹只给 `e₁+e₂`）在构造上**看不见**它 —— 分母半必须是比较算子 = 禁闭动力学。

## 4 · 可证性：(a)/(b)/(c) 判

**逐字（`ch05-theorems.tex:178-180`）**

```
$\rho^2\le C^2\iff e_1\ge t/(1+C^2)$: a thresholded floor. \LN{} (named class): the window therefore
inherits H1 rather than adding a fourth independent predicate, and it \textbf{cannot be used as a new
sufficient condition}.
```

**逐字（`ch02-squeeze.tex:219-223`）**

```
If $I_2$ is consumed through the window theorem $\rho^2\le C^2$ ..., its constant must be $C=2$, not
$1.5$, and the floor it yields is $m_1^2\ge\Delta/3$ ... Since $\rho^2\le C^2\iff m_1^2\ge t/(1+C^2)$
with $t=T_2(V)$ a computable rank-2 trace, $I_2$ \emph{inherits} H1 and cannot be used independently
of H1.
```

### (a) 可证且 `C` 有值 ⇒ 给 `C` 与证明 —— **`C` 有值，但"独立证明"不存在**

- **有值**：`C=2`（§2）。
- **无独立证明**，且有**已知 no-go**（`DT-DIRICHLET:DT-2(b)/DT-3`、`AUDIT-CH16:H3`）：
  **单侧 floor ⇏ 比值上界**。见证书面：`ρ² = 27.1846 @ e₁ = 18.0963 ≥ π²`（`AUDIT-CH16:35` 逐字
  "见证 B `ρ²=27.1846$ @ $e_1=18.0963\ge\pi^2`"）、非局部正项 `ρ² = 4+M/π² = 4.5, 9.0`、
  rank-`r` `4,9,16,24,…`（**无界**）。合法形式只能是**双侧**比较
  `c₋L₀ ≤ L ≤ c₊L₀ ⇒ C = 2√(c₊/c₋)`，`C=2 ⟺ c₊=c₋`（"两端钉住"），且还要下面的谱非退化。
- **结论**：上界的"载重"是**定理结构上的必要合取项**（去掉它 T3-B(i) 假，双井见证）；它**不是**
  可独立供给的输入。⇒ `T3:240` 与 `ch05:178-180` 两句话**相容且不矛盾**：T3 说它在**蕴含式里**载重，
  ch05 说它**不能当新的充分条件**。两句合起来就是一句话：**上界载重 = 它不是装饰，但它没有新内容。**
- **数值上更糟**（`ch13:505-508` 逐字）：`t/t★ = 3.28–273` ⇒ Ky Fan 界松 `3.8–279×`，
  `e₁ ≥ t/5` 需要的地板是真值的 `3.3–2671` 倍 ⇒ **`t/e₁` 这条"继承 H1"的路在 `β=2.5` 无数值希望**（`[E]`）。

### (b) `C` 无值 —— **不成立**（`C=2` 有值，类内精确饱和）

### (c) "上界载重"理解错了 —— **部分成立**：错的只有 §3.1 第 1 句（`ρ²` 大 ⇒ `Δ` 大）；
第 2 句（"第二层不是 `0⁺⁺` 态"）是 `C=2` 的**正确物理指称**，不是误解。

## 8 · ≤240 字答复（供汇总）

`C` 有值但是类常数：`C=2`（`C²=4`，Dirichlet 型塔类内尖锐、精确饱和 `4.000000`；类外 `ND=9`、
