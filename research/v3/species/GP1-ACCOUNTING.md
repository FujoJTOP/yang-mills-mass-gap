## §1 真空能扣除（任务 1）

### §1.1 真空能在核里——三条恒等（`[T]`，三行）

把 `b_a` 写成**定义**，不是写成"含有什么"：

```
(E1)  𝔮(ψ) = ‖H^{1/2}ψ‖² ,  𝔞_a(ψ) := 𝔮_a(ψ) − 𝔮(ψ)            （GP9:41–47 逐字）
      ε_a := sup_{ψ⊥Ω} |𝔞_a(ψ)| / 𝔮(ψ)
      b_a := inf{ b : |𝔞_a(ψ)| ≤ ε_a𝔮(ψ) + b‖ψ‖² ,  ∀ψ∈Q }      （GR2 §3.2 的"座 2"就是这个有限的 b_a）
```

取任意 `c-数` `c_a`（真空能、单位、`1/a` 归一——`GP9:114` 的 T1 全在此列），`H_a ↦ H_a + c_a·1`：

1. `𝔮_a ↦ 𝔮_a + c_a‖ψ‖²` ⇒ `𝔞_a ↦ 𝔞_a + c_a‖ψ‖²`；
2. `Δ_a` 是**间距**（`inf σ(H_a)∩(0,∞)`，在"基态在 0"的代表上取）；平移后必须重取代表，而 `(NEW)`/COST 消费的正是间距 ⇒ **不变**；
3. `b_a ↦ b_a + c_a`；而 `w₁ = f₁²/M₀` **根本不含 `b`**（`U4:101–104`）⇒ `(EDGE-ATOM)` 侧完全不动。

**一处必须补的定义缺陷（`[T]`+`[M]`）**：若 `ε_a` 用 `GP9:44` 的 sup 定义 `ε_a := sup_{ψ⊥Ω}|𝔞_a|/𝔮`，则它**不是**归一化不变的——由 `𝔮(ψ) ≥ Δ_a‖ψ‖²` 得 `ε_a ↦ ε_a + |c_a|/Δ_a`。⇒ **`(E1)` 的平移不变性以 `Δ_a>0` 一致为前提，而"`Δ_a>0` 一致"正是要证的东西（循环）**。归一化不变的对象是**集合**
```
E_a := { (ε,b) ∈ (0,∞)×[0,∞) :  |𝔞_a(ψ)| ≤ ε𝔮(ψ) + b‖ψ‖²  ∀ψ∈Q } ,
```
它对平移只改第二坐标；`(RB)` 消费的是 `{(ε,b)∈E_a : ε<1, b<∞} ≠ ∅`（且一致）。⇒ **"真空能在核里"的精确形式 = 这个非空性对 c-数平移不变。**

⇒ **判（任务 1 的第一半）：真空能扣除是免费的，而且它不是"扣"，是"商"**——`b_a` 的定义里的 inf 本来就在 c-数商上取值；"`b_a − E_a^{vac}`" 只是把商写出来。这与 `GS1-SEAT2:0.5`（"`b`-槽是规范方向"）同结论，且与 `GP9:114` 逐字一致（T1 是**约定**，不是定理）。**唯一要改的是 GS1 那句"`ε_a` 不动"**：它对 sup 定义不成立，对 `E_a` 的非空性成立。

**一条必须同时记的记账错误**：`GR2:193`／`GS1-SEAT2:4` 把座 2 写成 "`b_a ≤ b`"。按 `GO2:129–133` 的双边界
```
(COST-i)   (1−ε_a)Δ_cont − b_a  ≤  Δ_a  ≤  (1+ε_a)Δ_cont + b_a ,
```
`b_a` 与 `Δ_cont` **同量纲**（能量，量纲 1），而这条不等式**有内容**（能推出 `Δ_a>0`）**当且仅当** `b_a < (1−ε_a)Δ_cont`。⇒ **"`b_a ≤ b`" 的正确无量纲化是 `b_a/Δ_cont < 1−ε_a`，不是 `b_a ≤ b`。** 写成 `b_a ≤ b` 会丢掉分母 `Δ_cont`，从而把一个**约定量**误读成一个**广延量**（§1.5 的勘误 A 就是这么来的）。`[T]`（定义展开）+ `[M]`（记账）。

### §1.3 扣不掉的那个量：具名证书

> **（GP1-CERT-1）** 扣掉 c-数后，`(RB)` 座 2 的剩余物是

> **名字**：相对形式有界性（KLMN 型）；**量纲 0**（松弛/能量）；**不是能量**（是否仍 `∝V` 见下）。

**为什么它不是纯真空能（四条，各自可核）**：

1. **它对 c-数平移不变**：§1.1 的三条恒等；真空能一动就变的东西不是它。
2. **它在零真空能的族里为假**：§1.2 的见证（`GP9:261–267`）。
3. **它是一个算子性质，不是一个数**：`(FB)` 量化的是 `𝔞_a^{Q}` 这个**形式差**，而不是任何期望值；`GP9 §1.0`（`:34–39`）已把它钉死为"没有 `ι_a` 就没有对象"⇒ 它的自变量是**识别**，不是零点。
4. **它在自由场上精确为真且 `b=0`**：§1.2 的对照 ⇒ 它不是"总是发散"的量，不能拿"UV 散"当名字。

**它为什么也不是"广延量"（这里必须改 `GR2`/`GS2` 的账）**：`b_a ∝ a^{-4} ∝ N_p`（`GS2:56`）**只在 `b_a = E_a^{vac}` 时成立**。商掉之后 `b_a^{Q}` 是否仍 `∝ V`，本文件**未证**（`[NG]`）；但把 `b_a ∝ N_p` 当作已证的**座 2 属性**，是**没有依据的**：它继承自 §1.5 勘误 A 的那个等同，而那个等同被 §1.2 否掉。⇒ **座 2 的正确标签是"未证的相对形式有界性"，不是"未付的广延量"。**

1. **`M₀` 与 `∂²_βlog Z` 是同一族的不同成员**：KL 侧的 `M₀=C(0)=Var(O^{slice})` 取**单时间片**零动量算符（`GR2:104`、`P3:61–69`），而 `O_B=Σ_{p∈4D}s_p` 是**全 4D** plaquette 和 ⇒ 两者差**一个时间求和**与**类时 plaquette**。若忽略类时 plaquette（`[M]` 级近似），`Var(O_B) = L_t·Σ_{τ∈ℤ}C(τ)`，而 `M₀=C(0)` 是它的 `τ=0` 项；**精确恒等只对 4D 成员成立**（`GA4:76–77`）。`[T]`（展开）+ `[M]`（两成员不许混称）。

### §4.3 判：**不是同一个债**——三点差异，各自 `[T]`
