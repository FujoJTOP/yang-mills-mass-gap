## §1 `p=d` 的尖锐性（三件：维数恒等式 / 公理零信息 / 压线级）

**1.1 维数恒等式（`[T]`）。** `S_p=Σ_n c_n n^{-p}`、`c_n` 是 `ℓ¹` 球面点数、`c_n~(2^d/(d−1)!)n^{d−1}` ⇒ `p=d` 处被积项 `~ (2^d/(d−1)!)/n`，收敛判据 `p>d`。`d=4`：系数 `16/6=8/3`、`S_4` 逐段 `+6.046/+6.129/+6.139 → (8/3)ln10=6.1402`。**这条与测度无关**：它只数格点。

**1.2 公理在 `p=d` 处零信息（`[NG]`）。** 见证 `δ₀`：`C_q(z)≡Var·δ_{z0}` 满足 C–S（`|C_q|≤Var`）、PSD（`Ĉ≥0`）、RP、求和规则，且 `|q|≤2 ⇒ Var≤1`，全在公理类内；但它给 `Tail_p(R)=sup_{|z|_∞>R}|z|^p|C_q|=∞`。⇒ **紧致性（`|q|≤2`）恰好只能关内箱、对尾零判别力**（`QQ6:0.6` 的 `δ₀` 已把这条判死，本路只把它改写成"等号不可消费"的形式）。**下一手**：任何"用有界性/紧致性造尾率"的提案，先过 `δ₀`。

**1.3 压线级（`[T]`）。** 指数阶梯由**链数**给：`q_x=1−N^{-1}Re tr U_□` 是 4 链之积，`⟨q_0q_z⟩_c` 的配对第 `k` 级给 `p_k=k(d−2)`（`k=1`：RP 量纲 `p=2`；`k=4`：Wick/自由场 `p=2d=8`）。判据要 `p_k>d`：
```
p_k − d = k(d−2) − d ；  k=2 ⟹ = d−4 ；  k=3 ⟹ = 2d−6
d=3: p_k=1,2,3,4 → 需 k=4        d=4: p_k=2,4,6,8 → k=2 压线，需 k=3
d=5: p_k=3,6,12  → k=2 已过（余量 1）
```
⇒ `d=4` 的"尖锐"= 最省的非平凡配对 `k=2` 恰好落在 `p=d` 上，于是**没有 `ε` 可拿，只有 `log`**。这就是"等号是维数给的"的精确读法，也是 `II9:0.5` 里"无 `ε`/无窗/无 `log`"那句的补注：判据本身无 `log`，但**压线处的供给**只能是 `log`。
