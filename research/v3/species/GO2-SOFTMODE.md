## §1 路 A（构造）：有限重 / 紧预解版本**能造**——一支就够，"移植 + 尾移"

### §1.1 卡点复述与答案

`GN3-SPECTRAL.md:183` 把有限重情形记 `[O]`，理由是构造 E 把**无限重**注入了 `1`-能级：`H=1−|e₀⟩⟨e₀|` 在 `{e₀}^⊥` 上恒为 `1`（`:190`），故 `w_a` 可摊在无穷多个**同能级**方向上，"强零而不范数小"（`A_a→0` 强、`‖A_a‖≤1`）。问题（任务书原话）：**能不能用有限多支"携带"同一个 `ε_a` 而不违反 PF/Hausdorff？**

**答案 `[T]`：不需要多支，也不需要简并。** 无限维的"房间"由**无界谱**（紧预解 ⇔ `λ_n→∞`）提供，而不是由某个能级的重数提供。做法不是"在简并里摊"，而是**把第 `N_a` 支整体移植到 `ε_a`，并把尾巴下移一格填洞**：

```
ℋ = ℓ²(ℕ₀), 基 (e₀,e₁,e₂,…)
H    := Σ_{n≥1} n|e_n⟩⟨e_n|                  （σ(H)=ℕ₀，全单重，ker H=ℝe₀，Δ_cont=1，紧预解）
N_a ↑ ∞,  0<ε_a<1
H_a  := diag( 0, 1, 2, …, N_a−1, ε_a , N_a , N_a+1 , … )     （第 N_a 支 → ε_a；n>N_a 的第 n 支 → n−1）
等价地  H_a = H + A_a ,  A_a = −(N_a−ε_a)|e_{N_a}⟩⟨e_{N_a}| − P_{>N_a} .
```
即 `H_a e₀=0`；`H_a e_n = n e_n (1≤n<N_a)`；`H_a e_{N_a}=ε_a e_{N_a}`；`H_a e_n=(n−1)e_n (n>N_a)`。

### §1.4 对"PF/Hausdorff"这一问的直接回答

- **Hausdorff**：**不违反**，而且**必须**用尾移才不违反——这正是 `GN3:182` 那条"更强形式也堵不住"在有限重情形下的**精确对应物**：额外谱点落在 `ε_a`（离 `0∈σ(H)` 只有 `ε_a`），洞由尾巴补。
- **PF 单纯**：**不违反**（核一维）。若把"PF"强化成"`e^{−tH_a}` 严格正（positivity improving）"，可加**范数任意小**的 hopping 项 `−δ_a(S+S^*)`（`δ_a=o(ε_a)`）：本征值移动 `≤2δ_a`（Weyl），软模保持，`H_a≥0` 与紧预解保持，而离散 Laplacian 型半群在半直线上严格正。**记 `[C]`**（`S+S^*` 的严格正性未逐条写出）。
- **多重数**：**不是**载体。`w_a` 不需要摊在同能级上；需要的只是**指标** `N_a→∞`。
- **转移矩阵**：取 `T_a:=e^{−aH_a}`，则 `0≤T_a≤1`、`T_aΩ=Ω`、`H_a=−(1/a)log T_a` **逐字成立**（对角谱演算）⇒ 本族在"转移矩阵"意义下是**合法的抽象家族**。⇒ 挡住它的**不是**"转移矩阵/PF/紧预解/强预解/Hausdorff"这一组抽象结构，而只能是**几何实现**（`H_a` 必须来自同一个格点理论的 `a`-细化）与 §2 的 `(RB)`。这一句是本轮负面结论的**最强形式**。

### §1.5 代价：从"多重数"搬到"相对界"

```
‖A_a‖ = N_a − ε_a → ∞
ε_a^{form} := sup_{ψ} |⟨ψ,A_aψ⟩| / ‖H^{1/2}ψ‖² = (N_a−ε_a)/N_a = 1 − a² → 1
‖A_a(H+1)^{-1}‖ = (N_a−ε_a)/(N_a+1) → 1
```

## §2 路 B（排除）：四机制逐条判

### §2.0 主结果：定理 COST（本轮唯一的正面定理，3 行 + 3 行）

设定同 `REPORT.md:267–275`：固定空间，`H_a,H` 自伴、`H≥0`，`H_a→H` 强预解（`SPEC-RES`），`ker H=ker H_a=ℝΩ`，`Δ_cont:=inf{λ∈σ(H):λ>0}∈(0,∞)`，`Δ_a:=inf{λ∈σ(H_a):λ>0}`。**紧预解**：`(H+1)^{-1}` 紧（⇔ `λ_n→∞`）。设 `H_a` 由形式 `𝔮_a=𝔮+𝔞_a` 给出（`𝔮(ψ)=‖H^{1/2}ψ‖²`，公共形式域 `Q=D(H^{1/2})`），且

> **(i)（双边界，不需要 SPEC-RES）** `(1−ε_a)Δ_cont − b_a ≤ Δ_a ≤ (1+ε_a)Δ_cont + b_a`。

*证 (i).* `Δ_a = min_{ψ∈Q, ψ⊥Ω, ‖ψ‖=1} 𝔮_a(ψ)`（紧预解 + 核一维 ⇒ 下确界取到）。下界：`𝔮_a ≥ (1−ε_a)𝔮 − b_a ≥ (1−ε_a)Δ_cont − b_a`（用 `H ≥ Δ_cont` 于 `Ω^⊥`）。上界：取 `ψ=e₁`（`Δ_cont` 的本征向量），`Δ_a ≤ 𝔮_a(e₁) = Δ_cont + 𝔞_a(e₁) ≤ Δ_cont + ε_aΔ_cont + b_a`。∎

```
(1−ε)⟨φ_a,Hφ_a⟩ ≤ E_a + b ≤ E_* + b        ⇒   ⟨φ_a,Hφ_a⟩ ≤ C := (E_*+b)/(1−ε) .
```

### §2.1 机制 1（**重点**）："紧群 ⇒ 无场空间逃逸，代价 `~1/a`"

逐个判任务书给的三种写法。

**(1a) 字面不等式 `H_a ≥ c·(1/a)·N̂` —— `[T]` 判：假。**
物理格点的标准 Hamilton 极限是 `H = K+V+O(a)`，其中 `K=(g²(a)/2)Σ_ℓ Ĉ₂(ℓ) = (g²(a)/2)N̂`（`N̂` = 群谐波/Casimir 指标和），`V` 有界（Wilson 作用量在紧群流形上有界；Gauss 约束按惯例在规范不变扇区取）。故谐波代价的系数是 `g²(a)/2 = O(1/log(1/a)) → 0`（渐近自由），**不是** `1/a`。字面不等式差一个因子 `a·g²/2 → 0`。**"代价 `~1/a`"作为能量下界是错的，方向也反了：`a→0` 时谐波变便宜，不是变贵。**

**(1b) 交换子 `‖[H_a,·]‖` —— `[T]` 判：不可用（零信息）。**
`[K,N̂]=0`（`K` 是 `N̂` 的函数）；`[V,N̂]` 的矩阵元只在相邻谐波间非零、由 `‖V‖_∞` 控制，**无符号、无增长**。⇒ 任何"用交换子范数把指标与能量挂钩"的写法都给不出 `1/a`，也给不出 `ε_a` 的信息。

**(1c) 正确的形式：代价不等式（COST）—— `[T]`。** 这就是**要写下的那条不等式**：

```
(COST)        (1 − ε_a) · ⟨φ_a, H φ_a⟩  ≤  E_a + b_a                    [T]
⇒             ⟨φ_a, H φ_a⟩ ≤ (E_* + b_a)/(1 − ε_a)                     (E_a ≤ E_* < Δ_cont)
⇒             ‖(1−P_K) φ_a‖² ≤ (E_* + b_a)/((1−ε_a)·K)                  (P_K = H 的前 K 个谱投影)  [T]
⇒             N̂(φ_a) ≤ (E_* + b_a)/(c·(1−ε_a))                          (若 H ≥ c·N̂)             [T]
⇒             φ_a ⇀ 0 且 H 紧预解  ⇒  limsup_a ε_a ≥ 1                  （锐性，不可降）           [T]
```
其中 `ε_a` 是 `H_a−H` 对 `H` 的**相对形式界**（`(𝔞)` 的最优常数），`b_a` 是加性常数。

**判它是否真的成立**：`[T]` 成立（三行：(𝔞) 代入 `E_a=𝔮_a(φ_a)` 即得；后两条由 `H≥Δ_cont` 于 `Ω^⊥` 与 `H≥cN̂` 直接得）。它**不**假设紧群、不假设 `G` 紧、不假设 PF——**比任务书的机制 1 更强也更弱**：更强（给出定量界与锐阈值），更弱（不声称"逃逸不可能"，只说"逃逸 ⟺ `ε_a→1`"）。

**"`1/a`" 的正确位置（`[T]` 的算术 + `[J]` 的读法）**：
```
逃逸到指标 N̂ ≍ 1/a   ⟺   1 − ε_a ≲ a·(E_*+b_a)/c
物理族（若 (RB)）：ε_a = O(a) ⇒ 1 − ε_a = 1 − O(a)
短缺因子 = (1−ε_a^{phys}) / (1−ε_a^{need})  ≳  1/a
```
⇒ "代价 `~1/a`"**不是**能量壁垒，而是**"所需相对强度 / 可用相对强度"之比 `≳1/a`**：逃逸需要扰动**几乎和 `H` 一样强**（相对界 `1−O(a)`），而物理族（若 Taylor 展开在形式意义下成立）只提供 `O(a)`。**这个读法把所有"紧群/谐波"的内容都换成了相对界的内容，并且是可判定的。**

## §6 诚实边界（12 条）

1. **反例不是 YM。** §1 的族是抽象 `ℓ²(ℕ₀)` 上的对角族；它**不**证 `(NEW)` 在 YM 上假，只证"**紧预解 + 有限重 + PF 单纯 + 强预解 + Hausdorff** 这一组结构**不足以**推出 `(NEW)`"。⇒ `FINDING-02:142` 的"在 YM 类里造出"**未被满足**，不得把本轮读成 `(NEW)` 已被证伪。
2. **固定空间是理想化。** 物理上 `a→0`（固定物理 `L`）时 `ℋ_a=L²(G^{Λ_a})` 的维数 `~(L/a)^{3N_c}` 发散，"`H_a→H` 强预解"在单一空间里**没有字面意义**（`REPORT.md:267–275` 的设定本身是一个抽象）。定理 COST 只在这个抽象里成立。
3. **`(RB)` 未证，甚至未被逐字陈述过。** 它是"`log T_a` 的二阶余项对 `H` 相对有界"。BCH 展开下 `R_a=(1/2)[K,V]+O(a)`，而 `[K,V]` 是一阶微分算子、对 Laplace–Beltrami `K` 的相对形式界为 `0` ⇒ `(RB)` **看起来可证**。这是 `[J]`，不是 `[T]`；本轮不声称能证。
4. **`GN1-A` 的勘误**（§0.E）：原式在 `0` 端点为假，两个见证。**不改** `GN1-NODIP.md`；下游引用请按 `GN1-A′` 改写（`lead` 裁）。
