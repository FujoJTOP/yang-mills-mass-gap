## §0 判决（先写）

1. **RP 给了什么**（`[T]`，五条，两条定量、一条半定量）：自伴收缩 `T = e^{−aH}`、`0 ≤ T ≤ 1`、`H ≥ 0`；唯一真空 `Ω`（`λ₁ = 1` 单重，Perron–Frobenius，需正核）；**无负谱**（一般自伴收缩谱在 `[−1,1]`，RP 砍掉负半轴）；KL 测度 `ν ≥ 0`（⇒ `C(t)` 完全单调）；有限体积逐点严格正（`T > 0`）。**谱界只有 `spec T ⊂ [0,1]` 与端点结构，没有 `λ₂` 的任何界。**
2. **谱隙怎么读**（`[T]`）：`m = −(1/a)·log‖T|_{Ω^⊥}‖ = −log λ₂(T) = inf supp ν = 2Λ`（Poincaré）。**RP 恰好给的是非严格不等式 `‖T|_{Ω^⊥}‖ ≤ 1`；而"有隙"= 这条不等式**严格** + 一个模数。类型不匹配，不是松紧问题。**
3. **生死判据（`[T]`）：RP 在 2D YM 与 M6 上**都成立**。** 2D YM：`T` 在等距基下对角、本征值 `w_j = e^{−λC₂(j)} ≥ 0`（`λ = g²/2`，`∀λ ≥ 0`）⇒ RP；而 `m(λ) = λC₂(1/2)` 可任意小，`λ→0` 的成员 `m = 0` 且**仍 RP**。M6：`⟨Θf, f⟩ = (1/2ω)(∫e^{−ωt}f)²·(自由方向同类)` 是**平方**（数值核到 `1.8e−15`）⇒ RP。**⇒ 只靠 RP 的工具必须对两者给同一个值 ⇒ 失败。**
4. **四模型值**（§4 表）：RP 型量只有两种读法，**都不是"四模型全过的新工具"**——界读法给常数（自由场/2D YM/M6 全 `1`，单 plaquette 无定义）；精确读法给 `λ₂(T)²`，那逐字就是 `m` 的重标（= 靶本身）。
5. **判死线**：**(a) 不成立**（逐字：被测族里**没有**任何 RP 型量做到"自由场 `0` / 2D YM `>0` / M6 `0` / 单 plaquette 无定义"四项同时成立；唯一四项全过的是 `λ₂(T)`，即 `m`，它是靶、且**不是 RP 所给**）。**(b) 触发**：RP 的每一条**严格**定量陈述（`T > 0`、`λ₁ = 1` 单重、有限体积 `λ₂ < 1`）在 M6 上全成立而 `m = 0`（`L→∞`），甚至在有质量自由场的每个有限 `L` 上成立（`m_L = ½(2π/L)² > 0`）⇒ **连"自由场给 `0`"这条酸测都过不了**。**(c) 触发**：2D YM 上 RP 只给 `λ₂ ≤ 1`（`m ≥ 0`），真值 `e^{−3g²/8}` 出自**精确可解（Casimir 谱）**，不出自 RP。
6. **路径**：RP 保留为**舞台**（Hilbert 空间 + KL + `m_eff(t)` 单调），不作为**引擎**。缺的那一步是 `λ₂` 的**一致下界** = 一致 Poincaré/LSI = 本项目的墙；它只能由**指数/曲率**数据（Bakry–Émery、曲率地板 + 方差上界，`O06` 的 `β ≤ 3.882` 链）供给，RP 的**符号**数据补不上（§3.4 命题）。

## §1 RP 的确切内容（逐条，不许多给一分）

设 `(S, Haar)` 为 Wilson 作用、任意紧群、任意 `β ≥ 0`；时间片反射 `Θ`。

| # | RP 的输出 | 类型 | 定量? | 四模型上的值 |
|---|---|---|---|---|
| R1 | `T = e^{−aH}` 存在，自伴，`0 ≤ T ≤ 1`，`H ≥ 0` | 存在性 + 区间界 | `[0,1]`（常数） | 三模型全同（单 plaquette 无 `T`） |
| R2 | `spec T ⊂ [0,1]`（**砍掉负半轴**；一般自伴收缩是 `[−1,1]`） | 谱的**符号** | 常数 | 同上 |
| R3 | `f_{n}² ≥ 0` ⇒ `ν ≥ 0` ⇒ `C(t) = ∫e^{−Et}dν` 完全单调 | KL 正性 | 定性 | 同上 |
| R4 | `λ₁ = 1` 单重、`T` 逐点严格正（PF，正核） | 端点结构 | 定性 | M6 亦成立（`1.1e−3` 最小元，§3.2） |
| R5 | 强耦合下 `‖T|_{Ω^⊥}‖ ≤ e^{−c(β)}`（与**团簇展开合用**） | 定量**隙** | **是** | 只在 `β ≲ 0.7`（SZZ `β<1/48`；OS78 强耦合） |

**R1–R4 里没有一个数依赖模型**（都是 `1`、`0`、或"严格"）。**R5 是唯一给出正数的，而它的定量输入是"活动度小"，不是 RP**——这是全篇最关键的分工。

**R5 再拆一层**：即使 `β` 小，它给的是 `m·a ≥ c(β) > 0`，`a→0` 时 `m ≥ c/a → ∞`，即"相关长度 `=O(a)`"的平凡 UV 陈述（`L5-CLASSICAL.md:13,62`、`L3-TRANSMUTATION.md:127`）。**它不是 Clay 的靶**（靶要 `a`-一致、`β→β_c` 一致的下界）。

## §2 谱隙怎么读（四种等价、以及 RP 在其中的确切位置）

```
m := inf(spec H ∖ {E₀}) − E₀
  = −(1/a)·log‖T|_{Ω^⊥}‖            （T = e^{−aH}，T|Ω⟩=|Ω⟩）
  = −log λ₂(T)                       （λ₂ = T 在 Ω^⊥ 上的谱半径）
  = inf supp ν                       （KL：C(t)=∫e^{−Et}dν，ν ≥ 0，扣真空 δ₀）
  = 2Λ(μ_vac, ∇)                     （全空间 Poincaré 常数；U09 §5.1、U05 #5）
```
**四条是同一个数的四张脸**（`U05 §1 引理 2`、`U09 §5.1`，`[T]`）。**RP 在这张图里的位置**：它保证 `ν ≥ 0`（所以 `inf supp ν` 才是"谱底"而不是"复平面上的极点"），并保证 `T` 自伴（所以 `λ₂` 是实数、`‖·‖` 是谱范数）。**它是这张图能被写下来的前提，不是图中任何一个数。**

**R1 给的是 `‖T|_{Ω^⊥}‖ ≤ 1`。** 把这句话改写成关于 `m` 的话：`m ≥ 0`。**这逐字就是 RP 对谱隙的全部定量内容。** 四模型上它给 `0/0/0/无定义`——对 2D YM 是**错的紧**（`3g²/8 > 0`），对自由场是**空的对**（`0 = 0`）。酸测要的恰恰是"在自由场上失效"，而 RP 的 `m ≥ 0` 在自由场上**取等**、在 2D YM 上也取等 ⇒ 它不是判据，是恒真式。

## §3 生死判据：RP 在 2D YM 与 M6 上的显式验证

### 3.1 2D YM：RP 就是"权重非负"，而 `m` 是"权重之比" `[T]`

2D YM 的空间圆环上 `T` 在等距（特征标）基下**对角**：`T = Σ_j w_j P_j`，`w_j = e^{−(g²/2)C₂(j)}`，`d_j = 2j+1`，`C₂(j)=j(j+1)`（`SU(2)`；`T03 §2 M2` 的 `H=(g²/2)C₂`，`[T]*` 文献未核）。

- **RP ⟺ `w_j ≥ 0`（`∀j`）**：对角算子的正性 = 全部本征值非负。**对一切 `λ = g²/2 ≥ 0` 成立**（指数永远正）。
- **隙 ⟺ 比值**：`λ₂ = w_{1/2}/w_0`，`m = −log λ₂ = λ·C₂(1/2) = λ·3/4`。`g²=1` 时 `3/8 = 0.375 `——与 `T03` 的 `3g²/8` 逐字一致。

数值（`%TEMP%` 脚本，`[C]`，精确式无采样）：

| `λ = g²/2` | `w_j ≥ 0 ∀j` | `λ₂ = w_{1/2}/w_0` | `m` | `λ·C₂(1/2)` |
|---|---|---|---|---|
| `0`（族成员） | **是** | `1.000000000` | **`0`** | `0` |
| `1e−6` | 是 | `0.999999250` | `7.5e−7` | `7.5e−7` |
| `0.005` | 是 | `0.996257022` | `0.003750000` | `0.003750000` |
| `0.5`（`g²=1`，**靶点**） | 是 | `0.687289279` | **`0.375000000`** | `0.375000000` |
| `5`（强耦合侧） | 是 | `0.023517746` | `3.750000000` | `3.750000000` |

**逐字结论（本节最强的一句）**：
> **存在一族理论 `{2D YM(λ) : λ ≥ 0}`，其中每一条 RP/OS 不等式（`T ≥ 0`、自伴、`ν ≥ 0`、有限体积 `λ₂<1`）**逐点成立**，而 `m(λ) = 3λ/4` 连续地从 `0` 跑到任意大。⇒ **RP 的假设集沿这条族不变，`m` 却从 `0` 变到 `3.75`。任何只消费 RP 的推理，必须对 `λ=0` 那个成员也成立，而它 `m=0`。**
> ⇒ **"RP ⇒ `m>0`" 被这一条族一票否决（`[T]`，见证在族内，不需要新模型）。**

**注意口径**：`λ=0` 成员 = 时间片之间解耦（`T = 1` ⇒ 无传播）。它不是"物理 YM"，但它**是同一个 `T` 公式在 `λ=0` 的取值**，且 RP 在它上面成立——这足以驳倒"RP 单独足以定 `m>0`"，也足以驳倒"RP 型量能区分 2D YM 与无隙模型"。

### 3.2 M6：RP 的显式平方 `[T]` + 数值 `1.8e−15` `[C]`

M6 = 谐振子 `⊗` 自由模（`T03 §2 M6`）。它的测度是**两个 Gaussian 的乘积**，RP 逐因子成立、乘积保持：对半轴上的 `f`（含两个方向），
```
⟨Θf, f⟩_{M6} = (1/2ω)(∫ e^{−ωt} f_a(t) dt)² · (自由方向的同型平方)  ≥ 0 .
```
**这就是 RP 的全部证明**——一个平方，与 `ω`、`L` 无关，与谱隙无关。（`∫∫ f(s)f(t)C(−s,t)`，`C(−s,t) = (1/2ω)e^{−ω(s+t)}` ⇒ 秩一 ⇒ 平方。）

数值（半轴 `N=64`、`ω=1`、随机 `f`）：`R = 10.33286677964181` vs `平方 = 10.332866779641812`，差 `1.8e−15` `[C]`。
M6 的转移核在有限体积**逐点严格正**（PF 前提）：`⟨a'|e^{−H₀dt}|a⟩` 最小元 `4.46e−8`（`dt=0.5`）/`1.10e−3`（`dt=2`），最小本征值 `−7e−16`（机器零），最大 `5.82`/`2.75` `[C]`。

**⇒ M6：RP ✓、`T>0` ✓、`Ω` 唯一 ✓、有限体积 `λ₂<1` ✓，而 `m_L = min(ω, 2π²/L²) → 0`（`L→∞`）。** 这与 `T03/U09` 的 `m=0` 是同一句（`U09 §1` 口径注：`m=0` 是 `L→∞` 命题，任何候选必须按同一极限读）。

### 3.3 自由场：RP 是标准件，且**在有限环上也有隙**

有质量自由场（周期链、bond-心反射）半格核最小本征值：`μ=1e−3` → `−3.6e−11`、`μ=1` → `−1.3e−17`（机器零 ⇒ PSD ⇒ RP）`[C]`。
**无质量**：零模使协方差不可逆，去零模（pinv）破裂平移不变 ⇒ **该极限的这条数值检查不作证据**（脚本给 `−3.17`，是 pinv 伪影，不是 RP 失败）；按标准（Glimm–Jaffe；OS 公理）标 `[T-standard]`。
**关键的一行**：自由场在**有限环**上 `m_L = ½(2π/L)² > 0`（`L=2/10/40`：`4.934802 / 0.197392 / 0.012337` `[C]`，与 `U09`/`A1-FREE-TORUS` 同式）。**⇒ 任何"有限体积严格正性"型 RP 结论，在自由场的每个有限 `L` 上也成立 ⇒ 连"自由场给 `0`"这条酸测都过不了**（它必须只在无限体积/连续极限下失效才算过酸测）。

### 3.4 命题（RP 对谱隙的盲性）`[T]`

> 设 `{T_w}` 为同一组正交基下对角的、`w_r ≥ 0` 的一族自伴算子（2D YM 的等距基、M6 的 `H₀⊗H_free` 基都是这种）。则
> (i) `T_w ≥ 0` 对**一切** `w_r ≥ 0` 成立（⇒ 该族每条 OS 正性不等式恒真）；
> (ii) 隙只由**比值** `w_{r*}/w_0` 给出：`m = −log(w_{r*}/w_0)`；
> (iii) `w ↦ c·w`（`c>0`）与"压平"`w_r ↦ w_0` 都保持 (i) 而改变 (ii) 到 `0`。
> ⇒ **RP 约束的是权重的符号，`m` 是权重的指数率；两者是正权重空间上的独立坐标。RP 不蕴含 `m>0`。** 见证：2D YM 的 `λ=0` 成员（§3.1）、M6（§3.2）。∎

**这条命题解释了为什么"再换一个 RP 型不等式"永远换不出来**：`Θ`-内积的正性是对**符号**的陈述，而 `λ₂` 是**大小**的陈述。这与 `U09 §4.2` 的"边缘盲"是同一类结构（那里的盲是"单方向看不见自由方向"，这里的盲是"符号看不见大小"），也是 `GPP-STRUCT.md:101` 那句"positivity is blind to the edge"的定量版。

## §5 缺什么（`[M]`）——以及 RP 在正确装配里的位置

**缺的那一步**：`λ₂(T)` 的**一致下界** `<1`，等价于"一致 Poincaré / LSI 常数 `>0`，对 `(L, a)` 一致，且 `β` 到 `β_c`"。这是本项目的墙（`RATE-UNIFORM.md`、`CTL-CLOSEST.md`、`U05 §2`），现有已发表者只在 `β < 1/48`（SZZ arXiv:2204.12737，`[T-文献]`）。

**为什么 RP 补不上（§3.4）**：`λ₂` 是权重的**指数率**，RP 只约束**符号**。要压住 `λ₂` 必须用**曲率/方差**数据：
- Bakry–Émery：`−D²log ρ ⪰ κI ⇒ Λ ≥ κ/2`（`Q04-BAKRY-EMERY.md`；HO 取等）；
- 曲率地板 + 方差上界：`E[H_vv] ≥ (N/12)‖v‖²` 配 `Var ≲ β²`，给 `H1` 的**定量窗口** `β ≤ 3.882`（`O06-CURV.md §4`、`O05-FORCEVAR.md`）——注意这已在 `Σ` 型（不是 RP 型）里，且**窗口有限**。

**RP 的正确位置（保留，别丢）**：
1. 提供 `H_phys = L²(ts, μ_slice)` 与 `T = e^{−aH}`（`R1-BRIDGE §1.1(1f)`）——**没有它连"谱"这个词都不能用**；
2. 提供 `ν ≥ 0` 与 `m_eff(t) ↓ inf supp ν`（`U05 引理 2`）——**这是"从关联读速率"的唯一合法通道**（P3/强耦合链就在用它，`Y01-KL.md`）；
3. 与团簇展开合用时给 R5（`β` 小）——**这台机器已存在，但它的动力是小活动度，不是正性**。

## §6 诚实边界与窗口（`AGENTS.md §2.1`）

- **窗口**：四模型表全部在**可解模型**（`SU(2)`；2D YM 用 Migdal 对角化；M6 用 `ω=1`、环长 `L`；自由场用 `½(2π/L)²`）。`g=1`、`ω=1` 是**约定**，不是物理点。**没有一格是 4D `SU(N)` 格点数据。**
