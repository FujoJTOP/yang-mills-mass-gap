## §1 `C` 的精确定义 —— 从 KP 到 `O(1)`

### 1.1 要解释的那条式子

`PROOF-IN11.md:9` 逐字：
```
m_c(β) = a_c · ln(1/u(β)) + O(1),   u(β) → 0⁺  as β → 0
```
`L3C-STARSTRONG.md:99` 把它写成 `m_c ≥ ln(1/u) − C`（`c ∉ {0⁺⁺,2⁺⁺}`），并声明「`C` 须与 `c` 无关」。⇒ **`C` 是那个 `O(1)` 的显式常数**，不是系数、不是乘在 `½ln(1/u)` 前面的因子。

### 1.2 语料里唯一的显式 `O(1)` 项

| 步 | 逐字 | 出处 |
|---|---|---|
| 裸直管速率 | `κ := 4ln(1/u)/a`，`κ/4 = ln(1/u)/a`；`4` = 源 plaquette 的 4 条边（零扭折 `μ=1`） | `W02-L1:12`、`X01-L1C:17`、`A02:60` |
| 可达（dressed）率 | `δ = ln(1/ū)/a = κ/4 − ln(eΔ C̄)/a`，`ū = eΔ C̄ u` | `Z07-HOLEB:100`、`Z12-FIXC:124`、`A02:60` |
| 重耦合修正 | `ū ↦ Ĉ·ū`，`Ĉ = 4`（逐 plaquette 可证包络：`Σ_ℓκ_ℓ ≤ 4|γ|`、`R(κ) ≤ 2^{κ/2}`） | `Z12-FIXC:70,96` |
| 故 | `δ·a = κ/4 − ln(Ĉ eΔ C̄) = ln(1/u) − ln(Ĉ C̄ eΔ)` | 合并上三行 `[T]` |

⇒ **`C := ln(Ĉ·C̄·eΔ)`**。三项都**不吃 `J^{PC}`**：`Ĉ` 是共享链重耦合包络、`eΔ = e·20 = 54.3656365692` 是连通动物数包络（`Δ=20` 为 plaquette 邻接度，`P3-FULLREP-KP:89,116`、`A01-CBAR:33`）、`C̄` 是 Ursell 逐动物常数（`X01:71`）。**这正是 `C` 与 `c` 无关的来源**，也是 `A02:60` 逐字「`Δ, C̄` 是 KP 动物常数，**与算符无关**」的内容。
若取该常数的**求和级**读数（`C01-CBAR1:162`：`eΔ` 一笔、`C̄=1` 等价），`C = ln(4eΔ) = 5.38203`。

### 1.3 记号诚实性（`[O]` 所在）

- 语料**没有一处**写出「`C = ln(ĈC̄eΔ)`」这个等式；`L3C:105,189–190` 明记「余项对 `c` 一致」**检索 0 条**。⇒ 定义**可推导**，但**未被陈述**；把「C 与 c 无关」记 `[T]` 是越级，仍是 `[O]`。
- 另一个**相反读法**必须记账：若 `C` 取「回退/装饰（`f_dec`）项」而不是 `ū`-记账项，则 `f_dec = O(u/a)`（`X01:17`）⇒ `C = O(u) ≈ 5e-3…2e-2`，`C ≤ 2.691` **平凡成立**。两种读法判决相反 ⇒ **P3 的题目本身有两种解**，这是 `L3C:105` 未裁的部分。

## §3 为什么这是结构性的（不是数值巧合）

`β₁ = 8/(Ĉ C̄ eΔ) = 0.018393972`（`Z12-FIXC:96` 的 `Ĉū<1` 取 `N=2`；与题面 `0.018394` 相对偏差 `1.5e-6` `[E]`）。于是

```
C = ln(Ĉ C̄ eΔ) = ln(8/β₁) = ln(1/u)|_{β=β₁}        （u = β/8 口径，残差 1.5e-6）   [T]
⇒ ½ln(1/u)|_{β₁} = C/2 < C          ⇒ 「C ≤ ½ln(1/u)」在窗边**恒假**
⇒ 该地板可用当且仅当 ln(8/β) ≥ 2C ⟺ β ≤ 8e^{−2C} = 4.229e-5 = 0.00230×(1/48)        [T]
```
L3C 用的 `u=β/4` 口径只是把 `C` 换成 `C − ln2`：`ln(4/β₁) = 5.38203 = 6.07517 − 0.69315` `[E]`；`½` 后 `2.69101 = 3.03759 − 0.34657`。**两个口径给出同一判决**，2.691 与 6.075 是同一件事的两种单位。

**⇒ 正确的地板**：`inf_c m_c ≥ min(Δ₀, Δ₂, ln(1/u) − C)`，其中 `ln(1/u) − C > 0` **恰在窗内**（在边上退 0⁺）。`(★-gap)` 因 `δ` 可以在给定 `β` 上取 `δ(β)>0` 而**不死**；但 `L3C §4` 为取「干净正数 `½ln(1/u)`」而付的那一步 `c=(1/2)ln(1/u)` **是自设的 2× 收紧，且永不可满足**。`[T]`

## §4 判死线

### **(b) 触发：不成立**

```
真值  C = 6.07517            （C̄=2、Ĉ=4、Δ=20；三读数区间 [5.382, 8.378]）
阈值  C ≤ 2.69101            ⇒ 实际超 2.2576×
所需  Ĉ C̄ eΔ ≤ e^{2.691} = 14.7466     ⇒ 现值 434.9251，**差 29.49×**
等价  β ≤ 8e^{−2C} = 4.229e-5 = 0.0023×β₁（即窗内还差 435×）
```
`[T]`（`C` 的定义 + 窗恒等式）+ `[E]`（数值）。

### **(c) 局部成立：`C` 的定义必须先钉**

`C` 从未被写成公式；且存在**相反读法**（`f_dec=O(u)` ⇒ `C≈10⁻²` ⇒ 过）。⇒ 本轮**钉死最可能读法** = `C := ln(ĈC̄eΔ)`（语料唯一显式 `O(1)`、唯一吃 `a_c ln(1/u)` 系数的项、且 `A02:60` 已证其不吃 `J^{PC}`），并按它判 **(b)**。若采用 `f_dec` 读法，则 P3 平凡通过但**与 κ/4 的记账重复计账**（`A02 §2.1` 明确禁止把 `f_dec` 与 `κ/4` 混用）——故 `f_dec` 读法**不是** `L3C:99` 那个 `C`。

### **(a) 不触发**

`C ≤ 2.691` **不成立**，L3 第一关**未过**。且按 `L3C:200` 的自否证条件：这**只**杀路线 B 的「`½ln` 干净地板」，**不**杀路线 A（`β₀^{OS}` 窗对齐）——`(★-gap)` 仍有两条路，其中 B 需改成 `δ(β)=ln(1/u)−C`（窗内逐点正，但边上是 0⁺，**不给 `β`-一致 δ**）。

## §8 一句话
