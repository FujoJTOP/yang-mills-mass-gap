## §1 核恒等式（问一）

**1.1 逐字核 `YY5` 的恒等式 `[T]`。** `YY5:23–28`：
```
γ_O = −dln(β/2g)/dlnμ = 2b₀g²                     （U06-ZO:33 逐字）
1/g² = 2b₀ln(μ/Λ) ⇒ b₀g² = 1/(2ln)
⇒ (2g/β) = −2/(b₀g²) = −4ln(μ/Λ)                  （YY5:25 逐字）
⇒ ⟨O_S(x)O_S(0)⟩ = 16[ln(1/(|x|Λ))]²⟨θ(x)θ(0)⟩    （YY5:26 逐字）
⇒ log 幂 = γ₀/b₀ = 2；系数 16；符号 +
```
自算核：`2/(b₀g²)` 在 `b₀g²=1/(2L)` 处 `=4`，平方得 `16` ⇒ 与 `YY5:26` 同值 `[T]`。

**1.2 `γ₀/b₀=2` 的地址是 `ln` 的指数栏 `[T]`。** `HZ7:18` 逐字「（`Z_O` 是）对数正规变化（**指数 0、对数幂精确 1**）」；`HZ7:27`「`Z_O(k)≍ln(k/Λ)`，对数幂 `=1+O(lnln/ln)`」。两腿 ⇒ `(ln)²`；总幂 `2 = 2·γ₀/(2b₀)`（每腿 `γ₀/(2b₀)=1`）。

**1.3 `p` 的地址是 `|z|` 的指数栏，两栏不可加 `[NG]`。** `YY3:49` 逐字分开两通道：「轴（`γ_O` 是 UV 跑动对数 `log²(k/Λ)`；`a^{-4}` 管幂、对数由 `γ_O` 管）」。算术：`r^{-8}(ln r)² ≤ A r^{-4}(ln r)^{-1-δ}`（大 `r`，比 `r^{-4}ln^{3+δ}→0`），反向不成立 ⇒ `ln` 幂可在同一 `|z|` 幂上**输**，不会**赢**一个幂。

**1.4 核的结论。** 三件已知全真；**第四件（叠加）是新增假设**，且与它要解释的现象相反（0.3）⇒ `[NG]`。

## §2 是否精确（问二）

**2.1 精确的是两半的「各自」`[T]`。** `p=d−2` 精确到常数（`YY3:23,25`，机检 `sup_m/闭式 = 1.000000000000/1.000000000000/0.999999999993`）；`γ₀/b₀=2` 精确、`N`-无关（`U06:33`·`HZ7:25`；两圈改系数与 `O(1)` 宗量、不改幂，`YY5:29`）。

**2.2 一般式（本件给出）：**
```
槽 A（|z| 的幂）: p = 2Δ_class          O_S: 2·4 = 8 = p_4 = 2d
                  或配对梯 p_k = k(d−2)  k=1 免费 KL(=d−2)、k=2 压线、k=4 自由 Wick(=2d)
槽 B（ln 的幂）:  logpow = n_legs·γ₀/(2b₀)  每腿 1，两点 = 2 = γ₀/b₀
合成（乘法）:     |⟨O O⟩| ≍ |z|^{-p}·(ln(1/(|z|Λ)))^{logpow}
```
⇒ 「叠加」只在乘法下成立；写成 `p=(d−2)+γ₀/b₀` 是把槽 A 与槽 B 相加。

**2.3 为何"看起来"精确：`(d−2)+2=d` 是恒等式 ⇒ 该式唯一内容为 `p=d` `[NG]`。** `p=d ⟺ k(d−2)=d ⟺ d=2k/(k−1)`，取值集 `{4,3,8/3,5/2,…}`（`k=2` 给 `d=4`，`YY5:31`）。反例：`d=5` 梯子只给 `p_k=3,6,9,12`（自算，与 `TT5:31` 的 `3,6,12` 一致），`p=5` 无载体。循环处：`γ₀/b₀=2` 的前提 `θ=(β/2g)O_S`、`γ_θ=0` 本身是 4 维迹反常，把它当 `d`-无关输入再代回 `(d−2)+…`。

**2.4 判。** 作 `ln` 幂 = `[T]`（精确、`N`-无关）；作 `p` 的加数 = `[NG]`（`d=4` 的算术巧合）。附证：`p=4` 恰是现成供给表里唯一没有供给的一格（`p=2`、`p=8` 有，`4<p<8` 无，`II9:52`）——恒等式正落在这一格上，这不是机制的证据。
