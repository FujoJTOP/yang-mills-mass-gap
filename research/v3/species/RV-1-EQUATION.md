## §1 左端：两类变分与几何因子

### §1.1 setup（不改）

`C_R ⊂ ℝ⁴`，平面圆，`dA/dR = 2πR`。在一点切开，两弧长

```
L_1 = 2πRθ ,  L_2 = 2πR(1−θ) ,  L_1 + L_2 = 2πR          (1.1)
dL_1/dθ = +2πR ,  dL_2/dθ = −2πR                          (1.2)
G(R,θ) := W(C_1)·W(C_2) = 𝒲(L_1)𝒲(L_2) ,  𝒲(0)=1          (1.3)
```

`𝒲` 是"一段弧闭合成圈"的权（闭口方式：弦）。**`𝒲` 不是 `f`**：`f(R) = W(C_R)` 是整圆，`𝒲(L)` 是弧——上一轮的全部病灶就在把两者当同一个对象。

### §1.2 纯几何量（全部算得出，无编造）

两段闭合成圈的两个量：**围面积**和**弦长**。

```
段面积   A_1(θ) = (R²/2)(2πθ − sin 2πθ) ,  A_2 = πR² − A_1      ⇒ A_1+A_2 = πR²  （θ-无关）   [T]
面积速率 dA_1/dθ = πR²(1 − cos 2πθ) ,      dA_2/dθ = −它         [T]
弦长     ℓ(θ) = 2R sin πθ ,                dℓ/dθ = 2πR cos πθ    [T]
恒等式   A_1(θ) − θ·πR² = −(Rℓ/2)·cos πθ                        [T]
```

`dA_1/dθ` 偶（`θ↔1−θ` 不变）、`cos πθ` 奇、`ℓ` 偶。**这三条就是 `θ`-扇区全部可用的几何输入**——注意面积**速率**（不是面积本身）是 `θ`-动力学唯一可能的载体。

### §1.3 面积导数的规范化（唯一假设，标 `[C]`）

圆族上唯一的形变是呼吸。取"单位面积凸起"规范化：

```
δ/δσ_μν(x) |_{圆族}  =  (1/(2πR)) (∂/∂R)         量纲 L^{-1}·L^{-1} = L^{-2}  ✓   [C]
```

**这一步给出 `θ`-盲**：`(1/(2πR))∂_R` 不含 `θ`，且它在 `C` 上无 `x`-依赖（圆对称）——**这正是 `θ` 不能成为动力学方向的机制**（(a) 的根）。`[T]`（在此规范化下）

### §1.4 左端的算符（两项分开写）

回路空间散度 = 面积导数的二阶组合，配**总测度** `dA`：

```
LHS = (dA/dR)·(d/dA)² G = 2πR · (1/(2πR))∂_R [ (1/(2πR))∂_R G ]
    = (1/(2πR)) [ G_RR − (1/R) G_R ]                                  (1.4)
```

**各项拆开**（题要求逐项）：

| 项 | 算符 | 系数（不含 `G` 的导数） | 几何来源 | 标签 |
|---|---|---|---|---|
| 呼吸·二阶 | `∂_R²` | `+1/(2πR)` | `dA/dR = 2πR` 与单位面积凸起 | `[C]` |
| 呼吸·一阶 | `∂_R` | `−1/(2πR²)` | `dA/dR = 2πR` 的 `R`-导数（`1/R` 摩擦项） | `[C]` |
| 切点·二阶 | `∂_θ²` | `+c₀(1−cos 2πθ)²/R³` | `dA_1/dθ = πR²(1−cos2πθ)` | `[C]`+**c₀ 未定** |
| 切点·一阶 | `∂_θ` | `+d₀ cos πθ / R³` | `dℓ/dθ = 2πR cos πθ` | `[C]`+**d₀ 未定** |

## §2 右端：`x=y` 处的几何权重

`x ∈ C`，`y` 走遍 `C`。**这是 1 维支撑上的 4 维 δ**：

```
∮_C dy_ν δ⁴(x−y) = t_ν(x)·δ_C(x) ,   δ_C(x) = ∫_C ds δ⁴(x−y(s))          (2.1)
量纲：[dy]=L  ×  [δ⁴]=L^{−4}  =  L^{−3}  ✓ 与 LHS 同
```

**结论（题问"是 `1/(周长)` 型还是 `1/(面积)` 型"）**：

1. **都不是。** `δ_C` 是横向浓度的**分布**，其数值是 `1/(横向长度)³`（`= 1/ε³`，`ε` = 吻合极限的横向正则化尺度），**不是**任何回路几何的倒数。
2. **`θ`-独立性 `[T]`**：`∮dy_νδ⁴(x−y)` 只看见切点自身的切向 `t_ν`，**看不见弧长如何分配**——因为 `δ⁴` 的支撑是点集，不是参数化。故 `w(θ) ≡ 1`，切分长度 `L_1,L_2` **不进入**权重。
3. **转换为 `(R,θ)` 变量的函数**：唯一可用长度是 `R`，故唯一规范化的标量写法是 `1/R³`（`ε ↦ R`，`[C]`）；数值前因子被吸收进 `g²N` 的重整化。
4. **"每段弧的极小面"型权重被排除**（这一条针对 sp-b 的加法扇区）：若硬取 `w(θ) ∝ 1/(A_1A_2)` 或 `1/(L_1L_2)`，则 `θ→0` 时 `w → ∞`，而 `G(R,0) = 𝒲(0)𝒲(2πR) = f(R) ≠ 0` ⇒ 右端发散、左端有限 ⇒ **该权重不可采纳**。**[T]**（在要求方程在 `θ=0,1` 连续的条件下；与 §5 的退化检查自洽）

⇒ **右端良定义，`F(R,θ) = g²N/R³`，与 `θ` 无关。** `(c)` 的"不可良定义"**不触发**（唯一活的模糊是 `c₀,d₀,e₀`，那是左端的 `θ`-度规，见 §7）。

## §5 退化检查

### §5.1 `θ = 0`（切点在自身 / 一段零长弧）

`𝒲(0)=1`，`L_2 = 2πR` ⇒ `G(R,0) = 𝒲(2πR) = f(R)`。几何：`dA_1/dθ|₀ = 0`（偶，且 `1−cos0=0`），`dℓ/dθ|₀ = 2πR`。故 `C(R,0) = 0`（`θ`-二阶项**死掉**），`D(R,0) = d₀/R³`，`E(R,0) = −e₀/R²`。

```
(RV)|_{θ=0} :  (1/(2πR))f_RR − (1/(2πR²))f_R + (d₀/R³)·G_θ|₀ + (−e₀/R²)·G_Rθ|₀ = (g²N/R³) f
其中  G_θ|₀ = 2πR[ 𝒲'(0)f − f' ] ,   G_Rθ|₀ = 2πR[ 𝒲'(0)f' + 2πR𝒲''(0)f − f'' ]      [T]
```

**读法**：`θ=0` 处方程**不是**纯径向的：它含 `𝒲'(0)`、`𝒲''(0)`（弧权在 `L=0` 的 Taylor 数据，即**小回路 UV 数据**）。⇒ `(M)`：**`(RV)` 在 `θ=0` 的闭合需要 `𝒲` 的小回路展开，而 `(★)` 不提供**。这是本轮唯一真正缺的一步（不是几何，不是量纲）。

### §5.2 `θ = 1`（切点在自身，另一段）

与 `θ=0` **完全同型**（`θ↔1−θ` 交换 + `𝒲(0)=1`）：`G(R,1) = f(R)`，`C(R,1) = 0`，`D(R,1) = −d₀/R³`，`E(R,1) = +e₀/R²`。**两端的差只有 `D,E` 的符号**——这正是 §1.4 的奇偶性给出的自洽性检验，**通过** `[T]`。

### §5.3 `θ = 1/2`（对切）

`L_1 = L_2 = πR`。`2θ−1 = 0` ⇒ `E`-项**死**；`G_θ|_{1/2} = 2πR[𝒲'𝒲 − 𝒲𝒲'] = 0`（对称性）⇒ `D`-项**死**；`cos πθ|_{{1/2}} = 0` ✓ 一致。`(1−cos π)² = 4` ⇒ `C = 4c₀/R³`。

```
(RV)|_{θ=1/2} :  1/(2πR)·G_RR − 1/(2πR²)·G_R + (4c₀/R³)·G_θθ  =  (g²N/R³)·G
   G(R,1/2)   = 𝒲(πR)²
   G_RR       = 4π²(𝒲'² + 𝒲𝒲'')|_{πR}
   G_θθ       = (2πR)²·2(𝒲𝒲'' − 𝒲'²)|_{πR}          [T]（直接由 (1.3) 求导）
```

**这是全文件唯一"两个因子在同一宗量"的点**——`𝒲(πR)²` 是**真平方**，但宗量是 `πR`（弧半长），**不是 `R`**。⇒ 一变量约化 `f²` 的**唯一**合法重述是 `𝒲(πR)²`，这就是 (S2)。

- **(b) 不必须**；若强行要，偶扇区最低阶 `θ(1−θ) ≡ (1−(2θ−1)²)/4`，奇扇区最低阶 `cos πθ`。**不是 `cos 2θ`**（`θ` 是弧长分数，角变量 `2πθ`）。
- **(c) 不触发**：权重 = `t_ν δ_C`，量纲 `L^{−3}`，`w(θ)≡1`，良定义；`1/ε³` ↦ `1/R³` 的转换是 `[C]` 而非歧义。**活的歧义移到了左端的 `c₀,d₀,e₀`**（§7）——它们**不改变任何判据**，因为 (S1)(S3)(6.1) 只用 `A,B` 与右端的一次性。

## §8 定稿：采用 `rv-2` 的**局部环微商**（§1.3–§3 的 `(1/(2πR))∂_R` 版作废）

> 依据（`rv-2`，已核）：`c₃` 用了**总面积参数微商** `δW/δσ₁₂ = f′/(2πR)`（与 `x` 无关 ⇒ LHS 恒零），**错**。局部环微商显含 `x`：
> `δW/δσ_μν(x) = ½ε_μν·f′(A)·θ_S(x)`，`∂_μ(…) = ½f′ε_μν n_μ δ_{∂S}(x)`，**支撑在 `∂S` 上**，与 RHS 的 `∮dy_νδ⁴(x−y)` 同一支撑 ⇒ **LHS ≠ 0**。

### §8.1 每弧一个方程（核心）

`x` 落在弧 `i` 的**内部**时，只有圈 `C_i` 的边界 δ 通过 `x`（`C_j` 的边界在另一段弧上）⇒ 方程**逐弧**成立：

```
½ ∂G/∂A_i  =  (g²N/ε²) · G ,        i = 1, 2                          (8.1)
[∂_A G] = L^{−2} ,  [G] = L⁰ ,  [g²N] = L⁰ ,  [ε] = L  ⇒  [g²N/ε²] = L^{−2}  ✓
```

`ε` = 接触项的**横向长度**（`ε ↦ 1` 即无量纲约定，见 (8.5)）。**这就是"LHS 不恒零"的机制**：`∂_μθ_S` 把 `θ_S` 的跳变压到 `∂S` 上，`x`-依赖来自 `n_μ(x)`，不是来自总面积。

### §8.2 并回 `(R,θ)`（精确换算，`[T]`）

```
a_1(θ) := A_1/(πR²) = (2πθ − sin 2πθ)/(2π) ,   a_2 = 1 − a_1 ,   a_1+a_2 ≡ 1
G_θ = πR²(1−cos2πθ)·(∂_{A_1} − ∂_{A_2})G                             (8.2)
G_R = 2πR·(a_1∂_{A_1} + a_2∂_{A_2})G                                 (8.3)
```
（(8.2)：固定 `R` 移动切点，`dA_1/dθ = πR²(1−cos2πθ) = −dA_2/dθ`；(8.3)：固定 `θ` 呼吸，`A_i ∝ R²`。）

反解 ⇒ **`(RV)` 的两个分量**：

```
(RV1)   1/(2πR)·G_R  +  a_2(θ)·G_θ/(πR²(1−cos2πθ))  =  2g²N·G/ε²
(RV2)   1/(2πR)·G_R  −  a_1(θ)·G_θ/(πR²(1−cos2πθ))  =  2g²N·G/ε²
```

`A(R)=1/(2πR)`（两项共有）；`C(R,θ) = ±a_{2,1}(θ)/(πR²(1−cos2πθ))`；`B = D = E = 0`（定稿版**没有** `∂_R²`：局部环微商是一阶的，勿再加二阶）。**(8.2)(8.3) 的反解使 `∂_R`、`∂_θ` 项的系数从 `a_i(θ)` 与 `1−cos2πθ` 完全显式，无自由参数。**

### §8.3 `G_θ ≡ 0` 被**强制**（(a) 的定稿）

`(RV1)−(RV2)`：`(a_1+a_2)·G_θ/(πR²(1−cos2πθ)) = 0`，而 `a_1+a_2 ≡ 1 ≠ 0` ⇒

```
G_θ(R,θ) ≡ 0  对所有 θ   [T]      ⇒  G = G(R)，两变量退化回一变量（结论：log𝒲 对切分可加）
```

`(RV1)+(RV2)` 除以 2：

```
(RV₀)   G_R = 4π g²N R·G/ε²                     (8.4)
```

**⇒ 面积律扇区还原成代数式**（题之硬自检）：`G = exp(−σπR²)` 代入 (8.4)：

```
−2πσR = 4π g²N R/ε²    ⇒    σ = 2g²N/ε²         (8.5)
      ε = 1（无量纲约定）  ⇒    σ = 2g²N   ← 与 rv-2 完全一致
```

**`[T]`（条件于局部环微商与 `ε↦1`）。** 顺带两条：(i) **周长律 `e^{−2πaR}` 不是解**（(8.4) 右端 ∝ `R`，周长律给 `R`-无关的 `−2πa`）⇒ 方程在加法扇区里**只选面积律**；(ii) `ε` 就是 §6(2) 说的**唯一能装 `Λ` 的槽**——`σ = 2g²N/ε²` 把"接触项重整化"与"弦张力"钉成同一个数，这是本轮唯一可核查的**正面**结论。
