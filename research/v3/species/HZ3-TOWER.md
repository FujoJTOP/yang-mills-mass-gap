### 2.2 三条独立的「取不出」理由

1. **体积缺口**：L-序列要 4 个体积，`β=2.5` 上只有 2 个（§1.6）。两点连线既分不开 `L⁻²` 与常数，也分不开 `L⁻²` 与 `L⁻³`（`A06-VERDICT.md:68` 的判定器同样要求 ≥4 点）。
2. **读数缺口（统计）**：`Δ(1→2)` 的误差 `0.584`(L=6)、`2.038`(L=8) ≥ 模板层距 `0.462`、`0.274`。按 `σ ∝ N^{−1/2}` 把 L=8 的误差压到模板的 `1/3`（判定门槛）需要 `N ≈ 6.0×10⁶`（现 1.2×10⁴ 的 500 倍）；L=12 同法要 `N ≈ 2.8×10⁷`。这两笔的墙钟在 §3 的「上支」里，都是 `10²` 小时量级。
3. **对象缺口（系统）**：`λ₂/λ₁` 在**同一格点** `(L,t,N)` 上跨基 9–15 倍（§0.2）。把它按 `e^{−(m₂−m₁)t}` 读成层距，得到的「`m₂²−m₀²`」在同一 `(L=6,t=1)` 上是 `17.7`（B5）到 `27.4`（B1），差 5 倍以上，**大于整个被测动态范围**（L=6 模板 `1.645`）。

### 2.3 面值陷阱（本轮最需要写死的一条）

若把 `t=1` 的比值按面值读（`Δ=−ln λ₂/λ₁`）：L=6 给 `Δ=1.675`、L=8 给 `1.577`，于是

```
m₂²−m₀² = 2m₁Δ + Δ²  ⇒  L=6: 7.98 ± 0.64      L=8: 7.36 ± 0.49
```

两者与常数一致、且比模板高 5–8 倍——**照这个读法，结论会是「不塌」**。这正是 §2.2(3) 要挡住的那一步：换基（B1/B5）给出的同一量是 `17.7`–`27.4`。⇒ **面值读数不得进判词**；它只能当作「若第二层是态，它很重」的一个 [NG] 方向读数。

### 2.4 判

- **[NG] `m₂` 的 L-序列取不出**：L=10/12 零读数；L=6/8 的「层距」既带 ≥1 倍模板的统计误差（`1.3` 与 `7.4` 倍），又带 9–15 倍的基依赖。
- **[T] 现有数据已能判的另一件事**：这个判据在 `β=2.5`、现有统计下**没有判别力**——要它有判别力，先要有「第二层是一个态」的证书（§0.2），再要有 4 个体积（§1.6）。
  **下一手**：T-0（判 §0.2 的证书）+ T-1（把基依赖标定掉）+ T-2..T-4（补体积）。

### 3.2 为什么是这三个 `N`（判别力算，不是拍脑袋）

判据对象是 `r(L) := λ₂/λ₁(t=1)`（单点、系统误差由 T-1 标定）。积累假设给 `r_pred(L) = b(L)·e^{−δm(L)}`：从 `L=6` 到 `L=12` 抬升 `0.630 → 0.881`，即相对抬升约 `2/5`；取 `b = r(6)/0.630 ≈ 0.30`，可分辨量是 `(0.881−0.630)·b ≈ 0.075`。要求 `3σ` 判据 ⇒ 每点误差 `σ(r) ≤ 0.025`。三个 `N` 给的误差：`L=8` 的 `1.2×10⁵` ⇒ `0.0163/√10 ≈ 5×10⁻³`；`L=10/12` 的 `6×10⁴` ⇒ `≈7×10⁻³`（按 L=8 的 `12k` 读数按 `N^{−1/2}` 外推）。⇒ 三个 `N` 都在门槛上留 3–5 倍余量，不多不少。

### 3.3 判别规则（**跑之前写死**）

```
若 b(L) 在 L=6..12 上平（±0.10 内）：
   常量假设   H0: r(L) = c
   积累假设   H1: r(L) = b·e^{−δm_box(L)}      （δm_box 取 6π²/L² 与 16π²/L² 两个模板各算一次）
   判据： χ²(H1) − χ²(H0) ≥ 9（3σ）且 Δχ² 指向 H1 ⇒ 积累；指向 H0（同门槛）⇒ 未反 I2 的积累
若 b(L) 不平（>0.10）：比值路关 ⇒ 只剩上支（两点层距，N ~ 10⁷），本轮预算内不做
```

### 3.4 上支（只在 §3.3 判「比值路关」时启动；本轮不做）

`L=8`：`N ≈ 6.0×10⁶` ⇒ `10.7 ms × 6×10⁶ ≈ 18 h`；`L=12`：`N ≈ 2.8×10⁷` ⇒ `≈4×10² h`。⇒ 两点层距在 `β=2.5` 的现有算法下不是「一步」，而是 `10¹`–`10²` 小时的阶梯。

### 3.5 明确不做的三件事

1. **不并行**：`CLAUDE.md §4` 的内存纪律（`L=12` 的 GH3 口径单作业峰值 ≤1 GB，两作业并行即触到本机内存边界）。
