## §1 判据：什么叫"给下界"，什么叫"循环"

设 `H` 自伴、下有界，形式域 `Q(H)`，谱测度 `ν = ⟨Ω|E_H(·)Ω⟩`。

- **上界**：给数 `m` 使 `x ≤ m`。**取一个试验态**即可（Rayleigh）。
- **下界**：给数 `m` 使 `m ≤ x`。**只有两条逻辑通道**：
  - **(P) 全称证书**：`∀ψ∈Q(H)`（或某个**形式核**）验证一个不等式 ⇒ 代数/算符恒等式；
  - **(O) 与谱无关的量去钉它**：序比较（另一个算子）、隔离窗（另一段谱）、等周（集合几何）。
- **循环判据（本文用）**：若工具的**前提**已经包含 `inf σ` 的等量信息（隔离地板、本征空间、矩的主导项、`E₀`），记**循环**，不计出口。

**位置的外延警告 `[T]`**：`inf supp ν ≥ inf σ(H)`，可能**严格**大（单个态的谱测度可以漏掉谱底）。⇒ 任何 `inf σ(H) ≥ c` 的结论**可传**到 `inf supp ν`；反之，在**错误扇区**上得到的下界**不可传**（与 `U03-I2` 的扇区纪律一致）。

## §2 工具 1：Rayleigh 变分（Rayleigh 1877）

**[T] 定理.** `H` 自伴、下有界，`Q(H)` 稠密 ⇒
```
inf σ(H) = inf_{0≠ψ∈Q(H)}  ⟨ψ|H|ψ⟩ / ‖ψ‖² .
```
- **给的是什么**：`∀ψ: R(ψ) ≥ inf σ(H)` ⇒ 单个试验态给 **上界**。
- **反向？** 反向**不是**定理，而是**目标的改写**：
  `inf σ(H) ≥ c  ⟺  ∀ψ∈Q(H): ⟨ψ|Hψ⟩ ≥ c‖ψ‖²`.
  这条等式的**内容**全在"如何证"：需要写成 `H − c = A*A`（或 `Σ_α A_α*A_α`）这类**算符恒等式**。这就是 **PSD/SOS 证书**，属 (P) 通道，与变分原理无关。
- **形式核细节 `[T]`**：只需在**形式核**（form core，形式范数下稠密）上验证，再由形式闭性延拓；在**非核**的稠密子空间上验证**不能**延拓（这是最常见的伪证来源）。
- **YM**：`S_W` 不定 ⇒ 没有显然的 `H ≥ c`。仓内已把这条通道判到假设层：SDP 证书的引擎是 `H² − δH ⪰ 0 ⟺ spec(H)∩(0,δ)=∅`，前提 `H⪰0` 且 `E₀=0`；而格点 YM 的 `E` 无界、`E=0` 不在 `L²(G)` ⇒ 真基态 `E₀ = N×(零点能密度) > 0` ⇒ 证书输出 `δ_max = E₀ − c'`，**就是你对 `E₀` 的无知**（`SDP-CERT.md:21–27`，AKLT 上实测 `δ_max(c)=c` 而真隙 `0.350092`）。
- **判**：**[T] 上界；下界需独立证书，[O] YM 上缺 `E₀`。**
- **酸测**：自由场证书给 `c=0`（正确、无内容）⇒ 证书型工具过酸测靠的是"YM 上真有正下界"，不是形式本身。

## §3 工具 2：min–max（Courant 1920 / Fischer 1905；Reed–Simon IV, Thm XIII.1）

**[T] 定理.** `λ_k = min_{dim M=k} max_{0≠ψ∈M} R(ψ) = max_{codim M=k−1} min_{0≠ψ∈M} R(ψ)`.
- **可算的一侧**：给定 `k` 维试验子空间 `M`，`λ_k ≤ max_{ψ∈M} R(ψ)` ⇒ **上界**。
- **另一侧名义上是"下界侧"**（`max` over codim-`(k−1)`），但计算内层 `inf_{ψ∈M}R` 需要**已知前 `k−1` 个本征空间**（一般取 `M = (span{v₁..v_{k−1}})^⊥`）⇒ 前提里装着答案。
- **判**：精确刻画，**不是可算的界**；无独立下界输出 `[O]`。仓内同判：`min–max` 是 *min* ⇒ 上界（`E2-REGRESS-CIRCULARITY.md:65`）。

## §4 工具 3：Temple / Weinstein（Temple 1928；Weinstein 1934）—— **本清单唯一的"真下界"定理**

**[T] Temple 不等式.** `ψ` 归一，`β := ⟨ψ|H|ψ⟩`，`ε² := ‖(H−β)ψ‖²`。若存在 `ρ` 使
```
σ(H) ⊂ {E₁} ∪ [ρ,∞),        β < ρ ,
```
则
```
β − ε²/(ρ−β)  ≤  E₁  ≤  β .
```
右半 = Rayleigh（上界）；**左半 = Temple（下界）**。

**[T] Weinstein 形式.** 对任一 `λ ∈ σ_d(H)`，`δ := dist(β, σ(H)\{λ})`：
```
|β − λ|  ≤  ε²/δ .
```
取最低谱即上式。**自检**：二维模型 `H=diag(0,Δ)`、`ψ=(cosθ,sinθ)`：`β=Δsin²θ`、`ε²=Δ²sin²θcos²θ`、`δ=Δcos²θ` ⇒ `ε²/δ = β = |β−E₁|`，**取等**（两侧同时紧）。

- **循环在哪一步 `[T]`**：`ρ` 的语义是"`E₁` 与其余谱隔离，且其余谱绝对地板 `≥ ρ`"。而 `E₂ ≥ ρ`（与未知 `m₁` 无关的**绝对**地板）在单标度协变 `E₂ = ρ_true·m₁` 下**⟺ `m₁ ≥ ρ/ρ_true` = 隙**。⇒ 拿 `ρ` 当输入 = 预设答案（`E2-FLIP-L1-VNW.md:13`）。把**相对**比值 `E₂ ≥ (1+c)E₁` 喂进去更糟：`c` 取真值时 Temple **精确返回 `m₁ ≥ m₁`**（`E2-FLIP-L1-VNW.md:53,149`）。
- **非循环的唯一用法 `[C]`**：把 Temple 用在**已被独立隔离**的窗口上（盒上 Dirichlet/Neumann 夹逼、或某对称扇区内已知的第二本征值下界），把变分上界升级为**双侧夹逼** —— 它是**精化机**，不是**存在机**。
- **判**：**[T] 陈述；[C] 对目标循环**（`IMP-ARROWS.md:61` 行 9 已判 `[NG]` 循环；`COND-FILTER.md:55`）。
- **酸测**：自由场谱 `[0,∞)` 连续、无隔离窗 ⇒ 假设失败、自动失活 ⇒ **过酸测**（这也是它在本项目里"看起来能用"的原因）。

## §5 工具 4：Lieb–Thirring / 谱矩

**[T] LT（Lieb–Thirring 1976；CLR 1972–77）.** 对 `H=−Δ+V` on `L²(ℝ³)`，`p ≥ 1/2`：
```
Σ_j |λ_j(H)|^p  ≤  L_{1,p} ∫_{ℝ³} |V_−(x)|^{p+3/2} dx .
```
- **给的是什么**：`N(E;H) ≤ C E^{−(p+3/2)}∫|V_−|^{p+3/2}` ⇒ **计数函数的上界**（"至多几个在 `E` 以下"）⇒ 不能强制**存在**一个 ⇒ **对底部无下界**。
- **矩路（反向尝试）`[T]`**：`tr H^{−p} = Σλ_j^{−p} ≥ λ₁^{−p}` ⇒ 若 `tr H^{−p} ≤ C` 则 `λ₁ ≥ C^{−1/p}`。**方向是对的**（这是与 §1(P) 不同的第五条形式通道），但三条同时断：
  1. 该界**首项就是 `λ₁^{−p}`** ⇒ 任何足以给出正下界的 `C` 已经知道 `λ₁` ⇒ **循环**；
  2. LT/半经典常数对 `(λ,V)↦(t²λ,t²V)` **齐次** ⇒ 输出随标度走，给不出与耦合无关的正底；自由场 `V=0` 给 `λ₁ ≥ 0`；
  3. YM 的"位势"是 `2adF_B`（不定），其负部**不在** `L^{p+3/2}`（连续极限）；格点上 `V_−` 随体积增长。
- **与仓内 A1′ 的关系（须分清）**：`D06-SPEC.md:33` 推论 A1′ `[T]` 管的是**多项式矩** `∫s^k dν` 与 `s`-极值 ⇒ 那是 `𝔉 ≥ m₁`（**上界**）。`tr H^{−p}` 是**逆矩**，不属 A1′ 字面覆盖 ⇒ 本文件单列（这是 A1′ 的一处边界补丁）。
- **判**：**[T] 定理；[O] 对 `inf spec` 无内容/循环。**

## §6 工具 5：比较原理（Sturm 1836；算子形式 = 形式序单调性）

**[T] 定理.** 若 `Q(H₁)=Q(H₂)=:Q` 且 `∀ψ∈Q: ⟨ψ|H₁ψ⟩ ≥ ⟨ψ|H₂ψ⟩`，则 `inf σ(H₁) ≥ inf σ(H₂)`（逐点由 min–max 得）。
一维 Sturm：同 Dirichlet 边界下 `q₁ ≥ q₂ ⇒ λ_k(q₁) ≥ λ_k(q₂)`，`k` 全部。
- **给的是什么**：**下界**机器（挑一个底已知、可比较的参考算子）。
- **一般下界 `[T]`（记录形态）**：`inf σ(−Δ+V) ≥ −‖V_−‖_∞`（由 `⟨V⟩ ≥ −‖V_−‖_∞`）。**当 `V` 不定/负部大时无用**。
- **YM 适用？不能。** 要 `H_YM ≥ H_ref` 且 `inf σ(H_ref)>0`；但 Hessian `−D²+2adF_B` 在横向磁扇区有负模（`Hess` 不定，W4 实测 **7.1%** 负）⇒ 无逐点/形式序；与 `H_ref=0` 比较只给 `inf σ ≥ −‖V_−‖_∞`，负、无用。
- **仓内已判**：比较要么同义反复、要么已假设 `H1`（`PROOF-DIRICHLET-COMPARISON.md:16`："comparison is either tautological or assumes H1"）。
- **判**：**[T] 陈述；[O] 对 YM 不适用**（缺正定序）。

## §8 工具 7：Cheeger 型（Cheeger 1970；图版 Alon–Milman / Dodziuk）

**[T] 定理（流形）.** 闭 `d` 维 Riemann 流形：
```
λ₁ ≥ h²/4 ,      h := inf{ area(∂S)/vol(S) : vol(S) ≤ vol(M)/2 } .
```
**[T] 定理（测度版，本仓所用口径）.** `μ = Z^{−1}e^{−S}dU`：
```
λ₁(μ) ≥ h(μ)²/4 ,   h(μ) = inf_A  μ⁺(∂A) / min(μ(A), μ(A^c)) .
```
**[T] 定理（图版）.** 归一化 Laplacian：`λ₁ ≥ h²/2`（常数依归一化而异，用前必须核归一化）。
- **给的是什么**：**下界**，且输入 `h` 与谱**无关** ⇒ 结构上**非循环**。**是 sign-free**：不读 `Γ₂`、不要求 `−D²+2adF_B` 定号 —— 这是它相对 Bakry–Émery 的唯一真优势。
- **可算性**：`h` 是**集合上的下确界** ⇒ 直接计算不可行（组合爆炸）。要**下界** `h` 需等周不等式；举一个坏集合只给 `h` 的**上界**（⇒ `λ₁` 的上界，方向反了）。
- **在 YM 上它落到哪 `[T]`**：边际上 `h ≍ 1/√χ`（`h·√χ = √(2/π)`），而瓶颈集的宽度就是软模 `σ = √Var(a) = λ^{−1/2}` ⇒ `h_binding ∼ √λ` ⇒ 代入 Cheeger：`λ ≥ (√λ)²/4 = λ/4`，**同义反复、零正性**（`CHEEGER-CORE.md:59,102–104`）。⇒ 均匀 `h>0` **⟺ `χ ≤ 1/h₀²` ⟺ H1**（`CHEEGER-BUILD.md:141`、`BASE-NONLOCAL-BOUND.md:85`）。
- **严格标定**：`h²/4` 只抓到真隙的分数 **`1/(2π) = 0.159155`**（Gaussian 边际精确值，scale-invariant；`BASE-NONLOCAL-BOUND.md:74`）。
- **判**：**[T] 陈述可给；[O] 可算性不可 + 仓内已判死**（`CHEEGER-CORE` 2/5、`CHEEGER-BLIND` 2/5、`B3-ISOPERIMETRIC` 2/5；`LOOP-RUNBOOK §11.59` 记 Cheeger 超支 **2.262×**）。
- **替代但不可算**：Buser 反向 `λ₁ ≤ C(h+√h)` 需要 `Ric` 下界 —— 恰是 Savvidy 否掉的 `Γ₂`（`Ric+Hess S ≈ −2.3`）⇒ 两侧夹逼的两条腿都断（`CHEEGER-BLIND.md:48`）。

## §9 判死线 (a)/(b)/(c)——逐字

### (a) 有"给 `inf supp ≥ c` 下界且非循环"的逐字定理吗？—— **无。**

本清单里**输出下界**的只有四类机制，各自的输入：

| 机制 | 逐字定理 | 方向 | 必需输入 | 该输入在 YM 上的状态 |
|---|---|---|---|---|
| 形式正性证书 | `inf σ ≥ c ⟺ ∀ψ∈Q: ⟨ψ,Hψ⟩≥c‖ψ‖²`（定义级）＋ `H−c=A*A` | **下界** `[T]` | 算符恒等式 + `E₀` | `S_W` 不定；`E₀≠0` ⇒ 返回"`E₀` 的无知"（`SDP-CERT`） |
| 序比较 | `H₁ ≥ H₂ ⇒ inf σ(H₁) ≥ inf σ(H₂)` | **下界** `[T]` | 正定参考 `H_ref` | 无正定序（负模 7.1%） |
| 隔离窗 | Temple `β−ε²/(ρ−β) ≤ E₁` | **下界** `[T]` | `ρ ≤ E₂` 绝对地板 | **⟺ 隙**（循环；精确返回 `m₁≥m₁`） |
| 等周 | `λ₁ ≥ h²/4` | **下界** `[T]` | `h ≥ h₀` 均匀 | `h ≍ 1/√χ` ⇒ `λ≥λ/4`；均匀 `h>0` ⟺ H1 |

⇒ 四类全部命中"输入 = 目标"。**给不出 (a)。**

### (b) "位置下界没有现成工具"—— **成立**，但须精确成两句：

- **(b1)** 现成工具里**能**输出下界的只有 **{证书, 序, 隔离窗, 等周}** 四类（外加"逆矩"这条形式通道，但首项即答案）。
- **(b2)** 四者在本问题上分别因 **{`S_W` 不定 + `E₀≠0`, 无正定序, 隔离即目标, 无等周下界}** 而全部不可直接用。

**加强（比"没有工具"更强的一句，`[T]` + `[O]`）**：由 `D06-SPEC` 推论 A1′/A1″，任何**平均型**泛函（有限多项式矩、有限-`t` 正则化、`s`-极值）在 **M6**（`m₁=0` 但 `ν≠δ₀`）上**必为正**，而在 2D YM 上也 `>0` ⇒ 撞车、分辨不出。⇒ **若位置下界存在，其载体必须是"非平均、非弱连续"的对象**（地板函数 `1{m₁≥δ}` 型，lsc 而非连续），不能是任何积分。这条把"要造什么"钉死了：**不是更聪明的平均，而是一个判定/上确界-下确界对象。**

### (c) Cheeger 那条可行吗？—— **陈述可行，可算性不可，且仓内已判死。**

- **陈述**：`λ₁(μ) ≥ h(μ)²/4`，`h(μ)=inf_A μ⁺(∂A)/min(μ(A),μ(A^c))`（Cheeger 1970；图版 `h²/2`）。真、sign-free、方向对 `[T]`。
- **可算性**：`h` = 集合下确界 ⇒ 不可算；要下界 `h` 需等周不等式，而 YM 配置空间**无已知等周下界**。
- **自我拆解（决定性）**：唯一可得的 `h` 估计 `h_binding ∼ √λ` 代回自身给出 `λ ≥ λ/4` ⇒ 同义反复；均匀 `h ≥ h₀>0` 与 `χ ≤ 1/h₀²`（= H1）**等价**。
- **旁证**：`h²/4` 的分数 `1/(2π)` 结构性损失 > 目标余量（Gaussian 纤维上超支 **2.262×**）。
- **判**：**框架对、输入缺、已判死（2/5 三处独立）。**

## §11 出口的形状（`[O]`，非定理；供 lead 派工）

要证 `inf supp ν ≥ c`，必须在四类机制里**造**一个可用输入，或造第五类非平均对象：

1. **算符恒等式证书**：把 `H_YM` 写成 `A*A + c`（或 `≥ c` 于**形式核**），并**同时**处理 `E₀≠0`（把零点能显式移出，给出 `E₀` 的独立界）。唯一"证明型"出口；缺件 = `E₀` 与 `S_W` 的正定分解。
2. **序比较**：先把不定部分吸收进 `A*A`，得到 `H ≥ H_ref`（`inf σ(H_ref)>0`）—— 即把 §2 与 §6 合成一步。
3. **隔离窗 + Temple**：只要能**独立**得到"`E₁` 与其余谱隔开且其余 `≥ ρ`"，Temple 立刻把上界升级为下界。这是最省的**搬运接口**，但 `ρ` 的绝对地板是硬点（相对比值无用：`m₁≥m₁`）。
4. **等周下界**：造一个与谱无关的等周量并给下界。当前缺，且已知 `h ≍ 1/√χ` ⇒ 除非 `χ` 有独立上界，否则不可达。
5. **非平均对象（第五类）**：由 A1″/`D06-SPEC`，必须是非连续的地板型泛函（`1{m₁≥δ}` 型），或某个 sup-inf（判定）泛函 —— **任何积分都不可能**。

**反向陷阱（必须写清，纠正任务前提）`[T]`**：
```
Var_ν(f) ≤ C·E(f,f)   ⇒   λ₁ ≥ 1/C .
```
即 **方差型量是能给下界的**，条件是它构成**一致的 Poincaré 不等式**（常数与体积、耦合无关）。所以"曲率/方差只能给形状"这句话的正确形式是：**曲率本身不是下界；一致 Poincaré（或 `Γ₂ ≥ ρ` 全局成立）才是下界。** 本项目的障碍不是方向，而是**一致性/绝对标度**：`Γ₂≥ρ` 只在局部/正定扇区成立（负模 7.1%），且 `1/√χ` 是 lattice-unit 量、随 `a(β)` 变（`ROOF-TRANSPORT-SCALAR.md:31–34`）。⇒ `G″`/`Var` 路线的问题定位应改为"**一致性**"，不是"**形状 vs 位置**"。
