### 1.3 `(F4)` vs `(F1)`：三行代数（本文件的核心计算）

## §3 三条攻法（逐条判）

### 3.1 (a) 变分：能否造试验函数使 `χ ≤ (1−c)/λ` 由 min-max 得到 —— 判 **`[NG]`**

**(a-1) 方向。** `χ = Var(a)` 是**上确界**：`Var(a) = sup_{h: E[h]=0} (E[ah])²/E[h²]`（C-S）。要给它**上限**，需要一条对某个二次型/谱隙的**下限**。min-max（Courant–Fischer / 极小极大）确实产下界 —— 所以机器类型对，但它的输出是**隙**不是方差，两者之间没有免费通道。

**(a-2) 唯一的 min-max 上限路，以及它为什么吸不住 `(1−c)`。**

```
Rayleigh（试验函数 φ(a)=a）：  λ₁(ν) = inf_φ ℰ_ν(φ)/Var_ν(φ) ≤ 1/χ        [T]  (Q6:129–131)
故  λ₁(ν) ≥ λ  ⟹  χ ≤ 1/λ = H1(λ)                                          [T]
```
这条路**严格强于** H1（`λ₁ ≤ 1/χ` 取等 iff `φ=a` 是极小元 iff `ν` 高斯，`Q6:138–141`），而且它的失效模式是**指数**的：
```
Kramers 双井 V_eff=(g/2)(y²−1)²:  Var = O(1)（H1 对固定 λ 成立）而 λ₁ ∼ e^{−g/2} → 0
```
（`Q6-H1-STATUS.md:133–136`）。⇒ **变分产物可以比 H1 弱指数级**，而 `(1−c)` 余量是 `O(1)`。**余量吸不住指数差**。这一条同时解释了为什么 `(F4)` 的 `c` 在这条路上无处安放。

**(a-3) 阶数：min-max 碰不到 `D`。** 精确分解在 Lean 里是**结合律**：
```
gDouble_eq_S_sub_D :  G″ = S − D         由 ring 关闭，W 是自由参数     [T]
lean/YMStatement/Reduction.lean:66,72–74（经 GA2-DEFECT.md:66 转引）
```
`S = E[h_n|a₀]` 是**二阶型**（`h_n = vᵀHess V v`）的期望 ⇒ min-max 的范畴；而 `D = Var(∂_nV|a₀)` 是**一阶导数的二阶矩**，它不是任何二次型的极小极大值。`GA2-DEFECT.md:154` 已把 `F1` 的两条唯一逃法逐一判死（`D` 换鞅分解上界 / `S` 换 Schur 下界，后者"在 `D≥0` 时被靶蕴含 ⇒ 比靶弱且不足以推靶"）。⇒ **这条路上 `D` 没有任何变分表示**。

**(a-4) `ess inf` vs 点值。** min-max 在极小点给 `G″(a₀*)`；H1 要的是 `ess inf`。`Q6:147–150` 逐字：点值 `G″(a₀*)≥λ` 不是 `ess inf`；Savvidy 侧翼让 `G″` 在**半支撑**上为负 ⇒ BL 的前件恰在地板被引用的地方失败。

**(a-5) 已证最好常数也挡在路上。** 即使接受 `S` 的下界，`c` 槽已证最好值 `1.152 / 1.429 / 7.242` 全 `>1`（`GA2:126–129`）⇒ `(1−c) < 0`，`(F4)` 退化。

> **判 (a) = `[NG]`**，具名证书三条：**(a-i) 方向**（min-max 产隙、H1 要方差上限，中间无免费通道）；**(a-ii) 强度比**（唯一上限路 `λ₁≥λ` 严格强于 H1，失效模式 `e^{−g/2}` 指数，`O(1)` 余量吸不住）；**(a-iii) 阶数**（分解是 `ring`，`D` 是一阶导数的二阶矩，不在任何变分原理的值域里）。
> **下一手（唯一一条）**：把变分对象从 `Hess V`（阶 2）搬到 `∂_nV`（阶 1）——可达的最强形态是**条件 Simon–Lieb**：
> ```
> Var(∂_nV | a₀) ≤ E[ ⟨∇_⊥(∂_nV), K⁻¹ ∇_⊥(∂_nV)⟩ | a₀ ],   前件 K := Π₀ Hess V Π₀ ⪰ γI
> ```
> 前件 `K⪰γI` 就是 `H2-DEFECT-BOUND.md` 的具名缺步（等价 `E⟨K⁻¹c,c⟩ < S`）。⇒ **下一手 = 攻纤维隙 `K⪰γI`，不攻 `χ`**。

⇒ X := −2Cov ≤ 0 ⇒ 把 G″ 往【下】压 ⇒ 更强的关联 = 更轻的模 = anti-gap

### 3.4 三条攻法的合判：为什么它们死在同一点

| 攻法 | 死因（一句话） | 它产出的东西的**类型** | 与 H1 需要的类型的差 |
|---|---|---|---|
| (a) 变分 | 方向对但阶数错：min-max 作用在阶 2 二次型上，`D` 是阶 1 导数的二阶矩 | 谱隙（**下**界） | 指数 vs `O(1)` 余量 |
| (b) 正性 | BL 是换名且前件即墙；FKG/Ginibre **符号反** | 相关下界（**推高** χ） | 上界 vs 下界 |
| (c) 反例 | `¬H1 ⇒ ¬gap` ⇒ 反例即靶的反面 | 无隙模型 | 需要的是 YM，不是任意测度 |

**统一死因（本文件的中心判断）**：
```
H1 是【ν 在 0 附近支撑】的陈述（"没有一致光模"），
而仓内全部工具都通过【积分】读 ν：矩（Schur-凹）、PSD（C-S 只压非对角）、逐点曲率（点值≠ess inf）。
按 Schur-凹性，积分泛函只能给 f₁² 的【上】界、看不见支撑底：
      δ₀+δ₂ 与 2δ₁ 同矩异边（Q6:212–217；LOWER-AMPLITUDE-MECHANISMS.md:28）
⇒ 任何"从积分/正性/曲率推出的 H1"必须先在某个环节把【支撑】偷渡成【矩】，
   而偷渡点就是 1/χ = 调和平均 这条恒等式 —— 它把支撑问题伪装成矩问题。
```
> **判**：三攻法合判 = **`[NG]`**（统一死因已具名）。
> **下一手**：三攻法各自的下一手已写在 §3.1/§3.2/§3.3 末行；**共同**的下一手是 §5.4 (iii)：把"纯 YM 无标度不变性"接进来，因为只有它不是积分泛函。
