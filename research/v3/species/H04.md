## §2 等价吗

### 2.1 代数：等价，`X` 自动相消 `[T]`

两条恒等式（都逐字在库）：

```
G″ = Δ_dyn + W_geo + X                       （B03.md:26；sec02-obstruction-one.tex:14–15；S3-UV-FESHBACH.md:95）
W_full := W_geo + X                          （H3-RECONCILE.md:67；H1C-WFULL.md:18,30；H1A-EXACT.md:37；app.tex:190）
```

代入：

```
G″ − W_full = (Δ_dyn + W_geo + X) − (W_geo + X) = Δ_dyn      —— 对一切 X，无附加条件。
```

**语料自己就这么写**：

- `docs/paper-v2/app.tex:190–192` 逐字：*"This is the (M) form … with `W_full = W_geo + X` and `δ := a²Δ₀² + W_full`; **the two displays are the same inequality (the `W_full` cancels on both sides, since `G″_a = Δ_dyn + W_full`)**."*
- `H1C-WFULL.md:25` 逐字：「由 `eq:split`，`W_full = G″ − Δ_dyn`」。
- `RECONCILIATION-STAR.md:213–214` 逐字：`G″_j = Δ_dyn + W_j`，`W_j = W_geo + X`。

⇒ **等价性成立，而且是恒等式层面的等价 ⇒ 判 (a)。** 代价是**零信息**：义-2 不能当独立算法；`P03-M6REL.md:158` 逐字「四模型表对 `Δ_dyn` 的"测量"**在四格里都是恒等式记账**」`[T]`。

### 2.2 ★ 但 `H3-RECONCILE.md:100` 的判据写错了（必须更正）

`H3-RECONCILE.md:98–102` 逐字：

> 恒等式是 `G″ = Δ_dyn + W_geo + X`。代入 `W_full=W_geo+X` 得
> ```
> G″ − W_full = Δ_dyn + W_geo + X − (W_geo + X) = Δ_dyn  ⟺  X = 0 .
> ```
> ⇒ 义-2 **当且仅当 `X=−2Cov(G,Φ′)=0`** 时成立。`X≡0` 的窗口极窄…

**问题**：它自己的算式左端算出 `= Δ_dyn`，**与 `X` 无关**；后挂的「`⟺ X=0`」没有代数依据 —— 那一步只有在把 `W_full` 读成 `W_geo`（丢掉 `X`）时才成立，而同一句里刚写了 `W_full = W_geo+X`。⇒ **`H3-RECONCILE` 的结论（"只有义-1 是定义、义-2 只能当改写"）操作上对，判据错**：义-2 = 义-1 **无条件**成立，不是只在 `X=0` 窗口。`[T]`

**连带**：`H3-RECONCILE.md:102` 的「`X≡0` 窗口极窄（SU(2)@`a₀=0`）」不是义-2 的适用窗，只是 `W_full=W_geo` 的窗 —— 该句应改挂到 `W_full` 名下。

### 2.3 那 2D 与 M6 的"分歧"来自哪

- **2D `Δ_dyn = 0` 精确**：来自**平坦模引理**，与两定义无关。`B03.md:40–42` 逐字：`S_W≡0` 沿整条模线 ⇒ `Δ_dyn=E[H]−Var(G)=0`（取等）、`X=0`、`W_full=W_geo`。⇒ 两定义在 2D 上给同一数（`X=0`）。
- **M6 的分歧是"模"的分歧，不是"定义"的分歧**：`B03.md:57` 逐字「`ρ_a ∝ e^{−ωa²}` ⇒ `V_eff=−logρ=ωa²` ⇒ `H=2ω`、`G=2ωa`（只依赖被条件化的 `a`，故 `Var(G|a)=0`）、`Φ=0` ⇒ `Δ_dyn(a)=2ω=G″`；自由方向 `b`：`S≡0` ⇒ `Δ_dyn(b)=0`」。`B03.md:69` 表：M6 `2ω`(a)/`0`(b) ⇒ `inf_v=0` `[T]`。
- 真正使 M6 读数不唯一的是 **`V` 的口径**，`P03-M6REL.md:16` 逐字：「§4 三读法：`2ω / ω² / 0`，**在 `ω ≠ 2` 上互不相等**」；`:146` 逐字「`Δ_dyn = 2ω` **不是算出来的**，是把 `G″ = 2ω` 抄进一个定义式的右端」。⇒ **M6 上的 `2ω` 是义-2 的代入，不是义-1 的测量**（`V_eff=−logρ` 使 `E[H]=G″` 循环）。

## §3 `a²Δ₀²` 里的 `a` 是哪个

### 3.1 判：**格距**（lattice spacing）`[T]`

四条独立逐字：

| 证据 | 逐字 |
|---|---|
| 与 `L` 并列出现 | `app.tex:183`：*"uniformly in `$(L,a)$` and for every coarse transverse `v` at `k→0`"* ⇒ `a` = 与 `L` 同级的格点参数 = 格距 |
| 量纲锚 | `Q6-H1-STATUS.md:314`：`G″_a=a²m_phys²`；`:281`：`G″_a/a² ≥ Δ₀²` *"(dimension-correct under `Z_O` transport; a constant `λ` is a lattice artifact)"* |
| 连续极限 | `U4-CONTINUUM-ATOM.md:261`：*"on the lattice `m_lat=√G″_a=a·m_phys`"*；`:120`：`G″_a` → `→a²Δ₀²` |
| 记号明文 | `B02.md:24`：**「记 `β_W = 2N/g²`，`a` = 格距」** |

**量纲强制（独立复核）`[T]`**：`sec02:10–11` 里 `v` 是 **unit** coarse mode、`V=S_W+Φ`（`S_W` 无量纲）⇒ `H_{vv}=∂²_vS_W` **无量纲** ⇒ `Δ_dyn` **无量纲**。而 `a²Δ₀²` 要无量纲 ⇒ `Δ₀` 带质量量纲、`a` **只能是长度**。⇒ `Δ₀` = **物理质量地板**（`G″_a = a²m_phys²` ⇒ `m_phys ≥ Δ₀`），与 `B02.md:128` 逐字「`∃Δ₀>0 ∀(L,a)∀v: Δ_dyn ≥ a²Δ₀²` **量纲是对的**（`G″_a = a²m_phys²` ⇒ `m_phys ≥ Δ₀`）」一致。

⇒ **`a` = 格距，`a₀` = 粗幅，两者不是同一个东西。** 这就是 `H3-RECONCILE.md:110` 的 `Δ₀² := (G″−W_full)/a² = Δ_dyn/a²` 里那个 `a`：**格距**。

### 3.2 但口径有四处撞名（这才是 (c) 的真实内容）`[C]`

| 字母 | 三个身份 | 逐字出处 |
|---|---|---|
| `a`（裸） | ① 格距（`∀(L,a)`、`a²Δ₀²`、`G″_a`） | `app.tex:183,187`；`B02.md:24` |
| | ② **粗幅**（`ρ_v(a)`、`−∂²_a log ρ_v`、`Δ_dyn,a` 的下标） | `sec02:11` `⟨v,ξ⟩=a_0`；`RECONCILIATION-STAR.md:69,112`（`Δ_dyn,a`、`Δ_dyn,μ`）；`GPP-STRUCT.md:43` |
| | ③ **M6 谐振子坐标**（`a` ⊗ `b` 双模） | `B03.md:16`「谐振子 `a` ⊗ 自由圆环 `b`」；`:57` |
| `Δ₀` | ④ 曲率地板 vs 通道隙 `Δ_(0)/Δ_(2)`（**已改名消掉**） | `H3-RECONCILE.md:106–113`；`LOOP-RUNBOOK.md:10423` |

**⇒ 裸 `a` 不可读。** 本条的修法是纯记号层、不动任何断言：**格距写 `a`，粗幅一律写 `a₀`，M6 模写 `a`-模/`b`-模并加 `(M6)` 标签**。

**另有一处必须记的闭环风险 `[C]`**：`H3-RECONCILE.md:110` 把 `Δ₀²` **定义**成 `(G″−W_full)/a² = Δ_dyn/a²`。若采用这一定义，则 H1「`Δ_dyn ≥ a²Δ₀²`」退化为 `Δ_dyn ≥ Δ_dyn`，**恒真**。`app.tex:182–183` 用「There is `Δ₀>0` such that … uniformly in `(L,a)`」把它钉成**量词常数**（不是 `√Δ_dyn`；`N02-FOURMODEL.md:5–6`、`H1-FINAL.md:87` 逐字「不是 `√Δ_dyn`」）⇒ 只有这一读法使 H1 有内容。**引用 `Δ₀² := Δ_dyn/a²` 时不得同时把它当 H1 的右端。**

## §4 判：`Δ_dyn` 钉死了吗

| 层 | 状态 |
|---|---|
| **对象**（哪个数学量） | **钉死 `[T]`**：`Δ_dyn := E[H|a₀]−Var(G|a₀)`；义-2 是它的恒等式改写（§2.1），**不构成第二版本**。 |
| **算法**（怎么独立算） | **未钉死 `[C]`**：`P03-M6REL.md:158` 逐字「若要把 `Δ_dyn` 当独立对象用，**必须先给它的独立算法**（在 Gibbs 口径下逐点算 `E[V″|0] − Var(V′|0)`，`V = S_W + Φ`），这件事在语料里**一处也没做过**」。`N10-LATTICE.md:18` 说"能直接测"，但那是在**同一批构型上的两个期望**，仍受 `V` 口径支配。 |
| **数值口径** | **未钉死 `[C]`**：M6 三读法 `2ω/ω²/0`（`P03-M6REL.md:16`）；`∀v` 读法给 `inf_v Δ_dyn=0`（过），逐模 `v=∂_a` 读法给 `2ω`（不过）——`B03.md:61` 逐字「**当前口径下 `Δ_dyn` 的失败只剩 2D**」。 |

⇒ **结论**：`Δ_dyn` 作为**对象**已钉死；作为**数**没有。凡写 `Δ_dyn = 某数`，必须带 `(模型, 条件化的模 v, V=S_W 还是 S_W+Φ)` 三标签，否则不可比。
