## §1 · 定义钉死（先把两个"隙"分开，否则整节会串）


## §3 · 2D 的确认：`ν_{¼trF²} ≡ 0`（判据核心）

### 3.1 守恒论证 `[T]`（一行到三行）
2D 只有 `F₀₁ = E` 一个分量：`F² = 2 tr E²`、`¼trF² = ½trE²`；而 `H = (1/g²)∫dx ½trE²`
⇒
```
O := ¼trF² = g² · (能量密度 h)          ⇒   [O,H] = 0 ,   O|Ω⟩ = 0（真空能量密度为零）
⇒ (O − ⟨O⟩)Ω = 0  ⇒  全部连通矩阵元为零  ⇒  ν_{O,c} ≡ 0
```
**这不是"底上没有原子"，是"整个测度为零"。** ⇒ 2D 上 `I1` 假（`f₁²=0 < r₀`），而隙 `=3g²/8>0`。
**与语料一致**：`F06:102–108` 已判"2D 不是'原子在 `L→∞` 消失'的例子（它每个 `L` 都 `f₁²≡0`，机制是载体解耦）"；`IMP-ARROWS:57,62` 记"2D 的 `trF²` 原子**恰为 0**"。

### 3.2 格点侧精确核对 `[E]`（`w7/atom2_2dym.log`）
```
E_j = (g²/2) j(j+1)    j=0,1/2,1,…      (g²=1)
E_0 = 0 ,  E_{1/2} = 3/8 = 0.375 ,  E_1 = 1 ,  E_{3/2} = 15/8      ← [1]
gap = E(1/2)−E(0) = 3/8  （精确有理数；= 3g²/8，与题面同数）        ← [1]
```

### 3.3 ★ 判 (c)：`f₁²≡0` 是**逐算符**的，不是"这个模型没有原子" `[E]`
同一条 2D 模型、同一套 Hilbert 空间，取 `O₂ = ½trU = χ_{1/2}`（基本表示链算子）：
```
矩阵 ⟨n|χ₁|m⟩（`atom2_2dym.log [4]`）：⟨0|χ₁|1/2⟩ = 1.000（精确）
⇒ f₁² = ν_{O₂}({E₁}) = 1 ，E₁ = 3g²/8
```
⇒ **"2D 有隙无原子"必须读成**：
```

而**不是**：2D 这个模型不产生原子                    ← 假 [E]（½trU 给 1）
```

机制：`¼trF²` 在 2D 是**守恒荷**，连通部分湮灭真空；`½trU` 是**阶梯算子**（`j→j±1/2`），恰好把真空打到 `j=1/2`。
**⇒ 4D 不可搬**：4D 的 `¼trF²` 含 `B²` 项，`[O,H] ≠ 0`，2D 的"零原子"是**维数锁定**（`IMP-ARROWS:62` 已记 "n/a (`d=2`)"/"维数锁定"）。所以 2D 证明的是**"原子性不是隙的普遍伴随"**，而不是"A 路在 4D 上假"。

## §7 · 判死线

**(a) 部分成立（限定版）。** `A 路在 2D 上为假` 是 `[T]`（`f₁²=0` 而隙 `=3g²/8>0`）⇒ **A 路不是 Clay 的书写**。但题面的推论"⇒ 它们**比 Clay 强** ⇒ 不是 Clay 的路"**不成立**：`A ⇏ Clay`（M6 反方向），`Clay ⇏ A`（2D）⇒ **不可比**，不是"更强"。而 `B 路在 2D 上不假`——`ν≡0` 使 B 的位置谓词**空洞**（无定义），不是被否证。⇒ "两路都不是 Clay 的路"这个**结论对**，但两条路的死因不同：**A = 不可比 + 2D 反例**；**B = 严格弱（`B06`）+ 逐道量词缺（M6）**。

**(b) 成立。** `B 路`的陈述**只含位置**（`inf supp ν ≥ c`），不含原子性；"两路都要求原子性"对 B 是误读（§5 表 + `RUNBOOK §64.3` 的加强读法）。

**(c) 成立，且是本节最锋利的一条。** 2D 的 `f₁²≡0` **只对该算符成立**：同模型 `O=½trU` 在 `E₁=3g²/8` 处原子权重 `=1`（精确，§3.3）。⇒ 正确写法是 **"`2D` 有隙，且 `ν_{¼trF²}≡0`"**，而不是"2D 没有原子"。这一条**加强**判据核心（因为 A/B 要的正是 `ν_{¼trF²}`），同时**限制**它（2D 反例不搬到 4D）。
