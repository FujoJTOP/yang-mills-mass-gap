## §2 `𝒯` 的精确含义（任务 1 的正文）

`𝒯` 逐字（`G04:189`）：

```
𝒯 := { t(·) : √t(a) 固定物理量 , t(a)/a² → ∞ }
```

**读法（三层，逐层可核）**：

1. **它是一个方案族，不是一个方向。** 每个 `t(·)` 定义一个**重整化口径**：用流时 `t` 的 `tr F²(t)` 作
   `0⁺⁺` 算符。Lüscher–Weisz：`t>0` 时 `⟨E(t,x)E(s,y)⟩_c` 有限 ⇒ 算符**已被定义成重整化算符**
   （`[T]`，`PROOF-GRADIENT-FLOW §1`；文献 Lüscher arXiv:1006.4518、Lüscher–Weisz arXiv:1101.0963，
   本仓 `LIT-ERA-09:250–258` 标 VERIFIED，**未逐字核正文**）。
2. **"固定物理"= `a`-无关。** 若 `t(a)` 随 `a` 变，必须变的是"格点单位下的数"；`√t₀` 在**物理单位**
   下不动。等价写法：`√t₀ = c/Λ`，`c` 固定。（**反例**：`t₀ = c·a²·f(a)`，`f→∞` ⇒ 形式上 `t₀/a²→∞`，
   但 `√t₀` 物理上 →0 ⇒ 不满足条款 1。这说明两条款**在方向上不同**：条款 1 钉物理尺度，条款 2 钉格点分离。）
3. **必须 `∃` 一次、不能 `∀` 的理由**：`w₁` 是**同一算符**的比值，`f₁²` 与 `M₀` 同乘 `Z_O²` ⇒ `γ_{w₁}≡0`
   精确（`[T]`，`U4-1:145–154`）⇒ 没有**反常**跑动可用来跑遍 `t`。**但这不等于"零损失"** —— 见 §5(c)。

### 2.1 ★ `𝒯` 的三处缺口（任务 (b)：条件本身不清吗？——**清楚，但过宽 + 冗余 + 记号冲突**）

| # | 缺口 | 逐字后果 | 修法 | 等级 |
|---|---|---|---|---|
| **b1** | **条款冗余** | `t₀/a²→∞` 由条款 1 + `a→0` 推出（§1.3）⇒ 写两条给"两条独立约束"的错觉 | 只写一条：`√t₀ = c/Λ`（`c` 固定），或显式写 `t₀(a) := c²/Λ²` | `[T]` |
| **b2** | **缺 IR 上界（致命的一半）** | `𝒯` 允许 `√t₀ = 100/Λ`（仍"固定物理"、仍 `t₀/a²→∞`），而那里胶球重叠已退化 ⇒ `w₁(t₀)→0`（`U4 §3.3` `[C]`）⇒ `∃w₀>0` 在**该点上为假**。故 `𝒯` **不是**"随便挑一个都行"的域 | 域收紧为**窗** `𝒯' := { c₁/√σ ≤ √t₀ ≤ c₂/√σ }`（用**不预设 `m₁`** 的标度；`𝒯` 本身不许用 `1/m_G`，理由见 ③ 的循环性） | `[T]`+`[C]` |
| **b3** | **函数的集合 vs 一个点** | `∃t₀∈𝒯` 字面是"存在一个**函数**"，而 `G04:177` 又把它当"一次选定的点"用 | 写 `∃t₀(·)∈𝒯`，或直接钉 `t₀ := c²/Λ²`（常数按物理单位读） | `[T]`（记账） |

**⇒ (b) 的判**：`𝒯` **不是**"含义不清"，而是**"读对了就过宽"**：缺 b2 的上界 ⇒ 域太宽，`∃t₀` 必须**挑窗内的点**；
b1/b3 是记账冗余与记号，不致命但必须写清，否则"`t₀∈𝒯` 自动成立"会被误当成"定理"。

## §3 `t₀/a² → ∞` 的物理含义（任务 3）

**逐字三句**：

1. **它压掉 UV（是，且这是它的全部作用）**：涂抹半径 `√t₀ ≫ a` ⇒ 流场在格点上光滑、是**连续场**；
   `M₀(t₀) = ⟨O_{t₀}²⟩_c` 有限、`a→0` 极限存在到 `O(a²/t₀)` 修正（`[T]`，`PROOF-GRADIENT-FLOW §1`、
   `U4 §3.1:182–195`）。等价地：`a^{-8}` 接触项被换成 `≍t₀^{-4}`（量纲 8 ✓，`t₀^{-4}` 也是 8）。
2. **它把 `w₁^{bare}→0` 这个 UV 假象关掉**：`w₁^{bare} = f₁²/M₀^{bare} ≍ f₁²_{phys}a^8 → 0`（`U4:118,122–128`）；
   而 `w₁(t₀) ≍ f₁²_{phys}t₀^4`（§4）⇒ `t₀/a²→∞` 就是"从 `a^8` 换到 `t₀^4`"那一步。**这一步不改变物理，
   只是把分母里的 UV 计数**取掉**。
3. **它是免费的不是细调**：`t₀/a² ≍ c²e^{24π²β/(11N²)}` ⇒ 指数宽余量（§1.3）。

**但它只压一侧。** 反方向的 `√t₀ ≪ 1/m_G`（原子不被涂抹掉）**不在 `𝒯` 里**（b2）⇒ 这是 `𝒯` 的真缺口，
不是 `t₀/a²→∞` 的缺口。

## §4 ★ 定量骨架：`w₁(t)` 的形状、唯一极大、以及三个候选的读数（任务 2 的"为什么"）

### 4.2 分子 / 分母的 `t`-标度（`[C]`：幂计数，未用格点数据核）

```
分母（接触 + 高谱）：M₀(t) = Σ_n |c_n(t)|² ≍ c_M t^{−4}       （dim 8；ρ(s)∝s³ ⇒ ∫^{1/t}s³e^{−2ts}ds ≍ t^{−4}）

      唯一内点极大： t* = 2/(c m_G²)  ⇒  √t* ≍ 1/m_G
```

### 4.3 三个候选的读数（这就是任务 2 的判据表）

| 候选 | `t₀/a²` | 量纲 | `w₁(t₀)` 的读数 | 判 |

```
(i)  c 是 O(1) 常数，不被任何手上定理定  ⇒ [M]（与 MU-3 §5.4 的 c 同一物种）

```
