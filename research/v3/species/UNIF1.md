## §0 判词（一句话）

**(a) 成立：障碍是方法的。**
`不可定义 ⇒ 给不出一致` 是**单向充分条件的逆否误用**（`不适用 ≠ 不一致`）`[T]`；
更有甚者，**即便可定义，"o-minimal 给一致"也不成立**（参数集非紧，见 §2.2）⇒ 可定义性**根本不是**那个障碍。

## §1 "`(L,a)` 族不可定义"的**精确含义**

### 1.1 哪个族
```
族 = { f₁²_{L,a}(β) }  或等价地  { w₁(L,a) := f₁²/M₀ }        （P8-TRUTH:22）
目标 = inf_{(L,a)} w₁ ≥ w₀ > 0     在 β = 2.5 上（LOOP-RUNBOOK §155.2）
```
参数实际是**两维**：`L`（体积/格点数）× `β`，而 `a` 由跑动耦合 `a(β)` 反演（标度窗内单调可逆）。`p8` 写 `(L,a)`、`P8-TRUTH` 用 `(L,β)`，**同一族**。

**记号碰撞（必须先钉）**：`dim ~ (L/a)⁴` 只在 `L` = **物理长度**时成立；`P8-TRUTH` 里 `L=6` 是**格点数**，此时 `dim = L⁴ = 1296`，`a` 不改变 `dim`。
两种方向都会让 `dim→∞`：`a→0`（固定物理体积的 UV 极限，`dim=(V^{1/4}/a)⁴`）与 `L→∞`（固定 `a` 的 IR 极限）。⇒ 结论不受影响，但 `(L/a)⁴` 不能照抄到 `L`=格点数的语境。

### 1.2 "不可定义"唯一可能的解释
o-minimality 的环境是**固定**的 `ℝ^N`（`N<∞`）加一个 o-minimal 结构 `𝓜`，可定义族是 `F ⊆ ℝ^N × ℝ^k` 的纤维。所以这句话**只能**解成：
```
不存在 (N, 𝓜, F) 使得 N 固定、𝓜 是 ℝ^N 上的 o-minimal 结构、
F ∈ Def(𝓜)、且 w₁(L,a) = F(L,a) 对窗口内所有 (L,a) 成立。
```
这不是"函数野"，而是**"族根本不是一个族"**：`Def(𝓜)` 里没有以无界维数为下标的对象。⇒ `[T]` 平凡。
**但它是对"环境"的陈述，不是对任何成员或任何取值下界的陈述**——见 §2。

### 1.3 三条候选理由逐条核
| # | 理由 | 判 | 说明 |
|---|---|---|---|
| i | `dim ~ (L/a)⁴ → ∞`，无固定环境 | **真，但只是 typing** `[T]` | 同一条 typing 难题**同样**落在**每一个** `|Λ|→∞` 却**已证体积一致**的统计力学界上（团簇展开）⇒ 它不可能是"一致"的障碍（§3 M5） |
| ii | `L` 离散，`ℤ` 在 o-minimal 结构里不可定义 | 真，但**不承重** `[T]` | 取**有限** `L` 窗即可（紧性只需有限），或用实 `L` 插值；去掉它不改变任何结论 |
| iii | `β(a) ~ log(1/a)` 非可定义 | **假** `[E]` | `log` 在 `ℝ_an,exp` 里**可定义**（`exp` 的逆；Wilkie 1996 的 `ℝ_an,exp` o-minimal）。诚实的残留只有"`a(β)` 含非微扰修正、**没给闭式**"——那是**缺公式**，不是不可定义定理 |

⇒ **"族不可定义"的真内容 = "没有固定维数的环境空间"**；把它读成"这些函数不可驯服"是**超出了它**。

## §2 推理对不对

### 2.1 形式：`H ⇒ U`，`¬H ⊬ ¬U`
```
H  = 「w₁ 是固定环境里、紧参数集上的可定义族的纤维」
U  = 「inf_{(L,a)} w₁ ≥ w₀ > 0」
tame 一致性的定理形状：H ⇒ U
p8 的推理：¬H ⇒ ¬U      ← 否定前件，无效 `[T]`
```
o-minimality 是 `U` 的**充分**条件，不是必要条件。⇒ **"这个方法给不出" ≠ "不一致"**。本路生死线成立：`[T]`。

### 2.2 ★ 更强：**即便 `H` 成立，也给不出一致**
可定义族的**一致界只在紧参数集上**成立；非紧参数集上可定义族恰恰是一致界失效的教科书场景（`F(x,y)=xy` 在 `(0,1)²` 上可定义、`ℝ_an`-可定义、无一致上界）。
而本问题的参数集**两个方向都非紧**：`a→0`、`L→∞`。
⇒ **`H` 失败与 `U` 失败是两件不同的事；`p8` 把两件事叠成了一条链。**可定义性失败甚至**不是那个起作用的原因**；起作用的是**非紧**（若真有障碍）。
⇒ 推论：`(L,a)`-一致地板 ⟺ **逐点正性**（`H1`）+ **两个边界面的控制**。"一致"本身**不是一个额外的对象**。

## §3 别的办法（逐字给，含假设与代价）

**M1｜连续 + 紧 + 逐点正 ⇒ 截断窗一致** `[T]`（假设：连续性 `[C]`）
取 `𝒦 = {L_1..L_K}`（有限）× `[a_min, a₀]`（`a_min>0`，紧）。`L` 离散 ⇒ 对 `L` 连续自动；`a`-连续性由 `f₁²(β)` 解析（Kato）+ `a(β)` 在窗内连续可逆给出。`w₁ > 0` 逐点 ⇒ `inf_𝒦 w₁` 在 `𝒦` 上**取到**且 `>0`。**不用任何 tame 理论。**
⇒ 任意截断窗上的一致地板**免费**；全部剩余内容被压进下面两个**一参数**边界面。

**M4｜`β`-方向：解析 + 紧 + 逐点正 ⇒ 一致** `[T]`
`[1/48, 2.5]` 紧、`w₁(β)` 连续（同一 Kato 输入）、`w₁>0` 逐点 ⇒ 固定格点下 `β`-方向地板成立。
**★ 记账更正**：这里 o-minimality **完全多余**——"零集有限"（`F1`）比"连续 + 紧"**严格更弱**。`F1` 从来不是内容；内容是 `H1`（逐点正性）。此条把 `O-MINIMAL-UNIFORMITY` 的 `#2 FAIL (partial)` 的理由降级为"非必要"。

**M2｜`L`-方向：有限体积单调性 ⇒ `inf_L = lim_{L→∞}`** `[C]`
若 `w₁(L,a) ≥ w₁(L+1,a)`（体积增大则隙减小；正/反射正转移矩阵下的标准行为），则 `L`-一致性 ⟺ **一个** `L=∞` 的陈述。
**关键**：台账的 `L`-方向 no-go 是**对数凸化**（CLAUDE §5"周期（无对数凸化）"），**严格强于单调性** ⇒ **不排除 M2**。在手工具：**规范不变 PF**（CLAUDE §5 已证）。

**M3｜`L`-方向备胎：Arzelà–Ascoli 打在归一化剖面上** `[C]`
数值本身平凡紧（有界即可）；要打的是**剖面**：`φ_{L,a}(x) = C_{L,a}(x/r₀)/C_{L,a}(0)`。若 `{φ}` 在固定紧 `x`-窗上**一致有界 + 一致等连续**（需一个一致的导数/协方差界，仓内 `SP-C-GMT` 类工具），则存在子列收敛；`w₁` 是**矩比泛函**，在弱收敛 + 一致尾部控制下连续/下半连续 ⇒ 地板传到极限。
**诚实代价**：输入 = 紧性 + 极限处正性 = **`L3` + `H1` = 目标本身**。⇒ M3 是**合法但非捷径**（正是 `new-tools-registry:228` 的"`紧性(L3)+点态正性(H1)`"）。不编成"省了一步"。

**M5｜范式：维数增长族的体积一致是**家常**，不是奇迹** `[T]`
团簇展开 / Dobrushin 唯一性 / Fekete 次可加性对 `|Λ|→∞` 一律给**体积一致**界，**从不**借助 tame 几何。仓内 `S6-DOBRUSHIN` 的死因是 **`β` 范围**（`β_Dobr≈1/48`），**不是维数**。
⇒ `dim ~ (L/a)⁴ → ∞` **阻不住一致**；它阻住的只是 o-minimal 这一个具名类。

**M6｜(b) 的反例不可得** `[NG]`
"一致失败"= 存在 `(L_n,a_n)` 使 `w₁→0`，即**渐近无隙族**。仓内 0 条；且 1.2 的论证**对取值零内容**，不可能产出反例。数值上 `β=2.2` 的 `w₁=0.48–0.86`、余量 `15–82×`（`P8-TRUTH:47`）说明任何这样的列必须极特殊。⇒ 标 `[NG]`（未查到 + 不可由在手材料推出），**不**标"为假"。

**酸测（CLAUDE §1）**：M1/M3/M4 全部**对自由场失效**（自由 `f₁²≡0` ⇒ 逐点正性前提不成立 ⇒ 给不出地板；M3 的极限正性也失败）⇒ 非真空，通过。
