## §0 判词（六行，先给答案）

1. **"双边"= 两个**非紧边界面**，不是"上下两个界"。** 逐字：`b15:19` "一条**双边一致**不等式；`(i)`（`a→0` 方向）与 `(ii)`（`L→∞` 方向）是它的**两个量词方向**"。数学内容 = 参数域在两个方向都非紧（`UNIF1:63` 逐字"本问题的参数集**两个方向都非紧**：`a→0`、`L→∞`"）⇒ 一致性 = **控制两个无穷边界面** + 内部紧集免费（`UNIF1:65` `[T]`+`[C]`）。**不是 sandwich**：目标只有 `≥ c₀`，`b15:56` 自己把强耦合值 `37.75` 判为"**单侧**满足（只有下界、无上界）" ⇒ 无上界半。`[T]`
2. **三下标控什么（题面猜想 3/3 方向对，但 2/3 要降格）**：`inf_L` → 体积/热力学一致性，**且是 `m_{0⁺⁺}(a)` 有定义的前提**（`UNIF3:43` 逐字"`inf_L m(L,a)>0`，**否则 `m_{0⁺⁺}(a)` 未定义**"）；`inf_a` → 连续极限一致性，但 `[T]` 恒等 **`a`-一致 ⟺ `β`-尾-一致**（`UNIF3:48–57` 引理 A），固定 `β` 时**退化**（`UNIF3:46`）⇒ 不是第三条独立轴；`inf_t` → 重整化口径（`U07:48–49` 裸 `M₀~a⁻⁸` ⇒ `w₁^{bare}→0`），但**这个 `t` 只属于 `w₁` 对象，不属于 `m·a/(aΛ)`**（`U07:64–67` 族 `{w₁(L,β,t)}`；§6 见下）。
3. **`(i)(ii)` 不是"只是它的量词方向"。** 量词代数本身是 `[T]`（乘积集上 `inf_{L,a}=inf_L inf_a`，`U07:73–78` 两行证），但 `(i)`、`(ii)` 各自是 **合取**：（i）= 〔`m_phys≥Δ>0` = `c₀` 的内容〕∧〔`a`-一致 = 量词〕；（ii）= 〔无限体积极限**存在**/OS2/唯一真空〕∧〔隙**不退化** = 量词〕（`TRG-CLAY-BRIDGE:37–38` 逐字）。**内容半不是量词方向**：`c₀>0` 就是结论（`b15:12,128` 自认"循环"），"极限存在"被 `b15` 单列为 `G1`（`b15:105`）。⇒ 归约 = **一条不等式 + 一个不同类的合项 `G1`**；"不是三条腿"**成立**，"两方向尽收其中"**不成立**。
4. **写对了吗：形状对，写法未完成（(b) 部分触发）。** 分母 `Λ_lat(a)` 不带 `t`、分子 `m_lat(a,L;t)` 带 `t`（`b15:106`），而 `t` 那条注的理由说的是 `w₁`（`b15:108`）——**第三下标只挂在一侧**；恒等 `m_lat/(aΛ) ≡ m_phys/Λ`（`A04:22–25` `[T]`）要求**两侧同口径**，所以 `t` 不能在 `m/Λ` 上取 `inf`，只能**钉死**。
5. **判死线命中：(a) 成立（形状可作本轮基础，逐字见 §5 的修正形）+ (b) 部分触发（`t` 下标移植、单侧挂载）+ (c) 触发（(ii) 的"存在"半与 (i) 的"`c₀>0`"半都不是量词方向）。**
6. **净收益**：`b15` 的删 `(iii)` 判决**不受影响**（`(iii)` 不是腿，`B15 §5` 三判据无一 ✓✓✓）；受影响的是它那句**归约的美化措辞**——"一条不等式的两个量词方向"应改写成 §5 的两行。

## §1 "双边"的三种候选读法，逐条判

| # | 读法 | 内容 | 判 | 证据 |
|---|---|---|---|---|
| α | **上界 + 下界**（sandwich / 双边界） | `c₀ ≤ ratio ≤ C₁` | **✗ 不是这个**。目标逐字只有 `≥ c₀ > 0`；语料把"双边/sandwich"专门留给另一类对象（`H2-DEFECT-BOUND:85` "exact two-sided ceiling"、`Z03-DM:58,73` `\|log D_fin\|≤Cu`、`PROOF-FSS:11` "two-sided magnitude"）。且 `b15:56` 明说 `37.75` **只有下界、无上界** ⇒ 若"双边"指上下界，则 b15 自己已把该读法判死 | `B15:17,19,56,106`；`T3-TP2:200`（"two-sided window"=另一对象） |
| β | **两个量词方向** `a→0`（UV 边）/ `L→∞`（IR 边） | 一个常数 `c₀` 同时扛过**两个极限**：`∀L ∀a(β)` | **✓ 是这个**（`b15:19` 逐字）。数学骨架：非紧参数域的"一致"= **两个无穷边界面的控制**，内部紧集由连续性免费 | `B15:19,113`；`UNIF1:61–65`（`[T]`：可定义族在**非紧**集上恰恰一致界失效的教科书场景）；`UNIF3:16–17`（`(iv)` 序无关"由 (ii) 的一致性免费得" `[T]`） |
| γ | **强弱两端**（crossover 两侧：`CPB-W`/`CPB-S`） | 语料另有此用法 | **✗ 同名词、不同对象**。那是 `q₀≥q₁` 的强弱交接；本句是 `(L,a)` 的一致性，两者无交叉引用 | `CPB-preprint:11,26`；`roof-transport-scalar:54–57` |

**⇒ 判（题面第 1 问）**：是 `L` 与 `a(β)` 两个**方向**（读法 β），**不是**上下两个界（读法 α）。而且"方向"这个词有精确内容，不是修辞：**两个方向 = 参数域的两个非紧端**，所以"双边一致"可改写成一个可判真假的句子：
> `∃c₀>0 ∃L₀∃a₀ ∀L≥L₀ ∀a≤a₀ : ratio ≥ c₀`　——**这是"双边"的唯一可判形**（`∀` 在两个端上各一次，共用同一常数）。

## §2 `inf_{L,a,t}` 的三个下标，各控什么（逐条，含降格）

### 2.1 `inf_L` —— 体积一致性，**且是定义前提**（双重角色，题面只说了前半）

```
UNIF3:43（U2）逐字：inf_L m(L,a)>0，否则 m_{0⁺⁺}(a) 未定义        [M]（β=2.5 处）
TRG-CLAY-BRIDGE:38（(ii)）逐字：L→∞ 一致（OS2/聚类/唯一真空）：无限体积极限存在且隙不退化
```
⇒ `inf_L` 有**两个**角色，必须分开记账 `[T]`：
- **(L-def)** 定义前提：没有 `inf_L`，`m_{0⁺⁺}(a)` 就是"每个 `L` 一个数"，连续极限无从谈起；
- **(L-unif)** 一致性：同一个 `c₀` 对所有 `L` 成立（这才是 (ii) 的"不退化"半）。
- **(L-exist)** (ii) 的"极限**存在**"半**不在** `inf_L` 里：存在性是 `G1`/OS 重构的对象层陈述（`b15:105` 单列），`G02-LINF:12–27` 已把这条拆开判过（读 (a) 一致界 = 量词 / 读 (b) 极限存在 = 另一件、缺 `L3/(★)`）。

### 2.2 `inf_a` —— 连续极限一致性，但 `[T]` **它不是独立轴**（题面"三下标独立"要降格）

```
UNIF3:48–57 引理 A [T]：∃c₀∃a₀∀a<a₀: m ≥ c₀Λ  ⟺  ∃c₀∃β₀∀β>β₀: m ≥ c₀Λ
   （纯序算术：a<a₀ ⟺ β>β(a₀)，两边同一量、同一单位）
⇒ 逐字："a-一致 不是第五个方向，它就是 β-尾-一致。"
UNIF3:46 / G04:70 / F05:120–137 [T]：固定 β 下 a-一致是平凡的（a 只是单位）
U07:83 / U07:96 [T]：域被约束成图 a=a(β) ⇒ β 钉在 2.5 时 a-方向只有一个点 ⇒ "a-一致"零内容；
                     a 独立 ⇒ β 必须浮动 ⇒ 与"在 2.5 上"互斥（空集）
```
⇒ `inf_a` 的**真身份**：`inf_a ≡ inf_{β-tail}`。它是**一个侧面**（UV 边），但**不是与 `inf_L` 并列的独立坐标**：固定 `β` 处退化，浮动 `β` 处与 `β`-尾同一个全称量化。`[T]`

### 2.3 `inf_t` —— 重整化口径；**但对 `m·a/(aΛ)` 这个对象没有 `t` 轴**

```
U07:45–49 [T]：M₀^{bare}=C(0)~a⁻⁸（两 dim-4 场重合点接触项）⇒ w₁^{bare}=f₁²/M₀^{bare}→0 as a→0
            ⇒ 必须先钉重整口径（流时 t ≳ physical²，或固定物理点分裂 ε），w₁(t) 才有有限 a→0 极限
U07:49 [T]：U4:79 因此写 inf_{L,a,t} —— 而靶句 RUNBOOK:14802 只写 (L,a)，掉了 t
U07:64–67 [D]：族的正确定型 = { w₁(L,β,t) : L≥L₀, β∈[1/48,2.5], t∈[t₋,t₊] }，没有独立的 a 轴
A04:22–25 / MON3:47 [T]：m_lat/(aΛ) ≡ m_phys/Λ（a 约掉）—— 一个不含 t 的量
```
⇒ **`t` 是 `w₁` 对象的参数，不是 `m/Λ` 对象的参数**。`b15` 把 `U4/U07` 的三下标写法搬到了 §6 的 `m/Λ` 靶上（`b15:17,106`），于是出现两处不一致：
1. 分母 `Λ_lat(a)` 无 `t`、分子 `m_lat(a,L;t)` 有 `t` ⇒ **同一比式的两侧不同口径**；而恒等 `≡ m_phys/Λ` 是"同方案同归一化"下的等式（`b15:109` 把它当**要求**列出，说明写法本身没保证它）。
2. `t` 那条注（`b15:108`）逐字用"裸 `M₀~a⁻⁸` ⇒ 不钉 `t`，**`w₁`** 在 `a→0` 无意义"来论证 —— **理由出自 `w₁`，被用在了 `m/Λ` 上**。
⇒ 判：`inf_t` 在 `m/Λ` 上是**空下标（可 vacuous 地取）**，正确写法是把口径**固定**成一个参数 `t₀`，而不是取 `inf`。`[T]`（记账）+`[J]`（移植错位）

## §3 `(i)(ii)` 与这条不等式的关系：量词代数 `[T]`，但两项各有一半"内容"

### 3.1 量词代数半边是 `[T]`（所以"一条"不是修辞）

```
U07 §3.1 引理 [T]：f:A×B→ℝ̄ ⇒ inf_{(a,b)} f = inf_a inf_b f = inf_b inf_a f（两行证）
⇒ 在乘积域上，一个 inf 同时压两个轴 = 两个方向同时一致 ⇒ (i)(ii) 的量词半**确实是**它的两个方向
UNIF3:16 (iv) [T]：lim_a lim_L vs 联合极限"序无关 —— 由 (ii) 的一致性免费得"
```
⇒ **"不是三条独立腿"成立**：`(iii)` 被删是真删（`B15 §5`：常数版假 / 比值版 ≡ (i) / 第三版不可比），归约的**不合项**确实只剩 `G1` + 一条不等式。

### 3.2 但 `(i)`、`(ii)` 各自是合取，内容半不是方向（这是 (c) 的落点）

| 项 | 逐字（`TRG-CLAY-BRIDGE:37–38`） | **内容半（不是量词）** | **量词半（= 方向）** | 结论 |
|---|---|---|---|---|
| `(i)` | "标度率 / `a→0` 一致：`m_phys := lim m_lat/a ≥ Δ>0`，**比值的正下界，不是固定常数**" | `≥ Δ>0` 这半 = `c₀>0` 本身 = `(T4)` = `H1` 量纲修正 = **结论**（`M05:97,109–111`；`b15:12,128` 自认"循环"） | `a`-一致 = `inf_a` ≡ `β`-尾（引理 A） | 内容半 ⇒ 归给 `c₀`（**它就是靶**），不是方向 |
| `(ii)` | "`L→∞` 一致（OS2/聚类/唯一真空）：无限体积极限**存在** **且** 隙**不退化**" | 极限**存在** = `G1`/OS 重构（`b15:105` 单列 `G1`；`G02-LINF:20–23` 另缺三件） | 隙**不退化** = `inf_L` | 存在半 ⇒ 归给 `G1`，不是方向 |
| `(iii)` | 算子识别（最轻 `0⁺⁺` 边 + 原子 + 隔离） | — | — | **真删**（`B15 §5`） |

**统一一句（判死线 (c)）**：
> `(i)(ii)` **不"只是"它的两个量词方向**。去掉两个内容半之后剩下的才是两个方向；而这两个内容半一个是**靶本身**（`c₀>0`）、一个是**另一类合项**（`G1`）。所以 `b15` 的归约**正确形式**是 **`G1 ∧ 一条双边不等式`**（它自己就是这么写的，`b15:17`），**不是**"一切都收进一个 `inf`"。把 `(i)(ii)` 说成"只是它的两个量词方向"，是把 `G1` 与 `c₀>0` 悄悄地计入了 `inf` —— 前者造成**漏项**，后者造成**循环观感**（虽然 `b15 §7(c)` 已自认这点，但 §0.5 的措辞把它抹平了）。
