## §1 T1 核文献：Rai et al. 定理的**精确**形式 `[L]`

**引用（逐项核过，见 §8）**
Kshiti Sneh Rai, Ilya Kull, Patrick Emonts, Jordi Tura, Norbert Schuch, Flavio Baccari,
**"A Hierarchy of Spectral Gap Certificates for Frustration-Free Spin Systems"**,
*Quantum* **10**, 2065 (2026-04-13)；DOI [10.22331/q-2026-04-13-2065](https://doi.org/10.22331/q-2026-04-13-2065)；
arXiv:[2411.03680](https://arxiv.org/abs/2411.03680)v3（v1 2024-11-05，v3 2026-04-01）。

### §1.1 它证**哪一种**谱隙
**Hamiltonian 谱隙**，`Δ = E₁ − E₀`，对象是**平移不变、`k`-体、有限局域维数 `d`、frustration-free**
的自旋链 `H = Σ_{i=1}^{N} h_i`，`h_i ⪰ 0`，基态能设为 `0`，`Δ_N^∘` = 周期边界下的最低非零本征值，
目标是 `Δ_{N→∞} > 0`。**不是** Markov 链谱隙，**不是**转移算子的 `λ₁/λ₀`。

### §1.2 证书的**形式**（这是判定的关键，逐条抄）
- **等价判据（论文 (2) 式）**：`H² − δH ⪰ 0 ⟺ Δ ≥ δ`（**仅当** `H ⪰ 0`）。
- **精确 SDP（(3) 式）**：`Δ_N^∘ = max δ s.t. H² − δH ⪰ 0`，矩阵 `d^N × d^N` —— 与精确对角化同难。
- **截断（(4)(5) 式）**：`[H²]_n = Σ_{|i−j|<n} h_i h_j`（丢掉的是不相交支集上的 PSD 乘积），
  `Q_n(δ) = [H²]_n − δH`；`Q_n ⪰ 0 ⇒ H² − δH ⪰ 0`。**这一步是整个层级的发动机。**
- **LTI 原始 SDP（(11)(12) 式）**：
  ```
  Δ_LTI(n) = max_{δ, Y_{n-1}} δ    s.t.   g_n(δ) + 1⊗Y_{n-1} − Y_{n-1}⊗1 ⪰ 0 ,
  g_n(δ)   = h_1² + Σ_{1<j<1+n-k} {h_1,h_j} − δ h_1 ,      （支撑：n 个格点）
  ```
  `Y_{n-1}` = `(n−1)`-格点上的**任意** Hermitian 算子（telescoping 自由：`Σ_i (1⊗Y − Y⊗1) = 0`）。
  **`Y` 就是那个"对偶可行点"的载体**；`q_n ⪰ 0` 是原始可行点，`ρ_n` 是对偶可行点。
- **对偶（(16) 式）**：`Δ_LTI(n) = min_{ρ_n ⪰ 0} Tr[ρ_n(h_1² + Σ_j {h_1,h_j})]`，
  约束 `Tr_1(ρ_n) = Tr_n(ρ_n)`（**两端边缘相等**）。
  ⇒ **证书形式 = 一个局域 pseudo-密度矩阵 + 一条边缘一致性约束**，
  **不是**矩矩阵（和 Lasserre/moment-SOS 是**不同**对象，见 §2.3）。
- **层级单增（(13) 式）**：`Δ_LTI(n) ≤ Δ_LTI(n+1) ≤ … ≤ Δ_{N→∞}`，且 (6) 式后明说：
  "if (6) holds for a given support `n` and a global system size `N`, then the same decomposition
  will hold for any `N' > N`" ⇒ **`Δ_LTI(n)` 与 `N` 无关**。这是 §5 的命题 C。

### §1.3 规模/维数限制
单个 PSD 约束的尺寸 `d^n × d^n`；`Y` 的自由度 `d^{2(n−1)}`；`1⊗Y − Y⊗1` 稠密 `d^n × d^n`。
论文明说 1D 专门化、"straightforwardly generalized to higher-dimensional lattices"，
但 `n ≥ 2k+1` 且（`ν` 维格点）一个 `n`-块的格点数 `~n^ν` ⇒ 尺寸 `d^{n^ν}`。
**实证只在 1D 自旋链**（AKLT 及若干 1D FF 模型），对 AKLT 给出"迄今最准的下界"并"把能检出隙的参数范围
提高数个量级"。**无 4D、无规范场、无连续极限的任何实例。**

### §2.3 但"证书"不是免费的：三种 SDP 别混

|---|---|---|---|

P4 的特殊之处只在于它的值**可精确算出**。

### §5.3 真正的死亡在 `a`-轴（T0(c) 的**修正版**）`[T]+[V]`
- **成本**：层级第 `n` 级的 PSD 约束尺寸 `d^n`（`d` = 局域维数）。4D 上 `n`-块的格点数 `~n⁴`
  ⇒ `d^{n⁴}`。`SU(2)` 电截断 `ℓ_max`：`d = Σ_{ℓ≤ℓ_max}(2ℓ+1)²`（`ℓ_max=1/2 → 4`，`1 → 13`，`2 → 38`）；
  最粗的 `d=4`、`n=2` 已是 `4^16 = 4.3e9`。**与 `L` 无关，与 `a` 强相关。**
- **方向（可证，`[T]`）**：把局域空间放大（`ℓ_max ↑`）只会让 `Q_n ⪰ 0` **更难**满足；
  若截断族是**保旗**的（`H_{ℓ} ⊂ H_{ℓ+1}` 且每个局域项保持该旗），则压缩 PSD 仍是 PSD
  ⇒ `δ_max(ℓ_max)` **非增** ⇒ `δ_max(∞) = inf_ℓ δ_max(ℓ)`，**任何有限截断的证书都只是连续极限的上界**，
  而 L4 要的是**下界**。这与语料"finite box = upper bound"**同一个形状**，
  但这次是**在证书形式内部**得到的，不是反对证书。
- **注（诚实边界）**：真实电截断**不**保旗（`tr P` 升降 `ℓ`），所以上面的单调性不能直接引用；
  能确定的只有更弱的一句：**跨截断无收敛控制** ⇒ `a`-一致**不可得**。这一句足够判死 L4。

### §5.4 结论（T3）
> `c(L)` = **常数**（定理级：命题 C；P4 上精确到 `1e−16`）。
> **但 `(L,a)` 一致 = `L`-一致 ∧ `a`-一致**；这条路只买到前一半，后一半被 `d^{n⁴}` 与截断方向**判死**。

### (T-B) 正转移核：同一步**非法** `[T]+[V]`

## §7 T4 判定

### §7.1 一句话
> **"已有技术 + 更强计算"**——不是新物种；而且它连"更强计算"都不是，
> 因为卡住它的是**假设**（FF + `E₀=0` + 张量因子截断单调性），不是算力。

### §7.2 判定拆开（不许含混）
| 轴 | 判定 | 依据 |
|---|---|---|
| 它给的是**证书**而不是上界？ | **是**（判词方向正确，lead 的区分成立） | §2.2、§3 亲手做出 |
| `L`-一致 | **白送**（定理） | 命题 C；P4 实测 `≤8.4e−16` |
| `a`-一致 | **不可得** | §5.3：成本 `d^{n⁴}`；保旗截断的单调性方向是**上界**；非保旗截断无收敛控制 |
| 假设（FF / `E₀=0`） | **YM 不满足**，且补上的代价 = 真空能量密度 = H1 | §0.2、§4-C1、§6 |
| 截断合法性 | FF 链 **合法**；测度/核 **非法** | §6 (T-A)/(T-B) |
| 结论 | **不出新物种；把 L4 的缺口**提高分辨率**地重述一遍** | —— |

### §7.3 五条件记分（`CLAUDE.md` §1 + B3 五条件）
1. **非微扰** —— **PASS**。精确 SDP，任何 `β`，无圈展开、无 `1/N`。
2. **方向（要下界）** —— **PASS**（本语料罕见：`RB-2` 说变分只给上界，这条给下界）。
3. **非循环** —— **FAIL**。`E₀` ⟺ 真空能量密度 ⟺ 基态局域结构 ⟺ 聚簇性 ⟺ H1。**精确的循环。**
4. **反自由场（过酸测）** —— **FAIL（空真）**。自由有质量场同样 `E₀ > 0`（零点能），
   判据同样返回 `E₀` 而与 `m` 无关；自由无质量场同理。**对两者一样失效 ⇒ 无分辨力 ⇒ 空。**
5. **`(L,a)` 一致** —— **半 PASS / 半 FAIL**。`L`：白送；`a`：`d^{n⁴}` + 截断方向 ⇒ 无。

### §7.4 **精确缺失的那一步**（一句话，无退路）
> 需要一个**把 4D 纯 YM 的转移算子写成"PSD 局域项之和 + 已知精确为零的基态能 + 保旗有限局域维数"
> 的表示**；三种写法里任选其一都要求精确知道真空能量密度（`E₀ = 0` 的归一化），
> 而这与 H1 是同一个对象。**这一句就是缺口，写成可判定的形式："`∃` 一个 `(L,a)`-一致、
> `E₀=0`、截断保旗的 YM 局域 PSD 表示" ⟺ H1。**

### §7.5 什么会推翻本判定（可证伪）
1. 给出格点规范场的**任何**`(L,a)`-一致 PSD 局域表示，其 `E₀` 用**闭式**钉死（不需要知道隙）；
2. 证明电截断的 `δ_max(ℓ_max)` 有 `a`-一致**下界**（等价于截断误差可控）——那 §5.3 的 `a`-轴判死失效；
3. 在 `[1/48, 2.5]` 任一子区间上构造出可解的 LTI SDP 且 `Δ_LTI(n) > 0`——那 §0.2 的 FF 判死被绕开。
