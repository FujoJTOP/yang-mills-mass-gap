### 2.3 若某源能给模数，那条不等式长什么样：**Lemma T（本轮新增的 [T]）**

任务说"若某个能给出一致的 `s₂` 或 `χ` 模数，立刻写出那条不等式"。没有源能给；但**缺的那个模数的

> **Lemma 2.1（带速率的有限-`T` decay ⇒ 地板）`[T]`.** `ν ≥ 0`、`C(t)=∫₀^∞ e^{−st}dν(s)`、`M₀=C(0)`。
> 设存在 `c>0`、`θ ≥ 0`、`T>0` 使
> ```
>      C(t) ≤ M₀ (1+θ) e^{−c t}       对所有  t ∈ [0,T] .
> ```
> 则对每个 `ε ∈ [0,c)`：
> ```
>      ν([0,ε))  ≤  M₀ (1+θ) exp( −(c−ε) T ) .                                        (2.1)
> ```
> *证明.* `C(t) ≥ ν([0,ε))·e^{−εt}`（因为 `s<ε` 的每一块都衰减得比 `e^{−εt}` 慢），取 `t=T`，合并。∎

**三条直接推论（这就是 N1 的判决）：**

1. **`T<∞` 只能给"地板 ≥ ε 减去一坨质量"**：要把 `ν([0,ε))` 压到 `η` 以下，需要
   `T ≥ log(M₀(1+θ)/η)/(c−ε)`。`[V]`：`c=1`，`η=1e−10, ε=0.5` ⇒ `T ≥ 46.05`；`ε=0` ⇒ `T ≥ 23.03`。
2. **`ν([0,ε))=0`（真正的地板）需要 `T=∞`。** ⇒ **缺的那个模数就是 `θ(T)`**：衰减界在有限 `T` 处的**缺陷**。
   而 `θ ≡ 0`（对**所有** `T`）**就是** `C(t) ≤ M₀e^{−ct} ∀t`，**就是** `m₁² ≥ c`，**就是** gap。
   ⇒ **带速率的 Tauberian 不救场，因为唯一有用的速率是"无缺陷"，而那件事本身是 gap。**
3. **酸测方向对**：`[V]` 两点族 `ν_h=(1−h)δ_{s=1}+hδ_{s=0}`，`h=1e−2` 时 `r(t)=−(1/t)log(C/M₀)` 从

   而 `m₁²=0`。**这正是"有限 `T` 只给上界"的账面**（与 `TOOL-COMPLETELY-MONOTONE §2` 一致，本轮给了常数）。

**⇒ N1 的精确缺失步（一句话）：** `θ_T` —— **`0⁺⁺` 关联子在 `t∈[0,T]` 上相对 `e^{−ct}` 的一致缺陷**，

### 3.3 定理 N2-2（`[T]`+`[V]`）：RP 让 `χ` **超可加** ⇒ 任务要的次可加 `χ(2L) ≤ 2χ(L)` 被**公理禁止**

### 3.4 若只能得到次可加：**Fekete 核算是恒等式，不是一个推导**

任务要求"次可加 + 上界 ⇒ 有界"的定量推导，并指出差什么。`[T]`：

> **引理 3.3（Fekete 核算）`[T]`.** `a(L) ≥ 0`，`δ(L) := 2a(L) − a(2L)`。则**精确地**
> ```
>      a(L_n)/L_n = a(L_0)/L_0 − Σ_{k<n} δ(L_k)/(2L_k) ,      L_k = 2^k L_0 .              (3.2)
> ```
> 于是：
> - **(i) `δ ≥ 0`（次可加）**：`a(L)/L` 沿二进列不增 ⇒ Fekete 给 `a(L)/L → inf ≥ 0` ⇒ `a(L) ≤ C·L`：
>   **线性**，不是有界。
> - **(ii) `a` 有界 ⟺ `a(L)/L → 0` ⟺ `Σ_k [a(L_k)/L_k − a(L_{k+1})/L_{k+1}] = a(L_0)/L_0`（精确等号）。**
>   **即：这套"亏量"核算是一个恒等式。任何强到足以推出有界的亏量输入，都与结论等价。
>   所以"次可加 + 上界 ⇒ 有界"不存在"两个输入弱于输出"的版本：那个"上界"就是结论。**
> - **(iii) `δ = c`（`Θ(1)`，即"负的常数项"）**：`Σ_k c/(2L_k) = c/L_0 < ∞`，斜率只掉 `c/L_0`，
>   `a(L_n) ~ (a_0/L_0 − c/L_0)L_n`：**仍然线性/无界**。`[V]`：`a_0=8`、`c=1` 时 `a(L_n)/L_n : 8.000, 7.500, 7.250, 7.125, 7.0625, 7.0312, 7.0156 → 7`。
> - **(iv) `δ = cL`（线性，即"负的一次项"）**：`Σ_k c/2 = nc/2` 无界 ⇒ `a(L_n)/L_n < 0` 当
>   `n > 2a_0/(cL_0)`：**假设自毁**（`a ≥ 0` 不可能）。`[V]`：`a(L_n): 8, 15, 28, 52, 96, 176, 320`（在 `δ=cL` 下被压到低于等比）。

**⇒ 精确回答任务那句"差什么"：**
- 不只是"差一个负的一次项"。**常数项太弱（(iii)）、一次项自毁（(iv)）**——中间没有可用强度。
- 真正的答案是 **(ii)：所谓"亏量推导"是恒等式；所需的输入与结论同强度**。
- 所以：**"次可加 + 上界 ⇒ 有界"这条路在信息论上不存在。** 唯一可行的体积陈述必须直接是那个上界本身，
  而它有个名字：

> **定理 3.4（唯一正确的体积陈述）`[T]`.** 倍增 `V+V'` 下，`ā` 有界 ⟺
> ```
>      Cross(V,V')/(|V|)  →  0   ⟺   Cross(V,V') ≤ C·|∂V| = O(L^{d−1}) .                (3.3)
> ```
> 而 `Cross ≤ O(L^{d−1})` **就是**"跨平面指数聚类"——由正性（`C ≥ 0`）它与 `m₁>0` **等价**。
> **⇒ N2 的缺的那一步 = 跨平面关联的（面积律）上界 = gap 本身；体积坐标不是捷径，是 gap 的另一个名字。**

## §9 最锋利的一句

**战役说"唯一活口是 `beyond-ν`，而 `beyond-ν ≡ H1`"。本轮把这句话拆成两半：
`H1` 是 `beyond-ν` 证书的**必要**条件（真、平凡）；`H1` 的**充分性**才是那个活口。
把两者写成等号，等于把"缺口"写成了"已关闭"——`PROFILE-FACET-DATAMODE` 因此在一个错的方向上宣布了 CLOSED：
它在**谱类别**里关得很干净（这一点本轮完全同意，`C0` 的四模 + 无穷阶候选项确实全是盲或循环），
但那一整套见证（`d_N~e^{−0.46N}`、`ν_h` 射线、4-矩精确匹配）**全部依赖"数据不变而地板降下去"这个纤维**，
而 `beyond-ν` 的成员**根本没有那个纤维**（观察 1.2）。于是：
**四条候选逐一死在四个互不相同的地方——速率是点值不控变差（N1）、体积的方向被 RP 与可解模型双重钉死（N2）、
块变换没有尺度层级可跑（N3）、`L0` 在错的纤维上、`L2` 只给平凡那半（N4）——
而它们指向的是同一个缺失命题：`H1` 的充分性。四个坐标，一个缺口，零捷径。No QED. Clay 0%.**
