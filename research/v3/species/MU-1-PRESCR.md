## §2 处方 1：格点正规化 —— `μ² = 1/a²`

间距 `a` 的超立方格点，`C` 由格边组成（`N_ℓ` 个格点，`L_C = N_ℓ a`），`t_ν(s) ∈ {±e_μ}`。


**给显式：`1/a³`，不是 `1/a²`，也不乘面几何因子。** 理由：`δ⁴ = δ¹_{∥}·δ³_⊥`，`∥` 那一个被 `∮dy_ν` 吃掉，剩**横向 3 维**（4D 中曲线的法空间是 **3** 维，不是 2 维——"`1/a²`" 的直觉错在把横空间当成 2 维）。重合点上**没有面几何因子**：格边切向是单位向量 `|t_ν|=1`，无 `cos` 投影；`O(a)` 几何修正是零测度。若要用"每单位长度"语言，`2πR/a` 个重合点属于**圈测度**，不属于 `δ³_⊥(0)` 本身。

## §7 关键判定

**(1) 哪个处方的 `μ²` 是 `rv-2` 的 `σa²=2g²N` 在格点上自然给出的那个？**
> **处方 1（格点，Kronecker 重合 = 每格点一处）。** 且仅在 `a=1` 的**格点单位**下。它等价于在 §3/§4/§5 里把接触长度取成 `ℓ = a`（即 `t = a²`，给 `μ² = (4π)^{−3/2}/a²`——差一个 `4π`-型常数，见 (3)）。`rv-2` 的 `σa² = 2g²N` 是"接触项 = 每格点 1"的**归一化恒等式**，`[M]`。

**(2) `ε = a` 还是 `ε = 1/Λ`？**
> **`1/Λ²`。** 判据不是口味，是跑动方向：`ε=a` ⇒ `σ = 2g²N/a²`，固定 `g²` 时 `σ → ∞`；若再塞 AF 的 `g²(a) ~ 1/(b₀ln(1/aΛ))`，则 `σ ~ 2N/(b₀a²ln(1/aΛ))` **仍发散**——`σ ∝ 1/a²` 与 `Λ ∝ (1/a)e^{−1/(2b₀g²)}`（指数小）**方向相反**，物理错。唯一物理短距标度是 `Λ`，故 `μ² = 1/ε²` 的 `ε` **必须**是 `1/Λ`。于是
```
σ = 2g²N·Λ²·κ ,  κ ∈ {1/(4π), (4π)^{−3/2}, …}  （O(1)，处方/记账）  ⇒  σ/Λ² = 纯数  [C]/[M]
```
这正是 `a7` 的 `p=1` 形状（唯一非空洞）。

**(3) 处方的自由度落在哪里？** 只在 `κ`（`O(1)`），且可吸收进 `g²` 的归一化（耦合法定重定义）。三处独立值 `1`（格点）、`1/(4π)`、`(4π)^{−3/2}` 的**幂次与符号全同** ⇒ 物理内容（`σ > 0`、`σ ∝ Λ²`）与处方无关；数值系数 `[M]`。

**(4) (a)/(b)/(c) 终判**
- `(a)` **降级**：格点给有限正 `μ²a² = 1`，但那只是**格点单位归一**，不是连续物理（`σ∝1/a²` 与 `Λ` 指数小冲突）⇒ 不能凭它宣布"弦张力被算出来了"。
- `(b)` **成立**：`μ²` 需要**重整化条件**。条件不是任意的——幂次（二次）与符号（`+`）被固定，`O(1)` 自由；量纲 + 唯一物理尺度把它钉成 `μ² ∝ Λ²`。
- `(c)` **不成立**：处方不改 `σ` 的符号（全为正定核 / `0`），只改 `O(1)`。⇒ "处方就是物理内容"这句话在**符号**层面是假的；在**系数**层面是真的但平凡（耦合重定义）。

**缺口（精确的一步，不许含糊）**：`(★)` 给 `σ = 2g²Nμ²` 的**形状**，`μ²` 的**值**是重整化条件；本文只把该条件**定位**到 `Λ²` 上（幂次 + 符号 + 唯一尺度），**没有**算出 `κ·2g²N` 这个纯数。这与 `RV-2 §6` 的 `[NG]`（"一致，不给标度"）同向，且比它更紧一格：**标度的幂次是 1（`σ ∝ Λ²`），不是 0 也不是 2。** `[C]`
