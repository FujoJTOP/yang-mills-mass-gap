## §1 逐字：`GH1c-LIT:194` 的变元是谁

**逐字（全句）**：「`λ₁(A) = inf_{‖ψ‖=1}⟨ψ,Aψ⟩`，是连续（线性）函数族的**下确界** ⇒ `λ₁` 是 `A` 的**凹**泛函 ⇒ **usc**。`[T]`（初等）⇒ **min–max 本身永不可能给出「`λ₁ ≥ c` 一致」**；地板必须以**强制性的二次型下界** `⟨ψ,Hψ⟩ ≥ c‖ψ‖²` 形式**输入**，而那正是 H1。」

| 子句 | 变元 | 它允许说 | 它不允许说 |
|---|---|---|---|
| `λ₁` 是 `A` 的凹泛函 ⇒ usc | **算子** `A`（族，非单个 `H_a`） | `A_n → A` ⇒ `limsup λ₁(A_n) ≤ λ₁(A)`：极限侧地板会掉（除范数收敛） | 「固定 `A` 的 min–max 不给下界」 |
| 「`λ₁ ≥ c` 一致」不可能 | 族 `{H_a}` | 单点结果不自动 `a`-一致 | 「max 侧也给不出下界」 |
| 地板必须作为二次型界**输入** | 形式域 `Q(H)` | min–max 是**搬运** | ——（正是本轮结论） |

**三处核对。**
1. `GH1c:199` 同文自述：「min–max 只给 usc ⇒ 地板只能作为输入进来」——同一文件已把 min–max 定性为"保、不造"。
2. `GM1-KATO:83` 已对同文（`GH1c:37`／`MACHINE-SIEVE:105`／`LOOP-RUNBOOK:21644`）作更正：「usc 恰好是**保地板的最强形式**……问题不是"方向反"，是"只能保、不能造"。」⇒ 拿 usc 当"方向反"的证据，仓内已判为误读。
3. **命名碰撞**：`GN1-NODIP:142` 的 usc 是 `ν ↦ inf supp ν`（**测度**变元）；`GH1c:194` 的是**算子**变元。HV1:31 只写「只给 usc」，未标变元。

**判**：`GH1c:194` 对固定 `(L,a,β)` 的 `Δ_a` 无话可说；它管的是"沿 `a→0` 地板是否幸存"。`[T]` **下一手**：按 0.1 改口径；该句只留在"保向"栏。

## §2 min–max 的两侧、所需输入、以及它为什么是恒等式

**(a) 两个正确形**（`[T]`；Reed–Simon IV §XIII.1；`B02-TOOLS:53` 逐字）：
```
λ_k = min_{dim V=k}  max_{0≠v∈V} R(v)        （min 侧；任何 k 维试验空间给上界）
    = max_{codim M=k−1} min_{0≠v∈M} R(v)     （max 侧；任何余维 (k−1) 空间给下界）
```
**(b) 靶的形错在哪**：`sup_{dim V=k} inf_{v∈V} R` 与 `max_{codim M=k−1} inf` 不是同一个量。
- 索引：`H = diag(0,Δ)`、`k=2`：前者 `= sup_{2 维}(0) = 0 = λ_1`，后者 `= Δ = λ_2`。⇒ 靶写的形在 `k=2` 上只给 `Δ_a ≥ 0`。
- 由此推出的不等式有反例：`H = diag(0,1,2,3,…)`、`k=2`、`V_2 = span{e₁₀₀,e₁₀₁}` ⇒ `inf_{V_2} R = 100 > 1 = λ_2`。⇒ `λ_k ≥ inf_{V_k} R` 一般不成立；正确的是 `λ_k ≥ inf_{M} R`（`codim M = k−1`）。`[T]` **下一手**：全部改写为 `max_{codim}` 形。

**(c) 交错（Cauchy，只用一格）`[T]`**：`M ⊂ Q(H)`、`codim M = d`，`μ_j(M)` = 压缩 `H|_M` 的第 `j` 个本征值 ⇒ `λ_j ≤ μ_j(M) ≤ λ_{j+d}`。取 `d = k−1`：`∀M: μ_1(M) ≤ λ_k`。
`k=2`、`M = Ω^⊥` 时 `μ_1 = λ_2`（取等）；`M ≠ Ω^⊥` 且 `e₂ ∉ M` 时取 `u ∈ M ∩ span{Ω,e₂}`（`u = αΩ+βe₂`，`β ≠ 0`），`R(u) = λ_2|β|²/(|α|²+|β|²) < λ_2`，**严格**。

**(d) 命题 MM-EQ（`[T]`，三行）**：设 `H_a ≥ 0`、`λ_1 = 0`。则
```
∃ M (codim k−1):  ∀v∈M,  ⟨v,H_a v⟩ ≥ c‖v‖²     ⟺     λ_k(H_a) ≥ c .
```
*证.*（⇐）取 `M = (span{e_1..e_{k−1}})^⊥`，则 `H|_M ⪰ λ_k ≥ c`。（⇒）由 (c) `λ_k ≥ μ_1(M) ≥ c`。∎
⇒ **min–max 的下界侧与靶同强**：把「超平面上的形式界」译成「谱底界」，双向、无损、因而无净产出。**下一手**：§3（`RANK-1` / `DEFLATE`），不再在变分原理里找新形。

**(e) 要什么输入才能给 `Δ_a ≥ c`**：
```
HP(a,c):  ∃ 构造 M_a（codim 1，a-一致）  ∃c>0  ∀a  ∀v∈M_a:  ⟨v,H_a v⟩ ≥ c‖v‖² .
```
由 (d)（`k=2`）：`HP(a,c) ⟺ Δ_a ≥ c`。`M = Ω^⊥` 是 `HP` 的一格，恰是 `H1`；换 `M` 不产生弱化——(c) 把 `μ_1(M)` 封在 `λ_2` 以下。第三个坐标：`Δ_a = 2Λ(μ_vac,∇)`（全空间 Poincaré 常数；`a=1` 约定的同一式见 `B01-RP:45`，换算见 `GM1-KATO:65`）——`HP` 只是它的重写。

**(f) 等价换栈（`[T]`，不改强度）**：`Δ_a ≥ c ⟺ N(0; H_a − c) ≤ 1`（`N` = 负谱计数；`λ_1 = 0 < c`）。变分语言换成**秩计数**语言（BS 判据见 `GH1c:187`）。**下一手**：把它写成每格点计数（§3 下一手 1）。

**(g) 酸测**：两侧都是恒等式 ⇒ 对自由场、2D YM、M6、单 plaquette **同输出**（max 侧在 `M=Ω^⊥` 处逐字等于 `λ_2`，`m=0` 的模型也给 `λ_2>0`）⇒ 零判别力，不能当"过酸测的新工具"立项（同型：`GH1-SPECTRAL:285` 判 `R_t>1` 类恒真）。**下一手**：在工具册里给 min–max 记"零判别"，不记"过"。

## §3 `HP` 在 `ξ/a≈1`、无小参数时是否存在

| 候选来源 | 给 `HP` 的方式 | `β=2.5` 上的状态 | 判 |
|---|---|---|---|
| 形式正性 `H−c = A*A`（限到 `M_a`） | 算符恒等式 | 无；`S_W` 不定、`E₀≠0` ⇒ 证书返回"对 `E₀` 的无知"（`B02:152`） | `[NG]` |
| 序比较 `H ≥ H_ref` | 正定参考 | 无：`λ_min Hess = −g\|B\| < 0`，规范商后仍有负模（`GAP3:46`） | `[NG]` |
| Temple/Weinstein 隔离窗 | `ρ ≤ E₂` 绝对地板 | `ρ` 的语义 ⟺ 隙；喂真值精确返回 `m₁ ≥ m₁`（`B02:154`） | `[NG]` |
| Cheeger `λ ≥ h²/4` | `h ≥ h₀` 均匀 | `h ≍ 1/√χ` ⇒ 代回得 `λ ≥ λ/4`；均匀 `h>0` ⟺ `H1`（`B02:155`） | `[NG]` |
| PF ＋ 逐 `a` 严格 | `λ_2 < 1` 逐 `a` | 有，但模数依 `(L,a)`；`log₂(ξ/a)∈[−0.9,0.4]` ⇒ 0–1 步块自旋，无 `a`-一致模数（`A4:40`） | `[NG]` |
| 真空角（`M` = 单约束超平面） | `sup_{v∈M}\|⟨Ω,v⟩\| ≤ cosθ₀` | 由 (c)：`μ_1(M) ≤ λ_2(1−\|⟨Ω,u_M⟩\|²)`，右端 ∝ `λ_2` ⇒ 角度数据给不出与 `λ_2` 无关的正地板 | `[NG]` |

**判**：`HP(a,c)` 在目标窗没有独立来源——逐字就是 `Δ_a ≥ c`（(e)）。可写的只有逐 `a` 的严格性（`B01-RP:29` R4），它没有 `a`-模数，且在自由 `U(1)⁴` 上同样成立（`Δ_a(L)>0` 而 `m=0`，`GH1-SPECTRAL:285`）⇒ 不判别。`[NG]`（射程：min–max 下界侧 + `B02` 四类 + `HP`）
