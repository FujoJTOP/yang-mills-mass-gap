## §2 主测（B 段，`[E]`）

### §2.0 估计量（写死）
- `C_ij(t) = (1/N)Σ_n (1/L)Σ_{t₀} o_i(t₀+t) o_j(t₀) − ō_i ō_j`，反射对称化 `½[C_ij(t)+C_ji((−t) mod L)]`
  （同期望、噪声减半；`L=4` 只有 4 个时移，这条要紧）。
- GEVP `C(t)v = λ_n C(t₀)v`（`C(t₀)` 白化，对称本征分解，丢弃非正本征值并报 `cond`）。
- `m_n = −ln λ_n/(t−t₀)`（判据原写法），`ρ² = (m₂/m₁)²`，`Q = (ρ²−1)/3`；
  另报 **cosh 修正** `m^cosh = arccosh[(λ(t+1)+λ(t−1))/(2λ(t))]`。
- 误差：**按 config 非参数 bootstrap，B=400**；报 16/84 分位、`frac(ρ²>4)`、`frac(ρ²>2.25)`。
- 参数（实测记录）：`β=2.5, SU(2), 周期, 冷启动→热化 therm=200, gap=5, 12 链, α=0.5, APE 2/4 步`。

### §2.1 `[T]` 机器校准：无噪声精确 2 态模型（`w7/gevp_4d_toy.py`）

`C_ij(t)=Σ_{n=1,2}A_niA_nj[e^{−m_nt}+e^{−m_n(L−t)}]`，真值 `m₁=1, m₂=1.6, ρ²=2.56`，**零统计噪声**。

1. **机器精确**：`cosh` 修正在 `L=4,6,8,12,16` 与每一 `(t₀,t)` 上给 `ρ²^cosh = 2.5600`（4 位全对）。
2. **平-log 读数被周期像系统污染，幅度足以伪造 `ρ²>4`**：

| `L` | 平-log `ρ²`（`(t₀,t)` 扫描） | cosh |

| 4 | `(1,2)` → **4.764**（+86%） | 2.5600 |

**真值 2.56 的纯 2 态模型在 `L=4` 读出 `4.76 > 4`** ⇒ 单点 `>4` 可被**体积效应**伪造；
这是 KT-5（`3.00/3.62/3.88/4.13/3.45 vs 3.994`）的**零噪声版、且可事先算**。

## §3 对照：自由无质量场 / `β=0` Haar

### §3.1 `[T]` 自由场的 `0⁺⁺` 塔精确可算 ⇒ **`ρ²_free = 2 < 4`**（判据地板盲）
环面上二次算子（`F²` = plaquette）只耦合两胶子态，`e = 2ω(p)`，`ω(p)=2[Σ_μ sin²(p_μ/2)]^{1/2}`，
`p_μ=2πn_μ/L`：
```
  n=(1,0,0) 型 : e₁ = 4 sin(π/L)
  n=(1,1,0) 型 : e₂ = 4√2 sin(π/L)     ⇒  ρ²_free = 2      （精确，∀ L ≥ 4）
  n=(2,0,0) 型 : e₃ = 4 sin(2π/L)      ⇒  ρ²_free = 4cos²(π/L) → 4
```
1. **自由无质量场（无隙）给 `ρ² = 2 < 4`，且它在 `(t,t₀,L)` 上是完美平台** ⇒
   "平台 + `ρ²<4`"**不能**推出有隙、也不能推出有动力学。
   **判据对"自由 vs 相互作用"不分辨 —— 必须明写：不分辨。**
2. `4` 不特殊：塔的第三层给 `4cos²(π/L) → 4`，连续极限被**自由场饱和**。
3. ⇒ 只有 `ρ² > 4` 有信息量，且必须带 §2.1 的 cosh 修正稳定性。

### §3.2 `[E]` 同一代码在自由场上跑（`gevp_4d_fast.py … free`）
| 体积 | `N` | `C_ii(1)/C_ii(0)`（o0/o2/o4） | GEVP |
|---|---|---|---|
| `L=4` | 2000 | `0.0006 / 0.324 / 0.618` | 秩不足（`C(1)` 本征值 `−0.247/0.0057/0.577`，秩 1） |
| `L=6` | 1200 | 见 JSON | 全部秩不足 |

**⇒ 数值上自由场上 GEVP 直接退化**（`C(t₀)` 秩 1：三个算子对同一两胶子模完全相关）。
判词由 §3.1 的精确塔给出（`ρ²=2`），**不依赖**这次数值。

### §3.3 `[E]` `β=0`（Haar）对照
`L=4, N=400`：`C_ii(1)/C_ii(0) = −0.033 / 0.022 / 0.043`（**≈0**，理论要求：`t≠0` 与 `t=0` 不共享 link）、

## §4 判据 `Q` 与 `ρ²` vs `4`（`C=2`）/ `2.25`（`C=1.5`）

**`Q` 的数值版（写死）**：KT-8 的积分形式需要一条**一维束缚坐标 `x`**；4D 格点上没有这条坐标，
所以唯一忠实的离散版就是 KT-8 的**恒等式**：
```
   Q_4D := (ρ² − 1)/3 ,     Q_4D ≤ 1 ⟺ ρ² ≤ 4      （DD 类应 <1；ND 类应 >1）
```
（与 KT-RHO2 双井例 `Q=(ρ²−1)/3=15.6442` 同口径。）**它是 `ρ²` 的单调重标，不带独立信息**；
判据的全部内容在 `ρ²` 的 `(t,t₀,L,算子数)` 稳定性里（§2.4）。

**实测 `Q_4D`（`[E]`）**：`L=4`：`13.6 ± 15.3`（`ρ²=42±46`，唯一非退化点，`λ₂` 跨引擎变号）；
`L=6`：`2.78 ± 2.15` / `2.19 ± 1.35` / `2.34 ± 152`（`ρ² = 9.3/7.6/8.0`）。
**与阈值的关系**：`ρ² = 41.9±46.0` 与 `9.35±6.45` **名义上 `> 4`**，但
`frac(ρ²>4) = 0.55`（L=6, (1,2)）/ `0.72`（L=4），且 `ρ²` 的 16–84 分位区间宽到覆盖 `2.25` 与 `4` 两侧；
`cosh` 修正后分别降到 `11.2` 与 `8.18`（L=6 `(1,3)` 甚至降到 `2.88 < 4`）。
⇒ **不能说 `C=2` 死**（KT-5 的"单点不作数"在这里连点都不成立）；**也不能说活**。
