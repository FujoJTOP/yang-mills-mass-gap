## §1 补丁形

### 1.1 一行式（`(U2′)`）

```
(U2′)  存在**一个**与 a 无关的重正化映射 R 与一个常数 z∈(0,∞)，使 ∀n≤n₀：
          S^{(n)}_{L,a} = z^n · R[ bare ]^{(n)}_{L,a} + o(a⁰)            (∀a≤a₀(L))
       三条同时成立，缺一条即退回：
          (i)   R 是**一个**映射，不是映射族 {R_a}；              （乘性、加性、混合一网打尽）
          (ii)  0 < liminf_{a↓0} Z_n(a) ≤ limsup_{a↓0} Z_n(a) < ∞，Z_n := S^{(n)}/S^{(n)ref}；
          (iii) Z_n = z^n（由**单一**归一化诱导），不是逐阶任意常数列。
       钉死的是有限常数 z；g_R(a) 照旧沿 RT 跑 —— 它不是有限重正化。
```

**判据的等价操作形**（直接接 `(U1)`）：`sup_{a≤a₀}|Z_n(a)|<∞` ⇒ `|S^{(n)}|≤(sup_a Z_n)|S^{(n)ref}|`，`(U1)` 从参考 scheme 搬到本 scheme。**`(ii)` 的 `liminf>0` 不为 `L3` 服务，只为排除"空洞 scheme"**（见 R3b）。

### 1.2 三子句各自管什么（不可合并）

| 子句 | 排除 | 不排除 |
|---|---|---|
| **(i) 单一映射** | R5 加性/混合型（`S^{(n)}→S^{(n)}+c_n(a)`，纯乘性措辞看不见它） | 方案 C 的 `O_R=Z_O(O_bare−c)`：减除 `c` 是**固定映射的一部分**，不是第二族映射 |
| **(ii) 渐近夹逼** | R1 `C5`、R2 `a^{-p}`、R3 `e^{c/a}`、R4 RT-伪装、R3b `e^{-c/a}` | RT 的 `g_R(a)` 跑动（幅度 `O(1/log(1/a))`，有界，`lim→` 有限） |
| **(iii) `z_n=z^n`** | R6 逐阶常数列（**`a`-无关**，`(ii)` 对它零作用） | 任何单一场/算符归一化（含 `Z_O^n`）；破 `(U3)` 只可能来自非单一归一的逐阶常数 |

### 1.3 为什么判据必须是**渐近**的，语法判据必败

`Z(a)=(log 1/a)^p`（要排除）与 `g_R(a)^{-1}=2b₀log(1/aΛ)+…`（要保留）**都含 `log(1/a)`**，都是 `a` 的函数，也都能写成 `β(a)` 的函数。⇒ 任何"看表达式长相"的规则（不许出现 `log 1/a`／只许依赖 `β(a)`／只许"与 `a` 无关"）**要么放过 `C5`，要么连 RT 一起杀掉**。唯一能分开二者的是**比值在 `a↓0` 的极限行为**：RT 的比值有有限非零极限，`C5` 的比值发散。**这就是 §1.1(ii) 必须是 `liminf/limsup` 而不能是"不显含 `a`"的原因。`[T]`**

### 1.4 与 `glue-a-limits:90` 逐读法相容

| `:90` 的读法 | C5 是否活 | 补丁后 |
|---|---|---|
| (a) 发散项须按同一 scheme 常数 `C` 减除 | 活（它不动发散项） | 不变 `[T]` |
| (b) "同一 scheme" = 「同一族常数 `{C_a}`」 | **活**（这正是漏洞） | 被 (i) 关掉 `[T]` |
| (c) "这是 RT 进入 GL3 的唯一位置" | 活 | 不变：补丁不给 RT 新增入口 `[T]` |

⇒ **逐字相容**：只加量词（"一个/一族"）+ 一条渐近夹逼 + 一条 `z_n=z^n`，`(:90)` 原句可整句保留。
