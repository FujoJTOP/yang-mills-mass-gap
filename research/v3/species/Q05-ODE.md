## 2 · 从条件化结构推：`G′`、`G″` 的矩表示

### 2.1 引理 Q1（`ψ`-引理）`[T]`

设 `‖v‖=1`，切片分解 `X = a v + Y`，`Y ⟂ v`，`dX = da dY`，则 `ρ_v(a) = ∫_{v^⊥} e^{−V(av+Y)}dY > 0`。记纤维测度
```
dμ_a(Y) := e^{−V(av+Y)} dY / ρ_v(a) ,      E[·|a] := ∫ · dμ_a .
```
**断言**：对任意 `C¹` 的 `ψ`，
```
d/da E[ψ|a] = E[∂_vψ|a] − Cov(ψ, F|a) ,        F := ∂_vV .                        (Q1)
```
**证明**（纯积分号下求导，`ρ_v>0`，`V∈C²`、纤维紧）：`ρ_v′(a) = ∫∂_a e^{−V}dY = −∫F e^{−V}dY = −ρ_v E[F|a]`，即
`ρ_v′/ρ_v = −E[F|a]`，故 `G′(a) = −ρ_v′/ρ_v = E[F|a]`。又 `(ρ_vE[ψ])′ = ∫∂_a(ψe^{−V})dY = ρ_vE[∂_vψ] − ρ_vE[ψF]`，
两边除 `ρ_v` 再用 `ρ_v′/ρ_v = −E[F]` 即得 (Q1)。∎

> 注：`p21`/`p22` 用 `G_v:=∂_vS_W` 与 `Φ′:=∂_vΦ` 分写（`F=G_v+Φ′`），本文件的 `F` 就是它们的 `F`；`p22` 的 `m_G′ := d/da E[G_v|a]` 只是 `(Q1)` 取 `ψ=G_v` 的一条**局部**实例，**不是** `G′` 本身（见 §2.3）。

### 2.2 两条链（任务问的"矩表示"）`[T]`

取 `ψ = 1`：恒等 `0 = 0`。取 `ψ = F`（需 `V∈C²`、`F` 沿 `v` 可导，`∂_vF = ∂_v²V =: κ`）并注意 `Cov(F,F)=Var(F)`：
```
G′(a) = E[F|a]                                                                    (I1)
G″(a) = E[κ|a] − Var(F|a)                                                         (I2)
```
展开成 `p21` 的三块（`G_v`、`Φ`）：
```
G″ = E[H_vv + Φ″|a] − Var(G_v + Φ′|a)
   = (E[H_vv|a] + E[Φ″|a]) − (Var(G_v|a) + Var(Φ′|a) + 2Cov(G_v,Φ′|a)) .          (I2′)
```
这就是 `p21` `eq:split`（`p21_rebuild.py:88` 的 `Gpp`）与 `G4` Lemma G1 的 `E[∂_v²V|a]−Var(∂_vV|a)`。**`[T]`，机理是纯 IBP，不是假设。**

### 2.3 等价的输运形式（`G` 真正满足的"方程"）`[T]`

由 `∂_a log μ_a = −(F − E[F|a]) = G′(a) − F`：
```
∂_a μ_a = ( G′(a) − F ) μ_a ,        μ_a = e^{−V}δ(⟨v,X⟩−a)/ρ_v(a)                 (T)
```
这是一条**关于 `a` 的线性 ODE，状态是整个纤维测度 `μ_a`**（一阶、可积：给定 `μ_{a₀}` 唯一延拓）。`(I1)(I2)` 是它的第 0、1 阶矩投影。**`(T)` 才是"边缘分布满足的方程"的准确说法**：它不是 `G` 的标量 ODE。

### 2.4 数值核验 `[T]`

`q05_ode.log [A]`：定义级差商 `G=−log ρ_v`（`h=10⁻²`）对上 `(I1)(I2)`：
`G′` max rel `4.3e−06`；`G″` max rel `7.8e−04`（两者都被差商截断误差主导，`G″` 用 `h=2×10⁻²` ⇒ `O(h²)` 量级正对）。5 组 `(β,θ,a)`：`(2.5,π,0)`、`(2.5,π,0.75)`、`(2.5,π/2,0.5)`、`(1,π,0.5)`、`(5,π,1)`。

## 3 · 闭合判定：`G″ = F(a,G′)` 存在吗？

### 3.1 普适反证（实现引理）`[T]` —— 不存在任何普适的 `F(a,G′)`

> **命题**：对任意 `C^∞`、正、可积的 `ρ`（支撑含 `a₀` 的邻域），存在 `V∈C^∞` 使 `ρ_v ≡ ρ`。
> **构造**：取 `V(X) = −log ρ(⟨v,X⟩) + ½g‖Y‖²`（`g>0`），则 `ρ_v(a) ∝ e^{−log ρ(a)}·∫e^{−½g‖Y‖²}dY = ρ(a)`。∎

于是：任取两条在 `a₀` 处 `(ρ,ρ′,ρ″)` 中 `(a,G′)` 相同而 `G″` 不同的密度（`G″ = −(log ρ)″`），都存在对应的 `V`。
⇒ **"`G″=F(a,G′)`" 作为对"边缘自由能"这一函数类的普遍陈述为假。** 闭合若成立必是**模型特异的**（依赖 `V` 的具体结构），不能从条件化结构本身推出。

### 3.2 模型内数值否证（撞点检验）`[C]`

若存在 `F`，则 `(a,G′) ↦ G″` 在数据上必须是单值的。扫 `β∈{1,2.5,5}` × `θ/π∈{0,.25,.5,.7,1}` × `a∈{0,.25,.5,.75,1,1.5,2}` = 105 点（`q05_ode.log [C]`）：

| 点 1 | 点 2 | `Δa` | `ΔG′` | `G″₁` | `G″₂` | `\|ΔG″\|` |
|---|---|---|---|---|---|---|
| `(β=1,θ=0,a=0)` | `(β=2.5,θ=0,a=0)` | 0 | **0.000** | +0.3896 | +0.7299 | **0.340** |
| `(β=2.5,θ=π,a=0)` | `(β=5,θ=0.25π,a=0)` | 0 | **0.002** | +0.1360 | +1.2437 | **1.108** |
| `(β=1,θ=0.7π,a=.25)` | `(β=1,θ=π,a=.25)` | 0 | 0.001 | +0.2525 | +0.1731 | 0.079 |

⇒ `(a,G′)` 几乎完全重合处 `G″` 相差到 `G″` 自身尺度的 80%。**无 `F(a,G′)`。`[C]`**

### 3.3 无穷梯（`(b)` 要求的前几阶矩关系）`[T]`

`(Q1)` 取 `ψ = F^n`（`n≥1`，注意 `∂_v(F^n)=nF^{n−1}κ`）得**精确**梯子（记 `m_n := E[F^n|a]`，`m₁=G′`）：
```
m_n′(a) = n·E[F^{n−1}κ | a] − ( m_{n+1}(a) − m_n(a) m_1(a) ) ,        n = 1,2,3,…     (L_n)
```
- `n=1`：`G″ = E[κ] − (m₂ − m₁²)` = `(I2)`。
- `n=2`：`d/da E[F²|a] = 2E[Fκ|a] − (m₃ − m₂m₁)`。`q05_ode.log [D]` 核验：残差 `2.0e−05 … 4.4e−04`（差商），`[T]`。
- `n=3`：需要 `m₄` 与 `E[F²κ]`；一般 `n` 阶需要 `m_{n+1}` 且同时需要 `E[∂_v^n V]`（因为 `κ` 本身也要沿 `a` 求导：`d/da E[∂_v^{k}V] = E[∂_v^{k+1}V] − Cov(∂_v^{k}V,F)`）。

⇒ 梯子是**双向无穷**的（力矩链 ⊗ `V` 的 `v`-导数链）。截断只在 `F` 的条件分布落在有限维指数族时可能（如纤维高斯 ⇒ `m₃=3m₂m₁−2m₁³` ⇒ `n=2` 自动塌缩）。**此模型的 `F` 不是**（见 3.4 的 `θ=π` 变号）。

### 3.4 唯一真正闭合的情形：`a`-解耦（`θ=0`），且它不携带耦合信息 `[T]`

`θ=0` 时 `S` 与 `a` 无关，`a` 只从积分下极限 `|a|` 进入：`ρ_v(a)=∫_{|a|}^{2π} g(ρ)dρ`，
`g(ρ)=sin²(ρ/2)/ρ·e^{−β(1−cos(ρ/2))}`。于是（`a>0`）`G′ = g(a)/ρ_v(a)`，`ρ_v′=−g`，得**Riccati**：
```
G″ = G′² + c(a) G′ ,      c(a) := (log g)′(a)                                     (R)
```
`q05_ode.log [E]`：4 位小数逐位吻合，残差 `5.3e−11`，`[T]`。Riccati 可用 `G′=−u′/u` 线性化成 `u″=c(a)u` ⇒ **这是任务设想的"可积 ODE"的唯一样本**。但它出现在 `S` 与 `a` 解耦的退化情形：那里 `ρ_v` 本来就是 1-D 尾部积分，`G″` 及符号早已闭式已知（`G″(0)=W₀>0`），对 `θ≠0` 的耦合切片零信息。

### 3.5 为什么 `F≥0` 的闭合**不可能**存在（模型内精确）`[T]`

`O01-MARGINAL-BL.md:153` 的闭式（本文件 `[F]` 独立复算，6 位吻合）：
```
θ=π:  G″(0) = W₀ − V₀β² ,   W₀ = 1/(2·Cin(2π)) = 0.205115297123 ,  V₀ = 0.011059293772973 ,
      β* = √(W₀/V₀) = 4.30660785  ⇒  β > β* 时 G″(0) < 0（β=6: −0.193019）
```
任何"`G″=F(a,G′)` 且 `F≥0`"的闭合都会强制 `G″≥0` 处处。**与精确反例矛盾** ⇒ 即使强行找到闭合，`F` 也必然变号，`G″≥0` 不可能被"积分出来"。

## 4 · 与 `p22` 恒等式的一致性（任务第 3 问）

`p22` 的 `(ii)`（`[T]`，`P09 (*)`）：`m_G′ = E[H_vv|a] − Cov(G_v, G_v+Φ′|a) = E[H]−Var(G)−Cov(G,Φ′)`。
`p21` 的 `eq:split` 分块式：`G″ = m_G′ + E[Φ″] − Var(Φ′) − Cov(G,Φ′)`。

**命题**：两者是同一条 `(Q1)` 的两条实例，且**代数相加恒等于 `(I2)`**。
- `ψ=G_v`：`m_G′ = E[∂_vG_v] − Cov(G_v,F) = E[H_vv] − Var(G_v) − Cov(G_v,Φ′)` ⇒ 正是 `p22 (ii)`。
- `ψ=Φ′`：`d/da E[Φ′|a] = E[Φ″] − Cov(Φ′,F) = E[Φ″] − Var(Φ′) − Cov(Φ′,G_v)`。
- 两式相加：`G′ = E[G_v]+E[Φ′]` 的导数 `= E[H]+E[Φ″] − [Var G + Var Φ′ + 2Cov] = E[κ]−Var(F)` ⇒ `(I2)`。∎ **`[T]`**

**数值**：`q05_ode.log [B]`，5 组 `(β,θ,a)`，`G″` 与 `m_G′+E[Φ″]−VarΦ′−Cov` 的残差 `≤ 6.8e−06`（`m_G′` 的差商误差量级）。⇒ **一致，(c) 不成立；`p21` 与 `p22` 都没有错。**
（唯一需要的说明性区分：`p22` 的 `m_G′` 是 `G_v` 的条件均值的导数，**不是** `G′`；`G′=E[G_v]+E[Φ′]`。`p22` `[Q2]` 表里 `θ=π` 的 `m_G′(0)=−0.0691<0` 与 `G″(0)=+0.1360>0` 并不矛盾——差值正是 `E[Φ″]−VarΦ′−Cov = 0.2051`。）

## 5 · 精确的"可积内容"：一条第一积分，但只是加权平均 `[T]`

由 `(I2)` 与 `(Q1)`（`ψ=1` 等价形式 `ρ_v′=−ρ_vG′`）：
```
E_{ρ_v}[G″] = ∫ρ_v (G″) da = ∫ρ_v (G′)² da = I(ρ_v) = Fisher 信息 ≥ 0 ,               (F1)
```
用 `ρ_vG″ = −ρ_v″ + ρ_v(G′)²` 与 `ρ_v(±2π)=0`（Haar 边缘在图表边缘消失）得 `∫ρ_v″=0`。这就是 `H3-AVERAGED-HEAD.md` Theorem H3-A `[T]`。

**(F1) 是这条"方程"唯一精确的积分**：它对 `a` 的加权平均给出正性 `I(ρ_v)≥0`，但**不控制点态符号**。而 `H1` 要的是点态/一致下界 `G″(a) ≥ δ`（`RECONCILIATION-STAR.md:187` `(★_unif-a₀)`），(F1) 给不出——`E_ρ[G″]≥0` 与 `G″` 在个别 `a` 上为负（§3.5，`β>β*`）完全可以并存。

⇒ **H1 不是"某个 ODE 的符号问题"，它就是条件化的"`E[κ|a] ≥ Var(F|a)`"不等式**，逐字即 1-D 边缘 `ρ_v` 的 log-凹性（`O01` / `O18-CHEEGER.md:151` 的判词）。而它在 `θ=π, β>β*` 处**精确为假**——所以没有 ODE 能把 `G″≥0` 积分出来；能救的只有"在物理切片/物理测度上 `Var(F|a)` 被 `E[κ|a]` 压住"这一条**数据性**命题（= 第 6 物种）。

## 8 · 判死线裁决（逐字）

**(b)。** `G″ = E[κ|a] − Var(F|a)` 是精确恒等式，但它依赖**高阶条件矩**（`Var(F|a)`、`E[κ|a]`），二者都不是 `(a,G′)` 的函数：`(a,G′)` 撞点上 `|ΔG″|` 达 `G″` 尺度的 80%（§3.2），且存在**普适反证**（§3.1）。梯子无穷（§3.3）：
```
m₁ = G′ ;  G″ = E[κ] − (m₂ − m₁²) ;  (m₂)′ = 2E[Fκ] − (m₃ − m₂m₁) ;  …  ;
m_n′ = n E[F^{n−1}κ] − (m_{n+1} − m_n m₁)
```
并且还要 `E[∂_v^nV]` 链（`κ` 自身的 `a`-导数），故梯子是双向的。

**不是 (a)**：唯一的闭合样本是 `θ=0`（`S` 与 `a` 解耦）的 Riccati `G″=G′²+(log g)′G′`——那里问题本来就是 1-D 的，不携带耦合切片信息；且 §3.5 的精确变号说明**任何** `F≥0` 的闭合都与 `G″(0)=W₀−V₀β²<0`（`β>β*`）冲突。

**不是 (c)**：`p21` 与 `p22` 完全一致（§4，残差 6.8e−06）；差别只是 `p22` 的 `m_G′` 是 `G_v` 的局部对象，不是 `G′`。

**可搬走的东西**：`(F1) E_ρ[G″]=I(ρ_v)≥0` 是这条"方程"的唯一精确积分（`[T]`），它给加权正性、不给点态下界 ⇒ H1 仍恰是条件化 log-凹（第 6 物种），未被 ODE 化归。
