## §1 关系（第 1 问）

### 1.1 一行式（格距单位 `a_t=a_s=1`；物理单位 `m_phys=m_sp/a_t`）

```
m_sp = −ln(λ₂/λ₁) = −ln(1−δ_T),   λ₂ := ‖T|_{Ω^⊥}‖ = sup spec(T)∖{λ₁},   λ₁ = 1,   δ_T := 1−λ₂/λ₁
HZG 的 S(·) 吃的是 κ_q := inf{E_n−E₀ : ⟨0|q|n⟩≠0}，且 κ_q ≥ m_sp；不等号在"最轻激发对 q 无投影"时严格（2D YM: w₁=0）。
```

- 依据：`B01-RP:41–45`（四张脸同一个数）；`L02:118–136`（定理 G：`λ₂:=‖T|_{E₁^⊥}‖`、`δ:=λ₁−λ₂>0 ⇒ m≥−log(1−δ/λ₁)>0`，算术核已机检）；`D3:107`（`Δ_gap:=−log(λ₁/λ₀)=1/ξ`，同一读法）。
- **下一手**：把 `HZX ②` 的句子改写成"`κ_q ≥ m₀`（`0.1` 的界要的）∧ `m_sp ≥ m₀`（靶要的）"，两件分开记；`0.2` 已证前者弱于后者。

### 1.2 为什么不除 `d`（三行，逐条自带反例）

1. 率必须按步可加：`C(d₁+d₂) ≤ C(d₁)C(d₂)/C(0)` 逼出 `C(d)=e^{−m d}`；写成 `m d/d` 在 `d=1` 给 `e^{−m/4}`——`m=1` 时 `0.7788` vs 正确 `0.3679`。
2. `d_k` 是图距离（`HZH-ZLAST:28,37`），`coth(m/2)^4` 的 `4` 来自 `Σ_{z∈Z^4}e^{−m|z|_1}=(Σ_{n∈Z}e^{−m|n|})^4` 的四坐标乘积。
3. 唯一合法换算是 `m_phys=m/a_t` 与"时间向率 = 空间向率"（同一道、各向同性；`X1-MODULAR:174` 的模隙=`β×`隙是同一双射），不是除以 4。**下一手**：`m` 旁写"每步"，单位换算只写 `1/a_t`。

### 1.3 `λ₂` 是 `sup`，不是"第二个本征值"（一个词差一个数）

`λ₂:=sup spec(T|_{E₁^⊥})`（谱半径）与 `λ₂:=inf spec(T|_{E₁^⊥})` 给不同 `m`：`L02:149–159` 的 `mult((1+x)/4)` 反例给 `sup` 读法 `m=0`、`inf` 读法 `m=log2`。`0.4` 的单调传递只在 `sup` 读法下成立。**下一手**：正式陈述把 `λ₂` 的定义写死（这是本条唯一口径风险，`L02:160` 同判）。

### 1.4 扇区：不钉 `k=0∩0⁺⁺`，恒等式给的是动量塔

全转移矩阵在有限盒上 `λ₂` 由 `k≠0` 塔占据 ⇒ `m(L)~½(2π/L)²→0`（`B01-RP:89,95`）；`torelon` 可占第二态（`B01-M1:49`、`B03:97`）。⇒ 恒等式只在 `k=0∩0⁺⁺∩N-ality 0` 的投影核上读（或 `L→∞`）；`inf_L m(L)>0` 就是靶（`U06:114`）。**下一手**：任何"测到的隙"先报扇区，否则是塔不是隙。

### 1.5 勘误（登记不动原文：常数变、判词不变）

`coth(m/2)^4` 是 **ℓ¹/图距离**上的乘积和；`HZG:46,64,87` 与 `HZF:40` 写"`ℓ∞` 上的精确和"是笔误。自算：`Σ_{z∈Z^4}e^{−m|z|_∞}`（`N=12` 截断）在 `m=1` 给 **399.56**，是 `coth(0.5)^4=21.93` 的 **18.2×**（`m=0.5` 19.5×、`m=2` 9.4×）。⇒ 前件若按 `ℓ∞` 写，`ϖ≤4coth^4` 的常数要乘 ~18；按 `d_k=ℓ1` 读则 `HZG:0.1` 逐字成立。两者都 `O(1)`，`Θ(a^{-4})` 的判词不变。**下一手**：全仓 `coth(m/2)^4` 旁加"ℓ¹/图距离"。
