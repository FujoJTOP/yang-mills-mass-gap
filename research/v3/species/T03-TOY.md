## 1 定义（两个量都必须先钉死，否则五个模型的比较无意义）

**`G″(0)`：**
$$G''(0) := -\partial_a^2 \log \rho(a)\big|_{a=0},\qquad \rho = \text{粗变量 } a \text{ 在该模型自身测度下的边缘分布}.$$
- 0 维积分：`ρ ∝ e^{−S}` ⇒ `G″(0) = S″(0)`（与 `p09` 的 `−∂_a²log ρ` 同式）。
- 0+1 维：`ρ = |ψ₀|²`（欧氏路径积分单时刻边缘 = 基态模方）。
- 这条定义与 `q11_cert.py` 头注 `G″(0) = E[H+Φ″] − Var(G+Φ′)` **逐字同源**（同一 `−∂²log ρ`，只是后者用条件化期望展开）；本文件 M1 用它复现 `q11` 到 `1.1e−16`（见 §2 M1）。

**`m`（质量隙）：**
$$m := \inf\big(\mathrm{spec}(H)\setminus\{E_0\}\big) - E_0 .$$
**只在模型有 transfer 方向时定义**；0 维模型（单 plaquette、0+0 双井）**无谱、无 `E₁`** ⇒ `m` **无定义**（不是 `0`，也不是 `>0`）。
这是一条必须写死的纪律：把「无定义」写成 `0` 会凭空造出 (a) 反例，把「无定义」写成 `>0` 会凭空替 H1 辩护。

### M1 单 plaquette —— `G″(0)` 有，`m` 没有

`q11` 的严格区间锚 `S−D = +0.1359947110419882110`（宽 `1e−117`）在本文被独立复现（`Z = Cin(2π)/2` 级数）：
`Z = 1.218826696528612308`、`S = 1/(4Z) = 0.205115297123073026`、`D = β²Var(g) = 0.069120586081084928`、`G″(0) = +0.135994711041988098`，**与锚差 `1.1e−16`** `[C]`。

**但「它的质量隙是什么」这个问题在这个模型里没有答案**：单 plaquette 是 0 维积分（0 个时空方向），没有 transfer 矩阵、没有 `E₁`。两种「硬凑」都要被否掉：
- 若令 `m² := G″(0)`（曲率质量）⇒ 蕴含式退化成 `G″>0 ⇒ G″>0`，**同义反复，零信息**；
- 若把 plaquette 强行量子化成转子 `H = −Δ_{SU(2)} + βV` ⇒ 那个 `m` 是**另一个模型**的隙，与 `G″(0)` 无因果关系（见 M6 的一般机制）。

⇒ **M1 对蕴含式既不证实也不证伪**。语料里一直把 `q11` 当成「H1 左半边的第一条严格正性」，这没错；但**它从未提供过右半边**，而这一点此前没有被逐字写明。`[T]`

### M2 2D YM —— **(b) 反例，且是精确的**

二维 YM 的 Migdal 求和把空间圆环上的 transfer 算子化成群流形量子力学：`H = (g²/2)·C₂`，`E_R = (g²/2)C₂(R)`。
- 基态 = 平凡表示 = **常函数**（对 Haar 测度均匀）⇒ 任何粗变量的边缘 `ρ` 都是**平坦**的 ⇒ `∂²log ρ ≡ 0` ⇒ **`G″(0) = 0` 精确**；
- `m = (g²/2)·C₂(fund) = g²(N²−1)/(4N)`，`N=2, g²=1` 时 `= 0.375 > 0`；`m ∝ g²N` 与已知 2D 结果同号同量级。

⇒ **`G″(0) = 0` 而 `m > 0`：蕴含式的逆向失败**（前提不成立、结论成立）。
**口径说明（AGENTS §2.1）**：`H = (g²/2)C₂` 是 2D YM 的标准结果，本文按标准 Migdal 求和重列、未逐字核原文（无 arXiv 号可给）⇒ 该条标 `[T]*`（模型内推导严格，文献引用未核）。它**不依赖任何数值**。

### M3 1D Dirichlet 弦 —— 一致，且是「恒等式的」一致

高斯模型 `ρ ∝ e^{−ω²q²/2}` ⇒ `G″(0) = ω²`（恒等）、`m = ω`。格点 Dirichlet 谱核验（`N=999`）：
`L=1`: `ω₁ = 3.1415913617`（`π/L = 3.1415926536`）；`L=100`: `ω₁ = 0.0314159136`。
⇒ `G″ = π²/L² = m²`，两者同号同速率趋 `0`。**无反例**，但注意：**这是高斯模型的结构恒等式**（`G″ = m²` 对一切自由场成立），因此它**不提供任何关于相互作用理论的信息**——`h1a` 的「`G″=π²/L²→0`、`m→0`」在蕴含式上只是把同一件事说两遍。`[T]`

### M4 平直双井 —— `p09` 的 `−1` **不能**用来做 (b)

- **0+0（`p09` 的原始对象）**：`ρ ∝ e^{−S}`，`G″(0) = S″(0) = −1` **精确**。但 0 维无动力学 ⇒ **`m` 无定义**。
- **0+1 量子化**（`H = p²/2 + a⁴/4 − a²/2`，三对角精确对角化 `N=4001`，`h=3e−3`）：
  `E₀ = 0.147234913363`、`E₁ = 0.872259573278`、**`m = 0.725024659915 > 0`**；
  由 `ψ₀` 差分得 **`G″(0) = +0.5889400`**，与恒等式 `4(E₀−V(0)) = 0.5889397` 差 `3.9e−7`（网格误差）⇒ **`G″(0) > 0`，与 `m>0` 同号，一致**。

⇒ **`p09` 的 `−1` 在量子化后翻号**。因此在同一测度下（`ρ=|ψ₀|²`），双井**不是** (b) 反例；它反倒是个警示：**把 0+0 的 `S″` 直接当成「质量平方」会得到反号**。这条必须写明，否则会伪造出一个 (b)。

### M6 谐振 ⊗ 自由 —— **(a) 反例，这就是判死线 (a)**

`H = (p_a²+p_b²)/2 + ω²a²/2`（`b` 方向自由 = 无质量）：
- 边缘 `ρ_a ∝ e^{−ωa²}` ⇒ `G″(0) = 2ω = 2 > 0`（恒等；M4 单位测试数值核到 `2.000006`）；
- 谱：`a` 方向给 `{ω/2}`，`b` 方向自由给连续谱 `[0,∞)` ⇒ `spec(H) = [ω/2, ∞)` **连续**，连续谱自 `E₀` 起 ⇒ **`m = 0`**。

⇒ **`G″(0) = 2 > 0` 且 `m = 0`**。这不是数值现象，是精确谱。

**为什么这不是「廉价特例」**：它正是失配的**最小见证**——`G″(0)` 是**单方向**的曲率，`m` 是**整个谱**的性质。任何在对称点上 `ρ` 有局部极大、同时存在一个平坦（无质量）方向的模型，都会给出 `G″>0` 且 `m=0`；这类模型在**无穷多**。反例不需要「精巧」，只需要**结构性的**一处失配。

## 3 机制（比反例更有用的一条）

**命题（`[T]`，0+1 维，平直测度，`H = p²/2 + V`，`ρ = |ψ₀|²`）：**
$$G''(0) = -\partial_a^2\log|\psi_0|^2\big|_{a=0} = -2\frac{\psi_0''}{\psi_0}\Big|_{0} = 4\big(E_0 - V(0)\big).$$
（用 `−ψ₀″/2 + Vψ₀ = E₀ψ₀` 代入。谐振子核验：`4(ω/2−0) = 2ω`，数值 `2.000006` ✓；双井核验：`0.5889` ✓。）

**读法**：`G″(0) > 0 ⟺ V(0) < E₀`——**「`a=0` 这一点在基态能量之上」**，即该点处于经典禁区 / 是势垒顶 / 是边缘分布密度的一个局部极大。
这与「谱上方有没有隙」是**两个独立对象的两个不同命题**：
- `m = E₁ − E₀` 由**整体**势形与边界条件定；
- `G″(0)` 只由**单点** `V(0)` 与 `E₀` 的差定。
⇒ 想让 `G″(0)>0` 蕴含 `m>0`，等于声称「单点势值高于基态 ⇒ 谱上有隙」，而这在 M2/M6 上直接假。

**推论（对 H1 的直接含义）**：`G″(0)>0` 是一个**几乎处处成立**的弱条件（对称点上 `ρ` 通常取极大）。H1 的蕴含式若成立，就该对**所有**这样的模型成立——M6 一票否决。**这一票不需要 4D YM、不需要格点数据、不需要 β 窗口。**

## 4 判决（逐条对应用户的 (a)/(b)/(c)）

- **(a) 成立（判死线触发）**：M6，`G″(0)=2>0`，`m=0`。⇒ **`G″(0) > 0 ⇒ m > 0` 是假的。H1 不是通往隙的路。** 这是今天最重的结论。
- **(b) 成立（同一判死线）**：M2，2D YM，`G″(0)=0`，`m=3g²/8>0`。⇒ 蕴含式**逆向**也失败；`G″` 的符号既非充分也非必要。
- **(c) 不成立**：并非「所有可解模型都一致」，因此**不能**把 `⇒` 当成「在可解类上成立、只差一般证明」——那个台阶 4 不存在。
- **M1 / M4(0+0) / M5 是 vacuous**：`m` 无定义或平凡。语料把 `q11` 当 H1 左半边的严格正性没错，但**右半边从未被任何模型支持过**。
- **H1 的正确重定位**（一句话，不许含糊）：`G″(0)` 是**边缘分布的 log-凹性 / 单点势—基态能量差的符号**，是「对称点稳不稳」的指标；它**不是**「谱上有没有隙」的指标。要通向 `m`，必须换成**整体**对象（谱下界、转移算子的 Poincaré 不等式、`−∂²log ρ` 的**一致**下界配合 `L→∞` 的紧性），而不是 `a=0` 一点的曲率。
