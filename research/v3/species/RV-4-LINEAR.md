## §0 判死线（先写；全部量纲已逐项核，见 §1.2）

| 项 | 判 |
|---|---|
| **`G ≡ c`（`abs(c)≤1`）是不是解** | **不是**（除 `c=0` 平凡）。`θ`-导数项与 `R`-导数项**同时**消失（LHS ≡ 0），而 RHS `= k₂c/R³ ≠ 0`。`[T]+[V1]` |
| **`c` 是否自由** | **在严格常数层：不自由（无解）。** 自由度下移一层：由 `k₂ := 2c₂g²N` 决定的源强制 `1/R` 层出现，`c` 在**共振面** `2c₁−c₃=k₂` 上才重新自由。 |
| **`a(θ)` 是否被唯一确定** | **生成情形：是，唯一为 `a ≡ 0`（槽是空的），连带 `c=0`。** 共振情形：**不唯一**，`a(θ)= (k₂c/2β₁)·θ(θ−1) + C₂`，`(c, C₂)` 两参数自由。两分支都实测过（`[V5]`）。 |
| **判死线归位** | **(b) 字面成立**（`G≡c` 不是解 ∧ 生成几何下 `a(θ)` 被唯一确定）⇒ 落 `[C]`；**但 (b) 的推论"约化修好 ⇒ 可能强制隙"不成立**：生成扇区是幂律 `R^{λ₋}`、共振扇区是**不衰减的常数** `G→c≠0`，两者都不是 `e^{−mL}` ⇒ **环代数仍不强制隙**。⇒ **实质判 = (a) 的内容，形式判 = (b)。** |
| **(c) 是否成立** | **不成立**：方程在两变量下良定义（§1）。但缺一块几何（§6.2）。 |

**一句话**：`G≡c` 不是解，`c` 在常数层不自由；`a(θ)` 在生成几何下被唯一钉成 `0`（即**两变量的 `c₃` 槽是空的**），只有在 `c₃` 取**一个特定值**时该槽才有内容 —— 而 `C3-COEFF §3.2` 已证 `c₃` 由自由的法向延拓数据接管（`[U]`）⇒ **共振可达 ⇒ 自由常数以"共振条件 + 自由振幅"的形式存活 ⇒ 代数不强制隙。**

## §1 版本声明：本文件用的两变量方程 `[G2]`

### §1.1 唯一闭合的写法（不含未证成分）

`(★)` 对每个圈成立；`G = W(C₁)W(C₂)` 是两个圈的乘积，故在领头 `N` 下按 Leibniz 律：

```
∂_μ(δ/δσ_μν(x))[W(C₁)W(C₂)] = W(C₂)·[∂_μ δW(C₁)/δσ] + W(C₁)·[∂_μ δW(C₂)/δσ]
```

`C3-COEFF §4.1` 的硬事实：`x∈C` 时 `∮dy_ν δ⁴(x−y)` 只由 `y=x` 支撑，故取的是**退化分割**，一支弧长 `→0`（`W→1`）、另一支 `→` 整圈 ⇒ 每个因子的 RHS **线性**于自身。于是乘积方程的 RHS 是**两项之和**，不是 `G²`：

```
c₁ G_RR/R + c₃ G_R/R²  =  k₂ G/R³ ,   k₂ := 2·c₂ g²N（两圈 ⇒ 因子 2）        [G2-lin]
```

**这是唯一闭合的两变量写法 `[T]`**：若改用二次闭包 `W″ ~ W²`，乘积给出 `2W₁′W₂′ + κ(W₁²W₂+W₁W₂²)`，其中 `W₁′(R,θ)W₂′(R,θ)` **不能由 `G` 单独表示**（它依赖 `∂_R L₁, ∂_R L₂` 的分配）⇒ **不闭合**。⇒ 二次闭包在两变量下**无定义**（这是 `SP-F-EQ1 §2` 的 `f²` 估计在两变量上的死因之一，另一个是 `C3-COEFF [E]①` 的 `1/R`）。

### §1.2 量纲逐项（`[G]=0`、`[θ]=0`、`[R]=L`，LHS 与 RHS 必须同为 `L^{−3}`）

| 候选项 | 量纲 | 结论 |
|---|---|---|
| `c₁ G_RR/R` | `L^{−2}·L^{−1}=L^{−3}` | **留**（呼吸模，`C3-COEFF §2` 的 `dA/dR=2πR`） |
| `c₃ G_R/R²` | `L^{−1}·L^{−2}=L^{−3}` | **留**（原 `c₃` 槽） |
| `β₁ G_θθ/R²` | `L^{−3}` | **留**（唯一新增的两变量项） |
| `β₂ G_θ/R²` | `L^{−3}` | **删**：`∂_θ` 在 `θ↔1−θ` 下为奇，而 `G(R,θ)=G(R,1−θ)`（交换 `C₁,C₂`）⇒ `β₂≡0` |
| `β₃ G_Rθ/R²` | `L^{−3}` | **删**：同上为奇 |
| `G²/R³` | `L^{−3}` | **删**：不闭合（§1.1） |

⇒ **两变量下的方程是三项线性算子**（`β₂,β₃` 被对称性杀掉，不是被省略）：

```
c₁ G_RR/R + c₃ G_R/R² + β₁ G_θθ/R²  =  k₂ G/R³            [G2]
```

`β₁` 的符号**不由 `(★)` 定**（它是延拓/处方常数，同 `c₁,c₃`）。取 `β₁` 与 `c₁` 同号，理由：`δ/δσ_μν` 在平面两方向上的主象征同号（椭圆型二阶算子）`[C]`。本文数值取 `c₁=1, c₃=0.5, β₁=1, k₂=0.8`；共振值 `c₃=1.2` 单列。

**`[E]`（对 RV 路自己的勘误）**：`LOOP-RUNBOOK §1325` 说"右端必须两变量"，方向对，但**两变量不带来 `f²` 型的非线性，带来的是 `θ`-方向的二阶项 + 一个共振条件**。这一点决定 §0 的判。

## §2 步骤 1：`G ≡ c` 是不是解

`G≡c` ⇒ `G_R=G_RR=G_θθ=0` ⇒ LHS `= 0`（不是"小"，是**恒零**，因为 `θ`-项和 `R`-项同时死）。RHS `= k₂c/R³`。

```
0 = k₂ c / R³     ⟺     c = 0
```

**`[T]`**：`G≡c` 是解 ⟺ `c=0`（而 `W≡0` 不是物理解：空圈给 `W=1`）⇒ **常数扇区为空，`c` 在严格常数层不自由。**

**`[V1]`**（`k₂=0.8`，残差 `:= LHS−RHS = −k₂c/R³`）`c=0.5`：`R=3` → `−1.481481e−02`；`R=10` → `−4.000000e−04`；`R=100` → `−4.000000e−07`。`c=0` 全零。
⇒ **`(a)` 的前提"`G≡c` 是解"直接假，`(a)` 不能按字面成立。**

## §3 步骤 2：`G = c + a(θ)/R` —— 两个阶，过定

代入 `[G2]`（`G_R=−a/R²`、`G_RR=2a/R³`、`G_θθ=a''/R`）：

```
LHS = (2c₁−c₃)a(θ)/R⁴ + β₁ a''(θ)/R³ ,    RHS = k₂c/R³ + k₂a(θ)/R⁴
```

**两个独立阶（因为 `a(θ)` 与 `c` 是两个未知函数/数，而 `R` 的两个幂次必须分别对）**：

```
R^{−3}:   β₁ a''(θ) = k₂ c                (常源 ⇒ a(θ) 被积出来)      (I)
R^{−4}:   (2c₁ − c₃ − k₂) a(θ) = 0   （逐点于 θ）                  (II)
```

### §3.1 生成情形：`a(θ)` **被唯一确定为零**

若 `2c₁ − c₃ − k₂ ≠ 0`（生成；本文数值 `= 0.7`），(II) 逐点强制 `a ≡ 0`；回代 (I) 得 `k₂c = 0` ⇒ `c = 0`。

> **⇒ 生成几何下 `c + a(θ)/R` 只有平凡解。`a(θ)` 确实"被唯一确定"，但确定到的值是 `0` —— 两变量的 `c₃` 槽是空的。（这正是一维 `C3-COEFF` 的结论在更高一层的再现：`c₃` 不是一个待算的数。）**

### §3.2 共振面：`a(θ)` **不唯一**，`c` 重新自由

若 `2c₁ − c₃ = k₂`（一条**无量纲的代数关系**，余维 1），则 (II) 变成恒等式，(I) 只钉住 `a` 的二阶导：

```
a(θ) = (k₂c / 2β₁)·θ(θ−1) + C₂          (再要求 θ↔1−θ 对称 ⇒ 一次项系数 = −k₂c/2β₁)
```

```
G(R,θ) = c + [ (k₂c/2β₁)·θ(θ−1) + C₂ ] / R        (c, C₂) 两参数自由    [G2-res]
```

**`[V5]` 残差实测**（`c=0.5, C₂=0.3, θ=0.3`）：
- 共振 `c₃=1.2`：`R=10 → −5.4e−20`，`R=100 → 0.0`，`R=10⁴ → +5.0e−29`（机器零）✔
- 生成 `c₃=0.5`：`R=10 → 1.806e−05`，`R=100 → 1.806e−09`，`R=10⁴ → 1.806e−17`
- 预测 `(2c₁−c₃−k₂)A(θ)/R⁴`，`A(0.3)=0.258` ⇒ `R=10` 给 `1.806e−05` ✔ **逐位吻合**

**`[T]`（本节主结果）**：**"`c₃` 的两变量版本"不是一个数，是共振条件 `2c₁ − c₃ = 2c₂g²N` 与 `θ`-剖面系数 `k₂c/2β₁`。** 生成情形它把槽填成 `0`；共振情形它把槽变成自由函数的一个特定形状（`θ(θ−1)`，在 `θ=1/2` 取极小 `−1/4`，即"对称分割处修正最大"）。

## §4 这一步为什么**不**救环代数

两个独立理由，都已在库内：

1. **`c₃` 证明过不可定义**（`C3-COEFF §3.2`：`c₃ = c₁(1+a)`，`a` 由自由法向数据 `∂_n w` 与重合点处方定，`[U]`），`c₂` 同样处方依赖（`C3-COEFF §4.2`）。⇒ 共振条件 `2c₁−c₃ = 2c₂g²N` **总可以被处方选到**。所以 `[G2]` **不排除**常数扇区 ⇒ 代数对 `c` 无约束。`[T]`（条件于 `[U]`）
2. **就算不共振，(b) 也给不出隙**：`R^{−3}` 阶的齐次问题是 `c₁λ²+(c₃−c₁)λ−k₂=0`（`u=log R` 的常系数 ODE），
   ```
   c₃=0.5 :  λ₋ = −0.67870878 ,  λ₊ = +1.17870878
   c₃=1.2 :  λ₋ = −1.00000000 ,  λ₊ = +0.80000000      [V3]
   ```
   两根之积 `= −k₂/c₁ < 0` ⇒ 一正一负，**没有 `λ=0` 根** ⇒ 无常数模；有界扇区是**幂律** `R^{λ₋}`。幂律衰减 ⇒ 团簇不是指数 ⇒ **也不是隙**（物理上更可疑：它说明 `[G2]` 缺几何，见 §6.2）。

**⇒ 分支表**：

| 几何 | 有界扇区 | 有隙？ |
|---|---|---|
| 生成 `2c₁−c₃ ≠ k₂` | 幂律 `A·R^{λ₋}`（`λ₋<0`），`A` 自由 | **否**（幂律 ≠ `e^{−mL}`） |
| 共振 `2c₁−c₃ = k₂` | `G → c ≠ 0`（不衰减） | **否**（更强：反着来） |
| `c₃` 处方可调 | 共振可达 ⇒ 上表两行都在可达集内 | **代数不强制隙** |

## §5 数值印证：反向积分（`sp-c` 同法）

`[G2]` 在 `u=log R` 下是（`β₁` 项在 `R^{−3}` 阶不参与，`[V6]` 见下）：

```
c₁ G_uu + (c₃−c₁) G_u − k₂ G = 0        （θ-无关的领头阶）
```

**`[V4]` 反向积分**（`u: log(1e5) → log(2.7)`，RK4，20 万步）：
- 初值 `G(1e5)=0.5, G_u=0` ⇒ 终点 `G(2.7)=400.16629580`，局部斜率 `dlogG/du = −0.678709`
- 初值 `G(1e5)=0.900, G_u=0` ⇒ 终点 `G(2.7)=720.29933243`，局部斜率 `−0.678709`（**同一**）
- 校验解析慢流形 `A·R^{λ₋}`（`A=0.5`）：`G(2.7)=0.25480012` ✔

⇒ **反向积分下不同初值收敛到同一指数 `λ₋`、不同振幅（`A_eff = 785.26` vs `1413.46`）。**

**`[V7]` 正向积分（`R: 2.7 → 1e5`，落在有界流形上；这就是题目要的"两个 `c` 与对应 `R` 终点"）：**

| 初值（`R=2.7`） | 终点 `G(1e5)` | 拟合振幅 `A` |
|---|---|---|
| `G=0.25480012`, `G_u=−0.17293508` | **`2.02034734e−04`** | `0.500000` |
| `G=0.76440036`, `G_u=−0.51880524` | **`6.06104119e−04`** | `1.500000` |

两者都合法（`|G|≤1`）、都满足方程，末端值差 3 倍 —— 但**差的是同一个幂律的振幅，不是两个常数**。`[T]`

**`[V8]` 常数初值被排斥**：初值 `G(2.7)=0.5, G_u=0`（纯常数）⇒ `G(1e5)=4.434407e+04 ≫ 1`，违 `|W|≤1`。⇒ **常数不在有界流形上。** `[V]`

**`[V6]` `θ`-依赖被有界性杀掉**（`β₁` 与 `c₁` 同号）：把 `G_θθ → −μ²G`，方程给 `c₁G_uu = k₂G −(c₃−c₁)G_u + e^uβ₁μ²G`。同一反向积分，`μ²=0` 的增长因子 `8.00e+02`，`μ²=1` 为 `1.34e+273` ⇒ **任何 `θ`-依赖只能以被禁止的增长模存在**。⇒ **`R→∞` 时两变量解自发塌回 `θ`-无关**（`θ`-方向是快变量）。`[T]+[V]`

## §6 一句话判 + 缺的几何

### §6.1 判

> **两变量下"自由常数"没有消失，它换了形态：严格常数层被方程杀掉（`G≡c` 只有 `c=0`），自由度分裂成（i）幂律振幅 `A`（永远自由，`[V7]`）与（ii）共振面上的 `(c, C₂)` 两参数族（可达，因为 `c₃` 由处方自由）。⇒ 环代数仍不强制隙。**

### §6.2 缺哪一块几何（不是 (c)，但必须写明）

`[G2]` 只张成 `(R,θ)` 两参形变：`R` 是圆的呼吸（`C3-COEFF §2` 已证 `= `面积方向）、`θ` 是切点位置。**平面内的非圆/横截形变（`x` 处面元的角位置、多重分割、自交点）完全没有进入**。`[V6]` 说明正因如此 `θ`-方向在大 `R` 被压死，方程退化为一条 `R`-ODE —— 而一条尺度协变 ODE 的渐近字典只有 `{幂} × {(log)^q}`（`SP-C-GMT §5` 已证），**`e^{−mL}` 结构性不可达**。⇒ 要拿到隙，缺的是**横向（非呼吸、非切点）面元方向**这一个自由度；`c₃` 那条老路的两变量版本已在此判完。

## §7 未做 / 不许说 / 路径

- **未做**：`β₁` 的实算（与 `c₁,c₃` 同类，处方依赖）；共振面 `2c₁−c₃=k₂` 是否被别的几何条件（如 `θ→0` 的退化分割边界条件 `G(R,0)=f(R)`）**排除**——若 `G(R,0)=f(R)` 被当作硬边界条件，则 `C₂ = A_{1D}`、`c` 被一元扇区钉住，共振族降到 1 参数。这是本文留下的唯一可判口子。
- **不许说**：本文没给隙、没给衰减类定理、没给 `c₃` 的物理值。`(b)` 只覆盖"约化自洽"，**不覆盖"强制隙"**。`[U]` 仍是结论。
- **路径**：`(★)` → `[G2]`（三项线性 + 对称性杀两项）→ `G≡c` 否 → `c+a(θ)/R` 两阶过定 → 生成 `a≡0` / 共振 `a(θ)=θ(θ−1)` 族 → `c₃` 处方自由 ⇒ 共振可达 ⇒ 不强制隙。数值：`[V1][V3][V4][V5][V6][V7][V8]`（初值与终点均已标明）。
