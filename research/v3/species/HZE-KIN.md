## §1 三行（`sup` 路 / 独立路 / 记账路）

```
记  q := 1 − N^{-1}Re tr U_□ ∈ [0,2] a.e. ,  X := δ tr F² = a_k^{-4} q ,  ⨏_B := N_B^{-1}Σ_{x∈B} ,  N_B=(b̂/a_k)^4 ∈ ℕ
(1.0) ϖ_k = a_k^4 b̂^4 Var(⨏_B X) = a_k^4 b̂^4 a_k^{-8} Var(⨏_B q) = N_B·Var(⨏_B q)      ← 恒等（无估计）

行1  sup 路（零输入）
     Var(⨏_B X) ≤ sup_ω|⨏_B X − E⨏_B X|² ≤ (2a_k^{-4})² = 4a_k^{-8}        （⨏_B X∈[0,2a_k^{-4}]）
     ⇒ ϖ_k ≤ 4 b̂^4 a_k^{-4} = 4N_B = 4(b̂/a_k)^4          常数 = 4N_B（随 a_k→0 发散）
     紧读：Popoviciu ⇒ Var(⨏_B q) ≤ (2−0)²/4 = 1 ⇒ ϖ_k ≤ N_B

行2  块内独立（i.i.d.，或仅两两不相关 ⇒ 交叉项 0）
     Var(⨏_B X) = N_B^{-2}·Σ_{x,y}Cov_X = Var(X)/N_B ≤ 4a_k^{-8}/N_B
     ⇒ ϖ_k = Var(q) ≤ 4 ；Popoviciu 紧读 ⇒ ≤ 1              常数 = 4（粗）／1（紧）

行3  记账路（不假设独立，只吃窗口和；= HZE:1.2 去掉 a^{-8}）
     ϖ_k ≤ S_q := Σ_{|z|_∞<b̂}|C_q(z)| ,  C_q(z):=⟨q_x;q_{x+z}⟩_c ,  C_q(0)=Var(q)

     (V)/(7.19)：|C_q(z)| ≤ 4e^{−m|z|} 型 ⇒ S_q ≤ 4[#{|z|<2r}+A e^{2mr}S(m)] = Θ(1)
```

### 1.1 为什么行1 的 `4N_B` 不是「把常数算大了一点」，而是**没有常数**
`N_B=(b̂/a_k)^4` 是**变量**（`HZ6:0.4` 已勘误：`b̂` 固定物理 ⇒ `N_B` 随 `a` 变）。`ϖ` 的靶形是「`a`-一致的 `C`」，而 `4N_B` 在 `a_k→0` 上无界 ⇒ 它连一个数都给不出。**唯一让 `N_B` 消失的运算是把 `N_B^{-1}` 真的除进去**，那一步在行2 里以「独立」为价、在行3 里以「`S_q=Θ(1)`」为价。

| `b̂/a_k` | `1` | `2` | `4` | `8` | `16` |
|---|---|---|---|---|---|
| `N_B` | `1` | `16` | `256` | `4096` | `65536` |
| 行1 `4N_B` | `4` | `64` | `1024` | `16384` | `262144` |
| 行2（独立） | `4` | `4` | `4` | `4` | `4` |

**读表**：行1 与 `a` 同增，行2 与 `a` 无关。两行在 `b̂/a_k=1`（`N_B=1`，块=一个格距）重合于 `4`——那不是「常数已证」，是 `N_B=1` 的瞬间值（同型记账陷阱见 `HZ6:0.4` 的 `256`）。

### 1.2 两条自检（`[T]`）
1. **量纲/归一自检**：`4·(b̂/a_k)^4·(a_k/b̂)^4 = 4`（精确），`ϖ` 无量纲 ✓；按 `w≡1/N_B` 的双重和，`Z_a=a^{-8}N_B^{-2}Σ_z n_B C_q ≤ a^{-8}N_B^{-1}Σ|C_q|`，代进 `ϖ` 后 `a`-幂全消 ⇒ 与行3 同一式 ✓。
   **勘误候选（`HZF:1.1`，不改原文）**：其中间两式 `Z_a=a^{-8}N_B^{-1}Σ_z n_B C_q` 与 `Z_a=a^{-8}N_B Var(⨏q)` 各多一幂 `N_B`（应为 `N_B^{-2}` 与 `a^{-8}Var(⨏q)`）；同节界行 `≤a^{-8}N_B^{-1}Σ_{|z|<b̂}|C_q|` 与其定义 `ϖ_B:=N_B Var(⨏q)` **正确**，且 `ϖ_B` 与 `HZ6` 的 `ϖ=a⁴b̂⁴Z_a` 逐字同一 ⇒ 本文件与 `HZE`/`HZF` 的**界**一致，只记这两式。
2. **模型盲自检**：行1/行2 的界只用 `q∈[0,2]`，对自由场与相互作用场给**同一个数** ⇒ 判别力 0；`ϖ_free≡const`（`HZ6:D3-3` 结构，常数未算 `[NG]`）说明真值在 `O(1)`，而 `4N_B` 在 `b̂/a_k=16` 处松 `262144/ϖ_free`（该比值随 `a_k` 增）⇒ 界可用性随 `a` 变坏。

## §2 判定

**2.1 纯运动学：`[NG]`（主判）。** 无输入的界是 `4N_B`（紧 `N_B`），`sup_a 4N_B = ∞`。给出一个「`a`-一致 `C`」必须先付 `N_B^{-1}`，而它只有两个来源：**(i)** 块内独立、**(ii)** `S_q=Θ(1)`。**下一手**：凡引用本文件处写「`ϖ ≤ 4N_B`，非靶界」，不写「`ϖ ≤ O(1)`」。

**2.2 行2 是条件式 `[T]`，前提不可省。** `ϖ_k=Var(q)≤4`（紧 `1`）只在块内 $N_B$ 个 `q_x$ 不相关时成立；Wilson 测度是**单一体积上的 Gibbs 测度**，块内 `q_x` 经 shared links 耦合，独立不是它的性质（`HZE:1.3` 逐字判过同一句）。**下一手**：把行2 写在「假设 H_ind」名下，不进 `[T]` 的算术栏。

**2.3 `ϖ ≤ C` 无条件 = `[NG]`，具名障碍 = `(V)`（塔底 `β≈2.5`）。** 行3 把靶化成一式 `S_q=Θ(1)`：常数 `4[#{|z|<2r}+Ae^{2mr}S(m)]` 显式、纯数、不依 `a`，但 `(7.19)`/Thm 7.4 只到 `β<β₀(N)`，塔底每壳活度边际（`HZE:2.3`、`HZ8:0.5`）。**下一手**：只攻「塔底 `(V)`」，不再问幂（幂已由 (1.0) 钉死）。

**2.4 `(Z-last)` 的上界：`[T] ⟸ (V)`。** 由 (1.0)+行3：`Z_a=a^{-4}b̂^{-4}ϖ ≤ 4[#{|z|<2r}+Ae^{2mr}S(m)]·b̂^{-4}·a^{-4}`，即 `∃C ∀a ∀k: Z_a(k) ≤ Ca_k^{-4}`。**明说**：`(Z-last)` 的**上界**已证（mod `(V)`），**下界** `ϖ≥c₀` 不在这格（`HZ6:D4` 下半、`HZE:0.6`）⇒ `(Z-last)` 整体仍是 `[T] ⟸ (V) ∧ (ϖ≥c₀)`。**下一手**：常数并入 `L3` 台账第 8 行；`L3` 只引上界。

**2.5 不新增格。** 0.5 的 `[NG]` = `HZE:0.2/3.2` 的 `(V)` 格；2.2 的独立 = `HZE:1.3` 的同一句；`S_q` = `HZF:1.1` 的窗和式（`AGENTS §2.3`：算式对上 ≠ 新增内容，故不并行记两格）。
