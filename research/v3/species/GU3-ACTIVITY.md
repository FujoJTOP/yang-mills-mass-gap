## §2 最小可攻形态：一个不等式

### §2.1 打包无关的**唯一**写法（先把名字全部拆掉）

所有代数量（`uK`、`ū`、`u_eff`、`ρ_Ur`）都是下面这一条的**上界代理**，不是判据本身：

> **(ACT)** 固定 `d=4`、块因子 `b`、动物常数 `λ_a<∞`（`#{γ∋x, |γ|=n} ≤ λ_a^n`）。存在 `κ>0`，使
> ```
>   sup_x  Σ_{γ∋x} |w(γ)| e^{κ|γ|}  ≤  1/2 ,                        (ACT)
> ```
> 对**所有** `β≤β_phys`、**所有**体积 `L`、**所有**边界条件、**所有**管长 `T` 一致成立；
> 其中 `w(γ)` 是**物理测度**的连通（Ursell）权重（不是 `β` 的多项式）。

**为什么这是"最小"**：`κ>0` 是一个标量；`1/2` 可换成任意 `<1`；`Σ_{γ∋x}` 是逐点（per-plaquette）而不是逐体积
—— **它已经是"局部 activity 界"的最弱形式**。`C_cum` 版（`CPBW-cumulant.md:21–29`）与
`(M1)` 版（`v3/T1-POLYMER-RG.md:299–306`）都是它的推论。

**三个等价代理（仓内已逐字给出同一性，`[T]`）：**
```
  (i)  polymer-weight :  |w(P)| ≤ e^{−κ|P|},  κ ≥ ln λ_a     v3/T1-POLYMER-RG.md:303
  (ii) block-activity :  u_eff(β_phys) ≤ 1/λ_a              v3/T1-POLYMER-RG.md:304
  (iii) Ursell        :  ρ_Ur^eff := λ_a Φ(u_eff) < 1       v3/T1-POLYMER-RG.md:305
```
**打包换算（本轮的用处）：** 语料的 `uK<1`／`ū<1` 是把 `Σ_γ|w|` 换成 `u^{|γ|}·λ_a^{|γ|}` 后的 (i)，于是
`u := β/(2N²)` 与 `K := ĈC̄eΔ` 的乘积必须等于 `eΔβ`（`M07-WINDOW2.md:123` 逐字交叉验证）。
**⇒ `16.99` 与 `165.475` 的差别不是物理，是"谁把 `λ_a` 的幂吸收进 `u`"。**

### §2.2 β-一致的替代：**逐字只有一种**，而且它不是"更弱"

把 `(ACT)` 的 `∀β≤β_phys` 拿掉不行（那就是靶），把它绝对化也不行（两端死，§1.2）。
仓内唯一未被否证的替代 = **把绝对值换成固定边界上的带号和**：

> ```
>   | Σ_{γ: ∂γ=∂γ₀} w_β(γ) |  ≤  e^{−(c₀q+δ)n} · e^{γ_ent n} ,        (ACT-β)
>   且   δ  >  γ_ent − c₀ q          （⟺  κ_c := e^{−δ}  <  e^{γ_ent−c₀q} ≤ 1）
