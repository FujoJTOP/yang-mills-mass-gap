## 2. 五个候选障碍，逐个给判据

每条给三样：**(判据) 可判定的谓词** · **(实测/定理出处)** · **(若判据为真，攻击动作)**。

### O1 无格序

- **判据**：∃ 保测度偏序 `≼` 使 `e^{−S_W}` log-超模（TP₂ / 单交叉），且 `c_r(β)` 同号。
- **出处**：`GPP-STRUCT.md:99–100`（`SU(N)` 无平移不变格序、`e^{−S_W}` 非逐坐标超模）；`Q4-LOGCONVEX.md:33,46`（`β=2.5` 时 `c_r` 交替变号 ⇒ 无正测度/无全序）；`MG-META.md:61,95`（D9/T3：`no lattice order on the quotient`）；`BC-BETHE.md:78–81`（非阿贝尔规范商上无全序）。
- **判据判定**：**假**（0 个可用偏序）。
- **攻击动作**：**不做**。判据不是目标的必需品 —— 见 §3.1。

### O2 Weingarten / 字符系数带号

- **判据**：`c_r(β) ≥ 0 ∀r`（正锥存在）以及混合矩 `E[∏U ∏U†] = Σ_σ Wg(σ)·(收缩)` 的符号混合为空。
- **出处**：`GKS-GAUGE.md:3(c),:15`（**`β=2.5` 时 SU(3) 的 `c_r(β)` 交替变号 = 标准 sign problem**；最小阻挫 SU(2) plaquette 上 `Cov(G,Φ')=0.22β²>0`；全 SU(3) 格点逐模 `X∈[−0.09,+0.16]`）；`Q4-LOGCONVEX.md:33`（`[T]`：`SU(N)` 面权带号）；`LIT-CHECK.md:16,52–54`（现象已发表，综述 Collins–Matsumoto–Novak, *Notices AMS* **69**(5) 734–745 (2022), DOI `10.1090/noti2474`，**摘要级**；"变号 ⇒ 反 FKG 定理"**0 命中**）。
- **判据判定**：**假**（`β=2.5`、`N≥3` 上正锥不存在；`β<β₁≈1/48` 上为真，`GKS-GAUGE.md:9`）。
- **攻击动作**：**换锥，不换测度** —— 见 §3.2。

### O3 `tr` 的二次型不定 / `Re tr(UV)` 非双线性

**必须一分为二，否则会把已证的正部当障碍**：

- **O3a 环面（类角）部**：`Φ = −log|Δ(θ)|² = −2Σ_{α>0} log|sin(α·θ/2)|`，每项 `−log sin` 在 Weyl 房内**凸**。
  - **判据**：`Hess Φ ⪰ (N/12)I`？
  - **出处**：`REPRO-LONG.md:90`（`min λ_min(Hess Φ) = 0.166680` vs `N/12 = 0.166667`）；`TCI-COMPENSATION.md:142`；`NS-NOSUBTRACTION.md:76`（Lemma B）。
  - **判定**：**真，且是恒等式级正部** ⇒ **不是障碍**（`W_geo≥0` 的 Prékopa 正性即此）。
- **O3b 陪集（flag）部 + 面权交叉项**：`Re tr` 沿测地线变号，`Hess S_W` 取负。
  - **判据**：`inf_configs λ_min(Hess V) ≥ 0`？等价：`d²/ds² Re tr(e^{sX}U_p)` 是否变号。
  - **出处**：`R5-AUDIT.md:176`、`CONSTANTS-CHECK.md:91–93`、`MC-METRIC.md:155–156`：**`λ_min(Hess S_W) = −8β/N`**，SU(2) `−10.000`、SU(3) `−6.666667`（`β=2.5`，`L=2` 与 `L=4` 同值，机构 = 跨 link 集体模，不是逐 link 求和）。
  - **判定**：**假** ⇒ **O3b ≡ O5**，合并。

### O4 中心 `Z_N`（离散）vs `U(1)`（连续）

- **判据一（可加性）**：`S_W^{U(N)}` 能否写成 `S_W^{SU(N)} + S_W^{U(1)}`？写 `U_p = e^{iθ_p}V_p`（`V_p∈SU(N)`）得 `Re tr U_p = Re[e^{iθ_p} tr V_p]` ⇒ **双线性耦合，不可加**。⇒ "先做 `U(1)` 部分"作为**直接**分解是**假**的。
- **判据二（Ricci 侧）**：中心方向 `X_e = iθ·1` 上 `Ric = 0` 而 `Hess V = +O(N²β) > 0` ⇒ `U(N)` 上 Bakry–Émery **对任意 `β>0` 恒假**。
  - **出处**：`SZ-CEILING.md:380–392`（**"the centre is not cosmetic — it is load-bearing"**，`U(N)=(SU(N)×U(1))/Z_N`）；`LOOP-RUNBOOK.md:379`（同一句，逐字："`Bakry–Émery` 对任意 `β>0` 在 `U(N)` 上恒假，所以 `SU(N)` 限制不是装饰"）。
- **判据判定**：判据一 **假**（不可加）；判据二 **真**（中心承载预算）—— **但两者都不作用于 SU(N) 本体**：纯 `SU(N)` 的中心 `Z_N` 离散，T 大时只分类退禁闭相（`DF-CONTINUITY.md:32`），在热核卷积/字符展开下不破坏类函数性（`PL-POLCHINSKI.md:224`）。
- **攻击动作**：**有现成文献绕法** → §3.4（判死线 (c)）。

### O5 `Hess V ⪰ 0` 本身（Savvidy 墙）

- **判据（唯一一条）**：`λ_min(Hess V) ≥ 0` 在测度支撑上逐点成立？
- **出处（实测，全部 β=2.5）**：
  - 最坏构型精确：`λ_min(Hess S_W) = −8β/N`（`R5-AUDIT.md:176`；Z₂-cocycle 构型，`L=2`/`L=4` 同值 `−9.999998`，行和 `=6β`，`REPRO-LONG.md:25`）。
  - 测度典型：`P(λ_min(Hess V)<0) = 0.851`，`med λ_min(Hess V) = −0.1796`，中位数过零的 `β_c ≈ 0.76`（`REPRO-LONG.md:92–96`）。
  - 规范商后仍在：`W4` 实测 **7.1% 负模**（`CLAUDE.md §5`；`GPP-STRUCT.md:136`；`AT-STAR.md:294`："规范商后仍然存在，且是强度量"）。
  - `β*=4.30661` 是另一侧（单 plaquette `θ=π` 的 `G''` 变号点，`H1A-EXACT.md:21`），**不要与 β=2.5 混淆**。
- **判据判定**：**假，且是"变号"不是"变小"**。`CTL-CLOSEST.md:222` 逐字："在该方向 `ρ` 不是'变小'，是**变号**。'按定义失效'和'界不够紧'是两件事。"
- **攻击动作**：**这就是靶**（§4）。所有绕法都在这里汇合（§5）。

## 3. 逐个判：本质 / 技术，及每个技术障碍的绕法

### 3.1 O1（无格序）——**技术性，可绕**

**为什么不是本质**：`H1'` 的条件化变量是**标量** `ξ=⟨v,X⟩`，其推前测度住在 `ℝ` 上。**`ℝ` 有全序**，Chebyshev/BL 在 1D 无需任何纤维格序。真正在 `SU(N)` 纤维上需要格序的只有 FKG/GKS 那一族，而那一族**方向就是反的**（`Cov≥0 ⇒ X≤0 ⇒ G''≤W_geo+Δ_dyn`，`GPP-STRUCT.md:100` 原文"WRONG direction"）。⇒ "去掉格序，证明就能通"这一步**不需要**：目标从来不用它。

**绕法**：① 只在 1D 边缘上工作（已在 `GPP-STRUCT.md §1.2` 的定义里做了）；② 若仍需多维关联，用**不需要 FKG 的判据**：Bauerschmidt–Bodineau–Dagallier Thm 3.20 是**通用黎曼流形**判据、零相关不等式（`arXiv:2307.07619`；*Probab. Surveys* **21** (2024) 200–290；`PL-POLCHINSKI.md:58` 判："'FKG 不成立'不是判据层面的死因"）。
**代价**：绕法把障碍推到 §4（BDD 判据的承重步与 `H1'` 是同一堵墙的另一个坐标，`PL-POLCHINSKI.md:394` 逐字"承重步与 `L4/H1` 是同一堵墙的两个坐标 ⇒ 不构成绕过"）。

### 3.2 O2（Weingarten/字符带号）——**技术性（工具层），绕法有 β 门**

**为什么不是本质**：Weingarten 符号出现在**反解**（把乘积的期望展开成收缩和），它不改变测度本身的正性：`e^{−S_W}` 是一个**正的**密度，`ρ_v(a)=∫e^{−V}δ(ξ−a)dX` 是**正测度**。正性在测度上无条件成立；符号只在"选用的函数锥"上出现。⇒ 换锥即可，无需新测度。

**绕法（两条，都可核）**：
1. **字符正锥**：`β<β₁≈1/48` 时 `c_r(β)≥0`，正字符展开 + KP/OS 簇重求和给出 `f₁² ≥ r₀(β)>0`（`GKS-GAUGE.md §2`，即 P3 强耦合残数定理，**无条件**）。**但 β=2.5 上 SU(3) 的 `c_r` 变号 ⇒ 该锥不延伸到物理点**（`GKS-GAUGE.md:15`）。⇒ **这条绕法在本靶上失效**，只证明"符号不是不可克服"，不证明"能过 β=2.5"。
2. **反射正性（RP）**：Osterwalder–Seiler 1978 对**任意紧群、任意 `β≥0`** 成立（*Ann. Phys.* **110** (1978) 440–471, DOI `10.1016/0003-4916(78)90039-8`，**书目级已核**；`GPP-STRUCT.md:101`）。但 `GPP-STRUCT.md:101` 已钉死：**`RP` 是双线性型正定，不是协方差号；`RP≠FKG`；"positivity is blind to the edge"**。⇒ 绕法不产生 `H1'`。

**判**：技术性成立（可换锥），但两条现成绕法**都不落地到 `Var ≤ E[Hess]`**。所以 O2 是"**技术上可绕、绕过去也没到靶**"。

### 3.3 O3 —— **环面半部不是障碍（[T]），陪集半部 = O5（本质）**

**为什么必须一分为二**：`Φ = −log J` 的正部**已证**（`Hess Φ ⪰ (N/12)I`，实测 `0.166680` vs `0.166667`，`REPRO-LONG.md:90`），`W_geo≥0` 由 Prékopa 给（`GPP-STRUCT.md:65`）。所以"`tr` 不定 ⇒ 整个势不定"是**过度悲观**：环面方向上是**严格凸**的。不定性全部住在**陪集/flag 方向 + 面权交叉项**（`λ_min(Hess S_W)=−8β/N`）。⇒ O3 拆开后：**一半是正资产，一半是 O5**。

**结论**：O3 不独立存在。把它并入 O5 后，本质障碍计数**不增加**（这正是 (a) 而非 (b) 的判定依据）。

### 3.4 O4（中心 `Z_N`）——**技术性，绕法已发表**

**为什么不是本质**：中心离散 vs 连续改变的是 **`U(N)` 与 `SU(N)` 的分解方式**，不是 `SU(N)` 本体的 `Hess V` 符号。而本靶全程在 `SU(N)` 上（`SZ-CEILING.md:390–392`："`SU(N)` 限制是被架构**强制**的，不是方便"）。

**绕法（现成文献，判死线 (c) 命中）**：
> **Nissim 2025**, `arXiv:2510.22788`（math.PR 预印本，著录已核，**摘要级**）：把 `U(N)` 重写为**随机环境 `SU(N)`**（随机性来自 `U(1)` 场），`cluster expansion + Langevin` 处理 `U(1)×SU(N)`；原文自陈 `U(N)` 的 Ricci **不一致正**、`Bakry–Émery` 直接失效，故必须拆中心。
> —— 出处：`LIT-CHECK.md:97`、`RATE-UNIFORM.md:275–276`、`SZ-CEILING.md:138–147`、`CTL-CLOSEST.md:61–64`。

**为什么它只是绕开 O4、没有绕开 O5**：Nissim 的统一轴是 **`N`（'t Hooft）**，窗口仍是 `|β|<1/(16(d−1))` 型强耦合（`RATE-UNIFORM.md:276` 逐字："它的统一轴是 `N`，不是 `a`"）。⇒ 中心被商掉，墙没动。

**另一条（部分）**：`abelian projection`（MCG 后的 `U(1)^{N−1}` 单极子）是标准工具，但在纯 YM 上**只给 1-form `√σ`、中性盲**（`T23-TEMPLATE.md:119–122,207`；`IMP-ARROWS.md:155`："Gribov 歧义，无规范不变凝聚"）⇒ 不能当"先做 `U(1)`"用。**用户提的"把 `U(N)` 拆成 `SU(N)×U(1)`，先做 `U(1)`"这条路，被 `Re tr[e^{iθ}V]` 的双线性性 + Gribov 歧义双重挡住；能用的是 Nissim 的随机环境版，不是朴素加性版。**

### 3.5 O5 —— **本质：去掉它证明就通**

**判据（唯一一条）已判假**（§2 O5）。**且它是唯一"去掉就通"的**：

- 若 `Hess V ⪰ λ>0`，则 BL 直接给 `Var(∂_vV|0) ≤ (1/λ)·E[(∂_vV)²]` 型上界，`G''≥0` 即刻（`GPP-STRUCT.md:12,135`）。
- 反之，实测 `λ_min = −8β/N < 0`（精确、`L`-无关、规范商后仍在） ⇒ BL/Ginibre/Lebowitz **前提假**、`Γ₂` **变号**（`CTL-CLOSEST.md:222`）、GKS/FKG **方向反**（`GPP-STRUCT.md:100`）。
- **三条已知绕法全部回到同一点**（`§5` 表）：SZZ 只能 `β<1/48`；BDD 流形判据允许 `λ̇_t<0`，但死在参考测度 + 凸化输入，其 `T3*` 版缺的 `(★)` 与 `H1'` 同坐标（`PL-POLCHINSKI.md:394`）；Nissim 拆中心仍困在 't Hooft。

**⇒ 判死线 (a)：唯一靶 = "一条不需要点点凸性的条件方差上界"**，即 `H1'` 的弱化族（BL 的 `Γ₂`/条件化/log-凹版本），也就是语料反复命名的"第六物种"。

## 4. 唯一靶的精确陈述：三道 β 门，β=2.5 全在门外的同一侧

把所有"正性/凸性/良态"门槛并排放，`β=2.5` 落在**每一条**的同一侧——这就是"非阿贝尔 0 命中"的结构性原因，而不是五条独立的坏运气：

| 门 | 门槛值 | 谁在那里失效 | 出处 |
|---|---|---|---|
| 字符正性 / KP-OS / SZZ 的 LSI+Poincaré | `β < 1/48 = 0.0208`（`d=4, SU(N)`，`N`-无关） | `c_r≥0` 的正锥；LSI；Bakry–Émery | `LIT-CHECK.md:111`；`AUDIT-R1.md:108`；`GKS-GAUGE.md:9` |
| Ricci 补负曲率（`½Ric ≻ (3β/N)δ`） | `β < N²/24`（N=2/3/5 → `0.0625/0.14/0.39`） | BDD/`T3*` 的 `(★)` | `MC-METRIC.md:151`；`LEDGER.md:101` |
| 测度典型的 `λ_min(Hess V)` 过零 | `β_c ≈ 0.76` | `Γ₂`/BL 在典型点上 | `REPRO-LONG.md:96` |
| （对照，另一侧）单 plaquette `G''` 变号 | `β* = 4.30661` | H1 的"全 β"强读法 | `H1A-EXACT.md:21` |
| **物理点** | **`β = 2.5`** | **以上全部** | `CLAUDE.md §5` |

**靶的精确形状（可直接攻击）**：

```
(A)  ∀ 粗模 v，∃ 常数 c(v)>0 与一个"曲率减方差"分解，使
     Var_μ(∂_vV | ξ=0)  ≤  E_μ(∂_v²V | ξ=0) − c(v)，
     且 c(v) 与 (L,a) 一致（这是 H1(δ)，不是 δ=0 的弱读法）。
(B)  该分解的承重项不得是"点态 Hess V ⪰ 0"——因为该项已由 λ_min = −8β/N 精确证伪。
```
