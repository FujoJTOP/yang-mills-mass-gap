## 1. 首判（决定子空间法生死）：`S−D` 是不是 `v` 的二次型？

### 1.0 对象核准

Schur 项**精确相消**：`S = E[h_n − ⟨K⁻¹c,c⟩|0]`、`D = Var(f|0) − E⟨K⁻¹c,c⟩|0`（`H2-DEFECT-BOUND.md:66`）⇒

```
G″(0;v) = S − D = E_μ[V″|0] − Var_μ(V′|0) ,   V = S_W + Φ ,  μ = 条件化测度(⟨v,X⟩=0) .     (1.1)
```

与 `docs/PROOF-SKELETON.md:71` 的 `G″=E[V″|0]−Var(V′|0)`、`O24` 的 `Δ=E[κ|0]−Var(F|0)`（`R04:95`）逐字同一个量。`Π₀`、`K`、`c` 全部**退出**——它们只在中间步骤出现。

### 1.1 沿射线精确二次齐次 `[T]`

`t≠0` 时 `⟨tv,X⟩=0 ⟺ ⟨v,X⟩=0`（**同一个**超平面）⇒ `μ_{tv}=μ_v`；且 `V″(tv)=t²V″(v)`、`V′(tv)=tV′(v)` ⇒

```
G″(0;tv) = t² G″(0;v)     ∀ t ≠ 0 .        (1.2)
```

**推论（有用）**：`G″` 的零集是**锥**；`sign G″` 是**射影**性质，与 `‖v‖` 无关。`O24` 取 `v_{l,3}=1/8`、`‖v‖²=1`（`R04:46`）不是标定，只是选点。

### 1.2 但它**不是**二次型 `[T]`

固定 `v` 时 `G″ = vᵀA(v)v`，`A(v) := E_{μ_v}[Hess V] − Cov_{μ_v}(∇V)`（对称）。**`A` 依赖方向**：`μ_v` 是 `{⟨v,X⟩=0}` 上的截面，`v` 一转截面就转，`A(v)` 随之变。⇒ 没有与 `v` 无关的对称 `A`，**极化恒等式不成立**（`G″(v+w)` 不能由 `G″(v),G″(w)` 与某个双线性型拼出）。

**方向依赖本身是"非高斯性"的度量 `[T]`**：自由场（`V=½κ|X|²`，Gauss）在正交变换下不变 ⇒ `μ_v` 的转动**看不见**，`A(v)≡κI` 与方向无关。⇒ **`A(v)` 的方向依赖只由非阿贝尔 Haar/`Φ` 产生**。这一条后面会变成对子空间法的酸测否证（§2.3）。

### 1.3 连"半正定二次型"都不是 `[T]`

单 plaquette 精确 `G″ = 0.20511530 − 0.01105929 β²`（`SAV-CANCEL.md:289`）：`β*=4.30661` 之后**变负**；`β=2.5, θ=π` 给 `S=0.20512, D=0.06912, G″=+0.13599`（`:263`）。另一方向 `0.3623`（`SM4-CONSTANT-MODE.md:298`，TRANS）。再加上 `L=8` 实测 `5/12` 模 `G″<0`（`H2-DEFECT-BOUND.md:41`）。⇒ **不存在对称 `A⪰0`**，也就没有"特征值下界"这条路。

> **首判结论**：`S−D` 是**方向依赖的二次齐次泛函**，不是二次型，也不是半正定的。**子空间法的前提不成立。**

## 2. 路线 2（限制到子空间）：**不成立**——三条独立死因，任一条足够

### 2.1 方向反了 `[T]`

设真有二次型 `Q=vᵀAv`（`A` 对称、方向无关）。对子空间 `W`：`min_{v∈W} Q ≥ min_{v∈全空间} Q`。⇒ **子空间算出的是整体 `inf` 的`上`界**。要拿整体`下`界必须 `A|_{W^⊥} ⪰ 0`（或精确分块对角），而"把不定补空间控住"**就是 H1**（Savvidy 负模住在补空间：`SAV-CANCEL.md:108`、`G4-GENERAL-BOUND.md:243`）。⇒ 子空间法不省账，只是把账搬到补空间。

### 2.2 打错变量 `[T]`

`L=2` 的墙是**143 维纤维积分**（`R04:15`：`192−48−1=143`），不是方向 `v` 的选取。限制 `v` 到子空间**一维不降**（仍 143）。而且目标 `G″(0;v)` 在 `v` 固定时是**一个数**（`O24` 模 A），不是 `v` 上的 `inf`/`sup` ⇒ 无语义去谈"子空间上的下界 = 整体的下界"。

### 2.3 酸测否证（对子空间法最硬的一击）`[T]`

若某子空间界只用到"二次型/可对角化/特征值"这类结构，则**自由无质量场满足同一前提**；而有限 `L` 的自由场本来就有 `G″=2`（`L=4`）、`1`（`L=6`）（`A5-RIGOROUS-NUMERICS.md:3`）⇒ 该界在自由场上也成立 ⇒ **不是 YM-vs-free 判别器 ⇒ 不过宪章酸测（`CLAUDE.md §1`）**。**二分**：子空间界要么 vacuous，要么显式用非阿贝尔不定 Hessian = H1。

### 2.4 附：唯一合法的"子空间"用法是**降方差**，不是界

若"子空间"指限制**纤维**（均匀场 / `G`-不变 3 维子空间，`R04:71–73`）：换掉积分域得到的是**另一个量**，要成为界必须有一条正相关/条件化**不等式**——`Var` 的条件化恒等式只给恒等，不给方向。唯一合法的用法是 **Rao–Blackwell**（期望不变、方差降），见 §6.3 第 4 步。

另注：`H1D-PERIODIC.md:79` 给出 `P4` 周期核上"均匀场/常数模"在 `β=2.5, L=2` 的 `G″=0.20230`——那是 **1D 链（转移矩阵）模型**（该文件 `:9` 起），**不是** 4D `L=2`。拿它当 4D `L=2` 的子空间下界是**类别混淆** `[NG]`。

## 3. 路线 1（`1/L` 展开）：**(a) 不成立**

### 3.1 阶是什么：已算锚里**没有 `c/L`**

| 锚 | 阶 | 出处 |
|---|---|---|
| 自由 `U(1)` 周期链 | `Var≍L`, `G″≍1/L²` | `P5-PERIODIC-DECISION.md:35–37` |
| `D3` 精确 Cartan 转移矩阵 `L=2..10` | `G″=0.2688+A/L²`（`A>0`） | `D3-TRANSFER-CONSTANT.md:235` |
| `P2/P4` `β=2.5` `L=4..8` | `c+Aq^L`，`q=0.849`，`rms=3.3×10⁻⁶`（指数逼近） | `P-WAVE-SYNTHESIS.md:20` |

⇒ 题目设的 `G″(L)=G″(∞)+c/L` **在三个可算锚里一个都不出现**。更狠一层：指数形 `Aq^L` 的 `q=e^{−m}` **已经预设了转移矩阵有隙**（`P5:47–53` 的 `[C-B·periodic]`：`Δ=0.6444` 是 1D 的 `[T]`，4D 的 `Δ>0` 就是 H1）⇒ **用它给修正项定阶 = 假定隙**。

### 3.2 方向死：`c/L` 的锚必须在 `L=∞`

`1/L` 展开是 `L→∞` 的 Laurent 级数，锚点是 `G″(∞)` = 4D 无穷体积的值 = **目标本身**。用 ∞ 推 2 是循环。

### 3.3 `L=1→2` 的真实参数不是 `1/L`，是 `u`，而 `u>1`

语料的 `L=1` `[T]` 是**单 plaquette 模型**（固定边界 holonomy、条件化在 `ξ₃=0`），不是 4D 格点在 `L=1` 的极限（`L=1` 时 4D 环面退化到 1 个位点，不是同一族）。从单 plaquette 走到 `L=2` 要加 95 个 plaquette、63 条 link：这是**强耦合/聚合物**展开，参数 `u(2.5)=1.0143902001>1`，`β_c^{KP}≤1.182227`（超 **35.5×**），Ursell 和 `u/(1−u)=−70.49` 无定义（`UC-COMPLETE.md:49`、`BN-RESIDUAL.md:286`、`T1-POLYMER-RG.md:394`）⇒ **死**。

### 3.4 `L=2` 是所有求解器**最差**的一点

`H1D-PERIODIC.md:84`：`L≥3` 与语料差 `≤5×10⁻⁵`，**`L=2` 差 `−0.0054`**（核最宽、离散化误差最大）；`P5:44`：`P5` 的 `L=2` `G″=895` 是**纯 stencil artefact**，已被撤回。⇒ 把任何 Laurent 级数在 `L=2` 求值 = 在最不可信的端点上外推。

> **若硬写展开**（诚实版）：`G″(L) = G″(∞) + A/L² + O(e^{−mL})`，`A, m` 未定，`G″(∞)` 未知，余项不可控 ⇒ **不是 `[T]`，连 `[C]` 都给不出数值**。**判死线 (a) 不触发。**

(i)  G″ = G″_Haar + G″_Wilson                （D4，对常模边缘精确 [T]；Haar 部分 L 重卷积、极限 0.26883）

## 6. (c) 最少样本的严格方案 —— 并修一条统计地基 `[T]`

### 6.1 现有 `3e8` 的算术（复核，与 `R04:93–105` 一致）

`κ ≤ 2/δ²`、`P(δ<δ*) ≤ 64cδ*³`（机检斜率 `2.99999927`）⇒ `K=2/δ*²`，`δ*=3e−2 ⇒ K=2222`；
`ε=0.3` ⇒ `N ≈ (K/ε)²·ln(2/δ_p)/2 ≈ 3×10⁸`；`10 ms/sweep` ⇒ **≈35 天**（单核）。`[T]`算术 + `[C]`参数。

### 6.2 **新 `[T]`：`E[κ²]=∞` ⇒ `o24` 的 `6σ` 的 `σ` 不存在**

由 `κ ≤ 2/δ²` 与壳层体积 `∝δ³`：

```
E[κ²] ≤ 4·E[δ⁻⁴] = 4C∫₀^{δ*} δ⁻⁴·δ³ dδ = 4C∫₀^{δ*} dδ/δ = ∞   （对数发散）  ⇒  Var(κ)=∞ .
```

与 `O24` 实测尾指数 **`α≈1.97 ≤ 2`**（`R04:109`）**逐字一致**。⇒ **这是硬的**：`Δ=+0.3942±0.0258` 里的 `σ` 不是有限方差意义上的标准差；`α≤2` 时样本方差**不收敛**，任何基于它的 `kσ` 区间**不是渐近有效区间**。6σ 不仅"不是证书"，连"统计区间"的身份都要撤回——它只是"多点口径同号"的定性证据（`R04:109–110` 的三版本同号仍成立）。
（条件：壳层律的常数 `c>0`，即奇异集非退化——已机检斜率。）

### 6.3 严格方案（按序执行，别跳步）

1. **改写成精确恒等式**：用 Riccati `Δ = −d²/da² log ρ_v(a)|_{a=0}`（`[T]`），只估 `ρ_v` 的对数曲率，避免估 `Var(F)` 这个重尾量。
2. **有界截断**：`K=2/δ*²`，偏差 `≤ 2cδ*`（显式，非估计）；取 `δ*` 使偏差 `≤0.03`（`Δ/2` 的一半量级）。
3. **有界 Hoeffding**：`N = (K/ε)²·ln(2/δ_p)/2`，`ε=0.15`（要 `Δ/2`）⇒ `N≈1.2×10⁹`；若只判符号，`ε=0.3` ⇒ `3×10⁸`。**这是"最少样本"的答案：`3×10⁸`，且不可用 CLT 缩水。**
4. **唯一允许的常数级优化**：对 `a=⟨v,X⟩` 做**精确 64 重卷积**（Haar 部分闭式，同 `D1`/`D4` 手法），只对 `e^{−S_W}` 做 MC ⇒ Rao–Blackwell 降方差。它降**常数**、不降 `K=2222`，所以**不改变 `3e8` 的阶**。`[C]`
5. **算力**：`3e8 × 10 ms ≈ 35 天`单核；8 条独立链 + 逐链 Hoeffding + Bonferroni ⇒ `≈4.4 天`（内存纪律：一次一个重作业，`CLAUDE.md §4`）。
6. **别做**：把 `o24` 的 `σ` 当证书（§6.2）；用 `P5` 的 `L=2` `895`（artefact）；拿单 plaquette 的 `[T]` 当 `L=2` 的锚（§3.3 类别不同）。
