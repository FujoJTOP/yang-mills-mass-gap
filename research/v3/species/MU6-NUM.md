# MU6-NUM — `σ = 2g²N·Λ_MS²` 的量级核（数值判）

> 2026-11-25 · 目的：给 `σ = 2g²N Λ²`（`[C]`，5:1 判 `ε=1/Λ`）做**量纲闭合 + 量级**核查。
> 纪律：每个数给出处；两圈跑动写公式；标签 `[E]`=文献抽取、`[C]`=本文件算出、`[T]`=判定。
> 全部输入取自 `research/v3/species/L2-GLUEBALL-LAMBDA.md` 已核的 **AT2021 = arXiv:2106.00364v3**（JHEP 12 (2021) 082）。脚本 `research/unconditional/w7/mu6_scale.py`，日志 `mu6_scale.log`。

## 0 · 判死线（先说结论）

**`(a)` 触发。** 实测 `σ/Λ_MS² = 3.399`（SU(3)，`[C]`）落在 `[1,10]` 内；公式值 `2g²N = 6`（`β=6`，`g²=6/β=1`），比值 **`0.567`** ∈ O(1)。⇒ **`σ = 2g²N Λ²` 与数据相容**（差一个 `O(1)` 系数 `κ ≈ 0.36–0.74`），`[C]` **稳固**。

- `(b)` **不触发**：没有 `>10×` 的缺因子。最大偏离是 `1/0.363 = 2.75×`（用 `g²(Λ_MS)` 跑动值），属处方自由度允许的 `O(1)`。
- `(c)` **不触发（但有一句必须写的限制）**：`σ/Λ²` 是 `β`-无关常数，而 `g²=6/β` 随 `β` 跑（`2g²N` 从 `6.32@β=5.69` 到 `5.37@β=6.70`，仅 17%）。`g²` 取格点标度 ⇒ 6，取 `Λ_MS` ⇒ 9.36，两者差 `1.56×`——**公式自身带一个 `O(2)` 的标度歧义**（就是 `κ` 的槽位），但不是 `β`-依赖冲突，故不给 `[NG]`。

**额外数值判（§5）**：`σa²` 对 `x ≡ e^{−1/(2b₀g²)}` 的局域指数实测 **`n = 2.63`（SU(3)）/ `2.31`（SU(2)）**，而不是 `0`。`n=0` 才是"`σ ∝ 1/a²`（`σa²`=常数）"的签名；`n=2` 是"`σ ∝ Λ²`"的签名。⇒ **数据站在 `σ ∝ Λ²` 一边**，`1/a²` 被 `7.7×`（SU(3)）的跑动排除。这是广播里那条检验的直接数值答案。

## 3 · 公式值 `2g²N`（`[C]`）

**(i) `β=6` 的格点耦合**：`β = 2N/g²` ⇒ `SU(3)`：`g² = 6/β = 1.000` ⇒ **`2g²N = 6.000`**。

**(ii) 两圈跑到 `Λ_MS`**（从 `μ₀ = a⁻¹ = 2.91 GeV`，`g²(μ₀)=1`）：

```
dg²/dlnμ² = −b₀ g⁴ − b₁ g⁶
精确解： ln(μ²/μ₀²) = (1/b₀)[ (1/g²(μ) − 1/g²(μ₀)) − (b₁/b₀)·ln( (b₀/g²(μ)+b₁) / (b₀/g²(μ₀)+b₁) ) ]
```
解出 `g²(Λ_MS) = 1.5605`（`N=3`，`t = 2ln(0.26304/2.91) = −4.807`）⇒ **`2g²N = 9.363`**。
（`N=2`：`g²(Λ_MS) = 1.2929` ⇒ `2g²N = 5.172`。）

## 5 · `σa²` vs `e^{−1/(2b₀g²)}`：常数还是跑动？（`[E]`数据 + `[C]`计算）

`a√σ` 逐 `β` 实测值直接抄自 **AT2021 Table 13（SU(3)，`β=6/g²`，10 个 `β`）** 与 **Table 12（SU(2)，`β=4/g²`，6 个 `β`）** 的末列。`x(β) ≡ e^{−1/(2b₀g²)}`，`g²=2N/β`。

| `β`(SU3) | `a√σ` | `σa²` | `x` | `R=σa²/x` |
|---|---|---|---|---|
| 5.6924 | 0.40100 | 0.16080 | 1.103e−3 | 145.8 |
| 5.9900 | 0.21959 | 0.04822 | 7.725e−4 | 62.4 |
| 6.2350 | 0.14899 | 0.02220 | 5.762e−4 | 38.5 |
| 6.5000 | 0.10319 | 0.01065 | 4.197e−4 | 25.4 |
| 6.7000 | 0.07898 | 0.00624 | 3.304e−4 | 18.9 |

- `σa²` 落 `25.8×`，`x` 只落 `3.34×` ⇒ **`R` 跑动 `7.7×`，不是常数**。
- 局域指数（最小二乘 `ln σa²` vs `ln x`）：**`n = 2.630`（SU(3)）**、**`2.306`（SU(2)）**；`R` 跑 `7.7×`/`2.8×`。
- **判读**：`n=0` ⇔ `σa²`=常数 ⇔ `σ ∝ 1/a²`（用错幂次的 `1/a`）；`n=2` ⇔ `σ ∝ Λ²`（因为 `aΛ ∝ x`，故 `σa²=(aΛ)² ∝ x²`）；`n=1` ⇔ `σ ∝ Λ`（量纲错）。实测 `n = 2.6/2.3`，**贴 `n=2`（偏高 15–30%，即 `(1+c_σa²σ)` 与三圈项的量级）**，`n=0` 被 `7.7×` 排除 ⇒ **`σ` 跟 `Λ²` 走，不跟 `1/a²` 走**。`SU(3)`/`SU(2)` 两个群给同一个 `n≈2.3–2.6`，`N`-无关。
- 附带：`g²=1` 时 `x = 7.63e−4`，`R(β=6) = 61.2`。这个 `R` 的大数值只说明"`e^{−1/(2b₀g²)}` 不是 `aΛ` 的完整表达式（缺 `(b₀g²)^{−b₁/2b₀²}` 与格点修正）"，**不影响指数判读**（指数只依赖对数斜率）。

## 6 · 顺带查出的一个口径问题（`[T]`，须回报）

`a⁻¹(β=6)`：AT2021 **Table 13** 的 `a√σ(5.99)=0.21959`、`a√σ(6.0625)=0.19509` 内插 ⇒ `a√σ(6.00)=0.21621` ⇒ **`a⁻¹ = 0.48496/0.21621 = 2.243 GeV`**。
任务给的锚 `a⁻¹ ≈ 2.91 GeV` 比它高 **`1.297×`**（等价 `σa² = 0.0467` vs `0.0278`，差 `1.68×`）。本文件两个都算（§4 用 2.91，§5 用 Table 13 实测），**结论对两者不变**（都是 `O(1)`，指数判读不依赖 `a⁻¹` 绝对值）。`2.91 GeV` 的来源应是别的 `β`/作用量口径，建议后续核 `A2-A-SCALING.md` 的 `a⁻¹(β)` 表。
