## §1 T1 · 把 `(★)` 写成可算的量

### §1.1 标量化（恒等，一步）

`C_t = tg^{-1}` ⇒ `Ċ_t = g^{-1}`，`Ċ̈_t = 0`。取 `g`-正交标架（`g = 1`），矩阵 `Ċ = 1`，故
```
(★):   Ċ Hess V_t Ċ − ½Ċ̈_t  ⪰  λ̇_t Ċ
   ⟺   1·Hess V_t·1 − 0      ⪰  λ̇_t·1
   ⟺   for every g-unit v, for every φ:   ⟨v, Hess_g V_t(φ) v⟩_g  ≥  λ̇_t
   ⟺   λ̇_t  ⪯  m(t) := inf_{φ∈X} λ_min( g^{-1} Hess_g V_t(φ) ).
```
**`m(t)` 是一个数**（不再有场、不再有方向）。`(★)` 的全部内容 = 这个标量函数。

### §1.2 `λ̇_t` 的量纲

- `⟨v,Hess V_t v⟩_g`：`v` 是 `g`-单位、`V_t` 是作用量（无量纲）⇒ **无量纲**。故 `λ̇_t` 无量纲 = **每单位流时的曲率（curvature flux）**，`λ_t` 无量纲，`∫₀^∞e^{−2λ_t}dt` 的量纲是 `[t]`。
- `t` 是热时间，`C_t = tg^{-1}` ⇒ `[t] = [g^{-1}] = (长度)²`（在物理度量 `g_phys = a²g` 下）。故 `1/γ` 的量纲是 `a²` ⇒ **`γ ∝ 1/a²` 是物理质量²**。这与平坦自由场的 `γ = λ_min(A) = m²` 完全一致（`PL-POLCHINSKI` §6.3）。
- 这条量纲账**关掉了"用 `t` 重标度买正性"**：`λ̇` 在 `t→ct` 下不变（`Remark 3.8` 的重参数化不变性在这里就这一句话），能改的只有 `m` 本身。

### §1.3 `Hess V_t` 与 `Hess S_W` 的关系 —— 恒等式 (G)（本节的引擎）

**[T-here] 群上协方差恒等式（P12 的流形版）**。对任意 `t>0`、任意 `φ∈X`，在 `φ` 处的左不变正交标架里逐分量成立：
> **(G)**  `Hess_g V_t(φ)  =  E_{μ_t^φ}[ Hess_g S_W ]  −  Cov_{μ_t^φ}( ∇_g S_W , ∇_g S_W )`,
> 其中 `μ_t^φ` 是 `ζ` 上的概率测度，密度 `∝ e^{−S_W(φζ)} K_t(ζ) dHaar(ζ)`（"涨落测度"）。

**两行证明**：`Z_t(φ) = ∫f(φζ)K_t(ζ)dζ`，`V_t = −log Z_t`。
`∂_vZ_t = −Z_t·E_{μ}[⟨∇S_W,v⟩]`（把 `∂_v` 移进积分，`v` 是左不变方向）；
再求一次导：`∂_wE_{μ}[g] = E_μ[∂_wg] − Cov_μ(g,⟨∇S_W,w⟩)`，取 `g = ⟨∇S_W,v⟩`、`∂_wg = ⟨Hess S_W v,w⟩`，即得 (G)。∎

**数值验证**（`at_su2_exact.py` Part C，单 link、`S(U)=β(1−½Re tr(UM))`、`M` 固定，GL 100×60×64 求积 + `h=10⁻³` 有限差分）：

|---|---|---|---|
| `identity`（类函数） | `2.6e−8` | `4.8e−8` | `5.4e−8` |
| `generic`（非类函数） | `1.8e−8` | `1.3e−8` | `1.2e−8` |

（表值是 `max|Hess V_t − RHS| / max|RHS|`。）**⇒ (G) 是恒等式，精度到有限差分。**

**与平坦版的差别（这是 `T3*` 的关键结构事实）**：平坦恒等式是 `Hess V_t = C_t^{-1} − C_t^{-1}Cov C_t^{-1}`，正项 `C_t^{-1}` 来自**高斯参考测度**的 Hessian。群上的参考测度是 **Haar**，其"协方差"是 `∞`、"逆协方差"是 **0**。所以 (G) 里**没有 `C_t^{-1}` 这一项**：

### §1.4 heat-kernel 如何平滑它 —— 显式公式（低通滤波，负部指数衰减）

`Z_t = P_t f`，`f = e^{−S_W}`。取 `−Δ_g` 的谱 `{λ_k}`、正交基 `{ψ_k}`（`λ_0=0`、`ψ_0=1`），`f_k := ⟨f,ψ_k⟩_{Haar}`、`f_0 = ∫f dHaar = Z_∞`。则**严格**
> `Z_t(φ) = f_0 + Σ_{k≥1} e^{−λ_k t/2} f_k ψ_k(φ)`，**`V_t = −log Z_t`**，
> **`Hess V_t = − (1/Z_t)·Σ_{k≥1}e^{−λ_k t/2}f_k Hess ψ_k + (∇Z_t/Z_t)⊗(∇Z_t/Z_t)`。**

读法三条：
1. **平滑 = 逐模乘 `e^{−λ_kt/2}`**，即**低通滤波**：`k` 越大杀得越快。
2. **Savvidy 负模是短波模**（高 `k`，`λ_k ≫ λ_1`）⇒ 它被杀得**比 `Λ` 快得多**。§3 实测：one-link 模型的负部衰减速率 `0.405`，理论下界 `Λ = λ_1/2 = 0.375`（比值 1.08，实测偏**快**，符合"负部住高 `k`"）。
3. **两个必须承认的坏处**：(i) 分子里的 `f_k` 与分母 `Z_t` 都带体积，`Z_t` 的 `C²` 界里的系数含**模计数** `#{k: λ_k ≲ 1/t}` ⇒ **`‖Hess V_t‖ ⪯ C(L,β)e^{−Λt}` 的 `C` 随 `|E|` 增长**（§4 的 `log|E|`）；(ii) 指数因子 `e^{−λ_kt/2}` 里 `λ_1` **与 `|E|` 无关**（积流形），所以**速率**是一致的、只有**系数**不一致。这一点在 §2 决定一切。

**一个好界（可直接用）**：
> **[T-here] 平滑界** `‖(Hess_g V_t)_−‖_g ⪯ C₁(β,N)·e^{−Λt}`，`Λ = (N²−1)/(4N)`，

## §2 T2（核心）· `λ_t` 的三点可行性：纯 ODE 不等式，可以完全算清

### §2.1 定理 AT-0（literal 形式的 no-go）—— **[T-here]，无条件**

```
m(t)  ⪯  sup_φ ‖Hess_g V_t(φ)‖_g  ⪯  C e^{−Λ t}          (Λ = λ_1/2 > 0)
⇒  M(∞) := ∫_0^∞ m(t) dt  ≤  C/Λ  <  ∞ .
```

```
                  λ_t  ↛  +∞        and        ∫_0^∞ e^{−2λ_t}dt  =  ∞ .
```

**⇒ `(★)`（`C_t = tg^{-1}`，`Ċ̈_t = 0`，即 `Hess V_t ⪰ λ̇_tg`）无解。**

### §2.3 三点条件的**精确**判据（一个标量）

> **定理 T2（sharp）**。设 `m:(0,∞)→ℝ` 局部可积，`M(t) = ∫₀^t m`。则
> `{λ̇ : λ̇ ⪯ m,  λ_t→+∞,  ∫₀^∞e^{−2λ_t}<∞}` 非空 **⟺** `I(M) := ∫₀^∞ e^{−2M(t)}dt < ∞`。
> 且此时**最优解是 `λ_t = M(t)`**（逐点最大），`γ_max = 1/I(M)`。
>
> *证*：`λ̇ ⪯ m ⇒ λ_t ⪯ M(t)`（逐点）。⇐ 取 `λ = M`；⇒ 若 `I = ∞`，任何可行 `λ` 满足 `e^{−2λ} ≥ e^{−2M}` ⇒ `∫e^{−2λ} ≥ I = ∞`，矛盾。∎

**这一条把 T2 的三点条件**（`(★)` / `λ→∞` / `∫<∞`）**压成一个标量条件**。可行域是 `(t,λ)` 平面的**下包络**（hypograph）：`{(t,λ) : λ(t) ⪯ M(t)}`，上包络就是 `M`。`γ_max` 是上包络的"面积"的倒数。

**⇒ 对"`λ_t` 可以自由增大吗"的回答：不可以，符号反了。**
`(★)` 给的是**天花板**。我们能做的是把 `λ̇` **调低**（`λ̇ < m`），永远不能调高。所以可行集在 `λ` 方向上是**向下封闭**的：

## §7 · 未闭合清单与下一步（按"最便宜的杀"排序）

1. **[O-AT]（承重）**：`Q(∞) = ∫₀^∞‖(Hess V_t)_−‖dt` 的 `L`-一致性。**这一条等价于 `sup_L Q(∞) < ∞`。** 两个可行的攻击面：
   (a) **不靠 `Z_t` 的分母**：用 `q(t) ⪯ ‖Var_{μ_t^φ}(∇S_W) − Var_{μ_β}(∇S_W)‖ + ‖E_t[Hess S_W] − E_β[Hess S_W]‖`，把 `t`-衰减**直接绑到 `μ_t^φ` 与 `μ_β` 的 TV 距离**（后者是 `K_t` 的一阶展开，`ψ_1` 型单 link 模，**天然体积一致**）。这是本轮**没有做完**但最有希望的一步：它把 `Q(∞)` 从"`1/Z_t` 的病态"变成"`E_{μ_β}[ψ_1]` 的界"。
   (b) 用**中心对称**：`E_{μ_β}[tr U_ℓ] = 0`（`ℤ_2`）⟹ 领头模 `j=1/2` 的系数**恰好为零**，有效衰减从 `Λ` 提升到 `λ_{j=1}/2 = 1`（SU(2)）。**这会把 `Q` 直接砍掉 2.7 倍**，并且是**可证的**（中心对称在 `β>β_c` 上未破缺——但**这本身是未证的**，故只是一个**条件**改进）。
2. **`(3.99)` 在紧群上**：`K_t→Haar ⇒ V_t→const ⇒ ν_t→Haar^E`，纯技术活，`[O]`。**没有它，Thm 3.20 用不了。**
3. **`L=6,8` 的 `λ_min(Hess S_W)/β`**，判 §3.3 的轻微上升是否饱和。**一次一个作业，内存上限：`L=8` 的 Hessian 是 `3·4·4096 = 49152` 维，必须用 matrix-free + Lanczos，不能装 dense。**
4. **`(★)`-manifold 的 `γ` 数值**：本轮只给到 `e^{−2Q(∞)}` 的量级（单 link `Q=2.12` ⇒ `γ ≳ 7e−3`）。格点上 `Q` 会是 `|E|` 量级 ⇒ `γ` 指数小。**这条路线在数值上没有希望；它的价值是"给出一个真定理的形状"，不是"给出一个可用的常数"。**
5. **不要做的事**：不要再在 `C_t = tg^{-1}` 下试 `(★)`。定理 AT-0 已经把这条路封死（`Ċ̈≡0` + 无 `C_t^{-1}` ⇒ 无源）。

## 附 · 一句话

> **`(★)` 照字面（`C_t = tg^{-1}`，`Ċ̈≡0`）是一个可以一行反驳的假命题：热核平滑让 `Hess V_t` 的负部**指数衰减**（实测速率 `0.405 ≈ Λ=λ_1/2`，不是"趋到 `−cβ`"），于是 `‖Hess V_t‖ ⪯ Ce^{−Λt}` 可积，于是 `(★)` 给 `λ̇_t` 的天花板 `m(t)` 可积，于是 `λ_t ⪯ M(∞) < ∞`，于是**永远长不到 `+∞`**——连自由场 `S_W≡0`（`m≡0`）都过不了这一关，而 Haar 明明有隙 `γ=λ_1`。真正的判据是 manifold 形式 (3.100)，它的**正源是 `½Ric_g = (N/8)g`**（不是 `Hess V_t ⪰ 0`，Savvidy 与此无关），在这一形式下 `λ̇_t = N/8 − ‖(Hess V_t)_−‖` 可行、`γ ≥ (N/4)e^{−2Q(∞)} > 0`，**对每个 `β` 都成立**——这是一个真定理；但 `Q(∞)` 随 `L` 发散，故 `(L,a)`-一致性缺失，而它一旦补上就**直接给出质量隙**（⇒ 需新数学）。顺手抓到两条勘误：`w7_pl_hess.py` 的 Hessian 未对称化，负部高估 1.54–1.64×（`−(4.8/N)β → −(2.9/N)β`，几何占比 `9.7% → 15.7%`）；以及 `PL-POLCHINSKI` §6.3 的自由场酸测在 `C_t=tg^{-1}` 下**不通过**。
