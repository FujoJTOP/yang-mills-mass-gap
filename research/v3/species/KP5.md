## 2 · `2¹²` 的来源（第二问）

### 2.1 定义层：`2¹² = 2^{E₂}`，`E₂=12`

`C06-WINDOW.md:61–69` 逐字：

```
4F = E₁ + 2E₂ + 4E₄ + 6E₆ ,     ∂γ=∅ ⇒ E₂ = 2F − 2E₄ − 3E₆ ≤ 2F        (2.1)  [T]
4D 立方体 6 面（(2,2,2,1) 盒的全部 6 片）：F=6，κ 直方图 {2:12}
  E₂/F = 12/6 = 2.000000 ，∏R = 2¹² = 4096 ，几何均值 4096^{1/6} = 4.000000        (2.2)  [E]
```

`R(2)=2`（`C06:78` 逐字「`R(2)=2`（精确）」）⇒ 每条 `κ=2` 的 link 贡献一个因子 `2`，12 条 ⇒ `∏_ℓR(ℓ) = 2^{12} = 4096`。

**⇒ 底数 `2` 的来处 = `R(2)`，不是 `dim f`、不是 `N = 2`。** `[T]`（`E₂=12` 由 `(2.1)` 在该簇上 `E₄=E₆=0,E₁=0` 解出：`4·6 = 0 + 2·12`）。

### 2.2 它与 `Ĉ⁶` 的关系：**数值恒等，定义不同**

```
(∏R)^{1/F} = (2¹²)^{1/6} = 2² = 4 = Ĉ            ⇒  2¹² = Ĉ^F = 4⁶ = 4096
4⁶ = 4096 ✔（本轮复算）
```

* `4⁶ = 4096` 成立，**因为** `E₂/F = 2` 在此簇**取等**（`C06:65`：`max E₂/F = 1.7778 < 2`，唯全闭全 `κ=2` 才取等）。
* 一般簇上 `∏R = 2^{E₂}(5/2)^{E₄} ≤ 4^F`（`C06:75`），**只是界，不是等号**。

⇒ 所以：「`2¹²` 是 `Ĉ⁶` 的另一种写法」**作为数值等式对**，**作为定义错**：`2¹²` 是 link 计数的乘积，`Ĉ⁶` 是先取六次根再六次方。这个区别是实的 —— 换个簇（`E₂/F=1.7778`）两者就差开。

### 2.3 `64` 是什么（不是 `Ĉ`、不是幂）

`64 = 2⁶ = |φ^U(K_{2,2,2})|`，立方体簇的真实 Ursell 系数，**精确整数 `−64`**（`UR3:78`，两条独立整数路径；定义 `φ^U(Γ)=Σ_{A⊆E,(Γ,A)连通}(−1)^{|A|} ∈ ℤ`，`C01:13`）。`[T]`+`[E]`
⇒ `2¹²·2⁶ = 2¹⁸`，`(2¹⁸)^{1/6} = 2³ = 8`：**八来自 `2^{3}`，指数 `18/6 = 3` 是 `(E₂ + log₂|φ^U|)/F = (12+6)/6`**。

## 3 · `K̂` 与 `Ĉ·C̄` 的关系（第三问）

```

                            =  Ĉ · Λ_Ur
立方体上：Ĉ · |φ^U|^{1/6} = 4 · 2 = 8 = (2¹²·64)^{1/6}          ⇒ 取等
```

**⇒ `K̂` 与 `ĈC̄`：同一槽、不同量，`K̂ ≤ ĈC̄`。** 数量级对照（`N=2`）：

## 4 · `K̂ = 8` 对吗（第四问 + 判死线）

### 4.1 8 属哪个量：`τ` vs `|φ^U|` 的口径

`(5.1)` 里 `K̂` 带的是 `τ_γ`（树界）。`ur3` 写的 `(2¹²·64)^{1/6}` 里是 `64 = |φ^U|`（真值）。**这两者不是同一个 `K̂`**：

| 版本 | 立方体上的值 | 性质 |
|---|---|---|
| `K̂_τ := sup(∏R·τ)^{1/\|γ\|}`（`(5.1)` 逐字） | `(4096·384)^{1/6} = 10.7840492368` | 上界（`τ ≥ \|φ^U\|` ⇒ `K̂_τ ≥ K̂^Ur`） |
| `K̂^Ur := sup(∏R·\|φ^U\|)^{1/\|γ\|}`（`C06:187` 活路 A） | `(4096·64)^{1/6} = 2³ = 8` | **下界**（见证值 ⇒ `sup ≥ 8`） |

**⇒ `8` 不是 `K̂`（逐字）的值；它是 `K̂^Ur` 的见证下界。** `ur3` 的算式**逐字精确**（`2¹²·64 = 2¹⁸`，六次根 `2³`），但**归名**应改成 `K̂^Ur`（或写 `Λ_Ur` 口径），否则读者会以为 `K̂`（带 `τ`）落到了 `8` —— 实际带 `τ` 时它是 `10.784`。

**这不改判词，反而更硬**：`K̂_τ ≥ K̂^Ur ≥ 8 > 7.0632853`。

### 4.2 判死线逐条

**(a) 若 `K̂ = Ĉ·|φ^U|^{1/6}` ⇒ `4×2 = 8` 确认？** —— **成立，但限定**：该等式只在立方体见证上取等（§3）；一般只 `≤`。`sup ≥ 8` ⇒ `K̂^Ur > 7.0632853`（超 `1.132617×`）。`[T]`+`[E]`（本轮 `py -3.12`：`(2^12·64)^{1/6} = 7.999999999999999`（浮点）、整数路径 `(2¹⁸)^{1/6} = 2³` 精确；阈值 `7.063285270491693186203038804753186192389`）。

**(b) 若 `2¹²` 不是 `Ĉ⁶` ⇒ 定义错、给正确形式？** —— **不触发**：`2¹²` 的**定义**确不是 `Ĉ⁶`（是 `2^{E₂}`，`E₂=12`），但 `(5.1)` 的 `K̂` 定义**并不依赖** `Ĉ`，它是 `∏_ℓR(ℓ)` 的直接乘积 ⇒ 定义**无错**。真正要修的是 `ur3` 的**归名**（§4.1），不是 `K̂` 的形式。正确写法：
```
K̂^Ur_cube = (2^{E₂} · |φ^U|)^{1/F} = (2¹²·2⁶)^{1/6} = 2^{(12+6)/6} = 2³ = 8
```
（`E₂=12`、`F=6`、`|φ^U|=2⁶`，全整数，无 `Ĉ` 出场。）

**(c) 若 `K̂` 与 `ĈC̄` 是同一个量 ⇒ 指出（那 `7.0633` 就对）？** —— **否，不是同一个量**（§3：一个是合并 `sup`，一个是乘积）；**门槛 `7.0633` 本身对**（`ADJ5:11–29` 已逐字核：`1/(eΔ·u(1/48)) = 8·48/eΔ`，本轮复算同值），它是对「槽」（乘在 `eΔ·u` 前的那个常数）的阈值，与两个候选写法都相容。两写法在同一簇都 `≥8>7.0633` ⇒ 结论稳健。

### 4.3 `1/48` 到不到

`K̂·eΔ·u<1`，`u=β/(2N²)=β/8` ⇒ `β<8/(K̂·eΔ)`；`K̂=8` ⇒ `β<1/eΔ = 0.01839397 = 0.882911×(1/48)`。**不到。** `[T]`
（若改 `K̂_τ=10.784`：`β₁ = 1.3645×10⁻² = 0.6550×(1/48)`，更差。**两条口径都判负。**）
