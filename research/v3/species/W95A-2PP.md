## 1 · `2⁺⁺` 算符：显式 `[T]`

### 1.1 显式（格点、`t` 固定、零空间动量）

```
P_{ij}(x,t) := 1 − (1/N) Re tr[ U_i(x,t) U_j(x+a î,t) U_i†(x+a ĵ,t) U_j†(x,t) ],
                {i,j} ⊂ {1,2,3}, i<j          (单片空间 plaquette，¼trF² 的格点代理)

E_g 的两个分量：
O^{(1)}_{2⁺⁺}(t) = Σ_x [ 2P_{12} − P_{13} − P_{23} ](x,t)
O^{(2)}_{2⁺⁺}(t) = Σ_x [   P_{13} − P_{23}       ](x,t)

一般形：O(t) = Σ_x Σ_{i<j} c_{ij} P_{ij}(x,t),  c=(c_{12},c_{13},c_{23}) ≠ 0,  Σ_{i<j} c_{ij} = 0
对照 0⁺⁺（A1g 迹部）：O_{0⁺⁺}(t) = Σ_x Σ_{i<j} P_{ij}(x,t)      （c=(1,1,1)，Σc≠0）
```

**核心**：`O_{2⁺⁺}` 与 `O_{0⁺⁺}` **共用同一个单片单项式族**，差别只在系数 `c`（`Σc=0` vs `Σc≠0`）。因此"单片"这个前提对两者是同一个事实。

### 1.2 群论核准：`3 = A1g ⊕ E_g`（自算，`[T]`）

三张空间 plaquette 的**平面型置换表示**（转动 `x→Rx`、`P_{ij}→P_{Ri Rj}(Rx)`；`Re tr` 使定向反转不出号）在 `O`（24 元）上的特征标：

```
χ:  E(1)=3,  8C₃=0,  6C₄=1,  3C₂(面)=3,  6C₂′(棱)=1
n_{A1g} = (1/24)[3 + 8·0 + 6·1 + 3·3 + 6·1] = 1
n_{T1 } = (1/24)[3·3 + 6·1·1 + 3·3·(−1) + 6·1·(−1)] = 0
n_{T2 } = (1/24)[3·3 + 6·1·(−1) + 3·3·(−1) + 6·1·1] = 0
n_{E_g} = (1/24)[3·2 + 6·1·0 + 3·3·2 + 6·1·0] = 1      ⇒  3 = A1g ⊕ E_g
```

⇒ 迹零组合 = **纯 `E_g`**，而 `E_g ⊂ J=2`（立方群下 `J=2` = `E_g ⊕ T_2g`）⇒ `O^{(1,2)}_{2⁺⁺}` 是**合法的 `J=2` 插值算符**，且**无 `A1g`（`0⁺⁺`）混入**。

### 1.3 为什么不用 `T_2g`（最省原则，判 (c)）

`T_2g`（3 维，`xy, xz, yz` 型，反对角二次型）**不能**由三张空间 plaquette 张成（§1.2：`n_{T2}=0`），要**场的二次项**，例如 `Σ_x ¼tr[B_i(x)B_j(x)]`（`B_i` 为单片空间 plaquette 的场强代理）：
- 两片**共享一链** ⇒ `w = 4+4−2 = 6`；不共享 ⇒ `w = 8`；
- 而且是**更重的原子**（`FOURWALL §1.5(III)` 的 `6t/a` 类）。

⇒ `T_2g` 路线 `w≥6`，**不是**"再算一遍同一条管"，是**另一条更重的管**。`E_g` 路线 `w=4`，与 `0⁺⁺` 完全同管 ⇒ **最省**。

### 1.4 与 `PROOF-IN11:11` 的一处记账号修正 `[M]`

`PROOF-IN11:11` 逐字"单 plaquette 算符在 `O_h` 下 `A1g ⊕ E_g ⊕ T_2g`"。按 6 张 4D plaquette（3 空间 + 3 时间）的置换表示，应为 **`A1g ⊕ E_g ⊕ T_1u`**（时间面 = 极矢量）。该句的**结论不受影响**（单片只到 `{0⁺⁺,2⁺⁺}`），因为 `E_g` 本身已含 `J=2`；受影响的只是"`T_2g` 也在单片内"这一读法——它需要双片（§1.3）。**不改正性，只修正读法。**

## 3 · `a₀ ≠ 0` 的判据：`⟨Ω|O_{2⁺⁺}|𝔾_{2⁺⁺}⟩ ≠ 0` —— **成立** `[T]`

### 3.1 逐单片：`s=1`（借 `Z04 §2.3` 的补足证明）

`Z04 §2.3`（对 `O=¼trF²`，`[T]`）：四壁每条链上恰两面定向相反 ⇒ `(f,f̄)`；Weyl 正交 `∫_{SU(N)}dU χ_f χ_f̄ = dim Hom(1,f⊗f̄) = 1`；端点 `f⊗f̄→1` 的 `SU(N)` 不变量系数 `1/N>0`（`FOURWALL:82`）⇒ 每单片管的振幅 `a^{tube}>0`，`a₀=(2N)^{-2}`。**该论证只用"管的逐链定向结构 + 单片的空间 plaquette 形状"，对平面取向无偏好** ⇒ 三张面**各自**成立 `[T]`。

### 3.2 组合：模方，不是带号和

```
C_L(t) = Σ_{ij} c_i c_j C_{ij}(t)
i = j 项 : 直四壁管, 振幅 = a^{tube} u^{4N_t}(1+O(u)),  a^{tube}>0   (Z04 §2.3)

⇒ C_L(t) = (Σ_i c_i²) · a^{tube} · u^{4N_t} · (1+O(u))
⇒ a₀(O_{2⁺⁺}) = (Σ_i c_i²)·(2N)^{-2}·[端点重耦合 ×2]·[横向和] > 0        [T]
```
**关键**：`c_i` 的符号只进**平方**（残数 = 算子自身原子的**模方**，`FOURWALL:92` 逐字 `f₁² = |⟨Ω|O|G⟩|² = a₀(1−O(u))`；`Z04 §1.4` 同读法）。⇒ `Y05:41` 的"带号代数和是否对消"担心在**安全方向**解除：不是"只要不对消"，而是**只要 `c≠0` 就永不对消**。

### 3.3 量子数：最低原子**是** `2⁺⁺`，不是 `0⁺⁺`

- `Σc_i = 0` ⇒ 组合无 `A1g`（迹）部；`E_g` 与 `A1g` 是不同不可约表示 ⇒ 以 `A1g` 真空夹 `E_g` 算符的矩阵元按 Wigner–Eckart **恒为 `0`** ⇒ `O_{2⁺⁺}` 对 `0⁺⁺` 原子**零重叠**。
- 故其 KL 测度 `ν_{O_{2⁺⁺}}` 的**最轻原子属 `E_g ⊂ J=2`**，即 `2⁺⁺` 道 ⇒ `f₁²_{2⁺⁺} := ν({m_{2⁺⁺}²}) = a₀(1−O(u)) > 0`。
