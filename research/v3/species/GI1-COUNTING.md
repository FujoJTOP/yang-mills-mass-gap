## §2 三候选（最小公式 + 能否证）

### 2.1 (a) `f₁²` 的 NBC 化

**目标形状**（lead 逐字）：`f₁² = Σ_Γ (某权重)·N(G_Γ)`。

**能证的最小公式（`[T]`，系数层）：**

```
Z(w)      := Σ_{I ⊆ 𝒫, I 独立于 G_𝒫} ∏_{p∈I} w_p                        （GV1:58–64 的模型，f_e=1）
log Z      = Σ_S φ^U(S) ∏_{p∈S} w_p + （重复变量项，w_p²≠0 时不消失）
φ^U(S)     = μ(G_S) = (−1)^{|S|−1} N(G_S)                                 （GO1:75，本文件 §3.1 独立复核）
C(t)      := ∂²_{J₀J_t} log Z |_{J=0},  w_p → w_p(1+J_p)
⇒  [∏_{p∈S} w_p] C(t) = (−1)^{|S|−1} N(G_S)·1{S ⊇ {p₀,p_t}}               (A)
```

**(A) 是精确的吗？——是，但不是"排除了 `O(u)` 的近似"意义上的精确，而是"逐系数恒等式"意义上的精确。** 两个都不含糊的点必须分开写：

1. **(A) 没有余项**：它不是 `a₀u^{4t/a}(1+O(u))`（`P3-CYLINDER-RESIDUE.md:110–118` 那一层是 `[C]`、带 `O(u)`）；(A) 是**恒等式**，每个 `|S|` 一个精确整数 `±N(G_S)`。机验 150 个随机图 × 根对，**0 违例**（`gi1_count.run.log` S3）。
2. **(A) 只在多仿射层成立**：把 `w_p` 一律求成公共 `w` 之后，**它不等于解析的 `C(t)`**。精确反例（2 片相邻 plaquette，`Z = 1+w₀+w₁`）：`C = −w₀w₁/Z²`，公共 `w` 处 `= −w²/(1+2w)² = −w² + 4w³ − 12w⁴ + …`，而多仿射和在 `w_p=w` 处 `= −w²`（`w³` 系数 `0 ≠ 4`）。**Theorem E（§3.4，`[T]`）**。⇒ 语料的 `log Z_dec = Σ_Γ φ^U(Γ)∏w_p`（`KP1.md:35`、`P3-DRESSED-MASS.md:68`）**必须按"多仿射系数"读**；P3 的 `w(P)` 是**另一个对象**（逐聚合物的装饰权，不是 `φ^U∏w_p`）。

**`T_G(1,0)` 的求值能否给出闭式？——不能给一般的闭式，但能给它落到"该族可算"**：见 (c)（§2.3 / §3.3）。管族有闭式递推，一般簇没有。

**判**：**(a) `[T]`（方程 (A)，精确）+ `[NG]`（`f₁²` 的残数层：正计数表示被 2D 杀，`§3.6`；求值被 Theorem E 挡，`§3.4`）+ `[O]`（把 (A) 推到残数，需要的正是 `lim_t e^{E₁t}` 那一步 = 语料自己的 (R1)，`P3-CYLINDER-RESIDUE.md:176`）。**

### 2.2 (b) `m` 的 Tutte 求值

**能写出的最小关系式（都不成立，逐条给反证）：**

候选 B1:  m = T_G(x(β), y(β))             —— 恒等式？
候选 B2:  m|β_c = T_G(1,0) = N(G_Γ)       —— 只在某点？

**判**：**(b) `[NG]`**，两条独立证书（C1 β-刚性、C2 非解析），加一条正向替代（`m` = 同一 NBC 交错和的**速率**，`f₁²` = 它的**振幅**，见 §3.5）。

## §3 证明或证书

### 3.1 Theorem A（多仿射两点恒等式）— `[T]`

**陈述**：设 `𝒫` 有限、`G = G_𝒫` 为其邻接图（两片共 link 为边），`w_p` 形式变量，`Z = Σ_{I 独立}∏_{p∈I}w_p`。则在 `w_p² = 0` 的环里
`log Z = Σ_S μ(G_S)∏_{p∈S}w_p`，且 `[∏_{p∈S}w_p](∂²_{J₀J_t}log Z)|_{J=0} = μ(G_S)·1{S ⊇ {p₀,p_t}}`。
**证明**：(i) 多仿射系数 = 划分格上的交替和 `Σ_{π}(−1)^{|π|−1}(|π|−1)!·[各块独立]`，该和等于 `Σ_{A ⊆ E(S), 连通张成}(−1)^{|A|} = μ(G_S)` —— 这就是 `GO1.md:43` 的 (1.1)/(1.2) 与 `GO1:75`，本文件用独立实现（nilpotent 环上逐次乘 `Z−1`）在 150 个随机图上复核，**0 违例**。(ii) 代入 `w_p ↦ w_p(1+J_p)` 后在 `w²=0, J²=0` 环中，`∏_{p∈S}w_p∏_{p∈S}(1+J_p)` 的 `∂²_{J₀J_t}` 当且仅当 `{p₀,p_t} ⊆ S` 时为 `∏_{p∈S}w_p`，否则为 0。∎（初等；不含估计。）

**限（必须同写）**：这条是**系数**恒等式，**不是**求值恒等式 —— 见 3.4。

### 3.2 Theorem B（块乘性）— `[T]`

**陈述**：`G` 有限连通，`B` 跑遍其 2-连通块，则 `N(G) = ∏_B N(B)`；等价 `μ(G) = (−1)^{#br}∏_B μ(B)`（`C02:36` 的纯计数形式）。
**证明**：`μ` 在桥处乘性（`GO1:156` Step 3）；且 `n − 1 = #bridges + Σ_{2cc}(|B|−1)`（块-割点树计数：每个块贡献 `|B|−1`，桥块贡献 1）。于是
`μ(G) = (−1)^{#br}∏_{2cc}μ(B) = (−1)^{#br}(−1)^{Σ(|B|−1)}∏N(B) = (−1)^{n−1}∏N(B)`，
与 `μ(G) = (−1)^{n−1}N(G)`（`GO1:75`）比较即得。∎
**机验**：195 个随机连通图（`n ≤ 9`，Tarjan 独立分解），`|μ| = |∏N(B)|` **0 违例**；`#br + Σ(|B|−1) = n−1` **0 违例**。

### 3.3 Theorem C（四壁管族的闭式）— `[T]`（递推）+ `[E]`（`T ≤ 40`）

**陈述**：`C₄ □ P_T`（`4T` 片，`P3` 的每层 4 壁）满足 `μ_T = −N_T`、`N_T = 46N_{T−1} − 85N_{T−2}`、`λ± = 23 ± 2√111`。
**证明（机制）**：`μ_T = Σ_{A 连通张成}(−1)^{|A|}` 由"逐层连通性 DP"给出（状态 = 当层 4 点的连通划分，15 个；转移 = 8 条新边的子集）。DP 与暴力在 `T=1,2,3` 上逐位一致（`−3,−133,−5863`），说明 DP 覆盖的是**同一个** `N`。阶 2 的最小性：`N_2/N_1 ≠ N_3/N_2`（`44.33 ≠ 44.08`）故非一阶；二阶解唯一并通过 `T=3…40` 的全部 38 个校验。
**推论（新数）**：`λ_Ur ≥ λ₊^{1/4} = 2.57655243 > 120^{1/6} = 2.220906`（`GV2:247` 的改进）；SU(2) 口径 `λ_Ur·u ≥ 1.610345`（原 `1.388066`）。
**限定（`AGENTS §2.1`）**：`λ_Ur` 取 `GV2:245` 口径（`c_Γ := μ(G_Γ)`，不含 `u`）。若按 `GU4-NECESSARY.md:270` 的 `c_Γ = φ^U/u^{|Γ|}` 口径，同一不等式整体除 `u`，**结论方向不变**。

### 3.4 Theorem E（求值缺口）— `[T]`

**陈述**：多仿射和 `Σ_S μ(G_S)w^{|S|}` 在公共 `w` 处的值 **≠** 解析的 `C(t)`。
**证明（两片相邻 plaquette，`n=2, E={01}`）**：`Z = 1+w₀+w₁`，`A₀ = w₀`，`A₁ = w₁`，`A_{01} = 0` ⇒ `C = −w₀w₁/Z²`。多仿射和 `= μ(edge)w² = −w²`。公共 `w` 处 `C = −w²/(1+2w)² = −w² + 4w³ − 12w⁴ + …`（机验 `1/(1+2w)² = 1 − 4w + 12w² − 32w³ + 80w⁴`）。`w³` 系数 `4 ≠ 0`。∎
**后果（口径纪律，与 `AGENTS §2.1` 同类）**：`φ^U`-展开**只能在多仿射环里用**；把 `w_p` 一律求成 `w` 会引入"重复 plaquette 项"，那些项**不是** `φ^U` 型、也不受 `N ≥ 1` 控制。P3 的 `w(P)` 是逐聚合物权，**不是** `φ^U∏w_p`，两者不可互换。

### 3.5 (b) 的证书与正向替代 — `[NG]` + `[T]`

**（C1）β-刚性**：`T_G(x,y) ∈ ℤ`（`x,y` 固定）与 `β` 无关；`m` 连续非常数（2D 精确 `3/(4β)`，`ATOM2:43`）。⇒ 固定求值点的恒等式**不存在**；`(x,y)` 随 `β` 变则恒真。
**（C2）非解析**：`am ∝ e^{−cβ}`（`B10:215`）⇒ `m` 在 `u=0` 处各阶平坦；任何 `Σ N(G_S)u^{|S|}` 是 `O(u)` 幂级数。⇒ 不存在正系数幂级数表示。
**正向（同一式子的两读数，`[T]`）**：定义 `F(t) := Σ_{S ⊇ {p₀,p_t}} (−1)^{|S|−1}N(G_S)∏_{p∈S}w_p`（= Theorem A）。则
```
m  = −lim_{t→∞} (1/t) log|F(t)|        （速率；仅在 f₁²>0 ∧ I₂ 时成立 —— 语料的开环，P3-CYL:161）
f₁² =      lim_{t→∞} e^{m t} F(t)      （振幅；语料的 I1）
```
⇒ `m` 与 `f₁²` **不是**两个独立对象，是**同一个交错 NBC 和**的速率与振幅。这解释了为什么"计数化"对两者都只能到系数层：**速率/振幅是重求和，不是计数。**

### 3.6 Theorem N1（正计数 no-go）— `[T]`

**陈述**：设 `f₁² = Σ_{S 非空连通} a_S w^{|S|}N(G_S)`，`a_S ≥ 0`，`0 < w` 有限（`N(G_S) ≥ 1` 由 `GO1:204(c)`）。则等式在 2D 纯 `SU(N)` YM 上不成立。
**证明**：求和 `≥ a_{{p₀}}·w·1 > 0`（若 `a_{{p₀}}>0`），在任何维度、任何 `w>0` 成立；而 2D `f₁²(¼trF²) ≡ 0` **恒等**（`ATOM2:15,62-63`：`¼trF² = ½trE² = g²h`，`[O,H]=0`、`O|Ω⟩=0` ⇒ `ν ≡ 0` 空测度，**每个 `g`**）。⇒ 矛盾。若 `a_{{p₀}}=0` 则取最小 `|S|` 的非零项，同样得 `> 0`。∎
**后果**：`f₁²` 若要有 NBC 写法，系数必须**变号**；变号后"和 ≥ 1 项"就不再能推出正性 —— 这就是 `GO1` 的正性**到不了** `f₁²` 的精确原因。
