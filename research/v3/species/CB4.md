## 4 · `C̄ = 8` 成立吗 —— **(b) 主判 + (c) 机制**

`C̄` 的定义（`X01-L1C:71–75`）：`\|φ^U(Γ)\| ≤ C̄^{\|Γ\|}u^{\|Γ\|}`，`ū := eΔ·C̄·u` ⇒ `C̄ = (每片权重)/u`，量的是**一个聚合物里一片的权重**。三条互不等价的路：

```
真·每片权重（单支 r）:  |w_p| ≤ c_r dim r ≤ c_f dim f = N²u   ；或用 ∏c_f ⇒ c_f = Nu
                        ⇒ sup_p|w_p|/u = c_f/u = N = 2.0000（精确 cube/tube，C05:57，n=6,4,8,12）
活动度和（②，两支相加）: Φ(0)/u = 2N² = 8.06（墙处实测 8.0626）
```

* **不可加**：一片 plaquette 在一个聚合物里只能取 `f` **或** `f̄` 一支（`C05:91` 逐字："互斥的标签选择"）。`2N²` 里的那个 `2` 是**两支求和**，是"活动度"（`log Z`、`Σ_r`）的合法因子，**不是**权重界的因子。⇒ `C̄=8` 把 `Σ_r` 的求和口径塞进 `sup_p` 的权重槽 = **对象错**。`[T]`
* **`(b)`**：`Φ` 是另一个量（②而非"那个权重"）⇒ **`C̄=8` 不成立**。正确的权重槽是 `C̄ = c_f/u = N = 2`（`M07:106` 判"在"；`F07:113` 已证精确）。
* **`(c)`**：`Φ(0)=β` 这句话本身不是伪造，而是**撞名后的位移**：`Φ` 在语料里指 ①（Haar 权重，`research/v3` 内 `Φ` 命中 2987）与 ②（活动度，`P3-FULLREP-KP:85`）两物；`M07:109` 已把 `Φ(0)/u=2N²=8` 标为"**全表示活动度和（`log Z` 系数，不是聚合物权重）**……进此槽是 `c03` 的原始错"，`P3-CBAR:18` 同时记"`f07` 的 `N` 是三读法里最小、最松的那个"。本轮把这条从"记账分歧"钉成**身份判决**：`Φ` 是 ②，不是权重。`[T]`+`[C]`
* **附带（同一撞名）**：KP 判据是 `λ_aΦ(a)≤½` 在 `a=1`（`P3-FULLREP-KP:90,96`），`Φ(1)=2.755Φ(0)` ⇒ 语料的 `λ_aΦ(0)=eΔβ<1`（`C05:96`、`F07:139`、`M07:123`）是**放宽**的必要条件；KP 真窗 `β≤3.357e−3`（`P6-SPEC:114`；`Z01:123` 给 `3.4e−3`）。所以"`Φ(0)=β` 是 KP 判据左边每片的量"（`C05:52`）在 `a` 上也不对。`[T]`
* **所以 `0.0184` 不是被推翻，是被改判**：它等于 `1/(eΔ)`，靠 `Ĉ·C̄ = 4×2 = 8`（`M07:136`）而非 `C̄=8`；而它本身仍只是 `a=0` 半径，KP 真半径 `3.357e−3`。`[T]`+`[E]`
