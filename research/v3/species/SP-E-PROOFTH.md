## §1 两个命题的量词形式与层级

**P1（已得）**：`¬∃p≥0 ∀R≥1 : f(R) = R^{−p}`
即 `∀p≥0 ∃R≥1 : f(R) ≠ R^{−p}`。
但 `p` 由单点值钉死：`p₀ := −log₂ f(2)`（`f(2)>0`；`f(2)≤0` 时 P1 平凡真，因为 `R^{−p}>0`）。故对给定的 `f`，
**P1(f) ≡ ∃R [f(R) ≠ R^{−p₀}] = `Σ⁰₁(f)`** —— 一个数词存在量词，无函数词。

**P2（要的）**：`∀f∈𝓕 [ (★₁)(f) ∧ 0<f≤1 ∧ f′≤0 ⇒ ∃c>0 ∃R₀ ∀R≥R₀ : f(R) ≤ e^{−cR} ]`。
`c` 可限制为有理（对 `c` 单调：成立则更小的 `c` 也成立）⇒ `∃c∈ℚ⁺ ∃R₀∈ℕ ∀R∈ℕ`，即
**P2(f) = `Σ⁰₂(f)`**；句子层（`∀f`，`𝓕` 算术可定义）**P2 = `Π¹₁`**，与 P1 的句子层同为 `Π¹₁`。

**⇒ 差：恰好一次数词交替（一个 `∀∃` 块 = 一个"速率"量词），零次函数词交替。** 不是 `Π₁→Π₂`。

**P1 ⊬ P2（`[T]`，显式见证）**：`f(R) = R^{−2} log R` 不是幂律（P1 成立），不指数衰减（P2 不成立）。
所以那一次交替在同一层不可消除。**但算术交替不是强度阶梯**：集合存在公理/选择公理能给"存在"、给不出"速率"，任何公理都买不到一次 `Σ⁰₁→Σ⁰₂`。

## §2 关键定理：`(★₁)` 根本没有衰减解（8 行，`[T]` 条件于 `(★₁)`）

设 `A := c₂g²N/c₁ ≠ 0`，`f∈C²([R₀,∞))`，`f>0`，`f′≤0`，`f→0`。则 `(★₁)` 不成立。

- **(i) `A<0`**：`f″<0` ⇒ `f′` 递减且 `f′≤0` ⇒ 存在 `R₁` 使 `f′(R₁)<0` ⇒ `f(R) ≤ f(R₁)+f′(R₁)(R−R₁) → −∞`，与 `f>0` 矛盾。
- **(ii) `A>0`**：`f″>0` ⇒ `f′` 递增；`f′≤0` ⇒ `L:=lim f′ ∈ [−∞,0]`。`L=−∞` 使 `f` 有限时间变号；`L<0` 使 `f~LR→−∞`。故 `L=0`。于是
  `−f′(R) = ∫_R^∞ f″ = A∫_R^∞ f(s)²/s³ ds ≤ A f(R)²/(2R²)`（用 `f` 递减），
  即 `−f′/f² ≤ A/(2R²)`；积分得 `1/f(R) ≤ 1/f(R₀) + A/(2R₀) < ∞` ⇒ **`f(R) ≥ c₀ > 0`**，与 `f→0` 矛盾。∎

**推论**：`(★₁)` 的任何正解，要么增长（`f~CR`，即 `p=−1` 那一支），要么趋于正常数 `ℓ>0`。**没有任何一类衰减解——幂律、对数修正、`e^{−(\log R)^α}`、`e^{−mR}`，全都不存在。**

**稳健性**：把 `LHS` 换成 `f″+(1/R)f′`（保留 §2 略去的 `1/R` 项）结论不变：`(Rf′)′ = Af²/R² ≥ 0` ⇒ `−f′/f² ≤ A/R²` ⇒ 同一下界。**符号两面都死，`c₁,c₂` 的账救不了。**
