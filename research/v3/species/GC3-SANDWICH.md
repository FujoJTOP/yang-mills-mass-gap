### §0.1 **一行论证**（本任务要的那句）

> **`lo ≤ m` 一旦作为已证不等式成立，`lo > 0 ⟹ m > 0` 是逐字重言；且任何零隙模型上可靠性强制 `lo ≤ m = 0`，故 `f(0)=0` 不是机器的设计而是它的**逻辑后承**——于是下坐标 `lo` 逐字满足 `N09-1` 的 m-型签名（`f(0)=0`、`f>0` 当 `m>0`），成对输出经投影 `π(lo,hi) = lo` 与标量机**同构**，落 A 支。**

## §2 最小公式

### §2.1 严格陈述

固定算符 `O`（`sec04-survey.tex:57–63` 的强制条款：`w₁` 是 `(H,O)` 的对，不是 `H` 的函数），把质量写成
```
m := m(L,a) ∈ [0,∞) ,     目标量词：∀L ∀a(β)         （(L,a) 双非紧端，G02.md:13）
```
**成对夹逼机**是一台输出二元组并附证书的机器：

> **定义（成对机 Φ）.** `Φ` 在族 `{(L,a)}` 上输出 `(lo, hi) ∈ ([−∞,∞])²` 并附
> ```
> (i)  lo ≤ m(L,a) ≤ hi      ∀L ∀a        （"夹逼"，两侧都证）
> (ii) lo, hi 与 (L,a) 无关    （"一致"，否则是逐点陈述，不是本对象的量词）
> ```

要证出 `∃(lo,hi): 0 < lo ≤ m ≤ hi`，需要**两个输入**，方向相反：

| 输入 | 要证的不等式 | 方向 | 数学来源 | 可及性 |
|---|---|---|---|---|
| **U（上界）** | `m ≤ hi` | **↑ 从上压** | 变分 / min–max / Rayleigh：任一 `ψ⊥Ω` 给 `m = E₁−E₀ ≤ R(ψ) − E₀`（`BREAK-IN-10.md:14`；`BASE-NONLOCAL-BOUND.md:20,94`：变分**只**给上界） | **恒可及**；且 `hi=+∞` 空真 ⇒ 见 §2.3 |
| **L（下界）** | `lo ≤ m` | **↓ 从下托** | 三条互斥的可能：(L1) Temple/Weinstein 带阈值 `ρ ≤ E₂`；(L2) 全局证书（Cheeger / log-Sobolev / `H1` 型）；(L3) 直接就是靶 | (L1) 前件装靶 ⇒ `[NG]` 循环（`IMP-ARROWS.md:61` 行 9；`B02-TOOLS.md:78`：`ρ` 语义 ⟺ 隙）；(L2) 需 `(L,a)`-一致全局证书，`[O]`（`BASE-NONLOCAL-BOUND.md:94`）；(L3) 循环 |

⇒ **两个输入不同类**：`hi` 侧是**构造性/变分**（廉价、永远可做），`lo` 侧是**全局/存在性**（贵、且三条候选全断）。这就是 `MACHINE-SIEVE` F1（`MACHINE-SIEVE.md:24`）的成对版本：**下界是唯一缺件，上界是舞台。**

### §2.2 **`lo > 0` 是否等价于"已经知道 `m > 0`"** —— 本任务的判据

分成两个问题，答案**不同**，这正是全部混淆的来源：

**（问 A）作为结论：等价。** 命题（两行，`[T]`）：

> **命题 GC3-1.** 设 `m : (L,a) ↦ [0,∞)`，`lo` 与 `(L,a)` 无关。则
> ```
> [∃ lo > 0  s.t.  ∀L ∀a : lo ≤ m(L,a)]   ⟺   inf_{L,a} m(L,a) > 0 .
> ```
> **证.** （⇒）`∀(L,a): m ≥ lo ⟹ inf m ≥ lo > 0`。（⇐）令 `δ := inf m > 0`，取 `lo := δ/2`，则 `lo ≤ m` 逐点成立且 `lo>0`。∎

⇒ **`lo>0`（一致版）与"靶"是一对**逐字**等价的命题**，不是"推出靶的一条充分条件"。成对机的第 (i)(ii) 条义务**就是**这个命题：`m ≤ hi` 不参加。

**（问 B）作为方法：不等价，且不等价的方向不能救它。** `m>0` 逐点（在一个 `(L,a)` 上）不给 `lo` 的**可计算性**——1D 谐振子里 `m>0` 显然，但一致 `lo` 仍需非平凡工作（`CONSTRUCT-WAVEFUNCTIONAL.md:104–109`：要的试验态"⟺ 本征态"）。所以 `lo>0` 作为**待证物**严格难于 `m>0` 作为**已知事实**。

> **判它落 A 支的关键不是问 A 也不是问 B，而是符号/零集：** `lo` 与 `m` **同号、同零集**（`lo>0 ⟺ m>0`，`lo ≤ 0` 对 `m=0` 恒真）。这恰是 `N09-1` 的 m-型签名（`MACHINE-SIEVE.md:39`：`f(0)=0`、`f>0` 当 `m>0`）——而**其中 `f(0)=0` 不是设计出来的，是被"`lo ≤ m` 可靠"逼出来的**（`m=0 ⟹ lo ≤ 0`）。**免费得到的酸测签名，就是伪装的确证。**

### §2.3 `hi` 的位置：免费侧，与判决正交

- **`hi` 恒可容许**：`m ≤ +∞` 空真 ⇒ `(lo, +∞)` 合法 ⇒ 对 `(lo,hi)` 只要能取到 `lo>0`，退化成单侧机。
- **目标问题是单侧的**：`G02.md:26` 逐字——"`c₀ ≤ ratio ≤ C₁` **✗ 不是这个**。目标逐字只有 `≥ c₀ > 0`"；`G02.md:140` 表行 3："目标只有 `≥ c₀`，`37.75` 单侧（无上界）⇒ 不是 sandwich"。⇒ **上坐标即使有真内容（P2 的 `R(ψ)` 就是），也与"是否有隙"这个判决正交**。
- ⇒ 判决函数 `D(lo,hi) := 𝟙[lo>0]` 只读一个坐标。**对 ⊂ 区间 ⊂ "两个标量"，而判决是 `[0,∞)`-值的一个标量函数。**

## §3 二难判定

### §3.1 命题

> **命题 GC3-2（成对机落 A 支）.** 设 `Φ` 是定义 §2.1 的**可靠**成对机（即它交付的 `(i)(ii)` 为已证不等式/已证一致界）。则 `Φ` 的下坐标 `lo` 满足 `N09-1` 的 m-型签名，且 `Φ` 相对靶**不弱**：
> ```
> [Φ 交付 lo > 0]  ⟺  inf_{L,a} m > 0 .
> ```
> **级**：`⟺` 的前半行是 `[T]`（命题 GC3-1 + `lo ≤ m` 的可靠性）；"`lo` 落入 `m`-型类"这一归类承 `N09-1` 的**两条假设**（M6 规格 + `L→∞` 读法）⇒ 整条判 **`[C]`**；把判词读成"落 A 支"是 `[J]`。

**一行论证（与 §0.1 同一句，此处带结构）**：

> 可靠性给 `lo ≤ m`，故 (a) `lo>0 ⇒ m>0` 是重言、(b) `m=0 ⇒ lo≤0` 是重言 ⇒ `lo` 的零集与符号与 `m` **逐点一致**；`N09-1` 的 m-型类**就是**"逐点与 `m` 同号同零集的一族标量"，故 `lo ∈ m`-型类，`Φ` 与标量机 `Φ_lo: (L,a) ↦ lo` **在判决面上不可区分**，而 `Φ_lo` 已被 `MACHINE-SIEVE` §2 情形 A 判死 ⇒ `Φ` 落 A 支。

### §3.2 与 `MACHINE-SIEVE` 二难的对齐（为什么这不是循环）

`MACHINE-SIEVE` §4 说"二难只对**标量**成立，盖不住复合输出"（`MACHINE-SIEVE.md:65–70`）。本文件的动议是：**成对输出在判决面上**是标量，所以二难**盖得住**它，只是当初的分类按"输出的形状"（一个数 vs 二元组 vs 序列）而不是按"判决函数的定义域维度"分。改判据后：

| 形状 | 判决函数读到几维 | 二难覆盖？ | 依据 |
|---|---|---|---|
| 标量 `X` | 1 | **覆盖**（A / B 支） | `MACHINE-SIEVE.md:37–42` |
| **成对 `(lo,hi)`** | **1**（只读 `lo`） | **覆盖 ⇒ 落 A 支** | 本文件 §2.3、§3.1 |

### §3.3 三个反例式的逃生尝试，逐一打掉

要否证命题 GC3-2，必须造一个"`lo>0` 成立但**不知道** `m>0`"的对。因为 `lo>0 ⟹ m>0` 是重言，唯一出路是让**下坐标根本不是 `m` 的下界**。三种形状：

**E1｜下坐标界的是替身 `g`，且 `g` 与 `m` 在某酸测模型上脱钩。**
- 形状：`lo ≤ g ≤ hi`，`g ∈ {s₁, Δ_dyn, m_{0⁺⁺}}`。典型：`s₁ = inf supp ν`（`H06.md:24`），`s₁ ≥ m` ⇒ **`s₁` 的下界对 `m` 零信息**。
- **打掉**：(1) 违反定义 §2.1 的 `lo ≤ m`——这是**对象错位**，非成对机；(2) 已判死且是逐字判死：`H06.md:14`（"即使给到 `s₁≥c`，`s₁ ≥ m` ⇒ 对 `m` 的下界零信息；M6：`s₁=1`、`m₆→0`"）；`B10.md:154`（"`s₁(M6) = ω = 1 > 0 = m₆` ⇒ ① 挂 ⇒ `s₁ ∉ dom(N09-1)`"）；`sec04-survey.tex:107` row 15（`Δ_0`：M6 `Δ_dyn>0` 而 `m=0`；2D `Δ_dyn=0` 而 `m>0`）。⇒ **不是真格子，是 row 15。**

**E2｜对是"条件对"`(lo, hi | H)`，`H` 严格弱于靶。**
- 形状：机器只证 `H ⟹ lo ≤ m ≤ hi`，并把 `H` 摆出来。若 `H` 真弱于靶，则 `lo>0` 在 `H` 下成立而 `m>0` 未必——**这是唯一形式合法的逃生口**。
- **部分打掉**：形式上它不是本文件的反例（定义 §2.1 要的是无条件夹逼；有 `H` 的机器是**条件定理**，其判词按 `H` 独立定级）。实质上语料把这类全查过了，每个 `H` 都 ⟹ 靶：
  - `H = (ρ ≤ E₂)`（Temple 阈值）：`IMP-ARROWS.md:61` 行 9 判 `[NG]` 循环（"前件里装着隙"）；`B02-TOOLS.md:78`："`E₂ ≥ ρ` 在单标度协变下 **⟺ `m₁ ≥ ρ/ρ_true` = 隙**"；把**相对**比值喂进去"`c` 取真值时 Temple **精确返回 `m₁ ≥ m₁`"（`E2-FLIP-L1-VNW.md:53,149` 转引）。
  - `H = (Λ★ := inf supp(ν − f₁²δ) > m₁²)`：`IMP-ARROWS.md:66` 行 14"`Λ★` = 隔离 = Clay **上一级**"；判"A 比 Clay **强**（不是更弱）"。
  - `H = H1`（`χ ≤ 1/λ`）：`IMP-ARROWS.md:70` 行 18 判"`[T]` **等价** ⇒ A 是改写，不是更弱 ⇒ 零增益"；且 `H06.md:12`（`H1` 只落在**上界侧**，越强越松）。
  - `H = I1 ∧ H1`：`H06.md:34`——控出来的**是 `s₁`**（⇒ 落回 E1）。
  - `H = "已被独立隔离的窗口"`（P1 的"唯一非循环用法"）：升格条件本身 = 靶（`B02-TOOLS.md:79`）。
  ⇒ **语料 0 实例。** 但这是**检索性**结论，不是定理：**命题 GC3-2 不排除它**（§6.3）。

**E3｜两坐标"非可比"（比值/双坐标系统/自改进迭代）。**
- 形状：`lo ≤ A·m`、`hi ≥ B·m`，判决用 `lo/A`；或 `lo_{n+1} = F(lo_n,hi_n)` 迭代。
- **打掉**：两个变形都把 `m` 的界**换回一个标量**（`lo/A`；`lim lo_n`）。迭代版更弱：只要有**某一** `n` 使 `lo_n>0`，判决已完成 ⇒ `∃n: lo_n>0` 又是单坐标命题。⇒ 仍是 §3.1 的形状。

### §4.2 结论：**4/4 全自动 ⇒ F6 对成对机零判别力**

- 四格判决**全部**由"`lo ≤ m` 可靠 ∧ 该模型的 `inf m` 值"**唯一决定**，无一处用到机器的构造细节。⇒ **一台可靠成对机**无论内部是什么（Temple / Cheeger / ELS / 任何未来的），**都 4/4 通过**。
- ⇒ **`MACHINE-SIEVE` 的过滤器 F6（`MACHINE-SIEVE.md:29`）在这一格上是空转的**：它设计来"杀掉在带隙模型上仍盲、或在无隙模型上假阳性的机器"（`GW1:127` 记录它杀掉 `Δ₀`/`G″`），但成对机的拒签**由可靠性免费给出**。**通过酸测在这里不是本事，是语法。**
- **对照（判别力在别处是真的）**：`GW1-FLOW-TARGET.md:120–127` 的同一张表里，`(F-m)` 在 2D 上的拒签**不是**自动的——要算出 `d log m/dβ = −1/β` 再判 `∫_{β₀}^∞ 1/β = ∞`（`GW1:123`）；而 `(F-F)` 在 2D 上给的是 **"盲"**（`f₁²≡0 ⇒ 0 ≤ 0` 对任意 `C`）而非拒签（`GW1:123`）。⇒ **同一判决式对 `(F-F)`/`(F-m)` 有判别力，对成对机没有。** 这是本轮把 F6 用对地方之后的净发现。
- **一个副产品**：反过来看，任何**未**自动通过的成对机必然是**不可靠**的（在某个模型上给了假地板），而那是错误而非新物种。⇒ **成对类的"通过 / 不通过"不含信息。**
