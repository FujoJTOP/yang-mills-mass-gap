## §2 规格（一句，可执行）

> **`|ε_T| ≤ B₀(Ū)·exp{−T·ln(1/Ū)}`，`Ū = ū·exp{−c·Ū}`，`c` = 管的壁数（d=4：`c=4`），`B₀` 只含 `Ū`。**

三条**必要性**（逐条对任务的四条约束）：

1. **`ū>1` 要给指数小界**：`f(x)=ūe^{−cx}` 单调、`f(0)=ū>0`、`f(1)=ūe^{−c}−1`，故 `(0,1)` 内有唯一根 ⟺ **`ū<e^c`**。`c=4`：`ū<54.59815`。`ū=33.98` 在窗内 ⇒ `Ū=0.906087<1 ⇒ δ=+0.0986>0`。**这一条是它"能过"的全部来源**。`[T]`+`[E]`
2. **不能只给存在性（要正性）**：`δ=ln(1/Ū)`，`Ū<1` ⇒ `δ>0` **显式**；且 `B₀(Ū)=Ū³/(1−Ū)³` 在 `Ū<1` 有界（`Ū=0.906087`：`B₀=898.116`，仍是 `e^{−0.0986T}` 前的一个**常数**）。⇒ 正性、显式、`L,T`-一致三件都在。`[T]`
3. **不能用相似不变/均值型**：`Ū` 是 `β` 的**函数**（`ū=eΔc_f(β)/N` 进、`Ū` 出），不是任何算子的谱量、不是 `W` 的任何均值、不是 `W^{½}(·)W^{−½}` 型的相似变换（后者只重排谱，改不了 `ū`）。`[T]`

**与旧式的关系（逐字可复算）**：旧式 = `(1)` 中令 `Ū→ū` 且只保留 `|ū|<1` 的几何级数；新式 = 把 `ū` 换成**不动点**。⇒ 新式在 `ū<1` 时退化为旧式的**上界更松**版本（`Ū<ū` ⇒ `B₀(Ū)` 可比 `(ū/(1−ū))³` 大），故不是"更紧的常数"，而是"**换了载体**"。`[T]`

## §3 结构：为什么必须是"方程"

`P3-DRESSED-MASS` 的密度形式：`log Z_dec(B_T) = φ_dec·T + O(1)`，于是

```
m₁^{dressed} = κ − φ_dec ,        κ = 4 ln(1/u)/a
δ            = κ − φ_dec  (单位长度)          (3.1)
```

`(3.1)` 就是 §2 的 `δ`：把 `φ_dec` 取成"每个装饰的活动度被自己压掉的自由能"，即 `φ_dec = ū(1−e^{−cŪ})/a` 型，静止点给出 `Ū=ūe^{−cŪ}`。**结构判据**：

| 候选结构 | 能不能 | 理由（带数） |
|---|---|---|
| 多尺度 RG | **不能** | `β<1/48` 窗是**绝对收敛半径**（`H2-L3FINAL:118`：不是可优化常数堆）；`eΔu<1` 是熵半径，RG 分块只把 `Δ→Δ_ℓ`，`d=4` 边际 ⇒ `eΔ_ℓ u_ℓ` 停在 `O(1)`（`C-BBS-MARGINALLOG` (A)：AF 只吃 log，不吃符号） |
| 正性 / 特征标正测度 | **不能** | `β=2.5` 处 `c_r(β)` **变号**（`L4A-RG:191–193`、`GKS-GAUGE:3,15`）⇒ 该类 `[NG]`，且这是**在册**判词 |
| 硬核（hard-core / 自回避） | **不够** | 硬核只把熵常数 `μ` 从 20 压到常数倍；过 `β=2.5` 需 `μ<3.2`（§0-6），面族生长常数压不到 |
| 谱半径 | **同死** | = `H1`（60+ 轮已判）；`2D` 的精确答案确实住在转移权重里（`N02:120`），但 4D 拿不到 |
| **自洽不动点（本节）** | **唯一能过 `ū>1`** | 因为方程对任意 `ū` 有根；代价见 §0-8：假设在全 β 成立 ⇒ 证明 = Clay |

**⇒ 结构 = 两尺度自由能差（管 vs 装饰气）的自洽单点闭包。** 不是"多尺度"，因为 `T` 只有一个尺度；不是"正性"，因为不动点不靠符号；不是"硬核"，因为 `c` 是几何面数不是排斥；不是"谱半径"，因为 `Ū` 里没有算子。`[T]`

## §4 额外抑制机制 = **壁数**（这是本路最有价值的一格）

**机制**：管是 `1×1×T` 的对象，它有 **4 个壁**。一个装饰与管贴合 `k` 次，就失去 `k` 份自身的位置熵 ⇒ 有效活动度乘 `e^{−k}`，平均 `k=c`。`c` 因此**不是**拟合参数，而是**管的边界余维数**：

```
c(d=4) = 4   （四壁；与 κ=4ln(1/u)/a 的那个 4 是同一个 4，语料已在册）
c(d=2) = 2   （2D 的"管"是 1×T 条带，两条长边）
```

**为什么"就是这个"**：`§0-7` 的 2D 试金石给了一个**判别实验**：`c=4` 移植到 2D 时 `β=1` 处 `δ=0.5146 > m=3g²/8=0.375` ⇒ 声称的衰减比精确解**快** ⇒ 假；`c=2` 时 `δ=0.0418≤0.375` ⇒ 安全。**只有把 `c` 解释成壁数，两个维数才同时自洽。** `[T]`+`[E]`

**脆弱性（必须写死）**：需要 `c > ln ū`（根 <1 的条件）。门槛：`ln 33.9785=3.5257`（`u=β/N²` 口径）／`ln 13.787=2.6237`（`c_f` 口径）。四壁给 `c=4`，余量仅 **1.13×**（前者）／**1.52×**（后者）。⇒ 规格**骑在 `c` 的门槛上**，任何对"贴合面数"的重新计数（例如把斜贴、对角贴算进来）都可能翻符号。**这是本规格唯一的技术风险点。** `[C]`

## §7 判死线

**(a) 规格可执行吗 —— 触发，但只在"可写"这一半。**
规格写成一句、常数全由语料几何（四壁 `c=4`）给出、`β=2.5` 两个口径都给 `δ>0`（`+0.0986`／`+0.310`）、可过四模型（`4/4`，且 2D 有判别力）。⇒ 作为**靶**它是可执行的。**但作为定理它不可执行**：`Ū=ūe^{−cŪ}` 是**平均场闭包**，其严格版本就是装饰气压强 `φ_dec` 的存在 + 正性，而那正是 `[R]`（`W1B:20,56,78` 逐字"没有有限阶值"）；在 `ū=34` 处气体是**超临界**的，`φ_dec` 根本不在 Mayer 级数的收敛域内。⇒ **循环**。`[C]`

**(b) 规格要求的东西在 YM 里不存在吗 —— 触发（结构性 no-go，限定到"重求和型 species"）。**
那个"熵杀手"必须能压 `μ` 从 `20` 到 `<3.2`（§0-6）。语料里能压熵的只有两类：**正性**（`β=2.5` `c_r` 变号，在册 `[NG]`）与**谱**（`=H1`，已判死）。第三类（自由能差/屏蔽）**不是压制，是重排**——它把 `ū` 搬进 `Ū`，但对任意 `ū` 都有根，等于**什么都没排除**（§0-8）。⇒ 本 species 的 no-go 表述：**"任何在 `ū>1` 给指数小界的重求和，要么等价于正性/谱（二者已死），要么等价于目标本身"。** `[T]`（在册两条死的交集上）

**(c) 能指名那个额外抑制机制吗 —— 能，且它是本路唯一有价值的产出。**
**壁数 → 粘附熵损失**：`c = ` 管的边界面数（d=4 四壁，`c=4`；d=2 两条长边，`c=2`），它与 `κ=4ln(1/u)/a` 的 `4` 是**同一个几何常数**的第二次使用（一次进率、一次进指数）。这是本路唯一**可判别**的新陈述：它预言 `c` 随维数变，并被 2D 精确解在 `c=4` 移植上**证伪**、在 `c=2` 上**放过**。⇒ 机制**指名成功**，但它的**证明**要求超临界气体的自由能，仍是 `[R]` ⇒ **指名的机制是循环的**。`[C]`

**唯一剩余动作（若还要走）：** 把 `φ_dec` 的**正性**（不是存在性）在 `ū=34` 上单独攻：即证 `φ_dec < κ` 而**不用**任何收敛级数——这是一个"变分上界 + 单调性"问题，不是展开问题。语料里尚无一字。`[NG]`（当前）
