## 1. `β(a)` 的精确形式（逐项核）

### 1.1 约定（不钉死这条，下面每个数都会错 `N²` 倍）

```

β_A := 2/(g²N) = β_W/N²（SZZ 的 β，作用量 (1.2) 里带 N；`1/48` 是这一套）
λ   := g²N = 2/β_A = 2N²/β_W
b₀ = 11N/(48π²) = 11N/(3(4π)²)，b₁ = 34N²/(3(4π)⁴)，b₁/(2b₀²) = 51/121（对所有 N）
```

（出处：`BETA-CONVENTION.md:13–21,64–70`；`A6-TARGET.md:43–45`；`U06-ZO.md:49`。`2.5` 是 `β_W`、`1/48` 是 `β_A`，二者**不同源**，本文件一律缀下标。）

## 2. 核心：`β<1/48` 给出的是**粗格点上的隙**

### 2.1 "除以 `a` 仍然 `>0`"为什么是零信息（`[T]`，本题最容易被读错的一步）

题面推理是对的（`m_lat>0 ⇒ m_lat/a>0`），但它**没有内容**，原因是：

```
固定 β 下 a 不是自变量：`u=c_f(β)/N` 无 a（F05 §1 #1），a 只经 (i) 单位换算 1/a^p、
(ii) 格点数 L/a 出现（F05 §1）⇒ 在固定 β 的语句里 `m_phys := m_lat/a` 是**同一个数的两种写法**。
⇒ 要把它变成有内容的物理解，必须**先知道 a 在 Λ 单位下的值**，即 aΛ(β)。
```
而 `aΛ(β)` 的**弱耦合**形式正是 §1.2 的两圈式——它在 `β_A=1/48`（`g²=32–48`）处**不可用**（见 §8-1）。非微扰地把 `aΛ` 钉住，就是搬运本身。
⇒ **"除以 `a`" 不是免费的一步，它把 `aΛ(β)` 的动力学（=搬运）当作前提。** `[T]`（逻辑）

### 2.2 反过来，I1/I2 的**形状**就把 `ξ/a` **封了上界**（`[T]`，本题的正向结论）

```
(a) 闭式版（主）：P3/X02 的强耦合质量 `m₁ = 4ln(1/u)/a`（`X02:131`、`F05 §1 #4`）
    ⇒ **`m₁a = 4ln(1/u)` 是不含 a 的纯数** ⇒ `a = (m₁a)/m₁`
    ⇒ 只要物理质量 `m₁` 有限，`a` 就有正下界；`ξ/a = 1/(m₁a)` 有上界。
(b) 数值版：`β_A=1/48 ⇒ u=0.0104`（`main.tex` M-2 逐字）⇒ `m₁a = 4·ln(96.15) = **18.26**`
    ⇒ `ξ/a = 0.055`：光态的康普顿波长是格距的 1/18 —— **态在 cutoff 上**。
(c) 形状判据（`RATE-UNIFORM:289–296` 命题 3，`[T]`）：
    任何"格点单位的正地板 `r`"都兑成 `ξ/a ≤ 1/r < ∞`；连续极限要 `aΛ→0 ⇒ ξ/a→∞`。
    ⇒ 二者在 `ξ/a` 轴上**严格相反**。
```
⇒ **强耦合窗在这条轴上说的是"`a` 不能小"，且不止不能小：态贴着 cutoff。**
（"`a` 很大"必须读成无量纲的 `a/ξ = m_lat = O(1)`——`a` 本身带量纲，单说"大"没有意义。这是本题唯一免于单位陷阱的写法。）
**诚实的一处**：I1 给的是 `f₁² ≥ r₀`（**残数**地板，非质量），形状同为"格点单位的 `a`-无关正数"，但**不能**单独兑成 `ξ/a` 的界——(a) 那一步只有 P3/`X02` 的质量闭式能给。`[T]/[M]`

### 2.3 两圈数字（`[E]`，只作量级核对，替换不了 2.2）

`β_A=1/48 ⇒ aΛ_lat = 0.484(SU2)/0.408(SU3)`，即 **`a ≈ (0.4–0.5)Λ^{-1}`**：格距是 `Λ` 倒数的一半。
它与 2.2(b) 的 `m₁a=18.26` 合起来只有两种读法，**两种都不给 `a→0`**：

```
读法 1（照本宣科）：把 m₁ 当物理质量 ⇒ m₁ = 18.26/a = 38Λ ⇒ 该态在 cutoff 上，是格点产物；
读法 2（坚持它是粒子）：那 a = 18.26/m₁，而 m₁ 若不 ≫ Λ 则 a ≫ 1/Λ ⇒ 极粗格点。
两者都以"离开 aΛ≲0.01 的外推窗 13–18×"为代价（§1.3），且 §2.2 的 ξ/a 上界对两种读法都成立。
```
⇒ 三条独立论证（集合论/单调性、I1/I2 的 `ξ/a` 上界、两圈数字）同判：**`β<1/48` = 粗格点。**

## 3. "在 `β<1/48` 上成立"与"沿 `β(a)→∞` 成立"是**两个问题**

### 3.1 形状不同（不是强弱不同）

| | 固定 `β<β₁`（I1/I2 现在给的） | 沿 `β(a)→∞`（C5 要的） |
|---|---|---|
| 量 | `m₁a = 4ln(1/u)`（纯数，与 `a,β,L` 无关的**格点单位**质量） | `m_lat/(aΛ) ≥ c₀`（⟺ `m/Λ ≥ c₀`） |
| `a` 的角色 | 不出现（单位而已） | 显式出现（右端 `∝a`） |
| 极限行为 | 常数地板 ⇒ `m_phys=m₁→∞`（若延拓到 `β→∞`） | `m_lat→0`（`∝aΛ`），`m_phys→CΛ` 有限 |
| 依赖的数学 | 逐面 KP 判据（`[T]`） | cutoff-一致重整化 + 无量纲比值地板（`[M]`） |

**两行不是同一个命题的强/弱版本：右列的右端是 `a` 的函数，左列没有 `a`。**

### 3.2 为什么"扩窗"不是"更难"而是"不一致"（`[NG]`）

```
若"格点单位的正地板"（如窗内的 m₁a ≥ r > 0，或 I1 的 f₁² ≥ r₀）对一切 β（含 β→∞）成立：
    m_phys = m_lat/a ≥ r/a → ∞
    ⇒ 固定物理间距的两点函数 ≤ e^{−rx/a}·(…) → 0 ⇒ 连续极限测度 ≡ 平凡
    ⇒ 与"极限是 4D 纯 YM"矛盾。
⇒ **把窗口扩到 ∞ 的读法在 AF 场景内自我否定**（`A5:91–96` 的 no-go；`RATE-UNIFORM` 命题 3 的推论）。
```
**⇒ 正确读法：扩窗 = 把右端从常数换成 `c·aΛ`（即让界**随 `a` 衰减**）。这一"换右端"就是搬运。** `[T]`
