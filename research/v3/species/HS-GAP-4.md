## §1 三条结构

### 1.1 `w₀` 只有两个输入（本文件全部结论的地基）
```
∀O（Hermitian、规范不变、标量）：w₁ = f₁²/M₀ ≥ 4r_O/W_O² =: w₀^{O}                     [T]
  ← M₀ = Var_μ(O) ≤ (sup−inf)²/4（Popoviciu，两原子等权取等；段 [6]）
  ← f₁² ≥ r_O（残数地板；本仓只有 O=¼trF² 有，r₀=¼(2N)^{-2}）
⇒ O=¼trF²：W=N、r₀=1/(16N²) ⇒ w₀=1/(4N⁴)（N=2..5：1/64,1/324,1/1024,1/2500；段 [1]）
```

### 1.2 两格拉锯（本文件的结构核心）
```
分母格  W_O 越小 ⇒ w₀ 越大。有界载体占优，且优势随 N 增长：
   1−½trP ：W=2（N 无关）⇒ M₀^max=1 ⇒ ×N²/4  （N=2/3/4：×1, ×9/4, ×4）       段 [4]
   ½trU  ：W=2, 9/4, 4（N=2,3,4）⇒ ×1, ×16/9, ×1                               段 [2][5]
   (¼trF²)²：W=N² ⇒ 反而 ×1/N²（N=2/3/4：1/4, 1/9, 1/16）                       段 [3]
分子格  r_O>0 的定理只有 P3，且逐字只对 O=¼trF²（Y02:80–88；§4 的 29 命中 0 条推广）
⇒ 两格不同时有值：改善分母的载体全丢分子；保住分子的载体分母已定
⇒ w₀=1/(4N⁴) 是本仓唯一"两格都有值"的格子                                    [T]
```
**限定**：这个"唯一"是**本仓知识状态**的陈述（检索见 §4.1 #2），不是数学上的唯一性定理；它的作用是说明"换载体"不会给出更便宜的数，而不是禁止将来出现第二个残数定理。

   有界成员 ⟺ 靶、无界成员严格强于靶 ⇒ 无成员严格弱于靶（HQ4:136–143）
