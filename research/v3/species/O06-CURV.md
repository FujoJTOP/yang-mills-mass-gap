## 1. `H_vv` 的精确式

### 1.1 一般格点（精确分解，`[T]`）

平坦图 `X_ℓ=log U_ℓ ∈ su(N)`，`U_p=∏_{ℓ∈∂p}U_ℓ^{ε_ℓ}`，`v=(v_ℓ)`，`X_ℓ↦X_ℓ+sv_ℓ`。记

```
W_p := (d/ds)U_p(s)|_{s=0} · U_p^{-1}        （图的"速度"，∈su(N)）
W_p' := (d/ds)W_p(s)|_{s=0}                  （connection / 单插入项）
U_p'' = (W_p' + W_p²) U_p                    （恒等式，因为 U'=WU ⇒ U''=(W'+W²)U）
```

⇒ **精确式**

```
H_vv ≡ ∂_v² S_W = -β Σ_p ½ Re tr(∂_v² U_p)
     = -β Σ_p ½ Re tr[U_p W_p']  -  β Σ_p ½ Re tr[U_p W_p²]
     = -β Σ_p ½ Re tr[U_p W_p']  +  β Σ_p ½ Re tr[U_p K_p],     K_p := H_p²,  H_p := -iW_p = H_p† ⪰0 算子
```

**这正是要的"`β × 几何因子 × 正性`"形**：

```
H_vv = β · Σ_p ½⟨ U_p , K_p ⟩_Re  −  β · Σ_p ½⟨ U_p , W_p' ⟩_Re ,   K_p ⪰ 0  （正性）
                                                                  U_p     （几何/单位模因子，唯一带号者）
```

- **正性**：`K_p = H_p² ⪰ 0`（`H_p` 厄米）。它由双插入给出，是"动能"块；`U_p=1`（纯规范）时 `H_vv=βΣ_p½‖W_p‖²_HS ≥0`。
- **几何因子**：`U_p`。`⟨U_p,K_p⟩_Re ∈ [−tr K_p, +tr K_p]`，**两端都可取到**（取 `U_p` 在 `K_p` 支撑上 `=−1` 即下端）。⇒ 一般情形 `H_vv` **不定**，且不是范数问题而是**对齐**问题。
- **第二块** `W_p'`：单插入/协变导数块（连续极限的 `2adF_B`），也不定。⇒ 一般情形只有
  `H_vv ≥ −β Σ_p ½ tr K_p − β Σ_p ½|Re tr(U_p W_p')|`，**且此界随 `β` 线性发散**（§4.4）。

### 1.2 秩 1 类：闭式（`[T]`，本文件的主结果）

模型（与 `H1A-EXACT §2.1` 同约定，逐字核）：`U=e^{ξ}`、`ξ∈R³`、`|ξ|<2π`、`B=e^{iθσ₃/2}`、
`S=β(1−cos(ρ/2)cos(θ/2)+sin(ρ/2)sin(θ/2)u)`、`u=ξ₃/ρ`、`J=sin²(ρ/2)/ρ²`、`Φ=−log J`；
切片 `ξ₃=0`（`v=e₃`，`a₀=0`）。

```
H_vv = β cos(θ/2) sin(ρ/2)/(2ρ)  =  (β/2) cos(θ/2) √J  =  β · cos(θ/2) · ¼ · sinc(ρ/2)
Φ''  = (dΦ/dρ)/ρ = 2/ρ² − cot(ρ/2)/ρ
```

**读法**：几何因子 = `cos(θ/2)`（真空对齐因子，`θ=π` 时**精确为零**）；正性 = `√J = e^{−Φ/2} ≥ 0`——**`H_vv` 的正性因子就是 Haar 密度的平方根**，不是别的东西。`sinc(ρ/2)=sin(ρ/2)/(ρ/2) ∈(0,1]` ⇒ `0 ≤ H_vv ≤ β/4`（`θ≤π`）。

**核验**（`w7/o06_hvv_bound.log` §[1]，中心差分 `s=1e-5`）：`θ=0,ρ=1.7`：FD `5.524159e−01` vs 式 `5.524121e−01`（rel `6.9e−6`）；`θ=1.1`：rel `6.1e−6`；`β=6,θ=0.3,ρ=2.9`：rel `3.0e−6`；`θ=π`：FD `−4.4e−6`（差分噪声）vs 式 `3.4e−17` ⇒ 两者都是 0。

### 1.3 一般方向的反例（`[C]`，`w7` §[4]）

4 link 单 plaquette，`v` 在图上**逐 link 同值**（"chart 常方向"），`v=iσ₃/2`，`β=2.5`，120 个随机图：

```
min H_vv = −1.893   max = +1.248    frac(H_vv<0) = 0.600
对齐 Re tr(U_p K_p)/tr K_p :  min = −0.267   max = +0.946   mean = +0.392   frac<0 = 0.05
```

⇒ **`H_vv` 在一般方向上确实不定**，且负号与"对齐因子 `<0`"同时出现（§1.1 的第二项）。**这是 Savvidy 不定性在平坦图+多 link 方向上的直接证据**，与 `λ_min(Hess S_W)=−g|B|<0` 同一机制。

## 2. `W_geo` 与 `H_vv` 是同一物吗？——**不是**

| | 定义 | 依赖 | 同一测度上的数值（单 plaq，`θ=π`，`β=2.5`） |
|---|---|---|---|
| `H_vv` | `∂_v²S_W`，Wilson 作用的 Hessian | `S_W`（∝`β`） | **`0`（精确）** |
| `W_geo` | `E[Φ'']−Var(Φ')`，**纯 Haar 边缘**的曲率 | 只 `Φ=−log J`（`β`-无关） | **`0.2051153`** |
| `Φ''` | `Hess(−log J)` 的 `vv` 分量 | 只 `Φ` | `0.2051153`（此切片 `Var(Φ')=0`） |

**判**：`W_geo` 是 `Φ` 的泛函（Jacobian 边缘的 log-凹模量），`H_vv` 是 `S_W` 的泛函；秩 1 类里 `H_vv ∝ √J = e^{−Φ/2}` 而 `W_geo ∝ (log J)` 的曲率——**一个是密度的平方根，一个是对数的二阶导**。数值上同一切片上 `H_vv≡0` 而 `W_geo=0.2051` ⇒ 两个不同对象，[T]+[C]。

**`eq:wgeo-quant`（`ch05:214–228`，`W_geo ≥ (N/12)‖v‖²`）能否直接用在 `H_vv` 上？——不能，而且不需要**：

1. 它的**主语是 `W_geo`**，不是 `H_vv`；把它搬到 `H_vv` 上是**换对象**（本仓库 `GPP-STRUCT §7.2` 记的"`W_geo` 用条件化 Wilson 期望写、Prékopa 证在纯 Haar 上"的缝隙，正是这一条）。
2. 它其实**已经是**"`Φ''` 下界 + `Var(Φ')`"的合成：`W_geo = E[Φ''] − Var(Φ') ≥ λ`。真正能逐项用的是它的**点态前提**：**`Φ'' ⪰ λ`（Lemma B）**，见 §3。
3. **数值核准 `eq:wgeo-quant` 本身**：`θ=π,β=2.5` 切片上 `W_geo = E[Φ''] = 0.2051153`（与 `H1A §2.1` 存档逐位一致，7 位），`N/12=0.1666667` ⇒ 余量 `+23.1%`，**不等式成立** `[C]`。

## 3. `Φ''` 的下界：显式、点态、与 β/测度无关

### 3.1 来源（`[T]`）

`Φ = −log|c_SU(N)/c_flat|²`（c-函数/Weyl 分母交叉恒等式，`hc_spherical.py:17–18`，机器精度 `8.5e−16`）⇒ 在 Cartan 上 `Φ = Σ_{i<j} g(λ_i−λ_j)`，`g(d) = −2log(sin(d/2)/(d/2))`。

```
g'(d)  = -cot(d/2) + 2/d
g''(d) = ½ csc²(d/2) − 2/d² ,      g''(0⁺)=1/6 ,   g'' 在 (0,2π) 上单调增  ⇒  g'' ≥ 1/6
```

⇒ `Hess Φ[v,v] = Σ_{i<j} g''(λ_i−λ_j)(m_i−m_j)² ≥ (1/6)Σ_{i<j}(m_i−m_j)²`。用 `tr T^aT^b=½δ`（`‖v‖²=Σ_a(v^a)²`）与 Cartan 关系 `Σ_{i<j}(m_i−m_j)² = N·½‖v‖²`：

```
Φ'' ⪰ (N/12)‖v‖²   > 0     点态，任意 ξ、任意 β、任意测度      [T]
```

`SU(2): 1/6`、`SU(3): 1/4`（与 `ch05:207–209` 的 Lemma B 常数逐字一致）。

**横向（非 Cartan）方向同样成立**：`Φ` 在 `ξ=0` 附近是径向函数，`Φ''_⊥ = g'(ρ)/ρ = 1/6 + ρ²/360 + … ≥ 1/6`。

### 3.2 数值核验（`log` §[2]）

```
inf_(0,2π) Φ'' = 0.16666603  at ρ→0     （N/12=1/6=0.16666667；差 4e−7 = 求积分辨率）
Φ''(ρ) at ρ=2,3,4,5,6 = 0.178954, 0.198584, 0.239414, 0.347730, 1.224764  （单调增，全 ≥1/6）
FD vs 闭式: ρ=0.5 → 1.6736834e−01 vs 1.6736527e−01（rel 1.8e−5）
```

⇒ **`Φ''` 的下界取 `(N/12)‖v‖²`，不取 `0`。** `[T]`

### 3.3 量纲（逐项）

- `S_W`、`Φ` 无量纲（格点单位，`β` 无量纲）⇒ `H_vv`、`Φ''` 的量纲是 `1/[ξ²]`；`J d³ξ` 无量纲 ⇒ `√J` 量纲 `1/[ξ]`，与 `H_vv=(β/2)cos(θ/2)√J` 的 `1/[ξ]` **不符**——因为该式是 `∂²/∂ξ₃²` 在 `ρ` 有量纲的图上写的，`J=sin²(ρ/2)/ρ²` 中的 `ρ` 已按 `ξ` 的单位无量纲化。**结论：本文件所有式子都在"`ξ` 无量纲（`a=1` 格点单位）"下写，`H_vv`、`Φ''` 均无量纲。**
- 不等式两边**都是 `v` 的二次型**：`H_vv+Φ'' ≥ (N/12)‖v‖²` 的协变写法是 `⟨v,Hess(S_W+Φ)v⟩ ≥ (N/12)‖v‖²`，`v→λv` 两边同阶 ⇒ 与 `v` 的归一化**无关**；文中 `H_vv` 一律指 `‖v‖=1` 的 `⟨v,Hess v⟩`。**不得**把 `(N/12)` 读成物理质量（`H1A §1.4`/`ch03 sec:dim`：`G''_a=a²m²`）。

### 4.2 与 O05 的方差上界一比（**H1 的定量窗口**）

`H1A §1.3`：`H1(δ) ⟺ Var(G_v+Φ'|0) ≤ E[H_vv+Φ''|0] − δ`。用 §4.1 的可证地板：

```
H1 的充分条件：Var(G_v+Φ'|0) ≤ (N/12)‖v‖² − δ
```

在秩 1 类里 `Var = β²V₀`、`V₀=0.0110593`，故地板路线关闭的**阈值**：

```
β_c(floor) = sqrt((N/12)/V₀) = sqrt(0.1666667/0.0110593) = 3.882
β*（H1 自身的零点，H1A）= 4.30661        ⇒  3.882 < 4.307
β_phys = 2.4–2.5                          ⇒  余量 1.55×（Var/floor = 0.415 at β=2.5）
```

⇒ **在单 plaquette 类里，"曲率地板 `(N/12)‖v‖²` + 方差上界"这条链把 H1 证到 `β ≤ 3.882`，覆盖物理点、窄于 H1 真值域 `β*`。** 这是 (a) 的定量内容：地板的 `β`-无关性（`Φ''≥N/12`）配上 `Var` 的 `β²` 增长，交叉点 `3.882`。

### 4.3 `E[H_vv|0]` 的数值（判期望是否为正）

- `θ=π`（Savvidy 点，最大 holonomy、`c=0`）：`E[H_vv|0] = 2.74e−17` ⇒ **精确 0**（`[T]`：`cos(θ/2)=0`），与 `H1A` 的 `E[H]=0` 精确一致。
- `θ=0`（对齐真空）：`β=2.5 → +0.5531`；`β=β* → +0.9984`；`β=6 → +1.4200` ⇒ **随 β 单调增、`∝β`**（`H_vv∝β` 的直接体现）。
- `θ=π/2`：`β=2.5 → +0.3773`。
⇒ **期望在秩 1 类上确实 ≥0，但在 Savvidy 点恰好为 0**：期望救不了曲率侧——最坏点不是"平均为负"，而是"平均恰为零"。

### 4.4 一般方向（**(c)**，`[T]` 下界 + `[C]` 反例）

```
E[H_vv+Φ''|0] ≥ (N/12)‖v‖² − β·E[C_geo|0],      C_geo := Σ_p[½ tr K_p + ½|Re tr(U_p W_p')|] ≥ 0
```

`C_geo ≥ 0` 且 `∝β`，右端**不保证正**；`β` 越大越负。加上 §1.3 的 `min H_vv = −1.893`（`β=2.5`、`Σ_ℓ‖v_ℓ‖²=2` ⇒ 归一化 `H_vv/(βΣ‖v‖²) = −0.378`）⇒ **一般格点上曲率侧没有点态正地板**，唯一可证的是上面这条**负的、`β`-线性**的界。

## 6. 未闭合（诚实标注）

1. **一般方向的 `(a)` 未证也未反**：§1.3 只是 `[C]`（120 个随机图、一个方向族）。要把它升成 `[NG]` 需要一条"对齐因子在物理测度下可取负"的结构定理；要救 (a) 则需要一条"物理粗模的 `v` 落在 `K_p` 的 `U_p`-正锥里"的陈述——两者都没有。**这是精确缺失的一步。**
2. **`β_c(floor)=3.882` 是秩 1 类的数**（用了 `Var=β²V₀`）；一般格点上 `Var` 的 `β`-标度未定，故"地板+方差 ⇒ H1"的窗口宽度在一般情形未定。
3. **`W_p'` 块没有独立控制**：`|Re tr(U_pW_p')|` 只能给 `‖·‖₁` 型粗界，`β`-线性发散；要收紧必须用场强有界（`|F|≲1/a²`），本文件未做。
4. **`‖v‖²` 归一化**：本文件用 `tr T^aT^b=½δ`、`‖v‖²=Σ_a(v^a)²`，此时 Cartan 恒等式 `Σ_{i<j}(m_i−m_j)²=N‖v‖²/2` 给出 `(N/12)‖v‖²`，与 `ch05` 的 `SU(2):1/6, SU(3):1/4` 逐字一致；换归一化则该常数整体改标度（`AGENTS.md §2.1`：数值结论必须带窗口/归一化）。
