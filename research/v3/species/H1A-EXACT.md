## 0. 判死线（先读这段）

**结论：H1 在可解类上不是"全真"。有一个模型上 H1 以 `δ<0` 成立——H1 被证伪，但只在 `β > β* = 4.30661` 的区间；物理点 `β=2.5` 在安全侧。另有一个模型上 H1 退化（`δ→0`）。**

|---|---|---|
| 1. 单 plaquette `SU(2)`，`θ=π`，`β=2.5` | `δ = +0.135995` | (a) 真 |
| 1′. 单 plaquette `SU(2)`，`θ=π`，`β=6` | `δ = −0.193019` | **(b) H1 假** |
| 1″. 单 plaquette `SU(2)`，`θ=π`，`β=β*=4.30661` | `δ = 0`（精确） | (c) 退化 |
| 1‴. 单 plaquette `SU(2)`，`θ=0`，任意 `β` | `δ ≥ 0.2909` | (a) 真 |
| 2. 2D YM（Migdal/热核精确） | `δ ≥ +2.0102` | (a) 真 |
| 3. P4 周期核 `β=2.5` | `δ = +0.22196 ± 0.00011` | (a) 真（`L`-一致） |
| 4. 1D Dirichlet 弦 | `δ = π²/L² → 0` | **(c) 退化** |

- **(b) 成立的范围必须精确**：证伪发生在单 plaquette 的**高 β**区（`β>4.30661`，固定 `θ=π` 边界 holonomy）。物理点 `β_W=2.4–2.5` 在 `β*` 以下，`δ=0.136>0`。所以论文 H1（固定物理 `β`、`(L,a)`-一致）**没有被这四个模型推翻**；被推翻的是更强的读法"H1 对一切 `β`／一切真空点成立"。证伪的机制是**精确的 Savvidy 凹性**（见 §2.3），这决定了 H1 的证明必须依赖"条件化点落在哪一个真空里"——不是免费的方差估计。
- **(c)** 有两处：1D Dirichlet 弦的 `δ=π²/L²→0`（IR 无余量），以及单 plaquette 在 `β*` 处的精确零点。
- **(a)** 两处：2D YM（`δ≥2.01`，对 `t=g²A/2` 一致）与 P4 周期核（`δ=0.222`，对 `L` 一致）。

**结构发现（比逐模型数字更重要）**：`Var = 0` 且 `E[H] = 0` 在模型 2、3、4 里是**精确恒等**（粗模是 `S_W` 的平坦方向或 Gaussian 本征模，`G≡0` 或 `G` 只依赖被条件化的坐标）。所以这四个模型里 H1 的全部内容都在 Jacobian/Haar 项 `W_geo` 上，**方差与 Hessian 两侧同归于零**。H1 的"方差"半边只在模型 1（非平坦、非 Gaussian）上是非平凡的。这正是论文"floor 由 Haar/Brascamp–Lieb 承载、不由 rank-one 承载"的可解版本 [T/C]，也正是"H1 必要但不充分"的可解证据。

## 1. 定义核准（**不凭记忆**，逐条给论文出处）

### 1.1 H1 的精确形式

`docs/paper-v2/ch08-immune.tex:11–19`（式 `(M)`，label `eq:species`）：

```
(M)   Var_μ(⟨v,∇S⟩ | 0)  ≤  E_μ[H_vv | 0] + W_full − δ ,   对 (L,U') 一致
      W_full := W_geo + X
```

`docs/paper-v2/app.tex:179–202`（`app:sharp`，"the sharpest form, with no slack"）：同一不等式的无余量形式
`Var_μ(⟨v,∇V⟩|ξ=0) ≤ E_μ[H_vv|ξ=0] − a²Δ₀²`，`V=S_W+Φ`，并明写
`δ := a²Δ₀² + W_full`——**两式是同一个不等式**。任务里用的 `(M)` 形式以此为准。

### 1.2 三个量的定义（逐项）

| 量 | 定义 | 出处 |
|---|---|---|
| `W_geo` | `E[Φ''] − Var(Φ')`，`Φ = −log J`，`J` = 平坦图 `X=log U` 的 Haar Jacobian（`dU = J dX`） | `ch05-theorems.tex:196–206`（式 `eq:wgeo`）；`app.tex:795` |
| `X` | `−2 Cov(G, Φ')`，`G = ⟨v,∇S_W⟩` | `ch05-theorems.tex:230–239`；`app.tex:796` |
| `H_vv` | `Hess V` 的 `vv` 分量，`V=S_W+Φ`；**条件化**纤维 Hessian `K=Π₀ Hess V Π₀` 才是符号所在 | `ch13-machine.tex:58–82` |
| `Var` | `Var_μ(⟨v,∇S⟩ | ξ=0)`，**条件化**（不是无条件方差） | `ch08-immune.tex:13` |

### 1.3 关键恒等式 → H1 的等价刻画 [T]

`ch05-theorems.tex:230–239`（`eq:split`）、`ch03-existence.tex:129–134`、`ch13-machine.tex:69–73`：

```
G''(0) = E[H_vv|0] − Var(⟨v,∇S⟩|0) + W_geo + X = E[H|0] − Var(G|0) + W_full
```

移项（**代数恒等，不依赖模型**）：

```
Var − E[H] − W_full  =  − G''(0)
⇒  H1(δ)  ⟺  G''(0) ≥ δ        （逐点、逐模，精确）
```

**这是本次任务的操作核心**：`δ` 的符号 = 条件化曲率 `G''(0)` 的符号；`δ_max = G''(0)`。所以在任何可解模型上，"检验 H1"就是"精确算 `G''(0)`"。**没有独立的方差不等式可证或可反**——H1 的全部信息量在曲率符号里。（论文自己在 `ch08-immune.tex:19` 说"the display is then `G''≥δ` in curvature form"，此处只是把它当作判定工具用到底。）

### 1.4 量纲纪律 [T]

`ch03-existence.tex:146–165`（`sec:dim`）：`G''_a = a² m_phys²`；**"固定 `a` 下 `G''_a ≥ λ`、`λ` 为正常数"是量纲错的**，正确目标是 `G''_a/a² ≥ Δ₀²`。故本文所有 `δ` 均为**格点单位下的曲面下界**（无量纲），其 `(L,a)`-一致性正是未闭合处；不得把它们读成物理质量下界。

### 2.1 模型 1：单 plaquette `SU(2)`，`β` 任意（精确）

**模型**（与 `research/v3/species/w7/na_plaquette.py` 同约定）：`U = exp(ξ)`，`ξ ∈ R³`，`|ξ| < 2π`；边界 holonomy `B = exp(iθσ₃/2)`；`S = β(1 − cos(ρ/2)cos(θ/2) + sin(ρ/2)sin(θ/2) u)`，`u=ξ₃/ρ`；平坦图测度 `e^{−S} J d³ξ`，`J = sin²(ρ/2)/ρ²`，`Φ = −log J`。取 `v=e₃`，条件化 `⟨v,ξ⟩ = a₀ = 0`。

两个精确的解析化简（`a₀=0` 切片上 `u=0`、`ρ'=0`）：

1. `Φ` 径向 ⇒ `Φ' ≡ 0` 在切片上 ⇒ `Var(Φ')=0`、`X = −2Cov(G,Φ') = 0`。
2. `ρ'=0` 且 `u''=0` ⇒ `H_vv = β c sin(r/2)/(2r)`，`c = cos(θ/2)`。**`θ=π` 时 `c=0`，故 `E[H]=0` 精确为零**（不是数值小量）。

**`θ=π`（`B = iσ₃`，真空在 `ξ₃=−π`，远离条件化点）**：切片上 `S ≡ β`（与 `r` 无关），测度**恰为 Haar**，故

```
E[H] = 0 ,  W_geo = 0.2051153 (β-无关) ,  X = 0
δ_max = G'' = 0.2051153 − 0.0110593 β² ,   零点 β* = sqrt(W₀/V₀) = 4.30661
```

### 2.3 为什么模型 1 的证伪就是 Savvidy 凹性 [T]

`θ=π` 时 `S = β(1 + sin(ρ/2) u)` 只含 `u=ξ₃/ρ` 的**一次项**：条件化点 `ξ₃=0` 不是极小点（极小在 `ξ₃=−π`）。同一切片上 `S` 与 `r` 无关 ⇒ 测度是 Haar ⇒ 弯曲只能来自 Jacobian，而 `β²` 方差项把 `G''` 拉负。即：**"条件化点处的曲率" = "该点的稳定/不稳定"**。这与 `CLAUDE.md`§5 记录的墙完全同型：`Hess −D²+2adF_B` 不定、W4 实测 7.1% 负模。可解模型给出的是它的**精确标量版本**：`δ<0 ⟺ 真空不在条件化点`。

推论（对本战役的意义，[NG] 型约束，非 Clay 反证）：
**任何"对一切真空/一切 `β` 都成立"的 H1 证明路线必然失败**；H1 的证明必须携带"真空选择"信息（即 `Φ''`／`W_geo` 的符号控制），否则在 `β>β*` 上被这个 3 维模型一行反例打穿。这与语料"H1 需要 `Q`-无关的源、即量纲 transmutation"的判断同向，但把"必要性"从口号变成了可算的反例。

### 2.6 模型 4：1D Dirichlet 弦（`honey` 代码；语料 `dt_dirichlet.py`）

**模型**：自由（Gaussian）弦，`S = ½ φᵀKφ`，`Kv = λv`，Dirichlet ⇒ `λ = π²/L²`（最低模）。平坦坐标无 Jacobian ⇒ `Φ ≡ 0`。

精确：`G = ∂_v S = λξ`，`H = ∂_v²S = λ`；`G` 只依赖被条件化的坐标 `ξ` ⇒ **`Var(G|ξ=0) = 0` 精确**。故

```
Var = 0 ,  E[H] = λ = π²/L² ,  W_full = 0 ,  δ_max = π²/L²
Var − E[H] − W_full = −π²/L² ≤ 0  ⇒ H1 对每个 L 成立，但 δ = π²/L²
```

## 4. 裁决

1. **(b) 部分成立，但范围必须精确。** 单 plaquette `SU(2)`、`θ=π` 边界、`β>β*=4.30661` 上 `H1` 以 `δ<0` 成立——**这是精确反例，不是数值**：`δ_max = 0.2051153 − 0.0110593 β²`。物理点 `β=2.5 < β*`，`δ=+0.136`。故论文 H1（固定物理 `β`、`(L,a)`-一致、每个粗模）**未被推翻**；(b) 打掉的是"`β`-一致/真空无关"的强读法。机制 = Savvidy 凹性（`Hess` 不定）的精确 3 维实现。
2. **(c) 有两处。** 1D Dirichlet 弦 `δ=π²/L²→0`（IR 无余量，必须走周期核）；单 plaquette 在 `β*` 处精确零点。前者解释了语料"决定性情形是周期环面"的选择，后者说明 H1 的常数与真空稳定性同源。
3. **(a) 有两处，且都是 Haar 承载。** 2D YM `δ≥2.01`（`t`-一致）；P4 周期核 `δ=0.222`（`L`-一致，正截距）。但两者都满足 `Var=E[H]=0`：**余量全部来自 `W_geo`，与相互作用项无关**——这正是"H1 必要但不充分"的可解证据，也复现了 `β=0` 时 `G''=0.2688` 而 `f₁²=0` 的盲点。
4. **战役目标要不要重写：不要重写 H1 本身，要重写"常数"的语义。** 四个模型一致指向：`δ` 不是可自由选择的正数，它**就是** `G''(0)`；H1 的内容因此全部在"如何证明 `G''(0)≥a²Δ₀²` 且该点在有隙真空上"。可解类给出的支撑是：`W_geo≥0`（已证 [T]）+ 平坦/Gaussian 模上 `Var`、`E[H]` 精确同归于零 ⇒ 该情形下 H1 自动成立；缺口恰好是**非平坦、非 Gaussian、且条件化点不在有隙真空**的那一格，与 `ch13-machine.tex:49–56` 的"最后一格 = typical field × high momentum"是同一格。
