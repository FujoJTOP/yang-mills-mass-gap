## §1 `q` 与 `q^ren`（逐字定义；`a⁻⁴` 从哪来；是否同一对象）

**1.1 逐字。** `q_x := 1 − N⁻¹Re tr U_{□_x}`，`q ∈ [0,2]`（`HZ6-ZDEF:23`·`HZE-ZUB:24`·`HZF-COV:26`·`DDD3-NB:21`；等价 `1−N⁻¹Re tr U_p ∈ [0,1+1/N]`，`D05-FKG:128`）。物理密度 `δ_a tr F² := a⁻⁴q`、`O := δ_a tr F²` ⇒ 逐字 `‖O‖_∞ = 2a⁻⁴`（`HZE-ZUB:24`、`AA1-OS0:38`）。

**1.2 `q` 与 `¼trF²` 是同一对象（差有限常数）。** `O = ¼trF² ∈ [0,N]` 逐点（`D05-FKG:128` 逐字"`O = ¼trF² ≥ 0` 逐点"；`HZ1-PLATEAU:76` 给 `O∈[0,N]`），而 `q ∈ [0,2]` ⇒ 同算子、`q ↦ (N/2)q` 的有限标度；**幂完全由 `a⁻⁴` 承担**，有限常数不改幂。⇒ 不是两个对象。

**1.3 `a⁻⁴` 三重独立定值（`[T]`，`DDD3-NB:0.1,1.2`）。** ① 量纲：`[trF²]=4`、格点量无量纲 ⇒ `O=a⁻⁴O_lat`（`U4:110,117`）；② 对角/接触：`Var(⨏_B O)` 的对角 `=C(0)/N_B=4b̂⁻⁴a⁻⁴`（`HX3:43`）；③ 归一：`a⁻⁴` 恰是 `(U2)` 的**唯一**接触减除层（`A2:6`）。⇒ 该幂不是估计。

**1.4 `q^ren` 的定义是恒等。** `q^ren := q/(a⁴·trF² 的领头系数)`：因 `trF² 的领头 = a⁻⁴`，故 `q^ren = q` —— **与 `a` 无关，无 a-依赖可讨论**。检索：`q\^\{?ren|q_\{?ren` @ `research/**/*.md` → **命中 1**（`unconditional/PROOF-STEP-SCALING.md:3` 的 "renormalized observable"，与 `q` 无关），仓内从未把 `q^ren` 立项。⇒ **"换问法"= 现状重述**。

## §2 `q^ren` 是否 bounded；那个 `a⁻⁴` 是可观测量的还是矩的

**2.1 有界 [T]、恒真、且语料已判"不得记作成果"。** `|q|≤2` ⇒ 一切矩 `|E[qⁿ]|≤2ⁿ`，`C_n=2ⁿ` 自动满足 `(U3)` ⇒ `UVS` 免费 —— 但这是**有界类**（GL3-B）：`glue-a-limits:77,94` 经 `HQ1-L3:122` 判「紧性 = Tychonoff 免费、常数 = 1、**不得记作成果**」，`AA1-OS0:37` 逐字同判，`GGG2-COMPACT:33` 称"空洞"。⇒ 恒真 `[T]` ≠ 有内容。

**2.2 三处不匹配（`[T]`）。** (i) **标度**：`q` 的矩幂 `a⁰`，靶的幂 `a⁻⁴`，差**恰一个 `N_B=(b̂/a)⁴`**（`CCC5-V:0.4`·`DDD3-NB:0.2`）。(ii) **类**：`L3` 的类含**无界重正化多项式**（`HQ1-L3:78`）；有界类 `B1^fin` 只覆盖 `‖A_i‖_∞≤1` ⇒ 不销 `L3` 的账（`HY1-B1:0.4`）。(iii) **层级**：`q` 是**单格点**量；`Z_a := Var_μ(⨏_B δ_a trF²)` 是**块平均**（`N_B` 位点）的方差（`HZ6-ZDEF:41–44`）。

**2.3 精确代换（`[T]`）：`a⁻⁴` 在两处同名不同源。** 写 `Z_a = a⁻⁸·W`、`W := Var(⨏_B q)`：
- **不动靶**：`Z_a ≤ Ca⁻⁴ ⟺ W ≤ Ca⁴ → 0` —— 不是 `W ≤ C`；
- **写成 `W ≤ C`**：那是 `Λ⁰` 界 ⇒ `Z_a ≤ Ca⁻⁸`，即裸 C–S 界 `4a⁻⁸`（`CCC5-V:0.4`；计数形 `64a⁻⁸`，`DDD3-NB:3.2`）⇒ **比靶弱 4 个幂**。
⇒ 可观测量侧的 `a⁻⁴` 是**量纲**（进方差成 `a⁻⁸`）；靶侧的 `a⁻⁴` 是**矩的幂**，其来源是 `a⁻⁸ × N_B⁻¹(块平均 ≍ a⁺⁴)`，**只能由去相关付**。除前者不产生后者。

**2.4 拆开（`[T]`）。** `ϖ := a⁴b̂⁴Z_a = Var(q) + O_B`、`O_B := N_B⁻¹Σ_{z≠0}n_B(z)C_q(z)`（`HZF-COV:1.1`）。对角 `Var(q) ≤ 1` **就是"除掉 a⁻⁴"能买到的全部**，且它**已带靶幂** `4b̂⁻⁴a⁻⁴`（`DDD3-NB:0.4`）⇒ 靶 ⟺ `O_B ≤ C − Var(q)`（`HZF-COV:0.3`·`CCC5-V:1.2③`）。

**2.5 有界性到不了靶（`[T]`，形式级）。** 取块内**全相关**族 `q_x ≡ q`（取值 `[0,2]`）：`|q|≤2` ✓、所有矩 `≤2ⁿ` ✓，而 `C_q(z) ≡ Var(q)` ⇒ `O_B = N_B−1`、`ϖ = N_B → ∞`（`DDD3-NB:3.4`）。⇒ 凡只吃「`q∈[0,2]` 的边际 + 计数」的论证**都在这族上成立**，而该族上靶假 ⇒ 「bounded ⇒ 所有矩 `≤2ⁿ` ⇒ 解决」是**推理形式无效**，不是"缺供给"。已知供给：KL/谱界停在 `a⁻⁶`（相对靶差 2 幂，`DDD3-NB:3.3`，引 `YY3:23`）；计数相消停在 `a⁻⁸`（`DDD3-NB:3.2`）；正性方向**反**（`O_B ≥ 0`，`HZF-COV:0.6`）。

**2.6 答"`q^ren` 真的 bounded 吗 / 还是随 `a` 发散"。** 两个都不是：`q^ren ≡ q` 与 `a` 无关。**第二个发散源确实存在，但不在 `q^ren` 上**，而在块内 `≍N_B` 个位点的协方差和 `O_B`（`|O_B| ≤ N_B−1`，`HZE-KIN:0.3`）—— 这正是 `L3` 缺的那一幂。

## §3 判定

**3.1 `ren` 形不构造性成立（`[NG]`）。** 理由一行：它把 `L3` 换成一个**恒真空洞**（有界类，常数 `1`，语料判"不得记作成果"）或一个**逐字重写**；"bounded ⇒ `2ⁿ`"只覆盖对角那一项，而该项早被记为"免费第一份"（`HZF-COV:0.2`·`CCC5-V:1.2①`）。

**3.2 「换问法就解决了」不成立（`[NG]`）。** 真正的换问法**已经做过**（`δ_a trF² := a⁻⁴q`）。现状的残余是一个纯数 `O_B ≤ C − Var(q)`（`HZF-COV:2.1`）⇒ 靶没动，只换名。

**3.3 唯一"构造性成立"的正面事实属于别的类（`[T]`，但不可记功）。** 有界类上 `UVS` 免费、常数 `1`；而 `L3` 的类含无界重正化多项式（2.2(ii)）⇒ 该 `[T]` **不转移到** `L3`。

**3.4 下一手（两条，均非新）。** ⑤ 窗内 `ℓ¹`：`Σ_{0<|z|<b̂}|C_q(z)| ≤ C`（= `(V)`；`HZF-COV:2.3`、`HZG-BLOCK:0.1`），塔底 `β≈2.5` **未付**；⑥ 一致 `ρ_P`：`ϖ ≤ 144c₁²/ρ_P`（`HZF-COV:2.5`），不吃衰减但**= 墙/H1**。任一到手 ⇒ `O_B` 有界 ⇒ `ren` 形与 `L3` **同时**成立；在此之前 `ren` 形不是独立路。
