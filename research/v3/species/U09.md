## §1 · 「无格序」的精确含义（第 1 条）

### 1.1 三条腿（每条独立，`N=2` 也逃不掉）

1. **群论腿 `[T-std]`**：格序群无挠（orderable ⇒ torsion-free，Navas 讲义摘要级 `[B]`；`D05-FKG:88`）。`SU(N)`（`N≥2`）紧 ⇒ 含中心 `Z_N` 的有限阶元 ⇒ **无左/右不变全序**；极大环面 `U(1)^{N−1}` 是环面不是链，`U(1)` 只有**循环**序（`PROOF-COMPARISON-FKG:5` 逐字）。
2. **函数腿 `[T]`**：`V ↦ N^{-1}Re tr(UV)` 在 `V=U†` 取 max `1`、在对径侧取 min `−1/N`（`SU(2)` 为 `−1`）⇒ 不存在使 `Re tr U_p` 单调的群相容序（`D05-FKG:89`）。**而 FKG 的前提正是"密度 log-超模于某个坐标单调序"**（FKG 原摘要："increasing functions on a finite distributive lattice"，`GPP-STRUCT:110`）。
3. **超模腿 `[T]`**：Wilson 权 `e^{−S_W}` 是 `tr U_p` 的**类函数**，在共轭轨道上平坦；面/涡旋表示侧的权是 **Weingarten 带号** ⇒ 无正 Gibbs 测度 ⇒ 无 FKG（`D05-FKG:90`；`AREALAW-GAP:11`）。

### 1.2 关键澄清：「有偏序」与「有 FKG」是两件事

`SU(N)` 上**真实存在**的偏序至少四条，但它们全都**不是** FKG 需要的那条：

| 偏序 | 存在性 | 为何不够 |
|---|---|---|
| **Loewner 算子序** `K_β ⪰ K_{β'}` | **是**（见 §2.1，本轮升为 `[T]` 全 `N`） | 作用在**未归一化**本征值上；`T_β = D^{1/2}KD^{1/2}` 的 `D_β` 逐点**递减** ⇒ 全 `T_β` 无序；即便有序也只传本征值，不传归一化核与本征向量（`D05-FKG:70–82`） |
| **对偶侧优势序** `λ ⊳ μ`（特征标） | **是**（`INVENT-SECOND-CONE:5`） | 不是"配置空间的积序"；且只承 `c_λ≥0` 这种**基正性**，`PROOF-COMPARISON-FKG:3` 逐字："Positive character coefficients are **basis positivity, not association**" |
| **Weyl 偏序**（`N≥3`）/ 单 plaquette `N=2` 全序 | 是（`N=2` 有 Sturm 全序） | 见 1.3：**嵌套**导致酸测真空 |
| **Gantmacher–Krein 符号变号序**（`K_n`） | 是（`INVENT-SECOND-CONE:7–9`） | 同上：`K₀⊂K₁⊂…` 层层包含正锥 |

### 1.3 ★ 比"无格序"更狠的一条：**嵌套**（`INVENT-SECOND-CONE`，`[NG]`）

Gantmacher–Krein/Karlin 锥是**递增嵌套**的：`K₀⊂K₁⊂K₂⊂…`，而**自由场严格为正**（正核 ⇒ 零符号变号）⇒ 自由场在**每一个** `K_n` 的**内部**。⇒ 任何"正锥/符号变号锥"式论证在**最该失效的地方（自由场，`w₁=0`）也成立** ⇒ 过不了宪章 §1 的酸测。**这是"无格序"之外的独立第二刀**（`INVENT-SECOND-CONE:13,15` 逐字："nesting, stronger than orderlessness"）。

⇒ **对第 1 条的准确回答**：`gap3` 的话对，但只说了一半。`SU(N)` 不是格序群（三条腿），**且**它能提供的每一条偏序都（i）不与群作用/单调性/超模性同时相容，或（ii）嵌套在正锥之上而酸测真空。**"无格序"不是可修补的技术缺口。**

## §2 · 有什么别的关联不等式（第 2 条，逐个给作用域）

### 2.1 ★ 真的一条：对偶侧 Griffiths/Bochner 正性（`[T]`，本轮新增两条结论）

**陈述 `[T]`。** 写 `e^{(β/N)Re tr U} = Σ_r c_r(β)χ_r(U)`（`χ_r(𝟙)=dim r`）。因 `Re tr U = ½(χ_f + χ_{f̄})`，而**特征标乘积按张量积重数展开、重数是非负整数**：

```
c_r(β) = Σ_{m≥0} (β/2N)^m/m! Σ_{a+b=m} C(m,a) m_r(a,b),   m_r(a,b)=dim Hom(r, f^⊗a⊗f̄^⊗b) ∈ Z_{≥0}
⇒  c_r(β) ≥ 0  ∀r ∀β≥0,   且  ∂_β c_r ≥ 0（Taylor 系数全非负）                    [T]
```

（`P3-FULLREP-KP:40,44` 的 `(★)` 逐字给出同一式并标 `[T]`；`SIGNED-FOURIER-BUILD:20` 引 Drouffe–Itzykson `c_r>0`；`INVENT-SECOND-CONE:5` 引 Littlewood–Richardson。三处独立同判。）

**推论 A `[T]`（本轮新）**：`χ_r(UV†)` 是正定核（`χ_r` 正定：`χ_r(g)=tr ρ(g)`）⇒ `K_β − K_{β'} = Σ_r (c_r(β)−c_r(β'))χ_r(UV†)` 是 PSD 之和 ⇒
```
K_β ⪰ K_{β'}   (β>β'≥0),   任意 N 。                                            [T]
```
**这把 `D05-FKG:69` 的「`SU(N≥3)`：`c_r` 的 β-单调性 —— 无定理 `[NG]`」升级为 `[T]`。**

**推论 B `[T]`（`[V]` 复核）**：单 plaquette `⟨χ_r⟩ = c_{r̄}/c_0 ≥ 0`，且对 β 非降。**这是真 Griffiths 型单调性，作用在期望层。**

**★ 已知边界（不改任何判词）**：这条正性**严格地也成立在自由场**（热核 `c_R = d_R e^{−tC₂(R)} > 0`，`SIGNED-FOURIER-CORE:59`），**而自由场 `f₁²=0`** ⇒ 任何由它推出的 `w₁` 命题在自由场也成立 ⇒ **真空化**（`SIGNED-FOURIER-CORE:63` 逐字判过）。这正是它触不到 `w₁` 的**结构性**理由，而不是"再紧一点就行"。

**★ 本轮附带勘误（`AGENTS §2.1` 窗口核验）**：仓内四处写「`SU(3)` 的 `c_r` **变号**」（`GKS-GAUGE:3(c)`、`PROOF-ISOLATION:16`、`PROOF-EMERGENT-4D:9`、`BLIND-TEST:42`）——**与 `(★)` 矛盾，按 `(★)` 判为误**。符号栖息在**反向的 Weingarten/面权求和**里，不在前向特征标系数里（`AREALAW-GAP:11` 逐字："positive `c_r≥0` live only in the forward series"）。**本轮数值复核 `[V]`**：Haar `SU(3)`，Gram–Schmidt 采样，`n=3×10⁵`，β=0.1 校验（`Z=1.00252`、`⟨χ_f⟩=+0.05098`，与一阶 `β/2` 解析值吻合），β=2.5 与 β=5.7 上 `r` 取 dim 3,6,8,10,15,15,27 全部 **`⟨χ_r⟩>0`（>3σ）**。

### 2.2 Ginibre（1970）——**能给的与不能给的**（第 2 条 / 判死线 (c)）

- **正确的引用与作用域 `[C]`**：Ginibre, *Comm. Math. Phys.* **16** (1970) 310，"General formulation of Griffiths' inequalities"（`GPP-STRUCT:113` 著录）。其格点规范场形态的**前提**是"`−U` 的 Fourier/特征标系数非负（正定性）"，而非凸性——`U(1)` Wilson `θ↦β(1−cosθ)` 在 `S¹` 上**不凸**而 Ginibre 仍成立，这是决定性反例（`O03-CG2404:14,139`）。
- **可陈述域 `[C]`（仓内已核）**：标准陈述在**交换**紧群（Pontryagin 对偶 + "系数非负"）；非阿贝尔 `SU(N≥3)` 的**相关不等式**：检索 0 命中（`O03:115,164–166`；`GPP-STRUCT:171`）；唯一 abelian 侧可引的定理是 **Chevyrev–Garban `arXiv:2404.09928` Cor 1.6**（`G=U(1)`、Villain 的**耦合单调性**——**不是** `Cov≥0`，`O03:34` 逐字纠过这个引用）。
- **对本问题的产出**：`⟨W(C)⟩`、`⟨χ_r⟩` 对 β 的**单调**（而 `⟨W⟩` 其实只要两行恒等式 `∂_β⟨W⟩ = N^{-1}Var(W) ≥ 0`，`D05-FKG:54`）。**全部落在期望层，对 `f₁²`（非对角矩阵元）作用域为空。**
- **★ 为什么这不是"最有价值的"**：Ginibre 的结论形状是 `E[fg] ≥ E[f]E[g]` / 单调性；`w₁ ≥ w₀` 需要的是 `|Cov| ≥ √(w₀·Var·Var)`，即**协方差的量级下界**。**该族一条这样的定理都没有**（族内全是符号/序/单调）。且它的前提在自由场严格成立而 `w₁=0`。

### 2.3 OS / 反射正性 — 有，但方向与类型都不对 `[T]`

Osterwalder–Seiler, *Ann. Phys.* **110** (1978) 440–471（DOI `10.1016/0003-4916(78)90039-8`，仓内 `D05-FKG:259` 已著录）：**任意紧群、任意 β≥0** 的 RP `[T]`。但
- `RP ≠ FKG`（`GPP-STRUCT:101`；`LOOP-RUNBOOK:2097`）：RP 是 **PSD 条件**，只把**非对角元从上压**（Cauchy–Schwarz/Hölder），**绝不可能**生产单元素 `≥ c > 0`（`LOWER-AMPLITUDE-MECHANISMS:25`）。
- RP 给出 `ν ≥ 0`（KL 测度）⇒ `f₁² ≥ 0` **非严格**；要 `> 0` 需要原子，而原子正是要找的东西（`SIGNED-FOURIER-BLIND:30`）——**循环**。

### 2.4 Lebowitz/Ginibre 上界族 — `[NG]`

`U₄ = ⟨φ⁴⟩−3⟨φ²⟩² ≤ 0` 那一族要**正四次项/凸势**，Wilson 在 `β=2.5` 不凸（`λ_min(Hess S_W) = −g|B| < 0`，Savvidy 墙；`GPP-STRUCT:103,136`、`O04-NONAB-GAP:199`）。**不许再做**（`O04:199` 逐字）。

## §3 · `w₁` 与 `⟨O⟩` 的关系，以及它关于什么单调（第 3 条）

### 3.1 三张等价脸（`[T]`，`WA-ALIGNMENT:92–99`）

```
w₁ = f₁²/M₀ ,   f₁² = |⟨Ω|O|𝔾⟩|² ,   M₀ = C(0) = Var_μ(O)                    （定义）
w₁ = corr_μ(O,𝔾)² = Var_μ(E[𝔾|O])/Var_μ(𝔾) = E_{μ_O}[𝔾]²/Var_μ(O) ,  dμ_O := O dμ
     （O ≥ 0、E_μ[O]=1 ⇒ μ_O 是概率测度）
```

⇒ **`w₁` 与 `⟨O⟩` 的关系只有一条：`⟨O⟩` 至多进分母（`M₀=Var O`），分子是 `Ω` 与 `𝔾` 之间的跨扇区矩阵元。** 所以 `⟨O⟩` 的任何单调性对 `w₁` **零信息**。更要紧的方向：`∂_β⟨O⟩ = −Var(O) ≤ 0`（`D05-FKG:58` 勘误过 `V02` 的符号）——**`⟨O⟩` 随 β 递减**，与"权重集中到 ordering ⇒ `⟨O⟩` 升"的直觉相反。

### 3.2 `w₁` 关于什么单调（四条，逐条给标签）

1. **算符标度 `O → λO`：恒不变** `[T]`。`w₁ = f₁²/M₀` 是比值，`γ_{w₁}=0`（`U12-C0VAR:66`、`W95D-TRANSPORT:19`）。这是唯一**严格成立**的"单调性"——值是**常数**。它正是 `w₁` 之所以是正确的搬运靶（可过 `Z_O` 重标），也正因如此它**免疫一切依赖标度的正性论证**。
2. **β：非单调，已否证** `[E]`。唯一可精确求解且给出非零 `f₁²` 的模型里 `|F|² = ¼sin²θ` 是**驼峰**（`V02-BETAMONO:146`，§3[A]）；端点 `f₁²(β=0)=0`、自由端 `→0`。⇒「`w₁` 关于 β 单调」**是假命题**（有精确反例，不是"未证"）。
3. **谱展布：唯一非平凡真单调，且方向对（下界）** `[T]`。QI-1 精确恒等式（`QI-BRACKET:18–23`，数值 `3.6e−15`）：
   ```
   w₁ = ϑ + Δ/ε ,   ϑ := (s₂−Ē)/(s₂−s₁) ,  ε = s₂−s₁ ,  Δ = ∫_{[s₂,∞)}(s−s₂)dν_w ≥ 0
   ⇒  w₁ ≥ (s₂−Ē)/(s₂−s₁)      对 s₂ ↑、s₁ ↑、Ē ↓ 单调
   ```
   **这是 `w₁` 唯一的非平凡单调性**：它单调于**谱三点**，不单调于任何"测度参数"。而 `(s₁,s₂,Ē)` 在 4D 全是未知。
4. **测度序（FKG/MLR/随机占优）：不可陈述** `[T]`。MLR/TP2 只把单调性传给**递增函数的一阶矩**（`D05-FKG:50,60` 逐字"作用域不含"）。`𝔾` 变号（`⟨Ω|𝔾⟩=0` ⇒ 必有节线，`D05-FKG:111`，`[T]`），既非递增也非定号 ⇒ **序类工具连"能不能套"都不成立**；`w₁` 要的是 `E[𝔾|O]`/`corr`（二阶），而序只控一阶。即便硬套，输出是 `Cov ≥ 0` ⇒ **`w₁ ≥ 0`**。

**⇒ 第 3 条的答案**：`w₁` 单调于**谱三点比**（QI 括，方向对），**不**单调于 β（精确反例），关于算符标度**恒定**，关于任何测度序**不可陈述**。**"给 `w₁` 一条单调性"与"证明第二支撑点隔离 `s₂−s₁` 相对 `s₂−Ē` 不小"是同一件事** ⇒ 它不是 FKG 坐标，是 `I2`/`H1` 坐标。

## §4 · 判（第 4 条）

### (a) 若能 ⇒ 逐字不等式 + 引用 ⇒ **不成立**

**没有一条 FKG 类不等式能给 `w₁` 的 `(L,a)`-一致正下界。** 三条独立理由（任一条单独关闭）：

- **(a1) 符号 vs 量级**：本族全部输出是**符号**（`Cov≥0`、`⟨χ_r⟩≥0`、PSD），而 `w₁ ≥ w₀>0` 是**量级**。族内不存在"协方差下界"型定理。
- **(a2) 一阶 vs 二阶**：族的作用域是**递增函数的一阶矩**；`w₁` 是**归一化协方差的平方**，且其两个因子之一是**变号**的本征函数（`⟨Ω|𝔾⟩=0` `[T]`）。
- **(a3) 酸测真空**：该族最强的一条（`c_r≥0` + β-非降 + block-Loewner `[T]`）**在自由场上严格成立而 `w₁=0`** ⇒ 由它导出的任何 `w₁` 命题在自由场也为真 ⇒ 不可能给出自由场缺失的正地板。

### (b) `SU(N)` 真的无格序吗 ⇒ **是，且理由是不可修补的**
