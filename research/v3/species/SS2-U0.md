## §2 齐次性：`+1` 是什么意思，`a→0` 怎么走，`≍1/a` 能否自动

**2.1 逐字（`[T]`）。** 把谱变量整体重标 `s↦ts`（等价 `m↦√t m`、长度 `↦ t^{−1/2}`）：`M₀=ν(ℝ)` 不动，`χ=∫s⁻¹dν ↦ χ/t`，故

```
U₀(ν_t) = t·U₀(ν)        （次数 +1，机检 [1] 逐位）        [T]
⇒ U₀ 不是无量纲比值：它是一把"质量²尺"，单说"U₀ ≥ c"必须同时说单位。
```

**2.2 三条判（这是本文件的核）。**

**(i) 类层地板不存在（`[T]`，结构性）。** 容许类 `𝒜 := {ν≥0 有限: M₀∈(0,∞), χ<∞}` 对 `s↦ts` 封闭，`U₀` 是 +1 ⇒ `inf_𝒜 U₀ = 0`、`sup_𝒜 U₀ = ∞`（`δ_s` 上 `U₀=s`）。两个见证把"封闭"用实：(a) `δ₀` 给 `U₀=0`（`χ=∞`）；(b) `Unif[ε,ε+W]` 给 `χ<∞`、**无原子**、`U₀ ~ W/log(1+W/ε) → 0`（机检 **[6]**：`ε=1e−6 ⇒ U₀≈0.072`）。⇒ **任何只依赖（测度公理 + squeeze + 正性）的论证都不可能给地板**——不是"尚未找到"，是"这一类里没有"。**下一手**：新提案先过 (a)(b) 两格，不过则不改判。

**(ii) `a→0` 的标度（`[T]`，与 (i) 同一事实的另一面）。** `s` 是能量（衰减率）⇒ 格点值 `s^{lat} = a·s^{phys}`（`a` 以 `s^{phys}=1` 为单位），代入 +1 齐次：

```
U₀^{lat} = a·U₀^{phys}  ⇒  U₀^{lat} ≍ a  (→ 0)         机检 [5]：a=1/8 时 U₀^{lat}/a = U₀^{cont}  [T]
```

故 `U₀ ≍ 1/a` **不可能**：真幂是 `+1`（若 `s` 取质量² 则 `+2`），符号与"自动下界"的假设相反。直接推论（也是本轮最硬的一句）：**`∃c>0 ∀a: U₀ ≥ c` 在连续极限里是假的**——只要物理谱不退化，`U₀^{lat}→0`。所以 ∀a 形必须**协变化**（`U₀ ≥ c·(能量单位)`，即 `U₀/E₀ ≥ c`）；协变化之后逐字就是 `χ ≤ M₀/(cE₀)`，即 **H1 的归一形**。**下一手**：全仓凡写 `U₀ ≥ c` 必带能量单位；裸形退回。

**(iii) 上下界不对称（`[T]`）。** 转移归一 `0<U₀≤1`（0.6）；质量²归一 `0<U₀≤Ē`。两端都免费，中间全开 ⇒ 靶的**全部内容**是"不退化到 0"，与"有没有隙"是同一句话。**下一手**：槽一的证明栏只写"下侧"，上侧不再立项。

**2.3 判。** `+1` 齐次的净含义有两条：**(甲)** 类层无地板（2.2-i），**(乙)** `a`-幂为正、故 ∀a 自动性反向（2.2-ii）。这两条合起来说明：`U₀` 的地板**必须**由一个**破坏 `s↦ts` 的尺度外锚**供给；仓内可用锚只有三个（§3.2）。

## §3 判定：`U₀ ≥ c` 能否 `[T]`

**3.1 窗内（逐 β）`[T]`。** `β<1/48`：`I1 (f₁²≥r₀) ∧ H1 (χ≤1/λ) ⇒ s₁ ≥ f₁²/χ ≥ r₀λ`（`Reduction.lean:125–129`，0 sorry）⇒ 由免费右腿 `s₁ ≤ U₀`（`H06:27`）得 `U₀ ≥ r₀λ > 0`。**但这不是靶**：`r₀=r₀(β)`、`c(β)→0⁺` 于窗边，且无 `a`-一致（`B04:106` 限定 (i)(ii)）。**下一手**：窗内读数直接沿用，不记进度。

**3.2 窗外 `[NG]`：具名障碍 = 尺度外锚缺失（齐次 + 三个锚全不合格）。** 由 2.2(iii)，地板必须付一个锚；仓内穷尽三个：

| 锚 | 形状 | 判 | 为什么 |
|---|---|---|---|
| **(a) `a` 自身** | `U₀ ≥ c a^{-p}` | **方向反** | 2.2(ii)：`U₀ ≍ a`，`a` 把地板推向 0，不给地板 |
| **(b) `1/λ`（物理能量）** | `χ ≤ M₀/(cE₀)` = H1 归一形 | **`[NG]`** | 六证书（`HN1:373`）；"配 I1 给 `s₁`"的条件形 `[T]`（3.1）但前提窗外 `[NG]` |
| **(c) `M₀` 下界** | `M₀ ≥ m₀ > 0` | **`[NG]`** | `G-0` 未证（`HZ6:0.2` 点名）；只有上界 `M₀≤2N²`（`HZ1:47`） |

- **已知最便宜充分条件（`[T]`）**：`H1 ∧ (G-0) ⇒ U₀ = M₀/χ ≥ M₀λ ≥ m₀λ > 0`。它**严格强于**靶：靶 ⇏ H1（取 `M₀` 大、`χ = M₀/c` 即可，`U₀=c` 而 `χ ≫ 1/λ`）。
- **精确位置（`[T]`）**：靶 ⟺ `τ_int = χ/M₀ ≤ 1/c`，即"归一化 `M₋₁` 的一致天花板"。`H1` 的**绝对**形被 `M₀` 的 UV 漂移污染（同 `β=2.5` 上 `M₀` 从 `2.474` 到 `45.527`，×18.4，`I02:11`）⇒ 除以 `M₀` 不是弱化，是**去污染**；归一化后剩下的一件仍是 IR 输入。
- **比 `RR1` 精确在哪**：`RR1:0.7` 的判是"净内容 = `H1`"，其三分法按**写法**分（固定 `δ` / 协变 / 含 `Δ₀`）。本轮把它改成按**锚**分：唯一合法锚是 (b)(c) 一对，且 (c) 不是 `H1`；再加两条 `RR1` 没有的结构判 —— 类层下确界恰 `0`（2.2-i）与 `a`-幂为正（2.2-ii），后者**否证**了 ∀a 自动性这一候选（不是搁置）。

**3.3 反向不可冒领。** `s₁ ≥ δ ⇒ U₀ ≥ δ` 免费，`U₀ ≥ δ ⇒ s₁ ≥ w₁δ` 要 `C`（`w₁≥w₀`）⇒ 两命题等价（0.8），但**等价不产内容**：它只说明"换载体不改难度"，不说明 `U₀` 更容易。`RR4` 的"`U₀` 比 `s₁` 便宜"只在**测量**侧成立（0.2），**不在证明侧**。
