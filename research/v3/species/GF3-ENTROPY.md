## §1 转移矩阵：轮廓自动机（最小构造 ≤ 10 状态）

### 1.1 编码（`[T]`，双射引理）

固定一个 2-平面。薄膜 = 该平面内的 polyomino（片簇），**按平移类计数**（定根与否不改增长常数）。把 `x` 方向当生长方向，逐列生成：

```
列 j 占据行区间 [b_j, b_j+h_j−1]，h_j ≥ 1 ；列 x-坐标连续 ；相邻列必须相交（簇连通）
δ_j := b_{j+1} − b_j                                             （基步 / 界面相对位移）
相交 ⟺ δ_j ≤ h_j−1 且 −δ_j ≤ h_{j+1}−1
     ⟺ h_j ≥ max(1, δ_j+1, 1−δ_{j−1})  =: L(δ_{j−1}, δ_j)          (1.1)
```

**引理 1（双射）.** `薄膜（模平移） ↔ 序列 (h_1,δ_1,h_2,…,δ_{m−1},h_m)` 满足 `(1.1)`，且
`𝒟 := {δ_j ≤ 0 ∀j}`（有向 / 基线下行）、`𝒮_s := {|δ_j| ≤ s}`（双侧）、`𝒮_0 = 𝒟_0 = bargraph`。
*证明*：列 = 该 `x` 上的极大竖直区间（唯一）；相交条件即 `(1.1)`；反向由 `(h,δ)` 直接重建。∎
**独立校验**（不依赖本引理）：`n≤11` 暴力枚举 polyomino 后按「列凸 + 基线下行」/「列凸」筛选，与 DP 逐位相等（`log:45–48`，PASS）。这也顺带**再次复现**了平面 polyomino 的 `A_n`（`log:44`：`n=10` 给 `36446`、`n=11` 给 `135268`；前两次见 `GE2-DEFDIM.md:197`、`GD2-WSTAR.md:200–202`）。

### 1.2 定理 2（Perron–Frobenius 转移矩阵定理，`[T]`）

设状态集 `D ⊆ ℤ`（有限，或可数但 `Σ_{δ∈D}x^{1−δ}<∞`），
```
E(x)_{δδ'} = x^{L(δ,δ')} ,   F(x) = E(x)/(1−x) ,   u_δ = x^{max(1,δ+1)}/(1−x) ,  w_δ = x^{max(1,1−δ)}/(1−x)
G(x) = Σ_n a_n x^n = x/(1−x) + u^T (I−F)^{-1} w                              (1.2)
```
则
1. **【PF】** `x>0` 时 `F(x) > 0` 逐元为正 ⇒ 本原；`ρ(F(x))` 单重，左右特征向量可取正。
2. **【单调】** 每个元素是 `x` 的严格增函数 ⇒ `ρ(F(x))` 在 `x>0` 上**严格增**（Collatz–Wielandt）。
3. **【收敛半径】** `G` 的收敛半径 `x_c` = `ρ(F(x))=1` 的唯一正解；**Pringsheim**（非负系数幂级数的收敛半径必是奇点）+ 有理性（在最小正极点旁 `a_n ~ C·x_c^{−n}·n^k`，故 `lim` 存在）⇒ `μ := lim a_n^{1/n} = 1/x_c`。
4. **【代数】** `x_c` 是整数多项式 `P(x) := det((1−x)I − E(x)) ∈ ℤ[x]` 的**最小正根**，且 `P>0` 于 `[0,x_c)`；`μ = 1/x_c` 是代数数。

*要点*：`ρ(F)<1 ⟺ det(I−F)≠0`（因 `ρ<1` ⇒ 所有特征值模 `<1`）⇒ 首次归零处必是 `ρ=1`；单调性给唯一性。∎
**（4）的"最小正根"必须核**：`det` 可能带**伪因子**（如 `(1−x)`），故判据一律用「**最小正根 + 区间上 `P>0`**」，本文件全部按此执行（`x_c` 由 Sturm 在 `(0,1]` 上数根后二分隔离，见 §3.1）。

## §3 `μ ≤ e` 的精确判定

### 3.1 判定程序（5 步，零枚举、零浮点）

```
S1 双射：类 ↔ 轮廓自动机路径（引理 1）        —— 唯一的组合输入
S2 整数特征多项式：P(x)=det((1−x)I−E(x))      —— Bareiss 无分数消元（Z[x] 上精确整除）
S3 隔离：Sturm 链数根 + 二分 ⇒ x_c ∈ (lo,hi]，且 (0,lo] 内无根
S4 参照：1/e ∈ (elo,ehi)，由 1/e=Σ(−1)^k/k! 的交替部分和给有理夹逼（width 3.8e−33）
S5 判定：x_c ≥ 1/e ⟺ μ ≤ e
        lo > ehi ⇒ μ < e（YES）    hi < elo ⇒ μ > e（NO）    否则 UNDECIDED
```
**为什么这不是循环**：S1 是唯一"看起来像数数"的一步，但它是**结构命题**（双射），且被独立的 `n≤11` 暴力枚举核过（`log:47–48`）；S2–S5 全是**精确代数**，与 `n` 无关。⇒ **一旦 S1 成立，`μ ≤ e` 就不再是"枚举到多少"的问题。**
**为什么 S4 不能用浮点 `e`**：`e` 是超越数，`x_c` 是代数数 ⇒ 必不相等，任何**能分开二者的有理区间对**都足以判决；交替级数给的是**严格**有理界，故判决是 `[T]`。

### 3.3 方法的**结构边界**（`[T]` 的 no-go，关于方法自身）

```
任何包含 𝒮₁ 的类 𝒞 都有 μ(𝒞) ≥ μ(𝒮₁) = 2.831177 > e
⇒ 对「不做单向限制的列凸类」，**任何方法**（不止有限态机器）都证不出 μ ≤ e —— 命题本身假
⇒ 有限态机器的真正边界不是"状态数"，而是**类是否单向**：
   有向 ⇒ 可有限态化（𝒟 秩 1、𝒮_s 2s+1 态）⇒ μ 代数、判决 [T]
   双侧 ⇒ μ ≥ 2.83 > e，且极限 μ_CV ≥ 3.19（𝒮_s ↑）
```
⇒ **本路把 `μ ≤ e` 的全部内容压到一个 bit 上**：界面基线的**单向性**。这比 `GE2-DEFDIM.md:280` 的「排除悬垂/气泡」更精确（那里把"有向"和"无悬垂"并列，本文件把两者分开：**无悬垂 `⟹ μ ≥ 3.19 > e`，有向才 `⟹ μ = φ² ≤ e`**）。

### 3.4 脆弱性（诚实线，必须写）

```
Δ(bit)  = μ(𝒮₁) − μ(𝒟) = 0.2131     （换一个 bit 的代价）
margin  = e − μ(𝒟)     = 0.1002     （余量）
⇒ 代价 / 余量 = 2.13 倍
```
⇒ **结论的正确性完全押在"YM 的缺陷簇基类是单向的"这一物理输入上，而该输入的形式化敏感度（`Δ(bit)`）大于判据本身的余量（`margin`）。** 因此：

- `[T]`：`μ(𝒟) = φ² ≤ e`（纯组合，已证）。
- `[O]`：YM 的缺陷装饰类 `⊆ 𝒟`（等价：界面基线单向 / 缺陷只朝一个方向"铺"）。
- `[NG]`：任何"只靠无悬垂（列凸）"就能得 `μ ≤ e` 的说法（`μ ≥ 3.19`）。
- 不许写：`μ_eff ≤ e` 是定理。

### 3.5 刚度替代路线（`[C]`，`log:118–125`）

```
权重 y^{|δ|}（y<1 = 抑制斜率）：μ(y) 单调降，μ(y) ≤ e ⟺ y ≤ y*
s=1 : y* = 0.8449303  ⇒ κ* = 0.168501
s=2 : y* = 0.6695959  ⇒ κ* = 0.401081
s=3 : y* = 0.6424193  ⇒ κ* = 0.442514     （κ* 随 s 缓升：s=2→3 增 10.3%；s=4 未算）
```
⇒ **`[C]`：若缺陷作用量 = `σ|C| + κ·Σ_j|δ_j| + …` 且 `κ ≥ κ*(s)≈0.44`，则 `μ_eff ≤ e`。**
这是 `GE2-DEFDIM.md:276–277` 的「`cost(C) ≥ σ|C| + κ·curv(C)`」的**定量版**：`κ` 的阈值不是"某个 O(1)"，而是可算的 `0.44`（每单位界面斜率）。仓内既无 `κ` 的实测也无下界 ⇒ 该 `[C]` 的前件未支付（`[O]`）。
