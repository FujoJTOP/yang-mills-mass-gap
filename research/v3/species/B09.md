## 2. `"除掉有限点"` 够 (iii) 吗：**不够，两条互相独立的不足**

### 2.1 第一不足（用户的读法）：零点是**洞**——而且比洞更糟 `[T]`

```
(iii) 是 ∀β 的全称句；"除有限点"是 ∀β∉F 的句 ⇒ F 上**没有**陈述。
```
但真正的杀伤不在 `F` 上的三个点，而在**常数**：

```
设唯一在手的桥形为  m ≥ c·w₁ (c>0, 见 §3 说明为何这桥本身也没有)。
若 w₁(β_j)=0（|a|² 非负 ⇒ 局部极小、连续）：
   Δ₀ := c·inf_{β≥β₀} w₁ ≤ c·w₁(β_j) = 0
⇒ **Δ₀>0 在整个尾上失效**，不是只失效于 β_j。
⇒ 连续性能"补"掉洞的**定义**，补不掉**常数**：
   零点邻域内 m ≥ c(β−β_j)^{2k}h ⇒ inf = 0，任何 Δ₀>0 都被打掉。
```
**⇒ 逐字：`{零点}` 不是"有限个失败点"，是"把 `inf` 钉在 0 的一个见证"。** `[T]`
（这正是 `U04:102` 的同一句机制：`o-minimal` 机器**允许角点值 0** ⇒ 它**没有地板内容**。）

### 2.2 第二不足（更根本，且**与零点无关**）：逐点正 ⟹̸ 一致正 `[T]`

```
(iii) 需要  inf_{β≥β₀} w₁ > 0。
"零集有限"最乐观的加强版 = "零集空、处处正"。而在**非紧**尾上：
   处处正 ⇏ inf>0。
反例（就在所需函数类里，实解析、无零点、端点正）：
   w₁(β) = e^{−(β−β₀)} ，β≥β₀ ⇒ 实解析、∀β w₁>0、inf = 0。
```
语料同型见证（**且是真机理，不是造出来的病态**）：

| 见证 | 内容 | 出处 |
|---|---|---|
| 可定义反例 | `g(x,t)=x^t` 在 `(0,1)²` 上 `ℝ_an,exp`-可定义、**逐点 `>0`**、`inf = 0` 且不取到 | `[T]` `U05:29`；`RUNBOOK:19312` |
| OPE 机理 | `f₁²=1.0→1e−4` 时 `w₁: 0.3465→5.3e−5` ⇒ **`w₁→0` @ 固定 continuum**；"OPE 只界分母，不能逼出底部原子" | `[T]+[V]` `U2-WILSON-OPE:269–271,278` |
| 溶解机理 | `δ=1e0→1e−6` 时 `w₁: 0.347→5e−4` ⇒ `w₁→0` **连续**（测度仍 RP） | `[T]+[V]` `T2-TUBE-OVERLAP:364` |

**⇒ 逐字：`"零集有限 + 端点正 ⇒ 全正"` 这个 schema 若成立，它证的是「全正」，而 (iii) 要的是「一致正」。前者严格弱于后者。⇒ (a) 即使被证也不到 (iii)。** `[T]`

### 2.3 (iii) 的完整义务清单（把上面拆成四条，缺一不可）

```
(α) 无洞：w₁(β)>0 **∀**β≥β₀（不是"除有限点"）
(β) 一致正：inf_{β≥β₀} w₁ > 0   ← **"零集有限"一个字都不给这里**

⇒ 所以"洞"这个框架把难点放错了位置：**关掉洞不解 (β)**。
```

## 3. `w₁` 的解析性能推 `m` 吗：**不能，两条独立理由**（这是 (c) 的正身）

### 3.1 `w₁` 是**源方向余弦**，`m` 不是 `[T]`

| # | 事实 | 出处 |

| 2 | `U1-NG1` 逐字：`w₁` 是 **SOURCE direction cosine**；**正性 + 隙不界它** | `U1-HARNACK-BOUND:312` |

| 4 | 宇称错配的**局域**源给 `w₁=0` **精确**（`cos(θ₁−θ₂)` 型源与最低能级正交）⇒ **`w₁` 的零点可被源"造"出来** | `U1-HARNACK-BOUND:346–348` |

⇒ 要把 `w₁` 的正性搬到 `m`，必须 (γ) **`O`-一致的桥** `m ≥ c·w₁`，`c` 与 `O` 无关。**该桥不在手，且 `U1-NG1` 逐字说正性+隙不界 `w₁` ⇒ 桥的方向反了**（要从 `m` 推 `w₁` 才现成）。`[T]`

## 4. 死线裁决（逐字）

### (a) 有一个**逐字可给**的版本——但它不是 (iii) `[T]`

```
**可给的逐字式（U01.md:23–38 的 P-1，搬运引理）**：
   设 K 紧、w₁:K→[0,1] 连续、w₁(x)>0 ∀x∈K。则 inf_K w₁ = min_K w₁ > 0。∎（Weierstrass 一行）
**且反向也成立 ⇒ 是等价式**（`U01:35`）：
   「K 上一致下界」 ⟺ 「K 上逐点正 + K 紧 + w₁ 连续」
⇒ 它**不生产正性**，只把 `inf` 搬到唯一一个下确界点上（`U01:38`）。
**而 (iii) 的 K = [β₀,∞) 不紧** ⇒ P-1 在 (iii) 上不可用；
凡把它用在 `[β₀,B]` 上，得到的是 `Δ₀(B)`（依赖 B 的常数），不是 `Δ₀`（`U01:52,144`）。
**记账（不许省）**：`UNIF1:75–77` 已判「解析 + 紧 + 逐点正 ⇒ 一致」，并逐字更正：
   "o-minimality **完全多余**——'零集有限'（F1）比'连续 + 紧'**严格更弱**；
    F1 从来不是内容；内容是 H1（逐点正性）。"
⇒ **所以 (a) 的诚实形态：紧窗免费（且是恒等式），尾端一行都推进不了。**
```

### (b) 触发，且**比"洞"更糟** `[T]`

`{零点}` 是洞（§2.1 前半），但真正的问题是 `|a|²≥0` 使 `inf` 在零点**取到 0** ⇒ 由任何 `m ≥ c·w₁` 型桥给出的 `Δ₀` 归零；**关掉洞也救不回常数**（§2.1 后半）。⇒ (b) 成立。

### (c) 触发 `[T]`

`w₁` 依赖 `O`（§3.1 #1–#5：`U1:307,312`、`U5:239–240`、`U6:244`），`m` 不依赖 ⇒ 固定一个 `O` 的解析性**结构上**不能成为 `m` 的解析性/下界；且权重 vs 位置两槽不同（§3.2：`L3A-STAR:16,45`）。**这是 `O`-依赖的问题，不是技术细节。**

### 综合判（一句话）

```
**解析性能给 (iii) 吗？不能。** 它能给的是**紧窗**上的地板（且为等价式、零内容），
而 (iii) 的全部内容在**非紧尾**上；那里既缺 `inf>0`（§2.2），又缺 `O`-无关的桥（§3）。
"零集有限 ⇒ 除掉有限点" 与 "(iii) 要 ∀β" 的差别**不是本路生死**——
更早、更硬的分岔是 **"逐点正" vs "下确界正"**（§2.2），以及 **"权重槽" vs "位置槽"**（§3.2）。
```
