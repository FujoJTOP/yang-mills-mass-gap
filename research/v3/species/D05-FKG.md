## §1 · `T_β` 的序：四种读法，逐一判（任务第 1 条）

约定：柱面 `𝒞_L = T³_L×ℝ`、Wilson 作用 `S = βΣ_p(1−N^{-1}Re tr U_p)`、时间片劈分 `S = S_s(U)/2 + S_t(U,V) + S_s(V)/2`，故

```
T_β(U,V) = exp( − β Φ(U,V) ),   Φ(U,V) := Σ_p (1 − N^{-1}Re tr U_p)|_{(U,V)} ≥ 0   [T]
```

（`Φ ≥ 0` 是 `Re tr U_p ≤ N` 的直接后果；`Φ=0` ⟺ 该 `(U,V)` 上所有 plaquette 取 ordering。）

### 1.1 读法 A — 核逐点序：**随 β 递减**，且这是恒等式（`[T]`）

```
∂_β T_β(U,V) = − Φ(U,V) · T_β(U,V) ≤ 0 ,   等号 ⟺ Φ(U,V)=0 .                    [T]
```

⇒ **不是"`T_β ≥ T_{β'}`"，而是 `T_β ≤ T_{β'}`（`β>β'`）逐点**。任务书设想的"重权集中在 ordering 处"，在这层的**准确形式是比值**：

```
T_β(U,V)/T_β(U₀,V₀) = exp( −β(Φ(U,V) − Φ(U₀,V₀)) )  在 Φ<Φ₀ 时对 β 递增  ⟺ TP2 .  [T]
```

**这不是序，是"似然比"**。把它读成序是最常见的偷换：绝对值全部下降（配分函数归一化效应），只有**相对**权重向 ordering 移动。

### 1.2 读法 B — TP2 / MLR：**唯一无条件的"序"，但它是标量序**（`[T]`）

由 1.1，`{(β,Φ)}` 满足 **TP2**（`β>β'`、`Φ₁<Φ₂` ⇒ `T_β(Φ₁)T_{β'}(Φ₂) ≥ T_β(Φ₂)T_{β'}(Φ₁)`）。等价地：`μ_β ∝ e^{−βΦ}dU` 是**以 `Φ` 为充分统计量的指数族** ⇒ **MLR 随机序**。后果（两行，全部 `[T]`）：

```
对任意递增 f :  E_{μ_β}[f(Φ)] ≥ E_{μ_{β'}}[f(Φ)]        (β > β')
⟨W⟩ 递增：  ∂_β⟨W⟩ = N^{-1}Var(W) ≥ 0 ,   W := Σ_p Re tr U_p = N(N_p − Φ)
⟨O⟩ 递减：  ∂_β⟨O⟩ = −Var(O) ≤ 0        （∂²_β ln Z = Var ≥ 0 的一步推论）
```

**★ 本轮勘误（顺手抓到的）**：`V02-BETAMONO.md:52` 写 "`∂_β⟨O⟩ = Var(O) ≥ 0` 是 `[T]`（Griffiths）⇒ **`⟨O⟩` 递增**" —— **符号反了**。正确式是 `∂_β⟨O⟩ = −Var(O) ≤ 0`（`O ∝ S_W` 是**能量密度**，不是磁化强度；`∂_β⟨S_W⟩ = −Var(S_W) < 0` 是标准事实）。**方向：`⟨O⟩` 递减**。这不改 `V02` 的判词（它只用到"矩单调但矩不决定原子"），但"递增"这个词必须撤掉——否则 §4 的"集中到 ordering"会被读成"`⟨O⟩` 上升"。

**这一层的局限（决定性）**：MLR 只序化**统计量 `Φ` 的函数**，即**期望层**。`𝔾_β` **不是** `Φ` 的函数（它是本征函数，变号，见 §2），`F` **不是**期望（它是非对角矩阵元）。⇒ **读法 B 对 `F` 的适用性 = 0，不是"弱"，是"作用域不含"**。语料同型先例：`P05-CINF.md:145` 的 MLR 只作用在标量 `w` 上（那里合法且有用）。

### 1.3 读法 C — Loewner 算子序 `T_β ⪰ T_{β'}`：**全 `T_β` 未建立**（`D`-因子障碍），块级 `SU(2)` 有、`SU(N≥3)` 无定论，**且产出为零**（`[T]`/`[NG]`）

`T_β` 是 `L²(dU)` 上的对称 Hilbert–Schmidt 核（`e^{−βΦ}` 有界、`dU` 有限）⇒ Loewner 序良定义。劈分 `T_β = D_β^{1/2}K_βD_β^{1/2}`，`D_β = e^{−βS_s/2}`（空间 plaquette，**逐点随 β 递减**），`K_β(U,V) = e^{(β/N)Σ_t Re tr(U_lV_l^†…)}`：

```
K_β ⪰ K_{β'}  ⟺  c_r(β) ≥ c_r(β')  ∀r     （近似"⟺"：χ_r(UV^†) 正定 ⇒ 逐项）
c_r(β) = ⟨χ_r⟩_{单 plaquette}/d_r ；SU(2)：c_j ∝ I_{2j+1}(2β)/β 型 ⇒ 非降  [T]（Bessel 比单调）
SU(N≥3)：c_r(β) 的 β-单调性 —— 无定理                                  [NG]
D_β ≥ D_{β'} ？ —— **假**（S_s ≥ 0，故 D 逐点递减）
⇒ 全 T_β 的 Loewner 序：**未建立**（D-因子障碍；与读法 A 同一障碍搬到了算子层）
```

**★ 引用审计（本轮新发现）**：`O04-NONAB-GAP.md:114` 与 `W1B:168` 都记 "`β=2.5` 上 `SU(3)` 的 `c_r` **变号**"，其唯一出处是 `GKS-GAUGE.md:15`；而 `GPP-STRUCT.md:167` 已逐字记录 **该文件不存在**（悬空引用）。本轮独立检索（§6）**未取得** `SU(N≥3)` Wilson 作用特征标系数正/负的定理。⇒ 该主张从 `[T]` **降级为 `[NG]`**：既不能断言"变号"，也不能断言"恒正"。**结论只到"无定论"**。

**即便 Loewner 成立（它没有），它给什么**（这一步是本条的关键）：

- **给本征值**：min–max ⇒ `λ_k(β) ≥ λ_k(β')` ∀k `[T]`。
- **不给归一化核**：物理的随机核是 `P_β = T_β/λ₀(β)`；`T_β ⪰ T_{β'}` 对 `P_β ⪰ P_{β'}` **无蕴含**（分母不同向）⇒ **`m = −ln(λ₁/λ₀)` 的序拿不到**（比值无序）。
- **不给本征向量**：`A ⪰ B` **不**蕴含 `P_A ⪰ P_B`（谱投影无序，两行反例：两个近似平行的秩一投影不可比）⇒ `𝔾_β` 的序拿不到。

⇒ **`T_β` 的 Loewner 序的最高产出 = 未归一化本征值序列的序；对 `F`、对 `m`、对 `𝔾` 全部零输出。** 这正是任务书"比较 `T_β` 而非 `m(β)`"这条纪律的**意外答案**：比较 `T_β` 之后，能落地的仍然只有 `m` 侧的量，而那一侧已被 `b06` 判死。

### 1.4 读法 D — FKG 格序：**不存在**（`[T]`/`[NG]`）

FKG 的前提是"配置空间是**有限分配格** + 密度 log-超模"。三条独立障碍：

1. **无群相容序**：可序群必无挠（"Orderable groups are torsion free"，Navas 讲义，摘要级 `[B]`）；紧 Lie 群有挠 ⇒ **无左（或右）不变全序**。⇒ `N^{-1}Re tr U_p` 在任何群相容序下**不是单调函数** `[T-standard]`。
2. **非铁磁**：`V ↦ Re tr(UV)` 在 `V=U^{-1}` 取 **max `N`**、在 `V=−U^{-1}` 侧取 **min `−1`**（`SU(2)` 是 `−2`）⇒ 与"单调耦合"不相容。语料同判：`GPP-STRUCT.md:100`（"`SU(N)` 无平移不变格序（torsion）、`e^{−S_W}` 非逐坐标超模"）。
3. **对偶面权带号**：把 FKG 搬到面/涡旋表示时，Weingarten 权重带号 ⇒ 无正 Gibbs 测度 ⇒ 无 FKG。语料：`T5-CENTER-VORTEX.md:42–45,367`、`T23-TEMPLATE.md:117`、`LOOP-RUNBOOK.md:2137`。

⇒ **FKG 在 `SU(N)` YM 上不成立，且与 `N` 无关**（紧性障碍 `N=2` 就有）。

## §2 · `|𝔾_β⟩` 逐分量单调？——**不可陈述**（任务第 2 条）

三段，各自独立：

**(N1) 符号：`𝔾_β` 必须变号 `[T]`。** 语料约定 `Ω≡1`、`λ₀=1`（`U1-HARNACK-BOUND.md:130–133` "Proposition U1-2 … `Ω≡1`, `λ₀=1`"），故 `⟨𝔾_β|1⟩=0`。若在某个相位约定下 `𝔾_β ≥ 0`（a.e.）且 `≢0`，则 `T_β𝔾_β = λ₁𝔾_β` 与 `T_β` 的**正性改进**（核 `e^{−βΦ}>0` 处处）给出 `λ₁𝔾_β = T_β𝔾_β > 0` 处处 ⇒ `𝔾_β` 严格正 ⇒ 正本征函数 ⇒ PF 唯一性 ⇒ `𝔾_β ∥ 1` ⇒ 与 `⟨𝔾_β|1⟩=0` 矛盾。**⇒ `𝔾_β` 的零点集非空、两侧都有正测度**（Courant：`ψ₁` 恰两个节线域，与 PF 版本一致）。语料已逐字记录同一事实：`U1-HARNACK-BOUND.md:136`（"`ψ₁` is sign-indefinite (`⟨ψ₁|1⟩=0`, `ψ₁≢0`)"）、`:382`。

**(N2) 归一化：逐点 `≥` 与 `‖·‖=1` 不相容 `[T]`。** 设 `β>β'` 且 `𝔾_β ≥ 𝔾_{β'}` 逐点（同一相位约定）。则 `∫(𝔾_β−𝔾_{β'})(𝔾_β+𝔾_{β'}) = ‖𝔾_β‖²−‖𝔾_{β'}‖² = 0`；由 `𝔾_β+𝔾_{β'} > 0` a.e.（两边不同时为零：若 `𝔾_β=−𝔾_{β'}` 则两者都是本征函数且 `∫=0`，与 (N1) 的严格性冲突）⇒ `𝔾_β=𝔾_{β'}` ⇒ 同一个函数同时是 `T_β`、`T_{β'}` 的本征函数 ⇒ `∫e^{−βΦ(U,V)}φ(V)dV ∝ ∫e^{−β'Φ(U,V)}φ(V)dV` 对 a.e. `U` ⇒ `Φ(U,·)` 为常数 ⇒ 与 `Φ` 依赖 `V` 的 plaquette 矛盾。

**(N3) 相位：命题本身不良定义 `[T]`。** 本征向量的整体符号是约定（Kato 连续相位）；"逐分量单调"在 `𝔾→−𝔾` 下翻转 ⇒ 它**不是** `T_β` 的函数，**不可能**是定理。同理，任何"`|G_β⟩ ≥ |G_{β'}⟩` 逐分量"的写法在写下的那一刻就依赖一个未指定的相位规范。

⇒ **任务第 2 条要判的那件事不存在**：不是"未证"，是**没有良定义的对象**。因此"若 `|G_β⟩` 单调 ⇒ `F` 单调"这条链的**前件**是空的（见 §5(a)）。(N1) 是**新内容**：语料只证了 `ψ₁` 变号（`U1`），**没有**指出"变号 ⇒ 逐分量序路线整体作废"这一步。

## §3 · `O` 的符号（任务第 3 条）：一处勘误 + 一个更狠的死法

### 3.1 勘误：`O` 作为算符是**逐点非负**的（`[T]`）

`ch05-theorems.tex:52`："`tr F²` is a finite A1g sum of local plaquette observables"。在时刻 `t=0` 的片上是**乘性算符**，且

```
1 − N^{-1}Re tr U_p ∈ [0, 1 + 1/N]   ⇒   O = ¼trF² ≥ 0  逐点 .                [T]
```

⇒ 任务书"`O = ¼trF²` 的符号**不定**"**作为算符陈述是错的**。真正不定的是下面两件。

### 3.2 死法一：`F` 对常数平移**不变** ⇒ 不定性可以零成本制造（`[T]`）

```
⟨1|𝔾_β⟩ = 0   ⇒   F(β) = ⟨1|O|𝔾_β⟩ = ⟨1|(O − c)|𝔾_β⟩   对任意 c ∈ ℝ .     [T]
```

取 `c = ⟨O⟩_μ`（= 物理上必须做的真空减除/连接部分）。`O` 非退化 ⇒ `min O < ⟨O⟩ < max O` ⇒ `O_c := O − ⟨O⟩` 的数值域**跨 0** ⇒ **恒不定**（每个 β）。

⇒ **"`O ≥ 0`"这个资源对 `F` 完全无效**：任何以它承重的论证，在 `O → O−⟨O⟩` 这一步**不改变 `F`**，却**摧毁全部符号信息**。语料的已证版本：`W1B-P3-AMPLITUDE.md:172–177`（PF 只控**对角** `⟨Ω|O|Ω⟩`；**连接源 `φ=QO|Ω⟩` 符号不定**；`⟨G|φ⟩` 是"两个正向量流之差"，PF 无法把它与零分开）。这条把 `W1B` 的叙述从"PF 不够"升级为**结构性**：**不是 PF 弱，是 PF 的对象（正锥）与 `F` 的对象（连接矩阵元）不属于同一范畴。**

### 3.3 死法二：`F` 的**符号**是相位约定，只有 `|F|` 物理（`[T]`/`[E]`）
