## 3. 用 `ρ²` 反推 `f₁²`：**不行，且这是可证的** `[T]`

* `ρ² = μ₂/μ₁ = 2.48 ± 0.2` 是**转移生成元第二本征值比**（隔离坐标 `I`）；`f₁² = ν({m₁²})` 是 **KL 原子权重**（可见性 `A`）。语料已定：`W⊥I`、**`ρ²` 地板盲**（有限自由环面 `ρ² = 2 ≤ 4` 而 `f₁² = 0`；`new-tools-registry` A7、§B19）。
* 精确反例（本脚本）：`T = diag(μ₁, μ₂)`、源 `(cosθ, sinθ)` ⇒ **`ρ²` 与 `θ` 无关而 `w₁ = cos²θ` 自由**。固定 `ρ² = 2.48`，`w₁` 跨 **3.4 个数量级**（`4.3e−4 … 1.0000`）。⇒ `ρ²` 是 2 自由度对象上的 1 个约束，**结构上不能定 `w₁`**。
* 唯一精确桥：**残数–能级–隙引理** `f₁² ≥ M₀(Λ−R̄)/(Λ−m₁²)`，`R̄ = M₁/M₀`。两级情形**退化为恒等式**（返回 `w₁` 本身）；一般情形需要 `R̄`。
  用 `Λ = ρ²m₁²`、`r̄ := R̄/m₁²`：`w₁ ≥ (ρ² − r̄)/(ρ² − 1)`。表（脚本 §5）：
  `ρ²=2.48, r̄=1.5 ⇒ w₁ ≥ 0.662`；`r̄=1.9 ⇒ ≥ 0.392`；**`r̄ → ρ² ⇒ ≥ 0`（vacuous）**。
  **⇒ 这条桥能用，但缺一个数：`R̄ = M₁/M₀`（`C(t)` 的时间一阶矩/`m_eff` 加权），语料无。**

## 5. 死线裁决

* **(a) 成立——`f₁²(2.5)` 远大于 `r₀ = 0.031`**：`w₁(M) / r₀ = 0.48/0.031 … 0.86/0.031 =` **15× – 27×**（对最紧口径 `½c₁u|_{N=2}=0.0104` 是 46×–82×）。
* **⇒ 判：`f₁² ≥ r₀` 在 2.5 上「真而证不出」。** 强化证据 `[T]/[C]`：`f₁²(β) = |a(β)|²` 在 `λ₁` 简单孤立处**实解析**（Kato；`yang-mills-frontier:98`），且 `ℝ_an`-可定义 ⇒ **零集有限**（o-minimal 恒等定理；`:226`）⇒ 固定 `(L,a)` 下 `f₁² > 0` 除**有限个孤立 β** 外全成立，**不存在开的无隙区间**。⇒ 「1/48 之上为假」这件事**已被证伪**；1/48 是 Ursell 半径，**是方法的墙，不是对象的墙**。
* **但「一致地板」仍证不出，而且不是加把劲能补的**：o-minimal/解析性只给**逐点**正性；目标要求 `(L,a)`-一致（`dim ~ (L/a)⁴ → ∞`、`β(a) ~ log(1/a)` **非可定义**，`:226` 已明写可定义紧性不可达）。
* **方向结论**：要的是**新证明**——对**无量纲 `w₁`（`γ=0`）**做一致下界，而不是把 `r₀(β)=½c₁u^p` 外推。`r₀` 随 `β→0` 而 `→0`（`V05-CPTRANS:122`），它天然不是搬运用量；`w₁` 才是。（语料 `U6-NG1` 只否掉「权重数据强制 `ρ²`」，不否「权重本身有地板」。）
* **(b) 不成立**：`f₁²(2.5)` 不"很小"——`w₁` 是 O(1)。
* **(c) 需要的测量（按性价比）**：① 已有 npz 就能补 `R̄ = M₁/M₀`（零成本，`w₁` 的表 §5 立刻变可判）；② β=2.5 正式 run（`R4` 协议，6–12 CPU-h，一次一个）给 `w₁(2.5)` 与 `ρ²`；③ `L=8,12` 序列判 `w₁` 的 `L`-漂移（这才是缺的**一致**性，不是符号）。
