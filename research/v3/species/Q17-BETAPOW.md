# Q17 — `p19` 的 `Var(F) ~ β^1.57`：真幂还是窗口效应？

## 0. 裁决（一句话）

**`1.57` 是 `β∈[1,6]` 上一条**单调下降曲线**的弦平均，不是幂律；但渐近幂也**不是 2**。**
`β²` 只在单 plaquette 的 `S≡β` 切片上严格成立；`L=2` 上 `Var/β²` 从 `0.2888` 掉到 `0.1315`（×0.455），没有任何 `β²` 主导。
**`L=2` 的局域指数 `1.815 → 1.649 → 1.295 → 1.258`：单调下降，不漂向 2。** 故 `(a)` 否；`(b)` 的**前半**成立（`β²` 是单 plaquette 专属），后半（`1.57` 是 `L=2` 标度）不成立；渐近幂**判不出**，→ `(c)`。

## 1. 四点局域对数导数 `[T]`（对给定四点做精确算术）

数据 `p19_fit.py:7`：`Var(F) = 0.2888, 1.5232, 2.8421, 4.7329`（`β=1,2.5,4,6`）；误差 `p19_b*.log:22`。
题面四舍五入值 `0.289/1.523/2.842/4.733` 与全精度差 <0.1%，不改变任何结论。

|---|---|---|---|---|

逐区间坡度：`[1,2.5]=1.815`、`[2.5,4]=1.327`、`[4,6]=1.258` —— **三段连续下降**。
`Var/β² = 0.2888, 0.2437, 0.1776, 0.1315` —— 单调掉 55%，`β²` 项若为正只能使其上升 ⇒ **不存在**。

**单调下降的显著性**：用保守的 tau 误差，总降幅 `0.557/0.317 ≈ 1.8σ`（弱）；用 jackknife `0.557/0.128 ≈ 4.4σ`（强）。故**方向**（下降）不硬，但**反向**（升向 2）已被排除：`e(6)=1.258±0.307`，`+2σ` 仅 `1.87 < 2`，且趋势与之相反 `[C]`。

## 2. 单 plaquette 对照 `[T]`

`Var = β² V₀`，`V₀ = 0.011059293772974`（`h1e_var.log:12`，闭式 `N2/(4Z)` 与求积差 `2.5e-16`）。
同四点 `Var = 0.011059, 0.069121, 0.176949, 0.398135`，**四个局域指数全等于 `2.000000000000`**。
独立复核：`o05_var_scaling.log:65-72`（`θ=π`）在 `7` 个区间上全为 `k=2.0000`；`h1e_var.log:46-48` 的 `E[S]=β` 差 `0` / `8.9e-16`。
⇒ **`β²` 严格性来自 `S≡β` 切片把作用量方差钉死，而无高阶项**（同 `o05`/`h1e`/`q10`）`[T]`。

## 3. 窗口敏感性 `[C]`

| 窗口 | 单幂指数 |
|---|---|
| `[1,2.5]` | 1.815 |
| `[1,4]` | 1.649 |
| `[1,6]` 弦 / 最小二乘 | 1.561 / **1.572**（= `p19_fit.log:19` 的 1.57） |
| `[2.5,6]` | 1.295 |
| `[4,6]` | 1.258 |

单个数在换窗口时移动 `0.56`（`1.26 ↔ 1.82`）⇒ **`1.57` 是窗口产物**。
且 `[1,6]` 对数残差 `[-0.078, +0.145, +0.030, -0.097]` 是**系统曲率**（`-- - +`），不是噪声：单幂律在窗口内已不成立 `[T]`（算术）/`[C]`（数据）。

## 4. 模型比较（相对加权 `min Σ((model/V)-1)²`）`[E]`

| 模型 | rms | max\|r\| |
|---|---|---|
| `a β²` | 0.175 | 0.275 |
| `a β² + b β` | 0.132 | 0.204 |
| `a β + c` | **0.024** | 0.035 |
| `a β^{5/4}` | **0.025** | 0.039 |
| `a β^{1.571}`（p19） | 0.090 | 0.139 |
| 最优双幂 `aβ^p+bβ^q` | 0.003 | —（`p=1.04,q=0.30`） |

* 任何含 `β²` 正项的形式都在 `β=2.5` 处偏 `20–28%` ⇒ **`β²` 在 `L=2` 被排除**。
* `β^{5/4}` 与 `β¹(+const)` 都落在误差内（≤4%），**互相不可分**；`1.571` 在 `β=2.5` 偏 `14%`（≈2σ）。
* `rms<0.01` 的 `(p,q)` 组合有 **149** 个 ⇒ 四点**参数退化**，双幂无法定标。
* 外推局域指数：`β^{5/4}` → `1.30/1.28/1.26`（`β=8/10/20`）；`aβ+c` → `1.09/1.07/1.03`；`aβ^{1.571}` → 恒 `1.57`。

**正确写法（当前可判的唯一形式）**：
`Var(L=2) = A β^{p(β)}`，`p` 单调下降；四点内 `Var ≈ 0.50 β^{5/4}`（rms 2.5%）或 `≈ 0.89β − 0.60`（rms 2.4%）。
**渐近幂 `p_∞ ∈ [1, 5/4]`，但不能与 `1.57` 相容，也**绝不**是 `2`。**

## 5. 对 `p10`/`q06` 的后果（判死线 (a) 的链条断在第二环）

`(a)` 的逻辑是「窗口效应 ⇒ `β²` 才对 ⇒ `D/S→1` 要加强」。**第一环成立、第二环不成立**：
`1.57` 确是窗口弦平均，但 `β²` **不是** `L=2` 的渐近律 `[C]`。因此：

* `D/S→1`（`0.505, 0.787, 0.848, 0.889`）**不能**用「`β²` 项变大」解释 —— `Var/β²` 反而在掉。
* 实测机制是两个**近似同幂**的量在赛跑：`E[κ] ~ β^{1.156}`（`[2.5,6]`）/ `β^{1.140}`（`[4,6]`）对 `Var ~ β^{1.258}`。`Var` **略快** ⇒ `D/S→1`、相对余量 `G''/E[κ] = 0.495, 0.213, 0.152, 0.111` 趋于 0。
* **风险（末条必须下游核）**：若 `p_Var > p_Eκ` 持续，`G''(0)=E[κ]−Var` 会在有限 `β` 变号。用 `p_Eκ=1.14, p_Var=1.26` 锚在 `β=6` 得交叉点 `β* ≈ 16`；`q−p` 的不确定度 `±0.15` 使 `β*` 落在 `[5, 780]` 的巨大区间 `[E]`。
  **⇒ `G''(0)>0`（项目"钥匙"）在 `L=2` 的 `β∈[1,6]` 窗口内成立，但窗口不给出大 `β` 余量**；`p10`/`q06` 的 `D/S→1` 判断**必须**改成「相对余量消失 + 绝对余量仍增（`0.2835→0.5913`）」两句，并附 `β*` 未定。

## 6. 判死线归档

* **(a) 否**：局域指数下降（`1.815→1.258`），不漂向 2；`β²` 在 `L=2` 被模型比较排除（20–28% 偏差）。
* **(b) 部分成立**：`β²` 是**单 plaquette 专属**（`S≡β` 切片）`[T]`；但 `L=2` 的正确标度**不是** `1.57`，而是 `p(β)` 下降的 `A β^{p(β)}`，`p_∞ ∈ [1, 5/4]` `[C]`。
* **(c) 渐近幂判不出**：需 `β ∈ {8, 10, 12, 16}`（判据见 §7），四点不足以定双幂（149 组等价）。
