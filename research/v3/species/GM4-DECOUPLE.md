### 1.1 (a) 2D YM：精确见证

[O(x),H] = 0 ,      O|Ω⟩ = 0      ⇒  (O−⟨O⟩)Ω = 0  ⇒  全部连通矩阵元 = 0  ⇒  ν_{O,c} ≡ 0

### 1.2 (b) 一般构造：`O` 与最轻态正交（对称性）

**`O` 的量子数。** `O=¼trF²` 是：Lorentz 标量、规范单态、`C=+`、`P=+`、`T=+`、中心 1-形式中性、`J^{PC}=0^{++}`。它是 `0^{++}` 胶球的标准插值算符（格点上就是 plaquette/`trF²` 型算符）。

**4D 纯 YM 的已知整体对称性。** 规范、`C`、`P`、`T`、Lorentz、中心 `Z_N` 1-形式（作用在基本表示 Wilson 环上；`O` 中性）。**没有一条**迫使 `⟨Ω|O|G⟩=0`。`O` 与真空同量子数，`0^{++}` 是最轻态（格点），所以 `f₁²>0` 是**generic** 期望，不是对称零。

**唯一可能的对称性解耦**：最轻态若不在 `0^{++}`（例如 `0^{-+}`、`2^{++}`），`O` 会因 `J^{PC}` 与之正交。但：

1. 这是**动力学排序**，不是对称性；
2. "`0^{++}` 最轻"是**比靶更强、且与靶双向独立**的命题：窗外 `[O]`，攻它不等于攻靶（`GK4-LIGHTEST:17` 逐字）；
3. 格点给的是 `0^{++}` 最轻（纯 YM，`SU(2)/SU(3)`），不是 `0^{-+}`/`2^{++}`。

**2D 的"解耦"也不是对称性。** 它是 `O∝H` 的载体恒等式；同一 2D 里 holonomy 载体与 `¼trF²` 有**相同**的 `C/P` 量子数，却 `f₁²>0`（`ATOM2:81–86`；`GK4-OCHAN:22`）。⇒ 2D 的解耦不可能是"对称性把 `O` 与最轻态正交"，而是"`O` 恰好是守恒荷"。

**判。** (b) 在 4D 纯 YM 里**为空**：`[NG]`（无对称零；唯一可能的 `J^{PC}` 解耦是更强且独立的动力学命题，不是对称性路）。中心对称、`'t Hooft` 异常都不约束这个矩阵元。

## §2 · 2D 见证的 4D 可搬性

### 2.1 `K₂` 的事实与因果勘误

**事实 `[T]`。**

```
2D：H_a = (g²/2)ΣĈ₂ 无 a ⇒ K₂ ≡ 0                    （GM2-EDGE:282）
4D：K₂ ≠ 0。磁扇区显式：
    K₂^{mag} = −(1/(24g²))∫Σ_{i≠j} tr(D_iF_ij)² ≤ 0   （GM1-ALGEBRA:21,85）
    电扇区：本轮未算，[NG]（GM1-ALGEBRA:120）
    自由有质量：K₂ = −H³/24（单粒子扇区）              （GM2-EDGE:281）
```

所以题面的"2D `K₂≡0`，4D `K₂≠0`"作为**事实**成立。

**但它不是解耦的原因 `[T]`+`[M]`。** `K₂=0` 是**候选 (b) `c₁>0` 在 2D 上退化**的原因（`GE3-GAPLB:132`：2D `K₂=0 ⇒ c₁≡0`），不是 `O` 在 2D 上解耦的原因。解耦走的是**另一条**：`O∝H`（载体退化）。两者同源于"2D 无空间 plaquette"，但是**两个可分离的推论**；`GK4-2` 给出分离见证：同一个 2D YM，换 holonomy 载体，`f₁²` 从 `0` 翻成 `>0`，而 `d=2`、`K₂=0`、`F∧F=0` **一个没变**（`GK4-OCHAN:22`；因果勘误逐字见 `:23,96`）。

⇒ **`K₂≠0` 不蕴含"4D 有解耦机制"，`K₂=0` 也不解释"2D 解耦"**。4D 的正确问题不是 `K₂`，而是：**`¼trF²` 是不是 `H` 的函数/守恒荷？**——这是 `GK4-1` 的**载体命题**（"`O` 的谱测度的底落在 `Δ^H` 上"），不是 `H` 侧的谱命题（`GK4-OCHAN:0.2`）。从 `K₂≠0` 推"载体矩阵元非零"是**类型错位**：`K₂` 管 `H_a` 的 `a²` 系数，`f₁²` 管 `⟨Ω|O|G⟩`。

### 2.2 4D 的 `¼trF²`：为什么没有 `O∝H`

**2D 的恒等式 `[T]`。**

```
O = ½trE² ,   H = (1/g²)∫½trE²   ⇒   O = g² h ,   [O(x),H]=0（等时 E 对易）
```

**4D 的断裂 `[T]`（结构）+ `[M]`（归一）。**

```
O = ¼trF² = ½(E²+B²)（Euclidean）        ← 含 B²
H = (g²/2)∫E² + (1/(2g²))∫B²（KS 归一）  ← 电/磁系数不同
⇒ O 与 H 不成比例；[O,H] ≠ 0
```

- `O` 是**迹反常** `T^μ_μ ∝ (β(g)/2g) trF²`（模 β 函数），不是 Hamiltonian；2D 里它同时是能量密度（因为只有 `E`、无磁压），4D 里它是**伸缩荷密度**，与 `H` 是两个算子。
- `B²` 在不同点的对易子非零（非阿贝尔），所以即使把系数调成一样，`[O(x),H]` 也不为零；4D 没有"`E` 对易 ⇒ `O` 与 `H` 对易"这条 2D 专属结构。
- ⇒ **4D 没有 `O∝H`，因此没有 2D 那台"精确解耦"机制**。`[NG]`（机制）。这不是"还没算"，是**维数锁定**（`ATOM2:89` 同判："4D 的 `¼trF²` 含 `B²` 项，`[O,H]≠0`，2D 的零原子是维数锁定"）。

### 2.3 4D 自由有质量规范场：现象可搬、机制不可搬

`GK4-OCHAN:0.6` 的精确反例：**4D 自由有质量规范场**（字面 `1^⊥` 读法）里，`O=¼trF²` 的 `f₁²=0`（双光子割线），而 `Δ^ν/Δ^H = 2m/m = 2` **精确**（`GR2:223`、`R5-EXACT-ANCHORS:54–58` 同判"for a free field it is absent (`f₁²=0`)"）。

⇒ **"有隙+解耦"这个现象在 4D 规范理论里也是精确可实现的**；它的机制是**自由场 Wick**（`F²` 二次、单粒子态奇数 ⇒ `⟨Ω|F²|1p⟩=0`），**不是** `O∝H`。所以：

- 2D 机制 = **维数锁定**（无 `B²`、`E` 对易）；
- 4D 自由机制 = **自由锁定**（Wick 奇偶）；
- 两者都**不**搬到 4D 相互作用纯 YM：在相互作用里 `|G⟩` 是胶球束缚态，`⟨Ω|F²|G⟩` 没有 Wick 零；格点正是用 `F²`/plaquette 作 `0^{++}` 插值算符（`R5-EXACT-ANCHORS:54–58`：`f₁²` 非零的结构原因是 **BINDING**——`trF²` 的稳定单粒子态严格低于双胶子阈；2D/自由场/`β=0` 都没有它）。

⇒ **4D 纯 YM 的"有隙+解耦"= `[O]`**：没有见证，也没有 no-go；对称性路为空（§1.2），自由场机制不被保护，2D 机制维数锁定。**这是本路唯一保留的 `[O]`。**

### 2.4 判词

|---|---|---|---|

**⇒ 2D 见证的 4D 可搬性：`[NG]`（机制）；4D 纯 YM 的现象：`[O]`。** 这两条都**不**把 ③ 救成 `[T]`（见 §3）。

## §3 · 对 ③ 的意义（本路主判）

### 3.1 ③ 是什么

`docs/position-current.html:596` 逐字：**③ 振幅地板 `f₁² ≥ r₀`，窗内 `[T]` / 窗外 `[O]`**。这里的 `f₁²` 是 `O=¼trF²` 的 `0^{++}` 道 KL 测度在**最轻 `O`-耦合能级**上的原子权重：

```
ν_L = Σ_{n≥1} f²_{n,L} δ_{E_{n,L}} ,   f₁²_L := ν_L({E_{1,L}}) = |⟨G_L|O|Ω_L⟩|²
```

`L` 是**一致化轴**，不是极限；`L→∞` 的残数另需 `I2`（`P3-CYLINDER-RESIDUE:74,92`）。而靶 `T` 是**全道** `inf spec(H|Ω^⊥)>0`（`B06-VERDICT:13–14`）。所以 ③ 与 `T` 是**不同量词**的对象：③ 是**逐道 + 有限 `L`-一致**的振幅读数；`T` 是**全道**的谱底。**这个量词差不是细节，是本节的主刀。**

**先钉"模方"这一步**：`f₁² = |⟨Ω|O|G⟩|² ≥ 0` 是**恒真**的（模方）；③ 的全部内容在**严格性** `≥ r₀>0`，即"底上真的有一个原子"，不是"底上有一个非负数"。⇒ 证明 ③ 不是证明一个不等式，是证明一个**原子存在**；而原子存在是 **BINDING**（`R5:54–58`），不是模方的推论。

### 3.2 ③ 不必要（`T ⇏ ③`）

| 见证 | `m` | `f₁²` | 出处 |

| 4D 自由有质量标量 `θ^μ_μ` | `m>0` | `0`（从 `4m²` 的割线） | `[T]`：`GK3-ATOM:82–89` |
| 4D 自由有质量规范 `F²` | `m>0` | `0`（`Δ^ν/Δ^H=2`） | `[T]`+`[E]`：`GK4-OCHAN:0.6` |

⇒ **"有隙 ⇒ 有原子"不是结构真理**；③ 不是靶的必要条件。**限定（AGENTS §2.1）**：2D 见证在 4D 靶的论域之外（`GK4-OCHAN:0.7`）；4D 见证是自由场，不是纯 YM；薄原子族是测度/算子抽象，不是 YM 构造。所以这一条**不**证明"③ 在 4D 纯 YM 上假"，只证明"③ 不是 gap 的结构性伴随"。

### 3.3 ③ 不充分（`③ ⇏ T`）

⇒ **"有原子 ⇒ 有隙"也不是结构真理**：M6 的原子在 `E₁=ω`，零模在**另一条道**（`b` 的 `C→∞`）；全道 `m=0`。`B06` 把这一点写成量词：`m₁²=inf supp ν_{¼trF²}` 只是 `0^{++}` 一道，全道是 `inf_c Δ_c`；`Clay ⇒ B` 真，`B ⇒ Clay` 假。

**窗内的唯一缓和**：窗内 `δ` 是 `J^{PC}`-盲的，所以全道量词在窗内**免费**（`B06:52–53`）；但窗内隙已由 OS'78 给出，③ 在那里是**零增量**；窗外全道量词是同一堵墙。⇒ ③ 作为"路线"在窗内不产生新东西、在窗外不是充分条件。

### 3.4 判词：`[NG]`

```
③（作为靶的等价形式/路线） = [NG]
③ 的 4D 纯 YM 实例          = [O]（无见证、无 no-go）
```

**为什么 `[NG]` 不依赖 4D 可搬性**：

- 若 2D 见证可搬 ⇒ 4D 纯 YM 里 ③ **假**；
- 若不可搬（本文件 §2 的判） ⇒ ③ 在 4D 纯 YM 里至多是**必要条件**，而必要条件是**不能当路线**的（证它不给隙；且它在窗外本身是 `[O]`）；
- 两种情形下 ③ 都**不是**靶的等价形式。⇒ `[NG]` 稳健。

**为什么不是 `[T]`**：`[T]` 会要求"`m>0 ⇒ f₁² ≥ r₀`"是一条已证定理。但 (i) 2D/自由场/薄原子族三个精确见证否掉"必要性"；(ii) 4D 纯 YM 的"有隙+解耦"是 `[O]`，不是已证的假；(iii) 即便 4D 纯 YM 无解耦，也只给 `f₁²>0`，不给常数 `r₀`，更不给全道隙。⇒ **未证不标 `[T]`**。

**③ 的真实身份**：`R5-EXACT-ANCHORS:54–58` 逐字——使 `f₁²` 非零的结构原因是 **BINDING**（`trF²` 的稳定单粒子态严格低于双胶子阈），不是 Haar 测度、不是紧性、不是载体规范不变性本身；强耦合窗内有它（P3 四壁管），`β=0`、2D、自由场都没有它。⇒ **③ 是 `0^{++}` 道"束缚/稳定单粒子"的诊断量，不是全道隙的等价形式。** 这与 `B06` 的"逐道 vs 全道"是同一句话。

### 3.5 保留什么、下一手是什么

- **保留**：③ 在窗内是 `[T]`（P3），且它是 `0^{++}` 道绑定的**诊断**；`f₁²` 作为读数仍然有用（`CLAUDE.md §5` 的"钥匙"里它是一个名字）。
- **撤下**：把 ③ 当"靶的等价形式/路线"。`CLAUDE.md §5` 的"等价 `f₁²>0` 搬运 / H1 / (CP) / 胶子凝聚"这句话，按本判词必须读成**"一致搬运"版**（H1/I2 的 `(L,a)`-一致下界），不能读成**裸振幅地板**；裸振幅地板被 2D/M6 两个精确见证夹死。
- **下一手**：① 若攻隙：证 `(L,a)`-一致下界（`H1`/`I2`/`(CP)`）或全道 `δ`，不是 ③；② 若攻"4D 纯 YM 解耦"这个独立问题：正确对象是**载体矩阵元**（`GK4-1`：`O-chan` 是载体命题，不是谱命题），不是 `K₂`；（三）停做"用 ③ 当换名"的记账。
- **出口**：本条路的出口 = `[NG]`（机制/路线），下一手 = `H1`/`I2` 的一致地板，或把 `0^{++}` 稳定性作为**独立物理输入**（`R5:54–58` 的 BINDING）。
