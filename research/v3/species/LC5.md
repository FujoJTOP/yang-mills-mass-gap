# LC5 · `a_n` 的次可乘性与 `λ_*` 的有限项上下界

**靶**：`a_n` = 4D plaquette 图上**过固定片 `p₀` 的连通片集**数；`λ_* = lim a_n^{1/n}`；要证 `λ_* ≤ 48`。
**语料**（钉死，逐位复现）：`a_n = 1, 20, 458, 11132, 280175, 7218768`（`n=1..6`）
—— `research/v3/species/UR4.md:51`（`n≤5`）· `w7/ur4_enum_n6.log:19–21`（`n=6`）· 独立码 `research/v3/species/w7/ur1_enum_n6.log:3–5`。
**本轮机器**：`w7/lc5_submult.py` → `w7/lc5_run.log`（`py -3.12`，`exit 0`）。

## 1 · 第一问：次可乘性的精确形式

**精确次可乘性 `a_{m+n} ≤ a_m·a_n` 不成立——被数据硬推翻。** `[T]`（反例即证明）

`m+n ≤ 6` 的全部 **9** 对（`w7/lc5_run.log §2`）：

| `(m,n)` | `a_{m+n}` | `a_m a_n` | 比值 `a_{m+n}/(a_m a_n)` | 判 |
|---|---|---|---|---|
| (1,1) | 20 | 1 | 20.0000 | ✗ |
| (1,2) | 458 | 20 | 22.9000 | ✗ |
| (1,3) | 11132 | 458 | 24.3057 | ✗ |
| (1,4) | 280175 | 11132 | 25.1684 | ✗ |
| (1,5) | 7218768 | 280175 | 25.7652 | ✗ |
| (2,2) | 11132 | 400 | **27.8300** | ✗ |
| (2,3) | 280175 | 9160 | 30.5868 | ✗ |
| (2,4) | 7218768 | 222640 | 32.4235 | ✗ |
| (3,3) | 7218768 | 209764 | **34.4138** | ✗ |

* `SUB-FAIL = 9/9`。**最轻的一个杀手**：`a_1 = 1` ⇒ 次可乘性会强迫 `a_n ≤ 1 ∀n`，而 `a_2 = 20`。
* **反向在 9/9 对上全成立**：`a_{m+n} ≥ a_m a_n`（最小余量 `20.0`，在 `(1,1)`）⇒ 序列**经验上超可乘** `[E]`（不是定理；只验到 `m+n ≤ 6`）。
* 因此**"次可乘的 Fekete 上界"这条路在本序列上不存在**：符号是反的。

**能立的形式只有两种**（都非定理，需证）：

| 形式 | 内容 | 用途 | 状态 |
|---|---|---|---|
| (W-) 弱次可乘 | `a_{m+n} ≤ P(m+n)·a_m a_n`，`P` 多项式 | `log a_n` 次可加至 `O(log n)` 缺陷 ⇒ `λ_*` 存在 | `[C]`（组合拼接需 ≤ 多项式多计；本模型未写证明） |
| (C-) 常因子 | `a_{m+n} ≤ C·a_m a_n`，`C` 与 `m,n` 无关 | `b_n:=C a_n` 次可乘 ⇒ **有限项给上界** | `[C]`；观测 `C ≥ 34.41` 且随尺寸上升（27.83 → 32.42 → 34.41）⇒ 无证据支持"一致 `C`" |

## 2 · Fekete 两个方向（这是全部答案的骨架）

设 `b_n = log a_n`。

1. **次可乘**（`a_{m+n} ≤ a_m a_n`）⇒ `b` 次可加 ⇒ `λ_* = lim = inf_n a_n^{1/n}` ⇒ **每个有限项都是上界**：`λ_* ≤ a_n^{1/n}`。
   —— 本序列不满足（§1），**此路封死**。
2. **超可乘**（`a_{m+n} ≥ a_m a_n`）⇒ `b` 超可加 ⇒ `λ_* = lim = sup_n a_n^{1/n}` ⇒ **每个有限项都是下界**：`λ_* ≥ a_n^{1/n}`。
   —— 与本序列 9/9 相符（`[E]`）⇒ **有限项只给下界，永不给上界**。
3. **(C-) 变体**：`a_{m+n} ≤ C a_m a_n` ⇒ `λ_* = lim (C a_n)^{1/n} = inf_n (C a_n)^{1/n}` ⇒ 上界 `λ_* ≤ (C a_n)^{1/n}`，**但 `C` 必须是被证明的一致常数**。

## 3 · 下界：`λ_* ≥ a_n^{1/n}`（数）

| `n` | `a_n` | `a_n^{1/n}` | 相邻比 |
|---|---|---|---|
| 1 | 1 | 1.000000 | — |
| 2 | 20 | 4.472136 | 20.0000 |
| 3 | 458 | 7.708239 | 22.9000 |
| 4 | 11132 | 10.271723 | 24.3057 |
| 5 | 280175 | 12.288132 | 25.1684 |
| 6 | 7218768 | **13.901997** | 25.7652 |

* **更正一处数**：`n=6` 的 `a_6^{1/6} = 13.901997`（`tn1_enum_n6_final.log:14`），**不是 15.58**。
  `15.580645` 是 `m_n^{1/n}`，`m_n = Σ_{|Γ|=n}|φ^U(Γ)|` 的那个根（`w7/ur4_enum_n6.log:12,21`；`UR4.md:99`）。**两个常数（`a` 与 `m`）被混用了**。
  核对：`15.58^6 = 1.4302e7 ≠ a_6 = 7218768`。
* 单调性：`a_n^{1/n}` 严格升、`a_{n+1}/a_n` 严格升（`20 < 22.9 < 24.3 < 25.2 < 25.77`）⇒ 序列远未进渐近区，`λ_* ≳ 25.8`（下界，且**只会继续涨**）。

## 4 · 上界：给什么？

* **无条件**（repo 已有、不靠 Fekete）：`a_n ≤ r_n = (1/n)C(nΔ, n−1)`，`Δ=20` ⇒ `r_n^{1/n} → eΔ = 54.365637` ⇒ `λ_* ≤ 54.3656` `[T]`（`ADJ2.md:14,44`）。
  实测 `a_n ≤ r_n` 对 `n=2..6` 全成立（`lc5_run.log §5`）。**缺口 = 54.3656/48 = 1.1326×。**
* **(C-) 条件上界模板**（唯一能给"有限项 + 因子"的上界）：
  `λ_* ≤ min_{k≤n}(C a_k)^{1/k}`。若**假设** `C = 34.4138`（观测最小值，未证）⇒ `inf_{k≤6} = 24.878623 < 48`。**这不构成证明**：`C` 出现在界里，`C` 只能靠定理给，靠"观测下界 34.41"给不出上界。
* **够用的弱引理（本轮的正面产出）**：只要证出**任何**一致 `C ≤ 1694.277`，即得 `λ_* ≤ 48`。

  | `n` | `C_48(n) = 48^n/a_n` |
  |---|---|
  | 1 | 48.000 |
  | 2 | 115.200 |
  | 3 | 241.467 |
  | 4 | **476.861** |
  | 5 | 909.446 |
  | 6 | **1694.277** ← 最弱要求 |

  即 `a_{m+n} ≤ 1694 a_m a_n` 就够（配 `n=6`）；配 `n=4` 只需 `C ≤ 476.86`。观测到的 `C ≥ 34.41` 比阈值小 **49×**，所以**引理的真实内容很松**——难点不在常数大小，在"一致"二字。

## 5 · 判死线

* **(a) 逐字给的"缺口关闭"**：**不存在**。次可乘被推翻 `[T]`，故"次可乘 + 有限项 ⇒ 上界"不适用；`(C-)` 形给的上界依赖未证的一致常数，不能算关闭。
* **(b) 明说**：**有限项 + Fekete 不能证 `λ_* ≤ 48`。** 因为本序列是**超可乘**形状，Fekete 只给 `λ_* = sup_n a_n^{1/n}`（存在 + **下界**），方向与所需求相反。现上界 `54.37` 来自**树包络**（非 Fekete），而非有限项。
* **(c) 若仍想靠多项**：`n=7` 起 `a_7 ≈ 1.9e8`（按 `×25.8` 外推），穷举级别 `10^8` 集合，`ur4` 式枚举内存不可承受（`n=6` 已 59–198 s）⇒ 需换**拓扑 DP / 转移矩阵**（`UR5` 的 `#sets = n·|Orb|/6` 口径可接）。但即使拿到 `a_12`，也只是把**下界**抬到 `~26–30`，**永远不给上界**。**需要的不是更大的 `n`，是一条局部比引理或一致 `C` 引理。**

## 6 · 唯一能到 48 的路（本轮结论）

**局部比引理**：`a_{n+1} ≤ B·a_n`（`B` 显式，由"新片只能挂在已有片上 + 每 link 6 片、片有 8 邻片"的簿记给），则 `a_n ≤ B^{n-1}a_1` ⇒ `λ_* ≤ B`，**不需要 Fekete、不需要次可乘**。
观测最大比 `25.7652`，对 `B = 48` 有 **1.863× 松量**；且 `a_{n+1}/a_n < 48` 从 `n=2` 起就成立 ⇒ 该引理在数据上极稳，缺的是"每步 ≤ 48 个合法插入"的**组合簿记证明**（`48 = 8×6 = 邻片数 × 每 link 片数`，与 `Δ=20`、`d=4` 的算术一致）。

## 7 · 限制与遗留

* 次/超可乘的判定只用 `m+n ≤ 6`（9 对）；`a_7` 缺失 ⇒ "超可乘"只是 `[E]`，不是 `[T]`。
* `(C-)` 的一致常数**未被证**，且观测值随 `m+n` 上升（27.8 → 34.4），这本身就是"别指望一致 `C`"的负面信号 ⇒ `(W-)` 弱形更可能是真形态，而弱形**恰好给不出上界**。
