## 0 · 判死线（先说结论）

**(a) 触发 ⇒ 弱证据。** `χ²(1 dof) = 0.501`，`p = 0.479`（无张力，分支 (a) 的前提成立）；而**强耦合斜率也精确复现该比值**：

| 对 `r ≡ m a(6.30)/m a(6.00)` 的预言 | 值 | 与实测 `0.826 ± 0.163` 的差 |
|---|---|---|
| 强耦合（SC）斜率 `d(ma)/dlnβ = −4` | **`0.818–0.834`** | `0.05σ` |
| 两圈标度 `a(6.3)/a(6.0)` | `0.713` | `0.76σ` |
| 纯 cutoff／完全无跑动 | `1.000` | `1.07σ` |

三者彼此只差 **`0.74σ`** ⇒ 数据**分辨不了**标度与"纯 cutoff"。`p = 0.48` 只说明"没有张力"，**不构成"标度成立"的证据**；在同两点上把同一检验跑在"完全没有跑动"的世界里，它照样给 `p = 0.285`（`~28%` 的无标度假世界会产出这么大的偏差）。**"在 `ξ/a ≈ 1` 处两点一致"的偶然性不是小概率，它就是常态。**

**(b) 不触发**：SC 与 `0.826` 差 `0.05σ ≪ 3σ`。**(c) 不触发**：`χ²` 有意义（`σ_r/r = 19.7%`，非"无意义"）。

**对 A8 要改的一句**（`[M]`）：`A8:61`"这条把 (b) 排除了 …… 所以语料在这两点上**是**在微扰跑动曲线上的"——前半句成立（**无张力**），后半句不成立（**无判别力**）。正确写法：*"两点无张力（`0.71σ`），但 `ξ/a ≈ 1` 处该检验的判别力只有 `0.74σ`（SC 与标度不可分），故 `(b)` 只被'未被违反'地保留，未被'检验'。标度性的正面证据仍需 `ξ/a ≥ 2` 的两点。"*

## 3 · 关键对照：`ξ/a ≈ 1` 处 `m a` 由 `β` 定，还是由标度定？

### 3.1 写出来的公式（领头阶，两个都在语料里有前身）

**(F1) 强耦合（SC）领头质量**：4D SU(N) Wilson、`0⁺⁺`、四壁管

```
m a = 4 ln(1/u) + O(u),      u = c_f(β) ≍ β/(2N)
⇒ m a = −4 ln β + const      ⇒  d(m a)/d ln β = −4   （EXACT，与 log 里的常数取 6/β 还是 18/β 无关）
```

`[T]` 系数 `4` 与四壁几何：`P3-AUDIT-CORRECTED.md:11,33`（Gupta (14.20)–(14.21)、Münster `m=−4ln u+…`）；`[T]` 语料同式：`A4-SCALE-SEP.md:20`（SU(2) `ma = 4ln(4/β)`）、`A6-TARGET.md:22`。**斜率 `−4` 是约定无关的**——log 的自变量写成 `β/(2N)` 还是 `β/(2N²)`，`d/dlnβ` 都一样是 `−4`。

**(F2) 两圈跑动**（标度假说 `m = const` ⇒ `m a ∝ a`）：`A8-MASS-LAMBDA.md:22-24` 的 `b₀、b₁` 与闭式，本脚本复算 `a(6.30)/a(6.00) = 0.7130`，与 A8 用自己 `Λa` 值给的 `1.2489/1.7518 = 0.7129` 一致（`[C]`）。

### 3.2 三个预言，都不拟合 `r`

| 模型 | 预言 `r` | 依据 |
|---|---|---|
| **D1** SC **绝对式** `m a = 4 ln(2N/β)` | `β=6.00 → 0.0000`；`β=6.30 → −0.1952` ⇒ **比值无定义/符号翻转** | 式 (F1)。它的零点正好在 `β = 2N = 6`。**这两点就在 SC 展开的边界上/之外** `[M]` |
| **D2** SC **斜率** `d(ma)/dlnβ = −4`（一个锚定数 `m a(6.00)`，斜率无参数） | 加性 `m a(6.3) = 1.0730 − 4ln(6.3/6.0) = 0.8778 ⇒ r = 0.8181`；对数斜率 `exp(−4Δlnβ/ma) ⇒ r = 0.8337` | 式 (F1) 的微分内容 `[T]`→`[M]` |
| **D3** 两圈标度 | `r = 0.7130` | (F2) `[C]` |
| **D4** 零假设：完全无跑动（纯 cutoff 质量） | `r = 1.0000` | `[M]` |

**D1 念出来**：`m a = 4ln(2N/β)` 在 `β=6` 上**自己等于零**，即 `ξ/a → ∞`——与实测 `ξ/a = 0.93` 直接冲突。所以这个公式在这两点上**不能给比值**；能用的只有它**约定无关的斜率** `−4`（D2）。这不是含糊其辞：`β = 2N = 6` 就是 SU(3) 强耦合展开的零点，`β=6.0/6.3` 已在这一侧——**这本身就是"这两点不是强耦合点，但也不是标度区深处"的定量表述**。

## 4 · 判别力：这个检验有多"瞎"（"偶然性"的定量回答）

`[M]` 三把独立的尺，都指向同一个数：

1. **模型间距 vs 误差**：`|r_SC − r_scaling| = 0.1207 = 0.74σ`（用今天的 `σ_r = 0.163`）。要做到 `3σ` 分辨，需 `σ_r ≤ 0.0402`（`4.9%`）——**今天差 4.0 倍**。
2. **对数斜率**：`s ≡ dln(ma)/dlnβ = −3.92 ± 4.04`（**相对误差 > 100%，斜率根本没测出来**）。标度要 `−6.93`、SC 要 `−4/(ma) = −3.73`、无跑动要 `0.00`——**三者全在 `|z| < 1.1σ` 内**。
3. **功效检验**：把一个"零跑动"世界（`r ≡ 1`）拿去过同一道关，得 `p = 0.285`；标度假说得 `p = 0.489`。似然比 `L(标度)/L(无跑动) = 1.39`、`L(SC)/L(无跑动) = 1.77`——按任何证据分级都属**"不值一提"**（"中等"要 `≳10`）。

**所以"偶然性有多大"的正确答案**：如果格点质量根本没有 `β`-跑动（纯 cutoff 质量），产生今天这么大的偏差的概率是 `28%`；如果按 SC 斜率走，今天的数落在其曲线的 `0.05σ` 内——**几乎是必然**。**"两点一致"对标度不是稀有信息，是任何 `ξ/a ≈ 1` 的机制都会产出的常态。**

## 5 · 为什么 `ξ/a ≈ 1` 结构性无信息（不是"这次运气不好"）

- `[M]` `ξ ≈ a` ⇒ `m a ≈ 1` ⇒ 质量与**格距**同阶，`m` 本身不是物理量而是 cutoff 量：`O(a)` 污染与信号同阶。用 `probe-m/REPORT.md:150` 的两个数算：`β=6.0` 物理标定给 `m a = 1.71 GeV / 2.12 GeV = 0.807`，实测 `1.073` ⇒ **高 `33%`**，是该点统计误差 `8%` 的 `4×`。
- `[E]` 同一 `β`、同一算子的质量不稳定：`probe-m/REPORT.md:137-146`（`β=6.2, L=10`，ladder `n=0,8,16,32`，`t≤3`）给 `ξ/a = 0.41, 0.99, 1.18, 1.42`——**一个 `β` 上 3.5 倍散布**。`ξ/a ≈ 1` 处"质量"还不是算子无关的可观测量，**`8%`/`18%` 只能是误差下限**。
- `[E]` A8 自陈口径差：一圈 vs 两圈 `m/Λ` 差到 `30%`（`A8-MASS-LAMBDA.md:40`）——与 `σ_r = 19.7%` 同量级，即**理论误差与统计误差同大**。
- `[T]/[M]` 连续极限要 `ξ/a → ∞`（`A4-SCALE-SEP.md:67`，转 `RATE-UNIFORM.md:39`），标度区要求 `ξ/a ≫ 1`。两点停在 `0.93/1.13`，**`ξ/a` 只长了 `21%`**；把"一致"当"标度"用，等于用 `a` 本身的漂移去证明 `a → 0`。

## 6 · 判决与"需要什么数据"

**判决：弱证据**（判死线 (a)）。**不能**据此说"标度成立"；`(b)` 只是**未被违反**，**未被检验**。

要变成**强证据**，缺的是**杠杆臂**（不是精度）。先把两条定律在 `β` 轴上摊开（`[M]`；`m a(β)` 两列都由 §3 的公式算，未拟合）：

| `β` | `ξ/a`（SC 侧） | `m a`：SC 斜率 | `m a`：两圈标度 | 差 | 若 `σ(ma)=8%` 则分离 |
|---|---|---|---|---|---|
| `6.00` | `0.93` | `1.0730` | `1.0730` | `0`（锚定点） | `0` |
| `6.30` | `1.14` | `0.8778` | `0.7650` | `+0.113` | `1.61σ` |
| `6.60` | `1.45` | `0.6918` | `0.5449` | `+0.147` | `2.65σ` |
| **`6.90`** | `1.95` | `0.5140` | `0.3878` | `+0.126` | **`3.07σ`** |
| `7.20` | `2.91` | `0.3437` | `0.2757` | `+0.068` | `2.47σ`（过 `6.9` 两曲线靠拢） |

`8%` 是 A8 在 `β=6.00` 已有的统计量级；`β=6.30` 语料只有 `18%`。表读出来的是**形状**：只有走到 `ξ/a ≈ 2` 附近两条定律才拉开到 `3σ`，再远又收窄——所以目标是 `β ≈ 6.9`，不是 `β` 越大越好。

| 要求 | 数 | 依据 |
|---|---|---|
| 两点**实测** `ξ/a ≥ 2`（`m a ≤ 0.5`），即 `β ≈ 6.7` 与 `6.9` | SC 说 `ξ/a=2` 在 `β=6.92`；标度说在 `β=6.68`。语料外推 `β=6.4 → ξ/a=2.23`（`probe-m/REPORT.md:150`），但同一外推在 `β=6.0` 给 `1.24` 而实测只 `0.93`（高 `25%`）⇒ 实际要 `β ≳ 6.6–6.9` `[M]` | `[E]/[M]` |
| `m a` 误差 `≤ 5–8%` | 上表：`β=6.9` 处 SC 与标度在 `8%` 误差下分开 **`3.07σ`**（`β=6.6`：`2.65σ`；`β=7.2`：`2.47σ`——过了 `6.9` 又收窄，因两曲线靠拢） | `[M]` |
| 每点**独立标度**（`r₀/a` 或 `√σ a`） | 否则 `ξ/a` 与 `a` 互定义，检验循环。语料现报 `ξ/a` 全由 `1/(ma)` 得来，**无独立标度** | `[NG]` |
| 变分基/GEVP，`L ≥ 4ξ` | `ξ/a ≥ 2` 时 `L ≥ 8`；且 `β` 越高同一 `L` 的物理体积越小（`β=6.4` 的 `L=8` 只有 `0.41 fm`，`probe-m/REPORT.md:154`）⇒ 要 `L = 24–32` | `[E]` |
| 加一个 `β ≈ 6.6` 中间点做**形状**判别 | 两模型形状不同：SC 是 `m a = −4lnβ + c`（对 `lnβ` 线性），标度是 `∝ a(β)`（对 `1/g²` 指数）。三点拟合两者形状差远大于任一单点比值差 | `[M]` |

**一句话**：`ξ/a ≈ 1` 的两点一致是**"不矛盾"**，不是**"证据"**；把 `ξ/a` 推过 `2`（`β ≳ 6.6`）并配独立标度，才能在 `3σ` 上把"标度"与"强耦合/cutoff"分开。
