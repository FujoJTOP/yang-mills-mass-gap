## §1 固定 (L,a)：空洞自动的三层

**1.1 恒等式与界（`[T]`）。** `q_x=1−½Re tr U_□∈[0,2]`、`q̄=L⁻⁴Σ_xq_x`、`C_q(z)=⟨q_0;q_z⟩_c`：
```
χ_q := Σ_{z∈Λ_L}C_q(z) = L⁴Var(q̄) = −κ⁻¹∂_β⟨q̄⟩        （κ=6，AAA4:5 逐字）
|C_q(z)| ≤ C_q(0) = Var(q) ≤ (2−0)²/4 = 1              （C–S + Popoviciu）
```

界 `L⁴` 与 `α`、`β` 无关且随 `a→0` 发散——正是仓内判为非靶界的运动学族（`HZE-KIN:0.2,0.6`）。⇒ 有限和给的是 `∂_β⟨q̄⟩` 的界，不是 `α>0`。

**1.2 为什么固定 `(L,a)` 的 `α` 无定义（`[T]`）。** `T_a` 紧、正、自伴，`0<λ₁<λ₀=1`（`FFF2:4`）⇒ `E_n=−(1/a)lnλ_n` 离散、`E₁>0`；KL 测度 `ν=Σ_nf_n²δ_{E_n}`（`s=E²`）**原子且带隙**。`s→0` 密度不存在 ⇒ `α` 不是 `(L,a)` 的函数；按「密度在 0 消失」读则 `α=∞`（自动），按幂尾读则无对象——两种读法都不承载 `α>0` 的内容。

**1.3 与 `fff2` 的同构（`[T]`）。** `fff2` 用 PF/紧性把 `Δ_a>0` 在固定 `(L,a)` 上判 `[T]`、内容全推给一致下界；本轮用有限和把 `χ_q<∞` 在固定 `(L,a)` 上判 `[T]`、内容全推给一致上界。两处「免费」同类：**点态免费、一致性收费**。

## §2 `α(a)` 的 `a`-依赖：膨胀，不是跑动

**2.1 主判（`[T]`，结构 + 闭式）。** 取 `s=m²`（`SSS5:1.1` 口径）。窗内物理 `ν` 固定、`E_n^{lat}=aE_n^{phys}` ⇒ `ν_a=(s↦a²s)_*ν`（权重不变；乘性重整化只改总质量，不改 `s`-依赖）。于是
```
ρ_a(s) = a^{-2}ρ(s/a²) ⇒ ρ~cs^α 时 ρ_a ~ c·a^{-2α-2}s^α
suppν_a = a²suppν ⇒ s₁(a)=a²m₁² ;  χ_lat=∫s⁻¹dν_a = a^{-2}χ_phys（无限体积极限）
```
**指数逐位不变**（`py`：`α=0.5/1/2` 的对数斜率 `0.499999999848/0.999999999918/1.999999999835`；系数 `a^{-2α-2}` 在 `a=0.5` 给 `8/16/64`、`a=0.25` 给 `64/256/4096`，全对）。故 `α(a)=α+O(a²)`：**`α(a)` 不趋零**；趋零的是谱边 `s₁(a)≍a²`，趋无穷的是 `χ_lat≍a^{-2}`（`q` 归一；`δtrF²` 归一是 `a^{-4}`，`F05:124`/`HZ6:23`）。

**2.2 `α(a)≍a^k` 只在一个错读下出现（`[T]` 判形）。** 若把 `α` 读成 `U₀`-族参数（`dν=s^αds`、`U₀=α/(α+1)`、`χ=1/α`，`EEE4:0.4,(N1)`），实测 `U₀^{lat}=aU₀^{phys}`（`EEE4:0.2`）就给 `α(a)≈U₀^{lat}≍a`（`k=1`）。但该族把**无量纲指数**与**有量纲比值** `M₀/χ` 绑成 `α=U₀/(1−U₀)` ⇒ 这是单位伪影（族在吸收谱边 `a`），与 `fff1` 判死的 `Δ_a=m_phys·a` 同型（那里差一个 `a`，这里把 `1/a` 的量纲塞进指数）。

**2.3 缺什么（`[NG]`）。** 要把 `α(a)` 写成 `(L,a)` 的函数，缺两件：**(i)** IR-局部定义（检验函数 `supp≪1` 或 Mellin 变换 `∫s^{-z}ν(ds)`，使原子测度也有「密度」）；**(ii)** `L→∞` 极限（密度只在极限里存在）。要证 `α(a)=α+O(a²)` 还需格距伪影对 `s` 解析（窗内标准、仓内未证）。仓内现有 `α` 全是**族参数**（`EEE4:0.4`；`OOO6:§2` 的 `α*=22.38` 是预算阈值），不是 `a` 的读数。

**2.4 可执行判据（零 MC）。** 在两 toy（自由块 `p=8`↔`α=2`；W2 `α=1`）上按 2.1 的 pushforward 检验两件事：指数不动、系数 `a^{-2(α+1)}` 动。任一 toy 若显示指数随 `a` 变，那是一个**改变首幂**的机制，须单列（仓内 0 条）。
