## §2 · 零点排除（答题面第 2 条：Rouché / 最大模能不能排到 `β=0.625`）

### 2.1 题面要的那个估计**恒假**（不是"未证"，是"无解"）`[T]`

> **引理 2.1（最大模排除条）.** 设 `f` 在 `D̄(β₀,r)` 解析。则
> ```
> |f(β₀)| ≤ max_{|ζ−β₀|=r} |f(ζ)|            （最大模原理，恒真）
> ⇒ 题面条件  max_∂|f| < |f(β₀)|  对任何解析函数【不可能成立】。
> ```
> *（唯一例外 `f≡const`，此时等号成立，严格 `<` 仍假。而 `f₁²` 非常数：`f₁²(0)=0 < r₀ ≤ f₁²(β_★)`。）*

**⇒ 第 2 条被逐字否掉**：以 `|f₁²|` 在圆周上的**上确界**去夹 `|f₁²(β₀)|`，方向装反了。补一句同族的反向事实：最小模原理给 `min_∂|f| ≤ |f(β₀)|`（当 `f` 盘内无零），其逆否是 "**`min_∂|f| > |f(β₀)|` ⇒ 盘内**有**零**"——与想要的结论**反向**。⇒ **圆周上的模数据永远排不掉内部零点；能排的只有振荡（振幅差）数据。**

### 2.2 可修的形（Rouché），以及它为何**逐字循环** `[NG]`

> **引理 2.2（Rouché 排除条，`[T]`）.** 设 `f` 在 `D̄(β₀,r)` 解析、`f(β₀)≠0`。若
> ```
> max_{|ζ−β₀|=r} |f(ζ) − f(β₀)| < |f(β₀)|                             (RO)
> ```
> 则在 `D(β₀,r)` 内 `f ≠ 0`（取比较函数 ≡ `f(β₀)` 的 Rouché 定理）。

`(RO)` 是**可满足**的，也是**充分**的——它才是题面"Rouché/最大模型估计"的正确形状。它要两件东西：

| 输入 | 仓内状态 |
|---|---|
| **(i) 圆上的振幅差** `max_∂\|f₁²−f₁²(β₀)\|`（或 `\|∂_β f₁²\|` 的圆上界） | **无来源**。仓内对 `f₁²` 的界只有实轴上的 `0 ≤ f₁² ≤ M₀(β)`（谱分解 `ν_L≥0`，`P3-CYLINDER:67`；`M₀=∫dν`）；而 `f₁²≥0` 与 `ν≥0` 在**复 β 下不成立**（`PROOF-COMPLEX-BETA-2D:11`）⇒ **离轴界一处也没有**。记 **`NG-2 / NOSRC`** |
| **(ii) 新圆心的下界** `\|f₁²(β₀)\| ≥ r₀`（`β₀` 在靶窗内） | **这就是靶**。唯一 `[T]` 的下界在窗**内**（`P3`/`I1`，`β_A<3.777e−3`） |
| **(iii) Lipschitz 化**：`∃C<∞ : \|d log f₁²/dβ\| ≤ C` | **逐字等价于"无零点"**：`D04-ODE.md:89–103` 命题 2.1 / 命题 2.3（`C=∞` ⟺ 零点），`Lean` 机检版 `GW1-bridge.lean`、`GW1-FLOW-TARGET.md:86,164`（"可行 `C` ⟺ `f` 无零点"）。`[T]` |

⇒ **(RO) 的每一个可实现输入都退回靶**：`(ii)` 是靶、`(iii)` 是靶、`(i)` 无源。这就是 **`NG-3 / CIRC`**。
`D04` 自己的诊断规则也同向："任何以 `F` 的逐点非零为分母的微分不等式，**都是目标的改写**"（`D04:259`；`GA1:57` 转引）。
