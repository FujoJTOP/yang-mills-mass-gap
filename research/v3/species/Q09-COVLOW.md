> 任务：用 CS 给 `Cov` 一个**可证**下界，判 `Cov ≥ −Var(G)/2` 是否成立、余量够不够、`Var(Φ')` 能否可证上界。

## 0. 一句话版

**`Cov ≥ −Var(G)/2` 是 `[T]`（CS 直接给），但它对 H1 无用。** CS 的真下界在**格点窗口**是
`Cov ≥ −0.9406`（不是 `−0.14`——`0.14` 用的是**单 plaquette** 的 `Var(Φ')=3.6e−3`，**窗口错配**）。
H1 要的是 `Cov` 的**上界**：需要 `Cov ≤ +0.3607`，CS 只给 `+0.9406` ⇒ **CS 太松 2.61 倍，不够**。
缺的正是 `Var(Φ')` 的可证上界：需 `Var(Φ') ≤ 0.0332`，实测 `0.1624` ⇒ **判死线 (b)+(c)**。

## 1. `[T]` Cauchy–Schwarz 的直接结论

对任意平方可积 `G,Φ'`：

```
|Cov(G,Φ')| ≤ √(Var G · Var Φ') = σ_G σ_Φ'          [T]，无条件、无结构假设
⇒ Cov(G,Φ') ≥ −σ_G σ_Φ'
```

用任务给的 `Var(G)=5.4477`、`Var(Φ')=3.6e−3`（出处见 §2，**注意 §2 的窗口问题**）：

```
σ_G = 2.3340,  σ_Φ' = 0.06000,  CS = 0.14004
⇒ −0.140 ≤ Cov ≤ +0.140                             [T]|给定输入的数值
```

### 1.1 目标不等式：成立，且余量巨大

`Cov ≥ −Var(G)/2 = −2.7239`。CS 给 `−0.1400` ⇒ **成立，宽松 19.45 倍**。

等价的**尺度无关**形式（CS 是紧的判据，不是巧合）：

```
Cov ≥ −Var(G)/2  ⟸  σ_G σ_Φ' ≤ Var(G)/2  ⟺  Var(Φ') ≤ Var(G)/4 = 1.3619
```

实测 `Var(Φ') = 0.1624`（格点）⇒ 比门槛小 **8.4 倍**。所以**这条不等式本身毫无风险**。

## 3. 判死线：`0.14` 够不够 / 真值 `0.94` 够不够

### 3.1 记账要点：`Cov` 在 `Var(F)` 里带因子 **2**

`Var(F) = Var(G) + Var(Φ') + 2Cov`，`H1 ⟺ W_full = E[H] + Var(G) − Var(F) ≥ 0`。
所以 CS 的代价是 `2·σ_Gσ_Φ'`，**不是** `1·`。任务文本里 "`Var(G) ≤ E[H] − 0.14`" 应为
`Var(G) ≤ E[H] − Var(Φ') − 2·(CS 半宽)`。精确（二次式）形式：

```
H1  ⟸  (σ_G + σ_Φ')² ≤ E[H]                              [T]
⟺  Var(G) ≤ (√E[H] − σ_Φ')²
```

### 3.2 三个窗口的完整账（`w7/q09_cov_cs.log [3]`）

| 窗口 | `Var(Φ')` | `CS` | (i) `Cov≥−VarG/2` | (ii) H1 需 `Cov≤` | (ii) 判 |
|---|---|---|---|---|---|
| A 任务文本（**错窗口**） | `3.6e−3` | `0.1400` | `[T]` 19.5× 松弛 | `0.4401` | **CS 够**（余量 68%） |
| B 格点 P02（`VarG=5.4477`, `E[H]=6.3315`, `Δ=0.8838`） | `0.1624` | `0.9406` | `[T]` 2.90× 松弛 | `0.3607` | **CS 太松 2.61×** |
| C 格点 o27（`VarG=5.7307`, `E[H]=6.3191`, `Δ=0.5884`） | `0.1414` | `0.9002` | `[T]` 3.18× 松弛 | `0.2235` | **CS 太松 4.03×** |

`(σ_G+σ_Φ')²` 在 B 窗口 = `7.4913` > `E[H]=6.3315`（**超 1.1598**）⇒ CS 打包后**不足以**证 `Var(F) ≤ E[H]`；
A 窗口 = `5.7314` < `6.3315`（差 `0.6001`）⇒ 恰好够。**"够不够"完全由 `Var(Φ')` 决定，而 `Var(Φ')` 被换错了。**

### 3.3 `0.14`（或真值 `0.94`）占余量的多少

- 用 A 窗口：`2×0.1400 = 0.2801` = `Δ=0.8838` 的 **31.7%**（任务说的 16% 是只乘了 1 倍 `Cov` 的口径）。
- 用 B 窗口（真值）：`2×0.9406 = 1.8812` = `Δ` 的 **213%** ⇒ **CS 一项就能吃掉全部余量还倒欠**。
  所以"`Cov` 吃不掉余量"这句话**只在错窗口下成立**。

### 3.4 需要什么才算够（精确缺口的数）

```
H1 ⟸ Var(Φ') ≤ 0.03320        （B 窗口，由 (σ_G+σ_Φ')²≤E[H] 解出）
     或等价 corr(G,Φ') ≤ 0.3835
实测 Var(Φ') = 0.1624  ⇒ 差 4.89 倍（σ 上差 2.21 倍）
实测 corr = +0.008 ± 0.027（p14 复算）⇒ 差 48 倍，且远超 3σ 上界 +0.089
```

**这是好消息的方向**：H1 不需要"`Var(Φ')` 很小"，只需要 `corr ≤ 0.38`——一个**弱得多**的相对陈述。

## 5. 判死线逐条

### (a) `Var(Φ')` 有可证上界 ⇒ H1 化归 `Var(G) ≤ E[H] − 小量`？——**部分成立，但小量不是 0.14**

- `[T]`：`|Cov| ≤ σ_Gσ_Φ'`，无条件。
- `[T]`：**`Cov ≥ −Var(G)/2` 成立**，只需 `Var(Φ') ≤ Var(G)/4`（`8.4×` 余量）。
- `[T]`：**H1 化归 `(σ_G + σ_Φ')² ≤ E[H]`**，即逐字写清为

  ```
  Var(F) = Var(G)+Var(Φ')+2Cov ≤ Var(G)+Var(Φ')+2σ_Gσ_Φ' = (σ_G+σ_Φ')²
  ⇒ [ (σ_G+σ_Φ')² ≤ E[H] ]  ⟹  Var(F) ≤ E[H]  ⟹  W_full ≥ 0  ⟹  H1
  ```
- **但**：`Var(Φ')` 的上界**只能是实测值**（`0.1624`），不是定理 ⇒ 这条链是**条件定理**，
  且代入后 `(σ_G+σ_Φ')² = 7.4913 > E[H] = 6.3315` ⇒ **CS 这一条路本身给不出 H1**。
  能给出的最强无条件式是 `Cov ≥ −σ_Gσ_Φ'`，而它对 H1 **零信息**：
  `Cov ≥ −Var(G)/2` 只推出 `Var(F) ≥ Var(Φ') ≥ 0`，即完全不约束 `E[H] − Var(F)`。

### (b) `Var(Φ')` 无可证上界 ⇒ 缺什么

**没有**。现有工具给不出 `Var(Φ')` 的有限上界，两条路都死：

1. **逐点/路径界（死）**：`Φ' = Σ_l r_l(Λ_l − μ)c_l`，`Λ(r)=φ'(r)/r`。在实测 `r∈[0.30,5.657]` 上
   `Λ` 的极差 = `0.44161`，`Σr_l ≈ 195.8` ⇒ `|Φ'| ≤ 86.5` ⇒ `Var(Φ') ≤ 7480`，
   比需要的 `1.3619` 差 **5492 倍** ⇒ 该路**无内容**（`q09_cov_cs.log [4]`，`[E]`）。
2. **对齐极限（`[T]`，只给 0）**：约束 `Σ_l r_l c_l = 0` 精确成立 ⇒ 若 `φ'(r)=μr` 则 `Φ'≡0`、`Var(Φ')=0`。
   这是**恒等零**，不给连续依赖的上界。

**缺的是一句关于"`Λ` 的残差在约束测度下的二阶矩"的话**，两种等价的补法：
- Poincaré / 谱隙：`Var(f) ≤ C·E[|∇f|²]` 取 `f=Φ'`。`∇Φ'` 由 `φ''` 给出，而 `E[Φ'']=6.33` 恰是
  `Σφ''c²` 的均值 ⇒ 常数 `C` 是**唯一缺口**，目前未证。
- 或一条**单链边缘界**：`E[(φ'(r_l)−μr_l)² c_l²]` 在约束测度下的上界（转移核已平表化，可算但未算）。

### (c) CS 太松 ⇒ 更紧的界

**是，(c) 触发。** 松弛比 `1/|corr| = 40–125×`。更紧的替代（按可得性排序）：

1. **直接测 `Var(G+Φ')`**（最高效）：`W_full` 只需 `Var(G+Φ')`，不必拆成 `VarG+VarΦ'+2Cov`。
   `[C]`：P02 给 `Var(F)=5.5803 < E[H]=6.3315`，差 `0.7512`、`19.6σ_jk` ⇒ H1 实测已成立，
   交叉项的处理**完全不必用 CS**。
2. **单侧界即可**：H1 只要 `corr ≤ 0.38`（§3.4）。CS 给 `corr ≤ 1`，无用；
   而"约束湮灭"给的是 `corr = O(Λ 残差/α 残差)` 的**结构性小量**——把 `[T]` 的湮灭恒等式
   与 Poincaré 常数配对，就是比 CS 强 `40×` 的那条路。
3. **条件化结构（任务提示的方向，可行但本轮未做）**：按 `(r_l)` 条件化后 `c_l` 在
   `{Σr_lc_l=0}` 上是"球面切片"上的随机符号，`Cov = E[ Σ_l δ_lε_l E[c_l²|r] ]`
   （`δ=α−λr`、`ε=β−μr`），于是 `|Cov| ≤ ¼ Σ E[|δ_l||ε_l|]`——**这条界不经过 `Var(Φ')`**，
   只经过一维径向分布，是本轮之后最值得做的一步。
