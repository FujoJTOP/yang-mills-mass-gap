## 1 · 定义与口径（逐字钉死）

| 记号 | 定义 |
|---|---|
| plaquette | `(x, a, b)`，`x ∈ ℤ^4`，`0 ≤ a < b < 4`；带 4 条 link `(x,a),(x+e_a,b),(x,b),(x+e_b,a)` |
| 邻接 | 两片**共享至少一条 link**。`4D` 一条 link 恰属 `2(d−1)=6` 片 ⇒ 每片度 `=4·5=20` ⇒ `Δ=20`（实测 `deg(p₀)=20`）`[E]` |
| `φ^U(Γ)` | `Σ_{A⊆E(G_Γ), (Γ,A) 连通生成}(−1)^{|A|}`（Fernández–Procacci (2.4)，=`C01:27`） |
| 符号 | 只随片数：`φ^U = (−1)^{n−1}|φ^U|`（F–P (2.8)，`C07:124`）⇒ `|φ^U|` 是**正整数**，`N`-无关 |
| `m_n` | `Σ_{Γ: p₀∈Γ, |Γ|=n} |φ^U(Γ)|`，`p₀ = ((0,0,0,0),0,1)`，**过定点**（与 `C01:63` 同口径） |

**为什么正好是"过定点"**：`m_n` 是壳质量，`Σ_n m_n u^n` 就是 `log Z_dec` 里"含 `p₀` 的那部分"的 `u`-级数；其收敛半径 `= 1/limsup m_n^{1/n}`。`TT2:150` 的 `q` 正是这条级数的率。

## 2 · 算法与自校验

**2.1 池与几何界。** 共享 link 可使**基站点**移动 `L1 = 1` **或 2**（当共享的 link 是两片的"远边"时，例如 `p=(x,(0,1))` 与 `q=(x+e_0−e_2,(1,2))` 共享 `(x+e_0,1)`）。故连通 `n` 片集的每个基站点满足 `L1 ≤ 2(n−1)` ⇒ 池 = `L1` 球 `R=2(N_{max}−1)`（`n≤6` 时 `R=10`，`50166` 片）。**这一步是上一版脚本的 bug 源**：`R=5` 的池在 `n=5` 漏掉 208 个集合（`280175−279967`，恰为 208 个树型簇），修正后逐位复现 `C01`。

**2.2 枚举。** 逐层：`L_n = { Γ ∈ L_{n−1} 加一个邻片 } \ {已去重}`，键 = 池序号排序后按 16 bit/域打包成整数（`n≤6` ⇒ ≤96 bit），`set` 去重。`n=6` 一层 `59.0 s`。

**2.3 `|φ^U|`。** 集合 → `6×6` 邻接位掩码 → 1-WL 颜色细化 → 颜色类内置换取最小打包形式（**完整**不变量：任意同构都保 WL 颜色）→ 同构类缓存 → 每类一次**整数**精确 `φ^U`（对连通生成边子集穷举，`|E|≤15`）。全程 `abs()` 只在整数上取 ⇒ **无浮点、无 Weitzenböck/Weingarten 输入**，故 `Wg(k)`（任意 `k`）都不进 `|φ^U|`。

**2.4 自校验（全部通过）。**

## 6 · 判决：`q = λ_Ur·u ≟ 1`（`TT2 §4.3`，`u = 0.625`）

| `n` | `m_n^{1/n}` | `m_n^{1/n}·0.625` |
|---|---|---|
| 1 | 1.000000 | 0.6250 |
| 2 | 4.472136 | 2.7951 |
| 3 | 8.010403 | 5.0065 |
| 4 | 11.020043 | 6.8875 |
| 5 | 13.511131 | 8.4445 |
| 6 | 15.580645 | **9.7379** |

* 门槛 `1/u = 1.6`；**`n=5` 已是 `8.44 = 5.3×1.6`，`n=6` 是 `9.74 = 6.1×1.6`**。
* 要在 `u=0.625` 处有 `q<1`，需 `λ_Ur^{mass} < 1.6` —— 即使取 `1/n` 外推的**下**界 `15.58`，也超 `9.7×`。
* ⇒ **`TT2 (4.3)` 的 `q<1` 分支（`C06:187` 的"活路 A"）在本口径下判死**：真 `φ^U` 已算，它**没有**小到把壳质量率压到 `1/u` 以下；把 `τ`（`=eΔ=54.37`）换成真值只换来 `54.37 → 15.58` 的 `3.5×`，远不够 `34×`。`[E]`+`[C]`（`q` 的读法）
* **诚实边界**：`(4.3)` 真正要的是**跨管端点**的壳质量 `m_n^{(T)}`（`TT2:51`），它 `≤ m_n`；本表给的是**无限制**壳质量。故本判死对"整壳口径"成立；对"跨端点子壳"它是**必要条件的否证**：跨端点子壳若也随 `n` 以 `~λ^n`（`λ ≥ 2`）增长（跨端点簇必须绕管一圈，最小的那类 `n ≥ T`），结论不变，但本文件**没有**枚举 `T`-限制的壳 ⇒ 该步标 `[NG]`。
