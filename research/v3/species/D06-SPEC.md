## §1 no-go 的障碍分析（回答 Q1）

### §1.1 引理 A1（平均引理）`[T]`

设 `dν ≥ 0` 于 `[0,∞)`，`0 < ∫dν < ∞`，`m₁ := inf supp ν`。设 `w ≥ 0` 可测，`0 < ∫ w dν < ∞`，令

```
A_w(ν) := ( ∫ s w(s) dν(s) ) / ( ∫ w(s) dν(s) )          （ν 上的 s-加权平均）
```

则

```
A_w(ν) ≥ m₁(ν)     等号 ⟺ w·ν 是单点质量
```

**证明（两步）：** `(i)` 在 `supp ν` 上逐点 `s ≥ m₁`；`(ii)` `w ≥ 0` ⇒ 加权平均保序。∎

**推论 A1′ `[T]`（方向命题）：** 一切**平均型**泛函 —— 有限个多项式矩 `∫ s^k dν`、任何有限-`t` 的正则化/截断、任何 `s`-极值（Cheeger/容量/LD 率）—— 都是 `m₁` 的**上界**，即 `𝔉 ≥ m₁`。**它们从构造上就不可能证明 `m₁ ≥ δ`。**

**推论 A1″ `[T]`（M6 杀手）：** 若 `m₁ = 0` 但 `ν ≠ δ₀`（"有权重、无地板" —— 正是 M6 的位置），则 `A_w > 0`。⇒ 平均型泛函在 M6 上**必为正** ⇒ 筛选器 ①（M6 = 0）**必挂**。

### §1.2 所以"撞车"是**真的**，但机制不是单调性

用户假设："任何从结构推出的量都是谱的单调函数，单调函数在 M6 与 2D YM 上必然撞车"。**结论对，机制要改两条：**

1. **撞车对确实是 (M6, 2D YM)**，理由由 A1″ 给出：2D YM 有地板（`m₁>0`）而 M6 无地板却有权重 ⇒ **任何平均在两侧都 > 0 ⇒ 同值 ⇒ 分辨不出**。撞车的直接原因是**平均把地板信息摊掉了**（bulk 视野），不是"单调"。
2. **单调性既非必要也非充分**：`1{m₁ ≥ δ}` 是单调且**完全分辨**的 —— 它只是**不连续**（地板函数在 KL 弱拓扑下 lsc 而非连续）。∴ 真正的杀手是**弱连续**（= 由 α/γ 模决定），不是单调。这一改很重要：它把"要造什么"从"造一个更聪明的单调量"改成"造一个**非平均、非连续**的对象"。

### §1.3 20 条的死法归成一句（`[NG]`，具名类：时空平均型泛函）

> **D06-T3（筛选器不相容，`[NG]`）。** 把 ③"必须是整体"按**时空上的整体**读，则 ③+⑤ ⇒ `𝔉` 是 `s`-平均或 `s`-极值 ⇒ 由 A1 `𝔉 ≥ m₁` ⇒ 由 A1″ 在 M6 上 `𝔉 > 0` ⇒ 与 ①（M6 = 0）矛盾。**∴ ①③⑤ 联合不可满足。**

这不是新定理的"内容"（内容 = `SPECIES-EXISTENCE` Thm 2 的 `F3 ∧ F4 = ∅`），而是它的**几何形态**：**20 条全部死在筛选器 ①，而不是死在输出端。** 因为——

> **筛选器 ① 本身就是 gap 测试。** 一个能在 (M6, 2D YM) 上分开 0 / >0 的泛函，**逐字就是**一个地板探测器（`F3`）。所以 ①+②+④ 已经把"存在一个可算且地板敏感的泛函"写进了判据 ⇒ 判据预设了结论。

⇒ **要改的是 ① 的语义，不是候选**：见 §1.4。

### §1.4 唯一的出路：③ 的正确读法是"**模型族上的整体**"，不是"时空上的整体"

- "时空整体" ⇒ 平均 ⇒ A1 杀掉（§1.3）。
- "**族上整体**" ⇒ `𝔉` 的定义域从 `{单模型}` 换成 `{模型族 × 区间}`，**① 就不再是逐点可评的谓词**（一台证书机器在单模型上只能说"证不出"）⇒ **A1/T3 不再适用**。

**代价（必须写上）：** 机器放弃"给每个模型一个数"，换来"给出一个模数与一条证明"。这正是 `§15.3` 缺的东西 —— 一台机器，不是一把把手。

### §1.5 第二条结构事实：**证明必须有损**（本轮的元发现）

- **无损量**（`λ₂`、Poincaré 常数、`inf supp ν`、`f₁²`）与隙等价 ⇒ 循环（`SPECIES-EXISTENCE` Thm 3 `[T]`）。
- **有损但不一致**（20 条）⇒ 在 M6/自由场上要么报正（假证书），要么报零（空）。
- ∴ **机器 = 有损 + 一致为正 + 有界损失**：

```
机器输出 γ 满足   γ ≥ ρ(T|_{Ω⊥}) = e^{−a·m_eff}     （必为高估：相似不变性 ⇒ ‖·‖_W ≥ ρ）
而机器的全部内容是       γ ≤ e^{−aΔ} < 1  一致成立
```

**输出严格劣于 `λ₂`，且劣多少不知道 —— 这恰恰是它能被证的原因，也是"不是换名"的判据。**

### §2.3 输出 + 方向约定（陷阱，必须先钉死）

```
约定（生成元）：λ₂^{gen} := m_eff²  ≥ 0         [质量²]
机器给：        λ₂^{gen} ≥ Δ² > 0
等价形式：      ‖T|_{Ω⊥}‖ = e^{−a·m_eff} ≤ e^{−aΔ} < 1
```

- **`‖T|_{Ω⊥}‖ ≤ 1` 是 RP 白送的 `[T]`，严格性才是内容**（`§15.1`）⇒ 证书必须是**严格** `< 1` 的上界。

### §2.4 "不是 `λ₂` 换名"的三条可操作判据

1. **损失可见**：输出 `γ` 与真值之间有**不可消**的因子（`γ > ρ(T)`）；若某候选声称 `γ = ρ(T)`，那就是换名。
2. **证书对象不含谱**：载体（`W`、路径、同构）是**代数/几何对象**，不是任何 `sup/inf spec`。
3. **失败可诊断**：候选在给定容量下失败时，必须吐出一份**对偶/障碍证书**（Farkas 型：为什么这个容量不够）。**20 条没有一条有这条** —— 它们失败时只说"值为 0"。

## §3 三个候选设计

### §3.1 **D1 `W-SHIFT`（权移机器）——判：可造，本轮第一优先**

**机制类：** 相似变换 + 一条**算子不等式**（不是矩，不是测度泛函）。=`M4'`（"设计权"），与 BE 同族但**多一个自由参数**。

**规格：**
```
输入  I1 + I4 := 显式正权 W = exp(c·K)，K 局部、规范不变、可显式平方（候选：K = H_mag = Σ_□ (1 − RetrP) 或 K = Σ_□ RetrP）
输出  Δ 与证明：   W^{1/2}(H − ⟨Ω,HΩ⟩)W^{−1/2} ⪰ Δ²·1_{Ω⊥}        （H = Kogut–Susskind）
等价  ‖W^{1/2} T W^{−1/2}|_{Ω⊥}‖ ≤ e^{−aΔ} < 1
```
**五筛选器（机器口径）：** ① 自由场（`ρ=1`，相似不变 ⇒ 任何 `W` 都给不出严格界）→ 拒绝 ✓；2D YM → 需**真造**（§5.1）；M6（`ρ=1`）→ 拒绝 ✓；单 plaquette（无时间方向，`H` 不存在）→ 无定义 ✓。② `⪰`/`‖·‖` 型 ✓。③ 一条不等式管整条 β-段（`c` 可随 β 变，`W` 逐 β 重造）✓。④ `Δ(β)` ✓。⑤ `Δ` 质量量纲；`g→0` 时 `c→0`、`W→1`、`Δ→0` ✓。**5/5。**

**避开哪三条最近的死路：**
- **`变分`（死）**：变分给 `m ≤ R(f)`，**上界**；本机给 `m ≥ Δ`，**下界** ⇒ 方向相反，不是同一台机。
- **`BE / O06`（死，`Γ₂ = Ric + Hess S` 在 Savvidy 方向 −1.1β）**：BE 恰是**本机 `c = 1/2` 且 `K = S` 的单点**。Savvidy 凹性杀的是**正则权**；本机的自变量是 `(c, K)`，`c = 1/2, K = S` 只是族里一个点。**`[T]` 这一条差别是真的：`Γ₂` 计算只对 `e^{−S/2}` 成立。**
- **`SDP-CERT`（`[NG]`，死于 "`E₀ = 0` + 张量因子 + 截断不跨"）**：本机**不用截断层级**（不用 `H² ⪰ [H²]_n`），而用**相似变换后的有限块检验**：不等式在 ℓ-块上截断是**充分**的（`W` 局部 ⇒ 取迹/块对角化给出 `‖·‖` 的**上**界，方向安全），∴ 截断只损失常数，不损失合法性。**这是与 SDP-CERT 的结构性差别。**

**精确缺失对象（`[M]`）：`W-CALC`** —— 一套把 `H` 的负模（Savvidy）在 `W^{1/2}·W^{−1/2}` 共轭下**抵消**的**权演算**：给定 `(c,K)`，输出一条**逐点**（而非积分）的正下界。性质清单见 §4.3。

**风险（诚实）：** "存在 `W`" 在逻辑上是免费的（隙 ⟹ `W = 1` 就行）；∴ **本机的价值不在存在性，而在可检验性与可诊断性**（§2.4-3）。若只把它当"存在性命题"读，则它 = H1 换坐标 `[J]`。

### §3.2 **D2 `RETRACT`（路径提升机器）——判：逻辑上合法，但把墙定位到单点，不绕过**

**机制类：** 参数空间的**点集拓扑**（闭集 + 连通 + 非空），不是时空拓扑。

```
输出  若再给出 (d) 该集合在 β-轴上的**路径提升** RETRACT(δ)，则 β=2.5 处 m₁ ≥ δ
```
**(a) 的证明 `[T]`（新，两行）：** 设 `ν_n → ν` 弱、`supp ν_n ⊂ [δ,∞)`。取 `φ ≥ 0`、`supp φ ⊂ [0,δ)`：`0 = ∫φ dν_n → ∫φ dν` ⇒ `supp ν ∩ [0,δ) = ∅`。∎ **（注意：这是 floor（supp）的 lsc；`f₁²` 是 usc、可在交叉点掉落 —— 两个对象必须分开，这正是 `SUPPORT-NOT-ATOM` 的算术。）**
