## §1 · `★` 原陈述的核对（先核）

```
Γ(f,g) = ½( L(fg) − fLg − gLf )                                    （carré du champ）
Γ₂(f)  = ½( LΓ(f,f) − 2Γ(f,Lf) )
Γ₂(f,f) ≥ ρ·Γ(f,f),  ρ>0   ⇒   Var_μ(f) ≤ (1/ρ)·E_μ[Γ(f,f)]
```

**核对结论：三行全对，逐字成立。`[T]`（BE 1985，标准）。** 两处需要写清楚，因为后面全用它：

- 对 `L=Δ−⟨∇V,∇⟩`（语料约定：`L_ν=∂_a²−G″∂_a`）有
  `Γ(f)=|∇f|²`、`Γ₂(f)=|Hess f|² + Hess V(∇f,∇f)`。流形上 `Hess V → Ric_𝒜 + Hess S_W`，即语料 `(1.2)`。
- 推出链（不用引用）：`d/dt Var(f_t) = −2E[Γ(f_t)]`，`d/dt E[Γ(f_t)] = −2E[Γ₂(f_t)] ≤ −2ρE[Γ(f_t)]`
  ⇒ Grönwall `E[Γ(f_t)] ≤ e^{−2ρt}E[Γ(f)]` ⇒ 积分 ⇒ `Var ≤ (1/ρ)E[Γ]`。**[T]**

**唯一要小心的词是"⇒"。** 上面是 `Γ₂≥ρΓ ⇒ (Poincaré_ρ) ⇒ Var≤(1/ρ)E[Γ]`。**反向不成立**：
`Var≤(1/ρ)E[Γ]`（即 `(★)` 的 Poincaré 形式）**不**给 `Γ₂≥ρΓ`。所以"BE 是 `(★)` 的原型"只在**一个**意义下对——见 §2 引理。

## §2 · `Γ₂` 与 `G″` 的关系：一个无损引理 + 一个边缘化恒等式

> **引理 S09-1（1-D 平坦空间上 BE 无损）`[T]`。**
> `L=∂²−V′∂` 于 `ℝ`，`Γ(f)=|f′|²`、`Γ₂(f)=|f″|²+V″|f′|²`。则
> `Γ₂(f,f) ≥ ρΓ(f,f)  ∀f∈C²  ⟺  V″ ≥ ρ  a.e.`
> *证.*（⇐）显然。（⇒）取 `f(x)=x`：`f″=0`,`f′=1` ⇒ `V″(x) ≥ ρ` 逐点。∎
> **推论**：`CD-marginal(ρ) ⟺ ess inf G″ ≥ ρ ⟺ λ₁(ν) ≥ ρ`。**零余量。**（`Q4 §1.3 (1.3)`、`H6-B`、`B3-FUNCTIONAL-BE §1`）

这个引理是 `(★)` 与 BE 关系的**全部**内容：`(★)` 要的 `G″≥δ_W` **就是** 1-D BE 常数下界。**到此为止，BE 只是 `(★)` 的另一种写法。**

> **恒等式 S09-2（`G″` 是边缘化对象，不是 `Γ₂^{full}` 的限制）`[T]`。**
> `ν=P_*μ`，`ρ_ν = ∫ e^{−S}dHaar_fiber`，`V_eff=−log ρ_ν`。则
> `(log ρ_ν)′ = −E_μ[V′|a]`（Stein）⇒
> `G″ = V_eff″ = d/da E[V′|a] = E_μ[V″|a] − Var_μ(V′|a)`
> `    = E[H|0] − Var(V′|0) + W_geo + X`,  `W_geo = E[Φ″] − Var(Φ′) ≥ 0`.（`W_geo` 项：`PROOF-JACOBIAN-SAVES`；`X`：相关项）

**四个差别源**（对 `Γ₂^{full}(v,v)=Ric(v,v)+Hess S_W(v,v)`，`v` 为粗方向）：

| # | `Γ₂^{full}` | `G″` | 后果 |
|---|---|---|---|
| (i) | 逐点 `Hess S_W(v,v)` | 条件期望 `E[H|0][v,v]` | 最深逐点负 `−1.12β` 被**平均掉**（深处是少数测度） |
| (ii) | 无 | `−Var(V′|0)` | 变差惩罚，**减号**（对 `(★)` 不利） |
| (iii) | 无 | `+W_geo≥0` | Prékopa/Jacobian，唯一边界无关正项；`S1 §2(c)`：**"exactly the `+W_j` of `(★)`"** |
| (iv) | `+Ric_𝒜`（SU2 `½`、SU3 `¾`，`[T]`） | **消失** | `Ric` 被积进 `ν`；"gauge-group `Ric` 对 `G″` 沉默"（`Q4 §0·3`） |

**故：`Γ₂^{full}` 与 `G″` 差一个"条件化"。** `−2.30 → +0.51` 的净符号翻转 = `+Ric` 项被换成 `E[H|0]`＋`W_geo` 并减去 `Var` 的净效果。这不是矛盾，正是语料所说的 **"`G″` 是等分配的**条件化缺陷**"**（`ABC-FINAL-LEDGER`: `E[V″]=Var(V′)` 无条件成立，`G″` 就是偏离）。

## §3 · 死线 (a)：`Γ₂` 与 `G″` 同一个 ⇒ 全军停？

**结论：`(a)` 不成立。两重独立理由，任一即可否。**

**理由 1（对象不同 ⇒ 反号可共存）。** §2 恒等式给出 `G″ ≠ (Ric+Hess S_W)^{vv}`。语料在同一 `β=2.5` 上同时测得 `−2.30` 与 `+0.51`，**反号**；若二者同一，这两个数不可能同时为真。`[V]`

**理由 2（更强，且不依赖理由 1：即使把 `G″` 读成限制，负模也不在粗模上）。**
`Γ₂^{full}<0` 只说 `min_{v∈TM}(Ric+Hess S)(v,v)<0`，即"存在负方向"。要否 `(★)` 需要负方向**落在粗模 `v` 上**。语料直测：最负本征向量在低动量集体子空间上的权重只有 **3.4%**（SU2 L=4）/ **9.7%**（SU3），负方向 **90–97% 与之正交**（`W6-BE-at-2.5` §2；`MARGINAL.md`；`ABC2-SYNTHESIS`）。**负模长在测量中几乎是粗模的正交补里。** `[V]`

**因此 `Γ₂<0 ⇒ (★) 假` 是无效推理**（两次）：(1) 前提与结论谈的不是同一个数；(2) 存在量词的否定（`∃v<0`）不能否定"某个特定子空间上的下界为正"。**不要用它停全军。** `[NG-invalid]`

| **R2 marginal `CD(ρ,∞)`** | `ess inf G″ ≥ ρ`（引理 S09-1，**无损**） | `ess inf` **未知**；只有点值 `G″(0)=+0.51` | **逐字就是 `(★)`** ⇒ 不是工具，是改名/循环。证它 = 证 `H1` `[NG]` |

**汇总判**：BE 给 `(★)` 的三条路——(R1) 假设假、(R2) 是改名、(R3) 假设假且退化版空。**BE 是 `(★)` 的原型（R2 恒等），但不是 `(★)` 的证明机器。** `[NG]`

## §5 · 可靠性：`(c)` 成立，但对象是 `G″` 而不是 `Γ₂`

**限定（必须随数走）**：`L=4/L=3` **有限体积**、单一背景族上的 **sampled min**；`inf` over all configs 未证，`W6` 自标 "not a proof"。故 `−2.3` 是"该窗口的下界见证"，不是普适 `inf`。`[V]`
