## 2. `Φ`-only 上的四个量（Q1，核准）

`S_W ≡ 0` ⇒

```
G_v  = ⟨v,∇S_W⟩      ≡ 0        [T]
H_vv = ⟨v,Hess S_W v⟩ ≡ 0        [T]
total force ∂_v S = G_v + Φ' = Φ' = h'(ρ)·(v·ξ̂)          h(ρ) = −2log[sin(ρ/2)/(ρ/2)]
Φ''  = ⟨v,HessΦ v⟩ = h''(ρ)(v·ξ̂)² + (h'(ρ)/ρ)[1−(v·ξ̂)²] ,  min_ξ Φ'' = N/12 = 1/6  [T]
```

**核准任务书的猜测**：`G_v = ∂_v S_W = 0 ⇒ G = 0` ✅；但**H1 的方差不是 `Var(G)`，是 `Var(G_v + Φ')`**（`ch18:28`）。所以 `Var(G)=0` 不能把 H1 变成 `0 ≤ E[H_vv]`——那是另一条不等式，在 `Φ`-only 上退化成 `0 ≤ 0`（见 §5(c)）。正确的降维是 `Var(Φ'|0) ≤ E[Φ''|0]`，与任务书的最终形式一致。

## 3. 数值（Q2/Q3）：单 plaquette, `L=2`, SU(2), `β=0`

求和归一化自检：`4π∫₀^{2π}sin²(ρ/2)dρ = 39.4784176 = 4π²`（精确）。

### 3.1 无条件化（对 `a` 取边缘）

```
E[Φ''_vv]    = 0.333333333333
E[(Φ'_v)²]   = 0.333333333333
|diff|/E     = 0.0e+00            ← Stein/IBP 恒等式，机器精度

### 3.3 均匀性（`a ≠ 0`）：真正的 Φ-半边 H1

`p_Φ(a) = (2π/Z)∫_{|a|}^{2π} sin²(ρ/2)/ρ dρ`（精确），`G''_Φ(a) = −∂_a²log p_Φ(a) = f'(a)/(F_∞−F(a)) − [f(a)/(F_∞−F(a))]²`，`f=sin²(a/2)/a`。

```

## 5. 判定（逐字）

### (a) 结论真，路线假 —— 拿不到"关键"

`Var(Φ') ≤ E(Φ'')` 在 `Φ`-only 上**成立**（§3.1 恒等、§3.2 条件化 `0 ≤ 0.2051`，且 `≥ N/12`）。但**不是由 `HessΦ ⪰ N/12` + BL 推出**：

1. BL 腿的界是 `+∞`（§4），零信息；
2. 真正的机制是 **Stein/IBP 恒等式**（无条件的余量恰为 `(EΦ')²=0`）+ **`Φ` 径向导致切片上 `Φ'≡0`**（条件化的方差恰为 0）；
3. 点态地板 `Φ'' ⪰ N/12` 只贡献数 `0.2051 ≥ 0.1667`，不需要任何方差估计。

所以 **"H1 的 `Φ` 半边有 [T] 证明"这句只在"结论"层面成立，在"可作为半边使用"层面不成立**：它的余量是 0（无条件）或 0（条件化，方差恒零），没有可搬运的 `δ`。

### (b) 分解路线死 —— 且已有精确反例（不是本轮新造）

语料模型 1（`θ=π`）给出 `E[H_vv] ≡ 0`（精确，`c=cos(π/2)=0`）而 `Var = β²V₀`，`V₀ = 0.0110593`：

```
δ_max(β) = W_geo − β²V₀ = 0.2051153 − 0.0110593 β² ,   β* = 4.30661
β=6:  δ = −0.193019  < 0        [T]（sec03-failure.tex:48–54, 69–71）
```

这正是"`E[H_vv] ≥ 0` 吸收 `S_W` 贡献"的反例：`Φ` 半边给出**常数** `0.2051`，`E[H_vv] ≥ 0` 给不出增长，而 `Var(G_v)` 随 `β²` 无界增长 ⇒ 两半相加仍可为负。**拆开证不出 H1。**

### (c) 退化确实发生 —— 这是主因，且指出真正该问的量

- `G ≡ 0` 使 `Var(G) ≤ E[H_vv]` 化成 `0 ≤ 0`（`Φ`-only 上 `H_vv ≡ 0`）：**零信息**，不能当 H1 的替代品。
- 非退化的 `Φ`-侧量是 `G''_Φ(a) = E[Φ''|a] − Var(Φ'|a)`，而它的**均匀性在平坦图上失效**（§3.3，`a>1.588` 变负、cut locus 处 `−∞`）。所以 `Φ`-only 的"成立"是**点上的巧合**（对称切片 `Φ'≡0`），不是可推广的机制。
- **真正该问的量**：`Δ_dyn(a) = E[H_vv|a] − Var(G_v|a)` 的 `a`-一致下界（`ch19:56–58, 88–93`），加上交叉项 `X(a) = −2Cov(G,Φ'|a)`。这才是 `G''（= Δ_dyn + W_geo + X）` 里唯一没被本轮算掉的部分；`Φ` 半边（`W_geo` 的 `Φ` 部分）在点上已被算成 `[T]`，但它在完整测度里既非小量也非可加分项（`L=2, β=2.5` 实测：`E[Φ'']=1.2325`、`W_full=1.134`、`Δ_dyn=0.562`、`G''=1.696`，`ch19:134–141`）——`Φ` 侧占 `G''` 的 67%，"吸收"叙事与实际符号结构相反。
