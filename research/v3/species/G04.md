## §1 升级的精确账：丢的是一支函数，背上的是一笔债

```
M(β) := m_lat(β)/(a(β)Λ_lat(β))  =  m_phys/Λ_lat        （B07 §1–§2，[T]）
∀β ∈ I  ∃c₀(β) > 0 : M(β) ≥ c₀(β)        ← 取 c₀(β)=M(β)/2，恒真、零内容  [T]
∃c₀ > 0 ∀β ∈ I : M(β) ≥ c₀               ← 逐字 ⟺ inf_{β∈I} M(β) ≥ c₀ > 0  [T]
```

**⇒ 升级只做了一件事：把"逐点正"换成"整族有同一正数"。** 代价有两笔，且必须分开记：

| # | 账单 | 内容 | 谁能付 |
|---|---|---|---|
| 1 | **丢**：`c₀` 可以写成 `c₀(·)` 的自由 | 见证从函数降为常数 | 无（这是升级的定义本身）`[T]` |
| 2 | **背**：`inf` 必须指名集合与拓扑 | 域的每一处含糊都直接变成命题的含糊 | 见 §2 三张账单 |

**这就是为什么"三个分叉"不是脚注而是全部内容**：`∃c₀∀β` 的**每一个字**都已被 §1 的恒等式付清，
剩下的**唯一**未付项就是"`inf` 对哪个集合取"。

**推论（对 `b07` 的一句修正）**：`b07` 说"判别式是量词次序，且这是唯一的判别式"（`B07:72`）。
**次序是必要判别式，不是充分判别式。** 因为次序只区分"逐点（恒真）"与"一致（有内容）"；
而**一致句本身**是不是 Clay、可不可为真，由域决定（§3）。故：

```
判别式 = ( 域 , 次序 )      不是  ( 次序 )
```

### 2.2 ② `lim` 在 `inf` 内还是外

三个句子（`x(L,β) ≥ 0` 为族；`w₀>0`）：

```
(i)   ∀L : liminf_{β→∞} x(L,β) ≥ w₀          ← "每个体积各自、最终"（C5 的 uniform-in-L 形状）
(ii)  liminf_{β→∞} inf_L x(L,β) ≥ w₀          ← "最终、对全部体积同时"
(iii) liminf_{β→∞} liminf_{L→∞} x(L,β) ≥ w₀   ← **Clay 的形状**（无穷体积连续极限）
```

**严格关系（初等，`[T]`，逐字两行引理）**：

```
(ii) ⇒ (i) :  inf_L x ≥ w₀ (β 最终)  ⇒  ∀L: x(L,β) ≥ w₀ (β 最终)  ⇒  ∀L: liminf_β x ≥ w₀
(ii) ⇒ (iii): 同上诸 β 上 liminf_L x ≥ inf_L x ≥ w₀  ⇒  liminf_β liminf_L x ≥ w₀
⇒ (ii) 同时强于 (i) 与 (iii)；而 **(i) 与 (iii) 互不蕴含**（见证 W1、W1′）。
```

**见证 W1（本题的靶心）**：`x(L,β) = e^{−L/β}`（`L∈ℕ` 无界，`β>0`）。`[T]` 闭式 + `[E]` 数值：

⇒ **`(i)` 真而 `(iii)` 假**（同一族上）；反向 `(iii) ⇏ (i)` 由 **W1′**：`x = 1_{L≥3}`（与 β 无关）

**⇒ ② 的致命性（逐字）**：`(i)` 是"每个体积的连续极限都有地板"，`(iii)` 是"连续极限的无穷体积值有地板"。

`(ii) → (iii)`、`(i) → (iii)` 之间缺的那一步（等度连续/联合紧性/路径无关）是 `W3`·`L3`·`C4`，`[M]` —— **不是改写能补的**。

## §4 三处钉死后的正确串（逐字；本轮基础）

**先把三个方向各自的归宿写死（这就是"钉死"的全部内容）**：

```
a   : 不是量词 —— 由 β 决定（a = a(β)，两圈 AF 反解、严格单调降）        → 代换进函数
t   : 不是量词 —— 一次选定的定点重正化口径 t₀ ∈ 𝒯                        → ∃（一次）
β   : 不是 ∀  —— 唯一的非紧方向，只能进 liminf，且必须在最外层            → liminf（外）
L/V : 自由且可实现 —— 但"逐体积"与"无穷体积"是**两个不同问法**，必须指名  → ∀ 或 lim（内）
```

**(★_Clay) Clay 的形状（串里没有 `inf`，两个 `lim`，`β` 在最外）**

```
∃w₀ > 0   ∃t₀ ∈ 𝒯 :

      liminf_{β→∞}  liminf_{L_lat→∞}  w₁( L_lat , β , t₀(a(β)) )  ≥  w₀

𝒯  := { t(·) : √t(a) 固定物理量 , t(a)/a² → ∞ }        （定点重正化口径，选定一次）
a(β) := 两圈 AF 反解（G05:12–15）—— 出现在函数里，**不出现一个量词**
```

**(★_C5) C5 的 volume-uniform 形状（`∀V` 在最外、`lim` 在里）**

```
∃w₀>0  ∃t₀∈𝒯  ∀V>0 :  liminf_{β→∞} w₁(V, β ; t₀(a(β))) ≥ w₀ ,   L_lat = V^{1/4}/a(β)
```

**两版互不推出（这是 §2.2 的直接推论，不得合并）**：`(★_C5)` 是 `(i)`、`(★_Clay)` 是 `(iii)`，
W1 给 `(i)` 真而 `(iii)` 假 ⇒ 两个方向都不成立。接它们的那一步是**路径无关 + 联合紧性** `[M]`

**逐字读法（"那句话怎么读"）**：

> 存在一个常数 `w₀>0`，它**与体积、与格距、与重正化口径都无关**。读法分两层：先在**每个固定物理体积**里
> 让 `β→∞`（即 `a→0`），取该族的下极限；再让体积 `→∞`，取体积族的下极限；**两级下极限都 ≥ `w₀`**。
> `β` 是唯一的自由连续参数（`a` 由它决定，不另立量词）；口径 `t₀` 一次选定（是 `∃`，不是 `∀`）。
> **规范性判据（本文件定型）**：串里每出现一个 `inf`，都必须能指回一个**具体的 `∀`**（自由且可实现的方向）
> 或一个**具体的 `lim`**（非紧方向）。指不回去的 `inf`，就是 §2 的三处分叉。


**(★″) 比值地板（`b07` 的靶）—— 两行，且**不得**写成"等价"**：
