## §1 求和形（对角 / 非对角）

```
q_x := 1 − N^{-1}Re tr U_{□_x} ∈ [0,2] ,  X_x = a^{-4}q_x ,  ⨏_B := N_B^{-1}Σ_{x∈B} ,  N_B=(b̂/a)^4
C_q(z) := ⟨q_0;q_z⟩_c ,  C_q(0)=Var_μ(q) ,  n_B(z) := #{x∈B : x+z∈B} ≤ N_B ,  supp n_B ⊂ {|z|_∞<b̂}

(1.1) ϖ = a^4b̂^4·Var(⨏_B X) = N_B·Var(⨏_B q) = N_B^{-1}Σ_{x,y∈B}C_q(x−y) = N_B^{-1}Σ_z n_B(z)C_q(z)
       = C_q(0) + O_B ,   O_B := N_B^{-1}Σ_{z≠0}n_B(z)C_q(z)                   ← 有号，不取绝对值
(1.2) 对角 x=y ： N_B^{-1}·N_B·C_q(0) = Var(q) ∈ (0,1]                          ← 幂 0、与 a 无关
(1.3) 非对角  ： O_B ； |O_B| ≤ N_B^{-1}Σ_{z≠0}n_B(z)|C_q(z)| ≤ Σ_{0<|z|_∞<b̂}|C_q(z)|
                 靶 ⟺ O_B ≤ C − Var(q) ； 固定-β 读法 R_B := O_B/Var(q)（沿塔 Var(q) 自身跑动）
(1.4) 抽稀     ： B=⊔_{i=1}^K B_i（B_i 是 B 的平移）⇒ Var(⨏_B q) = Var((1/K)Σ_i⨏_{B_i}q) ≤ Var(⨏_{B_i}q)
(1.5) 幂账     ： 靶 ⟺ V(b̂):=Var(⨏_B q) ≤ C(a/b̂)^4 ；(1.4) 只给 V(b̂)≤V(b̂₀) ⇒ 缺口 = b̂^4 = 一个 N_B
```

### 1.1 为什么 (1.1) 是恒等而不是估计
`a^4b̂^4·a^{-8} = b̂^4a^{-4} = N_B`（`HZ6-ZDEF:46` 的 `ϖ` 归一），故 `ϖ = N_BVar(⨏q)`；`N_B^{-1}Σ_{x,y}` 摊成 `N_B^{-1}Σ_z n_B(z)` 只用了计数 `n_B(z)≤N_B`。两行都是代数，**不含任何输入**（`HZE-KIN:1.2` 的自检 1 同款）。

### 1.2 对角给什么（本题第一问的前半）
恰给 `Var_μ(q)`：**没有 `a`、没有 `b̂`、没有 `β`**。它同时是 (i) 靶常数的**免费第一份**（`C≥Var(q)`，且 `Var(q)≤1`），(ii) 正性下 `ϖ` 的**下界**。两个用途方向相反，但都由同一行给出 —— 这是本路最便宜的一条账。

### 1.3 非对角给什么（第一问的后半）
给的是**有号的和** `O_B`：块内 `N_B(N_B−1)` 个配对协方差按 `1/N_B` 加权的平均。靶 ⟺ `O_B ≤ C−Var(q)`；因 `Var(q)≤1` 且正性给 `O_B≥0`，实用充分形是 **`O_B ≤ C−1`**（⇒ `ϖ≤1+O_B`）。归一化的 `R_B=O_B/Var(q)` 是「有效相干格点数 / 接触项」，**只在固定 `β` 下是纯数**；沿塔 `Var(q)` 自身跑动，故塔上判据一律用绝对形 `O_B`。这不是"关联长度"陈述（`ξ_latt` 可远大于 1，只要振幅被接触项压住）。

### 1.4 抽稀单调（真正的「方差不增」）
`Var(均值) ≤ 均值的方差`（只用 `|Cov(X_i,X_j)| ≤ ½(VarX_i+VarX_j)`，任何测度都成立）＋平移不变 ⇒ `V(b̂') ≤ V(b̂)` 对 `b̂'=m b̂` 成立。⇒ `b̂↦V(b̂)` 单调不增、`V(∞):=lim` 存在且 `≥0`，且 `V(∞)=0 ⟺ q` 通道无长程有序。**这是 `[T]`，且是仓内首次把「方差不增」写成可用的抽稀定理**（检索：`方差不增` 全仓 0 命中；最近的 `H1C-WFULL:100` 是曲率力方差、且自标 `[O]`；`GR1-SPECRES:306` 是**隙**沿分块单调，不是方差不增）。

### 1.5 幂账与强形反例
**幂账**：靶是 `V(b̂)=O(b̂^{-4})`；1.4 是 `O(b̂⁰)` ⇒ **缺口 4 个幂**，与 `HZE-KIN:1.1`「`4N_B` 差一个 `N_B`」是同一件事，但这里给出原因：**单调性不带率**。
**强形（独立形）是假命题**：自由场 Wick ⇒ `C_q(z)=2(⟨AA⟩_{0z})²≥0`（`z≠0`）⇒ `O_B≥0`，块大于一格时 `>0`。故「块内不相关」（`HZE-KIN:行2`）不是"未证"，是**在酸测模型上就假**。

### 1.6 酸测（三模型）
自由场：Wick 给 `C_q(z)=2(⟨AA⟩_{0z})² ~ g⁴|z|^{-8}`（格点单位、`dim q=4`）⇒ `O_B=O(g⁴)`，靶真；`O_B≥0` ⇒ 强形假（1.5）。2D YM：plaquette 变量**精确因子化**（`HZC-SIGN:71`）⇒ `C_q(z)=0 (z≠0)` ⇒ `O_B≡0`：判据**恒真、判别力 0**（须报）。单片：无平移 ⇒ `V(b̂)` 无对象。
