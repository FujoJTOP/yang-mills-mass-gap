## §1 · `D_O` 的显式（答任务 1）

### §1.1 压缩 = 限制（关闭 `d08` 的 (c)-1）`[T]`

设 `T` 自伴（`H_phys` 上，OS 内积商掉零模后）、`|Ω⟩` 为 `T` 的本征向量（`λ₀=1`），`O` 自伴。令
```
K_O := clos span{ T^k O|Ω⟩ : k ≥ 0 } ,   P_O := 正交投影 onto K_O
```
`K_O` 是 `T`-**不变**的。`T` 自伴 + `K_O` 不变 ⇒ `K_O` **化约** `T` ⇒
```
P_O T P_O = T P_O  ，且在 K_O 上  T_O := P_O T P_O = T|_{K_O}          (1.1)
```
⇒ `spec(T_O) = {λ_n : P_n O|Ω⟩ ≠ 0} = {λ_n : f_n² = |⟨n|O|Ω⟩|² > 0}`。理由一行：`f_n ≠ 0 ⇒ |n⟩ = P_nO|Ω⟩/f_n ∈ K_O`；`f_n = 0 ⇒ ⟨n|T^kO|Ω⟩ = λ_n^k f_n = 0 ∀k ⇒ |n⟩ ⊥ K_O`。
**⇒ `det(1 − zT_O) = ∏_{n:f_n²>0}(1 − zλ_n)`：压缩与 Hadamard 分母在 `T` 不变子空间上恒等。**

> **对 `d08:52` 的更正 `[T]`**：`d08 §1.3-1` 引 `OS-P-INTERFACE:122`「compression raises the apparent gap … can **manufacture** a spurious one」判"压缩 ≠ Hadamard"。**那句话针对的是非不变子空间/变分截断**（此时确实抬高）。**`K_O` 由 `T` 生成，恒不变，故 (1.1) 成立，两者恒等。** ⇒ `d08` 的 (c) 三处减为一处（迹的归一，见 §3.1），(c)-1 **关闭**。

### §1.2 `D_O` 的显式矩阵元与已知行列式 `[T]` + `[E]`

在 Krylov 基 `e_k := T^kO|Ω⟩`（`k ≥ 0`，非正交；`{e_k}` 张成 `K_O`）：
```
Gram（内积）：        S_{jk} := ⟨e_j|e_k⟩   = C(j+k)              (1.2a)
双线性（嵌套）：      A_{jk} := ⟨e_j|T e_k⟩ = C(j+k+1)            (1.2b)
⇒ 算子矩阵：          [T_O] = S⁻¹A ,   D_O(z) = det(1 − z S⁻¹A) = det(S − zA)/det(S)   (1.2c)
```
其中 `C(k) := ⟨Ω|O T^k O|Ω⟩_c = Σ_{n≥1} f_n² λ_n^k`（真空相减后）。这是**Hankel/Gram 型**的 Fredholm 行列式；`C(k) ≤ C(0)λ₁^k` ⇒ 元素几何衰减 ⇒ `S, A` 迹类 ⇒ `D_O` 是**真** Fredholm 行列式（与 `d08:59`（`D02`）一致）。

**数值核查（`w7/_h08_b7.py`，4 原子 `λ = (0.95,0.80,0.65,0.40)`，`f² = (1,0.30,0.20,0.10)`）**`[E]`：

## §2 · `z₁` 能否由迹给出（答任务 2）—— `(a)` 不成立，`(b)` 成立

### §2.1 精确恒等式：`z₁` = `G` 的收敛半径 `[T]`

```
m_k := C(k) = Σ_{n≥1} f_n² λ_n^k ,   λ₁ := max supp ν = e^{−a m₁}
⇒  limsup_{k→∞} |C(k)|^{1/k} = λ₁            (2.1)
⇒  z₁ = 1/λ₁ = 1/limsup_k |C(k)|^{1/k} = G(z)=Σ C(k)z^k 的收敛半径      (2.2)
```
*证 (2.1).* 上界：`|C(k)| ≤ C(0)λ₁^k`。下界：`supp ν ∋ λ₁` 闭，故 `ν([λ₁−ε,λ₁])>0 ∀ε` ⇒ `|C(k)| ≥ (λ₁−ε)^kν([λ₁−ε,λ₁])` ⇒ `liminf ≥ λ₁−ε`。∎
**数值（`w7/h08_z1.log` B1）**`[E]`：`λ₁=0.95`，`|C(k)|^{1/k}` = `0.97834 (k=5) / 0.95540 (10) / 0.95000106 (50) / 0.950000000098 (100)`；`(C(k)/C(0))^{1/k}` 只以 `~1/k` 收敛（`0.94999 at k=4·10⁴`）。隔离度 `δ = 1−λ₂/λ₁ = 0.1579` ⇒ 分辨需要 `k ≳ 2/δ = 12.7`（与 `PADE-ROUCHE` 的 `M ≳ 2/(am₁)` 同一条）。

**判**：`(2.2)` 是 `[T]`，但**它就是"质量 = 两点函数指数衰减率"** —— `m₁ = −lim_k (1/(ak))log C(k)`。**它不是新路，是"质量"这个词的定义。** 且 `limsup` 要 `k→∞`。

### §2.2 有限前缀：Gauss–Padé 上界序列 `[T]` + `[E]`

取 `C(0..2M−1)` ⇒ `[M−1/M]` 分母 `Q_M` ⇒ `M` 个节点 `x_i`（Stieltjes：= `ν` 的 Gauss 节点）⇒ 估计

```

### §2.3 **方向定理（本文件核心）** `[T]` + `[E]`

> **命题 2.3.**
> ```
> m₁^{det} := (1/a) log z₁ = inf{ E_n : f_n² > 0 }  ≥  inf{ E_n } = m₁               (2.4)
> ```
> *证.* `{n : f_n²>0} ⊆ {all n}`，`inf` 在**子集**上 `≥` 在全集上。∎

## §3 · `Tr T_O^k = Z` 与体积展开（答任务 3）

### §3.1 更正：`Tr T^k = Z`，但 `Tr T_O^k ≠ Z` `[T]` + `[E]`

```
(A) Tr T^k  = Z_{S¹_k × T³}                        全迹 = 配分函数        [T]
(B) Tr T_O^k = Σ_{n:f_n²>0} λ_n^k                  通道**计数**迹        [T]
(C) C(k)    = Σ_n f_n² λ_n^k = ⟨O(0)O(ak)⟩_c       关联子（路径积分给的） [T]
```
**(B) ≠ (A)**：`O ≠ 1` 时 `supp ν ≠ spec T`；且**投影不能进迹** —— 路径积分无法只数"有 `O` 重叠的那些态"，它只能给带权 `f_n²` 的和 `(C)`。**⇒ `d08:39` 的 `Tr T_O^k = Z_{S¹_k×T³}` 作为 `[T]` 标注应降为 `[T]`（仅 `T`，不含 `T_O`）**；`d08 §1.3-2` 自己已察觉"extensive 与 `z₁` 口径矛盾"，本文件给出**成因**：混了 (A)(B) 两个对象。
**`(A)` 的数值验证（B5，单 plaquette，`β=2.5`）**`[E]`：`Tr T^k`（Haar 数值积分）vs 精确 `Z(kβ) = e^{−kβ}·2I₁(kβ)/(kβ)`，`k=1,2,3,5,10,20` 相对误差 `≤ 7.8e−15`。
**⇒ 结论**：`D_O` 的零点集 `= supp ν` 由 (B) 或 (C) **任一个**决定（两者支撑相同）；但只有 **(C) 可测**。⇒ **迹版本比关联子版本更差**（多要一个路径积分里不存在的量）。最短输入是 `{C(k)}` —— 已被 `PADE-ROUCHE` 用过。

### §3.2 体积展开对 `m₁` 失明 `[T]`

`log Z_{S¹_k×T³} = −V₃·k a·f(k) + O(1)`。`m₁` 只出现在 `e^{−akm₁}`（及 `e^{−L m}`）型项里。`1/V₃` 幂级数是**超越阶之外看不见指数小量**的（asymptotic series）：`e^{−cL}` 的 Taylor 系数全为零。⇒ **任何有限阶体积展开系数都不含 `m₁`。**
真正的提取必须走 `k→∞`：`f(k)` 在 `k` 复平面的奇点就是 `m₁`，而这**必须**做逆 Laplace 变换（= 同一个 `limsup`，§2.1），且是**病态**的。⇒ **答任务 3：不能用体积展开定 `z₁`；能把 `m₁` 拿出来的只有 `k` 方向（时间方向），不是 `V` 方向。**

### (c) `D_O` 显式不可得 ⇒ **部分（卡点从"显式"移到"方向"与"输入的合法性"）** `[T]`
