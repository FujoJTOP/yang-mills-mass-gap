# GGG3 · OS 公理在弱极限下的闭合性判

> 靶：连续极限要求极限测度满足 OS0–OS4。问：哪些在**弱极限**下自动保持，哪些要额外条件。
> **编号先钉死**：本文件按靶的编号（**OS2 = 反射正性、OS3 = 对称性**）；仓内 `docs/conditional-theorem.md:45` 是 **OS2 = O(4)、OS3 = RP**。§1 两列并列，跨文件引用必须带编号。
> 口径：「自动保持」= 极限对象已存在且与成员同类时，该性质是否**无需额外一致界**即传递。全篇只出 `[T]`/`[NG]`。

## §0 判词

**两条自动、三条不自动。** 平移（OS1）与反射正性（OS2）过弱极限**免费**；正则性（OS0）、`O(4)`（OS3）、簇聚（OS4）**不免费**，三条的挂点恰好就是项目三个已知缺口 `UVS/L3`、`IN-2/SYM-4D`、`GL9/MG`——**弱极限不新增缺口，只给它们改名**。

**一行判据（为什么分成这两类）：** 闭性只来自两件事——① **群元素能被逼近**：平移的像 `a_nℤ⁴` 随 `a_n→0` 在 `ℝ⁴` 中稠密；② **不等式在锥上**：`≥0` 逐项取极限仍 `≥0`。凡涉及**增长率**（OS0 的阶与矩）、**对称增强**（有限的 `W` 长不成 `O(4)`）、**一致速率**（OS4 的 `δ`）的，都不闭。

## §2 OS2 与 OS4

**OS2（RP）——自动，且代价为零 ⇒ 内容也为零。** 对 `A∈C_b`，`f_A=θA·A∈C_b`；`μ_n⇒μ` ⇒ `∫f_A dμ_n→∫f_A dμ`，逐项 `≥0` ⇒ 极限 `≥0`；无界 `A` 用 L² 截断 + Cauchy–Schwarz 收尾。**不需要一致矩界**（与 OS0/OS4 的分水岭）。代价为零的意思是：闭条件只**筛**对象、**不造**对象——`C_RP` 对整条 Wilson 半线 `β≥0` 成立（`GN3-NEARCRIT` 定理 B），RP 与 `β_c`、与质量无关；`Δ` 是 usc，隙只能在极限里掉。
（下一手：核 `θ` 在公共空间上连续——反射面与分块对齐，F4-4；否则 `θ_*μ=μ` 先失败。）

**OS4（簇聚）——需要 `L→∞` 后的唯一性吗？不需要；两件事正交，双向各有反例。**

- **唯一 ⇏ 簇聚**：2D Ising `T<T_c` 对称 bc，`L→∞` 的极限唯一（`=½(μ_+ + μ_−)`），而 `⟨σ_0σ_x⟩→m²≠0`：唯一、不簇聚。
- **簇聚 ⇏ 唯一**：两个不同纯相各自簇聚，子列分别落进去 ⇒ 每个极限点都簇聚，而极限不唯一。
- **正确配对**：`OS4` 给**每个极限点的 `VAC`**（真空一维）；`UNI-lim = W1₀∧W1₁` 给**极限唯一**；`OS4 ∧ UNI-lim` 才是「唯一聚类态」。
- **与 `W1` 的关系**：`MG ⇒ W1`（任意速率），`W1 ⇏ OS4`（上例），`OS4（带速率）⇏ W1` ⇒ **互不可替代**。
- **阶段约束**：`T⁴_L` 上周期关联不可能衰减 ⇒ OS4 只在 `L=∞` 有内容；`a→0` 阶段只有「速率传递」（`(U_a)`），没有「OS4 获得」。

（下一手：OS4 拆成两行——`(U_a)` 进 GL9，`W1` 进唯一性表；`m_n→0` 的 `1/|x|²` 极限作为验收测试 F4-1。）

## §3 判定

- `[T]`：`OS1`（群像稠密）+ `OS2`=RP（锥上不等式）。两条都是**闭条件**，所以都不携带存在性。
- `[NG]`：`OS0`（挂 `UVS(L)`）、`OS3`（挂 `IN-2`/`SYM-4D`）、`OS4`（挂 `(U_a)`/`GL9`）。
- **互证（AGENTS §2.1 窗口）**：本文件独立推出的 `[T]` 列 + `OS0` 的挂点，与 `research/unconditional/G1-CONTINUUM-OS.md:5` 的账簿「OS0 | L3、OS1、OS3(RP)」逐项相同，两路推理不共享 ⇒ 互证。
- **下一手（总表）**：① `OS0`/`OS1` 并入 GL3，公理表只留 `UVS`；② `O(4)` 的唯一入口是 `SYM-4D`/`IN-2`，不再从「格点对称 + 连续性」找；③ `OS4` 的唯一入口是 `(U_a)`，且与 `W1` 分列两行。
