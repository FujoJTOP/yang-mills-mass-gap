# B01 — `w₁(raw)` 对 `β = 3, 4, 6, 10`（`(iii)` 的第一手证据）

**靶**：`(iii) = ∃Δ₀ ∀β ≥ β₀ : m_{0⁺⁺}(β) ≥ Δ₀`。
`Δ₀` 已判死（M6 不充分、2D 不必要）、`M(β) = m/Λ` 是恒等式、`Ω = gap` 循环
⇒ 现在**没有替代候选**。第一个能做的实验只问一件事：**`w₁` 在 `β = 2.5` 之外还正吗？**

**结论（判 (a)）：四点全 `> 0`，`9.4σ–18.2σ`；`w₁` 随 `β` 单调下降但**在 `β ≥ 6` 后压平**（`6→10` 差 `1.0σ`），一致于一个正平台 `≈ 0.11`。`(iii)` 由此得到 `[E]` 级证据 —— 但**等级只到 `[E]`**，原因见 §4（固定 `L = 8` 时 `a(β) → 0`，这是紫外/短距命题，不是物理单位下的质量隙）。**

---

## 1. 设置（与 run1/run3 逐项一致，**只有 `β` 变**）

| 项 | 值 |
|---|---|
| 模型 | SU(2) Wilson，`κ = β/2`，Kennedy–Pendleton 单链热浴（`_sweep`，源自 `run3_apebase.py`） |
| 格 | `L_s = 8`、`L_t = 12`（6144 sites / 24576 links），全部四点相同 |
| 算符 | `run3` 的 `lev0 = raw`：`S(t) = (1/3) Σ_space Σ_{3 spatial planes} ½ Re tr U_p`（零动量、逐时间片） |
| 估计量 | `w₁ = A/C(0)`，`A = Σ_{t=1..3} g_t C(t) / Σ g_t²`，`g_t = e^{-mt} + e^{-m(L_t - t)}`，**`m = 1.546` 固定** |
| 误差 | 20 块 delete-one jackknife（块长 600 组态 ≫ `τ_int`），链 = 8 条 × 1500 组态独立热浴 |

自由质量版本 `w₁_fit` 一并记录（`β=2.5` 时 `0.4058`）。

## 3. 判（趋势）

**单调下降，但在 `β ≥ 6` 之后压平 —— 不是掉到 0。**

相邻差分（误差按两项独立相加）：

```
2.5 →  3 : Δw₁ = -0.1290                       (11σ)
 3  →  4 : Δw₁ = -0.0390 ± 0.0183               (2.1σ)
 4  →  6 : Δw₁ = -0.0438 ± 0.0198               (2.2σ)
 6  → 10 : Δw₁ = -0.0180 ± 0.0183               (1.0σ)  ← 平了
```

- **`β = 10` 处 `w₁/σ = 9.5`**：`w₁ > 0` 在 `9.5σ` 上成立，不是噪声正。
- `6 → 10` 的下降只有 `1.0σ`：与 **`w₁` 趋向一个正平台 `≈ 0.11`** 一致；
  与"线性掉到 0"（`6→10` 应降 `≈ 0.07`）差 `≈ 3σ`。
- 因此判 **(a)**：四点都 `> 0` ⇒ `(iii)` 得到 `[E]` 证据：`w₁` **没有**在 `β = 2.5` 之外塌掉。

## 4. 限定（为什么只到 `[E]`，不升格）

1. **这里是固定体积的短距命题。** `L = 8` 固定、`β` 增大 ⇒ `a(β) → 0` ⇒ 物理体积收缩。
   `m_fit` 在 `β = 10` 撞到扫描上沿（`4.000 edge`），`C(2)/C(0) = -0.0004 ± 0.0029`：
   相关函数在 `t = 1` 就耗尽。此时
   `A(1.546)/C(0) ≈ 4.48 · C₁/C₀ = 4.48 × 0.02513 = 0.1126`（与表中 `0.1129` 吻合），
   即 **`w₁ > 0` 在高 `β` 等价于"一步切片关联仍为正"**，是格点单位下的紫外/短距陈述，
   **不是** `m_{0⁺⁺}` 在物理单位下有下界。`(iii)` 未被证明；被证明的是"算符幅度不塌"。
2. **固定 `m` 测的是幅度不是质量。** 自由质量拟合在高 `β` 上不稳定
   （`w₁_fit = 1.37 ± 0.90`），不能拿来做质量结论。
3. **窗口**：`β ∈ [3, 10]`、`L_s = 8`、`L_t = 12`、`m = 1.546`、SU(2)。不外推到 `β > 10` 或 `L > 8`。

## 6. 三条工具教训（都已修，写在这里防止重犯）

1. **`correlators()` 的轴陷阱（真 bug，改前结果是错的）。**
   `correlators()` 对 `axis=1` 求和；把 3-D `(N, 1, L_t)` 直接喂给它 ⇒ 求和/滚动都发生在
   长度 1 的 `lev` 轴上 ⇒ `C(t)` 变成常向量 ⇒ `w₁ = Σg/Σg² = 5.6387`、jackknife 误差 `≈ 1e-15`。
   第一版 `b01_scan.py` 打出 `w₁ = 5.6381 ± 0.0000, S/N = 1.4×10¹⁵` 就是它。
   **修法**：jackknife 内部先切 `Sm[:, 0, :]`。修后 `β = 3` 为 `0.2137 ± 0.0117`。
   *教训*：`S/N > 10³` 是 bug 报警，不是好消息。
2. **32 链一把铺满不成立。** 本机报 `cpu_count = 32`（16 物理核），但单进程 8 线程只拿到
   `7.2` 个核的吞吐、全机 `%Processor ≈ 63–69 %`；`4β × 8 链 = 32 链` 的单次 `prange`
   跑了 **> 14 min 未完成**，而**单独一个 `β` 只要 60 s**。所谓"32 条轻链 10–20 s"的
   估算在这台机器上偏差 `> 20×`。有效并行度就是 **~8 条链**。
3. **自写的并行核比 `run3` 的慢。** `b01_multi.py` 里把一维 `S[j]` 传进 `parallel=True`
   核的写法，实测比 `_chains` 慢约 5×（`β=4, gap=1, 1600 sweeps` 应在 20 s 内完成，
   实际 5 min 未出结果）。原因未隔离；**回到 `run3` 的 `_chains`（已验证）**，不再自造。

## 8. 下一步（本轮之后最便宜的一步）

`w₁` 在 `β ≥ 6` 压平，但 `t ≥ 2` 无信号 ⇒ 若要把"平台"变成"物理量的下界"，必须
**放大 `L_s` 同时保持物理体积**（`L = 8 → 12` 或 `16`，`β` 同步增大），
否则 `a → 0` 只会把一切压成一步关联。这是 `[E] → [C]` 的唯一通道，也是本轮的边界。
