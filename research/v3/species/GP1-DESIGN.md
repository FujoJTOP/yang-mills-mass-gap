## §0 判词

### 0.1 三句话

1. **「`δ₁` 是单组态观测量」这一步是真的，而且它确实杀掉了 73 d 的成因。** `δ₁ = ⟨K₂⟩₁ + Δ_cont³/24`（`GK2-SYMBOL.md:121` 的 (1.4d)；边缘化读法 `GM2-EDGE.md:48`）里**没有 `a` 的导数、没有第二个 `a`、没有 `L_s ∝ 1/a`** ⇒ 成本从 `6.3e6 s`（`GM4-NUMERIC.md:238`，73 d 墙钟）降到**分辨级 8.1e3 s / 判定级 3.2e4 s**（本文件 §2，实测 `ρ`），即 **780× / 197×** 的压缩。这是真收益，不是换字母。
2. **但它不是「≤30 min 给判定级」的设计，差在两处，两处都不是矩阵-向量乘。** ① **(a) 少一整块**：`δ₁` 所在的是 **S2 方案**（时间也离散，自由场基准 `Δ_a=(2/a)asinh(am/2)` 只在 S2 成立，`GM1-ALGEBRA.md:52`），而 S2 的 `K₂` 有**电扇区**，`GM1-ALGEBRA.md:120` 逐字判它为 `[NG]`（"它的系数表本轮没有算，且它是**唯一**可能承载 `−H³/24` 的那块"）⇒ **计时器根本启动不了**：缺的不是算力，是一个算子。② **统计与系统学各超一截**：实测 per-config 噪声 `ρ = 13.5`（Ls=8）/ `15.7`（Ls=6）⇒ 判定级需 **8.9 h / 2.8 h**（超 **18× / 5.6×**）；变分态缺陷代理 `0.25–0.27`（映射到污染幅度 `ε ≳ 0.17`）给出 3-体系统项 `≥0.085 Δ³`，比要判的 `1/96 = 0.0104 Δ³` **大 8×** ⇒ 即使无穷统计也判不了。
3. **任务书把成本押在 (b) 上，押错了格子。** `H³/24` 在边缘态上是**一个 c-数**：`⟨H³⟩₁ = Δ³`（`ψ₁` 是 `H` 的本征向量）⇒ `[T]`，**0 次 matvec**。Chebyshev/`log` 那套只有在「概率表示」（相关函数矩阵）里才需要，而那里每一项 = 相关函数前进一格 ⇒ 总成本 `∝ e^{2m̂n} = e^{92}`（`n=27` 实测阶数，§1.2）⇒ **统计上死，不是 CPU 上贵**。⇒ (b) 既不是瓶颈，也不该按“多项式阶数×单次成本”记账。

## §1 三块设计

### 1.0 先钉方案：`K₂` 只在指明的方案里是一个算子

`GM1-ALGEBRA.md:47–52` 已钉死两种读法，本轮**不重开**，只承重其后果：

| | 方案 | `T_a` | `K₂` 的支撑 | 自由场 `c₁` |
|---|---|---|---|---|
| **S1** | Kogut–Susskind 极限（时间连续、空间间距 `a`） | `e^{−a_tH_a}`，`a_t→0` | 只有磁扇区 | `0` |
| **S2** | 全离散 Wilson 转移矩阵（时空同间距） | 4D 各向同性 | 磁 **+ 电** | `−m²/24` |

**靶在 S2**：`(SM-def)` 的 `ω_a := (2/a)sinh(aΔ_a/2)`、自由场基准 `Δ_a = (2/a)asinh(am/2)` 都是 **S2** 的式子（`GM1-ALGEBRA.md:52`；`GK2:65`）。仓内所有 `Δ_a` 数据（`b01`/`gh2`/`gw7`，β=2.5 的 4D 各向同性 Wilson）也是 S2。⇒ **`δ₁` 需要 S2 的 `K₂`，而 S2 的 `K₂` 缺电扇区。** `[M]`

### 1.1 (a) `K₂` 的显式式：闭式骨架 `[T]`（本轮新增）+ 电扇区 `[NG]`

#### 1.1.a 骨架（本轮算出来并核过）

Wilson 转移矩阵写成对称分裂 `T_a = e^{−aA/2} e^{−aB} e^{−aA/2}`（`A` = 电核，`B` = `−log T_P`，`:47` 的 `T_E^{1/2}T_P T_E^{1/2}` 逐字同一形式）。则

```
H_a := −(1/a) log T_a = (A + B) + a²K₂ + O(a⁴)
K₂ = −(1/24)·[A,[A,B]] − (1/12)·[B,[A,B]]                                (K2-BCH)   [T]
```

**核验**（`w7/gp1_delta1.py --bch`，`gp1_delta1.log:29–38`）：4×4/5×5 随机对称 `(A,B)`，`H_a` 由 `eig` 型 `log` 数值构造，按 `t=a²` 的三项最小二乘外推（`a ∈ [0.025,0.10]`）反解 `α,β`：

```
α = −0.0416667412   (α·24 = −1.000002)   ⇒ −1/24
β = −0.0833332891   (β·12 = −0.999999)   ⇒ −1/12
逐组核验 4/4：max|K₂^num − K₂^closed| / max|K₂| ≤ 2.046e−05
```
⇒ `(K2-BCH)` 的**两个系数**被钉到相对 `1.8e−6` / `5.3e−7`，闭式复现到 `2.0e−5`。这是本文件唯一一条**新**的 `[T]`（抽象 `A,B` 层的代数，不是 SU(N) 的系数表）。

**扇区对账（把 `(K2-BCH)` 的两项对到仓内已有的东西）**：

| `(K2-BCH)` 的项 | 结构 | 归属 | 仓内状态 |
|---|---|---|---|
| `−(1/12)[B,[A,B]]` | 磁场核的双交换子 | **磁扇区** | `GM1-ALGEBRA.md:85–86` 给出**独立**闭式 `K₂^{mag} = (1/(24g²))∫Σ_{i<j}tr(F_ij(D_i²+D_j²)F_ij) = −(1/(24g²))∫Σ_{i≠j}tr(D_iF_ij)² + ∂`，系数 `1/24` 由 `1−J₀(2a sin(qa/2)) = a⁴q²/4 − a⁶q⁴/48` 双路核死（`gm1alg_check.log [4]` 残差 `0`/`0`）⇒ `[T]`+`[E]` |
| `−(1/24)[A,[A,B]]` | 电核的双交换子 ⇒ `E`-依赖的 dim-6（`E²F²`、`E·(DF)` 多重收缩） | **电扇区** | **`[NG]`**：`GM1-ALGEBRA.md:120` 逐字"它的系数表本轮没有算，且它是**唯一**可能承载 `−H³/24` 的那块" |
| `trF³` / `tr(F_ijF_jkF_ki)` | — | **不存在** | `C`-奇 ⇒ Wilson 下恒零（`GM1-ALGEBRA.md:111–118`，`[T]`；撤回 `GK2:24,171–175` 的第 2 片） |
| `E²F²` 混合 | — | 随方案 | `[NG]`（`GM1-ALGEBRA.md:130`，须逐项 matching） |

**本轮对 (a) 的净贡献**：把 `[NG]` 的那一块**定位成闭式里的一个具体项**并给出它的系数 `−1/24`。这不是"算完了"——`[A,[A,B]]` 的 SU(N) 求值（`E^a_l` 与 `U` 的对易子、Casimir 代数、格点算符排序）仍是 `[NG]`，仍需 `gm1-algebra` 的输入。但它把"缺一整块扇区（不知道长什么样）"降级成"缺一个已知形状、已知系数的双交换子"。

#### 1.1.b 推导路径（三步，逐步骤说明"要什么"）

1. **写出 `A`、`B`**（`[std]`）：`A = (g²/2)Σ_l Ê_l²`（逐链 Casimir，**S1 下无 `a²` 修正**，`GM1-ALGEBRA.md:64`）；`B = −log T_P`，`T_P = Π_s∫dU e^{−S_p}`。S2 另需 `T_E` 的 `a`-依赖，那是把 `A` 换成 `(g²/2)Σ_l Ê_l² + a²(…)`——**这正是 S1/S2 的差**，也是本轮判 `[NG]` 的落点。
2. **`B` 的 `a`-展开**（`[T]`，已有）：`1 − (1/N)Re tr U_□ = (a⁴/2N)tr F² + a⁶(1/N)tr(F G) + O(a⁸)`，`θ³` 对 `Re` 无贡献（偶）⇒ `K₂^{mag}` 的两行推导（`GM1-ALGEBRA.md:66–87`）。
3. **两个双交换子的 SU(N) 求值**（`[NG]`）：`[A,[A,B]]` 与 `[B,[A,B]]` 各展开成 `E,E,F,D` 的局域密度。**需 `gm1-algebra` 的输入**：①`[Ê^a_l, U]` 的表示矩阵元；②`Ê` 的 Casimir 缩并（`Σ_a T^aT^a = C₂·1`）；③S2 里 `T_E` 的 `a`-修正项（与 `GM1-ALGEBRA.md:129–130` 的清单同一处）。**给 `gm1-algebra` 的一句话规格**：把 `(K2-BCH)` 的两项在 S2 的 `E,F,D` 基上算成显式密度，逐项报系数，并与磁扇区的 `1/24` 闭式（`:85`）交叉核对。

**交叉核对（用来钉骨架的那把尺）**：`−(1/12)[B,[A,B]]` 在 `S1` 下必须复现 `GM1` 的 `1/24` 闭式；若复现不出（哪怕差因子 2——`[M]`：`tr_adj = 2N·tr_fund` 的归一差，`GM1-ALGEBRA.md:107`），则骨架的分项归属错。**这条检验比自由场/2D 更直接地钉 (a)**，且成本是 `U(1)` 单模的闭式（`[E]` 级，分钟量级）；本轮**未做**，列为下一轮第一件事（§4.3）。

### 1.2 (b) `H³/24`：**在边缘态上它就是一个数**（`[T]`），多项式路统计上死

#### 路 (i) 精确路（推荐，成本 0）

`ψ₁` 是 `H` 的本征向量、本征值 `Δ_cont` ⇒ `H³ψ₁ = Δ_cont³ψ₁` ⇒

```
⟨H³/24⟩₁ = Δ_cont³/24      （c-数，不需要任何算子作用，0 次 matvec，0 个多项式系数）   [T]
```

这一步同时解释了 `GK2:121` 的 (1.4d) 为什么能写成"`δ₁` = 一个数 + 一个矩阵元"：`H³/24` 项**不是**待逼近的算子，它已经塌成一个数。**任务书 (b) 的整个 Chebyshev/log 讨论因此只对"非本征态"或"非对角矩阵元"有用**——而 `(SM-2)` 只需要对角的那一个。

#### 路 (ii) 多项式路（若坚持要它：阶数与成本都实测）

`H = −(1/a)log T` 非局域 ⇒ 用 `P_n(T) ≈ −(1/a)log T`。谱窗由 `m̂ = aΔ ≈ 1.7` 与 UV 端给出：`T` 的本征值落在 `[e^{−6}, e^{−1.7}] = [0.0025, 0.183]`（`m̂` 见 `B04:98` 经 `GM4-NUMERIC.md:96`）。实测最小阶数（`chebinterpolate` + 稠密网格校验）：

| 目标相对精度 | Chebyshev 阶数 `n` |
|---|---|
| `1e−3` | **27** |
| `1e−4` | **35** |

（`gp1_delta1.log:63–64`，`[E]`。）

**成本必须按"信号"记，不按"matvec"记**：在仓内唯一可用的表示（相关函数矩阵 `C(t)`，`gp6b_gevp_conn.py:12–15`）里，**作用一次 `T` = 相关函数前进一格**。第 `t` 格的每-组态噪声 `∝ e^{+m̂t}` ⇒

```
度 n 的总成本 ∝ e^{2 m̂ n} = e^{2·1.7·27} = e^{92}         （n=27，1e−3 精度）
```

⇒ **多项式路不是"贵"，是"没有信号"**。这一条也顺带说明：任务书要求的"多项式阶数与成本估计"若按"阶数 × 单次 matvec 成本"记，会低估 `e^{92}` 这个因子——那是本轮对成本模型最重要的一处更正。`[T]`（结构）+`[E]`（阶数）

**结论**：(b) 的成本是 **0**（路 i）。这块不是瓶颈。

### 2.2 统计：`N_req` 与 30 min 阈值

**定标律**（单时片插值量，`σ ∝ N^{−1/2}`）：

```

```

**`σ_target` 有两个档，必须分开写**（`GM4-NUMERIC.md:260` 的两侧检验是判定级）：

**30 min 的充要条件**（1800 s，`L_s=8` ⇒ `N ≤ 3.75e5`）：

```

实测   ρ = 13.5（Ls=8）/ 15.7（Ls=6），κ = O(1)
⇒ 分辨级超 4.5× / 1.4×；判定级超 18× / 5.6×
⇒ 要在 30 min 装下，需方差降 4.5×（分辨级）或 18×（判定级）
```

### 5.1 这套设计能否 ≤30 min 给出 `δ₁` 的判定级结果？—— **不能**

2. **两条定标（<1 s）**：自由场 `δ₁=0`（两路）、2D `δ₁=Δ³/24`。
3. **一块代数（1 轮，0 机器）**：`(K2-BCH)` 的 `−1/24`/`−1/12`（本轮已做，核到 `2.0e−5`）+ 电扇区的 SU(N) 求值（`[NG]`，留给下一轮）。

### 5.3 把 30 min 变成可能的三条硬条件（按代价排序）

1. **补 (a2)**（0 机器）：`−(1/24)[A,[A,B]]` 的 SU(N) 密度 + 与 `1/24` 闭式的交叉核（§4.3）。**必须先做，否则后面两条无意义。**

**「单矩阵元」把 73 d 变成小时级（780×/197×），但它把困难从"`a`-外推与 `L_s⁴`"搬到了"`K₂` 少一块 + 变分态不纯"——前者是代数缺口（1 轮），后者是 8–13× 的系统学缺口（要平台，而平台现在没有）。⇒ 30 min 给不出判定级；3 s 的 pilot 能诚实地告诉你这件事，这就是本轮该交付的东西。**
