## §2 共轭真正构造的东西：换测度 `ν ↦ ν^χ`

**(2.0) 定义与两条精确恒等式（`[T]`，机检 [8] 6/6）**：
```
ν^χ := s⁻¹dν / M₋₁  （概率测度，支在 supp ν 上）；w₁^χ := ν^χ({m₁}) = (f₁²/m₁)/χ
(2.1)  w₁ = w₁^χ · (m₁χ/M₀)          恒等式（逐个测度逐位核过）
(2.2)  w₁ ≤ w₁^χ ≤ 1                 等号 ⟺ 单原子 ⟺ w₁=1 ；比 w₁^χ/w₁ = M₀/(m₁χ) ≥ 1
```
**(2.1) 读法**：`ν^χ` 与 `ν` 的 RN 导数 `dν/dν^χ = s·M₋₁` 就是"质量变量 `s` 本身"。所以 (2.1) 说：**靶的原子分数 = 共轭的原子分数 × （RN 导数在底部的归一值）**。共轭这一侧能控的量全在第一个因子里。

**(2.2) 薄原子纤维（`HZ5-B`，λ=1，机检 [9]）**：`ν_ε=(ε/2)δ_ε+(1−ε/2)δ_{2−ε}` 上 `M₀≡1`、`χ≡1`、**`w₁^χ≡1/2` 与 ε 无关**，而 `w₁=ε/2`。全二进族 `ε=2⁻¹…2⁻²⁰` 的 `M₋₁≡1` 已在 `HZ5:139` 核过，本文件独立重核 `ε=2⁻¹,2⁻³,2⁻¹⁰,2⁻²⁰`（`M₀,χ,w₁^χ` 逐位相同、`w₁` 逐位减半）。⇒ **共轭侧读数恒定，靶读数趋于 0**：这不是"共轭不够精确"，是 0.5 的 RN 因子在底部没有信息。

## §4 `∂_β` 单调性能给的那一条（`[T]`）：`χ` 的，不是 `w₁` 的

**(4.1) 判**：`∂_β` 单调性**不是缺的**——在这个模型上它是**真的、所测全段的、速率已知的**。它单调的对象是 `ν^χ` 的总质量。**这正是本路最反直觉的一点**：共轭路不失败于"证不出单调性"，失败于"证出的单调性属于另一个测度"（O-1）。
