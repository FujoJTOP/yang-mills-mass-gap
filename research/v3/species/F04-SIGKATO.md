## 1 · `σ` 的两种精确陈述

### 1.1 `σ_sep`（"可分性"字面读法：有**平坦因子**）

设 `μ` 为真空概率测度，`λ₁(μ)` 为其 Dirichlet 形式的谱底（= `m`，`U09 §0.4`：`Λ(ρ,∇) = λ₁ = m`，`[T]`）。
`U05` 引理 1（min 律，`[T]`）：`μ = μ₁ ⊗ μ₂ ⇒ λ₁(μ) = min_i λ₁(μ_i)`。

**定义（精确）**
```
σ_sep(μ) := 1  ⟺  ∃ 非平凡张量分解 μ = ν ⊗ ν′  使  λ₁(ν′) = 0     （即有一个"平坦因子"）
            0  其他
```

**两条推论（这是 Q1 的实质答案）**

1. **`σ_sep` 只能是 1 bit，不能是数 `[T]`。** 定量化尝试 `D(μ) := min_i λ₁(μ_i) − λ₁(μ)` 在**任何**乘积上由 min 律**恒等于 0** ⇒ "分裂缺陷"作为实值泛函**恒等零**，无论哪个模型。所以 `σ` 的全部内容是"有没有一个 `λ₁=0` 的因子"这**一个 bit**，不是幅度。**（这解释了为什么 B05 的三个候选都只能钉 bit。）**
2. **`σ_sep = 0` ⇏ "不是乘积" `[T]`+`[E]`。** 2D YM 的真空测度是**逐 plaquette 热核的精确乘积**（§2.1 精确枚举），而 `σ_sep(2D YM) = 0`（每个因子都有隙 `3g²/8>0`，没有平坦因子可分裂）。用户提议的等价式 `σ=0 ⟺ 测度是乘积` **左边对、右边错**；正确写法：
   ```
   σ_sep(μ) = 1  ⟺  μ 有一个平坦（λ₁=0）张量因子      （严格强于"是乘积"）
   σ_sep(μ) = 0  ⟺  每个因子都有隙，或根本没有张量分解
   ```

**四模型值 `[T]`/`[M]`**
- **自由场（无质量）**：`σ_sep = 1`——`k=0` 模方差发散 ⇒ 平坦（非正常）因子。**限定**：若把零模投影掉（`T̃` 定义在 `Ω^⊥` 上，这正是语料的口径），自由场测度在 `Ω^⊥` 上是**有隙 Gauss 的乘积** ⇒ `σ_sep = 0`。**这一行随口径翻转**；但它不改变判死结论（该行 `Kato=假`，合取两读都得 `F`）。
- **2D YM**：`σ_sep = 0`（§2.1）`[T]`+`[E]`。
- **M6**：`σ_sep = 1`——`μ = μ_a ⊗ μ_b`，`μ_b` = `b` 环上的 Lebesgue，`λ₁ = 4π²/L² → 0`（`B05:30` 逐字）`[T]`。
- **单 plaquette**：**无定义**——只有一个面、一条链，**根本不存在非平凡张量分解**（不是"没有平坦因子"，是命题无意义）`[T]`。

### 1.2 `σ_str`（物理读法：带电扇区被**隙**分出去）

```
σ_str := −lim_{A→∞} (1/A) log|⟨W_R(∂A)⟩| ,  R = 基本表示
```
即"带一个静态基本源的最低态能量（相对真空）"。等价说法：`σ_str = 0` ⟺ 源不被任何隙分开（周长律/退禁闭）。2D 精确：`σ_str = g²C₂(R)/2` `[T]`。

**这一读法里"可分"= 真空与带电扇区可分离（有隙），不是"测度乘积"。** 它在 2D YM 行上与 §1.1 **符号相反**。

### 1.3 歧义就是判死点 `[T]`

| 模型 | `σ_sep` | `σ_str` |
|---|---|---|
| 自由场 | `1`（或 `0`，见口径） | `0` |
| **2D YM** | **`0`** | **`3g²/8 > 0`** |
| M6 | `1` | `0` |
| 单 plaquette | undef | undef |

⇒ **`σ` 在 2D YM 行上取值由读法决定，且两读相反。** 靶 `(σ>0)` 的成活与死完全取决于选哪一读——这不是物理，是命名。

## 2 · 四模型测（含精确证据）

### 2.1 2D YM 的**乘积性**：精确枚举（无采样）`[E]`

若 2D YM 测度精确乘积，则 (i) 不同 plaquette 的协方差**精确为 0**；(ii) `(tr P₀, tr P₁)` 的联合经验律 = 边际之积（`TV = 0`）。两者都在**有限群上穷举全部构型**直接检验：

| 群 / 格 | links | 构型数 | `max|cov|` | `TV(joint, marg×marg)` |
|---|---|---|---|---|
| `Z₄`，`2×2` 环面，`β=1.7` | 8 | 65 536 | `1.5e−33` | `0.0` |
| `S₃=D₃`（忠实 2×2 正交表示），`3×1` 环面，`β=1.9` | 6 | 46 656 | `1.9e−18` | `5.9e−17` |

⇒ **2D YM 的 plaquette 变量两两独立，每个的律 = 单面 Gibbs 权 ∝ e^{S}dg**（轴向规范 `P_p = U_v(p)`，Haar 变换 Jacobian 1）。**测度是精确乘积。** `[T]`+`[E]`

**诚实记录（一条失败的检验，保留）**：朴素计数式 `Z_lattice = z^{N_p}` **不成立**（`Z₄`: `18178.86` vs `12053.51`；`S₃`: `794.46` vs `797.17`）。原因是**环面上的计数效应**（最大树固定掉 `V−1` 条链 + 非平凡圈的全局约束），**不是**乘积性失效——乘积性由上面两条**精确**判据（协方差、全变差）单独确认。把这条写下来是因为它曾在本轮被误读成 FACTOR-FAIL。

### 2.3 `Kato` 与 `m` 的关系（严格性方向）`[T]`

- **`Kato ⇒ m>0`**（给定 `λ_bot(T̃)<1`）：孤立 + 有限重 ⇒ `spec(T̃) ⊂ {λ_bot} ∪ [0, λ_bot−κ]` ⇒ 底与其余有正距离 ⇒ 隙 >0。
- **`m>0` ⇏ `Kato`**：显式见证（精确、非数值）——`T = mult g`，`g(x) = (1+x)/4` on `L²[0,1]`，`spec(T) = [1/4, 1/2]` **纯绝对连续**；`m = −log(1/2) = 0.6931 > 0`，而 `dist(sup, spec∖{sup}) = 0` ⇒ `r_iso = 0`。同一现象在**有质量自由场**上出现（脚本 `[3]`：`m = ω₀ = 1 > 0` 而 `E₂−E₁ = 1.81e−1 → 1.23e−2 → 7.7e−4 → 0`）。
- ⇒ **`(σ>0) ∧ Kato` 的 Kato 半边严格强于 `m>0`**（更硬的目标，不是更软的）；而 `σ` 半边只加 1 bit，见 §3。

## 3 · 判

### (b) 成立：**靶死在 2D YM**，且**是结构性死**

`(σ_sep>0) ∧ Kato` 的唯一失败行就是 2D YM，因为：

1. 2D YM 的真空测度是**精确乘积**（§2.1，两条精确判据 + 穷举）；
2. 每个因子是**有隙**热核（第一个非平凡 Casimir `3g²/8>0`）⇒ 没有平坦因子可分裂 ⇒ `σ_sep = 0`。

**"可分性"与 2D YM 的精确可解性是同一件事**：2D YM 之所以精确可解，正是因为测度按 plaquette 精确分解。所以任何把 `σ` 读成"可分性/有平坦因子"的靶，**必然**在 2D YM 上取 0。**这不是本轮没造好，是这个形式化与那一行相斥。** `[T]`

### (a) 也能成立，但**空洞**：`(σ_str>0) ∧ Kato` 4/4 过，零新信息

按 `σ_str` 读法四行全过（`F/T/F/undef`），但：

- 在 2D YM 上 `σ_str = g²C₂(R)/2` 与 `m = g²C₂(1/2)/2` **是同一个式子**，逐位相同（脚本 `[2]` 打印两式同值）`[T]`；
- 四模型上 `σ_str` 的签名 `(0,+,0,undef)` **就是** `m` 的签名；`Kato` 的签名**也是** `m` 的签名（§2.2）。

⇒ 靶的两半**各自**都只重复 `m` 已有的那 2 bit 中的一位，合取**不产生任何 `m` 之外的 bit**。它与 `m>0` 的关系：
- **`(σ_str>0)` 与 `m>0`**：四模型上等价；4D 上互不蕴含（语料无任何方向的真定理）`[NG]`；
- **`Kato` 与 `m>0`**：`Kato` **严格强**（§2.3 有精确反例）`[T]`；
- **合取整体**：**严格强于 `m>0`**（靠 Kato 半边），**但严格强的那部分是 B05 已判死的 `𝐂₂`**，不是新东西。

### (c) `σ` 卡在哪：卡在"1 bit + 两读相反"

- **不能数值化**：定量分裂缺陷由 min 律恒等零（§1.1 推论 1）。
- **不能唯一化**：`σ_sep`（测度论）与 `σ_str`（场论）在 2D YM 上符号相反（§1.3）；LOOP-RUNBOOK:7258 写的是前者（"有没有平坦因子"），而**前者在 2D YM 上恰好是 0**——**RUNBOOK:7259 的"两者合起来恰好区分 M6（可分、非原子）与 2D YM（不可分、原子）"是对的，但那是把 `(σ,Kato)` 当 2-bit 签名读，不是当合取读；合取只有 1 bit，且那 1 bit 在 2D YM 上是 0。**
- `Kato` 本身**不卡**（可精确定义、可精确算、四模型全过），但它与 `m` 撞。

## 4 · 结论一句话

**`(σ>0) ∧ Kato` 不是新靶**：按"可分性"读法它死在 2D YM（(b)）；按"弦张力"读法它 4/4 过却零新 bit（(a) 空洞）；根因是 `σ` 只有 1 bit 且这一 bit 与 2D YM 的精确乘积性**反向绑定**。**要真正的第 3 bit，必须找一件 2D YM 上为"非乘积"（即破坏精确可解性）的事，而不是它的一个因子。**
