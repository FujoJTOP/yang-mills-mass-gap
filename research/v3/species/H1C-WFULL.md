# H1C · `W_full` 有没有定量下界？

**判死线：(b)。** `W_full = W_geo + X`，`X = −2Cov(G,Φ')` 符号不定 ⇒ **`W_full ≥ W_geo` 不成立**（扫描点上 21% 失效，
最大亏额 `−0.0230`）⇒ **(a) 的免费 `W_full ≥ (N/12)‖v‖²` 拿不到**。但**代之以一条精确恒等式**，
把缺的那一步压缩成**单个方差差**；且数值上 `W_full ≥ (N/12)‖v‖²` 在**每一个**测量点成立（最小比 **1.025**），
在冻结极限 `β→∞, θ=0` 下比值 **恰趋于 1⁺**（下界渐近锋利）。**[V]，非定理。**

## 2. 精确恒等式（本报告新增记账；代数恒等，无数值输入）

`W_full = E[Φ''] − Var(Φ') − 2Cov(G,Φ') = E[Φ''] + Var(G) − Var(G+Φ')`。  **(I)**

数值核验：两个独立求积（`sm1_exact.moment_decomp_1x1` 与 `h1c_wfull.moments_1x1`）
在 12 个 `(β,θ)`×19 个 `a₀` 上 `|Id − W_full| ≤ 1.5e−9`。

由 **(I)** 与 Lemma B（`Φ''⪰0` 逐点 ⇒ `E[Φ''] ≥ (N/12)‖v‖²`，`ch05:207–209`）：

```
W_full ≥ (N/12)‖v‖²   ⟺   Var(G+Φ') − Var(G)  ≤  E[Φ''] − (N/12)‖v‖²  ≥ 0 .        (II)
充分条件： Var(G+Φ') ≤ Var(G)   ⟺   X ≥ Var(Φ')      （比 [NA] 严格更强）。
```

所以**缺的不是共变号，而是一个「条件化不增力方差」的方差差**。这是 `[M]` 级的新目标；
`X ≥ 0`（[NA]）只是它的一阶影子。（`W_full ≥ W_geo − 2√(Var G·Var Φ')` 的 Cauchy–Schwarz 界
见 `ch08:134`——但它把 H1 自身的 `Var(G|0)` 又请回来，**循环**，不给定量下界。）

## 4. 裁决

- **Q2（能否简化成 `Var ≤ E[H]+(N/12)‖v‖²−δ`）：不能，`[NG]`。** 该简化需要 `W_full ≥ W_geo` ⟺ `X ≥ 0`
  ⟺ `[NA]`，而 [NA] 未证且**数值假**（21% 点失效，见上）。即便 [NA] 成立，它也**不闭合 H1**：
  未知量 `Var(G|0)` 一点没少，只是把另一未知量换成常数地板。
- **Q3（额外的负项）：有，是 `X = −2Cov(G,Φ')`。** 界的两种形式：
  (i) `[M]` Cauchy–Schwarz `X ≥ −2√(Var G·Var Φ')`——把 `Var(G|0)` 请回来，循环；
  (ii) `[M]` 恒等式 **(I)/(II)**：`W_full = E[Φ''] − [Var(G+Φ')−Var(G)]`，缺的正是方括号 ≤ `E[Φ'']−(N/12)‖v‖²`。
  这是**唯一不循环**的路线：左边全是已证正项（Lemma B），右边是单个方差差，不需要 `Var(G)` 的绝对上界。
- **Q4（比值 ≥1？）：是，逐点 ≥1，且 `β→∞,θ=0` 时 →1⁺（下界对 `W_full` 也渐近锋利）。**
  机制：该极限下测度集中到 `ξ→0`，`Φ''(0)=1/6=N/12` 逐点、`Var(Φ')→0`、`Def=Var(G+Φ')−Var(G)→0`，
  故 `W_full → N/12` 而 `E[Φ'']−floor → +0.0042` 仍不紧。**这是 `[V]`：`W_full ≥ (N/12)‖v‖²` 无证明，
  只有 232 点证据 + 一条可攻的精确中间式 (II)。**
- **Q1 副作用（(c) 检查）：定义在语料里一致**（`ch01:147–150`、`ch08:18`、`ch13:69`、`ch16:506`、`app:796`
  全为 `W_full=W_geo+X`）。唯一的**双对象风险**是 `ch15-uvface.tex:17` 的 `eq:v3shadow`
  （`G''_0=E[H]−Var(G)+W_geo=2W_geo`，**无条件化**对象，另一物）——`ch15` 自己标了「correct, but it is not (★)」，
  故**不是 P0 记账错**；但任何引用 `W_full` 的段落都必须继续带 `X`，否则退化成 `eq:v3shadow`。

## 5. 下一步（可攻，不再靠猜符号）

证 `Var(G+Φ'|0) ≤ Var(G|0)`（充分），或松版 `Var(G+Φ')−Var(G) ≤ E[Φ'']−(N/12)‖v‖²`（等价 (II)）。
工具候选：Brascamp–Lieb / Holley–Stroock 的**条件化方差单调性**——`e^{−S}` 对 `Φ` 是 log-concave 微扰，
`Φ` 凸（Prékopa 已用），故「加一个凸 Jacobian 力」应使总力方差**不增**；这是 `[O]`，
但如果成立，`W_full ≥ (N/12)‖v‖²` 成为**定理**，H1 的记账就只需 `Var(G) ≤ E[H]+(N/12)‖v‖²−δ`。
