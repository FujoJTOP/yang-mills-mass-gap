## 1 · 第一问：KP 原文里 `a` 的取法（逐字 + 原文状态）

**逐字 `[V]`（二级源，本轮核）**：

> **THEOREM 4.1 (Kotecký & Preiss 1986, Theorem 1).** *If there exists a function* `a: K → [0,∞)` *such that for all* `γ ∈ K` …
> —— 转引（KP Theorem 1 逐字引式）：`Σ_{γ′≁γ}|w(γ′)| e^{a(γ′)} ≤ a(γ)  ∀γ`

同式另见 `RS8:29,31`（arXiv:2611.14167 / 2306.12934v3 §3.1，两函数变体 `e^{a+b}`）与 ETH 论文的改述「If there exists a function `a` …」，其应用实例取 `a(X)=|𝒱(X)|`（**每顶点 1**，即 `a=1` 的一次**选取**）。

**判 `[T]`**：
1. **`a` 是自由的**——量化式是 `∃ a: 聚合物→ℝ₊`，**不是** `∃ a ≥ 1`，**不是** `a` 固定。KP 原文/标准重述里**没有任何下界除 `a ≥ 0` 以外**。
2. **`a=1` 的地位**：只是最常见、最省事的选取（上引 ETH 例；语料 `P3-FULLREP-KP:97` "taking `a=1`"、`:128` 自承 "the constant is explicit but crude (`a=1`, unoptimized)"）。**`a=1` 在本实例化里之所以"自然"，是因为语料把右端归一到 `1`**：`S_x(a) ≤ 1 = a` **只在 `a=1` 时**才等于 KP 形 `S_x(a) ≤ a`。⇒ `a=1` 是**归一化约定**，不是定理要求。
3. **唯一真约束是自洽**：右端 `a(γ)` 必须 ≥ 左端，故 `a(γ)>0`；`a≡0` 使判据对任何非零活度**恒假**（§4）。
4. 参考：`R4-PERCENT:15–16` 已写「**KP 判据的阈值是 `a`，不是 `1`**」——与 KP 原文一致。
5. **★ 语料里"必须取 `a≥1`"的唯一出处 = `LOOP-RUNBOOK.md:16893`（§127.1）**，其推理是：「`a` 是分级参数，判据 `S_x(a) ≤ a` **自指**（右侧就是 `a`）⇒ **必须取 `a ≥ 1`** ⇒ `a=0` 时右端归零」。**本轮裁决：前半对、后半错**——
   * **对**：`a=0` 使右端 `0`，判据恒假（§4.1 机器验证），只能给"收敛半径"，不能给"速率"；
   * **错**：`a>0` 就够，**推不出 `a ≥ 1`**。`a≥1` 是语料的**额外收紧**（把"≤1"当阈值），代价是窗 `3.372e−3`；放开到 `a*>0` 得 `3.777e−3`（`+12%`）。
   * **`grep` 核**：`a\s*≥\s*1|a\s*>=?\s*1|a\s*\\ge\s*1|a\s*\\geq\s*1` @ `research/**/*.md` → **26 命中，其中判据语境仅 1 条**（`LOOP-RUNBOOK:16893`）；其余为 `λ_a≥1`（动物计数下界，另一物）、`ma≥1`/`a≥1.5`（格距/几何）⇒ **"KP 要求 `a≥1`"无第二个来源**。
5. **原文状态 `[O]`**：KP 原页本轮未开（`RS8:32` 已记 `[O]`）；上式为**二级源逐字** `[V]`。**不冒充读过原文。**

## 2 · 第二问：`Φ(a)` 的 `a` ≡ KP 的 `a`（但三个 `a` 撞名）

## 4 · 第四问：`a` 该取多少、窗是 `0.0184` 还是 `3.357e−3`

**判据（`P3:90,96`，`[T]`）**：`S_x(a) ≤ a`，充分形式 `λΦ(a)/(1−λΦ(a)) ≤ a`，`λ=eΔ=20e=54.3656`。
⇒ **窗** `W(a) := sup{β : λΦ(a,β) ≤ a/(1+a)}`（`Φ` 随 `β` 严格增 ⇒ 唯一根）。

| `a` | `W(a)` | `×W(1)` | 备注 |
|---|---|---|---|
| `0` | **0** | 0 | 右端 `=0` ⇒ 判据恒假（§4.1） |
| `0.1` | 1.512e−3 | 0.448 | |
| `0.25` | 2.861e−3 | 0.849 | |
| **`a*≈0.615`** | **3.777e−3** | **1.120** | **自由 `a` 的最优** |
| `0.618=(√5−1)/2` | 3.777e−3 | 1.120 | 闭式极大点 |
| `1` | 3.372e−3 | 1.000 | **语料取法**（cb4 `3.357e−3`，差 0.44%） |
| `1.5` | 2.452e−3 | 0.727 | |
| `2` | 1.652e−3 | 0.490 | |
| `3` | 6.833e−4 | 0.203 | |

**优化点解析**：小 `β` 下 `φ(a):=Φ(a)/β ≈ e^{a}` ⇒ `W(a) ≈ a e^{−a}/[(1+a)λ]`，`d/da = 0` ⇒ `a²+a−1=0` ⇒ **`a*=(√5−1)/2`**；`g(a*)/g(1) = 0.20588/0.18394 = 1.119` = 上表 `1.120`（`[E]`）。
（`λΦ(a) ≤ ½` 这条**与 `a` 无关**的充分条件恰是 `a=1` 处的 `a/(1+a)` ⇒ **`P3:96` 的 `½` 只对 `a=1` 成立**；对别的 `a` 必须用 `a/(1+a)`。）

**★ 顺带否掉 `LOOP-RUNBOOK:16899` 的"或 `6.661e−3`" `[T]`**：`6.661e−3 = 2×3.372e−3` 是 `λΦ(1)=1` 的根，那里 `1−λΦ(1) → 0` ⇒ `S_x(1) = λΦ/(1−λΦ) → ∞`，**不满足 `S_x ≤ a`**。`3.372e−3`（`λΦ(1)=½`）是 `a=1` 唯一正确的窗。

### 4.1 `a=0` 为什么不是"最优点"而是"非法点" `[T]`

`a=0` ⇒ `a(γ)=0·|γ|=0`，而 `S_x(0) ≈ λΦ(0) = 1.0069 > 0` ⇒ **对一切 `β>0` 判据恒假**，`W(0)=0`。语料的 `0.0184` 是**另一个条件**的根：

```
λΦ(0,β) = 1  →  β = 0.018268566   ← 这就是 M3C-TAIL 的"判据根"、I1 的窗（本轮逐位复现）
Φ(0)=β 近似 →  β = 1/(eΔ) = 0.018393972   ← 必要条件根
```

两者都只是「`a=0` 处几何级数 `Σ_m (λΦ(0))^m` 收敛」的根，即**活度绝对可和**（= 一个必要条件），**不是 KP 窗口**。`[T]`
（这是 `cb4:78–79` 的同一结论：`0.0184` 是"`a=0` 放宽版"；本轮把它钉成"`a=0` 非法"，比"放宽"更强。）

### 4.2 高报倍数

| 对谁 | `0.018269 ÷` | 判 |
|---|---|---|
| `W(1)=3.372e−3` | **5.42×** | 与任务的 `5.44×` 一致（`[E]`） |
| `W*=3.777e−3` | **4.84×** | 取最优 `a` 后仍高报近 5× |

⇒ **`0.018269` 在任何合法 `a` 下都不成立；`5.4×` 的"高报"是真的。**

## 5 · 回填 / 限定

* **回填**：(i) `cb4:17,78` 的「KP 真窗 `3.357e−3`」**数对**（本轮 `3.372e−3`），但须并注「`a` 自由，最优 `a*=0.618` 给 `3.777e−3`；`3.357e−3` 是 `a=1` 的值」；(ii) 「KP 要求 `a≥1`」（**`LOOP-RUNBOOK.md:16893`** 逐字「⇒ 必须取 `a ≥ 1`」）**不成立**，须改写成「`a>0` 即合法；`a=0` 非法；`a=1` 是语料取法（窗 `3.372e−3`），最优 `a*=0.618`（窗 `3.777e−3`）」；(iii) `I1` 的窗 `0.018269` 应改标「`a=0` 活度和根，非 KP 窗；KP 窗 `≤3.8e−3`」；(iv) `P3-FULLREP-KP:96` 的 `λΦ(a)≤½` 须限定「仅 `a=1`」；(v) `LOOP-RUNBOOK:16899` 的「或 `6.661e−3`」应删（那是 `λΦ(1)=1` 的根，`S_x\to∞`）。
