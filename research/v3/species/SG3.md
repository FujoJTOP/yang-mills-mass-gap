1. **`s₁` 是什么量** `[T]`：`s₁ := inf supp ν_w` = **`O`-道谱测度的支撑下确界**（该算符最低激发能），
   τ-协变（`s₁(τ_aν) = a + s₁(ν)`，`B05-DUAL.md:80`）。**它不是模型隙**：M6 上 `s₁ = ω = 1` 而 `m₆ → 0`（`ATOM2.md:44`）。
   `s₁ = m` 是**物理前提 `[C]`**，不是定理（`NS2.md:34`）。
2. **`F` 是什么** `[T]`（关于语料）：语料里 `F` **只有规格、没有闭式** —— `F = F(S_W, β, L, a)`、谱盲（`NS2.md:62`）、τ-协变 `F(τ_aν) = F(ν)+a`（`NS2.md:63`）、`F(M6) = 0`（`NS2.md:65`）。
3. **(i) 不触发（不退）`[T]`**：τ-**不变**的迹差分 `tr(f(H)−f(H₀))` 只有 `f` 仿射这一支，其值 `= c·a·N`（随平移 `a` 与格点数 `N` **发散**）⇒ 撞「恒真/发散量」排除面（`NS2.md:85`）。
   且 SSF 本身**正是 τ-协变**（`NS2.md:116` 逐字「✓ 正是 G1-协变」）⇒ 迹差分属于 **`F` 侧**，不属于 `G` 侧。
4. **(ii) 字面不触发 `[T]`，实质未取尽 `[O]`**：`G = s₁ − F` 的表达式里 `s₁`、`F` 都不是 H1/Var/G″/f₁²，而四者**全 τ-不变**、`s₁` **τ-协变**。
   但「只能靠」是**穷尽性**命题，需要 P1–P3（`NS2.md:177,191`）才闭合 ⇒ 本轮**不判 (b)**，只把 (b) 的触发面写死（§3.3）。

## §1 `s₁` 与 `F` 的逐字定义（题面问题 1）

### 1.1 `s₁`：`NS2.md:31` 逐字

```
s₁ := inf supp ν_w  ,   τ_a ν := ν(· − a)   （能量轴平移，G1）
```
口径（`NS2.md:29`、`ATOM2.md:41–45`）：`ν = ν_w` 是 `O` 的谱测度，`w_n = |⟨Ω|O|n⟩|²`，`ν_w = Σ_n w_n δ(E_n − E₀)`
⇒ **`s₁` = 与该算符 `O` 有非零重叠的**最低激发能〔= `O`-道的第一激发〕。`[T]`

三条必须同时挂上的限定：
- **逐算符** `[T]`：`ν` 随 `O` 变（`ATOM2.md:31`）；2D 上 `O = ¼trF²` 给 `ν ≡ 0`（`ATOM2.md:43`）⇒ 该 (模型, `O`) 对上 `s₁ = +∞`（空测度），换 `O = ½trU` 才有内容（`NS2.md:189`）。
- **τ-协变** `[T]`：`s₁(τ_aν) = a + s₁(ν)`（`B05-DUAL.md:80` 表内逐字）。
- **`s₁ = m` 是 `[C]`**：`B05-DUAL.md:159` 把「位置 = `m₁`」列为「等于目标 ⇒ 循环」，`NS2.md:34` 因此把它降为物理前提。M6 上两者**不等**（`s₁ = 1`，`m₆ = min(ω,½(2π/L)²) → 0`，`ATOM2.md:44`）。

**⇒ `s₁` 是「位置」量：谱测度的支撑底。不是权（`f₁²`）、不是曲率（`G″`）、不是方差、不是计数。** `[T]`

### 1.2 `F`：`NS2.md:62–65` 逐字（规格，无闭式）

```
(2) F 可算且不经谱：   F = F(S_W, β, L, a)，不用 ν / E₀ / E₂ / 隔离窗 ρ
(3) 协变分工（G1）：   F(τ_aν) = F(ν) + a ;   G(τ_aν) = G(ν)
(5) 签名故意不过 M6 槽：F(M6) = 0 ,  G(M6) = ω ≠ 0 = m₆  ⇒ N09-1 不适用
```
**逐字结论 `[T]`（关于语料）**：`F` 在语料中**没有显式公式**——它由这三条性质（+`NS2.md:66` 的结论方向）**隐式**定义。
故本文件的所有判断都在**规格层**：问「`G`/`F` 的形是否被钉在 SSF 或 `H1/Var/G″/f₁²` 上」，而不是「某个已知公式等不等于 `G`」。

### 1.3 `G`：`NS2.md:16,45` 逐字

```
G := s₁ − F ,   G ≥ 0 且 G1-不变 （τ-不变 = 形状）
```

## §2 检查 (i)：`G` 是不是某个谱泛函的差？（`tr(f(H) − f(H₀))` 型）

### 2.1 路 A（主证，代数）`[T]`

设 `Φ_f(H, H₀) := tr(f(H) − f(H₀))`，`f` **固定**（不依赖 `ν`）。沿 G1 轨道取 `H ↦ H + a`、`H₀` 固定。
用 SSF（Krein–Birman，`[std]`；`NS2.md:116` 逐字给出）：`tr(f(H)−f(H₀)) = ∫ f′(λ) ξ(λ) dλ`，且 `ξ_{H+a}(λ) = ξ_H(λ − a)`，故

```
Φ_f(H+a, H₀) = ∫ f′(μ + a) ξ_H(μ) dμ .
```
`G` 要 τ-不变（`NS2-0`，`NS2.md:43–47`）⇒ 需 `∫ [f′(μ+a) − f′(μ)] ξ_H(μ) dμ = 0` 对 **∀a** 且对**类内每个 `H`** 成立。

- 若 `f′` 非常数：取类内一个 `ξ_H ≢ 0` 的成员（有限格上 `H` 可任取，`ξ_H` 为阶梯/非退化）⇒ 存在 `a` 使积分非零 ⇒ 矛盾。
- 故 `f′ ≡ c` ⇒ `f(λ) = cλ + d` ⇒ `Φ_f = c·(tr H − tr H₀) = c·a·N`（`N` = 格点自由度）。

**该唯一存活分支的两条死因**：
1. 它随 `a` 线性发、随 `N` 线性发 ⇒ 撞「恒真 / 发散量」排除面（`NS2.md:85`）；
2. 它**不是** `s₁ − F`：后者沿轨道**恒定**（`G(τ_aν)=G(ν)`），前者随 `a` 变。

（旁证，去 SSF 的初等算法：`tr f(H+a) = Σ_i f(λ_i + a)`，`∀a` 恒定 ⇒ `Σ_i f′(λ_i+a) ≡ 0` ⇒ `f′ ≡ 0` ⇒ `f` 常 ⇒ `Φ ≡ 0`。两支一致。）

**⇒ 无非平凡的 τ-不变迹差分 ⇒ `G` 不能写成 `tr(f(H) − f(H₀))`（除 `G ≡ 0`）。** `[T]`
前提：`f` 固定。若允许 `f = f_ν` 自适应，任何 `ν` 泛函都可表示 ⇒ 该式**恒真**、不是本退化条件所针对的对象（恒真式不能构成"换名"的指控）。

### 2.2 路 B（判别，不要哲学）`[T]`

`G ≡ 0` 这一支不是无害的：它意味着 `s₁ = F`，即「位置 = 迹差分」。但
- `s₁(M6) = ω = 1 ≠ 0`（`ATOM2.md:44`），
- 若 `F` 取 SSF 形，则 `F(M6) = s₁(M6) = 1 ≠ 0` ⇒ 撞 `NS2-S(5)` 的 `F(M6) = 0`（`NS2.md:65`）；
- 若强行 `F(M6) = 0`，则 `F` **不是** SSF 形。

**⇒ SSF 形与 `NS2-S` 在 M6 上一个数（`1` vs `0`）上就撞死，不靠"看起来"。**

### 2.3 路 C（类型归属）`[T]`

`NS2.md:116` 自己把 SSF 标为「**✓ 正是 G1-协变**」+「**它就是 ③ 的循环本体**（位置无损）+ ④ 的搬运」。
⇒ 迹差分是**位置侧**对象（`F` 的候选），`G` 是**形状侧**对象。
⇒ **若 (i) 成立，退的是 `F`，不是 `G`**：那是把 `s₁` 整个交给 SSF（`s₁ = F`），即 `NS2.md §3#3` 的循环 + 19 条 `0/19` 的扩窗（`β<1/48`，P3）。

### 2.4 **(i) 判：不退** `[T]`

`G`（τ-不变、`G ≥ 0`、`G(M6)=ω≠0`、有限）**不在** `tr(f(H) − f(H₀))` 的值域内（值域的非平凡部分只有「`c·a·N` 发散」与「`0`」两支，两支都撞墙）。
**退的入口在 `F` 侧**，且那条入口已被 M6 的 `1 ≠ 0` 与 P3 的 `β<1/48` 封住。

## §3 检查 (ii)：`G` 的表达式里有没有 `H1`/`Var`/`G″`/`f₁²`？

### 3.1 字面（表达式逐字拆）`[T]`

`G = s₁ − F` 的两个构件：
| 构件 | 逐字 | 是不是四者之一 |
|---|---|---|
| `s₁` | `inf supp ν_w`（`NS2.md:31`） | **不是**：`f₁² = ν({m₁²})` 是**权**（`ATOM2.md:32`）；`H1 := χ = ∫s⁻¹dν`（`A3-VERDICT.md:64`）是**积分泛函**；二者都不是支撑底 |
| `F` | `F(S_W,β,L,a)`（`NS2.md:62`） | **不是**：谱盲，且按定义排除了 `ν`/`E₀`/`E₂`/`ρ` |

**⇒ `G` 的表达式里四者一个都不出现。** `[T]`

### 3.2 类型（τ-作用下的归属）`[T]`

- `s₁` **τ-协变**（`B05-DUAL.md:80`）。
- 四者**全 τ-不变**：中心矩 / `Var` / `Λ★−m₁²` 在 G1 下不变（`B05-DUAL.md:81` 表内逐字）；`f₁²` 是原子**权**、平移不改权；`G″` 是形状（曲率）槽（`NS2.md:190` L3：不许把 `G″` 当 `s₁` 的替身）。
- ⇒ 四者张成的空间里**没有非平凡的 τ-协变成分**，而 `G` 的 τ-不变性**正是**由 `s₁` 的 `+a` 与 `F` 的 `+a` 相消得来的（`NS2-0`）。把 `s₁` 项换成四者的组合，`+a` 便无处可来，`G` 的 τ-不变性随之失去机制。

### 3.3 但**不许**拿 3.1/3.2 当「(ii) 不退」的证明 —— 反向把 (b) 的触发面写死

(ii) 是**穷尽性**命题（「只能靠」），只能在候选被取尽后判。本轮给出三条已可判的边界：

1. **若 `G` 被写成 `λ f₁²` 类组合** ⇒ 它**确实**能给 `s₁` 下界：`χ = ∫s⁻¹dν ≥ f₁²/s₁` 且 `H1: χ ≤ 1/λ` ⇒ `s₁ ≥ λ f₁²`。`[T]`
   但这条 (α) 逐字违反 `NS2-S(4)`（`NS2.md:64`）；(β) 要 `λ` 与 `f₁² ≥ r₀` 的 `(L,a)`-一致，正是 `I1/I2` 那道墙（`ATOM2.md:32`），而 `f₁²` 恰恰**不**一致正（thin atom：`w = ε/2λ → 0` 而 `inf supp = ε → 0`，`A3-VERDICT.md:66`）。
   **⇒ 落这一形 ⇒ 立刻 (b)。** `[T]` 方向 + `[O]` 一致性
2. **若 `G` 只由 `Var`/`G″`/`H1`（中心矩族）构成** ⇒ 引理 D1 逐字：G1-不变泛函在 `{ν_a}` 上恒定 ⇒ **不能决定 `inf supp`**（`B05-DUAL.md:90–92`）⇒ 与 `G = s₁ − F`（含 `s₁` 项）不相容，除非 `F` 把位置全吸收（⇒ 退回 §2.4 的 `F` 侧退化）。`[T]`（D1）+`[J]`（末一跳）
3. **穷尽性本身** `[O]`：是否所有可行 `G` 都落在上述两族，正是 `NS2.md:177`（P3）与 `NS2.md:191`（C1 自毁条款）要求机检判定的事。**本轮未跑**（时间盒 ≤25 min、且本轮任务只查两条退化条件）。

### 3.4 **(ii) 判：字面不退 `[T]`；实质未取尽 `[O]`；不触发 (b)**

- 不触发 (b) 的理由：`G` 的表达式**不含**四者（3.1 逐字 + 3.2 类型），(b) 的**字面**条件不满足。
- 不宣布「(ii) 已证不退」的理由：3.3-3 的穷尽性未做。**三者的强弱必须分开记，不许合并成一句「不退」。**

## §4 判 `(a)`：`G` 是真新对象 —— 逐字写清

### 4.1 一句定义（逐字）

```
G(O; β,L,a) := inf supp ν_{w,O}  −  F(S_W, β, L, a)
  其中 inf supp ν_{w,O} = O-道第一激发能（s₁，位置量，τ-协变）
       F = 由 (S_W,β,L,a) 直接算出、不经谱（ν/E₀/E₂/ρ）的量，τ-协变
  性质：G ≥ 0、G(τ_aν) = G(ν)（形状）、G(M6) = ω − 0 = ω ≠ 0 = m₆
```

### 4.2 「新」在哪：与全部已知槽的**类型表**

## §5 限定与自毁（本文可能错在哪）

- **W3（逐算符）**：`G` 必须带 `O`（`NS2.md:189`）；不许跨算符搬 `s₁`。
- **C1（自毁，仍活）**：若 P1–P3 表明唯一可行的 `G` 是 `H1/Var/G″/f₁²` 的换名 ⇒ `NS2-S` 塌回五类 ⇒ **改判 (b)**（`NS2.md:191`）。本轮**未触发**，但**未关闭**。
- **C2（自毁，仍活）**：若 `F` 的可算性只能在 `ν` 上落地 ⇒ ② 的循环未破 ⇒ 规格无执行面（`NS2.md:192`）。§2.4 只说 `F` 不在 SSF 形里，**没说** `F` 存在。
- **诚实线**：本文**没有新数字、没有新数值证据**；`[T]` 项全是代数（τ-导数、`f₁² ≤ χ s₁`、类型表）；`[J]`/`[O]` 项已逐条标出。

**⇒ 判 `(a)`：`G := inf supp ν_{w,O} − F(S_W,β,L,a)` 是真新对象 —— 「谱底对谱盲热力学量的缺口」，非任何已知槽的换名；但它是**定义上未被排除的空槽**，`F`、`G` 的闭式都不存在 `[O]`。No QED；Clay 0%。**
