## 1 · 三个数的对表（`Δ = 20`）

```
eΔ            = 54.3656365692   λ_a 的定义值（P3:89 "one may take"），"unoptimized"
L_t           = 53.0006865328   = Δ(1+1/(Δ−1))^{Δ−1} = eΔ·0.9748931472     ← 紧版上界
φ²e^{1/φ}     =  4.8571781362   = 1/max_α[α/(1+α)]e^{-α}  ← λ_a·K·u 的判据系数
```
`L_t` 与 `eΔ` 是**同槽**（同一 `λ_Ur` 的两个界）；`4.8572` 与它们**不同槽**（它是 `λ_a·K·u` 这一乘积的界，`λ_a`、`K`、`u` 三者的乘积无法拆出 `λ_a` 单独的界）。

`[T]` 一致性核验：`CB6:102` 的 `C̄_KP = (Δ/(Δ−1))^{Δ−1}/e` 与 `L_t/eΔ` **同式**（`0.974893`），所以 `CB6` 自己已经算对了比值 —— 只是判词把"比"写成了"值"（E2）。

## 2 · `L_t` 合法吗（第一问，必须先答）

**合法。** 三步，逐步有据：

1. **同对象**：`λ_Ur := limsup_{|Γ|→∞}|φ^U(Γ)|^{1/|Γ|}`（`UR6:66` 的形式），`eΔ` 与 `L_t` 都是它的上界，**不是两个不同的 `λ_a`**。
2. **同路线**：Penrose/KP 树图界 ⇒ `Σ_{|Γ|=n, p₀∈Γ}|φ^U(Γ)| ≤ r_n u^n`，`r_n = (1/n)C(nΔ,n−1)`；`r_n^{1/n} ↑ L_t`。`eΔ` 是这条路的**宽松版**（`(1+1/(Δ−1))^{Δ−1} ≤ e`）。
3. **已到终点**：`log r_n^{1/n} = [lnΓ(20n+1) − lnΓ(n) − lnΓ(19n+2) − ln n]/n`，`n = 10⁴,4×10⁴,1.6×10⁵` 给 `52.90721, 52.97455, 52.99346`，单调升、残差 `9.3×10⁻²→7.2×10⁻³`。**这条计数路内没有剩余松弛**；再压只能换输入。

**所以**：把 `λ_a` 代入为 `L_t` **合法且更优**；`eΔ` **可证非最优**（`[T]`）。反过来说，"optimized `λ_a` = 53.000687" 是**本路可证的最终读数**，不是 `λ_a` 的真值（E4）。

## 3 · 离 `48` 还差多少（第四问）

```
L_t/48    = 1.10418096943      → 还需降 9.435%
eΔ/48     = 1.13261742852      → 从定义值出发需降 11.709%
改善       = 1 − 0.974893147 = 2.5107%   （只覆盖所需 9.435% 的 26.6%）
窗口(C̄=1) : 2N²/λ = 0.14715178 (eΔ) → 0.15094144 (L_t)，+2.575%；即 7.063→7.245 个 (1/48)
窗口(C̄=N) : 4/λ    = 0.07357589 (eΔ) → 0.07547072 (L_t)，仍 < 1/12 = 0.0833333 的 1.1042×
```
两种 `C̄` 记账给出**同一个缺口倍数 `1.1042×`**（因为它是纯常数比，`C̄`/`N` 的影子约掉）—— `[T]`。

**若只靠打磨度数**：`Δ* = 18.1606`（解 `Δ(Δ/(Δ−1))^{Δ−1} = 48`）。`Δ=20` 是 4D plaquette 图的实际度（每片 4 link × 每 link 界 6 片 − 1 = 20，且 `a_2/a_1 = 20` 整数相等），**不是可调参数** ⇒ 该路不可达 `48`。

## 4 · `(a)/(b)/(c)` 判

- **`(a)` 不触发**：`L_t = 53.0007 > 48`，缺口**不关**。
- **`(b)` 触发（主判）**：给 **`λ_a^{opt} = 53.000687`**，缺口 **`1.1042×`**，改善 **`2.51%`**（`eΔ` 口径的比 `0.9749`；若按 `eΔ/L_t−1` 读则是 `2.575%`，两者分母不同，别混用）。`(1/48)` 窗**仍在窗外**，只是从窗外 `7.063/48` 挪到 `7.245/48`。
- **`(c)` 部分成立，但不在本路内**：同一路线内 `L_t` 是**终点**（§2.3），没有更小的严谨界可拿。要跨 `48` 必须换输入，两条候选：
  1. **真动物数**：把 `Δ`-度包络换成 4D plaquette 图的实际连通动物计数（`a_n = 1,20,458,11132,280175`；探针 `λ_* ≳ 25.2`）。**这需要 `λ_* ≤ 48` 的定理（子乘性/转移矩阵式界），语料内没有** ⇒ `[NG]`。
  2. **有效度**：若能把"每片可用邻接槽"从 20 压到 `≤18.16`（用排除体积/几何约束，而非纯度数），`L_t` 自动 `<48`。**这是新工具，不是重新优化 `eΔ`。**
- **不许编的边界**：`λ_* ≳ 25.2` 是**下界探针**（相邻比），它**不能**用来宣布 `λ_a < 48`；`4.8572` **不能**当作 `λ_a` 的读数（E6）。这两个都是**假闭合**的诱因，本轮明确排除。
