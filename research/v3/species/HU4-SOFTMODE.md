## §2 两条界（证明各两行）

### 2.1 上半（`[T]`，全塔）
`Hess V_j = β_j Hess S_W + Hess Φ`；每个 link 只与 `2(d−1)=6` 个 plaquette 相邻 ⇒ Gershgorin 给 `‖Hess S_W‖≤C_S`（与 `L` 无关的格点常数）⇒ `v^T Hess V v ≤ C_Sβ_j + v^T Hess Φ v`；`Hess Φ⪰0`（`V1:84–87`，Lemma B 的上侧只需 `Φ_0''≥0`，`Φ_0''=csc²ρ−1/ρ²≥0`）。又 `W=E[Φ″]−Var(Φ′)≤E[Φ″]=:C_Φ(L)`（Fisher 型有限积分）。故 **`G″_j ≤ E[H]+W ≤ C_Sβ_j + 2C_Φ(L)`（无条件）；按 (D) 除 `Z_j` 得 `Ĝ″_j ≤ C_S/c + 2C_Φ(L)/(cβ_j)`，全塔 j-一致 `[T]`**。**下一手**：`(★_ren)` 的上侧单独成行（现在它藏在"下侧"里）。

### 2.2 头部下半（`[T]`，模式盲）
`|G_v|=|∂_v S+∂_v Φ|≤Cβ_j+‖∂_vΦ‖₂`；`Var(G_v)≤E[G_v²]≤2C²β_j²+2C_Φ(L)`；`E[H]≥−C_Sβ_j`；`W≥−C_Φ(L)`（`W=E[Φ″]−Var(Φ′)≥−Var(Φ′)≥−C_Φ(L)`）。故 **`G″_j ≥ −C_Sβ_j − 2C²β_j² − 2C_Φ(L) − C_Φ(L) ≥ −C(L)β_j²`（`β_j≥0.37`）⇒ `j≤6: |Ĝ″_j| ≤ C(L)β_j²/Z_j = C(L)β_j ≤ 2.23C(L)`，任意 `v`、任意 `U′`、`a`-无关，`[T]`**。
- **为什么它是 soft mode 的全部**：`γ_j→0`、`η_j≥1` 只出现在"把 `G″_j` 与 `A_{j+1}` 比"的那一刻；而 (B) 不与任何东西比，它只与 `β_j` 比。⇒ 头部 finiteness 与 fibre gap 无关。
- **限定**：常数 `C(L)` 是紧性常数（fibre 体积 `~L⁴`），非显式；`j≤6` 的切法来自 `β_j≤2.5`（`V4-PINCER:278`）。**下一手**：S7 的措辞改成"任意单位 `v`"，并把 `j≤6` 写死。
