**T0(b) 回判：成立 ⇒ 这是死因。** 两个独立机制同时封死：
1. **`Ric` 项有硬上界**：`sup_G λ_min(δ^{−1}Ric_G) = N/4`，**恰好取在双不变量（标量）度量上**（数值优化 + `su(2)` 闭式，§2.4、§3.1 `[N]`）。所以"用 `Ric` 补负曲率"这件事**最好就是双不变量的 9.7%**，`G` 一分钱也加不上去。
2. **最坏负方向是各向同性的**：在常数 `Z₂` 2-cocycle 构型上（显式可实现，`L=2` 与 `L=4`），`Hess S_W` 的负部**整体是 `δ` 的标量倍** ⇒ 没有任何"方向"可供 `Ric` 的异向大本征值去对齐。`L=2`/`L=4`、`SU(2)`、`β=2.5` 实测：`λ_min(Hess S_W + ½Ric) = −9.750`，而 `∀G`（扫 50 个形状）最好仍是 `−9.750` ⇒ **改进倍数 1.000**（§4）。

## §2 T1 · 把 `(★)` 写成对 `g` 的泛函

### §2.1 约定（统一并写死）

`X = SU(N)^E`，`E` = link 数。取 `g` = 逐 link **左不变**度量的积：
```
g(X,Y) = Σ_ℓ G_{ab} x^a_ℓ y^b_ℓ ,   e_a = λ_a = i T_a ,  tr(T_aT_b) = δ_ab/2 ,
G  = n×n 对称正定 (n = N²−1)，δ_ab := 双不变量（Ad-不变）形式，即 G = 1。
```
**流约定统一为热核流 `C_t = t·g^{−1}`（线性分解）**，于是 `Ċ_t ≡ g^{−1}`、`Ċ̈_t ≡ 0`、`g_t ≡ g`、`ġ_t ≡ 0`，`V_t = −log(K_t^{G,*} e^{−S_W})`。此时

```
(★)_G :   Hess_G V_t + ½ Ric_G  ⩾  λ̇_t G          （作为 (0,2) 张量的不等式）
⟺        λ̇_t ⩽ λ̇_t(G) := inf_φ λ_min( G^{−1/2}(Hess_G V_t(φ) + ½Ric_G) G^{−1/2} )
```
（平坦 `(3.32)` 与流形 `(3.100)` 在此约定下**同形**：`(3.32)` 的 `Ċ Hess Ċ − ½Ċ̈ ⩾ λ̇ Ċ` 除以 `Ċ = G^{−1}` 即 `Hess ⩾ λ̇G`，与 `(3.100)` 差一个 `λ̇ → λ̇ − N/8` 的平移。这是 `[R]` 公式级核对。）

**`Ric` 的贡献单独标出（这是本路唯一白送的正项）：**
```
½ Ric_G  ⩾  (N/8) · G       仅在 G = c·δ 时取等        （P-C；本轮 §2.4 数值确认是上界）
```

### §2.2 两条把"自由度"砍到最小的事实（`[N]`）

**(i) 尺度无效。** `G → cG`（`c>0`）：Levi-Civita 联络不变 ⇒ `Hess_{cG} = Hess_G`、`Ric_{cG} = Ric_G`。故 `λ̇(cG) = λ̇(G)/c`，`λ_t(cG) = λ_t(G)/c`。同时末端 LSI 的右端用 `Ċ₀ = G^{−1} → G^{−1}/c`，即 `E|∇F|²_{Ċ₀}` 放大 `1/c`，而 `2/γ` 缩小 `1/c`——**乘积不变**。⇒ **只有形状（射影类）是自由数据。**

**(ii) 正交框架把形状压到 `n` 维。** 若把框架做正交变换 `e_a → O_{ab}e_b`（`O ∈ O(n)`，`δ` 不变），则 `G → OGO^T`、`Hess → OHessO^T`、`Ric → ORicO^T`，特征值不变。⇒ **WLOG `G` 对角**。数值核验：`max|λ̇(G) − λ̇(OGO^T)| = 1.5e−14`（`SU(2)`，`mc_ricci.py`）。故形状空间是 `n−1` 维（`SU(2)`: 2，`SU(3)`: 7），而不是 `n(n+1)/2 − 1`。

**(iii) 符号是张量性质。** `λ_min(G^{−1/2}MG^{−1/2})` 与 `λ_min(M)` 有**相同的惯性**（合同变换），所以"`λ̇_t > 0` 能否取到"是 `(0,2)` 张量 `M_G` 的正定性，与 `G` 怎么归一化无关。本轮所有决策量取尺度无关的
```
μ(G) := λ_min(M_G) ,     M_G = Hess_G S_W + ½ Ric_G          （δ-框架下的矩阵本征值）
```

### §2.3 显式 toy：`SU(2)`（`G` 是 `3×3`，形状 2 维）

`Ad`-不变把 `G` 压成标量（`su(N)` 单，不变内积唯一）⇒ **必须允许非 `Ad`-不变 `G`，这就是本路的全部关键自由度**（任务书预判，本轮确认为真且是唯一）。

单 plaquette，`φ(U) = Re tr(U W)`，`W := U₂U₃U₄U₁` 是 plaquette holonomy，在 `U₁ = 1` 处取值。精确（无差分）：

```
d_cφ   := e_c φ    = Re tr(λ_c W)
Hess_G φ = D²φ − Γ^c_{ab}(G) d_cφ              （协变 Hessian，张量）
Γ_{c,ab} = ½(f_abc − f_acb − f_bca),  f_abc = G_cd f^d_ab ,   Γ^c_ab = G^{cd}Γ_{d,ab}
Ric_ab = Γ^c_cd Γ^d_ab − Γ^c_bd Γ^d_ac
Hess S_p = −(β/N)·Hess_G φ ,  一条 link 在 d=4 落在 6 个 plaquette 里
```

`SU(2)` 对角闭式（本轮代码与闭式互核，误差 0）：


⇒ 在中心元构型上，`δ`（各向同性）**已经是** `λ̇` 的最大值点；所有异向形状都更差。

## §3 T0 回判的推导细节

### §3.1 T0(a)：共形/尺度不变性——一半成立

- **常数缩放**：如 §2.2(i)，`λ̇` 缩 `1/c`、LSI 精确不变 ⇒ **`g` 的尺度是规范方向，不是自由数据**。
- **场依赖共形** `g → e^{2σ(φ)}g`：`Hess` 会多出 `dσ ⊗ dσ` 与 `∇dσ` 项 ⇒ **不是共形不变的**，场依赖共形确实是自由度。但它必须同时满足 `(3.93)`（`Z_t dm_{g_t}` 反向热方程），`g_t` 一旦依赖 `φ` 就无法通过 `K_t` 卷积实现 ⇒ **本路只能取 `φ`-独立的 `g`**。本轮把这一点当硬约束。
- 结论：`(★)` 对 `g` 的依赖**不是**"只有 `Ċ = t g^{−1}` 的比值进入"，因此**没有当场死**；但也买不到尺度自由度。

### §3.2 T0(b)：负方向与 `Ric` 高曲率方向正交——**成立，且更强**

任务书设想的死法是"正交"。本轮实测是更强的两件事：

**(1) `Ric` 上界 = 双不变量值（§2.4）。** 给定 `G`，`Ric_G ⪯` 有一个 `G`-独立的障碍：`λ_min(δ^{−1}Ric_G) ⩽ N/4`，取等在 `G ∝ δ`。

**(2) 最坏负部是各向同性的。** 用 P-E（'t Hooft）的**常数 `Z₂` 2-cocycle**：
```
偶环面上取   U₁(x) = (−1)^{x₂+x₃+x₄} ,    U_μ(x) = 1  (μ = 2,3,4)
⇒ 每个 (1,μ)-plaquette = −1（μ = 2,3,4 全部），每个 (μ,ν)-plaquette = +1
⇒ 方向-1 的每条 link 恰落在 6 个取值为 −1 的 plaquette 里
```
（逐 plaquette 手验 + `mc_lattice.py` 实测 `S_W = 240` at `L=2`、`3840` at `L=4`，与"48/768 个 `−1` plaquette × `2β`"吻合。）

在该构型上 `dφ = 0`（中心元 ⇒ `Re tr(λ_c·(±1)) = 0`），所以 `Hess` = 图卡二阶导，且**与 `G` 完全无关**；而所有 6 个 plaquette 给出同号的 `+δ/2` ⇒
```
Hess S_W = −(3β/N)·δ   （每条方向-1 的 link，各向同性）
```
于是 `(★)_{t=0}` 要求 `½Ric_G ≻ (3β/N)δ`，即 `λ_min(δ^{−1}Ric_G) > 6β/N`；由 (1)，这只在 `6β/N < N/4` 即 `β < N²/24` 时可能。

**(3) 但真正的最坏方向跨 link。** 单-link 的估计**不是**全空间 `λ_min(Hess S_W)` 的界（本轮勘误 E1）：实测 `SU(2)`、`β = 2.5`、`L = 2` 与 `L = 4` 均给出
```
λ_min(Hess S_W) = −10.000 = −8β/N        （均匀铺在方向-1 links 上的模式）
μ(δ) = λ_min(Hess S_W + ½Ric) = −9.750
```
比"每条 link 独立 `−(3β/N)`" 差 `8/3 = 2.67` 倍。**且 `L=2` 与 `L=4` 数值完全相同 ⇒ 该负水平是 `L`-无关的**（每个方向上的强度，不是体积效应）。

### §3.3 T0(c)：最优 `G` 需要知道 `m₁` ⇒ 循环——**不成立**

`t=0` 时 `Hess V_0 = Hess S_W`，只含 `(β,N,L)`。`mc_lattice.py` 的形状搜索没有引用任何谱数据。**无循环。** 代价见 §5/§6：`t=0` 的结论只能"证伪"。
