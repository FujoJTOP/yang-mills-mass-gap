## 1. 代码与可观测量

`research/v3/w7/p11_volt.py`（由 `research/unconditional/w7/o24_lat.py` 推广到任意 `L`；同一平直图卡密度、同一 `v`）：

```
V(x) = β Σ_P (1 − ½ReTr U_P) + Σ_l Φ(r_l),   Φ = −2log|sin(r/2)/(r/2)|,  |x_l| < 2π
U_l = exp(i x_l·σ/2),  E[κ]=⟨d_v²V⟩,  F=d_v V,  Δ_dyn = E[κ] − Var(F) = G″(0)
v_l = ẑ/√N_L  （k=0 均匀 z-模，‖v‖=1，与 o24 mode A / o25 同模同归一化）
```

- 约束面 `{⟨v,X⟩ = Σ_l x_{l,z} = 0}` 用 **pair-transfer** 严格保持：`x_l += w`, `x_{l'} -= w`（`w ∈ R³`）。
  只动两条链，`ΔS` 只需 12 个 plaquette；`L=3`（`N_L=324`, `N_P=486`）因此不爆内存。
- 基本域：逐链硬约束 `|x_l| < 2π`（拒绝率 `domrej = 5.0e-3`，两 `L` 相同），初值投影到 `Σ_l x_{l,z}=0`。
- 有限差分 `h = 1e-3`，`κ = (V₊−2V₀+V₋)/h²`，`F = (V₊−V₋)/2h`；`β = 2.5`，`SU(2)`，`eps = 0.9`，`acc ≈ 0.42`。

**约定核对（必须做，否则全错）**：`U = exp(i x·σ/2)` 的 quaternion 乘法是 **anti-Hamilton**
`(q₀p₀−q·p, q₀p+p₀q−q×p)`，`Tr` 走 `U†`。首版 `trace4` 的 dagger 向量部符号写错，与
`o11_physical.tr_plaq` 差 `max|Δtr| = 0.86`（`dV = −2.7`）——**发现后立即停掉在跑作业、修正、重跑**。
修正后：

```
L=2  max|Δtr| = 2.22e-16   dV = 0.0e+00
L=3  max|Δtr| = 2.22e-16   dV = −5.7e-14        （对 o11_physical.Vtot，单组态逐项比对）
```

另修 `o24` 的一处小失真：当 `l, l'` 同属一个 plaquette 时 `o24` 把该 plaquette 的 `ΔS` 计了两次
（≈2–4% 提议），此处已去重（`np.sort` + 相邻去重掩码）。

## 2. `o25` 的 `L=3` 负值：基本域 bug，已定死

`o25_l3.py:92-95` 用**整体平移**投影：

```python
c = d[2]/nlink ;  x[l] += d ;  x[:, 2] -= c          # 移动了全部 nlink 条链
dS = beta*Σ_{rows(near[l])}(tr_old−tr_new) + φ(r_l)_new − φ(r_l)_old   # 只算 1 条链、6 个 plaquette
```

`Σ_l x_{l,z}=0` 确实保住了，但**该平移改变了所有链的 `r_l`（即所有 Jacobian 因子）与所有 plaquette 的迹**，
而 `ΔS` 只记了被选链的 6 个 plaquette 和 1 个 `Φ` ⇒ 接受率只对应一个**错误的 Boltzmann 权重**；
拒绝分支的还原（`x[l]=xl−d; x[:,2]+=c`）也不还原他链的 `tr/ph` 缓存。这是一个**权重错误的基本域实现**，
不是物理效应。

决定性旁证：`o25` 在 **`L=2`** 上也给出负值（`Δ = −0.2692, −0.3153`），而 `L=2` 的
正确值由 `o24`（pair-transfer）为 **`+0.3942 ± 0.0258`**（`Δ·L² = +1.577 ± 0.103`，即任务背景里的 6σ 数）。
同一 bug 在 `L=2` 就把符号翻掉了 ⇒ `o25` 的 `L=3` 负值**不可采信**。
用修正代码重算 `L=3`：**`Δ_dyn = +0.3713 ± 0.1005`，为正**。`[E]`

交叉核对：本 `L=2` 结果 `E[κ]=1.910`、`Var(F)=1.597`、`Δ=0.314`，与 `o24` 的
`1.924 / 1.536 / 0.394` 在 `1.0 σ_jk`（`Δ`）内一致；统计量仅 1200 sweep/链（`o24` 为 15000），
**`L=2` 的最佳锚点仍是 `o24`：`Δ = +0.3942 ± 0.0258`，`L²Δ = +1.577 ± 0.103`**。

## 4. 判死线落点

**(a) 命中**：两点 `Δ_dyn` 皆正、`k = 0.41 ± 0.98`（`σ_jk`）与 0 相容 ⇒
**`Δ_dyn` 与体积无关 ⇒ `(L,a)` 一致性有支撑**。
这是 H1 最后一个结构性问题的**正面闭合**：`G″(0)>0` 不是小体积假象，`L=2` 与 `L=3` 同号同量级
（0.31 vs 0.37，比值 1.18，误差内平坦），且 `E[κ]`、`Var(G_v)` 各自也都不随体积增长。

**(b) 未触发**：`k` 的中心值 `0.41` 略大于 0 但 `1σ` 内不为正；且 `Var(F)` 在 `L=3` 反而**小 3.8%**
（1.597 → 1.537），不存在"`Var` 跟着长"的迹象。若未来统计变好仍给出 `k>0`，它是 `Δ_dyn` 缓增，
不是 `Var` 驱动的。

**(c) 未触发**：`L=3` 在修正代码下为正，无需启用"符号依赖体积"分支。

### 诚实边界（不许读过头）

1. `σ_k ≈ 1`（`σ_jk`）/`≈2.6`（`σ_τ`）/`≈8.5`（链间散布 `σ_grp`）。**`k` 只被压到"与 0 相容、且 ≲2.4"**，
   不是"`k=0` 已测准"。要真测 `k` 需每链 ~10⁴ sweep（`L=3` 78.7 ms/sweep × 4 链 ≈ 13 min/10³ sweep）。
2. `L=2` 的 `σ_grp = 0.93` 远大于 `σ_jk = 0.091`（逐链 0.139…0.613 散布）⇒ `Δ_dyn` 的链间重尾仍在，
   `σ_jk` 是乐观误差；`(a)` 的 `k≈0` 结论在 `σ_grp` 下退化为"强正、量级平坦"的定性结论。
3. 只有两个体积点，`k` 是两点幂律（未做三点拟合、未做 `a` 相关项）；`Δ_dyn` 是否含 `O(1/L)` 修正在此分辨率下不可辨。
4. `κ`/`F` 为 `h=1e-3` 有限差分，`κ` 的三阶差分截断误差未单独估（`o24` 同尺度，`E[κ]` 与 `o24` 一致到 0.7%，可接受）。
