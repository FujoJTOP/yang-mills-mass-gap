# P7 — KP 的 `c_r·dim r ≤ β^{|r|}/|r|!·e^β`：在 `β = 2.5` 上是真阻塞吗？

**靶**：`P3-FULLREP-KP.md` 行 29 / 31 / 49 / 76 / 85 / 90 / 96 / 121 的 KP 通道。
**算**：`w7/p7_kp_bound.py`（mpmath dps=30）→ `w7/p7_kp_bound.log`。SU(2)，`N=2`，`|r| = 1..8`，`β ∈ {0.018394, 0.1, 1, 2.5}`。
**本轮判**：**(c) 两面都给** —— 作为"抑制高阶表示"的逐项界，KP 在 `2.5` 上**毫无约束力**（且它从来不是截断判据）；作为**收敛判据** `λ_aΦ(a)<1` / `uK<1`，它在 `2.5` 上**直接失效**（差 `2.9×10⁴` 倍）。失效的原因是 `β`（活性 `u=c_f≈β/2`），**不是 `|r|`**。

---

## §0 先把读法钉死：`e^β` 在分子，不在分母

任务里的字面串 `β^{|r|}/(|r|!e^β)`（`e^β` 在分母）与文件行 49 的式子**不是同一个东西**：

- 文件行 49 用的是 `Σ_{m≥n}β^m/m! ≤ (β^n/n!)·e^{+β}` ⇒ 界是 `β^n/n!·e^{+β}`，随 `β` **增**。
- 字面读法（`e^{-β}`）**在 `|r|=0` 就被证伪** `[E]`：`|r|=0` 的项是 `c_0·dim r_0 = c_0 = I_0-I_2`，`β=2.5` 时 `c_0 = 2.01337`，而 `e^{-β} = 0.082085`；`β=0.018394` 时 `c_0 ≈ 1.00004 > e^{-β} = 0.98177`。即 **每个 `β>0` 都失败**，与表示无关。
- ⇒ 唯一自洽读法：`c_r·dim r ≤ (β^n/n!)·e^β`，`n=|r|`。下文一律用这个；字面读法作为 `[1B]` 留档在 log 里。

## §2 精确的 `c_r·dim r`（`[E]`，自检 `|闭式−投影积分| < 1e-18`）

`N=2` 时 `e^{(β/2N)(trU+trU†)} = e^{β cos θ}`，SU(2) 的字符系数有闭式：

`c_n(β) = I_n(β) − I_{n+2}(β)`，`dim r_n = n+1`，`|r| = n`（fundamental `n=1`, `dim 2`），
与直投影 `c_n = ∫dU e^{βRe trU}χ_n*`（Haar `= (2/π)sin²θ dθ`）逐点一致。

`β = 2.5` 时 `c_r·dim r` = **4.085, 3.416, 1.766, 0.657, 0.190, 0.0450, 8.99e-3, 1.55e-3**（`|r|=1..8`）。

`[E]` **小 `β` 展开**：`c_1 = β/2 + O(β³)`（数值 `β=0.018394`: `c_1/(β/2)−1 = 2.8e-5`）。
⇒ 文件行 56 / §4.3 的"精确 `c_f ≈ β/(2N)`"在 `N=2` 上是 **`β/2`，差一个因子 2**（正确式是 `c_f = β/N`，因为 `trU+trU†` 是 `2χ_f`）。这只把 `uK` 放大 2 倍，不改结构；下文 `u := c_1`，用真值。

**`|r| = 1..8` 全部满足**，松弛从 7.5× 涨到 297×。**不是"只剩 `|r| ≤ 2`"。**

饱和比 `c_r dim r / 右端`（1=紧, 0=废）：`β=0.018394` 时 `|r|=1` 达 **0.982**（界几乎被填满），`β=2.5` 时只有 **0.134**，`|r|=8` 只有 **0.0034**。⇒ 这个界在 `2.5` 上接近**空话**。

**真正被压的是什么**（`a=1` 的 KP 活性 `Φ(1) = Σ_{r≠0}c_rdim·e^{|r|}`，log §4）：

| β | `Φ(1)` | 主导 `\|r\|` | `frac(\|r\|≤2)` | `frac(\|r\|≤4)` |
|---|---|---|---|---|
| 0.018394 | 0.05095 | 1 | **0.9998** | 1.000 |
| 0.1 | 0.3015 | 1 | 0.9942 | 1.000 |
| 1 | 8.721 | 1 | 0.6765 | 0.963 |

⇒ `β=2.5` 上表示内容**摊到 `|r| ≲ 8`**：`|r|≤2` 只占 21%，峰在 `|r|=4`。高阶表示**并没有被抑制**——压住它们的是真实系数的阶乘衰减 `c_n ~ (β/2)^n/n!`（`Φ` 对每个 `a` 都收敛，`a=1,2,4` 峰位 4/10/69，比 `t_{399}` 已 <1），**不是 KP 的界**。KP 的界只是这同一条事实的粗包络，它**从不截断** `|r|`。

## §5 判（死线）

- **(a) 不成立（按字面）**：`2.5` 上并不"只剩 `|r| ≤ 2`"——`|r|=1..8` 全过，松弛 7.5×→297×。但这**不**说明"KP 照常工作"：它工作得**太松**，是空界。
- **(b) 不成立（按字面）**：失效的不是"`|r|` 大也行"（`|r|` 大当然也行，且从来不靠 KP 允许），而是 `uK<1` 在 `2.5` 上差 `2.9×10⁴`——**判据本身不成立，故 KP 在 `2.5` 上不证任何东西**。
- **(c) 给两面** `[T]`（算术 `[E]`，逻辑 `[T]`）：
  1. **表示侧不是阻塞**：`c_r·dim r ≤ β^ne^β/n!` 对每个 `β`、每个 `|r|` 成立（`2.5` 上尤其松），它**是逐项优级数，不是截断判据**；"`β` 小 ⇒ 只留小 `|r|`"把 `β`-依赖的符号读反了。五环里"抑制高阶表示"这一环**不需要新的表示侧论证**。
  2. **判据侧是阻塞**：把它当 KP 假设用（`λ_aΦ<1` / `uK<1`），`β=2.5` 处差四个数量级。阻塞量是**活性 `u = c_f ≈ β/2`** 与聚合物熵 `λ_a = O(Δ)`，即**高温展开的收敛半径 / 到 `β≈2.5` 的搬运**（文件行 129 自列的 `[R]` 项），**不是** `δ>0`，也**不是** `(L1)`。

**一句话**：KP 的 `c_rdim r` 不等式在 `2.5` 上不是阻塞——它松到 7–300 倍且从不选表示；阻塞是 `u(β)K<1` 这个**半径条件**在 `2.5` 上差 `3×10⁴`，即"强耦合展开走不到 `2.5`"，与表示、与 `dim r` 无关。
