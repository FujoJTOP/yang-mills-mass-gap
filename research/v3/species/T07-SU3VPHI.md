## 1. `Φ′` 的显式与 `v`-依赖的定位 `[T]`

设 `X ∈ su(3)`（Hermitian、无迹），`λ` 升序，`P_a = |u_a⟩⟨u_a|`，`⟨A,B⟩=tr(AB)`：

```
Φ(X)  = Σ_{a<b} g(|λ_a−λ_b|),      g(d) = −2 log[ sin(d/2)/(d/2) ]
∇Φ(X) = Σ_{a<b} ω(λ_a−λ_b)(P_a − P_b),   ω(s) = g'(|s|) sgn(s)
Φ′(X;v) = ⟨∇Φ(X), v⟩ = Σ_a c_a (U†vU)_aa,   c_a = Σ_{b≠a} ω(λ_a−λ_b)
```

**任务里的写法 `Φ′ = Σ g′(d_p)(λᵢ−λⱼ)` 把 `v` 藏掉了**：
- `g′(d_p)` 只依赖 `X` 的谱；
- `(λᵢ−λⱼ)` 也只是 `X` 的谱差；
- `v` 的唯一入口是投影子矩阵元 `⟨P_a−P_b, v⟩`。对角 `X` 上 `Φ′ = Σ_a c_a v_aa`（`v` 只经对角元）；一般 `X` 上经 `(U†vU)` 的对角元。

`[E]` 差分核对：`max|⟨∇Φ(X),v⟩ − d/dt Φ(X+tv)|_{t=0}| = 3.9e−9`（N=500）。

**推论**：`Φ′(X;·)` 对 `v` 是**线性泛函** ⇒ 一切 `v`-依赖只能是二次型 `vᵀΣv`。这直接决定 §3 的 `inf/sup` 无差别。

## 2. `Φ` 径向到 4 次 —— `Var(Φ′)` 为什么可能很小 `[T]`+`[E]`

`su(3)`（无迹 3×3）的共轭不变量环由 `p₂=tr X²`、`p₃=tr X³` 生成。Newton 恒等式给出（`λ` 为 `X` 的本征值）：

```
p₄ = p₂²/2 ,   p₅ = (5/6) p₂ p₃                                  [E] max|残差|=1.4e−14 / 3.6e−15
Σ_{a<b}(λ_a−λ_b)² = 3 p₂
Σ_{a<b}(λ_a−λ_b)⁴ = 3p₄ + 3p₂² = (9/2) p₂²      ← 纯径向
Σ_{a<b}(λ_a−λ_b)⁶ = (33/4) p₂³ − 9 p₃²          ← 首个非径向         [E] max|残差|=7.7e−12
g(d) = d²/12 + d⁴/1440 + d⁶/90720 + O(d⁸)       (log(sin x/x): −x²/6−x⁴/180−x⁶/2835, x=d/2)
⇒ Φ = p₂/4 + p₂²/480 + (33/362880)p₂³ − (9/90720) p₃² + O(deg 8)
```

所以

```
∇Φ(X) = (径向标量)·X + O(|X|⁵),      非径向首项 = 2·(−9/90720)·p₃·∇p₃   （5 次）
```

`[C]` 数值：`|Φ − [p₂/4+p₂²/480+(33/362880)p₂³−(9/90720)p₃²]|/Φ ≤ 4.2e−2`（`|X|∼1.7`，与 `O(deg 8)` 截断相符）。

**这就是 `SU(2)` 与 `SU(3)` 的区别的准确形状**：`SU(2)` 是「`Φ` 严格径向」⇒ `∇Φ ∥ X` ⇒ 切片 `⟨X,v⟩=0` 上 `Φ′≡0`；`SU(3)` 是「`Φ` 径向到 4 次」⇒ 切片上 `Φ′` **不是 0，而是 `O(|X|⁵)`**，且系数只有 `9.92e−5`。

另外 `[E]`：`tr(X³v) = tr(Xv)·p₂/2`（无迹 3×3 恒等式，`max|残差|=3.6e−15`）⇒ 3 次探针在 `H_v` 上**恒**为 0，`r11[C-ii]` 那个「`a=0` 而 `Φ′≠0`」的反例只能来自 5 次及以上的项。

## 3. `v` 的选择：先澄清两件不同的事

项目里 `v` 出现在**两个互不相容**的位置，混用会得到相反的判：

- **V1（`su(3)` 内的方向）**：`v` 是切片法向，`a = ⟨X,v⟩`。此时 `v` 的等价类由 `v` 的本征三元组决定；`su(3)` rank 2 ⇒ **2 参数族**（"在 8 维里选一个方向"只对了一半：8 维是空间，`v` 的**类**是 2 维的）。
- **V2（环面模型里的 `λ`）**：`r12` 的 `λ=(1,0,−1)` 是**基本表示的权**，由模型给定，**不是自由参数**。那里没有 `v` 可调，只有「配对」可调。

下面的 `[T]`/`[C]` 全部是 **V1**（8 维 log-chart，`e^{−Φ}dX` = 纯 Haar）。

### 3.1 `E[Φ′]=0` 精确 `[T]`

`Φ(−X)=Φ(X)` ⇒ `∇Φ(−X)=−∇Φ(X)`；`e^{−Φ}dX` 与 `X→−X` 不变 ⇒ 任意固定 `v`，`E[Φ′]=0`。切片 `⟨X,v⟩=0` 是 `−`-对称集 ⇒ `E[Φ′|a=0]=0`。故 `Var(Φ′)=E[Φ′²]`。

`[C]` MC（N=3e5，ESS=1.65e5）：`E[Φ′]=+4.0e−4 / +9.3e−4 / +1.0e−3`（MC 误差 `1e−3`）对 `v=M₈/M₃/M₃+0.6M₈`。

### 3.2 全域：`Σ = κ·Id`，`v` 的方向无关 `[T]`

`e^{−Φ}dX` 共轭不变、`∇Φ` 等变、`su(3)` 伴随表示不可约 ⇒ `Σ := E[∇Φ⊗∇Φ] = κ·Id` ⇒

```
Var(Φ′(·;v)) = κ|v|²,    inf_v = sup_v = κ|v|²
```

`[C]`：`κ = tr Σ/8 = 0.238933`，`E|∇Φ|² = 8κ = 1.911465`，`max|diag−κ|/κ = 0.37%`，`max|offdiag|/κ = 4e−3`（MC 噪声级）。

**所以「`Var` 要不要对 `v` 取 inf 还是 sup」在非切片版本里是伪问题：两者相等。**

### 3.3 切片版本（`D` 真正用的那个）：恒正，但只差 15% `[C]`

`D = Var(G+Φ′)` 是在 `a=0` 切片上算的（`r11[B]`：`SU(2)` 的 `Var(Φ′)=0`、`D=β²Var(g)`）。这里用**精确条件抽样**（把 `v` 取作 ONB 首元，令其系数 `x₁=0`），扫遍 `v` 的整个共轭类（`θ∈[0°,60°]`，`|v|=1`）：

| `θ` | 0° | 15° | 30° | 45° | 60° |
|---|---|---|---|---|---|
| `Var(Φ′|a=0)` | 2.22e−5 | 2.28e−5 | **2.03e−5** | **2.34e−5** | 2.19e−5 |

```
min_v Var(Φ′|a=0) = 2.033e−5     max_v = 2.344e−5     max/min = 1.15
所有 v: Var>0 ?  True            max|E[Φ′|a=0]| = 3.5e−6  (应 0)
```

`O(|X|⁵)` 标度检验：固定 `X₀∈H_v`，`Φ′(tX₀)/t³` 从 `−1.25e−4` 变到 `−2.50e−3`（×20），而 `Φ′(tX₀)/t⁵` 只从 `−1.39e−3` 到 `−2.50e−3`（×1.8）⇒ 首个非零阶 `≥5`，与 `p₃²` 的 5 次梯度一致。

**窗口声明**（`AGENTS §2.1`）：上述 `2e−5` 是 `|X| = O(1)`（纯 Haar 典型区，`σ=1` 提案、`e^{−Φ}` 权重）的结果。`Var(Φ′|a=0)` 随 `|X|¹⁰` 增长，因此**在大场 / `d_ab→2π` 的 cut-locus 区不能直接引用这个数**——该区 `g′→+∞`，非径向项不再是 1e−4 量级。

## 4. `6.81` 的溯源：复现不出，且不可用作 `D` 的界 `[NG]`

`6.81` 的唯一出处是 `research/v3/w7/r12_su3_correct.log` 的 `[C]` 段（`N=2048`，权重 `|Δ|²e^{−S_W}`，`θ=π`，`β=2.5`）：

```
E[Φ′] = +2.4922    E[Φ′²] = +13.0218    Var(Φ′) = +6.8107    E[G] = −4.19e−17
⇒ Var = 13.0218 − 6.2109 = 6.8109                                            [E] 算术自洽
⇒ 6.81 里 6.21 是【均值平方】；同一 log 的 [D] 纯 Haar 分支 Var_T(Phi_B')=6.6154，D0=6.6765，S0−D0=−0.2358
```

三点否决：

1. **均值不为 0 与所述权重的偶性矛盾。** `|Δ|² = Π4sin²(d_p/2)` 在 `(a,b)→(−a,−b)` 下偶；`θ=π` 时 `cos(π±x) = −cos x` 也偶 ⇒ `|Δ|²e^{−S_W}` 偶。而 `Σ_p l_p(−cot(d_p/2))`（`l_p=λ_i−λ_j`）**奇**。偶×奇 ⇒ 均值必须为 0。
   `[C]` 我在**同网格同形式**上重算（`N=512`，`d_{12}=a, d_{23}=b, d_{13}=a+b`）：
   ```
   d13=a+b     纯Haar |Δ|²     E[Φ′]=−0.000000   Var=+8.000000
   d13=a+b     |Δ|²e^{−S_W}    E[Φ′]=−0.000000   Var=+8.465778
   ```
   `Var=8.000000` 正是 `r12[B]` 的**精确锚**（`E[Φ_A″]=E[Φ_A′²]=8`，`S=D`）。
2. **`6.81` 违反 IBP 恒等式**（`s04` S6 已判）：`Var ≤ M + g(g+√(g²+4M))/2 − (EΦ′)² = 1.2343`，实测 `6.8107`，残差 `6.3177` ⇒ `(Φ_O09, |Δ|²)` 不是 IBP 相容对。
3. **`Φ_O09` 不是环面上的函数**：`g(d)=−2log[sin(d/2)/(d/2)]` 含 `log(d/2)`，非周期；把它放进 `(0,2π)²` 环面积分，`d₁₃=a+b∈(0,4π)` 已越过一个周期。正确配对是 `Φ_Δ = −log|Δ|²`（周期、`E[Φ′]=0`、`Var=E[Φ″]=8`、`S=D`）。

**判**：`6.81` 不是任何 `v` 方向、任何 IBP 相容测度下的 `Var(Φ′)`；它不能作为 `SU(3)` 的 `D` 的界，**也不能作为 `D` 的主要成分**。因此 `R12-SU3CORR.md §4(b)-1` 那句「`SU(3)` 的 `Var(Φ′)=6.81`（`Var(G)` 的 89 倍）⇒ `D` 被 `Var(Φ′)` 主宰」**必须撤回**：在 8 维 log-chart 的 `a=0` 切片上，`Var(Φ′|a=0) = 2.0e−5`，是 `Var(G)=0.0767` 的 **2.7e−4 倍**（`[C]`，本文 §3.3）。

## 5. 判死线逐条

**(a) 「存在 `v` 使 `Var(Φ′)=0`，故 `SU(2)` 的 `[T]` 可沿那条 `v` 搬到 `SU(3)`」——逐字判：**
> 不存在这样的 `v`（`min_v = 2.033e−5 > 0`，§3.3）。**但 `(a)` 的结论不需要这个前提成立**：`SU(2)` 的 `[T]` 之所以成立，不是因为 `v` 选得好，而是因为 `∇Φ ∥ X`；`SU(3)` 上 `∇Φ = (径向)X + O(|X|⁵)`，切片把径向部分**恒等地**杀掉，剩下的正是 5 次项。于是
> ```
> Var(Φ′|a=0)^{SU(3)} = 2.0e−5 = 2.7e−4 · Var(G)      （|X|=O(1) 窗口）
> ```
> `SU(3)` 的严格证书**可做，但不再是精确等式，而是带 2.7e−4 相对泄漏的 `[T]`+`[C]` 混合步**：`D^{SU(3)} = Var(G) + 2Cov(G,Φ′) + 2.0e−5`，其中 `Var(G)` 项与 `SU(2)` 同阶同型。`Cov(G,Φ′)` 在纯 Haar 分支上需单独核（`r12[D]` 报 `E[GΦ′]=−0.0000000`）。
> **不得**写成「`SU(3)` 的 `Var(Φ′)=0`」；正确写法是「`SU(3)` 的 `Var(Φ′|a=0) ≤ 2.34e−5`，`O(|X|⁵)`，非精确 0」。

**(b) 「若 `Var(Φ′)>0` 对所有 `v` ⇒ `SU(3)` 的 `D` 必然比 `SU(2)` 大 ⇒ `gap` 更难，给最小值」——成立，最小值：**
```
min_v Var(Φ′|a=0) = 2.033e−5   (θ=30°, |v|=1, 8 维 log-chart, a=0 精确条件抽样)
```
但**「`D` 必然比 `SU(2)` 大」这句要限定窗口**：`+2.03e−5` 对 `Var(G)=0.0767` 是 `2.6e−4` ⇒ `D` 的**量级不变**，说「`D` 被 `Var(Φ′)` 主宰」是错的（§4）。若指 `|X|` 大的区（`|X|⁵` 标度生效），则 `Var(Φ′)` 可以反超 `Var(G)`——**这是唯一需要设防的方向**，也是 `r12` 那类大场数值真正对应的地方。

**(c) 「`Var(Φ′)` 依赖 `v` 且需 `sup_v` ⇒ 给最坏方向」——依赖很弱，`sup` 与 `inf` 只差 15%：**
```
sup_v Var(Φ′|a=0) = 2.344e−5  (θ=45°)
```
逻辑上 `D` 以**减号**进 `gap`，证书必须对最坏方向成立 ⇒ 用 `sup_v`。但这里用 `sup` 几乎不付代价（比 `inf` 贵 `15%`），且**非切片版本 inf=sup=κ|v|²=0.2389**（Schur，§3.2）——所以「`inf` 还是 `sup`」这个二选一在本问题里**不构成实质差别**，真正决定 `D` 的是 §2 的径向阶，不是 `v`。
