## §1 那个两行

### 1.1 记号（与 `HZ6:D1` 对齐）
`δ_a trF² := a^{-4}q`，`q:=1−N^{-1}Re tr U_□`，`|q|≤2`；`O:=δ_a trF²` ⇒ `‖O‖∞=2a^{-4}`；`⨏_B:=N_B^{-1}Σ_{x∈B}`，`N_B=(b̂/a)^4`；`C(z):=⟨O_x;O_{x+z}⟩_c`；`n_B(z):=#{x∈B: x+z∈B}≤N_B`。

### 1.2 两行
```
行1   Z_a = N_B^{-2} Σ_{x,y∈B} C(x−y) = N_B^{-2} Σ_z n_B(z) C(z) ≤ N_B^{-1} Σ_{z}|C(z)|
      Σ_z|C(z)| ≤ ‖O‖²∞·[#{|z|<2r} + A e^{2mr} S(m)] =: ‖O‖²∞·Θ(1)      ← (7.27)（§2）
行2   ⇒ Z_a ≤ 4a^{-8}·(a/b̂)^4·Θ(1) = [4Θ(1)b̂^{-4}]·a^{-4}                ∎
```
`S(m):=Σ_{z∈ℤ⁴}e^{−m|z|}<∞` 是纯数；幂=`a^{-8}·a^{+4}=a^{-4}`；常数全部显式、与 `a` 无关。

### 1.3 为什么"on-site `a^{-8}` ÷ 块体积"本身不是证明
- **裸版第一步就塌**：`Var(⨏_B O) ≤ ‖O‖²∞`，**与 `N_B` 无关** ⇒ 只有 `4a^{-8}`。把 `a^{-8}` 除以 `N_B` 等于假设各块位移**独立**——那是一条未被给的输入，不是算术。
- **真的来源**：`N_B^{-1}` 来自计数 `n_B(z)≤N_B`（双重和 → 单重和），而"单重和也是 `O(‖O‖²∞)`"由 `(7.27)` 提供。两件事缺一，幂就停在 `a^{-8}`。这就是本格的全部内容，也正是 `T4-CARRIER:48–54` 只写"on-site `a^{-8}`、求和 `a^{-4}`"时**跳过去**的那一步。

### 1.4 目标是它自己的残余
`HZ6:D1`：`Z_a(k)=a_k^{-4}b̂^{-4}ϖ(k)`（`ϖ:=a_k^{4}b̂^{4}Z_a`，无量纲，**定义**）。故
`Z_a ≤ Ca^{-4} ⟺ ϖ ≤ Cb̂^4`。⇒ 任何"从外部"给出上界的两行都不存在；§1.2 之所以成立，是因为它**调用了** `(7.27)`，即 `(V)`。

## §2 BKAR / 树图（`hz8` 的 (7.29)(7.30) 同款）

### 2.1 用的是哪几条（`fax` 直读）

### 2.2 它给 `Z_a` 的上界（本题第 2 问的答案）
`d_k` = **`Λ_k` 上的图距离**（`fax:22727`）；`α` 是聚合物衰减率、`diam(X)` 以块计 ⇒ `m` 是**每格一步**的率、`m a_k=O(1)`、不依 `k`。于是 `Σ_{z∈Λ_0}e^{−m|z|/a}=S(m)=Θ(1)`（**不是** `a^{-4}`），代入 §1.2：

**`Z_a ≤ 4A e^{2mr}S(m)b̂^{-4}·a^{-4}`。** 判：**树图/BKAR 给的上界恰好是 `a^{-4}`**（常数纯数、不依 `a`），这就是靶。

### 2.3 唯一的单位陷阱，与它给不了什么
- **陷阱**：若把 `m` 读成"每单位物理长度"的率（`m∼M` 不依 `a`），同一式子给 `Σ_z e^{−m|z|}=Θ(a^{-4})`，上界退成 `a^{-8}`。原文是图距离 + 块计直径，故取前者；此点与 `HZ8:§1` 第 1 条（"`(7.19)` 的 `α` 不是格距"）同型，必须写在式旁。
- **给不了下界**：绝对值型不等式只上界 `|C|`，`ϖ≥c₀` 无路（同型：`HW5:0.6`、`T4-CARRIER:§0.5`）。
- **给不了窗口**：(7.19) 的供给 = Thm 7.4，逐字 `0<β<β₀(N)`；塔底 `β≈2.5` 每壳活度边际、无小参量（`GU4:59`），`(V)` 在此未付。
