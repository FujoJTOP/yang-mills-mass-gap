## 2. 必做 1：`P4` 上 `Var` 与 `E[H]` 恒为 0 —— 理由（此段是 `[T]`，非数值）

**理由不是"周期平移不变性"，是更强的一条：全局左乘是 `S_W` 的精确对称，且 `v` 就是它的生成元。**

周期链 `X_1,…,X_L`，`X_{L+1}=X_1`，plaquette `= U_ℓ^†U_{ℓ+1}` 是**纯差**。取任意固定 `Ω∈SU(2)` 作 `U_ℓ→ΩU_ℓ`，则

```
U_ℓ^† U_{ℓ+1}  →  U_ℓ^†Ω^†ΩU_{ℓ+1} = U_ℓ^† U_{ℓ+1}     逐点、逐 β、逐 L、逐 N、逐中心扇区
⇒ S_W(Ω·U) = S_W(U)     在**整条轨道**上相等（不只是临界）
⇒ G = ⟨v,∇S_W⟩ ≡ 0      与 H = ⟨v,Hess S_W v⟩ ≡ 0      （常数模 = 该对称的生成元）
```

在 Cartan 约化语言里是同一条：`S_W=βΣ(1−cos((z_{i+1}−z_i)/2))` 只依赖**差**，故 `Σ_i ∂_i S_W ≡ 0`（`G=0`）、`Hess S_W` 是**循环图 Laplacian、行和为零**（`⟨v,Hess v⟩=0`）。**Haar 测度在左乘下不变** ⇒ 沿该方向的边缘仍是纯 Haar，曲率全部来自 Jacobian 的 Haar 块。这与论文自己的定性陈述一致：`ch15-uvface.tex:199–201`「every plaquette is a pure difference, so the uniform shift is an exact flat direction of `S_W`」。

**数值核验（机器零，非近似）**：`β = 0, 0.5, 2.5, 6, 20, 100, 10⁴` × `L = 2,4,8`：

| `β` | `L` | `max\|G\|` | `\|H_vv\|` | `max\|行和 Hess\|` | `max\|S_W(z+c)−S_W(z)\|` |
|---|---|---|---|---|---|
| 2.5 | 8 | 4.4e−16 | 2.4e−17 | 1.1e−16 | 1.1e−14 |
| 100 | 8 | 1.8e−14 | 7.2e−16 | 3.6e−15 | 4.6e−13 |
| 10⁴ | 8 | 1.8e−12 | 6.4e−14 | 4.6e−13 | 4.4e−11 |

⇒ **`Var(β) ≡ 0`，`E[H](β) ≡ 0`**（必做 2 的前提"若 `Var≠0`"不触发）。故

```
δ_max(β) = G″(0) − 0 = W_full = W_geo + 0 ,   X = −2Cov(G,Φ′) = 0  （G≡0）
```

**"恒正"的严格链**：`δ = G″ = W_geo` `[T 恒等式]`，`W_geo ≥ (N/12)/L > 0` `[T, ch05:224]` ⇒ **`δ>0` 对一切 `(β,L)`** `[T]`。数值只用来钉住**值**（`0.2052…0.2616`），符号不需要数值。**这是本次唯一一条不靠测量的结论。**

**对照单 plaquette 为什么会有零点**：`θ=π` 时 `S=β(1+sin(r/2)u)`，`u=ξ₃/ρ`；条件化切片 `ξ₃=0` 上 `dS/dξ₃=β sin(r/2)/r ≠ 0` ⇒ `v` **不是**平坦方向 ⇒ `Var = β²V₀`（`V₀=0.0110593`）能长到压过 `W_geo=0.2051153` ⇒ `β*=4.30661`。**`β²` 项的存在性 = "条件化点是不是 `v` 方向的临界点/对称点"。** 周期核上 `v` 是精确对称生成元 ⇒ `β²` 项**结构性缺席** ⇒ 不存在能压过 Haar 锚的机制。这不是"`β*` 更大"，是**没有这个通道**。

## 4. 必做 4：`0.22196` 与 `W₀ ∝ N` 是否一致？那 8% 是什么？

**结论：不一致，而且 8% 与 `N` 无关 —— 两个数都是 `N=2` 的同一个对象。**

`0.22196`（`ch15:207` 的 `c+Aq^L` 拟合影，`q=0.849`）与 `0.2051153`（`ch15:190`）**都是 `SU(2)`**。任何"`W₀∝N`"型的 `N`-律在固定 `N=2` 下给出比值恒等于 `1`，给不出 `1.082`。⇒ **`1.082` 不可能由 `N`-依赖解释**。

同时，`betastar-scaling` 自己的 `N`-扫描（`betastar_scaling.log:5`、`betastar_n3.log`、`betastar_n34.log`）也**不支持** `W₀∝N`：

| `N` | `W_geo(β=0)` | `W/N` | `W/(N/2)` | `N/12` 地板 |
|---|---|---|---|---|
| 2 | 0.2051 | 0.1026 | 0.2051 | 0.1667 |
| 3 | 0.3453 | 0.1151 | 0.2302 | 0.2500 |
| 4 | 0.4908 | 0.1227 | 0.2454 | 0.3333 |

`W(3)/W(2)=1.683`（∝N 预测 1.5）、`W(4)/W(2)=2.393`（预测 2.0）：**比线性更陡**，`W/N` 单调上升 `0.103→0.115→0.123`。所以 `W₀∝N` 是一条**近似/未证**的 `[M]` 口号，不是这批数据支持的律（且 `W/(N/12)` 也从 1.23 升到 1.47，说明连 `N/12` 标度也不精确）。

**那 8% 是什么（本报告用 `β`-扫描直接测出来，不是猜）**：

```
0.22196/0.2051153 = 1.08213  (+8.21%)
```

`β`-扫描给出三个极限，`0.22196` 是夹在中间的那个：

```
β→∞（锚）   0.2051153  = 1/(2Cin(2π))
β=2.5（物理）0.22196    = 中间值
β→0（CLT）  0.268830   = 1/Var(ξ₃)          ← L-重卷积 / 高斯极限
```

⇒ **`1.082 = 1 + 0.2644 × (0.268830/0.2051153 − 1)`**：

| 成分 | 数值 | 相对锚 |
|---|---|---|
| Haar 锚（`β→∞`，锁死） | 0.2051153 | — |
| `β=0` 的零模卷积展宽（CLT） | +0.0637147 | **+31.1%** |
| Wilson 刚性在 `β=2.5` 已淬掉的份额 | −0.0468700 | −73.6% of 展宽 |
| 残留（`= 0.22196`） | +0.0168447 | **+8.2%** |

即：**8% = 零模卷积展宽 `1/Var − 1/(2Cin2π)`（+31.1%）在 `β=2.5` 时尚未被 Wilson 刚性淬掉的那 26.4%。** 它是 `L=∞` 边上相干长度 `ξ=1.55`（`ch15:211`，`Δ=0.6444`）导致的**残余软化**，一个纯 `(β, L)`/模式效应；把 `β` 推到 `200` 它归零（残留 0.04%），把 `β` 推到 `0` 它涨到 31%。**与 `N` 无关。**

## 5. 窗口/适用范围核验（`AGENTS.md §2.1`，三条限定，都不改符号裁决）

1. **`Var≡0` 只对"常数/全局平移模"成立，不是对一切粗模。** `v` 必须是全局左乘的生成元。`H1` 量化的是**所有**粗模 `v`；`P4` 核按构造只检验 `k=0` 常数模。故本报告证明的是：**"周期核的常数模"这一格上不存在 `β*`**，不是"一切周期模都不存在 `β*`"。`ch15:234–237` 的 4D 保留条款（`c=0` 仍可能）与本条不冲突。
2. **`H1C-WFULL.md:73–74` 的"`G″=W_geo` 精确"只在约化链意义上成立。** 独立核对：`H1C` 的 `P4` 在 `β=0` 给 `W_geo=0.35865`（其 `Var(Φ′)=0.03715`），而精确 `G″(0,L=4)=0.25425`，差 **41%**；`β=2.5` 时 `0.20766` vs `0.21146`，差 1.8%；`β=5.7` 时 `0.20670` vs `0.20779`，差 0.5%。⇒ 用**三维全 Jacobian** 的 `W_geo` 与 `k=0` 边缘曲率只在横向方向被冻结（大 `β`）时重合；`H1C` 该行的数值当 `β=0` 读会偏大 41%。**本报告一律用 `G″(0)` 本身（可独立复现的核），不借 `W_geo` 的分解值。**
3. **地板要按 `1/L` 归一。** `ch05:224` 明写 `L` 链平均给 `‖v‖²=1/L`，即 `c=(N/12)/L`。所以 `L=8` 的地板是 `0.0208`（不是 `1/6`），实测 `G″=0.2052` 高出 10 倍；反之若错用 `1/6` 会得到"β=200 时 0.2052 vs 0.1667 仍成立"的**巧合式**过关 —— 记为已排除的陷阱。
