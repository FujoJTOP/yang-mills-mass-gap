## §2 "no bulk transition" 的精确含义（题 1）

**定义 `[T]`**：`f := −(1/V)log Z`（等价 `p=−(1/a)log λ₀`）在 `[β_eff,2.5]` 上**实解析** —— **"无体相变"就是"`p` 的解析性"**。
出处：`DF-CONTINUITY.md:30` 逐字：「字面形 `= [CP-a]`：`f = −(1/V)log Z` 在区间上实解析（无体相变）」；`PROOF-THERMODYNAMIC-FORMALISM.md:7`：「A phase transition = non-analyticity of `p` — a statement about `λ₀` only … **Analytic pressure = no bulk transition, strictly weaker than exponential clustering**」。

**它等价于什么、不等价于什么（逐条）`[T]`：**

| 命题 | 判 | 依据 |
|---|---|---|
| `Z_Λ(β)>0` 对所有**实** `β`（⇒ 实轴无 Fisher 零点） | **是，且平凡**（正被积函数）⇒ "无零"在实轴上**免费、零信息** | `CONTINUUM-CP.md:5` |
| `[CP-a]` ⇔ `Z_Λ` 在 `[β_eff,2.5]` 无零点（Vitali/Ruelle） | **是**（配 `p_Λ→p` 紧一致）——**指复 `β` 无零** | `PROOF-THERMODYNAMIC-FORMALISM:5` |
| 该无零域被 Pringsheim 钉在 `β<1/48` | **是**（复 `β` 团簇半径极大） | `PROOF-FISHER-ZERO-FREE:9`、`PROOF-THERMODYNAMIC-FORMALISM:3` |
| `[CP-a]` ⇒ 指数聚类/有隙 | **✘** | 自由场：`Z` 无零、`p` 解析、`Δ=0`、`f₁²=0`（酸测，`:9`） |
| `[CP-a]` ⇒ `f₁²>0` | **✘** | 同上；`λ₁` 无体压强，是 Fredholm 行列式 `det(1−zT_O)` 的共振，不是 bulk `log Z`（`:7`） |
| `[CP-b]`（一致隔离）⇒ `[CP-a]` | **✔ `[T]`** | `CONTINUUM-CP.md:1/5`：一致隙 ⇒ 指数聚类 ⇒ DLR 唯一 ⇒ 无共存；有界关联长度 ⇒ 禁临界点 ⇒ Fisher 零点不夹实轴 |

## §4 关键：`(CP)` 的"无体相变"**不等价于**"两标量无零"（题 3）

**判：不等价 —— 单向蕴含，`[T]` 双向都判死。**
- `[CP-b] ⇒ [CP-a]` `[T]`（见 §2 表末行）。**⇒ "两标量一致正地板" 强于 "无体相变"。**
- `[CP-a] ⇏ [CP-b]` `[T]`（`CONTINUUM-CP.md:1`：「`[CP-a]` is downstream of the gap, not a relaxation of it」；`U02-CP.md:84`）。**⇒ 单相可无能隙，也可让原子连续溶解。**
- **题面 (b) 的方向要反过来**：不是"无体相变比无零更强"，而是**严格更弱**，因为在 `(CP)` 的逐字量词里 "no bulk transition" **根本不是第三个合取项**，它是 `(i)∧(ii)` 的**推论**（`U02-CP.md:72` 逐字：「**不是**关于 `f=−(1/V)log Z` 的解析性（那是 `[CP-a]`，是**推论**）」）。
- **推论（本路记账）**：把 "no bulk transition" 当独立第三项去证，**只会削弱 `(CP)`**：证成 `[CP-a]` 对 `(CP)` 的贡献是 **0**（它被 `[CP-b]` 蕴含）。搬运问题**不需要**它单独可证。

## §5 判 (a)：化归成立，但"解析 + 端点"是 `[NG]`（题 4）

### 5.1 化归 `[T]`
```
(CP)  ⇔  ∃r₀,κ>0 : ∀β∈[β_eff,2.5] : f₁²(β) ≥ r₀  ∧  Λ(β)−m₁² ≥ κ
      ⇔  f₁² 与 Λ−m₁² 在 [β_eff,2.5] 上连续且无零        （闭区间紧致性，min>0）
      ⊋  [CP-a]（无体相变）                                  （§4：单向蕴含）
```
**⇒ 判 (a) 的形式部分成立 `[T]`：搬运问题确实**化成了**"两个标量在闭区间上无零"，且这是**唯一**有路径的形式（§3）。**

### 5.2 但路径 `[NG]`：β 方向没有正性承载
`MS-ANALYTIC-NOZERO.md` 已把这条路径**逐件判死**（`[NG]`，对具名仪器类）：

| 仪器 | 失效方式 | 出处 |
|---|---|---|
| Kato 解析性 | 给**离散**，不给**缺席**：非负实解析、`β<1/48` 上正，仍可在内部触零（`(β−1.5)²` 两端正、中间零）；**一个正端点不是无零** | `:3`, `:6` |
| 最小模原理 | 需 `a` **已**无零（循环） | `:19` |
| 最大模原理 | 只上界 | `:19` |
| Rouché | 需**无零比较函数**（=目标）+ 控制 `a` 离轴（=隔离） | `:19` |
| 单调性 | 无 `β`-单调且 atom-coercive 的泛函：atom-coercive ⇒ Schur-凸，`β`-单调对象（自由能/`a`-charge/`F_T`）是全量/逐态 ⇒ Schur-凹/离边，**两侧相反** | `:19`（`PROOF-TRANSPORT-MONOTONE`） |
| Perron 正性 | 锚在**真空**；`a(β)=⟨G(β)|O|Ω⟩` 是**激发态**重叠，⊥ Perron，**号不定** ⇒ `a(β)` 在 `β` 上**无符号保护** | `:21` |
| 迹反常 / Ward | 盲：极点的 Ward 在 `f₁²` 上**齐次（自行抵消）** | `:21`（`G2B`） |

**结构理由 `[T]`**：Herglotz/Stieltjes/passivity 正性住在**能量**（`λ=e^{−aE}`），**不在 `β`**；`β` 向只有 Perron，而它只管真空（`:21`）。**⇒ 这就是"解析 + 端点"为什么不是路径：端点信息 + 解析性对触及型零点（K2）结构性无力，而 K2 恰是 `(CP)` 的失效模式。**

### 5.3 化归不降难度 `[T]`
- `I2` 在 grading `Λ≈(1.5m₁)²` 下 `Λ−m₁²≈1.25m₁²` ⇒ **(ii) 一致 ⟺ `m₁≥μ>0` 一致**（`U02-CP.md:75`、`OTHER-F1SQ-TRANSPORT:14`）⇒ `(CP) ⟹ H1`，且 `I2` **严格高于 `m_g`**（`CONTINUUM-CP.md:11`）。
- 另有 `I1⟺I2` given moments（`GAP-G2-edge`）⇒ 两个"标量无零"不是两条独立路，是**同一级**的两个坐标。
- **⇒ "两个标量无零"不是比 gap 更容易的对象，是 gap 加半级。** 所以 (a) 的"有路径"只能读作**形式可攻**，不能读作**难度下降**。

### 5.4 唯一剩下的非循环路径 `[O]`
避开 §5.2 全部五件仪器的路，只有一条：**在 `β` 方向造一个"符号承载"**（守恒律 / 指标 / 反常类**恒等式**，把 `a(β)` 的符号钉在一个与 `β` 无关的量上），而不是**不等式**。语料现存三个候选全盲或方向反：

- 迹反常 ⇒ 在 `f₁²` 上齐次抵消（`MS-ANALYTIC-NOZERO:21`）`[T]`；
- 拓扑指标 `n(A)` ⇒ 只给 `<n>=0` 与 `⟨n²⟩=χ_t` ⇒ `m_{0⁻⁺}²≤χ_t/f₁²`，**上界、错通道**（`INVENT-NEW-INDEX:8`）`[T]`；
- 单调泛函 ⇒ Schur 反向（§5.2）`[NG]`。

**⇒ 本路交付的精确缺失步 `[O]`：一个 `β`-方向的符号承载（不是界），把 `a(β_a)=0` 从"codim-1 的偶然"排除。此物不存在于语料；它就是第 6 物种要造的东西。** 短期可攻面仍是单点 **`(CP)@2.5`**（`U02-CP.md:119`、`COV-T.md:233`）：`f₁²(2.5)≥r₀>0 ∧ Λ(2.5)−m₁(2.5)²≥κ>0`，**不需要**跨 `β` 一致。

## §6 判 (c)：`β_eff` 未定义 ⇒ 逐字尚未良定

1. **只有上界，没有下界** `[T]`：语料逐字写 `β_eff<1/48`（`INVENT-TRANSPORT-INEQ:17`），但量词要的是 `∀β∈[β_eff,2.5]: f₁²≥r₀>0`，而 P3 的地板 `r₀(β)=½c₁u^p`、`u=β/2N²`（`PROOF-P3-UNCONDITIONAL:22/31`）**随 `β→0` 而 `→0`**。⇒ **`β_eff>0` 必须固定，语料从未钉**；`β_eff` 越小 `(CP)` 越强，所以 `(CP)` 的**强度**目前是 `β_eff` 的函数，不是一个命题。
2. **区间两端混两套 `β` `[T]`**：`PROOF-FISHER-ZERO-FREE:9` 逐字：「The bracket mixes SZZ `β` with Wilson `β_W`; honest distance ≈13× in `λ`, ≈10²× in activity」⇒ `[β_eff,2.5]` **不是单一坐标轴上的区间**，逐字读它需要一个换算（未给）。
3. **一符号两义 `[T]`**：`(CP)` 在本仓承载两个不同命题 —— 义 A（谱/隔离，本文全用）与义 B（`d5/(CP)=p=1`，速率一致化）；`RATE-UNIFORM:182` 自认「与两者的轴都不同」（`U02-CP.md:49–59`）。**⇒ 引 `(CP)` 时必须标义，否则 `[β_eff,2.5]` 指向两个不同对象。**
4. **结论**：**`(CP)` 的逐字（区间版）不可直接当靶**；良定的可攻形式只有 `(CP)@2.5`（单点）或"对每个固定 `β_eff>0` 的族"。**⇒ 判 (c) 成立。**

## §8 对搬运问题（`β≈1/300` → 物理区）的直答

- **"从 `β≈1/300` 到 `2.5` 的搬运"** 逐字就是 `(CP)` 的 `∀β∈[β_eff,2.5]`，但它**不是**"`Z` 无零"问题，也**不是**"无体相变"问题 —— 后者只是它的**推论**，证成了也不搬运任何东西（自由场见证：`Z` 无零、`f₁²=0`）。
- **真正的搬运对象是两个标量的地板**：`f₁²`（残数，`I1`）与 `Λ−m₁²`（隔离，`I2`）。`Z_O²` 乘性搬运搬的是**值**，`(CP)` 说的是**同一个原子被搬过去**（`Ω=1`）——后者未被 `Z_O` 触及（`W95D-TRANSPORT:121`）`[T] given (CP)`。
- **⇒ 结论**：`(CP)` **可以**化成一个可攻的等价形式（`[T]`，§5.1），**这是唯一有路径的形式**；但该形式的证明**不是**"解析 + 端点"，而是"`β` 方向的符号承载"，**此物不存在** ⇒ 精确缺失步是 `[O]`，不是技术细节。
