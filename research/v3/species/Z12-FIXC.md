## 1 · `Ĉ` 的精确值

### 1.1 局部因子 = 2，且是**每因子化点**一个

链 `ℓ` 上（`P3:28` `Fact 0.1`）：`M(ℓ)=dim Hom(1,⊗_{p∋ℓ}r_p^{±1})`。`B_T` 侧在每条 `ℓ` 上恰给 `f,f̄`（横截面链在 `j=0,T` 处由源/汇 plaquette `p₀` 补足第 2 个），故 `f⊗f̄ = 1 ⊕ adj`，`M_B(ℓ)=1`。装饰侧给 `A_ℓ`（`κ_ℓ` 个 plaquette），于是

```
M_{B_T∪γ}(ℓ) = mult(1 ∈ (1⊕adj)⊗A_ℓ) = mult(1∈A_ℓ) + mult(adj∈A_ℓ)          (1.1)
naive        = M_B(ℓ)·M_γ(ℓ)         = 1·mult(1∈A_ℓ)
⟹  R(ℓ) := M_{B∪γ}/(M_B M_γ) = 1 + mult(adj∈A_ℓ)/mult(1∈A_ℓ)                 (1.2)
```

**精确值（SU(2) Weyl 闭式，40 位；`z12` §1）**：

| `κ_ℓ` | `A_ℓ` | `mult(1∈A)` | `mult(adj∈A)` | `R(ℓ)` |
|---|---|---|---|---|
| 2 | `f⊗f` | **1** | **1** | **2** ← 单回耦合对 |
| 4 | `f^4` | **2** | **3** | **5/2** |
| 1 | `f` / `adj` | `0` | `0` / `1` | `0/0`（见 §1.3） |

并核对 `Hom(1,f f f f)=2`（`C_2=2`）、`Hom(1,f)=0`、`mult(1∈f^{2m}) = Catalan(m)`（`1,1,2,5,14,42,132` 逐位相符）⇒ **`Z08 (2.1)` 的 `R=2` 复现，且它是「一个因子化点」的值**。

**所以「是 2 还是 `2^{划分数}`」的答案：两者都不是同一个量。**
`Ĉ = 2^{ν(γ)}`，`ν` = **真正带成对回耦合的共享链数**（每个因子化点贡献一个精确的 `2`），而 `ν` 随 `|γ|` 增长 ⇒ 必须换成**逐 plaquette** 常数才能进 KP：

```
Ĉ := sup_γ ( ∏_{ℓ}R(ℓ) )^{1/|γ|} .                                             (1.3)
```

### 1.2 逐 plaquette 上界：`Ĉ = 4`（可证）；Z08 的 `16` 是高估

`z12` §2 的**穷举**（4D 环面 `L=4,T=6`，直四壁管 `|B_T|=4T=24`，`|links(B_T)|=52`，全部 `6·L³T` 个 plaquette 逐一核）：

```
每个非 B_T plaquette 与 links(B_T) 的共享链数直方图 = {0: 4389, 1: 188, 4: 6}
其中 6 个「4 条共享链」的 plaquette 恰是 p₀ 的时间平移（各时间片一片），κ=1 每条链
backbone 侧每链的 plaquette 数直方图 = {1: 8, 2: 44}（1 的是 j=0,T 的横截面链，源/汇补足）
```

由此三条硬事实：**(i)** `κ_ℓ ≤ 4`（一链至多 6 个 plaquette，2 个属 `B_T`）；**(ii)** 只有 `κ_ℓ ≥ 2` 才产生因子（`κ_ℓ=1 ⟹ mult(1∈A)=0`，两边同为零或落进 §1.3 的 0-vs-非零类）；**(iii)** `Σ_ℓ κ_ℓ ≤ 4|γ|`（每 plaquette 至多 4 条链）。于是

```
∏_ℓ R(ℓ) ≤ ∏_ℓ 2^{κ_ℓ/2} = 2^{Σκ_ℓ/2} ≤ 2^{2|γ|} = 4^{|γ|}
（用到的逐点不等式 R(κ) ≤ 2^{κ/2}：2 ≤ 2¹ ✔，5/2 ≤ 2² ✔）                ⟹  Ĉ = 4 .   (1.4)  [T]
```

- `Ĉ = 4` **可证**，且**不必**用「每 plaquette ≤1 条共享链」（那条**假**：`p₀` 的时间平移有 4 条，`z12` §2 已证伪）。
- **Z08 的 `16 = ρ⁴`** 把「每链一个 `ρ=2`」乘到「每 plaquette 4 条链」，两层都按最大算 ⇒ 高估 `4×`。真正的最坏情形是 `κ_ℓ=2`（`R=2`）而非 `κ_ℓ=4`（`R=5/2`）。
- 典型/简单装饰（单回耦合对、`κ=2`）取到 `R=2`，故 `Ĉ` 的**精确局部值**是 `2`，`Ĉ` 的**逐片包络**是 `[2,4]`；KP 要的是后者 ⇒ 报 `4`。

### 1.3 定性失败：真实的类，但要换见证

`(1.1)` 的 `mult(1∈A)` 为零而 `mult(adj∈A)` 非零时，`w(γ)=0` 而 `w(B_T∪γ)≠0`。`z12` §1 的 cap test：

| `A_ℓ` | `w(γ)` | `w(B_T∪γ)` | 判 |
|---|---|---|---|
| `f`（`Z08` 的见证） | `0` | **`0`** | **见证无效**（`f f̄ f` 无单态） |
| `adj` | `0` | **`1`** | **定性失败成立** |
| `adj⊗j₂` | `0` | **`1`** | 同上 |

⇒ `P3:47` 的 `W(𝔇)=∏w(γ)` **丢类**这一条 `[T]` 保留；`Z08 §2.2` 的算术（`dim Hom(f,f)=1`）错，`f⊗f̄⊗f` 的真实重数是 `0`。**该项不产生新常数**：`mult(adj∈A) ≤ dim A = ∏dim r_p`，而 `∏dim` 已被 `P3:65` 的 `C_g`（「`dim(r) ≤ poly_N(|r|)`、`≤2(d−1)=6` 面共链」）吸收。故 §1.2 的 `Ĉ=4` 是**唯一新增的常数**。

## 3 · 新 `δ`

`z07:84` 给 `δ = ln(1/ū)/a`，其中 `ū` 是 `X01 §2.3` 里 `|A(α)| ≤ ū^{α+1}/(1−ū)` 的**活动度**。活动度换成 `Ĉū` 后同一式给出

```
δ_fix = ln(1/(Ĉ·ū))/a = κ/4 − ln(Ĉ·eΔ·C̄)/a ,     δ_fix/κ = ¼(1 − ln(Ĉ eΔ C̄)/ln(1/u)) .   (3.1)  [T]
```

**题给的 `δ = ln(Ĉ)/a + ln(1/(Ĉū))/a` 是恒等拆分**：

```
ln(Ĉ)/a + ln(1/(Ĉū))/a ≡ ln(1/ū)/a = 旧 δ        （z12 §4 数值核对：逐位相同）   (3.2)  [T]
```

即它是「旧 `δ` 换一种写法」，**不是**补洞后的值；补洞后的 `δ` **减掉** `ln Ĉ/a`，不是加上。等价的干净恒等式（`z12 §4` 精确核对到 `1e−12`）：

```
δ_fix(β) = δ_old(Ĉ·β)        ⟺   β ↦ Ĉβ 这一个替换就够（u ∝ β）              (3.3)  [T]
```

**数值（`C̄=1`，`u=β/8`，`eΔ=54.3656365692`）**：

- **`β=1/12` 的旧点**：`1/ū = 1.76865` ⇒ 只要 `Ĉ < 1.76865` 就活着。`Ĉ=2`、`4` 都越界 ⇒ `Z08:160` 的「`δ·a` 转负」在 `Ĉ≥2` 下成立；但**`Z08` 的前提「`Ĉ ≥ 2` 是最小可能值」是错的**（每因子化点是 2，逐片包络取 `4` 而非 `2`——`2` 与 `4` 都 `>1.76865`，故这一支结论不变）。
