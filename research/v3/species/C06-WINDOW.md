## 1 · KP 判据到底要什么

`P3-DRESSED-MASS.md:64` 逐字：

```
Σ_{γ∋x, γ connected} |w(γ)| e^{α|γ|} ≤ α          (2.1)
```

这是**对 `γ` 的求和**。要证它，标准手法是给**每个 `γ` 一个率** `|w(γ)| ≤ (Ku)^{|γ|}`（再乘动物数 `(eΔ)^{|γ|}`），于是判据归约成 `K·eΔ·u·e^{α} ≤ α`。所以：

- **判据的「自变量」是 `γ`**（每个聚合物一个数），**不是** plaquette 的乘积；「逐 plaquette 包络」`∏_{p∈γ}4` 从来不是判据的形式，它只是把 `sup_γ` 算出来的**一种**办法。
- 修法 (NC) 把 `w ↦ w·∏_ℓR(ℓ)`，于是判据里的率被乘上 `(∏_ℓR(ℓ))^{1/|γ|}`，**必须对 `γ` 取 sup**：

```
Ĉ_KP := sup_{γ} ( ∏_{ℓ} R(ℓ) )^{1/|γ|} ,     判据 = Ĉ_KP·eΔ·C̄·u < 1      (1.1)  [T]
```

`(1.1)` 就是 `Z12-FIXC:53` 的 (1.3)。**结论：KP 只要「逐 `γ` 一个数」，不需要逐 plaquette 包络** —— 用户的第 1 问答案是「只逐 `γ`」。**但**这个数是多少，必须老实算（§2），而它**不是** 2。

## 2 · `sup_γ` 的值是 4，而且取到（这是本轮的关键）

### 2.1 非零权 ⇒ 每个 link 上 `κ` 必为偶 ⇒ `∂γ=∅`　`[T]`

`w(γ)=∏_ℓmult(1∈A_ℓ)`（`Z12 (1.1)`）。SU(2)：`mult(1∈f^{κ})=0` 对 `κ` 奇（40 位 Weyl 复核，`c06_window.log §1`：`n=1,3,5,7` 全为 `<1e−46`）。故

```
w(γ)≠0  ⟹  ∂γ = ∅（无 κ=1 的边界 link）⟹ E₁ = E₃ = E₅ = 0
```

这条**不止是洞 C 的事，是聚合物系统本身的事实**：单 plaquette 的权为零、只有**闭曲面**才是有效聚合物。`[T]`（标准；本文件只用 `mult(1∈f^κ)=0`（`κ` 奇）这一条 + 40 位复核）

### 2.2 手数恒等式把 `E₂/F` 钉在 `≤2`，且闭簇取等　`[T]`+`[E]`

每片 4 条 link ⇒ `Σ_ℓκ_ℓ=4F`，即

```
4F = E₁ + 2E₂ + 4E₄ + 6E₆ ,     ∂γ=∅ ⇒ E₂ = 2F − 2E₄ − 3E₆ ≤ 2F        (2.1)  [T]
```

`log §2`：`(2,2,2,2)` 盒中 20000 个随机子复形，恒等式**违例 0**；`max E₂/F = 1.7778 < 2`。取等要全闭全 `κ=2`：

```
4D 立方体 6 面（(2,2,2,1) 盒的全部 6 片）：F=6，κ 直方图 {2:12}
  E₂/F = 12/6 = 2.000000 ，∏R = 2¹² = 4096 ，几何均值 4096^{1/6} = 4.000000        (2.2)  [E]
```

### 2.3 于是 `Ĉ_KP = 4`（不是 2，也不是「包络取大」）　`[T]`

```
∏_ℓR(ℓ) = 2^{E₂}·(5/2)^{E₄} ≤ 2^{E₂} ≤ 2^{2F} = 4^{F}   （用 E₄≥0 ⇒ E₂≤2F，且 2.5≤4）
```

- `R(2)=2`（精确）、`R(4)=5/2`、`R(6)=2.8`（`log §1`；`mult(adj∈f^n)=1,3,9`、`mult(1∈f^n)=Catalan`，全表符）。
- `Z12 (1.4)` 的 `4` 用的是 `R(κ)≤2^{κ/2}` 与 `Σκ≤4|γ|`；**本文件给出更硬的版本**：`4` 不是松包络，而是 `sup_γ` 的**取值**（`(2.2)` 见证）。

**⇒ 「精确 2」进不了 KP：`2` 是每因子化点（每 `κ=2` link）的值，而因子化点密度 `E₂/F=2`（闭簇手数），乘起来正是 `2²=4`。用户第 2 问的前提（"只需逐 `γ` ⇒ `Ĉ` 就该是 2"）不成立。**

## 5 · 判死线 (c)：第三路 —— 合并常数，可证界 `39.62`

### 5.1 定义（形式上是干净的：判据只剩一个数）

```
K̂ := sup_γ ( ∏_ℓ R(ℓ) · τ_γ )^{1/|γ|} ,     KP ⟺  K̂·eΔ·u < 1 ,   1/48 ⟺ K̂ < 7.0632853    (5.1)  [T]
```

`τ_γ` = 簇邻接图的生成树数（`A01 §2.1` 的 `|φ^U(Γ)|≤τ(G_Γ)∏|w_p|`）。这一步**合法**：`Ĉ_KP` 与 `C̄` 都是「每 plaquette 一笔」，合并后仍是「每 plaquette 一笔」，只是**两个 sup 不再分开取**。

### 5.2 可证界：`K̂ ≤ 39.62`（不是 80，但也不是 16）

按 link 型混合（`a_κ:=n_κ/F`，约束 `Σa_κκ=4`）优化 `(∏R)^{1/F}·(2E_graph/F)`，`E_graph=Σ_ℓC(κ_ℓ,2)`（Kirchhoff+AM-GM：`τ^{1/F}≤(2E/(F−1))^{(F−1)/F}F^{-1/F}→2E/F`）：

| 混合 `(a₂,a₄,a₆)` | `(∏R)^{1/F}` | 平均邻接度 | `G` |
|---|---|---|---|
| `(2,0,0)` 全 `κ=2`（闭曲面） | `4.000` | `4.0` | **16.0** |
| `(0,1,0)` 全 `κ=4` | `2.500` | `12.0` | **30.0** |
| `(0,0,2/3)` 全 `κ=6` | `1.987` | `20.0` | **39.73** |
| 最优 `(0.05,0,0.65)` | `1.99…` | `19.6` | **39.62418** |

⇒ **`K̂ ≤ 39.62418`**（`log §4`）。对比：`4×20=80`（`Z12/A01`）、`2×20=40`（用户的 (a) 退路）。

**要点（为什么合并几乎没用）**：`Ĉ_γ` 与 `τ_γ` 均由**同一个** `E₂/F`（= 平均邻接度）驱动，**同向**增长，两个 sup 是「一起变大」而不是「此消彼长」⇒ 分开取 sup 的乘积 `4×20=80` 里只有一层是虚的（`Ĉ` 要用平均度 4 的那一层），合并只回收 `80→39.6`，即 `2.02×`，**比 `2×20=40` 只紧 `0.9%`**。用户猜的「比 `4×20` 松、比 `2×20` 紧」（在 `(20,80)` 内）**数值上成立且几乎贴着 `40`**。

### 5.3 更硬的结论：这类打包里 `7.0633` **不可达**

显式见证（`(2.2)`）：4D 立方体 6 面

```
(∏R·τ)^{1/6} = (4096·384)^{1/6} = 10.7840492368   >  7.0632853        (5.2)  [T]+[E]
（τ(K_{2,2,2})=384 由 Kirchhoff 精确算得；八面体邻接图，与已知值相符）
```

即 `K̂ ≥ 10.784`（下界，见证）+ `K̂ ≤ 39.624`（上界，Kirchhoff）。**任何「均匀逐 `γ` 率」的打包（不管 `Ĉ` 与 `C̄` 怎么重分、怎么合并）都不可能给出 `K̂<7.0633`** —— 因为 `sup_γ` 已经被这个显式聚合物顶到 `10.78` 以上。该类能达到的最好窗口：

```
K̂=10.784 ⇒ β₁ = 8/(10.784·54.3656) = 1.3645×10⁻² = 0.6550×(1/48)
K̂=39.62  ⇒ β₁ = 3.7137×10⁻³   = 0.1783×(1/48)
K̂=16 (全 κ=2 闭簇) ⇒ β₁ = 9.1970×10⁻³ = 0.4415×(1/48)
```

### 5.4 `(c)` 判词

**形式可行，收益为零，且在本打包类内是可证的死路。** 合并常数 `K̂` 的可证界 = **`39.62418`**（≫ `7.0633`），最好情形（`τ` 用真值、`Ĉ` 只用闭曲面那 `4`）也只到 `10.78`（仍 `>7.0633`）。

> **诚实边界 `[C]`**：`(5.2)` 的 `10.78` 是**界**（`τ·∏R`）的产物，**不是**真 `φ^U` —— 立方体簇的真 Ursell 系数是 `u⁶` 阶的一个小整数型求和，远小于 `384u⁶`。所以要逃出 `7.0633`，唯一的活路是**换掉 `τ`**（算真 `φ^U` 而不上树界），或改用**不均匀（position-dependent）KP 活动度**（装饰只贴骨架 `B_T`，`P3 §1.4` 的 backbone 机制），本层两条都未做 ⇒ 只能报「类内不可达」。
