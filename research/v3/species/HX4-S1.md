## §2 三条路

**(a) 由 `M₀` 上界 + `χ` 下界合成 —— `[NG]`。** `S1 ⟺ χ ≥ cM₀/s₁`，右侧带 `1/s₁`，故 `χ` 的**非平凡**下界只有两条：① `χ ≥ f₁²/s₁`（夹逼左半，`[T]`）⇒ `factor ≥ w₁` ⇒ 要 `factor ≥ c` 就需 `w₁ ≥ c`，**循环**；② `χ ≥ M₀/M₁ = 1/Ē`（Jensen）⇒ `factor ≥ s₁/Ē` ⇒ 需 `s₁ ≥ cĒ`，这是**严格强于 S1** 的陈述，且类层假：UV-尾测度 `0.6δ₁+0.2δ₂+0.2δ_{10⁴}` 上 `factor=0.70002`、`s₁/Ē=1/2001`（差 `1400.74` 倍，机检 **[3]**）。`M₀ ≤ 2N²` 只压分母、不产比值；夹逼右半 `χ ≤ M₀/s₁` 给的是 `factor ≤ 1`（反方向）。**⇒ 合成路线每一条要么回到靶、要么经 `Ē` 而触 UV。** 下一手：把 `Ē` 从候选输入栏**注销**（`QI-BRACKET:89–90` 已把它点为 UV 量）。

**(b) Schur 侧 —— `[NG]`。** `χ` 是 Schur-凸（`HZ5:168–174`），S1 要它的**下**界 ⇒ 坐在"向上集中"那一侧，**侧面对**；但任何 Schur 型下界只是 `(M₀,M₁,…)` 的函数，而 `HZ5-B` 纤维上 `(M₀,χ)≡(1,1)`、`factor=s₁=ε` 取遍 `(0,2)` ⇒ 矩型下界对 `factor` **零分辨率**（`HZ5:134–141`，`[T]`）。且该族正是 `HQ4` 判死的那一族：有界成员 ⟺ 靶、无界成员严格强于靶、**无一条严格弱于靶**（`HQ4:0.5`；`SCHUR-CONVEX:19` 转引"不是新杠杆"）。**⇒ (b) 两步内退化成 (a)：Schur 序不含位置。** 下一手：位置输入只从谱侧取（边本征矢 / Feshbach，`A06:72`），不再从序侧造下界。

**(c) 造反例族判假 —— `[NG]`（否证器用尽）。** 类层：薄原子 `λ=1` 上 `factor=ε→0`，对每个 `c>0` 为假（`HZ5-B`）；但同族 `w₁=ε/2→0` 也假 ⇒ **不分离**。靶内：靶 ⇒ S1（§3.1）⇒ **任何 S1 的反例必是靶的反例** ⇒ 靶内不可反。**⇒ (c) 的产出是定位：S1 不是测度代数定理，必须吃 `β≥β_A` 的 YM 结构。** 下一手：把 S1 登记为靶的**否证器**（S1 假 ⇒ 靶假），不作定理候选。

## §3 ★ 相对靶的强度

**(3.1) 靶 ⇒ S1(w₀)** `[T]` 一行：`factor = s₁χ/M₀ ≥ f₁²/M₀ = w₁ ≥ w₀`（夹逼左半，`H06:25`）。故 S1 是靶的**必要条件**；`w₀` 可作 `c`。

**(3.2) S1(c) ⇏ 靶，∀c<1** `[T]`：两原子 `ν=wδ₁+(1−w)δ_{1+δ}` 给 `factor=w+(1−w)/(1+δ)`、`w₁=w`。取 `δ ≤ (1−c)/c`、`w<w₀` 即得；机检 **[1]** 的 `(1/2000,1/1000)` 实例：`factor=0.999001 ≥ 9/10` 而 `w₁=5.000e−4`。

**(3.3) `c=1` 是另一端** `[T]`：`factor=1 ⟺ 单原子 ⟺ w₁=1` ⇒ **严格强于靶**（YM 上非真）。故 `c` 没有任何取值使 S1 ⟺ 靶。

**(3.4) ★ 结构判（本路最重要的一行）**：S1 与靶是**同一条 Lean 夹逼的两端**。记 `L:=f₁²/χ`、`U:=M₀/χ`（`H06:25` 两端都 `[T]`）：靶 `⟺ L ≥ w₀U`；S1 `⟺ s₁ ≥ cU`；括号比 `U/L = 1/w₁`，位置比 `s₁/L = 1/w₁^χ`。**夹逼不含"`s₁` 在括号内何处"**：薄原子位置贴下端（`factor=w₁`），均匀密度 `[1,1+η]` 位置上端（`factor=log(1+η)/η→1`）而 `w₁=0`（括号比 `∞`）⇒ 位置是**独立坐标**。

**(3.5) 判**：**严格弱**，全局不 ⟺（3.2）；仅在 `HZ5-B` 纤维上 `factor=2w₁` ⇒ 纤维上等价（常数 2）。`HW5:53` 的"它就是靶的薄原子腿"须在此意义上读：**纤维上同强、全局只半边**。

**(3.6) 台阶判定**：**不能作台阶**。由乘积恒等式 `w₁=w₁^χ·factor`（`HS-GAP-6:52–53`），`靶 ⇐ S1(c) ∧ S1′(w₀/c)`（`S1′: w₁^χ ≥ w₀/c`）是**充分组合**；反向只给 `(c,c′)=(w₀,w₀)`、乘积 `w₀²` ⇒ 不是等价分解。**单独证 S1 不推靶**；本路的正面产出 = 新格 S1 + 值域（0.4）+ 可测性（0.7）。
