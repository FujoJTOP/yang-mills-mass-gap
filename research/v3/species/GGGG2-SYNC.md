## §1 `σ` 的定义与取值（逐字）

1. `fax:15042`：「A smooth horizon projector at covariant momentum scale σ > 0 is now defined.」
   `fax:15043`：「The function χσ : [0,∞) → (0,1] is fixed once and for all」；`15045`：「χσ (λ) = exp(−λ/σ²)」。
2. `fax:21373`（式 4.12）：「χσ (λ) ≥ 1 − εσ (λ ≤ σ²), χσ (λ) ≤ εσ (λ ≥ 4σ²)」；`21375`：「decay χσ (λ) ≤ C exp(−c λ/σ²)」
   ⇒ `σ²` 与 Laplacian 谱 `λ`（= 协变动量²）比，故 `σ` 是**动量量纲**的谱截断尺度。`fax:22159`（6.7）：
   「supp(dνσ ) ⊂ [c− σ^{-2} , c+ σ^{-2} ]」——热时 `t ≍ σ^{-2}`，核的定位长度 `≍ σ^{-1}`（`fax:22327` 逐字）。
3. **不是 UV 格距倒数**：`fax:6546`：「ultraviolet lattice artefacts at the cutoff scale a^{-1} do not re-enter」——
   UV cutoff 是 `a^{-1}`，与 `σ` 分属两个符号。`fax:6545`：「µ0 ≪ a^{-1}」。
4. **不是自由到无内容**：`fax:21484–21485`：「A = ∆Ah + µ² with µ > 0 chosen proportional to σ」——`µ ∝ σ`
   把 FRD 质量与 `σ` 绑定；`fax:21670`：「once m0 ∼ σ is fixed, since νσ is supported on [m20 , ∞)」。
   即 `σ` 是**这族测度的 IR/mass 尺度**（`23783` 逐字称「infrared cutoff scale σ > 0」），而 4751 的
   「encodes the ultraviolet resolution」是**泛称**（同一符号两处措辞不同，以 4.12/6.7 的算式为准）。
5. **自由度**：`fax:28489`「Fix a compact parameter set K = [σ− , σ+ ] × BK」；`fax:30725`「(σ, ν) admissible if σ > 0 and supp ν ⊂ [t− , t+ ]」；
   `fax:24185`「σ 7→ Tσ is strongly and hence norm-continuous on compact σ-intervals」。⇒ `σ` 在任意紧区间内**任取**。

## §3 判定：参数选择，还是真障碍

1. **算术**：把 22404 的定位长度读成 `L^{j*}σ^{-1}`（`fax:22327` 逐字给 `≍ L^j σ^{-1}`；22404/22430/22471 的抽取
   文本丢了指数，22315 同）。则 `j* ≥ 0` ⟺ `σ^{-1} ≤ c_* b a_k` ⟺ **`a_k σ ≥ 1/(c_* b)`**。取 `c_* = 1/16`、`b = 2`
   得 **`a_k σ ≥ 8`**——与靶给的数一致。`[T]`（算术）
2. **性质**：`1/(c_*b)` 是常数，`σ` 自由（§1.5），`a_k = b^k a` 随 `k` 增大（`fax:21898`「a_k = b^k a」）⇒ 固定
   `σ` 后**所有足够粗的块**自动满足 `a_k σ ≥ 8`，且同时满足 9.71 的 `σ ≪ a_k`（例：`σ=1`、`a_k=64` ⇒ `σ≪a_k` 且 `a_kσ=64`）。
   ⇒ **参数选择**，不是真障碍。`[T]`
3. **反转的读法从哪来**：`fax:5257` 另用「ak = b−k a0」（k 数 UV cutoff，`a_k ↓ 0`），且连续极限取
   `(a_n, σ_n) → 0`（`11180`/`11275`）。在该约定下 `a_k σ → 0`，条件必失效——但那时失效的是**整条 9.71 窗**
   （`σ/a_k → 0` 与 `a_k` 小同时不可兼得），说明这是**域限制**，不是新障碍。`[T]`（约定判别）
4. **结论**：`a_k σ ≳ 8` = **参数选择** `[T]`；标为「真障碍」`[NG]`。残余未知只有数值 `(σ, c_*, B)` `[NG]`。
   **下一手**：①把 `L3` 陈述显式绑到 `a_k = b^k a` 的粗化侧；②沿 `22444` 的 `K1,K2,c,C` 给 `B` 显式上界；
   ③用 `c_* = 1/16`、`b = 2` 重算 `c*` 窗非空性（窗宽 `0.429560/B − σ/(b a_k)`，两者同为上界，无下端冲突）。
