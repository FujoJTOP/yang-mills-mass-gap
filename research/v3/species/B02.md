## §3 Q2：两句是不是同一件事 —— **不是**（`[T]`，两行）

```
设 L(β) ≡ Λ(β) (同一单位, 即 aΛ)，且题面已给 L(β) → 0。
(i)  m = C·L  ⇒  m ≥ Δ₀ (Δ₀ 常数 >0)  ⟺  C·L(β) ≥ Δ₀  ⟺  L(β) ≥ Δ₀/C > 0.
(ii) 但 L(β) → 0 ⇒ 存在 β₁: ∀β>β₁, L(β) < Δ₀/C ⇒ ¬(i).
∴  [m/L → C>0] 与 [∃Δ₀ ∀β: m ≥ Δ₀] **不能同真**（在 Δ₀ 为同单位常数时）。[T]
```

**唯一使二者同义的条件**：`Λ` 换成 **β-无关**物理常数（即 `m` 用 `m_phys`、`Δ₀` 用物理质量）。那时

```
m_phys ≥ Δ₀  ⟺  m̂/(aΛ) ≥ Δ₀/Λ_phys =: c₀  ⟺  比值地板  (T2)      [T]
```

⇒ **两句"等价"的代价是把 (iii) 从常数地板改成比值地板**；改完它就不再是 (iii)，而是 M05:167–168 判"**避开自我否定**"的那个形式。**所以"AF 免费给 (iii) 的尾"不成立：AF 给的是一条归零的地板。**
