### 1.2 三个定义

**(K1) 类常数。** 对一族算子 `𝒦`（由 BC 型、权重型、图型、势型指定）

    C²(𝒦) := sup { e₂/e₁ : L ∈ 𝒦 }  ∈ [1, ∞] .

**(K2) 判别三元组（BC 台账）。** 对 1D 形式问题 `-(p u')' + q u = λ w u`，类由

    (BC ∈ {DD, NN, PP, ND},  w ≡ const?,  q 的符号/井型,  图是否分支)

指定。本文件的实测台账（§2 表）给出 `C²` 对每条轴的跃变：**`DD/NN/PP → 4`；`ND → 9`；

### KT-3（Wronskian 恒等式：把 `ρ² ≤ 4` 归约成**一条**不等式）`[T-standard]+[V]`

> 设 `-u₁''+qu₁ = λ₁u₁`（`u₁>0`）、`-u₂''+qu₂ = λ₂u₂`，Dirichlet，`λ₂>λ₁`，则
> ```
>     λ₂ - λ₁ = ∫ (W/u₁)² dx / ∫ u₂² dx ,        W = u₁u₂' - u₁'u₂ = const
>     ⇒  ρ² ≤ 4  ⟺  ∫ (W/u₁)² ≤ 3 λ₁ ∫ u₂² .
> ```
> *证明（三行）.* `(u₂/u₁)' = W/u₁²`；分部积分 + 基态方程 `(u₁'/u₁)' = (q-λ₁) - (u₁'/u₁)²` 得
> `∫u₁²((u₂/u₁)')² = λ₂∫u₂² - λ₁∫u₂²`。∎
> 数值核（`kt_e_identity.py`，FD `N=800`，6 个 `q`：自由/抛物/随机光滑/窄峰/双台阶）：
> `lhs` 与 `rhs` 相对误差 `8.2e-6 … 1.0e-5`（FD 精度极限）。DD 类：`(λ₂-λ₁)/λ₁ = 2.999981`
> （**恒等式在 DD 上饱和**，赤字 `1.9e-5 = FD 误差`）；ND 类：`8.00664`（赤字 `-5.0066`）。

**判词 KT-3′（"缺的那一条不等式"定位）`[T]+[V]`。** 整个 DD 类的 `ρ² ≤ 4` **等价于**一条关于
**基态对数导数** `u₁'/u₁`（= `W/u₁²` 的积分）的不等式。**这就是 RB §6 应该写的那一步**，
它比"单井/无 Kramers"精确得多：ND 类的违反**恰好**是这条不等式被违反 `5/3`。
