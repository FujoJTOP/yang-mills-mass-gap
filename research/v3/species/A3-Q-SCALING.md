**判：(b)。** 而且 `(b)` 是**结构性的**，不是拟合出来的：

## §2 两种 `t`-约定下的指数 `p`

设 `a` 为格距，`g` 为 link 群的 bi-invariant 度量（单位 `S³`）。`q_g = ‖(Hess_g V)_−‖`。

### (i) 天真标度（**只缩 `t`，冻住 `q`**）`[T]`（精确恒等式，逐点算过）

| 约定 | 变换 | `Q(a)` | 指数 `p` | `Q` 的极限 |
|---|---|---|---|---|
| **A：热核时间按 `a²`** | `t_phys = a² t_g` | `a²·Q(1)` | **`p = +2`**（log-log 拟合 `2.000000000000`） | `→ 0`（"判 (c)"） |
| **B：按 `a`** | `t_phys = a t_g` | `a·Q(1)` | **`p = +1`**（拟合 `1.000000000000`） | `→ 0`（"判 (c)"） |

数值（`Q(1) = 0.266660`，`a = 1/2 … 1/4096`）：`a=1/2` 时 `Q = 6.6665e−2`（A）/ `1.3333e−1`（B）；`a=1/4` 时 `1.6666e−2` / `6.6665e−2`；…… 两列严格按 `a²`、`a¹` 下降。

**这两个 `p` 都是量纲错误的产物**：`Hess` 用的就是 `t` 所参照的那个度量。缩 `t` 而不缩 `Hess`，等于把"米"改了却不动尺子的刻度。

### (ii) 自洽标度（**度量一起搬**）`[T]` + `[M]`

`g → g' = a²g` ⇒（常数缩放不改 Christoffel，但改 `g^{ij}`）`Δ_{g'} = a^{−2}Δ_g`，故

```
λ_l → λ_l/a² ,   Hess_{g'} = a^{-2} Hess_g ,   q_{g'} = a^{-2} q_g ,
t_{g'} = a² t_g     (唯一的取法，使 tΔ 不变、使 e^{-λ_l t} 不变)
⇒ Q_{g'} = ∫ (a^{-2} q_g)(a² dt_g) = ∫ q_g dt_g          ⇒  p = 0   精确
```

数值验证（把重标模型直接搭起来、`λ_l → λ_l/a²`、在它自己的时间轴上积分）：
`a = 0.5 → 0.26668197`，`a = 0.25 → 0.26668393`，`a = 1/64 → 0.26735174`，对 `Q_g = 0.26666024` 的相对差 `8.1e−5 / 8.9e−5 / 2.6e−3`（末项的偏差是网格分辨率，不是物理）。

**若坚持约定 B（`t ~ a`）**：`tΔ = (a t_g)(a^{−2}Δ_g) = a^{−1}t_gΔ_g → ∞`，热核在 `a→0` 下**完全混合** ⇒ `q ≡ 0` ⇒ `Q = 0` 平凡成立。**约定 B 不是"另一个答案"，它是一个退化的极限**（二阶生成元的 `t` 只能按 `a²`）。**⇒ 唯一非平凡的约定是 A（`t ~ a²`），配度量搬运，`p = 0`。**

## §3 量纲记账：`Q` 到底带什么量纲，归一标度是什么

1. **`S_W` 无量纲**：`S_W = βΣ_p(1 − ½Re tr U_p)`，`tr U_p` 是 `SU(2)` 元素的迹 = 纯数，`β` 是参数（纯数）。**没有 `a`、没有长度。**
2. **群坐标无量纲**：`U = exp(iθ^aσ^a/2)`，`θ ∈ [0, 2π]`（`ψ = |θ|/2`）。`Hess S_W` 关于 `θ` 是**纯数**；关于**物理场** `A = θ/a` 则是 `Hess_A = a²Hess_θ`（`∂_A = a∂_θ`）。
3. **`q` 无量纲**（`θ` 坐标口径下），**`t` 有量纲**（不管你把"量纲"记成 `R_g²` 还是 `a²`）。⇒ **`Q = ∫q dt` 带一个 `t` 的量纲。** `[T]`
4. ⇒ `e^{−2Q}` 只有在 `Q` 被**固定** `t_*` 归一后才合法：`e^{−2Q/t_*}`。BD 用的 `t_*` 是**他假设里那个度量自己的标度**：`Ric = (N/4)g`。
   - 单位 `S³`（`λ₁ = 3`，`Ric = 2g`）：`t_* = 1/λ₁ = **1/3**`；要 `Ric = (N/4)g = (3/4)g` 需 `g_{BD} = (8/3)g` ⇒ `λ₁^{BD} = 9/8` ⇒ `t_*^{BD} = **8/9**`。
   - **两者都是纯数**。**`a`-不变、`β`-不变。这就是"BD 原文的 `t` 被哪个固定标度归一过"的答案。**
5. **物理场口径下同一结论**：若把 `q` 定义在 `A` 上（`q_A = a²q_θ`）并把时间取成 `t_A = t_θ/a²`，则 `∫q_A dt_A = ∫q_θ dt_θ` —— **`a` 精确对消**。这正是 §2(ii) 的 `p = 0`，两条独立口径给出同一个不变量。`[T]`
6. **`a` 在 `q(t)` 里出现的唯一方式**是"它根本不出现"：`q = q(β, t)`，`t` 以 `λ_l t`（`λ_l = l(l+2)`）进入。**所以 `Q` 是 `(β, 群度量归一化)` 的函数，不是 `a` 的函数。**

## §4 `Q` 真正随什么动：`β`（而不是 `a`）

| `β` | 0.5 | 1.0 | 2.5 | 5.0 |
|---|---|---|---|---|

`A ∝ β^{1.138}`（`β ∈ [0.5,5]` 的 log-log 拟合；线性应为 `1.000`）⇒ **`Q` 随 `β` **超线性**增长，而不是饱和。**

> **`(a′)`（本轮的第二个判决，`[M]` + `[C]`）：沿"固定物理量"的连续轨迹，`a→0` 强制 `β = 2N/g₀² → ∞`，而 `Q ∝ β^{1.14}` ⇒ `e^{−2Q} → 0` ⇒ `γ ≥ (N/4)e^{−2Q} → 0`，BD 判据在连续极限**失去内容**。
> **但归因是 `β`，不是 `a`。** 这与 `(a)` 的表述**结论相同、机制不同**：`Q` 对 `a` 是常数（`p = 0`），对 `β` 发散。**标度问题（本题）的答案是 `(b)`；连续极限的失败是 `(a′)`。**
> 诚实标注：`β ≥ 10` 时交替 Bessel 和对 `B_t` 在 float64 下消去（本轮 `β = 10,20,50` 被脚本的健全性检查判为不可用），`β^{1.138}` 只在 `β ≤ 5` 上测。**要测 `β ≥ 10` 必须换成 `ψ`-求积路线（不做 `(−1)^l` 的交替和）。** 这一步未做。

## §5 汇总与可证伪条件

**答（单行）**：`Q` 的量纲 = 一个 `[t]`（`q` 无量纲）；`p = +2`（`t∝a²`，冻结 `q`）/ `p = +1`（`t∝a`，冻结 `q`）/ **`p = 0`（度量搬运，唯一自洽）**；归一键 = `t_* = 1/λ₁ = 1/3`（`Ric = (N/4)g` 口径 `8/9`），纯数、`a`-无关；判 **(b)**（`Q` 常数），附 `(a′)`（`Q ∝ β^{1.14}` ⇒ 连续极限下判据空转）。

**本轮新增（可入库）**
1. `[T]` `Q` 的 `a`-无关性是**恒等式**：`Hess → a^{−2}Hess` 与 `dt → a²dt` 精确对消；`p ≠ 0` 只在"缩 `t` 不缩度量"时出现。
2. `[T]` `t_* = 1/λ₁`，纯数；BD 判据的无量纲性靠它，与 `a` 无关。
3. `[M]` `Q = 0.26666`（`t` 单位）/ `0.79998`（`τ` 单位），修正 `COV-T` 的 `0.109856`（E1）。
4. `[M]/[C]` `Q ∝ β^{1.14}`（`β ≤ 5`）⇒ `(a′)`。

**可证伪**
- 若在 4D 格点上测出 `q(t)` 的曲线随 `a`（固定 `β`）变化 ⇒ §3 第 6 条假。本轮四个模型全部 `a`-盲（它们根本没有 `a`）。
- 若 `q` 的率随 `β` 或 `a` 移动 ⇒ `t` 不是群热核时间。实测 `λ/λ₁ = 1.000–1.007`。
