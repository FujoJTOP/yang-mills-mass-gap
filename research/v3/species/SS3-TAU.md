## §1 逐字核（给 `file:line`）

```

(L1) RR4:60  τ_int = χ/C(0)                                    ← 它所依赖的 τ 定义

     ⇒ χ/M₀ = Σ_{t₄}ρ = 1 + 2Σ_{t≥1}ρ + ρ(L_t/2) = 2τ_int + 边界项
```

**读法。** 「天花板 = `1/τ_int`」既不是纯恒等也不是纯不等式，而是**一条上界 + 一条定义写在同一行**：带「天花板」的半边是**上界**（`s₁ ≤ U₀`，且两端在 Lean 里是假设），带「`1/τ_int`」的半边是**定义**（`τ := χ/C(0)`），在标准约定下常数差 `2×`。**「天花板」这个词属于 `s₁`，不属于 `τ`**——把 `U₀` 说成「`1/τ_int` 的天花板」是把受语反了。

**(d) 的形状诊断。** 界本身是标准链理论（可逆 + 绝对谱隙 `γ` ⇒ `τ ≤ 1/γ + O(1)`；文献侧同形，§4-8）。它把地板绑在**算法的**松弛谱隙上：4D SU(2) 局部热浴有临界慢化 `γ ~ L^{−z}`，于是"地板"随 `L` 按 `L^{−z}` 掉，`∃c ∀L` 不成立；且 `γ` 是算法量、不是物理谱隙，把它当物理谱隙正是 `H1` 的错。

**§2 的判。** 反不过来。四个读法里逻辑上真能反的只有 (b)，而它恰是原题的换名（同强、零新）；(a) 方向错；(c) 是 `H1` 的归一化形、已是 `[NG]`；(d) 只在拿到 `γ` 的**一致正下界**时成立，那句与 `H1` 同强。**「是否比原问题弱」的答**：不弱 —— (b)(c)(d) 同强、(a) 不足。
