## 1 · J1：「沿管 1D 次可加」的精确陈述

### 1.1 对象与符号

沿管对象取 `p4` 的原物（`P4-OTHER.md:145`）：

```
b(T) := log Z_dec(B_T) ,   Z_dec(B_T) = 装饰簇气体在管 B_T 上的配分函数
b(T) = φ_dec·T + log D_∞ + ε_T      （p4 的目标分解）
```
- 管的几何：横截面固定（四壁，`FOURWALL:86`，`m₁ = 4ln(1/u)/a` 里的 `4`），纵向量 `T`。
- 装饰簇带**附着跨度** `α`（`X01:29–35`，`p4` 引）= 相互作用在时间方向的有效有限程。

### 1.2 次可加是哪一个（符号必须钉死，否则整条讨论会翻符号）

自由边界下沿横截面拼接：`Z(L₁+L₂+α) ≥ Z(L₁)·Z(L₂)`（多出来的 `α` 是重叠壳层，拼接不完美但**只差有限程**）。取 `a := −log Z`：

```
a(L₁+L₂+α) ≤ a(L₁) + a(L₂)          ← 这就是「沿管 1D 次可加」          [T]
```
等价地 `b := log Z` 是**超**可加（up to `α`）。两者是同一句话的两次取反，**下面所有结论在这个取反下一致**，但**看的方向相反**，这正是 `p4` 说"对的一侧"的意思。

### 1.3 Fekete 给什么（精确到"给了哪个方向"）

> **命题 1.1（Fekete，带 `O(1)` 松弛 / de Bruijn–Erdős 形式）`[T]`.**
> 若 `a : [0,∞) → ℝ` 满足 `a(s+t+α) ≤ a(s)+a(t)`（`α` 固定），则
> ```
> c := lim_{L→∞} a(L)/L = inf_{L} a(L)/L        （存在，∈ [−∞,+∞)）
> ```
> 对 `b = −a`：`φ := lim b(L)/L = sup_L b(L)/L`（存在），且 **`b(T) ≤ φT` 对所有 `T`**。

**给了什么，逐条：**
1. **率的存在**，且**不需要 `ū<1`、不需要任何小活动度**（Fekete 是纯组合引理）——`p4` 的这句是对的 `[T]`。
2. **率的单侧界**：`b(T) ≤ φT`，即 `Z_dec(B_T) ≤ e^{φT}`。**只有天花板。**
3. **`D_∞`：什么也没给。** `D_∞` 活在 `T⁰` 阶；Fekete 的结论是 `o(T)` 级（`a(L)/L → c` 允许 `a(L) = cL + √L`、`cL + log log L` 等等）。**`o(T)` 与 `O(1)` 之间没有任何蕴含。**

### 1.4 把 `p4` 的那句话翻译成最锋利的等价形式

由 `b(T) ≤ φT`，定义 `δ(T) := φT − b(T) ≥ 0`。则（在 `p4` 的分解约定下）

```
D_∞ > 0   ⟺   liminf_T δ(T) < ∞   ⟺   sup_T [ b(T) − φT ] > −∞
```
即：**`D_∞ > 0` ⟺ Fekete 的上确界被"逼近到 `O(1)`"**（而非仅仅"被逼近"）。Fekete 只说 `b(T)/T → φ`；把它加强到 `b(T) ≥ φT − C` 是**另一条定理**。`[T]`

> **这句话就是本轮最重要的定位：`I1`（残数地板）≡「Fekete sup 在 `O(1)` 内被取到」。** 它不是"更强的次可加性"，而是**同一次可加性的 `T⁰` 版本**——两者阶数不同，不可互推。

## 2 · J3：核算「次可加 + 下界 ⇒ 率 > 0」这条逻辑（结论：假的）

任务要求"这个逻辑要查清"。逐条核：

### 2.1 反例 A：常数下界完全无效

```
a(L) ≡ m > 0        次可加？ a(L₁+L₂)=m ≤ m+m ✓     率 c = lim m/L = 0        ✗
```
⇒ **"次可加 + 下界（常数）⇒ 率 > 0" 是假的。** 常数下界与次可加性**方向相同**（都允许"不增长"），不产生线性增长。

### 2.2 反例 B：单点线性下界也无效

```
a(L) = √L           次可加？ √(x+y) ≤ √x+√y ✓       a(4)/4 = 0.5 > 0，但 c = 0   ✗
```
⇒ **"某一点 `a(L₀) ≥ θL₀`" 也不够**；次可加函数的极端形态是 `cL` 与**有界函数**，`√L` 落在两者之间。

### 2.2b 数值核对（`[E]`，本轮 `pwsh`+`py -3.12` 实跑，`2×10⁵` 随机点，`α=0.3`）

| 被检函数 | `max[ a(x+y+α) − a(x) − a(y) ]` | 判定 | 率 |
|---|---|---|---|
| `a ≡ 3`（反例 A） | **0.000000** | 次可加（取等）✓ | `3×10⁻⁷ → 0` |
| `a = √L`（反例 B） | **0.125511**（上界 `√α = 0.547723`，**有界缺陷**） | 带 `O(1)` 缺陷的次可加 ✓ | `3.16×10⁻⁴ → 0`，而 `a(4)/4 = 0.5` |
| `a = 1.7L + log 0.01`（`γ=0.01`） | **5.115170** ≤ `2|log γ| = 9.210340` ✓ | 带 `O(1)` 松弛的次可加 ✓ | `1.7`（与 `γ=1` 同） |
| `a = 1.7L + log 100`（`γ=100`） | **0.000000** | 严格次可加 ✓ | `1.7`（与 `γ=1` 同） |

**⇒ 四行一起把 §2.1/§2.2/§3.2 全部落实**：率 = 0 与率 = 1.7 都满足同一条次可加公理（带 `O(1)` 松弛），而 `D_∞` 的平移量实测 `= log 0.01 = −4.605170`（精确）⇒ **`D_∞` 完全不被约束**。`[E]`

### 2.3 正确条件（这才是"另一侧"的准确形状）

> **命题 2.1（率的正性的充要形态）`[T]`.**
> 设 `a` 次可加（§1.2）。则
> ```
> c > 0   ⟺   ∃ θ>0, ∀L : a(L) ≥ θL
>         ⟸   ∃ L₀, C : a(2^kL₀) ≥ 2^k a(L₀) − C   （"沿 2 倍放大不掉"）
> ```
> 逆命题的另一半（⇒）由 `c = inf a(L)/L > 0` 直接给。
> **几乎超可加版**：`a(L₁+L₂) ≥ a(L₁)+a(L₂) − C` ⇒ `a(2^kL₀)/2^kL₀ ≥ a(L₀)/L₀ − C/(2^kL₀)` ⇒ `c ≥ a(L₀)/L₀ − C/L₀`，取 `L₀ > 2C L₀/a(L₀)` 即正。

**⇒ 精确记账：**
```
次可加（天花板）  +  超可加型下界（地板）  ⇒  率存在且 > 0        [T]
次可加（天花板）  +  任意常数下界          ⇒  率存在，可为 0      [T]（反例 A）
```
**`p4` 缺的正是"地板"，而地板的自然来源（绝对可和 / 正性改善的核）恰恰被 Ursell 的交错和毁掉——两处是同一件事的两种说法。** `[T]`

### 2.4 与 `p4` 逐字的对应（不是我的新说法，是它的原话的精确化）

`P4-OTHER.md:145` 逐字：「正性 `D_∞>0` 需要 `log Z_dec ≥ φ_dec T − C`，即次可加性的"对的一侧"，而 Ursell 系数有符号（`φ^U` 是交错和）⇒ 拿不到」。
本轮把它变成**可判的两句话**：
- 「对的一侧」= 命题 2.1 的 `a(L) ≥ θL`（地板），**不是**次可加的方向；`[T]`
- 「Ursell 有符号」= 地板无法由"绝对可和"给出 ⇒ 必须靠**抵消**（§6/§7）。`[T]`

## 3 · J2/J4：阶数定理与规范自由度（为什么"再强的次可加"都没用）

### 3.1 阶数不匹配（一句话版）

> **命题 3.1 `[T]`.** 次可加性是 `a` 的**一次齐次**约束（`a ↦ ta` 保持），结论落在 `T¹` 阶；`D_∞` 是 `T⁰` 阶量。**一次齐次约束不能定 `T⁰` 常数**——它对 `a` 的整体平移（= `b` 的整体乘常数）完全不敏感。

### 3.2 规范自由度（把上面这句做成"乘法"形式，最狠）

> **命题 3.2（`D_∞` 是次可加框架的规范自由度）`[T]`.**
> 取任意 `γ>0`，令 `a_γ(L) := a(L) + log γ`（即 `Z ↦ γZ`，`D_∞ ↦ γD_∞`）。则
> ```
> a_γ(L₁+L₂+α) = a(L₁+L₂+α) + log γ ≤ a(L₁)+a(L₂) + log γ ≤ a_γ(L₁)+a_γ(L₂) + 2|log γ|
> ```
> ⇒ `a_γ` 与 `a` **同样满足"带 `O(1)` 松弛的次可加性"**，Fekete 给出**同一个** `c`（松弛是 `O(1)`，不影响 `a/L` 极限）。
> **⇒ 全部 `{D_∞ = γ : γ>0}` 对次可加性而言不可区分。** 特别地 `γ→0⁺` 让 `D_∞→0` 而**公理一条不破**。

**这是本轮对 `p4` 的 `[NG]` 的实质性升级**：`p4` 说"取不到"；命题 3.2 说"**取不到是因为 `D_∞` 不在这个语言的论域里**"。所以任何"把沿管次可加做得更强/更细/更多维"的计划，**在原则上**都不可能产出 `D_∞>0`。`[T]`

## 4 · J5：「沿管」能否升级到 2D/3D 次可加？（能加，但不给更多）

### 4.1 先老实列出三种"2D/3D 次可加"的读法

| 读法 | 陈述 | 它多给了什么 | 等级 |
|---|---|---|---|
| **α 形状耦合** | `a(L₁+L₂, W) ≤ a(L₁,W)+a(L₂,W)` 且 `a(L,W₁+W₂) ≤ a(L,W₁)+a(L,W₂)` | 二变量极限 `φ_dec(W)` 与 `φ_T(L)` 存在；形状极限/表面张力**存在**（Robinson / Dobrushin–Zaharov 型，标准结论，本轮未逐篇核，**不给伪 ID**）。**仍只存在于 `T¹` 阶。** | `[T-standard]`（未逐字核） |
| **β 维数记账** | 沿 `2^d` 细化（`BN-RESIDUAL.md:19` 已证必须 `2^d` 不是 `2`） | 只定指数/体积常数，**无符号信息** | `[T]` |
| **γ 转折核（真正的候选）** | 用 `𝕋`（转移核）替掉标量 `a`，问 `spec 𝕋` 与锥 | **这一路才可能给 `D_∞>0`**（见 §5） | `[C]` |

⇒ **α、β 两种"升级"都只是把"存在性"复制到更多变量上；`D_∞` 一个字都不动。**

### 4.2 一般性定理：任何 `d` 的次可加都给不了正性

> **命题 4.1（锥论证，`d`-无关）`[T]`.**
> 令 `𝒮_d := { a : 有限程域族 → ℝ : a(W₁∪W₂) ≤ a(W₁)+a(W₂) 对所有相邻不交 W₁,W₂ }`。
> (i) `𝒮_d` 是**凸锥**；(ii) `0 ∈ 𝒮_d`；(iii) `a ∈ 𝒮_d ⇒ ta ∈ 𝒮_d ∀t ≥ 0`。
> 设 `Φ(a) := lim a(V)/|V|`（存在性由 Fekete-in-`d`/Robinson 给）。任何形如 `"a ∈ 𝒮_d ⇒ Φ(a) ≥ c₀ > 0"` 的命题取 `a ≡ 0 ∈ 𝒮_d` 即被否。
> **⇒ 不可能存在"某个 `d`、某个方向组合、某个偏序细化"的次可加版本给出正性。** 与 `d` 无关。

**⇒ 判死线 (c)：否。** 且这个"否"是**定理级**的，不是"本路未找到"。

### 4.3 唯一在 `d` 上真正变化的东西（诚实补一句，防被误读成"维数完全无用"）

`d` 确实改变**别的东西**，只是不改变正性：
- `d=1`：转移矩阵存在且通常可对角化 ⇒ **有可能**做 Krein–Rutman；
- `d≥2`：`𝕋` 变成"横截面上的算子值"对象，谱论更难，但**同时**换来了反射正性/OS 正性（`BN-RESIDUAL.md:191` 的 `[T]`）这一**独立的正性源**。
⇒ **维数的正确用法：不是加次可加的方向，而是换到"正性可从公理读出的语言"（RP/OS）。** 而 `p4` 的装饰气体恰好是**符号交错**的展开，RP 不直接作用于它。这正是"第 6 物种"缺口的所在（`p4:147` 原话）。

## 5 · J6：(a) 的条件版 —— 什么才真的给正性 + 收敛

> **命题 5.1（条件定理）`[C]`.** 设沿管转移核 `𝕋` 作用在"装饰簇截面态" Banach 空间 `𝔛` 上，且
> **(H1) 准紧**：`spec 𝕋 ⊂ {e^{φ}} ∪ {|z| ≤ ρe^{φ}}`，`ρ<1`（`e^{φ}` 单重、本征向量 `ℓ≠0, r≠0`）；
> **(H2) 正性改善**：存在闭锥 `𝒞 ⊆ 𝔛`，`𝕋𝒞 ⊆ int 𝒞`（Krein–Rutman 条件）。
> 则
> ```
> b(T) = φT + log⟨ℓ,r⟩ + O(ρ^T) ,    D_∞ = ⟨ℓ,r⟩ > 0 ,    ε_T = O(e^{−cT})
> ```
> **正性与几何收敛一次给出。**

**它换来了什么**：不需要 `ū<1`（不需要绝对可和），只要 `𝕋` 在某个锥上正性改善。
**它没换来什么**：装饰气体的 `𝕋` 由 Ursell 系数 `φ^U`（交错和）构成 ⇒ **`𝕋` 非正 ⇒ (H2) 在自然锥上直接失败**。要修 (H2)，要么把 `𝕋` 换成一个**正**表示（= 重求和 / resummation），要么放弃 `𝕋` 走 §7 的抵消引理。`[T]`（失败的原因）+ `[NG]`（修法尚不存在）

**与 `p4` 的 `D_∞ = 1 + O(ū)` 的关系**（`P4-OTHER.md:135`，`FOURWALL:88–92`「领先类唯一，取等 iff 直管」）：那条 `[T]` 说明 `D_∞` 的"1"是**结构性的正项**（直管），修正是 `O(ū)`。所以
```
D_∞ > 0   ⟺   |修正| < 1   ⟺   带符号和被"压到 1 以内"
```
在 `ū ≤ 0.25`（`P4:103`，`D_∞ ∈ [0.690478, 1.448374]`）这由绝对可和**已经做到**（`p4:101` 的 `e^{−Θ} ≤ D_∞ ≤ e^{Θ}`，`[T]`）。**在 `β=2.5`（`ū=33.98`、`u=0.625`，`P4:162`）绝对可和崩溃，`Θ(0.5654)=3.502870`（`P4:110`）只是把窗挪到中间**——需要的是"`ū` 大时的抵消"，而**抵消引理在语料中不存在**。`[NG]`

## 6 · J7：对 `rs4` 的接口 —— 「正性能否给收敛？」

**结论：不能。"正性 ⇒ 收敛"是错的；"准紧 ⇒ 正性 + 几何收敛"才是对的。**

> **命题 6.1 `[T]`.** `D_∞ > 0` **不**蕴含 `ε_T = O(e^{−cT})`（甚至不蕴含 `ε_T → 0`）。
> **反例**：`b(T) = φT + log D_∞ + 1/log(2+T)`。则 `D_∞>0` 成立、`ε_T → 0`、但收敛是 `1/log T` 级，**非几何**；且 §1.2 的次可加松弛（`O(1)`）**容许**这一项，Fekete 结论不变。

**正确蕴含图（这是 `rs4` 该拿走的）：**
```
        ┌──────────── (H1) 准紧 ────────────┐
        │                                    │
   (H2) 正性改善 ──┬──> D_∞ = ⟨ℓ,r⟩ > 0
                   └──> ε_T = O(ρ^T)  几何收敛
                        （两者同源于"外围谱单重 + 锥入内部"）
```
