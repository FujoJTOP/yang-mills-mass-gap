## §1 Birkhoff–Hopf 结构逐字核

### 1.1 `Δ` 的定义对象（逐字）

`D02-DIRECT.md:91` 逐字：

```
定义 Δ := sup_{U,U',V,V'} |log[ T(U,U')T(V,V') / (T(U,V')T(V,U')) ]| ，则 Birkhoff–Hopf 振荡收缩给
λ₂/λ₁ ≤ tanh(Δ/4)。d=2 时取等（机检：对称 2×2 正矩阵，4/4 组 J 全部 equal=True）⇒ 界是锐的，只在 d=2。
```

所以 `Δ` 是**算子 `T` 的核（`L²(SU(N)^{3L³})` 上的积分核）的两点 log-振荡**：
- **不是 `H_a` 的振荡**（`H_a` 在 `D02` 里连定义都不出现；`GN3-SPECTRAL.md:87–88` 定义的 `Δ_a` 是**谱底**，与本文件的 `Δ` 是**同名不同物**——这是本项目三义 `Δ` 之一，见 §5.2 第 4 条）；
- **不是 4D 作用量的振荡**（`D02:97–99` 逐字给出相消）。

**严格相消**（`D02:97–99` 逐字）：`T[U,U'] = e^{−S_sp(U)/2}e^{−S_sp(U')/2}W(U,U')`（`D02:36–37`），故

```
T[U,U']T[V,V'] / (T[U,V']T[V,U'])  =  W[U,U']W[V,V'] / (W[U,V']W[V,U'])        (1.1)
```

`S_sp` 的四个因子在比里各出现一次 +、一次 −，**逐字相消**（`[T]`，`D02:196` 机检 `5.96e−8`）。⇒

```
Δ = osc(log W) ，W(U,U') = ∫∏_x dV(x) exp[ (β/2)Σ_{x,i} Re tr( U_i(x)V(x+î)U'_i(x)†V(x)† )]   (1.2)
```

即 `Δ` 只依赖 **3D 片**（`L³` 位点、`L³` 条时向 link）——`D02:99` 逐字："`Δ` 只依赖 3D 的 `W`——一个 `L³` 位点、`L³` 条时向 link 的 3D 规范积分，而不是 4D 全环面"。**这一条是本轮所有算术的入口**：`Δ` 是 **3D 场论对象**，不是 4D 谱对象。

> **`[M]` 一处转写错**：`GAP3.md:61` 把它转写成 `Δ := sup log[...]`（**丢了绝对值**），并写 `gap ≥ −log tanh(Δ/4)`。丢绝对值后 `Δ` 可负、`tanh(Δ/4)` 无意义。正确形是 `D02:91` 的带 `|·|` 版本。`GAP3:61` 的这一行被 `GH1:159,211` 转引，建议同步改。

### 1.3 ★ 定理 A（两种写法严格等价）`[T]`+`[E]`

> **定理 A.** 记 `g := −log(λ₂/λ₁) = a·m_L`（格点单位隙），`Δ := osc(log K)`。则
> ```
> g ≥ −log tanh(Δ/4)      ⟺      Δ ≥ 2 log coth(g/2)          (1.3)
> ```
> *证.* 两边都等价于 `e^{−g} ≤ tanh(Δ/4)`：`−log tanh(Δ/4) ≤ g ⟺ tanh(Δ/4) ≥ e^{−g} ⟺ Δ/4 ≥ artanh(e^{−g})`（`artanh` 单增），而 `4·artanh(e^{−g}) = 2log((1+e^{−g})/(1−e^{−g})) = 2log coth(g/2)`。∎
> *机检*：`1600` 点网格上两条不等式**真假完全一致**，边界回代 `max|Δ − 2log coth(gb/2)| = 5.220e−46`（`Decimal` 50 位）。

**这条恒等式是本次判决的枢轴。** 它的三个后果，逐条写死：

1. **"BH 给地板"与"BH 给 `Δ` 的下界"是同一句话。** 说"`g ≥ −log tanh(Δ/4)` 是一条地板机器"与说"`Δ ≥ 2log coth(g/2)`"完全等价 —— 后者是**关于 `Δ` 的陈述**，其中 `g` 是输入。所以 BH 的**可消费方向**是 **隙 ⇒ `Δ` 大**。
2. **要 `g` 的下界，必须另输 `Δ` 的上界。** `Δ ≤ M ⇒ g ≥ −log tanh(M/4) =: c(M) > 0`。这个 `M` **不在 BH 里**（BH 只给 `Δ` 的**下**界）。
3. **`Δ` 的上界是"另一个对象"**：由 (1.3)，`Δ ≥ 2log coth(g/2) ≈ 2log(2/g) = 2log(2ξ/a)`（`g = a·m = a/ξ`）。⇒
   ```
   Δ  ≥  2 log(2·ξ/a)        （g 小，即 ξ≫a 时；数值：g=0.001 ⇒ Δ ≥ 15.2）        (1.4)
   ```
   **`Δ` 是关联长度（格点单位）的对数。** 所以"`Δ ≤ M`"逐字就是"`ξ/a ≤ ½e^{M/2}`"——**关联长度有上界**。这正是 `B04:92–97` 叫"反靶"的东西（§3）。

## §2 "vacuous" 判定

### 2.1 判据的准确形式（量词先写死）

```
(M-界)   ∃M<∞ ∀(L,a) ∀β :            Δ(L,a,β) ≤ M                     ← 救活所必需
(F-地板) ∃c>0 ∀(L,a) :               a·m_L(a) ≥ c = −log tanh(M/4) > 0  ← (M-界) 的推论
(E)      ∃Δ₀>0 ∀(L,a) :              m/Λ ≥ Δ₀                          ← 真正的靶（B04:101）
(N-无界) ∀M ∃(L,a,β) :               Δ(L,a,β) > M                     ← 本轮证的（[T]+[C]）
```

lead 题面写的是 `(M-界) ⇒ 给模数 ⇒ 救活`。**算术成立**（这就是 `(M-界) ⇒ (F-地板)`），但它到不了 `(E)`，见 §2.2。

### 2.2 ★ 定理 B（双向判死）`[T]`+`[C]`

> **定理 B.** (i) `(M-界)` 不可能成立；(ii) 若放弃 `(M-界)`，BH 只给退化的地板。两支都不到 `(E)`。
>
> *证 (i).*
> ```
> (M-界)  ⇒  a·m ≥ −log tanh(M/4) =: c > 0                      （定理 A + tanh 单增）
>         ⇒  ξ/a = 1/(a·m) ≤ 1/c   （关联长度有界）
>         ⇒  格点单位正地板 = 反靶（B04:92–97 逐字：⟺ 非平凡连续极限不存在）
>         ⇒  与 a·m → 0 冲突（B04:17,98,137；AF 两圈 + 数值，[C]）
>         ⇒  (M-界) 为假。
> ```
> *证 (ii).* 若只知 `Δ` 逐点有限：`Δ` 有限 ⇒ `tanh(Δ/4)<1` ⇒ 地板 `>0` 但**可以任意小**（`Δ=100` 时 `3.86e−22`，§4.6）⇒ 无模数。`Δ` 无界 ⇒ 地板 → 0。∎

**读法（这一节是本次判决的全部内容）**：`(M-界)` **不是"尚未证"，是"若成立则结论非靶、且与已知标度冲突"**。⇒ 第四类的问题不在"`Δ` 够不够小"，在"**要 `Δ` 小就等于要 `ξ = O(a)`**"。

### 2.4 "vacuous" 成立，但 `D02` 的理由是**非序列**

`D02:101` / `GAP3:64,93,116` / `LOOP-RUNBOOK:7480` 的推法都是：`Δ` 大 ⇒ `tanh(Δ/4)→1` ⇒ `vacuous`。**这一步在逻辑上不成立**：

```
Δ = 8   ⇒ 地板 = 0.036635   （而 β=2.5 的 SU(2) 实测 m·a=1.707 ⇒ 占地板 2.15%）
Δ = 20  ⇒ 地板 = 9.079986e−05
Δ = 100 ⇒ 地板 = 3.857500e−22  （tanh(25) 浮点算给 1；用恒等式 −log1p(−2/(e^{Δ/2}+1)) 取尾值；数学上严格 >0）
Δ = 200 ⇒ 地板 = 7.440152e−44
```

⇒ **地板永不消失**，只连续退化。所以
- `D02:101` 的 "vacuous" 是**"数值无用"**（几 % 到 `e−22`），不是**"逻辑空"**；
- `LOOP-RUNBOOK:7480` 的"路径：证 `Δ < ∞` 且 `tanh(Δ/4) < 1`"是**两步白给**：`Δ < ∞` 由紧性（`[T]`，`D02:58–59`）、`tanh(Δ/4)<1` 由 `Δ<∞`。这条"路径"不含任何内容 ⇒ `[M]`；
- `GAP3:116` 的"最便宜的第一刀：若 `Δ` 在 `β=2.5` 上被证 `≥8` 则正式判死"**缺 `L` 量词**：`Δ(L=1) ≥ 15` 已 `[T]`（§1.5），照字面已经"判死"，但那是退化格点。**这一刀不可执行**，因为判据本身没写清对哪个 `L` 取 `sup`。

**⇒ 本轮给出的判死方式不同**：不是"`Δ` 在 2.5 处大"，而是 §2.2 的**双向判死**（前提假 / 前提存在则结论非靶）。这个判死**不依赖任何 `β=2.5` 的数值**，也不依赖 `Δ` 的具体上界。

### 2.5 第五类存在吗：不存在

`GH1 §2.6` 列的四类"带模数的输入"是：`(1) Λ>0/AF`、`(2) 一致 Poincaré/LSI`、`(3)` 振幅地板 `f₁²≥r₀`、`(4)` `Δ` 界。本轮判 `(4)`：

- **它不是输入，是输出**：`Δ ≥ 2log coth(a·m/2)`（定理 A）——`Δ` 的**下界**由隙给。要把它当输入必须反用（上界），而那个方向是反靶。
- 与 `D01-OMEGA.md:61–63` 的既有判词同型（那里是 `Ω` 的 Doeblin–Birkhoff 定量化）：**`[C]` 逐字"定量 PF 不是 3.1 之外的另一条路，是 3.1 的一个估计器"**。本文件把同一句搬到隙：**BH 不是"隙"之外的另一条路，是隙的一个坐标**。

⇒ **四类 ⇒ 有效三类。** 这不是新增一堵墙，是**删掉一个槽位**。

## §4 酸测（自由场 / 2D / M6 / 单片 / `β=0`）

### 4.1 自由场：`Δ → ∞`，不是 0 `[T]*`+`[E]`

取自由无质量场（去掉零模），`g_L = aE₁ = 2·asinh(sin(π/L))`（`GH1:277` 同一写法）。定理 A 反向 ⇒ `Δ ≥ 2log coth(g_L/2)`：

| `L` | 4 | 8 | 16 | 64 | 256 | 1024 | 4096 |
|---|---|---|---|---|---|---|---|
| `g_L` | 1.31695790 | 0.74781940 | 0.38774704 | 0.09809601 | 0.02454246 | 0.00613590 | 0.00153398 |
| `Δ` 下界 | 1.098612 | 2.057762 | 3.305939 | 6.031514 | 8.801096 | 11.573496 | 14.346073 |
| `2log(L/π)` | 0.483129 | 1.869423 | 3.255718 | 6.028306 | 8.800895 | 11.573484 | 14.346073 |
| BH 地板 | 1.316958 | 0.747819 | 0.387747 | 0.098096 | 0.024542 | 0.006136 | 0.001534 |

三点读数：
1. **`Δ_free` 随 `L` 对数发散**（`≈ 2log(L/π)`，六位吻合）——**题面"自由场 `Δ` 应为 0"的预期是错的**：`Δ` 度量的是 `ξ/a` 的对数，无质量 ⇒ `ξ→∞` ⇒ `Δ→∞`。
2. 表最后一行的"BH 地板"**逐字等于 `g_L`**：在反转点 `Δ = ψ(g)` 上，不等式**取等** ⇒ **零 slack**。这说明 BH 在自由场上是**紧的**，同时**零信息**（输出 = 输入）。
3. 结论：自由场**通过**（`m=0` 给 `0`），但通过的方式是"输出 `≈` 输入"，不是"判据看见无隙"。

### 4.2 ★ 2D YM：**决定性 FAIL** `[T]*`

2D 里 `m/Λ` 是 `β`-无关的**纯数**（`B04:138` 逐字"`m/Λ = m/(√(g²)·纯数) = 纯数，β-无关（精确常数）"；`g²=1` 口径下 `m=3g²/8=0.375`，`B01-RP:60`），而 `m·a = c√(2N²/β) ∝ β^{−1/2} → 0`（`B04:137` 及其表）。⇒

```
a·m → 0   ⇒   Δ_2D ≥ 2log coth(a·m/2) → ∞   ⇒   BH 地板 ≤ a·m → 0
而真值 m/Λ = 0.375 ≠ 0
```

⇒ **BH 在 2D 上给 0 地板，而 2D 确实有隙（`3g²/8`）。** 这不是"松"，是**输出错了对象**：BH 的输出逐字是 `a·m`（UV 量），不是 `m/Λ`（IR 量）。按 `B04-INDEX.md:72` 的四模型纪律（"四模型测试的判别力全在 `2D YM` 与 `M6` 这对反例"），这一列**直接判死**。

### 4.3 M6：盲

`m_L = min(ω, ½(2π/L)²) → 0`（`GH1:288` 转引 `GR2-EDGEATOM.md:225`）⇒ `a·m_L → 0` ⇒ `Δ → ∞` ⇒ 地板 → 0。**与自由场同输出**（`0`），而 M6 与自由场的 `m` 都是 0 —— 即该判据**不区分**"有原子/无原子"。

### 4.4 单 plaquette：静默

无时间方向 ⇒ 无 `T` ⇒ `Δ` 无定义 ⇒ 静默（与 `B04-INDEX.md:62` 同）。

### 4.5 `β=0`（纯 Haar）：BH 唯一**取等**的一格 `[T]`

`β=0` 时 `S_W=0`、`W ≡ 1`（积分被积函数恒 1）⇒ `Δ = 0` **精确** ⇒ `λ₂/λ₁ ≤ tanh(0) = 0` ⇒ `λ₂ = 0`（`T` 秩一）⇒ **取等**。
⇒ **BH 精确的地方正是物理退化的那一格**（`GH1:86` 逐字："在 `β=0`（纯 Haar）上 `T` 秩一 ⇒ `λ₂=0` ⇒ `R_t=∞`，等式退化——这不是'物理'，是'对象消失'"）。

### 4.6 签名与判

```
签名（Birkhoff–Hopf 的 Δ 机器）：
   β=0       : 精确取等（λ₂=0，物理退化）
