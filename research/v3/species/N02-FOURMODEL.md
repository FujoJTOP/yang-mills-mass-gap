## 2 四模型的 `Δ_dyn`（逐个算，标签逐条）

### 2.1 自由无质量场 —— `Δ_dyn = 0` **精确** `[T]`

`S=½φᵀAφ`、`Φ=0`。`G=vᵀAφ`（`φ` 的一次型），`H=vᵀAv=:h`（常数）。
Gaussian 测度 `Cov φ=A⁻¹` ⇒ `Var(G)=vᵀA A⁻¹A v=h`。 ⇒ **`Δ_dyn = h − h = 0`，对每个 `k`（含 `k→0`）**。
（等价：Stein/等分律 `E[H]=E[G²]−E[∇·G]`；这是语料 `CAVITY-MEAN-FIELD:21` 的 "`Δ_dyn=0`" 的证明。）
**⇒ 存在式在自由场上为假 ✔（酸测过）。**

### 2.2 2D YM —— `Δ_dyn = 0` **精确**，而 `m = 3g²/8 > 0` `[T]*`

`k→0` 粗模 = 空间圆环上的**常值 holonomy**：取常值 `A₁`、`A₀=0`，则每个 plaquette `U_p = 1` **逐点精确**
⇒ `S_W ≡ 0` 沿整条模线 ⇒ `G = ∂_vS_W ≡ 0`、`H = ∂²_vS_W ≡ 0` ⇒ **`Δ_dyn = E[H]−Var(G) = 0`**，且 `X = −2Cov(G,Φ′)=0`
⇒ `W_full = W_geo`。`m = (g²/2)C₂(½) = 3g²/8`（`g²=1` 时 `0.375 > 0`）。
**⇒ 存在式在 2D YM 上为假，而 `m>0`：`Δ_dyn` 对 `m` 既非充分（见 §3 M6 读法）也非必要。**

**数值旁证（`[E]`，`n02_fourmodel.log` (A)/(A2)）**：SU(2) 单链接 flat chart，`v=e₃`、`‖v‖=1`、`a=0`：

```
β=0.00 : Δ_dyn = 0.000000000   W_geo = 0.820461188   Σ = 0.820461188
β=2.50 : Δ_dyn = 0.589671194   W_geo = 0.756343417   Σ = 1.346014612
独立核验：G″_flat = −d²/da² log ρ_X = 0.820467 (β=0) / 1.346018 (β=2.5)，与 Σ 差 ≤ 6e−6
```
`β=0`（纯 Haar，`S_W≡0`）逐字给出 **`Δ_dyn = 0`** —— 也就是说语料 `β=0` 的 `G″=0.248>0` **整个是 Jacobian**，
这条现在是精确的 `[T]`，不再只是"非动力学"的措辞。

### 2.3 M6 —— 逐模 `Δ_dyn = 2ω > 0`；`∀v` 则 `inf = 0` `[T]`

`ρ_a ∝ e^{−ωa²}` ⇒ `V_eff = −logρ = ωa²` ⇒ `H = 2ω`、`G = 2ωa`（只依赖 `a`，条件化后 `Var(G|a)=0`、`Φ=0`）
⇒ **`Δ_dyn(a) = 2ω`**，与 `G″ = 2ω` 一致（`W_full=0`）。自由方向 `b`：`S≡0` ⇒ **`Δ_dyn(b)=0`**。
故 `inf_{v∈{a,b}} Δ_dyn = 0`。`m_L = min(ω, ½(2π/L)²)`：`L=8→1024` 给 `0.3084→1.88e−5` ⇒ `m=0`。
**⇒ 逐模读法：存在式在 M6 上为真而 `m=0`（靶失明，(b) 触发）；`∀v` 读法：为假（不失明）。**

### 2.4 单 plaquette —— `Δ_dyn` **有定义**（`+0.5897`），`m` 无定义 `[E]`

`a=0, β=2.5`：`Δ_dyn = E[(dS_W/dr)/r] = +0.589671`（`(A2)` 行）。`m` 无 transfer ⇒ 无定义（`T03-TOY.md §1`）。
**⇒ (c) 不成立：`Δ_dyn` 不停在"无定义"，它停在"有值但无对象"。**

## 4 判死线逐条（不许含糊）

- **(a) 不成立（作为等价靶/决战目标）。** `Δ_dyn` 在自由场、M6(`∀v`) 上取 `0`（酸测方向对），但在 **2D YM 上取 `0` 而 `m>0`**
  ⇒ 它是 `m>0` 的**充分形状**（若成立则 `G″≥a²Δ₀²+W_geo>0` ⇒ H1(δ>0) ⇒ 隙），**不是必要条件**。
  把它当"决战靶"就是宣称"2D YM 该给 `>0`"，而它给 `0` —— **这一格判死"等价"读法，不判死"充分"读法。**
- **(b) 触发，但只对逐模读法。** `app.tex:190` 逐字 "uniformly in `(L,a)` and for **every** coarse transverse `v`" ⇒ 量词是 `∀v`
  ⇒ M6 的自由方向 `b` 使 `inf=0` ⇒ M6 一格过。**若把 `Δ₀` 写成"逐模地板"（每个 `v` 各自一个 `Δ₀(v)>0`），靶立刻对 M6 失明。**
  ⇒ 结论不是"(b) 靶死"，而是**"`∀v` 量词是靶的一部分，不能省"**；省掉即失明。
- **(c) 部分成立。** `Δ_dyn` 本身处处有定义（含单 plaquette `+0.5897`）；**无定义的是 `m`**。
  真正的 (c) 是**记账层**：四模型表的 `G″` 是 Haar-归一化，H1 的 `G″` 含 `Φ=−log J`，两者差 `−∂²log J`（`β=0` 时 `0.82`）。
  **任何"`G″=0 ⟹ Δ_dyn = −W_full`"的推理都跨了两个口径，作废。**

## 5 正确的替代靶（给 lead）

1. **`Δ_dyn ≥ a²Δ₀²`（Gate-4）保留，但降格为"充分砖"**，标签从"决战目标"改为 `[C]`+`[M]`（缺 `(L,a)` 一致化 + `Var(G|0)≤1/δ_W`）。
   它的四模型成绩是 `(0,0,0,—)`：**无假阳**（自由场/M6 都取 0），**无必要性**（2D YM 取 0）。作为酸测合格的**充分**判据这是合格成绩。
2. **若需要"过四模型"的判别式**，2D YM 一格要求 `>0`，只有把 `m` 的**整体**内容放进去才拿得到：`σ`（弦张力）、
   Kato 隔离裕量 `Λ★−m₁²`、Hilbert–Schmidt 衰减率 `2λ_bot`（`B05-INVENT.md §3`：三者过四模型，但按 §4 全是 `m` 的单调重标）。
   ⇒ **诚实的写法**：试金石只有 2 bit，**没有任何已知量既过四模型又不是 `m` 的重标**；因此"决战目标"只能是
   **`m>0` 本身 + 扇区/纯性**，`Δ_dyn` 是它的一条**必要强度不足**的充分路径。
3. **2D YM 的机制要写进死路台账**：可解 2D YM 的隙**整个在转移权重（Casimir）里，不在边缘曲率里**
   ⇒ 任何"边缘/条件化曲率"型量在 2D YM 上必给 `0` ⇒ **结构性不可能是必要条件**。这是一条 `[T]` 级的类内 no-go，
   比"没试过"强。
