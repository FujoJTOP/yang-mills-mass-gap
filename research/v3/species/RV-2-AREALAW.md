## §1 面积律扇区的 `G(R,θ)`：弓形面积**相加**

`C_R` = `ℝ⁴` 中某 2-平面内的半径 `R` 圆。弦的两个端点把圆周分成
`L_1 = 2πRθ`、`L_2 = 2πR(1−θ)`，对应中心角 `φ_1 = 2πθ`、`φ_2 = 2π(1−θ) = 2π−φ_1`。

**取的极小面**：两个**平面弓形（circular segment）**，各由「弧 + 弦」张成，都在圆自己的 2-平面内（零平均曲率）。弦是圆盘的测地线，故两段弓形**恰好铺满圆盘**——这正是 `sp-b` 的可加性结论；任何非平面的悬链面型面只会更大，指数权重下不选。

```
A_1 = ½R²(φ_1 − sin φ_1) = ½R²(2πθ − sin 2πθ)
A_2 = ½R²(φ_2 − sin φ_2) = ½R²(2π(1−θ) + sin 2πθ)        [因 sin 2π(1−θ) = −sin 2πθ]
⇒ A_1 + A_2 = ½R²·2π = πR²      （θ 严格掉出）
```

```
G(R,θ) = W(C_1)W(C_2) ≃ exp(−σ(A_1+A_2)) = exp(−σ π R²) = W(C)   [T]
```

**核准（`[V]`，`rv2_arealaw.log` PART 1）**：弓形闭式 vs 直接求积 `∫_{x_0}^{R}2√(R²−x²)dx`（`x_0 = R cos πθ`），400 组 `(R,θ)` 上最大相对差 `5.7e−9`（纯求积尾部，公式精确）；`|A_1+A_2−πR²| ≤ 1.4e−14`；端点值 `θ=0: (0, πR²)`、`θ=½: (πR²/2, πR²/2)` 都对。

> **结论 1 `[T]`**：面积律扇区里 `G ≡ W`，**与 θ 无关**。两变量族对面积律是**盲的**——不是因为 `θ` 被积掉，而是因为 `A_1+A_2 = πR²` 是恒等式。

## §3 代入、判、残差

两侧共享因子 `t_νδ_C` 之后（记账见 §4）：

```
(σ/2)·W(R,θ) = g²N·G(R,θ)      ⇒  ρ(R,θ) := LHS/RHS = (σ/2)W/(g²N G) = σ/(2g²N)
```

由 §1 的 `G ≡ W`：

```
σ = 2g²N·μ²        （μ = 接触项/重合点能标；见 §4 量纲表）
```

**`σ` 与 `R`、`θ` 都无关** ⇒ 在整族上**同一个** `σ` 同时满足。`[T]`

**残差（`[V]`，PART 3）**：`σ=1, g²N=1`、`R∈{1,2,3,5}`、`θ∈{0.1,0.25,0.5,0.75,0.9}` 共 20 点
`ρ ≡ 0.500000000000`，`max/min = 1.000000000000`；`ρ(5)/ρ(1) = 1.000000000000`。
- **`R` 幂次 = 0**，**`θ`-失配 = 0（精确恒等式，不是数值小量）**。
- 不驻 `σ` 时残差是**一个纯数**（`O(1)`），不是函数 ⇒ 没有可调的 `(R,θ)` 结构可修，只有常数槽本身。
- **稳健性（PART 4）**：给 `G` 加次领头前因子 `(1+a/R)`（`a=0.1/1.0`），残差比 `1.078 / 1.667`——仍是 `O(1)`，没有复活 `R`-幂。

## §4 记账表 + 量纲表（硬门槛）

**每个几何因子**（`[M]`：全体只在"`t_νδ_C` 两侧同消"这一条上承重）：

| 因子 | 出处 | 数值 | 量纲 |
|---|---|---|---|
| `½ε_{μν}` | `δA/δσ_{μν} = ½ε_{μν}χ_S` | `½`（`ε₁₂=1`） | — |
| `−σ` | `W=e^{−σA} ⇒ δW=−σW δA` | `σ` | `L^{−2}` |
| `ε_{μν}n_μ = t_ν` | 面内 90° 旋转 | `1` | — |
| `∮dy_νδ⁴(x−y)`，`x=y∈C` | `= t_ν·δ³_⊥(0)` | `1` | `L^{−3}`（含接触项） |
| `g²N` | `(★)` 右端系数 | `1` | `1` |

净：`(σ/2)W = g²N·G·(μ²/1)` ⇒ **常数 = `2g²Nμ²`**；`2 = 1/(½)` 纯来自 `ε` 归一，`μ²` 来自 `δ³_⊥(0)`。

**量纲（逐项，指数制的机器核对，PART 5）**：

```
[W]=L⁰   [A]=L²   [σ]=L^{−2}   [g²N]=L⁰        （4D：g 无量纲、N 是数）
[∂_μ δ/δσ_{μν}] = L^{−1}·L^{−2} = L^{−3}
[g²N ∮dy_ν δ⁴(x−y)] = L⁰·L¹·L^{−4} = L^{−3}      ⇒ 两侧同为 L^{−3} ✓（方程本体自洽）
裸写 σ = 2g²N        : L^{−2} vs L⁰      ⇒ 差 L^{−2}，**不自洽**
σ = 2g²N·μ²（[μ]=L^{−1}）: L^{−2} vs L^{−2}  ⇒ **自洽**；格点 a=1 即 σa²=2g²N
```

## §6 判 + 缺什么

- **`(a)` 成立**：面积律在两变量下**是解**，`σμ² = 2g²N` 在整族上一致 ⇒ **约化保真（第一次）**，`[C]`。不是 `(b)`（残差不长 `R`/`θ` 幂）、不是 `(c)`（`σ` 自洽）。
- **`[T]` 结构定理（这条最要紧）**：因为两侧同为 `t_νδ_C`，**平面扇区的 `(★)` 是逐点代数关系，不含 `∂_R`、`∂_θ`** ⇒ 任何 `W=e^{−σA}` 在平面扇区都通过，`σ` 是唯一槽。循环论证的风险在此：**平面族不检验面积律的函数形式，只检验系数**。
- **所以 `(b)` 的诊断仍待第三个变量**：要真正检验面积律的**函数形式**，需要有**不可加**的切分，即 `A_1+A_2 ≠ A` 的族——**非平面圈**（两段弓形不在同一 2-平面）或**自交点圈**（`fig8-setup` 正在做的那条）。平面圆族里 `A_1+A_2=πR²` 是恒等式，`θ` 永远掉出，故本族**不可能**否证面积律。
- **`[NG]` 仍在**：`σ` 只被钉到 `μ²` 上（`SP-F-LOOPALG §2`：有界非指数解整族、`c` 自由）。**方程给一致，不给标度。** 要标度仍需隙那一步（`[O]`）。
