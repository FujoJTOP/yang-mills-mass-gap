## §1 β=0 锚：四行精确（零 MC）

记 `x_x:=½Re tr U_{□(x)}`、`q_x=1−x_x`；`β=0` 时全部 link i.i.d. Haar（`κ=β/2` 口径无关）。

```
(1.1) 单片： U_p∼Haar ⇒ x∼(2/π)√(1−x²)·1_{[−1,1]}（SU(2) 半圆）⇒ E[x]=0、E[x²]=¼
       ⇒ Var(q)=¼ 精确（Popoviciu 的 sup 是 1，此处不紧）
(1.2) z≠0： 两片同平面 plaquette 至多共 1 条 link，各自另有 ≥3 条自由 link；每片对任一自由
       link 是线性的 ⇒ ⟨x_0x_z⟩=0 ⇒ C_q(z)=1−E[x]−E[x_z]+0 = 0 精确
(1.3) ⇒ C_q(z)=¼δ_{z0}、O_B(0)=N_B^{-1}Σ_{z≠0}n_B(z)·0=0、ϖ(0)=Var(q)+0=¼
(1.4) 一阶： 𝒮=Σ_pP_p=6V−Σ_all u（u:=x）；⟨u³⟩=0（半圆对称）、⟨u_x²u_z⟩=0（z 与 x 共 ≤1 link
       ⇒ 余下自由 link 呈奇次）、⟨u_xu_yu_z⟩=0（x≠y，含 z=x,y）⇒
       ⟨u_x²𝒮⟩=6V·¼=(3/2)V；⟨D𝒮⟩_0=(1/N_B)Σ_x(3/2)V−(3/2)V=0；⟨D⟩_0=0
       ⇒ ∂_βO_B(0)=−Cov_0(D,𝒮)=0 **精确**
```

**读法。** 锚给的是 `O_B(0)=0` 与**驻点**两件；`Δ_E>0` 那一支（`II6`）希望的是「随 β 增」，而锚在一阶上**什么也不说**。⇒ 本路的全部内容必须来自 `[0,2.5]` 上的**全域**单调，而全域单调在 `β→∞` 端反号（§2.4）。**下一手**：要一阶以上的小-β 信息只能算 `a₂`（§6-1）。
