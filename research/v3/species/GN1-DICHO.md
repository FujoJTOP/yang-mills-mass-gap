### 0.2 一句话

**原句把「认识论」写成了「本体论」、把「轨道坐标」写成了「性质坐标」。** 「RT 成员上没有 RP 的**证明**」是真的（`GL1:19` 的引文只支持这一条）；「RT 成员**没有** RP」是假的——自由场有质量完美作用量**就是**连续统 GFF 的边缘测度，因此**是**推前、**有** RP、**且** `Δ_a ≡ m > 0`（`GL1:94,256,269` 三行合起来就是反例本身）。真正成立的「分居」在**第三条轴**上：`R_b` 的**不动点**上 `m_lat = aΔ = 0`（自相似 + `m_lat ↦ b m_lat`，两步，**不用 RP**），而 `RP` 在推前下**前向不变**、在弱极限下**封闭**，`隙` 则**不封闭**（有质量 Gaussian `m_n↓0`，`GK2:66` 逐字「弱极限不保持聚类速率」）。⇒ **RP 过极限、隙不过**：这才是「两侧」，而且两侧不是 RP 与质量，是**极限与有限 `a`**。在 4D 渐近自由里，唯一 UV 不动点是 Gaussian（`FORGE5:11`）⇒ 原句的「有 RP 无质量」那一侧**逐字就是自由场**，也就是 `GL1:269` 自己判成 vacuous 的那一格。

#### (b) `RP ⇒ k₀ ≤ 2` —— **本文件不重判；只判它与 (a) 的关系：正交**

| (b-i) | 状态 | 出处 |

**与 (a) 的关系（本文件唯一要判的事）**：

1. **无蕴含（b ⇒ a）**：`k₀ = 2` 与 `Δ = 0` 共存（Wilson `β→∞` 逼近 Gaussian UV 不动点，`FORGE5:11`），也与 `Δ > 0` 共存（Wilson 任意有限 `β`，`RUN3:51`）。⇒ 「改进阶被封顶在 2」对「有没有质量」**零信息**。

#### (c) `Δ_a ≡ Δ_cont` ⇒ 无质量 —— **结论假；论证是「参数循环」的重述，且它是 (a) 的另一面**

- **结论假**：`Δ_a ≡ m` 而 `m>0` 的族**存在**（自由场完美作用量，`GL1:269`：`|m_eff−m| ≤ 2.386e−11`）。故「`Δ_a ≡ Δ_cont` ⇒ 无质量」不是定理，是误读。
- **论证（`m` 是输入）真，但它的内容是 proof-theoretic 的**：`Δ_a ≡ const` 逐字等于「这条线是 `R_b` 的一条轨道」（D3：`Δ` 沿轨道不变）。所以「沿线 `Δ_a = m`」不可能是 `m>0` 的**证明**，只可能是 `m` 的**转录**。这就是 `GL1:161–169` 的 `(b3)`，也是 `GK4:179`、`B01:123` 的同型循环。
- **它是 (a) 的另一面，不是第三读法**：a1 说「不动点处 `m_lat=0`」，(c) 说「轨道上 `Δ=m` 是标号」。两句合起来 = **质量是轨道的坐标，不动点是坐标零点**。⇒ 「分居」若指这个，则它成立且平凡；原句把它写成「RP vs 质量」才是那一步越界。

(ii) 弱极限封闭：设 `μ_n` RP、`μ_n ⇀ μ`。对任意有界连续 `F` 支撑在半格，`∫FΘF dμ_n ≥ 0` 且 `FΘF` 有界连续 ⇒ `∫FΘF dμ ≥ 0`。∎（这一步是 PF 之外的**独立**一条：`GL1:95` 把它记在「迭代 + 弱极限」项下，但等级要分清——**封闭性 `[T]`，极限点存在性 `[C]`**，`GL1:343` 的诚实边界说的正是后者。）

**(T2) 隙不是弱极限封闭量 `[T]`.**
取有质量 Gaussian 族 `m_n ↓ 0`（格点、周期、任意维）：每个 `μ_n` RP（Gaussian 测度的 RP 是标准件，`B01:93` 的机检 `−3.6e−11 / −1.3e−17` 机器零即 PSD），`Δ_n = m_n > 0`，而 `μ_∞` 是无质量 Gaussian，`Δ_∞ = 0`。⇒ **`Δ_n` 沿序列恒 `>0`，其极限却是 `0`**：隙不是弱极限封闭量。仓内已有逐字同一句：`GK2-TOWER.md:66` 记 `GL4Transfer.lean:30`「**弱极限不保持聚类速率**（massive Gaussian `m_n→0`）」`[T]`。

**(T3) 不动点 ⇒ `Δ = 0` `[T]`（两行，不用 RP）.**
设 `μ_{a*}` 是 `R_b` 的不动点（D4：无量纲测度自相似），`b>1`。由 D2，`m_lat(ba) = b·m_lat(a)`；由 D4，无量纲量不变 ⇒ `m_lat(ba) = m_lat(a)`。相减得 `(b−1)m_lat = 0` ⇒ `m_lat = 0` ⇒ `Δ = 0`（`a>0`）。
*排除 `Δ=∞` 一支*：`m_lat = ∞` 意味着 `λ₂(T_a)=0`（时间方向秩 1 / 无传播）。连续极限要求 `ξ/a → ∞`，而 `m_lat = a/ξ` ⇒ `m_lat → 0`；故**支配连续极限的那个不动点**不可能落在 `∞` 支上。（这一句是本文件补的窗口条件，`GL1:109` 只写了 `Δ_cont=0`。）

**(T4) 推论：`0 < Δ < ∞` ⇒ 不在不动点上 `[T]`.** 由 T3 逆否。

**(T5) 推论（真正的「分居」）`[T]`+`[C]`.**
沿 `R_b` 迭代取极限：RP 存活（T1），隙不存活（T2）。**故「不动点」正是「隙被极限杀死」的那个点。** 若要 `Δ_cont > 0`，它只能作为**有限 `a` 上的一致地板**被证明，不能作为极限点的性质被读出。
`[C]` 的部分：该不动点**作为迭代极限点存在**（tightness / 紧性），`GL1:95,343` 明记这是输入而非结论。

**⇒ 精确命题 GN1-P（本文件交出的）**：

> 设 `R_b = (Π_b)_*` 为 θ-协变块化，`Δ` 为物理隙（D1），`m_lat = aΔ`（D2）。
