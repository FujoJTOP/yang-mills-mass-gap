## §4.5 类外判据 C1（`GH1c`，`[T]`）

**先纠一处直觉**：「`SG1-1` 杀连续泛函 ⇒ 逃到 `lsc`」**是错的**。`lsc` 是**第二个封闭类**：

> `INEQ-R5:9` forcing lemma：若 `Ψ` 是 `lsc` 且在薄原子族上逐点满足 `Ψ ≤ f₁²`，则把边原子换成 `1/n`-bump 得 `Ψ ≤ 0`。
> ⇒ **任何 lsc 的、逐点压住原子的泛函恒 `≤ 0`。** `[T]`

于是"类外"必须写成下面前两条之一（`[T]`，任一即可），**不能**写成"非弱-* 连续"（`lsc` 而非连续者遍地，而 `lsc` 正是被砍的那类 ⇒ 既不充分也不必要）：

**C1(a) 不是泛函**：`Q` 的定义域含 `𝒫` 外的结构（算子 / 场 / 族）⇒ `SG1-1` 与 forcing lemma **都不可陈述**。
**C1(b) 不是 minorant**：在薄原子族 `ν_ε = εδ_{m²} + (1−ε)δ_Λ` 上 `Q(ν_ε) ↛ 0` 而 `f₁² = ε → 0` ⇒ `Q ≰ f₁²` ⇒ 刀砍不到。

**附带的一个分离（`[T]`，初等）**：同一薄原子族上 `f₁² = ε → 0` 而 `Δ = Λ − m²` **不变** ⇒ **"隙"与"原子权重"在该族上正交** ⇒ **能生产「隙」的技术不必能生产「原子」**。这把两个目标分开记账（不裁决 `CLAUDE.md §5` 与 `INEQ-R5:13` 的冲突）。

**两条最有希望、且都过 C1 的线（`GH1c §0.2`）**：
- **① Kato 谱半连续 + Birman–Schwinger**（过 C1(a)(b)）：给"`(c,c+δ)` 内无谱"与隙的搬运；**断点** = 它要的 norm-resolvent 一致性正是 H1 的另一半，而 `a→0` 时族活在不同 Hilbert 空间（`a=0` 无成员）⇒ 只可能拿到强-resolvent；且 min–max 只给 `λ₁` 的 **usc** ⇒ 地板必须**作为输入**进来 ⇒ 循环。
