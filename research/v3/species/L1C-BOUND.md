## 0. 裁决（三句）

1. **类型判（第一问，必须先判）**：这不是"矩阵元 vs 范数"的量纲对立，而是**依赖集对立**。
   `‖Π⊥Hφ₁‖` 只依赖 `(H, φ₁)`；`f₁²=|⟨Ω|O|𝔾⟩|²` 依赖 `O`。`O` 是自由输入 ⇒ **无一般代数关系**。
   另有一处**归一**必须先钉：`1−f₁²` 只在 `M₀:=∫dν ≡ 1` 时无量纲；一般情形正确的无量纲对象是**原子分数** `f₁²/M₀`（`A1-SUMRULE-A.md:166`：`f₁²∈[0,M₀]`；`A2-SUMRULE-CONDENSATE.md:42–43`：ch05 的 `f₁²` 带质量量纲 2）。本文件的界一律写成 `1−f₁²/M₀`。
2. **候选判**：`(i)` 方差式是**恒等式**（Pythagoras），与 `f₁²` 无关 `[T]`；`(ii)` 逐字式 **假**（`Π⊥φ₁≡0` ⇒ 右端恒 `0`）；`(iii)` 真界存在：`‖Π⊥Hφ₁‖² ≤ (‖H‖+m₀)²(1−f₁²/M₀)` `[T]`，**证明两行**，但需要识别 `φ₁ ∝ (1−P_Ω)OΩ`。
3. **线路判**：**`(c)` 空/循环**。`I1`（P3）给的是 `f₁² ≥ r₀>0` 的**下界**；本不等式要的是 `1−f₁²/M₀ → 0`，即"单态占据"，是**上界型**且严格更强的陈述；而 `β<1/48` 处 `f₁²∼β²/4≈1.1e-4` ⇒ RHS 取最大 ⇒ 不等式成立但**零内容**。第二步"`φ₁`≈本征向量 ⇒ 隙开"独立失效（要 bulk 谱底，`=I2` 的 bulk 半边）。

## 2. 三个候选逐条

### 2.1 `(i)` 方差式 —— 是**恒等式**，不是界 `[T]`

```
‖Π⊥Hφ₁‖² = ‖Hφ₁‖² − |⟨φ₁|Hφ₁⟩|²        (2.1)
```
**证明（Pythagoras，无自伴性要求）**：`Hφ₁ = ⟨φ₁|Hφ₁⟩φ₁ + Π⊥Hφ₁`，两项正交 ⇒ 取范数平方即得。∎
**读法**：`(2.1)` 是 `H` 在 `φ₁` 上的**二阶中心矩**（自伴时即方差）。它**不含 `O`、不含 `f₁²`**，所以把它列为"候选严格界"是记法错误：它是对 LHS 的**改写**，对 LHS 的**上界**没有任何信息。

### 2.2 `(ii)` `‖Π⊥Hφ₁‖ ≤ ‖Hφ₁‖·‖Π⊥φ₁‖` —— **假** `[T]`

同取 `Π⊥ = 1−|φ₁⟩⟨φ₁|`、`‖φ₁‖=1`：
```
Π⊥φ₁ = φ₁ − φ₁⟨φ₁|φ₁⟩ = 0        ⇒ 右端 ≡ 0     (2.2)
```
⇒ `(2.2)` 声称 `‖Π⊥Hφ₁‖ ≤ 0`，即"`φ₁` 恒为本征向量"。这是把要证的东西写成了不等式。
**形式相似的真命题**（这是 `(ii)` 唯一该活成的样子）：把**右**投影换成真底的投影，
```
‖(1−P_𝔾)Hφ₁‖ ≤ ‖H‖·‖(1−P_𝔾)φ₁‖        (2.3)
```
**证明**：`P_𝔾H = E_𝔾P_𝔾 ⇒ (1−P_𝔾)HP_𝔾 = 0 ⇒ (1−P_𝔾)Hφ₁ = (1−P_𝔾)H(1−P_𝔾)φ₁`，再取范数。∎
`(2.3)` 才是"投影界"的正确形态，且它的右端是**波函数亏损** `‖(1−P_𝔾)φ₁‖`，不是残数亏损。

### 2.3 `(iii)` 用 `f₁²` 的亏损 —— **需要且只需要一个识别**，然后两行证完 `[T]`

**(R) 识别（这是全文件的唯一新输入，也是唯一可能的桥）**
```
φ₁ := (1−P_Ω)OΩ / ‖(1−P_Ω)OΩ‖          (R)
```
即"**单算子试验态**"：`0⁺⁺` 道里由 `O` 直接生成的向量。此时
```
|⟨𝔾|φ₁⟩|² = f₁²/M₀                       (2.4)
```
（`⟨𝔾|O|Ω⟩` 就是 `f₁²` 的幅度，分母 `M₀` 是 `OΩ` 在 `1−P_Ω` 上的范数平方。）
`⇒ ‖(1−P_𝔾)φ₁‖² = 1 − |⟨𝔾|φ₁⟩|² = 1 − f₁²/M₀`。**这正是"残数亏损 = 波函数亏损"的全部内容。**

**定理 `[T]`（识别 (R) 下，`H` 自伴、`‖H‖<∞`、`E_𝔾=m₀`）**
```
‖Π⊥Hφ₁‖²  ≤  (‖H‖ + m₀)² · (1 − f₁²/M₀)                                    (2.5)
```
**证明（两行）**。记 `u=φ₁`、`P=P_𝔾`、`δ:=‖(1−P)u‖`。由 `PHu = m₀⟨𝔾|u⟩𝔾` 与 `P` 正交，
```
Hu − m₀u = (1−P)Hu − m₀(1−P)u ,   ‖(1−P)Hu‖ = ‖(1−P)H(1−P)u‖ ≤ ‖H‖δ
⇒ ‖Hu − m₀u‖ ≤ (‖H‖+m₀)δ .
```
又 `Π⊥ = 1−|u⟩⟨u|` 是压缩 ⇒ `‖Π⊥Hu‖ = ‖Π⊥(Hu−m₀u)‖ ≤ ‖Hu−m₀u‖`。代入 `δ²=1−f₁²/M₀`（式 `(2.4)`）即得 `(2.5)`。∎

**要点（必须写清，否则会被误用）**
- `(2.5)` 的**左端用 `Π⊥`（投影掉 `φ₁` 自己）**，右端是**原子分数亏损**——这正是 `N11` 要的形状 `(II)`，`θ=1/2`、`C=(‖H‖+m₀)²`。`[T]`
- `(2.5)` **不需要隙**、不需要 `I2`、不需要 KL 表示——只用 `P_𝔾`（`𝔾` 无简并即可；简并时把 `P_𝔾` 换成该本征空间的投影，`m₀` 同一，仍成立）。
- `(2.5)` 的**全部内容住在识别 (R) 里**：`(R)` 是定义，不是定理。若 `φ₁` 由别的变分程序（GEVP/Ritz）给出，(2.4) 不成立，`(2.5)` 无从落笔 —— 见 §3。

## 3. 缺识别 `(R)` 时：原式**假**（两个独立反例）

### 3.1 2×2 显式反例 `[T]`
```
H = diag(0,1) ,  Ω=e₀ ,  𝔾=e₁ ,  O = |e₁⟩⟨e₀| + |e₀⟩⟨e₁| ,  ‖O‖=1
⇒ f₁² = |⟨𝔾|O|Ω⟩|² = 1 ,   M₀ = ‖OΩ‖² = 1 ⇒ 1 − f₁²/M₀ = 0
φ₁ = (e₀+e₁)/√2  ⇒  Π⊥Hφ₁ = (e₁−e₀)/(2√2) ,  ‖Π⊥Hφ₁‖² = 1/4 = ‖H‖²/4
```
⇒ `1/4 ≤ C·0` 对任何 `C` 都假：**`f₁²/M₀=1` 与"`φ₁` 离任何本征向量最远"完全相容**。
`f₁²→1` 是关于 `O` 的陈述，**不是**关于 `φ₁` 的陈述。`[T]`

### 3.2 语料自带反例（双井）`[T]`
`R-WAVE-SYNTHESIS.md:46,126`：「double well: `O(1)` residue, gap `→0`, but `χ→∞`」。
即 `f₁²=O(1)`（`1−f₁²` 小）与"无隙"同时成立；在该模型里对称化试验向量与反对称态只差 `o(1)` ⇒ `‖Π⊥Hφ₁‖ = O(1)`。
⇒ `(II)` 的原形（不带 (R)）在本语料已记录的可解模型上**假**。

## 4. 为什么作为**线路**仍然是死的：定量惰性（不是逻辑，是数值）

`(2.5)` 的右端是 `(‖H‖+m₀)²·(1−f₁²/M₀)`。要让 `(II)` 有内容，必须 `1−f₁²/M₀ ≪ 1`。**在 `f₁²` 有 `[T]` 的唯一窗口里，这恰好最不成立**：

| 窗口 | `f₁²` 状态 | `1−f₁²/M₀` | `(2.5)` 的效力 |
|---|---|---|---|
| `β<1/48` | `f₁² ≥ r₀>0` `[T]`（P3）；且 `f₁² ∼ r² ∼ β²/4` `[C]`（读数自 `R1-RESIDUE-TRANSPORT.md:149`） | `≥1−1.1e-4`（`β=1/48`：`r=β/2` ⇒ `f₁²≲(1/96)²`） | **等同平凡界**，零内容 |
| `β=2.5` | 只有 `[E]`：pilot `C₁/C₀≈0.18–0.29`（`R-WAVE-SYNTHESIS.md:44`/R4） | `≈0.7–0.8` | 仍只给 `‖Γ‖² ≲ 0.8(‖H‖+m₀)²`，与 `‖Γ‖²≤‖H‖²` 同阶 |
| `f₁²→1` | **无处证**，且见下 | `→0` 才有效 | 需"单态占据" |

**"单态占据"是什么类型的陈述**：`1−f₁²/M₀→0` 即 `ν = f₁²δ_{m₁²}+o(M₀)`，即 `O` 的**全部**谱重压在单个原子上。它比 P3 的 `f₁²≥r₀` **强一个量级**（P3 只给 `f₁²>0`），且方向相反：语料已证一切矩/正性/Christoffel/Hankel/Stieltjes/预解式/迹泛函对该类对象只给**上界**（`A1-SUMRULE-A.md:139–147`、`H08-Z1.md:20`、`Q6-H1-STATUS.md:215–216`）——上界给的是 `f₁² ≤` 某量，**压不出** `f₁² ≥ M₀−ε`。⇒ `(II)` 的输入属于语料明确判为"该类工具缺席"的物种。`[T]`（关于工具类的 no-go）

**另一个更强的否证**：`(2.5)` 的右端随 `f₁²` **递减**，而 §2.3 的推导同时给出
```
‖(1−P_𝔾)Hφ₁‖² ≤ ‖H‖²(1−f₁²/M₀)   与   |⟨𝔾|O|Ω⟩|² + Σ_{n≥2}|⟨n|O|Ω⟩|² 全部 = M₀ − f₁²
```
即 `f₁²→1` 强制 `L₂:=Σ_{n≥2}|⟨n|O|Ω⟩|² → 0`（`O` 无高于 `𝔾` 的漏重）。这正是"单态占据"，同名同物。`[T]`

## 5. 第二步独立失效：`‖Γ‖→0` **不**蕴含隙开（要 bulk 谱底）

`N11-FALLBACK.md:44` 的 Feshbach 已逐字给出：
```
I2@δ  ⟺  Π⊥(H−m₀²−δ)Π⊥ − Γ*(δ)Γ(δ)/(…) ≻ 0
```
小 `‖Γ‖` 只有在 `Π⊥HΠ⊥ ≥ m₀²+δ`（bulk 谱底）**已知**时才推出 `I2`。⇒ "`‖Π⊥Hφ₁‖→0 ⇒ 隙开`"**缺的正是 bulk 谱底**，而 bulk 谱底就是 `I2`（乃至 `H*`）本身。`[T]`（逻辑）
⇒ 即便 `(II)` 成立且 `1−f₁²→0` 被证，得到的也只是"`I2` `⟺` bulk 谱底"这一**归约**，不是隙。
⇒ `LOOP-RUNBOOK.md:10127` 的"Feshbach ⇒ H1"已判过同一件事（`MG-META:107`：两区块/Feshbach 归约 ⇒ 归约到 H1，证书本身零内容）。

## 7. 路径（本轮的净结论）

1. **保留 `(2.5)`，降级为记账恒等式 `[T]`**：`‖Π⊥Hφ₁‖² ≤ (‖H‖+m₀)²(1−f₁²/M₀)`，**前提是把 `φ₁` 定义为 `(1−P_Ω)OΩ` 归一**（识别 (R)）。此后任何"把 `f₁²` 搬到 `β=2.5`"的论证都必须先声明它用的是 `(R)` 态，不是 GEVP/Ritz 态；两者不可换。
2. **`(II)` 不能当机器**：它把 `I2` 削成**两条独立输入**
   ```
   (B) bulk 谱底： Π⊥HΠ⊥ ≥ m₀² + δ            ← 与残数无关
   (S) 单态占据： 1 − f₁²/M₀ → 0 (‖·‖=M₀−f₁²→0) ← 比任何 floor 强，矩/正性类工具缺席
   ```
   合成即 `I2`；两条都不蕴含对方（§3.1：`(S)` 真而 `(B)` 可假；2D：`(B)` 真而 `(S)` 假到 `f₁²≡0`）。
3. **一击判死的探针（省时，优先做）**：`β=2.5`、`L=8,12`、`0⁺⁺`、`O=trF²`，测 `C₁/C₀` 的**β-趋势**。现有 pilot `0.18–0.29`（`R-WAVE-SYNTHESIS.md:44`）远离 1；若 `β=2.2→2.5→2.8` 上 `C₁/C₀` **不趋 1**，则 `(S)` 假 ⇒ `(II)` 的右端永不为小 ⇒ **L1 整线 `[NG]` 关闭**（`N11-FALLBACK.md:52` 已把这条写成止损判据，本文件给出它为什么是**唯一**的止损点）。
4. **要救 `I2` 只剩一条不经过残数的路**：给 `Γ` 一个**不来自 `f₁²`** 的小性来源（对称性/Perron 正性/能量亏损残差），且必须同时给 bulk 谱底。这是新物种，不是 `(II)` 的修补。`[C]`
