## 2. `δ²λ` 的下界：**没有**；有界的是复合账本

### 2.1 精确式（二阶微扰论，`X=diag(λ)`）

```
δλ_i = W_ii,    δ²λ_i = 2 Σ_{k≠i} |W_ik|²/(λ_i − λ_k),    W = U†vU
⇒ Σ_i δ²λ_i = δ²tr X = 0 ,   δ²λ_max ≥ 0 ≥ δ²λ_min
```

### 2.2 没有与间隙无关的下界（`[T]` + `[C]`）

三能级 `λ=(Δ,0,−Δ)`、`v` 纯非对角（`log [4]`）：

| `Δ` | `min_v δ²λ/⟨v,v⟩` | `−1/(2Δ)` | `max_v` |
|---|---|---|---|
| `1` | `−5.000×10⁻¹` | `−5.000×10⁻¹` | `+5.000×10⁻¹` |
| `10⁻²` | `−5.000×10¹` | `−5.000×10¹` | `+5.000×10¹` |
| `10⁻⁴` | `−5.000×10³` | `−5.000×10³` | `+5.000×10³` |

⇒ **`δ²λ` 无下界**：`δ²λ_i ≥ −2‖P_i v‖²/Δ_i`，`Δ_i = min_{k≠i}|λ_i−λ_k|`，`Δ_i→0` 时 `→−∞`。**`g'>0` 而 `δ²λ<0` 是真实现象（中间能级）。**

### 2.3 但 `g'·δ²λ` 不爆（这就是 `o09` 的 `g'≥0` 论证缺的那一半其实是可救的）

对每一对 `(i,k)` 的账本（`[T]`，`log [4]` 末两行）：

```
系数( |v_ik|² ) = (2/λ_ik)(w_i − w_k),  w_i := Σ_{j≠i} g'(λ_i−λ_j)
              = 4 g'(d_ik)/d_ik  +  cross(三重)
g'(d)/d = 1/6 + d²/360 + …  ≥ 1/6   ⇒  d→0 时该系数 → 4/6 = 2/3，有限
```

**`N=2` 纯非对角（`u=0`）精确检验**：`Φ''= g'(d)/d`，`δ²λ_− = −1/(2d)`，`g'δ²λ_− → −1/12`，而 `g''` 项为 `0` ⇒ 总和 `→ 1/6 = N/12`（`O06` 的 `inf Φ''=1/6` 同一数）。
⇒ **正确的对象不是 `δ²λ` 的独立下界，而是"`g''` 项 + `g'` 项"的成对账本**（§3 给出全局版）。

## 3. 定理（本文件的新东西）：`Φ'' ≥ (N/12)⟨v,v⟩` 对**所有** `X`、**所有**方向

```
h(X) := Φ(X) − (N/12)·tr X² = Σ_{i<j} φ(λ_i−λ_j),    φ(d) := g(d) − d²/12
```
`Σ_{i<j}(λ_i−λ_j)² = N·tr X²`（无迹）⇒ 二次部分恰为 `(N/12)tr X²`，其 Hessian 就是 `(N/6)tr(·)²`，即 `N/12` 在 `⟨v,v⟩=1` 下的地板。于是

```
Hess Φ ⪰ (N/12)·Id    ⟺    Hess h ⪰ 0    ⟺    φ 凸
φ'' = g'' − 1/6 ≥ 0    ⇒ φ 凸（且偶，φ(0)=φ'(0)=0，φ≥0）
F(λ) := Σ_{i<j}φ(λ_i−λ_j) 对称、凸（凸函数与线性映射的复合之和）
⇒ 谱函数 X ↦ F(λ(X)) 在 Hermitian 矩阵上凸（Davis 1957）
⇒ Hess Φ ⪰ (N/6)tr(·)²  即   Φ''(X;v) ≥ (N/12)⟨v,v⟩   对 flat chart 内所有 X, v
```

- **这是 `[T]`**，条件只有两条：(i) `g''≥1/6`（一行微积分，`O09 §1` `[T]`）；(ii) Davis 的对称凸谱函数定理。**文献核验等级：题录级**（C. Davis, *All convex invariant functions of hermitian matrices*, Arch. Math. 8 (1957) 276–278, DOI `10.1007/BF01898787`）——**未逐字核正文**（`AGENTS.md §3`）。等价的初等路子是 `N=2` 的手算（§4.1），已做。
- **`o09` 的 `Φ''⪰0` 是它的弱化版**（`o09 §7.5` 自认 `δ²λ` 项未写成定理）；本文件把 `δ²λ` 项**整块吸收**掉，得到的是**锐常数 `N/12`**，不是 `0`。
- **`Φ` 逐 link 可加**（`Φ=Σ_ℓ Φ_ℓ(X_ℓ)`）⇒ 对多 link 方向 `Φ'' ≥ (N/12)Σ_ℓ⟨v_ℓ,v_ℓ⟩ = (N/12)‖v‖²`。**这就是"全方向可用"的确切含义。**

## 4. `c` 的值

### 4.1 点态（最强形式，`a₀ := ⟨v̂,X⟩`）

`N=2` 精确（`O09 §1` 的径向公式，`u=⟨v̂,X̂⟩`，`ρ=|X|`）：

```
Φ'' − 1/6 = ρ²[u²/120 + (1−u²)/360] = ρ²/360 + a₀²/180  ≥ a₀²/120   (用 ρ² ≥ a₀²)
⇒ Φ''(X;v) ≥ N/12 + a₀²/120      (N=2, 精确, [T])
```
`ρ = a₀`（`v` 与 `X` 对齐）时取到 `1/120`。一般 `N`：Cartan 对齐方向给 `(1/120)·Σd⁴/|X|⁴`，`N=3` 等间距 `= 0.009375`、`N=4` 随机谱 `= 0.00834`；扫描极小 `±1%` 内都是 `1/120`（`log [5]`：`N=2:0.00833386 / N=3:0.00937533 / N=4:0.00834367`）。
⇒ **`c_p = 1/120` 可作通用点态常数**（`N=2` `[T]`；`N≥3` `[C]` + 对齐方向的 `[C]` 闭式）。
