## §3 T2 — 组合链：最长的一条，与每条链的唯一缺口

五条链，逐链标 `已证 / 已知在 4D 成立 / 缺`。`✓T` = 已证，`✓4` = 4D 已知（可作前件），`✗` = 缺。

### 链 I — 禁闭链：面积律 → 胶球隙（**缺口唯一**的最长链）
```
A₁  σ>0，L-一致（面积律）
 ├─e₁ ✓T  V(R) ≥ σR                                    [行1；Wilson/OS'78，一行谱表示]
 ├─e₂ ✓T  E(R) ≥ σR：由 W_R 生成的循环子空间底 ≥ σR      [行2；严格]
 ├─e₃ ✗   ★扇区转移★  q≠0(1-形式带电) → q=0(0-形式中性)  [行3：运动学被荷分级排除；动力仅行4]
 ├─e₄ ✓T  中性道 KL：inf supp ν_{trF²} > 0 ⟹ B_gap       [行8 的正向；RP + KL]
 └─ B_gap = Clay
```
**长度 4，已证 3，缺 1。唯一缺口 `e₃`。**
`e₃` 的精确形态（这是本清单最重要的一句）：
> **`e₃` 不是"没找到证明的引理"，而是"类型不对"**：`e₁,e₂` 的结论是**带电扇区的率**，
> `e₄` 消费的是**中性道的谱测度**；两者之间没有任何已知的、只依赖 `(σ, 弦谱)` 数据的泛函。
> 唯一已知的动力实现（行 4）是**同一个聚合物权重 `u` 的两次读数**：`σ=−(1/a²)ln u+O(u)`、
> `m₁=4ln(1/u)/a` ⇒ `m₁/√σ=4√(ln(1/u))≥4`。**这就是"桥"的全部内容：`u`-同一性。**
