## §1 `k` 的域与极限方向

1. **块层读法（定义式）**：`∀Λ∀L∀a∀b̂∀k∈{0,…,K̂}: Z_O(k):=[Z_a(k_*)/Z_a(k)]^{1/2}`，`a_k:=b^k a≤b̂`，`K̂:=max{k:a_k≤b̂}`，`k_*=0`（`HZ6-ZDEF.md:41,43`）。⇒ `k` 是**离散有限索引**；`K̂=log_b(b̂/a)` 随 `a→0` 发散（`II8-WIN.md:36`）⇒ 只有 `a→0` 时才有 `k→∞`。
2. **UV 读法**：`k=1/a`，`L` 固定、`β=β(a)` 沿方案 C 塔（`HZ7-ZCONV.md:23`；`HZ9-FINAL.md:55`）⇒ `k→∞` 即 `a→0`。
3. 两读法只差重参数化 `k ↔ log_b(1/a)` ⇒ **都指向 `k→∞`，无 `k→` 有限值的语义**；`k_*` 是锚（`Z_O(k_*)≡1`，`HZ6:46`），不进极限。
4. **名撞提醒**：`K̂` 本仓两义——块层上界（`HZ6:43`）与 KP 合并常数（`C06-WINDOW.md:118`）。引用必带行号。
5. **下一手**：台账统一写 `k↦a_k=b^k a`、`K̂→∞ ⟺ a→0`；`k` 只当离散指标（用差分/序列单调，不用导数判据）。

## §3 判定

**裁决（`[NG]`）**：`k`-极限的**存在性给不出**自单调 / 有界论证。两端都被精确钉住——
- 单调半 `[T]`、有界半 `[NG]`（`HZ7:43`）⇒ 单调收敛定理落在 `+∞`，给不出实数极限；
- 强行归一化使之有界，落点必是 `0`（吸收点，`R1:218`），那是归一化恒真、不是值；
- 中间那个「有限非零值」被 AF 精确排除（`HZ7:61`：⟺ `γ_O≡0` ⟺ 无 AF ⟺ 与 `b₀>0` 冲突）。

**前三步**：
1. **钉对象**：`(V)` 方差 / `(N)` 归一化 / `(R)` 算符重整，三选一之后才谈单调（`HZD:12`；`CLAY-PROOF-CHAIN.html:262`）。
2. **钉 `k`**：`k=1/a` 沿方案 C 塔、`L` 固定、`k→∞`（`HZ7:23`；`HZ9:55`）；`k` 有限值处不出极限语句。
3. **换命题**：不问「有没有极限」，改问恒等式 `Z_O(k)/Z_O(k₀)=(β/2g)(k₀)/(β/2g)(k)`（`HZ7:52` S8）+ 一圈系数 `2b₀g²(μ₀)`（`HZ7:53` S9）——`(U2)` 唯一可写的形。

**下一手（本文件出口）**：`(U2)` 台账词条由「`Z_O(k)` 的 `k`-极限存在」改为「对象识别 `(R)` + 两标度比 + 一圈系数」；`L3` 的承重格仍只在 `(Z-last)` 的**值**（`HZ9-FINAL.md:35`），本文件不动它、不提级。
