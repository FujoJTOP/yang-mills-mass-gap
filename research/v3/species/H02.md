## 0 · 结论（三行，不美化）

1. **构造**（`[T]`，`ch02-squeeze.tex:111–128` `prop:thinatom`）：`ν_ε = wδ_ε + (1−w)δ_{s₂}`，`w=ε/(2λ)`，`s₂=2λ(1−w)` ⇒ `χ = w/ε + (1−w)/s₂ = 1/(2λ)+1/(2λ) = 1/λ` **取等**，`M₀=1`，`inf supp ν = ε → 0`。**薄**就在 `w ∝ ε`：轻原子的 `ε⁻¹` 发散被 `∝ε` 的权重精确抵消。
2. **是否满足完整 `H1`？** ——**在 `H1` 被陈述的那一层（测度层）满足，且是取等式的满满足**：`χ ≤ 1/λ` ✓、`M₀` 固定 ✓、概率测度 ✓、对**任意** `λ>0`、**任意** `ε∈(0,ε₀)` ✓、且 `{ν_ε}_ε` 对 `χ` 与 `M₀` **一致**（同一个 `λ`），故连「一致性」这一条也不需要牺牲。**只有一处不满足：可容许性/载体**——它不是已证明的「`β=2.5` 格点族在指定载体上的 KL 测度」。
3. **判**：**(a) 在测度层成立 + (b) 在物理层成立，缺的条款 = 「可容许性（嵌入）∧ 载体指定」，不是 `(L,a)` 一致性。** 而真正要记的是：`H1 ⇒ m>0` **本来就不是**「唯一未否掉的环节」——语料的充分对是 `I1 ∧ H1 ⇒ m₁² ≥ f₁²/χ ≥ r₀λ > 0`（`[T]`，一行），thin atom **正好违反 `I1`**（`f₁² = ε/(2λ)→0`）。⇒ **thin atom 的杀伤半径 = 去掉 `I1` 的那条捷径；它分毫不动 `H* ⇒ 隙`。**

## 2 · ★ thin atom 的精确构造（`[T]` + 本轮 `[E]`）

**命题（`ch02-squeeze.tex:112–127`，逐字结构）**：固定任意 `λ>0`、任意 `M₀>0`（归一 `M₀=1`）。取

```
ν_ε = w δ_ε + (1−w) δ_{s₂},      w = ε/(2λ),      s₂ = 2λ(1−w),      0<ε<ε₀(λ,M₀)
⇒  χ := ∫₀^∞ s⁻¹ dν = w/ε + (1−w)/s₂ = 1/(2λ) + 1/(2λ) = 1/λ        （取等）
   M₀(ν) = 1        inf supp ν = ε → 0        f₁² = ν({ε}) = w = ε/(2λ) → 0
```

**机检（`[E]`，本轮实跑，精确分数，脚本临时、已删）**：`λ ∈ {1, 1/2, 3}` × `ε = 1e−1…1e−6`（18 组）
**全部** `χ = 1/λ` **精确取等**（不是数值近似）；`f₁² = ε/(2λ)`；`s₂ = 2λ(1−w)`。
**加严版（不等号留余量，堵「卡在约束边界不算」这个可能反驳）**：取 `s₂ = 4λ` ⇒ `χ = 5999999/8000000 < 1/λ = 1`（`ε=1e−6, λ=1`），余量 `2000001/8000000`。
⇒ **没有任何 `δ>0` 使 `m₁² = inf supp ≥ δ` 一致成立**，而 `χ ≤ 1/λ` 一致成立。

**机制一句话（`[T]`）**：`χ` 是**残数加权调和平均**（`ch02:107–109` "The susceptibility sees the *residue-weighted* mass, not the lightest mass"）。轻原子只要带 `∝ε` 的权重，就对 `χ` 无贡献；而 `m₁²` 由**最轻的支撑点**给。⇒ `χ` 的**上界**（一个矩泛函的上界）在结构上不可能逼出**支撑下界**（"upper-bound machine, lower-bound target" mismatch，`ch02:139–141` `[T]`）。

## 4 · 判：thin atom 杀到哪里？（(a)/(b)/(c) 三条全答）

### 4.1 逐条判死线

- **(a) —— 在测度层成立 ⇒ `H1 ⇒ m>0` 是假的。**`[T]`+`[E]`
  并且它杀得**比 `m>0` 更宽**：`H1 ⇏ (m₁²≥δ)`（任意 `δ`）、`H1 ⇏ (f₁²≥r₀)`（任意 `r₀>0`）、`H1 ⇏ clustering-rate 一致下界`。
  唯一的"独一环节"确实断了——**如果那环节真是「`H1` 单独」**。

- **(b) —— 在物理层成立：缺的条款 = ⑦「可容许性/嵌入（`ν` 是 `μ_{L,a,β=2.5}` 的 KL 测度）」∧ ⑧「载体指定（不空真且规范不变）」**；`H1'` 的候选正是这**两条**。
  **但要点明**：这两条一旦加上，`H1'` 就不再是"一个矩泛函的上界"，而变成"关于真实 YM 谱测度的命题"——即**离 Clay 本身只有一步**（`Q6:265–290` 已把它叫 `H*`）。所以 `H1'` 不是"救回 `H1`"，是**取消 `H1` 作为独立中间量的地位**。

- **(c) —— 构造不清？不成立。**`[T]`：构造是闭式、四行、精确取等，本轮 `[E]` 独立复算 18 组无一例外；`ch02:123–126` 有完整 `proofx`。**构造不清这一条不触发。**

### 4.2 ★ 但判死线之外有一句更重要的话：**`H1 ⇒ m>0` 从来不是"唯一未否掉的环节"**

语料的**充分对**是（`Q6-H1-STATUS.md:96`，`ch02` 挤压式 = Lemma G，`[T]` 一行）：

```
( I1: f₁² ≥ r₀ > 0 ) ∧ ( H1: χ ≤ 1/λ )   ⇒   m₁² ≥ f₁²/χ ≥ r₀λ > 0 .
```

而 thin atom 的 `f₁² = w = ε/(2λ) → 0` —— **它精确地违反 `I1`**。
⇒ **thin atom 是「去掉 `I1` 的捷径」的反例，不是 `H*` 的反例。** 谁把 `H1` 单独当最后一环，thin atom 就杀谁；`H*` 毫发无伤，因为 `H*` 把 `f₁²≥r₀` **当假设**，而 `f₁²≥r₀` 在 `β=2.5` **没有证明**（那才是 `[O]`）。

**⇒ 杀伤半径表：**

| 命题 | thin atom 是否杀 | 等级/理由 |
|---|---|---|
| `H1` 单独 ⇒ `m₁²≥δ` | **杀** | `[T]`+`[E]`（§2） |
| `H1` 单独 ⇒ `f₁²≥r₀` | **杀** | `[T]`；`H1_does_not_imply_atom` 机检其 `f` 版（`lean/H1Sharpening.lean:82–90`，0 sorry） |
| `H1` ⇒ 指数聚类率一致下界 | **杀** | `Q6:112–121` `[NG]` |
| **`H1` ⇒ `I2`** | **不杀 —— 反而满足 `I2`** | `[T]`+`[E]`：`Λ★−m₁² = s₂−ε = 2λ(1−w)−ε`；本轮 `ε=1e−6,λ=1` ⇒ `999999/500000 > 0`。`Q02-H1I2.md:106–118` 同判（故 `T01:78` 不能当 `H1⇏I2` 的证明） |
| `I1 ∧ H1 ⇒ m>0` | **不杀** | `[T]` 一行（`Q6:96`） |
| `H* = I1 ∧ I2 ∧ H1` ⇒ 隙（给定载体） | **不杀** | `[T] given the pair`（`Q6:66–68`） |
| `H1` 本身（作为 `β=2.5` 物理命题） | **不动** | thin atom 无嵌入证明（⑦），且载体未定（⑧） |
