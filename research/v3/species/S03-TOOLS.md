## 2 · 六件，逐一给精确陈述 + 判定

每件回答三问：**(Q1)** 方向对不对；**(Q2)** Hessian 在分子还是分母；**(Q3)** 等号点在哪（等号点就是"余量=0"的地方）。

### 2.1 Brascamp–Lieb（方差形式）—— 最接近的是"形"

> **定理 BL. [T]** 设 `Ω⊆R^n` 凸，`μ=e^{−V}dx/Z`，`V∈C²(Ω)`，`Hess V(x) ⪰ K ≻ 0`。则对一切
> `f∈C¹∩L²(μ)`（`∇f∈L²(μ)`）：
> ```
>   Var_μ(f) ≤ ∫_Ω ⟨(Hess V)^{−1}∇f, ∇f⟩ dμ .                                    (BL)
> ```
> 等号：`Hess V≡K`（Gaussian）且 `f` 仿射时两侧同值 `⟨K^{−1}a,a⟩`；此时**等号**。
> *Ref.* Brascamp & Lieb, *J. Funct. Anal.* **22** (1976) 366–389（标准陈述，随库引用；未逐字核页码）。

**Q1** 方向对（上界）。**Q2** Hessian 在**分母**。
**Q3** 等号点是 Gaussian ⟹ 余量恒 0。
**判定：不能给余量 `[NG]`（针对"余量"这一诉求）。** 库内已把 BL 用于此处并折到底：`S6-DOBRUSHIN.md` (5.1)–(5.2)，
取 `f=G_v`、`Hess V=Hess A`、`H_j⪰0`、`Φ″⪰0` 时 `(Hess A)^{−1} ⪯ H_j^{−1}` 给出**精确 equipartition**
`Var(G_v) ≤ E[H_j,vv]`，**"equality iff Gaussian"**——即 (★) 的等号面正是 BL 的等号面。
**BL 唯一能给的东西是符号**：`K_+⪰0 ⇒ D₊≤0`（`H2`、`S3`、`S1`），即 `W_geo ≥ 0`，`δ_W=0⁺`。

### 2.2 Poincaré（曲率形式）—— 常数 `C` 不能分辨方向

> **定理 PI. [T]** `Hess V ⪰ ρI`（`ρ>0`）`⟹ Var_μ(f) ≤ ρ^{−1}E_μ|∇f|²`。等号：Gaussian，`f` 仿射。
> *Ref.* 标准；`Ané–Blachère–Chafaï–Fougères–Hayek–Peccati–Tudor`, *Sur les inégalités de Sobolev
> logarithmiques*, Panoramas & Synthèses **10** (2000) Ch. 1（随库引用；未逐字核）。

**Q1** 上界。**Q2** Hessian 完全消失（只剩常数 `1/ρ`）。**Q3** Gaussian ⟹ 零余量。
**判定：`C` 是"最坏方向"的读数，对特定 (★) 方向 `v` 无分辨力；不能给 `δ_W`。**
唯一的用法是把余量**转嫁成一个显式小量比较**：
`W_geo = E[Φ″] − Var(Φ′) ≥ N/12 − ρ^{−1}E|∇Φ′|²`，故
`δ_W` 可取自 `N/12 − ρ^{−1}E|∇Φ′|²`，**前提**是 `ρ>0` **且**右侧 `>δ_W`。这是**充分条件**，不是恒等余量，
且头部 `ρ≤0` 时整条空。→ 记 `[C]`（条件性），不是普遍余量。

### 2.3 Bakry–Émery（`Γ₂` 判据）—— `ρ` 是曲率，但不是 `δ_W`

> **定理 BE. [T]** `L=Δ−∇V·∇`，`Γ(f,g)=⟨∇f,∇g⟩`，`Γ₂(f):=½LΓ(f,f)−Γ(f,Lf)=|Hess f|²+⟨Hess V∇f,∇f⟩`。
> 若 `∃ρ`：`Γ₂(f) ≥ ρΓ(f) ∀f`（flat 情形 ⟺ `Hess V⪰ρI`），则
> ```
>   (i) Var(P_tf) ≤ e^{−2ρt}Var(f);  (ii) Var(f) ≤ ρ^{−1}E|∇f|²;  (iii) Ent(f²) ≤ 2ρ^{−1}E|∇f|².
> ```
> *Ref.* Bakry & Émery, *Diffusions hypercontractives*, LNM **1123** (1985) 177–206（随库引用；未逐字核）。

**Q1** 上界。**Q2** Hessian 在"曲率"位置（`⟨Hess V∇f,∇f⟩` 是 `Γ₂` 的第二项——恰好是 (★) 右端的形状！）。
**Q3** Gaussian ⟹ `Var = ρ^{−1}E|∇f|²` **取等** ⟹ 余量 0。

这就是任务猜的"原型"能不能成立的分水岭：**形状对，余量错。** 具体地，`Γ₂ ≥ ρΓ` 的**余量**
`κ := inf(Γ₂−ρΓ)/Γ ≥ 0` 才能换成余量：`Var(f) ≤ (ρ+κ)^{−1}E|∇f|²`，从而
```
   δ_W^{BE} = E|∇f|²·κ/(ρ(ρ+κ)) ,        而 Gaussian/仿射下 κ ≡ 0 .          (2.1)
```
**判定：BE 是"ρ↔δ_W 字典"的唯一来源，但字典是单向的（§4）；作为余量工具 `[NG]`。**
库内一致：`H6`（`λ₁(ν) ≥ ess inf G″`，`Hess V_eff=G″`，粗模上 BE **lossless**）、`B3-FUNCTIONAL-BE`、`Q4`。

### 2.4 Stein / Malliavin —— 唯一"精确"的一件（它给的是恒等式，不是余量）

> **定理 Stein（IBP 形式）. [T]** `μ∝e^{−V}`（`V∈C¹`，`e^{−V}` 在有界域边消失或在 `R^n` 上可积+衰减）：
> `E_μ[∂_i f] = E_μ[f·∂_iV]`。
> **定理 Stein（Gaussian 形式）. [T]** `X~N(0,Σ)` ⇒ `Cov(F,G) = E⟨Σ∇F,∇G⟩`。
> **定理 Clark–Ocone / Malliavin. [T]** `Var(F) = E∫_0^T |E[D_tF|𝔽_t]|²dt ≤ E∫_0^T |D_tF|²dt`。
> *Ref.* Stein, *Approximate Computation of Expectations* (1986)；Nualart, *The Malliavin Calculus and
> Related Topics* (2006)（随库引用；未逐字核）。

**Q1** 恒等式（无方向）。**Q2** 无 Hessian 也要 Hessian：**用两次**（`f=∂_vV` 与 `f=Φ′_v`）就得到 §1 的
(1.1)，`H_vv` 是作为 `∂_v²S` 自然出现的。**Q3** 无等号问题——它是恒等式。
**判定：Stein 是 (★) 的"载体"，不是它的证明。** 它把 `−δ_W` 这个**槽位**精确造出来
（`Var(G_v) = E[H_vv] − Cov(G_v,Φ′_v)`，无损耗），但槽里的符号/量级仍是一个协方差。
`Clark–Ocone` 那半边是上界机器（适应被积函数取等）⟹ 也 `[NG]`。
**这是六件里唯一"用得上"的：不是因为它给余量，而是因为它把余量的定义写死。**

### 2.5 FKG / 正相关 —— 方向**不是**反的，但前提不在

> **定理 FKG. [T]** `Λ` 有限个全序集的积，`μ` 满足 FKG 格条件（密度 log-超模 / 正关联），`f,g` 皆增
> `⟹ E_μ[fg] ≥ E_μf·E_μg`（即 `Cov ≥ 0`）。乘积测度情形即 Harris 不等式。
> *Ref.* Fortuin–Kasteleyn–Ginibre, *Comm. Math. Phys.* **22** (1971) 89–103；Harris (1960)（随库引用；未逐字核）。

**Q1**：任务猜"方向反"——**在无条件读数下不反**。(1.2) 要的是 `Cov(G_v,Φ′_v) ≥ δ_W > 0`，FKG 给的正是 `≥0`。
**但**：(i) 它只给 `≥0`，即 `δ_W=0⁺`，**无量化**；(ii) 前提不成立——`SU(N)` Haar×Wilson 是**受挫**的
cos-sum，无格序、无吸引性，FKG/Griffiths 均不适用（库内 `C6-DEPENDENCE-CLASS`/`C5-NEG-ASSOC` 已判 `[NG]`）；
(iii) 在**条件化**读数里需要的是反向的 `Cov(G,Φ′|0) ≤ 0`（反 FKG），`ABC-FINAL-LEDGER.md` 已把该"反关联物种"
判为九类依赖结构全无。
**判定：`[NG]`。符号对而量级空，且前提（格序/正关联）在紧致 `SU(N)` 上不存在。**

### 2.6 Hoeffding / Efron–Stein —— 方差分解给的是**反方向**的界

> **定理 Efron–Stein. [T]** 独立 `X_1..X_n`，`f∈L²`，`E^{(i)}` 表示对 `X_i` 求期望：
> `Var(f) ≤ Σ_i E[Var^{(i)}(f)]`；等号 iff `f` 是坐标函数之和（无交互）。
> **定理 Hoeffding/ANOVA. [T]** `f=Σ_S f_S`（`f_S` 正交）`⟹ Var(f) = Σ_{S≠∅}Var(f_S)` **精确**。
> *Ref.* Efron & Stein, *Ann. Statist.* **9** (1981) 586–596；Hoeffding (1948)（随库引用；未逐字核）。

**Q1**：**方向相反**。分解给的是 `Var` 的**下界/等式**，而 (★) 要的是 `Var` 的**上界**；
写成 (1.2) 的形式：`W_geo = E[Φ″] − Σ_S Var_S(Φ′_v)`，每一项都在**减**。
**Q2** 无 Hessian。**Q3** 等号点=无交互 ⟹ 余量 0。
**判定：不能给 `δ_W` `[NG]`。** 但它有**独立价值**：它是把 `W_geo` 做成**逐尺度可和**的唯一工具
（`Q1-INFRARED-BOUND` §M3、`S6-DOBRUSHIN.md` §3.2 的 Efron–Stein/Simon–Lieb 就是这样用的），
即"若要证 `W_geo ≥ δ_W`，必须逐片证"。

## 4 · (c) 的正面回答：`ρ ↔ δ_W` 的对应（单向，含推导）

设 `Γ₂ ≥ ρΓ`（`ρ>0`），`L` 的 semigroup `P_t`，`Γ(f,g)=⟨∇f,∇g⟩`。三行：

```
  Cov(G,Φ′) = ∫_0^∞ E[Γ(P_tG, Φ′)] dt                                (谱表示; t→∞ 时 P_tG→EG)
  |Γ(P_tG,Φ′)| ≤ √(Γ(P_tG)Γ(Φ′))                                     (carré du champ 的 Cauchy–Schwarz)
  EΓ(P_tG) ≤ e^{−2ρt}EΓ(G)                                           (BE)
  ⟹ |Cov(G,Φ′)| ≤ ρ^{−1}√(E|∇G|²·E|∇Φ′|²) .                          (4.1)  [C]
```

于是 `δ_W ≤ W_j + Cov(G,Φ′) ≤ W_j + ρ^{−1}‖∇G‖₂‖∇Φ′‖₂`。**这是 `δ_W` 的**上界**（天花板），不是下界。**

**对应字典（写死）：**

| BE 的量 | (★) 的量 | 关系 |
|---|---|---|
| `ρ`（`Γ₂≥ρΓ` 的下界，曲率地板） | — | 只决定 `Cov` 的**上限**（4.1） |
| `κ = inf(Γ₂−ρΓ)/Γ ≥ 0`（**超额曲率**） | `δ_W` | `δ_W = κ/(ρ(ρ+κ))·E\|∇f\|²`（2.1）；Gaussian 下 `κ≡0` |
| `Γ₂` 的**第二项** `⟨Hess V∇f,∇f⟩` | `E⟨PᵀH_jPv,v⟩` | 同形，但一个是曲率、一个是被积量 |

**结论：`ρ` 不是 `δ_W`；`δ_W =` 曲率**超额**换来的余量，而超额在 Gaussian/free 点恒为 0。
这与库内"BE 在粗模 lossless ⟹ BE≡H1"是同一件事的两种说法。**
