## 2 · 环 2（KP）：显示式零约束，判据才是上界

### 2.1 `c_r dim r ≤ β^{|r|}/|r|!e^β` 是**定理**，不是窗

`P3-FULLREP-KP:29–31`（Lemma 1.1，`:33–50` 自证）：

```
0 ≤ c_r(β) ≤ β^{|r|}/(|r|! dim r) ⇒ c_r dim r ≤ β^{|r|}/|r|! e^β ,   对一切 β ≥ 0     [T]
```

**它给不出任何 `β` 上界**，两条独立算术：

1. **逐阶**：固定 `n=|r|`，`sup_β β^n/(n!e^β) = n^n/(n!e^n) = 1/√(2πn)(1+O(1/n))`（Stirling），在 `n=1` 取最大 `1/e=0.3678794<1`，随 `n` 单调降到 `0`。⇒ 每一阶的"率"都 `<1`，不等式**永不可能因 `β` 而失败**。
2. **题目点的 `|r|=4`**（plaquette 级）：`f(β)=β⁴/(4!e^β)`，`f'(β)=0` 在 `β=4`，`f(4)=256/(24e⁴)=0.19536681<1`；方程 `β⁴=24e^β` **无正根**：`g(β)=24e^β−β⁴` 有 `g(0)=24>0`、`g'(β)=24e^β−4β³>0` 对一切 `β≥0`（`6e^β>β³`，`[E]` 网格复算 `min g'=24` 于 `β=0`）⇒ `g>0` 处处。⇒ 约束是 `β∈(0,∞)`，**零**。

**它究竟给了什么**：`Σ_{n≥0}β^n/n! = e^β` 精确 ⇒ 全部 `|r|` 的"活动度和"归一为 `1`——`1/|r|!` 吃掉表示标号熵、`1/dim r` 抵消 `dim r` 的缩并（`P3-FULLREP-KP:17,105`）。这是**收敛机制**（"对每个 `a,β` 都收敛"，`:94`），**不是半径**。
> 反读警告（防误用）：若把该式当"对 `c_r` 的要求"，则在小 `β` 端它**必假**（`β=1/eΔ` 处右端 `=4.68×10⁻⁹`，任何 `O(1)` 的 `c_r dim r` 都不满足）⇒ 只能读作定理。**读作要求就把窗读成"`β` 下界"，方向反了。**
