## 1. 把 `S`/`D` 化成有限维积分（核准）

### 1.1 模型与测度（与 `h1e_var.py:6–9`、`p05_cinf.py:7–18` 逐项一致）

`U = exp(ξ·σ/2)`、`|ξ|<2π`、`h=ρ/2`（`ρ=|ξ|`）：

```
S_W = β(1 − cos h cos(θ/2) + sin h sin(θ/2) ξ₃/ρ),   J = 4 sin²h/ρ²,   dμ ∝ J d³ξ.
```

切片 `ξ₃=0`，`u := ρ/2 ∈ (0,π)`。**测度**：Haar 在指数坐标下 `dμ ∝ sin²(ρ/2) dρ dΩ`；切片 `d²ξ = ρ dρ dφ`；两者相除

```
切片密度 ∝ [4 sin²(ρ/2)/ρ²]·ρ dρ dφ ∝ sin²(u) du dφ/u   ⇒   w(u) := sin²u / u,  u ∈ (0,π)
```

（与 `h1e_var.py:9` "density `sin²(ρ/2)/ρ dρ`" 同；`DS-RATIO.md:86` 用 `sin²(ρ/2)dρ/ρ` 的 coarea 因子亦同。）

### 1.2 三个导数（本文件的核心核准点）

逐项求导（`u=ρ/2`，`ρ=2u`）：

```
G     = ∂_{ξ₃}S_W|_{ξ₃=0} = β sin(θ/2)·sin u/(2u) = β s g(u),      s:=sin(θ/2), g(u):=sin u/(2u)
H     = ∂²_{ξ₃}S_W|_{ξ₃=0} = β cos(θ/2)·sin u/(4u) = (βc/2) g(u),  c:=cos(θ/2)
Φ     = −log J = 2 log ρ − 2 log(2 sin h)              只依赖 ρ
Φ'    = ∂_{ξ₃}Φ = Φ_ρ'·(ξ₃/ρ) ≡ 0                      逐点：切片切于等-ρ 球面   ← 关键
Φ''   = ∂²_{ξ₃}Φ = Φ_ρ'/ρ = 1/(2u²) − cot(u)/(2u)
```

**核准**：`G|_{θ=π}=β sin(ρ/2)/ρ` ✓（题面给的形式，`h1e_var.py:8` 逐字同）；`H=(βc/2)g` ✓（`P05-CINF.md:54` 的 `Q=H/β=cos(θ/2)g(u)/2` 逐字同）；`Φ''=1/(2u²)−cot(u)/(2u)` ✓（`P05-CINF.md:63`、`p05_cinf.py:49–54` 的 `Φ''_t(u)` 逐字同）。`Φ'≡0` 是本次首次显式写出的**结构性事实**（切片与等-ρ 球面相切 ⇒ `∂_{ξ₃}ρ=0`），它把 `Var(G+Φ')` 的交叉项**恒等地**去掉。

### 1.3 `θ=π` 上的坍缩（为什么这一点最硬）

`θ=π ⇒ c=0`：`S_W ≡ β` 在切片上是**常数**。于是

1. **权重是常数** ⇒ 切片测度 = 纯 Haar 切片，**与 `β` 无关**；
2. `H ≡ 0` **逐点** ⇒ `E[H]=0`，`β`-线性正项（`Δ_dyn` 侧）整条消失；
3. `Φ' ≡ 0` **逐点** ⇒ `D = Var(G)`，无协方差项。

```
S = E[Φ''] = NS/Z ,     D = β² Var(g) = β² (NB/Z − (NA/Z)²)
Z  = ∫₀^π w du ,  NA = ∫₀^π g w du ,  NB = ∫₀^π g² w du ,  NS = ∫₀^π Φ'' w du
```

即 `S − D > 0` 在 `θ=π` 上**纯粹**是 `E[Φ''] > β²Var(G)`——正好是 `W_full>0` 的那一支（`H1C-WFULL.md` 的 (I)），且**不含** `Δ_dyn` 的任何帮助。这是正性最"没有帮忙"的点，因此也是最值得判死的点。

### 1.4 四个积分都是整函数（`cot` 必须消掉，否则区间算术无意义）

用恒等式 `cot(u)·sin²u = sin u cos u = sin(2u)/2`：

```
W  = sin²u/u
A  = sin³u/(2u²)
B  = sin⁴u/(4u³)
Φ''w = sin²u/(2u³) − sin(2u)/(4u²) = −(1/4)·d/du[ sin²u/u² ]     ⇒   NS = 1/4  精确
```

`NS` 的 `[T]` 证明：`Φ''w` 是**全导数**，端点 `sin²u/u²: 1→0` ⇒ `NS = −(1/4)(0−1) = 1/4`。**所以 `S = 1/(4Z) = 1/(2Cin(2π))`——恰好是语料锚 `eq:v3anchor` `0.20511530`。**（独立核对见 §3。）

代码里对这四个 Laurent 级数**断言负幂全部相消**（`q11_cert.py` 的 `assert not [k for k in ser if k<0]`），并断言 `Φ''w = −(1/4)(sin²u/u²)'` 逐系数成立（`IBP identity check`）——两条都是机器验证，不是叙述。

## 2. 区间算术（真向外舍入，`q11_cert.py`）

### 2.1 口径（5 条，缺一不可）

| # | 内容 | 实现 |
|---|---|---|
| 1 | Taylor 系数 `a_k` | `fractions.Fraction` **精确有理数**，零浮点 |
| 2 | 积分表示 | `∫₀^π f = Σ_k a_k π^{k+1}/(k+1)`（`f` 整函数 ⇒ 逐项积分是恒等式，非近似） |
| 3 | `π` | 只以区间 `[π_f, π_c]` 进入：`mpmath.libmp.mpf_pi(800,'f'/'c')` 定向舍入 |
| 4 | **向外舍入** | 每个 `+,−,×,÷` 走 `libmp` 的 `'f'(floor)/'c'(ceil)`，再统一加绝对外扩 `PAD=2⁻⁴⁰⁰` |
| 5 | 截断 | Cauchy 估计 `|a_k| ≤ |c|(e·j/(m+k))^{m+k}`（`f=c·sin^j u/u^m` 整函数）+ `π<3.2`；`K=260` |

`PAD=2⁻⁴⁰⁰` 是**故意浪费**的余量：即使 `libmp` 每一步有 `2¹⁰⁰` ulp 的欠正确（它的实际偏差是"几个 ulp"），累积仍 `<10⁻¹¹⁰`，比所需精度（`1e-1`）低 109 个数量级；比报告的区间宽（`1e-117`）也低 7 个数量级。**`PAD` 不是精度设置，是欠正确性的保险丝。**

**向外舍入"真做了"的机检证据**：`Z` 的区间宽 `2.018e-118`。`PAD=2⁻⁴⁰⁰=3.87e-121`，`2.018e-118 / 3.87e-121 = 522 = 2×261`（261 = `KMAX+1` 个累加步，每步一次 `f` 减 + 一次 `c` 加）⇒ 宽度**恰是 `PAD` 的逐操作累积**。若只做"高精度大概"，宽度会是 `0`（同一浮点表达式上下界相同）或 `~1e-800` 的 ulp 噪声，不可能恰好等于 `2(KMAX+1)·PAD`。`q11_cert.log` 每个区间都打印 `width=`，可逐个复核。`S` 的宽 `7.7e-121` < `Z` 的宽（除法把小宽度传播成相对量），`D` 的宽 `1.0e-117`（`E[g]²` 的抵消放大）——三者各自可解释。

## 6. `L=2`：不可化，只能 MC（题面第 4 条）

- 单 plaquette 可积的**唯一**原因：一个 link 变量 + 一个约束 ⇒ 切片是 2 维面，`ρ` 一条径向 ⇒ 化 1D 条带。`L=2`（`1×1×1×1` 环面，16 link，2 plaquette）的 `Z` 与边缘是 `SU(2)¹⁶` 上的 16 重积分；条件化切片 `⟨v,ξ₁⟩=0` 仍是 **15 维流形**，1D 约化不复存在。
- 只能走 character 展开（Kogut）：系数 `~ (β/4)^n`，`β=2.5` 时 `β/4=0.625`，需 `n ≫ 10` 才有 `1e-3`，且**无闭式截断**⇒ 只能给逐阶界（`[C]`），或 MC。
- **明说**：`L=2` 上**没有**有限维精确积分表示，因此**没有** `[T]` 区间证书；只有 MC。本次不做。
