## §1 SEP-2 判定（第 1 问：`δ₁` 是多少、过不过酸测）

### 1.1 SEP-2 的 `δ₁` = **−∞**（发散），不是"非零有限"`[T]`+`[E]`

`GR1:151–154` 逐字：`ℋ=ℓ²`、`H = diag(1,2,3,…)`、`H_a := H − δ_aP₁`、`δ_a := 1/log(1/a)`、`Δ_cont = 1`。于是边缘本征值 `Δ_a = 1 − δ_a`（`GR1:153`）。按 `GK2:45` 的 sinh-mass 定义：

```
ω_a = (2/a)sinh(aΔ_a/2) = (1−δ_a) + (a²/24)(1−δ_a)³ + O(a⁴)
⇒ (ω_a − Δ_cont)/a² = −δ_a/a² + (1−δ_a)³/24 + O(a²)
                     = −1/(a² log(1/a)) + (1−δ_a)³/24 + O(a²)   →  −∞
```

数值核（`gm3_falsify_check.log:52–56`，50 位 `mp`）：

|---|---|---|---|---|
| `1e-2` | `0.217147241` | `21.7147` | `2171.47` | `−2171.4524` |
| `1e-6` | `0.07238241365` | `72382.4` | `7.23824e+10` | `−7.2382414e+10` |

（与 `GR1:154` 的 `2.17e+01 / 2.17e+03`、`7.24e+04 / 7.24e+10`、`3.62e+10 / 3.62e+22` 逐位相符 ⇒ 交叉核 ✓；`a=1e-30` 一格是本轮新增。）

**⇒ SEP-2 不提供"`δ₁ ≠ 0` 且有限"的反例，它提供的是 `δ₁ = −∞`。** 这决定了它属于哪一类反例：它推翻的是 `(SM-2)_GK2` 的**"有限"**读法（`GK2:292` 逐字如此说），而**不能**推翻 `(SM-2)_brief` 的"`δ₁≠0`"前件（因为前件要求一个有穷数）。

### 1.2 它过不过酸测？——**过（作为一个"非真空"见证）`[T]`；但不能救 `(SM-2)`**

**(a) 作为反例它是合法的（`[T]`）。** `|Δ_a − Δ_cont| = δ_a` 而 `δ_a/a^k → ∞` 对每个 `k`（上表）⇒ `(SM-2)` 在它上面**正确地失败** ⇒ `(SM-2)` 不是恒真命题，`GK2:295` 的酸测成立。这一条本轮**确认**，不推翻。

**(b) 但它不是物理族，而这一步的证据等级必须降下来（本轮新增 `[C]`）。**
判它非物理的标准说法是"格点族的 `a`-依赖是幂 × `log`"，理由：`H_a = −(1/a)log T(β(a),a)`，其中 `β(a)` 由 RT 给（`GK2:198` 的 (Q1)、(Q2)，`GR1:163–166`）⇒ `Δ_a/Δ_cont = 1 + Σ_n a^n P_n(log a) + (非微扰小项)`。而 `1/log(1/a)` 在 `a=0` 处**Taylor 级数恒为零**（是"平坦函数"），**任何**幂×log 型渐近都到不了它 ⇒ 排除。

**但这句"幂 × log"就是 Symanzik 渐近展开**——仓内已判：4D **没有非微扰 Symanzik 定理**（`GK3:79–82` 的 P7/P9/P10：`NPSYM:28`、`G1-ASSEMBLE:54,81`、`IN-2:19`、`R32:177`），并把它具名为 `SYM-4D`/`SYM-IR`。⇒

> **`(SM-2)` 在 SEP-2 上的"正确失败"是 `[T]`；但由"SEP-2 非物理 ⇒ `(SM-2)` 仍活"这一步是 `[C]`，它依赖的正是缺步 `SYM-4D` 本身。** 所以 §1 的净产出是"`(SM-2)` 可被证伪"，**不是**"`(SM-2)` 为真"。

### 1.3 SEP-2 还有一处需要写死（`[M]`）

SEP-2 的 `H_a` 与 `H` **共享同一个 Hilbert 空间与同一组本征向量**（`P₁` 固定），而格点族的 `H_a` 与 `H` 不共享（`GK2:321` 引 `GN2:52`：`‖U_aH_aU_a^*−H‖=∞`）。⇒ SEP-2 检验的是**谱层的书签式慢凹陷**，不是"格点截断如何进入边缘"。**它测不到 `K₂` 的三片结构**（§3），因此**它天然不能**在"抵消是否巧合"这个问题上给任何信息。

## §3 巧合 vs 结构（第 3 问）

### 3.1 判：**巧合**——而且是**两个**互相独立的巧合

自由场里 `δ₁ ≡ 0` 的两个前提（缺一即破）：

| # | 前提 | 出处 | 破了会怎样 |
|---|---|---|---|
| **(i)** | **边缘在 `p⃗ = 0`**（所以符号差在边缘**逐位为零**：`h(0)=0=|k|²`） | `GR1:234`（"`p⃗=0` 扇区"）、`GR1:241`、`GK2:62,130` | **F1**（扭转，`p*≠0`）⇒ `δ₁ = −Σp⁴/(24Δ) ≠ 0`（§2.1） |
| **(ii)** | **Wilson 的 "half-mass" `cosh` 结构**：`cosh(aΔ) = 1 + a²m²/2` 精确 ⇒ `H_a = (2/a)asinh(aH/2)` **逐算子**成立 ⇒ `K₂ = −H³/24` | `GK2:65,124`；`GK3:148` | **F2**（Symanzik 改进，`cosh(aΔ)=4−3√(1−a²m²/3)`）⇒ `c₁=0` ⇒ `δ₁ = +m³/24 ≠ 0`（§2.2） |

**关键**：F1 **保持** (ii) 而破 (i)；F2 **保持** (i)（`p*=0`）而破 (ii)。两条反例**正交** ⇒ `δ₁=0` 不是"结构"（结构不会被单一改造打掉），而是"两件事同时成立时的一个点"。

### 3.2 三条"结构"候选逐个排除

| 候选结构 | 能否强制 `⟨K₂⟩₁ = −Δ³/24` | 判 |
|---|---|---|
| **规范不变** | **不能。** `δ₁` 是规范不变态里的一个标量；规范不变只约束 `K₂` 的**形状**（哪些不变算子可出现），不约束三个系数之和。**更强的反证：自由场根本没有规范场**，而它的 `δ₁` 恰恰是 0/非 0 都能取（F1 vs p=0） ⇒ 规范结构在 `δ₁` 上**完全不出场** | `[T]` |
| **`H(4)`（超立方对称）** | **不能。** 三片落在**不同**的 `H(4)` 表示里（4 导数动能片 / `trF³` 奇次片 / `tr(DF)²` 偶次片，`GK2:171–174`）⇒ `H(4)` 恰好**禁止**它们相等，因而不可能给出一个把它们**相加为零**的恒等式；`H(4)` 管的是"哪些项可以出现"，不管"系数取什么值" | `[C]` |
| **幂计数** | **不能。** 三片**都在 `a²`**（`GK2:171–174`）；幂计数定"哪一阶"，不定**系数与号**。`GK2:0.6` 已判"三者不共号 ⇒ 无对称性保护" | `[T]`（就"不共号"而言） |

**⇒ 结论：`δ₁ = 0` 在自由场里是运动学巧合（`p*=0` + `cosh` 形式），在 YM 里没有任何已知结构保护它。这与 `GK2:0.6`（"`c₁` 的号判不出"）是同一件事的两面。**

### 3.3 `β`-判据：在哪个 `β` 会破（子句 (B) 的"脆弱性"量化）

把 `K₂` 的三片按 `β = 2N/g²` 归类（Kogut–Susskind 归一：电片 `∝g²`、磁片 `∝1/g²`、纯导数片 `β`-无关）：

```
δ₁(β) = A·g(β)² + B/g(β)² + C                      （A,B,C = 三个边缘矩阵元，均为 O(1) 数）
零点判据：  A g⁴ + C g² + B = 0   ⇒  g*² = [−C ± √(C² − 4AB)]/(2A)
⇒ β 空间里 δ₁ = 0 的解集 **测度零**（0 或 2 个点）
⇒ 在零点上 dδ₁/dβ = (2A g − 2B/g³)(dg/dβ) ≠ 0（除非 A g⁴ = B，又一条测度零条件）⇒ **横截**
```

**数（形式）**：`β → ∞`（`g→0`）时 `δ₁ → B/g² + C → +∞·sign(B)`；`β → 0`（`g→∞`）时 `δ₁ → A g² + C → +∞·sign(A)`。⇒ 若 `A,B` 同号，`δ₁` 在两端同号、**可以全程不为零**（`(SM-2)_brief` 的前件根本不成立，`δ₁≠0` 恒成立）；若反号，则恰有两个 `β` 使它为零。**两种情形都不给 `k` 任何信息**（§2.4 与 §2.1/2.2 已把 `δ₁` 的整个值域与 `k` 解耦）。

**限定（不许读成已算）**：`A,B,C` 是**边缘态上的三片期望**，本文件**没有**算它们（要 YM 边缘数据 = 任务禁止 MC）；`A,B,C` 的具体 `β`-标度也**没有**逐项展开核对（`[C]`，不是 `[T]`）。这一格的全部内容是"**零点是一个标量方程，因此至多孤立**"这个结构。

### 3.4 附带一句：`δ₁=0` 真正管的是什么

由 `GK2:0.11/194`：`C = Δ²/24 + |δ₁|/Δ`。⇒ **`δ₁` 管的是常数 `C` 的大小（`δ₁=0` 时 `C = Δ²/24` 最干净），不管指数 `k`。** 任务书把"常数最干净"升级成"指数为 2"，是这次打假的**唯一误读源**。
