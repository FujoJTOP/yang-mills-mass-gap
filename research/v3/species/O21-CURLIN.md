## 0. 判死线（先读这段）

**(b)。`H_vv` 不恒非负，"曲率侧免费"不成立；`Φ''` 侧则完全免费且更强：点态 `Φ'' ⪰ (N/12)I₃`，对所有 β。**

1. **`H_vv` 的精确式**（从 `S_W = βΣ_p(1−½Re tr U_p)`）：
   ```
   ∂_v²(1−½Re tr U_p) = ½Re tr[U_p(W_p²+Ẇ_p)] = ½tr(H_p²)·[α_p − γ_p],
   H_p := i W_p (hermitian),  W_p := U_p^{-1} dU_p/ds,  α_p := Re tr(U_p H_p²)/tr H_p² ∈ [−1,1],
   γ_p := Re tr(U_p Ẇ_p)/tr H_p².
   ```
   `−½Re tr(U_p H_p²) = −½tr(H_p²)α_p` 就是 **Savvidy `2g·ad F` 的有限格点原身**：符号由 `U_p` 与 `H_p²` 的**对齐** `α_p` 定，`α_p` 可负 ⇒ **二次型不恒非负**。
   **精确反例（解析 + FD 对到 `2.5e−8`）**：单 plaquette `SU(2)`、切片 `ξ₃=0`、`v=e₃`、边界 holonomy `θ`：
   ```
   H_vv = β·cos(θ/2)·sin(ρ/2)/(2ρ)      ⇒   H_vv ≥ 0  ⟺  cos(θ/2) ≥ 0  ⟺  Re tr U_p ≥ 0
   ```
   `θ ∈ (π, 2π)` ⇒ **逐点负** ⇒ `E[H_vv|0] = βcos(θ/2)E[sin(ρ/2)/(2ρ)|0] < 0`，且 `β→∞` 时 `E[H+Φ''] → −∞`。**该支上任何 `c>0` 都不成立。**
   ⇒ **判 (a) 不成立**（`H_vv` 不恒非负 ⇒ 免费论证断了）。

2. **`Φ''`（这是本题的真免费项）**：`Φ = −log J` **逐构型不含 β**；本模型解析得
   ```
   Φ''_transverse = 2/ρ² − cot(ρ/2)/ρ        inf_(0,2π) = 1/6 = N/12   （ρ→0 取到）
   Φ''_radial     = −2/ρ² + ½csc²(ρ/2)       inf_(0,2π) = 1/6 = N/12
   ```
   ⇒ **`Φ'' ⪰ (N/12)I₃` 点态、对每个 β**（`[T]`，比 Lemma B 的 `E[Φ''] ≥ N/12` 更强：不需要边缘化）。
   而 `E[Φ''|0]` 随 β **单调下降**，`∂_β E[Φ''|0] = −Cov(Φ'',S_W^{(0)}|0) ≤ 0`（`Φ''` 与 `S_W^{(0)}` 同向增 ⇒ 正相关 ⇒ 导数 ≤ 0），
   数值 `0.20401 (β→0) → 0.166690 (β=1000)`，**下限恰为 N/12**。⇒ **判 (c) 部分成立但无破底**。

3. **`c` 的值**（v = e₃ 模即 `H1A/O05/O06` 的设定，`‖v‖=1`，格点单位）：
   ```
   c(β) = E[H_vv+Φ''|0]/(β‖v‖²) = E[Q|0] + E[Φ''|0]/β ,      Q := H_vv/β  (β-无关)
   c_∞  := lim_{β→∞} c(β) = Q(ρ=0) = cos(θ/2)/4 = Re tr U_p/(4N)      [解析]
   c(2.5): 0.2920 (θ=0) / 0.2739 (π/4) / 0.2233 (π/2) / 0.1523 (3π/4)
   c(β→200): 0.2504 / 0.2314 / 0.1772 / 0.0961
   ```
   **判：`c < N/12` 一般成立（θ→π 时 `c→0`）；只有 `θ ≤ π/2` 时 `c ≥ N/12 = 0.1667`。** 扫描窗最小值 `c_min = 0.0961`。
   **不需要任何数值的严谨界**：β ∈ (0,B] 上 `c ≥ N/(12B)`（β=2.5 ⇒ `1/15 = 0.0667`），因为 `β·Q ≥ 0`（北半球切片）而 `Φ'' ≥ N/12`。

**一句话**：**线性是真的、精确的（`H_vv = β·Q`，`Q` β-无关）；但系数 `Q` 的符号不免费——它由 `α_p`（Savvidy 对齐）与 `γ_p`（图表各向异性）两支决定，前者在 `Re tr U_p ≥ 0` 时给正、后者在深腔给负。于是 `c` 不是 `N/12`，而是 `c_∞ = Re tr U_p/(4N)`（外加 `E[Φ'']/β` 的小修正），在 `θ = 3π/4` 落到 `0.096`。**

## 1. `H_vv` 的精确式：从 `S_W` 抄下来，逐项量纲

`ch05:195–206`（`[T]`，本会话读正文）与 `ch05:230–240`（`eq:split`）：
`V = S_W + Φ`，`S_W = βΣ_p(1 − ½Re tr U_p)`，`Φ = −log J`（平直图 `X_ℓ=log U_ℓ ∈ su(N)`，`dU = J dX`），`H = Hess V`，`' = ∂_v`。

**一般 `SU(N)`（任意 `L`，任意方向 `v = (v_ℓ)`）**：`U_p(s) = Π_ℓ e^{X_ℓ + s v_ℓ}^{±1}`，
```
dU_p/ds = U_p W_p ,     W_p = Σ_ℓ Ad_{P_ℓ}(Φ_{X_ℓ}(v_ℓ)) ,      Φ_X = ∫₀¹ e^{−t ad_X} dt = (1−e^{−ad_X})/ad_X
∂_v²(1−½Re tr U_p) = ½Re tr[U_p(W_p² + Ẇ_p)]
                   = −½Re tr(U_p H_p²) + ½Re tr(U_p Ẇ_p) ,        H_p := iW_p (hermitian)
                   = ½tr(H_p²)·[α_p − γ_p] .                                            (1.1)
```
`（1.1）` 第一行是恒等式（只是对 `tr` 求两次导再分组）；第二行用了 `W_p² = −H_p²`。
`α_p ∈ [−1,1]` 是**对齐**（`U_p` vs `H_p²`），`γ_p` 是**图表各向异性**（`Φ_X ≠ 1`，即 `su(N)` 上指数图的非平凡性；平坦/abelian 极限 `Ẇ=0`）。

**量纲**：`X, v` 无量纲（角）⇒ `W_p, H_p` 无量纲 ⇒ `(1.1)` 无量纲；乘 `β` 后 `H_vv` 无量纲，与 `S_W` 同。
`Φ''` 无量纲。`c` 无量纲。**没有 `a→0` 标度**（`GPP-STRUCT §7.3` 同一限制）。

**`Q := H_vv/β` 与 β 无关**（`S_W^{(0)} = Σ_p(1−½Re tr U_p)` 不含 β）⇒ **`H_vv` 的符号与 β 无关，只有量值线性**。这就是 O05 `m=1.0036`（`dlogE[H]/dlogβ → 1`）的精确机制：`E[H]/β = E[Q|0] ↑ Q(0) ≠ 0`。

**本文件主模型**（`H1A-EXACT §2.1` / O05 / O06 约定）：单 plaquette `SU(2)`，`S = β(1−cos(ρ/2)cos(θ/2)+sin(ρ/2)sin(θ/2)u)`，`u=ξ₃/ρ`，`Φ = −2log(sin(ρ/2)/ρ)`，切片 `ξ₃=0`，`v=e₃`，`a=0`，切片测度 `w(ρ)dρ = 2π sin²(ρ/2)/ρ · e^{−S} dρ`。**解析 3×3 Hessian**（`V=S+Φ` 在 `ξ=(ρ,0,0)`）：
```
H = [[A,0,C],[0,B,0],[C,0,B]]
B = βcos(θ/2)sin(ρ/2)/(2ρ) + Φ''_trans          (两次横向本征值；正是 O06 的 H_vv+Φ'')
A = βcos(θ/2)cos(ρ/2)/4    + Φ''_rad            (沿半径)
C = βsin(θ/2)[ρcos(ρ/2)/2 − sin(ρ/2)]/ρ²        (混合；ρ→0 时 O(ρ³)→0 ⇒ 各向同性)
```
**校验（`[C]`）**：与中心差分 `h=1e−4` 逐元素对，`max|H_exact − H_FD| = 2.5e−8`（4 组 `(β,θ,ρ)`，`o21_curv_linear.log [P1b]`）。

**"是否恒非负？"——判：否。** 三条独立证据：

| 证据 | 内容 | 值（`[C]`） |
|---|---|---|
| 解析（精确） | `B = βcos(θ/2)sin(ρ/2)/(2ρ) + Φ''_trans`；`θ>π` ⇒ `cos(θ/2)<0` ⇒ 逐点 `B<0`（`Φ''≥1/6` 也压不住：`ρ→0` 时 `B → βcos(θ/2)/4 + 1/6 → −∞`） | `H_vv ≥ 0 ⟺ Re tr U_p ≥ 0` |
| 4-link 随机（`\|X_ℓ\|≈0.35`） | `α_p ∈ [0.42799, 0.997996]`（**全为正**），但 `Q<0` 占 **58.8%** | `Q: min −0.36263, max 0.32758, mean −0.022014` |
| 4-link 随机（`\|X_ℓ\|≈0.70`，窗外，`AGENTS §2.1`） | `α_p ∈ [−0.4995, 0.9936]`，`α_p<0` 占 **8.83%**；`Q<0` 仍 58.8%，`α<0 ∧ Q<0` 占 **7.33%** | 深腔才切到 Savvidy 对齐支 |

**读法（新，重要）**：在**小振幅（物理窗内）**，负号**不是**来自对齐 `α_p`（那里 `α_p>0.43` 恒正），而是来自 **图表各向异性 `γ_p`**；在大振幅才切到 `α_p<0` 的 Savvidy 支。⇒ 想要 `H_vv ≥ 0` 免费，必须**同时**控住 `γ_p`，这不在任何已知不等式的射程内（`GPP-STRUCT §3`）。

**真正免费的一条**（本题唯一无条件的正性）：
```
θ ≤ π  ⇔  Re tr U_p ≥ 0  ⇒  B ≥ 1/6 = N/12 点态（且 β-无关的符号）
此支上 E[H_vv|0] = βcos(θ/2)·E[sin(ρ/2)/(2ρ)|0] ≥ 0
```

## 3. `c`：定义、解析下界、数值

**定义**（把线性变成不等式）：要 `E[H_vv+Φ''|0] ≥ c·β·‖v‖²` 对窗内**所有** β 成立，则
```
c(β) = min_{‖v‖=1} E[H_vv+Φ''|0] / (β‖v‖²) = E[Q|0] + E[Φ''|0]/β        （本模型 v=e₃）
c    = inf_{β∈窗} c(β)
```

**解析（`[T]`）**：`β→∞` 时 `μ(·|0)` 集中到 `ρ=0`，Hessian 各向同性（`C(0)=0`），
```
H_vv+Φ'' → βcos(θ/2)/4 + N/12   (乘 ‖v‖²)      ⇒   c_∞ = cos(θ/2)/4 = Re tr U_p/(4N)
```
**这是 `m=1` 的精确系数**：`E[H]/β → 0.25cos(θ/2)`；θ=0、β=200 实测 `0.249584 ≈ 0.25`（与 O05 的 `0.2496` 逐位一致 ✔）。

**严谨窗口界（只用点态事实，不用任何数值）**：
`βQ ≥ 0`（`Re tr U_p ≥ 0` 支）且 `Φ'' ≥ N/12` ⇒ `E[H+Φ''] ≥ N/12` ⇒ 对 β ∈ (0,B]：
```
c ≥ N/(12B)     B=1 ⇒ 1/6 = 0.166667 ;   B=2.5 ⇒ 1/15 = 0.066667 ;   B=6 ⇒ 1/36 = 0.027778
```

## 5. 窗口与未闭合（诚实标注，`AGENTS.md §2.1`）

1. **窗口**：全部数值在**单 plaquette `SU(2)`**（纤维 3 维、切片 2 维、`Φ` 径向、固定边界 holonomy `θ`）上；`c` 的表是**该模型**的 `c`，不是 4D `SU(3)` 的 `c`。**本文件没有**把 `c` 搬到 `(L,a,真空)` 上。
2. **"min over ‖v‖=1"的完整扫描未做**：本模型的合法切片模是**横向**方向（与半径正交），三个坐标方向 `e₁,e₂,e₃` 都给出同一个**矩阵元** `B`（因三者在该点都与半径正交）；但 `v=e₁` 的切片 `{ξ₁=0}` 上 `u=ξ₃/ρ ≠ 0`，**切片测度不同**（2D 角向积分），那条分支**未算**。`A`（沿半径）与 `λ₋`（混合）是**该点 Hessian 的本征值，不是这套 toy 的切片模**，故只作诊断列出（`E[A]`, `E[λ₋]` 见 `[P4]` 末尾），**不进入 `c`**。4D 的模谱亦**未做**。
3. **`γ_p` 的地位未定**：小振幅下负号主要来自 `γ_p = Re tr(U_p Ẇ_p)/tr H_p²`（图表各向异性），而不是 `α_p`。这与"Savvidy"是**两回事**，本文件只把它标出来，**没有**证明 `γ_p` 的符号规律（`[NG]`）。
4. **`Φ'' ⪰ (N/12)I₃` 只在单 plaquette `SU(2)` 解析证得**。一般 `SU(N)` 的"点态 `⪰`（而非 Lemma B 的边缘化元 `E[·]≥`）"**未证**；`ch05` Lemma B 仍是 `[T]` 的可用版本。
