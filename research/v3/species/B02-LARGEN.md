## §2 · `1/N` 展开：`m(N)=m(∞)+c₁/N+…`，`c₁` 的界在哪

### 2.1 唯一有闭式的规范理论（2D，`[T]`）

**本轮精确算（PART A/B）**：

```
ρ²(N) = 2N²/(N²−1) = 2 + 2/(N²−1)
⇒ c₁ = lim N(ρ²−2) = 0        (无 1/N 项！)
⇒ c₂ = lim N²(ρ²−2) = 2
⇒ 余项精确:  |ρ²−2| = 2/(N²−1) ≤ 6/N²   (N≥2)
```

`'t Hooft` 定标（`λ=g²N` 固定）下 2D 的质量：

```
m_fund(N) = (λ/4)(1 − 1/N²) ,   m_adj(N) = λ/2  （对一切 N 精确 N-无关）
⇒ m(∞) = λ/4 或 λ/2 > 0，余项 = λ/(4N²)（几何）
⇒ ε-论证: N₀ = ⌈2C/m(∞)⌉ = 1 ⇒ 一切 N 的 m>0        [T]（2D 内）
```

**⇒ 这条路的"最好情形"在 2D 里是定理 —— 而它给的正是 2D 已经有的东西（零新地）。**

**同时它给出物理 `N` 上的代价（这是本轮最硬的一条数）**：

| `N` | `ρ²(N)` | 相对 2 的偏差 | `Λ★−2m₁²` | 相对错 |
|---|---|---|---|---|
| 2 | 2.6667 | **33.3%** | 0.5 | **25%** |
| 3 | 2.2500 | **12.5%** | 1/3 | **11.1%** |
| 4 | 2.1333 | 6.67% | 0.25 | 6.25% |
| 10 | 2.0202 | 1.01% | 0.1 | 1.0% |
| 100 | 2.0002 | 0.010% | 0.01 | 0.01% |

（`b02_largen.log` PART A/C）**⇒ "大 `N`"在 `N=2,3` 上**不存在**：`1/N²` 首修正就是 12–33%。**

### 2.2 4D：`c₁` 的界**没有**

- 已证者（`[T]`，读摘要）：Chatterjee–Jafarov 的 `1/N` 展开**在强耦合、固定 `β`、`SO(N)`、Wilson 环期望**上，且**自述为 asymptotic**。
- **缺的不是常数大小，是"对阶一致"**：固定阶 `k` 的误差 `O(N^{−k−1})` 若存在，其常数依赖 `k`（阶乘增长，PART E 的 `[M]` 属型：`g*≈πN`、最小项 `≈e^{−2πN}`），故 `k→∞` 时无一致界。
- **窗口不交（决定性）**：物理极限要 `λ` 固定而 `β→∞`（`β∝N` 或 `∝N²`，依 `β` 约定，两种都 `→∞`）；已证展开是**固定 `β`** 的强耦合展开。**⇒ 固定 `β` 的 `N`-一致界，永远够不到 `λ`-固定的标度窗。**

## §4 · 判死线

### (a) 是否"通往物理 `N` 的路"？**否 —— 逻辑有效但窗口不交，且前件是 `[M]`**

逻辑骨架**是 `[T]` 的**（纯 `ε`-论证）：

```
m(∞) > 0  [T]   ∧   |m(N) − m(∞)| ≤ C/N^k   (定量界)
⇒ ∃ N₀ = ⌈(2C/m(∞))^{1/k}⌉ : ∀N≥N₀, m(N) ≥ m(∞)/2 > 0
```

2D 里它**确实是定理**（PART B：`C=λ/4`、`k=2`、`N₀=1`）。**但在 4D 它差分两处，且都是硬缺**：

1. **前件 `m(∞)>0` 是 `[M]`**（§1 第 4 行）。把 4D 的 `N=∞` 隙当定理，等于把 't Hooft 平面图论证当证明。
2. **窗口不交**：已证的 `1/N` 展开在 **固定 `β`、强耦合**；物理极限要 **`λ` 固定、`β→∞`**。固定 `β` 的 `N`-一致界在 `β→∞` 时不被任何已证定理控制。**⇒ 这条路的"最后一公里"与 `I2`/标度窗是同一堵墙，只是换了坐标。**

**⇒ 逐字**：**这不是通往物理 `N` 的路**；它是把 4D 的 `Λ★>m₁²` 换成 `Λ★(∞)>m₁²(∞)`——**同一个开问题，换到 `N=∞` 上仍然开**。

### (b) `N=∞` 的 `m>0` 是否也只是 `[C]`/`[M]`？**是 `[M]`（4D）；`[C]` 只在"Casimir 塔 = 全谱"这一假设下**

v05 的 `N=∞` 行（`V05-I2TOY.md:40,76–89`）**自己**标了 `[C]` 边界；`LOOP-RUNBOOK.md:5191` 逐字："对 4D 一言不发"。**⇒ `[M]` 明说。**

### (c) `1/N` 无一致收敛？**是 —— 但要说准是哪一半**

| 命题 | 判 | 依据 |
|---|---|---|
| 部分和对阶数一致收敛 | **假** `[C]` | 作者逐字 "asymptotic series"（`1604.04777` 摘要）；阶乘尾使 `g*≈πN`、最小项 `≈e^{−2πN}`（PART E，`[M]` 属型） |

**⇒ (c) 成立的那一半是"对阶不一致" + "物理窗内无界"；"发散 ⇒ 无用"这一强读法不成立（PART E 的 `e^{−2πN}` 仍 `→0`）。**

## §5 · 路径（本轮新增的、可操作的两条）

1. **正面的唯一用法（弱但真）**：`1/N` 展开是**唯一已证的"从一个 `N` 搬到另一个 `N`"的机制**（Chatterjee–Jafarov）。把它当**搬运工**、不当**来源**：任何在某个 `N` 上得到的 `[T]`，可以用它搬到 `N±1`，误差 `O(1/N²)` 可算。**但这不产生 4D 的 `m>0`。**
2. **要它变成路，必须补的那一条（本轮精确定位）**：**"`λ` 固定、`β→∞` 时的 `1/N` 一致界"**。这一条比 `I2` **更强**（它蕴含隔离在所有 `N` 上的一致版本），因此**不是捷径，是加压后的同一堵墙**。⇒ 建议**不再单独派 `N=∞`/`1/N` 路**；把它并进 `I2`（`Λ★>m₁²`）的总账，作为"若 `I2` 在 `N=∞` 可解，则 `1/N` 可搬"的**附属条款**。
3. **保留的唯一 `N=∞` 资产**：2D 的精确 `ρ²(N)=2+2/(N²−1)` 与 `m_fund=(λ/4)(1−1/N²)` —— 它们是**校准器**（检验任何 `1/N` 方案在可解极限上是否正确），**不是砖**。
