### 2.1 引理（`D04` 命题 3.1 的单侧化：从 `C = A/Δ` 推广到任意可积单侧 C）

> **引理（GW1）**。设 `f ∈ C¹([b₀,b₁])`（b₀ < b₁）、`C, G : ℝ → ℝ`，`G` 是 `C` 在区间上的原函数（`G' = C`；对连续 C 这就是"`∫_{b₀}^{b₁} C = G b₁ − G b₀` 有限"的可行形式）、种子 `f(b₀) ≥ ε > 0`、微分不等式在 `f ≥ 0` 的点上成立：`f'(x) ≥ −C(x)·f(x)`。则
> **(a)** 对一切 `x ∈ [b₀,b₁]`：`f(x) ≥ ε·exp(−(G(x) − G(b₀))) > 0`；
> **(b)** 反之，`f > 0` 于紧 C¹ 区间 ⇒ 存在**常数** `C` 使 `f' ≥ −C·f`。
> ⇒ 对 C¹ 载体：**"可行 C（可积）的存在 ⟺ f 无零点"**——D04 命题 2.1 的机器检版本。

*证明（首零点论证，完整）*：
1. **正段上的单调化**。设 `f > 0` 于 `[b₀, y)`。令 `Φ(t) := f(t)·e^{G(t)−G(b₀)}`。在 `t ∈ [b₀,y)`：`f(t) > 0` ⇒ 不等式适用 ⇒ `Φ'(t) = e^{G(t)−G(b₀)}(f'(t) + C(t)f(t)) ≥ 0`。在端点 `y' < y`（此时 `f(y') > 0`，全段 `[b₀,y']` 正）：FTC-2 给 `Φ(y') − Φ(b₀) = ∫_{b₀}^{y'} Φ' ≥ 0` ⇒ `Φ(y') ≥ Φ(b₀) = f(b₀) ≥ ε`。`Φ` 连续 ⇒ 由左极限 `Φ(y) ≥ ε`（助手引理：连续函数在 `[a,b)` 上 ≥ c ⇒ 在 b 处 ≥ c）。⇒ `f(y) ≥ ε·e^{−(G(y)−G(b₀))}`。
2. **首零点**。反设 `∃x`：`f(x) ≤ 0`。令 `Z := {t ∈ [b₀,b₁] : f(t) ≤ 0}`（非空、有下界）、`s := inf Z`。则 (a) `b₀ ≤ s`（b₀ 是下界）且 `s ≤ b₁`；(b) `t < s ⇒ f(t) > 0`（否则 `t ∈ Z ⇒ s ≤ t < s` 矛盾）；(c) 第 1 步在 `y = s` 处适用（只需 `[b₀,s)` 正）⇒ `f(s) ≥ ε·e^{−(G(s)−G(b₀))} > 0`；(d) 连续性 ⇒ `s` 的邻域内（∩Icc）`f > 0`；(e) 下界稠密性（`∀d>0 ∃z∈Z: z < s+d`，否则 `s+d` 是更大下界）给 `z ∈ Z`、`z ≥ s`、`z < s+δ` 落入该邻域 ⇒ `f(z) > 0` 与 `z ∈ Z` 矛盾。⇒ `Z = ∅` ⇒ 全区间 `f > 0`，第 1 步对一切 y 成立。∎
3. **(b) 的证明**：`g := f'/f` 连续于紧区间（f > 0）⇒ 紧性给 `|g| ≤ M` ⇒ `|f'| = |g|·f ≤ M·f` ⇒ `C := M`（常数）。∎

**机器检**：`research/v3/species/GW1-bridge.lean`（本轮落盘，mathlib 风格）——`GW1.gronwall_floor`（(a)）、`GW1.pos_C_exists`（(b)）、`GW1.additive_floor`（加性版：`f' ≥ −A`、A 与 f 无关 ⇒ `f(x) ≥ f(b₀) − (G(x)−G(b₀))`，HF 货币形状）+ 助手 `GW1.left_le_of_leOn_Ico`。**`sorry = 0`；`#print axioms` = `[propext, Classical.choice, Quot.sound]`（无 sorryAx）**；编译器 lean 4.33.0-rc1 + mathlib badcache（§5）。未形式化的一步：连续 C ⇒ 原函数存在（FTC-1；`exact?` 两探未命中现成引理名，故引理以"原函数 G 存在"为假设——对连续 C 与"`∫C` 有限"等价，正文口径已写明）。a.e. 可微版：`[C]`（初等，未形式化）。
