## 0. 判死线（先读这段）

**答：`Var` 是 β-一致有界的，而且是"冻结到一个可算的极限"，不是"拟合出来近似不动"。极限有闭式**：

```
V_∞(θ)  :=  lim_{β→∞} Var_μ(G_v+Φ' | ξ=0)  =  (1/36)·tan²(θ/2)  =  sin²(θ/2) / (36 cos²(θ/2))
```

- `θ=π/2`：`1/36 = 0.0277778`（O05 存档 `0.0278`，相对差 `8.0e−4`）
- `θ=3π/4`：`5.828427/36 = 0.1619008`（O05 存档 `0.1618`，相对差 `6.2e−4`）

**⇒ 判 (a)。** `V_∞` 有**闭式**，`[T]`（作为极限，见 §3 命题 3），不是只能数值。O05 的 `0.0278/0.1618` 是有限 β 外推值，本次给出精确值；两个数的偏差（`8e−4`/`6e−4`）正是外推误差。

**⇒ 判 (c)：不触发。** 没有反例；`sup_β Var = lim_{β→∞} Var = V_∞`（数值上 `Ψ(B)=Var/V_∞` 单调↑、`≤1`、只有 `B=∞` 取到 1）。O05 的 `k≈0.0023` 不是拟合产物：`1−Ψ ≍ 0.13/B`，逐点复算 `β=50→200` 得 `k = −0.002318`（vs 实测 `0.0023`，3 位有效数字一致）。
**但**：常数**不是 θ-一致**的（`V_∞→∞`，`θ→π`），与 O05 §5 一致；`θ=π` 精确发散（`Var=β²·0.0110593`），机制在 §2 命题 2 的假设被破坏那一格。

**β-冻结的机制（一句话）**：切片律只依赖**一个**组合 `B := βcos(θ/2)`（命题 1），而 `B` 的作用是把律在 `u=r/2` 上压成宽度 `B^{−1/2}` 的 Rayleigh 律；因 `g'(0)=0`（`g=sin u/(2u)` 在 `u=0` 是驻点），`Var(g) ≍ B^{−2}`，乘上显式前因子 `β²sin²(θ/2)` 后 `β` **全部抵消**，只剩 `θ`。

## 2. 把"冻结"写成可证的命题

### 命题 1（精确 β-约化）`[T]`

**陈述.** `μ_β(·|ξ=0)` 只通过 `B = βcos(θ/2)` 依赖 `(β,θ)`；且

```
Var_{μ_β}(f|0) = β² sin²(θ/2) · W(B),      W(B) := Var_{ν_B}(g),   ν_B ∝ sin²u·e^{−B(1−cos u)}du/u .
```

**证明.** 切片作用量 `S|_slice = β(1 − cos(θ/2)cos u) = β − B cos u`，`β` 是常数因子，在归一化中消去；`J = sin²u/u²` 与 `β` 无关；`d²ξ = 4u du dφ` ⇒ 条件密度 `∝ sin²u e^{−B cos u}du/u`。`f = β s g(u)`，`g` 只含 `u`。∎

**这条命题就是"切片律随 β 收缩"的精确形式**：`Var` 对 `β` 的全部依赖只剩两处——显式前因子 `β²s²`，以及 `B=βc` 对律的隐式作用。O05 的定性说法（"横向宽度 ∝β^{−1/2}"）在此被替换为"一个参数的族 `ν_B` + 一个显式幂"。

### 命题 2（宽度 → 方差，`B^{−2}` 的来源）`[T]`

**陈述.** 令 `y = u√B`（即 `u` 的宽度标度变量），则 `ν_B` 的密度 `→ y e^{−y²/2}dy`（Rayleigh，`E[y²]=2`），且 `g = 1/2 − y²/(6B) + O(B^{−2})`，于是

```
W(B) = Var(y²)/(36 B²) · (1 + O(1/B)) = (1/36)B^{−2}(1+O(1/B)) ⇒ Var = β²s²/(36B²)·(1+O(1/B)) = tan²(θ/2)/36 · (1+O(1/B))
```

**证明.** `B(1−cos u) = y²/2 − y⁴/(24B)+…`；`sin²u/u = (y/B^{1/2})·… ` 给出 `u²=y²/B`，`sin u/u = 1−u²/6+O(u⁴) = 1 − y²/(6B)+O(B^{−2})`；`Var(y²)=4`（Rayleigh: `E[y⁴]=8`），故 `Var(g) = 4/(36B²)·… `。∎

**这里是"为什么是 `β^{−2}` 而不是 `β^{−1}`"的关键**（O05 §3 只用一句话带过）：`Var(u) ≍ B^{−1}`（宽度 `B^{−1/2}`），但 `Var(u²) ≍ B^{−2}`，因为 `ν_B` 在 `y` 变量下是**指数尾/Rayleigh**（相对涨落 `O(1)`），不是 Gaussian（相对涨落 `O(B^{−1/2})`）。再叠加 `g'(0)=0`，`Var(g) ≍ Var(u²) ≍ B^{−2}`。**若 `g'(0)≠0` 则是 `B^{−1}`**——O05 §6.1 的窗口警告在此被解释清了。

### 命题 2′（为什么 `θ=π` 破格）`[T]`

`θ=π ⇒ c=0 ⇒ B≡0`：命题 1 的族退化为**单点** `ν₀`（= Haar），命题 2 的 `B→∞` 失效 ⇒ `Var = β²·s²·W(0)`，`W(0)=Var_Haar(g)=0.0110593` 精确 β-无关 ⇒ `Var ∝ β²` 发散。**这就是 O05 表中 `θ=π` 的 `k=2`**，且是同一条机制的边界，不是另一个现象。

## 3. 命题 3（闭式极限）`[T]`

```
V_∞(θ) = (1/36) tan²(θ/2)
```

证明即命题 2 的 `B→∞` 极限（`Var(y²)=4`，`g = 1/2 − y²/(6B)+O(B^{−2})`，`Var(f)=β²s²Var(g)`）：
`Var(f) → β²s²·4/(36B²) = β²s²/(9B²) = β²s²/(9β²c²) = s²/(9c²)·(1/4)·… ` 直接给 `sin²(θ/2)/(36cos²(θ/2))`。**误差项 `O(1/B)`，即 `O(1/β)`。**

**这张表把 O05 §3 的 `Var_∞` 列从"数值上确界"升级为"闭式"：**

| `θ` | O05 数值 `Var_∞` | 本文件闭式 | 相对差 |
|---|---|---|---|
| `π/2` | `0.0278` | `1/36 = 0.02777778` | `8.0e−4` |
| `3π/4` | `0.1618` | `5.8284271/36 = 0.1619008` | `6.2e−4` |
| `θ→π` | "→∞" | `≈ 1/(9(π−θ)²)` | 同阶（`tan(θ/2)≈2/(π−θ)`） |

## 4. `β`-一致界，两个等级

### 4.1 锐界（数值认证）`[C]`

定义 `Ψ(B) := Var/V_∞ = 36B²W(B)`。`[P2]`（36 个对数网格点，`B∈[1e−3,1e4]`，自适应 Gauss–Kronrod，`epsabs=1e−13`）：

```
max_{grid} Ψ = 0.99998649  (at B=1e4)   ⇒ Ψ ≤ 1  ✓
Ψ 单调不减 (容差 5e−9)  ✓        1−Ψ ~ B^(−1.017)   (大 B 端 14 点拟合)
```

误差棒（`[P6]`，双容差 `1e−11` vs `1e−15`）：`B=1` 差 `3.0e−15`；`B=10` 差 `4.0e−13`；`B=1000` 差 `9.2e−8`（`B=1e3` 时 `1−Ψ` 本身已 `1.3e−4`，故相对误差 `<1e−3`）。**⇒ 数值上 `Var ≤ V_∞` 严格成立，等号只在 `B=∞`。**

`1−Ψ ≍ 0.13/B`：在 `B=35.355`（`β=50,θ=π/2`）与 `B=141.42`（`β=200`）**逐点复算**得 `Ψ = 0.99582867 / 0.99903322`，`1−Ψ = 4.171e−3 / 9.668e−4`（`0.13/B` 预测 `3.68e−3 / 9.19e−4`），于是

```
k_theory := dlogΨ/dlogβ |_{50→200}  =  −0.002318
k_measured (O05 §0/§3)              =   0.0023
```

**逐位一致到 3 位有效数字**：O05 的 `k≈0.0023` 就是"`1−O(1/β)` 逼近有限极限"的斜率，**不是"没有极限"**，也不是拟合假象。

### 4.2 严格界（可证，常数不锐）`[T]`

`w := 1−cos u ∈ (0,2)` 时 `ν_B ∝ φ(w)e^{−Bw}dw`，`φ(w) = √(w(2−w))/arccos(1−w)`，且 **`g = φ/2`**（`φ(0)=1`、`φ(2)=0`、`φ` 递减）。三条引理：

1. **尾界**：`ν_B((ε,2]) ≤ C₁ e^{−Bε}`，`ε ≥ 1/B`，`C₁ = 1/(1−e^{−1}) = 1.581977`。
 （分子 `≤ φ(ε)e^{−Bε}/B`；分母 `≥ φ(1/B)(1−e^{−1})/B`；`φ` 递减消去。）`[T]`
2. **矩界**：`Var(w) ≤ E[w²] = 2∫ε F̄ dε ≤ 2[1/(2B²)] + 2C₁·(2/e)/B² = 3.3279/B²`。`[T]`（实测 `E[w²]B² = 0.47, 1.06, 1.69, 1.93, 1.99`（`B=1,2,5,20,100`），**均在界内**且 →2）
3. **Lipschitz 分裂**：`Var(φ) = ½E[(φ(w)−φ(w'))²] ≤ L²Var(w) + P(w>w₁)`，`L = max_{[0,w₁]}|φ'|`；实测 `|φ'(w₁)| = 0.348/0.361/0.405/0.434/0.504` 于 `w₁=0.3/0.5/1.0/1.2/1.5`。`[T]`（`φ'` 公式解析）
4. **range 界**（小 `B`）：`f ∈ (βs/π, βs/2)` ⇒ `Var(f) ≤ β²s²(1/2−1/π)²/4` ⇒ `Ψ ≤ 0.2971B² ≤ 1` 当 `B ≤ 1.834`。`[T]`（**f 的有界性在这里真的用上了**）

合并（`[P4]`，61 点网格）：`C_rig = max_B min(0.2971B², min_{w₁}[29.95L² + 9B²·min(1,C₁e^{−Bw₁})]) = 6.505`。即

```
Var_μ(G_v+Φ'|0) ≤ 6.51 · V_∞(θ) = 1.808 × tan²(θ/2)     对一切 β ≥ 0, 0<θ<π   [T]
```

**严格界的松弛全在两处可指名的地方**：`L≈0.4` 而"有效斜率"实测 `≈0.19`（因 `φ` 的二阶项抵消一半），以及尾比值常数 `C₁`。把 `L` 换成 `φ` 的精确二阶展开（即 `W(B)` 的闭式）就能收到 1，见 §6。

## 5. 四个工具逐个判（任务清单逐条）

| 工具 | 能给 β-一致界吗 | 判据（本文件实测/推导） |
|---|---|---|
| **`f` 的有界性** | **小 `B` 能，大 `B` 不能** | `f ∈ (βs/π, βs/2)`，`f` 有界但**界 ∝ β** ⇒ `Var ≤ β²s²·0.0331` ⇒ 比值 `0.2971B²`。**只有 `B≤1.834` 时比值 ≤1**（`[T]`，§4.2-4）。它是"小 β 端"的**锐**工具，大 β 端必须靠收缩。 |
| **Poincaré（β-一致 λ）** | **不能** | `λ_cond ≥ 0` 是唯一 β-一致下界（O05 §2）。**新证据**（`[P5]`）：切片上 `Hess V` 的**总**（含 `Φ''`）径向特征值下确界 `= +0.2896 (B=0.707)`、`−0.3835 (B=7.07)`、`−163.4 (B=707)` ⇒ **切片本身在 `B≳5` 后非凸**（`u>π/2` 区，径向模），故 BL 前提 `Hess⪰λ>0` **在切片上也不成立**，`λ` 只能随 `β` 抬高 ⇒ 界与 `Var` 同 β-阶（O05 已实测 `bound/Var∈[1.02,1.51]`）。**判：不能给 β-一致界。** |
| **显式 Laplacian 谱** | **不能（有限 β）** | 约化算子是 1D 径向 `−d²/du² + …` 但带权重 `sin²u e^{−Bcos u}/u`；`1/u` 使本征问题化为**复阶/incomplete Bessel** 组合，**没有初等闭式谱**。`[NG]`（不是"未查到"，是结构性的：`1/u` 项不存在 Bessel 闭式）。**但 `B→∞` 的极限谱就是 OU/Rayleigh**，这一步给出闭式（§3）。 |
| **Gaussian 近似** | **能，且给出精确常数** | `B→∞`：`y=u√B` 下律 `→ y e^{−y²/2}dy`，`Var(y²)=4` 精确；`g = 1/2 − y²/(6B) + O(B^{−2})` ⇒ `Var = V_∞(1+O(1/B))`。这是**唯一**能同时给出"β-一致 + 常数正确"的工具；它的严格部分是命题 2/3。`[T]` |
