**`T` 的定义（本文全篇用它）**：
```
T[U,U'] = e^{−S_sp(U)/2} · e^{−S_sp(U')/2} · W(U,U')
W(U,U') = ∫ ∏_x dV(x) exp[ (β/2) Σ_{x,i} Re tr( U_i(x) V(x+î) U'_i(x)† V(x)† ) ]
```
`U,U' ∈ SU(2)^{3L³}`（`L=2`：24 条），`V` 是 `L³` 条时向 link。所以：

- **算子的维数是 ∞**：`L²(SU(2)^{24}, Haar^{24})` 是可分无穷维 Hilbert 空间，`T` 是作用其上的积分算子。
- **矩阵元的积分维数是 `3L³ = 24`**（`L=2`）；这是 `T` 里唯一"难算"的子对象（`d02_dimcount.log [D]`）。
- `r04` 的 `143` 是**另一个对象**：整个 4D 环面一次性参数化后的规范商维数。**把 `143` 当 `T` 的维数是口径串台**（`LOOP-RUNBOOK:3965–3988` 的 `143` 全部属于 (A)）。

## 2. `T` 到底是什么样的算子（`d02_cert.log [6]`）

- **核严格正**：`W > 0`（被积函数在开集上 `>0`），`e^{−S_sp/2} > 0` ⇒ `T[U,U'] > 0` 对一切 `U,U'`。
- **有界 ⇒ 紧**：粗界 `0 < T[U,U'] ≤ e^{β·6L⁴} = e^{240}`（`L=2`，机检 `1.70089e+104`）；把 `e^{−βN_p}` 归一化并进去则 `T ≤ 1`（因 `S_W ≥ 0`）。有限测度空间上有界核 ⇒ Hilbert–Schmidt ⇒ **紧**。
- ⇒ **Jentzsch / Perron–Frobenius 成立**：`λ₁` 单重、`λ₁>0`、本征向量 `φ>0`、`|λ_j|<λ₁ (j≥2)`。

**这就是本题的核心事实**：PF 给的是**符号/结构性**（严格不等号），**不是数**。要 `m(L=2) = −log(λ₂/λ₁)` 的**区间**，必须再用三件之一（下节），每一件都不便宜。

## 3. 想给出数：三条路，各自的真实成本

### 3.1 路 I：截断 + 余项（`d02_cert.log [1][2]`）

SU(2) 的 Peter–Weyl 基按**半整数** `j` 标号：`χ_j(θ)=sin((2j+1)θ)/sinθ`、`dim = m = 2j+1 ∈ {1,2,3,…}`。
**只有整数 `j` 是错的**（那只张成 `SO(3)` 的字符）——这一点本轮踩过：见 §7 的纠错记录。

- 严格闭式（正交性 + Basset 型积分，机检 `rel ≤ 3e−29`）：
  `κ_m := ∫ e^{βcosθ} χ_{(m−1)/2} dU = 2 m I_m(β)/β`
- 严格恒等式：`Σ_m m·κ_m = e^β`（`M=13` 时机检 `rel = 4.1e−9`）。
- 严格尾界（`I_m(x) ≤ (x/2)^m e^{x²/4}/m!`，`x>0`）：
  `β=2.5` 处 `M=7`：`tail/e^β ≤ 8.9e−3`（机检 `valid=True`）；`M=9`：`≤ 1.5e−3`。

**代价**：截断到 `j ≤ J`（`m ≤ 2J+1`）后，每条 link 的基大小 `b_J = Σ_{m≤2J+1} m²`：
`J=2 → 55`、`J=3 → 140`、`J=4 → 285`。切片有 `3L³ = 24` 条空间 link ⇒

```
J=3: 截断态数 = 140^24 = 1e51.5          (L=2)
J=4: 285^24 = 1e58.9                     (L=2)
L=4 任意 J: 140^192 = 1e412              -> 死
```
**⇒ 路 I 在 `L=2` 就已经死了**：不是维数问题（24 维积分可行），是**态数 `10^51.5`**。

### 3.2 路 II：振荡 / Hilbert–Dobrushin 界（`d02_cert.log [4][5]`）

定义 `Δ := sup_{U,U',V,V'} |log[ T(U,U')T(V,V') / (T(U,V')T(V,U')) ]|`，则 Birkhoff–Hopf 振荡收缩给
`λ₂/λ₁ ≤ tanh(Δ/4)`。**`d=2` 时取等**（机检：对称 `2×2` 正矩阵，`4/4` 组 `J` 全部 `equal=True`）⇒ 界是**锐的，只在 `d=2`**。

**本轮唯一的结构性新东西**（机检 `[5]`，2000 组随机数 `max|lhs−rhs| = 5.96e−8`）：

```
T[U,U']T[V,V'] / (T[U,V']T[V,U'])  =  W[U,U']W[V,V'] / (W[U,V']W[V,U'])
```
即 **`S_sp`（空间 plaquette）因子在振荡比里严格相消**。所以 `Δ` 只依赖 **3D 的 `W`**——一个 `L³` 位点、`L³` 条时向 link 的 3D 规范积分，而不是 4D 全环面。

**这条为什么仍然给不出数**：`Δ` 要取 `sup`，成对出现 ⇒ 变量数 = `2 × 72 = 144`（`L=2`，物理 `2×48=96`）。而且 `β=2.5` 是弱耦合，`Δ` 随 `β` 增长；`tanh(Δ/4) → 1` 只需要 `Δ ≳ 8`。**预期这条路在 `β=2.5` 无内容（`vacuous`）**，但本轮**没有**证 `Δ ≥ 8`，所以只能说"未证、预期"。`[C]`

### 3.3 路 III：闭式（只有 toy 有）

**单 link 卷积**（`d02_cert.log [3]`）：`T f(U) = ∫ e^{β cos(U V†)} f(V) dV` 被 Schur 引理**精确对角化**，
本征向量 `D^j_{mn}`、本征值 `κ_j/(2j+1) = 2 I_m/β`、重数 `m²`。于是

```
λ_m/λ₁ = I_m(β)/I₁(β)                                   (精确闭式)
m=2 (j=1/2，基础表示，重数 4): λ₂/λ₁ = I₂/I₁ = 0.5071951000470209
                                    m_toy = 0.678859536696
```
**与语料对上**：`u_tile(2.5) = I₂/I₁ = 0.5071951000`（`RATE-UNIFORM.md:67`）逐位吻合；而 `LOOP-RUNBOOK.md:1838` 记的 `c(2.5) = +0.679`（"两约定"之一）**正是 `−log u_tile = 0.678860`**。⇒ 字典条目：**单 link 转移矩阵的隙 = `−log u_tile(β)`**。

**但这不是物理点**：它是 decoupled-link toy，`L=2` 的 `T` 有 8 条时向 link 耦合、24 条空间 link。`[T]`（toy）/`[E]`（非物理）

## 4. 关键：`L` 固定 vs `L` 一致（题面第 3 条）

**题面的前提要改一个字**：

> "`m(L=2)>0` 是平凡的（有限维、正矩阵、`λ₁>λ₂` 由 PF 严格）"

- "正矩阵 + PF ⇒ `λ₁>λ₂`" **对**。`[T]`
- "**有限维**" **不对**：`T` 是 `L²(SU(2)^{24})` 上的积分算子，**无穷维**。要把它变成有限维必须先截断，而截断系统的隙 `≠` 真隙（余项见 §3.1）。`[T]`
- 所以正确陈述是：**`m(L=2) > 0` 定性成立（PF），数值无证书**。

**并且**：`L` 固定的 `>0` 与 `L` 一致的下界是**两个不同命题**：
- `∀L: m(L)>0`（含 `L=2`）——由紧性 + 严格正核，逐 `L` 成立，**但 `L`-依赖的常数可以是任何小的正数**。
- `∃m₀>0 ∀L: m(L) ≥ m₀` —— **这才是质量隙**。它需要 `λ₂/λ₁` 的 `L`-**一致**上界，而所有"逐 `L` 证书"都不会自动给出一致性（`L` 越大自由度越多、截断态数 `b^{3L³}` 爆炸）。
- 结论：**`L`-一致是唯一真正的难点**，且它与"搬运"是**同一个靶**（C5 = 台阶 1，踏板 `L=2`；`T10-C5.md:14` 同判）。`[T]`

## 5. 判死线

### (a) `L=2` 上可做严格区间证书？——**不成立**

给不出 `m(L=2)` 的区间。三条已知路线：路 I 态数 `1e51.5`（`L=2`）已经不可做；路 II 需 `144` 维 `sup` 且预期 `Δ ≳ 8`（`vacuous`，未证）；路 III 只有 toy。
**"物理点上的第一个严格数"：不存在。** 本轮能给的唯一严格数是 toy 的 `λ₂/λ₁ = I₂/I₁ = 0.5071951000`、`m = 0.678859536696`，**明确标注非物理点**。

### (b) `L`-一致是唯一难点？——**成立**，且它就是 C5

见 §4。`143` 维墙确实**不**拦 `T`（`24 ≪ 143`），但拦不住的那一堵换成了"定量 + 一致"。

### (c) `L=2` 的转移矩阵已经太大？——**不成立**（但另有硬墙）

- 维数上：矩阵元积分 **24** 维，`r04` 的可行性门槛是 `≤20` ⇒ **只差 4 维**，不是"差 123 维"。这是本题**唯一的正面发现**：`T` 把 `143` 维的对象换成了 `24` 维的对象。
- 但"太大"换个地方成立：截断态数 `10^51.5`（`L=2`），`L=4` 是 `10^412`。**指数在 `L³`，不在 `L`。** `[T]`+机检
