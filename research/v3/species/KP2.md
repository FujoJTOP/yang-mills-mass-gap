## 1 · 第一问：`K̂` 用 `sup`（逐字，两处独立）

```
C06:118  (5.1)   K̂ := sup_γ ( ∏_ℓ R(ℓ) · τ_γ )^{1/|γ|} ,   KP ⟺ K̂·eΔ·u < 1 ,   1/48 ⟺ K̂ < 7.0632853
```

## 2 · 第二问：`sup` ⇒ 抵消对 `K̂` 无用（结构性）

### 2.1 一句话机制

```
要证 K̂<θ，必须证：对每一个簇 γ， (∏R·|φ^U|)^{1/|γ|} < θ。
这式子对 γ 是逐个的，不含 Σ_γ ⇒ 任何"簇与簇之间相消"的机制都作用不到它。
```

等价地：`sup_γ |φ^U(γ)|^{1/|γ|}` 在**任意** `φ^U(γ) ↦ ±|φ^U(γ)|` 的符号重排下**逐位不变**。`tt2` 的交错（`S5`：`Σ_n(−1)^n m_n`）是**先按壳求和、再谈号**；`K̂` **从不求和**。`[T]`

### 2.2 更硬的一条：`−64` 已经是抵消后的数（`[E]`，本轮精确枚举）

| 量（八面体 `K_{2,2,2}`，`|E|=12`） | 值 |
|---|---|
| `Σ_{A⊆E, 连通} 1`（无号总质量） | **2656**（按 `|A|=5..12`：`384,740,744,489,220,66,12,1`） |
| `Σ_{A⊆E, 连通} (−1)^{|A|}`（带号） | **−64** |
| 抵消已给出的压缩 | `2656/64 = 41.5×` |

⇒ **用户的关键观察要反过来读**：`φ^U` 本身是交错和**这件事是对的**，但这正意味着**"立方体的 `−64`"已经把 `(−1)^{|A|}` 那一层的抵消全部用光了**（`41.5×`，精确整数）。`K̂` 拿到的就是残余；再要抵消，只能去"簇与簇之间"找 —— 而 `sup` 里没有"簇与簇之间"。`[T]`+`[E]`

### 2.3 若真改读 `limsup`，也救不了（两条独立判死，同号）

- `tt2 S6`：壳层配对**完备**但增益上限常数因子 `2`；`m_n ∝ ū^n` 时每对 `= −(ū−1)m_n`，`ū=33.98` 处**放大 `32.98×`**。`[T]`+`[E]`

### 3.2 为什么它顶不高 `K̂`（两条独立、各自足够）

**(i) `∏R` 记账（算术级）**：`K₆` 束的 `κ` 直方图 `{6:1, 1:18}`（1 个公共 link `κ=6`，18 条外沿 link 各 `κ=1`）。`R(2)=2`、`R(4)=5/2`、`R(6)=2.8`（`C06:78`，`c06_window.log §1`）。

```
立方体：∏R = 2¹² = 4096        ⇒ (∏R)^{1/6} = 4.000000 ，K̂ = 4.0000×2.0000000 = 8.0000000
K₆ 束 ：∏R = 2.8·1¹⁸ = 2.8     ⇒ (∏R)^{1/6} = 1.1872067 ，K̂ = 1.1872×2.2209062 = 2.6366747
比值：∏R 4096/2.8 = 1462.857 ；K̂ 8.0000/2.6367 = 3.034
```

⇒ **`|φ^U|` 大 `1.875×`，`K̂` 反而小 `3.034×`**：`K₆` 把 6 片挤在 1 条 link 上（`∏R` 极小），而 `K̂` 要的是"每片分摊的 `∏R` 几何均值 × 每片 `|φ^U|`"。**`sup` 不在 `K₆` 取到。** `[E]`

**(ii) 支撑（结构级，更强）**：`C06:52–55` 逐字 `w(γ)≠0 ⟹ ∂γ=∅（无 κ=1 的边界 link）`；`R(κ)=1+mult(adj∈f^κ)/mult(1∈f^κ)`，而 `mult(1∈f^κ)=0`（`κ` 奇）⇒ `R(κ)` 对奇 `κ` **没有定义**（`c06_window.log §1` 只给 `κ=2,4,6`，Catalan 表 `0,1,0,2,0,5,…` 奇数位全 `0`）。⇒ **`K₆`/`K₅`（带 18/15 条 `κ=1` 边界 link）不在 `K̂` 的 `sup` 域内**，其单簇权为零。`[T]`
