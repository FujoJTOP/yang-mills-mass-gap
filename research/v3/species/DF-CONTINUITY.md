## §2 T1 精确定义（**一个**形变，写到底）

### 2.1 作用量、系数、边界条件

几何：`ℝ³ × S¹_β`，坐标 `(x₀,x₁,x₂,x₃)`，`x₃` 是**空间**方向、周长 `β`，`T=0`（`x₀` 非紧）。`Ω(x₀,x₁,x₂) = P exp(i∮₀^β A₃ dx₃)`。

```
   S_{a,β}  =  S_YM  +  ΔS_{a,β}

   ΔS_{a,β} = (a/g²) ∫_{ℝ³×S¹_β} d⁴x (1/β⁴) |tr Ω(x)|²
            = (a/(g²β³)) ∫_{ℝ³} d³x |tr Ω(x)|²            (顶角与 x₃ 无关 ⇒ 收缩一重积分)

   a > 0 无量纲；边界条件：x₃ 方向 periodic、无 twist；x₀,x₁,x₂ 方向 ℝ³（无界）
```
**量纲核对**：`[|tr Ω|²]=0`，`[d⁴x]=−4`，`[1/β⁴]=+4` ⇒ 顶角无量纲 ✓；等价地 `[d³x]=−3`、`[a/(g²β³)]=+3` ✓。
**系数选择**：`a` 必须 `> a_c` 才把 GPY 单环势的中心破缺极小值掀翻（能量密度比 = `a/(c₀g²)`，`c₀` 纯数；GPY 势 `~(c₀/β⁴)f(Ω)`）。`a < a_c` ⇒ 形变真空中心破缺 ⇒ 与纯 YM 小 `β` 的 GPY 相重合 ⇒ **路线完全没有控制**（这个分支不是"另一种可能"，是自毁）。
**命名**：`|tr Ω|² = (tr Ω)(tr Ω)†` 是 Polyakov 圈算符的**双迹**（"double-trace"），文献形 `Shifman–Ünsal 0802.1232`、`Ünsal–Yaffe 0803.0344`。

### 2.2 三问

**(1) 保持反射正性吗？—— 保持（在"空间圈"读法下）。[T-modulo-domain]**
理由：`x₃` 是空间方向 ⇒ 顶角在 `x₀` 上是**局域**的 ⇒ 转移矩阵读法 `S_E ⊃ +λ∫dx₀ O(x₀)`，其中

```
   O = ∫dx₁dx₂ |tr Ω|²  ≥ 0      （因为 |tr Ω|² = tr Ω† tr Ω 是正算子）
   ⇒  H  →  H + λO ，  λ = a/g² > 0 ：正自伴算子加项 ⇒ OS 正性与谱条件保持
```

**必须写明的陷阱**：把同一公式读成"**温度圈**"（`x₃` 是时间、`β=1/T`）时，形变是对**迹**的修改而不是对 `H` 的修改，RP **不**自动。**这是两个不同理论**；本路线只能用前者（`T=0`、空间圈）。

**(3) 中心对称性变了吗？—— 算子显式破缺；真空可线性实现。**

## §4 T3 连续性：把"沿路径无相变"写成精确命题

### 4.1 先纠正任务草拟的命题——它是**反的**

草拟：`|∂Δ/∂λ| ≤ C` + `Δ(λ=0) ≥ 0` + `Δ` 连续 ⇒ `Δ(0) ≥ inf Δ`。三条问题：
1. `|∂Δ/∂λ| ≤ C` 只给 `Δ(λ) ≤ Δ(0) + Cλ`：这是**用目标去上界别人**（D1 方向反的教科书形，与 `MONOTONE-COUPLING §2` 同型）。
2. 结论若读作 `Δ(0) ≥ inf_{λ}Δ(λ)`，则对任何函数**恒真**（值 ≥ 下确界）。
3. 结论若读作 `Δ(0) ≥ 0`，则由谱定理**无条件真**（反射正理论）。

### 4.2 三条精确命题（S 弱形 / S⁺=路线所需 / S\* 可用形）

```
(S)   Δ: [0,1]→ℝ 连续，Δ(λ)>0 ∀λ∈(0,1]，零点集在 (0,1] 内为空
        ⇒ Δ(0) ≥ 0                             [真；恒真，零信息]

(S⁺)  同上 ⇒ Δ(0) > 0                           [假]   ← 这就是"若路径上无相变，则隙存活"
```
