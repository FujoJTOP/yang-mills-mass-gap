## 1. 对象、模、采样（逐项可复算）

`V = S_W + Φ`，flat chart `X_ℓ = log U_ℓ ∈ ℝ³`（`U = exp(i σ·X)`），`dU = J dX`，
`Φ = −log J = −2 log(sin r/r)`，`r=|X|`。`v` = 归一化 **k=0 常模**：`v_{(x,μ=1),a} = δ_{a1}/L²`（`‖v‖=1`，`k=0 ⇒ ⊥ 纯规范`）。
`ξ = ⟨v,X⟩`，条件化在 `ξ=0`（由 `X→−X` 对称性 ⇒ 是边缘**众数**）。

```
G = ∂_v S_W,  Φ' = ∂_vΦ,  H_sv = v^T Hess_X S_W v
Δ_dyn = E[H_sv|0] − Var(G|0)                 （h1c 的 Δ_dyn 项）
W_geo = E[Φ''_vv|0] − Var(Φ'|0),  X_cov = −2Cov(G,Φ'|0),  W_full = W_geo + X_cov
G''(0) = (E[H_sv+Φ''] − Var(G+Φ'))|0 = Δ_dyn + W_full        [eq:split]
恒等式 (I):  W_full = E[Φ''] + Var(G) − Var(G+Φ')             [H1C-WFULL eq (I)]
```

**精确条件采样**：`ξ` 是 `X` 的**仿射**泛函 ⇒ 约束面是超平面，力/动量用 `P = 1 − vv^T` 投影后，leapfrog **精确**留在 `{ξ=0}` 上（无 Jacobian、无偏差）。这是普通 HMC + 秩一投影，非近似。
`H_sv` 由沿 `v` 的中心二阶差分给出（`h=0.05`；`h=0.05/0.10/0.20` 三点差 `<4e−3` 相对，见日志），`Φ',Φ''` 解析闭式。

## 3. `Δ(L)` 的 `L`-标度

- **`Δ = G''(0)`**：`Δ(3)/Δ(2) = 0.463 ± 0.33` ⇒ 名义 `k = ln(2.015/0.934)/ln(1.5) = 1.90`，`σ_k = 1.75`。**指数判不出**（`k=0` 差 1.1σ；`k=4` 差 1.2σ）。
- **`Δ_dyn`**：`L=2` 到 `L=3` **变号**，`|Δ_dyn|` 从 1.07 掉到 0.57（`L=3` 与 0 相容）⇒ **幂指数无定义**。
- **非 `O(L^{−k})` 的直接理由**：两个成分 `E[H_sv]`（`−6.6%`）与 `Var(G)`（`+23%`）**各自几乎不动**，`Δ` 只是两个 `O(1)` 量之差 ⇒ `Δ` 天然是 `O(1)` 量级的**残差**，其 `L`-变化被单量误差淹没。没有任何成分显示 `L^{−2}`/`L^{−4}` 式的掉法。
- **判**：`Δ = O(1)`（两个体积上都是 `O(1)` 且 `>0`，`L`-变化 `≤2×` 且 `<2σ`）；指数**判不出**，只能在"`=0` 相容"的意义上记 **(a)**。

## 4. 与 `h1c` 的关系式（`Δ` 在哪一项）

```
G''(0) = Δ_dyn + W_geo + X_cov = Δ_dyn + W_full        [eq:split，逐字]
⇒ 若 Δ := E[H]−Var(G)（本任务字面定义），则 Δ 就是 h1c 的 Δ_dyn 项，
```

## 5. 判（(a)/(b)/(c)）

- **(a) `Δ` 的 `L`-指数与 0 相容 ⇒ `(L,a)`-一致性有支撑 —— 主判，`[E]`。** 两体积 `G''(0)>0`（`2.01`、`0.93`），`W_full>0`（`0.95`、`1.51`）、`W_geo` 在 `L` 上**平**（`1.07→1.10`）。更强的支撑来自**结构**：`G'' = Δ_dyn + W_full`，`W_full` 的主体是几何/Prékopa 块（`E[Φ'']≈1.3`，`Var(Φ')≈0.2`），`L` 上不衰减 ⇒ `δ` 不会随体积塌到 0。
- **(b) 不成立（不作判）。** 名义 `k=1.90` 只有 `1.5σ`，且若 `Δ→0` 只发生在 `Δ_dyn`（`L=3` 已与 0 相容），`G''` 仍被 `W_full` 顶住 —— **(b) 的前提"`Δ→0 ⇒ 无穷体积只有 `δ=0`"在本分解下不成立**：`δ` 的极限是 `W_full`，不是 `Δ_dyn`。
- **(c) 不成立。** `G''` 降（`2.01→0.93`），`Δ_dyn` 降且变号。
- **`Var` 是否广延（(c) 的核对项，一并给）**：在 `‖v‖=1` 归一化下 `Var(G+Φ') = 5.59 → 6.36`、`Var(G) = 5.27 → 6.49`，`L=2→3` 只变 `+14%/+23%`（`1.2–1.9σ`），**没有** `(3/2)^4=5.06` 式的广延放大 ⇒ 这些量在归一化后是 `O(1)` **强度量**，`Δ` 的 `O(1)` 性是归一化的直接后果，不是动力学结论。

## 6. 酸测与自检（防 vacuous）

1. **`k=0` 模的自由场曲率为 0**：无质量自由规范场的二次型在 `k=0` 横向极化为 0 ⇒ 自由理论给 `G''=0`。故这里测到的 `G''≈1–2` **全部是相互作用内容**，不是自由高斯块 —— 酸测不 vacuous。
2. **对称性**：`E[G|0]`、`E[Φ'|0]` 在 `1σ` 内为 0（两体积）⇒ 采样器保持了 `X→−X` 对称性。
3. **`β=0` 精确对照**（纯 Haar，与 3D 球面积分逐项比）：`E[Φ'']_ex = 1.33334` vs `mc = 1.3283±0.0342`（`L=2`）/`1.3201±0.0205`（`L=3`）；`E[Φ'^2]_ex = 1.33334` vs `1.2526±0.1079` / `1.3667±0.1009` ⇒ `Φ` 机器与采样器均通过。
