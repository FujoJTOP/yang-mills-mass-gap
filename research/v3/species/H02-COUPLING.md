## §2 `BC` 的变分式：精确形式、**inf** 型、以及方向为何决定一切

### 2.1 定义与唯一正确的亲和变分式

`BC(μ,ν) := ∫√(dμ dν)`（Hellinger 亲和）。若 `μ ≪ ν`，记 `ρ := dμ/dν`，则 `BC = E_ν√ρ`。

**(V1) `[T]`（一行证明）**
```
BC(μ,ν) = inf_{φ: X→(0,∞)} ½ ∫ ( φ(x)^{−1} dμ(x) + φ(x) dν(x) )
极小点 φ* = √(dμ/dν)，极小值 = ∫√(dμ dν)
```
证明：`½(a/t + b t) ≥ √(ab)`，等号在 `t = √(a/b)`。

**(V2) `[T]` 为什么必然是 `inf`**：`√` 是凹函数 ⇒ `BC` 对 `(μ,ν)` **联合凹**且一次齐次 ⇒ 它是"仿射泛函的**下确界**"族中的元素，对偶侧自然是 `inf`。反过来，`KL / χ² / TV` 是**凸**散度 ⇒ 其变分式是 `sup`（Donsker–Varadhan 型）。**所以答案是：`inf` 型。**

**(V3) `[T]` 关键的结构事实**：`Π(μ,ν)`（耦合集）**不出现在任何精确式里**。`BC` 是密度比的**函数**——耦合只是"同一对测度的一种读法"，不是"一对可优化的变量"。所有 `BC` 与耦合的真实联系只有三条，且方向固定：
1. **tensorization / Kakutani**：`BC(⨂μ_k, ⨂ν_k) = Π_k BC(μ_k, ν_k)`（Fubini）；
2. **数据处理**：任意信道 / 边缘化 `T`，`BC(Tμ,Tν) ≥ BC(μ,ν)`；
3. **比值界**：`ρ ≥ m` ⇒ `BC ≥ √m`。

### 2.2 ★ 方向定理 —— 这就是判死线 (c) 的证明

由 (V1)：**对任意 `φ`，`BC ≤ ½∫(φ^{−1}dμ + φ dν)`。** 也就是说——

> **每一个"测试函数 / 耦合 / 分块 / 粗粒化"的选择，都只能给出 `BC` 的上界。**
> 要拿**下**界，必须控制 `inf` 的**取到间隙**（attainment gap），即 `φ` 必须逼近 `φ* = √ρ` ⇒ 必须**逐点**控制密度比 ⇒ 这正是 `osc S`。

⇒ **"更少依赖 `osc S` 的更好耦合"在 `inf` 族里不存在**：`inf` 的见证元**就是**密度比本身。换耦合 = 换 `φ` = 走上界一侧。这不是"没找到"，是变分式的方向把它排除了。

### 2.3 题面给的那条公式是**另一个泛函**（判伪；两个反例）

题面写 `BC = inf_{π∈Π(μ,ν)} ∫√(dπ/d(μ⊗ν))`。它其实是一个**恒等式**，但指向别的对象：
```
∫√(dπ/d(μ⊗ν)) d(μ⊗ν) = Σ_{ij} √( π_ij · (μ⊗ν)_ij ) = BC(π, μ⊗ν)
```
即"**耦合离乘积耦合有多近**"，与 `BC(μ,ν)` **无单调关系**（两个方向都能破）：

| 例子（两点空间） | `BC(μ,ν)` | `inf_π BC(π, μ⊗ν)` | 判 |
|---|---|---|---|
| `μ=(½,½)`, `ν=(1,0)` | `0.7071067812` | **`1.0000000000`** | 比 `BC` **大** |
| `μ=(½,½)`, `ν=(¼,¾)` | `0.9659258263` | **`0.9159756150`**（`a=0` 端；`a=0.125` 给 `1`） | 比 `BC` **小** |

`sup` 侧更坏：对角耦合对 `μ⊗ν` 奇异 ⇒ `ρ = +∞` ⇒ `sup = +∞`。**两头都不是 `BC`** ⇒ 由它推出的任何界**不转移到 `Ω`**。这条必须写清：它看起来像"变分公式"，实际是把 `BC(μ,ν)` 换成了 `BC(π, μ⊗ν)`。

## §3 `d01` 的耦合为何障：`osc S = Θ(V)` 的真实内容是 `I > 0`

`d01 3.3` 用 `dμ_β/dμ_{β'} = (Z_{β'}/Z_β)·e^{−(β−β')S}`，比值落在 `[e^{−|Δβ|osc S}, e^{+|Δβ|osc S}]`。三件事要分开：

**(3.1) `[T]` `osc S` 的硬数**：`S = Σ_p (1 − ½tr U_p) ∈ [0, 2N_p]`，`N_p = 6V` ⇒ `osc(S) ≤ 12V`（与 `D04-ODE:198` 一致）。这是**范围**。

**(3.2) `[C]` 典型 spread 也是 `Θ(V)`，不是 `√V`**：`⟨S⟩/V ≈ 6`（`β=1/48`，按 `⟨½trU_p⟩ ≈ β/8 = 2.6e−3`）对 `⟨S⟩/V ≈ 3`（`β=2.5`，`⟨½trU_p⟩ ≈ 0.5`）⇒ `Δ(S/V) ≈ 3`、`|Δβ|·Δ⟨S⟩/V ≈ 7.4` 每 site。涨落只有 `O(√V)`（CLT）——**这正是"`√V` 只能进前因子、不能进指数"的根源**：指数的分子是 `⟨S⟩`（`Θ(V)`），`√V` 是它的**误差棒**，不是它的**主项**。

**(3.3) `[C]`（自由场 `[T]`）真障碍的精确名字**：令 `L := log(dμ_β/dμ_{β'})`，`I := lim_V −(1/V)E_{μ_β}L = lim_V KL(μ_β‖μ_{β'})/V`。压力对 `β` 严格凸 ⇒ `χ_S/V = Var(S)/V > 0` ⇒ `I > 0`。于是
```
log BC = log E_{μ_β} e^{−L/2}  →  −V·κ，  κ > 0    （Laplace/大偏差）
```
**`osc S = Θ(V)` 只是 `I > 0` 的影子。** 而 `BC` 是密度比的函数：**影子换了，`BC` 不换**。这就是为什么"换一个耦合"不能动它——`I` 由两个测度决定，不由读法决定。

## §4 三候选：逐条判词

### 4.1 逐 plaquette 独立耦合 ⇒ **`log` 误差 `∝ V`，不是 `∝ √V`** `[T]`

- `BC(⨂μ_k, ⨂ν_k) = Π_k BC(μ_k,ν_k)`（Fubini）⇒ `log Ω = Σ_k log Ω_k`：对体积**可加** ⇒ **线性**。
- `√V` 需要每块缺陷 `O(V^{−1/2})`。但每块**两测度的 Hellinger 距离就是 `Θ(1)`**：数值 `h_block = √(2(1−BC_k)) = 1.071898`，达最大值 `√2` 的 **75.8%** ⇒ 块内"失败"已近最大，**没有任何 `V^{−1/2}` 小参数可用**。
- 数值（Gaussian，每 dof `Ω_k = 0.181065308266`）：`n=16 → 1.155266e−6`，`n=64 → 1.781263e−24`，`n=49152 → log₁₀ Ω = −36478.882`。`√V` 的痕迹：**零**。
- 唯一例外：块内 `β`-无关（卷积核 ⇒ `ψ ≡ const`，2D YM / 单 plaquette）⇒ 每块 `BC = 1` ⇒ 总 `Ω = 1`。于是整体取值只有**二分** `{1, e^{−Θ(V)}}`——这**不是** `d01 §4` 四模型的巧合，是 **Kakutani 乘积二分** `[T]`。而 `Ω=1` 分支 ⇏ 搬运（`d01 §4` 已判）。

### 4.2 `β`-插值 + 热力学积分 ⇒ **退化为空** `[T]`

- **一步**：`h(β,β+δ)² ≈ δ²χ_S/4`，`χ_S = Var(S) = Θ(V)` ⇒ 每步 `−log BC ≈ δ²Θ(V)/8`。
- **细分 `M` 步**（Gaussian 1 dof，`Σ` 步之和，数值）：`M=1: 0.854449`，`M=2: 0.716042`，`M=4: 0.568982`，`M=16: 0.292320`，`M=256: 0.0285638` → **0**。即 `Π_k BC_k → 1`：**细分越狠，界越空**（Gaussian 上 `−log BC` 沿路径**次可加**，`[C]`+`[T]` 可逐点验算）。
- **三角不等式侧**：Hellinger 路径长 `L_path = ∫ ½√χ_S dβ = Θ(√V)`（1 dof 数值 `1.692634`），给 `BC ≥ 1 − L_path²/2 = −0.4325 < 0` ⇒ **`n=1` 就已空**。
- 本职错位：TI 算的是 `∫⟨S⟩dβ = Θ(V)` 的**自由能**差；`log BC` 是**另一个**广延泛函（`−Vκ`，`κ = −ψ(−½)` 型 CGF 值）。两者之间只有退化不等式 ⇒ TI 只能**复述** `e^{−Θ(V)}`，**改不了它**。

### 4.3 乘积结构 ⇒ **只买可算性，不买指数** `[T]/[C]`

若 `μ_β` 精确乘积：`Ω = Π_k Ω_k`，速率 `κ = −log Ω_k = 1.708897/dof`（`(2.5,1/48)`）**显式可算、可 falsify、可对 4D `SU(2)` 作预言**。但指数仍是 `Θ(V)`。而且 §5 会说明：**连相关性都不进指数** ⇒ "近似乘积"既不是障碍也不是救命。

## §5 ★ 死刑执行：自由场**任意协方差**下 `log Ω` **精确** `[T]`

对 `N(0,Σ)`、`N(0,Σ')`（**任意** SPD，含完全相关的格点传播子）：
```
BC(N(0,Σ),N(0,Σ')) = (det Σ)^{1/4} (det Σ')^{1/4} / det((Σ+Σ')/2)^{1/2}
```
若 `Σ' = sΣ`（`β`-改变只改方差尺度 ⇒ 恰好是 `s = β/β'`，`(−Δ+m²)^{−1}` 整体约掉）：
```
log BC = (n/4)log s − (n/2)log((1+s)/2)      ⇒      log Ω = n·log( 2√s/(1+s) ) = n·log( 2√(ββ')/(β+β') )
```
**⇒ 指数精确线性于 `n`，与协方差结构、质量、关联长度全部无关。**

数值核对 `[C]`：`2×2` 相关协方差（`ρ=0.6`, `s=120`）：解析 `0.181065308266` vs 网格 `1400×1400` 直接积分 `0.18106531`（相对误差 `1.2e−13`）；解析 vs `Ω₁²` 差 `2.8e−17`。非成比例（`Σ'=1.13sΣ`）：`BC = 0.1704940161`，仍是 `Θ(n)`。

**⇒ `√V` 不在这个泛函的标度阶梯上。** 阶梯是**错配的支撑维度**：
```
bulk 支撑 ⇒ log Ω = −Θ(V)      （§4.1/§5）
面支撑   ⇒ log Ω = −Θ(L^{d−1})  ⇒ Ω ≥ e^{−cL^{d−1}} > 0（一致）
O(1) 支撑 ⇒ log Ω = O(1)        ⇒ Ω ≥ e^{−c}
```
`√V` 一条都不占。任何"`e^{−c√V}`"都必须是**另一个泛函**，不是 `Ω`。

## §6 把 `d01` 的"量级紧"升级成定理形状（两侧夹）

- **下界 `[T]`（Jensen）**：`BC = E_μ e^{−L/2} ≥ exp(−½ E_μ L) = exp(−½ KL(μ‖ν))`。双向都可用 ⇒ 取 `min{KL,KL}`。数值：`e^{−1.897913/2} = 0.387144888 ≤ BC_k = 0.425517694`，**只差 9.02%** ⇒ 近乎最优。（另一向 `KL(1/48‖2.5) = 57.11` ⇒ `e^{−28.55}`，也仍是 `e^{−Θ(V)}`。）
- **上界 `[C]`**：把 `Λ` 切成 `K = Θ(V)` 个不相交块 ⇒ 数据处理 `BC(μ,ν) ≤ BC(μ|_Λ, ν|_Λ)`；再在 `β` 弱/可解侧用聚簇把块间因子化成 `Π_k` ⇒ `log BC ≤ −K·κ_ℓ < 0` ⇒ **`Ω ≤ e^{−cV}`**。`d01 §5(c)` 只用**一块**，得 `Ω ≤ Ω_{P₀}`（`O(1)`）；用 `K` 块就到 `e^{−cV}` —— 这是 `d01` 那条上界的**体积版**。
- ⇒ `log Ω ∈ [−I, −I/2]·V` 型：**`Θ(V)` 是定理形状，不是数值巧合**。`√V` 会同时违反两侧。

## §7 判（逐字）

**(a) `Ω ≥ e^{−c√V}` 或 `e^{−c}`：不可得，且为假。**
不是"未找到"：`[T]` §5 给出自由场**任意协方差**的精确值 `e^{−nκ}`（`κ = 0.854449` per dof for `BC`，`1.708897` for `Ω`），`[C]` §6 给出 `Ω ≤ e^{−cV}` 上界。两者一致地把指数钉死在 `Θ(V)`；`e^{−c√V}` 与它们**矛盾**。⇒ `(a)` 不成立。

**(b) 成立：耦合路线死。**
**逐字：所有耦合都给 `e^{−Θ(V)}`；这条路线的死不是"差一个更好的耦合"，而是 (c)。**

**(c) 成立，且它就是 (b) 的机制。**
`BC` 的变分式是 **`inf` 型**（凹/affinity），极小点 `φ* = √ρ` 就是密度比本身 ⇒
1. 任意测试函数/耦合/分块/粗粒化**只能给上界**（§2.2）；
2. 数据处理 `BC(marginal) ≥ BC(full)` 与 tensorization 同属一侧；
3. 于是"更好耦合"**不是自由度**；能动的只有**测度对本身**（= 换 `Ω` 的定义，`d01` 的 (b)/(c)）。

**附一条必须写清的伪公式**：题面的 `inf_π ∫√(dπ/d(μ⊗ν))` 算的是 `BC(π, μ⊗ν)`，与 `BC(μ,ν)` 无单调关系（§2.3 两反例：`1.0` vs `0.7071`；`0.9160` vs `0.9659`）⇒ 由它得不到 `Ω` 的任何界，两个方向都得不到。

## §8 路径（唯一还活着的一条，标 `[NG]`）

指数 `= Θ(错配的支撑维度)`（§5 阶梯）。所以 `Ω ≥ e^{−c}` **只**在错配被压到 `O(1)` 或面支撑时可能，即把"bulk `β`-改变"换成"**面 / 扭曲插入**"的比较：
```
Ω_surf ≥ e^{−c·L^{d−1}} > 0   （一致；仍 → 0，但不指数于 V）
```
这一步需要那个"状态匹配算子"把 bulk 差写成面算子——**它没有被写出**，正是 `d01` 结尾点的同一个洞 `[NG]`。除此之外：归一化的 `Ω ≥ c` 与 `f₁²(2.5) > 0` **换名**（`d01 §5(b)`），不是引理。
