## §1 Stein 的精确式（逐字，三种，缺一不可）

设 `μ = e^{−V}dx`（平图卡 `X=log U`；紧纤维 / 边缘密度为零 ⇒ 一维分部积分无边界项，正是 S2 的 "flat-chart"、G1 的 `div v=0` 条件）。

**(S-a) 无修正项的精确式（真正的 Stein/IBP 恒等式）。**
```
∫⟨∇f,∇g⟩ dμ = ∫ g (−Lf) dμ ,   L := Δ − ⟨∇V,∇⟩ ,   f,g ∈ C_c^∞
⇒  Var_μ(f) = E_μ⟨∇f, (−L)^{-1}∇f⟩ = ∫_0^∞ E_μ⟨∇f, P_t∇f⟩ dt        [T]
```
（`L` 在 `L²(μ)` 自伴；`0` 单特征值 ⇔ 遍历。**没有修正项** —— 修正项是换核时才出现的。）

**(S-b) 换成 Hessian 核：余项有符号，但那符号是 Brascamp–Lieb，不是恒等式。**
```
Var_μ(f) = E_μ⟨(D²V)^{-1}∇f, ∇f⟩ + R(f) ,
R(f)     = E_μ⟨[ (D²V)^{-1} − (−L)^{-1} ]∇f, ∇f⟩ .
R(f) ≥ 0  ⟺  (−L)^{-1} ⪯ (D²V)^{-1}  ⟺  BL  ⟺  D²V ⪰ 0（log-concave）        [C]
R(f) ≡ 0  ⟺  V 二次 且 f 仿射（Gaussian 参考，BL 的等号情形）                [T]
```
**⇒ 用户问的"精确式"的正确答案是：`(D²V)^{-1}` 版只在 Gaussian 时是恒等式；一般 `μ` 上它是一个"恒等式 + 符号未定的余项"。`R` 的符号 = BL；BL 的假设 `D²V⪰0` = Savvidy 墙（`λ_min(−D²+2adF_B)=−g|B|<0`，`PROOF-SAVVIDY-EXACT-SIGN`）。**

**(S-c) 对 `(★)` 里那个特定泛函，有带 Hessian（不是逆）的精确式，且修正项显式。**
```
m(a) := E_μ[∂_aV | a] ,  ρ_v(a) = 粗场边缘密度 ,  "G″(a)" := −(log ρ_v)″(a)
①  ρ′ = −ρ·m        ⇒  "G″" = m′                       （两行，任何 V、任何维数）
②  E_μ[∂_a²V|a] − Var_μ(∂_aV|a) = m′(a) = "G″"(a)      （一行 IBP，见 §3）
⇒  Var_μ(∂_aV|a₀) = E_μ[∂_a²V|a₀] − "G″"(a₀)                                    [T]
```
**这第三条就是 `(★)` 的 `=` 形态**（`∂_aV = ⟨v,∇V⟩ = G_v+Φ′_v`，`∂_a²V = H_vv+Φ″_vv`）。**`δ_W` 不在其中作为自由参数：它被恒等式钉成 `"G″"_j(v)`。**

## §3 ★ 比 `N05` 更强的一步：`G″ = m′` 本身是 IBP 恒等式（⇒ 三项之和恒等于曲率）

`N05 §4` 判"分解零内容"用的理由是"一个方程两个未知量的维数计数"。**本轮把它加强成逐字恒等式。**

固定方向 `v`、记 `a=⟨v,X⟩`、`y` = 纤维坐标，`V = S_W+Φ`。取任意 `h(a)` 作检验函数：
```
∂_a ∫ ∂_aV · h e^{−V} dy = ∫ ∂_a²V h e^{−V} dy − ∫ (∂_aV)² h e^{−V} dy
又  ∫ ∂_aV e^{−V} dy = ρ·m ,   ρ′ = −ρ m
⇒  E[∂_a²V|a] = −m² + m′ + E[(∂_aV)²|a]
⇒  E[∂_a²V|a] − Var(∂_aV|a) = −m² + m′ + E[(∂_aV)²|a] − (E[(∂_aV)²|a] − m²) = m′(a)   ∎
```
于是
```
G″  =  E[H+Φ″|a₀] − Var(G+Φ′|a₀)  =  m′(a₀)
    =  [E[H]−Var G] + [EΦ″−Var Φ′] + (−2Cov(G,Φ′))  =  Δ_dyn + W_geo + X .
```
**⇒ `T01:35` 的三项分解 = "把 `m′` 拆成三块"；`W_geo ≥ N/12 > 0`（Prékopa，`ch05:214–220`，`[T]`）是关于**一块**的真定理，但三块之和恒为 `m′`，正部被 `X<0`（或 `Δ_dyn<0`）逐点抵消——`H1C-WFULL.md` 的"21% 失效"、`N05 §3.1` 的"144/144 `W_full<N/12`"都是这个相消的影子。**
**⇒ `LOOP-RUNBOOK:10332` 记的"两个式子不相容"在此有解：不是算错，是**和恒等于曲率**，任何"某块 ≥ 某数"的读法都必须指定哪一块，而指定的那一块永远不是带符号的那一块。**

## §4 判死线

### (a) `(★)` 是恒等式 ⇒ 零内容 ⇒ 总攻点是空的（**这是最重要的可能，且成立**）

- `=` 形态：`δ_W` 只能定义为 `G″_j(v)`（§2/§3），**恒等式，零内容**（`ch18:31` 逐字 "an identity with no content beyond that display"；`N05 §4` 三条理由）。
- 于是"证 `(★)`"≡"证 `G″_j(v) ≥ δ_W` 且 `δ_W` 与左边同一个符号"——**同一句话**。要么 `δ_W := G″`（恒等式，空），要么 `δ_W` 独立给出（那就是 `H1(δ_W)`）。
- **⇒ 用户的"总攻点"在等号读法下是空的。**这不是"损失"，是把靶看清楚了：**它从来不是"要证的余项下界"，它就是 `H1` 换了字母。**

### (b) 若读成不等式，余量的来源在哪？——**没有非 `H1` 的来源**

可能的三个来源，逐个死：
1. **BL 余项 `R`**（§1(S-b)）：要 `D²V⪰0`。Savvidy 处 `λ_min=−g|B|<0` ⇒ 假设假。机器直证余项**会变号**（1D Gibbs，`f=x`）：
   ```

   凸四次    V=x²/2+0.1x⁴          : Var=0.615527  E[f′²/V″]=0.689254  BL_slack=+7.37e−2
   双井      V=−0.9x²/2+0.05x⁴     : Var=3.745899  E[f′²/V″]=−1.745198 BL_slack=−5.49e+00
   双井 f=x³                       : Var=154.543   E[f′²/V″]=43.348      BL_slack=−1.11e+02
   ```
   ⇒ **`V″` 一变号，"Hessian 型余项"就是负的、无下界**；`δ_W` 的符号正是要证的东西，不能由 BL 供给。

### (c) `n05` 的"零内容"与 `(★)` 是同一个东西吗？——**是，逐字同一个显示**

- `n05` 判的对象：`G″ = Δ_dyn+W_full`（`ch05:233–237`）与 `ch18:33–35` 的 `Var−E[H]−W_full = −G″`。
- `(★)` 的 `=` 形态：`Var = E[H]+W_j−δ_W` ⇔ `Var−E[H]−W_j = −δ_W`。**同一个显示**，`W_j↔W_full`、`δ_W↔G″`。
