## §1 方向判定：两个精确可解例子给出相反的符号

两个模型都**没有截断、没有拟合、没有 Monte Carlo**；公式与数据在 `w7/bc_gaussian.py`、`w7/bc_ising.py`。

### §1.1 自由标量（Gaussian）：树给**上界** `[T]`

作用量 `H = ½Σ_x φ_x² − βΣ_{⟨xy⟩}φ_xφ_y`。二次型的最小本征值就是质量隙：

```
Z^d     :  m_lat² = 1 − 4 d β            ,  β_c^lat = 1/(4d)
树(z=2d):  m_tree² = 1 − 4 β √(z−1)      ,  β_c^tree = 1/(4√(z−1))    （树邻接谱半径 2√(z−1)）
```

| d | `β_c^lat` | `β_c^tree` | 比 | `m_tree/m_lat` @`β=½β_c^lat` | **@`β_c^lat`** |
|---|---|---|---|---|---|
| 2 | 0.125000 | 0.144338 | 1.155 | 1.0649 | `m_tree=0.3660`，`m_lat=0` |
| 3 | 0.083333 | 0.111803 | 1.342 | 1.1201 | `m_tree=0.5046`，`m_lat=0` |
| 4 | 0.062500 | 0.094491 | 1.512 | 1.1570 | `m_tree=0.5819`，`m_lat=0` |

读法：树在 Gaussian 里**更晚**临界（谱半径 `2√(z−1) < 2d`），所以在同一 `β` 下**更重**（`m_tree > m_lat`）。
这条严格不等式 `m_tree ≥ m_lat` 是**上界**方向 —— 对"证隙"完全无用；而且它在自由无质量点上给出
`m_tree = 0.582 > 0 = m_lat`，见 §4 的酸测。

### §1.2 铁磁 Ising：树给**下界** `[T]`+`[E]`

```
树(z=4) :  m_tree = −log( (z−1) tanh β ) ，β_c = atanh(1/(z−1)) = 0.346574
Z^2     :  m_lat  = 2|K − K*| ，K* = −½ log tanh K   （Onsager；用 W=12 周期条带转移矩阵独立复算，差 ≤ 9e−4）
```

| β | 0.10 | 0.15 | 0.20 | 0.25 | 0.30 | 0.32 | 0.34 |
|---|---|---|---|---|---|---|---|
| `m_lat`（W=12 条带） | 2.105911 | 1.604581 | 1.222648 | 0.906834 | 0.633459 | 0.533083 | 0.437225 |
| Onsager 精确值 | 2.105911 | 1.604581 | 1.222648 | 0.906829 | 0.633358 | 0.532775 | 0.436336 |
| `m_tree`（z=4） | 1.207298 | 0.805969 | 0.524036 | 0.308217 | 0.134746 | 0.074163 | 0.017724 |
| **比值 `tree/lat`** | **0.5733** | **0.5023** | **0.4286** | **0.3399** | **0.2127** | **0.1391** | **0.0405** |

读法：树**更早**临界（0.3466 < 0.4407），所以在同一 `β` 下**更接近临界**、关联更长、**质量更小**。
比值随 `β→β_c^tree` 单调掉到 0；`β > β_c^tree` 时树自己已有序，`m_tree ≡ 0`。
这正是"树 = 最坏情形"的正关联图像（路径计数最大、衰减最慢）——**和 Gaussian 的符号相反**。

### §1.3 一句判决

`m_tree ≤ m_lat`（有用方向）**只在正关联类里成立**；`m_tree ≥ m_lat`（上界方向）在自由场类里成立。
两者都由**同一个"树"**给出，符号由测度的正性决定。⇒ "多连通 ⇒ 隙更大" **不是**一条几何定理。

## §2 T1：三条候选工具，逐条判"能用/不能用 + 差哪一步"

### §2.1 Liggett–Stacey / 单调性比较 —— **不能用（前提空 + 对象错）**

- 需要：`𝒜/𝒢` 上有**全序** + 测度保序（FKG），才能把 `⟨f⟩_tree` 与 `⟨f⟩_lat` 夹住。
- 语料已把它判到 `[T]`/`[O]`：**非阿贝尔规范商上无全序**（`Q1-INFRARED-BOUND.md` §F4：
  "no total order on `𝒜/𝒢`"；族 3："no lattice order on the quotient"）；4D 面权是 **Weingarten，带号**
  （`T5-CENTER-VORTEX.md`：SU(2) 的号是 Euler 示性数，SU(N) 近一半为负）⇒ **β≈2.5 处没有正 Gibbs/FKG 测度**，
  "hence no percolation inequality to state"（同文件原文）。
- 就算硬给 FKG，**对象也错**：比较给的是单调可观测量的期望，而质量是**两点函数的对数率**
  `m = −lim (1/n) log⟨σ₀σ_n⟩`；`log` 不是保序运算，`⟨σ₀σ_n⟩_tree ≤ ⟨σ₀σ_n⟩_lat` 才给下界，
  而 FKG 比较给的是**相反**方向（树是最大涨落）。差的一步：**"期望的序 ⇒ 率的序"需要逐点的指数控制，不是 FKG 给的。**

### §2.2 Percolation / random-cluster `p_c` —— **能用，但只能给 `β_c`，且整类对 SU(N) 不存在**

- 严格不等式是现成的 `[R]`：`p_c(tree)=1/(z−1) < p_c(Z^d)`。数字：`z=4` 时 `1/3 < 1/2`（`Z^2` 键渗流）；
  `z=6` 时 `1/5 = 0.2 < 0.2488126`（`Z^3` 键渗流）。
- **翻译成"谱隙"合法吗？** 只合法到一半：
  (i) 它控的是**临界耦合**（`β_c`），不是**质量**；`β_c` 的不等式对 `β<β_c` 的 `m(β)` 无信息。
  (ii) 从渗流到 Ising 需要 FK 表示（`q=2`、**正权**）。4D SU(N) 的 FK/面权是 Weingarten **带号**（族 3），
       表示不存在 ⇒ **不能在 SU(N) 上陈述这条不等式**（不是"没证"，是"没对象"）。
  (iii) 从"簇尾"到逐点两点函数的那一步**在正类里成立**（`τ(x) ≤ P(|C|≥|x|) ≤ P^{tree}`，指数率相同），
       这解释了 §1.2 的数值；但它**恰好是 FKG 类专属**，与 §1.1 的自由场反例不矛盾——两支模型属于两个不相交的类。
- 差的一步：**一个 SU(N) 的正随机簇/正关联表示**。这就是族 3 的具名缺口，不是新东西。

### §2.3 Bethe 自由能作为变分界 —— **能用（自由能层面），但方向已知、且给的不是隙**

- Gibbs 变分原理：任何试验测度给 `F ≤ F_trial`；树（Bethe）自由能是变分族的成员 ⇒ `F_tree ≥ F_lat`
  （正权时；对 SU(N) 因带号而**不是**变分界）。这就是"树 = 最大连通 ⇒ 自由能最大"的已知方向。
- 关键：**它是自由能，不是谱隙**。`F(β)` 的逐点上界给出的是 `∫E dβ` 的控制；要从 `F` 读出谱边需要
  `F` 的解析结构/凹性（Lee–Yang 型论证），而 4D YM 恰好**没有**这种解析控制（族 1/族 9 的判词）。
- 差的一步：**`F ↦ gap` 的解析桥梁**；而它一旦存在，就等价于 H1（`SIXTH-SPECIES-CHARTER.md` §5 的 `[T]`）。

**§2 小结**：三条里两条（2.1、2.3）死法已知；唯一"能用"的 2.2 在 SU(N) 上**无对象**，且在正类里也只控 `β_c`。

## §3 T2（核心证据）：SU(2) 的树 vs 格，数值对比

### §3.1 两侧都精确（无截断）

**树侧**：link 上的 BP/递归分布不动点。核 `K(U,V)=exp(β Re tr(U V†))` 是类函数，
`K = Σ_j (2j+1) c_j χ_j`，`c_j = 2 I_{2j+1}(2β)/(2β)`（与 Haar 求积对到 `1.2e−15`）。`q−1` 条非回溯支的递归
`η_{n+1} ∝ (K η_n)^{q−1}`；平凡不动点的线性化乘子 `(q−1)c_{1/2}/c_0`，故

```
m_tree(β) = −log( (q−1) c_{1/2}/c_0 ) = −log( (q−1) I₂(2β)/I₁(2β) )   [若 <1]，否则 0
β_c^tree : (q−1) I₂(2β)/I₁(2β) = 1
```

取 `q−1 = 7`（8 邻接，对齐 `Z^4`）；`q−1 = 3`（4 邻接，对齐 `Z^2`）作对照。

**格侧**：2D SU(2) Wilson LGT，时间规范 `U_t=1` 后各列退耦；转移矩阵在类函数上的本征值就是 `c_j`
（重数 `(2j+1)²`），故 `m_lat(β) = −log(c_{1/2}/c_0) = −log(I₂(2β)/I₁(2β))`。**精确**，小 `β` 校验
`m_lat + log(β/2) = 4.2e−4, 1.7e−3, 6.6e−3`（β=0.05, 0.1, 0.2）。


它把"树的相变点"精确标在"格侧质量 = 连通平移量"处——也就是说，树的序参量一开始非零，格侧的界就归零，
中间没有过渡窗口。

### §3.3 判"上界还是下界"

- 在树尚未有序的窗口（`β < β_c^tree`）里：`m_tree < m_lat` **恒成立**，差的正好是连通重数 `log(q−1)`
  ⇒ 树给的是**下界**（有用方向），但**只在低连通类**（并且 §1.1 说明它对自由场是反的）。
- 在 `β ≥ β_c^tree`：`m_tree ≡ 0` ⇒ 界退化成 `m_lat ≥ 0`。**`β=2.5` 正落在这个区域**：
  `cav·I₂/I₁ = 5.0354 > 1`，树已有序，`m_tree = 0`。
- 4D 量级的树（`q−1=7`）在 `β=2.5` 的"下界"是 **0**；2D 量级的树（`q−1=3`）也一样（0.8 就归零）。
- **结论：在物理耦合处，树–格比较给出的下界是空的。** 有内容的窗口是 `β < 0.29`，即深强耦合——
  那里 P3（`β<1/48`）已经无条件成立，树没有增加任何东西。

### §3.4 一个必须写明的定义缺口：**"树上的隙"不是单一对象**

- 本节的树是 **link-BP 树**（2 体核）。真正的 4D 规范树是 **4 体 plaquette 树**（每个 link 属 `q=6` 个 plaquette）。
  它的 cavity 图**逐表示对角**（`∫dU₁ χ_{j₁}(U₁)χ_J(UU₁U₂†U₃†) ∝ δ_{j₁J}`，因为每个 `U_i` 只出现一次），
  所以相变仍是 `c_J·(6j) = 1` 型的 `O(1)` 方程——但**数值不同**，本节没算。
- 各种约化给不同的 `β_c^tree`：link-BP `0.2897`（`q−1=7`）；4 体 plaquette 树 `O(1)` 但非此值；
  plaquette mean-field 类约化给 `O(2)`。⇒ **比较不等式的左端依赖"你选哪棵树"**，而右端是 `Z^4` 的唯一对象。
  这不是"还没算准"，是**不等式没有唯一的左端**（T0(b) 的第二个化身）。

## §4 T3 酸测：自由无质量场两侧各给什么

酸测要求：机制**必须在自由无质量场上失效**（不给正质量）。本路给的是两种坏法之一：

| 归一化 | 自由无质量点 | `m_lat` | `m_tree` | 判定 |
|---|---|---|---|---|
| 自旋/Gaussian（`β_c^lat = 1/(4d)`） | d=4: `β=1/16` | **0**（精确） | **0.5819** | **伪证书**：树侧正、格侧零 ⇒ `m_tree>0 ⇒ m_lat>0` 为**假** |
| 格点规范（`β→∞` 才是自由场） | `β→∞` | `0` | `0` | 空过：两边都是 0，什么也没证 |
| 格点规范强耦合（`β→0`） | 无穷耦合 | `∞` | `∞` | 无信息 |

**判决**：酸测 **FAIL**。第一行是最要命的：在**精确可解**的模型里，树给正质量而无质量场零质量——
任何"树有隙 ⇒ 格有隙"的推理都会给自由场发一张正质量证书。第二行说明规范归一化下它只是"空真通过"，
和 `(TCI)` 在 `ℋ₋={0}` 上的空量化是同一类毛病（`SIXTH-SPECIES-SYNTHESIS.md` §3.4）。

### §5.1 T0(b) 只成立一半（要写清是哪一半）

- **成立的一半（自由能/变分路线）**：Bethe 自由能是**每格点**量（广延/强度混合），而隙是**能量**（每单位时间）。
  从 `F/V` 的上界到 `m` 的界，量纲与体积都对不上：`[F/V] = 能量`，`[m] = 能量`，但 `F/V` 控的是**整条谱的和**，
  不是**最低激发**。缺的是"谱边 ≤ 平均"的反向不等式——一般不存在。
- **不成立的一半（渗流簇尾路线）**：簇尾界**可以**转成逐点指数率（§2.2(iii)），所以 (b) 不能当这条子路线的死因；
  它的死因是**类限制**（无 FKG ⇒ 无对象）。
- 所以 (b) 的正确写法是：**"体积不匹配"杀死自由能路线，"无正表示"杀死渗流路线**，两条子路线死因不同，不能混写。

## §6 归属与缺步

**归属：`(γ)` 决定性否证。** 不是 `(α)`（没造新数据模），不是 `(β)`（没造新等价坐标）。
它把地图收紧的方式是：**把"树/平均场作为 oracle"整块从候选池里删掉**，并证明"高连通 ⇒ 大隙"是**FKG 现象**而非几何现象。

**一句话缺步（无退路）**：
> 缺的是**把"树上 BP 不动点的线性化率"变成"`Z^4` 转移算子谱边的体积一致下界"的那一步**；
> 它要么需要 SU(N) 不存在的 FKG/正关联（族 3），要么需要一条被自由场反例（§4 第一行：`m_tree=0.582` vs `m_lat=0`）证伪的
> 体积无关比较不等式。**这条缺步不是"难"，是"两端不同类"。**

**它杀掉了整族什么（给 `SIXTH-SPECIES-SYNTHESIS.md` 用）**：
`Bethe/Cayley/BP/mean-field 作 oracle + 比较搬运` 整族（含 percolation `p_c` 翻译、Bethe 自由能变分界），
以及任何以"树连通度更大 ⇒ 更易有序 ⇒ 隙更大"为论证骨架的翻案。判 `[NG]`，并归并进**族 3（FKG/符号）**，
不新增族号（按 `SIXTH-SPECIES-SYNTHESIS.md` §3.1 的记账规则，这是族 3 的一个几何实例，不是新机制种类）。
