## 1 · `φ^U` 的展开是什么图？

`[T]`，三种等价读法，各自的"图类"不同——混用是本项目 `Y04:152`「一名两用」的续集：

| 读法 | 图类 | 权重 | 用途 |
|---|---|---|---|
| (i) cumulant / Möbius | **连通图**（划分格上的 `(−1)^{\|π\|−1}(\|π\|−1)!`） | `±`，有抵消 | 定义 |
| (ii) Penrose / Brydges–Kennedy 树插值 | **生成树** `T ⊆ G_Γ`（`V(T)=Γ`） | `±`，`\|w_b\|≤1` | 树图界 `\|φ^U\|≤τ` |
| (iii) **块积（本文件）** | **2-连通块** `B` 的直积 | `∏μ(B)` | **逐簇真值** |

(iii) 的证明一行（`[T]`）：`(Γ,A)` 连通 ⟺ `A` 含全部桥，且 `A` 在每个块内连通生成。故按块相乘：

```
φ^U(G) = (−1)^{#bridges} · ∏_{blocks B} μ(B),     μ(B) := Σ_{A⊆E(B), A 连通生成} (−1)^{|A|}    (1.1)
```

**为什么 (iii) 是关键的**：`|μ|` 只在**团**上阶乘增长（`K_n: (n−1)!`），而团数被格子卡死——**一条 link 上恰有 `2(d−1)=6` 片 plaquette，任意两片共享该 link，故 `K_6` 是最大团**（`A01:84` 已用 `Δ=4(6−1)=20` 的同一事实）。⇒ **`n≥7` 无 `K_n`，`(n−1)!` 型增长在 `n=6` 截止**，这是"逐簇 `C̄` 不会跑飞"的结构性原因，也是 `τ` 在稠密簇上高估的机制。

## 2 · `≤20` 是怎么来的，哪一步松

### 2.1 原路（`A01` §2.2）

`τ(G)=n⁻¹∏_{j≥2}λ_j`；AM-GM `∏λ_j ≤ (Σλ_j/(n−1))^{n−1}`；握手 `Σλ_j = 2|E| ≤ Δn` ⇒ `τ ≤ Δ^{n−1}/n` ⇒ `C̄ ≤ sup_n(Δ^{n−1}/n)^{1/n} → Δ = 20`。

三步都在，逐条定量（log §3–§4）：

| 步 | 损耗 | 量化 |
|---|---|---|
| (1) AM-GM（谱 → 均值） | 丢弃谱展布 | 只损 `e`-级，**不是主因** |
| (2) 握手 `2\|E\|≤Δn` | 丢掉几何 | 对**大盒子**不损：4D 盒 `\|E\|=10n`（每 link 一个 `K_6`、`C(6,2)=15`），**饱和** |
| (3) **拿 `τ` 当计数装置** | **位置熵重复支付** | **主因**：`τ` 数带位置的树，而 `ū=eΔ·C̄·u` 里的 `eΔ` 正是"带位置树计数 `(eΔ)^n`" |

### 2.2 No-go：`τ` 路线到不了 `3.5`（本文件的新事实）

L=2 周期 4D 盒（`6·2⁴=96` 片；64 条 link；简单邻接图 864 条边、18 正则——环面上有些片对共享两条 link 而并边，故少于无穷格的 960），**精确整数**：

```
τ = 3.35591544059935629510374×10^116 ,     τ^{1/96} = 16.36102587        (2.1)
```

⇒ **`sup_Γ τ(G_Γ)^{1/n} ≥ 16.36 ≫ 3.5`**。因为 `|φ^U|≤τ` 是逐簇不等式，任何对 AM-GM 的改进（更好的特征值界、更好的 `|E|` 等周估计）都只是在逼近**这条包络本身**，**不可能**把逐簇 `C̄` 压到 `3.5`。**结论 `[T]`：`τ` 路线对目标常量 `3.5` 是死的；松的不是代数，是对象。**

**顺带勘误 `A01:75`**：那里用平面网格（`m≤6`）作"非空性核对"得 `τ^{1/n}=1.4–2.37`，并写"真实簇远低于包络 20"。**真实 4D 簇已在 16.36** ⇒ 该句低估了 7×，且 `Δ=20` 的包络在 4D 上几乎饱和（不是"松 2–3 倍"）。

## 3 · 更紧的界：`C̄ ≤ e = 2.71828`

把 (2.1) 的 `τ` 换掉，改用**位置×形状**的拆分（`[C]`，标准树图计数 + Cayley/Stirling `[T]`）：

```
# 以固定片 p 为根的树，n 个顶点，最大度 Δ  ≤  (eΔ)^n = Δ^n · e^n
                                             └位置┘  └形状┘
Δ^n ：位置熵，已由 ū 里的 eΔ 支付
e^n ：标号树熵/n!  —— (n^{n−2}/n!)^{1/n} → e       （log §4 表：n=5:1.008, 20:1.785, 100:2.400, 500:2.630, 1000:2.669 → e）  (3.1)
```

⇒ **`C̄ ≤ e = 2.718281828…`**，`[C]`（Penrose 界 `[C]` + 拆分），并且

- **悲观口径**（不把位置付在 `Δ` 里，改数**无标号树形** A000081，增长常数 = **Otter `2.9557658…`**）也给 **`≤2.9558 < 3.5`**；
- 两口径都 `<3.5` ⇒ **对"位置/形状怎么拆"稳健**，这正是要的 `3.5`；
- 与 `C01-CBAR1.md §4` 的**树恒等式**（`Σ_{Γ∋x}τ(G_Γ)a^Γ=Σ_{树 T∋x}∏a`，`[T]`）一致且更保守：那条给**求和级 `C̄=1`**，本条给**逐顶点形状级 `C̄≤e`**。二者不矛盾：`1 ≤ e`。

## 4 · 判死线（逐字）

**门槛（`Z12-FIXC:111` 逐字重现）**：`Ĉ·C̄ < 2N²·48/(eΔ) = 7.06328527`（`N=2`，`eΔ=54.3656365692`）。

### (a) `C̄ ≤ 3.5` 可证 ⇒ 触发 ✅

**逐字**：`C̄ ≤ e = 2.71828 ≤ 3.5`（(3.1)，`[C]`；悲观 Otter 口径 `2.95577` 同样成立）。配 **`Ĉ = 2`（精确值）**：

```
Ĉ·C̄ = 2 × 2.718281828 = 5.43656366 < 7.06328527   ✔
β₁^fix = 2N²/(Ĉ·eΔ·C̄) = 8/(2×54.3656366×2.7182818) = 2.7067057×10⁻² = 1.299219×(1/48) ≥ 1/48
⇒ δ·a = ln(1/(Ĉū)) > 0 对整个 [0,1/48] 成立
```

⇒ **窗口回到 `1/48`，不再缩**（`A01` 的 `1.8394×10⁻³`/`3.6788×10⁻³` 作废，`A01` 判词 5/6 的窗口部分撤销）。**`I1` 状态逐字**：

> **`I1` = `[T]` mod `C̄`，其中 `C̄ ≤ e`（求和级可进一步取 `C̄ = 1`，`C01-CBAR1 §4`）；窗口 = `1/48`（`Ĉ=2`：`Ĉ·C̄ = 5.44 < 7.0633`；`Ĉ=4`：`Ĉ·C̄ = 10.87 > 7.0633` ⇒ 若坚持逐片包络 `Ĉ=4`，窗口 = `0.6496×(1/48) = 1.353×10⁻²`，仍非空）。

**注（诚实线）**：若坚持 `Ĉ=4`，则 `Ĉ·C̄=10.87 > 7.0633`，窗口缩到 `0.6496×(1/48)`——**`Ĉ=2` 的那一半是本结论不可省的**（`Z12-FIXC:75` 的局部精确值）。这正是任务写"配 `Ĉ=2`"的原因。

### (b) `C̄` 下界 `>3.5` ⇒ 触发？

**不触发（对 `C̄`）/ 触发（对 `τ`-包络），逐字分开**：

- `C̄` 的**可证下界**：`120^{1/6} = 2.2209062`（`K_6`，精确整数，`[T]`）**`< 3.5`** ⇒ 不构成障碍。
- `τ`-包络的**可证下界**：`16.361`（(2.1)，`[T]`）**`> 3.5`** ⇒ **`τ` 作为计数对象被判死**（不是 `C̄` 被判死）。
- `C̄` 的**真值区间**（本层能给的最窄）：`2.2209 ≤ C̄ ≤ e = 2.7183`（取 (3.1) 为上界、`K_6` 为下界）；若采 `C01` 的求和级恒等式，则 `C̄=1` 且 `K_6` 的 `2.2209` 是**逐簇**而非求和级的量——**两个口径不可混**（`AGENTS §2.1` 窗口核验）。

### (c) `>20` 那里的错在别处 ⇒ 指出 ✅

**触发，逐字**：`A01` 的 `20` 作为 Kirchhoff 不等式**算术无误**（`τ≤Δ^{n−1}/n` 成立）。错在**记账**：`ū = eΔ·C̄·u` 中 `eΔ` 已付"带位置树计数"，再令 `C̄=Δ` 就把**同一笔位置熵付两遍**。证据三条：① (2.1) 真实簇 `τ^{1/96}=16.36` 使 `Δ=20` 几乎饱和，而语料数值 `ū=0.5654 ⇒ C̄=1.0000`（`A01:39–43` 自己算出）——语料从来是 `C̄=1`；② `C01 §4` 的树恒等式把 `τ` 整体吸收；③ (3.1) 的 `e` vs `Δ` 拆分只留形状熵。**⇒ `A01` 判词 3/5/6 的对象标签须改为"逐簇 `τ^{1/n}` 上确界"，而不是 `ū` 里的 `C̄`。**
