## §1 `b̂` 的地位（三层 + 一条排除）

1. **L3 本体无 `b̂`。** `ch03-existence.tex:61–65` 逐字 `sup_a Z_a^{-1}‖H_a‖_D < ∞`。`b̂` 只经 `Z_a` 的定义进入 `[T]`。
2. **定义里它是 `∀`-约束的自由变量，且与 `a` 并列。** `HZ6-ZDEF:41–43` 逐字：`∀Λ ∀L ∀a ∀b̂ ∀k∈{0,…,K̂}: … N_B(k):=(b̂/a_k)⁴, b̂/a_k∈ℕ, a_k:=b^k a≤b̂, K̂:=max{k:a_k≤b̂}, k_*=0`。⇒ `b̂` 的两条约束都不含 `a`；`K̂=log_b(b̂/a)` 随 `a→0` 无界（`II8-WIN:36` 逐字「塔跨度就是 `M` 的比值」）`[T]`。
3. **靶的等价形里它被明写为"固定"。** `KK2-FINAL:24–26`：`b̂` 取固定物理块；(A) `∃C>4 ∀a ∀k: Z_a(k) ≤ C a_k^{-4}`，等价「（`b̂` 固定）」：`∃C ∀a: ϖ ≤ C ⟺ ∃C: O_B ≤ C − Var(q)`；`HZF-COV:35` 给 `Var(⨏_B q) ≤ C(a/b̂)⁴`。⇒ `C` 必须与 `(a,k,b̂)` 三者都无关（`II1-C4:0.9`）`[T]`。
4. **`b̂=κa` 被两层排除 `[T]`。** ①`Z_a` 的层数：`b̂` 固定物理 ⇒ `Z_a` 恰一层 `a^{-4}`；`b̂=λa` ⇒ `N_B` 常数、`Z_a≍a^{-8}`、`Z_a^{-1}` 带 `a^{+8}` 两层，被 `(U2)` 的单层减除排除（`HZ6-ZDEF:62` 逐字「一层 vs 两层」；`II8-WIN:0.4` 逐字「凡 `b̂=λa` 的写法一律标『两层，非 L3』」；`DDD3-NB:1.3` 称「已勘误的记账陷阱」）。②还有一条**下界**：`b̂⁴ ≥ Var(q)/C`（`II8-WIN:0.7`，`β=2.5` 数 `0.357–0.370`，`a`-无关）。
   **下一手**：`b̂` 的取值不裁（`II8-WIN:82` 同判），只裁「与 `a` 独立」这一层。

## §2 需要哪种（裁决）

- **L3 需要在 `b̂/a→∞` 下成立 `[T]`。** 三条独立：
  (a) 量词：`b̂` 与 `a` 独立量化 ⇒ 每个固定 `b̂` 上 `a→0` 都给 `b̂/a→∞`，`sup_a` 全域都在这条路径上（`HZ6:41`、`KK2:26`）。
  (b) 反证（固定比侧靶免费）：`b̂/a≤√2 ⇒ N_B≤4 ⇒ ϖ≤4`（Popoviciu，`II9-CLUS:64` 逐字「该扇区**不搬**；它只说明小块的靶是免费的、内容全在 `b̂/a` 变大」）；`b̂=a ⇒ ϖ=Var(q)≤1`（`II1-C4:0.9`）。
  (c) 反证（不钉 `b̂` 则形式失效）：`M=1` 给 `ϖ≤1` ⇒ 「`∃C>4: ϖ≤C`」平凡真，而 L3 不平凡 ⇒ 纯 `ϖ` 形与 `Z_a` 形不可混用，纯形必附「`b̂` 固定物理」（`II8-WIN:61` 归谬）。
- **那根 log 的位置与性质 `[T]`。** 逐字 `∫_{|z|≤b̂/a}|z|^{-4}≈Σ_{n≤b̂/a}c_n n^{-4}=(8/3)\ln(b̂/a)+O(1)`（`KKK2-TREE:25` 引 `LL6-MARG:32`；系数 `(8/3)ln10=6.1402` 见 `DDD3-NB:54`）；阈值 `p=4=d` **尖锐**：`S_4` 对数发散、`p>4` 立收敛（`II9-CLUS:0.5`）。⇒ 它是**压线最坏衰减 `|C_2|≈|z|^{-4}` 的代价**，不是块选择的产物。
- **为什么「取 `b̂=κa` 把 log 消掉」不构成出口 `[NG]`。** 取比 `κ` 只把 `S_4` **截断在 `κ`**：`S_4(κ)` 是有限数、`ln(b̂/a)=ln κ` 是常数，算术上都对；但截断和 ≤ 全和 ⇒ 截断界是**下界**，而靶要**上界**（`HZ6:D4` 上半 / `HZE-ZUB:0.3`：靶 ⟺ `ϖ≤C`）。**方向反**。
- **下一手**：log 的出口不是块，只有三格——`p>4`（判据 `[T]`、供给 `[NG]`，`II9-CLUS:0.5,0.11`）、窗内 `ℓ¹`=`(V)`（`[T]` mod `(V)`，`HZE-ZUB:0.1`）、一致 `ρ_P`（`ϖ≤144c₁²/ρ_P`，墙，`HZF-COV:2.5`）。只在这三格立项。
