## §1 · 核 ①：`Σ_{n≥1}|⟨n|S_W|𝔾⟩|²` 的精确式 `[T]`

### §1.1 推导（三行，无假设）

设 `{|n⟩}_{n≥0}` 是 `S_W` 的本征正交基，`|Ω⟩ = |0⟩` 是基态、`S_W|Ω⟩ = E₀|Ω⟩`；`|𝔾_β⟩` 是**热态矢量** `|𝔾⟩ = Σ_n √p_n|n⟩`，`p_n = e^{−βE_n}/Z`（归一 ⇔ `Σp_n = 1`）。则

```
   ⟨n|S_W|𝔾⟩ = √p_n·E_n            （同上基展开，逐项）
   Σ_{n≥1}|⟨n|S_W|𝔾⟩|² = Σ_{n≥1} p_n E_n² = ⟨S_W²⟩ − p₀E₀²                        (1.1)
   Var(S_W) = ⟨S_W²⟩ − ⟨S_W⟩²,   ⟨Ω|S_W|𝔾⟩ = √p₀·E₀
   ⇒  Σ_{n≥1}|⟨n|S_W|𝔾⟩|² = Var(S_W) + ⟨S_W⟩² − p₀E₀² = ⟨S_W²⟩ − |⟨Ω|S_W|𝔾⟩|²
                            = ‖(1−P₀)S_W|𝔾⟩‖²                                      (1.2)
```

`(1.2)` 的最后一等式是 **Parseval**：`P₀ = |Ω⟩⟨Ω|`，`{|n⟩}` 完备 ⇒ `Σ_{n≥0}|⟨n|ψ⟩|² = ‖ψ‖²`。**没有任何近似、没有 Cauchy–Schwarz、没有大 `V`。** `h06` 的 (1.2) 与本式逐字相同 `[T]`。

**`n≥1` 是否杀掉均值？——否。** `n≥1` 扣掉的是 `S_W|𝔾⟩` 在 `|Ω⟩` 方向上的分量，其模是 `√p₀·E₀`（`p₀<1`，只在 `T=0` 才是全部），而均值 `⟨S_W⟩ = Σ_n p_n E_n` 是**分布在 `n≥1` 上**的：`⟨S_W⟩ − √p₀E₀ = Σ_{n≥1}p_nE_n − (√p₀−p₀)E₀ > 0`。所以均值**留在**求和里，且是主导项。

### §1.2 `d07` 的错在哪：**同一个式子里的两种读法不相容** `[T]`

`d07 (2.1)` 的论证是 `S_W|𝔾⟩ = ⟨S_W⟩|𝔾⟩ + (1−P₀)S_W|𝔾⟩`，要求 `|𝔾⟩` 是 `S_W` 的本征矢（否则 `⟨S_W⟩|𝔾⟩` 这一项不成立）。但若 `|𝔾⟩` 是本征矢（纯基态读法），则 `S_W|𝔾⟩ ∝ |𝔾⟩` ⇒ `Σ_{n≥1}|·|² = 0`、`Var ≡ 0`；而 `d07` 又同时用 `Var(S_W) = −∂_β⟨S_W⟩ = O(V)`（热态读法）。**两者不可能同时为真。** `d07 (2.1)` 是把「纯态的 `S_W`-对角性」与「热态的方差」拼在一行。等价地：

### §4.3 (c) 若两者都对但指不同的 `A` —— **不触发**

- `d07` 的和式 `Σ_{n≥1}|⟨n|S_W|𝔾⟩|²` 与 `h06` 的 `‖(1−P₀)S_W𝔾‖²` **是同一个量**，逐字由 Parseval：`Σ_{n≥0}|⟨n|ψ⟩|² = ‖ψ‖²`、`P₀=|Ω⟩⟨Ω|`。**不存在「两个 `A`」**：`d07` 的 `A² = Var_O·Var(S_W)` 与 `h06` 的 `A² = Var_O·(Var+⟨S_W⟩²−p₀E₀²)` 是**同一泛函在两个不同（一个错、一个对）取值上的值**，差 `1+⟨S_W⟩²/Var`（`L=4`：`1493`）。
