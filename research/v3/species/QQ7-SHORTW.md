## §1 三行与三个门槛

```
记 f:=𝒮_q、A:=∫_0^{β₀}f=(1−⟨q̄⟩(β₀))/κ=⟨plaq⟩(2.5)/6（NN11:(4)，[T]；L=6: 0.108822，L=4: 0.109099，8³×12: 0.108723）
(1) f(β₀) − ⨏_{[β₀−δ,β₀]}f = δ⁻¹∫_{β₀−δ}^{β₀}[f(β₀)−f(t)]dt = δ⁻¹∫_{β₀−δ}^{β₀}∫_t^{β₀}f'(s)ds dt
    ≤ δ⁻¹·(δ²/2)·sup_w(f')₊ = (δ/2)Lip₊ ；又 f≥0 ⇒ ⨏_{[β₀−δ,β₀]}f ≤ A/δ
    ⇒ f(β₀) ≤ A/δ + (δ/2)Lip₊                                        [T]（无输入；比 OO9 的乘性形省一个 e^{}）
(2) min_{δ>0}{A/δ+(δ/2)Lip₊} = √(2A Lip₊) at δ* = √(2A/Lip₊)          [T]
(3) 门槛：√(2A Lip₊) ≤ 4 ⟺ Lip₊ ≤ 8/A = 73.51 ；此时 δ* = A/2 = 0.05441
    窗地板：A/δ ≤ 4 ⟺ δ ≥ A/4 = 0.02721（δ 再小，窗均项单独就超 4）    [T]
(4) 单侧 vs 双边：|κ₃(Q)| ≤ (2V−⟨Q⟩)Var(Q) ⇒ Lip=403.5（L=6）vs 单侧 84.7 ⇒ 4.76×  [T]
```
