`B=(ū/(1−ū))³` **在它被推出来的地方（`ū<1`）逐字正确、且自动为正**；`ū>1` 是**把闭式搬到收敛半径之外**，`B<0` 不是笔误、也不是可以改一个绝对值号就修好的东西。

## 1 · `B` 的逐字来源（问题 1）

**`X01-L1C.md:71–82` 逐字（唯一显式推 `B` 的地方；`A02-2PPI2.md:59` 只是引用）**：

```
|φ^U(Γ)| ≤ C̄^{|Γ|} u^{|Γ|}，动物数 ≤ (eΔ)^{|Γ|}，Δ=20
⇒ |A(α)| ≤ ū^{α+1}/(1−ū)          （ū := eΔ C̄ u）                     (2.3)
ε_T = Σ_{α>T}(α−1−T)A(α)          （(L1-c.1)，X01:43）                 (L1-c.1)
|ε_T| ≤ Σ_{α>T}(α−1−T)|A(α)| ≤ ū^{T+3}/(1−ū)³
⇒ |ε_T| ≤ B·ū^T ,   B := ū³/(1−ū)³ ,   δ := ln(1/ū)/a                 (L1-c.2)
```

**重放（`w7/l1sign_tail.py [1]`）**：令 `m=α−1−T` ⇒ `α=m+T+1`，
`Σ_{m≥0} m ū^{m+T+2}/(1−ū) = ū^{T+2}/(1−ū) · Σ_{m≥1} m ū^m = ū^{T+2}/(1−ū)·ū/(1−ū)² = ū^{T+3}/(1−ū)³`。

**⇒ 三次方的三个因子，逐一对号（这是问题的正面答案）**：

| 因子 | 出处 | 收敛条件 |
|---|---|---|
| `1/(1−ū)`（**一次**） | `(2.3)` 的 `|A(α)|` 上界尾部归一 | `ū<1`（`Σ_{α}ū^α`） |
| `1/(1−ū)²`（**两次**） | `Σ_{m≥1}m x^m = x/(1−x)²`，位移后前因子 `(α−1−T)` 把多项式吃成纯几何 | `|ū|<1`（幂级数半径 1） |
| `ū³` | `ū^{T+2}` 里的 `ū²` × `x/(1−x)²` 里的 `x=ū` | 同上 |

**⇒ 所以 `B` = `(ū/(1−ū))³` 的"三次方"完全是 `1/(1−ū)` 的一+二次幂，`ū>1` 时它没有任何一项能表示一个和。** 数值复现（`[2]`）：`B(0.57)=2.329267`，`ε_T/ū^T` 在 `T=0…12` 上**逐位** `2.329267`，`max` 偏差 `2.2e−15` —— 与 `LOOP-RUNBOOK:6044` 逐字一致 `[T]`。

## 3 · `ū>1` 时代进去是**恒假**，不是"平凡真"（问题 2 的前半）

`B<0` 且 `ū^T>0` ⇒ 右端 `B ū^T < 0 ≤ |ε_T|` ⇒ 除非 `ε_T≡0`，**不等式为假**。数值（`[5]`，`β=2.5`、`u=β/4`）：

```
ū = 33.97852   B = −1.093755   1−ū = −32.97852
|A(α)| ≤ ū^{α+1}/(1−ū) 的右端在 α=0 已是 −1.0303 < 0   ← 前提先垮
T=0: RHS = −1.0938 ; T=1: −37.164 ; T=2: −1262.78 ; T=5: −4.954e7   全 < 0
```

**两层垮塌，顺序要分清**：
1. **前提垮**：`(2.3)` 的 `|A(α)| ≤ ū^{α+1}/(1−ū)` 在 `ū>1` 直接把一个非负量"界"到负数 ⇒ 这一步不是"界变松"，是**不成句**；
2. **结论垮**：即便硬把 `B` 代进去，得到的也不是"无信息"，而是**假命题**。

**`B<0` 的承载因子只有一个**（`[4]`）：`x/(1−x)²` 在 `x>1` 是**平方**、值 `+3.469`（`x=1.7`）为正；翻号的只有 `|A|` 界里那**一个** `1/(1−ū)=−1.4286`，三次方是奇次才把它带到 `B` 上。**⇒ 负号不是独立的符号错误，而是"那个 1/(1−ū) 已经不代表任何和"的显影。**

**判 `(b)` 否**：修成 `|1−ū|` 会造出推导里**不存在**的模——`(2.3)` 与 `Σm x^m` 都没有绝对值号，`(1−x)²` 已在平方里；`|1−ū|` 只是把一个**假**不等式换成一个**关系不明**的不等式，无任何一步支撑 `B_{|1−ū|}` 是界。`[T]`（形式判）

## 4 · 「正确界应是 `|ε_T| ≤ |C|·ū^T`」也不成立（问题 2 的后半）

`ū>1` 时 `ū^T` **指数上涨**。任何**有界**的 `ε_T` 都满足 `|ε_T| ≤ C ū^T`，取 `C := sup_T |ε_T| ū^{−T}` 即可（该 `sup` 有限，且随 `T` 可放松到 0）⇒ 这个不等式**恒真、零信息**：它给出的"率"是 `ln(1/ū)<0`，即**负衰减**，与 `(L1)` 想交付的 `δ=ln(1/ū)/a>0` 恰好反号。**⇒ 它既不是错的界，也不是对的界，它不是界。** `[T]`

对照（`[4]`）：`ū=1.7` 时 `Σ_{m≤N}m ū^m` 在 `N=40` 已达 `1.547e11`，而延拓值只有 `3.469`（比值 `4.46e10`）⇒ **延拓值不逼近任何部分和**，把它当"和"的任何写法（含 `|C|ū^T`）都没有内容。

## 5 · `ū>1` 处**正确**的界（问题 3）

**换参数，不换符号。** 令真半径

```
r := limsup_{α→∞} |A(α)|^{1/α} ,      C_r := sup_{α≥0} |A(α)| r^{−α}
```

则由**同一个** `(L1-c.1)` 与**同一个** `Σ m x^m = x/(1−x)²`（现在在 `x=r<1` 上用）：

```
|ε_T| ≤ C_r · r^{T+2}/(1−r)²  =  [ C_r·r²/(1−r)² ] · r^T ,      r<1            (L1-r)
```

**恒等核对**：取 `C_r = ū/(1−ū)`、`r=ū` ⇒ `C_r r²/(1−r)² = ū³/(1−ū)³ = B` ✔ —— **语料的三次方正是 `(L1-r)` 在 `r=ū` 处的特例**，而 `ū` 只是 `|A(α)|` 的**粗界参数**（把动物数 `(eΔ)^{|Γ|}` 与单片成本 `u` 一起塞进一个数），不必等于真半径。

数值（`[6]`，真幅度模型 `|A(α)|=C r^α`，`C=0.5`、`r=0.57`，与 `ū=33.98` 的粗界**无关**）：`B_r=0.878583>0`，`T=0,2,5,10` 上 `|ε_T|/(B_r r^T)=1.000000` —— 形状不变、常数转正、率 `δ=ln(1/r)/a`。

**⇒ 三条结论**：
- `r<1`（真半径在圆内）⇒ `(L1-r)` 成立，`B_r>0`，`(L1)` 的可交付内容**完好**；
- `r≥1` ⇒ 这一路**不给任何界**，`ε_T` 可能不衰减（周期管反例 `LOOP-RUNBOOK:6054`：`ε_T=−TΣA` 线性增长就是 `r=1` 的实例，`[E]`）；
- **`ū>1` 与 `r` 的关系未知**：`ū>1` 只说明粗界失效，**不**说明 `r>1`。故 `r` 在 `β=2.5` 处是 `[NG]` —— 不许把 `ū>1` 读成"`ε_T` 不收敛"。

## 6 · 判死线（问题 4）

### **(a) 命中 —— 是"结构只在 `ū<1` 有意义"，不是"错号"** `[T]`

三条并列理由（每条都独立足以定 (a)）：
1. **推导自身**：`B` 的三个因子全部来自 `ū<1` 的几何和（`§1` 表）；在 `ū<1` 内 `1−ū>0` ⇒ `B>0` **自动**成立 ⇒ **不存在"应该在 `ū>1` 为正"的场合**，故无号可错。
2. **陈述自身**：`(L1)` 的逐字陈述带 `ū<1` 与"开管"两条前件（`A02:59`、`A02:125`、`P1:92`、`Y04:137`，`§2` 表）⇒ 在 `ū>1` 处**该陈述根本没有被提出**。
3. **数值自身**：`B` 在 `ū→1⁻` 处 `→+∞`、`ū→1⁺` 处 `→−∞`（`[3]`：`B(0.99)=9.703e5`、`B(1.01)=−1.030e6`）—— 一个在定义域边界发散的量，**边界外无定义**，这是定义域事实，不是符号笔误。

**⇒ 明说**：**`(L1)` 的界在 `ū>1` 处无定义（超范围）；不是错号。**

### **(b) 否** `[T]`
不是笔误：`|1−ū|` 在推导里**无来源**（`§3` 末），且它给出的"界"在 `ū>1` 处**未被任何一步证明**，只是把假命题换成待证命题。若有人要那条路，它等价于**重做** `(L1-r)` 并证 `r=ū`（在 `ū>1` 时不可能，因 `r≤1` 才可和）——那就不是"改符号"，是新定理。

### **(c) 否（其弱形式命中）** `[NG]` / `[C]`
`ū>1` **不**给"`ε_T` 不收敛"的证据：`ū` 是粗界参数，真半径 `r` 在 `β=2.5` 处未知 `[NG]`。
**但**必须记账：`β=2.5` 时 `ū=33.979≫1` ⇒ **环 2 在物理点什么都不交**（窗 `β<0.073576`），`(L1)` 整体需要另一次重求和或另一条路才到得了 `β≈2.5` —— 这不是 `(L1)` 内部矛盾，是**窗**（与 `FROZEN-POSITION` 的冻结窗一致）`[T]`。
**⇒ 故不需要"整体重写"`(L1)`；需要的是把它的前件写全（`ū<1` + 开管 + `L`-一致），并承认窗外零交付。**
