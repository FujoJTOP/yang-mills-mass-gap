## §2 · 精确命题与三条附加条件

### 2.1 命题（本文件的主形式）

```
设 F := f₁²(β) = |a(β)|²，a(β) := ⟨Ω|O|𝔾(β)⟩，固定 (L,a)、O = ¼trF²、β ∈ [β₀,∞)，β₀ = β₁。
已知： (H0) F 在 (0,∞) 上实解析                       [T]  V03:42,100（PF + Kato）
       (H1) F ≥ 0                                     [T]  V02:13（模方）
       (H2) F ≢ 0                                     [T]  V02:109（P3 在 β₁ 给 f₁² ≥ r₀）
       (H3) F(β₀) ≥ r₀ = 1/64 > 0                     [T]  D04:169；Z01:204
要证： (T)  ∃c>0 ∀β ≥ β₀ : F(β) ≥ c                   ← 这就是 (★)/H1/L3/ε_b
```
**(H0)–(H3) + (T) 不可由 (H0)–(H3) 推出。** 反例（同一函数类，`[T]`）：`F(β) = e^{−(β−β₀)}`，即 `B09:68`。它满足 (H0)(H1)(H2)(H3)，且**零集为空**，`inf = 0`。

### 2.2 命题 3.1（正确的分解式，`[T]`）

```
命题 3.1.  F ≥ 0、F 在 [β₀,∞) 上连续、Z := F^{-1}(0)∩[β₀,∞)。则
   inf_{β ≥ β₀} F(β) > 0   ⟺   [ Z = ∅ ]  ∧  [ liminf_{β→∞} F(β) > 0 ]              (3.1)
```
*证.*（⇒）`inf=c>0` ⇒ `F≥c` 处处 ⇒ `Z=∅`，且 `liminf ≥ c > 0`。
（⇐）设 `Z=∅`（⇒ 由 `F≥0` 得 `F>0` 逐点）且 `ℓ := liminf_{β→∞} F > 0`。取 `δ := ℓ/2 > 0`（`ℓ=+∞` 时取 `δ=1`），有 `B` 使 `β ≥ B ⇒ F(β) ≥ δ`。在紧段 `[β₀,B]` 上 `F` 连续且逐点 `>0` ⇒（Weierstrass）`m := min_{[β₀,B]} F > 0`。故 `F ≥ min(m,δ) > 0` 于全尾。∎

**读法**：`(T)` 被**精确地**拆成两条**各自严格弱于** `(T)` 的句子，但**合取起来 ⟺ `(T)`**。⇒ 这是**分解**，不是**放松**：义务数 1 变 2，一条不省。

### 2.3 候选附加条件 (i)：零点不积累于 ∞

```
(i)  Z ∩ [β₀,∞) 有界（⇔ 不积累于 ∞）。由 Z 闭 + 离散 ⇒ Z 有限。
```
**判 `[NG]`，双向都死。**

- **(i) 不可得（不是免费的）**：`F ≥ 0` 实解析**允许**零点积于 ∞。显式：取 `β_n = n²`、`F(β) := ∏_{n≥N}(1−β/β_n)²`（`Σ1/β_n < ∞` ⇒ 乘积在紧集上一致收敛 ⇒ 整；每因子平方 ⇒ `F ≥ 0` on ℝ；零点**恰在** `β_n`）。⇒ (i) 是**独立假设**，且与 (H0)–(H3) 相容地**失败**。`[T]`
