## §2 · (B) lsc minorant 的条件五行击杀（不是一般熵率定理）

设定：`Ψ` 是任意 **lsc** 泛函，路线希望 `Ψ` 给残数一个正的下界。`f₁²(ν) := ν({m₁²})`。

**L1（DV 是 `sup` ⇒ lsc；导数不自动继承）**
`H(Q|μ)=sup_{F∈C_b}{E_Q[F]−log E_μ[e^F]}`，连续泛函的 `sup` 是 lsc（`INEQ-R5:5`）。这只证明 **DV 本身**属于 lsc 类；`Ψ_β=∂_β H` 或 `∂²_γ H` 必须另证半连续。L5 以下采用的明确假设是：所讨论的 `Ψ_β` **已经是**测度上的 lsc 泛函。

**L2（lsc 只能下界 lsc —— 路线的全部指望在这一句）**
`INEQ-R5:5` 原文：DV 类"is the correct class to lower-bound a **lsc** quantity"。⇒ 若靶是 lsc，路线成立；问题只在靶。

**L3（靶是原子 ⇒ usc，且不是任何 `sup`）**
`f₁² = ν({m₁²})` 是点质量。Portmanteau：闭集 `F` 上 `limsup ν_n(F) ≤ ν(F)` ⇒ `ν ↦ ν({m₁²})` **上半连续**；且不 lsc（见证：把边缘原子换成无边缘 bump，`ν_n ⇒ δ_{m₁²}` 使取值 `0→1`）。度量空间上 `f` 是 lsc **当且仅当**它是其连续 minorant 的上确界 ⇒ `f₁²` 不是连续泛函的上确界，**a fortiori 不是任何 DV 率**（`INEQ-R5:7`；仓内同向的逐字记载：`R-WAVE-SYNTHESIS:45` "`f₁²` is upper-semicontinuous"；记号处 `ATOM2:32`）。

**L4（路线必须断言的前件 —— 这就是被杀的靶心）**
要"用熵率给残数正下界"，逐字等于断言
```
   ∃ Ψ ∈ lsc 类：  (i) Ψ(ν) ≤ f₁²(ν)  ∀ν      且   (ii) Ψ(ν_root) > 0 .                    (P)
```
`(P)` 的否定（`¬(P)`）逐字是 `r₀ ≤ 0`：`INEQ-R5:15` "Positing a positive sup-barrier is verbatim `H*(r₀)`"。**注意：`(i)` 是单侧不等式，`(ii)` 是正性；两者缺一不可。**

**L5（同一个 `1/n`-bump 对抗 ⇒ `Ψ ≤ 0`）**
取任意 `ν*`，把它在 `m₁²` 处的边缘原子替换为宽 `1/n` 的 bump：`ν_n ⇐ ν*`（弱收敛），`ν_n({m₁²}) = 0`。则 `Ψ(ν_n) ≤ f₁²(ν_n) = 0`（用 `(i)`）；lsc 给 `Ψ(ν*) ≤ liminf_n Ψ(ν_n) ≤ 0`。`ν*` 任意 ⇒ **`Ψ ≤ 0`**（`INEQ-R5:9` 逐字）。⇒ `(ii)` 不可满足 ⇒ `(P)` 假 ⇒ **`r₀ ≤ 0`**。

**L6（`β`-下标不救一个已假设为 lsc 的 minorant；但不证明导数 lsc）**
若对每个 `β` 已分别证明 `Ψ_β` 为 lsc，则 L5 可逐 `β` 使用；宽度 `1/n` 的 bump 不必依赖 `β`。这**不是**从 DV 的 lsc 性推出 `Ψ_β` 的 lsc 性。一般地，lsc 对可数下确界不封闭；`f_n(x)=max(0,1−n|x|)` 全连续，而 `liminf f_n=1_{x=0}` 是 usc。故若 `Ψ_β` 只定义成差商/liminf，本节的类级论证**不可用**，须另证半连续。
> 反向核对：§1.3 的具体 `Var_β(S_W)` 不需要这一步——2D 上它沿全 `β` 线恒正而 `f₁²≡0`，直接否掉 `Ψ≤f₁²`。

**L7（杀的到底是哪个前件 + 与 D04 的关系）**
- **被杀的前件 = `(P)` 的合取**，具体是 `(i) ∧ (ii)`：任何 lsc 的 `Ψ` 满足 `(i)` 必 `≤0`，故 `(ii)` 不可能。**不是**杀"DV 是 lsc"（L1 为真），**不是**杀"`d/dβ` 有定义"，**也不是**杀 `(F)` 的微分不等式 `|F'|≤C|F|`（那是 C¹ 函数对之间的界，没有半连续性问题）。
- **与 D04 的关系**：D04:14/`:87–103` 判“常数存在性⟺正性”；本节只判“已证 lsc 的 minorant 不可能正”。两把刀适用域不同。对一般熵率/LSI 泛函，不能仅凭本节宣称类级死亡。
- **2D 把 L5 的抽象对抗变成字面模型**：2D 的 `ν_{¼trF²} ≡ 0` 本身就是 bump 家族在 `n→∞` 的极限（空测度，`ATOM2:60–62`），且同模型另一 carrier 给 `f₁²=1`（`ATOM2:81`）⇒ 不必造对抗，模型内即封口。
