## 0 · 一句话判

**`L=4`（`L0=4`）上 `ρ²` 测不出来，而这**不是**资源问题，是三个结构性事实**`[E]+[T]`**：
(1) `n=8000`、`6` 个 `0⁺⁺` 算符、`3` 个 GEVP 点，**15/15 全部 `C(t0)` 非正定 ⇒ 无定义**（`λ₂≤0` 的更强形式：
连度量本身都不正）；
(2) `L0=4` 上**只有两个独立时间间隔**（`C(3)=C(1)` 精确，T-对称），"更高 GEVP 级"在 `L0=4` 上**不存在**；
(3) `L0=4` 在 `β=2.5` 是**有限温**格点，`T/T_c ≈ 1.2–1.5 > 1`（下文 §3.3）——测到的是**解禁闭相的筛解质量比**，
不是定理里那个 `0⁺⁺` 转移生成元的 `μ₂/μ₁`。
⇒ **判死线：(a) 不成立；(b) 成立（给清单）；(c) 同时成立（Ky Fan 3.8–279× 使解析侧也无望）。A 路这一读数没有戏。**

## 1 · 要 `λ₂>0`，需要什么算符？

### 1.1 失败的机制（先说清楚，否则候选列表是空的）

`λ₂` 的符号由 `C(t0)`（度量）的**正定性**决定：`λ₂>0` 的先决条件是 `C(t0)` 在 `0⁺⁺` 子空间**满秩且正**。
本测（`n=8000`，`β=2.5`，`4×4³`）逐字给出 rank-1 结构 `[E]`：

| 算符 | `C(0)` | `C(1)/C(0)` | `C(2)/C(0)` |
|---|---|---|---|
| `S_geo=12(1−P̄)` | `5.235e−2` | `+0.1455` | `+0.0332` |
| `clover ¼trF²` | `4.876e−5` | `+0.1441` | `+0.0180` |
| `1×2 rect` | `3.294e−4` | **`−0.0015`** | `−0.0142` |
| `2×2 square` | `3.263e−4` | `+0.0008` | `+0.0054` |
| `adjoint plaquette` | `6.161e−4` | `+0.1240` | `+0.0225` |
| `magnetic-only` | `2.149e−2` | `+0.0831` | `+0.0221` |

**读法**：plaquette 家族（`S_geo`、`magnetic`、`clover`、`adjoint`）**彼此 ~100% 相关**（`C(1)/C(0)` 全在
`0.08–0.145`），`2×2` 与 `1×2` 的 `C(0)` 比 plaquette 小 `100–160×` 且 `C(1)/C(0)≈0`（`1×2` 甚至为负）
⇒ 它们是**噪声方向，不是第二个态**。把噪声方向加进基只会把度量的最小本征值往负推（`[E]`，两组 `t0`）：
```
(t0,t)=(1,2):  k=2 → -1.34e-5 ;  k=3 → -2.06e-3 ;  k=6 → -2.09e-3
(t0,t)=(2,3):  k=2 → -2.68e-7 ;  k=3 → -2.77e-5 ;  k=6 → -2.90e-5
```

⇒ **"更大的算符基"在 `L=4` 上是负收益。** 能让 `λ₂>0` 的不是"更多算符"，是**每个算符都要有
`t≥2` 上 `S/N ≳ 10` 的信号**，且**彼此近正交**。这两条只有**分级 smearing**能同时给。

### 1.2 候选（`8` 个，按"是否可能近正交"排序）

| # | 算符 | 为什么可能给第二个态 | 本测状态 |
|---|---|---|---|
| 1 | **3D-APE 涂抹 plaquette，level `n=1,2,3,4`**（只涂空间链，保持算符活在一个时间片） | 涂抹半径 `→` 一组**分级、近正交**的 `0⁺⁺` 基；这是格点上唯一被验证能把 `λ₂` 推正的机制 | **未测**（本测唯一缺的关键杠杆） |
| 2 | **HYP-涂抹**（`n=1,2`）+ 上者 | 与 APE 同类但更少短程噪声，独立方向 | 未测 |
| 3 | `adjoint` 表示 plaquette `1−⅓tr_adj(P)` | 不同 Casimir ⇒ 不同态混合 | **已测**：有信号（`C(1)/C(0)=0.124`）但 ~100% 与 plaquette 相关 |
| 4 | `magnetic-only` `Σ_{i<j≤3}` | 电/磁分离（Savvidy 方向） | **已测**：`0.0831`，与 plaquette 仍近相关 |
| 5 | `1×2` 矩形 Wilson（6 平面 × 双向） | 周长/面积标度不同 | **已测**：`C(1)/C(0)<0` ⇒ `L=4` 上纯噪声 |
| 6 | `2×2` 方 Wilson | 更大环 ⇒ 更偏激发态 | **已测**：`+0.0008` ⇒ 噪声 |
| 7 | **多迹**：`Σ_x [¼trF²(x)]²` 的连通部分 | OPE 上更偏高维 ⇒ 不同态权重 | 未测（廉价） |
| 8 | **位移/双点**：`Σ_x ¼trF²(x)¼trF²(x+μ̂)` | 提供空间结构信息（非零动量混合） | 未测（廉价） |

**判**：需要的是 **#1（APE 3D 分级涂抹）+ #2**，不是在 `¼trF² / ΣP_p / Wilson 环 / plaquette 高次`里继续换外衣。
`¼trF²`、`Σ P_p`、`1×2`、`2×2` 四者在 `L=4` 上**已被本测判为同一方向或噪声**（上表）`[E]`。

## 2 · `L=4` 上能算吗？—— 能跑，但结果"无定义"

### 2.1 实测资源（`[E]`，本机单核 `py -3.12`，`4×4³`=256 sites，1024 links）

```
sweep  = 4.6 – 7.1 ms      （checkerboard heatbath，含 300 sweeps 热化 1.6 s）
measure= 8.5 – 10.9 ms      （6 个算符 × 4 时间片，全部空间平均）
per config (gap=2) = 21–25 ms
n = 8000 configs  ⇒  169.3 s 墙钟（含热化）
内存：算符值 8000×4×6×8 B = 1.5 MB；规范场按需重算，不存盘 ⇒ 峰值 < 100 MB
⟨½Re tr U_p⟩ = 0.6548（β=2.5 合理带 0.63–0.67，sanity ✓）
```

### 2.2 结果：`15/15` 无定义

```
GEVP（C(t)v=λC(t0)v, λ=cosh(m(T/2−t))/cosh(m(T/2−t0)), T=4）
k=2..6 × (t0,t)=(1,2),(1,3),(2,3) 全部： C(t0) 非正定 ⇒ ρ² 无定义
jackknife 8 bins：0/8 bins 有定义 ⇒ 连误差棒都不存在
ta03 三个配对的 L=4 复刻：(0,1),(0,2),(1,2),(0,1,2) 全 8 个点 ⇒ 全 undef
```

⇒ 语料 `ch13:646-651` 的 `λ₂=−0.011 ≤ 0` 不是统计涨落，**更强的说法成立**：`8000` 组态、`6` 算符、`3` 个
GEVP 点，度量的最小本征值仍是**负**的 ⇒ `ρ²` 在 `L=4` 上**没有定义**，与组态数无关（加统计只压噪声，
不改秩亏；§1.1 的相关矩阵结构是**信号**层面的事实）。

### 2.3 若硬要"给方案"：`L0=4` 是错的，方案必须换格子

| 格子 | 站点 | per config | `n` 目标 | 单核墙钟 | `T/T_c`（§3.3） |
|---|---|---|---|---|---|
| `4×4³` | 256 | 21 ms（实测） | — | 169 s 已做 | 1.2–1.5 **解禁闭** |
| `6×6³` | 1296 | ~65 ms（×3 外推） | `10⁵` | ~1.8 h | 0.8–1.0 临界 |
| `8×8³` | 4096 | ~0.39 s（×16 外推） | `10⁵` | **~11 h** | 0.6–0.75 禁闭 ✓ |

内存（`L=8`、`8` 个算符、`8` 时间片、`10⁵` 组态）：`10⁵×8×8×8 B = 51 MB`，规范场不存盘 ⇒ **不是瓶颈**。
`T` 长度（= `L0`）判据两条同时要：`m T ≳ 3–4`（`m a≈0.6` ⇒ `L0 ≥ 6`，最好 `8`）**且** `T < T_c`（`L0 ≥ 6`）。
⇒ **`L0=4` 两条都不满足**。

## 3 · 关键：口径离散（`1.8×`）能压下来吗？

### 3.1 `L=4` 上：不能，且证据是硬的

- **"更高 GEVP 级"在 `L0=4` 上不存在** `[T]`：周期时间、`T=4` ⇒ `C(3)=C(1)` **精确**（本测 log 逐行相同：
  `diag C(3)/C(0) = diag C(1)/C(0)` 到打印精度）。独立时间间隔只有 `t=1,2` 两个，而 `t=2` 的信号只剩
  `C(2)/C(0)=0.033`（plaquette）⇒ 两点定一条带激发态污染的曲线，系统误差 `O(e^{−(m₃−m₂)t})` **无法被抑制**。
- **"更大算符基"在 `L=4` 上是负收益** `[E]`：度量的最小本征值随 `k` 变负（§1.1）。原因不是统计：
  `1×2`/`2×2` 的 `C(0)` 比 plaquette 小 `100–160×`，`1×2` 的 `C(1)/C(0)` 还是**负**的。
- 因此 `ta03` 在 `L0=2` 量到的 `2.41–5.79`（`1.8×`）**不是**"基太小/级太低"，是 **`t` 太少**：
  `L0=2` 只有一个间隔（单极点假设），`L0=4` 只有两个。离散度 `=O(1)` 是 `L0` 的直接函数。

### 3.2 要压到 `|ρ²−4|` 之下的量

判据是**上界** `ρ²≤4`。若真值在 `2.4–2.5`（`atom3` 中心口径），余量 `1.5`。要 5σ 判 `≤4` 需
`σ(ρ²) ≤ 0.3` **且**口径系统误差 `≤ 0.5`。`ta03` 的 `L0=2` 统计棒已是 `0.15–0.39`，但口径离散 `1.8×`
⇒ **统计棒早已够小而判定仍不成立** ⇒ 这是系统误差主导的量，**加组态数不改结论**。

### 3.3 决定性的一条：`L0=4` 在 `β=2.5` **不是零温**

`T = 1/(L0 a)`，`T_c/√σ = 0.709`（SU(2) `3+1`D），`a√σ ≈ 0.24–0.27`（`β≈2.5`）`[E]`（文献值，本测未标定 `a`）：

```
T/T_c = 1/(L0 · a√σ · 0.709)
L0=4 : 1/(4×0.27×0.709) = 1.31  (取 0.24 则 1.47)      ⇒ > 1  解禁闭
L0=6 : 0.87 (0.98)                                       ⇒ 临界
L0=8 : 0.65 (0.74)                                       ⇒ 禁闭
```

⇒ `L0=4` 的转移矩阵**不是**定理里的零温 `0⁺⁺` 生成元。这解释了两件事：`m_eff(plaquette, L=4) ≈ 1.95` 格点单位
（`ta03` 在 `L0=2` 也给 `1.98`）与 `λ₂≤0` 同时出现 —— 测得的是高温相/近自由塔的量级比，而不是原子问题。
**即使把基和统计都做到完美，`L=4` 给出的数也不是判据要求的那个数** `[C]+[E]`。

## 4 · 判（死线）

**(a) 能在 `L=4` 上判定 ⇒ 不成立。** 不是"没算完"：`n=8000`、`6` 算符、`3` 个 GEVP 点，`15/15` 无定义；
且 `L0=4` 只有 `2` 个独立时间间隔、`T/T_c≈1.2–1.5`（解禁闭）。这三条都不因资源增加而改变。

**(b) 需要什么（清单，可执行）：**
1. **算符**：3D-APE 涂抹 plaquette `n=1,2,3,4`（+ HYP `n=1,2`），**每个**在 `t=2` 上 `S/N≥10`；
   已有四类（`¼trF²`/`ΣP_p`/`1×2`/`2×2`）在 `L=4` 上判为同方向或噪声，不再计入基。
2. **格子**：`L0 ≥ 6`（最好 `8`）且 `L ≥ 6`（`m₁L ≳ 3` 才算"态装得下"）。`L0=4` 直接放弃。
3. **统计**：`n = 10⁵`（`L=8`，单核 ~11 h；8 条流并行 ~1.4 h），内存 `≈51 MB`（不存规范场）。
4. **诊断同时报**：`λ₂` 符号 + `C(t0)` 最小本征值 + `m₂/2m₁` 与两胶子割的差（这才是判据 `Δ=(ρ²−1)μ₁`）。

**(c) `Ky Fan` 上界松 `3.8–279×` ⇒ 解析侧判定同样无望 ⇒ 是。** `ρ²≤4 ⟺ e₁ ≥ t/5`（`ch05:178-180`），
而 `t/t★=3.28–273`（`ch13:505-508`）⇒ `t/e₁` 通道在 `β=2.5` 无数值希望 `[E]`。**上界的可证性 = 零**
（与 H1 同一条件），**上界的可测性 = 零**（本文件）⇒ A 路两侧都堵。

## 5 · 路径

1. **`L=4` 这条路关掉**：`ρ²` 在 `L=4` 上无定义（`15/15`），理由是结构（秩亏 + 只有 `2` 个 `t` + 解禁闭），
   不是算力。
2. **唯一有意义的测量**：`L0=8, L=8`（或 `L0=6,L=6` 起步）+ APE 分级涂抹 + `10⁵` 组态，**同时**报
   `m₂/2m₁` 与 `C(t0)` 正定性。预计单核 ~11 h / 8 流 ~1.4 h `[E 外推]`。
3. **但即便测出来也不搬墙**：判据等价于 `e₁` 下界 = H1（`ch05:178-180` 逐字 "cannot be used as a new
   sufficient condition"）⇒ 测 `ρ²` 只是给 H1 换坐标。**A 路按 ta03 的判：转回 `μ₁`（H1）。**
4. **诚实**：本轮新增 = `λ₂>0` 的必要条件是"每算符 `t=2` 上 `S/N≥10` + 近正交"（不是"更多算符"）+
   `L=4` 三结构障碍 + `L0` 的 `T_c` 下限。Clay 0%，无 QED。
