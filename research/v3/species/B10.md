## §3 · ★ 问题 1：`s₁` 在 `β→∞` 的行为（三条读数，逐条给）

### 3.1 (R1) 物理线（`β→∞` 且 `a = a(β) → 0`，AS）：`s₁(β) → 0`

`s₁` 的谱参数是**格点单位**的转移矩阵能量 ⇒ `s₁(β) = a(β)·m_{0⁺⁺}^{phys}`。渐近标度 `a m ∝ D₀ e^{−cβ} → 0`（`B06-VAR:168`；`H05-WEAK:16` 逐字「`am ∝ D₀e^{−cβ}→0`，且对任何阶 `β^k e^{−cβ}→0`」）⇒
```
s₁(β) → 0   与 m(β) → 0 同步（同一条线上、同一单位）                [T]+[E]
⇒ 「β→∞ 时 s₁ → m」只在**无量纲比值**意义下有内容：s₁/(aΛ) = m_{0⁺⁺}/Λ。
```
**这恰好是语料对"常数地板延到 `β→∞`"的判死机制**：`G05B:117` 把三种读法分开，其中「常数地板延到 `β→∞`」**打到（真自否）`[T]`**；能活的只有比值形式（`G05B:121`、`UNIF3:86–89`）。⇒ **"`s₁` 在 `β→∞` 还正吗"若指格点单位：不正，它按 `e^{−cβ}` 塌到 0；若指比值：那是 H1 本身。** `[T]`

### 3.2 (R2) 固定 `a`、`β→∞`（不取 `a→0`）：`s₁ → m_{0⁺⁺}`，但这条线买不到尾

形式上固定 cutoff 时 `s₁` 趋于连续值（格点单位）而 `β`-无关；但 `UNIF3:46–58` 引理 A `[T]` 逐字：**「`a`-一致 ⟺ `β`-尾-一致」，两边同一量、同一单位**；且固定 `β` 下 `a`-一致是**平凡**的（`UNIF3:46`，引 `G04:70`/`F05:120–137`）。
⇒ 固定 `a` 的逐点结论**不能**当作尾端一致性的证据；`β`-尾那一维是独立的一层。`[T]`

### 3.3 (R3) 若把"`O`-可及"换成"全道"：`s₁ → m` 需 J^{PC}-盲

`s₁ = m_{0⁺⁺}`（`0⁺⁺` 道底），Clay 要 `m = inf` 全道。语料已判这条差额：**B 路靶严格弱于 Clay（Clay ⇒ B，B ⇏ Clay，反例 `W95C:77`）**（`B06-VERDICT:123` `[T]`），补上它要付 J^{PC}-盲（`A02:60,96`）。⇒ 「`s₁ → m`」这一步是 `[C]`，不是 `[T]`。

### 3.4 对题面"`s₁` 在 `β<1/48` 是 `[T]`（P3 给 `f₁²>0`）"的更正 `[T]`

1. **P3 给的是残数，不是位置**：`PROOF-P3-UNCONDITIONAL.md:31–32` 逐字「this is a finite-`L` strong-coupling **residue (I1)** theorem」「**Does NOT** give … the strong-coupling **gap** itself」；`f₁²>0 ⇏ m₁ ≥ δ`（`H07-RETRACT:97–101` 一行 witness `ν = wδ₀+(1−w)δ_M`：`f₁² = w > 0` 而 `m₁ = 0`）。⇒ **`f₁²>0` 不能顶 `s₁>0`**。
