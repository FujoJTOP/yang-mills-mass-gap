# Q06-RICCATI — `S = E[H+Φ'']`、`D = Var(G+Φ')` 在 `β` 上是否有可积的里卡提型不等式？

**日期**: 2026-11-25 · **禁 git commit**（遵守） · 脚本/日志: `research/v3/species/w7/q06_riccati.py` → `q06_riccati.log`

## 1. 定义 + `S′`、`D′` 的表达式 `[T]`

测度 `dμ_β = exp(−β h + Φ)`，`h = Σ_P(1−½ReTr U_P)`（Wilson，`β`-线性），`Φ = −log J`（`β`-无关）。对任意可观测量 `O`（分部积分/测度流恒等式）

$$\frac{d}{d\beta}E[O] = E[\partial_\beta O] - \mathrm{Cov}(O,h) \tag{1}$$

`V = β h + Φ` ⇒ **逐样本仿射**：`F = ∂_tV = β g + F_Φ`、`κ = ∂²_tV = β h₂ + κ_Φ`，`g := ∂_t h`、`h₂ := ∂²_t h`（两者 `β`-无关）。

$$S' = E[h_2] - \mathrm{Cov}(\kappa,h) \tag{2}$$
$$D' = 2\,\mathrm{Cov}(F,g) - \mathrm{Cov}(F^2,h) + 2E[F]\,\mathrm{Cov}(F,h) \tag{3}$$

两项都是**三阶 cumulant**：`Cov(κ,h)`、`Cov(F²,h)`。`h` 未被 `p19` 存盘，故本文用 `(2),(3)` 反解它们（`F_Φ`, `F` 的均值近零，末项 `≲1e-3` 忽略）：

| `β` | `E[h₂]` | `2Cov(F,g)` | `Cov(κ,h)`（反解） | `Cov(F²,h)`（反解） |
|---|---|---|---|---|
| 1 | 0.2427 | 0.4553 ± 0.009 | −0.6472 | −0.3395 |
| 2.5 | 0.6430 | 1.1756 ± 0.034 | −0.2839 | +0.3245 |
| 4 | 0.7569 | 1.3993 ± 0.046 | −0.2057 | +0.4917 |
| 6 | 0.8335 | 1.5653 ± 0.058 | −0.1752 | +0.5822 |

⇒ **三阶项不小**：`β=6` 时 `Cov(κ,h)` 是 `S′` 的 17%、`Cov(F²,h)` 是 `D′` 的 37%（且 `Cov(F²,h)` 在 `β=1` 变号）。任何"丢掉三阶项"的里卡提比较都不紧。`[T]`（公式）＋`[E]`（数值）。

## 2. 里卡提检验：`β` 方向上**没有**里卡提

`D` 是方差 ⇒ 在**马尔可夫时间** `t`（Langevin/HMC）上确实有 `d_t Var ≤ −2Γ ≤ 0` 与 `Γ₂`-Bochner 里卡提；**但 `β` 不是马尔可夫时间**：`(1)` 的生成元是 `−Cov(·,h)`，它是 PSD 双线性型（"协方差梯度流"），却没有半群（`β`-流反复作用 ≠ 马尔可夫算子）。后果就是 `(3)`：**每求一次 `β`-导数就多一个与 `h` 的 cumulant，不封闭**。想要 `D′ ≤ 2cD + …` 这种形状，必须先有与 `β` 无关的 Poincaré/BL 常数，这不在 `(S,D)` 里。

**`S′` 与 `S` 的关系**：由 `(2)`，若 `Cov(κ,h)` 可略，`βS′ ≈ S − E[κ_Φ]`（"0 次里卡提"，无 `S²` 项，`S/β` 应下降）。**实测相反**：`m = βS′/S = 1.56 → 1.14 > 1`，`S/β = 0.572 → 0.887` 单调升 ⇒ `S` 对 `β` **超线性**，`S` 的"增长"由 `Cov(κ,h) < 0` 撑着（`S′ = E[h₂] + |Cov|`）。所以 `S` 一侧既没有 `S²` 型里卡提，也没有线性松弛；它的 `β`-依赖是"平均曲率 `E[h₂]` + 曲率-作用负相关"两项，二者都只能实测。
**真正的"里卡提形状"在这里**：`G = S−D > 0` 等价于 `β·Var_β(g) ≲ E_β[h₂]`——即**曲率涨落 vs 曲率均值**的比较（Bakry–Émery 的 `Γ` vs `Hess` 形状），而不是 `D′` 与 `S′` 的比较。

## 3. 量化：`D/S` 的 `β`-依赖，两个互斥 closure

`S − D ≡ G`（`[T]`，`q06` 数值复核 `max|gap+G′| = 2e-16`）。因此**先看结构**：`D = β²Var(g) + 2βCov(g,F_Φ) + Var(F_Φ)`，`S = βE[h₂] + E[κ_Φ]`。

| `β` | `β²Var(g)/D` | `2βCov(g,F_Φ)/D` | `Var(F_Φ)/D` | `Var_β(g)` | `Var_β(F_Φ)` |
|---|---|---|---|---|---|
| 1 | 0.789 | −0.001 | 0.212 | 0.2279 | 0.0613 |
| 2.5 | 0.963 | +0.003 | 0.034 | 0.2348 | 0.0516 |
| 4 | 0.987 | −0.005 | 0.018 | 0.1754 | 0.0506 |
| 6 | **0.994** | −0.004 | 0.010 | **0.1307** | 0.0456 |

⇒ `β ≥ 2.5` 起 `D` 几乎全由 `β²Var_β(g)` 承担，而 `Var_β(g)` 只按 `β^{−0.67±0.06}` 缓降（`−0.62` / `−0.73` 两段）。`E[h₂]` 趋于饱和（`0.643 → 0.757 → 0.834`）。故**渐近式**

$$\frac{D}{S}\ \xrightarrow[\text{leading}]{}\ \frac{\beta\,\mathrm{Var}_\beta(g)}{E_\beta[h_2]},\qquad \beta=6:\ 0.941\ (\text{真值 }0.889)$$

**四种拟合（全都穿过四点）**：

| 模型 | 参数 | 大 `β` 结论 |
|---|---|---|
| `[P1]` `1−D/S = cβ^{−p}` | `c=0.434`, `p=0.729`（`p19_fit` 给 `0.483/0.834`） | **`D/S → 1`**，无穿越；`R(10)=0.919`、`R(20)=0.951` |
| `[P2]` `D/S ~ β^s` | `s = +0.323` | 无界，必有穿越 |
| `[P3]` 结构式 `D = Aβ²+Bβ+C`、`S = lβ+e` | `A=0.01884, B=0.75694, C=−0.48697`（残差 `9.2e-5`）；`l=0.9512, e=−0.41424`（残差 `3.8e-2`） | `D=S` at `β = 10.67`；`D′=S′` at `5.16` |
| `[P4]/[P5]` `R=Rs(β/6)^{q−m}`、`G''` 二次式 | `q−m(6)=+0.110`；`G''` 顶点 `7.9`、零点 `17.31`（复现 `p19_fit`） | `D=S` at `17.6` / `17.3` |

**`D/S` 是否趋向 1**：**窗口内"趋 1"是真的（0.505→0.889，单调），但不是极限 1**。`[P1]` 要成立需 `Var_β(g) ~ β^{−1.73}`，实测 `β^{−0.67}`——**`[P1]` 被结构排除**（除非 `g` 在分布上趋零）。由 `β Var(g)/E[h₂]` 的判据（`β=6` 时 `0.941`，差 6%）：
$$\text{交叉判据：}\ \beta\,\mathrm{Var}_\beta(g) \ge E_\beta[h_2]$$
按 `Var(g) ~ β^{−0.67}` 外推得 `β_c ≈ 7.1`；真值 `R` 还差一个 `−0.05` 的次项，实际 `β_c ≈ 8`。**统一判决：`β_c ∈ [7, 17]`，最可能 `8–11`**——`D/S` 会在 `β ≈ 8–11` **穿过 1**，然后 `G'' < 0`。

## 4. 判死线（逐条）

**(a) 不成立（不是"免费"，是同义反复）。** `D′ ≤ S′` ⟺ `−G′ ≤ 0` ⟺ `G′ ≥ 0`。而 `G` 正是 `p19` 已经测过的对象（`0.2835 → 0.5913` 单调升）。所以"由 `D(1)<S(1)` + `D′≤S′` 推出全区间 `D<S`"**在逻辑上只有重述 `G′>0` 的信息量**：`D−S = −G`，单调不减的是 `G` 本身，`D<S` 就是 `G>0`。**这条路不可能把 `[E]` 变成 `[T]`**：要证 `D′≤S′` 就要证 `G′≥0`，而 `G′` 的表达式同样需要三阶 cumulant（第 1 节）。
数值上它还**不硬**：窗口内点式间隙 `−0.095, −0.076, −0.055, −0.026`，显著性 `1.5σ, 2.4σ, 1.3σ, 0.15σ`（用 `p19` 的 `σ(G'')` 经同一 stencil 传）。区间平均（`dD−dS = −0.085, −0.066, −0.040`）是硬的，但它等于 `ΔG/Δβ > 0`，同样只是 `p19` 的单调性。

**(b) 部分触发。** 窗口 `[1,6]` 内无穿越（`G″` 处处 `≥ 2.3σ`…`1.3σ` 为正），但 `D′−S′ = −G′` 单调趋零，**两条独立路给出同一拐点 `β ≈ 7.9`**（区间间隙线性外推 `7.93`；`p19` 的 `G″` 二次顶点 `7.9`）。`β > 7.9` 后 `G′ < 0`（`G″` 递减），`D′ > S′`。穿越点预测：`β_c ≈ 8`（结构式 `βVar(g)/E[h₂]`）到 `10.7`（`P3`）到 `17.3`（`P5`）。**结论：大 `β` 余量确实消失，且不是"渐近趋 1"，而是"翻过去"。** 要定性只需一次 `β=8, 10, 12` 的测量看 `βVar(g)/E[h₂]` 是否越过 1。

**(c) 触发。** `S′`、`D′` 依赖 `Cov(κ,h)`、`Cov(F²,h)` 与 `Var_β(g)`（`= Var_β(∂_t h)`），在 `(S,D)` 内**不闭合**，且数值上占比 17%/37%，不可当小量丢掉。
但**不是无限层级**：`(1)` 是单-`β` 恒等式，`∂_β` 每次都只把 `Cov(·,h)` 带出来，不再往更高阶走。所以只要一次运行多存一列 `h`，`S′`、`D′` **可以在单点精确算出**（无需有限差分、无需截断）。**这是把 `p19` 从 `[E]` 往 `[C]`/`[T]` 推的真正路径**，见 §6。

## 5. 酸测（自由场）

自由场 `S = D`、`G = 0`，此时 `(2)(3)` 的每一项都退化为 0：`D′ ≤ S′` 取**等号**，`D<S` 取**等号**。⇒ 该比较在自由场是**边界紧的**（不是 vacuous，但不含任何余量）。所以任何"Riccati ⇒ `G''>0`"的说法都必须给出**严格**不等式的来源，而这正好是 `(c)` 的三阶项——不能靠比较定理白拿。`[T]`（结构）＋`[C]`（解读）
