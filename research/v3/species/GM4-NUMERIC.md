### 3.4 强行点估计 + 区间：**给不出**，且**被零模型复现** `[E]`

三点拟合 `ω = D + δ₁a²`（误差经 `σ_ω = cosh(m̂/2)·σ_m̂` 传播，`log[3d]`）：

```

δ₁      = −8.4664e+07 ± 3.40e+07          (χ² = 0.07/1)

```

**若只看这一行会误读成"`δ₁ ≠ 0` at 2.5σ"。** 决定性检验——**纯 cutoff 零模型**（三个 `m̂` 取常数 `2.195`，即"理论里根本没有连续质量"），同一拟合：

```
δ₁(null) = −4.8074e+07 ± 3.40e+07        (χ² = 0.03/1)
|δ₁(data) − δ₁(null)| / σ  =  0.76 σ
```

⇒ **该拟合分辨不了"有 `δ₁`"与"无连续极限"**。同时注意：`Δ³/24 = 2.07e8` 相对 `σ(δ₁)=3.4e7` 是 **6σ**——**名义分辨力是够的**，缺的是**对 cutoff 漂移的鉴别力**（`a²` 的一次项在 `a∈[2.4e−3,3.6e−3]` 上被用来吸收 `1/a` 的漂移）。

**卡在哪（逐条，`AGENTS §2.1` 窗口声明）**：
1. **R1 失败**（本节）：这条线只固定体积；物理质量没固定，且实测证明它**反向**漂移（`a^{-1.56}`）。
2. **R5 失败**：`a(β)` 的绝对值缺失（74×）；`Δ_a` 的"增长"有相当部分是 `a(β)` 选择造成的（取一圈 vs 两圈在 `Δβ=0.16` 内差 1.5%–2.7%，`GW7:114`；跨 `2.5→2.66` 更大）。
3. **R4 失败**：`σ/m̂ = 6.2%–18%`；`m̂≈1.9` 处 4σ 要求 3.8% ⇒ 差 2–5×（还只是统计）。
4. **⑤ 失败（结构性）**：`m̂≈1.9 ⇒ m̂²/24 = 15%`，`a⁴` 同阶；而 `δ₂` 裸值按幂次发散（`GK2:216`）⇒ 拟合的"余项"没有受控上界。**这一条**即使把 R1/R4/R5 全部修好也仍然在**。

⇒ **判：`δ₁` 在仓内"不可判定"；`(SM-2)` 既不被支持也不被否证。** 给不出点估计，也给不出区间（上面那个 `−0.85e8 ± 0.34e8` 是 cutoff 计，不是 `δ₁`）。
