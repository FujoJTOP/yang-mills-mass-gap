## 1 · 分解式核准：`[T]` 成立（两条前提都要点名）

```
log Z_dec(B_T) = Σ_{α≥0} #{i ∈ ℤ : 0 ≤ i, i+α ≤ T} · A(α)
               = Σ_{α≥0} (T−α+1)_+ A(α) .
```
放置数：`i` 从 `0` 到 `T−α`，共 `T−α+1` 个（`α≤T`），否则 `0`。`(T−α+1)_+ = max(T−α+1,0)`。∎

**为什么这不是"想当然"**——三条缺一不可：

| 前提 | 内容 | 缺失后果 |
|---|---|---|
| (P1) **开管计数** | 放置数是**区间计数** `T−α+1`，不是环绕数 `T` | 换成周期管（放置数 `=T`）⇒ 见 §3 反例，**必出 `T` 前因子** |
| (P2) **按 `att` 分组** | `α` 是附着片距，簇可越端延伸 | 按 `supp` 分组 ⇒ 漏掉越端簇，`ε_T` 公式变、`D_∞` 不存在 |
| (P3) **时间平移不变** | 簇权只依赖形状与 `att` 的相对位置 | 每条放置要单独求和，无 `A(α)` |

**精确核验（不靠眼力）**：取**符号混合**的有理数权 `A(α)=p_α/q_α`（`α=0..12`，随机 `p∈[−9,9]`、`q∈[1,11]`），用 `Fraction` 精确算术逐项算
`Σ_α(T−α+1)_+A(α) − [φ_dec T + log D_∞] − ε_T`，`T=0..7`：**残差 = 0（精确 0，不是 `1e−16`）**。
（`φ_dec:=Σ_αA(α)`、`log D_∞:=Σ_α(1−α)A(α)`、`ε_T:=Σ_{α>T}(α−1−T)A(α)`。）

## 2 · `ε_T` 的系数核准：**恒等式成立，但系数不会为负**

逐段算 `(T−α+1)_+ − (T−α+1)`：

| 区间 | `(T−α+1)_+` | 渐近式 `T−α+1` | 差 |
|---|---|---|---|
| `α ≤ T` | `T−α+1 ≥ 1` | `T−α+1` | **`0`** |
| `α = T+1` | `0` | `0` | **`0`** |
| `α ≥ T+2` | `0` | `T−α+1 ≤ −1` | **`α−1−T ≥ 1`** |

⇒ `ε_T = Σ_{α>T}(α−1−T)A(α)`，且

> **★ 关键：在求和域 `α>T` 上，`α−1−T ≥ 0` 恒成立**（`α=T+1` 处取 `0`）。逐点枚举 `T∈[0,9]`、`α∈(T,T+40]`：**负系数个数 = 0**。
> 所以"系数 `α−1−T` 可以为负"这句话**错**。负号不在被留下的项里，而在**被减掉的渐近系数** `T−α+1<0` 里 —— 两者是同一个数的相反数，写法不同而已。

**这个区别有实质后果**：因为求和域上系数非负、且 `A>0` 时 `ε_T>0`，**`ε_T` 不需要任何符号抵消**：
`|ε_T| = Σ_{α>T}(α−1−T)|A(α)|`（当 `A(α)` 同号），一般情形也只需**绝对收敛**，不需对消。
⇒ 这正是 `(L1-c.2)` 能"一页写完"的结构性原因：被截掉的不是"两端相互作用"，是**放不下的放置位**；截断误差是**同号累加**，故可用 `|A|` 直接控。

*自校 `T=0`*：`log Z_dec=A(0)`；右端 `=0+A(0)+Σ_{α≥1}(1−α)A(α)+Σ_{α≥1}(α−1)A(α)=A(0)` ✔（逐项抵消，`α=0` 项不特殊）。

## 3 · ★ 界核准：**无 `T` 前因子**；多一个 `1/(1−ū)`，但那是常数

设 `|A(α)| ≤ ū^{α+1}/(1−ū)`（`0<ū<1`，逐片 KP 的动物计数已被吸收进 `ū`）。令 `m := α−1−T ∈ ℕ₀`，则 `α = T+1+m`、`α−1−T = m`：

```
|ε_T| ≤ Σ_{m≥0} m·ū^{T+2+m}/(1−ū)
      = ū^{T+2}/(1−ū) · Σ_{m≥1} m ū^m
      = ū^{T+2}/(1−ū) · ū/(1−ū)²
      = ū^{T+3}/(1−ū)³  =  B ū^T ,      B := (ū/(1−ū))³ .        (★)
```

**逐条回答提问**：

1. **`Σ_{α>T}(α−1−T)x^α` 的量级**：**恰好** `x^{T+2}/(1−x)²`。数值核对（`x=0.57, 0.0104, 0.9`；`T=0,3,7`；截断 `α≤400`，十进制 40 位）：与闭式差 `3e−39 / 1e−43 / 2e−15` ⇒ **闭式正确**。
2. **"带 `(α−1−T)` 权重是否有额外的 `1/(1−ū)`？"** —— **是**：无权重尾 `Σ_{α>T}ū^{α+1}=(ū^{T+2})/(1−ū)`；加权尾 `=(ū^{T+2}/(1−ū))·(ū/(1−ū))`。总常数因此是 `(1−ū)^{−3}`（相对 `|A|` 界自带的一个 `(1−ū)^{−1}` 再多一个）。
3. **"有无 `T` 前因子？"** —— **没有**。位移 `m=α−1−T` 同时把**权重**（`α−1−T ↦ m`）和**指数**（`ū^α ↦ ū^{T+2+m}`）一起平移掉，`ū^T` 因此是**乘性**的 `ū^T × (T‑free)`，不是 `T·ū^T`。**`m`-和从 `0` 起、与 `T` 无关 ⇒ 对 `T` 一致**（这点是关键：一致收敛，不是"先固定 `T` 再求和"）。
4. **数值铁证（最极端情形）**：取 `A(α)=ū^{α+1}/(1−ū)`（恰好取到界，`α≤2000`），`ū=0.57, 0.5654, 0.30`，`T=0..12`：
   **`ε_T/ū^T` 对每个 `ū` 是常数**（`2.329267 / 2.211603 / 0.0787172`，逐位相同，`T` 变它不变），且恰等于 `B=(ū/(1−ū))³`（`2.3293 / 2.2116 / 0.0787`）。
   `T` 从 `0` 到 `12`，`ε_T` 缩小 `850×`，**比值一位不动** ⇒ 指数里只有 `ū^T`，没有 `T`。
5. **对 `|A|` 的细节稳健**：即使把 `|A(α)|` 弱化成 `≤ū^α`（丢掉 `1/(1−ū)`），加权尾仍是 `ū^{T+2}/(1−ū)²` —— **照样无 `T`**。所以"无 `T` 前因子"不是 `|A|` 界的巧合，而是 `(P1)` 开管计数的直接结果。

**⇒ (★) 成立；`B,δ` 与 `L,T` 无关（`ū` 逐片、`(2.1)` 逐片）；`L`-一致的机制是"附着点在 `1×1` 骨架上被**空间钉死**"，故动物计数 `(eΔ)^{|Γ|}` 与 `L` 无关（绕空间周期的装饰只让 `|A|` 更小）。**

## 4 · `κ=4ln(1/u)/a` 与"无面熵"核准

**4.1 `4` 从哪来 —— 不是 `d=4`，不是"面数"。`[T]`（几何）**
时间推进：切片 `j` 与 `j+1` 的 plaquette 只经 **temporal** plaquette 相邻（空间 plaquette 在相邻切片不共 link）。源是**单片空间 plaquette**，它有 **4 条边、4 个单位通量**；连通性 + 通量守恒 ⇒ 4 条通量各走一条链，每条链跨 `T` 个时间边界、每次 ≥1 个 temporal plaquette ⇒ `|P| ≥ 4T`；等号 ⟺ 4 面各一条直链、无空间 plaquette ⇒ **直四壁管**（`P3-FOURWALL §1.2–1.5`，Gupta (14.20) 矩形管）。
⇒ 每片成本 `4·ln(1/u)`，率 `κ = 4ln(1/u)/a` ⇒ **`κ/4 = ln(1/u)/a`，纯代数，精确 `[T]`**。
**注意这个 `4` 与时空维数无关**：任意 `d≥2` 的 plaquette 都恰有 4 条边；若源换成周长 `P` 的环，率就是 `P·ln(1/u)/a`。所以 `4` 是**源算符的周长**（4 个通量单位），不是 `d=4` 的巧合，也不是立方体的 6 个面。（`R4-PERCENT:156` 另说"球面拓扑前因子 `N^χ=4`"是同一数值的**第二个**来源——那是 `a₀` 的振幅因子，不是 `κ` 的壁数；两者数值相同纯属 `N=2` 的偶然，不能混用。）

**4.2 "零扭折极小唯一 ⇒ 无面熵" —— 这个推理对，但要写清它排除了什么、没排除什么**
- 若每片每壁有 `μ` 个**退化**极小延续，则 `w(B_T)=a₀(μu^4)^T` ⇒ 率变成 `4[ln(1/u)−ln μ]/a`，`κ/4` 要减 `ln μ/a`。这就是"面熵"通道。
- `P3-FOURWALL §1.5`：`4T` 处极小**唯一**（任何拐角/扭折/横向位移 `+≥1` plaquette）⇒ `μ=1` ⇒ **该通道关闭**。
- **横向求和不是面熵**：无动量源对汇位置求和给 `Σ_x u^{4|x|}=O(1)`，是**幅度**（进 `a₀`），不是 `μ^T` 率；它 `T`-无关。
- **扭折链的熵确实存在**，但它**不在 `κ` 里**：它就是装饰气体，已计入 `f_dec=O(u/a)`，而 `m₁^{dr}=κ−f_dec` 把它**减掉**。⇒ 不重复计、也不漏计。
⇒ **`κ/4=ln(1/u)/a` 精确 `[T]`**；**(c) 的"有熵因子"通道不触发**。

**4.3 但 `δ ≠ κ/4`（`(c)` 的"另一支"成立，`x01` 已自陈）**
`(★)` 给 `δ=ln(1/ū)/a`，`ū=eΔ\bar C u` ⇒ `δ = κ/4 − ln(eΔ\bar C)/a < κ/4`。
数值（`u=0.0104`、`eΔ=54.3656`）：`κ/4·a = 4.56595`，`δ·a = 0.57022`，差 `3.99573 = ln(eΔ)`，`δ/κ = 0.0312` ✔（`x01` §3 行 6 的 `[M]` 复现）。
**这一支不改 `κ/4`，只改"`(L1)` 里能取的 `δ`"**：`(L1)` 作为**存在性**陈述（`∃δ>0,B<∞`）仍是 `[T]`；但 `W02-L1.md:23` 的字面"**可取 `δ_{L1}=ln(1/u)/a=κ/4`**"**已被本复核推翻为 `[C]`**（只能取 `δ=ln(1/ū)/a`；要 `δ=κ/4` 需另证"簇数常数为 1"，而 `W02 §4` 自己担心的 `C^T` 簇数正是被 `ū` 吸收掉的那一项）。**这是本轮唯一需要回填下游的字面改动。**
