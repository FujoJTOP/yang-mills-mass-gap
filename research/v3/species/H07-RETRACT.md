## §1 （Q1）"地板集"是什么 —— 精确集合

### 1.1 三个**不同**的集合，必须先分开

| 层 | 集合 | 逐字出处 | 状态 |

### 1.2 判：`d06` 的地板集 = `F_δ`（即 `A_δ` 的 β-原像）。用户给的两个候选**都不是**它

- **候选甲 `{β : Λ★(β) − m₁²(β) ≥ δ}`**：这是**隔离 `I2`**，不是地板。二者**不可互推**，语料已逐字判过：`T6-BINDING-ADVERSARIAL.md:165` 的反例 `Λ★=3>0=m₁²` —— `I` 真而 `G`（`m₁>0`）假 ⇒ **`I ⇏ G` `[T]`**。单位也不同槽：`Λ★, m₁²` 是**质量²**（`A02-2PPI2.md:34`、`F01:45` 逐字"`Λ★` 与 `m₁²` 同槽位 = 质量平方"），而 `m₁ ≥ δ` 是**质量¹**。⇒ 读成甲 = 把"证隔离"当成"证地板"，方向上看是**更强的谓词**（隔离带原子），实际在语料里**更没戏**：`Λ★` 无下界伴随（`R2:103–105` 逐字 "*neither has a lower companion*"，`[NG]`）⇒ 该集**连"闭"都拿不到**（无已知下界 ⇒ 无水平集可谈）。

## §4 （Q4）"路径提升" —— 本机器的**全部**难点

### 4.0 纯拓扑先钉死

闭 + 非空 + 连通域 **⇏** 全空间：`{0} ⊂ [0,1]` 闭、非空、环境连通，但不是全空间。连通性能用的**唯一**形式是

> `F` 非空 **且** `F` 既闭又开（clopen）于连通域 ⇒ `F` = 全空间。

用户的问法（"这需要该集既开又闭"）**正确**，且这就是本机全部难点。下面四步把它判死。

### 4.1 **T1（测度层：`A_δ` 闭且**内部为空**）`[T]`** —— 开性在对象层是**假**的

*闭*：§2.2。*内部空*：任取 `ν ∈ A_δ`、`0<ε<1`，令 `ν_ε := (1−ε)ν + εδ₀`。则 `ν_ε ⇒ ν`（弱），而 `m₁(ν_ε) = 0 < δ` ⇒ `ν_ε ∉ A_δ`。∎

**加强（无连续性模数）`[T]+[V]`**：R1(ii) 的精确 Wasserstein-1（阶梯 CDF 精确积分，非插值）：

| `ε` | `W₁(ν_ε, ν)` | `m₁(ν_ε)` | `|Δm₁|/W₁` |
|---|---|---|---|
| `1e−2` | `1.090e−2` | `0` | `5.505e+01` |
| `1e−4` | `1.090e−4` | `0` | `5.505e+03` |
| `1e−6` | `1.090e−6` | `0` | `5.505e+05` |
| `1e−8` | `1.090e−8` | `0` | `5.505e+07` |

⇒ `W₁ → 0` 而 `|Δm₁| = 0.6` **不变**，比值 `∝ 1/ε → ∞`。**地板函数在 `A_δ` 的每一点都间断，且无任何模数** ⇒ **"紧性 + 弱连续"永远拿不到开性**。

> **⇒ 对 `d06` 的一处正面反驳 `[T]`**：`D06-SPEC:169` 说 openness「可被**独立**攻击（不需要任何谱信息）」。T1 逐字否证：在对象层 openness **是假的**；在族层它与结论**等价**（T2）。**不存在"独立的开性论证"** —— 这正是 `d06` 给 `D2` 记 5/5 的那条理由（"价值在把墙收成一点 openness"），它站不住。

### 4.2 **T2（零松弛：clopen ⟺ 结论）`[T]`**

设 `I` 连通、`F_δ ⊂ I`。则
```
   F_δ 闭 ∧ F_δ ≠ ∅ ∧ F_δ 开   ⇒   F_δ = I        （连通性）
   F_δ = I                      ⇒   F_δ clopen ∧ ≠ ∅
⇒  "既闭又开且非空"  ⟺  "m₁ ≥ δ 于整个 I"  ⟺  搬运结论
```
**逐字回应死线 (a)**：*若"地板集既闭又开"可证 ⇒ `β` 全空间成立 ⇒ 搬运解决* —— **对**；但该假设与结论**互为充要**，不是"更强的充分条件"，**是同一句话的两种写法**。∴ 它**不可能被证**而不已证结论。它是本机的**零松弛**（`d06` §1.5 的"无损即换名"判据）。

> **内部不一致（必须写死）**：`D06-SPEC:63` 逐字把 `inf supp ν` 列进"无损量 ⇒ 与隙等价 ⇒ 循环"的清单：「无损量（`λ₂`、Poincaré 常数、**`inf supp ν`**、`f₁²`）与隙等价 ⇒ 循环」。**而 `D2` 的地板集就是由 `inf supp ν` 定义的** ⇒ 按 `d06` 自己的 §1.5，`D2` 应判循环；§3.2 却给它 5/5。本轮按 §1.5（更严的那条）判。

### 4.3 **T3（连续族：`∂F_δ = {β : m₁(β) = δ}`）`[T]`**

设 `β ↦ m₁(β)` 连续、`F_δ ≠ ∅`、`inf_I m₁ < δ`。取 `β₁ ∈ F_δ`、`β₂` 使 `m₁(β₂) < δ`，由 IVT `∃β*` 介于两者使 `m₁(β*) = δ` ⇒ `β* ∈ ∂F_δ` ⇒ `F_δ` **不开**。∴ 连续非平凡族上

```
   F_δ clopen  ⟺  inf_I m₁ ≥ δ  ⟺  F_δ = I  ⟺  δ ∉ m₁(I)
```

数值（R4）：三族的**每个** `F_δ` 边界点都满足 `m₁(β) = δ`：

| 族 | δ | 边界点 | `max|m₁(β)−δ|` |
|---|---|---|---|
| 2D YM `m₁=2/β`（连续） | `0.81 / 1.0 / 2.0` | `2.4691 / 2.0 / 1.0` | `2.2e−6 / 3.8e−6 / 6.4e−6`（= 网格步长） |
| 两能级 `m₁=2|β−1|`（连续） | `0.5 / 1.0 / 2.0` | `0.75,1.25 / 0.5,1.5 / 0.0,2.0` | `2.0e−5` |
| 跳跃 `w=β`（间断） | `0.5 / 0.9` | `0.0` | `0.50 / 0.10`（**跳过**，非交点） |

⇒ **开性 ⟺ "`m₁` 不跨 `δ`" ⟺ 隙。** 两种情形（连续族的横截零点、间断族的跳跃）都归结为同一句话。

### 4.4 **T4（`(a)+(b)+(c)` ⇏ `(d)`）`[T]`** —— 反例（R3）

`I = [0,1]`，`ν_b = (1−w(b))δ₁ + w(b)δ₀`：

| 族 | `w(b)` | `F_δ`（`δ=0.5`） | (a) 闭 | (b) 非空 | (c) 紧 | (d) 结论 |
|---|---|---|---|---|---|---|
| mono | `b` | `{0}` | ✓ | ✓ `m₁(0)=1` | ✓ | **假**：`m₁(1)=0` |
| both | `b(1−b)` | `{0} ∪ {1}` | ✓ | ✓ | ✓ | **假**：`m₁(0.5)=0`，**两端都好仍无路径** |

族的弱连续：`sup_b W₁(ν_b, ν_{b+1e−3})/1e−3 = 1.00`（Lipschitz，R3）⇒ **族连续、像紧、（b）成立，(d) 仍假**。

⇒ **缺的假设不是紧性、不是连续性、不是种子，是开性**；而开性 ≡ 结论（T2）。`both` 那一行更强：**连"两端 `m₁ ≥ δ`"都满足，仍不存在 `F_δ` 内的路径** —— 这正是 `D2` 的"路径"步骤：它要的不是端点值。

### 4.5 **T5（最强结构输入也不够：解析性）`[C]`**

有限体积 + 固定截断下 `β ↦ T_β` 的矩阵元解析 ⇒ `m₁ − δ` 在避开简并处解析 ⇒ **其零集离散** ⇒ `∂F_δ` 离散。这排除了"孤立尖峰"这类病态（R4 的连续族印证），但**不排除横截零点**：R4 的两能级族 `m₁ = 2|β−1|` 的两支各自解析，交界处恰是 `F_δ` 的边界。
