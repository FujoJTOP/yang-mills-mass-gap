## §0 · 判决（逐字）

**(c)。** 四模型不是"钉不出靶"，而是**把靶钉死了**：任何合格的 `X` 必是 `m` 的重标（§2 定理 N09-1）。因此

> **决战目标（逐字）**：
> `∃δ>0, ∀β∈[1/48, 2.5], ∀L/a≥L₀, ∀ 粗模横向 v⊥轨道 (k→0)：  G″_{k=0}(v)/a² ≥ δ² > 0`（等价 `m(β,L/a)·a ≥ δ`），
> **且 `δ` 的证明不得取用下列五类证书之任一**：①平均/局域量；②极值-谱-容量族；③强耦合残数搬运；④相似不变比值；⑤恒真/发散量。
> 换言之：决战对象**不是再选一个 `X`**，而是"第六类证书"本身。

**(b) 不成立**，理由是措辞层面的：`(b)` 说"没有这样的靶 ⇒ 证明没有这样的靶"。但 N09-1 证明的是**靶唯一**（`m` 及其重标），不是**靶不存在**。`m>0` 是真命题的一个候选（正是 Clay 的内容），所以"证明没有靶"会证掉自己的题目。可用的 no-go 只是 `(b′)`：**没有非 `m` 的载体**——这条已在 §2 证成，其正确用途是**关闭"造 `X`"这条生产线**，不是关闭项目。

## §1 · 靶必须满足的最小性质（由四模型 + 死路台账反推）

四模型给的是**四值**签名，不是两值：自由场 `0` / 2D YM `真` / M6 `假` / 单 plaquette `无定义`。四个槽必须**互不合并**，这是全部约束的来源。

| # | 最小性质 | 反推出的死路 | 证据 |
|---|---|---|---|
| **M1** | `X(free)=0`，**精确**（不是极限口径） | 自由场必挂的都不算酸测 | 自由场 LSI 常数精确值 `γ̂=λ_min(K)=m̂²`，`m=0` 给 `0`（`A2-A-SCALING.md:69`，`[T]`） |
| **M2** | `X` 与 `G″` 在 `{2D, M6}` 上**反相关** | `G″`（M6 上 `2ω>0` 而 `m=0`；2D 上 `G″=0` 而 `m=3g²/8>0`，两向皆反） | `docs/position-current.html:131`、`:308` |
| **M3** | 必须依赖时间方向/谱/热力学极限 ⇒ 单片**无定义** | `det>0`（恒真）、`Kato`（空转）、单片平均 | 死路台账；`LOOP-RUNBOOK.md:8130`（`Kato ⇒ m>0` 真，逆假） |
| **M4** | 给的是**朝下的界**（`inf`/极小），不是平均或方差上界 | 矩/正性族、`(−Δ)^{1/2}`、BE/BL/LSI/Cheeger/容量/RCD | `H6-HEAD-SPECTRAL.md:22,46,384`（命名类 `[NG]`）；`CTL-CLOSEST.md:230`（方向错） |

**M1∧M2∧M3∧M4 合取的结果只有一个**：`X` 必须是"对谱底敏感的集体极小量"。这不是第 7 个候选，这就是 §2。

**注意 M2 的一个之前没被单列的推论（本文件新增）**：四模型钉的不是"两个 bit"，而是**一条反相关**——`X` 必须与 `G″` 反向。而 2D/M6 上唯一已知与 `G″` 反向的对象是 `m`。

## §2 · 结构定理 N09-1：四模型把靶钉死，不是钉不动

**定理 N09-1 `[T]`（给定 M6 的模型规格）。** 设 `M6 = 谐振子 ⊗ 自由模`（`H=(p_a²+p_b²)/2+a²/2`，`b` 在长 `L` 圈上，`w=1`），并按 `L→∞` 口径取值，则 `M6` 上**唯一趋于 0 的尺度是谱底** `m₆ := min(w, 2π²/L²)`；其余尺度（`w=1`、振子宽度、自由模方差）都不趋于 0。于是：

1. 若 `X` 在 M6 槽给出"假"而非"无定义"，则 `X(M6)` **必须有定义** ⇒ `X` 只能是 M6 数据的函数（M6 无规范场、无 `β`、无 plaquette）。
2. 若 `X` 又非恒真，则 `X(M6)` 必须**恰好取 0**（"真"= 正 ⇒ 错槽；"无定义"⇒ 与单片合并 ⇒ 判据塌成 3 值，违反 M1–M3 的互不合并）。
3. 在 M6 上"有定义、非恒真、取 0"⇔ "随 `m₆→0` 归零"（因为 `m₆` 是唯一退化尺度）。
4. 由 2D YM 槽 `X>0` 且 `m=3g²/8>0`：`X` 在 `m>0` 上正。

⇒ **存在 `f`：`f(0)=0`、`f>0`（`m>0`），使 `X = f(m)`。** 即：任何过四模型的 `X` 都是 `m` 在 0 处的单调重标。

**推论 N09-2 `[T]`（对 `B05-1` 的升级）**：`B05-INVENT.md:94–95` 用四个候选的**签名碰撞**得出"四模型只 2 bit"（`[T]`，经验式）。N09-1 把它升级成**结构式**：碰撞不是巧合，是 M6 只有一个退化尺度这一事实的必然结果。**故"四模型测试无鉴别力"这句话的准确形式是"靶唯一"，而不是"判据无效"。**

**推论 N09-3 `[NG]`（载体 no-go，(b′)）**：不存在"非 `m` 的载体"。这条只关闭 §1 的造靶生产线，不关闭 `m>0`。

**为什么这条推论不能当决战的终点**：`LOOP-RUNBOOK.md:9167` 自己已经指出，"四模型只 2 bit"是**元陈述**，"同类的账要一起改"。把元陈述当定理去证 no-go，得到的是 `H1` 的换述——零增益。这正是 `(b)` 不可取的第二个理由（第一个在 §0：它会证掉自己的题目）。

## §3 · 三个候选（各自过四模型 + 缺件）

口径统一：`M6` 一律按 `L→∞` 取值（`m_L = min(w,2π²/L²) = 0.1974/0.01234/0.000771`，`L=10/40/160`，`H03-ANOMALY.md:130`）。**这一步是硬要求**：若按固定 `L` 读，M6 的 `m_L>0`，任何以 `1/L²` 为底的量都会被误判成"真"。

### C1 — 谱/极值型：`X₁ = λ₁^Q(β,L/a) := inf_{f⊥1} ℰ_μ(f)/Var_μ(f)`（粗模态 Poincaré 常数 = 曲率语言的隙）

| 槽 | 值 | 判 |
|---|---|---|
| 自由场 | `λ₁ = m̂² = 0`（精确） | ✓ `[T]` |
| 2D YM | `m=3g²/8>0` ⇒ `λ₁>0` | ✓ |
| M6 | `λ₁ → m₆ → 0`（`L→∞`）⇒ "真"为假 | ✓ |
| 单片 | 无时间方向、无谱 ⇒ **无定义** | ✓ |

**4/4 过。缺件**：`(★)` `∃δ>0` 在 `β∈[1/48,2.5]`、`L/a` 一致——**且不得取用②类证书**，因为极值-谱-容量族在此处**退化成 `ess inf G″` = H1 本身**（`Q4-BAKRY-EMERY.md:50–58` 逐字：marginal BE 常数"literally `ess inf G″`"；`H6-HEAD-SPECTRAL.md:384` 命名类 `[NG]`）。升 `[T]` 要证的就是那条不等式本身——即 `(★)`。**这是唯一一个"缺件具体"的候选 ⇒ 逐字就是决战目标。**

### C2 — 平均/局域型：`X₂ = ⟨¼trF²⟩`（或迹反常、Christoffel 等一切正加权平均）

| 槽 | 值 | 判 |
|---|---|---|
| 自由场 | `0` | ✓ |
| 2D YM | `⟨C₂⟩ = 1.5/t − 0.25 + O(t)`：`t→0` 发散而 `m→0`；`t` 大时→0 而 `m` 大 | **反相关 ⇒ 方向错** |
| M6 | **必为正** | ✗ **错槽（给出"真"）** |
| 单片 | `⟨S_W⟩=0.492805` 精确，但 `m` 不存在 ⇒ 无真值 | — |

**判 `[NG]`，无需再试**。原因是一条定理而非一次失败：`H03-ANOMALY.md:130` 逐字 "`m₁=0` 且 `ν≠δ₀` ⇒ `A_1>0`。**⇒ 一切'正的加权平均'在 M6 上必为正 ⇒ 筛选器 ① 必挂**"（`[T]`）。**缺件：不存在可补的缺件**——这是类级 no-go，不是实例缺陷。

### C3 — 残数/搬运型：`X₃ = I1` 的 β-延拓（或 `I2`、或 `m(2L)/m(L)` 型比值）

| 槽 | 值 | 判 |
|---|---|---|
| 自由场 | 无耦合展开 ⇒ `0` | ✓ |
| 2D YM | 残数 `∝ g²>0` | ✓ |
| M6 | 无 `β` ⇒ **无定义** | ✗ **占错槽**（与单片合并） |
| 单片 | 无展开 ⇒ 无定义 | ✓ |

**判 `[C]`，最低概率**。两重打击：(i) 槽位错误（M6 上"无定义"，违反 N09-1 第 2 条）；(ii) 即使强行定义，其缺件是"把 `β<0.1472` 的证书延到 2.5"，而这**正是 19 条搬运已 0/19 的类型（扩窗自我否定）**。**缺件（若要救）**：`I1(β) ≥ c > 0` 对 `β∈[1/48,2.5]` 成立且不缩窗——与 19 条同型，不构成新方向。

**比值变体直接死**：2D YM 的 `m` 与 `L` 无关 ⇒ `m(2L)/m(L)−1 = 0` ⇒ 2D 槽给"假"，错槽。**⇒ 任何"同模型内两尺度之比"都过不了 2D 槽。** 这条顺带解释了 `W^{½}W^{−½}` 的死因（相似不变），是同一件事的两面。

## §4 · 判：哪个最可能

**C1，且无第二可能。** 理由不是"C1 看起来最好"，而是 `§2` 的定理：C1 是唯一一个既过 4/4、又其缺件**不与已判死类同型**的候选——因为它的缺件不在"造 `X`"里，而在"证 `m` 的界"里。C2 是类级 no-go，C3 槽位错误 + 同型 0/19。

**但 C1 ≡ m。** 故"最可能"这个问题的答案本身就是 `(c)`：靶必须是 `m` 本身，其余全是它的代理（`§2` 已证）。
