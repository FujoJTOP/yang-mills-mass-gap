### §1.3 一个必须点名的**任务书前提勘误**

任务书写"严格张量 RG …… 给的是'**谱隙在流下不丢**'的证书——形状正好对上 L4"。**实查：不是。**

- EKR 的摘要与引言给出的定理内容是 **(i) 迭代在 HS 范数下收敛到 `A_*`**、**(ii) 自由能密度在该邻域解析**（Prop 3.2 / 3.3）、**(iii) Ising/XY 的显式高温相界**（Table 1）。**"谱隙 / 质量隙 / 关联指数衰减"没有出现在摘要或引言的定理陈述里**（[A]；定理 3.1 逐字未读，故不断言它正文里没有）。
- 它真正给的是**"吸引域（basin）证书"**：`‖b‖` 小 ⇒ 流到平凡不动点。**这是关于初值的陈述，不是关于"隙在流下不丢"的陈述。**
- **形状对得上 L4 的地方在别处，而且是真的**：它示范了"**精确（无截断）RG 映射 + 有限维包围盒 + 区间算术 ⇒ 在坏参数处也能产出定量定理**"这套**机器形态**。L4 要的正是这种形态（而不是又一条不等式）。
- **⇒ 任务书那句"形状正好对上"应改为**："形态对上（严格定量搬运），但定理内容不对上（它证的是收敛到平凡点，不是隙的保持）"。这个替换不是抠字眼：它直接决定了 T4 的判定（§5）。

## §4 T3 最接近成立的版本：把 EKR 套到 4D 格点规范上

> 本节是"**若硬要做，长什么样 + 会得到什么数字**"。**不是可行性宣告**（§3 已判 P5/P6 不满足），是**上界的计算**。

### 4.1 状态空间用什么

**不用 `SU(2)` 的表示截断去做"状态空间"。** EKR 框架的整个卖点是**状态空间无穷维、映射无截断**（§2.1/2.2），而 `L²(SU(2))` 的 Peter–Weyl 分解恰好是**可数正交和**：

```
   V_leg  =  L²(SU(2))  ≅  ⊕_{j=0,½,1,…} ( V_j ⊗ V_j^* ) ,      dim V_j = 2j+1
```

`A` 是 `V_leg^{⊗6}` 上的一个 HS 张量（4D：每个 4-胞腔 6 条腿 = 6 个 2-胞腔），`A_*` = 全 `j=0` 的 15j-平凡张量（`β=0`：只有平凡表示活着 ⇒ `A_*` **确实可写**）。
**⇒ 状态空间这一层完全照抄 EKR，不需要 `j≤J`。**"`j ≤ J`"只在两处进来：

1. **hat-tensor 扇区簿记**（必须有限）：扇区 = "6 条腿各自取哪个表示" ⇒ 约 `(J+1)^6` 个扇区；
2. **区间算术的实际实现**（每扇区一个区间）。

**这与任务书的设想（"用 `SU(2)` 的 `j≤J` 表示截断"）不同，而且是更好的消息**：`j≤J` 不是"状态空间截断"，而是"**簿记截断**"，因此它的误差是**可加的、可算的**（§4.4），而不是"截断了一个无穷维空间，误差无界"。

### 4.2 定理该长什么样（把 EKR Thm 3.1 逐字改写）

```
   (EKR-YM4, 假想)  存在 δ>0 与一族 4D 规范张量上的无截断 RG 映射 R（2×1 型 + 90° 旋转
   在某个坐标平面内），使：若初张量 A 满足
        ‖(A − A_*)_{s}‖_HS  ≤  δ       对每个扇区 s（共 ~(J+1)^6 个）,
   则 R^n A → A_*（HS 范数），且自由能密度在 β 的相应邻域内解析；
   从而（+ 收缩 ⇒ 指数簇聚）该邻域内存在质量隙 m ≥ m(δ) > 0。
```

**这条定理的形式与 EKR 完全同构**，可迁移的部分是：(i) 4 步分解（gauge transformation / disentangling+splitting / reconnection+isometry / rotation）在 4D 有逐字对应（`2×1` 沿一个方向，旋转在垂直平面内）；(ii) 图形语言（把映射翻译成 HS 估计的不等式系统）不依赖维数；(iii) 区间算术 + master function。

**不能照抄的部分（两个，都是真障碍）**：

1. **`disentangler` 与 `splitting` 在规范张量上的定义**：EKR 的 `D: V⊗V→V⊗V` 与 `J: V⊗V→V` 是从 `b` 构造的；规范张量是**交织子**（每条腿带表示标签、顶点权是 15j），分裂必须**保持交织子结构**，即分裂点需要一次 **recoupling（6j/9j）变换**。**这一步没人做过**（[O]，§2.6 未查到任何 rigorous TRG on gauge）。
2. **4D 的组合排除步**：Kozic 明确指出 3D 的 `2+2>3` 在 4D 变成 `2+2=4`（§2.5）。他的"tagged cluster cancellation"给的是 `cluster exponent ≥ 17/16`、`‖a'‖ ≤ t ε^{32/31}`。**这条技术是否在交织子/规范张量上仍然成立，完全未知**——他的正文我看不到（文件受限）。

### 4.3 误差如何界（三层，必须分开记）

| 层 | 对象 | 界 | 4D 规范侧的状态 |

| **E1 映射误差** | 映射本身的截断 | **=0**（无截断映射） | 可迁移，**这是 EKR 相对数值 TRG 的全部优势** |
| **E2 邻域误差（硬）** | `‖b‖` vs `δ` | `δ = 0.02/扇区`，`0.02√63=0.1587` 总量（HS） | **`β=2.5` 处 `5.0508`** ⇒ 超 `31.8×`（总）/`252.5×`（扇区）。**这一层不可救**：它不是数值精度问题，是前提真假问题 |

## §5 T4 判定

> **判定：对本路（L4）而言 = "已有技术 + 更强计算"能买到的只是**强耦合半径的常数改进**（`7×–30×`，且与 SZZ 同一架）；**要它碰 L4，必须新数学**——而那门新数学恰好就是 H1。⇒ **不构成新物种。**
> **加一句限定（诚实边界）：这不是"No-Go 定理"。** 若有朝一日出现"在 `‖b‖=O(1)` 处仍收缩的 4D 规范映射"，本判定当场失效；而**那正是 H1，没人有**。

**理由（三条，按可核性排序）**：

1. **【可核·数值】邻域外 32×**：`‖b‖/‖A_*‖ = 5.0508` vs `0.1587`（`[V]`）。**这是"前提真假"，不是"精度不够"**：EKR 的定理是一句 `若…则…`，前件在 `β=2.5` 处为**假**。EKR 谱系三年（2022→2026）把 `β_max/β_c` 从 0 推到 0.17–0.27（2D/3D/XY），**没有一次跨过 `β_c`**——这是"机制而非常数"的**经验证据**（与 `CTL-CLOSEST` §5.5 的 R4 同构）。
2. **【可核·结构】目标不动点不存在**：机器需要"可写 + 有可计算邻域"的不动点。YM 只有 `β=0`（平凡，错侧）与 `β=∞`（高斯，marginal ⇒ 无收缩）。**非平凡 IR 不动点不存在（AF）。** ⇒ 这不是"没人做过"，是**没有对象**。
3. **【可核·自陈】最接近的 4D 结果自己划界**：Kozic 2026（唯一一份 4D 严格 TRG）摘要原文：*"This is an **infrared/high-temperature** … result. It **does not constitute** a continuum Yang–Mills construction or a proof of the Yang–Mills mass gap."* **[灰]** —— 借它的自陈，比借我的判断更硬。

**反面（必须有）**：本路的**真实收获**不是零，而是三条**可核增量**（§7.1）：把"tensor-RG 无误差控制"这条仓库内的死因**升级**了（误差控制现在有，死因改成"邻域 + 错误不动点"）；给出 `β=2.5` 处的 `32×/252×` 定量超界；给出"截断 `J≤7`、阶乘尾"这条**正面**结论（它是别的路也能用的工具数据）。
