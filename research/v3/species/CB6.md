## 1 · KP 判据的精确形式（第一问）

### 1.1 逐字

> `∑_{γ′≁γ} |w(γ′)| e^{a(γ′)} ≤ a(γ)   for all γ`

- **出处（原始）**：R. Kotecký, D. Preiss, *Cluster expansion for abstract polymer models*, **Comm. Math. Phys. 103 (1986) 491–498, Theorem 1**，DOI **10.1007/BF01211762**。**原文本轮未开 ⇒ `[O]`**。
- **出处（本轮二级逐字）**：arXiv:**2306.12934**v3 §3.1（"Polymer models and the Kotecký–Preiss theorem"，本轮取 HTML 目录页确认节存在；该节曾于 `RS8 §1.1` 逐字取，且明写 "see Theorem 1 in [KP86]"）；arXiv:**2611.14167** 正文同式。⇒ 形式 `[V]`。
- **`a` 是什么**：聚合物上的**正函数**（"size/grading"），标准取 `a(γ)=α|γ|`（`|γ|`=单体数）。它同时扮演**两个**角色：
  1. **右端** = 该 γ 允许的"局部活度额度"；
  2. **左端指数** = 用 `e^{a}` 换 **簇系数的指数衰减**（结论形如 `Σ_{X⊃γ}|φ^T(X)| ≲ e^{−c|γ|}`）。
- **`e` 从哪来**：只是 `e^{a(γ)}` 的**底**，**不是**判据里的常数。判据对 `a` 自指：`a` 放大 ⇒ 右端线性涨、左端指数涨 ⇒ **永远追不上**（`RS8 §1.2` 的 `[T]` 一行代数）。⇒ **KP 内禀是"小活度"判据，`d`-无关。**

### 1.2 纯数只在对 `a` 优化后出现——而最优 `a` 不是 `α=1`

设 `|w(γ)| ≤ (Ku)^{|γ|}`、过定点尺寸 `n` 的聚合物数 `≤ λ^n`。**两条路**：

| 档 | 写法 | 判据 | 常数 | `Δ=20` 的值 |
|---|---|---|---|---|
| **T1 最粗** | 一阶支配 `Σ ≤ x`（丢掉 `1/(1−x)`），取 `α=1` | `λKu e^{α} ≤ α` | `max_α αe^{−α} = 1/e` | **`e` = 2.71828**（即 C02 的答案） |
| **T2 中** | 固定分级 `α`、保留全动物和 `Σ=x/(1−x)` | `x/(1−x) ≤ α` | `max_α [α/(1+α)]e^{−α} = 1/(φ²e^{1/φ})`，`α*=1/φ=0.61803` | **4.857178**（`φ²e^{1/φ}`） |
| **T3 精确（KP 机制本体）** | 逐顶点分支递推 `R ≤ x(1+R)^Δ`（= 树图/Penrose 计数，每顶点 `Δ` 个槽） | 不动点存在 | `max_R R/(1+R)^Δ = (Δ−1)^{Δ−1}/Δ^Δ`，`R*=1/(Δ−1)` | **53.000687** |

`[T]`（三条都是一行微积分：T1 的 `max αe^{−α}`、T2 的 `α²+α−1=0`、T3 的 `(1+R)=RΔ`）。
`[E]`（`w7` 手算/闭式，见 §5；`Δ=20`：`19^19/20^20 = 0.0188676801`、`1/x* = 53.0006865`）。

> **判**：**T1 的 `e` 是"`a` 取错（`α=1`）"的产物**。KP 的正确读法是 T3，最优分级是 `e^{a}=Δ/(Δ−1)`（`α = ln(Δ/(Δ−1)) = 1/Δ·(1+O(1/Δ))`，`Δ=20` 时 `α=0.051293`），常数 `Δ^Δ/(Δ−1)^{Δ−1}`。而
> ```
> Δ^Δ/(Δ−1)^{Δ−1} = Δ·(Δ/(Δ−1))^{Δ−1} = Δ·e·(1 − 1/(2Δ) + …)
> ```
> ⇒ **`eΔ` 就是 KP 最优常数的首项**（`Δ=20` 差 2.575%）。**"KP 的常数是 `e`"只在 T1 档成立，而 T1 比最优差 2.72×。**

### 1.3 与用户引的 1D 硬棒 `1/(eℓ)` 对表

`[T]`（自算 `[E]`）：`Ξ_L=Ξ_{L−1}+zΞ_{L−ℓ}` 的分支点给**精确**半径 `|z_c|=(ℓ−1)^{ℓ−1}/ℓ^ℓ ~ 1/(eℓ)`；而 KP 的 per-site 判据 `ℓ z e^{αℓ} ≤ α` 在 `α=1/ℓ` 取极大只给 `z ≤ 1/(eℓ²)`（`RS8 §2.2`，本轮复算比值 `e, 3.62, 4.59, …, 8.54`，`ℓ=2,3,4,…,8`）。

⇒ **用户引的 `1/(eℓ)` 是精确半径（渐近），不是 KP 的常数**；KP 自己的阈值是 `1/(eℓ²)`，比它小 `ℓ/e` 倍——**这个 `ℓ` 就是聚合物尺寸 `|γ|`，与 4D 的 `Δ` 同槽**。**这条对表正是本文件的分水岭：把"精确半径"当成"KP 常数"会差一个尺寸因子。**

## 2 · `Δ = 20` 是什么（第三问的一半）

`[T]`+`[E]`：

```
d=4:  每片 plaquette 有 4 条 link；每 link 界 2(d−1)=6 片
⇒ 邻片数 Δ = 4·(2(d−1)−1) = 4·5 = 20
      d=2: 4·(2−1)=4   d=3: 4·(2·2−1)=12   d=4: 20
```

**不是语料自造**，两条独立核：
1. **几何**：`d=2` 给 `Δ=4`，与 `C03-BYPASS:158` 的 `Δ_2D=4(2−1)=4` 逐字一致；`d=4` 给 `20`，与 `P3-FULLREP-KP:116` 一致。
2. **精确计数**：4D plaquette 图过定点的连通集合 `a_n = 1, 20, 458, 11132, 280175`（`n=1..5`，`C03-BYPASS:111`；`C05-AUDITCBAR:76`）。**`a_2/a_1 = 20` 精确等于 `Δ`**（整数相等，不是界）。后续比 `20, 22.9, 24.3, 25.2` 上升 ⇒ 真实增长常数 `λ_∞ ≳ 25`，`eΔ=54.37` 是**合法包络且近优**（`r_n^{1/n}/eΔ → 1` 单调升，`C03 §2` 与 `F07 §1` 两处独立实测一致）。

**并且 `eΔ ≠ e^{Δ}`**：`e·20 = 54.3656365691809`（4 位内逐位合 `C07:102`、`G06:39`、`M02:91`）；`e^{20} = 4.8517×10⁸`。若误读成幂，所有语料数字会差 `10⁷`。⇒ **`Δ=20` 不是"指数 20"**。

## 3 · `C̄` 在 KP 框架里对应什么、正确归一化是什么（第三/四问）

### 3.1 槽位（四个乘子各是什么）

`K = Ĉ · C̄ · eΔ` 三个槽在 KP 里的身份（`[T]` 记账，不涉及物理）：

| 槽 | 语料值 | KP 里的身份 | 归一化判 |
|---|---|---|---|
| `eΔ` | 54.3656 | **动物/位置计数**：过定点树 `≤(eΔ)^n`（Cayley `e` × 度 `Δ`） | **对**，且这是 §1.2 的 T3 常数（差 2.6%） |
| `Ĉ` | 4（`2^{E₂/F}`） | **逐 γ 的重耦合率**（`sup_γ(∏_ℓ R(ℓ))^{1/|γ|}`） | **对**（`C06 §2.3`：`2` 是每因子化点、`4` 是每 `γ`；`E₂/F=2` 取到） |
| `C̄` | 争：`1`/`N`/`e`/`20` | **树/形状残差**：`e^{a}` 在最优 `a` 处**已经是 `eΔ` 的一部分**，`C̄` 只装"`eΔ` 与精确常数之差" | **KP 定死：`C̄ = (Δ/(Δ−1))^{Δ−1}/e = 0.974893`** |
| （权重比） | `c_f/u = N = 2` | `\|w(γ)\| ≤ (K_w u)^{\|γ\|}` 的 `K_w` | **不是 `C̄`**：它在 `\|w\|` 里，须显式记（`M07` 把它塞进 `C̄`，是**槽错位**） |

### 3.2 闭式与数值

```
由 §1.2 T3：判据 ⇔ u·K_w·λ ≤ (Δ−1)^{Δ−1}/Δ^Δ ,     λ := eΔ
⇒ 以语料写法 u·Ĉ·C̄·eΔ < 1 表示，必须
      Ĉ·C̄ = Ĉ · λ / [(Δ−1)^{Δ−1}/Δ^Δ]^{-1} = Ĉ · x*·λ
即    C̄_KP = x*·eΔ = [(Δ−1)^{Δ−1}/Δ^Δ] · eΔ = (Δ/(Δ−1))^{Δ−1}/e        [T]
```
`Δ=20`：`x* = 19^19/20^20 = 0.0188676801268`、`1/x* = 53.0006865328`、`eΔ = 54.3656365692`
⇒ **`C̄_KP = 0.9748929…`**（`[E]`，三位一致：`53.0006865/54.3656366 = 0.974893`，与 `(20/19)^{19}/e` 同值到 `1e-6`）。

`N`-依赖：**无**（`Δ` 是纯格点度）。`a`-依赖：**无**（`Δ`、`eΔ`、`C̄` 都是组合数）——这也顺带满足 `F05:112` 要的"`ē` 精确 `a`-无关"。

## 4 · 判死线

### (a) KP 给出 `C̄` 的具体值/形式 ⇒ **触发，给那个**
`C̄ = (Δ/(Δ−1))^{Δ−1}/e = 0.974893…`（`Δ=20`），**闭式、无自由参数、`N`-无关、`a`-无关**。等价说法：**KP 的精确常数就是 `Δ^Δ/(Δ−1)^{Δ−1} = 53.0007`，`eΔ=54.37` 只是它的 `Δ→∞` 首项**。
⇒ `Ĉ·C̄ = 3.8996 < 7.0633` ⇒ **`1/48` 保住，余量 1.81×**。**"8×"不在 `C̄` 里**：`[1,20]` 是**树常数被当动物数再付一遍**（`C01 §4`、`C05 §1.3`、`F07 §2` 三处独立判过），而 `ĈC̄=8` 那一路把**权重比 `N`**（`c_f/u ≡ N`，`[T]` 恒等）记进了 `C̄` 槽——KP 的 `|w|` 里才该有它。

### (b) 与 `ĈC̄eΔ` 是否可比 ⇒ **部分触发（必须指出）**
- **可比的部分**：`eΔ` **就是** KP 的最优常数（T3），所以"`eΔ` 是语料自造"是**假的**；`Δ=20` 也是真的格点度。
- **不可比的部分**：`eΔ` 里那个 `e` 是 **Cayley/Stirling** 的 `e`（`(n^{n−2}/n!)^{1/n}→e`，`[T]`；`n=1000` 时 `2.66929`，与 `C01:88` 逐位一致），而 KP 判据里的 `e` 是 **`e^{a(γ)}` 的底**。两者**同为超越数 `e`，但槽不同**：前者是"每步熵"，后者是"分级权"。把二者当同一个数会得到 `α=1`（T1），代价 2.72×。
- ⇒ **`Δ=20` 不是语料自造；"`Δ=20` 是语料的指数"才是自造**。

### (c) KP 是否需要我们没有的 `|w|` 归一 ⇒ **不触发**
`|w|^{1/|γ|}/u = c_f/u ≡ N`（`M07 §4` 恒等 + `F07 §1.4` 精确 cube 两路），语料有。**但 KP 不决定它记在 `Ĉ` 还是 `C̄`**：这一格是**记账约定**，`[C]`，不产生 8×，只产生 2×（`ĈC̄=4` vs `8`）——而按 `C06 §2.3`（`Ĉ=4` 是逐 `γ` 重耦合）+ `M07`（权重比 `N`）**两者都得付**，故取 `Ĉ·C̄·K_w = 4·0.974893·2 = 7.79914`，窗 `β₁ = 8/(7.79914×54.3656) = 1.8868×10⁻² = 0.9056×(1/48)`（`[E]`）。**这一路的 2× 是唯一活着的 2×，且它与 `C̄` 无关。**

## 6 · 限定（`AGENTS §2.1`）

- 全部数值：`d=4`、`Δ=20`、`a=1`、`N=2`、`u=β/(2N²)`（语料 `species` 归一，非 `P3` 的 `u=c_f`）。换 `P3` 归一（`u=c_f=β/2N`）时 `β₁` 差一个 `2N`——这是**符号归一**问题，与本文件的 `C̄` 无关（`CB1:70–80` 已列四行）。
- **T3 的合法性**：`R ≤ x(1+R)^Δ` 是**树图（Penrose）计数**，要求"每聚合物取一棵生成树、每顶点 `Δ` 个槽"——这对格点聚合物成立；**`eΔ` 的 T1 档（`(eΔ)^n`）是同一件事的更粗包络**。T3 与 T1 的比 `(Δ/(Δ−1))^{Δ−1} → e` 是纯代数，不含模型假设 `[T]`。
- **`C̄` 是"树槽"**这一点沿用 `A01:13`/`X01:71` 的定义（`|φ^U(Γ)|≤C̄^{|Γ|}u^{|Γ|}`）。若改用 `M07` 的"权重比"读法，则 `C̄=N=2` 且 §3.2 的结论不适用——**两个口径分列，不混**（这正是本文件要指出的槽错位）。
- **未做**：`SU(3)` 的 `c_f/u`、`β=2.5` 处（窗外，`uK≫1`）、`Ĉ` 是否应并入 `C̄`（`C06 §5` 判"可行但收益 0.9%"）、KP 原文原页逐字。
- **不作断言**：本文**不**声称 `1/48` 能延到 `β=2.5`（差 ~136×，`H2:145`），**不**声称真半径 = KP 阈值。
