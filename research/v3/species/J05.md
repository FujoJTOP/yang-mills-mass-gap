**口径声明 `[M]`**：本文件一律用**能量轴**，故 `m ≤ m₁` 字面成立。若改用 `s=E²` 轴（`ATOM2:27` 的 `m₁²`），下文每条命题按两边同时平方读，判词不变。**单点提醒**：`J01:198` 已记 `m₁` 是质量、`m₁²` 是能级；本文件不引入第三种口径。

### 1.2 步 0（免费半）`[T]`

`(O−⟨O⟩)Ω ∈ Ω⊥` ⇒ `ν_O(B) = ‖P_H(B)(O−⟨O⟩)Ω‖²` ⇒ `supp ν_O ⊆ spec(H|_{Ω⊥})` ⇒ `m ≤ m₁`。∎（`B10:79–83`）

### 1.3 步 1：`m < m₁` ⇒ 存在 `O`-盲态 `[T]`（本骨架的第一个真定理）

> **引理 J05-1 `[T]`.** 设 `m < m₁`。则存在 `ψ ∈ Ω⊥`，`ψ ≠ 0`，`E_ψ < m₁`，使
> ```
> ∀x ∈ ℝ⁴ :  ⟨ψ | O(x) Ω⟩ = 0 。
> ```
> 更强：令 `K := {ψ ∈ H : ψ ⊥ clspan{O(x)Ω : x∈ℝ⁴}}`（**O-盲子空间**），则
> ```
> K 闭、平移不变、Ω ∈ K，且  K ⊇ P_{[0,m₁)}(H) 。
> ```
> *证明.* 取 `ε ∈ (0, m₁−m)`，`P := P_{[m,m+ε)}(H) ≠ 0`（`m = inf spec` ⇒ 谱在 `[m,m+ε)` 非空）。任取 `ψ ∈ P H`，`ψ≠0`（必要时投影掉 `Ω`）。对任意 `x`：`O(x)Ω = ⟨O⟩Ω + (O−⟨O⟩)(x)Ω`，而 `(O−⟨O⟩)(x)Ω` 的谱支撑 `⊆ [m₁,∞)`（`m₁ = inf supp ν_O` 的定义 + 平移不变性）⇒ `P(O−⟨O⟩)(x)Ω = 0`（`P` 只到 `E<m₁`）；又 `PΩ = 0`。故 `⟨ψ|O(x)Ω⟩ = 0`。闭性/平移不变性由 `clspan` 与 `U(a)` 的对易直接读出；`Ω ∈ K` 因 `⟨Ω|O(x)Ω⟩ = ⟨O⟩` 与 `x` 无关。∎

**读法**：步 1 把"假设 `m < m₁`"翻译成一个**结构对象** `K`（不是不等式、不是估值），且 `K` 里明确装着 `P_{[0,m₁)}H`。这条不需要任何 YM 结构，纯谱定理 —— 它是本骨架**唯一**能免费拿到的定理。

### 1.4 步 2：要杀的东西，以及它**就是结论**（`[T]`）

> **引理 J05-2 `[T]`（骨架的精确闭合条件）.** 记 `K₀ := K ∩ Ω⊥`。则
> ```
> m₁ = m   ⟺   K₀ ∩ P_{[0,m₁)}(H) = {0} 。
> ```
> *证明.*（⇐）若 `m < m₁`，引理 J05-1 给出 `0 ≠ ψ ∈ K₀ ∩ P_{[0,m₁)}H`，矛盾 ⇒ `m ≥ m₁`；合 §1.2 得等号。（⇒）若 `m₁ = m`，则 `P_{[0,m₁)}H = P_{[0,m)}H = ℂΩ`，而 `K₀ ∩ ℂΩ = {0}`。∎

**这条是本节的主结果，也是本文件对 lead 最重要的技术判断**：

```
② 不能靠"把步 2 换成某个更弱、更可及的东西"来攻 —— 步 2 与 ② 是 [T]-等价，
   不是"充分条件"、不是"某个更强的充分版"，是逐字同一个命题（一个说数值相等，
   一个说子空间不相交）。
⇒ 骨架的价值不在"减弱"，在**换坐标**：② 从"两个数相等"变成
   "一个平移不变的闭子空间 K 不得进入能量窗 [0,m₁)"。
   这是一条**表示论/轨道**陈述（关于 {O(x)Ω} 的张成），不是估值陈述。
⇒ 于是所有"估计类"工具（KL、I2、RP、Sobolev、矩、Hankel…）全部**作用域不含**步 2：
