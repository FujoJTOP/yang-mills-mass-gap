## §A1 SU(3) `HessΦ|_0` —— 论文的 `N/12` 正确，`0.125` 是脚本 bug

### A1.1 独立重算（四种互不依赖的算法）

对象：平直图 `U = exp(X)`，`Φ(X) = −log J(X)`，`J = det((1−e^{−ad X})/ad X) = ∏_{α>0}(sin(α(X)/2)/(α(X)/2))²`。

1. **有限差分 Hessian**：`X₀=0`，`h=1e−3`，Killing 正交基（`−tr b_a b_b = δ_ab`）；
2. **Rayleigh 商** `2Φ(tv)/t²`：随机单位 `v` 与纯 Cartan `v`（各向同性检验）；
3. **Cartan 闭式** `Φ(i·diag x) = Σ_{k<l} g(x_k−x_l)`，`g(t)=−2log(sin(t/2)/(t/2))`，`g″(0)=1/6`
   （与谱公式核对：SU(2)/3/4 全部吻合到 **1e−10**，见 `audit_a1.log` 第 (3) 行）；
4. **根坐标**：`X = t·H_α`、`α(X)=t`（基本余根）⇒ `d²Φ/dt²`。

| N | dim | FD Hess 特征值 | **`c_N`（K 图）** | **`c_N`（P 图）** | 根坐标 `Φ″` | 论文 |
|---|---|---|---|---|---|---|
| 2 | 3 | `{0.333333 ×3}` spread `0.0` | **1/3 = N/6** | **1/6** | **1/6** | 1/6 ✓ |
| 3 | 8 | `{0.500000 ×8}` spread `5.7e−10` | **1/2 = N/6** | **1/4** | **1/4** | 1/4 ✓ |
| 4 | 15 | `{0.666667 ×15}` spread `4.3e−9` | **2/3 = N/6** | **1/3** | **1/3** | — |

**结论 1（Ad-不变 ⇒ 标量）**：是。`Φ(gXg⁻¹)=Φ(X)` ⇒ `Hess` 与 `Ad` 交换 ⇒ `su(N)` 伴随表示不可约
⇒ `Hess = c_N·I`。三种算法一致，spread ≤ `4.3e−9`（有限差分精度）。

**结论 2（常数，三种归一互相一致）**：

```
HessΦ|_0 = (N/6)·(−tr)         [K 图：−tr b_a b_b = δ_ab；数值 0.333/0.500/0.667]
         = (N/12)·δ_ab         [P 图：U = exp(iξ^aT^a)，tr T^aT^b = δ^{ab}/2；数值 1/6,1/4,1/3]
         = −(1/12)·B           [归一无关；B(X,Y)=2N·tr(XY) 在基本表示]
沿根坐标 t = α(X)：d²Φ/dt²|₀ = N/12  （对所有 N；数值与 P 图同列）
```

一行推导：`g(t) ≈ t²/12` ⇒ `Φ ≈ (1/12)Σ_{α>0}α(X)²`；Cartan 上 `Σ_{k<l}(x_k−x_l)² = N|x|²`
（`|X|²_{−tr} = Σx²`）⇒ `Φ ≈ (N/12)|X|²_{−tr}` ⇒ Hess `= (N/6)Id`；P 图 `|X|²_{−tr} = |ξ|²/2`
⇒ `(N/12)δ`。**`N/12` 在两个自然归一上都对**（不是巧合：P 图单位向量恰与"根坐标单位步"同标度）。

## §B2 PS 的 `e^{cV}` —— **过度外推确认；更正后 no-go 被加强**

### B2.1 数学核（不依赖原脚本）

`T = T₀ + E`，`‖E‖ = ε₁`，两算子都已归一（`‖T‖ = ‖T₀‖ = 1`）：

```
‖T^{⊗V} − T₀^{⊗V}‖ ≤ Σ_{k=1..V}‖T‖^{V−k}‖T₀‖^{k−1}‖E‖ = V ε₁      (三角不等式：恒真，但只是一阶)
‖T^{⊗V} − T₀^{⊗V}‖ ≤ ‖T‖^V + ‖T₀‖^V = 2                            (硬上界)
```

`Vε₁` 是**一阶展开**（`= Vε₁ + O(ε₁²)` 仅当 `Vε₁ ≪ 1`）；一旦 `Vε₁ > 2`，它**超过真值硬上界**，
成为**空上界**。`ps_witness.py` 的 `V = 65536` 给 `Vε₁ = 51583`，比 2 大 **25791 倍**——该行无信息。

Rouché/伪谱谱包含需要 `‖E‖ < dist(围道, σ(T₀^{⊗V}))`。本题 `dist = 0.001944`（`= ½(1−e^{−a_T·gap₁})`，

**所以**：
1. `[E]` 表 `V ≥ 3` 的行（含 8/16/256/65536）**全部过度外推**，须删或标"空上界"；唯一决定性的行是 `V=1`。

## §B3 SW 的 `(logρ)″` —— **确认，但两句话必须分开写**

`ρ_β(x) ∝ e^{−βx}√(x(2−x))`，`x ∈ (0,2)`（SU(2) 单 plaquette 精确边缘）。`logρ = −βx + ½log x + ½log(2−x) + c`：

```
(logρ)″(x) = −1/(2x²) − 1/(2(2−x)²)      ← β 项对 x 线性 ⇒ 二阶导 0 ⇒ β 不出现 ✔
x = 1 ⇒ −1 ✔（日志 logrho2_at_1 = −1.0）；整段 (0,2) 两项皆负 ⇒ (logρ)″ < 0 ✔
模态： (1−x)/(x(2−x)) = β ⇒ x*(β) = [(2β+1)−√(4β²+1)]/(2β)
```

（`audit_b3.log`）

| β | 0 | 0.5 | 1.0 | 2.5 | 4.0 |
|---|---|---|---|---|---|
| `x*(β)` | 1.0000 | 0.5858 | 0.3820 | 0.1802 | 0.1172 |
| `(logρ)″(x*)` | **−1.0000** | −1.7071 | −3.6180 | −15.5495 | **−36.5311** |
| `ρ″(x*) = ρ·(logρ)″` | −0.6366 | −1.1795 | −2.9721 | −21.8599 | −76.4881 |

**FD 交叉核对**（`h=1e−4`）：固定 `x=0.2/1.0/1.8`，β=0/2.5/4 的 `(logρ)″` 三者差 `≤ 2.7e−7` ⇒ **与 β 无关**。

**两句话，分开写（都要写对）**：
- **固定 `x`**：`(logρ)″(x)` 是 `−1/(2x²)−1/(2(2−x)²)`，**与 β 无关**——因为 `−βx` 对 x 线性。这是恒等式，
  也就是"β 只进前因子"的精确含义。
- **模态处**：`(logρ)″(x*(β))` **随 β 变**（−1 → −36.5）——不是 β 的显式依赖，而是**求值点随 β 移动**
  （复合函数）。`ρ″(x*) = ρ(x*)(logρ)″(x*)`，`ρ>0`、`ρ′(x*)=0` ⇒ **符号恒负**，而**值**随 β 变。

**另**：`ρ″(x) < 0` **并非**在整个 `(0,2)`（大 β 时中部为正：`ρ″ = ρ[(logρ)″+((logρ)′)²]`，
