[C1/T] THE CONTROL: the criterion certifies the gap ONLY if the ground energy is 0
------------------------------------------------------------------------------------------------------------
    Let H_c = H + c*1.  Its spectrum is {c + lambda_j}.  The criterion reads
        (lambda_j + c)^2 - delta (lambda_j + c) >= 0  for all j
    i.e.  x(x - delta) >= 0 for every x in spec(H_c), x >= 0, whose solution is
        delta_max = min{ x in spec(H_c) : x > 0 }  =  c   (for 0 < c < Delta),
    while the GAP of H_c is Delta, independent of c.  So a nonzero (or merely
    approximately known) ground energy replaces 'the gap' by 'the shift error'.
