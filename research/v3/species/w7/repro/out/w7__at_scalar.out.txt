SHARP FORM OF T2 (answers 'is lam_t free to grow?')
============================================================================================
  Write m(t) = mu - q(t) with q >= 0 integrable (q = the negative part, decaying).
  Then M(t) = mu t - Q(t),  Q(t) = int_0^t q <= Q(inf) < inf, and
      I = int_0^inf e^{-2 mu t + 2 Q(t)} dt.
    * mu > 0 : M(t) -> +oo linearly, I = e^{2Q(inf)}/(2 mu) < inf  =>  FEASIBLE,
               gamma_max = 2 mu e^{-2 Q(inf)}, optimal lam_t = mu t - Q(t).
    * mu = 0 : M(t) = -Q(t) <= 0 bounded above  =>  lam_t bounded above  =>  lam_t -/-> +oo.
    * mu < 0 : M(t) -> -oo  =>  lam_t -> -oo.
  ALSO: if q is NOT integrable but mu=0, a 1/t-type ceiling still works: m = delta/t - q,
  M ~ delta log t, I ~ int t^{-2 delta} converges iff delta > 1/2  (table row 4 vs 3).
  => ANSWER: lam_t is NOT free to grow.  The ceiling is what it is; the criterion is
     satisfiable iff the ceiling has a NON-INTEGRABLE PART: either a positive constant
     floor mu > 0, or a delta/t with delta > 1/2.  In our problem the ONLY candidate for
     mu is (1/2)Ric_g = N/8 (manifold form) -- the literal form has mu = 0 identically.
