## §2 β=2.5 在 Lt=18 的相

### §2.1 裁决 `[T]`：禁闭

1. `β = 2.5 < β_c(8) = 2.5115(40)`：**实测**锚（非外推）⇒ `Lt=8` 已在禁闭侧。
2. 固定 β 时 `a` 固定、`T = 1/(Lt·a)` ⇒ `Lt↑ ⇒ T↓`（算术）；相界在 `Lt` 向单调，两个测定锚给同一方向：`β_c(8) = 2.5115 < β_c(16) = 2.7395`。
3. ⇒ `Lt=18` 比 `Lt=8` 更冷。换算：`Nτ_c(2.5) = 4·exp((2.5−2.2986)/0.314) = 7.60`，`T/T_c = 7.60/Lt`。

## §3 靶点该在哪

- **β 不换。** 靶是零温（`Lt→∞`）、`β=2.5`；`Lt=18` 上的相界是 `2.78`，余量 `0.28`。**升 β 是朝相界走**（`β→2.78` 在 `Lt=18` 正是 `T_c`），不能当"修 Lt"的手段。`[T]`
- **要换的是 `Lt`（和 `L`）。** 由 `a(2.5115) = 1/(8T_c)`、`T_c = 0.694√σ`（Teper Table 3）、`√σ = 0.45 GeV` 得 `a(2.5) ≈ 0.082 fm` ⇒ 现盒 `(0.98 fm)³ × 1.48 fm`、`T = 134 MeV`、`m₀/T = 12.6`。故：**质量道可当零温**（`e^{−m/T} = 3e−6`），**任何用 Polyakov 圈 / 中心对称 / 有限温度谱的断言不可当零温**。`[T]`（缩放 + 算术）
- **两条自洽路线**：A) 守 `β=2.5` 加 `Lt`：`Lt=48` 给 `T/T_c = 0.16`、`Lt/L = 4`（成本 ~2.7× 现有 12³×18）；B) 守 `Lt=18`：则"零温"这句收回，读数降级为 `0.42T_c` 盒的有限温度读数。**不走 C（升 β）**。`[T]`（A、C）/ **`[NG]`**（B 的成本效益）

下一手：下一轮只在 `β=2.5` 上加 `Lt`（`12³×48` 一档）；本轮先把 `T/T_c` 列进台账、把 `Lt=18` 的 `2⁺⁺` 判据撤下。
