## 2 · 第 2 步：`log D` 的界怎么接上 `η` 的界 —— **链的弱点**

### 2.1 精确代数（`[T]`，初等）

`P3-DRESSED-MASS` 式 (1.2)（`:50`，逐字）：`C_L(t) = a₀u^{4T}Z_dec(B_T) + R^{hi}_L(t)`，`T=t/a`。
式 (3.1)（`:86`，逐字）：`a₀u^{4T}Z_dec(B_T) = a₀u^{4T}e^{f_dec t}D_{fin}(T) = A^{dressed}e^{−m₁^{dressed}t}D_{fin}(T)`，`A^{dressed}=a₀`。

```
C_L(t) = f₁² e^{−m₁^{dr}t} · [ D_fin(T)/D_∞ ] + R^{hi}_L(t),      f₁² := a₀ D_∞
⇒ η(t) := C_L(t)/(f₁² e^{−m₁^{dr}t}) − 1
        = ( D_fin(T)/D_∞ − 1 ) + ( R^{hi}_L(t)/f₁² ) e^{m₁^{dr}t}.

**⇒ 接得上，且是强制上的**：`log` 界 ↔ `η` 界只差一次 `exp`，**唯一需要的额外事实是 `D_∞` 有正下界**。该事实是 `[T]`：`P3 §4.1`（`:116`）逐字 `|\log D_fin(T)| ≤ C_1u + O(1)·u = C u, C=C(β,N)<∞, uniformly in T,L, hence D_fin(T)=e^{O(u)}=1+O(u)` ⇒ `D_∞∈[1−Cu,1+Cu]`，`u<1/(2C)` 时 `D_∞≥½`。**转换常数 `B'=O(B/D_∞)=O(B)`，与 `t,L` 无关。** `[T]`
