## §2 第二问：有没有"自动正"的道？——有三层，全都不承重

### 2.0 先记一条方向：任何一道的 `Δ_c` 都是 `m²` 的**上界**

```
Δ_c ≥ inf spec(H|_{Ω⊥}) = m²   （H_c ⊆ H，谱定理）⇒ m ≤ √Δ_c = m_c   ∀c     [T]
⇒ 一颗"自动正"的钉子钉在**高的那道**上，只给 m 的**上界** ⇒ 对 m>0 零信息
⇒ 唯一承重的是【可能最小的那道】的地板，且必须先知道它是最小的（成员性）
```
（这就是 `H06.md:60,65` 的方向定理在"道坐标"里的同一句话。）

### 2.1 第 (i) 层：点态平凡（**这才是"自动正"的真相**）

固定有限 `(L,a)`：transfer 矩阵 `T` 有限维、正性改善（规范不变 PF，`[T]`）⇒ 真空唯一 ⇒ `H|_{Ω⊥}` 的最小本征值 `> 0`。⇒ **每一条道都自动正，点态、无需任何动力学。**
**正因如此它零内容**：Clay 要的是 `inf_{V→∞, a→0}` 的正性；而 PF/Dobrushin 常数按 `e^{-cV}` 退化，有限体积隙只是 `Δ_{ℝ⁴}` 的**上界**（`ch05-theorems.tex:271–275` 逐字）。⇒ **"某道自动正"与"有隙"不在同一层。**

### 2.2 第 (ii) 层：窗内 `OS'78` 全道簇聚（真 `[T]`，零增量）

`β<β₀`：`OS'78`/SZZ 道**盲**簇聚给出**每道**最轻质量的**下界**（`Y02-CHANNELS.md:60` 逐字；`M3D:109` 逐字"窗内 `m>0` 由 OS'78 道盲簇聚给"）`[T]`。
**但**：(α) 窗 `β<β₀≈0.018394`，比目标 `β≈2.5` 低两个数量级（`M3D:100–105`）；(β) 窗内地板 `δ=δ(β)`，对 `a→0` **无信息**（`M3D:117–119`）；(γ) `(★-gap)` 的路线 A **就是**这条 OS'78 ⇒ **窗内零独立内容**（`M3D:111–116` 的二难）。

### 2.3 第 (iii) 层：窗内"重尾道自动在 `δ` 之上"（`[T]`，但钉错了位置）

```
m_c − m_{0⁺⁺} ≥ (a_c−1)·ln(1/u) + O(1) → +∞    (c ∉ {0⁺⁺,2⁺⁺})       [T]
```
（`PROOF-IN11.md:13`；`a_c` = 每单位时间最小 plaquette 数，`:9,11`。`0⁻⁺` 需两场强的 `ε`-收缩、C-奇需 ≥3 胶子、`J≥3` 需横向宽度 ⇒ `a_c≥2`。）

**这是"某道自动正"的最强形态，也是最没用的形态**：它保证的正是**非最小**的那些道（§2.0：只给上界）。它唯一的正当用途是反过来当**成员性 `(b′)`**：把"`δ` 以下没有别的道"推到无穷远——**它不含地板**，地板仍得由 `{0⁺⁺,2⁺⁺}` 两道各付一份（`W95C-ORDER.md:85,94`；`A2-IN11.md:101`）。

### 2.4 第 (iv) 层：窗外的真答案 = 0 条

`β≈2.5` / 连续统：`Y02-CHANNELS.md:60` 逐字"**不过 β≈2.5**"；`PROOF-IN11.md:27` 逐字"No rigorous continuation exists"。
逐道清点（`Y02:52–55`）：`0⁺⁺` 有残数（I1）+ `I2` 开的精确步；`2⁺⁺` **无 `f₁²`、无 `I2`、无定理**；`0⁻⁺` **只有上界**（`m²≤χ_t/f₁²`）；`1⁻⁻` **无**。⇒ **窗外没有任何一条道带 `[T]` 正性证书。**

### 2.5 一条"免费"的结构性正性——空道（并说明它无用）

若某道无态（如 2D 的 `ν_{¼trF²}≡0`），则 `Δ_c = +∞`：**自动正、且严格**。但 `+∞` 永不进 `min` ⇒ 对 `m>0` **零价值**（`ATOM2.md:43`；`J01.md:132` 的 `+∞ ≠ m` 同一件事）。

**⇒ 第二问答**：**有**（第 (i) 层每道、第 (ii)(iii) 层窗内），**但"自动正"在结构上不可能承重**：它要么平凡（点态）、要么在窗外不存在、要么钉在非最小道上（只给上界）。**没有一条"自动正且可能最小"的道。**

## §5 判死线（(a)/(b)/(c) 逐条）

### (a) 若"某道自动正 + 其它道由同一工具"⇒ 逐字给：**只在窗内兑现，窗外不兑现**

### (b) `m₁ > 0` 确实不够、别的道**更难** ⇒ **主判**

- `m₁ > 0` ⇒ 只 `m ≤ m₁`（§2.0、§3.3）。

- **而且越"自动正"的道越没用**（§2.0/§2.3）：自动正的是重尾，重尾只给上界。

### (c) `m = inf_c m_c` 本身不清楚 ⇒ **不触发**（四条读法钉住即 `[T]`），但两处**形式病**必须记
