## §0 判词（八条）

> ### ① **题面的 `R_t = sup{λ : λ∈σ(T_L)}` 逐字为假**；正确读法是**倒数**。`[M]`
> `B01-RP.md:26`（R1）给 `T = e^{−aH}`、`0 ≤ T ≤ 1`、`H ≥ 0`；`B01-RP.md:29`（R4）给 `λ₁ = 1` **单重**。故
> ```
> sup σ(T_L) = 1        （本征矢 = Ω，∀(L,a,β)）
> ```
> ⇒ 逐字读 `R_t > 1` 是**假命题**（对每个 `(L,a,β)`）。等式 `R_t = e^{am₁}` 里的 `R_t` **不是** `T_L` 的谱半径，而是
> ```
> R_t := e^{a·Δ_a(L)} = 1/λ₂(T_L) = 1/‖T_L|_{Ω⊥}‖ = ρ((T_L|_{Ω⊥})^{−1}) > 1 .
> ```
> （`Δ_a = inf{λ∈σ(H_a):λ>0} = −(1/a)log λ₂(T_a)`，`GN3-SPECTRAL.md:87–88`、`GI2-FREDHOLM.md:27,198`；`R_t = e^{am₁}` 见 `GF1-RADIUS.md:24,94`。）
> ⇒ 这是**口径级**勘误（与 `GF1-RADIUS.md:25,97` 记的 `log(1/R)` 符号错同类），但它决定后面一切：靶的对象是 **`sup` 的倒数**，即 `inf` 型量。

> ### ② **`R_t > 1`（正确读法）可以结构性证，且不需要任何常数估计。** `[T]`
> PF：`T_L` 紧、正核 ⇒ `λ₁` 单重、本征矢逐点正、`|λ_j| < λ₁`（`GAP3.md:70` 引 `D02-DIRECT.md:60`；`B01-RP.md:29`）。紧配置空间（`G^{links}` 紧）⇒ 谱离散 ⇒ `λ₂ < 1` **严格** ⇒ `R_t > 1`。**全程零估计**：只用了严格不等号，没有出现任何数。这与 `D02` 的自判逐字一致："PF 给的是**符号/结构性（严格不等号），不是数**"（`GAP3.md:71` 引 `D02:62`；`D01-OMEGA.md:1` 逐字"PF 只给符号，`Ω` 是大小"，经 `GAP3.md:72`）。

> ### ③ **但 `R_t > 1` 是"类恒真式"：它对一切有限体积紧群格点规范理论都成立，与有没有物理质量隙无关。**
> 命题 S（§1.4）：`∀` 紧群 `G`、`β>0`、`L<∞`：`λ₂(T_L) < 1` ⇒ `R_t > 1`。**见证：4D 自由 `U(1)` 规范场** —— 光子无质量、`m = 0`（`B04-INDEX.md:121` 逐字"自由 `U(1)` 规范场（`m=0`，光子无质量）"；`LOOP-RUNBOOK.md:21644` 记 Guth 1980 的 4D `U(1)` 退禁闭 Coulomb 相），而它是紧群（`U(1)`）、紧配置空间 ⇒ `Δ_a(L) > 0` 逐 `L` ⇒ `R_t > 1` 逐 `L`。
> ⇒ **S 在"无隙"模型上取真**。按 `CLAUDE.md §1` 的酸测规矩，这就是**假阳性**，与 `B01-RP.md:49` 对 RP 的判词（"`m ≥ 0` 在自由场取等、在 2D 也取等 ⇒ 不是判据，是恒真式"）**同型**。

> ### ④ 靶在 `R_t` 坐标里 = **`Δ₀ = 0` 的截断**。`[T]`+`[M]`
> ```
> m_L/Λ ≥ Δ₀  ⟺  log R_t ≥ (aΛ)·Δ₀  ⟺  R_t − 1 ≥ (aΛ)Δ₀ + O((aΛΔ₀)²) .
> ```
> 因 `aΛ → 0`（渐近自由，`[C]`，`GK5-CONTINUUM.md:252` 记 `a→0 ⟺ β→∞` 是 `[C]` 输入），右端**趋零**。⇒ `R_t > 1` 是 `Δ₀=0` 那一项；靶是"`R_t−1` 在 `a=0` 边界上的**一阶系数** ≥ Δ₀"。**结构性论证给函数值的符号，不给边界点上的导数。**

> ### ⑤ 候选 **(a) PF 是三条里唯一零估计的一条**；但"具体态/投影"那条子路 **方向反**。`[T]`
> `‖T_L|_{Ω⊥}‖ ≥ |⟨φ|T_L|ψ⟩|`：单态/投影只能给范数的**下**界 ⇒ 只能给 `Δ_a` 的**上**界（min–max：`Δ_a = min_{φ⊥Ω}⟨φ|H|φ⟩/‖φ‖²`）。真空投影给 `⟨Ω|T|Ω⟩ = 1`，与任何 `λ₂` 相容。⇒ **具体态永远认证不了 `‖T_L|_{Ω⊥}‖ < 1`**。仓内同判："仓内所有可用不等式给 `m` 的**上界**"（`GM1-KATO.md:22`；`H08-Z1.md:119`）。

> ### ⑥ 候选 **(b) 变分要估计**，而且题面的判据**符号错**。`[T]`+`[M]`

> 两个被点名的物理输入都不够：`⟨¼trF²⟩>0` 是**一阶矩**、不是原子（`H03-ANOMALY.md:94`，且 2D 上 `⟨C₂⟩→+∞` 而 `m→0`、`f₁²≡0` 而 `m>0`，`H03:129`）；`W_geo ≥ 0`（Prékopa）是**符号型地板**，`ω ≡ 0` 即 gap、自由 Gauss 上同样为正 ⇒ 不判别（`BN-RESIDUAL.md:102`），且 `k→0` 归一化 `‖v‖²=1/L` 下地板 `(N/12)/L → 0`（`H1-FINAL.md:61`；`GX1-SHELLS.md:94,122`）。

> ### ⑦ 候选 **(c) 单调性不存在，且已知三条全部指反方向**。`[NG]`
> - `β`-方向：唯一 `[T]` 级 `β`-单调量是**矩**（Griffiths `∂_β⟨O⟩=Var≥0`），不是质量（`B04.md:85`）；`m·a` **严格减 → 0** ⇒ `inf_{β≥β₀}` 在 `β→∞` 端取到（`B04.md:17,98,153`）；`m/Λ` 是常数——那是**标度假设**，不是单调量（`B04.md:17` 逐字"`m/Λ` 是常数（不是单调量）"）。

## §1 把 `R_t > 1` 写成结构性命题

### 1.1 `R_t` 有四个候选所指，只有一个对

| 读法 | 算子 | `sup σ` | 与 `m` 的关系 | 判 |
|---|---|---|---|---|
| **A** | `T_L = e^{−aH_L}`（`B01-RP.md:26` 的 `0≤T≤1`） | **`=1`**（Ω，单重） | `sup σ(T_L)=1` 恒成立 ⇒ `R_t>1` **假** | `[M]`，题面逐字读 |
| **B** | `T_L|_{Ω⊥}` | `=λ₂<1`（PF 严格） | `R_t := 1/λ₂ = e^{aΔ_a} > 1` ✓ | **`[T]`，唯一正确读法** |
| **C** | `e^{+aH_L}`（增长算子） | `=e^{aE_max}≈e^{c}`（UV，与 `m₁` 无关） | `≠ e^{am₁}` | `[M]` |
| **D** | 活度/聚合物矩阵 | `R_act`（纯组合） | `m ≠ (1/a)log R_act`（β-刚性，`GV1-LAMBDAUR.md:63`；四条死因见 `GF1-RADIUS.md:123–167`） | `[NG]` |

**⇒ 只有 B 对**，而 B 的对象是**"sup 的倒数"**，即 `inf` 型量 —— 这一点决定了后面 PF 只能给"严格"、给不了"模数"（§2.3）。

### 1.2 精确链（全 `[T]`）

```
H_a := −(1/a)·log T_a  于 1^⊥（谱演算；log 0 := +∞）;  0 ≤ T_a ≤ 1,  T_a 1 = 1      GN3-SPECTRAL.md:87
Δ_a := inf{ λ ∈ σ(H_a) : λ > 0 }                                                  GN3-SPECTRAL.md:88
C_L(t) = ⟨Ω|O T_L^{t/a} O|Ω⟩ − ⟨Ω|O|Ω⟩² = ∫e^{−st}dν_L(s) = Σ_n f_n² e^{−aE_n t}   P3 经 GF1-RADIUS:82–83
Φ_L(z) := Σ_{t≥0} C_L(t) z^t = Σ_n f_n²/(1−e^{−aE_n}z)  ⇒ 最近极点在 z = e^{aE₁}    GF1-RADIUS.md:94
R_t(L) := e^{a·Δ_a(L)} = 1/λ₂(T_L) = ρ((T_L|_{Ω⊥})^{−1})                          GF1-RADIUS.md:24,94
⇒  R_t > 1  ⟺  Δ_a(L) > 0  ⟺  λ₂(T_L) < 1 .                                       [T]
```

**两条前提必须随身带**（`GF1-RADIUS.md:268` 逐字）：固定 `L`、`ν_L ≠ 0`（即 `f₁² > 0`）。在 `β=0`（纯 Haar）上 `T` 秩一 ⇒ `λ₂ = 0` ⇒ `R_t = ∞`，等式**退化**——这不是"物理"，是"对象消失"。

### 1.3 靶在 `R_t` 坐标里的样子（`[T]` 代数）

```
log R_t = a·m_L            （m_L = Δ_a(L)，有限体积质量）
(iii)′:  ∃Δ₀>0 ∀(L,a)  m_L/Λ ≥ Δ₀
     ⟺  ∃Δ₀>0 ∀(L,a)  log R_t ≥ (aΛ)Δ₀
     ⟺  ∃Δ₀>0 ∀(L,a)  R_t − 1 ≥ (aΛ)Δ₀ + O((aΛ)²)
```

三个后果，逐条写死：

1. **`R_t > 1` 是靶在 `Δ₀=0` 的截断**。靶问的是 `R_t − 1` 的**一阶系数**，`S` 问的是**符号**。
2. **"绕过 `a→0`"只在表达层成立**：等式 `m=(1/a)log R_t` 确实不需要连续极限（固定 `L` 的紧 `T_L`，`GF1-RADIUS.md:181`），但它给的是 `m_L`，不是 `m`；靶的一致性整个坐在 `(aΛ)→0` 这一侧。
3. **`m/Λ` 是 `0/0` 型**：`m_L/Λ = (a·m_L)/(aΛ)`，分子 `a·m_L → 0`、分母 `aΛ → 0`。所以"分子单独的界"或"分母单独的界"**都不够**——必须给**比值**的模数。这正是 `B04.md:101` 把 `(iii)` 改写成 `(iii)′` 的全部原因。

### 1.4 命题 S（`R_t > 1` 的严格陈述）——它是**类恒真式**

> **命题 S.** 设 `Λ_L` 是紧群 `G` 上的 Wilson 格点规范理论，`L<∞`、`β>0`，转移矩阵 `T_L = e^{−aH_L}` 紧、正核、`λ₁ = 1` 单重（`B01-RP.md:26,29`；`GAP3.md:70`）。则对**每个** `(L,a,β)`：
> ```
> λ₂(T_L) < 1   ⇒   R_t := 1/λ₂(T_L) > 1 .
> ```
> *证.* 紧配置空间 `G^{links}` + 紧算子 ⇒ 谱离散、只以 0 为聚点；PF 给 `λ₁=1` 单重且 `|λ_j|<λ₁`（`GAP3.md:70`）。故 `λ₂<1`。全程无估计、无展开、无小参数。

**⇒ S 是 `{2D YM, 4D SU(N) YM, 4D free U(1)}` 这一整类的公共性质**（`β=0` 上 `T` 秩一 ⇒ `λ₂=0` ⇒ `R_t=∞`，按扩张读法同样"成立"）。它不区分 2D（有隙 `3g²/8`）与自由 `U(1)`（无隙）；而"区分 2D 与自由场"是本项目四模型测试的**最低要求**（`B04-INDEX.md:72` 逐字：四模型测试的判别力全在 `2D YM` 与 `M6` 这对反例）。

### 1.6 候选 (b)：变分原理

**方向先说死**（`[T]`）：
```
Δ_a = min{ ⟨φ|H_a|φ⟩/‖φ‖² : φ ⊥ Ω, φ ≠ 0 }      ⇒  试验态只给 Δ_a 的【上】界
下界需要  ∀φ⊥Ω : ⟨φ|H_a|φ⟩ ≥ δ‖φ‖²               ⇐  这就是 Poincaré 不等式，δ = 2Λ(μ_vac,∇)（B01-RP.md:45）
```
- `B01-RP.md:16` 逐字："缺的那一步是 `λ₂` 的**一致下界** = 一致 Poincaré/LSI = 本项目的墙；它只能由**指数/曲率**数据供给，RP 的**符号**数据补不上"。
- 题面判据 `⟨φ|H_a|φ⟩ − ⟨φ|H_a|Ω⟩ < 0` 的符号是**反的**：找到这种 `φ` 就证到 `Δ_a<0`，是否证 `H≥0`（`B01-RP.md:26` 已给 `H≥0`）。`[M]`。

**两个物理输入逐个判**：

| 输入 | 它是什么 | 能给 `Δ_a` 下界吗 | 依据 |
|---|---|---|---|
| `⟨¼trF²⟩ > 0` | **一阶矩**（`∫s dν`），不是原子 | **否**：矩型泛函与谱底结构性错位；2D 上 `⟨C₂⟩→+∞` 而 `m→0`、`f₁²≡0` 而 `m>0` | `H03-ANOMALY.md:94,129` |
| `W_geo ≥ 0`（Prékopa） | **符号**地板（纯 Haar 边缘） | **否**：`ω≡0` 即 gap；自由 Gauss 同样为正 ⇒ 不判别；`k=0` 归一化下 `(N/12)/L→0`；`W_full ≥ N/12` 已 `[NG]`（机检 144/144 全败） | `BN-RESIDUAL.md:102`；`H1-FINAL.md:61`；`GH1a-ALIGN.md:217` |

**判**：`(b)` **要估计**（Poincaré 常数），且两个"已知物理输入"连试验态都造不出来。

## §2 ★ "结构性"与"估计"的分界（本路判决点）

### 2.1 分界的准确陈述：**不是工具，是量词序**

把两条陈述并排写：

```
(S)   ∀(L,a,β>0):        R_t > 1                    ← 严格不等式，无常数
(E)   ∃Δ₀>0 ∀(L,a):      log R_t ≥ (aΛ)·Δ₀          ← 均匀模数，常数 Δ₀
```

- `(S)` 里 `a` **只出现在量词域**；`(E)` 里 `a` 出现在**被估计的量**里（`(aΛ)` 是 `R_t−1` 的量纲因子）。
- `(S)` 是**开条件**（严格不等式在开集上成立）；`(E)` 是**闭条件**（到边界的距离有正下界）。
- 结构性论证（PF / 变分上界 / 正性 / 凸性 / KL）只能产出开条件——它们全部是"某量严格大于/小于另一量"，**没有一处能说出距离**。

**⇒ 分界的一行判据**：`∀` 在严格不等式外面 = **结构**；`∃常数 ∀` = **估计**。

### 2.2 命题 S/E-二分（no-go schema，`[T]`）

> **命题 S/E.** 设 `ℋ_struct` 为下列事实的集合：
> `(i)` 有限 `L`、紧群、紧配置空间；`(ii)` `T_L = e^{−aH_L}` 紧、正核、`0≤T≤1`、`H≥0`；`(iii)` `λ₁=1` 单重（PF）；`(iv)` RP ⇒ `ν≥0`（KL）；`(v)` 谱离散。
> 若一个论证**只消费 `ℋ_struct`**，则它推不出 `(E)`。
> *证（模型级反例）.* 取 **4D 自由 `U(1)` 格点规范理论**（紧群、Wilson 作用、`L<∞`、`β>0`）：它满足 `ℋ_struct` 的全部条目；光子无质量 ⇒ 物理质量 `m = 0`（`B04-INDEX.md:121`）⇒ 对**任何**正标度 `Λ`，`m/Λ = 0 < Δ₀`（`∀Δ₀>0`）⇒ `(E)` 假。故 `ℋ_struct ⇏ (E)`。（若说自由 `U(1)` 没有 `Λ`，那就取最有利的 `Λ=1/a`：`m/Λ = m·a = 0` 仍为 0。）

**推论 1（对本题的直接判决）**：`(a)/(b)/(c)` 中任何"零估计"的版本，其假设都 `⊆ ℋ_struct`（PF 用 (i)(ii)(iii)；RP/KL 用 (iv)；紧性用 (v)），故**都推不出 `(E)`**。这与"它们够不够聪明"无关。

**推论 2（S 的真值与靶无关）**：`(S)` 在自由 `U(1)` 上为**真**（`Δ_a(L)>0` 逐 `L`），在 4D 无质量自由标量（非紧零模）上为**假**（零模给连续谱 `[0,∞)` ⇒ `Δ_a = 0` 精确）——两者 `m` 都是 0。⇒ **`(S)` 的真值甚至不是 `m` 的函数**。这是比"假阳性"更强的一句：`(S)` 不是一个"有偏的估计器"，它是**另一个对象**。

### 2.3 为什么 PF 给不了模数（机制层，不靠反例）

PF 的输出是**序**（`λ₂ < λ₁ = 1`），它的信息量是"边界不在谱里"。模数是"谱离边界多远"。这两件事在**紧算子**上是独立的：
- `spec T_L` 可以任意接近 0（`λ₂ → 0⁺`，强耦合），也可以任意接近 1（`λ₂ → 1⁻`，`a→0` 或 `L→∞`）；
- PF 的两条前提（正核、单重）在**两端都成立**；
- 决定 `1−λ₂` 的是**动力学**（`Δ_a` 的值），不是**符号结构**。

仓内对此已有逐字判词：`GAP3.md:71`（"全是严格不等号，不是数"）、`B01-RP.md:12`（"RP 恰好给的是非严格不等式；而'有隙'= 这条不等式**严格** + **一个模数**。类型不匹配，不是松紧问题"）。

**⇒ 这不是"PF 不够强"，是"PF 的输出类型里没有数"。**

### 2.4 常数的位置表（六条候选一起看）

| 候选 | 要估计常数？ | 常数住在哪 | 可达 `(S)` | 可达 `(E)` | 依据 |
|---|---|---|---|---|---|
| **(a) PF** | **否** | ——（无常数） | **✓** | **✗** | 命题 S；§2.2 推论 1 |

### 2.5 "绕过 `a→0`"的清账（题面的核心期待）

题面把 `m = (1/a)log R_t` 称为"唯一绕过 `a→0` 的等式"。**分三层判**：

| 层 | 判断 | 依据 |
|---|---|---|
| **表达层** | **成立**：不需要连续极限，固定 `L` 的紧 `T_L` 就够；`m` 与 `R_t` 双射 | `[T]`；`GF1-RADIUS.md:181` |
| **信息层** | **零信息**：系数是 `C(t)` 本身，一个 `N(G_S)` 都不出现 ⇒ "把 `m` 的定义抄了一遍" | `[T]`；`GF1-RADIUS.md:27,181` |
| **一致性层** | **不成立**：靶是 `log R_t ≥ (aΛ)Δ₀`，右端 `→0`；等式给的是 `m_L`，靶要的是 `m_L/(aΛ)` 的模数 | `[T]`；§1.3 |

### 2.6 逃逸口只有一个形状（与仓内"双座"结构一致）

由 §2.2，任何能证 `(E)` 的论证必须消费**一条自由 `U(1)` 不具备的输入**；而"多消费一条结构事实"（非阿贝尔性、`π₁=0`、Bianchi、`H(4)`、渐近自由的存在性）**并不够**——它们不带模数。本项目盘点下来的这类输入只有四种形状，**全部带模数**：

1. **`Λ > 0` / 渐近自由**：`[C]`（`GK5-CONTINUUM.md:252`），且它只给标度、不给 `m/Λ` 的地板；
2. **一致 Poincaré / LSI / 曲率**：`B01-RP.md:16` 的墙；Savvidy 侧 `Hess` 不定（`λ_min=−g|B|<0`，`GI4-FORMS.md:40,95`）⇒ 前件假；
3. **振幅地板 `f₁² ≥ r₀`**：`I1`，窗内 `[T]`、窗外 `[O]`（`GR2-EDGEATOM.md:16–18`；`GN1-NODIP.md:16`）；
4. **(d) 的 `Δ` 界**：预期 vacuous，未证（`D02:101`）。

⇒ **"结构性"与"估计"的分界，就是"不带模数的输入"与"带模数的输入"的分界**：前者的全部产出是 `(S)`（§2.1–2.3）；后者每一条都恰好是 `(E)` 缺的那一项。这条判据与 `GS2-PATTERN.md:5` 的"双座"结构（"每条残余 = 一座干净的 + 一座 `a`-发散/广延的量，且第二座都没付"）同型。**本轮没有发现第五类。**
