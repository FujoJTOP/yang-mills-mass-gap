### 0.2 一句话

**猜想的两半各自都有一半是真的，而真的那一半彼此不相交。** `k₀=∞` 在**经典**层是真的（"classically perfect"：二次谱精确、瞬子解尺度不变——HP1994 摘要逐字），在**量子**层是假的（HP1997 摘要逐字自纠：FP 作用量**不是** exactly 1-loop perfect）；RP 的推前论证是真的（命题 PF：θ-协变条件期望保 RP，两行），但它只对**推前测度**成立，而 HP 的 FP 作用量是**极小化**方程的解。于是本路不是"死在算术"，而是**死在对象**：唯一同时具备两件的成员是**临界不动点**，而它 `Δ_cont = 0`（尺度不变 ⇒ 无质量）；反过来，`Δ > 0` 的成员是 RT 上的有限质量点，它按定义就不是推前不动点。**把 `k₀ = ∞` 代进 `k = k₀/(m+2)` 得到 `k = ∞`，这一步合法但空**：`k ≤ ∞` 不约束任何东西，而真正要证的 `Δ_a → Δ_cont > 0` 一格未动。Clay 0%。

## §1 猜想与定义

### 1.1 猜想逐字重述（三句，便于逐条判）

> **C1**：块自旋 RG 的完美作用量（Hasenfratz–Niedermayer 型）有 `k₀ = ∞`（无格点伪影，all-orders improved）——因为它就是不动点作用量。
> **C2**：它**保留 RP**——因为它是**正测度的推前**（块自旋不破坏正性）⇒ 这正是 Symanzik 做不到的。
> **推论**：代入 GK3 公式 `k = k₀/(m+2)` ⇒ `k = ∞` ⇒ `(NEW)` 以任意速率成立。

**C1/C2 的判定在 §0.1 的 0.1/0.2/0.3 行；推论的判定在 0.4/0.5 行。** 下面只补定义与证明。

### 1.2 定义

**(D1) 完备方程（"完美"= RG 变换的不动点）.** 设 `Π: U ↦ V` 为块变换，`T[U,V]` 为块核。完美作用量 `S^{perf}` 由**不动点方程**定：

```
e^{−S^{perf}[V]} = ∫ [dU] e^{−S^{perf}[U] − T[U,V]}            (1.1)   积分版（推前不动点）
S^{perf}[V]      = min_U ( S^{perf}[U] + T[U,V] )              (1.2)   极小版（HP 实际计算的那一版）
```

`(1.1)` 是**测度**的方程（HP 的 FP 方程；仓内 `FORGE5-FPACTION.md:6` 记的就是它）；`(1.2)` 是**经典场**的方程，是 `(1.1)` 的鞍点近似，也是 2D O(3) 与 4D SU(3) 上**真正被解出来**的那一版。`(1.2)` 在文献里的名字逐字是 **"classically perfect"**（DeGrand–Hasenfratz–Hasenfratz–Niedermayer 1995 的**标题**就是「The **classically perfect** fixed point action for SU(3) gauge theory」`[R-书目]`）。

**(D2) RT / 量子完备作用量.** `(1.1)` 的不动点是**一个点**；在它之外沿重正化轨迹（RT）的每一点都"完美"（无 `a^k` 伪影），但每一点由**相关耦合**（质量 / `β`）参数化。`Δ_a ≡ Δ_cont (>0)` 只在 **RT 的有限质量成员**上实现，**不在**不动点上。这一区分不是我造的：HP1997 用它把"FP 作用量"与"quantum perfect action"分开，并逐字说「we **constructed the renormalized trajectory** explicitly in 1-loop perturbation theory」`[R-摘要]`。

**(D3) 经典完备（= 树级 all-orders）.** 逐字判据（HP1994 摘要）：二次谱精确（"the spectrum becomes exact"）+ 瞬子解尺度不变（"the classical equations have scale invariant instanton solutions"）。等价地：树级 `k₀ = ∞`——**所有** `a` 的幂次伪影为零，只有非微扰/圈图伪影。

**(D4) RP 与转移矩阵.** 时间反射 `Θ`；`μ` RP ⟺ 对一切支撑在**半格** `Λ_+` 的可观测量 `F`：`∫ F ΘF dμ ≥ 0`。RP ⇒ `T = e^{−aH}` 自伴、`0 ≤ T ≤ 1`、`H ≥ 0`、`spec T ⊂ [0,1]`、`ν ≥ 0`、唯一真空（`B01-RP.md:11` 的 R1–R4，`[T]`，设定逐字：**Wilson 作用量**、任意紧群、任意 `β≥0`——`:22`）。**本路要用的正是 `H_a ≥ 0` 这一条**（`GK3-SYMANZIK.md:229` 的第 1 行）。

**(D5) `Δ_a` 与"完美"的关系.** `Δ_a := −(1/a)log λ₂(T_a)`（`B01-RP.md:12`）。**"完美"是 `Δ_a` 关于 `a` 的稳定性，不是 `Δ_a > 0`。**

### 1.3 命题 PF（推前保 RP）`[T]` —— 猜想 C2 的**真**的那一半

> **命题 PF.** 设 `μ` 是细格点上的概率测度，`μ∘Θ = μ`；设 `Π` 块变换且 **θ-协变**：`Π∘Θ = Θ_c∘Π`；令 `ν := Π_*μ`。则 `μ` RP ⇒ `ν` RP。
>
> **证明（两行）.** 取 `F` 支撑在粗格点半空间。由 θ-协变，`F∘Π` 支撑在细格点半空间，且 `(Θ_cF)∘Π = Θ(F∘Π)`。于是
> `∫ F Θ_cF dν = ∫ (F∘Π)·Θ(F∘Π) dμ ≥ 0`，末步是 `μ` 的 RP。∎

**三条立即的推论（都要记账，不许外推）：**

1. **边缘化是特例**（`Π` = 把细格点限制到子格点，`T = δ`）：子格点上的**边缘测度**继承 RP。**这就是自由场完美作用的 RP 证明**（§4.1：完美作用量的测度 = 连续统 GFF 在格点上的边缘）`[T]`。
2. **迭代 + 弱极限**：`R^n(μ_0)` 全 RP ⇒ 任何弱极限点 RP（仓内 `GL2a`（`GK2-TOWER.md:62`，θ-协变条件期望保 RP）与 `OS3` Thm 5.2 / `GL4`（`GK5-CONTINUUM.md:59`）是同一件事的两份独立证据）。⇒ **(1.1) 的不动点，若是迭代的极限点，则 RP**——**这是 `[C]`，输入是"极限点存在"**。
3. **命题 PF 对 `(1.2)` 无效**：`min` 不是条件期望，也不是任何正算子的推前。⇒ **HP 的 FP 作用量没有 RP 继承**。

```
        不动点 S*（有 RP：推前不动点 + 弱极限）  ⇒  尺度不变 ⇒ Δ_cont = 0   ✗ 无质量
```

### 3.1 推导重写（三行，与仓内逐字对齐）

```
T3（KLMN 型）：  |𝔞^{(3)}_a(ψ)| ≤ ε·𝔮(ψ) + C_ε·a^{k₀}/ε·‖ψ‖² ,   C_ε ~ C ε^{−m}     (GR1:257; GP9-RB:120)

sup_α        ：  α* = k₀/(m+2)  ⇒  k ≤ k₀/(m+2)                                   (GK3-SYMANZIK.md:249)
```

`[E]` 复算（§5.1 `[1]`）：`k₀=2,4,6,8,16,64` × `m=0,1,2,3`，格点搜索的上确界与闭式 `k₀/(m+2)` 差 `≤ 4e−6`（GR1 自报 `4e−4`）。⇒ 前沿表（`[E]`）：

### 3.3 "`k₀=∞` 试图进入公式"的三个位置，逐个判

**(a) 位置一：当成 `α*` 的内点最优.** `α* = ∞/(m+2) = ∞` ⇒ `ε = a^α` 无定义（`α` 不是数）。**判：不合法——但这是把 `∞` 当"数"用的错，不是公式的错。**

**(b) 位置二：当成上确界的极限.** `sup_α min(α, k₀−(m+1)α) = k₀/(m+2)` 对每个有限 `k₀` 成立，且**对 `k₀` 连续、单调**（`[E]`：`k₀=2→64` 逐点单调，`[2]`），故 `lim_{k₀→∞} = ∞`。**判：合法 `[T]`**。这就是"任意速率"的严格读法：`∀k ∃k₀(k)` 使 `k ≤ k₀/(m+2)`——**"任意速率"= "对每个 `k` 都存在足够高阶的改进"，不是"存在一个作用量给出 `k=∞` 的单一不等式"。**

**(c) 位置三：当成"误差为零"的端点.** 若伪影**逐点为零**（`C=0`），公式的两项结构消失，`k ≤ ε` 对一切 `ε` ⇒ `k = ∞`。**判：合法但空**（D2）。且**更强的一条**：若伪影是 `e^{−c/a}`（经典完备的形态），把 `k₀` 换成 `c/a` 的幂律计数，最优化变成

```
sup_α min( α , c/a − α·log(1/a) )  =  α*  =  c / ( a(1 + log(1/a)) )   →  ∞      (3.3)
```

`[E]`（解析：交叉点满足 `α(1+log(1/a)) = c/a`；值 = `α*`）。⇒ **指数小伪影也自动给 `k=∞`**，无需 `k₀` 是整数。**所以"`k₀=∞` 超出 Symanzik 推导的定义域"这句话的正确版本是：它不越界，它**把公式变成零约束**。**

### 3.4 结论（本节的可带走结果）

> **`k = k₀/(m+2)` 的定义域是：`k₀ = D−2`（有限、整数、无关算符的 `a`-幂），`k` = **同一对 `(H_a,H_cont)`** 之间的速率，且 `Δ_a` 良定。**
> 在端点 `k₀ = ∞` 处：**公式仍然连续、极限仍是 `∞`（合法），但不等式退化为 `k ≤ ∞`（零约束）。**
> ⇒ **"完美 ⇒ `k=∞` ⇒ `(NEW)`" 的第二步没错，第三步没有内容**：`k=∞` 说的是"这一族与连续统之间没有 `a`-幂差"，而 `(NEW)` 要的是"这一族的 `Δ_a` 有正极限"。前者是**无关方向**的陈述，后者是**相关方向的幅值**——`Δ` 在完美作用量里是**参数**（D2/§2.2-b3）。
