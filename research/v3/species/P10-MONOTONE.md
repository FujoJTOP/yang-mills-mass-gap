## 0. 判死线（先读这段）

**答：`Δ_dyn(β)` 不是 β-单调函数——它的单调性由 `θ`（边界 holonomy）的窗口决定，而"最坏格"（`θ=π`）恰落在单调**减**的那一支。**

- **`θ ≤ θ_c(β)`（`cos(θ/2) ≳ 0.06–0.22`）**：`Δ_dyn` 严格增、处处 `>0` ⇒ **一个 β 免费**（取最小 β 作端点即可）。
- **`θ ≥ θ_c(β)`（含 `θ=π`）**：`Δ_dyn < 0` 且严格**减**。`θ=π` 上精确：`Δ_dyn = −β²V₀`、`∂_βΔ_dyn = −2βV₀ < 0`（`[T]`，无近似）⇒ **`β` 越大越坏**。
- 翻转角实测：`θ_c/π = 0.9616, 0.9285, 0.8738, 0.8604, 0.8634, 0.8811`（β=0.5,1,2.5,4,6,10）(`[C]`)。
- **(a) 不成立**：`[2.5,6]×[0,π]` 上 H1 判据 `f=Δ_dyn+W` 最小值在**角点** `(β=6, θ=π)`：`−0.193019 < 0` ⇒ **H1 在整个区间不免费**，`β* = 4.306608` 仍在区间内部。
- **(b) 不触发**：`Δ_dyn` 在 `β∈[0.2,14]` 上**没有内点极小**（极小恒在端点：`θ≤0.85π` 在 `β=0.2`，`θ≥0.9π` 在 `β=14`）。只有**内点极大**：`θ=0.9π` 处 `β=1.576`、`Δ=+0.020970`；`θ=0.95π` 处 `β=0.665`。⇒ **不产生新阈值**。
- **(c) 部分成立，但不是"拟合假象"**：`o05` 的 `m=1`、`k→0` 在本窗口**复现**（`∂_βΔ_dyn(θ=0,β=6)=+0.249319 ≈ 1/4`，`m=1`；`k→0` 只在 `β≳50`）。**错的是推论那一步**：`Var(G_v) = β²·Var[g]` 带 `β²` 因子，`∂_βVar(G_v) = 2βVar[g] + β²∂_βVar[g] > 0` **处处为正、且 `O(β)`**（`θ=π/2`：`β=2.5→6` 得 `+0.0126 → +0.0017`）。把 `∂_βVar ≈ 0` 当成 `Var(G_v)` 的导数是量纲/因子错误，`k≈0` 说的是 `Var[g]` 的幂、不是 `Var(G_v)` 的幂在 `[1,10]` 上的行为（那里 `k=0.1–1.8`，见 O05 §3 表）。

**结论一句话**：捷径只在 `cos(θ/2)` 不太小的窗口有效；H1 的敌人正是 `θ≈π` 的 β-冻结 Haar 切片，`Δ_dyn` 在那里随 β **二次变坏**，故"两端点免费"不成立。**但**最坏情形恒在 `θ=π`（`[C]`：六个 β 上 `argmin_θ(Δ+W)` 全为 `θ=π`），所以 H1 只需查**一角** `(β,θ=π)`——这是本题拿到的可证结构（§4）。

## 1. 模型、`Δ_dyn` 的闭式与精确式（`[T]`）

约定逐字同 `O05 §1` / `h1e_var.py`：`ξ∈R³`、`|ξ|<2π`、`h=ρ/2`、`u=ξ₃/ρ`、
`S=β(1−cos h cos(θ/2)+sin h sin(θ/2)u)`、`Φ=−log J`、`J=4sin²h/ρ²`、`v=e₃`、条件化 `ξ₃=0`。
切片上 `u=0`、`Φ'≡0`（逐点精确 ⇒ `X=−2Cov(G_v,Φ')=0`），且

```
G   = ∂₃S|₀ = β sin(θ/2) sin(r/2)/r      = β·s·g(r),   g(r)=sin(r/2)/r     (g(r→0)→1/2)
H   = ∂₃²S|₀ = β cos(θ/2) sin(r/2)/(2r)   = β·c·h(r),   h(r)=sin(r/2)/(2r)  (h(0)=1/4)
Φ'' = ∂₃²Φ|₀ = 2/r² − cot(r/2)/r          (→1/6 = N/12, N=2)
w(r)dr = 2π sin²(r/2)/r · e^{−βS₀(r)} dr,  S₀(r) = 1 − c·cos(r/2) ≥ 0
⇒ Δ_dyn(β;θ) = β c E_β[h] − β² s² Var_β[g]                                   (★)
```

`(★)` 是本题的**全部**代数内容：`E[H]` 线性、`Var` 二次，两者共用**同一个**随 β 收缩的条件测度 `w`。
`θ=π` 时 `c=0` 且 `w` 与控制 β 无关（Haar）⇒ `Δ_dyn = −β²·Var_Haar[g] = −β²V₀`，`V₀=0.0110593`，与 O05/O16/H1E 逐位一致（§2 对账）。

**β-导数闭式（`[T]`，由 `∂_βw = −S₀w` 直接得出，无需数值微分）**

```
∂_βE_β[f] = −Cov_β(f,S₀)
∂_βVar_β[g] = −[ Cov_β(g²,S₀) − 2E_β[g]Cov_β(g,S₀) ]
⇒ ∂_βΔ_dyn = c·[E[h] + β∂_βE[h]] − s²·[2βVar[g] + β²∂_βVar[g]]                    (★★)
                └── X(θ,β) > 0 ──┘        └──── Y(θ,β) ────┘
```

`X>0` 可证：`h↓r`、`S₀↑r`（`c>0` 时）⇒ Chebyshev 积分不等式给 `Cov(h,S₀) ≤ 0` ⇒ `∂_βE[h] ≥ 0`（`[T]`）。
`Y` 的符号不可由同一招数定（`g` 与 `g²` 同向单调，两项相减），实测 `Y>0`（`[C]`，§3）。
**核对**：`(★★)` 与中心差分 `h=1e−5` 在 36 组 `(β,θ)` 上逐位吻合（`p10_monotone.log [1]` 末列，如 `β=6,θ=π/2`：解析 `+0.174712` vs FD `+0.174712`）。

## 3. 三个问题的直接回答

### 3.1 `∂_βΔ_dyn = ∂_βE[H] − ∂_βVar(G_v)`，能证 `∂_βVar ≤ ∂_βE[H]` 吗？

**不能对全部窗口证。** 精确到手的只有 `(★★)` 的两条：

1. `∂_βE[H] = ∂_β(βcE[h]) = c[E[h]+β∂_βE[h]] ≥ c·E[h] > 0`（`[T]`，因 `∂_βE[h]≥0`）；
2. `∂_βVar(G_v) = 2βVar[g] + β²∂_βVar[g]`，第一项 `>0` 且 `O(β)`，第二项 `≤0` 但 `O(1)`（实测 `|∂_βVar[g]| ≤ 1.9×10⁻³`）⇒ `∂_βVar(G_v) > 0` 在**全域**成立（`[C]`，36 点无例外）。

**故 `∂_βVar ≤ ∂_βE[H]` ⟺ `(★★) ≥ 0` ⟺ `c·X ≥ s²·Y`**，这是 `θ` 的显式条件（§4），不是无条件真命题。`θ=π` 处**反例精确**：`∂_βE[H]=0` 而 `∂_βVar = 2βV₀ > 0` ⇒ `∂_βΔ_dyn = −2βV₀`。

### 3.2 用 `o16` 的分解 `Var = C₋ + C₊`，`∂_βVar` 的符号？

`o16`：`C₋ = C₊ = Var/2` 是 `c²=(½,0,½)` 的**恒等**推论（β-无关）。于是

```
∂_βC₋ = ∂_βC₊ = ½·∂_βVar(G_v) = ½[2βVar[g] + β²∂_βVar[g]]  > 0      (逐 β, [C])
```

⇒ **符号为正，且两半同号同率**（比价 `C₋:C₊ = 1:1` 冻结，`∂_β` 不改变这个比例）。**分解对单调性无帮助**：它把 `Var` 一分为二，但两半的 β-导数相等，任何"负模是敌人、正模是朋友"的抵消都不可能出现在 `∂_βVar` 上（`o16` 的抵消发生在 `E[H]` 的曲率通道，那里净效应恰为零）。**故 `∂_β Δ_dyn` 的符号只能靠 `θ` 窗口分档，不能靠模分解。**

### 3.3 `o05` 的 `m=1` / `k≈0` 是拟合假象吗？

**不是假象，是窗口外推。** 逐条：

- `m=1`：`E[H]/β = c·E_β[h] → c/4`，`h(0)=1/4`，`[T]`；实测 `β=6,θ=0` 给 `0.2367`（`≈1/4`，`1−m` 修正 `O(1/β)`）。**`θ=π` 上 `m` 无定义**（`E[H]≡0` 精确），而 `Var` 的幂在那里精确是 **2**（`k=2`，O05 §3 表）。**`k≈0` 只在 `β≳50` 出现**；在 `β∈[1,10]` 上 `k=0.11–1.9`。**"Var β-冻结"在 `[1,10]` 上不成立。**
- **被推翻的是推论链**：`"k≈0"` ⇒ `"∂_βVar(G_v)≈0"` 错在漏掉 `Var(G_v)=β²Var[g]` 的 `β²`（`[T]` 逐点线性：`G_v=βG^{(0)}`）。正确读法：`Var[g]` 冻结 ≠ `Var(G_v)` 冻结；后者 `∂_β = 2βVar[g] > 0`。
- **`Δ_dyn` 非单调的机制也不是拟合**：`(★)` 里 `−β²s²Var[g]` 与 `+βcE[h]` 的 β-幂不同（2 vs 1）⇒ **必然有交叉 β**；在 `c=0` 的退化切片上二次项独存 ⇒ `Δ_dyn` 单调减是**定理**，不是数值。

## 4. 充分条件（任务 4）：`Δ_dyn` 在 `[2.5,6]` 上单调增的可核条件

**定义（`(C-Mon)`)：** 固定 `β∈[2.5,6]` 与 `θ`，令

```
X(θ,β) := E_β[h] + β∂_βE_β[h] = E_β[h] − β·Cov_β(h,S₀)                 ( > 0, [T] )
Y(θ,β) := 2βVar_β[g] + β²∂_βVar_β[g] = 2βVar[g] − β²[Cov(g²,S₀) − 2E[g]Cov(g,S₀)]
(C-Mon) ⟺ cos(θ/2)·X(θ,β) ≥ sin²(θ/2)·Y(θ,β)
```

`X,Y` 都是**一维求积**（`(★★)`），可逐点核。等价写法（解出 `c=cos(θ/2)` 的临界值）：

```
单调增 ⟺ c ≥ c*(β;θ) := (√(X² + 4Y²) − X) / (2Y)      （c=1 时必增；c→0 时必减，因 X>0,Y>0）
```

**实测裕度（`[C]`，`p10_monotone.log [6]`，`A−B = ∂_βΔ_dyn`）**

**⇒ 可核的充分条件（本题给的形式）**：在 `[2.5,6]` 上
`cos(θ/2) ≥ 0.25`（即 `θ ≤ 0.837π`）时 `(C-Mon)` 成立，**裕度 ≥ 0.0593**（最坏在 `θ=0.75π, β=2.5`），故 `Δ_dyn` 严格增且 `Δ_dyn ≥ Δ_dyn(2.5) > 0` ⇒ **一个 β（取左端 2.5）免费**。
**边界（不可推）**：`θ ≥ θ_c(β)` 时 `(C-Mon)` 反向成立——`θ=0.9π` 上 `∂_βΔ_dyn = −0.012…−0.034`，`Δ_dyn(6) = −0.0768 < 0`。

## 5. 结构结论：H1 的"一角定理"（本题真正拿到的可证结构）

`f(β;θ) := Δ_dyn + W_geo`（`W_geo = E_β[Φ'']`，切片上 `Var(Φ')=0`）即 `G''(0)` 的切片值（`eq:split`，`X=0`）。实测：

- `β ∈ {0.5,1,2.5,4,6,10}` 上 `argmin_θ f = π` **全部**（`p10_monotone.log [3]`）⇒ **最坏情形恒为 Haar 切片**（与 `H1A-EXACT` 独立一致）；
- `f` 在 `[2.5,6]×[0,π]` 上的箱内极值：`min f = −0.193019 @ (β=6, θ=π)`、`max f = +1.590639 @ (β=6, θ=0)`；`∂_βf>0` 的格点占 `85.70%`，**除 `θ≈0.861π` 一条线外每 θ 都 β-单调**（`[C]`）；
- 端点：`f(2.5,π)=+0.135995 > 0`、`f(6,π)=−0.193019 < 0`；`θ=0.9π` 的穿越在 `β*=9.301396`，`θ=π` 的穿越在 `β*=4.306608`（= `sqrt(W₀/V₀)`，`[T]+[C]` 逐位）。

**判 (a)：不成立。** `Δ_dyn` 非单调增（`θ≥θ_c` 反向），且 `θ=π` 上处处 `<0`。**H1 在 `[2.5,6]` 上不免费**；条件定理**不能**由此变成真定理；`β*=4.306608` 仍落在区间内部（`[2.5,6]` 被它一分为二：左半真、右半假）。
**但可写成一个真定理（`[T]`+`[C]` 支撑）**：`θ=π` 切片上 `G''(0) = W₀ − β²V₀`，故 H1 **在该切片上** `⟺ β ≤ β*`（**双向、精确、无窗口**）。加上"最坏情形在 `θ=π`"（`[C]`，6 个 β、181×141 网格），得单 plaquette 模型的 H1 阈值就是 `β*`，**且不可能"免费"**。

**判 (b)：不触发，无新阈值。** `Δ_dyn` 在 `β∈[0.2,14]` 上无内点极小（极小恒在端点）；内点**极大**在 `θ=0.9π, β=1.576`（`+0.020970`）与 `θ=0.95π, β=0.665`（`+0.004615`）——极大不产生阈值。
**判 (c)：部分成立**，措辞见 §3.3：`m=1`/`k≈0` 本身正确且已复现，错在"`Var` β-冻结 ⇒ `Δ_dyn` 随 β 增"这一步（漏 `β²` 因子与 `θ→π` 的窗口）。

## 6. 缺口（诚实线）

1. **`L=2` 未做**（时间预算 10 min 用尽）。可行的精确归约（已核，未实现）：`L=2` 上单 link 的条件权重 `∝ exp(β(u₀k₀ − u·k))`（`k = Σ_{6 staples} P_i ∈ C²`）≡ 单 plaquette 形式但参数**逐构型**：`β_eff = β·κ`、`cos(θ_eff/2) = k₀/κ`、`κ = √(k₀²+|k|²)`。**故 §0 的翻转判据要按 `(β_eff, θ_eff)` 的分布积分**，不是直接搬 `θ_c(β)`。这一步没做 ⇒ `L=2` 上的单调性**未判**（非"不行"）。
2. `(C-Mon)` 里 `Y>0` 只有数值（36 点），无证明。要证 `∂_βVar[g] ≤ 0` 需 `Cov(g²,S₀) ≥ 2E[g]Cov(g,S₀)` 这类三阶矩不等式，**未证**。
3. 所有"最坏在 `θ=π`"结论是 `[C]`（网格 `181×141`，步长 `π/180`）；未有 `[T]` 版的 `∂_θ f ≤ 0`。
4. `W_geo` 的 β-导数符号未单独证（`Φ''` 在 `r→2π` 发散、非单调），`[C]` 网格已含它，但无解析界。
