## §1 问一：粗粒化流的**不动点**是哪些？

取 `s = log R` 作"呼吸流"的时间，`(★₁′)` 是自治二阶系统。不动点 ⟺ `F′≡0` ⟹ `κF² = 0`：

⇒ **不动点这一路对形状零信息**：它既不选 `R^{−p}`、也不选 `e^{−cR}`，只选空解。`[NG]`
（字面版 `(★₁)` 同样：`F′≡0` ⟹ `κF²e^{s}=0` ⟹ `F≡0`。`[T]`）

## §2 问二：流有单调量吗？它对中间类取什么符号？

`(★₁′)` 乘 `F′` 得精确一次积分

```
ℰ := ½F′² − (κ/3)F³ ,        ℰ′ = −a F′² .
```

- **它是不是 Lyapunov，取决于一个没人算过的数**：`ℰ′ ≤ 0 ⟺ a ≥ 0 ⟺ c₁′ ≥ c₁`。`[T]`
  `SP-F-EQ1 §6` 只承认 `c₁,c₂` 未算；**真正承重的是 `sign(c₁′/c₁ − 1)`——换符号，耗散变反耗散，单调量当场不存在**。`[T]`
- **对中间类取什么符号**：`f = R^{−p}(log R)^q` ⇒ `F = s^q e^{−ps}`，`F′/F = q/s − p`，于是
  `ℰ ≈ ½p²F² > 0`，且 `ℰ′ ≈ −ap²F² < 0`，`ℰ ↘ 0`。**这与任何衰减解（含纯幂律、含指数）上的符号和走势完全一样。** `[T]`
  ⇒ **`ℰ` 排不掉中间类**：它是 `(F,F′)` 的局部泛函，而中间类与纯幂律在 `(F, F′/F)` 这一阶上**同值**，差别只在下一阶（`F″`），`ℰ` 看不见。`[NG]`

**但把方程当 Riccati 解（`P=F′/F`）就把中间类关掉了**（这一步不用单调量，用匹配）：

```
P′ + P² + aP = κF ,        F → 0 时右端 → 0
⟹ P → 常数 ⟹ P²+aP = 0 ⟹ P ∈ {0, −a}；P → −∞ ⟹ F 在有限 s 归零（违反 f ≥ 0，弃）
```

代 `P = q/s − p` 逐阶匹配：`p²−ap = 0` **且** `q²−2pq+aq = 0` **且** `−q = 0` ⟹ **`q = 0`**。`[T]`

> **渐近三分（完备）**：`f → f_∞>0` ｜ `f ~ A R^{−a}`（`a=c₁′/c₁−1`，**纯幂律，指数由几何定**）｜ 有限 `R` 归零（非正，弃）。
> **对数列 `R^{−p}(log R)^q`：除 `q=0, p=a` 外全排除。对 `e^{−c(log R)^α}`（`0<α<1`）与 `α>1`：全排除（`P²` 项或指数的阶对不上）。纯指数 `e^{−cR^β}`：`P→∞`，同样排除。** `[T]

⇒ **中间类确实被关掉了——代价是结论反过来**：`(★₁′)` 允许（且只允许）**幂律** `R^{−a}`，**不允许指数**。
所以 `(★₁)` 不可能给隙；它给的是"幂律 + 一个可算指数"。`[NG]`
（字面版 `(★₁)` 更狠：`P ∈ {0,1}`，即 `F→const` 或 `F~R`——**一条有界衰减解都没有**，`F~R` 又被 `|W|≤1` 排除。`[T]` ⇒ 字面版自相矛盾，必须修维数。）
