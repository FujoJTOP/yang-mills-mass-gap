## §1 差值估计量

### 1.1 三种差分式（`[T]`，逐行可核）

记 `t := a²`、`ω(t) = Δ_cont + δ₁t + δ₂t² + …`（`GM4:37`、`GK2:45`）。所有 `ω` 都由**同一个实测** `m̂ = aΔ_a` 通过恒等式 `ω = 2sinh(m̂/2)/a` 得到（`(SI-1)` 的逆，`GM4:38`）。

| 形式 | 式子 | 偏差 | 备注 |
|---|---|---|---|
| **前差（2 点）** | `δ̂₁ = [ω(t₂)−ω(t₁)]/(t₂−t₁)` | `δ₁ + δ₂(t₁+t₂) + δ₃(t₁²+t₁t₂+t₂²) + …` | **精确**：对二次 `ω` 无偏（`[T]`） |
| **中心差（3 点，对称）** | `δ̂₁ = [ω(t₀+h)−ω(t₀−h)]/(2h)` | `δ₁ + 3δ₃t₀² + …` | **它给的是 `t₀` 处的斜率，不是 `t=0` 处的** ⇒ 必须再对 `t₀` 外推一次 |
| **Richardson（3 点）** | 与 `t` 的**二次插值的 `t`-系数**恒等（Neville） | `δ₁ + δ₃(t₁²+t₁t₂+t₂²) + …` | **`[T]` 恒等**：不是新估计量，是"把 `δ₂` 测出来而不是假设掉" |

**判**：三种里只有"前差"本身是一个 `a=0` 估计量；中心差给的是 `t₀` 处斜率（另需外推），Richardson 与三点二次拟合**逐位相同**（`RN` 与 `np.linalg.solve` 的 Vandermonde 解，log `[2]`）。⇒ **"几种差分式"实际只有两档：2 点（假设 `δ₂=0`）与 ≥3 点（解出 `δ₂`，但 0 自由度）。**

### 1.2 归一化：把 `δ₁` 变成 `R`（本文件的核心恒等式）

设两点 `(a₁, a₂ = λa₁)`，`m̂_i = a_iΔ_i`。令

```
F := 2sinh(m̂₂/2)/λ − 2sinh(m̂₁/2) ,     G := 2sinh(m̂₁/2) − F/(λ²−1)
R := δ₁/(Δ_cont³/24) = 24·F / ( G³(λ²−1) )                              (GP2-1)
```

**推导（三行，`[T]`）**：全程 `a₁=1`（于是 `ω`、`Δ`、`δ₁` 全部无量纲）。`ω` 在单位 `a₁=1` 下是 `ω_i = 2sinh(m̂_i/2)/a_i`（`a₁=1`、`a₂=λ`）；前差给 `δ̂₁ = (ω₂−ω₁)/(λ²−1) = F`；截距 `Δ̂ = ω₁ − δ̂₁ = G`。于是 `R = 24δ̂₁/Δ̂³`。∎

**三条性质（全部 `[T]`+`[E]`）**：

1. **无量纲、无 `a(β)`、无 `D`**：`(GP2-1)` 右边只有 `(m̂₁,m̂₂,λ)`。**R5 被恒等消去**——不是"误差小"，是**式子里没有** `a`。
2. **`λ` 是整数比**：体积匹配线 `L_s·a = const` ⇒ `λ = a₂/a₁ = L₁/L₂`。GW7 的实测 `aL` 比 `0.66723` vs `8/12 = 0.66667`（差 8e−4 = 纯舍入，`GM4:185–188`）⇒ **零标度误差**。
3. **两个酸测塌成两个数**：`R = 1 + 24⟨K₂⟩₁/Δ_cont³`（由 `GK2:121` 的 `δ₁ = ⟨K₂⟩₁+Δ³/24`）。自由场 `K₂ = −ω³/24` ⇒ `⟨K₂⟩₁ = −Δ³/24` ⇒ **`R=0`**；2D `K₂=0` ⇒ **`R=1`**。⇒ **`R` 是 `(SM-2)` 的天然序参量，量程正好 `[0,1]`。**

### 1.4 判据：如何区分"连续质量差"与"cutoff 差"

**这是本文件最有用的一件东西。**

在体积匹配线（`L_s a = const`）上，把 `a` 用整数 `1/L_s` 替代（**精确**，无需 `a(β)`）：

| 假设 | `m̂(a)` 的标度 | `p := dln m̂/dln a` | `ω` 的形状 |
|---|---|---|---|
| **连续质量** `ω = Δ + δ₁a²` | `m̂ = aΔ_cont + O(a³)` | **`+1`** | `ω·a = 2sinh(m̂/2)` 随 `a` **一阶降** |
| **纯 cutoff**（理论里没有连续质量） | `m̂ = const` | **`0`** | `ω = m̂/a ∝ a⁻¹` |
| GW7 实测（`GM4:190–192` 的 `a^{-1.56}`） | `m̂ ∝ a^{-0.56}` | **`−0.56`** | 反向 |

**判据（两个门，都不需要 `D`／`a(β)`／拟合）**：

- **门 1（比值）**：`m̂₂/m̂₁` 必须 `= λ = L₁/L₂`。实测 `1.4637 / 1.8765 / 1.2821`（三对，`log [8]`）⇒ **全部 ≫1 ⇒ R1 失败。**
- **门 2（对数斜率）**：`p = Δln m̂/Δln a`。实测 `−0.71±0.89`、`−0.55±0.44`、`−0.36±1.32`。

| 对 | `p` | 离 `p=0`（cutoff） | 离 `p=+1`（质量） |
|---|---|---|---|
| 1–2（β2.50/2.59） | `−0.707±0.888` | 0.80σ | 1.92σ |
| **1–3（β2.50/2.66）** | **`−0.552±0.437`** | **1.26σ** | **3.55σ** |
| 2–3（β2.59/2.66） | `−0.363±1.322` | 0.27σ | 1.03σ |

⇒ **判：`p=+1`（连续质量）在 3.55σ 上被排除；`p=0`（纯 cutoff）在 1.26σ 上**不能**被排除。** 这正是 GM4 §3.3 的"零阶判据"（`m̂` 该降不降）的**带误差条版本**，而且是 `R` 之外独立的一条：`p` 只用量纲比值，连 `Δ_cont` 都不出现。

## §2 重求和拟合

### 2.1 硬 no-go：`Δ ↔ ω` 是双射（`[T]`）

`ω_a = (2/a)sinh(aΔ_a/2)` 与 `Δ_a = (2/a)asinh(aω_a/2)` 互为逆（`GM4:37–38`）。**逐点精确**（log `[0]`：往返误差 `0` 或 `2.2e−16`）⇒

> **命题（GP2-1）`[T]`.** 任何只依赖 `{ω_{a_i}}` 的估计量，都等于同一个只依赖 `{Δ_{a_i}}` 的估计量。"用 `ω` 而不是 `Δ`"**不增加任何信息**；它唯一的效应是把**运动学**非线性（`sinh` 的级数）搬到显式位置。

⇒ 任务书问"用精确的 `asinh` 核是否已经把主要非线性吸收掉"：**是，但那是运动学的全部、也是动力学的零。** 下面给数。

### 2.2 Padé `[2/2]`：0 自由度，判 `[NG]`

把 `ω(t)`、`t=a²`，写 `P(t)/Q(t)`（`P` 至 `t²`、`Q = 1+q₁t+q₂t²`）。5 个未知数 `(p₀,p₁,p₂,q₁,q₂)`，5 个方程（`P−ωQ=0` 在 5 点上）⇒ **线性系统，唯一解，零残差**。

**关键：Padé 的 `p₁` 不是 `δ₁`；要的是 Taylor 系数 `a₁ = p₁ − p₀q₁`。**（这一条我第一次算错，纠正后 log `[7]` 才自洽。）

| `t_c/t_max`（cutoff 极点位置） | `a₁`（真值 0.1） | 极点 `|t|` | 条件数 | 噪声放大 |
|---|---|---|---|---|
| 100 | 0.100000000 | 100.0 | 2.75e3 | **7.66×** |
| 10 | 0.100000000 | ∞ | 2.98e3 | **7.72×** |
| 3 | 0.100000000 | 3.0 | 3.69e3 | **8.05×** |
| 1 | 0.100000000 | 1.0（**在窗内**） | 6.53e3 | **10.0×** |

**判 `[NG]`（作为精度工具）**：(i) `a₁` **在每个 `t_c` 上都精确**——因为 5 点 5 参 ⇒ 0 自由度，它**没有误差估计**，极点只是一个**输出**；(ii) 代价是噪声放大 7.7–10×，而两点差分在**同一跨度**（`t∈[0.05,1]` ⇒ `|Δt|=0.95`）的放大是 `√2/0.95 = 1.49` ⇒ **Padé 贵 5–7×，还要多 3 个点**；(iii) 条件数 1e3–1e4 说明它本质上是在做一次坏条件的插值。⇒ **Padé／连分式不给受控余项；它把 `δ₂` 换成一个没有任何物理约束的极点位置。** 与 `(SM-4)` 的 `[NG]` 是同一个洞（`GK2:256`）。

### 2.3 `asinh` 核到底吸收了什么（给数，`[T]`+`[E]`）

在 `Δ` 变量里拟合 `Δ = Δ_cont + c₁Δ_cont t + …`，其 `t²` 系数（`GK2:83–84`）是

```
c₂ = δ₂/Δ − δ₁Δ/8 + 3Δ⁴/640
```

⇒ **运动学项 `3Δ⁴/640` 与 `δ₂` 混在一起**。换到 `ω` 变量，这一项**精确为 0**（自由场 `ω ≡ Δ_cont`，log `[1]`：`|R| ≤ 6.3e−15`），于是 `t²` 系数**只剩 `δ₂`**。

**判**：核的贡献是**精确的**（不是"主要"）：它把"已知的 `asinh` 尾巴"整体移走，留下"未知的 `δ₂`"。所以
- **好的一面**：`t²` 系数变成纯动力学量；自由场变成**恒等于 0**（这是唯一的精确酸测）；2D 变成**恒等于 `Δ³/24`**（`R=1`）。
- **坏的一面**：`δ₂` 的**量级一分没减**。它在 `Δ` 变量里本来就按 `a^{-(d+2)}` 发散（`GK2:216,221`：`d=3` 时 `a⁻⁵`），换变量只是让它从"和 `3Δ⁴/640` 相加"变成"单独出现"。
⇒ **任务书那句"剩余 `δ₂a⁴` 的问题就轻得多"判：否。** 轻的是**记账**（少一个已知项），不是**界**。

### 2.4 何时可以只用两点（判据 + 数）

两点模型 `ω = Δ + δ₁t` 的偏差是 `δ₂(t₁+t₂)`。要求它 ≤ 半个 4σ 预算（`(Δ³/24)/8`）：

```
|δ₂|(t₁+t₂) ≤ Δ³/192     ⟺     |κ| ≤ 1/[192(m̂₁²+m̂₂²)] ,   κ := δ₂/Δ⁵     (GP2-2)
```

**核对（`[E]`，log `[3]`）**：注入 `(δ₁,δ₂)` 后 `R` 的精确闭式是

```
R = 24(δ₁a₁³ + κΔ_u⁵(1+λ²)) / (Δ_u − κΔ_u⁵λ²)³ ,   Δ_u = a₁Δ
```

与数值差分残差 ≤5.7e−14（16 组）；小 `m̂` 极限 `δR ≈ 24κ(m̂₁²+m̂₂²)`（残差 ≤4%）。⇒ `(GP2-2)` 是**从精确闭式**推的，不是启发式。

| `(m̂₁,m̂₂)` | `|κ|` 上界 | 幂次计数 `κ~m̂⁻⁵`（`GK2:216`） | 超 |
|---|---|---|---|
| (1.9,1.3) | 9.83e−4 | 2.69e−1 | **274×** |
| (1.9,1.0) | 1.13e−3 | 1.00 | **885×** |
| (1.9,0.55) | 1.33e−3 | 19.9 | **1.5e4×** |
| (0.55,0.18) | 1.56e−2 | 5.29e3 | **3.4e5×** |

**判**：(i) **两点在任何窗内都不合法**，除非先有 `δ₂` 的**外部界**（= `(SM-4)`，`GK2:256` `[NG]`）；(ii) **唯一例外是 2D**：`κ=1/1920` 精确 ⇒ `(GP2-2)` 变成 `m̂₁²+m̂₂² ≤ 10`，即 `m̂ ≲ 2.2`（log `[6]`：`(2.5,1.5)` PASS、`(3.0,2.0)` FAIL）；(iii) 因此"≥3 点"也不够——3 点 0 自由度，**必须 ≥4 点**才有 1 个 `χ²` 自由度去**检验** `δ₂` 是否落在 `(GP2-2)` 里。**这是本文件对"重求和"的净结论：受控余项不能来自重求和，只能来自 ≥4 点的 `χ²` + `(GP2-2)`。**
