## §1 `Λ` 是什么：定义，不是被物理量定出来的

### §1.1 `[D]`

```
aΛ(β) = exp(−12π²β_W/(11N²))·(g²/16π²)^{51/121}·[1+O(g²)],   β_W = 2N/g²      [C 渐近]
```
（`M05-RATIO.md:76–81` 逐字、`G05-BETAOFa.md:4` 转引 `numerics/REPORT.md:61`。）

这句话**只定义了一个无量纲函数 `aΛ(β)`**。它不定义"`Λ` 的数值"——数值要靠把 `a` 用某个物理量
（`m_{0⁺⁺}`、`√σ`、`t₀`）钉住，或靠给 `Λ` 一个方案（`Λ_lat` / `Λ_MS` / `Λ_I`）。
⇒ **`Λ` 是纯定义 + 方案约定 `[D]`**；唯一物理的是**比值**（`B01-M1.md:114` 逐字：
"两者之间少的不是一个不等式，而是**一把尺**——而'尺'在纯 YM 里唯一已知的供给是 `Λ`（维度透射）"）。

**方案常数不小 `[E]`**：`m_{0⁺⁺}/Λ_MS^{(N_f=0)} = 6.3(3)`（`L2-GLUEBALL-LAMBDA.md:152`，连续极限）；
换到 `Λ_lat` 还要乘 `Λ_MS/Λ_lat` 的有限部分（`A8-MASS-LAMBDA.md:82` 判 `c=O(10)`）
⇒ 任何**具体** `c₀` 必须带方案；只有 `∃c₀>0` 是 scheme-无关（`M05:88`）。

### §1.2 `Λ → 0 (β→∞)` 的正确读法 `[T]`/`[C]`

`aΛ(β) → 0` 是 `[C]`（两圈渐近）。它有两种同样正确的读法：
- **固定 `a`、`β→∞`** ⇒ `Λ` 在格点单位里 →0（**纯粹是单位陈述**）；
- **固定 `Λ`（物理尺度）、`β→∞`** ⇒ `a(β) = aΛ/Λ → 0`（连续极限）。

**两者是同一个事实**。说"`Λ→0` 说明物理质量也→0"是单位错误：`Λ` 在物理单位里不动。

### §1.3 任务给的两圈式有两处常数错（不影响方向）`[T]`

整数算术（`b₀=11N/(48π²)`、`b₁=34N²/(3(16π²)²)`）：

| 项 | 任务写法 | 正确 | 理由 |
|---|---|---|---|
| 幂 | `β^{−b₁/(2b₀)}` | `(b₀g²)^{−b₁/(2b₀²)} ∝ β^{+51/121}` | `b₁/(2b₀²) = 34N²/(768π⁴)·2304π⁴/(2·121N²) = 102/242 = 51/121`（`N`、`π` 全消）；且 `R(g²)` 随 `g²↓` **增长**，故 `β` 侧是**正**幂 |
| 指数 | `exp(−β/(4b₀))` | `exp(−12π²β_W/(11N²)) = exp(−Nβ_A/(4b₀))` | `1/(4b₀)=12π²/(11N)`，`β_W=2N/g²` ⇒ 实数指数 `=12π²β_W/(11N²)`（差一个 `N`） |

**方向不变**：指数项压倒 `β^{+51/121}`，故 `aΛ→0` `[C]` 照旧。改这两处只影响 log 斜率的数值读数。

## §2 `m ≥ cΛ` 与 `m/Λ ≥ c`：**逐字同一句** `[T]`

```
∃c>0 ∀β≥β₀:  m(β) ≥ c·Λ(β)    ⟺    ∃c>0 ∀β≥β₀:  m(β)/Λ(β) ≥ c
```
证明只有一行：对每个 `β`，`Λ(β) > 0`（`[D]` 给出的正函数），不等式两边同除 `Λ(β)`。
`c` 不被改写、量词不被改写 ⇒ **两个命题是同一个命题的两种排版**，不是"强弱"或"加强"关系。

**量纲账**：`[m]=[Λ]=质量¹`，故 `m/Λ` 无量纲、`m ≥ cΛ` 的 `c` 也无量纲。
⇒ 这是"**纯数 ≥ c**"型陈述，没有任何隐藏的单位自由度可调。
`M05-RATIO.md:99` 的 `(T1)⟺(T4)`（"除以 `a`"）是同一件事的格点侧写法：
`(T1) a·m ≥ c₀·aΛ` ÷`a` `(T4) m ≥ c₀Λ`，`Δ₀ := c₀Λ`。

**唯一能破坏等价的东西**：若 `Λ` 被定义成 `m` 的函数（例如 `Λ := m/c`），等价仍在，但命题变成恒真
——那才是 vacuous 版；两圈式**不是**这种定义（`§1.1`），故等价是信息保持的。

## §3 `m·a` 随 `β` 的行为：`→ 0` `[T]`

```
m·a = a·m_{0⁺⁺} = (aΛ)·(m/Λ)
aΛ(β) → 0            [C，§1.2]
m/Λ ≥ c₀ > 0         [即 (iii) 的内容]
⇒ m·a ≥ c₀·aΛ → 0    [T]
```
反向读法（反证）：若 `m·a ≥ λ>0` 且 `λ` 与 `β` 无关，则 `m_phys = (ma)/a ≥ λ/a → ∞`
⇒ 固定物理间距上的关联 `→ 0`（平凡极限）⇒ **自我否定**。这正是 `M05-RATIO.md:35` 的 no-go 引擎，
也是 `B01-M1.md:128` 逐字判的"字面常数地板 `[NG]`（自否）"。

**配套读数 `[E]`**（`M05:36–37`）：A 支（常数 `18.26`）ratio `37.8→1.8e5`、corr `4.0e−17→0`；
B 支（`∝aΛ`）ratio `≡6.3`、corr `≡1.8e−3`。⇒ 常数地板死，比值地板活。

## §4 (iii) 的正确量纲形式，与 (a)/(b)/(c)

### §4.1 正确形式（逐字）

```
(iii-物理)   ∃Δ₀>0 ∀β≥β₀:  m_{0⁺⁺}(β) ≥ Δ₀ ,  Δ₀ = c₀·Λ        （质量单位）
 ⟺ (比值版)  ∃c₀>0 ∀β≥β₀:  m_{0⁺⁺}(β)/Λ(β) ≥ c₀
 ⟺ (格点侧)  ∃c₀>0 ∀β≥β₀:  m_lat(β)/(aΛ(β)) ≥ c₀ ,  m_lat := a·m_{0⁺⁺}
 ⟺ (M05 的 T2) liminf_{a→0} m_lat/(aΛ) ≥ c₀
```
四个式子是**同一句**（两次除以正数 `Λ(β)` / `a`）。

### §4.2 (a) 触发 —— 给出正确量纲陈述

见 §4.1。(iii) **不需要**"比值版"替换：它**已经是**比值版，前提是 `Δ₀` 写成 `c₀Λ`（质量单位）、
`m` 是**物理单位**的质量。`b02`/`b07` 若指向"比值"，那不是另一条命题（§2），而是同一句的写法；
语料里这一句已有（`B01-M1.md:16,128`、`M05:20–24`）。

### §4.3 (b) 半触发 —— `Λ` 纯定义，但 (iii) **不是**恒等式

- `Λ` 纯定义：**是** `[D]`（§1.1）。所以 `Λ` 的**任何**性质（`Λ>0`、`aΛ→0`、`Λ→0` 当 `β→∞`）
  **都不含物理**，不能拿它当结论。
- 但"⇒ (iii) 是恒等式"**不成立** `[T]`：恒等式只在 `Δ₀` 被 `m` 自身校准（`Δ₀ := c₀·m`）时出现；
  两圈 `Λ` 不提供这种校准（它只给 `a↔β` 的关系）。⇒ (iii) 的内容 = "纯数 `m/Λ` 有正下界"，
  这是**动力学**陈述 `[M]`，缺件正是 `H1` 的物理成员 `δ_phys = a²Δ₀²+W_full`（`H1-FINAL.md:14,50`）
  ＝ `M05:42` 那一格。
- **一处必须写明的弱化** `[C]`：在**物理单位**里 `m_{0⁺⁺}(β)` 本就不随 `β` 变（连续极限一旦存在），
  `∀β` 的均匀性自动满足；`M05:112–113` 逐字"逆：`m>0` 且极限 `m_phys∈(0,∞)` 存在 且 同一个 `Λ`
  ⇒ `(T2)` 取 `c₀=m_phys/(2Λ)`"。⇒ (iii) 的真实内容 = **"连续极限存在且 `m_phys>0`"**，
  `Δ₀` 那个存在量词本身**不带**额外内容。它不是恒等式，也不是"额外的地板"。

### §4.4 (c) 触发 —— `m·a` 的极限是 0，故格点常数为底的地板必假

见 §3。**判**：任何形如 `m·a ≥ λ`（`λ>0` 与 `β` 无关、纯数）的地板 **`[NG]`**。
合法的地板只有 §4.1 的比值式（右端 `∝aΛ→0`，故不触发自否引擎）。
