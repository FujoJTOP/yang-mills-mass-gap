## 0 · 一句话判词

**`0` 和 `0.542943922353690` 都是对的，因为它们是不同测度上的两个量：**

```
全测度 dHaar = 4π sin²ψ dψ du :  S = D = 0.656830103891175 , S−D = −1.3e−16  ← s07 的 Stein 等式
a=0 切片 dμ  = 2π sin²ψ/ψ dψ :  S = 0.558183642724587, D = 0.015239720370897,
                                 S−D = +0.542943922353690                ← r03 的 G″(0)
```

`r03` 的 `S`、`D` **不是**全测度的 `E[H+Φ″]`、`Var(G+Φ′)`，而是**冻结在 `a=ξ₃=0` 的切片条件量** `E[H+Φ″|0]`、`Var(G+Φ′|0)`。s07 的恒等式对全测度是 `[T]`，但它**不约束**切片值 —— 它约束的是 `a`-平均（§3）。

**关于「最重的结论」**：如果证书线的 `S`、`D` 真是全测度的 `E[H+Φ″]`、`Var(G+Φ′)`，那么 `S−D ≡ 0`，整条证书线**确实**作废。**但那个读法是错的**：`r03_cert_theta.py:254-267` 的四个积分 `Z, NA, NB, NS` 的权重是 `ν ∝ e^{−β(1−c cos u)} sin²u/u du`（`u=ψ=ρ/2`，**一维、无 `∫du`**），即 `a=0` 切片的精确权重（`dμ_a = 2π sin²ψ/ψ dψ`，与 `s07` 的 `slices(a=0)` 同一个）。所以证书线判的不是被 Stein 归零的那个量。

## 4 · 两者如何在同一张账上闭合（这是本次的净收获）

`a`-切片族（`w7/v06_decide.log` [A]，81 点 `a=2π sinφ`、边际 `da ∝ Z(a)da`）：

```
G″(a) = E[H+Φ″|a] − Var(G+Φ′|a) = m_F′(a)
G″(0) = +0.542943922            ← 独立路径复现 r03 的 0.54294（不经 r03 的级数机器）
E_a[G″] = +0.646732  =  Var_a(m_F) = +0.646732   (差 6.7e−16)
Var(F) = E_a[Var(F|a)] + Var_a(m_F) :  0.656830 = 0.010098 + 0.646732
```

于是 `s07` 的 `0` 与 `r03` 的 `0.5429` 是同一个总方差分解的两端：

* `s07` 的零 = **全测度平均**的等式（`E[V′]≡0` 把平方项归零），它的非零内容在条件层：`E_a[G″]=Var_a(m_F)=0.646732>0`（`[T]`，总方差分解）；
* `r03` 的 `0.5429` = **点态**的 `G″(0)=m_F′(0)`，落在 `[0, +0.6467]` 的合法范围内，与平均恒等式**不冲突**。

两者同时为真、且数值互相校验（`0.646732` 由两条独立代码路径给出同一 6 位）。

## 5 · 判死线

**(a) 不触发。** 逐字：全测度确实有 `E[H+Φ″]−Var(G+Φ′)≡0`，**若**证书线的 `S`、`D` 取全测度，证书线作废；`r03` 的区间算术取的不是全测度（权重无 `∫du`、含 `1/ψ`），故不作废。

**(b) 不成立 —— `s07` 的等号没有一个错。** `(S-0)`/`(S-1)`/`(S-2)` 全部在本模型内逐位复核：`E[H+Φ″]=Var(G+Φ′)=0.656830103891175`、`E[G+Φ′]=1.9e−16`。

**(c) 成立，这是裁决。** 两个量的差别**精确地**是「全测度 vs `a=0` 条件切片」：

```
S_full − S_slice = +0.098646461      (= (E[H]−E[H|0]) + (E[Φ″]−E[Φ″|0]) = 0.053424565 + 0.045221896)
D_full − D_slice = +0.641590384      (= Var(G)+Var(Φ′)+2Cov − β²s²Var_ν(g) = 0.293242+0.088601+0.274987−0.015240)
```

**顺带必须更正 r03 的两处「写法」错误（数值对、标签错）**：
1. `R03-CERT-THETA.md:41` 把切片量写成无条件的 `S = E[H+Φ″] = (βc/2)E_ν[g]+E_ν[Φ″]`、`D = Var(G+Φ′) = β²s²Var_ν(g)`；按字面读是**假**（差 `0.0986` / `0.6416`）。应写成 `S = E[H+Φ″|a=0]`、`D = Var(G+Φ′|a=0)`。
2. `R03-CERT-THETA.md:33` 的 `H = ∂²_{ξ₃}S_W = (βc/2)g(u)` 不能靠「固定 `ρ` 求二阶导」得到（那给出 `0`）；正确来源是链式算子的 `S_ρ/ρ` 项在 `u=0` 的取值。**值对，推导句错。**
（`H_vv=(βc/2)g` 若被当成全测度公式用，会得到 `E[H]=0.377311` 而真值 `0.430735`。）
