## §2 核心：上界 vs 下界（四层方向，逐层独立）

### 2.1 层一 · 载架方向：`G″ = 1/χ ≥ m₁²` ⇒ 天花板（`[T]`）

`χ = ∫s^{−1}dν(s)`，`supp ν ⊂ [m₁²,∞)` ⇒ `s^{−1} ≤ 1/m₁²` ⇒ `χ ≤ 1/m₁²` ⇒
```
G″ = 1/χ  ≥  m₁²      （调和均值 ≥ 最小；等号 ⟺ ν 单原子 / 边缘 Gaussian，Q02:66）
```
⇒ **`q11` 的数即使在 `L=1` 上、以最宽容的口径读，也只是 `m₁²` 的上界。**要把它当下界用，等于把"天花板"当"地板"——方向反一次。
（`L2C-SD:130` 另记 `[D]=[G″]=[a]^{−2}`，`G″` 甚至与 `m₁²` **不同量纲归一**：`f₁²` 三种归一 `4/2/0`，无一种使 `f₁²` 与 `D` 同量纲。）

### 2.2 层二 · `L` 方向：体积越小隙越大 ⇒ 上包络（`[C]` 机制，`[NG]` 定理）

- **定理：0 条。** `D03-ML §1.2` 检索台账逐字：`m(L)` 在 `L` 上单调性的**任何**定理 = 未查到（工具 OK、命中 9、其中 0 条），`[NG]`。
- **机制：递减（4/5 有极限的精确模型）。** `D03-ML §3(ii)` 逐字："`λ₂` 是下包络 ⇒ 加体积等于给下包络**加候选函数**（动量塔 `2π²/L²`、二粒子阈、torelon `σL`），包络被**拉低**，不会抬高。"
- **唯一递增的实例是 torelon**：2D YM `m(L)=σL`，`m(L)/L=0.4038776782` 在 `L=2..5` **逐位恒定**，极限 `∞`（`D03-ML §2.1`）。
- **`D03-ML §0.4` 已把这条动机句判过一次，逐字**：「"有限体积的隙更大" ⇒ `m(L) > m(∞)` ⇒ 与要用的推断 `m(∞) ≥ m(2)` **方向相反**」。

⇒ 若递减机制成立：`m(1) ≥ m(2) ≥ … ≥ m(∞)`。**`L=1` 在包络最上方 ⇒ 它是 `inf_L` 的**上**界。**这恰好是"上界"的标准形状，也正是**拿不到下界**的原因。

### 2.3 层三 · 只有一个点 ⇒ 连"上界"也是条件命题（`[T]`）

`D02-DIRECT §0` 三行逐字：`T` 在 `L=2` 上**维数 ∞**（载体 `L²(SU(2)^{24})`）、PF 只给"单重 + `λ₂<λ₁`"**不给数**、路 I 截断态数 `140^{24}=10^{51.5}` 已死。
⇒ `β=2.5` 上被认证的 `G″`/`m` 数**只有 `L=1` 一个点**。因此：
```
严格可写：  G″(θ)|_{L=1} = 上表三值（区间证书）
不可写：     m₁(1) ≥ m₁(L) （L≥2 无值，无从比）
更不可写：   m₁ ≥ c > 0   （要的是下界）
```
⇒ 把 `L=1` 的证书升级成"下界"要**(i) 载架转移 + (ii) `L`-单调性 + (iii) `L≥2` 的第二个点**，三样都没有。

### 2.4 层四 · 靶的形状：要的是下界，上界对正性零信息

靶逐字是 `∃c>0: inf_{L,a} m₁ ≥ c`（`G04 §3.3`、`S10-IFTRIVIAL:17` 第二半"原子位置地板"）。`S10-IFTRIVIAL:93` 逐字："`(★)`/`H1` 是**上界形**（`χ ≤ 1/λ ⇒ m₁² ≤ M₀/χ`），**上界不能给正下界**。"
