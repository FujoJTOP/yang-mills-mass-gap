## §0 判决（先给，三段）

1. **判 (b)：同义反复，`[NG]`。** 一旦把 `w_β` 的每片率命名为 `c(β)`，q2 的条件 `c>κ` 与「弦张力 > 0」是**同一个不等式换名**：语料自己的 `[T]` 定理就是这条等价（`PROOF.md` 定理 B / 引理 2′）：`σ = −log(c_f/c₀) − γ`，其中 `γ`（曲面计数熵）就是 `κ`。**证 `c>κ` ≡ 证面积律。** 且 `c = κ + σa²/π`（由 q2 §6 反解）⇒ `c>κ ⟺ σ>0`。
2. **不触发 (c)：量纲匹配。** `c, κ, u, A` 全无量纲，`c>κ` 无量纲 ✓；`σ = π(c−κ)/a²` 是 `L⁻²` ✓。**q2 §6 不缺 `a`**。真正的记账错有两处，都不是缺 `a`：(i) `UC-1` 写 `σa² = ln(1/u)`（**漏 `−κ`**，即默认极小面主导/`κ=0`）；(ii) q2 §5(b) 把「`−log w` 凸」与「`w` log-凸」当同一句 —— 这两者其实是**同一条件**（`w` **log-凹**），而它推出的单调性方向与 q2 写的「`σ_A` 单调增」配套、却与「log-凸」这个前提**反向**。
3. **即使不管同义反复，活口在 `β=2.5` 也定量地死** `[V]`：唯一精确可算的面权率 `c(2.5) ∈ {−0.0143, +0.6789}`（两种语料约定），**都小于 `κ_min=1.40`**；`c(β)` 随 `β` 减小（`β→∞` 时 `→0`），故 `c>κ` **只在 `β ≲ 1` 成立**——那是 P3/KP 的地盘，不是 `2.5`。

**一句话**：活口把「`σ>0`」写成「`c>κ`」；`κ` 是它的对手项而不是独立信息，log-凸性只给**极限存在**、不给**极限大小**，小面权正性（`w(S_min)>0`，`[V]` `6.809e−2`）控制不了熵（`e^{κA}|_{A=6}=4.4e3`）。

## §3 方向引理（`[T]`，本题的技术核心）

设 `w_A>0`，`r_A := −log w_A / A`。

> **引理.** (i) 若 `A↦log w_A` **凸**（即 `w` log-凸），则 `r_A` **单调不增**，故 `lim r_A = inf_A r_A ≤ r_{A₀}`（**任何**有限 `A₀` 的读数都是**上界**）。
> (ii) 若 `log w_A` **凹**（`w` log-凹），则 `r_A` 单调不减，`lim = sup ≥ r_{A₀}`（有限 `A₀` 给**下界**）。

*证明.* `log w_A = cA + g(A)`，`g(0)=0`；凸性使 `g(A)/A` 单调不减，故 `r_A = −c − g(A)/A` 单调不增；凹性反向。∎

**后果（判死线的一半）**：Hadamard 判据要的是 `liminf r_A > κ`，即**下界**。**log-凸给的恰是上界** ⇒ 它只能**否证**衰减（`r_{A₀} ≤ κ` ⇒ `lim ≤ κ`），**永不能证明** `> κ`；能证明的方向是 **log-凹**，那正是 Savvidy 墙（`Hess` 不定 / `G″<0` 是 log-凸肩）与 `SU(N)` 变号所**不给**的方向。

**⇒ q2 §5(b) 的句子自相矛盾**：它写"把 `A↦−log w_β(A)` 证成凸、`A↦w_β(A)` log-凸，则 `σ_A` 单调增"。但 `−log w` 凸 ⟺ `w` log-**凹**（与"`w` log-凸"是**相反**条件），而"`σ_A = −log(w_{A+1}/w_A) − log μ` 单调增"只对 log-**凹**成立（因它等于差分 `(−log w)(A+1)−(−log w)(A)`，`−log w` 凹 ⇒ 差分递减 ⇒ `σ_A` **递降**）。⇒ **前提与结论配错了对象**；按题面所写的 log-凸读，`σ_A` 是递降的，`lim = inf`，有限 `A` 给上界。这与 q2 §0 的"`(b)` 只剩一小块"合起来说明：**这块不是"小"，是方向错**。

## §4 极限是什么：`c(β)` 的身份 + 量纲逐项

**设** `w_β(A) ~ e^{−c(β)A}`（管族严格如此：`a₀u^{4T}`，`c=−log u`）。**则** `lim_A(−log|w_β|)/A = c(β)`，判据变 `c(β)>κ`。

**`c` 与 `σ` 的关系（`[T]`，由 q2 §6 反解）**：`σ = π(σ₀−κ)/a²` 取 `σ₀=c` ⇒
```
c(β) = κ + σ(β) a²(β)/π ,        等价地    c > κ  ⟺  σ > 0 .
```
⇒ **`c` 不是 `σ` 的"零阶"**，而是无量纲的 `κ + σa²/π`：**逐片率**。`c` 与 `σ` 差 `π/a²`，`c` 与 "`σ` 的零阶"（即 `σa²` 的领头）差 `κ` 的平移。

**量纲表（逐项，`[T]`）**

| 量 | 定义 | 量纲 | 核 |
|---|---|---|---|
| `A` | 面片数 | `1`（格）= `L²/a²` | 无量纲 ✓ |
| `w_β` | 面权 | `1` | `|w|≤∏c_f` |
| `c = −log u` | 每片率 | `1` | 判据左端 ✓ |
| `κ = log μ` | 面熵（纯组合） | `1` | 判据右端 ✓ |
| `σ` | 弦张力 | `L⁻²` | `σa² = π(c−κ)` ✓ |
| `a` | 格距 | `L` | 只在 `σ↔c` 换算里出现 |

**⇒ (c) 不触发：`q2 §6` 不缺 `a`。** 需要记的不是缺 `a`，而是两处**口径**：
1. **`UC-COMPLETE (UC-1)`（`:88`）写 `σa² = ln(1/u)`**——这是 `c>κ` 在 **`κ=0`** 的退化版，即把「面熵被极小面主导」当恒等式（正是 q2 §2 的 S4，缺）。`PROOF.md` 定理 B 的完整式是 `σ = −log(c_f/c₀) − γ`（`γ`=曲面计数熵）`[T]`；`UC-1` 漏的正是那个 `−γ`。
2. **"`σ > κ/a²`" 这个写法是错的**：由 `σ = π(c−κ)/a²`，`c>κ ⟺ σ>0`（**不是** `σ>κ/a²`）。除非把 `κ` 重新定义成"每物理面积熵"（`LOOP-RUNBOOK §11.24` 提过这条 `[M]`），那时还要带 `π`，仍旧等价于 `σ>0`。⇒ **换算里没有失踪的 `a`；失踪的是 `κ` 与 `π`。**

**同义反复的精确形式（`[T]`）**：把和式写成 `⟨W(C)⟩ = Σ_A Ω_A w_β(A)`、`Ω_A ≃ e^{κA}`，则 `c>κ` ⟺ 该和**绝对收敛且有正隙** ⟺ 极小面主导 ⟺ 面积律。`PROOF.md` 定理 B 就是这条链在 `β<β₀` 的**一次性证明**（`σ = −log(c_f/c₀) − γ > 0`，同一个 `γ`）。**故 `c>κ` 不可能"独立于 `σ` 证"：证它=证 `σ>0`。**
