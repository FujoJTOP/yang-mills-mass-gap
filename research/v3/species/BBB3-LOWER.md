## §1 三路（最小公式、判据、精确障碍）

### 1.1 (a) 转移矩阵谱结构 — `T = e^{−aH}`, `T = ⊕_c T_c`, `spec T = ⋃_c spec T_c`, `m = inf_c m_c` `[T]`

三层分开算：恒等 `[T]`（a1）；**逐点严格** `[T]`（a2：RP 砍负谱+真空单重，不需每道 PF）；**一致** `[NG]`（a3）。
精确障碍（比"估计不够"硬）：`m_c = −ln λ_c`，直和让 `(λ_c)_{c≠0}` 成**自由坐标**（§2(2.2)）。同型已入库：`GI3:149`（"除四条外对 `(m_n,m_c)` 这一对没有任何约束"）、`GI3:151–155`（唯一 `[T]` 跨扇区序关系 `m_n ≥ min(m_n,m_c)` 是恒真式）。
判据：只消费{直和、`O_h×C` 对称、`T≥0`、`T≤1`、真空单重}的论证，在 §2(2.2) 族上仍成立 ⇒ 给不出地板。酸测：自由无质量场两侧 `0=0` ⇒ 过而 vacuous。**下一手**：把 (a) 降为"记账 + 反驳器"，新候选先在此族自杀一次。

### 1.2 (b) 逐道共享不等式 — 窗内 `0 ≤ C̄_L(t) ≤ A e^{−m_c|t|}`，`m_c=c(β)>0` ⇒ `m_c ≥ c(β)` `[T]`

- **为什么算"共享"**：它不逐道测量，只吃"所有规范不变观测量同一簇聚率、同一体积无关常数"（`GY1:95`；`Y02:16–20` 逐字"OS'78……已经逐道给最轻质量下界"）。三路里**唯一**兑现过"一条不等式覆盖全道"的。
- **障碍 1（正性类单向）**：`M_k=∫s^k dν≥0` 使每个矩比是均值 ⇒ `m_c² ≤ (M_a/M_b)^{1/(a−b)}` **恒上界**；有限正矩不定 `inf supp`、也不定该处原子（`GAP-G2:5,7` 的 `δ₀+δ₂` vs `2δ₁`）。
- **障碍 2（盲证书零松弛）**：跨窗要 `cert_blind ≤ inf_c Δ_c`，即隙强度（`C2:13`）；与障碍 1 及 (c2) 同一件（`C1:22`）。
- **障碍 3（逐算符≠逐道）**：`s_c := inf supp ν_{O_c}` 满足 `s_c ≥ m_c`；逐道 `s_c ≥ δ` 只给 `m_c` 的**上界侧**，除非"道内可及"`s_c=m_c`（M2，`GK4:123–127`）。**M6 精确见证**：边缘在 `ω=1`、`f₁²=1/(2ω)>0` 而同道 `m=0`（`U09-M6:28`）。
**下一手**：唯一未试的"非零松弛"载体 = `2⁺⁺` 的 `f₁²`（`T_{μν}` 受保护，仓内 0 条）；证到即可把 M2 从"逐道各一份"降成 `{0⁺⁺,2⁺⁺}` 两份。

### 1.3 (c) `0⁺⁺` 隙 + 一个道间比较 — `Δ_a = s₁/K*` `[T]`

- **归约是最弱形**：只要 1 道地板 + 1 个比值，不要 `|Chan|` 条证书（`RR6:21` 逐字"一个数"）；三路里唯一"减义务"的。
- **比较为何 `[NG]`**：`θ=0` 时 `P,C` 使混合两点核恒等零 ⇒ 跨道正性不等式退化为 `0 ≤ C_q C_S`（`C1:17`；`C1:20` 逐字 "No two-point comparison can order the channels"；`PROOF-IN11:31` 逐字 "no cross-channel inequality exists"）；`a₀=a₂=1` 使序与隔离都在 `O(1)` 次领头、无对称性可定（`PROOF-IN11:23`）；"两算符见同一态 ⇒ 证一道即够"缺 `2⁺⁺` 的 `f₁²`（`Y02:53,69`、`W95C:74`）。
- **窗内用的是简并、不是序**：`m₂/m₀→1` ⇒ `K*→1`（`RR6:0.5`），吃一个 `c`-一致余项，仓内未写（`RR6:0.6`，此处记 `[NG]`）。**下一手**：窗内只做对账；窗外整体改写为 `sup_{(β,a)}K*<∞` 一个标量（`BBB1:16`）。

## §2 `H = ⊕_c H_c` 能否把"全道"归约成"某一道"

**(2.1) 归约"陈述"：能。`[T]`** — `H|_{Ω⊥}=⊕_c(H_c∩Ω⊥)`，`inf spec = ⨅_c Δ_c`（`L3A:76`、`L3A:126`、`J06:41–44`）。"全道"是一个 `min`，不是 `N` 条证书的堆叠；完整 `Chan`／剥真空／固定 `(L,a)` 三条读法见 `J06:13`。

**(2.2) 归约"义务"：不能。`[NG]`** — 两行族即证：任取 `(λ_c)_{c≠0}∈(0,1)^{N−1}`，置 `T := P_{0⁺⁺} + Σ_{c≠0} λ_c P_c`；它满足直和、`O_h×C` 对称、`T≥0`、`T≤1`、真空单重，却实现任意一组 `(λ_c)`。⇒ 这些前提**不含**跨道不等式，"只需证某一道"的每一步都须额外用局部性。同型：`GI3:149`（`spec T` 只约束并）、`GI3:151–155`（唯一序关系恒真）。**判据**：候选若在 (2.2) 族上仍成立 ⇒ 它是恒等不是归约；若在某 `T` 上被打破 ⇒ 须报出"用了哪一条局部性"。

**(2.3) 唯一被证成的弱归约：1 道 + 1 个数。`[T]`/`[NG]` 各半** — `Δ_a = s₁/K*`（`BBB1:36(A)`、`RR6:45`）把 `N` 条证书降成"`0⁺⁺` 地板 + 一个比值"，但比值本身 `[NG]`（`BBB1:16`）。⇒ 分解能给到的最多是 `min + 1 标量`。

**(2.4) 一句话答**：分解把"全道"归约成 `min` 与 1 个标量（`[T]`），**不能**归约成"某一道"（`[NG]`）；后者等价于 `K*≤1`/`K*<∞`，与分解逻辑独立。
