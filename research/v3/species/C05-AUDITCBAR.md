## §1 逐条核准

### 1.1 `C̄` 的定义 —— 形式对，三条要钉死 `[T]`

`X01-L1C.md:71` 写 `|φ^U(Γ)|≤\bar C^{|Γ|}u^{|Γ|}`，`:73` 给 `|A(α)|≤\bar u^{α+1}/(1−\bar u)`。**形式可以**（`φ^U` 是 Mayer/Ursell 簇系数，`Γ` 是 `B_T` 上**连通装饰簇**；`|Γ|` 是 plaquette 计数，`P3-DRESSED-MASS.md:68` 的 (2.2) 就是这个和）。要钉三处：

1. **`|Γ|` 是 plaquette 数，不是 rep-box 数。** 若按 `|P| = Σ_p|r_p|`（`P3-FULLREP-KP.md:66`）记账，则 `∏_pβ^{|r_p|}/|r_p|!` 的阶乘不能扔；换成 plaquette 数只有在 `β^{|r|}/|r|! ≤ β`（`|r|≥1`，`β<1`）时无损 —— 可以，但要写明。
2. **`u` 的归一必须在定义里钉死。** `C̄` 没有独立意义，只是"每片权重 ÷ `u`"。`Z06-HOLEA:15–16` 钉 `u = c_f/N`（per-tile 归一权重，`=⟨(1/N)tr U_p⟩`），精确形式 `u = c_f/(Nc₀)`（`c₀=∫dU e^{(β/N)RetrU}=1+O(β²)`）。不写这一条，`C̄` 可被任意 `u` 平移。
3. **`C̄` 不得含 `Δ`。** `ū = eΔ·C̄·u` 的 `eΔ` 已经是过定点动物/树计数（`P3-FULLREP-KP:89`）；`C̄` 若再乘 `Δ`，同一组合因子计两遍。这是 `a01` 的**结构性错**（见 §1.3）。

### 1.2 `N`-标度 —— `C̄` **依赖 `N`**，`∝ N²` `[T]`

逐字链路（全部一手）：

* `c_f = β/(2N)+O(β³)`（`Z06-HOLEA:15`）、`u = c_f/N`（`:16`）⇒ **`c_f = N·u`（恒等，不是估计）**。
* `|w(S)| ≤ ∏_{p∈S}c_f`（`Z06-HOLEA:83`，`PROOF.md` 引理 2′）⇒ `|w| ≤ (Nu)^{|S|}`。
* 更松但更硬的一路：`|I(P)| ≤ ∏dim r_p`（`P3-FULLREP-KP:70–72`）+ `c_rdim r ≤ β^{|r|}/|r|!e^β`（`:30–31`）⇒ 每片 `c_rdim r = β/2 = N²u`（`dim f = N`）⇒ `|w| ≤ (N²u)^{|S|}`。
* `Φ(0) = Σ_{r≠0}c_rdim r = β + O(β²) = 2N²u`（`f` 与 `f̄` 各 `β/2`）——**这正是 KP 判据左边每片的量**（`P3-FULLREP-KP:85` 的 `(★★)`）。

**精确核（不是估计）**：`c05_cbar.py` §C，对 `cube(6片)`、`tube T=1,2,3`（`4T` 片）逐个算 `∏_links mult(1∈⊗)`（`P3-DRESSED-MASS:31` Fact 0.1）：每个 link 恰 2 片、定向相反 ⇒ `mult(1∈f⊗f̄)=1` ⇒ 积 `=1` ⇒

```
|w| = c_f^{n}·1 = (N u)^{n}   ⇒   |w|^{1/n}/u = N = 2.0000  （n = 6,4,8,12 全部精确 2.0000）
```

⇒ **`C̄ ≥ N`（精确）**。`N=2` 时 `C̄ ≥ 2 > 1.766`（`a01` 自己的不缩窗阈值）——**仅这一条就已经把 `C̄=O(1)` 打死**，在任何树因子之前。

**关于"N² 是重复计账"的判词**（`a01` 的核心理由）：要拆成两句。
* "每个 link 的 `1/N` 已在 `u=c_f/N` 里"——**对**，但 `u` 只吃了 **tile 归一的那一个** `1/N = 1/dim f`（`Z06-HOLEA:43` 逐字：`1/N` 来自**闭合迹归一 `(1/N)tr` 在每一个 tile 上的 `1/dim f`**）。
* "所以 `C̄` 该是 `O(1)`"——**错**：`u` 吃掉了 `1/N`，但**字符系数 `c_f` 本身没吃**，`c_rdim r = β/2 = N²u` 里的 `dim f = N` 仍在。`N²` 不是"再除一次 `N`"，是**字符维数 `dim f`**。⇒ 说 `N²` 是重复计账，等于说 `dim f` 不在权重里，与 `P3-FULLREP-KP:30`、`:70` 直接冲突。

**（c）的反面确认**：`β₁^fix = 2N²/(Ĉ eΔ C̄)`（`Z12-FIXC:206` 的一般 `N` 形式，`N=2` 即 `8/(Ĉ eΔ C̄)`）。
* `C̄ = 2N²` ⇒ `β₁ = 1/(Ĉ eΔ) = 4.5985e−3`，**`N`-无关** ✔ 与 `P3-FULLREP-KP:124`（"literal 半径 `N`-无关"，与 SZZ `1/48` 一致）自洽；也与 Gupta (14.21) `M=−4ln(β/2N²)` 自洽（`u=β/(2N²)` 已含 `ln N²`）。
* `C̄ = 20` ⇒ `β₁ = 2N²/(4·54.3656·20) ∝ N²`（`N=2/3/4/10 → 1.84e−3/4.14e−3/7.36e−3/4.60e−2`）✘ **违反** `N`-无关性。
⇒ 不是 `C̄` 的 `N`-依赖"翻转了 `β₁` 标度"，而是**`C̄` 的 `N`-依赖正是 `β₁` 保持 `N`-无关的唯一方式**。

### 1.3 `≤ 20` —— Kirchhoff+AM-GM 对，但 `20 = Δ` 不是 `C̄` `[T]`+`[E]`

**复现的部分（`[T]`+`[E]`）**

1. `Δ = 20`：`c05_cbar.log [A]` 在 `4D` 环面 `L=6` 上逐 link 计数 ⇒ `plaquettes/link = {6}`、plaquette 邻接度 `{20}` ⇒ `Δ = 20`（与 `P3-FULLREP-KP:116` 的 `4(6−1)=20` 逐字一致；原来的"`≤12`、每 link 3 片"确实是错的）。
2. 过定点动物数：`n=1,2,3,4 → 1, 20, 458, 11132`（`[B]`），`≤(eΔ)^n` 成立。
3. Kirchhoff（Matrix-Tree，整数精确，`Fraction` 消元）+ AM-GM：`t(G) = (1/n)∏_{i≥2}λ_i`，`Σ_{i≥2}λ_i = 2E ≤ Δn` ⇒ `t(G) ≤ (1/n)(2E/(n−1))^{n−1} ≤ eΔ^{n−1}/n ≤ Δ^n`。**这一步没错**，且 `Δ`（不是 `2Δ`）恰是正确常数。数值上 `max t^{1/n}`：`n=1..4 → 1, 1, 1.4422, 2.0000`；`n=7..12` 随机 `400` 组 → `3.2079`（`[B]`）。全部 `≤ Δ = 20`，`2Δ=40` 是浪费。

**错的部分（`[T]`）**

`|φ^U(Γ)| ≤ t(G_Γ)∏_p|w_p| ≤ Δ^{|Γ|}∏|w_p|` —— 但 `C̄` 的定义里要的是 `∏|w_p| ≤ (C̄ u)^{|Γ|}`，所以

```
C̄ = Δ × (每片权重 / u),   每片权重/u = N   （|w|≤∏c_f，Z06:83）
                                       = N²  （|I|≤∏dim，P3-FULLREP-KP:70）
```

⇒ `N=2`：`C̄ = 20·2 = 40`（或 `20·4 = 80`；连 `f`/`f̄` 两支取 `Φ/u` 则 `20·8 = 160`）。
⇒ **`20` 漏乘 `N`（或 `N²`）**，`N=2` 就少 2–8 倍，且随 `N` 恶化：`2N² > 20` 当 **`N ≥ 4`**（`N=3`：`18`，已在边缘）。所以 "`C̄ ≤ 20`，与 `N` 无关" 这条**作为 `N`-一致断言是假的**。

> **"粗版 `40`" 的来源辨析**：`40 = 2Δ` 里的那个 `2` 只可能是"每片 `f` 与 `f̄` 两支"——但 `f`/`f̄` 是**互斥的标签选择**（一片只能取其一），它们的和已经在 `Φ(0)=β` 里，而 `Φ(0)` 的每一支都带 `dim f = N`。所以 `2Δ` 既没算 `dim f`，又把互斥选择当成了可乘因子；真正的乘数是 `Φ(0)/u = 2N²`（`N=2`：`8`），不是 `2`。

### 1.4 `Kirchhoff+AM-GM` 是不是最优？—— 不是该算的对象 `[T]`

1. **对象错。** `ū = eΔ·C̄·u` 中 `eΔ` 已是"过定点的树/动物计数"（`P3-FULLREP-KP:89` 逐字 "`λ_a=eΔ`…animal-growth/tree-graph bound"）。`C̄` 若再含 `Δ`，`Σ_{Γ∋x}` 与 `Σ_{trees on Γ}` 就**同一组合因子计两遍**：过定点的**树**数本身 `≤(eΔ)^n`（树 ⊂ 动物），所以正确的界是 `(eΔ·Φ/u·u)^n`，不是 `(eΔ·Δ·Φ/u·u)^n`。
2. **KP 判据不需要 `C̄` 这个中间量。** `P3-FULLREP-KP:90` 的 `S_x(a) ≤ λ_aΦ(a)/(1−λ_aΦ(a))` 一步到位；`a=1` 时 `λ_aΦ(0) = eΔβ < 1 ⇔ β < 1/(eΔ) = 1.839e−2`。把它套进 `ū = eΔ C̄ u` 的壳子，就得到**唯一正确的** `C̄_sharp = Φ(0)/u = 2N²`（`N=2`：`8`，`Ĉ·C̄ = 32`，缩窗 `4.53×`）。
3. **`Δ^n` 本身极松**：实测 `max t^{1/n}` 只到 `2.00`（`n=4`）/`3.21`（`n≤12`），远低于 `Δ=20`。所以 Kirchhoff+AM-GM 即便在它自己的框架里也不是瓶颈——**真正的乘数是 `Φ(0)/u = 2N²`**，不是树的数。
4. **可改进的方向**（按收益排序）：
   (i) **别拆 `C̄`**，只留 `λ_aΦ`（上面第 2 条，收益：省掉 `Δ`，`4.53×` vs `45.3×`）；
   (ii) 用 `|w| ≤ ∏c_f`（`Z06:83`）而不用 `∏dim`：省一个 `N`；
   (iii) 用 `Γ` 的实际形状（`t(G) ≤ (1/n)(2E/(n−1))^{n−1}`，薄簇远小于 `Δ^n`）——但最坏类由薄/厚都可达 `O(1)` 常数，**不改变 `N`-标度**，只改常数；
   (iv) 用 rep 求和逐片吃掉 `1/∏|r_p|!`（`P3-FULLREP-KP:94` 已做）——已用尽。

## §4 强句
