## §3 钉 `Δ₀`：三个候选读法逐条判，唯一可采的写法

### 3.1 候选 A：`Δ₀ = √(Δ_dyn)/a`（即 `Δ_dyn = a²Δ₀²` 当定义）—— **判死，且是自我作废**

- **反问一句就死**：若 `Δ₀` 这样定义，则 `app.tex:194` 的 `G''_a/a² ≥ Δ₀²` 读成 `G''_a/a² ≥ Δ_dyn/a²`，即 `Δ_dyn + W_full ≥ Δ_dyn`，即 `W_full ≥ 0`（`[T]` 已证）。**整条 H1 变成 `W_geo ≥ 0` 的一个推论，墙消失。** 这与 `app.tex:182` 的 "The single open inequality" 直接矛盾。`[T]`
- **酸测反证**：自由场上 `Δ_dyn = 0` ⇒ 该定义给 `Δ₀ = 0` ⇒ `H1` 在自由场上也"成立" ⇒ **新工具在自由场上不失效 = vacuous**（`CLAUDE.md §1` 的酸测铁律）。`[T]`
- **标度反证**：`a²Δ₀²` 随 `a→0` 按 `a²→0`，而 `Δ_dyn` 是**固定 `a` 下的格点裸量**（`L=2, β=2.5`：`+0.562±0.277`，`T01-IMPLY.md:140`），没有理由 ∝`a²`。把两者**恒等**，等于断言 `Δ_dyn` 的连续标度为 `a²`，语料 0 处这么写。`[C]`
- **⇒ 语料里能站住的只有不等式** `Δ_dyn ≥ a²Δ₀²`；`Δ_dyn = a²Δ₀²` 只是**墙上取等的尖锐点**（若存在），**不是定义、也不是已断言的事实**。声称"`Δ_dyn = a²Δ₀²`"是**把靶当定义**。

### 3.2 候选 B：簇展开/`β`-级数的领头系数 —— **无出处**（0 命中）

全仓 `Δ₀` 的 250 条命中里，`Δ₀` 从不带 `β`、不带级数指标、不做展开；`W_geo`/`W_full` 的 `[T]` 出处（`ch05:203–206`）是 Prékopa 与 `NS-NOSUBTRACTION`，**不是簇展开**。`[T]`（缺席）

### 3.3 候选 C：`Hess` 的某本征值 —— **`[NG]`**

`Hess` 的对象是 `K=Π₀ Hess V Π₀`（`app:196–197`、符号表 `:794`），且**它的负边缘就是墙**（`:197–198` "whose negative edge (`det K=0`, the transverse massless mode) is the wall"）。若 `Δ₀` 是 `spec K` 的元素，它会随 `(L,a)` 变（违反 `:183` 的 `(L,a)`-一致），也会随 `v` 变（违反 `∀v`），并且**量纲**会是曲率量纲而非质量。语料 0 处在 `spec K` 与 `Δ₀` 之间连线。`[T]`/`[NG]`

### 3.4 唯一可采的写法（**这是本文件的正面结论**）

> **`Δ₀` 的唯一可用定义 = 隐定义（implicit definition），而它的内容是"一个上界 + 一个正的常数"：**
> ```
> Δ₀ ∈ (0, r] ,   r := inf_{L,a} √( G″_a(0) / a² ) = inf_{L,a} ( m_lat / a ) = inf m_phys ,   [T] 形式：app:194
> ```
> 即 `Δ₀` **就是一个被 `(L,a)`-一致的物理质量下界本身**，只是名字换了。它的**全部语义**是：`m_lat ≥ a·Δ₀`（⇔ `G″_a ≥ a²Δ₀²`，`ch03-existence.tex:161–162`、`M05-RATIO.md:22–23`）。

**因此 `Δ₀` 与 `Δ_dyn` 的正确关系是 `Δ_dyn ≥ a²Δ₀²`，不是 `Δ_dyn = a²Δ₀²`。** `Δ₀` 不是"`Δ_dyn` 的平方根"，而是"`Δ_dyn` 的**下界的平方根除以 `a`**"——两者差别就是 H1 的全部内容。`[T]`

**"最可能的意图"（(b) 要求给出）**：`Δ₀` 是作者用来**把 `λ` 从"格点单位常数"改成"质量量纲"的那个常数**——`ch03-existence.tex:161–162` 逐字"at fixed `a`, `G″_a ≥ λ` with `λ` a positive *constant* is dimensionally wrong"；`M05-RATIO.md` 把它记作 `(T4)`: `∃Δ₀>0 ∀a<a₀: m_{0⁺⁺}(a) ≥ Δ₀`（"物理单位的质量地板"）。⇒ **意图 = `Δ₀` 就是**物理质量隙本身**（`m_{0⁺⁺}` 的连续极限），而 `a²Δ₀²` 是它在格点单位下的像。** `[C]`（意图判读，非逐字）
