## §1 `W_full` 的显式（逐字 + 逐项）

### §1.1 定义（四个名字，两个来源）

```
W_geo  := E_μ[Φ''] − Var_μ(Φ')                Φ = −log J,  dU = J dX,  X_ℓ = log U_ℓ（平坦图）
W_full := W_geo + X                            X = −2 Cov_μ(G, Φ'),   G = ∂_v S_W = ⟨v,∇S_W⟩
G″(0)  = E_μ[H+Φ''|0] − Var_μ(G+Φ'|0) = Δ_dyn + W_geo + X
Δ_dyn  = E_μ[H] − Var_μ(G)
```
- 定义处：`app.tex:796`「`W_full`: `W_geo+X`，with `X=−2Cov(G,Φ')`」；`ch08-immune.tex:18`「`W_full := W_geo+X` is the full two-point remainder」；`ch05-theorems.tex:230–240`（`eq:split`，标签在 `:239`）。`[T]`
- **本文件新增的唯一代数恒等式**（等价改写，无数值输入）：
  ```
  W_full = E[Φ''] − Var(Φ') − 2Cov(G,Φ') = E[Φ''] + Var(G) − Var(G+Φ')          (I)
  ```
  `[T]`（`Cov` 展开，三行）。首次出现在 `H1C-WFULL.md:30`；本文件 §7 数值复核 `|Id−(I)| ≤ 1.5e−9`（引用其两路求积）。
- **`X` 的地位**：`X ≥ 0`（即 `Cov(G,Φ')≤0`）在语料里是**单列假设 [NA]**（`app.tex:800`「the negative-association inequality」），**未证**，且 `H1C-WFULL.md:3–6,76` 实测 **21% 点 `X<0`**（最大亏额 `−0.0230`）。⇒ `W_full ≥ W_geo` **不成立**（`[NG]`）。`[T]`/`[V]`

### §1.2 一句话读法

`Δ_dyn = E[H]−Var(G)` 是**作用力**的均值减方差（Gaussian 等分下 ≈0，`Δ_dyn→0`）；
`W_full` 是**Jacobian 力**的二阶余项（`E[Φ'']` 减 `Var(Φ')` 再减交叉协方差）。
`eq:scalar-identity`（`ch18:32–37` 逐字）把它写成
```
Var − E[H] − W_full = −G″(0) ,   H1(δ) ⟺ G″(0) ≥ δ ,   δ_max = G″(0)
```
⇒ **`W_full` 不是独立于 `G″` 的量**：`W_full = G″ − Δ_dyn`。任何"`G″=Δ_dyn+W_full` + 对 `W_full` 的下界 ⇒ 关于 `G″` 的结论"都只是把 `Δ_dyn` 换名。`[T]`

## §2 `≥ N/12` 到底从哪来（是 `N/12`，但连带三个限定）

### §2.1 论文原文（`ch05-theorems.tex:214–228`，`eq:wgeo-quant`，标签在 `:219`）

> `W_geo(v;a) ≥ λ(v) := inf_ξ ⟨v, Hess Φ(ξ) v⟩ ≥ (N/12)‖v‖² > 0  for every a, β, L`
> because strong log-concavity does not decay under marginalisation … (`NS-NOSUBTRACTION.md`, Prop. N1)
> **the mode enters only through `‖v‖²`, so an `L`-link average gives `‖v‖²=1/L`, i.e. `c=(N/12)/L`**；measured `≈0.24/L` sits right of `1/(6L)`。

同处 `:207–209`（Lemma B）：`Φ''⪰0` 逐点、任意测度、任意 β ⇒ `E[Φ''] ≥ (N/12)‖v‖²`（`SU(2)`: `1/6`；`SU(3)`: `1/4`；measured `0.34`, `0.46`）。

### §2.2 算术来源（本文件重算，`[T]`）

```
Φ(ξ) = Σ_{i<j} g(λ_i − λ_j),   g(d) = −2 log( sin(d/2)/(d/2) )
g(d) = d²/12 + d⁴/360 + …        ⇒ 二次系数 = 1/12      （= Haar 密度 J ≈ 1 − d²/12 的指数）
g''(d) = 1/(2 sin²(d/2)) ≥ 1/6，等号在 d=0                ⇒ min_ξ Hess Φ = 1/6·(Σ_{i<j}(v_i−v_j)²)
Σ_{i<j}(v_i−v_j)² = N·tr(v²) = (N/2)‖v‖²  （Σλ_i=0，‖v‖²=2tr v²）
⇒  inf_ξ min_{‖v‖=1} ⟨v,Hess Φ v⟩ = (1/6)·(N/2) = N/12
```
**数值核对（`n03_wfull.log` A 段）**：`g(d)/d² → 0.083333`（=1/12）；`g''(0) → 0.166667`（=1/6）；
SU(2) 精确闭式 `Φ''(u)=1/(2u²)−cot u/(2u)`（`u=ρ/2`，`ch19:80` 逐字）的 `min_u = 0.1666665`（= `2/12`）；
SU(3) `min_λ min_v = 0.250000`（= `3/12`）。⇒ **`N/12` 是锐的，等于 `ξ=0`（平坦图原点）处的逐点值。**

**`1/12` 不是 `ζ(2)/2`。** `ζ(2)/2 = π²/12 = 0.822467`，与 `1/12 = 0.083333` 差一个 `π²`；语料里也没有任何一处写过 `ζ(2)/2`（检索式 `zeta\(2\)|π²/12|pi\^2/12`，`grep` OK，命中 **0**，见 §8）。`1/12` 的唯一来源是 `−log J` 的二次展开。

### §2.3 三个限定（这决定它能不能用在 `G″` 上）

1. **它是 `W_geo` 的界，不是 `W_full` 的界。** `W_full = W_geo + X`，`X` 符号不定 ⇒ 需要 `[NA]`（未证，21% 数值假）。`[NG]`
2. **`β`-无关只对纯 Haar 边缘成立。** Prékopa 的强对数凹性作用在 `e^{−Φ}dX` 上；`β>0` 时总测度是 `e^{−(S_W+Φ)}`，而 **`S_W` 非凸 ⇒ 边缘不再 log-凹**（`D3-SUSCEPTIBILITY-VARIATIONAL.md:15` 逐字「Prékopa log-concavity of the marginal **fails** at 2.5」；`OTHER-H1-POINCARE.md:9` 同）。⇒ `W_geo ≥ N/12` 在物理点只有 `W_geo≥0` 这一半是 `[T]`。`[T]`/`[NG]`
3. **归一化：`(N/12)‖v‖²`。** `‖v‖=1` 的单 link 模给 `N/12`；`k→0` 的 `L`-link 平均模 `‖v‖²=1/L` ⇒ 地板 **`(N/12)/L → 0`**（`ch05:224` 逐字）。**"`L`-一致的正地板"在这一步就没有了**——这正是 `T01-IMPLY.md:18` 说的第 4 级台阶的一半。

**⇒ 结论：`W_full ≥ N/12 > 0` 在语料里是 `[V]`（`H1C-WFULL.md:5,89`：232 点、`min R=1.025`、`β→∞,θ=0` 时 `→1⁺`），不是 `[T]`。**
`T01-IMPLY.md:130` 把 `W_geo` 的 `[T]` 界搬给 `W_full` 并标 `[T]`，是**误标**；`ch19-h1-status.tex:41`、`paper-v5/sec01-summary.tex:22` 沿用同一误标（二者行文里写的是 `W_full ≥ N/12`）。

## §4 (b) `W_full=0` 在哪、`≥N/12` 的真实条件

`W_full = 0` 精确成立的模型：**自由场 / 1D Dirichlet 弦 / M6**（三者都是 `Φ≡0`：Lebesgue 或 Gaussian 测度，**没有紧凑群、没有 Haar Jacobian**）。`[T]`

⇒ `W_full ≥ (N/12)‖v‖²` 的真实条件（缺一不可）：

1. **紧凑非阿贝尔 SU(N) 的 Haar 测度在场**（`Φ≢0`）。`U(1)`、标量场、Gaussian 模上 `Φ≡0` ⇒ `W_full=0`。`[T]`
2. **模归一化 `‖v‖²`**：单 link `‖v‖=1` ⇒ `N/12`；`L`-link 平均模 ⇒ `(N/12)/L`（`ch05:224`）。**`L`-一致的正地板在这一步消失**。`[T]`
3. **`X ≥ 0`（`[NA]`）**，未证且 21% 点数值假 ⇒ 只能得 `W_full ≥ W_geo − 2√(Var G·Var Φ')`（Cauchy–Schwarz，把 `Var(G|0)` 请回来，循环）。`[NG]`
4. **Prékopa 的 `≥` 步**只在纯 Haar（`β=0`）边缘上成立；`β>0` 时 `S_W` 非凸、边缘非 log-凹 ⇒ 物理点上只剩 `W_geo≥0`。`[T]`/`[NG]`

⇒ **`W_full ≥ N/12` 不是普适不等式，是"紧凑 Haar + 单 link 归一 + `X≥0` + 纯 Haar 边缘"四条同时在场时的数值规律。** `[V]`

## §6 判死线 (a)/(b)/(c)

### (a) 若 `W_full≥N/12>0` 且 `Δ_dyn=a²Δ₀²≥0` ⇒ `G″ ≥ N/12 > 0` 恒成立？

**算术对，前提错。指出错在哪一步：错在 `Δ_dyn = a²Δ₀² ≥ 0` 这一步（不是 `W_full≥N/12`）。**

三条，逐条给数：
1. **`Δ_dyn ≥ 0` 为假**：单 plaquette `θ=π`、`β=2.5` 上 `Δ_dyn=−0.069121`；`β=6` 上 `−0.398135`。`[E]`
2. **`W_full ≥ N/12` 不成立为定理**：它需要 `[NA]`（`X≥0`，21% 点假）+ 纯 Haar 边缘的 Prékopa（`β=2.5` 失效）+ 单 link 归一。它是 `[V]`（232 点）。`[V]`/`[NG]`
3. **"平凡定理"的直接反驳**：`β=6,θ=π` 上 **`W_full = +0.205115 ≥ N/12 = 0.166667` 而 `G″ = −0.193019 < 0`**。⇒ **`W_full ≥ N/12` 不蕴含 `G″>0`**，所以 `G″>0` 不是"由地板白拿"的。`[E]`

**⇒ 你的 (a) 分支不成立；真实的定理只有：`G″ > 0 ⟺ Δ_dyn > −W_full`（`[T]`，逐点、逐模），而 `−W_full` 可以任意负、`Δ_dyn` 也可以负 ⇒ 符号是动力学的。**

**附：若把 `Δ_dyn≥0` 当额外假设强加**，则 `G″ ≥ inf W_full` 确实是平凡推论——但那是一个**空的前提**（在仓内两个精确模型上被否），且与"`G″>0` 是通往 Clay 的台阶"无关：`ch21-no-go-and-spec.tex:53–68` 的 M6 已证 `G″>0` 与 `m>0` 脱钩。

### (b) 若 `W_full` 在 2D 上为 0 ⇒ `≥N/12` 非普适？

**`W_full` 在 2D 上不为 0**（`=G″=W_geo ≥ 2`）；但 **`W_full=0` 在自由场 / 1D Dirichlet / M6 上精确成立**（`Φ≡0`）。⇒ **`≥N/12` 确实非普适**，真实条件是 §4 的四条（紧凑 SU(N) Haar + `‖v‖²` 归一 + `X≥0` + 纯 Haar 边缘 log-凹）。**"`L`-一致"的版本更弱**：`k→0` 模上地板 `(N/12)/L`。`[T]`/`[V]`

### (c) 若 `W_full` 的定义依赖 `Δ₀`（循环）？

- **`W_full` 自身的定义不依赖 `Δ₀`**：`W_geo+X` 只由 `Φ`、`G`、`μ(·|0)` 决定。**无形式循环。** `[T]`
- **但 `δ := a²Δ₀² + W_full` 循环**：`app.tex:182–194`（`app:sharp`，"the sharpest form, with no slack"）逐字把 `a²Δ₀²` **定义为** `E[H]−Var` 的全一致下确界：`Var ≤ E[H] − a²Δ₀²`。由 `eq:scalar-identity` 立刻得 `a²Δ₀² = Δ_dyn`（逐点）、`δ ≡ G″`，于是 `H1(δ) ⟺ G″ ≥ G″`。
  ⇒ **`Δ₀ > 0` 逐字就是 `Δ_dyn > 0`（的一致版）**，是改名，不是新量；与 `H1A-EXACT.md:68` 的 `δ_max = G″(0)` 同一句。`[T]`
- **另一处循环（不是 `Δ₀` 而是 `Var(G|0)`）**：任何想用 `W_full ≥ N/12` 去证 `G″≥λ` 的路线，都必须先证 `Var(G) ≤ E[H]+W_full−λ`（`(◆)`），而 `(◆) ⟺ Var(a)≤1/λ` ⟺ H1（`PROOF-JACOBIAN-SAVES.md:15`、`ch18-scalar-h1.tex:59–63` 逐字「`Var`, `E[H]`, `W_full` are not separately constrained by H1」）。`[T]`
