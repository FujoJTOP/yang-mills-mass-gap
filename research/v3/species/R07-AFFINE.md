## 0. 判死线（答案）

| 问 | 答 |
|---|---|
| `H = K(a)G + C(a)` 是**恒等式**吗 | **不是**。`[T]`：`W(G,H) ≢ 0`（`=O(a)`），`W(G′,H′) ≢ 0` ⇒ 既不比例也不仿射 |
| `H`、`G` 作为 `u` 的函数**线性相关**吗 | **不**。`Q_H/Q_G` 与 `P_H/P_G` 是两个不同的 `ρ`-有理函数（(3.4)(3.5)） |
| 仿射若能严格成立，零点集无关吗（`r01` 的疑问） | **对，但仿射本身不成立**；且更强的结论：`H−KG` 在 `{sin(ρ/2),cos(ρ/2),1}` 基下**没有常数项** ⇒ 若 `H−KG` 与 `ρ` 无关，那个常数**必须是 0** ⇒ 严格仿射 ⟺ 严格比例。`[T]` |
| 精确分解 | **`H = K₀G + βΔ`**，`K₀=½cot(θ/2)`，`Δ = tD − (c²/4t)A = O(a)`（(4.1)，`a` 的**奇**函数）`[T]` |
| `K`、`C` 有闭式吗 | **有**（相对 `Δ` 的矩）：`K=K₀+βCov(G,Δ)/Var(G)`、`C=β[EΔ−(Cov/Var)E[G]]`（(4.3)），数值复现 `r01` 至 `1e−16`。`K₀` 本身是闭式，`Δ` 是初等显式 ⇒ **`r01` 的缺失项补上了** `[T]+[E]` |
| `O(1e−3)` 残差是噪声吗 | **不是**。`[E]`：`N=1500/6000` 逐位相同；`relres/a → 1.43e−3`（`a→0`），sup-范数残差 `=1.1%/3.9%/12.9%·max|H|` @`a=0.3/0.75/1.2` |

**一句话**：`a=0` 的 `H=½cot(θ/2)·G` 是**秩塌缩**（四个函数里两个恒等：`C≡B`、`A≡a w`）；`a≠0` 时 `G`、`H` 是同一个一阶算子 `L=t∂_a+c/2` 作用在 `A` 与 `A′=∂_aA` 上 —— **同算子、不同自变量**，所以只差一个**显式函数** `βΔ`，不是常数。`r01` 的高 `R²` 是"光滑函数在短区间上近乎共线"的度量效应，不是结构恒等。

## 1. `θ=π` 切片与 `a≠0` 的 `u`-依赖（`[T]`，`log [A5]`）

模型逐字（`Q04 (2.4)(2.5)`，`H1A §2.1`）：`c=cos(θ/2)`, `t=sin(θ/2)`, `w(ρ)=sin(ρ/2)/ρ`, `ρ=√(a²+s²)`。

```
G/β = (c/2)·A + t·B ,   H/β = (c/2)·C + t·D
A = (a/ρ)sin(ρ/2) ,   B = w + (a²/ρ)w′ ,   C = sin(ρ/2)/ρ + (a²/2ρ²)cos(ρ/2) − (a²/ρ³)sin(ρ/2)
D = (3a/ρ)w′ − (a³/ρ³)w′ + (a³/ρ²)w″                                           (1.1)
```

令 `u=ρ/2`、`g(u)=sin u/u`（故 `w(ρ)=g(u)/2`，`w′=g′/4`，`w″=g″/8`）。**`a≠0` 的显式**：

```
G(u)/β = (c/2)·(a/2)g(u) + t·[ g(u)/2 + (a²/8)·g′(u)/u ]                                        (1.2)
H(u)/β = (c/2)·[ g(u)/2 + (a²/8)·g′(u)/u ] + t·[ (3a/8)·g′(u)/u + (a³/32)·( g″(u)/u² − g′(u)/u³ ) ]   (1.3)
```

（sympy 展开逐项核对，`log [A5]`；两式通分后与 (1.1) 代数等价，已验 `0`。）

- **`u`-依赖的种类**：`a≠0` 时 `G` 与 `H` **不再只是** `g(u)`，而是落在四个 `u`-块的张成里
  `{ g(u), g′(u)/u, g″(u)/u², g′(u)/u³ }`，系数 `a, a², a³` 各取一支：
  `G` 只用 `{g, g′/u}`（2 块），`H` 用全部 4 块。**维度不同 ⇒ 逐点比例不可能**。
- `a=0`（`c=0,t=1` 或一般 `θ`）：`G(u)=βt·g(u)/2`、`H(u)=(βc/2)·g(u)/2` ⇒ `H=(c/2t)G`。`[T]`
  （**注**：按 `S_W=β[1−c cos(ρ/2)+t a w]`，`a=0` 给的是 `βt·g(u)/2`；题面 `G=βt·g(u)` 差**整体 `½`**，是归一化约定，不影响任何比值/Wronskian 结论。）
- `θ=π`（`c=0, t=1`）：`G=β[g/2+(a²/8)g′/u]`、`H=β[(3a/8)g′/u+(a³/32)(g″/u²−g′/u³)]` ⇒ **`H` 不再恒零**（只在 `a=0` 零），`H/G` 有极点。

## 2. 三条精确恒等式：`a=0` 的"秩塌缩"其实**一直存在**（`[T]`，`log [A1][A2][A6]`）

```
A ≡ a·w(ρ)          (即 r01 的 A 就是 a w)                                      [A1a]=0
C ≡ B               (c-扇区的二阶 ≡ t-扇区的一阶；四函数只三独立)               [A1b]=0
∂_a²[ −cos(ρ/2) ] ≡ B/2 ,  ∂_a[ a w ] ≡ B ,  ∂_a B ≡ D                        [A1c]=[A1d]=0
```

于是把 `A := a w(ρ)`、`L := t∂_a + c/2`（一阶算子）写出来：

```
G/β = L A  ,      H/β = L (∂_a A) = ∂_a(L A)                                   (2.1)
```

**这是全篇的机制**：`G`、`H` 是**同一个算子** `L` 作用在**相邻两个 `a`-导数**上。`a=0` 时 `A=0`、`A′=B`、`A″=D` 退化成两条，`L A` 与 `L A′` 都只剩 `∝w` 一支 ⇒ 比例；`a≠0` 时 `∂_a` 与 `L` 不对易地"错开一层"，差额是一个**显式函数**（§4）。

## 3. Wronskian 判据（`[T]`，`log [A3][A4]`）

### 3.1 判据的正确形式

- **比例**：`W₁ := G H′ − G′ H ≡ 0`（`′=d/dρ`；对 `u` 只差因子 `2`，零点集相同）。
- **仿射**（`H = KG + C`，`C` 与 `ρ` 无关）：等价于 `H′ = K G′`，即
  **`W₂ := G′ H″ − G″ H′ ≡ 0`**。注意 `W₁=0` **不是**仿射的判据（`H=KG+C` 给 `W₁ = C G′ ≠ 0`）——`r01` 的疑问（"仿射时零点集无关"）正是这一条。

### 3.2 结果

```
W₁ = W(G,H)   ≢ 0 :  首阶 O(a)，[A4] 给出显式有理×三角式；数值 W₁(a=0.3,ρ=2.5) = −7.21e−4
                                              W₁(a=1.2,ρ=4.0) = −4.65e−3
W₂ = W(G′,H′) ≢ 0 :  首阶 O(a)，数值 W₂(a=0.3,ρ=2.5) = −8.46e−6，W₂(a=1.2,ρ=4.0) = −1.53e−4
W{sin(ρ/2), cos(ρ/2), 1} = −1/8 ≠ 0      ⇒ 常数函数 1 不在 {sin,cos} 的 ℂ(ρ)-张成里     (3.1)
```

`a=0` 时 `W₁=W₂=0`（数值 `0.000000e+00`）⇒ `q04` 等式复现。

### 3.3 显式比值：为什么**没有**常数 `K`

把 `G,H` 按 `{sin(ρ/2), cos(ρ/2)}` 分解（`R_G=R_H=0`，**无常数项**）：

```
P_G = [ (c/2)a + t − t a²/ρ² ] / ρ ,        Q_G = t a² / (2ρ²)                   (3.2)
P_H = [ (c/2) − ((c/2)a² + 3ta + (t/4)a³)/ρ² + 3t a³/ρ⁴ ] / ρ ,  Q_H = (c/2)a²/(2ρ²) + t[3a/(2ρ²) − (3/2)a³/ρ⁴]   (3.3)

Q_H/Q_G = K₀ + 3/a − 3a/ρ² ,      K₀ = c/(2t) = ½cot(θ/2)                        (3.4)
P_H/P_G = 与 (3.4) 不同的有理函数，(3.4)−(3.5) 的 a-展开首项 = −3/a ≠ 0              (3.5)
```

- (3.4) 是 `r01` 的 `(1.5)`（`H/G|_{2π}=½cot(θ/2)+3/a−3a/(4π²)`，取 `ρ=2π`）的**来源**：它就是 `cos`-通道的系数比，**随 `ρ` 变**。数值：`a=0.3` 时 `K_c(2.5/4.0/6.0)=10.356/10.444/10.475`，而 `K_s=0.308/0.385/0.413`（`log [B5]`）——两条通道**差 30 倍**，不存在共同的 `K`。
- **`C` 必为 0 的论证（`[T]`）**：`H−KG = (P_H−KP_G)sin(ρ/2) + (Q_H−KQ_G)cos(ρ/2) + 0`，**没有常数项**。若 `H−KG ≡ C`，用 (3.1) 得 `C=0`，再得 `P_H=KP_G`、`Q_H=KQ_G`。故**严格仿射 ⟺ 严格比例**，两者一起被 (3.4)≠(3.5) 判死。

## 4. 精确分解与 `K`、`C` 的闭式（`[T]`+`[E]`，`log [A2][B1][B2][B4]`）

### 4.1 精确分解（`[T]`）

```
H = K₀·G + β·Δ ,    K₀ = c/(2t) = ½cot(θ/2)                                      (4.1a)
Δ = t·D − (c²/4t)·A = [ t·∂_a² − c²/(4t) ] A ,      A = a w(ρ)                   (4.1b)
Δ = a·[ 3t cos(ρ/2)/(2ρ²) − 3t sin(ρ/2)/ρ³ − c² sin(ρ/2)/(4tρ) ] + O(a³)          (4.1c)
```

`[A2a]=0` 精确。**`Δ` 是 `a` 的奇函数、首阶 `O(a)`、非零非平凡** ⇒ `H−K₀G` 是 `ρ` 的非常函数 ⇒ 单项比例之外的"仿射修正"**不可能被一个常数吸收**。
一眼的机制：`(4.1b)` 的 `−(c²/4t)A` 项与 `G` 的首项 `∝t·w` **负相关**，所以 `K` 被拉低（`K−K₀ = −0.107/−0.228/−0.323` @`a=0.3/0.75/1.2`）。

### 4.2 零点上的一致性（`r01` 的 `ρ_z`，`[T]`+`[E]`，`log [B4]`）

`G(ρ_z)=0 ⇒ H(ρ_z) = βΔ(ρ_z) ≠ 0`，**不需要** `H` 在 `ρ_z` 过零——这正是"仿射与零点集无关"的正确表述；但 `H = K G + C` 本身不成立，所以 `ρ_z` 处的极点只是**推论不是判据**。

### 4.3 `K`、`C` 的闭式（补上 `r01 §4.3` 的"缺失项"，`[T]`）

设 `E[·]≡∫·p dρ`（`p ∝ w e^{−βS}`，`Q04 (1.6)`）。由 (4.1a) 的线性性：

```
E[H]      = K₀E[G] + βE[Δ]                                     (精确)
Cov(H,G)  = K₀Var(G) + βCov(G,Δ)                               (精确)
Var(H)    = K₀²Var(G) + β²Var(Δ) + 2βK₀Cov(G,Δ)                (精确)
```

于是（**这就是 `r01` 的 `K`、`C`，不是拟合参数而是矩的闭式组合**）：

```
K_LS := Cov(H,G)/Var(G) = K₀ + β·Cov(G,Δ)/Var(G)                               (4.3a)
C_LS := E[H] − K_LS·E[G] = β·[ E[Δ] − (Cov(G,Δ)/Var(G))·E[G] ]                 (4.3b)
Var(H) = K_LS²·Var(G) + β²·Var(Δ)·(1 − corr²(G,Δ))                             (4.3c)
1 − R²(仿射) = β²·Var(Δ)·(1 − corr²(G,Δ)) / Var(H)                             (4.3d)
```

`(4.3d)` 说明 `r01` 的 `1−R²` **不是噪声**，而是 `Δ` 在 `{1,G}` 正交补上的精确方差——**可算的误差条**。

## 6. 判死（逐字回答 (a)/(b)/(c)）

```
(a)  H 与 G 严格线性相关?  否。W₁ ≢ 0、W₂ ≢ 0、K_c ≠ K_s ⇒ 严格仿射亦不成立（C 必为 0）。
     ⇒ Var(H)=K²Var(G)、E[H]=KE[G]+C 都不是精确式；判据"Var(G) ≤ K(a)E[G]+C(a) 的精确一维比较"
     **不成立**，r01 的缺口**不能用仿射补**。精确的替代是 (4.3c)(4.3d)：缺口大小 = β²Var(Δ)(1−corr²)，
     可算、≤8e−4·Var(H)，于是判据变成"Var(G) ≤ K_LS E[G]+C_LS + 误差条"的**带条比较**。
(b)  只是近似。残差解析阶 = O(a) 首阶（Δ 是 a 的奇函数，首项见 (4.1c)），a≳0.5 超线性。
(c)  闭式有：K₀=½cot(θ/2)（精确、逐点、β-无关）；K_LS=K₀+βCov(G,Δ)/Var(G)；
     C_LS=β[E[Δ]−(Cov/Var(G))E[G]]；Δ=[t∂_a²−c²/(4t)]A、A=a w(ρ)。
     "点态 K" 的闭式 Q_H/Q_G=½cot(θ/2)+3/a−3a/ρ² 存在但**随 ρ 变**，正是"无常数 K"的证明。
```

**对 `H1` 的含义（诚实版）**：`q04` 的 `[T]` 判据仍是 `a=0` 的**孤立**结论；`a≠0` 上没有任何精确一维代数判据，只有**带显式误差条**的一维求积比较。**仿射结构不带来降维，带来的是缺陷的闭式**。
