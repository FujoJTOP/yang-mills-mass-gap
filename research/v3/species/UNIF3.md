## 1. 这一层到底要什么：三段分解 + 三条引理

### 1.1 三分（把"一致性"这个词拆开）

| # | 一致性在哪 | 内容 | 现状 |
|---|---|---|---|
| U1 | **`a`（= β 尾）** | `∃Δ₀∀a≤a₀: m_{0⁺⁺}(a) ≥ Δ₀`（物理单位） | **承重；= (T4) = H1 的量纲修正** `[M]` |
| U2 | **`L`（每个 a）** | `inf_L m(L,a)>0`，否则 `m_{0⁺⁺}(a)` 未定义 | `β<β₁` 由 SZZ/OS；`2.5` 是墙（`G04:31`）`[M]` |
| U3 | **`a`（相关函数）** | 均匀指数界在极限下不退化（紧性/收敛） | 构造性一半（`C2:376` "alive"）`[O]` |

`G04:70`/`F05:120–137` 已判：**固定 β 下 `a`-一致是平凡的**（a 只是单位）。⇒ U1 的全部内容是 `β`-尾上的统一性，**不是**"a 方向上还有一个额外维度"。

### 1.2 引理 A（尾恒等，`[T]`，零成本）

```
设 β ↦ a(β) 严格单调、a(β)→0（AS）。则
   ∃c₀>0 ∃a₀ ∀a<a₀:  m_{0⁺⁺}(a) ≥ c₀Λ
 ⟺ ∃c₀>0 ∃β₀ ∀β>β₀:  m_{0⁺⁺}(β) ≥ c₀Λ
（纯序算术：a<a₀ ⟺ β>β(a₀)。两边同一量、同一单位。）
⇒ **"a-一致"不是第五个方向，它就是 β-尾-一致。**
⇒ `liminf_{a→0} m_lat/(aΛ) ≥ c₀` 只是把同一句写成无量纲商。
```
这条恒等是本文的枢纽：它同时解释了"为什么 a→0 看起来免费"（左端 a 约掉）与"为什么它不免费"（右端要的正是尾上的一致下界）。

### 1.3 引理 B（传递：两个地板在极限里分岔，`[T]`）

设每个 a 上 OS 正性成立，局域 `O` 的两点函数满足**均匀**指数界
`|⟨O(x)O(0)⟩_a| ≤ C e^{−Δ₀|x|}`（`Δ₀` 与 `a,L` 无关，`|x|` 为物理距离），且沿子列在固定物理点收敛。则极限理论在同一道上有 `supp ρ ⊂ [Δ₀,∞)`。

```
把两种地板分别代入同一条引理：
  常数地板  m_lat ≥ r   ⇒ Δ₀ = r/a → ∞ ⇒ 固定 x 上 e^{−r|x|/a} → 0 ⇒ 极限相关 ≡ 0（平凡）
  比值地板  m ≥ c₀Λ     ⇒ Δ₀ = c₀Λ 固定 ⇒ 极限相关 ≤ C e^{−c₀Λ|x|} > 0（有隙）
⇒ **两个地板的差别不在"强弱"，在传给极限之后：一个变成 0，一个变成 ≥c₀Λ。**   [T]
```
**限定（不许省）**：`[T]` 只在"极限存在 + 相关函数收敛"的前提下；该前提 = U3，属 Clay 的另一半 `[O]`。**没有它，引理 B 一句都不成立**（`DF-CONTINUITY §4.2`：(S) 恒真、(S⁺) 假、只有 (S\*) 能支撑结论，而 (S\*) 的前提就是目标）。

### 1.4 引理 C（标度分离是**推论**，不是假设，`[T]`）

```
地板 m ≥ c₀Λ ⇒ ξ = 1/m ⇒ ξ/a ≤ 1/(c₀·aΛ) ——→∞（AS）
⇒ "scaling window / ξ/a≫1" 不需要单独假设，地板自己生产它。
反向不成立：ξ/a→∞ 对地板零信息（A11:99 的 21% 漂移正是"把一致性当标度"的反例）。
```
这一条把 `A11` 的方法论告警变成一句定理：**在没拿到地板之前，任何 `ξ/a` 的增长都只是"接近地板所在区"的诊断，不是地板的证据。**

## 2. 第一问：比值地板 `liminf m_lat/(aΛ) ≥ c₀` 够不够？

### 2.1 够的部分：它是**唯一合法**的形式（`[T]`）

`RATE-UNIFORM:289–296` 命题 3 + `A5:91–96`：**常数地板型证书不可能 `a`-一致**（引擎 = 分子有 a-无关正下界）。`M05 §3.2` 已证比值形式让引擎缺席；`G05B §4` 给了相容性见证（`m_lat ≡ aΛ` 同时满足"逐 β 有隙"+AF+量纲嬗变，无矛盾）。
⇒ **形式层：比值地板是合法形式的唯一候选，这一半 `g05` 对、`g05b` 对。** `[T]`

### 2.2 不够的部分：它**是**同一句话换单位（`[T]`+`[C]`）

```
m_lat/(aΛ) = (a·m_phys)/(a·Λ) ≡ m_phys/Λ          [T，A04 §2]
⇒ ① "比值是 β-常数"零信息（恒等）；"比值 = 正的常数"⟺ (T4) ⟺ H1 量纲修正  [T]
⇒ ② 与 m>0 的等价只在「极限存在 ∧ 同 Λ」下（M05 §2.1 两读法必须分开记账）[C]
⇒ ③ 引理 B 之外，它不给任何估计：`c₀>0` 是全部内容，`c₀` 的数由文献
     （181 Λ_lat / 6.3 Λ_MS，A04 §2.1、L2）钉，**不是本项目证的**。[C]/[E]
```
判词：**"够"= 陈述形式对；"不够"= 证明义务一点没减。** 它是 `H1` 的量纲修正（`m05` 的话逐字成立），不是新命题。

### 2.3 `liminf` 这个提法的两条加分（本节新增，`[T]`+`[E]`）

```
(A) 不需极限存在：C_n = 6.3+3(−1)^n ⇒ liminf=3.3、limsup=9.3、极限不存在而命题成立（M05 §3.4 已给）。
(B) ★ 免疫强耦合端的平凡化：`ta02` 指出强耦合端比值 18.26/0.4837 = 37.75 ≥ 任何 c₀≲37
    ——单侧、不问物理性、被 cutoff 态"平凡满足"。但 `{β≤1/48}` **不含 a→0 子列**
    （G05 §2.1，经 M05 §3.4 #4 转引）⇒ 该端对 liminf 的贡献**恰为 0**。
    ⇒ M05 把这条记成缺陷（`c₀` 无锚）；它同时是**保护**：
      **"逐 β 满足"可以被平凡化，"liminf" 不能。**
⇒ 比值地板的正确形式必须带 liminf（不是 "∃c₀ ∀β"），这一条有内容、不是装饰。 [T]
```

### 2.4 判（第一问，逐字）

```
形式：够（唯一合法形，[T]）。
内容：不够（= m∝Λ 的恒等改写，正性那一半 [M]）。
传递：另需引理 B 的前提（[O]），否则"比值有界"与"极限有隙"之间没有逻辑通道 [T]。
⇒ 一句话：**比值地板把"错单位的难命题"改写成"对单位的同一难命题"，并删掉一整类错误陈述；
   它不产生估计、不减少 Clay 的目标数。**（与 M05 §6.2、A04 §5 一致）
```

## 4. 判：技术还是本质

### 4.1 先把"两段论"打掉（`[T]`）

```
分法（题面）：段一 = 2.5 上的一致；段二 = AS 取 a→0。
问题：段一对 liminf 的贡献 = 0。
  · 任何**固定 β（含 2.5）**上的结论对 {a→0} 的子列都不构成约束；
  · 强耦合窗的贡献已被判定"恰为 0"（§2.3-B），2.5 若只是**一个点**，同理为 0；
  · 要让段一有用，它必须是"**β≥2.5 的尾**上一致"——而那已经是段二要的东西。
⇒ 段一与段二不是两段，是**一句**：`∃Δ₀∀β≥β₀: m_{0⁺⁺}(β) ≥ Δ₀`。
   AS 只负责把这句话翻译成 `liminf m_lat/(aΛ) ≥ c₀` 的形状（引理 A）。
```

**加一个数（`[E]`，`py -3.12 -c` 现场算，两圈、标准前因子）**：

```
aΛ(β_W=2.5,N=3)=1.068e−1 ；aΛ(β_W=6.0,N=3)=2.346e−3（标定后 3.137e−3，A04 §2.1）
⇒ 同一 AF 流上 aΛ 掉 34–45×。而 ma 在窗内只从 ~1.0 漂到 0.568–1.07
⇒ **比值 m_lat/(aΛ) 在窗内从 ≈9 升到 181–242，升 20–45×——它不是"常数"。**
⇒ 因此"比值地板"若只在 2.5 上成立，**搬不到尾端**；能搬的那条（非下降性）正是 `[NG]`。
   另：2.5 处 ξ/a≈1（H05:90 的 20–50× 偏差同源），两圈 `aΛ` 出域、scaling violation `O(0.32)`
   （A04 §3.3）⇒ **2.5 上连分母都没有可判定的值**。
```
（**口径警告**：A04 §3.1 的"四 β 全等 180.9"是**定义使然**（分子写成 `a·m_phys`）；上表用的是**实测 `ma`**。两者不矛盾，但只有后者的"升起"是动力学信号。）

### 4.2 三分判（逐字）

```
(a) **成立，但范围必须写死**：`a→0` 这一"操作"是技术 —— 引理 A 免费、AS 免费、
    引理 B 在"极限存在"下软、序无关由一致性免费。它**零承重**。
    ⇒ 但由此**不能**得出"Clay 的路是两段"：段一必须是尾-一致（§4.1），不是"2.5 一致"。

(b) **不成立**：`m_lat→0` 而 `m_phys` 固定**不是矛盾**，它是比值地板**要求**的行为
    （`G05B §4` 见证模型 `m_lat ≡ aΛ`：逐 β 有隙 + AF + 量纲嬗变，三者相容 [T]）。
    把这条读成"本质障碍"，等于把 g05 的常数地板判词错搬到比值地板上（`g05b` 已判）。
    附：不存在已知的"把地板逼到 0"的机理；非平凡性反而是地板的**推论**（引理 B）。

(c) **成立，但纠缠是"同一"型**：不是"技术层与本质层互相牵制"，而是
    "a-一致"与"β-尾-一致"是**同一个全称量化**（引理 A）。
    ⇒ 所谓"最后一层"其实是**同一层的另一套单位**：`a→0` 不新增证明义务，只新增**翻译**。
```
