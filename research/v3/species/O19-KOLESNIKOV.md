## 2. 定理的确切陈述（逐字抄，标式号）

### 2.1 设定（§1 开头，逐字）

> Throughout, `n ≥ 2`, and `o` denotes the origin of `ℝ^n`. Let `V ∈ C^∞(ℝ^n)` be **even**, with **`D²V > 0`**, and assume that its **sublevel sets are compact**. Adding a constant, we normalize `V(o) = 0`. The associated log-concave probability measure is
> `Z = ∫ e^{−V} dx`, `dμ(x) = Z^{−1} e^{−V(x)} dx`.
> `Var_μ f = ∫ f² dμ − (∫ f dμ)²`.

经典 BL（同处，逐字）：`Var_μ f ≤ ∫ ⟨(D²V)^{−1} ∇f, ∇f⟩ dμ`。

### 2.2 几何假设 (1.1)（§1.1，逐字）

`K` = 原点对称凸体，`∂K` 光滑、正曲率；`ν` 外法向；`II := D_{∂K}ν`（Weingarten 映射，正定）；`H = tr II`；`φ(x) = ⟨x, ν(x)⟩ = h_K(ν(x))`。对**每个偶函数** `u ∈ C¹(∂K)`：

```
(1.1)   ∫_{∂K} H u² dS + ∫_{∂K} u²/φ dS
         ≤ ∫_{∂K} ⟨ II^{−1} ∇_{∂K} u , ∇_{∂K} u ⟩ dS + (1/|K|) ( ∫_{∂K} u dS )² .
```

（即 `p = 0` 的局部 log-Brunn–Minkowski，取自 Kolesnikov–Milman [10, Prop. 4.6]。）

### 2.3 测试函数类与矩阵 `𝒱`（§1.2，逐字）

> `𝒯 = { f ∈ C^∞(ℝ^n) : f is **even** and constant outside a compact set }`.
> `𝒱(x) = D²V(x) + ∇V(x) ⊗ ∇V(x) / ⟨x, ∇V(x)⟩`, `x ≠ o`；`𝒱(o) = D²V(o)`。
> `ℰ_0(f) = ∫ ⟨(D²V)^{−1}∇f, ∇f⟩ dμ`，`ℰ_𝒱(f) = ∫ ⟨𝒱^{−1}∇f, ∇f⟩ dμ`。
> `D_0`、`D_𝒱` = `𝒯` 在两个 form norm `(‖f‖²_{L²(μ)} + ℰ(f))^{1/2}` 下的闭包。
> "Strict convexity and evenness give `⟨x, ∇V(x)⟩ > 0` for `x ≠ o`."（**这一句就是 even 的全部用处之一**）

### 2.4 主定理（逐字，**式 (1.2)(1.3)**）

> **Theorem 1.1 (A strengthened even Brascamp–Lieb inequality).** Let `V` and `μ` be as above, and assume that (1.1) holds for **every sublevel body `{V ≤ r}`, `r > 0`**. Then, **for every `f ∈ D_𝒱`**,
>
> ```
> (1.2)   Var_μ f ≤ ∫_{ℝ^n} ⟨ ( D²V + ∇V⊗∇V / ⟨x,∇V⟩ )^{−1} ∇f , ∇f ⟩ dμ .
> ```
>
> For `f ∈ D_0`, this is equivalently
>
> ```
> (1.3)   Var_μ f + ∫_{ℝ^n} ⟨(D²V)^{−1}∇V, ∇f⟩² / ( ⟨x,∇V⟩ + ⟨(D²V)^{−1}∇V, ∇V⟩ ) dμ
>              ≤ ∫_{ℝ^n} ⟨(D²V)^{−1}∇f, ∇f⟩ dμ .
> ```

**加强的机制（逐字）**：`𝒱 ≥ D²V` ⇒ `ℰ_𝒱 ≤ ℰ_0` ⇒ (1.2) 右端 **≤** 经典 BL 右端；且 (1.3) "identifies their difference as a nonnegative integral"。
**尖锐性（逐字）**："The coefficient one in (1.2) is optimal over this class of potentials." Proposition 2.1（"Equality under dilations"）：在二阶矩假设下，**`f(x) = ⟨x, ∇V(x)⟩` 取等**。Corollary 3.1：齐次势（`degree > 1`）得**sharp radial remainder**。

### 2.5 回答"它给的是哪一种不等式"

| 问 | 答 | 依据 |
|---|---|---|
| `Var(f) ≤ ...`？ | **是**，方差 / BL 型 | (1.2) |
| LSI？ | **否**。全文无 entropy / log-Sobolev | 正文 |
| Poincaré？ | **否**（Poincaré 是 `Var ≤ C·E|∇f|²`，此处系数是**矩阵** `𝒱^{-1}` 的二次型） | (1.2) |
| 修正项长什么样 | **恰好一项 rank-one**，`∇V ⊗ ∇V / ⟨x,∇V⟩`，**加在 Hessian 上**（在**分母**里 ⇒ 是"加强"）；换成 remainder 形式则是**一个积分**（(1.3) 第二项），分子 `⟨(D²V)^{−1}∇V,∇f⟩²`、分母 `⟨x,∇V⟩+⟨(D²V)^{−1}∇V,∇V⟩`（标量、显式非负） | (1.2)(1.3) |
| `Σ` 几项 | **1 项**（不是按模式/按模态求和）。若有 `Σ` 也只是隐式在 `tr`/`∫` 里 | — |
| 依赖 `Hess` 的哪个部分 | 依赖 `(D²V)^{−1}` **整个逆**（无截断）；rank-one 部分**只依赖 `∇V` 与径向配对 `⟨x,∇V⟩`** ⇒ **方向固定为径向 `r = ∇V/|∇V|`**，与 `Hess` 的特征方向无关 | (1.2) + Sherman–Morrison |

**Sherman–Morrison 展开（本文件自算，`[T]`）**：
```
𝒱^{−1} = (D²V)^{−1} − (D²V)^{−1} r r^T (D²V)^{−1} / ( ⟨x,∇V⟩ + ⟨(D²V)^{−1}∇V,∇V⟩ ),   r = ∇V
```
⇒ 右端 `= ℰ_0(f) − ℰ_0(⟨r,∇f⟩_{D²V})^{... }`，即 (1.3)。**增益是 rank-one，且沿 `r`。**
**Gaussian 校验（`[T]`，本文件手算）**：`V = |x|²/2` ⇒ `∇V = x`、`⟨x,∇V⟩ = |x|²` ⇒ `𝒱 = I + x̂x̂^T` ⇒ `𝒱^{−1} = I − ½ x̂x̂^T` ⇒ `Var ≤ E|∇f|² − ½E[(∂_r f)²]`；取 `f` 径向偶函数得 `Var ≤ ½E|∇f|²`，**正是偶函数在高斯下的最优常数 1/2**（与正文 "For the standard Gaussian measure, the best even coefficient is 1/2" 一致）。⇒ **公式抄对了，不是误读。**

## 3. 前提逐条核 Wilson 测度

**设定**：`Λ ⊂ Z^4` 有限格点，`dμ_W(U) = Z_W^{−1} e^{−S_W(U)} ∏_{ℓ} dU_ℓ`（`dU` = 归一化 Haar），`S_W = β Σ_p (1 − ½ Re tr U_p)`，`U_p = ∏_{ℓ∈∂p} U_ℓ`。**参考测度是群上的 Haar，不是 `R^n` 上的 Lebesgue。**

| # | Kolesnikov 前提 | Wilson？ | 判 |
|---|---|---|---|
| **P0** | 结论只对**偶** `f ∈ 𝒯 = D_𝒱` | H1 要的目标函数是 `f = ∂_vV`；`V` 偶 ⇒ **`∂_vV` 是奇函数** | **❌ 不满足（最硬的一条）** |
| **P1** | `V` **偶**（`V(−x)=V(x)`，线性中心对称，原点固定） | 形式上偶（见 3.1），但**结构性不偶** | **❌ 不满足** |
| **P2** | **log-concave**：`D²V > 0`（在 `R^n` 坐标中严格凸） | 在群坐标上**不凸**（`cos` 型；见 3.2） | **❌ 不满足（且不可修复）** |
| **P3** | `V` 的**下水平集紧、有内点、原点对称、边界光滑正曲率**，且每个 `{V≤r}` 满足 (1.1) | 下水平集**不是凸体**，(1.1) 里的 `II`、`H`、`φ=⟨x,ν⟩` **无定义** | **❌ 连陈述都不成立** |
| **P4** | `V ∈ C^∞(ℝ^n)` | `S_W` 在链变量下**实解析**（`Re tr` 的多项式） | **✅ 满足（唯一通过项）** |
| P5 | 二阶矩假设（Prop 2.1 取等用） | 紧群上自动（`E|X|²<∞`），但与判决无关 | ✅/无关 |
| P6 | `n ≥ 2` + `R^n` 平坦结构（`∇`、`D²`、`x↦rx` 膨胀、`⟨x,∇V⟩`、coarea） | **不存在**：群紧、无全局坐标卡、无原点、无射线 | **❌ 不满足** |

### 3.1 "even" 到底是哪种 even —— 核清

Kolesnikov 的 even **不是**"某个对合下不变"，而是**线性空间里的点反射 `x ↦ −x`（原点固定）**，并且这个 even 在证明里被用在**四处结构性位置**（正文逐字可查）：

1. `⟨x, ∇V(x)⟩ > 0`（`x ≠ o`）——rank-one 项的分母非退化；
2. `{V ≤ r}` 是**原点对称凸体** ⇒ (1.1) 可用（局部 log-BM 只对原点对称凸体陈述）；
3. `𝒯` 里的 `f` 偶 ⇒ "constant outside a compact set" + 层饼分解只在 `r ≥ 0` 上做（"Since `V + εf` is even and vanishes at the origin, its minimum value is zero"）；
4. 取等函数 `f(x) = ⟨x,∇V(x)⟩` 是**偶**的（`∇V` 奇），且沿**膨胀** `x ↦ rx` 是"the derivative of the potential under dilations"。

Wilson 实际拥有的对合（本文件逐条核）：

| 对合 | `S_W` 不变？ | Haar 不变？ | 是哪一类 |
|---|---|---|---|
| `U_ℓ ↦ U_ℓ^{−1}`（逐链取逆 = 复共轭） | ✅ `Re tr U_p^{−1} = Re tr U_p` | ✅ | **群反演**（**非线性**）；`U → U^{−1}` 在本项目语境中对应 `A → −A` |
| `U_ℓ ↦ −U_ℓ`（全体链同时） | ✅ 广场是链的**二次**式 ⇒ `(−U)_p = U_p` | ✅ | 线性，但 `−I ∈ SU(N)` **仅 N 偶**；`SU(3)` 上**不是群的自映射** |
| `U_ℓ ↦ z U_ℓ`（`z ∈ Z_N`，中心变换 = 中心值规范变换） | ✅（中心元 ⇒ `gU_pg^{−1}=U_p`） | ✅ | 群内平移，**不是 `x→−x`** |
| 格点反射 `x ↦ −x` | ✅ | ✅ | **时空**对合，不是群空间对合 |

⇒ **判**：Wilson 的"even"是真的（`U→U^{−1}` 与 `U→−U` 都给 `S_W` 不变），但**它是群上的非线性对合 / 中心平移，一个都不提供上面 1–4 那四样东西**：没有原点、没有射线、没有膨胀族、下水平集不是凸体。
⇒ **P1 = 不满足**。O17 §4.1 写的"evenness 白送"**判错**：白送的只是"某个对合下不变"，定理要的是"线性中心对称 + 原点 + 射线 + 膨胀"。**同名不同物。**

### 3.2 "log-concave" —— 两条独立死路（任一即死）

**死路甲（局部、逐点、`[T]` 本文件自算）**：沿"把某条链乘 `e^{tA}`"的曲线，某个广场的 holonomy 角 `θ_p(t)` 线性移动（`θ_p' ≠ 0`），
```
d²/dt² S_W = β [ cos θ_p · (θ_p')² + sin θ_p · θ_p'' ] .
```
在 `θ_p = π`（`θ_p'=1, θ_p''=0`）处得 `= −β < 0`。⇒ **`Hess S_W` 在正测度集上不定**（任何含 `Re tr U_p < 0` 的广场的构型）。这正是任务里点出的 `cos` 型障碍。
**注**：Savvidy 的 `λ_min(Hess S_W) = −g|B| < 0` 是它在**连续极限、微扰真空附近**的同一条事实的另一种呈现；不需要引入 Savvidy 就已经死。
**并且**：`cos` 型不可能靠"取对数/换变量"变凸——`1 − cos θ` 在 `θ ∈ (π/2, 3π/2)` 上凹，且 `e^{−β(1−cosθ)}` 在 `[0,2π)` 上**双峰**。

**死路乙（全局、与坐标无关、`[T]`）**：`S_W` 的零集（全局极小）包含微扰真空的 `Z_N` 轨道：对 `z ∈ Z_N`，构型 `{U_4 = z, U_i = 1}` 有 `S_W = 0`（时间-空间广场 `z·1·z^{−1}·1 = 1`，空间广场 `=1`），且**规范不等价**（Polyakov 圈 `tr P = z·N ≠ N`），两两在任意双不变度量下相距 `O(1)`。
⇒ 对充分小的 `c > 0`，`{S_W ≤ c}` **至少含 N 个互相分离的连通分支 ⇒ 不连通**。
⇒ **凸函数的下水平集必连通** ⇒ 不存在任何坐标卡使 `S_W` 全局凸 ⇒ **换坐标不可能把 Wilson 化成 log-concave**。（换度量：定理要求的是 `R^n` 的**平坦**结构与凸体二阶基本形式；改成 Riemannian / Bakry–Émery 的"测地凸"就**不是这条定理**，且双不变度量下 `S_W` 沿测地线仍不凸——圆周上的 `1−cos θ` 就是最小反例。）

**额外一条（参考测度）**：群上参考测度只能是 Haar；在极大环面的指数坐标里 `dU = Lebesgue × J(A)`，`J(A) = ∏_{α>0} (sin⟨α,A⟩/⟨α,A⟩)²` 型，**在 Weyl 墙上为零** ⇒ 即便写 `dμ = e^{−V_eff}dA`，`e^{−V_eff} = J·e^{−S_W}` 在墙上**不可微、不严格正** ⇒ **严格 log-concavity 连局部都不成立**。`[T]`

⇒ **P2 = 不满足，且不可修复。**

### 3.3 其余（P3/P6）

(1.1) 的每一件装备都是 `R^n` 的：`II = D_{∂K}ν`、`H = tr II`、`φ = ⟨x,ν⟩ = h_K(ν)`、`|K|`。Wilson 的下水平集 `{S_W ≤ r}` 是非凸闭集（由死路乙不连通），**没有"凸体边界"可言** ⇒ (1.1) **不是"难验证"，是无定义**。
`D²V`、`⟨x,∇V⟩`、`x ↦ rx`、coarea、层饼 `Z_ε = ∫_0^∞ A(r,ε)e^{−r}dr` 全部依赖 `R^n` 的原点与线性结构；紧群上无全局坐标卡 ⇒ **P6 不满足**。

## 4. 判：能用 / 需额外假设 / 不适用

### 4.1 主判：**(c) `[NG]`** —— 它是"对凸势"的定理，Wilson 不是凸势

**它确实是关于凸势的定理，明说**：设定第一行 `D²V > 0`（**严格凸**），且 §2.2 证明确实用到"`V + εf` 对充分小 `|ε|` 严格凸"（"For sufficiently small `|ε|`, the function `V + εf` is strictly convex"）——**证明本身就在凸性上做扰动**。这不是可以绕开的正则性假设，是定理的引擎。

**Wilson 不满足，四条独立死因（任一即足）**：
1. **P0**：定理结论只覆盖**偶** `f`；H1 需要的 `f = ∂_vV` 是**奇**的。⇒ 定理**字面上不覆盖我们的目标量**。
2. **P1**：even 是结构性的（原点/射线/膨胀/原点对称凸体），群反演与中心平移一样都不给。
3. **P2**：`cos` 型 ⇒ 不凸；且 `Z_N` 分支 ⇒ 不可换坐标修复。
4. **P3**：(1.1) 在非凸下水平集上**无定义**。

### 4.2 就算把 1–4 全"假设掉"，它也补不上 Savvidy —— 方向不对 `[T]`

由 §2.5 的 Sherman–Morrison：加强**恰好是 rank-one、沿 `r = ∇V/|∇V|`（径向、即下水平集的法向）**。
Savvidy 的负模是**横向磁**（落在 `ξ` 的纤维里，与"径向"无必然关系）。
⇒ **一个 rank-one 修正无法消掉一个 `rank-(n−1)` 的不定性**；即便 Savvidy 的负模恰是 rank-one（LLL 单个模），它的**方向也不是径向**。⇒ **形状对得上，方向对不上，机制不对。**
⇒ **修正 O17 §4.1(iii)**：O17 写"Savvidy 不稳定模是低秩 ⇒ 与'给 Hessian 加一个 rank-one 正项'的形状对得上"。**该句作废**：Kolesnikov 的 rank-one 是**径向**的（`∇V⊗∇V/⟨x,∇V⟩`，分母里的 `⟨x,∇V⟩` 就是径向导数），定理能看到的**只有**沿 `r` 的那一个方向，**对横向一个字的力都使不上**。

### 4.3 唯一"半能用"的退化区：局部 Lie 代数卡 + 截断 —— 且它过不了自由场酸测

在**一个真空的邻域、一个基本域、截断**之后：`S_W` 沿 `A → −A` **偶**（`U = e^{iA}`），`Hess S_W|_0 = ` 格点 Laplacian `+ O(A)`，在该邻域内**正定**（除规范零模）⇒ 局部像 log-concave。
但：(i) 下水平集**无界**（规范平坦方向）⇒ "compact sublevel bodies" 不成立；(ii) Haar 的 `J(A)` 不 log-concave；(iii) **截断丢掉的正好是非微扰内容**。
并且**退化后的界就是** `Var ≤ E⟨(Δ + O(A))^{−1}∇f,∇f⟩`，即**自由场 Poincaré / 微扰 Gaussian** 界 —— **对自由无质量场不失效 ⇒ 过不了"自由场酸测"**（`CLAUDE.md §1`）⇒ **作为工具 `[NG]`**。
