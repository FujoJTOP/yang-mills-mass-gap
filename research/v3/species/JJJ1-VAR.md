## §1 变分形（核验）

### 1.1 三条同值写法（同一条 min–max）`[T]`
```
(i)   g := 1−λ₂ = min{ ⟨f,(1−T_a)f⟩ : f ⊥ Ω, ‖f‖ = 1 }          ← 本判；本文件 §1.2 给证
(ii)  Δ_a = min{ ⟨φ,H_aφ⟩/‖φ‖² : φ ⊥ Ω, φ ≠ 0 }                 GH1-SPECTRAL.md:129   [T]
(iii) m = inf_f ½∫|∇f|²dρ / Var_ρ f (= Poincaré 常数)              B06-VAR.md:29         [T]
      Δ_a = −(1/a)·ln(1−g)   逐字（因 λ₀=1）；三条同值 ⇒ `Δ_a`/`m`/`1−λ₂` 是同一个数（`B01-RP.md:44–47`）
```

**证（三行，`[T]`）**：`A := 1−T_a` 自伴有界 ⇒ 谱定理给 `inf σ(A) = inf_{‖f‖=1}⟨f,Af⟩`；`T_a` 自伴 + `Ω=ker(1−T_a)` ⇒ `Ω⊥` 不变、`H = Ω ⊕ Ω⊥` 约化 ⇒ 该 `inf` 等于 `1 − sup σ(T_a|_{Ω⊥}) = 1−λ₂`。∎ **用到的与没用到的**：只用到**自伴**；**没用到**紧、正性、`β`、`W` 的位形形式。紧只用于"`λ₂` 是可数第二本征值"（`FFF4-LAM1.md:38` 的 HS 论证）；不紧时读成 `λ₂ := sup σ(T_a|_{Ω⊥})`，恒等式照旧。

### 1.2 `⟨f,(1−T_a)f⟩` 确是 Dirichlet 形（且取等）`[T]`

`⟨f,T_af⟩_μ = C_q(ae₀)`、`⟨f,f⟩_μ = Var_μ(q)`（`FFF4-LAM1.md:28`，转 `PP3-TRANSFER.md:24`）⇒

```
E_a(f) := ⟨f,(1−T_a)f⟩_μ = C_q(0) − C_q(a) = ½∬(f(U)−f(V))² K_a(U,V) dμ dμ  ≥ 0
```

⇒ 题面"`⟨f,(1−T_a)f⟩` 是一个 Dirichlet 形"**逐字对且可取等**；`K_a>0` 处处 ⇒ `E_a(f)=0 ⟺ f` 常数 ⇒ `g=0 ⟺ λ₂=1`（无隙）。

**1.3 唯一假设（须随结论携带）**：`Ω⊥` 不变性由 `T_a` 自伴 + `Ω=ker(1−T_a)` 给出（`B01-RP.md:11`）。若只给"正核"而不给自伴，`inf` 会落到 `Ω` 上 ⇒ 右侧恒 `0`，§1.1(i) **不成立**。

## §2 等价（一行判 + 反例）

**判（一行）**：`Δ_a ≥ δ ⟺ g ≥ 1−e^{−aδ}`（`[T]`，纯代数）；`g ≥ aδ ⟹ Δ_a ≥ δ`（`[T]`）；**反向假**（`[NG]`）⇒ "精确等价于谱隙 `≥ aδ`" 为 `[NG]`。

```
Δ_a = −(1/a)\ln(1−g)  ⇒  Δ_a ≥ δ ⟺ g ≥ 1−e^{−aδ} = aδ − (aδ)²/2 + O((aδ)³)
                      ⇒  g ≥ aδ  ⟹  Δ_a ≥ −(1/a)\ln(1−aδ) ≥ δ        （充分，不必要）
                      ⇒  g = 1−e^{−aδ} ⟹ Δ_a = δ 而 g < aδ            （反例族，逐 (a,δ) 可造）
```

**反例（`[T]`，零 MC）**：取 `T = P_Ω + (1−g)P_⊥`（自伴、`0≤T≤1`、`T1=1`、`λ₀=1` 单重、`g` 连续填满 `(0,1)`）。取 `a=1`、`δ=1`、`g = 1−e^{−1} = 0.6321205588…` ⇒ `Δ_a = −\ln(e^{−1}) = 1 = δ`，而 `g = 0.6321205588 < 1 = aδ`。⇒ **"谱隙 `≥ aδ`" 假、`Δ_a ≥ δ` 真**：两命题不同值，等价性 `[NG]`。

**错在哪一行**：题面写 `1−e^{−aδ} ≥ aδ`（"小 a"）。展开 `1−e^{−x} = x − x²/2 + …` **恒 `< x`** ⇒ 该不等式**方向反**；正确的小 `a` 形是 `g ≥ aδ(1−aδ/2)`。仓内正确版在 `FFF3-MPHYS.md:56–59`（`1−λ₂ ≥ δa²(1+o(1))` 一侧），与本判一致。**下一手**：凡出现"谱隙 `≥ aδ`"的句子，逐条换成 `1−e^{−aδ}`；两者差 `(aδ)²/2 − O((aδ)³)`，`a→0` 时相对差随 `a` 消失，但**逐 `(a,δ)` 不是同一命题**。

## §3 可算性（判据 + 精确障碍）

**判（一行）**：变分形**不给**可算下界（`[NG]`）。方向：`g` 是 `inf` ⇒ 任一试态给 `g ≤ E_a(f)` ⇒ `λ₂ ≥ 1−E_a(f)` ⇒ `Δ_a ≤ −(1/a)\ln(1−E_a(f))`，即 `Δ_a` 的**上**界（`GH1-SPECTRAL.md:129–130`；`FFF4-LAM1.md:20,31`；`B06-VAR.md:32–34` 的 RB-2 方向定理：下界只能来自形式比较）。

**判据（要可算下界，需下列之一；变分形只替代其中的书写，不替代其输入）**

