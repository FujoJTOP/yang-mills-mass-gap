## 0. 判词（先给答案）

**不是同一个对象。** `m_G′` 与 `E[H_vv]` 只差一个可精确写出的项：

```
m_G′(a) = d/da E[G_v|a] = E[H_vv|a] − Var(G_v|a) − Cov(G_v,Φ′_v|a)          [T]
```

**判据（为什么不对等）**：`a` **确**是沿 `v` 的坐标（`a=⟨v,X⟩`），故 `∂_a G_v = ∂_v²S_W = H_vv` **逐点**成立（`[T]`，实测 rel `≤2.3e−11`）；**但条件期望的导数 ≠ 导数的条件期望**——切片测度沿 `a` 变化，积分下来的额外项就是 score 项 `−Cov(G, ∂_aV) = −Var(G)−Cov(G,Φ′)`。两者相等**当且仅当** `Cov(G,∂_aV|a)=0`（纤维测度沿 `a` 平移不变，如高斯/无作用量），本模型不满足。

**数值仲裁（`β=2.5, θ=π`，同一模型、同一 `a` 参数化、同一次求积）**：`a=0` 上 `E[H_vv|0]=0.000000`（精确），而 `m_G′(0)=−0.069117`。**两者在同一 `a` 上给出 0 与 −0.069，故不同**（残差核对恒等式 `≤6.9e−6`）。

**判死线**：**(a) 不触发** —— 没有"`m_G′≥0` 已证"这回事，`G″(0)≥0` 链条**不因 `p05` 闭合**，**不构成重大结果**；**(b) 成立**；**(c) 成立**（`θ=π` 上 `p05` 的 `[T]` 精确给 0 = 退化）。

## 3. 判 `(a)/(b)/(c)`

**(a) 不触发。** 前提"`m_G′ = E[H_vv]`" **假**（§0/§2：同一 `a=0` 上 `0` vs `−0.0691`）。因此 **`p05` 的 `[T]` 不能给 `m_G′≥0`**，`−Cov` 窗口合并不出 `G″(0)≥0`，**链条不闭合**。**这里没有重大结果**——恰恰相反，本文件拒绝了那条看起来要闭合的链。

**(b) 成立：`m_G′` 是"条件平均力的斜率"，`p21` 的 `−0.13…−0.40` 是真的，不是参数化假象。** 逐项归因（`a=0.75`）：
```
m_G′ = E[H|a] − Var(G|a) − Cov(G,Φ′|a) = (−0.1816) − (0.0697) − (−0.0114) = −0.2399
        └ 曲率(在 a≠0 上已负)   └ 力方差(恒负贡献, 主导)   └ 交叉项(正, 3–5%)
```
- `a=0` 上 `Cov=Var(Φ′)=0`（运动学，`Φ` 只依赖 `ρ`），故 **`m_G′(0) = −Var(G|0) = −0.0691` 精确到差分误差**：`θ=π` 的负性**全部**来自条件力方差，与曲率无关。
- `−0.069 … −0.404` 与 `P21` 的 `−0.131…−0.404`（`a∈[0.25,2]`）逐点一致（差 `≤1e−4`），且 `a→0` 时它连续趋于 `−0.0691` ⇒ **不是参数化差异，是同一个量**。
- `ch15-uvface.tex:29` 早就写明这件事："The conditioning sets `E[H|a₀]=0` at the barrier and **exposes the negative force variance**"——`p05` 与 `p21` 的"张力"在论文里已有正确读法：**条件化把曲率清零、把力方差暴露出来**。

**(c) 成立，且必须明说。** `θ=π` 时 `p05` 的 `[T]` 给的是 **精确 `0`**（`E[H_vv]=β(c/2)G(B)`，`c=cos(π/2)=0`；实测 `0.000000`，逐点 `max|H|=0`）⇒ 那是**退化值**，即使退一步把两者当同一对象，`θ=π` 上也只得到 `m_G′ ≥ 0` 的平凡上界 `0`，**推不出任何正性**。**`m_G′ ≥ 0` 只能在 `θ<π` 上争取**（那里 `E[H_vv|0]=β(c/2)G(B)>0` 是真下界），而即便在 `θ<π`，因 `(b)` 的不等号，`p05` 仍**不足以**给 `m_G′≥0`：需要的是
```
m_G′ ≥ 0  ⟺  Var(G|a) + Cov(G,Φ′|a) ≤ E[H_vv|a]                       [T]
```
即在**条件化层面**把力方差压到条件曲率之下——`H1` 的力扇区版，`P21 §2` 已定位的同一步。实测 `θ=π`：`a=0` LHS `+0.0691` vs RHS `0`（FAIL）；`a=0.75` LHS `+0.0583` vs RHS `−0.1816`（FAIL）。

## 4. 结论（一句话交接）

`p05` 与 `p21` **不矛盾**：`p05` 的 `[T]` 是 `a=0` 切片上的**曲率**正性（`θ=π` 退化为 0），`p21` 的负数是**条件平均力的斜率**，恒等式 `m_G′ = E[H_vv|a] − Var(G|a) − Cov(G,Φ′|a)` 把两者精确分开。`m_G′ ≥ 0` 的缺口**没有被 `p05` 填上**，仍精确等于 `Var(G|a)+Cov(G,Φ′|a) ≤ E[H_vv|a]`。**`G″(0)≥0` 链条未闭合**；本文件拒绝了一个错误的合并，这是净收获（防止把 `p05` 的 `[T]` 误记成 `m_G′≥0`）。
