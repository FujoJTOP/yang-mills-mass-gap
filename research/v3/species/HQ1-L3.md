## §1 把 `L3` 写成一行式

### 1.1 一行式（承重面 = 矩面）

```
L3^{UV} :
  ∃ a₀(L)>0   ∃ {C_n(L)<∞}_{n≤n₀}   ∀a ∈ (0,a₀(L)]   ∀n ≤ n₀   ∀f₁,…,f_n ∈ C_c^k(B(0,L/4)) :
        | S^{(n)}_{L,a,β(a)}( f₁,…,f_n ) |  ≤  C_n(L) · ∏_{i≤n} ‖f_i‖_{C^k}          (U1)  a-一致 L^p 界
                                                                                     (U2) 同一 scheme 常数 C 的 a^{-4} 减除
  ∧     Z_{L,a}(f) := Σ_n i^n/n! S^{(n)}_{L,a}(f^{⊗n}) 在 0 处 a-一致等度连续            (U3) n! 增长：C_n(L) ≤ A^n n!·P(L)

  等价记法（生成元面，同一格）：
        sup_{a≤a₀(L)}  Z_a^{-1} ‖ H_a ‖_D  <  ∞ ,      D = smeared 规范不变核,  ‖ψ‖_D = ‖ψ‖ + ‖Fψ‖
```

- **对象**：重整化后的 Schwinger 矩族 `{S^{(n)}_{L,a,β(a)}}`（**不是**测度本身，也不是算子的范数）。
- **量词**：`∀n, ∀f_i, ∀a≤a₀(L)`；**`L` 固定**；`β = β(a)` 沿 RT/方案 C 被 `a` 决定（不是自由量词）；`U′`（粗边界）**不出现**——它只出现在充分条件 `(★)` 里。
- **拓扑**：`(C_c^k)'` 上的 **weak-***（Banach–Alaoglu 相对紧 + 可数对角子列），极限经 **Minlos** 实现成概率测度；`k` = 检验函数的 `C^k` 阶。
- **含量词但不在 `L3` 里的两件事**：`L`-一致（那是 `UVS-L`，另一条，`glue-a-limits/REPORT.md:64,137`）；谱隙（任何形式都不出现）。

### 3.2 为什么不是"全部"（两条非蕴含，各带见证）

**(I) `(A-phys) ⇏ L3`** —— 零阶 vs 一阶。
强预解收敛是**零阶**（`C⁰`）陈述；`L3` 是 `a=0` 处 `log T_a` 的 **`O(a)` 系数**的一致界。
反例之刃：`T_a=diag(1,e^{−c₁a},e^{−c₂a})` —— 一切裸矩阵元 `→1`（同一极限 `I`），而 `c₁≠c₁'` 给出不同隙；**"对恒等于常数的极限求 `a`-导数，信息为零"**（`BREAK-IN-9.md:14`；`glue-b-blocking/REPORT.md:285`）。⇒ 任何只消费 `‖T_a−T‖→0` / Schwinger / 弱收敛的论证**原理上**给不出 (II)。
（注：该族本身**满足** `L3`（`H_a=diag(0,c₁,c₂)` 有界），所以它不是"`L3` 假"的见证，而是"收敛 ⇏ 一阶矩"的见证——两者必须分开记。）

**(II) `L3 ⇏ (A-phys)`** —— 缺 (a) 与唯一性。
`L3` 给的是 `{S^{(n)}}` 的**子列**弱-* 极限 + Minlos（`glue-a-limits:66–87`），加上 GL4/OS 得 `(H_L,T_t,ν)`（`G1-CONTINUUM-OS:3,5`）。要把它变成 `(A-phys)` 的 `Ĥ_a→H` 强预解，还差：
- **唯一性 `W1`**（全收敛，非子列）：`glue-a-limits:75`；`uniqueness/REPORT.md:117`（它的引理链里的 `L3` = "唯一极限点 ⇒ 收敛"，**又一个同名异物**）。
- **`ι_a` 的 L² 识别**：`BREAK-IN-9.md:12`（`ℋ_a≇ℋ`，任意 `ι_a` 改变算子与谱）；`GK5:227`（靶算符 `A∈L²(μ)` 由 tightness/`UVS` 供给，不由 RP 供给）；`HZ8 §1.4(a)`（判 `[NG]`，"具名缺步 = 连续极限存在性 G1"）。

### 3.3 为什么不是"无关的一格"（正向：`L3` + 已证格 ⇒ 测度层全部）
