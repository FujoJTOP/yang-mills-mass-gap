## §2 标度判定

### 2.1 指数不可辨，因为振幅为零 `[NG]`

```
χ̃ = A·L^p ，A 由 L=4 锚定（A = χ̃₄/4^p）
 p=−2 : A=+0.1236  L=6 预测 +0.0034 vs 实测 −0.0230±0.0390 (0.7σ) ; L=8 +0.0019 vs +0.0000±0.0967 (0.0σ)
 p= 0 : A=+0.0077  L=6 预测 +0.0077 vs 实测 −0.0230±0.0390 (0.8σ) ; L=8 +0.0077 vs +0.0000±0.0967 (0.1σ)
 p=+2 : A=+0.00048 L=6 预测 +0.0174 vs 实测 −0.0230±0.0390 (1.0σ) ; L=8 +0.0309 vs +0.0000±0.0967 (0.3σ)
```

三族**全过**。判据不是"噪声大"：L=4 的 σ=`0.0157`，是 `C(0)` 的 `0.0042` 倍，足以在 L=4 分辨任何 `|χ̃|≥0.05` 的结构；不可辨的唯一原因是**振幅本身为零**。故按题设：`χ̃ ≲ 噪声` ⇒ **空转**（`[NG]`，对具名类"`k_min` 投影作为 β=2.5、L≤8 的光模探测器"）。

**"空转"≠"工具盲"**：同一估计量对 `f²=1` 的自由行给出 206σ/69σ/21σ 的偏离（§2.2）。这里空转的是**信号**，不是分辨力——与 HR1 对 `χ_flat` 的 `[NG]` 同型（β=0 与 β=2.5 返回同一个数），但零点从 `3.72` 移到了 `0`。

**`[NG]`**：`χ̃` 在 L=4,6,8 上都是 `0 ±(0.016…0.097)`，无 L 依赖；`L²`、`L^0`、`L^{−2}` 三族在零振幅下不可分。保留的正面产物只有两条：`⟨χ̃⟩_BZ≡0`（§0.4 恒等式）与 `f²≤0.055`（§2.2）。下一手：换 `C(0)=1/N²` 的 plaquette 载体（接触项小 15 倍），或补 L=8@β=2.5 的 N=4000 模组把 σ 压到 0.03。
