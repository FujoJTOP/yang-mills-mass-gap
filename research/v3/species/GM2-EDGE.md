## §2 三条边缘态专属攻法

### 2.1 (a) 变分/最小性：`⟨[H_a,·]⟩₁` 能不能逼出 `δ₁ = 0`？

**命题 A1（对角性，`[T]`）.** 设 `A` 有界、`ψ₁` 是 `H_a` 的边缘本征向量。则

```
⟨[H_a, A]⟩₁ = ⟨ψ₁|H_aA − AH_a|ψ₁⟩ = (Δ_a − Δ_a)⟨ψ₁|A|ψ₁⟩ = 0 .        (A1)
```

**⇒ 一阶条件/任意交换子的边缘期望恒为零，对 `A = K₂+H³/24` 与对 `A = 1` 给的是同一句废话。** 这一步没有任何内容。

**命题 A2（唯一能咬的形态，`[T]`）.** 若 `K₂ + H³/24 = [H, X] + c·1`（`X` 有界、保 `D(H)`、`ψ_n` 在其定义域内），则对 `H` 的**每个**本征态

```
⟨φ_n|K₂+H³/24|φ_n⟩ = c        ∀n .                                (A2)
```

*证.* `⟨φ_n|[H,X]|φ_n⟩ = ⟨Hφ_n|Xφ_n⟩ − ⟨Xφ_n|Hφ_n⟩ = 0`（同本征值），加 `c⟨φ_n|φ_n⟩`。∎

⇒ **"用一阶条件/维里恒等式逼 `δ₁=0`" 这条路，必须证明一条状态无关的命题**：`⟨K₂⟩_n = −Δ_n³/24 ∀n`，即 `K₂ = −H³/24` **在 `H`-对角上逐态成立**——这**就是**自由场身份（`GK2-SYMBOL.md:124`：`K₂ = −ω³/24`，`H = ω`），而且它比 `(SM-2)` **严格强**（`(SM-2)` 只要 `n=1` 一个态）。

**命题 A3（A2 的前件一般假，`[E]`）.** 2 能级：`H = diag(Δ,Δ₂)`、`K₂ = diag(κ,κ₂)`。(A2) 要求 `κ = −Δ³/24` **且** `κ₂ = −Δ₂³/24`——两个独立方程、一般不解。数值取 `Δ=1.7, Δ₂=3.1, κ=−0.41`：`δ₁ = κ+Δ³/24 = −0.205292 ≠ 0`（`(SM-2)` 要求 `κ = −0.204708`）。⇒ **A2 在一般模型上假 ⇒ 一阶条件在一般模型上不能逼出 `δ₁=0`。**

## §3 符号判定：在边缘态上能不能定 `c₁` 的号

### 3.1 精确的号归属（`[T]`）

```
c₁ = ⟨K₂⟩₁/Δ_cont ,        δ₁ = ⟨K₂⟩₁ + Δ_cont³/24 .                (3.1)
```

- `Δ_cont > 0` ⇒ **`sign(c₁) = sign(⟨K₂⟩₁)`**。
- `(SM-2) ⟺ ⟨K₂⟩₁ = −Δ_cont³/24 ⟺ c₁ = −Δ_cont²/24 < 0` ⇒ **`(SM-2)` 成立 ⇒ `Δ_a < Δ_cont`**（小 `a`）。
- 反过来：定出 `c₁ < 0` **不**蕴含 `(SM-2)`（后者要的是**精确值** `−Δ²/24`，不是号）。⇒ **号是 `(SM-2)` 的粗影子，不是它本身。**

### 3.2 无条件判词：**判不出**（`[NG]`），三条证书

**(c-1) 无保护机制。** 唯一已知的机制是 `K₂ = −H³/24` 逐算子（自由场，`GK2-SYMBOL.md:124`），它使 `A ≡ 0`；YM 上 `K₂` 含 `F、D` 的局域片，**无候选**使它成为 `H` 的函数。⇒ `⟨K₂⟩₁` 是一个**自由矩阵元**。
**(c-2) 未算矩阵元的竞争（`Θ`-偶时奇次片消失，剩两项）。** `⟨K₂⟩₁ = ⟨K₂^{kin}⟩₁ + ⟨K₂^{odd}⟩₁ + ⟨K₂^{ev}⟩₁`，其中协变动能片 `≤ 0`（形式负定，`GK2-SYMBOL.md:172`）、`trF³` 片无号、`trF⁴` 片 `≥ 0`（`[M]`：归一未定，`:174` 自注 + `:324` 第 5 条），再加固定 `+Δ³/24`。**三个都未算**，且片的清单**未穷尽**。
**(c-3) 号不是谱量。** C2：`c₁` 只依赖 `P₁K₂P₁`；把 `Δ₂` 从 `1.9` 改到 `5.0`，`c₁` 一位不动（`[E]`）。⇒ 任何"从低谱推断号"的论证都踩空。

### 3.3 边缘化为什么没把号一起便宜掉（本轮对"边缘专属"这条削弱路线的边界判定）

`gk2` 的"`K₂` 三片不共号"是**算子层**的困难。边缘化只把**量词**从 `sup_ψ` 降到"1 个数"，**不改变算子的符号结构**：`⟨K₂⟩₁` 仍是那个不定算子的一个矩阵元。

> **判**：**号的困难在结构层，不在量词层。** ⇒ "只在最轻态上判"这条削弱路线对 `(SM-2)` 的**存在性**有效（0.1），对它的**符号**无效。这是本文件对任务书最重要的边界修正。

### 3.4 条件版：可以定，但前件比 `(SM-2)` 还硬（`[C]`）

若

- **(H-Θ)** 边缘落在 `Θ`-偶扇区，`Θ: U_ℓ ↦ U_ℓ^{-1}`（Haar 测度与 Wilson 作用的对合；朴素连续极限下 `A→−A`、`F→−F`）⇒ 奇次片（`∝trF³`）的边缘期望 `=0`；

两条都**未证**：
- **(H-Θ)** 的物理版本就是 `IN-11` 的 "C-even、P-even 扇区"条款（`docs/conditional-theorem.md:207` 逐字；`A2-IN11.md:26` 明写"**物理输入，不可由 bootstrap 导出**"）；且 `Θ` 与 `C` 是否**逐字**同一映射，本轮**未核** `[O]`（对 `SU(2)`，`tr U_p ∈ ℝ` ⇒ 领头 `Θ`-奇局域算符可能**恒为零**，奇次片可能本来就不存在 `[M]`）。
