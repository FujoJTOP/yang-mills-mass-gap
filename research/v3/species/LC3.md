
**不是两套序列，是同一串 `#Γ` 的两个统计量被贴错标签。** `tn2` 的 `a_n = 1,20,458,11132,280175` 与 `ur4` 的 `#Γ` **逐位相同**（`UR4.md:92–99` 的 `a_n` 列同值）；`20→25.70→28.69→30.53→31.77` 是 `m_n = Σ|φ^U|` 的比（`UR4.md:14` 自己写的就是 `m_n/m_{n−1}`），**不是 `#Γ` 的比**。两步在 `n=2` 重合只因 `|φ^U|≡1`（`m_2=#Γ_2=20`），从 `n=3` 起 `mean|φ^U| = 1.122 → 1.325 → 1.607 → 1.982` 把两列拉开。`[E]`

**⇒ 判死线 `(a)` 不触发**：同一个序列 ⇒ **`tn2` 没有用错序列，`25.2` 不作废**。**`(b)` 触发但形态是"标签错位"而非"算错"**：`ur4` 侧的表没有算术错误（`a_n` 列与 `m_n` 列本来并列），错的是把 `m` 列读成 `a` 列的那一句转述。**`(c)` 给出 `m_n` 的比（上）**，但见 §3：`m_n` 的**率**该读 `m_n^{1/n}`（`n=6` 是 `15.58`），比列本身未收敛。

**`λ_*` 该用 `#Γ`**：`P3:89` 逐字为 `#\{connected m-sets through x\} ≤ λ_a^{m}` —— 被计数的对象是**集数**，不是加权质量 ⇒ `λ_* ≳ 25.2`（`n=5` 是 `25.168`，`n=6` 抬到 `25.765`），**不是 `≳31.77`**。`31.77` 属壳质量槽（§3）。

## 2 · 是不是同一个序列（第二问）

三条独立判据，指向同一结论：**是同一个序列（`#Γ`），不是两条序列。**

1. **整数逐位相同**：`tn2` 的 `a_2..a_5 = 20,458,11132,280175`（`TN2.md:111–114`）= `ur4` 的 `#Γ_2..#Γ_5`（`UR4.md:92–99` 的 `a_n` 列）= `ur4_enum_n6.json` 的 `sets`。三处同值 `[E]`。
2. **`n=2` 的重合有解释**：`|φ^U| = 1` 对**所有** `2`-片集成立（只有 `C(20,1)`-型树），故 `m_2/m_1 = #Γ_2/#Γ_1 = 20`；两列从 `n=3` 起必分岔，实测分岔量 `= mean|φ^U| = m_n/#Γ_n`：`1.000, 1.000, 1.122271, 1.324829, 1.607049, 1.981753`。`[E]`
3. **量级不可混**：`m_6^{1/6}/#Γ_6^{1/6} = 15.580645/13.901997 = 1.121`，而比列 `31.7727/25.7652 = 1.233` —— 差的是**同一个** `mean|φ^U|` 因子，不是两个不同的组合族。

**⇒ `tn2` 的 `a_n` 是 `#Γ`（过定点连通 `n`-片集数），`ur4` 的 `m_n` 是 `Σ|φ^U|`。问"`tn2` 的 `a_n` 是哪个序列"的答案是：就是动物计数序列本身，没有替换。** 若硬要说"错"，错在**转述层**把 `ur4` 的 `m` 列（`UR4.md:14`：`m_n/m_{n−1}`）称成了"`#Γ` 的比"。

## 3 · `λ_*` 该用哪个（第三问）

语料里有**三个不同槽**，本轮把它们钉死（这是冲突的真正来源：`25.2` 与 `31.77` 分属两个槽）：

| 槽 | 逐字定义 | 该读的量 | 实测 |
|---|---|---|---|
| `λ_a`（`P3:89`，`= λ_T`） | `#\{connected m-sets through x\} ≤ λ_a^{m}` | **`#Γ` 的比** | `≳25.168`（`n=5`），`n=6` 抬到 `25.765` `[E]` |
| `λ_Ur`（`TT2:150,213`） | `limsup (|φ^U(Γ)|)^{1/|Γ|}`（**逐簇**上确界） | `max|φ^U|^{1/n}` | `2.220906`（`n=6`，`K_6` 取到）`[E]` |
| `λ_Ur^{mass}`（`TT2:150` 的 `q`） | `lim m_n^{1/n}`（**壳质量**率） | `m_n^{1/n}` | `≥15.580645`，外推 `24.54`(`1/n` 拟合)/`37.93`(比列拟合) `[E]`+`[X]` |

* **`λ_*`（动物生长常数）用 `#Γ` 的比** —— `P3:89` 的被计数对象就是集数；套 `m_n` 的比等于把 `|φ^U|` 的**重数**再乘一遍（`mean|φ^U|` 已从 `1.12` 长到 `1.98`，`n≥7` 还会长），是把"重数"错记进"计数常数"。`[T]`（口径）+ `[E]`（数）
* **`31.77` 属壳质量槽，且它不是该槽的极限读数**：`m_n/m_{n−1}` 单调升但升幅仍大（`5.70, 2.99, 1.84, 1.24`），`m_n^{1/n}` 也仍在升（增量 `3.47→2.07`）。两种外推互不相等（`24.54` vs `37.93`）⇒ `λ_Ur^{mass}` 的点值**未定**，只能说 `∈[15.58, ≲38]`（与 `UR4.md:109` 同口径，本轮独立复算 `24.540 / −54.34` 逐位相同）。`[E]`+`[X]`
* **`λ_Ur`（逐簇）不是 `λ_a`**：`2.2209 ≪ 25.17`，差 `11.3×`；`TT2:152` 的"取 `λ_Ur ≤ eΔ`"是把逐簇上确界与包络混用，本轮不改 `TT2` 结论（`q<1` 仍不成立，因为它要的是 `λ_Ur^{mass}`），只标出槽位。

### 严格下界（诚实线，`AGENTS §2.3`）

严格可证的只有根检验：`λ ≥ #Γ_6^{1/6} = 13.901997`；`≳25.168` 是"比序列单调升 + 继续升"的**趋势读数**（`[C]`，不是定理），`n=6` 的 `25.765211` 把趋势读数又推高一点。**无论取哪一个，`1/λ_*` 都 `> 1/48`**：`1/25.1684 = 0.039732 = 1.907×(1/48)`；若误用 `31.7727`，`1/λ = 0.031474 = 1.511×(1/48)` —— 结论方向不变，但数字差 `1.26×`，所以槽不能混。`[E]`

## 4 · 判死线落点（第四问）

* **(a) `tn2` 用错序列、`25.2` 作废 —— 不触发。** 同一个 `#Γ` 序列，逐位相同（§2）。**`25.2` 不是作废，是"被 `31.77` 顶掉"的误判。**
* **(b) 同序列而数值不同 —— 触发，但归因是标签错位，不是算错。** `ur4` 的 `25.70/28.69/30.53/31.77` 与其表内 `m_n/m_{n−1}` 逐位一致（`UR4.md:14,98–99`），其 `a_n` 列与 `tn2` 的 `a_n` 也逐位一致 ⇒ 两文件的算术都**没有**错；错的是把 `ur4` 的 `m` 列冠以"`#Γ` 的比"。`[E]`
* **(c) `λ_*` 该用 `m_n` —— 对动物常数不成立；对壳质量槽成立。** 若问的是 `TT2:150` 的 `q = λ_Ur^{mass}·u`，则必须用 `m_n`：比列 `20 / 25.70 / 28.69 / 30.53 / 31.77`，**并把率读成 `m_n^{1/n}=15.58`（`1/n` 外推 `24.54`）**，而不是把比列末项当极限。

**⇒ 一句话**：冲突是**列错位**，不是序列不同、也不是算术错误；`λ_* ≳ 25.2`（`P3:89` 的 `λ_a` 口径），`31.77` 属 `λ_Ur^{mass}` 的比列、且不构成该槽的极限读数。
