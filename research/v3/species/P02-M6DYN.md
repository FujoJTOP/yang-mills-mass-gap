## §1 `E[H]`：`ω/2`，良定义；"基态不可归一"**不**使它无定义

**先钉死字母**。`Δ_dyn` 的公式 `E[H]−Var(G)`（`T01:35`、`ch05:230–240` 逐字 `Δ_dyn = E[H]−Var(G)`）里的 `H` 是
`H_{vv} := ∂_v²V`、`G_v := ∂_vV`、`V = S_W + Φ`，`E[·] = E[·|ξ=0]`（`ch05:233`、`ch15:23`、`P01-WHATG:77`）。
**它不是 Hamiltonian**。所以"`E[H]` 在非归一基态上良不良定义"这个问法本身是**字母撞车**，两个对象要分开算：

| 对象 | 精确值 | 良定义？ | 理由 |
|---|---|---|---|
| `E_ham[H] = inf spec H` | **`ω/2`** | **是** | `spec(H) = {(n+½)ω} ⊕ {2π²k²/C²}`（`U09-M6:28`）；`b` 零模（`k=0`）能量**恰 `0`**，`a` 底态 `ω/2` ⇒ 底 = `ω/2`。`[T]` |
| `E[H_vv]`（有效指数读法，§3 R1） | **`2ω`** | **是**（有限、正则无关） | `V_eff = −log ρ_a = ωa²` ⇒ `V_eff″ = 2ω`，确定性量。`[T]` |
| `E[H_vv]`（含动能的全作用读法） | `2/ε + εω²`（`ε`=格距） | 发散，**但与 `Var(G_v)` 同发散、差 `2ω` 有限** | `P01-WHATG:93` 已给该表；本文件 §3 用**闭环判据**把它定位为"同一 `Δ_dyn` 的另一种拆分"，不是另一个数。`[T]` |

**为什么"`b` 方向基态不可归一"不构成障碍（这是本条的核心）**：把 `b` 放到周长 `C` 的环上（`ψ₀ = φ₀^{HO}(a)·C^{−1/2}`，可归一），则
- `E_ham[H] = ω/2` **对每个 `C` 都精确成立**（`[E]`：`C=10,100,1000,1e5` 一律 `1.000000000000`，见 log §1(b)）；
- `Rayleigh 商 ⟨ψ₀|H|ψ₀⟩/⟨ψ₀|ψ₀⟩` 的分子分母同为 `O(C)`，比值 `= ω/2`，**`C`-无关** ⇒ 取 `C→∞` 得 `ω/2`，**不是 `0/0`**；
- 变的是**谱**：`m_C = min(ω, 2π²/C²) → 0`（`C=10: 1.97e−1` → `C=1e5: 1.97e−9`），`spec → [ω/2,∞)` 连续。`[T]`

⇒ **`E_ham[H] = ω/2`（不是 `ω/2+0` 的"含糊"，`b` 加的是**精确**`0`，也不是无定义）。**
**连带判掉一个诱惑**：把 `E_ham[H]=ω/2` 与 `Var(a)=1/(2ω)` 配成 `Δ_dyn`（§3 的 R5）会得 `(ω²−1)/(2ω)`，在 `ω<1` 上**为负**——那是**量纲混用**（`E₀` 是能量，`∂²V` 是场空间曲率，二者不同维，`P01-WHATG:112` 逐字"`H=∂_v²S` 是指数的曲率，不是能量"）**制造出来的假 (b)**。§3 表里给数（`ω=0.7 → −0.364`）。

## §2 `Var(G)`：`G` 是什么，就决定 `Δ_dyn` 是几

`G` **不是** `G(v;a) := −log ρ_v(a)`（那是**势**，方差恒 `0`，`P01-WHATG:62` 已判死），**是力** `G_v = ∂_vV`。逐模列表（`‖v‖=1`）：

| `G` 的取法 | `Var(G)` | `Δ_dyn = E[H_vv] − Var(G)` | 判 |
|---|---|---|---|
| `∂_aV_eff = 2ωa`，**条件化 `a=0`**（语料口径） | `0` | **`2ω`** | ✓ 闭环 ① |
| `∂_aV_eff = 2ωa`，**无条件化** | `2ω` | **`0`** | 自洽但**非**语料口径（`E[G_v]=0` 那条 Ward 才是无条件化的用法；数值上 `P02-DYNDYN` 用的是**约束 HMC**，即条件化） |
| `∂_bV = 0`（`V` 与 `b` 无关） | `0` | **`0`** | ✓ |
| `a`（坐标，非力） | `1/(2ω)` | `2ω − 1/(2ω)`（若 `H_vv=2ω`） | `0`-内容：这只复述 `Var(a)`；`G″=1/Var(a)` 的等价形，**不是独立读法** |
| `E₀`（Hamiltonian 值） | `0`（定态） | `ω/2` | 量纲混用，见 §1 末 |

⇒ **`G := a` 时 `Var(a)=1/(2ω)` 只是 `G″ = 1/Var(a)` 的另一半**（`G″·Var=1`，`[E]` 逐 ω 核到 `1.0`）；它**不**给出"`Δ_dyn` 的另一种值"，因为 `Δ_dyn` 的自变量是 `H_vv` 与 `G_v`，而 `G_v` 是力的方差、不是坐标的方差。**`P01` 说的"`G` 待定"在本文件这样定：`G = G_v = ∂_vV_eff`，`v` 是粗模方向。**

## §3 `Δ_dyn` 的精确值：闭环判据**唯一**选出 `R1`

`W_full = 0`（§5）⇒ 语料恒等式 `G″ = Δ_dyn + W_full`（`ch05:235–237`）在 M6 上**退化为 `Δ_dyn = G″ = 2ω`**。这是"closure ①"（`P01-WHATG:123` 的第①关）。逐读法验：

| # | 读法 | `E[H]` | `Var(G)` | `Δ_dyn` | closure ① `Δ_dyn = G″=2ω`? |
|---|---|---|---|---|---|
| **R1** | 有效指数 `−logρ`，条件化 `ξ=a=0` | `2ω` | `0` | **`2ω`** | **✓（残差 `0`）** |
| R2 | 有效指数，无条件化 | `2ω` | `2ω` | `0` | ✗（差 `2ω`） |
| R3 | 裸势 `½ω²a²`，条件化 | `ω²` | `0` | `ω²` | ✗，`|ω²−2ω| = 1.25 (ω=2.5)` |
| R4 | 裸势，无条件化 | `ω²` | `ω³/2` | `ω²(1−ω/2)` | ✗；`ω=2.5 → −1.5625` **（假 (b)）** |
| R5 | `E_ham[H]` 配 `Var(a)` | `ω/2` | `1/(2ω)` | `(ω²−1)/(2ω)` | ✗ 量纲；`ω=0.7 → −0.364` **（假 (b)）** |

`[E]`（`log §3`）：`ω=2 / 2.5 / 0.7` 上 R1 `= 4 / 5 / 1.4` 精确等于 `2ω`；R3 `= 4 / 6.25 / 0.49`；R4 `= 0 / −1.5625 / 0.3185`；R5 `= 0.75 / 1.05 / −0.3643`。

**判决（`[T]`）**：**`Δ_dyn(M6, v=∂_a) = 2ω > 0`，`ω>0` 恒正。** R2/R3/R4/R5 全部落在 closure ① 之外或量纲之外；其中 R3/R4/R5 会在某些 `ω` 上给出**负值**，**那是自造 (b)，不得当成"M6 上 `Δ_dyn<0`"读**（这是本文件最重要的防伪线：`(b)` 一旦被这样"证出"，`Δ₀>0` 就被假复活）。

**为什么 R1 是"退化"而不是"有内容"（必须写明）**：对**任何 Gaussian 边缘** `ρ ∝ e^{−κa²/2}`，条件化后 `G_v = κa` 在 `ξ=a=0` 上是**确定性零**，故 `Var(G_v|0) ≡ 0`、`E[H_vv|0] = κ = G″`。⇒ **"`Φ=0 ⇒ W_full=0 ⇒ Δ_dyn = G″"是平直测度 Gaussian 模型的恒等式，不含任何关于 `m` 的信息**：自由场（`κ=0`）同样满足，只是给 `0`。**M6 的 `2ω>0` 的全部内容 = "`a` 方向有质量 `ω`"。**

## §4 ★ 量词：`Δ_dyn` 是**方向依赖**的，`inf_v Δ_dyn = 0`

**命题（`[T]`，Gauss，`‖v‖=1`）**：`a~N(0,σ_a²)`、`σ_a²=1/(2ω)`；`b~N(0,σ_b²)` 独立；`v = (cosθ, sinθ)`；`ξ = ⟨v,X⟩`。则
```
E[H_vv|ξ=0] − Var(G_v|ξ=0)  =  H_vv − (H_vv − 1/Var(ξ))  = 1/Var(ξ)
                            = 1/(cos²θ·σ_a² + sin²θ·σ_b²)  =  G″(θ) .
```
（`H_vv = cos²θ/σ_a² + sin²θ/σ_b²`；`Var(G_v|0) = H_vv − 1/Var(ξ)` 是 Schur 补。）
**三路互核**（`log §4`：闭环式 / Schur 式 / 对 `ρ_ξ` 直接二阶求导）：`θ ∈ {0°,15°,45°,89°}` × `σ_b²∈{1,100,1e8}`，最大残差 `8.8e−32`。`[E]`

- `θ=0`（纯 `a` 模）：`Δ_dyn = 2ω`，**与 `σ_b²` 无关**（`σ_b²=1/1e8` 都给 `4.000000000000`）。
- `θ≠0`：`Δ_dyn = 1/(cos²θσ_a² + sin²θσ_b²) → 0`。`σ_b²=1e8, θ=45°`：`2.0e−8`。
- **M6 字面（`b∈ℝ`，Lebesgue）**：`σ_b²=∞`。不需任何调节子：沿含 `b` 分量的模，`V` 与 `b` 无关 ⇒ `H_vv = 2ωcos²θ`、`G_v = 2ωcosθ·a`，而切片约束 `a=−tanθ·b` 上 `Var(b|0) = 1/(2ωtan²θ)` ⇒ `Var(G_v|0) = 2ωcos²θ` ⇒ **`Δ_dyn = 0` 精确**（`θ=90°` 平凡：`H_vv=G_v=0`）。

⇒ **`Δ_dyn` 在 M6 上不是一个数，而是一族：`{2ω}`（`a`-模）`∪ {0}`（含 `b` 分量的模）。`inf_v Δ_dyn = 0`。**（`P01-WHATG:96` 已写 `inf_v Δ_dyn = min(2ω,0)=0`；本文件把它变成逐向可核的恒等式，并给出 `θ` 连续族的闭式。）

## §5 `Φ=0` 核对（`n12` 那句逐字对不对）

1. **`Φ` 是什么**：`Φ := −log J`，`J` 是 Haar 测度在指数坐标 `U=e^{iX}` 下的 Jacobian（`ch15:23–28`、`P01-WHATG:66`、`U09-M6:46`）。它是**运动学**的（与 `β`、与动力学无关），`W_geo = E[Φ″]−Var(Φ′) ≥ 0` 的 Prékopa 内容全部来自它。
2. **M6 里 `Φ` 是几**：M6 的场是 `(a,b)∈ℝ²`，测度是 **Lebesgue**（`U09-M6:46` 逐字"平直测度，坐标无 Jacobian 权"）⇒ `J≡1` ⇒ **`Φ≡0`**（常数项不影响任何导数）。⇒ `Φ′≡Φ″≡0` `[T]`。
3. **`⇒ W_full=0` 吗**：`W_geo = E[Φ″]−Var(Φ′) = 0`、`X = −2Cov(G_v,Φ′) = 0` ⇒ `W_full = W_geo+X = 0` **精确**。**`n12` 这一句对。** `[T]`
4. **`N/12` 分支**：`W_geo ≥ (N/12)‖v‖²` 是 **SU(N) 紧群 Haar** 的 Prékopa 下界；M6 **没有群、没有 `N`** ⇒ 该下界**无指称**，谈不上"`≥N/12`"（`P05-M6EQ:17` 同判）。所以 `n12` 选 `W_full=0` 这一支是对的，两难是伪的。
5. **必须补的一句**：`Φ=0 ⇒ Δ_dyn = G″` 的**真理由**不是"`W_full` 没了"（那只是移项），而是 §3 末那句：**平直测度 + Gaussian 边缘 ⇒ 条件化后 `Var(G_v|0)≡0`**。所以 `Δ_dyn=G″` 在**一切**平直测度 Gaussian 模型上成立（自由场给 `0=0`），**它是一条零信息的恒等式**，不是"M6 上算出了 `Δ_dyn`"。`[T]`

## §6 判死线（逐条落到数上）

- **(a) 成立（点读法）**：`Δ_dyn(M6, ∂_a) = 2ω > 0`（`ω=2 → 4`，`ω=2.5 → 5`，`ω=0.7 → 1.4`），而 `m=0`（`m_C = min(ω,2π²/C²) → 0`）。⇒ `Δ₀>0` 在无隙模型上成立 = **假阳性** ⇒ **`n12` 对**。**但见 §4.1：这条只在"点读法"下成立；按靶自己的 `∀v` 量词 M6 反而是"靶为假"。**
- **(b) 不成立**：**没有任何自洽读法给 `Δ_dyn<0`**。会给出负值的只有 R4（`ω>2`）与 R5（`ω<1`），两者分别破 closure ① 与量纲（§3）⇒ **是自造的 (b)，不得用来复活 `Δ₀>0`**。
- **(c) 不成立**：`Δ_dyn` **良定义**（有限、正则无关；两种读法都得 `2ω`）。`b` 方向的不可归一只让**联合**态范数发散，而 `E_ham[H]=ω/2` 与 `Δ_dyn=2ω` 都与它无关（§1）。**所以"四模型测试对 M6 不适用"这句不成立**——M6 是四模型里口径最干净的一个。
