### §1.4 生成函数（本轮构造；R2 语料只写"可试的靶"）

根片 `p₀`：4 条 link，每条"空 or 5 个候选中取 1"。非根片：父 link 已被父片占掉，只剩 3 条自由 link，同样每条"空 or 5 取 1"。

```
F(x) = x·(1 + 5G(x))^4        （根型：4 条自由 link）
G(x) = x·(1 + 5G(x))^3        （非根型：3 条自由 link；父 link 的另 4 片被 (L4) 封死）
⇒ F = G + 5G²  (因 x = G/(1+5G)^3)
G_n := [x^n]G = (1/n)·C(3n, n−1)·5^{n−1}
F_n := [x^n]F = (1/n)·[ C(3n,n−1)5^{n−1} + 10·C(3n,n−2)5^{n−2} ]
```

**为什么 `F_n` 是 `|𝒯_n|` 的上界**（与语料 `(P2)` 同一机制，`UR6:90`）：一个嵌入树 `A` 唯一决定一个"带标签结构"——每条边记下"父片的哪条 link（4 选 1）+ 该 link 的 6 个槽位中父片之外的那 5 个里哪一个（5 选 1）"；标签可由 `A` 唯一恢复（`p₀` 的 4 条 link 与每条 link 的 6 个槽位都有典范编号），反向由标签逐层走回嵌入 ⇒ **单射**。`F_n` 数的是**所有**带标签结构（含碰撞/成圈的），故 `|𝒯_n| ≤ F_n`。`n=2` **取等**：`F_2 = 20 = a_2`，与语料"首比恰为 20"的整数论证同型（`CB6:16`、`ADJ2:44`）。

### §2.1 精确常数 `135/4 = 33.75`（`[T]`）

单变量奇点分析（`P(u) = (1+5u)^3`，`u*` 解 `P(u) − uP'(u) = 0`）：

```
P(u) − u·P'(u) = 1 + 15u + 75u² + 125u³ − (15u + 150u² + 375u³)
               = 1 − 75u² − 250u³ = (1 − 10u)(1 + 5u)²          ← 精确因式分解
⇒ u* = 1/10（简单根；u = −1/5 为重根，非奇异方向）

κ(R2) = 1/x* = 135/4 = 33.75                                      [T]+[E]
```
