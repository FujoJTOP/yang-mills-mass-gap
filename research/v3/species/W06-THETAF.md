## 1. `θ=π` 上 `E[H]→0` 的机制：不是"数值小"，是**逐点恒零**

`N=2` 闭式（`O15:70–71`，`[T]`，非拟合）：

```
E[H|0](2,θ) = (β/2)·c·⟨A₀⟩_c ,   A₀|_slice = sin(ρ/2)/ρ > 0
⇒ E[H|0]=0 ⟺ c=0 ⟺ θ=π (mod 2π)，对一切 β 精确
```

更强、且是**解析**的（本文新增，`[T]`）：`H1A §2.1` 的作用
`S = β(1 − cos(ρ/2)c + sin(ρ/2)s·a/ρ)`，其中 `ρ=√(r²+a²)`。
`a→−a` 下 `cos(ρ/2)` 偶、`sin(ρ/2)a/ρ` **奇**。⇒ `c=0` 时 `S−β` 对 `a` 是**奇函数** ⇒ `∂²_a S|_{a=0} ≡ 0` **逐点** ⇒
`H_vv(a=0,θ=π) ≡ 0`、`E[H]≡0`，而 `G_v(a=0)=−β sin(r/2)/r ≠ 0`。
这与 `P22-MG-HVV.md:82` 实测「`max|H|=0`」逐字一致，并给出其**原因**：不是 `p05` 的 `[T]` 恰好给 0，而是**切片对称性**强迫。

⇒ 在 `θ=π` 上，H1 的两边退化为 `Var(G) ≤ 0 − a²Δ₀²`，而 `Var(G)=0.0691>0`（`O28:31`）。
**这个失败对一切 `β` 成立、且与动力学无关**——它是"在对称点比较一个恒零的曲率项"的必然结果，与 `P22` 判 `p05` 在 `θ=π` 给的是「精确 0 = 退化」同型。

`N≥3` 时零点**离开** `θ=π`（`O15:14`：`θ_c/π = 0.9333 (N=3,β=2.5)`、`0.8851 (N=4,β=2.5)`）：`⟨A₁⟩≠0` 使
`E[H|0]=(β/N)[⟨A₀⟩+(1−c)⟨A₁⟩]` 在 `θ>θ_c` 为负（`β=2.5`：`N=3` 在 `θ=π` 给 `−0.0265`）。
**注意这不是新动力学**：`O15` 式 (1) 说明 `H_vv` 对 `(c,s)` **逐点仿射**、系数 `A₀,A₁,A₂` 与 `θ,β` 无关（`[V1]` 相对误差 `5.7e−8`）。
⇒ 一切 `θ`-符号翻转都是**两个纯切片泛函的线性插值**；`E[H]=0` 的"曲面 `θ_c(N,β)`"是 `(c,β)` 平面里的**等值面**，不是物理相界。这正是"坐标性"的精确含义。

## 2. `θ` 不是 `v`：H1 的量词里根本没有 `θ`

- `v` 是**粗模方向**（`k→0` 的横模；本模型 `v=e₃`），H1 对它取全称；`θ` 是**冻结的三条 link 的 holonomy**，即块的**环境**。单 plaquette 模型把环境冻在一个点 `B` 上，等于对邻居场做 **δ-条件化**。
- 因此 `θ`-族是一族**条件分布**，H1 是关于**边缘分布**的陈述。二者的差别不是记账问题：混测度会引入 `E[Var]+Var(E[G|θ])` 的**外加方差项**，所以"逐切片都真 ⇒ 边缘也真"**不成立**（`[T]`，全方差公式），判 `(b)` 不能靠这句话免费拿到。真正撑住 `(b)` 的是**直接测出来的周期类结果**，见 §3。
- 语料对"要不要对所有边界成立"已有判决：`ch15:46`「the **uniform-in-`a₀` form** of (★) is false `[LN]`」——边界/条件化点取全称的加强版早被判死；`o28` §0.3 把同一逻辑用到 `a`。`θ` 的全称版属**同一族加强版**。

## 4. 判：`(b)`

**(b) 成立。** `θ ≳ 0.7π` 的失败**不是** Yang–Mills 的物理内容，而是**两件事的叠加**：

1. **边界条件伪影**：`θ` 是冻结环境的 holonomy，不是 `v`、不在 H1 量词里；固定 `θ` 的切片是**条件分布**，`ch15:215–218/227–229` 自己就把固定边界类判为**非物理**，把 `θ`-散布判为 **chart artifact**；周期类上无零点（`H1D:16`）。
2. **`θ=π` 的退化**：`c=cos(θ/2)=0` ⇒ 测度恰 Haar、`H_vv(a=0)≡0` **逐点**（§1，`[T]`）⇒ H1 在那里退化成 `Var≤0`，对一切 `β` 必假。这不是"反例"，是**在对称点评估一个恒零正项**。

**同一条判死线的另一半必须逐字写下**：**若**把 `θ` 读成 `v` 的一部分（即"H1 要对块环境的一切 holonomy 成立"），**则落 `(a)`：失败是真的，且是 H1 的固有缺陷**——`N≥3` 的 `E[H]<0` 区（`θ>θ_c`，`E[H]` 到 `−0.2348`）**不是**退化，`Q03 §4` 的「`E[H]<0` 的点上 `Var>E[H]` 对一切 `β`」在那里是真反例。该读法并非可忽略的诡辩；但它正是 `ch15:46` 已标 `[LN]` 的"边界一致加强版"，**不是论文里 H1 的陈述**（`app.tex:182–189`）。

**`(c)` 不适用**：`θ` 的地位在语料里**明确**（`ch15:37` 一句话里同时点了 `boundary holonomy B` 与 `mode v`；五份文件一律写"固定边界 holonomy `θ`"）。

## 5. 必须在同一份文件里记的窗口与限制（`AGENTS.md §2.1`）

1. **`0.7π` 是网格值，不是阈值。** `Q03:42` 的 `θ` 网格只有 `{0, ½, 0.7, 1}π`；「`θ≳0.7π` 整片」是**两个格点**（`0.7π`、`π`）。`A=Var−E[H]` 的零点在 `(0.5π, 0.7π)` 内**从未被定位**（`[NG]`）；`O15` 的 `θ_c(N,β)` 是 `E[H]=0` 的零点，**不是** `A=0` 的零点，二者不可互引。
2. **`N=2` 的 `θ=π` 恰是 `A>0` 的最"干净"来源**，也恰是最退化的一点；用它当"结构性失败"的证据会**高估**失败的面积。`N=3/4` 的负区（`θ>θ_c`）才是非退化的那一块——而它落在 `θ∈(0.89π,2π)`，即**逼近 `−I` 图表边**。
3. **`(b)` 的标签是 `[C]`，不是 `[T]`**：周期类无零点只在 `3D L=1` 模型上测到；4D 的 `(L,a)`-一致下界仍是 H1 本身（`ch15:234–237`，`[M]`）。**"失败是伪影"不等于"H1 已证"。**
4. **`p05` 在 `θ=π` 的 `[T]`（`E[H_vv]=0`）与本文 §1 的 `H≡0` 是同一件事**，不构成新的张力；`P22` 已判那是退化值。
