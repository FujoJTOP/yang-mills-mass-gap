## §1 T4 的尖锐常数（精确）

### 1.1 被算的对象（与 GC1 §3.4.2 同一归一，逐字）

取常链接族

```
U_1 = exp(i α T^1),   U_2 = exp(i α T^2),   T^a = σ^a/2,  tr(T^aT^b)=δ^{ab}/2
aA_1 = α T^1,  aA_2 = α T^2   （常 lift；"α = |aA|"）
U_□(α) = U_1 U_2 U_1† U_2†   （精确矩阵积，无 BCH 截断）
Φ := i[aA_1, aA_2]  ⇒  (1/2)|tr Φ²| = α⁴/4        （连续统磁项，常 lift 的精确 F）
```

GC1 的 `R(α)`（`GC1-NEW.md:253`）就是

```
R(α) := [N − Re tr U_□(α)] / [(1/2)|tr Φ²|] ∈ [0,1],       R(0)=1   (1.1)
T4*  := sup_{α∈(0,2π)} |1 − R(α)|.                                (1.2)
```

`R(0)=1` 是**归一条件**（小场匹配），它把 `(1.1)` 的常数钉死，因此 `R` 是**无量纲、`g`-无关、`N`-无关**的函数。

### 1.2 SU(2)：闭式（三行证明）

记 `c = cos(α/2)`、`s = sin(α/2)`、`n⊥m` 单位向量、`k = n×m`。用 `(n·σ)(m·σ) = i k·σ`：

```
U_1U_2      = c² + i s c (n+m)·σ − i s² k·σ
(U_2U_1)†   = c² − i s c (n+m)·σ − i s² k·σ
⇒ U_□ = (c² − i s² k·σ)² − (i s c (n+m)·σ)² − [c²−is²k·σ, isc(n+m)·σ]
      = [cos α + ½ sin²α] + i[−2s²c² k − 2s³c (m−n)]·σ
⇒ Re tr U_□ = 2cos α + sin²α   ⇒   2 − Re tr U_□ = 2 − 2cos α − sin²α = 4 sin⁴(α/2).   ∎
```

于是

```
R(α) = 16 sin⁴(α/2) / α⁴.                                    (1.3)   [T]
```

### 1.3 `sup = 1` 的精确陈述（不依赖"到奇点上取值"）

三条，全 `[T]`：

1. **分子非负、且零点唯一**：`Re tr M ≤ N` 对 `M∈U(N)`，等号 ⇔ `M=1` ⇒ `N − Re tr U_□ = 0 ⇔ U_□ = 1`。
2. **`R` 在 `[0,2π]` 严格单调降**：`d log R/dα = 2cot(α/2) − 4/α < 0`（`tan x > x`，`x=α/2∈(0,π/2)`）。⇒ `inf_{α∈(0,2π)} R = lim_{α↑2π} R = 0`，且 `sup_{α<2π}|1−R| = 1` **在光滑部分就取到（作为 sup）**，不需要在奇点上赋值。⇒ GC1 §5.3 #2（`GC1:329`「`0.9573` 是可用点」）对 `α=4` 成立，但**对 sup 不成立**：`0.9573` 是"`α≤4` 上的 sup"，不是"可用点上的 sup"。
3. **上界**：`R = Σ_i(1−cos θ_i)/[(1/2)Σ_iθ_i²] ≤ 1`（逐特征值 `1−cos θ ≤ θ²/2`），其中 `θ_i` 是 `Φ` 的特征值。⇒ `0 ≤ R ≤ 1`，`|1−R| = 1−R`，`sup = 1 − inf R = 1`。

**⇒ T4\* = 1（精确，非极限近似值 `0.999…`）。**

### 1.5 S1 / S2：为什么尖锐常数与方案无关，而 GC1 的 `0.9573` 是**方案内的采样**

- S1 的磁项逐字是 `(1/(g²a))Σ_p(N − Re tr U_p)`（`GM1-ALGEBRA.md:61`）⇒ `R(α)` **就是** (1.3)。
- S2 的磁位能是 `B = −log T_P`（`GP1-DESIGN.md:61–65`），一个 `U_p` 的类函数，与 `(1/(g²a))(N−Re tr U_p)` 有 `O(g²)` **相对**修正（同一 `GP1-DESIGN.md:64` 的 `(A+B)+a²K₂` 展开里 `B` 已是全阶）。⇒ S2 里 `R^{S2}(α) = R^{S1}(α)·(1+O(g²))`。
- **但 sup 仍是 `1`，且这不需要算 `T_P`**：只需两条结构事实——(i) `B ≥ 0`、`B(U_p)=0 ⇔ U_p = 1`（磁位能的极小唯一）；(ii) 分母 `(1/2)|tr(a⁴F²)|` 四次无界。⇒ 对**任何** Wilson 型完成（S1、S2、以及任何 `f(U_p)` 型改进作用量），截口处 `R = 0`、`|1−R| = 1`。**这是 `[T]` 级的结构结论，不依赖 `T_P` 的显式。**
- 反过来：`GC1` 的 `0.9573` 是 **S1 的 Wilson 磁项**在 `α=4` 的值；把它当"Y[M 的尖锐常数"是**方案内采样 + 截断 sup** 的双重口径（`[M]`）。

### 1.6 从"能量密度比"到 `ε_a^{form}`：电稀释只给 `O(g²)`，不给"同量级"

GC1 §3.4.3（`GC1:271`）写"全形比值 `≤` 磁扇区值，但同量级 `O(1)`"。**前半对，后半要精确化**：

```
A := 𝔮_a(ψ) = A_el + A_mag,    B := 𝔮(ιψ) = B_el + B_mag
A/B = (A_el + A_mag)/(B_el + B_mag) ≥ R(α)   （因 R≤1、A_mag = R·B_mag）
|1 − A/B| = (B_mag − A_mag)/(B_el + B_mag) = (1−R)/(1 + B_el/B_mag).       (1.6)
```

- 截口处 `A_mag = 0`；`B_mag`（连续统磁项）与 `A_mag`（格点磁项）**同带 `1/g²` 前因子**，但截口处后者**分子为零** ⇒ `A_mag/B_mag = R = 0`，**与 `g` 无关**（GC1 的"`g²` 相消"在这一层逐字成立）。
- 电项**只通过比值 `B_el/B_mag`** 进入 `(1.6)`。在 `B_mag` 的单位下、用 `A_el`、`B_el` 同源（同 spread）估：`B_el/B_mag = O(g⁴/δ²)`，`δ` = 态在无量纲场 `ξ=aA` 方向的宽度（取 `O(1)`）。**这是量级估计，前因子未算**（`[C]`＋`[M]`；本文件不重算 KS↔连续统的测度匹配常数）。
- ⇒ `|1 − A/B| = 1 − O(g⁴/δ²) ≥ 1 − O(g²)`，沿标度窗 `g²(a) ~ 1/(β₀log(1/a)) → 0` ⇒

```
liminf_{a→0} sup_ψ |𝔮_a(ψ) − 𝔮(ι_aψ)|/𝔮(ι_aψ)  ≥  1 − O(g²(a))  =  1.      (1.7)  [C]
```

**读法**：电扇区**不**把 T4 压回 `O(1)` 的"某个 `0.9`"；它把 `1` 变成 `1 − O(g⁴/δ²)`（保守界 `1 − O(g²)`）。⇒ 在标度窗里，全形比值**同样**顶到 `1`。GC1 的 `[C]`（"电扇区抵消未定"）本轮**部分关闭**：抵消存在，但是 `O(g²)` 的**赤字**，不是 `O(1)` 的救赎。

## §2 三条路：逐条判

### 2.1 (a) 改识别 `ι_a` —— **拓扑障碍（Gribov），不是技术缺口**

**要求写清**：要把 (1.2) 的 sup 从 `1` 降下来，`ι_a` 必须满足

```
∃ε<1 ∀ψ:  𝔮(ι_aψ) ≤ (𝔮_a(ψ) + b‖ψ‖²)/(1−ε).                        (2.1)
```

对 T4 的族 `ψ = φ_α`（常链接 `U(α)` 上的窄波包），(2.1) 要求

```
𝔮(ι_aφ_α)/𝔮_a(φ_α) ≤ 1/(1−ε) + o(1)   对 α ↑ 2π 一致.                 (2.2)
```

但左边在典范图表下是 `1/R(α) → ∞`。**要把它压回来，`ι_a` 必须把 `U(α) → U = −1`（`S_W ≡ 0` 的平坦配置）映到一个 `trF² = 0` 或 `O(1)` 的连续统联络。**

**这正是"规范协变截面"的要求，而它不存在**：

1. `U = −1`（全链接）的 lift 不唯一：**同一个**格点配置（`S_W = 0`）既可以 lift 成 `aA_1 = πσ^1`、`aA_2 = πσ^2`（**正交** ⇒ `tr(a⁴F²) = −7.7927e+2`），也可以 lift 成 `aA_1 = aA_2 = πσ^3`（**平行** ⇒ `tr(a⁴F²) = 0`）。`[E]`（脚本 [4]）
2. 两个 lift **不**互為规范变换（`trF²` 是规范不变量，一个 `0` 一个 `−779`）。⇒ **指数图表 `ι_a` 不是规范协变的** ⇒ `𝔮∘ι_a` 不是规范轨道上的函数。
3. 想要"选对 lift"，等价于要 `exp: su(N) → SU(N)` 的一个**连续截面**；`exp` 非单射（`U=−1` 就是二重点），且**任何**规范固定都没有全局连续截面（Gribov 1978；Singer 1978：`research/gauge-invariance/REPORT.md:315,318`，DOI 10.1007/BF01609471，`[R]` 未逐字核）。仓库自己的口径：`O10-CENTER.md:155`「跨扇区 `G''` 差是 chart artifact（`J(2π)=0`）」；`G1-BLOCK-IDENTITY.md:243,326`「Vandermonde 在 cut locus 上为零」；`G3-PROJECTION-TERM.md:121`「`J` 在 SU(N) cut locus 上消失」。
4. **为什么"不连续"就不能用**：`(RB)` 要 `𝔮∘ι_a` 是 `Q_a` 上的**闭二次型**（`GC1:54` 的分母就是它）。不连续的 `ι_a` 不保形式域，`𝔮∘ι_a` 不是闭型，`(RB)` 的写法本身失效。⇒ **拓扑障碍 + 表述障碍双重。**

> **判**：`(a)` **不成立**。T4 是**拓扑/紧致性**障碍：格点的紧致目标空间带来的 `exp` 多值性（=中心对称的图表显形），与连续统的**四次无界**磁项之间，没有任何连续规范协变的识别能把它们拉成同阶。**这不是"还没找到好 `ι_a`"，是"好 `ι_a` 不存在"**（后者是 `[C]`：本轮的论证是结构论证 + Gribov no-go 的标准引用，不是逐字定理）。

### 2.2 (b) 限制 `ψ` 的支撑 —— **非法；且合法的能量壳版无效**

把问题拆成两个不同的收紧：

**(b1) 场幅截断** `supp ψ ⊂ {|A| ≤ Λ}`。**三条否决：**

1. **不是规范不变量。** `|A|` 是图表代表的条件；`U` 与 `−U`（`L` 偶时纯规范等价，`L` 奇时是中心变换）给出同样的 `|A|`但完全不同的物理内容。`(RB)` 左侧 `𝔮_a` 是规范不变的（只依赖 `U_p`），右侧 `𝔮∘ι_a` 由图表代表定 ⇒ 截断后的命题**依赖规范选择**，不能作为 COST 的输入。
2. **它切掉的是谱的底部，不是顶部（0.7）。** 中心变换 `U_l → zU_l`（`z∈Z(N)`）满足 `U_p → U_p`，故是 `H_a` 的精确酉对称（`(Ŝψ)(U) = ψ(z^{−1}U)`）：`𝔮_a(φ_{−1}) = 𝔮_a(φ_1)` **严格相等**。⇒ 大场区里住着**与平凡态等能**的态。以 `|A| ≤ Λ` 筛选 = 把谱底切掉一半 ⇒ 剩下的 `sup` 不再控制 `Δ_a`。
3. **即便只在形式上做，也拿不到 COST**：COST 的下界 `Δ_a ≥ (1−ε)Δ_cont − b` 要对**所有** `ψ⊥Ω` 成立；对被切掉的补集没有任何界。（T4 恰恰说明补集里 `𝔮_a` 可以任意小、`𝔮` 任意大。）

**(b2) 能量壳截断** `𝔮_a(ψ) ≤ E₀`（这是 `GN2-VARIATIONAL.md:61` 的 `(E4)(iii)` 与 `:154–162` 的 GN2-ADD 已经在用的形式，`[T]` 合法）。**但它对 T4 无效，理由是一行：**

```
把大场态按 c 缩放： 𝔮_a(cφ) = c²𝔮_a(φ)、 𝔮(ι cφ) = c²𝔮(ιφ)
⇒ 比值 |1 − 𝔮_a/𝔮| **尺度不变**；取 c² = E₀/𝔮_a(φ) 即把 T4 的态放到任意壳上。
⇒ 壳上 sup 仍 = 1，而 b‖cφ‖² = bE₀/𝔮_a(φ) → 0（𝔮_a(φ) ~ V/(g²a⁴) → ∞）。
```

> **判**：`(b1)` **非法**（规范依赖 + 切谱底）；`(b2)` **合法但无效**（尺度不变）。⇒「`(RB)` 的量词允许不允许限制」的答案是：**允许一个（能量壳），但它不是那个能救 `(RB)` 的限制；能救的那个（场幅）不合法。**

### 2.3 (c) 换范数（`𝔮` 用 `‖F‖²` 而非 `H^{1/2}`）—— **非法且更糟**

1. **非法（对象被换掉，不是尺被换）。** COST（`GO2-SOFTMODE.md:129–141`）的唯一非平凡步骤是 `𝔮(ιψ) ≥ Δ_cont‖ιψ‖²`，它用的是 `𝔮 = ⟨·,H·⟩` 的**强制性**。`‖F‖²` 不能控制 `L²` 范数（也不能控制电扇区）⇒ 那一步断，`(RB)` 与 `(NEW)` 之间**不再有箭头**。⇒ 换范数不是"更弱的充分条件"，是**另一个命题**。
2. **无效（比值仍是 `0/∞`，而且更极端）。** 截口处 `𝔮_a^{mag} = 0` 精确，`‖F‖² = Θ(1/a⁴)`；若把分母的电稀释去掉，`|1 − A/B| = 1` **精确**（不是 `1−O(g²)`）。⇒ (c) 把 T4 的 `ε` 从 `1−O(g²)` 推到 `1`。

> **判**：`(c)` **双重失败**。它既救不了 `(RB)`，也让 `(RB)` 失去通向 `(NEW)` 的桥。

## §4 酸测

### 4.1 四模型（全盲，且是结构性全盲）

### 4.2 **新增第五条酸测：cut-locus test**（本轮的可复用产出）

> **判据（CTL）**：对任何形如 `sup_ψ |𝔮_a(ψ) − 𝔮(ιψ)|/𝔮(ιψ) < ε` 的候选估计，取常链接族 `U_1 = e^{iαT^1}`、`U_2 = e^{iαT^2}`，算 `R(α)`（**(1.1)**，一次 `2×2` 矩阵指数），检查 `sup_α|1−R(α)|`。
> **通过条件**：`sup < 1`。**成本**：一个 `2×2` 指数 + 一次扫描（`< 1 ms`）。
> **判**：`R_YM` **不通过**（sup `= 1`，精确）。

**为什么它是"第五条"而不是"1.3 的重复"**：它不测模型，测**判据**；它只用到作用量的**紧致性 + 非交换性**，不依赖 `β`、`L`、`N`、维数（除"有空间 plaquette"外）、也不依赖 `g`。⇒ 任何新判据在进四模型之前，应先过 CTL：**四模型可以全过而 CTL 不过**（`R_YM` 就是），反过来 CTL 不过的判据不可能在 4D YM 上成立（因 CTL 的族在 4D YM 里逐字可实现）。
