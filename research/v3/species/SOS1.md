## 0. 判（先读这段）

**SOS 在单片上不可行。但不是因为题面说的那条理由。**

题面预设：「`H` 有负本征值 `−g|B|` ⇒ `H − c` 不正 ⇒ SOS 死」。**这个预设对 `q11` 的 `H` 是假的**：
`q11` 的 `H = ∂²_{ξ₃}S_W = (βc/2)g(u)` 是**标量函数**，在整条切片上 **`H ≥ 0` 逐点**；`θ=π` 时 `c=cos(θ/2)=0` ⇒ **`H ≡ 0`**（`Q11-CERT §1.3` 已写）。

SOS 仍然死，死因是**另外两条，各自单独成立**：

| # | 死因 | 级 |
|---|---|---|
| **(I)** | `H − c` **表达式层面**就不对：在 `θ=π`（`q11` 的锚点）上 `H ≡ 0` ⇒ `H − c = −c < 0` **逐点**，不是平方和（`[T]`，机检 `sup_u(H−c) = −c`，`c=1e-3,1e-12` 两次） | `[T]` |
| **(II)** | 就算换个 `θ` 让 `H>0`，`H ≥ 0` 也**推不出** `G″ ≥ c`：`β=4.4` 时 `G″ = −0.00899263 < 0`，而 `H ≥ 0` 逐点**不变** ⇒ 任何只吃 `H` 正性的证书被精确数字**反证** | `[T]` |

**⇒ 判死线 (a) 成立**（结论），但 **机制不是题面猜的**；同时 **(c) 成立**（两个 `H` 不是同一个对象）；**(b)** 只有平凡读法、且**空**（见 §4）。

## 1. 单片上的 `H` 到底是什么（本文件的核心核准点）

沿用 `q11` 的模型：`U=exp(ξ·σ/2)`、`ρ=|ξ|`、`h=ρ/2=u`、`c=cos(θ/2)`、`s=sin(θ/2)`、
`S_W = β(1 − cos h·c + sin h·s·ξ₃/ρ)`，切片 `ξ₃=0`，密度 `w(u)=sin²u/u`（`Q11-CERT §1.1`）。

**两个不同的 `H`，必须分开：**

**(H1) `q11` 用的那个（标量，`v=e₃` 方向的 `vv` 分量）** `[T]`：
```
H(u) = ∂²_{ξ₃}S_W|_{ξ₃=0} = (β c/2)·sin u/(2u) = βc·g(u)/2,   g(u)=sin u/(2u)
⇒ H ≥ 0 逐点（c≥0 对 θ∈[0,π]，g(u)>0 对 u∈(0,π)）；值域 [0, βc/4]＝[0, 0.625c]（β=2.5）
⇒ θ=π：c=0 ⇒ H ≡ 0（逐点，不是"平均为 0"）
```
机检（`log [A]`，u 网格 399 点 × 5 个 θ）：`θ=0` max `0.624994`、`θ=π/2` max `0.441937`、`θ=π` max `1.29e−43`（`cos(π/2)` 的浮点残渣，精确分支取 `c=0`）。

**(H2) 真正携带符号的那个（"算子"读法，`f03` 的角色的单片对应物）** `[T]`：
单片上**没有 `−D²`**（`L=1` 是 0 维，`q11` 的整个证书是一个 `u∈(0,π)` 的一维积分，`B03-LATTICE §2`）。
最接近的算子是 `S_W` 在切片上的**全 3×3 Hessian**（框架 `(n̂,w,e₃)`，`n̂=ξ/ρ ⊥ e₃`）：
```
H_nn = βc cos u/4,   H_ww = H_33 = βc sin u/(4u),   H_n3 = βs·[cos u/(4u) − sin u/(4u²)],   其余 0
```
（**已用有限差分核验**：`u=1, θ=π/2, h=1e-4`，`max|H_解析 − H_差分| = 8.3e−11`，`log [B]`。）
谱（401 点网格，`β=2.5`）：

| `θ` | `min eig Hess S_W` | 取到点 `u*` | `min eig (Hess S_W + Φ″)` | `frac<0` |
|---|---|---|---|---|
| `0` | **−0.624981** | 3.134 | **−0.153032** | 0.50 / 0.28 |
| `π/2` | **−0.484487** | 3.055 | **−0.0798355** | 0.56 / 0.25 |
| `π` | **−0.272614** | 2.081 | **−0.0511430** | **1.00** / 0.41 |

**⇒ (H2) 在整条切片上不定，且 `θ=π` 时 `100%` 的 `u` 都有负本征值。** 这就是 `f03` 的 `−g|B|` 在单片的影子（`f03` 在 2D 网格上测到 `−1.000000 = −B`，`400` 个负模，`F03-2DTEST §2`）。
**但注意机理**：`θ=π` 时 `c=0` ⇒ 本该出场的"`2adF` 项"**恒等于零**（`S_W ≡ β` 在切片上是常数，`Q11-CERT §1.3`）；
负本征值全部来自叉项 `sin h·s·ξ₃/ρ` —— **也就是 `G` 本身**。即：**携带负曲率的东西与产生 `D=β²Var(g)` 的东西是同一个 `G`**。

## 2. `H` 是否不定？（SOS 的生死，逐读法回答）

| 读法 | 谱 | 不定？ | 级 |
|---|---|---|---|
| `q11` 的标量 `H` | `[0, βc/4]`，`θ=π` 时 `≡0` | **否**（半正、端点退化） | `[T]` |
| `Hess S_W`（3×3，切片） | min `−0.625 / −0.484 / −0.273`（`θ=0/π2/π`） | **是** | `[T]`（解析谱 + FD 核验） |
| `Hess S_W + Φ″`（真·对数密度 Hessian） | min `−0.153 / −0.080 / −0.051` | **是**（`θ=π` 时 41% 的 `u`） | `[T]` |
| 4D/2D 的 `−D²+2adF_B` | `λ_min = −g|B|`（`f03`：`−B=−1.000000`） | **是** | `[T]`（`F03 §2`）；**不是单片对象** |

**⇒ 题面那句「`f03` 的 `−g|B|`」属于最后一行，不属于前两行。** 这是 (c)。

## 3. SOS 为什么死：`H − c = ΣAᵢ*Aᵢ ⇒ H ⪰ c`，而这里 `H ⪰ c` 三种读法全假

1. **标量读法**：`θ=π` ⇒ `H≡0` ⇒ `H−c=−c<0` 逐点、任何 `c>0`、**任何级数**（0 级/1 级/无穷级）都写不出平方和；`φ(u) ≡ −c` 是负常数。机检：`sup_u(H−c) = −1e-3 / −1e-12 < 0`。`[T]`
2. **算子读法**：`λ_min = −0.625`（`β=2.5`）⇒ `H − c ⪰ 0` 对 `c>0` **不可能**。
   而且 **`F03 §3` 的相似不变定理是 `[T]` 的**：`W^{1/2}(H−c)W^{−1/2} ⪰ 0 ⟺ H−c ⪰ 0`（谱完全相同）——
   **所以"SOS 加上一个正权 `W`"这种常见补丁在数学上不可能救**（`f03` 用 24 个随机 `W`、`cond` 到 `1e2` 机检：`min spec` 位移 `4.75e−16`）。
3. **充分性**：`H≥0` 逐点 **⇒ 不了** `G″≥c`（`β=4.4` 反例，`G″=−0.00899263`，`H` 一字未变）。这一条把「SOS 只是没写出来」与「SOS 逻辑上不够」分开——是后者。

**⇒ 精确缺失的步**：`G″ = S − D` 里 `S=E[H+Φ″]` 是**期望**、`D=Var(G+Φ′)` 是**方差**。SOS 是**逐点多项式非负性**，**表达不了方差**；要让方差进入证书，唯一通道是 Poincaré/BL 型不等式，而它的前提正是 `Hess ⪰ 0` —— 表 2 说这里是 `−0.05`。`[T]`

## 4. `(b)` 的平凡读法（诚实汇报：存在但空）

`H = A²`，`A(u) = √(βc/2)·sin u/√(2u)`（`u∈(0,π)`，`c≥0`）。逐点恒等，`[T]`。
**但任何非负函数都是平方** ⇒ 信息量为 0，且它是**测度盲**的（对 `β=0` 的自由测度同样成立，`β=4.4` 的负 `G″` 也照样"证"，见 §3.3）。按项目酸测标准：**vacuous**。

**真正在单片上给出正性的不是 SOS，是两个别的东西**（必须写明，免得把功劳记错）：
1. `E[Φ″] = NS/Z = 1/(4Z) = 0.205115297123073148` —— `NS=1/4` 来自**全导数** `Φ″w = −(1/4)d/du[sin²u/u²]`（IBP，`Q11-CERT §1.4`）。这是**雅可比正性**，不是平方和。
2. `D = β²Var(g) = 0.06912058608108493695`（`β=2.5`）—— 差值项，是**方差**。

**顺带一条 `[T]`（本轮新增，可替 SOS 在 1D 上给出解析证书）**：切片密度 `w=sin²u/u` 在 `(0,π)` 上 **log-凹**：
`φ″ := −(log w)″ = 2/sin²u − 1/u² ≥ 1.5492346 > 0`（min 在 `u=1.3933`，机检）。
⇒ 1D Brascamp–Lieb（`φ″≥ρ ⇒ Var(f) ≤ E[f′²]/ρ`）给出
```
Var(g) ≤ E[g′²]/ρ_min = 0.02917444834/1.549234588 = 0.01883152401   （真值 0.01105929 ✓）
⇒ β=2.5：G″ ≥ S − β²·0.0188315 = +0.0874183 > 0   （解析，无需区间算术）
⇒ 窗口 β < 3.3003218（比 q11 的精确 β* = 4.3066079 窄 23%，但**是解析的**）
```
**但这条不迁移到 3D/4D**：`Hess S_W + Φ″` 的 min 本征值 `−0.0511` ⇒ 3D 密度的 log-凹前提 **假**。1D BL 只在**边缘**上成立 —— 这正是 `C4/C6` 那条「BL 前提 = Savvidy 墙」在单片上的精确影子。`[T]`（3D 失败）/`[C]`（1D BL 数值吻合）

## 5. 判死线逐条

| 判死线 | 结论 | 依据 |
|---|---|---|
| **(a)** `H` 不定 ⇒ SOS 必然失败 | **成立（结论对，机制须改写）**：`q11` 的标量 `H` **不定不成立**（它 `≥0`、`θ=π` 时 `≡0`）；但算子的 `H`（`Hess S_W`/`+Φ″`）**确实不定**（`−0.625`/`−0.051`）⇒ `H−c` 永不正；且 `θ=π` 上标量 `H−c=−c<0` 已足以判死 | `[T]` §1–§3 |
| **(b)** `H` 定 ⇒ 给 SOS | 平凡 `H=A²` 存在但 **vacuous**（任何非负函数皆平方）；真有内容的替代是 IBP（`NS=1/4`）+ 1D BL（`+0.0874`，窗口 `β<3.3003`），**不是 SOS** | `[T]`/`[C]` §4 |
| **(c)** `H` 不是同一个对象 | **成立，且这是本题的主答案**：`q11` 的 `H := ∂²_{ξ₃}S_W`（标量函数，`R11:89`/`Q11 §1.2`）≠ `−D²+2adF_B`（4D/2D 的微分算子，`F03 §1–§2`，`λ_min=−B`）≠ `m₁²` 的对象（`L=1` 0 维，`m` 无定义，`B03 §2`） | `[T]` §1/§2 |

**一句话**：**单片上 SOS 拿不到任何一个 `c>0`。**要证的 `G″=S−D` 是「雅可比正性（IBP 给的 `1/(4Z)`）减去方差」，SOS 既**表达不了**它，其前提（`Hess⪰0`）在片上**也是假的**。**P3-SOS 这一路在单片上判死；它若要有内容只能去 4D 的 `k→0` 块，而那里 `λ_min=−g|B|` 同样封死（`F03 §3` 相似不变）。**
