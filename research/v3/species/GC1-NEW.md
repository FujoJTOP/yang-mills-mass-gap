### 1.2 单一命题 `R_YM(S,ι)`

固定方案 `S ∈ {S1,S2}`（本轮取 **S2**，因为 `β=2.5` 的 4D 各向同性 Wilson 数据在 S2，`GP1-DESIGN.md:55`）。令 `𝔮(ψ)=‖H^{1/2}ψ‖²`（`Q=D(H^{1/2})`），`𝔮_a^S(ψ)=⟨ψ,H_a^Sψ⟩`（`Q_a` = 格点形式域），`ι_a:Q_a→Q` 为**典范场识别**（`U_l=e^{iaA(x_l)}`，Fourier 模 `k↔p=k`）。先做 c-数减除 `H_a ↦ H_a − (inf σ(H_a))·1`（去掉真空能；`GP1-ACCOUNTING.md:43–65` 的三条恒等），再定义

```
ε_a^{form,S} := sup_{0≠ψ∈Q_a, ι_aψ⊥Ω} |𝔮_a^S(ψ) − 𝔮(ι_aψ)| / 𝔮(ι_aψ)                     (1.1)
b_a^{S}      := inf{ b ≥ 0 : |𝔮_a^S(ψ) − 𝔮(ι_aψ)| ≤ ε_a^{form,S}𝔮(ι_aψ) + b‖ψ‖²,  ∀ψ∈Q_a }  (1.2)
E_a          := { (ε,b) ∈ [0,∞)² : |𝔮_a^S(ψ) − 𝔮(ι_aψ)| ≤ ε𝔮(ι_aψ) + b‖ψ‖², ∀ψ∈Q_a }        (1.3)
```

> **命题 `R_YM(S,ι)`（`(NEW)` 在 YM 类上的唯一残余，公式版）**
> ```
> ∃ ε̄ ∈ (0,1)  ∃ b̄ ∈ [0,∞)  ∃ a₀ > 0  ∃ {ι_a}_{a<a₀} :
>        ∀ a ∈ (0,a₀)  ∀ ψ ∈ Q_a  with  ι_aψ ⊥ Ω :
>              |𝔮_a^S(ψ) − 𝔮(ι_aψ)|  ≤  ε̄ · 𝔮(ι_aψ) + b̄ · ‖ψ‖²_{ℋ_a} .                    (R_YM)
> ```
> 等价写法：`limsup_{a→0} ε_a^{form,S} ≤ ε̄ < 1` **且** `limsup_{a→0} b_a^{S} ≤ b̄ < ∞`；等价于「集合 `E_a` 含一个与 `a` 无关的 `(ε̄,b̄) ∈ (0,1)×[0,∞)`」。

R_YM(S,ι) ∧ SPEC-RES ∧ (ker H = ker H_a = ℝΩ) ∧ ((H+1)^{-1} 紧)

### 1.4 `ε_a^{form}` 在 `g=0` 的四个精确值（这是「具体方案里它是什么」的定量答案）

自由扇区的形相对常数可精确算：`H_a` 与 `H` 都是二次型，`sup` 在 BZ 的角上取得。**值依赖识别**（Q2 的定量像）：

|---|---|---|---|---|
| **S1** | **场识别 `φ↔φ`**（典范） | **`0.5947152654`** | `1 − 4/π²`（角 `k=(0,0,π)`） | `0.4052847346` |
| S1 | 单粒子/Fock（同模同动量） | `0.3633802276` | `1 − 2/π` | `0.6366197724` |

> 1. **`GP9` 的 `0.5947` 是 S1-场识别值**。`GP9` 的 (E2) 用 `h(k)` 与 `|k|²` 比，时间方向不出现 ⇒ 是 S1。**把 `0.5947` 当成「YM 的自由扇区值」是方案混用**（`AGENTS §2.1`）；仓库靶数据是 S2，对应 `0.7657`。

## §2 与 `k = j` 的关系（本路核心问题）

### 2.1 `GL4` 的恒等式，逐字

> **定理 1.5（`GL4-MKL.md:132–136`）**：设 `|𝔞(ψ)| ≤ λ a^j q(ψ)^s‖ψ‖^{2−2s}`，则尖锐 KLMN 常数 `C_*(ε) ≤ (1−s)s^{s/(1−s)}(λa^j)^{1/(1−s)}ε^{−s/(1−s)}`，且该估计的参数满足
> ```
> k₀ = j/(1−s),    m_raw = s/(1−s),    m_KL = m_raw − 1 = (2s−1)/(1−s),    2+m_KL = 1/(1−s),
> ⇒  k := k₀/(2+m_KL) = [j/(1−s)]·(1−s) = j .                                        (2.1)
> ```
> **`k₀` 与 `m_KL` 被一条恒等式锁死；`k≡j` 恒成立，`m` 怎么标都不动 `k`。**

### 2.2 把 `R_YM` 翻译进同一张表：它是 `(j,s) = (0,0)` 格

`R_YM` 的估计是 `|𝔞| ≤ ε̄𝔮 + b̄‖ψ‖²`（`ε̄<1`，`b̄<∞`）。对照 `GL4-MKL.md:103` 的 (1.2)：

```
没有 a-幂        ⇒ j = 0
没有 q^s 增益    ⇒ s = 0（右端只有 εq + b‖ψ‖²）
⇒ k₀ = 0/(1−0) = 0,  m_raw = 0,  m_KL = −1,  2+m_KL = 1,
⇒ k = k₀/(2+m_KL) = 0 = j .                                                          (2.2)
```

**所以：`(RB)` 若成立，给的是 `k = 0`。** 不是 `1`，不是 `2`。这与 COST (i) 逐字一致：`|Δ_a−Δ_cont| ≤ ε̄Δ_cont + b̄ = O(1)`——**没有任何速率**。而速率版（`k>0`，即 COST (iii) 的 `ε_a+b_a→0`）为假：`g=0` 就给它 `ε_a^{form} ≥ 0.5947`（S1）/`0.7657`（S2），**与 `a` 无关**（`GP9:98–101` 的 C2；本文件 §1.4 把它精确到方案）。

### 2.3 判：**两件不同的事**，不是「同一件事的两种写法」

把这句判词拆成三条可核的句子：

**(i) `k = j` 是恒等式，零内容；` (RB)` 是不等式，全部内容在常数侧。**
(2.1) 对**每一条**形如 `GL4 (1.2)` 的估计都成立——包括 `j=0`、`j=1`、`j=2`、`j=4` 的每一格。它说的是「前沿指数 = 扰动的 `a`-幂」，不告诉你前沿是 `1` 还是 `0`。`GL4` 的真正内容不是 (2.1)，是它的**上界/夹逼**：T3 的 `s≥1/2` no-go ⇒ `(j,s,m_KL)=(1,1/2,0)` 精确（`GL4:282–292` 定理 4.3 + 推论 4.3″）⇒ 前沿 `1`。而 `R_YM` 的内容是**常数 `ε̄<1` 且 `b̄<∞`**——(2.1) 一个数字也不给。

**(ii) `(RB)` 是「跨扇区的常数和」，`k=j` 是「逐格的指数」。**
`H_a−H = T1+T2+T3+T4`，`R_YM` 约束的是 `sup_ψ |ΣT_i|/𝔮 ≤ ε̄`，即**各扇区尖锐常数的和**（三角不等式）。`k=j` 是**逐扇区**的：T3 那一格是 `(j,s)=(1,1/2)`，T2 那一格是 `(0,0)`，T4 根本不在表里（它是大场效应，KLMN 是小场展开）。**「逐格指数」推不出「跨格常数和」**——这正是 `(RB)` 不是 KLMN 命题的原因。

**(iii) 因此 `(RB)` 与 `k=j` 的精确关系是：**
```
(RB)  ⟺  [k = 0 且 那个 O(1) 常数 < 1]                    （由 (2.2) + 定义）
      ⟹  k = 0
      ⇏  k = 1（T3 的 k=1 对 (RB) 既不充分也不必要：
                 T3 的尖锐常数 = O(a) → 0，它不威胁 (RB)；
                 而 T1/T2/T4 威胁 (RB)，它们都不在 T3 的 k=1 格里）
```

> **一句话答「同一件事还是两件事」：两件不同的事，且正交。**
> `k=j` 是**记账坐标**的恒等式（`GL4` 的标题句：「`m_KL` 是汇率，不是参数」）；`(RB)` 是**常数阈值**的不等式。
> 谁把二者写成「同一件事」，只可能落在两种误读之一：
> **(α)** 用 `j=0` 读——那是退化的、零内容的（`k=j=0` 恒真）；
> **(β)** 把 T3 的 `k=1`（KLMN 前沿）当成 `(RB)` 的阈值——但 T3 的尖锐常数是 `O(a)`，它**根本不进** `(RB)` 的分子主项。
> **`(RB)` 若成立给 `k=0`；想要 `k=1` 是在问另一个坐标（速率），而速率版已被 `GP9 C2` + 本文件 §1.4 判假。**

| 陈述 | `(ε,b)` 要求 | `(j,s)` 格 | 前沿 `k` | 真值 |

### 3.1 攻法 (a)：「Gaussian 扇区 `ε^{form}=0.5947<1`，差额只剩相互作用是否把它推过 1」——**`[NG]`**
