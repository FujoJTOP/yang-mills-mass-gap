## 1 · Berezin–Lieb 给什么：**和的上界**，三个方向层各自致命

### 1.1 逐字陈述（Berezin–Lieb 1977；Lieb–Thirring 1976）

`H = Σ_{i=1}^N h(x_i) + Σ_{i<j} u(x_i−x_j)`，`u ≥ 0`，`h` 单体、本征值 `ε_1≤ε_2≤…`：

```
Σ_{j=1}^{N} λ_j(H)  ≤  Σ_{j=1}^{N} ε_j(h) ,        λ_j 为 H 的最低 N 个本征值 .        (1.1)
```

**读方向 `[T]`**：`λ_j ≥ 0` 时 (1.1) 逐项给 `λ_j ≤ Σε`，特别地

```
λ₁  ≤  (1/N) Σ_j λ_j  ≤  (1/N) Σ_j ε_j  .                                          (1.2)
```

⇒ **Berezin–Lieb 对底部是"上限"，不是"下限"。** 这与 `B02 §9` 的四类下界机制表**不同族**：BL 连"下界机"都不是。

**唯一的下界形推论 `[T]`**：由 `u≥0` 得 `H ⪰ Σ h_i`（形式序），故 `E₀(H) ≥ N ε₀(h)`。这只是"绝对底部 ≥ 单体底部之和"，**对隙零内容**：本项目 `E₀≡0`（真空归一），单体底部 `=0`（粗模算符的真空）⇒ **返回 `0 ≤ 0`**。`[NG]`

### 1.2 在 YM 上的假设失配 `[T]`

(1.1) 要求把 `H` 拆成"单体 + **正**两体"。YM 的粗模算符是 `Hess = −D² + 2adF_B`：`2adF_B` **不定**（Savvidy 负模；W4 实测 **7.1%** 负，`CLAUDE.md §5`、`B02:107`）。要套 (1.1) 必须先证一个**正分解**——而在 `β=2.5` 上"存在正分解"与 `G″>0` 是同一族命题（`SDP-CERT`、`B02:152` 的"证书类"）。⇒ **BL 的假设本身就是靶的一部分**。

### 1.3 即使假设成立，仍与 `w₁` 无关 `[T]`

(1.1)/(1.2) 的自变量是 **`Spec(H)` 的本征值多重集**。而 `w₁ = f₁²/M₀` 的自变量是**算子对 `(H,O)`**（§3）。这不是"界太松"，是**函数没有定义在同一个空间上**。

> **一句话**：Berezin–Lieb 是"迹和 ≤ 迹和"的比较不等式 ⇒ 它给底部的**上界**；唯一的"下界形"推论只重复 `u≥0`；而其假设在 YM 上恰是靶。**对 `λ₁` 无下界，对 `w₁` 连自变量都不对。**

## 2 · ★ 关键：存在给 `λ₁` 下界的 **`L`-一致**算子不等式吗？

先把"一致性"这一维说清，**因为它不是弱点**：

> **观察 U11-U（一致性是免费的）`[T]`.** 经典算子不等式的常数**与体积/格距无关**：Cheeger 的 `h²/4` 对任意流形、`LT/CLR` 常数与体积无关、Temple 的 `ρ` 一旦给定对任意 `L` 同式适用、比较原理逐点成立。⇒ **"`L`-一致"这一维对算子不等式是免费的**；它们若失败，失败在**输入**或**方向**，不在一致性。**把靶写成"要一个 `L`-一致的算子不等式"是问错了轴。**

按"输入是什么"把候选分成**四型**（这是本轮对 `B02 §9` 四类下界机制的**再切分**：按"输入与 `w₁` 的自变量的关系"而非按"定理名"）：

## 4 · (c)：`w₁` **是**一个谱泛函——但它是弱-* 不连续的那个

```
读法 B：  w₁ = Φ(ν) := ν({inf supp ν}) / ν(ℝ) ,     ν = tr F² 的 KL 谱测度 .             (4.1)
```

(4.1) 是 `[T]`（定义级）。**但 `Φ` 的连续性是决定性的**：

> **接口定理（`R3-ATOM-FUNCTIONAL` Thm R3-2，`[T]`）.** 对任意**弱-* 连续**泛函 `g`，
> `sup_ν |Φ(ν) − g(ν)| ≥ f₁²/2` —— **仪器的误差 ≥ 信号**（Stone–Weierstrass 分辨率界）。

而**所有迹型算子不等式的输出都是弱-* 连续泛函**：`tr f(H)`、矩 `∫s^k dν`、`⟨Ω|e^{−tO}|Ω⟩` 都是"对 `C_b` 试验函数积分" ⇒ 弱-* 连续。⇒ **迹型/Berezin–Lieb 型在原理上够不到 `Φ`，不是常数松。** `[T]`

计数型（`N(E)`）**不是**弱-* 连续（它是跳跃函数），所以它理论上**能**看见原子——但它要一个**已知的参考边**去数（`§2` 表第 2 行），YM 没有；且其右侧是体量 ⇒ `L`-一致失败。`[T]`

⇒ **(c) 的精确判词**：`w₁` 是谱泛函（`ν` 的），**但**：
1. `ν` 是**算子对**的谱测度，不是 `Spec(H)`；
2. `Φ` 落在弱-* 不连续点上，**迹型（含 BL/LT 的矩形式）结构性不可达**；
3. 可达的只有**分离型**，其输入是 `E₂`（Temple 型）或 `Λ★`（残数型）——都 ≥ 靶。

## 5 · 判：(a)/(b)/(c) 与路径

### (a) 能逐字给 ⇒ Clay 有路？—— **不触发**（`[NG]`，类级）


外加一条**不在清单里的**：相对界稳定性 (2.1) 方向对、免 `E₂`、`L`-一致，但窗 `β<1/48`（已证），到 `2.5` 差 `135.9×`。⇒ **不能给 (a)。**
