## 3. 三个基，同一批 12000 组态（同一 Markov 链，误差 20 块 delete-one jackknife）

```
P_n(x) = (1/3) Σ_{i<j≤3} ½ Re tr U_p(x)     空间三面；U 用 APE（仅空间链，α=0.5，n 步）
S_n(t) = Σ_{x∈slice t} P_n(x,t)              零动量
C_n(t) = (1/L_t) Σ_{t₀} ⟨S(t₀+t) S(t₀)⟩_c
w₁ = A/C(0),  C(t) = A(e^{−m t}+e^{−m(L_t−t)}),  窗 t=1,2,3；`w₁@1.546` = 质量钉在 1.546
S/N(2) = C(2)/σ_JK[C(2)]
```

`TAPE` 定义：算子只依赖**同一时间片的空间链**（staple 只取 `ν∈{0,1,2}`，时间索引不变）⇒ 结构上"时间方向不涂"；
`run1` 的 `APE1` 与本轮 `TAPE1` 唯一区别是 staple 归一（`/6` vs `/4`）与 `n=1` 单步。**两者都给 `10⁻³`**。

## 4. 判死线

* **(a) `S/N ≥ 10` 且 `w₁` 与 `0.342` 一致？**
  `w₁` 一致（`0.3427 ± 0.0119` 对 `0.3423`，**0.02σ**）；`S/N(2) = 5.0 < 10` ⇒ **不满足 (a)**。
  `[E]` 数值钉死的部分：`w₁(raw, L=8, β=2.5, m₁=1.546) = 0.3427 ± 0.0119`；**但"钉死"受 `S/N<10` 限定**。
* **(b) `w₁` 变了 `> 2σ`？** 没有。`raw` 基重跑（8 链、新种子、`N` 翻 2.9 倍）给 `+0.0004`（0.02σ）⇒ **`run1` 的 `raw` 基没问题**。
  变的只有**换基之后**的 `w₁`（`TAPE1` `0.017`）——那是另一个算符，不算对 `run1` 基的反驳。
* **(c) 换基后 `C(2)` 仍 `< 0`？** **没有 `< 0`**（`+0.0030 ± 0.0032`、`+0.0034 ± 0.0022`），
  但 `C(1)/C(0)` 也塌到 0 ⇒ **时间关联仍被杀**（`S/N(2) ≤ 1.6`）。按 (c) 的口径这是"未触发"，但事实上**这条 GEVP 路不可用**。

## 5. 为什么空间涂抹杀时间关联（机制，`[C]`）

`smeared` 算符的 `C(0)` **涨**（19.9 → 45.5）而 `C(t≥1)` **塌**：谱权被推到 `m ≳ 4`（`raw` 的 `m_fit=1.7`）。
即涂抹不是"提高基态重叠"，而是把算符变成**接触项/UV 主导**：`R̄` 从 2.61 变 5.80（`TAPE1`）→ 6.50（`TAPE2`）。
`[C]` 这条路上 `w₁ = A/C(0)` 的分母被近距离噪声放大，`A` 反而没拿到基态投影。

## 6. 工程记录（`[E]`，用于下一步）

* **踩到并修掉一个 bug**：初版把 `Ut = U[c]`（`numpy` 视图）直接传给 `_ape3d` 原地修改 ⇒ **Markov 链被涂抹污染**，
  下一 cfg 从过涂组态起跑；后果之一是热浴 KP 采样接受率退化（`x→±1`），单作业从 ~40 s 拖到 >10 min。
  修法：每 cfg 先 `buf = np.empty_like(U[c])` 再拷（`_chains` 内）。
* 8 条**独立链**（不是单链续跑）⇒ 自相关与链间差一起进 jackknife 块；`S/N` 没有随 `N` 涨，说明
  `run1` 的 `1/√N` 外推把 `C(2)` 的信号涨落当噪声处理了（`C(2)` 本身从 `0.0207` 落到 `0.0119`）。
