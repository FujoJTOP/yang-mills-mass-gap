## §1 两量定义（显式式 · `file:line` · 类型 · a-幂）

### 1.1 `ρ^{ren}`

```
(eq-ρ)   ρ_a := inf{ ρ>0 : |C_2(z)| ≤ ρ²|h(z)|  ∀z∈B_L }  =  ( sup_{a<|z|<L} |C_2(z)|/|h(z)| )^{1/2}
```

- **出处**：不等式 `HS-L3-9:14`（逐字"设 `|C_2(z)|≤ρ_a²‖h(z)‖`"）；`h` 的来历 `:41`（Ursell 树核，`|C_2(x,y)|≤ρ²|h(x−y)|`）；窗口 `:61`（`a<|z|<L`，与 `χ_2^{ren}` 径向积分同窗）。`HS-L3-9` 未写极值式 ⇒ 上式是极小常数读法（定义层，不增内容）。
- **类型**：`C_2` 的**振幅**（sup-型范数）。**不是期望**（无 `∫`、无测度）；**不是方差**（方差 = `S^{(2)}(f,f)` = `C_2` 的二次型、是 `f`-依赖泛函；`ρ` 是它的一个数）；**不是连通率**。
- **`a`-幂**：`a⁰`。自由场 `C_2=c|z|^{-8}`、`h=|z|^{-8}` ⇒ 比值恒 `c` ⇒ `ρ=√c`，与 `a` 无关。减除若为接触型（`(U2)` 的 c-数 `c₂(a)`，`HS-L3-6:0.3`）则只落在 `|z|≲a`，去心域上 `C_2` 不变 ⇒ `ρ^{ren}=ρ`（同幂且同值）。
- **规范**：`h` 未钉 ⇒ `ρ` 是 h-相对的，见 1.3。

### 1.2 `𝒢^{ren}`

```
(eq-𝒢)   𝒢_a := ρ_a^{-2} ∫_{B_L} |C_2| ,        |B_L| = π² L⁴/512
```

- **出处**：`HS-L3-9:14`（逐字 `𝒢_a:=ρ_a^{-2}∫_{B_L}‖C_2‖`）；`|B_L|` 见 `:46`、`HS-L3-5:48`。
- **类型**：**连通质量 / 有效格胞数** —— `|C_2|` 的 **L¹ 质量**用振幅平方归一，量纲 `[𝒢]=−4`（体积）。**不是期望**（L¹ 范数，无符号）；**不是连通率**（率是 `(★dec)` 的 `κ`；`𝒢` 是 `κ^{-4}` 的积分像）。两个锚：乘积测度 `𝒢=1`（`:50`，单格胞）；有隙 `𝒢≈m^{-4}`（`:51`）。
- **`a`-幂**：**它扛 `a^{-4}`**：`∫_{a<|z|<L}c|z|^{-8}d⁴z=(π²c/2)(a^{-4}−L^{-4})`（`:61`，`d⁴z=2π²r³dr`）。⇒ **分工：`ρ` 管振幅、`𝒢` 管幂。**

(h-gauge) h→λh :  ρ→ρ/√λ ,  𝒢→λ𝒢 ,  ρ𝒢→√λ·ρ𝒢 ;   (C-form) 右端 → λ^{(n−2)/2}·右端

## §2 `sup_a` 能否有界：三路

### 2.1 (a) 自由场标定 ⇒ **有界** `[T]`

```
ρ^{ren} = √c ,   M^{ren} = abs( c' − (π²c/2)L^{-4} )
S^{bare}(a) = √c·(π²/2)(a^{-4}−L^{-4})  →  ∞                       （(U2) 不可省）
S^{ren}   = M^{ren}/ρ^{ren} = abs( c'/√c − √c·(π²/2)L^{-4} )
          = √c·c_L²/(32π²)   当 c'=0 ,     c_L = 4π²/L²            （有界、IR 控制）
```

- 三步同一积分（`HS-L3-9:61`）：去心 sup 给 `ρ=√c`；`(eq-𝒢)` 给 `𝒢`；`(π²/2)L^{-4}=c_L²/(32π²)`。
- **判**：**有界**，且值 `∝c_L²`（盒隙的平方）——这与 `HS-L3-9:0.8`"自由场落在 §1.2 区间下端"一致。`c'≠0` 时值变、幂不变（`c'` = 方案有限部，`:18,:61` 记 `[NG]`）。
- **下一手**：写成 `(U2)` 的验收行（"任何方案先在此式取等"），并把"自由场已过"记为靶的第一道酸测（`L3` 在自由场上必须真：`HQ1-L3:63`；`HS-L3-9:16`）。

### 2.2 (b) 由已证逐壳/单块直接给 ⇒ **不直给** `[NG]`（三条理由均 `[T]`）

| 序 | 已证物 | 它给什么 | 差在哪 |
|---|---|---|---|
| 1 | **R3**：减除后 `p=0`（`HS-L3-6:38`） | **有符号**矩 `S^{(n)}` 的幂 | 靶吃 `abs`：`∫abs(C_2^{ren}) ≥ abs(∫C_2^{ren})` 只给**下**界；反向 `∫abs(C_2^{ren}) ≤ ∫abs(C_2^{bare})+abs(c₂)` 回 `a^{-4}`（`HS-L3-6:61` 同一现象换到模上） |
| 2 | **单块** `G″≥δ_W`（`HQ1:101` S2）+ 头部有限（`:106` S7） | `Var≤E[H]`，即 `ρ²` 的**上**界 | 商含 `1/ρ^{ren}` ⇒ 要 `ρ` 的**下**界；上限帮倒忙 |
| 3 | **自由盒隙** `c_L=4π²/L²`（`a`-一致） | IR 地板 | 只定 `L`-标度，不定振幅与 L¹ 质量 |

- **唯一可写的充分包（三行，`[T]`）**：若 (i) **符号比** `∫abs(C_2^{ren}) ≤ K·abs(∫C_2^{ren})`、`K` 与 `a` 无关；(ii) `R3`（有符号 `p=0` 带常数）；(iii) **振幅地板** `ρ^{ren}_a ≥ c>0` —— 则 `sup_a ρ^{ren}𝒢^{ren} ≤ K·C/c < ∞`。
- **判**：三件仓内全缺。`K` 需要"减除**保号**"（`K=1` 即 `C_2^{ren}` 在去心域定号，自由场满足；一般测度上 `C_2` 会振荡）。`ρ^{ren}≥c` 无任何供给：S2/S7/R3 全是上限型或符号型。⇒ **该格 `[NG]`**。
- **下一手**：攻 `K` 有界——它等价于"存在一个**正的**减除方案"（`c₂` 逐点支配，而非仅分布意义），比 `(★)` 弱，且不吃符号结构。

### 2.3 (c) 反例族 ⇒ 裸形 `[T]`、带减除 `[NG]`

- **裸形有反例**：自由场自身，`S^{bare}=√c(π²/2)(a^{-4}−L^{-4})→∞`（2.1 第一行）。比任何相互作用模型干净，同时是 `(U2)` 承重的见证（`HS-L3-9:18`、`HS-L3-6:0.1`）。
- **带减除无族**：`S→∞` 需 `M^{ren}/ρ^{ren}→∞`，两条互斥通道 `(α) M^{ren}→∞`、`(β) ρ^{ren}→0`。仓内无任一族。`(β)` 不被 `M≥m>0` 排除（`M≤ρ²∫abs h`、`∫abs h~a^{-4}` 太弱）；`(α)` 与"模面 `(U2)` 失败"同义。
- **判**：`[NG]`（无具名反例）。**下一手**：在 `C_2` 精确可算的格（2D YM 的 `χ₂`、单片的 `G″` 多项式、乘积测度 `𝒢=1`）上求 `M^{ren}/ρ^{ren}` 标定表；若某格给出 `(β)` 而该格 `L3` 为真，则 2.2 的充分包**必要**，可据此裁 `K` 与振幅地板的相对强弱。
