## §4 反向检查：`C` 能依赖什么？`L→∞` 后有无残余？

把 §0 的 (R1) 精确写出（这一步是全部记账的基础，`[T]`）：

```
m a = f(β, L/a, θ; N)                     [格点：参数表全无量纲]
Λa  = F(β)                                [transmutation，scheme 依赖，AF 分支单调可逆]
⇒ m = Λ · R(Λa, ΛL, θ; N),  R := f/F      [纯定义，[T]]
```

于是"`m = CΛ`，`C` 纯数"**逐字等价于** `R` 与其第一个自变量无关：

```
C := lim_{Λa→0, ΛL→∞} R(Λa, ΛL, θ=0; N),     要求 C 存在且 > 0
```

**`C` 能依赖什么（唯一性成立时）**：

| 自变量 | 能否进入 `C` | 理由 |
|---|---|---|
| `N` | **能** | 离散参数，`C = c_∞ + O(1/N²)`；这是唯一"正当"的依赖 |
| `θ` | **能**（`C(θ)`），但靶取 `θ=0` | 无量纲；由 §2 固定在 0 ⇒ `C(0)` 一个数 |
| **scheme**（`Λ` 的定义） | **能，且成对** | `(C, Λ) → (C/s, sΛ)` 不变；`A8`/`L2` 实测 `Λ_MS/Λ_I = 2.633` ⇒ `C` 是 **scheme-条件纯数**。计划里"`C` 为纯数"必须读作"**给定 scheme 后**为纯数" |
| `β`（即 `Λa`） | **不能**（这是要证的） | `R` 的 `Λa`-无关性 = 标度假设 = C1 |
| `ΛL` | **不能**（`L→∞` 后） | 见下 |
| `a, L, T` 自身 | 不能 | 调节器，已并入无量纲组合 |

**`L→∞` 后是否仍有依赖？——分两问，答案不同（这是本节的实质）：**

1. **作为"标度源"的残余：没有。** `L` 只以无量纲 `ΛL` 出现，`ΛL→∞` 若不收敛，得到的是**不同态/不同极限**，不是第二个标度。`[T]`
2. **作为"数值残余"的残余：有，且不能白拿掉。** 有限体积修正的**形式** `m(L) = m_∞[1 + O(e^{−m_∞L}/(m_∞L)^{3/2})]` 需要 `m_∞ > 0` 才能写 —— 这是**循环**（拿隙证 `L`-依赖消失，再拿 `L`-依赖消失证隙）。合法替代只有一条：`(L,a)`-**一致**的陈述（`W1₀` 型边界屏蔽，`G1-UNIQUENESS-VACUUM §2(i)`），它比隙弱但**不免费**。⇒ `ΛL` 的去除是 `[C]`（条件于一致界）或 `[O]`（无条件），**不是** `[T]`。

**再回到 `Λa`**：同理，`R(Λa)` 的常数性不能被"取极限"免费拿走 —— 极限存在性是 `[O]`。语料的**实测**正好在这一点上顶住：`CONTINUUM-PLAN §2` 自己算出 `d ln(ma)/dβ = −0.63`（SU(3)，`β=6.0→6.3`），而由 `Λa = F(β) ∝ e^{−12π²β/(11N²)}` 得要求值 `d ln(ma)/dβ = −12π²/(11N²) = −1.197`，**量值比 `0.53`**，符号同号。⇒ **`R` 在测量窗口内明显依赖 `Λa`。**
（**顺手抓一个符号笔误（`[T]` 级，纯运动学）**：`CONTINUUM-PLAN §1` 把要求斜率写成 `+12π²/(11N²)`，但它自己的推导 `1/(2b₀g²)=β/(4b₀N)` 给的是 `ln(Λa) = −12π²β/(11N²)+const`，故 `d ln(Λa)/dβ = −12π²/(11N²) < 0`（`β` 增大 ⇔ `a` 减小 ⇔ `Λa→0`）。计划 §2 的"0.53 倍"是取绝对值算的，**结论不受影响**，但 §1 的等式要加负号，否则"斜率匹配"会变成符号错配。）⇒ **"`C` 是纯数"在 `β≈6` 处被数据反驳（作为一个有限-`β` 陈述）；它只能作为一个关于极限的陈述存活。** 这不是新算，是计划 §2 的既有数字的另一种读法。

## §6 与 C1 的关系：C3 不是独立路线（本文件最有用的一条）

由 §4 的 `m = Λ R(Λa)`：

```
d ln m / d ln a |_β  = −1                                  [纯运动学，[T]，无需任何动力学]
d ln m / d β        = d ln f / d β = d ln R / d ln(Λa) · d ln(Λa)/dβ
```

- 第一式是**恒等式**：固定 `β` 时 `ma` 固定 ⇒ `m ∝ 1/a`。计划 C1 想要的"`m` 与 `a` 同标度"，在**固定 `β`** 下**什么也没说**（它是单位换算）。**这也是 `LEDGER` 那类量纲陷阱的来源**：`1/a` 不是 `Λ`。
- 第二式才是内容：**"`R` 与 `Λa` 无关" ⟺ `d ln(ma)/dβ = d ln(Λa)/dβ = −12π²/(11N²)`**（用 `Λa = F(β) ∝ e^{−12π²β/(11N²)}` 的一圈形式，即计划 §1 的恒等式，**带 §4 的负号修正**）。⇒ **C1 的斜率等式就是 C3 唯一性的定量形式**，二者**不是**两条路线，是同一件事的必要/充分两面。
- **对计划的净后果**：C3 不能与 C1 平行派工来"交叉验证"——它们同源。C3 的价值只有一条：**堵死"换形状"的逃逸**（防止出现 `m = C Λ²/g`、`m = C/a`、`m = C√σ` 这类"看起来是纯数、其实换了标度"的写法）。这一条**值得写进纪律**，因为 `A8` 的 `m/Λ ≈ 613` 与 `L2` 的 `12–18` 正是"形状对、归一错"的两种病：**形状唯一性不检测归一错误**（`613` 与 `6.3` 形状完全一样）。

## §7 精确缺失步（不做的事也写清）

1. **缺失步（唯一）**：证 `lim_{Λa→0} R(Λa)` 存在且 `> 0`，一致性在 `ΛL→∞` 下保持。等价形式三条任选一：`d ln(ma)/dβ = 12π²/(11N²)`；`m(2a)/m(a) → Λ(a)/Λ(2a)`；`(L,a)`-一致的 `m a` 界。**`[O]`**
2. **C3 已闭合的部分（不再派工）**：标度清单、`θ` 固定、`D1`、(R1)/(R2) 两读、C3⟺C1。**`[T]`**
3. **不做（避免扩散）**：`θ≠0` 的谱；一般 `N` 的 `c_∞`；`√σ` 的下界；有限体积界的锐化；scheme 常数的数值（`A8`/`L2` 已定位，属归一问题）。
4. **标签总账**：`[T]` = §1 清单、§2 的 `θ` 固定（Wilson 层面）、§3 D1、§4 的 `m = Λ R` 恒等式、§6 第一式；`[C]` = `ΛL` 的去除、`Λa` 的极限（条件于一致界/标度假设）；`[O]` = 极限存在 + `C>0`；`[NG]` = 无第二标度源（对 §1 清单这一**名类**）；`[M]` = **无**（唯一性对**形状**成立；若 `C4` 的路径依赖成立，失败模式是"无唯一极限"，不是"第二标度"）。
5. **无 QED**：本文件没有证明 Clay，也没有证明 `C > 0`；它只判定"`m = CΛ` 是唯一形状"这个**必要条件**成立，并把充分的定量内容原样交回 C1。
