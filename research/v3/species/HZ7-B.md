## §2 · Q2：单调性能否把射线折成一点 —— **`[NG]`**

### §2.1 两个输入（都可复核）

`β = 2N/g²`（`CLAY:81–84`，`g² = 2N/β`）；两圈（`B04.md:47` 的写法，`w7/b07_ratio_floor.log` `[0]` 复核了系数）：

```
b₀ = 11N/(48π²),      b₁ = 17N²/(384π⁴),      b₁/(2b₀²) = 51/121 (=0.4214876, N-无关)
a(β)Λ = C·(b₀g²)^(−b₁/(2b₀²))·exp[−1/(2b₀g²)]
1/(2b₀g²) = 12π²β/(11N²)          (N=2 ⇒ 2.691β，与 B04:145 的 exp(−2.69β) 同值)
⇒ ln(aΛ) = ln C + (51/121)ln β − (12π²/(11N²))β + const
```

定义分母的**对数斜率**（下面承重比较用）：

```
κ(β) := − d ln(aΛ)/dβ = 12π²/(11N²) − 51/(121β) > 0   ⟺   β > 0.0391·N²
数值：κ(3, 2.5)=1.0277   κ(3, 4.3066)=1.0984   κ(3, 6)=1.1261   κ(3,10)=1.1542
      κ(2, 2.5)=2.5231   κ(2, 6)=2.6215
```

### §2.2 公式：`d/dβ [ Δ_a/Λ ] = ?`

记 `Δ^lat(β,L) := aΔ_a = −ln‖T_a|_{Ω^⊥}‖`（格 2），`R := Δ_a/Λ = Δ^lat/(aΛ)`。则

```
dR/dβ = (Δ_a/Λ) · [ (dΔ^lat/dβ)/Δ^lat − d ln(aΛ)/dβ ]
      = (Δ_a/Λ) · [ d lnΔ^lat/dβ + κ(β) ]                                   (★)
```

展开到位（把两圈代进去）：

```
d/dβ [ Δ_a/Λ ]  =  (Δ_a/Λ) · [ d/dβ ln( a(β)·Δ_a(L,β) ) + 12π²/(11N²) − 51/(121β) ]
符号 ⟺ sign( d lnΔ^lat/dβ + κ(β) )，即比较"分子的 β-斜率"与"分母的 β-斜率"
```

**承重项 = `d lnΔ^lat/dβ`（分子自己的斜率）。** 分母那一项是全显式的：`κ(β)` 由 `b₀, b₁` 完全决定，`β`-依赖只剩 `51/(121β)`，在 `β≥2.5` 上只从 `1.028` 走到 `1.154`（`N=3`）。分子那一项**没有任何已证界**：`B04.md:167` 逐字"`m·a` 的严格单调性未证…要 `[T]`，需证 `β ↦ E₁(β)−E₀(β)` 的单调性——文献与本仓都**没有**这个工具"。

### §2.3 为什么 (★) 给不出单调性（三条，互相独立）

1. **恒等拆分的空转性**：把 `Δ^lat = R·(aΛ)` 代回 (★) 立刻回到 `dR/dβ = R·dlnR/dβ`。⇒ 任何"`R` 单调"的断言**逐字**是对 `dlnΔ^lat/dβ` 与 `κ(β)` 的比较断言，不是从两圈推出的东西。`[T]`
2. **标度情形把单调性变成零斜率**：若标度成立（`Δ/Λ = δ_∞` 在窗内常数），则 `dlnΔ^lat/dβ ≡ dln(aΛ)/dβ = −κ(β)`，于是 (★) 给 `dR/dβ ≡ 0`——`R` **同时**非减与非增。⇒ "单调"这类假设在靶自己的情形里**恒成立且零信息**（常数仍是未知）。`[T]`
3. **"单调升 ⇒ 折成一点"这条捷径与目标同强**：`R` 关于 `β` 非减时 `inf_{β≥β₀}R = R(β₀;L)`，于是 `(B) ⟺ ∃δ ∀L: R(β₀;L) ≥ δ`——射线折成 `β₀` 切片。但反过来，`R(β₀;L) ≥ δ ∀L` 本身就是一个 `L`-一致地板陈述；把它当"单点"读需要**先有**单调性，而单调性（§2.3-1）就是关于 `R` 自己的一侧不等式。⇒ **用单调性换单点，等价于用目标的一半换目标的另一层量词，不产生新输入。** `[T]`
   补一条量词事实：即使 `β`-单调成立，单点也必须是 **`L`-一致**的；单调性只交换 `β`，不交换 `∀L`。

用 `B04.md:60` 自己的 SU(3) 两圈表 `aΛ_L` 与实测 `m·a`（`B04.md:68,73`、`RUN3` 锚）算 `R = (m·a)/(aΛ_L) = m/Λ_L`：


### §4.1 (a) 无光模塔（`m₁² ≲ L^{-2}`）

- **能否让比值 → 0**：能，且是**最直接**的一条。固定 `β`、`L→∞`，若 `Δ_a(L) ≲ 1/L`（物理单位），则 `Δ_a/Λ ≲ 1/(LΛ) → 0`，正是 (Q4-0)（取 `δ_j = 1/(L_jΛ)`）。`[T]`（算术）
- **是否违反已证约束**：**不违反。** 仓内"无光模定理"是**等价窄化**不是排除：`GY2-NOGAP-MECH.md:180` 逐字"**无光模定理 ⟺ `F²` 连通关联不发展 `O(1)` 跨体积（时间向）平台**…这是靶的**等价窄化**"。而软模族给出的是"更强的收敛也堵不住"：`GN3-SPECTRAL.md:182` 逐字"同一构造里 `d_H(σ(H_a),σ(H)) = ε_a → 0` ⇒ **谱集 Hausdorff 收敛同时成立**…⇒ `REPORT:291` 的'更强形式'**也不排除软模**"；构造本体 `GN3:180`（`Δ_a = ε_a → 0`、`Δ_cont = 1`、强预解收敛）；紧预解类的分裂点见 `GO2-SOFTMODE.md:26,82`。⇒ **PF/反射正性/迹界/谱集收敛都不排除 (a)。**
- **精确模型见证**：M6 `m_L = min(ω, 2π²/L²) ∝ L^{-2}`（`U09-M6.md:11,28`、`B03-LATTICE.md:90`）——`L^{-2}` 塔在仓内是**精确事实**，不是假设。
- **判**：**`[NG]`（(a) 活，排除不了）**。排除 (a) 与证明靶同级。

### §4.2 (b) 双井（Kramers）

- **能否让比值 → 0**：能，且**更快**。双井的分裂 `ΔE ∼ e^{−c·L³}`（或 `e^{−c/λ}`），`L→∞` 时 `ΔE/(aΛ) → 0` 以超指数速率，满足 (Q4-0)。`[T]`（算术）
- **是否违反已证约束**：**不违反**，而且它是**唯一还剩的反例族**：`GY2-NOGAP-MECH.md:276` 逐字"本轮真产出…**反例族唯一化 = 双井型**"；同文件 `:26` 逐字"最后一格 = '`F²` `k=0` 边际的**无对称双井/平台排除**'在 `β=2.5` **无已知工具**"（列出的两个失败机制：log-凹性在 `2.5` 失败（`Q6:389–391`，经此转引）、FKG 符号反（`T5:367`，经此转引）。
