## §0 判定（先给）

**(a) 成立，而且比 (a) 更硬：不是"循环"，是"假设恒真"。** 缺的那条在链条上是**两段**，顺序不能颠倒：

- **(α)【在前 · 独立 · 且在 β=2.5 为假】** 该 `β` 处**面权**的 Hadamard 判据 + 极小面主导：
  `lim_A (−log|w_β(A)|)/A > κ` 且 `|W − w_β(S_min)| = o(w_β(S_min))`。
- **(β)【在后 · 循环】** 从"面求和收敛"到"`W` 的 `R`-衰减"的**转移矩阵/谱桥**：`W` 是矩阵元，衰减由**本征值比值**定 ⇒ 接上它 ≡ 弦张力 ≡ (E) 本身。

**(α) 在 β=2.5 对一切 `κ ≥ 0` 为假**（§3）：同一 `c` 序列给出 `σ₀ = ∞`（"最优"），同时给出 `lim(−log|w_β(A)|)/A = −log c₁(2.5) = −0.714 < 0 ≤ κ`（"最坏"）——**两个方向相反的读数**。

**(b) 只剩一小块，且不出口**：log-凸 + Chebyshev 型不等式 ⇒ 面积律，但 `lim σ_A` 就是弦张力 ⇒ 换名不换事；且在自由场上失败（§5）。

**(c) 假**：`κ` 有限，`1.40 ≤ κ ≤ 3.87`（§4）。**但 (c) 成立与否都不救**：`κ` 有限 ⇒ 假设恒真（假设空）；`κ = ∞` ⇒ 假设恒假（判据先死）。**两分支都让接口空。**

**一句话**：缺的是「**面权 `w_β(A)` 的每面积指数衰减率**」这一泛函，而 `σ₀` 是「**系数序列的指标渐近率**」——量纲相同、泛函不同；sp-b 把后者当前者，且前者在物理点为**负**。

**一个不等式**：`∃σ>0: lim_{A→∞} (Ω_A |w_β(A)|)^{1/A} ≤ e^{−σ} < 1`（`Ω_A ≃ e^{κA}`），等价地 `lim_A(−log|w_β(A)|)/A > κ`。

**自由场如何失效**：原判据（`σ₀>κ`）**自由场通过**（`σ₀=∞`）⇒ vacuous；修后判据自由场**失败**（`limsup|w_A|^{1/A} = λ_max(β) > 0`，`λ_max e^{κ} > 1`）⇒ 有内容。**本项目酸测（新工具必须对自由场失效）：原判据不过。**

## §1 先把 `c_n` 认出来：它是**单格面 Bessel 系数**（`[T]`/`[V]`）

sp-b 口径 `c_n = I_n − I_{n+2}`。Bessel 递推 `I_n − I_{n+2} = (2(n+1)/β)I_{n+1}` 给精确闭式，展开后

```
c_n / [(β/2)^n / n!] = Σ_{k≥0} (β²/4)^k / (k! (n+2)_k)
                     = 1 + β²/(4(n+2)) + (β²/4)²/(2(n+2)(n+3)) + …
```

**逐点核 sp-b §2 的七个数（β=2.5，`[V]`）**：

| `n` | sp-b | 闭式 |
|---|---|---|
| 0 | 2.013 | 2.01337 |
| 2 | 1.457 | 1.45726 |
| 4 | 1.292 | 1.29146 |
| 8 | 1.168 | 1.16783 |
| 12 | 1.118 | 1.11761 |
| 16 | 1.091 | 1.09047 |
| 24 | 1.062 | 1.06187 |

另三点全中：`c₀ = 2I₁(2.5)/2.5 = 2.013373`（sp-b 六位）；`u = c₁/c₀ = 2I₂(β)/I₁(β) ⇒ u(2.5) = 1.014390`（TRG-EKR 六位）；`u=1 ⇔ 2I₂(β)=I₁(β) ⇔ β* = 2.4469`（sp-b 四位）。
⇒ **`c_n` 就是单格面权 `e^{β cos θ}` 的字符系数**（同一 `10⁻⁴` 带内，`[V]`；剩下的 5 位差要么是 TRG 截断、要么是 4D 动力学，`10⁻⁴` 带内不可分）。**这条识别是本文件全部结论的地基。**

**推论 1（`[T]`）**：由 `I_{n+1}(β) ~ (β/2)^{n+1}/(n+1)!`（`β` 在紧集上一致），
`−log c_n = n log n − n + n log(2/β) + O(log n)` ⇒ **`σ₀ = lim(−log c_n)/n = +∞`，对每个 `β ∈ (0,∞)`**。
**推论 2（`[T]`）**：`σ₀ = ∞` 不是动力学事实，是"格面权在群上解析"的**运动学**事实 ⇒ 任何光滑格面权（自由 Maxwell、U(1)、SU(N)、任意 `d`、任意 `β`）都 `σ₀=∞`。
**推论 3（`[M]`）**：`c_n` **不是 `Z(β)` 的 Taylor 系数**（那是 `(−1)^n⟨S^n⟩/n!`，含 4D 全格组合）；它是 **0 维积分**（单格面）的字符系数，且对 `β` 是**整函数**，`β`-半径 `∞`——**`β`-平面上根本没有解析结构可读**。
⇒ **`σ₀ > κ` 是 `∞ > 组合常数`：对一切理论、一切维数、一切耦合为真。**

## §2 链 `c_n → W(C) ~ e^{−σR²}`：每一步要什么（逐条核）

记 `A` = 面片数（格单位 `A = πR²/a²`），`Ω_A ≃ e^{κA}` = 张成 `C` 的 A-面片面数，`w_β(A)` = 一个 A-面片的权，`W` = 圈期望，`m(R)` = 荷间距 `R` 的静态势（弦态最低本征值）。

| # | 步 | 需要什么（精确） | sp-b 状态 |
|---|---|---|---|
| **S1** | `c_n → w_β(A)` | `n` 必须**是面片数**、`c_n` 必须是**固定圈的面权**（面积-A 项系数），且 `w_β(A) ≈ Π_p c_{j_p}` 的同一成立 | **[M]**：`n` 是**字符指标**不是面片数；`n↔A` 只是记号替换，无几何内容 |
| **S2** | `W(C) = Σ_A Ω_A w_β(A)` | **该 β 处的恒等式**；只在 `u(β) < e^{−κ}` 的绝对收敛域内成立（强耦合展开定理） | **[C]**：sp-b 用的是 `u<1` 的边界行，并自承"该行无定义"；`u(2.5)=1.0144>1` |
| **S3** | 每面积衰减率 | `lim_A(−log|w_β(A)|)/A > κ`：**`β` 的函数，且是面权序列的泛函** | **[M]**：sp-b 换成 `σ₀ > κ` = 系数序列的指标渐近，且 `σ₀=∞` 对一切 `β` |
| **S4** | 极小面主导 | `w_β(S_min) > 0`（正性/RP）且 `|W − w_β(S_min)| = o(w_β(S_min))`：**下界**，不是收敛 | **缺**（sp-b §1 的 `≃ Σ A^{α−1}` 只给量级） |
| **S5** | `R`-衰减 `= e^{−σR²}` | **谱桥**：`W(C)=⟨Ω\|T_C\|Ω⟩/⟨0\|T\|0⟩` ⇒ `−log W(R,T) = T·m(R)+O(Te^{−ΔT})`，面积律 ⟺ **`m(R) = σR + o(R)`** | **缺，且原理上不可能由 `c_n` 给**（`c_n` 与 `R`、与谱均无关） |
| **S6** | 连续极限 | `σ_lat(β) = σ_phys a²(β) ∝ e^{−c/β}`（渐近自由/量纲传递） | **缺**：`σ₀−κ` 是 β-盲纯数 ⇒ 与 AF 冲突（§6） |

**关键怀疑逐条核（不照抄）**：

1. **"`β` 与 `R` 是不同变量"——对，但机制比这更狠**：`c_n` 甚至不是 `β`-幂系数（推论 3），`β`-平面结构是整函数；`n` 是字符指标。所以"比值检验给 `β`-平面解析结构"这一句在**对象上**就不成立——**它连 `β`-平面也没说到**。
2. **"中间需要转移矩阵/谱"——对**，且比"谱"更细一层：谱只免费给 `T`-方向衰减（`e^{−m(R)T}`）；`R²` 需要**弦态最低本征值随 `R` 线性增长** `m(R)=σR+o(R)`，那是**弦张力本身**，不是谱定理的副产品。
3. **sp-b §1 自带的一次循环（新增，`[M]`）**：它把 `Π_p c_{j_p}` 直接换成 `e^{−κA}A^{α−1}`，即**把 `κ`（一个计数熵）当作面权的衰减率**。于是 `σ = σ₀ − κ` 是**定义**，不是推导——`(E) ⟺ σ₀>κ` 把答案的结构预先写进了式子里。

**"`W` 是矩阵元"的量纲后果**：`W` 无量纲，其 `R`-衰减率必须带 `L^{−2}`（`σ`）；而 `σ₀`、`κ`、`u` 全无量纲 ⇒ 必须乘 `a^{−2}`，而 `a=a(β)` ⇒ 指数必须带 `β`-跑动。**sp-b 的指数不带 `β`。**

## §3 判：缺的是不是"转移矩阵桥"？

**是，但它是链条最后一段；链条在它之前就断了。**

1. **只补谱桥**：(α) 仍假（`u(2.5)>1`），没有可桥的面求和。**循环是真的**（谱桥 ⟺ `m(R)=σR` ⟺ (E)），但是**冗余的**
   循环：不需要它就已经死了。
2. **只补 (α)**：得到强耦合区面积律——**已是 P3 `[T]`（`β<1/48`）**，对 `β=2.5` 无话；且该路线的阈值是 `u(β)=e^{−κ}`，即 `β ≲ 10^{−2}–10^{−1}`，与 P3 **同阶、不超出**。
3. **两段都补**：等价于直接假设 `σ>0` + 幂等支配 ⇒ 就是 (E)。

**⇒ `sp-b` 的接口不是"单向"，是"空"**：其唯一假设 `σ₀>κ` 恒真（§1 推论 3），所以它既不支持也不反对任何一侧。
**⇒ (a) 判 `[NG]`：算术路线整体不成立。死因排序（任一足够）：① `σ₀>κ` 恒真（假设空）；② (α) 在物理点为假（前提假）；③ 谱桥循环（结论即假设）。**

## §4 `κ`：有限性判据 + 为什么它无关

**定义（`[T]`）**：`a_A` := `Z⁴` 中边连通、含固定面片、面积 `A` 的面片簇数。`a_{A+B} ≥ a_A a_B`（拼接）⇒ Fekete ⇒
`μ := lim_A a_A^{1/A} = inf_A a_A^{1/A} ∈ [1,∞)`，`κ := log μ`。**`κ` 与 `β`、`N`、耦合无关。**

**粗界（`[C]`，可复核）**：
- **下界**：把面片压在单个 2-平面内 ⇒ 退化为 `Z²` 对偶格点动物 ⇒ `μ ≥ μ₂ ≈ 4.06`（与 RUNBOOK 的 `4.06^n` 同源）⇒ `κ ≥ 1.40`。
- **上界**：固定根、按坐标字典序做**唯一** DFS，动物由「`A−1` 次下行（每次 ≤ `Δ=12` 个邻面片）+ 上行」的走法树编码 ⇒ `a_A ≤ Δ^{A−1}·C(2A−2,A−1) ≤ (4Δ)^A` ⇒ `μ ≤ 48` ⇒ `κ ≤ 3.87`。
⇒ **`1.40 ≤ κ ≤ 3.87 < ∞`。`(c)` 假。**

**但 (c) 无关紧要（`[T]`）**：正确判据是 `lim(−log|w_β(A)|)/A > κ`；按 sp-b 自己的因子化 `w_A ≈ Π_p c_{j_p}` 取主导项 `j_p=1`，得 `lim(−log|w_β(A)|)/A = −log c₁(β)`，而
```
−log c₁(2.5) = −log 2.042346 = −0.714   <   0   ≤   κ。
```
⇒ **在 β=2.5，面权随 `A` 增长（不是衰减），故对一切 `κ ≥ 0` 判据皆假**；而 `σ₀ = ∞` 同时成立。**两分支（`κ<∞`/`κ=∞`）都让接口空，故我的 `κ` 界即使偏了也不影响判决。**
**附带 `[V]`**：`u(β)=2I₂/I₁` 单调增（`0.0100 / 0.2474 / 0.4804 / 0.9871 / 1.0008 / 1.0144`，`β=0.02/0.5/1.0/2.4/2.45/2.5`，`β→∞` 时 `→2`），`u=1` 在 `β*=2.4469`。**这是 0 维 Bessel 交叉，与 4D 相结构无关——`2.4469` 不可读作任何临界点。**

## §5 缺失条件的精确形式 + 自由场失效

**一句话**：`(E)` 缺的是「**在物理 `β` 处，面权序列 `w_β(A)` 的每面积指数衰减率必须超过面熵 `κ`，且极小面主导**」——一个 **`β`-局部、关于面权**的条件；`σ₀>κ` 用一个**与 `β` 无关、恒为 `∞`** 的系数渐近率替代了它。

**一个不等式**（把 sp-b 的 `≃` 全写成 `≤`）：
```
∃σ>0:   lim_{A→∞} (Ω_A·|w_β(A)|)^{1/A} ≤ e^{−σ} < 1 ,
       且  |W(C_R) − w_β(S_min(R))| = o(w_β(S_min(R))) .
```
（第一式 = 绝对收敛 + 正隙 = S3 的正确形式；第二式 = S4。S5 谱桥再把面求和翻译成 `m(R)=σR+o(R)`。）

**自由场酸测（`[V]`/`[T]`）**：

| 判据 | 自由场（`W=exp[−(g²/2)∮∮Δ]`，无面积项） | 强耦合 `β<1/48`（P3，有面积律） | 结论 |
|---|---|---|---|
| **原判据 `σ₀>κ`** | **通过**（`σ₀=∞`） | 通过（`σ₀=∞`） | **不分辨 ⇒ vacuous** |
| **修后判据（上式）** | **失败**：`w_A` 来自 `det(1−βM)^{−1/2}` 展开，`limsup|w_A|^{1/A}=λ_max>0`，`λ_max e^{κ}>1` | 通过（`u e^{κ}<1`） | **分辨 ⇒ 有内容** |

⇒ **原判据连自由场都排除不了：它不是"还差一条"，它没有任何假设。**

**`(b)` 的活口（唯一有内容的独立条件，`[C]`/提案）**：若能把 `A ↦ −log w_β(A)` 证成**凸**、`A ↦ w_β(A)` **log-凸**（Chebyshev / Griffiths–Kelly–Sherman 型），则 `σ_A := −log(w_β(A+1)/w_β(A)) − log μ` 单调增，面积律以 `σ = lim σ_A` 成立——**独立、可证、判据显式**。但：`lim σ_A` 就是弦张力 ⇒ **证它就是证 (E)**；自由场上它失败（`w_A` 变号 ⇒ 非 log-凸）。⇒ **活口是真活口，不是捷径：它把 (E) 换了个名字。**

## §6 量纲逐项（`[T]`）

| 量 | 定义 | 量纲 | 备注 |
|---|---|---|---|
| `c_n` | `I_n − I_{n+2}` | `1` | 单格面字符系数，`β`-整函数 |
| `σ₀` | `lim(−log c_n)/n` | `1` | `=∞`，`β`-盲 |
| `κ` | `log μ` | `1` | 纯组合 |
| `u` | `c₁/c₀ = 2I₂/I₁` | `1` | `β`-函数，`u(2.5)=1.014390` |

| `A` | 面片数 | `1`（格）= `L²/a²` | `A_min = πR²/a²` |
| `m(R)` | 静态势 | `L^{−1}` | 谱桥的输出 |
| `σ` | `−lim log W/A` | `L^{−2}` | 弦张力 |
| `a` | 格距 | `L` | `a = a(β)` |

`σ = π(σ₀−κ)/a²`（圆环；格单位 `σ_lat = π(σ₀−κ)`）。两条后果：
