## 1. `C(0)=Var`：恒等式，但要把它成立的三条前件写清（恒等 ≠ 无条件）

记 `O=¼trF²`（对每个 `(L,a)` 有界），`C(t):=⟨O(t)O(0)⟩−⟨O⟩²`，`ν` 为 `O` 的 KL/OS 谱测度。

1. **恒等 `[T]`**：`C(0)=⟨O²⟩−⟨O⟩²=Var_Ω(O)`。这一步只用 `t=0` 时 `O(0)O(0)=O²`，
   **不需要**自伴、不需要时间平移、不需要 RP、不需要谱的任何信息。它是**定义展开**，故**零内容**。
2. **恒等成立的三条前件（缺一即不成立，且都不是"物理"）**：
   (i) **必须已做连通减除** `−⟨O⟩²`；否则 `C(0)=⟨O²⟩≠Var`。
   (ii) **方差有限**：固定 `(L,a)` 成立；`V→∞` 且 `O` 不除以 `√V` 时两侧同为 `+∞`（同一对象，但等式无信息）。
   (iii) **接触项口径一致**：重整化后 `C_ren(0)=Var_ren(O_ren)`（两者同时乘 `Z_O²`，`T2:141–144`）。
3. **陷阱（本项目特有，必须先钉）**：`Var_Ω(O)` 是**算符**方差 `M₀=‖QOΩ‖²`，**不是**场零模方差
   `χ=Var(a_{k→0})=M₋₁`。`G″(0)=1/χ` 走的是后者（`META-GAPFORCING-IDENTITY:59`、`ch06:17–20`）。
   把两者混为"同一个 Var"，会把 `C(0)=Var` 读成 `C(0)=χ`——那是**错的**（`M₀~a⁻⁸`，`χ~a⁻⁴`，`U4:41–42`）。
4. **谱侧的恒等（连通减除的作用）`[T]`**：`C(t)=∫e^{−Et}dν`，`ν≥0`，且 `ν({0})=0`
   ——连通减除**恰好**删掉真空原子 `|⟨Ω|O|Ω⟩|²`。故
   ```
   M₀ := ∫dν = C(0) = Var_Ω(O) = Σ_{n≥1} fₙ²  (离散谱),  fₙ²=ν({Eₙ})=|⟨n|O|Ω⟩|² ≥ 0.
   ```
   这与语料逐字一致：`ch02:12`（`M₀=∫dν` 是总谱权）、`T2:134`（`M₀:=C(0)=‖φ‖²=Var(O)`）、
   `R4:223`（`f₁²=A₁ ≤ C(0)=Var(O_s)`）、`ch05:442`（`M₀=f₁²+∫dμ`）。

## 2. `f₁²` 与 `Var` 的关系：`≤` 是定理，`=` 是假设

1. **`f₁² ≤ Var` `[T]`（正性一行）**：`Var=M₀=f₁²+∫dμ`，`μ≥0` ⇒ `f₁²≤M₀`；
   等价地 `w₁:=f₁²/M₀∈[0,1]` 是**原子分数**（`T2:136`、`U6`）。
2. **`lim_{t→∞}e^{E₁t}C(t)=f₁²` `[T]`（不需要隔离）**：`e^{E₁t}C(t)=f₁²+∫_{E₁}^∞ e^{−(E−E₁)t}dν`，
   被积函数 `≤1` 且 `ν` 有限 ⇒ 支配收敛 ⇒ 极限 `=ν({E₁})=f₁²`。
   故 `t02` 的 `f₁²` 定义式（`T02:16`）与任务第 2 条的算术**正确**；`Λ★>m₁²` 是**率**（双指数余项）需要的前件，
   不是**极限存在**的前件（`ch05:434–436`）。
3. **等号 `⟺` 单原子 `[T]`（作为等价，不是作为事实）**：
   ```
   f₁² = Var  ⟺  ∫dμ = 0  ⟺  supp ν = {E₁}  ⟺  C(t)=Var·e^{−E₁t} ∀t  ⟺  O|Ω⟩ 是 H 的单个本征矢.
   ```
   语料已写明："the ground state carries at most all the spectral weight; **equality iff single-state**"
   （`R4:223–225`）；`w₁=1 iff the source is the tube`（`T2:139–140`）。
4. **多极点的算术（确认任务第 2 条）`[T]`**：`ν=Σfᵢ²δ_{Eᵢ}` ⇒ `C(0)=Σfᵢ² ≥ f₁²`，**严格**当 `∃n≥2: fₙ²>0`。
   即 `C(0)=Var` **不是** `f₁²`，而是 `f₁²` 的**上界**。

## 3. 单极点：不是"尚未证明"，而是**三处独立地不行**

1. **无来源 `[NG]`**：语料无一条定理、假设或近似给出"`ν` 单原子"。相反，`P3` 的余项本身**就是**多极点：
   余项 `O(u)`（`t`-一致）对应多管/多态贡献，`ch05:69–77`、`PROOF-P3-UNCONDITIONAL:31–33`。余项非零 ⇒ `w₁<1`。
2. **精确反例 `[T]`（`β=0` 锚点，语料已有）**：`β=0` 的 Haar 测度是乘积测度，
   `C(0)=Var>0` 而 **`f₁²=0` 精确**（`R4:226–229`："plaquette autocorrelation is a contact term (`C(t>0)=0`), so `f₁²=0` exactly"）。
   ⇒ **恒等 + 接触型单原子，仍然给出 `f₁²=0 ≠ Var`**：单原子可以坐在**截断/接触项**（`λ=0`，`E=∞`）上，
   其权重被重整化搬走，**不是**物理残数。要让"单极点"蕴含 `f₁²=Var`，必须再加一句
   **"该极点是物理最低极点 `E₁=am₁>0`，不是 UV 接触原子"**——这句正是接触减除/重整化/`a→0`，又一次是同一堵墙。
3. **连续极限下等号结构性不可能 `[T]`**：`f₁²` 在 IR 质量 `m₁≪1/a`，**只带乘性 `Z_O`、无接触项**；
   `M₀=C(0)=⟨O²⟩_c ~ a⁻⁸` **由 UV 接触项主导**。所以 `w₁^{bare}=f₁²/M₀^{bare}→0`（UV 假象，非物理跑动），
   "`f₁²=M₀`"在 `a→0` 是**有限量 = 发散量**（`U4:39–49`、`U4:116–118`）。
   ⇒ 至多能谈的是**重整化后**的比值 `w₁=f₁²/M₀∈[0,1]`（`γ_{w₁}=0`，`U4:27–37`），而 `w₁=1` 仍是假设。

**⇒ (a) 判死**：`C(0)=Var` 是恒等 `✓`，但"**能证单极点**"这一步既无来源、被 `β=0` 否证、且在 `a→0` 上与 IR/UV 错配不相容。
**"免费"不是"省一步证明"，而是把一条被否证的条件当成免费的。**

## 4. (b) `Var>0` 只给 `Σfᵢ²>0`；`f₁²>0` 需要的新信息是什么（逐字）

1. **`Var>0` 的全部内容 `[T]`**：`Var>0 ⟺ O|Ω⟩∉ℂ|Ω⟩ ⟺ M₀>0 ⟺ Σ_{n≥1}fₙ²>0`。
   它**不定位**权重落在哪一层谱，因此对 `f₁²` 只给 `f₁²≥0`（自由 Maxwell：`Var>0`，`ν` 是零阈连续谱，`f₁²=ν({0})=0`，`ch05:284–287`）。
2. **所需的新信息（唯一形式）`[T]`**：一条**尾部/泄漏上界**
   ```
   tail := Σ_{n≥2} fₙ² = ∫dμ ≤ (1−c)·M₀ ,   c>0     ⇒     f₁² = Var − tail ≥ c·Var > 0 .
   ```
   这就是语料已有的裁决："`f₁²=Var−tail` **是恒等式（同义反复）**；把它变成下界需要 `tail≤(1−c)Var`，
   而该尾部界**从正性/矩/算符范数可证为假**，且**等价于 `Λ=E₂` 的残数–level-gap 引理**"（`INEQ-R2-concentration:3,15`）。
3. **可算形式（唯一已证的定量证书）`[T]`**：`ν=f₁²δ_{m₁²}+μ`，`supp μ⊂[Λ★,∞)` ⇒
   ```
   f₁² ≥ (Λ★M₀ − M₁)/(Λ★ − m₁²) = M₀·(Λ★−R̄)/(Λ★−m₁²),   R̄:=M₁/M₀ .
   ```
   右端 `>0 ⟺ Λ★>R̄`（`ch05:422–436,439–449`；`T2:208` 的 `w₁` 版同式）。
   ⇒ **新信息的具体身份 = 第二尺度 `Λ★=E₂`（隔离 `I2` / `H1` 的等价物）**，一个**边（edge）数据**；
   而 `Var`、`M₁`、`χ` 全是**矩**数据。矩 ↛ 边：`δ₀+δ₂` 与 `2δ₁` 前两矩相同、边 `0` vs `1`（`GAP-G2-edge`、`A4:13`）。
   **这就是"差什么"的精确回答：差一个 `Λ`，不是差一个 `Var`。**
4. **一句话**：`Var(O)>0` 是**分母**（总权），`f₁²` 是**谱边的原子**；`Var>0` 甚至不能排除 `w₁→0`（`WA`：固定 `(M₀,Ē)` 时 `w₁` 从 `1` 滑到 `0`）。
