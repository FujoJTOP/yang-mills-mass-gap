### 2.1 `p` 的定义（三种旧写法 + 一种新写法）

`p` 是**边缘态在 UV 的自由能含量**的衰减指数。沿用 `GK1:172–179` 的三写法，本轮加第四种（矩写法，便于数值核与逐门记账）：

| 写法 | 内容 | 与 `p` 的关系 | 级 |
|---|---|---|---|
| **Sobolev**（`GK1:176`） | `q_high(ψ) ≤ CΛ_*^{2−2s}‖ψ‖²_{H^s}` | `p = 2s−2`，`k = 2−2/s` | `[M]` |
| **形状因子**（`GK1:177`） | `\|\hatψ(k)\|² ≲ \|k\|^{−2σ}` | `p = 2σ−5` | `[M]` |
| **直接**（`GK1:178`） | `q_high ≤ C(m_*/Λ_*)^p` | `p` | `[M]` |
| **矩写法（本轮）** | `κ_n(ψ) := Σ_k\|k\|^{n+2}\|\hatψ(k)\|² / Σ_k\|k\|²\|\hatψ(k)\|²`；`p := sup{n : κ_n(ψ_0) = O(a^n)}` | `κ_n = O(a^{min(n,p)})` | **`[T]`+`[E]`** |

### 2.2 ★ 命题 C4′（T2 段的正确记账，本轮核心技术结果）

> **命题 C4′（`[T]`+`[std]`+`[C]`）.** 记 `M := k₀/2 + 1`（`M` = 作用量里**不同时间跨度数**，`GL3:116` 的矩定理；`M=1` Wilson，`M=2` Lüscher–Weisz 树级，`M=3` dim-8）。设
>
> **(a)** `h^{imp}` 是 `H(4)`-不变的三角多项式（圈作用量符号），归一化 `h^{imp}(k) = |k|² + O(|k|⁴)`，且满足 `M−1` 个 Symanzik 条件（轴矩 `κ_2=…=κ_M=0`）；记 `b^{imp}(k) := |k|² − h^{imp}(k)`；
> **(b)** `Δ_cont` 是连续统谱隙，`q(ψ) ≥ Δ_cont‖ψ‖²` 对一切 `ψ ⊥ Ω`（`[std]`：`q` 用连续统符号 `|k|²` 定义）；
> **(c)** `ψ_0` 是 `q_a` 在单位球上的最小化者（边缘态），`Δ_a = q_a(ψ_0)`。
>
> 则
> ```
> |Δ_a/Δ_cont − 1|  ≤  C_M · κ_{2M}(ψ_0)  +  [T3 段] ,        C_M := sup_{k≠0} b^{imp}(k)/|k|^{2M+2} < ∞ .   (C4′)
> ```
> 若 `κ_{2M}(ψ_0) = O(a^p)`（即 `(H_p)` 以矩写法成立），则
> ```
> k_{T2} = min( 2M , p ) .                                                        (C4′-k)
> ```

**证明（四行）**：`q_a = q − 𝔟`，`𝔟 = (1/a²)Σ_k b^{imp}(k)|\hatψ|² ≤ C_M·(1/a²)Σ|k|^{2M+2}|\hatψ|² = C_M κ_{2M} q`。⇒ `Δ_a = q_a(ψ_0) ≥ q(ψ_0)(1−C_Mκ_{2M}) ≥ Δ_cont(1−C_Mκ_{2M})`（用 (b)）。另一侧：取连续统底态在格点上的采样 `ψ_1`（变分），`Δ_a ≤ q_a(ψ_1) = q(ψ_1) − 𝔟(ψ_1) ≤ q(ψ_1) = Δ_cont`（用 `𝔟 ≥ 0`）。两侧合起来即 (C4′)。∎

**为什么 `C_M < ∞`（(a) 的非平凡部分）**：`b^{imp}` 在 `k=0` 的 Taylor 展开落在 `H(4)` 不变多项式环 `ℝ[|k|², Σk_i⁴, Σk_i⁶, …]` 里；归一化杀 `|k|²`；`M−1` 个条件各杀一个组合。`2n` 阶不变式的个数是 `p_{≤4}(n)`（`GL3:87–96` 的同一张表），而条件数只有 `M−1 = k₀/2`：
```
2n=4 :  p_{≤4}(2)=2 ，杀 1（κ₂）⇒ 剩 1（=Σk_i⁴）⇒ 但归一化再杀 |k|⁴ ⇒ b 从 6 阶起
