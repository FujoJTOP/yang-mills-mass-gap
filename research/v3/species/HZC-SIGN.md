## §1 命题：什么叫"钉住"，判它是哪一句

### 1.1 两条读法，只有一条承重

```
(A) 唯一确定：ν 存在 ⇒ sign ∂_βw₁ ∈ {+,−,0} 有唯一值。       真，但等于"理论存在"，零不等式。
(B) 结构可判定（SP）：∃σ∈{+,−,0}，只用公理清单 I 与恒等式、不评估任何矩阵元，
    就证出窗内 sign ∂_βw₁=σ。                                （A)⇒(B) 假。
I = {规范不变, 反射正性, PF+唯一真空, 和规则 M₀=Σa_n², KS 恒等式 ∂_βH=(1/a)[¼X_B−(2/β²)X_E],
     O=¼trF²=pX_B+qX_E（p,q>0,β-无关）}
```

**判定法（可判命题）**：`SP` 真 ⟺ 符号在类 `𝔄(I)`（满足 `I` 的三元组）上**恒定**。故只需在 `𝔄(I)` 里造**两号见证**即可判假——不需要也不可能"遍历"。

### 1.2 三条恒等式（全部由 `⟨ψ_n|H|ψ_m⟩=0`（`n≠m`）一行推出）

`H=A(β)X_B+B(β)X_E`，`A=β/(2Na)`、`B=N/(aβ)`（`N=2,a=1` 复现 `HX6` 的 `¼` 与 `2/β²`）。对任意本征对：

```
(L1)  0=A·m_nm+B·e_nm  ⇒  e_nm = −(A/B)m_nm = −(β²/2N²)m_nm
(L2)  K₂₁=A'm₂₁+B'e₂₁ = m₂₁(A'−AB'/B) = m₂₁(1/(2Na)+1/(2Na)) = m₂₁/(Na)     ← 电项=磁项
(L3)  a_n=p·m₀ₙ+q·e₀ₙ = (p−qβ²/2N²)m₀ₙ  ⇒  w₁=a₁²/Σa_n² = m₀₁²/Σm₀ₙ²
      （m_ij:=⟨ψ_i|X_B|ψ_j⟩，e_ij:=⟨ψ_i|X_E|ψ_j⟩，a_n:=⟨Ω|O|ψ_n⟩）
```

`(L2)` 的关键不是"算出 `K₂₁`"，是 `A'−AB'/B=A'−A·(−2/β²)/(2/β)=1/(2Na)+1/(2Na)`：**两项同号等大**。`HX6` 说的"电-磁反号"住在系数 `(c_B,c_E)=(β/(2Na),N/(aβ))` 的导数里（`c_B'>0>c_E'`），**不进矩阵元**；矩阵元被 `(L1)` 锁成反号，两个反号相乘即得正。

### 1.3 `(L2)` 的读法勘误（对 `HS-GAP-1:45` 的标注，不改其判词）

`HS-GAP-1:45` 写 `sign ∂_βw₁ = sign(a₁a₂K₂₁)`；`σ₁−σ₂<0` 在分母 ⇒ 整体差一个 `−`：正确为 `sign ∂_βw₁ = −sign(a₁a₂K₂₁)`。其 `±192/125` 表与 `§0.7` 二分不受影响（只用乘积结构）。**下一手**：凡引 `(2)` 的符号句加 `−`，并注明首项 vs 全式（`∂_βM₀` 腿仍在）。

### 1.4 符号的最终形状

`w₁=m₀₁²/S`（`S=Σm₀ₙ²`）⇒ `∂_βw₁=(2m₀₁m₀₁'S−m₀₁²S')/S²`。⇒ **符号 = `X_B` 谱数据旋转率的符号**：`β` 的系数、`X_E`、`O` 的归一（`p,q`）、`Z_O` 全部不出现。这与 `HS-GAP-1 §0.3` 的"分子腿不在 `ν` 里"同向，但更窄：不在 `ν` 里的不是"源–流相关"，是 `m₀ₙ'`。

### 1.5 退化耦合

`A=B ⟺ β=√(2N²)`（`N=2`：`2.82843`）。此处 `H=(β/(2Na))(X_B+X_E)`，`p=q` 时 `O∝H` ⇒ 所有 `a_n=0`，`w₁=0/0`；比值 `m₀₁²/S` 有限 ⇒ **可去**。`β_W=2.66` 距它 `0.168`——`HV6` 的三点读数都在它下方，过点外推必须报这个距离。

## §2 玩具：为什么单片/2D 不算，KS 三能级算

### 2.1 单片 plaquette：无对象

单个 plaquette 没有时间方向 ⇒ 无转移矩阵 ⇒ 无 `|ψ_n⟩`、无 `σ_n`、无 `a_n`。`w₁` 不是"等于 0"，是**没有定义域**。`HS-GAP-1 §4` 已记，本文件只把它写成判据失败项：`PIN-C(i)` 失败。

### 2.2 2D 纯 YM：`0/0`

2D 的 Wilson 测度对 plaquette 变量**精确因子化**（`Z=z^{N_p}`；U(1) 上一行积分即可证：共享 link `φ` 时 `∫dθ e^{βcos(θ+φ)}` 与 `φ` 无关）。⇒ 分离 plaquette 的连通函数 `=0`，全部方差是**接触项**，KL 谱和为空。⇒ 谱意义下 `f₁²=M₀=0`，`w₁=0/0`；欧氏 `Var>0`（机检 [5]：`0.210509`）只是接触项。`PIN-C(i)` 失败。**2D 的"符号 = 0"是假通过**，不得引用。

### 2.3 3 能级 KS 玩具：正确的试验台

`X_B,X_E` 为 `3×3` 正矩阵（`X_B` 定，`X_E=R diag(.9,.4,.15)Rᵀ`），`H=AX_B+BX_E`，`O=X_B+X_E`，`A=β/4`、`B=2/β`。机检：

## §3 判定：`[NG]`，以及它对柱 2 意味着什么

**判 `[NG]`（`SP` 假）。** 不是"符号不可知"，是"符号不是结构量"：`(L1)–(L3)` 把电-磁竞争、`O`-归一、`Z_O`、 dressing 四条全消掉，符号只剩 `(2m₀₁m₀₁'S−m₀₁²S')/S²` 这一格，而它在 `𝔄(I)` 里取两号（2.3 [2]）。**既有的两条 `±` 见证不判 `SP`**（0.7）：它们的流是单支旋转，没有 `X_B/X_E` 分解——所以"符号不定"此前只是"不是 `ν` 的函数"，本文件把它升级成"不是 `I` 的函数"。

**柱 2 因此不可攻吗？不是。** 三件事：(1) 第三封**并进值封**——符号 = `X_B` 谱数据的 `β`-旋转率，与 `HV9 §0.4` 的分子腿 `∂_β𝔾` 是同一件；(2) 于是三条已封装置的真实分类是：单调形=更强、Grönwall=换名、符号=**值**——不是三种技巧，是两类；(3) 结构给出的**唯一新件**是 `(L2)`：核的符号 `=sign m₂₁`，`β`-无关 ⇒ 核不提供 `β`-换号，换号只能来自 `m₀ₙ` 的零点（`X_B` 的选择定则）。

**下一手（三条，按可执行性）**
