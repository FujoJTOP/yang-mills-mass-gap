# SP-F-LOOPALG — 环代数的**标度扇区**：`(★₁)` 有**有界非指数解**（自由模数 `c`，`f→c`）⇒ `[NG]`；同时 `(★₁)` 比 `(★)` **少一个 `R` 的幂**（非标度协变），`p=−1` 那个"解"根本不是解

## §0 判决（先写）

> **`[NG]`。`(★₁)` 的通解里存在有界非指数的整族解：`f(R) = c + κc²/(2R) + O(R^{−2})`，`c` 是**自由**积分常数（`|c|≤1` 即满足 `|W|≤1`），且这是**唯一的**有界扇区。⇒ 环代数不强制指数衰减，`c` 就是一个没被方程钉住的模数。**
> **附带（更致命，且是本轮真正的新发现）：`(★₁)` 本身错了一个 `R` 的幂。** 算符 `∂_μ δ/δσ_{μν}` 的量纲是 `L^{−3}`（`δ/δσ` 是 `L^{−2}`、`∂_μ` 是 `L^{−1}`），而 `d²/dR²` 是 `L^{−2}`。可判据：`(★)` 在 `R→sR` 下**精确协变**（两侧同为 `s^{−3}`），把 `f_s(R):=f(sR)` 代入 `(★₁)` 会**多出一个因子 `s`** ⇒ `(★₁)` **不是** `(★)` 的标度扇区约化。一个破坏了方程精确对称性的约化，不能用来断言"不存在标度不变解"。

## §1 化成自治方程：正确的替换是 `f = R·u(ln R)`（不是 `f = R^{−1}u`）

记 `κ := c₂g²N/c₁`（`κ>0`，几何常数比）、`R = e^t`。

- **lead 的替换 `f = R^{−1}u`**：`f″ = R^{−3}(u″ − 3u′ + 2u)`，右端 `= c₂λR^{−5}u²`，于是
  `c₁(u″ − 3u′ + 2u) = c₂λ e^{−2t} u²` —— **显含 `t`，不自治**。(符号也反了：`u~const` 对应 `f~R^{−1}`，而指数匹配要的是 `f~R^{+1}`。)
- **正确替换 `f = R u(t)`**：`f″ = R^{−2}(f_{tt}−f_t) = (u″ + u′)/R`，右端 `= c₂λ R^{-1}u²`，`R` 全部约掉：

  ```
  (★₂)   u″ + u′ = κ u²          （自治）
  ```

**这一行就是整个物种的结构定理**：`(★₂)` 不显含 `t` ⟺ 解空间对 `t`-平移（即 `R`-标度）封闭 ⟺ **算符没有内禀标度**。自治性 = 标度协变性 = "代数不可能自己长出一个标度"。（这一步与 `(★)` 的精确协变性一致，也正是 `(★₁)` 因丢了 `R` 幂而**不**具有的性质。）

**首次积分（积分形式）**，由 `(e^tu′)′ = e^tu″ + e^tu′ = κe^tu²`：

```
e^t u′(t) = u′(0) + κ ∫₀^t e^s u(s)² ds
```

降阶：`p:=u′`，二维系统 `u′ = p`，`p′ = κu² − p`；**原点线性化** `M = [[0,1],[0,−1]]`，`eig = {0, −1}` ⇒ **一维稳定流形 + 一维中心方向**（非双曲）。这正是"解里带一个自由常数"的来源。无初等闭式通解（二阶非线性；`u~A(t−t₀)^{−2}` 的领头平衡给 `A=6/κ`、共振 `r=−1,6`，属 Painlevé 型），但**渐近分类是完整的**（下节）。

## §2 有界非指数解：**存在**，且是唯一的有限扇区

设 `u ~ C e^{−λt}`，代入 `(★₂)`：`C(λ²−λ)e^{−λt} = κC²e^{−2λt}` ⇒ **`λ = 1`**（`λ=0` 只给 `C=0`）。逐阶展开（一参数族，`c` 自由）：

```
u = c e^{−t} + (κc²/2) e^{−2t} + (κ²c³/6) e^{−3t} + …
f = R u = c + κc²/(2R) + κ²c³/(6R²) + …                      (2.1)
```

⇒ **`f` 有界、非指数**（幂律指数 `p = 0`，带 `1/R` 尾），`c` 不被方程决定。`[T-形式渐近] + [V]`

**其余扇区全部无界**（故 `(2.1)` 是唯一的"有界"扇区）：

| 扇区 | `t→∞` 行为 | `f = Ru` | 判定 |
|---|---|---|---|
| 稳定流形（`λ=1`） | `u ~ c e^{−t}` | `f → c`，`c` 自由，`p=0` | **有界非指数 ⇒ 命中 lead 的 `[NG]` 判据** |
| 中心方向（`M` 的 `0` 本征向） | `u′ = κu²` ⇒ `u ~ −1/(κ(t−t₀))` | `f ~ −R/(κ ln R)` | 无界，被 `|W|≤1` 排除 |
| 增长支 | `u` 单调增 | `f → +∞` | 排除 |

**数值见证 `[V]`**（`py -3.12 -I`，RK4，`κ=1`；从 `t=20` 的三阶渐近**反向**积分到 `t=0` 取得稳定流形初值，再正向推进）：

- `c=+0.5`：`f = 0.500836 (R=1.5e2)`、`0.500025 (R=2.7e5)` ⇒ 收敛到 `c`；`c=−0.5`、`c=0.9` 同样收敛到各自 `c` ⇒ **一参数族，`c` 自由**。
- 偏离稳定流形（如 `f(1)=0.5, f′(1)=0`）⇒ 数值发散（`f≈4.0` 后爆掉）⇒ 有界族的余维数 = 1。

**⇒ 判决 2：`(★₁)` 的通解里有"有界非指数"解，而且是整族。按 lead 的判据：环代数不强制隙，`[NG]`。**

## §3 面积律自检：**不满足**；但由此得到的不是"面积律错"，是 `(★₁)` 错

`f = e^{−σR²}`（`σ=1`）代入 `(★₁)`，`LHS/RHS`：`5.44 (R=1)` → `6.1e3 (R=2)` → `7.4e6 (R=3)` → `8.8e14 (R=5)`，一般地 `∝ e^{+σR²}R⁵ → ∞`。**确实不满足。** 但这不是面积律的问题，是约化的问题——三处账：

- **(F1) 丢了一个 `R` 的幂（根因）。** 算符 `L^{−3}`，"`d²/dR²`" 是 `L^{−2}`。正确形式必是 Euler 型 `αR²f″ + βRf′ + γf = κf²`（两侧同为 `R⁰`，**显式标度不变**）；`(★₁)` 写成了 `c₁f″ = κf²/R³`。**判据（无需算出常数 `c₁,c₂`，纯对称性）**：设 `f` 解 `(★₁)`。在宗量 `sR` 处方程是 `c₁f″(sR) = κf(sR)²/(sR)³`；两边乘 `s²` 得 `c₁s²f″(sR) = κf(sR)²/(sR³)`。而把 `f_s(R):=f(sR)` 代入 `(★₁)` 得 `c₁s²f″(sR) = κf(sR)²/R³`。两式右端差**因子 `s`** ⇒ `f_s` 只在 `s=1` 时是解 ⇒ **`(★₁)` 破坏标度协变**；而 `(★)` 在 `x→sx` 下两侧同为 `s^{−3}`，精确协变（`W_s(C):=W(sC)` 是解）。
- **(F2) 于是 `p=−1` 是记账产物，而且 `f=cR` 根本不是解。** 正确权重匹配是 `−p−3 = −2p−3 ⇒ p = 0`（`(★₁)` 用的是 `f″` 的 `−p−2`）。直接验：`f=cR ⇒ f″=0`，右端 `κc²/R ≠ 0`，残差 `−κc²/R` **永不消失**（`R=1,3` 给 `−1.000, −0.333`）。**所以"`p=−1` 被 `|W|≤1` 排除"排除的是一个空集**——指数匹配在 `f″` 上做、而 `f~R` 让 `f″≡0`，这是自相矛盾的匹配。
- **(F3) 圆扇区本来就装不下二次项的内容。** "呼吸模 ⇒ 局部算符"这个*形式*没错（`αf″+βf′/R+γf/R²`），错在**只留首项**；更要紧的是：简单圆上 `x=y` 的切分是退化的（切的是一段零长弧 + 整圈），**MM 方程的二次项在自交点上才有非平凡内容**（语料 `unconditional/CONSTRUCT-LARGEN-BOOTSTRAP.md`：`D=4` 的闭合亏欠按多联骨牌 `~4.06ⁿ` 增长，`D=2` 才精确闭合）。故"圆环扇区"单 ODE 在结构上不可能承载禁闭内容。

**顺带一条更强的负结果 `[T]`**：`(★₁)` 里**不存在任何衰减解**（不止幂律）。主导平衡 `−q−2 = −2q−3` 只给 `q=−1`（增长）；指数衰减更不行（`R⁵e^{+σR²}` 型失配）。**一个把面积律和一切衰减都排除掉的约化，不可能是禁闭环方程的约化**——这本身就证明它是错的约化，而不是一条"禁止幂律"的定理。

## §4 判决（给 lead 的三行结论）

1. **自治化**：`f = R·u(ln R)` ⇒ **`u″ + u′ = κu²`**（自治；`f=R^{−1}u` 不自治）。首次积分 `e^tu′ = u′(0) + κ∫₀^te^su²ds`；原点 `eig={0,−1}`。
2. **有界非指数解存在**（唯一有界扇区，一参数族，`f = c + κc²/(2R)+…`，`c` 自由）⇒ **`[NG]`：环代数不强制隙**。自由常数 `c` 就是"本该由隙来钉住"的那个模数；矩阵 `M` 的那个 `0` 本征值就是这条平坦方向。
3. **面积律不满足 `(★₁)`，但错在 `(★₁)`**：`(F1)` 少一个 `R` 的幂（`(★₁)` 非标度协变，`(★)` 是）；`(F2)` 正确匹配给 `p=0`，`f=cR` 残差 `−κc²/R≠0`，"排除 `p=−1`"排除的是空集；`(F3)` 圆的切分退化，二次项活在自交点（`D=2` 精确闭合 vs `D=4` 多联骨牌爆炸）。
4. **要正结论还缺什么**：一个**标度协变**的约化（`p=0` 扇区）+ 一个自交点/多圈扇区，并且要把 `c` 之外的那个常数钉住——**那一步不是代数，正是隙本身**。`[O]`

**文献佐证 `[A]`**：4D 的 MM 方程"admit a family of solutions which is then subjected to the constraints"（KEK preprint 8501138, *Loop equations and constraints in QCD₂*）——即文献自己就说 4D 的解是**一族**、靠额外约束才收窄；这与 `[NG]` 同向。
