## §1 `w₁` 的三条概率形式：逐字推导与各自的失效点

### 1.1 P1（原子质量）——`[T]`，但事件自指

`ν ≥ 0`、`M₀ = ν(ℝ) ∈ (0,∞)` ⇒ `μ = ν/M₀` 是 `[0,∞)` 上的概率测度，`w₁ = μ({m₁²})` 是**一个概率**，
`w₁∈[0,1]` 白拿（与 `U01.md §3` 一致）。**但**：事件 `{S = m₁²}` 里的 `m₁² = inf supp ν` **就是隙本身**
⇒ 要写下这个事件，已经要会算 `m₁²`。（`w₁` 与 `m₁` 互相定义：这正是 `R3-ATOM-FUNCTIONAL.md` 的循环性。）

### 1.2 P2（稀有事件前缀）——`[T]`，但提取要隙

`C(t)=∫e^{−st}dν(s) ⇒ C(t)/C(0) = E_μ[e^{−tS}]`。概率读法：取率 `S~μ` 的 Poisson 过程 `N_t`，则
`E_μ[e^{−tS}] = P(N_t = 0)` 是"`t` 内**零次跃迁**"这一**稀有事件**的概率，其大偏差率即 `m₁`，**前缀即 `w₁`**：

```
P(N_t=0) = w₁ e^{−m₁ t}(1+o(1)),   w₁ = lim_{t↑∞} e^{m₁ t} P(N_t=0) .        [T]
```

⇒ `w₁` 确实是"稀有事件的**指数前缀**"。**失效点**：读前缀要 `m₁`，读 `m₁` 要前缀 ⇒ **双未知**；
且 `ŵ₁(T) ↓ w₁` 是**递减上界**（`T2:190`），有限 `T` 只从**上方**逼近，`inf_T` 是极限不是新参数（`U07.md:61`）。
`L` 侧同病（`R3:169–171` Stone–Weierstrass：`sup_ν|E−g| ≥ f₁²/2`，仪器误差 ≥ 信号）。

### 1.3 P3（方差份额）——`[T]`，但相关对象**变号**

取 `o` = 单点 `¼trF²`、`1` = 真空常函数、`ψ₁` = 转移矩阵最低非平凡本征向量，则

```
w₁ = |⟨ψ₁|o−1⟩|² / Var(o) = ρ²(o,ψ₁) ∈ [0,1] .                                [T]
```

这是纯统计语言：**最低模解释的方差份额**（`R²`）。**失效点**：`ψ₁` 是**节线函数**（`⟨ψ₁|1⟩=0` ⇒ 必变号，
`U1-HARNACK-BOUND.md:136`、`D05-FKG.md §2` `[T]`），故 `ρ²` 的相关对象**不是增函数**，FKG 的 `Cov(f,g)≥0`
对它无话可说；且 `ρ²` 需要 `Var(o)` 的**上**界才有下界——方向错（§2）。

> **§1 小结**：三条都是概率/统计量，`[T]` 全过。**"是不是概率"不是本路的瓶颈。**

## §2 模方 → 期望：为什么这一步过不去（本路的真阻塞）

任务书设想的读法是 `|⟨Ω|O|𝔾⟩|² = P(某事件)`。**逐字判：不能。** 原因是 Cauchy–Schwarz 的**方向**：

```
记 φ := QO|Ω⟩（Q = 1−|Ω⟩⟨Ω|，源）， 则  f₁² = |⟨𝔾|φ⟩|² ,  w₁ = |⟨𝔾|φ⟩|²/‖φ‖² .
⟨𝔾|φ⟩ 是"两个正流之差"：PF 只控 |·|，不能把差与 0 分开。   [T]（W1B-P3-AMPLITUDE.md:172–177）
若硬写成期望： w₁ = |E_μ[X]|²  ⇒  |E_μ X|² ≤ E_μ|X|²  —— 给的是【上界】。
```

⇒ **模方的下界 ⟺ "无相消" ⟺ `X` 定号。** 定号正是 P3 在 `β<1/48` 拿到（`f⊗f̄→1` 的正重叠，`U5`/`R5`）、
在 `β≈2.5` **拿不到**的那一条（`W1B §4.4–4.5`：`SU(N≥3)` 的 `c_r≥0` 无定理；`φ` 符号不定）。这条与语料三处同判：

## §4 「局域 ⇒ `L` 无关」：任务前提 (3) 是**假**的（精确反例）

### 4.1 局域源 + 离域最低模 ⇒ `w₁ ∝ 1/L`　`[E]` 精确

`U1-HARNACK-BOUND.md:334–340`（本仓已跑，精确解）：

| `L` | 4 | 8 | 16 | 32 | 64 |
|---|---|---|---|---|---|
| `w₁`（**局域**源 `:φ²:`，自由链） | 0.6667 | 0.2857 | 0.1333 | 0.0645 | 0.0317 |
| 解析 `2/(L−1)` | ✓ | ✓ | ✓ | ✓ | ✓ |

⇒ **源是局域的，`w₁` 仍 `→0`**。原因：局域性在**分子（源）**上，而 `w₁` 是**比值**，分母由**最低本征向量**定，
最低模在无隙时**离域**（`ψ₁ ~ 1/√L`）⇒ 重叠 `∝1/L`。
**这一条直接否掉任务前提 (3)："事件局域 ⇒ 概率与 `L` 无关"。** 局域只保证**分子**的 `L`-无关，
不保证**原子分数**的 `L`-无关。（有隙时 `ψ₁` 局域化，`w₁` 才可能 `L`-稳——那又回到"要有隙"。）
