## 2. 三个精确恒等式

### 2.1 `(I)` 条件化求导恒等式 —— `Δ_dyn` 的**正确**识别 `[T]`

条件测度 `ρ(a) = ∫ e^{-V}δ(ξ−a)dX`（`ξ = ⟨v,X⟩`）。用 `ρ' = −ρ·E[∂_vV|a]` 与
`(ρE[f|a])' = ρE[∂_vf − f∂_vV|a]`（分部积分，边界项由 `J|_{∂Ω}=0` 消掉，同 `main.tex:1145–1150`）：

```
d/da E[f|a] = E[∂_v f|a] − Cov(f, ∂_vV|a) .                                   (*)
```

- 取 `f = F = ∂_vV`：`d/da m(a) = E[κ|a] − Var(F|a) = G''(a) = −∂_a² log ρ(a)`。**这就是题目问题 3 的识别，但它对应的是 `(F,κ)`，不是 `(G,H)`。**
- 取 `f = G = ∂_v S`：`d/da E[G|a] = E[H|a] − Cov(G, G+Φ'|a)`，故

```
(I)   Δ_dyn(a) = d/da E[G_v|a] + Cov(G_v, Φ'|a) = m_G'(a) + Cov(G,Φ'|a) .      [T]
```

`Δ_dyn` **是「条件平均力的斜率 + 一个交叉协方差」**，两项符号独立 ⇒ **不是方差**。
（对照：若 `Φ≡0`，(I) 退化为 `Δ_dyn(a) = m_G'(a) = E[∂_v²S|a] − Var(∂_vS|a) = −∂_a²log ρ(a)`。）

**所以题目问题 2 的提示只在 `(F,κ)` 对上成立**：`E[κ] − Var(F) = −∂_a² log ρ = ρ'²/ρ² − ρ''/ρ`，
它 `≥0 ⟺ log ρ` 凹，**不自动成立**；而 `Δ_dyn = −∂_a²log ρ − W_full`（`W_full = W_geo+X`），
即 `Δ_dyn ≥ 0 ⟺ −∂_a²log ρ(a₀) ≥ W_geo(a₀) + X(a₀)`。这是 §4 的充分条件骨架。

### 2.2 `(II)` 平均正性 —— 唯一「免费」的正性 `[T]`

无条件下恒等式 `E_μ[H] − Var_μ(G) = W_geo^avg`（`= E_μ[Φ'']−Var_μ(Φ') ≥ (N/12)‖v‖²`，`eq:shadowproof`）
+ 全方差公式 `Var_μ(G) = E_ρ[Var(G|a)] + Var_ρ(m_G)`、`E_μ[H] = E_ρ[E[H|a]]`，两式相减：

```
(II)  E_{a∼ρ}[Δ_dyn(a)] = W_geo^avg + Var_ρ(m_G)  ≥  (N/12)‖v‖²  >  0 .        [T]
```

**这是本题能拿到的最强正性**：`Δ_dyn` 在**条件变量 `a` 的 ρ-平均**下是「已证正项 + 一个方差」，
无任何假设、无小参数、对自由场退化为 `0`（`S≡0 ⇒ G≡0 ⇒ m_G≡0`, `W_geo^avg` 侧由 Prékopa 仍 >0，
但 `Δ_dyn≡0`——见 §3 酸测，**不 vacuous**）。
**但它不是 (a)**：H1 要的是**固定粗场 `a₀` 的点值** `Δ_dyn(a₀) ≥ a²Δ₀²`，而 (II) 只约束 ρ-平均。
两者的差额恰是 `Var_ρ(m_G)`（条件化把「条件平均力的涨落」整块扣掉），这就是精确缺失的一步。

### 2.3 `(III)` 横向分部积分仍活 ⇒ 方差表示**只对除 `v` 外的方向存在** `[T]`

在条件测度 `ν = μ(·|ξ=0)` 上，横向 `ONB {e_i}_{i≥2}` 的 IBP 不被切断：
`E_ν[∂_{e_i}f] = E_ν[f∂_{e_i}V]`。取 `f = ∂_{e_i}S` 并对 `i` 求和：

```
(III) E_ν[Δ_⊥S|0] = E_ν[|∇_⊥S|²|0] + E_ν[∇_⊥S·∇_⊥Φ|0] ,    Φ≡0 时 = E[|∇_⊥S|²|0] ≥ 0 .
```

**结构解释**：方差/平方表示对**每一个横向**都成立（纯平方），**唯独沿条件化方向 `v` 的那一个不成立**——
条件化 `ξ=0` 正好把 `v` 方向「用掉」，沿 `v` 的分部积分没有边界项可消。`Δ_dyn` 偏偏就是沿 `v` 的那一个。

## 3. 反例与酸测（判 (c) 的硬证据）

**(i) 精确反例 `[T]`（平直测度双井）**：`Φ≡0`（无 Jacobian），`ρ ∝ e^{-S}`，`S(a) = a⁴/4 − a²/2`。
在井间 `a=0`：`G = a³−a`、`H = 3a²−1` ⇒ `E[H|0] = −1`、`Var(G|0) = 0` ⇒

```
Δ_dyn(0) = −1 < 0      （且 −∂_a²log ρ(0) = S''(0) = −1，与 (I) 一致）
```

⇒ **任何「`Δ_dyn` 恒等于某方差/平方期望」的断言被此例证伪**。这不是 YM 的特例，但它排除了**代数恒等式**这一整类；
而 `Δ_dyn` 的表达式**完全不含 `Φ`**，故没有任何 `Φ`-侧的凸性（Prékopa）能替它补符号。

**(ii) 自由场 / 高斯酸测 `[T]`**：`S = c a²/2`（平直）⇒ `E[H]=c`、`Var(G)=c²·Var(a)=c` ⇒ `Δ_dyn ≡ 0`。
即 **`Δ_dyn` = 边缘分布的「非高斯性/非 log-凹性亏损」**：高斯边缘给 0，`S≡0` 给 0。
⇒ 它**过酸测**（自由场失效），是真正的动力学对象，不是记账伪量。

**(iii) YM 类内的负值**：`o27` o11 模给 `−0.179 ± 0.225`（`0.8σ`，`O27-ADJUDICATE.md:89,130`）。
`[C]`：与 (c) 同向，但**不足以**判 `Δ_dyn<0` 在 `β=2.5` 真发生。

## 5. 对 `o27` 数值（`+0.562 ± 0.277`）的判读

- 它是 `(I)` 的**点值**：`Δ_dyn(a₀) = m_G'(a₀) + Cov`，不是定理，`2σ` 内符号未定——**只能当 `[C]/[E]`**。
- **与 (II) 不矛盾、且 (II) 给出新约束**：`β=2.5, L=2, o13 图`上 `W_geo^avg`（实测 `+1.09±0.02`）⇒
  `E_ρ[Δ_dyn] ≥ 1.09`（再加 `Var_ρ(m_G) ≥ 0`），而障壁点值只 `+0.56`。
  ⇒ **可核后果（`[M]`，一次 ensemble 就能做）**：`Δ_dyn` 在 `a₀` 之外的某些 `a` 上必须 `≥ 1.09`；
  若在 3–4 个 `a` 采样点上 `ρ`-加权平均都到不了 `1.09`，则这批数（或 `eq:shadowproof` 的口径）有问题。
  这同时说明：**把 `Δ_dyn(a₀)` 当 H1 的左半边是拿点值顶平均值**，`2σ` 不是统计问题而是对象问题。
- `Δ_dyn` **不该**承重：承重的是 `G''(0) = C = Δ_dyn + W_full`（两个模都 `>0`：`+1.696±0.293` / `+0.946±0.210`，`O27:90–91`），
  且 `G''(0) = −∂_a²log ρ` 是**单一**对象（`2.3`/(I) 的第二条）——H1 挂在它上面才不需要 `Δ_dyn` 的符号。

## 6. 判

- **(a) 不成立。** `Δ_dyn` 没有显式非负表示：`(I)` 的两项符号独立，§3(i) 的精确反例排除一切代数恒等式；
  `Δ_dyn` 不含 `Φ`，拿不到 `W_geo` 那条 Prékopa 免费正性。**H1 的左半边不是免费的。**
- **(b) 部分成立且给了最硬的替代品。** 点值只要**一个**可核充分条件 `S1`（力单调 + 非负关联）；
  另有 `[T]` 的 **(II) 平均正性**：`E_ρ[Δ_dyn] = W_geo^avg + Var_ρ(m_G) ≥ (N/12)‖v‖²`，
  这是本物种的真结果——**把 `Δ_dyn` 的正性从「点值未定」精确搬成「平均免费 + 点值差一个 `Var_ρ(m_G)`」**。
- **(c) 点值意义成立。** `Δ_dyn` 本质不定（`S1` 的两个符号都不受已证定理约束；`o11` 模 `−0.18±0.23`）。
  `o27` 的 `+0.56` **只是数值**，且是点值、非 ρ-平均，不能进免疫图。
