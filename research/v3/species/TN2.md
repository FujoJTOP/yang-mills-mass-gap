## 2 · `2.4 = 12/5` 有结构意义吗（第二问）

### 2.1 `48` 与 `Δ` 各自的来历

```
48  = 16(d−1)          ← SZZ 阈值分母：|β| < 1/(16(d−1))，d=4 ⇒ β<1/48   (AUDIT-R1:17,108)
Δ   = 4(2(d−1)−1) = 4(2d−3)  ← 每片 4 link × (每 link 6 片 − 自己)        (P3:116)
⇒ 48/Δ = 16(d−1) / 4(2d−3) = 4(d−1)/(2d−3)     d=4  ⇒  12/5 = 2.4        [T]
```

### 2.2 `2.4` 是 d-族的 d=4 值（这才是它的结构）

| 5 | 28 | 64 | 2.28571 | 1.18925 |

`g(d) := eΔ/48 = e(2d−3)/(4(d−1))`，`g' ∝ 1/(d−1)² > 0`（单调升），`g(d*)=1 ⇒ d* = (3e−4)/(2e−4) = 2.89221119`（**非整数**）⇒ **整数 d ≥ 3 全部缺口 >1**，d=3 只差 `1.90%`，d=4 差 `11.71%`。`[E]`

## 3 · `λ_T ≤ 2.4Δ` 若成立，推出什么（第三问）

判据（`KP6:65` 逐字）：`K̂·λ_T·u(1/48) < 1`，`u = β/(2N²) = β/8`（`N=2`）⇒ `λ_T < 48 = 2.4Δ`。因 `K̂·u(β) = 2N²·β/(2N²) = β`（**`N`-无关**，`ADJ2:56`），这条等价于

```
λ_T · β < 1        ⟺        β < 1/λ_T =: β_KP         （λ_T = eΔ ⇒ β_KP = 0.0183940）
```

于是若 `λ_T ≤ 2.4Δ = 48`：

1. **窗变宽到 `β < 1/48`**（现为 `0.88291×(1/48)`）⇒ **KP 簇展开的绝对收敛半径恰好够到 SZZ 的天花板 `1/48`**。`[C]`
2. **推论是"同一窗两条独立证明"**：P3 强耦合残数定理（`f₁²>0` at `β<1/48`，`PROOF-P3-UNCONDITIONAL.md`）与 SZZ 的 `β<1/48` 有隙定理**首次在同一条半径上重合**，不再留 `0.8829` 的空档。`[C]`
3. **不推出任何关于 `β=2.5` 的事**：`2.5/(1/48) = 120×` 不变；Savvidy 交叉点仍在窗外 ⇒ **Clay 进度不变（0%）**。`[T]`
4. 真值层看 `1/λ_* ≈ 0.0397 = 1.91×(1/48)`：若用真值，窗不仅够到、还**超出 1.9 倍**（但 SZZ 那条只用到 `1/48`，多出的部分对 Clay 无用）。`[E]`

**⇒ 结构结论**：`λ_T ≤ 2.4Δ` 的价值是**"把 `1/48` 从引文变成自证"**，不是开窗。它若成立，`1/48` 的**天花板身份被加固**（`p1` 的 `1/48` 由两条独立路线钉住），而不是被突破。
