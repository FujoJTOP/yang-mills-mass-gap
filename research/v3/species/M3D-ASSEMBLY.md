## §1 装配的精确形式：`m>0` 是直接的，而且**过直**

```
Δ_c := inf spec( H|_{H_c∩Ω⊥} )                                   [定义；L3A:58，单位 = 质量²]
装配引理：H 与 O_h 及平移对易 ⇒ H_c 约化，H|Ω⊥ = ⊕_c (H_c∩Ω⊥)
            ⇒ inf spec(H|Ω⊥) = inf_c Δ_c                          [T；L3A:76，纯表示论+谱定理]
(★-gap)： ∃δ>0 ∀c∈Chan : Δ_c ≥ δΛ
⇒ （序论） inf_c Δ_c ≥ δΛ                                          [T，一步]
⇒ m² := inf spec(H|Ω⊥) = inf_c Δ_c ≥ δΛ > 0                        [T]
```

**这就是全部。** 若问"那 `m>0` 是直接的？"——**是，且比直接更强：它是恒等的。**

1. **反向也成立**：`m>0` ⇒ 取 `δ = m²/2` ⇒ `∀c: Δ_c ≥ m² ≥ δ`。⇒ `(★-gap) ⟺ m>0`（在同一窗口、同一 `δ`-无关意义下）。
   ⇒ **装配不缩短任何一个字**；`(★-gap)` 的全部内容就是"全道一致地板"，没有别的。
2. **`I1/I2` 的不可省性不在装配里**：地板由 `(★-gap)` 单独给出（`L3A:85` 逐字："`(★)` 单独已给 `m>0` 的 floor；`I2` 不参与第 1–2 步"）。
   `I2` 的承重点只有一个：让那个 `inf` 被**孤立层**达到而不是累积点（`L3A:82` 第 3 步）——那是**粒子性/隔离**，不是 Clay 的 floor。
   ⇒ 用户块里的"两道：`0⁺⁺` 与 `2⁺⁺` 各有 `I1`+`I2`"在装配中扮演的是**`(★-gap)` 的证据**（且只在窗内对两个 `a_c=1` 的道有效），**不是**前提。
3. **装配引理的唯一实质内容是两个技术点，都不是新数学**：
   (i) 约化 + 穷尽性（`[T]`，有限空间群的表现论）；
   (ii) **真空原子的剥离**——见 §1.4。
4. **形式病（必须改，否则陈述为假）**：`inf supp ν_c` 若 `ν_c` 是道内算符的谱测度，则 `c=0⁺⁺` 上
   `⟨Ω|O|Ω⟩² δ_0` 是**真空原子**，`inf supp ν_{0⁺⁺} = 0` ⇒ **字面式 `(★-gap)` 在 `0⁺⁺` 上假**，
   而且"证明"它只能得到 `δ = 0`。正确形式必须写 `Δ_c = inf spec(H|_{H_c∩Ω⊥})`（`L3A:58` 已经是对的），
   或写 `inf(supp ν_c \ {0})`。这是**形式修正，不改实质**：`a_c ≥ 1` 的分级本来就是把真空减掉的读法。
   ⇒ `L3C:124` 的逐字式应替换为 `∃δ>0 ∀c: inf spec(H|_{H_c∩Ω⊥}) ≥ δΛ`。`[T]`

**⇒ 一句判**：装配是 `[T]`，但它是**恒等映射**；L3 的"装配"不是把难变易，而是把**同一个目标**换成一个**按道标号展开**的坐标。

## §4 判死线

### (a) 若 `(★-gap)` 的**证明结构**能推到 `β=2.5` ⇒ 那才是价值：**不可行，`[NG]`**

三条**独立的**理由，任一条就够：

1. **路线 A 的引擎是收敛半径，不是常数**：通道级判据是 KP/聚合物条件（`Σ_{P∋x}|w(P)|e^{α|P|} ≤ α`，`L3C:91`），
   它与 `u<1`（即 `eΔβ<1`）同生共死。`β=2.5` 上 **`u` 是 `O(1)`，不存在展开参数** ⇒ 不是"缺一个数"，
   是**没有小参数**。⇒ `[NG]`（原理性，非 `[O]`）。
2. **路线 B 的式子本身是强耦合渐近**：`m_c = a_c·ln(1/u) + O(1)`（`PROOF-IN11:9`）在 `2.5` 上没有意义——
   `ln(1/u) = 5.38` 只是**窗边**的一个数；`a_c` 分级的"每片多花"结构在 `2.5` 上不是谱的渐近，`a_c` 甚至无定义。
   ⇒ 结构不可移植。
3. **`2.5` 上承重的形式不是 `(★-gap)` 的常数地板，是 (T4)**：`∃Δ₀>0 ∀a<a₀: m_{0⁺⁺}(a) ≥ Δ₀`（`L4B:104`，= `H1` 的量纲修正版）。
