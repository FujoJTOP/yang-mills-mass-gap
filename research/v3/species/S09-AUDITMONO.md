## 1. Jacobian 核对（第 1 项，最关键）`[T]`

`x = cos u`：`u∈(0,π) ↔ x∈(−1,1)`，C¹ 双射、单调递减，故
`du = −dx/√(1−x²)`，`sin²u = 1−x²`。代进测度：

```
sin²u/u du = (1−x²)/u · du = (1−x²)/arccos x · (−dx/√(1−x²))
           = − √(1−x²)/arccos x dx      （负号 = 定向翻转：u:0→π  ⇔  x:1→−1）

∫₀^π h(u) du = ∫_{−1}^{1} h(arccos x)·w(x) dx ,     w(x) := √(1−x²)/arccos x
```

于是

```
ν_c ∝ e^{−β} · e^{βcx} w(x) dx ∝ e^{βcx} w(x) dx        （e^{−β} 与 w 都与 c 无关）
```

**结论：是 `e^{βcx}w(x)dx`，指数族成立。** 关键点：那个 `1/√(1−x²)` 被 `sin²u = 1−x²` **正好吃掉**，剩下的 `w(x)=√(1−x²)/arccos x` **不含 c**；Jacobian 唯一的作用是把 `sin²u/u du` 换成 `w dx`，**没有**给指数注入任何 `c`-依赖。因此 `∂_c E[f] = β·Cov(f,x)` 的整条推导**成立**。

数值核对（`s09_audit_mono.log` §[1]）：

| 量 | 我的值 |
|---|---|
| `∫₀^π sin²u/u du` | `1.218826696528612205905355170718342072206` |
| `∫_{−1}^{1} w(x)dx` | 同值，`|diff| = 0.0` |
| `Cin(2π)/2`（精确闭式） | 同值，`|diff| = 0.0` |
| u-积分 vs x-积分，`f∈{1, x, g, Φ″}`，`c∈{0,.3,.7,1}` 共 16 组 | 相对差 **≤ 8.2e−37**（`f=Φ″` 最差，其余 ≤1.7e−52） |

即 `w(x)=√(1−x²)/arccos x = 2g(x)` 逐点成立（`w(1)=1`、`w(−1)=0`），`r06 §1` 的"副作用"一句也对。

## 5. `Φ″` 严格单增 `[T]` ⇒ `T3<0` `[T]`

`Φ‴(u) = F(u)/(2u³)`，`F = u²csc²u + u cot u − 2 = H(u)/sin²u`，
`H(u) := u² + (u/2)sin2u − 1 + cos2u`（即 `F·sin²u`）。**证明**：

```
H''''(u) = 8u·sin2u > 0  于 u∈(0,π/2) ;   H(0)=H'(0)=H''(0)=H'''(0)=0
  ⇒ H''>0 ⇒ H'>0 ⇒ H>0           于 (0,π/2)
u∈(π/2,π):  H' = u(2+cos2u) − (3/2)sin2u ≥ u > 0（因 sin2u≤0, 2+cos2u≥1）
  ⇒ H 增，且 H(π/2)=π²/4−2=0.4674>0 ⇒ H>0
⇒ F = H/sin²u > 0 于 (0,π)  ⇒ Φ‴ = F/(2u³) > 0 ⇒ Φ″ 严格单增   [T]
```

数值旁证（`[0.02, π−0.02]`，4001 点）：`min Φ‴ = 4.44e−4 @ u=0.02`（正合 `u/45 = 4.44e−4`），`Φ″` 相邻差最小 `3.5e−7 > 0`；`u→0` 用 Taylor `Φ‴ = u/45 + 4u³/945 + …`。

于是 `x=cos u` 严格递减 ⇒ 反向重排（Chebyshev 积分不等式）⇒ `Cov(Φ″,x) < 0`。数值：

| `c` | 0 | 0.25 | 0.5 | 0.75 | 1 |
|---|---|---|---|---|---|
| `Cov(Φ″,x)` | −0.02246407 | −0.01561942 | −0.01020238 | −0.00650733 | −0.00418996 |
| `T3` | −0.05616018 | −0.03904855 | −0.02550595 | −0.01626832 | −0.01047489 |

⇒ **`T3<0` 是唯一的负项，且 `Φ″↑` 是 `[T]`（`r06 §3.1` 的 `[C]` 由此升格；它原来依赖的 `F>0` 引理已被 `H` 证明取代）。**
