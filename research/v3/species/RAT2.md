### 3.2 比值到底是什么：`⟨边界⟩ ÷ ⟨简并度⟩`（`[E]`，本轮新分解）

**两个计数都在涨**：`⟨b⟩ = 20 → 66.5`，`⟨c⟩ = 1 → 2.58`。⇒ 比值**既不是边界片数、也不是简并度**，而是二者的商——即用户猜的**"形状数"**，精确形式是"每个 `n`-形状平均长出多少 `(n+1)`-形状"。

**决定性判据**：`a_3/a_2 = 22.9 > Δ = 20`。单一片的邻接度上限就是 `Δ = 20`，任何"局部插入片数"必然 `≤ 20` ⇒ **比值在 `n=2→3` 这一步就已越界 ⇒ 它不是局部计数。** `[T]`+`[E]`

**关于"真上界 = `λ_*`"的精确说法**（`[T]` 算术 + `[E]` 数据）：任意序列都有 `sup_n a_{n+1}/a_n ≥ λ_*`（否则比值全 `< λ_*−ε` 会逼出 `limsup a_n^{1/n} < λ_*`）；等号需要比值单调升（本序列 `n≤6` 实测单调升，**未证**）。⇒ **`λ_*` 是唯一能当"常系数上界 `B`"的候选**；`B = λ_*`。

## §4 判（按题面三条判死线）

### (c) 触发 —— `48 = 16(d−1)` 是 **SZZ 的**，不是从 `a_n` 来的
- 出处逐字：`|β| < 1/(16(d−1))`，`K_S = (N+2)/2 − 1 − 8N|β|(d−1) > 0`（arXiv:2204.12737，`C1:52,55,267`）。**N-无关**、**无计数**、**曲率型**。
- 它落进 `a_n` 槽**只靠一条代数替换**：`β=1/48` 代入 `K̂λ_Tu<1` ⇒ `λ_T < 48 = 2.4Δ`（`KP6:65`）。`2.4 = 12/5` 本身在两处**都无推导**（`KP6:72` 自认"需新计数定理"）。
- ⇒ **`a_{n+1} ≤ 48 a_n` 是巧合而非结构**：它是"把 SZZ 窗边搬到 KP 门槛里"的产物。`[T]`+`[E]`

### (a) 不成立（不能判真）
- 观测 `sup_{n≤6} a_{n+1}/a_n = 25.76521 < 48`（松 **1.86298×**）**只是数据**，`[M]`。
- 而**唯一的诚实逐步界 `14n+6` 在 `n≥4` 就 `>48`**（§3.1）⇒ 想证 `a_{n+1} ≤ 48a_n` 必须换一种计数（不是边界数），等于要 `⟨b⟩_n ≤ 48⟨c⟩_n`。
- 该引理 `⇒ λ_* ≤ 48`（叠乘）`[T]`；反向需要比值单调性（未证）⇒ **引理比 `λ_* ≤ 48` 更强、不是更弱**：证出来就是比 K–P 紧 9.4% 的新动物计数定理。

### (b) 不成立（不能判假）
- 上界侧只到 `53.0007`（`[C]`）/`54.3656`（`[T]`），比值仍在升（`20<22.9<24.31<25.17<25.77`）⇒ `sup` 可能停在 26–28，也可能继续走到 48 以上。**现无判据。**

### ⇒ 一句话
**`(c)` 是唯一能落的判：`48` 是 SZZ 的曲率常数，`a_{n+1} ≤ 48a_n` 是它在 `β=1/48` 处的巧合投影；比值本身的真上界 = `λ_*`（形状类生长常数），严格已知只在 `[25.765, 53.0007]`，与 48 的关系**开放**。**

### 5.2 计数侧的真靶（比"48 次插入"正确）

```
(P-RAT)   Σ_{Γ∈A_n} |∂Γ|  ≤  48 · a_{n+1}        ⟺   ⟨b⟩_n ≤ 48 ⟨c⟩_n
```
