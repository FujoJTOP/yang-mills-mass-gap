## 0. 判死线（先裁决）

**主判 `(b)`。** 2D 精确解给出 `m_lat(β) = c/β`（`c>0`）：`(iii)` 原样（常数地板、格点单位）**在 2D 上假**，而且**可以精确算出它假多少**。这不是"2D 无隙"——2D **每个 `β` 都有隙**（`SZ-CEILING.md:242–245`）——而是 **`(iii)` 把 `a(β)` 丢了**。**正确的陈述是比值/带跑动尺度的地板**：`m_lat(β) ≥ a(β)·Δ₀`（`Δ₀` 为物理质量），即语料已有的 `(T4)`/`(T3)`（`M05-RATIO.md:96–97`），不是 `m_lat ≥ Δ₀`。

**次判 `(c)`。** 3D 纯 `SU(N)` **没有**已证 `β`-尾定理；且**结构性上不可能有 `(iii)` 形的 3D 定理**：`a(β) = 2N/(β g₃²)` 是**恒等式**（超可重整，**无** dimensional transmutation），故 `m_lat = m_phys·a ≍ m_phys/β`——`m_phys>0` 也趋于 0，`m_phys=0` 更是 0。**`(iii)` 形在 3D 无条件假 `[T]`**，与"3D 有没有隙"无关。

**(a) 不触发**：没有可搬的 3D 尾定理。

**2D 的 `m→0` 与"2D 有隙"不矛盾**（§2.3）。**另**：题面的 `m = 3N/(4β)` 只对 `SU(2)` 成立，`N`-一般式是 `(N²−1)/(2β)`（§2.4，`[T]` 算术）。

## 2. 2D：`m(β)` 的精确行为，以及张力的解

### 2.1 精确谱 `[T-standard]`

2D 纯 YM 在 `ℝ×S¹`（周长 `L = L_lat·a`）：`Z` 是群上热核之积（plaquette 独立，Migdal），转移算子按特征标对角，谱为 **Casimir 塔**

```
E_R = (g²/2)·C₂(R)·(L/a)          (L_lat = L/a)
m_lat(β) := E_{fund}·a = (g²/2)C₂(fund)·L_lat ,   g² = 2N/β
         = (N²−1)/(2β) · L_lat                                        [T-standard]
```

`SU(2)`、`L_lat = 1`：`m_lat = 3/(2β)`（`β=2.5 ⇒ 0.6`，`D07-G.md:121` 逐字 `3/(2β)=0.6 @2.5`），与 `m = 3g²/8` 在 `g²=4/β` 下一致（`T03-TOY.md:41,60–65`）。语料同结论：`B06-VAR.md:159` 逐字"在 `β=2N/g²` 下 `m(β)=c/β`，**严格递减**"；`MU5-SIGMA-M.md:113`（`σ=g²N/2`，谱 `∝g²N`）。

**⇒ `m_lat(β) = c/β → 0`（`β→∞`），且是 `1/β`（不是指数）。** `[T]`

### 2.2 为什么这**不是**"2D 无隙"：`d` 与 `β↔a` 的关系

格点归一化（标准 Wilson 推广到 `d` 维）：`β = 2N/(a^{4−d} g_d²)`；`d=4` 退化为 `β_W = 2N/g²`（`BETA-CONVENTION.md:5,64` 已钉）。于是

| `d` | `[g_d²]` | `a(β)` | `m_lat = m_phys·a` | 有 `Λ`（transmutation）？ |
|---|---|---|---|---|
| 2 | `M²` | `√(2N/(βg₂²)) ∝ β^{−1/2}` | `≍ m_phys β^{−1/2}` | **无**（超可重整，`g₂` 自带量纲，`L1-UNIFORM-A.md:17`） |
| 3 | `M` | `2N/(βg₃²) ∝ β^{−1}` | `≍ m_phys/β` | **无**（超可重整） |
| 4 | `M⁰` | `∝ β^{51/121}e^{−β/(12b₀)}` `[C]` | `→0`（快于幂） | **有**（`Λ_QCD`） |

**关键 `[T]`**：`d=2,3` 的 `β↔a` 关系**精确**（无指数因子、无 transmutation）⇒ `m_lat = m_phys·a(β)` 是**恒等式**，`m_lat→0` 与 `m_phys>0` **同时成立**。
`d=4` 的 `a(β)∝e^{−cβ}` 依赖渐近标度，只有 `[C]`——这正是 `B05.md:15,88,110` 已记的那一条。

### 2.3 张力解开（三句话）

1. **"有隙"是关于物理谱的陈述**：2D 的谱是 `{0} ∪ {离散塔}`，`∀ β<∞` 有正隙，无上临界耦合（`SZ-CEILING.md:242–245` 逐字"confining with a mass gap at **every** `β<∞`; there is no upper critical coupling"）。
2. **`m_lat` 是"物理质量 × `a`"**，`a→0` 时必趋于 0。把 `(iii)` 写成常数地板 = 要求 `m_phys→∞`——这不是"隙更强"，是**非物理**。
3. **2D 的"尾定理"其实存在，而且是等式，但指数是反的**：`β·m_lat(β) = (N²−1)L_lat/2`（`SU(2)`、`L_lat=1`：`3/2`）`[T]`。**2D 给的是 `∝1/β` 的精确尾，不是 `≥Δ₀` 的常数尾。**

**⇒ 2D 的"有隙"完全成立；被否掉的是 `(iii)` 的写法。**（`(b)` 成立）

### 2.4 勘误（算术层）`[T]`

题面 `m = 3g²/8 = 3N/(4β)` 用了 `C₂(fund) = 3/4`（`SU(2)` 值）。`N`-一般：`C₂(fund)=(N²−1)/(2N)` ⇒
`m_lat = (g²/2)C₂ = (N²−1)/(2β)·L_lat`，`N=2` 给 `3/(2β)` ✔（与 `3N/(4β)` 同值）；`N=3` 给 `4/β`，而 `3N/(4β)` 给 `2.25/β`（**差 1.78×**）。**同为 `∝1/β`，§0 的裁决不动。**

## 3. 3D：有已证 `β`-尾定理吗？

### 3.1 有——但窗**相反**（强耦合）`[T]`

Osterwalder–Seiler 1978（`DOI 10.1016/0003-4916(78)90039-8`）的团簇展开对**任意 `d`**（含 3）给出：无限体积极限 + 指数聚类 ⇒ `m(β)>0`，**在 `β` 小（强耦合）的窗内**。3D 同理。**这不是尾定理**：`(iii)` 要的是 `β ≥ β₀`（大 `β`/连续极限端），OS'78 给的是 `β < β₀'`。二者**互补不重叠**（`B05.md:92` 同一句，4D 版）。

### 3.2 无——全 `β`/连续极限

分层记（沿用 `A5-LIT-UNIFORM.md` 的四类"一致"表）：

| 3D 的严格资产 | 给了什么 | 给隙？ |
|---|---|---|
| OS'78 团簇展开 | `β` 小：`m>0`、体积 `L`-一致 | 只在小 `β` |
| Balaban, *CMP* **102** (1985) 255（3D 纯规范 UV 稳定性，`DOI 10.1007/BF01229380`） | **有效作用量**在 RG 步上一致 | **否**（`A5-LIT-UNIFORM.md:37–41` 逐字） |
| Chandra–Chevyrev–Hairer–Shen 2024（3D YM–**Higgs** 随机量化，Invent. Math.） | 构造（带 Higgs） | **否**（`CTL-CLOSEST.md:92–96`） |
| Cao–Chatterjee 2024（3D 欧氏 YM 的**状态空间**） | 测度定义域 | **否**（`CTL-CLOSEST.md:98–101`） |
| Nair 2026（`arXiv:2608.10133`，"outlines of a proof"，**摘要级**） | 3D 隙的**纲要**，未给那条不等式 | **否**（`L4-PREPRINTS.md:154`；`D06-SPEC.md:292` 同判） |

**⇒ 3D 纯 `SU(N)` 无已证隙定理，更无 `β`-尾定理。** `[NG]`（文献 0 命中，检索台账见 §1）
**注意**："3D 更容易"是物理直觉，不是文献事实（`CTL-CLOSEST.md:103` 逐字）。

### 3.3 3D `U(1)`：有 `[T]`，但被 `π₂` 锁死

3D 紧致 `U(1)`：单极子等离子体 ⇒ Debye 屏蔽 ⇒ 面积律 + 质量隙，**全耦合**（Polyakov 1977, *NPB* **120**, 429；Göpfert–Mack, *CMP* **82** (1982) 545；`IMP-ARROWS.md:63` 行 11 `[T]`）。**这是 3D 唯一的全 `β` 非微扰隙定理**——但 `π₂(U(1))=Z` 而 `π₂(SU(N))=0`：**非阿贝尔没有可用的单极子机制**，机制**不迁移**（`B06-VAR.md:82`、`T23-TEMPLATE.md:100–117`）。

### 3.4 ★ 结构性 no-go：`(iii)` 形在 3D **不可能**为真 `[T]`

`a(β) = 2N/(β g₃²)`（§2.2）⇒ `m_lat(β) = 2N·m_phys/(β g₃²)`。于是

- 若 3D **有**隙（`m_phys>0`）：`m_lat ≍ 1/β → 0 < Δ₀`，`(iii)` **假**；
- 若 3D **无**隙（`m_phys=0`）：`m_lat ≡ 0 < Δ₀`，`(iii)` **假**。

**两种情况都假 ⇒ 不存在 `(iii)` 形的 3D 尾定理，不是"文献没做"，是"命题不真"。** 3D 的正确尾形是纯数命题
`β·m_lat(β) ≥ Δ₀ ⟺ m_phys/g₃² ≥ Δ₀/(2N)`——**它就是 3D 质量隙本身**（语料的 `(T4)`，`M05-RATIO.md:97`）。

## 4. `(iii)` 的正确陈述（三种等价写法）

以 `Δ₀` 为**物理质量**（`d=4`：GeV；`d=2,3`：`g_d²` 的幂），`m_lat := m·a`：

```
(iii′)  [T4 形, 语料 M05-RATIO:97 / FROZEN-POSITION:40]
        ∃Δ₀>0 ∀a≤a₀ (⟺ ∀β≥β₀):  m_{0⁺⁺}(a) ≥ Δ₀          （m 取物理单位）
等价    ∃Δ₀>0 ∀β≥β₀:            m_lat(β) ≥ a(β)·Δ₀       （格点单位，地板随 a 跑动）
等价    [T3 形]                 G″_a/a² ≥ Δ₀²             （曲率侧，M05-RATIO:96）
比值形  [P2]                    liminf_β m_lat/(aΛ) ≥ c₀>0 （Λ 只在 d=4 存在）
```

**三条裁决**：

1. **题面的 `(iii)`（常数地板、单位未定）必须废弃**：`d=2` 精确假 `[T]`、`d=3` 无条件假 `[T]`、`d=4` 与渐近标度冲突 `[C]`（`B05.md:15`）。**"应是比值"这个直觉方向对，但更准的说法是"地板必须带 `a(β)`"**——比值只是它的一个写法。
2. **`d<4` 时 `Λ` 不存在**（超可重整、无 transmutation）：`m/Λ` 的读法在 2D/3D 无定义，正确归一化是 `g_d²` 本身。**2D/3D 的尾定理只能是纯数命题**（§3.4）。
3. **2D 是唯一"尾定理已证"的维度，内容与 `(iii)` 相反**：`β·m_lat = (N²−1)L_lat/2`（等式）`[T]`。
