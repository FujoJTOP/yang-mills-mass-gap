## §2 ① EBK / Bohr–Sommerfeld 量子化条件 → 计数或能级下界

逐条核：
- **(i) 前提**：EBK 的输入是 `d` 个**对合的作用量** `I_k=(1/2π)∮_{γ_k}p·dq`（`d` = 可积自由度）。目标算符 `L_{0⁺⁺}` 活在 `L²(𝒜/𝒢,μ̄)` 上（无穷维）；其经典极限是格点规范流 `(A,E)`，Biro–Matinyan–Müller：`λ_L>0`、`h_KS>0`（`HAMILTONIAN-CHAOS.md` §1 引）。**非可积 ⇒ 无环面 ⇒ `I_k` 无定义**，Maslov 指标亦无指称。这不是"还没找到作用量变量"，是**定义域空**。
- **(ii) 有环面的地方**：`a₀`-minisuperspace（`MINISUPERSPACE.md`）与 `LP-LIOUVILLE` 的 Liouville 坐标把 `0⁺⁺` 径向问题化成 **1D** `−v″+Qv=λv`（Dirichlet，长 `T_intr`）。1D 可积性平凡成立 ⇒ **EBK 的严格形 = Sturm 比较** `λ₁ ≥ π²/T² + ess inf Q`。语料已经算出这个数：`T_intr=10.180126`、`ess inf Q=−0.052530` ⇒ **地板 `+0.042704`**，而目标 `Δ=0.6444` ⇒ **差 15.09×**（W6）。并且 LP-6（普适 SL 比较非原子证书）与 LP-7（**二阶 SL 表示不存在**：`β=0` 的隙为 ∞ 而任何二阶算符 `λ₁≤1.61`）已把它判 `[NG]`。

### §5.3 "重分配"的精确式子（任务要求的核心）

**具体的 frame（两个，都用真的）：**
```
(F1) 扩散框架：     e_k = e^{−tL}δ_k ,  k=1..d ,   S = Σ|e_k><e_k| = e^{−2tL}
                    A = e^{−2t λ_max(L)} ,  B = e^{−2t·0} = 1                [W2b 实测]
(F2) 壳框架（正交）： {P_ℓ} 正交投影分解， Σ_ℓ P_ℓ = 1  ⇒  Parseval（k=1）
```
**精确重分配（对任意正交分解 `{P_ℓ}`，无任何近似）：**
```
  ‖f‖²   =  Σ_ℓ ‖P_ℓ f‖²                                    (Parseval，恒等式)
  <Lf,f> =  Σ_ℓ <P_ℓ f , L P_ℓ f>  +  cross(f)               (恒等式，定义 cross)
  cross(f) := Σ_{ℓ≠ℓ'} <P_ℓ f , L P_ℓ' f>
           =  <f, Lf> − f^T M f ,      M := Σ_ℓ P_ℓ L P_ℓ   (M 对称)
```
**要的方向（下界）必须从下面这一行来，而这一行不是恒等式：**
```
  (★)  ∀f ⊥ Ω :   cross(f) ≥ −s     ⇒    <Lf,f> ≥ f^T M f − s ≥ (λ_min(M|Ω⊥) − s)‖f‖²
      取 λ := λ_min(M|Ω⊥) − s  ，要的正是  λ ≥ Δ .
```
**哪一步产生了不等式方向？—— `cross(f) ≥ −s` 这一步，且只有这一步。** 三条论据说明它**不是恒等式换皮**：
1. **(恒等式里没有 `L`）。** `Σ_ℓ‖P_ℓf‖²=‖f‖²` 只约束 `f` 的**行和**，是 `f` 的单边陈述；`cross` 是 `L` 在框架**非对角块**上的矩阵元。**把 `L` 换成任何别的算子，恒等式一字不变，`cross` 全变**。⇒ 恒等式对目标零信息，缺口全在 `(★)`。
2. **`(★)` 不能被 Parseval 推出，且它的符号是真的会变。** 同一个 `L`、`Δ=0.6444`，三个随机壳框架给 `min cross = −0.9322 / −0.8235 / −0.7848`、`max cross = +0.8388 / +0.7257 / +0.6879`（W3）：**交换子项两符号都实现**。⇒ `(★)` 不是"把恒等式两侧截断"，它是一个**关于框架与 `L` 对齐程度的独立不等式**（这正是 `D14` 的"控核不控对齐"）。
3. **`(★)` 的两个极端都是已知死路，中间是空的。**
   - `[L,P_ℓ]≡0`（对齐）⇒ `cross≡0`，重分配**精确**，但壳就是 `L` 的谱投影 ⇒ 你已经有谱了（`D2`）；
   - 完全不对齐 ⇒ `cross` 无符号（上条实测）⇒ 要 `(★)` 就得**独立证明**它。
   ⇒ 唯一能救 `(★)` 的是"框架由相互作用（不是由 `L`）造出来、且仍与 `L` 可比"，那就是一条**场空间非线性不等式 ≡ `H1`**（`E2-FLIP-L2-COMPLEMENT` Lemma L2）。

**与语料主恒等式的对账（这条是本候选的真价值）。** `(★)` 的形状与 `ch08` 的中心恒等式
`G″ = Δ_dyn + W_geo + X`（`X = −2Cov(G,Φ′)`，两点余项）**逐项对应**：
```
   重分配:   <Lf,f>  =  f^T M f           +  cross(f)
   语料:     G″       =  Δ_dyn + W_geo    +  X
```
⇒ **`cross` 就是 `X` 在框架坐标里的名字**。而语料对 `X` 的唯一判词是"**无下界控制**"（`LOOP-RUNBOOK` §1："`X` 无下界控制 ⇒ 唯一还可独立攻击的是…"）。⇒ ④ 不是新机制，是 `X` 的一个**坐标**——但它是**第一个把 `X` 写成"框架交换子"的坐标**，且这个坐标自带一条**已被证明的恒等式**（Parseval）去承担"重分配"那一半。**这就是它半活的全部理由。**

### §5.4 五条件 + 酸测五点

### §5.5 判决：**半活**（3 死 + 1 半活里的那 1）

**它比另三条强在哪（为什么不能直接判死）**：
- 另三条的**规范输出都不含"(L,a)-一致、非循环"的数值界**（① 计数、且误差不单向；② 秩 1 + `Z(2a)`；③ 指数 `≡0` 或 `=隙本身`）。④ 的重分配**实测给出真界**：`λ_min(M|_{Ω^⊥}) = 1.4555/1.5339/1.6801 ≥ Δ=0.6444`（三例全过）。
- 且有**一个被证明的恒等式**（Parseval）承担"能量守恒"那一半，是四条里唯一"免费"的一半。

**它的缺步（**一句话**，无退路）**：
> **给 `M = Σ_ℓ P_ℓ L P_ℓ` 在 `Ω^⊥` 上、或等价地给框架–算子对齐亏损 `cross(f)` 一个 `(L,a)`-一致的下界；而 `cross` 正是 `G″ = Δ_dyn + W_geo + X` 里的 `X`，故这句缺步与 `H1` 同名。**

**为什么它仍然不是逃生口**：上句的等价链是 `(★) ⟺ X 有下界 ⟺ H1`。半活的"活"仅指**坐标**（一个新的、自带恒等式的、把 `X` 写成交换子的坐标），**不是机制**。

### §5.6 反证形状（会推翻 §5.1/§5.5 的东西）

要让它从"半活"升到"活"，必须交出一对 `({P_ℓ}, w)` 使
1. `(★)` 的 `s` **由恒等式给出**而非由最小本征值给出（即 `cross(f) ≥ −s` 是 Parseval 型等式的一个直接推论）；
2. `s` 与 `λ_min(M|_{Ω^⊥})` 的差 `≥ Δ` 且 `(L,a)`-一致；
3. 该对 `({P_ℓ},w)` 在自由无质量场上使 `λ_min(M)−s = 0`（酸测）。
**可核的堵点**：第 1 条要求"交换子项的符号由一个不含 `L` 的恒等式决定"；而 W3 的实测（同一 `L`，三框架，`cross` 两符号都实现）说明 `cross` 的符号**本质依赖 `L` 与框架的相对结构**，不能由 `f`-侧的恒等式定出。⇒ 反证形状存在但为空的前提（`D6` 型的空）。
