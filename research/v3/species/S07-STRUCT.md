# S07-STRUCT — `E_μ[H] − Var_μ(g)` 的测度论身份

日期戳：2026-11-25T17:0x（仅追溯用）。轮次口径见 §7。
标签：`[T]` 真定理（本文件自证）／`[C]` 计算或数值／`[NG]` no-go／`[M]` 缺失步。

---

## 0. 一句话裁决

> `E_μ[⟨v, Hess V v⟩] − Var_μ(⟨∇V,v⟩) ≡ (E_μ⟨∇V,v⟩)² = 0`，**对任意 V、任意维数、任意方向 v**。`[T]`

它不是"非高斯性"的度量，而是**梯度结构恒等式的零**。任何 `≥ δ_W > 0` 必须由**得分失配**
`r := f − ∇V` 提供；高斯只是 `r ≡ 0` 这个边界点上的一个特例，不是"唯一使等式成立的分布"。
（判 (c) 因此被推翻：见 §3 的非高斯反例、§4 的自由场反例。）

---

## 1. 主恒等式：Stein 缺陷恒等式 `[T]`

**设定.** `μ = e^{−V}dx / Z`，`V ∈ C²`，`∫ e^{−V} < ∞`，且
`|∇V| e^{−V} ∈ L¹`、边界通量消失（`𝕋ⁿ` 上**自动**成立且无边界项；`ℝⁿ` 上由此条保证）。
`f ∈ C¹(μ)`，`∫ (|f|² + |f||∇V|) dμ < ∞`，固定 `v ∈ ℝⁿ \ {0}`，记

```
H := Df          （Hessian 型量 = f 的 Jacobian）
H_vv := ⟨v, Df v⟩ = ∂_v⟨f,v⟩
g    := ⟨f, v⟩
r    := f − ∇V   （得分/梯度**失配**场）
```

**则**

```
E_μ[H_vv] − Var_μ(g)  =  (E_μ g)²  −  E_μ[ g · ⟨r, v⟩ ].          (1)
```

**证明（三行）.**
Stein 恒等式（分部积分，边界项为 0）：`E_μ[∂_v ψ] = E_μ[ψ ∂_v V]` 对一切合适 `ψ`。
取 `ψ = ⟨f,v⟩ = g`：左端 `= E_μ[⟨v,Df v⟩]`，右端 `= E_μ[g ∇V_v]`（`∇V_v := ⟨∇V,v⟩`）。
于是

```
E_μ[H_vv] − Var_μ(g)
 = E_μ[g ∇V_v] − E_μ[g²] + (E_μ g)²
 = (E_μ g)² − E_μ[ g (g − ∇V_v) ]
 = (E_μ g)² − E_μ[ g ⟨r,v⟩ ].   ∎
```

**等价的矩阵形式**（同样由 Stein，取 `ψ = ∇V_a`）：`E_μ[Hess V] = Cov_μ(∇V, ∇V)`，
即"平均 Hessian = 得分的协方差"。对方向 `v` 取二次型即得 §2 的等式。

---

## 2. 纯梯度配对：恒为零 `[T]`

取 `f = ∇V`（于是 `H = Hess V`、`g = ⟨∇V,v⟩`、`r ≡ 0`）。散度定理：

```
E_μ[∇V] = (1/Z)∫ ∇V e^{−V} dx = −(1/Z)∫ ∇(e^{−V}) dx = −(1/Z)∮_{∂} e^{−V} n dS = 0.
```

于是 (1) 给出

```
E_μ[⟨v, Hess V v⟩] − Var_μ(⟨∇V,v⟩) = (E_μ⟨∇V,v⟩)² = 0.                       (2)
```

**这是恒等式，不是不等式，不依赖 V 的形状、维数、方向，也不依赖高斯性。**
意义：`E_μ[Hess V] = Cov_μ(∇V,∇V)`（矩阵等式），两侧相等；`(★)` 的 LHS 只是它的差。

## 3. 一维入口与高斯核对 `[C]`

**用户的入口算对。** `V = x²/(2σ²)`：`V'' = 1/σ²`，`V' = x/σ²`，
`Var_μ(V') = Var(x)/σ⁴ = σ²/σ⁴ = 1/σ²`，故

```
E[V''] − Var(V') = 1/σ² − 1/σ² = 0.   ✓
```

**一维一般闭式**：`E[V''] − Var(V') = (E_μ V')² = 0`（在 §1 的边界条件下）。

**数值核对**（bundled python 3 + numpy 2.3.5；Gauss–Legendre 4000 点在 `[−12,12]` 上，
权重在端点 ≤`e^{−518}`；无 scipy，`TOOL-FAIL` 未发生）：

| V(x) | 是否高斯 | `E[V'']` | `E_μ[V']` | `Var(V')` | `E[V'']−Var(V')` |
|---|---|---|---|---|---|
| `x²/(2·1.3²)` | 是 | 0.5917159763 | 0.0 | 0.5917159763 | **+1.1e−16** |
| `x⁴/4` | 否（对称） | 2.0279347202 | 4.3e−17 | 2.0279347202 | **0.0** |
| `x²/2+0.3x³+x⁴/4` | 否（偏斜） | 2.3027994367 | 1.1e−16 | 2.3027994367 | **+4.4e−16** |
| `0.1x⁴+x` | 否（强偏斜） | 1.9629444828 | −8.4e−17 | 1.9629444828 | **−6.7e−16** |
| `0.02x⁴−0.05x²` | 否（双井） | 0.5638416921 | −4.1e−17 | 0.5638416921 | **+3.3e−16** |

**第 2–5 行是决定性的**：**非高斯**，差仍是 0（机器精度）。故"偏离高斯"**不**是该量的读法。

## 4. 自由场反例：`P ≠ I` 时高斯上就已经 > 0 `[C]`

取 2D 各向异性高斯 `V = xᵀΣ⁻¹x/2`（`Σ = R·diag(4,1)·Rᵀ`，`θ=0.4`），
正交投影 `P = diag(1,0)`，`v = (0.3,0.9)`。两种"配对"给出两个不同的值：

| 配对 | `H` | `g` | `E[H_vv] − Var(g)` | 闭式 |
|---|---|---|---|---|
| A | `Hess V` | `⟨P∇V,v⟩` | **+0.57261** | `vᵀΣ⁻¹v − (Pv)ᵀΣ⁻¹(Pv)` |
| B | `Df = P·Hess V` | `⟨P∇V,v⟩` | **−0.07263** | `⟨Σ⁻¹Pv,(I−P)v⟩` |
| A，各向同性 `Σ=I` | `Hess V` | 同上 | +0.91 | `(1/σ²)(|v|²−|Pv|²)` |
| B，各向同性 `Σ=I` | `Df` | 同上 | 0 | `⟨Pv,(I−P)v⟩ = 0` |

（Σ = [[3.54506, 1.076034], [1.076034, 1.45494]]；MC 4e6 样本核对 A：`Var(g)=0.032704` vs 闭式
`0.032736`，`E[H_vv]=0.605346`，`LHS=0.572643`，与闭式 0.572610 一致到抽样误差。）

**酸测判决 `[NG]`**：配对 A 在**纯自由高斯场、零相互作用**上就给出 `+0.57`。
按本仓宪章第 1 条，凡在自由场上**不失效**的量不能承载 `δ_W`。
⇒ **若 `(★)` 用的是"`H = Hess V` + `g` 投影"这种配对，`(★)` 对 YM 是 vacuous 的，且其正值来自
投影 `P ≠ I`（规范/切片选择），不是来自质量间隙。**
配对 B（`H = Df`，自洽配对）时符号由 `⟨Σ⁻¹Pv,(I−P)v⟩` 决定，可为**负**（本例 −0.073）
⇒ 连"非负"都不保证，`≥ δ_W > 0` 更无由。

**边界项陷阱（本轮新增，`[C]` 一行的推论）**：若不做周期边界（开边界/有限格点 Dirichlet），
则 `E_μ[∇V] = −(1/Z)∮_{∂Λ} e^{−V} v·n`，`(2)` 变成

```
E[H_vv] − Var(g) = (边界通量 / Z)²  ≥ 0 ,  量级 O((∂Λ/Λ)²) → 0 于热力学极限。
```

这是**体积/边界效应**，绝不可当作 `δ_W`。周期边界（本仓 PL/格点规范论的标准设置）上**恰为 0**。

## 5. `W_j` 唯一可能的角色 `[M]`

由 (1)，要 `(★)` 成立（`δ_W > 0`）必须

```
E_μ[ g · ⟨r, v⟩ ]  ≤  (E_μ g)² − δ_W ,        r = Pᵀ∇S_j − ∇V.                (3)
```

即 **`g` 与失配场 `r` 的（带号）负相关证书**，而不是任何"方差下界"。
`W_j` 的可能身份，只有三种，且都必须在 `r ≡ 0` 处**退化为 0**（否则破酸测）：

1. `W_j` = `−E_μ[g⟨r,v⟩]` 的一个可算下界（把失配项显式化）——最经济；
2. `W_j` = 修正项，使配对从 A 变成 B（`H := Df`，自洽配对），即 `W_j` 吸收 `Hess V` 与 `Df` 的差；
3. `W_j` = `r` 的显式来源：`V = S + log J`（Faddeev–Popov / 规范固定 Jacobian）时的 `∇log J` 项，
   或粗粒化后 `P` 与 `Σ` 不交换产生的项。

**为什么高斯"看起来临界"**：因为 `r = 0` 且 `E g = 0` 同时成立的最小模型就是二次 `V` + `P = I`。
临界的是**梯度结构**，不是高斯性。

## 6. 判死线

| 项 | 判 | 依据 |
|---|---|---|
| (a) 有闭式？ | **有** | 一般：式 (1)；一维/高斯：`(E_μ V')² = 0`。§1、§3 |
| (b) 高斯上为 0 ⇒ `W_j` 须非平凡？ | **是，且更强** | 不只高斯：**任意** `V` 上只要 `f = ∇V`，LHS 恒为 0 ⇒ `δ_W > 0` 在该结构下**不可能**（不是"需要非平凡 W_j"，是"下界机器没有余量"）。§2、§3 |
| (c) `(★)` 只是"非高斯性"的量化？ | **否** | 它是**非梯度性（得分失配）**的量化。给出两个反例：非高斯=0（§3 四例），高斯>0（§4 配对 A）。非高斯性既不充分也不必要。 |

**结论（本轮）**：`(★)` 的 LHS 在纯梯度配对下是恒等零；在投影配对下是**自由场就非零**的量
⇒ 目前的 `(★)` 作为攻克点**未过酸测**，不能充当 `δ_W` 的载体。可救的唯一形式是 (3)。

## 7. 路径（下一轮）

1. **定死配对**：只用 `H := Df`（自洽配对），否则 §4 的 0.57 会冒充物理。`(★)` 需重写为
   `E_μ[⟨v,Df v⟩] − Var_μ(⟨f,v⟩) ≥ δ_W`，并同时声明 `f` 与 `μ` 的关系（`f = ∇V`? `f = Pᵀ∇V`?）。
2. **换靶**：把 `δ_W` 的载体从"均值减方差"改成带号相关 (3)：`Cov_μ(g, ⟨r,v⟩) ≤ (E g)² − δ_W`。
   这是一条**可证伪**的不等式（每边都有独立算路）。
3. **`r` 的显式候选**：FP/Jacobian 项 `∇log J`；或粗粒化 `P` 与 `Σ` 的不交换项。
4. **先在四模型试金石上算 `r` 的符号**：自由场（`r=0`，必须 0）、2D YM（弱耦合，`r` 应为
   `O(g²)`）、M6、单 plaquette。单 plaquette 的 `r` 符号决定 (3) 是否可能成立。
5. 累计：本轮新增一条 `[T]`（式 (1)）、一条 `[T]`（式 (2) 恒为零）、一个 `[NG]`（配对 A 破酸测）、
   一个边界项陷阱。未闭合：`r` 在 YM 上的符号。
