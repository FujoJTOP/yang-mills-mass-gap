## §1 这条坍缩是什么、要证什么

**1.1 引理（PC）.**
```
(PC)  ∃R>0 ∃κ>0 ∃C<∞ ∀L ∀z∈D(β_c,R):
      f_L(z) = Σ_{γ∋0, 连通} w_γ(z)               （恒等：含全部装饰与余项）
    ∧ Σ_{γ∋0} |w_γ(z)| e^{κ|γ|} ≤ C               （β-一致绝对可和）
    ∧ sup_{z∈D} Σ_{γ∋0} |w_γ(z)| ≤ (R/2Δβ) r₀      （Jensen 预算）
```
三条按难度：恒等 `[T]`（`β=0` 的形式恒等 + 有限体积解析性）；第二条是全部内容；第三条是常数。`(PC)` 加 BCL ⇒ `f₁² ≥ δ`（`III5:28–36`）。**排除的是什么**：不再要求复盘 `D(β_c,R)` 上的 `L`-一致模界，只要求实轴 `[β_c,2.5]` 上逐点绝对可和且余项 < 首项——这是"把解析延拓从关键步骤排除"的逐字含义。**下一手**：先写恒等，再写第二条。

**1.2 为什么 `L`-一致性免费。** KP 判据 `Σ_{γ∋x}|w(γ)|e^{a|γ|} ≤ a` 是**逐片**的（`P3-FULLREP-KP:120`；`Z01:335` 逐字"逐 plaquette ⇒ `L,T`-无关"）；体积只进聚合物个数，不进过定点的局部和。⇒ 坍缩的"一致"只需 β 一致：两轴降成一轴。**下一手**：把这一句写成引理的第一行。

**1.3 为什么压成一个数。** 精确闭聚合物最小 `|X|=6`（`AUDIT-R5B:185–198`：`|X|≤5` 为 0、`|X|=6` 有 4 个），权 `4u_tile⁶`；`u_tile` 单调增（`I₂/I₁` 的标准单调性，本轮 5 点数值复核）。⇒ `min_a S/a` 随 β 单调，坍缩域是 `[0,β_*^{KP}]`，由 `u_tile(β)=u_*` 唯一决定。**下一手**：把 `β_*^{KP}` 表成 `u_*` 的反函数。

**1.4 BCL 预算的算术。** `M_R ≥ f_L(β_c) ≥ r₀`，与 `M_R < R r₀/(2Δβ)` 并读 ⇒ `R > 2Δβ`。P3 的逐点行给 `f ≥ ½a₀ ≥ ½(2N)^{-2} = 2r₀`（`GK3-ATOM:141`；`inf_L` 行给 `r₀`，仓内两行差 2×），用前者（`r₀` 按 BCL 原值不动）再推 `R > 4Δβ = 9.9167`。⇒ 圆盘最右实点 ≥ `4.9792`，P3 常数下 ≥ `9.9375`：**2.5 不是端点**。**下一手**：BCL 的 H3 按 `R>2Δβ` 重述。

## §3 判定

**3.1 `[T]` 的判据。** `[T]` ⟺ ∃R（BCL：`R>2Δβ`；实轴：`R=0`）使
```
(i)  u_tile(β_c+R) ≤ u_*(γ)          （坍缩；u_* 取可得的最好值 0.395584）
```

- **出口二**：带符号重求和（放弃绝对可和）。语料无引理，是第六物种的具名缺口。
- **出口三**：换聚合物类（穿衣/阻塞）。活性要交叉点/质量隙 ⇒ 循环。
