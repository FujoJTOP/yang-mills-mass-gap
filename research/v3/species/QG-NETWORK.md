## §1 "图约化"的精确定义：三种读法，只有一种能承载 `λ ∝ 1/R_eff`

**R1（几何骨架网络）.** 顶点 = 格点，边 = 链路，电导 = 正的几何权重 `c_e`（例如 1）。
Dirichlet 形式 `E(f)=Σ_e c_e(f_x−f_y)²`。**这是唯一使 "加边只降电阻" 有意义、且 `R_eff` 有

本文件 §2 QG-1、§3 全表、§4 全部酸测都在这个读法上。

**R2（精度 / 曲率网络）.** 顶点 = 场的分量，`Σ = A⁻¹`，`A = Hess S`，
"电阻" `R_eff(v) := v^TΣv`。这一读法**唯一**能使 `λ = c/R_eff` 成立 —— 因为
`λ = 1/λ_max(Σ) = 1/sup_{‖v‖=1}R_eff(v)`，那是**定义**（§2 QG-D，数值 1e-15）。
代价：`A` 必须正定；YM 的 `A` 不定（首段 (a)），且 `Σ` 就是要证的方差（`H1`）。

**终端间 `R_eff` 精确不变**（3e−13），而**隙只会被抬高**（4000/4000 次随机试验 ratio ≥ 1，

## §2 真定理（能证的写上，不能证的写"缺什么"）

> 设 `G=(V,E,c)` 有限连通加权图，`L` 为组合 Laplacian，`λ₁` 为首个非零本征值，

>        λ₁ · R_eff(a,b)  ≤  2 ,                                                   (2.1)
> ```

`=Σ_k ψ_k(a)²+Σ_kψ_k(b)²−2Σ_kψ_k(a)ψ_k(b)=1+1−2δ_{ab}=2`。∎

**读法（这就是判词）.** (2.1) 给出的是 **`λ₁ ≤ 2/R_eff`：隙的上界**。
于是 Rayleigh 单调性（加边 ⇒ `R_eff` 下降 ⇒ `2/R_eff` 上升）**放松**上界。
任务书假设的"电阻上界 = 隙下界"需要的是反号的不等式；**它在标量网络类里是假的，

## §6 精确缺失的一步（一句话，无退路）

> **造一个正定、β-依赖、且 `(L,a)`-一致可算的标量 Dirichlet 形式 `E_β`，使 `R_eff(E_β)`
> 有 (L,a)-一致**上界**，同时 `E_β` 在每一点仍"看得见" Savvidy 不定号。**

**为什么这句就是 `H1`**：`E_β` 正定 ⇒ 必须逐点投影掉负方向（首段 (a)）⇒ 投影后的形式对不定号
不敏感 ⇒ 与隙无关（这是 §3.2 的 β-盲现象的一个精确版本）；不投影 ⇒ 无 M-矩阵 ⇒ 无 `R_eff`。
而 `E_β` 的"可算上界"在梯度情形下就是 `Var_μ(φ) ≤ (1/λ)E(φ)` 的常数——**命题 `H1` 本身**。
所以本路把"第六物种"收敛成一句**可判定的话**：

```
   存在正定标量 Dirichlet 形式 E_β，使 sup_{‖v‖=1} v^T (Hess S_β)^{-1} v 有 (L,a)-一致上界，
   且 (Hess S_β) 的最小本征值 ≥ λ > 0 —— 这与 H1 逐字等价。
```

判据是数（左边是 Hessian 的最小本征值），不含别的未定义对象 —— 与
`SIXTH-SPECIES-SYNTHESIS.md` §4(i) 的"定量隔离"是同一句话的两种写法。
