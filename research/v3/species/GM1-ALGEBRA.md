## §1 `K₂` 的显式式

### 1.1 先钉方案：`K₂` 只在**指明的方案里**是一个算子

任务书写 `H_a = −(1/a)log T_a`，`T_a` = Wilson 转移矩阵。这句话允许两种互不相同的读法，`K₂` 的**内容**随读法变：

| | 方案 | `T_a` | `K₂` 的支撑 | 自由场边缘的 `c₁` |
|---|---|---|---|---|
| **S1** | Kogut–Susskind 极限（**时间连续**，空间间距 `a`） | `T_a = e^{−a_t H_a}`，`a_t→0` | **只有磁扇区** | `0`（`Δ_a = m` 精确） |
| **S2** | 全离散 Wilson 转移矩阵（**时间也离散**，间距同为 `a`） | `T_a` 为 4D 各向同性 | 磁扇区 **+ 电扇区** | `−m²/24`（`Δ_a = (2/a)asinh(am/2)`，`GR1:237`） |

`GR1`/`GK2` 的自由场基准式 `Δ_a = (2/a)asinh(am/2)`（`GR1:237`、`GK2:65`）**只在 `S2` 成立**：它是 `cosh(aE) = 1 + a²m²/2` 的解，即**时间方向**被离散化。而 `GK2` 的三片（`GK2:24,171–175`）**全部**是空间 plaquette 的展开，即 `S1` 的语言。**两个方案被混用了**——这是本轮第一条对账结论（§1.6）。

`K₂` 不是"算子之间的差"：`H_a` 与 `H` 不在同一 Hilbert 空间（`GK2:321` 逐字：格点与连续统无公共空间，`‖U_aH_aU_a^*−H‖=∞`）。能严格写下的只有**符号**：一个由 `(E, F, D)` 构成的、系数被格点作用量钉死的**局域密度**。下面就在这个意义上算。

### 1.2 磁扇区的一般式（两行推导）

取 `S1`。标准 KS 极限（`[std]`，作用量 `S = (1/g²)Σ_p(N−Re tr U_p)`，`tr` 在基础表示、`tr(T^aT^b)=δ^{ab}/2`）：

```
H_a = (g²/2a)Σ_l Ê_l²  +  (1/(g²a))Σ_{p 空间}(N − Re tr U_p)                                (1.1)
```

**电项无 `a²` 修正**（`Ê_l` 是逐链的 Casimir，无空间导数）；磁项的标准展开：

```
1 − (1/N)Re tr U_□ = (a⁴/2N)tr F² + a⁶·(1/N)tr(F G) + O(a⁸) ,   θ := a²F + a⁴G + …        (1.2)
```

（`θ³` 项对 `Re` 无贡献：`1 − Re tr e^{iθ} = tr(1 − cos θ) = tr(θ²/2 − θ⁴/24 + …)`，**偶**。这一行顺带否掉一类常见写法。）按 `(1/a)Σ_p → ∫d³x` 得

```
K₂^{mag} = (1/g²)∫d³x Σ_{i<j} tr( F_ij G_ij )                                               (1.3)
```

**`G_ij` 被下列条件唯一确定**（局域性 + 量纲 + `H(4)`（含反射）+ `C`）：

1. **指数结构**：`(i,j)`-plaquette 只含 `A_i,A_j` ⇒ 其展开只能产出 `F_ij` 与 `D_i,D_j`；
2. **量纲 + `H(4)`（含 `i↔j` 与**反射**）**：`G_ij` 是 dim-4、与 `F_ij` 同槽（反对称）⇒ 候选只有两个：`(D_i²+D_j²)F_ij` 与 `D_iD_jF_ij`（注：`(D_iD_j+D_jD_i)F_ij = 2D_iD_jF_ij`，因 `[D_i,D_j]F_ij = i[F_ij,F_ij] = 0`——**不是** `[D_i,D_j]F_ij`）。后者被**反射**杀掉：`x_i→−x_i` 下 `F_ij` **奇**、`D_iD_jF_ij` **偶** ⇒ `tr(F_ij D_iD_jF_ij)` **奇** ⇒ 其格点和恒为 `0`（配对 `x` 与 `−x`）⇒ 系数 `= 0`。**`H(4)` 在这里承重（而不是在 dim-5 上，见 §3.1–3.2）**；
3. **`C`-宇称**：`F→−F^T` ⇒ `F` 与 `G` 都 `C`-奇；任何 `{F,F}`-型（`C`-偶）项**不许**进 `G`。⇒ 排掉 `F_ikF_kj` 一类。

⇒ `G_ij = (1/24)(D_i²+D_j²)F_ij`，系数 `1/24` 由**阿贝尔部分**给出（非阿贝尔的 `D` 化是唯一的协变化，且 `C`/维数不给第二个选择）。代回 `(1.3)`：

```
K₂^{mag} = (1/(24g²))∫d³x Σ_{i<j} tr( F_ij (D_i²+D_j²) F_ij )
         = −(1/(24g²))∫d³x Σ_{i≠j} tr( D_iF_ij )²   +   (全导数)                            (1.4)
```

（用 `tr(F D_i²F) = −tr(D_iF)² + ∂_i tr(F D_iF)`；`Σ_{i<j}Σ_{i'∈{i,j}} = Σ_{i≠j}`。）**符号：负半定**。全导数项在格点上是**真的** dim-6 算子（格点破坏连续平移），所以"平方和"这一读法是**方案相关**的；不拆开的 `(1.4)` 第一行才是无歧义的。

### 1.3 `1/24` 与符号的精确核（`[T]`+`[E]`）

取 `U(1)`、`A_2(x₁) = f(x₁)`、其余分量为 `0`。则 `(1,2)`-plaquette `U_□(x) = exp(ia[f(x+a)−f(x)])`，`1 − Re U_□ = 1 − cos(aΔf)`，且

```
(1/a)Σ_p(1−ReU) = ∫d³x [ f'²/2 + a² f'f'''/24 + O(a⁴) ]      （连续统预言）               (1.5)
```

`f = cos(qx)`、`L = 2πn/q` 时 `Σ_x` 有闭式（Jacobi–Anger）：`Σ_x = n[1 − J₀(2a sin(qa/2))]`，而

```
1 − J₀(2a sin(qa/2)) = a⁴·(q²/4) + a⁶·(−q⁴/48) + O(a⁸)        ← sympy，残差恰 0            (1.6)
```

⇒ `a⁴` 系数 `= q²/4` 与 `∫f'²/2 = q²L/4` 逐位吻合；`a⁶` 系数 `= −q⁴/48` 与 `∫f'f'''/24 = −q⁴L/48` 逐位吻合（`gm1alg_check.log [4]`；两处 `÷理论值 − 1` 都打印 `0`）。**直接格点和核**（不经 Jacobi–Anger；`n₂=n₃=1` ⇒ 横向体积 `a²`，故预言 `(1/a)Σ_x = a²L(q²/4 − a²q⁴/48)`）：`R := (1/a)Σ_x/(a²Lq²/4)` 应为 `1 − a²q²/12`；`a=2.4544e−2` 时 `R = 0.999949778872` vs `1−a²/12 = 0.999949800596`（差 `2.2e−8`，余量是浮点相消）。⇒ **(1.4) 的系数与符号都钉死**。

**自由场符号形式**：`Σ_{i≠j}tr(D_iF_ij)² → Σ_{i≠j}k_i²|F_ij|²`，横模取 `k = (k,0,0)`、`A = (0,A₂,A₃)` 时 `= k⁴|A_⊥|²` ⇒ `K₂^{mag} → −k⁴|A_⊥|²/(24g²)`。这就是 `GK2:172` 说的"协变化了的 `Σk_i⁴`"，但**系数是 `1/24` 不是 `1/12`**：差的因子 `2` 是 `tr_adj = 2N·tr_fund` 的归一差（`[M]`，不是矛盾，但引用时须点名归一）。

### 1.4 不出现的片（一条 `[T]`，一条 `[NG]`）

**(a) `trF³` 不出现：`[T]`。** `C` 作用在群元上为 `U → U*`，在代数上为 `X → −X^T`。则

```
tr(T^aT^bT^c) → tr((−T^{aT})(−T^{bT})(−T^{cT})) = −tr(T^{cT}T^{bT}T^{aT}) = −tr((T^aT^bT^c)^T) = −tr(T^aT^bT^c)
```

（末步：`tr M^T = tr M`）。⇒ 任何**三场强**迹算子都是 `C`-**奇**。Wilson 作用量 `C`-不变（`tr U_□ → conj(tr U_□) = tr U_□`，实数）⇒ `K₂` 必 `C`-偶 ⇒ `trF³` 与 `tr(F_ijF_jkF_ki)` **一律不许出现**。
⇒ 需撤回/降级：`GK2-SYMBOL.md:24`（"`trF³` 片奇次"）、`:171–175`（三片第 2 条）、`GK4-SCALINGWIN.md:135`（"如 `Σ tr F F F`"）。三处都不是"未证"，是**与 `C` 对称性直接冲突**。

## §2 猜想的判定

### 2.1 猜想的三种精确形式（必须分开，混着说会得到矛盾的判词）

```
(I)   算子恒等式：  K₂ = −H³/24 + (全导数/交换子项)          （任务书原话，无 X 的类）
(P)   谱恒等式：    ⟨n|K₂|n⟩ = −Δ_n³/24   ∀ 能量本征态 n     （(I) 的"可判"内核）
```

**(I) 作为字面陈述无法度量**：`H³` 是**三重积分** `(∫h)³`，`K₂` 是**单重积分**；"全导数"在单重积分里、`H³` 在重积分里，等号两边的**局域性不同**。任务书的"逐算子"（`GK2:124`）等于声称一个**非局域**算子等于一个**局域**算子——这在自由场里就已经是假的（§2.4）。

### 2.2 `(b)` ⟺ `(P)`，以及"要对所有态成立才够吗"

> **命题 B1（`[T]`，两行）.** 设 `K₂`、`H` 自伴、`H` 有纯离散谱 `{Δ_n}`。则
> `∃ 有界 X : K₂ + H³/24 = [H,X]`  ⟺  `⟨n|K₂|n⟩ = −Δ_n³/24 ∀n`。

## §3 `H(4)` 唯一性：为什么"形状唯一 ⇒ 比对 `−H³/24`"是空的

### 3.1 `H(4) ⊂ O(4)`：逻辑方向先摆正

`H(4)`（超立方群）是 `O(4)` 的子群 ⇒ `Inv(H(4)) ⊇ Inv(O(4))`。**`H(4)`-不变是更弱的条件**，它**不可能**禁掉任何 `O(4)`-允许的算子。⇒ `GK4-SCALINGWIN.md:135–136` 的"H(4) 禁 dim-5 ⇒ 无 `O(a)` 项"在**逻辑形式上**不能由 `H(4)` 单独给出（`[T]`，群论一行）。结论（无 `O(a)`）对，理由要换（§3.2）。

### 3.2 dim-5 不存在的**真**理由：维数 + Bianchi（`[T]`）

纯 YM 的建材只有 `F`（dim 2）与 `D`（dim 1），规范不变的迹算子需 `n_F ≥ 2`。dim 5 ⇒ `2n_F + n_D = 5` ⇒ 唯一解 `(n_F,n_D) = (2,1)`，候选只有 `ε^{μνρλσ}tr(F_μν D_ρF_λσ)`，而

```
ε^{μνρλσ}D_ρF_λσ = (1/3)ε^{μνρλσ}(D_ρF_λσ + D_λF_σρ + D_σF_ρλ) = 0     （Bianchi 恒等式）
```

⇒ **纯 YM 没有 dim-5 不变量**，与 `H(4)` 无关。这正是 `GK4:135` 想说的东西，但归因必须改：**"无 `O(a)`"是维数 + Bianchi 的推论，`H(4)` 在此不承重**。（对含标量/费米子的理论，dim-5 **是存在的**（如 `φ trF²`，`φ` dim 1），而它 `H(4)`-不变、`P`-偶 ⇒ **`H(4)` 连它都堵不住**。这正是"`H(4)` 方向反了"的最干净证据。）`H(4)` 的真作用是**选择**哪些 dim-6 被允许——而且它是**放宽**（允许 `O(4)`-破坏的形状，如 `Σ_i D_i⁴`），不是收紧。

### 3.3 dim-6 空间**不唯一**：两个独立结构的显式反例（`[T]`）

在 `C`-偶、`P`-偶、`H(4)`-不变、规范不变、`F`-only 的 dim-6 算子里，至少有

```
O_a := Σ_{i≠j} tr(D_iF_ij)²                      （= (1.4) 的那个，§1 算出来的）
O_b := Σ_j    tr( (Σ_i D_iF_ij)² )               （另一个独立收缩）
```

**反例（两行，`[T]`）**：取 `F_12 = f(x)`、`F_23 = g(x)`、`F_13 = 0`（纯空间、Bianchi 要求 `g₁ + f₃ = 0`，不涉及下面用到的 `f₁,g₃`），则

```
O_a = f₁² + f₂² + g₂² + g₃²          O_b = f₂² + (f₁ − g₃)² + g₂² = O_a − 2 f₁g₃
```

`O_b` 与 `O_a` 差一个**交叉项 `−2f₁g₃`** ⇒ 不成比例 ⇒ dim-6 空间 `≥ 2` 维。**模 IBP 仍独立**：`∫(O_b−O_a) = −2∫f₁g₃ = 2∫f g₁₃ = 2∫f f₃₃ = −2∫(∂₃f)² ≠ 0`（用 Bianchi `g₁ = −f₃`），而 `∫O_a` 是另一个泛函 ⇒ **不是同一算子的两种写法**。⇒ **`H(4)` + 规范 + 幂计数不唯一确定 `K₂`**。

补充：`S2` 方案还要加 `E`-片（`E²F²`、`E·D`-型多重收缩），维数更高；`trF³` 被 `C` 排除（§1.4a）。⇒ 任务书第 3 问的"若唯一 ⇒ 直接比对"**前提不成立**。

**与 §1.2 的"唯一"不冲突（必须点明，否则下一轮会误读）**：§1.2 唯一的是**单个 plaquette 的指数系数 `G`**——那条唯一性吃到了"`G` 只由 `A_i,A_j` 组成"这个**局域性**信息（plaquette 是 `1×1` 的）；这里不唯一的是**一般的 dim-6 算子空间**。⇒ 想用对称性**替代** matching，就必须丢掉"`G` 是 `1×1` plaquette 的指数"这条信息，而那正是 matching 的唯一入口。⇒ **对称性给形状、matching 给系数**（§3.4）。

### 3.4 但"系数唯一"：这才是本轮能拿的正面结果
