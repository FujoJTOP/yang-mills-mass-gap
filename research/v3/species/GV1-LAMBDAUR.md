## §2 · 算法与脚本（任务 2 前半）

### 2.1 模型（唯一一条假设，必须摆在最前面）

```
φ^U(Γ) = u^{|Γ|} · μ(G_Γ) ,   G_Γ = plaquette 邻接图（共享 link 为边，Δ=20）
μ(G)   = Σ_{A⊆E(G), (V,A) 连通生成} (−1)^{|A|}     （整数；sign = (−1)^{n−1}，无一例外）
⇒ c_Γ = μ(G_Γ)  （u-无关） ,  m_n = A_n := Σ_{|Γ|=n, p₀∈Γ}|μ|
```

**为什么是这个模型**：它就是语料自己一直在用的那个对象 —— `C02:14` 的块积 `φ^U = (−1)^{#bridges}∏_{blocks}μ(B)`（`[T]`）、`A01/C03` 的 `|φ^U| ≤ τ` 链、`C06:159` 的"立方体簇真值是 `u⁶` 阶小整数型求和"。同时也是 SU(2) 特征标展开的**首项**（每片取基本表示，共享 link 上的两片按 Weingarten 系数缩并，归一常数由 `c_f = u` 吸收；两套 `u` 归一并存见 `Z02:46`）。**高阶修正未算**（见 §7-1）。

`m_n^{1/n}` 与 `|c_Γ|^{1/n}` 的 `u` 归位逐条核对（这是 `GU4:267` 那个"差一个 `u`"的续）：本文件报 `A_n = Σ|c_Γ|`，故 `m_n^{1/n} = A_n^{1/n}·u` **只在 `|φ^U|` 含 `u^n` 的写法下成立**；`gv1_enum` 输出两列（`A_n^{1/n}` 与 `u·A_n^{1/n}`）以免二次混淆。

### 2.2 算法

* **簇枚举**：4D 超立方格，plaquette `=(x,μν)`，邻接=共享 link（每 link 恰 6 片 ⇒ 度 `4·5=20`，与 `P3-FULLREP-KP:116`、`C05:75` 一致）。含固定根 `p₀=((0,0,0,0),(0,1))` 的连通 `n`-集逐层生成、按排序元组去重。
* **`μ` 计算**：`f(S)=g(S)−Σ_{B∋min S,B⊊S}f(B)g(S∖B)`，`g(S)=(1−1)^{e(S)}`（`O(3^n)` 精确整数）。快速路径：树 `m=n−1 ⇒ μ=(−1)^{n−1}`；单圈 `m=n ⇒ μ=(−1)^{n−1}(L−1)`（剥叶求圈长 `L`）。**`ur1_fast6.py` 的两条快速路径我独立重写，且加了 1445 个抽样点与 DP 对拍，0 不一致**（`gv1_enum_n6.log:39`）。
* **单位元测试**（`gv1_enum_n6.log:4–16` 全 PASS）：`K_k ⇒ ±(k−1)!`（`k≤6`）、`C_n ⇒ ±(n−1)`、树 `⇒ −1`、`K₃–桥–K₃ ⇒ −4`（块积）、`K_6` 实数化 `|E|=15, μ=−120, τ=1296`（`Fraction` Kirchhoff）、4D 立方体 6 面 `|E|=12, μ=−64, τ=384`。
