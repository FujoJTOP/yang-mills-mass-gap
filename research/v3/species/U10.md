## 2 · Krein–Rutman 的精确陈述（问 1）

> **定理（Krein–Rutman 1948）`[T-standard]`.** 设 `X` 为 Banach 空间，`K⊆X` 为**全锥**（`K−K` 稠），`A∈𝔅(X)` **紧**且 `A K ⊆ K`。若 `r(A) := lim‖A^n‖^{1/n} > 0`，则
> 1. `r(A) ∈ σ(A)` 是**本征值**，且 `∃ 0≠x∈K`：`Ax = r(A)x`；
> 2. `r(A)` 也是 `A*` 的本征值，`∃ 0≠φ∈K*`：`A*φ = r(A)φ`。

**它给了什么，逐条（这是"问 1"的答案）：**

| 项 | KR 给不给 | 说明 |
|---|---|---|
| 主特征值 `r(A) > 0` | **不给（是假设）** | 正算子可拟幂零：Volterra `V`，`VK⊆K`，`r(V)=0`。要 `r>0` 需另证，例如 `A^n x₀ ≥ λx₀`（`x₀∈int K`，`λ>0`） |
| 存在 `K`-内本征向量 | **给（弱形：`x∈K`，非 `int K`）** | 强形（`x∈int K`）要**正性改善** |
| 简单性（`r` 单重） | **不给**（`A(K∖{0})⊆int K` 时给，Jentzsch–Krein） | 需**不可约/正性改善** |
| 谱隙（`sup{|λ|:λ≠r}<r`） | **紧性自动给**（非零谱是孤立本征值） | 但**间隙的均匀性**不给（§4） |
| 任何**数值常数** | **不给** | 语料已记：KR 的常数是 `~e^{−cV}` —— "existence, not a bound"（`FORGE5-WILSON-ALGEBRA-POSITIVITY:12`） |

**两条协变性（决定它能表达什么）：**
- `A ↦ cA`（`c>0`）：`r ↦ cr`，本征向量不变 ⇒ KR 的**全部结论对正标度不变**。它只能表达对 `A` 正齐次 0 次的陈述。
- `D_∞` 本身对 `T ↦ cT` **不变**（`Z↦c^T Z`、`φ↦φ+log c` 相消）⇒ 上与不矛盾；**但 `⟨ℓ,r⟩` 依赖 `ℓ,r` 的归一化**：`ℓ↦cℓ`、`r↦dr` 使 `⟨ℓ,r⟩↦cd⟨ℓ,r⟩`。**"`D_∞=⟨ℓ,r⟩`"是把归一化写进式子的约定，不是定理。**

**⇒ 对 `rs5` 逐字行的修正（J4）**：锥真正交付的是

```
D_∞ = ⟨φ₀, r⟩·⟨ℓ, r₀⟩        （φ₀∈K*, r₀∈K 是管两端的边界泛函）
```

即**两个锥正配对之积**：`>0` 由 `r∈int K`、`ℓ∈int K*` + 边界泛函严格正给出（**符号**），而 `≥c>0` 需要**配对的一致下界**——那不是 KR 的结论，那是"单端簇和一致有界"本身。

## 4 · "一致性"到底是什么：族版本定理（问 2 的正面回答）

**逐算子 KR 与"一致"之间隔着一整个定理。** 要 `inf_{(L,a)} D_∞ > 0` 与 `sup ρ_{(L,a)} < 1`，需要：

> **(U1) 均匀正性改善（Doeblin）**：`∃ n₀∈ℕ, ε>0`（**与 `(L,a)` 无关**）使
> ```
> T^n₀ x  ≥  ε‖x‖·e        ∀x∈K, ∀(L,a)        （e∈int K 固定）
> ```
> **(U2) 均匀准紧**：`sup_{(L,a)}‖T‖ < ∞` 且 `sup_{(L,a)} (second/top) ≤ 1−δ`，`δ>0` 与 `(L,a)` 无关。

**⇒ 有了 (U1)(U2) 才有族结论；KR 本身对 (U1)(U2) 一个字不说。** `[T-standard]`

**为什么"逐纤维套用 KR"原理上到不了一致（J3 的证明）：**

```
取族  A^{(n)}(0) := A(0) − n      （其余 A(α) 不动）
  ⇒ 符号结构不变（𝕋 的每一矩阵元的符号不动），全部逐纤维前提原样保留
  ⇒ log D_∞^{(n)} = log D_∞ − n ⇒ D_∞^{(n)} = e^{−n}D_∞ > 0   ∀n
  ⇒ ∀n: "D_∞^{(n)} > 0"（逐纤维 KR 的结论）成立，而 inf_n D_∞^{(n)} = 0
```
**⇒ 任何在 `A(0)↦A(0)−n` 下不变、且只逐纤维陈述的判据，都不可能给出 `inf D_∞>0`。** 这不是"未找到"，是**语法层**的不可能（与 `RS5` 命题 3.2、命题 4.1 同型）。`[T]`

## 5 · 缺步（Ursell 核变号）能否绕过？（问 3）

**不能。三条独立理由：**

1. **顺序错**：KR 的假设 (H2) 就是"存在不变锥 + 正性改善"。装饰气体的 `𝕋 = Σ_Γ φ^U(Γ)T_Γ` 而 `φ^U` 是**交错和**（`X01:71`、`C01:13`）⇒ `𝕋 K ⊄ K`。**`[NG]` 在 KR 的上游**，KR 不是绕它的工具。`[T]`
2. **小性绕过定量死**：`‖𝕋₋‖ < gap(𝕋₊)` 需要负部**小**。`β=2.5` 处 Ursell/KP 比 `ρ_Ur = 4.6×10³`（需 `<1`），超墙 **`1.5×10³×`**（`T1:33,36,354`，`[V]`）⇒ 不是"紧一点"，是三个数量级。`[T]`
3. **结构性绕过 = 语料已判的 `[NG]`**：`P6-1` 的 Gram/反射正性 `A = ⟨v|𝕋|v⟩ ≥ |⟨v|𝕋_∅|v⟩|²`（`P6-SPEC:36,65,70`，标 `[R]` 未证）；`RS2 §7` 已判它是"唯一未被判死的形状"，但**没被证**。且即便证成，Gram 只给 **sign + rate**，`size` 仍要 `ū<1`（`D_∞=1+O(ū)` 的"领先类唯一"= 绝对可和）。`[NG]`

## 6 · 判死线

### (a) —— **不成立**

KR 给不出"一致性"。三层冗余（J5）+ 逐纤维不可升级（J3）+ 即便全给也到不了 `w₁`（J1）。**⇒ 无 Clay 路径。**

### (b) —— **成立，且不可绕**

缺步 `[NG]` 立在 KR **上游**：KR 需要正表示，而正表示正是缺的那件东西。小性绕过在 `ū=33.98` 定量死（`4.6×10³` vs `1`）。**明说：此步绕不过。**

### (c) —— **触发（这是本轮的判）**

**`D_∞` 的一致 ≠ `w₁` 的一致**，因为 `w₁ = (a₀/M₀)·D_∞`，`M₀`（以及 `a₀` 的 `u`-幂，见 §1.5）**也变**，且 `M₀ ~ a^{−8}` 是 UV 接触项、与转移谱不同源。**`D_∞` 最多贡献一个 `2.10` 的因子（窗内）。** `[T]`

### 酸测（宪章 §1）

| 模型 | `D_∞` | `f₁²` | `w₁` | 工具（`D_∞>0`）表现 |
|---|---|---|---|---|
| 自由场 / `β=0` | `1`（最大正） | `0` | `0` | **不失效 ⇒ vacuous** |
