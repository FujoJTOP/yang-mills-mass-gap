## §3 ★ `l3b` 逐字解剖：它**没有**给 `inf m₁² ≥ δ²`

### 3.1 机器陈述（`lean/L3B-Assembly.lean:40–45`，`assembly_of_I2`，`sorry=0`）

```
spec : Finset ℝ ,  m₀ δ c : ℝ ,  hm : 0 ≤ m₀ ,  hδ : 0 < δ ,  hc : 0 < c
h1 (I2) : ∀ x ∈ spec,  x = m₀  ∨  x ≥ m₀ + δ
hstar(★): ∀ y ∈ spec,  y ≠ m₀ → y ≥ c          ← Lean linter：**未被引用**
⊢ ∃ g > 0, ∀ x ∈ spec,  x ≠ m₀ → x ≥ g          （g := min δ c；仅用 h1 + hm 时 g := δ）
```

### 3.2 三条独立的否定理由（任一条足够，三条都有）

1. **结论的作用域**：`x ≠ m₀`。`m₀` 在陈述里是**参数**，其唯一下界是**假设** `hm : 0 ≤ m₀`。⇒ `l3b` 对 `m₀`（= 底原子 `m₁²`）给出的全部是 `m₁² ≥ 0`，**不给正下界**。它把 `x ≥ m₀+δ` 降成 `x ≥ δ`，被降的对象是**除底层以外的层**（即 `Λ★`），不是底层。`[T]`
2. **自身见证即反例**：`L3B-LEAN:105 witness_satisfiable` 逐字取 `spec={0,1}, m₀=0, δ=1, c=1` —— 满足 `hm,hδ,hc,h1,hstar` **且**满足结论（`g=1`），而 `m₁² = m₀² = 0`。⇒ `l3b` 在 `m₁²=0` 的模型上**为真** ⇒ **不蕴含** `inf m₁² ≥ c`（对任何 `c>0`）。这与"酸测"同一条逻辑：一个在 `m₁=0` 上仍成立的命题不能产出 `m₁>0`。`[T]+[E]`
3. **它不生产 `δ`**：`g = δ` 里的 `δ` 是 `h1`（= I2）**借来的假设**；`assembly_of_I2` 只用 `I2`，`(★)` 冗余（linter 逐字 `hstar is not explicitly referenced`）。⇒ `l3b` 是**装配簿记**（`L3B-LEAN:44,60` 逐字"装配是簿记，不是物理难点"），不是一条新原语。`[T]`

### 3.3 那条误读的出处（必须先认账，否则会反复）

`FROZEN-POSITION.md:11` 的冻结句写成 "`I2 ∧ m₀ ≥ 0 ⇒ m ≥ δ > 0`（`g = δ`，三行）"。这是**缩写**：其中的 `m` 指"**非底层**的质量"，按 §3.2(1) 的唯一合法读法即 `Λ★`；若读成"底原子 `m₁ ≥ δ`"则**陈述为假**（§3.2(2) 的见证）。⇒ 建议此后把该条改写为 `I2 ∧ m₀ ≥ 0 ⇒ (∀x∈spec, x≠m₀ ⇒ x ≥ min(δ,c))`，**禁用 `m ≥ δ` 的简写**。

### 3.4 `l3b` 到底给了什么（别浪费它）

它确实是一条**"距离档 → 位置档"**的转换，只不过转换的是**第二支撑点**：`Λ★ ≥ min(δ,c) ≥ 0`。这条与 `H3:128` 的自否证条件（"若造出距离→位置的引理 ⇒ §4 价值塌成一条"）**不同**：它要的是**底层**的位置，`l3b` 给的是**上层**的位置。⇒ 对 B 无贡献；对 `(E-I2)` 第一半（`Λ★` 的下界）有贡献，但 `Λ★` 的下界本来就等价于 `m₁²` 的**上界**，而 `(E-I2)` 第一半要的是 `Λ★ − m₁² ≥ δ`（**两者的下界**，`F06:118`/`G02:166` 逐字"整侧缺席"）。`[T]`
