### 2.1 形式化：`G″(0)` 的 `(L,a)`-一致界 ⟺ 什么

先把对象钉死（`GPP-STRUCT` 的精确方差分解，`[T]`）：

```

G″(0) = E[H|0] − Var(G|0) =: S − D          （eq:split，[T]，逐点恒等）
R := D/S = 1 − G″/S                          （比值，[T]；与 v 的标度无关）
```

于是，若**固定模 `v`、`‖v‖`、`k`**，

```
「G″(0) 的 (L,a)-一致界」
  ⟺ ∃λ>0 ∃γ*:  ∀(L,a)∈W :  λ ≤ G″(0;L,a) ≤ γ*(L,a)          （下界 + soundness）
```

## 3. `o07` 说只有水平集 `R=1` 一致 —— C5 该不该改写成"`{R=1}` 与 `(L,a)` 无关"？

**不该。三条理由，第一条是判死性的。**

**(i) 它过不了酸测 —— 因此 vacuous `[T]`。**
`{R=1} = {G″=0}`。自由无质量场：`G″≡0` ⇒ `R≡1`（`S>0`）⇒ **`{R=1}` 就是整个空间，对一切 `(L,a)` 完全相同** ⇒ "`{R=1}` 与 `(L,a)` 无关"在自由场上**为真**。按 `C4`（酸测）：一个在自由场上成立的陈述不叫 C5 ⇒ **这条改写恰好是 C4 要抓的空转**。

**(ii) 它严格弱于 C5。** `G″≡0` 对一切 `(L,a)` 也满足它，却给不出任何 `λ>0`；C5 要的是**带余量的下界**，不是零点位置。

**(iii) `o07` 的 `[T]` 恒等式本身就退化。**
`R_L−1 = L(R_1−1)E_1/E_L` 的前提是 `G″_L=L·G″_1`（按块幅固定）。若同一约定下 `S` 也是广延量（`S_L=L·S_1`，独立复制体必然如此），则 `E_1/E_L=1/L` ⇒ **`R_L≡R_1`**；若改用 `‖v‖=1`（把模摊到 `L` 块），则 `S_L=S_1`、`D_L=D_1` ⇒ **Again `R_L≡R_1`**。两种自洽约定都给 `L`-无关。⇒ 表里 `R` 变号只能来自**混用归一化**。**`R` 的 `L`-依赖不是 C5 的障碍**（`p11` 实测 `E[κ]` 比值 `0.998`、`Var` `0.962`、`Δ` `1.18` ⇒ 全都 `O(L⁰)`，`[E]`）。

**结论**：`R` 的正确用法**不是**取水平集，而是**保留为正余量的比值**：
```
C5 ⟺ ∃ρ₀>0: R(L,a) ≤ 1−ρ₀   即   D ≤ (1−ρ₀)S
```
——这条**带余量**、**与 `v` 的标度无关**、**在自由场上失效**（自由场 `D=0, S>0 ⇒ R=0`，故 `R≤1−ρ₀` **假**）⇒ 过酸测。**这是唯一既保留 `o07` 的正确直觉（比值才是一致量）、又不 vacuous 的写法。**
