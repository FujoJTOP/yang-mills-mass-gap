## §1 第一刀：`0.018832` 与 `Var` **不是同一把尺**（单位错 6.25 倍）

`SOS1.md:99–107` 原文：`w=sin²u/u` 在 `(0,π)` log-凹，`φ″ ≥ 1.5492346`，1D BL 给
```
Var_Haar(g) ≤ E[g′²]/ρ_min = 0.01883152401      （真值 Var_Haar = 0.011059294）
⇒ G″ ≥ S − β²·0.0188315 = 0.2051153 − 0.1177 = +0.0874183
⇒ 窗口 β < 3.3003218
```
**注意它自己已经把 `β²` 乘上去了**（`SOS1.md:104`：`β²·0.0188315`）；窗口 `β<3.3003` 正是 `β²B = S` 的解。
逐字读候选链的 `Var ≤ 0.018832` 与 `E[H]+W > 0.018832` 是**同一常数**，就等于把 `β²` 丢掉：

```text
β=2.5：Var(G) = β²·Var_Haar = 6.25 × 0.0110593 = 0.069121   （≠ 0.018832）
真阈值（同尺）= β²·0.0188315 = 0.117700
```

**后果（可当场核）**：在 θ=π 切片上 `Var(G)` 实测 `0.0175…0.0718`（`a∈[0,2.6]`），
`Var ≤ 0.018832` **只在 `a ≳ 2.5`** 才成立，而那里 `E[H]+W_j = −0.03 < 0` ⇒
**字面链在 β=2.5 的整条切片上"两前提同时成立"的点集为空**。它不是"尚未证"，是**取错了尺**。
反过来，若只保留 `E[H]+W>0.018832` 而不查 `Var` 前提，链在 `a=1.0` 会"得出" `G″>0`，而**实测 `G″=−0.0368`**
（`S02-ORDERS.md:123`、本轮独立复算，§6）⇒ 字面推理**不可用**。
