## §2 在它下面算单片 `⟨V({p})⟩`

**识别（唯一可写候选）**：`V({p}) ↦ δ_p = ½‖1−U_p‖²_F`（`fax:21924`，`∈[0,2N]`，SU(2) 下 `=2(1−½tr U_p)`）。这是**假设**，不是逐字等同（见 0.5）。

**精确算式**（`C_k^int` 通用，`σ_k² := ⟨(F^a_p)²⟩_{C_k^int}` 每色）：

```
⟨δ_p⟩ = ∫_{SF_k} δ_p R_k dN(0,C_k^int) / ∫_{SF_k} R_k dN(0,C_k^int)      （依赖 λ, δ ⇒ 非唯一数）
 二次阶： ⟨δ_p⟩ = ¼ Σ_a⟨(F^a_p)²⟩ = (N²−1) σ_k²/4
 精确：   ⟨δ_p⟩ = 2(1 − ⟨cos(R/2)⟩) ,  R = |χ₃(σ_k)|
```

**自由归一取 β=2.5**（同一 Wilson 归一 `Σ_p β(1−½tr U_p)`，SU(2)）：

```
σ_k² = (4/β)·P_pp ,  P_pp = [F(F^TF)^{+}F^T]_{pp}
 精确：每个 k≠0 有 rank F(k)=3（核 = 纵向模）⇒ 6 分量平均 P_pp = 3/6 = ½
 数值：[F(F^TF)^{+}F^T]_{pp} = ½(1−V^{-1})：L=4,8,12,16 → 0.498046875 / 0.499877930 /
        0.499975888 / 0.499992371（缺陷恰为单个零模 0.5/V，机器精度吻合）
 ⇒ σ² = 2/β = 0.8 ,  ⟨δ_p⟩_quad = 3/5 = 0.6 ,  ⟨δ_p⟩_exact = 0.55226013114246468294
```

| 量（同一 `δ_p` 定义） | Haar（基例特征标，`β=2.5`） | 高斯（`C_k^int`，自由归一 `β=2.5`） |

## §3 能否 `< ε`：裁决

1. **门逐字**：`ε ∈ (0,1)`（`fax:22711`）。故"存在 ε 使 `‖Φ_k‖_a ≤ ε`"**当且仅当**该值 `<1`（`ε` 事后可选取 `(值,1)`）。**下一手**：判前件只问"值<1?"，不问"差几倍"。
2. **两条参考都过**：高斯 `0.55226<1`（`ε` 余量 `0.448`）、Haar `0.98561<1`（余量 `0.0144`，极窄）。⇒ **`[T]`：`(V)` 的幅度前件未被否定**；`(V)` 不因此被反证。
3. **第二条不额外收钱**：`Cε ≤ ε/2 ⟺ C ≤ 1/2`（`fax:22490`；`HZ8-VLEMMA.md:32,38`），`ε` 抵消——故"`ε` 贴着 1"不加重收缩条款。**下一手**：把两条分开记账，别用一条的余量抵另一条。
4. **仍未证（`[NG]`）**：①`V(B;·)=δ_p` 的等同（0.5，仓内无原式）；②`sup_k σ_k²` 的 `k`-一致界（`C_k^int` 幅度未数值化：`c₀,ν_σ,σ` 数值 0 命中，只有 `µ=1` 可行 `fax:19917`）。**下一手**：先钉 ②，它决定"单片过门"是否对一切 `k` 成立；①决定这个数是否就是 `(V)` 的对象。

**裁决**：`C_k^int` 不是相互作用测度，而是**截断高斯协方差**（`[T]`）；它下面的单片值**不是** Bessel 比，而是高斯矩：`(N²−1)σ²/4`（二次阶）/`2(1−⟨cos(R/2)⟩)`（精确）。自由归一 `β=2.5` 给 `0.55226`，Haar 同一 `δ_p` 给 `0.98561`，**两者都 `<1=sup ε`** ⇒ `(V)` 的幅度前件**未被否定**（`[T]`）；`1.01439>1` 是**比值归一**的产物，不是 `δ_p` 档的事。要把它变成对 `(V)` 的真判，差 0.5 与 4.②两步。
