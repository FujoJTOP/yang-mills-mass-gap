## §1 负模的精确位置 `[T]`（问题 1）

`s = ±1` 螺旋度、`n` 为 Landau 级、`k_∥ = (k₃,k₄)`。Savvidy 横向磁背景（`F^3_{12}=B`，色方向 3）下，带电胶子（a=1,2）的 Hessian 谱为

```
λ_{n,s}(k_∥) = k_∥² + (2n+1) g|B| + 2 s g|B|                     (1)
λ_min = λ_{0,-1}(0) = g|B| − 2g|B| = −g|B|      < 0
```

- **方向（显式）**：色方向 = 背景的 3；偏振 `ε_− = (e₁ − i e₂)/√2`（横向、磁）；横向横向平面内取 **最低 Landau 级 `n=0`**（LLL 型，宽度 `1/√(gB)`，即 `∝ exp(−gB(x₁²+x₂²)/2)` 的规范等价类）；沿 `x₃, x₄` **常数**（`k₃=k₄=0`）。
- **`s=+1` 分支**：`λ_min = +3g|B|`（正），即"同一位置的正伙伴"存在但被 LLL 结构推高。
- 校验（`f02_wcalc.log §1`，振子基精确截断）：`s=+1 → +3.000000000000`，`s=−1 → −1.000000000000`（`gB=1`）。

## §2 三个候选 `W` 的 `W^{1/2}HW^{−1/2}`（问题 2）

记 `f := W^{1/2}`、`M := Hess(S_W+Φ) = −D² + 2g·adF`，`A := f M f^{−1}`。**精确**（无近似，`f` 为色标量乘子）：

```
f(−D²)f^{−1} = −D² + 2(∇log f)·D + (Δ log f − |∇log f|²)                       (2)
A            = M + 2(∇log f)·D + (Δ log f − |∇log f|²)                          (3)
½(A + A*)    = M − ¼|∇ log W|²                     [ 自伴/形式意义 ]            (4)
```

**逐字读 (4)：换位子项 = `−¼|∇log W|² ≤ 0`。它是负的，且是"设计梯度的均方"的负值 —— 想要的正项不存在。** 这一条是本轮的核心算术；`f02_wcalc.log §4` 在格点上给出**精确**离散版（误差 `5.7e−14`）：

```
½(A+A*) = (1/h²)[ 2d − Σ_μ cosh(½ δ_μ log W)(S_μ + S_{−μ}) ]                    (4')
⇒ 每个键权 cosh ≥ 1（只增大），且 A_ii = M_ii **逐位精确**（对角元一点没动）
```

即：**"逐点"层面没有任何正项被造出来；被改动的只有跳跃项，且一律改大（谱底只会下移）。**

| 候选 | `∇log W` | `½(A+A*)` 相对 `M` | `⟨ψ₀|A|ψ₀⟩`（负模，未加权） |
|---|---|---|---|
| `W = e^{−cΦ}` | `−c∇Φ` | `M − (c²/4)|∇Φ|²` | `−gB − (c²/4)⟨|∇Φ|²⟩_{ψ₀}` |

## §3 判（问题 3、4）

### §3.1 主结果 `[T]`

> **F02-T1（W-CALC no-go）。** 设 `M = −D² + 2g·adF` 自伴、`λ_min(M) = −g|B| < 0`（§1 的 Savvidy 负模），`W > 0` **任何**可逆正算子，`A = W^{1/2} M W^{−1/2}`。则
> **(i)** `spec(A) = spec(M)`（相似不变）⇒ `λ_min(A) = −g|B|`，**没有任何 `W` 能移动谱底**；
> **(ii)** `φ_W := W^{1/2}ψ₀` 是 `A` 的**精确**本征向量（本征值 `−g|B|`）⇒ 负模不是"被压住"，而是被**重标定后原样搬运**；
> **(iii)** 若 `W` 为乘子（本任务的全部候选类）：在**未加权**的负模上
> ```
> ⟨ψ₀| A |ψ₀⟩ = −g|B| − ¼ ⟨ |∇log W|² ⟩_{ψ₀}  ≤  −g|B|
> ```
> 等号 ⟺ `∇log W ≡ 0` 于 `supp ψ₀`。∴ **整个类的最优点 = 平凡权 `W = const`；任何"设计"都严格更差，代价恰为设计梯度的均方 `(1/4)⟨|∇log W|²⟩`。**
> **推论。** `W^{1/2}(H−E₀)W^{−1/2} ⪰ Δ²1_{Ω⊥}` 与 `H ⪰ E₀+Δ²1_{Ω⊥}` **等价**（谱）/ **更弱**（形式）⇒ 该不等式**不携带任何超出被证结论的内容**。

数值确认：`§3` 相似残差 `≤ 7.2e−13`（全候选）；`§4` 离散恒等式 `5.7e−14`；`§5` 任意 SPD `S`（非乘子、`80×80`）的谱漂移 `2.5e−12`。

### §3.2 (a)/(b)/(c) 逐条

- **(a) 不成立。** 没有 `W` 使不等号成立。`D1 W-SHIFT` 作为**证书机**死：它不是"含 BE 为特例、严格更强"，而是**整类为相似变换**，`c=1/2, K=S` 这个 BE 点不是"族里一个点"，而是这个族**唯一的结构**。
