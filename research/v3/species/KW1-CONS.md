## §1 逐项标度权重：`κ_W` 的精确定义与三族计算

### §1.1 定义（先把"权重"钉成可算的东西）

变换：`x → sx`（`R → sR`），**`Λ` 固定**，`θ` 不变（无量纲，`RV-3 §1`）。定义

```
κ_W(s) := d ln W(sC) / d ln s   =  ε(sx),      ε(x) := x F′(x)/F(x)
```

其中 `W = F(x)`、`x = Λ·L(C)`、`L` 在膨胀下是 1 次齐次（`[C]`：见 §3，(A1)(A2)）。
`ε` 是 `F` 的对数微商（弹性）。**`κ_W` 只有在 `ε ≡ const` 时才是"一个数"** —— 这一步是全部争执的来源。

### §1.2 三族逐项

**(i) 纯幂 `F(x)=x^{−p}`.**
`ln W = −p ln x`；`d ln W/d ln s = −p`（`x→sx` 只给 `d ln x/d ln s = 1`）。
⇒ `κ_W = −p`，**`s`-常数**。`κ_W=0 ⇔ p=0 ⇔ F≡const`。
⇒ **幂律类里 `κ_W=0` 排掉一切衰减幂，只留常数（不衰减）。** `[T]` ⇒ 这就是既有 `[T]`："`W` 不能按 `R` 的幂衰减"。

**(ii) 指数 `F(x)=e^{−c x^α}`，`c>0`，`α>0`.**
`ln W = −c s^α x^α`；
`d ln W/d ln s = −c α s^α x^α`（`α` 从 `s^α` 掉下来，`x` 不动）。
⇒ `κ_W(s) = −α c (sx)^α`。**不是常数**（除非 `α=0` 或 `c=0`）。
⇒ `κ_W=0` 对 (ii) **无定义/不适用**：`κ_W` 依赖 `s`（也依赖 `x`），把它写成"`=0`"是类型错误。`[T]`

**(iii) 幂×指数 `F(x)=x^{−p}e^{−c x^α}`.**
`ε(x) = −p − cα x^α`；`κ_W(s) = −p − cα(sx)^α`。
要求 `κ_W` 是常数 `0`：⇒ `p=0` **且**（`c=0` 或 `α=0`）。
⇒ **"零反常维"这一条对 (iii) 的全部内容 = `p=0`（无 prefactor 幂）；对 `α` 零内容。** `[T]`
（`p≠0` 是反常维；`ε` 的常数部分就是它。`κ_W=0` 只能杀常数部分。）

**(iv) 对数 `F(x)=(ln x)^{−p}`.**
`ε(x) = −p/ln x → 0`（`x→∞`）。
⇒ `κ_W` **非零但渐近趋于 0**，与 `κ_W=0` 在 `R→∞` 不可分辨。`[T]`

### §1.3 `[V]` 数值核（`numpy 2.3.5`，`x₀=1`，`c=1`；`s=0.5,1,2,8`）

| 剖面 | `s=0.5` | `s=1` | `s=2` | `s=8` | `s`-常数？ |
|---|---|---|---|---|---|
| `e^{−x}`（`α=1`） | `−0.5000` | `−1.0000` | `−2.0000` | `−8.0000` | **否** |
| `e^{−x²}`（`α=2`） | `−0.5000` | `−2.0000` | `−8.0000` | `−128.0000` | **否** |
| `e^{−√x}`（`α=1/2`） | `−0.3536` | `−0.5000` | `−0.7071` | `−1.4142` | **否** |
| `e^{−x³}`（`α=3`） | `−0.3750` | `−3.0000` | `−24.000` | `−1536.0` | **否** |
| `x^{−2}` | `−2.0000` | `−2.0000` | `−2.0000` | `−2.0000` | **是** |
| `x^0`（常数） | `0` | `0` | `0` | `0` | **是** |

**对数族**：`κ_W((ln x)^{−2})` 在 `x=10²,10⁴,10⁸,10¹⁶,10³²` 给 `−4.343e−1, −2.171e−1, −1.086e−1, −5.429e−2, −2.714e−2` ⇒ 每十倍程减半，**趋 0**。

⇒ 数值与 `[T]` 逐位吻合：**`s`-常数权重 ⇔ 纯幂**；指数/对数族根本没有 `κ_W` 这个常数。`[V]`

## §2 `κ_W=0` 的非空内容：零反常维（一条），以及一条定案用的归谬

### §2.1 唯一的非空内容

按 `RV-3 §1` 的口径：`W` 无量纲 ⇒ 量纲权重恒 `s^0`；`κ_W` 是**齐次次数**（反常维），两者只在 `κ_W=0` 重合。所以

> **`κ_W=0` ⇔ 反常维为 0 ⇔ `W` 的全部标度由量纲ful的 `Λ`（或 `σ`、`μ`）承载，`W` 自身不带剩余幂。**

可操作表述（这一条是**真的**且可用的）：

```
W(C) = Φ( 无量纲几何量 ;  Λ·L(C) ),     无 R^{−p} 乘性前因子，且 Λ 是唯一标度
```

⇒ **它排除**：`W ~ R^{−p}`（`p≠0`）；`W ~ R^{−p}Φ(ΛR)`（`p≠0`）；任何被当作自由参数调的 `κ_W`（`(★)` 权重匹配的唯一解是 0，`RV-3 §2`）。
⇒ **它不提供**：`Φ` 的函数形式、`Φ` 的 argument 是哪个几何量、`Φ` 的衰减指数。`[T]`

### §2.2 归谬（把 (a) 彻底关掉）

假设 `κ_W=0` 是对剖面的**逐点**约束（即对所有 `s`：`ε(sx)=0`）。则：
`ε ≡ 0 ⇒ F′≡0 ⇒ F≡const`，面积律 `e^{−σR²}` 被排除。
但 `RV-2 §3` 定面积律**是** `(★)` 的解（`[C]`，`σ=2g²N/ε²`，残差比 `1.000`）。矛盾。
⇒ **`κ_W=0` 不是对 `F` 的约束。** ⇒ 对 `F(x)=e^{−cx^α}` 的 `α`，`κ_W=0` **一句话都说不出**。`[T]`

**这一步是本题最要紧的一步**：`RV-3 §2` 的 `κ_W=0` 是在**幂律 ansatz**（`W(sC)=s^{κ_W}W(C)`）内部匹配出来的；那个 ansatz 本身就把指数类排除在定义域外。把结论搬到指数类上，是把"类内定理"当"类外约束"用——`(★₁)` 的错是"漏 `R` 幂"，这里的错是"越类使用"。`[E]`（方法学，非 `RV-3` 的算错：`RV-3 §2` 自己已写"把 `κ=0` 读成 `G` 必为常数会重犯错"）

**⇒ (a) 不触发。`α` 不被 `κ_W=0` 钉。**（钉它的机器在 §4。）

## §3 "`W = F(Λ·几何)`" 这步：几何量**不被**权重定出来

### §3.1 候选表：谁过 `κ_W=0`？

| argument | 膨胀次数 | 无量纲组合 | `κ_W=0` | 弧分割可加？ | 线性剖面给 |
|---|---|---|---|---|---|
| 周长 `P` | 1 | `ΛP` | ✓ | **精确**（`P₁+P₂=P`，任意分割） | 周长律，`α=1` |
| `√A` | 1 | `Λ√A` | ✓ | ✗（`√A` 不可加） | 面积律，`α=2` |
| 面积 `A` | 2 | `Λ²A` | ✓ | 平面扇区内精确（`A₁+A₂=A`，`RV-2 §1`） | 面积律，`α=2` |
| 直径 `d` | 1 | `Λd` | ✓ | ✗ | —（非可加，非标准） |
| 总曲率 `∮k ds` | 0 | `∮k ds` | ✓ | 可加（但取值离散） | 相位因子，非衰减 |
| 形状无量纲量（如 `P²/A`、自交点数、`θ`） | 0 | 本身 | ✓ | — | 只调幅 |

**⇒ 六个候选全过 `κ_W=0`。** 权重是**一个数**（齐次次数），它只看得见"总次数"；`ΛP`、`Λ√A`、`Λd` 的总次数都是 1。**由 `(★)` 的权重定不出来。** `[T]`

### §3.2 计数论证（为什么"定不出来"不是我没找到，而是原理性的）

记 `𝒲 := {F(ΛL) : L 是 1 次齐次几何泛函，F 任意}`，模去重参数化 `(L,F)~(L′,F′)`（若 `F(ΛL)≡F′(ΛL′)`）。
`𝒲` 是无穷维（`F` 自由）。`κ_W=0` 是**一个**标量方程（常数权重 = 0）。
**一个标量方程在无穷维空间里至多杀掉一个方向** ⇒ 既不能钉 `L`（离散/连续选择），也不能钉 `α`（`F` 的连续参数）。`[T]`

### §3.3 为什么"换几何量"的问题上标度天然失明（具体机制）

`ΛP` 与 `Λ√A` 的判别式是 **`P/√A`**。这是**标度不变量**（`P(sC)/√A(sC) = P/√A`）。
而 `κ_W` 也是标度不变量。**一个标度不变量无法区分两个标度不变量**——除非它比"次数"携带更多信息，而它不携带（它只有一个数）。

`[V]`：圆 `P/√A = 2√π ≈ 3.5449`；方 `=4`；`2:1` 矩 `=4.2426`；`10:1` 矩 `=6.9570`。⇒ 只有**变形状**能区分，**变标度**不能（固定形状时 `ΛP ∝ Λ√A`，同一族）。

**⇒ 这与 `RV-2 §1` 的"平面圆族对面积律是盲的"是同一件事的两个面**：`A₁+A₂=πR²` 是恒等式（族退化），`ΛP ∝ Λ√A`（形状退化）。两者都是**族退化**，不是标度信息。`[T]`

## §4 `α` 的自由度：`α = q+1`，及 `α=1` 的判死

### §4.1 乘法性只冻到"指数型"，不冻 `α`

若要求 `W(C_xy)W(C_yx)=W(C)`（`RV-3 §4` 的乘法律，`θ`-无关时成立），则 `ln W` 对弧可加 ⇒ `W=e^{−E}`、`E` 可加。
1 次齐次可加泛函 = 弧长（`∮ds`）；2 次齐次可加泛函 = 面积（平面扇区）。⇒ **可加性把候选压到 `{P, A}`，但 `α` 仍自由**（`α=1` ↔ `P`，`α=2` ↔ `A`）。`[T]`+`[C]`
⇒ 乘法性**不**钉 `α`；它恰恰**同时放行** `α=1` 与 `α=2`。这就是 `RV-3 §5` 的"面积律/周长律都给 `A_1=0`"。

### §4.2 `α = q + 1`（钉 `α` 的真机器）

`(★)` 在加法/平面扇区约化为（`RV-1 §8.3(i)`，`MU-3 §2(ii)` 引用）：

```
G_R = −(4π g²N / ε²) · R · G          (G_R := dG/dR)
⇒  d ln G / dR = −(4π g²N / ε²) · R      ⇒  源的 R-幂  q = 1
⇒  ln G = −(2π g²N / ε²) R² + C          ⇒  **α = q+1 = 2**,  σ = 2g²N/ε²
```

**逐项**：`G=e^{−cR^α}` ⇒ `d ln G/dR = −cαR^{α−1}`；与 `−λR^q` 匹配 ⇒ `α−1=q` ⇒ `α=q+1`。系数 ⇒ `cα = λ`。取 `α=2`、记 `c := σπ`（因 `G=e^{−σπR²}`）⇒ `2σπ = λ = 4πg²N/ε²` ⇒ `σπ = 2πg²N/ε²` ⇒ **`σ = 2g²N/ε²`**。
`[V]`：`σ=2`、`g²N=1`、`ε=1`，`R=0.5,1,2,4` 处 `G_R/RHS = 1.000000000000`（四位全对）。`[V]`

**`α` 的坐标依赖（必须写清，否则 `α=1 vs 2` 是可争论的）**：
`α` 是"指数在 `ΛR` 里的次数"。面积律也可写成 `exp(−(σ/Λ²)(Λ²A))`（对 `Λ²A` **线性**）或 `exp(−(σ/Λ²)(Λ√A)²)`（对 `Λ√A` **二次**）；周长律写成 `exp(−(μ/Λ)(ΛP))`（对 `ΛP` **线性**）。
⇒ **坐标无关的说法是"指数对哪个可加泛函线性"**；`α` 是它在 `ΛR` 坐标下的读数。两者信息等价，`α=2 ⇔ 指数 ∝ Λ²A`。`[T]`

### §4.3 `α=1`（周长律）允许吗？—— 分四层判

| 层 | 判 | 依据 |
|---|---|---|
| (i) `κ_W=0` | **允许** | `ΛP` 无量纲、无 prefactor、`α` 自由（§1、§3） |
| (ii) 乘法性（任意分割） | **允许，且比 `α=2` 更稳** | `P₁+P₂=P` 对**任意**分割精确；`A` 只在平面退化扇区可加（`RV-2 §1`） |
| (iii) `(★)` 的 `R`-幂 | **排除** | 周长律 `d ln W/dR = −2πμ` 是 **`R`-无关**（`q=0`，`α=1`）；`(★)` 的 `q=1` |
| (iv) 物理目标 | **排除（在有 `σ>0` 的域内）** | 周长律 ⇒ `V(R)` 有界 ⇒ `σ=0` ⇒ 无禁闭；而 `β<1/48` 面积律是 `[T]`（P3） |

**`[V]` 核 (iii)**：`(W_R/W)_周长 = −2πμ`（常数）；`(RHS/W)_{(★)} = −(4πg²N/ε²)R`（∝`R`）。比值在 `R=0.5,1,2,4` 给 `1.0000, 0.5000, 0.2500, 0.1250` ⇒ 精确 `∝1/R`。
**方法论警告（值得单列）**：`R=0.5` 处比值恰为 `1`（因 `μ=g²N/ε²` 时 `2πμ = 4πg²N·0.5/ε²`）——**单点拟合会把周长律误判成解；必须做 `R`-扫描**。这与 `FIG8 §4` 的"面积律在反对角线单点上看似成立"同型。`[V]`+`[E]`

**判死（第三题的正答）**：
> **`α=1` 由 `κ_W=0` 明确允许；它被排除的依据是 `(★)` 接触项的 `R`-幂（`q=1`，不是 `q=0`），而非法定标度。**
> **物理上**：周长律 ⇒ **无禁闭**（`σ=0`），**与隙无关**——周长律既不蕴含隙（`d=4` `U(1)` Coulomb 相：周长律 + 无能隙光子），也不排除隙（有质量屏蔽相：周长律 + 有隙）。⇒ **"无禁闭但可能有隙"成立，且更强的说法是"周长律与隙逻辑独立"**，与 `IMP-ARROWS` 行 3/7（面积律 ⇏ 隙；RP + 面积律 可无隙）互为镜像。`[T]`
> ⇒ **周长律不能用来证隙，但它也不排除隙；它是 YM 的错误相，不是错误逻辑。**

### §4.4 张力（本条是 `κ_W=0` 完全不参与的第三条独立结论）

`α=2` 需要 `ln W` 对**面积**可加；面积只在平面退化扇区可加（`RV-2 §1`、`FIG8 §4`：8 字形上面积律残差 `4πσ²(ρ₁R₁+ρ₂R₂) ≠ 0`，`R`-幂 `+1`）。
⇒ **`α=2` 与"对全部分割的乘法性"不能同时成立。** 二择一：
- 非平面扇区 `W` 非乘法 ⇒ `G ≠ W·W` ⇒ `k≥1` 非零 ⇒ 正是 `RV-3 §3/§5` 的结论与 `A₁(R)≠0` 判据；

## §5 完整后果清单（一行一条）

### §5.1 `κ_W=0` **能**排除

3. **Coulomb 相**：`V(R) ~ 1/R` ⇒ `W = e^{−TV(R)}`；`W` 本身不是 `R` 的幂 ⇒ **完全放行**。**`κ_W=0` 管的是 `W` 的 `R`-幂，不是 `V(R)` 的 `R`-幂** —— 这条最容易被误读成"排除了 Coulomb"。`[T]`
4. 周长律 `α=1`（§4.3：被 `(★)` 排，不被 `κ_W` 排）。`[T]`
5. 有界不衰减 / 振荡 / 非单调的 `F`（`κ_W` 定义域外）。`[T]`
6. **哪个几何量**（`ΛP` / `Λ√A` / `Λ²A` / `Λd` / 形状无量纲量）——§3.2 计数论证。`[T]`
7. `G` 的 `k≥1` 分量（θ-依赖）——`RV-3 §3`，正交问题。`[T]`

### §5.3 `κ_W=0` **不涉及**（另有归属）

4. **隙**：`κ_W=0` 对 `σ`、对谱、对 `m_{0⁺⁺}` 零内容 ⇒ **不能用于证隙**。`[T]`
