## §2 · 「更可及」的判决

### §2.1 判据（先给判据，再判）

**判据 A（可及性判据，本轮采用）**
> 货币 `κ` 比货币 `κ′` "更可及" ⟺ 其**最平凡可证上界**满足 `sup_L ∫_{β₀}^{2.5} κ^{triv} dβ < ∞`
> （`L`-一致），且在 `∫κ^{triv} ≤ budget` 这条判据上过关。

理由（不是发明）：桥引理消费 `∫C` 且其对 `L` 的结论必须是 `L`-一致的（靶的量词是 `inf_L`，`Z01:204`）；而 `L⁴` 型常数在 `L → ∞` 时把地板压成 `0`（`D04:194` 逐字"不是 `L`-一致地板"；`D04:203` "`C ~ V` 是硬上限"）。
**判据 A 是任务书示例判据（"对角货币的最平凡界是否 `L`-一致"）的逐字形式化。**

### §2.2 判据 A 的答案：**否**（三条独立理由，均 `[T]`）

1. `∫ 12L⁴/Δ dβ` 的平凡上界是 `12L⁴Δβ/δ`，**`∝ L⁴`** ⇒ 不满足 `sup_L < ∞`。对角侧 ✗。
2. 残数侧同一句：`12L⁴N_OΔβ/δ`，**`∝ L⁴`** ⇒ ✗。**两侧同判。**
3. 比值 `1/N_O` 与 `L,V,Δ` 无关（§1.3）⇒ **不存在任何 `L`、`V`、`Δ` 轴上的改善**。

### §2.3 "只要不引入 `1/Δ` 就不可能 `L`-一致"？——真，但**不具判别力**

这是本轮要正面回答的一句。分三步：

- **(a) 不引入 `1/Δ` 的形，界是 `12V`，`∝ L⁴`，确实不 `L`-一致 `[T]`。** 加性形是无条件可判的（§1.2），且判为**负**。
- **(b) 引入 `1/Δ` 的形，界是 `12V/Δ`，仍 `∝ L⁴`，同样不 `L`-一致 `[T]`。** 因为 `Δ = O(1)`（格点单位；`[E]` `1.707`，`RUN3:51`），`1/Δ` 是 `O(1)` 的乘子，**不能抵消 `V`**。
  要让 `12V/Δ` 过关需 `δ ≥ 12L⁴/K`：`L=1` 时 `1.750`（对角）/ `3.102`（残数）；`L=2` 时 `28.00` / `49.64`。
  而 `δ ≤ Δ(β₀) = 25.09`（`[T]`+`[E]`）⇒ **`L ≥ 2` 时无 `δ` 可救**。
- **(c) 合题**：`1/Δ` 这个分母**不是障碍所在**。障碍是 `∂_βH = S_W ~ V`（`D04:203`）。
  ⇒ 任务书假设的二分（"有 `1/Δ` ⟹ 可及；无 `1/Δ` ⟹ 不可及"）**两支都落在不可及**。
  ⇒ **对角版的优势只能是形式上的（少一个因子在分子的表示里），不可能在可及性上。**

### §2.4 唯一的逃逸 = 相消 = 靶

要在 `12V/Δ` 之外得到 `O(1)` 的率，唯一形状是**比值界**

```
      |Δ⟨S_W⟩| ≤ c·Δ ,   c = O(1)、L-一致          (2.1)
```

而 `(2.1)` 逐字就是 `|d log m_lat/dβ| ≤ c`，即 `log Δ` Lipschitz；经 `GW1.pos_C_exists`（`GW1:37`、`:93`，Lean 机检）
**`(2.1)` 的可行性 ⟺ `Δ` 在区间上无零点 = 靶**。`GW1:65` 已逐字记此判（"O(1) 分子界是靶的改写，**循环**"）。
⇒ 对角货币的"更可及"若成立，必须建立在这条相消上；而这条相消**不是货币问题，是载体问题**。
**⇒ 货币层的降级对相消毫无贡献。**
