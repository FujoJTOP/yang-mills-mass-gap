## 1. 定义核准（`Φ`、`Φ′`、`a`）

`O09 §1` / `ch05:196–206` / `ch16:120–124`：

```
Φ = −log J_Haar = −log | c_SU(N) / c_flat |² ,   c_SU(N)=Π_{i<j} 2 sin(d_ij/2) ,  c_flat=Π_{i<j} d_ij
  = Σ_{i<j} g(λ_i−λ_j) ,   g(d) = −2 log( sin(d/2)/(d/2) ) ,   g′(d)=2/d−cot(d/2) ,  g″(d)=½csc²(d/2)−2/d²
```

`Φ` 是**复行列式模平方的对数**，且是 `Ad`-不变（类函数）：`Φ(gXg†)=Φ(X)`。`Φ′` 是沿固定生成元 `E`（`v=E`）的方向导数；切片坐标 `a := ⟨E,X⟩ = 2tr(EX)`，`τ` 流为 `X ↦ X+τE`。

一阶微扰论给出（`P16 §2.1`，`X=diag(x)`）：

```
δx_i = E_ii (在 X 的本征基里) ,   Φ′ = Σ_{i<j} g′(x_ij)(E_ii − E_jj) ,   a = 2 Σ_i E_ii x_i
```

## 2. 第 1 问：`a=0` 上 `Φ′` 恒 0 吗？——`SU(2)` 是，`SU(3)` 不是

### 2.1 `SU(2)`：`Φ′ = (g′(ρ)/ρ)·a`（**精确**，`[T]`）

`N=2` 时 `Φ = g(ρ)`，`ρ=|ξ|`（`SU(2)` 的类函数只依赖 `tr X²` ⇒ 径向）。于是

```
Φ′(ξ) = g′(ρ) (ξ·E)/ρ = (g′(ρ)/ρ)·a        （a=ξ₃, v=e₃）
⇒ Φ′ ≡ 0  ⟺  a = 0 ，  且  Φ″|ₐ=0 = g′(ρ)/ρ = 1/(2u²) − cot(u)/(2u) = Φ_ρ′/ρ
```

机检（`r11_adjudicate.log [A]`）：4 个切片点 × `a∈{0,0.4,−0.7}`，
`max|Φ′|_{a=0} = 0`（点态），`max|Φ′ − (g′(ρ)/ρ)a| = 8.6e−42`；横向 `Φ″|ₐ=0` 与 `g′(ρ)/ρ` 及 `1/(2u²)−cot(u)/(2u)` **三式一致到 12 位**（`u=0.3/1.0/1.4`）。径向 `Φ″=g″(ρ)` 亦逐位吻合。

**「对一切 `θ`」是 trivially 的**：`θ` 不以任何方式进入 `Φ`（`Φ=−log J`，`J` 只依赖 `ρ`）；`θ` 只进入 `S_W`。所以 `Φ′≡0` **与 `θ` 无关**。
**它不是巧合，是 `N=2` 的结构**：`Φ` 径向 ⇒ `N=2` 的 `∇Φ ∥ ξ` ⇒ 只要切片满足 `⟨E,ξ⟩=0`（`E ⊥ ξ`），`Φ′` 就整块为零。而「`Φ` 径向」**只对 `N=2` 成立**（见 2.2）。

### 2.2 `SU(3)`：`Φ′|_{a=0} ≢ 0`（反例 `[T]`）

`N=3` 的 `Φ` 是类函数但**不**径向：`∇Φ ∈ t_{X}`（与本征值同基底的对角元）一般不平行于 `X`。故 `a=0`（一个线性条件）**不**蕴含 `Φ′=0`。

反例（`log [C-ii]`，随机搜索取最大者）：`x=(−1.5797, 0.3243, 1.2554)`（`Σ=0`，谱差 `1.904/2.835/0.931` 全非零 ⇒ 正则，且 `|x_ij|<2π` 在平图内），`e=(0.9153,−2.7871,1.8718)`（`Σe=0`，`e⊥x`）：

```
a = 2tr(EX) = −1.6e−16 ≈ 0        Φ′(X) = Σ g′(x_ij)(e_i−e_j) = +7.99090189719e−3 ≠ 0
```

且 `g′` 奇 ⇒ `Φ′(−X) = −Φ′(X)`，`a(−X)=0`；切片密度 `|Δ|²=Π 4sin²(x_ij/2)` 关于 `θ↦−θ` 偶 ⇒

```
E[Φ′ | a=0] = 0 ,      Var(Φ′ | a=0) = E[Φ′² | a=0] > 0        （SU(3)，[T]）
```

**量级要说准（不许夸大成 O(1)）**：`g′(d)=d/6+d³/360+…`，`Σ_j(x_i−x_j)=N x_i`、`Σx=0` ⇒ 线性项 `∝ Σ_i E_ii x_i = a/2` 在 `a=0` 上被**精确**抵消，故

```
Φ′|_{a=0} = O(|x|³)      （三次项系数 Σ_i E_ii x_i³/120 起）
```

机理：`Hess Φ(0) = (N/12)·Id` 对 `N=2` 和 `N=3` **都各向同性**（`P16 §3` 的 `N/12` 地板），二次阶 `Φ=(N/12)Σx²` 对一切 `N` 都「径向」，各向异性从四次项 `φ=g−d²/12=d⁴/1440+…` 才进入。
机检（`log [C-ii]`末）：`Φ(t x)/t² → 0.16333334 / 0.38000001`，`(N/12)Σx² = 0.16333333 / 0.38000000`（`N=2/3`）。

⇒ **`SU(2)` 与 `SU(3)` 的差别是「恒等于 0」vs「不为 0 但三阶小」**，两者都**不是**「O(1) 的对立」。这一点决定了下面第 4 问的答法：`Var(Φ′)` 在 `SU(3)` 上也是高价小量，**不能**用它来解释 r08 的 `S≡D`。

## 3. 第 2 问：`SU(2)` 的 `D` 到底是哪个？——`β²s²Var(g)`，不是 `Var(Φ′)`

## 4. 第 3 问：`SU(3)` 的 `g` 是什么？——`S_W` 的展开系数（`q04` 对），不是 `Φ` 的

`q11_cert.py` 头注的两条逐字式（`[T]`，本文件 `log [A]/[B]` 复算）：

```
S_W = β(1 − cos u·c + sin u·s·ξ₃/ρ)  ⇒  G = β s g(u) ,  H = (βc/2) g(u) ,
g(u) := sin u/(2u) = sin(ρ/2)/ρ ,   u=ρ/2
```

同时 `J = 4sin²u/ρ²`、`√J = sin u/u` ⇒ **`g = √J/2 = ½·(c_SU(2)/c_flat)`**，而 `Φ = −log J = −2 log(2g)`。
所以 `g` 有**两个身份且恰好同函数**：(i) `S_W` 沿 `v` 的一、二阶展开系数（`q04` 的说法，也是它在 `D` 里的**功能**）；(ii) 半个 Weyl 比（`sin u/u` 的一半）。这不是巧合：`g` 就是 `(1/2)tr(WU†)|_{ξ₃=0}=cos u·c` 的 `ξ₃`-展开里 `∂_{ξ₃}、∂²_{ξ₃}` 带出的那个函数。
**`SU(3)` 没有单一 `g`**：`G=(β/3)Σλ_i sin(φ_i−θ_i)`、`H=(β/3)Σλ_i²cos(φ_i−θ_i)`（`r08` 式 (65)(66)）是**逐 link/逐分量**的，对应物是**逐对**的 `g_ij=sin(x_ij/2)/x_ij`，不是标量 `g`。

## 5. 第 4 问：`r08` 是否漏项？——形式上是（漏 `G`），但它把 `G≡0` 当成了**定义**

```
一般式（[T]，q11 恒等式）:  D = Var(G) + Var(Φ′) + 2Cov(G,Φ′)
  r03/SU(2):  Φ′≡0（精确）  ⇒ D = Var(G) = β²s²Var(g) = 0.06912 ≠ 0
  r08/SU(3):  G≡0（声明）   ⇒ D = Var(Φ′)
```

`r08 §2` 的原话是「`θ=π` 切片：`S_W≡β` ⇒ 权重常数 ⇒ … `G≡H≡0` 逐点（切片内 `S_W` 常值）」。**这一步不合法**：`G = ∂_τS_W` 是**离开切片的方向导数**，切片**上**的常值对它什么也没说。`r03` 就是反例——`θ=π` 时切片上同样有 `S_W≡β`，而 `G=β s g(u) ≠ 0`（否则 `D` 会是 0，`q11` 的 `0.06912` 就不存在）。

`r08` 里 `G≡0` 之所以成立，是因为 `τ: θ↦θ+τλ` 是**环面平移**：`λ∈t` 与切片切向，`τ` 把切片映到自己身上，`S_W` 在**整条轨道上**都是 `β`。于是

```
Z(τ) = ∫_T |Δ(θ+τλ)|² dθ ≡ Z(0)   ⇒   ∂²_τ log Z ≡ 0   ⇒   S ≡ D      （恒等式，[T]）
```

**`∫∂²_τJ=0` 这一步没错**（点态残差 `9.1e−8`，`[C]`；`r08` 已给精确 `[T]`）。900² 台形均值（半格偏移避奇异线）：`mean|Δ|²=6.000000`、`mean JΦ″=48.040044`、`mean JΦ′²=48.026696`（差 `+1.3e−2` 是求积/奇异线裁剪误差；`r08` 的精确有理值是 `48−48=0`）。

⇒ **`r08` 不是算术错误，是模型退化**：它取了一个 `S_W` 恒等于常数、且 `τ` 属测度对称群的模型，`S≡D` 由构造成立，故对 `S−D>0` 结构性无话可说（vacuous / no-go），**不能**读成「`SU(3)` 在 `θ=π` 的 gap = 0」。

## 6. 判死线逐条

**(a) 成立（判死线给定形式），但两条理由都要改口径：**

1. 正确的机制不是「`Φ′≠0` 且 `S≡D`」，而是 **`τ` 是测度对称（环面平移）⇒ `∂²_τlogZ≡0` ⇒ `S≡D` 是恒等式**。这与 `Φ′` 是否为零**无关**：即使把 `Φ′` 换成 0，`S≡D` 仍由 `Z(τ)=Z(0)` 强制。
2. 「`SU(2)` 的正性是 rank-1 现象」有**精确形式**（可写死）：
   `Φ′ = (g′(ρ)/ρ)·a`（`N=2`，`[T]`）⇒ `Φ′|_{a=0}≡0` ⇒ `Var(Φ′)=0` ⇒ `SU(2)` 的 `D` **只剩** `Var(G)`；
   `N=3` 上 `Φ′|_{a=0}≢0`（反例 `[T]`），但 `O(|x|³)`（因 `Hess Φ(0)=(N/12)Id` 各向同性）⇒ `Var(Φ′)` 是两个模型里都属高价的小量。
   ⇒ 真正的「rank-1 现象」是 **`D` 的 `Φ′` 支在 `N=2` 被精确抹零**，而 `SU(3)` 抹不掉；不是「`SU(3)` 的 gap 恒为 0」。

**(b) 不成立**：`r03` 的 `Φ′≡0` 只在其切片（`N=2`、`v=e₃`、`ξ₃=0`）成立，不能搬到 `SU(3)`；因此「`r08` 的 `D` 用错」这个指控**只能对 `SU(3)` 成立、不能靠 `r03` 推出**。（若真要给 `SU(3)` 的正确 `D`：`D=Var(G+Φ′)`，两项都非零，需 8 维指数坐标模型才可算，`r08 §4(b)` 已承认缺这一步 —— 本文件不做，`[NG]`。）

**(c) 不成立**：`r08` 的 `∫∂²_τJ=0` 是**对的**（点态+积分两路核对）。

**额外必须记的一条（不许省）**：即便在 `SU(2)`，`S−D>0` **也不是结构性正性**——`O09 §4.2` 已证 `β*=√(W₀/V₀)=4.30661` 处 `S=D` 精确相交（`Φ″` 是 `β`-无关、`Var(G)∝β²`）。所以「`SU(2)` 的 `+0.136`」是 `β=2.5` 落在窗口内的事实，不是定理性强性。这条使得「`SU(2)` 有正性、`SU(3)` 没有」的对比更弱：**两边都是窗口/模型现象，差别只在 `N=2` 的 `Var(Φ′)` 恰好为 0。**
