## §1 `T` 的结构：不是 `L`-张量积，只有时间幂

### 1.1 定义（`[T]`，逐字取 `D02-DIRECT.md:36–43`）

```
T_L[U,U'] = e^{−S_sp(U)/2} · e^{−S_sp(U')/2} · W_L(U,U')
W_L(U,U') = ∫ ∏_{x∈T³_L} dV(x) exp[ (β/2) Σ_{x,i} Re tr( U_i(x) V(x+î) U'_i(x)† V(x)† ) ]
U,U' ∈ SU(2)^{3L³}，V ∈ SU(2)^{L³}，H_L = L²(SU(2)^{3L³}, Haar)
```

`S_sp(U)=βΣ_{空间 plaquette p}(1−½Re tr U_p)`；空间切片有 `3L³` 条 link、`3L³` 个空间 plaquette、`L³` 条时间向 link。

### 1.2 为什么不是 `T_1^{⊗L}`（`[T]`）

三条独立理由，任一条都足够：

1. **空间 plaquette 因子不按 link 因子化。** `e^{−S_sp(U)/2}` 是**按 plaquette** 的乘积，每个 plaquette 因子耦合 4 条 link；它不是 `∏_{link} f(U_link)`。故连对角部分都不是 link-张量积。
2. **`W_L` 不按 site 因子化。** 被积函数按 link 因子化，但每个 `V(x)` 出现在 6 个 link 因子中（`x` 与 `x−î` 两个方向各三条）；对 `V(x)` 的积分把 `x` 处及相邻的 `U_i(x), U'_i(x)` 耦合起来。`W_L` 是一个 **3D 规范积分的配分函数**，不是 `∏_x W_x`。
3. **耦合图随 `L` 变，不只是“份数”变。** 图是单个连通的 `L`-环面（周期边界），有 `3L³` 条 link、`3L³` 个空间 plaquette；`L=2` 与 `L=4` 不是同一个图的 `L` 份拷贝。**没有与 `L` 无关的因子可张量化。**

因此不存在 `T_L = T_1^{⊗L}`（也不存在 `⊗_{x∈T³_L} T_x`）。**定义核不做张量分解** `[T]`。若存在某个酉等价把 `T_L` 变成张量积，那会把 4D 理论变成乘积理论（连通关联/面积律不因子化），与本模型不符——此句标 `[C]`，不是 `[T]`。

### 1.3 唯一的乘积结构是**时间幂**，不是张量积（`[T]`）

4D 环面 `T³_L × (Z/L_t Z)` 上

```
Z = tr( T_L^{L_t} ) .
```

- 这是 `T_L` 的 **`L_t` 次幂**（同一 Hilbert 空间上的复合），**不是** `T_L^{⊗L_t}`。`tr(T^{L_t}) ≠ tr(T)^{L_t}`；`T^{L_t}` 的本征值是 `λ_n^{L_t}`，不是“每层独立本征值的乘积”。本征值比 `λ₂/λ₁` 按 `L_t` 指数缩小（能量隙 `−ln` 为 `L_t m`，线性），这与张量积的“逐因子乘积”是两件事。
- 每单位时间的质量是 `−ln(λ₂/λ₁)/a`，与 `L_t` 无关——这是转移矩阵的**定义**，不是 `L`-一致性定理。若把 `L` 读成时间长度 `L_t`，`w₁` 还恰好与 `L_t` 无关（`T2-TUBE-OVERLAP.md:254–259`：`f₁²` 是极点留数，`w₁` 与管长无关），于是“一致性”是恒等式；但**靶的 `L` 是空间格点数**，两者不能混。时间方向的平凡性不解决空间方向的 `L`。
- 把 `T^{L_t}` 误读成 `T^{⊗L_t}` 是本题最容易被误用的“张量积”：前者是幂（谱 `λ_n^{L_t}`，本征值比按 `L_t` 指数缩小），后者是不同 Hilbert 空间上的乘积（谱是逐因子乘积）。**两者都不是 `T_L = T_1^{⊗L}`。**

### 1.4 精确的“乘积”反例：2D YM 与 M6（`[T]`）

这不是空谈：仓内有两个**精确**的乘积结构，二者都判死“乘积 ⇒ 靶”。

- **2D YM**：时间规范下 `T[U',U]=∏_{l=1}^{L} w(U'_l U_l^{−1})`，规范不变子空间上 `T=w^{*L}`，本征值 `ŵ(R)^L`，故
  ```
  m(L) = −ln(λ₂/λ₁) = L·(−ln(ŵ(R₁)/ŵ(R₀))) =: Lσ  → ∞   （torelon）
  ```
  逐位机检 `m(L)/L=0.4038776782` 在 `L=2..5` 相同（`D03-ML.md:69–76`、`G04-M1UNIF.md:37–39`）。而 `tr F²=H` 守恒 ⇒ `f₁²≡0`、`w₁=0` 精确（`G04:37–39`；`FOSP-B.md` §B7）。**唯一精确的“按 `L` 乘积”给的是 `m(L)=σL→∞` 与 `w₁=0`，不是 `L`-一致地板。**
- **M6**（谐振子 ⊗ 环上自由模）：`μ=μ_a⊗μ_b`，`μ_b` 是平坦 Lebesgue，故 `m_L=min(ω, 2π²/L²)→0`，而 `G″=2ω>0`（`B05-INVENT.md:23–38`、`F04-SIGKATO.md:24–48`、`D03:150`）。**乘积 + 正局部曲率仍可无隙。**
- **自由场按动量张量分解**：`T=⊗_k T_k`，最低模 `ω_min=√(m²+4sin²(π/L))`，无质量时 `=2sin(π/L)→0`（`X3-TENSOR.md:141–158`）。**张量积的谱底是 min，不是“一致正”。**

## §2 `w₁` 与 `T` 的谱：权重不是位置

### 2.1 定义（`[T]`，逐字取 `WA-ALIGNMENT.md:87–93`）

```
T = e^{−aH},  Tψ_n=λ_nψ_n,  λ_n=e^{−aE_n},  E₀=0,  ψ₀=Ω=1
w_n = |⟨ψ_n|φ⟩|²/M₀ = ⟨ψ_n|o⟩²/Var_μ(o),   Σ_{n≥1}w_n=1
w₁ = ⟨ψ₁|o⟩²/Var_μ(o) = cos²∠(φ,ψ₁),   φ=QO|Ω⟩,  M₀=‖φ‖²
```

**谱给的是位置** `s_n=E_n−E₀=−ln(λ_n/λ₀)/a`；**`w₁` 是权重**，需要本征矢 `ψ₁` 与源 `o`。两者不是同一个数据。

### 2.2 `w₁` 不是谱泛函：四个精确反例（`[T]`）

1. **源转动**（`U1-HARNACK-BOUND.md:226–232`）：固定 `T`，取 `o_θ=1+ε(cosθ ψ₁+sinθ ψ₂)`（小 `ε` 下合法正源），则 `w₁=cos²θ→0`（`θ→π/2`），而 `T` 与整个谱不变。⇒ 同一个谱可以配任意 `w₁∈[0,1]`；**谱数据不可能确定 `w₁`**。
2. **有质量自由场**（`U1:240–243`；`D08-LOGDET.md:96`）：`T` 有隙，但 `O=:φ²:` 是两粒子割，`f₁²=w₁=0`。⇒ **有隙 ≠ 有原子**。
3. **2D YM**（`G04-M1UNIF.md:37–39`；`R5-EXACT-ANCHORS.md` §1.1）：`T` 的有限体积第二态是 `σL` 的 torelon（`σ=3g²/8` 是弦张力，不是有限体积 `m(L)`），而 `tr F²` 守恒 ⇒ `w₁=0`。⇒ “有质量隙、无原子”的精确模型（且 `m(L)=σL→∞`，不是 `L`-一致）。
4. **离域最低模**（`U1:246–248`）：局部源对离域模 `w₁=2/(L−1)→0`。⇒ **源的投影不由谱的“有隙/无隙”决定**；真正的 `w₁` 地板需要“模局域化 + 源对齐”，不是谱。

### 2.3 唯一的精确下界：residue–level-gap，且它循环（`[T]`）

设 `s₁:=m₁²=inf supp ν_O`，`s₂:=inf supp(ν_O−f₁²δ_{s₁})`，`Ē:=M₁/M₀`，`M₁=∫s dν_O(s)`。则

```
w₁ = f₁²/M₀ ≥ (s₂ − Ē)/(s₂ − s₁),     非空 ⟺ s₂ > Ē .
```

（`T2-TUBE-OVERLAP.md:203–214`；`WA-ALIGNMENT.md:58–64,105–114`。）它是**不等式**，不是恒等式；对两点测度 `εδ_{s₁}+(1−ε)δ_{s₂}` **取等**（尖锐）。它消耗的是 **`s₂`＝第二支撑点＝隔离**，也就是“比隙高一阶”的量；没有 `s₂` 就没有下界。**这不是 `λ₂/λ₁` 的函数，而是 `(Ē,s₂)` 的比较。** 在 YM 里 `s₂` 正是 `I₂`/`H*`，所以用它给 `w₁` 地板＝用隔离给地板，循环（`T2:205–214`；`T-WAVE-SYNTHESIS.md:49–76`）。

### 2.4 连 `λ₂/λ₁` 都可能是错对象（`[T]`）

靶里的 `m₁` 按局域算符的 KL 测度定义：`m₁²=inf supp ν_{¼trF²}`（`G04-M1UNIF.md:19–27`）。**全转移矩阵的第二本征值** `−ln(λ₂/λ₁)` 可能是 **torelon**：2D YM 精确 `m(L)=σL`（`D03-ML.md:69–76`）；4D `β=2.5` 盒子上 `σL` 与 `m_glueball` 同量级，第二态很可能就是 torelon（`D03:163–175`）。⇒ `G″` / `m₁²=inf supp ν` / `−ln(λ₂/λ₁)` 是**三样东西**（`B03-LATTICE.md:84–97`）。把 `w₁` 接到 `λ₂/λ₁` 上，先要证明第二态在 `0⁺⁺`、N-ality 0 道内——这本身是 `I₂` 的一部分。

## §3 `L`-一致性：转移矩阵给不了

### 3.1 转移矩阵实际给的三样（`[T]`）

1. **有限体积隙** `m(L)=−ln(λ₂/λ₁)/a`。它是**定义**，不是 `L`-一致下界；`λ₂<λ₁` 由紧性/PF 逐 `L` 成立（`D02:58–61`、`F06-KLATOM.md:16,32–43`），但 `inf_L m(L)>0` 是墙。
2. **`w₁` 的递减上界**：`ŵ₁(T)=e^{E₁t}C̄(t)=w₁+Σ_{n≥2}w_n e^{−(E_n−E₁)t} ≥ w₁`，关于 `t` 递减、极限为 `w₁`；**每个有限 `t` 的数都是上界**，不给下界（`T2:180–201`）。有限 `T`（管长）的数是上界；有限 `L` 的数也不能认证（`T2:194–201` 引 R3 的 Stone–Weierstrass），但 `L` 方向没有“从上方”的单调性定理——不能把 `T`-单调性搬到 `L`。
3. **residue–level-gap**：见 §2.3，需 `s₂`，循环。

### 3.2 有限体积隙本身就不 `L`-一致（`[T]`）

`m(L)` 的 `L`-单调性**没有定理**（`D03-ML.md:48–57`：检索 OK、命中 9、0 条是该定理）。精确反例覆盖两个方向：

| 模型 | `m(L)` | 极限 | 标签 |
|---|---|---|---|
| M6（谐振⊗自由） | `min(ω,2π²/L²)` | `0` | `[T]`（`D03:150`） |
| 自由标量·扭曲 | `√(m²+π²/L²)` | `m`（上方递减） | `[T]`（`D03:153`） |
| 横场 Ising `g<1` | `~Ae^{−κL}` | `0`，而真隙 `=1` | `[C]`（数值，`D03:154`） |
| 2D YM | `σL` | `∞`（torelon） | `[T]`（`D03:149`） |

“**递增 + 有限正极限**”在四模型表里**0 个实例**（`D03:157`）。⇒ 即使只谈隙，`T` 也不给 `L`-一致；`w₁` 比隙多一层源重叠，**更不可能**由 `T` 的 `L`-结构白拿。

### 3.3 就算 `T_L` 是张量积，也不够（`[T]`/`[NG]`）

- **谱侧**：`T=T₁⊗T₂` ⇒ 本征值相乘 ⇒ `λ₂/λ₁=max(λ₂(T₁)/λ₁(T₁), λ₂(T₂)/λ₁(T₂))` ⇒ `m=min(m₁,m₂)`。一个平坦因子就给 `m=0`；M6 是精确见证（`B05:23–38`）。自由场的动量因子给 `2sin(π/L)→0`（`X3:141–158`）。**张量积继承最差因子，不创造一致正。**
- **权重侧**：即使所有因子有隙、`m>0` 一致，`w₁` 仍可为零：有质量自由场的 `:φ²:`（`w₁=0`）、2D YM 的 `tr F²`（`w₁=0`）、源转动（`w₁=cos²θ`）。**均匀隙只控 `s₁`，不控 `⟨ψ₁|o⟩`。**
- **唯一的精确 `L`-乘积**是 2D YM：`m(L)=σL→∞`、`w₁=0`（§1.4）。它不是“一致性”的正面例子，而是**反例**：乘积结构把 `L` 放进谱的指数（torelon），并把原子关掉（守恒量）。

### 3.4 唯一可能的两条路（都未证）

1. **有限体积单调性**：若 `w₁(L,a) ≥ w₁(L+1,a)`，则 `inf_L = lim_{L→∞}`（`UNIF1.md:79–85`，M2，`[C]`）。这是一条**独立的单调性引理**，不是 `T` 的张量结构给的；仓内 `m(L)` 的单调性已判 `[NG]`（`D03-ML §1.2`），`w₁` 的单调性更未证。
2. **一致隙 + 一致对齐**：`W∧H1 ⇒ G`（`T-WAVE-SYNTHESIS.md:67–76`）；对 `w₁` 本身，这就是靶 `W`，不是 `T` 的推论。`β<1/48` 窗内 `P3`+SZZ/OS 给 `f₁²≥r₀` 且 `L`-一致（`T2:226–252`、`G04:63–69`），但 `β=2.5` 在窗外（`G04:68–69`）。

## §4 判死线逐条

### (a) 转移矩阵能给 `w₁` 的 `L`-一致吗？——**不成立** `[NG]`

逐字：

> **转移矩阵不能给 `w₁` 的 `L`-一致性。** 它最多给有限体积隙（非单调、可趋 `0` 或 `∞`）与 `w₁` 的**递减上界**；唯一的精确下界是 residue–level-gap，需第二支撑点 `s₂`（隔离），循环。`T` 的无穷维只挡区间证书，不挡 `L`-一致；真正的障碍是**非张量积 + `w₁` 非谱泛函**。

### (b) `T` 非张量积、有 `L`-依赖耦合——**成立** `[T]`

逐字：

> `T_L` 的空间 plaquette 因子耦合 4 条 link，`W_L` 的时间向 link 积分通过共享的 `V(x)` 耦合相邻站点；耦合图是单个 `L`-环面，`3L³` 条 link、`3L³` 个空间 plaquette、`L³` 条时间向 link。**没有 `T_L=T_1^{⊗L}`，也没有 `⊗_x T_x`。** 唯一精确的乘积是时间幂 `Z=tr(T_L^{L_t})`；2D YM 的 `T=w^{*L}` 是精确乘积，但给 `m(L)=σL→∞`、`w₁=0`。

### (c) `w₁` 与谱的关系不清——**成立** `[T]`

逐字：
