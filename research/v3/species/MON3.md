### 1.2 定义（`[M]`，与 A04 §2 的恒等式对齐）

```

  (S2) **流不变**：dM/d ln a = 0 沿 β(a) ⟺ d ln m_lat/d ln a ≡ 1 + d ln(aΛ)/d ln a
```

## §3 第三问：`δ_A·a = 0.5686159` 是不是那个稳定模量 —— **不是**（四处不对）

先给 `[T]` 的正面部分（不许抹掉）：`δ_A = ln(1/ū)/a` 是**恒等式**、`ē=eΔC̄` 纯组合数 ⇒
`δ_A·a = ln(1/ū) = 0.5686159179138452…` 与 `a` 无关，50 dps 扫 `a=1…1e−12` 偏差 ≤4e−51（G06 §2–§3）`[T]+[E]`。
**但它不是 §1.2 的 `M`：**

**(i) 对象错位。** `δ_A` 是 β<β₁ 窗内 KP 团簇展开的**衰减率 = 该道质量**，`δ_A·a = ln(1/ū)`
是"格点单位质量是纯数"——这正是 `m_phys = 0.5686/a → ∞` 的**UV 系数**，即 P1 自否那一种形状
（G05B §3.1：`m_lat = a·m_phys` 才是要的；`m_lat` 常数 ⇒ `m_phys∝1/a`）。**要的模量是 `m_lat ∝ aΛ → 0`，不是常数。**

**(ii) 窗口错位（台账自己钉死的）。** M01-CHECKLIST C.2（`:93–98`）逐字：该 `[T]` **"限定 只在固定 β、β<β₁ 窗内；不是 cutoff-一致"**（`:96`）；
`D.3`（`:124`）："β<0.0736 是粗格点 … ⇒ **不是 a→0**"。`FROZEN-POSITION:19` 的 `A.7` 同条限定。
⇒ 它连"跨 β"都没做，谈不上 `β→∞`。

**(iii) 离流。** G06 的 `a`-扫描是**固定 `u=1/96`（=`β`=1/12）** 的，即 `β(a)` 没动
⇒ 扫的是**代数恒等式**，不是沿 RG 轨迹。物理轨迹上 `ū=ū(β(a))` 随 `a` 变 ⇒ `δ_A·a` 不是流不变量。

**(iv) 数值巧合陷阱（必须写进台账，否则会被误用）。** `δ_A·a = 0.5686` 与 `aΛ_lat(1/48) = 0.5700` 只差 **0.24%**
（本轮 py-3.12 核）⇒ 有人会宣称"`δ_A·a` 就是 `aΛ`，模量=1"。杀掉它：

| `β_A` | `aΛ_lat`（A04 §3.1） | `δ_A·a/(aΛ_lat)` |
|---|---|---|
| 1/48 | 0.5700 | **0.9976** ← 巧合点 |
| 0.1 | 0.4708 | 1.208 |
| 1 | 7.690e−5 | 7.394e3 |
| 2.5 | 1.096e−11 | **5.188e10** |

⇒ "在一个 β 上恰好 ≈1"**不是模量**：(S2) 要求的是**同一个数对所有 β**。

**酸测（决定性的那一刀）**：`δ_A·a = 0.5686` 与自由无质量场的 `m_lat = 2π/8 = 0.7854` 同量级（比 0.724）
且同形（"常数"）。**常数性判据被无隙理论满足 ⇒ 常数性不能当 `a→0` 的证书**（§1.3）`[T]+[V]`。

**⇒ (c) 判**：`δ_A·a` 是**纯数**`[T]`，但它**不是** RG 稳定模量；"认它就是模量"是把两件事叠在一起：
"纯数性 `[T]`" + "正性与流不变性（= T4）`[NG]`"。**合取之后是 `[NG]`，不是 `[T]`。**
