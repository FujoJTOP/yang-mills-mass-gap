## §0 判词（五行，逐字）

1. **合成 `[T]`（本文 NS2-0）**：②（下界）＋③（G1-协变）**不可能由单个泛函满足而不产生第三个对象**。一行代数：
   `F(τ_aν)=F(ν)+a` 且 `F ≤ s₁` `⇒` `G := s₁ − F` 满足 `G ≥ 0` 且 `G(τ_aν)=G(ν)`（形状），故 `F = s₁ − G`。
   ⇒ **第 6 种不是"量"，是"量 + 缺陷 + 恒等式"三元组**。这就是 7 条合成的形态。`[T]`
2. **一处读法必须钉死**：③ 的"平移"只能是 **G1（能量轴 `τ_a`）**；读成 **G2（空间平移 `U(x)`）** 则 `inf supp` 本身 G2-不变（`B05-DUAL.md:76–83`）⇒ ③ 与 ② 直接矛盾、判 (b)。**矛盾是读法造成的，不是数学造成的。** `[T]`
3. **(a) 成立**：规格可写成一句可执行的话（§1.3 的框 `NS2-S`）。**这是本路唯一可能的产出**，且它把"造一个量"整体换成"证一条分解式"。`[T]`/`[J]`
4. **(b) 不触发**：7 条不互相矛盾。矛盾只在两种误读下出现：③ 读成 G2（见 2.）；或把 ② 读成"`F` 就是目标"（那违反 ①，但那是把结论当前提）。`[J]`

## §1 合成定理 NS2-0（`[T]`）—— 7 条为什么只能合成出"分解"，不能合成出"量"

### 1.1 设置与窗口（`AGENTS §2.1`：先写适用范围）

在**测度层**工作：`ν = ν_w` 为 `O` 的谱测度（`w_n = |⟨Ω|O|n⟩|²`，`ATOM2.md:41–45` 的口径），
```
s₁ := inf supp ν_w  ,   τ_a ν := ν(· − a)   （能量轴平移，G1）
```
**窗口 1（必带）**：本文的定理全部在**测度类** `{ν ≥ 0, 矩有限}` 上成立（`B05-DUAL.md:61` 明写 60+ 轮的每一条实际只用了这一层）。
**窗口 2（必带）**：`s₁ = m` 这一步是**物理前提**，不是定理——`B05-DUAL.md:159` 逐字把"位置"与 `m₁` 列在同格、并标"**等于**目标（无损）⇒ 循环"。本文不重证它，只把它当条件。

### 1.2 定理与两行证明

**定理 NS2-0 `[T]`.** 设泛函 `F` 定义在 `{ν}` 的 `τ`-轨道上，且
```
(i) 协变（G1）：   F(τ_aν) = F(ν) + a          ∀a ≥ 0
(ii) 下侧：        F(ν) ≤ s₁(ν)                ∀ν
```
则 `G := s₁ − F` 满足 `G(τ_aν) = G(ν)`（即 `G` 是 **G1-不变 = 形状**泛函）且 `G ≥ 0`；等价地
```
        F = s₁ − G ,        G ≥ 0 且 G1-不变 .
```
*证.* `s₁(τ_aν) = a + s₁(ν)`（`inf supp` 协变，`B05-DUAL.md:80`）与 (i) 相减即得 `G(τ_aν)=G(ν)`；(ii) 即 `G ≥ 0`。∎

**推论 NS2-1 `[T]`（"单项不可能"）.** 若 `F` 同时满足 ②③，则 `F` 的**全部信息量** = `s₁` 的信息量减去一个形状量。
故「协变 + 下侧」这一格**在单项层面是空的**：它要么退化成"位置本身"（`G≡0`，撞 ③ 的循环），要么必须交出 `G`。

**推论 NS2-2 `[J]`（"形状项吸收 M6 槽"）.** M6 上 `s₁ = ω = 1` 而 `m₆ = min(ω, ½(2π/L)²) → 0`（`ATOM2.md:44`）。
取 `F(M6) = 0`，则 `G(M6) = 1 ≠ 0`。⇒ **四模型的 M6 槽由 `G` 承担，不由 `F` 承担** ⇒ `F` **不过 4/4**
⇒ **N09-1 的前提（"过四模型"）不成立**（`Q03-TARGET.md:87` 逐字：它的前提就是它的适用域）⇒ `F ≠ f(m)` **被允许**。
这是 ① 与 ②③ 能同时成立的**唯一通道**：不是"绕过" N09-1，而是**站到它的域外**。

### 1.3 那"一句"（可执行规格；本路唯一产出）

```
NS2-S  求一对可算泛函 (F, G)，使
  (1) 恒等式（精确，不是不等式）：   s₁ = F + G ,   s₁ := inf supp ν_w
  (2) F 可算且不经谱：               F = F(S_W, β, L, a)，不用 ν / E₀ / E₂ / 隔离窗 ρ
  (3) 协变分工（G1）：               F(τ_aν) = F(ν) + a ;   G(τ_aν) = G(ν)
  (4) G ≥ 0 可算，且 G 不是 H1 / Var / G″ / f₁² 的任何换名
  (5) 签名故意不过 M6 槽：           F(M6) = 0 ,  G(M6) = ω ≠ 0 = m₆   ⇒ N09-1 不适用
  (6) 结论：F 的 (L,a)-一致正下界  ⇒  s₁ ≥ c₀   （因 G ≥ 0；G 只在 (4) 的排除面上不许出现）
```
**逐条对号（不许含糊）**：(1)(2)←②⑦ · (3)←③ · (4)←④⑤⑥⑦ · (5)←① · (6)←②。
**注意 (6) 的方向**：因为 `G ≥ 0`，"`F ≥ c₀`" 直接给 "`s₁ ≥ c₀`"——**这就是全部内容**；若 (4) 无法满足，`G` 只能从 `H1/Var/G″/f₁²` 里取，规格立刻塌回五类（§6 自毁条款 C1）。

## §4 判死线逐字


## §6 限定与自毁条件（本文可能错在哪）

- **L1（窗口）**：NS2-0 是**测度层**定理（`{ν≥0,矩有限}`）。升到"KL 测度 ∩ 物理可实现"层是 `[C]`；`s₁ = m` 是物理前提，本文不重证（`B05-DUAL.md:159`）。
- **L2（逐算符）**：位置**逐算符**成立（`atom2`：2D 上 `O=¼trF²` 给 `ν≡0`，`O=½trU` 给 `f₁²=1` 精确）⇒ **任何 NS2-S 的实例必须带 `O`**，不许跨算符搬运（`ATOM2.md:43`、`LOOP-RUNBOOK.md:14259–14307`）。
- **L3（载体）**：不许把 `G″` 当 `s₁` 的替身（`L2C-SD.md:202`：两个槽，类型不可比）。
- **C1（自毁）**：若 P1–P3 表明"唯一可行的 `G` 是 `H1/Var/G″/f₁²` 的换名" ⇒ **NS2-S 塌回五类** ⇒ 本路改判 **(b)**（那时才允许写"结构性 no-go"）。
- **C2（自毁）**：若 `F` 的可算性只能在 `ν` 上落地（即 P1 的所有候选都退化成"先求谱"）⇒ ② 的循环性未被打破 ⇒ **(c)** 仍成立但规格无执行面 ⇒ 本路停。
- **诚实线**：本文**没有一个新数字**、**没有一条新数值证据**；§1 的两条推论是代数，§3 是盘查（7 类），不是穷尽性证明。

## §7 一句话

**7 条不许任何"一个量"通过；它们只放行"位置 = 协变可算项 + 非负形状缺陷"这条精确分解（`NS2-S`）——
规格可写、无矛盾、但该三元组在先例里没有原型（Lyapunov 放弃下侧，SSF 放弃"非目标"，指标/拓扑撞 `b04`，等周撞 `tb02`），
所以第 6 种若存在，它不会长得像一个量，而会长的像一条分解恒等式：那是一个还没被造的对象。No QED；Clay 0%。**
