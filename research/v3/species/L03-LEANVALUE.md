## 3 · 用法 B：验有限 `L` 的部分 —— 判 **`[NG]`（主体）+ `[C]`（玩具）**

### 3.1 逐字为什么不行

1. **对象无穷维。** `T` 在 `L=2` 上作用在 `L²(SU(2)^{24})`（`D02-DIRECT`）⇒ 没有"矩阵"，`m(L)` 是**无界算子**谱下确界。Mathlib **无**无界自伴算子谱理论（§1 #8）⇒ 「`m(L)` 是 `T` 的谱下确界」这句话**在 Lean 里写不出来**（只能写成"存在一个实数 `m` 使 …"，那已把内容弄丢）。
2. **能验的只有"截断 + 尾界"：**
   ```
   给定截断 P_J（字符/表示截到 j≤J）：
     (i)  P_J T P_J 是有限维（可验：矩阵、特征多项式、`Matrix.spectrum` 级别）
     (ii) 尾界  ‖(1−P_J)T P_J‖ ≤ ε  ⇒  dist(spec T, spec_trunc) ≤ ε
   ```
   **(ii) 就是缺的物理**（等价于 KP 型对易衰减估计）。Lean 不供给 (ii)；把它当**假设**写进定理，定理就变成"假设搬运已完成"。**⇒ 恰好是同一堵墙换了语言。**
3. **`torelon` 警告（`D03`）**：2D YM 上 `m(L)/L = 0.4038776782` 在 `L=2..5` **逐位恒定** ⇒ `m(L)` 是 torelon 而非胶球。任何"验 `m₂²−m₀²>0`"的有限维截断都必先过这条诊断，否则验的是一个**没有搬运意义**的量。这一条**机器可验**（§5 D-5），但它验的是**诊断**，不是 `inf_L`。

### 3.2 判

- **主体 `[NG]`**：给不出 `inf_L(m₂²−m₀²)>0` 的任何内容；给不出 `L=2` 的真谱。
- **玩具 `[C]`**：在**有限维可解模型**（单 plaquette、`osc⊗free` M6、`L=1` 的字符截断）上，「截断 + 尾界 ⇒ 谱逼近」的**方法论**可以形式化。价值 = 把"这个方法在数学上成立"钉死，防止以后有人拿截断当结论。**工作量 1–2 轮，收益仅方法学。**

### 5.1 D-1 的逐字链条与诚实边界

**链条（三段，只有后两段是 Lean 的活）：**

- **诚实边界（不许省）**：`C̄ ≤ 3` **弱于** `c02` 的 `C̄ ≤ e`，也**弱于** `c07` 的 `1.054`。**它不改进任何数学常数；它只说明**：即使把 `C̄` 的可用上界放宽 2.85×（`e → 3`），窗**仍然开着**（余量 1.1772×，距门槛 `C̄*=3.5316` 还有 15%）。**⇒ 结论对 `C̄` 的精确值不敏感；`C̄ ∈ [2.2209, 3]` 内的任何值都够。** 这条**可引、可写进总册**，且**不依赖任何手算**。
