## §3 · 判死线逐条（用户 (a)/(b)/(c)）

### (a) `Δ₀² < 0` ⇒ `Δ₀ > 0` 不是正确靶 —— **实质成立，但机制要改写**

- 2D 上 `Δ₀² = Δ_dyn/a²`，`Δ_dyn` 在 `φ ∈ (π/4, 3π/4)` 上**确为负**（`t=5`：`φ=π/2` 给 `−1.09e−3`），⇒ 那些点上 `Δ₀` **是虚的**，`Δ₀ > 0` 无定义。**判死线在字面上被击中。**

- **两条合起来 = 判死**：`Δ₀ > 0` 作为"有隙的必要条件/可测靶"，在 2D 上（有隙！）既不成立为正、又不成立为定号。⇒ **`Δ₀ > 0` 只对 4D 的那个特定粗模有意义，不是四模型不变量。**
- **替代靶（要求：2D `>0`、M6 `=0`、自由场 `=0`）**：
  ```
  m_lat := a·m_phys      （无量纲谱隙；等价 λ₁ = 1 − e^{−a m}，即转移算子的 Poincaré 常数）
      2D YM :  a·3g²/8 > 0        （与 A 无关）

      自由场:  0                  （零阈连续谱）
      单 plaquette: 无定义（无 transfer 方向）⇒ 真空，同 T03 M1
  ```
  `[T]`；这是"换成整体对象（谱下界/转移算子 Poincaré）"那条（`T03 §4` 末段、`H1A §4.4` 同判），**不是** `G″` 家族的任何一点曲率。

### (b) "`Δ₀` 无定义（`δ` 只对 4D）" —— **不触发**

`δ := a²Δ₀² + W_full` 的每一项在 2D 上都有定义（`W_full = 2/sin²φ`、`Δ_dyn = −∂²log K_t`，都是有限实数），`Δ₀² = Δ_dyn/a² ∈ ℝ` 逐点有定义。**没有"只对 4D 成立"的缺口**；问题不在定义域，在**符号与体积标度**。
