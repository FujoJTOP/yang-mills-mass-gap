### §1.1 两难（把 `rv-2` 的两条路都堵死）`[T]`

`RV-2 §2` 断言 LHS 的 `δ_C` 与 RHS 的 `∮dyδ⁴` **"同一支撑、同型"**。二者只能有一个是真的：

⇒ **判**：候选一是**关于接触项 UV 身份的**最自然读法（它是周长/自能反项），但它给出的 `μ` 是**反项**，在与 `σ` 的关系里**不是**物理质量；而且纯 YM 无 dynamical quark，周长项**必须减掉**、不可解释为谱。⇒ **候选一与候选四不是两条路，是同一条**（见 §5）。**`μ²` 不是质量。**

## §5 候选四：格点自然值 `μ² = 1/a²` —— **成立且被逼出**，然后 **物理不相容** ⇒ 打回

### §5.1 它是被逼出的，不是选项 `[T]`

由 §1：`μ² = 1/ε²`，而参数里**唯一的长度**是调节子。格点上唯一长度是 `a` ⇒ `ε = a` ⇒ `μ² = 1/a²`。⇒ `σ = 2g²N/a²`。`rv-2` 的 `σa² = 2g²N`（`a=1`）**逐字就是这个**。⇒ **`rv-2` 的记账里有一个未标的 `a`。**

### §5.2 不相容写成不等式 `[T]`

记一圈 `t := 1/(2b₀g²) = 12π²β/(11N²)`，`aΛ = t^{51/121}e^{−t}`（`C1-SLOPE-EQUIV §4`，`[T]`，`b₀ = 11N/(48π²)`，`A7 §1` 已三重核）。

- **候选四给**：`σa² = 2g²N = N/(b₀ t)` —— 只随 `t` **幂律**衰减。
- **物理要求**（`σ` 固定、`Λ` 由透射定）：`σa² = (σ/Λ²)(aΛ)² = (σ/Λ²)·t^{102/121}e^{−2t}` —— **指数**衰减。

```
比  (σa²)|_{ε=a} / (σa²)|_phys  ∝  t^{−223/121} e^{+2t}  ──→  ∞
```

⇒ 二者对 `t` 的依赖**不同型**（幂律 vs 指数），不存在能同时满足的 `t` 区间；等价地，`t > ½` 后 `2g²N > (aΛ)²` 恒成立。

**最锐的一条（可核判据，纯指数）：**

```
固定物理 σ ⇒ σa² = (σ/Λ²)(aΛ)² ⇒  d ln(σa²)/d ln a = 2   （精确，σ/Λ² 与 a 无关）
候选四     ⇒ σa² = 2g²N(a)      ⇒  d ln(σa²)/d ln a = 1/t ──→ 0
```

⇒ **指数 `2` vs `1/t`**：这是无数字、可核、且只用量纲+AF 的死刑判据。`[T]`

### §5.3 `2g²N` 里的 `g` 必须在哪个标度（lead 的硬问） `[C]`

`σ = 2g²N/ε²` 里 `μ² = 1/ε²` 是**在 `1/ε` 处定义的**接触系数；`g` 必须与它**同标度**，否则是把一个在 `1/ε` 归一的对象乘上一个在别处的耦合（`[M]` 级错误）。

- **`ε = a`**：`g = g(1/a)` **随 `a` 跑动** ⇒ `σa² = 2g²N(1/a)` 随 `a` 跑 ⇒ `σ` 不是常数 ⇒ 与"`σ` 是物理量"矛盾。**这就是"物理错"的确切所在**：不是"`σa²` 无量纲所以错"（那一步是对的），而是**跑动**。
- **`ε = 1/Λ`**：`g = g(Λ)`，`a`-无关 ⇒ `σ/Λ² = 2g²N(Λ)` 是 `a`-无关的纯数 ⇒ `p = 1` 形状**站得住**。但字面的 `g(Λ)` 落在 **Landau 极点**（`1/g²(Λ)=0`）⇒ 必须取 `g(cΛ)`、`c≠1`，此时它是**方案内可算的纯数** `N/(b₀ ln c)`（§5.4）。`[T]+[C]`
- **第三读法 `ε = 1/ξ`（`ξ` = 弦厚 `~1/√σ`）**：方程变成齐次的（`σ` 两边消掉），只留下 `2g²N·(ε√σ)² = 1` 这一个**比值**条件 ⇒ `σ` 的**幅度仍然自由** ⇒ `[NG]` 不变。**所以 `ξ` 读法不救场。** `[T]`

### §5.4 `g` 的标度：圈式答案 `[C]`（本文件对 lead 三问的直接回答）

一圈流（与 `C1-SLOPE-EQUIV §4` 同口径）：`1/g²(μ) = 2b₀ ln(μ/Λ)`。**要求 `g` 与 `μ² = 1/ε²` 同标度**（同一标度上的系数与耦合才有一致的 RG，`[M]`），于是：

```
ε = cΛ  (c = O(1) 方案/接触几何常数)
⇒ σ/Λ² = 2g²N(cΛ) = 2N/(2b₀ ln c) = N/(b₀ ln c)     纯数，a-无关  ✓ p=1 站得住   [C]
```

```
ε = a   ⇒ g = g(1/a)、t := ln(1/(aΛ))  ⇒ σ/Λ² = 2g²N(1/a) = N/(b₀ t) → 0
⇒ σ/Λ² 随 a 跑（像 1/ln），不是常数  ⇒ p=1 垮            [T]
```

**三条判读**：
1. **不能取 `c = 1`**：`ln c = 0` 是一圈 Landau 极点 ⇒ 接触标度必须离 `Λ` 一个 `O(1)` 因子；这正是 `MU-1 §7(3)` 说的"`O(1)` 自由度可吸收进 `g²` 重定义"的**同一件事的另一面**。
2. **`σ/Λ² = N/(b₀ ln c)` 是"方案内可算的纯数"，不是 `(★)` 的定理**：`c` 不被 `(★)` 定 ⇒ `[M]`；幂次（`∝Λ²`）与符号（`>0`）是硬的（`[T]`/`[C]`），系数不是。
3. **`g(1/a)` 与 `g(cΛ)` 是全部差别的所在**：候选四与候选一的"物理错"不是量纲错（`σa²` 无量纲，那步对），而是**把跑动耦合当成冻结常数**。⇒ lead 的三问答案收成一句：**`g` 必须在 `∝Λ` 的标度。**

**⇒ 判：`1/a²` 结构性成立但物理不相容（§5.2）；`1/Λ²` 是唯一与 `p=1` 相容的（`σ/Λ² = N/(b₀ ln c)`），但 `c` 不被定 ⇒ 是**重整化条件**，不是可算数（§5.4）；`1/ξ²` 让 `σ` 从方程里掉出（两边消），只留 `2g²N·(ε√σ)² = 1` 一个比值 ⇒ 幅度仍自由 ⇒ `[NG]` 不变。**

## §6 结论：什么条件固定 `μ²`

**(0) 前提确认（题面那句"若它发散或处方依赖 ⇒ 它是重整化常数"）。** 现在有五条独立取值：`1/a²`（格点）、`0`（维数正规化 / 纯 ζ）、`(4π)^{−3/2}/ε²`（点分裂）、`Λ²/(4π)`（热核）、`∝σ`（本文件 `(c)` 的循环解）。**四个处方四个不同的 `L^{−2}` 值 ⇒ 处方依赖成立 ⇒ `μ²` 确实是重整化常数**（`MU-1 §0` 的同一结论，本文件加的是"没有一个条件能把它定住"）。`[T]+[M]`

**(1) `(★)` 内部：没有。** `(★)` 无量纲、无标度（`RV-1 §6(2)` 已证：齐次 + 标度协变 ⇒ 解空间是向量空间 ⇒ 不含量纲）。接触项的**数值**只能来自调节子（`1/ε²`），那是 UV，不是动力学。`[T]`

**(2) 物理上唯一自洽的固定方式：减除条件（= 一个方案）。** 即要求 `μ²` 的 `∝1/ε²` 部分被扣掉、剩下 `∝Λ²` 的部分；等价于给 `σ` 在参考尺度上的归一。**这条条件的数学位置正是候选二**（`μ² := σ/(2g²N)|_scheme`）⇒ 对"推导 `σ`"而言**循环** ⇒ `[NG]`。`[M]+[NG]`

**(3) 可交付的正面残余（一条可核判据，`[V]`，无数字）：**

```
σ = 2g²N μ²   ⇔   格点上量两个数：接触项 (a²μ²_lat) 与 σa²
预言：a²μ²_lat = σa²/(2g²N)       [M]-依赖：同一方案、同一 a
判别：a²μ²_lat −→ 1（候选四，bare）   还是   −→ (aΛ)²·(σ/Λ²)/(2g²N)（renormalized，指数小）
```

⇒ 这是一条**能用已有格点量判生死**的检验：接触项在格点单位下是 `O(1)` 还是**指数小**。两者差一个 `e^{−2t}`，不可能混淆。`[V]`

**旁注**：`w7/mu4_lattice.log` 已经把这个检验的**一半**做了（它测的是 `σa²` 一侧的幂次，`R ~ L^{+0.70}`），结论与本文件 §5.2 同向；缺的另一半是**直接测接触项** `K = ∮dy_νδ⁴(x−y)|_{x=y}`（该 log §1 里 `K_A` 在 `L=4,6,8` 全为 `1.0000`，`K_B = a^{−3}`，`K_C = a^{−2}` —— 三个归一被打出来，但**没有一个是"物理"选择**，这正是 §1 的两难）。

## §7 `σ = 2g²N·m²` 与 `σ = m²` 差什么（题面 (a) 的那一问）

即使候选一成立（它不成立，§2），`σ = 2g²N m²` 与物理图象 `σ = m²` 的差是：

| 因子 | 来源 | 性质 |
|---|---|---|
| `2` | `½ε_{μν}` 的归一（`1/(½)`） | **纯约定**，无物理 |
| `g²N = λ(μ)` | `(★)` 的 RHS 系数；4D 下**跑动**、**方案依赖** | **物理内容在这里** |

⇒ **意味着一件事**：物理比值 `σ/m²` 必须是 **RG-不变**的（`σ`、`m` 都是物理谱量）。而 `2λ(μ)` 跑动 ⇒ **若 `m` 是物理质量，这条关系只能是方案依赖的记账式，不能是恒等式**。⇒ 反过来，正是 `2g²N` 这个跑动因子把 `μ²` 从"质量"**降格**为"重整化常数"：它占 `(质量)²` 的**量纲槽**，但不是谱里的质量。`[T]+[J]`

⇒ 若哪天格点量到 `σ/m²` 是**普适 `O(1)` 常数**，则 `μ²` 不是这个对象，本文件的 `μ²` 必须与 `m` 分开命名。
