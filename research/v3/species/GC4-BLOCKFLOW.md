固定 `(L,a,β)`、`T⁴_L`、块因子 `b=2`（要求 `b^k | L`，`K := log_b L`）。细格 `Λ`，粗格 `Λ' = bΛ`。链接 `U_l ∈ SU(N)`。

**(B-1) 块内平均 —— 用"共同端点路径族"，不用平行移动。** 对粗链接 `(x,μ)`（`x ∈ Λ'`）取
```
𝒫_μ(x) := { 最短格路径 γ : x → x + b e_μ ，γ 完全落在块 [x, x+b e_μ] 内 } ，
A_μ(x) := (1/|𝒫_μ(x)|) Σ_{γ∈𝒫_μ} Π_{l∈γ} U_l   ∈ M_N(ℂ)          (B-1)
```
**关键事实（一举消掉"块间怎么传规范"）**：`𝒫_μ(x)` 的所有路径**共享两个端点**，故对任意细规范变换 `s`，
```
Π_{l∈γ} U_l  ↦  s(x) · (Π_{l∈γ} U_l) · s(x+b e_μ)†      对一切 γ 同时成立
⇒ A_μ(x) ↦ s(x) A_μ(x) s(x+b e_μ)† .                        (B-2)
```
⇒ **块内平均不需要平行移动、不需要把不同点的 link 搬到共同基点**：端点一致就自动拿到统一的两侧因子。这就是"块内 link 怎么平均"的老大难的正解。

**(B-3) 粗链接 = `SU(N)` 的迹最大投影（"极分解 + 行列式修正"）。** 令 `A = U Σ W†`（SVD，`Σ=diag(σ_1≥…≥σ_N≥0)`），`d := det(UW†) = e^{iθ}`，
```
π_SU(A) := U · diag(1,…,1, d̄) · W† ,      d̄ = conj(d)               (B-3)
U'_μ(x) := π_SU( A_μ(x) ) ∈ SU(N)
```

**(B-4) 三条已核性质**（本轮机检，`py -3.12`，确定性 seed，见 §5）：

| 性质 | 内容 | 数值 |
|---|---|---|
| **等变** | `π_SU(s A t) = s π_SU(A) t` 对一切 `s,t ∈ SU(N)`（500 组 `(s,t,A)`，`N=3`） | `max‖·‖ = 1.33e−14` `[E]` |
| **最优** | `Re tr(π_SU(A)† A) = Σσ_i − σ_N(1−cos θ)`；`U(N)` 上界是 `Σσ_i`（`argmax = UW†`）⇒ `SU(N)` 的代价**显式** | 恒等式残差 `8.0e−15` `[E]`；2000 次随机 SU(3) 切向步**0 次**超过它 `[E]` |
| **秩亏仍单值** | `A` 的核方向相位被 `det=1` 钉住 ⇒ `σ_N=0` 处**无多值**、连续（`δ∈{1e−2,1e−8,0}`、三个 `φ`，`A=diag(1,1,δe^{iφ})`） | `max‖π_SU − I‖ = 2.22e−16` `[E]` |

**⇒ 规范侧结论**：`(B-1)+(B-3)` 是**规范等变**的确定性映射，粗测度 `μ' := (P_b)_*μ` 良定义，**不需要固定规范**。与 `glue-c-gauge-group/STATUS.md:10` 的 GL6 `[T]`（orbit-sum identity、无需 section）**独立一致**。这与 `glue-b-blocking/REPORT.md:127` 的分工吻合：等变（GL6）与反射协变（GL2a，(B1)）是**两个不同群**上的条件，互不蕴含。

## §3 · 谱流陈述与 `I2`/`H1` 的关系

### §3.1 设定（固定 `L,a,β`）

嵌套块代数 `𝒜_0 = L²(μ_{L,a,β}) ⊃ 𝒜_1 ⊃ … ⊃ 𝒜_K = {常数}`（`k` 级 = 块因子 `b^k`），`E_k` 为到 `𝒜_k` 的正交投影，`T = T_f` 为细转移矩阵（`0 ≤ T ≤ 1`、`T1 = 1`）。定义

```
T_k := ( E_k T^{b^k} E_k ) |_{𝒜_k} ,        λ_1(T_k) = 1 ,
Δ_k := − (1/(b^k a)) · log λ_2(T_k)           （k=K 时约定 +∞，因 𝒜_K 一维）
```

**机器的两条候选陈述（任务 §3 要的那两条）：**

```
(SF-MONO-点)  ∀k∈[0,K]:  Δ_k ≥ δ > 0          ← 只要求"每一级都有隙"
(SF-MONO-链)  Δ_0 ≤ Δ_1 ≤ … ≤ Δ_K              ← 真正的"流"（相邻级比较）
(SF-FLOW)   沿任一连续路径 s ↦ T(s) ⊂ {自伴, 0≤T≤1, T1=1}（T(0)=T_0, T(K)=T_K），
            谱流 SF_ε := #{λ_s 穿越 e^{−ε b^k a}}_signed ；断言 SF_ε = 0 ∀ε>0  ← 流版
```
（把 `(SF-MONO)` 拆成"点"与"链"两条是必要的：机器要的是**从粗端反推细端**，那是**链的反向**；而下面 `(BF-1)` 给的是**点**的对细级比较。二者强度不同，混写会掩盖真正缺的那一条。）

### §3.2 BF-1：单调性存在，`[T]`，**方向朝外**

```
λ_2(T_k) ≤ λ_2(T^{b^k}) = λ_2(T)^{b^k}      （Cauchy 交错 + T≥0 幂次）
⇒ Δ_k = −(1/(b^k a)) log λ_2(T_k) ≥ −(1/a) log λ_2(T) = Δ_0 .        (BF-1)
```
`[T]`。证明两行（`glue-b-blocking/REPORT.md:194–204` 的同一变分论证，`b → b^k`）。

**`(BF-1)` 给的是 `Δ_k ≥ Δ_0`（每一级对细级），不是 `(SF-MONO-链)`。** 相邻级 `Δ_k` vs `Δ_{k−1}` 是两个**不同幂**的压缩（`T^{b^k}` vs `T^{b^{k−1}}`），min-max 对它们给不出相邻不等式 —— 这一条我**既没证明也没找到反例**，记 `[M]`。**⇒ 机器的"流"（链）本身就没有定理；有定理的只有"每级 ≥ 细级"。**

**而机器要的恰好是链的反向**：由粗端 `Δ_K ≥ δ` 反推 `Δ_0 ≥ δ`，即需要 `Δ_0 ≥ Δ_K`。`(BF-1)` 给的是**相反**的 `Δ_K ≥ Δ_0`；`glue-b-blocking/REPORT.md:212–214` 的 `Δ_c=+∞` 例使 `Δ_K − Δ_0` **无界** ⇒ `Δ_0 ≥ Δ_K` 是**假**的 `[T]`。**这是 `glue-b-blocking/STATUS.md:38` 的原句在尺度方向上的逐字重放。**

> ⇒ **尺度方向的两条可用断言里，一条真而无用（`Δ_k ≥ Δ_0`），一条假（`Δ_0 ≥ Δ_K`），第三条（链）没有定理。没有第四种。**

### §3.3 BF-2：谱流版不是新不变量，**它是计数函数的一次差** `[T]`

把 `ε` 按各自尺度归一（每级在自己的 `b^k a` 单位下读数），记
```
n_k(ε) := #{ λ ∈ σ(T_k) : λ < e^{−ε b^k a} } = #{ i : Δ_i^{(k)} > ε } .      （数"衰减率 > ε"的模）
```
则 `n_K(ε) = 0`（`𝒜_K` 一维、`T_K = 1`）。谱流是计数函数的望远镜和：
```
SF_total(ε) = n_K(ε) − n_0(ε) = − n_0(ε) .                            (BF-2)
```
`[T]`（每一步只是"过零 ⇔ 计数变化"的定义展开；端点平凡）。**⇒ 整条块流的"总谱流"逐字等于（负的）细尺度计数函数 `n_0(ε)`。** 于是：

- **(SF-FLOW) 的"`SF_ε = 0`"** ⇔ **`n_0(ε) = 0`** ⇔ **`Δ_0 ≤ ε`** —— **方向是反的**。机器要的是 `Δ_0 ≥ δ`，它逐字等于
  ```
  Δ_0 ≥ δ   ⟺   n_0(ε) = 0  ∀ ε < δ   ⟺   SF_ε = 0  ∀ ε < δ .
  ```
  ⇒ **整个内容都压在 `∀ε<δ` 这个量词上，值本身（"流 = 0"）一个字也不含。** 这与 `MACHINE-SIEVE.md:66` 对 A1 的判法同型（逐字："它的内容**在量词里，不在值里**"）。故这是 `D04-ODE.md:259` P3 规则的同一句话（转引：`GW1-FLOW-TARGET.md:38` 逐字"任何以 `F` 的逐点非零为分母的微分不等式，都是目标的改写，不是弱化"），也命中 `MACHINE-SIEVE.md:23` 的 **F2（核心包络不得是恒等式）**。
