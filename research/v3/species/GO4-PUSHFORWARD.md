## §1 构造（写死，不留自由度）

### 1.1 三件东西

**(i) 细格点测度 `μ`。** 两种取法，用途不同，但**结构相同**：

- **物理取法**：`μ = μ_β` = 4D 纯 `SU(N)` Wilson 测度，`dμ_β = Z^{-1}e^{−S_W[U]}∏_l dU_l`，`S_W = βΣ_p(1 − (1/N)Re tr U_p)`。RP `[T]`（Osterwalder–Seiler 1978 / Lüscher 1977；仓内 `B01-RP.md:11–12,26–30` 的 R1–R4，设定逐字是"Wilson、任意紧群、任意 `β≥0`"）。
- **算 `k₀` 的取法**：`μ = ` Gaussian 极限（`β→∞` 的二次型，或等价地"把 `S_W` 展开到二次项"）。理由见 §3.1：**`k₀^{shell}` 按定义是自由符号的 `a`-幂**（`GL2:153`；`GK3:249`），所以二次型就是它的**定义域**，不是近似。

**(ii) 块核 `Π_τ`。** `τ = (b, k)`：块尺度 `b`（每方向 `b` 个细格点，最大 `b=2` 本文件主用）与**权重函数** `k: aℤ⁴ → ℝ`，

```
V(y) = Σ_{x} k(x − y) A(x) ,      y ∈ b·aℤ⁴ ,  A = log U（或 A = 规范势）
```

三条硬要求：
1. **归一化** `k̂(0) = Σ_x k(x) = 1`（否则粗场只是被重标度，`h_τ ≈ p'²` 这一步不成立）；
2. **粗平移协变**：`k` 是细格点上的**任意**函数（这就是"所有线性、平移协变块核"的全体，无额外对称性约束）；
3. **`Θ`-协变**：`Π ∘ Θ_f = Θ_c ∘ Π`。**这一条不是装饰**：它强制"反射面 = 块边界"，`[F]` 证明违反它 RP 就**失败**（§2.3）。

非阿贝尔情形下 `V` 要写成群上的确定型映射（块平均 / 块乘积 / 带 `exp∘log` 的 smearing）；**树级符号只看它的线性化**，故 §3 的全部结论与"选哪种群上写法"无关（`[T]`）。

**(iii) 推前作用量。**

```
ν_τ := (Π_τ)_* μ ,        S_τ(V) := −log (dν_τ/dV)(V)                     (1.1)

（Gaussian 情形下显式）  Ĉ_f(q) = 1/Ĥ(q) ,   Ĉ_c := P C_f P^T ,
                        Ĉ_c(p') = Σ_{n∈{0,1}⁴} |k̂(θ' − nπ)|² Ĉ_f(θ' − nπ)      (1.2)
                        h_τ(p') := 1/Ĉ_c(p')        （粗格点上的卷积算子之符号）  (1.3)
```

其中 `θ' = p' a ∈ [−π/b, π/b]⁴`（`b=2` 时 `[−π/2,π/2]⁴`），`Ĥ(θ) = 4Σ_μsin²(θ_μ/2)`（Wilson 自由符号；Feynman/横模规范下就是 `1/Ĥ`）。**(1.2) 的 alias 结构是本文件一切结论的唯一来源**，两行推导：

`C_c(D) = ∫_{BZ_f}|k̂(q)|²e^{iqD}Ĉ_f(q)dq`（`D∈b aℤ⁴`）⇒ 对粗格点做 Fourier 变换，用 Poisson 求和 `Σ_{D∈b aℤ⁴}e^{i(q−p')D} ∝ Σ_m δ(q − p' − mπ/a)`，得 (1.2)。**无近似。**

### 1.2 `μ` 取哪一个、为什么这不影响判词

| `μ` | `Δ_cont` | `k₀^{shell}(S_τ)` | 用途 |

## §2 RP：按构造成立，且"严格"这件事要说清

### 2.1 命题 PF（引 `GL1:85–90`，两行，`[T]`）

### 3.1 先把"算的是什么"钉死（否则下面会被读反）

`k₀^{shell}` 的定义（`GL2:153`）：最大 `k` 使 `|h(p) − |p|²| ≤ C(aΛ)^k|p|²`，`∀|ap| ≤ Λ`，**方向一致**；`h` = 作用量的**自由符号**。三个必须明写的限定：

1. **`h` 是二次型**。作用量的二次部分 = `S_τ` 在 `V = 0` 的 Hessian。Gaussian 时它就等于 `1/Ĉ_c`（(1.3)）；`β<∞` 时 Hessian = 树级 + 圈，**树级部分**逐字等于 Gaussian 的（因为 `S_W` 的二次项 + 核完全决定它）。⇒ **本文件算的是树级**，这是 `k₀` 这个量的定义域（`GL1:218–220` 的 D1/D2；`GK3:249` 的乘子消费的是它）。`β<∞` 的圈修正属于"1-loop 伪影"，与 `k₀` 是**另一个问题**（HP1997 的 `not exactly 1-loop perfect`，`GL1:330`）。
2. **`Λ` 是小动量窗口**。`|ap| ≤ Λ ≪ 1`（Symanzik 展开的窗口）。把 `Λ` 推到 BZ 边缘会让 `k₀=0` 对所有格点作用量成立（边缘上人人差 `O(1)`），那样这个量就没内容了。**本文件一律在 `|ap| ≤ 0.05` 的窗口内拟合**（`[A2]` 里 `ε` 从 `0.05` 到 `0.0125`，系数稳定到 `1e−5`）。
3. **"方向一致"是全文件的承重点**。`GL2:24/0.6` 的 `k₀` 三义里，只有 `k₀^{shell}` 要方向一致。**本文件的封顶正是来自方向不一致**（§3.3）。

### 3.2 精确公式（无近似）

设 `θ' = p'a`，`S(θ') := Σ_{n∈{0,1}⁴}|k̂(θ'−nπ)|²/Ĥ(θ'−nπ)`，`R(θ') := |θ'|² S(θ')`。则

```
h_τ(p')/p'²  =  1 / R(θ') ,        R(0) = |k̂(0)|² = 1 .                    (3.1)
```

⇒ `k₀^{shell}` = `R` 的 `O(|θ'|²)` 系数（作为方向函数）是否**恒为零**。

### 3.3 主定理：`r₂ ≢ 0`（`[T]`）

**定理 A（推前自由符号的 `O(a²)` 系数）。** 设
(i) `k̂` 在 `θ = 0` 与全部奇数 alias 点 `nπ` 的邻域内 `C²`，`|k̂(0)| = 1`；
(ii) `Ĥ(θ) = |θ|² − c₄Σ_μθ_μ⁴ + O(|θ|⁶)`（细格点 Laplacian 型自由符号；Wilson 给 `c₄ = 1/12`）。
则

```
h_τ(p')/p'² = 1 − r₂(û)(a p')² + O((ap')⁴) ,      û = p'/|p'| ,              (3.2)
r₂(û) = Σ_μ b_μ û_μ² + A + c₄ Σ_μ û_μ⁴ ,        A = Σ_{n≠0}|k̂(nπ)|²/(4|n|) ≥ 0 ,   (3.3)
```

其中 `Σ_μb_μθ_μ²` 是 `|k̂(θ)|²` 的二次部分。**特别地 `r₂ ≢ 0`，故 `k₀^{shell} = 2`。**

**证明（三步，全是代数）。**

**第一步：只有 `n = 0` 那一项能给出各向异性的 `O(θ'²)`。**
`R = T_0 + Σ_{n≠0}T_n`，`T_n := |θ'|²|k̂(θ'_n)|²/Ĥ(θ'_n)`。
- `n ≠ 0`：`Ĥ(θ'_n) = 4|n| + O(θ'²)` ⇒ `T_n = |θ'|²[|k̂(nπ)|²/4|n|](1 + O(θ'))`。**`O(θ'²)` 部分是各向同性的**（一个常数乘 `|θ'|²`），各向异性只出现在 `O(θ'⁴)`。
- `n = 0`：`T_0 = |θ'|²(1 + Σb_μθ_μ² + …)·|θ'|^{−2}(1 + c₄Σθ_μ⁴/|θ'|² + …) = 1 + Σb_μθ_μ² + c₄Σθ_μ⁴/|θ'|² + O(θ'⁴)`。

⇒ `R = 1 + |θ'|²[Σb_μû_μ² + A + c₄Σû_μ⁴] + O(θ'⁴)`，即 (3.3)。

**第二步：`Σû_μ⁴` 不是"二次型 + 常数"。** 若 `r₂ ≡ 0`，则 `Σ_μû_μ⁴ ≡ Σ_μb_μû_μ² + A` 在单位球面 `{Σû² = 1}` 上恒成立。把 `Σû² = 1` 代入：左边作为多项式没有 `û_μ²û_ν²`（`μ≠ν`）交叉项、也没有 `û_μ²` 项和常数项。右边两项都**只能**产生这三类。用消元写清：令 `f := Σû⁴ − Σb_μû² − A`，`f` 在实球面（Zariski 稠密）上为零 ⇒ `f ∈ (Σû²−1)` ⇒ `f = (Σû²−1)g`，`deg g ≤ 2`。比较 `û_μ²û_ν²` 系数 ⇒ `g` 的二次部分为零 ⇒ `g = ` 常数 ⇒ 右边 `= 0` ⇒ 要求 `Σû⁴ − Σb_μû² − A ≡ 0`，比较 `û_μ⁴`（左边系数 1、右边 0）矛盾。∎

**第三步：方向一致 ⇒ `k₀^{shell} = 2`。** `r₂(û)` 连续、`≢ 0` ⇒ `sup_û|r₂| > 0` ⇒ 任何 `k ≥ 4` 所要求的 `|h−p²| ≤ C(ap)^4 p²` 都不成立（因为 `|θ'|²` 项还在）。∎

**为什么 `d=1` 不封顶（窗口声明）**：`d=1` 时 `Σû⁴ ≡ 1` 是**常数** ⇒ 第二步的"不存在"变成"存在"（取 `b = 1 − A`），于是 `r₂ ≡ 0` 可达 ⇒ `k₀^{shell} = 4`。`[E]` 给出显式见证（§3.4）。⇒ **本定理是 `d ≥ 2` 现象，且机制是各向异性（`Σû⁴`），与正锥、与符号、与局域性均无关。**

### 3.7 `k₀ ≥ 4` 需要什么：核必须**不 `C²`**

由 §3.3 第一步，`n≠0` 的项在 `O(θ'²)` 上只能给**各向同性**常数。要`r₂ ≡ 0`，唯一的活路是让 `T_n` 的 `θ'²` 部分**带各向异性**，即 `|k̂(θ'−nπ)|²` 作为 `θ'` 的函数在 `θ'=0` 处**不 `C²`**（否则它只有 `c_n + O(θ')` + 二次项，二次项乘 `|θ'|²` 已是 `O(θ'⁴)`）。而 `k̂` 的 `C²` 性 ⟺ `Σ_x|k(x)||x|² < ∞`（两阶矩可和 = 二阶局域）。⇒

> **推论（`[T]`）：`k₀^{shell}(S_τ) ≥ 4` ⇒ `k` 不是两阶局域的。**

这把"抬 `k₀`"和"付非局域性的账"**焊在了同一个不等式上**（GL1 §2.1 的 `2(−1)^n/n²` 正是 `∉C²` 的极端：它的 Fourier 系数 `~(−1)^n/n²`，一阶矩 `Σn·|K_n| = Σ2/n = ∞`）。§4.1 给出方向：局域核的核在位置空间是**指数衰减**的（实测），所以达不到。

### 3.8 守恒律：推前**不能制造** `p⁴` 改进

由 (3.3)：(i) 若细符号的 `c₄ ≠ 0`（Wilson：`c₄=1/12`），则再好的核也只能把 `r₂` 压到 `1/32`，**`k₀^{shell}=2`**；(ii) 若细符号本身 `c₄ = 0`（已是 `p⁴` 改进的），则取 `Σb_μû_μ² + A = 0` 可让 `r₂ ≡ 0`，得 `k₀^{shell} ≥ 4`——**但此时细理论本来就有 `k₀ ≥ 4`**。⇒

> **推论（`[T]`，树级、`C²` 核窗口）：`k₀^{shell}(S_τ) ≤ k₀^{shell}(S_μ)`。** 推前**转运** `k₀`，**不生产** `k₀`。

这条与 GL1 的判决**同构而不重叠**：GL1 说 `k₀=∞` 的 FP 作用量**不是**推前（`GL1:19`）；本文件说**推前给不出超过细理论的 `k₀`**。两条合起来是同一个"没有免费午餐"：**`k₀` 的每一阶都得在细作用量里先有。**

## §4 死因：非局域性、转移矩阵、`Δ`

### 4.1 推前（局域核）**不是** `2(−1)^n/n²` 型（`[E]`）

对 §3.6 的盒子核，把 `h_τ` 在粗 BZ 上做 `32⁴` FFT 得位置空间核 `K_n`（粗格点单位，沿轴）：

| `n` | `K_n` |
|---|---|
| 0 | `+1.4475e+01` |
| 1 | `−2.0924e+00` |
| 2 | `+1.9263e−01` |
| 3 | `−1.9225e−02` |
| 4 | `+2.0158e−03` |
| 5 | `−2.2494e−04` |

相邻比值 `0.092, 0.100, 0.105, 0.112, …` ⇒ **指数衰减**（`~e^{−2.3n}`）。`n²K_n = −2.092, +0.771, −0.173, +0.032, …` **不是** GL1 的 `±2`（`GL1:135` 的 `K_n = 2(−1)^n/n²`）。网格上的 `Σ|K| = 34.86`、`Σn|K_n| = 2.54` ⇒ 绝对可和**且**一阶矩可和。

⇒ **局域核的推前作用量是 quasi-local（指数衰减）**，GL1 §2.1(a) 那条"截断 ⇒ 无单粒子极点 ⇒ `Δ_a` 不是谱量"的机制**在本路不触发**（`[E]`，`32⁴` 网格窗口）。

### 4.2 转移矩阵：**存在**

- RP（§2.1，`[T]`）+ 时间方向指数衰减（§4.1，`[E]`）⇒ `T = e^{−a'H}` 是良定有界算子，`0 ≤ T ≤ 1`、`H ≥ 0`（`B01-RP.md:26` R1）。⇒ `Δ_a := −(1/a')\logλ₂(T_a)` **有对象**。
- `[F]` 在 2D 自由标量上把"RP 形式非负"**机检**了一遍（粗侧 `λ_min = +1.11e−2 > 0`）。

### 4.3 `Δ`：压缩关系 ⇒ **推前只能转运隙，不能造隙**（`[T]` 模 `GR3:21`）

`GR3-RGMONO.md:21` 的压缩关系 `T^{(b)}_{2a} = E_a T_a^2 E_a^{*}`（`E_a` = 到 `σ(Π_a)` 的条件期望；**对推前测度它是恒等式**，`ε ≡ 0`）。压缩的 Ky-Fan 极小极大给出 `λ₂(T_c) ≤ λ₂(T_f²) = λ₂(T_f)²`，于是

```
Δ_c := −log λ₂(T_c)  ≥  −2 log λ₂(T_f)  =  2 Δ_f          (4.1)
⇒   Δ_c > 0  ⟺  Δ_f > 0 .
```

**读法（必须写清，否则会被读成"白赚"）**：`Δ_c ≥ 2Δ_f` 的右边是**细理论的隙**；等号 ⟺ 块化是"隙精确"的。所以本路要么输入 `Δ_f > 0`（**那就是靶**），要么什么都得不到——这与 GL1 §(b3) 的"参数化循环"（`GL1:161–169`）**同型**，但这次是**不等式级**的、可复算的。

`[D]` 把"质量是输入"这件事在自由场上做成逐字可见：`Ĉ_f = 1/(Ĥ+μ²)` 时

| `μ` | `S(0)` | `h_τ(0) = 1/S(0)` | `μ²` |
|---|---|---|---|
| 0.10 | `100.0000000000` | `0.0100000000` | `0.0100000000` |
| 0.30 | `11.1111111111` | `0.0900000000` | `0.0900000000` |
| 0.50 | `4.0000000000` | `0.2500000000` | `0.2500000000` |

（因为 `k̂(nπ)=0 ∀n≠0` ⇒ `S(0) = 1/μ²` **精确**。）⇒ **质量逐字是输入**；这就是 `GL1:269` 的 vacuous 格在本路上的精确对应。
