## §1 · `dF/dβ` 的谱表示（`[T]`）——含两条必须记的口径修正

```

### §1.2 口径修正 1：`dF/dβ` 有两项，不止一项

任务书写 `dF/dβ = ⟨Ω|O|d𝔾/dβ⟩`。这只在 `|Ω_β⟩` **β-无关**时成立。一般情形（`[T]`，链式法则）：

```
  dF/dβ = ⟨∂_βΩ|O|𝔾⟩ + ⟨Ω|O|∂_β𝔾⟩                                        (1.1)
```

两项的谱形状**完全相同**（bra 侧的 Kato 展开给 `⟨∂_βΩ| = −Σ_{n≠0}⟨Ω|∂_βH|n⟩⟨n|/(E_n−E₀)`），故下面所有界都只需把 `A` 换成 `A + A′`，结论不变。**唯一使第二项消失的读法是 `Ω = 𝔾`——但那种读法会把问题变成平凡（命题 1.4(i)）。**

### §1.3 一阶微扰（`[T]`，Kato）

在 `E₀` 孤立单重的前提下（**这就是判死线 (c) 的第一层**，见 §1.6）：

```
  ∂_β|𝔾⟩ = −Σ_{n≥1} |n⟩⟨n|S_W|𝔾⟩ / (E_n − E₀)                           (1.2)
```

代入 (1.1)，取 `Ω` β-无关：

```
  dF/dβ = −Σ_{n≥1} ⟨Ω|O|n⟩⟨n|S_W|𝔾⟩ / (E_n − E₀)                        (1.3)
```

**界**（Cauchy–Schwarz，两次；丢掉 `n≠0` 限制只会放大）：

```

（`12V` = `6V` 个 plaquette × `s_p ≤ 2`。）⇒ **(1.4) 是本文一切定量判定的唯一来源。**

## §2 · 主定理：`|F'| ≤ C|F|` 的假设 **⟺** 结论（`[T]`）

### §2.1 命题 2.1（等价性；本文件的主定理）

> 设 `F ∈ C¹([β₁,2.5])`、`F(β₁) > 0`。则以下三条**等价**：
> **(i)** `∃C<∞`：`|F'(β)| ≤ C|F(β)|` 对一切 `β∈[β₁,2.5]`；
> **(ii)** `F(β) > 0` 对一切 `β∈[β₁,2.5]`；
> **(iii)** `log F` 在 `[β₁,2.5]` 上良定义且 Lipschitz（`∃C: |d log F/dβ| ≤ C`）。

*证.*
**(ii)⇒(iii)**：`F>0` 且 `F∈C¹` ⇒ `F'/F` 连续；紧区间上连续 ⇒ 有界，`C := max|F'/F|`。**(iii)⇒(i)**：`|F'| = |F|·|F'/F|`。
**(i)⇒(ii)**（首零点论证，**这里就是"Grönwall 免费"的全部内容**）：反设 `F` 在区间内有零点，令 `β* := inf{β>β₁ : F(β)=0}`。由 `F` 连续、`F(β₁)>0` 得 `β*>β₁`，且 `F>0` 于 `[β₁,β*)`。于是在 `[β₁,β*)` 上 `|F| = F`，由 (i)：
```
   F'(β) ≥ −|F'(β)| ≥ −C F(β)   ⇒   (F e^{Cβ})' ≥ 0   ⇒   F(β) ≥ F(β₁)e^{−C(β−β₁)}
```
右端在 `[β₁,β*]` 上 `≥ F(β₁)e^{−C(β*−β₁)} > 0`；令 `β ↑ β*`，连续性给 `F(β*) ≥ F(β₁)e^{−C(β*−β₁)} > 0`，与 `F(β*)=0` 矛盾。∎

**推论 2.2（任务书第 3 步的裁决）**
> Grönwall 不等式 `F(2.5) ≥ F(β₁)e^{−C(2.5−β₁)}` 本身**是对的 `[T]`**（上面就是证明），但**不免费**：它把"`F` 无零点"整件事**搬运进 `C<∞` 这个符号**，而由命题 2.1，`C<∞` **⟺** `F` 无零点。⇒ **"只需 `C<∞`"= "只需目标"。** 这一步的价值是**形式**上的（把符号问题换成常数存在性问题，可用谱表示攻），**不是难度**上的。

### §2.3 命题 2.3（零点处的发散律 = 判死线 (b) 的精确形态）`[T]`

由 `V02-BETAMONO` 定理 Z：固定 `(L,a)`、`F` 实解析、`F ≢ 0` ⇒ 零点集离散；若 `β*` 是零点且 `F ≥ 0`（`f₁²` 为平方模/残数 ⇒ 非负），则**偶数阶**，且定理 Z 逐字给 `f₁² ≈ c(β−β*)²`（`d log f₁²/dβ` 有**单极点**）。于是
```
   |F'(β)/F(β)| = 2/|β − β*| + O(1)      (β → β*)      ⇒  C = ∞         (2.1)
```
**⇒ 判 (b)：`C` 在零点处**不可**有限，且发散阶是 `1/|β−β*|`（不是任意阶）。** ⇒ 若 `β*∈(β₁,2.5)`，则 `|F'| ≤ C|F|` 在整个区间**无解**；而由命题 2.1，这也正是"`F` 有零点"的同义反复。

### §2.4 对任务书第 4 步的逐字裁决

任务书写："若 `F(β*)=0`，则 `|F'| ≤ C|F|` **仍成立**但 `F` 恒 0 之后 —— `F` 解析，若在区间恒 0 则处处 0，与 `F(β₁)>0` 矛盾 ⇒ **只需 `C<∞`**。"

| 子句 | 判定 |
|---|---|
| "`F(β*)=0` 时 `\|F'\|≤C\|F\|` 仍成立" | **假 `[T]`**。命题 2.1 的 `(i)⇒(ii)`：不存在"零点与不等式共存"的情形。二次零点处 `F'/F ~ 2/(β−β*)` 发散（(2.1)）。 |
| "`F` 恒 0 之后" | **不会发生**，也不必要：`F` 有零点就**已经**与不等式矛盾，不需要走到"区间恒 0"。 |
| "解析性 ⇒ 区间恒 0 ⇒ 处处 0 ⇒ 与端点矛盾" | **这一步本身对**（解析函数在连通域子区间恒零 ⇒ 恒零），但**多余**：Grönwall 单独排除**首零点**，不用解析性。⇒ 解析性是**更弱的备用论证**，不是必需。 |
| "⇒ 只需 `C<∞`" | **结论对、难度被低估**。由命题 2.1，`C<∞ ⟺ F 无零点`，所以"只需 `C<∞`"是**同义反复**；真正的问题是"能不能**证** `C<∞` 而不预设 `F≠0`"，而 §1.6/(1.4) 说：不能（存在性 + 定量都带隙）。 |

## §3 · 任务 2：有限区间能换来什么？——唯一真实的放松 (G)

### §3.1 动机

矛盾：`dF/dβ` 需要隙；`F>0` 要证隙。打破方式**只有一条路**：让 `F'` 的界**不需要点态的 `Δ`**，而只需要 `1/Δ` 在有限区间上**可积**。这确实可行，因为 Grönwall 只消费 `C` 的**积分**（`∫C`），不消费 `sup C`。

### §3.2 命题 3.1（`(G) ⇒ 目标`）`[T]`

> 记 `A(β) := ‖O†Ω_β‖‖S_W𝔾_β‖ + ‖S_WΩ_β‖‖O𝔾_β‖`（两项对应 (1.1) 的两项）。若
> ```
>    (G)   ∫_{β₁}^{2.5} A(β)/Δ(β) dβ  <  ∞ ,
> ```
> 则 `F(2.5) ≥ F(β₁)·exp(−∫_{β₁}^{2.5} A/Δ dβ) > 0`。

*证.* 由 (1.4)（含 `Ω'` 项的同形界）得 `|F'| ≤ (A/Δ)|F|` **在区间上逐点成立**（此式不需要 `F≠0`：`|F'| ≥ −|F'|` 恒真）。令 `C(β) := A(β)/Δ(β)`，重复命题 2.1 的首零点论证，把常数 `C` 换成可积的 `C(β)`，即得 `F(β) ≥ F(β₁)exp(−∫_{β₁}^β C)`；`(G)` 保证指数有限。∎

**关键**：`(G)` 里**没有 `F`**。⇒ **逻辑上不循环**：这是"谱侧假设 ⇒ 结论"的真推理。

### §3.3 `(G)` 严格弱于"统一谱隙" `[T]`

| 假设 | 允许 `Δ` 在区间内触零？ | 允许 `1/Δ` 不可积？ |
|---|---|---|
| 统一隙 `∃δ>0: Δ ≥ δ` | 否 | — |
| **(G)** | **是**（零测集上） | 否，但允许**对数薄**：`Δ(β) ≥ c/log(1/\|β−β_c\|)` 给 `∫1/Δ = ∫log < ∞` ✓；而 `Δ = c\|β−β_c\|^α`（`α ≥ 1`）给**发散** ✗ |

⇒ **`(G)` 是"隙可以在 `β_c` 处以对数速率塌陷"的陈述。** 这是本文对任务 2 的正面回答：**有限区间确实换来了量词形状的下调（`sup` → `L¹` 加权），且这是 Grönwall 能消费的最弱形状。**

### §3.4 但 `(G)` **严格强于**目标（反例 `[T]`）

**反例（三能级玩具，可手算）**：`H(β) = diag(0, |β−β_c|^α, 1)`、`O = |0⟩⟨1| + h.c.`、`Ω = |0⟩`。则 `F = ⟨0|O|1⟩ = 1 > 0` **且 `F' ≡ 0`**（`|F'| ≤ 0·|F|` 以 `C=0` 成立），但 `Δ(β) = |β−β_c|^α` 在 `β_c` 触零 ⇒ `α ≥ 1` 时 `∫1/Δ = ∞`，**`(G)` 假**。
⇒ **`Target` 真而 `(G)` 假** ⇒ `(G)` **严格强于** `Target` ⇒ 欠账 `(G) − Target > 0`。
**但同时暴露 (1.4) 是有损的**：上例中真 `F' = 0`，而 (1.4) 给 `|F'| ≤ A/Δ → ∞`。⇒ `(G)` 是**充分不必要**条件。是否存在更聪明的（利用 `⟨Ω|O|n⟩` 与 `⟨n|S_W|𝔾⟩` 相消的）界，使 `C<∞` 而 `(G)` 假？——在 YM 里 `S_W ≥ 0`（`s_p ≥ 0` 为算子）与 `O` 的结构**不提供**这种相消（`V02 §3` 已判一般 `β` 处无对称性零保护；`n=1` 项的分子正是残数本身、非零）。标 **`[C]`**：不能排除，但语料里没有任何相消机制可用。

### §3.5 `(G)` 的验证 = 六条全死的同一靶

`(G)` 要求 `Δ(β) > 0` 对 a.e. `β∈[β₁,2.5]`。这正是 `CLAUDE.md §5` 的"未闭合"：**跨 `[1/48, 2.5]` 的 cutoff 一致粗模谱隙下界**。⇒ **任务 2 的答案是：能打破的是量词形状，不能打破内容。**
