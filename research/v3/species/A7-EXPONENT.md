# A7 · 指数 `p`：`f ~ e^{−c'/g²} ⇒ f ~ (aΛ)^p`，`p = 2b₀c'`

> 对象：已发表界的形状 `m a ≥ c·f(g)`、`f(g) ~ e^{−c'/g²}`（`A5-LIT-UNIFORM.md:93`；`LOOP-RUNBOOK.md:678/692`）。问：把 `f` 用 `a` 表示后幂次 `p` 是多少，以及由此该形状在 `a→0` 是空洞 / 恰好 / 荒谬。
> 输入：单环 AF `a = Λ^{-1}e^{−1/(2b₀g²)}(1+O(g²))`。标签：`[T]` 精确代数 / `[C]` 条件（依赖单环输入） / `[NG]` no-go / `[M]` 实测或语料数字。

---

## §0 判死线（先写结论）

**`p = 2b₀c' = (11N/(24π²))·c'`** `[T]`（在 §2 的一环输入下是精确恒等式，无近似）。分界点 `p=1 ⟺ c' = c'_crit := 1/(2b₀) = 24π²/(11N)`：

| 档 | 条件 | 界的极限 | 意义 | 命中者 |
|---|---|---|---|---|
| `p > 1` | `c' > c'_crit` | `m ≥ cΛ(aΛ)^{p−1} → 0` | **空洞**（界随 `a→0` 消失，不排除 `m=0`） | **语料实测 c' 全在此档**（§5）：`8π²/N`、`c*`、`c**` ⇒ **判 (a)** |
| `p = 1` | `c' = c'_crit = 24π²/(11N)` | `m ≥ cΛ` | **恰好可用**（常数型） | 仅当 `f ≡ aΛ`，即 `t3` 的 `ma ≥ c·aΛ` |
| `p < 1` | `c' < c'_crit` | `m ≥ cΛ(aΛ)^{p−1} → ∞` | **荒谬**（形状不可能对） | `c'=1,2,4` 这类 O(1) 强耦合常数 ⇒ **判 (c)** |

**(a) 成立，且是主判决**：语料里唯一带数的 `e^{−c'/g²}` 指数（拓扑缺陷 fugacity `c'=8π²/N`，以及 `BC-CHAIN` 的 KP/并集阈值 `c*`、`c**`）全部 `> c'_crit`，故 `p>1` ⇒ **所有这类界的形状在 `a→0` 时空洞**；连续极限必须换成**不同形状**的界：常数型 `m ≥ cΛ`（`[C]`，需 `c>0` 另证），或等价地把它写成 `t3` 的 `ma ≥ c·aΛ`。
**(b) 只在定点上**：`c' = 24π²/(11N) = 10.7668 (N=2) / 7.1779 (N=3)` 时 `f = aΛ`，界退化为 `m ≥ cΛ`；这不是 `e^{−c'/g²}` 的"自由常数"，它被 `b₀` **钉死**。⇒ 结论：**不要写 Wilson 指数形状，直接写常数型**；`e^{−c'/g²}` 只是 `aΛ` 的幂的重写，`c' ≠ c'_crit` 时必错（非空洞即荒谬）。
**(c) 是"c' 不能是 O(1)"的定量版**：`c'=1,2,4` 给 `p=0.09…0.56 < 1` ⇒ `m→∞`，荒谬；故任何把 `c'` 当 `O(1)` 强耦合常数的引用（"典型常数 1–4"）与 `f→0` 的物理要求**不相容**。

**一句话**：`p = 2b₀c'`；`p⋛1 ⟺ c' ⋛ 24π²/(11N)`。这是关于 `c'` 的**单参数判据**，而 `c'` 的实际值把它推到 (a)。

## §1 `b₀` 归一核准：`11N/(48π²)` 与 `11N/(3·16π²)` 是**同一个数**

`3·16π² = 48π²` 逐字相等（`[T]`，算术）。故两写法不是两种归一，是同一归一的两种排版：

```
b₀ = 11N/(48π²) = (11N/3)/(16π²) ,    48π² = 473.741012
b₀(N=2) = 22/473.741012 = 0.0464388
b₀(N=3) = 33/473.741012 = 0.0696582
```

**三处独立交叉核对（语料内）`[M]`**：

1. `BC-CHAIN.md:121` 写 `2β₀ = 0.13932 (N=3)` —— 与 `2b₀(N=3)=0.139316` 一致。
2. `BC-CHAIN.md:114` 写 "到 `g²=1` 需 `j = 1/(2β₀) = 7.18 (N=3) / 10.77 (N=2)` 个壳层" —— 正是本文件的 `c'_crit`（§0），且与 `24π²/(11N)` 同值（10.7668 / 7.1779）。
3. `DF-CONTINUITY.md:139` 写 `S₀ = 8π²/(g²N) = (11/3)ln(1/(Λβ))` —— 反解恰得 `b₀ = 11N/(48π²)`（把 §2 的 `1/g²` 代入即得 `11/3`）。

⇒ 归一**核准通过**；本文件全程用 `b₀ = 11N/(48π²)`，且 `aΛ = e^{−1/(2b₀g²)}(1+O(g²))` 里的 `b₀` 就是它（不是 `b₀/2`、也不是 `11N/(48π²)·2`）。**唯一可能的口径坑**：若把 `β = 2N/g²`（标准 Wilson）当自变量，`e^{−1/(2b₀g²)} = e^{−N β/(4·…)}` 会整体换字母，但 `p` 是**标度指数**，对 `β`-口径不变（§6 第 3 条）。

## §2 `a(g)` 领头阶 ⇒ `1/g² = 2b₀ ln(1/(aΛ))`

`[C]`（单环渐近自由；`[T]` 是给定该式后的代数）：

```
a = Λ^{-1} · e^{−1/(2b₀g²)} · (1 + O(g²))                     (2.1)
⇒  aΛ = e^{−1/(2b₀g²)} (1 + O(g²))                             (2.2)
⇒  ln(1/(aΛ)) = 1/(2b₀g²) − ln(1+O(g²)) = 1/(2b₀g²) + O(g²)    (2.3)
⇒  1/g² = 2b₀ ln(1/(aΛ)) · [1 + O(g²)]                         (2.4)
```

量纲：`[a]=L`、`[Λ]=L^{-1}` ⇒ `aΛ` 无量纲（且 `aΛ<1`，`ln(1/(aΛ))>0`）`[T]`；`b₀` 无量纲 ⇒ 右端无量纲 = 左端 `1/g²` ✓ `[T]`。方向：`g→0 ⇒ aΛ→0 ⇒ ln→∞`，与 AF（`a→0` ⇔ `g→0`）一致 `[T]`。

## §3 代入 ⇒ `p = 2b₀c'`

`[T]`：

```
f(g) ~ e^{−c'/g²} = exp{ −c' · 2b₀ ln(1/(aΛ)) } = (aΛ)^{2b₀c'}       (3.1)
⇒  p = 2 b₀ c' = (11N/(24π²)) · c'                                    (3.2)
```

（(3.1) 是 `e^{−c'·A}=(aΛ)^{c'·2b₀}` 的直接换底；`O(g²)` 只改前因子，不改幂次 `[T]`。）

于是 `m a ≥ c (aΛ)^p ⇒ m ≥ c Λ (aΛ)^{p−1}` `[T]`，量纲：`[cΛ]`=质量、`(aΛ)^{p−1}` 无量纲 ⇒ 右端质量 ✓；`a→0` 时 `(aΛ)^{p−1}` 的行为由 `sign(p−1)` 唯一决定 ⇒ §0 的三档划分是**穷尽且互斥**的 `[T]`。

**`p` 与 1 的分界是一个 `c'` 值，不是一个模糊命题**：

```
p⋛1  ⟺  c' ⋛ 1/(2b₀) = 24π²/(11N) = 10.7668 (N=2) / 7.1779 (N=3)     (3.3)
```

## §4 数值：`c' = 1,2,4` 与 `N=2,3`（§4 全表）

`[M]`（`pwsh` 直算，`b₀` 见 §1）：

| `c'` | `p` (N=2) | `p` (N=3) | `p−1` (N=2) | `p−1` (N=3) | 档 |
|---|---|---|---|---|---|
| 1 | 0.09288 | 0.13932 | −0.9071 | −0.8607 | `p<1` ⇒ 荒谬 `m→∞` |
| 2 | 0.18576 | 0.27863 | −0.8142 | −0.7214 | `p<1` ⇒ 荒谬 |
| 4 | 0.37151 | 0.55727 | −0.6285 | −0.4427 | `p<1` ⇒ 荒谬 |
| **`c'_crit`** | **10.7668** | **7.1779** | 0 | 0 | **`p=1` ⇒ `m ≥ cΛ`** |
| `c** = ln(2d)/(2b₀)` | 22.389 | 14.926 | **`p = ln 8 = 2.0794`** | 同（N-无关） | `p>1` ⇒ 空洞 |
| `c* = d ln L/(2b₀)` | 29.852 | 19.901 | **`p = 4ln2 = 2.7726`** | 同（N-无关） | `p>1` ⇒ 空洞 |
| `8π²/N`（缺陷 fugacity） | 39.478 | 26.319 | **`p = 11/3 = 3.6667`** | 同（N-无关） | `p>1` ⇒ 空洞 |

两条**精确**（非拟合）的漂亮结果是表的第 5–7 行：因为 `c* ∝ 1/(2b₀)`，`p` 与 `N`、与 `b₀` 全约掉 `[T]`：

```
p = 2b₀ · [d ln L/(2b₀)] = d ln L = 4 ln 2 = 2.77259        (L=2, d=4, 并集阈值)
p = 2b₀ · [ln(2d)/(2b₀)] = ln(2d) = ln 8 = 2.07944          (KP 阈值)
p = 2b₀ · [8π²/N]        = 16·11/48 = 11/3 = 3.66667       (拓扑缺陷 e^{−S₀})
```

`[T]`：三者的 `2b₀` 与分母的 `2b₀` 相消，故这三个 `p` **与归一无关、与 `N` 无关**——它们是 `d ln L`、`ln(2d)`、`11/3` 这几个**纯组合数**。这把"界随 `a→0` 以何幂趋零"变成了可核的整数/对数表达式，而不是拟合值。**`p>1` 三连中，且都 `> 2`** ⇒ (a) `[NG]`。

对 `p>1` 档，空洞率写成幂：`m ≥ cΛ(aΛ)^{p−1} = (aΛ)^{∈{8/3, ln8−1, 4ln2−1}}` 级地趋零（例：缺陷档 `m ≥ cΛ(aΛ)^{8/3}`，`a→0` 时像 `a^{8/3}`）`[T]`。

## §5 语料实测 `c'`：**未取数**（"已发表界的拟合 `c'`"），但**能取到三个数**

检索（可复现）：`grep -n "c'\s*[=≈:]\s*[0-9]" / "e\^{−c'/g" / "exp(-c" -r research` ⇒ **0 条**；`SZ-CEILING.md`、`UC-COMPLETE.md` 通读（前者是 `β`-天花板与 `c_n=I_n−I_{n+2}` 特征标，后者是 KP 判据 `ρ(a,β)`，其 `e^{an}` 的 `a` 是**分级/动物常数**，与 `g` 无关）⇒ 二者**都没有** `e^{−c'/g²}` 型界的拟合 `c'`。

**结论：`c'` 的"实测值"（就"已发表界的常数"这一项）未取数。** 语料里能直接取的只有三类，全部列在 §4 表尾：

1. `[T]` 拓扑缺陷 fugacity：`S₀ = 8π²/(g²N)` ⇒ `c' = 8π²/N`，`p = 11/3`（`DF-CONTINUITY.md:139` 的输入；本文件自算，非引用）。
2. `[M]` `BC-CHAIN.md:113/121` 的阈值族 `c* = 19.90/29.85`、`c** = 14.93/22.39` ⇒ `p = 4ln2 / ln8`。
3. `[C]` 若只有一个"格点强耦合展开的典型常数"级别的说法，那只能是 `c' = O(1)` ⇒ 落 `p<1` ⇒ (c)。

三者给出**同一个判决方向**：`c'` 一旦按语料/物理取值，`p` 就 `≥ 2`（空洞）；只有把 `c'` 压到 `24π²/(11N) ≈ 7–11` 才 `p=1`。

## §6 量纲逐个核 `[T]`

1. `[a] = L`，`[Λ] = L^{-1}`，`[g] = 0` ⇒ `aΛ`、`g²`、`b₀`、`c'`、`p` 全无量纲 ✓。
2. `m a` 无量纲 ✓；`c f(g)` 无量纲 ⇒ `c` 无量纲 ✓（界的两端都是"每格距的质量数"）。
3. `m ≥ cΛ(aΛ)^{p−1}`：`[cΛ] = L^{-1}` = 质量 ✓（`ℏ=c=1`）。**`p` 对 `β`-口径不变**：换 `β=2N/g²` 只把 (2.4) 的系数从 `2b₀` 改成 `2b₀·2N`，`c'` 同改，`p = 2b₀c'` 的**乘积**不变（本文件已用 `aΛ` 这一 `β`-无关量表述，故为口径不变量）✓。
4. `S₀ = 8π²/(g²N)` 无量纲 ✓；`8π²/(g²N) = (11/3)ln(1/(aΛ))` ⇒ 幂 `11/3` 无量纲 ✓（与 §1 第 3 条互证）。

## §8 结论（供总册引用）

> **`p = 2b₀c' = (11N/(24π²))c'`**，且 `p⋛1 ⟺ c' ⋛ 1/(2b₀) = 24π²/(11N)`（`[T]`，给定单环 AF）。
> 取 `c'=1,2,4`：`p = 0.093/0.186/0.372`（`N=2`）、`0.139/0.279/0.557`（`N=3`）⇒ `p<1` ⇒ `m→∞` 荒谬 `[NG]` ⇒ **`c'` 不能是 O(1) 常数**。
> 取语料实测/可算的 `c'`（`8π²/N`、`c*`、`c**`）：`p = 11/3 / 4ln2 / ln8`，全 `>1` ⇒ **判 (a)：该形状的界在 `a→0` 空洞** `[NG]`。
> 唯一活口是定点 `c'=24π²/(11N) ≈ 7.18–10.77`，此时 `f ≡ aΛ`、`m ≥ cΛ`（**(b)**，`[C]` 可用，`c>0` 另证）——即 `t3` 的常数型/`ma ≥ c·aΛ` 形状。
> ⇒ **连续极限要的不是新的 `c'`，是换形状**：常数型 `m ≥ cΛ`；把 `e^{−c'/g²}` 留着写，就是"非空洞即荒谬"的二值陷阱。
