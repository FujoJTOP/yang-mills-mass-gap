## 0 · 判词（一句话）

**`C̄ = 1` 作为恒等式是假的**：`Σ_{Γ∋x}τ(G_Γ)a^Γ = Σ_{T∋x}a^T` 在 `n=3` 就有反例（差项 `3a₁₂a₁₃a₂₃`），
**正确式**是 `Σ_{Γ∋x}τ(G_Γ)a^Γ = Σ_{T∋x}a^T·∏_{e∉T}(1+a_e)`（本文件 §1 手算 + 符号/整数复核）。
⇒ **判死线 (b) 触发**：`C̄ = 1` 塌。**但**（这是关键）差项是一个**正因子** `∏(1+a_e) = 1+O(u)`，
不是发散的动物计数，所以 `C̄ ∈ [1, e^{Δu}]`：`β ≤ 1/48` 时 `C̄ ≤ 1.0535`，`Ĉ·C̄ ≤ 4.214 < 7.0633`
⇒ **窗口 `1/48` 与 `δ>0` 都还在**，但 `I1` 必须记成 **`[T]` mod `C̄ ≤ 1.03`（不是 `C̄=1`）**。
**Penrose 界 `|φ^U| ≤ τ` 核准为 `[T]`**（本文件给出 4 行删–缩证明 + 875 个图 0 违例）；**(c) 不触发**。

## 1 · 恒等式：手算 `n ≤ 4`（任务第 1 项）

定义按 `φ^U(Γ) = Σ_{A⊆E,(V,A)连通生成} (−1)^{|A|}`（与 Fernández–Procacci arXiv:math-ph/0605041 式 (2.4) 逐字一致；`a^Γ = ∏_{e∈Γ}a_e`，`τ(G_Γ)` = 生成树数）。

### 1.1 `n = 3`，顶点 `{x,y,z}`，边权 `a₁₂=a₀, a₁₃=a₁, a₂₃=a₂` —— 全表手算

| `Γ` | 边集 | `τ` | `φ^U` | `a^Γ` | 贡献到 LHS |
|---|---|---|---|---|---|
| 树 | `{xy,xz}` | 1 | `+1` | `a₀a₁` | `a₀a₁` |
| 树 | `{xy,yz}` | 1 | `+1` | `a₀a₂` | `a₀a₂` |
| 树 | `{xz,yz}` | 1 | `+1` | `a₁a₂` | `a₁a₂` |
| 三角 | `{xy,xz,yz}` | **3** | `+2` | `a₀a₁a₂` | `3a₀a₁a₂` |

- **LHS** `= a₀a₁+a₀a₂+a₁a₂+3a₀a₁a₂`
- **RHS** `= Σ_{T} a^T = a₀a₁+a₀a₂+a₁a₂`
- **LHS − RHS = `3a₀a₁a₂` ≠ 0** ⇒ **恒等式假**。见证是最小的一只动物：三角。
  它的 `τ=3` 条生成树被"算 3 次"，但 RHS 里根本没有 `O(a³)` 项。

`n=4`（`K₄`，6 变量、38 只连通图、16 棵树，sympy 精确）：

```
LHS - RHS = 16a₀a₁a₂a₃a₄a₅ + 8a₀a₁a₂a₃a₄ + …… (共 22 项，次数 [4,6]；树项精确对消)
```
（全多项式 + 38 只图的 `τ` 表见 `c07_handcheck.log`；n=5 同式见 `c07_cbar1.log` §1。）差项只出现在 `|E| ≥ |V|` 的圈图上，这正是"动物因子"。

### 1.2 正确的恒等式（同一次手算就能读出来）

按生成树 `T` 归并：`Σ_Γ τ(Γ)a^Γ = Σ_T a^T · Σ_{Γ⊇T}a^{Γ∖T} = Σ_T a^T ∏_{e∉T}(1+a_e)`。

| 检查 | 结果 |
|---|---|
| `n=3`：`LHS − Σ_T a^T∏_{e∉T}(1+a_e)` | **0**（`3a₀a₁a₂ + Σa_ia_j − [Σa_ia_j + a₀a₁a₂(1+1+1)] = 0`） |
| `n=4` sympy 精确 | **0** |
| `n=4,5`，整数活动度 `a_e ≡ 1` | `n=4: LHS=128, RHS=16, RHS2=128` ✔ |
| `n=4,5`，`a_e ≡ 3` | `LHS=27648, RHS=432, RHS2=27648` ✔ |

**单位活动度比值 = `2 / 8 / 64`（`n=3,4,5`）`= 2^{C(n−1,2)} = 2^{#非树边}`** —— 即差项恰好是
"非树边"的 `∏(1+a_e)`。**这就是"树吸收动物因子"这句话的错误所在：树不吸收动物因子，动物因子原样回来。**

### 1.3 对 `C̄` 的定量后果（不是"塌成不可控"，而是"塌成一个可算的数"）

`Σ_Γ|φ^U(Γ)|u^{|Γ|} ≤ Σ_Γ τ(Γ)u^{|Γ|} = Σ_T u^{|T|}∏_{e∉T}(1+u) ≤ e^{Δu/2}·Σ_T u^{|T|}`

（每棵树 `≤ Δn/2` 条非树边可用，`Δ = 20`；取更保守的 `e^{Δu}` 亦可。）故

`ū = eΔ·u·C̄`，`C̄ = ∏(1+a_e)^{每顶点} ∈ [1, e^{Δu}]`。

`u = β/(2N²) = 1/384`（`β=1/48, N=2`）：`C̄ ≤ e^{0.0521} = 1.0535`，`Ĉ·C̄ ≤ 4.214 < 7.0633` ✔
`u = 0.0104`（`z12` 旧参考活动度）：`C̄ ≤ 1.2312`，`Ĉ·C̄ ≤ 4.925 < 7.0633` ✔

⇒ **`1/48` 窗口在 (b) 下仍然复原，但常数从 `4` 变成 `≤4.22`；`C̄=1` 这个"精确 1"必须作废。**

## 3 · `Ĉ·C̄ = 4` 与 `z12` 的 `Ĉ` 定义是否一致（任务第 3 项）

- `z12`（`z12_fixc.py:17,53`、`Z12-FIXC.md:53,96`）的 `Ĉ := sup_γ(∏_ℓR(ℓ))^{1/|γ|} = 4`，是**逐 `γ` 的几何均值率**，且 `C06 §2.3` 证明这个 `sup` **取到**（立方体见证）⇒ 取 `4` 正确。
- 但 `z12` 式 `(2.1)` 里与 `Ĉ` 相乘的 `C̄` 在 `X01-L1C:71` 的定义是 **`|φ^U(Γ)| ≤ C̄^{|Γ|}u^{|Γ|}`** —— 逐 `Γ` 的率。
  `c01` 自己的 `K_6` 数据给出这个量 `≥ 120^{1/6} = 2.220906`（本文件复现：`sup_{n≤5}|φ^U|^{1/n} = 1.888175`，`K_6 = 2.220906`）。
- ⇒ **`Ĉ` 一致；`C̄` 不同层。** `Ĉ·C̄ = 4` 只在把 `C̄` 从"逐 `Γ` 的 sup"**替换**成"求和级常数"时成立，
  这是一次**未声明的重定义**（也正是 `c01` 想做的替换）。按 `z12` 原口径：`Ĉ·C̄ ≥ 4×2.2209 = 8.884 > 7.0633` ⇒ 窗口不保。
- 判：**`4` 这个数不是从 `z12` 的 `C̄` 推出来的**；它需要 §1.2 的正确恒等式给出 `C̄ ≤ e^{Δu} ≈ 1.03` 才能站住。
  也就是说：`Ĉ·C̄ = 4` 的正确陈述是 **`Ĉ·C̄ ≤ 4.22`（不是 `= 4`）**。

### 4.2 我自己证（4 行，删–缩归纳）`[T]`
对带权 `w` 定义 `φ_w(Γ) = Σ_{A conn. spann.}(−1)^{|A|}∏_{e∈A}w_e`，`τ_{|w|}(Γ) = Σ_{T}∏_{e∈T}|w_e|`。取任一边 `e`：
`φ_w(Γ) = φ_w(Γ−e) − w_e·φ_w(Γ/e)`，`τ_{|w|}(Γ) = τ_{|w|}(Γ−e) + |w_e|·τ_{|w|}(Γ/e)`
（前一式是 `A∌e` / `A∋e` 的拆分并收缩；后一式是生成树的删–缩。）归纳于 `|E|`：
`|φ_w(Γ)| ≤ |φ_w(Γ−e)| + |w_e||φ_w(Γ/e)| ≤ τ_{|w|}(Γ−e) + |w_e|τ_{|w|}(Γ/e) = τ_{|w|}(Γ)`。
基例：单边 `|φ|=1=τ`；树 `|φ|=1=τ`；桥 `e` 时 `Γ−e` 不连通 ⇒ 两项皆 0。∎

**⇒ `|φ^U(Γ)| ≤ τ(Γ)` 是无条件定理，不需要"`a` 足够小"这类条件 ⇒ 判死线 (c) 不触发。**
单位活动度即 `w≡1`；加权版给出 `|φ_w(Γ)| ≤ τ_{|w|}(Γ)`。

## 5 · 结论与回填

1. **恒等式（错）⇒ 判死线 (b)**：`Σ_Γ τ a^Γ ≠ Σ_T a^T`，差项 `= Σ_T a^T(∏_{e∉T}(1+a_e) − 1) > 0`（`a>0`）。
   手算见证：`n=3` 三角，`LHS−RHS = 3a₀a₁a₂`；单位活动度比值 `2,8,64`。
2. **正确式** `Σ_Γ τ a^Γ = Σ_T a^T∏_{e∉T}(1+a_e)`（`n=3,4` 符号精确，`n=5` 整数精确）⇒
   `C̄ = ∏(1+a_e)^{每顶点} ∈ [1, e^{Δu}]`，**`C̄=1` 只在 `u→0` 的极限成立**。
3. **数值后果**：`Ĉ·C̄ ≤ 4·1.0535 = 4.214 < 7.0633`（`β=1/48`）⇒ **`1/48` 窗口与 `δ·a>0` 都保**；
   但 `I1` 的标签改为 **`[T]` mod `C̄ ∈ [1, 1.03]`**，不得写 `C̄ = 1`。
4. **`Ĉ·C̄ = 4` 应改为 `≤ 4.22`**（§3：`Ĉ` 与 `z12` 一致，`C̄` 被静默换了层）。
5. **Penrose 界成立（`[T]`，自证）**，但它只给逐 `Γ` 界；`c01` 把"逐 `Γ` ≥2.2209"与"求和级 =1"并列时，
   中间那一步（恒等式）是空的。
6. 建议回填 `C01-CBAR1.md`：判词 5/6 与 §4 表 `C̄=1` 一行；`7.0633/4` 的 `1.766` 余量改 `1.68`（`/4.214`）。
