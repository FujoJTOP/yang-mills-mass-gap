## §1 `K` 的显式定义与两类减除

### 1.1 (K-def)
```
(K-def)  W_a := { z : a<|z|<L }
         M_a := ∫_{W_a} |C_2^{ren}(z)| d⁴z ,      A_a := | ∫_{W_a} C_2^{ren}(z) d⁴z |
         K_a := M_a/A_a (A_a=0 ⇒ K_a:=∞) ,       K := sup_{0<a≤a₀} K_a
         ⇒ K∈[1,∞] ;   K=1 ⟺ C_2^{ren} 在 W_a 上 a.e. 定号（∀a≤a₀）
```
- `K≥1` 来自 `|∫|≤∫|·|`；`K=1` 是三角不等式取等。与 `HX1-RHOG:2.2` 的"符号比 `∫|·|≤K|∫·|`"逐字同义（定义层，不增内容）。
- **下一手**：把 `K` 标成 `∃`-scheme 谓词（`s_a` 属方案族），所有 `K` 结论带 class。
### 1.2 「保号减除存在」的精确含义与两类
```
(POS)  ∃ s_a（方案族内的函数/常数） s.t.  C_2^{ren} := C_2^{bare} − s_a 在 W_a 上定号（∀a≤a₀） ⟺ K=1
```
| 类 | `s_a` | 谁在用 | 自由场 `K` |
|---|---|---|---|
| **C-class** | `c₂(a)·1`（接触 c-数，`|z|≲a`） | `(U2)`/HX1（`HS-L3-6:0.3`） | `(L/a)^4−1`（§2.3） |
| **F-class** | `c|z|^{-8}` on `r<r₀`、`0` on `r>r₀`，`r₀` 固定 | 点分裂/流时有限部（`HS-L3-6:59`） | `1`（§2.1） |
- **C-class 刚性引理（自由场，`[T]`）**：`C_2=c|z|^{-8}`。p=0 要 `∫s_a=(π²c/2)a^{-4}+O(1)`，即 `c₂=m_a+O(L^{-4})`、`m_a=ca^{-4}L^{-4}`；定号要 `c₂≤min_{r>a}C_2=cL^{-8}`。二式差 `(L/a)^4→∞`；方案族有限部是 `a⁰`（`HS-L3-6:0.4`）⇒ **C-class 无成员能同时满足**。
- **F-class 是另一个方案代表**：与 C-class 的减除项在**有符号**矩上**都扛 `a^{-4}`、差为有界常数**（`∫_{r<r₀}c r^{-8}−(π²c/2)a^{-4}=−(π²c/2)r₀^{-4}`），故对 `p` 同类；在**模**上不同（密度在 `(a,r₀)` 被改）。⇒ `K` 区分的正是 `p`-route 视为同一的那些代表；`K` 有界只能读成 `∃`-scheme。
- **下一手**：把 `(POS)` 的 `∃` 写进 `L3` 充分包；`K` 的 class 与 `r₀` 一起钉。
### 1.3 与 `(★)` 的一行对照
```
(★)  Var_{μ(·|U′)}(Pᵀ∇S_j v) ≤ E⟨PᵀH_jP v,v⟩ + W_j(v) − δ ,   ∀U′, ∀j, ∀v   [HQ1-L3:59]
(K)  sup_{a≤a₀} ∫_{W_a}|C_2−s_a| / |∫_{W_a}(C_2−s_a)| < ∞
```
| 轴 | `(★)` | `K` |
|---|---|---|
| 导阶 | 2（`Var`、`∇S_j`、`Hess`） | 0（函数值） |
| 量词 | `∀U′∀j∀v` + defect `δ>0` | 无（一个 `sup_a`） |
| 自由场 | **假**（`Var=E[H]`、`W=0` ⇒ `0≤−δ`；`HQ1-L3:63`） | **真**（F-class `K=1`） |
| 蕴含 | `(★)⇏K`、`K⇏(★)`（仓内 0 条） | 同左 |
- **"弱"的确切位置**：导阶 2→0、量词塔 `U′,j,v` 全删、defect `δ` 全删；这使 `K` 能过 `(★)` 过不了的自由场酸测，也使它**不含** `∇`/`Hess` 信息 ⇒ 对 `ρ` 无话（§3）。
- **下一手**：任何"`K` 蕴含 `(★)` 某弱化"的句子按本表驳回；`K` 只替代充分包里的"符号"槽。
## §2 三路
### 2.1 (a) 由 `(U2)` 直接给
- `(U2)=L1+L2`（`HS-L3-6:0.3`）：给 `c₂(a)=a^{-4}c(g)` 与 `p=0`（**有符号**矩），有限部 `a⁰`（`:0.4`）。**C-class**：由 1.2 刚性引理，`K=1∧p=0` 无解 ⇒ `[NG]`；2.3 又给 `K=(L/a)^4−1` ⇒ 是**假**，不止缺证。
- **F-class**：取 `s_a=c|z|^{-8}·1_{r<r₀}`，`r₀` 固定。自由场逐项：
```
C_2^{ren} = c r^{-8} (r>r₀) ,  0 (r<r₀)
M = A = (π²c/2)(r₀^{-4}−L^{-4})       （∫_a^L r^{-5}dr = ¼(a^{-4}−L^{-4})，下限量 r₀）
ρ = (sup |C_2^{ren}|/|h|)^{1/2} = √c ,  S = M/ρ = √c(π²/2)(r₀^{-4}−L^{-4}) < ∞
p=0（r₀ 固定）,  K=1,  floor ρ=√c>0
```
- **判**：`(U2)` 本身 `[NG]`（C-class 无解）；F-class 自由场 `[T]`；相互作用侧 `[NG]`（`C_2−c r^{-8}` 在 `r>r₀` 的定号未证）。
- **下一手**：把 `HX1-RHOG:0.5` 的 `√c·c_L²/32π²` 换成上式；那个值是 `A/ρ`（有符号），`M/ρ` 按 (K-def) 是 `√c(π²/2)(a^{-4}−L^{-4})→∞`。
### 2.2 (b) Schur 侧 / 正性
- RP/OS ⇒ 柱面 KL：`C_L(t)=∫e^{-Et}dν_L`、`ν_L≥0`（`Y01-KL:91`）；这是**时间向/零空间动量**的正性。靶要 `W_a` 上**逐点**定号（4D、含空间分离）；空间分离的核由 `e^{i p·x}` 变换给出，**没有**逐点号（`HS-L3-9:20` 的"符号盲"即此）。
- 自由场见证：正性成立、F-class `K=1`，而 C-class `K→∞` ⇒ 正性既不蕴含也不排除 `K`；Schur 型（PSD/二次型）与 `L¹/L¹` 比不同层。
- **判**：`[NG]`（作用域不含）。**下一手**：正性只用于 `(★)` 轴，不再用于 `K`。
### 2.3 (c) 反例（C-class）
- 自由场（`HX1-RHOG:0.5` 的同一核）：`C_2^{ren}=c|z|^{-8}` 在 `W_a` 上（接触 c-数只在 `δ` 支）：
```
M = ∫_a^L c r^{-8}·2π²r³dr = (π²c/2)(a^{-4}−L^{-4})
A = |∫C_2^{ren}| = (π²c/2)L^{-4}      （c'=0；p=0 的减除只动有符号矩）
K_a = M/A = (L/a)^4 − 1 → ∞
```
- **密度读法**（把 `c₂` 当常数加进 `C_2`，不取 `δ`）：`c₂=m_a+O(L^{-4})` 时 `P≈N≈(π²c/2)a^{-4}`、`|P−N|=A=O(1)` ⇒ 同幂 `K_a≍(L/a)^4`。**两读法同幂**，只有常数不同。
- **判**：`[T]`（否证 C-class 的 `K` 有界）。**下一手**：位置图把 C-class 注销；F-class 才是 `K` 的载体。
## §3 ★ 蕴含关系
### 3.1 `K⟹ρ≥c`？否
- profile（谓词层，不声称来自 Gibbs 测度）：`C_2^{ren}=a⁴|h|`（`h=|z|^{-8}`）在 `W_a` 上：
```
ρ² = sup |a⁴|h||/|h| = a⁴ ⇒ ρ=a²→0
M = ∫ a⁴r^{-8}2π²r³dr = (π²/2)(1−(a/L)^4) ;  A=M ⇒ K=1
A → π²/2 =: C（R3 成立：A≤C，C 与 a 无关）
S = M/ρ = (π²/2)(1−(a/L)^4)·a^{-2} → ∞
```
- ⇒ `K=1 ∧ R3` 而 floor 假、`S` 散。**`K` 对 `ρ` 无信息**。**下一手**：floor 写成独立缺件（`ρ^{ren}≥c`），不得由 `K` 导出。
### 3.2 `ρ≥c ⟹ K`？否
- 自由场 C-class（§2.3）：floor `=√c` ✓、`A=(π²c/2)L^{-4}≤C` ✓、`K=(L/a)^4−1→∞` ⇒ 反向亦断。**下一手**：两条独立性都进缺件表（`K` 与 floor 互为独立）。

### 3.3 三件是否可缩
- 充分包 `K∧R3∧ρ≥c ⇒ S≤KC/c` 是**代数**（`S=M/ρ≤KA/ρ≤KC/c`，`[T]`）；3.1/3.2 给 `K` 与 floor 双向独立，3.1 还给 `K∧R3⇏S<∞` ⇒ **三件不缩成两件、也不缩成一件**。
- 唯一能缩的是**表述**：把 `K` 写成 `∃`-scheme（F-class），自由场三项同时成立 ⇒ 该包非空；但 `∃` 号不减弱相互作用侧的缺件。
- **下一手**：`L3` 充分包按 `∃`-scheme 重述；相互作用侧只攻 `r>r₀` 上 `C_2−c r^{-8}` 的定号（0 阶，比 `(★)` 少一个导阶与整座量词塔）。
