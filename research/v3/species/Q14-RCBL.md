## 1. 拆分：`Hess V = Hess S_W + Hess Φ`，`K_+` 到底能有多大

### 1.1 逐方向恒等式（`[T]`）

```
K(v,x) := N/4 + ⟨v, Hess S_W(x) v⟩ + ⟨v, Hess Φ(x) v⟩ ,      ‖v‖=1
```
- `N/4` = `Ric(v,v)`（`SU(N)` Einstein，`O08 §4.1`，witness `q4_bakry_emery.py:151,153`，偏差 `1e−15`）`[T]`
- `Hess S_W` **不定**：`λ_min = −g|B|`（连续，`H1E`）；格点上 `min H_vv = −1.893`、`max = +1.248`、`frac(H_vv<0)=0.600`（`O06 §1.3`，120 随机图，`β=2.5`）`[C]`
- `Hess Φ ⪰ (N/12)I`：**全方向、点态、与 `ξ`/`β`/测度/`a₀` 无关**（`O06 §3.1`，数值 `inf Φ''=0.16666603`，差 `4e−7`；横向 `Φ''_⊥=g'(ρ)/ρ≥1/6`）`[T]`

⇒ **逐方向确定性下界**（这是任务问题 1 的答案，无假设）：

```
K ≥ N/3 − 1.893 = −0.893   (SU3)        K_+ ≥ 0
K ≥ 2/3 − 1.893 = −1.226   (SU2)        K_+ ≥ 0
```
并且**这个下界是锐的**：`O06 §1.3` 的见证图上 `⟨v,Hess S_W v⟩=λ_min` 与 `Hess Φ` 的下界可同时取到（`Φ` 的下界在 `ρ→0` 取到，`Hess S_W` 的负部在对齐 `Re tr(U_pK_p)/tr K_p = −0.267` 取到；两者不互斥）。**故 `ess inf K = −0.893`，`ess inf K_+ = 0`，且 `K_+ ≡ 0` 在坏集上。** `[T]`

### 1.2 三个必须分辨的"下界"

| 量 | 值（SU3，`β=2.5`） | 用途 | 判 |

## 3. `Σθ_j`：定义、数、以及为什么"`<1`"是错的资源

### 3.1 `θ_j` 的唯一可核定义

```
P₋(x) := 负模谱投影（Hess S_W 的本征值 < 0 的部分）
θ(x)  := ⟨v, P₋(x) v⟩ ∈ [0,1]        （固定粗模 v 的负模权重）
Σθ_j := E_{μ_a}[θ]（= 坏集质量的上界）；ess sup θ = 最坏配置的坏集质量
```
**这是 `o08` (R2) 里 `E[K_−|∇f|²]` 的谱版本**；也是 `o16` 的 `c²` 的直接推广（`O16` 的 `C_k = c_k²Var` 用的正是 `c_k²`）。

### 3.2 三个数

| 来源 | `θ` | 标签 | 说明 |
|---|---|---|---|
| `O16` 赤道切片 `c²=(½,0,½)` | **0.500000000**（15 位） | `[T]` | `e₃=(ê₊−ê₋)/√2` ⇒ `θ≡½` 对所有 `x` 成立，**不是统计值** |
| `O16 §5b` 负模计数 + 均分假设 | `E[θ]=E[n₋]/3=1.476/3=0.492` | `[M]` | 均分是假设（未测 `⟨v,ê_j⟩²` 于非切片窗口） |

⇒ **`Σθ_j ≈ 0.49–0.5`（均值，与任务的 `θ≈0.5` 一致），但 `ess sup = 1`。** `[T]`（精确窗口）+ `[M]`（均分）+ `[C]`（上确界）。

### 3.3 为什么 `Σθ_j<1` 买不到东西（本轮的结构性判词，`[T]`）

`κ̄ := (E[1/K_+])^{−1}`。设坏集质量 `θ`、其上 `K_+=\varepsilon`、其余 `K_+≈K₀`：

```
E[1/K_+] = θ/ε + (1−θ)/K₀   ⇒   κ̄ = [θ/ε + (1−θ)/K₀]^{−1}   →   ε/θ → 0  (ε→0)
```
- `θ=0`（无坏集）：`κ̄ = K₀`，与算术平均实测只差 **0.30%**（§6.1）⇒ 调和 vs 算术在此**无关紧要**。
- `θ>0` 且 `ε=0`：`κ̄ = 0`，结论 `Var ≤ ∞`，**vacuous**（`o08` 猜想形式直接失效）。
- `θ>0`、`ε` 小但非零：`κ̄ ≲ ε/θ`，**界按 `1/ε` 退化**。

⇒ **`Σθ_j<1` 是截断型（truncated / `K^{(ε)}`）的正确预算；对调和平均型是错配资源。** `o08` 的 (R2)（负曲率预算 `c<1`）是截断型的语言，但它被写进了 (R1) 的调和平均旁边——**两者不配套**。这是对 `o08 §3.1` 的一条实质修正。

### 3.4 `(R2)` 直接检验：失败因子与 `c` 同源

`K_− ≤ d = 1.893`（`O06 §1.3`）且坏集质量 `≤1` ⇒
```
E[K_−|∇f|²] ≤ d·E|∇f|² = 1.893 E|∇f|²    ⇒   需 c ≥ d/κ̄ ≥ d/F = 1.893/1.000 = 1.893 > 1  ⇒ (R2) 失败
```
**同一个比值 `d/F = 1.893`（原始读数）/ `0.947`（÷2 读数，此时 `(R2)` 尚可容）在三条路上都以"差 `d/F` 倍"出现**：经典 `κ`、调和平均、`(R2)` 预算。⇒ **这三条路不是三个独立障碍，是同一个数。** `[T]`

## 4. 判词：`(a)` / `(b)` / `(c)`

### (a) `Σθ_j<1` 可证 ⇒ 猜想成立？ —— **不可得**
- 精确值只有 `θ=½`（`O16` 窗口）与 `ess sup θ = 1`（12% 全负图）`[T]/[C]`；**一致界 `<1` 不成立**。
- 更根本：**即使 `<1` 成立也不够**（§3.3，`ε→0` 使 `κ̄→0`）。⇒ **(a) 关闭**，且关闭的原因不是预算不够，是**资源用错**。

### (b) `Σθ_j ≥ 1` ⇒ 缺什么 —— **成立（这是主判之一）**
`ess sup θ = 1` ⇒ 需要（按代价排序）：
1. **`v` 的谱限制**：把粗模限制到 `⟨v,P₋v⟩ ≤ θ_max < 1` 的子空间。数据支持：负部 `90–97%` 在 UV/涨落块（`O08 §4.2` 引 `W6-BE`），而物理粗模是 IR ⇒ **这条有物理依据，是本轮最可行的一条**。`[C]`
2. **把 `K_+` 换成 `K^{(ε)}=max(ε,K)` 并显式付坏集项**（§5 的 RC-BL(ε)）。
3. **坏集上换机器**：`Cheeger λ₁ ≥ h²/4` 不读 `Γ₂`、不要求 `κ` 任何符号（`O18-CHEEGER`；`O08 §6(c)` 已列）⇒ 在坏集上它是正确的配对工具。
4. **`E[H_vv]` 在一般窗口未测**（`O06 §1.3` 只给 `min/max/frac`）：连目标右端的**符号**都未知 ⇒ 必须补测（同一 120 图上的 `E[H_vv]`、`Var(G_v)`）。`[C]` 缺口

### (c) `K_+` 下界为负 ⇒ 猜想的该形式不适用 —— **成立（主判之二），给修正形式**
`ess inf K_+ = 0`（原始读数）/ `ess inf K = +0.0535`（÷2 读数，余量仅 5.6%）。且**即便 `c>0` 也落不到目标**：`K≥c` ⇒ `CD(c,∞)` ⇒ **范数型**输出（`O08 §2.3` 墙）。

**修正形式（本轮提出，`[C]` 未证）**：

> **RC-BL(ε) —— 截断型定向随机曲率 BL**
> 设 `K^{(ε)} := max(ε, K)`，`κ̄_ε := (E_{μ_a}[1/K^{(ε)}])^{−1} ∈ (0,∞)`，坏集 `B_ε := {K ≤ ε}`、`θ_ε := μ_a(B_ε)`。则
> ```
