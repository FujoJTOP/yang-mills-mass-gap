## 2. `SU(2)`、`θ=π`：`E[H_vv]=0` 是**精确恒等式**

```
X = x·σ/2,  x₃ = 0 (切片 a = 2tr(EX) = 0),  v = e₃,  λ = (0,0,1)
H_vv(x₃=0) = β cos(θ/2) · sin u/(4u),     u = |x|/2                       [T]
θ = π  ⇒  cos(θ/2) = 0  ⇒  H_vv ≡ 0   逐点
```
两项来源：`cos(φ−x)` 项的 τ 二阶导给 `βc·sin u/(4u)`；`sin(φ−x)` 项**在 `x₃=0` 上对 τ 是奇函数**（`≈ sinφ·sin u·τ/r`），二阶导在 `τ=0` 恰为 0。故 `θ=π` 只剩前者，而前者 `∝c`。

数值（`[A]`，`u,ψ` 网格 400×200，切片 Haar 权重）：
| `θ` | `E[H_vv]` FD | `E[H_vv]` 闭式 | 差 |
|---|---|---|---|
| `π` | `−4.51e−10` | `+2.36e−17` | `4.5e−10`（差分截断） |
| `0` | `+0.5149315278` | `+0.5149315252` | `2.6e−09` |
| `0.7π` | `+0.2071387539` | `+0.2071387518` | `2.1e−09` |

⇒ **`0` 是恒等式，不是数值小量**；`h1a`/`o15`/`v06`/`v04 §4`（"`0`（精确，中心元）"）一致。**判"精确"成立 `[T]`。**

**旁注 `[E]`（不影响本例）**：`θ=0` 的锚点我复现 `0.5149315`，`p05 §2` 记 `0.553061`。差 3.8e−02 来自测度的 `1/u`：`p05 §3.1` 的 `ν_B ∝ sin²u e^{−B(1−cos u)}du/u`，我这个是切片 Haar `sin²u du`。`θ=π` 时 `H_vv≡0`，任何测度都给 0，故不动裁决；但 `p05` 的 `G(B)`/`c(β,θ)` 数值表在 `θ=0` 侧偏高（`⟨A₀⟩`：`0.442448` vs Haar `0.20597·2`），标 `[E]`。

## 3. `SU(3)`、`θ=π`、`β=2.5`：`E[H_vv] = +0.102302193`

**关键结构（`[T]`）**：`φ=(π,π,0)` ⇒ `cos(φ_j−x_j) = −cos x_j`（`j=1,2`）、`+cos x_j`（`j=3`），于是

```
H_vv(λ) = (β/3)[ −λ₁²cos x₁ − λ₂²cos x₂ + λ₃²cos x₃ ]
⇒ E[H_vv] = (β/3)[ λ₃² c₃ − λ₁² c₁ − λ₂² c₂ ],     c_j := ⟨cos x_j⟩_w     ← 对 λ 【线性】
```
即 **三个数 `c_j` 定全部 `v`**。实测（`[C]`，`[C]` 段 N=2048 中点，收敛到 1e−12）：

```
c₁ = −0.5107755260    c₂ = +0.8648193714    c₃ = −0.3880128944
```

**`v = diag(1,0,−1)`（`s02`/`v04`/`r12` 用的那个）**：

| 方法 | `E[H_vv]` | 误差/宽度 |
|---|---|---|

区间只包住**中点和**（真外舍入），求积截断未作严格界 ⇒ 与 `v04`/`s02` 同口径标 **`[C]`，不是 `[T]`**。

## 4. `v04` 的 `−0.1023` 是什么（`(a)` 的答案）

它的链是 `G = (β/3)Σλ_j sin(φ_j−x_j)`、`H = d_τG = −(β/3)Σλ_j²cos(φ_j−x_j)`。**恒等式 `H = d_τG` 正确**，错在 `G` 不是 `∂_τS_W`：

```
∂_τS_W = −(β/3)Σ λ_j sin(φ_j−x_j)  =  −G_v04      ⇒  H_v04 = ∂_τG_v04 = −∂_τ²S_W = −H_vv
```
`s02_su3_2dcert.py` 的 docstring 原文已自认：「`G=(beta/3)sum lam_j sin(...)` ⇒ `H=d_tau G = -(beta/3)sum lam_j^2 cos(...)`（r08/r12 用 `H=+...`；**与它们自己的 `G` 不自洽** —— 本脚本两个分支都算）」。

**`v04` 自己写了后果**（`V04-SU3SPLIT.md:7`）：「换到 `s02` 的 `H=+(β/3)Σλ²cos` 支，`E[H]→+0.102302`、`gap→+0.102092`」——**它的 `gap<0` 头条随分支翻号**。故：
- `v04` 的 `E[H_vv] = −0.102302` **量值对、符号错**：它算的是 `−∂_v²S_W`。
- `v04` 的 `gap = −0.10288` 结论**在规范支上不成立**（规范支给 `gap = S − D = +0.102092`）。
- 这不改变 `v04` 的另一半（`Φ` 半边 `W_full = +0.0762`、`Var(Φ′)=6.81` 主宰 `D`）——那部分只依赖 `|H|` 与 `Φ` 项，与 `H` 的号无关。

## 5. `p05` 的 `[T]` 洞在哪（`(b)` 的答案：`(b)` 不成立，但 `[T]` 不可外推）

`p05 §1.2` 的链是：`H_vv = β·Q`、`Q = cos(θ/2)·g(u)/2`、`g>0` ⇒ `Q ≥ 0 ⟺ c ≥ 0` ⇒ `E[H_vv|0] = β(c/2)G(B) ≥ 0`。

**这个 `c`-分解是 `N=2` 的恒等式**：`c=cos(θ/2)` 只有在 `N=2` 才同时是**唯一的**背景相（`φ=(θ/2,−θ/2)`）；`O15` 的闭式 `E[H|0]=(β/N)[⟨A₀⟩+(1−c)⟨A₁⟩]` 里，`N=2` 靠 `A₁=−A₀` 才合并成 `c⟨A₀⟩`。`N≥3` 没有这个恒等式（`p05 §5.4` 自己列为"未做"）。

`SU(3)` 上 `c`-分解的失效可见于 `S_W` 本身：`θ=π` 时
```
S_W(x=0) = β(1 − (1/3)(−1−1+1)) = 4β/3 = 3.3333   ≠ β
```
⇒ **`p05`（及用户在题面里引的）"`θ=π` 切片上 `S_W ≡ β`" 只在 `N=2` 成立**（那里 `Σ_j cos φ_j = cos(π/2)+cos(−π/2) = 0`）。`SU(3)` 上 `S_W` 在 cell 内不是常数，`Σ_j cos(φ_j−x_j)=0` 只是一条曲线。

**但 `p05` 的结构性论断（"切片上 `S_W` 常数 ≠ `H_vv = 0`"）在 `SU(3)` 里确实存在，而且恰好在一个非退化切片上**（`[G]`）：
```
λ = (2,−1,−1)/√3  ⇒  ⟨λ,X⟩ = √3·x₁ ,  切片 x₁ = 0 (即 b = −2a)
该线上: x₂ = −a, x₃ = a,  S_W = β(1 − (1/3)(−1)) = 4β/3  【常数】
        H_vv = β(4 + 2cos a)/9 ≥ 2β/9 > 0    逐点
        E[H_vv | x₁=0] = +0.888889   （1D 求积 2e5 点；exp 因子在线上是常数，约掉）
```
⇒ **用户的判断（3）正确**：`S_W ≡ const` **不**蕴含 `H_vv = 0`；`∂_v²S_W` 是离开切片的导数。

无迹 Cartan 全线扫（`Σλ=0`、`‖λ‖²=2`，用 §3 的线性式，3601 点；`[F]`）：

## 7. 两个量各自在什么 `v`/测度上（`(c)` 的定义表）

| | `p05` 的 `E[H_vv]` | `v04` 的 `E[H_vv]` |
|---|---|---|
| `N` | **2**（`SU(2)`，全 `su(2)` 3 维） | **3**（`SU(3)`，仅 2D Weyl cell / Cartan） |

## 8. 判死线

**判 `(a)`（对 `v04`）+ `(c)`（对两者）；`(b)` 不成立。**

- **(a) 成立的部分**：`v04` 的 `−0.102302` **不是 `E[H_vv]`**，是 `−E[H_vv]`。它算的是 `E[−∂_v²S_W]`（`G` 取了 `−∂_τS_W` 的符号）。规范支下 `E[H_vv] = +0.10230219 ≥ 0` ⇒ `v04` 的 `gap<0` 头条与 `E[H_vv]` 的负号**同时作废**（`v04:7` 自己给了 `gap=+0.102092`）。
- **(b) 不成立**：不存在"`E[H_vv] = −0.1023 < 0` 而 `p05` 的 `[T]` 有洞"的情形；`G ∈ (0,1/2)`、`c ≥ 0` 的论证在它自己的窗口内**无洞**。
- **(c) 同时成立**：`p05` 的 `0` 与 `v04` 的 `0.1023` **不同 `N`、不同 `v`、不同测度**（条件切片 vs 无条件 cell），且 `p05` 的条件化在 `SU(3)` 的 2D Weyl frame 对简单根方向退化（`|Δ|²≡0`）。
- **必须改写的两处**：① `p05`/`LOOP-RUNBOOK §11.111, §11.116` 的 `E[H_vv] ≥ 0`（`θ ≤ π`）须限定 **`N=2`**——`SU(3)` 上实测范围 `[−1.08439, +0.25988]`，变号。② `V04-SU3SPLIT.md:3, 32, 97` 与 `S02` 的 `H` 分支须改为 **`H_vv = +(β/3)Σλ²cos(φ−x)`**；`[C]` 数字保留、符号翻转。
