## 1. 第 1 问：`Φ` 与 `Φ_r08` 的代数差（`[T]`）

`O09/q11` 的 `Φ`（指数坐标 Jacobian）与 `r08` 的 `Φ`，**逐对**：

```
g(d)        = −2 log[ sin(d/2) / (d/2) ] = −2 log sin(d/2) + 2 log d − 2 log 2
Φ_r08^{(1)} = −log(4sin²(d/2))          = −log 4 − 2 log sin(d/2)
g − Φ_r08^{(1)} = 2 log d − 2 log 2 + log 4 = 2 log d = log d²        （log4 = 2log2 精确抵消）
```

⇒ 求和后

```
Φ_O09 = Σ_{i<j} g(d_ij) = −log|Δ|² + Σ_{i<j} log d_ij² ≡ Φ_r08 + ψ ,
ψ := Σ_{i<j} log d_ij² ,     常数项 = 0  （不是"加上常数"）
```

`[T]`（sympy `logcombine/simplify → 0`；`s08_psi.log [1]`）。**`r12` 的 `ψ = Σlog d²` 核准；且常数恰好为零**——因为 `−2log2` 与 `−log4` 来自同一 `d/2`，这是 `g` 与 `−log4sin²` 同源的必然结果。

**等价的几何写法（供 (c) 用）**：

```
e^{−Φ_O09} = |Δ|² e^{−ψ} = ∏_{i<j} 4sin²(d/2)/d² = ∏_{i<j} [ sin(d/2)/(d/2) ]²
```

⇒ `Φ_O09` 的 Gibbs 权 = **纯指数映射 Jacobian，Vandermonde 被完全吸收**；`Φ_r08` 的权 `|Δ|²` = "Vandermonde 全留、Jacobian 全丢"。`ψ` 就是这两者之间的换算因子。

## 2. 第 2 问：`ψ′`、`ψ″`（`[T]`）

`v` 的方向：`τ: θ ↦ θ+vλ`，`λ∈t`（`Σλ_i=0`）。于是 **`d_ij` 对 `v` 仿射**：`d_ij(v) = d_ij + v a_ij`，`a_ij := λ_i−λ_j`（`r08` §2 / `r12` §2 的 `Φ′=Σg′(d_p)(λ_i−λ_j)` 就是这个事实）。

```
ψ(v)  = Σ_{i<j} log(d_ij + v a_ij)²
ψ′(v) = 2 Σ_{i<j} a_ij / d_ij(v)                = 2 Σ a_ij/d_ij
ψ″(v) = −2 Σ_{i<j} a_ij² / d_ij(v)²             ≤ 0   逐点（实数 a）
```

sympy：`ψ′ = 2a/(av+d)`、`ψ″ = −2a²/(av+d)²`（`s08_psi.log [3]`）。

配套的 `Φ_r08` 导数（`r08` §2，独立复算一致）：`Φ_r08′ = −Σ a cot(d/2)`、`Φ_r08″ = ½Σ a²csc²(d/2)`、`Φ_r08‴ = −½Σ a³csc²(d/2)cot(d/2)`。
注意 **`ψ″ ≤ 0` 而 `g″ = ½csc²−2/d²` 在 `d→0` 时 `→ 1/6 > 0`**：`ψ` 正是把 `Φ` 的 `v`-凸性从 `Φ_r08` 的"逐点凸"扭成 `g` 的"小 `d` 凸 / 大 `d` 凹"。这就是"使 `Φ` 非二次"的定量内容。

## 3. 第 3 问：`E[Φ′²]=E[Φ″]` 的**真因**（`[T]`，前提被推翻）

**`Φ_r08` 不是 `v` 的二次函数。** `Φ_r08‴` 在 `(d;a)=(1.1;1),(1.7;1),(2.8;2)` 三点之和 `= −4.473687 ≠ 0`（`[4]`）；`csc²cot` 不可能恒零。⇒ 用"二次性 ⇒ `Φ′²≡Φ″`"解释恒等式**不成立**。

**真因（更强、更普适）**：`r08` 的测度就是 `Φ_r08` 自己的 Gibbs 测度，`w := |Δ|² = e^{−Φ_r08}`。

```
∂_v² w = w (Φ′² − Φ″)      ⇒   ∫_T ∂_v² w dθ = 0（w 在 v-平移下周期性/不变）
                            ⇒   E_w[Φ′²] = E_w[Φ″]      对任意光滑 w 成立
```

即这是 **Stein/IBP 恒等式**：`E_w[Φ″] = E_w[V′Φ′]`，取 `V = Φ` 立即得 `E[Φ″]=E[Φ′²]`。**与 `Φ` 是不是二次的毫无关系**——只要是"自势（self-potential）"就成立。这也解释了 `r12` 的 `∫|Δ|²(Φ′²−Φ″) = ∂²_τ∫|Δ(θ+τλ)|² = 0`。

**数值确认（`s08_psi.log [5]`，中点网格，权 `|Δ|²dθ`，`λ=(1,0,−1)`、`N=1536`）**：

```
E[Φ_r08″] = 8.000000    E[Φ_r08′²] = 8.000000    E[Φ_r08′²]−E[Φ_r08″] = −2.7e−15
E[Φ_r08′] = 3.3e−17 （平移不变的另一面）
```

⇒ `[T]+[C]`：恒等式 = **自势/平移不变**，不是二次性。**`Φ_r08` 的"二次"标签必须撤掉**（若 `r08`/`r12` 某处按二次性论证，那一步要重写；本次核到的 `r12` 正文只用了平移不变，未用二次性 ⇒ `r12` 无此错）。

**`ψ` 的定位（照任务的话说）**：`ψ` 不是"使 `Φ` 非二次的那部分"（因为 `Φ_r08` 本来就不二次），而是**使测度不再是自势**的那部分：`e^{−Φ_O09} = e^{−Φ_r08}·e^{−ψ}`。`ψ` 让"权"与"势"错位——这才是恒等式破缺的机制。

## 4. 第 4 问：`gap` 的精确拆解与符号（`[T]` 代数 + `[C]` 数值）

记 `V := Φ_r08`、`Φ := Φ_O09 = V+ψ`、`E := E_w`（`w=|Δ|²`）。由 `E[V″]=E[V′²]`、`E[ψ″]=E[V′ψ′]`（同一 IBP）、`E[V′]=0`：

```
S − D = E[Φ″] − Var(Φ′)
      = E[V″] + E[ψ″] − [E[V′²] + 2E[V′ψ′] + E[ψ′²] − E[Φ′]²]
      = −E[V′ψ′] − E[ψ′²] + E[Φ′]²
      = −Cov(Φ′, ψ′)                        (§4.1)
      = −E[ψ″] − Var(ψ′)
      = 2 Σ_{i<j} E[a_ij²/d_ij²] − 4 Var( Σ_{i<j} a_ij/d_ij )        (§4.2)
```

`[T]`（代数；三项在数值上互证到 `≤1e−6`，`s08_psi.log [5]`）。

### 4.1 一句话判据（"新的等价判据"，逐字）

> **在 `r08` 的 `|Δ|²dθ` 测度下，对 `λ∈t`：`S−D = −Cov(Φ_O09′, ψ′)`。**
> 所以 **`S−D = 0 ⟺ Cov(Φ′,ψ′)=0 ⟺ ψ′ 与正确 score `Φ′` 不相关**；`ψ′≡const`（当且仅当 `a_ij≡0`，即 `λ∝(1,1,1)`，**违反 `Σλ=0`**）只是它的一个充分情形。
> **`S−D ≤ 0 ⟺ Var_w(ψ′) ≥ −E_w[ψ″] = 2Σ_{i<j}E_w[(λ_i−λ_j)²/d_ij²]`。**

右边只含 `{1/d_ij}`（不是关联函数、不是 Hessian 谱、不含 `G`、不含 `Φ_r08`）⇒ 这是一条**单函数（`ψ′`）的 Poincaré 型不等式**，是 `H1`/`G″>0` 的一条**窄化判据**：`H1` 若真，先得让这条对 `λ` 一致成立。**注意它是 `≥` 方向（`Var ≥ 二阶矩`），比通常的 Poincaré（`Var ≤ ...`）反向**——这正说明 `r08` 路线"白拿正性"不可能。

## 5. 判死线逐条

### (a) **修正版：成立一半，另一半被推翻**

- **`[T]` 成立**：`ψ` 是 `gap≠0` 的**唯一**来源。精确式 `S−D = −Cov(Φ′,ψ′) = −E[ψ″]−Var(ψ′)` 里**没有 `G`、没有 `H`、没有 `Φ_r08` 的残项**。所以"`r08` 的恒等式只能被 `ψ` 打散"是准的。
- **`[T]` 推翻**：前提"`Φ_r08` 是 `v` 的二次函数"**假**（`Φ_r08‴≠0`）。恒等式来自**自势/平移不变**这一更强事实，`ψ` 的作用是**让权与势错位**（`e^{−ψ}` 倾斜），不是"破坏二次性"。
- **`[T]`+`[C]` 修正**："`gap` 的符号完全由 `ψ` 决定"须写成：符号由 `ψ` 的**两个矩** `E[ψ″]` 与 `Var(ψ′)` 的**竞争**决定，**没有定号**；同测度下 `λ=(1,0,−1)` 为负、`λ=(1,−1,0)` 为正 ⇒ **不存在"`ψ` 一劳永逸给出 `S≤D`"的判据**。
- **可用的新等价判据（逐字，见 §4.1）**：`S−D ≤ 0 ⟺ Var_w(ψ′) ≥ 2Σ_{i<j}E_w[(λ_i−λ_j)²/d_ij²]`，即 `ψ′` 在 Vandermonde 测度下满足一条**反向**（`Var ≥ 二阶矩`）单函数不等式。

### (b) **成立：恒等式被打散成"有序的差"——一次指数倾斜**

`e^{−Φ_O09} = e^{−Φ_r08}·e^{−ψ} = |Δ|²·∏ d_ij^{−2}`。`ψ` 就是**换测度**的 Radon–Nikodym 对数密度。于是

```
S−D = −Cov_w(Φ′, ψ′) = −[ 倾斜引起的 score-相关 ]
     ↘ 分解 1（Girsanov/Stein）   : −E_w[ψ″] − Var_w(ψ′)
     ↘ 分解 2（"能量 vs 涨落"）   : +2ΣE[a²/d²]  −  Var(ψ′)        ← 有序差：正项 − 正项
```

`−E[ψ″] = 2ΣE[a²/d²] ≥ 0` 是**确定的非负项**（`ψ″≤0` 逐点），`Var(ψ′)≥0` 是对抗项。所以差是"**整流项 − 涨落项**"的竞争，而不是"`ψ` 一出现就变负/变正"。`[T]` 代数，`[C]` 数值。

### (c) **成立：`ψ` 就是几何量（且正是 `d` 的量）**

1. **重合点正则化项**：`d→0` 时 `Φ_r08^{(1)} ~ −log d² → +∞`，`ψ^{(1)} = log d² → −∞`，**精确相消**（§1 的 `log(1)`），使 `g(0)=0`。`ψ` = 使 `Φ` 在 `d=0` **正则**的那部分。`[T]`
2. **弦长↔测地线换算**：`|Δ|²=∏|z_i−z_j|²`（弦），`∏d_ij²`（测地），`ψ = log(∏d²)`；`e^{−Φ_O09}=∏[sin(d/2)/(d/2)]²` = **纯指数映射 Jacobian**。`[T]`
3. **`SU(2)` 为什么看不见**：`SU(2)` 的 Weyl 胞只有**一个**角 `θ` ⇒ 无 `i<j` 对 ⇒ `ψ≡0`（`Φ_r08` 与 `Φ_O09` 同为零/同差常数），恒等式与"二次性"都无从暴露。**这是"`SU(2)` 上二者只差常数"的代数根源**（与 `r12` §4(b)-2 一致）。`[T]`
4. **平坦极限**：`d` 小 ⇒ `ψ ≈ 2Σlog d` 是**自由（`R³` 平直）拉普拉斯**部分，`Φ_r08` 只剩紧致（正弦）部分 ⇒ `ψ` 是"平直几何内容"，`Φ_r08` 是"曲率内容"。酸测（自由场）若要对 `ψ` 失效，须在 `d`-小端；这正是 `ψ″` 与 `Var(ψ′)` 在 `d→0` 处都被 `1/d²` 支配的原因。`[C]`
