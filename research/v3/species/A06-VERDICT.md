## §2 ★关键：有没有一条**不是扩窗**的？

**有，恰好两条形态；两条都不是"证明路线"。**

### 2.1 (A) 单点 `P1`：`L1` 的 Feshbach 余项界 —— `[C]`

```
(I)   I2@δ ⟺ Π⊥(H−m₀²−δ)Π⊥ − Γ(δ) ≻ 0 ,  Γ = 秩一耦合          [T]（L4B §1，N11 §1）
(II)  待补：‖Π⊥Hφ₁‖² ≤ C(1−f₁²)^θ ，且必须 L-一致                  [C]，现行写法不提供 L-一致
```

- **起点（1 h 探针，已写成可执行判据）**：`L4B §7 序 1` —— `L=2, SU(2), β=2.5`，扫 `(1−f₁², ‖Π⊥Hφ₁‖)` 散点；**同一散点在 `L=2,4,6` 重复**，斜率 ≤0 ⇒ `(II)` 假；有界但 `L`-不一致 ⇒ 2.5 上的产出仍 `[X]`。
- **缺件（两件，都承重）**：① `(II)` 的 `L`-一致版；② `f₁²@2.5>0`（P3 只在窗内 `[T]`，2.5 只有 `[E]`，`L4B §1.2`）。
- **难度**：探针 = 工程（1 h，`L=2,4,6` 小体积）；**承重件 = 新机器**（`(II)` 是算子范数界，不是现有不等式的收紧）。
- **判**：`[C]`。它**不是**扩窗，但它的**有限 `L` 版**交付的 `I2` 已 `[X]`（空转 + 自由场也真），`L=∞` 版就是缺件本身 ⇒ **不能作为 A 路的出口**。

### 2.2 (B) 单点层距地板 + 判定器 —— `[O]` / `[E]`

```
靶：  inf_L ( m₂(L)² − m₀(L)² ) > 0        （m₂ = 0⁺⁺ 道次小谱点；β=2.5，a 固定）   [O]
```

## §3 判死线逐条（(a)/(b)/(c) 同时落判）
