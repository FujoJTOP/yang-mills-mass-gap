## §2 `I2 ⇒ H1` 判定

### 2.0 判据式：把两式放在同一条恒等式上（`[T]`）

`ν = f₁²δ_{m₁²} + μ`，`supp μ ⊂ [Λ★,∞)`。于是（`m₁²>0` 时）

```
χ = ∫₀^∞ s⁻¹dν = f₁²/m₁² + ∫_{[Λ★,∞)} s⁻¹ dν                                    (HN2-0)
  ⇒  f₁²/m₁²  ≤  χ  ≤  f₁²/m₁² + (M₀−f₁²)/Λ★  ≤  f₁²/m₁² + M₀/Λ★
```
（两边都逐字对得上语料：左端 `Q6:110–111` 逐字 `χ = f₁²/m₁² + ∫_{≥Λ★}s⁻¹dν`；右端的"`m₁²≥λ ⇒ χ≤M₀/λ`"即 `ch02:94–97` 的必要性定理。）

**⇒ 判据**：`I2`（`Λ★ ≥ m₁²+δ`）能约束的**只有第二项**：`∫_{[Λ★,∞)} ≤ M₀/Λ★ ≤ M₀/(m₁²+δ)`。**第一项 `f₁²/m₁²` 完全在 `I2` 的视野之外**（它是"位置 × 权重比"，不是"距离"）。要把 `HN2-0` 合起来压到 `(1−c)/λ` 以下，必须**另外**有
```
(A) 位置地板  m₁² ≥ c_pos > 0        ← 不在 I2 里（内置 2），是靶的投影
(B) 权重比控制 f₁²/m₁² ≤ 某上界      ← 与 I2 无关，且见 §2.1 的符号定理：矩数据给的是反向
```
**(A)+(B) 就是 `H1` 的另一半内容，不是 `I2` 的推论。** 三条路线逐一判。

### 2.1 路线 (a)：直接（矩-隔离引理 → 把 `Λ★` 译成 `χ`/`λ`）——`[NG]`

**(a1) 符号定理（HN2-1，`[T]`）：引理的输出进的是 `χ` 的分子。**
```
矩-隔离引理（GM6:161–163 / IMP-ARROWS:66 / R2 Lemma D）：若 Λ★ > R̄ := M₁/M₀
   ⇒  f₁² ≥ r₀ := (Λ★M₀ − M₁)/(Λ★ − m₁²) > 0
配合 HN2-0 左端：      χ ≥ f₁²/m₁² ≥ r₀/m₁²                                    (HN2-1)
```
⇒ **`r₀` 越大，`χ` 越大。** 任何"用引理把 `Λ★` 变成 `f₁²` 的信息、再推 `χ` 的上界"的链条，方向都是反的：引理是**地板机**，`χ` 的上界是**天花板命题**，而 `f₁²` 在 `χ` 里带**正号**。这与 `GM6-2`（正性机只能给 `f₁²` 上界，`GM6:147–155`）是同一现象的对偶侧：**`f₁²` 的每一台机器都在 `χ` 的错误一侧。**

**(a2) 阈值错位（HN2-2，`[T]`）：引理的前件严格强于 `I2`。**
```
R̄ = M₁/M₀ ≥ inf supp ν = m₁²  （均值 ≥ 下确界）
⇒ {Λ★ > R̄} ⊊ {Λ★ > m₁²} = I2            （单向：引理正性 ⇒ I2；反向假）
```
反向的显式见证（本机精确算术）：`ν = δ₀ + δ₁ + (1/100)δ₁₀₀₀`
```
M₀ = 201/100 ,  M₁ = 11 ,  R̄ = 1100/201 = 5.4726…
Λ★ = 1 ,  m₁² = 0  ⇒  I2 余量 = 1 > 0  ✓ ,  f₁² = 1  （真原子）
引理下界 = (Λ★M₀ − M₁)/(Λ★ − m₁²) = (201/100 − 11)/1 = −899/100 = −8.99   ← 负
```
⇒ **任务书"已知"里的 `严格性 ⟺ 隔离` 只有 `⟹` 成立**；`⟸` 被上表与 `R2:112–114`（"side condition `Λ★>R̄` is load-bearing"）以及 `GM6-OVERLAP` 自己的 `§2.4`（`:179–181`，`ε=0.1`：`Λ★=4>m₁²=1`、矩下界 `−0.65`、真值 `f₁²=0.1`）三重否证。

**(a3) 引理取等点上的见证（最有利于本路的一点，仍然死，`[T]`）。**
```
ν = δ₀ + δ₁ ：  M₀=2 , M₁=1 , Λ★=1 , m₁²=0 , f₁²=1 , I2 余量 = 1 > 0
引理：Λ★=1 > R̄=1/2 ✓ ；下界 = (1·2 − 1)/(1−0) = 1 = f₁²   ← **逐点取等**（引理在此最锐）
而 χ = 1/0 + 1/1 = +∞                                       ← H1 最大程度地假
```
⇒ **即便引理在等式处被"完美"使用，`H1` 仍可假到 `χ=∞`。** 这不是"引理不够紧"，是**引理与 `H1` 不同槽位**。
