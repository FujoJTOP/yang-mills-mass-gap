## §1 `T² − mT ⪰ 0` 到底是什么意思

### 1.1 读法 B（规格原读法）`[T]`

`T = T* ⪰ 0`（无界、正）⇒ 逐谱点 `t ≥ 0` 上

```
T² − mT = T(T − m) ⪰ 0  ⟺  t(t − m) ≥ 0 ∀t ∈ spec(T)  ⟺  t = 0  或  t ≥ m
                        ⟺  spec(T) ∩ (0, m) = ∅
                        ⟺  T ⪰ m  on (ker T)^⊥
                        ⟺  −Δ_{𝒜/𝒢} ⪰ m² · 1_{(ker Δ)^⊥}        （令 t = √s）
```

（`t = 0` 恒满足，故 `ker T` 自由；数值核对见 log §(B5)：随机 6×6 的 `T ⪰ 0`，`min eig(T²−mT)`、`min eig(T−m)`、`min eig(T²−m²)` 逐 `m` **同号**，翻转点 = `min spec(T) = 0.084122`。）

**⇒ 正确的读法**：这**不是"隙"**，而是**"轨道 Laplacian 的谱底 ≥ `m²`"**，且 `m` 是 `T` 的**谱底**，即 `T² − mT ⪰ 0 ⟺ m ≤ m* := inf{spec(T) ∖ {0}}`。**方向：给 `m` 上界。**

### 1.2 读法 A（`T = e^{−aH}`）——用户第 1、3 条的链条哪里断了 `[T]`

读法 A 下 `T² − mT` 的本征值 = `λ_n(λ_n − m)`，`λ_n = e^{−aE_n} ∈ (0,1]`，`λ₁ = max`（PF）。

| # | 用户写法 | 判定 | 修正（逐字） |
|---|---|---|---|
| 1 | `⪰0 ⟺ e^{−aE} ≥ m 对所有本征值 ⟺ E₁ ≥ −ln(m)/a` | **右边错** | `λ_n ≥ m ∀n ⟺ −aE_n ≥ ln m ⟺ E_n ≤ −ln(m)/a ∀n ⟺ **E_max** ≤ −ln(m)/a`。即 `m ≤ λ_min = e^{−aE_max}`，右端是 **UV 端**，不是基态。若"`E₁`"指基态，则不等式讲的是**最高态**。 |
| 2 | `λ_n ≤ λ₁²`，因 `λ₁ = max ⇒ λ_n ≤ λ₁`，又 `λ₁ ≤ 1 ⇒ λ₂ ≤ λ₁² ⟺ λ₂ ≤ λ₁` | **两处错** | (i) `λ₁ ≤ 1 ⟹ λ₁² ≤ λ₁`，方向反：`λ₂ ≤ λ₁²` **更强**，不等价；(ii) `λ₂ ≤ λ₁²` 本身**不自动**：见证 `λ = (0.8, 0.7)` ⇒ `λ₂≤λ₁` True 而 `λ₂≤λ₁²` False（log §(A4)，另 `(0.9,0.891)` 同）。 |
| 3 | "自动成立 ⇒ 给 `m = 0`（平凡）" | **对了一半** | 自动的是**反号**那一条：`λ_n² ≤ λ₁λ_n ⟺ λ₁T − T² ⪰ 0`（PF 直接推论）。被查的 `T² − λ₁T ⪰ 0` **为假**：`λ₁ = 1` ⇒ `T² − T = diag(λ_n(λ_n−1)) ⪯ 0`，整体差一个符号。 |

**数值（log PART I）**：`T² − λ₁T ⪰ 0` 在自由场/2D YM/M6 上全 `FAIL`（`min = −2.136e−1 / −2.325e−1 / −2.479e−1`）；`λ₁T − T² ⪰ 0` 全 `OK`（`min = 0.0`，取等于 `λ₁` 本身）；`T² − λ_min T ⪰ 0` 全 `OK` 但**取等在 `λ_min`**，而 `λ_min = e^{−aE_max}` 随塔延长塌向 0（`4.321e−2 / 7.583e−10 / 5.123e−35`）。

## §2 "轨道空间同构"是什么

**内容（三条，`[T]` 规格层）**：等距 `U : ℋ_phys → L²(𝒜/𝒢, dμ_W)` 使 `UHU^{−1} = −Δ_{𝒜/𝒢} + V`：

1. **空间**：物理（规范不变）Hilbert 空间 ⇄ **轨道空间** `𝒜/𝒢`（联络模规范）上的 `L²`。不是"规范轨道 ↔ 有限维简化空间"的一般陈述，而是**具体等距**：把 `H` 变成一个**显式 Schrödinger 算子**。
2. **测度**：`dμ_W` 不是 Lebesgue，是带 **CKN/WZW 权**的测度（`W` 下标 = WZW；内积里出现 `e^{2c_A S(H)}`，`c_A` = 伴随 Casimir，`S` = WZW 作用量）。**这是曲率/权进场的唯一入口**：动能项在 `L²(dμ_W)` 里共轭成 `−Δ + (权给出的势)`。
3. **`T`**：取动能的平方根 ⇒ `T ⪰ 0` **由构造**，这就是"不需 `E₀`"的确切出处（不需要先知道 `E₀ = 0` 来平移 `H`）。

**3D 有、4D 无**（`[L]`/`[M]`）：3D 是 KKN（Karabali–Kim–Nair）型约化，`𝒜/𝒢` 可用 `H` 场参数化、WZW 权显式；Nair 2026（`arXiv:2608.10133`，3D YM，**仅摘要级、未逐字核**）用 `T² − mT ⪰ 0`（`T` = `𝒜/𝒢` 的 Laplacian）得 `λ ≥ e²c_A/2π`。4D：空间切片 3 维、`𝒜/𝒢` 无限维、**无 WZW 归约** ⇒ 无 `dμ_W` 显式形式 ⇒ `KKN₄` 是 `[M]`（`D06-SPEC.md` L190/L234 同判）。

## §3 判点一："是否自动成立"（**核心**）

**答：不自动 —— 但两种读法"不自动"的方式完全不同。**

| 模型 | 读法 A：`T²−λ₁T ⪰ 0` | 读法 A 自动项：`λ₁T−T² ⪰ 0` | 读法 B：`m* = inf spec T` | 读法 B：`⪰` 对某 `m>0` |

- **(i) 读法 B 下它是一条真定理，不是恒真式**：2D YM 上 `spec(T) = {√(j(j+1))}` 离散、谱底 `√2 > 0`，`⪰` 真的成立且**可证**（不需要 `E₀`，只需要 `𝒜/𝒢` 紧 + 谱离散）——这正是 `d06` 说的 "2D YM: `𝒜/𝒢` 减到有限维 ⇒ 显式 ✓ >0"。
