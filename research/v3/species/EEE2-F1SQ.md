## §1 算符：`2⁺⁺` 的 `f₁²` 是哪一件对象

**(1.1) 算符（格点、`t` 固定、零空间动量；每项 = 1 张空间 plaquette = 4 条 link）`[T]`**
```
P_{ij}(x,t) = 1 − (1/N) Re tr[ U_i(x,t) U_j(x+î,t) U_i†(x+ĵ,t) U_j†(x,t) ],   i<j ⊂ {1,2,3}
O_{2⁺⁺}(t) = Σ_x Σ_{i<j} c_{ij} P_{ij}(x,t),    c ≠ 0,  Σ_{i<j} c_{ij} = 0
最省两分量：O^{(1)} = Σ_x[2P_{12} − P_{13} − P_{23}] (c=(2,−1,−1), Σc²=6)
            O^{(2)} = Σ_x[  P_{13} − P_{23}      ] (c=(0, 1,−1), Σc²=2)
对照 0⁺⁺：O_{0⁺⁺} = Σ_x Σ_{i<j} P_{ij},  c=(1,1,1), Σc ≠ 0
```
单项式仍是**单片**空间 plaquette ⇒ 每插入点 `4` 条边界 link、`w=4`、`a_c=1`（`W95A:24–32,77–80`）。

**(1.2) 量子数 `J^{PC}=2^{++}`（特征标自算，`[T]`）** 三张空间面的置换表示在 `O`(24 元) 上：`χ(E)=3, 8C₃=0, 6C₄=1, 3C₂=3, 6C₂′=1` ⇒ `n_{A1g}=1, n_{E_g}=1, n_{T1}=n_{T2}=0` ⇒ `3 = A1g ⊕ E_g`（`W95A:39–49`）。`Σc=0` 即**纯 `E_g`**，而 `J=2` 在 `O_h` 下 = `E_g ⊕ T_2g` ⇒ 领头匹配 `J=2`；空间 `Re tr` 环 ⇒ `P=+`，胶子实组合 ⇒ `C=+`。

**(1.3) 定义与归一 `[T]`** `ν^{(2)} := ν_{O_{2⁺⁺}}` 由连通核给出、`C(t) = (1/L_t)Σ_{t₀}⟨O(t₀+t)O(t₀)⟩_c = ∫e^{−Et}dν^{(2)}(E)`，于是
```
f₁²_{2⁺⁺} := ν^{(2)}({m₂²}) = |⟨0|O_{2⁺⁺}|2⁺⁺⟩|² = lim_{t→∞} e^{m₂ t} C(t)
强耦合值：f₁²_{2⁺⁺} = a₀^{(2)}(1−O(u)),  a₀^{(2)} = (Σ_{i<j}c_{ij}²)(2N)^{-2}·[端点重耦合×2]·[横向和]
```
归一三点：① 只吃 `Σc²` ⇒ `O^{(1)}:O^{(2)} = 6:2`；② `0⁺⁺` 的在册底 `¼(2N)^{-2}` 用的是 `c=(1,1,1)` 与 `½Re tr` 口径 ⇒ **跨道数值比必须把 `Σc²` 与 `Re tr` 口径一并带上**，否则比值无意义（`[T]` 于"随 `c` 变"，数值比本身不主张）；③ `2⁺⁺` 的最轻原子必属本道（`Σc=0` ⇒ 与 `0⁺⁺` 原子零重叠，`W95A:107`），故 `f₁²` 是**道内**量。**下一手**：若要和 `0⁺⁺` 比，先写一张 `(Σc², tr 口径)` 对照表再比。
