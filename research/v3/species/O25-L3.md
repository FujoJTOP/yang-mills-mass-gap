## 1. 归一化（先把口径钉死）

- 观测量与 `O11-PHYS §1` **逐字相同**：`V = S_W + Φ`、`Φ = −log J`（平坦图 `X_link = log U_link` 的 Haar Jacobian）、`κ = ∂²_v V`、`F = ∂_v V`、`Δ = E[κ|⟨v,X⟩=0] − Var(F|⟨v,X⟩=0) = G''(0)`。
- 模：**`k=0` 均匀 z-模**，`v_{l,3} = 1/√(4L⁴)`（`L=2`: `1/8`；`L=3`: `1/18`），**每个 `L` 都取 `‖v‖ = 1`** ⇒ 三个 `L` 用同一口径 `Δ_raw`。
- **精确标度恒等式**（不是约定，由定义）：`κ(cv) = c²κ(v)`、`F(cv) = cF(v)` ⇒
  **`Δ(cv) = c²Δ(v)`**。所以"带 `‖v‖⁻²` 还是 `‖v‖⁻⁴`"完全由 **`v` 的逐 link 振幅**决定：
  - 我的口径 `v_l = 1/(2L²)`、`‖v‖=1`（`c=1`）；
  - `‖v‖² = 1/L` ⇒ `v_l = 1/(2L^{5/2})`，`c = L^{-1/2}` ⇒ `Δ` 再乘 `1/L`；
  - `Δ_norm = L²Δ_raw` 对应 `v_l ∝ 1/L`（`c = 1/L`）；
  - 逐 link 振幅 `=1`（`c = 2L²`）⇒ `4L⁴Δ_raw` = `+0.544 / −18.7 / −230`（单调降，见 `§3`）。
- **`W_full`/`a²Δ₀²` 在不在我的 `Δ` 里？** `Δ = ⟨H_vv⟩ + ⟨Φ''⟩ − Var(F)`，实测 `⟨H_vv⟩ = +1.37…+1.40`、`⟨Φ''⟩ = +0.324…+0.333`、`Var(F) = 1.83…1.95`。**曲率项与 Jacobian 项都在里面**（`Φ''` 就是 `W_geo` 那一路的量），但**没有**拆成 `δ = a²Δ₀² + W_full`（`X` 未单独算、`a²Δ₀²` 未识别）。**⇒ 我算的是 `G''(0)`，是 `δ` 的一个组成块，不是完整的 `δ`。** 不得把本节数值直接当 `δ`。

## 3. 三点趋势与广延性（`(c)(d)` 的答数）

**`Δ_raw(L)`：`+0.136 → −0.292 ± 0.110 → −0.177 ± 0.062`。**

形状判读：**不是 (i) 单调降，不是 (iii) `L`-无关，最接近 (ii)——`L=2` 附近有极小、`L=3` 已回升——但回升量 `+0.115 ± 0.126` 只有 `≤1σ`，所以在现有统计下 (ii) 与"`L≥2` 平台 `≈ −0.2`"不可区分。** 已被数据排除的是：**`L=3` 回到正**（`−2.85σ`，保守口径 `−1.55σ`）。

**广延性（这是 `(c)` 的核心）**：`L⁴: 16 → 81`（`×5.06`）

| | `L=2` | `L=3` | 比值 | 广延预言 |
|---|---|---|---|---|
| `E[κ]` | `1.6583` | `1.7147` | `×1.034` | `×5.06` ✗ |
| `Var(F)` | `1.9506` | `1.8917` | `×0.970` | `×5.06` ✗ |
| `E[κ]/L⁴` | `0.10364` | `0.021171` | `×0.204` (`≈1/4.9`) | 常数 ✗ |
| `Var(F)/L⁴` | `0.12191` | `0.023355` | `×0.192` (`≈1/5.2`) | 常数 ✗ |

**⇒ `Var/L⁴` 与 `E[κ]/L⁴` 都不收敛（按 `1/L⁴` 掉）。** 原因是清楚的：`‖v‖=1` 的 `k=0` 模把振幅摊到 `4L⁴` 条 link 上，逐 link 振幅 `∝1/L²`；`E[κ]`、`Var(F)` 各自都是 `O(‖v‖²)` 的**全局**量而不是密度，于是**对 `L` 平坦**。这不是"新物理"，是**归一化错配**：`/L⁴` 把 `O(L⁰)` 的量当密度除。
**可用的广延列**：逐 link 振幅固定（`×4L⁴`）后 `E[κ]`: `0.82 / 106 / 556`、`Var(F)`: `0.276 / 125 / 613`、`Δ`: `+0.544 / −18.7 / −230`（`L=1/2/3`）——三者都随体积长，`Δ/4L⁴`（曲率密度）`: +0.544 / −0.292 / −0.177` 与 `Δ_raw` 同值（自洽：`Δ_raw` 就是"每 link 振幅 `1/(2L²)`"下的密度）。

**⇒ `(d)` 的裁决**：两列趋势确实相反（`Δ_raw` 先降后回升；`L²Δ_raw` 单调降；`4L⁴Δ_raw` 单调降更快）。**但选口径不能靠偏好，要靠实测**：`E[κ]`、`Var(F)` 在 `‖v‖=1` 下各自 `L`-平坦（`×1.03`、`×0.97`，`5%` 精度内），所以 `Δ_raw = E[κ]−Var(F)` 天然 `L`-可比；`L²` 或 `L⁴` 因子是**纯粹把模振幅换算成"每 link 固定振幅"**，换算后得的是**曲率密度×体积**，其单调性来自体积因子而不是来自 `Δ` 的物理漂移。**结论：争论不在归一化，在"要不要把 `Δ` 当密度"**——`H1` 的 `Δ` 是 `G''(0)`（一个方向上的曲率），**按定义是 `O(L⁰)`，不该乘 `L²`**；若 o23 的 `v` 确实逐 link 振幅 `∝1/L`，那 `L²` 换算**数学上正确**，但它换出的是另一个量（曲率密度×体积），拿它判 `H1` 的符号会得到 `(a)` 的"单调降"，与 `H1` 的对象错位。

## 7. 未闭合（诚实标注）

1. **`Δ = G''(0)`，不是 `δ = a²Δ₀² + W_full`。** 曲率项 `⟨H_vv⟩` 与 Jacobian 项 `⟨Φ''⟩` 都在 `Δ` 里但未拆开，`X` 未算。`§0` 的负号判的是 `H1` 所需 `Δ>0` 的那个 `Δ`，不是完整的 `δ`。
2. **`(a)`/`(ii)` 仍不可分**：`L=2→3` 的回升只有 `≤1σ`。要分开需 `L=3` 的 `Neff` 再翻 `4×`（`σ→0.03`），即每群 `~2e4` sweeps（`L=3` 约 `7.6 min/群`）。
3. **`L=3` 单体积、单 `β`、无 `a→0`**：`β=2.5` 靠近 `β_c(2)=2.2986`，`L=3` 的 `β_c` 未定；未做 `β`-扫描。
4. **`L=4` 未做**（`4·256=1024` link，估 `~75 ms/sweep`，`5e3` sweeps `≈6 min/群`）——趋势的第三点若换成 `L=4` 会比 `L=3` 决定性得多。
5. `E[F]` 的 `±0.4` 散布未解释到 `0`-中心性的定量水平（`sem≈0.2`），只是"相容"。
6. 并行 `5` 进程偏离资源纪律（`§2` 已注），虽内存无风险，但若同机有别的重作业并存，本轮数字的墙钟不可外推。
