## §3 `P3-DRESSED-MASS:36` 的逐字与解析（★ 第二问）

### 逐字（`research/unconditional/P3-DRESSED-MASS.md:36`，整行）

> `` where `∏_{p∈B_T}c_f = u^{4T}` (each of the `4T` temporal plaquettes carries `c_f=u`) has been absorbed into the exponential, and the **`T`-independent amplitude is** `a₀(β) = (2N)^{-p}·s > 0`, with `s ∈ ℤ_{≥1}` the product of link **recoupling multiplicities**  ``

（上一行 `:35`：`` `w(B_T) = a₀(β)\,u^{4T} = a₀\,e^{−κ t}`, `κ := 4\ln(1/u)/a` ``；`:25` 给算子归一 `O(x)=Σ_p (2N)^{-1}Re tr U_p`。）

### 那句子是"`c_f=u`"还是"`c_f` 携带因子 `u`"？

**逐字是等式 `c_f=u`**（括号内直接写 `carries c_f=u`，不是"carries a factor `u`"）。**但**这个等式只在 `:28` 的 `u:=c_f(β)` 归一里成立——那里它就是**恒等式**（`u` 定义为 `c_f`）。它**不是**关于数字 `β/(2N²)` 的陈述。

### 为什么这不救 `cb1`

`:36` 的**承重内容**是"每个 tile 贡献一个 `c_f`" ⇒ `∏_{p∈B_T}c_f = c_f^{4T}`。写成 `u^{4T}` 需要 `u=c_f`（U1）。若改用 U2（`u=c_f/N`，即语料其余全部窗口算术用的那套），则

```
∏_{p∈B_T} c_f = c_f^{4T} = (N u)^{4T} = N^{4T} u^{4T} ≠ u^{4T}
```

⇒ `w(B_T)=a₀u^{4T}` 与 `∏c_f=u^{4T}` **在 U2 下不能同时成立**，缺口恰为 `N^{4T}`（`N=2`、`T=1,2,3`：`16, 256, 4096`）。这正是判死线 (a) 指的那个 `N^{4T}`，也正是 `X01:16` / `Z06:53` 已经逐字记过的**不相容**。`[T]`

**物理上钉死选择的是 `a₀` 的 `T`-无关性**（`:36` 自己写 "the **`T`-independent amplitude**"）：`a₀=(2N)^{-p}s`，`s∈ℤ_{≥1}` 是整数重耦合乘积，装不下 `N^{-4T}` ⇒ `N^{-4T}` 只能由 `u^{4T}` 携带 ⇒ **U2**。`[T]`

### 判死线对照

* **(a) 触发**：`c_f = Nu`（`c_f/u=2=N` 精确）⇒ **`cb2` 对**；`cb1` 的 `C̄=1` 断在 `N^{4T}`：`c_f^{4T}=(Nu)^{4T}=N^{4T}u^{4T}`，`C̄=|w_p|/u=c_f/u=N`，不是 `1`。`[T]`
* **(b) 不触发**：`c_f=u` 只在 `u` 被**定义**为 `c_f` 的 DR 内部归一里成立（U1），它不是 `β=0.018394`、`N=2` 那组数（`u=0.00229925`）的归一。`[T]`
* **(c) 触发（主判，歧义根）**：`u` 在语料里**有两个逐字定义** —— `β`-标度同阶（都 `≍β`）但**差了 `N` 倍**：
  * **U1** `u := c_f(β)`（`P3-DRESSED-MASS.md:28`；`P3-FULLREP-KP.md:77`）
  * **U2** `u := c_f(β)/N = β/(2N²)`（`X01-L1C.md:15`；`Z06-HOLEA.md:16`；Gupta (14.18)–(14.21) `[O]`）

  ⇒ `cb1` 与 `cb2` **不是两个物理情形，是两个 `u` 符号的记账**；`cb1` 的错不在算术，在**把 U1 的等式搬进 U2 的数值**。`[T]`

### 谁对（定案）

> **`cb2` 对**：在**唯一能同时满足**（i）`a₀` 的 `T`-无关性（`DR:36` 逐字）、（ii）`κ=4ln(1/u)/a` 与 `w(B_T)=a₀u^{4T}` 承重、（iii）Gupta (14.20)/(14.21) `(β/2N²)^{4T}` 与 `M=−4ln(β/2N²)` 的**那套归一（U2）**里，`c_f = Nu = 2u`，`C̄ = c_f/u = N = 2`。
