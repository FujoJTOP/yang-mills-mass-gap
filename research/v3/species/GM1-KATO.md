### §1.3 一条记账勘误（本线必须用，否则 §3 的量词式会写错）

### §2.2 Birman–Schwinger 在此设定下的**确切**判据（含证明）

> 下面三条引理是教科书级别的（Birman 1961 / Schwinger 1961 / Simon；仓内著录见 `META-CROSSDOMAIN-PROTOTYPE.md:179`）。本文**不引用未核正文**（`[R-09]` 与 `[R-10]` 在仓内均非逐字核，见 `GH1c-LIT.md:98–100`），而是**就地证明**——三条都是三行。

**引理 BS-1（Schur/Sylvester 精确形）`[T]`.** 设 `H₀` 自伴，`λ∉σ(H₀)`，`R₀(λ):=(H₀−λ)^{-1}`，`V=AA*`（`A` 有界），`H:=H₀+V`。则

```
λ ∉ σ(H)   ⟺   −1 ∉ σ( A* R₀(λ) A ) .
```

*证.* `H−λ = (H₀−λ) + AA* = (H₀−λ)[1 + R₀(λ)AA*]`。`H−λ` 可逆 ⟺ `1+R₀AA*` 可逆。而 `1+XY` 可逆 ⟺ `1+YX` 可逆（取 `X=R₀A`、`Y=A*`；由 `(1+XY)X = X(1+YX)`，左逆右逆同时传递）；取 `K:=A*R₀(λ)A=YX`。`1+K` 可逆 ⟺ `−1∉σ(K)`。∎

**引理 BS-2（充分形，即任务书引的那条）`[T]`.** `‖K(λ)‖<1 ⇒ λ∉σ(H)`。反之一般不真：`−1∉σ(K)` 是**集合条件**，norm 界是它的一个**充分**代替。

**引理 BS-3（唯一充要的规范形）`[T]`.** 若 `λ < inf σ(H₀)` 且 `V≥0` 有界，则 `K(λ)≥0`，且

```
σ(H) ∩ (−∞, λ] ≠ ∅   ⟺   ‖K(λ)‖ ≥ 1 .
```

*证.* `λ<inf σ(H₀)` ⇒ `R₀(λ)>0` ⇒ `K≥0`；自伴正算子 `−1∈σ(K) ⟺ ‖K‖≥1`。再套 BS-1 并注意"`λ` 之下有谱"⟺"`H−λ` 不可逆且下方有负谱"。∎

**引理 BS-4（只能定位，不能生产）`[T]`.** 设 `λ∈σ_p(H)`、`λ∉σ(H₀)`、`Hψ=λψ`。则 `−1∈σ(K(λ))`，且对应的 `K`-本征向量为 `φ=A*ψ`：

```
K(λ)φ = A*(H₀−λ)^{-1}A A* ψ = A*(H₀−λ)^{-1}(H−H₀)ψ = A*(H₀−λ)^{-1}(λ−H₀)ψ = −A*ψ = −φ .
```

⇒ **在谱底 `λ=m₁` 上，BS 判据恒成立，且它就是本征方程的一次重写。** 推论：**BS 判据在被定位的那个 `λ` 上不携带任何"该 `λ` 与 0 有间距"的信息。** 它能把"已知 `m₁` 落在某个区间"变成"`K(λ)` 有本征值 −1"，**不能**给出"存在 `δ>0` 使 `(0,δ)` 内无谱"。∎

> **§2.2 结论**：BS 在此设定下的确切内容是**一个行列式/秩陈述**（`det(1+K(λ))=0 ⟺ λ∈σ_p`），与 `A3`（`D_O(z)=det(1−zT_O)`、`z₁=e^{am₁}`，`new-tools-registry.md:28–34`）**是同一个对象换字母**（`META:63,124`；`BASE-ORDER-PARAMETER.md:89–90` 同判"BS-det = A3 = circular"）。**"有限维时它就是行列式/秩论证"在这句话上是对的：它给的是恒等式，而内容全在常数。**
