## §2 `(e)` 最详细：纯组合路能给出什么界？够不够 `(U3)`？

**2.1 它能给的界（全部 `[T]`，全部不碰展开）。**
1. `q∈[0,2]` ⇒ Popoviciu `Var(q) ≤ (2−0)²/4 = 1`，**`a`-无关、`β`-无关**（`HZF-COV.md:46`；`HZE-KIN.md:30`）。这是 `L3` 里唯一一条"白拿"的 `a`-一致不等式。
2. 块平均同界：`Var(⨏_B X) ≤ ‖X‖²_∞ = 4a^{-8}`，与 `N_B` 无关（`HZG-BLOCK.md:55`）。
3. 组合计数被**精确相消**：`N_B⁻¹` 与 `#{|z|<b̂}≈16N_B` 相抵，净 `0` ⇒ 停在 `Z_a ≤ 64a⁻⁸`（`DDD3-NB.md:52`）；紧读 `ϖ≤N_B`、粗读 `4N_B`（`HZE-KIN.md:14`）。
4. 靶形：`Z_a ≤ Ca^{-4}`（`∃C∀a`）⟺ `ϖ≤C`（`HZF-COV.md:21`）。**差 4 个 `a`-幂 = 一个 `N_B=(b̂/a)⁴`**，且"顶到界的正是靶要的那个 `N_B`"。
5. 障碍是**可证性层面**的，不是"未算完"：块内全相关族 `q_x≡q` 使 `Var(q)≤1` 与 `ϖ=N_B→∞` 同时成立 ⇒ 任何只用"`q∈[0,2]` 边际 + 计数"的论证都到不了 `∃C∀a`（`DDD3-NB.md:56`；该族**不主张**是 Gibbs）。

**2.2 够不够 `(U3)`？—— 形够、内容不够，且 `(U3)` 本来不开。**
- 形够：有界 ⇒ `|S^{(n)}|≤2^n` ⇒ `C_n=2^n`，取 `A=2` 即 `A^n n!` 形，**自动**满足（`AA1-OS0.md:37` 逐字"自动满足 `(U3)`（`A=2,P=1`）"）。
- 内容不够（三条独立）：① 类不匹配：物理场 `O=a^{-4}q` ⇒ `|E[O^n]|≤(2a^{-4})^n` 随 `a` 发散，`a`-一致界**只能**来自减除后的抵消（`AA1-OS0.md:38`）；② `P(L)=1` 与 `χ_2>0` 不相容（`HS-L3-9.md:66`）；③ `n!` 的**真来源**是树界/聚类（`HS-L3-9.md:15`），而树界在 `β=2.5` 本身 `[NG]`（`HS-L3-9.md:84`）⇒ 纯组合与 `(U3)` 的真内容**不相容**；若走 partition 估界，`Bell(n)≫n!` 与 `n!` 直接冲突（`HS-L3-6.md:16`）。
- 更要紧：`(U3)` 不开 —— 它是树界的推论、非独立（`YYY1-U123.md:38,44`）。故 `(e)` 把力气花在一条已 `[T]` 的格上。

**2.3 为什么它必然停在"形"。** `(e)` 的三件工具全是**不等式/计数**：Popoviciu 是方差上界、计数是 `N_B` 记账。而 `@2.5` 唯一开的是 `(U2)` 乘性半 = `Z_O(k)` 的 `k`-极限（`YYY1-U123.md:36`；`HZ1-UNBOUND.md:19`），是**值**不是界 ⇒ 不等式类工具对它结构性地盲。这就是"不用展开"五条全过而全灭的原因。
