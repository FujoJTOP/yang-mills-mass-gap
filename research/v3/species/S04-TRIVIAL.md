## 3. `W_j` 会不会变负？能不能抵消 `E[H_j]`？—— 一般切片

切片上 `X≡0`；**离开切片** `W_j=W_geo+X`，`X=−2Cov(G,Φ′)` 符号不定，唯一普适天花板是 Cauchy–Schwarz：

```

⇒ |X| ≤ 2√0.04 = 0.400  >  W_geo ≈ 0.32    ⇒  W_j ≥ 0.32 − 0.40 = −0.08 < 0
```

（数取自 `ABC2-CONSTRUCTIVE.md:13`、`A5-RIGOROUS-NUMERICS.md:10–11`，`[C]`+`[E]`；同处实测 `W_full≈0.54 > W_geo≈0.32 ⇒ X≈+0.22>0`。）

## 4. 判死线（逐字）

### (b) 非平凡（`W_j` 可抵消）—— **成立，但主犯是 `Var_j`**

## 5. 那真正的缺件是什么（本题要的正面答案）

把本题的数代进 `(★)` 的两边，缺口的位置是唯一的：

```
(★) ⟺ Var_j ≤ E[H_j] + W_j − δ_W        （在 a₀* 上、j,U′ 一致）
     ⟺ Var_{μ(·|U′)}(⟨Pᵀ∇S_j,v⟩) ≤ (E[H_j]+W_j) − δ_W
```

- `W_j` 这一侧：`β=0` 是 `W_geo=0.2051`（`≥N/12`，`[T]`），一般切片 `W_geo+X` 可跌到 `−0.08`（`[E]`，CS 界）—— **`W_j` 的下界是缺件之一，但它是"θ/边界"的病，不是"β"的病**（`W_geo` β-无关）。
- `Var_j` 这一侧：**这是缺件的主体**。可解族证明它**不是 `o(1)`**（`=β²V₀`，无界），`O05` 证明它在非退化切片上幂 `k→0/1 < m=1` 所以大 β 自动、**小 β（`β≈1–6`）才是危险窗**。缺的正是 `β∈[1,6]`、`a₀*` 上、`(j,U′)` 一致的 `Var_j` 上界 —— 即 `H1`/`(◆)`，不是 `(★)` 的"平凡性"。

**一句话**：`(★)` 的困难**不在 `W_j` 会不会负**（`β=0` 它 `+0.2051`，可解族上钉死不动的正是它），**而在 `Var_j` 是 `β²V₀` 而不是 `o(W_j)`**；把 `0.2051` 记成 `E[H_j]` 会让"`E[H]` 是 Θ(u⁰)"这句话成立，代价是把 `W_j` 记成 0（R2），于是 `(★)` 变成 `Var_j ≤ E[H_j]−δ` —— 同一个不等式，同一个失败窗口，**没有变平凡**。
