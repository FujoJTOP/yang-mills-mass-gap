## §1 七个工具的**精确陈述**

### #1 一致有界原理（Banach–Steinhaus / resonance）`[T]`
**陈述.** `X` Banach、`Y` 赋范、`{T_α}_{α∈A} ⊂ 𝓛(X,Y)`。若 `∀x∈X: sup_{α∈A}‖T_α x‖_Y < ∞`，则
`sup_{α∈A}‖T_α‖_{𝓛(X,Y)} < ∞`。等价共鸣形式：若 `sup_α‖T_α‖ = ∞`，则 `{x : sup_α‖T_α x‖ = ∞}` 是**稠 `G_δ`**。
**输入.** `X` 完备（Baire）+ 逐点有界。**`A` 无任何结构假设。**
**引用.** Banach 1927 / Steinhaus 1927（独立）；教材口径 Brezis, *FA·SS·PDE*, Thm II.1（**未逐字核**）。

### #2 Ascoli–Arzelà（等度连续）`[T]`
**陈述.** `K` 紧度量、`𝓕 ⊂ C(K)`。`𝓕` 在 `(C(K),‖·‖_∞)` 中相对紧 ⟺ `𝓕` 一致有界 **且** 等度连续：
`∀ε>0 ∃δ>0 ∀f∈𝓕 ∀x,y: d(x,y)<δ ⇒ |f(x)−f(y)|<ε`（**同一个 `δ` 对整族**）。
**输入.** 一个**整族共用的模** `ω_𝓕`。给不出模 = 工具不启动（不是"不可定义"，是"缺模"）。
**引用.** Arzelà 1883 / Ascoli 1883（原始无 DOI）；教材口径 Rudin, *PMA* 3rd ed., Thm 7.25（**未逐字核**）。

### #3 Prokhorov 紧性 `[T]`
**陈述.** `S` Polish、`Π ⊂ 𝒫(S)`。`Π` 弱相对紧 ⟺ `Π` **紧胎/tight**：
`∀ε>0 ∃K_ε ⊂ S` 紧，使 `sup_{μ∈Π} μ(S∖K_ε) ≤ ε`。一致性全在"**同一个 `K_ε` 管整族**"。
**输入.** 对整族一致的质量不逃逸估计（在 `[0,∞)` 上就是一条一致的高质量尾部界）。
**引用.** Prokhorov 1956, *Theory Probab. Appl.* **1**, 157–214（DOI 未核 ⇒ 不编）；教材口径
Billingsley, *CPM* 2nd ed., §5（**未逐字核**）。

### #4 半连续 + 紧性（Baire 纲）`[T]` — 必须拆成两句
**(W) Weierstrass.** `K` 紧、`f` lsc ⇒ `f` 在 `K` 上取到最小值。给的是**取到**，不给一致。
**(B) Baire 引擎.** `X` 完备度量、`{f_α}` lsc、`∀x sup_α f_α(x) < ∞` ⇒ `F := sup_α f_α` 是 lsc 且
在每个非空开集上局部有界于某个非空开子集；即 `{F 局部有界}` 含一个**稠开（剩余）集**，例外集是 meagre。
**输入.** 参数空间完备 + 逐点有界。**结论只是"剩余集上一致"，不是全族一致**——一条物理族可以整条落在 meagre 例外集里。
**引用.** Baire 1899；Banach 1931（condensation of singularities）；教材口径 Oxtoby, *Measure and Category* 2nd ed., Ch. 9（**未逐字核**）。

### #5 变分收敛（Γ-convergence）`[T]`
**陈述.** `X` 拓扑空间、`F_n, F : X → ℝ̄`。`F_n ↝ F` ⟺
(i) `∀x, ∀x_n→x: F(x) ≤ liminf_n F_n(x_n)`；(ii) `∀x ∃x_n→x: limsup_n F_n(x_n) ≤ F(x)`。
则 `lim_n inf_X F_n = min_X F`；且最小点列的任何极限点是最小点、`F_n(x_n) → min F`。只取 (i) 得
`liminf_n inf_X F_n ≥ inf_X F`。
**输入.** 一个**共同空间** + **对一切收敛序列**的 liminf 不等式（比"可定义"强：是对整族的逐序列要求）+
族里每个成员本身是**泛函**。
**引用.** De Giorgi 1975；教材口径 Dal Maso, *An Introduction to Γ-Convergence* (Birkhäuser 1993)（**未逐字核，节号不担保**）。

### #6 均匀大偏差（Freidlin–Wentzell / 均匀 LDP）`[T]`（作为定义性定理）
**陈述.** `{μ_ε} ⊂ 𝒫(S)`、速率函数 `I : S → [0,∞]` lsc 且水平集紧。上界：闭 `F`，
`limsup_{ε→0} ε log μ_ε(F) ≤ −inf_F I`；下界：开 `G`，`liminf_{ε→0} ε log μ_ε(G) ≥ −inf_G I`。
**均匀版**：另有参数 `γ` 时两式对 `γ` 一致、`I` 与 `γ` 无关；引擎是**指数紧胎**
`∀M ∃K 紧: limsup_ε ε log sup_γ μ_ε^γ(S∖K) ≤ −M`。
**输入.** 指定的随机扰动结构（小参数 `ε`）+ 一个与 `γ` 无关的速率函数 + 指数紧胎。
**引用.** Freidlin–Wentzell, *Random Perturbations of Dynamical Systems* 3rd ed., Ch. 3；
Dembo–Zeitouni, *LDP* 2nd ed., §1.2 + Ch. 4（**未逐字核**）。

### #7 数学归纳 / 递推（在 `L` 上）`[T]`（模式）+ `[C]`（一致不变量）
**陈述.** `P(L₀) ∧ ∀L≥L₀(P(L) ⇒ P(L+1)) ⇒ ∀L≥L₀ P(L)`。
**为得一致所需加强（关键）.** 必须存在**不含 `L` 的常数 `C`** 使 `P_C(L) := [w₁(L,a) ≥ C]` 对**所有** `L`
满足 `P_C(L) ⇒ P_C(L+1)`。否则归纳只给"每个 `L` 有一个 `C_L`"，而 `C_L → 0` 完全不违背归纳。
⇒ **递推本身不产出一致，除非不变量带 `L`-无关常数**；而这要求族由**一条递归规则**生成 = 最强的可定义要求（有限描述 + 良序）。
**引用.** Peano 归纳（标准）；一致不变量 = Lyapunov/单调比较（标准）。仓内实例：UNIF1 的 **M2**（有限体积单调性）`[C]`、`S4-DECIMATION`（退耦递推）、`CLAUDE §5` 的规范不变 PF `[T]`。

| # | 工具 | 一致性来自 | `w₁` 上的独立供给 |
|---|---|---|---|
| 1 | Banach–Steinhaus | **定义域完备性**（`A` 任意） | 无（`‖T‖≡1`，输出平凡） |
| 2 | Ascoli–Arzelà | 整族共用等度连续模 | 无（缺 `L`-一致的导数/协方差界） |
| 3 | Prokhorov | 整族共用紧胎 | **免费**（`[0,Λ]` 紧） |
| 4 | Baire（lsc） | 参数空间完备 + 逐点有界 | 剩余集，不是全族 |
| 5 | Γ-convergence | 共同空间 + 全序列 liminf | 无（`w₁` 是读数，不是极小值） |
| 6 | 均匀 LDP | 指数紧胎 + 速率函数 | 无（无小参数随机结构） |
| 7 | `L`-归纳 | **单调不变量**，不靠紧性 | **`[C]`：待证的有限体积单调性** |

## §2 ★ 哪一个不要求族可定义？—— **#1 Banach–Steinhaus**

`A` 是**任意集合**：`BS` 的证明只用 `X` 的 Baire 性（`X` 完备），一致性从**定义域**一侧挤出，
**不从族的描述挤出**——不可数、不可测、不可定义都行；甚至不需要 `A` 上有拓扑。

三条对照，把这条答案的边界钉死：

1. **#4 是同一引擎，但结论更弱**：`lsc` 族逐点有界只给"稠开集上局部一致"。
   `BS` 之所以能从局部升到全局，靠的是 `T` **线性 + 齐次**（局部界 `M` 在球上 ⇒ 用尺度 `‖x‖` 摊平）。
   **没有线性，就没有全局一致**——这一条解释了为什么"族上一致"在一般泛函族上只能到剩余集。
2. **#2/#3/#5/#6 不要求可定义，要求一致估计**：共同模 / 共同紧胎 / 全序列 liminf / 指数紧胎。
   它们比"可定义"更"物理"、也更硬：这些估计一旦有，一致性立刻到手；而它们恰恰是仓内缺的东西。
3. **#7 最需要可定义**：递推规则 = 有限描述。这条与 UNIF1 §1.2 的 o-minimal 记账**同向**，
   但内容不同：o-minimal 要"固定维数环境"，归纳要"良序 + 有限步规则"。

**⇒ 结论（回答"通用工具"）.** 作为**发生器**：这一格**是空的**。七个工具全部是一致性的
**搬运/提升**（逐点 → 一致、局部 → 全局、弱 → 强、`L` → `L+1`），没有一个把"非一致"变成"一致"。
`BS` 唯一不要求族结构，代价是它的假设就是"族在每个点上已经一致"。

## §3 `w₁` 是原子质量：能嵌进哪个框架

### 3.1 正规化（`[T]`）
`ν` = `O = ¼trF²` 的 Källén–Lehmann 谱测度（`ν ≥ 0` 于 `[0,∞)`，`M₀ = Var(O) = ∫dν`），
`m₁² = inf supp ν`，`f₁² = ν({m₁²})`。令

```
μ_{L,a} := ν_{L,a} / M₀ ∈ 𝒫([0,∞)) ,      w₁ = μ_{L,a}({m₁²}) = μ_{L,a}({inf supp μ_{L,a}}) = E(μ_{L,a})
```

即 **`w₁` 就是某个概率测度的（底边）原子质量** —— 答案：**是**。`E` 就是 R3 的原子泛函，质量归一后
（`w₁ = f₁²/M₀ ∈ [0,1]`，`Σ_{n≥1} w_n = 1`，U1/U2 主恒等式）。与 `L1C-BOUND:13` 的归一记账一致。

### 3.2 框架：`𝒫([0,Λ])` 上的 **Banach–Alaoglu + Portmanteau**（且紧性侧免费）
`Λ` 由**变分上界**给（`m₁² ≤ Λ`：拿一个试探态即可，是"便宜"的一侧，与 `m₁² ≥ c` 的靶不同向）。
于是 `K := [0,Λ]` 紧：

```
𝒫(K) 弱*紧且可度量化（Banach–Alaoglu）  ⇒  Prokhorov 前提"紧胎"自动满足  ⇒  #2/#3/#5 的紧性部分免费
ν ↦ ν(F) 对闭 F 是 USC（Portmanteau）： limsup_n μ_n({m}) ≤ μ({m})            [T]（Y1 §1）
```

**⇒ 七个工具里所有紧性类对 `w₁` 已经"用过了"，不可能是难点。** 难点只可能在 `E` 的不连续：
R3 Thm R3-2 已证对任何弱*连续 `g`，`sup_μ |E(μ) − g(μ)| ≥ w/2`。

### 3.4 两个被排除的"原子质量"框架（记账）
