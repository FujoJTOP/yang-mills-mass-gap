### §0.x 一句话

两点式是 `ν` 上的一次 Cauchy–Schwarz，**它是恒等式**：`D=Var_ν(e^{−st})≥0`。因此它对 `P` 的判别力**恰好为零**——自由场满足它、HN1 否证族满足它、类 3 双井在阈值上下都满足它、类 4 spread 满足它、M6 满足它。仓内数据在唯一忠实的三格里也确实满足它（1σ 内），但那个「满足」是恒等式的重述，不是 P 的证据；而 `τ=L` 这个读数在现统计量下根本不可分辨（判据 `7.4×10⁻⁵` vs 噪声 `1.5×10⁻²`）。**唯一还活着的用法**是把 `K=Var_ν(e^{−st})/C(t)²` 量出来并试图证它一致有界——那是 `HZ1:143` 传播链里被默认成 0 的那个假设。

## §3 ★ 判别力：自由场与 HN1 族应当给出什么（`hr4_power.log`）

### 3.1 先钉死：它是恒等式

```
C(t) = ∫ e^{−st} dν(s),  ν ≥ 0
D(t) := C(0)C(2t) − C(t)² = ½∬(e^{−st}−e^{−s′t})² dν dν′ = Var_ν(e^{−st}) ≥ 0
```
- 4000 组随机正测度：**违反 0/4000**；`|D − Var|/C(0)² ≤ 2.2×10⁻¹⁶`。
- 有限 `L_t` 的周期估计量（**这就是仓内实际在跑的估计量**）：Hankel 矩阵 = `e^{−m(t+t′)}` 与 `e^{−mL_t}e^{mt}e^{mt′}` 两个秩一 PSD 核之和 ⇒ 每个 2×2 子式 `≥0`；3000 组随机 `(ν,L_t,t)` **违反 0/3000**。
- 等号 ⇔ `ν` 是单原子。

⇒ **「满足」= 恒等式的重述（0 bit）；「违反」= 估计量的偏置/噪声（0 bit 关于模型）。**

### 3.2 判别力电池（每条都带闭式 + 数）

| 模型 | `m₁²` | `C(t)` | `K = D/C(L/2)²` | 两点式 | `P` |
|---|---|---|---|---|---|
| **自由场（箱隙）** | `4sin²(π/L)` | `Σ_n(2E_n)^{−4}e^{−E_nt}`，`E_n=2√(Σsin²k_i)`，`k₁=(2n₁+1)π/L` | `0.383(L=6) / 0.419(8) / 0.416(16) / 0.443(64)` | **PASS**（`D = 3.19×10³…1.11×10⁶`） | 真 |

### 3.3 自由场「应当满足还是违反」——**满足**，而且是**大幅**满足

- 闭式：两壳即得 `D = w₁w₂(e^{−E₁L/2}−e^{−E₂L/2})² > 0`；等号只在单原子。
- 数：`L=6` 箱隙：`C(0)=3.50×10³`，`C(3)=1.24×10²`，`C(6)=6.10`，`C(3)²/C(0)=4.41`，`D=5.92×10³`（比判据大三个量级）。
- 载子依赖：取 `w=(2E)^{−1}` 时 `C(0)` 随截断发散（`n_max=20→80`：`C(0)` 由 `1.54×10⁴` 涨到 `9.47×10⁵`），但 **`K` 只在 3.85–4.24 之间摆动、符号永不变**。
- ⇒ **自由场这一格「必须能判」的要求落在两点式上兑现不了**：自由场的 `P` 为**真**，所以它满足不等式只说明两者相容，不提供任何排除。要用自由场作判据，只能靠 `P` 自身（`G_c→0`，`HZ1:233` 段 [1] 已给 `3.3×10⁻²→1.3×10⁻⁴`）。

### 3.4 HN1 族「应被排除」——**没有被排除**

- `ν_L = ½δ_{1/L²}+½δ_4`，`χ_L = L²/2+1/8 → ∞`（`HZ1:154`）。`P` 假（`G_c→1.359`，见勘误 0.8）。
- 两点式：**每一 `L` 都 PASS**，精确 slack `¼(e^{−1/2L}−e^{−2L})²`；`L=6` 时 `D=0.2116`、`K=0.99997`；`L=10⁶` 时 `D→1/4`、`K→1`。
- ⇒ **判别格上不排除**。这条族造出来就是为了打 `P` 的，两点式对它完全免疫。

### 3.5 M6「盲」

`ε=10⁻⁹` 时 `D=4.0×10⁻¹⁰`、`K=0`（谱塌成单原子 ⇒ 等号）。而 M6 的 gap 为假。⇒ 两点式在 M6 上同样盲。

### 3.6 方向：为什么它连「弱检验」都当不成

```
C(2t) = (1 + K(t)) C(t)² / C(0),     K(t) = Var_ν(e^{−st}) / C(t)²  ≥ 0
```
- 两点式 **就是** `K ≥ 0`：给的是 `C(2t)` 的**下界**。
- `P` 要的是 `C_L(L) ≤ r₀e^{−√c}`：**上界**。
- Cauchy–Schwarz 的上界半边 `C(t) ≤ √(C(0)C(2t))` 是**逆时间**的读法；要从 `t<L` 推到 `t=L` 需要**对数凹** `C(2t) ≤ C(t)²/C(0)`，它在单原子之外全假。
- 唯一可用的弱化：`K(t) ≤ K₀`（一致于 `L`）⇒ `C(2t) ≤ (1+K₀)C(t)²/C(0)`。`HZ1:143` 的 `ρ↦ρ²/M₀` 是 `K₀=0`；这个假设**未被证**，且在除单原子外的每个模型上都是**假**的（自由场 `K≈0.4`、HN1 `K→1`、M6 大 `L` 上 `K→8.8`）。
- 复现 `HZ1:295` 段 [10]：`0.18 → 3.24×10⁻² → 1.05×10⁻³ → 1.10×10⁻⁶ → 1.21×10⁻¹²`（逐位一致）。但**每一格都是 `C(2^kL)` 的下界**：有地板时它开证书，没地板时它一言不发。

### 3.7 `K` 也不分 P（但它决定上界可不可传）

| 模型 | `K(L=6)` | `K(8)` | `K(16)` | `K(64)` | `P` | gap |
|---|---|---|---|---|---|---|
| 自由场（箱隙） | 0.383 | 0.419 | 0.416 | 0.443 | 真 | 假 |
| HN1 否证族 | 1.000 | 1.000 | 1.000 | 1.000 | **假** | 假 |

⇒ `K` 在 `P` 假的行上落在 `[0,1]`，在 `P` 真的行上落在 `[0, 8.8]`，**不分离**。它之所以仍值得量，理由只有 3.6 的那一句：`K ≤ K₀` 是把下界机器翻成上界机器的唯一缺件。数据已给出 `K(1)=1.0614±0.0432`（4σ 级）、`K(2)=7.17±1.91`。
