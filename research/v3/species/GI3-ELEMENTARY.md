## §2 · 三候选：一台机器，三个坐标

### 2.0 机器的本体（先证方向，再谈收敛）

**命题 2.0（`c_N` 单调下降、极限 = `m₁`）`[T]`（标准；转引 `H08-Z1.md:262` 已核清单：Stieltjes 1894 / de Montessus / Gautschi，本轮未取原文逐字核）。**
`c_N` 是 `ν` 的 `(N+1)` 点 Gauss 节点的最小者。Gauss 节点由 `Q_N` 的根给出，且 `Q_N` 与 `Q_{N+1}` 的根**交错**：`x_{1,N+1} < x_{1,N} < x_{2,N+1} < ⋯`。由此：
1. `x_{1,N}` 单调下降；2. 节点落在 `supp ν` 的凸包内 ⇒ `x_{1,N} ≥ m₁`；3. 单调有下界 ⇒ 收敛；4. 极限必在 `supp ν` 内且其任意邻域承载正质量 ⇒ 极限 `= m₁`。
**取等**：`ν` 恰有 `n` 个原子时 `Q_N ∝ Q_{n−1}`（`N ≥ n−1`），`c_N = m₁` 从此**精确**（witness `[6]`：两原子 `0.5/0.75` 在 `N=1` 就给 `0.500000000000`）。

**命题 2.1（PSD 形与根形是同一个 `c_N`）`[T]`。** `supp ν ⊂ [c,∞) ⟺ H_N ⪰ 0 且 H_N^{(1)} − cH_N ⪰ 0`（Stieltjes 矩问题的有限判据：对每个多项式 `p`，`∫p²dν ≥ 0` 与 `∫p²(s−c)dν ≥ 0`）。使该条件首次成立的 `c` 正是 `λ_min(H_N⁻¹H_N^{(1)})`。⇒ `m₁ = sup{c : 该 PSD 条件对所有 N 成立}`，截断值 `= c_N`。
**推论（SDP 松弛在有限阶永远不紧）`[T]`。** 对 `|supp ν| = ∞` 的 `ν`，交错是**严格**的 ⇒ `c_N > m₁` 对每个有限 `N` 成立。⇒ 用半正定规划证 `m₁ ≥ c` 的层级，在任何有限阶都给出 `c < m₁` 的可行证书与 `c_N > m₁` 的对偶上界，**永不合拢**。

**命题 2.2（`min` / gauge 结构：没有任何线性矩泛函能等于 `m₁`）`[T]`。**
`supp(ν'+ν'') = \overline{supp ν' ∪ supp ν''}` ⇒
```
m₁(ν' + ν'') = min{ m₁(ν') , m₁(ν'') } ,        m₁(tν) = t·m₁(ν)  (t>0)
```
即 `m₁` 是矩锥上的**凹、正齐次**泛函（一个 `min` 型 gauge）。⇒ 任何**线性**矩泛函（含一切矩比 `M_a/M_b`、一切 `Σ c_k M_k`）都与之在两条边不同的测度对上冲突。**这解释了为什么"矩比/Christoffel"族在结构上只能给上界：它们凸，`m₁` 凹。** 具体的对偶见证就是 `c_N`（凸泛函族的 sup）。

### 2.1 (a) Hankel 判据 —— **口径要改一行**

任务书写"`inf supp ν` 由 Hankel 行列式的**零点**唯一决定"。**行列式是数，没有零点；有零点的是多项式 `Q_N(λ) = det(λH_N − H_N^{(1)})`**，即 Hankel **铅笔**的最小正广义特征值。改这一行，结论照旧；但它是"可算"与"写不出来"的分界。

- **收敛率**：边是**原子**时 `c_N − m₁` 几何小（witness `[2]`：`0.3δ_{1/4}+0.7Unif[1,2]`：`0.3631 → 0.2561 → 0.25028 → 0.250012 → 0.2500005 → 0.2500000`，6 阶见底）；边是**割**时 `c_N − m₁ ~ N^{−2}`（`Unif[1,2]`：`1.211→1.113→1.069→1.047→1.034→1.025→1.020`；`Unif[0,1]`：`0.2113→0.1127→0.0694→…`）。**⇒ 物理上最相关的一支（边原子）恰好是收敛最快的一支。**
- **条件数墙 `[T]+[E]`**：`cond₂(H_N) ~ (sup supp / m₁)^{2N}`，而 `c_N` 的相对误差 `~ eps·cond₂`。witness `[3]`（`Unif[0,1]`，即 Hilbert 矩）：`cond₂ = 1.93e1, 5.24e2, 1.55e4, 4.77e5, 1.50e7, 4.75e8, 1.53e10, 4.93e11, 1.60e13, 5.22e14, 1.64e16, 4.47e18`（`N=1..12`），拟合 `10^{1.5N}`；相对误差 `5.1e−6 (N=8) → 1.6e−3 (N=10) → 6.5e−2 (N=11) → 1.6e−1 (N=12)`，`N=12` 的 `c_N` 已**回升**（纯噪声）。**需要的十进制位数 = `2N·log₁₀(sup supp/m₁)`。**
  - **诚实的窗口说明（AGENTS §2.1）**：在 `β=2.5` 的格点上 `sup supp/m₁ ≈ 1/(am₁)`，而 `A4-SCALE-SEP.md:7` 给 `ξ/a ≤ 1.30` ⇒ `am₁ ≈ 0.77` ⇒ 该比值 ≈ `1.3`，`N ≤ 20` 的条件数都温和。**⇒ 条件数墙不是 `2.5` 的墙，是 `a→0` 的墙**：连续统里 `1/(am₁) → ∞`，位数需求 `→∞`。这与 `H08-Z1.md:123` 的"指数病态"同源，但**在 2.5 上并不咬人**——2.5 上咬人的是 §2.3 的数据缺席。

### 2.2 (b) 初等对称多项式 —— **不是独立候选**

`Q_N(λ) = Σ_{k=0}^{N} (−1)^k e_k^{(N)} λ^{N−k}`，其中 `e_k^{(N)}` 是 Gauss 节点的初等对称函数，由 Hankel 系统
```
Σ_j a_j M_{n+j} = −M_{n+K}      （a_j 给出 e_k）
```
解出（`R2-ISOLATION.md:156–163` 已把这条"有限塔 Prony"记为 `[T]`）。Newton 恒等式正是 `{M_k} ↔ {e_k}` 的映射。⇒ **`m₁` = `Q_N` 的最小正根，而 `Q_N` 的系数就是 `e_k`。** 所以：
1. **(b) ⊆ (a)**：`e_k` 只是 pencil 的系数坐标，`[E]` 上已由 `[1]` 直接确认（`Q_N` 的根 = Legendre 节点 = `m₁` 的 Gauss 节点）。
2. **存在性判据**：有限个 `e_k` 存在 ⟺ `ν` 有限原子 ⟺ Stieltjes 变换 `F(z)=P(z)/Q(z)` 有理 ⟺ `rank H_N` 有界。YM 实况 `|supp ν| = ∞`（`H08-Z1.md:123`）⇒ **`e_k` 作为有限对象不存在**（形式上级数 `Σ_k |s_i|` 发散，质量无界）。
3. **有限 `L` 的例外恰好是 vacuous 的那支**：有限格点上 `ν` 是有限原子（转移矩阵有限维）⇒ `e_k` 存在、恒等式在 `N=n−1` 精确（witness `[6]`）——但 `n` = 谱数 ⇒ 指数大，且"有限 `L` 上 `f₁²>0`"已被判 vacuous（`F06-KLATOM.md:182`）。
4. **根映射不连续**：次数 `n` 无界时，"最小正根"作为 `e_k` 的函数非连续（一个根可以从任何位置冒出来）⇒ 与 §2.1 的 usc 是同一条墙的代数面。**判：(b) `[NG]`（不独立 + 存在性条件在 YM 上假）。**

### 2.3 (c) Padé / 连分数 / Stieltjes 变换 —— **2.5 上"成本小、数据无"**

`F(z)=∫dν/(z−s)=Σ_k M_k z^{−k−1}` 的对角 Padé 分母 = `Q_N`；连分数系数（Jacobi 矩阵 `J` 的 `(a_k,b_k)`）给出 `supp ν = spec J`，`m₁ = inf spec J`。这是同一台机器的算子形。
- **在 `β=2.5` 是否可算？** 分三问答：
  1. **成本**：真见原子的坐标是 `λ = e^{−aE}`（转移变量），所需阶 `M ≳ 2/(am₁)`（`H08-Z1.md:64`；`TOOL-COMPLETELY-MONOTONE.md:76`）。在 2.5 上 `am₁ ≈ 0.77` ⇒ `M ≳ 3`。**⇒ 成本不是障碍。**
  2. **数据**：仓内在 2.5 上拥有的是 `Var`、`E[H]`、`D/S ≈ 2%`、`G″ = S−D`（`CLAUDE §5`；`GA4-HAAR.md:92`）——**全是一阶/二阶场空间量**。`M_{+1}`（= `C''(0)` = `⟨O H² O⟩_c`）与更高阶**一个都没有**。⇒ **输入缺席，`[O]`。**
  3. **一致性**：即使拿到精确矩，读数的 `(L,a)` 一致收敛条件是"孤立极点 + `e₂−e₁ ≥ Δ > 0`"，即 `WI-PLATEAU-RIGOR.md:36–40`（逐字："the Padé convergence theorem is *conditional on* the uniform gap, which is the wall"）。⇒ **一致性 = `I2` = H1，`[NG]`。**
- **唯一的正面形状判据**：`WI-PLATEAU-RIGOR.md:22–27` P3 —— 原子的 approach 是**指数** `e₁+Ce^{−Δτ}`，割是**幂律** `e₁+1/τ`。这是仓内最锐的"原子 vs 割"判别律，但 `τ→∞` ⇒ 隔离。`[T]`

**§2 总结**：三候选 = 一台机器（`Q_N` 的三种坐标）。机器本身：`[T]` 恒等式 + `[E]` 可复跑；作为 Clay 工具：`[NG]`（方向 + 数据 + 一致性三重，且三重各自独立成墙）。

## §3 · R6 反例的影响：它不杀恒等式，它杀"有限矩 → 下界"

### 3.1 R6 说了什么（逐字坐标）

`R6-ATOM-ADVERSARIAL.md:252–260`：**对每个 `λ>0, M₀>0, m₁>0` 存在正测度 `ν`**，`M₀(ν)=M₀`、`inf supp ν = m₁`（有隙、固定）、`ν({m₁²})=0`（无原子）、`χ = ∫s^{−1}dν ≤ 1/λ`。构造 `ν = ηδ_{m₁} + (1−η)Unif[θ,θ+W]`，`θ ≥ 2m₁`，`η→0`。
`:263–267` 的后果句：**"No functional built from H1, the moments, the squeeze, positivity, or convex order can lower-bound `f₁²`"**。`GK3-ATOM.md:142,160`（M7/M15）把同一族用作矩/RP 类的判死见证。

### 3.2 它**不**杀恒等式（逐点命题 ≠ 族上一致命题）

恒等式 `m₁ = lim_N c_N` 对**每一个**测度成立，包括每个 `ν_η` 与极限 `Unif[θ,θ+W]`：`ν_η` 的 `c_N ↓ m₁`，极限的 `c_N ↓ θ`。两者都对。R6 说的是**族**的极限行为（`η→0` 时矩收敛而边不收敛），恒等式说的是**点上**的存在性。**⇒ 逻辑上不冲突。** `[T]`

### 3.3 它杀的是**稳定性**：`m₁` 作为矩泛函没有连续模

witness `[5]`（`ν_η = ηδ_{1/2} + (1−η)Unif[1,2]`；`m₁ = 1/2` 对一切 `η>0`；`m₁(η=0) = 1`）：

### 3.6 元层：R6 是 `META-GAPFORCING` 的一个坐标切片

`META-GAPFORCING-IDENTITY.md:11–20`：**不存在逼出隙的精确恒等式**——每条恒等式的解集含无隙元（自由无质量场），恒等式在那里**退化而不被违反**；READING 恒等式存在（Fredholm 零点 / B6），但定位它在连续统中的位置 = 输运/H1。R6 是这句话在 `(M_0, M_{−1}, m₁)` 三坐标上的**定量切片**：它把"含无隙元"加强为"含**有隙但无原子**元，且 `χ` 任意小"。⇒ **R6 的判决与元 no-go 的判决一致：形态三 只能在 READ 语义下活。**
