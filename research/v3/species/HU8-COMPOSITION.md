## §1 ceiling 引理（本文件唯一的定理）

### 1.1 三行
```
数据类  D(λ) := { Λ:𝒥→(0,∞) | ∀j∈𝒥: Λ_j ≥ λ_j } ,  𝒥={j*,…,J},  λ_j:=e^{−2β_jN_p(B)}/C_G ,  β_j=4Nβ₀j ↗
目标量  T(Λ) := inf_{j∈𝒥} Λ_j
合成    = 任意 (I,Φ)：I 是 𝒥 的细化（𝒥×ℬ、超壳划分、块对格），Φ(D)∈(0,∞)，要求 sound：∀Λ∈D: Φ(D) ≤ T(Λ)
引理     ∀ sound Φ :  Φ(D) ≤ inf_j λ_j = λ_J                                [T]
证       Λ⁰:=λ 属于 D（H2 是下界，取等可行）⇒ Φ(D) ≤ T(Λ⁰) = λ_J . ∎      （三行；与 I 的形状无关）
```
- **为什么换形式无效**：上界在**最坏模型** `Λ⁰=λ` 上取到，而 `Λ⁰` 与细化 `I`（壳/块/块对/超壳）无关 ⇒ 换权重、换求序、换坐标都撞同一个数。
- **锐性**：`Λ⁰` 不是纯逻辑点——振荡类 `{osc≤2β_jN_p}` 内存在 Poincaré 常数 `≤4e^{−2β_jN_p}` 的测度（`HS-L3-1.md:78` 两阱），最坏模型在该类内可实到常数 `4C_G`；`4C_Gλ_J` 照样趋零。属**方法类**，不触 Wilson 纤维（`HS-L3-1.md:118` ⑤）。**下一手**：位置图记作"合成类已裁"，不记"合成未试"。

### 1.2 数量（闭式；`N=2`、`L=2`、`N_p=96`、`β₀=0.0464385`、`aΛ=10^{−3}`、`J=9`、`j*=7`）
```
θ=8Nβ₀N_p/ln L = 102.907      λ_J = 10^{−278.80}/C_G（2β_JN_p=641.97 nats）     λ_{j*} = 10^{−216.85}/C_G
sup/inf = 10^{61.96}          每壳比 λ_{j+1}/λ_j = 10^{−30.98}                 乘积聚合 = 10^{−1394}/C_G^J（Σ_{j≤J}2β_jN_p=3209.9）
```
`[T]`（闭式算术）。`λ_J=e^{−2β_JN_p}/C_G` 与 `(aΛ)^θ/C_G` 差一个 `L^{θ·frac}`（整数 `J` vs 实数 `log_L(1/aΛ)`），`a`-无关因子，两式同时趋零。**下一手**：账上把 `λ_{j*}=10^{−216.85}` 标成 "sup，不当地板"——这是唯一"看起来不趋零"的数（§2.3 第 2 行）。

## §2 候选穷举（四类，各带一个数或一条方向）

### 2.1 按块 → 恒等
`Λ_{j,B}≥λ_j`（`λ_j` 与 `B` 无关，`PROVE-H2-uvgap.md:10,13`）⇒ `inf_{(j,B)}Λ=inf_j(inf_BΛ) ≥ inf_jλ_j=λ_J`，换序同数：细化只加坐标、不加信息。**下一手**：若还要"按块"，唯一有内容的量是 2.2 的减法项。

### 2.2 块对合成 = 减法
`inf_j[λ_j−Σ_{B′≠B}|Cov(s_B,s_{B′})|]`：算术闭（`Z₄(√2)=103.1`、`Z₄(π/2)=68.7`；门槛 `Σ|Cov|<δ_W=0.132` ⇒ `C≲1.3–1.9×10^{−3}`），但它要求 `δ_W` 与 `κ>0` **先存在** = M2 + M3（`HQ1-L3.md:113,114`）。输出 `≤` 输入。`[T]`（算术）/`[NG]`（前提）。**下一手**：记作 M3 的下游，不作地板源。

### 2.3 `j`-轴四种聚合
| 聚合 | 形式 | 值 / 方向 | 判 |
|---|---|---|---|
| 加权和/平均 | `Σ_jw_jΛ_j`, `Σw=1` | `≥λ_J`；绑的是平均，而 `inf≤平均` | **方向反**（不控 `inf`） |
| sup | `sup_jΛ_j` | `≥λ_{j*}=10^{−216.85}/C_G`（`a`-无关） | **`sup` 不控 `inf`**：`Λ=λ` 上 `sup=λ_{j*}`、`inf=λ_J` |
| 乘积（Lipschitz 推前） | `C_blk^{−2J}Π_jλ_j` | `10^{−1394}/C_G^J` | **更差**（`ln→ln²`，因子 `(J+1)/2`） |
| 倒数和（鞅/Dirichlet） | `(Σ_jC_blk²/λ_j)^{−1}` | 深壳支配，同指数 `θ` | **无改进** |

前两行是**类型错**（绑错泛函），后两行是**数值更差**；四行合起来把"换一种 `j`-聚合"穷举掉。**下一手**：四种各记一个数进死路台账。

### 2.4 方向引理（与 §1 独立）
`ν_j=P_j#μ_{j+1}`、`Lip(P_j)=C_blk=O(1)`、`a`-无关（`G1-L3-TOWER-POINCARE.md:5–6`）；Lemma SC 逐字 `Var_ν(φ)≤(C_blk²/λ_μ)∫|∇φ|²dν`（`PROOF-COARSE-POINCARE.md:15`）⇔ `Λ_coarse≥Λ_fine/C_blk²` ⇔ `Λ_{j+1}≤C_blk²Λ_j`：**沿塔的流方向只出上界** `[T]`。⇒ "拼块映射拿 `Λ_J` 的下界"方向就错；下界只能来自逐壳纤维条件化（HS），而它的常数正是 `λ_j`。**下一手**：拼映射/推前型合成按此条退回。

## §3 判词与逻辑理由

### 3.1 三条独立理由
1. **最坏模型在类内**：`Λ⁰=λ∈D` ⇒ 任何 sound 输出 `≤λ_J`（§1.1），与 `I` 的形状无关。
2. **方向**：从"块/映射"侧能进来的只有 `Λ_{j+1}≤C_blk²Λ_j`（§2.4，上界）与 `−Σ|Cov|`（§2.2，减法）；两者都不生产下界。
3. **仓内唯一的下界机制是纤维条件化**（Holley–Stroock），它输出的常数就是 `λ_j`（同类内至多差 `4C_G`，`HS-L3-1.md:78`）⇒ 输出与输入同阶。

### 3.2 二难（一句话形式）
```
对载体的任何泛函 Φ：
  (i)  Φ sound            ⇒ Φ ≤ λ_J = 10^{−278.80}/C_G → 0
  (ii) Φ a-无关（≥c>0）   ⇒ Φ 在 Λ⁰=λ 上越过 inf=λ_J ⇒ unsound
⇒「不趋零」与「控 inf」在载体上不可同时成立。                                [T]
```
这不是"合成没做完"：`inf` 合成已做完（恒等，`HT1:55`）；本文件补的是**换任何形式都同一结果**的理由。**下一手**：换载体 `(★_sf)`（同 0.7）。

### 3.3 「按块」三读逐条（任务点名的那一格）
- 块作为**坐标**：恒等（§2.1）；块作为**装配**：减法（§2.2），且要求 M2/M3。
- 块作为**对象**：塔语句本身是 block-local（`Λ_j` = 块内条件测度的 Poincaré 常数，`HS-L3-1.md:33–34`）；块→全纤维装配是**另一条腿**（`PROVE-H2-uvgap.md:27`(iii)，`[NG]`），不在本靶内。
- ⇒ 三读都到不了"新地板"。**下一手**：把 3.3 写进位置图的"已裁类"栏。

## §4 唯一例外：descent（换种子），以及它为什么不在本类内

### 4.1 组式与数
一步引理 `G″_j⪰(1+η_j)^{−1}G″_{j+1}` + 可加损失（`ch15-uvface.tex:112–121`）⇒ 组式 `Ĝ″_0⪰ĉĜ″_J−Σℓ_j`（`HT2:18`）；`ĉ=0.914`、`Σg⁴=0.0908<c_L=0.152`（`j≥8`）。种子 `Ĝ″_J=c_L`（`V1:43,53–55`；`c_L=Q_c=4π²/L²` 是 **`j`-一致**地板）：


### 4.2 为什么它不是「HT1 数据的另一种合成」

```
ĉ·λ_J − Σg⁴ ≈ 0.914·10^{−278.80} − 0.0908 < 0        ⇒ 组式空。                                     [T]
```
⇒ 组式给出正数**完全因为种子 `c_L` 比损耗 `Σg⁴` 大**，而 `c_L` 不在 HT1 的数据里。它是**换载体**（M2 的坐标写法），不是对 `{Λ_j≥λ_j}` 的合成；否则与 §1.1 直接矛盾。
