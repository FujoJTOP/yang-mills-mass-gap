## 1. `O = ¼trF²` 在格点上的核准形式

**另外两个候选为什么不是它**（这也是任务第 1 问的直接答案）：

## 3. `E₁`

⇒ C(0) = f₁² ,  C(L_t/2) = f₁² / cosh(E₁L_t/2)
L_t=2:  f₁² = C(0) ,  E₁ = arccosh( C(0)/C(1) )

## 4. ★ `C(0) = Var_Ω(O)` 吗？—— **是，恒等式**

`[T]`。三句话写清：

1. **定义层**：`C(t) = ⟨Ō(t)Ō(0)⟩_c = ⟨Ō(t)Ō(0)⟩ − ⟨Ō⟩²`。取 `t=0`：
   `C(0) = ⟨Ō²⟩ − ⟨Ō⟩² = Var_Ω(Ō)`。**这不是性质，是同一个式子的两个名字。**
2. **实现层**：本文代码里 `C(0)` 与 `Var(Ō)` 由**同一个估计量**给出，输出两行数值逐位相同
   （`C(0)=2.2521182393e−02`；"mean-of-slice-Var = 0.022414"，差 `1.08e−4` = 纯 MC；
   `L=4`：`1.7570953058e−03` vs `0.001789`，差 `3.2e−5`）`[C]`。
3. **谱层**（这才是 ★ 想问的那一层）：转移矩阵 `T=e^{−aH}`、`T|n⟩=e^{−E_n}|n⟩`、`E_0=0`、
   完备性 `Σ_n|n⟩⟨n|=1` ⇒
   ```
   C(t) = Σ_n |⟨Ω|Ō|n⟩|² e^{−E_n t}  ≡  Σ_n f_n² e^{−E_n t}      [T]
   ⇒ C(0) = Σ_n f_n² = Var_Ω(Ō)                                  [T]
   ```
   于是 **`C(0) = Σᵢ fᵢ²` 成立，且求和一般有无穷多项**（`Ō|Ω⟩` 不是 `T` 的本征矢；
   有限格点、`β<∞` 时 `T` 的谱是离散但**不退化到一项**的；`β=0` 时甚至全简并）。

**必须同时写下的两点，否则这个恒等式会被误用**：

- `[T]` `Var_Ω(Ō) > 0` **无条件成立**（`O` 逐点非负且非常数 ⇒ 涨落必正），
  `β=0`（纯 Haar、无动力学、真值 `f₁²=0`）也成立。所以 `C(0)>0` **不含任何动力学信息**。
- `[C]` `U04-MEASF1.md:18,136–145` 已实测：`β=0` 时同一估计器给
  `f₁²_est = 4.1441(103)e−2`（`40σ`）。**一个在真值 0 处报 40σ 的估计器不能报 `(CP)`。**

`[C]` 另一条**关键的量纲错配**（本任务最容易被当成"结果"的一步）：`Var_Ω(Ō)` 里的 `Ō` 是
`1/V_s` 平均，而 `fᵢ² = |⟨Ω|Ō|i⟩|²` **就是这个 `Ō` 的矩阵元**，所以 `C(0)=Σfᵢ²` 在
**平均算符** `Ō` 上逐字成立；但**物理残数是 `Σ_{x_s}` 求和的那个算符的矩阵元**
（`f²_sum = V_s²·f²_avg`，`U04-MEASF1.md:209`）。平均算符的 `f₁²` 随 `V_s` 掉，
**不是物理残数**。用 `C(0)` 报 `f₁²>0` 报的是 `∝1/V_s` 的数（本文实测 `L=2→L=4`：`12.8×`）。

## 5. 判死线：(a) / (b) / (c)

### (a) `C(0)=Var` 且谱单极点 ⇒ `f₁² = C(0)` ⇒ `f₁²>0 ⟺ Var(O)>0`，可证

**逐字承认**：这条推导**在"单极点"前提下是 `[T]`**，我复述并复核它：
`C(0)=Σᵢfᵢ²`（§4）＋ 只有一项 ⇒ `f₁² = C(0) = Var_Ω(Ō)`；又 `Var>0` 恒成立
⇒ `f₁²>0`。**推理链无洞。**

**但它作为证据是空转的，三条独立理由**：

1. `[T]` **结论与"哪个理论"无关**：`Var_Ω(Ō)>0` 对**任何**非平凡测度成立，含 `β=0`。
   若 `f₁²>0 ⟺ Var>0` 可用，则 `β=0` 也被"证出" `f₁²>0`，与 `t02` 的 `f₁²(β=0)=0`
   （`U04-MEASF1.md:19,128,137` 引用）**直接冲突**。⇒ 该等价关系在唯一知道两边的点上不成立。
   （严格说 `β=0` 处单极点前提失败，故这不是对 (a) 的逻辑反驳，而是说明
   **(a) 的全部内容就是"单极点"这四个字**，而单极点恰恰是不知道的那件事。）
2. `[C]` **单极点在 `L=2` 上不可检验**：`L_t=2` ⇒ 独立点只有 `t=0,1`，两个数、两个参数
   `(f₁²,E₁)` ⇒ **自由度 = 0**，无残差、无 `χ²`（`U04-MEASF1.md:13–16,122–123`）。
   本文把它做实了：`C(1)/C(0)` 在 `L_t=2` 与 `L_t=16` 上差 `3.6×`（`0.383` vs `0.108`），
   而 `e^{−E₁}` 与 `1/cosh E₁` 的差只有 `1.9×` ⇒ **`L_t=2` 的关联里有一半以上不是单极点能解释的**。
3. `[C]` **`C(0)` 量到的是接触项，不是传播**：`U04` 的纯磁场扇区判据在 `L_t=2` 上
   `C_B(1) ≈ 0`（`≤1.5σ`），而 `C(1) ≠ 0` ⇒ `C(1)` 来自 `O(0)` 与 `O(1)` **共用链接**
   （唯一时间薄板上的 temporal plaquette + clover 反射共用空间链接，`U04-MEASF1.md:24–27,146–149`）。
   本文的 `16×2³` 独立支持这一读法：给定 `V_s=8` 拉长 `L_t` 后，`C(t)` 在 `t=2` 已降到
   `0.6%` 且误差 3 倍于信号，`t≥3` 与 0 一致 ⇒ **关联长度 `≲ 1` 步（格点截断尺度），无传播。**

⇒ **(a) 不予采信为 `(CP)` 证据。不得写"`f₁²>0` 可证"。**

### (b) 多极点 ⇒ `C(0)=Σfᵢ²`，只给"某 `fᵢ²>0`"，不给 `f₁²>0`

**判 (b) 为默认情形，明说**：

- `[T]` `C(0)=Σᵢfᵢ²` 一般有无穷多项（§4）。`C(0)>0` ⇒ **存在** `i` 使 `fᵢ²>0`；
  **不能**推出 "`i=1` 那一项 >0"。这是本任务唯一的逻辑判决，无统计成分。
- `[C]` 本文数据**没有**支持截断到一项：`L=4/β=2.5` 的 `m_eff(t)` 只有 `t=1` 可分辨
  （`C(2)` 误差 `219%`）；`16×2³` 的 `m_eff(1)=2.23` 与 `m_eff(2)=2.87` 不相等（后者未分辨）。
  **在能分辨的范围内看不到单极点所需的平台。**
- `[C]` 更硬的一条：`E₁` **随提取方式**从 `1.61` 变到 `2.23`（§3），而单极点要求这个数唯一。
  ⇒ 谱不是单极点，或至少 `L=2` 的关联不是单极点给出的。

### (c) `L=2` 太小 —— **是，判 (c)，需 `L≥4`（实质 `L≥8`）**

四条独立读数（`[C]`/`[T]`）：

1. `[T]` `L_t=2` ⇒ `t=1=L_t/2` 是**最大间距 = 时间反演点**，`C(1)` 被反演伙伴加倍；
   题面的 `e^{−E₁}` 在此处失效（§3）。
2. `[T]` 自由度 = 0（§5a 第 2 条）。
3. `[C]` `E₁` 随 `L` 移动：`1.61`（`L=2`）→ `2.02`（`L=4`）→ `2.23`（`L_t=16`）；
   同 `U04` 的 `L=2→L=4`（`β=2.0`）`1.67→2.35`（`+41%`，`U04-MEASF1.md:196,201`）同型。
   **物理质量不随箱子变** ⇒ 量到的不是质量。
4. `[C]` `⟨O⟩`、`⟨U_p⟩` 的 `L=2 ↔ L=16` 差异（`0.7216 vs 0.7401`、`0.6733 vs 0.6497`）说明
   `L=2` 连 VEV 都未收敛（`U04-MEASF1.md:205–206` 同判）。

**代价（`[E]`，本机 `py -3.12`，numpy 向量化热浴）**：`2⁴×30000cfg×2sweeps` = 123 s；
`16×2³×12000` = 45 s；`4×4³×10000` = 52 s。
要"`t=0..3` 有平台 + 5% 误差"：`L=4, L_t=8`（`512` 站点）估 `≈ 3–5 min/β`；
`L=8, L_t=16`（`8192` 站点）估 `≳ 1 h/β·种子`，`β≥2.3` 的临界慢化再抬一档。
**要判 (a) 与 (b)，最低配置 = `L_t ≥ 8`、`L_s ≥ 6`、`C(2)/C(0)` 误差 ≤ 5%**——本轮不达。
