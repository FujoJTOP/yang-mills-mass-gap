## 1. `m_lat` 与 `aΛ` 是哪个量

### 1.1 `m_lat`（`[D]`，`M05 §1.1` 已钉，本文不改）

```
m_lat(a) := a · m_{0⁺⁺}(a)                    [D]
  m_{0⁺⁺}(a) = 耦合 β(a) 上、无限体积、真空道（A₁⁺⁺ ∩ N-ality 0）、局域载体 ¼trF² 的逆关联长。
  ⇒ 量纲：无量纲（长度 × 质量）。
  ⇒ 若用 I2 的 m₁a = 4ln(1/u) = 18.2638 当分子，就落 A 支（§3）；它不是 a·m_phys。
```
`G05` 的两用（同一符号指两个对象）是 `M05` 已记的缺口 1，本文的数值表把它变成可见的两行。

### 1.2 `Λ` = `Λ_lat`，不是 `Λ_MOM`、不是 `Λ_MS`

```
三条必须同时钉（缺一条 c₀ 就与 scheme 常数混淆）：
  (i)   作用量：Wilson 单 plaquette；
  (ii)  β 约定：β_W = 2N/g²，β_A = β_W/N²（BETA-CONVENTION:64）；
  (iii) 两圈系数：b₀ = 11N/(48π²)，b₁/(2b₀²) = 51/121（N-无关）。
aΛ_lat(β) = (b₀g²)^{−51/121} · exp[−1/(2b₀g²)] · [1+O(g²)]                [C 渐近]
Λ_MS/Λ_lat = 28.809 (SU(3)) / 19.82 (SU(2))     ← A10-SCHEME 表（Capitani §10）[C]
⇒ 换口径只乘一个纯数（28.809 / 19.82），**不改变常数性**，只改 c₀ 的数 29×/20×。
```
**`β` 标签的两个源必须分开**（`BETA-CONVENTION` C-1）：`1/48` 是 `β_A`（SZZ），`2.5` 是 `β_W`（Teper），
差 `N²`。本文两个读法都算（`log` 两组表），因为"四个 β"里两个标签不同源。

## 2. 核心：比值为什么是（并只是）`m_phys/Λ`

```
m_lat/(aΛ_lat) = (a·m_phys)/(a·Λ_lat) = m_phys/Λ_lat           [T，a 约掉]
```
三条推论，逐条：

1. **常数性是定义的推论**。`m_phys` 与 `Λ_lat` 都是物理标度（β-无关，只差 scheme 常数）
   ⇒ 比值 β-无关。这里**没有可检验的动力学内容**。
2. **它等价于 `m ∝ Λ`**：`m_phys = C·Λ_lat`，`C` 纯数。这正是 `L3-TRANSMUTATION` 说的
   "`m=CΛ`，格点无先例"——比值写法把这句话写成了一句不等式。
3. **常数性不给 C>0**。`C=0`（无质量/谱贴 cutoff）时比值恒等于 0，同样是"常数"。
   ⇒ `liminf ≥ c₀` 的全部内容是 `C ≥ c₀ > 0`，即 `(T4)`：`∃Δ₀>0: m_{0⁺⁺}(a) ≥ Δ₀`。

**判词（逐字）**：*"该比值是常数"是零信息；"该比值是常数 C>0"才是有隙。前者的证明义务为零，
后者的证明义务等于 H1 的量纲修正版。`g05` 把前者当成了后者的证据。*

### 2.1 数值标定（`[E]`，两条独立路径对到 0.08%）

```
路径 1（文献 + scheme）：C = (m/Λ_MS)·(Λ_MS/Λ_lat) = 6.28 × 28.809 = 180.92
路径 2（格点直算）：     C = m_phys/(Λ_lat) = 0.568 / 3.1371e−3 = 181.06
  用 β_W=6.00 SU(3)：a⁻¹=2.91 GeV（L2 §6.1）、Λ_MS=263 MeV、Λ_lat=263/28.809=9.129 MeV
  ⇒ aΛ_lat = 9.129/2910 = 3.137e−3；真值 m a = 1.653/2.91 = 0.568。
⇒ 180.92 vs 181.06 —— 差 0.08%。这是唯一一个"四个 β 之外"的真实标定点。
```

## 3. 四个 β 的数值表

`β ∈ {1/48, 0.1, 1, 2.5}`。两圈 `aΛ_lat`（标准式）；SU(2) 与 SU(3) 的两圈 `aΛ` 在 `β_A` 读法下**逐位相同**
（指数 `1/(2b₀g²)` 与 `b₀g²` 都 N-无关），差别只进 scheme 常数，故下表给 SU(3)。

### 3.1 B 支（分子 = `a·m_phys`）：四个 β 全等

| `β`(=β_A) | `aΛ_lat` | `m_lat/(aΛ_lat)` SU(3) | 同上 SU(2) | `m_lat/(aΛ_MS)` SU(3) |
|---|---|---|---|---|
| 1/48 | 0.5700 | **180.9** | **129.0** | **6.28** |
| 0.1 | 0.4708 | 180.9 | 129.0 | 6.28 |
| 1 | 7.690e−5 | 180.9 | 129.0 | 6.28 |
| 2.5 | 1.096e−11 | 180.9 | 129.0 | 6.28 |

**散布 = 0（恒等，`[T]`）**。这张表的四行不是四个测量，是**同一句话的四种写法**：
"`m_phys` 不随 β 变"。它有用处只有一处：把 `c₀` 的数钉成 180.9（Λ_lat）/ 129.0（Λ_lat,SU2）/ 6.28（Λ_MS）。

### 3.2 A 支（分子 = `18.2638`，I2 闭式）：随 β 炸

| `β`(β_A) | `aΛ_lat` | 比值 | `β`(读作 β_W) | `aΛ_lat` | 比值 |
|---|---|---|---|---|---|
| 1/48 | 0.5700 | **32.0** | 1/48 | 0.2756 | 66.3 |
| 0.1 | 0.4708 | **38.8** | 0.1 | 0.4856 | 37.6 |
| 1 | 7.690e−5 | **2.38e5** | 1 | 0.4366 | 41.8 |
| 2.5 | 1.096e−11 | **1.67e12** | 2.5 | 0.1068 | 171 |

- `β_A` 读法：极差 **5.2e10×**。引擎是分子的 `a`-无关性（`G05 §3.2` 的自我否定，`[T]`）。
- `β_W` 读法：极差 **4.6×**，看着"近似常数"——**这是假象**：`β_W∈{0.1,1,2.5}` 落在 `aΛ ∈ [0.1,0.5]`，
  而真实的外推区是 `aΛ ≲ 0.01`（`G05 §1.3`：要 `aΛ≤0.01` 需 `β_W≈2.39(SU3)`）。四个点全在"格距≈Λ⁻¹"的粗格点区。

  ⇒ 表里 `β=1, 2.5` 的 `aΛ`（1e−5、1e−11）**只能读作量级**，不能读作"精确到三位"。

### 3.3 scaling violation（`[C]`）

`O((aΛ)²)`：`β_A=1/48` 时 **0.32**（不能忽略），`β=2.5` 时 1.2e−22（完全可忽略）。
⇒ 若真有格点数据，`β=1/48` 那一点的"常数性"会给出 `O(30%)` 的散布——**那也不是动力学的**。
