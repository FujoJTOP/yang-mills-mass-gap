## §2 合并定义（一行）

```
𝔓_tube(T; β, L) := 𝔫(u,L) · u^{4T} · exp[ Σ_{α≥0} (T−α+1)_+ A(α) ]
        𝔫(u,L) := Σ_{d≥0} n_d(L) u^{4d} ∈ [1, (1−u⁴)^{-1}],      u := c_f(β)/N = β/2N²+O(β³)
   ⇒   d log 𝔓_tube/dT = 4 ln u + φ_dec = −a(κ − f_dec),   κ := 4ln(1/u)/a,   f_dec := φ_dec/a = Σ_{α≥0}A(α)/a = O(u/a)
```

逐项：`u^{4T}` = 四壁支撑（S2 等号类，每股 `T` 片，`4` 个面）；`n_d` = 横向整体位移 `d` 的落点数（`+4d` 片，`FOURWALL:69`；`Σ_d n_d u^{4d}=O(1)` 且 `L`-一致到 `e^{−cL}`，故并进振幅而非余项）；`A(α)` = 附着跨度 `α` 的簇权（`X01:35`，条件 `att Γ⊂[0,T]` 不是 `supp`）；扭折/游走链留 `Z_dec` 内（`DRESSED:38`、`X01:32`）。两个速率 = `log` 对 `T` 的两个线性系数 ⇒ `m₁^{dressed}=κ−f_dec`（`DRESSED:88`）。位移族**只增振幅**：`𝔫≥1`、逐项正 ⇒ `a₀(1−O(u))` 的下界不受损（`Z11:52`）。

## §3 判定：定义还是证明

**定义 + 一条定理。** §2 的书写是定义（`[T]`，不新增 MC、不改任何既有式子）；使这次合并**有用**的那句 —— `C_L(t)=𝔓_tube(T)+𝔓_rest(T)` 且 `inf` 率 `=ln(1/ū)/a` —— 是定理（当前 `[NG]`）。

**证明骨架（顺序 L2 → L1 → L3；L2 是唯一真缺口）**

- **L2（`∂B_T` 乘性与活动界）**：`Σ_{P⊇B_T}w(P)=w(B_T)Z_dec(B_T)` 被 `DRESSED:53` 称作"平凡"，但共享链上不按块乘性；需带边条件活动的显式界 `|A(α)|≤ū^{α+1}/(1−ū)`，`ū=eΔC̄u`，常数显式于 `L,T`。**= 洞 C（`HHH4:22`），仍开。下一手：先做它。**
- **L1（规范化分解）**：任意连结 `P` 唯一分解为 (骨架 `𝔅_T^{(d)}`, 装饰集)，代价 `4T+4d+|dec|`；需最小代价规范（`min(T+d)`，字典序打破平局）防多重计数。`DRESSED:38` 只对领头类证过，含位移/游走的版本未写。记账级。**下一手**：随 L2 一起写。
- **L3（余项率）**：`𝔓_rest:={α>T 越端簇}∪{周长≥6}∪{双管}`（`Z07:129`），率下确界 `ln(1/ū)/a=κ/4−ln(ē)/a`（`Z07:100`），由 `|ε_T|≤Bū^{T}`（`X01:80`、Lemma `X01:123`）给；两块已 `[T]`，只需接上 L1 的分解。**下一手**：回填，撤 `DRESSED:51,94–95` 的 `≥6T` 与 `δ≥κ/3`（`Z07:128`）。

**判**：「合并 ⇒ 二分穷尽 + `δ=ln(1/ū)/a`」`[NG]`；「合并后的 `𝔓_tube` 存在、为正、两速率同处」`[T]`。**酸测**：自由场 `a₀=0` ⇒ `𝔓_tube≡0`，不 vacuous（`DRESSED:127`）。
