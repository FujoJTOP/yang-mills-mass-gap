## §2 每步要什么（引理 / 定理 / 工具）

### ① `[T]` 方差分解
`Var(f) = E[f²] − E[f]²`，`f = ⟨Pᵀ∇S_j,v⟩ = ∂_vS_W`（取 `w = Pv`，`f = ⟨G,w⟩`；只需 `P` 有界）。
工具：无。**这一步不产生任何内容**，它只是把 `(★)` 换成 `E[f²] − E[f]² ≤ E[∂²S·Pv,Pv] + W − δ_W`。

### ② `[T]` Stein + 边际恒等式（两个不同对象，必须分开）
- **(2a) 无条件 Stein + cross-Stein**（`G4:95–110` Lemma G2）：总导数 `∫∂_v[(∂_vV)e^{−V}] = 0`、`∫∂_v[Φ′e^{−V}] = 0`，边界项被 `e^{−V}→0` 吃掉（`∂_vV,Φ′` 增长被 `e^{−V}~(edge-dist)²` 压住）。得
  `E[∂_vV]=0`、`E[∂_v²V]=E[(∂_vV)²]`、`E[Φ′∂_vV]=E[Φ″]`，进而
  `Δ_dyn := E[H]−Var(G) = E[Φ″]−Var(Φ′) = Cov(G,Φ′) = W_geo`（`G4:103`），
  故 **`G″_lit = Δ_dyn + W_geo + X = 2W_geo − 2W_geo ≡ 0`**（`G4:104`，数值残差 ≤10⁻⁶，`G4:110`）。
- **(2b) 边际恒等式**（`G4:87–93` Lemma G1，**不用 IBP**）：`ρ′=−ρE[∂_vV|a]`、`ρ″=ρE[(∂_vV)²−∂_v²V|a]`，故
  `G″(v;a₀) = E_{μ}[∂_v²V|a₀] − Var_{μ}(∂_vV|a₀)`。

工具：紧群/chart 上的散度定理；`ρ_v>0` 下的积分号下求导。**没有新分析**。

### ③ `[T]` Schur / Feshbach 分解（"Savvidy 型分解"的正确形状）
`Π₀ = I−vvᵀ`、`K = Π₀ Hess V Π₀`、`c = Π₀ Hess V v`、`Σ = vᵀ Hess V v − ⟨K⁻¹c,c⟩`，`D := Var(∂_vV|a₀) − E[⟨K⁻¹c,c⟩|a₀]`：
```
G″(v;a₀) = E_{μ}[Σ | a₀] − D                                        （G4:126–131 Lemma G3；S3 Lemma S）
K ⪰ 0（纤维 log-凹）⇒ D ≤ 0 ⇒ G″ ≥ E[Σ]                              （Prékopa 保 log-凹 + Brascamp–Lieb）
```
工具：Schur 补；**Prékopa–Leindler**（线性约束下的 log-凹保持）；**Brascamp–Lieb**（log-凹纤维上 `Var ≤ E⟨K⁻¹c,c⟩`——引文按 `LIT-CHECK.md:41` 更正为 *J. Funct. Anal.* **22** (1976) 366–389，**未逐字核原文**，`[M]`）。
注意：`W_j` 在这里**不再单独出现**——它被溶解进 `Σ`（经 `Φ″`、`Π₀HessΦ`）与 `D`（经 `Var(Φ′)`、`Cov`），见 `S3:160–165`。所以候选的第 ③ 步"用 Savvidy 分解把 E⟨∇f,·⟩ 拆成 E[H]+W−δ"**不是一步不等式，而是 (2b)+(3) 两条恒等式**，且**没有 δ**。

## §3 硬点（按失败概率排序，带数）

1. **④ 的 `D` 符号**（最可能失败）。`D>0` 恰好等价于纤维**失** log-凹：`S3:114–117` 的非高斯见证里 `K>0` 给 `D=−0.0208`（`G″=0.260 ≥ E[Σ]=0.240`），`K` 变号给 `D=+7.29`。head（`β≈2.5`）处 `A_S` 可 Savvidy-不定、`K` 可不 `⪰0`（`S3:144–146`）⇒ ④ 需要在**没有纤维隙**的地方给裕度。
2. **`a` 的量词**（不是技术问题，是**真假**问题）。`(★)` 若读作"所有 `a`"：单 plaquette **精确** `G″ = 0.20511530 − 0.01105929β²`（`MASTER:235`）在 `β>4.30661` 变负，**纵向模在 `im P`、满支撑**（投影救不了）；另一见证给 `G″=0.206−0.0123β²`、`β*=4.09`（`G4:36–39,329`）。**两个 β\* 不一致（4.09 vs 4.30661，系数 0.0123 vs 0.011059）——不同模式/参数化，本轮未裁决，不许取平均**（`AGENTS §2.1`）。
3. **`U′` 的量词**。全 `U′` 强形式 **[NG]**（`frontier:202`；`MASTER:235`）；只剩 `(★_sf)`（小场边界/切除）、`(★_avg)`（对边界平均）、`(★_{δ(U′)})`（边界依赖裕度）三种可写形式。④ 必须先选定一种。
4. **`P` 与条件化变量的相容**（易被忽略的记账）。`(★)` 的 LHS 无条件化，`a₀` 要条件化在 `⟨Pᵀ∇S_j,v⟩` 上；Stein 用测试向量 `Pv`，`H` 侧是 `PᵀH_jP`。若 `P` 非对称/非幂等，`f = ∂_{Pv}S_W` 与 `a = ⟨v,X⟩` 就不是同一坐标——门 0 必须把 `P` 的假设（有界、`Pv` 是粗模）写死。
5. **两个"看起来能用"的假工具**（本轮抓出，写进禁用清单）：
   - `LOOP-RUNBOOK.md:3708`（§11.148）的"`E[H_vv]=E[G_v²]`（Stein）⇒ `E[H]−Var(G)=E[G]² ≥0`"**只在 `Φ≡0` 的参考测度上成立**。物理纤维测度带 `Φ`，正确式是 `E[H]−Var(G) = E[G]² + E[GΦ′] = Cov(G,Φ′)+E[G]²`（由 `G2` 的 `E[G]=−E[Φ′]` 直接算）。拿它当"正裕度"用就是循环。
   - **`(★) ⇔ 2W_geo ≥ δ_W`（S2 归约）无效**（`G4 §0.4`、`G4:118–124`），两个读法都不成立。

## §4 判 (a) / (b) / (c)

**(a) 不可执行**：④ 没有现成工具；`(H-C)`、`(H-SL)` 在语料里都是 `[O]`（`S3:140–141`）。

**(b) 缺物（指名）**：**U′-一致的条件 Schur 裕度**——即
```
∃δ_W>0 :  ∀j ∀U′∈𝒰 ∀v :  E_{μ_{U′}}[Σ | a₀(U′)] − D(a₀(U′)) ≥ δ_W ,
```
在 `𝒰` = 小场边界类、`a₀(U′)` = 该边界下粗模边际的 mode。它的物理内容就是"**对每个 `U′` 都不存在 Savvidy 负模**"，而 Savvidy 负模是**真**的（`CLAUDE.md §5`：`Hess −D²+2adF_B` 不定，`W4` 实测 7.1% 负）——所以缺的不是技巧，是**排除负模的类限制**（`𝒰` 要由 `(H-SL)` 反解）。

**(c) 字面式的一致性不可证 —— 因为它假，不是因为它难**。两条独立理由，都已在账本里：
1. 无 `|a₀`（读 (L)）：`G2 ⇒ G″_lit ≡ 0` **[T]**（`G4:104`，数值 ≤10⁻⁶）⇒ `(★)` 变成 `0 ≥ δ_W`，在**每个模型**（含单 plaquette）每个 `δ_W>0` 都假。这时"在 `j,U′,a` 上一致"是关于常数 0 的一致下界，不可证是因为**它是空命题的反面**。
2. 有 `|a₀` 但量词是"所有 `a`"：单 plaquette 精确多项式在 `β>4.31` 给负值、且模在 `im P` 内 **[NG]**（`MASTER:235`）。

⇒ **只有第三种写法活着**：`|a₀` 取 `a₀ = a₀(U′)`，`U′` 取类，`v` 取粗模，`δ_W` 取归一化后的 `Θ(β_j)`。这时 `(★)` 的**符号**是 `[T]`（`H4 (0.1)`），**裕度**是 `[O]`（H1）。
