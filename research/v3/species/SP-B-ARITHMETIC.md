## §1 三类的 `c_n` 增长阶（显式）

设表面熵 `Ω_A ≃ e^{κA}`（`κ` = 4D 格上单位面积表面的对数计数，纯组合常数，与 `β` 无关），
字符系数 `c_n ≃ e^{−κn} n^{α−1}(log n)^q`。圈权重

```
W(R) = Σ_{A ≤ A_max(R)} Ω_A · Π_p c_{j_p}           A_max ≃ πR²
     ≃ Σ_{A ≤ A_max} A^{α−1}(log A)^q  ≃  R^{2α}(log R)^q
```

⇒ 与 `W ~ R^{−p}` 对齐得 `α = −p/2`，`q` 原样传递。**三类与系数的对应**：

| 类 | `W(R)` | `c_n` 的增长（`n→∞`，`σ₀ := lim −(log c_n)/n`） |
|---|---|---|
| **(E) 指数** | `e^{−σR²}` | `σ₀ > κ`：几何衰减且比值检验**有正隙**（`σ = σ₀ − κ`） |
| **(P) 幂律** | `R^{−p}` | `σ₀ = κ` **恰好**，且 `c_n ≍ e^{−κn} n^{−p/2−1}` |
| **(I) 中间** | `R^{−p}(log R)^q` | `σ₀ = κ` 恰好，且 `c_n ≍ e^{−κn} n^{−p/2−1}(log n)^q` |

反读：`(E) ⟺ c_n 的比值检验有隙`；`(P)/(I) ⟺ 恰好临界 + 幂／幂×对数前因子`。
（"系数奇异性 ⟷ 渐近"是标准件：Flajolet–Odlyzko 的 singularity analysis，`[T-standard]`。）

**两轴必须分开**：`c_n` 是 `β` 的**函数**。表中条件是**逐 `β`** 的；"`c_n` 的值"（如 `u=c_1/c_0`）与"`c_n` 的 `n`-增长"是两个不同的轴，上面三类的分界靠的是后者**加上** `κ`。

## §4 判决 + 两条顺带算出的可核结果（都只动 `(★₁)`）

**判决**：`[NG]`。接口单向：`c_n ⇒ (E)` 仅当 `u<1`；要它吐 (P)/(I) 的判别，需要 `κ`，而 `κ` 不在 `c_n` 的信息里。

**(i) 中间类直接在 `(★₁)` 上就是无解的（比 lead 的"未排除"更强）。** 代 `f = A R^{−p}(log R)^q`：

```
f″ = A R^{−p−2}[ p(p+1)L^q − q(2p+1)L^{q−1} + q(q−1)L^{q−2} ],  L=log R
RHS = c₂g²N A² R^{−2p−3} L^{2q}
```
① R-幂对齐：`−p−2 = −2p−3 ⇒ p = −1`。② 但 `p=−1` 时 `p(p+1)=0`，LHS 的对数阶只剩 `{q−1, q−2}`，RHS 是 `2q` ⇒ 需 `2q=q−1` 且 `2q=q−2` ⇒ **对每个实数 `q` 都矛盾**。③ 作废不了掉的检查：`p=−1 ⇒ f=R ⇒ f″≡0`，LHS`≡0` 而 RHS`=c₂g²N/R≠0` ⇒ **文件里那条 `p=−1` 也不是解**。
把 LHS 换成量纲自洽的 `c₁f″/R`（`f″` 是 `L^{−2}`、`f²/R³` 是 `L^{−3}`，原式差一个 `L^{−1}`）后 `p=0`，再走 ② 同样矛盾（`[V]`，sympy，两种记账都跑）。**⇒ `(P)` 与 `(I)` 整族被同一条方程杀掉；正确表述是"幂律-对数组无解"，不是"唯一解是 `R^{+1}`"。**

