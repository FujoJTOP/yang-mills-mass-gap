### §1.2 为什么机检过的 `susceptibility_squeeze` 对 `m` **零信息**（正面回答）

三句，逐句带方向：

1. **它的两个坐标都是矩。** `M₀=∫dν`、`χ=∫s^{−1}dν`、`f₁²=ν({s₁})` —— 三者都是 `ν` 的**积分（或点质量）**读数。`G2A-INFSUPP-DIRECT.md:32` 逐字：「bootstrap 只**上界** `inf supp`…**矩永不见支撑底**」`[T]`。
2. **支撑底不是矩的函数。** 见证 `H05.md:17`：`ν=√s ds` 与 `ν'=δ_0`（或任意底为 0 的测度）可配出**同一个 `χ`** 而 `s₁=0`。⇒ 任何**只由 `(M₀,χ,f₁²)` 决定**的量，对 `s₁` 至多给上界。
3. **而 `m` 在 `s₁` 的另一侧。** `s₁ ≥ m`（`H06.md:60` 的 `B10-1`，`[T]`）⇒ `s₁` 的下界对 `m` 是**惰性**的（`H06.md:71-73` 的修正写法）；`s₁` 的上界才下传成 `m` 的上界。⇒ **(SQ) 机检为真、且两端都对，但它把 `m` 关在门外**：这是「对落在错对象上」的**已判实例**（`GC3-SANDWICH.md:67`、`MACHINE-SIEVE.md:55`）。

### §1.3 IRB 路线与 squeeze 是**不同**的吗？差在哪一步？

**不同，差且只差一步：`f₁²`（原子） vs. 底层切片（`ν([m,m+ε])>0`）。**

| | `(SQ)` | **Lemma G1（本文件）** |
|---|---|---|
| 变量 | `s`（谱变量 = 质量²） | `r`（时间/距离） |
| 输入数据类型 | **矩**（`M₀, χ, f₁²`） | **整条 Laplace 变换** `r ↦ C(r)`（`r∈[1,∞)`） |
| 左臂靠什么 | `χ ≥ f₁²/s₁`：**只留底原子那一项**（`H06.md:28`）⇒ **必须有原子**，否则该项为 0 | `C(r) ≥ ν([m,m+ε])e^{−(m+ε)r}`：**保留底层整片切片**，该片对**任意** `ν` 非空（`m∈supp ν`） |

**⇒ 一句话**：`(SQ)` 想从**矩**里挤位置（失败，因为矩不见支撑底）；IRB/G1 想从**整条 Laplace 变换**里挤位置（成功，因为 Laplace 变换可逆、确实含支撑底）。**两者不是强弱关系，是「数据类型」不同。** 这也解释了为什么 `(SQ)` 机检了却零信息，而 G1 一行就够——**不是后者更聪明，是后者用了更多数据**。

### §2.1 Lemma G1（逐点上界 ⇒ 下界，**恒等**）

> **Lemma G1.** 在 (G0) 下，定义 `R(r) := −(1/r)·ln( C(r)/C(0) )`，`r>0`。则
> ```
> (i)   R(r) ≥ m          对一切 r > 0                                   [T]
> (ii)  lim_{r→∞} R(r) = m                                               [T]
> ⇒     m = inf_{r>0} R(r) = lim_{r→∞} R(r)                              [T]
> ```
> **证 (i)** `supp ν̂ ⊆ [m,∞)` ⇒ 其上 `e^{−Er} ≤ e^{−mr}` ⇒ `C(r) ≤ M₀e^{−mr}`（`≤`）⇒ `ln(C/M₀) ≤ −mr`（`≤`）⇒ `R(r) ≥ m`（`≥`）。∎
> **证 (ii)** 对任意 `ε>0`：`C(r) ≥ ∫_{[m,m+ε]}e^{−Er}dν̂ ≥ ν̂([m,m+ε])·e^{−(m+ε)r}`（两步都 `≥`）；与 (i) 的 `C(r) ≤ M₀e^{−mr}` 联立取对数 ⇒ `m ≤ R(r) ≤ m+ε+(1/r)ln(M₀/ν̂([m,m+ε]))`（`ν̂([m,m+ε])>0`，因 `m∈supp ν̂` 且 `supp` 闭）。令 `r→∞` 再令 `ε↓0`。∎

> **推论 G1′（上界 ⇒ 下界的**唯一**合法形式）。** 若
> ```
> (H-in)   C(r) ≤ A·e^{−μ r}   对一切 r ≥ 1，且  0 < A ≤ C(0)                [输入]
> ```
> 则 `μ ≤ m`（**下界**）。
> **证** `C(r)/C(0) ≤ (A/C₀)e^{−μr} ≤ e^{−μr}`（`≤`，用的是 `A ≤ C₀`）⇒ `R(r) ≥ μ`（`≥`）⇒ 由 G1(i) `m ≥ μ`。∎
> **必须标出的两个不可省条件**：**`A ≤ C(0)`** 与 **`∀r`**。
