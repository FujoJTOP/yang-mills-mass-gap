## §1 一行式（对象 / 量词 / 有限还是幂）

```
(SV-R2) ∃C₁<∞  ∀a∈(0,a₀]  ∀j∈{j₀,…,J(a)}  ∀U′∈𝒮_t^coer(j)  ∀v∈(kerP)^⊥,‖v‖=1 :
         Var_{μ_j(·|U′,a₀)}(∂_vV)  ≤  C₁                 (裸读 = (★dec) 的 boundedness)
(SV-R1) ∃C₁'<∞ 同上量词 :  Z_j^{-1} Var_{μ_j(·|U′,a₀)}(∂_vV)  ≤  C₁'   (归一读 = [Var bounded]_hat)
      a₀=a₀(j,U′,v),  m(a₀)=−ρ′/ρ=0,  Z_j≍β_j (自由块 Z_j=β_j),  β_j=4Nβ₀j,  J(a)=⌊ln(1/(aΛ))/ln L⌋
      R2 ⇒ R1（C₁'=C₁/Z_{j*}）；R1 ⇏ R2
充要形（M2）：R2 需 C₁ ≤ (1−c)·inf_{j,U′∈𝒮}E[∂²V|a₀]（头部 binding = (1−c)c_H·25.667）
              R1 需 C₁' ≤ (1−c)·inf_j Z_j^{-1}E[∂²V|a₀] = (1−c)(Q_c+m/β_J) ≤ (1−c)Q_c + m/β_J
```

| 读 | `Var` 是哪个 | `sup` 对谁 | 值 / 现有上界 | 判 |
|---|---|---|---|---|
| R0 | 条件（钉点） | 只在 `U′,v`（`j,a` 固定） | `≤144β_{J(a)}²<∞` | **`[T]` 平凡**（有限塔，零内容） |
| R1 | 同上 | `j`+`U′∈𝒮`+`v`，`a`-一致，`Z_j`-归一 | `≤144β_j`；要 `≤(1−c)Q_c` | **`[NG]`**；语义 = `M2` 的 boundedness（`HS-L3-2:50`） |
| R2 | 同上 | 同上，裸 | `≤144β_j²`；要 `≤(1−c)c_Hβ_{j*}Q_c` | **`[NG]`**；尾部比 `M2` 更强（`HS-L3-2:56` 同逻辑） |
| R3 | 比值 `R=Var/(E[H]+W)` | 同上 | 头部实测 `2.273`、`A→0⁺` 发散 | **`[NG]`**；须带窗 `{A>0}∧{G″≥0}`（`HT2:0.4`） |

**判。** "有限"只对 R1/R2 有意义，且**必须带数值上限**（R1：`(1−c)Q_c`；R2：`(1−c)c_H·25.667`）；"某个幂"不成立——`β_j²` 是要消掉的**界**，不是要证的标度。

**判（三层，分开记）。**
1. **那一幂 = `β_j`（`[T]`）**：`Z_j=Θ(β_j)`（自由块精确 `Z_j=β_j`）只把 `β_j²` 除一次，余 `Θ(β_j)`；`Z_j/β_j=1` ⇒ "`Z_j`"是这幂的**归一别名**，不是独立因子。若 `Z_j≍β_j²` 则归一后免费闭合，来源不支持（`V1:320`）。
2. **能否补**：作为**独立的幂次改进**没有来源（唯一 `[T]` 上界就是 `144β_j²`），且它不是"缺一步"：靶的右端 `(1−c)(β_jQ_c+m)` 与 `144β_j²` 差一幂，补这一幂 ⇔ 直接证 `M2`；作为**界**必须换掉 L∞ 上限，换成条件二阶矩/`a`-模估计（0.5）。⇒ 不产新命题。
3. **货币陷阱（`[T]`，两行）**：钉点自由块 `Var_cond=0` ⇒ 靶 `0≤(1−c)(β_jQ_c+m)` 对任意 `c<1` 成立；`1−R=0.01282`(j=7) 属**未条件** `R=Var/(E[H]+W)` 的货币，只有把靶误写成该货币时才限 `c≤0.0128`。**下一手**：任何用 `144β_j²` 论证"缺口一幂 ⇒ 靶难"的稿，先报 `144β_j²/Var_free=38.19` 与货币名。
