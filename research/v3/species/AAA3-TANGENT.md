## §1 凹性 vs `(EP)`：一行量词对照

```
凹性   ∀x,y∈[0,2.5] ∀λ∈[0,1]: f(λx+(1−λ)y) ≥ λf(x)+(1−λ)f(y)   ← 可微时 ⟺ f' 非增
(EP)   单实例 (x,y)=(0,2.5):  f(0)=1 ≤ f(2.5)−2.5f'(2.5)=1.1226 ← 再把 f(0) 弱化为 0 即 (EP)
```

- **严格强于，但强度在 `∀`、不在常数**：凹 ⟹ 切线处处在上 ⟹ `切线(0) ≥ f(0)=1 > 0` ⟹ `(EP)`。反向不成立：`(EP)` 对 `f'(0)` 一无所知，而凹性要求 `f'(0) ≥ 割线 = −0.1390`。
- **同一实例上两式方向相反**：保留 `f(0)=1` ⇒ `β₀ ≤ 7.196`（**上界**）；把 `f(0)` 弱化成 `0` ⇒ `β₀ ≥ 0`（**下界**）。所以"凹性比 `(EP)` 强"不能写成"同一个 `β₀` 的不等式更强"——它是另一个方向的不等式，且在 `∀` 上有无穷多份副本。
- 机检同源：`切线(0) = f·β₀/(β₀−2.5) = 1.122600`（逐位）。

## §2 凹性的可能性：四点不只够判，且判死

- **约定闸（先过）**：题面 `χ_q(2.5)=0.0332` 与 `|plaq'|=0.188` 不是同一个量。仓内恒等式 `𝒮_q = −plaq'/6`（`QQ5-LOCALW.md:0.2`）配 `𝒮_q(0)=1/24`（`OO7-Q3.md:44`，精确 Haar）给 `|plaq'(0)| = 6/24 = 0.25`；`|plaq'(2.5)| = 6×0.0314 = 0.1884`（`RR7-EP.md:0.2` 的 Fano `0.288499×0.6526`）。`0.0332` 是 `𝒮_q` 量级，`χ_q := −plaq'` 才是 0.188。
- **判死（读法 A，`|plaq'|=0.188`）**：凹 ⟹ `plaq'` 非增 ⟹ `plaq'(0) ≥ plaq'(2.5)` ⟹ `|plaq'(0)| ≤ 0.188`；实测 0.25，**超 1.33×**。等价割线形：`|plaq'(0)| ≤ (1−0.6526)/2.5 = 0.1390`，超 **1.80×**。（Haar 直算 `E[cos²φ]=1/4` ⇒ `f'(0)=−1/4` 精确，与 `−6𝒮_q(0)` 相互印证。）
- **判死（读法 B，若硬把 0.0332 读成 `−plaq'`）**：`切线(0)=0.6526+2.5×0.0332=0.7356 < 1 = f(0)` ⇒ 凹性的端点实例**直接不成立**；斜率序超 **7.5×**。两条读法都否，只是否法不同。
- **四点的信息量**：两个值给割线 `−0.1390`，两个斜率给端点序。凹性是 `f''≤0` 的 `∀` 命题，n 个点一般只给必要条件；但这里必要条件**已被违反** ⇒ 结论是"否"，不是"不足"。
- **自洽残留**：`β₀=5.971 < 7.196`，说明端点切线仍在 `f` 上方——**端点实例通过而整体凹性失败**可以并存（曲线在 `(0,2.5)` 中途有拐点）。这正是"一个实例 ≠ 凹性"的实物见证。

## §3 判定

- **能否 `[T]`**：不能。精确障碍不是"缺数据"，而是**数据反证**：`|plaq'(0)| = 0.25 > 0.188 = |plaq'(2.5)|`（读法 A）／`切线(0)=0.7356<1`（读法 B）。要救凹性只能换窗口（如 `[2.2,2.5]` 的局部段）或换对象（`plaq/β` 的单调），那不再是 `[0,2.5]` 上的凹性。
- **`(EP)` 不受影响**：`[T]`（`plaq>0` ∧ `plaq'<0` 两行即得），读数 `1.1226`；切线截距路对它**无增益**，因为它证的是一个更强的**假**命题。
- **下一手（按价格）**：①台账 `(EP)` 供给行改为「`plaq'(2.5)<0` 的符号 + `plaq>0`」，一句话闭合（0 机器）；②保留几何语言则只用 0.3 的夹逼 `0 ≤ β₀ ≤ 7.196` 作一致性闸，新 `L` 序列落地时自动复核；③凹性若复活，必须在**局部窗**上重述（`QQ5-LOCALW.md:0.7`：左侧 21.9σ、右侧 1.35σ），全区间形不可用。
