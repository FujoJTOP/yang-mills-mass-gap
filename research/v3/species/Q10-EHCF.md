## 1. 闭式（两个，一个参数）

切片上 `x = ρ/2 ∈ (0,π)`，切片测度与逐点量：

```
w(x)dx ∝ sin²x / x · e^{B cos x} dx ,        B := β cos(θ/2)        [T，与 o05 l.28 同]
G = ∂_v S = β sin(θ/2) sin x / x = β s · g(x) ,  g = sin x/(2x)    [T]
H = ∂_v²S = β cos(θ/2) g(x)      = β c · g(x)                     [T]
```

于是**逐项闭式**（`s = sin(θ/2)`, `c = cos(θ/2)`，均对 `params` 有 `B`–依赖）：

```
E[H|0]   = (β c / 2) ⟨A₀⟩(B) ,      ⟨A₀⟩(B) := E_{w_B}[g]          [T]
Var(G|0) = β² s² V₀(B) ,            V₀(B)   := Var_{w_B}(g)        [T]
```

**`Var(G|0)` 的闭式 = `β² sin²(θ/2) · V₀(β cos(θ/2))`**，`V₀` 的两个端点都精确已知：

| 端点 | 值 | 来源 |
|---|---|---|
| `V₀(0)` | `(N₂Z − N₁²)/(4Z²) = 0.011059293772973` | `[T]` `h1e`（`Z=Cin(2π)/2=1.218826696528612`, `N₁=0.871244998311964`, `N₂=0.676703157945519`）——本脚本用 `scipy.sici` 独立复算，逐位一致（`h1e_var.log:12-13`） |
| `V₀(B→∞)` | `1/(36B²)`（`B²V₀ = 0.0272437 / 0.0277394 / 0.0277741 / 0.0277774` at `B=10/100/1000/10⁴` vs `1/36=0.02777778`） | `[C]` Laplace：`y=x²~Exp(B/2)`，`g=1/2−y/12+…` ⇒ `Var(g)=Var(y)/144=1/(36B²)` |

`⟨A₀⟩(0)=N₁/(2Z)=0.357411353391`，`⟨A₀⟩(∞)=1/2`，`(1/2−⟨A₀⟩)B → 1/6`（与 `p05_cinf.log:44-47` 的 `0.1665` 一致）。
**注**：`p05` 给的 `⟨A₀⟩∈(0.4424,0.4998)` 是 `B≥2.5`（`β≥2.5`）窗口值；`B→0` 时是 `0.35741`。窗口必须写清（AGENTS.md §2.1）。

`V₀` 单调降（`0.01106 → 0.000277` at `B=100`），故 `Var(G)` 在 `c>0` 时**随 β 饱和**：

```
Var(G) → sin²(θ/2)/(36 cos²(θ/2)) = tan²(θ/2)/36 + O(B^-3)
```

核准（`o05` 存档 `[E]` vs 本式 `[T]`）：`θ=π/2` → `0.027778` vs `o05 sup=0.027773`；`θ=3π/4` → `0.161901` vs `0.161844`。差 `<1e-3`，是 `o05` 在 `β≤1000` 未完全饱和，不是公式错。

## 2. 逐项比：比值随 β 的幂

```
Var(G)/E[H] = 2β sin²(θ/2) V₀(B) / (c ⟨A₀⟩(B))
```

- `c>0, B≫1`：`V₀ → 1/(36B²)` ⇒ `Var/E[H] ≈ sin²(θ/2)/(18 c³ ⟨A₀⟩ β)` ∝ **`β^{-1}`** ⇒ **大 β 成立（不败）**。
- `c=0`（`θ=π`，`B≡0` 与 β 无关）：`Var = β²V₀`，**`E[H] ≡ 0` 对一切 β**。
- 数值（`q10_ehcf.log` §3）：`θ=0.9π` 时 `Var/E[H]` = 0.359 / 0.796 / **1.408** / 1.304 / 0.286 / 0.028（β=1/2.5/6/20/100/1000）——**中间一段违反，两端都回到 <1**。

**所以 `Var>E[H]` 的集合不是 `β>β*`，而是一个有限的 β-窗口 `[β_lo(θ), β_hi(θ)]`**（`[E]`，网格 `β∈[0.1,10⁴]`×`θ∈[0,π]`）：

| `θ/π` | `β_lo` | `β_hi` | 说明 |
|---|---|---|---|
| ≤ 0.8738 | — | — | **无违反**（`θ_crit = 0.8738π`，出现在 `β≈7.8`） |
| 0.90 | 3.38 | 27.8 | `max Var/E[H] = 1.61` |
| 0.95 | 1.34 | 228 | 窗口变宽 |
| 0.99 | 0.26 | `>10⁴`（预测 `~1/(9c³) ≈ 3×10⁴`） | `[C]` `β_hi ≈ 2/(9c³)` |
| 1.00 | 0（无下界） | ∞ | `E[H]≡0` ⇒ **一切 β 都违反** |

## 3. `β*` 到底是什么（重定性）

`β*=4.30660785 = √(W₀/V₀)`（`h1e_var.log:20`）**不是** `Var(G)=E[H|0]` 的根——该方程在 `θ=π` 上对任何 β 都不成立（`E[H]≡0`）。它在 θ=π 上真正等的对象是

```
E[H + Φ''] = 0 + E[Φ''|0] = W₀ = 1/(2Cin(2π)) = 0.205115297123      [T]
```

因为 θ=π 切片上 `S(ρ) ≡ β` 是**常数**，测度与 β 无关 ⇒ `E[Φ'']` 与 β 无关、`E[H]` 被 `c=0` 整体杀掉。`Var(G)=β²V₀` 撞的是一个**β-无关常数**，自然在 `β*` 必输（`q10_ehcf.log` §2：`Var/(E[H+Φ''])` = 0.054 / 0.337 / 1.000 / 1.941 / 5.392 at β=1/2.5/4.307/6/10）。

**判决**：`β*` 的机制是「β² 方差 撞 β⁰ 的 Jacobian 项」，**不是**「β² 方差 撞 β¹ 的 H」。它在 `c>0` 的任何切片上都不存在（H 项回来，且 Var 饱和），故 `β*` **不推广**。

## 4. `β²` vs `β^{1.57}` 的仲裁

**两者都不矛盾——它们是同一个单参数族上的两个点**，族的参数是 `B = β cos(θ/2)`。因为 `Var = β² s² V₀(B)`，

```
k(β) := ∂lnVar/∂lnβ = 2 + ∂lnV₀/∂lnB
```

- `B→0`（`c=0` 或 β 小）：`V₀→const` ⇒ `k=2`（`θ=π` 精确 `k=2.0000`，`o05` 也报 `k=2.0000` 全段）。
- `B` 中段：`k` 连续下滑 ⇒ `θ=0.9π` 在 p19 同一窗口 `β∈[1,6]` 给 `k=1.8242`，`θ=0.99π` 给 `k=1.9866`。
- `B≫1`：`V₀∝B^{-2}` ⇒ `k→0`（`Var` 饱和；`o05 sup_beta Var` 就是 `tan²/36`）。

故 `k` 的取值域是 `(0,2]`，`2` 与 `1.57` 都是合法读数，**没有「哪个对」**；把 `2` 当普适指数才是错。

**`L=2`（`p19`）侧**（`[E]`，源 `p19_fit.log:19-20`、`p19_b6.log`）：`Var(F)/E[κ] = 0.505, 0.787, 0.848, 0.889`（β=1/2.5/4/6）**单调逼近 1 但始终 <1**，`1−D/S = 0.483 β^{-0.834}`，`G''(0) = 0.2835→0.5913 > 0` 全程无穿越。`L=2` 上不存在 `c=0` 的零曲率切片（`E[κ_W]` 是 4 个 plaquette 求和，恒正、随 β 涨 `β^{1.25}` 量级），所以 β² 的「必败」从未发生。

## 5. 判：(a) / (b) / (c)

- **主判 (a) — 采纳，但要说准**：`β²` 是**精确**的（不是数值假象、不是退化切片上的拟合），但它只在 `c=0` 那一个切片上成立，而同一 `c=0` 恰好把 `E[H]` 精确杀成 0。**所以 `β²` 不能当作「大 β 时 `Var>E[H]`」的证据，`β*` 不推广；`p19` 的 `L=2` 结论是那个可推广的对象。**
- **(b) — 对 lattice 被否**：`p19` 在 `β∈[1,6]` 无穿越、`G''(0)>0` 且升。**但保留一句明话**：若 H1 非要在 `⟨ReTr U_p⟩=0`（中心对称）的切片上、并要 `β>β*(θ)`，那 `Var≤E[H]` 就**不可能**——因为 `E[H]∝⟨ReTr U_p⟩` 在该切片恒 0。这条是 `[NG]`（模型内），必须写死，不能当「大 β 一般成立」。
- **(c) — 同时成立，判据给了**：`R(β,θ) := Var/E[H] = 2β sin²(θ/2)V₀(βc)/(c⟨A₀⟩(βc))`。**`Var≤E[H]` ⟺ `R≤1`**；
  - `θ ≤ 0.8738π`：对一切 `β∈[0.1,10⁴]` 成立（`max R = 0.041` at 0.5π）。
  - `0.874π < θ < π`：只在窗口外成立，`β_hi ≈ 1/(9c³)`（`⟨A₀⟩→1/2` 的渐近）随 `θ→π` 发散。
  - `θ = π`：一切 β 不成立。

**一句话**：`β²` 真、但它是 `c=0` 端点；`β^{1.57}` 是同一族在 `B~O(1)` 的读数；`β*` 是撞 Jacobian 的 `W₀`，不是撞 `E[H]` 的 `β`。
