## 1 · 关键：`u = 0.625` 无正根，已经说明什么（任务 1）

方程（`C03:81` 逐字：`R ≤ zu(1+R)^Δ`，取等即"全部装饰树之和"）：

```
R = u(1+R)^Δ ,   Δ = 20 ,   求最小正不动点 R(u)
```

**存在性判据（本文件重新独立推出，仅用一次求导）**：

```
f(R) := u(1+R)^Δ − R ,   f(0)=u>0 ,   f(R) → +∞ (R→∞)
f'(R) = 0  ⟺  (1+R)^{Δ−1} = 1/(uΔ)  ⟹  R* = (uΔ)^{−1/(Δ−1)} − 1
f(R*) = (1+R*)/Δ − R*  ≤ 0  ⟺  R* ≥ 1/(Δ−1)  ⟺  uΔ ≤ ((Δ−1)/Δ)^{Δ−1}
⟹  【正根存在 ⟺ u ≤ u* := (Δ−1)^{Δ−1}/Δ^Δ = ((Δ−1)/Δ)^{Δ−1}/Δ】
```

### ★ 所以"无正根"说明的是**什么**、**不是什么**

**说明的是**（`[T]`）：在 `β=2.5`，`R=u(1+R)^Δ` 这一支**没有不动点** ⇒ 用"根树计数 × `u^n`"做的绝对可和界**在此点不成立**。等价写法：**计数常数 `L_t = 1/u* = 53.000687` 乘 `u` 得 `33.125 > 1`**。

**不是**（`[T]`）：**不是** `λ_Ur·u > 1`。理由是**单向**的：

```
Penrose/KP 树图不等式（C03:69–89）:  |φ^U(Γ)| ≤ Σ_{T 生成树} Π_{p∈Γ}|w_p| ,  |w_p| ≤ u
   ⇒  Σ_{|Γ|=n, p₀∈Γ} |φ^U(Γ)|  ≤  #根树(n) · u^n
   ⇒  λ_Ur := limsup |φ^U(Γ)|^{1/|Γ|}  ≤  limsup #根树(n)^{1/n} = L_t = 53.000687      [T]
```

`L_t` 是**上界**。上界 `L_t·u = 33.125 > 1` 与真值 `λ_Ur·u < 1` **完全相容**。**上界 > 1 什么也证不出。**

### ★★ 而 `gap = 1−ū = −32.98 < 0` 不是"第二个见证"

```
ū := eΔ·u = 54.3656365692 × 0.625 = 33.97849   （= 语料 33.98 ✓）
gap = 1 − ū = −32.97849                        （= 语料 −32.98 ✓）
```

`ū` 用的常数是 `eΔ`，`eΔ` 与 `L_t` 是**同一个 Lagrange 计的松/紧两版**（`eΔ/L_t = 1.0257`）。所以：

> **`gap<0`、`ū>1`、"无正根" 三者是同一个事实 `(计数常数)·u > 1` 的三种写法，不是三个独立证据。**
> 把它们叠加成"因此 `λ_Ur·u>1` 已被隐含证明"是**把上界的失效当成对象的性质**。`[T]`

## 4 · `D_∞(0.25)=1.34487` 对 `λ_Ur` 有约束吗（任务 3）

### 4.1 复现 + 它是什么

`[D]` 段：几何模型闭式 `D_∞ = exp(U(1−2U)/(1−U)³)`（`TT1:125`，本文件独立从 `log D_∞ = Σ_{α≥0}(1−α)A(α)`、`A(α)=U^{α+1}/(1−U)` 重算符合同式）：

|---|---|

| `0.5654`（`β=1/12`） | `0.406188917` |
| `33.9785`（`β=2.5`，**解析延拓，不是和**） | `1.06548684` |

`U=0.25` 是 `ū=1/4` 点（`TT1:62`：`ū=1/4` 恰），**窗内**。所以 `1.34487` 是**窗内的一个几何模型值**，与 `β=2.5` 无关。

### 4.2 `D_∞ > 1 ⇒ f₁² > a₀` 成立，但它不碰 `λ_Ur`

`f₁² = a₀·D_∞`（`RS2:44`、`P4:54`）⇒ `D_∞=1.3449 > 1` 给 `f₁² > a₀`。**这条 `[T]` 成立，但它是振幅侧的话。**

**零约束的理由（不是"没找到"，是"不可能"）**：

```
D_∞ := exp Σ_{α≥0} (1−α)A(α)      ← 一个"值"（级数和）
λ_Ur := limsup |φ^U(Γ)|^{1/|Γ|}    ← 一个"半径"（增长常数）
```

**尺度见证（[D] 段实算，`[T]`）**：固定 `A(α) = U^{α+1}/(1−U)`（`U=0.25`），只在 `α=0` 加一个尖峰：

| 加在 `A(0)` 上 | `log D_∞` | `λ_Ur` |
|---|---|---|
| `0` | `0.2962962963` | 不变 |
| `+1` | `1.2962962963` | **不变** |
| `+5` | `5.2962962963` | **不变** |
| `−3` | `−2.703703704` | **不变** |

`α=0` 只有**有限多项**，`limsup` 对它**完全不敏感**；而 `log D_∞` 被它**任意搬动**。⇒ **`D_∞` 与 `λ_Ur` 是 `{A(α)}` 的相互独立的两个泛函**，任一方都定不了另一方。`[T]`

> **So `D_∞(0.25)=1.34487` 对 `λ_Ur` 的约束是空集。** 唯一能救的说法（`P4:83` 的 `D_∞ ≥ e^{−Θ(ū)}`）也是 `ū` 的泛函、而 `ū` 本身是**计数常数乘 `u`**，同样不是 `λ_Ur`。
