## §1 反模型（逐字抄，`BBB3-LOWER.md:46`）

> 任取 `(λ_c)_{c≠0}∈(0,1)^{N−1}`，置 `T := P_{0⁺⁺} + Σ_{c≠0} λ_c P_c`；它满足直和、`O_h×C` 对称、`T≥0`、`T≤1`、真空单重，却实现任意一组 `(λ_c)`。`BBB3:46`

| 前提 | 满足？ | 备注 |
|---|---|---|
| 直和 `H=⊕_cH_c` | **满足** | `T` 就长在 `⊕_c` 上（`BBB3:44`） |
| `O_h×C`（含 `C`）对称 | **满足** | `P_c` 是 `O_h×C` 投影 |
| `T≥0` | **满足** | `λ_c∈(0,1)`、`P_c` 正交投影 |
| `T≤1`（收缩） | **满足** | `spec T = {1}∪{λ_c}`（`BBB3:10`） |
| 真空单重 | **满足** | `λ_{0⁺⁺}=1` 固定 |
| **局部性**（局部 Gibbs 测度 / 局部 RP 转移矩阵；局部基下**道间非零混合**） | **缺** | 反模型在道指标下**块对角**，`c≠c'` 的矩阵元恒 `0` |
| **跨道不等式** | **缺** | 同缺项（`BBB3:18`：跨道核 = 盲证书 = `f₁²>0` 是**同一件**） |

**读法**：缺的不是"某条估计不够"，而是**在哪个基里看 `T`**——五条前提只读 `spec T` 与道内结构，故对 `(λ_c)` 逐坐标无话。任何新假设若要钉死 `(λ_c)`，必须写出**反模型上取零、真 `T` 上取正**的量。
