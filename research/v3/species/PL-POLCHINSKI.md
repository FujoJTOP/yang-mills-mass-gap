## 首段 · 判死线（T0 三条预判，先给定性）

**T0(a) 凸性/一致正曲率 ⇒ 预判不成立，被源文明确否掉。** BD 判据的正文明写
> *"Contrary to the Bakry–Émery criterion (Theorem 2.8), the initial potential V₀ is **not required to be convex**. The relevant parameter is an **integrated** estimate (3.33) on the Hessian of the renormalised potentials V_t."* —— [R] `arXiv:2307.07619v2` §3.3, Theorem 3.6 后

且判据里的 `λ̇_t` **允许为负**（原文 *"λ̇_t (allowed to be negative)"*）。所以**它不可能是"Savvidy 负模处当场死"**——负曲率被显式地预算进去了。**这一条对 SZZ 是死因，对它不是。**［真正搬过来的死法在别处，见 (b) 与 §4。］

**T0(b) 高斯参考测度 ⇒ 预判"半真"；"有限维近似"半是误判。**
- **有限维近似：不是障碍。** 判据定义在 `X ⊂ ℝ^N` 上恰恰是为了**目标就是 N-一致**（"uniform in the system size up to the critical point"）。N→∞ 是结论，不是前提负担。
- **高斯参考测度：是硬障碍。** (3.10) 要求 `E_{ν₀}[F] ∝ E_{C∞}[e^{−V₀}F]`，即 ν₀ **绝对连续于一个高斯测度**，且 `V₀` 有下界。Wilson 测度的参考测度是**紧群上的 Haar**，不是任何高斯卷积；`β=2.5` 无小参数（`g²=2.4`）也排除了"Haar = 高斯 + 小扰动"。**唯一现成的阶梯是 Theorem 3.20（Riemannian 流形版）**，而作者自陈*"我们目前不知道任何有意思的应用"*、其连续性假设在非平坦情形*"似乎难以验证"*。
- 因此 (b) **不是"前提空 ⇒ 记死"，而是"前提须换载体 ⇒ 走 Theorem 3.20"**。

**T0(c) 只对标量 φ⁴ 成立 ⇒ 预判不成立（判据是通用的），搬运的代价判为"需额外工作"，不是"需新数学"。**
- Theorem 3.6 对 `ℝ^N` 上任意测度成立（不限 φ⁴）；Theorem 3.20 对任意**黎曼流形**成立。`SU(N)` 带双不变度量是紧黎曼流形，且 `Ric = ¼ g_K > 0`——**几何项符号是正的**。
- 但"需额外工作"不是小数目：承重的是**三件**（§3.1 的 `P12 → P10 → P6` 三段链：群上 `Hess V_t` 的可计算表示 → 涨落协方差的算子序压住 → 沿尺度积分到 `+∞`），其中第三段与 `L4`/Balaban 未闭合处重合。
- **一句话**：**(a) 不成立、(b) 半真（要换载体）、(c) 不成立（通用判据）⇒ 该进口不死在预想的三个地方；它的死法在 §5 的 T4 判定里，且是"**未闭合处的坐标变换**"，不是"新物种"。**

## §2 T1 · 前提清单（逐条带定理号，**这是本文件最承重的一节**）

### §2.1 平坦判据（`arXiv:2307.07619v2` §3.3, **Theorem 3.6**）——原句结构

> "Consider a measure ν₀ of the form (3.10) associated with a covariance decomposition Ċ_t differentiable for all t …, and assume also (3.31). Suppose there are real numbers λ̇_t (**allowed to be negative**) such that
>  **(3.32)** ∀φ∈X, t>0: `Ċ_t Hess V_t(φ) Ċ_t − ½ Ċ̈_t ⩾ λ̇_t Ċ_t`,
> and define **(3.33)** `λ_t = ∫₀^t λ̇_s ds`, `1/γ = ∫₀^∞ e^{−2λ_t} dt`. Then ν₀ satisfies the LSI **(3.34)** `Ent_{ν₀}[F] ⩽ (2/γ) E_{ν₀}[(∇F)²_{Ċ₀}]`."

拆成可判定的 7 条：

| 编号 | 前提 | 精确形式 / 出处 |
|---|---|---|
| **P1 空间** | 状态空间是**实线性空间**（有限维子空间 `X ⊂ ℝ^N`） | (3.10) 前后；§3.2 开头 *"measures ν₀ supported on a linear subspace X ⊂ ℝ^N"* |
| **P2 参考测度** | ν₀ **绝对连续于高斯**：`E_{ν₀}[F] ∝ E_{C∞}[e^{−V₀(ζ)}F(ζ)]`，`V₀: X→ℝ` **有下界** | **(3.10)** |
| **P3 协方差分解** | `C_t = ∫₀^t Ċ_s ds`，`Ċ_t ⪰ 0` 有界 cadlag；`Ċ_t` 扮演**逆度量**，t 增大 ⇒ 越来越粗（block-spin） | §3.1；§3.6 Remark 3.16 |
| **P4 重整化势 = Polchinski 流** | `V_t(φ) = −log E_{C_t}[e^{−V₀(φ+ζ)}]`；满足 **Polchinski 方程** `∂_t V_t = ½ Δ_{Ċ_t} V_t − ½ |∇V_t|²_{Ċ_t}` | **(3.11)**、**Prop. 3.4 (3.21)** |
| **P5 核心判据** | `Ċ_t Hess V_t(φ) Ċ_t − ½Ċ̈_t ⪰ λ̇_t Ċ_t`，**∀φ∈X（全字段、逐点）、∀t>0**，`λ̇_t` 可负。**约定**：`Ċ̈_t := d²C_t/dt²`（**不是** `d/dt Ċ_t` 的再求导；本轮用 `intro.tex` 第 3836 行对 `C_t=(A+1/t)^{-1}` 验算过：`Ċ_t=(tA+1)^{-2}`、`Ċ̈_t=−2A(tA+1)^{-3}`、`−½Ċ̈_t=A(tA+1)^{-3}`，三式自洽） | **(3.32)** |
| **P6 常数可积** | `λ_t = ∫₀^t λ̇_s ds` 必须使 `∫₀^∞ e^{−2λ_t}dt < ∞`（即 `λ_t → +∞`；**不要求 `λ̇_t` 逐点为正、不要求单调**） | **(3.33)** |
| **P7 技术性** | 连续性假设 `lim_{t→∞} E_{ν_t}[g(P_{0,t}F)] = g(E_{ν₀}[F])`；原文称*"can be easily checked in all examples of practical interest"* | **(3.31)** |

**两条必须一起记住的补充（否则会把判据误判为"跟 B–É 一样"）：**
- **Remark 3.8 [R]：判据在 `t` 的重参数化下不变。**（3.40）给出 `Ċ₀^a ∫₀^∞ e^{−2λ_t^a}dt = Ċ₀ ∫₀^∞ e^{−2λ_u}du`。⇒ **不能靠"把流跑快一点"买出正的 `λ̇`**；能改的只有流本身的**凸化能力**。
- **§3.5 / Prop. 3.13 [R]：凸化是流的现象，不是原作用量的性质。** §3.5 标题即 *"Example: Convexification along the Polchinski flow for one variable"*，处理 `inf H'' < 0` 但离某段后严格凸的 `H`——正是"负曲率被流吃掉"的最小模型。

### §2.2 流形判据（`arXiv:2307.07619v2` §3.6, **Theorem 3.20**）

> **(3.100)** `Hess_{g_t}(φ) V_t(φ) + ½ Ric_{g_t}(φ) + ½ ġ_t(φ) ⩾ λ̇_t g_t(φ)`，**(3.101)** `1/γ = ∫₀^T e^{−2λ_t}dt`，

### §3.2 为什么 P2 不满足（**不是"难"，是"范畴不匹配"**）

Wilson 测度 `dμ_β = ∏_{ℓ} dHaar(U_ℓ) · e^{−S_W}`。判据要求把它写成 `E_{C∞}[e^{−V₀}]`，即**先有一个高斯，再用 `e^{−V₀}` 加权**。三个具体障碍：
1. **没有"加法"**：`Ċ_t` 是协方差，`φ+ζ` 是向量加法；群上只有乘法。任何指数坐标 `U = e^{X}` 都 (i) 依赖 chart，(ii) 在 cut locus 失效，(iii) Haar 密度 `J(X) = det(sinh ad X / ad X)` 在 cut locus **为零** ⇒ 形式化写出的 `V₀` 含**硬壁 +∞**。
2. **粗化不是热半群**：判据的整个机制是 `E_{C_t}` 为**热半群**（Prop. 3.1: `∂_t F_t = ½Δ_{Ċ_t}F_t`）。Wilson 的粗粒化是**群乘法上的 block spin**，不是任何 `Δ_{Ċ}` 生成的半群。*（唯一出路是**改用**群上的 heat kernel 粗化替代 block spin，见 §4.2——但那已经是**换一条流**，不是原来那条 Wilson 流。）*
3. **无小参数**：若 `β` 很小，可试"Haar ≈ 高斯 + O(β)"；但目标点是 `β=2.5`、`g²=6/β=2.4`、`g≈1.55`、`λ_tH∈[1,7.3]`——**`O(1)`，没有展开参数**。（这三个数是语料既有值：`CTL-CLOSEST` §5.2、`ch13-machine.tex` 第 107 行 `λ_tH∈[1,7.3]`。）

⇒ **必须走 Theorem 3.20（Riemannian）**：把 `SU(N)^{E}` 当黎曼流形，`dm_{g_t}` 当"高斯"的替身。这条阶梯是**源文自己留的**，但 (3.99) 未验证、无应用（§2.2 原句）。

### §3.3 为什么 P10 不满足（**`CTL-CLOSEST` 的 FKG 论证要挪位置**）

`CTL-CLOSEST` §T4-1 说"核心输入是 FKG 型不等式；`SU(N)` 无 FKG ⇒ 第一步就不成立"。**精确化后分两层**：

**(i) 判据层不含 FKG**（§1.3 M1）。(3.32)/(3.100) 对任意测度成立，零相关不等式。

**(ii) 但"验证 (3.32)"这一步在源文里是`三段链`，`YM` 断了前两段**（§2.3 补充，`[R]` 第 3820–3849 行）：

|---|---|---|

### §3.4 为什么 P6 不满足（**几何项补不上，量化**）

```
Hess S_W  ⪰  −(6 c_N / N) β · g ,  c_N = sup_M (−λ_min) ≈ 0.777  (N=3, 4000 Haar 样本)
SU(3), β=2.5:  作用量项 = −3.886    几何项 ½Ric = N/8 = +0.375     ⇒  λ̇₀ ≥ −3.511
```

### §4.2 候选实例化：**群上的 heat-kernel Polchinski 流**（本轮构造，`[T-here]` 的骨架）

### §6.1 算什么、为什么算、精确到什么程度

脚本：`research/v3/species/w7_pl_hess.py`（本轮新增，可复跑）。
**要测的命题**：`T0(b)`/`§3.3` 说"φ⁴ 的非凸性被**抵消项**拖成无界负，所以 BD 判据要额外的凸化输入"。**Wilson 作用量有没有同样的机制？**

> 把 BD 的 Polchinski-LSI 判据进口到 4D 纯 YM，**不死在预想的三个地方**——判据**不要求凸性**（`λ̇_t` 显式可负，`T0(a)` 不成立）、**不要求小参数**、**不是只为 φ⁴ 写的**（`Theorem 3.20` 是通用黎曼流形判据，而 `SU(N)` 双不变度量 `Ric=(N/4)g>0`，`T0(c)` 不成立）；它死在**参考测度**（Haar 不是高斯，须换到 Thm 3.20，而源文自陈该版"无有意思的应用"、连续性假设"难以验证"）与**凸化输入**（`P12` 的平坦协方差恒等式 + FKG/Griffiths/DSS 三段链在 `SU(N)` 上全缺席）。最接近成立的版本是 **`T3*`：heat-kernel Polchinski 流 + 双不变度量 + `g_t≡g`（于是 `ġ_t=0`、`Ċ̈_t=0`）**，它的精确陈述只缺一条 —— **`(★) Hess_g V_t + (N/8)g ⪰ λ̇_t g` 全字段逐点成立且 `∫e^{−2λ_t}<∞`，`(L,a)`-一致**，即"**热核流把 Wilson 作用量凸化到可积无穷**"。**判定：`已有技术 + 改造`（⇒ 无新物种，值得继续），但承重步与 `L4/H1` 是同一堵墙的两个坐标 ⇒ 不构成绕过。** 唯一的结构性红利是真实的：**YM 没有 φ⁴ 那种把非凸性拖成无界负的质量抵消项**——本轮实测 `Hess S_W ⪰ −(4.8/N)β·g`，`c_N≈0.78` 与 `N` 无关（`§6.2`）。
