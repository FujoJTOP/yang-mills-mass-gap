## §0 判决（先写，全部量纲已核）

| 项 | 判 |
|---|---|
| **`c₃` 显式式** | **在唯一能从 `f(R)` 唯一决定的延拓（平面面积泛函 `W=F(A)`，`A=πR²`）里：`c₁ = c₃ = 0`，联合归零。** 一般延拓里 `c₃ = c₁·(1+a)`、`a := c₃/c₁ − 1 ∈ ℝ` **自由**（由圆的**法向**延拓数据与重合点处方决定，见 §3）⇒ **`c₃` 无定义** |
| **数值** | 面积延拓：`c₁ = c₃ = 0.000000`（但这是**退化零**：整个算子消失，方程退化为 `0 = RHS`，不是"双根"）；一般延拓：**无值**（`0/0`） |
| **`c₃ = 0` 还是 `≠ 0`** | **两者都不是答案**：`c₁` 与 `c₃` 从不独立，且可同时为 0 也可同时取任意比值 ⇒ 二分法本身不成立 |
| **判** | **(c)**：右端不能塌成单变量（§4 给两条比 `sp-e`/`sp-f` 更强的理由）⇒ **问题不在 `c₃`，在约化。** 附：**(a) 假**（§5.1 残差恒不为零，与 `c₃` 取值无关）、**(b) 假**（§5.2 `c₁=c₃=0` 使 indicial 恒为零，推不出双根；对数只在 `a=0` 边界出现，成因与 `c₃` 数值无关） |

**一句话**：`(★₁)` 上那个 `f′/R` 槽在几何上要么**空**（面积延拓，算子 ≡ 0），要么**填多少由延拓自由选**（法向导数 `∂_n w` 是一个自由函数）。`c₃` 不是"没算过的数"，是**没有基对象可算**。

## §1 `c₃` 到底是哪个槽（先把槽定死，否则后面全是空话）

`(★)` 两侧量纲（`[T]`，与 `SP-A-SPDE` §0 一致）：`[∂_μ δ/δσ_μν] = L^{−1}·L^{−2} = L^{−3}`；`[∮dy_ν δ⁴(x−y)] = L·L^{−4} = L^{−3}`，`W` 无量纲 ⇒ 两侧同为 `L^{−3}`。✔

`f(R)` 无量纲，`[f″]=L^{−2}`、`[f′]=L^{−1}`。**能凑出 `L^{−3}` 的单项只有两个**：

```
c₁ f″/R + c₃ f′/R²  =  c₂ g²N f²/R³            (★₁″)   [T：量纲唯一选择]
⇔（×R）  c₁ f″ + c₃ f′/R = c₂ g²N f²/R²          (★₁‴)
```

**`[E]` 勘误两处：**
1. `SP-F-EQ1 §2` 的 `(★₁)`（`c₁f″ = c₂g²Nf²/R³`）少一个 `1/R` —— 已由 `SP-A-SPDE §0`、`SP-F-LOOPALG (F1)` 分别抓到，本文确认并给出唯一合法形式 `(★₁″)`。
2. **`SP-C-GMT` 的 `(★₁′)`（`c₁f″ + c₃f′/R = c₂g²Nf²/R³`）右端多一个 `R`**：它的左两槽与 `(★₁‴)` 左两槽同型（对，`c₃` 就是 `SP-A` 的 `c₁′`），但右端应为 `c₂g²Nf²/R²`。**这条勘误直接废掉 `SP-C-GMT §5(2)` 的"刚性精确解"**（见 §5.1）：那个解的振幅 `c₃/(c₂g²N)` 是这条错标度的产物。

**约定**：以下 `c₃` 一律指 `(★₁″)`/`(★₁‴)` 里 `f′` 槽的系数（= `SP-A-SPDE` 的 `c₁′`）。

## §2 步骤 1：圆族上的呼吸方向 = 面积方向（精确，无近似）

`C_R`：`y(θ) = R e(θ)`，`e=(cosθ,sinθ,0,0)`，切向 `t = e⊥`，法向 `n = e`。呼吸位移 `ξ = δR·n`。扫过的面元双矢量

```
dσ_μν = ξ_μ dy_ν − ξ_ν dy_μ ,   n∧t|_{12} = n₁t₂ − n₂t₁ = cos²θ + sin²θ = 1
⇒  dσ₁₂ = δR·dl ,   ∮_{C_R} dl = 2πR = dA/dR ✔        [T]
```

`[V1]` 数值核 `dA/dR = 2πR`：`R=0.7/3/11` → `4.398230 / 18.849556 / 69.115038`。

⇒ **圆族上唯一起作用的形变就是面积形变，权函数在圆上恒为 1。** 这一步是干净的；量纲与 `2πR` 因子都在这儿，不多不少。

## §3 步骤 2：`∂_μ(δW/δσ_μν)` 在 `W=f(R)` 上的精确值 —— 分两种延拓

`W=f(R)` 只说"圆上取 `f`"，**对"非圆的圈"没有任何定义**；而 `δ/δσ_μν(x)` 是逐点的泛函导数。所以必须先选延拓。两种自然的延拓给出**完全不同**的答案。

### §3.1 面积延拓（唯一由 `R` 与 `A` 唯一决定、且面积导数与 `x` 无关者）

`W := F(A)`，`A = πR²`，`f(R) = F(πR²)`。面积泛函的基本事实 `δA/δσ₁₂(x) = 1`（对平面内形变恒等于 1，`x`-无关；这是"面积是面积导数的原函数"）。故

```
δW/δσ₁₂(x) = F′(A) = f′(R)/(2πR) =: κ_A ,   与 x 无关         [T]
δW/δσ_μν(x) = 0 ，(μν) 出平面（A 不变）                        [T]
⇒  ∂/∂x_μ (δW/δσ_μν(x)) ≡ 0                                   [T]
```

**`[T]`（本节主结果）：面积泛函类上，`(★)` 的左端恒等于零。** 于是 `(★)` 在圆族上退化为

```
0 = g²N ∮_{C_R} dy_ν δ⁴(x−y) W(C_xy) W(C_yx) ,   x ∈ C_R       (★|_A)
```

对任何非零 `W` 右端非零 ⇒ **(★|_A) 无解**，唯一解 `f ≡ 0`。
**⇒ 在这个延拓里 `c₁ = c₃ = 0`，且这是"整个算子为零"，不是"首项系数为零"** —— indicial 多项式是 `0·q(q−1) ≡ 0`，恒为零，**"双根"这个词在这里没有内容**（每个指数都是根）。

### §3.2 非面积延拓：`f′` 槽的系数由**法向导数**接管（⇒ 不可定义）

设一般延拓下 `δW/δσ₁₂(x) = ∮dl δ⁴(x−y) w(y)`（`[w]=L`，`[∂W/∂σ]=L^{−2}` ✔）。平面圆上 `B_μν := n_μt_ν − n_νt_μ` 是**常张量**（`= 平面单位面元`），故

```
∂_μ B_μν = 0     （[T]：唯一非零分量为常数，对任何延拓成立）
∂_μ(w B_μν) = B_μν ∂_μ w = t_ν (∂_n w) − n_ν (∂_s w)
⟹ V_ν(x) := ∂_μ(δW/δσ_μν(x)) = −∮dl δ⁴(x−y) [ t_ν ∂_n w − n_ν ∂_s w ]
   第二项 = ∮dl ∂_s w = 0（闭圈）⟹  V_ν = −∮dl δ⁴(x−y) t_ν (∂_n w)        (V)
```

而 `W=f(R)` 只钉住 `w` 的**环平均值**：`∮dl w = f′`（由 §2：呼吸总变分 `= f′δR`）。**`∂_n w` 完全不在 `f(R)` 里** —— 它是圆的**法向（出圈）延拓数据**。

⇒ `[T]`：`(★₁″)` 的两个系数 `c₁`、`c₃` **不是两个独立的几何数**，它们**是同一个自由函数 `∂_n w` 的两种打包**：`f″` 与 `f′` 都经由 `w` 的一阶 `R`-导数进入（`w = f′/(2πR)` 时 `w′ = (f″R − f′)/(2πR²)`，两个槽一起出现，比值为 `c₃/c₁ = −2`；换一个法向延拓，这个比值连续取遍 `ℝ`）。

```
c₃ = c₁ (1+a) ,   a = c₁′/c₁ − 1 ,   a 自由（由 ∂_n w 与重合点处方定）   [U]
```

**这就是 `c₃` 不可定义的机制**：它不是一个待积分的泛函，`(★)` 里没有哪个对象能把它单独钉住。

## §4 步骤 3：右端**不能**塌成单变量 —— 两条比 `sp-e`/`sp-f` 更强的理由

`sp-e §4` / `sp-f (F3)` 说右端依赖分割点。**对，而且更糟：它连"二次"都不是。**

1. **δ 支撑 = 重合点，不是"分割点附近"。** `x ∈ C_R` 时 `∮dy_ν δ⁴(x−y)` 只由 `y=x` 支撑（曲线上的 `δ⁴` 是 3 维横截 δ）。于是取值的不是"某个一般分割"，而是**退化分割**：一支弧长 `→0`（`W→1`），另一支 `→` 整圈（`W→f(R)`）。所以 `W(C_xy)W(C_yx) → 1·f(R)` 的可能极限是**线性**的，`SP-F-EQ1 §2` 的"`f²` 闭包"连极限阶都对不上。`[T]`
2. **短弧依赖 = 处方自由。** 要拿到非退化的 `y`-依赖（含短弧的周长/尖点因子），必须先给 `x=y` 处的**重合点处方**（`SP-F-LOOPALG §3` 的"分割退化"、`SP-E §4` 的"待核实分割项"就是这个）。这个处方是**额外输入**，`(★)` 自己不给；`c₂` 因此也不是纯数，而是处方依赖的常数。

⇒ 右端既**不塌成 `f(R)`**（理由 1），其归一化也**不由 `(★)` 定**（理由 2）。两步都不成立，`c₃` 的"分母" `c₁`、"分子" `c₃`、右端常数 `c₂` 三者同时失去定义。

## §5 步骤 4–5：逐条判 (a)/(b)/(c)

### §5.1 `(a)` 假：`f=(c₃/c₂g²N)R` **在任何维数自洽的约化里都不是解** —— 与 `c₃` 取值无关

用 `(★₁‴)`（或等价地 `SP-A-SPDE (★₁′)`：`F″ + aF′ = κF²`，`F=f(R)`，`s=log R`，`κ=c₂g²N/c₁`）。取 `f = HR` ⇒ `F = H e^s` ⇒ `F′ = F″ = F`：

```
LHS = (1+a) H e^s ,    RHS = κ H² e^{2s}
⟹ LHS/RHS = (1+a)/(κ H e^s)  →  0  (s→∞) ，恒 ≠ 1
```

**`[V2]`**（`κ=1,H=0.5,a=1`）`s=0/1/2/4` 给 `4 / 1.47152 / 0.541341 / 0.0732626`：**从不为 1、且趋于 0**。⇒ `f = HR` 只有在 `H=0` 时"成立"（平凡）。`[T]`
**`[V3]`** 字面 `(★₁)` 同一结论的对照：`f=cR` 给 `f″=0`，而 `RHS = κc²/R ≠ 0`（`R=1/3/10` → `0.25/0.083333/0.025`）。

⇒ **`SP-C-GMT §5` 的"`c₃≠0 ⇒ f=(c₃/c₂g²N)R` 是精确解"是 `(★₁′)` 右端多一个 `R` 的产物**（§1 的 `[E]`②）。把标度摆正，刚性解消失：**刚性指数 `p=−1` 本身是那个错标度的影子**（`SP-A-SPDE §0` 后果一：正确指数平衡是 `p(p−a)=0`，`p ∈ {0,a}`）。

### §5.2 `(b)` 假：`c₁=c₃=0` 不是"双根"，对数也不由 `c₃` 控制

- `c₁=c₃=0`（面积延拓，§3.1）⇒ indicial 恒为 `0` ⇒ **没有根结构**；此时方程是 `0 = RHS`，比"共振"强得多（连方程都不剩）。`[T]`
- 对 `(★₁‴)`，indicial 是 `c₁q² + (c₃−c₁)q = c₁ q(q+a) = 0` ⇒ 根 `{0, −a}`，**`a ≠ 0` 时两两相异**（`[V4]`：`a=1/0.5` 分别给 `{0,−1}/{0,−0.5}`）。`c₃ ≠ 0`（即 `a ≠ −1`）**根本不产生双根**。`[T]`
- 对数真正的来源：非线性项权重 `2p` 与线性核权重 `p` 的共振。匹配 `2p = p` 逼 `p=0`，而 `p=0` 恰是核里的常模（`q=0` 是根，对**一切** `a`）⇒ 常数模是**边缘模**（`λ=0`），修正只能是 `log` 的幂，与 `c₃` 数值无关。`a≠0` 时 `F = c + [κc²/(2a²)]e^{−as} + …`（无 log）；`a=0` 时 `F″=κF²` ⇒ `F = c + (κc²/2)s² + …`（`[V5]`：`c=0.3`，`s=5/10/20` 给 `F−c = 1.125/4.5/18`，即 `log²` 增长）。`[T]+[V]`

⇒ **`SP-C-GMT` 的判决树（`c₃=0 ⟺ 双根 ⟺ 对数强制` vs `c₃≠0 ⟺ 精确刚性解`）两支都不成立**：两支的推论都建立在那条多一个 `R` 的标度上。对数确实被强制 —— 但成因是 `2p=p` 的权共振（`p=0` 常模边缘），即**约化本身的标度结构**，不是某个系数为零。

### §5.3 `(c)` 判：**问题不在 `c₃`，在约化**

```
结论（本文最终判）：c₃ 在此框架内不可定义。
(a) 假（§5.1：残差恒不为零，与 c₃ 无关）；
(b) 假（§5.2：c₁=c₃=0 是退化零，indicial 恒为零；对数来自 2p=p 的权共振）；
(c) 真：右端不塌成单变量（§4 两条），且 f′ 槽系数由自由的法向延拓数据接管（§3.2）。
⇒ 圆的"呼吸单 ODE"不是 (★) 的约化：面积延拓下它恒为零，其余延拓下它的系数不被 (★) 决定。
```

**物种判决（对 `sp-c`）**：`SP-C-GMT` 的"缺口具名且只一个数 `c₃`"**不成立** —— 缺口不在那个槽，在"圆族 `W=f(R)` 是 `(★)` 的一个封闭扇区"这个假设本身。`SP-F` 不是"差一个数"，是**少了整块形状自由度**（`SP-F-LOOPALG (F3)`、`SP-E §4` 已指方向，本文给出"面积延拓恒零"这条硬理由）。
