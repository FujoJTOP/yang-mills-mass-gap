## 1. 判据只有一个，三行证完 `[T]`

设权重 `w` 在环面 `T²` 上周期，族 `w_τ(x)=w(x+τ·λ)`，`Z(τ)=∫_{T²}w(x+τλ)dx`。

```
x ↦ x+τλ 保 Lebesgue 测度  ⇒  Z(τ) ≡ Z(0)  ⇒  (log Z)″ ≡ 0
(log Z)″ = Var(Ψ′) − ⟨Ψ″⟩,  Ψ := −log w
⇒  Var(Ψ′) = ⟨Ψ″⟩   ⇔   gap := S − D ≡ 0        （对任意光滑 w、任意 λ、任意 S_W）
```

推论（本文件全部结论的骨架）：**只要 `S, D` 里的 `Φ` 就是权重里的 `−log(密度)`，`gap` 恒为 0**。所以 `gap ≠ 0` 只能是三种口径病之一：

1. **配对错**：`Φ` 不是权重密度（`r12` 的 `Φ_O09` v.s. 权重 `|Δ|²e^{−S_W}`）；
2. **记账错**：`S_W` 的导数进了 `(G,H)`，权重里却没放 `e^{−S_W}`（`r12` 的 pure-Haar 分支的 `Var(G)`）；
3. **域错**：积分域不是流的环面（`(a,b)` 方形 ⇒ 见 §5；`r03` 的 `SU(2)` 1D 球 ⇒ 见 §2）。

**机检**（`s03_haarneg.log [A]`）：匹配核 `β=0` 给 `S=D=8.00000000`（精确）；`β=2.5` 给 `O(h²)` 残差 `1.05e−4 / 2.62e−5 / 6.56e−6 / 1.64e−6 / 4.10e−7`（`N=256…4096`），Richardson `−4.4e−13`。**换个任意平滑核做同一配对，`gap=1.6e−8`；把核里漏一项 `0.7cos a`，立刻 `−0.584`** ⇒ 恒等式与核的函数形式无关，只与"配对"有关。`[T]`+`[C]`

## 6. 判死线逐条

**(a) 不成立。** `SU(3)` 纯 Haar 的负 `gap` 不能支撑"S_W 的测度是 `SU(3)` 正性的必要条件"。理由：该负值在配对一致时**恒为 0**（§1 恒等式 + §3 `8=8`），`−0.2358` 只是 `Φ_O09 ≠ −log|Δ|²` 的账差（§4 记账恒等式逐位对上）。因此**不能逐字写"S_W 是 `SU(3)` 正性的必要条件"**；这条要说，必须换一个"流不是环面平移"的表示（见 (c) 末尾）。

**(b) 成立 —— 判定在这里。** 三处口径病，逐字：

1. **配对错**：`S, D` 用 `Φ_O09=Σ g(d_ij)`（指数坐标 Jacobian），权重用 `|Δ|²=4·e^{−Φ_A}`。二者差 `ψ=Σ log d²`，`r08` 的平移不变恒等式只对 `Φ_A` 成立。`r08` 的 `8=8` 与 `r12` 的 `−0.2358` 是同一件事的两面。`[T]`
2. **记账错**：`r12` 的 pure-Haar 分支（权重 `|Δ|²`，无 `e^{−S_W}`）仍把 `H, Var(G)` 算进 `S, D`；`−0.23580249 = −0.17471768 − 0.06108481` 拆得干干净净。`[C]`
3. **域错（新，`r12` 与 `S04/S08` 都没提）**：`(a,b)=(x₁−x₂,x₂−x₃)` 不是单射（3 折覆盖），`e^{−S_W}` 在 `(a,b)` 上**只有 `6π` 周期**。机检：同一环面只改切片（chart cut）`δ`，`(0,2π)²` 方形上的 `Z` 从 `260737.78`（`δ=0`）走到 `452173.82`（`δ=2`），**变 73%**；改到 `6π` 基本域则 `δ` 无关（`261192.735911` 三次完全相同）。`ψ` 本身也非周期（`ψ(a+2π)−ψ(a)=+10.148`，`a=0.3`）。 ⇒ **`r12` 的加权分支 `+0.1017` 连"SU(3) 上的平均值"都不是**；纯 Haar 行（权重 `|Δ|²` 是 `2π` 周期）不受此病。`[T]`+`[C]`

**(c) 纯 Haar 下没有 `θ` 窗口。** 纯 Haar 的权重就是 `|Δ|²`，`θ` 只进 `S_W`，所以**纯 Haar 的 `gap` 与 `θ` 无关**——机检 `θ=0, π/4, π/2, 3π/4, π` 全给 `−0.17471620`（错配）/ `0`（匹配）。**若有人看到 `SU(3)` 的 `gap` 在某个 `θ` 上转正，那是 `e^{−S_W}` 分支里错配残差随 `θ` 变号**（`θ=0 → −0.994`，`θ=π/2 → +0.163`，`θ=π → −0.264`，见 `[E2]`），**不是正性**。
真正要换的不是 `θ`，是**表示**：只有把流做成"非环面平移"（7 维 `a=0` 切片 = 1 条本征值方向 × 5 维 flag；或指数/球坐标下 `ξ→ξ+τê` 不保测度），`S−D` 才不再是恒等式、才开始有内容。这是精确缺失的那一步，`[NG]` 在 2D Weyl 里测 `S>D`。
