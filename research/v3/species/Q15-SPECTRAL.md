# Q15 — `Var(G) ≤ E[H]` 是不是谱陈述？

> 2026-11-25 · 裁决：**不是。** 它是 **Stein/散度恒等式 + `Var ≥ 0`**，Hessian 谱在差值里**逐项精确抵消**：
> `E[H_vv] − Var(G_v) = E[G_v]²`。因此"把 `Var(G)≤E[H]` 化成谱条件再用谱方法证"这条路**不成立**——不是因为谱条件错，而是它退化成 `(Σ_k c_k m_k)² ≥ 0`（空条件）。
> `SU(2)` 单 plaquette 上**等号**成立（`E[G]=0`），谱 `λ_k = β cos φ`（**三度简并**），`λ_max = β = 2.5 > 1` ⇒ 通常猜想的"`λ≤1`"型谱条件**反而不成立**，故谱判据既不必要也不充分。

## 1 · `S_W` 沿 `v` 的展开（题设 1）

`U(t) = U e^{itV}`，`V = v·σ/2`，取 `|v| = 2`（单位弧长：`g(A,B) = −½tr(AB)` 下 `|i n·σ| = 1`，测地距 `= φ`）。写 `U = cos φ + i sin φ (n·σ)`：

```
½tr(U e^{itV}) = cosφ cos(t|v|/2) − sinφ (n·v̂) sin(t|v|/2)
⇒ G_v = dS/dt   = β sinφ (n·v̂)
⇒ H_vv = d²S/dt² = β cosφ                     (|v|=2, 弧长)
```
`G_v = ∂_v S_W`、`H_vv = ∂_v²S_W` 与题设一致（`S_W = β(1−cosφ)`）。**[T]**

## 2 · 重写与谱写式（题设 2–3）

设 `h(x) = ∇²S_W(x)`，逐点谱分解 `h e_k = λ_k e_k`，`g_k := ∂_{e_k}S_W`，`v = Σ_k c_k e_k`：

```
G_v   = Σ_k c_k g_k ,              H_vv = Σ_k c_k² λ_k
Var(G_v) = Σ_{k,l} c_k c_l Cov(g_k,g_l)
E[H_vv]  = Σ_k c_k² E[λ_k]
----------------------------------------- 谱式（逐字等价于 Var≤E[H]）
   Σ_k c_k² E[λ_k]  −  Σ_{k,l} c_k c_l Cov(g_k,g_l)  ≥  0 .            (S)
```

**Stein（矩阵形）**：`E[∇²S_W] = Cov(∇S_W) + E[∇S_W]⊗E[∇S_W]`，即 `E[λ_k] = E[g_k²]`。代入 (S)：

```
(S)  ⟺  ⟨v, E∇S_W⟩²  ≥  0       即   E[H_vv] − Var(G_v) = E[G_v]²       (I)
```

`E[G]²` 是个**平方**，`(I)` 恒成立。**谱 `{λ_k}` 不在 (I) 里出现**——这就是"不是谱陈述"的精确含义：谱在差里抵消，`λ_k` 只以 `E[λ_k]=E[g_k²]` 的形式**被恒等式钉住**，不再约束任何东西。

### 2.1 题设猜的 `Σλ_k² ≤ Σλ_k + (Σ…)²` 在哪里才对

它**只**在**二次模型**（`S_W = ½xᵀΛx`，测度 `N(0,I)`，`λ_k` 是确定数）里成立：此时 `g_k = λ_k x_k`、`E[g_k²]=λ_k²`，

```
Var(G_v) = Σ_k c_k² λ_k² ,   E[H_vv] = Σ_k c_k² λ_k
⇒ 条件  Σ_k c_k² λ_k (λ_k − 1) ≤ 0   ⟺   max_{k: c_k≠0} λ_k ≤ 1   ⟺   Λ ⪯ I .    (Q)
```

即 (Q) = **`Hess S_W ⪯ Id`** = 与标准 Gaussian 的 Brascamp–Lieb 比较常数 / Bakry–Émery `Γ₂ ≥ 0`。注意两处修正：`(Σλ_k)²` 项在二次模型里是 `E[G]²`、恰为 0（`E[G_v]=0`），故它**不该**出现在 `Var` 一侧；左端该带 `c_k²` 权重。`(Q)` 是**充分条件**且远强于 `(I)`。

## 3 · `SU(2)` 单 plaquette：谱与数（题设 4）

`S_W = β(1−½trU)`，`U ~ Haar`，测度 `∝ e^{−S_W}dU`（单 plaquette：`∏dU_ℓ = dU_P × const` ⇒ `U_P` 的分布就是 `e^{−S_W}dHaar`）。`SU(2) ≅ S³`（单位球，测地距 `= φ`），`f(φ)=β(1−cosφ)`：

```
λ_radial   = f''(φ)        = β cos φ        (重数 1)
λ_transver = f'(φ) cot φ   = β cos φ        (重数 2)
⇒ {λ_k} = { β cos φ, β cos φ, β cos φ }     三度简并（dim su(2)=3）
```

`f'' = f'cotφ ⇔ f = β(1−cosφ)`：**Wilson 作用是唯一使 Hessian 在 `SU(2)` 上为标量的类函数**。数值验证（`[P3]`，`h=10⁻⁴` 五点差分，6 个随机 `U`）：`max|eig(M) − βcosφ/4| = 3.7×10⁻⁸`。**[T]**

而 `Var(G) ≤ E[H]` 在所有点上**成立且取等**。⇒ 谱条件与目标不等式**不同真**：`(Q)` 假而 `(I)` 真。

## 4 · 裁决

**(a) `[T]` 证明：有，但不是谱证明（且谱条件为空）。逐字：**

> 取左不变方向场 `v`（生成 `U ↦ e^{itX}U`）。Haar 左不变 ⇒ `div_Haar v = 0` ⇒ `∫(vf)dHaar = 0` 对一切光滑 `f`。
> 令 `f·e^{−S_W}`：`0 = ∫v(f e^{−S_W})dHaar = ∫[(vf) − f(vS_W)]e^{−S_W}dHaar` ⇒ `E_μ[vf] = E_μ[f G_v]`，`μ ∝ e^{−S_W}dHaar`。
> 取 `f = G_v`：`E_μ[H_vv] = E_μ[G_v²]`。
> 故 `E[H] − Var(G) = E[G]² ≥ 0`，即 `Var(G) ≤ E[H]`，**等号 ⟺ `E[G_v]=0`**。∎

单 plaquette 上 `E[G_v] = βE[sinφ(n·v̂)] = 0`（`n ↦ −n` 对称）⇒ **恒取等号**，`β=2.5`：`Var(G)=E[H]=1.26799`。**谱无用武之地**。

**(b) 有名字的谱等价只有 (Q)**：`λ_max ≤ 1 ⟺ Λ⪯Id` = Brascamp–Lieb 方差不等式 / Bakry–Émery `Γ₂≥0` 的 Gaussian 比较。它在真实（非二次）`S_W` 上**不成立**（`λ_max=β=2.5`，10.5% 负模）；仓内已有对应物是 `Δ_dyn = E[H]−Var(G) = W_geo = Cov(G,Φ′)`（`G4-GENERAL-BOUND.md` §2 (2.3)、Lemma G2），平坦图里把 `(I)` 的 `E[G]²` 换成 Jacobian 散度项后，不等式 `⟺ W_geo ≥ 0`（Prékopa，仓内 `[T]`）。**外文出处仅名称级：本轮未调 `web_search`/`web_fetch`，DOI 未核，不作引用证据（§3）。**

**(c) `SU(N)`：谱分解可做但无必要。** `SU(N≥3)` 的类函数 Hessian **非标量**：径向 `f''`（重数 1）与横向 `f'·(cot 型曲率因子)`（重数 `N²−2`）分裂，只在 `U=I`（`φ=0`）处任何类函数 Hessian `Ad`-不变 ⇒ 标量 `λ·Id_{N²−1}`（小振幅近似；`SU(2)` 的 `λ=β`）。`[C]`。但 `(I)` 与谱无关，故 `SU(N)` 的谱分裂不影响 `Var(G)≤E[H]` —— 需要的是 `E[∇²S_W] = Cov(∇S_W)+E∇S⊗E∇S`（Stein），不是 `{λ_k}`。

**净结论**：`Var(G) ≤ E[H]` 是**恒等式的一半**（`E[H]−Var(G)=E[G]²`），不是谱条件；`SU(2)` 单 plaquette 给 `{λ_k}={βcosφ (×3)}`、`β=2.5` 时 `E[λ]=1.268`、`λ_max=2.5`、`P(λ<0)=0.105`，等号成立。**"用谱方法证"此路不通（谱条件退化为 `0≥0`），但目标不等式本身是 `[T]`。**
