## 1. `SU(3)` 的 Weyl 公式（显式）

对**类函数** `F(gUg^†)=F(U)`：

```
∫_{SU(3)} F dU = (1/3!) (2π)^{-2} ∫_T |Δ(θ)|² F(θ) dθ₁dθ₂ ,     T: θ₁+θ₂+θ₃ ≡ 0 (mod 2π)
```

Vandermonde 显式（题面要求的两个等价写法）：

```
|Δ|² = ∏_{1≤i<j≤3} |e^{iθ_i} − e^{iθ_j}|² = ∏_{i<j} 4 sin²((θ_i−θ_j)/2) = ∏_{i<j} (2 − 2cos(θ_i−θ_j))
     = s₁₂ s₁₃ s₂₃ ,   s_ij := 4 sin²(x_ij/2) = 2 − e^{ix_ij} − e^{−ix_ij} ,  x_ij := θ_i−θ_j .
```

取 `θ₃ = −θ₁−θ₂`，`dθ = dθ₁dθ₂` 于 `[0,2π)²`（该 patch 是 `T²` 的基本域，一次覆盖）。
**归一化机检**：`CT[|Δ|²] = 6`（= `|W(S₃)|`，逐项常数项 = 1），故 `∫_T|Δ|² = 6·(2π)² = 24π²`，
代回 `(1/3!)(2π)^{-2}·24π² = 1` ✓（`r08_su3_cert.log` `[1]`）。

**适用范围（不许外推）**：上式对**类函数**成立。单 plaquette 的 `S_W = β(1 − (1/3)Re tr(WU^†))` 一般**不是**类函数；本证书取的是"`θ=π` 切片 ⇒ 权重常数 ⇒ 纯 Haar"的那一支，其中被积观测量只依赖环面坐标 `θ`（§2 的 `Φ`、`λ` 方向），公式按此使用。

## 2. `SU(3)` 上的 `J`、`Φ`、`Φ′`、`Φ″`、`G`、`H`（显式）

```
J(θ)  = ∏_{i<j} 4 sin²(x_ij/2) ,          Φ = −log J = −Σ_{i<j} log(4 sin²(x_ij/2))
∂_k Φ = −Σ_{j≠k} cot(x_kj/2)               (x_kj = θ_k−θ_j)
∂²_{kk}Φ = ½ Σ_{j≠k} csc²(x_kj/2) ,        ∂²_{kl}Φ = −½ csc²(x_kl/2)   (k≠l)
```

涨落方向 `τ: θ ↦ θ+τλ`，`λ ∈ t`，`λ₁+λ₂+λ₃ = 0`（本证书取超荷方向 `λ = (1,0,−1)`）：

```
Φ′  = Σ_k λ_k ∂_k Φ = −Σ_{i<j} (λ_i−λ_j) cot(x_ij/2)
Φ″  = Σ_{kl} λ_k λ_l ∂²_{kl}Φ = ½ Σ_{i<j} (λ_i−λ_j)² csc²(x_ij/2)          ← 逐点 ≥ 0
G   = ∂_τ S_W = (β/3) Σ_i λ_i sin(φ_i−θ_i)                                 [W = diag(e^{iφ})]
H   = ∂²_τ S_W = (β/3) Σ_i λ_i² cos(φ_i−θ_i)
```

`θ=π` 切片：`S_W ≡ β` ⇒ 权重常数 ⇒ `ν = |Δ|²dθ / Z`（纯 Haar），且 `G ≡ H ≡ 0` 逐点（切片内 `S_W` 常值）。于是

```
S = E_ν[Φ″] ,   D = Var_ν(Φ′) = E_ν[Φ′²]   (E_ν[Φ′]=0)
G″(0) = S − D .
```

**关键恒等式（`[T]`）**：环面上 `τ` 是**平移**，故 `Z(τ)=∫|Δ(θ+τλ)|²dθ ≡ Z(0)`，`∂²_τ log Z = 0`：

```
∫ J(Φ′² − Φ″) dθ = ∫ ∂²_τ J dθ = 0      ⇔      S ≡ D   （对所有类函数权重、所有 λ 方向）
```

⇒ **纯 Weyl/环面模型对 `S−D>0` 不能给出非空证书；它是恒等式，不是不等式。**

## 3. 化成二维积分（可精确化的原因）

`Φ` 的 `cot/csc` 全部被 `|Δ|²` 吸收（这是能把 2D 积分做成**精确有理**的原因）：

```
s_ij · cot(x_ij/2) = 2 sin x_ij ,      s_ij · cot²(x_ij/2) = 4 − s_ij ,      s_ij · csc²(x_ij/2) = 4
```

故 `|Δ|²Φ″` 与 `|Δ|²Φ′²` 都是 `(θ₁,θ₂)` 的**三角多项式**：

```
|Δ|²Φ″  = ½ Σ_{i<j} (λ_i−λ_j)² · 4 · s_kl s_mn
|Δ|²Φ′² = Σ_{i<j} (λ_i−λ_j)² (4−s_ij) s_kl s_mn
        + Σ_{i<j<k<l} 2(λ_i−λ_j)(λ_k−λ_l) (2 sin x_ij)(2 sin x_kl) s_mn
```

而 `∫_{[0,2π)²} (三角多项式) dθ = (2π)² × 常数项`，常数项用 `fractions.Fraction` **精确**求出（`u=e^{i(θ₁−θ₂)}`、`v=e^{i(θ₁−θ₃)}` 的 Laurent 字典，系数在 `Q[i]` 上精确，最后断言虚部 = 0）。`[T]`

### 3.1 定向舍入（真做）

`π` 只以 `[π_f, π_c] = mpmath.libmp.mpf_pi(800,'f'/'c')` 进入；每个 `+ − × ÷` 走 `libmp` 的 `'f'/'c'` 定向舍入，并统一加绝对外扩 `PAD = 2^-400`。宽度是机检指纹：

| 量 | 区间宽 |
|---|---|
| `Z = 24π² = 236.8705056261446068520277839970276272` | `2.401e−119` |
| `A = B = 192π² = 1894.96404500915685481622227197622101798` | `1.867e−118` |
| `S = D = 8` | `7.516e−121` |

`Z` 宽 `2.4e−119 ≈ 2·PAD·(量级)`：若只做"高精度大概"，上下界会相同（宽 0）或呈 `1e−800` 的 ulp 噪声；这里宽度恰是 `PAD` 的逐操作累积 ⇒ 向外舍入确实发生。`[T]`（口径：精确有理系数 + 定向舍入 + `PAD` 保险丝；唯一外在于纯算术的输入是 `libmp` 的舍入行为，被 `2^400` ulp 余量覆盖）

### 3.2 判定

```
S_lower − D_upper = −7.516e−121 < 0        (区间重叠)
精确值: S − D = 8 − 8 = 0                   (Fraction 相等, CT[A]−CT[B] = 48−48 = 0)
```

## 4. 判死线逐条

**(c) 触发（最尖锐形式）**：`SU(3)` 上不是 `≤0`，而是**恒等于 0**。与 `SU(2)` 的差别在哪里，逐字说清：

| | `SU(2)`（q11） | `SU(3)`（本文，Weyl 环面） |
|---|---|---|
| 测度 | 指数坐标 Haar：`w(u)=sin²u/u du` | 纯 Haar 的 Weyl 像：`|Δ|²dθ` |
| 涨落 `τ` | `ξ₃`（Lie 代数固定生成元方向） | `λ` 方向（**环面平移**） |
| `τ` 是否是测度的对称 | **不是**：`ξ₃`-平移 ≠ 右乘，`J` 随 `τ` 变且非平移 ⇒ `∂²_τ log Z ≠ 0` | **是**：`Z(τ) ≡ Z(0)` ⇒ `∂²_τlogZ = 0` |
| 结果 | `S−D = +0.1359947`（真不等式） | `S−D ≡ 0`（恒等式） |

**`SU(2)` 的正性来自"横向、非对称"的 `ξ₃` 方向；`T²` 上每个方向都是平移，所以 2D Weyl 约化结构性地杀掉了这个差。** 这不是精度的失败，是模型层面的退化。

**(a) 不成立**：没有拿到覆盖 `SU(2)+SU(3)` 的严格证书；本文拿到的是一个 **no-go 型结论**（Weyl/环面路线在 `SU(3)` 上必然给出 `S≡D`，故对 Clay 目标无用）。不许写成"`SU(3)` 也过了"。

**(b) 瓶颈（明说）**：真正的 `SU(3)` 类比需要**指数坐标**（`dim su(3)=8`）：`U=e^{iξ}`、`dμ ∝ J_exp(ξ)d⁸ξ`、涨落沿固定生成元 `E`（如 `λ₈`），此时 `τ` 不是对称方向，`S−D≠0` 才可能出现。但
- 切片是 **7 维**（`⟨E,ξ⟩=0`），`SU(2)` 的"球面切向 ⇒ `Φ′≡0`"降维在 `SU(3)` 不再给出 1/2 维积分；
- Weyl 公式只对类函数成立，**不能**把非类函数的横向观测量搬到 `T²` 上；
- 题面提示的 `θ↔−θ`（Weyl 群 `Z₂`）与 `Z₂` 子群对称**帮不上**：它们只把基本域再砍一半（2D → 2D 的一半），减不掉横向自由度——缺的是横维，不是纵向冗余。

⇒ **降维在本路线下不可行；`SU(3)` 的非零差需要 8 维指数坐标模型上的（数值/区间）计算，不在 15 min 内。**
