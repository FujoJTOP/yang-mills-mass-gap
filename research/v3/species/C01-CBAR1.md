## 1 · `φ^U` 与 `C̄` 的来源（问题 1）

**1.1 `φ^U` 的逐字定义。** 对连通片集 `Γ`、邻接图 `G_Γ`（顶点=plaquette，边=共享 link）：

```
φ^U(Γ) = Σ_{A ⊆ E(G_Γ), (Γ,A) 连通} (−1)^{|A|}                  (1.1)  [T] 定义
```

这就是 cluster/Mayer 系数（`φ^U = φ^T`，Ursell）。三个精确值（S1/S5，整数运算，无浮点）：

| `Γ` | `G_Γ` | `φ^U(Γ)` |
|---|---|---|
| 树（含单点） | 生成树 | `(−1)^{n−1}`，`|φ^U|=1` |
| `K_3`（3 片两两相邻） | `K_3` | `+2` |
| `K_n` | 完全图 | `(−1)^{n−1}(n−1)!` ⇒ `|φ^U|=(n−1)!`（S1：`1,2,6,24,120,720,…`） |
| **`K_6`（一个 link 上的 6 片）** | `K_6` | **`−120`**（S5 实测） |

**1.2 `C̄` 来自哪个求和？——树。** 用 Penrose 树图不等式把 (1.1) 的交错和压成**正项树和**：

```

## 3 · Cayley 不发散：`1/n!` 是必须的（问题 2）

`A01 §2.1` 用 `(n^{n−2})^{1/n}` 判"树熵发散"，**漏了 `1/n!`**：`Γ` 是**无标号的位置集**（`plaquette ⊂ ℤ^4`），`n` 片的位置上的树数 = `(#树形) × (#嵌入)`，而 Cayley 的 `n^{n−2}` 数的是**标号树**，每个无标号树形被重复数 `n!/|Aut|` 次。除 `n!` 后（S3，`lgamma` 精确）：

| `n` | `(n^{n−2})^{1/n}`（`A01` 口径） | `(n^{n−2}/n!)^{1/n}`（正确口径） |
|---|---|---|
| 5 | 2.626528 | 1.008198 |
| 20 | 14.822689 | 1.784928 |
| 100 | 91.201084 | 2.400490 |
| 500 | 487.723997 | 2.630276 |
| 1000 | 986.279486 | 2.669288 |
| `∞` | `n/e → ∞`（假发散） | **`e = 2.718282`（收敛）** |

⇒ **每顶点树熵 = `e`**（纯 Cayley+Stirling），再乘位置邻接度 `Δ`：**`λ_tree = eΔ = 54.365637`**。

**这就是问题 2 的答案：Ursell 展开用的是"树"，但正确的树计数是"标号树 `/n!`"，它收敛，且熵恰好是 `eΔ`——和动物计数 `≤(eΔ)^n`（`P3-FULLREP-KP:89`，`λ_a=eΔ`）是同一个常数。** 树熵 = 动物熵。

## 4 · 一笔账定理：`C̄ = 1`（求和级）的逐字证明（问题 3）

> **Lemma 4.1（位置树恒等式，`[T]`）.** 设 `𝒢` 为任一图（顶点=plaquette），`x ∈ 𝒢`，`a_p ≥ 0`。则
> ```
> Σ_{Γ∋x, Γ 连通} τ(G_Γ) ∏_{p∈Γ} a_p  =  Σ_{T: 𝒢 中的树, x∈V(T)} ∏_{p∈V(T)} a_p .      (4.1)
> ```

> **Theorem 4.2（一笔账，`[T]` modulo (1.2)）.** 对固定 plaquette `x`、`u>0`、权重 `|w_p|≤C_g u`：
> ```
> Σ_{Γ∋x} |φ^U(Γ)| ∏_{p∈Γ}|w_p|  ≤  Σ_{T∋x} (C_g u)^{|T|}  ≤  (λ_T C_g u)^{|T|} 求和 ≤ ...          (4.2)
> ```
> 且 **`λ_T = λ_a = eΔ`**：树和与动物和是**同一个常数**（§3 + `P3-FULLREP-KP:89`）。
> *证明.* (1.2) 逐项 + Lemma 4.1 ⇒ 第一个 `≤`；树计数（每顶点 `eΔ`，§3 的 `e` × 位置 `Δ`）⇒ 第二个 `≤`。∎

```

**理由：** `X01:71` 的链是「`|φ^U|≤C̄^{|Γ|}u^{|Γ|}`」**再乘**「动物数 `≤(eΔ)^{|Γ|}`」。但 `τ(G_Γ)`（树）**已经**是"连通集"计数的超集（每个动物都有生成树），`Σ_{Γ∋x}τ(G_Γ)` 就是**树的计数**；把它再乘动物数，等于**付两遍**。树的部分被 `Σ_{T∋x}` 整体吸收 ⇒ `C̄` 只剩 `1`。
