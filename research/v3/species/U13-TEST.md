## 1. 设定与判据

模型由**谱数据**给：转移算符谱 `E_i ≥ 0`、权重 `w_i ≥ 0`，`C(t) = Σ_i w_i e^{-E_i t}`（**本文一律取"扣除真空 `δ_0`"的连通 `C`**）。`μ` = `C` 的谱测度。
`c3` 从 `μ` 的**支撑**读，`c1/c2/c4` 只用 `C(t)` —— 三条路**互不共用数据**。

| 候选 | 定义 |
|---|---|
| c1 | `lim_{t→∞} −(1/t) log|C(t)|` |
| c2 | `lim_{t→∞} C(2t)/C(t)` |
| c3 | `inf supp μ` |
| c4 | `E₁ = lim_{t→∞} log[C(t)/C(t+1)]`（局域对数斜率 = 首激发能） |

| 模型 | 结构 | 参数 | 候选**应有** |
|---|---|---|---|
| **M6** | 谐振子 tower `nω`（⊗）自由模（`E=0` 零模） | `G″=2ω>0`，**`m=0`** | **0** |
| **2D YM** | `E_j=(g²/2)j(j+1)`，`j=1/2,1,…`；最轻非平凡 `j=1/2` | `G″=0`，`m=3g²/8>0`（`g=1` → 0.375）`[M]` | **>0** |
| **自由场** | `ρ(E)=E^{1/2}` 连续谱，闭式 `C(t)=Γ(3/2)t^{-3/2}` | `m=0` | **0** |
| **单 plaquette** | 一个 `U`，无 transfer 方向 | `m` 无定义 | **无定义**（不是 0） |

**判据（任务给定）**：`m=0` 的模型给 0；`m>0` 的模型给 >0；无 transfer 方向给"无定义"。

## 3. 判死线

### (a) 四模型全对的候选 → **c1、c3、c4 全对，c2 独败**

但**必须立刻说清**：`[T]` 对任意有限正测度 `μ`（支撑有下确界 `E₀`、阈值附近不超指数稀薄），

```
lim_{t→∞} −(1/t) log C(t)  =  inf supp μ  =  lim_{t→∞} log[C(t)/C(t+1)]  =  E₀
```

三者是**同一个泛函的三个写法**（拉普拉斯/Laplace–Stieltjes 渐近的两个等价形式），因此 **c1=c3=c4 只是一个独立成功，不是三个**。
**唯一正确的量**：谱隙 `Δ := inf supp μ（扣除真空 δ₀）` `[C]`，其两个可直接测的等价格 `−(1/t)log|C(t)|` 与 `E₁`。

**c2 单独失败，且失败方式是结构性的**（`[T]`）：
`C(2t)/C(t)` 在有隙时 `→ 0`、无隙时 `→ 1`、**幂律尾时 `→ 2^{−α}`**。它对 `E₀` 不敏感，只对"有无指数尾/幂律指数"敏感 ⇒ **它不是谱隙，甚至不是任何与 `m` 的函数**（自由场 `0.3536` 会被读成"有隙"，M6 的 `1` 会被读成"无隙"，与真值全反）。

### (b) 是否"全部候选在 M6 上都给 >0" → **否**

- **c2 触发（b）**：M6 上给 `1.0000>0`，与 `m=0` 直接矛盾 ⇒ c2 测的不是谱隙，明说。
- `c1/c3/c4` 在 M6 上给 **0**，通过最硬试金石。

### (c) 是否"M6 给 0 但 2D YM 也给 0" → **主表不触发；变体触发，见下**

主表：无（`c1/c3/c4` 在 2D YM 上给 `0.3750>0`）。

**但有一个必要条件必须点名** `[E]`：c3 若**忘记扣除真空 `δ₀`**（用 `μ_full = δ₀ + μ`）：

| 模型 | `inf supp μ_full` | 后果 |
|---|---|---|
| M6 | `0` | — |
| **2D YM** | **`0`** | 与 `m=3g²/8>0` 矛盾 ⇒ **(c) 触发** |
| 自由场 | `0` | — |

即：**c3 只有在"真空已扣除"的窗口里才是谱隙**；不扣真空时它在 M6 与 2D YM 上同给 0，判死线 (c) 立刻打死它。
（同理 c1/c4 也隐含"`C` 为连通/真空扣除后的 `C`"—— 若不扣，`C(t)→w₀` 常数，三者同给 0。）

## 4. 这个试金石真正的教训 `[T]`

| 模型 | `G″` | `m` | 结论 |
|---|---|---|---|
| M6 | `2ω > 0` | `0` | **曲率 > 0 ⇏ 有隙** |
| 2D YM | `0` | `3g²/8 > 0` | **曲率 = 0 ⇏ 无隙** |

⇒ 任何从 `G″`（或其一半、或 `f₁²`）**直接读**质量的候选，在两个模型上**同时错**，不是"窗口没取对"而是**对象错**：`G″` 是作用量的二阶变分（涨落/方差），`m` 是转移算符谱的基底。二者由 M6/2D YM 这对反例**证明互不蕴含**。
⇒ 正确的量只能是**转移（自伴、正）算符的谱量**：`Δ = inf supp μ`（扣除真空）。

**窗口声明（§2.1）**：`Δ` 的值依赖"取哪些算符 `O`"与"哪些扇区"。
本文对 2D YM 取**全部非平凡扇区** `{j≥1/2}` ⇒ `Δ=3g²/8`。
若 `O` 只耦合整数 `j`（例如基本表示 Wilson 线，`1/2⊗1/2=0⊕1`），同一函数在该窗口上给 `g²` 而不是 `3g²/8` —— **函数同一个，窗口不同**。本测试的判据（0 / >0 / 无定义）在两种窗口下都不变。
