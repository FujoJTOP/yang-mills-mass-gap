## §1 减元：`(★₁)` 是自治方程

设 `k := c₂g²N/c₁ > 0`（`c₁,c₂` 语料未算，本节结论**对所有 `k>0` 成立**，符号与 `k` 无关）。令

```
s := log R ,   h(s) := f(R)/R   （尺度不变剖面）
⇒   f′(R) = h + h′ ,   f″(R) = (h′ + h″)/R
⇒   (★₁)  ⟺   h″ + h′ = k h²                                   (★₂)
```

`(★₂)` **自治**（`s` 不再显含），故可用能量法。`(★₂)` 的力学读法：

```
ḧ + γẖ = −V′(h) ,  γ = 1（单位阻尼）,  V(h) = −(k/3)h³        （反号立方）
```

**`h>0` 侧势无下界（爆破解）；`h<0` 侧有极小 `h=0`，但退化（`V∼|h|³`，无线性频率）。**

## §2 Q1：单调量的正确定义与它真正判出的东西

```
Θ(s) := ½ h′(s)² + V(h(s)) = ½ h′² − (k/3) h³
Θ′(s) = h′(h″ − k h²) = − h′(s)²  ≤ 0                             (MON)
```

`R` 形式（`h′ = (Rf′−f)/R`）：

```
Θ(R) = ½ (f′ − f/R)² − (k/3) f³/R³ ,   dΘ/d log R = − (f′ − f/R)²  ≤ 0        (Θ)
```

**`[V]` 数值核验**（`k=1`，RK45 `rtol=1e-11`，初值 `(h,h′)=(1,0)/(0.5,−0.5)/(−0.5,0)`，`s∈[0,60]`）：`max ΔΘ` 三组分别为 `−1.0e−10 / −4.8e−10 / −1.5e−11`，**违例数 `0/0/0`**。⇒ `(MON)` 确为单调量 `[T]`。

**为什么不是 `R f′/f`**：`R f′/f = 1 + h′/h = 1 + (log h)′`；`(log h)′` 可正可负可振荡，**不单调**。

**等号情形 = 刚性指数**：
```
Θ′ ≡ 0  ⟺  h′ ≡ 0  ⟺  f′ = f/R  ⟺  f = cR   （自相似，p = −1）
```
⇒ **`p = −1` 恰好是单调量的刚性/校准情形。** 这正是 Q1 要的答案，但**判在等号，不在极限**。

**极限值 `Θ_∞` 无用（诚实）**：下面所有非爆破解都有 `h→0, h′→0` ⇒ `Θ_∞ = 0`。分辨靠**率**：

| 支 | `h(s)` | `f=Rh` | `Θ` 的衰减率 |
|---|---|---|---|
| C | `B e^{−s} + (kB²/2)e^{−2s}` | `→ B`（常数） | `∼ ½B² e^{−2s}`（指数） |
| E | `−1/(k s)` | `−R/(k log R) → −∞` | `∼ 1/(3k²s³)`（`[V]` 拟合 `−2.79`） |
| 爆破解 | `→ ±∞`（有限 `s`） | `→ ±∞` | `→ −∞` |

## §3 Q2：单调性 ⟺ 能量不等式（显式），以及它断在哪

**是恒等**：`(MON)` **就是** `(★₂)` 的能量耗散恒等式，`Θ` 的“摩擦功率” `−h′²` 精确等于 `−γẖ²`（`γ=1`）。等价写法（把 `(★₁)` 乘 `h′` 再积分）：

```
½(h′²)|_a^b − (k/3)(h³)|_a^b  =  −∫_a^b h′(σ)² dσ
⇔  Θ(b) − Θ(a) = −∫_a^b h′(σ)² dσ  ≤ 0
```

**GMT 单调性公式给结论靠三件事，这里两件不成立**（这是本文件的核心诊断）：

| # | 要件 | 本处 | 证据 |
|---|---|---|---|
| 1 | `Θ` 单调 | **✔** | `Θ′=−h′²≤0`，`[V]` 违例 0 |
| 2 | `Θ` **有下界** | **✘**（`c₃=0` 时） | `V=−(k/3)h³` 反号；`h>0` 侧无下界。**`[V]`：9 组初值中 7 组在有限 `s` 内爆破解**（`h` 达 `10²⁴`）。**放回 `c₃>0` 后有下界（§5）** |
| 3 | 等号情形刚性 | **✔ 但被方程禁掉** | 等号 = `f=cR`；代入 `(★₁)` 得 `0 = c₂g²Nc²/R` ⇒ 只有 `c=0`。**`[V]`：`c=0.5/1.0/−0.7` 全是 `LHS=0, RHS≠0`** |

**⇒ 缺口在要件 2（无底），不在要件 2 的常数。** 单调量在这里**不是"下界机器"，是"上界机器"**：它只能证明 `Θ` 下降得多快，不能证明它掉到哪。

## §4 Q3：对数不是排除不了 —— 是**强制**

三条独立理由：

1. **Frobenius 共振 `[T]`（`c₃=0` 时）。** `f=R^α`：`α(α−1)R^{α−2} = kR^{2α−3}` ⇒ 指数方程 `α−2 = 2α−3` ⇒ **唯一根 `α=1`**，且系数 `α(α−1)|_{α=1} = 0`。**单根、双重** ⇒ 第二解是 `∂_α R^α|_{α=1} = R log R` ⇒ **对数出现在前阶**。若把 `c₃` 放回，系数变 `c₃ ≠ 0`，共振解除、`f = (c₃/(c₂g²N))R` 是精确解（§5）。
2. **等号情形被禁 ⇒ 强制 `[T]`。** `Θ` 刚性情形 `f=cR` 不是解（`c₃=0` 时）⇒ `Θ` 在每个非零解上**严格**下降 ⇒ 解**绝不**自相似 ⇒ 由单调性公式的标准机制（等号情形不可达 ⇒ 对数修正）⇒ 修正**必须**是对数。
3. **存活支实测 `[V]`**：`f = B + kB²/(2R) + …`（残差比 `f″/(kf²/R³)` 在 `R=50/200/800` 为 `0.9940/0.9985/0.9996 → 1`）与 `f ~ −R/(k log R)`（`h′+h″` 对 `kh²` 的比为 `1−2/s`：`s=2.3/4.6/6.9` 给 `0.13/0.57/0.71`）。**两支都是对数修正幂，`p` 都是 `−1`，对数都在首项。**

**对"洞"的关闭**：`e^{−c(\log R)^α}` 类**确实被排除**（`[V]` 残差比 `41 → 2.6e7 → 1.5e13`，对 `α=0.5/1/1.5/2`、`c=0.5/1`，**永不为 1**），但这对**所有** `α` 成立 ⇒ 关掉这个洞**什么也没换到**。

**结构定理 `[T]`（这条最重要）**：`(★₁)` 在 `(f,R) → (λf,λR)` 下协变（两边同权 `λ^{−1}`）⇒ `h` 的方程自治 ⇒ `f=Rh` 只能落在自治 ODE 的渐近字典里：`{幂} × {(log)^q}` 或 爆破解。**`e^{−cR} = e^{−ce^s}` 不在该字典内 ⇒ 指数衰减从这条归约结构性不可达**，与 `c₁,c₂,c₃` 取值无关。

## §5 `[X]` 勘误：`p = −1` 是不是解，取决于一个没算过的数 `c₃`

`SP-F-EQ1.md` §3–§4 的链是「`p=−1` ⇒ `f~R` ⇒ 被 `|W|≤1` 排除 ⇒ 禁止幂律衰减」。**这条链的每一步都不成立，原因同一个。**

**(1) 在 `(★₁)` 上（即 `c₃=0`）：`p=−1` 不是解。** 指数匹配 `−p−2 = −2p−3` 只给 `p=−1`，但此时**左端系数 `p(p+1) = 0`**：

```
f = cR  :  LHS = 0 ,   RHS = k c²/R ≠ 0    (k>0)
```
**`[V]`**：`LHS/RHS` 在 `p=−1` 处 `= 0.000000000000e+00`；`p=−0.5` 给 `−0.433`、`p=−2` 给 `+0.667`、`p=1` 给 `+18.0` —— **无一为 1**。⇒ `(★₁)` 无幂律解（除 `f≡0`），故「禁止幂律衰减」**空真：无可排除之物**。

**(2) 但只要把 `(★)`→`(★₁)` 丢掉的项放回去，`p=−1` 就变成精确解，且振幅由该项系数给出。** 设

```
c₁ f″ + c₃ f′/R = c₂ g²N f²/R³            (★₁′)
⇒  c₁ h″ + (c₁+c₃) h′ + c₃ h = c₂ g²N h²        （h=f/R, s=log R）
⇒  h ≡ H 为常数解  ⟺  c₃ H = c₂g²N H²
⇒  H = c₃/(c₂g²N) ,    f_rigid(R) = H R        （`[T]`，任意 c₃≠0、任意 k>0）
```

**直接代回 `(★₁′)` 核**：`f = cR` ⇒ LHS `= c₃c`，RHS `= c₂g²Nc²` ⇒ `c = c₃/(c₂g²N)`。✔ 与前式一致。
**⇒ `c₃=0`（即 `(★₁)`）把刚性解压成 `c=0`（平凡）；这是标 `p=−1` 为“被排除”的真正原因，不是 `|W|≤1`。**

**(3) 两项后果，都是可判的：**

| `c₃` | 指数方程 | `p=−1` | 势 `V(h)` | GMT 要件 2（`Θ` 有下界） | `SP-F-EQ1` 标题 |
|---|---|---|---|---|---|
| `= 0`（现归约） | `α(α−1)=0`，**双重根** | **不是解** | `−(k/3)h³` 反号，**无底** | **✘** | **空真** |
| `≠ 0` | `α[c₁(α−1)+c₃]R^{α−2}`，`α=1` 仍唯一 | **精确解** `f=HR` | `(c₃/2)h² − (k/3)h³`，`c₃>0` 时**有底** | **✔** | 有效（但排除的是**增长**律，非衰减律） |

**⇒ 缺的那一步 = 算 `c₃`。** 它不只需要，它**是全部**：`c₃` 一个数同时决定（i）`p=−1` 存在与否、（ii）`Θ` 有无下界、（iii）`SP-F-EQ1` 的结论是定理还是空真。**这是本文件唯一值得执行的下一步。**
