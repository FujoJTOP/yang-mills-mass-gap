## §1 三件事逐条（数与误差）

### §1.1 `β=0` 的测度与隙：iid Haar，`m = ∞` `[T]`+`[M]`

`S_W = β Σ_p (1 − ½tr U_p)`，`β=0` ⇒ `S_W ≡ 0` **恒等**（与构型无关，故不"似"而是"是"）⇒ `μ = ⊗_links Haar(SU(2))`。三条证据：

| 项 | 数 | 误差 |
|---|---|---|
| 单 link 抽样的 Haar 校核（`M=4×10⁵`） | `E\|tr U\|² = 1.000164`（Haar: `1`）；`⟨Re tr U⟩ = +6.54e−05`（Haar: `0`） | `±1.58e−03` |
| 幺正性 | `max\|UU†−1\| = 6.67e−16` | — |
| 连通关联，**无共享 link** 的两 plaquette | `+8.99e−04` | `±1.58e−03`（0.57σ） |
| 连通关联，**共享 1 link** | `+1.50e−03` | `±1.58e−03`（1.0σ） |

两者都是 0，而且是 `[T]`：`E_Haar[U]=0` ⇒ `E[tr(UA)]=0` 对任何固定 `A` 成立 ⇒ **单迹 plaquette 关联在一切间距上都没有连通部分** ⇒ `ξ = 0` ⇒ `m = ∞`。（比"只在远处为 0"更强：`β=0` 没有传播子。）

**可定量的强耦合载体（精确可解角）** `[T]`+`[M]`：`Z₂` 2+1D、`β_s=0`，`T = ∏_l(1+tσ_x)`，`t=e^{−2β}` ⇒ `λ₂/λ₁=(1−t)/(1+t)` ⇒

```
m(β) = −ln tanh β        （闭式，L-无关；稠密 T 独立复算，|diff| ≤ 4.4e−15）
```

| `β` | 0.01 | 0.05 | 0.10 | 0.25 | 0.50 | 1.00 | 2.00 | 4.00 |
|---|---|---|---|---|---|---|---|---|
| `m` | 4.60520 | 2.99657 | **2.30591** | 1.40683 | 0.77194 | 0.27234 | 0.03664 | 6.709e−4 |

`β=0.10` 的 `2.305910670` 与 `qg2_abelian.log` PART A 的 `2.3059106704` 逐位一致（独立复算）。⇒ `β→0` 时 `m→+∞`（`β=0` 处 `T` 秩一，`λ₂/λ₁=0`）；`β→∞` 时 `m ≈ 2e^{−2β} → 0`。

**`β=0` 处判据的真值**：`γ_true = λ₁(SU(2), 单位度量) = l(l+2)|_{l=1} = 3`（乘积测度按张量化取 `min`，仍是 `3`）`[T]`；判据给 `γ ≥ N/4·e⁰ = 0.75`。**`3 ≥ 0.75`：判据在这一点的结论为真。**
**⇒ 判定：`β=0` 不是酸测点。** `COV-T` §6.2 那句在此处是坐标错标（见 §4 `[E1]`）。

### §1.2 真酸测点：`β→∞` / 高斯作用量 `[T]`+`[M]`

**闭式（比 `COV-T` §4 更贴近定义，无归一化歧义）**：`S_W = ½φᵀAφ`（`A = −Δ + m² ≻ 0`），`K_t` 取 `e^{tΔ}` 的核 ⇒

```
B_t ∝ exp(−½ xᵀ(A − A(A + t⁻¹1)⁻¹A)x)
⇒ Hess V_t = A − A(A+t⁻¹1)⁻¹A = A^{1/2}[1 − (1 + A⁻¹/t)⁻¹]A^{1/2} ⪰ 0 ,   谱 = a/(1+at) ≥ 0
⇒ q(t) ≡ 0  ⇒  Q(∞) = 0        （对一切 A≻0，即一切 Gaussian，故含 β→∞）
```

数值见证（`T⁴₃`，`n=81`，`t`-网格 33 点 `[0,10³]` 对数）：`min_t λ_min(Hess V_t) = 9.960e−04 > 0`（`m=0.5`）/ `9.990e−04`（`m=1`）⇒ `q = 0`，`Q(∞) = 0`；矩阵式与谱式的最大差 `6.08e−15 / 8.44e−15`。`COV-T` §4 的 `A(I+2tA)⁻¹` 是同一对象取 `t→2t`，同样 `⪰0`。`[T]`+`[M]`

**自由场的真常数（这一条是关键）**：`μ = N(0,C)`，`C=A⁻¹`，`E(f,f)=∫|∇f|²dμ` ⇒

```
γ_free = 1/λ_max(C) = λ_min(A) = m²            （环面上 k=0 模在场，精确）
```

数值：`λ_min(A) = 0.250000000000` vs `m² = 0.25`，`|diff| = 7.2e−16 / 1.1e−15 / 5.6e−16 / 2.1e−14`（`L=4,6,8,16`）；去掉 `k=0` 的版本 `= m²+4sin²(π/L)`，闭式核对到 `1e−14`（`L=16`：`0.402240934977`）。`[T]`+`[M]`

**违反的定量形式**：

| 判据读数 | 判据给的界 | 被证伪的条件 | 交点 |
|---|---|---|---|
| `γ ≥ (N/4)e^{−2Q}`，`Q=0` | `γ ≥ 0.75` | `m² < 0.75` | `m* = 0.866025` |
| `γ ≥ (N/8)e^{−2Q}`，`Q=0` | `γ ≥ 0.375` | `m² < 0.375` | `m* = 0.612372` |

取 `m = 0.5`（有限、非退化、无零模）：`γ_free = 0.25 < 0.75` ⇒ **判据的结论为假，且没有取任何极限**。`m→0` 时 `0.75/m² → ∞`。
**⇒ 判定：真酸测点在 `β→∞`/高斯；失败在这里发生。**（归一化常数 `2` 只把 `m*` 乘 `√2`：`0.866→1.22`，不改"有限 `m`"这一事实。）

## §2 酸测是对"有限格点"还是"连续极限"？——决定性的二分

1. **有限格点上每个 `β` 都有隙** `[T]`：`β=0` 时 `m=∞`（§1.1）；`0<β<∞` 时有限体积谱离散 ⇒ `m>0`；`β=∞` 时 `m₁=2sin(π/L)>0`（`k=0` 被 Gauss 律拿掉）。⇒ **"隙的符号"在格点上永不可能失败，酸测不可能由符号检验构成。**（唯一例外：纯标量场在环面上 `k=0` 零模 ⇒ `m=0` 即使在有限 `L`——本项目是规范场，走 Gauss 律那一支，故不适用。）
2. **因此酸测只能是关于一致性 / 连续极限的陈述。** 这是 `(b)` 说对的那一半，也是 `COV-T` 说错的那一半：`COV-T` 把 `β=0` 当作酸测点，而那里符号是"有隙"，判据也给"有隙"——**符号一致，什么都测不出来**。
3. **但"仅极限失败"不成立**：判据的常数 `(N/4)e^{−2Q}` 与 `β,L,a` **全都无关**，而自由点的真常数 `γ_free = m²`（`[T]`）随 `m→0` 掉到 0 ⇒ 比值 `0.75/m² → ∞`。故失败是**点态（有限 `m`、有限 `L`）的定量错误**；极限只是它最显眼的一面。
4. **措辞定稿（供 `lead` 直抄）**：
   > **判据的常数是 `(β,L,a)`-无关的 UV 数（Ricci 供），物理质量隙是 IR 数。自由点上真常数 `γ_free = m²`（精确）⇒ 对一切 `m < √(N/4)`（或 `√(N/8)`）判据的结论为假。这是点态失败；只有"隙的符号"那一层才是仅极限失败。**

## §3 对 BD 是"死"还是"只是措辞要改"？——**死**，但坐标要改

- **死。** 作为**质量隙路线**，BD 在唯一答案已知的点（自由/高斯）上给出**假**的结论（§1.2 的 `m < 0.866` 一族）。没有 `Q(∞)` 的清洗能改变这一点：`Q(∞)=0` 是它最好的情形。
- **但死的坐标不是 `β=0`**：`β=0` 是 iid Haar 强耦合，隙 `=∞`，判据在那里**正确**。真坐标是 `β→∞`/高斯（等价：把 `S_W` 换成 `½φᵀAφ`）。
- **也不是"缺桥"**（`(c)` 不成立）：桥是 `[T]`。死因是**桥 + 几何常数**的合成结论在自由点被证伪——换句话说，桥把"几何 UV 常数"翻译成"有限体积转移矩阵隙"的下界，而该下界在有限 `L` 已不成立。
- **机制（与 `R1-BRIDGE` 末段一致，`[T]`）**：几何常数带 `1/a²` 的 UV 幂次（`Ric = (N/4)g` 是**单位度量**下的目标空间曲率）；读成质量就是 `m ≥ √(N/4)/a → ∞`（真空，物理上无意义），读成格点单位就是 `m_lat ≥ 0.375`（自由点为假）。两条读法都废。
