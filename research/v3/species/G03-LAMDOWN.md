## §1 为什么只有上界 —— 精确形态

### 1.1 两类命题的分界 `[T]`

`Λ★ := inf supp(ν − f₁²δ_{m₁²})`，`m₁² := inf supp ν`。两条恒等：

```
   (U)  Λ★ ≤ s        ⟸   s ∈ supp(ν − f₁²δ)          「有一个支撑点」——存在性，单个见证足够
   (L)  Λ★ ≥ a        ⟺   supp(ν − f₁²δ) ∩ [m₁², a) = ∅ 「区间内无谱」——缺席，须排除整段
```

`(U)` 可由**任何能显影一个谱点的数据**供给：矩、权重 `w_n`、关联函数、`m_eff(t)`。
`(L)` 不可能由这类数据供给：它们的值只由 `supp` 上的**平均**决定，而平均 `≥ inf supp`（`D06-SPEC` 引理 A1 `[T]`），
因此**方向天生反**——平均给 `m₁²` 的上界，永远给不出下界。这正是 `R2 Lemma C`（`Λ★ ≤ Λ_max`）是 `[T]`、
而 `R2:103–105` 逐字写 "`neither has a lower companion`" 的原因：Lemma C 是 Christoffel 上界的**对偶**，不是它的缺口。

### 1.2 题面那句话的正确形式（本轮修正）`[T]`

题面「下确界天然只有上界」若照字面读会被一行反驳：`supp ν ⊆ [m₁²,∞)` ⇒ `Λ★ = inf supp μ ≥ m₁²` 恒真。
所以精确表述是：

> **`Λ★` 的平凡下界（= 整体支撑的底）永远免费、且零内容；只有"严格高于底的下界"才携带信息，而它逐字是一个缺席命题。**

g03 Part A（`[E]`/`[V]`）：20000 个随机 4-原子测度，`Λ★ − m₁² < 0` 违反 **0** 次；样本最小 gap `8.5e-5` 只因支撑离散，
精确下确界 `0` 由塔测度实现（`R2` 见证 T6-3：`supp={m₁²+1/n}`，`Λ★=m₁²`）。

### 1.3 为什么矩一侧彻底死（`[NG]`，具名类：矩/正性/Hankel/Stieltjes）

g03 Part B 用**闭式解**复现并加强了 W4：三原子 `{1, 1+ε, L}`、取 `q := 0.4ε`，则


### 1.4 正确的"下界"工具在这里长什么样 `[T]`

能产出缺席命题的只有**谱侧**信息：

- **紧致性**：有限 `L` 上 `T_L` 紧 ⇒ 谱纯离散 ⇒ 次一能层严格更大（`F06 §3`，`[T]`+`[E]`）——真但空（§2.2）。

- **子空间正定证书**（Feshbach/Schur）：在剔除底层的子空间上 `T − (m₁²+δ)` 正定 ⇒ 无谱。**这是唯一可能通过的形状**
  （它必须用到边的本征矢，因此与 `f₁²` 纠缠——见 §4 的回路）。

## §2 `Λ★` 的下界是否 ⟺ `I2`

### 2.1 定义层恒等 `[T]`

```
   I2 :   Λ★ − m₁² ≥ δ > 0
   "Λ★ 有一个严格高于 m₁² 的下界" :   Λ★ ≥ m₁² + δ
   "空隙" :  (m₁², m₁²+δ) ∩ supp(ν − f₁²δ_{m₁²}) = ∅
```

三行是**同一个式子**的三种写法（`δ` 越大写法越强，但"是否存在 `δ>0`"是同一命题）。g03 Part E 逐对验证：18/18 一致。
⇒ **要 `Λ★` 的下界，就是要 `I2` 本身。** 不是 `I2` 的推论、不是它的必要条件、不是它的弱化——**同一句**。

### 2.2 唯一的岔口：`δ` 的量词，不是命题本身

| 读法 | 命题 | 判 |
|---|---|---|
| 逐点（对每个 `(L,a,β)` 各有一个 `δ>0`） | 有限 `L`：`[T]`（`F06 §3`）；`L=∞` 的逐点版即 `I2` 去掉一致性 | 有限 `L` 部分**真但空**（盒中自由无质量场同样成立 ⇒ 酸测失败）`[T]`+`[E]`；`L=∞` 部分仍 `[O]` |
| 一致（`∃δ>0` 与 `(L,a,β)` 无关） | `I2`（`R2:276–282` 的 `(E-I2)`） | `[O]` |
| 尺度不变（`ρ²=Λ★/m₁² ≥ 1+c`，`c` 与 `β` 无关） | SSC 形态；`ρ` 有界下 ⟺ 前一行（`R2 §5`） | `[C]`/`[O]` |

⇒ **`V02 §5(b)` 的"缺 `Λ★` 下界"与 `F06 §6(a)2` 的"`I2` 全开"是同一格。** 台账里它是**一件**，不是两件。

## §3 判死线逐条

**(a) `Λ★` 下界 ⟺ `I2` ⇒ 是同一个命题，缺件只有一个。逐字：**

> **唯一缺件：`∃δ>0`，使 `(L,a,β)` 一致地 `Λ★ − m₁² ≥ δ`。**
> 它的四个名字是同一格：**`Λ★` 的下界** = **`I2`** = **`(E-I2)`** = **`H*`**（`H*=I1∧I2`，`P6:63`；`I2⟹I1` 使 `H*` 定性上就是 `I2`，`R2 §2`）。
> `V02` / `F06` 的"缺下界"与"`I2` 未证"**不是两个缺件**；把它们记成两件是**记账错误**，本轮纠正。

**(b) 不触发（作为独立缺件）。严格变强的形态被写死在这里：**

若把要求提到 **`ρ² = Λ★/m₁² ≥ 1+c` 且 `c` 与 `β` 无关**（尺度不变、不是固定绝对 `δ`），则它**确实**比"固定 `δ`"强
——固定 `δ` 在 `m₁²→0` 时自动满足（无内容），尺度不变式不会。但这一条**已经**是 `(E-I2)` 的原文
（`R2:276–282`；`R2 §5` SSC 行：`ρ` 有界时二者等价，`ρ` 无界时尺度不变式更强）。⇒ **强的那部分有名字，不是新缺件。**

**(c) 不触发（不是结构性 no-go）。no-go 的**正确**范围：**

- **定义侧可用**：非平凡下界是定理，至少三处 `[T]`/`[M]`/`[E]`：
  2D YM SU(2) `Λ★=C₂(1)=2` vs `m₁²=C₂(1/2)=0.75`，margin `5/4`、`ρ²=8/3`（g03 Part D 精确复算）；
  1D 转子 `E_n=n²/2I`；**Prony**：给定 `K<∞`，`Λ★−m₁²` 是前 `2K` 个矩的**代数函数**，g03 用 6 矩恢复 `{1,2.5,7}`、`isolation=1.5`、误差 `8.9e−15`；
  而以 8 原子塔冒充 `K=3` 时报出的 `isolation=1.67`（真值 0.70）**无意义** ⇒ 关键输入是 `K`，不是矩。
- **方法侧必死**：矩/正性/Hankel（§1.3 的 `[NG]`）；"再取一个平均量"（`D06` 引理 A1 + T3）；
  **`2m₁` / `s_th` 只给上界**（`Λ★ ≤ s_th`，g03 Part F：`[T]`）——把它们当"候选下界"是重复劳动，记 `[X]`。
- **⇒ 真正的结构性结论（本轮该写死的）**：`Λ★` 下界的唯一可用形状是"**离散层/状态计数**"；
  而"阈值下 `0⁺⁺` 层数 `K` 有限"（`STATE-DENSITY-I2`）**就是 `I2` 命名的量**（`R2 §3.2` 有限塔 Thm 的收尾：
  "finiteness relocates the missing input to `K`, i.e. to `I2`"）。⇒ 在 `L=∞` 上 **`Λ★` 下界 ≡ `I2` ≡ gap，不独立**。
  **不独立 ≠ 不可用**——它可以作为 `I2` 的**第二个坐标**去做维数计数，但不能作为"第二条路线"去并账。
