## §1 逐行

```
(L0)  M₀ := ν(ℝ) = C(0) = Var(O)                               [T]  HR3-NORM:16,72–77（直读）
(L1)  Σ_{n≥1} m₀ₙ² = Var(X_B)                                  [T]  H 本征基完备；n≥1 ⇒ ⟨Ω|ψ_n⟩=0，常数项被杀

(L3)  ⇒ w₁(O) = a₁²/Σa_n² = m₀₁²/Σm₀ₙ² = w₁(X_B) = f₁²/Var(O)   [T]  c≠0；机检 |差| ≤1.2e−15

```

- **`X_B` 与 `O` 差什么（逐层，别一句话带过）**：`(a)` **常数**——`O` 的 `c·1` 部分在 `n≥1` 上被 `⟨Ω|ψ_n⟩=0` 杀掉，故 `m₀ₙ`/`a_n` 都不含常数；`(b)` **系数**——任何 `s>0` 在比值里相消（`GS1-1`）；`(c)` **电项**——`O` 比 `X_B` 多 `qX_E`，**这一层不由"常数/系数"消掉**，靠的是 `(L1)`：`X_E` 的非对角元被 `H` 的本征正交锁成 `e_nm=−(β²/2N²)m_nm`，于是 `a_n=c(β)m₀ₙ`。⇒ "`X_B` 与 `O` 差一个常数/系数"这句话**只覆盖 `(a)(b)`**，不覆盖 `(c)`。
- **缺的那一格就是 `c(β)`**：`Σm₀ₙ²=Var(X_B)` 与 `Σa_n²=Var(O)` 是两个不同的分母；题面在两步之间默认了 `c=1`，而 `c(2.5)=7/32=0.21875`、`c(2.66)=0.11555` ⇒ `1/c`=`4.57×`/`8.65×`（矩阵元层），`1/c²`=`20.9×`/`74.9×`（方差层）——`c` 既非 `1` 也非常数。
- **机检（零 MC，3×3 KS toy，`HZC §2.3` 同构）**：`$env:TEMP\hzp_eps.py`（`py -3.12 -I`，exit 0）：`β∈{1,2,2.5,2.66}` 上 `|w₁(X_B)−w₁(O)| ≤ 1.2e−15`、`|a_n−c·m₀ₙ|max ≤ 2.8e−16`、`|Var(O)−c²Var(X_B)| ≤ 5.6e−16`。
- **边界（四条）**：`(1)` `M₀=Var(O)` 是**固定尺度/接触减除后**的恒等；裸格子 `M₀^{bare}~a⁻⁸` 带接触而 `f₁²` IR-干净 ⇒ `w₁^{bare}≍a⁸→0`（`GS1:0.1,0.4`；`U4:123–128`）⇒ 靶量词只能 `∃a₀`。`(2)` `ν≡0`（2D、M6）⇒ `0/0`，恒等式**未定义**而非"等于 0"（`HQ4:0.1`）。`(3)` `c` 依赖 `p,q` 归一，本文件只在 `p=q` 用 `√8`（`HZC 边界(2)`）。`(4)` toy 是浮点 3×3，不是 YM 读数（`HZC 边界(3)`）。
