### 2.2 ★ 引理 LOG≠POW（`[T]`，一行 + 一行）

> **引理.** `∀k>0, ∀a∈(0,1)`: 记 `x = log(1/a)`，则 `a^k·x = x e^{−kx} ≤ 1/(ek)`。故
> ```
> (a) k > 1/e  ⇒  a^k < 1/log(1/a)  ∀a∈(0,1)          （sup = 1/(ek) < 1）
> (b) 一般 n 阶截断： (log(1/a))^{−n} 对 a^k 的支配条件是 k > n/e
> ```
> *证.* `x ↦ x e^{−kx}` 在 `x=1/k` 取极大 `1/(ek)`。∎

**推论（对靶的直接后果）**：
```
β-函数 n 阶截断 ⇒ aΛ 的相对误差 = O(g^{2n}) = O((log(1/a))^{−n})
⇒ 对一切 k > n/e，该项 **大于** a^k  ⇒  它不可能被任何 a^k 界吸收
⇒ "k = 1/阶数" 把 log^{−n} 误当 a^{1/n}：两者在 a→0 时差指数级
```

**数（`[E]`，`py -3.12` 直算，见 §5 台账 #4）**：

| `a` | `a^{1/2}` | `a^1` | `a^2` | `1/\log(1/a)` | 谁大 |
|---|---|---|---|---|---|
| `1e−1` | `3.162e−1` | `1.000e−1` | `1.000e−2` | `4.343e−1` | **log**（1.37×） |
| `1e−2` | `1.000e−1` | `1.000e−2` | `1.000e−4` | `2.172e−1` | **log**（2.17×） |
| `1e−4` | `1.000e−2` | `1.000e−4` | `1.000e−8` | `1.086e−1` | **log**（10.9×） |
| `1e−6` | `1.000e−3` | `1.000e−6` | `1.000e−12` | `7.238e−2` | **log**（72.4×） |

**⇒ 结论（不可回避）**：**β-函数截断所能证明的 `k` 是 `0`**（误差是 log 级，无任何正幂），不是 `1/2`，不是 `1`。`2/(m+2)` 这个数至少是**幂**；本路给的"`1/阶数`"连幂都不是。

**一处自我限制（诚实）**：`(i)` 若用**非微扰**定义的 `Λ(a)`（`√σ`、`t₀`），β-函数**根本不进入** `k` —— 那时 `k_Λ` 由 `(ii)` 的 Symanzik 幂次给。所以 LOG≠POW 杀的不是"本路全部"，只杀"**k 从 β-函数来**"这一句（0.2）。

## §3 ★ 循环判定（任务书要求"必须正面判这一条"）

### 3.1 命题 R1/R2：`(i)+(ii)` 与 `QSPEC-C` **互推**，`k = min(k_c,k_Λ)`（`[T]`，各 3 行）

> **命题 R1（min 律）.** 设 `Δ_cont = c₀Λ`、`c₀≠0`。若 `∀a<a₀`：`|Δ_a/Λ(a) − c₀| ≤ A c₀ a^{k_c}` 且 `|Λ(a)/Λ − 1| ≤ B a^{k_Λ}`，则
> ```
> |Δ_a/Δ_cont − 1| ≤ C a^{min(k_c,k_Λ)},     C := A + B + AB .
> ```
> *证.* `Δ_a/Δ_cont = (Δ_a/Λ(a))·(Λ(a)/Λ)/c₀ = (1+O(a^{k_c}))(1+O(a^{k_Λ})) = 1+O(a^{min})`。∎

> **命题 R2（逆）.** 若 `|Δ_a/Δ_cont − 1| ≤ C a^k` 且 `(ii)` 以 `k_Λ` 成立，则 `(i)` 以 `min(k,k_Λ)` 成立、`c₀ = Δ_cont/Λ`。
> *证.* 同式乘 `(Λ/Λ(a))`。∎

> **推论 R3（本路的身份）.** 在 `(ii)` 固定的意义下 `{(i),(ii)} ⟺ {QSPEC-C}`，且
> ```
> k_目标 = min(k_c, k_Λ)  ≤  k_c .
> ```
> ⇒ **本路不能"产出" `k`：它只能把 `k` 拆成两个因子，其中一个（`k_c`）逐字就是靶的速率。** 若 `k_Λ = 2`（候选 (a)/(d)），本路的**上限**是 `k=2`，而**达到 2 的充要条件是 `k_c ≥ 2`** —— 即"**要先有 `k=2`**"。

**这张表把"上限"说尽（`[T]`）**：

| `k_c` | `k_Λ` | 本路给出的 `k` |
|---|---|---|
| `0.5` | `2` | `0.5` |
| `1` | `2` | `1` |
| `2` | `2` | `2` |
| `4` | `2` | `2`（**封在 `k_Λ`**） |
| `∞` | `2` | `2` |

⇒ **本路的 `k` 恒 ≤ `k_Λ = 2`，且没有任何一格能超过 `k_c`。** 这就是"循环"的**定量形态**：它不是"论证里绕了一圈"，而是**输出的指数被输入（= 靶）的指数**上下夹住。

## §4 酸测（自由场 / 2D / M6 + 两条反酸测）

### 4.1 自由无质量场：`Λ` 无定义 ⇒ 必须沉默 —— **通过，但通过的方式是"前提已含结论"**

### 4.2 2D（`m = 3g²/8`）：**通过，且是退化通过 —— 它的通过恰好暴露本路的机制**
