## §1 三个候选：逐条判"是 H1 要的 / 量纲对不对 / 错在哪"

## §3 `a⁻⁴` 推理核查（任务书第 3 条，逐字）

**被核的推理（逐字）**：*"若 `χ` 在 `a=1` 上平台但搬运后随 `a` 跑，则 `H1` 无证据。判：由 `hz5` 的 `χ ~ a⁻⁴` 出发，`χ/a² ~ a⁻²` ⇒ 搬运后必然随 `a` 跑。"*

### 第 1 步：`χ ~ a⁻⁴` 成立吗 —— **`[T]`（条件：指裸/接触载体）**

- 出处齐：`T4-CARRIER.md:48–54`（"on-site value scales as `a^{-8}`; summed to `χ` it diverges as `a^{-4}`"）、`U4-CONTINUUM-ATOM.md:117`（`χ = ∫s⁻¹dν`，量纲 4，裸格点 `~a⁻⁴`）、`T4-CARRIER.md:327` 标 `[T]`、`HZ5:20` 转引 `HN1:23`。
- **但它的内容不是"随 `a` 跑"，是"单位换算"**：`χ_p = a⁻⁴χ_u`（`CLAUDE-METHOD-POINTSPLIT.md:198` 逐字 `χ_phys=χ_lat/a⁴`）。⇒ `χ ~ a⁻⁴` ⟺ **`χ_u = O(1)`**，即"格点读数不随 `a` 动"。**这是平台陈述本身**，不是平台的否定。
- 且它与仓内另一条 `a`-幂**矛盾恰好 `a²`**：`Q6:314–315` 逐字 `G″_a = a²m_phys²`，而 `G″ = 1/χ`（`Q6:83`）⇒ `G″ ~ a²` ⟺ `χ ~ a⁻²`，与 `χ ~ a⁻⁴` 差两幂。`U4-CONTINUUM-ATOM.md:113–120` 自己的表里也是两套（`χ` 行 `~a⁻⁴`，`G″_a` 行 `~a²m_phys²`）。**`[T]`：仓内 `χ` 的 `a`-幂有两个互斥版本，差 `a²`。** 下一手：把这一条登记为 `ch03 §dim` 的对账项（§3.4-1）。

### 第 2 步：`χ/a² ~ a⁻²` 的算术 —— **`[T]` 算术对，`[NG]` 归位错**

- `a⁻⁴·a⁻² = a⁻⁶`，**不是** `a⁻²`。链里写出的 `a⁻²` 来自把 `/a²` 读成 `·a²`（`a⁻⁴·a^{+2} = a⁻²`）。
- 而 `·a²` 恰好**是**仓内的规范形（`a²χ ≤ 1/Δ₀²`，`Q6:280–283`）—— 也就是说：链的**数字**在说 `F3` 的意思（`a²χ ~ a⁻² → 0`，`F3` **被平凡满足**），而链的**符号**在说候选 (i) 的意思（`χ/a² ~ a⁻⁶ → ∞`，`F3` 的倒数侧）。两者相差 `a⁴`。
- ⇒ **判 `[T]`：这一步的结论（"会跑"）对，但跑的方向取决于你乘还是除 `a²`，而仓内规范形是乘。** `[NG]`：链没有归一化到仓内的规范形，因此它证的既不是 `F1` 也不是 `F3`，而是它自己。

### 第 3 步："搬运后必然随 `a` 跑" —— **`[T]` 恒真 / `[NG]` 作判据**

- **恒真**：对任何 `χ_u = O(1)` 的读数，`χ_p = a⁻⁴χ_u` 必然 `∝ a⁻⁴`。这与"平台是不是偶然"**无关**；自由场、`β=0` Haar、M1/GY3 的平面图载体全都满足。⇒ 它对**任何**数据成立 ⇒ 零判别力（与 `HN1:0.11` 的"三格全盲"同型）。
- **反向还要注意**：`χ_p` 要 `a`-一致，唯一的路是 `χ_u ~ a⁴`——即格点读数**必须随 `a⁴` 趋零**。而"平台"（`p=0`）正好是它的反面。⇒ 这条链如果成立，它同时否掉的不是"GY3 的平台"，而是**任何** `p=0` 的读数（包括 `T4-CARRIER.md:41–46` + `docs/YANG-MILLS-MASTER.md:247` 主张的那个）。
- **它证不了的**：它说不出 `p` 是 0 还是 2 还是 4（那要 §2.3 的作业）。`[NG]`

### 第 4 步："则 H1 无证据" —— **结论 `[T]`，路由 `[NG]`**

- **结论对**：GY3 claim 6 确实**不提供** H1 的证据。
- **路由错**：真正的理由不是"搬过去会跑"，而是**搬不过去**——GY3 的载体（`log U` 的方差）**没有 `a⁻⁴`**（`GY3:33`），对它做 `a`-搬运是对象错（§0.1）。"会跑"的说法**预设了**两个物体是同一个，恰恰是要证的那件事。
- **还有一层**：链把 `F1` 的失效（`p<4`）当成对 `H1` 的否证，但仓内的 `H1` 规范形是 `F3`（`p ≥ 2`），`Q6:280–283` 逐字给了这个降级；`HN1:0.6` 也明说"裸形量纲错、不是未证"。⇒ 用 `F1` 的失效论证 `H1` 无证据，是在攻击一个已经被撤下的写法。
- **净判**：`[T]`（结论）/ `[NG]`（"必然随 `a` 跑"作为理由与判据）。**下一手**：把这段改写为两句——(a) "GY3 的载体不是 H1 的载体，搬运无定义"（对象判）；(b) "`p` 未测，`F1`/`F3`/三候选的门槛 4/2/6/14 全部悬空"（指数判）。
