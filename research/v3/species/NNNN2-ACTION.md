## §1 `1/48` 的来历（逐字）
1. **SZZ 假设（读到摘要）**：`BETA-CONVENTION.md:35` 逐字「**Assuming $|\beta| < \frac{N-2}{32(d-1)N}$ for the structure group $SO(N)$, or $|\beta| < \frac{1}{16(d-1)}$ for $SU(N)$**」。
2. **正文 Assumption 1.1**：`BETA-CONVENTION.md:46` 逐字 `K_S = (N+2)/2 − 1 − 8N|β|(d−1) > 0`（`SU(N)` 支），`:48` 逐字「Assumption 1.1 **is equivalent to** the following strong coupling assumption: `|β| < 1/(16(d−1))`」（原文 "is equivalent to"）。
3. **一行算术定 `1/48`**：`(N+2)/2 − 1 = N/2` ⇒ `N/2 > 8N|β_A|(d−1)` ⇒ `|β_A| < 1/(16(d−1))`；`d=4` ⇒ **`1/48`**。`N` **精确消掉**，因为作用量 (1.2) 自带 `Nβ`（`BETA-CONVENTION.md:41` 逐字 `S(Q) = Nβ Re Σ_p Tr(Q_p)`）⇒ `1/48` **与 `N` 无关**（`new-tools-registry.md:273`；`GY1-NOGAP-CLUSTER.md:114` 逐字「`|β_A| < 1/48`（SU(N), d=4, N 无关；Assumption 1.1 ⟺ (1.3) 逐字）」）。
4. **独立复核（非转引）**：`GX2-WINDOW.md:70,330–331` 记录 `web_fetch arxiv.org/abs/2204.12737` 与 `/html/2204.12737v1` 均 **HTTP 200**，读到摘要与 §1.1 式 (1.2) 渲染文本。
5. **它是什么**：**假设窗口的边界**，不是结论常数。`BIBCHECK-REPORT.md:37` 逐字「`1/48` 是**定理的假设窗口**…**不是**某个"log-Sobolev 半径"的数值。把 `1/48` 说成"log-Sobolev 半径"是把**假设**当成了**结论常数**」。
6. **`u`-读法被数值否定**：`w7/m07_window2.log:11` 逐字 `u(1/48) = beta/(2N^2) = 0.0026041666…`（=1/384）。若窗真是 `u<1/48` 则 `β_W<1/6`，是 SZZ 值（SU(2) `1/12`）的 **2×** ⇒ 两种读法差 2×，禁混写（`BETA-CONVENTION.md:70–71` 逐字「`1/48` 是 SZZ 的 `β`，不是标准 Wilson 的 `β`」「SZZ 的 `β` 与 `2.5` 不同源」）。
7. **因此它可被作用量移动——但只按 O(1)**：`1/48` 是**单位 plaquette 曲率不等式**的零点 = 群数据之比（Curie 项 `N/2`）比（代价项 `8N(d−1)`）。这解释了为什么"换作用量"这句话**有意义**（不是空谈），也给出它的**量级上限**（§2a）。

## §2 四条候选
**共用机制**：窗 = 判据 `λΦ(a,β) ≤ a/(1+a)` 的根（`w7/adj4_kp_a.py:9` 逐字）。`λ = eΔ` 是**纯组合数**（`Δ = 4(6−1) = 20` 邻接度硬数，`P1-EDGE.md:124`），**与作用量无关**；只有 `Φ`（角色系数比 `c_r/c_0` 的级数，`adj4_kp_a.py:17–25`）随作用量变。而结构界 `W ≤ 1/(eλ)` 把 `Φ` 的**前置因子**压在同一地板下（`b14_window_extend.log:38–46`）。⇒ **把 `Φ` 压小 ≡ 改 `β` 的标度**：窗在"自己的 `β`"里变宽、物理点不动。以下四条都撞这一句。

## §3 换作用量是否满足 Clay（`[Wilson]`）
1. **Clay 是四件**：`docs/PROOF-TEXT.html:93` 逐字 `Clay ⟸ AX ∧ NT ∧ GAP ∧ [Wilson]`；`:287` 逐字「Clay 是四件不是三件（+[Wilson]）」。
2. **换作用量 = 换第四件**：证出的是 `AX ∧ NT ∧ GAP ∧ [𝔉_S]`，**不是** Clay。判 **[NG]**。
3. **项目固定 Wilson 的理由是承重的**：`gluing/REPORT.md:79` 逐字「作用量取 Wilson（基本表示），**不取 Manton/adjoint/improved**……Wilson 是**已知反射正性**的最简选择（Osterwalder–Seiler 1978），而 RP 是承重的」；`new-paths/SURVEY.md:374` 已判「**换正则化**（Symanzik/fixed-point/不同分块）——**不是清楚的正收益**……RP 需重证」。
4. **等价类够不够大？——够，但不省一件**：Wilson 与 Hasenfratz–Niedermayer 的 FP 代表**同一 universality class**（`GN3-NEARCRIT.md:180` 逐字「同一类（同一 UV 高斯 FP、同一相关指数）」）⇒ 类**大到容得下 Wilson**。但 ① RP **不是**类不变量（`GN3-NEARCRIT.md:24`：同类里 Wilson 每点 RP，HP 的 `min` 方程代表**无** RP 继承）；② "同一连续极限"在微扰层是定理（dim-4 类只剩 `trF²`/`FF̃`）、**非微扰层 `[NG]`**（`GK3-SYMANZIK.md:282` 的 F3 第二合取项）。
5. **裁决**：**[NG]**。瓶颈**不在类的大小**，在**搬运**。走"等价类"路线，账面从 1 件变 3 件（RP + 同连续极限 + 窗），一件也没少；且窗本身仍是 §2 的根。
6. **下一手**：不动 `[Wilson]`；扩窗只走"改判据"或"Wilson 族自身"。若仍要动作用量，唯一记账合法的写法是把 `SYM-4D` 之类写成**新具名输入**并明写 Clay 多一件——不写成"已经满足"。
