### §1.2 合法性核验：逐项 `d/dβ` 合法 ⇔ 什么

**(0) 被微分的对象先钉死。** 本文件取
```
D_∞(β) := exp( Σ_{α≥0} (1−α) A(α;β) ),      A(α;β) := Σ_{Γ: α(Γ)=α} φ^U(Γ;β)        (1.1)

**(1) 每项 `β`-解析 `[T]`。** `φ^U(Γ;β)` 是 `|Γ|` 次多项式，变元是 `{c_r(β)}`（`X01:71` 的 `|φ^U(Γ)|≤C̄^{|Γ|}u^{|Γ|}` 就是按 `c` 的幂计阶）；`c_r(β) = 2 dim r · I_{dim r}(β)/β`（`ADJ4:67`），归一 `c_0 = 2I_1(β)/β = 1`（`R5-AUDIT:63`）。对 `r ≠ 0`，`c_r` 是 `β` 的**正幂**整级数（`c_r ≥ 0`、`c_r ≤ β^{|r|}e^β/(|r|! dim r)`，`P3-FULLREP-KP:29,44`）⇒
```
β ∂_β c_r = |r|·c_r·(1+O(β²))      ⇒      β ∂_β φ^U(Γ) = |Γ|·φ^U(Γ)·(1+O(β²))     (1.2)  [T]

**(2) 可和 → 可微：真正的条件，比"KP 收敛"强一格 `[T]`。** `(1.2)` 把 `β`-导数换成一个 `|Γ|` 权重，于是需要

## §2 · `C(β)` 的推导

### §2.1 选哪个量、为什么（这是全文件最关键的一步）

```
F(β) := f₁²_L(β) = a₀(β) · D_∞(β)                                        (2.1)
   a₀(β) = (2N)^{-p}·s ,  p∈{0,2}, s∈ℤ_{≥1}   —— 与 β 无关                [P3-DRESSED-MASS:36,119]
   D_∞(β) = exp( Σ_{α≥0}(1−α)A(α;β) ) = 1 + O(u)                          [X01:40–43,47]
   u(β)  = c_f/N = β/(2N²) + O(β³)                                          [X01:15–16, Z01:85]
```
出处链：`Z01:203`（`f₁²_L = a₀D_∞ ≥ a₀(1−Cu) ≥ ½a₀`）、`Z01:204`（`inf_L f₁²_L ≥ ¼(2N)^{-2}`，**无 `β` 依赖**）、`X01:42`。

**为什么不是 `Φ(a*,β)`**（`ADJ4:69` 的 `Σ_{n≥1}(n+1)²[I_{n+1}/I_1]e^{a*n}`）：`Φ` 是**每 plaquette 的活动度**，`Φ(0,β) = β + (3/8)β²`（`ADJ4:70,81`）⇒ `∂_β log Φ = 1/β + O(1)`。但 `Φ` 的 `β`-幂次在残数里**被归一化严格抵消**：管子重量 `w(B_T) = a₀u^{4T} = a₀e^{−κt}`，`κ := 4ln(1/u)/a`（`P3-DRESSED-MASS:35`、`Z01:83`），`u^{4T}` 的 `β^{4T}` 被 `e^{−κT}` 吃干净，剩下的振幅就是 `a₀` —— **`β`-幂次 0**。⇒ 拿 `Φ` 当 `F` 会得到 `1/β` 型"发散"，那是**把归一化误当物理**。§3 表 2 把 `C_Φ` 的数照样给出，作反面对照。

**为什么是 `a₀D_∞` 而不是 `F = Σ_n a_n` 的原始级数**：`(2.1)` 是**乘积**，`d log F = d log a₀ + d log D_∞`，`d log a₀ = 0`（`a₀` 与 `β` 无关）⇒ 求导落在**收敛的簇级数**上，`F > 0` 不出场（`D04:89–92` 的"假设⟺结论"在这里被**绕开**而不是被重复：本文件不比 `|F'| ≤ C|F|`，而是**算出** `|F'/F|` 的显式界）。这是 `GW3:172` 那条"逐项 `d/dβ` 产出显式 `C(β)`"的执行，且**产物比预期好**（§4）。

g(0) = ū/(1−ū)² ,       Σ_{α≥2}(α−1)g(α) = O(ū³)                                          (2.5)
```
代回 `(2.2)`：
```

## §4 · 预算判决

### §4.1 `Δβ` 必须同坐标

| 记号 | 定义 | 值 | 依据 |
|---|---|---|---|
| `Δb_win` | `β_A∈[1e−4,3.777028e−3]` | `3.677028e−3` | 任务表点 + `ADJ4:96` |
| `Δb_tr` | `β_A(2.5)−β_{1,A}=0.625−3.777028e−3` | `0.6212229717` | `β_W=N²β_A`，`N=2` |
| `Δw_tr` | Wilson 窗边 `4β_{1,A}` 到 `β_W=2.5` | `2.4848918868` | 同坐标换算 |

`C_A=|∂_{β_A}log f₁²|` 与 `C_W=|∂_{β_W}log f₁²|` 满足 `C_W=C_A/4`，故 `C_AΔb_tr=C_WΔw_tr`。旧式 `7.15847×(2.5−0.0034)=17.87183` 混合两个坐标，无效。

### §4.2 主判决（`[E]`）

预算标量：`B=log(r₀/ε)=log((1/64)/1e−6)=9.6566274746`。另一口径 `r₀=1/32` 给 `10.3498`，判决不变。

| 比较 | 左端 | 右端 | 比 | 判 |
|---|---|---|---|---|
| 窗内 | `C_A·Δb_win=0.02632` | `B=9.65663` | `0.002726`（余 `367×`） | 不超 |
| 点态 Wilson 预算 | `C_W=1.7896174` | `B/Δw_tr=3.8861359` | `0.460513` | 不超 |
| **反事实全跨度** | `C_AΔb_tr=C_WΔw_tr=4.4470056` | `B=9.65663` | **`0.460513`** | **不超，但外推非法** |

窗内地板保留率 `e^{−0.02632}=0.97402`。反事实全跨度地板为 `e^{−4.4470056}/64=1.8302483e−4>1e−6`；**这不是 GW4 证明的输出**，因为同一窗内常数在窗外没有定理。

### §4.3 `[E]`+`[NG]` 结论

> **窗内不超预算，且旧的“全跨度超 1.85×”已撤回。** 正确同坐标乘积是 `4.4470<9.6566`。路线没有死于预算，而是死于**有效域**：GW4 只控制 `β_A≤3.777028e−3`，靶在 `β_W=2.5`。把窗内界铺满全段需要新的窗外一致估计；在拿到它之前，Grönwall 不提供搬运。

### §4.4 与 `GW3:172` 的预期裁决相反 —— 差在哪

| `C ~ √V c(β)/Δ(β)`，`V`-幂 `√V` | **`V`-幂 `0`**（`L`-无关） | `C` 的 `L`-依赖只经**绕空间周期**的装饰 `O(u^{L/a}) = e^{−cL}`（`P3-DRESSED-MASS:79` 逐字"L-uniform"）。`C` 的来源是 `D_∞` —— 一个**端点/边界缺陷**（`X01:41–43`：`φ_dec T` 已被**减掉**），**不是**体自由能 ⇒ 无 `V` 增长。`D07` 的 `√V` 属于 `|F'| ≤ √(Var·Var)/Δ` 那条 Cauchy–Schwarz 路，不是 `log F` 的簇级数路 |
