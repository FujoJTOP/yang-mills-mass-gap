## 2. `g` 在 `d=0` 的奇性：**光滑，无奇性障碍** `[T]`

`g(d) = −2log[sin(d/2)/(d/2)]`：

| `d` | `g(d)/(d²/12)` | `g″(d)`（应 `1/6`） | `g − (d²/12 + d⁴/1440)` |
|---|---|---|---|
| 1e−1 | 1.0000833465633 | 0.166750033 | 1.10e−11 |
| 1e−2 | 1.0000008333347 | 0.166667500 | 1.10e−17 |
| 1e−3 | 1.0000000083333 | 0.166666675 | 1.10e−23 |
| 1e−5 | 1.0000000000008 | 0.166666667 | 1.10e−35 |

- `g(d) = d²/12 + d⁴/1440 + O(d⁶)`，**偶解析**，`g(0)=g′(0)=0`，`g″(0)=1/6` ⇒ `g ∈ C^∞`。
- 故 `Φ = Σ_p g(d_p)` 在 `d_p=0` 处解析；**没有 `d=0` 奇性障碍**。
- 边界上真正起作用的是 `|Δ|² ~ d_p²`：`T·Φ′ = O(d²)`、`T·Φ″ = O(d²)`（`a=1e-6, b=1`：`T·Φ′=4.30e-13`，`T·Φ″=8.82e-13`），**乘出后光滑**，无 `1/d` 奇性。
- **但**：`g` 含 `log(d/2)`，不是 `2π`-周期函数 ⇒ **`Φ_O09` 不是环面上的函数**，`S` 依赖 `d_p` 的 lift 约定（见 §3）。这一点 `r12` 没记。

## 3. `G` 的 `v`：具体是哪个方向 / 有没有 `inf_v`

### 3.1 式子与 `v` 的显式关系 `[T]`
`G` 是 `S_W` 沿**离开切片**方向的导数。切片内坐标是 `(a,b)`（`a=x1−x2`, `b=x2−x3`），
`S_W = β(1 − ⅓Σ_j cos(φ_j−x_j))`，`G = d_τ S_W`。取 `x → x + τu`（`Σu_j = 0`）：
```
G(v) = (β/3) Σ_j sin(φ_j − x_j) u_j ,   H(v) = (β/3) Σ_j cos(φ_j − x_j) u_j²
u = ( (2v_a+v_b)/3 , (v_b−v_a)/3 , −(v_a+2v_b)/3 ) ,   v = (∂_τ a, ∂_τ b) ∈ R²
```
- `r12` 隐含取 `v = (1,1)` ⇔ `u = λ = (1,0,−1)`。**"离开切片的方向"= `(a,b)` 平面里的 `v`，不是唯一**。
- 没有 `inf_v` 型测度问题（`v` 是求导方向，不是积分方向）；真正的问题是**方向选择**。

### 3.2 `gap` 是 `v` 的**2 次齐次、不定**二次型 `[E]`

`N=2048`，单位 `v` 扫方向：

| `ψ` | `v_a, v_b` | `S` | `gap` | `gap/S` |
|---|---|---|---|---|
| 0 | 1.000, 0.000 | 1.92540783 | **−0.20235347** | −0.1051 |
| 0.4 | 0.921, 0.389 | 2.93795554 | +0.01642070 | +0.0056 |
| π/4 | 0.707, 0.707 | 3.40320013 | **+0.05086204** | +0.0150 |
| 1.2 | 0.362, 0.932 | 3.04556607 | −0.12653766 | −0.0416 |
| π/2 | 0.000, 1.000 | 2.15511016 | **−0.38169090** | −0.1771 |

齐次性核验（`ψ=0`）：`gap(0.5v)=−0.05058828`，`gap(v)=−0.20235313`，`gap(2v)=−0.80941253`
⇒ `gap(cv)/c² = −0.20235313` 三份一致（`1e-8`）。`ψ=π/4` 的 `+0.05086 = 0.5 × 0.10172` 也吻合（`|(1,1)|²=2`）。

⇒ **`gap(v)` 沿不同方向变号**：`v=(1,0)` 负、`v=(1,1)` 正、`v=(0,1)` 更负。
`SU(2)` 里 Cartan 是 1 维、`v` 唯一，所以"一个数"是 1 维假象；`SU(3)` 得到的是 `2×2` 的 `Q(v)`，**不定**，
**没有正则化前的唯一 `gap`**。这是 `SU(3)` 相对 `SU(2)` 的真正结构性新增难点。

### 3.3 恒等式结构（为什么 `S≠D` 是"合法"的）`[T]`
设 `A = −log|Δ|²`（`r12` 的 `Φ_r08`）。对任意 `v`、任意权重，环面平移不变性给出**严格**
`⟨H + A″⟩ = Var(G + A′)`（这正是 `r12` 的 `[B]` 复现的 `S=D=8`）。
`Φ_O09 = A + ψ + const`，`ψ = 2Σ_p log(d_p/2)`，于是
```
gap = S − D = ⟨ψ″⟩ − Var(ψ′) − 2Cov(G+A′, ψ′) ,     ⟨ψ″⟩ = −2⟨Σ_p v_p²/d_p²⟩
```
`N=8192`：`D−S = −0.101723`，`−⟨ψ″⟩ = −1.787277`，残差 `+1.685554`（= `Var(ψ′)+2Cov`）。
⇒ `gap` 的**符号完全由 `ψ` 的方差/协方差决定**，不是"维数/精度"问题，也不是 `g` 的奇性。

## 4. 域诊断：`(a,b)∈(0,2π)²` 只覆盖环面的 1/3 `[E]`

真 Weyl 积分的必要条件：`Z(τ)=∫ ρ(a+τ,b+τ) da db` 与 `τ` 无关（`(a,b)→(a+τ,b+τ)` 就是 `x→x+τλ`）。

| `N` | `τ` | `Z(τ)` | `Z(τ)/Z(0)−1` |
|---|---|---|---|
| 2048 | 0 | 1042951.114 | 0 |
| 2048 | 0.5 | 1053920.544 | +1.05e−2 |
| 2048 | 1.0 | 1195392.517 | +1.46e−1 |
| 2048 | π | 1247783.642 | **+1.96e−1** |

⇒ 破 `19.6%`：`(a,b)→x` 是 **3 对 1**（`x → x + k(2π/3)(1,1,1)`, `k=0,1,2`），
`(0,2π)²` 只覆盖 `x`-环面的 **1/3**。`r12` 的 `+0.10172` 是这 1/3 上的积分，**不是 Weyl 积分**。

补全 `Z_3` 平均后（`Z(τ)` 复原到 `2e-16`，即真的是 Weyl 积分）：

| `N` | `S` | `D` | `gap` |
|---|---|---|---|
| 1024 | 6.49480737 | 4.10040756 | +2.39439982 |
| 2048 | 6.49480737 | 4.10040942 | **+2.39439795** |
| 4096 | 6.49480737 | 4.10040989 | +2.39439749 |

⇒ 完整环面上 `gap = +2.39440 ± 1e-5`（`[C]`），远超 `r12` 的 `+0.1017`。
两套约定都给**正**号，所以 `(b)` 不成立；但 `r12` 的具体数值是"1/3 域"数值，**不能当 Weyl 积分引用**。

顺带一条自检：`⟨Φ′⟩ = +2.492 ≠ 0`（两种域都是），正是 `Φ_O09 ≠ −log|Δ|²` 的直接指纹
（`⟨Φ′⟩ = ⟨ψ′⟩ − ⟨G⟩`，`⟨G⟩ = −4e−17`）。任何"`⟨Φ′⟩=0`"的断言对这个 `Φ` 都不成立。

## 5. 判死线裁决

- **(a) 成立，但要改口径**：`v=λ` 下 `gap` 加密 2×/4× 稳定在 `+0.1017226`（1/3 域）/ `+2.39440`（完整环面），**不翻号**，`SU(3)` 数值为正。
  它**不是**纯"维数/精度"问题——正确说法是：**符号稳定，数值强依赖域约定与 `v` 方向**。
- **(b) 不成立**：加密后不翻号（`+0.10181484 → +0.10172273`；Haar `−0.23580101 → −0.23580295`）。`r12` 的数在其自身约定下**可复现、可靠**；不可靠的是把它读成 "`SU(3)` 的 `gap`"。
- **(c) 成立（且是本轮最硬的新结论）**：`v` 是 `(a,b)` 平面里的自由方向，`gap(v)` 是**不定**二次型（`ψ=0` 时 `−0.2024`，`ψ=π/4` 时 `+0.0509`）。`SU(2)` 的 `v` 唯一是 `1` 维 Cartan 的偶然，`SU(3)` 没有规范选择。**要一个数，必须先给出选 `v` 的原则（或对 `v` 的泛函，如 `gap/S` 的方向扫描）**。

**缺失的那一步（精确）**：一个把 `v`-方向与域（`Z_3` 补全）同时固定、并让 `Φ_O09`（含 `log(d/2)`，非环面函数）的 lift 约定不进入答案的表述。在那之前，`SU(3)` 的 `gap` 是**一族**数，不是一个数。
