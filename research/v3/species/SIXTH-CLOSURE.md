## §1 四个物种的共同结构（为什么"再换一个物种"不是出路）

四个物种的输入不同、输出形式不同、死法不同，但**退化门是同一扇**：

```
   上界进 ──▶ [某个单调包络] ──▶ 下界出
                    │
                    └─ 包络若是【恒等式】：前件 = 结论（零内容）
                       包络若是【严格不等式】：需要 H1（塔底隔离）
```

逐项核对（这是本轮唯一的"新结构"）：

- **梯度型**：Grönwall 包络 `F(β) ≥ F(β₀)e^{−∫C}` 是恒等式型（`D04` 2.1），严格化 ⇒ `C<∞` 在整段成立 ⇒ `F>0`。
- **信息型**：DV 率本身是 `sup`（lsc）而原子是 `usc`；但 `β`-导数不自动保持 lsc。无条件反例是具体 `Var(S_W)` 在 2D 上正而残数零；条件引理只封已另证 lsc 的 minorant（`GW5` §1–§2）。
- **计数型**：`Λ(B) := sup_t[−(1/t)log B(t)] ≤ m₁` 的 Tauberian 包络**是恒等式**（`B=Z_*` 时取等）；要与 `f₁²` 搭桥就退化成 `log det(1−K)`（位置 vs 留数错位，`D08` 已判）或 `(G)`（`D07` 已判）。`GW6-COUNT` §3 三个退化门 **D-1/D-2/D-3 逐一命中**。
- **预算型**：常数优化不改包络的**类型**，只改它的**大小**；但 GW4 窗内余量充足，不能用“1.85×超预算”判死。未闭合的是**窗外有效域**，不是某个已算出的临界倍数。

⇒ **结论（本轮的主要产出）**：在"输入 = 某个谱量的上界、输出 = 某个谱量的下界"这一类里，**没有第四扇门**。`GW6-COUNT` §2.3 把计数型的三个形态穷尽（`N_X(E) ⋈ k`，`X∈{H,O}`，无第四格）；本文件把四个物种的退化门对齐到同一扇。**"再换一个物种"如果仍在这一类里，它在结构上已经写完了。**

## §2 唯一没被这一刀碰到的格子：**非抵消**（载体不是 ν 的泛函）

`GW4-CWINDOW` §0 的机制段给出一个**不在上面四类里**的形态：

```
f₁²_L = a₀(β) · D_∞(β),     a₀ = (2N)^{-p}s  与 β 无关
⇒ f₁² 的全部 β-依赖坐在 D_∞ 上
⇒ "f₁²(β) > 0"  ⟺  "D_∞(β) ≠ 0"        ← 非抵消陈述，不是地板陈述
```

它为什么可能躲过上面四刀：它**不是 ν 的泛函**（不进 `usc/lsc` 二分），**不是计数**，**不是梯度**，也不经过 `Tauberian` 包络。

**但它有一个已知的反向红牌**：论文正文（`docs/paper-final/sec04-survey.tex` 表第 5 行，源 `U10.md`）把 `D_∞` 叫 **Krein–Rutman residual**，并逐字写它"**fails the free-field acid test: at β=0, `D_∞=1` while `w₁=0`**"。若 GW4 的 `D_∞` 与这个是同一个对象，则"`D_∞ ≥ c > 0`"在自由场照样为真（=1）⇒ **载体当场死**。

⇒ 所以这一格**还没有被判**，它的状态取决于一次**消歧 + 代换检验**（`β=0` 时 `a₀D_∞` 是否给 `0`）。这是本轮唯一派出去的后续（`GW8-DINF`）。
