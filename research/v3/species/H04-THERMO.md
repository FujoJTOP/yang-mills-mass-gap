## §1 · `F` 的积分版：精确，但零内容 `[T]`

### §1.1 恒等式及其成立范围

```
F(β') − F(β) = ∫_{β}^{β'} (dF/dβ) dβ                                  (1.1)
dF/dβ = −Σ_{n≥1} ⟨Ω|O|n⟩⟨n|S_W|𝔾⟩ / (E_n − E₀)     （d04 (1.3)，Kato）
```
*`(1.1)` 的成立范围 `[T]`.* 固定 `(L,a)`：`T(β)=e^{−βS_W}` 的矩阵元是 `β` 的整函数；`S_W` 的元素非正（Wilson 作用量 `s_p=1−u_p≥0`，`u_p` 取 `Re tr` ⇒ `T` 为逐元非负矩阵），Perron–Frobenius ⇒ **`𝔾_β` 严格正、`E₀(β)` 单重对一切 `β>0`** ⇒ `F` 在 `[β₁,2.5]`（`β₁>0`）上**实解析** ⇒ `F'` 连续 ⇒ `∫|F'| < ∞`。**`1/Δ(β)` 在这个论证里完全不出现**——Kato 展开只是 `F'` 的一种**写法**，不是 `F` 可微性的前提。

**⇒ 对任务 1 的直接回答：积分收敛。而且是绝对收敛。`
- `[E]` 恒等式层复核（`w7/h04_integral.log` A 段，`F` 取解析指定形状）：`∫F' = 3.2008127773e−1`，`F(2.5)−F(β₁) = 3.2008127773e−1`，残差 `2.78e−16` ⇒ `(1.1)` 逐字精确。
- 低端 `β→β₁`：`Δ(β)=β·δ_{S_W}`（`H=βS_W`）⇒ `1/Δ` 在低端最大，`∫_{β₁}^{2.5}dβ/Δ = ln(2.5/β₁)/δ = 6.60/δ`（`d07 (1.2)`）⇒ 是**对数因子**，不是极点。⇒ **"`1/(E_n−E₀)` 让积分发散"这个担心，在恒等式层面为假、在证书层面为真——两者必须分开记。** `[T]`（解析，`d07 (1.2)`）。

### §1.2 为什么它没有 `⟨S_W⟩` 那样的内容 `[T]`

| 对象 | 是否某已知标量函数的导数 | 被积函数符号 | 恒等式的信息量 |
|---|---|---|---|
| `log Z(β)` | **是**（`= −log Z` 本身） | `⟨S_W⟩ = −∂_β log Z ≥ 0` 定号（Griffiths） | 精确式 `∫⟨S_W⟩` 把**一个**未知标量变成**一个**积分 ⇒ 可做凸性/求和级数 |
| `F(β)` | **不是**：`F` 就是待证非零的对象 | `dF/dβ` **无定号**（`n≥1` 求和，正负项混） | `(1.1)` 只是把 `F(β')` 写成 `F(β)+∫F'` ⇒ **同义反复** |

⇒ **`F` 的"积分版"作为等式没有可用的推论**：`log Z` 的版本能推出凸性、能接 Legendre，`F` 的版本连"`F(β')` 与 `F(β)` 同号"都给不出（要同号必须控制**绝对值**）。**这就是"隙版热力学积分为何不存在"的一句话答案。**

## §2 · 判据 `∫|F'| < F(β₁)`：反向三角直接否决 `[T]`

### §2.1 主命题（Grönwall 的积分版）

> **命题 2.1 `[T]`.** 设 `F∈C¹([β₁,2.5])`、`F(β₁)>0`。则
> ```
>   ∫_{β₁}^{2.5}|F'| dβ < F(β₁)   ⇒   F(β) > 0 ∀β∈[β₁,2.5]，
>   且  F(β) ≥ F(β₁) − ∫_{β₁}^{β}|F'| ≥ F(β₁) − ∫_{β₁}^{2.5}|F'| > 0 .     (2.1)
> ```
> *证.* `F(β) = F(β₁) + ∫_{β₁}^{β}F' ≥ F(β₁) − ∫_{β₁}^{β}|F'|`。∎

**这是任务书 (a) 的"搬运"的正确写法**：它确实是 `d04` 命题 2.1 的积分版，**假设的形态从 `sup|F'/F|` 换成了 `∫|F'|`**。但：

### §2.2 反向三角：判据自带一条与 `1/Δ` 无关的必要条件 `[T]`

```
   ∫_{β₁}^{2.5}|F'| ≥ |∫F'| = |F(2.5) − F(β₁)|                          (2.2)
```
⇒ 判据 `∫|F'| < F(β₁)` 的**必要条件**是
```
   |F(2.5) − F(β₁)| < F(β₁)   ⇔   F(2.5) < 2F(β₁)   （在 F>0 的窗口内）.      (2.3)
```
**这就是这条路的结构性死刑**：判据要求**残数在整个窗口内不许翻倍**。而
- `F(β₁) = r₀ > 0` 是 `I1`（`P3`，`β₁=1/48`，强耦合，`[T] mod [KL]`，`r₀` **未被数值化**）；
- `F(2.5) = f₁²(2.5)` 是**靶本身**，量级 `O(1)`（`d07 §3.3/§5` 的口径）；
- `β` 从 `1/48` 到 `2.5` 跨 `120×`，`f₁²` 从强耦合残数长到弱耦合残数，**没有理由不翻倍**；语料里所有"残数搬运"的叙述（`W95D` 的 `Ω∈[0,1]` 分解、`f₁²=Z_O²Ωf₁²(β_eff)`）都隐含**增长**。

⇒ **前件 `F(2.5) ≥ 2F(β₁)` 是 `[C]`（未证，但比靶弱得多：它只说"增长 ≥2 倍"，不断言非零）；一旦成立，命题 2.1 的假设就逐字为假 ⇒ 判 (b)，且这个 (b) 不依赖任何谱估计、不依赖 `Δ`、不依赖 `1/Δ`。**

**`[E]` 见证（`h04_integral.log` A 段）**：`F=0.60+0.35sin3(β−β₁)` 全程 `F≥0.25>0`，而 `∫|F'|/F(β₁)=2.867` ⇒ **判据为假而靶为真**。`A5` 段扫幅值：`amp≤0.20`（`F(2.5)/F(β₁)≤1.18`）时判据成立（`TV/F(β₁)=0.246/0.492/0.983`），`amp=0.35`（`F(2.5)/F(β₁)=1.32<2`）时**已失败**（`1.720`）⇒ **`(2.3)` 是必要不充分：`F` 的**振荡**额外花钱**；充分必要只在 `F` 单调时成立。这是本文件与 `d04` 等价性最尖锐的差别。**

## §3 · `d07` 的 `∫Var = 3.043V` 能给出什么 `[T]`+`[E]`

### §3.1 C–S 桥（本文唯一新恒等式）

`n` 方向 C–S（`d07 (2.1)` 的谱权恒等式 `Σ_{n≥1}|⟨n|S_W|𝔾⟩|² = Var(S_W)`），再在 `β` 方向 C–S：

```
   |F'| ≤ √(Var_O(Ω_β)·Var(S_W,β)) / Δ(β)                                 (3.1)   [T]
   ∫|F'| ≤ √Var_O(Ω) · √( ∫Var(S_W)dβ · ∫ Δ^{−2}dβ )                      (3.2)   [T]
   ∫_{β₁}^{2.5}Var(S_W)dβ = 6V·u_p(2.5) = 3.0432·V   （d07 (2.2)，精确）    (3.3)   [T]+[E]
   ⇒  ∫|F'| ≤ √( Var_O · 3.0432 V · ∫Δ^{−2} )                              (3.4)
```
**这是语料里第一次把 `d07` 的精确数 `3.04V` 用在"靶自己的导数"上**（`d07` 只把它用在 `∫A` 的 Jensen 下界）。它是 `[T]`；`[E]`（`w7/h04_integral.log` B 段）复核 β-方向 C–S 的**损失因子** `∫√Var/Δ ÷ √(∫Var·∫Δ^{−2})`：

| 形状 | 损失因子 |
|---|---|
| `Δ=β`、`Var∝e^{−β}` | `0.589` |
| `Δ=0.1β`、`Var∝e^{−β}` | `0.589`（**与 `Δ` 的整体标度无关** ⇒ 不改变 `L`-标度） |
| `Δ≡const`、`Var≡const`（自由场型） | **`1.000`（无损）** |
| `Δ=β`、`Var∝β` | `0.236` |

⇒ **C–S 不是发散的来源**：在自由场型（`Δ` 常数）上它**无损**，`d07` 的 `0.487L³` 被逐字继承；在 `Δ∝β` 上只丢 `0.59`。**所以 (3.4) 的 `L²`-标度是 `∫Var` 自带的，不是 C–S 的假象。**
