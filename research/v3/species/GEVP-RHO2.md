# GEVP-RHO2 · `β=2.5` 的 `ρ²` 读数：`e₂/e₁` 到底是什么、`L=6/8/12` 各给了多少、平不平稳

> 处方（`ta02` 逐字）：`β = 2.5、L = 6/8、零动量 0⁺⁺、T ≳ 12–16` 的 GEVP，取 `e₂/e₁`；`ρ²` 平稳 ⇒ 隔离；`ρ² ≥ 1+c` = `H*`（同一堵墙）。
> 本轮执行：`L=6` → `L=8` →（补）`L=12`，**一次一个重作业**（`CLAUDE.md §4`），立方体、`SU(2)` Wilson、`β=2.5`、零动量 `A₁⁺⁺`、4 算符基。

## 0 结论（一行一条）

1. **[T] 对应关系钉死**：`ρ² = e₂/e₁` **当且仅当** `e_k` 是「`0⁺⁺` 投影生成元的第 `k` 个非零能级」即 `e_k = m_k²`。本轮脚本的 `e_n = −ln λ_n/(t−t₀)` 是**质量**（能量），故 **`ρ² = (e₂/e₁)²`**。两者只差一次平方：`e₂/e₁ = 1.56 ⇒ ρ² = 2.4336`。**不是**"`ρ²` 等于 `e₂/e₁` 的平方根"——方向不许反。
2. **[T] `ρ²>1` 在本读数里是恒真的、白送的**：GEVP 本征值按降序排 ⇒ `λ₁>λ₂` ⇒ `e₂>e₁` ⇒ `ρ²>1` **自动**。38/38 个可解点全 `>1`，这与"有没有原子"无关（自由场 `ρ²=4`/`2`，`m=0`；语料 `A03-RHO2.md:120-132`、`B02-LARGEN.md:79-88` 同判 `[NG]`）。
3. **[E] 三档体积都测不出 `e₂/e₁`**：可解点只有 8/18（`L=6`）、16/30（`L=8`）、14/54（`L=12`）；最紧的一行是 `L=8` 的 `ρ² = 2.34 ± 15.2`，其余 `σ(ρ²)` 从 `8.4` 到 `3.5×10⁷`。
4. **[E] ⇒ 平稳性不可判**（不是"不平稳"，是**读数不存在**）。判死线命中 **(c)（定义已钉死）+ (b)（资源/基不够）**，未命中 (a)。
5. **[T] 处方自相矛盾**：立方体里 `T = L`，所以 `L=6/8` 给的 `t` 窗口只有 `t≤3/4`（`t₀=1,2` ⇒ `dt≤2`），`λ₂` 全是接触项。`T ≳ 12–16` 要求 `L_t ≥ 12`（矩形体积），我补的 `L=12`（`T=12`）**也没救回来**（14/54 可解，最紧 `ρ²=1.35±108`）。

## 1 (c) `ρ²` 与 `e₂/e₁` 的对应（钉死）

语料逐字（**转引**，`A03-RHO2.md:31-47`，本轮**未逐字核** `docs/paper-v2/*.tex` 原文 ⇒ 标 `[C]`）：

- `docs/paper-v2/ch05-theorems.tex:155-156`：`ρ² := (m_{0⁺⁺*}/m_{0⁺⁺})²`，`Δ := m₂²−m₁²`。
- `docs/paper-v2/ch05-theorems.tex:171-173`：`Let e_k be the k-th nonzero level of the 0⁺⁺-projected coarse generator L (m_k²=e_k, so ρ²=e_2/e_1)`。
- `docs/paper-v2/app.tex:705-706`：`ρ² := μ₂/μ₁ ≤ C²`，`μ_n` = 生成元本征值，且**必须 distinct**。

⇒ **同一件事的两种记号**：
```
e_k = m_k² (生成元能级)     ⇒  ρ² = e₂/e₁ = (m₂/m₁)²
e_n = −ln λ_n/(t−t₀) (质量) ⇒  ρ² = (e₂/e₁)²
```
**锚点**：`ρ² ≈ 2.43 = 1.56²`（`[E]/[J]`，淬火 `SU(3)`、跨道旁证；`1.56` 一手源未核，见 `AUDIT-CH16.md:21,33-34`）⇒ 对应 `e₂/e₁ = 1.56 ± …`，不是 `2.43 ± …`。本档 `§2` 两列都印。

## 3 判：`ρ²(L)` 平稳吗？

**不可判**。三档给出的 `ρ²` 中心值 `27.8 / 2.34 / 1.35` 之间的差**远小于各自的误差**（`8.4 / 15.2 / 108`），且**每一档内部的 `(t₀,t)` 离散**（同一档内中心值跨 `1.35–72`）大于任何 `L` 依赖。⇒ 既不能说稳，也不能说不稳：**读数不存在**。
顺带：`ρ²>1` 在 38/38 个可解点成立，但那是本征值排序的后果（`§0-2`），**不是证据**。

## 4 (b) 需要什么 + 最小可行配置

**诊断（每条带数）**
1. **`T` 不够**（硬约束）：立方体 `T=L`。处方要 `T≳12–16` ⇒ 必须 **`L_s × L_t` 矩形**，而现有抽样核（`m1_fast.py:sh`、`m1_4d_run.make_stream`）**只支持单一 `L`** ⇒ 需要写矩形 njit 热浴（估 **1–2 h**：改 `sh` 为四轴长度 + `staple`/`sweep` 循环 + 用规范不变性 `<1e−15` 与 `plaq` 同一值校验）。
2. **基不够**（主导）：「plaquette + APE 若干级」几乎是同一个算符，`C(t₀)` 只剩 2–3 个独立方向（`§2` 的 rank 与 Gram `3.5%`）。最小改法：`{1×1, 2×1, 2×2} × {unsmeared, APE(0.5,8)}` = 6 算符，并在 `t₀` 上加**门槛** `λ_min/λ_max ≥ 0.1`、`rank ≥ 3`。
3. **统计量不是瓶颈（按现基算它是灾难）**：要把 `σ(ρ²)` 从 `15`（`L=8` 最好那行）压到 `0.2` 需 `×(15/0.2)² = 5.6×10³` 构型 ⇒ `N ≈ 2.3×10⁷` ⇒ `2.3e7 × 48.5 ms = 1.1×10⁶ s ≈ 310 h` 聚合。**⇒ 只加 `N` 是死路；先换基。**

**最小可行配置（估）**
| 项 | 配置 | 成本 |
|---|---|---|
| 抽样 | 矩形 `L_s=8, L_t=16`，`β=2.5`，`SU(2)`，`gap=10`，16 链单作业 | 每链每构型 ≈ `776 ms × (8³·16/8⁴) ≈ 0.26 s` ⇒ 聚合 ≈ `16 ms/conf`；`N=2×10⁴` ⇒ **≈ 5–6 min** |
| 基 | 6 算符（`1×1/2×1/2×2` × `n=0/8`），`t₀=2,3`，`t=4..7` | 测量开销 +30%（≈ +2 min） |
| 读数 | `e₂/e₁` + `ρ²`，链级两级 bootstrap；要求 `rank≥3` 且 `σ(ρ²)≤0.3` 才算数 | 分析 <1 min |
| 前置 | 矩形 njit 热浴 + 6 算符（含 `2×2`） | **1–2 h 编码 + 校验** |
| 内存 | 单链 `U` ≈ `4·8192·4·16 B ≈ 2 MB`（16 链 ≈ 32 MB） | 不是约束（32 逻辑核 / 31 GB） |

**诚实提示**：即便上述都做到，`ρ²` 仍是比值坐标——自由场 `ρ²=4`、2D `8/3`、`ρ²>1` 恒真（`A03-RHO2.md:145-147`、`B02:79-88`）。读数只能把 `ρ²(2.5)` 从"无定义"变成"有数"，**不能**把 `ρ²≥1+c` 的**一致下界**变成定理（`A02-ROUTES.md:194-197`：那一步 = `H*`）。

## 5 纪律与限制（不许省）

- **一次一个重作业**：`L=6`(172 s) → `L=8`(194 s) → `L=12`(345 s) 串行，无并发重作业；每作业内 8/16 条独立链（单进程单核，`NUMBA_NUM_THREADS=1`）。
