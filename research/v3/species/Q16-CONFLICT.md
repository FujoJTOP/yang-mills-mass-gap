## 1. 任务 1：`g` 的值域（`[Q1]`/`[S1]`）

```
us = linspace(1e-9, π, 2e6):   sup g = 0.500000000000  (u→0)
                               inf g = 0.000000000000  (u=π)
g(π/2) = 0.318309886184 = 1/π  （逐位）
⇒ g((0,π)) = (0, 1/2)   ；g((0,π/2)) = (1/π, 1/2)
Popoviciu: 36·(1/2−1/π)²/4 = 0.297102   ← o20/p04 的 0.2971
           36·(1/2)²/4     = 2.250000   ← p17 的 2.25
```
`ν_B` 在 `u>π/2`（即 `w>1`）上的质量实测：`0.3238 (B=1e−6)`、`0.3040 (0.1)`、`0.1590 (1)`、`2.8e−5 (10)`
——与 p17 §4.4 的 `[P7b]` 逐位一致。**range 界被用到的地方正是 `B≲1`，那里 16%–32% 的质量在 `u>π/2`，值域必须算 `(0,1/2)`。**
⇒ **`[T]`：`Var(g) ≤ 1/16` ⇒ `Ψ ≤ 2.25B²`；`0.2971B²` 是错的。**

## 2. 任务 2：`C₁ = 1` 的核（`[Q2]`）

p04 的 L2：`φ` 递减 ⇒ `S ≤ φ(t)(e^{−Bt}−e^{−2B})/B`，`A ≥ φ(t)(1−e^{−Bt})/B`；
要 `S(1−e^{−Bt}) ≤ e^{−Bt}A`，只需 `(e^{−Bt}−e^{−2B}) ≤ e^{−Bt}` ⟺ `−e^{−2B} ≤ 0` ✓。**两行，无漏洞。**
数值：`max_{B,t} P(w>t)/e^{−Bt} = 0.993309`（`B∈{0.3,0.5,1,2,5,10,50,200}` × `t∈[0.02,1.98]` 25 点）。
（o20/p17 的 `C₁=1/(1−e⁻¹)=1.581977` 是**同一事实的弱 1.58 倍**，两者不矛盾——p17 只审 `o20`，没审 p04 的 L2。）
⇒ **`[T]`：`C₁=1` 成立；`1.582→1` 的提升真实。**

## 3. 任务 3：`3.3279/B²` 与 range 无关（`[Q3]`）

```
E[w²] = 2∫₀² ε·ν_B((ε,2])dε ≤ 2∫₀^{1/B}ε dε + 2C₁∫_{1/B}^∞ ε e^{−Bε}dε
      = (1 + 4C₁/e)/B² = 3.327907/B²   (C₁=1/(1−e⁻¹))
      = (1 + 4/e)/B²    = 2.471518/B²   (C₁=1，用 p04 的 L2)
```
链条里**只有**「截断 `1/B`」与「尾界 `C₁`」，`sup g/inf g` 一次没出现。实测 `E[w²]B² = 0.5768, 1.1816, 1.7172, 1.9324, 1.9866`（`B=1,2,5,20,100`）→ 2，全在界内。
⇒ **p17「range 修正使矩常数变大、故 p04 偏小」的推断不成立**：两者是不同量。range 只进 range 支（`0.2971B²`）。

## 5. 判死线逐条

**(a) `C=1.7454 [T]`？—— 不成立。** 它的数值 `= 0.2971·B*²`，即错 range 常数本身（§4.1 逐位）。p04 的 `C₁=1` 与「矩常数不受 range 影响」两点**都对**，但不足以救 `1.7454`。

**(b) `C=10.05 [T]`，p04 的 `6.51→1.70` 提升作废？—— 不成立。** `10.05` 是**旧四引理**（range+Lip+`3.3279`）在修正 range 下的常数，不是 p04 链的修正值；同一台机器换 `C₁=1`+`2/B²` 就是 `6.46`（我复算）。p04 的 centre 链（L4–L8）本身没有被 p17 的 range 论证触及，`1.70` 这一**等级**仍然可达——但**常数不是 `1.7454`**。

**(c) 各对一半 —— 触发。正确值 `C = 3.95`（`[C]`；全 `[T]` 原料，只差 `r≤1` 的数值门槛与 L6 系数）。** 分解：range 常数错（7.57×）把交叉点从 `B=1.33` 推到 `2.43`；`1.7454` 作废、`3.95` 接管；`10.05` 属另一条（更弱的）链。**唯一没被推翻的两条**：`g` 的值域 `(0,1/2)`（p17）与 `C₁=1`（p04）。
