## §4 块化熵（本路赌注）：增益**精确为 0**；唯一正收益是"形状类"

### 4.1 题面的两个前提，逐条核

**前提 (a)："`γ_ent` 大是因为位置熵"—— 假 `[T]`+`[E]`。**
```
簇数 a_n 的指数来自**形状数**（lattice animal 计数）：a_n ≈ μ^n·n^{−θ}
位置只给多项式因子：n 片簇的平移数 ~ n（span⁴ ~ n）
实测：a_6/a_5 = 25.7652，B_6/B_5 = 31.7727   ← 与 e^{3.249}/e^{3.459} 一致（动物增长常数）
⇒ 要降的是"形状熵"，不是"位置熵"；块化对**形状数毫无影响**（见 (b)）
```

**前提 (b)："块化后每块内簇数固定 ⇒ γ 变成每块常数"—— 假 `[T]`。**
```
b=2：每块 96 片细 plaquette（6b⁴），块内构型上限 2^96，ln = 66.5421（≈ ln C(96,48)=64.03）

```

### 4.2 重排恒等式（本节的定理）`[T]`

```
把细簇集按"块影"分割： z = Σ_D W(D),   W(D) := Σ_{sh(C)=D} |w(C)| e^{κq|C|}
W(D) 的每块代价下界： min over the fiber
   总有"每块一片"的连通蛇形（|C| = M，M = |D|）⇒ W(D) ≥ e^{−c₀q·M}

⇒ 块级判据  γ_b < cq_eff   与细级  γ_f < c₀q   **是同一个不等式**（γ_b = γ_f, cq_eff ≤ c₀q）
```
> **⚠️ 这一条正是"块化不能抬高每块代价"的几何理由**：`b²` 的面积放大只对**薄面**成立；而块影的**最便宜**成员是"每块一片"的蛇形，其每块代价不随 `b` 缩放。**`b²` 增益被"块内构型熵"精确抵消。**

**⇒ 判：块化（任意块因子、任意块形状）对 `ρ = e^{γ−c₀q+κq}` 的增益 = 0。它只改单位，不改收敛性、不改窗。** `[T]`
