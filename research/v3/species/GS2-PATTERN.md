## §1 单一 schema

### §1.1 形式化（三行，定义级）

对台账第 `k` 条（`k` 遍历 §2 的 14 行），把它写成三个对象：

```
(S1)  Residual_k  ⟺  Clean_k  ∧  Pay_k
(S2)  Clean_k :  在固定 (L,a,β) 上、对**强度量/密度**成立的不等式，常数 O(1)、不随 (L,a) 变
(S3)  Pay_k   :  Φ_k(𝒩) ≤ B_k ,   B_k = O(1)（"预算"），𝒩 := 分解的计数参数
```

*为什么这是无损的*：台账里每一条的散文都形如"X 已经成立（`[T]`/固定尺度），只差 Y"。`X` 就是 `Clean_k`，`Y` 就是 `Pay_k`。本文只做两件事：(i) 把 `Y` 的**量**抽出来（§1.2）；(ii) 按 `Y` 进入 `Pay` 的**槽**分类（§1.3）。**`(S1)` 不是新命题，是把散文的"只差"改成合取式**——这一步必须做，因为"只差"允许两条独立的差项被读成一条（`GC1:294–307` 的四缺件就是实例）。

### §1.2 那个量是什么：`𝒩 := N_p`（仓内已有名字，不需要新名）

| 断言 | 逐字 / 数 | 出处 |
|---|---|---|
| `N_p = 6L⁴`（4D 环面），`‖S_W‖_∞ ≤ 2N_p = 12L⁴` | "4D 环面 `N_p=6L⁴`，`\|1−½tr U_p\|≤2` ⇒ `‖S‖_∞ ≤ 2N_p = 12L⁴`" | `U08.md:28` `[T]` |
| 所以 `12V = 12L⁴` **就是** `2N_p`，不是另一个对象 | `12V` = `6V` 个 plaquette × `s_p ≤ 2` | `D04-ODE.md:64`；`GC2:29` |
| 块局部版：`N_p(B) = 6b⁴ = 96` | `β=2.5, b=2 ⇒ N_p=96, 2βN_p=480` | `GA5:147` |

### §1.3 `𝒩` 只从三个槽进入（`[T]`），外加两类非 `𝒩` 座（`[T]`+`[C]`）

| 槽 | 形态 | 机制（为什么这个槽会出现） | 仓内见证 |
|---|---|---|---|
| **`(EXT-lin)`** | `c·𝒩 ≤ B` | `β`-Lipschitz / Grönwall：`\|d log F/dβ\| ≤ osc(S) ≤ 2N_p` | `D04-ODE.md:198–203`；`GC2:29` |
| **`(EXT-exp)`** | `e^{−c𝒩} ≤ B` | 上面那一句**积分**（或用 Holley–Stroock / 有界密度比） | `GA5:107,147`；`GM2:230`；`GA1:55` |
| **`(EXT-log)`** | `c·log 𝒩 ≤ B`（或其反向：`log 𝒩` **不够**） | RG 时间 `t_up`、塔层数 `J`：`∫γ d log μ` 与 `log(1/a)` | `GK2:169,200`；`GC1:212` |

**三槽的常数同源同阶**（这是把它们并成一类的实质依据，不是类比）：

```
GA1  e^{−29.8187L⁴}  = e^{−(2N_p)·2.4848918868}     ⇒ c = 2Δβ_W = 4.970
GA5  e^{−2βN_p(B)}   = e^{−480},  β=2.5            ⇒ c = 2β    = 5.000
GM2  e^{2βN_p}       = e^{30L⁴},  β=2.5            ⇒ c = 2β    = 5.000
GX1  e^{−N_k},  N_k = 12L⁴Δβ_k = 2N_p·Δβ_k          ⇒ c = 2Δβ_k
```
⇒ **`c ∈ {2β, 2Δβ}`，全部 `= O(1)` 且 `5` 上下**。三个"不同的常数"其实是同一对参数 `(2, β 或 Δβ)`。

**两类非 `𝒩` 座**（这就是 14 条里剩下的 5 条，见 §2）：

| 类 | 形态 | 含义 | 为什么不能塞进 `𝒩` |
|---|---|---|---|
| **`(TGT)` 靶座** | `Pay ≡ 靶本身（或其换名）` | 第二座不是外部量，是第一座的对偶面 | 它不以 `𝒩` 为自变量；把 `𝒩` 付清也不会让它变小（`GA2:73`：`S=1/Var(a)`，需 `χ` 上界 = `H1`） |
| **`(NIL)` 空座** | 不存在 / 免费 / 方向反 | 该条**没有**未付的第二座 | `GC3:122`（`hi=+∞` 空真）；`GC4:195`（`Δ_0 ≥ Δ_K` 为**假**，不是未付） |

### §1.4 座的判定法（三步，可对任何新条目机械执行）

```
步1  写下该条的"只差 Y"那句散文（台账逐字）。
步2  问：Y 里出现的量，在 a→0 或 L→∞ 下是否无界？
        否 ⇒ 座 = (INT)（每单元常数；§2 的副座）
        是 ⇒ 步3
步3  问：Y ≤ O(1) 若成立，靠的是
        (a) 一个 Lipschitz/单调常数         ⇒ (EXT-lin)
        (b) 一个 e^{−c·(无界量)} 的指数小    ⇒ (EXT-exp)
        (c) 一个 log(无界量) 的有界性        ⇒ (EXT-log)
        都不是 ⇒ 座 = (TGT)（Y 逐字就是靶）或 (NIL)（Y 免费/方向反）
```
