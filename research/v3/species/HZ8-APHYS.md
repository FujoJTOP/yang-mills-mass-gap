## §1 把 `(A-phys)` 写成可检验的陈述

### 1.1 字面形，以及它为什么不是良定义的

`docs/CLAY-PROOF-CHAIN.html:234–237` 写 `H_a ⟶ H（强预解），a=a(β)→0`。三个词各自需要钉死：**`H_a` 在哪**、**`→` 是哪种拓扑**、**沿哪条序列**。

- **`H_a` 在哪**：`H_a := −(1/a)\log T_a` 作用在 `1^⊥ ⊆ ℋ_a = L²(G^{Λ_a})`（`glue-b-blocking/REPORT.md:267–272`）。`Λ_a = aℤ⁴ ∩ L` 的链数 `~ (L/a)^4`，故 `dim ℋ_a ~ (L/a)^{3N_c} → ∞`。⇒ `(4.1)` 里那两个算子**不同空间**，逐字无意义（`GO2-SOFTMODE.md:286`；`BREAK-IN-9.md:12`；`GN2-VARIATIONAL.md:81`）。
- **可修的三种写法**（都不改变难度，只改变可写性）：
  1. **重整生成元**：`Ĥ_a := Z_a^{-1}·ι_a H_a ι_a^{-1}`，`ι_a` = 块自旋插值 + 高斯标度 `A ↦ (1/a)(U−1)`（`BREAK-IN-9.md:7`）。`(A-phys)` 变成 `Ĥ_a → H` 强预解。
  2. **形式（二次型）收敛**：`ι_a` 把 `Q_a` 送进公共形式域 `Q`，比 `𝔮_a` 与 `𝔮`（`GP9-RB.md:192,244–255`）。这条**不需要**算子级 `ι_a`，只需要形式级，是仓内最接近可执行的一支。
  3. **测度/相关函数层**：不写 `H_a→H`，写 `S^{(n)}_{L,a} → S^{(n)}` 加 OS 重构（`G1-CONTINUUM-OS.md:3,5`）。这条**已知不编码 `Δ`**（见下 1.4），所以它是替代品不是等价品。
- **沿哪条序列**：`a = a(β)`，`β → ∞`；`a(β)` 是 RT 上的单调双射（`GK5-CONTINUUM.md:252`），"`a→0 ⟺ β→∞`"在仓内是**输入**而非定理。⇒ `(A-phys)` 是**沿一条指定射线**的极限，不是 `a` 的全极限。

**判**：`(A-phys)` 的**可检验形**必须写成

```
(A-phys)′   ∃ ι_a, ∃ Z_a > 0, ∃ 共同核 D ⊆ ℋ :
            (i)   ∀ξ,η ∈ D :  Z_a^{-1}⟨ι_a ξ, H_a ι_a η⟩ ⟶ ⟨ξ, H η⟩
            (ii)  sup_a Z_a^{-1}‖H_a|_D‖ < ∞                                  （一致预解/矩阵元界）
            ⇒ (iii) (Ĥ_a − z)^{-1} ψ → (H − z)^{-1} ψ   ∀ψ, Im z ≠ 0          （强预解）
```
`(i)∧(ii) ⇒ (iii)` 是 Trotter–Kato（`BREAK-IN-9.md:9`，Reed–Simon I Thm VIII.25，**未逐字核正文**）。⇒ **`(A-phys)′` 的可检验内容全部在 `(ii)`**：`(i)` 是"收得到"，`(ii)` 是"收得到**且不炸**"。

`GE3-GAPLB.md:95–109`（`[T]`，纯谱演算）：`H = 0·P_Ω + m₁P_{Ω^⊥}`、`H_a = 0·P_Ω + m₀P_{u_a} + m₁(1−P_Ω−P_{u_a})`、`u_a ⇀ 0`。逐条：`ker` 一维、`H_a≥0`、`Δ_cont=m₁`、**`Δ_a=m₀` 对一切 `a`**；**`SPEC-RES` ✓**（第二预解式范数 `≤|(m₁−m₀)/((m₀−z)(m₁−z))|` 有界）；同时 `ε^{form}=(m₁−m₀)/m₁`、`b=0`。取 `m₀=m₁/2`：`Δ_a/Δ_cont=1/2`。
⇒ 这条**不**违 `(B)`（`Δ_a` 是正常数，比值 `m₀/(aΛ)→∞` 仍满足下界）；它证明的是**更强的一句**：`(RB)` 形状所能给的最强结论是 `Δ_a ≥ (1−ε)Δ_cont − b`（`GE3-GAPLB.md:113`，两行 min–max），而 W-εb **把该界取等** ⇒ **连定量化的 `(A-phys)` 也只到 `Δ_cont` 的一个比例，到不了 `Δ_cont`，更到不了 `(B)` 所需的"与 `a` 无关"的地板**。

**(I-d) 物理侧的同型见证：自由场。** 连续极限存在（massless GFF，满足全部 OS 公理）而 `Δ_cont=0`（`CONTINUUM-TIGHTNESS.md:9`；`G1-CONTINUUM-OS.md:13`）。⇒ "极限存在"与"有地板"在**物理模型**上就分开了（§5）。

### 3.3 方向 II：`(B) ⇏ (A-phys)` —— 三证

**(II-a) 量词域证（`[T]`，文本级）。** `(B)` 全句在 `(L,β)` 上量化、右端是 `‖T_a|_{Ω^⊥}‖` 的**一个数值**（`CLAY-PROOF-CHAIN.html:296–300,431–439`）。⇒ 任何两个算子族 `{H_a}`、`{H_a'}`，只要 `‖T_a|_{Ω^⊥}‖` 相同（等价地 `Δ_a` 相同），`(B)` 的真值就相同，而 `(A-phys)′` 可真可假。故 `(B)` 不蕴含 `(A-phys)`。这不是"没查到反例"，是**符号集不允许**。

**(II-b) 同层不同泛函证（`[T]`，这是本路最锋利的一条）。**
`glue-b-blocking/REPORT.md:285` 逐字："**极限（弱/分布/范数）不编码 `Δ`；编码它的是 `a=0` 处 `log T_a` 的 `O(a)` 项**。" 记该 `O(a)` 项为 `𝒜_a`（等价地 `Ĥ_a` 的"高能相对支配"部分，`GP9-RB.md:195` 逐字："`O(a)` 项 = 高能相对支配 = `(RB)`"）。于是

```
(B)           读 𝒜_a 的  inf σ 的下界：   inf σ(𝒜_a) ≥ δΛ          （一个 inf-下界）
(A-phys)′ 实体 读 𝒜_a 的  sup ‖·‖_D 的上界： sup_a Z_a^{-1}‖𝒜_a|_D‖ ≤ C   （一个 sup-上界）
```
（写法说明：`𝒜_a` 与 `H_a` 的 `O(a)` 部分同槽；上式右端与 `BREAK-IN-9.md:9` 的 `sup_a Z_a^{-1}‖H_a|_D‖ < ∞`、`:17` 的 `sup_a Z_a^{-1}⟨ψ_a,H_aψ_a⟩ ≤ C` 是同一格的两种记法。）
`BREAK-IN-9.md:13,17,20` 逐字给出右侧：需要的是"**一致一阶矩** `∫λdν_a = ⟨ψ_a,H_aψ_a⟩ < ∞`"，它们"**正是 `Z_a^{-1}\log T_a` 的 `O(a)` 系数**"；"**对恒等于常数的极限求 `a`-导数，信息为零**"。
⇒ **`inf`-下界不支配 `sup`-上界，`sup`-上界也不支配 `inf`-下界。** 两者落在**同一个对象**上，却是两个**不可比**的泛函。这就是"独立"的精确含义——不是"无关"，是"**同址不可互推**"。

**(II-c) 抽象见证（`[T]`，3 行谱演算；`(B)`-型地板成立而 `(A-phys)` 失败）。**
```
ℋ = ℂ ⊕ ℂ²,   Ω = 第一个基向量。
H_a := 0·P_Ω ⊕ (D + ε|u_a⟩⟨u_a|),   D = diag(1,2),   u_a = (cos θ_a, sin θ_a),  0<ε<1.
θ_a 取两条子列 0 与 π/4 交替（θ_a 无极限）。
(i)  H_a ≥ 0、ker H_a = ℝΩ、H_a ⪰ 0⊕D ⇒  Δ_a ≥ 1  （∀a）        ⇒ (B)-型地板 ✓（δ=1）
(ii) 沿 θ=0：块 = diag(1+ε, 2)；沿 θ=π/4：块 = [[1+ε/2, ε/2],[ε/2, 2+ε/2]]
     （特征值 (3+ε ± √(1+ε²))/2，ε=1 时 {1.2929, 2.7071}）
     ⇒ (H_a−z)^{-1} 沿两子列取**不同**极限 ⇒ 不强预解收敛 ⇒ (A-phys)′ ✗
```
⇒ `(B)`-型地板在、`(A-phys)` 失败。**与 `GE3` 的 W-εb 同规格**（抽象类内的逻辑见证，不是物理族的陈述）。
