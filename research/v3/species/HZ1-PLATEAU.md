### 1.2 一行式（三写法）

```
(G)   G_c(L) := e^{√c} · inf_{0≤τ≤L} C_L(τ)
             =  e^{√c} · C_L(L)                              [T] 端点恒等（§1.3 T1）

(P)   无 O(1) 跨体积平台：
          ∀c>0 ∀r₀>0 ∃L₀ ∀L≥L₀ :  G_c(L) ≤ r₀               （等价于 G_c(L) → 0，每个固定 c）

(P′)  累计等价形（承重，唯一可用的等价）：
          P  ⟺  ∀c>0 ∀r₀>0 ∃L₀ ∀L≥L₀ :  M_c(L) := ν_L({m ≤ √c/L}) ≤ r₀
```
出处：`(P)` 的原始来源是 `GY2:172` 逐字 `PLAT(c, r₀) : ∃族{L} : C_L(τ) ≥ r₀ e^{−√c} 对所有 τ ∈ [0,L]`，以及 `GY2:175–176` 的双条件；`(G)` 的端点化是本轮紧化（原式给的是窗口量词，`(G)` 把它压成单点）。

### 1.3 四个 `[T]`（本轮全部承重件）

**(T1) 端点恒等** `[T]`
```
C_L(τ) = Σ_{n≥1} w_n e^{−m_n τ}（w_n ≥ 0, m_n > 0）  ⇒  τ ↦ C_L(τ) 完全单调 ⇒ inf_{[0,L]} = C_L(L)
```
出处：`GY2:141–143`（谱表示）· `GY1:37`（OS 正性 ⇒ `C̄_L(t) ≥ 0`、`f² = |⟨n|O_c|Ω⟩|² ≥ 0`）· `PROOF-P3-UNCONDITIONAL.md:19`（离散谱）。
⇒ `(P)` 是**单点**陈述：`C_L` 在时刻 `L` 的一个数，不是整段形状。

**(T2) 有界免费** `[T]`
```
G_c(L) ≤ e^{√c} C_L(0) = e^{√c} M₀ ≤ 2e^{√c} N²      （对固定 c 一致）
```
理由：`O = ¼tr F² ∈ [0,N]`（plaquette 迹有界）⇒ `Var(O) ≤ 2N²`。
⇒ `(P)` 的"有界"半边是**零成本**的；命题的全部内容在"下界/极限值"。

**(T3) 量词序不可换** `[T]`
```
∃L₀ ∀c ∀r₀ : G_c(L) ≤ r₀   对任何 ν ≠ 0 恒假
```
理由：固定 `L`，`G_c(L) ≥ e^{√c} w₁ e^{−m₁L}`；令 `c → ∞` 得 `G_c(L) → ∞`（因 `e^{√c}` 压过 `e^{−√c}` 型衰减）。
⇒ **`∀c` 必须在 `∃L₀` 之外**（每个固定质量尺度 `c` 各有一个起点）。这是 `(P)` 与"平凡真"的分界线：反写即恒假。

**(T4) 修正等价（累计版）** `[T]`
```
向前：  M_c(L) ≥ r₀   ⇒   ∀τ∈[0,L]: C_L(τ) ≥ r₀ e^{−√c}      （窗口内每个 e^{−mτ} ≥ e^{−√c}）
反向：  C_L(L) ≥ r₀   ⇒   M_{c′}(L) ≥ r₀ − M₀ e^{−√c′}        （任意 c′ > c；窗外贡献 ≤ e^{−√c′} M₀）
⇒  (P)  ⟺  (P′)      （取 c′ 使 M₀e^{−√c′} < r₀/2，用 (T2) 的 M₀ ≤ 2N²）
```
**与 `GY2 §4.4` 的差**：那里的反向用的是 `ν_L({m₁²}) = w₁`（**单原子**），而 `C_L(L)` 是**整条谱**的和——谱和可以摊开在 `~L³` 个近简并原子上（段 **[3]**：`f₁² = 1/L³ → 0` 而 `G_c → 0.809`）。故 `GY2:178` 那一步不成立，`[T]` 须换成 (T4)。

### 1.4 "O(1)" 这个词在名字里承什么重

`(P)` 的 `r₀` 是**绝对水平**（与 `L` 无关、与 `c` 无关的常数），它承的不是归一化，而是**权重地板**：
- 若只有"轻质量"而没有权重（thin atom `w = ε/2λ → 0`），`P` **看不见**（§2(b)）——这就是 `(P)` 必须配原子地板的原因；
- 若有权重而无轻质量（有隙），`P` 平凡成立（§3 S2）。
⇒ 名字里的 `O(1)` = **"累计质量在盒尺度窗口内是常数级"**，不是"关联子值 `O(1)`"（后者是 (T2) 的免费有界，不含内容）。

## §2 三条路（逐条判 + 逐条下一手）
