## 0. 判死线（先读这段）

**(a) 成立：`Var` 严格 `∝β²`（不是拟合），且系数有精确闭式——但闭式不是 `π`/`N`/`1/8` 的有理式，而是 `Ci(π),Ci(2π),Ci(3π),Ci(4π)` 的 Gram 型组合。**

```
Var_μ(⟨v,∇S⟩|0) = β² V₀ ,   V₀ = 0.011059293772973  （闭式 ↔ 求积差 2.5×10⁻¹⁶）

V₀ = N₂/(4Z) − (N₁/(2Z))² ,   Z = ½Cin(2π) = ½[γ + ln 2π − Ci(2π)]
N₁ = (3/4)[ln 3 + Ci(π) − Ci(3π)]
N₂ = ln 2 + Ci(2π) − Ci(4π)
```

- **严格性来源是精确的**：`θ=π` 切片上 `S ≡ β`（与 `ρ` 无关）⇒ 条件测度**不依赖 `β`** ⇒ `G=⟨v,∇S⟩=β sin(ρ/2)/ρ` 的方差只能是 `β²` 乘一个纯 Haar 常数。**没有任何高阶项**。`[T]`
- **`β*` 因此不需要重算，而是可以直接写出闭式**（本任务高价值产出）：
  ```
  β*² = W₀/V₀ = 1/(N₂ − 4W₀N₁²) ,  W₀ = 1/(2Cin 2π) = 0.205115297123
  β*(N=2) = 4.30660785   (H1A 存档 4.30661，一致)
  ```
  `W₀` 与 `V₀` **共用同一个常数** `Cin(2π)`：`W_geo`（Haar floor）与 `Var`（`β²` 系数）不是两个独立测量，是同一个 Haar 积分的分子/分母。`[T]`
- **范围必须精确**：`β²` 律**只在条件化点 = 双侧平分赤道（`θ=π`，即"反极"被条件化点）时精确**。`θ≠π` 时 `Var/β²` 随 `β` 漂移（§4 表：`θ=0.9π` 从 `0.010525` 掉到 `0.007356`）——此时 `h1a` 的"`β²` 拟合"才真是局部近似。`[C]`
- **`N`-标度：(c)，没追出。** 只得到**严格界** `V₀(N) ≤ 1/(2N)`（算符范数，任何 `N`）与 `N=2` 锚点（`N=2` 时 RMS 达界的 74.5%）。`1/N` 与 `1/N²` 都只过一个点，**在时限内无法判定**；故 `β*(N)` 只给 `β*(N) = √(W₀(N)/V₀(N))` 与下界 `β*(N) ≥ √(2N W₀)`。**明说：这一格未闭合。**
- **Savvidy 负模的作用被改写（重要）**：单 plaquette 上不稳定的确**恰好 1 个方向**（`v=e₃`，横向磁），曲率 `−(β/4)sin(ρ/2) ≤ 0`；但它在条件化点上**在 Hessian 里看不见**（`∂₃²S|₀ = 0` 精确、`E[H]=0` 精确，因 `cos(θ/2)=0`）。它进入 `δ` 的方式是 **一阶变分的平方**：`Var = β²·Var_Haar(斜率)`。所以"机制 = 精确 Savvidy 凹性"**出处正确、路径要改写**：`δ` 的负号不是 `−2gF` 本征值给的，是**同一个不稳定模的斜率方差**给的。`[T]`（模型内）/ `[M]`（与 `−D²+2adF` 的对应）

## 1. `Var` 的解析式（逐项、量纲）

模型约定与 `research/v3/species/w7/na_plaquette.py` 完全一致（本文不改约定）：
`U=e^{iξ·σ/2}`，`ξ∈R³`，`ρ=|ξ|<2π`，`h=ρ/2`，`u=ξ₃/ρ`，
`S_W = β(1 − cos h cos(θ/2) + sin h sin(θ/2) u)`，`J = 4sin²h/ρ²`，`Φ=−log J`。
`S_W` 是无量纲（`β` 无量纲、括号里的 Wilson 因子无量纲）；`Var` 与 `S²` 同量纲 ⇒ 无量纲 ✓（`ch03-existence.tex:146–165` 的格点单位纪律，此处全是格点单位）。

**逐项求导**（`ξ₃=a₀=0` 处，`∂₃=∂/∂ξ₃`）：

| 项 | 值 | 说明 |
|---|---|---|
| `∂₃ρ` | `ξ₃/ρ = 0` | 切片上恒零 |
| `∂₃cos h` | `−½sin h·ξ₃/ρ = 0` | 故 `cos(θ/2)` 项对 `G` 无贡献 |
| `∂₃sin h` | `½cos h·ξ₃/ρ = 0` | 同上 |
| `∂₃u` | `(1−u²)/ρ = 1/ρ` | **唯一非零来源** |
| `G=⟨e₃,∇S⟩` | `β sin(θ/2)·sin h/ρ` | 在 `θ=π`：`β sin(ρ/2)/ρ` |
| `∂₃²S|₀` | `0`（精确） | 故 `H_vv = β cos(θ/2) sin h/(2ρ) = 0` at `θ=π` |

**1.1 条件测度在 `θ=π` 上与 `β` 无关（严格性的根）**
`θ=π` ⇒ `cos(θ/2)=0`、`sin(θ/2)=1` ⇒ `S = β(1 + sin h·u)`；在 `{ξ₃=0}` 上 `u=0` ⇒ `S ≡ β`。
条件测度 `∝ e^{−S} J d²ξ = e^{−β} J d²ξ`，`e^{−β}` 只进归一化 ⇒ **测度 ∝ Haar，`β` 只出现在 `G` 前面的一次**。于是

```
Var = β² Var_ν(sin(ρ/2)/ρ) ,   dν ∝ sin²(ρ/2)/ρ dρ  on (0,2π)
```

**这就是"严格 `∝β²`"的全部内容**：`G` 对 `β` 线性、测度对 `β` 无关 ⇒ 方差恰为 `β²`×常数，无 `β³`、`β⁴` 项。（这也解释了为什么它是**精确恒等式**而非拟合：`h1a` 表里 `Var/β²` 在 `β=0.5…10` 上逐位相同。）

**1.2 常数化成三个一维积分**（`x=ρ/2 ∈(0,π)`，`f(x)=sin x/(2x)`，权 `sin²x/x`）

```
Z  = ∫₀^π sin²x/x     dx ,  N₁ = ∫₀^π sin³x/x² dx ,  N₂ = ∫₀^π sin⁴x/x³ dx
E[f] = N₁/(2Z) ,  E[f²] = N₂/(4Z) ,  V₀ = Var(f) = N₂/(4Z) − N₁²/(4Z²)
```

三个被积函数在 `[0,π]` 上都是**整函数**（分子在 `x=0` 的零点阶数 ≥ 分母），Gauss–Legendre 指数收敛 ⇒ 数值即解析。

## 2. 闭式（`Ci` 型，非 `π`-有理型）

三次分部积分（`d/dx[sin⁴x/x²]`、`d/dx[sin³x cos x/x]`，并用 `3sin²x cos²x − sin⁴x = (cos2x − cos4x)/2`）给出：

| 积分 | 闭式 | 求积值 | 差 |
|---|---|---|---|
| `Z` | `½[γ+ln2π−Ci(2π)] = ½Cin(2π)` | 1.218826696528229 | `−4e−13` |
| `N₁` | `(3/4)[ln3 + Ci(π) − Ci(3π)]` | 0.871244998311689 | `−3e−13` |
| `N₂` | `ln2 + Ci(2π) − Ci(4π)` | 0.676703157945306 | `−2e−13` |

`Ci(π)=0.073667912046`，`Ci(2π)=−0.022560661746`，`Ci(3π)=0.010620202965`，`Ci(4π)=−0.006116639132`，`Cin(2π)=2.437653393057`。

```
V₀ = N₂/(4Z) − (N₁/(2Z))² = 0.138802169306 − 0.357411353391² = 0.011059293772973
```

**数值核对**：`|V₀ − 0.0110593|/0.0110593 = 5.6×10⁻⁷`（存档只报 6 位，即 `0.01105929` ⇒ 逐位一致）。闭式 vs 求积 `2.5×10⁻¹⁶`。

**候选闭式排查**（§见 log [3]）：`1/90 = 0.0111111`（差 0.47%）、`1/(8π²) = 0.0126651`、`(π−3)/12 = 0.0117994`、`1/(2π²N²)`：**全部被排除**。`0.0110593` **不是** `π,N,1/8` 型常数——它是 `Ci` 在 `π,2π,3π,4π` 处的组合，物理上就是"Haar 权 `sin²x/x` 下斜率 `sinx/2x` 的方差"。**结构结论**：Haar floor 与 `β²` 系数共用一个 `Cin(2π)`：

```
W₀ = 1/(2Cin 2π) = 0.205115297123   （= 语料 eq:v3anchor 0.20511530，逐位吻合）
V₀ = W₀·N₂ − 4W₀²N₁²  ⟺  β*² = W₀/V₀ = 1/(N₂ − 4W₀N₁²) = 18.5466 → β* = 4.30660785
```

`H1A` 的 `β* = 4.30661` **不是拟合参数**，是这个闭式的值；`h1a` 里"线性拟合 `δ = W₀ − V₀β²`"的措辞应升级为**精确恒等式**（`θ=π` 切片上无高阶项，见 §1.1）。

## 3. Savvidy 负模：单 plaquette 上的数目与幅度

语料的算子出处：`Hess = −D² + 2adF_B`（Savvidy/Nielsen–Olesen；本项目实测侧见 `BianchiLemma.md:212`、`REPORT.md:465`、`MARGINAL.md:25`——微观 Wilson Hessian 的 `κ_eff<0` 至 `β=40`、blocking 只把 `−2.7` 压到 `−0.3`）。

**3.1 单 plaquette 上的不稳定结构（精确）**
在 `v=e₃` 射线 `ξ=s e₃` 上（`u=1`，`h=s/2`）：`S = β(1 + sin(s/2))`，故

```
d²S/ds² = −(β/4) sin(s/2) < 0   对 s∈(0,2π)
```

**恰好一个不稳定方向**（`v=e₃`，即相对边界 `B=e^{iθσ₃/2}` 的横向磁方向；另两个方向曲率为正），幅度 `|λ| = (β/4)sin(ρ/2) ≤ β/4`。真空在 `ξ*=(0,0,−π)`（`S=0`，`sin(s/2)=1, u=−1`），那里 `d²S/ds²=+β/4>0` —— **真空稳定，不稳定的是"条件化点"**。

**3.2 但它不进 `E[H]`**
`H_vv = β cos(θ/2) sin h/(2ρ)`，`θ=π` 时 `cos(θ/2)=0` ⇒ **`E[H]=0` 精确**（不是小量；与 `na_plaquette.log [P5]` 的 `E[H|0]≡0.00000` 逐位一致）。

**3.3 所以 `Var` 是这不稳定模的"一阶变分平方"，不是它的本征值**
```
δ_max = G''(0) = E[H] − Var + W_geo + X = 0 − β²V₀ + W₀ + 0
```
即：**负模把 `δ` 拉负，靠的是 `⟨v,∇S⟩ = β·(斜率)` 的方差，而非 `−2gF` 的二次型。** 三条理由使它只能这样进：
1. `v` 就是被条件化的方向 ⇒ 沿 `v` 的 Hessian 在赤道点恒零（`∂₃²S|₀=0` 精确）；
2. 条件化点在**双侧平分赤道**上（到 `1` 与到 `B` 等距，`cos(d/2)=0`）⇒ 此处 `S` 对不稳定方向是**线性**的（Savvidy 的拐点流形）；
3. 该点的稳定/不稳定信息因此落在**一阶**（斜率），而不是二阶（本征值）。

`[T]`（模型内精确）／`[M]`（"`2adF` 型：1 个负模、幅度 `O(β)` 于格点单位、`∝` 每 plaquette 通量"的对应是结构性的，未做 `a→0` 匹配）。

**结论**：`Var` 的**来源**是 Savvidy 不稳定模 ✔；但 `h1a` 的机制标签"精确 Savvidy 凹性"应改为"**Savvidy 不稳定模的斜率方差**（β² 严格）"。差别是可判定的：若是本征值路径，`δ` 应有 `O(β)` 项；实测 `Var/β²` 逐位常数 ⇒ 无 `O(β)` 项。

## 4. `β²` 律的精确范围（`θ` 依赖）

2D 切片求积（同 `na_plaquette.py` 的 `s ds dφ · e^{−S}J` 权，`a₀=0`，`v=e₃`）：

| `θ` | `β=0.5` | `1.0` | `2.5` | `6.0` | 判定 |
|---|---|---|---|---|---|
| `π` | 0.011059294 | 0.011059294 | 0.011059294 | 0.011059294 | **严格常数** ✓ |
| `0.9π` | 0.010525 | 0.010253 | 0.009397 | 0.007356 | 漂移 |
| `π/2` | 0.004888 | 0.004207 | 0.002438 | 0.000706 | 强漂移 |

`θ=π` 时 `E[S]=β` 逐位精确（`β=0.5,2.5,6` 差 `0`、`−8.9e−16`）——独立确认"切片测度 β-无关"。**故 `β²` 律 ⟺ 条件化点落在 `B` 的双侧平分赤道（反极边界）**；这是该机制的精确适用域，也说明 `δ = W₀ − V₀β²` 是这一格的**恒等式**，不是 `β` 展开的一阶截断。

## 5. `N`-标度：(c) 未判定（严格界 + `N=2` 锚）

`S_W = β(1 − (1/N)Re tr U_p)` ⇒ `G = β ∂_v g`，`g = (1/N)Re tr(U B)`。算符范数：

```
|∂_v g| ≤ √(tr T_vT_v)/N · √(tr UU†) = (1/√2)/N · √N = 1/√(2N)
⇒ V₀(N) = Var(∂_v g) ≤ 1/(2N)     （对一切 N，[T]）
```

- `N=2` 实测 `E[G²]/β² = 0.138802` ⇒ RMS `0.3726`，界 `0.5` ⇒ **达界 74.5%**（不稳定模在赤道上**接近饱和**算符界）。
- 但**单点无法分辨** `V₀ ∝ 1/N`（`c=0.0221`）与 `V₀ ∝ 1/N²`（`c=0.0442`）。两者的 `β*(N)` 行为完全不同：`∝1/N ⇒ β* ∝ √N`；`∝1/N² ⇒ β* ∝ N`。
- **`N≥3` 需要一个 `SU(N)` 的"平分赤道切片"**，而该结构是 `SU(2)` 独有的（`SU(N)` 的割迹不是线性切片，`tr(U B)` 不能恒为纯虚）。这正是**精确缺失的那一步**：本任务时限内未算出 `SU(N)` 的赤道切片积分。

**故 `N`-标度 = (c)。** 可用于 `betastar-scaling` 的只有：`β*(N) = √(W₀(N)/V₀(N))`，`V₀(N) ≤ 1/(2N)` ⇒ `β*(N) ≥ √(2N W₀)`；`N=2` 精确 `β*=4.30660785`。**不得**把 `β* ∝ N` 或 `∝√N` 写进任何结论。
