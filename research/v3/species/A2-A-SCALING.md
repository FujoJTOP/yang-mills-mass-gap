# A2-A-SCALING — BD 链 × 谱桥：`a` 的幂次到底落在哪一侧

> 纯解析，无数值。上游：`AT-STAR.md`（定理 AT-1）、`R1-BRIDGE.md`（链 (1)–(6)）、`COV-T.md`（`Q(∞)` 实测）。
> 术语：BD 链 = `γ ≥ (N/4)e^{−2Q(∞)}`；谱桥 = `λ₁(μ_vac) = 2m₁`。

## 0 · 判死线（先写）

**(b)。** `γ/λ₁ = ½·m·a`（格点无量纲规范），幂次 **(a⁺¹, m⁺¹)**：`γ ∝ (ma)²`、`λ₁ ∝ (ma)¹`，多出来的那一次 `a` 在 **γ 侧**。等价的协变写法是 **`λ₁ = 2m₁/a`** —— 谱桥按字面 `λ₁ = 2m₁` 只在 `a = 1` 成立，欠的那个 `a^{−1}` 就是全部内容。

于是 `ma → 0` 时 `γ/λ₁ → 0`：BD 的 `(N/4)e^{−2Q}` 相对 `2m₁` **退化为 0**，BD 给不出 `a`-一致下界。**不是 (a)**：BD 界写成同一比值是 `(N/8)e^{−2Q}/(ma) ∝ (ma)^{−1}`，这个 `1/(ma)` 是记账陷阱——它不表示"判据变强"，只表示**相容性要求**

```
Q(∞) ≥ ln[1/(ma)] + ½ln(N/4)          (★)
```

**也不是 (c)**：`γ` 与 `λ₁` **不同标度**（`a²` vs `a¹`），"同标度"只在 `ma = 2` 这一点上偶然成立（自由场精确等式 `m̂² = 2m̂` 的唯一根）。

## 2 · 量纲一致性倒推：`γ` 是什么量纲，`∇` 关于什么度量

BD 的 LSI 逐项写出（`F = f²`）：

```
Ent_μ(F)  ≤  (2/γ) · E_μ[ |∇√F|² ] ,      |∇√F|² = Σ_ℓ ⟨∇_ℓ√F, ∇_ℓ√F⟩_g(ℓ)
```

- **`∇` 关于什么**：#T 它是**场组态空间** `X = SU(N)^{#links}`（或 `θ_ℓ = a g A_ℓ` 的李代数坐标）上的梯度，`g(ℓ)` 是**每一条链**上的双不变度量，求和是**逐链**求和。**不是**时空梯度 `∂_μ`。这一点决定一切：时空体积 `∫d⁴x` 与"逐链求和"之间差一个 `a⁴`。
- **左端**：`Ent_μ(F) = ∫F ln F dμ − (∫F dμ)ln(∫F dμ)`，`μ` 是概率测度 ⇒ **无量纲**。 [T]
- **右端**：`E` 在 `θ` 坐标下无量纲（`F` 与 `θ` 都无量纲），在 `A` 坐标下带 `a^{−6}`（`∂/∂A = a·∂/∂θ`，逐链求和又给 `a^{−4}`；这是 `R1-BRIDGE.md:254` 那条 `1/a²` 的来源之一）。 [T]
- **`γ` 的判读**：`(2/γ)·E/Ent` 是无量纲比值 ⇒ `[γ] = [E]`。在 `θ`（格点）规范 `[E] = 1` ⇒ `γ̂` 无量纲，物理 `γ = γ̂/a²`（`M²`）。 **`γ` 的量纲 = 它所在 Dirichlet 型的量纲**，这是全题**唯一**的自由度；`MC-METRIC.md §2.2(i)`（`G→cG` 时末端 LSI 精确不变）说明**常数重标度是规范方向**，不会改变本结论——但 `a` 不是这种重标度（它同时把 `θ = aA` 与 `T = e^{−aH}` 朝**相反**方向推）。 [T]
- **BD 链的一致性**：`γ ≥ (N/4)e^{−2Q}` 的右端是**纯数** ⇒ 左侧只能是无量纲的 `γ̂`，即该链的规范**逐字就是格点单位** `a = 1`。物理写法必须是

```
a²·γ_phys  ≥  (N/4)·e^{−2Q(∞)}      ⇔      γ_phys ≥ (N/4)a^{−2}e^{−2Q(∞)}   [T]
```

- **谱桥的一致性**：`λ₁ = 2m₁` 两端量纲 `M²` vs `M¹` 不符 ⇒ 只有两条出路，**都要求一个 `a`**：
  (i) 把它当格点恒等式 `λ̂₁ = 2m̂₁`（`a=1` 才成立）；(ii) 把它写成协变形式 `λ₁ = 2m₁/a`。
  若坚持 `λ₁ = 2m₁` 且把 `λ₁` 认成**同一个** LSI 常数，则 `γ = 2m₁` 会给 `γ` 强加 `M¹`，与 #7 冲突 ⇒ **`γ` 的定义被污染，整条链不再是同一个 Dirichlet 型**。 [M]

**倒推结论**：BD 链与谱桥**不能同时**在"无 `a`"的规范里成立；两者相差**恰好一次幂 `a`**，位置在 `λ₁ ↔ m₁` 的换算上。

## 3 · `γ/λ₁` 的显式表达式

**自由场精确标定**（严格，可算，不靠 BD）：`μ_vac` 是高斯，精度算子 `K = −Δ_L + m̂²`，LSI 常数的**精确值** `γ̂ = λ_min(K) = m̂²`（`m = 0` 给 `0`，与 `R1-BRIDGE.md:239` 的内部数值 `λ_conf = m²` 逐位一致）。谱桥给 `λ̂₁ = 2m̂₁`。于是

```
(3a)   γ/λ₁ = m̂₁² / (2m̂₁) = ½·m̂₁ = ½·m·a                [T] 自由场精确
(3b)   γ/λ₁ ≥ (N/4)e^{−2Q} / (2 m̂₁) = (N/8)·e^{−2Q}/(m a)   [C] 代入 BD 界
(3c)   (3a)+(3b) 相容  ⇔  m̂² ≥ (N/4)e^{−2Q}  ⇔  Q(∞) ≥ ln[1/(m a)] + ½ln(N/4)   [T]
```

`γ/λ₁` 只留 `a, m, Q` 三个符号即 **(3b) 的 `e^{−2Q}/(ma)`** 与 **(3a) 的 `ma`** 两条；二者不矛盾——(3b) 只是把 (3c) 改写成"`e^{−2Q}` 必须被 `(ma)²` 压制"。

**等号位置**：`γ = λ₁`（即桥取等号）⇔ `½m̂ = 1` ⇔ **`ma = 2`**。这是**截断尺度**，不是标度窗。标度窗里 `ma ≪ 1` ⇒ `γ/λ₁ = ma/2 ≪ 1`：**桥在标度窗内是严格不等式，而且差距正是 `ma`。**

## 5 · 判定与代价

- **不是 (a)**：`(ma)^{−1}` 只出现在**界**里，且它被 (3c) 反解成"`Q` 必须对数发散"——那是**条件**，不是**强度**。把它读成"连续极限判据变强"就是本文要拆的那个误读。
- **是 (b)**：真实比值 `γ/λ₁ = ma/2 → 0`，BD 的常数相对转移矩阵隙按 `a` 幂退化 ⇒ **BD 在 `a` 上无一致下界**。
- **不是 (c)**：`γ` 与 `λ₁` 不同标度；只在 `ma = 2` 一点偶然同标度（截断点），所以"BD 只在有限 `a` 有意义"这句话**方向对、理由要换成 (b)**：不是"同标度所以只在有限 a 有意义"，而是**在有限 a 有意义、`a→0` 按其自身幂次归零**。

## 6 · 路径（下一步该造什么）

1. **`[Q-LOG]`（承重，替换现有 `O-AT`）**：现有缺口写作"`Q(∞)` 的 `(L,a)`-一致有界"（`R1-BRIDGE.md:347`、`AT-STAR.md:321`）。按 (3c)，正确的靶**不是有界**，而是
   ```
   Q(∞; β) ≥ ln[1/(m a)] + ½ln(N/4)  ~  c·β     (β → ∞, 渐近标度)
   ```
   即 `Q` 必须**至少以关联长度对数发散**。有界 `Q` 与 `ma → 0` **互相排斥**。
2. **`[NG]` 现成反证**：`COV-T.md:130` 实测 `Q(∞) = 0.1099`（`L`-无关、`O(1)`），`R3-L4.md:245` 给 `Q ≈ β`-多项式；把任一有界/慢增长读数代进 (3c) ⇒ 只有 `ma ≳ e^{−Q} ≈ 0.90` 时 BD 可能成立。**`β = 2.5`（`ma ≈ 0.8–1.3`，`A4-SCALE-SEP.md`）恰在边界上**——这解释了为什么这条链在格点上"看起来很对"，而 `a→0` 时必假。
3. **`[M]` 若 (1) 证不出**：BD 只能作为**有限 `a` 判据**（(c) 的实用版），此时唯一出路是把 `a^{−1}` **吸收进势**——在 `m̂²`-归一化的 Dirichlet 型上重做 BD（`γ' := γ/m²`），让 (3c) 变成恒等式而非条件。
4. **过酸测**：任何修补必须在自由场 `m̂ → 0` 处**失效**（`γ̂ = m̂² → 0`，而 BD 右端不随之归零 ⇒ (3c) 失败）。BD 现状正是在此处失败（`COV-T.md:238`）——本文件的贡献是把"失败"定量成 **一个幂次 `a`** 而不是一句定性话。
