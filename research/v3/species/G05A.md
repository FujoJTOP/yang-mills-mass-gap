## 1. 从标准公式重推（不引用任何二手式）

### 1.1 系数

```
β(g) = μ dg/dμ = −b₀g³ − b₁g⁵ + O(g⁷)
b₀ = 11N/(48π²) = 0.0232200·N ,   b₁ = 34N²/(3(16π²)²) = 4.54503e−4·N²   [T]
恒等：b₁/(2b₀²) = (34/3)·(9/242) = 51/121 = 0.4214876033…（40 位数值逐 N 复核：N=1..10 同值）
```
`51/121` 的 N-无关性是**纯统一性**的：b₀ 的一圈系数 ∝N、二圈 ∝N²，π/16π² 的幂次在比值里对消。
加费米子后 `b₁` 变、此数变 —— **不是普适常数**，只是"纯 SU(N) 家族内 N-无关"。`[T]`

### 1.2 积分（这一步同时定住指数**与**符号）

```
∫^g dg'/β(g') = (1/b₀)∫ dg'/[g'³(1+(b₁/b₀)g'²)]
              = 1/(2b₀g²) + (b₁/(2b₀²))·ln[g²/(1+(b₁/b₀)g²)] + C        [T]（部分分式）
Λ = μ·exp(−∫)  ⇒  ln(aΛ) = ln(aμ) − 1/(2b₀g²) − (51/121)·ln g² + O(g²)
⇒ aΛ = exp(−1/(2b₀g²))·(b₀g²)^{−51/121}·[1+O(g²)]
     = exp(−12π²β_W/(11N²))·(b₀g²)^{−51/121}·[1+O(g²)]                 [T]
```
> **为什么不能只翻一个符号**：`exp(−1/(2b₀g²))` 的 − 与 `(g²)^{−51/121}` 的 − 是**同一次积分**
> 的两个项（`1/g²` 项与 `ln g²` 项）。任翻其一 ⇒ 该式不再是 `Λ`。这是代数，不是约定。

### 1.3 加号式的来路（`g05` 错在哪，逐字）

```
numerics/REPORT.md:61 逐字：a⁻¹/Λ_lat = F(g²) = exp(8π²/(b₀g²))·(g²/16π²)^{b₁/2b₀²}
   —— 这是 **a⁻¹/Λ**：exp 取 +、幂次也取 +，**自洽且正确**（8π²/(b₀g²)=1/(2b₀g²) @SU(3)）。
g05 §1.2:73 把它抄成 aΛ = exp(−1/(2b₀g²))·(g²/16π²)^{+51/121}
   —— 取了 aΛ 方向的 exp(−)，却保留了 a⁻¹/Λ 方向的幂次(+)。**同一式内两支混用** ⇒ 必错。
   量纲/反演核：把 g05 式取倒数，得 a⁻¹Λ⁻¹ = exp(+1/(2b₀g²))(g²/16π²)^{−51/121}，
   与 REPORT 的 F(g²) 差一个 (16π²)^{102/121} 的常数 —— 即"两次都错"，不是"抄反"。
```
⇒ **这不是"口径不同"（不是 (c)）**：加号在本支上不与任何已知 Λ 定义相容。`[T]`

## 2. 两条独立判据（都不依赖 0.748/0.029 这组标定）

### 2.1 RG 不变性残差（代数判据，`[T]`）

```
把 Λ = μ e^{−Φ}，Φ = 1/(2b₀g²) + s·(51/121)ln g²（s=+1 ⇔ 负号前因子；s=−1 ⇔ g05）沿两圈流求
  dlnΛ/dlnμ = 1 − Φ'(g)·β(g)
  s=+1（std  (b₀g²)^{−51/121}）：残差 = +(b₁/b₀)²g⁴ = O(g⁴)   ← 正是两圈解应有的三圈余项
  s=−1（g05  (g²/16π²)^{+51/121}）：残差 = −2(b₁/b₀)g² − (b₁/b₀)²g⁴ = O(g²)  ← 与一圈项同阶
数值（N=3, g²=0.5）：std +8.6e−4 ；g05 −5.96e−2（逐位与闭式相符，`g05a_prefactor.log:38–46`）
```
⇒ **加号式在两圈阶就不是不变量**（相对漂移 6%/e-fold）。它不可能是一个 `Λ`。`[T]`

### 2.2 数值积分两圈 ODE（`[E]`，独立于 2.1）

```
RK4 解 dg/dt = β(g)（N=3），把 Λ 沿流取值：
  g:1.0→0.3（lnμ 跨度 71.6）：std max/min = 1.0221 ；g05 = 7.415
  g:1.0→0.1（lnμ 跨度 708.7）：std max/min = 1.0241 ；g05 = 46.75
```
