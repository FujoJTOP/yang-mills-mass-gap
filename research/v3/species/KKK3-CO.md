## §1 `(CO)` 的逐字陈述与缺的常数

**1.1 逐字（`LL3:48`）**：记 `past` = 除 `e` 外已揭示的 link 组态，
> `∃c ∀e ∀past ∀u,u′: |E_μ[X_B|past,U_e=u] − E_μ[X_B|past,U_e=u′]| ≤ c/N_B`

**1.2 缺的 5 处（补全后记作 `(CO*)`）**：①`c` 与 `a`（即 `N_B`）、`L`、`N`、`β`、`B`、`e`、`past` **全无关**——原文只写 `∃c`，而这一条是唯一有内容的量词（`c=2N_B` 平凡）；②`u,u′∈SU(N)` **全体**（含 `|A_e|→0` 支），测度取 `dU` 归一；③同一行绑定 `X_B=N_B⁻¹Σ_{x∈B}q_x`、`N_B=(b̂/a)⁴`、`b̂` 固定物理、`k=0` 单平面（`LL3:4,26`·`DDD3:2`），否则 `c/N_B` 无意义；④`e` 的范围**可缩到** `e∈Lk(B)`：`X_B` 只依赖块内 `≤4N_B` 条 link ⇒ `e∉Lk(B)` 的鞅差恒 `0`，原文写 `∀e∈E` 是宽了（约束从 `~4(L/a)⁴` 降到 `≤4N_B`）；⑤与靶对接的常数（见 1.4）。

**1.3 内容一句话（`[T]`）**：`β=0` 时（乘积 Haar）`E[q_x|past,U_e=·]` 只经 `≤2` 个块内 plaquette 依赖 `u`，每条 `q∈[0,2]` ⇒ `osc_u ≤ 4/N_B`、且**与 `past` 无关**。`(CO*)` = 「把 `β=0` 的这个 `c=4` 与 past-无关性保到 `β=2.5`，允许 `c` 变大，只不许它依赖 `a`」。故 `(CO*)` 的全部张力是那个**差额 `c(β)−4`**。

**1.4 常数账收紧（`[T]`）**：`Δ_e=E[X_B|F_e]−E[X_B|F_{e−1}]` 是中心化的 `u`-函数，`|Δ_e| ≤ ½osc_u ≤ c/(2N_B)`；鞅差正交 ⟹ `Var(X_B)=Σ_{e∈Lk(B)}E[Δ_e²] ≤ 4N_B·(c/2N_B)² = c²/N_B`。⇒ **`σ_B²=c²/N_B`、`C=c²`**（`LL3:48` 走 Azuma 得 `4c²`，多出 4 倍；指数形仍由 Azuma 保住，常数只需换掉）。**两算一致校验**：`β=0` 时 `c=4`；同点用 Efron–Stein 直接算 `Var(X_B)≤4N_B·(2/N_B)²=16/N_B`，而 `c²=16` ✓。

## §2 三路

**2.1 (a) vMF 显式 mgf —— `[NG]`；给出精确归约。** 已给：`μ(dU_e|rest) ∝ e^{(β/N)Re tr(U_eA_e)}dU_e`、`|tilt|≤6β=15`（`NN1:45`）。这一层只控 `osc_{U_e}(X_B)≤4/N_B`，即 1.3 的 `β=0` 行；`(CO*)` 要的是**反贝叶斯方向**：钉住 `U_e` 后其余 link 的律（`LL3:52` 的步 1 也是这个方向）。两者只差一个显式似然比：`w:=(β/N)[Re tr(uA_e)−Re tr(u′A_e)]`、`|w|≤12β=30`，且
`E_μ[X|past,u]−E_μ[X|past,u′] = Cov_{μ_{u′}}(X,e^w)/E_{μ_{u′}}[e^w]`（精确，无窗）。
⇒ `(CO*)` ⟺ `Σ_{x∈B}|Cov_{μ_u}(q_x,e^w)| ≤ c·e^{O(β)}`：常数 `e^{12β}` 进 `c` 合法（只要 `a`-无关），**缺口只剩「对钉扎测度一致的聚簇」**（`H1` 的「一致」版）。vMF 作**取证机构**另已判天花板（`NN1:0.6`：`k_max·v/N_B→0`）。下一手：把这条归约写成 `(CO*)` 的等价叙述，不在 vMF 上找聚合。

**2.2 (b) Dobrushin 系数 —— `[NG]`@2.5。** `α(β)=72β` ⇒ `α(2.5)=180`，阈 `β_Dobr=1/72`，窗 `(0,1/72]` 与 `[2.5,∞)` 不相交（`S6:113,114,130`）。窗内 `α<1` ⇒ DS 完备解析性 + 几何衰减 ⇒ `(CO*)` 取 `c ≤ 4 + C(1−α)^{-4}`（4D 壳数 `(d+1)³` 求和）`[T]`；但靶在窗内已由 LSI/SZZ 给（`LL3:14`）⇒ **不添真**。2.5 处：一步收缩差 180 倍、`q`-percolation 超临界（`S6:156`），迭代无意义。另有一处**对象错位**：`α` 是 sup-over-past 的 **TV** 系数（不分符号、且按邻域求和），`(CO*)` 要的是块内 `≤4N_B` 条 link 的**有号**响应 `ℓ¹` 和——更细。下一手：不投 `α`，只把它当窗内 `(CO*)` 的证书。

**2.3 (c) `ℓ¹` 影响 —— `[NG]`。** 逐字同一件事：`(CO*)` ⟺ `sup_e Σ_{x∈B}|C(e,x)| ≤ c`，其中 `C(e,x)` 是单 link 钉扎响应（`LL3:40` 的 `(1/N_B)Σ_x|C(e,x)|` 乘 `N_B`）。这就是仓内 ⑤「窗内 `ℓ¹`」（`CCC5:40`·`DDD3:58`·`HZF-COV:65`·`HZH-ZLAST:27`），2.5 未付；`II5:14` 把它换名成 `χ_q<∞`（谱隙/`H1`），并证明该换名不产新输入。绝对值堵死正性工具：`C_q≥0`/RP 只给**下界**（`HZF-ZUB2:63`·`NN4:77`）。一处必须标注的退化：`II6:49` 指出在 `C_q≥0` 的 OS 类里 `|O_B|=O_B`，故「绝对值强于有号」在**两点和**上会消失；`(CO*)` 的绝对值在**钉扎响应**上、符号未定 ⇒ 该退化不适用，仍严格强于有号靶。下一手：凡引 `(CO*)`，ℓ¹ 形与有号形并列写。

**2.4 三路汇合（`[NG]`：非独立）。** (a) 的缺口是「对钉扎测度一致的聚簇」；(b) 的窗内正是它的一个充分条件（`α<1`）；(c) 的 `χ_q<∞` 是同一物在两点相关坐标下的名字。⇒ 三路**共一个断口**，是一张墙的三个坐标，不是三张独立的墙。下一手：台账把 0.4–0.6 并成一行，注明共用断口。
