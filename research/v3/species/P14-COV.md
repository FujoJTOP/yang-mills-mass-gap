## 3. 符号的结构论证

### 3.1 `[T]` 宇称：两个均值精确为零，`Cov = E[G Φ']`

`SU(2)` 里 `½ReTr(U_0U_1U_2^{-1}U_3^{-1})` 写成四元数就是标量积 `⟨q_0q_1, q_2q_3⟩_{R⁴}`，
它对全链反转 `q_l→q̄_l`（即 `x→−x`）不变；`Φ` 是径向的 ⇒ `V` 偶。约束面 `{⟨v,X⟩=0}`、定义域都是偶集。
`G_v=d_vS_W`、`Φ'=d_vΦ` 都是偶函数的沿固定方向导数 ⇒ **奇**。
故（未截断、精确，与采样无关）

```
E[G_v] = E[Φ'] = 0 ,   Cov(G_v,Φ') = E[G_v Φ'] .
```

意义：`o27` 表格里 `E[G+Φ']≈0` 不是巧合，`Cov` 的"均值减除"是恒等式而非修正。

### 3.2 `[T]` 约束湮灭：`Cov` 与 `W_full` 的哪一项对应，以及"同号⇒正协方差"为什么不成立

对应关系（`o27`/`ch05-theorems.tex eq:split`）：
`X = −2Cov(G,Φ')`，`W_full = E[Φ''] − Var(Φ') − 2Cov`，`Var(F)=Var(G)+Var(Φ')+2Cov`。
所以 `Cov` 就是 `W_full` 展开里的**交叉项那一半**（`−2Cov`），符号决定 `Var(F)` 相对 `Var(G)+Var(Φ')` 偏大还是偏小。

用户提的"同号 ⇒ 正协方差"**只有一半对**。逐链写 `c_l := (x_l·v)/r_l ∈[−1,1]`，
径向剖面 `α_l := ∂_{r}S_W > 0`（在 `(0,2π)` 上 `S_W` 随 `r` 单调增）、`β_l := φ'(r_l) > 0`
（`φ'(r)=−cot(r/2)+2/r = r/6+O(r³) >0`）：

```
G_v = Σ_l α_l c_l + (切向残部) ,      Φ' = Σ_l β_l c_l .
```

`α,β>0` 与 `c_l` 同号 ⇒ **同一链、同一 `c_l` 的对角项** `Σ_l E[α_lβ_l c_l²] ≥ 0` 恒正。
但 `mode A` 的成对传送给出 `Σ_l x_l·v = 0` 精确成立，即 `Σ_l r_l c_l = 0`，于是**对任意 `λ,μ`**

```
Σ_l α_l c_l = Σ_l (α_l − λ r_l) c_l ,    Σ_l β_l c_l = Σ_l (β_l − μ r_l) c_l .
```

即：**两个径向剖面里"正比于 `r_l`"的对齐部分被约束精确消去**。取纯对齐模型 `α=λr, β=μr`
（正、同号、完全符合"直觉"）得 `G_v ≡ 0`、`Cov ≡ 0`。
**所以"同号"推不出"正协方差"——同号产生的是方差，不是协方差**；`Cov` 只由残差 `α−λr`、`β−μr` 决定，
而 `α(r)= (β/2) sin(r/2)` 与 `β(r)=−cot(r/2)+2/r` 在小 `r` 都 `∝ r`（`∝` 对齐 ⇒ 被湮灭），
这解释了为什么格点上 `Cov` 只有 `1e-2` 量级。

**定量铁证（`[E]`，精确求积，`o27` Tier 1，`4e6` 点径向积分，误差 `<1e-9`）**：无约束单 plaquette
（无 `Σ r_l c_l=0`）给 `Cov=+0.09606`，`VarG=0.272802`，`VarΦ'=0.034694` ⇒

```
corr_single = +0.987   （几乎完全对齐：同号直觉在"无约束"下几乎精确成立！）
corr_lattice(本页) = +0.008 ± 0.027   （对齐部分被约束吃掉，只剩残差）
```

这条 0.99 → 0.01 的塌缩，就是 `Cov` 符号不设防的机制。判"结构上必然正"——**不成立**。

### 3.3 `[C]` 残差为什么略偏负

格点体的 `r` 分布集中在 `r≈3.06 ∈ (π,2π)`（`o24_L2A.log`：`final r mean=3.059, max=5.657`）。
在该区间：

```
dα/dr = (β/4) cos(r/2) < 0        （α 下降）
φ''(r) = 0.5/sin²(r/2) − 2/r² > 0  （β 上升）
```

同一链路里 `δ_l=α_l−λr_l<0` 而 `ε_l=β_l−μr_l>0`，两者乘同一个 `c_l²` ⇒ 同链对角贡献
`E[δ ε c²] < 0`，即天然给一个**小的负** `Cov`。这与"约束湮灭后残差由径向斜率失配决定"是同一句话。
标注 `[C]`：机制清楚、数值点估计同向（`−0.008`、`o27 −0.021`），但**没有到 3σ**，不作定理。

## 4. 界

| 界 | 值 | 层级 |
|---|---|---|
| Cauchy–Schwarz（无假设，精确） | `|Cov| ≤ σ_G σ_Φ' = 0.296` | [T]，但无内容 |
| 3σ 窗口（主样本 4×1e4，`σ_τ`） | `−0.022 ≤ Cov ≤ +0.027` | [C] |
| 3σ 窗口（8 群合并，`σ_τ`） | `−0.035 ≤ Cov ≤ +0.019` | [C] |
| 作废量级 `c`（取最紧的正则叙述） | **`Cov ≥ −0.035`**（`≳ −0.02` 更贴近） | [C] |

代入 `Var(F)`：

```
2|Cov| / Var(F)  ≤ 2*0.035/1.49 = 4.7%      （主样本点估计只占 0.3%）
2|Cov| / E[Φ'']  ≤ 3.6%
W_full = E[Φ''] − VarΦ' − 2Cov :  实测 1.871 = 1.933 − 0.057 + 0.005
```

**方向判决**：`Cov ≤ 0 ⇒ Var(F) = VarG+VarΦ' − 2|Cov| < VarG+VarΦ'` ⇒ H1（`G''(0)≥0` 的余量）**更容易**；
`Cov ≥ 0` ⇒ 更难。本页点估计在**负侧**，所以"更容易"方向占优 **但未达 3σ**；
即便取 3σ 边界，交叉项对 `Var(F)` 的影响 `≤4.7%`，对 `W_full` 的影响 `≤3.6%` ⇒ **量级上不可能改变判据**。

## 5. 判

* **`o27` 的 `−0.021±0.030`：是"零"，不是"真负"。** 它本身只有 `0.7σ`；本页 8 群 ×(`1e4`+`1e3`)
  把它压到 `−0.008 ± 0.009`，两个独立批次点估计符号相反（`+0.002` / `−0.017`），
  尺度无关值 `corr=−0.029±0.032` 与 `o27` 的 `−0.024` 相容。
  ⇒ 不能把 `−0.02` 当成"真负"，也不能当成"精确零"；**只能给界**。

* **判死线**：
  * (a) `≥3σ` 为正 ⇒ H1 更难 — **不成立**（正方向 3σ 上限 `+0.027`，点估计 `+0.002`，`0.3σ`）。
  * (b) `≥3σ` 为负 ⇒ H1 更容易、`Var(F)` 更小 — **不成立**（负方向 `0.9σ`）。
  * **(c) 与零相容 ⇒ 交叉项可忽略、`W_full ≈ E[Φ'']` — 成立。** `W_full=1.871` vs `E[Φ'']=1.933`，
    差 `3.2%`；`o27` 同口径差 `8%`（`1.134` vs `1.233`）。**主角就是 `E[Φ'']`。**
