## 1. `V_∞`：用 `O20` 的闭式，`o05` 实测对账

`O20`（`w7/o20_varbound.log`）先证**精确缩放恒等式** `Var(f) = β²sin²(θ/2)·Var_B(g)`，`B=βcos(θ/2)`、`g(u)=sin u/(2u)`、`u=r/2`；再证 `Ψ(B) := 36B²Var_B(g) ≤ 1`（网格 `max Ψ = 0.9999865`，单调不减，`1−Ψ ~ B^{−1.017}`，双容差 `1e-11/1e-15` 差 `≤4e-13`）。于是

```
Var ≤ β²s²·Ψ/(36B²) = tan²(θ/2)/36 · Ψ  ≤  tan²(θ/2)/36 =: V_∞(θ)      [P3]
```
**这是上界而非"外推的 sup"**——比 `o05` 的有限 `β` 外推强一档。对账（`[P3]`）：`θ=π/2` 闭式 `1/36` vs `o05` `0.0278`（相对差 `8.0e−4`）；`θ=3π/4` 闭式 `0.1619008` vs `0.1618`（`6.2e−4`）——`o05` 是有限 `β` 值，闭式是 `β→∞` 极限 `[C]`。
本文件独立复算（`o22_threshold.log [CHK]`，复用 `o05_var_scaling.slice_stats`，`n=400001`）在 `β=400` 处给 `Var = 0.027765 / 0.161756`，与闭式一致到 `5e−4`（有限 `β` 欠饱和方向）。

## 3. `‖v‖²` 的归一（`ch05` 核准）：**它在 `β₀` 里约掉**

`ch05-theorems.tex:216–224`（`eq:wgeo-quant` 逐字）：
> `λ(v) = inf_ξ⟨v,HessΦ(ξ)v⟩ ≥ (N/12)‖v‖²` … “The mode enters only through `‖v‖²`, so an `L`-link average gives `‖v‖²=1/L`, i.e. `c=(N/12)/L`”

⇒ `ch05` **没有**把 H1 陈述成 `‖v‖=1`；H1 的底与 `V_∞` 都随 `‖v‖²` 走。而

- `Var(⟨v,∇S⟩|0)`：`∇S` 对 `v` 线性 ⇒ 方差**二次齐次**；
- `E[H_vv|0]=E[⟨v,Hess V v⟩|0]`：**二次齐次**；
- 条件切片 `{⟨v,ξ⟩=0}` 只依赖 `v` 的**方向**、与 `‖v‖` 无关；

⇒ 两侧同时 `∝‖v‖²`，**`β₀ = V̂_∞/c` 与 `‖v‖²` 无关**（`[T]`，由 `eq:split` 的齐次性）。`o05`/`O21` 都取 `v=e₃`（`‖v‖=1`，且 `O21` 的 `c` 定义里已显式除以 `‖v‖²`），故 `V̂_∞ = V_∞`、`‖v‖²=1`。
**`L`-归一同样不影响**：`‖v‖²=1/L` 时 `V_∞ → V_∞/L`、`c → c_∞/L`，比值不变。
⇒ 任务问的"归一化是什么"的答案是：**不需要选；它在阈值里约掉**。`L` 若要真进入，只能通过"粗模形状改变 `V̂_∞`"——而本文的 `V̂_∞` 是**单 plaquette** 值（§6 窗口 1）。
（`§11.63` 记的 "`gpp` 缺 `‖v‖⁻⁴` 因子" 属恒等式书写层面，本文不依赖 `gpp` 的写法，只用 `eq:split` + 齐次性。）

## 5. `θ=π`：`β₀=+∞` 不是"策略没用"，是**前提塌**

```
θ=π:  V_∞ = +∞（Var = β²·0.0110593, β=2.5/6/200 三位不变）;  c_∞ = cos(π/2)/4 = 0
      E[H] ≡ 0（H_vv = βcos(θ/2)sin(r/2)/(2r)，cos(θ/2)=0，逐点 [T]）;  E[Φ''] = 0.2051153
      ⇒ H1A 的精确反例点 β* = sqrt(0.2051153/0.0110593) = 4.30661
```
策略第二条假设是 `E[H+Φ''] ≥ cβ‖v‖²`；该格 `c_∞ = 0`、`E[H]≡0`，**假设本身假**，`β₀` 无从定义。这与 `H1A-EXACT` 的"`θ=π` 上 `β>4.30661` 时 H1 以 `δ<0` 成立"是同一件事，**是 `cos(θ/2)=0` 的零测退化切片，不是阈值大小的问题**。
