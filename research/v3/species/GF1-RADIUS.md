## §0 判词（七条）

> ### ① `F(t)` 不是级数，是**多仿射（squarefree）多项式**；"半径"只在把它投影成单变量后才存在，而两个投影给出**两个不同的半径**。
> 逐字定义（`GI1-COUNTING.md:179`）：
> ```
> F(t) := Σ_{S ⊇ {p₀,p_t}} (−1)^{|S|−1} N(G_S) ∏_{p∈S} w_p          （= Theorem A，GI1:16,93）
> ```
> 它只在环 `w_p²=0` 里等于 `∂²_{J₀J_t}log Z`（`GI1:148`）；在公共 `w` 处**不等于**解析的 `C(t)`（**Theorem E**，`GI1:169–173`）。所以"`F(t)` 的收敛半径"这句话本身没有唯一所指 —— 必须先指定投影。

> ### ② 时间投影给**等式**，但它把定义抄了一遍：`R_t = e^{a m₁}`，`[T]`。
> `Φ_L(z) := Σ_{t≥0} C_L(t) z^t`，由 KL 谱表示 `C_L(t)=Σ_n f_n²e^{−E_n t}`（`P3-CYLINDER-RESIDUE.md:67`）得
> ```
> Φ_L(z) = Σ_n f_n² / (1 − e^{−E_n}z)  ⇒  R_t = e^{a·m₁,L}      （m₁ = inf supp ν，P3:73,108）
> ⇒ m = (1/a)·log R_t          （等式，[T]）
> ⇒ m ≠ (1/a)·log(1/R_t)       （R_t > 1；题面的 log(1/R) 只有把变量换成 ζ=1/z 才对）
> ```
> 但 `Φ_L` 的系数是 `C(t)` 本身，**一个 `N(G_S)` 都不出现** ⇒ 这条等式对"计数化"零信息，它就是 `lim_t` 换了个写法。

> ### ③ 计数投影给的是**活度平面的边界**，不是能量平面的极点：`[NG]`，且是定量排除的。
> 计数投影的系数是**壳质量**（求和泛函，不是逐簇上确界 —— 这一点语料已判，`GV1-LAMBDAUR.md:52`）：
> ```
> c_n(t) = Σ_{|Γ|=n, Γ∋{p₀,p_t}} φ^U(Γ) ,   |c_n| ≤ A_n := Σ_{|Γ|=n, p₀∈Γ}|μ|   （GV1:63）
> A_n = 1, 20, 514, 14748, 450255, 14305816    （GV1:92–99，n≤6 精确整数）
> ⇒ 1/R_act ≥ A_6^{1/6} = 15.580645 ,  且 1/R_act ≤ 53.000687   （GV1:16，严谨夹逼）
> ⇒ log(1/R_act) ∈ [2.74603, 3.97030] ,   m = 1.707 在区间之外（低 1.61×–2.33×）
> ```
> 逐簇读数（题面给的 `2.5766`）只给 `log(1/R)=0.94645`，在 `m` **下方** `1.804×`。⇒ **两个读数把 `m` 夹在 `(0.94645, 2.74603)` 里，两个端点都不是 `m`。**

> ### ④ 判词：**`m` 不能由计数增长率直接给出 —— `[NG]`**（四条互相独立的死因，§2）。
> - **半径错配（精确反例，`[T]`）**：2 片相邻 plaquette 上，计数级数 `−w²` 的半径 `=∞`，解析级数 `−w²/(1+2w)²` 的半径 `=1/2`（`GI1:172`）。**两个半径差一个无穷大**，所以"半径由计数给出"在最小模型上已是伪命题。

## §2 Cauchy–Hadamard 判定（核心）

### 2.1 把问法写准

题面问：`R` 能否由 `{N(G_Γ)}` 沿簇形状的增长给出（`1/R = limsup|c_n|^{1/n}`）？三条必须钉死：

1. **哪条序列**：不是 `{|φ^U(Γ)|}`，也不是 `{N(G_Γ)}` 本身，而是**固定 `t` 的系数的和** `c_n(t) = Σ_{|Γ|=n,Γ∋{p₀,p_t}}φ^U(Γ)`。`{N}` 只给**单项**。
2. **哪个方向**：`R_ζ` 是"增长率的倒数"，`m = −log(增长率)`；要的是 `1/R = limsup`，而 `m` 是 `−lim(1/t)log`。**两个 `lim` 的变量不同**（`n` vs `t`）。
3. **哪个奇点**：半径 = 复平面上**最近奇点**的模。`m` 是**固定活度**下 `t`-方向的指数率。这是**同一函数的两个方向**上的两个不同奇点。

### 2.2 杀 1（结构）：半径错配 —— 最小反例已是 `[T]`

**陈述**：2 片相邻 plaquette，`Z = 1+w₀+w₁`。则
```
计数（squarefree）级数:   S(w) = Σ_S μ(G_S)w^{|S|} = −w²          ⇒ R_S = ∞
解析对象:                 C(w) = −w₀w₁/Z² |_{w₀=w₁=w} = −w²/(1+2w)² ⇒ R_C = 1/2
```
（`GI1:172` 逐字给这条反例，含 `1/(1+2w)² = 1−4w+12w²−32w³+…` 的机验。）

⇒ **两个半径一个 `∞` 一个 `1/2`**。这不是数值差距，是**对象不同**：`N` 决定的是 `log Z` 的 **squarefree 部分**（`GI1:148`），而半径由 `Z` 的**零点**（Yang–Lee 边）决定，后者不是前者的函数。`[T]`

### 2.3 杀 2（刚性）：`R` 是纯数，`m` 是 `β` 的函数

```
c_Γ = μ(G_Γ)（u-无关）                                     GV1:63
⇒ R_act 只依赖 plaquette 邻接图的组合，与 β 无关
m(β=2.5) = 1.707（RUN3:51） ;  m(β=10) = 5.9×10⁻³（B04:98） ⇒ 比值 289×
```
⇒ 任何 `m = f(R_act)` 都必须让 `f` 是常函数，而 `m` 非常数。⇒ **不存在这样的 `f`**。`[T]`
（这条是 `GI1:177` 的 (C1) β-刚性在**半径层**的翻版：那里杀的是"求值"，这里杀的是"半径"。）

### 2.4 杀 3（定量）：区间 `[2.746, 3.970]` 与 `1.707` 不相交

用**正确**的系数（壳质量，`GV1:52` 已判"半径是求和泛函"）：

```
[E] A_6 = 14 305 816（精确整数，三套独立代码）        GV1:14,99
    ⇒ 1/R_act ≥ 15.580645
[T] 上界 53.000687（τ-包络 ⇒ 嵌入树计数）             GV1:16
⇒ log(1/R_act) ∈ [2.74603, 3.97030]                   （log 15.580645 = 2.74603，log 53.000687 = 3.97030）
m = 1.707 ⇒ m / log(1/R_act) ∈ [0.430, 0.622] ⇒ m 比它低 1.61×–2.33×
点估计 λ_Ur ≈ 30 ⇒ log = 3.40120 ⇒ 低 1.992×
```
**这个区间对 `n` 的改进是单调封闭的**：`n=6` 已给下界，`n` 再大只能推高（`GV1:126` 逐字"不会翻回 `1.6` 以下"）。⇒ 不存在"算得更大就能对上 `m`"的数。`[T]`+`[C]`+`[E]`

对照**逐簇**读数（题面 `2.5766`）：`log(1/R)=0.94645`，比 `m` **低** `1.804×`。⇒ 两种读数把 `m` 夹在中间，**两端都不是 `m`**。

### 2.5 杀 4（定义域）：靶点在收敛圆盘之外

```
λ_Ur·u ∈ [9.738, 33.125]（u=0.625）        GV1:145（严谨夹逼）
判据"绝对收敛"要求 λ_Ur·u < 1               GU4:161/UR6:190–196（经 GV1:3 转引）
⇒ β=2.5 处超判据 9.7×–33×
```
⇒ 在 `β=2.5` 上，"半径"这一概念所描述的是**发散边界**，`m` 住在圆盘外的极点上。**用一个圆盘的边界去读盘外极点的位置**，这是这条路的结构性错位。`[T]`

### 2.6 卡在哪 —— 逐条回答题面的三个候选

| 题面的猜测 | 判定 | 依据 |
|---|---|---|
| **系数不是 `N` 本身** | **对，而且更糟** | 不只是"系数是 `Σ_S μ`"：`F` 是 squarefree 投影，解析对象的系数含**重复变量项**（`GI1:90`）。2 片反例：`C` 的 `w³` 系数 `4`，squarefree 给 `0`（`GI1:172`）。⇒ 连"系数 = 求和"都不成立，要先补重复变量项 |
| **求和含 `w^{\|S\|}` 因子** | **对，且这正是 `β` 的唯一入口** | `R_act` 的 `β`-依赖全在 `w=w(β)` 这个因子；计数部分是纯常数（`GV1:63`）。⇒ 半径的"内容"是**活度**，不是质量。§2.3 |
| **`t` 与簇体积不同步** | **不成立（这条不是障碍）** | 沿管族 `n = 4T = 4t` **完全同步**（`GI1:135`；`N_T` 是 `4T` 片上的计数）。同步了也救不回来（`0.94645` vs `1.707`）。⇒ 障碍不在同步性 |

**⇒ 真正的卡点（一句话）**：新问法把 `lim_t` 换成了 `limsup_n`，**但换的是另一条序列的 `lim`**。两个 `lim` 不交换、也不相等：一个是"固定活度、时间方向的指数率"，一个是"固定时间、簇体积方向的系数增长率"。前者是 `m`，后者是**聚合物临界活度**。

### 2.7 存活的两件东西（必须同写，否则上面四条会被读成"计数一无用处"）

1. **`[T]` 时间级数的半径等式**：`m = (1/a)log R_t`，`R_t = e^{am₁}`。**完全绕过 `a→0`**（不需要连续极限，只要固定 `L` 的紧 `T_L`），但**系数是 `C(t)`** ⇒ 不是"计数"，是"把 `m` 的定义抄了一遍"。它的价值在**口径**：它证明"半径 ↔ `m`"这条通道**存在且精确**，只是通道入口要的是**关联函数**，不是**计数**。
2. **`[T]/[C]` 强耦合窗内的计数指数**：`m₁ = 4·ln(1/u)/a + O(u/a)`（`P3:112,116`），`4` = 每层 4 壁。**这是语料里唯一真正"由计数给出 `m` 的某个东西"的陈述**，给的是 `ln(1/u)` 的系数。
