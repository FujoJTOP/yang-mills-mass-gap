## §1 精确 Haar（任务 1 前半）

### 1.1 闭式与求积 `[T]`

Haar 下 `U = cos θ + i sin θ n̂·σ`，`p(θ) = (2/π) sin²θ`（`θ∈[0,π)`）。主对数分支 `ξ = 2θ n̂`，`|ξ|∈[0,2π)`：

```
⟨θ²⟩_Haar = (2/π)∫₀^π θ² sin²θ dθ = π²/3 − 1/2 = 2.789868133696453
s²  := (1/3)⟨|ξ|²⟩ = (4/3)⟨θ²⟩ = (4π²−6)/9 = 3.719824178261937
1/s² = 0.268829910
```

求积与闭式差 `4.4e−16`。**分支不是一个旋钮**：若取 `ξ = θ n̂`（即 `|ξ|∈[0,π)`），同一个 Haar 测度给 `0.929956 = s²/4`。语料 `GY3-NOGAP-NUM.md:33` 已经钉死用 `|ξ|∈[0,2π)`；本轮把**估计量自己的** `C.su2_log_x` 喂进确定性的 Haar 张量求积（θ 400 点 × `cosθ_s` 60 点 × φ 60 点，无 MC），得 `(1/3)⟨|x|²⟩ = 3.71982`、`max|x| = 6.283 = 2π` —— **与闭式 `3.719824178` 逐位对到 6 位** ⇒ 代码、语料、本轮三处同一分支，且估计量取的正是 `|ξ|∈[0,2π)`。

### 1.2 定理：未固定（flat）测度的单 link 边缘恰为 Haar `[T]`

```
dμ(U) = Π_l dU_l · e^{−S(U)} / Z ,   S 规范不变，dU_l = Haar
取任一格点 x，令 G∈SU(2) 作用为  U_{x,μ} → G U_{x,μ},  U_{x−μ,μ} → U_{x−μ,μ} G†
（其余 link 不动）。这是位形空间的**双射**、Jacobi = 1、S 不变。
⇒ 边缘 m(U_l) = ∫ Π_{l'≠l} dU_{l'} e^{−S}/Z 满足  m(G U_l) = m(U_l)  ∀G。
⇒ m 左不变 ⇒ 紧群上的左不变概率密度 = Haar。      `[T]`
```

实际用到的假设只有三条：**(i)** 作用量规范不变；**(ii)** 逐 link 的 Haar 测度；**(iii) 不做任何依赖规范的 conditioning**（不固定规范、不按中心/Polyakov 扇区分块）。M1/GY3/WG 的 flat-chart 采样全部满足（`GY3-NOGAP-NUM.md:111` 明写"无 Landau/Gribov"）。

### 1.3 五条推论 `[T]`

- **(B1)** `(1/3)E|ξ_l|² = s² = 3.719824`，**对每个 β、每个 L、每个维数、每个 N**。
- **(B2)** `E[χ_flat] = (1/3N)Σ_{l,l'}⟨ξ_l·ξ_l'⟩ = s² + Δ`，`Δ := (1/3N)Σ_{l≠l'}⟨ξ_l·ξ_l'⟩`。**`Δ` 是唯一能带 β 的项。**
- **(B3)** `β=0`：link iid ⇒ `Δ ≡ 0` ⇒ `χ_flat = 3.719824` 逐位、任意 `L`（语料独立得到，`D6-DECISION.md:135`、`Q6-H1-STATUS.md:177`、`R5-EXACT-ANCHORS.md:46-49`）。
- **(B4)** 与维数无关 ⇒ **2D/3D 同值**（§4·F3 用它当酸测）。
- **(B5)** **plaquette 不受 (B1) 约束**：它是 4-link 关联量，可以在单 link 边缘恒定的同时动 `5.30×`。⇒ **"用 plaq 反推单链路分布"在 flat chart 里原理上不成立**（回答任务 1 的第二问，见 §2.2）。

定理与群无关。存档的 `witness_L4_b{2.2,3.0,6.0}.npz`（各 1024 link，未固定规范）上：

## §2 预期 β-依赖（任务 1 后半 + 任务 2）

### 2.1 正确答案是 **0**，不是"某个大于 0.20 的量" `[T]`

任务给的路子是"`ξ` 的逐 link 方差 × 独立性和"。按 §1.2，**能用的那个逐 link 方差就是 Haar 边缘的方差，它在 β 上是常数**。所以：

```
β → 0（Haar，iid）：Var(a) = (1/N)Σ_l Var(ξ_l) = s² = 3.719824     （任意 L，精确）
β = 0.5 / 1.5 / 2.5：E[χ_flat] = s² + Δ(β,L)，Δ 由数据限制在 |Δ| ≲ 0.10
```

⇒ **理论预期不是"变化 > 0.20"，而是"变化 = 0"**。任务判据（">0.20 预期、实测 ±0.03 ⇒ 被β-无关常数支配"）**成立，且被加强**：常数不是"淹没信号"，常数**就是**首项；信号（`Δ`）是 `O(1/N)` 级的关联修正。

**实测 `Δ`（逐 β）**：`−0.071±0.066`（0.5）/ `−0.035±0.064`（1.5）/ `+0.029±0.055`（2.5）。三个都兼容 0，无单调趋势。

**不是 bug 的旁证** `[T]`：同一批采样的 plaquette 单值 `⟨½tr U_p⟩` 与强耦合领头阶 `u = β/4` 对得上（`0.1234 vs 0.125`、`0.3619 vs 0.375`、`0.6547 vs 0.625`；β=0.5/1.5/2.5），即作用量密度 `1−⟨½tr⟩` 对 `1−β/4`（`0.8766 vs 0.875`、`0.6381 vs 0.625`、`0.3453 vs 0.375`）⇒ **联合测度是物理的**，被冻住的是边缘。两者同时成立，正是定理的内容。

### 2.2 为什么"用 plaq 估计单链路分布"这条建议在本通道内不可执行 `[T]`

`plaq = ⟨½Re tr U_p⟩` 是 4 个 **相互关联** 的 link 的联合泛函；`(B1)` 只钉住 1-link 边缘。二者可以任意解耦：本数据里 `plaq` 动 `5.30×` 而边缘恒定。所以"用 plaq 校准一个单链刚度，再乘独立性"得到的是**另一个模型的对象**（把 link 当 iid 指数族），不是 `χ_flat`。**这个模型被数据否掉**：它要求读数随刚度至少动 `0.61`（相对量，`1−plaq` 的幅度），而数据 2σ 只允许 `0.073` ⇒ 差 **8.3×**。
