## §1 判据、结论摘要、以及"承重步"的定义

### 1.1 什么叫"承载隙的那一步"

一条"给出隙"的证明链一律可以切成三段：

```
  (M) 测度/表示       →   (L) 承重不等式（给出正的、与 (L,a) 无关的数）   →   (S) KL/谱 ⇒ 隙
```

**(L) 是承重步**，判据有两条，缺一不算：

- **(A1) 可删性**：把 (L) 删掉，链条断（其余两步单独不给任何正数）。
- **(A2) 自由场失效**：把 (L) 用在自由无质量场上，它必须失效（`f₁²=0` 或 `λ=0`）。
  这是项目宪章的酸测（`CLAUDE.md §1`）；只满足 (A1) 不满足 (A2) 的，是重述不是机制。

另有一条**本项目特有**的判据，必须写死：

- **(A3) 对象一致**：Clay 的"隙"只要求谱有下界；本项目的 H1 要的是
  `f₁² = |⟨0|tr F²|G⟩|² > 0` **加**隔离 `ρ=m_{0⁺⁺*}/m_{0⁺⁺}>1`。
  两者不同。**一个只在"别的算子"上给出隙的机制，不算把 H1 解决**（见 §2.1 的 2D 反例：
  2D 有面律、有弦谱，而 `f₁²(tr F²)=0` **精确**）。

### 1.2 结论（先写在这里，细节在后四节）

1. **[T]+[J] 四类共性里只有三类真的承载过质量**：C1 精确可积/有限维转移算子、
   C2 半经典缺陷气体、C3 反射正性 + 团簇展开。**C4（表示论⇒离散谱）没有在任何维度承载过"4D 型质量"**，
   它只承载**标签**（N-ality / 中心荷 / 超选扇区）与**离散性**；2D 里它与 C1 重合，
   而那次重合给出的也不是局部质量（§2.1）。⇒ 有效类数 **4 → 3**。
2. **[T] 2D YM 不是"隙模板"，是"禁闭而无原子"模板**：2D 无横向自由度 ⇒ 转移算子就是紧群上的热核
   ⇒ 谱 = Casimir 谱（C1/C4），**但有限体积的能级间距由 `L` 定、无穷体积没有局部有质量粒子**；
   而 `tr F² = H` 守恒 ⇒ `f₁²=0` 精确。
   **2D YM 因此给的是"面律 + 零原子"，不是"4D 型隙"**（与 `T5 §5.3` 一致，并把它加强一格：
   它使"`σ>0` ⇒ 局部质量"变成**空真**——`σ>0` 精确成立，而局部谱是空的）。
3. **[NG] C2 在 4D 是定性缺失，而且是四重定性缺失**：无半经典有限作用量单极子（纯 YM 无 Higgs）、
   非阿贝尔情形对偶面权 **Weingarten 带号**（无正测度/FKG）、无规范不变的局域缺陷（Singer/Elitzur）、

4. **[O] C3 是唯一"形似量的不足"的类**：定理在 4D **确实成立**（OS/SZZ，`β<1/48`，与 N 无关），

## §2 T1 逐案：链条 / 承重步 / 用到的定理 / 4D 是否成立 / 弱化后够不够

### 2.1 2D 纯 YM（Migdal 精确解；Casimir 谱）——**反例样本，不是机制样本**

**链条 [T-standard]**

1. 2D 无横向极化 ⇒ 格点上每个 plaquette 独立，`Z` 是群上的热核之积；Migdal 求和给出
   全部 Wilson 圈的闭式（character 展开 + 正交性）。
2. 转移算子 **就是** `L²(G)` 上的 Laplacian（空间切片上只剩一个 holonomy）；Peter–Weyl 给
   `L²(G)=⊕_R End(V_R)`，本征值以 `C₂(R)` 标记、逐项可写。
   **但这是紧空间量子力学的谱：能级随空间周长 `L` 移动，不存在与体积无关的局部质量**
   （2D 没有横向自由度可供"传播"）。
3. 于是"谱可读"；同时 Wilson 圈面积律 `σ_R = g²C₂(R)/2 > 0`（所有 β，Migdal 精确）。
   **面律与"隙"在 2D 是两件不同的事**：`σ>0` 精确成立，而局部谱是空的。

**承重步**：第 2 步——**场空间是有限维的**（每条空间切片只剩一个 holonomy）。
这是"可积"的真正内容：**维数锁定**，不是技巧。

**4D 是否成立**：**否，且是最硬的一种否**。4D 的 Kogut–Sitter 转移算子作用在
`L²(3-切片上的联络空间)` 上，含磁项 `Σ(1−Re tr U_p)`，**不是任何已知算子的热核**；
逐点是无穷维、势非二次。 [T-standard]

**弱化版够不够**：**不够**。把磁项丢掉只剩电项 ⇒ 逐点回到 2D 型热核 ⇒ 那正是强耦合展开，
**它就是 C3**；也就是说 C1 在 4D 的唯一影子是 C3，而 C3 卡在 `β<1/48`（§2.3）。

**A3 检查（关键）**：`tr F² = tr E² = H`，`⟨0|H|R⟩ = E_R δ_{0R} = 0` ⇒ **`f₁²(tr F²)=0` 精确**
（`T5 §5.3` 见证 [B]，Haar 正交性 `1,0,3e-17,...`）。所以：
**2D 有面律、有离散的 Casimir/弦谱、却没有 `tr F²` 原子**。任何把 2D 当模板的路线，
即使"搬过来"，拿到的也是**另一个算子**的隙。

### 2.2 3D 紧致 `U(1)`（Polyakov 单极子等离子体）——**唯一"干净"的缺陷气体样本**

**链条 [T-standard]**

1. 3D 紧致 `U(1)` 的 `A_μ` 对偶到 3D 标量（Poisson 对偶）；拓扑缺陷 = 单极子世界线，
   其对偶像 = 稀薄 Coulomb 气体（Polyakov 1977）。
2. 单极子有**有限作用量** `S_mon ∝ 1/g²` ⇒ Boltzmann 因子 `ζ = e^{−S_mon} ≪ 1`（弱耦合）⇒ **稀薄**。
3. Debye 屏蔽：气体对无质量对偶光子给 `m_D ∝ ζ^{1/2} > 0`（Debye–Hückel / 环图求和）。
4. `m_D>0` ⇒ 谱隙；荷的禁闭同时给 `σ_{3D} ∝ m_D g²`。

**承重步**：第 2 步——**半经典缺陷 + 作用量压制**。第 3 步是标准等离子体，不含秘密；
秘密全在"`ζ` 小"。

**4D 是否成立**：**否**，三条独立理由（每条单独致命）：
(i) 纯 YM **没有**有限作用量单极子（无 Higgs 无 't Hooft–Polyakov 解；瞬子有有限作用量但是 4D **事件**、
无长程 Coulomb 相互作用，不给屏蔽质量）；
(ii) 中心涡旋是**面**不是点，且 `Z(N)` 相位对 N-ality-0 的局域算子**精确为 1**（`T5` Lemma CV-1 [T]）；
(iii) 非阿贝尔对偶（面）权是 **Weingarten 带号** ⇒ 无正 Gibbs 测度 / 无 FKG（`PROOF-RANDOM-CLUSTER` [T-standard]）。

**弱化版够不够**：**不够**。唯一现成的弱化是 abelian projection（MCG 后的 `U(1)²` 单极子）：
它给得出**荷道**的 `√σ`，但对中性 `tr F²` 恰好盲（CV-1），而且它的密度是 UV 噪声（§4.2）。

### 2.3 4D `Z_N`/`SU(N)` 强耦合（Osterwalder–Seiler / SZZ 聚合物）

**链条 [T]**

1. Wilson 测度在 `β` 小时按连通聚合物（plaquette 簇）展开；活动度 `u(β) → 0`。
2. Kotecký–Preiss / Brydges–Fröhlich–Seiler 判据 ⇒ 展开绝对收敛 ⇒ 指数团簇
   `⟨O(x)O(0)⟩_c ≤ C e^{−m(β)|x|}`，`m(β)>0`。
3. 反射正性（Wilson 作用 [T-standard]）+ OS 重构 ⇒ KL 谱测度支撑在 `[m²,∞)` ⇒ 隙。
4. OS 1978（任意 d，小 β）；SZZ 2023：`β < 1/48`，**与 N 无关、d=4 包含在内**；
   't Hooft 标度下 `λ_0 = 1/(8(d−1)) = 1/24 = 0.0417`。

**承重步**：第 2 步——**小活动度**。这是四类里唯一"前提全是定理、只差一个数"的承重步。

**4D 是否成立**：**成立！**（这是本报告最重要的一条正面事实）
`d=4` 明确在定理范围内。**缺的不是定理，是 regime**：
物理点 `λ = g²N = 2N²/β = 3.2`（β=2.5），`λ_0 = 0.0417` ⇒ **77×**。

**弱化版够不够**：见 §4.4。形式上是"量的不足"（一个活动度不够小），
内容上**不是**——展开是渐近级数，越过半径没有"更强的估计"可用。

### 2.4 2D `CP^{N−1}`（额外样本：**唯一"真局部自由度 + 真隙"的 2D 样本**）

**链条**：`CP^{N−1}` 二维渐近自由；大 N 鞍点（D'Adda–Di Vecchio–Lüscher–Veneziano）给单一 massive
多重态，`m ∝ Λ` **[T-standard, 大 N]**；半经典图像 = **分数瞬子气体**，密度 `∝ e^{−cN}` ⇒ 大 N 稀薄。
`N=2`（`O(3)`）另有 Bethe ansatz 精确 S-矩阵与三粒子谱 `m, m, 2m` **[T-standard]**。

**承重步**：瞬子气体（C2）或精确 S-矩阵（C1）。**两者在 2D 都要求一个"小参数"**：
大 N（`1/N`）或可积性。

**4D 是否成立**：**否**。4D 瞬子**不**给屏蔽（它们是拓扑事件，不是等离子体）；
大 N 在 4D 只给 master field / 闭合的 loop 方程（而 4D 的 Makeenko–Migdal 方程**不闭合**：
需要同一点的全部多点函数）[T-standard]；4D 无可积结构 [J，无人证否]。

**这条样本的价值**：它证明 C2 的"缺陷气体"在 2D **可以**是真的（不是只有 3D U(1) 才成立），
所以 C2 的失败不能归因于"维度太低"，只能归因于 4D 缺那三条（§2.2）。

## §3 T2 共性：四类候选 → 只有三类承载过质量

### 3.1 四类的表述（把承重步单独拎出来）

- **C1 精确可积 ⇒ 谱可读。** 承重步 = **转移算子是已知算子**（紧群热核 / 可对角化），
  谱**逐项可读**。隙 = 第一个非平凡本征值。
- **C2 拓扑缺陷气体 + 稀薄性 ⇒ 屏蔽质量。** 承重步 = **半经典缺陷有 `S∝1/g²` ⇒ `ζ≪1`**；
  气体求和给 `m_D>0`（或涡旋凝聚给 `σ>0`）。要四条前提：
  **(a)** 有限作用量解、**(b)** 稀薄（`ζ≪1`）、**(c)** 正性/符号控制（气体求和可控）、
  **(d)** 局域对象（对偶把缺陷写成局域气体）。
- **C3 反射正性 + 团簇展开 ⇒ 指数衰减。** 承重步 = **小活动度**；展开给与 `(L,a)` 无关的衰减率。
- **C4 表示论 ⇒ 离散谱。** 承重步 = **紧性 ⇒ 谱离散、底是 Casimir**。

### 3.2 分类结论：C4 不承载质量（任何 d），C1 与 C4 在 2D 重合

- 2D：C1 = C4（热核谱就是 Casimir 谱）。**重合 ⇒ 只算一个机制（计给 C1）**。
- 3D：C4 给的是**超选扇区/荷量子化**（`Z_N`、't Hooft 代数），质量由 C2 的气体给。
  ⇒ C4 在 3D **不承重**。
- 4D：中心对称精确，给 N-ality 标签；但 (i) 局域中性扇区**精确盲**（CV-1 [T]），
  (ii) 转移谱**先验不离散**（"有隙"就是要证这个），(iii) 4D 空间切片无紧性论证。
  ⇒ C4 在 4D **只给标签，不给质量**。

**⇒ 真正承载过质量的只有 C1、C2、C3 三类**（且 C1 只在"有限维场空间"这一条上承重）。

**为什么这不是文字游戏（可判定的形式）**：
"量的不足"若要成立，必须存在一条**同一数学**的改进路径，使得把某个常数从 `x` 推到 `x'` 就够。

**结论：定性缺失。**

## §5 T4 最短链与最终判定

### 5.1 最有利读法下的最短链（C3，唯一"形似"的一类）

```

        ↓

        ↓

        ↓
 [T] 一致率 + OS 重构 ⇒ 连续极限的隙（此处还要 G1：连续极限存在）
```

- **缺的那一环**：第 4 行。**类型**：**定理**（一个半径 > 2.5 的收敛展开），**不是估计**。
- **链上还有第二处缺口**：即使第 4 行成立，也只给"隙"，**不给原子**。
  `f₁²>0` 在强耦合是 P3 `[T]`（`β<1/48`，模 `[R]` 的 dressed 重求和），
  把它搬到 2.5 是**第二条独立的缺环**（`T5 §4.1`、`(E-CV)`）。
- ⇒ 这条"最短链"其实有 **2 个具名缺口**，且都不是"常数再紧一点"。

### 5.2 判定

> **2D/3D 的隙机制在 4D 全部定性缺失。** 四类共性（有效三类）在 4D 各缺一条**结构**：
> C1 缺"有限维场空间"、C2 缺"半经典缺陷 + 正测度"、C3 缺"小参数"、C4 缺"紧性"。
> 唯一形似"量的不足"的 C3，其缺口是**收敛半径**（`6u=3.04` vs `1`；`λ/λ_0=77`），
> 而不是**精度**；把常数压回去等价于换相位结构，因此**不构成"无新物种"的逃生口**。

   这三条正是 §4 的三行 `✗/◐` 的**公共内容**——四类共性的失败可以被**一次**命名。
2. **它解释免疫图为什么不是意外**：44 族的死因轴里 `D2 循环 21`、`D1 方向反 11`、`D6 空前提 8`

3. **它把 `D12 无尺度分离` 第一次变成主因**（`LOOP-RUNBOOK §2.1` 记录 D12 计数为 0、列为潜在逃生口）：
