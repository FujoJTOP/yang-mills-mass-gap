## §2 第三坐标：存在、唯一、且就是靶

**2.1 坐标计数（`[T]`）。** 括号由三数 `(f₁²,χ,M₀)` 定，齐次 0 次 ⇒ 只有**一个**不变量 `U₀/L₀ = M₀/f₁² = 1/w₁`；`s₁` 的位置是第二个不变量：

```
s₁ = factor · U₀ ,   factor = s₁χ/M₀ = w₁/w₁^χ ,   w₁^χ = f₁²/(s₁χ) ∈ (0,1]     [T]
⇒ s₁ = (f₁²/χ)/w₁^χ = L₀/w₁^χ    （左半 ⟺ w₁^χ ≤ 1；右半 ⟺ factor ≤ 1）
```

**2.3 所以地板必须由 `w₁` 侧取，且回到靶（`[T]`）。**
