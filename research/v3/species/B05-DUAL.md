## §5 对偶：有**一个**（变换型），没有**对称性型**

### 5.1 变换对偶（存在，`[T]`）

```
C(t) = ∫ e^{−ts} dν(s) ,        ν ≥ 0 ,  C(0) = 1                     (5.1)
t → 0 :  Taylor 系数 = 各阶矩  = 形状                                    [T]
t → ∞ :  inf supp ν = lim −(1/t) log C(t)  = 位置                       [T]（U10 (1.1)；CTL-CLOSEST:232）
```

`ν ↦ C` 单射（Laplace 变换）⇒ **全体**形状数据（所有阶矩 + 增长条件）在原则上定出位置（矩问题唯一性）；但

- **有限阶不行**：`{ν_a}` 在任意**有限**阶上都同（§1）⇒ 截断即盲，且**截断在任意阶都盲**（不只是"6 阶不够"）；
- **逆映射不连续**：thin-gap 把 isolation 从 `9` 打到 `0.01` 而 `(M₀,M₁,M₂)` 不变（`V01-I2S:108` 引 `R2:130–151`，`[NG]`）。

### 5.2 这个对偶**预言**了失败表（本文件的核心解释）

```
形状  = t→0 端的 Taylor 数据（局部、可微、可由 S_W 的短时/弱场展开算出）
位置  = t→∞ 端的指数率（需要"对全 t 一致"的界）
而：  C(t) ≤ C(0)e^{−mt} ∀t   ⟺   inf supp ν ≥ m          （U10 §4，[T]，两行互推）
```

⇒ **从 `C(t)` 一侧拿位置，就等于拿隙本身。** 所以"只能算形状"不是能力问题、不是对偶缺失、不是对称性禁令，而是：

> **截断不对称**：任何有限阶 `t=0` 数据都是 G1-不变的（引理 D1 ⇒ 盲）；位置只活在 `t=∞`，而 `t=∞` 与 `m₁>0` 等价。

这是本路对 60+ 轮失败表唯一**能解释而非仅记录**的机制。

### 5.3 对称性对偶（不存在，`[NG]`）

没有任何酉/场变换把 `τ_a` 实现为对称性（§2）；G2 只给"不变"，而 `inf supp` 本来 G2-不变 ⇒ **G2 既不禁止也不帮助**。⇒ "位置/形状对偶"在对称性意义下**不存在**，别再按这个方向找。

### 5.4 顺带把"能算"降级（`[J]`，与 `FROZEN-POSITION.md` 一致）

## §7 位置轴酸测 + 路径

### 7.1 新增酸测（一行，可一次判死整栏）

> **位置轴酸测**：任何 `m₁` 的候选代理 `Φ`，必须能区分 `ν_a` 与 `ν_{a'}`（**形状恒同、位置差 `a'−a`**）。

- 若 `Φ` 是均值型 ⇒ `Φ ≥ inf supp`，它区分得开 `ν_a`（差 `a`），但**方向恒错** ⇒ 仍不通过。

### 7.2 四模型试金石（CLAUDE.md §2 强制）

### 7.3 路径（诚实，三条都已核过形状）

## §8 判词（正文版，≤ 250 字）

> **反例成立（精确）**：`ν_a = ½δ_a + ½δ_{a+1}`，`Var` 与 `k=2..6` 阶中心矩两列逐字相同（`1/4,0,1/16,0,1/64`），`inf supp` 差 `100`；距离量 `Λ★−m₁² ≡ 1` 也与 `a` 无关。**但题面"只依赖矩的量都漏位置"要改**：一阶原始矩 `1/2` vs `201/2` 恰差 `a` ⇒ **中心矩盲、均值单侧可见**。

> **`E₁`**：`U(x)` 下**不变**（`UHU*=H`）`[T]`；`τ_a` 下**协变**，不变的是**隙** `E₁−E₀`。⇒ (3) 结论对、表述要分群。
