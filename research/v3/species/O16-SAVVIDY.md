## 2. `Hess S_W` 在切片上的精确结构（分解的基）

`S` 只通过 `(ρ,u)` 依赖 `ξ`，用链式法则（含 `∇²u = −(δ_{3a}ξ_b+ξ₃δ_{ab})/ρ³ + 3ξ₃ξ_aξ_b/ρ⁵`）得切片 `{ξ₃=0}`（`u=0`）上

```
H₁₁ = H₂₂ = H₁₂ = H₃₃ = 0          （数值：1.5×10⁻¹⁷）
H_{i3} = M·ρ̂_i ,  M = β[cos h/(2ρ) − sin h/ρ²] ,  i = 1,2
⇒ H = M(ρ̂e₃ᵀ + e₃ρ̂ᵀ)  的本征值 { −|M|, 0, +|M| }，零本征向量 = 方位角 φ̂（`S` 的精确对称）
```
- **`h1e` 的 `|λ|=(β/4)sin(ρ/2)` 是"沿磁轴 `u=±1`"的值；在条件化切片上是另一个 `O(β)` 廓形** `|M|`。两者都 `∝β`，但**不是同一个函数**（`ρ=π` 处切片值 `β/π²`、轴向值 `β/4`）。引用时须带窗口，不能互换。`[T]`
- `⟨λ₋⟩ = −β⟨μ⟩`，`⟨μ⟩ = 0.081337146669`（1D 积分 `∫(sin x−x cos x)sin²x/(4x³)dx / Z`；与 2D 求积的 `⟨λ₋⟩/β` 独立吻合）。`[T]`
- **方位角零模**是精确的（`λ₀ ≤ 2.8×10⁻¹⁷`），因为 `S` 与 `φ` 无关 ⇒ 切片上恒有 1 个零方向。`[T]`
- **注意**：`e₃` 本身**不是**本征向量（`H₃₃=0` 而 `H_{i3}≠0`）；`e₃ = (ê₊ − ê₋)/√2`，故 `e₃` 在简并对里"各占一半"。这正是 50/50 的几何来源。

## 3. 分解结果（`C_k` 精确）

`A_k := c_k g_k`，`g_k := ⟨ê_k,∇S⟩`，`Σ_k A_k = ∂₃S ≡ G` ⇒ `Var = Σ_k C_k`，`C_k := Σ_l Cov(A_k,A_l)`。因切片上 `∇S ∥ e₃`，有 `g_k = c_k G` ⇒ `A_k = c_k²G` ⇒ **`C_k = c_k² Var`**（恒等，不是拟合）。

| β | `Var` | `C₋`（负模） | `C₀`（零模） | `C₊`（正模） | `ΣC_k − Var` | 负模份额 | 正模份额 |
|---|---|---|---|---|---|---|---|
| 0.5 | 0.002764823 | 0.001382412 | 3.2×10⁻³⁵ | 0.001382412 | 3.5×10⁻¹⁸ | 0.500000000 | 0.500000000 |
| **2.5** | **0.069120586** | **0.034560293** | 1.1×10⁻³³ | **0.034560293** | 0.0 | **0.500000000** | **0.500000000** |
| **6.0** | **0.398134576** | **0.199067288** | 4.9×10⁻³³ | **0.199067288** | 4.4×10⁻¹⁶ | **0.500000000** | **0.500000000** |

**误差**：份额不是采样值，是 `c²=(½,0,½)` 的恒等推论；`c²` 的最大偏差 `7.2×10⁻¹⁶`，分解残差 `≤4.4×10⁻¹⁶`。**故"50.00%"的有效位数是 15 位，不是统计误差。**

**同一模内的均值/涨落再分解**（回答"负模贡献会不会是负的"）：`E[G²]/β² = 0.138802169306`，`E[G]²/β² = 0.127742875533`，`V₀/E[G²] = 7.968%`。
即 `−Var = +E[G]² − E[G²]`：负模的**相干斜率** `+0.12774β²` 是朋友，其**二阶矩** `−0.13880β²` 是敌人，净 `−0.01106β²`。**Savvidy 模 92.0% 在自我抵消**，这才是"反直觉"的真正内容：`Var` 小不是因为没有敌人，而是因为敌人在自己内部几乎打平。

## 4. 与 `β` 的关系（问题 4）

`|λ| ∝ β`、`Var ∝ β²`，两者相除：

| 组合 | 值 | β 依赖 |
|---|---|---|
| 负模**份额** `C₋/Var = c₋²` | 0.500000000 | **恒为 ½（精确）** |
| `⟨|λ|⟩/RMS(G) = ⟨μ⟩/√V₀` | 0.773437519 | **常数**（β 无关） |
| `⟨|λ|⟩/Var = ⟨μ⟩/(βV₀)` | `7.354642 / β` | **∝ 1/β** |
| `Var/W₀ = β²/β*²` | 0.3370（β=2.5）/ 1.9410（β=6） | ∝ β² |

**判读**：份额**不随 β 变**（`c²` 是几何量，与 `β` 无关）；变的是**总量** `Var ∝ β²`。而"曲率朋友 : 斜率敌人" = `β⟨μ⟩ : β²V₀` = `⟨μ⟩ : βV₀`，**按 `1/β` 衰减** ⇒ β 越大，负模越"纯粹是敌人"。
**交叉点（可检验预言）**：正模预算 `B₊ = (β⟨μ⟩ − β²V₀)/2` 在
```
β_cross = ⟨μ⟩/V₀ = 0.081337146669 / 0.011059293772974 = 7.354642
```
变号 ⇒ `β<7.355` 正模是净朋友（替负模还债），`β>7.355` 正模也变成敌人。**这是本任务给出的、可被独立路核的一位数**（`[C]`，模型内；未与 `β*` 挂钩）。
