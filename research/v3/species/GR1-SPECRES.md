## §2 最小命题（量词、`ε_a`/`b_a` 的确切定义、等价性判定）

### 2.1 记号与两个不同的 `ε`

固定 `L`（`GL-B:267` 的"阶段 1"）。`Ω` = 真空，`1^⊥ = Ω^⊥`。

```
Δ_a      := inf{ λ ∈ σ(H_a) : λ > 0 } ,      H_a := −(1/a)·log T_a          (GL-B:270)
Δ_cont   := inf{ λ ∈ σ(H)   : λ > 0 }                                      (GL-B:271)

【间隙级 ε（gap level）】一个标量不等式，最优对不唯一：
    ε_a^Δ  := (Δ_a − Δ_cont)_+ / Δ_cont ,      b_a^Δ := (Δ_cont − Δ_a)_+        (D-Δ)
    即：|Δ_a − Δ_cont| = ε_a^Δ·Δ_cont − b_a^Δ（两边恰好抵满）；任何 (ε,b) 满足
    ε ≥ ε_a^Δ、b ≥ max(0, b_a^Δ − (ε−ε_a^Δ)Δ_cont) 都可行 ⇒ **(ε,b) 对不是不变量**。

【形式级 ε（form level，= 仓内唯一被算过的那个）】
    𝔮_a = 𝔮 + 𝔞_a 于公共形式域 Q；ε_a^{form} := sup_{ψ∈Q, ψ⊥Ω} |𝔞_a(ψ)|/𝔮(ψ) ,
    b_a^{form}   := 使 |𝔞_a(ψ)| ≤ ε𝔮(ψ) + b‖ψ‖² 的最小 b（给定 ε）。        (D-form)
    （逐字同 GO2:126 的 (𝔞)、GP9-RB:44 的 (E1)）
```

**桥（`[T]`，`GO2` COST (i)，`GO2:135`）**：`(1−ε_a^{form})Δ_cont − b_a^{form} ≤ Δ_a ≤ (1+ε_a^{form})Δ_cont + b_a^{form}`。⇒ **形式级对 `(ε,b)` 是间隙级的一个可行对**（不是最优对）。这个单向包含是全部混淆的来源：形式级强 ⟹ 间隙级强，反之不然（§4.1 的反向分离，比值 `7e−4…7e−10`）。

### 2.2 三层（量词写全）

```
(A) 有界层   QSPEC-A :  ∃ ε̄ < ∞, b̄ < ∞, a₀ > 0 :  ∀a<a₀,  |Δ_a − Δ_cont| ≤ ε̄·Δ_cont + b̄ .

(C) 幂律层   QSPEC-C :  ∃ C < ∞, k > 0（与 a 无关，由 (正则化, RT, 单位约定) 显式定）:
                        ∀a<a₀,  |Δ_a/Δ_cont − 1| ≤ C·a^k .

- **(C) 里 `Δ_a` 与 `Δ_cont` 必须同单位**：`Δ_a` 是格点单位下的 `−(1/a)log λ₂`，`Δ_cont` 是连续统单位 ⇒ 比较前要选一个标度约定（弦张力 / `Λ` / 质量重整化点）。**这是 (C) 的第二个自由参数**（见 §2.6）。

### 3.1 攻法 (a)：三项逐项给界 —— **T2 的全套（含精确常数）**

#### 3.1.1 Lemma SHELL（`[T]`，乘子微积分，3 行）

> ```
> |𝔟_a(ψ)| ≤ ( (aΛ)²/12 )·(1 + O((aΛ)²))·𝔮(ψ) .
> ```
