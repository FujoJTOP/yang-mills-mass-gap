## 1 · 端点簇分解（精确式）

**1.1 索引量：用"附着支撑"，不是 plaquette 支撑。`[T]`**
设 `𝒞` = 附着于**无限**直管的装饰气体的连通 Ursell 簇集（`log Z_dec=Σ_{Γ∈𝒞}φ^U(Γ)`，`:68`）。对 `Γ∈𝒞` 记

- `att Γ=[i_Γ,j_Γ]⊂ℤ`：`Γ` 中与管共享 link 的聚合物所占时间片区间的**最小–最大**；
- `α(Γ):=j_Γ−i_Γ`：**附着跨度**（片距）。

**限制到有限管 `B_T` 的条件是 `att Γ⊂[0,T]`，不是 `supp Γ⊂[0,T]`** —— 装饰可伸到 `0` 以下或 `T` 以上，只要它的附着点落在 `[0,T]`。**这是本页最易错的一处**（把条件写成支撑包含会漏掉 `T` 以上的整类簇，并破坏下面的恒等式）。

**1.2 平移不变性。`[T]`** 直管 + 时间平移 + 空间环面 ⇒ 簇权只依赖形状与 `att` 的**相对**位置：
`A(α):=Σ_{Γ: α(Γ)=α, att Γ=[0,α]}φ^U(Γ)` 与绝对位置无关。`att Γ⊂[0,T]` 的放置数 `= (T−α+1)_+`。

**1.3 精确恒等式（`L1-b` 与 `L1-c` 合成一页）**

```
log Z_dec(B_T) = Σ_{α≥0}(T−α+1)_+ A(α)
               = φ_dec·T + log D_∞ + ε_T ,
φ_dec := Σ_{α≥0}A(α) ,   log D_∞ := Σ_{α≥0}(1−α)A(α) ,
ε_T   = Σ_{α>T}(α−1−T)A(α) .                                     (L1-c.1)
```

*验算 `T=0`*：`log Z_dec=A(0)`；右端 `=0+(φ_dec−ΣαA)+Σ_{α≥1}(α−1)A(α)=A(0)` ✔（逐项抵消，无余项）。
*推论（附赠）*：`(L1-c.1)` 同时**证明 `D_∞` 存在**（右端是绝对收敛级数，不先取极限）；且 `|φ_dec|,|log D_∞|≤\bar u/(1−\bar u)²=O(u)` ⇒ `D_∞=1+O(u)`，与 `:89` 一致。

**1.4 三类簇（"伸到两端"的分类，逐类给去处）**

| 类 | 条件 | 在 `(L1-c.1)` 里的去处 |
|---|---|---|
| **(i) 内部** | `att Γ⊂(0,T)` | 贡献**恰**为密度×长度 `φ_dec T`，**零缺陷**（这就是 P3 只看见 `O(u)` 却看不见 `δ` 的原因：内部类把 `T` 吃干净了） |
| **(ii) 单端** | `0∈att Γ` 或 `T∈att Γ`，不同时 | 总数与 `T` 无关 ⇒ 全部进 `log D_∞`；**两端同值**（时间平移），故不留 `O(1)` 残差 |
| **(iii) 跨/越端** | `att Γ` 含两端 且 `α>T`（"越端"；"真跨"者 `α≤T` 已被 `(T−α+1)_+` 计入） | **唯一被 `(T−α+1)_+` 截掉的一类** ⇒ 即 `ε_T` |

> **分解的精确内容**：`log Z_dec` 的全部 `T`-依赖**只**落在 (iii) 类，且只以"放不下"的形式出现。`ε_T≠0` 的原因不是"两端相互作用"，而是**超出管长的簇少了 `α−1−T` 个放置位**（这个系数就是 `ε_T` 的 `(α−1−T)`）。

## 2 · `ε_T` 的定义与 `|ε_T|≤Bu^T`

**2.1 定义（纠正提问中的写法）。`[T]`**
```
ε_T := log D_fin(T) − log D_∞ = log Z_dec(B_T) − φ_dec T − log D_∞ ,        (L1-c.2a)
```
**不是** `log D_fin(T)−log D_∞−(−δT)`。理由：`δ` 是 `ε_T` 的**上界率**（`|ε_T|≤Be^{−δt}` 的指数），不是 `ε_T` 式的一个加项；若把 `−(−δT)` 写进定义，等价于定义 `D_∞:=\lim e^{δt}D_fin`，而 `D_fin` 只**收敛**到 `D_∞`、不指数增长（`(L1-c.1)` 里 `D_∞` 是级数和，与 `δ` 无函数关系）⇒ 该写法在 `T=0` 就不成立。

**2.2 成本下界（`L1-a`，逐字在用）。`[T]`** `Γ` 连通且 `att Γ=[i,j]` ⇒ `Γ` 内有一条连通链把片 `i` 与片 `j` 相连；它跨 `α=j−i` 条时间边界，每跨一次 ≥1 个 temporal plaquette（`FOURWALL:42` (1.2)、`DRESSED-MASS:55` §1.4）⇒ `|Γ|≥α`。

**2.3 簇计数与绝对收敛。`[T]`** `|φ^U(Γ)|≤\bar C^{|Γ|}u^{|Γ|}`（Ursell 树图界 + 每 plaquette 一个 `u`）；经定点 plaquette 的连通动物数 `≤(eΔ)^{|Γ|}`，`Δ=20`（`:65`）。取 `\bar u:=eΔ\bar C u`，得
```
|A(α)| ≤ \bar u^{α+1}/(1−\bar u)   （α≥0；多出的一个 \bar u 因每个簇至少 1 个 plaquette）
```
`\bar u<1` ⟺ KP (2.1)（`uK<1`，`:64`）——**L1-c 不引入新的 `β` 限制**；必要时按 P3 §4.3（`:123`）同一手法把 `β₁` 缩一个 `N`-依赖常数。

**2.4 求和（无多项式前因子）。`[T]`**
```
|ε_T| ≤ Σ_{α>T}(α−1−T)|A(α)| ≤ \bar u^{T+3}/(1−\bar u)³  ⟹
|log D_fin(T) − log D_∞| ≤ B\,\bar u^{\,T} ,  B:=\bar u³/(1−\bar u)³ ,  δ:=\ln(1/\bar u)/a .   (L1-c.2)
```
关键一步：`Σ_{m≥1}m x^{m}=x/(1−x)²` —— 位移后**前因子 `(α−1−T)` 恰好把多项式吃成纯几何**，故 `T` 不出现在 `B` 之外。`B,δ` 与 `L,T` 无关（`Δ`、(2.1) 均逐 plaquette，同 `:77` 的 `L`-一致论证）⇒ 满足 `(L1)` 对 `B` 的要求。∎

> **与 `W02 §4(b)` 的关系**：`(L1-c.1)+(L1-c.2)` 说明 `(L1)` **不需要**装饰气体纵向转移矩阵的谱隙（`sup_{j≥2}|θ_j|≤u`）；那条路是多余的。`(L1)` 是**尾部求和**，不是谱陈述。
