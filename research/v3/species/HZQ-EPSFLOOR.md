## §1 精确形（量词齐）

```
场地   SU(N) Wilson，T⁴_L（或圆柱 𝒞_L=T³_L×ℝ，HQ4:43）

**(EF)**
```
∀N≥2  ∃ε₀(N)>0  ∀L≥2  ∀a∈(0,a₀]  ∀β∈[β_A,∞) :  [ M₀>0 ] ⇒ ε_*(L,a,β;O) ≥ ε₀(N)

四条读法（缺一条形就变）：

2. **非退化项**：`M₀>0` 不可去。2D 上 `ν≡0` ⇒ `0/0`（`HQ4:0.1`）⇒ 缺此项靶"未定义"而非"真"。
3. **`β_A>0` 不可去**：`β=0` 处转移算子秩一 ⇒ `f₁²=0` 而 `M₀>0` ⇒ `ε_*=0`（机检[8]；`GM6:130` 的 `β=0` 行同值）⇒ `∀β≥0` **假**。

## §2 三路

### (a) min–max 比值 `ε_* ≥ (λ₂−λ₁)/λ₂` — `[NG]`（`[T]` 级杀）
字面两读：降序（`λ₁=1≥λ₂`，转移算子）⇒ RHS `=1−λ₁/λ₂ ≤ 0` ⇒ **恒真零内容**（机检[5]：`−1/9`）；升序（能量 `λ₁=0≤λ₂=Δ`）⇒ RHS `=1` ⇒ 断言 `ε_*≥1`，被 `0.269` 当场推翻。本意形 `ε_* ≥ 1−λ₂/λ₁ = 1−e^{−aΔ}` 被三格否证：2D YM（`O=trF²=H ⇒ f₁²=0`，`GM6:128`；`Δ=3g²/8>0`）· 无原子有隙定理（`R6:254–255`）· 薄原子 `w=m²/(2λ) < 1−e^{−m}` 对 `m<1,λ≥1` 全成立（机检[6] 六格）。**下一手**：唯一诚实写形是 `M=Ω^⊥` 上的 form 不等式——`HZB:0.4`（MM-EQ）已证它与 `Δ_a≥c` **逐字等价**，换坐标不换强度，不作地板源。

### (b) I1 + Var 上界 — 窗内 `[T]`，`∀β` `[NG]`
```
(B-1) 分母  M₀ ≤ W_O²/4 = N²/4      [T] ∀β∀L∀a（Popoviciu，O∈[0,N]；取等=两原子等权，机检[4]）
(B-2) 分子  f₁² ≥ r₀ = 1/(16N²)     [T] 仅窗 β_A<3.777e-3（Z01:204；GK3:30）
⇒ ε_* = f₁²/M₀ ≥ r₀/(N²/4) = 1/(4N⁴) = w₀          （两个 [T] 相除，零额外假设）
```
**结构**：分母免费 + 分子昂贵。`w₀` 不是新数，是 `r₀` 经一个 β-无关归一（`w₀=4r_O/W_O²`，`HS-GAP-4:13`）。预算恰为 1（`HV9:0.3`）：窗内地板与靶常数逐位同数 ⇒ 任何 `<1` 传递因子都破坏它，而 `β`-积分型最好形状 `e^{−∫C}<1` ⇒ 该族对本靶无效。**窗外唯一结构下界**（`[T]`，`GM6:162` 除以 `M₀`）：
```
ε_* ≥ (Λ★ − s̄)/(Λ★ − s₁),   s̄=M₁/M₀,  s₁=m₁²；正值 ⟺ Λ★ > s̄ (≥ s₁)
```
前件 = 隔离（`I2`），严格强于 Clay（`ATOM2:112`）。稀释见证（机检[7]）：`f₁²/M₀=0.1>0` 而右端 `=−0.65` ⇒ 结构性数据在 `f₁²>0` 时给负下界。
**下一手（两条并列）**：**1. 单调形** `∂_β ε_* ≥ 0` 于 `[β_A,2.5]`——给同一个数、无 `Z_O`、无 `Ω`、无搬运（`HS-GAP-9` K6 的 `ε_*` 版），代价一条 `∂_β` 恒等式 + 一个玩具；**2. 紧窗口链**——`∀β` 拆成 `∪_n[β_A,B_n]`，每段用紧性 + 段间不变量（`HQ4:0.11` 的下一手），缺件是段间传递不等式，与 1 同型。

### (c) Schur 侧 — `[NG]`（`[T]` 级杀）
三条并列，任一条已足够：**(1) 侧不变**：换载体只换 `ν` 不换泛函型（`HS-GAP-4:0.2`；`HV7:0.7`）。**(2) 反号**：`M₋₁` 核 `1/s` 凸 ⇒ H1 是 Schur-凸泛函的**上**界；`f₁²` 是单点值 ⇒ Schur-凹，I1 是它的**下**界 ⇒ 两台反号机（`HZ5:0.10`）。`ε_*` 在固定 `M₀` 上同为凹 ⇒ 序型约束只给上界。**(3) 对齐自由**：`w₁=cos²θ_O`（`U1:23–32`）⇒ 源在 `Ω^⊥` 旋转把 `ε_*` 推到 0，而一切序型/正性/Harnack 常数不变；`HQ4 §2.1` 三类穷举已判死。**下一手**：位置/对齐输入只从谱侧取（边本征矢、Feshbach 秩一缺陷），不再从序侧造下界。
