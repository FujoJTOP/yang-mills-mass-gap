> **判 1.1（`[R]`+`[M]`）**：KLMN 是一个**存在性**定理。`C_ε ~ Cε^{−m}` 这种**定量增长阶**不是它的内容，也不是任何教科书的定理；仓内把它写成"KLMN 前沿"是**在存在性定理上加了一条自造的定量假设**。这不是错，但必须记账：**`m` 的合法性只能来自"尖锐常数的增长指数"这个定义，不能来自"KLMN 定理说"**。

### 1.2 定义：`m` 是尖锐常数的增长指数

**定义 1.1（尖锐 KLMN 常数，`[T]` 定义级）**。固定形式 `q`（`GP9-RB:66–67` 的符号形式）、范数 `‖·‖`、扰动形式 `𝔞`（在 `Q` 上、`ψ⊥Ω`），令

```
C_*(ε) := sup_{ψ∈Q, ψ⊥Ω, ‖ψ‖=1} [ |𝔞(ψ)| − ε q(ψ) ] ,      ε > 0 .          (1.1)
```

它是使 `|𝔞(ψ)| ≤ εq(ψ) + C‖ψ‖²` 对**所有** `ψ` 成立的最小常数（正部；下文不再重复 `[·]_+`）。

**定义 1.2（两个指数，`[M]` 口径）**：

```
m_raw := limsup_{ε↓0} log C_*(ε) / log(1/ε)          （"加性项自己的 ε-幂"）
m_KL  := m_raw − 1                                   （"扣掉 a²/ε 里那个 ε^{-1} 后的余额"）
```

`−1` 的来源是仓内的写法：`GP9-RB:120` 的加性项是 `C_ε a²`，而 `GR1:257` 把它拆成 `C_ε a²/ε` 并把 `C_ε` 记作 `~ ε^{−m}`，于是加性项 `= C a² ε^{−(m+1)}`，故 `m_KL = m_raw − 1`。**这个 `−1` 不是物理，是拆分方式**（§1.4 定理 1.5 会证明：它被 `k₀` 吸收，净效应为零）。

**引理 1.1（`[T]`，三行）**：`ε ↦ C_*(ε)` **凸、单调不增**。
*证.* 对每个固定 `ψ`，`ε ↦ (|𝔞(ψ)| − εq(ψ))/‖ψ‖²` 是斜率 `−q(ψ)/‖ψ‖² ≤ 0` 的仿射函数；一族单调不增仿射函数的上确界仍单调不增、且凸。∎

**引理 1.2（谱束刻画，`[std]`/`[T]`）**：若 `𝔞(ψ) = ⟨Aψ,ψ⟩`、`q(ψ) = ⟨Qψ,ψ⟩`（`Q ≥ 0`），则在 `A − εQ` 上有界的范围内
```
C_*(ε) = max σ(A − εQ) ,
```
即 **`m` 是谱束 `A − εQ` 的上端在 `ε→0` 时的增长指数**。

> **这一条是对任务书措辞的精确化（`[M]`）**：任务书说"`m` 来自 `H` 的谱在 `q` 与 `‖·‖²` 之间的**相对强度**"。严格说，`q` 与 `‖·‖²` 是同一空间上的两个形式，单个 `ψ` 上只有比值；真正决定 `m` 的是**三元组 `(|𝔞|, q, ‖·‖²)` 的联合值域**（等价地：谱束 `A − εQ` 的上端，等价地：`A` 相对 `Q` 的插值阶）。它**不是** `H` 的两点谱密度，也**不是** `m_phys`。

### 1.3 定理 1.3（Young–序计数律）：`m` 由"扰动的阶"给

> **定理 1.3（`[T]`）.** 设存在 `j ≥ 0`、`s ∈ [0,1)`、`λ < ∞` 使
> ```
> |𝔞(ψ)| ≤ λ a^j q(ψ)^s ‖ψ‖^{2−2s}          ∀ψ ∈ Q .                       (1.2)
> ```
> 则 `C_*(ε) ≤ C(s,λ) a^{j/(1−s)} ε^{−s/(1−s)}`，`C(s,λ) := (1−s)s^{s/(1−s)}λ^{1/(1−s)}`（对 `s=0`：`C_* ≤ λa^j`，与 `ε` 无关）。
> *证.* 记 `t := q(ψ)^{1/2}/‖ψ‖ ≥ 0`，则 `|𝔞(ψ)|/‖ψ‖² ≤ λa^j t^{2s}`，故 `C_*(ε) ≤ sup_{t≥0}[λa^j t^{2s} − εt²]`。令 `u=t²`：`sup_u[λa^j u^s − εu]` 在 `u = (sλa^j/ε)^{1/(1−s)}` 取到，值 `= (1−s)s^{s/(1−s)}(λa^j)^{1/(1−s)}ε^{−s/(1−s)}`。∎
> **注（等号何时成立）**：右端是 Young 步的**最优主控**（对每个 `t` 取等），但 `C_*` 是 `ψ` 上的**上确界**，故一般只有 `≤`。**当 `𝔞` 在 `k` 上对角（乘子形式）时上确界在单模取到 ⇒ `=`**（§1.6 的格点模型就是这一格）；定理 1.4 给另一个取等的模型。**一般情形：`m_raw(尖锐) ≤ s/(1−s)`**——估计的阶只给上界，尖锐常数可以更慢地发散。

**推论 1.3′（`[T]`+`[M]`）**：
```
k₀ := j/(1−s) ,     m_raw = s/(1−s) ,     m_KL = (2s−1)/(1−s) ,     2 + m_KL = 1/(1−s) .   (1.3)
```
> ⇒ **"分母"不是整数，是 `1/(1−s)`；"2" 只是 `s=1/2` 的像。**

**定理 1.4（尖锐性，`[T]`）**：对模型形式 `𝔟_λ(ψ) := 2λ Re⟨A^{1/2}ψ, φ⟩`（`q(ψ)=‖A^{1/2}ψ‖²`、`‖φ‖=1`），有 `C_*(ε) = λ²/ε` **精确**，极值点 `t_* = λ/ε`（即 `ψ_* ∝ A^{-1/2}φ` 配 `q^{1/2}/‖ψ‖ = λ/ε`）。
*证.* `|𝔟_λ| ≤ 2λ q^{1/2}‖ψ‖`（Cauchy–Schwarz 取等），代入定理 1.3 的 `s=1/2, j=0, M=2λ`：`C_* = (1/2)(1/2)^{1}2λ·ε^{−1} = λ²/ε`。∎
> ⇒ `s=1/2` 的指数 `1` **不是上界估计的松弛，是精确值**。这正是 `[K,V]` 的结构（§1.6）。

### 1.4 与仓内 `2/(m+2)` 的逐行对接

取 `ε = a^α`，两个误差是 `α`（相对项 `ε`）与 `k₀ − m_raw·α`（加性项 `C a^{k₀}ε^{-m_raw}`）。平衡：
```
α = k₀ − m_raw α   ⇒   α* = k₀/(1+m_raw) = k₀/(2+m_KL) = j ,     最优误差 = C' a^j .   (1.4)
```
- `m_KL = 0`、`k₀ = 2` ⇒ `α* = 1`、`k = 1`（= `GR1:27` 的 `2/(m+2)|_{m=0} = 1`）。
- `m_KL = 1,2,3` ⇒ `2/3, 1/2, 2/5`（= `GR1:257` 的表 `0.667/0.500/0.400`）。
- `k₀ = 4`（`m_KL=0`）⇒ `2`（= `GK3:357` 的 `4/(m+2)` 表 `2.000/1.333/1.000/0.800`）。
- `k₀ = 8`（`m_KL=0`）⇒ `4`（任务书的第三行）。

**数值核（`[E]`，`§5.2` 表 2）**：`k₀=2`：`α* = 1.000000, k = 1.000000`；`m=1,2,3`：`0.666666/0.500000/0.400000`（与闭式差 `≤ 1.3e−6`，网格分辨率所致）；`k₀=4`：`2.000000/1.333332/1.000000/0.800000`；`k₀=8`：`4.000000/2.666666/2.000000/1.600000`。

```

## §4 `m_KL < 0` 的可能性（★）

### 4.1 字面读法：**不可能**（定理 4.1，一行凸性）

> **定理 4.1（`[T]`）.** 若 `C_*(ε) ≤ C ε^{p}`（`p>0`，`ε↓0`），则 `C_* ≡ 0`，从而 `𝔞 ≡ 0`。
> *证.* 引理 1.1：`C_*` 对 `ε` 单调不增。固定 `ε₀`，对 `ε<ε₀` 有 `C_*(ε₀) ≤ C_*(ε) ≤ Cε^{p} → 0`，故 `C_*(ε₀)=0`；`ε₀` 任意 ⇒ `C_*≡0` ⇒ `|𝔞(ψ)| ≤ εq(ψ)` 对一切 `ε>0` ⇒ `𝔞(ψ)=0`。∎

> ⇒ **"`C_ε` 随 `ε→0` 反而减小"在任何非零扰动上都不会发生。** 这是 `[T]`，不是未证。任务书问句的字面答案：**不可能**。

### 4.2 约定读法：**可能**，判据 `s < 1/2`（定理 4.2）

> **定理 4.2（`[T]`）.** 在 `(1.3)` 的参数化下（`s` = **估计**的插值阶）
> ```
> m_KL = (2s−1)/(1−s) :   s ∈ [0,1)  ⟼  m_KL ∈ [−1, ∞) ,
> ```
> 严格单调递增，`m_KL = 0 ⟺ s = 1/2`，`m_KL < 0 ⟺ s < 1/2`，`m_KL → −1 ⟺ s → 0`。
> 前沿：`k = k₀/(2+m_KL) = j`（定理 1.5），**对一切 `s` 成立**。
> **真实的尖锐常数只会更慢地发散**（定理 1.3 注：`m_raw(尖锐) ≤ s/(1−s)`）⇒ 真实的 `m_KL` 只会**更小**。⇒ 本节的"可能为负"对真实的 `C_*` 是**更宽**的结论，不是更窄。

**表（`[T]`，`k₀` 按 `s` 由 `k₀=j/(1−s)` 给）**：

| `s` | 0 | 1/4 | **1/2** | 3/4 | →1 |
|---|---|---|---|---|---|
| `m_KL` | −1 | −1/3 | **0** | 2 | →∞ |
| `k₀`（`j=1`） | 1 | 4/3 | **2** | 4 | →∞ |
| 前沿 `k`（`j=1`） | **1** | **1** | **1** | **1** | **1** |
| 前沿 `k`（`j=2`） | **2** | **2** | **2** | **2** | **2** |

> **这张表是本文件的核心**：`m_KL` 从 `−1` 走到 `∞`，前沿**一格不动**。⇒ "让 `m_KL` 变小 ⇒ 分母变小 ⇒ 前沿增大"这条推理链在**第二步就断了**：分母变小的同时 `k₀` 变大，比值不变。

### 4.3 反例：`m_KL = −1` 是**取得到的**（`[T]`+`[E]`）

**(a) 有界乘子（抽象、精确）**：`𝔞(ψ) = a^j⟨Vψ,ψ⟩`，`‖V‖_∞ = M < ∞`。则 `|𝔞| ≤ Ma^j‖ψ‖²` 对一切 `ψ` 成立 ⇒ `C_*(ε) = Ma^j` **与 `ε` 无关** ⇒ `m_raw = 0`、`m_KL = −1`、前沿 `k = j`。
**数值核（`§5.2` 表 1，`s=0` 行）**：`C_* = 1.000000000` 对 `ε = 10⁻¹,10⁻²,10⁻⁴,10⁻⁸` 逐位不变。

### 4.4 对 T3 的 no-go：`s ≥ 1/2` ⇒ `m_KL ≥ 0` ⇒ 分母 `≥ 2`（定理 4.3），并与上界**夹逼**成精确值

> **定理 4.3（`[T]`，单模/波包）.** 设扰动形式的符号满足 `b(k) = c|k|(1+o(1))`（`|k|→0`，`c>0`；一阶算符在 IR 的**主符号**）。若 `(1.2)` 成立，则 `s ≥ 1/2`。
> *证.* 取单模 `ψ`（`|ψ̂(k)|=1`、`‖ψ‖=1`），`|𝔞| = b(k)`、`q = |k|²/a²`。代入 `(1.2)`：`c|k|(1+o(1)) ≤ λa^j(|k|²/a²)^s`。令 `|k|→0`：左 `∼ |k|`、右 `∼ |k|^{2s}` ⇒ 需 `2s ≤ 1`。∎
> （非对角情形把单模换成动量 `k` 的波包：`q ≳ |k|²/a²`、`|𝔞| ≳ c|k|`，常数变、指数不变。）

> **推论 4.3″（`[T]`，双向夹逼 ⇒ `m_KL = 0` 是**精确值**）.** 对 T3 型形式，`C_*(ε) = Θ(a²/ε)`，故 `m_raw = 1`、`m_KL = 0` **精确**。
> *上界.* `(1.6)` + 定理 1.3（`s=1/2, j=1`）⇒ `C_*(ε) ≤ λ²a²/(4ε)`。
> *下界.* 反设 `m_raw < 1`。则对任一 `m' ∈ (m_raw,1)` 有 `C_*(ε) ≤ Cε^{−m'}`（`ε` 小）。由 `C_*` 的定义，`|𝔞| ≤ εq + C_*(ε)‖ψ‖²` 对一切 `ψ`；对 `ε` 作 Legendre 优化：
> `inf_{ε>0}[εt² + Cε^{−m'}] = Const·t^{2m'/(1+m')}`（`t = q^{1/2}/‖ψ‖`）⇒ `|𝔞| ≤ C' q^{s_eff}‖ψ‖^{2−2s_eff}`，`s_eff = m'/(1+m') < 1/2` —— 与定理 4.3 矛盾。∎
> ⇒ **对 T3 型形式，`m_KL = 0` 不是"回读"，是上下夹出来的精确值**；`m_KL<0` 在这里没有缝。

**推论 4.3′**：`m_KL = 0`、分母 `= 2`、`k = 1`。**`m_KL < 0` 对 T3 不可能。**
> **注（对 `GK3:252` 的精确化，`[M]`）**：`GK3` 写"`k₀/(m+2)=4 ⇒ m=−1` 无解"。在 `j`-语言里：`k=4` 需要 `j=4`；`m_KL=−1` 那一格只为 `s=0` 开放，而 `s=0` 意味着扰动**不携带 `q`**——对一阶交换子不可能（定理 4.3）。所以"无解"的正确理由是 `s=1/2`，不是"`m` 不能为负"（`m` 可以为 `−1`，见 §4.3）。**这条勘误不改 `GK3` 的结论（`k=4` 在 KLMN 通道上不可达），只改理由。**

### 4.5 四条"想让它为负"的假路，逐条判死

**(a) 窗口化（最诱人的一条，`[NG]`，且**双重**判死）**：只在能壳 `{q ≤ Λ²‖ψ‖²}` 上量。由 `(1.6)`：`|𝔞| ≤ λa q^{1/2}‖ψ‖ ≤ λaΛ‖ψ‖²` ⇒ `C_*^{win} ≤ λaΛ`（与 `ε` 无关）⇒ 报出来的 `m_KL = −1`。
**第一重（零收益）**：`k₀` 同时从 `2` 掉到 `1`（`j` 不变，仍是 1），`k₀/(2+m) = 1/1 = 1`——**这又是定理 1.5 的一次实例**，前沿一格不动。窗口化不是"抬高前沿"，是"把分母和分子一起改小"。
**第二重（非法）**：`Δ_a` 的变分刻画（min–max）取遍**所有** `k` 维子空间，不留在任何 `q`-球里；形式比较 `q_a ≥ (1−ε)q − b‖ψ‖²` 要给出 `σ(H_a) ⊆ [(1−ε)Δ_cont − b, ∞)`，必须对**全形式域**成立。窗口界的适用范围是"低能态"，而谱底是全域下确界 ⇒ **窗口界进不了谱比较**（同型于 `GN2:104–114` 的"已证方向不消费一致速率"）。
**数值旁证**：`§5.2` 表 3 的极值点在 `|k| = λa²/(2ε)`，**随 `ε→0` 跑向 IR**——这正是 `C_*` 发散的机制；窗口化等于把这个极值点切掉，而切掉它的代价就是把 `k₀` 也切小。

**(b) 换 `s` / 换 `ε` 的写法（`[T]`，零收益）**：把同一估计改写成另一种插值形式（`s` 变）或把 `ε` 的定义换一换，都只是改写 `(k₀, m)` 的拆分：`k₀` 与 `2+m_KL` 同比例变，`k₀/(2+m_KL) = j` 不动（定理 1.5）。**这是"改 `m_KL`"唯一真实可行的含义，也正是它为什么无用。**
**（顺带一句，`[M]`）**：若把 `q` 的**单位**也换掉（`q→a²q`），`j` 的**定义**会跟着变；`j` 只在固定物理归一化（`GP9-RB:66–67` 的 `𝔮=(1/a²)Σ|k|²|ψ̂|²`）下有意义。所以"换 `ε`"要么只是改写拆分（比值不变），要么换了 `j` 的定义（比较的已不是同一条前沿）。**两条都不产生收益。**

**(c) 用 `q_full` 的 `m_phys²‖·‖²` 把 `s` 降到 0（`[T]` 判死）**：定理 3.1：加 `c‖·‖²` 不改 `m`、不改 `j`。**`q` 侧的加法进不了 `|𝔞|` 的分子。**

**(d) 先精确重求和一步、只估余项（唯一合法，`[NG]`）**：若能把一阶项**删掉**（`𝔞≡0`），则 `j` 抬到下一阶（`2`），前沿 `2`。这不是"把 `m` 调负"，是"删项"；仓内唯一实例是自由场的 `asinh`（`GK2:249`：仓内无 Magnus/BCH 全阶工具）。

### 4.6 判（本文件对"分母能不能变小"的正面回答）

> **`m_KL` 的确定值**：`0`（excess 约定，即 `2/(m+2)` 里的 `m`）/ `1`（raw 约定，即 `2/(q+1)` 里的 `q`）。**两者是同一句话**（`q = m+1`）。**对 T3 型形式这是精确值**（推论 4.3″ 的上下夹）；对一般扰动，由估计给的 `m` 是上界，真实尖锐常数的指数只会更小（定理 1.3 注）——那只会让前沿更好、不会更差（**T3 已被推论 4.3″ 夹死，这条"更好"只对别的扰动开放**）。
