## 1. `L=1`：`β_c(θ)` 的显式

沿用 `Q04 §3.1`（`a₀=0` 切片，`ρ=2φ`、`w=sinφ/(2φ)`、`c=cos(θ/2)`、`s=sin(θ/2)`）：

```
dμ_{β,θ} ∝ e^{−β(1−c cos φ)} sin²φ/φ dφ ,   φ∈[0,π]                        (1.1)
S(β,θ) = (βc/2)⟨w⟩ + ⟨Φ″⟩ ,    D(β,θ) = β² s² Var(w) ,    G″ = S − D       (1.2)
      Φ″ = (−cotφ + 1/φ)/(2φ) ,   Φ″(0)=1/6
```

`G″=0` 对 `β` 是**二次方程**（矩的 `β`-依赖留在系数里）：

```
β² − K β − M = 0 ,   K = c⟨w⟩/(2 s² Var w) ,   M = ⟨Φ″⟩/(s² Var w)
⇒  β_c(θ) = ½ [ K + √(K² + 4M) ]                                            (1.3)
```

**这是显式但不是闭式**：`⟨w⟩, Var(w), ⟨Φ″⟩` 都是 `β_c` 处的一维矩，故 (1.3) 是一个**标量不动点**（一维求积一次即可，无需迭代求解 `(S,D)` 的耦合）。数值上 `½[K+√(K²+4M)]`（`log [B]` 末列）与直接二分 `S=D` 的结果**六位全同**（差 `≤1e-6`，打印精度内不可分；`θ=π` 处 `1.6e-14`）。

**`θ=π` 的闭式**（`c=0 ⇒ K=0`，测度与 `β` 无关）：

```
β_c(π) = √(W₀/V₀) = √(0.2051152971230 / 0.0110592937730) = 4.30660785256     (1.4)
```
与任务给的 `β* = 4.30660785` **逐位相同**；`mpmath(dps=30)` 独立路 `|Δβ*|=1.1e-12`（`log [A]`）。
锚点还复现：`V₀=0.011059293772974`（`H1A`）、`W₀=0.205115297122968`（`H1A`）、`E[w]_{Haar}=0.357411353391`（`Q04`）、`Z=Cin(2π)/2=1.218826696528616`。`n=200…1600` GL 节点三位不变 ⇒ `[C]` 的求积不是瓶颈。

## 4. 大 `β` 的 `[T]` 渐近结构（解释双根）

`ρ→0`（即 `φ→0`）的 Gaussian 化，`Var(w)=Var(ρ²)/48²+O(β^{-3})`、`Var(ρ²)=64/(β²c²)`：

```
⟨w⟩ → 1/2 ,   Var(w) → 1/(36 β² c²) ,   ⟨Φ″⟩ → 1/6
S → βc/4 + 1/6  (发散)      D → tan²(θ/2)/36  (饱和)                          (4.1)
```

**逐位验证**（`β=1e5`，`log [E]`）：`S/β` 与 `c/4` 差 `≤1e-6`；`D` 与 `tan²(θ/2)/36` 三个 `θ` 上**五位全同**（`0.10700/0.26312/1.10731`）。

⇒ `θ<π` 时 `G″→+∞`，**任何有限 `β_c` 必成对**；`θ=π` 是唯一例外（`c=0`，无集中 ⇒ `D=β²V₀` 无界）。第 2 根随 `θ→π` 发散：`0.95π:222 → 0.97π:1050 → 0.99π:2.9e4`。**这是本轮的结构性发现**：`L=1` 的 `G″` 在 `β` 上**不是**单调的，"穿越"是**区间**不是**点**；`β_c` 必须读成"第一根"。

## 6. 判：`L=2` 的 `β_c` 与 `β_c(SU3)=5.6924` 比

1. **不需要外推（最关键）**：`β_c(SU3)=5.6924 < 6`，**落在实测窗口内**。窗口内插 `G″(5.6924)=0.5789`（`β=4,6` 线性内插），`σ` 为 `0.161(jk)/0.429(τ)` ⇒ 归零需 `3.6σ_jk / 1.4σ_τ` 的位移。**(a) 的判决完全不依赖任何 `β_c` 拟合。**

3. **所有有限 closure 都在 `[7.9, 17.3]`**，无一低于 `5.6924`；比值 `β_c/5.6924 ∈ [1.39, 3.04]`。

**余量（逐条，单位 `β`）**：硬 `≥+0.31`（`β_c>6`，`5.5%`）；最悲观 finite closure `+2.24`（`1.39×`）；中位 `+5.0…+11.6`（`1.8–3.0×`）。**值级余量**：`G″(5.6924)=+0.579`，`σ_τ=0.429`。
