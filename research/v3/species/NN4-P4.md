## §1 引理 P4（逐字 + 三行证明）

```
记  Λ=(ℤ/Lℤ)⁴,  C_q(z)=⟨q_0;q_z⟩_c,  Var(q)=C_q(0)∈(0,1]（Popoviciu）,
    ϖ=Var(q)+O_B,  O_B=N_B^{-1}Σ_{0<|z|_∞<b̂}n_B(z)C_q(z),  0≤n_B≤N_B   （KK2-FINAL:§1；II1-C4:§1 (I)）

引理 P4.  若 ∃p>4, A<∞：
   (P4)   |C_q(z)| ≤ A|z|₁^{-p}    对 0<|z|_∞<b̂，A 不依 (a,L,N,β,b̂)
   则     O_B ≤ A·S_p,   S_p := Σ_{z∈ℤ⁴, z≠0}|z|₁^{-p} < ∞
          ϖ ≤ Var(q) + A·S_p ≤ 1 + A·S_p =: C < ∞      （C 与 b̂,N_B,n_B 全无关）

证明.  ① n_B≤N_B ⇒ O_B ≤ N_B^{-1}Σn_B|C_q| ≤ Σ_{0<|z|_∞<b̂}|C_q(z)|（核权 ≤1，绝对值可提）；
       ② 块窗 ⊂ ℤ⁴ ⇒ 窗和 ≤ 全和 = A·S_p；③ Popoviciu Var(q)≤1。∎
```
**读法**：本引理的**全部内容**是 `(P4)` 的两个量词（`p>4`、`A` 一致）；`C`、`S_p`、`(2r0+1)⁴` 这类数在判据里**不承重**（§2）。`p=+∞`（指数率 `m≥m₀`）是 `(P4)` 的一个特例（`II9:0.2`）。
