## §2 自由还是钉死

1. **语法层：自由。** 全篇唯一陈述是 `for small fixed c∗ > 0`（`22404`）——无赋值、无阈值、无 “provided `c*` ≤ …”。`fixed` 的唯一实质是“不随 `k` 变”（`22430` 的 `≲` 常数即 `c*`）。`[T]`
2. **使用层：变小三处全改善，无一处要下界。** ① `22405` 领口宽 `≍ L^{j*}σ ≤ c* b a_k`，`c*` 小 ⇒ 领口窄；② `22429` 边衰减长度 `B L^{j*}σ ≤ B c* b a_k`，`c*` 小 ⇒ 衰减快；③ `22447` 需 `a < 1/(B L^{j*}σ) ≥ 1/(B c* b a_k)`，`c*` 小 ⇒ 越松。⇒ 三条都是“越小越好”，无一条给 `c*` 下界。`[T]`
3. **唯一反向约束（推论）：`j* ≥ 0`。** 求和指标 `j ∈ N0`（`22306`）。若 `c* b a_k < σ` 则无 `j ≥ 0` 满足 `L^j σ ≤ c* b a_k`，`j* < 0`、`C_k^int = ∅`、`C_k^ext = C_k`，`22405` 的 collar 句失去对象。故切分非退化要求 `c* b a_k ≥ σ` ⇒ **`c* ≥ σ/(b a_k)`**。`fax` 未写此句，本文件标 `[T]`（推论），不作字面引用。**下一手**：在 `fax` 找 `σ` 与 `a_k` 谁大（`22327–22331` 的 `t ≍ L^{2j}σ^{−2}` 与本仓副本 `L^j σ` 的 OCR 混用须核 pdf 页）。
4. **判**：`c*` 是**自由参数**（作者可选，受 `k`-一致性与 `σ/(b a_k)` 下端两条约束），不是钉死的物理常数；把它写成 `1/64`、`1/2` 之类都是外加。`[T]`

## §3 判定：`Bc* ≤ 0.429560` 能否靠选 `c*` 达成

1. **等价链（算术）**：`α ≥ 1/(Bc*)`；`1/(Bc*) ≥ 2.3279637276 ⟺ Bc* ≤ 0.4295599575`。`pwsh`：`1/2.3279637276 = 0.4295599575`；`B=1,c*=0.4296 ⇒ α=2.327747`（四位口径下过门）。`[T]`
2. **取值窗口**：`c* ∈ [σ/(b a_k), 0.429560/B]`。数值对照：`c* = 0.429560 ⇒ B ≤ 1`；`c* = 0.1 ⇒ B ≤ 4.295600`；`c* = 0.01 ⇒ B ≤ 42.955996`。`B` 只被称 “independent of k”（`22419`），是树边指数常数（来自热核 `K1, K2, c, C`，`22341–22344`），fax 无值。`[T]`（对照算术）
3. **裁决**：**可以选。** `c*` 既未被钉死又被逐字称 “small”，取 `c* ≤ 0.429560/B` 与 `fax` 的三处使用完全相容；代价是 `c*` 须 ≥ `σ/(b a_k)`，故窗口非空的充要条件是 **`B σ/(b a_k) ≤ 0.429560`**。这一条是**单条二变量不等式**，不是“某个未知常数”的黑箱。形式 **`[T]`**；非空性 **`[NG]`**（`B, σ, a_k` 无数值）。**下一手**：① 由 `22341–22344` 的 `K1, K2, c, C` 给 `B` 一个显式上界（`B ≤ 43` 即够 `c* = 0.01`）；② 核 `σ ≲ b a_k` 是否 `k`-一致；③ 若 ② 失败，改攻 `B` 侧（`(6.31)` 的 `B` 取 `1` 是否已够）。
