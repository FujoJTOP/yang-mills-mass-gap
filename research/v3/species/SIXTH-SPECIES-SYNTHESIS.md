## §4 精确缺失的一步（两句可判定的话，不许模糊）

**(i) 定量隔离（对齐面的唯一缺口）.** 沿 β=2.5 物理线、`(L,a)` 一致、并在源的重定化窗口 `t∈[t₁,t₂]`
（`√t_i ∼ c_i/m_G`）内一致，证明
```
    s₂(t;a,L)  ≥  ( Ē_t(a,L) − w₀ s₁(t;a,L) ) / (1 − w₀) ,
    Ē_t := ½⟨Ω|[o_t,[H,o_t]]|Ω⟩ / Var_μ(o_t) = −(d/dτ) log C_t(τ)|_{τ=0} .
```
一旦这句成立，`L2`（尖锐，§2.2 桥一）立刻给 `w₁ ≥ w₀`；在此之前四条候选一条也不通。`[M]`
**可判定性**：左右两端都是数；左端来自第二支撑点，右端来自可算的 `Ē` 与 `s₁`。判据里没有其它未定义对象——它**就是** gap 的定量形式（这也是它与 `H1` 等价的原因）。

**(ii) 束缚坐标上的地板（比值面的唯一缺口）.** `0⁺⁺` 粗转移生成元 `L_{0⁺⁺}` 在其束缚坐标 `s` 上满足
```
    L_{0⁺⁺}  ≥  −d²/ds²      （Dirichlet，s ∈ [0, L_s]）        ⇒     e₁ ≥ π²/L_s² ,
```
等价说法：**束缚坐标上的有效势是"底归一化单井"、底部无 Kramers 二重化**。二重化的两张脸都可判：
**精确二重 ⇒ `ρ² = 1`**（下界死）、**近简并 ⇒ `ρ² = ∞`**（上界死）——所以判别式只有一个：底部是否单值。`[M]`

**等价性（本节的判决）.** (i) 与 (ii) 都与 `H1` 等价（前者是 `I` 的定量形式，后者是 `(CP)` 的 Dirichlet 形式；
见 `WA-ALIGNMENT.md` §6、`RB-RATIO-BOUND.md` §6）。所以：
> **本轮没有造出第五数据模，也没有造出第六范式；只把"它不能在哪"写死。**
> 在具名类「谱数据类别 `S`（`ν` 的一切泛函）」内**不存在**可计算且地板敏感的成员（`[NG]`，§1 DM）；
> 唯一出口是场空间不等式，而它就是 H1（`[M]`）。
