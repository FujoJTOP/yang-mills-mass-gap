## §1 `H1` 的精确陈述（两个形，**不等价**）

### 1.1 族形（`[T]`，逐字）

`docs/paper-v2/ch18-scalar-h1.tex:42–48`（`eq:scalar-rule`）：

```
42:  \begin{equation}
43:  H1(\delta)\iff G''(0)\ge\delta
44:  \qquad\text{(pointwise, mode by mode, for every }(\beta,U')\text{)},
46:  \qquad \boxed{\ \delta_{\max}=G''(0).\ }
47:  \label{eq:scalar-rule}
```

`:55–58`（claimbox 第 1 条，`[T]`）：族 `{H1(δ)}` **全序**，`H1(δ) ⇒ H1(δ′)` 对 `δ′≤δ`；
"`H1`" without a δ **is** `G″(0)>0`。
⇒ **"`G″(0) ≥ δ`"与"`G″(0)>0`"是同一族的两端，差一个 `δ`。**

### 1.2 物理成员形（`[T]`，恒等式移项）

`app.tex:190–191`：`δ := a²Δ₀² + W_full`；`P03-EQUIV.md:253–258` 逐字判 `[T]`：
`H1 ⟺ G″ ≥ a²Δ₀²+W_full ⟺ Δ_dyn ≥ a²Δ₀²`，`W_full` **两端同一个对象、直接相消**，"零新估计，只是换名"。
`G″ = Δ_dyn + W_full` 本身是恒等式（`ch18:30–36`；`N05 §3` 机器残余 `6.7e−16`）⇒ 这一步的 `[T]` 无争议。

### 1.3 ★ 两形**不等价**（这是 `n05` 与 `n12` 的分歧点，裁在这里）

```
(i) 绑定时：Δ_dyn ≥ a²Δ₀²  ⟺  G″ ≥ a²Δ₀² + W_full        [T]（同一式移项）
(ii) 自由 δ：G″ ≥ δ            ⇏  Δ_dyn ≥ a²Δ₀²            [T]（W_full 可吞掉 δ；T01:116–119 第 4 级台阶）
```

- `app.tex:194` 的 "equivalently `G″_a/a² ≥ Δ₀²`" **只能单向**（差 `W_full`）：`N12:32` 判 `[T]`，`RUNBOOK:10133–10135` 记 `app.tex` 已改 "implies"。

### 5.3 正面结论（本轮唯一新增的结构句）：H1 与 I2 是支撑上的**两个独立坐标**

对任一 KL 测度 `ν`（同一道内，`[T]`）：

```
位置：  χ = ∫s⁻¹dν ≥ f₁²/m₁²  ⇒  (I1: f₁²≥r₀) ∧ (H1: χ≤1/λ)  ⇒  m₁² ≥ r₀λ > 0        [T]（一行）
        —— 这正是 G04:75 逐字 "inf_L m₁² ≥ c > 0 …（等价 I1∧H1）" 的内容：**位置要"重量 + 天花板"两件**。
距离：  I2 : Λ★ − m₁² ≥ δ      ⇒  平移协变，**永不给位置**（G07:53）                [T]
盲区：  H1 : χ≤1/λ             ⇒  对原子存在性/位置/间距**全盲**（Q6:53–56）          [T]
```

⇒ **`H1` 单独永远给不出距离；`I2` 单独永远给不出位置。** 两轴正交 ⇒ **不可比**，不是"严格更弱"。
这也给出 `H*∧H1 ⇒ gap`（`R6:162`、`F06:117`、`Q6:67`）三项为何一个都不能删的机制：
**`H1` 给天花板、`I1` 给重量、`I2` 给距离**——`H1` 与 `I2` 之间没有第二条路。
