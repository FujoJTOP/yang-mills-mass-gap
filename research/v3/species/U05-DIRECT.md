## §1 三条结构引理（把「为什么所有自然候选都不行」写成定理）

### 引理 1（min 律）`[T]`
设 `μ = μ₁⊗μ₂`，Dirichlet 形式相加（`E_μ(f)=E_{μ₁}(f)+E_{μ₂}(f)`）。则
```
λ₁(μ) ≤ λ₁(μ_i)   ∀i        （即「全空间常数 ≤ 任何边缘常数」）
```
*证明.* 取 `f = f_i⊗1`：`Var_μ(f)=Var_{μ_i}(f_i)`、`E_μ(|∇f|²)=E_{μ_i}(|∇f_i|²)` ⇒ Rayleigh 商逐一相等 ⇒ 全空间的 inf ≤ 子空间的 inf。∎

**推论 1.1（M6 不是病态，而是取 min 的普遍行为）`[T]`.** M6 的 `Ω` 是乘积 `|0⟩_a⊗|k=0⟩_b` ⇒ `μ_vac = μ_a⊗μ_b`，`μ_b` 在 `T¹_L` 上均匀 ⇒ `λ₁(μ_b)=4π²/L² → 0`（`ℝ` 上无 Poincaré ⇒ 精确 `0`）；而 `λ₁(μ_a)=1/Var(a)=2ω`。故
```
λ₁(μ_vac) = min(2ω, 4π²/L²) → 0 ,   而 a-边缘常数恒 = 2ω = G″
```
**⇒ 任何建立在「单方向 / 某边缘」上的量，都是全空间常数的上界；由它出发只能得到隙的上界，永远得不到下界。** M6 是这条的极值点，不是巧合。

**推论 1.2（`G″` 与边缘 Poincaré 常数只在 Gaussian 处重合）`[T]`/`[C]`.** `G″(0)=−∂²log ρ|_0` 与 `λ₁(μ_a)=1/Var(a)` 只在 `ρ` 恰为 Gaussian 时相等（M3/M5/M6 是；`CONSTANTS-CHECK:118` 的高斯互核 `=2m` 即此）。**2D YM 上它们相差极大**：`ρ_a` = Haar ⇒ `G″=0` 而 `λ₁(μ_a)=C₂(fund)=0.75`。⇒ **M2 杀死的是「局部曲率」版，M6 杀死的是「边缘 Poincaré」版 —— 两个反例是两个不同机制，别混为一谈。**

### 引理 2（KL 速率 = 通道质量，`[T]`）
设 `C_O(t)=∫_0^∞ e^{−Et}dν_O(E)`，`ν_O` 有限非零，`E_* := inf supp ν_O`。则 `R(s):=−C_O′(s)/C_O(s)=∫E e^{−Es}dν/∫e^{−Es}dν` 满足
```
R′(s) = −Var_{ν(·|s)}(E) ≤ 0 ,      R(s) ↓ E_* ,
−(1/t)log C_O(t) = (1/t)∫_0^t R(s)ds  ↓  E_*     （且 ≥ E_* 对一切 t）
```
又 `supp ν_O ⊂ spec(H)−E₀` ⇒ **`m_O := E_* ≥ m`**。∎
**⇒ 候选 1 测的是「该算子看得见的最低态」`m_O`，是隙的上界；`m_O > 0` 与 `m > 0` 之间没有任何蕴含。**

**M6 的账（逐字）**：取 `O=a`，`a`-扇区谱为等距的 `{ω(n+½)}`，且 `b` 自由 ⇒ `ν_a = δ_ω` 精确 ⇒ `Γ_a = ω > 0`；而 `m=0`。**候选 1 在 M6 上给 `ω`，不给 `0` ⇒ (c) 不过。**
再取 `O = e^{2πib/L}` ⇒ `ν = δ_{2π²/L²}` ⇒ `Γ → 0` ✓ —— **同一模型、同一公式，换算子换答案**：它测的是算子，不是模型。这正是 `kw2` 的 `inf supp μ` 在**固定通道**下的读法；`kw2` 的 `⟺` 对每个 `μ` 都对，但 `μ` 是**该通道的** KL 测度，故它给的是「该通道有质量隙」，离 `m>0` 差一步 `inf_O m_O = m`。

### 引理 3（各阶矩都是上界，`[T]`）
`−C′(0)/C(0)=⟨E⟩_{ν_O} ≥ inf supp ν_O`（Markov）；`C″/C−(C′/C)²=Var ≥ 0` 是**展宽**不是标度。M6 上 `O=a` ⇒ `⟨E⟩=ω ≠ 0` ⇒ **cumulant 全族在 M6 上失败**。

### 引理 4（裸比值无速率，候选 2 不是独立候选，`[T]`）
阈值型 `dν ∝ (E−E_*)_+^{1/2}dE` ⇒ `C(t)=Γ(3/2)e^{−E_*t}t^{−3/2}` ⇒
```
C(2t)/C(t) = e^{−E_*t}·2^{−3/2} → 0      对一切 E_* ≥ 0
```
⇒ **裸比值趋于 `0` 与「`E_*` 是否 >0」无关**，只有带 `log/t` 归一才回到速率，而那就是引理 2。**候选 2 ≡ 候选 1，逐字同一极限。**

## §3 `(a)` 的漏洞（必须逐字写，否则会误判）

用户判据 `(a)` 的三条件 = 「有隙模型上 `>0` + 自由场上 `=0` + 可证 ⇒ 那就是正确的量」。**`σ` 三条全满足，但 `σ` 不是隙**：
1. 自由场：`σ=0` ✓；
2. 有隙模型：2D YM `σ=g²C₂(f)/2 > 0`，且 `[T]*`（Migdal 级严格）、`β<1/48` 有已发表定理 `[T-文献]` ✓；
3. **但它 `≠ m`**：取 `YM × U(1)_free`（`T01-IMPLY §4.3` 已用的同一夹具）⇒ `σ>0`、`m=0`。∎

**⇒ `(a)` 作为「正确量」的判据不成立**（它会放过 `σ`）。正确判据必须**双向**：`Q>0 ⟺ m>0` **且** 在 M2/M6 两个方向都对（M2：`G″=0,m>0`；M6：`G″>0,m=0`）。
**附加警告 `[T]*`**：2D 里 `σ = (g²/2)C₂(f) = m` 是**恒等式** ⇒ **2D YM 对 `σ` vs `m` 是不可判的试金石**；任何「用 2D 验 `σ=m` 所以 `σ` 是隙」的推理证据量为零。

## §4 `(b)`：循环的确切位置（以及为什么它是必然的，不是运气）

**过 M6 的候选只有 `#4`/`#5`，而它们与隙 `[T]`-等价**：
- `#4`：`inf_O inf supp ν_O = m`，用「`Ω` 对局部代数循环」（格点上 `[T]`：有限维 + Perron 严格正；连续统 `[C]`：Reeh–Schlieder）。
- `#5`：`λ₁(μ_vac) = 2m₁`（`R1-BRIDGE §1.1(1b)`，高斯互核 `CONSTANTS-CHECK:118` `=2m`）。

**为什么必然（`[J]`，理由可写死）**：自由场 = M6 的 `ω=0` 退化 ⇒ 两者**只差一个「强方向」**。一个量要在 `ω>0` 的强方向上仍给 `0`，就必须**对「添加一个强方向」完全不敏感** ⇒ 它只能依赖**最弱方向** ⇒ 只能是 min 型 ⇒ 只能是隙。**「过 M6」与「逐字是隙」在本题里是同一件事。**
这正是 `T01` P3 那句「缺口逐字就是隙」的升级版：**不只是那一条链循环，而是任何过 M6 的候选都循环。**
