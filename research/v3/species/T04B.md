## §2 三条引理（全部 `[T]`，初等，逐行可核）

**引理 2.1（单边性）** 对任意 `ℒ ∈ Path`：`D ≤ P_ℒ`。

```
证：固定 β。liminf_L w₁(·,β) = sup_M inf_{L≥M} w₁(L,β) ≤ w₁(ℒ(β),β)（取 M ≤ ℒ(β) 即可）。
    逐 β 成立 ⇒ 取 liminf_β：D = liminf_β g(β) ≤ liminf_β w₁(ℒ(β),β) = P_ℒ。        ∎
```

**三条即时推论（这就是判死线 (c) 的全部内容）**：

```
(i)  P_ℒ ≥ D  ⇒  证 P_ℒ ≥ w₀ **不推出** D ≥ w₀：它是靶的**必要条件**，弱句。
(ii) 反方向可用：若某条 ℒ 有 P_ℒ < w₀ ⇒ D < w₀ ⇒ **地板死**。⇒ 路径版是**伪证器**（falsifier），不是证书。
(iii) 引理 2.1 不需要 ℒ(β)→∞：连常路径 ℒ≡L₀ 都给 D ≤ liminf_β w₁(L₀,β)（= G04 的 (i) 的单点版）。
```

**引理 2.2（等价判据）** `P_ℒ = D` ⟺ `liminf_β δ_ℒ(β) = 0` 且该 `0` 沿实现 `D` 的子列；**可检验的充分条件**：

```
δ_ℒ(β) → 0   (β→∞)        ⇒   P_ℒ = D .
证：δ→0 ⇒ 对 β 大，g(β) ≤ w₁(ℒ(β),β) ≤ g(β)+ε ⇒ liminf(g+δ) ≥ liminf g = D，且 ≤ liminf(g+ε) = D+ε。∎
```

**引理 2.3（inf-over-paths = 双层；这是唯一真成立的"化单层"）**

```
inf_{ℒ∈Path} P_ℒ  =  D .
证：≤ 取逐 β 的 ε-最优选择 ℒ(β)（liminf 的定义保证存在）⇒ P_ℒ ≤ D+ε；≥ 由引理 2.1。∎
```

> **引理 2.3 的读法（本文件最要紧的一句）**：双层 `liminf_β liminf_L` **就是**"路径族上的 `inf` 再取 `β`-`liminf`"。
> 所以"化成单层"若保留 `inf_ℒ`，**层数守恒**（内层 `liminf_L` 只是改名成 `inf_ℒ`），一个符号都没省；
> 若把 `inf_ℒ` 删掉（固定一条 `ℒ`），就按引理 2.1 掉到上界。**两条路都不给简化。**
> 注意 2.3 **不是** minimax 换序：`liminf_β inf_ℒ P = liminf_β inf_L w₁ = (ii)`，而 `inf_ℒ liminf_β = D = (iii)`，
> 二者之间正是 G04 §2.2 的 `(ii)⇒(iii)` 那道不可逆的坎（`[M]`）。

## §4 `e^{−L/β}` 的教训（**为什么"单调性"不是等价条件**）

```
e^{−L/β} 对每个固定 β 在 L 上**严格单调递减**，且 g(β)=0。
  ⇒ 单调性成立，等价仍然**不成立**：ℒ(β)=β 给 1/e，ℒ(β)=β ln β 给 1/β。
  ⇒ 缺的不是单调性，是**速率比较**：ℒ(β) ≫ Λ(β)，此模型 Λ(β)=β·ln(1/ε)。
```

**⇒ 一般判据（本文件定型，`[T]`）**：把"尾部尺度"定义成

```
Λ(β;ε) := min{ L₀ : w₁(L,β) ≤ g(β)+ε  ∀L ≥ L₀ }        （β-依赖；可以 = ∞）
则： ℒ(β) ≥ Λ(β;ε(β)) 且 ε(β)→0   ⇒   P_ℒ = D .
```

`Λ(β;ε)` 就是"这条族从 L 收敛到内层极限有多慢"，**它含 `β`**。谁想化单层，谁就得交出 `Λ`。
**这与 G04 §2.2 的 `[M]` 是同一个缺件**：`W3`（体积一致）/`L3`（连续极限）/`C4`（路径无关）都在要这条 β-一致的尾部耗尽。
