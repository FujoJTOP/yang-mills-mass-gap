## 1. 第 1 问：`c` 的来路

`O21` 的定义（`.py:20,264-274`，与 md §3 逐字一致）：

```
c(β) = min_{‖v‖=1} E[H_vv+Φ''|0]/(β‖v‖²) = E[Q|0] + E[Φ''|0]/β ,   Q := H_vv/β  (β-无关)
Q(ρ) = cos(θ/2)·sin(ρ/2)/(2ρ)        （横向本征值 B 的 β-部分, .py:117）
S(ρ) = β(1 − cos(ρ/2)cos(θ/2))       （切片 u=0, .py:111）
```
`S = β(1−ReTr(U_p B)/N)`、`N=2` ⇒ **`1/N` 已在**。`Q(ρ→0)=cos(θ/2)/4`，`c_∞=cos(θ/2)/(2N)=Re tr U_p/(4N)`（`[T]`，`ρ→0` 时 `Φ''→N/12` 而 `E[Φ'']/β→0`）。

**3× 的真实位置**：`O15 §4.2` 复算的是 `BETASTAR-N §4` 的 `Z_N` 中心元 `B=diag(ω²,1,ω)`、`N=3`、`β=6`：带 `1/N` 得 `+0.1021`，BETASTAR 表给 `+0.3060`，比值 `2.9971`。`N=2` 上两种归一化给同一个数（`ReTr/N` 与 `1−cos` 恒等），所以 **`N=2` 的 `O21` 不存在这个自由度**。

⇒ **判死线 `(c)`：`3×` 修正不适用**。但要说清：不适用的理由是"**3× 在别处**"（BETASTAR 的 N=3 列），**不是**"`c` 用了别的东西"——`c` 走的正是 `E[H]`，只是那份 `E[H]` 没被高估。**下游不得转述成"`O21` 的 `c` 与 `E[H]` 无关"。**

2. **`N`-搬运是真风险，但方向与 3× 无关**：`c_∞ = cos(θ/2)/(2N)` 是 `[T]`（`O15` 的 `(β/N)[A₀+(1−c)A₁]` 在 `ρ→0` 取 `βc/(2N)`），故 `N=3` 时 `c_∞` 是 `cos/6`，比 `cos/4` **小 1.5×**（`β₀` 反而 ×1.5 **大**，窗口更窄）。但 `V_∞` 的 `N`-依赖（`O20` 是 `SU(2)`）**未推**，`β₀ ∝ V_∞/c_∞` 的净 `N`-标度因此**未定** ⇒ **不给 `N=3` 的 `β₀`**（`[NG]`）。这是比 3× 更该先补的一步。
