## 1. 模型（与 S2 §1 逐字一致）

一个 plaquette，一个自由 link：`P = U·B`，`U∈SU(2)` 自由，`B` 固定，

```
S(U;B) = β (1 − ½ tr(UB)),       dμ(·|B) = Z_B^{-1} e^{-S} dU,   dU = Haar.
```

平坦（指数）chart：`U = exp(ξ)`，`ξ∈su(2)≅ℝ³`，`ρ=|ξ|`，`t = ρ/2`，`u = ξ₃/ρ`，`B = exp(iθσ₃/2)`，`μ=θ/2`。

```
½ tr(UB) = cos t cos μ − sin t sin μ · u      （直接展开 UB 的实部）
dU = J d³ξ,  J = sin²t / t² = sin²t/(t²),  Φ := −log J = 2 log t − 2 log sin t
d³ξ = 8 t² dt du dψ  ⇒  measure ∝ sin²t e^{−S} dt du   (ψ 积分是自由因子)
```

`SU(2) ≅ S³`，Haar 就是 `d³Ω`；chart 是半径 `2π` 的球，`ρ=2π` 是 `−I`，`J→0`（密度在边界消失，
两条 Stein 引理的全部边界项因此为零）。

**方向 `v`。** 取 chart 内**常方向**（class (a)，`div v = 0`）：`v = e₃`（纵向，沿边界轴）或
`v = e₁`（横向 = Savvidy 型方向）。`e₁` 与 `e₂` 等价，`e₃` 自成一类；故只有两个不等价方向。

```
G_v = ∂_v S,   H_vv = ⟨v, Hess S · v⟩ = ∂_v²S,   Φ′_v = ∂_vΦ,   Φ″_vv = ∂_v²Φ
W_j(v)   = E[Φ″_vv] − Var(Φ′_v)                       （campaign 的 W_geo，ch05 eq:wgeo）
G″_j(v)  = E[H_vv] − Var_j(G_v) + W_j(v)              （(★) 的左端）
```

**`H` 是哪个方向**：`E[H]` 的 Hessian 双线性型取在**与 `Var_j` 里那个 `∇S` 相同的常方向 `v`** 上
（`v` 是模式方向，不是 `∇S` 方向；`∂_v² ≠ ⟨v,Hess v⟩` 只在 `v` 随 ξ 变时才不同，见 G1 §2）。

## 2. 精确结构：`(★)` 在这个块上就是 `2W_geo ≥ δ_W` — **[T]**

对任意固定常方向 `v`（S2 Lemma 1+2，此处重证并机器验证）：

```
(M1)  ∫ ∂_v𝒱 e^{−𝒱} d³ξ = 0            （𝒱 = S+Φ；边界 ρ=2π 上 e^{−𝒱}→0）  ⇒ E[∂_v𝒱] = 0
(M2)  E[∂_v²𝒱] = E[(∂_v𝒱)²] = Var(∂_v𝒱)
(M3)  E[∂_v𝒱 · Φ′_v] = E[Φ″_vv]        ⇒ Cov(G_v,Φ′_v) = E[Φ″] − Var(Φ′) = W_j
⇒     E[H] − Var_j(G) = W_j,           G″_j = 2 W_j.
```

数值验证（每个 (β,θ,v) 点都打）：`E[∂_v𝒱] ≤ 8×10⁻¹⁴`、`E[∂_v²𝒱]−E[(∂_v𝒱)²] ≤ 3×10⁻¹³`、
`W_j − Cov ≤ 2×10⁻¹³`、`|G″ − 2W_j| ≤ 3×10⁻¹³`；节点数 40/80/160/260 结果不变到 `1×10⁻¹²`。**[E]**

## 4. 判死线三条

- **(a) `G″>0` 且可算 ⇒ 给具体下界。** 取 `δ_W(β) = 2 inf_{θ,v} W_geo = 2W_geo(θ=π,v=e₁)`
  （`β≤10`；`β≳10` 后 argmin 移到 `θ=0`）。**β=1：`δ_W = 0.02880673…`；β=2.5：`δ_W = 0.13173051`。**
  这是本 campaign 目前**唯一一个能算出来的数**。它 uniform in 边界 `U′`（`θ`）与模式 `v`，固定壳 `β`。
- **(b) 不成立。** 最小实例上 `G″>0`，`(★)` 不假；`β=0` 时 `G″=0` 精确——正是酸测要求的失败，而不是反例。
- **(c) `W_j` 可定**（`= W_geo`，闭式见 §1，数值见 §3）；**不可定的是 β-一致的 `δ_W`**：
  它要求 `inf_{β>0} W_geo > 0`，而 `W_geo(β→0) → 0`（精确）。这一条等价于 H1/粗模谱隙，
  **不在最小块内**，也**不能**由最小块供给。本块能给的只有 `δ_W(β_j)` 的逐壳数值。
