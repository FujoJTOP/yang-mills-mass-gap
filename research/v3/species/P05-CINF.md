## 1. 拆两项：`E[H_vv]` 的下界（本题的判死线 (a)）

### 1.1 一般式（沿用 O21 (1.1)，不改）

`V = S_W + Φ`，`S_W = βΣ_p(1−½Re tr U_p)`，`∂_v²` 给
```
∂_v²(1−½Re tr U_p) = ½tr(H_p²)·[α_p − γ_p],   H_p = iW_p,  W_p = Σ_ℓ Ad_{P_ℓ}(Φ_{X_ℓ}(v_ℓ))
```
⇒ `Q := H_vv/β = ½tr(H_p²)(α_p − γ_p)`，**`Q` 与 `β` 无关 `[T]`**。

**下界**：`|α_p| ≤ 1`，`tr(H_p²) ≤ ‖v‖²·C(x)²`（`C(x) = max_ℓ‖Φ_{X_ℓ}‖`，只依赖构型振幅），`|γ_p| ≤ ‖Ẇ_p‖/‖W_p‖²·(…)` 同为振幅函数 ⇒
```
|Q| ≤ C₁(x)·‖v‖²   ⇒   E[H_vv|0] ≥ −C₁(x)·‖v‖²·β                                   (1.2)
```
**`(1.2)` 就是判死线 (a) 说的形状：β-一致的负系数乘 `β`。** 实测幅值（`[C]`，O21 §1）：小振幅 `|X|≈0.35` 时 `Q ∈ [−0.36263, 0.32758]`、均值 `−0.022014`；一般格点 `min Q = −1.893`。
⇒ **`E[H_vv]` 永远不会比 `−Cβ‖v‖²` 更负**；`(b)`（"随 β 发散负、超线性"）在 `θ ≤ π` 支**不成立**。

### 1.2 本模型里它是正的（这就是 `C = 0` 的来源）

单 plaquette、切片 `ξ₃=0`、`v=e₃`（O21 §1 的精确 3×3 Hessian）：
```
B_tt = βcos(θ/2)sin(ρ/2)/(2ρ) + Φ''_trans     ⇒    Q = cos(θ/2)·g(u)/2 ,  u=ρ/2,  g(u)=sin u/(2u)
```
`g > 0` 于 `(0,π)`、`g(0)=1/2` ⇒ **`Q ≥ 0 ⟺ cos(θ/2) ≥ 0 ⟺ Re tr U_p ≥ 0`** `[T]`。故
```
E[H_vv|0] = β·(c/2)·G(B) ,   c := cos(θ/2),  B := βc ,  G(B) := E_{ν_B}[g] = ⟨A₀⟩ ∈ (0,1/2)
```
**`G < 1/2` 严格**（`g` 递减、测度不全在 `u=0`）——这正是 `c` 达不到 `c/4` 且要多付 `1/(12β)` 的全部原因。

### 1.3 `E[Φ'']` 侧（已证 `[T]`，O21 §2）

`Φ''_t(u) = 1/(2u²) − cot(u)/(2u) = 1/6 + u²/90 + O(u⁴) ⪰ 1/6 = N/12` 点态；`F(B) := E[Φ''] = 1/6 + O(1/B)`，单调降到 `1/6`。
⇒ `E[Φ''|0] ≥ N/12`，**与 β 无关**（`‖v‖=1`）。

## 6. 两条更正/锐化（对 O21、对 `LOOP-RUNBOOK`）

### 6.1 `c_∞ = cos(θ/2)/4` 只对 `θ < π`（集中点在 `ρ=0`）

`θ > π ⇒ c<0 ⇒ B=βc<0`，测度集中的是 `S` 的最小点 `ρ→2π`（`cos(ρ/2)=−1`），**不是 `ρ=0`**。那里 `g(π)=0` ⇒ `Q→0`。所以 `c_∞ = cos(θ/2)/4`（O21 §3、§5.5）在 `θ>π` **不能用作 `c` 的极限**；那条支的 `c_∞ = 0`。

### 6.2 `θ>π` 支的发散速率是 `√β`，不是 `β`（`[C]`，`[P8]`）

边界层展开（`v=π−u`，密度 `∝ v²e^{−|B|v²/2}`，`a=|B|/2`；`E[v]=2/√(aπ)`、`E[1/v]=2√(a/π)`）：
```
g ≈ v/(2π)        ⇒  G ≈ E[v]/(2π) = 1/(π√(aπ)) = [√2/(2π^{3/2})]·|B|^{−1/2}
Φ''_t ≈ 1/(2πv)   ⇒  F ≈ E[1/v]/(2π) = √(a/π)/π = [√2/(2π^{3/2})]·|B|^{1/2}
⇒ E[H_vv|0] = β(c/2)G = −0.126987·√(|c|β)                                          (6.1)
⇒ F/β       = +0.126987·√(|c|β)/β = +0.126987·√|c|/√β
⇒ c_tot = (c/2)G + F/β = 0 + O(β^{−1})    ← 领头 β^{−1/2} 项**精确对消**（系数同为 √2/(2π^{3/2})）
```
