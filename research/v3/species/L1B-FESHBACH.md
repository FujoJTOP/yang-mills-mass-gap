## §2 从 Feshbach 到 `‖Π⊥Hφ₁‖² ≲ (1−f₁²)`：4 步，缺第 4 步

### §2.1 Step 1 — 块分解与"秩一"的来源 `[T]`

`H := H_phys`（`N11-FALLBACK:43`），`φ₁` = `0⁺⁺` 底向量（归一），`E₁ := ⟨φ₁|H|φ₁⟩`。取

```
H_phys = span{φ₁} ⊕ φ₁^⊥ ,   b := Π⊥ H φ₁ ,   A_⊥ := Π⊥ H Π⊥ ,
H = [[E₁, b*],[b, A_⊥]] ,    ⟨φ₁|H|·⟩ = E₁⟨φ₁|·⟩ + ⟨b,·⟩   （秩一，因为 dim span φ₁ = 1）
```

**逐字说清**：L1 里 `Γ = ⟨φ₁|H|·⟩` 之所以**秩一**，不是因为任何结构定理，而是因为 `φ₁` 张成**一维**。这一步只用了定义 `[T]`。

### §2.2 Step 2 — Schur 消去，且**符号是加号** `[T]`

要消去 `φ₁` 方向，先要它可逆：`(H − m₀² − δ)_{φ₁φ₁} = E₁ − m₀² − δ = −δ`（取 `m₀² := E₁`）。⇒ **必须 `δ > 0`**，且消去块的符号是 `−δ ≺ 0`：

```
Σ_δ = Π⊥(H − m₀² − δ)Π⊥ − b*(−δ)^{-1}b = A_⊥ − δ + δ^{-1} |b⟩⟨b|  ⪰  A_⊥ − δ        (★)
```

即 `N11-FALLBACK:44` 的 `Γ(δ) = δ^{-1}|b⟩⟨b|`，`‖Γ‖ = δ^{-1}‖b‖²`，与 `ch05:387–390` 的 **Lemma NS** 同号（"eliminating a negative block raises the survivor"）。**这是本卡的第一个硬发现**：在 L1 的配置 A 里，Feshbach lift **只会抬高**，所以 `Σ_δ ≻ 0` **由 `A_⊥ ⪰ δ` 蕴含**，而 `A_⊥ ⪰ δ` 就是"`H` 在 `φ₁` 以上有隙"，**即 H1 本身**。lift 项**不生产正性**。

### §2.3 Step 3 — 另一配置里 `‖B‖` 只进常数 `[T]`

`ch05:330–336` / `FORGE-BLIND:18` 的配置 B（`H_−` = 快子块，`H_+` = 稳定块，`C ≥ γI`）：`Σ = A − BC^{-1}B* ⪯ A`，需 `Σ ⪰ μ` ⇒ 需 **`μ > 0`**；`‖B‖` 只出现在 `min{μ/(1+2‖B‖²/γ²), γ/2}` 的**常数**里。`μ = 0 ⇒ 界 = 0`，**与 `‖B‖` 取值无关**。

⇒ **(II) 至多改常数，不能把"无隙"变"有隙"。**

### §2.4 Step 4 — 缺的那一步 `[NG]`

缺件（`(II)`）：**边缘耦合—残数缺陷引理** `‖Π⊥Hφ₁‖² ≤ C(1−f₁²)^θ`（`N11-FALLBACK:46`）。三条理由，独立成立：

- **(i) 语料无**：`‖Π⊥H` 在 `research/v3/**/*.md` **0 命中**；`coupling bound` **0**、`edge vector` **0**、`耦合界` **1**（= N11 自己，§5）。⇒ 不是"没找到"，是**第一次写出**。
- **(ii) 有限 `L` 上它自动真 ⇒ 酸测失灵**：`φ₁` 是精确本征向量时 `b = Π⊥Hφ₁ ≡ 0`（`Hφ₁ = E₁φ₁`），左边 `=0`，`(II)` 对任何右边恒成立；而"有限 `L` 上 `T_L` 紧、谱纯离散、次层严格更大"正是语料自己判为 **trivially true / vacuous** 的那类（`ch09:200–201`、`ch12:12`、`N11-FALLBACK:97`）。同一真空性也出现在 `(TCI)`：`ch05:355–359` 逐字"it does **not** return zero, it **removes the test object**"（`ℋ₋={0}`，`.log` 里 `λ_min=1.1667` 但 `dim ℋ₋=0`）⇒ `(II)` 与 `(TCI)` **撞同一个 D6 空量化死因**（`MG-META:58,133`）。
- **(iii) 无界与量纲**：`H = −log T` **无界**，故唯一的平凡链 `‖b‖ ≤ ‖H‖·‖Π⊥φ₁‖ = ‖H‖√(1−f₁²)` 是 **`∞·0` 不定式**，不给任何常数。且语料的 `f₁² = |⟨0|tr F²|G⟩|²`（`ch01-intro:79`）是**量纲非 [0,1]** 的残数平方，`1−f₁²` 需要**未声明的归一化**（原子比 `w₁=f₁²/M₀`，`ch15-uvface:332`）⇒ `(II)` 的**良定义性本身未定**。

### §2.5 顺带给出的两个恒等式（本卡新增，供 L1 数值端用）`[T]`

```
(L1B-1)   ‖Π⊥Hφ₁‖² = ‖Hφ₁‖² − ⟨φ₁|Hφ₁⟩² =: Var_{φ₁}(H)        （归一 φ₁；纯代数）
(L1B-2)   Var_{φ}(H) ≥ dist(⟨φ|H|φ⟩, σ(H))² ≥ (E₂−E)²  (E∈[E₁,E₂])   （谱距离）
```

⇒ 左边**不是新的几何量，就是 `H` 在 `φ₁` 上的方差**；而方差是**天然有下界**的量（`(L1B-2)`），所以配置 A 的 lift 要的是**下界**。**`(II)` 给上界 ⇒ 方向反。** 自由场上 `Var=0`（`Hφ₁=0`）⇒ `(II)` 在自由场上是 `0 ≤ 0` ✓ 过酸测，但这不构成正面证据（同 `(TCI)` 的"removes the test object"）。

## §3 判死线落判

**(b) —— 触发，且强于"缺一步"：`Feshbach + (II) ⇏ H1`。** `[T]`

1. 配置 A（消去基态，`(★)`）：lift `= +δ^{-1}Var` 为正，`Σ_δ ⪰ A_⊥ − δ`；`Σ_δ ≻ 0` 由 `A_⊥ ⪰ δ` 蕴含，后者 `= H1`。**`(II)`（上界）在最理想的用法里也只能削弱 lift，不能建立 `Σ_δ ≻ 0`。**
2. 配置 B（消去稳定块，§2.3）：`μ = 0 ⇒ min{·,·} = 0`，`‖B‖` 无关。**`(II)` 永不能把 `μ=0` 变成正。**
3. ⇒ 两条可用配置下，`(II)` 都**不是**正性的来源。`Feshbach ⇒ H1`（`MG-META:107`）之所以成立，是因为箭头右边写着 `TCI = H1`——**假设就是结论**。这与 `MG-META:107` 的自述完全一致（"reduces to TCI = H1"），也与 `FORGE-BLIND:35` 的 "only debt is TCI" 一致。

**(c) —— 作为限定成立（不是主因）：**

- **前提失效**：L1 配置 A 里消去块 `C = −δ ≺ 0`，**违反** `C ≥ γI`；能用的是 `Lemma NS`（`ch05:387`），其结论方向与经典 Feshbach **相反**（§2.2）。若坚持经典形式，就必须换到配置 B，而配置 B 的 `μ>0` 就是 `TCI = H1`。
- **`H` 无界 / 谱不分离**：`H = −log T` 无界 ⇒ `‖H‖ = ∞`（§2.4(iii)）；`φ₁` 上方是否**一致**分离（`γ` 与 `L,a` 无关）正是 `I2`/`H1` 本身 ⇒ 用 Feshbach 的**一致性**要求与靶**同一件账**（`N11-FALLBACK:99`）。
- **但 Feshbach 本体不是"不适用"**：有限 `L` 上 `T_L` 紧、谱离散，lemma 逐字可用——只是结论平凡（`ch09:200–201`）。⇒ 记 **(b) 主判 + (c) 限定**，不记纯 (c)。

**(a) —— 不触发。** `MG-META:107` 未给严格推导（§1 逐字），故**不能**把 L1 的缺件说成"只是数值端"。L1 的**理论端缺一件**：`(II)` 本身（且方向/适定性未定）；数值端（`N11-FALLBACK:131` 的 1 h 探针）**只能判 `(II)` 假，不能判真**。
