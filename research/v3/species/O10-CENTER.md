2. **权重形式（精确）**：固定 `Ũ`，单 plaquette 的 `z`-条件分布是离散 von Mises

3. **因此不因子化**：`μ ≠ μ_{SU(N)/Z_N} ⊗ ν_{Z_N}`（既非乘积，`ν_{Z_N}` 也不是均匀）。`(a)` 的降维不等式**不成立**；强写下来的"分解"只能给出"只亏不赚"的那一支（§3.3），而该支的**一般形式已被语料证过**（`R2-H2GLOBAL §0.2` 工具 1 的"只亏不赚"）⇒ 本文件判 **(b)**，并把 `(c)` 的范围划清：**`z` 的平坦性在"观测者级"与"常 holonomy 切片级"语料已做，且已判 inert；"测度级 `z` 权重"未做**（§4）。

## 1. `SU(N)` 的中心分解与 `z` 的幂次

### 1.1 群层：`Z_N`-主丛，纤维只有**一个** `Z_N`

`Z(SU(N)) = Z_N = {ω^k I}`，`ω=e^{2πi/N}`。`PSU(N)=SU(N)/Z_N`，`SU(N)→PSU(N)` 是 `Z_N`-主丛。任何 `U∈SU(N)` 写成
```
U = z · Ũ ,   z ∈ Z_N ,   Ũ ∈ PSU(N) （Ũ 取 SU(N) 的代表元）
```
**给定 `U`，`Ũ` 的选法只差一个 `Z_N`**（`Ũ → z'Ũ`，torsor）。这一点必须先钉死，否则"中心 × 其余"很容易被误读成"多出一个 `Z_N` 自由度"：**群层的这个 `Z_N` 是规范的（lift 的歧义），它不可观测**。它平庸到什么程度：对任意表示 `R` 与任意 `z∈Z_N`，

> **Lemma CT-0（中心 phase 只记 N-ality）** `χ_R(zI)/d_R = ω^{q_R}`，`q_R` = `R` 的 N-ality。
> 证明：`zI` 中心 ⇒ 在 `R` 的每个权上作标量 `z`。∎（与 `T5-CENTER-VORTEX §2 Lemma CV-1` 同一事实，[T]）

`q_R=0`（adjoint、以及**一切色单态局域算子**，含 `tr F²`）时相位**恰为 1**。这是本任务第一个决定性的结构事实，§3.4 会用它。

### 1.2 格点层：`Re tr U_p` 里 `z` 的幂次（四个不同答案）

`S_W = βΣ_p(1 − N^{-1} Re tr U_p)`。`z` 可以以四种方式进入，幂次各不相同：

| # | `z` 的用法 | 每 plaquette 的 `z_p` | `Re tr U_p` 的幂次 | 是否是作用量的对称 | 结论 |
|---|---|---|---|---|---|
| P1 | **逐 plaquette 描述性坐标** `U_p=z_pŨ_p` | `z_p∈Z_N` 独立（受 `∂z` 约束） | **+1**（`tr U_p = z_p tr Ũ_p`） | 否（它只是改写） | **有权重的描述**；动力学在这里 |
| P2 | **'t Hooft twist / 平坦 `Z_N` 1-cocycle** `z_e`，`z_{∂p}` | `z_p=z_{∂p}∈Z_N`，被约束为平坦 | **+1**（但 `z_p` 受 `∂z=0`） | 否——它是**边界条件/扇区** | 扇区自由能不同；语料已测（`P3 §3` 的 `L=1` twist 值 `0.730`） |
| P3 | **朴素全局 `z` 作用于所有链** | `z_p=z^4` | **+4** | 仅当 `z^4=1`，即 `N\mid 4k`（`SU(2)`：`(-1)^4=1` ✓；`SU(3)`：`ω^4=ω\ne1` ✗） | **`N≥3` 不是对称**；"`U→zU` 是中心对称"只对 `N=2` 字面成立 |
| P4 | **真正的 1-形式中心对称**（沿超平面乘 `z` 的带扭曲**规范**变换，反向 dagger 给 `z̄`） | 净 `z_p\cdot\bar z_p` | **0** | **是，严格**（`z` 是标量矩阵，可与一切交换，`tr(zAz̄ B)=tr(AB)`） | 这正是它精确的原因 |

**P4 是本任务的关键**：中心对称之所以严格，恰恰因为它在**每个 plaquette 上的净幂次为 0**——它只作用在**闭合环的环绕数**上（Polyakov/Wilson 环的 N-ality），对 plaquette 权重**逐点不可见**。而任何"把 `U` 分解成 `z×Ũ`"的**描述性**分解（P1）把幂次变成 `+1`，**必然**引进一个非平凡的权重。**"中心对称精确"与"中心方向平坦"是两件事，且方向相反**：前者说的是 P4（净幂 0，不可见），后者要求 P1（幂 1）上的权重为常数——而下节证明它不是。

## 2. 关键：`μ(·|0)` 在 `z` 方向是什么？

**答：离散、有权重、且权重是 `Ũ` 的函数（不是"离散且被作用量固定"，也不是"均匀"）。**

### 2.1 精确形式（单 plaquette，可直接核）

固定 `Ũ_p`，`tr Ũ_p = |tr Ũ_p|e^{iφ_p}`。由 P1 幂次 `+1`：
```
Re tr(z_p Ũ_p) = |tr Ũ_p| cos(φ_p + 2πk_p/N) ,   z_p = ω^{k_p}
⇒  w(k_p | Ũ_p) ∝ exp{ (β/N) |tr Ũ_p| cos(φ_p + 2πk_p/N) }        (2.1)
```
这是 `Z_N` 上的**离散 von Mises**：峰位 `k*_p = round(−Nφ_p/2π) mod N`，宽度 `~(N/β|tr Ũ_p|)^{1/2}`。三条读法：

- **不是平坦**：`w` 随 `k` 变化，变化幅度由 `β|tr Ũ|/N` 控制；[V] 见 §2.3。
- **不是"被作用量固定"**：没有任何 plaquette 把 `k_p` 钉成常数——峰位由 `φ_p = arg tr Ũ_p` 这**连续**变量决定（`φ` 在 `Ũ` 上稠密 ⇒ 峰位遍历 `Z_N`）。⇒ `z` 既非固定、也非自由：它是**被 `Ũ` 的相位条件化的**。
- **耦合**：`w` 依赖 `Ũ` ⇒ 测度**不**是乘积 `μ_{PSU(N)}⊗ν_{Z_N}`。这已经足够判死 (a)。

### 2.2 对 `z` 求和 = N-ality 投影（精确闭式）

```
(1/N) Σ_{k=0}^{N-1} exp{ a cos(φ + 2πk/N) } = Σ_{j∈Z} I_{jN}(a) e^{ijNφ},   a = β|tr Ũ|/N     (2.2)
```
（由 `e^{a cos θ}=Σ_m I_m(a)e^{imθ}` 与 `Σ_k ω^{mk}=Nδ_{m≡0 (N)}`；[V] 已核到 `2.2×10^{-16}`。）

三个推论，全部是 `[T]`：

- **诱导权重不再是 Wilson 权重**：`(2.2)` 只依赖 `(|tr Ũ|, e^{iNφ})`，而原权重是 `e^{(β/N)Re tr Ũ}`（依赖完整的 `e^{iφ}`）。⇒ 边际化 `z` 之后，`Ũ` 上的测度**不是** `PSU(N)` Wilson 测度，而是"只保留 N-ality ≡ 0 character"的测度（等价的 Fourier 投影表示）。**没有任何 `ν_{Z_N}` 可以把这个修正吸收掉**。
- **力的均值被精确杀成 0**：取 `v∈\mathfrak{su}(N)` 无迹 Hermite，`力 ∝ Re tr(i v U_p)`（幂次 +1，同 P1）：
 `\sum_{k=0}^{N-1} \mathrm{Re}\,\mathrm{tr}(i v\, \omega^k \tilde U) = \mathrm{Re}\big[\mathrm{tr}(iv\tilde U)\underbrace{\textstyle\sum_k\omega^k}_{=0}\big] = 0`（[V]：`−1.1×10^{-16}`）。
 ⇒ **若 `z` 真的均匀（"平坦"），力的条件均值恒为 0**。这一条把"平坦 ⇒ 白送"直接否掉：平坦极限不是最好的情形，而是**最坏**的情形（§3.1）。
- **`SU(2)` 的 `Z_2` 块就是 `β→−β`**：`N=2` 时 `k=1` 的 plaquette 权重是 `e^{−(β/2)|tr Ũ|}`，即反铁磁；而 `U` 与 `−U` 在 `PSU(2)=SO(3)` 上是同一点 ⇒ `k=1` 块 = `PSU(2)` 上 `β_eff=−β` 的**同一个理论**。这不是"两块各自变简单"，是"一块是另一块的符号翻转"。

## 3. 判：能不能把非阿贝尔问题降成"`SU(N)/Z_N` + 有限群和"？

### 3.1 `(a)` 不触发：平坦前提假

任务给的 (a) 条件链是 **`z` 平坦 ⇒ 因子化 ⇒ 方差分解**。§2.1 已否决第一环（`w` 非常数），§2.2 否决第二环（边际化改变了 `Ũ` 的测度）。因此 **`(a)` 的降维不等式写不出来**——不是"写了但弱"，是**前提不成立**。

必须顺手钉死一个反直觉点：**"平坦"若真成立，它给出的是零信息，不是免费降维。** 由 §2.2 第二点，`z` 均匀 ⇒ `E[力|Ũ]≡0` ⇒ 力的**全部**二阶矩都是"块间"的。平坦极限把问题推到块间项上，而块间项正是无法用 `PSU(N)` 结构控制的那部分。

### 3.2 精确分解永远存在（但不构成降维）

离散纤维 ⇒ 无测度论障碍，`μ = Σ_k w_k μ_k` 精确，且（`[T]`，全方差律；语料同一工具见 `R2-H2GLOBAL §0.2` 工具 1、`D3-AVERAGED §1`、`CONDITIONAL-LATTICE-GAP` Step 2）：
```
Var(力|0) = Σ_k w_k Var_k(力|0) + Σ_k w_k | E_k(力|0) − E(力|0) |²          (3.1)
              └── 块内 ──┘        └──────── B_k ≥ 0：块间惩罚 ────────┘
```
若**强行**写成任务猜想的形状，正确的式子只能是
```
"Var_{SU(N)}(力|0) = Var_{PSU(N)}(力|0) + Var_{Z_N}(E[力|0,Ũ])"            (3.2)
```
且 (3.2) **不是相等而是下界亏损**：`Var_{SU(N)} ≥ Var_{PSU(N)} + Var_{Z_N}(...)`，因为右二的"块内"项还要再减一截；换言之，右二是**两个非负项之和的一个下界替代物**，直接等号要用 (3.1)。而 (3.1) 的内容是：**块内要给不等式、块间还要加一个正的 `B_k`。**

### 3.3 为什么这**不可能**是降维：合装"只亏不赚" + 两块都不更简单

**(i) 合装只亏不赚（语料已证，[T]，本文件只是套用）。** `R2-H2GLOBAL §0.2` 工具 1 的"只亏不赚"定理：两尺度合成后的 Poincaré 常数是**调和平均** `m = λλ_f/(λ+λ_f) ≤ min(λ,λ_f)`，严格小于任一侧。⇒ **任何"分成两块、各自证、再合装"的操作在常数上必然亏损**；要赢，只有"某一块的问题严格更简单"这一条路。

**(ii) 块内不更简单，而且换了理论。** 条件于 `z` 的块 `μ_k` 是把每个 plaquette 权重做相位平移 `2πk_p/N`：
- 在 `U_p=\mathbb 1` 附近的 Hessian **精确等于**原 Hessian 乘 `\cos(2πk_p/N)`（`SU(2)` 精确 `[V5]`：`f''` 由 `−2` → `+2`）。⇒ **Savvidy 负模没有被移除，它被搬到 `\cos<0` 的块里，并整体变号**。对 `N≥3`，`\cos(2πk/N)<0` 的块是"反铁磁（`β_eff<0`）plaquette 的 `SU(N)` 理论"——它的"隙"甚至不是同一个物理陈述。
- `k_p` 逐 plaquette 独立取值 ⇒ 块的个数是 `N^{|P|}` 量级（模规范后是 `Z_N` 的 2-形式数据）⇒ **逐一证不等式 = 更贵**。
- 因此 §3.1 的"平坦 ⇒ 白送"与 §3.3 的"不平坦 ⇒ 更贵"两头都堵：**`Z_N` 分解在任何一支上都不产生降维**。

**(iii) 更深的一层：目标对象与权重分属两个扇区。** 目标是 `f₁²`、`m_{0^{++}}`、`tr F²` 关联——**全 N-ality 0**（Lemma CT-0，相位 `=1`，[T]）；而**作用量**是 N-ality 1。⇒ 要求的"中心 × 其余"因子化必然把**带荷的权重**留在外面、**中性的观测者**留在里面：因子化能做，但它**恰好把有关系的那一半扔了**。这正是语料记过的"扇区错配"的测度版（`new-paths/SURVEY`、`E2-FLIP-SECOND-SCALE §2(v)`、`T5 §1.3`）。

### 3.4 那"中心结构是分水岭"这个动机错在哪

`U(1)` 的中心连续、`SU(N)` 的中心离散，这个差别**不进入 H1 的机制**。`GPP-STRUCT §4(b)` 已钉死：H1 缺的是**"条件方差 ≤ 条件曲率"**的 BL/log-凹**上界**，它要的原料是**凸性**（`Hess V⪰0`），而 Wilson 作用量在 `β=2.5` 上 `λ_min(Hess S_W)=−g|B|<0`（Savvidy）。中心分解**既不制造凸性、也不破坏凸性**——它只是把非凸性在块之间**搬运**（§3.3(ii) 精确：Hessian 乘 `cos`）。所以：

> **中心离散/连续不是分水岭；分水岭仍是凸性。** `Z_N` 分解把"一个非凸问题"换成"`N^{|P|}` 个非凸问题 + 一个正的块间惩罚"，属于 §3.3(i) 的严格亏损支。

### 3.5 唯一真平坦的两处，及为什么它们不给分

1. **观测者级平坦**（`[T]`，`T5 §1.3`）：`U=zV` 下 N-ality 0 观测量的中心相位**恰为 1** ⇒ 观测量因子化成"相位 1 × `V`-部"。这是**乘 1**，信息量为零，产生不了方差分解。(c) 的边界就在这里。
2. **常 holonomy 切片**（`[T]+[V]`，`P3 §2.1`、`P-WAVE-SYNTHESIS §4`）：常 holonomy 切片在**每个**中心扇区都平坦（`S_W≡0`），周期测度**精确 `θ`-无关**（`∫ρ da=26.0980322`，跨扇区 spread `2.7×10⁻⁸`），floor 由 Haar 携带 `≈0.222` 而非中心扇区。⇒ **平坦情形的语料结论是"平坦 ⇒ 不贡献"，不是"平坦 ⇒ 降维成功"。**
