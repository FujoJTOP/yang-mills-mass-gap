读法：**每往干净走一步，显著性掉一截**（3.66→2.40→1.34），"全正"只住在最池化那一行；池化把 σ 从 0.046 压到 0.041 的同时 `χ²/dof=3.14` 说两路本身不合 ⇒ **区间变窄是池化的算术，不是证据变多**。**下一手**：`q` 与系统项同印；"升"只用 `GH2:44` 那一行说。

### 1.2 四条具名理由（为何拟合判不了非减）

```
(n-1) 族循环：单幂 AL^q 对 q>0 自动严格增 ⇒ "拟合给非减"是所选族的性质，不是数据性质。
(n-2) 无内部：L∈{6,8} 只够一次比较；"非减"作为函数性质要 ≥3 点才有内容
      （HT5:16 自记第三体积为 [NG]）⇒ 该性质在本窗口不可判。
(n-3) 端点错：地板要 inf over L≥L_min（含 L→∞ 端），数据在最小 L 端；
      正 q 的局部趋势不可外推到 L→∞（AL^q e^{−cL} 同过两点而非单调）。
(n-4) 符号不独立：B 路"6/6 同号"重在同一批组态（HT5:61：同一 gh3_*.npz，仅 APE 层不同）
      ⇒ 2⁻⁶ 的符号检验不可用；下一手 = 换成同组态配对差的协方差。
```

### 1.3 精确反例与判别式
```
族 A（离域点源，精确）：w₁(L)=2/(L−1) ⇒ 严格减（U1:68,247；W3:24）
族 B（强耦，精确）：    w₁=s/2，∀L ⇒ ∂_L w₁≡0 恒平（MON1:85；W3:22）
⇒ 精确族只给"平"或"降"，无一条给"升"；"升"只出现在 β=2.5 的单一数值族。
判别式：非减若成立，必须能解释它在 A/B 两族上失效 ⇒ 它带 (β=2.5, 裸 trF², L≥6) 三重限定。
```

**判**：**`[NG]`**（HT5 的数不支持非减）：n-1/n-2/n-3 + 系统项跨 0 + 两个精确反例。
**下一手**：三点 `L=10/12`（`HT5:Y-A`）——唯一能把"两点不可判"变成"三点可判"的动作。

## §2 一步到地板：单调性够不够

### 2.1 免费的那一步（`[T]`）
```
设 w₁(·,β) 在 L≥L_min 上非减，且 w₁(L_min,β) ≥ w₀
⇒ inf_{L≥L_min} w₁ = w₁(L_min) ≥ w₀                                        [T]
```
序论恒真，**且方向唯一**：非增给 `inf=lim≥0`（`MON1:82`），非减才把 `inf` 压成**点值**。⇒ 判据的**形式**选对了；要审的是前件与坐标。

### 2.2 两种读法，各断一条

| 读法 | 窗是什么 | 断在哪 | 判 |
|---|---|---|---|
| **甲**：窗外 = `β>1/48` | β-窗 | **轴错**：锚 `w₁=s/2` 本就 `L`-一致（`W3:22`）⇒ `(β<1/48, L≥L_min)` 整块在窗内；`L`-步不改 β 坐标，一步也跨不出去 | **`[NG]`** |
| **乙**：窗外 = `L>L_max`（靶 `inf_L w₁(·,2.5)`，`ARCHIVE-r214:17`） | `L`-窗 | **等级不升**：轴对了，但点必须 `[T]`；`β=2.5` 只有 `L=6,8` 两点（`0.3491±0.0036`/`0.3568±0.0045`，`GH2:43`，实测未升为 `[T]`），且 `β=2.5` 的点态正性本身未证（`GK3:286`） | **`[NG]`** |

### 2.3 等级律
```
[T] 步 × 非 [T] 点 = 非 [T] ；  [T] 步 × [T] 点 = [T]（甲里那个 [T] 点已在窗内且 L-一致 ⇒ 冗余）
⇒ 单调性的产出 = 量词压缩（∀L → 1 点），不是等级提升。β 轴两个已知锚的值朝下
（β<1/48 给 s/2=1/2（`W2:210`），β=2.5 给 0.35）⇒ 即便补 β-单调，inf 也落在无锚的远端，方向帮倒忙。
```

### 2.4 判 + 下一手

**判**：**`[NG]`——单调性不够拿地板。** 甲：轴错（`L`-单调不改 β，而窗是 β 上的）；乙：等级不升（实测点进、实测点出）。
**下一手**两条：**(i)** 走乙 ⇒ 先证 `β=2.5` 的**单点** `w₁>0`——它与地板同难，不更便宜；**(ii)** 走甲 ⇒ 需 `β` 方向的搬运（`∂_β` 或连续性），而 `β`-锚朝下（§2.3），不提供下界。
