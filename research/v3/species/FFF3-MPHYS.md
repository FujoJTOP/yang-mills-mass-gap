## §1 三路逐条

**(a) `Λ_MS` + 维数透射 —— `[T]` 恒等 + `[NG]` 号。**
`[T]`：`Δ_a/(aΛ) ≡ m_phys/Λ`（`a` 约掉，`A04-RATIO2:88–97`；`B15.md:49`），常恒性**零动力学内容**（`B02.md:49` 逐字引 `A04:91–96`「没有可检验的动力学内容」；`M05-RATIO.md:172–173`）。透射只给 `a(β) ∝ Λ^{-1}e^{−∫dg/β_g}` ⇒ 搬的是**前因子 `a(β)>0`，从不搬号**（`PROOF-GAP-DIFFERENTIAL-INEQ.md:11` 逐字 "transports the *prefactor* `a(β)>0`, never the sign"）。
`[NG]`：`6.3(3)` 是 `m/Λ` 的**读数**（`LOOP-RUNBOOK.md:1626` 引 `l2`；`A04:132` 给 `6.28`），不是界。判别力 0 的精确见证：`C=0`（`m_phys=0`）时 `Δ_a/(aΛ) ≡ 0` 同样 `β`-无关、同样过自由场 ⇒ 该恒等式**分不开 `C>0` 与 `C=0`**。
**下一手**：`6.3(3)` 只作 `[a₀,a]` 窗口的读数；要它成路，须先有**独立**的 `liminf_{a→0} m_phys/Λ ≥ c₀>0`——那正是 §3 的缺口。

**(b) 面积律弦张力 —— `[NG]`（三条独立死因）。**
`[T]`：已证方向是 `m>0 ⇒ σ>0`（Chatterjee 2021, *CMP*，arXiv:`2006.16229` / DOI `10.1007/s00220-021-04086-y`；`B06-VAR.md:98`，摘要级）⇒ **`σ>0` 严格强于 `m_phys>0`**。故"经 σ 证 δ"是把靶换贵。
`[NG]` ①：反向 `σ>0 ⇒ m>0` 无定理，且面积律扇区**自带无隙方向**（Lüscher 修正 `−π/(12R)`，激发间距 `O(1/R)→0`；`B06-VAR:98`、`MU5-SIGMA-M:15,45,84`）。②：`m ≥ c√σ` 的**蕴含本身**仓内 **0 条 `[T]`**（`GH2-STRINGS.md:56` 表判：`[C]` 5 / `[O]` 3 / `[NG]` 2，蕴含标 `[T]` 的 0 条）；唯一 `[C]` 的 `m_{0⁺⁺} ≥ 4√σ` 只在 `β<8.9e−3`，与 `σ>0` **同域锁定、同一 KP 引擎**（`IMP-ARROWS.md:56`）；`c≈3.5–4` 是测量（`AREALAW-GAP.md:14,18,27`）。③：闭弦侧 `inf_{L≥L_c}E=0` ⇒ `inf_L E_closed ≥ c′√σ` **为假**（`TRANSMUTE-TENSION-GAP.md:3,21`）。④（格点形）：`ma=4σa²` 在 `a→0` 要求 `m∝a`，与 `m_phys>0` 不相容（`research/v3/KG5-UPPER.md:151`，grep 命中行，未逐字读上下文）。
**下一手**：`σ` 只作数值标度（`√σ≈440 MeV`、`σ/Λ_MS²≈2.8`，`LOOP-RUNBOOK:1626`）；若要真用它，先把 `L4`（面积律扇区 → 局域算符扇区）具名，那是缺的整层。

**(c) (EP) 型端点界 —— `[T]` 等价 + `[NG]`（vacuous 或假）。**
`[T]`：常物理线上 `Δ_a=a(β)·m_phys` ⇒ `d lnΔ_a/d lnβ = d ln a/d lnβ =: −κ(β)`（恒等）。端点比较两读：
(i) **字面形** `Δ_a ≥ βΔ_a'`（= `d/dβ[Δ_a/β] ≤ 0`）：因 `Δ_a'<0` ⇒ 恒真，且 `m_phys=0` 时是 `0≥0` 也真 ⇒ 自由场酸测不过、判别力 0；
(ii) **符号修正形** `Δ_a ≥ β|Δ_a'|` ⟺ **`κ(β) ≤ 1`**。
一圈（AF 定义式）：`κ = β/(4b₀N)`，`4b₀N = 11N²/(12π²) = 0.371511(N=2)/0.835900(N=3)`（机检）；`κ(2.5)=6.73/2.99`、`κ(6.0)=16.15/7.18`；`κ≤1` 只在 `β ≲ 0.37/0.84`，且 `κ ~ β/(4b₀N)(1+O(g²)) → ∞`（两圈只挪一个 `β`-常数项，尾段发散照旧）。
`[NG]`：修正形在标度窗内**为假**；字面形**vacuous**。⇒ (EP) 形在这里既非"未证"也非"更便宜"。
**下一手**：`κ(β)` 独立立项：`κ` 是格点 β-函数的弹性，可用 `C1-SLOPE-EQUIV.md`、`HQ5-AFSLOPE.md` 的斜率账与既有 `a(β)` 数据直接读；它是 (EP) 形唯一的闸门。

## §3 判定：能否 `[T]`

**判据（`[T]`，等价链，可当台账用）**：
```
m_phys ≥ δ ∀a  ⟺  Δ_a ≥ δ·a ∀a  ⟺  1 − λ₂(T_a) ≥ δa²(1+o(1)) ∀a
                ⟺  lnλ₂ 的 O(a) 系数 ≥ δ，且对 (L,β) 一致
```
（`λ₂(T_a)=1−aΔ_cont+o(a)`，`GN3-SPECTRAL.md:207–214`；`GL-B:285` 逐字"编码 `Δ` 的是 `a=0` 处 `log T_a` 的 `O(a)` 项"。）δ 一旦取定，靶就**不是新陈述**：它逐字是 `H1`/`T4` 的量纲修正版（`B02.md:128`；`N01-DEF.md:101`）。
**精确障碍（三条，各 `[T]`）**：①**恒等层**：`m_phys/Λ` 是唯一物理对象（`a` 约掉），`δ>0` 就是 `C>0` = 靶本身，没有绕开它的第三腿；②**机器层**：现有夹逼只给 `limsup_{a→0}Δ_a ≤ Δ_cont`（`GN3` 引理 A），缺的一半 `Δ_cont ≤ liminf` 逐字就是同一条（`GN3:16` 判 6）⇒ 夹不出东西；③**读数层**：`Δ_a=1.5–2.0` 的 `∀a` 延拓是自否形（0.2），靶要 `Δ_a≍a`。
**判**：`[NG]`（作独立路）；可 `[T]` 的只有判据与三条障碍。
**下一手（按价格）**：①**零 MC**：把 `m_eff` 的 `β`-序列与 `aΛ` 同图，判 `Δ_a/(aΛ)` 是否 `β`-平坦（平坦 ⇒ 读数支持靶；随 `1/a` 掉 ⇒ cutoff 钉住）——这一步直接改 0.2 的等级；②**立项**：`(L,β)`-一致的 `O(a)` 系数下界（`H1` 的量纲修正版），入口是 `κ(β)` 与 `C1-SLOPE-EQUIV` 的斜率账；③**否证器**：任一 β 上 `Δ_a/a` 跌破 δ ⇒ 靶假，直接写墓碑。
