## 1 · 第一问：`∂_β w₁` 的界是否与 `L` 无关

### 1.1 无条件的那条界是**广延**的 `[T]`

```
   ∂_β⟨A⟩ = −Cov_β(A,S)      ⇒   |∂_β⟨A⟩| ≤ 2‖A‖_∞‖S‖_∞ .
```
4D 环面 `N_p=6L⁴`，`|1−½tr U_p|≤2` ⇒ `‖S‖_∞ ≤ 2N_p = 12L⁴`。`[T]`（初等，无任何 YM 输入）

## 5 · ★ 更硬的一层：紧性/等度连续是**正性盲**的

### 5.1 酸测（宪章 §1）：自由场/`β=0` 也一样"有界 + 等度连续"

自由无质量场：`w₁≡0` 对所有 `β`（`T2:298-304`、`W3:108-112`，`[T]`，`f₁²=0`）；
`β=0`（Haar，i.i.d. 链）：转移矩阵秩一、**无第一激发态** ⇒ `w₁` 退化/为 0（`W3:114-117`、`:131`）。
两族的 `w₁(·)` 都是**常函数 0**：`[0,1]` 有界、等度连续（模数 `ω≡0`）。
⇒ 任何"有界 + 等度连续 ⇒ 紧 ⇒ 极限 ⇒ 地板"的推理链，**逐字**作用在自由场上会输出 `w₁≥w₀>0`——**矛盾**。
⇒ **紧性/等度连续里没有任何正性内容**：它至多给"极限函数存在"，给不了"极限函数 > 0"。

### 5.2 更根本：`w₁` 对测度**弱拓扑不连续**（`[T]`，两行）

取 KL 测度 `ν`（最轻原子 `m₁²`，原子分数 `w₁>0`），令 `ν_ε := (1−ε)ν + εδ_{m²_*}`
（`m²_*<m₁²` 固定在下方）。则 `ν_ε ⇒ ν`（弱，质量差 `ε→0`），而**最轻**原子变成那个赝原子：
```
   w₁(ν_ε) = ε  →  0 ,     而  w₁(ν) > 0 .
```
⇒ `w₁` 在 `ν` 处**跳跃**，且**无任何连续性模数**（`|Δw₁|/W₁ ≈ w₁/ε → ∞`）。
这与 `H07-RETRACT:126-135` 在 `m₁` 上是**同一个机制**的实测（那里 `W₁→0` 而 `|Δm₁|=0.6` 不变，
比值 `∝1/ε→∞`，`[T]+[V]`）。
⇒ **任何紧性（无论多强）都过不了 `w₁` 这一关**：弱紧只给子列 `ν_{ε_n}⇒ν`，而 `w₁` 在极限处跳。
要过这一关，需要**比弱拓扑更强**的紧性——即对原子权本身的控制——**那就是地板**。
⇒ **第八路把"紧性"当成与正性无关的独立缺口，这是对象选错**：`w₁` 恰是测度空间上**最不连续**的那类泛函。

### 5.3 与语料已判的一条对齐

`C2-BALABAN-UNIFORM:278` 逐字："**The wall is tightness (uniform a-priori bounds), i.e. L3 = `(★)`**"。
⇒ 语料自己已把"紧性"等同于"一致先验界"= 墙，**不是**"只差等度连续"的软缺口。

## 6 · 定量判死 (a)：把地板从 `β=0` 用 Lipschitz 搬过去，**算术上**也过不去

**传播机制**（(a) 唯一可能的形状）：`w₁(β) ≥ w₁(0) − C·β`，要它在 `β=2.5` 处 `≥ r₀=0.03125`，
需 `C ≤ (w₁(0)−r₀)/2.5`；而**实测强制** `C ≥` 平均斜率（`β=2.2` 处的实测值 `[E]`，`UNIF2:24-28`）：

```
  锚 w₁(0)=s/4=0.25   [T](mod [KL], W1:19-20,97-99)
  实测 w₁(2.2)≥0.4838 [E](UNIF2:24)         ⇒ 强制 C ≥ (0.4838−0.25)/2.2 = 0.10627
  允许 C ≤ (0.25−0.03125)/2.5 = 0.08750      ⇒ 强制/允许 = 1.215 > 1
  ⇒ 传播地板(2.5) = 0.25 − 0.10627·2.5 = −0.01568 < 0   （vacuous）
```
**两个分支都堵**：
- 用 `0.25` 锚 ⇒ **算术直接死**（差 1.215×，`[T]`+`[E]`，本轮实算 §7）。
- 换 `0.5` 锚（`P5-R0:17`）⇒ 算术不死（强制斜率 −0.00736，允许 0.18750），**但锚本身是 `[C]`**
  （`UNIF2:53-55` 逐字"靶 `N=2` 上强耦锚点是 0.25 还是 0.5 尚未统一"），
  且 `β=0` 秩一接触给 `w₁=0`（`W3:131`）⇒ **锚的存在性本身被削掉**。
⇒ **(a) 不成立**：`β=0` 的地板**搬不到 `2.5`**，无论用哪个锚。
