## 3. `6.51` 的来源逐项分解（任务 2）

`[P2]`（`[Q3]`）：复算 O20 §4.2 的合成式，`L(w₁) = sup_{[0,w₁]}|φ'|`，`C₁ = 1/(1−e⁻¹) = 1.581977`，`Var(w) ≤ 3.3279/B²`：

**答：贡献最大的是「矩常数 × Lipschitz」，不是尾界。** 并且它的**常数地板**是

（`B→0` 与 `B→∞` 两端 `w₁→0`、`L→|φ'(0)|=1/3`）。所以即使把尾项完全删掉，链也压不到 `3.3` 以下。`6.505` 超出 `3.328` 的部分（`3.18`）是 `B≈5` 处为压尾而抬高 `w₁` 的代价（`L²` 随 `w₁` 平方增长）。

## 4. 新严格链（任务 3/4）

### 4.1 八条引理

`w = 1−cos u`，`φ(w) = sin u/u`，`h := 1−φ`，`dν_B ∝ φ(w)e^{−Bw}dw`。

- **L1 `[T]`** `φ ∈ C^∞(0,2) ∩ C[0,2]`，`φ(0)=1`，`φ(2)=0`，`φ` 严格递减。
  证：`u↦sin u/u` 在 `(0,π)` 严格递减（`(sin u/u)' = (u cos u − sin u)/u² < 0`：`u≤π/2` 用 `tan u > u`，`u>π/2` 时 `u cos u<0`）；`w↦u` 严格增。∎
- **L2 `[T]`**（**关键新引理**）`P_ν(w>t) ≤ e^{−Bt}` 对一切 `t ∈ [0,2]`，**常数精确为 1**。
  证：令 `S=∫_t^2φe^{−Bs}ds`，`A=∫_0^tφe^{−Bs}ds`。`φ` 递减 ⇒ `S ≤ φ(t)(e^{−Bt}−e^{−2B})/B`，`A ≥ φ(t)(1−e^{−Bt})/B`。要证 `S(1−e^{−Bt}) ≤ e^{−Bt}A`，由上式只需 `(e^{−Bt}−e^{−2B})(1−e^{−Bt}) ≤ e^{−Bt}(1−e^{−Bt})` ⟺ `−e^{−2B} ≤ 0` ✓。∎
  **这把 O20 的 `C₁ = 1/(1−e⁻¹) = 1.582` 换成 1**，是 §3 尾项常数的来源。
- **L3 `[T]`** `E[w^k] = k∫_0^2 t^{k−1}P(w>t)dt ≤ k!/B^k`；特例 `Var(w) ≤ E[w²] ≤ 2/B²`。
- **L4 `[T]`** `Var(h) = min_{c∈ℝ}E[(h−c)²]`（方差的最小二乘刻画），故**任何常数 `c` 都能给出上界**。
- **L5 `[T]`** 取 `c = W_lo/3`、`Δ = w−W_lo`：`E[Δ²] = E[w²]−2W_loE[w]+W_lo² ≤ E₂−W_lo²`，其中 `E₂ ≥ E[w²]` 是 §4.2 的除式矩界、`W_lo ≤ E[w]` 是 L8。
- **L6 `[T/C]`** `h = w/3 + e`，`e := h−w/3 ≥ 0`，且 `e ≤ w²/45 + 0.06w³`（`[C]`，见 §5 核验）。于是
  `Var(h) ≤ (E₂−W_lo²)/9 + (2/3)[E[w³]/45 + 0.06E[w⁴]] + 0.01185/B⁴ + 0.1654/B⁵ + 0.6918/B⁶`
  （末三项为 `E[e²]` 的界；`(2/3)E[eΔ]` 用 `Δ ≤ w` 与 `e` 的多项式界）。
- **L7 `[T]`** `φ ≤ 1−w/3`（因 `h ≥ w/3`）⇒
  `E[w^k] ≤ [∫_0^2 w^k(1−w/3)e^{−Bw}dw] / Z_lb`
- **L8 `[T]`** `Z_lb ≤ Z₁ := ∫_0^2φe^{−Bw}dw`，用分段下界：
  `[0,1]`：`φ ≥ 1−w/3−w²/45−w³/189−0.0035w⁴`；`[1,2]`：`φ` 在该区间**凹**，故 `φ ≥ 弦 = (2/π)(2−w)`（`φ(1)=2/π`）。
  `E[w] ≥ W_lo = (1−r)/B`，`r = K̄/Z_lb`，`K̄` 由分部积分 `B∫wφe^{−Bw} = Z₁ − ∫_0^2w|φ'|e^{−Bw}dw` 给出：`K̄ = M·∫_0^1we^{−Bw}dw + Σ_k e^{−Ba_k}∫_{a_k}^{a_k+1}w|φ'|dw`，`M = sup_{[0,1]}|φ'|`。
  **`M = π/6`（全 `[T]`：`|φ'| = (sin u−u cos u)/(u² sin u) ≤ (u³/3)/(2u³/π) = π/6`，用 `sin u−u cos u ≤ u³/3` 与 `sin u ≥ 2u/π`）；`M = 0.406` 需数值认证（`[C]`，实测 `max_{[0,1]}|φ'| = 0.405285`）。**

| `(2/3)E[eΔ]` 修正（L6 前两项） | ≈ 0.44 | ≈ 0.09 | ≈ 26% |
| `E[e²]_ub`（L6 末三项） | ≈ 0.21 | ≈ 0.005 | ≈ 12% |

**精确缺失的那一步（一句话）**：`Ψ ≤ 1` 需要 **`Var(h)` 的 `1/B³` 系数**，即 `Var(h) = (1/(9B²))(1 − 0.133/B + O(1/B²))` 中 `−0.133` 的**符号**。用恒等式

```
d/dB Var_ν(φ) = −Cov_ν( (φ−Eφ)² , w )
```

（对指数族 `dν_B ∝ φe^{−Bw}dw` 直接求导即得，`[T]`），`Ψ` 单调 ⟺ `Cov((φ−Eφ)²,w) ≤ 2Var(φ)/B`；而对 `Exp(B)` 参照测度该式**取等**（`Cov((w−m)²,w) = 2/B³ = 2Var(w)/B`）。所以 `Ψ ≤ 1` 是**逐阶紧**的命题，任何一步粗估计都会把常数推离 1 —— 这就是为什么初等不等式只能到 `1.70` 而到不了 `1`。缺的工具仍是 O20 §6 指出的那一个：**"指数倾斜族下方差型泛函的单调性"**。本文件没有证它。
