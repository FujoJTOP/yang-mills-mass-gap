### 1.3 2D 为什么破 —— **是载体退化，不是 `K₂≡0`**

**(A) 机制（逐字链）**。2D 的空间切片上只有一个方向，`F` 只有一个分量：

```
trF² = trE² = H        （能量密度；U3:144、R5:41–42）

⇒ f²_{n,L} ≡ 0 ⇒ ν_{a,L} ≡ 0 ⇒ supp ν = ∅ ⇒ Δ^ν = +∞
而 Δ^H = (g²/2)C₂(f) = 3g²/8 = 0.375   (g²=1；N02:56)
⇒ O-chan ✗ ： +∞ ≠ 0.375
```
（`U3:145–149` 的三种写法等价：`w₁(trF²,2D)=f₁²/M₀=0` **EXACTLY**，每 `N` 含 `N=∞`；`R5:42–45` 逐字"`f₁²=0` exactly … The `0⁺⁺` 'glueball' in 2D is a holonomy/character state, **not** a `trF²` atom"。）

**(B) 这不是 `K₂≡0` 造成的 —— `GK4-2`（载体判别）`[T]`.**

> 同一 2D YM、同一 `H`、同一 `d`，只把载体从 `O=¼trF²` 换成 `O=tr U(空间圆)`（holonomy）：

> ⇒ inf supp ν_hol = (g²/2)C₂(f) = 3g²/8 = Δ^H   ⇒  O-chan  ✓
> ```
> 而 `d=2`、`K₂=0`（`GM2:282`）、`F∧F≡0` 三个事实**一个没变**。∎

**⇒ 判**：`O-chan` 的真值由**载体**（`O` 的矩阵元）决定，不由**理论**（`d`/`K₂`/拓扑）决定。这条是本路后面所有判词的支点：**任何"理论侧"前提都不可能修复一个"载体侧"命题**（除非它同时约束矩阵元，见 §3.5）。

### 1.4 `GK4-1`：`O-chan` ⟺ 单侧不等式 `Δ^ν ≤ Δ^H`（两行，`[T]`）

> **引理 `GK4-1`（单侧化）.** 设 `ν≥0` 有限、`supp ν ⊆ σ(H)∩(0,∞)`，`Δ^ν:=inf supp ν`、`Δ^H:=inf σ(H)∩(0,∞)`。则
> ```
> (O-chan)  [Δ^ν = Δ^H]   ⟺   [Δ^ν ≤ Δ^H] .
> ```
> *证.*（⇐）`supp ν ⊆ σ(H)∩(0,∞)` ⇒ 每个 `E∈supp ν` 满足 `E ≥ Δ^H` ⇒ `Δ^ν ≥ Δ^H`；与假设合并得等号。（⇒）显然。∎

**三条立即后果**：

1. **`O-chan` 只有一半是"谱"的**：`Δ^ν ≥ Δ^H` 是**免费的**（KL 表示 + `f²≥0`，`P3:61–69`），所以 `O-chan` 的**全部内容**是"`ν` 在 `Δ^H` 上方任意近处有质量"。这是一句**关于载体谱测度**的话。
2. **它不能是"谱上半连续"类命题的换名**：`(NEW)` 是 `σ(H_a)` 与 `σ(H)` 的关系（`GN1:121–130` 的 `GN1-A`），其中**不出现 `O`**；`O-chan` 里 `σ(H)` 只出现在右端且那一半免费。两者**符号集不同**（`GT2:246` 同判）。
3. **它没有量词内容**：`∀a∀L` 是逐点等式，没有"一致""极限""速率"。⇒ 它不能单独推出任何 `a→0` 的陈述（§0.9 的 `[T]` 见证）。
