## §1 `V` 的精确陈述：`逐尺度同一常数` = 对 `(a,k)` 的联合一致

```
(V₀)  论文逐字：∃α>0 ∃ε∈(0,1) ∃C<∞（不带 k）  ∀k ∀Λ:
         ‖Φ_k‖_α := sup_x Σ_{X∋x, X conn.} ‖Φ_k(X)‖ e^{α·diam(X)} ≤ ε,
         Cε ≤ ε/2,   Σ_k δ_k < ∞           （一条塔：a_k = a₀·L^{−k}，fax:6982）
(V)   引理要用：同一个 (α,ε,C) 对每个起始网格 a∈(0,a₀*] 的整条塔都成立
         ⇒ ∀a ∀k ∀Λ ∀σ: 上式成立。          ← "整族 a" 这一格在这里，不在三行里
```

| 常数 | 它不随什么变 | 逐字出处 |
|---|---|---|
| α（聚合物衰减率） | 不随 k；是 FRD 的定域率 | `fax:22720`·`22767` |
| ε（KP 小活动界） | 不随 k；`Cε≤ε/2` ⇒ `sup_k‖Φ_k‖_α≤2ε` | `fax:22720`·`22488–22490` |
| C（一步递推常数） | 不随 k；不带起始网格 | `fax:22481–22484`·`24523` |

**三个必须写死的地方。**
1. `(7.19)` 的 `a` **不是格距**，是聚合物衰减率；照抄会把"α 不随 k 变"误读成"格距不随 k 变"（后者显然假）。本文一律记 α。
2. "逐尺度同一常数"的精确内容 = **一个绝对三元组 (α,ε,C)**：α 管定域、ε 管小活动、C 管递推；三者不带 k，**也不带起始网格 a**。只对 k 一致（`V₀`）只覆盖几何塔 `{a₀L^{−k}}`，覆盖不了 `∀a∈(0,a₀]`。
3. `Cε≤ε/2` 是迭代条件（`fax:22488–22490`）：它保证"一个 ε 管整条塔"，这正是 `∃µ_n` 站到 `∀a` 前面的全部来源。

## §2 三行

**行 1（`V` ⇒ 每尺度 2 点核界，常数只依赖 `(α,ε,C)`）。** 固定 `(a,k,σ,Λ)`：`V` 给 (7.19) 形；Kotecký–Preiss ⇒ (7.20)（`fax:22725–22732`）；树图界 (7.29) + 计数 (7.30) 给
`|⟨O_x;O_y⟩_k| ≤ C₅‖O‖²∞ e^{−m(d_k(x,y)−2r)}`，`m = min{α/2, (1/C₄)log(1/(e^{C₃}C₁ε))} > 0`（`fax:22800–22811`）。
`C₁,C₃,C₄` 只依赖 `(α,ε,C)` ⇒ `(C₅,m)` 不带 a、k、σ、Λ（Thm 7.3 的常数表，`fax:22780–22784`）。

**行 2（2 点 ⇒ n 点 Ursell，速率不变）。** 取 n 个源 `λ_1…λ_n`：`κ_n(A_1;…;A_n)=∂_{λ_1}…∂_{λ_n}log Z_k|₀=Σ_{X conn., X∩supp A_i≠∅ ∀i}ζ_k(X;λ)`（`fax:22753–22758` 的 n 源版），`|ζ_k(X)|≤C̃e^{−α diam(X)}∏_i(…)`（`fax:22761`）。同一树图界 (7.29) + 同一计数 (7.30)，`D` 换成最小连接树长 `T₄−Σ2r_i`，得 `|κ_n|≤C_n e^{−µ_n T₄}`，`µ_n=m/C₄`，`C_n=C_n(m,α,ε,r,n)`。

**行 3（量词搬位）。** 行 1–2 的 `(µ_n,C_n)` 不含 a、k、σ、Λ；`V` 的 `∀a`、`∀k` 已在假设里 ⇒ `∃µ_n∃C_n` 站到 `∀a∀Θ∀Λ∀n∀A` 之前：`|κ^{(Θ)}_{Λ,a}(A_1;…;A_n)|≤C_n e^{−µ_n T₄}`。此即 a-uni。∎

## §3 判定

**3.1 `[T]` 的边界。** 三行没有一步是新估计：行 1 是 Thm 7.3 的常数表，行 2 是 (7.25)+(7.29)+(7.30) 的 n 源重排，行 3 是量词。判 `[T]`（蕴含），不判"新定理"。→ 下一手：引用写"`V ⇒ a-uni`（Thm A⇒B 的转写）"。

**3.2 三处非逐字，必须写在定式里。** (i) **n≥3**：论文逐字只给 2 点（Thm 7.3）与 n **步时间**关联（Thm 7.4，n 是时间步不是点数）；n 点 Ursell 是我用 (7.25)+(7.29) 补的一行树图扩展。(ii) **∀σ**：论文的均匀性逐字写"in the spatial volume and in k"（`fax:22732`、`24523`），σ 未入句；`V` 把 ∀σ 放进假设，供给端这一格是标准的但非逐字。(iii) **塔方向**：`fax:6982` 写 `a_k=a₀L^{−k}`（细化），`fax:24520` 写 `a_{k+1}=b a_k`（粗化）——同一篇两处相反；引理只用"几何塔"，方向不影响，但台账记这一处不一致。→ 下一手：三处各写一行，不许藏进 `[T]`。

**3.3 "假设≈结论"判：对象上不是，a-轴上正是。** 对象上：`V` 是活动层、a-uni 是关联层，`V⇒a-uni` 过聚合物展开、`a-uni⇏V`，故 `V` 严格强于 a-uni（不是换名）。a-轴上：`µ_n` 不随 a 变，唯一来源是 `V` 的 `(α,ε,C)` 不随 a 变——三行只是把这个"不随"从作用层搬到核层。**所以引理不降价：它把靶的 a-一致性原样收进假设，再把假设原样还给结论。** → 下一手：台账把 `V` 记"比靶贵"列，`[NG]` 作路线。

**3.4 作路线 `[NG]`。** `V` 的供给限 β<β₀(N)（强耦合，`fax:22813–22815`）；同窗口 a-uni 已由 Thm B 给出。故本引理把 ∃µ 位**在强耦合窗口填满**（`[T]`），对物理窗口零供给（`[NG]`）；缺的是 β-窗口搬运，不是 a-窗口引理。→ 下一手：a-uni 台账拆两行（β<β₀ 填满 / 物理窗口空），位置图只改这一处。

**3.5 酸测（未做，标 `[—]`，不许先标 `[T]`）。** 自由无质量场：a-uni 假（`κ₂` 多项式衰减）；`V` 是否同假取决于 FRD 残差是否把多项式尾吃进 `Φ_k`——若吃进，`sup_k‖Φ_k‖_α` 发散，`V` 与 a-uni 同假，引理不 vacuous。→ 下一手：逐字核 §6 的 `Φ_k` 定义与 FRD 残差，再补这一格。
