## §1 模型与三个对象的定义 `[T]`

单片 SU(2) / 一条自由链，边界 `B = exp(iθσ₃/2)`（S2 / G4 / `H1A-EXACT §2.1` 的同一模型），flat chart `ρ∈(0,2π)`，`u = ξ₃/ρ`：

```
V(ρ,u) = h(ρ) + g(ρ)u ,   h = β(1 − cos(ρ/2)cos(θ/2)) + Φ(ρ) ,   g = β sin(ρ/2) sin(θ/2)
Φ(ρ) = 2log(ρ/2) − 2log sin(ρ/2)        (Haar, 球坐标图; e^{−Φ} ∝ sin²(ρ/2))
```

条件化切片 `⟨v,ξ⟩ = a`，`v = e₃`：测度 `e^{−h(ρ)} r dr`，`ρ = √(r²+a²)`，`u = a/ρ`。
粗曲率 `G″(a) = −∂_a² log ρ_v(a) = E[V₃₃|a] − Var(V₃|a)`。在 `a=0`（`u≡0`）：

```
V₃₃ = h′(r)/r ,   V₃ = g(r)/r ,   E[V₃|0] = 0
⇒ G″ = E[H] − Var + W ,   E[H] := β cos(θ/2)·E[sin(ρ/2)/(2ρ)] ,
                           W  := E[Φ′(ρ)/ρ] ,   Var := Var(g(ρ)/ρ)
```

`[T]` 这只是把 `V = S_W + Φ` 拆成"Wilson 部分 + Haar 部分"，无近似。
注意：`W = E[Φ′(ρ)/ρ]`，**不是** `E[Φ″(ρ)] = 0.384654628`（两者差 0.18，勿混）。

**本题的 `(★)` 之所以可假，机制就一行 `[T]`**：`θ=π` 时 `cos(θ/2)=0`，`h = β + Φ(ρ)`，
故 `a=0` 切片的**测度与 β 无关**（除归一化常数）⇒ `E[H] ≡ 0`，只有 `Var ∝ β²` 随 β 增长：

```
G″(e₃; θ=π; a=0) = A − Bβ² ,   A = E_Haar[Φ′(ρ)/ρ] ,  B = Var_Haar[sin(ρ/2)/ρ] ,   β* = √(A/B)
```

## §3 判：`G″_j` 会不会为负？ **会。** `(b)`

### 见证 1（题给的 `β=6`，已验证）`[T]`
`β=6, θ=π, v=e₃, a=0`：`G″ = 0.2051153 − 36·0.0110593 = −0.1930193 < 0`。
负面机制正是题面所说：**`Var`（Savvidy 方差）以 `β²` 增长，越过固定的 Haar 锚 `W`**，于是
`Δ_dyn − W` 的负值超过 `E[H]`。`β > β* = 4.30661 ⇒ G″(a=0) < 0`（`[T]`，精确零点）。

### 见证 2（**在窗口内**，比 `β=6` 更要命）：`β=2.5, a ≈ 1.82` `[E]`

- `min_a G″ = −0.0791948 @ a = 1.8195`（归档 `w7/o28_infa.log:32`：`−0.0791946 @ 1.822`）
- 负窗：`a ∈ (0.7200, 2.9714)`（归档 `w7/o28_infa.log:33`：`0.7147..2.9688`；`w7/o02_bscan.log:17`：`[+0.78,+2.97]`）
