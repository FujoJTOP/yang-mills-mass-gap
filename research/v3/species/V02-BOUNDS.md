1. **`Λ★` 只有一侧界：上界。** `Λ★ ≤ Λ_max := (M₁−f₁²m₁²)/(M₀−f₁²)` `[T]`
   （`research/v3/R2-ISOLATION.md:95–101`；`docs/paper-v2/ch05-theorems.tex:441–447`）。
   **下界：不存在**，且**由矩/正性不可得** `[NG]`（W4：同一 `(M₀,M₁,M₂)=(2,11,101)` 下
   isolation `9→0.5→0.05→0.01`，`R2:130–151`）。强耦合、大 `N`、`L=1` 亦无（§1 检索，0 结果）。
2. **`m₁` 有两侧界，但是「夹逼式、含未知量」的，且在 `tr F²` 上退化。**
   `f₁²/χ ≤ m₁² ≤ M₀/χ` `[T]`（`ch02 eq:squeeze`；Lean 已证：`susceptibility_squeeze`、
   `m_sq_ge_of_squeeze` 均 PROVEN、0 sorry，`docs/LEAN-STATUS.md:33,36`）。
   强耦合端另有显式值/下界：`m₁=4ln(1/u)/a` `[T]`（`β<1/48`）；`m_{0⁺⁺} ≥ 4√σ` `[C]`（`β<8.9×10⁻³`）。
   `tr F²` 的 `χ=∫s⁻¹dν ~ a⁻⁴` 发散 ⇒ 两臂都退化成 `m₁²≥0`（`research/unconditional/CLAUDE-METHOD-POINTSPLIT.md:59–61`）`[NG]`。
3. **互不接触（判死线 (c) 成立，但形态不是「上界 < 下界」）。** 证 `I2` 需要的一对界是
   **`Λ★` 的下界 + `m₁²` 的上界**；语料里**前者根本不存在**，后者只有 `≤M₀/χ`（退化）。
   而现存的 `Λ_max` 恒满足 `Λ_max ≥ m₁²`（因 `M₁ ≥ m₁²M₀`），**与 `m₁` 的任何界都不冲突**；
   于是界所允许的 `Λ★−m₁²` 是 **`[0,∞)`，下确界 `0` 且被实现**（W4）。**间隙大小 = 无有限裕度**，
   不是某个数；要证 `I2` 缺的是**整侧**（`Λ★` 的下界），不是把两条界挪近一点。
4. **模型验证（判死线 (a)）：只在 `[M]` 层成立，且带载子限制。**
   `2D YM`（Migdal, SU(2)）：`Λ²=2C₂(1)=2`、`m₁²=(3/4)`（∝）⇒ **`ρ²=Λ★/m₁²=8/3=2.6667` 精确，

   **载子限制（要紧）**：2D 的 `8/3` 是 **holonomy** 的隔离；同一模型里 `O=¼trF²` 的 `f₁²=0`
   （`w₁=0` at every `N`，`W1-STRONG-ALIGN.md:246`；`T-WAVE-SYNTHESIS.md:43`）⇒ 对**物理载子** `tr F²`
   的 `I2`，**任何模型上都没有验证过**（0 命中）。4D 侧 `β<1/48` 只有 `I1`，`I2` 全开
   （`LOOP-RUNBOOK.md:4839`；`ch05:69–77`）`[O]`。

**⇒ 判死线落判：`(a)` 限定成立（`[M]`，2D YM holonomy `8/3`、1D 转子 `4`；`tr F²` 载子 0 命中）

## 5 · 判死线逐条落判

**(a)「`I2` 在某个模型上已验证」⇒ 给模型与数值（存在性证据）——限定成立。**
- 模型 1：**2D Yang–Mills（Migdal 热核，`e^{−(g²/2)C₂}`）**，SU(2)：`C₂(1/2)=3/4`、`C₂(1)=2`
  ⇒ `Λ★²/m₁² = 2/(3/4) = 8/3 = 2.6667`，`Λ★−m₁² = 5/4 > 0`。**精确、对称性固定、无动力学** `[M]`
  （`R2:216–220`；脚本 `research/v3/w7/r2_isolation.py`）。
- 模型 2：**1D 量子转子** `E_n=n²/2I`：C-偶 `0,2,8` ⇒ `ρ²=4`，`Λ★−m₁²=6/2=3`（单位 `1/2I`）`[M]`。
- **限制（逐字）**：这两条只证明「隔离是真实、可算、非小常数巧合的谱数据」，且是 **holonomy/转动**
  载子；**对 `I2` 的载子 `ν_{¼trF²}`，2D 里 `f₁²=0`（无原子）⇒ `Λ★=m₁²`，`I2` **假**。4D 无任何模型。

**(b)「`Λ★` 只有一侧界」——成立。** 只有 `Λ★ ≤ Λ_max` `[T]`；下界不存在 `[NG]`（W4 实现 `0`）。
要证 `I2` 缺的正是**下界一侧**（且不是「再紧一点」，是整侧缺席：`R2:103–105` 明言无下界伴随）。

**(c)「两界互不接触 ⇒ `I2` 在当前界下不可证」——成立，且强于「上界 < 下界」。**
- 所需对：`Λ★ ≥ m₁²+δ`（`Λ★` **下**界）＋ `m₁² ≤ …`（`m₁` **上**界）。
- 实际只有：`Λ★ ≤ Λ_max`（上）＋ `m₁² ≥ f₁²/χ`、`m₁² ≥ r₀λ`（下）——**两条都在错的一侧**。
- `Λ_max ≥ m₁²` 恒真（`M₁≥m₁²M₀`）⇒ 现存界**不排除** `Λ★=m₁²`。
- 间隙量：界允许 `Λ★−m₁² ∈ [0,∞)`，**下确界 `0` 被实现**（W4：`ε=0.5→0.05→0.01`，同三矩）
  ⇒ **无有限裕度可报**；`I2` 在现界下不可证 `[NG]`。唯一可报的正裕度是模型值 `5/4`（2D，`[M]`）
  与 `ρ²=8/3`，**都不能搬到 4D**。

**净判**：`I2` 的**存在性**已在 `[M]` 层给出（2D `8/3`、1D `4`），但（i）载子不同、（ii）无 4D 转移、
（iii）`Λ★` 下界整侧缺席 ⇒ **`I2` 在 4D 任何 β、任何 `N`、`L=1` 上均未被验证**。**Clay 0%。**
