  ```
  β_c(θ) = 16.1588687 · cos(θ/2)/sin²(θ/2)        [c]
  ```

## 1. 关键约化：只剩 `γ = βc` 一个参数 `[T]`

`x := ρ/2 ∈ [0,π]`，`dρ = 2dx`，`w = sin x/(2x)`。测度：
```
μ ∝ e^{−β(1−c cos x)} sin²x x^{−1} dx = e^{−β(1−c)} · e^{γ cos x} sin²x x^{−1} dx ,   γ := βc .
```
归一化常数 `e^{−β(1−c)}` **约掉** ⇒
```
⟨w⟩(β,c) = W(γ) ,   Var(w)(β,c) = V(γ) ,   γ = βc ∈ [0,∞) .
```
**这是 `q04` 判据的结构性事实**：`θ` 只通过 `c` 进入、`β` 与 `c` 只以乘积出现。故 `⟨w⟩/Var` 的最小值**与 `θ` 无关**（对固定 `θ`，`β` 跑遍 `[0,∞)` ⇔ `γ` 跑遍 `[0,∞)`）。

记三个母积分（`γ=0` 时与 `h1e` 的 `Z,N₁,N₂` 完全同源）：
```
A₀(γ)=∫₀^π e^{γcos x} sin²x/x dx ,  A₁(γ)=∫₀^π e^{γcos x} sin³x/x² dx ,  A₂(γ)=∫₀^π e^{γcos x} sin⁴x/x³ dx
⟨w⟩ = ½ A₁/A₀ ,   ⟨w²⟩ = ¼ A₂/A₀ ,   Var = ¼A₂/A₀ − (½A₁/A₀)² .
```

## 2. `β=0`（Haar）：`⟨w⟩₀` 的闭式 `[T]`

两次分部积分（边界项在 `x=0,π` 均为 0）：
```
A₁(0) = ∫₀^π sin³x/x² dx = 3∫₀^π sin²x cos x/x dx = ¾∫₀^π (cos x − cos3x)/x dx     [sin²x cos x = ¼(cos x − cos3x)]
      = ¾[Cin(3π) − Cin(π)] =: N₁ ,        (∫₀^L (cos ax−cos bx)/x dx = Cin(bL) − Cin(aL))
A₀(0) = ½∫₀^π (1−cos2x)/x dx = ½Cin(2π) =: Z .
```
⇒
```
⟨w⟩₀ = N₁/(2Z) = ¾ · [Cin(3π) − Cin(π)] / Cin(2π)                        [T]
```
与语料一致：`h1e` 的 `N₁ = ¾[ln3 + Ci(π) − Ci(3π)]` 与 `¾[Cin3π−Cinπ]` 是同一个数（`ln3 = ln3π−lnπ`，`γ_E` 抵消），`H1E-SAVVIDY.md:17`。

**数（40 位，`r05_wcf.log` §[1]）**
```
Cin(π)=1.6482776387045075488   Cin(2π)=2.4376533930572244118
Cin(3π)=2.8099376364537924380  Cin(4π)=3.1143565510027432265
Z = 1.2188266965286122059   N₁ = 0.87124499831196366694   N₂ = 0.67670315794551881466
```

> **注（与语料对齐）**：`h1e` 的 `E[g] = N₁/(2Z) = 0.357411353391`（`Q11-CERT.md:148`）就是本式；`g = G|/β = sin(ρ/2)/ρ = w`。**故 `⟨w⟩₀` 不是新数，是 `h1e` 已有的 `E[g]`；本节新的是"它就是 `w` 的 Haar 均值"这一读法与 `Var` 的配对。**

## 3. `β=0` 的 `Var(w)` 闭式 `[T]`

```
A₂(0) = ∫₀^π sin⁴x/x³ dx = 2∫₀^π sin³x cos x/x² dx = 2∫₀^π sin²x(4cos²x−1)/x dx
```
（两次 IBP，`d/dx(sin³x cos x) = sin²x(4cos²x−1)`；再用 `sin²x(4cos²x−1) = ½(cos2x − cos4x)`）
```
A₂(0) = ∫₀^π (cos2x − cos4x)/x dx = Cin(4π) − Cin(2π) =: N₂
```
⇒
```
⟨w²⟩₀ = N₂/(4Z) = (Cin4π − Cin2π)/(2 Cin2π)
Var₀  = N₂/(4Z) − (N₁/(2Z))²  =  0.011059293772973589911                   [T]
```
**这正是 `h1e` 的 `V₀`**（`V₀ = N₂/(4Z) − (N₁/(2Z))²`，`H1E-SAVVIDY.md:16`），差 `<1e−41`。`Var₀` 不是新常数，但**配对是新的**：`h1e` 用它算 `β*`，这里用它算 `2Var ≤ ⟨w⟩`。

## 6. `⟨w⟩/Var` 的最小值与 `2Var ≤ ⟨w⟩` 的**严格**证明

### 6.1 严格不等式（`[T]`，5 行，**与测度无关**）

`w(x) = sin x/(2x) ∈ [0,1/2]`（`sin x ≤ x`）。令 `D := 1/2 − w ∈ [0,1/2]`，则任意概率测度下
```
w = 1/2 − D ,  Var(w) = Var(D) = ⟨D²⟩ − ⟨D⟩² ,  Var(D) ≤ ⟨D²⟩ ≤ ⟨D⟩/2     (因 0≤D≤1/2 ⇒ D² ≤ D/2)
⇒ ⟨w⟩ − 2Var(w) = (1/2 − ⟨D⟩) − 2(⟨D²⟩−⟨D⟩²) ≥ 1/2 − 2⟨D⟩ + 2⟨D⟩² = 2(1/2 − ⟨D⟩)² ≥ 0 .
```
即
```
⟨w⟩ − 2Var(w)  ≥  2(1/2 − ⟨D⟩)² = 2⟨w⟩² ≥ 0     对一切测度、一切 β、一切 c 。        [T]
```
（最后一步 `1/2 − ⟨D⟩ = ⟨w⟩`。等号仅在 `w ≡ 0`（质量退化到 `x=π`）时取到，本族中不可能。）

**判死线 (a) 触发**：存在严格证明，`2Var ≤ ⟨w⟩` 对一切 `β` 成立 ⇒ `q04` 判据放宽为
```
2βt² Var(w) ≤ c⟨w⟩   ⟺   βt² ≤ c · s(γ)/2 ,   s(γ) := ⟨w⟩/Var(w) ,  γ=βc .
```
且 s 的下界即 `s ≥ 2`（上面的 `[T]`），**故原充分条件 `βt² ≤ c` 恰好就是"`s≥2`"这一档**——`[T]` 级放大的倍数**恰为 2/2 = 1，没有净增益**。

### 6.2 定量最小值（`[E]`+`[C]`）
```
min_{γ∈[0,∞)} ⟨w⟩/Var = 32.317737527230899  =  2N₁Z/(N₂Z − N₁²) ,  取于 γ = 0（即 β=0）
⇒ sup_β (2Var/⟨w⟩) = 0.0618855202446 .
```
**依据**：`γ∈[0,1000]` 的 41 点对数网格 + `[0,2]` 上 41 点线性网格 + 黄金分割细化（最优点 `γ* = 7.2e−15 ≈ 0`，即边界 `γ=0`），`s(γ)` **单调递增**；两端渐近 `s(0⁺) = 32.3177`、`s(γ) = 18γ²+O(γ)` 均给出同向。`⟨w⟩↑`（`d⟨w⟩/dγ = Cov(w,cos x) ≥ 0`，`w` 与 `cos x` 在 `[0,π]` 上同为减函数 ⇒ Chebyshev，**`[T]`**）；`Var↓` 只有数值（`[C]`，指数倾斜下单调量方差收缩的标准事实的数值版，未逐字证）。

### 6.3 放宽后的 `β_c(θ)`（逐字）
`s_min = 32.31773753` ⇒ 放大因子 `s_min/2 = 16.158868764`：
```
【放宽判据，数值证明档】
  2βt² Var(w) ≤ c⟨w⟩   ⟸   β ≤ β_c(θ) := (s_min/2)·c/t² = 16.158868764 · cos(θ/2)/sin²(θ/2)
  （原条件 βt² ≤ c ⇔ β ≤ c/t² = cos(θ/2)/sin²(θ/2)，即上式取 s_min/2 = 1）
  等价写法：β_c(θ) = 16.158868764 · cot(θ/2)/sin(θ/2)
  自洽性：β ≤ β_c ⇒ γ = βc ≤ 16.16 c²/t²，而 s(γ) ≥ s_min 在整个 [0,∞) 上成立，故 s(βc) ≥ s_min 无需迭代。
【严格判据，[T] 档】
  2βt² Var ≤ c⟨w⟩  ⟺  βt² ≤ (c/2)·s(βc)，其中 s(γ) ≥ 2 可证 ⇒ 严格推论只有原条件 βt² ≤ c。
```
**一句话**：`q04` 判据的**结构**是对的（方差项永远不是瓶颈），**定量**上按数值最小值可放宽 `16.16` 倍；但要把 `16.16` 升级成 `[T]`，缺的是 §6.2 的 `Var(w)` 对 `γ` 单调不增（或 `s(γ) ≥ 32.32`）的严格证明——**这就是精确缺失的那一步**。
