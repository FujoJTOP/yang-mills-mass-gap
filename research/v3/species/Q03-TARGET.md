## §2 问题 A 的裁决（三条 `[T]`，不按票数）

### 2.1 相消是真的，且**零内容** `[T]`

```
δ := a²Δ₀² + W_full            （app.tex:191）
H1(δ) ⟺ G″ ≥ δ                 （ch18:43）
      ⟺ Δ_dyn ≥ a²Δ₀²          （P03:253，W_full 两端同一个对象，恒等相消）
```
`[T]`。但 `P03-EQUIV.md:258` 同页判 `[NG]`：**"这是换名，不是化简……被证明的对象一个没少"**。
⇒ **n05 的代数成立，内容为零**；它能推出的最强结论只是"`H1` 的 `a²`-刻度形是 `Δ_dyn` 侧的不等式"。

### 2.2 "⟺ I2" 是**命名步**，而命名步被量纲否掉 `[T]`

| | `δ_curv`（`app.tex:190–191`） | `δ_I2`（`g03:95`、`A02:26`） |
|---|---|---|
| 定义 | `a²Δ₀² + W_full` | `Λ★ − m₁²` |
| 量纲 | **无量纲**（格点曲率） | **质量²** |

⇒ 相消消掉的是 `δ_curv`，`δ_I2` **一次也没进入那条式子**。n05 的 "⟺ I2" 要求 `δ_curv = δ_I2`，**被量纲直接排除**（`n12 §4` `[T]`）。
⇒ **`n05` 与 `n06`/`n12` 的分歧不是一个待证的数学分歧，而是一个可当场判死的记号混用。**

### 2.3 EQ3 判否 `[T]`

`n06 §3` 的 EQ3 要求 (E1) 同一被比较函数、(E2) 同一量词域、(E3) 双向可推。三项全不满足：
`G″_a(v)/a²` vs `Λ★−m₁²`；( `∀(L,a,v)` **无** `β`) vs (`∀(L,a,β)` **无** `v`)；两个方向各有一个 `[T]` 反例（`ν=δ₀+1_{[δ,δ+1]}`；有质量自由模）。

### 2.4 "2:1 说不是"这个记法应当废掉

`§29.3` 用票数记（2:1）。按 AGENTS §2.2，票数不是判据：这里的判据是**三条精确陈述**（相消 `[T]` + 量纲 `[T]` + EQ3 `[T]`），而它们全部落在 n06/n12 一侧，n05 只贡献了那条 `[T]` 的换名式本身。

## §3 问题 B：N09-1 使 A 失效了吗？——**没有；它把 A 裁成单边**

### 3.1 N09-1 的**前提**就是它的适用域

`N09-RESTATE.md:46–53` 的定理链是：*"若 `X` 在 M6 槽有定义、非恒真……则 `X = f(m)`，`f(0)=0`、`f>0`（`m>0`）"*。
**前提 = "过四模型"**。所以 N09-1 能说的只有：**过筛者必是 `m` 的重标**。它不能把不过筛的东西也拉进这个族。

### 3.2 `I2` 过筛 `[T]`

签名 `(0,+,0,undef)`（自由场 `0` / 2D YM 真 `5/4` / M6 `0` / 单片无定义），逐模型出处见 `n12 §5`。⇒ `I2` **在 N09-1 的适用域内**：它可能是 `m` 的重标（`[J]`：是，未被排除），故"`I2` 与靶同一层"这句话在 N09-1 下**被允许**。

### 3.3 `Δ₀` 不过筛 —— 而且是用**同一台 M6** 判的 `[T]`

```
M6 规格（b05 §2 / H03:130）：H=(p_a²+p_b²)/2 + a²/2，b 在长 L 圈上，w=1
  μ = μ_a ⊗ μ_b，μ_b = 圆环 Lebesgue（λ₁ = 4π²/L² → 0）
  谱底：m₆ = min(w, 2π²/L²) = 0.1974 / 0.01234 / 0.000771  (L=10/40/160) → 0     [T]
  G″  = λ₁(μ_a) = 2ω，**L-无关、恒 > 0**（B05:14,30,35；n12 §2 的 M6 行同值）
  Φ = 0 ⇒ W_full = 0 ⇒ **Δ_dyn(M6) = G″ = 2ω**                                    [T]
⇒ m₆ → 0 而 Δ_dyn → 2ω ≠ 0  ⇒  **Δ_dyn 不是 m₆ 的函数**（违反 `f(0)=0`）        [T]
```

**这一步比 `n12 §2` 的 2D 行更硬**：它不依赖 `G″=0`（那一行 `n12 §7` 自裁为 `[C]`），也不依赖 `W_full ≥ N/12`（那只是 `[M]`/`[V]`，`n05 §3.1`、`n10` 已判）——**M6 上 `Φ≡0` 是精确的，`W_full=0` 是精确的。**

### 3.4 结构上：`Δ_dyn` 是**单边缘**量，靶要求对载体取 `inf`

`B05-INVENT.md:35` 逐字：**"M6：项在、min 走。`G″=λ₁(μ_a)=2ω` 是 min 里被丢掉的那一项 ⇒ 它是全空间常数的上界 ⇒ 充分性失败（`G″>0 ⇏ m>0`）"**；`:100` 逐字："**通过者必须对载体取 `inf`**"。
⇒ `Δ_dyn`/`G″` 测的是**一个张量因子的边缘曲率**；`m` 是**对所有载体取下确界**的谱底。M6 就是把两者分开的那台机器。
⇒ 这不是"`Δ_dyn` 与 `I2` 谁更强"的问题：**`Δ_dyn` 连"隙的代理"这个类都进不去。**

### 3.5 所以任务书第 2 条的推论错在哪（逐字判）

任务书写："若 N09-1 成立 ⇒ 两者都只能是 `m` 的某个函数 ⇒ `Δ₀` 与 `I2` 的关系就不重要了"。
**判：前提只在 `I2` 一侧成立；`Δ₀` 一侧被 N09-1 自己的判据排除。** 这是把 N09-1 的**结论**外推到它的**前提之外**（外推方向恰好是"让不合格者与合格者同权"）。
⇒ **"关系不重要"这个结论仍然成立**，但**理由要换**：不是"两者都是 `m` 的函数"，而是"`Δ₀` 根本不是候选，所以比较它和 `I2` 的强弱对靶无信息"。**结论对、论证错。**
