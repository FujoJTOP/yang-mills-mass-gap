## §1 `f` 的单调性（确定性数值，`[T]`）

级数 `I_n(x)=Σ_k (x/2)^{2k+n}/(k!(k+n)!)`，逐项递推、终止于 `t<1e−18·S`。两条自检：①`I₀−I₂ = 2I₁/β` 逐位到 `1e−12`；②单格模型独立求积（Gauss–Legendre 4001 点，`∫₀^π sin²θ e^{βcosθ}dθ`）给 `⟨cosθ⟩=0.5071951000`，与级数 `I₂/I₁(2.5)` 逐位同，且 `∂_β log Z` 同值。

| `β` | 0.5 | 1.0 | 1.5 | 2.0 | **2.5** | 2.8 | 3.0 |
|---|---|---|---|---|---|---|---|
| `f(β)` | 0.2474359 | 0.2401937 | 0.2294293 | 0.2165637 | **0.2028780** | 0.1946780 | 0.1893079 |

精确导数恒等式（Bessel 递推，`r:=I₂/I₁`）：`r' = 1 − r² − 3r/β`；代 `r(2.5)=0.5071951000` ⇒ `r'(2.5)=0.1341190104`（中心差分 `h=1e−6` 逐位一致）。故

```
f' = r'/β − r/β² ;   f'(2.5) = 0.1341190/2.5 − 0.5071951/6.25 = 0.0536476 − 0.0811512 = −0.0275036
```

网格 `2e5` 点扫描 `β∈(1e−6,3]`：最大增量 `−2.7e−12`（无一处 `>0`）；`minₚ f' = −0.027532` 于 `β=2.4054`；`f(0+)=1/4`。⇒ `sup_{β>0} f = 0.25`。**这一个数就是 0.3 的死因**：锚点值 `plaq(2.5)/2.5 = 0.26105 > 0.25`。

## §2 `plaq ≤ I₂/I₁` 有没有依据：无，且数值反向

- **闭式自身是 `[T]`**：单格（0 维，四条独立 Haar link ⇒ `U_p` Haar）`Z=∫e^{β½trU}dU`，`⟨½trU⟩=I₂(β)/I₁(β)`；本轮求积 `0.5071951000` 复核。
- **不是"全格 ≤ 单格"的关联不等式。** 那一族（`⟨P⟩_{Z⁴} ≤ ⟨P⟩_{单格}`）的符号由正关联（FKG/Griffiths 型）决定，而 `SU(N)` 无 FKG；仓内已把「mean-field/Bethe 作 oracle + 比较搬运」整族判 `[NG]`，死因逐字为"符号由 FKG 决定，几何决定不了"（`docs/new-tools-registry.md:195–200`，B22）。本命题属同一族，且 oracle 方向还反了（下一条）。
- **数值反向**（同口径 `⟨½Re tr U_p⟩`）：`L=6: 0.65262±0.00002`、`L=8: 0.65229`（`GH3-OPERATOR.md:208`）对 `I₂/I₁(2.5)=0.5071951`（`RATE-UNIFORM.md:67`；`AUDIT-R5B.md:223` 同到 13 位）⇒ 比值 `1.28672`。锚点上闭式比真值**低** `1.2867×`；前提假。

## §3 逐行推 / 精确障碍

记 `g(β):=plaq(β)/β`。目标 `g'(2.5) ≤ 0` 等价于 `plaq'(2.5) ≤ g(2.5)=0.26105`，即 `χ_q(2.5) ≤ 0.043508`（用 `plaq'=−6χ_q`）。

1. 前提 **(P)** `plaq ≤ I₂/I₁` ⇒ `g ≤ f`。2. 事实 **(M)** `f' ≤ 0`（§1，`[T]`）。3. 由 (P)(M) 读出的只是"`g` 被一个递减函数压住"。**没有任何一步给出 `g'` 的号。**

- **障碍 (a) 类型错配（值 vs 斜率）**：`g' = (β·plaq' − plaq)/β²` 只要 `plaq'` 的**上界**；闭式给的是**值**，`f` 递减是它自身的性质，对 `plaq'` 无约束。若退一步借用它的自伴量 `χ_single := r'(2.5)=0.1341`，则 `6χ_single=0.8047`，比所需 `0.26105` 松 `3.08×`；且 `χ_lat ≤ χ_single` 同样无据。
- **障碍 (b) 递减上界的 `sup` 够不到锚点（结构性）**：用"`g ≤ U`，`U` 递减"在 `2.5` 处只能给重言 `g(2.5) ≤ g(2.5)`；有用的只有 `β ≥ β₀:=U⁻¹(g(2.5))`。而 `sup f = 0.25 < 0.26105` ⇒ **`β₀` 不存在**，`f(β) < g(2.5)` 对一切 `β`；即 (P) 与 `g(2.5)=0.26105` **不相容**。换到 `M(β):=I₂(2β)/(βI₁(2β))`：`M` 递减 `[T]`（网格 `[1,6]` 步长 `5e−4`，无正增量），`M(2.5)=0.28774`（对 `plaq` 侧余 `1.102×`，**未被 2.5 反证**），但 `M=0.26105` 落在 `β₀=2.8894` ⇒ 只能得 `g` 在 `[2.8894,∞)` 非增，**锚点邻域 `[2.5,2.8894]` 仍空**。
- ⇒ 本路能给出的最强形式是 `[T]` 条件句：**若** `plaq ≤ I₂(2β)/I₁(2β)`，**则** `plaq/β` 在 `[2.8894,∞)` 非增；`β=2.5` 的单点斜率不在其内。同型先例：`GX2-TRANSPORT.md:31`（"BL 是切向算子，`G″` 的缺口是法向方差"——切向/法向错配，不是常数不优）。
