## 1. 自立实现（不看 `o20` 代码）

沿用笔记 §1 给出的对象（未重推，只核），把一切化成一个 1D 求积：

```
ν_B(u) du ∝ sin²(u)·e^{−B(1−cos u)}·du/u ,  u ∈ (0,π),  B := βcos(θ/2)
g(u) := sin(u)/(2u) ,   W(B) := Var_{ν_B}(g) ,   Ψ(B) := 36 B² W(B)
Var(f|0) = β² sin²(θ/2)·W(B)   ⇒   Var/V_∞ = Ψ(B)  （θ 全部抵消）
```

两条独立数值路 + 一条精确级数路：

| 路 | 方法 | 用途 |
|---|---|---|
| `[P1]` float64 | `scipy` Gauss–Kronrod，`epsrel 1e−14`，**稳定形式** `h:=g−1/2`、`W = E[h²]−E[h]²` | 网格（`B≤1e3`） |
| `[P1]` mpmath | `mp.quad` tanh–sinh，**30 dps** | `B>1e3` 与全部锚点 |
| `[P3]` sympy | 精确有理系数级数 `Ψ = Σ a_k B^{−k}`（Gaussian 矩 `m_k = 2^{(k−1)/2}Γ((k+1)/2)`） | 判 `Ψ<1` 的方向 |

**为什么要 `h = g−1/2`**：`W ~ 1/(36B²)`，而 `E[g²]`、`E[g]²` 都是 `0.25` 量级。直接 `E[g²]−E[g]²` 在 `B=1e4` 相对误差 `1.31e−7`（`[P1b]` 实测），而待测信号 `1−Ψ = 1.3e−5` —— **只能分辨 1% 的效应**。换成 `h` 形式后 `E[h²]≈1/(18B²)`、`E[h]²≈1/(36B²)`，只丢 1 bit；float 与 30 dps 在 `B=1e4` 差 `1.9e−12`、`B=1e6` 差 `0`（`[P1]`）。

## 2. `V_∞ = tan²(θ/2)/36`：自己的推导 `[T]`

令 `y = u√B`（宽度标度变量）。三件事分开算：

**(i) 律 → Rayleigh（这一步给出 `B^{−1}` 的宽度，不含常数）**

```
sin²u/u·du = [ y/B − y³/(3B²) + 2y⁵/(45B³) − … ] dy
B(1−cos u) = y²/2 − y⁴/(24B) + y⁶/(720B²) − …
⇒ ν_B → y e^{−y²/2} dy ,   ∫₀^∞ y e^{−y²/2}dy = 1 ,  E[y²]=2 ,  E[y⁴]=8 ,  Var(y²)=8−4=4
```

**(ii) `g` 的展开：`g'(0)=0` 是全部关键**

```
g(u) = sin(u)/(2u) = 1/2 − u²/12 + u⁴/240 − …   ⇒   g = 1/2 − y²/(12B) + O(B^{−2})
```

一阶项**消失**（驻点），所以 `Var(g) ≍ Var(y²)·(1/12B)² ≍ B^{−2}`，不是 `B^{−1}`。
（若 `g'(0)≠0`，则 `Var(g) ≍ Var(y)/B ≍ B^{−1}`，`β` 抵消不掉——这正是"为什么必须是 `β^{−2}`"的机制。）

**(iii) 常数**：`Var(g) = Var(y²)/(144 B²)·(1+O(1/B)) = 4/(144B²) = 1/(36B²)`，于是

```
Var(f) = β²s²·W(B) → β²s²/(36B²) = β²s²/(36 β²c²) = tan²(θ/2)/36 =: V_∞(θ)     ∎
```

**与 `o20` 命题 2 的一处中间式勘误（结论不受影响）**：笔记写 `g = 1/2 − y²/(6B)` 且 `Var(g) = 4/(36B²)` —— 这两个**互相矛盾**（`(1/6)²·4 = 1/9`，不是 `1/36`）。正确是 `1/2 − y²/(12B)`、`Var = 4/(144B²) = 1/(36B²)`（漏的 `1/2` 前因子）。`V_∞` 的**最终常数 1/36 是对的**（笔记后一行用的就是 `1/12` 的平方）。

**数值核（`[P2]`）**：`Var(θ,β) = β²sin²(θ/2)W(βcos(θ/2))` 直接算，与 `tan²(θ/2)/36` 比：

| θ | β | B | `Var/V_∞ − 1` | `−2/(15B)` |
|---|---|---|---|---|
| 90° | 50 | 35.355 | `−4.1713e−3` | `−3.771e−3` |
| 90° | 200 | 141.42 | `−9.6678e−4` | `−9.428e−4` |
| 135° | 50 | 19.134 | `−8.4050e−3` | `−6.968e−3` |
| 135° | 200 | 76.537 | `−1.8249e−3` | `−1.742e−3` |

`[C]`：比值 → 1，偏差 `O(1/B)` 且**从下方**趋于 1，`θ` 依赖性只剩 `V_∞` 因子。

## 3. 新网格的 `sup Ψ`：`0.99999986666619`（241 点，`[C]`）

`B` 对数分布 241 点，`[1e−4, 1e6]`（`o20` 是 36 点 `[1e−3,1e4]`）：

```
Ψ(1e−4) = 3.98122e−9      Ψ(1e6) = 0.99999986666619
sup Ψ   = 0.99999986666619 @ B = 1e6          (窗口端点，Ψ→1)
1 − sup Ψ = 1.333e−7  ==  2/(15B)  (精确级数预测)
单调：min dΨ = +8.421e−10 (>0)  ⇒ 全窗口单调不减
Ψ>1 的点数 = 0
```

`(1−Ψ)·B` 的走向（`[P4]`）：`0.5503(B=3) → 0.19225(10) → 0.15018(30) → 0.13816(100) → 0.13381(1e5) → 0.1333338(1e6)`，极限 `2/15 = 0.133333`。

**精确级数（`[P3]`，sympy 有理系数，`B ≥ 1e4` 与求积逐位符到 `3.3e−16`）**：

```
Ψ(B) = 1 − (2/15)/B − (149/315)/B² − (4244/4725)/B³ − …
     = 1 − 0.133333/B − 0.473016/B² − 0.898201/B³ − …

E[h]   = −ε/6 + ε²/30 + 61ε³/1890 + …            (ε = 1/B)
E[h²]  =  ε²/18 − 2ε³/135 − …

```

**⇒ `Ψ < 1` 对大 `B` 是精确的、从下方逼近 1**（不是数值巧合）。这比 `o20` §4.1 的"拟合 `1−Ψ ≍ 0.13/B`"强：系数是**精确的 `2/15`**，符号为负也有证明。

## 4. 核 `6.51`：四个常数逐条自立

把 `β²s²` 与 `Ψ` 的关系写清：`Var(g)=Var(φ)/4`，`φ(w):=√(w(2−w))/arccos(1−w)`，`g=φ/2`（`w = 1−cos u`，`ν_B ∝ φ(w)e^{−Bw}dw`）。
`Ψ = 36B²Var(g) = 9B²Var(φ)`。

### 4.1 尾常数 `C₁` `[T]`，数值 `[C]`

```
ε ≥ 1/B:   ν_B((ε,2]) = ∫_ε² φe^{−Bw}dw / ∫_0² φe^{−Bw}dw
         ≤ [φ(ε)e^{−Bε}/B] / [φ(1/B)(1−e^{−1})/B]      (φ 递减、e^{−Bw}≥e^{−1} 于 [0,1/B])
         ≤ e^{−Bε}/(1−e^{−1})                            (φ(ε)≤φ(1/B))
⇒ C₁ = 1/(1−e^{−1}) = 1.581976707      ✓ 与笔记 1.581977 一致
```

`[C]` 数值扫（`B∈{0.5,1,2,5,10,50,200,1e3}` × `ε=f/B`，`f∈{1,1.5,2,3,5}`）：`sup ν_B((f/B,2])/e^{−f} = 0.999666 ≤ C₁` ✓ **成立（且不紧，真 sup 已接近 1）**。

### 4.2 二阶矩 `3.328` `[T]`+`[C]`

```
E[w²] = 2∫₀² ε ν_B((ε,2])dε ≤ 2∫₀^{1/B}ε dε + 2C₁∫_{1/B}^∞ ε e^{−Bε}dε
      = 1/B² + 2C₁·(2/e)/B² = (1 + 4C₁/e)/B² = 3.327907/B²      ✓ 笔记 3.3279
（Var(w) ≤ E[w²]，同一界。）
```

`[C]` 实测 `E[w²]B² = 0.4745, 1.0596, 1.6857, 1.9310, 1.9866, 1.9987, 1.99987`（`B=1,2,5,20,100,1e3,1e4`）→ 2，**全在 3.3279 内**；界松了 1.66 倍（真值 →2）。

### 4.3 Lipschitz `L(w₁)` `[T]`+`[C]`

`φ'(w) = ((1−w)·b/a − 1)/b²`，`a=√(w(2−w))`、`b=arccos(1−w)`；`φ'(0⁺) = −1/3`，`|φ'|` 在 `(0,2)` 单调↑（`min Δ|φ'| = −1.0e−7`，数值零），故 `L(w₁)=|φ'(w₁)|`：

| `w₁` | 0.3 | 0.5 | 1.0 | 1.2 | 1.5 |
|---|---|---|---|---|---|
| 我 | 0.348297 | 0.360562 | 0.405285 | 0.433602 | 0.503637 |
| 笔记 | 0.348 | 0.361 | 0.405 | 0.434 | 0.504 |

逐位一致 ✓。装配常数 `A_lip = 9·3.327907 = 29.9512`（笔记 29.95 ✓）。

### 4.4 range 界 —— **这里错了** `[T]`

```
g 在 (0,π) 上： sup g = 1/2 (u→0)， inf g = 0 (u→π)   ⇒ 值域 (0,1/2)，长度 1/2
Var(g) ≤ (1/2)²/4 = 1/16   (Popoviciu, 用满值域)
⇒ Ψ = 36B²·Var(g) ≤ 36B²/16 = 2.25 B²
```

笔记的 `0.2971B² = 36·(1/2−1/π)²/4` 对应值域 **`(1/π,1/2)` —— 那是 `g` 只在 `(0,π/2)` 上的值域**。`ν_B` 的支撑是**整个 `(0,π)`**，且 `(π/2,π)` 上的质量并不小（`[P7b]`）：`0.3238 (B=1e−6)`、`0.324 (1e−3)`、`0.304 (0.1)`、`0.159 (1)`、`2.8e−5 (10)`。**在 range 界真正被用到的区域（`B ≲ 2`），那里有 15%–32% 的质量**，值域必须算 `(0,1/2)`。
⇒ 正确 range 界是 `Ψ ≤ 2.25B²`（`≤1` 只到 `B ≤ 2/3`，不是笔记的 `1.834`），**比笔记松 7.57 倍**。

### 4.5 合成

```
C(B) = min( k·B² ,  min_{w₁∈(0,2)} [ A_lip·L(w₁)² + 9B²·min(1, C₁e^{−B w₁}) ] ) ,   C_rig = max_B C(B)
```

| 版本 | `k` | `max_B min(...)` | 位置 | 备注 |
|---|---|---|---|---|
| 笔记的 range 常数 | 0.2971 | **6.696** | `B=4.751`（`w₁*=1.224`，`L=0.4728`） | 与笔记 `6.505` 差 3% |
| **真值域 `(0,1/2)`** | 2.25 | **10.046** | `B=2.114`（`w₁*=1.393`，`L=0.5791`） | 我自立的数 |
| Lipschitz 支单独最大 | — | 10.641 | `B=1.481` | 两版相同 |

**`6.505` 本身也复现不到**：同样的 `A_lip`、同样的 `L` 表、同样的 `C₁`，我精网格得 `6.696`（差 3%，最可能是原文 §4.2 `[P4]` 的 61 点 `B` 网格太粗——`max_B min` 落在两支交叉点上，采样偏一点就差 3%）。
**主要差异不在 3%，而在 range 界：`6.51 → 10.05`（×1.50）。**

**松弛在哪（`[P7c]`）**：`Var(φ)` 与 `L²Var(w)` 的比 = `0.641 (B=2) / 0.623 (3) / 0.665 (5) / 0.770 (10) / 0.896 (30)`，等效斜率 `0.378` vs `L = 0.4725`（`B=2`）。所以笔记自己点出的"`L≈0.4` 而有效斜率 `≈0.19`"是准确的诊断：**把 Lipschitz 步换成二阶 Taylor（或直接用 `Var(φ)` 的精确值）才能把常数压回 1 附近**，而不是靠 range 界。
