## §2 论证的精确形式

把它写成三段论，前提与结论逐条分开（这才是"精确形式"）：

```
P1【常数地板】   ∃ r>0  ∀β :  m_lat(β) ≥ r            （m_lat = m·a，格点单位）
P2【AF】         β → ∞  ⇒  a(β) → 0
P3【量纲嬗变】   m_phys(β) := m_lat(β)/a(β)  =  C·Λ，C 为β-无关纯数
--------------------------------------------------------------
⇒ (P1,P2)   m_phys ≥ r/a → ∞
⇒ (P3)      与"m_phys 有限"矛盾
∴  ¬P1（在 β→∞ 的尾上）        ← 结论只到这里
```

等价的关联形式（G4，同一件事的物理写法）：`⟨O(x)O(0)⟩ ≤ e^{−r x/a}`，`m_phys = r/a` ⇒ 相关长度 `a/r → 0` ⇒ 固定物理间距上关联 → 0 ⇒ 极限测度平凡。**这一步是对的**（`e^{−(x)·m_phys}` 就是 `e^{−rx/a}`）。[T]

**结论的精确形状**：`¬∃ r>0 ∀β`，即 "**m_lat 的 β-下确界是 0**"。这是关于 **P1 这个全称量化 + 常数** 的否定，不是关于"每个 β 有没有隙"的否定。

### §2.1 一处前提不合法（`[NG]`，必须记）

(G2) 把 `I1 的 f₁² ≥ r₀` 并列进前提。**它进不了这条链**：`f₁²` 是**残数**地板，不是质量；`G05:129` 逐字自认「I1 给的是残数地板，非质量 … **不能**单独兑成 `ξ/a` 的界」。
⇒ 论证的合法前提只有 `m_lat ≥ r` 一条。写成"`收数地板`也自否"是 **`[NG]`**。

## §3 矛盾**真的**吗？—— 是（`[T]`），但矛盾对象是 P1

`P1 ∧ P2 ∧ P3` 三者不可同真，这是一个**初等算术矛盾**，没有漏洞：[T]
- 无参数可调：纯 YM 无质量参数，`m_phys/Λ` 是纯数 ⇒ P3 的"C 固定"成立（不是"可以调小"）。
- 没有隐藏的`Λ`-方案依赖：`m_phys` 固定、`aΛ→0` ⇒ `m_lat = a·m_phys → 0`，与 P1 直接对撞。

**⇒ 矛盾真；但"矛盾真"只说明 `P1` 假。**"矛盾存在"不等于"目标被否"——这需要单独论证，而 (G1) 没有给。

## §4 (a) 的决定性一步：给出**见证模型**（扩窗 ∧ P2 ∧ P3 相容）

造一个模型，同时满足"每个 β 有隙"与 P3，看会不会矛盾：

```
取   m_lat(β) := a(β)·Λ        （即 m_phys ≡ Λ，C=1）
   · 每个有限 β：m_lat(β) > 0                          ⇒ 【逐 β 有隙】✓
   · β→∞：m_lat → 0                                    ⇒ P1（常数地板）假 ✓
   · m_phys ≡ Λ 固定                                     ⇒ P3 ✓
⇒ 无矛盾。⇒ 「扩窗（逐β有隙）」与 P2、P3 相容 ⇒ **不被 §3.2 否证**。  [T]
```

**限定（不许省）**：这是**相容性见证**，证明的是"没被否证"，**不是**"扩窗可达"、更不是"YM 有隙"。它只否掉"§3.2 否证了扩窗"这一读法。

### §4.1 更狠的一条：§3.2 会否证 g05 自己的新靶

(G6) 逐字把"扩窗"**重定义**为 `m_lat/(aΛ) ≥ c₀`；而 `M05-RATIO:168` 判「新靶确实避开自我否定」`[T]`。
⇒ 若 §3.2 否证的是"扩窗"，它同样否证 g05 自己给出的**唯一合法代替靶**。
⇒ 二者不能同真。**唯一自洽的读法：§3.2 的 no-go 只打常数地板，(G1) 的标题是错标。** [T]

## §5 ★ 第二条独立发现：这个机理**连那条死路都不覆盖**（窗口是有限的）

`RUNBOOK §19.2`（`LOOP-RUNBOOK:8655–8657`）逐字：

```
它们都在做同一件事：把 β 窗口从 1/48 扩到 2.5
⇒ 而 g05 证明扩窗在原理上自我否定（m_phys ∝ 1/a 会发散）
⇒ 所以 19 条不是"技术不够"，是"目标本身错了"
```

**这是 non-sequitur**（`[T]`）：
- 机理要 `a→0`，而 `a→0 ⟺ β→∞`（`LOOP-RUNBOOK:8626`）。
- 那条路的终点是 **β = 2.5，有限**。`aΛ(β) = exp(−12π²β/(11N²))·(g²/16π²)^{51/121}` 对**一切有限 β** 是有限正数 ⇒ `a(2.5) > 0`，`r/a(2.5) < ∞`。
- ⇒ 在 `[1/48, 2.5]` 上，**连常数地板都不自否**：它只是"更强且大概为假"（`m_phys ≈ 5.8e3·r·Λ`，两圈、方案常数未核，`[E]`），**不是"自相矛盾"**。

**⇒ 自否只发生在 β→∞ 的尾端。** 把"扩到 2.5"的 19 条路线一律用尾端机理判死，是拿一个够不着的理由结案。
（判法：对"只要 2.5 上有隙、不取 `a→0`"的路线，§3.2 **不覆盖**；对"要 `a`-一致常数地板、再取 `a→0`"的路线，§3.2 **覆盖**。19 条要逐条分，不能一句"扩窗全死"。）
