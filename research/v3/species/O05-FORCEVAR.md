## 0. 判死线（先读这段）

**答：右侧可以被 β-无关的量控制，但只在"条件切片测度随 β 收缩"的那一格；控制的常数在 Haar 切片（`cos(θ/2)=0`）上发散，而恰恰在那张切片上 `E[H]≡0`。**

**β-幂（单 plaquette `SU(2)` 切片 `ξ₃=0`, 边界 holonomy `θ`）**：

| 格 | `k = dlogVar/dlogβ` | `m = dlogE[H]/dlogβ` | 大 β |
|---|---|---|---|
| `cos(θ/2) ≠ 0`（非退化、切片测度收缩） | **`k → 0`**（实测 β:50→200 得 `0.0023`，θ=π/2；`0.0048`，θ=3π/4） | **`m = 1`**（实测 `1.0036`，θ=0，β:50→200） | `Var→Var_∞<∞`，`E[H]→0.25βcos(θ/2)` ⇒ **右侧输**，自动成立 |
| `cos(θ/2) = 0`（θ=π：切片测度**恰为 Haar**，β-冻结） | **`k = 2` 精确** | `E[H] ≡ 0`（不是幂，是恒零，因 `H_vv = βcos(θ/2)sin(r/2)/(2r)`） | `0 ≥ β²V₀ − W_geo` ⇒ 在 `β*=4.30661` 精确穿越 |

⇒ **判 `(a)`（主判）**：非退化格上 `Var` 的幂 `<` `E[H]` 的幂 ⇒ 大 β 自动，只需小 β（且实测最坏比值出现在 `β≈1–6`，见 §4）。
⇒ **(b) 只在退化的 Haar 切片上成立**，且那里 `E[H]` 恒零、`Var` 幂 2 是"冻结律"的产物，**不与 N=3 的 MC（δ 递增）矛盾**——它复现的是 `H1A-EXACT` 的 `β*>4.30661`，不是物理点。
⇒ **(c) 不需要**（同幂只在退化格上出现，且不是同幂而是 `m` 未定义）。

**"谁错"（若有人按 `k=2 > m=1` 判"大 β 必败"）**：错在把 `Var(βg|0)` 写成 `β²Var(g|0)` 而令 `g|0` 的律 β-无关。**条件律随 β 收缩**（切片上的横向宽度 `∝β^{-1/2}`，见 §3），这一步给出额外的 `β^{-2}`，把 `k` 从 2 拉到 0/1 之间。冻结律只在 `cos(θ/2)=0` 上精确成立。**MC 对，幂次计数错。**

## 1. `G_v` 与 `Φ'` 的精确表达式与 `β`-依赖

`GPP-STRUCT.md §1.3` / `ch05:230–240`（`eq:split`，逐字）：

```
G''(0) = E_μ[H_vv + Φ'' | ξ=0] − Var_μ(G_v + Φ' | ξ=0) = Δ_dyn + W_geo + X
Δ_dyn = E[H] − Var(G_v),  W_geo = E[Φ''] − Var(Φ'),  X = −2Cov(G_v,Φ'|0)
V = S_W + Φ,  Φ = −log J (平坦图 X=log U 的 Haar Jacobian),  H = Hess V,  ' = ∂_v
```

`ch05:196–206`（`eq:wgeo`）：`Φ = Σ_{i<j} g(λ_i−λ_j)`，`g(d) = −2log(sin(d/2)/(d/2))`，`g''≥1/6`；`Φ''⪰0` **逐点、任意测度、任意 β**（Lemma B）。

**逐项 β-依赖（`[T]`，因为 `S_W = β·S_W^{(0)}` 而 `Φ` 不含 β）**：

| 项 | 精确式 | β-依赖 |
|---|---|---|
| `G_v = ⟨v,∇S_W⟩` | `β·⟨v,∇S_W^{(0)}⟩` | **线性 `β^1`**（逐点） |
| `Φ' = ∂_v Φ` | `Φ` 的逐点导数 | **`β^0`**（逐点，逐构型） |
| `H_vv` | `β·∂_v²S_W^{(0)}` | **`β^1`**（逐点） |
| `Φ''` | `∂_v²Φ ⪰ 0` | **`β^0`**（逐点） |

**本题的结构要点（`[T]`）**：右边两个**被加项**的幂是 `β^1` 与 `β^0`；左边 `E[H+Φ'']` 的幂也是 `β^1` 与 `β^0`。**幂差不可能来自被加项，只可能来自"条件律随 β 移动"**——这就是 §3 的唯一机制。`GPP-STRUCT §4(b)` 的"`E[Hess V]=E[∇V⊗∇V]` 只对无条件期望成立"是同一件事的矩阵版。

**单 plaquette 切片上的精确式**（`H1A-EXACT §2.1` 约定：`ξ∈R³`、`S = β(1 − cos(ρ/2)cos(θ/2) + sin(ρ/2)sin(θ/2)u)`、`J = sin²(ρ/2)/ρ²`、`v=e₃`、条件化 `ξ₃=0`；`u=ξ₃/ρ`、`ρ=r`、`u=0` 于切片）——`[T]`，BLAS 无关，纯解析：

```
G   = ∂_3 S   |_slice = β sin(θ/2) sin(r/2)/r
H   = ∂_3²S   |_slice = β cos(θ/2) sin(r/2)/(2r)      (θ=π ⇒ ≡0)
Φ'  = 0       (Φ 径向 ⇒ 切片上逐点为零 ⇒ Var(Φ')=0, X=0)
Φ'' = ∂_3²Φ   |_slice = 2/r² − cot(r/2)/r             (r→0 极限 = 1/6 = N/12, N=2)
测度 w(r)dr = 2π sin²(r/2)/r · e^{−β(1−cos(r/2)cos(θ/2))} dr
```

**对账（`[C]`，与存档逐位）**：θ=π 时脚本给出 `Var = β²·0.0110593`（β=1,2.5,6,10 全同）、`E[H] ≤ 1.1e−16`、`E[Φ'']=0.2051153` — 与 `H1A-EXACT §2.1` 的 `V₀=0.0110593`、`W=0.2051153`、`β*=sqrt(W/V₀)=4.30661` 一致（`o05_var_scaling.log [CHK]`）。

## 2. 条件 Poincaré：`λ` 是什么？已知下界？

**定义**（`ch08-immune.tex:138` 的 "Poincaré constant of the 1D marginal"）：给定条件测度 `μ(·|ξ=0)` 在切片 `S₀={ξ:⟨v,ξ⟩=0}` 上，

```
Var_μ(f|0) ≤ (1/λ)·E_μ[|∇_{S₀} f|²|0] ,      λ = λ_cond(v;β) = inf spec(−Δ_{S₀} + ∇V·∇_{S₀}) 的底
```

即"切片上 `e^{−V}dX` 的条件 Poincaré/BL 常数"。取 `f = G_v+Φ'` 得

```
Var(G_v+Φ'|0) ≤ (1/λ)·E[ |Hess V·v|²_{S₀} | 0 ] ,   |∇f|² = ⟨v,(Hess V)²v⟩  (切片切向部分)
```

**已知下界（`[T]`，逐条核过）**：

1. **`Φ'' ⪰ 0` 逐点**（`ch05:207–209` Lemma B；`g''≥1/6`）⇒ `λ ≥ 0`，**β-无关**。但这是 `v`-**法向**（被条件化掉的那个方向）的界，落在 `G''` 的曲率侧，**不控制切片**。
2. **`Hess Φ ⪰ (N/12)I`** 只在 `su(N)` 的**非 Cartan（根）方向**成立；`Φ` 依赖本征值 ⇒ Cartan 方向 `Hess Φ = 0`。⇒ 作为**算子**，`Hess Φ ⪰ 0`，**没有正的 β-一致下界**（`V2-TRUE-BOUND §142` 同一读法）。
3. `Hess S_W` 的特征值可负：`λ_min(Hess S_W) = −g|B| < 0`（Savvidy；`CLAUDE.md §5`，W4 实测 7.1% 负模）。⇒ **切片上的 `λ_cond` 没有 β-一致正下界**；`λ_cond > 0` 只在"条件化点落在非退化极小"的切片上成立，并且它**随 β 增长**。

**实测 `λ_cond`（`[C]/[M]`，径向 m=0 模，CDF 变换 + 三对角本征，`o05_lambda.log`）**：

| `θ` | β=1 | 2.5 | 6 | 10 | 50 |
|---|---|---|---|---|---|
| π/2 | 0.711 | 0.865 | 1.250 | 2.451 | 15.30 |
| π | **0.643** | **0.643** | **0.643** | **0.643** | **0.643** |

**读法（关键）**：θ=π 时切片测度**恰为 Haar**（`S|_slice ≡ β` 与 `r` 无关）⇒ `λ_cond = 0.64301` **严格 β-无关**；而 `E[|∇f|²|0] ∝ β²` ⇒ BL 界 `∝β²`，与 `Var ∝β²` 同阶（`bound/Var = 1.026`，界**锐到 2.6%**）。θ<π 时 `λ_cond` 被 β 抬起，`E|∇f|²` 只 `∝β^{0..1}`，界**停滞为常数**（θ=π/2：`0.0043, 0.0166, 0.0383, 0.0355, 0.0314`；`bound/Var ∈ [1.02, 1.51]`）。

⇒ **`λ` 的答案**：`λ = λ_cond(v;β)`，**已知下界只有 `0`（β-一致）**；正的 β-一致下界不存在，且它与 Savvidy 墙同源。**所以 BL 路线不能给"β-无关的 `Var` 上界"当定理；它给的是"同 β 的界"，其 β-标度恰好与 `Var` 相同。**这与 `GPP-STRUCT §4(b)` 的判词（BL 需 `Hess⪰0`=墙）逐字一致，本节把它量化了。

## 3. `β`-标度：`k` 与 `m`

**机制（`[T]` 的定性 + `[C]` 的定量）**：切片上 `ρ_v(a;β) ∝ ∫e^{−βS_W^{(0)}−Φ}δ(⟨v,ξ⟩−a)`；
- 若条件化点是切片作用的**非退化极小**：`β→∞` 时切片律 → 以该点为中心的 Gaussian，横向宽度 `∝β^{−1/2}`。于是
  `Var(β g|0) ≍ β²·Var_{Gauss(β)}(g) ≍ β²·β^{−1} = β^1`（若 `g'(0)≠0`）；单 plaquette 另有 `g'(0)=0`（`g=sin(r/2)/r`，`r=0` 是切片径向的驻点）⇒ `Var(g) ≍ Var(r²) ≍ β^{−2}` ⇒ **`Var ≍ β^0`**。
- 若切片律 β-冻结（`S_W^{(0)}|_slice ≡ const`，即 `cos(θ/2)=0`）⇒ `Var = β²·Var_Haar(g)`，**`k=2` 精确**。
- `E[H] = β cos(θ/2)·E[sin(r/2)/(2r)|0]`，括号 → `1/4`（`r→0` 极限 `g(0)=1/2` 的一半）⇒ **`m=1`**（`E[H]/β → 0.2496` at β=200, θ=0）。

**实测幂（`[C]`，`o05_var_scaling.log [P2]`）**：

同表 `m`：θ=0 全部 `1.076/1.102/1.077/1.042/1.024/1.011/1.0036`（→1 精确）；θ=π/2 的 `m` 同（`E[H]` 只差常数因子 `cos(θ/2)`）。**`m=1` 是精确幂（`[T]` 的结构 + `[C]` 收敛）。**

⇒ **`k → 0 < m = 1`**。`Var` 被**它自己的上确界** `sup_β Var = Var_∞(θ)` 控制：**这确实是一个 β-无关的量**（`[C]`：θ=π/2 时 `0.0278`，θ=3π/4 时 `0.1618`，由 `[P4]` 的 7 点序列单调收敛）；但 **`Var_∞(θ) → ∞` 当 `cos(θ/2)→0`**（θ=π 时 β=100 已 `110.6`）。**不是 θ-一致常数。**
