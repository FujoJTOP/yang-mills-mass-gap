## §1 一行式（`h`、`sup` 域、量词）

```
(eq-floor)   ∀L≥L₀   ∀β≥β_A   ∃c=c(L,β)>0   ∀a∈(0,a₀(L)] :
        ρ^{ren}_{L,a,β} := ( sup_{z∈W_a} |C_2^{ren}(z;L,a,β)| / |h(z)| )^{1/2}  ≥  c
  W_a      := {z : a<|z|<L}            （C-class；F-class 换成 {r₀<|z|<L}）
  C_2^{ren} := (U2) 同方案减除后的连通 2-点核，O = ¼trF²
  ρ        := inf{ρ>0 : |C_2^{ren}(z)| ≤ ρ²|h(z)| ∀z∈W_a}   （极小常数读法，HX1:0.1）
  ⟺  ∃z₀∈W_a : |C_2^{ren}(z₀)| ≥ c²|h(z₀)|                  （非抵消形，0.3）
```

- **`h`**：Ursell 树界的**成对**核（`|C_n| ≤ ρ^n Σ_T ∏_{edges}|h|`，`HS-L3-9:41`）；UV 端 `|h|=|z|^{-8}`、有隙时乘 `e^{-m|z|}`；按 `∫_{B_L}|h|` 归一一次，**不随 `a`、`β` 重标**（`HX1:1.3`）。
- **`sup` 域**：去心窗 `a<|z|<L`（接触点 `|z|≲a` 排除，`HS-L3-9:61`）；只取一个见证点即可，故 `ρ` 是 `sup`-型**范数**，不是期望、不是方差（`HX1:0.2`）。
- **量词**：`c` 在 `a` **之前**（`a`-一致）；`L` 固定（`L3` 的窗口，`HQ1:72`）；`β=β(a)` 沿 RT 被 `a` 决定（`HQ1:48`）⇒ `∀β` 是**窗标签**，不是自由量词；两种读法（固定 `β` / 沿 RT）都记，不互代。
- **为什么必须带 `h`**：`h` 未钉时 `h∝|C_2|` 使 `ρ≡1`，地板自动真（0.2）⇒ 地板只在 `h` **外生**钉住时才有内容。

## §2 三路

### 2.1 (a) 由 `(U2)` 的减除方案直接给 ⇒ **`[NG]`**

- `(U2)=L1+L2` 的全部内容是 **`p=0`**（`HS-L3-6:0.3,0.4`）——**幂面**；地板是**振幅面**，`HS-L3-6:0.6` 逐字「缺的是振幅」。
- **C-class**：`s_a=c₂(a)δ` 支撑在 `|z|≲a` ⇒ `W_a` 上 `C_2^{ren}=C_2^{bare}` ⇒ `ρ^{ren}=ρ`（`HX1:0.2`）。减除既不造也不毁振幅。
- **F-class**：`s_a` 支撑到 `r₀`、`r₀` 不随 `a`（`HY2:1.2`）⇒ 地板变成 `(r₀,L)` 上的 **IR 振幅**（`r~r₀`），不再看 UV 系数。
- **二难**（0.5）：固定 `s_a` ⇒ 地板由残余 `|κ(a)−c_s|` **免费**满足，但 `M`、`A` 都 `∝a^{-4}` ⇒ 包在 R3/结论端散；跑动 `s_a` ⇒ 残余 `O(g⁶)`、`A=O(1)`，地板回到 IR 振幅。⇒ 出口：固定读法**空**，跑动读法**同格重述**，没有第三种。
- **下一手**：把 `s_a` 的读法写进 `HX1:2.2` 那三行充分包的**第一行之前**；C-class 的地板按「裸振幅」记账，不写成「减除后」。

### 2.2 (b) 由 BKAR/FRD 的现成界 ⇒ **`[NG]`**

- **方向**：`(C-form)` 的树界 `C_n ≤ n!e^n(ρ/c_k)^n𝒢^{n−1}|B_L|`（`HS-L3-9:46`）对 `ρ` **单调增** ⇒ 任何 `ρ` 的上界都能消费，地板是反号不等式；`sup` 的下界等价于「某点不抵消」，绝对值的上界给不出见证。
- **角色**：KP/BKAR 收敛要**小活动度**；`HT7:52` 逐字「FRD controls ranges and yields uniform exponential-distance decay of polymer activities」——它控制的是**范围与衰减**，不是振幅。
- **速率**：4D FRD 与 4D BKAR 都 `[T]`，但 Thm 4.5 的速率是 `µ/L^j`，跨标度保留定值要 `Δ₀>0`（`HY1:11–13,58–64`）⇒ 这是 **IR 速率**轴，与 `|z|→a`/`r₀` 处的振幅不同轴（`HZ3:14,24`）。
- **另**：`β=2.5` 处树界可用性本身 `[NG]`（`HS-L3-9:84`）⇒ 即便只当上界用，在靶窗也不可直接消费。
- **下一手**：把 BKAR/FRD 的用途钉在 `𝒢` 的 `a`-一致上界（M2）；地板改由「单点不抵消」供给，不走展开。

### 2.3 (c) 造反例判假 ⇒ **自由场不否证、混合族否证**

| 族 | `ρ` | 判 | 说明 |
|---|---|---|---|
| 无质量自由场（固定归一） | `√c` | **`[T]`** | **不否证**；C/F 两类同值（`HX1:0.5`） |
| 混合/双峰 `μ_w=wμ_Gibbs+(1−w)μ_{β=0}` | `√w·ρ_Gibbs` | **`[T]`** | **否证**；同族 `S_w=√w·S_Gibbs→0` |
| `β=0` 乘积测度 | `0` | **`[T]`** | 上族 `w=0` 端点；`C_2≡0` 于去心窗 |
| C-class + AF Gaussian | `g²√c` | **`[T]`**（Gaussian）/ **`[NG]`**（YM 推论） | 地板被测量 = UV 系数 `κ(a)≍g(a)^4` |

- **为什么自由场不是反例**：它的振幅不随 `a` 变（`ρ=√c`）；地板是振幅命题，不是衰减命题。⇒ 「地板在自由场通过」是 `L3` 的要求（`HQ1:63`，自由场必须满足 `L3`），不是酸测失败——但它因此**不携带**相互作用信息。
- **为什么混合是反例**：`ρ²` 是 `|C_2|` 对测度的仿射泛函的上确界 ⇒ 对权重**正齐次**；`w→0` 同时杀地板与 `S` ⇒ 两者互相独立（与 `HY2:3.1` 的 `a⁴|h|` profile 同型：谓词层见证，不声称来自单一 Gibbs 测度）。
- **下一手**：在 2D YM（`χ₂` 精确）与单片（`G″` 多项式）上取 `ρ` 的值；若 2D 也给 `ρ>0`，则地板只能靠「C-class + AF」这一支判假，活窗口仍留。
