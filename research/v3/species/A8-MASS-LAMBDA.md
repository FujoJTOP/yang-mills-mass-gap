**(c) 触发。** `m/Λ` 的语料值是 **`6.1×10²`（SU(3) `β=6.00`）与 `7.1×10²`（`β=6.30`）**，比 1 高 **2.5–2.9 个数量级**；SU(2) `β=2.5` 给 `2.9–4.7×10²`（三个质量估计共用同一个 `Λa`）。**(a) 不成立**（值不在 `O(0.1–3)`）。**(b) 未触发**——这是本次的新信息：SU(3) 两点 `612±50` vs `709±127`，差 `0.71σ`，**标度性在两圈层面自洽**（无量化检验：`a(6.30)/a(6.00)` 两圈预言 `0.713`，实测 `m a` 之比 `0.826`，差在 18% 误差内）。

**那么 `6×10²` 从哪来**：`Λ_2loop(β=6.0) = 5.1 MeV`（用 `a⁻¹=2.91 GeV`，`probe-m/REPORT.md:150` 的 Necco–Sommer `r₀/a=7.380`），而物理 `Λ_MS^{(0)} ≈ 200–240 MeV`——差 **40–47×**。这是**裸格点耦合到 MS-bar 的 scheme 常数**：`m/Λ` 对 `1/g²` 的常数平移按 `e^{δ/(2b₀)}` 放大，`1/(2b₀) = 7.18`（N=3），`δ(1/g²)=0.5` 就搬 `36×`。要把它从 `613` 拉回 `O(1)` 只需 `δ(1/g²)=0.894`——一个完全普通的匹配常数。**语料没有这个匹配，所以 `c = m/Λ` 不是纯数，是 scheme-条件数。**

**一句话**：形状对了（常数型、`β`-一致），**数值没定**——`c` 只能报到 `c × [scheme 常数]`，而 scheme 常数不在语料里。a7 要的"纯数 `c`"在语料里**取不出来**；缺的是**一步 scheme matching**，不是缺数据。

## 1 · 归一逐步核（每个等号都落到数上）

`β`-函数标准形式（本文唯一口径，不引任何别的约定）：

```

b₀ = 11N/(3(4π)²) = 11N/(48π²)
b₁ = 34N²/(3(4π)⁴) = 34N²/(3·(16π²)²) = 34N²/(768π⁴)      [Nf=0]
```

- 第 5 步的 `N`-无关性是恒等式 `[T]`：`(34N²/3)/(11N/3)² = (34/3)(9/121) = 102/121`。**`b₁/b₀²` 不随 `N` 走**——凡写出 `N`-依赖的 `b₁/b₀²` 就是错的。
- 第 6 步是今天最容易丢 `½` 的位置：指数是 `b₁/(2b₀²) = 51/121`，**不是** `b₁/b₀² = 102/121`。丢这个 `½` 会把 `(2b₀g²)^{-0.4215}` 变成 `^{-0.8430}`，`m/Λ` 乘 `0.44`（`[C]`，见 log `[10]`）——量级不变，但数值全错，故单列。
- 数值：`b₀ = 0.046439 (N=2) / 0.069658 (N=3)`；`b₁ = 0.001818 / 0.004090`。
- 耦合口径：`β_W = 2N/g²` ⇒ `g² = 4/β`（SU(2)）、`6/β`（SU(3)）。
- 两圈解 `aΛ = e^{−1/(2b₀g²)}(2b₀g²)^{−b₁/(2b₀²)}` 与**精确二圈闭式** `aΛ = e^{−1/(2b₀g²)}[b₀g²/(1+(b₁/b₀)g²)]^{−b₁/(2b₀²)}` 在 `g²=1` 差 `−27.1%`（`[C]`）。这是标准的截断差，**不改量级**，但说明单点 `m/Λ` 的理论误差本身就在 30% 级——下面的 `0.71σ` 一致性别读得太硬。

## 3 · 一致性检验

- **SU(2)：只有一点 ⇒ 无法检验。** 三个质量估计（`1.2562 / 0.8467 / 0.770`）共用同一个 `Λa`，所以它们的 `m/Λ` 散布（`471 / 317 / 288`，`1.63×`）**全部来自质量估计的散布**，与标度性无关。这一格**不能**当"两点一致"来报。
- **SU(3)：两点可检，结论是一致。** `612.5 ± 50.2`（`6.00`）vs `709.4 ± 127.3`（`6.30`）：差 `−97 ± 137` ⇒ **`0.71σ`**。等价的、与 `Λ` 归一无关的检验：两圈预言 `a(6.30)/a(6.00) = 0.713`，实测 `m a` 之比 `0.826`（同物理 `m` 假设），差 16%，在 18% 误差内 ⇒ **两圈的 `β`-依赖对了**。

这条把 (b) 排除了。**(b) 不成立是本文件最该记的一条**：`§10.4` 的"无 `ξ/a ≥ 2` 实测"说的是**关联长度**不够长，不是**跑动**不对。本检验只用 `Λa` 的比值（与绝对归一无缘），它通过；所以语料在这两点上**是**在微扰跑动曲线上的。

## 4 · 为什么会 `> 1`：不是算术，是 scheme

- `[C]` `Λ_2loop(β=6.0) = 1.7518e−3 / a`，`a⁻¹ = 2.91 GeV` ⇒ **`Λ = 5.1 MeV`**。物理 `Λ_MS^{(0)} ≈ 200–240 MeV` ⇒ 差 **40–47×**。
- `[C]` 敏感度：`∂ln(m/Λ)/∂(1/g²) = 1/(2b₀) = 10.77 (N=2) / 7.18 (N=3)`。`δ(1/g²) = 0.5` ⇒ `m/Λ` 乘 `e^{5.38} = 218×`（N=2）/ `e^{3.59} = 36×`（N=3）。**在 `g² ≈ 1` 处，`Λ` 是个指数放大过的量**，`m/Λ` 继承这个放大。
- `[C]` 要把 `613` 拉回 `1`：`δ(1/g²) = ln(613)·2b₀ = 0.894`。**普通的 `O(1)` 匹配常数**，不是病态要求。
- `[C]` 结构上限：`aΛ(g²)` 在 `(0,200]` 上最大值 **`0.4558`（`g² = 17.0`，N=3）**；`g² → ∞` 时回落（`g²=50` 给 `0.382`）。故 `m/Λ ≥ (m a)/0.456`：**取实测 `m a ∈ [0.77,1.26]` 得 `m/Λ ≥ 1.7` 恒成立**。也就是说在这套公式里 `c < 1` 与 `m a ≈ 1` **不相容**；而 (a) 要的 `O(0.1–3)` 下界那段只有把 `g²` 推到 `≳5`（`β_W ≲ 1.1`，深度强耦合、两圈公式早已失效）才够得着。**这是形状层的 `[NG]`：公式把 `m/Λ` 与 `g²` 绑死，语料的 `g²` 落在陡峭支上，`m/Λ ~ 10²`–`10³` 是必然，不是异常。**

## 5 · 判定与对 a7 的后果

| 判据 | 结果 |
|---|---|
| (a) `m/Λ ∈ O(0.1–3)` 且两点一致 | **否**（`6×10²`；而且两点一致这条本身**通过**） |
| (b) 不同 `β` 的 `m/Λ` 相差很大 | **否**（`0.71σ`） |
| (c) `m/Λ > 1` ⇒ 物理可疑，查归一 | **是**（高 2.5–2.9 个量级）；归一查过，**算术无错**，差的是 scheme |

**对 a7 的直接后果**（`[M]`）：

1. **形状成立、数值未定。** 常数型 `m ≥ cΛ` 的 `β`-一致性在 SU(3) 两点上是**被数据支持**的（`0.71σ`），这比 `A7-EXPONENT` 预期的要好；但 `c = m/Λ` 只能报到 `c × [scheme 常数]`，语料没有 `δ(1/g²) ≈ 0.9` 的匹配，所以 `c` **不是纯数**。
2. **"取 `c = 613`"是自校准的空话。** 那等于把 `m a ≥ 613·aΛ` 写回 `1.073 ≥ 1.073`：在标定点上是恒等式，在别的 `β` 上只复述"两圈跑动 + 常数质量"。它不给出 `a`-一致的物理下界（`Λ_2loop` 本身随 `g→0` 趋于 0）。
3. **缺的那一步是精确的**：`bare g² ↔ MS-bar g²` 的常数项（`δ(1/g²) ≈ 0.9`，或等价地 `Λ_MS/Λ_L` 的有限部分）。补上它，`m/Λ_phys ≈ 3.12 GeV / (0.20–0.24 GeV) ≈ 13–16`（`m a = 1.073` 当 `0++` 用；若按物理 `m(0^{+}) a = 1.71/2.91 = 0.588` 修正，则 `≈ 8–9`）——**仍是 `> 3`**，所以即使归一补对，(a) 的 `O(0.1–3)` 也不成立，`m` 确实"超过 `Λ`"十来倍。这本身不矛盾（`m/Λ_MS^{(0)} ≈ 8.6` 是纯 YM 的常识值），但它意味着 `c` 是个 **`O(10)`** 的数，不是 `O(1)`——`A7-EXPONENT` 里"`c` 是纯数"的写法要改成"`c = O(10)`，且含 scheme 常数"。

**未取数 / 未核**（`[NG]`）：语料**没有** `Λ_MS/Λ_L` 的匹配常数（检索式：`grep -r "Lambda_MS\|Lambda_L\|2.66\|28.8" research`）；`a⁻¹(β=6.0)=2.91 GeV` 是借 Necco–Sommer `r₀/a=7.380` + `r₀=0.5 fm` 的**外部锚**，非本组直测（转录：`research/probe-m/REPORT.md:150`）。
