## 0 · 判词

**① `48` 的来历（第一问，`[V]` 逐字）**：`48 = 16(d−1)` **不是某个误差界、不是导出半径**，它是 SZZ **唯一假设**（Assumption 1）的**等价改写**：`K_S = (N+2)/2 − 1 − 8N|β|(d−1) > 0`（`SU(N)` 支）⟺ `|β| < 1/(16(d−1))`，`d=4` ⇒ `|β| < 1/48`。论文自己把 (eq:a) 称作 "**the strong coupling assumption**"。`SO(N)` 支更差：`1/(32(d−1)) − 1/(16N(d−1))`。**语境是假设（充分条件），不是定理结论**。`[V]`

**② `2.4Δ` 的结构（`[T]`+`[E]`，本轮新拆）**：
```
16(d−1) = 2 · 8(d−1)          ← 8(d−1) = Lemma 4.1 的 Hessian 常数；2 = 1/(Ric 密度 ½)
8(d−1)  = Δ + 4               ← Δ = 4(2d−3) 去掉"自身 4 条 link"后就是每片 4 link × 每 link 6 片
⇒ 48    = 2Δ + 8      ⇒  48/Δ = 2 + 8/Δ = 2 + 2/(2d−3)   d=4⇒ 2 + 2/5 = 12/5 = 2.4
```
`2` = **SU(N) Ricci 曲率密度的倒数**（源文 `Ric(u,u) = (α(N+2)/4 − 1)|u|²`，`α=2` ⇒ 恰 `N/2`，密度 `½`，两处 `+2/2` 与 `−1` 精确对消）；`8/Δ = 0.4` = **自身 link 关联富余**（SZZ 数全部 24 条关联，动物数只数 20 条非自身）。两块都**有结构**，但 `2.4` 是"曲率归一 × 格子计数"的比，**不是 YM 物理常数**。`[T]`

**③ Δ 能变小吗（第三问，判）**：**`2.4Δ > eΔ` 永远不成立 —— Δ 全抵消**：`eΔ < 48 = 2.4Δ ⟺ e < 2.4 ⟺ e < 12/5`，与 Δ 无关。`48/e = 17.6582`（"Δ 必须 < 17.66"）只是同一不等式的改写，**不是杠杆**；而 `Δ = 20` 是 `L=6` `T⁴` 上穷举实测的**唯一值 `{20}`**（`ADJ2:43`、`C05:75`、`TN2:107`），`d=4` 上不可降。缩小 Δ 的唯一真实含义是**改 d**（`Δ(3)=12 < 17.66` ⇒ `eΔ/48 = 1.0194`）⇒ **改题**，不是改进常数。`[T]`

**④ `48` 硬不硬（判死线）**：
- **(a) 触发** —— `48` 是 SZZ 的**精确分母**（Assumption 1 是**等式** `K_S = N/2 − 8N|β|(d−1)`，`K_S>0` 的边界就是 `1/(16(d−1))`，零代数松弛）；两个输入各自也精确：`Ric = (N/2)|X|²` 是**等式**（源文 L1943/L1951，引 AGZ (F.6)），`8(d−1)` 是**精确关联计数**（L1616）。⇒ **在 Bakry–Émery / Wang `Ric−Hess ≥ K_S` 这条路线内，`48` 是硬的**。`[T]`
- **(b) 不触发** —— 语料与源文内**无**更好的 `16(d−1)` 版本（只有更差的 `SO(N)` `1/(32(d−1))`；OS78 只给未量化常数）。且**即便有也不改战局**：`48` 在 KP 不等式 `λ_T < 48` 里是**右端天花板**，抬它只把右端放松；缺口在**左端 `λ_T`**（实测 `λ_* ≈ 25.2 < 48`，`TN2 §4`），那需要"动物常数定理"，语料无。`[T]`+`[X]`
- **(c) 不触发** —— `2.4` **有**结构（①式 `2 + 2/(2d−3)`，且 `2`/`0.4` 各有明确槽）；但**没有** 12-结构（`12 = 4(d−1) = 48/gcd`，与立方体 12 条边无关，`TN2:80` 已裁）。`[T]`

### 1.3 所以 `48` 的精确来历（三行）

```
K_S(SU(N)) = (N+2)/2 − 1 − 8N|β|(d−1) = N/2 − 8N|β|(d−1)          (两处常数精确对消)
K_S > 0  ⟺  |β| < (N/2)/(8N(d−1)) = 1/(16(d−1))
d = 4    ⇒  |β| < 1/48 = 0.0208333…
```

## 2 · 第二问：`2.4 = 48/Δ` 的结构（本轮新拆）

### 2.1 两个量的组合含义

```
Δ  = 4 · (2d−3) = 4 · (2(d−1) − 1)
   = [4 link/片] × [每 link 2(d−1)=6 片 − 自己]        d=4 ⇒ 4·5 = 20      (P3-FULLREP-KP:116)
8(d−1) = 4 · 2(d−1) = [4 link/片] × [每 link 6 片]
   = Δ + 4            ← 差的正好是"自己那 4 条 link"
```
⇒ 两者**数的是同一批 link–plaquette 关联**，`Δ` 去对角（非自身），SZZ 的 Hessian 计数**不去对角**。

### 2.2 拆开 `16 = 2 · 8`

```
48 = 16(d−1) = 2 · 8(d−1) = 2 · (Δ+4) = 2Δ + 8              [T]（整数恒等，本轮 py 核）
48/Δ = 2 + 8/Δ = 2 + 2/(2d−3)     d=4 ⇒ 2 + 0.4 = 2.4       [E]
```
| 槽 | 值 | 结构含义 | 标签 |
|---|---|---|---|
| `2` | `1/(½)` | SU(N) **Ricci 密度**的倒数：`Ric = (α(N+2)/4 − 1)|u|²`，`α=2` 时 `(N+2)/2 − 1 ≡ N/2`（`+2/2` 与 `−1` 精确对消）；是**单位颜色曲率**，格子无关、`N` 无关 | `[T]` `[V]`(L1943) |
| `8/Δ = 0.4`（`=2·(4/Δ)=2/(2d−3)`） | `(8(d−1) − Δ)/Δ · 2` | **自身关联富余**：SZZ 数 24 条关联，动物渡越只数 20 条非自身；富余比例 `4/Δ = 1/(2d−3) = 1/5` | `[T]` |

**⇒ `2.4` 的意义**：`2.4` = 「曲率归一的 `2`」+「格子自身关联的 `0.4`」。**它有结构，但两半都不是 YM 物理量**：换 SZZ 的 `β` 归一化 `48` 就变，`2.4` 随之变（`TN2:153`）⇒ 它是**归一化相依的组合比**，不是普适常数。

## 3 · 第三问：若 Δ 能变小，`2.4Δ > eΔ` 会不会成立？——**判：不会，Δ 抵消**

### 3.1 代数（`[T]`，一行）

```

```

* 等价的"Δ 形式" `Δ < 48/e = 17.6582131762` 是**同一句话的改写**（`LOOP-RUNBOOK §134` 的"Δ=20 必须 < 17.66"），**不构成杠杆**：它没有把 `e` 挪动分毫。`[E]`

## 4 · 第四问：`48` 是硬的吗？——`(a)` 触发 / `(b)` 不触发 / `(c)` 不触发

### 4.1 (a) `48` 是 SZZ 的精确分母 ⇒ 该路线内硬 `[T]`

* `K_S` 在 Assumption 1 里是**等式**，`K_S > 0` 的边界恰是 `|β| = 1/(16(d−1))` ⇒ **无代数松弛**。`[V]`
* 两个输入各自是**精确/锐**的：
  * 正项 `Ric = (N/2)|X|²`：**等式**（源文 L1943/L1951，引 Wang / AGZ (F.6)）——`α=2`、`(N+2)/2 − 1 ≡ N/2`，`1/2` 抬不动（除非换度量/换路线）。
  * 代价 `8(d−1)`：**精确关联计数**（L1616；`= Δ+4`，见 §2.1），不是松界。
* ⇒ 在 **Bakry–Émery + Wang 判据**这条路线内，`48` **不可改进**：要动只能动 Lemma 4.1 的 Hölder 排列或换度量。
* **限定（必须带）**：`48` 是**该证明路线**的硬，不是"强耦合的真半径"。SZZ 明写 `1/48` 是**充分**条件（§1.2）；真半径未知。

### 4.2 (b) `16(d−1)` 有没有更好版本？——**无**，且抬它也没用 `[T]`+`[X]`

* 源文只有一个更**差**的同族式：`SO(N)` 的 `1/(32(d−1)) − 1/(16N(d−1))`（`d=4, N→∞` ⇒ `1/96`）⇒ SU(N) 的 `1/48` 已是该族最好。
* OS 1978 只给"小 `β` 有隙"，常数随群/维数、未量化（`LIT-ERA-04:20`、`V3-LIT-SYNTHESIS:106`）。
* **检索结论**：语料 + 源文内**无**任何 `>1/(16(d−1))` 的 4D SU(N) 半径（检索式见 §6；命中 `0`）。`[X]`：未查付费墙后的其它文献。
* **结构性判**：即使有更好的 `48'`，在 KP 不等式 `λ_T < 48` 里它是**右端天花板**，抬它只放松右端；当前缺口是 `λ_T > 48` 而 `λ_* < 48` ⇒ **真正的缺口在左端**（§3.3）。**抬 `48` 是"把天花板抬到云上"，不解决"包络太松"。**

### 4.3 (c) `2.4` 无结构意义？——**不成立（它有结构）** `[T]`

见 §2.2：`2.4 = 2 + 2/(2d−3)`，`2` = SU(N) Ricci 密度倒数，`0.4` = 自身关联富余。两块各有槽、可逐位核对（`py` 整数/40 位小数双核）。**唯一要撤的是"`12 = 立方体 12 条边`"**（`TN2:80` 已裁；`12 = 4(d−1) = 48/gcd(48,20)`）。

## 7 · 限定（`AGENTS §2.1`）

1. **口径**：`d=4`、`Δ=20`、`N=2`、SZZ 的 `β`（`S = Nβ Re Σ tr U_p`，'t Hooft 归一）；`48` 与 `2.4` 都是**该归一口径下**的数，换 `β/2` 约定则 `48 → 24`（`TN2:153`）。
