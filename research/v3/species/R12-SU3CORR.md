## 1. 第 1 问：`G` 是什么，`S_W ≡ β` 为什么推不出 `G = 0`

`G = ∂_τ S_W`，`τ: X ↦ X+τE`（`v=E` 是 Lie 代数涨落方向）；`a := ⟨E,X⟩ = 2tr(EX)`。
`θ=π` **切片** = `{c=cos(θ/2)=0} ∩ {a=0}`。在切片**上** `S_W = β`（值）；但

```
S_W(u,a) = β(1 − c cos u + s sin(u)·a/ρ),   ρ=2u,  sin u/ρ = g(u)=sin u/(2u)
∂_τS_W   = β s g(u) ≠ 0        (c=0 只杀 "cos u" 项, a=0 只杀 a 的一次项)
```

机检（`mp.dps=40`，`r12.log [A]`）：`S_W(0)−β = 0.0`（3 点），而 `G_FD = 1.22167375663838506 / 0.970874047882527448 / 0.247837197991088575` 与 `β s g(u)` **18 位吻合**。`[T]`

⇒ **核准**：`r08` 的 `S_W≡β ⇒ G≡0` 非法（`S_W` 的值与它沿 `v` 的导数无蕴含关系）；`SU(3)` 的 `D` **必须**含 `Var(G)`。

## 2. 第 2 问：`SU(3)` 的 2D Weyl 积分表示

共形坐标 `a = x₁−x₂, b = x₂−x₃ ∈ (0,2π)`，`dx₁∧dx₂ = ⅓ da db`，`x₁=(2a+b)/3, x₂=(b−a)/3, x₃=−(a+2b)/3`：

```
⟨f⟩ = ∫_{T²} |Δ|² e^{−S_W} f (da db/3) / ∫_{T²} |Δ|² e^{−S_W} (da db/3)
|Δ|² = s₁₂s₂₃s₁₃ ,  s_p = 4sin²(d_p/2) ,  (d₁₂,d₂₃,d₁₃)=(a,b,a+b)
Φ′  = Σ_p g′(d_p)(λ_i−λ_j) ,   Φ″ = Σ_p g″(d_p)(λ_i−λ_j)²
G   = (β/3)Σ_j λ_j sin(φ_j−x_j) ,  H = −(β/3)Σ_j λ_j² cos(φ_j−x_j)     [W=diag(e^{iφ})]
S = ⟨H + Φ″⟩ ,   D = Var(G+Φ′) = ⟨(G+Φ′)²⟩ − ⟨G+Φ′⟩²
```

`Φ` 取哪一个决定了 `S ≡ D` 是否成立：

```
Φ_r08 = −log|Δ|²          ⇒  ∫|Δ|²(Φ′²−Φ″) = ∂²_τ∫|Δ(θ+τλ)|² = 0   （平移不变，恒等式）
Φ_O09 = Σ_{i<j}g(d_ij)    ⇒  多出 ψ = Σlog d² ；恒等式失效
```

## 3. 第 3 问：800 bit + 定向舍入

### 3.1 可精确化的一半（`Φ_r08`，三角多项式）`[T]`

`l_ij cot(d/2)`、`s_ij csc²(d/2)`、`s_ij cot²(d/2)` 全被 `|Δ|²` 吸收，`|Δ|²Φ″` 与 `|Δ|²Φ′²` 是三角多项式，常数项用 `Fraction` 精确（`u₁,u₂,u₃=u₁⁻¹u₂⁻¹` Laurent 字典）。`π` 只经 `libmp` 的 `'f'/'c'` 进入，逐操作定向舍入 + `2⁻⁴⁰⁰` 外扩：

| 量 | 值 | 区间宽 |
|---|---|---|
| `CT[|Δ|²]` | `6` | — |
| `CT[|Δ|²Φ_r08″]`, `CT[|Δ|²Φ_r08′²]` | `48`, `48`（**两个 λ 都是**）| — |
| `S = D` | `8` | `1.239e−119` |

```
λ=(1,0,−1): S_lo − D_up = −1.2392294e−119 < 0   （精确有理 S−D = 48−48 = 0）
λ=(1,−1,0): 同上
```

⇒ **`S ≡ D` 不是数值巧合，是"常数项平移不变"的恒等式**（对一切 `λ ∈ t`）。由此
`S − D = E[Φ′²] − Var(G+Φ′) = −Var(G) − 2Cov(G,Φ′)`：`G=0`（r08）给 `0`；**`G≠0` 给负数**。`[T]`

## 4. 第 4 问：判死线逐条

**(a) 不成立**。`S_lo − D_up > 0` 拿不到：`Φ_r08` 下差恒为 0（`−1.2e−119` 只是 `PAD` 痕迹），`Φ_O09` 下符号随权重截面翻（`−0.236` / `+0.102`）。**不得**写成「`SU(3)` 也过了」。

**(b) 部分成立，数字在上表**；与 `SU(2)` 的差别来自三处，逐字：

1. **rank 2 ⇒ `Φ` 不径向**：`SU(2)` 的 `Φ′(ξ)=(g′(ρ)/ρ)a` ⇒ 切片上恒 0 ⇒ `Var(Φ′)=0`，`D` **只剩** `Var(G)=0.0691`；`SU(3)` 的 `Var(Φ′)=6.81`（`SU(2)` 的 0 倍，`Var(G)=0.0767` 的 89 倍）⇒ `D` 被 `Var(Φ′)` 主宰。
2. **正确 `Φ` 的 `ψ=Σlog d²` 破坏 `E[Φ′²]=E[Φ″]`**：这是 `r08` 的第二个独立错误（它用 `−log|Δ|²` 当 `Φ`）。`SU(2)` 上二者恰好只差常数，故显不出来。
3. **横向方向**：`G≠0` 加 `Var(G)` 与 `2Cov(G,Φ′)`；在纯 Haar 分支 `Cov=0` ⇒ `S−D=−Var(G)=−0.0611<0`。

**(c) 成立（判在这里）**。瓶颈不是精度：
- 2D Weyl 公式只对**类函数**精确；`G, Φ′` 是横向观测量（`E_ii=(V†EV)_ii` 依赖 flag 标架）⇒ 不是类函数；
- `a=0` 切片是 **7 维**（2 维本征值空间里的 1 条线 × 5 维 flag），`SU(2)` 的「球面切向 ⇒ `Φ′≡0`」降维在 `SU(3)` 没有对应物；
- `Φ_O09` 含 `log d²`、`cot`、`csc²`，`|Δ|²` 把它们化成解析函数，但**不再是三角多项式** ⇒ 800 bit 常数项路线失效；要严格区间需 `log/cot` 的单调 Taylor + Cauchy 尾（可行，约 1–2 h），或直接把 5 维 flag 积分（`E_ii` 的 Itzykson–Zuber 型平均）写成闭式再做区间（≥半天）。

⇒ 所需资源：**7 维（或 flag 闭式 + 2 维区间）**，非 15 min 内可得；本文件不报 `SU(3)` 的"正确 `S, D`"作为一个**唯一**数——因为 2D 表示本身没有把它们定义成唯一。
