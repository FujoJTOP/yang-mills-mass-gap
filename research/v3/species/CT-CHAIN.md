## §3 L=2 的精确（半闭式）约化

### 3.1 第一步：逐点代数（`[T]`，FD 验证 `≤7e−10`）

记 `nᵢ³ = ξ₃ⁱ/ρᵢ`，`w = n̂₁·n̂₂`，`ψ(ρ) := φ′(ρ)/ρ = 2/ρ² − cot(ρ/2)/ρ`，`A₁ := s₂(k₁/2 − s₁/ρ₁)`，`B₂ := s₁(k₂/2 − s₂/ρ₂)`：

```
Φ′ = Σ_i ψ(ρ_i) ξ₃^i                                                (逐点恒等)
G  = +β[ (n₂³ − w n₁³)A₁ + (n₁³ − w n₂³)B₂ ]                        (逐点恒等)
```

在约束面 `a=0`（`ξ₃² = −ξ₃¹ = −t`，`n₁³=t/ρ₁`，`n₂³=−t/ρ₂`）上：

```

## §4 符号定理：`X(0)<0` 归约为**一条二变量代数不等式**

### 4.1 两条已证引理

**Lemma 1（`ψ` 严格递增）`[T]`.** `ψ(ρ)=2/ρ²−cot(ρ/2)/ρ=(sin v − v cos v)/(2v² sin v)`，`v=ρ/2`。
`sign(ψ′)=sign H(v)`，`H(v):=v²−2sin²v+(v/2)sin2v`；`H(0)=H′(0)=0`，`H″(v)=4 sin v (sin v − v cos v) > 0`（因 `(sin v − v cos v)′=v sin v>0`），故 `ψ′>0` 于 `(0,2π)`。∎

**Lemma 2（`sign Q = sign(ρ₁−ρ₂)`）`[T]`.** `Q = ½k₁k₂[T(ρ₁)−T(ρ₂)]`，`T(ρ)=tan(ρ/2)/ρ`。
`T′=[ρ−sinρ]/(2ρ²cos²(ρ/2))>0` 于 `(0,π)`；`(π,2π)` 上 `tan<0` 使 `(ρ/2)sec²(ρ/2)−tan(ρ/2)>0` ⇒ `T′>0`；
且 `T(π∓)=∓∞`。分三种情形（同侧两支 / 跨 `π`）逐一代入 `k₁k₂` 的符号，得 `sign Q = sign(ρ₁−ρ₂)`。∎

**Corollary `[T]`.** `P·Q ≥ 0`，等号仅当 `ρ₁=ρ₂`。

### 4.2 唯一剩下的不等式 `(R)`（数值验证，未证）

```
(R)   |R(ρ₁,ρ₂)| ≤ |Q(ρ₁,ρ₂)|   在 (0,2π)² 上

## §6 全 `L`：最强陈述、精确卡点、`L`-依赖

### 6.1 一般 `L` 的结构性恒等式（`[T]`）

```
X(0) = −2 Σ_{i,j} Cov(g_i, p_j),   g_i = ∂_{ξ₃ⁱ}S,  p_i = ψ(ρ_i)ξ₃ⁱ
环上平移不变 ⇒ X(0) = −2L Σ_j Cov(g_0, p_j)
```
⇒ `X/L` 有体积极限（强度量 `χ := −2Σ_jCov(g_0,p_j)`）。**这是"链族"能成为一个"族"的全部结构理由**：
不是因为 `X` 对每个 `L` 单独有意思，而是因为它是**强度量**。

### 6.2 精确卡点（一句话，无退路）

> **`L≥3` 时约束面是 (3L−1) 维超平面，`ξ₃` 不再两两反号，§3.2 的 Bessel 一步（唯一把横向结构压成 `(p,q,ψ)` 的步骤）没有对应物；
> 于是符号问题从"一个可算的三维积分"退化为"约束球模型上的一个正相关不等式"，而**正相关（FKG 型）不等式需要乘积结构，全局线性约束恰好破坏它**。**

这就是 `L≥3` 证不出来的**精确**原因：缺的不是估计，缺的是**把 (3L−1) 维约束积分化到有限维的结构**。
（`L=2` 之所以可算穿，只因为约束把两个变量锁成 `±t`，剩余的 `S²×S²` 只通过 `n̂₁·n̂₂` 进入，`ψ`-积分退化为 `I₀`。）

## §7 T2：Hadamard 警告 —— 三条可核结论 + 语料审计

### 7.1 正确形式 vs 错误形式（差在**哪一项**）

```
正确（Najfeld–Havel / Mathias，三点）：
    d²/dh² f(W+hM)|₀ = 2 Σ_k  M̃_{jk} M̃_{kl} f[2](w_j, w_k, w_l) ,   f = exp(i·)
    f[2](x,y,z) = ( f[1](x,y) − f[1](y,z) ) / (x − z) ,  f[1](x,y) = (f(x)−f(y))/(x−y)
错误（两点，na2 初版）：
    f[2](w_j,w_k,w_l)  ⟶  f[2](w_j,w_k,w_k) = ( f[1](w_j,w_k) − f'(w_k) ) / (w_j − w_k)
```

**差的就是"第三个节点"。** 二阶 Fréchet 导数在**非交换方向**上是**三点**对象（三个特征值都要进来）；
两点核只能携带一阶信息。**精确成立 ⟺ `M̃` 对角 ⟺ `[M,A]=0`。**
（`[2b]` 实测：`M=A` 时两点形式误差 `2.5e−7`、三点形式同量级 ⇒ 两者都对；`M=λ₃/2` 时两点 `1.44e−1`、三点 `1.1e−7`。）

### 7.2 复现"两点形式错"（`NA2` 记为 66%；按同一协议实测 **36/36 = 100%**）

`[2]` 最小例（`N=2`，一点）：两点形式相对误差 `1.443e−1`，在 `h=1e−2 … 1e−6` **完全不变** —— 这是**公式错**（不是离散化错）的签名。
`[3]` 按 `na2_selftest.py` 的协议（`N=2,3`；6 次随机；`h=1e−3,1e−4,1e−5`，共 36 项）：两点形式在 `1e−3` 阈值下失败 **36/36 = 100%**；三点形式 **0/36**。
⇒ **实测 36/36 = 100%**（不是 66%）；`NA2` 的 "66%" 只在把阈值放到 `1e−1`（33/36）或换计数口径时才复现。
**对复用者真正重要的是"误差与 `h` 无关"这一条**：它一眼区分"公式错"与"步长错"，而 36/36 这个数字本身依赖阈值。
诚实说法是「凡 `[M,A]≠0` 的方向全错（`[M,A]=0` 时两点形式精确）」，见 `[2b]`。

### 7.3 语料审计（`grep Hadamard|∂_a²U|two-point|second difference|Loewner|ddU`，全 `research/`）

| 脚本 | 二阶导怎么来的 | 受影响？ |
|---|---|---|
| `species/w7/na2_selftest.py` | `ddU = 2V((M̃M̃)*f2_2pt)V†` | **是**（就是被弃用的那条路线本身） |
| `species/w7/na2_su3_na.py` | 不构造 `∂²U`；`H` 走恒等式 `E[H]=−dE[G]/da+Var+Cov` | 否（设计上避开） |
| `species/w7/na2_chain.py` | 只用**一阶**导（`G`、`Φ′`） | 否 |
| `species/w7/na_plaquette.py` | 标量 **2-jet**（`class J`）作用在 `cos/sin/log/sqrt` 上 | 否 |
| `v3/w7/v3_counterexample_scope.py` | 显式标量 Hessian（`gr/hess` 的 `ρ,u` 形式） | 否 |
| `unconditional/w7/gpp_core3.py` | 真·有限差分 `exp(i s v)U` | 否 |

**`na_plaquette.py` 为什么能复现 `A−Bβ²` 到 5 位而不受污染**：它的模型是
`S = β(1 − cos(ρ/2)cos(θ/2) + sin(ρ/2)sin(θ/2)u)`，`u=ξ₃/ρ` —— **`ξ` 的标量函数**。
`d/dh`、`d²/dh²` 全由 jet 的链式法则在**标量**上传播；矩阵指数**根本不出现**，只有 `cos/sin/log/sqrt` 的标量组合。
所以那个两点形式的公式误差不在它的代码路径里，`A=0.20511530`、`B=0.01105929`、`β*=4.30661`、`G″=A−Bβ²` 一个数字都不动。
`v3_counterexample_scope.py` 同理（`gr/hess` 是显式标量链式法则），`gpp_core3.py` 是真差分。
**结论：这条负结果只有一个"用户"，而且它已经被弃用；但它必须留在册上，因为"矩阵指数 + 二阶导"在任何新脚本里都会重现这个坑。**
