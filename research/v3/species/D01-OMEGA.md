## §2 PF 给了什么：**符号**，不是**大小**

设 `T_β ≥ 0`（正核）、`|G_β⟩` 为其 PF 向量。任务书的第 1 问——"两个不同 `β` 的基态向量都非负 ⇒ 内积 `≥` 什么"——有三层，必须分开：

**(2.1) 直接结论（`[T]`，三行）**：`ψ,ψ' ≥ 0 ⇒ ⟨ψ|ψ'⟩ ≥ 0`，故 `Ω = (⟨ψ|ψ'⟩)²`，**无相消**。但 `|⟨u|v⟩|² ≥ 0` 对**任意**复向量成立（无任何假设）。⇒ **PF 对 `Ω` 的净信息 = 0。** 这正是 `B01-RP §2` 的"`Θ`-内积的正性是**符号**的陈述，`λ₂` 是**大小**的陈述"在 `Ω` 上的同一句话。

**(2.2) 为什么非负性无法升级成下界（`[T]`，反例）**：在非负象限的球面上
```
min{ ⟨u,v⟩ : u,v ≥ 0, ‖u‖₂=‖v‖₂=1 } = 0        （取 supp u ∩ supp v = ∅）
```
`Ω` 是 `|·|²`，所以**任何**从"逐分量非负"出发的下界，都必须**额外**用到"支撑不交**不可达**"这一条——而这条只能来自"PF 向量逐点**严格正**"，即有限体积的 `T > 0`。严格正给的是 `Ω > 0` **在固定 `L`、固定 `(β,β')` 上**；它给不出跨 `L` 一致的正下界（§3.1 给出它的精确形式与量级）。

**(2.3) ★ 一个恒等式，把问题搬到测度上（`[T]`，但注意它是恒等式不是定理）**：PF 向量归一（`‖ψ_β‖₂ = 1`）后 `μ_β := ψ_β²` 是 PF 链的**定常测度**（`∫ψ²T(x,dy)/λ = ψ(y)²`，两行验证）。于是
```
Ω = |⟨ψ_β|ψ_β'⟩|² = ( Σ √(μ_β μ_β') )² = BC(μ_β, μ_β')²
```
即 **`Ω` = 两条 PF 测度的平方 Bhattacharyya/Hellinger 亲和**。这一步的价值：`Ω` 从此是一个**测度间距离**，可以用耦合/比值/输运去攻（§3）。它的代价是必须承认一件事：

> **`μ_β` 不是 Boltzmann 测度。** `T_β` 的 PF 向量在"变量是流过核的群元"的模型里**与 `β` 无关**（§4：2D YM、单 plaquette 上 `ψ ≡ const`），而 Boltzmann 权重 `e^{-βS}` 变得再多也看不见。⇒ `Ω` 眼睛盯的是**真空**，不是**权重**。四个模型上这一点就是判死的全部。

## §3 三条候选下界：条件、量级、以及它们为什么**必然**只到 `e^{-Θ(V)}`

### 3.1 反向 Cauchy–Schwarz 的**正确**形式（`[T]`）

两个非负**向量**在球面上内积可以任意小（§2.2），所以任务书写的 `⟨u|v⟩ ≥ ‖u‖₁‖v‖₁/√dim` **作为普适命题是错的**（量纲上 `dim` 应为 `dim^{1/2}` 才可能，且仍需支撑重叠假设）。正确且可用的版本只有一条，靠**下界**不做上界：

```
u,v ≥ 0, ‖u‖₂=‖v‖₂=1  ⇒  ⟨u,v⟩ ≥ (min_i u_i)·‖v‖₁ ≥ min_i u_i
⇒  Ω ≥ ( min(min ψ_β, min ψ_β') )²
```
再用 `‖ψ‖₂ = 1 ⇒ max ψ ≤ 1` 把 `min ψ` 换成**投影直径**（PF 的定量语言）：
```
R_β := max_i ψ_β(i) / min_i ψ_β(i) ,  dim = n
min_i ψ_β(i) ≥ 1/√(n R_β)     ⇒     Ω ≥ 1/(n² R_β R_β')
```
**这是"用 PF 给 `Ω` 下界"的全部真内容。** 它在固定体积上严格 `> 0`；但 `n = e^{Θ(V)}`、`R_β = e^{Θ(V)}`（`ψ = e^{-β·H_eff}` 型，`H_eff` 广延），所以 `Ω ≥ e^{-Θ(V)}`。**这是本轮唯一一条可证的 `Ω` 下界**，见 §5(a) 的判定：它不解决搬运。

### 3.2 定量 PF / Doeblin–Birkhoff 收缩（`[C]`，同一件事的另一种写法）

`R_β` 就是 Hilbert 投影度量下的直径；Doeblin 系数 `α_β` 给 `R_β ≤ ...`，Birkhoff 给 `T^t` 的收缩率。把它代回 3.1，得到的**还是** `Ω ≥ 1/(n²R_βR_β')`。⇒ **定量 PF 不是"3.1 之外的另一条路"，是 3.1 的一个估计器。** 这一点必须写清，因为它正是任务书第 2 问"PF 的定量版（`T^t` 的收缩）能给什么"的答案：`T^t` 的收缩率控制的是**一个** `β` 自己的混合速度，而 `Ω` 需要的是**跨 `β`** 的比较；跨 `β` 时 `R_β` 与 `R_β'` **乘起来**，没有任何一条收缩能把两者的比值压下来。

### 3.3 耦合：`dμ_β/dμ_β' = e^{-(β-β')S}`（`[T]` 的结构 + `[C]` 的量级）

在**同一个** fixed-`L` 的 slice 空间上写密度比（Boltzmann 侧）：
```
dμ_β/dμ_β' ∝ exp( -(β-β')·S[X] ) ,   osc(S) = Θ(V)   （S 广延）
```
⇒ 比值落在 `[e^{-|Δβ|·osc(S)}, e^{+|Δβ|·osc(S)}]`，代入 3.1 形式的"比值有界"界（`BC ≥ 2√m/(1+m)` 一族，`m = e^{-|Δβ|osc(S)}`）：
```
Ω ≥ exp( -|Δβ|·osc(S) ) = e^{-Θ(V)} ,   Δβ = 2.5 - 1/48 = 2.458333…
```
**耦合没有比 3.1 更好，而且不可能更好**：`Δβ` 是 `O(1)`，`S` 是广延量，故 `μ_2.5` 与 `μ_{1/48}` 在 `L→∞` 时**互奇异**。这是 `Ω` 作为"原始 overlap"的**结构性**事实，不是方法松弛。

### 3.4 ★ 紧性检查：`e^{-Θ(V)}` 是**真值**，不是界的松弛（`[T]` 解析 + `[C]` 数值）

**自由场（Gaussian）上 `Ω` 精确可算**。单自由度、二次型系数 `λ`、`σ² = 1/(βλ)`：
```
Ω_k = BC_k² = 2√(ββ')/(β+β')        （λ 约掉 ⇒ 与质量/动量无关）
β=2.5, β'=1/48:   Ω_k = 0.1810653082661706 ,   log Ω_k = -1.7088974936
```
数值核对（bundled python 3.12/numpy 2.3.5，`x∈[-80,80]`、`8×10⁵` 格点、直接求 `(Σ√(p₁p₂))²`）：

| `λ` | 数值 `Ω` | 闭式 `0.1810653082661706` |
|---|---|---|
| 0.3 | 0.18106530831215217 | 差 `4.6e-11` |
| 7.0 | 0.1810653082661706 | 差 `0` |

⇒ **`Ω` 在多自由度上按模数**乘积**：`Ω = 0.1811^{n_dof}`**。4D `SU(2)`、`L=8`、`n_dof = 3×4×L⁴ = 49152`（近恒等/弱场读法；即使按规范约束折成 `4L⁴`，结论不变）：
```
log₁₀ Ω ≈ -1.7089/ln10 × 49152 = -36479        （即 10^{-36479}）
```
**这就是 3.1/3.2/3.3 三条界的真值对照**：三者都给出 `e^{-Θ(V)}`，自由场真值**也是** `e^{-Θ(V)}`，且**只差多项式前因子**。⇒ **没有"更好的 PF 定量收缩"可找**——缺的不是不等式。

## §4 ★ 四模型测试（**重新解释：`Ω` 是跨 `β`、同模型**，不是跨模型）

**口径**（任务书纪律）：`Ω(β,β')` 在每个模型**内部**取两个 `β`（本文件一律 `2.5` 与 `1/48`），**不跨模型比**。可比的是"这个模型上 `Ω` 的值 vs 该模型上原子的有无"。

| 模型 | PF 向量 `ψ_β` 的 `β`-依赖 | `Ω(2.5, 1/48)` | 该模型原子 `f₁²` | 判 |

## §5 判

### (a) `Ω` 有可证下界吗？—— **有，`Ω ≥ 1/(n²R_βR_β') = e^{-Θ(V)}`（§3.1，`[T]`）；但不构成"搬运解决"**

可证下界**存在**（固定 `L`、固定 `(β,β')` 上严格 `>0`），且 3.1/3.2/3.3 三条路给的是**同一个** `e^{-Θ(V)}`；自由场真值 `0.1811^{n}` 证明这个量级**是紧的**（§3.4）。所以 `Ω ≥ ω₀ > 0` **一致地**（`L`-一致）不成立 ⇒ **本轮不产生"搬运解决"这一发现**。理由不是"少一条不等式"，是 `Ω` 本身 `= e^{-Θ(V)}→0`。

### (b) 主判：成立。**PF 缺的不是定量收缩，是"跨 `β` 可比"这件事**

- 缺的是：**`Ω` 的下界在 `L→∞` 必然退化**（§3.3：`Δβ = 2.458` 下两测度互奇异；§3.4：真值就是 `e^{-Θ(V)}`）。
- 因此 `Ω ≥ c` 若要有内容，只能**换定义**：要么把 `Ω` 换成**归一化**的（除掉 `e^{-Θ(V)}` 的平凡因子），要么换成残数侧的比值 `f₁²(2.5)/(Z_O²f₁²(1/48))`。**但后者就是搬运本身**（`W95D:21` 的乘性式；`f₁²(1/48) ≥ r₀ > 0` 由 `P3` 无条件给出）⇒ `Ω ≥ c ⟺ f₁²(2.5) > 0` **是同一个命题的换名**，不是引理。这条与 `V01-INVENT:144`（引 `R1:226-230`：`Ω` 只在**错的一侧**有界、`ν≥0/RP` 泛函皆 Schur-凹）**独立同向**，且本轮给了它的**定量版**（§3.1–3.4：界的量级 = `e^{-Θ(V)}`，与真值只差多项式）。

### (c) 四模型测试：**失败**（§4）。且比 `(b)` 更硬的一条：

> **`[C]` `Ω = 1` 在 4D 上不只是未证，是被"数据处理"判死。** Hellinger 是 `f`-散度 ⇒ 对任意信道（取一个空间 plaquette `P₀` 的 holonomy 作 marginal）单调：
> `BC(μ_β,μ_β') ≤ BC(μ_β|_{P₀}, μ_β'|_{P₀})` ⇒ `Ω ≤ Ω_{P₀}`。
> 而 `⟨tr U_{P₀}⟩` 在 `β<1/48` 由簇展开严格 `≈ β/4 = 5.2e-3`、在 `β=2.5` 为 `O(0.5)`（后者的严格性依赖非微扰输入）⇒ `1 - Ω ≥ 1 - Ω_{P₀} > 0`，**与体积无关**。
> ⇒ 若"搬运 ⟺ `Ω = 1`"逐字成立，则 `(CP)` **假**（不是"没证"）。唯一的出路仍是承认 `Ω` 需要**归一化/状态匹配**；那个归一化子**从未被写出**。

**三条判词的关系**：`(b)` 说下界只能到 `0`；`(c)` 说那是因为 `Ω` 从定义起就盯错了对象（真空 ≠ 残数），并顺手把 `Ω=1` 的**字面**读法判假。**主判 `(b)`，附带 `(c)` 成立**——若只报 `(b)` 会误导成"PF 还不够强"，而实际是"要证的东西不该写成 `Ω`"。
