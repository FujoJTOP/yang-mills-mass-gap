## 1. 逐阶展开与矩/累积量表示（推导）

### 1.1 Ward/Stein 主恒等式（本文件全部公式的唯一来源）

对纤维测度 `ν_a(dy) ∝ e^{−V(a,y)}dy`，`∂_a log ν_a = −(F−E[F])`，故对任意 `φ`（`P22 (*)`，`main.tex:1148–1152`）：

```
d/da E[φ|a] = E[∂_aφ|a] − Cov(φ, F|a)                                    (W)
```

- `φ=1` ⇒ `d/da(1)=0` ✓；
- `φ=F` ⇒ **`G″ = E[κ] − Var(F) = S − D`** `[T]`（与 `p21/p22/o24/o27` 完全一致）；
- `φ=V⁽ᵏ⁾` ⇒ `d/da E[V⁽ᵏ⁾] = E[V⁽ᵏ⁺¹⁾] − Cov(V⁽ᵏ⁾,F)`。

### 1.2 密度对数导数（原始矩形式，最稳、可算）

`u_n := ρ^{(n)}/ρ`。由 `ρ^{(n)} = ∫(∂_a)^n e^{−V}` 逐次求导（Ward 多项式）：

```
u1 = −E[F] = −m
u2 = E[F² − κ]
u3 = E[3Fκ − V⁽³⁾ − F³]
u4 = E[F⁴ + 4F V⁽³⁾ + 3κ² − 6F²κ − V⁽⁴⁾]
```

而 `ℓ := log ρ = −G`，标准对数导数递归给出**逐阶展开系数**：

```
G′   = −ℓ′  = m = E[F|a]
G″   = −ℓ″  = −(u2 − u1²) = E[κ] − Var(F)                                   = S − D
G‴   = −ℓ‴  = −(u3 − 3u1u2 + 2u1³)
G⁗   = −ℓ⁗  = −(u4 − 4u1u3 − 3u2² + 12u1²u2 − 6u1⁴)
```

### 1.3 累积量（半不变量）形式

把 `u1=−m` 代入并整理（`κ_j := κ_j(F|a)`、`γ := Cov(F,κ|a)`、`A_k := E[V⁽ᵏ⁾|a]`）：

```
G″ = A2 − κ2                                                        [T]
G‴ = A3 − 3γ + κ3                                                   [T]
```
即 **`G‴(0) = E[V⁽³⁾|0] − 3Cov(κ,F|0) + κ₃(F|0)`**：三项分别是「势的三阶导」「曲率–力耦合」「力的三阶累积量」。Gaussian 纤维（`V` 二次）上三项全零 ⇒ `G‴=0`，与「高斯 ⇒ `G` 二次」一致。**`[T]`**

四阶用 `u`-递归的等价累积量写法（`m=0` 的对称切片，本项目的相关情形）：

```
G⁗|_{m=0} = 3(κ2 − A2)² − [ κ4 + 3κ2² + 4E[F V⁽³⁾] + 3E[κ²] − 6E[F²κ] − A4 ]
```
一般 `m`：`G⁗ = 6m⁴ − 12m²u2 + 3u2² − 4m·u3 − u4`（`u2,u3,u4` 见 §1.2）。**`[T]`**

**符号判据（本轮的结构性收获）**：若势在 `a` 方向二次（`V⁽³⁾=V⁽⁴⁾=0`）、纤维力高斯（`κ3=κ4=0`），则 `G″=A2−κ2≤A2`、`G‴=−3γ`、`G⁗=3(κ2−A2)²−3κ2² = 3A2²−6A2κ2`——**`G⁗` 的符号由 `A2`（曲率）与 `κ2`（力方差）之比决定，`κ2>A2/2` 即 `G⁗<0`**。这正是本项目 `D/S` 之比：`D/S≈0.97`（Savvidy 带）⇒ `G⁗<0`，即**非高斯性把 `a⁴` 项压负**。

## 3. 判：`G″(0)≥0` 有没有结构原因？

### 3.1 唯一真结构恒等式 = Fisher 信息，但它是**平均**

对任意密度 `ρ`（边界项 `[ρ′]_{±∞}=0`，本模型 `|a|<2π` 紧支）：

```
E_ρ[G″] = ∫ρ·(−(log ρ)″) = −[ρ′] + ∫ (ρ′)²/ρ = I(ρ) = Var_ρ(score) ≥ 0     [T]
```
并把 Cramér–Rao 接上：`I(ρ) ≥ 1/Var_ρ(a)`。**这是非负结构量**（Fisher 信息 / 得分方差），但**它约束的是 `G″` 在 `ρ` 下的加权平均，不是 `G″(0)` 的值**。逐点只能写到

```
G″(0) = E[κ|0] − Var(F|0)      （两个非负量之差；自由场 = 0）
```

⇒ 在 `ρ`-平均意义上，"`G″` 的均值是 Fisher 信息"是真的、非负的（这与 `Q7-TOOL-FORGE.md` 的 `E_ρ[G″]=I(ρ)≥1/Var` 是同一条，本轮给出**分部积分的一行证明**）；但**逐点 `G″(0)≥0` 不由此推出**：`E_ρ[G″]≥0` 与 `G″(0)<0` 完全可以并存（`o28` 实测 `θ=π` 的 `G″(a)` 在 `a∈(0.709,2.973)` 为负，占 288/401 格点）。

### 3.2 为什么 (a) 不能逐字成立

自由场酸测：`V` 二次 ⇒ `E[κ]=Var(F)`（equipartition）⇒ `G″≡0`。**任何"恒非负"的函数泛函在自由场上仍必须 `≥0`，但 `G″` 在自由场上恒 `0`**——所以 `G″` 的符号**不可能**由"非负结构量"逐点解释；它度量的是**对 equipartition 的条件化缺陷**（`ABC2-CONSTRUCTIVE/B3-FUNCTIONAL-BE` 的同一定性：`G″(0)=E[V″|0]−Var(V′|0)`，非条件化时 `E[V″]=Var(V′)` 精确）。

### 3.3 逐条判死线

- **(a)** —— **不成立（逐字不行）**。可写的 `[T]` 只有平均式 `E_ρ[G″]=I(ρ)≥1/Var_ρ(a)`，它是**方差地板**（`Var ≥ 1/I`，上界方向），与 H1 需要的 `Var(a)≤1/λ` 相反。**H1 在 `a=0` 没有因本轮而获得 `[T]` 证明**；不得把这一条记成 `G″(0)≥0` 的证明。
- **(b)** —— **成立（主导结论）**。`G″(0)` 的符号在 `β=2.5` 是数值：单 plaquette `θ=0:+0.7299`、`θ=π/2:+0.5429`、`θ=π:+0.1360`；`L=2:+0.3942`（`6.0σ`）。`a≠0` 的行为由 `G‴/G⁗` 决定：`θ=0` 上 `G‴=0`、`G⁗=−0.1352<0` ⇒ 大 `a` 处 `G` 被压（`a⁴` 负）；`θ=π` 上 `G‴=−0.2322<0` ⇒ `a=0` 右侧 `G` 先平后跌，左侧先跌后平，与 `O28` 的 `G″` 零点 `a₁=0.709`、`a₂=2.973` 相容。
- **(c)** —— **在 `θ=π` 成立、在 `θ=0`/格点不成立**。`θ=π`：`G′(0)=+0.8935≠0` ⇒ `a=0` **不是极小/极大点**，`G″(0)>0` 只是"对数密度的局部凹性"，**不含稳定性内容**（`P22 §3(c)` 的 `θ=π` 退化在这里的延伸：那条退化是 `E[H]=0`，本轮补上 `E[F]≠0`）。`θ=0`/格点：偶边际 ⇒ `G′(0)=0` 精确，`a=0` 是临界点，`G″(0)>0` ⟺ `a=0` 是 `ρ` 的局部极大 ⟺ 粗模最可能幅度为 0（即 `f₁²>0` 的读法）。
