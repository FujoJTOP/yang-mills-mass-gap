## 1 口径（`G″` 到底是 `log C` 还是 `C`）

| 位置 | `−∂²log ρ` | `−ρ″/ρ`（若把 `G` 读成 `C`） |
|---|---|---|
| `a=0` | `+2.000007593` | `+2.000007593` ← **同值**（因 `ψ₀′(0)=0`） |
| `a=1` | `+2.000003` | **`−1.992025`** ← **反号** |

⇒ 两种读法**只在对称点重合**（`ψ₀′/ψ₀|₀ = +9.85e−14`，故 `2(ψ₀′/ψ₀)² = 1.9e−26`），**离开 0 点就分开**。

**2D 独立复核**（`281×241` Dirichlet 双方向、稀疏 `eigsh`、再对 `b` 边际化）：`G″ = +2.000938364`（误差 `9.4e−04`，网格更粗）⇒ `b` 方向**不污染** `a` 边缘，`G″ = 2ω` 是边缘本身的性质 `[E]`。

## 4 为什么 (c) 同时成立（量纲 / `G` 不明确，全给数）

`ω=1, L=10` 下 `E[H] = 0.697392088` 固定，只换 `G`：

| `G` | `Var(G)` | `Δ_dyn` |
|---|---|---|
| `a`（任务口径） | 0.500000 | **+0.197392** |
| `ω a`（同归一化） | 0.500000 | **+0.197392** |
| `2ω a = −∂log ρ`（score） | 2.000000 | **−1.302608** |
| `a²`（`q11` 式第二项） | 0.500000 | **+0.197392** |

**标度事实**：`Var(a) ∝ ħ/ω`、`E[H] ∝ ħω` ⇒ `Δ_dyn(ω) = (ω − 1/ω)/2 + m` **非 `ω` 齐次**，故其符号随 `ω` 翻（`ω*` 如上）。`ω=1` 的正号是**单位取法**（`ħ=1` 且恰好 `1/(2ω) = ω/2`）的产物 `[T]`。

**更硬的一刀**：若 `E[H]` 取真期望 `⟨H⟩ = E₀ = ω/2 = 0.5`（而非 `E₀+m`），则 `ω=1` 时 `Δ_dyn = 0.5 − 0.5 = 0` **精确**。⇒ **同一个模型，只改 `E[H]` 的定义，"正/零/负"三种都拿得到。**

**需要的澄清（三条，缺一此路无意义）**：
1. `G` 是哪一个：粗变量 `a`、还是 `−∂log ρ`（score）、还是 `q11` 的 `G+Φ′` 合成量？
2. 归一化：是否固定 `ħ=1` 并声明 `Var(G)` 与 `E[H]` 承载同一幂次 `ω`（否则量纲不匹配，符号随 `ω` 变）。
3. `E[H]` 是 `⟨H⟩ = E₀` 还是 `E₀ + m`（前者给 `0`，后者给 `+0.1974`）。

## 5 条款逐字

- **(a) 锚点成立**：`ω=1, L=10` 周期 BC，`G″ = +2.0000076 = 2ω`、`E[H] = +0.6973921`、`Var(G) = +0.5`、**`Δ_dyn = +0.1973921 > 0`** `[E]`。按判死线 (a)，此点上"`Δ_dyn` 为正"、`n12` 不被数值推翻。
- **(b) 锚点不触发，但可被自由 `ω` 触发**：`ω=0.5` 给 `−0.552605`、`ω*=0.821904` 过零 ⇒ 若 `ω` 不是外部固定而是模型参数，**`Δ_dyn>0` 不是该模型的普适事实**，`n12` 只能以"`ω=1` 归一"+"`G=a`"+"`E[H]=E₀+m`"三条同时成立为条件。
- **(c) 成立**：`E[H] ∝ ω` 与 `Var(G=a) ∝ 1/ω` **量纲不匹配**，符号在 `ω*` 翻；换 `G` 归一化给 `−1.302608`；换 `E[H]=⟨H⟩` 给 `0`。⇒ **`G=a` 这条路上 `Δ_dyn` 没有标度不变意义；要它有意义，必须先按 §4 的三条澄清把 `G`、`ħ`、`E[H]` 钉死。** 在此之前，`+0.1974` 只是"`ω=1` 单位下的一个数"，不能当作 `n12` 的证据。

**标签**：`§1/§2/§3/§4` 全部数值 `[E]`（`p04_m6_numeric.log` 逐行可核）；`log` 与 `C` 在对称点同值 `[T]`（`ψ₀′(0)=0`）；`Δ_dyn(ω)=(ω−1/ω)/2+m` 与 `ω*` 闭式 `[T]`；`⟨H⟩=ω/2` 时 `Δ_dyn=0` `[T]`；**没有**任何一条标 `[T]` 的"物理"结论——本节全部是数值 + 标度代数。
