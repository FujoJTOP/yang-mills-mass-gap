## §1 定义与两条恒等式（不作记忆，逐字）

```
G″(0) = E[H+Φ″|a₀] − Var(G+Φ′|a₀) = Δ_dyn + W_geo + X ,      X = −2Cov(G,Φ′)        (1.1)
Δ_dyn := E[H|a₀] − Var(G|a₀) ,   H = ∂²_v S_W ,  G = ∂_v S_W ,  Φ = −log J          (1.2)
H1(δ) ⟺ G″(0) ≥ δ ,   δ_phys := a²Δ₀² + W_full ,   W_full = W_geo+X                  (1.3)
```

`(1.1)` 是恒等式（`ch05:230–240`；机检残余 `6.7e−16`，`N05 §3`），`(1.3)` 使 `Δ₀>0 ⟺ H1(δ_phys) ⟺ Δ_dyn ≥ a²Δ₀²`——**题面的"等价"成立且零新估计** `[T]`（`H1-FINAL §1.1`、`P03-EQUIV:253–258`）。
关键结构事实（本文件唯一机制，`N02 §1` 逐字）：**`H`、`G` 只由 `S_W` 定，Jacobian 全在 `W_geo` 里**。⇒ `S_W` 沿某方向为常数 ⇒ 该方向 `Δ_dyn ≡ 0` **精确**，与 `β,L,m` 无关。

**两条箭头（题面前提，逐字采信）**：`Δ₀>0 ⇏ m>0`（thin atom，`[T]`）；`m>0 ⇏ Δ₀>0`（2D：`m=3g²/8` 而 `Δ_dyn=0`，`[T]+[E]`）。限定随结论引：两条都是**逐测度/逐点**反驳，一致版是 `[M]`（`H1-FINAL §4`）。

## §2 2D 为什么 `Δ_dyn=0`：平坦模引理（不是拓扑）

**引理 B03-1（平坦模）`[T]*`.** 若在条件化点所在模上 `S_W` 沿 `v` 为常数（该模只由测度/Jacobian 承载），则 `G=H≡0`、`X=0`，于是 `Δ_dyn=0`、`G″=W_geo≥0`。

**2D 实例（`N02 §2.2`，逐字）**：`k→0` 粗模 = 空间圆环上的**常值 holonomy**：常值 `A₁`、`A₀=0` ⇒ 每个 plaquette `U_p=1` **逐点精确** ⇒ `S_W≡0` 沿整条模线 ⇒ `Δ_dyn=E[H]−Var(G)=0`（取等，不是负）、`X=0`、`W_full=W_geo`。
而 `m=(g²/2)C₂(½)=3g²/8=0.375>0`（`g²=1`），且 2D 上 `G″=W_geo+Δ_dyn`、`W_geo=2/sin²φ≥2`，数值 `G″=+2.0000`（`t=40`）/`−26.478`（`t=0.5`），**从不为 0** `[E]`（`N04-2D:14,49`；`N03-WFULL §0` 推翻旧"`G″=0`"）。
⇒ **2D 的失败模式是假阴性**（有隙而给 `0`），不是"开方为虚"。

**第三见证（比 2D 更硬，不靠群紧性）`P4` 周期核**：均匀平移是 `S_W` 的**精确平坦方向**（`ch15-uvface:199–201`「every plaquette is a pure difference, so the uniform shift is an exact flat direction of `S_W`」）⇒ `Var=0`、`E[H]=0`、`X=0`、`Δ_dyn=0`、`W_full=W_geo=0.22196`（`L→∞`），而**周期转移矩阵有隙 `Δ=0.6444`**、`β∈[0,10⁴]` 无 `β*`（`H1A:165–176`；`H1D §0`）`[V]`。
⇒ **必要性失败在 2D 与 P4 两个不同维数/机制上各出现一次**，不是 2D 的偶然。

**"拓扑平凡"这条要分开记**：2D `SU(N)` 确实 `F∧F` 恒零、无瞬子、`π₁(SU(N))=0` 使谱流/`η`/指标恒零（`B04-INDEX:33,112`）——这是**另一条**路线整体 `[NG]` 的理由（"只看拓扑的量在唯一可解 gapped 规范理论上必给 0"）。**它解释"为什么拓扑量不行"，不解释"为什么 `Δ_dyn` 为 0"**；后者是 `S_W≡0` 的代数恒等。

**为什么这条机制不能搬到 4D（重要限定，防误用）`[T]+[J]`**：平坦模引理要求 `v` 是该模型的**对称/平坦方向**（2D 经 Migdal 精确约化后只剩 holonomy、`S_W` 在其上为常数；P4 的均匀平移是真对称）。4D 的 `k=0` 模**不是** `S_W` 的平坦方向（`O11-PHYS:149` 逐字）。虽然 4D 场空间里存在"方向 1 所有链 `=e^{ia}`、其余链 `=1`"的**平坦线**（该线上所有 plaquette `=1` ⇒ `S_W=0`，`[T]`），但那只是**一条线、不是纤维方向的对称性**，不足以让 `E[H]−Var(G)` 的纤维平均消失 ⇒ **不得据此宣布 4D 上 `Δ₀>0` 为假**。`Δ₀>0` 的真值仍是**开 `[O]`**（`H1-FINAL §2`），缺的仍是同一格。

## §3 M6 为什么 `Δ_dyn>0` 而 `m=0`：它是 0+1 且 `Δ_dyn` 是单边常数

**模型（`N02 §2.3` 逐字）**：`ρ_a ∝ e^{−ωa²}` ⇒ `V_eff=−logρ=ωa²` ⇒ `H=2ω`、`G=2ωa`（只依赖被条件化的 `a`，故 `Var(G|a)=0`）、`Φ=0` ⇒ `Δ_dyn(a)=2ω=G″`；自由方向 `b`：`S≡0` ⇒ `Δ_dyn(b)=0`。`m_L=min(ω,½(2π/L)²)`：`L=8→1024` 给 `0.3084→1.88e−5` ⇒ `m=0`。

- **"0 维模型？"→ 是 `0+1`**：`a` 是一个谐振子（量子力学），`b` 是长度 `L` 的圆环上的自由转子；没有规范场、没有空间转移方向、没有 `U′`（holonomy 空量词，`S05-ACID:79`：M6 上 `(★)` 的真**是空真**）。
- **"为什么它不充分"→ min 律**：`λ₁(μ₁⊗μ₂)=min_i λ₁(μ_i)`（`U05` 引理 1，`B05:25` 逐字）⇒ M6 的真空测度是**乘积且带一个平坦因子** ⇒ 模型的隙被 `b` 拉走，而 `a`-边缘常数仍是 `2ω`。⇒ **`Δ_dyn=2ω` 是 min 里被丢掉的那一项**，即全空间常数的**上界**；充分性失败（`Δ_dyn>0 ⇏ m>0`）是结构性的，不是数值巧合。
- **按 `∀v`（`app.tex:183` 逐字 "for every coarse transverse `v`"）：`inf_v Δ_dyn=0` ⇒ M6 一格**过**。`P02`/`H1-FINAL §3.2` 已撤回 `n12`/`q03` 的 M6 票。**⇒ 题面的 "M6 ⇒ 不充分" 只在逐模（`v=∂_a`）读法下成立；当前口径下 `Δ_dyn` 的失败只剩 2D（+ 单片的符号伪影）。**

**当前记分（`Δ_dyn` 本体，`∀v` 读法）**：

| 模型 | `m` | `Δ_dyn` | 应给 | 判 |
|---|---|---|---|---|
| 自由无质量场 | `0` | `0` `[T]` | 0 | ✓ |
| 2D YM | `0.375` | `0`（取等）`[T]*` | `>0` | **✗ 假阴性** |
| M6 | `0` | `2ω`(a)/`0`(b) ⇒ `inf_v=0` `[T]` | 0 | ✓ |

⇒ `2/4`（`H1-FINAL §3.2`）或 `3/4`（N02 的"无对象"读法）。**无论哪种读法都不是 4/4，且差的那一格是必要性。**

## §4 变体逐条过 4/4（一个都不能省）

判据：四行 = 自由（要 `0`）· 2D（要 `>0`）· M6（`∀v`，要 `0`）· 单片（要 `undef`）。**逐行给值，不许跳行。**

### V1 比值版 `Δ_dyn/a^p`（`p∈ℝ`，含 `p=2` 的 `Δ₀²` 本身）`[T]`
| 行 | 值 | 判 |
|---|---|---|
| 自由 | `0/a^p=0` | ✓ |
| **2D** | **`0/a^p=0`** | **✗** |
| M6 | `2ω/a^p`(a)、`0`(b) ⇒ `inf=0` | ✓ |
| 单片 | `−0.069/a^p<0` 或 `undef`（`a=0` 处 `0/0`） | ✗ |

**结论：不过。** 齐次化对**精确零**无能为力：`0/a^p ≡ 0`。若 `Δ_dyn` 在 2D 是"小正数"还有救，但它是恒等零 ⇒ 比值版**结构性**无救 `[T]`。

### V2 任意一元函数 `g(Δ_dyn)`（单调、非单调、幂、对数同论）`[T]`
两行同时看：`g(0)` 必须 `=0`（自由场）**且** `>0`（2D，因 2D 的 `Δ_dyn=0`）——**矛盾**。
⇒ **`Δ_dyn` 单变量泛函全体无解，且这是 [T]（不是"没试到"）**：自由场与 2D 在 `Δ_dyn` 上**同值 0 而 `m` 不同（0 vs 0.375）** ⇒ `Δ_dyn` 在这两模型上**不可分**。

### V3 `Δ_dyn^{(3D)}`（换维数）`[NG]`
1. **无 2D 槽**：四模型是固定清单，3D 对象在 2D 行没有实例（取 `d=2` 的同一公式就退回 `Δ_dyn` 本身）。换维度不是"同一量的变体"，是换载体（同类错误 = `δ_curv`（无量纲）↔ `δ_I2`（质量²）的跨槽混读，`H3-RECONCILE:48`）。
2. **3D 的隙不是定理**：3D `SU(N)` YM 的 `m>0` 只有格点证据，不能当试金石行。
3. **同一缺陷照抄**：3D 里"某方向链恒定、其余为 1"仍使所有 plaquette `=1`（`S_W=0` 的线，`[T]`），且 3D 没有平坦**对称**方向 ⇒ 与 2D 的零不是同一机制、也不能保证零。
⇒ **判 `[NG]`：既不是合法变体，也不带来新信息。**

### V4 与 `s₁` 组合（`s₁ := inf supp ν_w`）`[T]`
先把 `s₁` 自己的四行摆出来（`SG1 §3` `[E]/[T]`）：`(0,\ 0.375,\ ω=1,\ undef)` ⇒ **`s₁` 自己在 M6 行是假阳性**（`s₁(M6)=ω=1 ≠ 0=m₆`，`SG2 §4`、`RUNBOOK:15415`）。所以组合有两种、两种都死：

- **乘性**（`Δ_dyn·s₁`、`Δ_dyn/s₁`、`Δ_dyn^α s₁^β`）：**2D 上 `Δ_dyn=0` 因子把一切杀死** ⇒ `0` ⇒ 2D 行 ✗ `[T]`。
- **加性**（`Δ_dyn + c·s₁`，`c≠0` 常数）：M6 的 `b`-模给 `Δ_dyn=0`、`s₁=ω` ⇒ 值 `=cω≠0` ⇒ **M6 行 ✗** `[T]`；`c=0` 退回 V2 ⇒ 2D ✗ `[T]`。
- **量纲**：`Δ_dyn` 是无量纲曲率、`s₁` 是能量 ⇒ 加性组合本身量纲不齐（与 `f₁²` vs `s₁` 同类，`SG1:119`）。**若强行引入固定标度 `E₀`（`Δ_dyn + s₁/E₀`）则 M6 的 `b`-模留 `ω/E₀≠0` ⇒ ✗** `[T]`。
- **量词域**：`Δ_dyn` 逐模（`∀v`），`s₁` 是模型/算符级（不随 `v` 变）⇒ 混合后 `∀v` 槽**没有良定义**（与 `Δ₀`↔`I2` 不可比同型：`N06`/`H3 §7` 三项不同：载体、类型、量词域）`[T]`。

⇒ **`Δ_dyn` 与 `s₁` 的任何 `+,·` 组合都不过 4/4。**

## §5 "过 4/4"太弱：一个可拟合的显式反例（`[E]` 手算 + `[J]`）

取 `F := Δ_dyn + s₁(1 − s₁)`（单位取 `ω=1`，即四模型表的口径）：

| 行 | `Δ_dyn` | `s₁` | `F` | 要求 | 判 |
|---|---|---|---|---|---|
| 自由 | `0` | `0` | `0` | 0 | ✓ |
| 2D | `0` | `0.375` | `+0.234375` | `>0` | ✓ |
| M6 | `2ω/0` | `1` | `2`(a) / `0`(b) ⇒ `inf=0` | 0 | ✓ |
| 单片 | `−0.069` | `undef` | `undef` | undef | ✓ |

**逐行 4/4 全过**——但这是一个**四点拟合**：(i) 常数 `1` 必须恰等于 M6 的 `ω`（模型数据），(ii) 量纲混用（无量纲曲率 + 能量），(iii) 换个归一化 `ω=2` 立刻破。**⇒ "过 4/4"是 4 个符号位，不是"隙探测器"的证书**；任何 4 点都能被插值。**这正是判死线 (c) 的内容**，也是 `B05` 的机检结论（通过集 = 重标集）的直观版。
