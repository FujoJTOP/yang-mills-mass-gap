## §1 谱位置：`C(0)` 是全 BZ 平均，`χ` 是 `k=0` 权重（两个平均，不互相蕴含）

```
(1.1) Parseval 反向：  C_q(0) = (1/V)Σ_k Ĉ(k)        ← 全 V 个模的平均（UV 主导）
(1.2) 窗和：           χ := Σ_z C_q(z) = Ĉ(0)        ← 只有 k=0 一个模
(1.3) 系综均值方差：   Var(Q̄) = Σ_{a,b}χ_{ab}/(36V)   ← 同一侧（只含 k=0 权重）
(1.4) 两个估计量分工： 单组态内空间方差 → C(0)；跨组态均值的方差 → Ĉ(0)
```
**判 `[T]`。** 所以「用 12000 组态算 `Var(q)`」是**谱上取错了模**：(1.3) 与 (1.1) 相差 `1.41e4` 倍不是精度问题，是对象不同。**下一手**：凡报 `Var(q)` 必须写「单组态内」；凡报 `Var(Q̄)` 必须写「`k=0`/`χ` 一侧」。

## §3 「能否算」的四条路，逐条判

1. **闭式 `[NG]`**：`β=2.5` 的 `Var(q)` 是 4D Gibbs 的同期两点函数，不是 `β=0` 的单 link 积分；仓内 `0` 条闭式（检索见 §7）。
2. **热力学恒等式 `[NG]`**：`d⟨P⟩/dβ = Σ_□′Cov(q_0,q_□′) = Σ_bχ_{ab}`（行和）——它给的是 `χ` 的**行和**，不是 `C(0)`。由 §1，两者在谱的两端。
3. **12000 组态 `[NG]`**：`run3` 存 `plaq` = `_plaq_all`（`6V` 平均，`run3_apebase.py:210–218`）⇒ `Var(Q̄)=5.2904e-06±7.5e-08`；与 `C_q(0)` 差 `1.41e4`。**且** `Var(Q̄)·V = 0.0325/0.0335/0.0328/0.0327/0.0327`（`L8T12`12k / `L8T12`4152 / `L8T16` / `L8T20` / `L6T12`）四跑五点在 `±0.015` 相对内一致 ⇒ 这个估计量是干净的 `1/V` 标度，**它测的是 `χ`，不是接触项**。
4. **单组态内空间方差 `[T]`**：`Ĉ(0)=Var_x(q_x)`，偏差 `−Var(Q̄_a)=−2.7e-5`（相对 `3.6e-4`）；`sd≈C(0)√(2/N_eff)≈1.65e-3`（`N_eff≈V=4096`）⇒ `0.0745±0.002`。**这是唯一现成的路**，也是 `HV2` 已走的那条。

**判**：`Var(q)` 的实际值**能算**，但只在 `[T]-4` 这一条路上；`[T]-1/2/3` 三条都给不出它。**下一手**：把 `[T]-3` 的数登记成 `χ` 一栏（见 §4），台帐里与 `Var(q)` 分开。

`ϖ ≤ A·coth(m/2)⁴`（`HZG-BLOCK:46`，`S(m)>1 ∀` 有限 `m`），振幅 `A` 三档：
