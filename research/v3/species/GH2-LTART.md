### 1.3 两个量的精确关系：`w₁ = κ · e^{m−R̄}`

`[T]` 恒等式（纯算术，把 `A` 的线性最小二乘展开）：

```
w₁ = Σ_t g_t r_t / Σ_t g_t²  ,   r_t ≡ C(t)/C(0)
R̄  = −ln r₁
κ  ≡ w₁/(e^m r₁) = Σ_t g_t r_t / (e^m r₁ Σ_t g_t²)
⇒  w₁ = κ · e^{m} · r₁ = κ · e^{m − R̄}            ⇒  d ln w₁ = d ln κ − dR̄
```

- `[T]` **单指数极限**（`r_t = g_t/g₀`）给 `w₁ = 1/g₀`、`e^m r₁ = (1+e^{−m(Lt−2)})/g₀` ⇒ **`κ = 1`**。
  所以 `κ` 是纯**形状泛函**（只由 `r₁,r₂,r₃` 决定），与归一化、与 `L_s`、与体积都无关。
- `[E]` 本数据上 `κ ∈ [0.973, 1.025]`（5 点，跨度 **5.2%**）。`GW2-NUMERICAL-PRIOR.md:78` 的「`0.96–0.99`」是本表的低端；
  本表把上边界推到 **1.025**。
- `[C]` **`w₁ ≤ ŵ₁(1) = e^m C₁/C₀` 不是恒等式**（论文 `:339` 写「is an identity」）。反例就在论文自己的表里：
  `RUN1.md:52` 那行 `κ = 1.0252 ± 0.0148`（**1.7σ 越过天花板**）。代数原因：该不等式等价于
  `g₂r₂+g₃r₃ ≤ (e^m Σg² − g₁) r₁`，只在「`t=3` 点落在单指数外推之下」时成立；单指数时取等号。
  ⇒ 该「天花板」应当读作 **0.97–1.03 的经验带**，不是严格上界。（这条本身不影响 8.3%，但它正是
  「`w₁` 不能由 `R̄` 单独决定」的机制。）

## §5 诚实边界

### 5.1 窗口（本报告全部数值结论只在此内成立）


**不外推**到 `β ≠ 2.5`、`L_s > 8`、`L_t > 20`、`SU(3)`、其它作用量、其它算符基（APE/`¼trF²`/多算符 GEVP）。

### 5.2 不可说的六件事

1. **不是「`w₁ = 0`」**：`w₁(6,20)=0.3491±0.0036` 离零 `97σ`。本轮只说**体积依赖**没分辨，不说量本身。
2. **不是「任何 β 上都没有体积依赖」**：窗口只有 `β=2.5`。`β=2.2` 的存档族（`C₁/C₀ = 0.1367→0.1229→0.1216`，
   `sec03:195-197`）本轮**没有**重测；它在 `R̄` 单位下是 1.4% 级，与本轮结论不冲突但也不互证。
3. **不是「`L_t=12` 处处够用」**：`δ(6)=+4.1%±2.0%`（2.0σ）是**正**提示，只是差分不够、方向不对。
   且 `(6,20)` 两复本自己差 2.1σ（`χ²_w=4.5`）⇒ 这个 4.1% 只能当**上界**（§3.2）。
4. **不是「`GW7` 的 0.1% 错了」**：`GW7` 的 `R̄(2.66,12×18)=2.7904` 与内插 `2.7932` 的 0.1% 差异本轮逐位复现
   （`gh2_reanalyze.log`：`2.7904±0.0368`）。本轮只指出**它不是盒对照**（含 `β` 外推），所以不能拿来当
   `β=2.5` 那对的反证。真正可比的存档盒对照是 `GW2:55` 的 `β=2.2` 对（`R̄` 差 1.4%）。
5. **不是「`w₁ ≤ ŵ₁(1)` 是定理」也不是「它是错的」**：本报告证明它**不是恒等式**（`κ=1` 只在单指数取等号），
   并把经验带推到 `0.973–1.025`。`RUN1` 那行 `κ=1.0252±0.0148` 只 1.7σ 越界 ⇒ 记为 `[C]`，
   而不是「论文的 Bug 2 判错了」。
6. **不是「`RUN1` 错了」**：`RUN1` 的 `L_s=6` 与本轮的差是 2.03σ 的**统计**差（同期 `C(0)` 复现到 0.13%、
   `⟨plaq⟩` 到 0.01%、`raw` 支未被涂抹污染——`run1_b25_l6.py:198,245`）。一个 2σ 不构成「谁错」，
   只构成「论文不该把 8.3% 当已分辨的效应」。
