## 0. 结论（一句话）

**造不出 ⇒ 机器是空的 ⇒ 按 d06 判 (c)→(b)，D1 死。**
两条独立的死因，各自单独成立：

1. **2D `Hess` 本身不定**（有 Savvidy 负模），数值给出 `inf spec = −B`（`B=1` 时为 `−1.000000`）；
   而**任何正权 `W` 都动不了谱**（相似变换），所以 `Δ² > 0` 不可行。`[T]`
2. 即便把 `E₀` 定义成 `min spec(H)` 硬抬负模，`Δ²` 也只有 `5.6e-14 ≈ 0`；
   而在"最有利"的读法（`c=1`、背景 Landau 规范 ⇒ 谱 `{0,2B,2B,…}` 半正定）下只剩一个**平模 0**，
   `Δ²=0`，同样过不了。**两条读法都死。**

## 1. 2D 的 `H`：`F_B` 是什么

`[T]` 2D 只有 `μν = 01`：`F_01 = ∂_0A_1 − ∂_1A_0 + [A_0,A_1]`，**单分量、Lie 代数取值的标量**。
"磁" = `F_01 = B`（`su(N)` 里取 Cartan 方向），无 `E`/`B` 之分，只有这一个数。

**注意（口径）**：把 `−D²+2adF_B` 当**Lorentz 标量**写是错的 —— `ad F` 反对称，本征值 `±iθ_α`，
`−D²+2adF` 不自伴（"谱"是复数）。自伴对象是**带指标混合**的
```
H_μν^{ab} = −D² δ_μν δ^{ab} + 2 f^{abc} F_μν^c        (作用在 2 分量涨落 a_μ^a)
```
`[T]` 2D 作用量的**精确二级变分**（`S=¼∫F²`，`F(A+ta)=F+t𝒜+t²[a,a]`）：
```
Q(a) = ½ d²/dt² S|₀ = ½∫ 𝒜_01² + ∫ F_01^a [a_0,a_1]^a ,   𝒜_01 = D_0a_1 − D_1a_0
```
即 `Q = ½ a^T M a`，`M = −D² + c·(adF)`，**由作用量定出的系数 `c = 1`**（`c=2` 不是 Hessian，是另一个算子）。

## 2. 2D 有没有 Savvidy 负模？—— 有 `[E]`（数值，格点/实空间网格）

`B=1`，`x∈[−5,5]`，`nx=200`，Dirichlet，`dim=6·nx=1200`：

| 系数 | `min spec M` | `#neg` | 说明 |
|---|---|---|---|
| `c=1`（作用量） | **`−1.000000`** | 400 | `= −B`，infimum 不 attained |
| `c=2`（"2adF"字面） | `−2.000000` | 400 | 控制组，线性于 `c` |

**最负本征向量的分量**：`a0^1 = 0.707, a1^2 = 0.707`，其余 0 ⇒ **通道 `(a_0^1, a_1^2)`**：
```
Q(u) = ½ (B x u)² − B u²        ⇒  inf = −B   (u→δ 处取得下确界)
```
这正是 2D 版的 Savvidy 负模（4D 的负模住在 (01) 平面，2D 的整个空间就是那个平面）。
`[T]` 若改成背景 Landau 规范 `D·a=0` 读 `−D²+2fF`：Landau 能级 `2B(n+½)` ± `B` ⇒ `{0,2B,2B,…}`，
**半正定但仍有一个平模 0**。两种读法都拿不到 `Δ²>0`。

## 3. 造 `W`：`W` 能不能压负模？—— 不能 `[T]`

**定理（相似不变，两行）** `[T]`：设 `H` 自伴、`W≻0` 可逆。则
```
W^{1/2}(H−E₀)W^{−1/2} ⪰ Δ²·1   ⟺   H−E₀ ⪰ Δ²·1 .
```
证：`W^{1/2}(·)W^{−1/2}` 是相似变换 ⇒ 谱完全相同 ⇒ `A ⪰ Δ²·1 ⟺ spec(A)⊂[Δ²,∞)`；反向取 `W=1`。∎
（等价地：`W^{1/2}AW^{−1/2} ⪰ Δ²` ⟺ `A ⪰ Δ²W` ⟹ `A ⪰ Δ²·λ_min(W)·1 ≻ 0`。）

**数值验证 `[E]`**（`dim=1200`，24 个随机 `W=exp(cK)`，`cond` 1…1e2）：

| `E₀` | `min spec(H−E₀)` | 24 个 `W` 引起的 `min spec` 相对位移 |
|---|---|---|
| `E₀ = 0`（背景值） | **`−1.000000`** | `4.75e-16` |
| `E₀ = min spec(H)`（硬抬） | `+5.58e-14` | `6.60e-16` |

⇒ `sup_W Δ² = min spec(H−E₀)`：**`W` 完全不参与**。`Δ²` 的数是 `−B` 或 `0`，没有正的。

**关于 `1_{Ω⊥}`（D1 原文）**：把不等式限制在 `Ω⊥` 上确实不是相似（`W` 可把负方向推进被排除的法向），
但那正是**指向真真空的方向**——排掉它等于排掉物理内容；且 `Δ²` 仍被 `min spec(H−E₀)` 之外的东西限制为 0，
不产生任何 `>0` 的数。

## 4. 即便取最有利读法：`Δ² = 2B ∝ 1/A → 0`（D06 验收 (ii) 挂）

`E₀ = 平模能量`，`c=1` 规范读法 ⇒ Hessian 隙 `Δ² = 2B = 4πm/A`（环面面积 `A`，磁通 `m`）。
对照 2D 精确隙（Migdal/Casimir）`m_true² = g²C₂(adj)/2 = g²N/2`（`β=2.5, g²=0.4, N=2`）：

| `A` | `Δ²` | `Δ²/m_true²` |
|---|---|---|
| 16 | 7.854e-01 | 1.96e+00 |
| 64 | 1.963e-01 | 4.91e-01 |
| 256 | 4.909e-02 | **1.23e-01** |
| 1024 | 1.227e-02 | 3.07e-02 |
| 1e5 | 1.257e-04 | 3.14e-04 |

`Δ² ∝ 1/A → 0`，`m_true` 与 `A` 无关 ⇒ **D06 验收 (ii)「`Δ ≥ 0.1·m_true`，损失有界」在 `A ≳ 256` 就挂**。
Hessian 的"隙"是 UV-Landau 隙，不是物理隙；搬运不到 IR。

## 5. 判

- **(c)**：2D `Hess` 本来就不定（负模 `= −B`，最负方向 `(a_0^1,a_1^2)`），`W` 压不住（相似不变 `[T]`）。
- **(b)**：由 (c) ⇒ **机器是空的**（`d06` 逐字："造不出则机器是空的"）⇒ **判死 D1**。
- **(a) 不成立**：没有 `Δ² > 0` 的数可写；唯一"能写"的是 `Δ² = 2B = 4πm/A`，它 `→0`，且 `W` 不参与 ⇒ 即便搬到 4D 也
  只是把"要证的隙"改成"已知的 Hessian 隙"，而 4D 的 Hessian 有 W4 实测 7.1% 负模，同一相似不变定理照样封死。

**精确缺失对象**：一条**不是相似变换**的权重演算（`W` 必须进入**测度/锥**，不是相似），
使"负模"在**加权二次形式**下被排斥 —— 现有 `W^{1/2}·W^{−1/2}` 形式在数学上不可能做到。
