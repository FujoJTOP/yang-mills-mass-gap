## 1. `Δ` 的显式（`[T]`，`log [A1][A2]`）

模型逐字（`Q04 (2.4)(2.5)`）：`w(ρ)=sin(ρ/2)/ρ`、`ρ=√(a²+s²)`、`c=cos(θ/2)`、`t=sin(θ/2)`。`A := a·w(ρ)`。`∂_aρ=a/ρ`、`∂_a²ρ = s²/ρ³`，于是

```
∂_a (a w)   = w + (a²/ρ) w′                              ( = r07 的 B )
∂_a²(a w)   = 3a w′/ρ − a³ w′/ρ³ + a³ w″/ρ²               (1.1)

Δ = t·∂_a²(a w) − (c²/4t)·(a w)
  = a·[ 3t w′/ρ − (c²/4t) w ]  +  a³·[ t w″/ρ² − t w′/ρ³ ]        (1.2)   ← 有限、无余项
  ≡ a·δ₁(ρ) + a³·δ₃(ρ)
```

**初等闭式**（`sympy` 通分，与 (1.2) 差 `0`）：

```
δ₁(ρ) = [ −c²ρ² sin(ρ/2) + 6t²( ρ cos(ρ/2) − 2 sin(ρ/2) ) ] / (4 t ρ³)
      = 3t·w′(ρ)/ρ − (c²/(4t))·w(ρ)                                        (1.3)
δ₃(ρ) = t[ −ρ² sin(ρ/2) − 6ρ cos(ρ/2) + 12 sin(ρ/2) ] / (4 ρ⁵)
      = t[ w″(ρ)/ρ² − w′(ρ)/ρ³ ]                                           (1.4)
```

**`u`-形式**（`u=ρ/2`、`g(u)=sin u/u`，故 `w=g/2`、`w′=g′/4`、`w″=g″/8`；与 `R07 (A5)` 的 `u`-块一致）：

```
δ₁(u) = (3t/8)·g′(u)/u − (c²/(8t))·g(u)
δ₃(u) = t·[ g″(u)/(32u²) − g′(u)/(32u³) ]                                  (1.5)
```

**结构性质（全部 `[T]`）**：

| 性质 | 结论 |
|---|---|
| `ρ→0` 极限 | `δ₁(0) = −(c²+t²)/(8t) = −1/(8t) = −t/8 − c²/(8t)`；`δ₃(0) = t/480` — **有限**，`1/ρ³,1/ρ⁴,1/ρ⁵` 全部抵消 ⇒ `w` 在 `u=0` 的奇性**可去** |
| 小 `ρ` 展开 | `δ₁ = −t/8 − c²/(8t) + ρ²(t/320 + c²/(192t)) + O(ρ⁴)`；`δ₃ = t/480 − tρ²/26880 + tρ⁴/3870720 + O(ρ⁶)` |
| 奇偶性 | `δ₁`、`δ₃` 都是 `ρ` 的**偶**解析函数 ⇒ `Δ(a,ρ)` 是 `a` 的**奇**函数（只有 `a,a³` 两支，`R07 (4.1c)` 的 `O(a³)` 就是全部高阶） |
| 符号 | `δ₁ < 0` 在 `(0,2π]` 上**严格**成立（见 §2 证明）；`δ₃ > 0` 在 `(0,2π]` 上（数值 min `6.805e−4`、max `1.473e−3`） |

> 与 `R07 (4.1c)` 的对接：`R07` 写的 `Δ = a[3t cos/(2ρ²) − 3t sin/ρ³ − c² sin/(4tρ)] + O(a³)` 正是 (1.3)，本文件把"`+O(a³)`"**换成精确的 `a³δ₃`**（(1.2)），并证明 `a²` 项**不存在**（不是小，是零）。

## 2. `E[Δ]` 在 `a→0` 的阶与 `c₁`（`[T]` 系数 + `[E]` 数值）

测度（`R07`/`r01` 同约定）：`p ∝ w(ρ) e^{−βS}dρ`、`S = 1 − c cos(ρ/2) + t a w`、`ρ ∈ [|a|, 2π]`、`w ≥ 0`。

**`a→0` 记账（`[T]`，`log [A3]`）** 令 `F = w e^{−βS₀}`、`S₀=1−c cos(ρ/2)`、`F₀=(1/2)e^{−β(1−c)}`：

```
Z(a) = ∫_a^{2π}F e^{−βtaw}dρ = Z₀ − a F₀ − β t a Z₀⟨w⟩₀ + O(a²)
N(a) = ∫_a^{2π}(aδ₁+a³δ₃)F e^{−βtaw}dρ
     = a D₁ − a²[ βt∫δ₁Fw + (δ₁F)(0) ] + a³ D₃ + O(a⁴)
⇒  E[Δ] = c₁ a + c₂ a² + c₃ a³ + … ,     c₁ = D₁/Z₀ = ⟨δ₁⟩₀              (2.1)
```

**关键点**：动下界 `ρ ≥ |a|` 只贡献 **`a²`**（因 `δ₁F` 是 `ρ` 的偶函数 ⇒ `∫₀^a = a(δ₁F)(0)+O(a³)`），**不污染 `c₁`**；测度平移 `e^{−βtaw}` 也只从 `a²` 起。所以 `c₁` 是**纯 `a=0` 测度下的平均**，与 `β` 只通过 `Z₀`/权重有关。

```
c₁(β,θ) = ⟨δ₁⟩₀ = Z₀^{−1} ∫₀^{2π} δ₁(ρ) w(ρ) e^{−β(1−c cos(ρ/2))} dρ             (2.2)
```

**符号定理 `[T]`（与 `β`、与 `θ∈(0,π)` 无关）**：`δ₁` 的分子
`N(ρ) = −c²ρ²sin(ρ/2) + 6t²·f(ρ)`，`f(ρ)=ρcos(ρ/2)−2sin(ρ/2)`。
第一项 `≤0`（`sin(ρ/2)≥0`）；第二项 `f(0)=0`、`f′(ρ)=−(ρ/2)sin(ρ/2) ≤ 0` ⇒ `f ≤ 0`。
故 `N ≤ 0`，且仅在 `ρ=0` 取 `0` ⇒ **`δ₁(ρ)<0` 逐点** ⇒（配 `w>0`、`Z₀>0`）**`c₁ < 0`**。∎

**数值（`β=2.5`、`θ=π/2`，即 `c=t=1/√2`、`K₀=0.5`；`log [B2][C3]`）**：

```
c₁ = ⟨δ₁⟩₀ = −1.6398774531e−01        （a=0 测度直接求积）
Richardson（E[Δ]/a, a=1e−2…6.25e−4）→ −1.6398211e−01   （差 5.6e−6 = c₂·a，与 O(a) 相容）
c₂ ≈ +9.02e−03 ,  c₃ < 0（表内数值）
⇒ E[Δ] = −1.63988e−01·a + 9.02e−03·a² + O(a³) ,  c₁ ≠ 0  ⇒  E[Δ] = Θ(a)，符号由 c₁ 定 = **负**
```

`c₁ ≠ 0` ⇒ `Δ` 是**一阶**（不是 `O(a²)`，与 `R07 §5` 的 `relres/a → 1.43e−3 ≠ 0` 同结论），且**负**：`βE[Δ] < 0` 在判据里是**扣分项**。

## 5. 诚实边界（不许读成无条件）

1. **`M(a)` 是 `[E]`**：`E[G]`、`Var(G)` 是确定性一维求积（GL，`n` 到 `9000` 逐位不变），不是定理。`c₁<0`、`δ₁<0`、`Δ=aδ₁+a³δ₃` 是 `[T]`。

4. **不是新机制**：这里的"可证余量"仍是 `K₀E[G]−Var(G)` 这个数；本文件只证了**误差项 `βΔ` 有多大、多负、在哪失效**，没给 `M(a)` 的解析下界。
