## §0 判词（先说；五问速答表在前）

**假设（本物种）**：`0⁺⁺` 塔服从一条 Dirichlet 弦的算子下界
`L_{0⁺⁺}|_{1^⊥} ≥ −d²/ds²`（`s ∈ [0,L_s]`）⇒ `e₁ ≥ π²/L_s²`，于是 `ρ² = e₂/e₁ ≤ 4`，
窗口取**锐常数** `C = 2`，`μ₁ ≥ Δ/3`。

**判词十句（逐条带标签）**：

0. **一句话。** `e₁ ≥ π²/L_s²`（floor）**是**真的、且是这类机器唯一能给的；`ρ² ≤ 4`（ratio）**不是**它的推论 ——
   两者之间**没有**逻辑通道。RB §6 用 `t = T₂(V)` 把 floor 拐到窗口上是对的（那条链只用到 floor），
   但"Dirichlet 弦 ⇒ `ρ² ≤ 4`"这句**作为推导不成立**（§2 DT-3，两个精确见证）。
1. **`L_s` 不能是谱的函数。** `L_s = π/√e₁` ⇒ `e₁ ≥ π²/L_s²` 退化成 `e₁ ≥ e₁`（循环）；
   `L_s = π/√Ē`（`Ē = Σw_n s_n` 是 WA 的可算矩）⇒ 结论变成 `e₁ ≥ Ē`，**当 `w₁<1` 即假**。`[T]`

## §2 控号定理

### DT-1（floor：一侧比较足够）`[T]`

> 设 `L ≥ −d²/ds² − β` 在 `L²(ds)` 的形式意义下成立（形式定义域包含关系按 RB-2(b) 的标准写法），
> 则对每个 `n ≥ 1`：`e_n(L) ≥ n²π²/L_s² − β`。特别 `e₁ ≥ π²/L_s² − β`。

*证明（Prüfer 相位，`[std]`，无小参数）.* 写 `Lu = λu` 为 `−u'' + (q+β)u = (λ+β)u`，`q+β ≥ 0`。
取 `u = ρ sin θ`，`u' = ρ√(λ+β) cos θ`，则 `θ' = cos²θ + ((λ+β) − (q+β)) sin²θ ≤ (λ+β)`（因 `sin²θ ≥ 0`）。
故 `θ(L_s) ≤ L_s√(λ+β)`。第 `n` 个本征函数在 `(0,L_s)` 内恰有 `n−1` 个零点 ⟺ `θ(L_s) − θ(0) = nπ`。
于是 `nπ ≤ θ(L_s) ≤ L_s√(e_n+β)` ⇒ `e_n + β ≥ n²π²/L_s²`。对 `n` 用 min-max 可去掉 Prüfer 的"简单谱"前提。∎

**锐性**：`q ≡ 0`（`β = 0`）时 `e_n = n²π²/L_s²` 取等；`q ≡ −β` 时 `e₁ = π²/L_s² − β` 取等。
数值（PART B1，FD `N=2000`）：`β/π² = 0.25/0.5/0.9/0.99` 四例，`e₁` 与 `π²−β` 全命中（`<1e-4`）。`[V]`

**预算的锐性（新）**：局部井 `q = −β·1[|x−1/2|<w]` 的临界深度 `β_crit(w)`（二分 `e₁ = 0`）：

```
   w        0.5      0.3      0.2      0.1      0.04
 β_crit    9.8696  10.8528  13.5455  23.0556  52.8250
 β_crit/π²  1.000    1.100    1.373    2.336    5.352
```

⇒ **`β < π²/L_s²` 对每个宽度都充分，且只在 `w = L_s/2`（最宽的单井）取等**；窄的（=动量空间局域的、
Savvidy 式的）负性被 `(L_s/2w)²` 惩罚 ⇒ **朴素预算在那里是亏损的**。`[V]`

### DT-2（ratio 半：一侧比较不给比值界）`[T]+[V]` —— **本文的核心否证**

> **(a)** `L ≥ L₀` **不蕴含** `ρ²(L) ≤ ρ²(L₀)`。**(b)** 更强：连**推论** `e₁ ≥ π²/L_s²` 也不蕴含 `ρ² ≤ 4`。

*见证 (a)：非局部正项.* `L = −d² + M|ψ_k⟩⟨ψ_k|`（`M ≥ 0`）。则 `L ≥ −d²` 成立（`M|ψ_k⟩⟨ψ_k| ≥ 0`），
floor 完好；而 `ψ_n ⊥ ψ_k`（`n ≠ k`）是 `L` 的本征向量、本征值不变 ⇒ 谱 = `{n²π²/L_s²}_{n≠k} ∪ {k²π²/L_s² + M}`。
FD 实测（`N=800`，`L_s=1`）：`k=2, M = 0.5π² → ρ² = 4.5000`（公式 `4 + M/π²` 命中）；`M = 5π² → ρ² = 8.9999`；
rank-`r`（把 `ψ₂…ψ_{r+1}` 一起抬高 `20π²`）：`ρ² = 4.0000, 8.9999, 15.9997, 24.0000` —— **无界**。
`[T]`（谱的精确计算）+`[V]`
（诚实注：`k = 3, 4` 的行里 `ρ²` 停在 `4.0000` —— 不是公式失效，而是被抬高的那一阶已经越过未被触动的
`n = 2` 阶（`4π²`），故 `e₂` 仍取 `4π²`。秩-`r` 序列正是靠**把 `2…r+1` 阶全部抬过下一个未触动阶**才递增。）

*见证 (b)：局部、变号、floor 已满足.* 在 20-bin 分段常数 `q ∈ [−500,500]` 上最大化 `ρ²` 同时强加 `e₁ ≥ π²`：
最优点 **`e₁ = 18.0963 ≥ π²`，`e₂ = 491.9404`，`ρ² = 27.1846`**（`q` 剖面 `min = −366.8, max = 500.0`，2/20 负箱）。
`[V]` ⇒ **floor 与比值之间没有单通道**。

**结论（判死的是哪一句）**：`一侧比较 ⇒ ρ² ≤ C²` 这整类推导 `[NG]`。
合法的常数写法只有**双侧**比较 `c₋L₀ ≤ L ≤ c₊L₀`：
```
   ρ² ≤ (c₊/c₋)·4   ⇒   C = 2√(c₊/c₋) ,      C = 2  ⟺  c₊ = c₋   （L 是 Dirichlet 弦的标量倍）
```

## §5 归属：**β（退化）+ 一条 γ**，以及它为什么过不了 F3∧F4

**不是 (α) 第五数据模。** DT **不是**一个数据模：它没有"可算输入"。它的输入是一条**算子不等式**，

所以 DT 不在 `ℭ^comp` 里 —— 元定理对它的"不适用"**不是逃逸**，而是因为它根本不是算法，是一个**蕴含式**。

**不是合格 (β)**，按章程 §5 自己的判据（"必须写清：这台机器在哪一步**严格强于** H1"）：
DT-比较 ⇒ 一个 Poincaré 不等式（Dirichlet 给显式常数），所以 **DT ⊂ H1 的充分条件类**；
它在**结论的显式性**上强（名字叫出 `π²/L_s²`、并给出 `m₁ ≥ π√σ`），在**假设的可达性**上**不更强**。
⇒ 记为 **β⁻（退化 β）**：新坐标 `(L_s, β)` + 新机器（Prüfer/Sturm 比较 + 符号预算）都是真的，

**是 (γ)（一条决定性的否证）。** 本轮最硬的产出是否证：
```
   「一侧形式比较 / 单侧 floor  ⇒  ρ² ≤ 4」    —— 假
   见证 A（非局部正项）： ρ² = 4 + M/π² = 4.5000, 8.9999 ；rank-r ⇒ 4, 9, 16, 24, …（无界），floor 完好
```
