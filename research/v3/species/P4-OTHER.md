## 1 · Q1：`δ` 的来源枚举（只有两档，且一档是错的类型）

**(i) 谱型（五环环 3）** `δ_{L1} = ln(1/ū)/a = κ/4 − ln(ē)/a`，`ē=eΔC̄`，`ū=ēu`。
`X01:79–82` 逐字：`|ε_T| ≤ \bar u^{T+3}/(1−\bar u)³` ⇒ `B=\bar u³/(1−\bar u)³`、`δ=ln(1/\bar u)/a`；`:75` 逐字：**`\bar u<1` ⟺ KP (2.1)**，即 `(L1)` **不引入新的 β 限制**，它就是 KP 盘。

**(ii) 振幅型（率分离）** `δ = (6−4)ln(1/u)/a = 2ln(1/u)/a`，来自周长 6 单管 `6t/a` 相对四壁 `4t/a` 的**整数代价差**（`FOURWALL:126–128`）。

**但 `FOURWALL:94` 逐字判死它的用途**：「it does **not** establish the level-isolation `I2` … the cost grading is an **amplitude** statement, not eigenvalue spacing」。
⇒ 它是"振幅/成本"隙；`I2` 要的是**本征值**隙（`Λ★−m₁²=2m₁δ+δ²`，`X01:99`）⇒ **喂不了 `I2`**。`[T]`

**(iii) 把 `I2` 当输入**（`R2-ISOLATION` 的 Lemma D 方向）与 `I1` 互为条件 ⇒ 循环，不计为"来源"。`[T]`

## 3 · Q3：`ū<1` **不是**只在 `(L1)` —— 它在同一页出现两次，且环 1 那一处更紧

`X01-L1C` 一页里 `ū` 的角色：

1. **`:71–75`（§2.3，环 1 的输入）**：`|φ^U(Γ)|≤C̄^{|Γ|}u^{|Γ|}`，定点动物数 `≤(eΔ)^{|Γ|}` ⇒ `|A(α)| ≤ ū^{α+1}/(1−ū)`。这里 `1/(1−ū)` **就是 `ū<1`**。推论（`:47` 逐字）：`|log D_∞| ≤ ū/(1−ū)²` ⇒ `D_∞=1+O(u)`。
2. **`:79–82`（§2.4，环 3 的输出）**：`|ε_T| ≤ B ū^T`，`B=ū³/(1−ū)³`，`δ=ln(1/ū)/a`。`B<∞` 与 `δ>0` **同一个 `ū<1`**。

**同一个数 `ū=ēu`、同一条不等式、同一页。** 所以"只要把 `(L1)` 换掉"这句话**在结构上无效**：`(L1)` 只是 `ū<1` 的**第二个**消费者；第一个消费者是 `r₀` 自己（`D_∞`）。

**而且环 1 那一处更紧（本轮新算术 `[T]`）**：`r₀ ≥ a₀/2` 只需 `D_∞ ≥ 1/2`，由 `|log D_∞|≤Θ(ū)` 指数化得
```
D_∞ ≥ e^{−Θ(ū)} ,   Θ(ū) = ū(1+ū²/(1−ū)²)/(1−ū)   （由 |A(α)|≤ū^{α+1}/(1−ū) 重算，比 X01:47 的 ū/(1−ū)² 更紧）
```
- `Θ(0.25)=0.370370` ⇒ `D_∞ ≥ 0.690478`；（用 X01 的粗式 `ū/(1−ū)²` 也只需 `ū≤0.3204`）
- `D_∞≥1/2 ⟺ Θ≤ln2 ⟺` **`ū ≤ 0.349675`**（粗式 `ū≤0.32037`）
- ⇒ `r₀≥a₀/2` 的窗：`u ≤ 6.4319×10⁻³`，`β ≤ 0.025728`（`u=β/4`）/ `0.051455`（`u=β/8`）

**⇒ Q3 结论**：`(L1)` 的 `ū<1` **不是唯一**要 u 小的地方；环 1 的 `D_∞` 要同一条（且更紧）。**"换掉 `(L1)`"不解锁。**

## 4 · ★ 本轮真改进：`[R]`（signed remainder）不必要

`FOURWALL:120` 把 `r₀` 的**下界**卡在 `[R]`，理由逐字：「Absolute convergence gives `|1+r|≤1+O(u)`, **not** `1+r≥1−O(u)`」。
**这个理由被 `X01:47` 的 log 版本绕过了**：绝对收敛给的是 **`log` 的两侧界** `|log D_∞| ≤ Θ(ū)`，指数化后**两侧界自动变成单侧正界**：
```
e^{−Θ(ū)} ≤ D_∞ ≤ e^{Θ(ū)}   ⇒   D_∞ ≥ e^{−Θ(ū)} > 0        （只要 ū<1）
```
在 KP 盘内（`Ĉū<1 ⇒ ū≤0.25`）：`Θ≤0.370370` ⇒ `D_∞ ∈ [0.690478, 1.448374]` ⇒
```
r₀ = a₀ D_∞ ≥ 0.690478 · a₀ ≥ 0.690478 / 32 = 0.021578   （N=2，a₀≥1/32）      [T]
```
**⇒ 环 1 的残余标签从 `[C] mod [R]` 改为 `[T] mod [KL]`（KP 盘内）。** `[T]`+`[E]`
**注意它换来了什么、没换来什么**：换来"不需要符号定理"；**没换来**"不需要 `ū<1`"（`Θ` 的分母仍是 `1−ū`）。所以它**不**回答总攻目标，只把 `[R]` 从路上搬走。`[T]`

**数值交叉核对（`[M]`）**：语料参考点 `β_W=1/12`、`u=0.0104`、`ū=0.5654`（`C01:142`）⇒ `Θ=3.502870` ⇒ `D_∞ ≥ 0.030111` ⇒ `r₀ ≥ 0.030·a₀`（仍正，但常数掉到 `1/33`）——正是 `ū` 逼近 1 的代价，与 `ū` 的单调性一致。
