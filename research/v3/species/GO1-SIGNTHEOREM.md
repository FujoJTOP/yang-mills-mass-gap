## §1 五路（最小公式 + 可行 + 障碍）

### 1.1 路 1 — Möbius / 分拆格

**最小公式（成立的那一版，[T]）：**

```
φ^U(Γ) = Σ_{π∈Π(Γ)} (−1)^{|π|−1}(|π|−1)! · W(π),
W(π)   = 1  若 π 的每个块在 G_Γ 里是独立集（块内两两不相邻），否则 0.                (1.1)
```

这就是"`log Z` 的**多线性**系数"公式（`Z = Σ_{独立 S}∏_{p∈S}w_p`，`log Z` 的 `∏_{p∈Γ}w_p` 系数）：`log(1+N) = Σ_k (−1)^{k+1}N^k/k` 里 `∏_{p∈Γ}w_p` 的系数 = 把 `Γ` 切成 `k` 个**有序**独立块的方案数 `÷ k`，而"有序方案数 `= |π|!`" ⇒ 每个 `π` 的权正是 `(−1)^{|π|−1}(|π|−1)!`。等价于色多项式的下降阶乘展开 `P_G(q) = Σ_k a_k (q)_k`（`a_k` = 用 `k` 个**无标号**颜色正常染色的划分数），于是

```
φ^U(Γ) = Σ_k (−1)^{k−1}(k−1)! a_k(Γ),   a_k = #{π : |π|=k, 各块独立}.              (1.2)
```

**验证（本轮 `[E]`，非引用）**：`go1_sign_cert.log:56–58`
- 4D `n≤4` 全枚举 11 611 簇 + 2D `n≤4` 全枚举 99 簇，共 **11 710 簇**，(1.1) 与 `3^n` DP 逐簇相等，**0 不一致**；
- 2D `3×3` 环面（`2⁹−1 = 511` 个 `Γ`）与 4D `1⁴` 环面（`2⁶−1 = 63` 个 `Γ`）：`Z` 的多线性 `log` 系数与 `Σ_A(−1)^{|A|}` **逐个 `Γ` 相等，0 不一致**（`log:56–57`）。

**判"`W(π)` 是否对每个 `|π|` 同号"（任务指定的唯一支点）：是同号，但这个支点平凡、且不承重。**
- `W(π) ∈ {0,1} ⊂ ℤ_{≥0}` ⇒ "同号"**恒真**，无需证明；
- 但 (1.2) 是一个**跨 `k` 的交替和**，块内同号对它的符号**毫无控制力**：决定符号的是 `(k−1)!a_k` 的**增长**，不是它们的符号。
- 反例式读数（手算，可复核）：
  - `K₄`：`a₁=a₂=a₃=0, a₄=1` ⇒ 只有一个 `k` 有项，**无抵消**，`μ = −3!·1 = −6`（`KP1:55` 的 `−6` ✅）；
  - `C₄`：`a₁=0, a₂=1, a₃=2, a₄=1` ⇒ `μ = −1·1 + 2!·2 − 3!·1 = −1 + 4 − 6 = −3`（`KP1:58` 的 `−3` ✅）。三项符号交替、系数**递增**，符号由 `k=4` 那一项压出来 —— 这条支配关系**不在**"同号"里。

**两条障碍（各自独立足以判死这条路作为证明）：**
1. **Möbius 值的块结构陷阱**：`μ_{Π_n}(0̂,π) = ∏_{B∈π}(−1)^{|B|−1}(|B|−1)!` 是**块积**，不是 `(−1)^{|π|−1}(|π|−1)!`；后者只是 `π = 1̂` 的特例（`n = |π|`）。`K₄` 的 `1+3` 分拆：块积 `= 1·2! = +2`，而 `(−1)^{|π|−1}(|π|−1)! = −1` —— 两者只在"每块都是团"时重合。**能用的 (1.1) 用的是"独立块"指示函数，不是键格 Möbius 的块积**（键格版对非团块给错值：`C₄` 的 `μ_{L}(0̂,1̂) = −3 ≠ −3! = −6`）。
2. **符号 ≡ 支配不等式**：(1.2) 的正性 ⟺ `[q]P_G = (−1)^{n−1}N ≥ 1` ⟺ **路 2**。

**判：`[T]`（公式真）+ `[NG]`（作为独立证明路）。** 它不是"新路"，它只是 `KP1:41` 那条恒等式 + 色多项式系数；它的价值是**把 `φ^U` 写成显式正项交替和**，而这条正好是 AS 命题需要的形状。

### 1.2 路 2 — 树/森林展开（Brydges–Kennedy 型）⇒ **这就是证明**

**最小公式：** 固定边序 `e_1 < … < e_m`；破圈 `B = C∖{min C}`（`C` 为圈）；`N(G) := #{生成树 : 不含任何破圈}`。则

```
φ^U(Γ) = μ(G_Γ) = (−1)^{n−1} N(G_Γ),        N(G_Γ) ∈ ℤ_{≥1}.                          (2.1)
```

**判"号是否来自树数奇偶性"：不是，而且这个提法直接死。** 所有生成树都恰有 `n−1` 条边 ⇒ **树数奇偶性是常数**，它给不出 `(−1)^{n−1}` 的交替。交替号住在 `|A|` 上（求和跑遍**所有**连通张成 `A`，不只树）；树是**符号反转对合的幸存者**，每个幸存者贡献同一个 `(−1)^{n−1}`。**所以号源是"对合 + 幸存者边数恒定"，不是"树数奇偶"。**

**BK 树图展开在这里不承重**：`C02:30` 记的 `(ii) Penrose/BK 树插值` 要的是 `|w_b| ≤ 1` 的**正性**（把 `φ^U` 界成 `τ`），而硬核情形 `f_e = −1`，正性机器不适用。真正管用的是**破圈对合/删-缩**（Whitney 侧），两者不是一回事。**`C02:30` 的 `|φ^U| ≤ τ` 与本文件的 `|φ^U| = N ≤ τ` 相容且更紧**（`N` 是 `τ` 的一个子集计数）。

**4D 的"书"（`k_ℓ ≥ 3`）是否破坏它：不破坏，且它根本不进 `G_Γ`。** `k_ℓ` 是**曲面/表示**数据的链价（`GA4:105`），`G_Γ` 只有"两片是否共 link"这一位。数值佐证：`k_ℓ=3` 首现于 `|Γ|=3`（`GA4:155`，转引 `UR5.md:91`），而 `n=3` 的 458 个簇号已成立（`GV2:128` 与本文件 `log:27`）。

## §2 证明（若成：逐步 + 每步消费什么）

> 对象：有限连通图 `G = (V,E)`，`n = |V| ≥ 1`。目标：`μ(G) := Σ_{A⊆E, (V,A) 连通张成}(−1)^{|A|} = (−1)^{n−1}N(G)`，`N(G) ≥ 1`。

**Step 0（桥 / 定义级，`[T]`，不消费任何假设）**
`φ^U(Γ) = Σ_{A ⊆ E(G_Γ),(Γ,A) 连通张成}(−1)^{|A|} =: μ(G_Γ)`，`G_Γ` = plaquette 邻接图（顶点 = 片，边 = 共 link）。
消费：`TT2.md:15`（L2 定义）、`ur1_enum.py:9`、`KP1.md:14`（`[T]` 定义）、`GU4-NECESSARY.md:270`（`c_Γ = φ^U/u^{|Γ|}`）。**这一步不是定理，是口径。**

**Step 1（归约）** 记 `W(G) := (−1)^{n−1}μ(G)`。要证 `W(G) ∈ ℤ_{≥1}`。消费：整数性（`μ` 是 `±1` 的有限和）。

**Step 2（边序与破圈，定义级 `[T]`）** 取 `E` 上任一全序 `<`。**破圈** `B := C∖{min C}`（`C` 跑遍 `G` 的圈；多重边时 `C` 可为 2-圈）。`S ⊆ E` **NBC** ⟺ `S` 不含任何破圈。两条基本事实：
- (2a) `S` 含圈 ⇒ `S` 含破圈（取该圈 `C`，`C∖{min C} ⊆ S`）⇒ **NBC ⇒ 森林**；
- (2b) 若 `S` 是**生成树**，则 `S` 含破圈 ⟺ 存在 `e ∉ S` 使 `e` 恰是其基本圈（`T + e` 的唯一圈）的**最小元**。（⇒：`B = C∖{min C} ⊆ S` ⇒ `min C ∉ S`，而 `S ∪ {min C}` 的唯一圈就是 `C`；⇐：该基本圈减最小元落在 `S` 里。）
消费：无（纯组合）。

**Step 3（`μ` 的删-缩，`[T]`）** 设 `e ∈ E`。

## §3 2D 酸测

**问题：** 这个号定理在 2D（那里逐项全正，`GA4:257–260` 的"2D 行、4D 不行"）上应给什么？若证明在 2D 给错号，证明有病。

3. **"逐项全正"住在哪**：`GA4:257–260` 的 2D 正性是**特征标/曲面**表象的正性 —— 2D 每条链恰 2 片（`k_ℓ ≡ 2`）⇒ 每项是流形曲面 ⇒ `c_S ≥ 0`；4D 的"书" `k_ℓ ≥ 3` 从 `n=3` 起就有 ⇒ 正性丢失。**那是逐项系数，不是簇系数**。两个表象对同一个 `log Z` 做不同的重排；`φ^U` 是簇表象的系数，它**必须**交替——否则 2D 的 `log Z` 会与精确解差 `2Σ_{n even} m_n > 0`。
4. **酸测判据（可操作版）**：任何"号定理的证明"必须满足三条 ——(i) 维度盲；(ii) 2D 给 `(−1)^{n−1}`；(iii) 不消费 `k_ℓ`、`Δ`、平面性。§2 三条全满足。反之，任何**用曲面逐项正性**推号的证明在 2D 会"恰好对"、在 4D 会**结构性崩**（`GA4:158`），那是**病**：它把 2D 的表象巧合当成机制。
