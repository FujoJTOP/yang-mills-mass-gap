## 2 · ★ `a_n ≤ t_n` 的证明（`[T]`）

**命题.** `Σ_{Γ∋p₀, |Γ|=n, Γ 连通} τ(G_Γ) ≥ #{Γ ∋ p₀, |Γ|=n, 连通}`。

*证明.* 右端每项 `1`；左端每项 `τ(G_Γ)`。`G_Γ` 连通（枚举域的定义就是"连通片集"）⇒ 由 `G_Γ` 上的 BFS/DFS 生成树**存在** ⇒ `τ(G_Γ) ≥ 1`。逐项比较，求和即得。等号 ⟺ 每个 `Γ` 的 `G_Γ` 都是树。∎

- **等价说法（更强，更好用）**：`T` 张成 `Γ` ⇒ `Γ = V(T)`，故 `t_n = #{(Γ,T)} = #{n 顶点树 T ⊆ G : p₀ ∈ V(T)}`，而 `a_n = #{连通 n 片集 ∋ p₀}`。`Γ ↦ (Γ, 任一生成树)` 是**单射**（`Γ` 由 `T` 的顶点集还原）⇒ `a_n ≤ t_n`。`[T]`
- **全部内容就是 `τ ≥ 1`**，没有第二条来源；这也说明它**不可能**比"连通 ⇒ 有生成树"更强（`[T]`：图论恒真，不依赖 4D、不依赖 `Δ=20`）。

## 5 · ★ 推论与缺口（`[E]`，`w7/adj7_ratio.log`）

`a_n ≤ t_n ≤ B^n` ⇒ `a_n^{1/n} ≤ t_n^{1/n} ≤ B` ⇒ `limsup a_n^{1/n} ≤ limsup t_n^{1/n} ≤ B`。`[T]`（逐项取根、取极限，无额外假设）

| 量 | 值 |
|---|---|
| `B = 19¹⁹/18¹⁸` | `50.2820906008560238796321500140` `= 1978419655660313589123979 / 39346408075296537575424` |
| `B/48` | `1.0475435541845004975` |
| **缺口 `B/48 − 1`** | **`4.7543554185%`** |
| 需降多少才到 48（`1 − 48/B`） | `4.5385754124%` |
| `a_n ≤ B^n`（有理数精确，`n=1..6`） | **全 True** |
| `a_n^{1/n}`（`n=1..6`） | `1, 4.472136, 7.708239, 10.271723, 12.288132, 13.901997` |
| `t_n^{1/n}`（`n=1..6`） | `1, 4.472136, 8.291344, 11.705791, 14.625581, 17.106662` |

- 夹逼：`a_n^{1/n}` 升 ⇒ `liminf a_n^{1/n} ≥ 13.902`；上界 `B = 50.282` ⇒ **`48` 在夹逼里面**（`[13.902, 50.282]`）。`[T]`+`[E]`

## 6 · 判（对照三条死线）

### (a) `a_n ≤ t_n` 成立且 `B` 界 `t_n` ⇒ **`a_n ≤ B^n`，缺口 `4.7544%`** —— **成立** `[T]`+`[E]`
上表 `a_n ≤ B^n` 六项全 True；缺口数字 `4.7543554185%` 与 `TN1:61` 的 `4.75%` 逐位一致。**这是本路的目标，达成，但目标本身没开窗**（`a_n ≤ 48^n` **未证**，判据 `t_n^{1/n} ≤ 48` 也**未证**）。

- **必须写死的方向性**：`a_n ≤ t_n` 只把 `t_n` 的界**传给** `a_n`，不能反传；KP 判据落在 `t_n`（`TN1:29`）⇒ `a_n ≤ B^n` 是判据的**弱化版**。**真正的内容在反向**：任何"`λ_T ≤ 48`"的证明都**自动**给 `λ_a ≤ 48`——片集侧**永远不需要自己的论证**。这是本不等式唯一的净收益 `[T]`。

### (b) `τ ≥ 1` 有例外吗 —— **无**（在定义域上）`[T]`+`[E]`
`τ ≥ 1 ⟺ G_Γ 连通`（生成树存在性），枚举域就是连通片集，`n ≤ 6` 全量实测 `7 510 554` 个集合 `min τ = 1`、零个 `τ = 0`。**承重条件**：若把 `a_n` 换成"全部 `n` 元片集"，§4 的反例使不等式立假——所以"连通"必须写在 `a_n` 的定义里，不是可以省掉的修饰。

### (c) `B` 的推导只对特定类吗 —— **否** `[T]`
`TN1 §3`：每条 `(Γ,T)` 经唯一提升映到 20-正则树（万有覆盖）中的 `n` 子树，**单射**；计数由 `F = x(1+G)^{20}`、`G = x(1+G)^{19}` 给出，`y = 19/18` 为临界点 ⇒ `B = 18(19/18)^{19}`。无 `n` 限制、无 `Γ` 类限制、无 `β`/`L` 依赖。**但**它界的是"片集+树"的对象，不是 `λ_a` 本身；把它搬到 `a_n` 上合法（`a_n ≤ t_n`），代价是 `(t_n/a_n)^{1/n}` 的松（§5）。
