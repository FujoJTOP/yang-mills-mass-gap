## §2 五机制：最小公式 + 逐个排除

**先把表变成可能的三条引理**（本轮新增，各 2–4 行）。

### 引理 GN1-A（等价化：`(NEW)` = 谱无掉队极限点）`[T]`

设 `H_a ≥ 0`、`Δ_a := inf{λ∈σ(H_a): λ>0}`、`Δ_cont := inf{λ∈σ(H): λ>0}`。则
```
(NEW)  Δ_cont ≤ liminf_{a→0} Δ_a     ⟺     limsup_{a→0} σ(H_a) ∩ (0, Δ_cont) = ∅ .
```
*证.*（⇒）设 `E* ∈ limsup σ(H_a)`、`0<E*<Δ_cont`。则 ∃`a_n→0`、`λ_n∈σ(H_{a_n})`、`λ_n→E*`；`λ_n>0`（`n` 大）⇒ `Δ_{a_n} ≤ λ_n` ⇒ `liminf Δ_a ≤ E* < Δ_cont`，与 `(NEW)` 矛盾。
（⇐）取子列 `Δ_{a_n} → E := liminf Δ_a`。若 `E=0` 则 `(NEW)` 平凡。若 `E>0`，取 `λ_n∈σ(H_{a_n})`、`0≤λ_n≤Δ_{a_n}+1/n`（`Δ_a` 未达到时用下确界逼近），则 `λ_n→E>0` ⇒ `E ∈ limsup σ(H_a) ∩ (0,∞)`；由假设 `E ∉ (0,Δ_cont)` ⇒ `E ≥ Δ_cont`。∎

> **读法**：`(NEW)` **不是**一个"界"，是一句**谱集的上半连续**：格点谱不许有极限点**严格掉在**连续统底之下。已证的 `σ(H) ⊆ limsup σ(H_a)`（`REPORT:279`）给"每个连续统能级都有格点列逼近"；`(NEW)` 给"**没有多余的**逼近"。合起来就是 `REPORT:291` 里那条"更强、不必要"的 Hausdorff 收敛 —— **本轮把它证明成"必要且充分"**（在同一 `SPEC-RES` 记账下）。⇒ `(NEW)` **不是**新物理，是 `σ(H_a)→σ(H)` 的**上半**那一半。

### 引理 GN1-B（无凹陷定理的唯一可证形：边原子一致下界 ⇒ `(NEW)`）`[T]`

设 `ν_a, ν` 为 `[0,∞)` 上概率测度、`ν_a ⇒ ν`（弱），`Δ_a := inf supp ν_a`、`Δ_cont := inf supp ν`。若
```
(EDGE-ATOM)   ∃c>0 ∀a:  ν_a({Δ_a}) ≥ c²        （= 边原子带一致正权 = f₁²(边) ≥ c²）
```
则 `Δ_cont ≤ liminf_a Δ_a`。
