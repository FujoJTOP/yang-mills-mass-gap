## §1 精确分解（逐点恒等，三行）

```
记 x:=½Re tr U_□=1−q；取 □ 的一条 link ℓ=U₁，W:=U₂U₃U₄∈SU(2)，A:=Σ_{p∋ℓ}W_p（六片；W_p = p 去 ℓ 的三链积）
(N1) 四元数 u,w：|w|=1 ⇒ x=u·w=u·ŵ；|W_p|=1 ⇒ |A|≤6，c:=β|A|≤6β                          [T] 代数
(N2) 给定 rest=Λ∖{ℓ}：U₁ 的律 ∝ exp[β u·A]（vMF，c=β|A|），
     E[u·ŵ|rest]=m₁(c)cosθ，Var(u·ŵ|rest)=α(c)+(b(c)−α(c))cos²θ，
     cosθ:=ŵ·Â，α:=(1−m₂)/3，b:=m₂−m₁²，m_k:=∫x^k e^{cx}√(1−x²)dx/Z                [T] vMF 两行
(N3) Var(q)=E[Var(q|rest)]+Var(E[q|rest])=E[b(c)]+E[(b−α)(cos²θ−1)]+Var(m₁cosθ)      [T] 总方差
     b≤α ∀c ⇒ 中项 ≥0（(b−α)≤0 且 cos²θ≤1 两负相乘）⇒ Var(q)≥E[b(c)]≥b(6β)            [T]
```

**(N2) 的易错点（本路自查，留痕）**：可按规范轨道平均的只是 `e₀·Â`（两端点规范各把 `A` 单侧搬 ⇒ `E[(e₀·Â)²]=¼`），**不是** `ŵ·Â`：`W` 与 `A` 在两端点规范下**同向**搬（`W→Wg^†`、`A→Ag^†`），故 `cosθ` 是**规范不变量**。若误按 `E[cos²θ]=¼` 代入，会得到 `(3α+b)/4=4.67e−2`——那不是定理，本路已作废。

## §3 判据、三条路、具名障碍

**3.1 条件方差对 `σ` 的方向 `[T]`**：`σ₁⊆σ₂` ⇒ `E[Var(X|σ₂)]=E[X²]−E[E[X|σ₂]²]≤E[X²]−E[E[X|σ₁]²]=E[Var(X|σ₁)]`。故 `σ₄`（除 □ 四 link）**粗于** `σ₁`（除单 link）⇒ 四链条件项 `≥` 单链条件项；`HZY-C0:0.7` 的 `6.42e−3` 是**最细** `σ` 一侧的保证值，不是四链的上限。**四链形不因此关闭**：要它出数须算「四链 + 四外场（`|A_i|≤5`）」的最坏情形；最坏外场（全对齐）下每条 link 的有效倾角回到 `6β`，`b` 那一半回到 `b(15)`，剩余增益只能来自 `E[q|σ₄]` 的起伏——一笔**待算**的数，不是恒等。

**3.2 二阶矩与楔形环**：`|A|²=Σ_{p,p'}½tr(W_pW_p'^†)=6+2Σ_{p<p'}½tr(W_pW_p'^†)` ⇒ `E|A|²=6+2Σg`（15 对，`g` = 6 链楔形环期望）。0.7 要 `E|A|²≤2.7225`，即 `Σg≤−1.639`；若 `Σg≥0` 则前提**必假**（`E|A|²≥6`，比"单个 staple 的平方"还大就不可能更小）。仓内对 `g` 的符号/大小 0 条（§5 检索式①，命中全为别的对象）。

**3.3 特征标形**：`x=½χ_{1/2}`、`χ_{1/2}²=1+χ₁` ⇒ `4Var(q)=1+⟨χ₁(U_□)⟩−4P²`。`P=E[m₁(c)cosθ]≤E[m₁(c)]≤m₁(6β)=0.9018` ⇒ `Var(q)≥0.07` ⟸ `⟨x²⟩≥0.8832`（`⟨χ₁⟩≥2.533`）；读数 `⟨x²⟩=0.50005`、`⟨χ₁⟩=1.00019` ⇒ 该形要求近有序，不是近路。

**3.4 具名障碍（一句话，可当靶）**：
> **自绞对齐**：单链路把可观测量写成 `x=u·ŵ`、把倾角写成 `β(W+Σ₅W_p)`，而 `ŵ` 是倾角**自己的一项** ⇒ `cosθ=ŵ·Â` 恒为规范不变量、不可按规范轨道平均；免费输入只到 `|A|≤6`，于是条件项只到**逐点下确界** `b(6β)=6.42e−3`（在 `|A|=6,cosθ=1` 取到），而 `0.07` 所需的 `|A|` 之律（`Σg≤−1.639`）与 `cosθ` 之色散（`Var(m₁cosθ)≥0.07−E[b]`）两件在仓内均为 0 条供给。
