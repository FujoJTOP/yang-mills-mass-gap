## §0 五列的定义（读表前必须过一遍）

1. **量纲**：一律写成"格点单位（无量纲，a=1）/ β 的幂 / N 的幂 / 质量² / 群曲率(1/a²)"之一，并给出**倒推依据**（它进入的那条不等式，两侧靠什么配平）。
2. **强度量 / 广延量**：显式写出**是否已被除以** `N_p = 6L⁴`（plaquette 数）或 `V = L⁴`（site 数）或 `|E| = 4L⁴`（link 数）。
   - `强度` = 每 site / 每 plaquette / 每 link / 每 generator 的量；跨 L 应稳定。
   - `广延` = 未除、随 L⁴ 增长；**引用时必须同时给出"除以了什么"**，否则跨文件不可比。
3. **方向**：`inf` = 在判据里当**地板/下界**用（越大越好，要证明它 ≥ λ）；`sup` = 当**天花板/上界**用（越小越好，要证明它 ≤ λ）；`比值` = 既非 inf 也非 sup，只是无量纲比（不能当界引用）。
4. **两处位置不同（R1 的教训）**：同一个量在 (★)（BD/Polchinski 判据）与 `Q(∞)`（谱桥的积分负部）里的位置不同 —— (★) 里出现的是**逐点 λ̇(t)**，`Q(∞)` 里出现的是**时间积分**。混用即 P0。本表对每个这种量单独标"进 (★)"或"进 Q(∞)"。
5. **`N/8` 与 `½Ric` 的尺度**：`N/8` 是**群空间曲率**，格点单位里 O(1)，A-场单位里带 `1/a²`（`R1-BRIDGE.md:254`）。它不是质量；把它当质量隙证书的那一步是错的（同处）。

## §2 矛盾清单（同量两用 ⇒ P0 候选；逐条给"哪两处冲突 / 谁对"）

**共 10 条。前 3 条是本节新抓的（此前未被任何文件并列对比），其中 C1 与 C3 各含一个"两处同时承重"的硬冲突。**

### C1 ★★★ `sup|∇S_W|² ∝ L⁴`：**同一量在三处被当成三种东西**（广延量当 sup 用；单构型点值当 sup 用；迹当算子范数用）

- **冲突方 A**：`MC-METRIC.md:251–257` 与 `LOOP-RUNBOOK.md:408–409/484` —— "`sup|∇S_W|²` 是**广延量**，实测 `900→14400`，`∝L⁴`，**这就是本路的真实死因坐标**；真正的敌人是体积"。
- **冲突方 B**：`w7/dn_density.log`（同目录、同脚本族、可重跑）——
  - `S1/S2`：`900 / 14400` 是**单构型点值**（z₂ s=0.5），**不是对测度或对场取的 sup**；`S5` 用贪心上升给出 `d_sup ≥ 21.575346`（密度），即 `9.375` 比真 sup 低 **2.30×**；`S7` 给 Gibbs 均值 `5.1227`，`sup/均值 = 4.21×`（同阶，无指数差）。
  - `S8`：语料引的数是 `tr(Cov)`，**矩阵维数 `E=4L⁴` 的迹**；`‖Cov‖_op` 的行和是 `3.5 / 4.3 / 3.4`，**跨 L 恒定**；并且 `t=∞` 的精确恒等式 `Cov_ν(∇S_W) = E_ν[Hess S_W]` 给**严格**的 `‖Cov‖_op ≤ 6β = 15`，`L`-一致。
- **谁对**：**B 对**。`L⁴` 是**迹 / 维数**伪影，不是增长的物理机制；`900→14400` 的 `16=(4/2)⁴` 正是 `E=4L⁴` 的比。把 `tr` 当 `sup`、再当 `2`-范数进 `Hess V_t ⪰ −[sup|Hess S_W| + sup|∇S_W|²]`，是把一个 `O(E)` 的量塞进一个 `O(1)` 的槽。
- **后果（P0）**：`LOOP-RUNBOOK.md §9` 自己给 R3 写的判死线是"**若 `L⁴` 是估计子伪影 ⇒ BD 路障消失**"。该条件**已被触发且未回填**：`LOOP-RUNBOOK §8.2`、`MC-METRIC §5.3/§6.1`、`R1-BRIDGE §8.2` 三处仍把 `L⁴` 写成"引理级死因"。若 B 成立，则 BD/(★) 路线的死因从"体积"退回"`Q(∞)` 的一致性"，与 `sup|∇S_W|²` 无关。
- **旁证（同目录、并行任务在跑）**：`w7/r3_l4.log S1` 给出**解析**上界 `|∇S_W|² ≤ 9β²·#links = 36β²L⁴ = 225L⁴`（β=2.5）—— 这是**广延**上界本身（`#links = 4L⁴` 出现在式子里），与 B 的诊断同向：`L⁴` 的来源就是"对 `4L⁴` 个 link 求和"，不是任何单个方向的增长。

### C2 ★★★ 距离 `2.5−阈值`：`120×` 与 `13.3×`，差恰好 `N²`

- **冲突方 A**：`LOOP-RUNBOOK.md:279`、`CTL-CLOSEST.md:57/221/268`、`UC-COMPLETE.md:196`、`R4-PERCENT.md:203`、`BN-RESIDUAL.md:105` —— `1/48 = 0.021`，到 `2.5` 差 **120×**。
