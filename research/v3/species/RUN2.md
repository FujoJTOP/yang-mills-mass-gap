## 0 · 一句话判

**基能出 `w₁`，出不了 `R̄`。**
(a) **部分成立**：`L=6,T=12` 上算符基够 `w₁`（`[C]`）；**不够 `R̄`**（`R̄` 是 UV 量，见 §3）。
(b) **成立**：`R̄` 的定义**是清楚的**（`[T]`，`R̄=C″(0)/C(0)=⟨m²⟩_ν`，质量²）；不清楚的是 `p8` 的那句算子标签（"时间一阶矩"给的是 `⟨m⟩`，质量，差一个 `m₁` 幂），并且"零成本"这件事**只有下界可零成本**，而桥要的是**上界**。

## 2 · 正交化与 `S/N`（怎么保证两条门槛）

### 2.1 先说死：**原始算符空间不存在"近正交"** `[E]`
实测（`β=2.2, L=6, N=4000`）归一化 Gram：

```
t=0:  max|offdiag| = 0.929      (0-2: .723  2-4: .929  4-8: .884)
t=2:  max|offdiag| = 1.009      eig = [3.588, 0.407, 0.014, -0.009]
```
⇒ a1 的"近正交"**只能对白化后的基定义**，对裸算符不成立。另外 `t=2` 的 Gram 已有负本征值 `−0.009`（非正定）⇒ **GEVP 的度量点取 `t₀=0` 或 `1`，不取 `t₀=2`**（与 `A1-RHO-L4.md:14` 在 `L=4` 的 `15/15` 同病，但在 `L=6` 也已出现）。

### 2.2 四步方案
1. **度量**：`G = C(t₀)` 归一化为相关矩阵，`t₀=0`（或 `1`）。门槛 `rank ≥ 2`、`κ=λ_min/λ_max ≥ 0.1`。
2. **白化**：`G=VΛVᵀ`，`W=VΛ^{−1/2}Vᵀ`（截断 `λ>10^{−2}λ_max`）。GEVP：`W C(t) W` 的本征值 `λ_n(t)`，`m_n = −ln λ_n/(t−t₀)`。
3. **近正交判据**：`max_{i≠j}|(W C(t) W)_{ij}| ≤ 0.1`。在 `t=t₀` 由构造恒成立 ⇒ 真正的检验在 `t=2`。
   实测不通过：`t=2` 给 **`0.416`**（4 级 APE，`N=4000`）⇒ 必须靠几何算符（#7/#8）+ 提 `N` 才可能压到 0.1 `[E]`。
4. **`S/N` 估法（这一步有个坑）**：**不要**用 `u14_analyze.conn` 的逐块自心化做 jackknife——它给每块注入 `2mσ/√N_b` 噪声，`4/16/32` 块给 `se=0.20/1.29/2.94`（随块数发散），与两半分割差 `28×`。
   固定整体均值后，20 块 delete-one JK 与 400 次 block bootstrap 一致到 `0.01`。

## 3 · `R̄ = M₁/M₀` 的估法

### 3.1 定义（`[T]`，逐字口径）
`ν` 定义在 `s=m²`（`m` = 能量）；`M_k = ∫ s^k dν`、`C(t)=∫e^{−mt}dν=Σ_n f_n² e^{−m_n t}`
（`docs/paper-v2/ch02-squeeze.tex:12–13`、`PROOF-P3-UNCONDITIONAL.md:19`）。
⇒ `M₀ = C(0) = ∫dν`（总谱权）、`M₁ = C″(0) = ∫m²dν`（"平均质量²"）、**`R̄ = M₁/M₀ = ⟨m²⟩_ν`，量纲 = 质量²**（`ch05-theorems.tex:426–428`）。
桥：`f₁² ≥ M₀(Λ★−R̄)/(Λ★−m₁²)`，`Λ★=ρ²m₁²` ⇒ `w₁ ≥ (ρ²−r̄)/(ρ²−1)`，`r̄=R̄/m₁²`（`P8-TRUTH.md:36–38`）。

### 3.2 零成本能拿到什么（三条，全 `[T]`）
1. `C(0)−C(1) = M₀⟨1−e^{−m}⟩`；
2. `⟨m⟩ ≥ −ln⟨e^{−m}⟩ = −ln(C₁/C₀)`（Jensen，`−ln` 凸）；
3. `R̄ = ⟨m²⟩ ≥ ⟨m⟩²`。
**方向**：桥要 `Λ★ > R̄`，即要 `R̄` 的**上界**；上面三条全是**下界** ⇒ 它们只能给余量封顶，**给不出 `w₁>0`**。

### 3.3 实测（`β=2.2, L=6, N=4000`，`m₁=1.50`，`ρ²=2.48`）`[E]`
| `s` | `C₁/C₀` | `⟨m⟩_LB` | `r̄` 下界 | 桥在此下界处 | `p8` 式算子 `r̄(lin)` | NNLS `r̄` |
|---|---|---|---|---|---|---|
| 0 | 0.1229 | 2.096 | **1.953** | 0.356 | 1.992 | 8.74 |
| 2 | 0.1989 | 1.615 | 1.159 | 0.892 | 1.145 | 1.375 |
| 4 | 0.1965 | 1.627 | 1.177 | 0.881 | 1.152 | 1.410 |
| 8 | 0.1644 | 1.805 | 1.449 | 0.697 | 1.375 | 1.908 |

- 余量上限：`ρ²−r̄ ≤ 0.53`（`s=0`）⇒ **任何可证 `w₁` 界 `< 0.356`**，且这是"测度退化成单点"才取到的极限。
- **测度可证非退化**（Cauchy–Schwarz，精确）：`(C₁/C₀)² = 0.0151 < C₂/C₀ = 0.0360` ⇒ `R̄ > ⟨m⟩²` 严格 ⇒ `r̄ > 1.953`。
- **`R̄` 随 UV 端无界增长**（NNLS 网格）：`m_max=3/4/6/10` ⇒ `R̄=6.75/10.07/19.67/52.2`、`r̄=3.0/4.5/8.7/23.2`。⇒ `R̄` 是 **cutoff 量**，不是 IR 量；`r̄≥3 > ρ²` ⇒ 桥在 `β=2.2` 上 **vacuous** `[C]`。
- `p8` 的"时间一阶矩/`m_eff` 加权"= `∫C(t)m²dt/M₀ = M₀⟨m⟩/M₀ = ⟨m⟩`（**质量**，不是质量²）。照它算得 `r̄=1.99`、桥 `0.330` —— 数值上贴近真 `r̄` 只因 `m₁≈2`，**量纲不合法**，差一个 `m₁` 幂 `[T]`。

### 3.4 附带抓到的一个内部矛盾（`[E]`，run1 必须用）
同取 `m=1.50`：`ŵ₁(1)=e^{m₁}C₁/C₀ = 0.551` 是**严格天花板**（`U14.md:56`），而 `U14.md:59` 的 `w₁(s=0)=0.577 > 0.551` ⇒ **估计量在 `m=1.50` 处自相矛盾**。
两分量闭合同样判不可行：`w₁e^{−m₁}=0.1287 > C₁/C₀=0.1229`。
⇒ 若 `w₁=0.577` 成立，则必须 `m₁ ≥ 1.546`；⇒ **run1 别固定 `m=1.50`，用 GEVP 拟合的 `m₁`**，并同时报 `ŵ₁(t)`。

## 4 · 判（死线）

**(a) 这套基能给出 `w₁` 与 `R̄` 吗？—— `w₁` 能，`R̄` 给不出。**
`w₁`：`A/M₀` 的 GEVP 投影 `[C]`；`L=6,T=12` 满足 a1 的 `L0≥6, L≥6`，`(g1)` 在 `N≈10⁴` 可过 `[E]`。
`R̄`：**`C(t)` 的有限个时间点定不出 `⟨m²⟩`**（`T=12` 只有 7 个独立点，测度无穷维）；任何重构的值都由所设 UV 端决定（§3.3）。

**(b) `R̄` 的定义不清？—— 定义清，`p8` 的算子标签不清（且"零成本"不成立）。**
`R̄ = C″(0)/C(0) = ⟨m²⟩_ν`（质量²）是 `[T]`；`p8:39` 写的"时间一阶矩"算出来是 `⟨m⟩`（质量）⇒ 差一个 `m₁` 幂，会系统性地把 `r̄` 报小、把桥报强。零成本只覆盖三条**下界**；桥要**上界** ⇒ `p8` 的"零成本欠账"应改写为"**上界欠账，且只有取 cutoff 才能给**"。

**(c) `L=6, T=12` 上基不够？—— 够 `w₁`，不够 `ρ²`/`R̄`。**
- 4 级 APE：`κ=5.4e−3 < 0.1`，第 4 级是噪声方向（`[E]`）；`t=2` 的 Gram 非正定 ⇒ 度量点只能取 `t₀=0/1`。
- `L=6` 限制涂抹半径（`n≤4`），所以 `GEVP-RHO2` 的 `n=8` 六算符配方**不可照搬到 `L=6`**。
- `ρ²` 仍不可判：`GEVP-RHO2.md:10` 的 `σ(ρ²)=8.4–3.5e7` 在 `L=6/8/12` 三档全部覆盖 `0–15`。

## 5 · run1 直接可用的清单

**抽样**：`β=2.5`，`L=6`，`T=12`，`SU(2)` Wilson，独立链 `≥8`，`N=2×10⁴`（`(g1)` 只需 `10⁴`，留 2× 余量），`gap≥10` sweep。

**测量**（每构型每时间片 8 个数）：`Σ_x ⅓Σ_{i<j}½Re tr U_{ij}`，涂抹 `{APE3D n=1,2,3,4} ∪ {HYP n=1,2}`（`α=0.5`）。

**分析顺序**（缺一步就作废）：
1. `C_ij(t)`，`t=0..6`；`C(t₀=0)` 归一化 Gram → 打印 `eig`、`κ`、`rank`；`κ<0.1` 或 `rank<2` ⇒ 加 `1×2 / 2×2`（`n=4`）。
2. 白化 `W`；打印 `max_{i≠j}|(W C(2) W)_{ij}|`（门槛 ≤0.1）。
3. 每算符 `S/N(2)`（20 块 delete-one JK，**固定整体均值**；同时报两半分割做交叉核）。
4. `m₁` 用 GEVP 拟合（**不要固定 1.50**）；`M₀=C(0)`；`w₁=A/M₀`；同时报 `ŵ₁(t)=e^{m₁t}C(t)/C(0)` 的单调序列与 `w₁ ≤ ŵ₁(1)` 的自检。
5. `C₁/C₀`、`r̄` 的 Jensen 下界、`(C₁/C₀)²` vs `C₂/C₀` 的退化检验；`R̄` **不报单值**，报"随 UV 端 `3→10` 的区间"。
6. `w₁` 的 `n`-平台：`n=1..4` 的 `w₁` 必须给出单调/收敛趋势（`u14` 的 `s`-展宽 `0.29` 只能靠这个平台压）。
