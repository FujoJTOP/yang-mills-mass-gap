## 2 `G″(0) = 4(E₀ − V(0))` 的推导

**设定**：`0+1` 维欧氏路径积分，**平直测度**（坐标无 Jacobian 权），`H = −½∂_q² + V(q)`。

**第 1 步（测度从哪来）**：`β→∞` 时欧氏路径积分的单时刻边缘 `= |ψ₀(q)|²`（Feynman–Kac；基态唯一、`L²` 归一）。这是"`ρ = |ψ₀|²`"的全部内容，也是 `G″` 与 `H` 发生关系的唯一入口。

**第 2 步（定义）**：`G″(q) := −∂_q² log ρ(q) = −2 ∂_q² log|ψ₀(q)|`。

**第 3 步（代数）**：
```
(log|ψ0|²)″ = 2[ ψ0″/ψ0 − (ψ0′/ψ0)² ]
```

**第 4 步（用 Schrödinger 方程）**：`−½ψ₀″ + Vψ₀ = E₀ψ₀` ⟹ `ψ₀″/ψ₀ = 2(V − E₀)`。代入：

$$G''(q) = 4\big(E_0 - V(q)\big) + 2\Big(\frac{\psi_0'}{\psi_0}\Big)^2(q). \tag{$\star$}$$

**第 5 步（退化成 `t03` 的式子）**：在 `ψ₀′(q)=0` 的点 —— 特别地 `V` 偶函数时的 `q=0` —— 第二项为零：

$$G''(0) = 4\big(E_0 - V(0)\big). \tag{$\star\star$}\qquad\blacksquare$$

1. **归一化**：`ℏ=m₀=1` 才有因子 `4`。带质量时 `G″ = (4m₀/ℏ²)(E₀−V(0))`；因子随归一化走，**不要**把 `4` 当普适常数。

## 3 `E₀ − V(0) > 0` 是什么条件？（并纠正 `t03` 的一句读法）

`(⋆⋆)` 给出 `G″(0) > 0 ⟺ V(0) < E₀`。这句话的正确物理读法是：

> **原点（`a=0`）落在经典允许区**（势值低于基态能量）⟹ 密度 `ρ` 在 `0` 处取**局部极大**（粒子"坐"在原点）。

`t03 §3` 把它写成"**该点处于经典禁区**"——**方向反了**（禁区是 `V>E`，不是 `V<E`）。可核的反例就在上表：

- `V = a⁴/4`：`0` 是 `V` 的**极小**、在**允许**区，`G″ = 4E₀ = +1.683 > 0`；
- `10(a²−1)²`：`0` 是 `V` 的**局部极大**（势垒顶）、在**禁区**，`G″ = −23.5 < 0`。

**顺带杀掉一个常见误读**：`G″` **不是 `V` 的曲率**。`V=a⁴/4` 有 `V″(0)=0`，而 `G″(0)=1.683≠0`。`G″` 是"**原点高度** `E₀−V(0)`"（加上 `(⋆)` 的 `(ψ₀′/ψ₀)²` 与测度权修正），不是任何二阶导的几何量。这正是判死线 **(c)**。

**它什么时候 `>0`？** 只要 `V(0) < E₀`。对"对称单井、井底在 `0`"的模型（`V(0)=min V`），`E₀ = min V + 零点能 > V(0)` **恒成立** ⟹ `G″>0` 是**通例**，不是判据。这与 `t03 §3` 的"几乎恒真"一致，但理由不是"禁区"，是"允许区/密度峰"。

## 4 为什么 `G″` 与 `m` 无关（三条独立机制）

### 4.1 局部 = 高度（`(⋆⋆)` 的直接后果）
`G″(0)` 只取决于**两点数据** `(E₀, V(0))`（一般点再加 `ψ₀′/ψ₀` 与测度权）。`E₀−V(0)` 是**一个数**，说的是"原点坐得多高"；`m = inf(spec∖{E₀})−E₀` 是**整个谱底之上的一步**。一个是 `V` 的**局部**泛函，一个是 `V`（在给定动能归一化下 `ρ` 与 `V` 互相决定）的**整体**泛函。**单点数据不可能等于整体泛函**——这不是"选错了局部量"，是维数不够。`[T]`

### 4.2 边缘同一性（本文件的主判据，比"曲率不够"更硬）`[T]`
M6 与 `ω`-谐振子是**两个不同模型**（`m=0` vs `m=ω`），但它们的 `a`-边缘是**同一个函数**：

```
sup_a | ρ_a^{M6}(a) − ρ^{HO}(a) | = 2.259e−14     (同网格 na=401)
G″_M6 = 2.000600 ,  G″_HO = 2.000600              (m: →0 vs 0.999800)
```

> **引理（边缘盲）.** 设 `F` 是 `ρ_a` 的任意泛函（含 `a=0` 处的**任意阶** jet、含整个函数、含一切矩）。则 `F(M6) = F(HO_ω)`。若 `F` 还满足 (ii)（在谐振子上 `>0`，因 `m=ω>0`），则 `F(M6) > 0`，**与 (i) 要求的 `F(M6)=0` 矛盾**。∎

⇒ **任何只依赖单坐标边缘（哪怕整条边缘曲线）的量都不可能当靶**。`m=0` 的信息全在**自由方向**里，而单方向边缘对它**结构性地不可见**。这是"M6 为什么能当反例"的最终解释，也解释了为什么"再换一个 `ρ_a` 的导数"永远换不出来。

### 4.3 IR 标度（量纲论证）
`G″ = 2ω` 对 `L` **零依赖**（三个 `L` 上同一数）；`m_L ∝ L^{-2}`。两个量的 IR 标度指数不同（`0` vs `−2`）⟹ 不存在常数因子、单调函数、或任何与 `L` 无关的变换把它们联系起来。**除**非自由方向被"关掉"（`L` 有限且 `L` 小到 `b`-模被 `a`-模压住）——那正是 `L=2` 那一行（`m=ω`，两量巧合同值），也正是一切"看起来对"的假象的来源。

## 5 什么量才有关：`Λ`（三者兼顾），以及为什么"局部修正"不够

### 5.1 正确的靶 `[T]`
$$\Lambda(\rho,\nabla) := \inf_{f\in H^1(\rho),\ \mathrm{Var}_\rho f>0}\ \frac{\tfrac12\int|\nabla f|^2\,d\rho}{\mathrm{Var}_\rho(f)} \;=\; m .$$

**为什么是恒等而不是不等式**：基态变换 `H = ψ₀(−L)ψ₀^{-1} + E₀`，`L = ½Δ − ∇φ·∇`（`φ = −logψ₀`，`ρ = e^{−φ}·Z`），把 `H` 谱平移到 `−L` 谱；`L` 在 `L²(ρ)` 上自伴，且 `½∫|∇f|²dρ = ∫f(−L)f dρ`。故 `Λ = m`。`[T]`

**三种等价读法**（同一个对象的三张脸）：
1. **测度侧**：`ρ=|ψ₀|²` 的 **Poincaré 常数**（`1/Λ` 是 `Var ≤ C·½∫|∇f|²` 的最优 `C`）；
2. **算子侧**：`L` 的谱底之上第一个特征值（`= m`）；
3. **关联侧**：连通欧氏关联的**指数衰减率** `m = −lim_{t→∞} t^{-1}\log⟨O(t)O(0)⟩_c`（对"看得见最慢模"的 `O`；`M6` 取 `O=b` 时关联不衰减 ⟹ `0`）。

### 5.2 局部最坏方向修正 `Γ₀` 不够 `[T]/[T]*`
`Γ₀ := λ_min(−D²log ρ)(0)`（把"单方向"换成"全方向取 min"）：

| 模型 | `Γ₀` | `m` | 满足? |

⇒ `Γ₀` 只在"M6 那种由**平坦方向**造成的退化"上有效；2D YM 的隙**不来自 `ρ` 的形状**，来自群流形的紧性（动能算子本身）。**这是全篇的分水岭**：

### 5.3 `Λ` 的用处（诚实版）
`Λ = m` 是恒等，所以它**不**给出新的充分条件；它的用处是**换形式**：把"证有隙"变成"证一条带权 Poincaré 不等式"，后者有可查的**充分**判据族——点态曲率（Bakry–Émery：`−D²logρ ⪰ κI ⟹ Λ ≥ κ/2`，HO 上取等：`κ=2ω, Λ=ω`）、Gross 的 `LSI ⇒ Poincaré`（语料 `RATE-UNIFORM.md:21/54`）、Lyapunov/漂移条件。**缺的那一步仍然是"一致下界"（墙），不是"缺一个量"**——与 `U05 §0` 的判词一致。
