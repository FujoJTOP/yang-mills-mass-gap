## §1 `Ric_g = (N/4)g` ⇒ 半 Ricci 项 `N/8`

**推导（8 行，`[T]`）**

1. 双不变度量的截面曲率：`K(X,Y) = ¼|[X,Y]|²_g`（Milnor 1976；Besse Ch.7）`[R]`。
2. 取正交归一的 `{e_i}`：`Ric(X,X) = Σ_i K(X,e_i) = ¼ Σ_i |[X,e_i]|² = ¼|ad_X|²_HS`。
3. `[λ_a,λ_b] = Ω^c_{ab}λ_c`，`Ω` 全反对称（`Ω^c_{ab} = −2tr([λ_a,λ_b]λ_c)`），故 `|ad_{λ_a}|²_HS = Σ_{b,c}(Ω^c_{ab})²`。
4. 恒等式 `Σ_{b,c}(f_{abc})² = N`（本归一；数值 `[N]`：SU(2..5) = `2, 3, 4, 5` 精确）。
5. ⇒ `Ric(λ_a,λ_a) = ¼·N = N/4`，各向同性 ⇒ **`Ric = (N/4)g`**。
6. 独立交叉核对（`[N]`）：Koszul 式 `Ric_ab = Γ^c_{cd}Γ^d_{ab} − Γ^c_{bd}Γ^d_{ac}`、`Γ^c_{ab} = ½Ω^c_{ab}` ⇒ `Ric = diag(N/4)`：SU(2) `0.500`、SU(3) `0.750`、SU(4) `1.000`、SU(5) `1.250`。
7. **为什么判据里是 `½Ric` 而不是 `Ric`**：Γ₂ 恒等式 `Γ₂(f) = ‖Hess f‖² + ⟨(Hess V + Ric)∇f,∇f⟩ ≥ 2λΓ`（Bakry–Émery）。BBD (3.100) 的 `λ̇` 就是这里的 `λ`（`Ent ≤ (2/γ)E`、`1/γ = ∫e^{−2λ_t}`），于是判据写作
   ```
   Hess V + ½Ric ⪰ λ̇ g      ⟺      Hess V + Ric ⪰ 2λ̇ g
   ```
   —— `½` 是在把 `2λ` 折成 `λ` 时**同一次**搬过来的（下面 §4 的 `2` 与它不同源，别混）。
8. 校准：平坦 `ℝⁿ`、`V = ½|x|²` ⇒ `Hess V = g`、`Ric = 0` ⇒ `λ̇ = 1`，而 `N(0,1)` 的 LSI 常数（`Ent ≤ (2/γ)E`）`γ = 2 = 1/(1/2)`，`1/γ = ∫₀^∞e^{−2λ̇t}dt = 1/2` ✓ 自洽。紧群上 `V≡0`：`λ̇∞ = ½Ric = N/8`，`1/γ = 1/(2λ̇) = 4/N` ⇒ `γ ≥ N/4`。

**数值**：SU(3) `Ric = 0.750 g`、`½Ric = 0.375 g`；SU(2) `0.500 / 0.250`。与 `AT-STAR` §1（`Ric=(N/4)g`、`½Ric=(N/8)g`）、`MC-METRIC` §2.4（`sup_G λ_min(δ⁻¹Ric_G) = N/4`：SU(2) 0.500、SU(3) 0.750）**逐位一致** `[N]`。

**归一换算表**（`s := g/g_phys`，`g_phys = −2tr(XY)`；规则 **`½Ric/g_s = N/(8s)`**）

| 归一 | 生成元/度规 | `s` | `Ric/g` | `½Ric/g` | SU(3) | SU(2) | 典型误抄场景 |
|---|---|---|---|---|---|---|---|
| **A 物理（语料固定）** | `tr T^aT^b=½δ`；`g = −2tr(XY)`（`{λ_a}` 正交归一） | 1 | `N/4` | **`N/8`** | **0.375** | 0.25 | —（正确） |
| B 数学/常见 SM 写法 | `tr T^aT^b=δ`；`g = −tr(XY)` | ½ | `N/2` | `N/4` | 0.75 | 0.5 | "半 Ricci = N/4"——**与 A 的 `Ric` 同形，最易混** |
| C 双倍放大 | `g = −4tr(XY)` | 2 | `N/8` | `N/16` | 0.1875 | 0.125 | 把`−tr` 再乘 2 / 双次半化 |
| D Killing 归一 | `g = −K = N·g_phys` | `N` | `1/4` | `1/8` | 0.125 | 0.125 | Besse 的 "`Ric = ¼g`" 原句（**与 N 无关**） |

> 一句话：**看到 `N/8` 先问 `s`。** 同一个几何对象在 `s=1, ½, 2, N` 下分别是 `N/8, N/4, N/16, 1/8`。语料取 `s=1`，`N/8 = 0.375`（SU(3)）**正确**；把它写成 `N/4` 等于偷了 B 行的 `s`，`N/16` 等于 C 行。

## §2 `λ_tH = βN`、`g² = 2N²/λ_tH` ⇒ `g² = 1 ⟺ λ_tH = 2N²`

**推导（5 行，`[T]`）**

1. Wilson 作用量：`S_W = β Σ_p (1 − (1/N)Re tr U_p)`。
2. 小 `a` 展开：`1 − (1/N)Re tr U_p = (a⁴/4N)·tr F²_μν + O(a⁶)` ⇒ `S_W → (β/4N)∫tr F²`。
3. 与连续作用量 `(1/4g²)∫tr F²` 比较（本归一下 `tr F²` 就是标准 `tr F²`）⇒ **`β = 2N/g²`**。
4. `λ_tH := βN`（格点归一化量，**不是** 't Hooft 耦合 `g²N`）⇒ `λ_tH = 2N²/g²` ⇒ **`g² = 2N²/λ_tH`**。
5. 故 `g² = 1 ⟺ λ_tH = 2N²`。

**数值**：

| N | `2N²` | β=2.5 处 `λ_tH = βN` | 该点 `g² = 2N²/λ_tH` | 交叉核对 `g² = 2N/β` |
|---|---|---|---|---|
| 2 | **8** | 5.0 | 1.6 | 1.6 ✓ |
| 3 | **18** | 7.5 | **2.4** | 2.4 ✓ |

**`8` 与 `18` 不是笔误（已确认）**：`2N²` 在 `N=2` 给 `8`、`N=3` 给 `18`。语料的两个语境分别是 SU(2)/SU(3)：`BC-CHAIN` §1 表（`λ_tH=1` 处 `g² = 8 / 18`，SU(2)/SU(3)）、§4.2 数值表同；`LOOP-RUNBOOK` §0.7 也说 `2N²`（SU(3):18 / SU(2):8）。**两处都对，不是笔误。** 唯一真实风险是把它读成 N-无关常数（"`g²=1` at `λ_tH=18`"）——那 SU(2) 就错 2.25 倍；这条已在 `BC-CHAIN` §1 作为"同名不同坐标"钉过。

## §3 协变 Hessian 的界：正确常数是 **8**（不是 4.8，不是 2.9）

**结构推导（8 行，`[T]`+`[N]`）**

1. 单 plaquette，把被变 link 用迹的循环性拉到最前：`φ = Re tr(e^{σX}M)`，`M` = 其余三个 link 的积 ⇒ `D²_ab = Re tr(λ_aλ_bM)`、`d_c = σ·Re tr(λ_cM)`。
2. 双不变度量的 Levi-Civita：`∇_{e_a}e_b = ½[e_a,e_b] = ½Ω^c_{ab}e_c` ⇒
   `Hess_ab = D²_ab − ½Ω^c_ab d_c = Sym_ab(D²)`。
   这就是**"图卡"**（`D²` 本身，非张量）与**"漏 `½[λ_a,λ_b]`"**（漏 `−½Ω·d` 那一项）的准确内容：**两者是同一个缺陷的两面**。
3. 单 plaquette 协变 Hessian 的**精确谱**：`xᵀ Hess x = Re tr(A²H_W)`，`H_W = ½(W+W†)`，`A = Σx_aλ_a`，`Σθ_j² = ½`（`|x|=1`）⇒ **`sup|λ| = ½` 精确**（`W = −1` 给 `+½`、`W = +1` 给 `−½`；4000 Haar 采样 `0.4944`(SU(3))/`0.4954`(SU(2)) 贴住 `½` `[N]`）。
4. ⇒ 每条 link 的 6 个 plaquette **对角块** = `−6·(β/2N) = −3β/N`（SU(3), β=2.5 ⇒ `−2.500`）。
5. 中心（`±1`）构型上**精确 rank-one**：`Q_p = (β c_p/4N)(Σ_iσ_ix_i)²` ⇒ `Hess S_W = (β/2N)Σ_p c_p v_pv_pᵀ`，`v_p` 为带符号关联向量 ⇒ 常数是**组合量**，`λ_min = (β/N)·μ_min`，`μ_min` 与 `N` **无关**。
6. Z₂ cocycle（`U_1 = (−1)^{x₂+x₃+x₄}`，其余 `1`）：`−1` plaquette 数 = 全部 (1,ν) 面（L=2 时 48/96，L=4 时 768/1536），`λ_min(Σc_pv_pv_pᵀ) = −16`（`L=2` 与 `L=4` **同值**）⇒ **`λ_min = −16·β/2N = −8β/N`**。
7. 全块验证（8 个生成元 + Koszul 项，SU(3)、L=2、dim=512）：`λ_min = −6.666667`；梯度二阶差分校验（沿测地线 `U ↦ Ue^{εA}`，`ε=2e-3`）与 `xᵀHx` 相对误差 `≤1e-6` `[N]`。
8. 上界侧：rank-one + Cauchy–Schwarz ⇒ `|Q| ≤ (β/N)Σ_{i∈p}x_i²` 逐 plaquette 求和 ⇒ **`λ_min ≥ −12β/N`**；`8` 是**已构造达到**的值。

**数值（回答任务要求的"一个数"）**

```
SU(3), β = 2.5, d = 4:    λ_min(Hess S_W) = −8β/N = −6.6667      (L=2 与 L=4 同值)
                          ⇒ λ̇_0 ≥ N/8 − 8β/N = 0.375 − 6.6667 = −6.2917
SU(2), β = 2.5        :    λ_min(Hess S_W) = −8β/N = −10.000      （与 MC-METRIC §3.2 的 −10.000 逐位吻合）
逐 link 对角块（不含跨 link）:  −3β/N = −2.500 (SU(3)) / −3.750 (SU(2))
集体增强因子              :  8/3 = 2.667
```

**另两个数各错在哪**

| 数 | SU(3),β=2.5 | 是什么 | 错在哪 |
|---|---|---|---|
| `−(4.8/N)β` | −4.000 | `w7_pl_hess.py` 的镜像 `D²`（= `Hess + ½Ω·d`，即**图卡**且未对称化）取 Haar 采样的 sup：`6×0.80`（我复现 `0.7522`(SU(3))/`0.7628`(SU(2))） | 两处错：**(i) 图卡/漏 `½[λ_a,λ_b]`**（同一缺陷）；**(ii) Haar 采样不是 sup**（图卡形的真 sup 更接近 1） |

Haar 采样只给出更浅的值（SU(2) `4.4–4.8 β/N`、SU(3) `3.9–4.1 β/N`）⇒ Z₂ cocycle 在实测中就是最坏构型，但"全局最坏 = 8"**未证**，标 `[C]`。

## §4 谱桥的因子 2：`λ₁(μ_vac) = 2m₁`

**推导（6 行，`[T]`+`[N]`）**

1. 物理 Hamiltonian：`H_phys = ½⟨π,π⟩_g + V`，`π = −iδ/δA`（动能带 `½`）；数学 Hamiltonian：`H_math = −Δ_g + V = 2H_phys`。
2. 基态变换**精确**（相似变换，残差 `1.2e-15`）：`gap(H_math) = λ₁(μ_vac)`（`R1-BRIDGE` (1a)）。
3. ⇒ `λ₁(μ_vac) = gap(2H_phys) = 2m₁`。
4. **高斯精确校验**（不用引用）：`H_phys = ½p² + ½m²x²` ⇒ `Ω ∝ e^{−mx²/2}`、`μ_vac = |Ω|² = N(0, 1/(2m))` ⇒ Poincaré 常数 `= 1/Var = 2m = 2m₁` ✓，而 `gap(H_phys) = m` ✓。
5. 所以这个 `2` **来自 `½` 动能归一**（不是损失、不是拟合）：若把 `m₁` 定义为 `−Δ+V` 的隙则为 `1`；若度量取 `2g` 也为 `1`。
6. 方向：`γ ≤ λ₁(μ_vac) = 2m₁ ⇒ m₁ ≥ γ/2`，与 `γ ≥ (N/4)e^{−2Q}` 合起来 `m₁ ≥ (N/8)e^{−2Q}`。

**判死线**：`2` 正确，`[T]`+高斯精确，**不是 P0**。
**但要点清两件事**：
- 若漏掉这个 `2`（写成 `m₁ ≥ γ`），常数从 `N/8` 变 `N/4`：**差 2，但不会把正界变成 0**。能把"有隙"变"无隙"的只有 `Q(∞)` 的 `(L,a)`-一致性；`2` 只改常数，不改符号。
- `§1` 的 `N/8` 与这里的 `N/8` **是两个不同来源的 `N/8`**（前者 = `½Ric`，后者 = `½Ric ÷ 2`）。把这两个 `2` 当成同一个 `2` 会引入 **4 倍**错。
