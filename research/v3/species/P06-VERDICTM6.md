## §2 关键一步：M6 上 ② 是**刚性**的 ⇒ `Δ_dyn ≡ G″ = 2ω`

**`Φ ≡ 0` 在 M6 上是模型规格，不是近似**：`Φ` 是**测度/Jacobian 块**（从群 Haar 边缘化来的那些项，`ch05:203–219` 的 `eq:wgeo`）；M6 的测度是**两个 Gaussian 的乘积**（`B01-RP.md:80` 逐字），没有任何群测度、没有 `β`、没有 plaquette（`D05-FKG.md:169`、`H04-THERMO.md:157`、`D07-G.md:122` 三处独立记"无 `β`"）。于是

```
W_geo = E[Φ″] − Var(Φ′) = 0 ,      X = −2 Cov(G, Φ′) = 0
⇒  G″ = Δ_dyn + 0 + 0 = Δ_dyn .                                            (2.1)
```

再用 ③ 的 `G″ = 2ω`：

```
Δ_dyn(M6) = G″(M6) = 2ω  > 0    ∀ω > 0 .                                   (2.2)   [T]
```

**这条 (`2.2`) 与语料已有一条逐字命中的记账一致**：`LOOP-RUNBOOK.md:9747` 逐字「**M6** | `Φ=0 ⇒ W_full=0 ⇒ Δ_dyn = 2ω > 0`，**无隙却过**」；`N12-VERDICT.md` 的 M6 行同值。本文件**不新增这条事实**，只把它核到定义层（§1 三行）并给出它在 `min` 两支上的行为（§3）。

### 2.1 排除"`Δ_dyn = 0`"的错误读法（这是唯一能伪造 (b) 的入口）

若把 `Var(G)` 误读成**粗变量自己的无条件**高斯方差：`H = S″ = ω²`、`G = S′ = ω²a`、`Var_ρ(G) = ω⁴·(1/ω²) = ω²` ⇒ 得 `Δ_dyn = ω² − ω² = 0`。**这个读法必须被排除，理由是它违反 ② 本身**：② 是恒等式，`Φ≡0` 时它是**刚性**的（右边三个块，两个为零），任何给出 `Δ_dyn ≠ G″` 的读法都自相矛盾。而 `G″ = 2ω ≠ 0`（`T03` 的恒等式 `4(E₀−V(0)) = 2ω`，§6 数值核到 `6e−6`）⇒ `Δ_dyn = 0` 是**混口径**的产物，不是 M6 的性质。
**注意**：这个 `0` 恰好是**自由场酸测值**（`Δ_dyn=0` 于自由无质量场，`H5-HEAD-NUMERICS.md:258`）——它属于自由场那一格，不属于 M6。把自由场的值抄到 M6 上，就会把 `(a)` 误判成 `(b)`。`[T]`

### 2.2 归一化备注（诚实边界）

`Δ_dyn(M6)` 的**具体数值**依赖"哪一支 `G″` 被指定为 M6 的 `G″`"：按 `T03` 的 `ρ = |ψ₀|²` 归一化给 `2ω`（本文件采用，因为 ③ 就是这么写的）；按经典 Boltzmann 边缘 `ρ ∝ e^{−½ω²a²}` 给 `ω²`。**两者都 `> 0`、都严格单调增、都不改变 §3–§4 的任何判决**。差别只在常数，不影响符号、不影响 `min` 的分支判定、不影响失明结论。`[T]`

## §3 `min` 落在哪一支：这是本路最关键的细节（用户第 3 条）

**谱**：`spec(H) = {nω} ⊕ {2π²k²/L²}`（`n,k ∈ ℕ`，`b` 方向只有 IR 调节子 `L`，`D03-ML.md:106`；`U09-M6.md:23–28`）⇒ 最轻激发
```
m_L(ω,L) = min( ω , 2π²/L² ) .           分界点 ω*(L) := 2π²/L² .                 (3.1)   [T]
```

| 支 | 条件 | `m_L` | `Δ_dyn = 2ω` | `Δ_dyn / m` | 能否做"失明"的见证 |
|---|---|---|---|---|---|
| **小 `ω` 支** | `ω < ω* = 2π²/L²` | `ω` | `2ω → 0`（随 `ω→0`） | **`≡ 2`（常数）** | **不能**：判据余量与隙同步缩，且固定 `a,Δ₀` 下 `ω < a²Δ₀²/2` 时**判据本身就是假** |
| **大 `ω` 支** | `ω > ω* = 2π²/L²` | `2π²/L²` | **`2ω`（`L`-无关，固定）** | `ω L²/π² → ∞` | **能，且是最强形式**：`L→∞` 时 `m→0` 而 `Δ_dyn` 不动 |

**⇒ 用户的前提"要取 `ω` 小（`ω < 2π²/L²`）才有 `m = ω → 0`"是一个真陈述，但它把**见证放错了支**。** `m→0` 有两条路，只有一条能同时保住 `Δ_dyn` 的固定正余量：

- 路 I（**小 `ω` 支**，`ω→0`）：`m = ω→0` **且** `Δ_dyn = 2ω→0`。这与"失明"要的东西**正相反**——失明要求"判据成立而隙为零"，这里判据的余量也归零。
- 路 II（**大 `ω` 支**，`L→∞`，`ω` 固定）：`m = 2π²/L²→0` **而** `Δ_dyn = 2ω` **恒定**。**这才是见证。**

**语料自己的 M6 数字全部取自路 II**，这是可核的：
- `H03-ANOMALY.md:130` 逐字：`m_L = min(w, 2π²/L²) = 0.1974 / 0.01234 / 0.000771`（`L=10/40/160`，`ω=1`）。核：`2π²/100 = 0.19739`、`2π²/1600 = 0.012337`、`2π²/25600 = 0.0007711` —— **三格全部等于 `2π²/L²`**，即**全在 `ω > ω*` 支**（`ω*(10) = 0.1974 < 1`）。`[E]`
- `D03-ML.md:186` 逐字：`L=6..80` 上 `0.5483 → 0.00308`。核：`2π²/36 = 0.5483`、`2π²/6400 = 0.003084` —— 同支。`[E]`
- `N09-RESTATE.md:65` 把 `L→∞` 定为 M6 的**硬口径**（"若按固定 `L` 读，M6 的 `m_L>0`，任何以 `1/L²` 为底的量都会被误判"）。`[T]`（口径）

**⇒ 结论：`min` 的关键性判断正确（必须分支读），但关键支是 `ω > 2π²/L²`，与本轮任务前提的指向相反。**

## §4 判死线逐条

### (a) —— **成立**：小/大 `ω` **两**支上 `Δ_dyn = 2ω > 0`，而大 `ω`+`L→∞` 支上 `m→0` ⇒ **失明成立，靶死**

**见证（最简形式，一步）**：取 `ω = 1` 固定、`L → ∞`。则 `Δ_dyn = 2`（常数，`L`-无关，`ω`-无关的部分也固定）；`m_L = 2π²/L² → 0`。判据 `Δ_dyn ≥ a²Δ₀²` 由**任取 `Δ₀² ≤ 2/a²`** 即满足（`a` 在 M6 里是外部约定，`Δ₀` 是存在量词常量 ⇒ 这是合法取值，不是避重就轻）。于是

```
∃ Δ₀ > 0 使  Δ_dyn(M6) ≥ a²Δ₀²  （一切 L）   而   m(M6) = 0 .
⇒ 判据在无隙模型上成立 ⇒ 判据对"有无隙"失明 ⇒ Δ₀>0 不是合法靶 .            [T]（条件于 M6 规格）
```

这与语料已判的 `LOOP-RUNBOOK.md:9750`（"`Δ₀>0` 不是合法靶：它在 2D（有隙）上假、在 M6（无隙）上真"）与 `N12-VERDICT.md`（M6 一格 = **假阳性**）**同结论**。**`n12` 对。**

**但 `n12` 的见证句要改**：若有人按"小 `ω`、`m=ω→0`"来写这条见证，它就**可被攻击**（§3 路 I：那里判据余量同比归零，撑不住"判据成立"）。**失明必须挂在 `ω > ω*` + `L→∞` 上。** 这是本文件对 `n12` 的唯一实质性收紧。

### (b) —— **不触发**：小 `ω` 支**不复活** `Δ₀>0`

小 `ω` 支（`ω < ω*`、`m = ω`）上 `Δ_dyn = 2ω > 0` **符号仍是正的**，所以这里**不存在"`Δ_dyn ≤ 0` 的区"**。所谓"复活"需要的是"判据成立/失效与间隙同向解耦"的第三种形态，而该支给的是 `Δ_dyn = 2·m`（**同向同速率**）：隙没了，余量也没了。**⇒ 该支既不救靶、也不做见证，是"无害退化"。**
**（明确写死：(b) 不触发的判据是符号，不是余量。符号在小 `ω` 支上仍是 `+`。）**

### (c) —— **不触发**：`Δ_dyn` 对 `ω` **严格单调（线性 `2ω`）**，无分界翻号点

`ω* = 2π²/L²` 只切换 `m` 走哪一支，**不切换 `Δ_dyn` 的符号**（`Δ_dyn` 里根本没有 `min`）。⇒ 不存在"分界点处 `Δ_dyn` 变号"这种事；`∂_ω Δ_dyn = 2 > 0` 全域。`[T]`

## §5 对用户第 1/2 条**论证方式**的更正（结论对，理由不能用）

用户提议：`E[H] ≥ 0`（能量）、`Var(G) ≥ 0`（方差）⇒ 若 `E[H] > Var(G)` 恒成立（例如 `Var(G) = 1/(2ω) → 0` 而 `E[H] = ω/2 → ∞`）则 `Δ_dyn > 0`。

**这个论证形式上是空的**：`Δ_dyn = E[H] − Var(G)` 是**两个非负量之差**，两个非负性**不给出任何符号**。"`E[H]` 增长、`Var(G)` 收缩 ⇒ 差为正"只在**两者确实按该速率分离**时成立，而那正是要证的东西，不是结构性论证。逐条：

1. **`Var(G) = 1/(2ω)` 是错的量。** `1/(2ω)` 是**粗变量 `a` 自己的无条件方差**（由 `ρ_a ∝ e^{−ωa²}` 得 `Var(a)=1/(2ω)`，`L05-COUNTER.md:20` 同一数）。而 ① 的 `Var` 是**条件化在 `a₀` 后的内层方差**（§1）。两者不是同一个对象。
2. **`E[H] = ω/2` 是错的量。** `ω/2` 是**基态能量** `E₀`（`U09-M6.md:23–28`），而 ① 的 `H = ∂²V` 是**势的二阶导**。在 M6 上 `∂²V = ω²`（常数）⇒ `E[H|a₀] = ω²`（经典读法）/ `2ω`（`|ψ₀|²` 读法，= ③ 的 `G″`）。**两个都是 `Θ(ω)`，都与 `ω/2` 差一个口径。**
3. **⇒ 把 `E[H]` 读成 `ω/2`、`Var(G)` 读成 `1/(2ω)`，会得到 `Δ_dyn = ω/2 − 1/(2ω) → ∞`（真但无关），或更糟：与 §2.1 的 `ω² − ω²` 混用会得到 `0`（假）。** 结论 `Δ_dyn > 0` 仍然对，但它**不是**由这条论证支撑的。
4. **真正结构性的那一条是 §2**：`Φ ≡ 0` ⇒ ② 刚性退化 ⇒ `Δ_dyn ≡ G″`，再由 ③ `G″ = 2ω`。这**不引用任何"非负量之差"**，只用恒等式。**⇒ 请把第 1/2 条的理由换成 §2 的那一句。**

**（本文件不采信"`E[H]>Var(G)` 恒成立"这类论证；上面第 1–3 条即为其失效的具体位置。）**
