## 1. 框架（照抄 `r12`，一个符号补正）

```
⟨f⟩ = ∫|Δ|²e^{−S_W} f (da db/3)/Z ,  |Δ|² = ∏_p s(d_p) ,  s(d)=4sin²(d/2) ,  d=(a, b, a+b)
a=x₁−x₂, b=x₂−x₃, x₁=(2a+b)/3, x₂=(b−a)/3, x₃=−(a+2b)/3
Φ = Σ_{i<j} g(d_ij) ,  g(d) = −2log[sin(d/2)/(d/2)]        (O09，非 −log|Δ|²)
Φ′ = Σ_p dd_p g′(d_p) ,  Φ″ = Σ_p dd_p² g″(d_p) ,  dd_p = λ_i−λ_j
S_W = β(1 − ⅓Σ_j cos(φ_j−x_j)) ,  W = diag(−1,−1,1) ,  β=2.5 ,  λ=(1,0,−1) ⇒ dd=(1,1,2)
G = (β/3)Σ_j λ_j sin(φ_j−x_j) = ∂_τ S_W   [x_j ↦ x_j+τλ_j]
H = ∂_τ G = −(β/3)Σ_j λ_j² cos(φ_j−x_j)        ← **符号由 G 定死**（r08/r12 用 +，错）
S = ⟨H+Φ″⟩ ,  D = Var(G+Φ′)
```

**`H` 的自洽性（`[T]`）**：`G` 是盒子给的；`∂_τ` 作用在 `sin(φ_j−x_j−τλ_j)` 上得 `−λ_jcos(·)`，故
`H = ∂_τG = −(β/3)Σλ_j²cos(φ_j−x_j)`。取 `+` 号等价于把 `G` 也翻号，与盒子冲突。`β=2.5`、`θ=π` 处 `E[H]=∓0.1023022`，**这正是 `gap` 的全部差值来源**（`|Δ S| = 2|E[H]| ≈ 0.2046` 的两半）。

```
log(sin x / x) = −Σ_{n≥1} c_n x^{2n} ,   c_n = ζ(2n)/(n π^{2n}) = 2^{2n−1}|B_{2n}| / (n (2n)!)   （精确有理）
```

## 3. 奇性吸收（真正的技术点，`[T]`）

`Φ′`/`Φ″` 用到 `g′=2/d − cot(d/2)` 与 `g″=1/(2sin²(d/2)) − 2/d²`：**两处奇性** ——
`d→0` 的 `1/d`（`log` 的导数）与 `d→2π` 的 `cot`/`csc²` 极点（`s(d)` 的零点）。二者都被 `s(d)` **精确**吸收：

```
s(d)·g′(d)   = A(d) = 4(1−cos d)/d − 2 sin d                  ← 整函数
s(d)·g″(d)   = B(d) = 2 − 4(1−cos d)/d²                       ← 整函数
s(d)·g′(d)²  = E(d)² ,  E(d) = 4 sin(d/2)/d − 2 cos(d/2)      ← 整函数（平方）
```

- 60 dps 机检 4 点：`|s g′−A| ≤ 3.1e−61`、`|s g″−B| ≤ 3.8e−61`、`|s g′²−E²| ≤ 2.5e−60`（`[C]`）。
- **`r12` 的 `q2` 正是 `E²`**（`(4sin(d/2)/d − 2cos(d/2))²`）—— 我先前误读成 `A²/s`，实测两者数值上不等价；用 `E²` 才复现 `r12` 的 `D`（8 位吻合）。
- **必须有 `E²` 而不是 `A²/s`**：区间算术里 `A²/s` 在 `d₁₃=a+b→2π` 处 `s` 的区间含 `0` ⇒ `Z11 = +inf`（本脚本第一版实测，已修）。这就是"奇性要单独处理"的机检证据。

于是全部被积量（`TΦ″`、`TΦ′`、`TΦ′²`、`G·TΦ′`、`T`、`T·G²`）都是 `(a,b)` 的**整函数**：
**`log`/`cot` 的逐点界在 `|Δ|²` 权重下根本不需要** —— `r12` §4(c) 说的这一条障碍不存在。
（需要 `log` 界的只有 `Φ` 本身，而 `Φ` 不出现在 `S`、`D` 里。）

## 6. 判死线逐条

**(a) 不成立。** 按盒子自洽的 `H=∂_τG`：`S_lo − D_up = −0.102881748 < 0` ⇒ **`SU(3)` 没有严格证书，而且点估计是负的**。
`r12` 的 `+0.101724` 完全来自 `H` 的符号翻转（`+ ↔ −` 使 `S` 变 `+0.1023022` 而不是 `−0.1023022`）；
若采纳 `r08/r12` 的 `H` 约定，区间是 `[+0.1017208, +0.1017245]`（`±1.8e−6`）—— **正，但那个 `H` 与它自己的 `G` 不自洽，不能当证书**。

**(b) 区间宽度不是障碍，需要的网格点极少（外推）。** 用 `C h²`（`C=2.904e−2`，由 `N=1024/2048` 的 `dS/3` 标定）：

```
宽度 1e−3  →  N ≥ 34        宽度 1e−4  →  N ≥ 107        宽度 1e−6  →  N ≥ 1071
```

而结论需要的宽度只有 `≲0.1`。**严格化（`Cauchy` 余项）**：中点法每格
`|∫_Q F − |Q|F(c)| ≤ |Q|·(h²/24)(‖F_aa‖+‖F_bb‖)`，总余项 `≤ (h²/24)(‖F_aa‖+‖F_bb‖)·4π²`。
以 `‖F″‖≈5×10²` 估：要 `R ≤ 1e−3` 需 `h ≤ 1.1e−3`，即 **`N ≳ 5.7×10³`/维（`3.2×10⁷` 格）**，
`libmpi` 逐格区间 AD 约 `20–40 min` 单线程 —— **可行，但不在 15 min 内**；本文件给的是"网格和严格 + 余项外推"，余项标 `[C]` 不标 `[T]`。
（更省的路：因被积函数**整**，把 `(a,b)↦x` 的非周期性做一次光滑化/周期化后可用条带 `Cauchy` 界，`N` 可降到 `O(10²)`。）

**(c) `log`/`cot` 不是卡点。** 已给：`g` 的严格双侧界（§2，`24/24` 包含参照值）+ 三个整函数恒等式（§3，`1e−60`）。
**真正卡的是两件事**：(i) `H` 的符号（定义层，不是算力层）；(ii) `(a,b)` 上 `e^{−S_W}` 的非周期性使收敛只有 `O(h²)`（余项常数未证）。
