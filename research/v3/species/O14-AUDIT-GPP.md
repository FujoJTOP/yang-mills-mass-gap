## 1. 第 1 条：`G''(0)` 的独立重推

### 1.1 设定（只用对象，不用结论）

平坦图 `X_ℓ=log U_ℓ`，Haar `dU=J dX`，`Φ=−log J`，`V=S_W+Φ`。测度 `μ ∝ e^{−V}dX`（因为 `e^{−S_W}dU=e^{−S_W}J dX=e^{−(S_W+Φ)}dX`）。粗坐标 `ξ=⟨v,X⟩`，条件边缘

```
ρ_v(a) := ∫ e^{−V(X)} δ(⟨v,X⟩−a) dX ,      G(v;a) := −log ρ_v(a) .              (1)
```

### 1.2 三步推导

**(i) 纤维分解。** 写 `X = a v/‖v‖² + Y`，`Y⊥v`（因 `⟨v, X⟩=a`）。则 `dX = ‖v‖^{−2} da dY`，故

```
ρ_v(a) = ‖v‖^{−2} Z(a) ,   Z(a) := ∫_{ξ=a} e^{−V} dσ_Y .                        (2)
```

**(ii) 一阶。** `Z'(a) = ∫ ∂_a(e^{−V}) = −Z·E_a[∂_aV]`，于是 `G' = −Z'/Z = E_a[∂_aV]`。

**(iii) 二阶。** `Z'' = −Z(E_a[∂_a²V] − E_a[(∂_aV)²])`，故

```
G'' = −Z''/Z + (Z'/Z)² = E_a[∂_a²V] − E_a[(∂_aV)²] + (E_a[∂_aV])²
    = E_a[∂_a²V] − Var_a(∂_aV) .                                               (3)
```

**(iv) 换回 `v`。** 在切片上 `∂_a = ‖v‖^{−2}⟨v,∇⟩ =: ‖v‖^{−2}∂_v`，故

```
G''(v;a) = ‖v‖^{−4} { E[∂_v²V | a] − Var(∂_vV | a) }
         = ‖v‖^{−4} { E[H_vv+Φ'' | a] − Var(G_v+Φ' | a) } ,                     (4)
   H_vv := ⟨v,Hess S_W v⟩ ,  G_v := ⟨v,∇S_W⟩ ,  Φ' := ∂_vΦ ,  Φ'' := ∂_v²Φ .
```

`‖v‖=1` 时 (4) 就是 `eq:split` / `eq:v3object` 的第一行**逐字**。⇒ **第 1 条的恒等式成立** `[T]`。

**(v) 三块展开（代数恒等）。**

```
E[H_vv+Φ''] − Var(G_v+Φ')
 = (E[H_vv]−Var(G_v)) + (E[Φ'']−Var(Φ')) − 2Cov(G_v,Φ')
 = Δ_dyn + W_geo + X ,        X = −2Cov(G_v,Φ') ,                               (5)
```

与 `eq:split` 第二行、`eq:v3object` 的 `X=−2Cov(G,Φ')` **逐项一致** `[T]`。

### 1.3 `Φ` 的符号：正确（用 `β=0` 闭式钉死，不靠记忆）

单 plaquette `θ=π`、`β=0`：`V=Φ`，`ρ(a)=∫J δ(ξ₃−a)dξ`。取 `J=sin²(ρ/2)/ρ²`、`ρ=|ξ|≤2π`，代换 `r dr=ρ dρ` 得**精确**

```
ρ(a) = 2π ∫_{|a|}^{2π} sin²(ρ/2)/ρ dρ ,   I(0)=½Cin(2π),  I''(0)=−¼
⇒ G''(0) = (¼)/I(0) = 1/(2Cin(2π)) = +0.2051153 > 0 .                            (6)
```

`G''=E[Φ'']−Var(Φ')>0` 与 `Φ''⪰0`（`Φ''|_{slice}=2/r²−cot(r/2)/r → 1/6 = N/12`，与 `ch05:207–209` 的 Lemma B **独立吻合**）同号。若 `Φ` 的符号写反（`V=S_W−Φ`），(6) 会给**恰好 `−0.2051153`**，与闭式矛盾。⇒ **`Φ` 进 `V` 取 `+`、且 `Φ''` 进 `G''` 取 `+`，正确** `[T]`。

## 2. 第 2 条：`−0.08` 是怎么来的、对不对

**出处**（逐条）：`B4-VARIANCE-MAG.md:6,30`、`B3-TYPICAL-COERCIVITY.md:15–16`、`ABC2-CONSTRUCTIVE.md:13,27`、`C6-DEPENDENCE-CLASS.md:29`、`ABC-FINAL-LEDGER.md:11`。

```
|X| = 2|Cov(G,Φ')| ≤ 2√(VarG·VarΦ') = 2√(2×0.02) = 0.40 ,   slack W_geo = 0.32
⇒ G'' ≥ 0.32 − 0.40 = −0.08 < 0 .                                               (7)
```

**核数**：`√(0.04)=0.20`、`2×0.20=0.400`、`0.32−0.40=−0.08` —— **逐位正确** `[C]`。系数 `2` 也对（`X=−2Cov`）。

**三处口径必须记（不改数值，但改"这是不是一条不等式"）**：

1. **不是 Chebyshev，是 Cauchy–Schwarz。** `|Cov|≤√(VarG·VarΦ')` 是 CS；多维无全序时 Fréchet–Hoeffding 退化到 CS（`C6:29`、`C4:6`、`PROOF-SKELETON:44`）。`GPP-STRUCT §3` 行 1 的单元格里**已自标**"多维版退化为 CS"，所以标题式写法"Chebyshev 只给 `−0.08`"是**简写而不是错**，但严格读应作 "CS/Chebyshev 退化"。
2. **两个方差是实测，不是界；且暗含 `Δ_dyn≈0`。** `VarG≈2`（等分律）、`VarΦ'≈E[Φ'']−W_geo≈0.02`、`∆_dyn≈0`（`B4:6` 原文 "With `Δ_dyn≈0` (equipartition)"）。所以 `−0.08` 是**把实测数代进 CS 的算术值**，不是"Chebyshev 给出的下界"；这一点 `B4:6` 自己也写"CS is sign-blind"，`C4:33` 写"小的是 `X`，松的是界"。
3. **窗口未固定（AGENTS.md §2.1）。** `W_geo≈0.32` 的实测行是 **SU(3) `β=5.7, L=8`**：`+0.318±0.006`（`H5-HEAD-NUMERICS.md:156`）；同表 SU(2) `β=2.4` 是 `+0.254±0.005`（`:155`），单 plaquette `β=2.5,θ=π` 是 `+0.205115`（本文 §1.5）。而 `B3/B4/B5` 把这个三元组标成 `β=2.5`。**一个三元组、三个来源、一个窗口标签**——按 §2.1 必须补标。*判决不变*：CS 要闭合需 `VarG<W_geo²/(4VarΦ')≈0.8–1.3 < 2`（`B4:6`、`C4:26`），在**任何**窗口都不成立，所以"CS 只到 `−0.08`、短 `O(0.1)=λ`"的结论方向对。

**判**：数值 `OK`；作为"不等式"它不成立（实测 + 假设），`GPP-STRUCT` 的用法（说明 Chebyshev 族给不出 `G''≥0`）**结论正确**。
