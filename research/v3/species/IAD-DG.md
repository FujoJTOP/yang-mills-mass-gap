## §1 `𝔾` 是什么，`∂_β𝔾` 的目标形

### 1.1 定义（三处直读 + 一处冲突）

```
|𝔾_β⟩ := T(β)=e^{−aH_a(β)} 在 E₁(β) 的归一化本征矢（E₀(β)<E₁(β)≤…），
        取在 ν-循环子空间 H_cyc = span{(1−P₀)OΩ, (1−P₀)(H−E₀)OΩ, …}，Kato 连续相位，⟨Ω_β|𝔾_β⟩=0。
        f₁² = |⟨Ω|O|𝔾⟩|² = ν({E₁})       [T]  ch05-theorems.tex:60；ATOM1:43,45；L1C-BOUND:28
```
在 `HS-GAP-1:26–29` 的记号里 `𝔾 ≡ ψ₁`、`a₁=⟨Ω|O|ψ₁⟩`、`f₁²=a₁²`、`w₁=a₁²/M₀`。**冲突**：`D04:30` 写 `|𝔾_β⟩ 基态（PF ⇒ E₀ 单重、𝔾_β 严格正）`——那里 `𝔾`=基态=`Ω`。二者**同名不同态**，凡引 `D04` 的 `∂_β𝔾` 必先换座标（`HX6:13` 的同类事故第二次）。

### 1.2 目标形（四行，全部 `[T]`）

```
H = A X_B + B X_E ,    A=β/(2Na) , B=N/(aβ)          (KS；HX6:31；HZC:40)
∂_βH = A'X_B + B'X_E ,  A'=1/(2Na) , B'=−N/(aβ²)       (HX6:35)

(L1)  A m_nm + B e_nm = 0  (n≠m)   ⇒  K_{n1} := ⟨ψ_n|∂_βH|ψ₁⟩ = A'm_{n1}+B'e_{n1}
      = m_{n1}[A' − B'(A/B)] = m_{n1}[1/(2Na)+1/(2Na)] = m_{n1}/(Na)        ← 与 β 无关
      （m_ij:=⟨ψ_i|X_B|ψ_j⟩、e_ij:=⟨ψ_i|X_E|ψ_j⟩；同 HZC:43–44，本文件把 n 拓到全部 n≠1）

∂_β𝔾 = Σ_{n≠1} |ψ_n⟩ K_{n1}/(E₁−E_n)                                     (Kato；D04:49)
     = (1/(Na))[ |Ω⟩ m₀₁/(E₁−E₀) + Σ_{n≥2}|ψ_n⟩ m_{n1}/(E₁−E_n) ]         ← 目标形
     = −(1/(Na)) (1−P₁)(H−E₁)^{-1} X_B |𝔾⟩                                ← 算符形
分子腿 = ⟨Ω|o|∂_β𝔾⟩ = (1/(Na)) Σ_{n≥2} a_n m_{n1}/(E₁−E_n)               ← 进 f₁² 的那一格
```

**读法**：目标形里**没有** `X_E`、没有 `∂_βH` 的显式 β、没有 `O` 的归一。`∂_β𝔾` 是「约化预解式」乘「一个**固定的局域算符** `X_B` 打在 `𝔾` 上」再乘常数 `1/(Na)`：**全部 `β`-依赖住在本征基 `{ψ_n(β), E_n(β)}` 里**。这就是 `HZC:15`「分子腿的精确形状 = `m₀ₙ'`」的算符版。

## §2 三路

### 2.1 R1 核→值：`[NG]`

**(i) 核能做什么 `[T]`。** `HX6:66` 给 `⟨U|½{O,∂_βH}|U'⟩ = ½[O(U)+O(U')]·⟨U|∂_βH|U'⟩`（磁 `≥0`、电 `≤0`）。去掉权 `½[O(U)+O(U')]` 即得 `∂_βH` 的核 ⇒ **这条核与"已知 `∂_βH`"信息等价**（`HX6:11` 已把它写成 `¼X_B−(2/β²)X_E`）。再用 `(L1)` 把两项坍成一项。
**(ii) 它给不到什么 `[NG]`。** 差的是 `(1−P₁)(H−E₁)^{-1}`——约化预解式。核里没有任何 `E_n`、任何 `P₁`；而核的 `2/β²` 已被 `(L1)` 在**矩阵元层**一次换掉 ⇒ **核的 β-信息 = 零**。要数就回到 `1/(σ₂−σ₁)=1/ε`（`HS-GAP-1:50` 逐字"β-流没有消掉 `1/ε`，它复制了一份"）。
**下一手**：在 `HX6:74` 的 2-链精确模型（零 MC、整数算术）上算 `‖(1−P₁)(H−E₁)^{-1}X_B|𝔾⟩‖`，把 `‖K‖/ε` 的系数钉成一个数；若该数 `>0` 而 `ε` 无一致下界，则本路在 `R5` 的尾段上无可投。
