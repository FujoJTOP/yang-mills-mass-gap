## §0 判词（先说，不 QED）

**任务：给 `ρ² ≤ C²` 找一条与已死 150 路不同的机制，或证明其不存在。四条结论，逐条带标签。**

0. **一句话。** `ρ² ≤ C²` **不是**一个"比值型"命题：把任何上界拆开都**必然**是
   ```
        ρ² ≤ C²   ⟺   μ₁+μ₂ ≤ (1+C²)μ₁ ,
   ```
   即 **分子（两阶迹 `T₂=μ₁+μ₂`）用变分/测试函数从上方构造**、**分母（`μ₁`）用比较算子从下方压住**。
   两半属于**两种不同的机器**，且**没有任何单一机制能同时给出**（§2 RB-2 是这个"不可能"的定理形式）。
   所以：**`ρ² ≤ C²` 不能作为"第五数据模"（α）**；它最多是一个**分解坐标**（β 的失败形态），
   而它真正的价值是把战役里那句"上界是可处理的一半"**证伪**（§4 对 T3 §7 的更正）。

1. **分子半是活的、可执行的 `[T]`。** Ky Fan（rank-2 迹）原理给出**精确**等式与**可直接构造**的上界：
   ```
        μ₁+μ₂ = min{ tr(P_V L P_V) : dim V = 2, V ⊥ 1 } ,     T₂(V) := tr(G⁻¹M) ,  G_ij=⟨φ_i,φ_j⟩, M_ij=⟨φ_i,Lφ_j⟩ ,
   ```
   于是 **`ρ² ≤ T₂(V)/μ₁ − 1`，对任意一对测试向量成立**（方向正确：对 min 的上界 = 造一个测试空间）。
   这是候选 3 的形式化；它**不需要知道 `ψ₁`**（`⊥ψ₁` 被 rank-2 形式自动消掉，§2 RB-3）。

2. **分母半是死墙，而且和 H1 是同一个对象。** 所有变分原理（min-max、Ritz、Ky Fan、交错、TP₂ 第二锥、
   正性、凸性）**只能给本征值的上界**；`μ₁` 的下界**只能**来自**形式比较** `L ≥ L₀`（比较算子）——
   而那就是"禁闭动力学"（有效势无下沉井 / 曲率地板）。**`ρ² ≤ C²` 因此不是独立的第四个谓词，
   它把 H1 的困难原样继承下来**（§2 RB-2、§2 RB-8）。

## §1 新对象（定义）：rank-2 迹坐标 `T₂` 与迹比坐标 `R₂ = 1+ρ²`

### 1.1 站台

`(E,𝔅,ν)` 概率空间；`L` 是 **0⁺⁺ 投影后的粗转移生成元**：`L²(ν)` 上自伴、`L ≥ 0`、
`Lψ₀ = 0`（单重、`ψ₀ > 0`，Perron），谱离散：
```
   0 = μ₁ < μ₂ ≤ μ₃ ≤ …        （本文一律记 μ_j = "第 j 个非零本征值"，与 T3 的 μ_n 同号）
```
**记号澄清（重要，避免和 T3 的 `μ₁` 撞名）**：本节起用
```
   e₁ := μ₁,  e₂ := μ₂        （"第 1、2 个非零本征值"，取不同的值）  ⇒  ρ² = e₂/e₁
```
`ν = Σ_n g_n² δ_{e_n}`（`g_n = ⟨0|O|n⟩`），`C(t) = ∫e^{−√s t}dν(s)`。

**Rayleigh 商**：`R(φ) = ⟨φ,Lφ⟩/⟨φ,φ⟩`，`φ ∈ D(L) ∩ 1^⊥`。

### 1.2 三个定义

**(D1) rank-2 迹泛函（新对象）。** 对任意 2 维子空间 `V ⊂ D(L) ∩ 1^⊥` 及其任意基 `(φ₁,φ₂)`：
```
   T₂(V) := tr(P_V L P_V) = tr(G⁻¹ M),      G_ij = ⟨φ_i,φ_j⟩,   M_ij = ⟨φ_i, Lφ_j⟩.        (1.1)
```
`T₂(V)` 就是 `L` 在 `V` 上的两个 **Ritz 值之和**（广义本征问题 `Mx = ν Gx` 的两个根相加），
**只需 `ν₁+ν₂`、不需单个根**——这是它比"逐个本征值"可算的原因。

**(D2) 迹比坐标。**
```
   R₂ := (e₁+e₂)/e₁ = 1 + ρ²   ∈ [2, ∞),        R₂ = 2 ⟺ e₂ = e₁（无隔离）
   R₂(V) := T₂(V)/e₁ .                                                            (1.2)
```
`R₂(V) ≥ R₂`（RB-1），等式 ⟺ `V = span(ψ₁,ψ₂)`。**窗口 `ρ² ≤ C²` 就是 `R₂ ≤ 1+C²`。**

**(D3) 归一化赤字（把"缺的那一步"变成一个数）。** 给定可算的 `t := T₂(V)` 与目标常数 `C`，定义
```
   η := e₁ / ( t/(1+C²) )   ⇒   ρ² ≤ C²  ⟺  η ≥ 1 .                                (1.3)
```
`η` 度量"地板比阈值 `t/(1+C²)` 高出多少"。**`η ≥ 1` 是纯地板命题**（RB-2 的结论）；
`t` 是**可算的**（blocked Ritz / 格点 GEVP），所以 `η` 把一个"比值上界"问题**完全**化成一个
"**带上确界阈值的地板**"问题。

### 1.3 与已注册对象的差别（差在哪一行）

| 对象 | 定义 | 类型 | 与 `L` 的关系 |
|---|---|---|---|
| `H1` | `χ = ∫s⁻¹dν ≤ 1/λ` | 测度的 **(−1) 阶矩** | 非线性、非加性 |
| `G″` | 粗场条件化边缘曲率 | 某点处的**二阶导** | 局部、非谱 |
| `ρ²` | `e₂/e₁` | **比值**（非加性、非线性的谱数据） | 只依赖两个本征值 |
| **`T₂`（本文件）** | `tr(P_V L P_V) = e₁+e₂`（最优 `V`） | **和**（对谱线性） | **在固定 `V` 上对 `L` 线性** |

**唯一的新性质是"加性"**（也是它唯一的用处）：
```
   L = L₁ + L₂（可交换、共享 V 的本征向量）  ⇒  T₂(V) = T₂^{(1)}(V) + T₂^{(2)}(V).            (1.4)
```
注册表里**没有任何对象是生成元的加性泛函**——`χ`、`G″`、`ρ²`、`f₁²`、`w₁` 全不是。
加性正是"粗化/decimation 后还能算"的原因：块化把 `L` 变成 `L_b`，`T₂` 随块化**逐块相加**，
不必知道 `e₁` 的绝对值。**这就是候选 3 唯一真正可执行的内容。**

### 1.4 `ρ²` 自己的 min-max（并核方向）

```
   e₂ = min{ R(φ) : φ ∈ D(L), ⟨φ,1⟩ = 0, ⟨φ,ψ₁⟩ = 0 }                                    (1.5)
   ⇒  ρ² = e₂/e₁ = min{ R(φ)/e₁ : 同上 } .                                              (1.6)
```
**方向核对（这是本节的关键，逐条判）**：

| 装置 | 给出的方向 | 对 `ρ² ≤ C²` 是否有用 |
|---|---|---|
| `e₂ ≤ R(φ)`（**单个**测试函数，(1.5) 的 min 的上界） | 分子**上**界 | **有用**（方向正确，只需造一个 `φ`） |
| `e₁ ≤ R(φ)`（同一原理） | 分母**上**界 | **有害**（要的是分母下界；分母上界只会让比值**更大**） |
| `T₂(V) ≥ e₁+e₂`（Ky Fan，任何 `V`） | 分子（和）**上**界 | **有用**，且 `ψ₁`-free |
| `L ≥ L₀`（形式比较） | 分母**下**界 | **必需**（唯一来源） |
| `sup_V R(φ) = ∞` | —— | ⇒ 测试函数**永不**给下界（RB-2(a)） |

> **RB-1′(方向定理的雏形，`[T]`).** `ρ² ≤ C²` **当且仅当**存在 2 维测试空间 `V ⊥ 1` 使
> `T₂(V) ≤ (1+C²)e₁`。**分子半是一个"存在性/构造"命题，分母半是一个"普适性/地板"命题——两者方向相反，
> 不可能由同一个变分原理同时给出。**（证明见 §2 RB-2。）

**可执行形式（这就是本物种的"活口"）。** 取两个**粗模**（blocked 观测量）`o₁,o₂`（例如两个不同
smeared 半径的 `tr F²` 密度，或两个 block 尺度的粗场），令 `φ_i = o_i − ⟨o_i⟩`，则
```
   t = tr(G⁻¹M),   G_ij = ⟨φ_i φ_j⟩_c ,   M_ij = ½⟨∇φ_i·∇φ_j⟩_c   （Dirichlet 形式，L²(ν) 中）
   ⇒   ρ² ≤ t/e₁ − 1 ,   e₁ = 0⁺⁺ 地板 .
```
**在 `V` 固定之后 `t` 是 `(L,a)` 一致的两个数**（无小参数、无 β 展开）—— 这正是任务要求的
"不依赖维数与局部度数以外的东西"的那种量；**但它乘上的是 `1/e₁`，地板仍是硬的**（RB-2）。

## §2 该对象的控号定理（能证的写上，不能证的写"缺什么"）

### RB-1（Ky Fan rank-2 迹恒等式）`[T]`

> 设 `L ≥ 0` 自伴、谱离散、`ker L = span{1}`（单重）。则
> ```
>    e₁+e₂ = min{ T₂(V) : V ⊂ D(L), dim V = 2, V ⊥ 1 } ,        T₂(V) = tr(P_V L P_V) ,      (2.1)
> ```
> 且对**每个**这样的 `V`：`T₂(V) ≥ e₁+e₂`，等式 ⟺ `V = span(ψ₁,ψ₂)`。

*证明.* `T₂(V) = Σ_{i=1,2}⟨φ_i,Lφ_i⟩` 对任意正交基；`(φ₁,φ₂) ↦ Σ⟨φ_i,Lφ_i⟩` 在约束集上是
`(e₁+e₂)` 的 Ky Fan 极大-极小（等价地：`tr(P_V L P_V)` 的谱 = `L` 在 `V` 上的两个 Ritz 值，
min-max 给 `ν_k ≥ e_k`）。Optimum 在 `V` = 最低两维不变子空间处取得。∎

**推论 RB-1′（可执行的测试函数上界）`[T]`。** 对任意 `φ₁,φ₂ ∈ D(L) ∩ 1^⊥`：
```
   ρ² = e₂/e₁ ≤ T₂(V)/e₁ - 1 = tr(G⁻¹M)/e₁ - 1 ,    G_ij=⟨φ_i,φ_j⟩, M_ij=⟨φ_i,Lφ_j⟩ .     (2.2)
```
**这是候选 3 的确切形式，方向正确（对 min 的上界 = 造一个测试空间），且 `ψ₁`-free。**
数值核验（`rb_ratio_bound.py` PART H，path graph `N=40`，`e₁=0.023439, e₂=0.052609`）：
2000 个随机 `V` 上 `T₂(V)-(e₁+e₂) ∈ [2.529, 5.420] > 0`（无违反）；`V=span(ψ₁,ψ₂)` 时
`T₂ = 0.076048305 = e₁+e₂`（差 `1e-9`）。`[V]`

### RB-2（方向定理：变分只能给一半）`[T]`

> **(a)** 任何 min-max / Ritz / Ky Fan / 交错 / 第二锥装置都只给**本征值的上界**：
> `e_k ≤ ν_k(V)`；而且 `sup_V ν_k(V) = +∞`（把 `V` 朝高 Rayleigh 商的方向转即可），
> **所以测试空间永远给不出 `e₁` 的下界**。
> **(b)** 唯一能产下界的变分装置是**形式比较** `L ≥ L₀`（`D(L) ⊆ D(L₀)`、Dirichlet 形式逐点
> 不等式）⇒ `e_k(L) ≥ e_k(L₀)`。
> **(c)** 因此 `ρ² ≤ C²` **严格分解**为"构造 + 比较"两半：
> ```
>    ρ² ≤ C²  ⟺  ∃V ⊥ 1, dim V=2 : T₂(V) ≤ (1+C²) e₁                                        (2.3)
>             ⟸  [ ∃V: T₂(V) ≤ t ]  ∧  [ L ≥ L₀ , e₁(L₀) = λ ]  ∧  [ t ≤ (1+C²)λ ] .         (2.4)
> ```
> **(d)** 反向读法（同样 `[T]`）：`ρ² ≤ C² ⇒ e₁ ≥ e₂/C²`。**即窗口的上界 `C²` 本身就是一个
> "地板 / 分子" 的比较式，不是新坐标。**

*证明.* (a) min-max；(b) 形式比较的单调性（Rayleigh 商逐点比较）；(c)(d) 代数。∎

> **RB-2″（等价式，本文件的主定理）`[T]`。** 令 `t := T₂(V)` 为某一对**显式**粗模上算出的
> rank-2 迹（有限、可算、无小参数、`(L,a)` 无关）。则
> ```
>        ρ² ≤ C²      ⟺      e₁ ≥ t/(1+C²) .
> ```
> **窗口的上半 = 一个"带上确界阈值的地板命题"。** 阈值 `t/(1+C²)` 是**可算的**（blocked Ritz），
> 所以这句等价把一个比值问题**完全**换成 `H1`-型的绝对地板问题——`ρ² ≤ C²` 因此**不是**独立谓词。

**这就是候选 3 的判词**：方向对、可执行、**但只给一半**；另一半（`e₁` 的下界）与 `H1` 是同一个对象。

### RB-2′（候选 2 判死：Cauchy 交错给不出比值上界）`[T]+[V]`

交错：`W ⊂ H`, `dim W = m` ⇒ `e_k(L) ≤ ν_k(L_W)`，`k ≤ m`（压缩**抬**本征值）。于是

| 粗空间 `W`（path `N=8`，`ρ²_true = 3.879385`） | `ρ²(W)` | 与真值关系 |
|---|---|---|
| `span(δ₁,δ₂)`（相邻两点） | 3.000000 | **< 真值** |
| `span(ψ₁,δ₁)`（最低模 + 一个 δ） | 4.605348 | **> 真值** |
| `span(δ₁,δ₄)`（隔开两点） | 1.000000 | << 真值 |

**⇒ 交错与压缩/膨胀都不给比值的任何单向序**（两个方向都能实现）。候选 2 **`[NG]`**：
"压缩 + 交错 ⇒ `ρ²` 上界"是**方向错误**；交错只复述 RB-1 的 Ritz 上界（分子），不给分母。
（3000 个稀疏随机粗空间：低于 2725 / 高于 92 —— 只说明"多数偏高"，不是序。）

### RB-3（`ρ²` 的 min-max 与 `ψ₁`-free 化）`[T]`

```
   e₂ = min{ R(φ) : φ ∈ D(L), ⟨φ,1⟩=0, ⟨φ,ψ₁⟩=0 } ,      ρ² = e₂/e₁ ,                       (2.5)
```
`⊥ψ₁` 是 (2.5) 的**实质约束**，但 Ky Fan 形式 (2.1) 把它消掉：`dim V = 2` 自动吃掉两个方向。
**可执行清单**：`V = span(o₁-⟨o₁⟩, o₂-⟨o₂⟩)`，`o_i` 为两个粗模（两个 smearing / 两个 block 尺度），
```
   G_ij = ⟨o_i o_j⟩_c ,   M_ij = ½⟨∇o_i·∇o_j⟩_c   ⇒   t = tr(G⁻¹M) ,   ρ² ≤ t/e₁ - 1 .
```
**诚实注**：`t/e₁` 里的 `e₁` **不能**用 Ritz 值 `ν₁` 代替（`ν₁ ≥ e₁` 会让右端**变小**，即非法加强）；
必须来自 RB-2(b) 的比较算子。

### RB-4（真正的"只依赖维数/度数"比值界：存在，但住在非相互作用类）`[T]+[V]`

> **(i) 超立方体。** `L = Σ_{i=1}^n (1-flip_i)` 于 `{0,1}^n`：谱 `2|S|` ⇒ `e₁=2, e₂=4` ⇒
> **`ρ² = 2`，对一切 `n ≥ 2`**（`n` 只改简并度，不改比值）。
> **(ii) 乘积链。** `L = Σ_s L_s`（可交换，最低两阶为单格激发）⇒ `ρ² = (γ₁+γ₂)/γ₁ ≤ 2`。
> **(iii) 判词。** 这是**真正**的"只依赖维数/度数、（`L,a`）、β 全无关"的比值界 —— **但只存在于
