## 0. 判死线（先读这段）

**(P0) 结构定型 `[T]`。** 三个不同的命题共用"1D BL"这个名字，它们的真值完全不同；不分开就会把死路当活路：

- **(A) 无条件 BL（Stein 型）**：`Var_μ(∂_vV) ≤ E_μ[∂_v²V]`。**真，且免费**：它就是 Stein 恒等式 `E_μ[∂_v²V]=E_μ[(∂_vV)²]` 减一个 `(E∂_vV)²≥0`。对 `f=⟨v,∇V⟩` 这类极值函数 BL **精确取等**（Gaussian 情形），故在这条泛函上 **BL 零 slack**——条件化后失效的差额恰好是 `G''`。**⇒ 无条件 BL 无信息量。**
- **(B) 边缘 1D BL（对 `ρ_v`）**：`G''(a)≥λ ∀a ⇒ Var_{ρ_v}(ξ)≤1/λ`。**真 `[T-standard]`，但前提比结论强、且在此模型里假**：单 plaquette `θ=π` 精确 `G''(0)=W₀−V₀β²`，`β>β*=4.30660785` 即 `G''<0`。**⇒ 作为路线 `[NG]`。**
- **(C) 条件/切片 BL（对 `μ_0=μ(·|ξ=0)`）**：只要 `Hess V|_{v^⊥}⪰λ_⊥>0`。**这是唯一的活口，但它严格不蕴含 (B)**——精确反例见 §4.3：`θ=π` 单 plaquette 上切片 `S≡β` 为常数、切片测度 `∝J` 是 log-凹（`λ_⊥>0`），而边缘仍 `G''<0`。

**(P1) 判词 `[NG]`（BL 不能直接用）+ 替代 `[T]/[O]`。** BL 的凸性前提是**本质的**：损失不在不等式本身（P0 已证零 slack），而在前提；而"放宽前提"的四条候选里只有 **W2 = `SAV-CANCEL` Lemma SC.1 的谱分解 BL** 是不循环且已有精确代数的形态：`D=D₊+D_Sav`，`D₊≤0`（BL on `K₊⪰0`），`D_Sav=E|⟨φ₋,c⟩|²/|λ₋|≥0`，故 `G''≥E[Σ]−D_Sav`。**所需 = `D_Sav ≤ E[Σ]−λ`**——这是本文件钉出的精确缺失步，**它不是凸性、是粗-细混合能的上界**（BL 对它无话可说）。

**(P2) 与 H1 的关系 `[T]` 三层，不是等价。** (i) 点值形态 `Var(∂_vV|0)≤E[∂_v²V|0]−λ` **逐字等于** `G''(0)≥λ`（`[T]` 恒等式改写，零内容 ⇒ 作路线 `[NG]`）；(ii) 一致形态 `ess inf G''≥λ ⇒ H1` 是**严格更强**的命题（`Q6 §2.3`），前提点态假；(iii) **不等价的证据**：2D `SU(N)` 的 volume-uniform LSI 已证（Piazza–Shen 2026，`[V-doc]`）⇒ 2D 的 H1 已证，而 2D 边缘的 `ess inf G''≥λ` 未被任何已知结果蕴含（LSI 不给点态曲率）⇒ **H1 真而 (B) 未证，两者不同一**。

## 1. 记号锁定（与 `GPP-STRUCT.md §1` 逐字对接）

`Λ⊂Z⁴` 有限环面，链变量 `U∈SU(N)^Λ`，Haar `dU`，纤维维数 `d_L=(N²−1)|Λ|`。

| 符号 | 定义 | 备注 |
|---|---|---|
| `X` | 指数图 `U=exp X`，`X∈𝔤^Λ⊂R^{d_L}` | 割迹测度零，以下 a.e. |
| `J(X)` | `dU=J(X)dX` | `J>0` |
| `Φ` | `Φ:=−log J` | `e^{−Φ}dX=dU` **精确**（Haar 就是 `β=0` 的测度） |
| `S_W` | `βΣ_p(1−(1/N)Re tr U_p)` | 无量纲（格点单位；`ch03 §sec:dim`） |
| `V` | `V:=S_W+Φ`；`μ=e^{−V}dX=e^{−S_W(U)}dU` | Wilson 测度 |
| `v` | 粗横向 `k→0` 模，`|v|=1`；`∂_v:=⟨v,∇⟩` | **`v` 就是被条件化的方向** |
| `ξ` | `ξ(X):=⟨v,X⟩` | 1D 边缘坐标 |
| `H` | `H:=Hess S_W`（**不是** Hamiltonian） | `Hess V=H+Φ''` |
| `G(a)` | `G(v;a):=−log ρ_v(a)`，`ρ_v(a)=∫e^{−V}δ(ξ−a)dX` | 自由能；**力**写作 `G_v=∂_vS_W` |
| `μ_0` | `μ(·|ξ=0)`，切片 `H_v:=v^⊥` | 切片密度 `∝e^{−V}|_{H_v}` |
| `P_⊥` | `H_v` 上正交投影 | `K:=P_⊥(Hess V)P_⊥`，`b:=P_⊥(Hess V)v`，`h:=⟨v,(Hess V)v⟩` |

**恒等式的三行复算（本文件自核，`[T]`，与 `eq:split` 逐项一致）**

```
ρ(a)=∫_{H_v} e^{−V(a,y)}dy
⟹ (d/da)log ρ = E[∂_vV|a] =: G'(a)
⟹ (d²/da²)log ρ = E[(∂_vV)²|a] − E[∂_v²V|a] + (G')²
⟹ G''(a) = E_μ[∂_v²V|a] − Var_μ(∂_vV|a) = E[H_vv+Φ''|a] − Var(G_v+Φ'|a) .
```

（`dX=da dy`，`y` 为 `H_v` 坐标；`d/da` 与 `∫δ(ξ−a)` 的换序是有限维 Fubini。）

## 2. 标准 BL：陈述与可核出处

### 2.1 定理（R^d 版本，即本项目要用的形式）

> **BL（方差/二阶形式）** `[T-standard]`。设 `V∈C²(R^d)`、`μ=e^{−V}dx` 为概率测度，且
> **(V1)** `Hess V(x) ⪰ λ I`（`λ>0`）对 `μ`-a.e. `x` 成立。
> 则对所有 `f∈C¹`、`E_μ|∇f|²<∞`：
> ```
> Var_μ(f) ≤ E_μ[ ⟨(Hess V)^{−1}∇f, ∇f⟩ ] ≤ λ^{−1} E_μ|∇f|² .          (BL)
> ```
> 二次 `V` 取等（Gaussian 是等号情形）。

**可核出处（分级）**
- **H. J. Brascamp, E. H. Lieb**, *On extensions of the Brunn–Minkowski and Prékopa–Leindler theorems, including inequalities for log concave functions, and with an application to the diffusion equation*, **J. Funct. Anal. 22 (1976) 366–389** — `[T-standard]`，**书目级已核**（多篇引用文献一致复述卷/页/题名；本文件未取正文）。
- 同作者，*On extensions of the Brascamp–Lieb and Prékopa inequalities*, **Bull. Amer. Math. Soc. 81 (1975) 601–605** — `[T-standard]`，**书目级（题名）**；**DOI 未核** ⇒ 标 `[E]`。
- 一般（多线性/多测度）形式：**Brascamp–Lieb, Adv. Math. 20 (1976) 151–173**（"Best constants in Young's inequality…"）——`[T-standard]`，与本条不是同一篇，见 §8 勘误。
- 极值函数族 `f=⟨c,∇V⟩`（`c` 常向量）见 Bordeaux 讲义 [Poincaré 讲义 PDF](https://www.math.u-bordeaux.fr/~mibonnef/Poincare__Toulouse.pdf) — `[C]`（外部讲义片段，**未逐字核定理号**）。**这一条是本文件 P0 的关键**：`f=∂_vV=⟨v,∇V⟩` **正在**该极值族里。
- 1D 等价形式：`V_eff''≥λ` a.e. `⇒ Var(a)≤1/λ`（即"`ess inf G''≥λ ⇒ H1`"）——内部已用：`Q6-H1-STATUS.md:145`（`[T]`）。

### 2.2 为什么 P0 的"零 slack"是真的（一行）

取 `f=⟨c,∇V⟩`，则 `∇f=(Hess V)c`，(BL) 右边 `=E_μ⟨(Hess V)^{−1}(Hess V)c,(Hess V)c⟩=E_μ⟨c,(Hess V)c⟩`。二次 `V` 时 `f` 线性、`μ` Gaussian，(BL) 两边同为 `⟨c,Σc⟩` ⇒ **等号**。取 `c=v`：`f=∂_vV`。∎

**推论（本文件最重要的一句）**：BL 在我们要用的那条泛函上**没有可改进的余量**。把 BL 换成"更强的 BL"是空集；唯一可能的进展是**放宽 (V1)**。

## 3. 三个"1D BL"与目标不等式的精确形式

### 3.1 (A) 无条件（Stein 型）：真、免费、无用

```
Var_μ(∂_vV) = E_μ[(∂_vV)²] − (E_μ∂_vV)² = E_μ[∂_v²V] − (E_μ∂_vV)²  ≤ E_μ[∂_v²V] .     (A)
```
`[T]`（Stein 恒等式 `E_μ[∂_v²V]=E_μ[(∂_vV)²]`；`app.tex:167–172` 记该式**只对无条件期望成立**）。**缺口恰是条件化**：条件化把 `E[(∂_vV)²]` 换成 `E[(∂_vV)²|0]`，而 Stein 不再闭合，差额 = `G''`。

### 3.2 (B) 边缘 1D BL：要证的那条（本任务对象）

**要证的不等式（精确形式，用 `v,Φ,S_W` 写）**

```
(BL-1D)(λ)   Var_μ( ∂_vV | ξ=0 )  ≤  E_μ[ ∂_v²V | ξ=0 ]  −  λ ,
             即   Var_μ(G_v+Φ'|0)  ≤  E_μ[H_vv+Φ''|0] − λ ,
             即   G''(0) ≥ λ .                                            (BL-1D)
```
- **等价性 `[T]`**：三行全部由 `eq:split` 的一行移项得到（§1 复算）。
- **前提形态（"λ-一致"版，唯一有内容的写法）**：
```
(BL-1D)ᵤ   ∃λ>0:  G''(a) ≥ λ  对所有 supp ρ_v 内的 a      ⟹   Var_{ρ_v}(ξ) ≤ E_{ρ_v}[1/G''(ξ)] ≤ 1/λ .
```
`[T-standard]`（1D BL，`f(a)=a`；`Q6-H1-STATUS.md:145`）。
- **两者的关系 `[T]`**：`(BL-1D)ᵤ` **严格强于** `(BL-1D)(λ₀)`（后者是单点值）。物理点是 `(BL-1D)(a²Δ₀²)`（`app.tex:179–202`），故 `(BL-1D)ᵤ` **比 H1 更强**，不是 H1 的换名，也**不是**它的充分必要条件。

### 3.3 (C) 条件/切片 BL：活口，但只覆盖切向

对 `μ_0`（密度 `e^{−V}|_{H_v}`，Lebesgue 参考测度在 `H_v` 上）：

```
(CBL)  若 λ_⊥ := essinf_{X∈supp μ_0} inf_{w∈v^⊥,|w|=1} ⟨w,(Hess V(X))w⟩ > 0
       则  Var_{μ_0}(f) ≤ E_{μ_0}[⟨K^{−1}∇_⊥f,∇_⊥f⟩] ≤ λ_⊥^{−1} E_{μ_0}|∇_⊥f|² ,  K=P_⊥(Hess V)P_⊥ .
```
`[T-standard]`（把 §2.1 的 BL 用在 `H_v` 上；`Prékopa`：log-凹密度在超平面上的条件化仍 log-凹，`S3-UV-FESHBACH.md:106–107`）。

**把它对准 `f=∂_vV`（本任务要做的对齐）**

```
∇_⊥(∂_vV) = P_⊥(Hess V)v = b ,   K = P_⊥(Hess V)P_⊥
(CBL)+f=∂_vV :  Var_{μ_0}(∂_vV) ≤ E_{μ_0}⟨K^{−1}b,b⟩                             (C-f)
⟹  G''(0) ≥ E_{μ_0}[h] − E_{μ_0}⟨K^{−1}b,b⟩ ,   h=⟨v,(Hess V)v⟩ .
```
**两处结构性错配（本文件的判定核心，`[T]`）**：
1. **(C-f) 对 `f=∂_vV` 不是极值形态**：极值族要求 `f=⟨c,∇_⊥V⟩`（`c∈v^⊥`），而 `∂_vV` 含 `v` 分量，一般不在该族里 ⇒ **条件版 BL 有 slack，且 slack 的符号未知**。
2. **Gaussian/二次近似下可算清**：`V=½⟨x,ℋx⟩` 时 `Var_{μ_0}(∂_vV)=⟨b,K^{−1}b⟩`（(C-f) 取等），且 `G''=h−b^{T}K^{−1}b` = `ℋ` 关于粗模的 **Schur 补** `=(ℋ^{−1})_{vv}^{−1}`。**故 `K≻0` 只给 `b^{T}K^{−1}b≥0`（曲率被"积分掉"的软模下压），要 `G''≥λ` 必须另有 `b^{T}K^{−1}b ≤ h−λ`——这是粗-细混合能上界，不是凸性。**

### 4.2 为什么 (V1) 的失效是**本质**的，而不只是"技术上不满足"

若 (V1) 只在一个 1 维方向坏，`λ` 仍可能由其余方向支撑；但 BL 的常数是 `λ` = 全 Hessian 的 inf，**一个负方向就让 `λ<0`，`(BL)` 的右边无意义**（`(Hess V)^{−1}` 不定，二次型可从下方无界）。这不是"常数变差"，是**不等式退化为无定义**。`[T]`（线性代数：`(V1)` 是 `(Hess V)^{−1}` 存在且正定的**充要**前提）。

### 4.3 关键精确反例：**切片凸 ⇏ 边缘 log-凹**（钉死 §3.3 的桥）

单 plaquette `SU(2)`，`θ=π`，`v=e₃`，条件化点 `ξ=0`：

- 切片 `{ξ₃=0}` 上 `u=ξ₃/ρ=0`，`S_W=β(1+sin h·u)≡β` **常数**（`H1E §1.1`）⇒ 切片测度 `∝e^{−β}J d²ξ∝J d²ξ`，而 `J=(sin h/h)²`、`Φ=−log J` 凸 ⇒ **切片 log-凹，`λ_⊥≥inf Φ''>0`**（点态 floor：SU(2) 引 `¼`，`A5-RIGOROUS-NUMERICS.md:31` 的 `E[Φ''|0]≥¼` 是**期望**版，本文件未逐字核点态版 ⇒ 该格标 `[C]`）。
- 而同一切片的**边缘** `G''(0)=W₀−V₀β²`，`β>4.30661` 时为负。
- **⇒ `(CBL)` 的前提成立、`(BL-1D)` 的结论为假。`[T]`**
- **机制**：`G''` 的负号来自 `Var(∂_vV|0)=β²V₀`——**被积分掉的法向**的力的方差，切片 Hessian 完全看不见它（切片上 `∂_vV` 不是任何切向导数的势函数）。**"BL 是切向算子，`G''` 的缺口是法向方差"——这是类型不匹配，不是常数不优。**

## 5. 若把 `Hess` 换成 `Φ''`（已证 `⪰0`）：会得到什么

**分三种用法，结论完全不同，必须分开写。**

**(5.1) 正确用法（`β=0` 面）** `[T]`：`V=Φ` 时 `Hess Φ=Φ''⪰0`，且 `e^{−Φ}dX=dU` 正是 Haar ⇒ BL 成立，给出
```
Var_Haar(f) ≤ E_Haar[⟨Φ''^{−1}∇f,∇f⟩] ⇒ (f=∂_vΦ) ⇒ G''_{β=0}(0) ≥ N/12 > 0 .
```
这与语料已证的 `[T]`（`ch05:209–212`；`Prékopa+Lemma B`）**同一条**，**无新内容**。

**(5.2) 错误用法（"用 `Φ''` 当 `Hess V` 的替身"）：被精确证伪 `[T]`。** 若允许在 `Var_μ(·|0)`（`μ=e^{−S_W}dU`）下把 `Hess V` 换成 `Φ''`，等价于断言 `(V5)` 可绕开，即断言 `G''≥0` 恒成立。**反例精确**：`θ=π`、`β=6` 给 `G''=−0.193019<0`；`β*` 的闭式给出失效点 `4.30660785`。⇒ **替换不是"损失常数"，是改变命题真假。** 另：`Φ''` 只能以加项进恒等式（`E[H_vv+Φ''|0]`），它在 `β=2.5` 处给 `+0.205` 量级的 floor，而 `Var(G_v|0)=β²V₀` 在 `β=6` 时已 `0.398>0.205`——**Haar floor 按 `β²` 被吃掉**（`W_geo∝β⁰` vs `Var∝β²`，正是 `H1E` 的闭式结构）。

**(5.3) 唯一有意义的"部分 `Φ''`"用法（W2，活口）** `[T]`：谱分解 `K=K₊−|λ₋|P₋`（`rank-one`，（`SAV-CANCEL.md:82–94` Lemma SC.1）：
```
K^{−1}=K₊⁺ − P₋/|λ₋| ,   D = D₊ + D_Sav ,
D₊ := Var(f) − E⟨K₊⁺c,c⟩ ≤ 0   （BL，仅需 K₊⪰0）,   D_Sav := E|⟨φ₋,c⟩|²/|λ₋| ≥ 0 ,
λ₋ = −g|B| .
```
这是**把 BL 限制在正谱块上**的"条件/方向 BL"，是 BL 在不定 Hessian 下**唯一严格存活**的形态。它把目标化成
```
G'' ≥ E[Σ] − D_Sav   ⇒   所需:  D_Sav ≤ E[Σ] − λ ,  E[Σ]=E[⟨K₊⁺c,c⟩] .
```
**这不是凸性，是"负模耦合能 ≤ 正模刚度 − λ"的竞争不等式**；`D_Sav` 是**一阶变分的平方**（`H1E §3.3` 的机制标签），量纲 `O(1/|λ₋|)=O(1/(g|B|))`。缺的工具：`D_Sav` 的**上界**（现只有 `S1` 的下界见证 `D_Sav` 随 `f_∂` 增大）。

## 6. 判死线复核

### (a) BL 的凸性前提是本质的 ⇒ **明说：BL 不能直接用**，需要的替代是

1. **不是 log-凹**：`(BL-1D)ᵤ` 恰是"`ρ_v` log-凹"的定量版；`β>β*` 时它**假**，所以 log-凹不是替代，是同一个东西。
2. **半凸（semiconvex）不够**：半凸只给**局部** BL（限制在凸子域上，`CLL` 的非同态注记也只到"局部不等式"，`[V-doc]`），而局部 BL 的方差是在**局部化测度**上算的，与 `μ_0` 差一个**坏集质量项**——那正是缺失项，不是免费项。
3. **Holley–Stroock 有界扰动 `[T]` + `[O]`（对 H1 无用）**：`S_W` 在紧群上**确有界**（`0≤S_W≤2βN_□`），故 HS 可用：`Var_μ(f) ≤ e^{2·osc(S_W)}·λ_Φ^{−1}E_μ|∇f|²`，`osc(S_W)≤2βN_□`，`N_□=6L⁴`。在 `β=2.5, L=4`：指数 `4βN_□=15360` ⇒ 常数 `≈10^{6671}`。**HS 把"非凸"换成"体积指数"，对 `L`-一致目标是死路**（`[O]`；这正是 `ABC-NEW-INEQ:30` 记的"`S_W` 广延 ⇒ 无体积一致 log-凹常数"）。
4. **真正需要的替代（W2）**：`K₊⪰0` 上的 BL + `D_Sav` 的上界（§5.3）。或 **W3**：`CLL` 的非同态局部 BL（`[V-doc]`，明确在其定理 B–E **之外**：`Φ_B` 是四次多项式映射、非群同态，`arXiv:2602.10647` Def 1.1/Thm C 的 codim 条件不适用，`BIANCHI-COAREA.md:59–76`）。

### (b) 存在"条件版 BL"（只要求某方向凸）⇒ **这是活口，但它是"正谱块 BL"，不是"切向 BL"**

- **真活口 = `(W2)` 谱分解 BL**（`[T]` 恒等式 + `D₊≤0`）。它只要求 `K₊⪰0`（正谱块），不要求整体凸。**它把缺口精确定位到一个标量不等式 `D_Sav ≤ E[Σ]−λ`。**
- **半活口 = `(CBL)` 切向 BL**（`[T-standard]`）。**但它传不到边缘**：§4.3 的精确反例（切片 log-凹 + 边缘 `G''<0`）证明 `(CBL) ⇏ (BL-1D)`。**⇒ 若有人提出"只在 `v^⊥` 上凸就够了"，用 §4.3 一句话否掉。**
- **不是活口**：`(A)`（无条件，免费）、`W4`（HS，体积指数）、`W3`（非同态局部，无一致常数）。
