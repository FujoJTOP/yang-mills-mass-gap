## §1 三行写死（各给取值 + 为何只取这一个）

### 1.1 (a) `‖H_a‖_D` 的指数 = `a^{-4}`（规范归一）
- **定值**：`δ_k tr F² := a_k^{-4}q`、`q:=1−N^{-1}Re tr U_□`（`|q|≤2`）；`H_k` = 以块场 `φ_k:=⨏_{B_k}δ_k tr F²` 为变量的作用量二阶导，`‖·‖_D` = 图范数 `‖ψ‖+‖Fψ‖`；`η_k:=a_k^{4}‖H_k‖_D`（定义，无量纲）。同一规范归一给 `‖H_k‖_D=a_k^{-4}η_k`（`η_k`、`ϖ_k` 均无量纲）⇒ **比值指数 0（临界）**，恰是 `(U2)` 的单一 `a^{-4}` 接触层（`A2:6`「the additive `a⁻⁴` … a *finite* local constant」）。
- **为何不是 `log`**：`β_j≍log(1/a_j)`（`HZ2:32` 逐字 `Z_j≍β_j`、`β_j=4Nβ₀j`；`HW2-A6:51` 逐字 `Z_j^{-1}H_j=O(Q)`）是**平直坐标面**，`ι_a` 与耦合已被约掉；代进 `eq:l3` 而 `Z_a` 仍取规范面 ⇒ 指数 `+4`（退化到 0）⇒ `eq:l3` 对**任何**测度恒真（`HU5:0.2` 的「取 `Z_a→∞` 使 F2 平凡真」是同一洞，判别力 0）。两面不可混：混就是 `±4`（HX2/HX3 的 8 幂与「幅度 vs 方差」之争）的来源。
- **下一手**：`eq:l3` 补「双侧」——`sup_a Z_O(k)²‖H_k‖_D<∞` **且** `inf_k Z_O(k)²‖H_k‖_D≥c>0`；只写 `sup` 的版本按 `HU5:0.2` 记「可能空洞」。

### 1.2 (b) `ch03:67` 的 `Z_a` = 块方差（不是无量纲常数）
- **定值**：`eq:l3`（`ch03:63`）里的 `Z_a` 读作 §2·D1 的块平均方差（幂 `a^{-4}`）；`ch03:67` 按语 "the field-strength renormalization constant" 是**标签误**，改为「block-variance normalisation」（勘误记本文件，`ch03` 零改动）。
- **为何不是无量纲常数**：`(i)` 无量纲（`a⁰`）进 `eq:l3` ⇒ 命题退化成 `sup_a‖H_a‖_D<∞`，而规范面给 `≍a^{-4}` ⇒ **假**；`(ii)` 合法的无量纲对象是迹反常比 `Z_O^{anom}=(β/2g)(μ₀)/(β/2g)(μ)`（`R1:78`），它 `a⁰·log`、扛不动 `a^{-4}`，且符号 `Z_O` 已被它占用；`(iii)` 它会把自由场酸测读成口号：`C2:342–344`「`Z_a=1`、`‖H_free‖` `a`-一致」是**平直面**陈述，换到规范面即 `ϖ_free(k)≡const`（D3-3），不是「`Z_a=1`」。
- **下一手**：`ch03` 只改按语一词（交 `lead`）；`C2:342` 的「`Z_a=1`」改写为「`ϖ_free(k)≡const`」。

### 1.3 (c) 绝对值 = 单位约定 ⇒ 只写锚定比
- **定值**：一切陈述只用 `Z_O(k)`（`Z_O(k_*)=1`）与 `ϖ(k_*)/ϖ(k)`。`Z_a` 的绝对值在 `Λ↦λΛ`（`a↦a/λ`、`b̂↦b̂/λ`）下按 `λ^8` 变（`GP9-RB:114` 逐字「值由单位选择定（弦张力/`Λ`），不是由 YM 定」）。
- **为何不是绝对值**：真值随单位标号变的句子不是命题，标不上 `[T]`；锚定比是唯一在单位重标下不变、且在自由场上可精确校准的形式（`HU5:0.3` 的「锚 `j*` + 窗 + 口径」三件）。
- **下一手**：凡 `Z`-式一律带锚 `k_*=0` 与窗 `k≤K̂`，禁裸 `Z_a` 进命题。

## §2 `Z_O(k)` 的最终定义

**D1（定义式，一行，量词齐）**
```
∀Λ ∀L ∀a ∀b̂ ∀k∈{0,…,K̂}:  Z_O(k) := [ Z_a(k_*) / Z_a(k) ]^{1/2},
  Z_a(k) := Var_{μ_k}( ⨏_{B_k} δ_k tr F² ),  ⨏_{B_k} := N_B(k)^{-1} Σ_{x∈B_k},
  N_B(k) := (b̂/a_k)^4,  b̂/a_k ∈ ℕ,  a_k := b^k a ≤ b̂,  K̂ := max{k : a_k ≤ b̂},  k_* := 0,
  δ_k tr F² := a_k^{-4}(1 − N^{-1} Re tr U_□)（k-层 plaquette）,  μ_k := T⁴_L（周期、体积 L⁴）上 Wilson 作用的 Gibbs 测度，
  其裸耦合由方案 C 定：1/g²(a_k) = 2b₀log(1/(a_kΛ)) + (b₁/b₀)loglog(1/(a_kΛ)) + C + o(1).
⇒ Z_O(k_*) ≡ 1;  Z_O(k)² = Z_a(k_*)/Z_a(k) = (a_k/a_{k_*})^{+4}·[ϖ(k_*)/ϖ(k)],  ϖ(k) := a_k^{4} b̂^{4} Z_a(k).
```
**D2（面：一符号一面）**

| 面 | 乘子 | `a`-幂 | 消费它的式子 |
|---|---|---|---|
| 幅度（场） | `Z_O(k)` | `+2` | `O^{ren}_k=Z_O(k)φ_k` 单位方差（`A2:14`）；`sup_k E⟨ι_kO^{ren},f⟩²≤C‖f‖²_{H^s}`（`HZ1:27–28`） |
| 二次（`H`/`Var`/`f₁²`） | `Z_O(k)²` | `+4` | `Ĥ_a=Z_a^{-1}ι_aH_aι_a^{-1}`（`A2:14`）；`f₁²_{k+1}=Z_O(k)²e^{−H_k}f₁²_k`（`TRANSPORT-MACHINE:6`） |

**D3（三条 `[T]` 推论）**
1. **存在与正性**：`|q|≤2` ⇒ `|φ_k|≤2a_k^{-4}` ⇒ `Var<∞`；`β_k<∞` 的 Gibbs 密度处处正 ⇒ `φ_k` 非常数 ⇒ `Var>0`。故 `Z_a(k)∈(0,∞)`、`Z_O(k)∈(0,∞)`、`Z_O(k_*)=1`。`[T]`
2. **幂是记账**：`ϖ` 由 `ϖ:=a_k^4 b̂^4 Z_a` **定义** ⇒ `ϖ` 无量纲、`a^{-4}` 全在显式因子 `a_k^{-4}` 里，`Z_O(k)²‖H_k‖_D=a_{k_*}^{-4}(ϖ(k_*)/ϖ(k))η_k` 对 `a_k` **恒为 0 次**。`[T]`
3. **自由场校准**：自由块 `C_q(z)` 只由 Gaussian 传播子定，块内和 `Σ_{z∈B}C_q=Θ(1)` 且与 `k` 无关（差 `O((a_k/b̂)^4)`）⇒ `Z_O^{free}(k)=(a_k/a_{k_*})²(1+O((a_k/b̂)^4))`，即 `C2:343` 的「`Z=1`」读作 `ϖ_free≡const`。`[T]`（结构）；其常数未算 `[NG]`

**D4（残余，具名一格）`[NG]`**：`ϖ(k)=Θ(1)` **双侧且 `(a,k)`-一致**，且 `lim_k ϖ(k_*)/ϖ(k)` 收敛到方案 C 的有限常数。等价：`Z_O(k)(a_{k_*}/a_k)^{-2}` 沿塔收敛。这是 `(U2)` 的承重格（`HZ1:65,72`；`HV1:56`），是**值**不是估计。**下一手**：先在自由块与单片上把 `ϖ` 的常数算出来（仓内有 `V1:115–122` 的自由块值可对），再问相互作用侧的双侧界。

**注 2（`N_B` 勘误，`[T]`）**：`HX3:42–44` 同时用 `N_B=(b/a)^4`（`b` 固定物理）与 `b=2a⇒N_B=16`（`b` 随 `a`，UV 块），两者互斥。取前者：块 = 固定物理 UV 块，`N_B=(b̂/a)^4` 随 `a` 变 ⇒ 块和/块平均之比 `(b̂/a)^8` 也随 `a` 变，`256` 只是 `b̂=2a` 的瞬间值；取后者则 `Z_a≍a^{-8}`、`Z_a^{-1}` 带 `a^{+8}`（两层），被 `(U2)` 的单层（`A2:6`）排除——与 `HX3` 的裁决同向，但理由该换成「一层 vs 两层」，不是「256」。
