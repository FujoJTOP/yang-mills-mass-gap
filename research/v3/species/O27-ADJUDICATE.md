```
C ≡ B ≡ G''(0) = A + W_full ,      W_full = E[Φ''] + Var(G) − Var(G+Φ') = E[Φ''] − Var(Φ') − 2Cov(G,Φ') = W_geo + X
```

## 4. 判

### (a) `A` 与 `C` 是同一个量吗？——**不是**

- 定义：`C = E[H+Φ''] − Var(G+Φ')` 含 Jacobian 的两项（`Φ''` 的均值、`Φ'` 的方差与交叉），`A` 完全不含。
- 数值：同一 ensemble 上 `C − A = +1.134`，是 `A` 的两倍大；`A` 自己只有 `+0.56±0.28`。
- **所以不存在"谁算错"**；若强行按"同一个量"读，则是**比较者（把 o13 的 `Δ_dyn` 与 o11/o26 的 `Δ` 并列）**错，错在把 `Δ_dyn` 当成 `G''(0)`。
- 论文本身把这件事写得明确：`ch15 eq:v3object` 之下"`X` is not optional"，`ch05 eq:split` 把 `Δ_dyn` 与 `W_geo`、`X` 显式分成三项。

### (b) `A ≠ C`，差的是哪一项？——**整块 `W_full = W_geo + X`，量上被 `E[Φ'']` 主导**

`C − A = E[Φ''] − Var(Φ') − 2Cov(G,Φ')`。本点：

- `E[Φ''] = +1.2325`（把 `A` 推高 `+1.23`）⇒ **不是"小修正"，是主项**；
- `−Var(Φ')−2Cov = −0.0984`（把 `A` 压低 `−0.10`，其中 `Cov` 项 `+0.043`，与 o13 的 `X=−0.125` 同号相反量级内）；
- 精确锚点（单 plaquette）给同一结构但符号相反地**放大交叉项**：`E[Φ'']=+0.184`，`−Var(Φ')−2Cov=−0.227`，故 `W_full=−0.043<0`。

**当前定义下两方各等于什么**：

- `o13` 的量 `Δ_dyn = A = E[H_vv] − Var(G_v)` = `+0.562 ± 0.277`（o13 模）/ `+1.065 ± 0.333`（o13 原跑）；**不含任何 `Φ`**。
- `o11/o26` 的量 `Δ = C = E[H_vv+Φ''] − Var(G_v+Φ')` = `G''(0)` = `+1.696 ± 0.293`（o13 模）/ `+0.946 ± 0.210`（o11 模）；**`= Δ_dyn + W_geo + X`**。
- 二者关系：`C = A + 1.13`（本点），恒等式，不是偶然。

### (c) 四组合里 `D = B = C`：代数一致性**确认**

`A + W_full = (E[H]−Var G) + (E[Φ'']+Var G−Var(G+Φ')) = E[H+Φ''] − Var(G+Φ') = B`，逐样本成立 ⇒ 残差 `0.00e+00`（不是 `1e−16`，因为两项在同一浮点表达式里算出）。`C` 与 `B` 也是同一算式，故 `|C−B| = 0`。**这三者是同一个量的三种写法。**

**`Δ_dyn` 的符号（H1 承重）**：

- o13 模 `+0.562 ± 0.277`（`1.9σ`）；o11 模 `−0.179 ± 0.225`（`0.8σ`）；o13 原跑 `+1.065 ± 0.333`（`3.2σ`，但其 `Var(G)=5.27` 与本工作 `5.73±0.27` 差 `1.7σ`，`A` 的差 `0.50` 主要来自 `Var(G)`）。
- ⇒ **`Δ_dyn` 符号在本统计量下未定**；它处在 `E[H] ≈ Var(G)` 的近抵消结构里（`6.29` vs `5.73`，差 `9%`），是**两个大数之差**，`N_eff≈94` 不够判符号。
- 承重的 `G''(0) = C` 两个模都给正（`5.8σ` / `4.5σ`），精确 plaquette 也给正（`+0.1848`）。**H1 应当挂在 `G''(0)` 上，而不是 `Δ_dyn`。**

## 5. 第三处混淆：`o11` 与 `o13` 的**图归一化差 4 倍**（`[T]`）

两份代码的平直图不同：

- `o11_physical.py` `expi()`：`U = cos(r/2) + i (sin(r/2)/r) x·σ = exp(i x·σ/2)`，`Φ = −2log(sin(r/2)/(r/2))`，`r∈(0,2π)`；
- `o13_ldep.py` `x_to_q()`：`U = cos r + i (sin r/r) x·σ = exp(i x·σ)`，`Φ = −2log(sin r/r)`，`r∈(0,π)`。

`x_o13 = x_o11/2` ⇒ 两图中"单位范数 `v`"对应**物理位移差 2 倍** ⇒ 一切 `v` 方向曲率/力方差 **×4**。

核验：o11 的 `L=2` `E[κ]=1.796`、`Var(F)=2.101`（o11 图）⇒ o13 图为 `7.18 / 8.40`；本工作同模（o13 图）为 `7.605 / 6.660`。`E[κ]` 吻合到 `6%` ✔，`Var(F)` 偏高 `26%`（o11 `N_eff≤104`、`τ_K≈35–90`，二阶矩最不可靠）。

因此 o11/o26 的 `Δ = 1.796 − 2.101 = −0.305`（o11 图）换到 o13 图为 `−1.22`，与同模预测 `+0.946±0.210` 差 `2.2`，**主导项是 `Var(F)` 过大**，而不是 `Δ_dyn`/`Δ` 的定义。**结论：`−0.2209` 既不是 `A` 也不是 `C` 的正确值；它同时受"定义口径 + 图归一化 + `Var(F)` 采样"三重污染。** 它数值上恰好落在 `A`（o11 模 `−0.18±0.23`）附近，是巧合，不能当作 `E[κ]−Var(F)` 的判据。
