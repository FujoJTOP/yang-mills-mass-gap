## §2 `C` 是自由还是钉死

`[T]` **自由**，且是**构造自由度**（不是物理参数）：

1. **作为自由参数出现在哪条陈述**：`Theorem C.6`（10082–10083）与 `Theorem 6.2`（22322–22325）都把它写成 `∃`：**对任一族**满足该支撑条件的单位分解都成立，且结论常数 `c₁,c₂,c₃` **随选择变**（10188；22344 逐字 `depending only on K1 , K2 , c, C`）。⇒ 定理对 `C` **全称量化**，故 `C` 无钉死值。
2. **有无规范值**：**无**。`0 命中`。只有"惯用锚"：`j=0` 单元对应局部化长度 `σ^{-1}`（22327–22331）⇒ `c ≤ 1 ≤ C`；再加"相邻单元覆盖 `t` 轴"⇒ `C ≥ cL²`。合起来 `C = cL² ∈ [1, L²]`（`L=2` ⇒ `C ∈ [1,4]`，`B ∈ [2,4]`）。这是**可选约定**，不是推论。
3. **单调方向（关键）**：10132–10133 把 `t` 的**上端** `C` 代入，故 `C ↓ ⇒ c₂ ↓ ⇒ exp(−d/(c₂L^jσ^{-1})) ↓ ⇒ 界变强`。**`C` 只能把界加强，不能把界削弱** ⇒ 任何"`B` 太大"的障碍都不成立。
4. **`L` 也是自由的**：`L > 1`（10082、22319、22332）任取，且明言与实空间分块 `b` 无关（22319–22322）⇒ 即便锚定，`B = 2√C ≤ 2L` 仍随 `L` 无界。

**下一手**：若要 `B` 有值，必须先在项目内**声明**一套约定（建议 `L = 2`、`C = cL² = 4`、`c = 1`），并把门写成"在该约定下"；否则 `C` 每次引用都可移位。

## §3 `B` 的可达范围与裁决

- **字面（不锚）**：`C ∈ (0,∞)` ⇒ `B = 2√C ∈ (0,∞)`。门 `Bc* ≤ 0.43`：取 `C` 使 `B = 0.43/(2c*)` 即可，`c*` 亦不必小 ⇒ **门恒真、恒空**。
- **锚定（`C ∈ [1,L²]`）**：`B ∈ [2, 2L]`（`L=2` ⇒ `B ∈ [2,4]`）。此时门才**咬得住**：`c* ≤ 0.43/B`，即 `B=2 ⇒ c* ≤ 0.215`；`B=4 ⇒ c* ≤ 0.1075`（`0.43/2`、`0.43/4` 均为精确十进制）。
- **裁决 `[T]`**：`B` **不是常数**，其"值"= 你选的单位分解。⇒ 门可满足（`[T]`），但满足**不携带信息**；若项目的质量间隙链以该门为承重，则该链在此处为**空链环**，必须换 `C`-无关的内禀量。
- **下一手**：① 用 `L=2, C=4` 做**一次性冻结**并把门重述为 `c* ≤ 0.1075`（可证伪的具体数）；② 同时核 `c₁ = a₁ν̃σ([0,∞))` 是否也是自选常数（10144/10157 指向"是"）——若两者皆自选，则整条 FRD 常数链都需重锚。
