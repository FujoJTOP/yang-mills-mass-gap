## 1 · `D_∞` 的逐字定义（钉死）

**恒等式（`X01-L1C.md:40–43`，逐字；`[T]` 精确，非近似）**

```
log Z_dec(B_T) = Σ_{α≥0}(T−α+1)_+ A(α)
               = φ_dec·T + log D_∞ + ε_T
φ_dec := Σ_{α≥0} A(α) ,      log D_∞ := Σ_{α≥0}(1−α)A(α) ,
ε_T := Σ_{α>T}(α−1−T)A(α) .                                  (L1-c.1)
```

⇒ **定义**：`D_∞ := exp Σ_{α≥0}(1−α)A(α)`。`A(α)` = 按**附着跨度 `α`** 分组的簇权重和（`α` = 簇的附着区间长度，不是 plaquette 支撑）。

**等价读法（`LOOP-RUNBOOK:5501`、`5800–5802`，逐字）**

```
D_fin(T) := Z_dec(B_T)·e^{−φ_dec T}      ⇒   D_∞ = lim_{T→∞} D_fin(T)
三类簇：内部 → φ_dec·T（密度项）；单端 → log D_∞（两端同值，不残留）；越端 → ε_T
```

⇒ `D_∞` = **管子两端的单端簇残数**（`T→∞` 的幅度前置因子），物理身份：`f₁² = a₀ D_∞`（`A02:124`、`X01:118`、`P4:54`）。**它是"一个值"**，不是率、不是隙 —— `CYL-RES:151` 逐字 "the coefficient is a value, the gap is a separate object"；`:168` "the residue theorem (I1) stands without I2"。

**存在性**：`(L1-c.1)` 右端是**绝对收敛级数**，故 `D_∞` 存在（`X01:47` 逐字"同时证明 `D_∞` 存在"）；绝对收敛所用之界 `|A(α)| ≤ ū^{α+1}/(1−ū)`（`X01:73`）就是 `ū<1`。

## 3 · `D_∞ ≥ ½` **只要正**吗？—— 拆成两个互不相同的话

`p6`（`LOOP-RUNBOOK:15046`、`P6-SPEC:36,65`）把**两件事**并成一句。必须分开：

### 3.1 真·"只要正"的部分：**符号**（`Z>0`），不是数字

`log D → η` 这一步（`LOOP-RUNBOOK:5707–5708`、`X02:11`、`A02:61`）：

```
η = (D_fin/D_∞ − 1) + (R_hi/f₁²)e^{m₁^{dr}t}
exp/log ⇒ |η| ≤ 2B e^{−δt}      只 需 D_∞ ≥ ½   [T]
```

逐步还原它到底吃了什么：

1. `D_fin/D_∞ − 1 = e^{ε_T} − 1`，`|e^ε−1| ≤ 2|ε|`（`ε` 小）—— 纯代数，吃的是 `|ε_T|≤Bū^T`，即 **`ū<1`**；
2. 除法 `D_fin/D_∞` 要 `D_∞ ≠ 0`；Theorem A 的 `SharpDecay` 逐字要 **`0 < Z`**（`X02:32`、`:463–465`：`0 < Z ∧ m₁ < m₂ ∧ 0 ≤ C ∧ …`）；
3. 而 `D_∞ = exp(实数)` ⇒ **`D_∞ > 0` 是结构性的、白拿的**（`exp` 恒正），与 `ū` 大小无关。

⇒ **"只要正"的真实内容 = "只要 `Z>0`"，而 `Z>0` 由 `exp` 白送 ⇒ 该步确实不消费 `ū<1`。** 这是 `p6`"半"判的**唯一**合法依据。`[T]`

### 3.2 假·被并进去的部分：**数字 ½**

`D_∞ ≥ ½` 这个**数值地板**不是白拿的，它只能由"界 + 指数化"给出，而那条界住在几何级数里：

```
e^{−Θ(ū)} ≤ D_∞ ≤ e^{Θ(ū)}         （只要 ū<1）         P4:101
⇒ D_∞ ≥ 1/2  ⟺  Θ(ū) ≤ ln 2  ⟺  ū ≤ 0.349675           P4:86  [T]
（用 X01:47 的粗式 ū/(1−ū)² ⇒ 门槛更窄：ū ≤ 0.32037）    P4:85
```

⇒ **`D_∞ ≥ ½` 的门槛 `ū ≤ 0.3497` 比 `δ>0` 的门槛 `ū<1` 更紧**（`P4:17` Q3 逐字："环 1 那一处更紧（`r₀≥a₀/2` 要 `ū≤0.3497`，`δ>0` 只要 `ū<1`）"）。`[T]`

**而语料里"½ 的门槛"有三个互不相同的数**：

| 出处 | 门槛 | 来源 |
|---|---|---|
| `P5-R0:66,73` | `ū ≤ ½`（`⟺ β ≤ 0.073576`） | 线性下界 `1−Cu ≥ ½`（最粗口径） |
| `P4:85` | `ū ≤ 0.32037` | `X01:47` 粗几何界 `ū/(1−ū)²` |
| `P4:86` | `ū ≤ 0.349675` | 本轮重算的紧界 `Θ(ū)` |

三数不一致 ⇒ **`½` 是窗口函数、不是常数**；这正是它**不**"只要正"的证据：凡给得出 `½` 的路线都自带 `ū<1` 且更紧。

**数值对照（`[M]`，`P4:110`）**：`β_W=1/12`、`u=0.0104`、`ū=0.5654` ⇒ `Θ=3.50287` ⇒ `D_∞ ≥ 0.030111`（仍 **正**，但地板掉到 `1/33`）。⇒ 正性确实在 `ū>0.35` 仍在，**但给不出任何固定常数**；`D_∞≥½` 在此点**未证**（真值可能仍 ≈1，但没有证书）。

## 4 · `D_∞ ≥ 0.6905` 怎么算的（`p4` 的"log 两侧界指数化"）

**四步，全部 `[T]`（`P4:19,81–105`）**

```
① 两侧 log 界   |log D_∞| ≤ Θ(ū) ,  Θ(ū)=ū(1+ū²/(1−ū)²)/(1−ū)      （由 |A(α)|≤ū^{α+1}/(1−ū) 重算，比 X01:47 更紧）

⇒ **`0.6905` 与 `½` 是同一族、同一算法、只差取点 `ū=0.25` vs `ū=0.3497`**。它**不是**新机制，是**同一不等式的更紧常数**；并且**没有**绕过 `ū<1`（`P4:19` 原文："在 `Ĉū<1` 内 `≥ e^{−0.3704}`"）。

## 5 · 判死线

### (a) —— **不触发**

`D_∞ ≥ ½` **不**只要正性：正性只给 `Z>0`（§3.1），给不给 `½`；`½` 的证书一律经过 `ū ≤ 0.3497`（§3.2）。
更硬的一句，语料自己说过（`P4:18`，Q4；`P4:129` 逐字）：

> "能替换掉 u 小的唯一东西是**直接证 `D_∞≥c>0`**——而那**就是** `I1`（残数地板）本身。所以'绕开 u 小'与'直接证 `I1`'是同一句话，不是两条路。" `[NG]`（无已知工具）

⇒ 所以 **`D_∞ ≥ ½` 不是"`ū>1` 仍收敛的重求和"的核心**；它反而是**该重求和的一个特例内的常数**。把它当软化，等于把"已经在 KP 盘内的更紧窗口"当成"盘外的机制"。

### (b) —— **不触发（但有一处口径债）**

`D_∞` **不是** `p4` 的新记号：定义在 `X01:42`（独立、精确、`[T]`），`p4` 用的是同一个对象（`D_∞=1+O(ū)` 与 `P4:60` 同式）。唯一债：`a₀` 与 `r₀` 的常数口径（`½(2N)^{-2}` vs `0.6905 a₀`，`P4:164`）需 `lead` 统一；`P5:65` 另指出 `F05:65` 的 `½` **双计**（该步在窗内为假）。

### (c) —— **触发（这是本轮的判）**

`D_∞ ≥ ½` **蕴含（其证书蕴含）`ū < 1`，且是更紧的 `ū ≤ 0.3497`** ⇒ 它**不是软化**，是**加强**。
`p6` 的"半"应当读成：**`D_∞ ≥ ½` 的"正性侧"只是 `Z>0`；数字侧仍住在 `ū<1` 里。**

### 对 `p6` 原话的改写（建议逐字替换）

```
③ (L1)  不是"半" ：ε_T 率要 ū<1（要小）；D_∞ 的**符号**只要正（exp，白拿）；
        而任何**数值**地板（½、0.6905）都要 ū<1 且更紧（0.3497 / 0.25）⇒ 同侧，不软化

## 7 · 路径（把靶换成能造的东西）

若真要在 `ū ≥ 1` 处拿到地板，**唯一未被判死的形状**是把"绝对收敛 + 几何级数"换成"**条件收敛 / 正性**"，让求和**不经过** `|A(α)|≤ū^{α+1}`：

1. **对象**：`Σ_{α≥0}(1−α)A(α)`（`log D_∞` 的级数本体）在 `ū ≥ 1` 的**可和性**，而非其绝对值级数。目标产出：`D_∞ ≥ c > 0`（任意 `c`，`½` 只是记账），⇒ 直接 `I1`（`f₁²=a₀D_∞ ≥ a₀c`），⇒ 残数地板不依 KP 盘。
2. **机制候选（已有半成品，非本轮新造）**：`P6-1` **Gram/反射正性** —— 把装饰和写成 `A = ⟨v|T|v⟩ ≥ |⟨v|T_∅|v⟩|²`，**尾项靠正性丢掉，不靠它小**（`P6-SPEC:36,65,70`，标 `[R]` 未证）。这正好是"`ū>1` 仍收敛的重求和"的**唯一工程形态**：用符号抵消替代几何衰减。
3. **必过的酸测（宪章 §1）**：自由场（`f₁²=0`）必须**失效**；且要在 `ū=0.5654`（`β=1/12` 的实点，现只有 `≥0.0301`）上给出 `≥½`，才叫"软化成功"。
4. **同时必须付的账**：`(L1)` 的 `ε_T` **率** 仍要 `ū<1`（§3.1 第 1 步），且 `p6` 的 `(a)` 判词说 ②KP 与 ③`(L1)` 是**同一个** `λ_aΦ<1` ⇒ 只软化 `D_∞` 的**符号**不会去掉 KP 盘，除非第 1 步的代数（`e^ε−1`）也换成不消费 `ε` 小的形式 —— 那需要 `D_fin` 与 `D_∞` 的**同伦**（连续形变）而非界。
