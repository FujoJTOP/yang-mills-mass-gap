## 1. 维数账（逐步，像 `r04_dimcount` 那样）

模型（与 `r08/r11/r12` 同一对象，本文件 `s01_su3red.log [C]` 逐位核）：

```
X = X†, tr X = 0,  U = e^{iX},   W = diag(-1,-1,1) = 2P-1,  P = |3><3|
S_W(X) = β(1 - (1/3) Re tr(W e^{-iX})),   v = (3P-1)/√6  (|v|²=tr v²=1, v ∥ W)
测度 = dX · J(X) · e^{-S_W},   J = Π_{i<j}(2 sin(x_ij/2)/x_ij)²,  Φ = -log J
a = tr(vX),  G = ∂_τ S_W(X+τv)|₀,  H = ∂²_τ S_W|₀,  S = E[H+Φ″|a=0],  D = Var(G+Φ′|a=0)
```

| 步 | 砍什么 | 维数 |
|---|---|---|
| (1) | `su(3) = 8 = N²−1` | **8** |
| (2) | gauge：变量是 plaquette `U` 本身（外侧链已固定），**无残余 gauge 冗余** ⇒ 0。与 `r04` 的 `192→144` 不同（那里 4 条链才有 48 个生成元；这里没有链） | 8 |
| (3) | 条件化 `a = tr(vX) = 0`（一个线性超平面） | **7** ← `r12` 的 7 ✓ |
| (4) | 极分解 `U = g D g†`：`x`（本征值，2 维）+ flag `G/T²`（6 维）。`flag = p(2) + fiber(4)`，`p_j = |⟨3|u_j⟩|² ∈ Δ²`。**被积函数（`J, S_W, a, G, Φ′, Φ″`）只经 `(x,p)` 依赖 `U`** ⇒ fiber(4 维) 精确积分掉，但 `a=0` 已吃掉其中 1 个方向 ⇒ 净 −3 | **4** |
| (5) | 在 `(x,p)` 上重写 `a=0`：`a = (3/√6) p·x` ⇒ 一条**线性**方程 | **3** |
| (6) | `p` 只剩 1 维（`{p∈Δ² : p·x=0}` = 线段），且被积函数 `= e^{κ p·c}×poly₂(p)`（`κ=2β/3`）⇒ 线段积分闭式（二次除差） | **2** |

**合计 `8 −1 −3 −1 −1 = 2`。** 对照 `SU(2)`：`3 → 2(a=0) → 1(径向 O(2))`，同一套算法，只是 `N=2` 的 flag 那步是 0 维（`Φ` 径向）——这就是 `q11/r03` 能拿 1 维区间证明的全部原因。

**关键等式（本文件的中心）**：`W` 与 `v` 是**同一个** rank-1 投影 `P` 的多项式 ⇒

```
W = 2P-1,  v = (3P-1)/√6,  W_{jk} = 2u_j u_k* - δ_jk,  v_{kj} = α(3 u_k u_j* - δ_kj)
⇒ W_{jk} v_{kj} = α[6 p_j p_k + δ_jk(1 - 5 p_j)]      （相位 u_j u_k*·u_k u_j* = |u_j|²|u_k|² 全消）
⇒ v_jj = α(3 p_j - 1),   |v_jk|² = 9α² p_j p_k          （α = 1/√6）
```

所以 `G`（含 Duhamel 积分）与 `Φ′,Φ″`（一、二阶微扰：`ẋ_j=v_jj`、`ẍ_j=2Σ_{k≠j}|v_jk|²/(x_j−x_k)`）**只用到 `p`**。这是 `v ∥ W`（即 `θ=π` 切片的粗模就是 plaquette 自己的方向）的专属性质，见 §6。

## 3. 类函数核查（`r12` 说「2D Weyl 不够」是对的）

`S`、`D` 是数（期望），要问的是**被积函数**：

| 对象 | 类函数？ | 理由 |
|---|---|---|
| `J = ∏(2sin(x_ij/2)/x_ij)²` | **是**（全 `Ad SU(3)` 不变） | 只依赖 `x` |
| `Φ = −log J` | **是** | 同上 |
| `S_W = β(1−(1/3)Re tr(We^{-iX}))` | **否** | 共轭下只被 `Stab(W)=S(U(2)×U(1))`（4 维）保持；`S_3` 只 `S_2` 存活 |
| `G = ∂_v S_W`（离开切片） | **否** | `S_W` 本身不类；`v` 固定 ⇒ 只被 `Stab(v)=Stab(W)` 保持 |
| `Φ′ = ∂_vΦ`、`Φ″ = ∂²_vΦ` | **否** | 类函数的**固定方向**方向导数；`S_3` 只 `S_2` 存活（`Φ` 是径向的只有 `N=2`） |

**机检（`log [E]`，闭式 vs 沿 `X+τv` 的有限差分，4 个样本）**：

```

Φ″     : rel 8.3e-05 / 3.2e-05 / 1.5e-06 / 5.8e-05   (FD 噪声主导)
```

## 5. 判 (a)：2D 区间算术的逐字步骤（`p` 已解析消去）

**结论**：降到 **2 维**（`x ∈ alcove`），所以 `q11` 型严格证书的机器路线**在这里存在**——但被积函数**不是** Weyl 型 `|Δ|²e^{−β(1−cos)}`，而是 `ρ(x) × (线段积分的闭式)`。步骤：

1. **固定参数**：`β=2.5`、`W=diag(−1,−1,1)`、`v=(3P−1)/√6`、`α=1/√6`；声明 `x` 密度 `ρ(x)=∏(2sin(x_ij/2)/x_ij)²`（exp-chart 口径；若改用 Haar 口径则 `ρ=|Δ|²`，**两者的比值 `∏x_ij²` 必须显式带上**，这就是 `ψ`）。
2. **分块**：按 `x₁,x₂,x₃` 的符号把 alcove 分成 6 个开三角形（`Σx=0` ⇒ 至多一个符号不同）；每个块内 chord 端点是 `x` 的**有理光滑**函数（无分支跳变）。
3. **线段积分**：对每块解析算出 `∫₀^L e^{κ p(s)·c}·{1, G, G², Φ′, Φ′², Φ″, GΦ′} ds`——被积函数是 `e^{线性 s}×poly₂(s)`，结果是 `(e^{a}−e^{b})/(a−b)` 型有限和；`a=b` 用 `e^{a}L` 的极限（除差 `(e^a−e^b)/(a−b)` 是整函数，可直接用 Taylor 展开做区间包络）。
4. **乘 Jacobi**：`J_chord = L(x)/|∇_p a|`，再乘 `ρ(x)`；一切 `1/(x_j−x_k)` 都被 `ρ` 的零点（`~ (x_j−x_k)²`）压住 ⇒ 2D 被积函数在 alcove 内部光滑、边界 `|Δ|²` 型归零。
5. **2D 分支定界**：对 `x` 用 Taylor-model 区间包络（先粗网格 `64²`，再对 `S_lo−D_up` 不确定的单元八分），组装
   ```
   S ∈ [S_lo, S_up] = E[H] + E[Φ″]           (H 用同一套闭式: H 由 §1 的 W_{jk}v_{kj} 二次 Duhamel 给出)
   D ∈ [D_lo, D_up] = E[G²] + E[Φ′²] + 2E[GΦ′] - (E[G]+E[Φ′])² ,  E[G]=E[Φ′]=0 (θ↔−θ, §2)
   ```
   若 `S_lo − D_up > 0` ⇒ `G″(0)>0` **严格**（本模型、本 `β`、本 `v`、`a=0`）。若区间跨零 ⇒ 继续细分（被积函数除 `x_j=x_k` 外光滑，那里 `ρ→0`）。

**标签**：降维本身 `[T]`-in-model（§1 的恒等式 `W_{jk}v_{kj}=α[6p_jp_k+δ(1−5p_j)]` 是代数的）+ `[C]`（闭式 vs FD `≤8e−5`、`p` 均匀性 `±0.003`）。**§5 第 5 步的 `S_lo−D_up>0` 本身本轮未算** ⇒ `SU(3)` 的 `S−D` 数值与严格性仍是 `[NG]`（缺的是执行，不是维数）。

## 6. `(c)` 的另一半：`v` 不平行 `W` 时怎么办（诚实边界）

§1 的降维**用到了** `v ∥ W`（两者都是同一个 `P` 的多项式 ⇒ `W_{jk}v_{kj}` 只含 `|u_j|²`）。一般 `v`（`H1` 要求所有粗模）时：

```
a = tr(vX) = Σ_{a,j} v_a M_{aj} x_j ,   M_{aj} = |g_{aj}|² ∈ Birkhoff 多胞形 (4 维)
⇒ 维数 = x(2) + M(4) - a(1) = 5
p 只是 M 的第 3 行 ⇒ p-边缘化只能砍 2 维, 砍不到 2
```

⇒ 一般 `v` **落在 (b)**：需要 **5 维稀疏网格 / Birkhoff 多胞形的 flag 分解**（`M` 的极端点是置换矩阵，`v` 的对角元给线性函数 `M↦Σ v_a M_{aj}x_j`，可在多胞形上用"顶点 + 边"分解做严格包络）。`v∥W` 的物理切片（`θ=π`，粗模 = plaquette 自身方向，与 `SU(2)` 的 `v=e₃` 同构）是唯一能降到 2 的。
