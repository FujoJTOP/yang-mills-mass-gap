## §3 判 (3)：`EEE3` 那句能否承重 —— 4D 上成立吗

**3.1 结论成立（两种读法）**：面积律给的是 `σ`，而 `σ` 是 **diagonal / on-loop** 量（形状导数 `δ²/δσ²⟨W⟩=−g²⟨tr F² W⟩+contact`，其面积系数就是 `σ_R`），靶 `f₁²` 是 **off-diagonal 边残数** `|⟨G|tr F²|Ω⟩|²`；且定理 SS 禁止任何带电数据函数给中性下界 `[T]`（`U2:15,19,236`；`SS-SECTOR:353`）。

**3.2 证据不能搬**：2D 的机制是"`tr F²` = Casimir Laplacian ⇒ 特征标基对角 ⇒ `⟨χ₀|trF²|χ_R⟩=0`"。4D 无此结构，且 4D `f₁²(trF²)` 在 `β=2.2` **实测 `7.14±0.42`（17σ）非零**（`R4-RESIDUE-PROTOCOL:24`）⇒ "`f₁²≡0`" 是 2D 专属，不得当 4D 事实。故 4D 要引的是**对角/非对角 + SS**，不是 2D 反例。

**3.3 靶的转写需纠**：2D 里 `σ_fund>0` **且** `m_n≥2m_ch>0`（`GH2:207,218`）⇒ 2D **不**证"面积律 ⟹ 隙"为假；它证的是"面积律 ⇏ **中性原子** `f₁²>0`"（`T5:296` 同判）。此外仓内无 `σ>0 ∧ m=0` 的 4D 模型（`GH2:235` 逐字穷举）。

**§3 裁决**：`[T]` 面积律**不承重**（作为充分性，经 SS + 对角/非对角）；`[NG]` 用 2D 反例当 4D 证据；`[NG]` "面积律 ⟹ 隙 是假的"这一读法。**下一手**：在 `EEE3-META` 行 (i) 把证据列换成 `U2 §2–3 + SS`，并加一句"2D 只杀原子、不杀隙"。
