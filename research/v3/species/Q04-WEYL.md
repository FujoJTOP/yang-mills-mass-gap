## 0. 判死线（先给答案）

## 1. Weyl 积分公式（写对，含常数）

### 1.1 一般 `SU(N)`

`G=SU(N)`、极大环面 `T={diag(e^{iθ_1},…,e^{iθ_N}) : Σθ_i=0}`、Weyl 群 `|W|=N!`、Vandermonde

```
Δ(e^{iθ}) = ∏_{i<j}(e^{iθ_i} − e^{iθ_j}),      |Δ|² = ∏_{i<j} 4 sin²((θ_i−θ_j)/2)     (1.1)

∫_{SU(N)} f(U) dU = (1/N!) ∫_T |Δ|² f dμ_T ,      dμ_T = 归一化 Haar = dθ/(2π)^{N−1}.   (1.2)
```

**三个必须写清的常数**（`AGENTS.md §3` 的纪律）：

1. **`1/N!` 不可省**。`N=2`：`(1/2!)(1/2π)∫_0^{2π}4sin²t dt = 1`（数值 `0.999999999999893`）；去掉 `1/2!` 得 `2`。
2. **`dμ_T` 是归一化 Haar**。写成裸 Lebesgue `dθ`（`Σθ=0` 上）需补 `(2π)^{−(N−1)}`；写成本文件 (1.2) 的形式则不用补。凡把 (1.2) 的 `dθ` 当 Lebesgue 用的写法都错 `(2π)^{N−1}` 倍。
3. **`|Δ|²` 已是 `4sin²((θ_i−θ_j)/2)`**，不要再乘 `2^{N(N−1)}`。

### 1.2 `SU(2)` 显式

`U=exp(ξ)`，`ξ∈su(2)≅R³`，`ρ=|ξ|∈[0,2π]`，`n=ξ/ρ∈S²`。类角 `θ_class=ρ/2`，`T` 上 `Δ=4sin²(ρ/2)`，`|W|=2`：

```
∫_{SU(2)} f dU = (1/π)∫_0^{2π} sin²(ρ/2) f(ρ) dρ                     （类函数）      (1.3)
∫_{SU(2)} f dU = (1/4π²)∫_0^{2π} dρ sin²(ρ/2) ∫_{S²} dΩ f(ρ,n)        （一般 f）      (1.4)
```

数值：`(1/π)∫_0^{2π}sin²(ρ/2)dρ = 0.999999999999894`；`(1/4π²)∫∫ = 0.999999999999998`。
等价的标准写法 `∫f dU = (2/π)∫_0^π sin²φ f(φ)dφ`（`φ=ρ/2`）与本式逐位相同。

### 1.3 模型的 `J`：`dU = (1/4π²) J d³ξ`（本文件的地基）

`H1A §2.1` 的平坦图测度：`J=sin²(ρ/2)/ρ²`，`d³ξ=ρ²dρdΩ`

```
J d³ξ = sin²(ρ/2) dρ dΩ  ,   ∫J d³ξ = 4π²  ⇒  dU = (1/4π²) J d³ξ  **精确**     (1.5)
```

⇒ **单 plaquette 模型 `e^{−S_W}J d³ξ` 逐字就是 `4π² e^{−S_W}dU`**，即**一个 Haar 积分**。这就是 Weyl 公式能直接用的原因（不是类比）。`J` 的常数只有 `4π²` 这一个，与 `β`、`θ` 无关。

**切片（`ξ₃=a`）的一维化**（§3 的引擎）：`{ξ₃=a}` 是 2-维平面，`d²η=2π|η|d|η|`、`|η|d|η|=ρdρ`（`ρ=√(a²+η²)`）

```
dμ_a(ρ) ∝ J(ρ)·ρ dρ · e^{−βS_W} = e^{−β(1−c cos(ρ/2)+t sin(ρ/2)·a/ρ)} · sin²(ρ/2)/ρ · dρ ,
                                                               ρ∈[|a|, 2π]                     (1.6)
```

（`c=cos(θ/2)`、`t=sin(θ/2)`）。**任意 `a` 上条件测度都是 1-维的**——因为 `u=ξ₃/ρ=a/ρ` 也是 `ρ` 的函数；这是本文件最有用的结构性事实：`E[·|a]` 全部退化成**一个一维求积**，`a₀` 参数化不需要 MC。

`a=0` 时 (1.6) 的权重是 `sin²(ρ/2)/ρ dρ`，**不是** `sin²(ρ/2)dρ`（后者是 3-维径向）。这一条被数值判死：错用 3-维权重给 `Var(G)=0.072367`，正解是 `0.0691206`（`log [2]` 末两行）。

## 2. `G_v`、`H_vv` 作为 `ρ` 的函数

模型（`H1A §2.1` 逐字）：`S_W=β(1−cos(ρ/2)c+sin(ρ/2)t·u)`，`v=e₃`，`u=ξ₃/ρ`，`ξ₃=a`。
记 `w(ρ):=sin(ρ/2)/ρ`（即 `θ=π` 时 `G/β`）。

### 2.1 `a=0` 切片（闭式，**这是主结果**）

```
G_v(ρ) = β t · sin(ρ/2)/ρ = β t w(ρ) ,
H_vv(ρ) = (β/2) c · sin(ρ/2)/ρ = (β c/2) w(ρ) ,                                        (2.1)
⇒  H_vv(ρ) = ½cot(θ/2) · G_v(ρ)       逐点、精确、与 β 无关。                          (2.2)
```

- `θ=π`（`c=0,t=1`）：`G=β sin(ρ/2)/ρ` ✓（与任务给的已知式**逐字一致**）、`H≡0`（`H1A` 的精确零）。
- `θ=0`（`t=0`）：`G≡0`（故 `Var=0`）、`H=(β/2)w`。
- 数值验证 (2.2)：4 个 `θ` 上 `max|H/G−½cot(θ/2)| ≤ 8.9e−16`（`log [4]`）；`G,H` 的解析式与 `S_W` 的中心差分一致（`rel dev ≤ 1.2e−8`，`log [6]`）。

### 2.2 一般 `a≠0`（初等闭式，**(c) 不触发**）

`ρ=√(a²+η²)`、`u=a/ρ`、`c=cos(θ/2)`、`t=sin(θ/2)`

```
w  = sin(ρ/2)/ρ ,   w'  = ((ρ/2)cos(ρ/2) − sin(ρ/2))/ρ² ,
w'' = −sin(ρ/2)/(4ρ) − cos(ρ/2)/ρ² + 2sin(ρ/2)/ρ³                                      (2.3)

G_v = β[ (c/2)(a/ρ)sin(ρ/2) + t( w + (a²/ρ) w' ) ]                                     (2.4)

H_vv = β{ (c/2)[ sin(ρ/2)/ρ + (a²/2ρ²)cos(ρ/2) − (a²/ρ³)sin(ρ/2) ]
        + t[ (3a/ρ)w' − (a³/ρ³)w' + (a³/ρ²)w'' ] }                                      (2.5)
```

`a=0` 时 (2.4)(2.5) 退回 (2.1)。**注意 `a≠0` 时 `H/G` 不再是常数**（`(2.4)` 与 `(2.5)` 是 `ρ` 的两个不同函数）⇒ 逐点比较在 `a≠0` 上**不存在**，这是 (a)/(b) 分界的机制。

`Φ' = ∂_aΦ = Φ_ρ·a/ρ`，`Φ''_{slice} = Φ_{ρρ}(a/ρ)² + Φ_ρ(1−(a/ρ)²)/ρ`，`Φ_ρ=−cot(ρ/2)+2/ρ`。`a=0` 时 `Φ''_{slice}=Φ_ρ/ρ`（**不是** `Φ_{ρρ}`；先写错这一处，`E[Φ'']` 给 `0.3847` 而不是 `0.2051`，已修，`log [5]` 现在逐列吻合）。

## 4. 能否**代数地**看出 `Var(G) ≤ E[H]`？

### 4.1 逐点内容是**等式**，不是不等式

`a=0` 上 (2.2) 给出 `H(ρ)=½cot(θ/2)G(ρ)` **逐点**。于是被积函数之比与 `ρ` 无关 ⇒

> **任何"逐点 `H(ρ) ≥ G(ρ)²/…`"式比较都是空的**；真正的比较只剩**一个数**：两个同测度矩之比 `Var(w)/⟨w⟩`。

这带来一个真正 `[T]` 的东西——**用 `w` 的逐点界**：

```
0 ≤ w(ρ)=sin(ρ/2)/ρ ≤ 1/2  (ρ∈[0,2π])  ⇒  Var(w) ≤ E[w²] ≤ ½⟨w⟩                    (4.1)
⇒ Var(G) = β²t²Var(w) ≤ (β²t²/2)⟨w⟩ ≤ (βc/2)⟨w⟩ = E[H]   只要  β sin²(θ/2) ≤ cos(θ/2)   (4.2)
```

**(4.2) 是 `[T]`**（前提只有 (2.1)+(4.1)，都是初等）。数值：`β=0.5/1/2.5` 时充分条件分别覆盖 `θ/π ≤ 0.7281/0.5758/0.3881`（`log [8]`）。**这是"代数看出"的正面答案，但它是充分而非必要。**

### 4.2 精确阈值 `θ_c(β)`（`Var=E[H]` 的真穿透点，`[C]`：一维求积 + 线性内插）

| `β` | 0.5 | 1.0 | 2.5 | 6.0 |
|---|---|---|---|---|
| `θ_c/π` | 0.9805 | 0.9618 | **0.9171** | 0.8771 |
| 充分式 (4.2) 的界 | 0.7281 | 0.5758 | 0.3881 | — |

⇒ `Var(G)≤E[H]` 在 `θ<θ_c(β)` 上**真**、在 `θ>θ_c` 上**假**；`θ_c` 随 `β` **缓慢**下降（`β:0.5→6` 只从 `0.98π` 掉到 `0.88π`），而 (4.2) 的界保守得多（`θ_c` 的 0.4–0.8 倍）。**⇒ 逐点路线的损失是"常数因子",不是"符号"**——这就在 `(a)` 与 `(b)` 之间给了确切位置。

### 4.3 反例：**无条件的 `Var(G)≤E[H]` 是假的**（`[T]`）

`θ=π` 切片：`c=0 ⇒ E[H]≡0` 精确（不是小量，`H1A` 的 `2.7e−17`），而 `Var(G)=β²V₀>0`（`V₀=0.0110593>0`）。
⇒ **`Var(G) ≤ E[H]` 在 `θ=π` 上对每个 `β>0` 都假**；`a≳0.2` 上因 `E[H]<0` 也假。

**因此**：单 plaquette **不能**给 `Var≤E[H]` 的无条件 `[T]` 证明，任何声称的"普适定理"必被这一格杀死。**但 `H1` 的形式（`Var ≤ E[H]+W_full`）在同一格上是 `[T]`-可算的**：

```
a=0 上 Var(Φ')=0、Cov=0  ⇒  W_geo = E[Φ''_slice]，且  G'' = E[H]+E[Φ''] − Var(G)   （精确；log [9] 后两列逐行相等）
Var(G) ≤ E[H]+W_geo  ⟺  G''≥0  ⟺  β²t² Var(w) ≤ (βc/2)⟨w⟩ + ⟨Φ_ρ/ρ⟩ ,   Φ_ρ = −cot(ρ/2)+2/ρ
       θ=π:  β²·0.0110593 ≤ 0.2051153   ⟺  β ≤ β* = 4.30660785   （`H1A` 的零点，本轮精确复现）
       β=6:  Var−E[H]−W = +0.193019 > 0  ⇒ H1 在该点假（`H1A` (b) 的同一数）
       θ=π/2,β=2.5: 0.377311+0.180870−0.015240 = +0.542941 = G'' > 0  ⇒ H1 真
```

⇒ **`Δ_dyn = E[H]−Var` 在单 plaquette 上的"符号"由 `(θ,a,β)` 三维决定**：`θ<θ_c` 正、`θ=π,a=0` 为零（`H1` 靠 `W_geo` 撑）、`a>0.2` 为负。与 `P16 §6` 的记账一致：**缺口 100% 在 `H_vv`**。

## 6. 这对 `H1` 意味着什么（一句话一段）
