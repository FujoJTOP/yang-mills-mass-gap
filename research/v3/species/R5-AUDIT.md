## §1 · `u(β)=c₁/c₀`：定义、四个值、根、2.12%

### 1.1 先把 `c_j` 钉死（本节是本审计最重的一条）

SU(2) Wilson 作用量 `e^{βcosθ}` 按**特征标**展开。用 Chebyshev-U 作基（`U_n(cosθ)=χ_{n/2}`，即指标 `n = 2×自旋`）：

```
 e^{βcosθ} = Σ_{n≥0} c_n U_n(cosθ),   c_n = ∫ e^{βcosθ} χ_{n/2}(U) dU
           = I_n(β) − I_{n+2}(β) = 2(n+1) I_{n+1}(β)/β        (Bessel 递推)
 ⇒ c₀ = I₀−I₂ = 2I₁/β ,   c₁ = I₁−I₃ = 4I₂/β  (基础表示) ,   c₂ = I₂−I₄ = 6I₃/β (伴随)
```

**所以任务书里 `(2j+1)I_{2j+1}(β)/β` 这个写法差一个因子 2**（正确为 `2(2j+1)I_{2j+1}/β`，`j` = 自旋），且它把 **`c₁` 指向伴随而不是基础**。论文写的是 "`c₁/c₀` the ratio of the first two character coefficients"，数值上只与**基础读法**相容。

### 1.2 四个数（我方复算，`scipy.special.iv`，Bessel 递推恒等式互核到 `1e−15`）

| `β` | `u=(I₁−I₃)/(I₀−I₂)` | `=2I₂/I₁` | 论文印刷 | 绝对差 |
|---|---|---|---|---|
| 1/48 | 0.0104164783 | 0.0104164783 | 0.0104165 | `2.2e−8` |
| 0.5 | 0.2474358566 | 0.2474358566 | 0.2474359 | `4.3e−8` |
| 1 | 0.4803874477 | 0.4803874477 | 0.4803874 | `4.8e−8` |
| 2.5 | **1.0143902001** | 1.0143902001 | 1.0143902 | `9.4e−11` |

另核三条恒等式（全部通过）：`u = 2(ln c₀)′`（差 `<4.1e−10`）；`u′ = 2Var(cosθ)`（差 `<6.7e−12`）；`β→0` 时 `u = β/2·(1+O(β²))`（`β=1e−3` 比值 `0.99999996`）。

### 1.3 根与 2.12%

`brentq(u−1) = 2.446918311289`（论文 `2.446918`，差 `+3.1e−7`）；`2.5 − 2.446918311 = 0.053081689`；`0.0530817/2.5 = 2.1233%`；`2.5/2.446918 = 1.021693`（论文 `1.0217×` ✓）。

### 1.4 「另一个选择」的后果（这条必须写进论文）

若按自旋指标把 `c₁` 读成**伴随**：`u_adj = 3I₃/I₁`，则

```
 u_adj(1/48, 0.5, 1, 2.5) = 5.43e−5, 0.03077, 0.11768, 0.56546
 u_adj(β)=1 的根 = 3.906187   （>2.5）
```

即：**`β=2.5` 处 `u_adj<1`，根本不存在"2.12% 的缺口"**，整条阻断故事蒸发。所以 `c₁` 的所指**是承重的**，不是记号洁癖。

另：因子 2 也承重——`Φ(0,β)=Σ(n+1)c_n/c₀=(e^β−c₀)/c₀` 只有在 `c₀=2I₁/β` 时成立（我直接求和 vs 闭式，`β=2.5` 差 `5.3e−15`）。若误用 `c₀=I₁/β`，`β=2.5` 处 `Φ(0)` 由 `5.0508` 变 `1.3399`，`§0(a)`/`§1.2` 那一串 `β_max`（`0.765528` / `0.018269`）全部作废。

**判定：数 OK，定义 SHIFTED。** 改法见 §8。

## §3 · `C=2` 在 DD 类内的尖锐性

**(a) 精确部分（`[T]`）.** `q≡c`：`μ_k=k²π²+c`，`ρ²₊(c)=(4π²+c)/(π²+c)`。`ρ²₊≤4 ⟺ 4π²+c ≤ 4π²+4c ⟺ c≥0`（我逐点扫 `c∈[−3,3]` 601 点验证，全部一致）。`c=0` 时 `ρ²=4` **精确**。

**(b) 数值部分.** 我方 FD（`N=2000`，三对角 `eigh_tridiagonal`）：

| `q` | FD `ρ²` | 精确 | 差 |
|---|---|---|---|
| `0` | 3.999997535 | 4 | `−2.5e−6` |
| `+1` | 3.723998705 | 3.724000995 | `−2.3e−6` |
| `+10` | 2.490154772 | 2.490156150 | `−1.4e−6` |
| `−5` | 7.080328643 | 7.080332356 | `−3.7e−6` |

**⇒ `3.999999` 就是 `4` 的离散化值**（`O(h²)≈(π/N)²` 量级）。论文 `ch15` 里同时写 "saturates 4 exactly at q≡0" 与 "`sup ρ²=3.999999`"，两者不矛盾但**并存会误导**：sup 是 `4.000000`，`3.999999` 是 FD 读数。

**(c) 对抗搜索（我自己的电池 + 优化）.** 15 个确定性形状 + 240 个随机 `q≥0`（多峰高斯、阶跃、正弦平方、端点集中）：`sup=3.9999975`（在 `q≡0`），`inf=1.0329`。20-bin 非负剖面 × Nelder–Mead 10 次重启：**在良态区（`q≤1e8`）从未超过 4**；唯一越过 4 的那些重启（`9.02`、`14.88`）全部落在 `q≳1e14` 的病态区——把同一剖面换成 `q=1e6` 立刻回到 `3.99996`。**这是三对角求解器在 `diag~1e18` 下的假值，不是反例**（记下来：语料若用同类优化器，`q≥0` 侧的 `>4` 报告需先做标度体检）。

**(d) 一条解析旁证.** 硬壁把 `[0,1]` 切成子区间时，并谱的两个最低值只能来自最长段的前两阶（比 `4`）或"最长段基态 + 次长段基态"（比 `(ℓ_max/ℓ₂)²`）。但后者一旦 `>4`，最长段的第二阶 `4μ₁` 必低于它 ⇒ 实际比 `≤4`。**故 `sup=4` 且由 `q≡0` 取到**，与电池一致；一般 `q≥0` 的严格证明仍未给出，论文标 `[C]` 是诚实的。

**判定：SHIFTED（`3.999999 → 4.000000`），其余 OK。**

## §4 · `β*=1/32`（SZZ 天花板）与 `C*`

定义（照 SZ-CEILING §0.1）：`C* = sup_{configs} sup_{|v|=1} (−λ_min Hess S)/(N|β|)`。我用与 §6 同一套格点 Hessian（`SU(2)`，`L=2`，`β=2.5`，协变、对称化），标定到 `C* = 2N(−λ_min)/β`（该因子 2 是度量约定；校准点：z₂ 组态 `λ_min=−10`，与语料 `mc_lattice.log` 逐位一致）。取**全阻挫 Z₂ 组态**（GF(2) 线性解：每个 plaquette 的 link 符号积 `=−1`；`d=2,3,4` 均有解）：

| `d` | 全阻挫可解？ | `S_W` | `λ_min` | `C*=2N(−λ_min)/β` | `8(d−1)` | `1/(2C*)` |
|---|---|---|---|---|---|---|
| 2 | 是 | 20.000 | −5.000000 | **8.000000** | 8 | 0.0625 |
| 3 | 是 | 120.000 | −7.500000 | **12.000000** | 16 | 0.041667 |
| 4 | 是 | 480.000 | −10.000000 | **16.000000** | 24 | **0.03125 = 1/32** |

与我另算的真空 `λ_max` 交叉核：`λ_max(vac)=(β/2N)·curl_max`，`curl_max = 8/12/16`（`d=2/3/4`），与 `C*` 完全一致（`1e−8`）。**`d=2` 恰好 `8.000000 = 8(d−1)`；`d=4` 落在 `[16,24]` 的下端（16）。**

两点措辞修正：
1. **"For `d≥3` the saturating family is obstructed"** —— 我确认**组态本身存在**（全阻挫 Z₂ 解在 `d=3,4` 都有，`S_W=120/480`）；被阻的是**CS 饱和**（常数模是 curl 的零模，所以 `8(d−1)` 取不到）。这是两件事，句子应写成 "the saturating *mode* is obstructed, not the configuration"。
2. **`1/48` vs `1/32`**：`C*∈[16,24]` ⇒ 天花板 `∈[1/48, 1/32]`。论文说 "the published constant is `1.5×` loose" 应改为 **"at most `1.5×` loose"**（真值可能一点都不松）。

**判定：三个 `C*` 值 OK（机器精度复现）；`β*=1/32` OK；措辞两处 SHIFTED。**

## §5 · `sup|∇S_W|² ∝ L⁴`：`900 → 14400`

### 5.1 算术（全对）

```
 900 / 64 links  = 14.0625 = 9β²/4  (β=2.5)
 14400 / 1024    = 14.0625           (L=4: 4L⁴=1024)
 14400/900 = 16  = (4/2)⁴  ✓
```

### 5.2 对象是什么（论文措辞不精确）

`∇S_W` 的 link 分量：`g_{ℓa} = −(β/N) Re tr(T_a M_ℓ)`，`M_ℓ = Σ_{p∋ℓ} s_p X_{p,ℓ}`（`X` 为把该 link 旋到迹末端的 plaquette 积，`s=±1`）。对 SU(2)：`|g_ℓ|² = (β/2)²|m_ℓ|²`，`m_ℓ = Σ_p s_p sinθ_p n_p`，六项单位向量 ⇒

```
  |g_ℓ|² ≤ 9β² = 56.25   （逐 link 的解析上界，L-无关）
  语料实测 14.0625 = 9β²/4 = 3 个 plaquette 对齐的值
```

**所以：`sup` 是对场取的，被取范数的对象是「对 link 求和」。** 求和给出 `4L⁴` 个 `O(1)` 项 ⇒ 总和必然 `∝L⁴`。这不是"局域梯度随体积增长"：**逐 link（逐点）的 sup 是 `L`-无关的**（`≤56.25`，语料组态取 `14.06`）。

### 5.3 900 不是 sup

我用**同一套**梯度（对 `S` 的 FD 校验 `3.2e−6`）做逐 link 爬山（`L=2`，`β=2.5`，4 次重启 × 30 轮）：

```
 max per-link Σ_a (∂S/∂x^a)² = 34.37     (语料 14.06；上界 56.25)
 total (L=2)                = 2199.5    (语料 900)
```

即语料的 `max_config` 只是它 8 个采样组态里的最大，**比可达值低 2.4×**。这与"∝L⁴"不冲突（指数仍是 4），但**常数不是 sup**，而且 `900→14400` 的 16 倍在任何组态上都成立（纯 link 计数），**不携带"场越强梯度越大"的信息**。

**判定：SHIFTED。** 建议句：`Σ_ℓ|∇_ℓS_W|²` 是广延量（逐 link `≤36β²/N²`——`N=2` 即 `9β²=56.25`——`L`-无关），故总和对 link 数 `4L⁴` 正比；`L⁴` 是体积计数，不是局域导数的增长。

## §6 · `−(4.8/N)β` vs `−(2.9/N)β` vs `−8β/N`（SU(3)，β=2.5）

方法：4D 周期格点 `L=2`（`SU(3)`：64 link × 8 = 512 维；`SU(2)`：192 维）；`S_W=βΣ(1−(1/N)Re tr U_p)`；**协变 Hessian** = 左不变标架下平坦二阶导的**对称化** `½(D²+D²ᵀ)`（等价于 `Hess = ½(D_vD_w+D_wD_v)`，即带 `∇^{LC}_{λ_a}λ_b=½[λ_a,λ_b]` 的协变版本），`h=2e−4`；组态取全阻挫（每 plaquette 为 `−1`（`N=2`）/ `diag(−1,−1,1)`（`N=3`），梯度严格为 0 ⇒ Hessian 无 `Γ·dS` 歧义）。

**我的数字：**

| 对象 | `N=2` | `N=3` | 归一化 |
|---|---|---|---|
| 逐 plaquette 精确界 | `⪰−(β/4)g` | `⪰−(β/6)g` | `= −(β/2N)g`，`c_N=1/2` **精确**（`M=−1` 取等） |
| 逐 link（6 片求和） | `−3β/2 = −3.75` | `−3β/3 = −2.50` | `= −(3.0/N)β` |
| **全格点 `λ_min`** | **`−10.000000`** | **`−6.666667`** | **`=−(8/N)β`，`N`-无关** |

（`N=3` 底部谱：`−6.667` 三重 + `−5.000` 三重；`N=2`：`−10` 三重 + `−7.5` 三重。全部为规范不变方向。）

**判定：**

- **`−(4.8/N)β`：WRONG.** 图卡 `D²_{ab}=Re tr(λ_aλ_bM)` 的 `sup λ_max=0.763`（未对称化），对称化后精确 `1/2`；高估 `1.53×`（`SU(2)`）/`1.64×`（`SU(3)`），与 AT-STAR/LOOP-RUNBOOK 的勘误一致。
- **`−(2.9/N)β`：口径混淆.** 它等于 `6·c_N` 取 `c_N=0.4789`（Haar 抽样值）⇒ `2.87/N`；但 `c_N` 的**精确上确界是 `1/2`**（`M=−1` 取到，见上表），故逐 link 的**正确常数是 `3.0/N`**，不是 `2.9/N`（低 `3.3%`）。更要紧：逐 link 求和**不是**格点 Hessian 的 `λ_min`。
- **`−8β/N`：正确（全格点、集体模）.** `N=2` 与 `N=3` 都精确 `−8β/N`（`−10`、`−6.667`），并且 `8β/N = C*β/(2N)`（`C*=16`）——它和 §4 的天花板是同一个常数。

**对论文那句话**（`ch13` §Errata）："the covariant bound is exactly ½, the measured worst case `−8β/N` against the formerly quoted `−(4.8/N)β`" —— 两个数都对，但属于**两个不同对象**（逐 plaquette 系数 vs 全格点集体模），准确关系是 `λ_min = −C*β/(2N) = −8β/N`（`C*=16` 的 curl 集体模），它不是六片逐 link 求和 `6·(1/2)/N = 3/N`。建议补全，否则读者会把 `½` 与 `8` 当成同一量的两个估计。

## §7 · `2N²=18` 的换算

```
 λ_tH := βN = 2N²/g²      (β=2N/g²)
 ⇒ g² = 2N²/λ_tH ,  λ_tH = 1 ⟺ g² = 2N² ,  g² = 1 ⟺ λ_tH = 2N²
 SU(3): 2N² = 18 ;  SU(2): 8
 β=2.5, N=3: λ_tH = 7.5 , g² = 2N/β = 2.4 , 2N²/g² = 7.5 ✓
 β=2.5, N=2: λ_tH = 5.0 , g² = 1.6 , 2N²/g² = 5.0 ✓
```

另核：`λ_tH ≠ 't Hooft`：`λ_H=g²N`（`β=2.5,N=3` 时 `7.2`），`λ_tH = 2N³/λ_H`（`54/7.2=7.5` ✓）。两个"1"相差 `2N²`（18 / 8）✓。

**判定：OK。** 唯一提醒：`λ_tH` 这个名字容易被读成 `g²N`，论文已在附录写清，建议正文第一次出现时就给 `λ_tH=2N³/λ_H`。
