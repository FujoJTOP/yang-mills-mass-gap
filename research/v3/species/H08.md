## §1 前提的逐字口径（不许含糊）

```
H1 (窗口版, [C]) :  ∃Δ₀>0  ∀(L,a) ∈ 连续统窗  ∀ 粗横模 v（k→0，群方向）:
                       Δ_dyn(v) ≥ a²Δ₀² ,        Δ_dyn := E[H] − Var(G) ,
                       H = ∂²_v S_W ,  G = ∂_v S_W
恒等层 ([T])     :  G″ = Δ_dyn + W_full ,   W_full = W_geo + X ,  X = −2Cov(G,Φ′)
                    W_geo ≥ N/12 ([T], Prékopa) ；W_full ≥ 0 只有 [V]（21% 点 X<0，min 比 1.025）
m 的两个名字     :  m := inf (spec T_phys \ {0})  =  m_{0⁺⁺} := inf supp ν_O   （目标处二者同一）
```

**三条量词事实（全部可核，且决定后面卡在哪）**

1. **`v` 是群方向，`k` 只有一个值 `k→0`**（`app.tex:190` 逐字 "uniformly in `(L,a)` and for every coarse transverse `v` at `k→0`"）。⇒ H1 **不是**动量一致的。
2. **`s₁ ≥ m` 是 `[T]`**（连通测度 + 谱定理，`B10-1`）⇒ **任何 `≥ m` 的量都不可能给 `m` 的下界**。这一条直接封死"谱侧退路"。
3. **`Δ_dyn` 在 2D YM 上 `= 0` 精确而 `m = 3g²/8 > 0`**（`[T]*`，`N02 §2.2`）⇒ **H1 不是 `m>0` 的必要条件**；"曲率携带隙"这个机制**在 2D YM 里不成立**。⇒ 任何 `H1 ⇒ m>0` 的证明**必须消费 4D 特有的输入**，不能只做曲率侧代数。

## §3 ★卡点具名★（不许含糊）

**卡在 S2 → S3，且是三个独立的子卡点，一个都不能省：**

### C-a 「点值 → 一致」：H1 是**一个动量**的曲率，隙是**一个 infimum**
`∀v` 里的 `v` 是**群方向**（`su(N)` 里的粗横模），`k` 只有一个值 `k→0`。而
`m = inf{λ_c : c 走遍整个动量塔}`。⇒ 要把 S2 的单道结论升成隙，**必须把 H1 的 `∀v` 换成 `∀(k,v)`**。
这个替换**不是免费的**：它把 H1 强化成一个新假设；而且它在窗口外是**假**的
（`[NG]` 见证：`θ=π, v=e₃, β>4.30661` 给 `G″<0`；更硬的一条是 `θ=π` 上 `Δ_dyn = −Bβ² < 0` 对一切 `β>0`）。
**⇒ 卡点 C-a 的名字：`k`-一致化（动量一致化）。**

### C-b 「道 → 扇区」：`G″` 活在 `a`/`S_W` 道，Clay 要中性 `0⁺⁺` 道
这是 `e₃`。语料已把它判成**类型不可比**而非"没证到"：
运动学桥被荷分级排除 `[T]`（`IMP-ARROWS:76`）；`SS-SECTOR` 推论一 `[T]`：**任何补 `e₃` 的推导必须消费至少一条非装饰不变假设**，而该类只有三型（中性数据本身 / 联合-态层 / 显式解），全被逐条判掉。
**⇒ 卡点 C-b 的名字：`e₃`（扇区转移）。**

### C-c 「`≥ m` 的量不能下界 `m`」：方向定理把谱侧退路封死
`s₁ ≥ m` `[T]`。任何"谱量 `X` 满足 `X ≥ m`"的对象，`X ≥ c>0` **只给 `m ≤ X`**。
S2 的产出正属此类（单道速率 ≥ λ ⇒ `m ≤ λ`）。
**⇒ 想用 `s₁`（或任何 `≥ m` 的谱量）推 `m > 0`，方向反，此路不通。**（题面的提示在此处落地。）

## §4 缺的 X 是什么类型的东西（正面回答，允许造）

### X1 = `k`-一致化的曲率地板（C-a 的解药）
**要什么**：`∃λ>0 ∀(L,a) ∀ 块自旋尺度 j ∀ 动量 k ∀v : Δ_dyn^{(j)}(v;k) ≥ λ`，
其中 `Δ_dyn^{(j)}` 是**第 `j` 层块**的边缘（marginal）曲率，并且要**带尾切除**：Savvidy 尾（测度 `≤ e^{−c/g²}`）可以排除，其余部分必须一致。
**它是什么类型**：
- **测度层（概率测度）不等式**，不是逐点代数不等式；
- **Brascamp–Lieb / Bakry–Émery 常数的 IR 一致下界**：等价于"块边缘测度族 `{ν_j}` 的 BL 常数有一致正下界"；
- 必须**非微扰**（在 `β=2.5` 无小参数可用，`LOOP-RUNBOOK:263` 已钉死）；
- 必须**对 `U′` 是 a.e./typical 的**，不能是逐点 `∀U′`（否则被 `θ→π` 的 `[NG]` 反掉）；
- 必须**在 UV 一致**（块尺度 `j` 的计数和 `Σ_j g_j⁴` 收敛，`H1-RG-DESCENT §2`）以免累加损失吃掉常数。

### X2 = `e₃`（C-b 的解药）
**要什么**：一条**非装饰不变**的动力输入，把 `a`-道的 IR 谱地板搬到中性 `0⁺⁺` 道。
**它是什么类型**：**不是估计，是"换对象"**——需要一条把带电（1-形式）扇区的信息搬到中性扇区的新机制
（唯一已知实例是 `u`-同一性，只在 `β<1/48`）。类型上它是**假设类更换**，不是常数改进。

### X 明确**不是**什么（三条负面边界，防止把靶又降级成改名）
1. **不是恒等式**：`H1 ⟺ Δ_dyn ≥ a²Δ₀²` 已用完（S1），零新估计（`P03:253`）。
2. **不是 Prékopa 型运动学界**：`W_geo ≥ N/12` 是 `[T]`，但它**加号方向相反于需要**（它掩盖 `Δ_dyn<0`，T01 §5 警示 1）。
3. **不是 RG 一步下降**：`H1-RG-DESCENT` 只搬"曲率"不搬"原子"，且在 `β≈2.5` 头上有 `γ_j→0`、`η_j≥1`、`G″≤0`（`SM5:383`）⇒ 下降在物理点**朝坏方向走**。

## §5 (a)/(b)/(c) 逐条

- **(a) 不成立。** S1、S2 是 `[T]`，S3 的 S3a/S3b **都没有定理**。`H1 ⇒ m>0` **未被证**。
- **(b) 成立，且已具名。** 卡的步 = **S2→S3**；缺的 = **X1（k-一致化的 BL/BE 常数下界，带尾切除、a.e.-in-`U′`、UV 一致）+ X2（`e₃`）**。类型见 §4。
- **(c) 循环存在，位置唯一且必须写死**：
  > 若有人把 S2 写成"`G″ ≥ λ` ⇒（Poincaré/Bakry–Émery）`λ₁(ν) ≥ λ`"，则
  > 在 flat 粗图上 **`λ₁(ν) = 1/Var_ν(a) = G″`（Ward）**，于是得到的是 `H1 ⟺ H1`；
  > 再从 `λ₁(ν) ≥ λ` 到 `m ≥ λ` 又需要"纤维消去把 `λ` 原样留住"，而纤维/快模隙**恰是 silent 的那一个**（`H6 §2`）。
  > **⇒ 循环 = 「曲率 ⇒ Poincaré ⇒ 隙」这两跳：第一跳是改名，第二跳是 silent 纤维隙。**
