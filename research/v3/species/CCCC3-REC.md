## §1 递推：迭代几步、要什么收敛

1. **步数 = 无穷**（`∀k` 整条塔；常数不带 `k`：`fax:22720`）。但**要求的不是收敛，是一致有界**：结论是 `sup_k‖Φ_k‖_α ≤ 2ε`（`fax:22490`），下游消费它来换"scales-independent locality constants, uniformly in the spatial volume"（`fax:22505–22513`）。
2. **`ε/2` 的来历**：`C‖Φ_k‖²_α ≤ (Cε)‖Φ_k‖_α`，故 `‖Φ_{k+1}‖_α ≤ ε/2 + Cδ_k`（`fax:22499`）。所以"`1/2`"是 `Cε` 的**放大因子价签**，不是一个余量。
3. **`Σδ_k<∞` 在论文里的位置**：`δ_k := e^{−c4λ_k}+b^{−γk}`（`fax:22487`），接着两句都是**选择句**——"choose `λ_k=λ₀+αk` so that `e^{−c4λ_k}` decays geometrically; then `Σ_kδ_k<∞`"（`fax:22488–22490`）；证明末 "Choosing `λ` so that `Σ_{j≥0}e^{−c4λ}<ε/(2C)`"（`fax:22500`）。⇒ 可和性是**构造的产物**，不是被假设的对象。
4. **核对**：`fax:12459` 的 `Σδ_k<∞` 是**另一个** `δ_k`（(F.58) 的 FRD 度量距离），不是 (6.36) 的 `δ_k`。`AAAA3-BUYS.md:9` 把两处并引（`22490`+`12459`），不宜当同一句用。
