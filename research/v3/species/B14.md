## 1 · `W(a)` 的形状与全局极大（Q1）

W(a) ≤ a e^{-a}/λ ,  max_a a e^{-a} = 1/e  ⇒  W ≤ 1/(eλ)

数值核（六列全过，比值 `0.770–0.993 ≤ 1`）：`λ=54.366` 的 `1/(eλ)=6.76676e−3` vs 数值 `6.7207e−3`（`0.993`）；`λ=25.2` 的 `1.45984e−2` vs `1.43872e−2`（`0.986`）；`λ=1` 的 `0.36788` vs `0.28339`（`0.770`，大 `β` 处高阶表示使 `Φ>βe^a`，界更松）。

**⇒ 判 `[C]`**：`λ = eΔ` 且 `Δ ≥ 1`（**每点至少一个 animal**，组合地板）⇒

**这是"判据形状"的天花板，不是常数天花板**：只要右端仍是 `O(a)`（KP/分级型），把 `Δ` 从 `20` 一路压到 `1`（物理上荒谬）、把包络全丢掉，**也到不了 `2.5`**。要过 `2.5` 必须换**物种**（右端不是 `O(a)` 的判据），而不是换常数。

## 3 · `p1` 的「`1/48`」与 `gap1` 的「`λ_* ≤ 48`」（Q3）

**1. `1/48` 在 KP 族里够不到（差 2.7×–5.6× 的常数）** `[E]`。
**2. `λ_* ≤ 48` 是错的靶数** `[T]`（算术）：
```
a=0 的非法判据:  W = 1/λ          ⇒ W=1/48 ⟺ λ=48        ← gap1 的 48 从这来
合法判据 (env):   W = g(a*)/λ     ⇒ W=1/48 ⟺ λ = 48·g(a*) = 48×0.205884 = 9.882
合法判据 (bare):  W = 1/(eλ)      ⇒ W=1/48 ⟺ λ = 48/e    = 17.657
```
数值核：`λ=48` 在 `bare` 下给 `7.6052e−3 = 0.365×(1/48)`，`env` 下给 `4.2765e−3 = 0.205×(1/48)`（**不是** `1/48`）。⇒ 「`λ_* ≤ 48`」若被当成"到 `1/48` 的目标"，**过松 4.86×**——与 `0.018394` 过报 `4.84×` 是**同一个因子**（同一个 `1/λ ↔ g(a*)/λ` 混淆）。

**3. 那 `1/48` 是不是"硬天花板"？分两层** `[C]/[NG]`：
* **不是硬天花板**（对全项目）：`P3` 强耦合残数定理已在 `β < 1/48` 给出 `f₁² > 0`（`[T]`），那是**另一物种**的判据，与 KP 族无关；
* **是 KP 族的硬天花板之上**：KP 族连 `1/48` 都到不了（§2/§3.1）。⇒ `1/48` 的"天花板"地位**未被本轮推翻，也未被本轮支持**；能被证的是 **`1/e²` 才是 KP 族的硬天花板**。

## 5 · 限定 / 不主张 / 诚实线

* **限定**：`SU(2)`、`β ≤ 1/48`、`Ĉ`-类动物常数 `λ = eΔ`（`Δ=20`）；`Φ` 求和 `n ≤ 300`（`a*` 处已收敛到 `1e−9`）。`λ` 只作前置因子 ⇒ **`a*` 与一切比值对 `λ` 不变**。
* **不主张**：`1/e²` 只界 **KP/分级型判据**；`bare` 形（丢包络）本身是**上界口径**，不是可实现的判据——所以 `iii` 档 `1.4387e−2` 是**天花板**，不是"新窗"。真实可得的窗仍是 `3.777e−3`（做完包络改进是 `6.72e−3`）。

* **诚实线**：`(iii)` 的 `174×` 缺口是**判据形状**造成的，不是算术失误；要闭合必须造**右端非 `O(a)`** 的新物种判据或跨越判据（本项目尚未有）。
