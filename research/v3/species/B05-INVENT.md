## 1 · Q1 的精确答案：三个模型是 min 律的三个极端

**U05 引理 1 `[T]`**（逐字）：`μ=μ₁⊗μ₂`、Dirichlet 形式相加 ⇒ `λ₁(μ) ≤ λ₁(μ_i)` ∀i；取 `f=f_i⊗1` 逐一相等 ⇒ `λ₁(μ)=min_i λ₁(μ_i)`。推论：**任何建立在"单方向/某边缘"上的量都是全空间常数的上界**，由它出发只能得隙的上界。M6 是这条的极值点。

| 模型 | 真空测度的形状 | `λ₁` 为什么是这个值 | `G″` 是什么 |
|---|---|---|---|
| 自由场 | 一整块 Gauss，`κ=0`（方差发散） | 平坦方向**就是整个理论** ⇒ `0` | `0`：同一条平坦性 |
| **M6** | `μ_a ⊗ μ_b`，`μ_b` = 圆环上的 Lebesgue（`λ₁=4π²/L²→0`） | **min 被张量因子拉走** | `2ω`：`μ_a` 的**边缘**常数，恒 >0，`L`-无关 |
| **2D YM** | 紧群上的热核（无乘积因子、无平坦方向） | **无平坦方向可拉**，min 落在第一个非平凡 Casimir `3g²/8`，`L`-无关 | `0`：载体 `trF²=H` **守恒** ⇒ 关联是接触项、常数模边缘是 Haar 平坦 |

**两条独立机制，方向相反**（这是本轮对 Q1 的核心答案）：

- **M6：项在、min 走**。`G″=λ₁(μ_a)=2ω` 是 min 里**被丢掉的那一项** ⇒ 它是全空间常数的**上界** ⇒ 充分性失败（`G″>0 ⇏ m>0`）。
- **2D YM：min 对、项不在**。`G″=0`、`f₁²≡0` 是因为**载体守恒**（`trF²=H`，2D 无传播自由度 [FOSP-B §B7]），局部数据与谱完全解耦 ⇒ 必要性失败（`m>0 ⇏ G″>0`）。

⇒ 一句话：**局部关联与谱底在两个模型里都以相反的方式脱钩**。所以任何"局部/单尺度"量必死两次；而任何"整体"量必然等于 `λ₁`，即 `m`。**试金石的两行 (2D YM, M6) 是同一枚硬币的两面，它们共同只钉住了一个 bit。**

**旁证（为什么"维数"不是答案）**：M6 的 `m_L=min(ω,2π²/L²)` 与自由场的 `~1/L` 是**不同的体积指数**（`−2` vs `−1`），2D YM 是 `0`（`L`-无关）。所以"体积指数"能分开自由场与 M6，但**分不开"两个都要 0"**：要把 0 与 0 同时拿到，只能读"`m=0` 这一事实"本身 ⇒ 又回到 `m`。见 §4 B05-1。

## 2 · Q2 的精确定位："整体"就是循环

`m` 的定义 `−lim_t t^{-1} log‖T^t‖`（真空归一）**就是**全空间 Poincaré 常数 `λ₁(μ_vac)`（`U05 #5`，`[T]`-等价）。所以任务的提示"𝔐 必须是整体的（整条 `t` 或整个谱）"在数学上指向 `λ₁`，而 `λ₁` 与被测对象是同一个数。**"整体"与"不是换名"两条要求互斥。**

这不是措辞问题，是**扇区问题**：`λ₁(μ_vac)` 只在**一个** Hilbert 空间（`Ω^⊥`）上取 min。要拿到"非换名"，唯一出路是**换扇区**（带电/扭结/隔离），而换扇区之后它就不再是"隙的判据"，而是另一个动力学数。§3 的 `𝔐₁` 就是这个出路，§4 说明它为什么仍然过不了"仅四模型"这一关。

## 3 · 三个候选（定义 + 四模型值）

记 `T̃ := e^{-(H-E₀)}|_{Ω^⊥}`（真空归一、去真空），`σ(T̃)` 为其谱。

### `𝔐₁` = 带电扇区隙 / 弦张力 `[T]`
```
𝔐₁ := −lim_{A→∞} (1/A) log|⟨W_R(∂A)⟩| ,   R = 基本表示
```
即"带一个静态基本源的最低态能量"（不是真空扇区的 min，是**带电扇区**的 min）。

| 自由场 | 2D YM | M6 | 单 plaquette |
|---|---|---|---|
| `0`（Gauss ⇒ 周长律）`[T]` | `3g²/8 = 0.375`（精确 `σ=g²C₂(R)/2`）`[T]` | `0`（无规范扇区，`W≡1`）`[M]` | **无定义**（无 `t`、无广延 `A`）`[T]` |

4/4 通过。**但**：在 2D YM 上 `σ ≡ m`（退化恒等式，`U05 #6` 已记），四模型里**唯一非零的那一行数值逐位相同** ⇒ 试金石**无法**把它与 `m` 的换名分开。它的非重名性只能靠**第 5 行**（大质量自由标量：`m=ω>0` 而 `σ=0`）建立，而那一行**不在试金石里**。

### `𝔐₂` = 隔离半径（Kato 边距）`[T]`/`[E]`
```
𝔐₂ := min{ |λ−λ′| : λ≠λ′ ∈ σ(T̃) }        （底是聚点时记 0）
```
"底原子到谱其余部分的距离"，即 `(CP)` 里 Kato 隔离的量；它是**整条谱的两点量**，不是 `inf`。

| 自由场 | 2D YM | M6 | 单 plaquette |
|---|---|---|---|
| `0`（连续谱，间距 = 0）`[T]` | `5g²/8 = 0.625`（`j=1/2` 与 `j=1` 之间）`[T]/[E]` | `→0`：`L=10/40/160` 给 `1.8e−3 / 7.0e−4 / 3.4e−5` `[C]` | 无定义 |

4/4 通过。**死因**：任何相对论靶上本质谱始于两粒子阈 `2m` ⇒ `𝔐₂ = 2m−m = m` ⇒ **换名** `[NG]`。它比 `m` 多的只是"底是原子"这一句（`2D YM` 上确实真：`0.625≠0.375`），但四模型**不检验这句**。旁证 `[E]`：`𝔐₂/m` 在 SU(2) 是 `1.667`、SU(3) 是 `1.250` ⇒ 不是固定倍数，但仍然只是"第二个谱数"。

### `𝔐₃` = 转移算符的 Hilbert–Schmidt 衰减率（对照，故意做错）
```
𝔐₃ := −lim_{t→∞} (1/t) log‖T̃^t‖_HS
```
| 自由场 | 2D YM | M6 | 单 plaquette |
|---|---|---|---|
| `0`（`C_HS~t^{-3/2}`：`t=10/100/1000` 给 `0.345/0.069/0.010`）`[T]/[C]` | `2×3g²/8 = 0.75`（`t=5/10/20/40` 给 `0.472/0.611/0.681/0.715 → 0.75`）`[T]/[C]` | `→0`：`L=10/40/160` 给 `0.395/0.0247/0.00154` `[C]` | 无定义 |

4/4 通过。**死因**：`‖T̃^t‖_HS` 的指数率**恒等于** `2λ_bot`（自伴、正）⇒ `𝔐₃ ≡ 2m`，纯换名 `[T]` ⇒ 按纪律淘汰。它的价值是**反证**：任何"单一算子范数的指数率"都只能给 `2λ_bot`。

## 4 · 判：`(b)` 成立（两条独立证明），`(a)` 不成立，`(c)` 逐条

### B05-1（测试不足性：四模型只钉两个 bit）`[T]`
四行能给的信息只有：(i) **transfer 是否存在**（plaquette：无）；(ii) **隙是否为 0**（自由场/M6：0；2D YM：>0）。于是任何 4/4 通过者的**签名型** `pat = (0, +, 0, undef)` 必与 `pat(m)` 相同 —— 脚本 `[6]` 核实四个候选（含 `m` 自身）**全部 COLLISION**。而且四行**不钉数值**：`0.375 / 0.625 / 0.75` 都被判 PASS。⇒ **通过集 ⊆ `m` 的单调重标集，"不是换名"这条要求不可能被四模型测试检验。** 这不是候选不够好，是**判据的信息量只有 2 bit**。

### B05-2（载体-inf 强制：想通过就必须算 `λ₁`）`[T]`
两步。

1. **M6 强制"对 `a`-扇区失明"**：载体 `O=a` 时关联底部是 `ω>0`，而该行要求 `0`；唯一给 0 的载体是耦合到平坦因子 `b` 的（`U05 #1`：`O=e^{2πib/L}` 的速率 `→0`）。⇒ 通过者必须**对载体取 inf**。
2. **2D YM 里没有局部载体携带 `3g²/8`**：物理载体 `trF²=H` 守恒 ⇒ 关联是接触项，`f₁²≡0`（`FOSP-B §B7`）⇒ `inf_O`（局部载体）要么退化（`0`/无值），要么 `∞`，**都给不出 `0.375`**。⇒ 要在 2D YM 上非零，只能对**扇区**取 sup/inf（带电扇区），而 `inf_O (μ_O 的底) = λ₁(μ_vac) = m`（`U05 #4/#5`）。

⇒ **任何通过者的"最小"结构都是 `λ₁`。** 顺带得到更强的单关联不可行：自由场自身有**接触载体**（`O=□φ`，`C≡0`、`m=0`），2D YM 的 `trF²` 也 `C≡0`、但 `m=3g²/8>0` ⇒ **任何 `Φ(C)` 给这两者同一个数** ⇒ 不可能同时满足 `0` 与 `>0`。**"单点/单尺度"不必假设，整条 `C(t)` 也不行。** `[T]`

### (c) 三个候选的死因（一句话各一条）
- `𝔐₃`：`≡2λ_bot`，**恒等式即换名**。`[T]`
- `𝔐₂`：相对论靶上 `=m`（两粒子阈），四模型的 0 来自"底是聚点"= `λ_bot=0` 的另一种写法。`[NG]`
- `𝔐₁`：2D YM 上 `σ≡m` 逐位相同，四模型无法把它与换名分开；非重名要靠**第 5 行**，而第 5 行不在试金石里。`[NG]`（就"仅四模型"这一判据而言）

### 反向诚实：`𝔐₁` 是唯一有**结构**理由的
它取的是**另一个扇区的 min**，不是真空扇区的；4D 里 `√σ/m₀⁺⁺ ≈ 0.28`（`√σ=484.956 MeV` 见 `TIE-SIGMA §1` `[E]`；`m₀⁺⁺≈1.7 GeV` `[M]`，本轮未复核）⇒ 不是常数倍；强耦合下 `σ>0` 是**定理**（Osterwalder–Seiler / 本项目 P3 机制）。但它**不是隙的判据**，是"带电扇区有隙"的判据。
