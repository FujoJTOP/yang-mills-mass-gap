## §1 加权增长率：`μ(类,σ) = σ·μ(类)` 对不对

### 1.1 先核"权重是否真的只依赖 `|C|`"——逐字核三处

**(a) `GF2-STIFFNESS.md:113–128`（§2.1，逐字）**
```
S(U) = Σ_{p ∈ 全格} β(1 − (1/N) Re tr U_p) ,   每个 s_p 只依赖 U_p 自己
⇒ 对任何"支撑在 C 上"的组态：cost(C) = Σ_{p∈C} s_p
⇒ 对任何两个 |C| 相同的簇：min cost 相同（= |C| · s_min），与是否悬垂、是否有气泡无关
```
**(b) `ge2_defdim_witness.py:46–47`（逐字）**
```
def cost_of(chain, E, N):
    return sum(cu(E[p], N) for p in chain)
```
（`cu(exp,N) = 1 − cos(2π·exp/N)`，`:31–32`；`E` 是每片的整数 holonomy。）
**(c) `gf2_stiffness.py:12,331–360,566`**：tilt sum 一律写成 `Z_n(κ) = Σ_C e^{−κ f(C)}`，`f` = 周长/反角——即 **`f` 是"外挂"的边界量**，Wilson 本身不产生它（`GF2:140–147` 的四条候选逐条判死，`:142` 的 L-tromino 反例：`n=3, curv=1, cost=3σ` ⇒ 要让 `cost ≥ σ|C|+κ·curv` 成立必须 `κ≤0`）。

⇒ **判**：`cost(C) = Σ_{p∈C}s_p` 形状盲是 `[T]`。**但"权重 = `y^{|C|}`"是另外一步，带两条 rider**（§1.5）。

### 1.2 正确的加权增长恒等式

设 `y := e^{−σ}`（每片的 Boltzmann 因子，`σ = β(1−cos2π/N)`，`GE2-DEFDIM.md:177–189`）。

```
(1.1)  cost(C) = Σ_{p∈C} s_p ≥ σ|C|                              [T]  （逐片可加 + 最小扭转率）
(1.2)  c₁ y^{|C|} ≤ |w(C)| ≤ c₂ y^{|C|}                           [C]  （H2 非退化形式，GC2-H23 的 R=c₂/c₁）
(1.3)  Σ_{C:|C|=n} y^{|C|} x^{|C|} = (y x)^n A_n^{(𝒞)}
(1.4)  μ_weighted(𝒞) = lim (Σ_{|C|=n}|w(C)|)^{1/n} = y · μ_class(𝒞)   [T]
```
**(1.4) 的证明是换元**：`Σ_n A_n (yx)^n = G_𝒞(yx)`，`G_𝒞` 的收敛半径 `x_c` ⇒ `yx_c` ⇒ `μ_weighted = 1/(y x_c) = y·μ_class`。∎
**所以任务书写的 `μ_weighted = σ·μ_class` 应为 `μ_weighted = e^{−σ}·μ_class`。** 差别不是记法：`σ=5.00` 时前者给 `13.09`（>e，"不过"）、后者给 `0.01764`（≤e，"过"）。**符号相反**（`log` P4）。

### 1.3 阈值不是 `e`：`e` / `1/3` / `1` 三个数必须分开

`BianchiLemma.md:109–111` 逐字：`z(1) ≤ 1/(e^{c₀−0.5−γ_ent}−1)`；要 `z(1) ≤ 1/2` ⇒ `c₀ ≥ 0.5+γ_ent+ln3`（`:116` 表行 `γ=1 → 2.60`）。

```
记 L := Σ_{n≥1} r^n ,  r = e^{γ_class + κ − σ} = e^{κ}·μ_weighted ,  κ=0.5
L = 1/(1/r − 1) ≤ 1/2  ⟺  r ≤ 1/3                          [T]
⇒ 判据是   r ≤ 1/3   ，不是  μ_weighted ≤ e
⇒ 等价写法  σ ≥ κ + ln(1+2PR) + γ_class   （P=R=1 ⇒ κ+ln3 = 1.598612）
```
三个数各是什么：
| 数 | 是什么 | 出处 |
|---|---|---|
| `2.598612` | `0.5 + 1 + ln3`，**`γ_ent=1` 时的需求** | `BianchiLemma.md:111,116`；`GD2-WSTAR.md:265` |
| `e = 2.718282` | 判据里"`μ ≤ e`"的那个 `e`，**只在 σ=2.598612 处与上式同义** | `GD2-WSTAR.md:265` |
| `1/3` | 几何级数余量 `z(1)≤1/2` 对应的 `r` 阈值（**σ-无关**） | `BianchiLemma.md:109–111` |

⇒ **"μ_eff 到底是 μ_class 还是 σ·μ_class" 的答案：两个都不是。** 正确的是 `r = e^{κ−σ}μ_class`（含代价）与阈值 `1/3`；`μ_class ≤ e` 是它在 `σ = 2.598612` 的切片（`log` P7 逐值打印）。

### 1.5 形状盲的三条 rider（不写就会误用）

1. **指数层 vs 前因子层**：形状盲说的是**指数率**只依赖 `|C|`；前因子 `c₂`（群维数/测度/共享 link 数 `ℓ(C)=2|C|+p(C)/2`，`GF2:143`）**可以带形状依赖**，但它只进闸门常数 `ln(1+2PR)`（`GC2-H23.md:349` 逐字："`AS` 的门常数 = `ln(1+2PR)`，`ln3` 只是 `(1,1)` 切片"）——**有界、不承重**。`[T]`+`[M]`
2. **"cost 形状盲"不等于"代价无用"**：它恰恰意味着代价侧**只剩一个数** `σ_min`，而这个数**在闸门里承重**（③）。所以 GF2 的 ③（`GF2:29–30`「类与类之间 `μ_eff` 的全部差异都是熵」）只对**类间差异**成立，对**过/不过**不成立。
3. **自由场酸测**（`GF2:283`）：`β=0 ⇒ σ=0 ⇒ y=1 ⇒ μ_weighted = μ_class`，判据退化为纯组合判据 ⇒ 与 YM 动力学**零关联**。本路的判据 ③ 同样对 `β` 只通过 `σ` 依赖 ⇒ **能进闸门的仍是常数（γ）与一个动力学数（σ_min），不是隙**。`Clay = 0%`。

## §3 反主张判定（任务 §3：`μ_eff = μ_class` 还是 `σ·μ_class`）

### 3.1 逐条判

| # | 反主张的分句 | 判 | 理由 / 数 |
|---|---|---|---|
| R1 | 「Wilson 的 cost 形状盲（`cost = σ|C|`）」 | **`[T]` 成立** | `GF2:118–121`、`ge2_defdim_witness.py:46–47` 逐字；但见 §1.5 三条 rider |

### 3.2 `μ_eff` 的三种候选定义，逐一判决

```
定义 A  μ_eff := y·μ_class = e^{−σ}μ_class（真·加权增长率）
        性质: [T]，但判据必须是 r = e^{κ}μ_eff ≤ 1/3；若拿它跟 e 比 ⇒ σ≥2.4576 时 9/9 全过 ⇒ **判据恒真、无内容**
        判:   作为"μ_eff ≤ e"的宾语 ⇒ **判据被杀**（形状盲把它变成恒等式）

定义 B  μ_eff := μ_class（σ 被吸收进 2.598612）
        性质: 只是 σ=2.598612 的切片；依赖 γ_ent=1（已作废）
        判:   作为判据 ⇒ **口径错**（[M]），但作为纯组合事实 ⇒ 成立且与 σ 无关 [T]

定义 C  μ_eff := e^{ln3+κ−σ}μ_class = 3r（把 1/3 阈值归一成 1）
        性质: [T]；"≤ 1" ⟺ 真判据；σ=2.598612 时 C = μ_class/e，故 C ≤ 1 ⟺ μ_class ≤ e（与 B 只差常数 1/e）
        判:   **这是唯一自洽的定义**；仓内写作 "μ_eff ≤ e" 时隐含的就是它 + σ 冻结
```

⇒ **回答任务 §3 的原问**：`μ_eff` 既不是 `μ_class` 也不是 `σ·μ_class`；它是 `e^{κ−σ}μ_class`（定义 A），判据阈值 `1/3`。
语料的 `μ ≤ e` **确实已经含了 σ**——以"把 σ 冻结在 `0.5+1+ln3`"的方式含的。**所以不是"μ 的定义错"，而是"σ 被当成了常数，而那个常数是 γ_ent=1 的窗"。**

### 3.3 那么 GF3 的 `[T]` 还剩什么

- **仍然 `[T]`**：`μ(𝒟)=φ²`、`μ(𝒮₁)=2.831177207208`、`μ(𝒟)<μ(𝒮₁)<e`、以及"排序与 σ 无关"（本文件 `log` P3/P4 独立复核到 `4e−14`）。
- **降为 `[M]`**：`GF3-ENTROPY.md:38` 的"买下 `μ ≤ e` 的是有向性，一个 bit 之差值 8.1%"——8.1% 是 **μ 的比**，落到判据上是 **Δσ = 0.0783（3.06%）**；且只在 `σ∈(2.561,2.639)` 内有判别力，而仓内 5 个候选 σ 无一在此。
- **降为 `[M]`（连带）**：`GE2-DEFDIM.md:233` 的 `[NG]`「`d=2 ⇒ μ_eff ≤ e`」是 **σ-条件的**：平面类（`μ=2.927–4.063`）只需 `σ ≥ 2.673–3.000`，而 `SU(2)/SU(3)` 的扭转率 `5.00/3.75` **都满足** ⇒ 该 `[NG]` 只在 `σ=2.5986` 口径下成立。**注意这条与 `GD2-WSTAR.md:184–187` 自己的算术同源（那里已经写"SU(2) 5.00 > 4.23 过"），不是本文件新引入的。**
- **不变 `[O]`**：`𝒟 ⊆` YM 缺陷类；现在它等价于"σ_min 落在窗口内"，仍是动力学，仍无证书（`GD2:86,295` 的 0 命中）。

### 3.4 §3 判词（一句话）

> **形状盲没有杀死 `μ ≤ e` 这个数学事实，也没有杀死"哪一类更大"这个排序；它杀死的是"这个 bit 是判据的承重内容"这个叙述。**
> 因为一旦代价形状盲，代价就只剩一个数 `σ_min`，闸门变成 `σ_min ≥ 1.598612 + γ_class`——**判决由 `σ_min` 与 `γ_class` 的对数差决定，bit 只是把 `γ_class` 从 `0.962424` 抬到 `1.040693`，即把对 `σ_min` 的要求抬 3.06%。** 在仓内所有自洽的 `σ` 读数（0.543 / 1.000 / 3.423 / 3.750 / 5.000）上，这 3.06% 都不改变任何判决。
