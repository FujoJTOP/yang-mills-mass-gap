## 0. 判死线（先读这段）

**`G''(a) ≥ 0` 不是结构性真命题：它在唯一含非平凡方差项的模型（单 plaquette）上以一段**有界窗口**失败，而且失败点 `β_cv = 1.87329` **早于**已知的 `G''(0)` 变号点 `β* = 4.30661`。但它也不是"只在 `a=0` 一点"：凸区是一段**以真空为锚**的区间，`a=0` 只是恰好落在窗口边界内侧 0.71（`β=2.5`）。**

- **(a) 只在"Haar 承载"的模型上成立，而且正是 H1A 自己点出的盲点**：P4 与 2D YM 都满足 `Var=E[H]=0`，全部余量来自 `W_geo`（`H1A §2.5/§2.2`）。它们的全局凸性**不经过任何相互作用项**，因此在自由场酸测意义上**没有内容**。唯一 `Var≠0` 的模型（单 plaquette，`N=2` 与 `N=3` 都是）**不是**全区间凸。⇒ **"[C] 全局 log-凹活口"这个读法不成立**；成立的是第四条（§5）。
- **(b) 也不是"只在 `a=0`"**：凸区不是一点，是**以真空为锚的一段**。`θ=π` 时该模型真空在 `a=−π`（`H1A §2.3` 逐字），而 `G''(−π)` **随 β 单调上升**：`+0.39371 (β=0) → +2.18539 (β=8)`，**从不变号**。失败窗口在真空的**远侧**（`+a` 半轴），深度 `O(β²)`。

## 1. 定义与三条精确算法（逐项可核）

### 1.1 对象（逐字取 `GPP-STRUCT.md §1.2`，不重定义）

```
ρ_v(a) := ∫ e^{−V(X)} δ(⟨v,X⟩ − a) dX ,   V = S_W + Φ ,  Φ = −log J ,  G(a) := −log ρ_v(a)
G''(a) = −∂²_a log ρ_v(a) = E[H_vv+Φ''|a] − Var(G_v+Φ'|a)          （eq:split，[T]）
```
本文件只算 `G''(a)` 这条**函数**；`H1A-EXACT.md` 的 `δ_max = G''(0)` 是它在 `a=0` 的一个值。

### 1.2 `N=2` 单 plaquette：**精确降为 1 维求积**（`[T]` + `[C]`）

模型与 `H1A §2.1` / `na_plaquette.py` 逐字同（`S=β(1−cos(r/2)cos(θ/2)+sin(r/2)sin(θ/2)u)`，`J=(sin(r/2)/(r/2))²`，`dU=J d³ξ`，`v=e₃`）。关键化简：整条积分**只经 `r=√(s²+a²)` 与 `u=a/r` 依赖切片半径 `s`**，方位角 `φ` 精确掉出 ⇒

```
ρ_v(a) = 2π ∫_0^{√(4π²−a²)} s ds · e^{−S(r,u)} J(r)          （4000 点 Gauss–Legendre，谱精度）
G''(a) = −[5 点差分 of log ρ],  h = 0.02
```
**校验（`o02_plaquette.log:10–18`）**：`G''(0) = +0.205115 / +0.135995 / −0.193019 / +0.729924 / +1.590639`，对存档 `0.20511530 / +0.135995 / −0.193019 / +0.729924 / +1.590639`，**逐位差 ≤3.9e−7**；`β=0` 质量求和规则 `∫ρ da = 157.913670 = 16π²`（相对差 `3.2e−13`）；`β* = 4.30657`（存档 `4.30661`）。差分步 `h=0.01/0.02/0.04` 给**同 6 位**（`o02_plaquette.log`，`a=0,0.43,0.78,1.86,2.97,3.62`，`β=2.5,6` 全测）。

### 1.3 `N=3` 单 plaquette：**用 U(2) 对称性精确降为 3 维求积**（本文件的唯一新机器）

`H1A` 只做到 `N=2`；`BETASTAR-N.md` 的 `N=3` 用中心元 + 7 维切片 Monte Carlo，**只能给 `a=0`**。整条曲线需要 `a≠0`，所以这里选**唯一能精确降维的 Cartan 方向**：

```
v = T₈ = diag(1,1,−2)/√12  (Tr v² = 1/2)，B = exp(iπT₈)   ← SU(2) 的 θ=π 提升（真空在 a=−π）
S = β(1 − ReTr(U B)/3),  U = e^{iH},  J = ∏_{i<j}[sin(Δλ_ij/2)/(Δλ_ij/2)]²  （de Wit–'t Hooft，与 BETASTAR 同式）
```
`v` 在 `SU(3)` 里的稳定子群是 `U(2)`，7 维切片按 `(A,w) ∈ R³×C⁴` 分解（`H=[[A₁₁+t,A₁₂,w₁],[A₂₁,A₂₂+t,w₂],[w̄₁,w̄₂,−2t]]`，`t=a/√3`，`tr(vH)=√3t`），三个不变量 `(r=|a|, q=|w|², μ=cos∠)` 把积分**精确**压成 3 维：

```
∫_{R³×C⁴} f dA d⁴w = 2π³ ∫ r² dr ∫ q dq ∫_{−1}^{1} dμ f ,   ρ_v(a) = 2π³ ∫∫∫ e^{−S} J · 1[|Δλ|≤2π]
```
**校验（`o02_plaquette.log:5–8`）**：取 `f=e^{−k Tr H²}`（`Tr H² = 2r²+2q+6t²`），降维求积 vs 有限域闭式（`erf` 型）相对差 **`1.2e−14` / `1.3e−14`**（`k=0.3/1.0`）⇒ 常数 `2π³` 与测度分解**不是猜的**。节点 `48×48×32 / 64×64×40 / 88×88×56` 给 `G''(0)=+1.18434/+1.18374/+1.18357`（`±5e−4`）；`a=±π` 处差异 `≈1.5%`（陡区，已标注）。`h_FD=0.2`（噪声/截断折中，`|t|≤1.75` 内避开图表边界 `|t|≲2.09`）。

**必须同时记的限定**：`T₈` 方向是**唯一**能做此降维的方向；`BETASTAR-N`/`H1A` 的 `N=3` 用 `v=T₃`（残对称只有 `U(1)²`，5 维）与中心元（`S` 是类函数），**两者与本节是不同模型**，数值不可互引。且 `B=exp(iπT₈)` 把真空放在 `t=−1.814`，离图表边界 `|t|≈2.09` 只差 13%，所以 `G''(−π)=35.6…38.1` 这个**大数里含边界贡献**，可靠的结论只在**内部窗口**（`a≈0.4~0.9`）与 `G''(0)`。

### 1.4 P4 周期核与 2D YM

- **P4**：`Z(k)=Tr[M_k^L]`，`M_k(z,z')=√(ρ₁ρ₁')e^{−ik(z+z')/(2√L)}e^{−β(1−cos((z'−z)/2))}`，`ρ₁(z)=π(Cin2π−Cin|z|)`；`ρ_v(a)=(1/2π)∫Z(k)e^{ika}dk`，`G''=−∂²_a log ρ_v`（5 点差分 `h=0.02`）。**`M_k = D M_0 D` 是复对称但非 Hermitian**（`D^{1/2}M_0D^{1/2}` 只是相似、也不 Hermitian）⇒ 必须用一般特征值。**校验**：`Z(k)` 对 `β=0` 闭式 `(∫ρ₁e^{−ikz/√L})^L` 逐位吻合（`o02_p4_2dym.log:8`），`G''(0)=0.21146 (L=4) / 0.21649 (L=8)` 对存档 `0.2115 / 0.2165`（`:11–12`），差分步 `h=0.01…0.1` 给同 5 位（`:43–46`）。

## 5. (a)/(b)/(c) 判决与对 H1、`[C]` 的后果

### (a) 全区间凸（"结构性 log-凹"）——**只在无相互作用的两模型上成立，故 `[C]` 活口不成立**

- P4：`a∈[−4,4]` 全正、无翻转（`β=2.5`，`L=4,8` 一致）。
- 2D YM：全正 **iff** `t ≥ 1.3439`；`t→∞` 的极限是纯 `2/sin²φ`（Weyl/Jacobian）。
- 但两者都满足 **`Var = E[H] = 0`**（`H1A §2.5/§2.2` 已记）：`G''` 全部由 `W_geo`（`Φ''`，Haar）承载，**与 `S_W` 的一阶项无关**。这正是 `H1A` 自己标为「ceiling 不是 atom」的盲点（`β=0` 时 `G''=0.2688` 而 `f₁²=0`）。⇒ 它们的全局凸性**过不了自由场酸测**（或更准确：它们对相互作用项**不敏感**），所以**不能**支撑"log-凹是结构性的、`[C]` 有活口"这个读法。

### (b) "只在 `a=0` 一点"——**也不是**：凸区是**以真空为锚的区间**，但确实**不是全轴**

- `N=2, β=6, θ=π`：凸区 `= (−2π, −0.26) ∪ (4.07, 2π)`，真空 `−π` 在内部，`|−π−(−0.26)| = 2.88`。
- `N=3, β=6`：凸区 `= [图表]∖[0.377,0.874]`，真空 `−π` 远离窗口。
