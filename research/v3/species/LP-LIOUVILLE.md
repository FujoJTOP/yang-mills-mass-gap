## §1 新对象（定义）

### 1.1 正规形（T1 的硬结论，纯数学，与 YM 无关）

设 `p>0, w>0` a.e.，`q ∈ L¹_loc`，区间 `(a,b)`。定义

```
   φ(x) := √(p(x)w(x)) ,      t(x) := ∫_a^x √(w/p) ,      T := t(b) = ∫_a^b √(w/p) ,      v(t) := (p w)^{1/4} u(x(t)) .
```

则 `−(p u')' + q u = λ w u` 在 `(a,b)` 上 **⟺** `−v'' + Q v = λ v` 在 `(0,T)` 上，其中

```
   Q(t) = q(x(t))/w(x(t)) + ½ (φ''/φ) − ¼ (φ'/φ)²          ( ' = d/dt )          (LP-1)
```

Dirichlet `u(a)=u(b)=0 ⟺ v(0)=v(T)=0`；Neumann（自然 BC）同理；`periodic` 在 `(0,T)` 上周期化。
**证明**：链式法则三行。`p u_x = √(pw) u_t`，除以 `w` 得 `−u_tt − (φ_t/φ)u_t + (q/w)u = λu`；取 `u = φ^{−1/2}v` 消去一阶项即得。∎ `[T]`

**（唯一一处代数陷阱，本文自己踩过并修正）**：Perron 因子的指数是 `−1/4`（`v = φ^{1/2}u = (pw)^{1/4}u`），
**不是** `−1/8`；写成 `(pw)^{1/4}` 当 `φ` 会留下伪一阶项 `−v_t/2`。`lp_framework.py` 的 A4/A5 是对这条的定点检查
（先用错版本得 `Q=−x²/16−¼` 与 `Q=−(5/16)e^{−2t}`，与直接代入差 2% ⇒ 抓到）。

### 1.2 内蕴 `s` 的定义（DT 缺的第一样，现在有了）

```
   s 的内蕴定义 := Liouville 坐标 t .      T_intr := t(b) − t(a) = ∫_a^b √(w/p) .         (LP-s)
```

三条性质，逐条对上 DT 的三条要求：

1. **只依赖系数**（不依赖谱）⇒ 不循环。判死线 (a) 的答案。
2. **坐标不变 `[T]`**：在重参数化 `x → y` 下按密度变换 `p̃ = p/x′、w̃ = w x′`，有 `T̃ = T`、`Q̃ = Q`。
   数值（A6）：`x`-卡 `T=0.6931471806`，`y = log(1+x)`-卡 `T=0.6931471806`，`|ΔT| = 1.1e−16`；
   谱 `20.7922875 / 20.7922874`（`|Δ| = 8.3e−8`）。⇒ `T` 是**算符的泛函，不是坐标卡的**。
   这就是 `𝒜/𝒢` 上"无全局序"（T3-C 的 no-go）不挡路的原因：**`s` 是算符自己的坐标，不是组态空间的序。**
3. **正规形里 `Q` 也一起不变**，所以 `(T,Q)` 是一对坐标不变量——DT 要的"比较算子"就是 `−d²/dt² + Q`。

### LP-2（Prüfer 地板，BC 词典明确）`[T]+[std]`

> 在 LP-1 的转换下，`λ_n ≥ n²π²/T² + ess inf Q`（Dirichlet，`n≥1`）；

> 周期 BC 则 `λ₁ ≥ 4π²/T² + ess inf Q`。`Q ≡ const` 时全部取等。

统一写法 `λ ≥ κ²/T² + ess inf Q`，`κ = π`（Dirichlet / Neumann 首阶）、`2π`（周期）、`0`（Neumann 的常数模）。
证明：SL 本征值对势的单调性 + 常系数精确塔；等价地 Prüfer 相位 `θ' = cos²θ + (λ−Q)sin²θ`，零点计数给 `n`。∎

### LP-6（普适性 no-go：任何 SL 比较界都不是原子证书）`[NG]`

> 设 `𝔅` 是任一"对所有 `(p,w,q)` 成立的 SL 不等式"`λ₁ ≥ F[p,w,q]`。则 `F` 在**自由无质量场**的 SL 数据上
> 也给出同一个数，因此 `𝔅` 不能在自由场上失效，也就**不可能**是原子证书。
> 唯一的"沉默"机制只有两条：`T = ∞`（内蕴坐标非紧）或 `ess inf Q = −∞`。

这不是哲学：它是 T3(i) 的精确形式，且给出**唯一的补丁**——把 Jacobian 放到正确的位置。
数值（C1，`lp_anchor.log`）：

```
 (a) Φ = −log J 放进 w（测度）:  q = Hess V = k²I , q_min = 0 , T = L
     L=1/10/100:  界 = 9.8696 / 0.0987 / 0.000987   →  0        ✔ 沉默

### LP-7（二阶 SL 表示的不可得性 —— 本节最刺的一条）`[NG]+[V]`

> 在 1D 锚点上：`Δ(β=0) = ∞`（数值 `35.1–35.6`；`β=0` 的核**秩 1**，各链节独立），`Δ(2.5) = 0.6444`。
> 而任何二阶 SL 算符 `−(pu′)′+qu`（`w=1`、区间长 `4π`、`p ≤ ½max σ² = 25.8`）满足
> `λ₁ ≤ π²·25.8/16π² + sup q`；取 `q=0` 得 `λ₁ ≤ 1.612 ≪ 35`。
> **⇒ 不存在"精确的"二阶 SL 表示来重现常模的隙**：它在 `β=0` 就存在且发散，**由测度零阶产生**，
> 不是二阶微分算符的效应。Liouville 只能作用于一个**近似**，而该近似把 `β=2.5` 的隙低估
> `0.6444/0.05504 = 11.7` 倍。

只是被换成了"存在性"：**要么**造出精确的 SL 表示（1D 已否），**要么**退回 DT 的直接比较不等式。
