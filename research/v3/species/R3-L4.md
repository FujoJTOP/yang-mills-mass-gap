## §2 T1 · 解析：逐点量、`sup` 量、谱量 —— 三个**不同**的对象

约定：`S_W = β Σ_p (1 − ½ Re tr U_p)`，`λ_a = iσ_a/2`，`tr(T_aT_b)=δ_{ab}/2`，群上**左不变**梯度 `∇_a = d/dt|_{0} S_W(U e^{tλ_a})`（与 `mc_lattice.py` 的 `U → U e^{tλ_a}` 同约定）。

### §2.1 逐 plaquette（精确，`[N]`+[R]）

由 P-D：`Re tr(λ_a W) = −n_a(W) sin(θ_W/2)`，`W = cos(θ/2)+i sin(θ/2)n·σ`。对一条 plaquette 的任一 link，
```
∂_a S_p = ∓(β/2)·Re tr(λ_a U_p)   ⇒   Σ_{a=1}^{3} (∂_a S_p)² = (β²/4) sin²(θ_p/2) ≤ β²/4 .
```
数值核对：`β=2.5` 时上界 `β²/4 = 1.5625`；逐 plaquette 达到最大当且仅当 `θ_p = π`（`U_p = iσ₃` 型，**非中心元**）。

### §2.2 逐 link（逐点，`L⁰`）—— **这就是 (b) 说的那个 `O(β²L⁰)`**

一条 link 落在 `2(4−1) = 6` 个 plaquette 里（`ν ≠ μ`，两个朝向）。三角不等式：
```
|∇_ℓ S_W|²  ≤  (6 · β/2)²  =  9β²        （β=2.5：56.25，与 L、β 之外的任何量无关）
```
**这是逐点上界**：对每个 `φ`、每条 link 成立，`L`-无关。

### §2.3 全局（`sup` over `φ` 的那一侧，`L⁴`）

```
|∇S_W(φ)|² = Σ_{ℓ} |∇_ℓS_W(φ)|²  ≤  9β² · #links = 36 β² L⁴ = 6 β² N_p .
```
⇒ **`sup_φ` 与"求和"在同一行里，`L⁴` 由 `#links = 4L⁴` 产生，与 `sup` 无关**。这是 (b) 的正解：`L⁴` = 维数，不是极值。

### §2.4 三个对象必须分开（本任务的核心区分）

| 对象 | 记号 | 标度 | 数值（`β=2.5`） | 谁需要它 |
|---|---|---|---|---|
| **逐点**（每 link 密度） | `\sup_φ |∇_ℓS_W|²` | `O(β²L⁰)` | `≤ 9β² = 56.25`；TI 最优 `5.04β² = 31.48` | 无（中间量） |
| **向量/迹范数** | `\|∇S_W\|² = Σ_ℓ\|∇_ℓ\|² = tr(∇S⊗∇S)` | `Θ(β² L⁴) = Θ(β² V)` | 构造构型 `9β²L⁴`；TI `≥ 1.26×10²L⁴` | **不用于 BD**（这是 `HS` 范数） |

**`‖·‖₂` 与 `‖·‖_op` 差 `V` 倍**——这就是 `L⁴` 的全部来源。

### §2.5 `Hess V_t` 的正确下界（P-B + P-C）

```
Hess V_t = E_{μ_t}[Hess S_W] − Cov_{μ_t}(∇S_W)
 ⇒ λ_min(Hess V_t) ⩾ − sup_φ‖Hess S_W‖_op − λ_max Cov_{μ_t}(∇S_W)
   ︸ 第一项：Gershgorin，带宽有限（每行 ≤ 18 个邻 link），= O(β)L⁰
   ︸ 第二项：一个 V 维协方差的最大本征值，= O(β²)L⁰（§3.4 实测）
```
而语料 §5.3 用的是 `−[sup|Hess S_W| + sup_φ|∇S_W|²]`，第二项把 `λ_max Cov` 换成 `tr Cov`
（因为 `λ_max ≤ tr`）：**合法的界，但丢 `V` 倍**。`AUDIT-BBD` §5 的恒等式本来就把负部写成了协方差，语料却把它当标量用。
