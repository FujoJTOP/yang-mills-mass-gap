## §2 · `det(1−K)` 的零点与原子的关系（答任务 2 的核心 —— 用户给的等价式**不成立**）

### §2.1 三区分析 `[T]`

对 `z ∈ (0,∞)`（实、正、`z≠z_n`）：

| 区 | `det(1−zT_O)` | 与原子(`f₁²>0`)的关系 | Grönwall 可用性 |
|---|---|---|---|
| **Ⅰ** `0 < z < 1` | `∏_n(1−zλ_n) > 0`，**对一切反射正性格点理论恒真** | **零信息**：自由无质量场、`β=0` 纯 Haar、YM 全都 `>0` | 可用，但结论是恒等式 ⇒ 纯绕远路 |
| **Ⅱ** `1 < z < z₁(β)` | `> 0` | 需要**先知道** `m₁(β) > (1/a)log z` 才能进这一区 | 入口费 = 质量下界；出口是“仍是正” ⇒ 不产出留数 |
| **Ⅲ** `z ≥ z₁(β)` | 在 `z₁` 变号，`log D_O` 有**对数分支点** | 零点位置 = 质量 | ODE 不可写（`log` 不解析） |

- **区 Ⅰ 的判别力 = 0**：`λ_n ∈ (0,1] ⇒ 1 − zλ_n > 0`，与 `O`、与 `β`、与是否成原子**全无关**。
- **区 Ⅱ 的入场费就是目标**：`z` 要落在 `z₁(β)` 左侧，必须已知 `m₁(β) > (1/a)log z`；而 `d04` 的靶是 `m₁(2.5)>0`（即 `z→1⁺` 时的极限）。⇒ 想取“`z` 贴着 `1`”只能取 `z ↓ 1`，此时**同时**要求 `m₁(β)>0 ∀β`（见 §3.3）。
- **区 Ⅲ 不可用**：`log` 的分支点就是零点本身。

### §2.2 命题 2.2（类型引理 —— 本文件的核心）`[T]`

> **(i)** `log D_O` 及其所有 `β`-导数只读到 `{z_n(β)}` 与 `Tr T_O^k`；**不含任何 `f_n²`**。
> **(ii)** 由 Hadamard 拆分 `N_O(z) = Σ_n f_n²∏_{m≠n}(1 − z/z_m)`，在 `z = z₁` 处**所有 `n≥2` 项精确消失**（其乘积含因子 `(1 − z₁/z₁) = 0`），故
> ```
> N_O(z₁) = f₁² ∏_{m≠1}(1 − z₁/z_m) = − z₁ D_O′(z₁) · f₁²                       (2.1)
> ```
> 即 (1.3) 是**恒等式**（不是估计）；但因此
> ```
> ∂_β log N_O(z₁) = ∂_β log f₁² + Σ_{m≠1} ∂_β log(1 − z₁/z_m)                  (2.2)
> ```
> ⇒ **`∂_β log f₁²` 是 `∂_β log N_O(z₁)` 的一个加项。** “把 Grönwall 移到不含 `F` 的量上”若选 `log D_O`，则它**根本不到 `f₁²`**；若为了到 `f₁²` 而写 `log N_O`，则 `1/F` **原样回来**。
> **(iii)** 因此 P2 缺的那一步是：`det ≠ 0`（位置）⟹ `f₁² > 0`（留数）。语料已判这一步不成立：`SYNTHESIS-NEWCONSTRUCTS:6` 逐字“the determinant sees the mass continuously, **not a lower bound on the residue**; zero-below-cut ⇏ residue bounded below”；`SIXTH-SPECIES-SYNTHESIS:68` 把 Fredholm 零逐字记为“`= m₁` 改名 + 提取 `= I2`”。

### §2.3 酸测：`det>0` **不**等价于原子存在（一个精确反例）`[T]`

- **自由无质量**：`ν` 纯 a.c.、`f₁² ≡ 0`；`D_O` 在 `|z|<1` 无零点（`INVENT-NEW-IDENTITY:16` 逐字“cut, no pole below it ⇒ residue 0”）。⇒ 区 Ⅰ 上 `det>0` 而**原子不存在**。
- **有质量自由标量 + `O=:φ²:`（更狠）**：`PROOF-TRANSPORT-ANALYTIC:11` 逐字——“Massive free scalar: **gapped** transfer matrix; the lightest `0⁺⁺` is simple and isolated. ## §3 · `log det` 的 `β`-导数与 `‖(1−K)^{-1}‖`（答任务 3）

### §3.1 命题 3.1（预解式范数的精确等式）`[T]`

> `K = zT_O` 自伴（Hadamard 读法下本征值 `zλ_n`）⇒
> ```
> ‖(1−K)^{-1}‖ = 1/min_n |1 − zλ_n| = 1/(1 − z/z₁)  ,     0 < z < z₁          (3.1)
> ```
> 一般（非自伴）只留 `≥`：`‖(1−K)^{-1}‖ ≥ 1/dist(1, spec K)`。两种读法下界相同。

**⇒ 对“`‖(1−K)^{-1}‖` 有界吗？”的回答：有界 ⟺ `z` 与零点集分离。** 它**不是**某个可改进的估计，**它就是 `1/`距离**。代入 `z = e^{am_*}`：

```
‖(1−K)^{-1}‖ = 1/(1 − e^{−a(m₁ − m_*)})  ≈  1/(a(m₁ − m_*))      (a(m₁−m_*) ≪ 1)     (3.2)
```
`m_* → 1`（即 `z → 1`，去真空后的最低测试能级 `m_* → 0`）⇒ `‖(1−K)^{-1}‖ ≈ 1/(am₁)`。**若 `m₁ ≈ Δ`，这就是 `d04` 的 `1/Δ`，一字不差。**

**⇒ 用户问的“若它 `≈ 1/Δ`，那又回到 `1/Δ`”——是的，而且不是“≈”，是等式 `(3.1)`。**

### §3.2 命题 3.2（`β`-导数：确实无 `1/F`，代价是 `1/dist`）`[T]`

```
∂_β log D_O(z) = −tr[(1 − zT_O)^{-1} ∂_β(zT_O)] = a Σ_n zλ_n⟨S_W⟩_n/(1 − zλ_n) ,  ⟨S_W⟩_n := ⟨n|S_W|n⟩   (3.3)
⇒ |∂_β log D_O| ≤ a·12V· Σ_n zλ_n/(1 − zλ_n) ≤ a·12V·Tr T_O/(1 − z/z₁) ,         Tr T_O = Z_{S¹×T³}   (3.4)
```
（`12V = 6V` 个 plaquette `× s_p≤2`，同 `d04 (1.4)` 的 `A_V`；`1 − zλ_n ≥ 1 − zλ₁ = 1 − z/z₁`。）

**⇒ 命题 3.2 的两句话**：(i) `(3.3)` **确实不含 `F`**（`d04` 的“无 `1/F`”成立）；(ii) 它含 `1/(1 − z/z₁)`，即 `1/Δ` **换了一件衣服**；并且多出一个 `Tr T_O = Z_{S¹×T³}`（粗界下 extensive，见 §1.3-2）。

### §3.3 Grönwall 常数：与 `d04` 同一个式子 `[T]`+`[E]`

`d04 (1.4)`：`C_d04 ≥ A_V/Δ = 12L⁴‖O†Ω‖‖𝔾‖/Δ`。本文件 `(3.4)`（取 `z=1`，`1 − e^{−am₁} ≈ am₁`）：

C_logdet ≈ 12L⁴ · Tr T_O / m₁          ⇒   C_logdet / C_d04 = Tr T_O · Δ/m₁ = Tr T_O = Z_{S¹×T³} = O(1)   (3.5)

（`0⁺⁺` 道里 `m₁ = Δ`。）**⇒ 同一个 `L⁴`、同一个 `1/Δ`，只差一个有限的乘性因子。**
