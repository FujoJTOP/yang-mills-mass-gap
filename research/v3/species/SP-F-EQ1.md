# SP-F 环代数：**第一条方程**（只写这一条，不做整个物种）

**日期**：2026-11-25。**方法纠正**：先写方程、做替换与标度、给判决；不先造框架。

---

## §1 方程（Makeenko–Migdal，大 `N` 极限，`ℝ⁴`）

设 `W(C) = ⟨(1/N) tr P exp ∮_C A⟩`。闭环方程：

```
∂/∂x_μ  ( δW(C)/δσ_μν(x) )  =  g²N ∮_C dy_ν δ⁴(x−y) W(C_xy) W(C_yx)          (★)
```

右边只在 `x ∈ C` 时非零；`C_xy`、`C_yx` 是 `x` 处把圈切开得到的两段。

**这条方程是精确的**（大 `N`、`ℝ⁴`、无源），不是近似。它是**代数约束**：任何"合法"的 `W(C)` 必须满足它。

---

## §2 替换：圆环的标度扇区

取半径为 `R` 的圆 `C_R`，设 `W(C_R) = f(R)`（即只依赖标度）。

**左边**：圆环上唯一起作用的形变是"呼吸"模。逐项量纲：
- `δ/δσ_μν` 是**对面元**的变分 ⇒ 量纲 `L^{−2}`；
- `∂_μ` 又是 `L^{−1}`；
- 两者作用在 `f(R)` 上都等价于 `d²/dR²`（相差常数与 `1/R` 项）。

⇒ **`LHS ≃ c₁ f″(R)`**

**右边**：`x ∈ C`，故 `∮ dy_ν δ⁴(x−y)` 的量纲是 `L · L^{−4} = L^{−3}`；`W·W = f²`；`g²N` 无量纲。

⇒ **`RHS ≃ c₂ g²N f²(R) / R³`**

**于是第一条方程化为一维：**

```
c₁ f″(R)  =  c₂ g²N f(R)² / R³            (★₁)
```

这就是**这个物种的第一条方程**。`c₁, c₂` 是与圈几何有关的纯数（圆的呼吸模），不影响下面的标度结论。

---

## §3 代入幂律解 `f(R) = R^{−p}`

```
f″ ∝ p(p+1) R^{−p−2}
LHS   ~  R^{−p−2}
RHS   ~  R^{−2p−3}
```

令指数相等：

```
−p − 2 = −2p − 3   ⟹   p = −1
```

**⇒ `(★₁)` 的幂律解只有一个指数 `p = −1`，即 `f ~ R^{+1}`。**

**这被物理上界排除**：由反射正性 / 定义，`|W(C)| ≤ 1`，所以 `f ~ R` 不可能。

---

## §4 判决

> **`(★₁)` 在衰减幂律类 `f = R^{−p}`（`p ≥ 0`）中无解。**
> **⇒ 环方程禁止幂律衰减。**

这是一条**排除性结论**（`[C]`，条件于圆扇区与领头大 `N`）：**代数不允许"质量为零"的软解**。

**但它不给指数衰减。** "禁止幂律" ≠ "强制指数"：介于两者之间还有 `e^{−(log R)^α}`、`R^{−p}·(log R)^{q}` 等无穷多类。**所以这条方程目前只排除了一类，不是隙。**

---

## §5 下一步（同一条方程，继续走，不换物种）

在 `(★₁)` 上继续做三件事，每件都只用这一条方程：

1. **代入对数修正解** `f = R^{−p}(log R)^{q}`：若也被排除，排除类扩大。
2. **代入面积律** `f = e^{−σR²}`：核它**是否**是 `(★₁)` 的解（面积律应当满足闭环方程——若不满足，说明圆的呼吸扇区不够，是 `c₁,c₂` 的账错）。
3. **把 `(★₁)` 当 ODE 解出来**：`c₁ f″ = c₂ g²N f²/R³` 是一阶自治型（令 `f = R^{−1}u(log R)`），**给通解**，看是否存在**有界非指数**的解。若有 ⇒ 环代数不强制隙（判 `[NG]`）；若通解全部指数 ⇒ **那是隙**。

---

## §6 必须标明的不确定性

| 项 | 状态 |
|---|---|
| `(★)` 本身 | `[T]`（Makeenko–Migdal 已发表，大 `N`） |
| 圆的呼吸模把 `δ/δσ` 化为 `d²/dR²` | `[C]` — **常数 `c₁,c₂` 未算**；`1/R` 项被略 |
| 指数相等 `p = −1` | `[T]`（纯标度） |
| `p=−1` 被 `\|W\|≤1` 排除 | `[T]` |
| **"禁止幂律衰减"** | **`[C]`** — 仅圆扇区、领头大 `N` |
| "禁止幂律 ⟹ 有隙" | **不成立**（不是逻辑蕴含） |

## §7 这条方程**还没有**回答的

它没有回答 `N=3`（大 `N` 结果），没有回答格点（`(★)` 是连续 `ℝ⁴`），也没有回答 `1/N` 修正的量级。**这三条是它作为"物种"的全部代价，写在这里，不许含糊。**
