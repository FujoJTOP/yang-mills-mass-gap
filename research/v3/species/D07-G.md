## §2 · 任务 2：`A(β)` 的真界 —— `D04 (1.4)` 把**均值**算了进去，锐化后是 `√V` 而不是 `V` `[T]`

### §2.1 恒等式：`n≥1` 杀掉 `S_W` 的均值

`(1.3)` 的求和是 `n≥1`，而 `S_W|𝔾⟩ = ⟨S_W⟩|𝔾⟩ + (1−P₀)S_W|𝔾⟩`，第一项**整块投影掉**。于是

```
   Σ_{n≥1} |⟨n|S_W|𝔾⟩|² = ‖(1−P₀)S_W𝔾‖² = Var(S_W) = −∂_β⟨S_W⟩ ≤ 6V·…        (2.1)
```
（`Var(S_W)=−∂_β⟨S_W⟩ ≤ 0` 的符号见 `D05-FKG:58` 的勘误，逐字：`∂_β⟨S_W⟩=−Var(S_W)<0`。）由 Cauchy–Schwarz（对其余一侧用 `Σ_{n≥1}|⟨Ω|O|n⟩|²=Var_O(Ω)`）：

```
   |F'| ≤ A/Δ ,    A² = Var_O(Ω_β)·Var(S_W,β)        （锐化；替代 D04 (1.4) 的 12V‖O†Ω‖‖𝔾‖）
```
**`D04 (1.4)` 的 `12V‖O†Ω‖‖𝔾‖` 用的是 `‖S_W𝔾‖ ≳ ⟨S_W⟩ ~ V`，即把被投影掉的均值算成了分子 ⇒ 比真值大 `V^{1/2}`（甚至 `V`）。**

### §2.2 `Var(S_W)` 的 β-质量是**精确**的：`∫Var = #plaq·Δ⟨s_p⟩`

微积分基本定理 + (2.1)：
```
   ∫_{β₁}^{2.5} Var(S_W) dβ = 6V·[⟨s_p⟩(β₁) − ⟨s_p⟩(2.5)] = 6V·[u_p(2.5) − u_p(β₁)]     (2.2)
```
（`s_p=1−u_p`，`#plaquette=6V`。）SU(2) 在 `β₁→0` 时 `u_p→0`，故 `∫Var dβ = 6V·u_p(2.5)`。
**精确锚**（`[E]`，`d07_g.py` 求积，`1e−14` 容差）：`u_p(2.5)=0.507195100`（与语料 `v06_radius.log:43` 的 `0.507195` 逐位命中）；`Var(s)(2.5)=0.134119010`、`Var(s)(0)=0.250000000`（`=1/4` Haar，Peter–Weyl）；`∫₀^{2.5}Var(s)dβ = 0.507195100`，与 `u_p(2.5)−u_p(0)` 残差 `1.1e−16` ⇒ **恒等式 (2.2) 的机制被数值复核。**
⇒ `∫₀^{2.5}Var(S_W)dβ = 6·0.5072·V = 3.043V`。

### §2.3 结论：`A` 的 `L¹`-质量按 `√V` 增长（**不可绕过**）

`√·` 凹 ⇒ Jensen：`∫√Var dβ ≥ √(T·∫Var dβ)`，`T=2.5`：
```
   ∫_{β₁}^{2.5}√Var(S_W) dβ ≥ √(2.5·3.043V) = 2.758·V^{1/2}          (2.3)
   ⇒ ∫ A dβ ≥ 2.758·V^{1/2}·√Var_O(Ω)                                  (2.4)

## §5 · 机制：`f₁²(2.5)>0` 自己就造出那个 `√V`

`n=1` 项（`F'` 中唯一含靶本身的项）分子是 `|⟨Ω|O|1⟩|·|⟨1|S_W|𝔾⟩|`。而

```
   |⟨1|S_W|𝔾⟩| = √(φ·Var S_W) ,   φ = 最低 p=0 态在 S_W 谱权中的份额 ∈ (0,1]      (5.1)
```

⇒ **`n=1` 项本身是 `√V/Δ` 量级。** 任何**保留 `n=1` 项分离**的 Cauchy–Schwarz 界都 ≥ `√V/Δ`，**无论 `Δ` 多大**。
⇒ `(G)` 若要成立，必须有 **`n≥2` 对 `n=1` 的 `√V` 级相消**（即一条 sum rule）。语料**没有**这种相消机制（`D04 §3.4` 已把"更聪明的界"标 `[C]`）。
⇒ **`(G)` 的欠账不是 `Δ` 的技术性，是一条 sum rule。** 这是本文件对 `(G)` 失败原因的定位：不是"积分技巧不够"，而是**分子里的 `√V` 是靶自己产生的**。
