# Q02-BL-PHI — Brascamp–Lieb with `Hess Φ ⪰ (N/12)I`: 能不能把凸性变成 `Var` 的界？

> 日期 2026-11-25 · 任务：用 p16 的 `Hess Φ ⪰ (N/6)tr² ⪰ (N/12)I`（`Φ=−log J`）推一条**严格**方差界，并与
> 实测 `Var(G_v)=5.45`、`Var(Φ′)=3.6e−3` 比，判它够不够。
> **判词（一句话）**：**不够，而且是前提级的不够。** `N/12` 是**纯 Haar（β=0）** 的常数；Wilson 测度
> `e^{−S_W}dHaar` 的指数是 `V=S_W+Φ`，`Hess V` 在 β=2.5 **不定**（Savvidy），BL 假设逐条不成立 ⇒ **(c)**；
> 即便硬套，`(12/N)E|∇G_v|² ≥ 240.5`（≥38×`E[H_vv]`）⇒ **(a) 假、(b) 真**。故 `Var(G_v) ≤ E[H_vv]`
> **没有** BL 证明，`[T]` 只在 β=0 成立（那里 `G_v≡0`，空洞）。H1 在 `Cov≈0` 下**仍未证**。

标签：`[T]` 定理/精确 · `[C]` 条件定理 · `[E]` 数值/测量 · `[NG]` no-go。

## 1 · Brascamp–Lieb 标准式与出处

**式（BL 方差引理）** `[T-standard]`。设 `dμ = e^{−V}dX`（`X` 为某开集上的坐标，`dX` Lebesgue），`V ∈ C²`，
`Hess V ⪰ λ I`（λ>0，逐点）。则对 `f∈H¹(μ)`：

```
Var_μ(f)  ≤  E_μ[ ⟨∇f , (Hess V)^{−1} ∇f⟩ ]  ≤  (1/λ) E_μ|∇f|² .                        (BL)
```

**出处**：H. J. Brascamp, E. H. Lieb, *On extensions of the Brunn–Minkowski and Prékopa–Leindler
theorems, including inequalities for log concave functions, and with an application to the diffusion
equation*, **J. Funct. Anal. 22 (1976) 366–389**，DOI `10.1016/0022-1236(76)90004-5`
（卷 22、期 4、页 366–389 已核；**具体定理编号未逐字核**——只核到卷期页与"方差引理"这一条，
本条属标准结果，项目内亦按此用：`research/v3/H6-HEAD-SPECTRAL.md` §H6-B 引
`λ₁(ν) ≥ 1/E_ν[1/V_eff″]`）。派生读法：Bakry–Émery `Γ₂` 判据（1985）与 Ledoux《Concentration of
Measure》同一条；1-D 情形两次分部积分即可。

**前提（逐条核）**：

| # | 前提 | 本项目状态 |
|---|---|---|
| P1 | `V ∈ C²`，`dX` 为**平坦坐标** | 平图 `X_ℓ∈Lie`，`U_ℓ=exp(X_ℓ)`，`dHaar = e^{−Φ}dX`，`Φ=−log J` `[T]` |
| P2 | `Hess V ⪰ λI` **逐点**（不是平均） | **不成立**，见 §5(c) |
| P3 | `f∈H¹(μ)`，`∫f dμ` 有限 | `G_v, Φ′` 光滑、紧流形，`[T]` |
| P4 | 测度是 `e^{−V}dX` 而非流形上的 `e^{−V}dHaar` | **关键**：本题写成 `dμ=e^{−Φ}dHaar`，但 `e^{−Φ}dHaar = dX`（**平坦 Lebesgue**，`V≡0`），`Hess V=0` ⇒ (BL) 不适用；若按 `dHaar = e^{−Φ}dX` 读，则 `V=Φ`，λ 才有 `N/12` |

> **P4 是本题的陷阱**：`Φ=−log J` 与 `dHaar=e^{−Φ}dX` 是同一句话的两面。
> "`Hess Φ ⪰ (N/12)I`"**恰好是**"Haar 在平图里比 Lebesgue 更凸"的度量，而不是"物理测度更凸"。
> 所以 `N/12` 只能喂给 **β=0 的 Haar 测度**。物理测度 `dμ_β = e^{−S_W}dHaar = e^{−(S_W+Φ)}dX`
> 的指数是 `V=S_W+Φ`。**这是后面 (c) 的全部内容。**

## 2 · 取 `f = G_v` 与 `f = Φ′`：`∇f` 是什么（运算级）

**记号**（与 `research/v3/G1-BLOCK-IDENTITY.md` §1、`w7/p02_dyndyn.py` 一致）：`S_W` Wilson 作用，
`Φ = −log J` Haar 对数 Jacobian，平图坐标 `X`，单位向量 `v`，

```
G_v  := ∂_v S_W = ⟨v, ∇S_W⟩ ,        H_vv := ⟨v, Hess S_W · v⟩ ,
Φ′   := ∂_v Φ  = ⟨v, ∇Φ⟩ ,           Φ″   := ⟨v, Hess Φ  · v⟩ .
```

**推导（逐行，只用链式法则）**：

```
G_v(X) = Σ_ℓ ⟨v_ℓ , ∇_{X_ℓ} S_W(X)⟩
⇒ ∇G_v(X) = Σ_ℓ Hess_{X_ℓ} S_W(X) · v_ℓ  =  Hess S_W(X) · v        (全空间切向量)      [T]
⇒ |∇G_v|² = ⟨Hess S_W v , Hess S_W v⟩ = vᵀ (Hess S_W)² v
⇒ |∇G_v|² ≥ (vᵀ Hess S_W v)² = H_vv²           (Cauchy–Schwarz, ‖v‖=1, Hess 自伴)      [T]
```

同理

```
∇Φ′ = Hess Φ · v ,    |∇Φ′|² = vᵀ (Hess Φ)² v ,                                      [T]
```

于是 (BL) 给出两条可用式（**前提是 `Hess V ⪰ λI`**）：

```
Var_μ(G_v) ≤ E_μ⟨Hess S_W v , (Hess V)^{−1} Hess S_W v⟩ ≤ (1/λ) E_μ vᵀ(Hess S_W)² v      (B1)
Var_μ(Φ′)  ≤ E_μ⟨Hess Φ v , (Hess V)^{−1} Hess Φ v⟩     ≤ (1/λ) E_μ vᵀ(Hess Φ)² v         (B2)
```

`(1/λ)=12/N`（N=2 时 = 6）。**注意 (B1) 的右端不是 `E[H_vv]`**：`E|∇G_v|² ≥ E[H_vv²] ≥ (E H_vv)²`，
所以 BL 天然给的是**二阶矩**尺度，不是一阶矩。这就是 (a) 必然失败的算术根源。

## 4 · 判（逐字写清）

### (a) `(12/N)E|∇G_v|² ≤ E[H_vv]` ？——**不成立（假）**

```
(12/N)E|∇G_v|² ≥ 240.5  >  E[H_vv] = 6.3315      (≥ 38.0×)                       [T]+[E]
```

所以**不能**由此得到 `Var(G_v) ≤ E[H_vv]`。即使把 BL 右端换成"最乐观"的 `E[H_vv²]` 也救不了：
`H_vv` 本身的涨落（Savvidy 负区/正区混合）让二阶矩远大于一阶矩的平方。
**"差一个 Cov" 的说法在这里不适用**：`E[H_vv]−Var(G_v)=Δ_dyn=+0.88`（17.7σ，`p02_dyndyn.log:25–26`）
是**测量事实**，不是 BL 推论；BL 给的方向（240 ≫ 6.33）与"仅差 Cov"差 38 倍，不是小量。

### (b) 界太松？——**是，且松 1–3 个数量级；需要的 λ**

```
G_v :  要 (1/λ)E|∇G_v|² ≲ E[H_vv]  ⇒  λ ≳ E|∇G_v|²/E[H_vv] ≥ (E H_vv)²/E[H_vv] = E[H_vv] ≈ 6.33
       而 N/12 = 0.1667  ⇒ 短 38.0×      [T]+[E]
Φ′  :  λ ≳ 0.19/3.6e−3 ≈ 53…77（以条件方差为分母）⇒ 短 3×10²–5×10²×
```

**结论**：`BL 在 N/12 这个常数下太弱**（不是"差一点"，是差一个量级以上的 λ）。要用 BL 证 H1，需要
`Hess V ⪰ λI` 且 `λ ≳ 6.3`，即 `λ` 要比 `N/12` 大 **~38×**；而 `Φ` 能提供的上限就是 `N/12`
（p16 [3]：`min eig(Hess Φ)=1/6` 精确取到，锐），**`Φ` 已经用满了**。

### (c) BL 前提不满足？——**是，这是决定性的**

1. `Hess Φ ⪰ (N/12)I` 本身 **`[T]` 成立且锐**（`w7/p16_phiquant.log` [3]，N=2…6 比值 =1.000000；
   本次复算 `inf Φ″_trans = inf Φ″_rad = 1/6`，见 `q02_bl_phi.log` [0]）。**但这不是 BL 要的 `V`。**
2. BL 要的是 `Hess V ⪰ λI`，`V = S_W + Φ`（Wilson 测度的指数）。β=2.5 时 `Hess S_W` **Savvidy 不定**：
   逐点 `min H_vv = −1.893`（`p16_phiquant.log` [7]，`o06` [4]），全 Hessian `min ≈ −2.8 / −2.7`
   （`research/cpb-attack/11-slc-blocked/MARGINAL.md`：L=4 全精细 Hessian min≈−2.7，100% 构型有负模；
   `research/v3/ABC3-DIFFERENT-DUALITY.md`：SU2 β=2.5 min≈−2.8）。**`Hess V ⪰ (N/12)I` 为假。**
3. 唯一让 `V=Φ` 成立的测度是 **β=0 的纯 Haar**；那里 `S_W≡0` ⇒ `G_v≡0`、`H_vv≡0`、`Var(G_v)=0`。
   **BL 给出 `0 ≤ 0`，空洞。** 对 β>0 它没有传递性：`Hess Φ` 的 `N/12` 不能吸收 `Hess S_W` 的负模
   （`W_geo≥N/12` 只是一个**平均**漂移，不是逐点 Hessian 下界；见 `PROOF-JACOBIAN-SAVES`）。
4. 因此 **`Var(G_v) ≤ E[H_vv]` 没有 `[T]` 证明**；H1 在 `Cov≈0` 下**仍未证**。
   BL 路线在 `λ=N/12` 上 **no-go**：`Φ` 的凸性预算（1/6）对 `S_W` 的负模预算（`−1.89` 逐点、`−2.8` 全谱）
   差 **11–17 倍**，且方向无关的 `λ` 无法只对"好方向"生效（BL 要求全方向）。

## 5 · 一句话账

| 条目 | 状态 |
|---|---|
| `Hess Φ ⪰ (N/12)I`，锐，方向/`a₀` 无关 | `[T]`（p16 [3]；本次复算一致） |
| BL 方差引理（`V` 凸 + λ>0） | `[T-standard]`（Brascamp–Lieb 1976，DOI 10.1016/0022-1236(76)90004-5，定理号未逐字核） |
| `∇G_v = Hess S_W·v`，`∇Φ′ = Hess Φ·v` | `[T]`（链式法则） |
| `Hess(S_W+Φ) ⪰ (N/12)I` @β=2.5 | **假**（Savvidy；`[T]`+`[E]`） |
| `(12/N)E|∇G_v|² ≤ E[H_vv]` | **假**（≥240.5 vs 6.33，≥38×） |
| `Var(G_v) ≤ E[H_vv]`（H1@Cov≈0 的入口） | **`[NG]` 由本路线**；BL 在 λ=N/12 上不够 |
| 需要的 λ | `≳6.3`（38× `N/12`），而 `Φ` 的预算恰为 `N/12` ⇒ 用满仍缺 |

**结论**：这条凸性**不能**变成 β=2.5 的 `Var` 界。要它有用，必须换测度（把 `S_W` 的负模吸收进 λ）
或换不等式（不只依赖 `ess inf Hess`，例如利用 Savvidy 负模的**方向局域性**——但那已不是 BL）。
