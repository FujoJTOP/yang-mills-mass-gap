### §2.4 `sup` 候选为什么**恰好**与 `L` 无关（恒等式，非拟合）
`L=2` 的一次单 link 上升找到的构型是**周期 2** 的；周期 2 构型可以**精确提升**到任何偶 `L`：`U_L(x) = U_2(x mod 2)` 使每个 plaquette 与 `L=2` 完全相同，故 `|∇S_W|²_L = (E_L/E_2)·|∇S_W|²_2`，**密度逐位不变**。实测：`d = 21.575346` 在 `L = 2,4,6,8` 全部相同（`S5` 的 LIFT TEST）。

**⇒ 只要近最优构型是周期的，`d` 的指数就恒为 0。** 结合 D1 的严格界，**`d` 的有界性是定理、不是拟合**。

### §2.5 `sup` 到底多大（`S5`）

## §3 定理 D1：密度严格有界（`L`-一致、`φ`-一致）

> **定理 D1** **[T]**。对任意 `L`、任意 `β`、任意构型 `φ ∈ SU(2)^E`：
> ```
> |∇S_W(φ)|²_δ  ≤  9 β² E  =  6 β² N_p ,      即      d(φ) ≤ 6 β² 。
> ```
> 证明：`g[l,a] = Σ_{p ∋ l} s_{p,l,a}`，`s_{p,l,a} = −(β/2)·sg·tr(λ_a X_{p,l})`，一条 link 至多落在 **6** 个 plaquette 里。
> (i) 逐 plaquette：由 `Σ_a tr(λ_aX)tr(λ_bX)` 的完备性关系（`su(2)`，`tr(λ_aλ_b) = −δ_ab/2`），
> ```
> Σ_a s²_{p,l,a} = (β²/4) sin²(ψ_p) ≤ β²/4 ,     tr X_p = 2 cos ψ_p 。
> ```
> (ii) 对 6 个 plaquette 用 Cauchy–Schwarz：`|g_l|² ≤ 6 Σ_{p∋l} Σ_a s² ≤ 6·6·β²/4 = 9β²`。
> (iii) 对 `E = 4L⁴` 条 link 求和：`|∇S_W|² ≤ 9β²·E = 36β²L⁴ = 6β²·N_p`。∎

**数值证书**（`S3b`）：`|∇S_W|² / (6 Σ_p Σ_{k,a} s²) = 0.5000` 在 `L = 2,4,6,8` **全部相同**（`≤1` ✓）。`z2 s=0.5` 处该比值 `= 0.25`（用掉上界的 `1/4`），上升候选处 `= 0.575`。

**三条推论**
1. `sup_φ |∇S_W|²` 存在且 `≤ 6β² N_p`；`d` 有界。**[T]**
2. 上界的**第一个等号是紧的**：`z2(s=0.5)` 的方向-1 link 上 Cauchy–Schwarz **恰好饱和**（§1.3），所以常数 `9β²`（per link）不能靠改进 C–S 降下来。**[N]**
3. `d` 的 `L`-指数为 `0`，**与构型无关**（`d ≤ 6β²` 对一切 `φ`）。**[T]** ⇒ `LOOP-RUNBOOK` R3 的判死线「若 `L⁴` 是估计子伪影 ⇒ BD 路障消失」中，**`L⁴` 部分确为伪影**（是 `N_p`），但「路障消失」尚不能断言（§6）。

**D1 是不是新物种？不是。** 它是 P-D（Cauchy–Schwarz + `su(2)` 恒等式）在一条 link 的 6 个入射 plaquette 上的直接代入。没有任何新结构。

## §4 Hessian 一侧：也不广延（D2、D3）

### §4.1 定理 D2：`‖Hess S_W‖_op` 与 `L` 无关 **[T]**
`Hess S_W` 是 `3E × 3E` 的**带状**矩阵：每个 plaquette 只触及 4 条 link（12 个指标），每条 link 只落在 6 个 plaquette 里 ⇒ 每行至多 `6 × 12 = 72` 个非零元，每个 `O(β)`。故
```
‖Hess S_W‖_op ≤ max_i Σ_j |Hess_ij| = O(β) ，常数与 L 无关。
```
**实测（FD 精确 Hessian，`S6`）**：

| `L` | `λ_min` | `λ_max` | `max_i Σ_j|H_ij|` |
|---|---|---|---|
| 2 | **−9.999998** = `−4β` | +7.499999 = `+3β` | **15.0000** = `6β` |
| 4 | **−9.999998** = `−4β` | +7.499999 = `+3β` | **15.0000** = `6β` |

逐位相同（`L=4` 的 FD Hessian 是 `3072×3072`，`16.8 s`）。**负部不是广延的**（与 `ch13` 行 267 的定性一致，且本报告给出的是**精确 `L`-无关**，比 "intensive" 更强）。

### §4.2 束缚本征矢的提升：`RQ = −10.000000` 在 `L = 2,4,6,8` **[N]**
取 `L=2` 的 `λ_min` 本征矢 `v`（`‖v‖²=1`），按周期 2 提升到 `L = 4,6,8`，用沿该方向的 `S_W` 二阶差分算 Rayleigh 商：
```
L=2: RQ = −10.000000   L=4: RQ = −10.000000   L=6: RQ = −10.000000   L=8: RQ = −10.000000
```
（`L`-无关是**恒等式**：`U` 与 `v` 都周期 2 ⇒ `S_W^{(L)}(t) = (E_L/E_2) S_W^{(2)}(t)`。）**⇒ `λ_min ≤ −10` 在一切偶 `L` 成立；配合 D2 的 `≥ −6β = −15`，得 `λ_min ∈ [−10,−15]` 与 `L` 无关。** **[T]**

### §4.3 定理 D3：`t = ∞` 端点的协方差算子范数有界 **[T]**
由 P-C 恒等式与 `V_∞ = const`（`K_t → 1`，P-D）：
```
Hess V_∞ = 0   ⇒   Cov_ν(∇ S_W) = E_ν[Hess S_W] ,   ν ∝ e^{−S_W} dHaar 。
```
`E_ν[Hess S_W]` 的**每个矩阵元都是 `Hess` 相应矩阵元在 `ν` 下的平均**，故
```
Σ_j |E_ν H_ij| ≤ E_ν[ Σ_j |H_ij| ] ≤ sup_φ max_i Σ_j |H_ij| = 6β  （D2）
⇒  ‖Cov_ν(∇ S_W)‖_op ≤ 6β = 15 ,   与 L 无关。
```
**这是把 `AUDIT-BBD` §4「必须保留的假设 5（`q(t)` 必须是整个构型空间的上确界，不是有限样本估计）」在 `t = ∞` 处真正落实的一步，且不需要任何相关性衰减假设。** **[T]**

### §4.4 顺带的两条勘误
- **[E1]** 语料把束缚模描述成「**均匀铺在方向-1 links 上的模式**」（`MC-METRIC` §3.2(3)）。**错**：那种模式在中心元构型上 `RQ ≡ 0`（`L = 2,4,6,8` 全部 `+0.0000`）——因为一条方向-1 link 在一个 plaquette 里出现两次、承同一个右乘子，而 `U_1 = ±1` 与一切交换。真实的本征矢：方向-1 links 上质量 `0.75`，**`gen 1` 分量恰为 `0`**，`gen 2` 主导，且**只有 2 个不同取值**（`±`）⇒ 是**变号（staggering）模**，不是均匀模。
- **[E2]** `ch13` 行 267 说 `λ_min/β` 在 `L=2,4` 是 `−0.588 / −0.771`（`1.31×` 漂移）。在 δ-框架全 link 空间上，本报告测得 **严格 `−4β` 两者相同**（§4.1）。两个数的差别来自是否商掉规范（`−0.588` 是商空间值）；**若论文用"intensive"做论据，应用 `−4β`（严格 `L`-无关）更稳妥**。`[J]`

λ̇_t  ≤  N/8 + inf_φ λ_min Hess_g V_t(φ) .                       (5.1)
```
`inf` 取在构型 `φ` 上：这是 `(★)` 在**每一个** `φ` 都要成立、故被**最坏点**卡住。

**位置 2（`sup`）——进入 `Q(∞)`。** `ch13` 行 247–250（同 `AUDIT-BBD` §4、`R1-BRIDGE` §4.2(6)）：
```
q(t) := sup_φ ‖(Hess_g V_t(φ))_−‖_op ,   λ̇_t = N/8 − q(t) ,
λ_t = Nt/8 − Q(t) ,  Q(t) = ∫_0^t q ,   γ ≥ (N/4) e^{−2Q(∞)} .   (5.2)
```

### §5.2 它们是不是同一个对象？——**是，语料没有搞反** **[T]**
对称算子的负部满足 `‖A_−‖_op = max(0, −λ_min(A))`，故
```
sup_φ ‖(Hess V_t(φ))_−‖_op = ( − inf_φ λ_min Hess V_t(φ) )_+  = (N/8 − λ̇_t^{max})_+ ,
```
即 **(5.1) 与 (5.2) 逐字等价**：`q(t) = (N/8 − λ̇_t^{max})_+`。`inf` 与 `sup` **不是两个对象，是同一泛函的两种写法**（正部）。`AUDIT-BBD` §4、`ch13`、`LOOP-RUNBOOK` §8.3、`R1-BRIDGE` §4 四处**用法一致**。

**⇒ 语料没有把一个当成另一个。这一条是干净的，[T]。**

### §5.3 但有一处替换是错的：`sup` 被样本 `max` 顶替，`算子范数` 被`迹`顶替
`MC-METRIC` §5.3 的承重估计是
```
Hess V_t ⪰ −[ sup|Hess S_W| + sup|∇S_W|² ]   ⇒   λ̇_t ⪰ −C L⁴ .      (5.3)
```
两步各有问题：
1. **`sup` 被样本 `max` 顶替。** 需要的是 `sup` 的**上界**；`900 / 14400` 是 8 个样本的 `max`，即 `sup` 的**下界**。方向上不成立。（严格的上界由 D1 提供：`6β²N_p`。）
2. **`sup|∇S_W|²` 本身是 `Cov` 的**迹**上界，不是算子范数上界。** 精确地：`E_μ|∇S_W|² = tr(Cov) ≥ ‖Cov‖_op`。实测（`S8`，Haar 测度，平移平均）：

| `L` | `tr(Cov)` | `tr(Cov)/N_p` | 行和 `Σ_{r,b}|Cov_{(0,a),(r,b)}|`（`‖Cov‖_op` 上界） | `tr/行和` |
|---|---|---|---|---|
| 2 | 442.5 | 4.6093 | **3.5064**（16 个位移类，**完备**） | 126 |
| 4 | 7077.3 | 4.6076 | **4.3105**（81 类，下界） | 1642 |
| 6 | 35286.3 | 4.5379 | **3.4048**（81 类，下界） | 10364 |

**`tr(Cov) ∝ N_p`（密度 4.6 平），而 `‖Cov‖_op` 的 Gershgorin 行和 `O(1)` 且 `L`-无关。** `tr/行和 = 126, 1642, 10364`——**这一列就是"那个 `L⁴`"**（矩阵维数的比值）。

**⇒ 「`L⁴` 是曲率爆炸」是记账错误：它是把算子范数换成迹，损失恰为 `dim = 3E = 12L⁴`。** **[E3]**

### §5.4 结论
> 结论（`λ̇_t ⪰ −Cβ²N_p`）**是对的**，但语料给的**证据符号反了**（样本 `max` 当上界）**且量搞错了**（迹当算子范数）。正确版本由 D1 提供：`λ̇_t ≥ N/8 − 6β − 6β²N_p`。**而恰恰是这个"正确版本"暴露了真正的问题：它仍是 `∝ N_p`，因为右手边是迹。**

## §6 密度界 ⇒ `Q(∞)` 一致：链与唯一缺口

### §6.1 链（每步标注状态）
```
(1) [T]  Hess V_t = E_μ[Hess S_W] − Cov_μ(∇ S_W)                         (P-C，恒等式)
(2) [T]  q(t) ≤ q_H(t) + q_C(t) ,  q_H := sup_φ‖E_μ Hess S_W‖ ,  q_C := sup_φ‖Cov_μ(∇ S_W)‖
(3) [T]  q_H ≤ sup_φ‖Hess S_W‖ ≤ 6β = 15          （D2；实测 L=2,4 完全相同）      ← L-一致
(4) [T]  t = 0 :  μ = δ_x ⇒ Cov = 0 ⇒ q_C(0) = 0                                   ← L-一致
(5) [T]  t = ∞ :  Cov_ν = E_ν[Hess S_W] ⇒ q_C(∞) ≤ 6β = 15                    （D3）← L-一致
(6) [T]  D1 :  d ≡ sup_φ|∇S_W|²/N_p ≤ 6β²                                          ← L-一致
(7) [E]  语料在此处的步子  q_C ≤ E_μ|∇S_W|² = tr(Cov) = d·N_p ≤ 6β²N_p   ← **用迹界算子范数，损失 3E**
(8) [N]  ⇒ λ̇_t ≥ N/8 − 6β − 6β²N_p ；Q(∞) ≤ T*(N/8 + 6β + 6β²N_p)
(9) [N]  ⇒ γ ≥ (N/4)·exp(−2T*(6β + 6β²·6L⁴))  ：**体积退化，指数率 L-一致但仍是 e^{−cβ²L⁴}**
```

### §6.2 唯一缺口

> **`<GAP>` [O]** 设 `μ_{t,x}(dz) ∝ K_t(z) e^{−S_W(xz)} dz`。需要
> ```
> sup_φ  sup_{0 ≤ t < ∞}  ‖Cov_{μ_{t,x}}(∇ S_W)‖_op  ≤  C(β)        (G1)
> 以及           ∫_0^∞  sup_φ ‖Cov_{μ_{t,x}}(∇ S_W)‖_op  dt  ≤  C'(β)   (G2)
> ```
> 二者**与 `L` 无关**。有了 (G1)+(G2)，`Q(∞) ≤ (6β + C(β))·(1 + C'(β))` 与 `L` 无关，`(5.2)` 即给出一致的 `γ`。

**已做掉的部分**：两个端点 **(4)、(5) 已证**（`t=0` 恰为 `0`；`t=∞` 由 D3 给 `≤ 6β`，不需要任何相关性衰减假设），且是 `L`-一致的。**小 `t` 还有一条免费的界**：`μ_{t,x} → δ_x` 时 `Cov = t·Hess S_W·G^{−1}·Hess S_W + O(t²)` ⇒ `q_C(t) ≤ t·(6β)² = O(β²t)`，也是 `L`-一致的 `[J]`。

**没做掉的部分**：`t` 的**中段**（`t ~ 1`）既不是 `δ` 也不是 Gibbs，上面的两个端点估计不能内插（`Cov` 对 `t` 不是凸的，也没有已知的最大原则）。**(G2) 的时间可积性**另需一个 `L`-一致的收敛率。

**为什么"密度界"原则上填不了这个缺口** **[T]**：任何形如 `sup_φ|∇S_W|²` 的量都是 `N_p` 个局部项之和的上确界，由三角不等式必然 `∝ N_p`；`d` 有界只把**系数**定死（`6β²`），**不改变 `∝ N_p`**。要拿到 `O(1)`，唯一出路是**抵消**（`E[Hess]` 与 `Cov` 在 `t=∞` 精确对消）或**算子范数**（`(G1)`），**不是**"把 `sup` 换成平均"：`E_μ|∇S_W|²` 自己也是 `∝ N_p`（Gibbs `5.12 N_p`、Haar `4.6 N_p` 实测）。**⇒ 缺口的坐标从 `sup|∇S_W|²`（体积量，假障碍）搬到 `‖Cov‖_op`（无体积量，真缺口）。**

### §6.3 一条可能仍然把体积带回来的次级路径（诚实标注）**[O]**
`Q(∞)` 的时间可积性最终要用 `Hess V_t = −Hess log B_t`，`B_t = P_t e^{−S_W} → Z`。把相对误差压住需要 `‖B_t − Z‖/Z` 小，而 `Z ≥ e^{−sup S_W} = e^{−2βN_p} = e^{−12βL⁴}`（因 `1 − ½tr P ∈ [0,2]`）。**任何走"相对误差"的论证都会把体积从 `Z` 的下界重新带回来。** 若最终只能走这条路，(G2) 就退化为 `L4/H1` 型障碍。**这是本报告唯一还不能排除的"体积回头路"，必须写在这里。**
