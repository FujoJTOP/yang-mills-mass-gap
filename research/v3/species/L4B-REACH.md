## §1 L1｜耦合界：给的是"**某个 β 上的 `I2`**"，不是任何地板

**骨架（全是 `[T]`，`N11 §1 L1`）**：
```
(I)  I2@δ  ⟺  Π⊥(H−m₀²−δ)Π⊥ − Γ(δ) ≻ 0 ,   Γ = 秩一耦合,
(II) 待补：[C]/[NG]  ‖Π⊥Hφ₁‖² ≤ C(1−f₁²)^θ .
```

1. **`(II)` 真时能得到什么 —— 精确地说是 `I2`，且带定量 `δ`。** `(II)` 唯一的作用是把 `Γ` 压住，使 `(I)` 里的
   `Π⊥(H−m₀²−δ)Π⊥ − Γ` 保持正定 ⇒ **结论的形状是"层距 `δ(β)>0`"，不是"质量地板 `Δ₀`"** `[T]`。[C]
2. **在哪个 `β` 有内容**：`(II)` 的右端靠 `f₁²`。`f₁²>0` 的等级是 `β<0.018394` `[T]`（P3 残数）、`β=2.5` `[E]`（`F06` 测）。
   ⇒ **L1 在 2.5 上是"条件于一个数值事实的条件定理"**：`f₁²>0` 在 2.5 无 `[T]`。`[C]`
3. **2.5 的一道硬闸（本轮新增判）**：`(I)` 是**有限 `L`** 的算子陈述；`(II)` 原文是算子范数界，**未声明 `L`-一致**。
   而"有限 `L` 原子 ⇒ `I2@2.5`"已被 `F01 §7.5` 三重判死 `[X]`。⇒ **L1 必须自己给出 `L`-一致，否则 2.5 上的产出是 `[X]`**；
   `(II)` 的现有写法不提供。`[T]`（对 `(I)` 的量词范围而言）

**⇒ L1 判词**：给的是**"某个 `β` 上的 `I2`（条件于该 `β` 的 `f₁²>0`）"**，`β=2.5` **可及**（不经扩窗）但交付层是 `I2`、且要先补 `L`-一致。
比值地板、`m>0`：**都没有**。

## §4 关键（问题 2）：三线**没有一条**在扩窗上——那它们怎么到 2.5？

**先固定逻辑形状。** "到 `β=2.5`"只有两条可能路径：

```
(P1) 单点：在某一个 β 上直接证 m>0（不经任何 β 搬运）—— 不触 g05 的自我否定；
(P2) 全窗/极限：∀β∈[0.018394,2.5]（或沿 a→0 的尾部）逐点成立，靠 β-一致性 —— 这就是"扩窗"，
     而 g05 已证"常数地板延到 β→∞"自我否定 ⇒ (P2) 只剩"比值地板"这一种合法写法（M05 §3.2）。
```

- **L1 走 (P1)？** 形态上是（`(I)` 是逐 `β` 的算子命题），但交付的是 `I2`，且要 `L`-一致。⇒ **触到 2.5，但不是 `m>0`。**
- **L2 走 (P2)？** 形态上是（`a²Δ₀²` 正是合法写法），但 `f₁²≥c` 只在窗内 `[T]`，而窗内无 `a→0` 子列。⇒ **形在 (P2)，位置在窗内，内容 = 0。**
- **L3 走哪条？** 都不是——它把 (P1)/(P2) 的选择**推迟**给前件。

**⇒ 答**：三线**都不扩窗**；它们**不经扩窗也到不了 2.5 上的 `m>0`**——`L1` 能到 2.5 但只到 `I2` 层（且有限 `L` 版是 `[X]`），`L2` 有对的形但没有窗，`L3` 只是条件句。
**"三线全胜"⇒ 得到的是：`β=2.5` 上的 `I2`（`[C]`，需 `L`-一致 + `f₁²>0@2.5` 升 `[T]`）+ 窗内的比值地板形（`[C]`，贡献 0）+ 一条显式条件定理。三者之和仍 < "`β=2.5` 上 `m>0`"。**

## §5 判死线落判

**(a) 某条线直接给 `β=2.5` 上的 `m>0`（不经扩窗）⇒ 真决战？**
→ **不触发。** 最接近的是 `L1`：它是唯一具备"逐 `β`、不依赖 β 搬运"形态的线，确实可以**在 2.5 这一点上出力**。

**(b) 三线都只在强耦合或有条件 ⇒ 明说"三线都不解决 `β=2.5`"？**
→ **触发，主判。** `L1` = 条件（`(II)`+`f₁²@2.5`+`L`-一致，且只到 `I2`）；`L2` = 强耦合窗（`β<0.018394`，`[T]` 只在那里）；`L3` = 纯条件。
**真正的缺件（唯一承重，与 `M05 §4 ④` 同一件）**：
```
∃Δ₀>0 ∀a<a₀：m_{0⁺⁺}(a) ≥ Δ₀      （= (T4) = H1 的量纲修正版）
且必须带两点配套：(i) L-一致（I1@2.5 的 [O]）；(ii) aΛ 的非微扰钉定（c₀ 与 scheme 常数分离）。
```
三线**没有一条**提供 `Δ₀`；`L1` 提供的是"`δ(β)` 在某 `β` 上 >0"，`L2` 提供的是"`Δ₀(c(β))` 在窗内"，两者的 `a`/`β` 量词范围都不覆盖 `[0.018394,2.5]` 的尾部。`[T]`

**(c) 三线给的是比值地板（`liminf m_lat/(aΛ) ≥ c₀`）⇒ 与 `g05` 新靶一致？**
→ **局部触发。** `L2` 的产出（`G″ ≥ a²Δ₀²`）与 `(T3)` 同形 ⇒ 与 `g05` 新靶**一致**；但四件事必须同时写：
 (i) `Δ₀` 必须与 `a` 无关（L2 只给 `Δ₀(c(β))`）；(ii) `c(β)` 要 `β`-一致正下界；(iii) 窗内对 `liminf` 贡献 `0`；(iv) `m_lat` 的定义必须是 `a·m_{0⁺⁺}(a)`（`M05 §1.1` 已钉；用 `18.26` 即落 A 支自我否定）。
 (i)–(iii) 全未满足 ⇒ **形一致、内容 `[NG]`**。`L1`/`L3` 都**不**给比值地板。
