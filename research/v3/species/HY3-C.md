## §1 精确形

### 1.1 记号（两个陈述分别写清）

```
μ_{a,+}   : a-格时间零片的 Gibbs 测度；H_a := −(1/a)log T_a 于 1^⊥ ⊆ ℋ_a = L²(μ_{a,+})

Cyl       : 柱代数（有限个粗链/固定次数涂抹多项式），在两侧 L² 中同稠密
𝔐（矩极限）: ∀n ∀试验函数 ∀固定实时间隔：S^{(n)}_a → S^{(n)}         （= L3/UVS(L) 的收敛面）

```

## §3 最窄可攻形 `(C-n)`（`[T]`，条件于 `L3`）

```
取嵌套 a_k = a_0·2^{−k}；固定一个规范不变、固定次数的光滑涂抹多项式 φ，令 c_k:=⟨φ⟩_{μ_{a_k,+}}、ψ_k:=φ−c_k（⊥Ω_a）：
 (n1) ∀j≥1：⟨φ, T_{a_k}^{j a_0/a_k}φ⟩_{μ_{a_k,+}} → ⟨φ, e^{−j a_0 H}φ⟩_{μ_+}        （= 𝔐 的一个特例，L3 ⇒ [T]）
 (n2) Δ_cont ∈ supp ν_φ，ν_φ := φ 在 H 下的谱测度（取 φ 与最低激发有非零谱重；2 行密度论证，[T]）
 (n3) M := sup_k ‖φ‖²_{μ_{a_k,+}} < ∞                                                  （= 2-点 a-一致界，L3 的一部分）
 ⇒  limsup_k Δ_{a_k} ≤ Δ_cont  ⇒  Δ_cont ≥ liminf_a Δ_a = (A-abs) 的结论
```

*证（5 行，就地自证，零外部引用）.* 反设沿子列 `Δ_{a_k} ≥ Δ_cont+δ`。`ν_{ψ_k}({0})=0`（`H_a≥0`、`ker=ℝ1`）且 `supp ν_{ψ_k} ⊂ [Δ_cont+δ,∞)` ⇒ `F_k(t):=⟨ψ_k,e^{−tH_a}ψ_k⟩ ≤ e^{−t(Δ_cont+δ)}M`。由 (n1) 与 `ψ_k=φ−c_k`（用 `T1=1`、`c_k=⟨φ⟩`，1-点矩亦收敛）得 `F(t):=⟨φ,e^{−tH}φ⟩−c² = lim_k F_k(t) ≤ e^{−t(Δ_cont+δ)}M`，对 `t=j a_0` 全部成立。由 (n2) 取 `s<Δ_cont` 上正质量：`F(t) ≥ e^{−ts}c`（`c>0`）⇒ `c e^{t(Δ_cont+δ−s)} ≤ M`，`t→∞` 矛盾。∎

**消耗/不消耗**：只用 (n1) 矩 + (n2) 谱论 + `M<∞`；**不用** `ι_a`、强收敛、`(NEW)`、紧性、Minlos、PF（与 `GN3-SPECTRAL.md:109` 的"谁没被用"同表）。

**技术限定**：`φ` 必须是**固定次数的光滑涂抹多项式**，不能是随 `a` 变长的 Wilson 环链（否则 `L3`/`UVS` 的 all-`n` 界不覆盖它）。
