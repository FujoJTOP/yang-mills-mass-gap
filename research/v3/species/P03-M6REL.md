## §3 ★ `(⋆)` 与 `Δ_dyn + W_geo + X` 是不是同一个分解？

**不是。** 三条独立理由（每条都可单独判死"逐项对号"）：

1. **`V` 的口径不同。** `Δ_dyn + W_geo + X` 是**任何**测度 `e^{−V}` 的精确恒等式（本文件 `[4]` 段数值核到 `1.2e−8`：`−∂_a²log Z(a)|₀ = ⟨V_aa|0⟩ − Var(V_a|0)`，非 Gauss、`Var(V_a|0)=0.179 ≠ 0`）。它要求 **`V` = 测度的对数密度**（Gibbs 作用量）。而 `(⋆)` 里的 `V` 是 **Hamiltonian 势**。二者在 M6 上**不是同一个函数**：`ρ_a = |ψ₀|² ⇒ V_eff = −log ρ_a = ωa²`，而模型写下的势是 `V_osc = ½ω²a²`。二者只在 `ω = 2` 相同（`½·4a² = 2a² = ωa²`）；一般 **`V_osc ≠ V_eff`**，且 `H_eff = ∂²V_eff = 2ω` 与 `H_osc = ∂²V_osc = ω²` 是两个不同的数。
   **反例（`[5]` 段，`[T]`+`[E]`）**：`V = a⁴/4` 时 `G″(0) = 1.683382`，而用 Hamiltonian 势算 `E[V″|0] − Var(V′|0) = 0 − 0 = 0`。**差 1.6834。** 故"`E[H|0] − Var(G|0)` 就是 `G″`"这句话**只在 Gibbs 口径下**成立（`U09:106` 逐字"`G″` 不是 `V` 的曲率"是同一件事）。
2. **`Φ″` 与 `W_geo` 不是同一个量。** `(⋆)` 的带权版加的是**逐点** `Φ″(q)`（`U09:68`）；`W_geo` 是 `E[Φ″] − Var(Φ′)`。只有在 `Φ` 只依赖**一个**坐标且该坐标被条件化钉死（`Var(Φ′|0)=0`）时两者才相等 —— 4D YM 里 `Φ` 依赖全部 link，条件化 `ξ=0` 后仍有涨落 ⇒ `W_geo ≠ Φ″`。
3. **`(⋆)` 没有 `X`。** `X = −2Cov(G,Φ′)` 在 `(⋆)` 里根本没有对应项；把 `2(ψ₀′/ψ₀)²` 当 `X` 是把"基态相位"读成"协方差"。

**结论**：`(⋆)` 是 `G″` 的**闭式求值**（在 `ρ=J|ψ₀|²`、单坐标、基态支配下），`Δ_dyn+W_geo+X` 是 `G″` 的**条件化矩分解**（任意测度）。二者**都等于 `G″`** ⇒ 不是两个分解，而是**同一个数的两种语言**；**只要试图把 `(⋆)` 的各项搬去当 `Δ_dyn`/`W_full`，就一定错。**
