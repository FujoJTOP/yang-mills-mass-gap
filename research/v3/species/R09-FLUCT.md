# R09-FLUCT — 判 `β·Var(∂_t h) ≤ E[∂_t² h]`（曲率涨落 vs 曲率均值）

日期 2026-11-25 · 目标由 `q06` 提出 · 模型 = `q04`/`r03`/`r02` 同一单 plaquette SU(2) 精确框架
β=2.5，切片 ξ₃ = a，`u = ρ/2`，`c = cos(θ/2)`，`s = sin(θ/2)`，`g(u) = sin u/(2u) = w(ρ)`

## 0. 定义核准（先定义，后判；这是 (c) 的核心）

| 记号 | 定义 | 出处 |
|---|---|---|
| `h` | **Wilson 作用量密度，β-free**：`h = Σ_P(1 − ½ReTr U_P)`，`V = βh + Φ` | `q06_riccati.py` L6–13 |
| `S_W` | `S_W = β·h`（逐点恒等，本脚本 [0] 数值 `max|βh − S_W| = 0.0e+00`） | q04 L73 |
| `G_v` | `G_v = ∂_a S_W = β·∂_a h` | q04 L90 |
| `H_vv` | `H_vv = ∂_a² S_W = β·∂_a² h` | q04 L96 |
| `t` | **切片方向 `ξ₃ = a`**（Hessian 方向 `v = e₃` 上的位移）——**不是** β，**不是**热时间 | q06 L11–12 + L18 |

**`h` 与 `H_vv`、`S_W` 的关系**（逐条核准，非类比）：

```
S_W   = β h                     (q06 的 affine 分解 V = βH + Φ 在单 plaquette 就是这一条)
G_v   = β ∂_a h                 ⇒  q06 的 g := ∂_t h  = G_v/β       = q06 写的 "F_W/β"  ✓
H_vv  = β ∂_a² h                ⇒  q06 的 h₂ := ∂_t² h = H_vv/β      = q06 写的 "κ_W/β"  ✓
```

即 `q06` 的 `t` **就是** q04 的切片坐标 `a`（`κ = ∂_a²(总作用量) = H + Φ''` ⇒ `h₂ = ∂_a²h` 恰好是 `κ` 的 Wilson 部分）。因此 `h` 与 `H_vv` 不是同一个对象：`h` 是零阶作用量，`H_vv` 是它的二阶切片导数乘 β。

**这一条把目标不等式完全定死：**

```
β·Var(∂_t h) ≤ E[∂_t²h]
  ⟺  β·Var(G_v/β) ≤ E(H_vv/β)
  ⟺  Var(G_v) ≤ E[H_vv]            (β 两侧同乘 β>0，比值逐位相同：本脚本 [2] diff = 0.0e+00)
  ⟺  2β s² Var_ν(g) ≤ c E_ν(g)      (r03 L14–17 的 S、D 骨架；r02 的判据)
ν ∝ e^{−β(1−c cos u)} sin²u/u du,  u ∈ (0,π)
```

⇒ **`q06` 建议的这条不等式，在唯一能精确算它的框架里，逐字就是 `q04`/`r02` 的判据 `Var(G_v) ≤ E[H_vv]`**，不是新工具。`β` 前面的因子正好被 `G_v = β∂_a h`、`H_vv = β∂_a²h` 的两次 β 吸收 —— 若有人把它读成 “β 加权的”新不等式，那是 `[M]`（β 在这里不携带任何新权重）。

**另外两个读法必须排除**（否则会得出假结论）：

1. `t = β`（温度）：`h` β-free ⇒ `∂_β h ≡ 0`，`∂_β²h ≡ 0`，不等式退化成 `0 ≤ 0`，**空洞**（过不了酸测）。
2. `t` = 梯度流时间：`q04`/`r03` 是静态单 plaquette 模型，**无流动力学**，`∂_τ h`、`∂_τ²h` 在该框架下不可定义；`q06` 自己也说 `h` 没存（L19–20）⇒ 该读法只能标 `TOOL-UNAVAIL`，不可判。

## 1. 显式公式（a=0 切片，`u = ρ/2`，`w(ρ) = sin(ρ/2)/ρ = g(u)`）

```
h(ρ,a)     = 1 − c·cos u + s·sin u·(a/ρ)                          (β-free)          [T]
∂_a h      = s·[ (c/2)(a/ρ) sin u + w + (a²/ρ) w′ ]                                 [T]
∂_a² h     = (c/2)[ sin u/ρ + (a²/2ρ²)cos u − (a²/ρ³)sin u ]
             + s[ (3a/ρ)w′ − (a³/ρ³)w′ + (a³/ρ²)w″ ]                                  [T]
a = 0 ⇒    ∂_a h = s·g(u),        ∂_a² h = (c/2)·g(u)                               [T]
```

FD 核对（本脚本 [0]，θ=0.7, η=1.1, d=1e−6）：`∂_a h` 解析 vs FD 差 `9.1e−12`；`∂_a² h` 差 `2.6e−5`（FD 截断）。

**关键结构**：`a=0` 上 `∂_a h` 与 `∂_a² h` 是**同一个随机变量** `g(u)` 乘以常数 `s`、`c/2`。于是 `Var(∂_a h) = s²Var(g)`、`E[∂_a²h] = (c/2)E[g]` —— 不等式两侧只差一个**常数比** `2s²/c`，这是它能化成 1-D 积分的全部原因，也是它在 `c→0` 时必死的全部原因。

## 3. 裁决

**(b) 不成立（有反例点）** — 且失效点不是一个孤立点，而是 `c = 0` 整条边界：

- 精确反例：`θ=π`，`a=0`，任意 `β>0`：`0.027648 ≤ 0` 假。`H_vv ≡ 0` 是**点态恒等式**，不含求积误差 ⇒ `[T]` 级别的否定。
- 更强反例：`θ=π`，`a>0`：`E[H_vv] < 0`，`Var(G_v) > 0`（q04 [7] 原表），双侧符号都错。

**(c) 定义确认** — `q06` 的 `h` 与 `q04` 的 `S_W`、`H_vv` 关系是 `S_W = βh`、`H_vv = β∂_t²h`（非 `h = H_vv`）；`t` 是**切片方向**（`v = e₃` 上的位移），不是时间/温度参数。澄清后不等式才可判，结论即 §2。

**(a) 部分成立（可给，但不是新工具，且带窗口）** — 真正 `[T]` 的是核比对那一步（§4）：

> **[T]** 对一切 `β ≥ 0`、`c ∈ [0,1]`（单 plaquette 单胞 `u∈(0,π)`）：`2Var_ν(g) ≤ E_ν(g)`。
> **[T]** 故 `β·sin²(θ/2) ≤ cos(θ/2)` ⇒ `β·Var(∂_t h) ≤ E[∂_t²h]`（β=2.5 时即 `θ/π ≤ 0.3882`）。
> **[C]** 数值上 θ=π/2 在 β∈[10⁻³, 60] 全程成立（最大比值 0.0405 @ β=2.33），远非临界。

**β-方向 `[T]` 单调性的诚实版本**：窗口内 `D ≤ (βc/2)E[g] < S` ⇒ `G″ = S − D > 0` ⇒ 自由能 `G(β) = −log Z_v(β)` 在 β 上严格凸、`G′` 单调增 `[T]`。但这条**在 θ=π 处断了**（`c=0` ⇒ 判据 RHS=0），而 θ=π 恰是 q11/r03 出了严格区间证书的那一片；那里的 `S > D`（`0.205115 > 0.069121`，`S−D = +0.135995`）靠的是 `E[Φ″] = 0.205115` 这一 β-free 项，不是 `E[H_vv]`。

**这是最有信息量的一句**：`q06` 想用的 “曲率涨落 ≤ 曲率均值” 把 `E[Φ″]` 丢掉了；补上它才回到 H1（已是 `[T]`），而丢掉它就得到一个 `θ=π` 必假的命题。⇒ 该形式**不能**把 `q06` 的里卡提失败转化成 β 方向的新单调性；它只是 H1 的一个**残缺投影**。

## 4. 1-D 积分 + r02 核比对（直接证明，一行代数）

`r02_crit.py` L232–257 的恒等式（此处 `u` 即其 `s` 变量）：

```
E[g] − 2E[g²] = (1/2Z)∫₀^π e^{−β(1−c cos u)} · sin³u · (u − sin u)/u³ du
```

被积核**逐点 ≥ 0**：`e^{−…} > 0`，`sin³u ≥ 0`（u∈(0,π)），`u − sin u ≥ 0`，`u³ > 0`。
⇒ `E[g] ≥ 2E[g²] ≥ 2Var(g)` ⇒ `Var(g) ≤ E[g]/2`，**与 (β,c) 无关** `[T]`。
数值核对 [3]：`Z(E[g]−2E[g²])` 与 `(1/2)∫核` 在 15 组 (β,c) 上逐位相等（如 β=2.5,θ=π：`7.984483e−03` vs `7.984483e−03`），核逐点最小值 `≥ 1.9e−22 > 0`。

代入：`β s² Var(g) ≤ β s² E[g]/2 ≤ (c/2)E[g]` ⟺ `β s² ≤ c`。 ∎

**窗口纪律（AGENTS §2.1）**：本 `[T]` 是**单胞**（`u∈(0,π)`，即 ρ∈(0,2π)）模型的结论，与 q04/r03 同一测度。`r02_crit.py` 的 `β_c` 表用的是多周期 `Λ=22π` 测度，属**不同对象**，其 `β_c(π/2)=4.1063` 不可搬到这里（本模型同 θ 在 β≤60 全程成立）。两处都成立的是核不等式本身。

**自由场酸测（CLAUDE.md §1）**：`β→0` 且 `c=1`（自由/无质量极限）时判据退化为 `0 ≤ (1/2)E[g]`，核 `2Var/E = 0.0619 > 0` **不失效** —— 但它失效的方式是 θ=π，而 θ=π 恰是自由场/平凡场那一片（`H_vv≡0`）。⇒ 该不等式在物理靶点上是**边界紧**的，不构成独立工具。
