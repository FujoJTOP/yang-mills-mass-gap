## 1 · 问题 1：`w` 是什么（逐字）

`f07 §1.4` 逐字（`F07-ADJCBAR.md:82–86`）：

```
|w|^{1/n} = c_f = N·u          （cube/4-壁 tube，n=6,4,8,12 全 2.0000；c05 §1.2 [T]）
|w(S)| ≤ ∏_{p∈S} c_f            （Z06-HOLEA:83 / PROOF 引理 2′）
⇒ 每片权重/u = N ；而 Φ(0)/u = 2N²（含 f,f̄ 两支）
SU(2) 精确核对：⟨(1/N)tr U_p⟩ = 0.0208273 (β=1/12) ≈ c_f = β/(2N) = 0.0208333 ✔（差 0.03%）
```

**`w` 不是"某种权重"的占位，是 `Z_dec` 簇展开的 plaquette 权重**：`w(S)=∏_{p∈S}w_p`，`|w|^{1/n}` 是它的每片几何平均。`f07` 给它的值是 `c_f` = 基本表示**字符系数** `∫dU χ_f e^{(β/N)RetrU} = ⟨tr U_p⟩ = β/(2N)`（`Z06:15,33` 逐字 `[T]`）。

**为什么 `f07` 认为 `= c_f` 而不是 `≤ c_f`**：闭合曲面（cube；4 壁管）上每条 link 关联度 2、定向相反 ⇒ `∏_{link} mult(1∈f⊗f̄)=1`，字符收缩不留额外 `dim f` 因子 ⇒ 每片恰好一个 `c_f`，没有"多重计数"（`F07:64,88`、`P3-CBAR:52` 独立复核同一结论 `[T]`+`[E]`）。

> **这一步是对的，但它证明的是「没有额外的 `dim f` 重数」，不是「每 tile 权重 `= c_f` 而不是 `c_f/N`」。** 后一个问题正是 `Z06` 的洞 A——见 §2、§3。

## 2 · 问题 2：`u := c_f/N` 是定义还是推论

**逐字（`Z06-HOLEA.md:15–16`，`[T]`）**：

| 对象 | 值 | 标签 |
|---|---|---|
| `c_f(β)`（基本表示**字符系数**，`=` 未归一化单片迹期望 `⟨tr U_p⟩`） | `β/(2N)+O(β³)` | `[T]` |
| `u`（**每 tile 的归一化权重**，`=` `⟨(1/N)tr U_p⟩`） | `c_f/N = β/(2N²)+O(β³)` | `[T]` |

`Z06:39–43` 逐字：「**"每片"最终权重是它再乘一个 `1/N = 1/dim f`**……`⟨(1/N)tr U_p⟩ = c_f/N = β/(2N²)`……**这就是"每片带一个 `1/N`"的确切来源**：不是 `SU(N)` 的"每色权重"这种含糊说法，而是**闭合迹归一化 `(1/N)tr` 在每一个 tile 上的 `1/dim f`**。」

`Z06:56–62` 给**三条互相独立的确证**（同一结论：tile 权重 `= c_f/N`）`[T]`：

1. **单片精确**：`⟨W₁₁⟩ ≡ ∫dU (N^{-1}tr U)e^{(β/N)RetrU} = c_f/N`；同时 `⟨tr U_p⟩ = c_f`。
2. **2D 精确**（面积律按片因子化）：`⟨W(A)⟩ = (w₁)^A` 是纯 `A` 次幂 ⇒ `A` 个 tile 带 `A` 个 `1/N`，**不可能是整体一个**。
3. **Gupta 逐字**：(14.18) `⟨W_RT⟩=(β/2N²)^{RT}`、(14.20) `(β/2N²)^{4T}`、每 tile 一个 `1/N`（`[O]`，转引 `P3-FOURWALL-DERIVATION:150–153`，本轮**未回 PDF**）。

**⇒ 判：`u` 有独立定义，`c_f/u = N` 是推论。** `p3` 的行话（`P3-CBAR:38`「`u := c_f/N` ⇒ `c_f/u ≡ N`……**这是定义，不含任何数学内容**」）在"零内容"这一点上对，但**在"它是定义"这一点上不精确**：`u` 不是被定义成 `c_f/N` 的，而是被独立定义成每 tile 归一权重；`c_f/N` 是同一个数的**代数结果**。

**这对本题的后果（关键）**：`c_f/u = N` 这条恒等式**对 `C̄` 说零句话**——它只说明「`tr` 系数是 `(1/N)tr` 权重的 `N` 倍」，这是归一化的定义性事实，**不是**关于簇权重上确界的陈述。

## 3 · 问题 3：`|w|^{1/n}` 是否真等于 `c_f` —— 单片上是 `⟨(1/N)trU⟩` 还是 `⟨trU⟩`

### 3.1 三条互相排斥的精确单片读数（同一片，三种归一）

`P3-CBAR:44–46` 表（口径已整理）+ `Z06:60,83`：

| 读法 | 精确单片值 @`β=1/12, N=2` | `C̄ = W/u` | `Ū=eΔ·W` | 窗 `β₁` |
|---|---|---|---|---|
| `W = u = ⟨(1/N)tr U_p⟩`（Z06 钉死；Gupta 14.18） | `0.0208273`（本轮复算，见 §3.3） | **1** | `1.13262` | `0.073576`（SU(2) 口径，见 §3.4） |
| `W = c_f = ⟨tr U_p⟩`（f07 用；`∏c_f` 界） | `0.0416546` | **2** | `2.26458` | — |
| `W = Φ(0)=Σ_{r≠0}c_r dim r = β`（KP (★★) 字面） | `0.0833333` | **8** | `4.53047` | `0.018394` |

**`f07:85` 的那一步「SU(2) 精确核对」在这里露了馅**：`⟨(1/N)tr U_p⟩ = 0.0208273` 与 `β/(2N) = 0.0208333` 相符——但 `β/(2N)` 在 `N=2` 上**数值上就等于 `⟨(1/N)trU⟩`**（因 `SU(2)` 两定向重合使 `c_f` 翻倍为 `β/2`，`Z06:75` 逐字）。所以这条核对实际证明了

```
⟨(1/N)tr U_p⟩ = β/(2N)        （N=2 的数值巧合）
```

而不是 `|w|^{1/n} = c_f`。真 `c_f = ⟨tr U_p⟩ = 0.0416546 = β/2`，是它的 **2 倍**。**`f07:85` 的核对在 `N=2` 上不可判别 `c_f` 与 `u`**，因此它不能支持 `|w|^{1/n}=c_f`。`[T]`+`[E]`

### 3.2 与 `Z06` 的管子权重直接矛盾（这是 `N` 的真正入口）

`Z06-HOLEA.md:17` 逐字 `[T]`：

```
w(B_T) = a₀·(c_f/N)^{4T} = a₀ u^{4T}
```

`f07` 恰恰把**同一根 4 壁管**当成 `|w|^{1/n} = c_f` 的证据（"cube/4-壁 tube，`n=6,4,8,12` 全 `2.0000`"）。两处对同一对象给的是 `c_f^{4T}` vs `(c_f/N)^{4T}`——**差 `N^{4T}`**。`Z06:17` 这一边锚在 Gupta (14.20) `(β/2N²)^{4T}` 与 (14.21) `M=−4log(β/2N²)`（`[O]` 逐字），`f07` 这一边锚在"无额外字符重数"的收缩论证。**收缩论证只排除 `dim f` 重数，不排除逐片 `1/dim f` 归一**（`Z06:43`）⇒ 两条都成立时，管的每片权重必须是 `c_f/N`。

**⇒ `N` 的入口逐字定位**：

```
|w|^{1/n}/u = c_f/u
      ↑ 分子取 tr 归一的字符系数 c_f（= |w| 的上界，不是 |w|）
                ↑ 分母取 (1/N)tr 归一的每片权重 u（= |w| 的真值）
⇒ 比值 = N = 被分子漏掉的那个逐片 1/N 的倒数
```

这与 `P3-CBAR:50` 逐字判词同向：「`N` 既不是"恒等式的推论"，也不是"方向正确的那条界的值"：它是 **`tr` 系数（`c_f`）配 `(1/N)tr` 归一（`u`）的错配商**」。**但 `p3` 把它归到"三读法的中间值"，本文件把它进一步钉成一句话：`N` 不是任何一次测量的产物，是两次归一化相除的商。**

## 4 · 判：`C̄ ≡ N` 的性质

**`C̄` 有两个不相等的定义，`f07` 的等号跨了它们。**

| 槽 | 逐字定义 | 出处 |
|---|---|---|
| `C̄_φ`（Ursell 簇系数槽） | `\|φ^U(Γ)\| ≤ C̄^{\|Γ\|}u^{\|Γ\|}`，`ū := eΔ·C̄·u` | `X01-L1C.md:71,75` `[T]` |
| `C̄_w`（每片权重槽） | `C̄ := sup_S \|w(S)\|^{1/\|S\|}/u` | `C05-AUDITCBAR.md:17`、`P3-CBAR:28` `[T]` |
| `C̄_T`（树/簇计数槽，另一物） | `C̄_T ∈ [1, e^{Δu}] ≤ 1.0535` | `C07-AUDIT.md:12–16` `[T]` |

`f07` 在 `C̄_w` 槽里算 `= N`，却把它代进 `ū = eΔ·C̄·u` 的 `C̄_φ` 槽（`F07:130,144`）。而 `C̄_φ ≥ C̄_w` 的一半是**组合**（`φ^U` 与 `w` 不是同一个对象：`|φ^U| ≤ τ∏|w_p|`，`F07:63` 实测 `0` 违例）。**⇒ `≡` 至少在两个地方越界**：

1. **`C̄_w` 内部**：`|w|^{1/n}/u ≤ c_f/u = N` 是**上界**（`∏c_f` 松 `N^{|S|}`，`Z06:83` 逐字），精确单片给 `= 1`。等号未证。
2. **`C̄_φ` 跨槽**：把权重槽的值当簇系数槽的值，缺一步 `φ^U` vs `w` 的比较。

**⇒ 逐字判词**：`C̄ ≡ N` 是**把 `N` 塞进去的**，写法应为 `C̄ ≤ N`（`[T]`），`C̄ = N` 需 `[NG]`。**这是第 28 处记账错，入口在 `F07-ADJCBAR.md:82` 的 `|w|^{1/n} = c_f = N·u`，不在 `u := c_f/N`。** 修正逐字：

```
F07:82   |w|^{1/n} = c_f = N·u
   →     |w|^{1/n} ≤ c_f = N·u        （界；Z06:83 逐字"松 N^{|S|}"）
         |w_p| = u  （精确单片，Z06:60）⇒ 真 sup 给 C̄_w = 1，不是 N
F07:130  C̄ ≡ N（唯一确定）
   →     C̄_w ≤ N（界）；C̄_w 的真值锁在 {1（精确单片）, 2N²（KP 字面 Φ(0)/u）} 两个归一读法之间
```

## 5 · 判死线

### (a) `u := c_f/N` 是定义 ⇒ `C̄ ≡ N` 是把 `N` 塞进去的 —— **前提不成立，结论成立，入口移位**

`u` **不是**定义成 `c_f/N` 的（§2：三条独立确证 + Gupta 14.18 `[O]`）。但 `N` 确实是塞进去的，入口是 `|w|^{1/n} = c_f`：分子取 `tr` 归一的**上界** `∏c_f`，分母取 `(1/N)tr` 归一的**真值** `u`，商就是被漏掉的逐片 `1/N` 的倒数。逐字：**第 28 处记账错 = `F07:82` 把 `Z06:83` 的上界 `≤ ∏c_f` 写成等号 `= c_f`，再除以已经含了 `1/N` 的 `u`。**

### (b) `u` 有独立定义、`c_f/u=N` 是推论 ⇒ `C̄ = N` 可能对 —— **不触发**

前提成立（`c_f/u = N` 确是推论，`[T]`），**但推不出 `C̄ = N`**：那条恒等式钉的是 `u ↔ c_f`，钉不住 `sup\|w\|`。要与 `c_f/u = N` 合成 `C̄ = N`，必须再加一条**等式** `sup\|w_p\| = c_f`——而这正是被 `Z06:83`（界松 `N^{|S|}`）与 `Z06:60`（精确单片 `=u`）两边否掉的那一条。⇒ **(b) 的"可能对"不成立；`C̄ = N` 只在"上界"意义下对。**

### (c) `|w|^{1/n}` 的量纲/归一化有歧义 —— **触发，且是本题主因**

* 单片三读法 `{u, c_f, Φ(0)}` ⇒ `C̄ ∈ {1, N, 2N²}`、`Ū ∈ {0.566, 1.133, 4.530}`、窗 `{0.1472, 0.0736, 0.0184}` —— **跨度 8×，全部是归一化，不含一条新估计**（`P3-CBAR:18` 同判 `[T]`+`[E]`）。
* 再加 `SU(2)` 特例的 `β/(2N²)` vs `β/N²` 因子 2（`C05:121` `[E]`，本轮 §3.3 复现）⇒ 实际跨度 **16×**。
* 量纲层面：`c_f = ⟨trU⟩` 带 `dim f = N`；`u = ⟨(1/N)trU⟩` 不带。二者**不同量纲的同一个 Wilson 量**——`|w|^{1/n}` 必须声明取哪个，否则 `N` 可以任意搬。
* 另加：`C̄_φ` 与 `C̄_w` 是两个对象（§4），`≡` 跨槽。
