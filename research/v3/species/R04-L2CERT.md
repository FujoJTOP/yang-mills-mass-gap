## 1. 自由度与条件化（题面第 1 条）

### 1.0 先纠一条记账错（`Q11-CERT.md:206`）

`Q11-CERT.md:206` 写 "`L=2`（`1×1×1×1` 环面，16 link，2 plaquette）"。这不是 `L=2`：
`4·L⁴` 在 `L=2` 是 **64** link、`6·L⁴` 是 **96** plaquette，`16` 位点；`4·L⁴=16` 无整数解。
那个 `1×1×1×1`（4 link、6 plaquette）是**粗格点** `L_c=1`（由 `L=2` 经因子 2 分块），不是 `L=2` 本身。`[T]` 本文件按 `L=2` 记账，`O24-L2-PUSH.md:49`（"`L=2` ⇒ 16 位点、64 link、96 plaquette"）逐字一致。

### 1.1 逐项（`w7/r04_dimcount.log` `[0]`，全部整数机检）

```
sites            = L^D         = 16
links            = D*L^D       = 64
link components  = 3*links     = 192
plaquettes       = C(D,2)*L^D  = 96
plaquettes/link  = 2(D-1)      = 6      (逐条统计 = 6.0)
gauge generators = 3*sites     = 48
physical dim     = 3*links - 3*sites = 144
```

### 1.2 条件化不是规范固定（机检）

粗模取 `O24` 的模 A：`v_{l,3}=1/8`（64 link 同向），`‖v‖² = 64·(1/8)² = 1`（机检 `1.000000000000`）。
`⟨v,X⟩ = a₀` 是 `ℝ¹⁹²` 上的**一个**超平面 ⇒ codim 1。机检 `rank([J_gauge | v]) = 46 = 45+1`（平坦点，`J` 的 rank 45 = 48−3，见 §1.3）⇒ **`v` 与规范轨道线性无关**，条件化砍掉的维数**不重复**计入规范的 48。

```
fiber:  link 层 3*64-1 = 191 ;  商规范 144-1 = 143
```

### 1.3 平坦点上的精确分解（附带结构发现，`[T]`+机检）

曲率映射 `d(holonomy_p)/d(link)` 在平坦位形上是 288×192 的 `±1` 矩阵，机检 **rank = 135**：

```
192 = 45 (exact 1-forms dλ；常数 λ=3 被平坦点稳定子吃掉) + 12 (H¹(T⁴)⊗su(2)) + 135 (image)
```

`45+12+135 = 192` ✓。那 **12 = 4 方向 × 3 色**是**自由 Hessian 的精确零模**（`toron`/常数规范场），
即：`L=2` 上"自由场 `G″=0`"这条酸测（`CLAUDE.md §1`）不是靠一个零模、是靠 12 维零模实现的，
且这 12 维是**物理方向**（被 `Φ=−log J` 抬起来），**不是**规范冗余 ⇒ 144 的口径正确。

## 2. 对称性能降多少维（题面第 2 条）：**0**

| 群 | 阶 | 机检 | 对 64 条 link 的轨道 | 不变切空间维 |
|---|---|---|---|---|
| 点群 `W4`（4D 超立方体） | `2⁴·4! = 384` | 枚举 384 ✓ | 8 个（大小 4/12） | 24 |
| 平移 `(Z₂)⁴` | 16 | ✓ | 4 个（各 16） | 12 |
| 全空间群 `(Z₂)⁴⋊W4` | **6144** | 384×16 ✓ | **1 个（64）** | 3 |

**定理（一句话，`[T]`）**：`G` 有限 ⇒ 对任意 `x`，轨道 `G·x` 是**有限集**，维数 0；`dim(M/G) = dim M`。
所以 `∫_M f = |G|⁻¹∫_{M/G} (Σ_{g}f∘g)` 里出现的只有**测度因子 `|G|⁻¹`**，**不是**维数。
对称性真正买到的是两件别的事：(i) 基本域（同 143 维，测度 1/6144）；
(ii) **二次截断**在平坦点按不可约表示块对角化（不变子空间 3 维）——但那一层是**自由场**，
`G″≡0`（酸测失败），见 §1.3 的 12 零模。**⇒ 对称性对"能不能做区间算术"的回答是零。**

对比：`q11` 的 1D 约化**不是**对称性给的，是**闭式**给的（`w(u)=sin²u/u`、`Φ″w` 是全导数、`NS=1/4`
IBP 精确）。`L=2` 上 `Φ=Σ_l Φ_l` 但 `S_W=βΣ_p(1−…)` 与 `Φ` 共享链变量，**不存在**这样的全导数配对。

## 3. 裁决：**(b) 只能 MC**（题面第 3 条）

`143 ≫ 20` ⇒ 判据判死。`q11` 的区间算术需要"整函数 + 精确有理 Taylor 系数 + 逐项积分"，
在 143 维上对应 `(3·64)` 重积分，**没有**任何一项是精确闭式。`Q11-CERT.md §6` 的第二条理由
（character/Kogut 展开 `β/4=0.625`、需 `n≫10`、无闭式截断）我也复核为 `[C]` 级成立：
它给**逐阶界**，不给证书。

### 3.1 次优选择 B1：区间算术 + MC 的"统计严格界"——**算过账，今天不可交付**

`Δ = E[κ|0] − Var(F|0)`。要把它做成严格界，唯一干净的路线是"有界部分 + 显式尾体积界"：

```
κ ≤ 2/δ²      （δ = 2π − r，Φ″ 的奇性；O24 §3 的重尾机制）
P(δ < δ*) ≤ 64·c·δ*³        （单链壳层体积 ∝ δ³，本文件 §4 机检斜率 2.99999927）
K = 2/δ*² ,   ε_Hoeffding = K·sqrt( ln(2/δ_p) / (2N) ) ,   尾界 ≈ κ_max·64 c δ*³
```

`δ* = 3e−2 ⇒ K = 2222`；要 `ε = 0.3`（`Δ≈0.39` 的一半）需
`N ≈ (K/ε)²·ln(2/δ_p)/2 ≈ 3e8` 个独立样本；`O24` 实测 `10 ms/sweep` ⇒ **≈ 35 天**（单核）。
`δ* = 1e−2` 更差（`K=2e4`、`N≈3e10`）。**⇒ 今天给不出 `[T]`。**

### 3.2 次优选择 B2：可交付的现有最强物 = `O24` 的 `[E]` 判决（`+6.0σ`）

`O24` 已给双误差（`σ_jk=0.0258`、`σ_τ=0.0653`）、尾指数 `α≈1.97`、median/winsor 三版本同号 ⇒
`Δ_raw = +0.3942 (+6.0σ)`。这是 `[E]/[M]`，**不是**证书；`R04` 不重复跑格点（内存纪律）。

### 3.3 B3（诚实标注为不存在）

把 `L=2` 的 `S−D` 拆成"96 个 plaquette 的乘性因子"没有结构支撑：每条 link 进 6 个 plaquette
（机检 6.0），因子化会要求 `S_W+Φ` 按 link 分离，而 `S_W` 是 plaquette 的**和**。⇒ 无。

## 4. `θ=π` 的 `L=2`（题面第 4 条）：**不简化，且是最坏点**

**先拆题面的两个混淆**（这是本条的核心）：
- `θ=π` 是**边界 holonomy 角**；`a₀→2π` 是**粗模幅度**。`Q08-LARGEA.md §2.1–2.2` 逐字：
  "`a=π` 处 `s_max=π√3`，切片仍是 2 维"、"真正的端点 `a→2π`（切片塌成单点 `U=−1`）"。
  ⇒ **"`θ=π` 时切片塌成 `U=−1`"是两种量的串台**，`q08` 并没有这么说。
- 单 plaquette 上 `q11` 能用，靠的是 `θ=π ⇒ c=cos(θ/2)=0 ⇒ S_W≡β` **在 `a₀=0` 切片上**（两个条件同时），
  于是权重是**常数**、测度是纯 Haar、`S=1/(4Z)` 与 `β` 无关。**这两条在 `L=2` 上都不复现**：
  4D 的 `θ=π`（`Z₂` 't Hooft 扭转一个平面）只让**被扭转 plaquette** 的 `cos h cos(θ/2)` 项消失，
  剩下 `β(1+sin h·u)` **仍依赖链变量的方向/角度** ⇒ 切片不塌、测度不是常数、无 1D 条带。

**Weyl 展开能不能用**：逐 plaquette 的 `Φ″ = 1/(2u²) − cot u/(2u)` 可以逐项写出来（`q04` 的式子），
但它**不闭合**：`L=2` 上它是 143 维耦合积分里的一项，没有"全导数 ⇒ 边界值"的 IBP 配对
（`q11` 的 `NS=1/4` 是单 plaquette 的偶然）。**⇒ `θ=π` 在 `L=2` 上：维数仍 143、无简化、
且因 `E[H]≡0`（β-线性正项整块消失）它是最坏点。**`[T]`

### 4.1 唯一的精确坍缩：`a₀ = 16π` 角点（这才是 (c)）

`a₀ = ⟨v,X⟩` 在 `|x_l| ≤ 2π` 上的**最大值**：`Σ_l v_{l,3}·2π = 2π·8 = 16π = 50.265482457437`（机检）。
该角点 = 64 条 link 全在 `|x|=2π` 壳层、方向 `e₃` ⇒ 全链 `U=−I`（**规范等价于平坦真空**，`S_W=0`）。
逐链 `J ≈ (2π−r)²/const`、壳层面积 ∝ `δ` ⇒ 逐链权重 `∝ δ³`（**机检斜率 `2.99999927`**）。
Dirichlet 律 `∫_{Σδ=ε} ∏δ_l² dδ = ε^{3n−1}·const`（`n=2,3` 机检 `5.0000000000`、`8.0000000000`）⇒

```
ρ_v(a₀) ∝ (16π − a₀)^{3·64−1} = ε^{191}      ⇒   G″(a₀) = +191/ε² + O(1/ε) → +∞   [T]
```

这是 `Q08-LARGEA.md §2.1` 的 `+3/(2π−a)²` 在 `L=2` 上的**精确推广**（`3n−1`，`n=64`）。
**但它对 `a₀=0`（`H1` 的条件化点）零信息**：`a₀` 从 0 到 16π 有 16π 的距离，指数律只在角点邻域成立。
⇒ (c) 的答案是"有特殊简化、但简化的点在**无关的端点**"，因此**不能**用来判 `a₀=0` 的号。
