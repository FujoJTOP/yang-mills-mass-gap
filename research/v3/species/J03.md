## §2 它的陈述是什么（蕴含？不等式？）

**既不是蕴含，也不是不等式**，是**成员性/排序前提**：

1. 形状是「`argmin_{c} Δ_c ∈ {0⁺⁺, 2⁺⁺}`」＋「其余道 `≥ δ`」——是**对 `J^{PC}` 标签的量化**，不是两个量的比较。
2. 它唯一"像不等式"的产物经 `min` 得到：`inf_c Δ_c = min(Δ_{0⁺⁺}, Δ_{2⁺⁺}) ≥ δ`（`PROOF-IN11.md:17`；`M3C-TAIL.md:184` 的 `(iv) 取 min`）。**方向仍靠外部 `δ`，`IN-11` 自己不给任何数。**
3. 分层（`A2-IN11.md §1.2`，核过原文）：
   - L1 成员性（`(b′)`）：仅 `0<β<β₁≈0.0184` 上 `[T]`（`PROOF-IN11.md:11–19`，SZZ/OS 收敛＋有限立方群引理）；
   - L2 序＋隔离（`0⁺⁺` 更轻）：`[C]`，且领头 `a_{0⁺⁺}=a_{2⁺⁺}=1` ⇒ **精确简并**，序在 `O(1)` 次领头；
   - L3 存续到 `β≈2.5`/连续统：`[C]`（`β₁` 与 `β_W≈2.47` 之间**无桥**）。

## §3 与 `m₁ → m` 的关系（关键）

- 定义：`m := inf spec H|_{1^⊥}`（全道），`m₁ := inf supp ν_{¼trF²}`＝`0⁺⁺` 道底（`B06-VERDICT.md:123` 逐字"`m₁² = inf supp ν_{¼trF²}`（`0⁺⁺` 道）**≠** `inf spec(H|Ω⊥)`（全道）——`[T]`"）。
- ⇒ **`m ≤ m₁` 恒真**；故 `m₁ > 0 ⇏ m > 0`（`LOOP-RUNBOOK.md:20867` 逐字「因为 `m ≤ m₁` ⇒ `m₁ > 0` ⇏ `m > 0`（`h06` 的惰性）」）。
- 这正是 `IN-11` 要补的那一格：**`IN-11`（`0⁺⁺` 全道最轻）＋ 底 `O`-可及 ⇒ `m = m₁`**（`H06.md:85`、`B10.md:118–120` 逐字"`s₁ → m` 需 `J^{PC}`-盲"）。
- **桥是等式，不是下界**：`m = m₁` 把两边变成同一个未知量，故 `(I1∧H1)` 已得的 `s₁ ≥ r₀λ`（`[T]`）**只有在 `IN-11` 已付时**才等于 `m ≥ r₀λ`；未付则一步也不转移。
