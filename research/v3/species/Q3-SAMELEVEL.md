## §0 判死线（先给）

**(a) 死。** 不存在能补那次交替的**同层原理**——不是"没找到"，是结构性排除（§4 引理 N）：任何"对次指数类（`e^{−√R}` 满足）全体成立"的原理，连同 `f′≤0`、`0<f≤1`，**产不出** `∃c>0` 的速率。买一次 `Σ⁰₂`，靠的是**排除次指数类的方程内容**，不是更强的不等式。

**(b) 成立，但理由必须换。** 那次交替在 `(★₁)` 上**已经付过**：`(★₁)+单调+正` 自己就产出一条 `Σ⁰₂` 定理——**符号相反**（§1 的 `(SL)`，`ℓ>0`）。故缺口不是"少一次量词跳跃"，而是"跳过去之后买到的是一句反话"。

**(c) 成立，且这是对当前判断最重要的一条。** `sp-e` 的 8 行证明的首要一维特有假设是 **H2：RHS 是同一标量函数的平方 `f²`**（齐次性 ⇒ 符号确定性 + `f(s)²≤f(R)²` 的比较）；次级是 **H7：单序尾积分 + 核 `s^{−3}` 的低维收敛性**（`d≤2` 才活）。两者在两变量/fig8 约化里失效或减弱 ⇒ **该定理杀的是方程 `f″=Af²/R³`，不是环代数；它不能用来否定 fig8 约化。fig8 仍有希望。**

## §1 `(★₁)+单调+正` 能推出的最强命题 `(SL)`（`[T]`，条件于 `sgn A`）

**(SL)** 设 `A>0`，`f∈C²([R₀,∞))`，`0<f≤1`，`f′≤0`，且 `f″ = A f²/R³` 于 `[R₀,∞)`。则 `∃ℓ`：

| | 结论 | 依据 |
|---|---|---|
| (i) | `ℓ ∈ (0,1]` 且 `f(R) ↓ ℓ` | `SP-E` §2 (ii) 的引擎（`f′↑`、非负 ⇒ `lim f′=0`），`f` 单调有界 ⇒ 极限存在 |
| (ii) | `∀R≥R₀ : f(R) − ℓ ≥ Aℓ²/(2R)` | `−f′ = ∫_R^∞ f″ ≥ Aℓ²∫_R^∞ s^{−3} = Aℓ²/(2R²)`，再积一次 |
| (iii) | `R·(f(R) − ℓ) → Aℓ²/2` | `f→ℓ` + 控制收敛 ⇒ `−f′ = Aℓ²/(2R²)+o(R^{−2})`，再积 |
| (iv) | `f(R) ≥ (1/f(R₀) + A/(2R₀))^{−1} =: c₀ > 0` | `d(1/f) = −f′/f² ≤ A/(2R²)` 的积分，`ℓ ≥ c₀` |

**精确量词形式**：`∃ℓ∈ℚ⁺ ∃R₀∈ℕ ∀R≥R₀ : f(R) ≥ ℓ + Aℓ²/(2R)` —— **`Σ⁰₂`**（两个 `∃`、一个 `∀`，一次交替）。
**其余两分支**（同一证明的收口）：`A=0 ⇒ f ≡ const ∈ (0,1]`（`f″=0`+`f′≤0`+有界 ⇒ 斜率 0）；`A<0 ⇒ 前提类空`（`SP-E` §2(i)）。
`[E]` 代数核对：族 `f = ℓ + Aℓ²/(2R)` 满足 `f″/(Af²/R³) → 1`，且 `R(f−ℓ) = Aℓ²/2` 逐点相等（`sympy`，`limit` 与 `simplify` 双验）—— 即 (iii) 的常数是**被钉死的**，不是估计。

## §2 逐条对比：`(SL)` vs `P2`

`P2(f) := (★₁) ∧ 0<f≤1 ∧ f′≤0 ⇒ ∃c∈ℚ⁺ ∃R₀∈ℕ ∀R≥R₀ : f(R) ≤ e^{−cR}`。

| 轴 | `(SL)` | `P2` | 谁强 |
|---|---|---|---|
| 算术层 | `Σ⁰₂` | `Σ⁰₂` | **同级——交替已付** |
| 结论方向 | **下界**：`f ≥ ℓ + Aℓ²/2R > 0` | **上界**：`f ≤ e^{−cR}` | `(SL)` 更强：它在整个前提类上**否定后件** |
| 蕴含 | `(SL) ⊢ ¬(P2 后件)`，且 `(SL) ⊢ P1`（`ℓ>0` ⇒ 非幂律） | — | `(★₁) ⊢ P1 ∧ ¬(P2 后件)` |
| 弱在哪 | 只给"离极限至少 `1/R`"，不给任何**离 `1` 之下**的形状界；只碰单点值，不碰两点关联 / 面积律 / 分割点 | 给形状（但无实例，§3） | — |
| 依赖 | (i)–(iv) 只用 `A` 的**符号**；非空性用 `A≥0` | 无 | — |

**一句话**：`P2` 与 `(SL)` **同为 `Σ⁰₂`**。那次 `Σ⁰₁→Σ⁰₂` 的交替在 `(★₁)` 路线上**不是待付的账，是已付的账**；付完买到的符号是相反的。⇒ "多付一次交替就能拿 P2"这个诊断，在 `(★₁)` 上是**方向错**，不是**力度不够**。

## §3 修正 `sp-e` §3：`P2` 在 `(★₁)` 上不是"真但空"

`SP-E-PROOFTH.md` §3 说"前提类为空 ⇒ P2 真但空"。**这步是过度结论**：§2 的引理只否证**衰减**解，并不给前提类空。（`[T]` 修正）

| `sgn A` | 前提类 | `P2` | 显式见证 |
|---|---|---|---|
| `A>0` | **非空** | **假** | `f = ℓ + Aℓ²/(2R) + o(1/R)`，`0<ℓ≤1`（`SP-F-LOOPALG` §7.2 数值沿稳定流形取到 `ℓ=0.5,0.9`） |
| `A=0` | **非空** | **假** | `f ≡ c`，`0<c≤1` |
| `A<0` | 空 | 空真 | — |

⇒ **`sgn A ≥ 0 ⇒ ¬P2`（有显式反例）；`sgn A < 0 ⇒ P2` 是空话。** 两支都**不给隙**，故无需知道 `sgn A` 就能判死 `P2` 的路线。
`[M]`（唯一残留的账号）：`sgn A = sgn(c₁c₂)` 未算（`SP-F-EQ1` §6 自认 `c₁,c₂` 未算）。它只决定 `P2` 是"假"还是"空"，**不决定有无隙**。

**结构读数**：`P2` 想从 `(★₁)` 里取的那件东西，`(★₁)` 已经用**反方向**给了。要 `P2` 成立，就得让 `f→ℓ>0` 那一族不存在；而那一族是 `(★₁)` 的**真解**——所以能给出 `P2` 的"原理"必须在前提类上**为假**，即它不是原理，是与方程矛盾的假设。

### §4.1 对 fig8 的直接结论（c）

`sp-e` 的定理是 `f″ = A f²/R³` 的定理。两变量约化的 RHS 不再是"一个函数的平方"，因此

> **H2 失效 ⇒ `f″` 无定号 ⇒ `f′` 无单调 ⇒ §2 的三步引擎在起点就断。** 该定理**对 fig8 无约束力**；"`(★₁)` 无衰减解"**推不出**"两变量约化无衰减解"。fig8 未被否证。

### §4.2 (c) 的代价（不许含糊的两条）

1. **H5 不自动**：物理单调性（`W` 在圈扩大下减小）只对**包含序**成立；两模族若不被包含序排序，`∂_i f ≤ 0` 是**额外输入**，且它不是由 `(★₁)` 类方程给的。`[M]`
2. **H2 可能被继承**：若 fig8 的分割取在对称点使 `C_xy ≅ C_yx`，则 `W(C_xy)W(C_yx) = W² ≥ 0` **又是平方** ⇒ 符号确定性回来了 ⇒ **"无衰减解"在两尺度下照样成立**（`H7` 只剩 `1/(4R)`，`1/f ≲ C + A log R`，仍 `f ≥ 1/(C+A log R) > 0`）。
   ⇒ **可检验判据（`[J]`，无方程故不作定理）：fig8 的生机只在"RHS 非平方"（分割不对称 / 两段权不同号）时存在。先核这一点，再谈解。**

## §5 第四条同层原理候选：逐个判

判据用 §6 的引理 N：**能在次指数类上成立的原理，推不出 `c>0`。**

| 候选 | 算术层 | 物理上真实？ | 能给出那次交替？ | 依据 |
|---|---|---|---|---|
| `|W|≤1`（有界性） | `Π⁰₁`（逐点） | 真（定义 / RP） | **否** | `e^{−√R}` 满足它且 `c=0`：幅度 ≠ 速率 |
| **Chebyshev 不等式**（单调函数和/积分型；格点上 `⟨trU trU⟩ ≥ ⟨trU⟩²` 一类，强耦合字符展开的标准件） | `Π⁰₁` | 真 | **否** | 它给**符号/相关号**，`e^{−√R}` 同样满足；它是**保速率**的，不产速率 |
| **次可加性 / 半群性**：`|W(A₁+A₂)| ≤ |W(A₁)||W(A₂)|`（RP + 平移半群，标准） | `Π⁰₁` | 真 | **否——但最接近** | Fekete ⇒ `c := lim_R (−log f(R))/R ∈ [0,∞]` **存在**：`∃c` 那一格确实可填。但 `c>0` 仍是一次 `Σ⁰₂`，且恰好等价于"排除次指数类"——交替**搬家而非消失**。且在 `(★₁)` 上 `c=0` 自动成立（`f→ℓ>0`），这条原理与 `(★₁)` 相容却吐出 `c=0`，最直白地证明**符号不由原理给** |
| `θ`-无关性 | `∀θ` 块（**加**一层） | **不是原理**：大 `N` 下 `m(θ)=m(0)+O(1/N²)` 是 `[C]` 渐近事实；有限 `N` 有 `θ`-依赖（`θ=π` 相变） | **否** | 它是"对 `θ` 一致"，即**增加**交替数；且按 `纪律` 不算同层原理 |
| `L`-单调性 | — | 若 `L`=圈尺度：**就是 `f′≤0`，已计入，不是第四条**；若 `L`=格点尺度/`N`：速率落在**别的变量**上，"对 `L` 一致"是热力学极限陈述 `[C]` | **否** | 要么冗余，要么变量错位 |

**唯一的"活口"形态**：次可加性把 `P2` 归约为 `c>0`。这不是填补，是把那次交替**从"存在速率"搬到"速率非零"**——两者同为 `Σ⁰₂`。

## §6 引理 N（`[T]`，平凡但决定性）

令 `𝒞_sub := {f∈C¹((0,∞)) : 0<f≤1, f′≤0, f 次指数}`（含 `e^{−√R}`、`e^{−R^{0.1}}`、`R^{−p}`）。若 `𝒫` 是**对 `𝒞_sub` 全体成立**的任一陈述集，则
`𝒫 ⊬ ∃c>0 ∃R₀ ∀R≥R₀ : f(R) ≤ e^{−cR}`。
**证**：`f₀(R) := e^{−√R} ⊨ 𝒫 ∧ ¬(结论)`。

> **⇒ 任何不排除次指数类的同层原理，都填不上那次交替。能填的只有"排除次指数类"的陈述——而那是方程（或模型）的内容，不是原理的内容。** 这就是为什么 `(★₁)` 能产 `Σ⁰₂`：它不是原理，它**排除模型**。它排除得过头（把指数类一起排除），于是付了交替、买了反话。

## §7 判决（一句话）

> **(a) 死；(b) 成立且方向反了；(c) 成立。** 那次数词交替**不是逻辑资源，是方程内容的记账**：`(★₁)` 上它已付清、符号为负；同层原理（`|W|≤1`、Chebyshev、`θ`-无关、`L`-单调）在引理 N 下集体出局，次可加性只把它从"存在速率"搬到"速率非零"（仍 `Σ⁰₂`）。**故"用同层原理补交替"这条路必须放弃；fig8 的生机不在原理，在"RHS 是否仍为平方"（§4.2-2）这一条可检验判据上。**

**路径**：
1. 核 `sgn(c₁c₂)`（`[M]`，只决定 `P2` 是假还是空，不影响判死）。
2. fig8：先判**分割是否对称**（`C_xy ≅ C_yx` ⇒ `W²` ⇒ 机制继承 ⇒ 两尺度下仍无衰减解）。
3. 若不对称：供 `∂_i f ≤ 0`（不当成免费）+ 核尾积分（`d=2` 只给 `1/(4R)`，故下界形为 `f ≥ 1/(C+A log R)`，**仍正**）——此时"无衰减"未必死，但**指数速率仍须由方程排除次指数类来买**，不由任何原理买。
