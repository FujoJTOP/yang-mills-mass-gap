## 1. 必做①：代数重写（`[T]`，一行）

`Var(X)=E[X²]−E[X]²` 取 `X = F := G+Φ'`：

```
S − D := E[H+Φ''] − Var(G+Φ')
      = E[H+Φ''] − E[(G+Φ')²] + E[G+Φ']²                                   [T] 代数
      = E[κ] − Var(F),        κ := H+Φ'' = ∂_v²V,  F := G+Φ' = ∂_vV        [T] 定义
```

**与 `p21` 骨架交叉核对（`P21 §0 (Q-id)`）**：把 `Var(F)=Var(G)+Var(Φ′)+2Cov(G,Φ′)` 展开，

```
S − D = [E[H]−Var(G)−Cov] + E[Φ''] − Var(Φ') − Cov        ← 与 (Q-id) 逐项同形
```

（`E[H]−Var(G)−Cov` 就是 `P21 §1 候选 3` 表里那列「`m_G′`」。）**数值核对（`log [1]`，β=2.5, θ=π, 5 个 `a`）**：

- `EHvv(0.75) = −0.181550` vs `P16 §6:183` 的 `−0.1816` ✓；`EΦ''(0.75)=0.226178` vs `P21` 的 `0.226178` ✓；`S−D(0.75)=−0.005888` vs `P21/P22` 的 `G″=−0.0059` ✓ ⇒ **本文件的 `a`-切片求积与项目同对象**。
- **附带更正（`[C]`，可核）**：`P21 §1 候选 3` 那列「`m_G′`」**不是** `d/da E[G|a]`，而是代数组合 `E[H]−Var(G)−Cov`；真正的 `d/da E[G|a]` 恒等于 `S−D` 本身（上表两列 5/5 位一致）。这解释了 `P22 §0` 记的「`m_G′ = E[H_vv]` 前提为假」：那是**标签错位**，不是物理张力。

## 2. 必做②：候选平方结构

三个正项候选 + 唯一负项：

```
Φ'' ⪰ (N/12)‖v‖²      (p16 §3, [T]);   在 a=0 上 E[Φ''] = 0.205115 = N/12 + 0.038449
E[H_vv] = β(c/2)G(B)   (p05, [T], θ≤π); 在 θ=π 上 c=cos(π/2)=0 ⇒ E[H_vv]≡0（[T] 退化）
−Var(G+Φ')            唯一负项
```

于是字面上的 SOS 只能是

```
S − D = [E[Φ''] − N/12] + E[H_vv] + [N/12 − Var(G+Φ')]                       (★)
```

第三项 `N/12 − Var` **不是**非负量：它要在 `H1`（`Var ≤ N/12 + β(c/2)G(B)`）下才有下界 `−β(c/2)G(B)`，而这是个**负**下界，不是平方。⇒ **SOS ⟺ 把 `Var` 写成「某量²」再与两个正项比 ⟺ `H1`**，没有多出任何东西。这就是任务书里那句「SOS 等价于 H1」的确切含义。

## 3. 必做③：用 `o16` 的模分解做逐方向配对（`[C]`，`log [2]`）

Hess 本征基 `e_k`，`c_k := ⟨v,e_k⟩`，`g_k := ⟨e_k,∇S⟩`，`A_k := c_k g_k`，`C_k := Σ_l Cov(A_k,A_l)`，`Var=Σ_k C_k`。

**`a=0, θ=π, β=2.5`（`log [2]` 第 1 块）**：

| `k` | `c_k²` | `⟨λ_k⟩` | `C_k` | `c_k²Var` | 规范配对项 `c_k²(λ_k+N/12−Var)` |
|---|---|---|---|---|---|
| 0 (负模) | 0.500000 | **−0.203343** | 0.034560287 | 0.034560292 | **−0.052898391** |
| 1 (方位) | 0.000000 | 0.000000 | 0 | 0 | 0 |
| 2 (正模) | 0.500000 | **+0.203343** | 0.034560299 | 0.034560294 | **+0.150444478** |

- `|Σ_k C_k − VarF| = 2.8e−16`、`max|c_k²VarF − C_k| = 4.8e−09` ⇒ **`C₋=C₊=Var/2` 是精确的**。
- 结构原因（`[T]-in-model`）：`a=0, θ=π` 切片上 `∇S = s_u g_u = β sin h·e3/ρ` ⇒ `∇S ∥ v` ⇒ `g_k = c_k G` ⇒ `A_k = c_k²G` ⇒ `C_k = c_k²·(Σ_l c_l²)Var = c_k²Var`；而 `H` 在 `(e1,e3)` 平面上的**反射反对称**给 `c²=(1/2,0,1/2)`、`λ_±=±|M|`（`o16 log [2]: max|c²−(1/2,0,1/2)|=7.2e−16`、`max|λ₊−|M||=1.4e−15`）。
- **所以「负模部分与 `Φ''` 配对」这件事的符号是反的**：`Φ''` 的地板按 `c_k²` 分给两个模各 `N/24`，而负模的曲率是 `−|M|/2`（`⟨|M|⟩/2 = β⟨μ⟩/2 = 0.1017`）。要负模项 ≥0 需 `λ₋ + N/12 ≥ Var`，即 `Var ≤ N/12 − ⟨|λ₋|⟩`。**`log [3]`：`0.1667 − 0.2033 = −0.0367 < 0`** ⇒ 对**任何** `Var≥0` 都不可能。这是算术，不是精度。

`a=0.75`（`log [2]` 第 3 块）：`c²=(0.685,0,0.315)`、`⟨λ₋⟩=−0.325960`、`C₀=−0.012229`（`dev=1.1e−1`，因 `∇S` 不再 ∥ `v`，`C_k=c_k²Var` **失效**）⇒ `a≠0` 上模分解本身也不再是 50/50，`(c)` 的干净版本只属于 `a=0` 切片。

## 4. 必做④：有没有一条逐方向的 `Φ''_k ≥ (−Var 的正部)_k`？——没有

两个必须分开的配对口径（`log [3]`）：

- **T1 规范（地板按 `c_k²` 分）**：`S−D = R + Σ_k c_k²(λ_k + N/12 − Var)`，`R := E[Φ'']−N/12 ≥ 0`（`p16`）。`R` 是**单标量**，不能拆成逐模非负。T1 的充要条件 `Var ≤ N/12 − ⟨|λ₋|⟩`。`log [3]`：`a=0…1.0` 五点**全部 False**（`N/12−⟨|λ₋|⟩ = −0.0367 … −0.1950`）。
- **T2 自由分配（把 `R` 与正模盈余全部挪给负模）**：两模自由转移下「各自 ≥0」**⟺ 全局 `S−D ≥ 0`** —— 配对变成同义反复（vacuous），没有任何新信息。`log [3]`：`S−D` 在 `a=0.75, 1.0` 为 **False**。

**⇒ 判死线 (b)+(c) 同时成立，且 (b) 比任务书的预期更硬**：不是「只能整体比」，而是**整体比也过不了**（`S−D(0.75, β=2.5, θ=π) = −0.005888 < 0`）。⇒ 形如 `S−D = Σ_i c_i·(非负量)` 的**非负系数** SOS 表示**不存在**（否则 `G″≥0` 处处成立，与 `P21/P22` 的 `a=0.75` 反例矛盾）。要救 SOS 只能允许**带号系数**，那就退回 `H1`。

**β 窗口（`log [3]` 末，`a=0` 精确标度 `Var=β²V₀`、`⟨|λ₋|⟩=β⟨μ⟩`）**：

```
T1 ⟺ β⟨μ⟩ + β²V₀ ≤ N/12,   ⟨μ⟩=0.081337146669, V₀=0.011059293772974
   ⇒ β_c = (−⟨μ⟩+√(⟨μ⟩²+4V₀·N/12))/(2V₀) = 1.669919
   β=1.0: 0.0924 ≤ 0.1667 ✓   β=1.5: 0.1469 ✓   β=2.5: 0.2725 ✗   β=4.3066: 0.5554 ✗   β=6: 0.8862 ✗
```

**这正是酸测失败的形状**：配对只在 `β<1.67`（近乎自由场）成立，在 `β=2.5`、`β*=4.3066`、`β=6` 全部失败 —— 对自由场有效、对 YM 失效的反面：**对自由场有效、对 YM 失效的工具是「反工具」**（`CLAUDE.md §1` 的酸测要求是反过来）。

**点态见证（`log [4]`）**：`o06` model B（`β=2.5`、`Σ‖v‖²=2`）`min H_vv = −1.893109` ⇒ 单位归一下 `min λ₋ = −0.946554 = −5.68×(N/12)`。**单个方向的负数就是整个 Jacobian 地板的 5.7 倍**，所以「逐方向配对」在点态上也没有任何余地。

## 5. 结论（逐字）

1. **`S−D` 的代数式**：`S−D = E[H+Φ''] − E[(G+Φ')²] + E[G+Φ']² = E[κ]−Var(F)`（`[T]`）；与 `p21 (Q-id)` 同形，`5/5` 个 `a` 点数值一致（`[C]`），且 `d/da E[G|a] ≡ S−D`（`[C]`，5 点 ≤1e−6）。
2. **逐方向配对不可能**（`[T]`-in-model 的算术）：`Var ≤ N/12 − ⟨|λ₋|⟩` 而右端 `<0`。
3. **最坏方向**：Hess 负模 `λ₋`（`c²=1/2` 的横向磁 Savvidy 模），`⟨λ₋⟩=−0.2033(β=2.5)`、`−0.4880(β=6)`，随 `β` 线性增长而地板 `β`-无关；最坏点 `a≥0.75, θ=π, β=2.5`（`S−D=−0.0059<0`）。
4. **(a) 不成立；(b) 成立且被加强成「整体也过不了」；(c) 成立且是结构性的**（`∇S∥v` ⇒ `C_k=c_k²Var`；`λ₊=−λ₋` ⇒ 对半劈到反号曲率）。
5. **路径**：SOS/平方和这一族**到此为止**（`[NG]`，非负系数的版本已被反例杀掉）。要继续只能放弃「非负系数」——即回到 `H1`，其缺口精确等于 `Var(G+Φ') ≤ E[H+Φ'']`，而 `E[H_vv]` 在 `a≠0` 上已负（`−0.1816 @ a=0.75`）。**`G″(0)≥0` 仍未证，且 SOS 不能证它。**
