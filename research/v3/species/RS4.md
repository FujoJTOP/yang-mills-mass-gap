## §0 判词（先行）

```
正性的产出 = 单侧不等式（振幅地板 + D_∞>0 定性）
率 ε_T 的产出 = 需要严格谱隙 θ₂≤ū<1 / 需要熵因子 C^T 被吸收
⇒ 二者不是同一类语句：正性给「≥」，率要「≤ 小的」
⇒ (a) 不触发；(b) 触发；(c) 不逻辑冲突、但是 scope 冲突，且使 (β) 承重
```

**一句话**：`⟨·,·⟩_G ⪰ 0` ⇒ Cauchy–Schwarz ⇒ **永远把对角元上界成别的对角元**，从不给 `(小)^T`。语料已有同一判词：`INEQ-R6-4pt-ward.md:13` 逐字「Positivity never lower-bounds a diagonal entry beyond `≥0`」。

## §1 「Gram 正性」的三个候选 —— 必须先分，否则是空话

名称「Gram 正性」在语料里对应**三个不同对象**，只有一个含内容：

### G1（`P6-1` 的本意）Haar/Weingarten 内积上的正（CP）算子 `[T]`（定义）/`[C]`（引理）

- **空间**：`H = H_f ⊗ H_f̄`（开管两端的指标空间）；
- **内积**：`⟪A,B⟫_G := ∫_G dU tr(A†B)`（= 各 link 上 `tr(A†B)` 的乘积，Haar 归一）。这正是使 `∫dU χ_a \overline{χ_b} = δ_{ab}` 对角的内积（机验在册：`w2b_master_w0.py:77` 残差 `2.22e−16`；`t07_su3_vphi.py:302`）。
- **陈述**：每个**无扭**装饰类给一个 `T_D : H→H`，要求 `T_D ⪰ 0`（自伴 + 正，即 CP），等价于其插入向量的 Gram 矩阵 `G^{(D)}_{ij} = ⟪A_i,A_j⟫_G ⪰ 0`。
- **注意**：这不是关联函数的 Gram（`C(j+k)`），是**插入算子的 Gram**。两者差一个 `ν`。

### G2（会自动真的那个）关联 Hankel Gram `[T]`（自动）/ 酸测失败

`S_{jk} = ⟨e_j|e_k⟩_{L²(ν)} = C(j+k)`（`H08-Z1.md:45`）；`rank S_N = min(N,|supp ν|)`（`H08-Z1.md:123`）。⇒ 对**任意** `ν ≥ 0` 自动 PSD。
**若「Gram 正性」读成 G2 ⇒ 恒真、对自由场也真 ⇒ vacuous、过不了酸测**（charter §1）。这条必须写死，否则「Gram 正性」三个字什么也没说。

### G3（真正可能给率的那一个）装饰气体的纵向转移矩阵 `[C]`

`W02-L1.md:88` 逐字：所需新引理是 `sup_{j≥2}|θ_j| ≤ u < 1`，`θ_j` = 装饰气体**纵向转移矩阵**的次本征值，`L`-一致、`T`-无关。
这是唯一「正性 ⇒ 率」在语法上说得通的位置 ⇒ §2 (P5) 单独处理它。

## §2 正性能推出什么（逐条，逐字）

### (P1) 振幅：一行，`[T]`

`T_D ⪰ 0` ⇒ `⟨v|T_D|v⟩ = ‖T_D^{1/2}v‖² ≥ 0` ⇒

```
A = Σ_D ⟨v|T_D|v⟩ ≥ ⟨v|T_∅|v⟩ = a₀ = (Σc_i²)(2N)^{-4}      (2.1)
```

尾项**被丢掉、不被估计**（这正是 `P6-SPEC:74` 的设计意图，成立）。代价：**(2.1) 里没有 `T`**——它对任何截断都成立，因而**不含任何率信息**。

### (P2) Cauchy–Schwarz 的方向是错的，`[T]`

对 `T_D ⪰ 0`、任意 `w`：

```
|⟨v|T_D|w⟩|² ≤ ⟨v|T_D|v⟩·⟨w|T_D|w⟩                            (2.2)
```

(2.2) 把**一个对角元**上界成**另外两个对角元之积**。要得到 `|ε_T| ≤ (小)^T` 需要的是 `⟨v|T_D|v⟩ ≤ (小)^{|D|}`，即**逐类范数界**；`‖T_D‖` 是独立输入（= 活动度 `u^{|D|}`），**正性不供给**。⇒ C–S 只能把「小」当**假设**用，不能当**结论**产。同判词：`INEQ-R6-4pt-ward.md:13`；`P4-OTHER.md:123`。

### (P3) ★ 正性止步于 `log` —— 这是决定性的 `[T]`

`ε_T` 定义在**对数**上（`W02-L1.md:78` L1-b 逐字）：

```
log Z_dec(B_T) = φ_dec·T + log D_∞ + ε_T ,  ε_T = Σ_{Γ 跨端点} φ^U(Γ)      (2.3)
```

`φ^U` 是**连通（Ursell）系数**，是交错和（`P4-OTHER.md:145` 逐字「Ursell 系数有符号（`φ^U` 是交错和）⇒ 拿不到」）。
`T_D ⪰ 0` ⇒ `tr T_D ≥ 0` ⇒ `W(𝔇) ≥ 0` ⇒ `Z_dec ≥ 1` ⇒ `log Z_dec` **超可加** ⇒ 只给**下侧**

```
log Z_dec(B_T) ≥ φ_dec T + log D_∞     （⇒ D_∞ > 0，但常数不可控）        (2.4)
```

`ε_T` 是 (2.3) 的**双侧**残差 ⇒ 需要**上侧** `log Z_dec ≤ φ_decT + log D_∞ + Bū^T`。**正性给不出上侧**：`Z ↦ log Z` 不是正性保持的映射，`φ^U` 的号与 `W` 的号无函数关系。⇒ **正性对 `ε_T` 完全无话。**

> 净增（诚实记账）：(2.4) 把 `D_∞ > 0` 从 `P4-OTHER.md:145` 的「拿不到」升级为「可得、但常数不可控」。这**不是** `D_∞ ≥ ½`——`½` 要常数，常数要率。

### (P4) 率的两因子，正性一个都不供给 `[T]`

`W02-L1.md:79` L1-c 逐字：`|ε_T| ≤ B u^T` 靠 (i) 跨度⇒成本 ⇒ `u^{T-O(1)}`（L1-a，`[T]`）；(ii) **簇数 `≤ C^T` 须由 KP 的 `e^{α|γ|}` 权重吸收**。
(ii) 就是 `C·u < 1`，即 `ū = eΔC̄u < 1`（`A02:59`、`P6-SPEC:48`）。`C^T` 是**熵**，正性对熵无话。
⇒ `P6-SPEC §2` 的判词（环 2 = 环 3 = 同一不等式 `λ_aΦ<1`）**原样适用于 P6-1**：正性换掉的只是 (2.1) 的振幅，换不掉 `C^T`。

### (P5) 转移矩阵版的严格回答 `[T]`（逻辑）

设纵向转移矩阵 `T_dec` 已按 `e^{φ_dec}` 归一 ⇒ PF 给 `θ_1 = 1`、`θ_2 ≤ θ_1`。
**正性/PF 的天花板就是 `θ_2 ≤ 1`；率要的是 `θ_2 ≤ ū < 1`（严格、定量）。** 正性 + PF 是**等式型**工具（顶部本征值 = 1），严格隙是**定量**输入（需 aperiodicity/正性改善或显式范数界）⇒ 正性单独给不出隙。这与 `W02-L1.md:88` 所需引理的形式**恰好差一个 `<`**。

## §3 「无扭装饰」是什么 —— 语料里**两个**不同的「扭」

### (T-A) 几何扭（`W95A` 口径）`[T]`

`W95A-2PP.md:97–98` 逐字：`i=j` 项 = 直四壁管；`i≠j` 项 = 扭管（`12` 面源 → `13` 面汇，截面必须转向），成本 `≥4N_t+1`，`O(u)` 压制；`:83` 逐字「只进 `(1−O(u))`，**不改速率、不改 `w`**」。
⇒ 这个「扭」**没有符号问题**，已被 `O(u)` 吸收。若 `P6-1` 的「无扭」指它，则 (α) **平凡为真且无用**（几何扭从来不是 CP 的障碍）。

### (T-B) 配位扭（`P6-SPEC` 口径）`[C]`

`P6-SPEC:77` 逐字：「已知不定号来源：扭管/手柄的 **Weingarten 符号**（`T2`/`T6` 已记）」。
在 `U(N)` Weingarten 展开里，装饰类的两端指标配位是一个置换 `σ`：
- **无扭 = 恒等（非交叉）配位** ⇒ 收缩成 `tr(A†B)` 型 ⇒ 真 Gram ⇒ PSD；
- **扭 = 交叉（对换）配位** ⇒ `tr(AB)` 型，系数取 `Wg` 在对换分割上的**负号**（`Wg(2) = −1/(N(N²−1))`，标准 Weingarten 演算）⇒ 算子**不定号**。

⇒ **「无扭」的可用定义 = 恒等配位扇区**；`T_D ⪰ 0` 只在它上面成立，且**由构造成立**（Gram 阵定义即 PSD）。`P6-SPEC:74` 要求在 `L=1` 上机验——那是**核口径**，不是核定理。

**⚠ 口径警告（`[X]`）**：`P6-SPEC:75` 的 (β) 说「每单位长度多付 `≥1` plaquette」，**偏低**：按 `W95A:83,98`/`A02:59` 是 `≥4N_t+1`，即**每单位长度 ≥4**。这恰好与 `e^{−m₁} = u^{4}` 配对，所以 (β) 的算术在 `β=2.5` 上过得去（`u=0.3125`：`u⁴·8 ≈ 0.076 < 1`，`[E]`）；若按「≥1」写则 `u·8 = 2.5 > 1` **失败**。⇒ 修 (β) 的措辞，不是修它的数学。

## §4 判死线

### (a) 不触发 `[T]`/`[NG]`

正性 ⇒ 率，**结构性不可能**：(P2) 方向错、(P3) 止步于 log、(P4) 熵因子、(P5) PF 只给 `≤1`。四条互相独立，任一条单独就够。**无法逐字给出 (a) 的推导，因为它不存在**——不是"还没找到"。

### (b) 触发（主判）`[T]`

正性的全部产出是**三件单侧/定性物**：
1. 振幅地板 (2.1)（`ν`-盲、`T`-无关）；
2. `D_∞ > 0`（常数不可控，(2.4)）；
3. 截断可证性（有限 `K` 上 `A ≥ ⟨v|T_{|D|≤K}|v⟩`，无需率）——这条**确有价值**，但给的是「可算」不是「收敛」。

**而 `ε_T` 的一个字都没得到。** ⇒ **(b)**：正性只给不等式，不给收敛率。

### (c) 与 `f03`/`W4` 的 7.1% 负模：**不逻辑冲突，但是 scope 冲突** `[T]`(证据)/`[C]`(归属)

证据逐字（`unconditional/W4-blocked-positivity.md:11`，表首行）：SU(2) `β=2.5`，`full Q⊥ trans neg = 7.1% (−0.82)`，且「negative modes are **not pure gauge**」。
- **不冲突**：`P6-1` 的 (α) 只断言**无扭类**（(T-B) 的恒等扇区）；7.1% 负模住**横向磁/交叉扇区**，正是 (β) 明文允许**不定号**的那一部分。⇒ 逻辑上相容。
- **但是 scope 冲突（真正的杀伤）**：7.1% 证明了**任何把 (α) 扩到全部 `D` 的版本为假**。所以 (β) **必然承重**；而 (β) 是**率论证**（每单位长度成本 ≥4、`e^{−m₁}=u⁴`、熵因子）⇒ 回到 `ū<1` 或回到 (P4) 的 `C^T`。⇒ **P6-1 想省的 `ū<1`，在 (β) 处以「按长度计的熵」形式原样回来。** 这正是 `P6-SPEC §2`「环 2 = 环 3」的第三次出现。
- **酸测附判** `[T]`：`P6-1` 的产出 `A ≥ a₀ > 0` **对自由场也成立**（`f₁²=0` 时振幅地板照样被满足）⇒ **过不了酸测**（charter §1）⇒ 不能单独当 `I1` 用，与 `P6-SPEC:78`「不许把 `(P6-1)` 单独当 I1 用」一致，此处给出**独立理由**（`ν`-盲），不只是设计约定。

## §5 路径

1. **不要把正性用在率上**（§4(a) 四条）。任何「正性 ⇒ `|ε_T|≤Bū^T`」的写法都是 (P2) 的方向错误。
2. **正性的正确用途（唯一净增，记在账上）**：
   - `D_∞ > 0`：从「拿不到」（`P4-OTHER:145`）→「可得、常数不可控」（(2.4)）`[C→T 半格]`；
   - 振幅地板免率（(2.1)）+ 截断可证（有限 `K` 机验）；
   - **仍不给 `D_∞ ≥ ½`、不给 `A ≥ ¼(2N)^{-2}` 的数值**（常数 = 率）。
3. **要 `D_∞ ≥ ½` 只有两条**：(i) 原 `(L1)` 的 `ū<1`（`W02-L1:79`）；(ii) 独立算出 `φ_dec`、`D_∞`（语料无候选）`[O]`。
4. **所以 P6-1 不扩窗**：窗仍由 `λ_aΦ<1` 定（`P6-SPEC §2`，`[T]`/`[NG]`；窗 `≤0.006661`–`0.018394`，`P6-SPEC §5`）。
5. **下一个可执行步（不改判词也能做）**：`P6-SPEC:125` 的 (α) 机验仍值得做——但验收目标要改写为「**恒等配位扇区 PSD 且对换扇区取负号**」，**不是**「CP 正性 ⇒ 率」。这是把 (α) 从「路」降格为「口径核定」`[X→C]`。
