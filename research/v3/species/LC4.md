## 2 · 增长位置数（第二问，本文件主结果）

### 2.1 单片层面

* 每片邻居 **恰 20**（`[T]`，§1）。
* 新加一片能带来的**新**增长位置 ≤ `20−1 = 19`（父片那一格已占）。

### 2.2 整只动物层面：`b(A)` 的**精确恒等式与上界**

```
b(A) := |∂A| = #{ q ∉ A : q 与 A 相邻 }                    （= "增长位置数"）
b(A) = |∪_{p∈A} N(p)| − n  ≤  20n − 2|E(A)|  ≤  18n + 2      [T]
```

中间一步：`Σ_{p∈A}|N(p)| = 20n = 2|E(A)| + b(A) + (撞车数，≥0)`；最后一步用 `A` 连通 ⇒ `|E(A)| ≥ n−1`。**`18n+2` 在 `n≥3` 已 >48，与 48 无关。**

**实测（`lc4_growth.log`，全枚举，无抽样）** `[E]`：

| `n` | `a_n` | `mean b` | `max b` | `min b` | `Σ b` |
|---|---|---|---|---|---|
| 1 | 1 | 20.0000 | 20 | 20 | 20 |
| 2 | 20 | 32.4000 | 34 | 32 | 648 |
| 3 | 458 | 44.0437 | 48 | 39 | 20 172 |
| 4 | 11132 | 55.3719 | 62 | 46 | 616 400 |
| 5 | **280175** | **66.5286** | **76** | **49** | 18 639 660 |

⇒ **平均增长位置从 `n=4` 起已 `>48`（55.37）；`n=5` 起连最小值也是 `49>48`；而 `n=3` 的最大值恰为 `48`（数值巧合，见 §4）。**
⇒ **"一个 `n` 片动物能加多少片"的答案随 `n` 线性涨（`mean b ≈ 11.1/步`），`48` 不是任何 `n≥4` 的逐动物界。**

### 2.3 为什么"逐动物增长位置数"这条路**结构性地**证不出 `λ_*≤48`（`[T]` 的 no-go，方法层）

**精确恒等式（本轮核心，`[T]`，`n=1..4` 逐位数值验证 `OK`）**：

```
Σ_{A∈𝒜_n} b(A)  =  Σ_{B∈𝒜_{n+1}} m(B),      m(B) := #{ p∈B, p≠x₀ : B∖{p} 连通 }
⇒  a_{n+1}/a_n = mean_{𝒜_n} b / mean_{𝒜_{n+1}} m                    [T]
```

验证（全部**整数相等**，`[E]`）：`20=20`（`m≡1`）· `648=648`（`mean m=1.41485`）· `20172=20172`（`1.81207`）· `616400=616400`（`2.20005`）。

**判（方法层 no-go，`[T]`）**：恒等式说 `a_{n+1}/a_n` 是**两个都在涨的均值之比**（`mean b: 20→66.5`，`mean m: 1→2.58`）。任何"逐动物增长位置 ≤ C ⇒ 比 ≤ C"的论证要 `sup_n max_A b(A) ≤ C`，而 `max b ≥ 18n+2` 无界 ⇒ **"增长位置数"这条账给不出任何常数上界，更给不出 48。** 反过来，"`m(B)≥1`"只给 `a_{n+1}/a_n ≤ 18n+2`（随 `n` 发散，`λ_* ≤ lim (18n)^{1/n} = 1`，空洞）。

### 2.4 25.7 能不能推广（第三问）

**不能，方向反了**（`[T]` 逻辑）：
