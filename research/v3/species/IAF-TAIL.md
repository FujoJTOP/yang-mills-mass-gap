## §1 段间形（L1–L5）

```
(L1) 记 ε(β,L):=ε(β,a(β),L)，e(β):=inf_L ε(β,L)，ε₀:=e(2.5)，B:=ln(ε₀/w₀)。
     尾段靶 ⟺ e(β) ≥ w₀ ∀β≥2.5（R5_* 取 β₀=2.5，HZV §0.5）。                      [T]

(L2) 线性形 no-go：设 ε(β') ≥ ε(β)(1−c(β'−β)) ∀β'≥β≥2.5，c>0。
     Δβ ≥ 1/c ⇒ RHS ≤ 0 < ε(β') ⇒ 该格对任意正函数成立 ⇒ 零信息。
     强令全射线因子 >0：常数 c ⇒ c≡0（ε 非降 = β-单调，严格强于靶且无定理）；
     c=c(β)>0 ⇒ 需 Σc<∞，此时已不是线性链，而是 (E) 的积分形（L4）。               [T]
     ⇒ 有限分割的末格 [b_{N−1},∞) 无界 ⇒ 同一句：线性段间式打不通尾段。

(L3) 积分形（够）：在 ε>0 处 ε(·,L)∈AC_loc（固定 (L,a) 实解析 V02:107–113；零点孤立
     V02:110–111），∃c∈L¹([2.5,∞),[0,∞)): ∂_β ln ε(β,L) ≥ −c(β) a.e.，C:=∫_{2.5}^∞ c。
     ln ε(β,L) − ln ε(2.5,L) = ∫_{2.5}^β ∂_β ln ε ≥ −∫_{2.5}^β c ≥ −C
     ⇒ ε(β,L) ≥ ε(2.5,L)e^{−C}。若 ε(2.5,L) ≥ ε₀ ∀L 且 C ≤ B ⇒ e(β) ≥ w₀。
     （乘性形 (E₊) 不需要 AC/对数，见 §2；两者在 ε>0 处等价。）                        [T]

(L4) 段数不入判：迭代 (L2) 给 ∏(1−c_n)；∏>0 ⟺ Σc_n<∞（c_n<1），与 N 无关。
     且 ∏(1−c_n) ≤ e^{−Σc_n}（(1−½)²=0.25 < e^{−1}=0.3679）⇒ 线性截断更亏。
     正 cocycle 通形 = 比值 Φ(β,β')=g(β')/g(β)（可复合 + 正）；取 g=e^{−∫c} 即 (E)；
     线性形不满足 cocycle 方程（(1−ca)(1−cb)=1−c(a+b)+c²ab）。                    [T]

(L5) 段≠射线：有限分割的前 N−1 格是紧格（Heine–Cantor 可用），末格是射线；
     尾段全部量词内容落在末格（同 HS-GAP-8 §0.12）⇒ 紧段引理对末格不适用。         [T]
```
