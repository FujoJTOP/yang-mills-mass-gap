## §1 定义裁定（先裁口径，再谈算法）

### 1.1 仓内 `κ_c` 只有一个语义，但有**两条不等价的归一化**

| 版本 | 出处（逐字行） | 公式 | 语义 |
|---|---|---|---|
| **V-A**（比值/每块根） | `handoff-proof/CPBW-bianchi-lemma.md:40`；`BianchiLemma.md:209`（T1）；`BREAK-IN-3.md:5`；`research/v3/species/GU3-ACTIVITY.md:288` | `κ_c(n) := (z_signed/z_abs)^{1/n}` | 每块（每单位边界面积）**权重**抵消因子 |
| **V-B**（指数/每块抑制） | `CPBW-bianchi-lemma.md:22`；`BianchiLemma.md:120` | `κ_c := e^{−δ}`，`δ = ln(1/κ_c)` 是每块额外抑制 | 同上，但写成**指数率** |

**裁定（本文件口径，此后不再变）：**
1. **报表用 V-A**（与 `BREAK-IN-3` / `GU3` 一致），因为可算。
2. **判据必须用 V-B 的指数形式**，即 `z_signed/z_abs ≤ κ_c^{\,n}`（`n = |C₀|`）。理由见 §1.2：V-A 的 `n` 次根会把任何 O(1) 比值压成 `→1`，**使判据恒真**。
3. **`n` 钉死为边界面积 `|C₀|`**（B2 字面，`CPBW-bianchi-lemma.md:38`），**不是壳层截断**。§3 给两列换算。
4. **V-A 与 V-B 在假设 ① 下不相等**（§1.2）：V-B 恒为 `δ=0`（`κ_c=1`），V-A 是 O(1) 比值的 `n` 次根。`BREAK-IN-3.md:11` 的 `1.000000000000` 是**两版重合的退化点**（那里 `z_signed=z_abs` 精确）。

### 1.2 为什么 `κ_c(n) := R_n^{1/n}` 在 `n` 小时没有判别力（`[T]` + `[E]`）

设 `R_n := z_signed(n)/z_abs(n) ∈ (0,1]`。若 `R_n` 有**正下界**（不随 `n` 指数衰减），则 `κ_c(n) = R_n^{1/n} → 1`。于是：

```
判据 "κ_c ≥ 0.81"   ⟺  R_n ≥ 0.81^n  （对 n 指数小的要求）
判据 "κ_c ≤ 0.80"   ⟺  R_n ≤ 0.80^n
```

**⇒ 真正的判据是 `R_n ≟ 0.8^n`，不是 `R_n ≟ 0.8`。** 表 §3.2 的 `R/req` 列就是这个比：`R_6/(0.8^6) = 3.04`（SU(3)）/`3.45`（SU(2)）—— 差 3 倍**指数距离**，不是差 20%。

**⇒ 一个可当场演示的伪信号（§3.3）**：`n=2` 时 `R_2 = |1−20u|/(1+20u)`，在 `u* = 1/B_2 = 0.05` 处**精确归零**（完美"抵消"）。`u=0.04` 处 `κ_c(2)=0.333`、`κ_c(4)=0.385` —— 全都 `<0.80`，全部是**低阶偶然抵消**，与机制无关。任何把 `n≤3` 的 `κ_c` 直接喂进 0.81/0.80 判据的做法都会得到假信号。

### 1.3 "无直接数值通道"这句话的准确范围（本条是回填建议）

`BREAK-IN-3.md:18` 与 `lattice-cpb/STATUS.md:46`（`REPORT.md:784`）逐字是"`κ_c` has no direct numerical route"，**理由给的是**"`w_q(C)` 是阻塞有效作用量的 polymer 系数，MC 只返回关联函数"。裁定：

- 该判词对**带号泛函**这一层**不成立**：只要记号住在 `n` 上，`z_signed/z_abs` 就只是 `{m_n}` 的交错部分和，**不需要** `w_q` 的逐项值，只需要**壳质量**；而壳质量正是 `gv1`/`ur1_enum.py` 已经在算的东西。

### 1.4 命题（交错号只给 O(1) 增益 ⇒ B2 的 `κ_c<1` 与 `c₀q≥γ_ent+ln3` 冲突）

> **命题 AS（Alternating-Sign）。** 设
> (i) `sign(w(C)) = σ(|C|) ∈ {±1}`（号只依赖片数，假设 ①）；
> (ii) 双侧权标度：`e^{−c₀q|C|} ≤ |w(C)| ≤ e^{−c₀q|C|}` 的首项（即最小曲面 `C₀` 自身的质量 `A₀ ≥ e^{−c₀q|C₀|}`）与上界；
> (iii) 熵：`#{C : ∂C=∂C₀, |C|=|C₀|+j} ≤ e^{γj}`，`γ := γ_ent`，**对一切 `|C₀|` 一致**。
> 记 `ρ := e^{γ−c₀q} < 1`。则
> ```
> |Σ_{∂C=∂C₀} w(C)| ≥ A₀ − Σ_{j≥1}A_j ≥ e^{−c₀q|C₀|}·(1 − ρ/(1−ρ)) .
> ```
> 故 **`c₀q ≥ γ_ent + ln 3`（即 `ρ ≤ 1/3`）⇒ `|Σw| ≥ ½·e^{−c₀q|C₀|}` ⇒ B2 只能以 `κ_c=1` 成立。**
>
> **证明（三行）。** 由 (i)，`Σ_{∂C=∂C₀}w(C) = Σ_j (−1)^{σ(·)}A_j`，各项号只随 `j` 翻转；由逆向三角不等式 `|Σ_j(−1)^jA_j| ≥ A₀ − Σ_{j≥1}A_j`；由 (iii)+(ii) 上界，`Σ_{j≥1}A_j ≤ Σ_{j≥1}e^{γj}e^{−c₀q(|C₀|+j)} = e^{−c₀q|C₀|}ρ/(1−ρ)`。合并即得。∎

**等级 `[T]`（条件于 (i)(ii)(iii)）**；其中 (i) 是 `[E]`(n≤6)+`[C]`(一般 `n`)，(ii) 是语料自己的 `|w(C)|~e^{−c₀q|C|}`（`CPBW-bianchi-lemma.md:13`）的两侧读法，(iii) 是 `BianchiLemma.md:39` 的 `N(n)≤e^{γ_ent n}`。

**⇒ 判：** `κ_c<1` 的唯一存活区间被压成一条**等式约束**：
```
κ_c < 1  ⟺  1 − ρ(n) ≲ κ_c^{n}   （无号装饰质量必须临界到指数精度）
```
这就是 §0 的 **O3**。**这不与 `CPB-S` 需要的 `c₀ ≳ 2.6` 冲突** —— 恰恰相反：`CPB-S` 的窗口（`BianchiLemma.md:117`：`γ_ent=1 ⇒ c₀≥2.60`）**自动满足** `c₀q ≥ γ_ent+ln3 ≈ 2.10`，所以**在 `CPB` 自己需要的窗口里，B2 的 `κ_c<1` 被 AS 排除**。
