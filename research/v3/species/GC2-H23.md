## §3 `H2` 的正确形式：从"退化等式"到 `(c₀q,c₁,c₂)`，并改写 `H4` 的常数

### 3.1 字面式为什么不是"弱"，是"假"

**逐字（`GV2:75`，命题 AS 的 `(ii)`）：** `e^{−c₀q|C|} ≤ |w(C)| ≤ e^{−c₀q|C|}` 的首项…与上界。
左右两端**同一个式子** ⇒ 作为不等式链只蕴含**等式** `|w(C)| = e^{−c₀q|C|}`。三条立即的后果：
1. **等面积的不同曲面权重必须相等**——而 `GV2:217` 自己的 `β=2.5` 特征标系数给出每片因子 `0.217`（`c_(1,1)/c_(0,0)`）到 `0.496`（`c_(1,0)/c_(0,0)`），**同片数、不同表示标签下差 2.3 倍**。⇒ 字面式在仓内已有数据上就假。
2. **它把 `R` 强行钉成 1**：逐曲面严格等于同一指数 ⇒ 首项与尾项的幅度比恒为 1（`R=1`）⇒ `H4` 的常数自动落到最好情形 `ln3`。而这张等式在等面积上假（第 1 条）⇒ **字面式要么假、要么（若读成"至多差常数"）它已经偷设了 `R=1`，而那正是 §3.3 里最有利的一格。** 两条都不是"弱"，是"把答案预设进去了"。
3. 所以它不是"写得松"，是**写得紧到假**。`GP9 §1.2` 把它记为 `[M]` 转录缺陷，方向对；本轮补的是**它同时污染了 `H4` 的常数**（§3.3）。

### 3.2 非退化形式（本轮钉死的内容）

```
(H2)  ∃ c₀>0, q>0, 0 < c₁ ≤ c₂ < ∞   （全部与 β、块尺度 a_k、|C₀| 无关）
      ∀ 边界 ∂C₀, ∀ C with ∂C=∂C₀ :
            c₁ e^{−c₀q|C|}  ≤  |w_q(C)|  ≤  c₂ e^{−c₀q|C|}
      记 R := c₂/c₁ ∈ [1,∞)
```
**它到底在说什么（四条，缺一不可）：**
1. **率两侧相同**：`−ln|w_q(C)|/|C| → c₀q` **从两侧**，且极限与 `C`、与 `∂C₀`、与 `|C₀|` 无关。这是"面张力有极限、且首项不异常"的联合陈述。
2. **上界侧 = "没有比 `c₀q` 更便宜的曲面"**（作用量语言：`σ(C) ≥ c₀q|C|`）。这是**禁止竞争曲面**的那一侧，也是 `BL-3` 平板直接威胁的那一侧（§3.5）。
3. **下界侧 = "首项不比率更重"**（作用量语言：`σ(C₀) ≤ c₀q|C₀|`）。它禁止 `A₀` 指数小。
4. **`R` 必须有限**：这正是 `GP9 §2.2-2` 里那个 `P` 的**同一格**（见 §3.3）。**没有 `R<∞`，`AS` 的几何尾不收敛。**

### 3.3 ★ 新算：`AS` 的门常数是 `ln(1+2PR)`，`ln3` 只是 `(1,1)` 切片

**命题（本文件新增，三行证明，`[T]` 条件于 `(H2)+(H3)`）：** 设
```
(H2)  c₁ e^{−c₀q|C|} ≤ |w_q(C)| ≤ c₂ e^{−c₀q|C|}
(H3)  #{C : ∂C=∂C₀, |C|=|C₀|+j} ≤ P e^{γj}     （P 与 |C₀|、j 无关；P≥1）
```
则对每个 `∂C₀`：
```
|Σ_{∂C=∂C₀} w| ≥ A₀ − Σ_{j≥1} A_j
                ≥ c₁e^{−c₀q|C₀|} − P c₂ e^{−c₀q|C₀|} Σ_{j≥1} ρ^j ,     ρ := e^{γ−c₀q}
                = e^{−c₀q|C₀|} [ c₁ − P c₂ ρ/(1−ρ) ] .
