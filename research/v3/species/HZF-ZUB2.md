## §1 积分表示（三行恒等 + 两条核界）

```
O_x := δ_a trF²(x) = a^{-4} q_x ,   q_x := 1 − N^{-1}Re tr U_□(x) ∈ [0,2]          (HZ6-ZDEF:23)
φ_B := ⨏_B O = a^{-4} N_B^{-1} Σ_{x∈B} q_x ,   N_B = |B|_latt = (b/a)^4          (块取物理尺度 b)

(1.1)  Z_a = Var(φ_B) = Σ_{x,y∈B} w(x)w(y) C_q(x,y) ,  w ≡ 1/N_B ,  C_q(x,y) := ⟨q_x q_y⟩_c
           = a^{-8} N_B^{-1} Σ_z n_B(z) C_q(z) ,   n_B(z) := #{x : x, x+z ∈ B} ≤ N_B
           = a^{-8} · N_B · Var_μ( ⨏_B q )    （≡ a^{-8}·ϖ_B，ϖ_B := N_B Var(⨏q) 为无量纲块方差比）
       ⇒ Z_a ≤ a^{-8} N_B^{-1} Σ_{|z|_∞<b̂} |C_q(z)|        （n_B 窗外恒 0：只吃**窗口和**）

(1.2)  KL：  C_q(x,y) = ∫_{[0,∞)} K_m(x−y) dρ(m) ,  ρ ≥ 0 ,  K_m ≥ 0 ,  K_m(0)=1     (IMP-ARROWS:58)
       ⇒  Z_a = ∫ G_B(m) dρ(m) ,   G_B(m) := Σ_{x,y∈B} w(x)w(y) K_m(x−y) ∈ (0,1]

(1.3)  G_B(0)=1 ;   m ≤ 1/(2b̂)  ⇒ G_B(m) ≥ e^{−1/2} = 0.6065
       m ≥ 1/b̂ ⇒ Σ_{z∈Z^4} e^{−m|z|_∞} = coth(m/2)^4 ⇒ G_B(m) ≤ coth(m/2)^4/N_B ≤ 21.93/N_B

(1.4)  靶 ⟺ 谱权界：   Z_a ≤ C a^{-4}   ⟺   ρ([0, c/b̂]) ≤ C·b^4      (c=1/2；由 1.3 两界夹出，模常数)
                     （下侧精确：Z_a ≥ e^{−1/2}a^{-8}N_B^{-1}ρ([0,c/b̂])；上侧尾部 ≤ a^{-8}N_B^{-1}·21.93/N_B，吸收进常数）
```

**读法。** `Z_a` 不是"期望×体积"，而是**块核 `G_B` 对正测度 `ρ` 的加权平均**。`G_B(m)` 是"块内两点的相干度"：慢模（`m≲1/b̂`）整块相干 ⇒ 权重 `O(1)`；快模（`m≳1/b̂`）只在 `O(1/N_B)` 的份额上相干。于是 `Z_a` 的**全部** `a`-内容就是 `ρ` 在 `[0,c/b̂]` 上的质量。这不是隙（`1/b̂` 以上任意谱都允许），但它是**单行、无 `a`、可算**的一条——本路真正的产出。

## §3 判定

**3.1 判 `[NG]`。** 不能 `[T]`：本路把靶化到一条干净的输入（1.4），但该输入是 `ρ` 的**低端质量上界**，仓内与文献都没有；相反的输入（`ρ≥0`）有，且方向错。

**3.2 具名障碍：谱正性单侧障碍（KL/OS 正性只给 `ρ≥0`）。**
形如：`Z_a≤Ca^{-4} ⟹ ρ([0,c/b̂])≤Cb^4`（1.4 下侧，精确），而 RP 的全部定量输出是 `ρ` 的**非负性**与 `m_eff↑`；`ρ≥0` 与"`ρ([0,c/b̂])` 小"**相容亦可反**，no-go `OS-正性 ⊬ 指数衰减`（`e^{−√R}`）给出同一机制的显式见证。⇒ 本路不是"没算完"，是**缺一类输入**（谱权上界），且该类输入已在仓内被具名判为 RP 不可供。

**3.3 下一手（三条，按性价比）。**
1. **（判决性，零 MC）** 用自由 Maxwell 的显式 `C_q(z)` 算 `ρ([0,c/b̂])`。若自由场已给 `≫ b^4`，则**字面归一读法（`δ_a trF²=a^{-4}q`、`N_B=(b/a)^4`）下靶为假**——那是比 `[NG]` 更强的结论，且一次闭式求和即定。若过，则本路剩下的只是 3.3②。
2. **（可证形）** 攻加权版：`ρ([0,c/b̂]) ≤ Cb^4` 只要"块尺度以下无大权重"，比逐对指数衰减弱；与 `W`/`B1^rate` 同址（`HW3-WRENAME:13` 判 `W` 为**换名格**）⇒ 立项必须写明"只付加权、不付逐对"这一格差，否则重复计数。
3. **（并账）** 把（1.1）的窗口 `ℓ¹` 形与 `COV-T:92` E5 的"行和衰减 = 有限关联长度"并成本路台账的一行；两者是同一物的两个坐标（`COV-T` 判它对 `Q(∞)` 不需要，但对**本靶**正是所需）。
