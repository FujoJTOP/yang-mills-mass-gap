## 1 · ① 量纲：`f₁²` 是量纲量，且语料有**三套** `d`

### 1.1 对象

| 量 | 定义 | 量纲 |
|---|---|---|
| `O(x)` | `¼tr F²(x)`（`ch05`；本任务算符） | **mass⁴**（`F` 是 mass²）`[T]` |
| `f₁²` | `\|⟨Ω\|O\|𝔾⟩\|²`（模方，`T02-F1SQ.md:17`） | **mass⁸** `[T]`（`(mass⁴)²`） |
| `M₀` | `∫dν = Var_Ω(O) = C(0) = ‖(1−P_Ω)OΩ‖²`（`B06-VAR.md:43`） | 与 `f₁²` **同量纲**（同一个测度的原子/总质量）`[T]` |
| `w₁` | `f₁²/M₀` | **无量纲**、`Z_O`-不变、标度不变（`B04.md:34`、`U4:88–90`）`[T]` |
| `m₁` | `inf supp ν`（`s₁=m₁²`） | **mass¹**（`m₁²` 是 mass²）`[T]` |

**⇒ 第 1 问的答案**：`f₁²` 是**量纲量**（`mass^d`，`d=8` 在 `O` 未归一的口径下）。它**不是**无量纲数，
所以"`f₁² ≥ c`（`c` 纯数）"这句话只有在**固定单位**（格点单位 / 固定 `a`）下才有意义，
一旦沿 `β→∞`（`a→0`）走，右端的**单位本身在变**——这就是整个问题的根源。

### 1.2 ★ 三套记账（这是 (c) 的触发点，也是 `c'` 的唯一不确定性）

| 口径 | `d` | 出处 | 对 `c'` 的影响（SU(3)） |
|---|---|---|---|
| `\|⟨Ω\|O\|𝔾⟩\|²`，`O` dim 4 | **8** | `T02-F1SQ.md:17`、`A2-SUMRULE-CONDENSATE.md`（"`O(x):=¼trF²(x)`, **dimension 4**"） | `9.5705` |
| KL 测度的原子 `ν({m₁²})` | **6** | `A2-SUMRULE-CONDENSATE.md` 逐字："`ν` … a **dimension-6** measure; atom `f₁²:=ν({m₁²})`, **dimension 6**" | `7.1779` |
| `ch05` 的算符归一版 | **2** | `A2` 同处逐字："`ch05-theorems.tex` writes `f₁²=\|⟨Ω\|O\|G⟩\|²` and uses it in the squeeze `f₁²/χ ≤ m₁²`, i.e. with the operator normalized so `f₁²` has dimension **2**" | `2.3926` |

**这三套都自洽（各自把 `χ`、`M₀`、`s` 的量纲一起调），但只差一个**常数**因子；而 `β`-标度的**指数**
`c' = d·12π²/(11N²)` **直接乘 `d`** ⇒ 三套给三个**不同**的尾端速率（差 `4×`）。
**⇒ "量纲是全部"在这里是字面真的：`d` 不是记账细节，`d` 就是尾端消失的速率。**
`[M]`（必须先钉一套；本轮不钉，只把三种都算出，见 `i04_dim_beta.log [B]`）。

## 2 · ② `f₁²` 的 `β` 标度：`a(β)^d`，随 `β` **指数降**

### 2.1 恒等式（`[T]`，一行）

```
f₁²_lat(β) = a(β)^d · f₁²_phys ,   f₁²_phys := 物理单位下的矩阵元平方（dim d，a-无关）
⇒ 格点单位下 f₁² 的全部 β 依赖 = 单位换算 a(β)^d（外加 γ_O 的对数跑动，见 §2.3）
```

### 2.2 `a(β)` 的两圈式（`[C]`，`G05-BETAOFa.md:69–77`、`B08.md:26`）

```
aΛ_lat = exp[−12π²β_W/(11N²)]·(g²/16π²)^{51/121}·[1+O(g²)]
⇒ f₁²_lat ∝ exp[−(d·12π²/(11N²))·β_W]  ⇒  c' = d·12π²/(11N²)
```

**`[E]` 本轮实算**（`i04_dim_beta.log [A]`：两圈 `aΛ` 的数值对数斜率）：

| `N` | `β_W` | `dln(aΛ)/dβ` | 极限 `−12π²/(11N²)` |
|---|---|---|---|
| 2 | 2.5 | −2.8603 | −2.6917 |
| 2 | 10 | −2.7339 | −2.6917 |
| 2 | 100 | −2.6959 | −2.6917 |
| 3 | 2.5 | −1.3649 | −1.1963 |
| 3 | 10 | −1.2385 | −1.1963 |
| 3 | 100 | −1.2005 | −1.1963 |

⇒ 斜率**从上往下**收敛到 `−12π²/(11N²)`（两圈的 `51/121` 幂次贡献一个 `1/β²` 尾巴），
与解析式一致。于是 `f₁²_lat` 的指数是它的 `d` 倍：

| `d` | `N` | `c' = d·12π²/(11N²)` | `f₁²(2.5)/f₁²(6.0)`（`[E]`） |
|---|---|---|---|
| 2 | 2 / 3 | 5.3834 / 2.3926 | 1.5e+8 / 4.3e+3 |
| 6 | 2 / 3 | 16.1503 / 7.1779 | 3.5e+24 / 8.1e+10 |
| **8** | **2 / 3** | **21.5337 / 9.5705** | **5.4e+32 / 3.5e+14** |

**⇒ `c(β)` 是 `e^{−c'β}` 型（分支 ②），不是 ① 也不是 ③。** `[C]+[E]`

### 2.3 对数跑动不改结论（`[T]`）

`Z_O` 只给多指数修正：`f₁²(μ)=Z_O²f₁²(μ₀)`、`γ_O=2b₀g²+⋯`（`U06-ZO.md:15,49`）⇒ `f₁²_phys(β)` 有
`[1+O(g²)]` 的**对数**修正，压不过 `e^{−c'β}`。**根数不变。**

## 3 · ③ 题目第 3 步的符号错误：`w₁` 标度不变**不**蕴含 `f₁² ~ a^{−8}`

题目原链：`w₁=f₁²/M₀` 标度不变 ⇒ `f₁²` 与 `M₀` 同标度 `~a^{−8}` ⇒ `f₁² ~ a^{−8}w₁` ⇒ `f₁²` 随 `β` **升**。

**逐环核**：

| 环 | 判定 | 依据 |
|---|---|---|
| `w₁` 标度不变（`γ_{w₁}≡0`） | **真** `[T]` | `B04.md:34`、`G04.md:135–136`（`2γ_O−2γ_O≡0`）、`U4:88–90` |
| ⇒ 分子分母**同量纲** | **真** `[T]` | 同一测度 `ν` 的原子与总质量（`B06-VAR.md:43`）⇒ 都 `mass^d` |
| ⇒ 二者同标度 = `a^{+d}`（格点单位） | **真** | 单位换算；`d>0` ⇒ 都是 `a^d`，**同号同幂** |
| ⇒ 二者同标度 = `a^{−8}` | **假（符号反）** | `a^{-8}` 是 `M₀^{bare}` 这个**接触项**在**物理单位**下的 UV 发散；换到格点单位就是 `a^8·a^{-8}=O(1)`（`[E]`：`U06-ZO.md:107` 的 `⟨O⟩a⁴=1−⟨P⟩=0.36` 就是 O(1) 的裸数） |
| ⇒ `f₁²` 随 `β` 升 | **假** | `f₁²_lat = a^d·f₁²_phys`，`d>0` ⇒ **降**。语料同向：`w₁^{bare}=f₁²/M₀^{bare}→0` 而 `M₀^{bare}` 是 O(1) 裸数 ⇒ **分子**必须是那个 `→0` 的（`G04:133`、`U07:46`、`U12-C0VAR:64`）`[T]` |

**⇒ 一句话**：`a^{−8}` 属于 `M₀^{bare}` 的**接触项**，且只在**物理单位**下成立；把它搬到 `f₁²` 上，
就同时错了对象和单位。语料 [T] 级的 `w₁^{bare}→0` 正是"分子降、分母不降"的直接证据。
⇒ **(a)（"f₁² 是 UV 量、随 β 升、地板免费"）不成立。**

## 4 · ④ 与 `m` 的关系（第 2 问）

```
m_lat(β) = a(β)·m_phys/Λ·Λ ...
实写： m_lat = aΛ(β)·(m/Λ)      ⇒  m_lat ∝ exp[−12π²β/(11N²)]·(m/Λ)      [C]（B08:80–84）
      f₁²_lat = a^d·f₁²_phys   ⇒  f₁²_lat ∝ exp[−d·12π²β/(11N²)]          [C]
⇒ f₁²_lat / m_lat^d ≡ f₁²_phys / (m/Λ)^d  —— 与 β 无关（只差 γ_O 的对数）  [T]
```

`[E]`（`i04_dim_beta.log [C]`）：取 `m/Λ=1` 时 `a^8/m^8 ≡ 1.000000` 于 `β=2.5/6/10` 三点（恒等）。

**⇒ 两个答案**：
1. **不是同标度**（幂不同：8 vs 1）⇒ 题目第 2 问的"若同标度"前提**不成立**；`f₁² ~ m⁸` 是正确关系。
2. **但方向相同**：`f₁²` 与 `m` 都随 `β` 指数降，`f₁²` 快 8 倍 ⇒ b08 的 no-go（"格点单位常数地板在
   `β→∞` 自否"）对 `f₁²` **原样成立**，只是把指数从 `1` 换成 `8`。**没有"免费的 UV 地板"这一支。**
