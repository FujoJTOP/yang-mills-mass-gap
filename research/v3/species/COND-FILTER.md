## 1. 形式化：目标、谓词、三种量词形式

### 1.1 对象与真值 `[F]`
```
𝓜      = 候选机制类；M ∈ 𝓜
ν      = 理论数据（格点测度 / 场空间 / 算子）
Φ_M(ν) ∈ ℝ ∪ {⊥}    M 在 ν 上的"声称下界"；⊥ = 不给数 / 无定义
γ*(ν)  = 真值（ν 的最优 LSI 常数，或 m_eff² 的真下界）；Gap(ν) :⟺ γ*(ν) > 0
ℱree   = 自由场参考类 = {同格点高斯测度族，m ≥ 0}；ν_free : m=0，γ*(ν_free)=0
𝒯_YM   = YM 参考类（β≈2.5 的物理点族）
```
**唯一目标命题 `[F]`**：
```
Goal :⟺ ∃M∈𝓜 ∃λ>0 ∀(L,a) ∀ν∈𝒯_YM :  Φ_M(ν_{L,a}) ≥ λ  ∧  Φ_M(ν_{L,a}) ≤ γ*(ν_{L,a})
```
`Goal` 的内核就是 `[M]` 那一条开不等式（`ch13`：the single open inequality）。**只有 `Goal` 可记分。**

### 1.2 五个谓词，量词写出来 `[F]`
```
P₁(M) :⟺ M 在 β≈2.5、g≈1.5 处不依赖收敛展开                         （非微扰）
P₂(M) :⟺ Φ_M 是下界且正（Pos ∧ Sound 在 𝒯_YM 上成立）                （控号下界）
P₃(M) :⟺ Hyp(M) ⊉ {Gap(𝒯_YM) ∪ Thresh ∪ Isolation}                  （非循环）
P₄(M) :⟺ [∃ν∈ℱree: Φ_M(ν) > γ*(ν)] ∨ [Φ_M 在 ℱree 与 𝒯_YM 上不可分辨]  （酸测 FAIL：误报或空转）
P₅(M) :⟺ P₂ ∧ 对一切 (L,a) 成立 ∧ a→0 极限存活                      （(L,a) 一致）
```
**集合包含（不是猜测）**：`P₅ ⟹ P₂`，即 `P₅ ⊆ P₂`。故 `C5 ⇒ C2`，**二者占一条轴**（`H1B-FIVE.md:88-97`）。

## 2. "过滤器"与"要证 `C3`"的区别：命令式 vs 陈述式

| | 过滤器（准入） | 命题（要证） |
|---|---|---|
| 逻辑类型 | 命令式 / 判定规则 | 陈述式 |
| 真值 | **无**（`PASS`/`FAIL` 是 verdict，不是 truth） | 有 |
| 证明负担 | **零**（只需给候选出一份证书） | 全额 |
| 可否部分满足 | **不可**：闸只有 `{PASS, FAIL}`，没有 3/5 个闸 | 可以（`[M]`→`[T]` 是整块） |
| 失败的含义 | **出局**（候选死） | 反例（理论错） |
| 通过的信息量 | 可以**完全无信息**（§3） | 必有信息 |
| 量词 | `P(M)`，per-candidate | `∀`/`∃`，about the world |

**一句话**：**"要证 `C3`"把 `C3` 放等号左边当目标；"过滤器"把它放等号右边当守卫。** 前者要求世界上的一个事实，后者只要求候选的一份证书。**守卫不能"被证"，只能"被违反"。**

**"要证 `C3`"的三种读法，逐条落空 `[F]`**：
1. `∀M∈𝓜: P₃(M)` —— **假**（四反例）；
2. `∃M: P₃(M)` —— **由 §3 的 `M^∅` 平凡真**；
3. `P₃(M₀)`（具体候选）—— **真但便宜**，且其内容侧 `s₂`（隔离）**就是 H1**（`ch13:509-513`）。
⇒ **没有一种读法给出"待证的第五分之一"**。这是 (a) 的形式证明。

**回答"可丢弃还是必须证"**：**都不是——必须*用***。不可丢弃（丢了 `C4` 就丢了唯一查出 `(TCI)` 空转的仪表；丢了 `C3` 就丢了族 47 的判词）；不可证（闸无真值，其 per-`M` 实例是**判词**不是**待办**）；只能用——**度量是收益率（杀死的族数 / 检出的空转数），不是真值。**

## 3. 加宽引理：`C3` 可"免费"通过 ⇒ 它不度量内容 `[T]`

**引理（加宽）** `[T]`。设 `M∈𝓜`，`s` 为 `M` 的决定性但不可算的输入。令 `M^∅ := M[s ↦ σ]`（把 `s` 换成自由参数 `σ`）。则
1. `P₃(M^∅)` 成立；
2. `Φ_{M^∅}(ν) = ⊥` 对一切 `ν ∈ ℱree ∪ 𝒯_YM`；
3. 故 `M^∅` 对 `Goal` 的贡献 = 0。
**证明**：假设集只增 `σ∈ℝ`，不增 `Gap`；`Φ` 含自由参数 ⇒ 不给数。∎

**推论 1 `[T]`**：`P₃` 在"内容严格递减"的加宽下**不变** ⇒ `P₃` 对内容不单调 ⇒ **`P₃` 不是进展的度量**。
**这不是假想**：`ch13:509-513` 的 `w₁ ≥ (s₂−Ē)/(s₂−s₁)` 正是 `M^∅` 形态——原文自评 "sharp and presupposing nothing, hence non-circular"，代价是 "the decisive input `s₂` is not computable"。**非循环是"把未知换成字母"买来的。**
**语料自己的同一观测** `[E]`：`BC-BETHE.md:199` 记 "3 非循环 **PASS（但空）**"——`PASS` 与"空"同时成立，正是本引理。

**推论 2（记分后果）`[T]`**：`M^∅` 得 `P₁`（不展开）+ `P₃`（不预设）= **2/5**，而 `Goal` 贡献 **0**。⇒ **"2/5" = 零内容**（`H1B-FIVE.md:104` 的警告，现在是推出来的，不是断言的）。

## 4. `C4`：定义，还是命题？

### 4.1 作为条件 = 定义 `[D]`
"酸测"的定义内容是：**一个在自由场上与 YM 上给同一个数的仪表，不叫仪表。** 定义式：
```
𝓜_adm := { M∈𝓜 : P₁(M) ∧ P₃(M) ∧ ¬P₄(M) }   ⇒   (∀M∈𝓜_adm) ¬P₄(M) 由定义真
```
`[T]` 平凡、**零证明负担**。**用户判死线里"`C4` 平凡"的那一半成立。**

### 4.2 作为命题 = 反证，per-`M`，已兑现 `[T]+[E]`
唯一非平凡形式：
```
P₄(M₀) :⟺ ∃ν∈ℱree : Φ_{M₀}(ν) > γ*(ν)      （误报：自由场上发出正证书）
        ∨  Φ_{M₀} 无判别力                 （空转：空量化 / 自由与相互作用同值）
```
| `M₀` | `P₄(M₀)` 的见证 | 出处 |
|---|---|---|
| BD/Polchinski-LSI | `Φ = N/4 = 0.75 > 0 = γ*_free`；"falsified pointwise for every `m<0.866`" | `ch13:291-296` |
| `(TCI)` | `Hess V=(k²+N/12)𝟙>0 ⇒ ℋ₋={0}` ⇒ **对空集量化**；`λ_min=1.1667, 0.2567, 0.1767, 0.1667` | `ch13:526-530` |
| NOSUB | `0.20512 > 0` 而 `f₁²=0`；"collapses to `NOSUB≡G''` … dying exactly where H1 dies" | `ch13:683-685` |
| `u`-完备性（族 51） | 闭聚合物最小 `|X|=6` ⇒ `|X|=1` 的估计**描述空集** | `LOOP-RUNBOOK.md:1130` |

⇒ **`C4` = 定义 + 已兑现的 per-`M` 反证；不是"待证的全局条件"。** `P₄(M₀)` 的真是**该候选的死因**，不是目标的进展。

### 4.3 极性：失败是产出，通过是"无事发生" `[F]`
记分表把 `C4: FAIL` 记作失分；但 `ch13:299-300` 原话是 "it is now a failure **with a computed location**. Every route … is therefore closed, and the closing is **arithmetic**"——**那是交付**。反之"过酸测"只说明"还没被抓到"，零信息。**闸的符号与命题相反：命题 PASS 是好消息，闸 PASS 只是没消息。**（`LF-LASTFOUR.md:182` 在存活账上的同一读数："方向过关对存活率没有贡献（0/2）"。）

### 4.4 求值坐标必须钉死，否则 `C4` 不是谓词 `[T]`
`ch13:287-291` 记语料自己在 `β=0` 处**判错**：那里 `S_W≡0`、iid Haar，"the criterion's `γ≥0.75` is therefore **correct** there"；真酸测点在 `β→∞`（自由高斯点）。⇒ **未钉坐标的"酸测"没有真值**（(c) 对朴素形式成立）；钉死后是 `P₄(M₀)`（谓词）。**"钉坐标"就是 `C4` 从口号变成条件的全部内容——而它已完成。**
旁证 `[E]`：同一词在语料里至少三种外延——`ch13:24-26` 的自由场单点、`WA-ALIGNMENT.md:259-267` 的"酸测五点"、`LOOP-RUNBOOK.md:1140` 的准入第 2 问。**外延不统一时它是口号；统一后才是条件。**

## 5. `C3`/`C4` 是串联双闸，不是两条并列条件 `[T]`

§3 的 `M^∅` 通过 `P₃` 但 `Φ=⊥` ⇒ 被 `P₄` 杀（空转）⇒ **`P₄` 恰好拦下 `P₃` 的免费通行策略**。
（方向注意：`P₄ ⇒ ¬P₃` **不普遍成立**——`(TCI)` 空转但不是循环。得到的只是"`P₃` 的唯一免费策略被 `P₄` 封死"，`[T]` 只对这一条。）

`(∀M∈𝓜_adm) ¬P₄(M)` 若 `𝓜_adm=∅` 则真空真——**这正是 `(TCI)` 在 `ℋ₋={0}` 上的空量化，只是升了一阶**。⇒ **`C4` 必须以 per-`M`（`∃`）形式作用在已展示的候选上**，否则它的"∀"与它抓的空转同型。这也是"per-`M` 读法是承重读法"的独立理由。

## 6. 判：语料把定义当命题了吗？—— 是；两处失真 + 一处内部矛盾

**6.1 分母膨胀（把 1 记成 5）** `[E]`：`LF-LASTFOUR.md:79/130/184/273`、`MG-META.md:240/254/266` 用 `x/5` 分数。真实可记分轴 = **1**（§1.1 的 `Goal`）⇒ 剩余工作量被记成 3.5–5 单元，实际 **1**。
**6.2 分子膨胀（闸白拿分）** `[E]`：`MG-META.md:240` "1 非微扰 PASS · 3 非循环 PASS · 2 FAIL ⇒ **1/5**；`4/5` 不可判"——该候选按 `D1`（方向反）在**第一段已死**（`:236-238`），`1/5` 里的 `1` 全是 `C3`。`BC-BETHE.md:199` 更直白："`3` 非循环 **PASS（但空）**"。⇒ **空候选拿分。**
**6.3 极性反转** `[E]`：`SDP-CERT.md:299` 把 "4 反自由场 **FAIL（空真）**" 记为失分，而该行判词（"自由有质量场同样 `E₀>0`，对两者一样失效 ⇒ 无分辨力"）**正是一条已交付的 no-go**。⇒ 记分表把**产出**记成**缺项**。
**6.4 内部矛盾（最硬的一击）** `[E]`：同一语料的**准入**程序是**字典序**——"任何新提案必须逐条回答，**缺一不得进入酸测**"（`LOOP-RUNBOOK.md:1138-1143`）；**记分**表是**算术**——`x/5` 相加（`LF-LASTFOUR`、`MG-META`）。**字典序与算术平均不能同时是同一批对象的聚合规则。** §11.1 是对的（闸在前、分在后），记分表是错的。⇒ 这不是"口径不同"，是**两套不相容的聚合规则并存**。

**判词**：**是。语料把 `C4`（和 `C3`）当"五条件之一"记分，是把定义/闸当命题计分；且因闸的符号与命题相反，它同时把唯一有产出的那一栏（酸测 FAIL）记成了缺项。** `[T]`（就类别错误而言）+ `[E]`（就四处文本的实现而言）。
