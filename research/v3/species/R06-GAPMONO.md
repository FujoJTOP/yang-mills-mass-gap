## 1. `gap` 的 `c`-参数化（`[T]`）

```
c = cos(θ/2), s = sin(θ/2) = sqrt(1−c²), u = ρ/2 ∈ (0,π),  g(u) = sin u/(2u)
Φ″(u) = 1/(2u²) − cot(u)/(2u) = (1/u − cot u)/(2u)
ν_c ∝ e^{−β(1−c cos u)} sin²u/u du
S(c) = (βc/2)·E_ν[g] + E_ν[Φ″]                      ← 两项都显式/g 含 c
D(c) = β²(1−c²)·Var_ν(g) = β² s²·Var_ν(g)          ← `(1−c²)` 显式
gap(c) = S(c) − D(c)
```

**关键精确重写 `[T]`（本文件的主要解析成果）**：取 `x = cos u`，

```
sin²u/u du = (sin u/u) dx =: w(x) dx ,   w(x) = sqrt(1−x²)/arccos x   （与 c 无关）
⇒ ν_c ∝ e^{β c x} · w(x) dx ,   x ∈ (−1,1)
```

即 **`ν_c` 是以 `x=cos u` 为充分统计量、参考测度 `w dx` 的 1-参数指数族**。于是 `c`-导数全部变成协方差（对 `log Z(c)` 求导即得，逐字可核）：

```
∂_c E_ν[f] = β·Cov_ν(f, cos u)                                              [T]
```

**副作用（结构事实）**：`ν` 在 `x` 坐标里的密度正比于 `e^{βcx}·2g(x)`，参考测度就是出现于 `S` 里的那个 `g` 本身。

## 2. `∂_c S` 与 `∂_c D` 分开算（`[T]`）

```
∂_c S = (β/2)·E[g]  +  (β²c/2)·Cov(g, x)  +  β·Cov(Φ″, x)                    [T]
        └─显式 c─┘     └─E[g] 随测度动─┘     └─E[Φ″] 随测度动─┘

∂_c D = −2β²c·Var(g)  +  β³(1−c²)·[Cov(g², x) − 2E[g]·Cov(g, x)]            [T]
        └─(1−c²) 因子─┘   └────── Var 自身随测度动 ──────┘
```

`∂_c gap = ∂_c S − ∂_c D`，记成五项：

```
T1 = (β/2)E[g]        > 0                                      平凡 [T]
T2 = (β²c/2)Cov(g,x)  > 0    g、x 都关于 u 严格单减 ⇒ 重排不等式   [T]
T3 = β·Cov(Φ″,x)      < 0    Φ″ 关于 u 严格单增 ⇒ 反向重排        [T]（Φ″↑ 见 §3.1）
T4 = +2β²c·Var(g)     > 0    （−∂_c D 里的 (1−c²) 求导项）        [T]
T5 = −β³(1−c²)[Cov(g²,x) − 2E[g]Cov(g,x)]   符号不定（测度移动项）  [C]
```

## 3. 符号判定

### 3.1 `Φ″` 严格单增（`[C]`，可升 `[T]`）

```
Φ‴ = (u²csc²u + u·cot u − 2)/(2u³) =: F(u)/(2u³),   F = u² + t² + t − 2,  t := u·cot u
F(0)=0, F ≈ 2u⁴/45 (用 cot u = 1/u − u/3 − u⁴/45…)，在 (0,π) 上 F > 0
```
网格核验（2000 点，`py -3.12` 实跑）：`Φ″(u)` 相邻差全正（`min diff = 8.2e-8`），`min F = 2.7e-13` 出现在 `u→0`，与 `2u⁴/45` 一致。
⇒ `Φ″↑`，与 `x=cos u↓` 反向 ⇒ `Cov(Φ″,x) < 0` ⇒ **`T3 < 0` 是唯一的负项**（`[T]`，条件：3.1 的 `F>0` 引理）。

### 3.2 数值定号（`[C]`）

- 网格：**501** 个内部点（401 均匀 + 101 Chebyshev 两端加密，去重），全部 `c ∈ (0,1)`。
- `∂_c gap > 0`：**501/501**，最小 `+0.44361829`（`c=2.4e-4`），最大 `+0.63898109`（`c=0.883`），符号翻转 **0**。
