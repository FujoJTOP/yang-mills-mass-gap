## §1 第一问（纪律项）：`Λ` 是独立定义的量，不是由 `m` 定义

这是全判的地基，先钉死。四条独立证据：

| # | 证据 | 逐字/数值 | 标签 |
|---|---|---|---|
| E1 | **公式入口里没有 `m`** | `aΛ_lat = (2b₀g²)^{−51/121} e^{−1/(2b₀g²)}`，`b₀=11N/(48π²)`，只含 `g²` | `[T]`（`A04:78–80`；本 log `[0]`） |
| E2 | **它有非平凡的结构上限** | `sup_{g²∈(0,200]} aΛ = 0.45582874 @ g²=17.03`（N=3）；`g²=1e−3` 给 `2.0e−3116` | `[T]+[E]`（本 log `[1]`；`A8:68` 报 0.4558@17.0，五位符合） |
| E3 | **`m/Λ` 带误差棒** | `612.5 ± 50.2`（`β_W=6.00`）、`709.4 ± 127.3`（`β_W=6.30`） | `[E]`（`A8:52`） |
| E4 | **两个独立归一同时存在** | `Λ_MS/Λ_lat = 28.809`（纯数）+ 文献 `m/Λ_MS = 6.3(3)` | `[C]`（`A04:80`、`L2:152`） |

**E3 是决定性的**：**恒等式不带误差棒**。若 `Λ` 由 `m` 定（`Λ := m/C`），则 `m/Λ ≡ C` 逐位相同、误差栏必为 0。
实测 `±8%` ⇒ `Λ` 与 `m` 是两次独立取数 ⇒ **独立量** `[T]`。

**⇒ 判 (a)。** `m/Λ = C` 是**内容**（= `γ_m=0` 且 `m∝Λ`、`C≠0`），不是定义。

### §1.1 ★ mon3 对的那一半：语料里**确实**有一张「散布=0」的循环表

`A04:124–131` 的 B 支表四个 β 全是 `180.9`，并自注「**散布 = 0（恒等，`[T]`）**…这张表的四行不是四个测量，是同一句话的四种写法」。

```
m_lat/(aΛ) = (C·aΛ)/(aΛ) = C     对**任意** C 都精确成立、散布恒为 0（mpmath 逐位 True）
```

⇒ **那张表的「恒等」是代入的产物，对任何 C 都成立 ⇒ 零内容 `[T]`。**
**但循环在表，不在靶。** mon3 抓到的对象是 A04 的 B 支表（以及「`M` 是纯数」这句），不是 §1 的比值地板。

## §2 第二问（关键）：三个读法，只有第三个有内容

把 `M(β) := m_lat/(aΛ_lat) = m_phys/Λ_lat` 拆成三句话，逐条判：

| 读法 | 陈述 | 判定 | 标签 |
|---|---|---|---|
| **R1** | `M` 无量纲、且 `= m_phys/Λ` | **恒等式**（`a/a=1`，纯代数） | `[T]` 平凡、零内容 |
| **R2** | `∀β: M(β) > 0` | **恒等式**：正数除正数 | `[T]` 平凡、零内容 ← **mon3 打的就是这一句，打对了** |
| **R3** | `∃c₀>0 ∀β: M(β) ≥ c₀` | **定理形状**，非恒等 | `[NG]`（现况） |

**判别式是量词次序，且这是唯一的判别式**（log `[4]`）：

```
∀β ∃c₀(β)>0 : M(β) ≥ c₀(β)     ——取 c₀(β)=M(β)/2 即成立 ⇒ **恒真，零内容**
∃c₀>0 ∀β   : M(β) ≥ c₀          ——c₀ 必须与 β 无关 ⇒ **这才是 H1/T4 那一句**
```

⇒ **g05b/m05 与 mon3 在量词上错身而过**：mon3 否定的是 `∀β∃c₀`（恒真），g05b/m05 主张的是 `∃c₀∀β`（未证）。
两句都真，指的**不是同一个命题**。`M05-RATIO:94–96` 的 T1/T2 用的是**正确次序**（`∃c₀>0` 在外、`∀a<a₀` 在内）`[T]`。

### §2.1 R3 与 T4 等价（双向，`[T]`）

```
T4 => R3 :  m_phys ≥ Δ₀  ⇒  m_lat = a·m_phys ≥ aΔ₀ = (Δ₀/Λ)·(aΛ)  ⇒  M ≥ Δ₀/Λ =: c₀
R3 => T4 :  m_lat ≥ c₀·aΛ ⇒  m_phys = m_lat/a ≥ c₀·Λ =: Δ₀      （**用到 Λ 与 a 无关**）
```

两个方向的**唯一承重前提都是「`Λ` 与 `a` 无关」**——即 §1 的独立性。log `[5]` 在 `a=1e−1…1e−12` 上双向抽样成立。
⇒ **比值地板 ⟺ T4 ⟺ 物理单位的质量隙**。它**不是**新靶 `[T]`。

## §3 第三问：严强弱——比值地板**严格弱于**常数地板（这也解释了 g05 为什么没杀它）

```
常数地板 P1: ∃r>0 ∀β: m_lat ≥ r        —— 被 G05 §3.2 判死 [T]（r/a→∞）
比值地板 R3: ∃c₀>0 ∀β: m_lat ≥ c₀aΛ    —— 不被杀
```

**(i) P1 ⇒ R3**：`sup aΛ = 0.45583` ⇒ 取 `c₀ = r/0.45583`；`r=18.26` 给 `c₀ = 40.06` `[T]+[E]`（log `[6]`）。
**(ii) R3 ⇏ P1**：见证 `m_lat := aΛ` ⇒ `M ≡ 1`（每 β 有隙、R3 真），而 `m_lat→0` ⇒ P1 假 `[T]`。
⇒ **R3 严格弱**。这不是缺点，**这正是它活下来的全部原因**；也说明**它不可能"更强"**，只能"不被杀"。

⇒ **g05b 的自我否定确实只否证常数地板**，这一点 g05b 对 `[T]`。
但「比值地板活着」只等于「它没被那条 no-go 打到」，**不等于**「它可证」。弱命题活着是廉价的：`0=0` 也没被 no-go 打到。

## §5 `c₀` 的数值锚：一个本轮新查出的口径分歧 `[C]`

`A04:126` 的 `aΛ(β_A=1/48) = 0.5700` **高于** `A8:68` 的结构上限 `0.4558`。本 log `[3]` 定位到**常数因子**：

```
A04 四行 / 本式四行 = 1.33937 / 1.33940 / 1.33935 / 1.33974   ——  全同
2^(51/121) = e^{0.4214876·ln2} = 1.33937                        ——  逐位吻合
```

⇒ 分歧 = 两圈式里写 `(b₀g²)^{−51/121}` 还是 `(2b₀g²)^{−51/121}`（`A8:40` 两种都逐字出现过）。
**后果**：`c₀` 的数值锚在 `180.9`（A04，`Λ_MS/Λ_lat=28.809` 路线）与 `612.5`（A8，两圈直算）之间差 **3.39×**，
再乘 scheme 即 §1 的 E4 —— 即 `c₀ ∈ O(10)–O(10²)`，**与 β 无关这一点不受影响**（`[T]`），只有数受影响（`[C]`）。
另：`612.5/180.9 = 3.386 ⇒ δ(1/g²) = 2b₀ln(3.386) = 0.1699`（有限正数 ⇒ **再一次证明不是恒等**）`[T]`。
