## §1 形式核上的两条初等命题（先立，后面全用它）

**命题 1.1（`ΣAᵢ*Aᵢ ⪰ 0`，无条件）`[T]`**
`Aᵢ` 闭、稠密定义；`Aᵢ*Aᵢ` 由 `⟨Aᵢψ,Aᵢψ⟩` 给出的形式在 `Dom(Aᵢ)` 上显式 `≥0`。和的形式在交域上仍 `≥0`（有限和；无限和取上确界仍 `≥0`）。**⇒ 与维数、无界性、定义域选择全部无关。**

**命题 2.2（SOS `⟺` PSD）`[T]`**
`(⇐)` `H ⪰ c` ⇒ 谱定理给 `A := (H−c)^{1/2}` 自伴 `⪰0`，`A*A = H−c`（一个平方就够）。
`(⇒)` 命题 1.1。
⇒ `{∃(c,Aᵢ): H−c = ΣAᵢ*Aᵢ 且 c ≥ c₀} ⟺ {inf spec H ≥ c₀}`，**逐字等价，不是充分条件**。
**推论 2.3**：`k`（平方个数）**不是约束**——`k=1` 配稠密 `A` 永远够（§3·C 残差 `4.9e−15`）。唯一有内容的读法是**限制代数**（`Aᵢ ∈` 固定有限阶局域代数），那是真 SDP；但它的可行性先被 §2·(i) 卡死。

## §2 真障碍（两层，顺序不可换）

### (i) 硬阻断：`λ_min(H) = −g|B| < 0` ⇒ `c>0` 不可能 `[T]`+`[V]`
`H = −D² + 2s g|B|`（`s=±1` 螺旋度），`λ_{n,s}(k∥)=k∥²+(2n+1)g|B|+2s g|B|`，`λ_min = λ_{0,−1}(0) = −g|B|`（`F02-WCALC.md:17–27` 式 (1)；语料同位：`S1-CONDITIONAL-POINCARÉ` §4.2、`Q4-BAKRY-EMERY.md:139–140`、`S4-DECIMATION.md`）。
⇒ `inf spec(H−c) = −g|B| − c`；`c=m>0` ⇒ `H−c` 有负谱 ⇒ 由命题 1.1 **不存在** `Aᵢ`。**这是"假"，不是"难"。**
**附带的精确事实 `[V]`**：`0 ∉ spec(H)`（谱是 `{−g|B|} ∪ [g|B|,∞)`）——所以 `H` **有**围绕 0 的谱隙 `2g|B|`，却仍有负本征值。**⇒ 失败与"有没有隙"无关，纯粹是"底部在零下"。**（SOS 想要的 `c>0` = 要求底部在零上，而它是 `−g|B|`。）

### (ii) 退到 `c = λ_min` 后：SOS `⟺` PSD ⇒ 零内容 `[T]`
命题 2.2。**并且证书把"病灶"本身背在身上 `[V]`**：`c=λ_min` 时 `ker A = span{ψ₋}`（`‖Aψ₋‖ = 8.7e−09`）。**同一个对象（负模本征向量）既是"在 `λ_min` 上给出证书"的东西，又是"`c>0` 不可能"的原因。** 于是证书不可能 `(L,a)`-一致：`ψ₋` 随背景 `(L,a)` 移动。

## §3 数值（`w7/sos3_obstruction.py` → `.log`，`dim=960`，`gB=1`）

**A. 谱** `[V]`：`λ_min = −1.000000000000`（解析 `−g|B|`）；`s=+1` 支 `λ_min = +3.000000000000`；`min|λ| = 0.2346 > 0`（格点值，连续极限 `g|B|`）；负本征值个数 5（LLL×`k∥=0` 邻域）。
**B. 可行性** `[V]`：`c` 扫描 `λ_min(H−c) = −1−c`，`c ≤ −1` 全部 `≥0`，`c ∈ {−0.5, 0, +0.01, +0.5, +1}` 全部 `<0` ⇒ **最大可行 `c = −1.000000000000 = λ_min < 0`**。
**C. 因子存在性** `[V]`：`c=λ_min` 时 `k=dim` Cholesky 残差 `1.4e−15`；`k=1` 稠密 `A=√T` 残差 `4.9e−15` ⇒ `k` 不是约束；`c=λ_min+0.5 ⇒ λ_min = −0.5 <0` ⇒ 无因子。
**D. 平移逃逸** `[V]`：`λ_min(H+g|B|) = 9.8e−16 ⇒ 最佳 c'=0`，得 `H ⪰ −|gB|`（非 `m>0`）；0 之上的间隔 `0.1522` 是盒长 `k∥` 间隔（连续极限 `2g|B|`），**属于平移后算子**。
