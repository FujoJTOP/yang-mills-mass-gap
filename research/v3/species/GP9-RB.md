## §1 `ε_a^{form}` 的显式候选

### §1.0 T0：没有 `ι_a` 就没有对象（这是 `(RB)` 的第一道门，不是技术细节）

`(RB)` 逐字是 `ε_a^{form}(H_a − H)`。`H_a := −(1/a)log T_a` 作用在 `ℋ_a = L²(G^{Λ_a})` 上（`GL-B:267–272`），`H` 是连续统 Hamiltonian。两者**不同空间**，且**没有任何典范等距**——本仓对此已有两条 `[T]`：

- `GN2-VARIATIONAL.md:52`：自由场 `ω_a(p)=(2/a²)Σ_μ(1−cos ap_μ)` **有界**（`≤4d/a²`），`H_cont` 符号 `|p|²` **无界**；幺正共轭保持有界性 ⇒ **对任何**识别 `U_a`，`‖U_aH_aU_a^* − H‖ = ∞`。**识别无关。**
- `BREAK-IN-9.md:12,17`（经 `GN2:81` 转引）：`SPEC-RES` **预设**一个重整化识别 `ι_a:ℋ_a→ℋ`，而 `ι_a` **非典范**；`SPEC-RES ⟺ {ι_a 物理 ; sup_a Z_a^{-1}⟨ψ_a,H_aψ_a⟩ ≤ C}`。

⇒ **在范数意义下 `ε_a^{form}` 恒为 `∞`（`[T]`，`GN2:52`）。唯一有限的读法只能是形式（form）读法，而形式读法必须先固定 `ι_a`。** 这就是 `(RB)` 的第一性事实：**它不是一个"更难算的数"，它首先是一个"要先选的数"。**

**给出精确一点的表述（本文全程用它）**：固定 `ι_a:Q_a→Q`（`Q_a` = 格点形式域，`Q = D(H^{1/2})`），令 `𝔮_a := 𝔮∘ι_a`、`𝔞_a := 𝔮_a − 𝔮`，则

```
ε_a^{form} := sup_{ψ∈Q, ψ⊥Ω} |𝔞_a(ψ)| / 𝔮(ψ) ,      𝔮(ψ) = ‖H^{1/2}ψ‖² .          (E1)
```

（与 `GO2-SOFTMODE.md:110` 的定义逐字一致，只是把 `⟨ψ,A_aψ⟩` 换成形式差，因为 `A_a` 无界、`H_a−H` 无范数。）

### §1.1 T1/T2/T3：三项分解（这是本题的答案骨架）

`H_a − H` 在物理族里**不是**一个对象，是三个机制不同的项之和：

### §1.2 T2 的精确值：`1 − 4/π²`（本题最硬的一块）

取 `GN2:52` 逐字给的符号（自由格点场，`d` 维，`a=1` 单位）：

```
h(k) = 4 Σ_{i=1}^d sin²(k_i/2)  = 2 Σ_i (1−cos k_i) ,      k = a p ∈ [−π,π]^d ,
𝔮(ψ) = Σ_k |k|² |ψ̂(k)|² /a² ,     𝔮_a(ψ) = Σ_k h(k) |ψ̂(k)|² /a² .
```

于是（同一 `ι_a` = Fourier 识别）

```
ε_a^{form} = sup_{k≠0} |h(k) − |k|²| / (|k|² + a²m²) .                              (E2)
```

**定理（精确闭式，`[T]`+`[E]`）。** 对 `m=0`：`ε_a^{form} = 1 − 4/π²`，**与 `d` 无关、与 `a` 无关**。

*证（三行）。* 逐轴记 `r_i := 1 − 4sin²(k_i/2)/k_i² ≥ 0`（因 `sin(x/2) ≤ x/2`），则

```
|h−|k|²| / |k|² = Σ_i k_i² r_i / Σ_i k_i²  =  Σ_i w_i r_i ,   w_i := k_i²/Σ_j k_j² ∈ [0,1], Σw=1
⇒ 比值 = 逐轴 r_i 的凸组合 ≤ max_i r_i ≤ max_{|x|≤π}(1 − 4sin²(x/2)/x²) = 1 − 4/π² ,
```

等号在 `k ∈ {0,±π}^d ∖{0}` 取得（非零分量全为 `±π` 时每个 `w_i r_i = w_i(1−4/π²)`，权重和为 1）。`∎`

**核（`log §[1]–[2]`）**：`d=1,2,3,4` 的网格上确界全为 `0.594715265431`，`|数值−闭式| = 0.0e+00`；四个测试点的 `Σ_i w_i r_i` 与直接比值**逐位相同**（`0.521003961336 / 0.173988623705 / 0.557779445200 / 0.000208315973`）。`1−4/π² = 0.5947152654306489`。

**有质量的情形（`[T]`+`[E]`）**：`ε_a(m) = c·(1 + a²m²/(dπ²))^{-1} + o(a²)`，`c := 1−4/π²`；即 `ε_a(m) = c − O(a²m²)`。逐位：

| `a` | `ε_a(m=1)` | `c − ε_a` | 相对修正（`=a²m²/(3π²)`） |
|---|---|---|---|
| `10⁻¹` | `0.594514475729` | `2.008e−04` | `3.377e−04` |
| `10⁻²` | `0.594713256862` | `2.009e−06` | `3.377e−06` |
| `10⁻³` | `0.594715245345` | `2.009e−08` | `3.377e−08` |
| `10⁻⁴` | `0.594715265230` | `2.009e−10` | `3.377e−10` |

⇒ **`ε_a` 的 `a`-依赖是 `O(a²)`, 而且它收敛到一个正的常数。** 这直接判死两件事：

1. **速率版 `ε_a+b_a→0` 为假**（`b_a ≥ 0` 救不了：`liminf ε_a = 1−4/π² > 0`）。`[T]`
2. **`GO2:183,186` 的 `ε_a = O(a)` 猜想为假**；且 `GO2:287` 的"看起来可证"读法**把 T2 当成不存在**。`[T]`/`[NG]`

**为什么 T2 不能被任何交换子论证吃掉（这是 `GO2:287` 的精确缺口）**：T2 的算子差在 `a=1` 单位下是乘子 `(h(k)−|k|²)·1`，其**上确界范数**是精确的

```
sup_k |h(k) − |k|²| = d(π²−4)      （每轴 x²−4sin²(x/2) 在 [0,π] 上递增）
⇒ 范数意义下它 ~ d(π²−4)/a² → ∞ ；形相对界却是 1−4/π²
```

⇒ **同一个对象：`‖·‖ = ∞`（`GN2:52` 的 `[T]`），形相对界 `= 1−4/π²`（本文）。** 这就是 `(RB)` 唯一的有限读法，也是它"看起来小/看起来大"两种错觉的来源。
