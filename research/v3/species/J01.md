## §1 · `m₁` 的逐字定义（三条原文，一条不给）


## §3 · ★ `m₁ = m` 的精确条件（判死线 (a) 的逐字答案）

### 3.1 `≥` 恒真，等号要一格 `[T]`

`B10.md:79–83`（一行证明，`[T]`）：取连通测度，`(O−⟨O⟩)Ω ∈ Ω⊥`，`ν_O(B) = ‖P_H(B)(O−⟨O⟩)Ω‖²` ⇒ `supp ν_O ⊆ spec(H|_{Ω⊥})`（谱定理）⇒

```
m₁ = inf supp ν_O  ≥  inf spec(H|_{Ω⊥}) = m .                                   (J1)
```

（若 `(O−⟨O⟩)Ω = 0` ⇒ `ν_O ≡ 0` ⇒ `m₁ = +∞`，同式按 `+∞` 读仍成立。）

### 3.2 等号的**充要**条件（这是本条要钉的那一格）

由 `(J1)`，`inf supp ν_O = inf spec(H|_{Ω⊥})` ⟺ **`m` 落在 `supp ν_O` 里**，即

```
m₁ = m   ⟺   ∀ε>0 :  ν_O((m−ε, m+ε)) > 0   ⟺   m² ∈ supp ν_O        （闭包意义）   (J2)
```

读法（逐字）：**全道最轻态（能级 `m`）必须被 `O` 看见** —— `O` 在该态上的矩阵元不全为零（更准确：`ν_O` 在 `m²` 的任何右邻域里都有质量）。反之

```
最轻态是 O-盲的（J^{PC} 不匹配，例如最轻态 ∈ 1⁻⁻ / 2⁺⁺ 而 O = ¼trF² ∈ 0⁺⁺）
  ⇒ ν_O 在 m² 附近可以整体为零 ⇒ m₁ > m  （严格）                              (J3)
```

### 3.3 语料的 `[C]` 版是**充分非必要**的加强 `[T]`

语料把这一步写成「`s₁ = m` ⟺ 谱底是 `O`-可及（该道底上有原子，`f₁²|_{全道底} > 0`）」（`B10.md:86` = 推论 B10-4；`B05-DUAL:159` 逐字「位置 ⋯ **等于**目标（无损）⇒ 循环」，经 `B10:86` 转引；`NS2:34` 把它降为"物理前提，不重证"）。精确分工：

```

IN-11 ∧ f₁²|_{底}>0 = 充分（⇒ 等号），非必要                 [C]  ← 语料用的形状
   · IN-11：全道最轻态 ∈ 0⁺⁺（ch05:468–469 逐字 "one physical input"；语料明标物理输入，非定理）
   · f₁²|_{底}>0：底上是**原子**（不是"底上有连续谱"）
另需 (G1)：`(L,a)`-一致 + 真取极限（ch13-machine:27–29 逐字 "It must be uniform in (L,a) … A fixed-a or fixed-L statement does not give Clay"）  [C]
```

（`(V)`=通道/可见性、`(G1)`=极限一致性，逐字见 `B01-M1.md:63–64`；`B01-M1.md:69` 另判：`m>0` 只需**一个**与最轻态非零重叠的算符，"推广到所有道"不是必要条件。）

### 3.4 为什么这一步不能省：方向定理 `[T]`

```
m ≤ m₁  ⇒  下界 m₁ ≥ c 只给 m ≤ c（上界）⇒ 用 m₁ 的下界证 m>0，方向反
```

⇒ **缺口②不是"再证一个正性"，而是"证等号本身"**：`(J2)` 的闭包条件（或 `[C]` 的 `IN-11` ∧ 底上原子）。

### (a) **成立 —— 精确条件已逐字给出**（`[T]`）


### (b) **触发 —— 质量 vs 质量平方确有账要记**（`[M]`）

- **账面一（记号等号）**：`H06.md:24` 逐字 `s₁ := inf supp ν = m₁²`；`RUNBOOK:20745` 逐字 `f₁²/χ ≤ s₁ = m₁² ≤ M₀/χ`。左侧 `s₁` 是**能量**（`NS2.md:31`：`ν_w = Σw_nδ(E_n−E₀)`，能量轴），右侧 `m₁²` 是**质量²**（`ATOM2.md:27`）。同一符号被同时绑在两个量纲上。
