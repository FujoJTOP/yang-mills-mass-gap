## §2 七条逐个：定理陈述 + 判

### 2.1 Borel / Écalle：对 Gevrey-0 是恒等，**不加域** `[T]`

**定理（Borel 可和性，Costin 2009；Nevanlinna 判据）`[T]`（标准，未逐字核原文）**：设 `f(z)=Σ a_n z^n` 满足 Gevrey-1 界 `|a_n| ≤ C A^n n!`（等价：`f` 在扇形内满足 `|f(z)−Σ_{n<N}a_nz^n| ≤ C A^N N!|z|^{N+1}` 一致），则 Borel 变换 `Bf(ζ)=Σ a_n ζ^n/n!` 在 `|ζ|<1/A` 解析，且 `f(z)=∫_0^∞ e^{−ζ/z}Bf(ζ)dζ` 在扇形内成立。

**命题（本文件，`[T]`，两行证明）**：设 `f` 的 Taylor 半径 `R∈(0,∞)`（即 `|a_n| ≤ C R^{−n}`，Gevrey-0）。则 `Bf` 是**指数型整函数**，`|Bf(ζ)| ≤ C e^{|ζ|/R}`，故
`∫_0^∞ e^{−ζ/z}Bf(ζ)dζ` 绝对收敛 `⟺ Re(1/z) > 1/R ⟺ |z|<R`。
*证明*：`|Bf(ζ)|≤Σ|a_n||ζ|^n/n! ≤ C Σ(|ζ|/R)^n/n! = C e^{|ζ|/R}`；代回，被积函数指数为 `exp(−ζ(1/z−1/R))`。∎

**⇒ 判**：Borel 对**几何型（熵驱动）发散无效**——它把原点圆盘原样搬回，`ū>1` 处仍需 `Bf` 的**解析延拓**，而延拓需要圆外信息（奇点结构），正是我们所缺。Borel 只在"发散来自可数多个 `n!` 型奇点（瞬子/renormalon）"时加域。本对象的发散来自**动物熵**（`C03:111` 的 `25.2`/片），是稠密奇点型，不是 `n!` 型。语料对 Borel 的既有判词与此一致：`H05-WEAK:15`、`BLAST-RESUMMATION:5–13`（4D `SU(N)` 无 Borel 可和性定理，IR-renormalon 歧义与 `m` 同族）`[T]/[O]`。

**注（诚实线）**：`Bf` 的"零点/奇点位置"可作**诊断**（`W1-STRONG-ALIGN:174–204`：Padé/Borel 在 normaliser 上确实收到 `2.5`，但那是 `M0(β)>0` 的**构造性正**，vacuous `[NG]`）。⇒ Borel 能"算出数"，不能"证不等式"。

### 2.2 Padé / 有理逼近：极点在哪 `[T]`+`[NG]`

**定理（de Montessus de Ballore）`[T]`（标准；摘要级已核，见 §6 `web_search`）**：设 `f` 在 `|z|<τ` 内除**恰好 `ν` 个极点**（计重数）外解析，则 `[n/ν]` Padé 序列在 `|z|<τ` 内**去掉极点邻域后一致收敛**到 `f`，且其 `ν` 个极点逐个收敛到真极点。

**定理（Pringsheim）`[T]`（标准；摘要级已核）**：若非负系数幂级数 `f(z)=Σa_nz^n` 的收敛半径为 `M`，则 `z=M` 是 `f` 的奇点。

**⇒ 判**：
- 本对象是 `F(ū)=Σ_α A(α)ū^α`，`A(α)` 在求和域上**同号非负**（`Y04:69`，`ε_T` 不需符号对消）⇒ Pringsheim：**`ū=1` 是奇点**，在正实轴上。
- de Montessus 的前提是"包含 `ū=34` 的圆盘内只有 `ν` 个极点"的**亚纯性**——对动物/簇展开函数**未证**，且一般**不真**（正系数 + 熵率 ⇒ 圆上奇点稠密/自然边界是常见图像；本模型是否 holonomic 未知，`[O]`）。
- 即便形式收敛：Padé 给**逼近**不给**不等式**，而本路需要的是 `D_∞≥½`、`|ε_T|≤B'ū'^T` 这类**有符号的界**。⇒ **`[NG]`**。
- 极点的**位置**（若被问）：在 `ū` 变量上，有理逼近的极点会聚集在 `|ū|=1`（`F` 的奇点圆），而不是"移到 `ū=34` 之外"。**"极点在哪"这个提法本身错层**：`F` 没有"挡住 `ū=34` 的极点"，它有一个挡在 `ū=1` 的奇点，而 `ū=34` 已在奇点之外。

### 2.3 多尺度（每个尺度自己的 `ū_T`）：唯一的正解形式，但沿管退化 `[NG]`

**定理（multiscale / dressed 展开，Brydges–Slade; Bauerschmidt–Brydges–Slade, LNM 2242 (2019)）`[T]`（方法存在；4D 规范理论无对应定理 `[O]`）**：把聚合物按**尺度** `j` 分层，每层用自己的活动度 `w_j` 与熵率 `λ_j`；若逐层判据 `Σ_{j} Σ_{γ∋x, scale j}|w_j(γ)|e^{a_j|γ|} ≤ a_{j−1}`（或 `sup_j ū_j<1` 且 `Σ_j ū_j<∞`）成立，则簇展开收敛、压力解析、关联以率 `a` 指数衰减，且 `log D_∞ = Σ_j log(1+O(ū_j))` 收敛。

**关键**：这套机器的**小量不是裸活度，而是逐层的有效活度** `ū_j`——这正是"活度 `>1` 仍收敛"在文献里的**唯一**严格实现方式（`ū_0` 可以大，只要流把 `ū_j` 压到 `<1`）。

**⇒ 判（本对象，`[NG]`，理由可查）**：
1. **沿管无尺度**：`(L1)` 的"多尺度"就是 `α`（附着跨度）分层，而**管向平移不变** ⇒ `A(α)` 与 `α` 的起点无关（`X01:40–43` 的精确恒等式正是靠这个）⇒ `ū_T ≡ ū`（**只有一个 `ū`**），没有"递减的 `ū_T`"。⇒ 多尺度在此**退化为单尺度**。
2. 若要造尺度，只能造**4D 底空间**的块自旋 RG；那台机器在 4D 纯 `SU(N)` 上**不存在**（Balaban 只到 UV 稳定性、`g²≲1`，`H05:15`）⇒ 用它就是重证 mass gap。
3. **"乘积给指数小 ⇒ 是否就是 `p6` 的 `D_∞`"：不是。** `log D_∞ = Σ_α(1−α)A(α)` 是**一个数**（`X01:47`）；多尺度只是这同一个数的另一种**求和次序**，不产生新对象、不产生正性。`p6` 的出口是 **P6-1 的正性**（`P6-SPEC:68–77`），不是换求和次序。**别把方法当对象。**

### 2.4 Möbius / 变元：一般 no-go，任何双全纯重参数化都不能加域 `[T]`

**命题（本文件，`[T]`，一行证明）**：设 `f` 在 `0` 的某邻域解析，`φ` 在 `0` 邻域双全纯、`φ(0)=0`。则 `f∘φ` 在 `z₀` 收敛 `⟺ f` 在 `φ(z₀)` 收敛。
*证明*：`f∘φ` 的解析性域 `= φ^{−1}(f 的解析性域)`；双全纯映射保"点是否在域内"。∎

**⇒ 判**：`ū ↦ w = ū/(1+ū)` 把 `(0,∞)→(0,1)`，但把**奇点一起搬走**：`ū=1 ↦ w=1/2`，`ū=34 ↦ w=0.9714`。变换后级数的收敛圆盘是 `|w|<1/2`，`0.9714` 仍在圆外。⇒ "能把 `ū>1` 映到 `<1`"是**错觉**：映进去的是**数**，不是**点相对于奇点的位置**。任何"改写活度定义使之 <1"的做法（含 `ū↦ū/(1+ū)`、`ū↦tanh ū`、`u↦u/(1+u)`）都在此 no-go 之下，**除非**同时使用系数之外的信息（解析延拓 / 正性 / 谱）。这条把语料里反复出现的"换个活度变量试试"一类提案**一次性判死** `[T]`。

### 2.5 Hard-core / 薄聚合物：KP 与其变体（判死线 (c)） `[T]`

**(c-1) Kotecký–Preiss 判据（逐字）`[T]`**（Kotecký–Preiss, *CMP* **103** (1986) 491–498, DOI `10.1007/BF01211762`；语料内已 `[V]` 核书目，本文件沿用转引，原文未取到）：
设 `𝒫` 为可数聚合物集，`w:𝒫→ℂ`，`≁` 为对称不相容关系。若存在 `a:𝒫→[0,∞)` 使
$$\forall\gamma\in\mathcal P:\qquad \sum_{\gamma'\nsim\gamma}|w(\gamma')|\,e^{a(\gamma')}\ \le\ a(\gamma), \tag{KP}$$
则簇展开 `Σ_{Γ connected} φ(Γ)` 绝对收敛，`log Ξ` 与截断关联解析，且截断关联以率 `a` 指数衰减（`P3-DRESSED-MASS:63–68` 的 (2.1)/(2.2) 与 `IMP-ARROWS:67` 同一陈述）。

**(c-2) 推论（本文件，`[T]`，三行）——KP 类判据强制 `sup|w| ≤ 1/e`**：
取 `a(γ)=κ|γ|`，`κ>0`。若单体聚合物存在（即 `{p}∈𝒫`，`|γ|=1`；本模型成立，`C03:111` 的 `a_1=1`），则对每个与某单体 `γ`（`|γ|=1`）不相容的 `γ'`（含 `γ'=γ`，因 `γ∩γ≠∅`）：
`|w(γ')|e^{κ|γ'|} ≤ κ|γ| = κ ⇒ |w(γ')| ≤ κe^{−κ|γ'|} ≤ κe^{−κ} ≤ 1/e = 0.367879`（`max` 在 `κ=1`）。∎

**⇒ 判（硬否决）**：`β=2.5` 上**裸**单片活度 `u=0.625 > 1/e`（超 `1.70×`）⇒ **任何** `a(γ)∝|γ|` 的 KP 型绝对收敛判据（无论几何多薄、熵率多小）**必然不可满足**。这不是常数松，是**判据的可满足性**问题。⇒ 语料的窗 `β<1/eΔ`（`H2:15`）不只是"算出来的紧"，它背后有一条**与几何无关的必要条件** `u≤1/e`（本文件首次写出，`[T]`）。

**(c-3) 薄聚合物变体（存在，且正是缺的那台机器）`[T]`（本文件陈述，KP 的直接特化）**：
给每个聚合物配"跨度" `s:𝒫→ℕ`，`s(γ)≤|γ|`（沿管方向的长度；横向厚度不计入）。若
(i) **[薄]** 对固定 `γ`，`{γ'≁γ : s(γ')=n}` 的个数 `≤ λ_s^n`（**每单位跨度**的熵，而非每 plaquette 的 `Δ=20`）；
(ii) **[权重]** `|w(γ)| ≤ a_s^{s(γ)}`；
则 (KP) 成立，只要 `λ_s a_s e^{κ} ≤ κ`（后者对某 `κ>0` 可解 `⟺ λ_s a_s < 1/e`，因 `min_κ κe^{−κ}=1/e`）。

**⇒ 它的作用与极限**：薄化只压 **(i) 的熵率**（`25.2 → λ_s`），**不解除 (c-2) 的 `|w|≤1/e`**。本模型：
- 若装饰真"沿管"（`λ_s≍e`），则 `λ_s u = 1.70 > 1`——只差 `1.7×`，这就是"薄聚合物"路线诱人的原因；
- 但装饰**不在管上**：`ε_T` 只要求与簇**连通**，不要求与管相邻，故可离管进入 4D 体（`C03:104–111` 逐字），实测熵率 `20→25.2` 上升 ⇒ **`λ_s = 25.2`，`λ_s u = 15.75 ≫ 1`** ⇒ (c-3) 的 (i) 是**假**的（`[T]`+`[E]`，数在 `C03:111`）。
⇒ **(c) 触发（变体给出）但不可用**：变体的条件在本对象上被一个**显式数字**否证。

### 2.6 `L²`/Hilbert：谱半径 vs 范数 `[T]`（算子）+ `[NG]`（本对象）

**定理（Gelfand 谱半径公式；Neumann 级数）`[T]`**：`K` 为 Banach 空间上有界算子，`ρ(K)=lim_n‖K^n‖^{1/n} ≤ ‖K‖`；`(1−K)^{−1}=Σ_{n≥0}K^n` 按范数收敛 `⟺ ρ(K)<1`。且 `‖K‖>1`、`ρ(K)<1` 可同时成立（例 `K=[[0,2],[0,0]]`：`‖K‖=2`，`ρ=0`）。

**用户命题正确**：把活度当算子范数确实会**过估**，正确判据是谱半径。**但本对象无增益**：
- **Cauchy–Hadamard `[T]`**：`F(ū)=Σ A(α)ū^α` 的半径 `=1/\limsup|A(α)|^{1/α}`。`A(α)` 的增长由**动物计数**（正的组合数）给出，`\limsup` 就是那个熵率（`≥25.2`；用 `eΔ=54.37` 作上界）。⇒ 谱半径**不可能**低于系数增长率——"`ρ<‖K‖`"的松弛在**正系数**情形被 `Fekete`/`Perron–Frobenius` 钉死（正核的 `ρ` 就是增长率）。
- **Pringsheim + 同号**（`Y04:69`：`ε_T` 系数非负、无需对消）⇒ 奇点在 `ū=1` 正实轴上，**不是**复平面里可以被"绕过"的近邻奇点。
- ⇒ 唯一能真正把 `ρ` 压下去的东西是**符号对消**（`A(α)` 交错），而本模型的 `A(α)` 同号 ⇒ **无对消可用** `[NG]`。

### 2.7 反射正性 / Gram（`p6` 的 P6-1）：给正性、不给率 `[C]`→`[NG]`

**定理（OS 反射正性 ⇒ 正谱测度）`[T]`**：若 `(θ,·)` 反射正，则 `C(t)=⟨θF_t,F_0⟩ = ∫ e^{−Et}dν(E)`，`dν≥0`（`Y01-KL:77` 逐字：`Theorem A` 的 `⇐` 要 `ν≥0`）。⇒ `D_∞` 作为正测度的原子重量 `≥0`。

**但**：
1. `ν≥0` 给 `D_∞≥0`，**不给** `D_∞≥c>0`（`≥0` 与 `>0` 之间没有定理）；`p6` 的下游要的是 `D_∞≥½`（`X02:77`、`P4:81–86`）。`[T]`

## §4 判死线

**(a) 能给 `ū>1` 时的指数小界 ⇒ 触发？—— 不触发（对本对象）。**
一般机制存在（§3 的 A/B/C），但每条都有一个在本对象上**被数字否证**的假设：
A：无表面张力（`[T]`，`β=2.5` 无小 `e^{−βτ}`）；
B：4D 规范无 RG 机器 + 沿管 `ū_T≡ū`（`[NG]`）；
C：`u=0.625`、`1/u=1.6` 双端不小（`[T]`）。
**且 §2.5 (c-2) 给出一条与几何无关的硬否决**：`a∝|γ|` 的 KP 型判据要求 `u≤1/e`，而 `u=0.625`。
⇒ 本路**拿不到** `ū>1` 的指数小界；**(L1) 在 `β=2.5` 上不可修复为原形**（`(L1)` 的右端在 `ū>1` 时**为负**，§1 事实 1）。

**(b) 全部不行 ⇒ 明说"没有现成的"。—— 触发。**
**没有现成的。** 逐条：Borel（Gevrey-0 恒等）、Padé（奇点在正实轴 `ū=1`、且给逼近不给界）、Möbius（双全纯 no-go）、KP（`u>1/e` 硬否决）、谱半径（正系数 ⇒ `ρ` 钉死）、RP/Gram（给 `≥0` 不给 `>c`）、多尺度（沿管退化 + 4D 无机器）。**七条里五条是定理级否决（`[T]`），两条是"方法存在但假设被数字否证"（`[T]`+`[NG]`）。**

**(c) KP 变体能用于"细聚合物" ⇒ 给陈述与条件。—— 触发（陈述在 §2.5 (c-3)），但条件假。**
条件：`s(γ)`-跨度熵率 `λ_s` 与活动度满足 `λ_s a_s < 1/e`，且**装饰必须被管约束**（不离开管）。实测：熵率 `20→25.2` 上升、装饰可离管进 4D 体（`C03:104–111`）⇒ `λ_s u=15.75≫1`，**条件假**。

## §5 路径（本轮之后唯一未被判死的三件，按代价排序）

1. **不换右端，换目标**（最便宜，`[T]`）：既然 `B<0`，`(L1)` 在 `β=2.5` 上**不该被修**；`p4` 的定位（"只坏 `D_∞` 这一格"，`P4:19`）意味着**放弃 `δ>0`/`I2` 在 `β=2.5` 的版本**，只保留 `D_∞≥c>0`（= `I1`）这一格。⇒ 靶 = **`D_∞>0`**，不是 `|ε_T|≤Bū^T`。这是唯一与 §4(b) 相容的读法。
2. **正性（P6-1）是唯一"不要小量"的机制**（`[C]`）：若能在**核带号**的情形造出不依赖绝对收敛的 Gram/单调量（例如把 Weingarten 符号并进一个**不定号但有锥**的结构），则 `D_∞>0` 不靠 `ū<1`。杀判据已写死（`P6-SPEC:77`），且**尚无候选**（`[O]`）。
3. **1D 转移算子 + 谱隙**（`[O]`，最贵）：`D_fin(T)−D_∞=Σ_{j≥2}c_jθ_j^T`、`|θ_j|<1`（`W02:26`）。存在性由 1D 次可加/Fekete 给（**不需小活动度**，`P4:145`）；**缺的只是 `sup_{j≥2}|θ_j|≤1−δ` 的显式界**——而这恰是 `(L1)` 的另一写法 ⇒ **等价于直接证 mass gap**。`[NG]` 作为"重求和技术"，`[O]` 作为"研究纲领"。

**一句话路径**：`β=2.5` 上不存在"重求和把 `ū>1` 救回来"的技术（§2.4 一般 no-go + §2.5 硬否决 + §2.1 Gevrey-0）；**唯一出口是把靶从"率"降到"正性"**（`D_∞>0`），用 §5.2 或 §5.3，二者都**不是**重求和技术，而是正性/谱论。
