## §1 四句话把对象钉死（`[T]` 记号层）

| 记号 | 定义 | 本轮用途 |
|---|---|---|
| `S_W` | `β Σ_p (1 − ½Re tr U_p)`（`SU(2)`）；模型 ② 是 `½φ^TAφ`；模型 ④ 是 `−βΣ_x cos(θ_x−θ_{x−1})` | 全部模型共用 |

| `λ₁` | 单群因子 `−Δ` 的第一个非零本征值：`SU(2)`（单位 `S³`）`= 3`；`U(1)`（单位圆）`= 1` | 时间轴单位与率的候选 |

三条**只用已有定理**的结构事实（全部 `[T]`，无新物种）：

1. **Peter–Weyl + Chebyshev–Bessel（`R5-AUDIT` §1.1 已核）**：`SU(2)` 上 `e^{βq_0} = Σ_l c_l χ_l`，`c_l = I_l(β) − I_{l+2}(β)`（`c_0 = 2I_1/β`）；`χ_l = sin((l+1)ψ)/sinψ`，`l(l+2) = λ_l`；类函数卷积模逐点相乘 ⇒
   `B_t(x) = e^{−β} Σ_l c_l e^{−λ_l t} χ_l(ψ_x)`，`λ_l = l(l+2)`。**这是模型 ① 的精确闭式。**
2. **左不变标架 + `P-D`（`R3-L4` §2.1）**：`∂_a S_W = (β/2)q_a`，`Hess^{flat,sym}S_W = (β/4)q_0·1₃`

3. **Stein / 分部积分（平坦空间即分部积分，群上即 `P-B` 的 `t=∞` 端点）**：`Cov_ν(∇S_W) = E_ν[Hess S_W]`，`ν ∝ e^{−S_W}`。
   ⇒ **`t=∞` 端点不是"小量"，是一个正的 `O(1)` 常数**（本轮逐模型复核到 `1e−15`，见表 T1 的 `C_∞` 列与 §3 的 Stein 校核）。

## §3 模型 ①：单 link 的精确曲线（`SU(2) = S³`，Bessel 精确）`[T]`

`S_W = β(1−q_0)`，`q_0 = ½Re tr w = cos ψ`。**精确闭式**（§1 事实 1）：

```
B_t(x) = e^{−β} Σ_l c_l e^{−l(l+2)t} χ_l(ψ_x),   c_l = I_l(β) − I_{l+2}(β)
Hess V_t = (β/4) E_{μ_{t,x}}[q_0] · 1₃  −  (β²/4) Cov_{μ_{t,x}}(q⃗)
q(t) = max(0, −λ_min(Hess V_t))
C(t) = (β²/4) ‖Cov_{μ_{t,x}}(q⃗)‖_op
```

（`Hess V_t` 的两项都已在 §1 事实 2–3 给出；`q⃗ = sinψ n̂` 是 `w` 的“空间”分量，`∂_aS_W = (β/2)q_a`。）

**校核三件**（`cov_link.log` S0a/S1b）
1. `B_t` 的 character 和 vs `S³` 上 3D 求积：`max rel diff = 4.95e−07`（`λ₁t = 0.1`）→ `2.18e−15`（`λ₁t ≥ 10`）。
2. `t=0`：`B_0 = e^{−S_W}` 逐位相同（`0.00673794699908548` vs `…67`）。
3. 恒等式 `Cov = E[Hess S_W] + Hess log B_t`：`‖HV(num) − HV(analytic)‖` 从 `2.3e−06`（`λ₁t=0.003`）降到 `1.8e−18`（`λ₁t ≥ 100`）。**两条独立路径（求积 vs `−log B_t` 的二阶差分）在同一处收敛。**

## §4 模型 ② 与 ④：可精确对角化的两个极端（Dirichlet vs 周期/循环）

两者都是 `S_W = ½φ^TAφ`（Gaussian），于是**全部闭式**（`cov_models.log`）：

```
Hess V_t = A(I+2tA)^{-1}  ⪰ 0  ⇒  q(t) ≡ 0        (逐 t、逐 L、逐 φ)
Cov_t    = 2t A²(I+2tA)^{-1}  ⪰ 0，逐 t 单调增     ⇒  sup_t ‖Cov_t‖_op = λ_max(A)
C_int(t) = ‖Cov_t‖_op/L          （1D 链：N_p = L 个 link/面）
```

### §6.2 那么缺口在哪：两条，且都不是"`Q(∞)<∞`"`[C]`/`[NG]`

**缺口 1（技术性，`[C]`）：对消后**系数**的 `L`-一致性**

`q(t) = ‖(E_μ[Hess S_W] − Cov_μ(∇S_W))_−‖`。两项各自 `O(1)`、各自饱和（`E_μ[Hess S_W] → E_ν[Hess S_W]`、`Cov → E_ν[Hess S_W]`，**同一极限**），差值以 `e^{−λ₁t}` 衰减。在 4D 上：

```
B_t − Z = Σ_{n≥1} e^{−λ_n t} ⟨ψ_n, e^{−S_W}⟩ ψ_n ,     λ_n ≥ λ₁ = 3（单 link 模最低）
⇒ Hess V_t = Σ_{n≥1} e^{−λ_n t} ⟨ψ_n, e^{−S_W}⟩ Hess(...) / B_t
⇒ |q(t)| ≤ C(β) e^{−λ₁ t} · E_ν[局部观测量]
```

要证的**只剩一条**：`⟨ψ₁, e^{−S_W}⟩/Z`（`ψ₁` = 一条 link 的 `l=1` 模）= **局域期望**，在 `(L,a)` 上一致有界。
- 它是**局域量**（`e^{−S_W}` 的模重叠只涉及一个 link 的 plaquette），与 `N_p` 无关；`β=0` 时它**恒为 0**（`e^{−S_W} ≡ 1`，所有 `n≥1` 的系数为 0）⇒ **这条界过酸测**（自由场让它消失，而 `C_∞` 与 `q` 同时消失）。
- 严格的 `L`-一致界需要 `β`-小的团簇展开或 (CP)/`H1`。**⇒ 这条与 `H1` 是同一个对象，但**只需要 `β=2.5` 处的单点**、不需要跨 `β` 的一致性。这是比 `LOOP-RUNBOOK` §8.2 的"`L`-一致性死点"窄得多的靶。**

**缺口 2（结构性，`[NG]`）：BD 判据过不了自由场酸测**

`β = 0` 时 `Q(∞) = 0`，而 `γ ≥ N/4 = 0.75 > 0` 仍然成立（`N = dim SU(2) = 3`，`Ric = (1/4)g` 的归一化下 `N/8 = 0.375`，与自由 `SU(2)^Λ` 上热流的 LSI 常数逐位一致）。
**⇒ 即使 `Q(∞) ≡ 0`，判据仍给出正的 LSI 常数。这个常数是几何（Ricci）供的，不是动力学供的。** 按项目宪章 §1 的酸测：**"自由无质量场若不失效 ⇒ vacuous"。⇒ BD-Thm-3.20 这条路线，无论 `Q(∞)` 可积性多好，都在酸测上失败。** 这与 `AUDIT-BBD` §7、`R3-L4` §6.2 (i)(ii) 的定性一致（`R3-L4` 称之为"不救 BD 路"），本轮给出的是它的**定量形式**：失效点不是 `Q` 的大小，而是 `N/4` 的**结构性存在**。
**⇒ "BD 路线只是 H1 的换述"这句话，正确的位置不在 `Q(∞)` 的率上（那里不循环），而在"几何 LSI ⇒ 物理隙"这一步上（那里缺谱桥 R1）。**
**而谱桥 `λ₁(μ_vac) = 2m₁` 若成立，则 `m₁ ≥ γ/2 ≥ (N/8)e^{−2Q(∞)}`，`Q(∞) = O(1)` ⇒ `m₁ > 0` 且 `L`-一致 —— 链条在"桥 + 缺口 1"两件事下闭合。桥的现状是 `R1-BRIDGE` 的 `[T]`（本轮不重审，与 `R1-BRIDGE` 无分歧）。**
