## §3 · `w₁(a)`：不是单调问题，而是"恒等 + 假象"`[T]`

1. **`γ_{w₁} ≡ 0` 精确**：`f₁²` 与 `M₀` 都是 `O=¼tr F²` 的两次插入、同带 `Z_O²`，
   ```
   f₁²(μ)=Z_O²f₁²(μ₀),  M₀(μ)=Z_O²M₀(μ₀)  ⇒  w₁(μ)=w₁(μ₀),  d ln w₁/d ln μ = 2γ_O−2γ_O = 0 .
   ```
   （`v3/U4-CONTINUUM-ATOM.md:32–33`，`[T]`）
   ⇒ 重标后 `w₁(a)` 沿物理线是**常数**。"单调"在这里**退化**（常数既非增也非减），端点 `a=0` **零信息**。
2. **裸比的"单调降"是接触假象**：`M₀^{bare}=C(0)~a⁻⁸`、`f₁²` 是 IR-clean，故 `w₁^{bare}→0`
   是 UV 假象、不是跑动（`v3/U4-CONTINUUM-ATOM.md:41–48`，`[T]`）。**若照这条单调性取 `a→0` 端点，会"证"出 `w₁→0` —— 正是自由场的值**，酸测（自由场必须报零、YM 必须报正）立刻杀掉该论证。
3. **唯一合法的 `a`-型正面陈述**是导数的**一致界**，且它**充分非必要**：
   `∃C: |d ln w₁/d ln a| ≤ C ⟹ 排除零点`（`species/V02-BETAMONO.md:160–166`，`[O]`）；缺口是 `γ_{f₁²}−γ_{M₀}` 的一致界——**但由第 1 条，这个差恒为 0，所以该路只排"零点"，不给"地板"**。`[O]`
