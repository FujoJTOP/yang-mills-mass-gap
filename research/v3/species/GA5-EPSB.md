## §1 `ε_b` 的精确对象

### §1.1 定义式（并纠正任务书里的一处反写）

`F_b: Config_f → Config_c` 为块化映射（面平均 + 平行移动，`b=2`，`PROOF-BLOCK-RG-GAP.md:6`），`μ_b := (F_b)_*μ`。粗 Dirichlet 型取 **粗链**上的形式

```
E_b(f) := Σ_{l ∈ 粗链} ∫ |∂_l f|² dμ_b ,      Var_{μ_b}(f) := ∫ f² dμ_b − (∫ f dμ_b)² .
ε_b    := inf { E_b(f)/Var_{μ_b}(f) : f ∈ L²(μ_b), Var>0 }        (Poincaré 速率)   (1.1)
⟺      Var_{μ_b}(f) ≤ (1/ε_b) E_b(f)   ∀f .                        (1.2)
```

**任务书的猜测要取倒数**：`inf_f Var/E = 1/ε_b`，不是 `ε_b`。这不是记号洁癖——它决定了 `ε_b` 在 `min(Λ_UV, ε_b)/(1+2S/ε_b)` 里出现在**分子**、以及 `2S/ε_b` 里出现在**分母**。反过来写会把量纲与单调性全部读错（见 §3.3 的 `ε*`）。

### §2.2 `ε_b ≤ Λ_UV` 没有独立来源 —— 因为它**不需要**

`ε_b ≤ Λ_UV` 只在一种情形下被需要：为了让 `min(Λ_UV, ε_b)` 取到 `ε_b`（`GC4:232` 的解出 `ε*` 的前提）。而**权威形式不带 `min`**：

```
REPAIR-2SCALE.md:20–24 / VERIFY-FINAL.md:9（独立核验 "algebraically correct"）：
Var_μ(F) ≤ (1/Λ_UV)(1+2S/λ)E|∇_⊥F|² + (2/λ)E|∇_∥F|²  ⇒  m = min( λ/2 , Λ_UV/(1+2S/λ) )
```

在 `λ=ε_b` 时代入即得 §2.3 的精确条件；其中**没有 `ε_b ≤ Λ_UV` 这一项**。于是任务 §2 的答案是双层的：

1. **`ε_b ≤ Λ_UV` 是 `min(Λ_UV,ε_b)/(1+2S/ε_b)` 这个压缩形式的产物**，而该压缩形式本身在 `2S<ε_b≤Λ_UV` 区间**不是定理**（§3.2 给出精确反例）⇒ 条件随形式一起消失。
2. **它本来也不该有独立来源**：`ε_b` 与 `Λ_UV` 是两套归一化下的常数（粗链计数 vs 纤维/细链计数，`VERIFY-FINAL:10` 已点出体积因子 `N_{E′}~L⁴` 被 `S=sup_B` 丢弃），把它们直接比大小在量纲上就不成立。**语料从未给出两者的同归一化比较，本轮也不给。**

### §2.3 换来的**真**条件：形式无关的 `Λ_UV` 上限 `[T]`

```
m ≥ δ  ⟺  ε_b/2 ≥ δ   ∧   Λ_UV/(1+2S/ε_b) ≥ δ

```

## §3 `ε_b ≥ ε*(δ,S)`：`S` 是什么、`ε*` 怎么依赖、以及记录里的一处因子 2

### §3.1 `S` 的精确身份

`REPAIR-2SCALE.md:15`：`S := sup_{U′,B} Var_μ(s_B|U′) ≤ 4‖∂_{U′}S_W‖_∞² < ∞`，其中 `s_B=∂_{U′_B}log μ(·|U′)=−(∂S_W−E[∂S_W])` 是**score**（纤维均值零）。三条口径必须写明：

### §3.2 `ε*` 的依赖，以及为什么它其实**不该出现**

`GC4:232` 的 `ε*(δ,S)=(δ+√(δ²+8δS))/2` 来自解 `ε ≥ δ(1+2S/ε)` ⇔ `ε²−δε−2δS ≥ 0`（代数**正确**，`[E]`：`S=900,δ=0.1 ⇒ ε*=13.4665`，复核 `ε*²=181.3467=δε*+2δS` ✓）。依赖形状：`S→0` 时 `ε*→δ`；`S≫δ` 时 `ε*≈√(2δS)`。**但它是从一个在目标区间不成立的形式解出来的。**
