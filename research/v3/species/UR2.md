## 1 · `λ_Ur` 的精确定义（问题 1）

```
m_n      := Σ_{|Γ|=n, Γ∋x₀} |φ^U(Γ)|            （第 n 壳的绝对 Ursell 质量，正）
λ_Ur     := limsup_n m_n^{1/n}                   （= 1/(u-级数的收敛半径)，Abel 半径）
```
- `[T]` **它是"系数增长率"**：`Σ_Γ φ^U(Γ) u^{|Γ|}` 绝对收敛 ⟺ `λ_Ur u < 1`。`|Σ_Γ φ^U| ≤ m_n` ⇒ 符号不能把小 `n` 的事后变大；而 Leibniz/壳配对增益上限是常数因子 `2`（`TT2 S6`）⇒ **符号抵消不能把半径推过 `1/(λ_Ur u)`**。所以"交错"不救 `λ_Ur`。
- `[T]` **它不是 `ū`**：`ū := eΔ·C̄·u` 里的 `eΔ` 是 `λ_Ur` 的**可证上界**（Penrose `|φ^U| ≤ τ` + 过定点树/动物计数率 `= eΔ`，`C01:16–17,88`）。即

```
λ_Ur ≤ eΔ = 54.3656365692        [T]      ū = λ_Ur^{界}·u        （C̄=1：同一笔账）
```
⇒ `TT2` 的 `q ≟ 1` 与 `(L1)` 的 `ū ≟ 1` 是**同一个判据**，只是把 `eΔ` 换成 `λ_Ur` 的真值。**判据没有中间地带**：要 `(a)`，`λ_Ur` 必须比它的可证上界小 `≥34×`；而实测方向相反（下表在**上升**）。

## 3 · 严格下界：`λ_Ur ≥ 120^{1/7} = 1.9816`（`[T]`+`[E]`）

1. **块乘积 `[T]`**：若 `G` 的块（2-连通分量）串行相连（割点/桥），任一 spanning 连通子图 = 各块 spanning 连通子图之并 ⇒ `φ^U(G) = ∏ φ^U(block)`。机验 `K_3–桥–K_3 → 4`。

3. **格内可实现 `[E]`**：两束分置 link `(0,(0,0,0,0))` 与 `(0,(0,0,3,0))`，用单片 `P(0,2,(0,0,1,0))` 作桥（各恰 1 邻）⇒ `n=13`、`|E|=32`、`φ^U = 14400 = 120²` ✅。周期重复 ⇒ 任意 `k` 的束链，`n = 7k−1`、`|φ^U| = 120^k`。
4. ⇒ `m_{7k−1} ≥ 120^k` ⇒ `λ_Ur ≥  120^{1/7} = 1.981645` ⇒ **`λ_Ur·0.625 ≥ 1.2385 > 1`**（**不依赖任何外推**）。
