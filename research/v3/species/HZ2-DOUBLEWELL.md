## §1 双井闭式（精确族）

### 1.1 定义（把 `ν_g` 写成不含歧义的对象）

取语料自己的 1-D 正规形（`H6-HEAD-SPECTRAL.md:177`，同一式见 `SM5-TCI-HEAD.md:26`）：

```
V_g(y) = (g/2)(y²−1)² ,   g>0
井: y=±1, V=0 ;  垒: y=0, ΔV := V(0)−V(±1) = g/2            (1.1)
曲率: V_g″(±1)=4g ,  V_g″(0)=−2g ,  V_g⁗(y)=6g
边际: μ_g(dy) ∝ e^{−V_g(y)}dy
KL 谱测度（粗模 a=y 的 Källén–Lehmann 测度）:
ν_g = Σ_{n≥0} f_n² δ_{m_n²} ,   f_n := ⟨0|y|n⟩_{μ_g} ,   m_n := E_n−E₀   (1.2)
（E_n = 生成元 L_ν=−∂_y²+V_g′∂_y 的谱；Dirichlet 型 ℰ_ν(φ)=∫|φ′|²dμ_g）
```

**族**（类 3 的深垒端）：对 `κ ≥ 2`、`L ≥ 2`，

```
ν_{κ,L} := ν_{g}   取   g = g_κ(L) := κ·log L + 2loglog L + O(1)                (1.3)
```

`g_κ` 的下阶项由 §3.1 的精确不等式唯一确定（不是自由参数）。

### 1.2 三个闭式（全部自算，推导见 1.2.1–1.2.3）

```
m₁²(g) = λ₁(g)² = (2g²/π²)·e^{−g}·(1+O(1/g))                  (1.4)
f₁²(g) = |⟨0|y|1⟩|² = (1 − 3/(8g))² + O(g^{−2}) = 1 − 3/(4g) + O(g^{−2})   (1.5)
χ(g)  := ∫ s^{−1}dν_g(s) = Σ_n f_n²/m_n²  ≥  f₁²/m₁²
      = f₁²·(π²/(2g²))·e^{g}·(1+O(1/g))  →  ∞                   (1.6)
Var(a) = M₀ = Σ_n f_n² = 1 + 1/(4g) + O(g^{−2}) = O(1)            (1.7)
```

**1.2.1 `λ₁`（Kramers 渐近，标准 1-D）**。对称双井的一阶非零特征值
`λ₁ ≍ (1/2π)√(|V_g″(0)|·V_g″(1))·e^{−ΔV} = (1/2π)√(2g·4g)·e^{−g/2} = (√2/π)g e^{−g/2}`。
这就是 `m₁`（KL 频率 = 转移隙）。**`λ₁` 是隧穿劈裂本身，不是它的平方。**

**1.2.2 `f₁²`**。井基 `{|L⟩,|R⟩}`，`y|L⟩=Y|L⟩`、`y|R⟩=−Y|R⟩`，
`|0⟩=(|L⟩+|R⟩)/√2`、`|1⟩=(|L⟩−|R⟩)/√2` ⇒ `⟨0|y|1⟩ = Y`（交叉项 `⟨L|y|R⟩` 为 `O(e^{−g})`）。
`Y = E_L[y] = 1+⟨u⟩`，井内展开 `V_g(1+u) = 2gu² + 2gu³ + (g/2)u⁴ + O(u⁵)`
⇒ `ω²=4g`、`λ=2g`、`⟨u⟩ = −3λ/ω⁴ = −3/(8g)`（标准三阶微扰，误差 `O(g^{−2})`）。
⇒ `f₁² = Y² = 1 − 3/(4g) + O(g^{−2})`。**原子权重不塌。**

**1.2.3 `χ`**。squeeze 的定义式是 `χ=∫s^{−1}dν`（`Q6:76,88–90`）。`n=1` 项主导：
`χ ≥ f₁²/m₁²`，代入 (1.4)(1.5) 得 (1.6)。`χ` 按 `e^{g}` 增长——**不是 O(1)**。

**1.2.4 必须写清的一处分寸（`Var` ≠ `χ`）**。`Var(a)=C(0)=M₀`、`∫₀^∞C dτ=∫s^{−1/2}dν`、
`χ=∫s^{−1}dν` 是**三个**不同泛函；三者只在单原子 + 归一化下同值（`Q6:159–164` 的「iff Gaussian」）。
双井把它们分到极端：**`Var=O(1)` 而 `χ=∞`**。`U6:168,223`、`R6:126` 用的是后者（正确口径）；
`Q6:133–136` 的措辞「`Var=O(1)`（有界，H1 以固定 `λ` 成立）」在 `χ=∫s^{−1}dν` 口径下**不成立**——
双井恰恰是 H1 **失效**的见证。**这条记为本轮更正 C1（§5.3）。**

### 1.5 宇称 / 偏置二分：双井**能否**在偶载体上产生原子

把井基截到 2×2（误差 `O(e^{−2ΔV})`，标准 instanton 展开）：

```
H_2 = [[ δ/2 , Δ ],[ Δ , −δ/2 ]] ,  Δ = λ₁/2 ,  δ = 井深差（偏置）
m₁ = 2√((δ/2)²+Δ²) ≥ |δ|                                                     (1.9)
f₁² = |⟨0|O|1⟩|² = (O_L−O_R)²/4 · Δ²/((δ/2)²+Δ²)                             (1.10)
```

三分（`O` = 载体在两侧井的值；`O` 的宇称由 `y→−y` 决定）：

| 情形 | `m₁` | `f₁²` | 在类 3？ |
|---|---|---|---|
| **对称井**（`δ=0` 精确，由任何 `y→−y` 对称保证） | `2Δ`（指数小） | `O` 偶 ⇒ `O_L=O_R` ⇒ **`f₁²=0`** | **否**（原子为零） |
| **倾斜井，一般** `δ≫Δ` | `≈|δ|`（**非指数**） | `≈(ΔO/2)²·(2Δ/δ)² → 0` | **否**（无轻模，或原子塌） |
| **倾斜井，指数细调** `δ≪Δ` | `≈2Δ` | `≈(ΔO/2)² = O(1)` | **是**（唯一活法） |

**判**：
- **`[T]` 对称双井 + 偶载体（`¼tr F²` 是偶）⇒ `f₁²=0`**。语料的双井见证用的是**奇**载体（坐标 `y` 本身，`Q6:133–136`、`H6:285`），它的 `f₁²=O(1)` **不迁移到 `F²` 道**。这是本文件最硬的一条结构限制。
- **`[T]` 非对称双井进类 3 需 `δ ≲ λ₁ ≍ g e^{−g/2}` 的指数细调**（一条 codimension-1 的动力学调参，**非对称性保护**：对称性会把 `δ` 精确置 0，但同时把 `f₁²` 置 0——两者不可兼得）。
- ⇒ **双井在 `F²` 道里是「细调对象」，不是「结构」**。这一条把 §2 的判决从「没有已知机制」加强为「即使有机制也必须恰好落在一条指数细调线上」。

↳ **下一手**：把 `δ` 写成 `ν_{κ,L,δ}` 的独立轴；在 YM 上估 `δ` 的自然量级（唯一候选是有限体积偏置 `~1/L²`，见 §2.2 (iii)），判它是否可能落在 `≲1/L²` 且**同时** `≪Δ`。

## §2 YM 可达性（★ 判决点）

### 2.1 双井在 `F²` 的道里确切需要什么（四条，缺一不可）

```
(A) 两个谷在【同一个测度】里（同一 Hilbert 空间 / 同一 θ-扇区；不同扇区的叠加不构成双井）。
(B) 载体 O=¼tr F² 在两侧谷取【不同值】：O_L ≠ O_R，否则 f₁²=0（§1.5）。
(C) 垒 ΔV ≳ log L（精确形见 §3.1）：否则 m₁ 不小于箱隙，不进类 3。
(D) 偏置 δ ≲ λ₁（§1.5）：否则 m₁≈δ 非指数。
```

`(A)` 是 `GY2-MIX`（`GY2:184–191`）的直接要求；`(B)` 是宇称/值差要求；`(C)(D)` 是 §1 的闭式要求。

### 2.2 三条候选机制，逐条判

## §3 `barrier ≳ log L` 这个门槛：假设还是可导出

### 3.1 推导（三步，全部精确）

```
第 1 步 [T]  Kramers/WKB：m₁(g) = λ₁(g) = (√2/π)·g·e^{−g/2}·(1+O(1/g))          （(1.4)）
第 2 步 [T]  靶的假设逐字：m₁²(L) ≤ c/L²      （HN1-H3 §3.3 (c-3)，经 GY2:7）
第 3 步 [T]  合并：  (2g²/π²)e^{−g} ≤ c/L²
             ⟺  g − 2log g ≥ 2log L + log(2/(π²c))
             ⟺  g(L) = 2log L + 2loglog L + log(π²c/2) + o(1)                  (3.1)
```

⇒ **门槛 `barrier ≳ log L` 是 (1.4)+(靶条件) 的代数结果，不是独立假设**；其精确指数是 **`κ=2`**（不是 1）：
`κ:=liminf g/logL`，`κ>2 ⇒ m₁²=L^{−κ+o(1)}≪L^{−2}`（类 3 内部，更深），`κ<2 ⇒ 不进类 3`。

### 3.2 三种「看上去像假设」的东西，其实是量词/算术

| 说法 | 实际身份 | 判 |
|---|---|---|
| 「垒必须随 `L` 增长」 | **靶的 `L→∞` 量词**的推论：固定垒 `g₀` 只在 `L ≤ (cπ²/2)^{1/2}e^{g₀/2}` 内是类 3，指数大的 `L` 之后自动退出 | **`[T]` 不是假设** |
| 「`κ≥2` 是一族选择」 | 是**族参数**，不是假设：`κ=2` 是临界线，`κ>2` 是同族更深处 | **`[T]`** |
| 「门密度必须 `≥c`」 | 与「`κ<2`」等价：`ρ(gate)≍e^{−ΔV}=e^{−g/2}`，故 `κ≥2 ⟺ ρ(gate) ≲ 1/L` | **`[T]`**（与 `Q-WAVE:45` 的 H1 面 (iv) 同一对象的两侧） |

**⇒ 门槛的可导出性带来一个负向结论（本轮的分量在这里）**：既然门槛是靶条件的翻译，它**不携带任何关于 YM 的信息**。任何「因为垒必须 ≳log L 所以双井不可能」的论证都是**循环**（它假设了 `m₁²≲L^{−2}` 的反面）。反过来，任何「YM 的垒最多 O(1) 所以安全」的论证必须**独立**给出垒的 `L`-一致上界——而那正是 §2.4 的具名缺件的对偶形。

### 3.3 判

- **`[T]`**：门槛**可导出**，表达式 (3.1)，临界指数 `κ=2`；它在本路里**零独立内容**。
- **`[T]`**：「垒有 `L`-一致上界」是一条**独立**陈述，且等价于 H1 的面 (iv)（`ρ(gate)≥c`）；本路拿不到免费版本。
- **`[NG]`**：`ρ(gate)` 在 `β=2.5` 的一致地板——具名缺件（同 §2.4）。
- ↳ **下一手**：把 (3.1) 直接写进族定义（`g_κ` 的下阶项），并把「垒的 `L`-一致上界」列为与 H1 (iv) **逐字同一**的待办，避免第四次重复造名。
