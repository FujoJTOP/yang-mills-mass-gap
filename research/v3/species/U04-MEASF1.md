## 1. `O = ¼trF²` 在格点上是什么

取 Wilson 作用量 `S = β_W Σ_p (1 − ½Re tr U_p)`（`β_W = 4/g²`，`N=2`；见 `BETA-CONVENTION.md`），
`a = 1`，`SU(2)` 元素写成四元数 `U = c₀·1 + i c·σ`（`c₀²+|c|² = 1`）。

**Plaquette**：`U_{μν}(x) = U_μ(x) U_ν(x+μ̂) U_μ(x+ν̂)† U_ν(x)†`。

**Clover**（同平面 4 个 plaquette 的平均，含 `x` 的全部）：

```
C_{μν}(x) = ¼ [ U_{μν}(x) + U_{μν}(x−ν̂)† + U_{μν}(x−μ̂)† + U_{μν}(x−μ̂−ν̂) ]
```

（翻转一个指标 ⇒ 反向遍历 = 取 dagger；翻转两个 ⇒ 同向，不取 dagger。`[T]`）

**展开**：`U_{μν} = 1 + i a²F_{μν} + O(a⁴)` ⇒ `C_{μν} = 1 + i a²F_{μν} + O(a⁴)`。
用 `tr(T^aT^b) = ½δ^{ab}`、`F = F^aT^a`，并注意 `½Im tr(σ^a C) = a²F^a`，得

```
F^a_{μν}(x) = (2/a²) Re c_a(C_{μν}(x)) + O(a²)                       [T]
O(x) ≡ ¼ tr F_{μν}F_{μν} = (1/a⁴) Σ_{μ<ν} Σ_{a=1..3} (Re c_a(C_{μν}(x)))²   [T]
```

即 **clover 四元数矢量部分的平方和，对 6 个 `(μ<ν)` 平面求和**（`a=1`）。
`O(x) ≥ 0` **逐点**，且 `|c_a| ≤ 1` ⇒ `O` 有界 ⇒ 所有矩有限
（这点与 `E[κ²]=∞` 的无界情形不同；仍按纪律用 winsor/MAD）。

**时间片算符**（零动量、`A₁⁺⁺`/`0⁺⁺` 投影，无导数结构）：

```
O(t) = (1/V_s) Σ_{x_s} O(x_s, t) ,   V_s = L³
O_B(t) = (1/V_s) Σ_{x_s} Σ_{i<j≤2} Σ_a (Re c_a(C_ij))²   （纯磁场扇区，用于酸测）
```

方向约定：`μ = 0,1,2` 空间，`μ = 3` 时间。周期边界。
`[E]` 实现：`w7/u04_measure_f1sq.py`（`build/measure/sweep/analyse`）。

## 3. 提取 `f₁²` 与 `E₁`

周期 `L_t`、单态：

```
C(t) = f₁² (e^{−E₁t} + e^{−E₁(L_t−t)}) / (1 + e^{−L_tE₁})                    [T]
⇒ C(0) = f₁² ,  C(L_t/2) = f₁² / cosh(E₁ L_t/2)
L_t = 2:   f₁² = C(0) ,  E₁ = arccosh( C(0)/C(1) )
```

| `β` | `f₁² = C(0)` | `E₁ = arccosh(C(0)/C(1))` |
|---|---|---|
| 0.0 | 4.1441(103)e−2 | 1.6916(30) |
| 0.5 | 4.1227(120)e−2 | 1.7511(28) |
| 1.0 | 3.9187(108)e−2 | 1.7509(27) |
| 1.5 | 3.4377(103)e−2 | 1.7495(36) |
| 2.0 | 2.8499(79)e−2 | 1.6659(31) |
| 2.3 | 2.3085(87)e−2 | 1.6742(49) |

**这是"数"，不是"测"**。三条结构性理由（各自独立）：

1. `[T]` **自由度 = 0**。两点、两个参数 ⇒ 单态解是**代数恒等**：`f₁² ≡ C(0)`。
   任何 `C(0) > 0` 的系综都会"给出 `f₁² > 0`"。这不是拟合，是重命名。
2. `[T]` **`C(0) = Var(O) ≥ 0` 恒成立**，`O` 逐点非负 ⇒ 只要 `O` 不是常数就有 `C(0) > 0`。
   故 `β=0`（无动力学）也"给出" `f₁² > 0`（见第 4 节）。
3. `[C]` **`E₁` 对 `β` 不敏感**：`1.67–1.75` 跨越 `⟨U_p⟩: 0.001 → 0.639`。
   物理 `0⁺⁺` 质量应 ∝ `a(β)` 单调下落；水平线 ⇒ 落在格点截断尺度。
   同 `t02` 的 `β=0 → f₁²=0` 一起看，这条水平线**正是**"接触项"的指纹。

## 4. 判：(a) / (b) / (c)

### (a) 若 `f₁² > 0` 数值上成立 ⇒ `(CP)` 的证据？

**不成立。** 数值上 `f₁² = C(0) > 0` 是 40σ 级别的"成立"，但**它同时是 `β=0` 的成立**。
`β=0` 时测度是纯 Haar（无作用量、无传播、无质量隙），按 `t02` 应有 `f₁² = 0`：

```
β=0:  f₁²_est = 4.1441(103)e−2   (40σ) ,   E₁ = 1.6916(30)
```

一个在真值 `0` 处仍报 `40σ` 非零的估计器**不能**用来报 `(CP)`。
这正是 `E[κ²]=∞` 的教训的同一形状：**估计量的"正"来自定义（`C(0)=Var≥0`），
不来自物理**。本文因此**不写** `(CP)` 数值证据。
`[C]` 反证细节：纯磁场扇区 `C_B(1) ≈ 0`（≤1.5σ，六个 `β` 全如此），
而 `C_B(0) ≈ 2×10⁻²` ⇒ `t = L/2` 上**没有传播信号**；全 `F²` 的 `C(1) ≠ 0` 完全由
`L_t = 2` 的**共享链接**（唯一时间薄板上的 temporal plaquette + 经 clover 反射共用的空间链接）
制造。共享链接 = 接触项。

### (b) `f₁² ≈ 0` 或负？

不是。数值 `f₁² = C(0) > 0`，且 `C(1) > 0`。**但**这与 (b) 的"`β=0` 时 `f₁²=0`"
**不矛盾也不印证** —— 因为 (b) 说的是物理 `f₁²`，而 `L=2` 的估计器在 `β=0` 给出
`4.1×10⁻² > 0`。`β`-依赖表（§3）显示：`f₁²_est` 随 `β` 单调**下降 44%**（`4.14 → 2.31`），
`E₁` 基本不动。这个下降可由"`O` 的分布随 `β` 变窄"（`⟨O⟩` 从 1.118 降到 0.778）
完全解释，**不需要**任何 `f₁²` 物理。故 `β`-依赖**也**不给 (a)/(b) 判据。

### (c) `L=2` 太小 —— **是。本文判 (c)。**

`L=2` 上：
* 时间方向只有 2 个点，`t = 1` 就是 `L/2`（反周期点/最大间距），既不能做有效质量平台，
  也不能做 2 态拟合；
* `t = L/2` 的那一点被共享链接污染（§4a），**接触项 ≫ 传播项**；
* 自由度 = 0（§3.1）⇒ 无残差、无 `χ²`、无系统误差估计。

**必须 `L ≥ 4`**（要 `t = 0,1,2` 三点才能让 1 态拟合有 1 个自由度并检验指数性）；
真正提取 `f₁²` 需要 `L ≥ 8`（`t = 0..4`，看到 `t = 2..4` 的平台）。
`[C]` `L=4` 已实测（§5）：`E₁(2.0)` 从 `L=2` 的 `1.67` 变成 `2.35`，`C_B(L/2) ≈ 0` 依旧
⇒ `L=4` 单点**也不够**做物理判读（接触项仍在 `C(1)` 里，只是被稀释），
`L=4` 的价值是"给 `L≥8` 定标 + 证明 `L=2` 的质量是假象"。

`[C]` `L=4` 的三条读数：
1. `C(1)/C(0)` 从 `0.365` 掉到 `0.0965`，`E₁` 从 `1.67` 抬到 `2.35` ⇒ **`L=2` 的"质量"随 `L`
   剧烈移动**（`+41%`），这正是接触项主导的指纹（物理质量不该随箱子大小变）。
2. 纯磁场扇区在 `t = L/2` 上**又**是 ~0（`1.8(2.3)e−5`，≤1σ，`L=2` 处同样 `≤1.5σ`）
   ⇒ 磁场信号在最大间距上消失，这是格点事实而非统计。
3. `⟨O⟩`/`⟨U_p⟩` 的 `L=2 ↔ L=4` 差异（`0.861 → 0.919`，`0.560 → 0.505`）说明 `L=2` **连
   VEV 都没收敛**（`L=2` 的 `β=2.0` 值偏高，因为只有 2 个时间片）。

**归一化警告（必须写在数旁）**：本文的 `O(t)` 用 `1/V_s` 平均。对 ultralocal 算符，
`C(0) ∝ 1/V_s` ⇒ `f₁²_avg` **不是**物理残数（物理残数对应 `Σ_{x_s}` 求和、`f²_sum = V_s² f²_avg`）。
实测 `C(0)_avg(L=2)/C(0)_avg(L=4) = 16.6`，而纯体积因子是 `64/8 = 8` ⇒ 剩下 `~2×` 来自逐点
方差随 `L` 变化。因此 §3 的 `f₁²` 数字**只在本节的归一化下有意义**，跨 `L` 不可直接比。

**结论（代价）**：以纯 Python 现码，`L=2` 全 `β` 扫描 20 s；`L=4` 单 `β` `therm=300/meas=600`
14 s（`⟨U_p⟩` 误差 0.35%）。要 `L=4` 拿"3 点 + 5%"，估 `≈10 min/(β·种子)`；
`L=8`（`t=0..4`、看平台）估 **≥5 h/(β·种子)**，`β≳2.3` 的临界慢化再抬一个量级。
要把 `f₁²` 从会计恒等式变成测量，**必须**先做矢量化/`numba` 重写（`sweep`/`measure` 的
`O(L⁴)` Python 环换数组核），否则 `L≥8` 不可达。
