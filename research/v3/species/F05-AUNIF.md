## 3. 核心：`δ ∝ 1/a` 的方向（`I2` 的 `Λ★ − m₁² ≥ δ`）

### 3.1 先拆槽位（不然必错）

`δ` 在语料里是**三个不同的量**（`X02:117–127` 逐字）：

| 名 | 值 | 量纲 | 备注 |
|---|---|---|---|
| `δ_L1` | `ln(1/ū)/a = κ/4 − ln(ē)/a` | **质量**（`1/a`） | `t`-指数上的余项率 |
| `δ_I2` | `Λ★ − m₁²` | **质量²**（`1/a²`） | `I2` 的那个 |
| `δ_phys` | `≈0.5m₁` | 质量 | `[M]/[E]`（`ch05:151`） |

桥（`[T]`，`X02:131–137`）：`Λ★=(m₁^{dr}+δ_A)²` ⇒

```
Λ★ − m₁² = 2 m₁ δ_A + δ_A²       （δ_A := δ_L1）
```

⇒ **`δ ∝ 1/a` 与 `Λ★−m₁² ∝ 1/a²` 不是同一个幂次，不抵消，也不是同一个槽。**

### 3.2 幂次表（`[T]`，纯量纲）

```
m₁ δ_A   ∝ (1/a)(1/a) = 1/a²          δ_A² ∝ 1/a²
Λ★ − m₁² ∝ 1/a²                        δ_A  ∝ 1/a
⇒ (Λ★−m₁²)/δ_A ∝ 1/a → ∞              ⇒ (Λ★−m₁²)/m₁² = 2r + r² ，r:=δ_A/m₁  【a-无关】
```

### 3.3 `1/a` 到底"帮忙"还是"捣乱"—— 都不是

- **不是帮忙**：`a→0` 时 `Λ★−m₁²→∞` 只是"格点单位 ⇒ 物理单位"的换算（`×1/a²`）。真正的内容是**无量纲比值**：
  `r = δ_A/m₁ = ln(1/ū)/[4ln(1/u)]`，`ρ² := Λ★/m₁² = (1+r)²`。
  `[E]` 代入 `SU(2)`、`β_W=1/12`（`u=0.0104`、`ē=54.3656`、`κ/4·a=4.56595`、`δ_A·a=0.57022`）：
  `r = 0.1249`、`ρ² = 1.2652`、`(Λ★−m₁²)/m₁² = 2r+r² = 0.2652`、**`(Λ★−m₁²)a² = 5.53`（a-无关纯数）**。
  上确界读法（`δ_A=κ/4`，`r=1/4`）：`ρ² = 25/16 = 1.5625`、余量 `9/16 m₁²`。
- **不是捣乱**：`δ_A>0 ⟺ ū<1 ⟺ u<1/ē ⟺ β<β₁=8/ē=0.14715` —— **窗本身 a-无关**（`C03:183` 的 `0.147152` 就是这个数）。所以 `a→0` **既不缩窗也不宽窗**。
- **真正的危险（唯一）**：`δ_A = (1/a)[ln(1/u) − ln ē]` 是**两个 `1/a` 项之差**，`1/a` 是**放大器**。`ln ē` 里一个 `O(a)` 的相对修正 → `δ_A` 里 `O(1)` 的修正 → 可翻符号。故 `ē=eΔC̄` 必须**精确 a-无关**：`Δ`（KP 动物常数）、`C̄`（Ursell 常数）、`Ĉ`（`=4`，逐 plaquette）都是格点组合数，无 `a`（`Z12:124,206`；`Z07:100`）⇒ 现无破坏，但这是**唯一**能破坏 `a`-一致的通道，须写死。

### 3.4 判

**`δ ∝ 1/a` 既不"帮忙"也不"抵消"：它与 `Λ★−m₁²` 差一个幂次（`1/a` vs `1/a²`），`I2` 的内容是 a-无关纯数 `ρ²>1`（`≈1.265`，上界 `25/16`）。** ⇒ **`a→0` 不是"隔离越强越好"；它是同一句话换单位。**
