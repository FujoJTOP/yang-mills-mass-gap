## 1. 自由场上 `V_∞` 还是 `tan²(θ/2)/36` 吗？

**是，一个字节都不变** —— 但**"不变"本身就是病灶**。

`V_∞` 的定义是 `lim_{β→∞}Var`（`O20` 命题 3），`O20` 的精确缩放恒等式给出

```
Var(f) = β²sin²(θ/2)·Var_B(g) = V_∞(θ)·Ψ(B),   Ψ(B) := 36B²Var_B(g),  B=βcos(θ/2)
```

`β` 在 `V_∞` 里**解析地约掉**，只剩 `θ`。所以自由场（`β→0`，此时 `B→0`、`Ψ→0`）**改不了 `V_∞` 的值**，只能改 `Ψ`：

| `B` | `Ψ = Var/V_∞` | 说明 |
|---|---|---|
| `1e−6` | `3.98e−13` | 自由端：界小到 0（`Ψ ∝ B²`，`W(0)=0.0110593`） |
| `0.1` | `3.857e−3` | `Ψ ≈ 36B²W(0)` |
| `1` | `0.263366` | |
| `10` | `0.980775` | |
| `1e4` | `0.99998689` | `YM` 侧（`β→∞`）：界**饱和**，等号在 `B=∞` |

**于是出现酸测要抓的形状**：`Var ≤ V_∞` 这条腿的**等号在 `B=∞` 的 Gaussian/Rayleigh 涨落处取到**（`O20` 命题 2：`Var(y²)=4` 精确，`g=1/2−y²/(6B)+O(B^{−2})`）——**它是自由涨落的常数**，不是相互作用量。自由场上它当然成立（还松到无穷倍）。**"对自由场也成立的上界"不可能是 YM 侧的证据。**

另注：自由场上 `V_∞` 仍是**非零**有限常数，所以不存在"`V_∞=0` 使 `β₀=0`"的第三类（`(iii)`）。

## 2. 自由场上 `c_∞ = cos(θ/2)/4` 吗？—— 任务猜的 `c_∞=0` **不成立**

**否。`c_∞ ≠ 0`，而且自由场把它变得更大。** 任务问的"自由场 `E[H]=0` ⇒ `c_∞=0`？"错在把 `c` 的对象记成 `H` 了。`O21:64` 的定义是

```
c(β) := E[H_vv + Φ''|0] / (β‖v‖²)
```

两点，逐条：

1. **`E[H]→0` 是对的**：`H_vv = (B/2)g(u)`（归一由 `O20 [P5]` 的 `0.25(B sin u/u+ψ'/u)`、`sin u/u=2g` 定；本文数值复算 `O21` 表到 4 位，见 §5），`B=βcos(θ/2)→0 ⇒ E[H]→0`。
2. **但 `Φ'' = 2/r² − cot(r/2)/r ⪰ 0` 有 `β`-无关地板**：Haar 律下 `E[Φ''] = 0.2051153`（`u→0` 时 `Φ''→1/6`）。所以

```
c(β) = (E[H] + E[Φ''])/β:   β=1e−3 → 205.2      β=0.01 → 20.62     β=0.157 → 1.418
                            β=0.5  → 0.5285     β=2.5  → 0.223273   β=6     → 0.192499
                            β→∞    → c_∞ = cos(θ/2)/4 = 0.176777
```

`c(β)` **单调降、`β`-一致下确界在 `β=∞`**。`c_∞` 是**大 `β` 端点**的值，不是自由场的值；自由场在它的**另一头**（`c=+∞`）。⇒ **`c_∞ = 0` 是错的，`β₀ = V_∞/c_∞` 有限，所以不是 `(i)`。**

## 3. 第二条腿的字面版在任何有限 `β` 上不成立（独立缺陷）

## 6. 为什么必然 vacuous（结构原因，比数字重要）

1. `V_∞ = tan²(θ/2)/36` 是 `B=∞` 的 **Gaussian/Rayleigh 涨落值**（`Var(y²)=4` 精确，`O20` 命题 2）。它是**自由涨落常数**。
2. `c_∞ = cos(θ/2)/4 = Q(ρ=0) = Re tr U_p/(4N)`（`O21:40/137`）是 **`U_p=1` 平凡 plaquette 构型**上的值 —— 正是任务列的自由场端点 `U_p=1`。
3. 于是 `β₀ = V_∞/c_∞` 是**两个自由构型常数之比**，纯 `θ`-运动学，**不含任何相互作用信息**；`H1(M)` 里剩下的全部内容由 `Φ'' ≥ N/12` 的 Haar 地板承载，而自由场的地板**一模一样**（`0.2051`）。
4. 这正是 `H1A-EXACT §0` 早就记录的结构发现（模型 2/3/4：`Var=0`、`E[H]=0`，H1 仍真）。**P13 只是把它抬到阈值层：`β₀` 不是 YM 的量。**

## 7. 重造方向（不算结论，只给下一步）

要让酸测通过，工具必须**在自由场取 0 或反向**。三个候选，都不需要新数值框架：
1. **`Φ'' − N/12` 的超额**（interaction excess）：自由场恒 `0`，YM 侧 `>0`；`β₀` 由它的零点给。
2. **`Var` 的下界**：自由场 `Var→0`（`∝β²`）⇒ 任何 `Var ≥ cβ^{−p}` 型下界在自由端自动失效，正是要的形状。
3. **`G''(0)` 本身的符号/零点**（`H1A §1.3`：H1 ⟺ `G''≥δ` 是恒等，不是估计）⇒ 阈值改为 `G''(0)` 的零点定位，而不是两个自由常数的比。
