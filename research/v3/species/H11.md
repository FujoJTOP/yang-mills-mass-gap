## §1 · thin atom 缺什么（逐项核，不是印象）

取 `ν_ε = wδ_ε + (1−w)δ_{s₂}`，`w = ε/(2λ)`，`s₂ = 2λ(1−w)`：

| 条件 | thin atom | 依据 |
|---|---|---|
| `H1`：`χ = ∫s⁻¹dν ≤ 1/λ` | **真，取等**：`w/ε + (1−w)/s₂ = 1/(2λ)+1/(2λ) = 1/λ` | `ch02:101–105,123–127` |
| `M₀ = ∫dν = 1`（归一化 F4） | **真** | 同上 |
| `I2`：`Λ★ − m₁² ≥ δ` | **真**：`Λ★ = s₂ = 2λ(1−w)`，`m₁² = ε`，余量 `= 2λ(1−w) − ε → 2λ > 0` | `Q02-H1I2.md:106–118`（`λ=1, ε=1e−6`：余量 `1.999998`） |
| 全部矩有限且收敛 | **真**：`m_k(ν_ε) = wε^k + (1−w)a^k → a^k`（`k ≥ 1`） | `sg1/main.tex:282–301`（Lemma「all moments converge, `s₁` jumps」） |
| 正性 / `ν ≥ 0` | **真** | 定义 |
| `G″ = 1/χ = λ > 0`（曲率正） | **真** | `Q6:333` |
| **`f₁² = ν({m₁²})`** | **假**：`f₁² = w = ε/(2λ) → 0`；`s₁ = inf supp ν = ε → 0` | `ch02:120–121,126` |

**⇒ thin atom 满足 `H1`、`I2`、归一化、正性、全部矩、曲率正；它只缺一样：原子自己的重量 `f₁²`。**

**机制一行 `[T]`**：`χ = ∫s⁻¹dν` 是**残数加权调和平均**；thin atom 取 `w ∼ ε` 使 `w/ε` 保持 `O(1)` ⇒ **H1 只看见 `w/ε`，看不见 `w`**（`ch02:106–109` 逐字 "the susceptibility sees the *residue-weighted* mass, not the lightest mass"）。
**⇒ 补口必须是那个"不被 `s` 除"的量** —— 也就是 `f₁²`。这不是选择题，是 `χ` 的定义式所迫。

## §3 · 出口 (a)：`(?)` 是什么

### §3.1 逐字

```
(?) = I1 :   f₁² = ν({m₁²}) ≥ r₀ > 0        （等价坐标：w₁ = f₁²/M₀ ≥ w₀，M₀ 归一后）
H1  ∧  I1   ⇒   m₁² ≥ f₁²/χ ≥ r₀ λ > 0       [T]
```

依据逐条：squeeze `f₁²/χ ≤ m₁² ≤ M₀/χ`（`ch02:335` 账、`ch02:62–82` 锐性）；`eq:sufficient` 逐字 `(f₁² ≥ r₀) ∧ (χ ≤ 1/λ) ⇒ m₁² ≥ f₁²/χ ≥ r₀λ > 0`（`ch02:197–203`）；Lean `cert_necessity`（`ch02:158–161`）：`0<f ∧ 0<χ ∧ 0<λ ∧ χ≤1/λ ∧ f≤χm ∧ 0<m ⇒ λf ≤ m`。

### §3.2 为什么它补上 thin atom 的缺口

thin atom 的 `H1` 之所以成立，是因为它把 `w` 与 `ε` 一起送向 0（`w/ε = 1/(2λ)` 固定）。`I1` 恰好是**对 `w` 本身**（不是对 `w/ε`）设地板 ⇒ 该族在 `ε` 足够小时**被逐出可行集**。这不是"再加一条更强的假设"，而是**把 H1 看不见的那一维补上**：`χ` 只固定了 `f₁²/m₁²` 与尾部的和，`f₁²` 是 `ν` 在底部的**权重**，与 `χ` 线性无关。

### §3.3 `(?)` 的**形式唯一**（本轮的正面结构句）`[T]`

squeeze 的下界**在全体测度上锐**：`ch02:72–76` 逐字 "For every `η>0` there is a measure with `f₁²/χ ≤ η`（thin atom at tiny mass）…… Hence **no improvement of either constant is possible without extra structure**"。
⇒ 任何**不**给 `f₁²` 正下界的补口，都留下 `m₁² ≤ M₀/χ`（甚至 `→0`）的可行点 ⇒ 出不了 `m>0`。
⇒ 在"不直接写 `m₁>0`（那才是循环）"的补口里，**唯一的自由度就是 `f₁²`**。这就是 `(?)`。

## §4 · 三条要求的逐条核（这是判死线 (a) 的实质）

### §4.1 ① 从 `S_W` 可算？—— **可算，且与 `χ` 同一份数据**

`f₁²` = `C(t) := ⟨¼trF²(t) ¼trF²(0)⟩_c` 的**最慢指数幅度**；`χ = ∫s⁻¹dν` 是同一 `C(t)` 的 `k→0` 零模方差（`Q6:76–80`：`C̃(k) = ∫e^{ikx}C(x) → χ`）。二者是**同一个 Boltzmann 平均 `μ ∝ e^{−S_W}`** 的两个读数 ⇒ **`χ` 可算到什么程度，`f₁²` 就可算到什么程度**。

已算出的值（不是潜能）：
- `β=2.5`：`w₁(L=8) = 0.3427 ± 0.0119`（`28.8σ`）、`w₁(L=6) = 0.373 ± 0.018`（`20.7σ`）（`w1/main.tex:201–203,233`；裸 base `¼trF²`，**不是** APE base）。
- `β=0`：`χ = 3.7198` 精确（`Q6:343`）；强耦 `w₁ = s/2`（`yang-mills-frontier:338` 段）。
⇒ **可算性 `[T]`（同一泛函类、同一数据）；值 `[E]`。**

**两处必须写的限定**（否则是编）：
1. **它不可由矩算**：`f₁²` **不是**矩泛函 —— `ν_ε` 与 `δ_a` 有相同的全部矩极限而 `f₁² = 0` vs `1` `[T]`（`sg1:282–301` 的同一族）。这正是它**既唯一正确、又拿不到**的原因：它恰在 **SG1-1**（矩型 `F ≤ s₁` = ∅，`[C]`）所杀类之外。
2. **它按算符定**：`w₁(O_θ) = cos²θ` 扫过 `[0,1]` 而 `Spec(H)` 不动（`w1:270–272,395–403`）⇒ 地板必须写在**固定算符** `O = ¼trF²` 上（N09-1 的窗口）。

### §4.2 ② 不循环？—— **双向独立，两个精确见证**

| 方向 | 见证 | 数 |
|---|---|---|
| 隙 ⇏ `I1` | **2D YM** | `m = 3g²/8 > 0` 而 `ν_{¼trF²} ≡ 0` ⇒ `w₁ ≡ 0`（`ch14:256`） |
| `I1` ⇏ 隙 | **M6**（谐振子⊗自由模） | `w₁ = 0.5`（单原子，`E₁=ω=1`）而 `m = 0`（`ch14:259`；`w1:390`） |

⇒ `I1` **不是隙的改写**（这正是 `U6` 的 `W` 与 `I` 不可比、`W ⊥ gap`）。补口**不是**"补它的就是隙"。
