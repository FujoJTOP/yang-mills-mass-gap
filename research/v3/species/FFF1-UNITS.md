## §0 裁决

`[T]` **`Δ_a := inf{λ∈σ(−(1/a)log T_a|_{Ω⊥}): λ>0}` 以质量为单位，`Δ_a = m_phys`**（不是 `m_phys·a`）。
因此「`Δ_a = m_phys·a` ⇒ `Δ_a→0` ⇒ `∃δ>0 ∀a: Δ_a ≥ δ` 为假」这条链在**第一行**断：前提是 `[T]`-假。
真正为假的是它的**格点单位孪生句** `∃Δ₀>0 ∀a: a·Δ_a ≥ Δ₀`（= SS6 的 `(i)`）——两者恰差**一个 `a`**。
⇒ 本路判：原陈述**不需要改归一**；`Δ_a ≥ δ` 就是要证的东西，状态 `[NG]`。

## §3 正确形（三候选 → 选 A）

- **(A) `∃δ>0 ∀a<a₀: Δ_a ≥ δ`**（δ 质量量纲）——**选它**。仓内规范同形：`∃Δ₀>0 ∀(L,a): m_L/Λ ≥ Δ₀`（`GH1-SPECTRAL.md:92`）；`Λ` 与 `a` 无关 ⇒ 两式只差 `δ ↔ δ/Λ`（`A04-RATIO2.md:91` 转引：`a` 约掉）。
- **(B) `Δ_a/a ≥ δ`** ——错。真单位下它 = `Δ_a ≥ δa`：一条**随 `a` 消失**的下界；自由场对**任意** δ 皆真（`Δ_a→m`），且容忍 `Δ_a ≍ δa` 型把隙送到 0 的族 ⇒ 零内容、严格弱于 (A)。它只是 (A) 在「`Δ_a = m_phys·a`」这一 **`[T]`-假代换**下的影子。
- **(C) `∃λ>0: G″_a ≥ λ` ⇔ `aΔ_a ≥ √λ`** ——错。`[T]`-假（同上格点单位行），且与 Clay **反向**：Clay ⇒ `m_lat = aΔ_a → 0`；`λ>0` 常数地板 ⇒ `m_phys ≥ √λ/a → ∞`（`Q6-H1-STATUS.md:314–315` 逐字）。这正是 SS6 `(i)`。
- **为何 (A) 对**：它是唯一同时满足「量纲 = 质量」「`(L,a)`-一致」「与已证桥相容」的写法；与 `Δ_cont ≥ liminf_{a→0} Δ_a`（`glue-b-blocking/REPORT.md:277–279` 直读，`[T]`）合用即 `[窗口地板] ⇒ Clay`（`docs/FINDING-02-TWO-HALVES.md:3`，转引）。
- **(A) 必带限定**（`AGENTS §2.1`）：窗口 `a ≤ a₀`（标度窗 `β(a)→∞`，`GC1-NEW.md:83` 转引）；`δ` 与 `(L,a)` 无关；强耦合区 `Δ_a~1/a` 自动满足，不承重。
**下一手**：把 (A) 登记为唯一「隙为正」陈述，其余两形只在引文中作反例保留。
