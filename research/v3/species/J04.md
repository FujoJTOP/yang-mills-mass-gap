## §3 · ★ 2D：`O = ¼trF²` 是否触及基态？（题面核心）

**(3.1) `F∧F ≡ 0` 在 2D 是空话** `[T]`。2D 上 `F` 是唯一的 2-形式，`F∧F` 是 4-形式而 `Λ⁴=0` ⇒ 该式**恒零、零信息**，与 `¼trF²` 的真空期望值**无关**。

**(3.2) `¼trF²` 是 Hodge 平方，不是拓扑荷** `[T]`。2D 只有 `F₀₁=E`：
```
¼ tr F_μν F^μν = ½ tr F₀₁² = g² · h ,   h := (1/g²)·½trE² = 能量密度 ≥ 0
拓扑密度是**线性的** trF₀₁（积分量子化 ∝ n）；¼trF² 是**二次的** ⇒ 不量子化、非拓扑
```
⇒ `F∧F≡0` 既不使 `¼trF²` 为零，也不使它成为拓扑项。**它是 `≥0` 的能量密度。**

**(3.3) 所以它不"触及"基态——它湮灭基态** `[T]`+`[E]`。2D YM 的真空是规范轨道空间上的常波函数，`E=−i∂` ⇒ `E|Ω⟩=0` ⇒ `h|Ω⟩=0` ⇒
```
O|Ω⟩ = g²H|Ω⟩ = 0     ⇒     [O,H]=0（O 是守恒荷）  ⇒  ν_{O,c} ≡ 0  ⇒  m₁ = +∞
```
机检：`O_{nk}=½C₂(n)δ_nk`、`⟨Ω|O|k⟩=0 ∀k`、`Σ=0`（精确有理数，`log [B]`）。`ATOM2:15,60,73` 同判。
**限定（`AGENTS §2.1`）**：这条 `ν≡0` 是**逐算符**的：同一模型换 `O=½trU` 给 `m₁=3g²/8=m`（原子权重 `1`，精确；`ATOM2:81`）。2D 的"空"是**维数锁定**（4D 的 `¼trF²` 含 `B²`、不守恒，`IMP-ARROWS:62`），**不搬 4D**。
**另加窗口**：2D 的 `3g²/8` 是**空间单链（`L=1`）截断**；圆上 `L` 链给 `L·3g²/8`（`ATOM2:70–71`）⇒ 该读数不承重、也不可与 torelon 混（`G04:27`）。
