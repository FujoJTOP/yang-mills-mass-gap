## 3 · ★ 关键：见证是不是合法物理测度？搬到 `T̃` 上的两处违规

### 3.1 三条互斥出口（`D` 行展开）

1. **`δ₀` = VEV？** `¼trF²` 的 VEV `⟨0|¼trF²|0⟩ ≠ 0`（胶子凝聚），无减除测度里它正是 `s=0` 的原子，质量 `|⟨0|O|0⟩|²`。**语料的 `ν` 不是它**：`F06:53` 逐字把 `ν_L` 建在 `(O−⟨O⟩)Ω_L` 上。减掉后，见证的底上**没有任何原子**（`[δ,δ+1]` 是 a.c.）⇒ `f₁² = ν({m₁²}) = 0` ⇒ **`I1` 当场为假**，`I1∧I2` 不成立。
2. **`δ₀` = 连通测度里的原子？** 那要求 `Ω^⊥` 里有一个 `E=0` 的态：**真空简并**。纯 YM 上被 PF 唯一真空排除（`B01-RP:11` 逐字"唯一真空 `Ω`（`λ₁=1` 单重，Perron–Frobenius，需正核）"）`[T]`。
3. **`δ₀` = 无质量 `0⁺⁺` 态？** 那么它的二粒子阈在 `0`，不在 `δ`；而 `¼trF²` 是两胶子算子，成对耦合 ⇒ 连续谱应从 `0` 开，见证的 `[δ,δ+1]` 与自己的底**不自洽**（`[C]`：要豁免需"该态与 `¼trF²` 不成对耦合"，无据）。另：有限 `L` 上 `T_L` 紧 ⇒ `spec` **纯点，根本没有 a.c.**（`F06:73`）；a.c. 只在 `L=∞` 出现，且必须从阈开。

⇒ **见证是合法的正测度、合法的"原子+割"形状**（`R2 Lemma B` 的 `0.6δ₄+1_{(4,∞)}e^{−(s−4)}ds` 同形，`F06:24`），**但把原子放在 `s=0` 就要求"裸的零能态"**。故：**把它当 `ν_{¼trF²}` 是非法**；把它当抽象测度是合法。二者区别就是本裁的落点。

## 4 · 判：(a)/(b)/(c) 逐条

**(a) 不成立 `[NG]`。** 见证**不**同时是 `Kato` 的见证：去真空后 `r_iso=0`；含真空则 `m` 必须由 `rest` 反解（`=δ>0`）。两种情况都到不了 `Kato ∧ ¬(m>0)`。

**(b) 成立 `[T]`。** 见证**非法/不适用**于 `ν_{¼trF²}`：三条出口（VEV 必须减除 / 真空简并被 PF 排除 / 无质量阈不自洽）全关；并且**搬运那一步**（`ν` 层距 ⇒ `T̃` 谱距）在 `I1∧I2` 里没有。⇒ **`g04` 的反例对 `f04` 无效**。

**(c) 半成立、须改写 `[T]`。** 题面给的"`r_iso`（`T̃` 谱）vs `Λ★`（`ν` 支撑）是两个不同的量"——**按语料自己的话不成立**：`F04:15` 写"同构"、`RUNBOOK:8106` 写"`⟺`"、2D YM 上同值 `0.625`。**它们是同一个量（距离）。** 真分歧是：
```
r_iso  ≡ (距离) = E₂−E₁ = Λ★−m₁²          （平移协变，给不出位置）
m      ≡ (位置) = E₁ = inf supp ν          （位置命题）
```
⇒ `Kato ⇒ m>0` 的**逻辑通道**只有一条：旁条件 `sup spec T̃ < 1`（`F04:105` 写作 `λ_bot(T̃)<1`；此处 `λ_bot` 指 `spec T̃` 的**上端**，否则 `[0, λ_bot−κ]` 无意义——**命名待改**）。而由 `B01-RP:12`，`sup spec T̃ < 1` **逐字就是 `m>0`**。故：
```
Kato ⇒ m>0     为真 [T]（含旁条件）
Kato ∧ (m>0) ⇒ (m>0)   ⇒ 蕴含**空转**，0 新内容 [T]
去掉旁条件 ⇒ 为假，唯一反例族 = 真空简并（0∈spec H|_{Ω^⊥} 为原子）：r_iso=1−e^{−aδ}=0.4484>0、m=0
```
