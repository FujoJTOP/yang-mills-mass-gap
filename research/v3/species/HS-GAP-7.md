## §1 `ε(w₁−w₀) ≥ 0`：两行证明 + 它实际说了什么

```
设 ν_w 概率化（M₀=1）、s₁=inf supp、s₂=第二支撑点、ε=s₂−s₁>0、δ₁=Ē−s₁、Δ=∫_{[s₂,∞)}(s−s₂)dν_w
QI-1:  w₁ = 1 − δ₁/ε + Δ/ε                                            [T]（QI-BRACKET:114）
⇒  ε(w₁−w₀) = ε(1−w₀) − δ₁ + Δ = [(1−w₀)ε + Δ] − δ₁                  （一行代数）
⇒  预算形  δ₁ ≤ (1−w₀)ε + Δ   ⟺   ε(w₁−w₀) ≥ 0   ⟺（ε>0）  w₁ ≥ w₀ = 靶   [T]
```

**三个读法，都在 [T] 里，且都指向"零内容"：**
1. **它不是新坐标**：预算形与靶之间只差一个正因子 `ε`。HQ4 的"⟺"是对的，但它的**力量来源**不是 `δ₁,Δ` 的估计，而是这次乘除——`(δ₁,ε,Δ)` 是靶的**参数化**，不是靶的**分解**。
2. **它解释了"为什么 `④` 承重"**：`err(w₁) = err(δ₁)/ε`。`ε` 是分母 ⇒ `ε→0` 时任何对 `δ₁` 的常数级误差都被放大到毁掉证书——这正是自由场上 `ϑ→−∞`（`QI:194`）与 `N_eff→∞`（`QI:145`）的同一句话。
3. **它让 c-2.4 变精确**：HQ4 说"`ϑ` 与 `Δ/ε` 的方案依赖必须相消"（`HQ4:268`），本轮的版本更强——**不是"必须相消"，而是"只能以乘积形式出现"**：`w₁` 的读数就是 `ε(w₁−w₀)` 除以 `ε`，两项的误差按除法合成。

**⇒ 判**：**`[T]`**（恒等式 + 等价重写）。**下一手**：全仓把 `(B)₁^bud` 记成"靶 × `ε`"，并把它从"候选靶面"栏移到"靶的同一式"栏（与 `HQ6:247` 的 `Δ` 形对齐，见 0.8）。
