## 1. `L=2` 周期 4D 的 plaquette 计数（核准）

**算法**（`o26_varjump.py:plaquettes(L)`，枚举，非公式）：周期环面 `Z_L^4` 上，取所有平面 `μ<ν`（`C(4,2)=6`）与所有位点 `x∈Z_L^4`（`L^4` 个），每个 `(x,μ,ν)` 生成 4 条 link 的集合

```
(x,μ), (x+μ̂,ν), (x,ν), (x+ν̂,μ)          # 模 L 取余
```

以 `frozenset` 为键去重，统计多重度。

| `L` | 项数 `6L^4` | 不同 link 集合 | 多重度 | `6L^4/2` |
|---|---|---|---|---|
| 1 | 6 | 6 | `[1]` | 3 |
| **2** | **96** | **96** | **`[1]`** | 48 |
| 4 | 1536 | 1536 | `[1]` | 768 |

**判（逐字）**：
- **`N_p(L=2) = 96 = 6L^4`**。`S_W = βΣ_P(1−…)` 的求和恰是 96 项，每项对应一个**互不相同**的 link 集合 ⇒ **无重复计数**，`[T]`（公式）+ `[E]`（枚举，多重度全 `1`）。
- **`48` 是错的**。`6L^4/2` 在这里不对应任何物理计数。曾被设想为"`x` 与 `x+μ̂+ν̂` 给出同一 plaquette"的**反向定向配对**——**枚举否证**：`x` 的集合是 `{(x,μ),(x+μ̂,ν),(x,ν),(x+ν̂,μ)}`，`x+μ̂+ν̂` 的集合是 `{(x+μ̂+ν̂,μ),(x+ν̂,ν),(x+μ̂+ν̂,ν),(x+μ̂,μ)}`，四元 link 集合**互不相同**（多重度 `[1]` 即为证）。
- **旁证（对归一化很关键）**：`L=1` 有 **6** 个不同 plaquette，而 `O11-PHYS` 的"单 plaquette 模型"只有 **1** 个 plaquette 项 ⇒ **单 plaquette 模型 ≠ `L=1` 格点**。两侧不是同一族体积的两个成员，per-plaquette 的绝对值不必相等（见 §2）。

## 2. `Var/N_p`：次广延（不是严格广延）

| 归一化 | 单 plaquette | `L=2` | 比 |
|---|---|---|---|
| `Var` 原值 | `0.069121` | `2.0011` | `29.0×` |
| `Var/96`（核准口径） | `0.06912` | **`0.02084`** | `0.302` |
| `Var/48`（否证口径，仅对照） | `0.06912` | `0.04169` | `0.603` |

- **"30 倍"= `29.0×` ≈ `96^0.737`**，远小于严格广延的 `96×`（那会给 `6.636`，实测 `2.001`，只有 `30.2%`）。**幂次拟合 `Var ∝ N_p^α`：`α = 0.737 < 1`** ⇒ `[E]` **次广延**。
- 但**不可**据此判"`Var` 不是和式"：`Var(F)` 中 `F = ∂_v V`，而 `V = βΣ_P(1−…) + Σ_l Φ_l` 是**局域和式**，`F = Σ_P v_P·(∂_P) + Σ_l v_l·(∂_l Φ)` ⇒ `F` 是和式，`Var(F) = Σ_{i,j}Cov(f_i,f_j) ~ N_p·Var(f)·(1+O(1))`，`α<1` 的缺口来自**格点关联（`Cov≠0`）与模 `v` 的支撑**，不是来自"非和式"。两者不矛盾 `[T]`。
- 另一个必须说的量纲事实：`Var` **二次型于 `v`**（`F` 线性于 `v`），单 plaquette 的 `‖v‖` 支撑在 3 维（一 link），`L=2` 支撑在 192 维。两侧 `‖v‖²=1` 的**分配方式不同**（`v_{l,3}=1/8` 均匀 vs `v=T₃` 单点），故 `Var/N_p` 的绝对值有 `O(1)` 级模型差；**只有 `L`-扫描的同族比较才严格**。`L=2` 是单体积 ⇒ 这里的"次广延"标 `[E]/[C]`。

## 3. 关键：`G_v` 与 `Φ'` 是哪一类量 ⇒ `Δ` 必然广延

**`[T]`（定义直读，非估计）**：`O11-PHYS §1` 与 `GPP-STRUCT:24,62` 给出

```
V = S_W + Φ = β·Σ_P (1 − (1/N)ReTr U_P) + Σ_l Φ_l,     Φ_l = −log J(x_l)
F := ∂_v V = G_v + Φ',    G_v := β·Σ_P ∂_v w_P,    Φ' := Σ_l ∂_v Φ_l
κ := ∂²_v V = H_vv + Φ'',  Φ'' ⪰ 0 点态（Lemma B，`ch05:208`）
Δ = E[κ|0] − Var(F|0) = Δ_dyn + W_geo + X = G''(0)
```

- **`G_v` 与 `Φ'` 都是和式**：`G_v = βΣ_{P=1}^{N_p} ∂_v w_P`（对 plaquette **求和**），`Φ' = Σ_{l=1}^{N_l} ∂_v Φ_l`（对 link **求和**）。`N_p = 6L^4`（`L=2`: `96`），`N_l = 4L^4`（`L=2`: `64`）。
- ⇒ **`E[κ]` 与 `Var(F)` 都是广延量**（`∝ N_p` / `∝ N_l`，至 `O(L^3)` 边界/关联修正）。
- ⇒ **`Δ = E[κ] − Var(F)` 是两个广延量之差 ⇒ `Δ` 本身广延**（同阶 `N_p`；`W_geo`/`X` 分别是 `Φ''`/`Φ'` 的广延块）。
- ⇒ **`Δ` 跨体积不可直比，`Δ/N_p` 才是可比的量。** 这一点是本文件所有判决的骨架。
- **符号的 `‖v‖` 不变性**（`O11-PHYS §1`）：`G''(cv) = G''(v)/c²` ⇒ **`Δ` 的符号与 `‖v‖` 无关**；乘正因子 `L²` 不改符号。

## 4. 判：`Δ/N_p` 变号（b），且变号与归一化无关

| 对象 | `Δ` | `N_p` | **`Δ/N_p`** |
|---|---|---|---|
| 单 plaquette `SU(2)`，`β=2.5` | `+0.1359947` | `1` | **`+0.135995`** |
| `L=2` 4D `SU(2)` 模式A（2 群） | `−0.2209 ± 0.1198` | `96` | **`−0.002301`** |
| （对照）`L=2`，若按 `N_p=48` | `−0.2209` | `48` | `−0.004602` |

- **判死线 (a) 不成立**：`Δ/N_p` **不同号**（`+0.136` vs `−0.0023`）⇒ **"`o11` 的 `L=2` 负值是归一化错"不成立，该警报不能解除——因为它是真的**。
- **判死线 (b) 成立**：变号**是真的**（在 `96`、`48`、以及 `×L²` 三种口径下都变号）。`H1` 在 `L=2` 上**有麻烦**——但按 `O11-PHYS §0` 的显著性纪律，`1.84σ < 3σ` ⇒ **麻烦是"方向不利且未闭合"，不是"已证假"**。
- **判死线 (c) 不触发**：`G_v`/`Φ'` **是**和式（§3），归一化方式就是 `÷N_p`，无"完全不同"的方式可言。
- **注意"变号"的含义边界**：`Δ/N_p` 比的是 `+0.136`（单 plaquette，`N_p=1`）与 `−0.0023`（`L=2`，`N_p=96`）；两个对象的 `v` 支撑维度差 `192/3`，per-plaquette 的**绝对值**不可比（§2 末）。**符号**可比（因 `G''(cv)=G''(v)/c²`，符号对 `‖v‖` 不变）；**这才是本条判决只依赖符号的原因**，也是它弱的地方。要严格，需要 `L=1,2,3,4` 同族扫描 + 同一 `v` 构造。

## 5. `W_full` 与 `a²Δ₀²` 是否在 `Δ` 里

**逐项核（`[T]`）**：`O11-PHYS §1` 的 `V = S_W + Φ`、`Φ = −log J`，故 `κ = H_vv + Φ''`、`F = G_v + Φ'`，于是

```
Δ_measured = E[H_vv + Φ''] − Var(G_v + Φ') = Δ_dyn + W_geo + X = G''(0)
```

| 项 | 在 `Δ` 里？ | 依据 |
|---|---|---|
| `W_geo = E[Φ''] − Var(Φ')` | **在**（经 `Φ = −log J` 全额进入） | `GPP-STRUCT:62`；`ch05:203` |
| `X = −2Cov(G_v,Φ')` | **在**（经 `Var(G_v+Φ')` 的交叉项，中心差分自动含） | `GPP-STRUCT:31,62` |
| `W_full = W_geo + X` | **在（整体）** | `app.tex:796` |
| `a²Δ₀²` | **不在** | `app.tex:190–191`：`δ:=a²Δ₀²+W_full` 是 **H1 的右端阈值**（`(L,a)`-一致的无量纲下界 `Δ₀>0`，语料无数值），**不是**被测量的一项 |

- ⇒ **`O11-PHYS` 的 `Δ` 就是 `G''(0)` 全体**，**不是**"`G''` 的一部分"。缺的只有 `a²Δ₀²`，而它是**目标**（`G'' ≥ δ` 的 `δ`），**不能**加进被测量。
- **但必须诚实标出**：`H1` 的物理陈述是 `G''(0) ≥ a²Δ₀² + W_full`。把它改写成方差式（`app.tex:182–188` 的 (M)）：
  ```
  Var(G_v+Φ'|0) ≤ E[H_vv|0] − a²Δ₀²        （W_full 已含在两端，抵消）
  ```
  ⇒ 本次测的 `Δ = E[κ]−Var(F)` **正是该式左端与 `E[H_vv]` 的差**；判 `Δ` 的符号 = 判 `E[H_vv] − Var(F) − W_full − a²Δ₀²` 的符号再加回 `a²Δ₀²+W_full`。**因 `Δ₀` 无数值、`W_full(L=2)` 未单测，本次只能给出 `Δ` 本身（= `G''(0)`）；不能宣称"已判 H1 的 `δ`"。** `[C]`

## 6. `‖v‖⁻⁴ = L²` 因子：三个互斥可能，判哪个

`GPP-STRUCT:49`（逐字核）：`G''(v;a) = ‖v‖⁻⁴·{E[∂²_vV|ξ=a] − Var(∂_vV|ξ=a)}`，`∂_v:=⟨v,∇⟩` **未归一**；`ch05:208`（Lemma B `E[Φ'']≥(N/12)‖v‖²`）与 `ch05:214–228`（`eq:wgeo-quant`：`c=(N/12)/L`，"an `L`-link average gives `‖v‖²=1/L`"）互相核准这一点；`‖v‖²=1/L ⇒ ‖v‖⁻⁴ = L²`。

**关键事实（决定判哪一个）**：`O11-PHYS §1` 明确写"下表全部取 `‖v‖=1`（`Σ_a v_a²=1`）"，且 `L=2` 模式A 取 `v_{l,3}=1/8` 于 `64` 条 link ⇒ `Σ=64·(1/64)=1`。**两侧都在 `‖v‖²=1` 上**。故：

| 可能 | 判 | 理由 |
|---|---|---|
| **1. `o11` 的 `Δ` 已含 `L²`** | **部分对**：`o11` 的 `Δ` 是 `‖v‖=1` 定义下的 `G''`，**不含** `L²` 的 `L`-link 平均约定；但 `Δ(‖v‖=1)` 就是 `eq:split` 的**隐式约定原式**，用它比 `Δ` 是**文档内合法**的 | `ch05:233–235` 无显式 `‖v‖⁻⁴`（`GPP-STRUCT:203` 逐字核） |
| **2. `o11` 的 `Δ` 未含 `L²` ⇒ 真值 `=4×(−0.221)=−0.884`** | **若改到 `‖v‖²=1/L` 约定，这是对的**：`Δ·L²`，`L=2` 给 `−0.884`，**更负** | `G''(cv)=G''(v)/c²`，`c=1/√L` |
| **3. 单 plaquette 侧 `L` 取法不同 ⇒ 两侧不可直比** | **也部分对**：单 plaquette 模型 **不是** `L=1` 格点（`L=1` 有 6 个 plaquette，模型只有 1 个，§1 旁证）⇒ 它的"`L`"在 `L²` 因子里**没有良定义** | §1 枚举 |

**裁决（逐字）**：乘 `L²` 后 **`+0.13599`（`L=1`）vs `−0.88360`（`L=2`）⇒ 符号相反**。三个可能中 **不改变符号判决的是全部三个**——因为 `‖v‖` 标度只改**幅度**（`Δ→Δ/c²`，`c²>0`），**符号对 `‖v‖` 不变**（`O11-PHYS §1` 已证）。故：

> **`L²` 因子在"符号"这个问题上是无关的；它在"幅度/阈值"问题上才是决定性的（`−0.884` vs `−0.221`：差 `4×`，直接改变 `H1` 需要多少统计量与 `a²Δ₀²` 的比较）。**

## 9. 未闭合（诚实标注）

1. **`L=2` 的 `Δ<0` 只有 `1.84σ`**（`O11-PHYS §4`）。变号**与归一化无关**是本次新结论 `[T]`（符号对 `‖v‖` 不变）+ `[E]`（`96/48/L²` 三口径）；但**"`H1` 在 `L=2` 假"仍未证**，需 `σ≤0.0736`（约 `2.65×` 样本）。

5. **`N_p=48` 的否证只对 `L=2` 周期 `4D` `μ<ν` 计数口径成立**（窗口已标）。开放边界或计入 `μ>ν` 反定向项时，项数分别是 `48`、`192`——那是**不同口径**，本文件只用 `96`（与 `O11`/`ch05` 的 `S_W=βΣ_P` 一致）。
