## §2 · 「过四模型」的精确含义 —— 三种读法，逐个判

被核的那条论证用了一个**未声明**的等价：`G(M6) ≠ 0` ⇒ `G` 不过四模型 ⇒ 所以 `G` 在 `N09-1` 域外。这个推理**成立**；争点只在反向：**域外是否等于"合格但定理管不到"**。三种读法：

| 读法 | 内容 | 判 |
|---|---|---|
| **(i) 逐值读法** | 四模型 = 四个**槽值**：自由场 `0` · 2D `>0` · **M6 `0`** · 单片 `undef`。`position-current.html:327` 逐字；`N12-VERDICT.md:36` 同口径；`N09-RESTATE:27`（"四值签名，不是两值"）、`:49`（"必须恰好取 0"）；`Q03:91`（`I2` 的签名 `(0,+,0,undef)` 被当作"过筛"的**定义**） | **这是语料的实际判据** `[T]`。它把 M6 槽钉成**数值**，不是"可分辨性"。 |
| **(ii) 语义读法（只要求区分有隙/无隙）** | M6 是**无隙**模型（`m₆→0`）⇒ 任何"正 ⇒ 有隙"的量在 M6 上读正 = 断言 M6 有隙 = **错**。⇒ 读法 (ii) 只放行 `X(M6) ≤ 0`，**仍不放行** `X(M6)=ω>0` | **判 (ii) 也不救 `G`** `[T]`。`ω=1>0`，在 (ii) 下同样读作"有隙"。 |
| **(iii) 纯判别读法（"只要能在四模型上取不同值"）** | 只要四槽不全合并即可 | **不作为读法** `[NG]`：它把判据变成"非盲"，于是 `G″`（签名 `(0,0,2ω,?)`，`position-current.html:131`）、`H1`（`position:332`："只在 ① 的 M6 一栏失败"）、`Δ₀`（`N12:13`："M6 正（假阳性）⇒ 3/4 败"）**都已被同一判据判死**；采用 (iii) 等于同时推翻这三份已封的判决。且 `N09-1` 的 (P2) 句（"必须恰好取 0"）在 (iii) 下**直接为假**，而 (P2) 是 `[T]` 链上的前提 ⇒ (iii) 不是"N09-1 的另一种读法"，而是**否认 N09-1**。 |

**§2 的一句话**：`N09-1` 的前提"过四模型"与 ① 的 M6 栏（`=0`）**是同一张表**（`N09-RESTATE:49` 就是 `①` 的 M6 栏的文字版）。因此

   ```
   s₁(M6) = F(M6) + G(M6) = 0 + ω = 1 > 0 = m₆        [T]
   ```

## §5 · 二分定理 `SG2-2`：签名槽记在**哪个成员**上？（`NS2-2` 的错位）

`NS2-2`（`NS2.md:52–55`）的推理是：「取 `F(M6)=0`，则 `G(M6)=1≠0` ⇒ 四模型的 M6 槽由 `G` 承担，不由 `F` 承担 ⇒ `F` **不过 4/4** ⇒ `N09-1` 前提不成立 ⇒ `F ≠ f(m)` 被允许」。

**判：错位。** 四模型测试作用于**承载证书方向的那一个量** —— 在 `NS2-S` 里结论 `s₁ ≥ c₀` 由 `F ≥ c₀`（+ `G ≥ 0`）得出，故被检验的是 **`F`**；`G ≥ 0` 在每个模型上都成立（`G(M6)=1 ≥ 0` ✓），**不产生任何关于"有没有隙"的方向**。于是：

**定理 `SG2-2 [T]`（穷尽二分）.** 设 `s₁ = F + G`、`G ≥ 0`、结论取 `F ≥ c₀`，则对 `F`：

| 分支 | 后果 |
|---|---|
| **(I) `F(M6) = 0`** | `F` **过** ① 的 M6 栏 ⇒ `F ∈ dom(N09-1)` ⇒ `F = f(m)`、`f(0)=0` ⇒ **逃逸失败**：`F` 是 `m` 的重标，"`F ≥ c₀`"与"`m ≥ δ`"同一命题 ⇒ 剩下的硬活逐字就是 Clay（`[O]`） |
| **(II) `F(M6) ≠ 0`** | `F` **不过** ①（M6 假阳性）⇒ `F` 不是靶（同 `Δ₀` 的 `(B)`：`N12:13,16`）⇒ 规格无候选 |

对 `G` 同一二分：`G(M6)=ω≠0` ⇒ 分支 (II) ⇒ `G` 不是候选；`G(M6)=0` ⇒ 分支 (I) ⇒ `G = f(m)`（`G` 是形状量、`τ`-不变、无证书方向，不影响结论）。**`NS2-2` 把 (I) 的 `F` 说成"不过 4/4"，是把 (II) 的失败记到了 (I) 的账上——两个分支被对调。**

2. **`L→∞` 口径是设计选择**（`N09:138`）：固定 `L` 读，M6 的 `m_L>0`，"`G(M6)≠0`"就**不再**区分 M6 与 2D ⇒ 逃逸论证**只在 `L→∞` 下成立**；而 `N09-1` 的 `[T]` 也只在同一口径下成立 ⇒ **两者共享同一个口径**，逃逸不是在定理之外，是在定理的同一口径之内被 ① 判死。
3. **载体归属**（`SG2-2`，§5）：前提里的"`X`"是**承载证书方向的那一个**；`NS2-S` 把它错记给了 `G`。
