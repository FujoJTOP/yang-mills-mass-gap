
## §3 · 决定性的一条：格点单位的 (iii) 是**反靶**（`[T]` 逻辑 + `[C]` 数）

```
m·a ≥ Δ₀ > 0  (∀β ≥ β₀)   ⟺   ξ/a = 1/(m·a) ≤ 1/Δ₀  (有界)
连续极限要求：a→0 且 ξ/a→∞（临界点；否则平凡）
⇒ "格点单位有正地板" ⟺ "关联长度有界" ⟺ "该 β-序列上不存在非平凡连续极限"
```

**所以 (iii) 若以格点单位写，它的结论不是"质量隙有地板"，而是"理论平凡"。** 这不是措辞问题：`m·a` 的地板一旦为正，`ξ/a` 就封顶，`β→∞` 只能收敛到零关联长度（自由/平凡）理论。
`[C]` 数值见证（§2.3 表）：`m·a` 从 `1.707`（`β=2.5`，RUN3 实测）一路到 `5.9e−3`（`β=10`），`ξ/a` 从 `0.59` 到 `170`；`β=100` 时 `ξ/a=8.6e114`（SU(2) 列）。**没有任何正地板。**

**⇒ 结论（给 lead 的硬话）**：(iii) **必须**改成无量纲比的形式，例如
`(iii)′ ∃Δ₀>0 ∀β ≥ β₀: m/Λ_MS ≥ Δ₀` 或 `m/√σ ≥ Δ₀`。
而 `(iii)′` **恰好就是**"连续极限存在且隙不为零"——即**靶本身**，不是靶的廉价推论。**单调性不能把它化成一个点。**

## §4 · `w₁ = 0.3427` 为什么不能当 `Δ₀`（`[E]` 精确反例，`b04_beta_mono.log [C]`）

`w₁ = A/C(0)`（`RUN3.md:45,51`）= 谱权分数，量纲 1。两条精确事实：

**(i) `w₁` 对整体能量标度完全盲（`[T]`）**：`H ↦ cH` 时 `f₁² ↦ f₁²`、`Var ↦ Var` ⇒ `w₁` 不变，而 `gap ↦ c·gap`。数值（2 能级，机器精度）：

| `gap` | 2.236e−2 | 2.236e−1 | 2.236 | 22.36 | 223.6 |

⇒ **`w₁=0.3427` 与 `m=0.017`、`m=1.707`、`m=170.7` 全部相容**。⇒ `w₁>0` **推不出** `m` 的任何正地板 `[T]`。

**(ii) 同一个 `gap` 上 `w₁` 可扫过一整个区间（`[E]`，3 能级）**：

⇒ `w₁` 与 `gap` **互不决定**。

**⇒ 对 `β₀` 那一点，可用的数是 `m_fit = 1.707`（格点单位，`RUN3.md:51` `[E]`，**且受 `S/N(2)=5.0<10` 限定**，`RUN3 §4(a)`），`w₁=0.3427±0.0119` 只说明"该通道的谱权分数"，不含质量尺度。**

## §5 · 2D 精确对照：同一个理论里"一个减、一个是常数"（`[E]`）

2D SU(N) YM 超可重整：`g²` 的量纲 = 质量²，`β=2N/(g²a²)` ⇒ `g²a²=2N/β`；`m = c√(g²N)`（`c` 纯数）：

```
m·a = c·√(2N²/β) ∝ β^{−1/2}   严格减 → 0
m/Λ = m/(√(g²)·纯数)          = 纯数，β-无关（精确常数）
```

| `β` | 2.5 | 4 | 10 | 100 | 1e4 |
|---|---|---|---|---|---|
| `m·a`（`c=1,N=2`） | 1.789 | 1.414 | 0.894 | 0.283 | 0.0283 |

⇒ **同一理论、同一 β-区间：`m·a` 严格减，`m/Λ` 严格常数。** 这就是 (c) 的字面形态：两个"单调性"不共存（一个减、一个是零斜率），而 (iii) 在两者上含义相反。**在 4D 只是把 `β^{−1/2}` 换成 `exp(−2.69β)` 型的 AF 指数。**

## §6 · 判死线逐条（逐字）

**(a) 某量单调且给 (iii) ⇒ 逐字给？** **不成立。** 单调量是 `m·a`，方向**递减**，它给的是
```
inf_{β≥2.5} m·a = 0        ⇒ (iii)（格点单位）假，Δ₀ 只能取 0
sup_{β≥2.5} m·a = m·a(2.5) = 1.707  ⇒ β₀ 那一点给的是【上确界】，不是地板
```
⇒ 用户稿"左端点一步锁死地板"的**方向是反的**：递减量在左端点锁的是 **ceiling**。要地板就得取 **β→∞ 的极限**，而那正是连续极限外推（= 靶，未证）。`[T]`/`[C]`

**(b) 单调性只在标度窗内 ⇒ 是一段不是尾？** **成立，且比用户稿预想的更弱。** `m/Λ` 的"平"只在标度窗（SU(3)：`β≳6`；`a²`-修正 `O(1–5%)` 且**符号未知**，无单调性定理）；`β∈[2.5,5]` 这段（含 `β*=4.3066`）是**跨接区**，`Λ_L`/`Λ_MS` 的换算都带 `O(10)` 不确定（§2.2 警告）。且"平"本身**就是标度假设**，用它证 (iii) 是**循环**（`m/Λ` 平 ⟺ 渐近标度成立）。`[C]`/`[NG]`
   —— 附带一条：`β₀=2.5` 对 SU(2) 只**刚好**在 bulk 交叉点（`β≈2.2`）之上，`m·a` 在 `β<2.5` 一侧连"递减"都没有定理；故"`β≥2.5` 的尾"这个起点本身也不是单调性的自然端点。`[C]`

**(c) `m` 与 `m/Λ` 单调性相反 ⇒ (iii) 的陈述又出问题？** **成立（比"相反"更准确：一个是减、一个是零斜率常数）。** 后果是 (iii) **在陈述层就定义不完备**：不写单位时，(iii) 可为真（`m/Λ` 口径，内容=连续极限）、可为假（格点单位，内容=平凡性）、可为空（MeV 口径，β-无关）。**⇒ 建议把 (iii) 钉死为 `(iii)′`（§3 末），并明确 `m` 的归一化与 `Λ` 的 scheme。** `[T]`（量纲）+`[C]`（窗）

## §7 · 缺件 / 诚实线

1. **`m·a` 的严格单调性未证**（`[NG]`）。本文件的"严格减"是**两圈 AF 口径**下的 `[E]`（131 点），不是格点转移矩阵本征值的定理。要 `[T]`，需证 `β ↦ E₁(β)−E₀(β)` 的单调性——文献与本仓都**没有**这个工具（`V02 §2` 同判：单调量的方向"不唯一"）。
2. **标度窗的边界无数**：`SU(3)` 的 `a²`-修正系数与符号未取（`L2` 只给连续极限值 `6.3(3)`）。
3. **`β₀=2.5` 那一点的 `m` 本身受 `S/N` 限定**：`RUN3 §4(a)` 明写 `S/N(2)=5.0<10` ⇒ `m_fit=1.707` 是 `[E]` 但**未过 `S/N≥10` 门**。
4. 本文件**不**主张"隙随 β 增长或衰减"的任何物理机制（Savvidy 交叉、`β*` 跳变）；`β*` 在 `m·a` 的单调性里**不出现**（`[A]` 表在 `β*=4.3066` 处无异常）——这点与 `P10 §5` 的 `f=Δ_dyn+W` 阈值是**两个不同的量**，不可混。
