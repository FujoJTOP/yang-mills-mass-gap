## 0. 判死线（T0 三条回判）——结论先写

**总判决：`λ~1` 是定性边界（定理形状），不是余量。三条回判里 (b)(c) 命中、(a) 部分命中。但语料把这个边界写错了坐标，修正后"要跨的倍数"不是 7.3 而是 2.47（到物理点）/ 18（到交叉区下边缘）。**

### 0.1 (a) 每一步都最优？

**部分成立 ⇒ 不能单独判死。** 链上确有**两步是精确/最优**的，另有一环的常数不是自由参数（余量记在 L2 账上）：

| 环 | 为什么最优 | 类型 |
|---|---|---|
| L4 规范固定（盒底 Poincaré 常数） | `c_L = λ_min(a,L) = (4/a²)sin²(πa/L) = 4π²/L² + O(a²/L⁴)`（`P1-L0-proof.md` 的等式，非不等式），**被最低非零模取到** | 谱常数，取到 ⇒ 无余量 |
| L5 uv-稳定性的指数 | "superrenormalizable type" ⇒ 指数由 4D 量纲/幂次计数定；幂次计数是恒等式 | 量纲，无余量 |
| L1 小场半径 | 半径 `t_j = κ g_j` 里的 `κ` **不是自由参数**，被 L2 的熵平衡逼出 | 由下游决定 |

但 L2 有**可算的** 4/3 余量（§2），L3 有**未量化的** ≤10 余量（§2）。所以 (a) **不单独判死**。

### 0.2 (b) 展开参数在 `λ~1` 处是否已 `O(1)`？

**成立 ⇒ 这一条判死。** 显式量见 §4：`η_B := t*·g`（`t*` = Lemma B 逼出的小场半径，`g` = 该壳层耦合），

```
η_B(λ_tH = 1) = 18.93  (SU(3))   /   15.45  (SU(2))
η_B(物理点)   =  7.00  (SU(3), λ_tH = 7.3)
η_B = 1      只在 λ_tH = 2N²c* = 358 (SU(3)) / 239 (SU(2))
```

任务书给的判据带是 `≥ 0.3–1`。**18.9 比上界 1 高 19 倍、比下界 0.3 高 63 倍**。且这不是"我构造的量正好大"——最朴素的读数也够：**`λ_tH = 1` 处 `g² = 2N² = 18`（SU(3)），`18 ≥ 0.3` 高出 60 倍**。任何以耦合为展开参数的多尺度展开在这里都不在收敛半径内。

### 0.3 (c) 要推过 1 是否必须放弃小场条件？

**成立 ⇒ 与 L4 同墙。** 链上唯一的"小参数"来源是 `g_j → 0`（AF-UV 锥）。`λ_tH` 从 18 降到 1 是把 `g²` 从 1 抬到 18；这个方向上**没有任何 `g_j` 变小**。要把展开继续做下去，只能换展开参数（在典型场 `|F| ~ O(1)` 处展开），而那**逐字**就是 `CTL-CLOSEST.md` §4.2 的 `L4`（"典型场 × `k→0` 的单向方差界"）。⇒ **明写：与 L4 同墙，不是 Balaban 内部的一步。**

### 0.4 本路组合了哪几条已发表定理（首段硬要求，逐条给状态）

本路**没有**发明任何新机制；它是下面七条的**算术组合**（定理清单与核验状态见 §5.2）：

## §1 坐标：语料里三个叫 `λ` 的东西，换算因子恰为 `2N²`

> 这一节是本路最先要做的事，因为**整个"1 到 7.3"的叙事依赖一个未声明的单位约定**，而语料已经因同族问题改过两次（"75×"、`λ_tH < 1/24`，见 `ch13-machine.tex` 第 124–127 行与 `LIT-CHECK` §Q3′）。本节的结论会改变 T2 的靶子。

### 1.1 三种读数（都在这份语料里出现过）

| 读数 | 定义 | 出处 |
|---|---|---|
| **(R1) `λ = g²`** | 裸耦合，即 `β = 2N/g²` 里的 `g²` | `preprint/CPB-preprint.md` §3.3 原话：*"The small-field expansion is around the trivial connection, **with the coupling as expansion parameter**; by construction it stops at `λ ~ 1`."* |
| **(R2) `λ = λ_tH := βN`** | 格点归一化量，**不是** 't Hooft 耦合 | `ch13-machine.tex` 第 105–108 行："reaches `λ ~ 1` … the crossover is at `λ_tH ∈ [1, 7.3]`"；`CTL-CLOSEST` §1.3 |
| **(R3) `λ = β`** | 格点作用量系数 | `CTL-CLOSEST` §1.3（"`β≈2.5`，SU(3) 下 `g²=2.4`、`λ_tH≈7.2`"） |

注意 `λ_tH = βN = 2N²/g²`。所以 **`λ_tH` 不是 't Hooft 耦合**：以 `λ_H := g²N` 计，`λ_tH = 2N³/λ_H`（N=3 时是 `54/λ_H`）。这层混乱本身要先钉死，否则"到 7.3 差几倍"没有意义。

### 1.3 判：只有 (R1) 自洽

- `ch13-machine.tex` 说 "reaches `λ~1`"，紧接着说交叉区在 `λ_tH ∈ [1,7.3]`，**并且**说 "where the expansion parameter is `O(1)`"。若把两处 `λ` 读成同一个数（即 (R2)），结论是"Balaban 在 `λ_tH = 1` 处触界，而那里展开参数是 18"——**这与"`O(1)`"相差 `2N² = 18` 倍，自相矛盾**。小场展开不可能在 `g² = 18` 处收敛。
- 若读成 (R1)（`λ = g²`），则"stops at `λ ~ 1`" 逐字成立，且 `λ_tH = 2N² = 18`——这时"到交叉区下边缘 `λ_tH = 1`"的距离是 **18 倍**，不是 1 倍。

**⇒ 判定 [J]：`λ~1`（Balaban 的触界）与 `λ_tH = 1`（交叉区下边缘）是同名不同坐标，两个 "1" 相差恰好 `2N²`（SU(3): 18；SU(2): 8）。这条应作为第三次单位勘误回填。**

### 1.4 后果：真正的靶子是 2.47×（到物理点）与 18×（到下边缘）

- **到物理点**（Clay 真正需要的点，`β = 2.4–2.5`，SU(3)）：`g²` 从 1 到 2.4–2.5 ⇒ **要跨 2.4–2.5 倍**（`λ_tH` 从 18 到 7.2–7.5，即 2.4–2.5 倍，一致）。
- **到交叉区下边缘**（`λ_tH = 1`，`g² = 18`）：**18 倍**。
- 语料的 "7.3×" 是 (`λ_tH` 从 1 到 7.3) 这个读法的产物；它**既不是到物理点的倍数**（2.4×），**也不是到下边缘的倍数**（18×）。

**这条修正把 T2 的靶子从 `[1, 7.3]` 改成 `{2.47, 18}`（SU(3)）**，是本路可交付的第一个硬结论。

### 1.5 可证伪

### 2.2 逐环注（为什么每一环恰好是那个数）

**L1/L2 是同一件事的两面。** Lemma B 的判据 `2cβ₀ > d ln L` 里，左边是"高斯抑制每壳层涨 `2cβ₀`"，右边是"块数每壳层涨 `d ln L`"。取 `d = 4, L = 2`：`d ln L = 4 ln 2 = 2.7726`，`2β₀ = 0.13932`（N=3）⇒ `c* = 19.90`，`t* = 4.46`。**含义要念出来**：小场域必须宽到 `4.46` 个"耦合单位"（`4.46 σ`，若 `‖F‖` 的标准差 ~ `g_j`），否则大场熵不收敛。也就是说**"小场"这个词不含任何小性**：`e^{−c}` 在 `c = 19.9` 处是 `2.3×10⁻⁹`，域外只剩这么点测度。Balaban 展开的小参数**完全来自 `g_j → 0`，不来自域的窄**。这是 §4 的根。

**L2 的 4/3 是精确的、且可解释。** 块并集界按"每块"数，KP 按"每聚合物"数。`d=4` 里固定聚合物的实现数 ≤ `(2d)^n = 8^n`（每新块贴已有块，8 个方向），所以逐块熵从 `d ln L = 4 ln 2` 降到 `ln(2d) = ln 8`，比值 `4 ln 2/ln 8 = 4/3`。**两点附带结论**：
- `c**_KP` 与 `L` **无关**，而 `c*_union = d ln L/(2β₀)` **随 `L` 增长**（L=3: 31.54，L=4: 39.80）⇒ **`L = 2` 是最优整数阻塞因子**（不是"习惯取 2"）。
- 4/3 这个数**不随 `N` 变**（比值里 `β₀` 约掉），所以它对 `N`-一致性问题无贡献。

**L3 的两个读法必须分开。** 塔深 `K_steps` 是运动学（`a_j = a_0 L^{−j}`），改不了；到了 `g² = 1` 只需 7.18 个壳层，即尺度跨 `2^{7.18} ≈ 145` 倍——这是"UV 窗的宽度"，不是自由常数。计数常数 `K_count ≤ 80e^{2+β}N` 是**并集式的、自陈 crude 的**，`W1-STRONG-ALIGN` 自己写"true `K` is smaller"。这是一个**真实存在、但没被量化**的余量位置：`≤ 10×`，标 **未取数**。

**L4 是"等式"，所以没有余量。** `λ_min(a,L) = (4/a²)sin²(πa/L)` 是格点环面上 `−Δ` 的**最低非零特征值**，被最低模**取到**。任何"更精细的 Poincaré 估计"都不会改变它。⇒ 这一环是 (a) 的一个**具名实例**，也是"全链最优假设"唯一被坐实的两处之一（另一处是 L5）。

**L5 为什么也算最优。** "superrenormalizable type" 的准确含义是**界的形式**：有效密度被场的多项式控制，系数只依赖耦合的负幂与 `log` 幂，**没有 `a^{−p}` 型的增长**；这些幂由 4D（临界维数）上的**顶角计数**定死，是整数而不是可调参数。**幂次计数是恒等式，不是不等式**，所以"优化指数"这个动作没有对象。真正可能松的是**同幂次前的系数**（含 `log` 幂），但它们**不移动任何阈值**——阈值是 `λ` 的，不是系数的。这也是为什么 `C2` §1.1 用"superrenormalizable type"这个措辞而不是"superrenormalizable"：4D YM 本身是临界（可重整）的，这个措辞讲的是**界形状**，[J]。

**L6 是整条链的要害：它不是界，是假设。** Balaban 的定理形如"若有效耦合序列 ∈ `(0,γ]` 且 `γ` 小，则…"。`γ` 的数值**没有公布**（`C2` §7 注 (i)：正文在 Springer 付费墙后、证明未经机器检验）。所以"`λ~1`"这个数**不是从任何常数算出来的**，它是 `CPB-preprint` §3.3 的一句定性描述。**这就是本路最重要的技术事实：`λ` 阈值的"常数链"在最后一环上不存在数字，因此"改进它"没有对象。**

## §3 T2 定量外推：`M ∈ [1.3, 13]`，但决定性一环恒为 1

### 3.1 `M` 的构造（逐环相乘，见证 P5）

口径：每一环的因子 = "若把这一环换成今天已知（或可算）的最精细估计，**可容许的 `g²` 能抬高多少倍**"。这是唯一能把"常数改进"翻译成"阈值推进"的口径。

| 环 | 因子 | 依据 |
|---|---|---|
| L1 小场分解 | **1.00** | 半径由 L2 定，无独立余量 |

| L3 `K`-量 | **[1, 10]** | crude `K` 的未知修正，**未取数**，按典型 KP 常数给上界 10 |
| L4 规范固定 | **1.00** | 谱等式 ⇒ 最优 |
| L5 uv-稳定性指数 | **1.00** | 幂次计数 ⇒ 最优 |
| L6 `λ` 阈值 | **1.00** | 参数，不是界 |

```
M = 1 × 1.333 × [1,10] × 1 × 1 × 1  ∈  [1.33, 13.3]
几何中点 √(1.33×13.3) = 4.2   ⇒  数量级 10^0.5 ~ 10^1（半个到一个量级）
```

### 3.2 与靶子比较

| 靶子（`g²` 需抬高的倍数，SU(3)） | 值 | `M` 够吗 |
|---|---|---|
| 到**物理点** `β=2.4–2.5` | **2.4–2.5** | **够（`M` 的上半区间覆盖）** |
| 到 `λ_tH = 7.3` 这个坐标值 | 2.47 | 同上（与物理点同值，因为 `λ_tH=7.3` 就是 SU(3) 物理点） |
| 到**交叉区下边缘** `λ_tH = 1`（`g²=18`） | **18** | **不够（`M_max = 13.3 < 18`）** |

**所以"`M` 够不够覆盖到 7.3"这个问法要先拆**：
- 若 7.3 指 `λ_tH = 7.3`（= SU(3) 物理点），则 `M` 的算术上界**够**（13.3 > 2.47），**且留了 5 倍**；
- 若 7.3 指"从 `λ_tH=1` 往上到 7.3"，则真正要跨的是 18 倍（到 1）——`M_max = 13.3` **差 1.35 倍**。

### 3.3 为什么"M 够"**不等于**"阈值能被推到 `1×M`"

这是本节唯一重要的判断，也是 T2 的结论：

1. **`M` 是"界"的余量，`λ` 是"参数"的值。** 乘出来的是"能容许多大的 `g²`"，而"能不能在 `g² = 2.4` 处展开"取决于**该点是否存在一个小参数**，与界松不松无关。L6 的因子恒 1 不是巧合，而是**类型不同**。
2. **算术上的巧合不足以支撑结论。** `M_max ≈ 13` 与 18 同量级（差 1.35 倍），任何人都会想"再紧一点就过了"。但**紧一点的方向是错的**：把 L2 从并集界换到 KP，`c*` 只降 4/3；把 `K` 从 `80e^{2+β}N` 修到真值，最多 10×——**两者都不改变"展开参数 = `g²` = 2.4 在物理点"这件事**。唯一能改变它的是**换展开参数**，即造一个新的小参数（`1/N`、`q = ma`、`1/L`），而 `CTL-CLOSEST` §5.5 的经验事实是：2022→2026 阈值一步未动。
3. **`M` 的上界是我给的，不是文献给的。** `[1,10]` 里的 10 来自 `K_crude/K_true` 的猜测：`K_crude = 80e^{2+β}N ≈ 591N`（β=2.5，`W1-STRONG-ALIGN` §4(C)），若 `K_true` 落在 `60–600`，该环因子就是 `1–10`；若 `K_true ≈ K_crude`（即那条"crude"不是粗），此项退化为 1、`M` 降到 `1.33`。**所以 `M ∈ [1.3, 13]` 的上端是"最宽松猜测"，下端才是文献直接支持的；而无论是 1.3 还是 13，都不改变第 1 条的类型论证。**

**⇒ T2 结论：`M` 的量级 `10^0.5–10^1`；覆盖物理点（2.47×）绰绰有余，覆盖 `λ_tH=1`（18×）不够；但由于决定性一环不是界，`1×M` 这个外推式本身不成立。**

## §4 T3 交叉区的"定性"检验：`η_B = t*·g`，在 `λ_tH = 1` 处 = **18.9**

### 4.1 先把量造出来（并说清它是怎么来的）

任务书要"把'展开参数在交叉区是 `O(1)`'写成显式量"。Balaban 的展开参数**就是耦合**（`CPB-preprint` §3.3 原话），但**光有 `g` 不够**：小场域不是"`|F| < g`"，而是"`|F| < t* g`"，而 `t*` 由 L2 的熵平衡定死（§2.2）。所以该壳层真正的展开参数是两者之积：

```
η_B(λ_tH) := t*(N) · g(λ_tH),      g² = 2N²/λ_tH,      t*(N) = √( d ln L / (2β₀(N)) )
```

- `t*` = **4.461**（N=3）/ **5.464**（N=2）——来自 `C2` §2.3（`c* = t*²`）。
- `g` = 该壳层的无量纲耦合，由 `λ_tH = 2N²/g²` 换算。

**诚实标注**：`η_B` 是**我构造的乘积**（[J]，非定理）。但它由两个**都已在语料里**的数相乘，且下面还给了两个**不需要构造**的替代量（`g²` 本身、`β₁`），三者同向。所以结论不依赖构造。

### 4.2 数值（见证 P3；`g²`、`g` 两列按 SU(3) 列，`λ_tH = 2N²/g²`）

| `λ_tH` | `g²` | `g` | `η_B` (N=2) | `η_B` (N=3) |
|---|---|---|---|---|
| **1**（交叉区下边缘） | 18.00 | 4.243 | **15.45** | **18.93** |
| 2 | 9.00 | 3.000 | 10.93 | 13.38 |
| **7.3**（物理点坐标） | 2.466 | 1.570 | 5.72 | **7.00** |
| 18（= `2N²`，`g²=1`） | 1.00 | 1.000 | 3.64 | 4.46 |
| 50 | 0.36 | 0.600 | 2.19 | 2.68 |
| 100 | 0.18 | 0.424 | 1.55 | 1.89 |
| **358**（`η_B = 1`） | 0.0503 | 0.224 | 0.82 | **1.00** |

**`η_B = 1` 的位置**：`λ_tH = 2N²c*` = **358.2**（N=3）/ **238.8**（N=2），即 `g² = 1/c* = 0.050`。

### 4.3 两个不需要构造的替代量

1. **耦合本身**：`λ_tH = 1` 处 `g² = 2N² = 18`（SU(3)）、`8`（SU(2)）；物理点处 `g² = 2.4`。**`18` 与 `2.4` 都 ≥ 0.3–1**，分别超出 60 倍与 8 倍。这一条**不需要任何构造**，只用 `β = 2N/g²`。
2. **塔头逆耦合**（用 `C2` §2.1 自己的一环流 `g_j² = 1/(2β₀ j)`, `β_j = 4Nβ₀ j`）：`j = 1`（塔头/最粗壳层）给
   ```
   β_head = 4Nβ₀ = 0.836 (SU(3)) / 0.372 (SU(2)),    g²_head = 7.18 / 10.77
   ```
   **`β_head < 1`：塔头落在强耦合侧**，`e^{−β}` 在这里根本不是抑制（`CPB-preprint` §3.3 同款句："At `λ~6` the large-field region is not suppressed by `β`"）。而且一环流到 `g² = 1` 只需 `j = 7.18` 个壳层，到物理耦合 `g² = 2.4` 只需 `j ≈ 3` 个壳层——**展开必须"从"物理尺度起步，那里没有小参数可乘**。

### 4.4 结论

**三个量在 `λ_tH = 1` 处同向，全部 ≥ 0.3–1**：`η_B = 18.9`（高 19–63 倍）、`g² = 18`（高 18–60 倍）、`g²_head = 7.18`（高 7–24 倍）。**连最宽容的读法**——把塔头的大场抑制写成 `e^{−β_head} = e^{−0.836} = 0.43`，即"几乎不抑制"——也不在"有抑制"的一侧。⇒ **Balaban 的停止点是定性边界，不是"算得不够紧"。**

**这就是本路最重要的结构性结论，且它是"定理形状"的**：任何形如"小场展开 + 大场 `R`-操作"的多尺度证明都必须以 `g_j` 为小参数；`λ_tH = 1` 处的 `g` 是 4.24（SU(3)），**没有任何重排能让 4.24 变小，除非引入新的无量纲大参数**。候选只有三个：`N`（`1/N²`，`W1-STRONG-ALIGN` 已算 `u(2.5) = 1.25/N²`）、`q = ma ≫ 1`（`CPB-S` 的 massive-Gaussian 支配，未证）、`L`（盒底 `4π²/L²`，与体积一致性冲突）。**三种都不在 Balaban 的链上。**
