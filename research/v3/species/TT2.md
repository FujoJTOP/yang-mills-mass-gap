## 1 · 交错和的结构：符号到底从哪来

### 1.1 三层定义，逐字对齐

```
（L0）多重集层：   Z_dec(B_T) = Σ_{𝔇 多重集} W(𝔇)                  ← 正项（无扭扇区 W≥0，rs4 §3 (T-B)）
（L1）对数层：     log Z_dec = Σ_{Γ 连通} φ^U(Γ)                    ← 号从这里冒出来
（L2）图展开层：   φ^U(Γ) = Σ_{A⊆E(G_Γ), (Γ,A) 连通} (−1)^{|A|} ∏_{e∈A} f_e
```
- **(L1)→ 号源①**：`log(1+x) = Σ_{k≥1}(−1)^{k+1}x^k/k`。在簇语言里就是"`k` 个块的多重集"带 `(−1)^{k+1}`。**这一支号是纯组合的、与物理无关**——只要你在做 `log`，它就一定在。`[T]`
- **(L2)→ 号源②**：连通生成子图的交错和 `(−1)^{|A|}`，即 Mayer/Ur­sell 系数（`C01:13`、`C02:13`、`C07:124` F–P(2.4)）。**这一支号是图的，也与物理无关**（`f_e` 的号才是物理）。
- **两支叠合**（S2）：F–P(2.8) 记 `φ^T = (−1)^n|φ^T|` ⇒ **两支的号互相"对齐"成一个只依赖 `n` 的符号**。这就是全部分析的支点。`[C]`

> **⇒ 符号的来处一句话**：`φ^U` 的号**不来自** Wilson 测度、**不来自** Weingarten、**不来自**管的方向；它来自 **"取 `log`" 这一操作**（号源①）与**连通图的容斥**（号源②）。`[T]`
> （对照：`rs4 §3 (T-B)` 的 Weingarten 负号是**另一层**的号，住在"配位扭/对换"上；它破坏的是 `T_D ⪰ 0`，**不是** `φ^U` 的交错性。两者必须分开记账，混在一起会得出错误的 no-go。）

### 1.2 写法钉死（避免"交错"三义混用）

```
n(Γ) := |Γ| = 簇内 plaquette 数                （片数，离散）
α(Γ) := 附着跨度 ∈ ℤ                           （沿 T 的长度，C03:13）
φ^U(Γ) = (−1)^{n(Γ)} |φ^U(Γ)|                  （S2；号只跟 n 走）
m_n := Σ_{|Γ|=n} |φ^U(Γ)|                      （第 n 壳的总质量，正）
ε_T 的壳分解：  ε_T = Σ_{n≥N(T)} (−1)^n m_n^{(T)}，m_n^{(T)} := 只数"跨端点"的簇
```
**⚠ 三义**：`n`（片数）、`α`（跨度）、`T`（管长）是三个不同坐标。**"交错"发生在 `n` 上，`α`/`T` 上都没有交错结构。** 这是 `rs4 (P3)` 说"`φ^U` 是交错和"的精确读法，也是本文件与"沿 `T` 成对"这一直觉分道的地方。`[T]`

## 2 · 抵消发生在哪：三种候选配对，只有一种与符号对齐

| 候选配对 | 配对方向 | 是否与 `φ^U` 的号对齐 | 结论 | 等级 |
|---|---|---|---|---|
| **(P-b)** 相邻**簇**（沿 `T`）配对 | `T` 方向 | **否**——同一 `T` 上偶/奇 `n` 同时出现，号不随 `T` 交替（S3） | **结构性不可用** ⇒ (c) | `[T]` |
| **(P-c)** 图 → 树（Penrose/F–P 树图） | 图/环方向 | 是（把 `(−1)^{\|A\|}` 的交错压成正项树和） | **真定理，但消的是"环"不是"号"**：`\|φ^U(Γ)\| ≤ τ(G_Γ)`，而过定点的树/动物计数率 `= eΔ`（`C01:16–17`、`C07:73,102`、`P3-FULLREP-KP:89`） | `[T]` |
| **(P-a)** 相邻**壳层** `n ↔ n+1`（或块）配对 | `n` 方向 | **是**，唯一 | 唯一可用的谈判桌（S5–S7） | `[T]` |

### 2.1 为什么 (P-c) 不能算"抵消引理"（这条最容易被误当成答案）

`(P-c)` 把 `Σ_A (−1)^{|A|}` 压成 `τ(G_Γ)`（生成树数），**抵消增益是"环 → 树"，一次性的、完备的**（`C07:17` 核准 `|φ^U| ≤ τ` 为 `[T]`，875 个图 0 违例）。但：

```
τ(G_Γ)^{1/n} ≤ λ_tree = eΔ = 54.3656     （Cayley n^{n−2}/n! → e，位置 Δ=20：e·20）
ū := eΔ·u                                 （C01:113 "同一笔账"，C03:113）
```
⇒ **`(P-c)` 的"剩余"恰好就是 `ū` 的分子。** 也就是说：**唯一存在的那个抵消定理，其残留因子正是把 `ū` 顶到 `33.98` 的那个因子。** 用 `(P-c)` 做的任何估计，等于先用掉全部抵消、再原样付 `eΔ` 的钱。`[T]`

> 这不是"抵消不够强"，而是**"抵消的方向错了"**：`(P-c)` 抵消的是**图的环**（组合），而 `ū>1` 的病在**壳层质量随 `n` 增长**（计数）。两者不是同一笔账。`[T]`

### 2.2 所以"成对抵消"的准确几何/组合含义（任务问句的正面回答）

- **不是**"把一根弯管和一根直管配成一对"（那是 `W95A:97–99` 的**扭管 `O(u)` 压制**，已被 `u` 吸收，`rs4 §3 (T-A)` 已判"无符号问题"）；
- **而是**"把**同一条管同一个跨度**上、片数差 1 的两族簇配成一对"：`Γ_n ↔ Γ_{n+1}`。配对的组合内容 = **加/减一片 plaquette**（或加一个"块"）。
- 这就是为什么它必须是 **`n`-方向的**：加一片 `plaquette` 是唯一既改变 `n`（翻转号）、又能在同一 `T` 内完成的局部操作。**这是本文件对任务第 2 问的答案：配对 = 片数平移，不是管长平移。** `[T]`

## 3 · `(b)`：壳层配对的定量增益（为什么 `ū=34` 顶不住）

设 `m_n = c ū^n`（最乐观的几何形状，`c` 常数）：

```
第 n 对（n 与 n+1 合并）:   m_n − m_{n+1} = c ū^n (1 − ū)
Leibniz 尾界（未配对）    :   |Σ_{k≥n} (−1)^k m_k| ≤ m_n   ⇒ 相对增益 ≤ 1（因子 2，若把两项都算）
配对尾界                 :   每对幅度 = |1 − ū|·m_n
```
`[E]`（本轮实跑，`ū = eΔ·u = 54.3656365691809×0.625 = 33.97852285573806`）：

| 量 | 值 |
|---|---|
| `ū` | `33.97852285573806` |
| `ū − 1`（**配对放大因子**） | `32.97852285573806` |
| 配对后每对 / 原壳质量 | `−32.98`（**不变小，变 33 倍**） |
| 未配对的 Leibniz 最好情形（若 `m_n` 递减） | 增益 ≤ `2×` |

**⇒ 判死线 (b)，逐字：** 壳层配对是**完备的**（它把整条交错和化成"配对 + 首个未配项"，不留残余误差），**但它的增益上限是常数因子 `2`**。在 `ū<1` 时这**够**（`1−ū` 本身 <1，配对确实缩小）；在 `ū=33.98` 时 `1−ū = −32.98`，配对把"交错"变成"同号放大" ⇒ **`(b)`：抵消只能到"对"，且这对在 `ū>1` 是负收益。**

**注（防止误读成"抵消无意义"）：** 配对在 `ū<1` 区间给出的是**指数级更好**的界（把 `ū^n` 的系数从 `1` 压到 `1−ū`），这在 `ū≤0.25` 的 KP 盘内是实收益；它的失效**只在 `ū>1`**。这与 `P4-OTHER:103` 的窗内界、`C03` 的 `B` 常数完全相容，不构成对旧结论的推翻。

## 4 · `(a)` 的唯一可写形状：块 Euler–Kummer 重求和

### 4.1 引理（这是本路的目标；逐字给出）

> **拟引理 SC（块交错可和性 / Block-alternation）。`[C]`**
> 设 `m_n ≥ 0`，`Σ_n (−1)^n m_n` 为壳分解（S5）。定义块质量
> ```
> M_k := Σ_{2^k ≤ n < 2^{k+1}} m_n ,      q_k := M_{k+1}/M_k
> ```
> **(i)（收敛）** 若 `limsup_k q_k = q < 1`，则 `Σ_k (−1)^k M_k` 收敛，且
> ```
> | Σ_{k≥K} (−1)^k M_k | ≤ M_K/(1 − q)                              (4.1)
> ```
> **(ii)（配对残差 = `q/(1+q)` 型）** 在 `M_k = M₀ q^k` 时，部分和恒等变形给
> ```
> Σ_{k≥0} (−1)^k M_k = M₀·1/(1+q) ,   且   Σ_{k≥K} = (−1)^K M_K/(1+q)      (4.2)
> ```
> 即"成对抵消后的剩余"以**比率 `q/(1+q)`** 衰减（`1/(1+q)` 是"对后余项"，`q/(1+q)` 是对内占比）。
> **(iii)（等价形式，便于写进 `(L1)`）** 若把 `q` 取为 `ū/(1+ū)` 的**目标值**，则等价于要求
> ```
> M_{k+1}/M_k ≤ ū/(1+ū) < 1      （对一切 ū>0 都 <1）                  (4.3)
> ```
> ⇒ **这正是任务第 3 问要的 `/1/(1+ū)/` 型机制**：不是逐项 `ū^T`，而是块比的 `ū/(1+ū)`。

### 4.2 `[E]` 数值（`ū=33.98`，本轮实跑）

| 量 | 值 |
|---|---|
| `q := ū/(1+ū)` | `0.9714110283008719` |
| `T` 使 `q^T ≤ 1/2` | `24` |
| `q^T ≤ 1/10` | `80` |
| `q^T ≤ 10⁻²` | `159` |
| `q^T ≤ 10⁻³` | `239` |

⇒ **形状成立的话它是真收敛**（`q<1` 对一切 `ū>0`），但速率极慢（`1/2` 要 `T≈24`，`10⁻³` 要 `T≈239`）。这对 `D_∞>0`（只要 `T⁰` 常数）**足够**，对 `ε_T` 的"几何收敛"叙事**不够**（那是 `rs4 §5` 的事）。`[T]`+`[E]`

### 4.3 ★ `q` 的真实身份 —— 这才是承重的一步（也是本路的门）

`(4.3)` 里的 `q` **不是**可自由选的：`M_k` 是壳质量，`M_{k+1}/M_k → (第 k 块的平均 `m_n^{1/n}`)·`——即

```
q  ≈  lim_n m_n^{1/n}  =  λ_Ur · u            （λ_Ur := lim (|φ^U|)^{1/n}，"真实 Ursell 增长"）
```
- 若取 `λ_Ur ≤ eΔ`（唯一**可证**的界，`C07:73`、`P3-FULLREP-KP:89`）⇒ `q ≥ ū = 33.98` ⇒ `(4.3)` **当场失败**。
- 若 `λ_Ur` 的**真值** `< 1/u = 1.6`（`u=0.625`），则 `(4.3)` 成立 ⇒ **`D_∞>0` 无需任何 `ū<1`**。

> **⇒ (a) 的承重点被精确定位成一个数**：`λ_Ur·u ≟ 1`。这不是"抵消够不够强"的问题，而是**"真实 Ursell 增长比动物常数小多少倍"**的问题。
> 语料对此有**同向的两条读数**，但都不是 `λ_Ur`：
> - `C03:111`（`[M]`）：过定点连通集计数 `a_n^{1/n}` 实测 `20 → 22.9 → 24.3 → 25.2`（`n≤5`，**仍在升**）⇒ **动物计数**的 `λ ≈ 25`，`25×0.625 = 15.6 > 1`（但这是**计数**，不是 `φ^U`）；
> - `C06:159`（`[C]`）：立方体簇的**真** `φ^U` 是 `u⁶` 阶"小整数型求和"，远小于树界 `384u⁶` ⇒ 真 `|φ^U|` 比 `τ` **小一个量级以上**；
> - `C06:187` 逐字把"**算真 `φ^U`** 而不上树界"列为"唯一活路 A"。
> ⇒ **`(a)` 需要的那一个数，恰好是语料已判为"唯一活路"的那个计算。本文件不新造它。** `[NG]`（数据缺，不是机制缺）

### 4.4 酸测（`CLAUDE.md §1`）—— 一个必须写死的警告

## 5 · 为什么 `ū=34` 必须非微扰（任务第 3 问的正面回答）

三条独立理由，任一条就够：

1. **半径（`[T]`+`[E]`）**：任何 `u`-幂级数 `Σ_n c_n u^n` 的收敛半径 `≤ 1/λ_Ur ≤ 1/eΔ = 0.018393972058572114`；`β=2.5` 处 `u = 0.625`，**超 `33.9785×`**。逐项估计在窗外**没有定义**（不是"松"，是"不存在"）。
2. **奇点（`[C]`）**：Euler/Kummer/Borel 重求和的**合法性**要求"正实轴上无奇点"。SU(2) 纯规范在 `β≈2.2` 处有相变（体相变，本文件**未逐字核文献**，不编 ID）⇒ 正实轴上存在奇点 ⇒ 重求和**不唯一**、且"哪个延拓是物理的"不能由级数本身决定。
3. **表述（`[T]`）**：`ε_T = Σ_n(−1)^n m_n^{(T)}` 里的 `m_n^{(T)}` 依赖 `T`；`T→∞` 与 `n→∞` 两个极限**不对易**。交错和给的是 `n`-极限，`D_∞` 要的是 `T`-极限 ⇒ 必须换到**两个极限同时可控的表述**（转移算子 `𝕋` 的谱）。

> **⇒ "非微扰"的准确含义（三个字，不许含糊）：`ū>1` 时，`u`-级数不是"难算"，而是"没有定义"；要拿到 `D_∞`，必须换到不做 `u`-展开的表述。** 这就是为什么 `rs5 §7.1` 的 `‖𝕋₋‖/gap(𝕋₊)` 才是"判生死"的量——它是**算子层**的比率，不是级数系数层的。

### 5.1 把 `(a)` 与 `rs5 §7.1` 接起来（两条路的等价陈述）

```
块重求和 (4.3)   ⇔   ‖𝕋₋‖ / gap(𝕋₊) < 1
```
理由：`M_{k+1}/M_k` 是"负部质量 / 正部质量"在块尺度的比值，而 `gap(𝕋₊)` 是正部在块尺度的衰减；两者是同一个比率的两种记账（`rs5:229` 的 `𝕋 = 𝕋₊ − 𝕋₋` 分解）。⇒ **`rs5` 的"先算 `‖𝕋₋‖/gap`"与本文件的 `q ≟ 1` 是同一个判据。** `[C]`
