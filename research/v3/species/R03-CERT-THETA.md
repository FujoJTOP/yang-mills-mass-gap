## 1. `θ ≠ π` 的积分表示（第 1 条，`[T]`）

同一约化（`u := ρ/2 ∈ (0,π)`，`c := cos(θ/2)`，`s := sin(θ/2)`），切片 `ξ₃=0`：

```
S_W = β(1 − cos u·c + sin u·s·ξ₃/ρ),   J = 4 sin²u/ρ² = sin²u/u²   （只依赖 ρ）
测度:  dμ ∝ e^{−β(1 − c cos u)} · sin²u/u du          ← 与 q04 的 μ ∝ e^{−β(1−c cos(ρ/2))}sin²(ρ/2)ρ^{−1}dρ 同一个（ρ=2u）
G = ∂_{ξ₃}S_W|_{ξ₃=0} = β s g(u),          g(u) = sin u/(2u) = sin(ρ/2)/ρ   ← q04 的 w
H = ∂²_{ξ₃}S_W|_{ξ₃=0} = (β c/2) g(u)                                        ← H_vv，c≠0 时 ≠ 0
Φ = −log J 只依赖 ρ ⇒ Φ′ = ∂_{ξ₃}Φ = Φ_ρ′·(ξ₃/ρ) ≡ 0                          ← 对一切 θ
Φ″ = Φ_ρ′/ρ = 1/(2u²) − cot(u)/(2u)
```

⇒（**对一切 `θ`**，不只是 `π`）

```
S = E[H + Φ″] = (βc/2)·E_ν[g] + E_ν[Φ″],        D = Var(G + Φ′) = β² s² Var_ν(g),
ν ∝ e^{−β(1−c cos u)} sin²u/u du ,   Z=∫ν, NA=∫g ν, NB=∫g² ν, NS=∫Φ″ ν
```

**必须更正题面的一条前提**：本切片上 **`Φ′ ≡ 0` 对一切 `θ` 成立**，不是只在 `θ=π`。原因是 `J = sin²u/u²` 只依赖 `ρ`，而切片 `ξ₃=0` 与等-`ρ` 球面**相切**（`∂_{ξ₃}ρ|_{ξ₃=0}=0`）。故 `θ≠π` 时 `D` **仍**是纯 `Var(G)`、**仍**无交叉项；`θ≠π` 真正多出来的是 **`H_vv = (βc/2)g ≠ 0`**（`θ=π` 时它整条消失），即 `S` 多一个 `β`-线性正项 `(βc/2)E[g]`——这一项是 `θ≠π` 比 `θ=π` **更容易**过的结构原因。`Var(G+Φ′)=Var(G)` 的交叉项**不需要**新处理。

**核准**：`θ=π`（`c=0`）退化回 `S=E[Φ″]=NS/Z=1/(4Z)=0.205115297123…`、`D=β²Var(g)`；本文件的代码把 `θ=π` 当回归跑，`S`、`D`、`S−D` 与 `q11_cert.log` 吻到 **4e-41**（`r03_cert_theta.log:68-71`），这是整套 `θ≠π` 机器的最强单点校验。

## 2. 严格区间（第 2 条，`[T]`，`r03_cert_theta.py`）

### 2.1 `θ≠π` 新增的一件工具：`e^{βc cos u}` 的严格处理

`θ=π` 能 15 分钟做成 `[T]` 的结构原因是 `c=0` ⇒ 权重常数、不需要指数。`θ≠π` 必须把 `Ē(u) := e^{−β(1−c cos u)}`（`Ē(0)=1`，偶函数，整函数）也变成精确级数：

```
Ē′ = −βc·sin(u)·Ē ,  Ē(0)=1   ⇒   e_{m+1} = −(βc)/(2(m+1)) · Σ_{j=0}^{m} (−1)^j e_{m−j}/(2j+1)!
```

`e_m` 是 `u^{2m}` 的系数，**`Q[√2]` 里精确**（`θ=0`：`c=1` ⇒ 有理；`θ=π/2`：`c=√2/2` ⇒ 系数 `a+b√2`，`a,b ∈ Q`，乘法 `(a+b√2)(c+d√2)=(ac+2bd)+(ad+bc)√2`）。`√2` 与 `π` 只在最后一步以 `libmp` 定向舍入区间进入。

被积因子（全部整函数，负幂必须消掉；代码里四个级数在 `u=0` 无负幂）：

```
W  = sin²u/u              = Σ (−1)^{m+1}2^{2m−1}u^{2m−1}/(2m)!
A  = sin³u/(2u²)          = Σ (−1)^m(3−3^{2m+1})u^{2m−1}/(8(2m+1)!)
B  = sin⁴u/(4u³)          = Σ (−1)^{n}(16^n−4·4^n)u^{2n−3}/(32(2n)!) ,  n=m+1
Sf = Φ″W = sin²u/(2u³) − sin2u/(4u²)     （IBP：c=0 时 ∫Sf = 1/4 精确，回归已验）
```

**严格性口径（5 条，与 q11 同，只改第 4 条，且这一改是必须的）**：

| # | 内容 | 实现 |
|---|---|---|
| 1 | 级数系数 | `Fraction` 精确，`Q[√2]` 精确对 |
| 2 | 逐项积分 | `∫₀^π u^k du = π^{k+1}/(k+1)`（整函数恒等式） |
| 3 | `π`、`√2` | 只以 `libmp.mpf_pi / mpf_sqrt` 的 `'f'/'c'` 800bit 区间进入 |
| 4 | **定向舍入 + 外扩** | 每步 `'f'` 下 / `'c'` 上；外扩改为 **纯相对** `pad = max(|lo|,|hi|)·2^{−400}` |
| 5 | 截断 tail | Cauchy：`|a_k| ≤ M(r)/r^k`，`r=4.2`，`M(r) ≤ e^{β|c|(cosh r−1)}·sup|f₀|`（`sinh4.2≤34`、`sinh8.4≤2230`、`cosh4.2−1≤33.4`、`π<3.2`）；`Σ_{k>K} ≤ M(π/r)^{K+1}π/((K+2)(1−π/r))`，`K=400` |

**第 4 条为什么必须从"绝对"改成"相对"（本次抓到并修掉的真 bug，两次）**：

1. **`B` 的幂次索引错位**：`sin⁴u/(4u³)` 的 `u^{2m−1}` 项对应 `sin⁴` 的 `n=m+1`（且分母是 `32(2n)!`，我第一次漏了 `4u³` 的 `4`）。症状：`θ=π` 回归的 `Var(g)` 给出 `0.5528…` 而 q11 是 `0.0110592937…`，其余量全对——**只有 `NB` 错**，因此这个 bug 被回归当场抓住。修后 `θ=π` 全部量吻合到 4e-41。
2. **绝对外扩在灾难性相消下失效**：`θ≠π` 的级数有峰值项 `~1e7`（`W=1.33e7, A=2.35e7, B=4.16e7, S=1.46e6`，`log:79`），而 `k=399` 的系数小到 `8.5e−227`。绝对外扩 `2^{−400}=3.9e−121` 会把 `1e−227` 的系数整条吃掉（区间塌成 `±3.9e−121`），再乘 `π^{k+1} ~ 1e199` 放大成 **`1e78` 的假误差**，`Z` 直接算成 `±1.56e76`（区间端点还倒挂）。改成纯相对外扩后 `Z=0.44788127215571638092…`。**"定向舍入真做了"的证据在 `θ=π/2` 的 `Z` 宽 `3.5e−21`：它等于 tail 上界 `1.77e−21` 的量级，而不是 0 或 ulp 噪声；若只做"高精度大概"，上下端点会相同。**
