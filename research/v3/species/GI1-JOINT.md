## §3 · 最小 joint 形式（若存在，它长什么样；逐条判）

### 3.1 (J1) 逻辑上的最小形式：带号两测度求和规则

因为两个测度各自**扇区纯**（§1.2），把它们放进**同一个预算**的唯一线性方式是**带号组合**：
```
  (J1)   ∫ w(s) dν_0(s)  −  λ ∫ w(s) dν_q(s)  =  C ,     w ≥ 0,  λ > 0,  C 已知.
```
- **为什么这是最小**：任何形如 `Φ(ν_0,ν_q)=0` 的**线性** joint 约束都可写成两个线性泛函之差；`λ>0` 是唯一能让"带电总额"去**压**中性总额的符号。
- **它存在吗？不存在。** 正性/KL 是 intra-sector，跨道核恒零（`PROOF-IN11:31`；`E2-FLIP-L1-VNW:84`；`A2-IN11:88`）。Weinberg 型带号差只在**同一扇区的两道之间**（`V−A`，都 N-ality 0，`INEQ-R10:16`）；一旦跨 1-形式扇区，核 `⟨O_0O_q⟩` 恒零，`λ` 项无定义。要有非零跨扇区核需 `θ≠0` 或非局域缺陷，而 Clay 点在 `θ=0`（`C1-derive-INb.md:15–22`）。
⇒ **(J1) `[NG]`**（定理级：无跨道不等式）。

### 3.2 (J2) 实际存在的最小联合对象：'t Hooft 比值

```
  (J2)   R_q(T,L) := Z_q(T,L) / Z_0(T,L) = ⟨H_q⟩ ,      H_q = 't Hooft 环（缺陷算符，H_0 → H_q）.
```
- **它是真的**：Lemma M 的直和 + 缺陷算符的跨扇区矩阵元（`SS:167–173`；`SS:124` "带电关联是跨扇区非对角矩阵元"）。`[T]`（定义级）
- **它给什么（逐项拆）**：`Z_q=Σ_nd_n^{(q)}e^{−E_n^{(q)}T}`、`Z_0=e^{−E_0T}(1+d_1e^{−m_nT}+…)`，故
  ```
  (1/T) log R_q(T,L)  →  −(E_q(L) − E_0)      (T→∞)      （leading：带电谱）
  ```
  中性隙 `m_n` 只进**分母的次 leading**（`Z_0/Z_vac` 向 1 的逼近）。⇒ 它是**测量通道**（同时依赖两扇区），**不是求和规则**；要把 `m_n` 分离出来必须已知 `E_q(L)`（循环）。`[T]`（代数）
- **任何不等式版本方向反**：要把 `R_q` 变成 `m_n` 的**下界**，需要 `R_q` 的**下界**（等价地，`E_q` 的**上界**）；而可得的界是面积律 `R_q ≍ e^{−σ̃A}`（上界型，`[C]`），面积律给 `E_q ≥ σL` 也是下界。§3.4 的 (J4) 是这条要求的**最小形式**。`[NG]`（作下界工具）

### 3.3 (J3) P2 的最小形式：联合方差——**精确退化**

P2 的原始提议是"带电 × 中性**联合方差上界**"（`SS:330`；`UC-COMPLETE.md:223` 的 #5；`R2-H2GLOBAL.md:331`）。写出最小形式：
```
  (J3)   Var_μ(ξ_ch + ξ_0) ≤ V ,      ξ_ch 荷≠0,  ξ_0 荷=0 .
```
因 `⟨ξ_ch⟩=0`（荷分级：带电量在真空的期望为零，`SS:121`）且 `ξ_chξ_0` 的支撑不相交（取 `ξ_ch, ξ_0` 为**扇区对角**的荷观测量，如 `|W|`、plaquette；若取 off-diagonal 的带电算符本身，两点函数是跨扇区矩阵元——那是 §3.2 的对象，不是这里的方差），
```
  Cov(ξ_ch, ξ_0) = ⟨ξ_chξ_0⟩ − ⟨ξ_ch⟩⟨ξ_0⟩ = 0 − 0 = 0
  ⇒  Var(ξ_ch + ξ_0) = Var ξ_ch + Var ξ_0        （精确，无余项）
```
（Witness S3：`Cov=0.000e+00`、`Var(ξ0)=0.16`、`Var(ξq)=0.40`、`Var(和)=0.56`，差 `0.000e+00`。）
⇒ **联合界 ⇔ 两个逐扇区界之并**：
- 只有逐扇区**上界**（H1 类）时，`Var ξ_0 ≤ V − Var ξ_ch` 的最好读法是 `Var ξ_0 ≤ V`——**就是原来的边际界，零增益**。
- 要真产出中性上界，必须加 `Var ξ_ch ≥ v > 0`——这是**带电扇区的下界**（本身是 gap 级输入，且正性只给 `Var≥0`）。
⇒ **(J3) `[NG]`（作为"更弱假设"）；欠账守恒，不减反增。** 这与 `E2-FLIP-L2-COMPLEMENT.md:57,64–69` 的 L0/L2 一致：joint 约束只能当"证书"，而它要证书的东西**就是 H1**。

> **与同批 `GI2-P2` 的对齐（必须写，防"把 P2 一刀切死"）**：本节判死的是 P2 的**字面形态**（"联合方差**上界**" = `GI2-P2.md:54` 的 P2-L）。同批 `GI2-P2.md:55,58–68` 指出：唯一不死的是**条件方差下界**

### 3.4 (J4) 唯一能给下界的最小不等式——在大 `L` 为假

要把带电数据变成中性**下界**，最小形式是
```
  (J4)   ∃ c > 0 , ∀(L,a):   E_q(L) ≤ c · m_n          （带电边 ≤ c × 中性边）
  ⇒      m_n ≥ E_q(L)/c .
```
- 它是"带电完备性"（`SS:324`：中性谱无"带电致盲"分量）的**定量形态**：若存在一个远轻于带电塔的中性态，它就"对带电数据致盲"，(J4) 就假。

- **松弛也不行**：若放宽成 `E_q ≤ c m_n + c′σL`，它由面积律**自动为真**（`E_q ~ σL`），但 `σL` 项在 `L→∞` 吞掉一切 ⇒ 对 `m_n` **零信息**。`[T]`
⇒ **(J4) 不是 joint 求和规则；它就是缺的那条动力输入本身。**
