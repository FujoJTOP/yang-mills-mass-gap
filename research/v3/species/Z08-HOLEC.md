## 1 · 逐字：`Z_dec(B_T)` 与 `B_T`

### 1.1 `B_T` —— 它是什么，活在哪个域

**定义（`P3-DRESSED-MASS.md:44`，逐字）**：
> **1.1 Backbone. `[T]`** Fix, among the four-wall tubes of temporal length `T`, a **backbone** `B_T`: the straight four-wall tube with cross-section the source spatial plaquette `p₀` (its four walls are the `4T` temporal plaquettes of a `1×T` "rectangular tube" as in Gupta). The `A₁g` sum over the transverse sink position is folded into `a₀` (§0). The backbone weight is `w(B_T)=a₀u^{4T}` (§0, Fact 0.2).

**所在域（`:24`，逐字）**：
> …`Λ_{L,T} = T³_L ×_a ℤ`, spacing `a`, spatial torus `T³_L`, infinite/discrete time `ℤ`; we take `L→∞` last and `t→∞` before that.

**四条结构化事实，逐条钉死：**

1. **`B_T` 不是「域」，是一个固定的聚合物。** `[T]` 它是 plaquette 集合（`4T` 个 temporal plaquette，全在 `f`），不是区域。
2. **几何位置：`1×1×T` 矩形管（Gupta (14.20)）的四个「侧壁」，不是它的内部。** `[T]` 横截面 = 源空间 plaquette `p₀` 的**四条边**。源 `p₀` 本身**不在** `B_T` 里（它是算符位置，`a₀` 携带）。
3. **时间方向开、空间方向周期。** `[T]` `:44` 的 `1×T` 与 `Y04:19`（"时间方向**开**，端点在 `0` 与 `T`"）一致；空间方向在 `T³_L` 上闭。**这一条是 `Y04 §5(b)` 的反例所锁死的承重点**：换成闭环管，`(L1-c.2)` 立刻出 `T` 前因子。
4. **`∂B_T` 的定义是「共链」，不是「支撑邻接」（`:46`，逐字）**：
   > A **decoration configuration** `𝔇 = {γ₁,γ₂,…}` is a set of pairwise disjoint decoration polymers … The decoration polymers are the connected polymers `γ` of plaquettes that are (i) disjoint from `B_T`, (ii) **adjacent** to `B_T` (share a link with it), possibly also adjacent to each other.

   ⇒ `∂B_T := {ℓ : ℓ ∈ links(B_T) ∩ links(γ), γ ∈ 𝔇}`。**`∂B_T` 是链集，不是面集** —— 这正是非块乘性的载体：链接积分住在**链**上，而块分解被提在**plaquette** 上。

### 1.2 `Z_dec(B_T)` —— 逐字定义

**（`:46–47`，逐字）**：
> Its weight is `W(𝔇)=∏_i w(γ_i)`, and the **decoration partition function** is
> `Z_dec(B_T) := Σ_{𝔇} W(𝔇) = 1 + Σ_{𝔇≠∅} W(𝔇)`. `(1.1)`

**（`:28`，`w` 的定义，逐字）**：
> A **polymer** `P` is a link-connected set of plaquettes carrying nontrivial irreps; its weight is `w(P) = (∏_{p∈P} c_{r_p})·∏_{links ℓ∈P}(link recoupling)` times operator coefficients at the source/sink.

**（`:28` 上方，`Fact 0.1`，逐字 —— 链接积分就是重耦合重数）**：
> `∫_{SU(N)} dU ∏_{i=1}^{k} χ_{r_i}(U) = dim Hom(1, ⊗_i r_i) = mult(1 ∈ ⊗_i r_i) ∈ ℤ_{≥0}.`

**（`:53`，被审计的那句，逐字）**：
> *Proof sketch. `[T]`* The first equality is tautological (`B_T` is a fixed polymer; the sum over `P⊇B_T` factors as `w(B_T)·Σ_{decor}` because `w` is multiplicative over disjoint pieces and the recoupling at the interface `∂B_T` is fixed into `a₀`).

⇒ **要补严的就是 `:53` 的两个断言**：(i)「`w` is multiplicative over disjoint pieces」；(ii)「the recoupling at the interface `∂B_T` is fixed into `a₀`」。

## 2 · 非块乘性的精确形式

`w(P)` 的链因子是 `M(ℓ):=dim Hom(1, ⊗_{p∋ℓ} r_p^{±1})`（朝向进符号，`Fact 0.1`）。**关键：`Hom(1,·)` 对张量因子的划分不乘性。** 三层失败，逐层给精确形式。

### 2.1 层一（定量）：`∂`-链上的重耦合比不是 `1`，精确等于 `2`

设 `γ` 在共享链 `ℓ` 上向 `B_T` 贡献净 `f̄` 后又贡献 `f`（即 `γ` 在 `ℓ` 处**两次过链**，这是闭合装饰的常规形态）。则

```
真值：      M_{B_T∪γ}(ℓ) = dim Hom(1, f⊗f̄⊗f⊗f̄)
naive 值：  M_{B_T}(ℓ)·M_γ(ℓ) = dim Hom(1,f⊗f̄) · dim Hom(1,f⊗f̄) = 1·1
```

**精确算**：`Hom(1, V⊗V*⊗V⊗V*) = (End V ⊗ End V)^G`，`End V = 1⊕adj`，故 `= (1⊗1)^G ⊕ (adj⊗adj)^G = 1 ⊕ 1 = 2`（交叉项 `1⊗adj`、`adj⊗1` 的 `^G` 为 `0`）。**Weyl 积分独立复核（`N=2`）**：`χ_{1/2}(θ)=2cos θ`，
```
(2/π)∫_0^π (2cos θ)^4 sin²θ dθ = (2/π)·16·(π/16) = 2   ✔
```
⇒
```
R(ℓ) := M_{B_T∪γ}(ℓ)/(M_{B_T}(ℓ)M_γ(ℓ)) = 2  ≠ 1 .        (2.1)   [T]
```
**⇒ `:53` 的「fixed into `a₀`」为假**：`R` 依赖装饰在 `ℓ` 处的表示标签/过链次数，**不是常数**，提到 `a₀` 外面当常数是错的。`R` 是**活动度的乘性重标**，不是振幅的常数因子。

### 2.2 层二（定性）：cap 型装饰上 `w(γ)=0` 而 `w(B_T∪γ)≠0`

取「cap 型」装饰：`γ` 只在共享链 `ℓ` 处靠 `B_T` 闭合，在 `ℓ` 处向 `γ` 只贡献**一个** `f`（其余三面自行闭合）。则按 `:28` 的字面定义、
```
M_γ(ℓ) = dim Hom(1, f) = ∫dU χ_f(U) = 0   ⟹   w(γ) = 0 ,
```
而
```
M_{B_T∪γ}(ℓ) = dim Hom(1, f⊗f̄⊗f) = dim Hom(f,f) = 1   ⟹   w(B_T∪γ) ≠ 0 .
```
⇒ **`:47` 的 `W(𝔇)=∏_i w(γ_i)` 把这一整类装饰赋零权，而 `(1.2)` 的左边需要它们。** `[T]`

**这不是「差个常数」，是丢掉非零类。** `:53` 的 `w` multiplicative over disjoint pieces」在这一类上连**零点**都错：`w(B_T)w(γ)=0` 而 `a₀u^{4T}·(真值)≠0`。

**这正是 `Z05:90` 说的「带边界条件的活动（须与 `f` 重耦合）」的精确内容**：cap 型装饰的净 `f` 通量由管**屏蔽**，其活动度是**带边界条件的**，不是体活动度。

### 2.3 层三：装饰 × 装饰同样不乘性

`:47` 的 `W(𝔇)=∏_i w(γ_i)` 对两只装饰共一链也用同一个乘积。共链时 `M(ℓ)` 是并集的重耦合，`(2.1)` 的 `R=2` 复现。

⇒ **`Z_dec` 不是 `w`-活动度的自由（硬核）气体，而是「链中介」的有限程耦合气体。** 键在**链**上（`∂B_T` 与 `γ∩γ′`），不在 `γ` 内。这是「多项式气体」而不是「聚合物气体」的标准形态，KP 仍适用（有限程、有界耦合），但**活动度必须是链耦合之后的活动度**。

### 2.4 文件内部的不自洽（`[O]`）

- `:53`：`∂B_T` 的重耦合「fixed into `a₀`」⇒ 应是 **`T`-无关常数**。
- `:115`：`log D_fin` 的缺陷含「the two endpoint terms where the tube terminates」⇒ 端点项进 **`D_fin=1+O(u)`**。

**同一个界面两个去处，二者不同源。** 端点项是 `O(u)` 的**密度/常数**修正，不是「进 `a₀` 的常数」。`(1.2)` 的分解要么写 `a₀` 携带常数、要么写 `D_fin` 携带端点 —— `:53` 与 `:115` 必须选一个。**这个不自洽本身可当洞 C 的独立证据，不需要外部输入。**

## 3 · 活动界：需要什么

### 3.1 需要的界（`[R]`，形式确定）

**不是**新类型的界，就是 `:64` 的 KP 判据，但必须：

```
(NC)  ∀ x ∈ plaq(∂B_T) :   Σ_{γ∋x, γ 附着于 B_T} |w_{B_T}(γ)| e^{α|γ|} ≤ α ,
      w_{B_T}(γ) := w(γ)·∏_{ℓ∈links(γ)∩links(B_T)} R(ℓ) ,                  (3.1)
```
其中 `R(ℓ)` 如 `(2.1)`（含 cap 型：`w_{B_T}(γ)` 在此情形下 `≠0`）。

**两条附加要求，缺一即不通：**

| # | 要求 | 为什么缺不了 |
|---|---|---|
| (i) | 常数 `α` 对 `x` **一致** | `∂B_T` 每片有 `O(1)` 个 plaquette（横截面 4 条链 × 每链 `O(1)` 邻面），`T`-一致 ⇒ 这是 `X01:97`「附着点在 `1×1` 骨架上被空间钉死」的同一机制 |
| (ii) | `w_{B_T}` 沿管**平移不变** | 否则 `A(α)` 不存在，`(L1-c.1)` 的整条腿断。**直线管使它成立**：`∂B_T` 的局部形态在 `j∈(0,T)` 每片相同，只有 `j=0`,`j=T` 两片多一个源/汇 `p₀` |

### 3.2 `(NC)` 的推导：`|R|` 有界

```
|R(γ)| ≤ ∏_{ℓ∈links(γ)∩links(B_T)} ρ ,   ρ := max_ℓ R(ℓ) = 2  (2.1);
#(shared links) ≤ 4|γ|  (每 plaquette 4 条链)
⟹  |R(γ)| ≤ ρ^{4|γ|}   ⟹   \hat C := ρ^4 = 16 ,   最省界 \hat C ≥ ρ = 2 .      (3.2)  [T]
```
故 `(NC)` 由 `:64` 在 `u↦\hat C u` 下直接给出，`\bar u↦\bar u':=\hat C\bar u`。**KP 盘仍是 `\bar u'<1`，只需按 `:122–123` 的现成手法把 `β₁` 缩一个 `N`-依赖常数** —— 该手法文件里已有，不是新件。`[T]`

### 3.3 窗口账（`AGENTS §2.1`，硬）

**先报窗口再报数值。** 参考点 `SU(2)`、`β_W=1/12`、`u=0.0104`、`\bar u=eΔ\bar C u=54.3656×0.0104=0.5654`（`Y04:92,:117` 逐字复现）。

## 4 · 判：`Z_dec = e^{φT}·D_∞·(1+ε_T)` 成不成立

### 4.1 成立，但「`1+ε_T`」的写法要钉一下

`X01` 的 `(L1-c.1)` 是 `log Z_dec` 的**恒等式**，逐字（`X01:40–43`）：
```
log Z_dec(B_T) = Σ_{α≥0}(T−α+1)_+ A(α) = φ_dec·T + log D_∞ + ε_T ,
ε_T = Σ_{α>T}(α−1−T)A(α) .
```
⇒ 精确指数化给
```
Z_dec(B_T) = exp(φ_dec T)·D_∞·e^{ε_T} = exp(φ_dec T)·D_∞·(1 + ε_T^{mult}) ,   ε_T^{mult}:=e^{ε_T}−1 .   (4.1)  [T]
```

`|ε_T|=O(\bar u^T)`（`X01:79–80`，`Y04:84` 的 `B=(ū/(1−ū))³` 独立复现）⇒ `ε_T^{mult}` 同阶，`(1+ε_T)` 的字面写法**要读成 `(4.1)`**。**这一条是记号，不是洞。**

### 4.3 ★ 为什么 `∂B_T` 的簇**不能**归入 `ε_T`（对 (a) 机制的一处更正）

任务书 (a) 的候选机制是「把 `∂B_T` 的簇归入 `ε_T`」。**这条路量级不对，走不通**：

- `R` 沿管**平移不变**（`B_T` 是直管，§3.1(ii)）⇒ 每片贡献 `O(u)`，沿 `T` 累计 `T·O(u)` ⇒ 这是**密度修正**，不是指数小量。
- `ε_T = O(\bar u^T)`（`X01:80`）是**指数小**；`T·O(u)` 是**线性**。把它塞进 `ε_T`，`ε_T` 从 `O(\bar u^T)` 抬到 `O(uT)`，`(L1-c.2)` 立即毁掉。
- 正确去处：**进 `φ_dec`**，即 `:74` 的 `C_{dec}`：
  ```
  φ_dec ↦ φ_dec + δC_{dec}·u ,    δC_{dec} 由 ∂B_T 的链耦合定（O(1)，T-无关）      (4.2)  [T]
  ```
  ⇒ `f_dec=φ_dec/a` ⇒ `m₁^{dressed}=κ−f_dec` 的**常数移位**，结构不变。
- **`O(u)` 的移位在文件声明的精度内不可见**：`:88` 只声称 `m₁^{dressed}=κ(1−O(u/\ln(1/u)))`，`:74` 只声称 `C_{dec}` 是「a finite constant」而**从不钉其值**。⇒ 洞 C 的重耦合在 `m₁^{dressed}` 的**当前精度上是 inert** 的，但**不是**可省的一行，因为 `\hat C` 进 `\bar u`，而 `\bar u` 直接定 `ε_T` 的界（§3.3）。

**⇒ (a) 的判：触发，但机制须从「归入 `ε_T`」改成「并进活动度 → 进 `φ_dec`」。** 与 `X01 §1.4` 的分类**完全一致**：内部类 → `φ_dec T`；单端类 → `log D_∞`；**只有越端类进 `ε_T`**（`X01:55` 逐字：「**唯一被 `(T−α+1)_+` 截掉的一类** ⇒ 即 `ε_T`」）。`x01` 的分类本身就是正确的去处表，`∂`-重耦合按 (4.2) 落进第一类。

## 5 · 优先项：`x01` 的分解是否等价于补上洞 C

**不等价。`x01` 补的是「簿记一半」，缺「活动度一半」—— 一行，但那一行决定窗口。**

### 5.1 `x01` 实际证了什么、没证什么

`(L1-c.1)` 的推导只用到三件：**(P1)** 开管区间计数 `T−α+1`；**(P2)** 按 `att` 分组；**(P3)** 时间平移不变（`X01 §1.1–1.2`、`Y04 §1` 的两表逐条复核，`Fraction` 残差精确 `0`）。
