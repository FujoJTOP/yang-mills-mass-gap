## 0 · 判词（先给答案）

```
∫(vf)e^{−V}dHaar = 0   ⇒   E_V[∂_v f] = E_V[f·∂_vV]                      (S-0)
f = V′ = G+Φ′  ⇒  E[H+Φ″] = E[(G+Φ′)²] = Var(G+Φ′)                      (S-1)
f = 1          ⇒  E[G+Φ′] = E[∂_vV] = 0   (score 零均值)                 (S-2)
(S-1)−(S-2) 时   E[H+Φ″] − Var(G+Φ′) = E[G+Φ′]² = 0                     (S-3)
```

**推广的结果不是"更大的不等式"，而是退化成等式**：`q15` 的 `E[H]−Var(G)=E[G]²≥0` 里那个平方，在带 `Φ` 的版本里变成 `E[∂_vV]²`，而 `E[∂_vV]≡0` 是**恒等**的（不靠对称性、不靠任何窗口、任何块、任何 `θ`）。所以

* `E[H+Φ″] − Var(G+Φ′) = 0`，**恒取等号**；
* **拿不到**任何 `≥ 0` 的正余量 ⇒ **`H1` 不免费**（`(a)` 不触发）；
* **修正项 = 0**：`Φ` 的 `v`-导数结构**不产生**额外项（平直图里 `v` 无散，`∂_v` 与 `∂_v²` 同一算子）；
* 唯一真正的"非负"出现在**条件化层、且只在 `a`-平均之后**：`E_a[G″(a)] = Var_a(m_F) ≥ 0`（总方差分解，`[T]`）；逐 `a` 的 `G″(a)` 无符号 —— `θ=π` 实测 **45/221 点为负**（`min −0.079`）。**故点态 `H1` 在本模型里数值上是假的**（`θ≥0.75π`），不是"只差一个证明"。

**与 `p22` 的关系**：`p22` 的 `m_G′ = E[H]−Var(G)−Cov(G,Φ′)` 是 `f=G` 这条 Stein 式；本文件的 `(S-1)`/`(S-3)` 是 `f=V′` 那条。两条都精确，**不是同一个对象**，`p22` 的负性不被本文件的等号抵消。

## 1 · 题设 1：`∫(vf)e^{−V}dHaar = 0` 得到什么？

取左（或右）不变方向场 `v`（`div_Haar v=0`），`μ ∝ e^{−V}dHaar`，`V=S_W+Φ`，`G_v=∂_vS_W`、`Φ′_v=∂_vΦ`、`H_vv=∂_v²S_W`、`Φ″_vv=∂_v²Φ`：

```
0 = ∫ v(f e^{−V}) dHaar = ∫[(vf) − f·vV] e^{−V}dHaar
⇒  E_μ[∂_v f] = E_μ[f·(G_v+Φ′_v)]                                        (S-0)
```

**取 `f = G_v+Φ′_v`（即 `f=V′`）：**

```
E_μ[H_vv+Φ″_vv] = E_μ[(G_v+Φ′_v)²]                                       (S-1)
```

**关系**：`E[H+Φ″]` 与 `E[(G+Φ′)²]` 是**同一个数**（逐字等于 `main.tex` 的 `eq:stein2: Var(G_v+Φ′_v)=E[H_vv+Φ″_vv]`）。**不是不等式，也没有"某一边大"**。

**再取 `f=1`**（`main.tex` 的 cross-Stein，`f=1` 版）：

```
0 = E_μ[1·(G_v+Φ′_v)]  ⇒  E[G] = −E[Φ′]  ⇒  E[G+Φ′] = 0                 (S-2)
```

`(S-1)+(S-2)` ⇒ `E[H+Φ″] = Var(G+Φ′)`。**这一步就是 `q15` 的 `E[H]=Var(G)` 的带 `Φ` 对应物，但它是等式；`q15` 那边是 `E[H]−Var(G)=E[G]²`，平方项在带 `Φ` 时被 `(S-2)` 归零。**

### 1.1 前提核验（`[T]`，模型内已核）

| 前提 | 内容 | 核验 |
|---|---|---|
| 散度为零 | `div_Haar v = 0` | `[T]`：Haar 左/右不变 ⇒ 不变场无散 |
| 边界项 | `∮_{∂Ω} f e^{−V} (v·n) dS = 0` | `[T]`（模型内）`+[C]`：[S5] 实测 `ρ→2π` 处 `J~sin²ψ→0` 二次而 `Φ′~1/sinψ` 一次 ⇒ `\|f\|e^{−V}→0`（`5.3e−11` @ `ψ=π−1e−6`）；`ρ→0` 处 `J→1/4`、`Φ′=−cotψ+1/ψ=O(ψ)→0` 无奇异 |
| `f` 的可积/衰减 | `f=V′` 在 cut locus 按 `1/sinψ` 发散 | `[T]`：被 `J` 杀掉；`V′` 的边界项仍为 `0`。**若 `V′` 发散快过 `J` 的零，此条不成立**——这是本推广唯一的结构性前提 |
| 测度绝对连续 | `e^{−V}` 局部可积 | `[T]`：`J` 只在 `ψ=0`（有限 `1/4`）与 `ψ=π`（零）取值 |

**注意（`(c)` 的正确读法）**：`Φ=−log J` 是**图的 log-Jacobian，不是群上的函数**（换图 `X→X′` 时 `Φ→Φ+log\|∂X/∂X′\|`）。所以 `V=S+Φ` **不是** `M` 上的函数，只有 `e^{−V}dξ` 这个**测度**是内蕴的。`(c)` 问的"`Φ` 不是 `v` 的单值函数"**不构成障碍**：Stein 需要的是把 `V` 当成图上的一条光滑函数做分部积分，这一点在**每张图上都成立**（结论 `(S-1)` 逐图成立，且换图时两边的变化由同一散度恒等式吸收）。真正的障碍只有上表的"边界项/衰减"。

## 2 · 题设 2：展开与修正项

```
E[H+Φ″] = E[G²] + 2E[GΦ′] + E[Φ′²] + (修正项)
```

**修正项 = 0，恒等。** 代数上：

```
修正项 ≡ E[H+Φ″] − E[(G+Φ′)²] ≡ −E[G+Φ′]² = 0        (用 (S-1) 与 (S-2))
```

一般场（`div_ξ v = c ≠ 0`）才有非零修正项，逐字：

```
0 = ∫ div_ξ(f e^{−V} v)dξ = E[∂_v f] − E[f·∂_vV] + E[f·div_ξ v]
⇒  E[∂_v f] = E[f ∂_vV] − E[f div_ξ v]
⇒  取 f=V′:  E[V″] = E[(V′)²] − E[(div_ξ v)·V′]        (修正项 = −E[div_ξ(v)V′])
```

平直图里 `v=e₃` 常系数 ⇒ `div_ξ v=0` ⇒ 修正项 `=0`。**`Φ` 的 `v`-导数结构不产生任何额外项**，因为 `Φ` 只以 `V′=G+Φ′`、`V″=H+Φ″` 成对出现，`Φ″` 正好是 `(V′)²` 展开里 `Φ′²` 项所需的二阶导；Jensen/log-Jacobian 没有"半项"残留。**数值**（`β=2.5, θ=π/2`）：`E[H+Φ″]=0.656830104`，三项和 `=0.656830104`，差 `0.0e+00`（`[S2]`）。

### 2.1 唯一的非零"修正"在条件化层

切片测度沿 `a` 变 ⇒ `P09 (*)`（`main.tex:1148–1152` 的条件版）：

```
d/da E[f|a] = E[∂_v f|a] − Cov(f, ∂_vV|a)                                 (*)
f=V′  ⇒  G″(a) = E[H+Φ″|a] − Var(G+Φ′|a) = m_F′(a),   m_F(a):=E[V′|a]
```

**这里没有平方**：`G″(a)` 是条件平均力的**斜率**，不是方差。非零的"修正"正是 `−Cov(f,∂_vV|a)`（切片密度沿 `a` 的变化），也就是 `p22` 的 `−Cov(G,Φ′|a)` 那一族项的来源。**逐字**：

```
E[H+Φ″|a] − Var(G+Φ′|a) = m_F′(a)        ≠  E[V′|a]²（除了全测度那一层）
```

## 3 · 题设 3：能否得到 `E[H+Φ″] − Var(G+Φ′) = 平方 ≥ 0`？

**能，但平方是 `E[V′]²`，而 `E[V′]≡0`。** 所以：

```
E[H+Φ″] − Var(G+Φ′) = E[G+Φ′]² = 0         （恒等，[T]）
```

* 这不是"非负量"，这是**零**。`q15` 里 `E[G]²` 之所以非空（在非对称块上可 `>0`），是因为 `E[G]` 一般不为零；带 `Φ` 后 `E[∂_vV]=0` 是 **score 恒等式**，没得商量。
* 想要非负量只能退到 **`a`-平均**：由总方差分解 `Var(F)=E_a[Var(F|a)]+Var_a(m_F)` 与 `(S-3)`：

```
E_a[G″(a)] = Var_a(m_F(a)) + E[m_F]² = Var_a(E[V′|a]) ≥ 0                 (S-4)  [T]
```

`(S-4)` 是**真的**、精确的、非负的，而且**它把"H1 的点态非负"精确地换成了"条件平均力的方差"**。但它**只**给平均非负：`E_a[G″]≥0` 不蕴含任何单个 `a` 上 `G″(a)≥0`。

**数值（`β=2.5, θ=π/2`）**：`E_a[G″]=+0.646732`，`Var_a(m_F)=+0.646732`，`E[m_F]²=2.3e−28`，差 `3.7e−15` ⇒ `(S-4)` 成立 `[C]`。

**点态**（`[S6]`，窗口 `|a|≤5.5`，221 点）：

| `θ` | `min G″(a)` | 位置 | 负点数 |
|---|---|---|---|
| `π/2` | **+0.003200** | `+2.800` | **0/221** |
| `0.75π` | **−0.066061** | `+2.350` | **34/221** |
| `π` | **−0.079171** | `+1.800` | **45/221** |

⇒ **点态 `G″(a)≥0` 在本模型 `θ≥0.75π` 上数值为假。** `H1` 不是"只差一个证明"，它在 `θ` 大的一侧**不成立**（至少在此单 plaquette 模型、此 `a` 参数化下）。

## 5 · 判死线 `(a)/(b)/(c)`

### `(a)` **不触发。** 逐字：

> `E[H+Φ″] − Var(G+Φ′) = E[G+Φ′]²`，而 `E[G+Φ′] = E[∂_vV] = 0`（score 零均值，`[T]`，不依赖任何窗口/块/对称性）。故平方**恒为 `0`**，Stein 在带 `Φ` 时只给**等式** `E[H+Φ″]=Var(G+Φ′)`，**给不出任何正余量**。`H1` 的 `[T]` 证明**不在**这条路上。

**并且**：点态 `H1`（`G″(a)≥0`）在 `θ≥0.75π` 上**数值为假**（`[S6]`：`34/221`、`45/221` 点为负，`min −0.079`）——所以不是"差一步"，是在此模型里就**不成立**。

### `(b)` **成立，精确式如下（这是本文件的交付）**：

```
全测度:   E[H+Φ″] = E[(G+Φ′)²] = Var(G+Φ′),   E[G+Φ′] = 0                   [T](+[C] 1e−16)
校正项:   E[H+Φ″] − [E[G²]+2E[GΦ′]+E[Φ′²]] = −E[G+Φ′]² = 0                  [T]
条件化:   G″(a) = E[H+Φ″|a] − Var(G+Φ′|a) = m_F′(a)                          [T] (P09 (*))
平均层:   E_a[G″(a)] = Var_a(E[V′|a]) ≥ 0                                    [T](+[C] 3.7e−15)
余量:     E[H+Φ″] − Var(G+Φ′) = E[V′]²  ≡ 0   ← **退化平方，非正下界**
```

等价于说：带 `Φ` 的 Stein **不自动非负**，它自动**取等**；`H1` 需要的是 `m_F′≥0`（`P22 §3(c)` 已定位的同一步），**不是** Stein 的直接推论。`(S-4)` 给了 `H1` 在 `a`-平均层的**恒等表示**（`=Var_a(m_F)`），这是净收获：它说明 `H1` 的平均版是**自动的**，全部内容在**点态**，而点态在 `θ` 大的一侧为假。

### `(c)` **不适用 —— Stein 在带 `Φ` 时成立。** 理由逐条：

1. `Φ` 不是 `v` 的单值函数（它依赖基点 `U`，即依赖 `(ρ,a)`），但这**不是障碍**：Stein 只需要 `V` 在图上光滑、`v` 无散、边界项为零。
2. 真正需要核的是 `∂Ω` 上的衰减：`\|V′\|e^{−V}→0`（`[S5]` 已核，`[T]` 模型内 + `[C]` `5.3e−11`）。
3. `Φ=−log J` 是**图的 log-Jacobian**（不是群上函数）：`V` 逐图不同，但 `(S-1)` 逐图成立且换图自洽（两边的变化由同一散度恒等式吸收）。**任何把 `E[H+Φ″]` 当"内蕴量"的用法要打 `[C]` 折扣**；`E[(G+Φ′)²]` 才是内蕴的（因为它只依赖测度与 `v`）。
4. cut locus（`ρ→2π`，`ψ→π`）：`Φ′~1/sinψ` 发散，`J~sin²ψ` 二次归零 ⇒ 乘积 `→0`。**`Φ` 的奇异性恰好被 `dHaar` 的零吸收**，这正是 `main.tex` 的 `J\|_{∂Ω}=0` 那条前提。

## 6 · 结论（一句话交接）

**带 `Φ` 的 Stein 逐字是 `E[H_vv+Φ″_vv] = E[(G_v+Φ′_v)²] = Var(G_v+Φ′_v)`（因 `E[G+Φ′]≡0`），修正项恒为 `0`，非负平方是 `E[V′]²≡0` ⇒ 退化为等式、`H1` 不免费 `(b)`；条件层 `G″(a)=m_F′(a)`，只有 `a`-平均的 `E_a[G″]=Var_a(m_F)≥0` 是真非负 `[T]`，而点态 `G″(a)` 在 `θ≥0.75π` 数值为负（`45/221`），故 `(a)` 的"H1 免费"不成立；`(c)` 不适用——Stein 成立，唯一结构前提是 `\|V′\|e^{−V}→0` 在 cut locus 上成立。**

**未闭合（`[NG]`）**：`L=2`/4D 块未算（全部数值是单 plaquette `SU(2)`、`v=e₃`、`β=2.5`、`θ∈{0,π/2,0.7π,0.75π,π}`）；`SU(N≥3)` 的 `Φ` 非径向（`J` 依赖 `N²−1` 个角）未核；`a`-平均的权重取 `ρ(a)∝Z(a)`（flat chart 的 `a`-边际），换粗场定义需重算。
