## §2 作用

1. **出现在哪一步**：`CCC4` §3 的第 3 条（替代判据）。位置明确——`§3.1`（按方向）与 `§3.2`（按定理）都判 `[NG]` 之后（`CCC4:49,50`），它是「单体积 + 单调」这条搬运被撤后**唯一剩下的搬运形**（`CCC4:12,53`）。
2. **是不是 `L3`**：**不是**。`L3` 是 `a`-向的 `sup_a Z_a^{-1}\|H_a\|_D<∞`，且明写不含 `L` 量词（`CCC5-V:12,20`；`HQ1-L3:32–51,72,136`）。`ε` 是 `L`-向的**一点**比较，与 `L3` 的轴、对象、量词全不同；也不是 `UVS-L`（那才是 `L`-一致的那条，`HQ1-L3:136`）。
3. **是不是 `L`-一致**：**不需要，也不需要更强**。`ε` 只在 `L=12` 出现一次；`L→∞` 时 `|a(L)−a(∞)|→0`，故更大的 `L` 只会更容易。**这是一个单点、单侧、带常数的一跳**。
4. **服务哪个断言**：`plaq(∞,2.5) ≥ 0.625`（⟺ `⨏_{[0,2.5]}𝒮_q ≥ 1/24`，`CCC3-WINMEAN:13,44,57`），即 `(EP)` 那道门（`ZZ1-PLAQLB:0.1,5`）。跳跃形：`a(∞) ≥ a(12) − ε(12) ≥ 0.625 ⟺ ε(12) < a(12) − 0.625`。**它不服务 `L3`、不服务 `(★)`、不服务 `m>0`**：它只做「一个体积的读数 ⇒ 热力学极限的下界」这一跳。
5. **与既有严格栏的型差**：仓内最强严格 `plaq` **值**下界是 `0.005208`（`ZZ1-PLAQLB:0.1`、`CCC3-WINMEAN:14`，差 `120.0×`）。那是**值**，`ε` 是**修正量**——不同型；但两者同族，且仓内修正量界 **0 条**。

## §3 判定（三条路逐条）

**(a) 由 `Var(q) ≤ 1` 的粗界 ⇒ `[NG]`。** 免费只有：`q∈[0,2]` ⇒ Popoviciu `Var(q)≤1`（`CCC5-V:22`、`HZF-COV:0.2`、`II1-C4:(P)`）。它界的是**抽样误差**（`Var(q̄)=χ_q/L⁴`），而 `a(L)−a(∞)` 是**偏差**（两个均值之差），方差界与偏差之间没有桥。即用积分形，Popoviciu 只给 `χ_q≤L⁴`（L=8：`4096`）；`CCC2-TIGHTEN:39` 逐字：「纯 Popoviciu／逐点 `Var(q̄)≤1` 给 `χ_q≤L⁴`，零信息」。⇒ 型号不匹配。**下一手**：注销该路，不再用方差上界喂 `ε`。

**(b) 有限体积差 + Lipschitz ⇒ `[NG]`。** 差本身是 `[T]`（`L=4→6` 降 `2.27e−3`、`24σ`；`L=8→12` 的 `4.18e−4` 连自身 `σ` 都没有，`CCC4:11,41`）。三条硬阻：① 仓内唯一 Lipschitz 是 `β`-向 `‖S_W‖≤12V`（`D04:203`、`GX1:371`），带正幂 `L⁴`，而靶是 `L⁰`（`OO9-ALT:0.5,38` 逐字「一切 β-局部输入带正幂 `L`，靶是 `L⁰`」）；② `plaq'≥0` 使一切 Lipschitz 行只给**天花板**、方向盲（`ZZ1-PLAQLB:0.2`）；③ 锚点自身出族——`0.651984` 比 `{L=6,L=8}` 的 `1/L⁴` 外推低 `3.30e−4`（`8.3σ₈`，`CCC4:42`），故无模数可拟合。**下一手**：只在 `β`-向继续用 `12V`；`L`-向的 Lipschitz 不立项。

**(c) 由 `C_q(z) ≥ 0`（`II6`）⇒ `[NG]`（结构级）。** 方向反：正性只给**下界**——`χ_q≥C_q(0)` ⇒ `ρ≥1`（`HZF-COV:0.6`、`AAA4-RP:2.3`）；`O_B≥0` ⇒ `ϖ≥Var(q)`（`HZY-C0:0.6`）。`ε` 要的是**修正量的上界**，正性只会抬高它。且格点 `β=2.5` 上号本身 `[NG]`（`II6:0.5`；`HZY-C0:0.2`），读数提示相消（`𝒮_q(2.5)≈0.032 < C_q(0)≈0.07`，`II2-OB:0.6`）。⇒ 给不给号都不通。**下一手**：正性栏只记在 `c₀≤ϖ` 下界行，不进 `ε` 栏。

**总判：`[NG]`。** 具名障碍 = **「有限体积–极限比较缺一致聚类率」**：`PROOF-FSS-RIGOROUS:3,9` 已逐字判同形命题「两两侧幅度界**就是**所求陈述，只有体积一致指数聚类（率 `μ>0`）供给它」；仓内该供给的陈述形为 `∃m₀>0 ∀L ∀N ∀b.c.`（`HZU-M:0.1`，判 `[T]`），**供给**为 `[NG]`。**唯一有希望的下一手（两选一）**：① 在 `β<1/48` 的聚类窗把 `ε(L)≤Ce^{−cL}` 显式写出来（仓内 0 条，故本轮记 `[NG]`，不借 `[T]`）；② 换门——`ZZ1-PLAQLB:40` 的镜像锚 `∫_{2.5}^∞𝒮_q ≤ 0.0625`，实测只差 `1.0805×`，是全表唯一 `<1.10×` 的门。
