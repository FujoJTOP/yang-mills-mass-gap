## §1 精确式：拆成三层，只有第一层是"恒等式"

### §1.1 层 A —— 热力学恒等式（`[T]`，无需反常，无需重整化）

```
Z(β_W) = ∫ DU exp(−β_W S_W),   S_W = Σ_p ( 1 − (1/N) Re tr U_p )    ≥ 0
⇒  ∂_{β_W} log Z = − ⟨S_W⟩
```
有限 `L`、任意 `N`、任意 `d`、任意 `β_W`，**逐字恒等**（把导数移进积分即可）。它**没有用到迹反常**——迹反常的存在与否不影响这一行。
**同轮独立复现**：`H04-THERMO §0` 从 `F(β)` 的热力学积分侧得到同一结论 —— *"精确版是恒等式（零内容）"*。两条路互不引用而结论相同 ⇒ 层 A 的"零内容"不是单一来源的判断。

**层 A 与 `F²` 的桥（也是恒等式，常数可算）**：`S_W` 的朴素连续极限 `S_W → (1/8N)∫F²`，而连续作用量 `S_cont = (1/4g²)∫F² = β_W S_W`（`β_W = 2N/g²`）。于是逐字

```
⟨ ¼ F² ⟩ = − ∂_{β_c} log Z ,      β_c := 1/g²            （单位系数，[T]）
⟨ F² ⟩   = − 8N ∂_{β_W} log Z = − 4 ∂_{β_c} log Z        （[T]，tree-level 算子归一）
```

## §2 `⟨F²⟩` 与 `m`：有没有 `⟨F²⟩>0 ⇒ m>0` 的论证？—— **没有**

2. `m_GI = inf supp ρ_s`（`ch06-tools` 式 `mgi`，`s=(β/2g)trF²`，`ρ_s ≥ 0` 由反射正性）—— 地板是 `supp` 的**端点**，不是任何矩。
3. 端点与矩之间只有 `A1` 一个方向：`⟨s⟩ ≥ inf supp ρ_s`。

```
A1（w≡1）：   inf supp ρ_s ≤ ⟨s⟩ = ⟨(β_YM/2g)·¼trF²⟩·4      ← 地板 ≤ 一阶矩
还原量纲：    supp 的端点 ~ m²（ρ_s 是 s 的谱测度）⇒ 得到的是 m² 的**上界**，不是下界  [T]（方向）/ [J]（量纲读法）

**方向是死的**：地板在矩的**下面**，所以矩能给的最大信息是"`m` 不超过某个正数"——对 `m>0` 零贡献。

**`o11`/`ch05` 的"胶子凝聚是钥匙"要更正**：`O11-PHYS.md` 通篇是 `G''(0)` 的数值判决（`Δ = E[κ|0] − Var(F|0)`），**不是**凝聚（§7 检索核验：`凝聚|condensate` → 0 命中）；"胶子凝聚"作为钥匙之一只出现在 `CLAUDE.md §5` 的并列清单里，且原文把它与 `f₁²` 列成"同一个对象的多个名字"。**本轮判：这两个名字不是同一个对象** —— `f₁² = |a_G|²` 是谱**残数**（原子），`⟨¼F²⟩` 是**一阶矩**（平均）。`ch06-tools` 自己写着：Fredholm 行列式 *"linear-blind but sees the atom"*，而"线性盲"盲的正是矩。**⇒ 把钥匙写成凝聚 = 用矩去探测原子，结构性错位。** `[T]/[NG]`（具名类：矩型泛函）

⇒ 缝隙只能从"零点的位置"取，不能从"矩的大小"取：
   ch06 式 (fredholm)： f₁² = −λ₁ Res_{z=z₁} 𝒢(z) = −(1/z₁)·N_O(z₁)/𝒟_O′(z₁),  z₁ = e^{a m₁}
   它是"linear-blind but sees the atom"——盲的正是 ⟨F²⟩，看见的正是 m₁。
```
**⇒ 路径：迹反常只负责把 `s` 钉成 `T^μ_μ`（从而 `ρ_s≥0`、`m_GI` 良定义），`m>0` 必须由 Fredholm 零点的**简单性/位置**给出，不能由 `⟨F²⟩` 给出。** 这与 `D06 §1.4` 的修复方向一致（把 `𝔉` 从"单模型上的数"换成"族上的证书"）。`[M]`（缺的仍是 `CONTINUUM-FREDHOLM` 的 `a→0` 零点）。

**顺带记一笔死路账**：`∂_β log Z` 的**符号**（`= −⟨S_W⟩ ≤ 0`，逐字 `[T]`）不是"符号承载"——它承载的是 `S_W ≥ 0`（逐点正性，`S_W` 是 `1−Re trU/N ≥ 0`），与 `m` 无关。**别把 `⟨S_W⟩≥0` 误读成"β 向的正性"。**（`V05 §5.4` 要的那个"β-方向的符号承载"仍然缺。）
