## 1. 推导：`E[H_vv|0]` 的显式式

### 1.1 模型与约定（与 `betastar_scaling.py` 逐项一致，`N=2` 与 `H1A` §2.1 逐位一致）

```
X = Σ_{a∈off-Cartan} ξ_a T_a,  U = exp(iX),  B(θ) = exp(iθ T₃),  T₃ = diag(1/2,−1/2,0,…,0)
S = β(1 − ReTr(U B)/N),   测度 e^{−S}J dX,  J = ∏_{i<j}[sin(μ_ij/2)/(μ_ij/2)]²
切片 Σ = {Tr(T₃X)=0}（Cartan-横截，即条件化 <v,ξ>=0），域 |μ_i−μ_j|≤2π
v := T₃,   H_vv := ∂²_t S(X+tv)|_{t=0} = −(β/N)·∂²_t ReTr(exp(i(X+tv))B)
E[H|0] := ∫_Σ H_vv e^{−S}J / ∫_Σ e^{−S}J
```
`N=2`：`θ=π` ⇒ `B=iσ₃`，与 `H1A` 的 `B` 逐位相同（`e^{iπσ₃/2}=iσ₃`）。

### 1.2 关键分解（**这是本任务的全部内容**）

`B(θ)` 在 `su(N)` 里对 `θ` 是**仿射**的（只在 1–2 块上非平凡）：

```
B(θ) = c·P + (1−P) + i s·V,     c=cos(θ/2), s=sin(θ/2)
P = diag(1,1,0,…,0),            V = diag(1,−1,0,…,0) = 2T₃
```
（逐项核对：1–2 块上 `e^{iθ/2}=c+is`、`e^{−iθ/2}=c−is`；3…N 块上恒为 1。）

因为 `−β∂²_t ReTr(·B)` 对 `B` 线性，**`H_vv(X;θ)` 逐点对 `(c,s)` 仿射**：

```
H_vv(X;θ) = (β/N)[ A₀(X) + (1−c)·A₁(X) + s·A₂(X) ]                                  (1)
A₀ = −∂²_t ReTr e^{i(X+tv)}|₀ ,   A₁ = ∂²_t ReTr(e^{i(X+tv)}P)|₀ ,   A₂ = ∂²_t ImTr(e^{i(X+tv)}V)|₀
```
`A₀,A₁,A₂` **与 `θ,β` 无关**（纯切片函数）。`∂²_t` 必须走差分：`d/dt e^{i(X+tv)} ≠ i v e^{i(X+tv)}` 除非 `[v,X]=0`（BETASTAR §5.3 同一条教训）。

**验证（`[V1]`）**：随机 200 点 × 4 个 θ，`|H_exact − 式(1)|` 相对误差 `N=3: 5.7e−8`、`N=4: 4.8e−8`（`N=2` 处 `H≡0`，相对误差是 `0/0`，绝对误差 `<1e−9`）。⇒ 式 (1) **精确**。

### 1.3 反射对称 ⇒ `⟨A₂⟩=0`（零点集与符号对称性的来源）

`D=diag(1,−1,1,…,1)` 的共轭 `X→DXD` 保持切片、域、`J`、`q_P`，只把 `V→−V`、`v→−v`（`∂²_t` 对 `v` 偶）⇒ `A₂(DXD)=−A₂(X)` 而测度不变 ⇒ `⟨A₂⟩_θ = 0`。
逐位核对（`[V2]`）：`⟨A₂⟩_Haar = −1.3e−12 (N=2)`、`+4.3e−7 (N=3)`。故

```
E[H|0](N,θ) = (β/N)[ ⟨A₀⟩_θ + (1−c)⟨A₁⟩_θ ],      θ ↔ −θ 偶                       (2)
```
（`⟨·⟩_θ` 的测度仍依赖 `|θ|`：`S = β(1 − [c q_P + q_I − q_P − s q_V]/N)`，`q_I=ReTr U`、`q_P=ReTr(UP)`、`q_V=ImTr(UV)`。）

### 1.4 `N=2` 的闭式（把 `H1A` §2.1 从"数值"升级为"恒等式"）

`N=2`：`P=1` ⇒ `A₁ = −A₀` 逐点（恒等式，非近似）；切片上 `A₂≡0`（`[V2]`：`1e−12`，也可解析：`ImTr(e^{iX(t)}σ₃) = 2 sin(R/2)t/R` 的 `t` 二阶导在 `t=0` 为 0）。于是

```
E[H|0](2,θ) = (β/2)·c·⟨A₀⟩_c,   A₀ 在切片上 = sin(ρ/2)/ρ > 0  (0<ρ<2π)
⇒ E[H|0](2,θ) = 0  ⟺  c = 0  ⟺  θ = π (mod 2π),  对一切 β 精确
⇒ 且 θ∈(π,2π) 时 E[H|0] < 0（c<0）
```
`⟨A₀⟩_c` 精确为 `⟨sin(ρ/2)/ρ⟩`，测度 `e^{−β(1−c cos(ρ/2))}J dX`；`c=0` 时测度**恰为 Haar**（`S≡β`，与 `ρ` 无关）——这就是 `H1A` 说"`θ=π` 切片上测度是 Haar"的结构原因。
数值（`[V3]`）：`⟨A₀⟩=0.442503 (β=2.5,θ=0)`、`E[H](θ=0,β=2.5)=0.553129`，与 `H1A` 存档 `0.553061` 差 `1.2e−4`（MC）；`β=0.5→0.095567`（存档 `0.095581`）、`β=6→1.420204`（存档 `1.420010`）。

## 3. 含义：零点上 `Δ = Φ'' − Var`，这个比较**更难**

`H1A` §1.3 的恒等式 `G''(0) = E[H|0] − Var + W_full`。在零点 `E[H|0]=0` 上：

```
Δ = G''(0) = W_full − Var = Φ''(0) − Var(⟨v,∇S⟩|0)          （X=−2Cov(G,Φ')=0 在 N=2 切片上）
```
**更难，而且零点正是唯一已知能被打穿的地方。** 三个理由（都可算，不是说法）：

1. **机制被抽掉了**：`E[H|0]` 是唯一带"曲率"来源、且随 `β` 单调增的正项（`θ=0`：`β=2.5→10` 时 `N=2` 从 `0.553→2.419`）。零点把它清零，只剩两个"结构项"对撞。
2. **两边量纲不同、增长不同**：`W_geo` 是纯 Haar 项，`β`-无关（`N=2` 上 `=0.2051153=1/(2Cin2π)`）；`Var = β²V₀`（`V₀=0.0110593`）。⇒ `δ = 0.2051153 − 0.0110593β²`，`β*=4.30661` 后 `δ<0`。**零点上 H1 必死于大 β**——这不是巧合，是幂次：`Φ''` 有界、`Var∝β²`。
3. **零点 = 测度恰为 Haar 的点**（`N=2,θ=π` 时切片上 `S≡β`）⇒ `Var` 取到它的"全 Haar 值"，`Φ''` 取到全 Haar 锚点。即：零点把两边都推到极值，且方向相反。

**推论（对 H1 的用途）**：任何"H1 在零点上更容易"的路线都反了。零点集的正确角色是**判据**：若能把 `E[H|0]` 的符号控制到 `θ<θ_c` 上（即证明"条件化点落在有隙真空里"），H1 就多一个 `+E[H]` 的正项；反过来，`θ>θ_c` 上 `E[H]` 变成负债，`β*` 下移。**这就是 `H1A` §2.3 "Savvidy 凹性"的可解标量版**：`E[H|0]<0 ⟺ 条件化点不在极小点上`。

## 4. 判：`θ=0` 上 `E[H|0] ≥ 0` 是否普遍？

### 4.1 结论：**是（[C]，平均意义），但不是定理，也不能升格**

`θ=0` ⇒ `c=1,s=0` ⇒ 式 (2) 只剩一项：

```
E[H|0](N,0) = (β/N)·⟨A₀⟩_β ,     A₀ = −∂²_t ReTr e^{i(X+tv)}   与 θ 无关
```
`⟨A₀⟩` 的数值（`[V5]`）：

| `N` | `⟨A₀⟩_Haar`（β=0） | `⟨A₀⟩`(β=2.5) | `⟨A₀⟩`(β=10) | `E[H]`(β=2.5) | 逐点 `min A₀` | `frac(A₀<0)` |
|---|---|---|---|---|---|---|
| 2 | +0.35732 | +0.44250 | +0.48375 | +0.5531 | **+0.0000** | **0.000** |
| 3 | +0.24695 | +0.31191 | +0.42114 | +0.2599 | −0.0771 | 0.075 |
| 4 | +0.19977 | +0.22682 | +0.28359 | +0.1418 | −0.2174 | 0.231 |

- **`N=2`**：`A₀ = sin(ρ/2)/ρ > 0` 在 `0<ρ<2π` 上**逐点**成立（解析），故 `E[H|0](2,0) = β⟨sin(ρ/2)/ρ⟩/2 > 0` 对一切 `β>0` **[T]**。
- **`N≥3`**：逐点**可负**（`N=3` 有 7.5% 的切片点 `A₀<0`，最深 `−0.077`）⇒ 没有逐点正性；但**加权平均全正**，且随 `β` 增（`β` 大时负 `A₀` 区被 `e^{−S}` 压掉）。`N=4` 是 `15000` 点低统计（误差 `±3e−3`），结论方向一致。
- 因此 `E[H|0](θ=0) ≥ 0` 是 **`[C]`（3 个 `N` × 4 个 `β`，无例外）**，**不是 `[T]`**。⇒ **判死线 (a) 不成立**：没有"曲率侧的免费正性"；`θ=0` 上 `Φ''+E[H] ≥ Var` 仍是**要证的**不等式，只是 `E[H]` 这一项帮正忙（尤其在 `β` 大的地方，`E[H]∝β` 对抗 `Var∝β²` 的方向是对的）。

### 4.2 与 `BETASTAR-N` §4 的量级打架（必须记，`[NG]`）

用 `BETASTAR` 的 `Z_N` 中心元 `B=diag(ω²,1,ω)` 复算（`[Z2]`，`N=3,β=6`）：

| 量 | 本方 | `BETASTAR-N` §4 表 |

⇒ 同一测度、同一 `G`，**`BETASTAR` 的 `E[H|0]` 列恰好是带 `1/N` 值的 `N` 倍**（`0.3060/0.1022=2.99`）。`N=2` 上两种归一都给 0（`θ=π`）或给 `H1A` 锚点（`θ=0`，本方 `0.553129` vs 存档 `0.553061`，带 `1/N`）——**带 `1/N` 的一支才对上 `H1A`**：不带 `1/N` 时 `N=2,θ=0,β=2.5` 会给 `1.106`，与存档 `0.553061` 差 `2×`。故 **`BETASTAR-N` §4 的 `E[H]`（及 `δ` 的 `aβ` 项）被高估 `N` 倍**，其 `δ(3)` 应下调：`β=6` 时 `0.635 → 0.416`、`β=14` 时 `1.338 → 0.585`（本方 `0.1022+0.3453−0.0317`、`0.3453+0.3453−0.1058`）。

## 5. 裁决

1. **(1) 显式式成立且已验证**：`H_vv(X;θ)=(β/N)[A₀+(1−c)A₁+sA₂]`，`E[H|0]=(β/N)[⟨A₀⟩+(1−c)⟨A₁⟩]`（`⟨A₂⟩=0`，反射对称）。`N=2,θ=π` 给 `|E[H]|<4e−13` **[T+C]**；`N=3` 在 `θ=π` 给 **`−0.0265`(β=2.5)、`−0.0493`(β=6)**，即"零点在 `θ_c<π`，`π` 上已为负" **[C]**。
2. **零点集 = 一条曲面 `θ_c(N,β)`**：`N=2` 精确 `θ=π`（`β`-无关，唯一性与 `A₁=−A₀`、`A₂≡0` 等价）；`N≥3` 时 `θ_c<π` 且 `β↑⇒θ_c↑`（`0.933→0.952`，`N=3`）。**不是单点，也不是"θ=π 全家"**，`(b)` 的形状如上。
3. **含义：零点上的 `Φ'' vs Var` 比较更难**，且零点就是 `H1A` 的精确反例点（`δ=0.2051153−0.0110593β²`，`β*=4.30661`）。零点不是避难所，是失败轨迹。
4. **`θ=0` 上 `E[H|0]≥0` 数值普遍成立（`N=2,3,4`，`β=0.5…10`），但（i）非逐点（`N≥3` 有 `7.5%/23%` 负点）、（ii）无证明 ⇒ 标 `[C]`。** 故 **(a) 不成立**（没有免费正性），**(b)(c) 成立**（有族状零点集；`θ>θ_c` 上 `E[H]<0`，最低点 `θ→2π⁻`：`−0.2735`(N=2,β=2.5)、`−0.3952`(N=2,β=6)、`−0.2348/−0.4170`(N=3)）。
5. **对 H1 的操作结论**：`E[H|0]` 在 `θ=0`（真空即条件化点的位形）是**正资产**，在 `θ>θ_c` 是负债。想把 H1 变成 `Φ''+E[H] ≥ Var` 的"曲率帮忙"形式，必须携带 `θ<θ_c`（即"条件化点在有隙真空上"）的信息——与 `H1A` §2.3/§4.1 的"H1 必须携带真空选择信息"同一条，但这次给出的是 `θ_c(N,β)` 这条可算的边界。
