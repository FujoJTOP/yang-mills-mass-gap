## 1. 逐点代数：`G,H` 都是 `(c/2,t)` 的一次型（`[T]`）

模型（`H1A §2.1` 逐字）：`c=cos(θ/2)`、`t=sin(θ/2)`、`w(ρ)=sin(ρ/2)/ρ`、`ρ=√(a²+s²)`、`u=a/ρ`

```
S_W(a,ρ) = β[ 1 − c cos(ρ/2) + t·a·w(ρ) ]                                             (1.1)
```

(Q04 (2.4)(2.5) 即 `G=∂_aS`、`H=∂_a²S` 的显式；本文件 §4 用中心差分独立复核到 `2e−11`。) 把 `β` 提出：

```
G = (c/2)·A + t·B ,   H = (c/2)·C + t·D ,        （A,B,C,D 为 β-无关的 ρ-函数）
A = (a/ρ) sin(ρ/2)                                          ( 来自 −c cos(ρ/2) 的一阶 )
B = w + a²w′/ρ                                              ( 来自 t·a·w 的一阶 )
C = sin(ρ/2)/ρ + (a²/2ρ²)cos(ρ/2) − (a²/ρ³)sin(ρ/2)         ( 二阶 )
D = 3a w′/ρ − a³w′/ρ³ + a³w″/ρ²                             ( 二阶 )
```

**关键结构**（逐项看，不用算）：`A` 显含 `a`（`∝a`）；`D` 的**每一项**都含 `a` 的正幂。故

```
A|_{a=0} = 0 ,  D|_{a=0} = 0 ,  B|_{a=0} = C|_{a=0} = β w(ρ)                          (1.2)
```

### 1.1 比例性的正确判据

`H = K·G`（`K` 与 `ρ` 无关）作为**函数恒等式**：

```
∃K 常数：  (c/2)C + tD ≡ K[ (c/2)A + tB ]                                             (1.3)
```

`a=0`：`(1.3)` 变成 `(c/2)βw ≡ K·tβw` ⇒

```
K = c/(2t) = ½ cot(θ/2)        ← q04 的等式，被 (1.2) 的秩塌缩单独挑出来     [T]
```

`a≠0`：`(1.3)` 是 `{A,B,C,D}` 之间的一条线性相关，而 `G,H` 的**零点集不同**（§2）⇒ 无解。

### 1.2 两条边界上的**精确**值（判死的硬证据，`[T]`）

`c/2` 括号在 `ρ=a` 处出现 `sin(a/2)/a − sin(a/2)/a = 0` 的对消：

```
ρ = |a|（s=0, u=1）:
  G(a,a) = β[ (c/2)sin(a/2) + t( w(a) + a w′(a) ) ]
  H(a,a) = β[ (c/4)cos(a/2) + t( 2w′(a) + a w″(a) ) ]                                 (1.4)

ρ = 2π（w=0，w′=−1/4π，w″=1/4π²）:
  A(2π)=0,   B(2π)=C(2π)= −a²β/(8π²),   D(2π)= 3aβ(a²−4π²)/(32π⁴)
  G(2π) = −β t a²/(8π²)
  H(2π) = −β(c/2)a²/(8π²) + βt( −3a/(8π²) + 3a³/(32π⁴) )
  ⇒  H/G |_{2π} = ½cot(θ/2) + 3/a − 3a/(4π²)                                          (1.5)
```

**(1.5) 就是判死线**：`a≠0` 时 `H/G` 在 `ρ=2π` 的值与 `½cot(θ/2)` 差 `3/a−3a/(4π²)`（`a=0.3`：差 `+9.98`，即 20 倍）。而 `(1.4)` 在 `ρ=|a|` 给出 `H/G≈0.369`（`a=0.3, θ=π/2`）。同一连续函数在两个边界取 `10.477` 与 `0.369` ⇒ **`H/G` 不是常数**，`(a)` 死。

**顺带一个新事实**：`B(2π)=C(2π)` 精确成立——`t`-扇区与 `c`-扇区在端点**数值相等**但不是同一个函数，这正是 `H/G|_{2π}` 有界而 `H/G|_{ρ_z}` 发散的原因。

## 2. 零点集论证（比 (1.5) 更强：`H/G` 有**极点**，`[T]+[E]`）

- `a=0`：`G=βt w`、`H=(βc/2)w` ⇒ 两者零点集**完全重合** `={sin(ρ/2)=0}`，比值恒为常数。这是 `a=0` 唯一"干净"的地方。
- `a≠0`：`G(a,2π) = −βta²/(8π²) < 0`（`∀a>0`），而 `G(a,|a|)>0`（`(1.4)`，`β=2.5,θ=π/2` 下 `1.006/1.146/1.229`）⇒ `(0,2π)` 内**至少一个零点** `ρ_z(a)`（数值：`a=0.3→6.270677`、`0.75→6.216699`、`1.2→6.133125`，各**唯一**）。而 `H(ρ_z) ≠ 0`（`≈ −0.02 / −0.06 / −0.09`）⇒ `H/G` 在切片内部**有极点**（网格上 `max|H/G| = 4.0e5 / 8.1e4 / 1.2e5`）。
- ⇒ **不是"近似常数"，是"结构上不可能成比例"**。`G` 的零点从 `2π` 向内迁到 `ρ_z(a)`，`H` 的零点不动在别处（`a=1.2` 时 `H` 在 `ρ≈4.0` 过零）——两个零点集从 `a=0` 起**立刻分裂**。

## 3. `a=0` 为何特殊（三条等价说法，`[T]`）

1. **秩塌缩**：`(A,B,C,D)|_{a=0} = (0,βw,βw,0)`（(1.2)），4 个函数只剩 `span{w}`（1 维）⇒ `H` 与 `G` 自动成比例，`K` = 两系数之比 `= (c/2)/(t)`。
2. **偶/奇分解**：`S_W = c·[−cos(ρ/2)] + t·[a w(ρ)]`，`ρ=√(a²+s²)` 使第一项是 `a` 的**偶**函数、第二项是**奇**函数。故 `a=0` 处：偶部一阶导 `=0`（`A(0)=0`）、奇部二阶导 `=0`（`D(0)=0`）。**剩下的两块**——奇部的一阶（`=βw`）与偶部的二阶（`=βw/2`）——**恰好都是 `sin(ρ/2)/ρ`**，因为二者都来自"对 `sin(ρ/2)` 求一次导再除以 `ρ`"（框架场 `n=ξ/ρ` 的 `1/ρ`）。这是模型的一次**巧合**，不是普适机制。
3. **`Φ'≡0`**：`Φ=Φ(ρ)` ⇒ `∂₃Φ = Φ_ρ·a/ρ → 0`。故 `a=0` 上"力 = `∂_aS`"与"力 + `Φ'`"是同一对象（`Q04 §4.3` 的 `W_geo=E[Φ'']`、`Var(Φ')=0` 都是这一条）。

## 5. 对 H1 / `q04` 判据的结论

```
a=0:  H = ½cot(θ/2)·G  逐点、β-无关  ⇒  E[H]=K E[G], Var(H)=K²Var(G)  ⇒ 判据 = 一维比较
                                  ⇒ [T] β sin²(θ/2) ≤ cos(θ/2)   (Q04 (4.2))
a≠0:  H = K(a)G + C(a) + O(1e−3)     ⇒  Var(H)=K²Var(G) 仍在 (≤1e−5)
                                    ⇒  E[H]=K E[G] 不在 (7%–57%)
⇒ 判据只剩:  Var(G) ≤ E[H]  ⟺  Var(G)/E[G] ≤ K(a) + C(a)/E[G]
```

最后一行是**恒真的代数变形**，不是结构定理——因为 `Var(G), E[G], E[H]` 三者都已是 1-维求积（`Q04 §3.3`），本来就可算。**`K` 的存在性原本带来的唯一增益**是：(i) `K` 与测度无关（`β`-无关、闭式），(ii) 由 `0≤w≤1/2` 的**逐点界**能直接榨出充分条件 `(4.2)`。`a≠0` 时两点**全部丢失** ⇒ `(a)` 不成立。

**所以（判死线）**：

- **(a) 不成立**：不存在确定性 `K(θ,a,β)` 使 `H=KG` 逐点；`q04` 判据**不能**代数化推广到全 `a`。
- **(b) 成立（逐点/精确层面）**：`K` 只在 `a=0` 存在，原因是 `(A,B,C,D)|_{a=0}` 秩塌到 1（`Φ'≡0` 是同一件事的第三种说法）。
- **(c) 成立（矩层面）**：`H/G` **不是**"近似常数"——它有极点（`ρ_z(a)`）、bulk 漂移 `−26%…−54%`（`a=0.3`）、`a=1.2` 整段变号。但**仿射**结构使 `Var(H)=K²Var(G)` 在 `≤8e−4` 内成立、`K` 由 `Cov/Var(G)` 给出，`E[H]=KE[G]` 不成立。

**给下一手的入口**：要回到"全 `a` 的一维比较"，需要的不是 `K`，而是 `C(a)` 的闭式（`§4.3` 的缺失项）+ `Q08 §3` 的 `G″(a)` 符号表（负区 `[a₁,a₂]` 就是判据的失效集）。两者都是 1-维求积，**已在手**。
