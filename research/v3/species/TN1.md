## 3 · ★ 无条件上界 `B = 19¹⁹/18¹⁸`（本轮新，`[T]`）

**命题.** `t_n ≤ B^n`，`B = 19¹⁹/18¹⁸ = 50.2820906008560238796…`。

*证明.* `(Γ,T)` 是 `G` 的嵌入子树（含 `p₀`）。`T` 单连通 ⇒ 到万有覆盖（20-正则树）的提升**存在且唯一**，且 `T` = 提升的像 ⇒ `T ↦ T̃` **单射**。故 `t_n ≤ #`{20-正则树中含定点的 `n` 顶点子树}。后者由 `F = x(1+G)^{20}`、`G = x(1+G)^{19}` 的系数给出：令 `y = 1+G`，`x = (y−1)/y^{19}`、`F = y(y−1)`，`x'(y)=0 ⇒ y = 19/18` ⇒ 增长常数 `1/x_s = 18(19/18)^{19} = 19¹⁹/18¹⁸`。∎

| 量 | 值（`decimal` 40 位 / 精确有理数） | 备注 |
|---|---|---|
| `B` | `50.28209060085602387963215001398393431922` | `=1978419655660313589123979/39346408075296537575424` |
| `eΔ` | `54.36563656918090470720574942705324995514` | 语料常数 |
| `B/eΔ` | `0.92488736955873732668…` | **无条件改进 7.49%** |
| `B/48` | `1.04754355418450049749…` | **仍高于门槛 4.75%** |
| 门槛换算 | `thr = 8·48/λ_T`：`λ_T=eΔ ⇒ 7.0633`；`λ_T=B ⇒ 7.6369` | 仍需 `>K̂=8`，**不够** |

⇒ **`λ_T = eΔ` 这个写法把 Cayley 界的松弛当成了常数**（`A01:26`、`ADJ2:14` 的 `(eΔ)^n` 只是 Cayley×度，未用"嵌入树 ≪ 标号树"）。本轮给出第一条**严格更紧**的常数；它与 `eΔ` 同型（都是"每片一个因子"的界），故**不换判据、只换常数**，可直接代进 `P3` 的 `|w(γ)| ≤ (Ĉλ_Tu)^{|γ|}`。

## 4 · 判（对照任务的三条死线）

### (b) 严格假 `[T]`
`t_n^{1/n} ≤ 50.282 < 54.366 < 54.37`（`n` 全）⇒ **不可能"趋于 `>54`"**。语料若把 `λ_T` 当成"真常数 = `eΔ`"，该读法被上面这条上界**无条件否掉**（真常数 `≤50.282`）。

### (a) 未定 `[X]` —— 本轮**不**给 (a)，因为 `n≤6` 判不了
- 精确：`t_n^{1/n}|_{n≤6} = 1, 4.4721, 8.2913, 11.7058, 14.6256, 17.1067`；逐比 `20, 28.5, 32.940, 35.642, 37.448` **仍在陡升**。
- 外推**不稳**（这是实数）：`L−C/n` 逐窗给 `11.5, 19.6, 24.8, 28.4`；`L−C/n²` 逐窗给 `21.7, 27.2, 30.8, 33.3` —— 拟合值**随窗口单调爬升**，没有平台 ⇒ 用它们断言 `<48` 或 `>48` 都是编。
- 严格夹逼现状：`17.1067 ≤ liminf ≤ limsup ≤ 50.2821`。**`48` 在这条夹逼里面**，`n≤6`（乃至手推 `n≤8`）都不可能定案。
- 唯一能开窗的诚实路径有两条：**(i)** 把 `B` 压到 `<48`（需"覆盖-子树里非提升者"的**计数定理**：4D 面片图的短圈使一部分覆盖子树不是提升 ⇒ 可剪，缺口只有 `4.75%`，量级上**现实**）；**(ii)** 算 4D 面片**树常数**的真值（`Q5:19` 已记 `μ` 未知；需要 Baxter/转移矩阵型方法，不是枚举）。

### (c) 否 `[E]`
`t_n ≠ m_n`：`n=3` `570 vs 514`、`n=4` `18776 vs 14748`、`n=5` `669215 vs 450255`。`t_n` 还 `≠ a_n`。三者互不相同，且 `m_n`（`ur2`/`RUNBOOK:16962`）本轮独立复算一致 ⇒ `m_n` 本身没错，只是**对象不同**。

## 5 · 两条必须写死的假朋友（本轮实测，防下一个人踩）

1. **"生长枚举"数出来的不是片集数**：按"每步把一个边界片加进来"直接数（不按集合去重）得到
   `1, 20, 514, 14748, 450255` —— **恰好等于 `m_n` 的前 5 项**。即：**一个不去重的 `n≤8` 生长枚举会输出 `ur2` 的 `m_n` 数列，看起来完全对**（`n≤5` 逐位对），从 `n=6` 起才分叉（本轮 `a_6 = 7218768`，若沿用生长计数会得 `~1.1×10⁷`）。
   ⇒ 任何 `t_n`/`a_n` 枚举**必须按片集去重**；`m_n` 不能被当成"簇数"。`[E]`
2. **`τ_max` 涨得慢不代表 `t_n` 涨得慢**：`τ_max = 1,1,3,16,125,1296`（`1296 = 6⁴`），`mean τ = 1,1,1.2445,1.6867,2.3886,3.4716` —— 树因子只贡献 `(mean τ)^{1/n} ≈ 1.19`（`n=6`），`t_n` 的上升**主要来自 `a_n`**（`a_n^{1/n}=13.90`，`n=6`）。⇒ 想压 `λ_T` 等价于压**片集计数**，不是压 `τ`。
