## 0 · 判死线（先写完，后给论证）

1. **恒等式本身：成立，逐位** `[T]`。`1/(2b₀g²) = 12π²β/(11N²)` 精确。数值：**`SU(2) = 2.691710`**（`3π²/11`）、**`SU(3) = 1.196316`**（`4π²/33`）。
   ⚠ 计划写的 `1.197` **应为 `1.196`**（`4π²/33 = 1.1963157`）；`2.692` 对（`3π²/11 = 2.6917103`）。
2. **`⟺` 是 (A)：纯运动学恒等式，零物理内容** `[T]`。它不是 (B)。
3. **计划的字面写法双向皆假**（两处错，见 §4.3、§9）：
   - **符号错**：正确是 `d ln(ma)/dβ = −12π²/(11N²)`，**不是 `+`**。因为 `β→∞ ⟺ a→0`，而 `aΛ = e^{−t}`、`t = 12π²β/(11N²)` 随 `β` 单调增 ⇒ `d ln(aΛ)/dβ < 0`。语料自己的数据（`ma` 随 `β` **下降**）与负号一致。
   - **少了一阶**：两圈给出 `+51/(121β)`，使"字面等于一圈数字"在**任何有限 `β`** 都不成立（`SU(3), β=6`：`−1.126068` vs `−1.196316`，差 **5.87%**）。
4. **判死线归属：(a) 成立 + (c) 成立；(b) 只对"字面数字版"触发。**
   - **(a)**：化简**成立**，但**只是把目标重写，没有削弱、也没有推进**（它就是恒等式，不可能削弱）；
   - **(c)**：两圈把结论变成 `斜率 = −(12π²/(11N²))[1 − (b₁/b₀)g² + O(g⁴)]`，`O(g²)` 系数 **`−b₁/b₀ = −17N/(88π²)`**（`N=2: −0.0391468`；`N=3: −0.0587202`）；等价写成 `[1 − (17/44)·N²/(π²β)]`；
   - **(b)**：字面版有反例（§4.3），但**恒等式版不会被 `m/Λ` 的 `β`-依赖破坏**——`m/Λ` 在两边同号出现、恒等抵消。
5. **循环性：是，且无法避免。** `⟺` 只在"两边取同一截断阶"时成立，此时它是**重言式**；一混阶（左边用真 `m`，右边用一圈数字）就**假**。所以它**永远不携带信息**。同理，斜率等式**预设 `ma > 0`**（否则 `ln ma` 无定义）⇒ **它预设质量隙，不能用来证质量隙**（§7）。

## 1 · 恒等式逐步核 `[T]`

**输入（本文件唯一口径，与 `A8-MASS-LAMBDA §1` 同）：**

```
β(g) = dg/d ln μ = −b₀g³ − b₁g⁵ + O(g⁷)   [纯 YM, Nf=0]
b₀ = 11N/(3(4π)²) = 11N/(48π²)            b₁ = 34N²/(3(4π)⁴) = 17N²/(384π⁴)
Wilson: β_W = 2N/g²  ⟺  g² = 2N/β_W
```

**四步，每步落到数上：**

| 步 | 算式 | N=2 | N=3 |
|---|---|---|---|
| 1 | `2b₀g² = 2·(11N/48π²)·(2N/β) = 44N²/(48π²β) = 11N²/(12π²β)` | 符号式 | 符号式 |
| 2 | ⇒ `1/(2b₀g²) = 12π²β/(11N²)` | `= 3π²β/11` | `= 4π²β/33` |
| 3 | 系数 `12π²/(11N²)` | **`2.6917102912`** | **`1.1963156850`** |
| 4 | `β=2.5` / `β=6` 处 `t := 1/(2b₀g²)` | `6.729276` | `7.177894` |

第 4 行 SU(3) 的 `7.177894` 与语料已核的 `t(g²=1) = 7.18`（`A6-TARGET §2`）逐位吻合 ⇒ 恒等式 `[T]`，无遗留。

## 2 · 归一二义性：三套 `β` 的系数**必须分别给**（不是同一个数）

同一个物理量 `t := 1/(2b₀g²)`，换 `β` 变量就换系数。设 `d ln(ma)/dβ = −κ[1 − (b₁/b₀)g² + …]`：

| `β` 变量 | 定义 | `g²` | **`κ = dt/dβ`** | N=2 | N=3 |
|---|---|---|---|---|---|
| **Wilson `β_W`**（格点标准、`BETA-CONVENTION` 已钉） | `2N/g²` | `2N/β_W` | **`12π²/(11N²)`** | `2.691710` | `1.196316` |
| **`λ_tH = βN`**（语料 `CONSTANTS-CHECK §2` 的格点量 `= 2N²/g²`） | `2N²/g²` | `2N²/λ_tH` | **`12π²/(11N³)`** | `1.345855` | `0.398772` |
| **SZZ `β_A`**（`S = Nβ_A Re ΣTr`，`= 2/(g²N)`） | `2/(g²N)` | `2/(Nβ_A)` | **`12π²/11`** | `10.766841` | `10.766841`（**N-无关**） |

- 三者关系：`κ(β_W) = N·κ(λ_tH) = κ(β_A)/N²`（用 `β_W = N²β_A = Nλ_tH`）。**任一处混读即错 `N` 或 `N²`——这正是 `BETA-CONVENTION` 抓到的 C2 病。**
- **第四行的陷阱**：若把 `λ = g²N`（真 't Hooft 耦合，**不是**倒数）当自变量，则 `t = 24π²/(11λ)`、`dt/dλ = −24π²/(11λ²)`，**符号相反**（`β↑ ⟺ λ↓`）。语料 `λ_tH` 不是 `λ`，别再混（`CONSTANTS-CHECK` R1 已记）。

## 3 · 解出 `a(β)`：领头阶 + 两圈（带 `b₁`）

两圈 `Λ` 的标准闭式（把 `2b₀` 显式写出，与 `A8` 同口径）：

```
aΛ = e^{−t} · (2b₀g²)^{−b₁/(2b₀²)} ,  t = 1/(2b₀g²) = 12π²β/(11N²) ,  b₁/(2b₀²) = 51/121
```

代 `β`：`2b₀g² = 11N²/(12π²β) = 1/t`，故

> **`aΛ = t^{51/121}·e^{−t}`，`t = 12π²β/(11N²)`。**（领头阶 = 丢掉 `t^{51/121}`。）

**独立交叉核对 `[M]`**：本闭式给 `aΛ(SU(3), β=6) = 1.751751e−3`、`aΛ(β=6.3) = 1.248928e−3`，与 `A8-MASS-LAMBDA §2` 表的 `1.7518e−3 / 1.2489e−3` **四位全同**；比值 `0.71296` 与 `A8 §3` 的两圈预言 `0.713` 同。⇒ 闭式无误（常数 `2` 已被吸收，导数不受任何常数因子影响）。

**精确两圈原函数（做符号裁判用）**：分部积分给

```
aΛ = e^{−t}·[b₀g²/(1+(b₁/b₀)g²)]^{−b₁/(2b₀²)}
```

即 `A8 §1` 第 4 行记的那条"精确二圈闭式"，与标准式差一个 `O(g²)` 的 log 自变量修正，**不改导数主项**。

## 4 · `⟺` 的裁决

### 4.1 (A) —— 运动学恒等式 `[T]`（这就是那个 `⟺`）

记 `m̂ := m_phys·a`（无量纲格点质量 = 语料的 `ma` 列）。`m̂ = (m_phys/Λ)·(aΛ)`，于是

```
ln m̂ = ln(m_phys/Λ) + ln(aΛ)                                        (4.1)
```

对 `β` 求导，`d ln(aΛ)/dβ` 与 `m_phys` 无关，故

> **(A)** `[ m_phys/Λ 为 `β`-无关纯数 ]  ⟺  [ d ln m̂/dβ = d ln(aΛ)/dβ  ∀β∈区间 ]  ⟺  [ d ln m̂/d ln a ≡ +1 ]**

三个等价式是**同一句话的三种写法**：由 (4.1)，`m̂/(aΛ) ≡ m_phys/Λ`，所以第一个括号就是 `X = const`，第二/三个是 `d ln X/dβ = 0` 的改写。
**零物理内容**：不含 `m` 的大小、不含 `m>0`、不含 `Λ` 的跑动，只用 "`Λ` 是唯一标度" 的定义。`[T]`，但它是一句**重言式**。

### 4.2 (B) —— 数值钉死 `[T]`，但只是微扰级数

(A) 的右边是**函数** `d ln(aΛ)/dβ`。把它**算出来**（用 §3）才是 (B)：

```
t = 12π²β/(11N²) ,  ln(aΛ) = −t + (51/121)ln t
d ln(aΛ)/dβ = κ·[−1 + (51/121)/t] ,  κ = dt/dβ = 12π²/(11N²)
```

并用恒等式 `(51/121)/t = (b₁/b₀)g²`（**精确**，见 §5），得

> **`d ln(aΛ)/dβ = −(12π²/(11N²))·[1 − (b₁/b₀)g² + O(g⁴)]`**  `[T]`（两圈 RG；`O(g⁴)` 含**方案依赖**的三圈系数 `b₂`，故只有到 `O(g²)` 是方案无关的）。

这就是 (B)：**RHS 是一个可以算的、与 `m` 无关的函数**。计划把它写成 `12π²/(11N²)`——(B) 的**领头阶近似**。

### 4.3 字面 `⟺` 的两个方向都假（反例）`[T]`

把 RHS 当**字面常数** `12π²/(11N²)`（不带 `[1−…]`），并修符号：

- **`⟸` 假**：设 `d ln m̂/dβ = −12π²/(11N²)` **对所有 `β`**，则 `m̂ = A e^{−t}`，而真 `aΛ = t^{51/121}e^{−t}` ⇒
  `m_phys/Λ = m̂/(aΛ) = A·t^{−51/121}`，**随 `β` 跑动**（`∝ β^{−0.4215}`）。⇒ 字面等式**逼出**"`m` 不是物理的"。**方向的结论反了。**
- **`⟹` 假（反例）**：取**完全物理**的 `m_phys/Λ = const`（最干净的情形：`m/Λ = 1`）。则真斜率是
  ```
  SU(3), β=6 :  −1.196316 + 51/(121·6) = −1.126068   ≠  −1.196316      (差 5.87%)
  SU(2), β=2.5: −2.691710 + 51/(121·2.5) = −2.523115 ≠ −2.691710      (差 6.26%)
  ```
  ⇒ **`m` 是物理的，字面等式却不成立。** 反例就是 `m/Λ ≡ 1` 本身。

**结论**：字面 `⟺` **不是定理**；它是"一阶截断 + 符号错"。**(b) 对字面版触发，且反例就是 `m/Λ=const`。** 而 (A)（把 RHS 写成函数）**不会被任何 `m/Λ` 的 `β`-依赖破坏**——`m/Λ` 在两边同号，恒等抵消。

### 4.4 循环性诊断（计划 §1 的实质）

- **同阶 → 重言式**：若 `aΛ` 与 `m̂` 用**同一阶**的 `Λ`-轨迹（§3 的 `t^{51/121}` 两边都在），则 `⟺` 精确成立且是 (A) —— 空的。
- **混阶 → 假**：左边真 `m`（两圈真轨迹），右边一圈数字 ⇒ §4.3 的双向反例。
- **没有第三种情形。** 所以"斜率 = 一圈系数"这句话**不可能携带信息**：要么它在定义上真，要么它在数值上假。

**⇒ 明确裁定：`⟺` 是 (A)。** 计划 §1 的化简**成立，但是"把目标重写"，不是"把目标削弱"，更不是"把目标推进"。

## 5 · 两圈系数 `[T]`（题面要求的 `O(g²)` 系数）

```
b₁/b₀ = (17N²/384π⁴)/(11N/48π²) = 17N/(88π²)            N=2: 0.0391468 ; N=3: 0.0587202
b₁/(2b₀²) = 51/121 = 0.4214876                          （N-无关，精确有理数）
恒等式:  (b₁/(2b₀²))/t = (b₁/b₀)g²                       （用 t = 1/(2b₀g²)，精确）
```
