**`(b)` 触发（在 3–8 段）。** 文献实测的纯规范（`N_f=0`）值是

| 群 | `m_{0++}/Λ_MS` | 出处 |

**错在哪一步（见 §6 定量诊断）**：主因是 **`m a` 口径**——`A8` 把语料的 `m a = 1.073(88)`（`β=6.00`，格点单位）当成**物理 `0++` 质量**乘 `a^{-1} = 2.91 GeV` 得 `3.12 GeV`，而实测 `m_{0++} = 1.653(26) GeV`，**高 `1.89×`**；次因是 `Λ` 取 `200–240 MeV` 而实测 `Λ_MS^{(0)} = 263(4)(9) MeV`，**低 `1.10–1.32×`**（两个错方向相反，净 `1.4–1.7×`）。修好后 `c = 6.3–7.5`，与文献一致。
**第二候选机制（同样能落到 12–18 区间，须排除）**：若 `Λ` 实际是 **`Λ_I`（lattice/I-scheme）** 而非 `Λ_MS`，则 `m/Λ_I = 16.5`（SU(3)）/ `17.1`（SU(2)）——正好压在 `12–18` 里。两者差一个 `Λ_MS/Λ_I ≃ 2.633` 的 scheme 常数（AT2021 eq.(16)，**正文**）。`A8` §4 已指出"缺一步 scheme matching"；本节给出这一步之后**收敛到的文献值**。

## 3 · 换算 A：`√σ` 路线（同一篇文章内闭合，最干净）

用 E1 的 `Λ_MS/√σ`（Table 15）除 E1 的 `m/√σ`（Table 34）：

```
SU(3):  m/Λ_MS = 3.405(21) / 0.5424(13)[185] = 6.278
                 stat ±0.016（两条统计误差相加）
                 syst ±0.214（0.0185/0.5424 = 3.41%）
        ⇒  m_{0++}/Λ_MS = 6.28 ± 0.02 ± 0.21

SU(2):  m/Λ_MS = 3.781(23) / 0.5806(21)[570] = 6.512
                 stat ±0.024   syst ±0.639（0.0570/0.5806 = 9.82%）
        ⇒  m_{0++}/Λ_MS = 6.51 ± 0.02 ± 0.64
```

**中间值出处**：`m/√σ` ← E1 Table 34（p.82）；`Λ_MS/√σ` ← E1 Table 15（p.67，正文 p.18 eq.(22) 复述 SU(3) 值）；方括号系统误差 ← Table 15 表头注明"estimate of the (correlated) systematic error in square brackets"，并由 eq.(22) 的 `[185]` ↔ `r_0Λ` 的 `[22]` 交叉验证其量纲（`0.0185 × 1.160 = 0.0215 ≈ 0.022` ✓）。

**稳健性**：
- SU(3) 若改用 `a⁴` 变体 `3.391(23)` ⇒ `6.252`（差 0.4%，可忽略）。
- SU(3) 若把 `Λ` 换成 Table 15 的 **2-loop** 值（`√σ/Λ_I` 2-loop `5.210` vs 3-loop `4.855` ⇒ `Λ` 低 `6.8%`）⇒ `6.28 × 5.210/4.855 = 6.74`。**"两圈 vs 三圈"只搬 7%，搬不动 2.6 倍**（见 §6）。

## 5 · 换算 C：物理单位直除（最不依赖约定）

`m_{0++} = 1.653(26) GeV`（E1 Table 37；E2 Table 15 给 `1.651(23) GeV`，两者一致）÷ `Λ_MS = 0.263(4)(9) GeV`（E1 eq.(22)）：

```
m/Λ_MS = 1.653 / 0.263 = 6.285  ⇒  6.28 ± 0.14 (stat) ± 0.22 (syst)
```

三条路线（A/B/C）在 SU(3) 上收敛到 **`6.28`**，互为独立校验（A 用 `√σ` 消掉 `a^{-1}`，C 直接用 MeV，B 用 `r_0`）。

## 6 · 判定 (a)/(b)/(c) 与定量诊断

| 判据 | 结果 |
|---|---|
| **(a)** 文献落在 8–25 ⇒ `c=12–18` 有独立支撑 | **否**。最高一条（E3 旧变体 `4.30`）也只到 `6.84`；整带 `6.3–6.9`，SU(2) `6.5`。 |
| **(b)** 落在 3–8 或 25–100 ⇒ 我们的 `c` 有问题 | **是**。`6.3` vs `12–18`：高 `1.9–2.9×`。 |
| **(c)** 找不到 `N_f=0` 的值 | **否**。E1/E2/E3/E4 全是 `N_f=0`，不需要借 `N_f=2` 的不可比数据。 |

### 6.1 反解：`c = 12–18` 要求 `Λ` 是多少

`Λ = 1.653 GeV / c` ⇒ `c = 18` 要 `Λ = 92 MeV`，`c = 12` 要 `Λ = 138 MeV`。**文献 `Λ_MS^{(0)} = 263(4)(9) MeV`**。所以我们的 `c` 等价于**把 `Λ_MS` 压低了 `1.9–2.9×`**（或把 `m` 抬高了同样的倍数）。两个方向逐一核：

| 候选错步 | 定量效应 | 判定 |
|---|---|---|
| **`m a` 口径**：拿语料 `m a = 1.073(88)`（`β=6.00`）当物理 `0++` 乘 `a^{-1}=2.91 GeV` ⇒ `m = 3.12 GeV` | `3.12/1.653 = 1.89×`（`+89%`） | **主因**。`ma = 1.073` 是**粗格点上未取连续极限、且很可能是弱耦合支的格点质量**；真值 `m a = 1.653/2.91 = 0.568`。这一步单独就能把 `6.3` 抬到 `11.9`。 |
| **`Λ` 取值**：用 `200–240 MeV` 而非 `263(4)(9) MeV` | `263/220 = 1.20×`（`12–32%`，方向相反=压低 `c`） | 次要，但方向**与我们需要的相反**，说明 `c` 偏高的主因只能来自 `m`。 |
| **`Λ` 两圈 vs 三圈** | `Λ_2loop` 比 3-loop 低 ~7%（E1 Table 15：`√σ/Λ_I` 4.855 vs 5.210）⇒ `c` 抬 `8%` | 太小，**不是主因**。`A8` §1 第 6 步的 `½` 缺失是 30% 级，也不是主因。 |
| **scheme：用了 `Λ_I` 而非 `Λ_MS`** | `Λ_MS/Λ_I = 2.633` ⇒ `m/Λ_I = 16.5`（SU(3)）/`17.1`（SU(2)） | **强候选**：恰好落在 `12–18`。若语料拟合出的是 lattice/I-scheme 的 `Λ`，则 `c` 报的是 `m/Λ_I`，不是 `m/Λ_MS`。**必须核**：`c` 的分母到底是哪一个 `Λ`。 |
| `ma` 之外：把 `0^{-+}`/`0^{+-}` 质量误当 `0++` | `5.276/0.5424 = 9.7`；`7.29/0.5424 = 13.4`；`9.32/0.5424 = 17.2` | 通道错标的后果与 `12–18` 重叠，**顺带排除**：语料若报 `0^{+-}`/`0^{-+}ex1` 会落进同区间。 |

**结论**：`c = 12–18` 来自**两个可修的口径问题同时存在**——(i) `m` 用格点单位质量冒充物理质量（`×1.89`，主因）；(ii) `Λ` 的 scheme/loop 归一未落到 `Λ_MS^{3-loop}`。把 (i) 修好（`m = 1.653 GeV`）就落到 `c ≈ 6.3–7.5`；若 (ii) 里是 `Λ_I`，还需再乘 `1/2.633`。**两个都修 ⇒ 与 E1 的 `6.28` 一致。**

**对 `A8` 的更正（只更正数值，不改其结构结论）**：
- `A8` §5.3 的 "`m/Λ_phys ≈ 13–16`"（`3.12/0.21 = 14.9`、`3.12/0.24 = 13.0`）**偏高 `1.9–2.4×`**。
- `A8` §5.3 括号里"按物理 `m(0^+)a = 0.588` 修正，则 `≈ 8–9`"**仍然偏高 `1.25–1.35×`**——因为它同时用了偏低的 `Λ = 200–240 MeV`：`1.653/0.21 = 7.87`、`1.653/0.24 = 6.89`，用 `263 MeV` 才是 `6.28`。
- `A8` §5.3 末句"`m/Λ_MS^{(0)} ≈ 8.6` 是纯 YM 的常识值"——**这条常识值本身偏高了 ~37%**，实测是 `6.28 ± 0.02 ± 0.21`。
- **不受影响的部分**：`A8` 的判定"`c` 是 `O(10)` 而非 `O(1)`"在形态上仍成立（`6.3` 确实是 `O(10)`），只是系数要改成 `6.3` 而不是 `13–16`；"缺一步 scheme matching"的诊断也仍成立。

## 7 · 未取数 / 未核（诚实清单）

- **`m_{0++}/T_c`**：本次**未**检索到 E1/E2 系列直接发表的 `m/T_c`，也**未**核到 `T_c/√σ` 的逐位值与其 `T_c` 定义（`N_τ` 外推细节），故**不列数**（不凭记忆写）。任务允许 `m/T_c` 替代 `m/√σ`，而 `m/√σ` 已经由 E1 单文闭合，`m/T_c` 非必需。
- **`N_f=2` 的胶球质量**：**未查**（任务要求只在找不到 `N_f=0` 时才用；此处 `N_f=0` 齐备，故不引入不可比数据）。
- **`Λ` 的其它专用测定**：E1 正文称其 `Λ_MS = 263(4)(9) MeV` 与"近期两篇不同方法的专用计算"（其 refs [48,49]）一致，但**我没有打开那两篇核数值**，故不作为本文件的独立条目，只作 E1 的自述。

## 8 · 一句话给 `c` 的定值

**`m_{0++}/Λ_MS^{(N_f=0)} = 6.3(3)`**（SU(3)：`6.28 ± 0.02 ± 0.21`，带内 `6.3–6.9`；SU(2)：`6.51 ± 0.02 ± 0.64`）。`A8` 的 `c ≈ 12–18` 应改为 **`c = 6.3(3)`**（若分母确为 `Λ_I`，则等价表述是 `m/Λ_I = 16.5(6)`，必须显式写成 `Λ_I` 而不能写成 `Λ`）。
