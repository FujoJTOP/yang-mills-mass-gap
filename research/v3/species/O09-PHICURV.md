## 1. `Φ` 的精确定义（逐字核准）

`docs/paper-v2/ch05-theorems.tex:196–206`（`eq:wgeo` 上方正文）：

```
flat chart X_l = log U_l ∈ su(N),  dU = J dX,  Φ = −log J
SU(N):  Φ = Σ_{i<j} g(λ_i − λ_j),   g(d) = −2 log( sin(d/2)/(d/2) )
```

`docs/paper-v2/ch16-sixth-species.tex:120–124`（`eq:hccrosswalk`）：

```
Φ = −log J_Haar = −log | c_SU(N) / c_flat |² ,   c_flat = Π_{α>0}⟨α,X⟩
```

两者**同一个东西**：`c_SU(N)=Π_{i<j}2sin(d_ij/2)`（Weyl 分母），`c_flat=Π_{i<j}d_ij`，
`−log|c_SU/c_flat|² = Σ_{i<j}[−2log sin(d/2)+2log(d/2)] = Σ g(d)`（差常数 `2log2`，`Φ''` 不受影响）。
`ch16` 自己已把 `eq:hccrosswalk` 判为**定义而非桥梁**（残差 `8.5e-16` 是同一乘积）。

**`Φ''` 的表达式**

```
Φ''(X;v) := ⟨v, Hess_X Φ v⟩ = Σ_{i<j} [ g''(λ_ij)(δλ_ij)² + g'(λ_ij)(δ²λ_ij) ],  λ_ij := λ_i−λ_j
g'(d)  = 2/d − cot(d/2)  = d/6 + d³/360 + …           ≥ 0  on (0,2π)
g''(d) = ½csc²(d/2) − 2/d² = 1/6 + d²/120 + …         ≥ 1/6 on (0,2π)
径向特例（`SU(2)`，`u=⟨v̂,ξ̂⟩`）:  Φ'' = g''(ρ)u² + (g'(ρ)/ρ)(1−u²)
```

**`Φ'' ⪰ 0` 是已证还是数值？——已证 `[T]`。**

1. `g''(d) = ½[csc²x − 1/x²]`，`x=d/2`。`h(x):=csc²x − 1/x²` 在 `(0,π)` 上**严格增**（Cauchy 中值定理，标准），`h(0⁺)=1/3` ⇒ `g'' ≥ 1/6 > 0`。
2. 于是 `Φ'' ≥ (1/6)Σ_{i<j}(δλ_ij)²`，即 `Hess Φ ⪰ (N/12)·id`（归一 `⟨v,v⟩:=2tr v²=1`，`v=T₃=diag(½,−½,0,…)`）。
   `Σ_{i<j}(δλ_ij)² = N·tr(v²) = N/2`（`tr v²=1/2`）⇒ `Φ''(0) = (1/6)(N/2) = N/12`，与 `[2]` 表逐位一致。
3. `Φ''⪰0` **不依赖测度、不依赖 `β`、不依赖条件化点**——这是全项目**最强**的输入（比 `W_geo≥0` 的 Prékopa 更强，后者只在纯 Haar 边缘上，见 `GPP-STRUCT §7.2` 的记号缝隙）。
4. `X≠0` 处含二阶项 `g'·δ²λ`，符号由 `g'≥0` 与 Weyl 型二阶变分给出；本文件数值验证 `N=2,3,4` 各 30 组随机 `(X,v)`：最小 `Φ''` = `0.1672 / 0.2593 / 0.3686`，全部 `≥ N/12`，**地板恰在 `X=0` 取到**（与 `ch16:130` 的 `min Φ''=1/6=N/12` 一致）。

**证 `Φ''⪰0` 还需要什么？不需要新东西**（`g''≥1/6` 是一行微积分）。真正未证的是**另一半**：`Var(力|0)` 的上界——那才是 H1 的缺口，与 `Φ''` 无关。
