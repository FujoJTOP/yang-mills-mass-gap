## 2 · 可证上界：为什么 `C̄ ≤ 20`，为什么 Cayley 不行

### 2.1 第一条路（**失败**，但必须记）：Cayley 计数给不出常数 `[T]`

Penrose 树图界，块 = plaquette：
`|φ^U(Γ)| ≤ τ(G_Γ)·∏_p|w_p|`，`τ` = 簇邻接图 `G_Γ` 的生成树数。
若只用 Cayley `τ ≤ n^{n−2}`，则逐顶点包络

```
n:     1    3     5      10     20     50     100
(n^{n-2})^{1/n}: 1.0  1.442  2.627  6.310  14.82  42.76  91.20      （log §2）
```

像 `n/e` 一样发散 ⇒ **`C̄` 不可能由"标号树计数"给成常数**。这不是技术瑕疵，而是必须换成图论界的原因：树熵必须由**格点位置和**（即 `Δ`）来付。

### 2.2 第二条路（**成立**）：Kirchhoff + AM-GM `[T]`

`Γ` 连通、`n` 片、邻接图最大度 `≤Δ=20`。Kirchhoff：`τ(G)=n⁻¹∏_{j≥2}λ_j`；AM-GM：`∏λ_j ≤ (Σλ_j/n)^{n−1}`；握手 + 最大度：`Σλ_j = 2|E| ≤ Δn`。故

```
τ(G_Γ) ≤ Δ^{n−1}/n  ,     C̄ ≤ sup_n (Δ^{n−1}/n)^{1/n} ⟶ Δ = 20      (1)
```

（去掉握手一步即粗版 `C̄ ≤ 2Δ = 40`。）逐 `n` 数值（log §3）：`n=2: 3.16`、`n=5: 7.96`、`n=50: 17.42`、`n=500: 19.63`、`n=5000: 19.95` —— 单调升到 `20`。

> **结论 `[T]`：`C̄ ≤ Δ = 20`（粗 `≤40`）。**
> **非空性核对**：`m×m` 平面 plaquette 网格（`n=m²`）的 `τ^{1/n}`：`m=2:1.414`、`m=3:1.793`、`m=4:2.054`、`m=6:2.373`（log §3，Kirchhoff 积公式精确）—— 真实簇远低于包络 `20`，但**这是"松"，不是"证到 20 就取 20"**；本文件只主张上界。
> **窗口（`AGENTS §2.1`）**：`(1)` 只对**plaquette 级**簇展开且块重耦合已由 `C_g` 吸收时成立；若块取"聚合物 `γ`"（`P3-DRESSED-MASS:63` 的口径），`n≤|Γ|`，界同形、常数不变。

## 3 · `N`-标度（核心）：`C̄ = O(1)`，`C̄=N²` 是重复计账

`z02` 试过的两读（`Z02-SEILER:84–85` 表 C/D 行）：`C̄=1` 与 `C̄=N²`。钉法：

1. **(1) 里没有 `N`。** `Δ=20` 是 plaquette 邻接度（每 link 6 片 ⇒ `4(6−1)=20`，`P3-FULLREP-KP:116`），纯格子量。故 `C̄` 的可证上界**与 `N` 无关**：`C̄=O(1)`。`[T]`
2. **每-link 的 `1/dim f = 1/N` 已经在 `u` 里。** `u := c_f/N = β/(2N²)`（`X01-L1C:15`、`Z06-HOLEA:88` 逐字"`β/2N` from the expansion × `1/N` from the integration"）。若再乘 `C̄=N²`，同一笔 `1/N` 付两次：`eΔ·N²·(c_f/N) = eΔ·N·c_f`，这正是 `Z02:82` **route A**（`u=c_f`，无每-link `1/N`）的判据。⇒ 两读**是同一判据的两种记账**，不是两个物理情形；而 route A 的 `u` 与精确强耦合质量公式不符（下一条）。`[T]`
3. **精确锚点判死 `C̄=N²`。** 精确 SU(2) 强耦合质量 `M_{0⁺⁺} = −4\ln(β/2N²)`（Gupta hep-lat/9807028 (14.21)，`X01:119` 逐字）。这个 `−4\ln u` 里的 `u` **就是** `β/2N²`，公式里**没有**任何额外的 `N²`。⇒ `C̄=O(1)`；若 `C̄∝N²`，`M` 的 `N`-依赖会多一个 `N²`，与 (14.21) 直接冲突。`[T]`

**⇒ 对 `V06-RADIUS:137` 的回答**：`C_g≤2Ne^β` 的 `N`-标度**不翻转** `β₁`。`β₁ = 2N²/(Ĉ eΔ C̄)`，`C̄=O(1)` ⇒ `β₁ ∝ N²`（Wilson `β` 坐标），即 Hooft 坐标下 `β₁ ∝ N⁰`——与 `1/48` 的 `N`-无关性同向（`Z02:91`）。**`β₁=c·N`（Hooft）不被翻转。**

### 3.1 窗口勘误（`[M]`，不改变判词方向）

`log §4` 用 mpmath 精确积分算 SU(2) 基本特征标系数（权重 `exp(βN^{-1}Re tr U)=exp(β cos θ)`）：

```
β=0.01      c_f=0.005000041667   β/(2N)=0.0025   β/N=0.005
β=1/48      c_f=0.01041704343    β/(2N)=0.005208 β/N=0.0104167
```

即 **`c_f = β/N + O(β³)`**（因 `f≅f̄` 使 `χ_f=χ_f̄` 双计）⇒ 语料的 `c_f=β/(2N)` 是 **`N≥3`** 的陈述；`N=2` 时 `u=c_f/N=β/4`，是语料 `β/8` 的 **2 倍**。后果：`u` 大 2 倍 ⇒ 窗口再窄 2 倍（`Ĉ=4,C̄=1` 时 `β₁` 从 `3.68e−2` 降到 `1.84e−2 = 0.88×(1/48)`）。**方向不变（只更紧），判词 (b) 更稳。** 本文件其余数值一律用语料归一化 `u=β/(2N²)`，便于与 `z02/z12` 对表。

## 5 · 判死线

### (a) `C̄` 可证上界 `< 1.766` ⇒ `I1` 升 `[T]`（无 mod）—— **不触发**

可证上界 `20`；真值只在 `[1,20]`。**本轮不能升级 `I1`。** 要把 `I1` 升成无 mod，需要一个**结构性**论证把树熵消掉（例如证明"位置树计数 `≤(eΔ)^n` 且动物计数不再另付"——即 `C̄=1` 与 `λ_a` 只有一笔账），本层只有 Kirchhoff 界，做不到。

### (b) 上界 `>1.766` 但 `Ĉ·C̄` 仍可控 ⇒ 重算 —— **触发，已重算**

`Ĉ·C̄ = 80`（`Ĉ=4`）/`40`（`Ĉ=2`）虽越 `7.0633`，但 `β₁^{fix}>0`、`δ>0` 在窗口内成立：

```
Ĉ=4, C̄=20:  β₁^{fix} = 1.8394×10⁻³ ,  δ·a(10⁻³)=0.60944
Ĉ=2, C̄=20:  β₁^{fix} = 3.6788×10⁻³ ,  δ·a(2×10⁻³)=0.60944
```

**`I1` 保持 `[T]` mod `C̄`，但窗口改为可证的 `β<1.84×10⁻³`（`Ĉ=4`）/`3.68×10⁻³`（`Ĉ=2`）**；`1/48` 不再可用（除非外部给出 `C̄<1.766`）。

### (c) `C̄` 依赖 `N` 且 `N=2` 超界 ⇒ 明说 `N` 范围 —— **不触发**

`C̄` 的可证上界**与 `N` 无关**（§3 条 1），故不存在"`N=2` 时才超界"的分叉；超界是**常数级**（`20` vs `1.766`），与 `N` 无关。本文件全部数值窗口：`N=2`、`a=1`（`κ` 的单位）、`β<β₁^{fix}`、`L,T` 一致（KP 逐片条件）。
