## §1 "不可定义"的精确含义

### 1.1 族是什么（记法先钉）
```
族 = { f₁²_{L,a}(β) }  或  { w₁(L,a) := f₁²/M₀ }     （UNIF1 §1.1；P8-TRUTH:22）
物性参数实为 (N, β)：N := L/a ∈ ℕ，a = a(β) 由 AF 跑动反演  （a 是单位，见 §4.1）
```

### 1.2 在**哪个结构**里？—— 答案：**没有任何结构**（结构无关）
o-minimality 的环境固定为：**一个** `ℝ^n`（`n<∞`）+ **一个** o-minimal 结构 `𝓜`；可定义族是某个
`F ∈ Def(𝓜) ⊆ ℝ^n × ℝ^k` 的纤维。所以那句"不可定义"**只能**解成

```
不存在 (n, 𝓜, F) 使 n 固定、𝓜 在 ℝ^n 上 o-minimal、F ∈ Def(𝓜)、且 F(N,β) = w₁ 在窗内全同  [T]
```

⇒ 这对 `ℝ_an`、`ℝ_an,exp`、**以及任何** o-minimal 扩张同时成立：**不是选错结构，是不存在环境**。

### 1.3 `dim ~ (L/a)⁴ → ∞` 为什么使它不可定义（精确机制）
```
① 句法层 [T]：可定义集由一个**有限变元**的公式定义 ⇒ 所有点住在同一个 ℝ^n。
   而族的纤维维数 = 4·dim G·N⁴（格点：N⁴ 个格点 × 4 方向 × dim G），N 无界
   ⇒ 没有公共环境空间 ⇒ 不是可定义族的纤维。这就是"族根本不是**一个**族"。
② 索引层 [T]：N = L/a ∈ ℕ，而 **ℕ 在任何 o-minimal 结构里都不可定义**
   （可定义子集 = 有限个点 ∪ 有限个区间；ℕ 无限且内点空）。
③ 数值层 [T]：以上两层**对任何下界零内容** —— 同一条 typing 难题同样落在每个 |Λ|→∞ 却
   **已证体积一致**的统计力学界上（团簇展开/Dobrushin/Fekete，UNIF1 M5）⇒ 它不可能是"一致"的障碍。
```
**⇒ 被审的那句话（`LOOP-RUNBOOK:18670`）的真内容 = ①+② 的 typing；把它读成"这些函数不可驯服 ⇒ 无一致"是超出了它。**

### 1.4 一条勘误（已在 `UNIF1 §1.3(iii)`，此处记账）
`β(a) ~ log(1/a)` **非可定义**是**假**：`log` 在 `ℝ_an,exp` 里可定义（`exp` 之逆；Wilkie 1996）。
诚实残留只有"`a(β)` 无闭式"= **缺公式**，不是不可定义定理。`[E]`

## §2 ★ 第一问：**限制到子族够不够**（逐条判，这是本路的核心）

### 2.1 三条候选限制的对照表

| # | 子族 | 可定义？ | 保留 `β→∞`（`a→0`）？ | 保留 `N→∞`（`L→∞`）？ | 够 Clay？ | 标签 |
|---|---|---|---|---|---|---|
| R1 | `L/a ≤ C`（有界比例） | **是**（`N ∈ {1..⌊C⌋}` 有限 ⇒ 维数 ≤ `4C⁴dim G` 固定 ⇒ 平凡可定义） | 名义上有 | **没有**（`L = Na ≤ Ca → 0`） | **否** | `[T]` |
| R2 | `a ∈ {2^{-k}}`（离散、可数） | **否**（无限离散 + 在 `0` 处累积 ⇒ 非 o-minimal 可定义） | 有 | 取决于 `L` | **否** | `[T]` |
| R3 | `a ∈ [a₀, a₁]`（紧、远离 0） | **是**（紧 + 解析 ⇒ `ℝ_an`-可定义） | **没有** | 取决于 `L` | **否**（与"固定 `(L,a)`"同等 vacuous） | `[T]` |
| R4 | 全族（要 Clay） | **否**（§1.3） | 有 | 有 | —— | `[T]` |

### 2.2 R1（`L/a ≤ C`）——**可定义，但把它要的东西一起扔了**
1. `[T]` `N` 有界 ⇒ 族 = **有限个**一参数（`β`）族的并；每支是有限维解析积分 ⇒ `ℝ_an`-可定义
   （紧 `β` 窗内由 `ℝ_an` 的定义直接给）。
2. `[T]` **但 `a`-方向恒等恒定**：固定 `(N, β)` 时格点无量纲量 `f₁²` 与 `a` 的**数值**无关
   —— `a` 只是单位，`β` 与 `Λa = F(β)` 是同一条一维流形的两个坐标（`C3-UNIQUENESS:33–34`）。
   ⇒ 在 R1 里说"对 `a` 一致"是**空句**：它恒真且不含信息。
3. `[T]` **而且取错了角**：`L = Na ≤ Ca`，`a→0` ⇒ 物理体积 `V = L⁴ → 0`。这是**小环面**角，
   不是无穷体积连续极限。Clay 要的是 `N→∞` **同时** `β→∞`（`ΛL` 固定大），R1 里前者被禁令排除。
4. `[E]` 顺手勘误 brief 的读法："有界比例 ⇒ 族变成 1 维（参数 `L/a`）"**两处不准**：
   (i) `L/a` 在 R1 里只取**有限多个**值，不是一个参数；(ii) `a` 根本不是参数（§2.2-2）。

### 2.3 R2（`a ∈ {2^{-k}}`）——**可数既不等于可定义，也不给地板**
1. `[T]` `{2^{-k} : k∈ℕ}` 无限、离散、在 `0` 累积 ⇒ **在任一 o-minimal 结构里不可定义**。
   `ℕ` 同理（§1.3-②）。**"变成可数"是把族推离可定义，不是拉近。**
2. `[T]` **可数性连"有地板"都不给**：反例 `λ_k = 1/k`。每一项显式、可定义、`>0`，
   而 `inf_k λ_k = 0`。⇒ 一致地板的内容在**极限值**，不在索引集的基数。
3. `[T]` **若把离散集换成区间**（`a ∈ (0,a₀]`，这才是可定义的做法），则 (§1.3-①) 环境问题回来，
   且 (§2.4) 非紧失控。

### 2.4 就算真把它变可定义：**o-minimal 在非紧参数集上不给地板**
1. `[T]` 可定义族的一致界**只在紧参数集上**成立。教科书反例：`F(x,y)=xy` 在 `(0,1)²` 上
   `ℝ_an`-可定义、无一致下界/上界。而本族**两个方向都非紧**（`β→∞`、`N→∞`）。
2. `[T]` o-minimal 能给的只有**沿可定义路径极限存在**（单调性/曲线选取 ⇒ 极限 ∈ `ℝ∪{±∞}`）：
   它保证"不振荡"，**不保证不是 0**。
3. `[T]` **酸测反证**：自由无质量场 `f₁² ≡ 0` 是 `ℝ_an`-可定义族，角点值 `= 0`。
   ⇒ o-minimal 机器**允许**角点值 0 ⇒ 它没有地板内容。判别力全在**逐点正性**（= `H1`），
   与 `UNIF1 M4`"o-minimal 在这里完全多余"一致。

### 2.5 结论（第一问）
```
"限制到子族"**不是**够不够的问题，而是**方向相反**：
  · 让族可定义的每一种限制（固定 N / 紧 a 窗）**都恰好切掉** Clay 需要的极限方向；      [T]
  · 保住极限方向的每一种限制（R2 或全族）**都不可定义**；                              [T]
  · 而"子族上的界 ⇒ 全族的界"需要传递原理；在手唯一的一条（Arzelà–Ascoli 紧性，UNIF1 M3）
    的**输入就是目标**（紧性 L3 + 极限处正性 H1）⇒ 循环。                                [T]/[C]
⇒ **不够。** 且不是"少一步"，是"两边互补"。
```

## §3 **o-minimal 对可数族给什么？** —— 什么也不给

| 疑问 | 判 | 依据 |
|---|---|---|
| 可数 ⇒ 更"驯服"？ | **否** `[T]` | o-minimal 里没有"可数"这个概念；可定义子集 = 有限个点 ∪ 区间 ⇒ **无限离散集不可定义**。可数无限可定义子集（在 `ℝ`）**不存在** |
| 可数 ⇒ 能给 `inf>0`？ | **否** `[T]` | `{1/k}` 反例：全 `>0`，`inf=0`，每项平凡可定义 |
| 可数 ⇒ 紧性有？ | **否** `[T]` | 可数 + 有界 + 累积点 ⇒ 非闭、非紧；紧性来自闭+有界，不来自基数 |
| 可数族有无 o-minimal 定理 | **无** `[R]` | 该理论的统一性定理形状是"紧参数集上的可定义族"（`H ⇒ U`），与基数无关 |

## §4 Clay 的量词账（"全序列"到底要什么）

### 4.1 `a` 是单位，不是参数
`[T]` 格点理论的参数是 `(β, N, θ, BC)`（全无量纲；`C3-UNIQUENESS:33`）。`a` 只在 `Λa = F(β)` 里出现。
⇒ 所谓"对 `(L,a)` 一致"**实为**"对 `(N,β)` 一致"，两个方向：

```
UV：β ↑ ∞（a→0，固定物理体积）      —— 需要连续极限的存在性 + 该极限处 m>0
IR：N ↑ ∞（固定 β/固定物理 a，L→∞） —— 需要有限体积单调性或紧性（L3）
```

### 4.2 Clay 要的是**双极限沿所有路径**
`[T]` 一个子族上的界只给"某条子序列上 `≥λ*`"；要升级到"所有序列"必须**紧性/单调性**（§2.5）。
⇒ **"全序列"恰恰是被子族限制破坏的那一半**：Clay 的量词是 `inf_{(N,β)}`，而任何可定义化的
限制都把 `inf` 的取极限点搬出定义域。

### 4.3 唯一不循环的可定义化形状（并且它已经是 Clay）
```
要 o-minimal 真正给出地板，必须让角点成为可定义族的一员：
   存在可定义 F 与角点 c = (N=∞, a=0 即 β=∞ 的渐近角)
   F(c) ≥ λ* > 0  ⇒  地板                                     
而 "c 是族的点" = 连续极限对象存在（4D 非阿贝尔：仓内 L1 未建，DF-CONTINUITY §5 L1）
   "F(c) > 0"  = 该对象有隙                                    
⇒ 这条"可定义化"= 「连续极限存在 + 正性」= 目标本身 ⇒ **循环**
```
`[T]`（逻辑层面）+ `[M]`（两个缺失输入：4D 连续极限构造；其正性 = `H1`）。

## §5 死线裁决 + 路径

### 5.1 (a)/(b)/(c)
* **(a) 不成立** `[T]`：任取可定义的子族，Clay 所缺的**两个极限方向**至少缺一个（§2.1 表）；
  且"子族 ⇒ 全族"的传递就是目标（§2.5-3）。⇒ **不是"Clay 有路"**。
* **(b) 部分成立，但只在不承重的意义上** `[T]`：**全族不可定义化**为真（§1.3），但这是 typing，
  对取值零内容（`UNIF1 §1.3(i)` + `M5`）。⇒ **不得**写成"因此无一致"。
* **(c) 成立 —— 本路判 (c)** `[T]`：可定义化**做得到**（R1/R3），但**不够发 Clay**；
  且"半途"要更精确地说成 **互补**：可定义 ∩ Clay-够用 `= ∅`（在保 `N∈ℕ` 的格点族内）。
  ⇒ **可定义化救不了**，因为它不是在补缺的那一步，而是在**删掉那一步**。

### 5.2 路径（可执行的三条，按优先级；均**不**经过可定义化）
```
P1（可造、最小）  有限体积单调性引理：w₁(N+1,β) ≤ w₁(N,β)
                  ⇒ IR 方向 inf_N = lim_{N→∞}，把两个非紧方向压到一个
                  （UNIF1 M2；在手工具：规范不变 PF。`[C]`，量纲/维数/o-minimal 全无关）
P2（备胎）        Arzelà–Ascoli 打在归一化剖面 φ = C(x/r₀)/C(0) 上
                  —— 诚实代价：输入 = 紧性 L3 + 极限正性 H1 = 目标（`[C]`，非捷径）
P3（UV 半边）     连续极限的存在 + 其正性 —— 这就是 4D 构造（L1）与 H1；本路**不提供**
```

### 5.3 不许说
* 不许说"可定义化已使 o-minimal 适用"——可定义化的每一种形状都删掉了 Clay 的方向（§2.5）`[T]`。
* 不许说"族不可定义 ⇒ 无一致"——逆否误用（`UNIF1 §2.1`）`[T]`。
* 不许说"可数族可救"——`{2^{-k}}` 不可定义，且 `{1/k}` 说明基数无用（§3）`[T]`。
* 不许把 P2 说成省一步——其输入即目标（§5.2）`[C]`。
* 不许说"一致地板已证 / 已否证"——只证了"可定义化不是钥匙"与"障碍的定位在非紧 + 角点"。
