## 1 · `φ^U` 的精确读法（任务 1）

### 1.1 逐字

```
Γ        = 有限 plaquette 集（"片"），|Γ| = 片数 F
G_Γ      = 簇邻接图：V(G_Γ)=Γ，{p,q}∈E(G_Γ) ⟺ p,q 共享 ≥1 条 link
φ^U(Γ)   = Σ_{A ⊆ E(G_Γ), (Γ,A) 连通张成} (−1)^{|A|}                     (1.1)
```

- **"连通"与"片"的关系**：连通是 `A` 的性质、作用在**片**上 —— `(Γ,A)` 连通 **且张成**（`A` 的每个端点都在 `Γ` 内、`Γ` 每个点都被 `A` 触到）。**不是**"取 `Γ` 的连通子集"：`Γ` 一旦给定，`φ^U` 对**整块** `Γ` 求和，求和变量只有 `A`。这是 Mayer 系数与"连通子图计数"最易混的一步。
- **它住在哪一层**：`log Z_dec = Σ_{Γ 连通} φ^U(Γ)∏_{p∈Γ}w_p`（`P3-DRESSED-MASS.md:68` 的 `(2.2)` 同式）。故 `φ^U` = **去掉每片权重后的纯图系数**（Mayer/Ursell/Möbius of bond lattice），`A` 的边权取 1（硬核型 `f_e=1`）。这与 `A01:13` 的 `|φ^U(Γ)| ≤ C̄^{|Γ|}u^{|Γ|}` 一致：`u^{|Γ|}` 是**外面**乘上去的。
- **符号**：本文件 8 个图上实测 `φ^U(Γ) = (−1)^{|Γ|−1}|φ^U(Γ)|` **全符**（§2 表），⇒ `TT2` 的 `S2`（"号只跟片数走"）在 `|Γ|≤8` 上由 `[C]` 升为 `[E]` 级证据。

### 1.2 一条便宜恒等式（本轮新增工具，`[E]` 机验）

```
φ^U(G) = [q] P_G(q) = (−1)^{n−1} T_G(1,0)                                (1.2)
```
（`P_G` 色多项式、`T_G` Tutte；推导：`T(1,0)` 只留 `c(A)=1` 项，再用 `P_G(q)=(−1)^{n−1}qT_G(1−q,0)`。）
⇒ 任何簇的 `φ^U` 可用**色多项式系数的首项**一算到底，不需要 `2^{|E|}` 枚举；本文件把它当**独立第二路**。

## 3 · 归一化审计（任务 3，★ 第一问）

### 3.1 三层账，必须分开

```
第 1 层（簇系数）：  φ^U(Γ) ∈ ℤ           —— 无 N、无 β、无 dim r、无 mult      [T]
第 2 层（每片权重）：w_p = u  或  c_f = N u  —— 差一个 N=2                        [T] 口径二选一
第 3 层（每 link）  ：R(κ) = C_{κ/2+1}/C_{κ/2}（Catalan 比）⇒ R(2)=2，∏R=2¹²      [T]+[E]
```
`K̂` 只是把三层乘起来再取 `|γ|` 次根 —— **第 1 层没有归一化自由度**，所以 `−64` 是不可改的（改它等于换定义，不是换归一化）。
