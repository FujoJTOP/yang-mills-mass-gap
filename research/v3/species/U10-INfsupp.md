## §1 `inf supp μ` 的格点实现

设 `C(t)=∫e^{−Et}dμ(E)`，`μ≥0`（KL/OS 给出），归一 `μ(ℝ)=1 ⟺ C(0)=1`。恒等式

```
inf supp μ = lim_{t→∞} −(1/t)log C(t)                                        (1.1) [T]
```

**格点实现（3 步）**：

1. **算子**：零动量 `0⁺⁺` 能量密度 `O(t) = Σ_x P(x,t)`（`P=1−½Re tr U_p`）。`C(τ)=⟨O(τ)O(0)⟩_c`，用 `C̄(τ)=C(τ)/C(0)` 实现 `C(0)=1`（`C(0)=⟨O²⟩_c=Var(O)`，是正数）。
2. **估计**：`E_eff(τ) = −log|C̄(τ)|/τ`，`τ=1,…,⌊L/2⌋`。`τ=0` 无定义（`0/0`）。
3. **取极限**：`τ→∞` 然后 `L→∞`、`a→0`。三项顺序不可交换——`τ ≤ L/2` 是**运动学硬墙**，与 `a→0` 无关。

**绝对值的地位（重要）**：若 `μ≥0` 则 `C(t)>0`（`∫e^{−Et}dμ>0`），`|·|` 是**惰性的**，Jensen 可用。一旦实测 `C̄(τ)<0`（本次 `L=4,τ=2` 就出现），说明 `μ≥0` 已被（减除/噪声）破坏，`|·|` 不再是美化而是**换了一个量**——此时 `E_eff` 连 `μ` 的 Laplace 变换都不是。见 §3 的 WARNING 行。`[J]`

## §2 有限 `t` 的偏差：**从上方**（Jensen 型论证，`[T]`）

> **引理 U10-1.** `μ≥0` 有限，`E0:=inf supp μ`，`M0:=μ(ℝ)`。则 `∀t>0`
> ```
> E0 − (1/t)log M0  ≤  E_eff(t)  ≤  E0 + ε + (1/t)log(1/q_ε),   q_ε:=μ([E0,E0+ε])>0
> ```
> 特别 `M0=1`（格点 `C(0)=1`）时 **`E_eff(t) ≥ E0`**，且 `E_eff(t)→E0`。

*证.* 下界：`E≥E0` `μ`-a.e. ⇒ `e^{−Et} ≤ e^{−E0 t}` ⇒ `C(t) ≤ M0 e^{−E0 t}` ⇒ 取 `−log/t`。
上界：`C(t) ≥ ∫_{[E0,E0+ε]}e^{−Et}dμ ≥ q_ε e^{−(E0+ε)t}`。
两式夹逼即得极限 `=E0`（`ε→0, t→∞`）。

**读法**：`E_eff(t)` 是**底部倾斜**（`dμ_t ∝ e^{−Et}dμ`）下的"平均能量"，它永远 `≥` 支撑底部，`t→∞` 时倾斜测度**塌到支撑底**才取等。**收敛侧 = 上侧**；`E_eff(t)` 的上偏差是 `O(1/t)`（多态时是 `−(1/t)log(c₀+(1−c₀)e^{−Δt})`，**单调降**到 `E0`；连续谱时不必单调，但仍 ≥ `E0`）。

## §4 能否给 `inf supp μ` 一个**可证下界**？

**这个量不能。** 三条理由，逐条不可绕：

1. **方向定理（§2）**：`E_eff(t) ≥ E0`，即上界；任何上界都不能推 `E0>0`（`E0=0` 满足同一条）。
2. **实测侧无信息**：`L=2` 的 `2.191`、`L=4` 的 `2.271`、无隙模型测度的 `0.565` 都是同类型的上界读数；酸测说明它们的**数值大小**不区分有隙/无隙（`[V]`）。
3. **矩/单点盲**：`inf supp` 不是任何有限谱数据的连续泛函（`GAP-G2-edge`：`δ₀+δ₂` 与 `2δ₁` 同矩异边；`A4-SPECTRAL-BOOTSTRAP`：每个真定理只**上界**边）。`E_eff(t)` 是"一个 `C(t)` 值 + 归一"的函数，比矩还少。

**能给出下界的唯一形状（`[T]`，与本文件结论方向互补）**：

```
∃m>0 :  C(t) ≤ C(0)·e^{−m t}   ∀ t          ⟺   inf supp μ ≥ m
```

（`⇐` 平凡；`⇒` 若 `(0,m)` 上有质量 `q`，则 `C(t) ≥ q e^{−(m−ε)t}` 与大 `t` 矛盾。）**注意这是"对全 `t` 的一致上界"，即衰减率定理**——强耦合下它就是 OS/P3 的 `|C(t)|≤Ce^{−mt}`（`GKS-GAUGE L5`），`β=2.5` 没有它。**`E_eff(t)` 的单个值给的是反面**：`E_eff(1)≤M` 只说"`C(1)` 不太小"，与"`C(t)` 全 `t` 都小"无关。

## §5 `(c)`：`t→∞` 需要 `L/2` 够——本格点不够，代价逐项

1. **运动学**：`L=2 ⇒ t_max=L/2=1`，**只有一个非零时间分离**。`E_eff` 序列长度 1 ⇒ 无收敛判据、无单调性可核、无法外推 `t→∞`（§2 的夹逼上界 `E0+ε+(1/t)log(1/q_ε)` 里 `1/t` 项完全不可控）。
2. **`t=L/2` 是环绕最脏点**：周期边界下 `C_meas(t)=C(t)+C(L−t)`，`t=L/2` 时双向相加 ⇒ `E_eff^meas = E_eff^true − (log2)/t`。`t=1` 的偏置 `=0.693`，占 `2.19` 的 **32%**。
3. **有限 `t` 偏差的量级**：偏差 `≈(Λ★−m₁)e^{−(Λ★−m₁)t}`（`e^{−Δt}` 型），而隔离间隙 `Λ★−m₁≈1.5m₁`（`BS-THRESHOLD` 引 `PROOF-ISOLATION §4.4`）。`m₁≈2.2`（格点单位）、`t=1` ⇒ 偏差 `O(1)`，**不是百分级**。要 1% 需 `t≳4–5` ⇒ `L≥8–10`（且同一个 `a`）。
4. **体积极限不是免费的**：`L=2` 的 `2.191` 是 `m₁(L=2)`，被有限体积推高；真隙要 `L→∞` 且 `a→0` 的 `E_eff`，本文件一个都没做。**因此 `2.191` 连"物理 `0⁺⁺` 质量"都不是**，只是 `L=2` 的 `E_eff(1)`。

**结论**：即使把方向问题搁置，`L=2` 也给不出 `t→∞`；而方向问题不搁置，`E_eff` 本来就不该给下界。
