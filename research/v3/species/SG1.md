## §2 `G = s₁ − F` 的具体形式：**它是恒等式，不是公式**

`NS2-0 [T]`：若 `F(τ_aν)=F(ν)+a` 且 `F ≤ s₁`，则 `G := s₁ − F` 满足 `G(τ_aν)=G(ν)`、`G ≥ 0`，且 `F = s₁ − G`。
**这条定理的信息量 = 0**：给定任意 `G1-不变` 的 `G ≥ 0`，`F := s₁ − G` 自动满足两条前提。⇒ `(F,G)` 不是被"造"出来的，是被 `(s₁, G)` 参数化的。

于是"`G` 的具体形式"只有一个真问题：**存在不存在 `F`，同时 (i) 协变、(ii) `F ≤ s₁`、(2) 不经谱可算？**
机检（`sg1_G.log` 段 (1)）给出候选分类：

| 候选 `F`（全部"由 `S_W` 直接算出"） | `F(τ_aν) − F(ν)` @ `a=0.1/0.5/1/2` | (i) | (ii) `F ≤ s₁` |
|---|---|---|---|
| `F = s₁`（靶本身） | `0.1 / 0.5 / 1 / 2` | **OK** | 等式 |
| `F = mean = ∫λ dν / ∫dν` | `0.1 / 0.5 / 1 / 2` | **OK** | **✗**：`mean − s₁ = 0.5 > 0` 恒成立（`B05:141–143` NG-3） |
| `F = Var` | `0 / 0 / 0 / 0` | ✗ | 模型相关 |
| `F = f₁²` | `0 / 0 / 0 / 0` | ✗ | 量纲不同，无定义 |
| `F = m₂` | `0.11 / 0.75 / 2 / 6` | ✗ | ✗ |
| `F ≡ 0` | `0 / 0 / 0 / 0` | ✗ | ✓（但空洞） |

⇒ **协变集合 = `{s₁, mean}`；`mean` 在 (ii) 的错侧。二者都不是"造出来的 `G`"。**

### 定理 SG1-1 `[T]`：`(i) ∧ (ii) ∧ 有限矩可算 = ∅`

*证（三行，机检见 `sg1_G.log` 段 (3)(3b)）.* 设 `F` 对 `ν` 的有限个矩连续。取原子族
`ν_ε^{(a)} = (ε/2λ)δ_ε + (1−ε/2λ)δ_a`。`ε→0` 时矩向量收敛到 `δ_a` 的矩，而 `s₁(ν_ε^{(a)}) = ε → 0`。
(ii) 要求 `F(ν_ε^{(a)}) ≤ ε ⇒ F(δ_a) ≤ 0`；(i) 在原子族上要求 `F(δ_a) = F(δ_0) + a`。
⇒ `F(δ_0) + a ≤ 0` 对一切 `a > 0` ⇒ 矛盾。∎

机检：`a = 0.5/1/2/5`，`ε = 1e-6` 时矩偏离 `2.5e−7…2.5e−6`、`(ii)` 只能给 `F ≤ 1e−6`、`(i)` 要求 `F = a` ⇒ 四行全部 `consistent? NO`。

**推论 `[T]`（二分法）**：逃出 SG1-1 只有一条路——放弃有限矩，用**全矩序列**。而全矩序列在紧支撑下唯一确定 `ν` ⇒ 唯一可及的 `(i)+(ii)` 对象就是 `s₁` 本身 ⇒ `G ≡ 0` ⇒ 签名 `(0,0,0,undef)` ⇒ 过 4/4 ⇒ 落回 `N09-1`。
**⇒ "把 `G` 造出来"与"把 `m` 算出来"是同一件事。**

## §4 判：签名是 `(0, +, ≠0, undef)` 吗？

**不是（在"非空洞"的意义上不是）。**

1. **非空洞候选**（`G″ / Δ_dyn / Var / f₁²` 任一）：M6 上 `G = 1 − 2 = −1 < 0` ⇒ **P1 的第一条 `G ≥ 0` 直接失败**。
   签名实际是 `(0, +, −1, undef)`：第三格"≠0"虽然满足，但它是**负的**，而 `(0,+,≠0,undef)` 的第三格在 NS2 里指的是"`G(M6)=ω>0`"——`−1` 不是它。
2. **空洞候选 `F ≡ 0`**：签名确实是 `(0,+,≠0,undef)`，但 `G = s₁` ⇒ `G` 的全部信息 = `m` 的全部信息（`NS2-1` 的"退化成位置本身"）⇒ **循环**，且 `F` 的 (6)（`F ≥ c₀`）无从谈起（`F ≡ 0`）。
3. **`(i)` 把非空洞候选全灭**：`G″/Var/f₁²` 是 `G1-不变`，故 `G(τ_aν) = G(ν) + a` ⇒ 规格要求的 `G(τ_aν)=G(ν)` **失败**（§2 表）。唯一协变的 `mean` 在 `(ii)` 的错侧。
4. **`f₁²` 连量纲都不对**：`f₁²` 是无量纲权重，`s₁` 是能量 ⇒ `F ≤ s₁` 对 `f₁²` 无定义（`NS2.md:190` L3 的同类警告）。

## §5 判死线逐字

### (a) **不成立。** 不是"第一个逃出 `N09-1` 的对象"

`(0,+,≠0,undef)` 只在 `F ≡ 0` 上出现，而那里 `G = s₁`：`G` 不是"可算协变项 + 非负形状缺陷"里的缺陷，它就是位置。**这是 `NS2-1` 已经预告的退化**，不是逃逸。

### (b) **触发 ⇒ 改判 (b)（退化）。明说。**

`G` 只能从五类里取：`G″`（M6 给 `−1`）、`Δ_dyn`（M6 给 `−1`，`∀v` 读法给 `+1` 但 `(i)` 失败）、`Var`/`f₁²`（`(i)` 失败）、`H1`（`B02-TOOLS:137`：均匀 `h>0 ⟺ H1`）。
**更强的理由（定理 SG1-1）**：任何"由 `S_W` 直接算出"的 `F` 都是有限矩的函数，而有限矩 + `(i)` + `(ii)` 三者互斥 ⇒ **五类之外没有位置**。这不是"没试过"，是一条 `[T]` 级的类内 no-go。

### (c) **对唯一存活项也触发。明说。**

存活的只有两个：(1) `F ≡ 0` ⇒ `G = s₁`；(2) 全矩极限 ⇒ 仍是 `s₁`。二者都把 `G` 化成"位置本身"，而**位置本身的协变写法正是 SSF/Krein–Birman**：`tr(f(H) − f(H₀)) = ∫f′ξ`，`ξ_{H+a}(λ) = ξ_H(λ−a)`（`NS2.md:116` 逐字："**✓ 正是 G1-协变**"，"✓：`ξ≡0` 于 `(−∞,c)` ⇒ 投影相同 ⇒ 底被无损搬过"）。
⇒ `G = s₁ − F` 在唯一可行读法下**就是** `tr(f(H)−f(H₀))` 形态的第 3 类 ⇒ **撞搬运（19 条 0/19）**。
