## 1 · 匹配式（显式，带引文）

**一级（耦合）** [2] §2.1（标号 `eq:alpharel`、`eq:Zg1`）：

```
g_MSbar(μ) = { 1 + Z^(1)(μa, λ₀) g₀² + O(g₀⁴) }^(−1/2) · g₀ ,   λ₀ = 1 (Feynman 规范)
Z^(1)(μa, λ₀)|_{λ₀=1} = b₀ ln(a²μ²) + l₀
⇔  1/g²_MSbar(μ) = 1/g²₀ + 2b₀ ln(aμ) + l₀ + O(g₀²)
```

`b₀ = 11N/(48π²)`（`n_f = 0`）——与 A8 的归一逐位相同（[2] 表 `tab:coeffs`：`0.0696583`(N=3)、`0.0464389`(N=2)）。

**二级（Λ 比）** [2] §2.1（紧跟 `eq:Zg1` 的那一行）：

```
Λ_lat / Λ_MSbar = exp[ l₀ / (2b₀) ]      ⇔      Λ_MSbar / Λ_lat = exp[ −l₀ / (2b₀) ]
```

**显式指数**（`l₀ ≡ t₁ ≡ c₁`，一级有限常数；`C₂(F)`、`C₂(A)` 为基本/伴随 Casimir）[2] §2.1（标号 `eq:l0`）：

```
l₀ = (1/(8π²)) · [ −2π² C₂(F) − 3.54958342046 C₂(A) + 1.057389936 T_R n_f ]

n_f = 0, C₂(F) = (N²−1)/(2N), C₂(A) = N, 2b₀ = 11N/(24π²)  ⇒
                                                                    ┌ 代数量 [C] ┐
−l₀/(2b₀) = (3/11) · [ π² (1 − 1/N²) + 3.54958342046 ]
           = 3.659779 − 2.692365/N²
```

这个闭式与 [2] 的 `eq:Nscal`（`l₀/(2b₀) ≃ −3.65978 (1 − 0.735484/N²)`）**逐项相同** —— 代数自洽 [T]。`N→∞` 时指数 `3.65978` ⇒ `Λ_MS/Λ_lat = 38.9`（只作极限说明，**不用**）。

注意指数里**没有 `b₁`**：`b₁` 只进 Λ 的定义 `(b₀g²)^{−b₁/(2b₀²)}`（`b₁/(2b₀²) = 51/121`，A8 已核），不进匹配常数。A8 §1 第 6 步担心的那个 `½`（`b₁/(2b₀²)` vs `b₁/b₀²`）属于 Λ 的定义，与匹配常数无关；把 `l₀/(2b₀)` 写成 `l₀/b₀` 才是这里的同款错。

## 3 · `δ(1/g²)` 是 `0.468`，不是 `0.894`

A8 §4 的表观需求是"把 `613` 拉回 `1` 需要 `δ = 0.894`"。真实的 scheme 常数只有 `0.468`：

```
ln(m/Λ_MSbar) = ln(m/Λ_bare) − (−l₀)/(2b₀)
612.5 → 612.5 / 28.809 = 21.26          （不是 1）
差值：0.894 − 0.468 = 0.426  ⇒  exp(0.426/0.13932) = 21.3 ✓（同一件事的两种说法）
```

也就是说：**A8 把"整个 613 都是 scheme 假象"当成了前提，实际上 scheme 只解释了 `28.8×`，剩下的 `21×` 是物理的 `c`。** 这是本次唯一需要修的概念错误，且它把结论从"`c` 定不出来"改成"`c` 有数值"。

## 5 · 一致性检查

1. **SU(3) 两点仍一致 [C]：** 两点除同一个 `28.809`，差与 `σ` 同步缩放：`3.36 ± 4.75 = 0.708σ`（A8 原值 `0.71σ`）。归一无关的那个检验（`Λa` 比 = 两圈预言的 `a(6.30)/a(6.00) = 0.713`）本来就不受影响。
2. **绝对值也自洽 [C]：** `aΛ_MS = 28.809 × 1.7518e−3 = 5.0468e−2`（`β=6.00`）、`28.809 × 1.2489e−3 = 3.5980e−2`（`β=6.30`）；配 `a⁻¹ = 2.91 GeV` 与两圈 `a(6.3)/a(6.0) = 0.713 ⇒ 4.081 GeV`，两点都给 **`Λ_MS^{(0)} = 146.9 / 146.8 MeV`**。对照 [5] 的 `238 ± 19 MeV`：`0.62×`，即偏低 `1.6×`。这正是 [2] §2.2 记录的**二圈渐近标度在 `β ∈ [5.8,6.2]` 上 30–50% 的偏差** —— 量级对上，且方向对（两圈给 `Λ` 偏小）。**不是 scheme 错，是二圈截断错** [C]。
3. **落在 `m_{0⁺⁺}/Λ_MS ≈ 8–18` 吗？** 主口径 `21.3 / 24.6 / 23.7` **超出上界 1.2–1.4×**（用 `Λ_MS=0.147`、`m=1.71 GeV` 直算则是 `11.6`，**在带内**）。差别全部来自 `m`：语料的 `m a = 1.073` 对应 `3.12 GeV`，是物理 `0⁺⁺` 的 `1.8×`。SU(2) 的另两个质量估计（`16.0`、`14.6`）也在带内。⇒ **带内/带边取决于用哪个质量，与 scheme 无关** [M]。
4. **`c` 的最终读数 [C]：** `c = 21.3 (6.00) / 24.6 (6.30) / 23.7 (SU(2))`，即 `c = O(20)`；口径 (B) 给 `O(16–18)`、(C) 给 `O(12)`。**`c` 是纯数，精度受限于二圈截断（~30%）与 `a⁻¹` 外锚，不受 scheme 限制。**

## 6 · 对 A8 的两处订正（`[C]`）

1. **A8 §1 的"精确二圈闭式 vs 简单式差 `−27.1%`"复算不成立**：`[1+(b₁/b₀)g²]^{b₁/(2b₀²)}` 在 `g²=1, N=3` 给 `1.0243`，即 `+2.4%`，不是 `−27%`。故本文件不采用那个 30% 带宽，改用 `1.339` 的归一口径差 + [2] 的 30–50% 标度偏差作为系统带。
2. **A8 §5.3 的"补上归一后 `m/Λ_phys ≈ 13–16`"** 走的是"物理 `Λ` 反推比值 ≃ 40–47×"的路（即已含口径 B 的 `1.339`）；用引文比值直算是 `28.8×`（A）或 `38.6×`（B）。`13–16` 恰落在两口径之间，量级不错，但**它不是从引文比值算出的**，本文件以 §4 的表为准。

## 7 · 未取数 / 未核（`[NG]`）

- 只覆盖 `n_f = 0` 的 **Wilson（单 plaquette）** 作用量。clover / Lüscher–Weisz / SF 的 `l₀` 不在本文（`Λ_SF/Λ_MS = 0.48811(1)` 见 [1]，未用）。
- `l₀` 里的两个三位常数 `3.54958342046`、`1.057389936` 直接取自 [2] 的解析式；我**没有**独立重算那两个格点积分（其精度由 [1] 的 `Z₀/Z₁` 400 位表背书，未逐位复核）。
- SU(2) 只有一点，**不能**做标度性检验（A8 已指出：三个 `m` 估计共用同一个 `Λa`）。
- `a⁻¹(β=6.0) = 2.91 GeV` 是 A8 借 Necco–Sommer `r₀/a = 7.380` 的外锚，非本组直测；`Λ_MS = 147 MeV` 继承这个外锚的全部系统误差。
