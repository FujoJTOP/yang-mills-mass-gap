## §1 目标对象（必须严格用这些）

**三个命名不等式**（任一证出即闭合 gap；都在 `docs/paper-v2/ch13-machine.tex` §15.6）：

1. **(H1)** `Var_μ(⟨v,∇S⟩ | 0) ≤ E_μ[H_vv | 0] + W_full − δ`，对 `(L,a)` 一致、每个 `k→0` 粗模 `v`。
   等价：`Var_ν(φ) ≤ (1/λ)∫|∇φ|²`，`λ>0` 一致 ⟺ `m_eff²(k→0) ≥ λ` ⟺ `G″(0) ≥ λ` ⟺ `χ ≤ 1/λ`。
2. **(NA)** `Cov_μ(G, Φ′ | 0) ≤ 0`，对连续、frustrated（cos-sum Wilson）、非吸引的 `SU(N)` Haar×Wilson 测度。
   —— **唯一的 variance-free 面**，即 `X = −2Cov(G,Φ′) ≤ 0`。
3. **(TCI)** `⟨φ,Qφ⟩ + ⟨φ,𝕂φ⟩ − cF ≥ μ > 0`，∀ 单位 `φ ∈ ℋ₋`，逐点非微扰。

**四个谓词**（`research/v3/T6-BINDING-ADVERSARIAL.md`、`U6-BINDING-LOGIC.md`）：
`A: f₁²>0`（可见性）、`W: w₁ = f₁²/M₀ ≥ w₀`（权重）、`I: Λ★ = inf supp(ν − f₁²δ_{m₁²}) > m₁²`（隔离）、
`G: m₁²>0`（地板）。关系：`W ⇒ A`、`I ⇒ B_spec ⇒ A`、**`W ⊥ I`**；`W ∧ H1 ⇒ G`，`I ∧ (ρ² ≤ C²) ⇒ G`。
**载子 `q`** = 规范不变密度在固定物理尺度重整化的**总归一化零模** `q = V^{-1/2}Σ_x(O(x) − ⟨O⟩)`，
`Var(q) = χ_O = O(1)`（**不是** `1/V`；`1/V` 是均值归一化，记账假象，见 `T4-CARRIER.md`）。
**靶**：在 `0^{++}` Källén–Lehmann 测度上的原子 + 隔离，`χ ≤ 1/λ` 只是**天花板**。

**正确对象（v3 的核心修正，不许再退回去）**：`G″` 是**粗场条件化**的边缘曲率
`G″(v;a₀) = E_a[∂_v²V] − Var_a(∂_vV) = Δ_dyn + W_geo + X`，**必须条件化、必须含 `X`**。
`G″₀ = E[H] − Var(G) + W_geo = 2W_geo` 是**真的恒等式，但是影子对象**（`STAR2-CLASSIFICATION.md`）。

## §2 五条件规格（一个工具必须同时满足，`ch13-machine.tex`）

1. **非微扰**：在 `β≈2.5`（`g≈1.5`，无小参数）有效，不属于任何收敛展开。
2. **控号下界**：给 `m_eff²(k→0) ≥ λ > 0`（不是又一个上界）。
3. **非循环**：不得预设 gap / 阈值 / 隔离（Temple–Weinstein、`E₂`、BS 阈值全在此死）。
4. **非 SUSY 且败自由场**：**必须**在自由无质量场上失效（`f₁²=0`、`G″=0`）。这是酸测。
5. **均匀**：`(L,a)` 一致，且过 `a→0`。

## §3 酸测电池（每条候选必须逐条交结果）

| # | 测试 | 通过判据 |
|---|---|---|
| 1 | **自由场** | 自由无质量场（`f₁²=0`）上**必须失败/报零**。报正 ⇒ 伪正性 ⇒ vacuous |
| 2 | **薄原子** | 不许给"薄原子"（`w₁→0`、`χ = 1/λ` 带 `inf supp ν = ε→0`）发证书 |
| 3 | **深双井** | 无 barrier-uniform `λ`；`W∧I` 但 `λ₁→0`、`χ→∞`、`ρ²→∞` |
| 4 | **归一化/真空性** | 总归一化 vs 均值归一化（`Var(q)=χ` vs `Var(q̄)=χ/V`）不许混 |
| 5 | **量纲** | `G″_a = a² m_phys²`；不许拿 equipartition 的 `E[f²]≈2` 冒充 `a²Δ₀²` |

**附加**：β=0 Haar 上 `χ=0.2688` 但 `f₁²=0` ⇒ **曲率地板不是原子**。任何"`G″>0` 就算证到"的
路线当场死（`R5-EXACT-ANCHORS.md`）。

## §5 元定理：搜索的真正瓶颈（必须处理，否则白干）

`research/unconditional/SPECIES-EXISTENCE.md`：

- 形式化类 `ℭ` 用四条公理 `F1–F4`；其中
  - **[NG]** 可计算子类 `ℭ^comp = ℭ_uniform ∩ {F4}` = **空**：`F3 ∧ F4 = ∅`，
    证据是四种数据模（**有限矩 / 不变量 / 有限-t 解析 / 定量极值**）全都"可计算 ⇒ 地板盲"；
  - **[T]** 全类 `ℭ_uniform` 里"存在证书" **⟺ gap 本身**（唯一够到界的证书就是边原子自己）；
  - **[T-shape]** 只存在**次均匀**（vNW 逐点隔离）或**次 regime**（P3，`β<1/48`）的成员。

**因此新物种必须满足下面之一**（这是本轮的全部指望）：

- **(α) 第五数据模**：造出一种**可计算**且**地板敏感**（看得见 `inf supp ν`）的**新数据类型**，
  它不属于上述四种。需要：精确类型定义 + 为何不用 `inf supp` 就能读出边 + 反例排除。
- **(β) 新的等价坐标**：给出一个**新的数学对象 `𝔉_object`**，其正性 ⟺ gap，但**带上新机器**
  （新恒等式 / 新单调量 / 新锥 / 新指标 / 新不动点），且该机器**不是**已死类的一个实例。
  必须写清：这台机器在哪一步**严格强于** H1，而不是 H1 改名。
- **(γ) 决定性否证**：证明某条在册逃生口**是假的**（例如 (NA) 在可解模型上不成立），
  从而把地图收紧。这也算找到了东西——但必须标明是 **no-go**，不是物种。

**禁止**：只写"应造一台机器"、"需要新想法"而不给定义/不等式/构造。没有公式的候选视为未交卷。
