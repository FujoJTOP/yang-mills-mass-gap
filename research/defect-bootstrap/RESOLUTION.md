# Resolution: the correct object, and what is actually missing

> CPB-attack probe (resolution). Verdict: group `SO(2,1)×SO(3)` (codim-3); the bulk–defect
> block has **3 cross-ratios** and is **genuinely missing**; the available hypergeometric
> blocks are **defect-4-point** blocks (a different object); the non-SUSY pure-gauge `Z_N`
> setup is **not built**.

## (a) Group

A line in 4D is codim-3; preserved group **`SO(2,1)×SO(3)`** (= `SL(2,ℝ)×SO(3)`). Confirmed:
2501.06900 states "`SL(2,ℝ)×SO(d−1)`" (`d=4` → `SL(2,ℝ)×SO(3)`); 1806.01862 states
"`SO(2,1)×SO(3)`". The codim-3 subagents are right; the "`SO(2,1)×SO(2)`" is the **3D
codim-2** case (2208.11715).

## (b) Cross-ratios

The **bulk two-point function in the defect background has 3** cross-ratios: 8 coordinates
minus a 5-dimensional generic orbit (`SL(2,ℝ)` on two points: `3−1=2`; `SO(3)` on two vectors:
`3`). The single `ξ` used in the available papers is the **defect 4-point** (four points on the
line), a different observable.

## (c) Blocks

The closed-form hypergeometric blocks that ARE available (2501.06900 App. B:
`(t/(1+t))^Δ ₂F₁`; 2208.11715 eq. 2.17; 1806.01862) are **defect-4-point** blocks (one
cross-ratio). **Bulk–defect blocks (3 cross-ratios) are NOT computed in any of the three.** So
"blocks available" refers to a different object; the bulk–defect block is genuinely missing.

## (d) Non-SUSY pure-gauge `Z_N`

**Not set up.** 2501.06900 covers `O(N)` (non-SUSY) and SUSY gauge (`N=4`, ABJM); 2208.11715 is
`O(2)` in 3D. No `Z_N`, no pure gauge appears.

## Verdict

The codim-3 subagents are substantively right (group, 3 cross-ratios, missing bulk–defect
block). The SUSY-adapt subagent was wrong on the group and **conflated the defect-4-point block
(available) with the bulk–defect block (missing)**. Both the `Z_N` setup **and** the
3-cross-ratio bulk–defect block are missing.

**Possible simplification:** one *could* bootstrap the **defect 4-point** (blocks available)
rather than the bulk–defect 3-cross-ratio object — but the gap certificate wants a **bulk**
operator (`tr F²`), so the bulk–defect block is the relevant object. The defect 4-point's
crossing does contain a bulk channel, so it may constrain the bulk spectrum — but that is a
weaker/indirect handle.

Sources: arXiv:2501.06900; arXiv:2208.11715; arXiv:1806.01862.
