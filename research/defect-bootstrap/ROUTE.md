# Route: Defect Bootstrap with 1-Form Symmetry (DB)

> 2026-11-23 · 自创路线。目标：绕开交叉点，用**缺陷共形 bootstrap** 证 (iii)。
> 这是十路扫描里没有的，而且换了一种数学。

## 0. 一句话

**1-形式对称性不作用在局域算符上（`tr F²` 中性），它作用在线缺陷（Wilson/'t Hooft）上。所以局域 bootstrap 看不见它——要对含 `Z_N`-荷线缺陷的谱做水平 bootstrap，才能排除"相互作用的纯规范 4D CFT"。**

## 1. 逻辑骨架

| 步 | 内容 | 状态 |
|---|---|---|
| (i) | 无隙 IR ⟹ 4D CFT | 标准 |
| (ii) | CFT 唯一真空 ⟹ `Z_N` 1-形式**自动未破缺** | 成立；**不消费面积律**（2408.14532；2310.03786） |
| (iii) | 纯规范+无物质+无 SUSY 的 4D CFT ⟹ 自由 | **DB 要证的目标** |
| (iv) | IN-7 非高斯 ⟹ 有隙 | 项目输入 |

## 2. 为什么是新的

- 不是十路里的任何一条；
- 与 ESI 的区别：ESI 是**解析枚举**（4D 6-点 31,990 个结构，作者自己没做完），DB 是**数值 + 系统**；
- 1-形式对称性在局域 bootstrap 里**不可见**，必须走**缺陷**——这是 2023 起的前沿（line defect bootstrap / symmetry TQFT），成熟度低但工具在长。

## 3. 第一检验（具体）

写一个假想纯规范 CFT 里 **`Z_N`-荷 Wilson 线的两点 crossing 方程**：

```
Z_N-荷 线两点函数 + crossing + 幺正性 + θ-异常流入
```

加 θ-异常，跑数值 bootstrap——**看相互作用解是否被排除**。

## 4. 死亡判据

- 若存在一族**相互作用**解存活 ⟹ (iii) 假，或 DB 证不了；
- 若缺陷 bootstrap 只给**界**、不给**唯一性** ⟹ 路线无法"证明"，只能"强证据"。

## 5. 诚实边界

- 这是**提案**，不是证明；
- 缺陷 bootstrap **不成熟**，4D 线缺陷的共形块很难；
- 很可能和 ESI 一样卡在"非阿贝尔线缺陷到底怎么设"。

## 6. 已知相邻工具（子代理去核）

- 缺陷 / 线缺陷共形 bootstrap（2023–2025）；
- 1-形式对称性的 't Hooft 异常与对称 TQFT（GKSW；Cordova–Tachikawa；symmetry TQFT）；
- 数值 bootstrap 的 SDPB 能否处理线缺陷。
