# Probe: single-level inverse Monte Carlo (IMC) for the b=2 blocked SU(3) effective action

> 2026-11-23 · decision probe for `research/new-paths` NP-1 · code and data in
> `research/probe-imc/` · does not touch any `gluing` R number, `bianchi` BL
> number or `handoff` proposition.

## 0. 判定 — read this first

三层结论。**第一层是"机器没问题"，第二层是"任务判据是假阳性"，第三层是
"对 κ_c 不行、对 c₀ 行但用不着 IMC"。**

### 第一层：单级 IMC 本身可行

3 耦合环基拟设 $\{$Wilson, 6-link, 8-link$\}$ 在 b=2、β=2.6 上**收敛**
（Newton/Swendsen 迭代 7 次；协方差条件数 2.2，不是共线性不适定），
残差 1–11%。**留出的**阻塞层量——全部 plaquette–plaquette 与 link–link
连通关联、$c_6'$、$R_4$——与实测**在 1σ 内一致**（唯一例外 CL$_2$ 3.2σ，
两者都只有 2×10⁻⁴）。阻塞 plaquette **实部分布**（均值、方差、偏度、尾部
$f(<\theta)$）复现到 **≲1%**。

### 第二层：任务的字面判据会给出假阳性

* $c_3\equiv3\langle P\rangle$ 是恒等式（§9.2 可验：3×0.17369=0.52107），
  且 $\langle P\rangle$ 正是拟合算符 → "复现 ⟨P⟩、c₃ 到几个百分点"**按构造**
  成立，不是检验。
* 更关键：复现上面那一切的**不是 3 个耦合，而是一个 Wilson 耦合**。
  单独 $\lambda_P=0.549$ 的模型就把 $\langle P\rangle$、$\langle P^2\rangle$、
  偏度、$f(<0)$、$c_0$ 全部复现到 ≲1%（§6.1）。6-link/8-link 两项只用来
  匹配它们自己那个 $10^{-3}$ 量级的环密度。
* 而 2×2（8-link）环密度的信号只有 **1.0σ**（β=2.6）/ **−0.4σ**（β=3.0，
  L=8、3000 组态）；换更光滑的阻塞（$w=0.5$）仍只有 0.5σ（§8.2）。
  这个耦合**本质不可辨识**——它的数值由拟合的偶然性决定，不由数据决定。

### 第三层：对 κ_c 不可行；对 c₀ 可行但不需要 IMC

* 3 耦合拟设唯一显著失败的量是 $c_8'=\langle|\mathrm{tr}U|^2\rangle-1$：
  **−40%（6σ）**。$c_8$ 的主体是 $\mathrm{Im\,tr}$ 的涨落，任何**实**
  character 的短程作用量都不产生它。$\kappa_c$ 依赖完整 character 结构
  （含虚部与高阶表示），所以拟合出的作用量**不足以支撑 $\kappa_c$**。
* 反过来，若 $c_0$ 只由实部缺陷尾部定义，则**单参数** $\lambda_P$ 已足够：
  模型 $c_0=-\ln f(<0)=0.681$，实测 0.678（0.4%；§6.3）。

### 给决策树的话

按字面判据"单级 IMC 通过"→ 会放行 3–6 个月的多级 IMC。**不建议**。本探针表明
这条判据在 b=2 上无法区分"有用"和"平凡"。真正应该设的门槛是：
**(i) $c_8'$（或任何含 $\mathrm{Im\,tr}$ 的 character 量）能否复现；
(ii) 8-link 耦合是否有 ≥5σ 信号。** 按这两条，b=2、β=2.6/3.0 都**不通过**。

### 附带结论（对项目有用，独立于成败）

在 β=2.6–3.0，b=2 阻塞后的理论是**深度强耦合**的——阻塞 plaquette
⟨P′⟩ = 0.032，6-link 密度 0.0017，8-link 密度 1×10⁻⁴（对照：同样的阻塞在
β=6.0 给出 ⟨P′⟩ = 0.585）。原因不是阻塞方案不好，而是这些 β 下细格点间距
**已经大于关联长度**（STATUS：ξ/a ≲ 0.3），所以 2a×2a 的细格 Wilson 环本身
≈0（实测 W(2,2) = −0.005），阻塞只能把它升到 0.03。`c₀`/`κ_c` 所针对的有效
作用量，在这些 β 上是 β_eff ≈ 0.5 的强耦合展开——高阶环算符恰好落在数值
噪声附近，这是第二层那个 1σ 信号的来源。

### 1.2 b=2 链接阻塞（尺度 2，Teper/Swendsen 型）

对细格点链接 $U_\mu(x)$ 定义

$$V_\mu(y) = \mathcal P_{SU(3)}\Big[ U_\mu(2y)U_\mu(2y+\mu)
+ w\sum_{\nu\ne\mu}\big(B_1+B_2\big)\Big],$$

$B_1 = U_\nu(2y)U_\mu(2y+\nu)U_\mu(2y+\nu+\mu)U_\nu^\dagger(2y+2\mu)$，
$B_2 = U_\nu^\dagger(2y-\nu)U_\mu(2y-\nu)U_\mu(2y-\nu+\mu)U_\nu(2y-\nu+2\mu)$，
$\mathcal P_{SU(3)}$ = 极分解 + 均匀立方根相位（**不是** `su3.project_su3` 的
首行消相位——后者不是规范协变的，见 §1.4）。

主结果用等权 $w=1$；$w=0.5$ 的变体见 §8.2。

### 1.3 阻塞与观测量的验证（全部为代码级检查）

| 检查 | 结果 |
|---|---|
| $V$ 的规范协变：$V_\mu(y)\to g(2y)V_\mu g^\dagger(2y+2\mu)$ | 5×10⁻¹⁵ |
| 纯规范位形 → 阻塞 plaquette = 1 | 1.0000（精确）|
| $U=\mathbb 1$ → $V=\mathbb 1$ | 0 |
| 环乘积 unitary / det=1（P, 1×2, 2×2, 1×3） | ≤7×10⁻¹⁵ |
| 表驱动作用量与独立的 `blk` 循环求和一致 | 1×10⁻¹¹ |
| $\beta=6$ 对照：微观 ⟨P⟩=0.594 → 阻塞 ⟨P′⟩=0.585（L=8） | 阻塞近似保值（弱耦合应有的行为）|

### 1.4 两个发现的坑（可复用）

* `su3.project_su3` 用 `U[...,0,:] *= conj(det)` 去掉 U(3) 的相位，**这不是
  规范协变的**（左乘 diag 会破坏 $g(x)$ 的作用）。必须用
  `project_su3_cuberoot`（全体乘 det^{-1/3}）。第一次规范协变性检查差了 O(1)，
  就是这里。
* 用 "straight + 6 staples" 等权求和阻塞时，7 条路径在强耦合下几乎互不相干，
  投影后的链接方向接近随机——这是物理（见 §2），不是代码错误；但要意识到
  $w$ 的选择会改变阻塞场的光滑度约 2 倍（§8.2）。

**读数**：

  同样代码在 β=6.0 给出 ⟨P′⟩=0.585。根本原因是 **a ≳ ξ**（STATUS：ξ/a ≲ 0.3），
  所以 2a 格点已经远在强耦合端。

这对项目的含义：NP-1 想反演的 `c₀`、`κ_c` 正是这个强耦合有效作用量的
polymer 系数。强耦合下 character/polymer 展开收敛得好，但**高阶环的耦合本身
小到测不出**（下一节）。

## 3. 有效作用量拟设与 IMC 算法

### 3.1 拟设

$$S_{\rm eff}[V] = \sum_{k\in\{P,R,S(,R3)\}} \lambda_k \sum_{\ell\in k}\big(1-\tfrac13\mathrm{Re\,tr}\,V_\ell\big),$$

$P$ = plaquette（4 链），$R$ = 1×2 矩形（6 链，两种取向），$S$ = 2×2 方块（8 链），
$R3$ = 1×3 矩形（8 链）。主拟设 $\{P,R,S\}$ 三个耦合；另做 $\{P,R\}$ 两耦合与
$\{P,R,S,R3\}$ 四耦合作稳定性检验。

### 3.2 Swendsen 逆蒙特卡洛

记 $S_i(V)=\sum_{\ell\in i}\tfrac13\mathrm{Re\,tr}V_\ell$（**和**，不是平均值），
则 $\partial\langle S_i\rangle/\partial\lambda_j = \mathrm{Cov}(S_i,S_j)$
（正号，因为 $S=\sum\lambda_k(1-T)$）。迭代

$$\lambda \leftarrow \lambda + \eta\,\mathrm{Cov}_{\lambda}^{-1}\big(\hat S - \langle S\rangle_\lambda\big),$$

$\hat S$ 来自阻塞系综，$\langle S\rangle_\lambda$ 来自模型抽样；$\eta=0.8$。

### 3.3 模型抽样器（新代码，`model.py`）

作用量对单条链非线性，热浴不适用，故用 **Metropolis + Haar SU(2) 子群提议**
（Cabibbo-Marinari 式，3 个子群顺序更新），局部 $\Delta S$ 由包含该链的全部
环精确给出。提议宽度可调（$w_p=1$ 为完全 Haar；弱耦合端用小宽度）。

验证：

* **局部 ΔS 与全作用量之差**：对 3 个环族、12 组随机 (link, 子群) 提议，
  核给出的 ΔS 与独立全作用量重算之差 < 10⁻⁹。
* **分布正确性**：只保留 P 项时模型就是 Wilson 理论。
  β=2.6, L=4: Metropolis ⟨P⟩=0.17385(51) vs 热浴 0.17325(49)（1σ 内）；
  β=6.0, L=4（宽度 0.2）: 0.5970 vs 0.5975。
* 这是本次全部结论依赖的两个前提，都是代码级硬检查。

**结论**：

* 协方差良态（cond ≈ 2），所以**不是共线性/数值不适定**——这一点要讲清楚，

  它对应的耦合只能给成 $|\lambda_S|\lesssim 0.002$。
* 6-link 可用（20–27σ）；plaquette 极好（300σ）。

### 5.2 character 基（强耦合下更自然的一组算符）

强耦合下有效作用量的自然展开是单 plaquette 的 character 展开

$\chi_3$ 270σ、$\chi_6$ 12.5σ、$\chi_8$ 27σ；协方差条件数 17.5，
$\delta\lambda=(0.0015,0.0005,0.0004)$。β=3.0 同样（312 / 19 / 37σ）。
与环基的 $\chi$-对应量（2×2 环 1σ）形成鲜明对比——**同样的数据，换到
character 基就可辨识**。

| **阻塞系综实测** | **0.03151** | **0.06175** | **0.609** | **0.5078** | **0.678** | **0.01308** |

三耦合完整拟合（$\lambda=0.549,0.010,0.006$）给出：均值 +1.0%、Var −0.2%、
$f(<0)$ −0.2%、$c_0$ 0.679 vs 0.678 —— 与单耦合几乎**没有区别**。所以：

* **实部分布（也即 $c_0$ 的载体）一个耦合就够**，复现到 ≲1%；
* $c_8'$ 两者都低 30–40%（P-only 0.0091、三耦合 0.008–0.011 vs 实测 0.0131），
  但 $c_8$ 的主体是 $\mathrm{Im\,tr}$ 的涨落：
  $\langle|\mathrm{tr}|^2\rangle = 9\langle P^2\rangle
  + \langle(\mathrm{Im\,tr})^2\rangle$，实部约占 0.555，$c_8$ 的 0.004 差异
  只对应 $\langle(\mathrm{Im\,tr})^2\rangle$ 的 **~1%** 差。也就是说，
  "分布更宽"发生在**虚部**，不在实部——而这正是任何**实** character 短程
  作用量都不产生的方向。

**注意误差**：$c_8$ 在模型侧的统计误差需要小心。3000-sweep 的验证给出
$\pm0.0007$，但 $c_8$ 的链条自相关可能被低估（§8.4 用 10⁴ sweeps 复核）。
无论如何，**$\langle|\mathrm{tr}|^2\rangle$ 的绝对差只有 ~0.4%**——这是一个
"相对差大、绝对差小"的量，它对 $\kappa_c$ 的影响取决于 character 展开里
它如何进入，本探针不做这个映射。

**与项目的关系**：$c_0$（实部缺陷尾部）对 3–6 耦合 IMC 不敏感——单参数就够；
但 $\kappa_c$ 依赖完整的 character 结构（含 $\mathrm{Im\,tr}$ 与高阶表示），
而那里拟设差 40%（相对）。所以 IMC 的拟合作用量可以支撑 $c_0$ 型量，
**不能支撑 $\kappa_c$**。

## 7. 任务判据的两个问题

**(a) $c_3 \equiv 3\langle P\rangle$。** 由定义 $c_3=\langle\mathrm{Re\,tr}\,U_p
\rangle=3\langle\frac13\mathrm{Re\,tr}\,U_p\rangle=3\langle P\rangle$。
§9.2 的数据验证了这一点（β=2.6, L=6: 3×0.17369=0.52107）。
所以"复现 ⟨P⟩ 与 c₃"是**一个**条件，不是两个；而 plaquette 密度正是拟设里
的 $P$ 项算符，拟合会**按构造**把它匹配上。它不是一个检验。

**(b) 微观系数不是阻塞链接的泛函。** §9.2 的 $c_3,c_6,c_8,c_{10}$ 是**细格点
单个 plaquette** 的 character 系数。阻塞有效作用量作用在 $V$ 上；细格点的
$U_p$ 不是 $V$ 的局部函数，它的分布也不可能由 $S_{\rm eff}[V]$ 决定。所以
"用拟合出的作用量复现 §9.2 的数"在定义上做不到，与 IMC 好坏无关。

**有意义的替代判据**（本报告采用）：拟合出的 $S_{\rm eff}$ 能否复现**阻塞层**
的 ⟨P′⟩（= 细格点 2a×2a 环的抹平版本）、$c_6',c_8',c_{10}'$、$R_4$ 与关联函数
到几个百分点，且拟合残差 ≪ 信号。

### 8.1 有限体积 $L'=3$ vs $L'=4$

## 9. 结论与成本

### 9.0 按任务判据的逐条对照

| 判据 | 字面结果 |
|---|---|
| 残差 ≪ 信号 | ⟨P⟩：残差 1.0%（信号 100%）✓；6-link：11.4%（信号 100%）✓；8-link：在 1σ 内（信号 ≈0）— 无意义 |
| 复现 ⟨P⟩ 到几个百分点 | **+1.0%** ✓ |
| 复现 $c_3$ 到几个百分点 | **+1.0%** ✓（但 $c_3\equiv3\langle P\rangle$，同一个数）|
| 拟合不适定？ | 否：协方差条件数 2.2，Newton 迭代收敛 |
| 残差 > 信号？ | 否 |

→ **按字面判据，结论是"可行（PASS）"。** 但本报告主张这个 PASS **不可信**，
因为它几乎全是构造性的：

1. $c_3\equiv3\langle P\rangle$，而 ⟨P⟩ 是拟合算符；
2. **单** Wilson 耦合 λ_P=0.549 就达到同样的复现（§6.1 表），3 耦合没有增加
   任何可测的东西；
3. 8-link 耦合的信号是 1.0σ / −0.4σ——它的数值不由数据决定；
4. 真正有区分力的量（$c_8'$，含 $\mathrm{Im\,tr}$）失败 **40%（6.2σ）**。

### 9.2 建议（给父会话）

1. **不要把"单级 IMC 通过"当成放行多级 IMC 的门槛**——在 b=2、β=2.6/3.0 上
   它会给出假阳性。多级 IMC（3–6 个月）**不建议启动**。
2. 若要保留一条 IMC 判据，用下面三条替代（本组 β 全部不过）：
   (i) $c_8'$ 或任何含 $\mathrm{Im\,tr}$ 的 character 量复现到几个百分点；
   (ii) 8-link（及更高）耦合有 ≥5σ 信号；
   (iii) 在一个**未参与拟合**的新 β 上，预测的 ⟨P′⟩ 与 $c_0$ 正确。
3. **对 $c_0$**：不需要 IMC。单参数 λ_P（↔⟨P⟩）已把实部分布复现到 ≲1%，
   而 $c_0=-\ln f$ 在该分布上以 0.4% 精度复现。若 $c_0$ 的定义能落到实部
   尾部，其数值成本 ≈ 一次 ⟨P⟩ 测量。
4. **对 $\kappa_c$**：本探针的数据不支持任何数值提取。要么回到解析（BL-6），
   要么改用 character 基把 $\mathrm{Im\,tr}$ 结构拟合进去——那时 $c_8$ 变成
   拟合算符，就需要别的留出量（例如 $c_{10}$、连续关联）来验证。
5. 附带：b=2 阻塞在 β=2.6–3.0 上是**深度强耦合**（β_eff≈0.5）。如果项目真正
   关心的是"物理尺度"的有效作用量，用一个已经远在强耦合端的阻塞格点去谈
   Bianchi/character 结构，本身就要先论证这个尺度是对的。

### 9.1 计算成本（本机实测，单条链）

| 步骤 | 成本 |
|---|---|
| 细格点系综 L=8，3000 组态 | 4 min（16 线程热浴） |
| 细格点系综 L=6，4000 组态 | 2 min |
| 模型抽样 L′=4，三环族 | 67 ms/sweep（单线程 Numba） |
| 模型抽样 L′=3，三环族 | 15 ms/sweep |

N×25 ≈ 7.5×10⁴ 组态（L=8 约 1.5 h 生成），再加上同比例的模型抽样。
注意：统计量**不能**修复第 5.1 节的 c₈ 型模型不足（那是拟设的问题，不是噪声）。

### 9.2 与 3–6 个月多级 IMC 的关系

`new-paths` 的决策树把"单级 IMC 通过"作为进入多级（3–6 个月）的门槛。按
本报告的结果，单级在**环基**上不通过，所以多级不应启动。character 基若通过
（见 §5.2），正确的下一步也不是多级 IMC，而是**单级 + character 基 + 多算符
的受控截断研究**（先看截断误差能否压到百分点）。

## 10. 对 `c₀`/`κ_c` 的含义

即使拟合在阻塞层"成功"，从 $S_{\rm eff}$ 的少数几个耦合去算 `c₀`、`κ_c`
还有一个放大问题：polymer 权重 $w_q(C)\sim e^{-c_0 q|C|}$ 对作用量系数是**指数
敏感**的，而 6-link 耦合在数据上只能定到 ~10%（数据极限 2%，本次拟合 ~10%），
8-link 完全定不了。$c_0$ 的不确定度至少是耦合相对误差的量级（O(10%)–O(1)），
`κ_c` 的误差则要穿过 BL-6 的 $\kappa_c\approx1$ 平台——以现有数据精度无法
区分 0.8/1.0。

**因此 NP-1 的数值路线在本组 β 上应判死**；如果还要继续，必须换靶子：

* 换到**弱耦合**（β ≳ 6）去验证/标定 IMC 本身（本报告 §8.3 已经开了这个头），
  但那不是 `c₀/κ_c` 所在的物理点；
* 或者放弃"从 MC 反演 $c₀$"，回到 `new-paths` 的 NP-3（常数打磨）与 NP-7
  （center vortex，且已被判为 sector-mismatched）。
