# OS3：反射正性在 block-spin RG 与连续极限下的存活

> 2026-11-22 · 范围：纯 Yang–Mills₄、Wilson 作用量、紧单群 G。
> 问题：细格点上的反射正性（reflection positivity, RP）是 Osterwalder–Seiler 定理，
> 但重整化群（RG）的 block-spin 变换**一般破坏 RP**。本文回答：
> （i）blocking kernel 要满足什么充分条件才保 RP；（ii）规范理论里这些条件能否满足、在哪一点上卡住；
> （iii）RP 是否活过整个 RG 流与连续极限；（iv）还剩下什么真障碍。

---

## 0. 结论摘要

1. **RP 不是 16 输入里那种"硬"输入。** 细格点 RP 是**无条件定理**（OS 1978 过链平面；Menotti–Pelissetto 1987 过格点平面），
   而且 RP 在两类操作下**自动封闭**：(a) 满足两个几何条件的 block-spin（定理 3.1）；
   (b) 弱极限 / Schwinger 函数逐点收敛（定理 5.2）。因此只要 RG 按下面的设计搭，**每个尺度的 RP 都免费**，
   子列连续极限也满足 OS3。这把 OS3 从"输入"降为"设计约束"。

2. **保 RP 的充分条件只有两条（外加两条自动项）**：
   - **(B1) 等变性**：`F ∘ θ_fine = θ_coarse ∘ F`（blocking 与反射交换）；
   - **(B2) 半空间分离**：粗格点时间 `n₀ ≥ 0` 的粗变量只依赖细格点 `x₀ ≥ 0` 的链；
   - (B3) 细格点 RP（定理，见 §2）；(B4) 规范协变 ⟹ 规范不变性自动保持（§4.1）。
   证明只有五行（定理 3.1 的证明），**全部数学内容在几何**，不在测度论。

3. **规范理论特有的困难精确地定位在 (B1) 上，且是"路径级"的。** 粗链是细链的 Wilson 线
   （沿路径的群乘积），非线性、非阿贝尔。于是：
   - 不存在"线性平均"（群不是向量空间）⟹ 不能用 φ⁴ 式的线性 RG；
   - 等变性变成**几何条件**：反射必须把选定的路径映到选定的路径（可能反向、取逆）；
   - 规范协变**强迫**粗格点 ⊂ 细格点（粗规范群 = 细规范群的限制），于是出现**奇偶性/对齐**问题。

4. **奇偶性定理（§4.3）**：
   - **Route A**：细格点用 OS 的**过链平面**（`θx₀ = −1−x₀`），block 边长 `L` 为**奇数**，粗格点平移到 `Ln + (L−1)/2`
     ⟹ (B1)(B2) 都成立 ⟹ 粗测度对**粗格点的过链平面** RP（正是转移矩阵要的那个平面）。
   - **Route B**：细格点用 Menotti–Pelissetto 的**过格点平面**（`θx₀ = −x₀`），block 对齐（任意 `L`，含偶数）
     ⟹ 粗测度对**粗格点的过格点平面** RP。
   - **偶数 L + 粗过链平面**：需要半整数平移（`s₀=(L−1)/2 ∈ ℤ+½`），粗链变成 staircase Wilson 线；
     等变性"应该"成立但我**没有逐路径验证**，列为 open（§8 O2）。

5. **朴素"平方论证"是错的，而错误恰好是规范困难的极小模型。** 见 §2.4：
   在 SP 上试图把 `⟨θF,F⟩` 写成 `∫ds e^{S₀(s)} |∫dU F e^{S₊}|²` 不成立，因为另一半给出的是 `conj(∫ F∘θ e^{S₊})`，
   与 `∫ F e^{S₊}` 不是同一对象。MP 用一个**幺正规范变换**（保 Haar 的变量替换，用跨平面的时间链构造）消掉跨平面耦合后才成立，
   这一步**只用 Wilson 形式的特殊结构**。这也是为什么"直接证粗测度 RP"不可行：粗作用量一般不是 Wilson 形式。

6. **障碍清单的要点**：真正的障碍**不是 RP**，而是 **(i) 粗作用量的类闭合（class closure）**（RP 不给这个，需 Balaban 的小场/大场分析）
   与 **(ii) MG（体积一致指数聚类）**——后者与 RP 无关。RP 的作用是：(a) 保证 OS 重构与转移矩阵为正；
   (b) 通过 chessboard estimates（§6）为大场分析提供 Peierls 型界；(c) 让 `Δ(n)` 间隙检验（§5.3）成为合法推理。

7. **与主会场的接口**：`Δ(n)=4logZ(n²)−logZ(2n²)` 的"小 ⟹ 转移矩阵有隙 ≥ log2/n"**依赖 RP**
   （推导用到 RP 的正性与 Cauchy–Schwarz）。所以本报告的定理是那个检验的合法性前提；
   而 MG 仍需主会场的弱→强 RG 交接。**注意方向**：RP 只让隙"有意义"并让 `Δ(n)` 检验成立，
   **不**提供跨尺度的定量下界回传（§4.7）。

8. **与 os2 的接口，已定案（§4.6）**：必须区分两件事。
   **(a) 倾斜块作为 RG 步**：`(B1)` 成立当且仅当 **`A Λ' = Λ'`**（`A` = 标准时间反射，`Λ' = 5Rℤ⁴`）；
   精确算术给出时间-空间倾斜（`B₁₂, B₁₃`）违反它（`(3,4,0,0) ↦ (−3,4,0,0) = (7/25)b₀ + (24/25)b₁ ∉ Λ'`），
   纯空间倾斜（`B₂₄`）满足但混合不了时间与空间。故**保 RP 的 RG 步只能用轴对齐 blocking**。
   **(b) 旋转立方正则化（os2 的实际用法）**：独立的格点 QFT，RP 直接由 OS/MP 给出，`(B1)` 不出现，
   **定理 3.1 不受影响**。两者不冲突；剩余义务（跨正则化比较不得预设 O(4)）在 os2/gluing 一侧。

## 1. 精确定义

### 1.1 反射正性（RP）的三种写法

固定一个反射 `θ`（对时间坐标做 `θ: x₀ ↦ −x₀` 或 `x₀ ↦ −1−x₀`，空间坐标不动），
它诱导测度空间 `(Ω, μ)` 上的保测对合 `θ_Ω: Ω → Ω`（`θ_Ω² = id`，`(θ_Ω)_*μ = μ`）。
设 `𝒜₊` 为"正时间半空间"上的可观测代数（规范不变、有界、复值）。

- **实代数形式（本报告主用）**：
  ```
  ∀ f ∈ 𝒜₊ :   ∫_Ω f(θ_Ω ω) · f(ω) dμ(ω)  ≥  0.
  ```
  （`f` 实值；复值时代入 `conj(f(θ_Ωω))·f(ω)`。）
- **反线性形式（OS 原文）**：`J` 为反线性对合，`⟨J F, F⟩ ≥ 0`，`⟨·,·⟩` 为 `L²(μ)` 内积。
- **核形式（转移矩阵）**：把时间分层，令 `K(U,V)` 为相邻两层边界构型 `U,V` 之间的 slab 权重。
  则 RP ⟺ `K` 作为核半正定：`∫∫ conj(f(U)) K(U,V) f(V) dUdV ≥ 0`。

三者等价是标准结果（Lüscher 1977 构造格点规范转移矩阵；OS 1973/1975）。

**关键点**：RP 是 `𝒜₊` 上的一个**二次型非负**条件。它只约束"同一半空间内两次可观测"的关联，
不约束跨平面关联的符号；也**不给速率**（那是 MG 的事，§8 O4）。

### 1.2 两类反射平面与对链/面/格点的作用

设格点 `Λ_{L,a} := (aℤ)⁴ ∩ [−L/2, L/2)⁴`（**时间方向取自由边界**——OS/MP 的形式，且半空间最干净），
链 `(x,μ)` 占据线段 `[x, x+ê_μ]`。两种自然选择：

| | 过链平面 (LP) | 过格点平面 (SP) |
|---|---|---|
| 定义 | `θx₀ = −1−x₀`（平面 `x₀=−½`，不含格点） | `θx₀ = −x₀`（平面 `x₀=0`，含格点） |
| 时间链 `k` | `k=−1` **固定、反向**（逆）；`k ↦ −2−k` 配对 | `k ↦ −1−k` 全部配对、反向 |
| 空间链 `k` | `k ↦ −1−k` 配对，不反向 | `k=0` **固定、不反向**；`k ↦ −k` 配对 |
| `(0,i)` 面 `k` | `k=−1` **固定**（反向 ⟹ `Re tr` 不变）；其余配对 | `k ↦ −1−k` 全部配对 |
| `(i,j)` 面 `k` | `k ↦ −1−k` 配对 | `k=0` **固定、不反向**；`k ↦ −k` 配对 |
| 平面对象是否跨半空间 | **是**（`(0,i)`@`k=−1` 同时含层 `−1` 与层 `0` 的空间链） | **否**（平面对象只含层 `0` 的空间链） |

作用量分解 `S = S₊ + S₋ + S₀`，`S₋ = θS₊`。**LP 的 `S₀` 跨半空间**（含下层与上层的空间链），
**SP 的 `S₀` 完全落在平面内**。这个表是后面所有几何讨论的依据。

`θ` 对群元的约定：反向的固定链取逆 `U ↦ U⁻¹`（Haar 不变，`Re tr` 不变）；不反向的固定链取 `U ↦ U`。

**记号约定（与合同 A0 对齐）。** `Λ_{L,a}` 是有限格点（合同同记号）。本报告**不使用** QCD 标度，
若需引用写作 `Λ_QCD`，故无冲突。§4.6 中的裸 `Λ := ℤ⁴`、`Λ' := Bℤ⁴` 分别指**无限细格点**与**粗格点**，
沿用 gluing 已记录的写法以保持跨文档一致。

**与 `T⁴_L` 的桥。** 取自由边界是因为 OS'78 / MP'87 在此形式下陈述、且半空间与平面代数最干净。
`T⁴_L`（周期）版本由**同一证明**给出：平面经过链、不经过格点时把环面切成两个半空间，
所有链与面成对（见上表），作用量同样分解；两种边界的无限体积极限都由定理 5.2 保持 RP。

**极限次序。** 固定 `L` 先取 `a → 0`，再取 `L → ∞`，**不取联合极限**（与合同 §R3 一致）。
代价是 UV 极限需对 `L` 一致——那是 MG 的内容，本报告不涉及；本报告对每个 `L, a` 都给出 RP，
并只依赖定理 5.2 把 RP 传到上述两个极限。

### 1.3 半空间代数与规范不变性

`𝒜₊ := `由"下端点 `x₀ ≥ 0` 的链"生成的**规范不变**可观测（Wilson 环）代数。
- 细格点：`𝒜₊^fine`。
- 粗格点（边长 `L`、粗格点位置见 §4.2）：`𝒜₊^coarse := {a∘F : a 由粗时间 n₀ ≥ 0 的粗链生成}`。

规范不变性和半空间在反射下如何互动，是 §2.4 的主题。

## 2. 细格点：已知定理

### 2.1 Osterwalder–Seiler 1978（过链平面）

**定理（OS）** 设 `G` 紧，`N_c := dim f`（`f` 为基本表示），`β := 2N_c/g² ∈ (0,∞)`，`γ := β/N_c = 2/g²`。
Wilson 测度（**归一化迹，与合同 A0 一致**）
```
dμ_{L,a} = Z⁻¹ ∏_p exp( (β/N_c) Re tr_f U_p ) ∏_ℓ dU_ℓ
         = Z⁻¹ ∏_p exp( γ Re tr_f U_p ) ∏_ℓ dU_ℓ ,
```
`θ` 为 LP（`x₀↦−1−x₀`）。则对 `𝒜₊` 中任一规范不变可观测 `F`，
```
∫ conj(F(θω)) F(ω) dμ_{L,a}(ω) ≥ 0.
```
> **归一化的记账要点**：RP 对**任意** `γ>0` 成立，故归一化不影响定理内容；
> 但**不可把 `β` 直接代入指数**——`exp(β Re tr)` 与 `exp(γ Re tr)`（`γ=β/N_c`）是不同理论，
> `SU(3)`、`g²=1` 时前者给出 `g²=1/3`。本报告一律用 `γ = β/N_c = 2/g²`，与合同 A0 一致。

文献：Osterwalder–Seiler, *Ann. Phys.* **110** (1978) 440–471；Seiler, LNP **159** (1982) 第 3 章。

### 2.2 Menotti–Pelissetto 1987（过格点平面）

**定理（MP）** 同上，但 `θ` 为 SP（`x₀↦−x₀`）；结论对**所有**可观测成立（强于仅规范不变）。
证明用**幺正规范变换**（保 Haar 的变量替换），依赖 Wilson 作用的特殊结构。
文献：Menotti–Pelissetto, *Comm. Math. Phys.* **113** (1987) 369–373；会议版 *Nucl. Phys. B Proc. Suppl.* **4** (1988) 644–648。

> **这就是解决对齐问题的钥匙**：两类平面都能用。于是"粗格点的过链平面 = 细格点的过格点平面"这类错位，
> 可以通过选择用哪一类细格点 RP 来消化（§4.3）。

### 2.3 机制：Wilson 权重的正定性与 slab 核的正性

两个定理的公共内核是：

**(P1) 单面权重是 `G` 上的正定函数。** `e^{γ Re tr_f U}` 在特征标基下系数非负：
- `U(1)`：`Re tr_f U = cos θ`，`e^{γ cos θ} = Σ_n I_n(γ) e^{inθ}`，`I_n(γ)>0`；
- `SU(2)`：`Re tr_f U = 2cos θ`，`e^{2γ cos θ} = Σ_n I_n(2γ) e^{inθ}`，对 `χ_j` 的系数为
  `I_k(2γ) − I_{k+2}(2γ) > 0`（Bessel 单调性）；
- 一般紧群：标准结果（强耦合展开的收敛性依赖它）。

**(P2) slab 核的正性。** 把时间分层（层 = 空间链构型），slab `[k,k+1]` 的边界是层 `k`、`k+1` 的空间链，
**内部**是层 `k` 的时间链。展开 slab 内每个面的特征标 `e^{γ Re tr_f U_p} = Σ_λ c_λ χ_λ(U_p)`，
`c_λ ≥ 0`；对内部时间链做 Haar 积分，用正交关系
`∫ dU χ_λ(A U) χ_μ(U⁻¹ B) = δ_{λμ} (1/d_λ) χ_λ(A B)`，
得到 slab 权重 = 正系数 × 边界链上特征标之积。**每一项都是正定的 rank-one 核**，故 `K ≥ 0`，即 RP。

这是"对偶/曲面展开"的观点。**注意**：时间链是 slab 的**内部**自由度，不是边界——这正是为什么转移矩阵为正，
也是为什么 LP 上跨平面的时间链不会破坏正性（它们被积掉）。§2.4 说明为什么直接对"半空间代数"做初等分解会失败。

**关于常数。** 本报告**不引入任何独立的未定常数**：出现的常数只有 Bessel 系数 `I_k(·)` 与被引定理内部的常数；
全文没有形如"存在常数 `C` 使 …"的独立估计。因此若审计清单要求"钉定 RT 常数 `C`"，在本文件中**无对象可钉**
（若所指是 `Basic.lean` 的 `ExponentialClustering`，那里的 `C` 是对固定测试函数 `f,g` 存在的常数、
依赖 `f,g`，**不应**钉成单一数值）。

### 2.4 朴素平方论证为何失败（规范困难的最小体现）

在 SP 上，`S₀` 落在平面内、`S = S₊+S₋+S₀`，`S₋ = θS₊`。令 `s` 为层 0 空间链，`U₊/U₋` 为上下半空间链。
天真地写
```
⟨θF,F⟩ = ∫ ds e^{S₀(s)} [∫ dU₋ conj(F(s,U₋)) e^{S₋(s,U₋)}] [∫ dU₊ F(s,U₊) e^{S₊(s,U₊)}].
```
用 `S₋(s,U₋) = S₊(s,θU₋)` 换变量 `U₊ = θU₋`，第一因子化为
`conj( ∫ dU₊ F(s,θU₊) e^{S₊(s,U₊)} )`。
**第二个因子是 `∫ F(s,U₊) e^{S₊}`，二者不是同一对象**（因为 `F∘θ ≠ F`，且 `S₊` 在 `U₊ ↦ θU₊` 下不不变）。
所以乘积**不是** `|·|²`，平方论证崩掉。

MP 的修复：在上半空间做一个**由跨平面时间链构造的幺正规范变换**（变量替换，Jacobian = 1），
把跨平面耦合"规范掉"，之后才恢复可分解性。这一步逐项用到 Wilson 形式，**对一般的规范不变作用量不成立**。

> **推论（重要）**：粗作用量一般**不是** Wilson 形式（block-spin 生成无穷多耦合）。
> 因此 MP 的过格点 RP **不能**对粗测度重跑。粗测度的 RP 只能**由下降（descent）证明**，不能用细格点的证明模板。§3 正是干这个的。

## 3. 主定理：RP 沿 blocking 下降

### 3.1 抽象设定与充分条件

- `(Ω, μ)`：细格点构型空间 + Wilson 测度；`θ_Ω`：保测对合（LP 或 SP 诱导）。
- `F : Ω → Ω'`：blocking（可测，粗构型空间 `Ω'`）；`μ' := F_*μ`（推出测度）。
- `θ'_{Ω'}`：粗格点上的反射。
- `𝒜₊ ⊂ L²(Ω,μ)`：细正时间半空间**规范不变**代数；`𝒜₊' := {a∘F : a ∈ 𝒜₊^{coarse}}`。

**充分条件（对 blocking kernel 的要求）**

| 编号 | 条件 | 含义 |
|---|---|---|
| **(B1)** | `F ∘ θ_Ω = θ'_{Ω'} ∘ F`（作为 `Ω→Ω'` 的映射恒等） | **等变性**：blocking 与反射交换。等价于 `σ(F)` 是 `θ_Ω`-不变的，且诱导的粗作用恰为 `θ'`。 |
| **(B2)** | `a ∈ 𝒜₊^{coarse}（粗时间 ≥0）⟹ a∘F ∈ 𝒜₊（细时间 ≥0）` | **半空间分离**：粗正时间变量只依赖细正时间链。 |
| **(B3)** | `μ` 对 `θ_Ω` 在 `𝒜₊` 上 RP | 细格点定理（§2）。 |
| **(B4)** | `F` 规范协变（粗规范群 = 细规范群限制） | 自动：`a` 规范不变 ⟹ `a∘F` 规范不变（§4.1）。 |

### 3.2 定理（RP 下降）

> **定理 3.1.** 设 (B1)–(B4)。则 `μ'` 对 `θ'_{Ω'}` 在 `𝒜₊'` 上 RP：
> ```
> ∀ a ∈ 𝒜₊^{coarse} :   ∫_{Ω'} a(θ'y) · a(y) dμ'(y)  ≥  0.
> ```

**证明.** 令 `g := a∘F ∈ 𝒜₊`（由 (B2)）。则
```
∫ a(θ'y) a(y) dμ'(y)
  = ∫ a(θ'F(x)) a(F(x)) dμ(x)        [y = F(x)，推出测度]
  = ∫ a(F(θx))   a(F(x)) dμ(x)        [(B1)]
  = ∫ g(θx) g(x) dμ(x)               [定义 g]
  ≥ 0.                                [(B3)]
```
∎

**说明.**
- 证明**没有**用到 `g∘θ` 落在外半空间；(B2) 只需一半。这是 RP 的定义（只对 `𝒜₊` 中的 `g` 要求）给的。
- 不需要粗测度是 Gibbs 测度、不需要局部性、不需要 `F` 是线性的。**RP 对"非 Gibbs 推出"是稳的**，这是它的优点。
- (B1) 是**唯一实质性的几何条件**；(B2) 是关于 block 与平面相对位置的组合条件。

### 3.3 必要性/锐性（为什么不能更宽）

- **任意** `F` 都诱导一个条件期望 `E[·|σ(F)]`（定义级），所以"是条件期望"不是约束；**约束是 (B1)+(B2)**。
  这与 MathOverflow 上"保 RP 的 RG 映射本质上必须是条件期望"的说法一致：条件期望把 RP 传递到子代数，
  但前提是子代数在反射下不变（B1）且在正时间侧被正时间侧决定（B2）。
- **反例机制**：若 (B1) 失败（`σ(F)` 不被 `θ_Ω` 保持），则 `a(θ'y)` 无法写成 `a∘F` 的反射，证明断链；
  此时粗测度可能有负的 `⟨θ'a,a⟩`。这正是多数"block spin 破坏 RP"的现象（Kadanoff 多数规则、even-L 越平面 blocking）。
  Menotti–Pelissetto 一类文献与 Balaban 的非局部多尺度方案都因此**不控制** RP 的传递。
- **注意**：RP **不**保证 `μ'` 唯一、不保证聚类、不保证有隙。见 §8 O4。

## 4. 具体化：规范理论的 blocking kernel

### 4.1 直 Wilson 线 blocking

粗格点嵌入：粗格点 `n` ↔ 细格点 `Ln + s`（`s ∈ ℤ⁴` 待定，空间分量取 0）。粗链
```
U'_{n,μ} := ∏_{k=0}^{L−1} U_{Ln+s + k ê_μ, μ}      （沿直线路径的长度 L 的 Wilson 线）
```
- **规范协变**：细规范变换 `g` 下，`U'_{n,μ} ↦ g'_{n} U'_{n,μ} (g'_{n+ê_μ})⁻¹`，其中 `g'_n := g_{Ln+s}`。
  故粗规范群 = 细规范群的**限制**，粗链协变。⟹ (B4)。
- **规范不变性自动保持**：粗 Wilson 环 `W'` 是细 Wilson 环沿"加厚"环路的限制，规范不变；
  `a∘F` 是细规范不变可观测。⟹ 细格点 OS/MP 定理适用。
- **非线性**：`U'` 是群元的非交换乘积。**没有线性平均**（群非向量空间），
  这与 φ⁴ 的 block sum / O(N) 的归一化平均都不同（§7）。

### 4.2 对齐：(B1) 是路径级条件

(B1) 要求 `F(θU) = θ'(F(U))` 作为**构型恒等**。对直 Wilson 线，这意味着：
> 反射 `θ_fine` 必须把"粗链 `n` 的路径"映到"粗链 `θ'(n)` 的路径"（可能反向、取逆），
> 且路径上的**逐条细链**一一对应。

于是 (B1) 化为两条纯几何的算术条件：
1. **格点条件**：`θ_fine(Ln+s) = L·θ'(n) + s`，对一切 `n`；
2. **链条件**：`θ_fine` 把从 `Ln+s` 到 `Ln+s+Lê_μ` 的直线路径映到 `θ'(n)` 对应的直线路径。

第二条在 LP/SP 下自动满足（直线路径是坐标方向的，反射保持/反转它）；第一条给出平移 `s` 的奇偶性条件。

**（B2）** 则要求：粗时间 `n₀ ≥ 0` 的路径上所有细链下端点 `x₀ ≥ 0`。对直线路径这是组合条件：
`L n₀ + s₀ ≥ 0` 且 `L(n₀+1)+s₀−1 ≥ 0` 之类，逐方向检查。

### 4.3 奇偶性定理：两条可行路线

记 `LP: θx₀=−1−x₀`，`SP: θx₀=−x₀`。

> **定理 4.2（Route A：奇 L，过链粗平面）.**
> 取 `L` 奇数，平移 `s₀ = (L−1)/2`（空间分量 0），细格点用 **LP**。
> 则 (B1) 成立，粗反射 `θ'` 为 `θ'(n)₀ = −1−n₀`（粗格点**过链平面**），且 (B2) 成立。
> 故粗测度对粗过链平面 RP。

*验算.* `θ_fine(Ln₀+s₀) = −1−Ln₀−s₀ = L(−n₀−1) + s₀`（用 `−1−s₀ = −(L+1)/2 = −L+(L−1)/2`）。✓
时间链：粗链 `(n,0)` 的细链集合 `{Ln₀+s₀, …, Ln₀+s₀+L−1}` 在 `k↦−2−k` 下变为
`{−Ln₀−s₀−L−1, …, −Ln₀−s₀−2}`，恰为粗链 `(−n₀−1, 0)` 的细链集合（因为 `L(−n₀−1)+s₀ = −Ln₀−L+s₀`，
且 `L = 2s₀+1` 使上下端点对齐）。✓ 空间链同理（不反向）。✓ (B2)：粗 `n₀≥0` ⟹ 细下端点 `≥ Ln₀+s₀ ≥ s₀ ≥ 0`。✓

> **定理 4.3（Route B：任意 L，过格点粗平面）.**
> 取任意 `L ≥ 1`，平移 `s = 0`（粗格点对齐细格点 `Ln`），细格点用 **SP**。
> 则 (B1) 成立，粗反射 `θ'(n)₀ = −n₀`（粗格点**过格点平面**），且 (B2) 成立。
> 故粗测度对粗过格点平面 RP。

*验算.* `θ_fine(Ln) = −Ln = L(−n)` ✓。时间链：`{Ln₀, …, Ln₀+L−1}` 在 `k↦−1−k` 下变为
`{−Ln₀−L, …, −Ln₀−1}` = 粗链 `(−n₀−1, 0)` 的细链集合 ✓（(`−n−1`) 的粗链在 `−n₀` 与 `−n₀−1` 之间）。
空间链：`k↦−k`，同一空间方向，不反向；粗链 `(n,i) ↦ (−n, i)` ✓。(B2)：粗 `n₀≥0` ⟹ 细下端点 `≥ Ln₀ ≥ 0` ✓。

| 路线 | 细平面 | L | 粗平移 `s₀` | 粗平面 | 粗 RP 平面适合转移矩阵？ | 状态 |
|---|---|---|---|---|---|---|
| A | LP（OS'78） | 奇 | `(L−1)/2` | 过链 `n↦−1−n` | ✅ 是 | **已验算** |
| B | SP（MP'87） | 任意 | 0 | 过格点 `n↦−n` | ⚠ 是（不同但等价的层约定） | **已验算** |
| — | LP | 偶 | 无整数解（`2s₀≡−1 mod L` 无解） | — | — | ✗ 不存在 |
| C | LP | 偶 | 半整数 `(L−1)/2` | 过链 | ✅ | 需 staircase 粗链；**未验**（O2） |

> **结论**：**偶数 L + 过链粗平面是唯一需要新工作的组合**。要么用 Route A（奇 L），要么接受 Route B 的过格点粗平面，
> 要么做 Route C 的半整数平移（staircase Wilson 线）。三者都足以让 RP 活下来；Route A 最干净。

### 4.4 非线性性的确切后果

1. **无线性 RG**：不能像 φ⁴/高斯那样把粗场写成细场的线性泛函再做高斯积分。粗作用量必须通过群积分得到，天然非 Gibbs。
2. **等变性是几何的**：`(B1)` 变成"路径选择"的约束（§4.2），而不是"kernel 的线性性"。这是规范 blocking 的设计自由度所在。
3. **粗格点 ⊂ 细格点**：规范协变 ⟹ 粗规范群 = 限制 ⟹ 出现奇偶性（§4.3）。这是**规范特有**的：
   自旋系统的粗site可以放在任意位置而无规范约束，但那样 (B1) 的对齐问题仍然存在（§7 对照）。
4. **`U ↦ U⁻¹` 的记账**：反向链取逆。对 RP 无害（测度与 `Re tr` 在取逆下不变），但必须在 (B1) 里显式写出，
   否则会误判等变性（例如把"粗链 ↦ 粗链⁻¹"错读成"不等变"）。

### 4.5 阿贝尔对照：U(1) 的通量阻塞

对 `G=U(1)`，可取**对偶变量**：粗面通量 = 细面通量之和，**线性**。在这个变量里 blocking 是线性的，
RP 的讨论回到 φ⁴ 型。所以规范困难的本质是**非阿贝尔性**（乘积非交换、无通量线性化）。
但对偶变量里 RP 的陈述变了（RP 是关于对偶场的），且 OS 重构需要原变量；因此这条路线不能直接搬。
价值仅在于：**它显示"RP 保 block-spin"不是原理上不可能**，非阿贝尔的障碍是技术性的。

### 4.6 与 OS2 的接口：inclined **blocking**（RG 步）vs 旋转立方**正则化**（非 RG 步）

必须区分两个不同的对象；把两者混为一谈是我初稿的错误，也是"OS3 与 OS2 冲突"这一说法的来源：

| | (a) inclined **blocking** | (b) 旋转立方**正则化**（os2 实际使用） |
|---|---|---|
| 是什么 | 同一套 RG 里 `F: Λ=ℤ⁴ → Λ'=5Rℤ⁴` 的一步 | 独立的一套格点 QFT，格点 `5Rℤ⁴` 本身就是 UV 正则化 |
| RP 从哪来 | 只能靠**下降**（定理 3.1）⟹ 需要 (B1) | **直接**由 OS/MP（该格点是立方格点，共轭后逐字适用） |
| 与 (B1) 的关系 | **受 (B1) 约束**（本节下面证明它失败） | (B1) 根本不出现：没有 `ℤ⁴ → 5Rℤ⁴` 的映射 |
| 定理 3.1 | 直接适用 | **不受影响** |

**(b) 的合法性**：`5Rℤ⁴` 是边长 5 的立方格点；其 Wilson 测度经 `R` 共轭后就是 `ℤ⁴` 上的 Wilson 测度，
故 OS'78 / MP'87 的 RP **无条件成立**（坐标平面在旋转后仍是由该格点自身坐标轴张成的平面）。
所以"在倾斜格点上 RP 成立"不需要任何新定理——它是 OS/MP 的换元。

**本节余下部分只讨论 (a)**：即如果有人试图把倾斜块当作**一步 RG** 用，会怎样。
结论是 `(B1)` 失败；但既然 os2 的用法是 (b) 而非 (a)，**这条结论不构成对 os2 的反对**，
它只是排除了一种错误用法。并行会话已按 (b) 定案。

#### 判据

设细格点 `Λ = ℤ⁴`，粗格点 `Λ' = Bℤ⁴`，blocking 为 `Λ'`-**周期**（每个 block 用同一规则——标准类）。
若 (B1) 成立，`θ_fine(x) = Ax + v`、`θ_coarse(y) = M'y + v'`，则 `A`、`M'` 分别是两侧格点的自同构，
且必有
```
A Λ' = Λ'        (等价地  A ∈ W ∩ R W R⁻¹，W = 超立方点群)
```
*证明.* `Λ'`-周期性给 `F(x+b) = F(x) + τ(b)`（`b ∈ Λ'`）。代入 (B1)：
`θ_coarse(F(x)+τ(b)) = θ_coarse(F(x)) + M'τ(b)`，左端 `= F(Ax+v+Ab) = θ_coarse(F(x)) + τ(Ab)`。
故 `τ(Ab) = M'τ(b)` 对一切 `b ∈ Λ'`，即 `A Λ' = Λ'`。∎

（反射永远不是 `±I`，所以"`A ∈ W ∩ R W R⁻¹`"是一条**实质**条件。）

#### 情形 1：倾斜混入时间 ⟹ **(B1) 失败**

os2 的 `B₁₂`（0-based 平面 `{0,1}`）与 `B₁₃`（0-based `{0,2}`）把时间坐标卷入旋转。
取 `b₀ = 5Rê₀`：对 `B₁₂`，`b₀ = (3,4,0,0)`，
```
A b₀ = (−3,4,0,0) = (7/25)·b₀ + (24/25)·b₁   ∉  Λ'         （7/25 ∉ ℤ）
```
对 `B₁₃` 同理：`b₀ = (3,0,4,0) ↦ (−3,0,4,0) = (7/25)b₀ + (24/25)b₂ ∉ Λ'`。
等价的矩阵计算：`R A R⁻¹ = [[7/25,−24/25],[−24/25,−7/25]] ⊕ I₂`，含非整数元，故 `A ∉ R W R⁻¹`。
另一侧同样不可行：保 `Λ'` 的反射全在 `R W R⁻¹` 里（在物理坐标里是**倾斜**的），
它们不保 `Λ = ℤ⁴`，故细格点 RP (B3) 不可用。
**两侧不能同时满足 ⟹ 不存在可行配对 ⟹ 时间-空间 inclined blocking 不能进入保 RP 的 RG 步。**

> 这里的算术要点值得记住：`3-4-5` 的有理性**不够**——反射后的系数是 `7/25`，而 `7 ∤ 25`。

#### 情形 2：纯空间倾斜 ⟹ 成立，但对 O(4) 无用

os2 的 `B₂₄`（0-based `{1,3}`，纯空间）有 `A R = R A`，故 `A Λ' = Λ'` ✓：
```
b₀ = (5,0,0,0) ↦ (−5,0,0,0) = −b₀ ∈ Λ'  ✓
```
于是 (B1) 以**标准（轴对齐）粗时间反射**成立；(B2) 也成立（`b₀ = 5ê₀`，粗时间 = `x₀/5`）。
RP 下降无碍，粗理论对**轴对齐粗时间平面** RP。**但纯空间倾斜不混合时间与空间，不生成 (0,i) 旋转**，
对 O(4) 无贡献。

#### 结论（对 gluing / os2 的明确答复）

1. **作为 RG 步 (a)：排除。** 保 RP 的 RG 步只能使用"粗格点在物理时间反射下不变"的 blocking。
   轴对齐 blocking（Route A/B）满足；纯空间倾斜满足但无用；
   **时间-空间 inclined blocking（`B₁₂, B₁₃`）不满足，任何一步用它都会在该步丢失 RP。**
2. **作为正则化 (b)：无碍，且不需要本报告的任何东西。** `5Rℤ⁴` 上的 Wilson 测度就是立方格点上的 Wilson 测度
   （经 `R` 共轭），OS'78 / MP'87 的 RP 逐字适用。**定理 3.1 不受影响**，因为 (b) 里没有 blocking，(B1) 不出现。
   ⟹ **"OS3 与 OS2 不冲突"**：两者作用在不同对象上。
3. **剩余义务落在 os2/gluing，不在 OS3**：跨正则化比较（`ℤ⁴` 与 `5Rℤ⁴` 的极限如何关联）**不能预设 O(4)**，
   否则就是循环。可行的做法是 os2 的"稠密子群 + 连续性"或者 Symanzik 无关算符，两者都不需要 RP 参与。
   本报告只保证：**每一套正则化各自都 RP，且若对它做 RG，轴对齐即可。**
4. **分工**：RG 步 = 轴对齐（本报告 Route A/B）；O(4)/OS2 = 旋转正则化族 / Symanzik（os2）。二者正交。
5. **一句话**：`(B1)` 加上"`θ_fine` 必须是细格点自同构"排除了时间-空间 inclined blocking 作为 **RG 步**；
   把它当作**独立正则化**则完全允许。这是上面 `A Λ' = Λ'` 判据的直接后果，**不是**对旋转正则化的限制。

*验证方式*：上表两个情形的格点系数与 `R A R⁻¹` 均由 `Fraction` 精确算术复算（脚本一次运行，无浮点）。

### 4.7 与 gluing 会话 GL2 的关系（含一处方向性更正）

gluing 的 GL2 原表述："若 blocking `E_B` 是 θ-协变的条件期望，则 `T_coarse = E_B T_fine E_B*`，
故 `gap(T_coarse) ≥ gap(T_fine)`；RP 让隙的结论从粗尺度回到格点。"

**光谱事实成立，但最后一句的推理方向是反的**（gluing 已在合同中拆成 GL2a / GL2b；本报告采纳该更正）：

- 设 `T` 自伴正压缩、`E` 正交投影，`T_E := E T E`。Cauchy 交错给出
  `λ_k(T) ≥ λ_k(T_E) ≥ λ_{k+m}(T)`（`m = codim ran E`），故 `λ₂(T_E) ≤ λ₂(T)`，
  归一化隙 `λ₂/λ₁` **上升**，即 `Δ_coarse ≥ Δ_fine`。
- **这个方向对"下界回传"是反的**：若在粗尺度证得 `Δ_coarse ≥ δ`，由 `Δ_fine ≤ Δ_coarse` **推不出** `Δ_fine ≥ δ`。
  要把下界拉回细尺度，必须控制被投影掉的那部分谱质量——即**截断有效作用量的误差**（Balaban 型），
  这是**解析**内容，**不是 RP 的推论**。把这条记在 OS3 名下会误导实现者。
- **RP 真正提供的是**：转移矩阵的正性与 Hilbert 空间的存在（否则"隙"无从谈起），
  以及 §5.3 中 `Δ(n)` 间隙检验的**合法性**。它**不**提供定量的尺度间回传。

**因此与 GL2 的接口是**：
- **GL2a（RP 下降）**：由定理 3.1 给出；其中"`θE = Eθ`"这一条正是 (B1)，由 §4.6 的判据可判定。
  这是干净且成立的部分，也是本报告的全部贡献。
- **GL2b（隙回传）**：**不是** RP 的推论，是独立义务（截断有效作用量误差）。不计入 OS3。
- 原 GL2 的义务"blocking 必须是规范不变的群平均、不能是 Balaban 的逐块规范固定"仍由
  **(B1)+(B2)+规范协变 (B4)** 满足；§8 O8 说明机制，§4.6 给出 inclined 的陷阱。
- 附注："θ-协变条件期望"中的"条件期望"是**自动**的（任何 `F` 都给出 `σ(F)` 上的条件期望）；
  真正的约束是 **(B1)+(B2)**，且 (B1) 在规范理论里是**路径级**条件（§4.2），不是 kernel 的线性/协变性。

## 5. 迭代与连续极限

### 5.1 逐步下降 ⟹ 所有尺度

设 `μ₀` 为细格点 Wilson 测度，`F₁, F₂, …` 为满足 (B1)(B2) 的 blocking 序列（如每步 Route A，`L` 奇）。
由定理 3.1 归纳得：每个 `μ_k := (F_k)_* μ_{k−1}` 对其粗反射 RP。
> **推论 5.1.** RP 对整个 RG 流封闭：任一尺度上粗测度都 RP，且 `𝒜₊^{coarse}` 上的二次型非负由上游细格点的 RP 直接继承，
> **无需重新验证粗作用量的任何解析性质**。

这是本报告对"RP 是否活过 block-spin RG"的直接回答：**活得下来，前提是每一步的 blocking 都按定理 4.2/4.3 设计。**

### 5.2 连续极限 / 弱极限下的封闭性

> **定理 5.2.** 设 `μ_n ⇒ μ`（弱收敛），每个 `μ_n` 对同一 `θ` RP。
> 则 `μ` RP。若只有 Schwinger 函数 `S_n(f₁,…,f_k) → S(f₁,…,f_k)`（有限阶矩收敛），
> 则对多项式可观测 `F`，`∫ conj(F∘θ) F dμ_n → ∫ conj(F∘θ)F dμ ≥ 0`，故 `μ` 在多项式代数上 RP。

**证明.** 弱收敛 + `conj(F∘θ)F` 有界连续（格点情形）直接取极限；连续极限情形用矩收敛 + RP 二元型是有限个 Schwinger 函数的有限和。∎

**应用**：
- **无限体积极限**（`Λ_{L,a} ↗ aℤ⁴`，固定 `a`；子列）：RP 对热力学极限封闭。
  ⟹ 16 输入构造给出的**子列**无限体积极限满足 OS3。
- **连续极限**：UV 极限下，Schwinger 函数收敛（16 输入含此项），故连续极限满足 OS3。
- **唯一性/子列问题**：RP 与"只得到子列极限"无关——每个子列极限都 RP，但不同子列是否同一个理论是另一回事（主会场的 uniqueness 问题）。

### 5.3 与 16 输入的关系

若 16 输入（`RG1–RG5, UV1, PH1–PH3, AN1, Y1–Y4, B1, C1`）中 `PH1–PH3` 含"物理 Hilbert 空间/正性"，
则本报告说：**OS3 不是独立输入**，它是 (i) 细格点 OS/MP 定理 + (ii) blocking 设计条件 (B1)(B2) + (iii) 极限封闭性 的**推论**。
即：把"在每一尺度上重新证正性"这件不可行的事，替换为"按定理 4.2/4.3 搭 RG"这件可行的事。
（若 `PH` 已含 OS3，则本报告给出的是它的**独立证明**；若不含，则本报告**补上**它。两种情况都降低风险。）

**与 `Δ(n)` 间隙检验的接口**（主会场模板）：`Δ(n) = 4logZ(n²) − logZ(2n²)` 的"精确 block 下不变"与
"若在盒子上小则转移矩阵有隙 `≥ log2/n`"**依赖 RP**。所以 OS3 是那个检验的合法性前提；本报告保证它成立。
但 `Δ(n)` 的**一致性/裸尺度估计**（即 MG）与 RP 无关，仍在主会场。

## 6. Chessboard estimates

### 6.1 陈述与条件

若 `μ` 对**所有坐标方向、所有超平面**（两类平面都要）RP，则对支撑在块 `B` 上的可观测 `F` 及其在
"棋盘反射群" `T` 下的像，
```
| ⟨ Π_{τ∈T} (τF) ⟩ |  ≤  Π_{τ∈T} ‖ τF ‖_cb ,      ‖F‖_cb := μ( Π_{τ∈T} τF )^{1/|T|} ,
```
即 chessboard 范数控制任意乘积的期望。这是 Dyson–Lieb–Simon 1978 的"棋盘估计"，
FILS（Fröhlich–Israel–Lieb–Simon, *Comm. Math. Phys.* **62** (1978)）系统化；
Seiler LNP 159 有格点规范版本。

**条件**：需要 RP 在一个**生成元集**的反射下（四个方向的超平面）；OS + MP 提供全部。

### 6.2 规范版本的注意点

- 反射把链映到链、面映到面；反向链取逆。可观测必须选**取逆不变**的，如 `|Re tr U_p|`、`|tr W(C)|`。
- 对 Wilson 环，`|tr W(θC)| = |tr W(C)|`（`tr` 取逆 = 共轭），所以反射不改变 `|·|`，估计可用。
- 这就是"用 chessboard 给大场估计"在规范理论里可行的原因。

### 6.3 在 RG 中的用途

- **Peierls / 大场界**：`μ(某块大作用量) ≤ exp(−c·面积)`。Balaban 的大场分析需要此类界（"大场区域稀少"）。
- **与 FSS 的兼容**：chessboard 给出的是"以面积指数小"的界，恰好是曲面展开 / polymer 界的输入。
- **但**：chessboard 只给**上界**，不给聚类、不给 RG 步进定理。它是**工具**，不是证明 MG 的引擎。

## 7. 2026 O(N) sigma model blocking 的对照

- **为什么是最近的样板**：`O(N)` 的靶空间是球面——**非线性**，与规范群的非线性同类；而自旋的 RP 是标准的。
  Douglas 的 Stony Brook 2026 讲座报告：OpenAI 的 O(3) 二维模型构造用 **Balaban 式 block-spin RG**，
  满足 OS 公理、有质量隙（约 22k 行，未形式化）。
- **关键设计**（据 Douglas 讲座与相关预印本可见的部分）：
  1. 绕**分片常数 block spin** 展开（而非约束能量极小点）；
  2. 粗键用 **signed gas**（而非 polymer 展开）；
  3. 有效密度保持在固定类；
  4. block-spin **decimation**（`2a→4a`）保持 **reflection-positive measure**（见 OSF 预印本对 Step II/III 的描述）。
- **与规范的差别**：
  - 自旋的 block 平均可以**归一化**（朝球面投影），规范链没有"平均"只有"乘积"；
  - 自旋没有规范约束 ⟹ 粗 site 位置自由，只需 (B1)(B2)；规范有**粗格点 ⊂ 细格点**的额外约束（§4.4.3）；
  - 自旋的"one-sidedness"由 block 对齐（平面落在块间）实现；规范同理但还要处理 `U↦U⁻¹`。
- **可否直接搬**：**RP 部分可以直接搬**——定理 3.1 对任何满足 (B1)(B2) 的 `F` 成立，`O(N)` 与规范无差别。
  差别在**解析部分**（signed gas、class closure），那属于主会场的 RG 工作。
- **诚实警告**：这些 2026 预印本我**未能逐条核对**（24 小时内发布的 AI 生成稿件，venue 可疑）；
  但"decimation + 对齐 block + 保持 RP"的设计与我们定理 4.2/4.3 一致，可作**设计存在性**的证据，不作依据。

| 编号 | 障碍 | 性质 | 影响 | 处置 |
|---|---|---|---|---|
| **O1** | 平面类型/奇偶性记账 | 组合/几何 | Route A 需奇 L；偶数 L+过链粗平面需新工作 | 用 Route A 或 Route B；L 是自由参数，取奇数即可 |
| **O2** | 偶数 L + 过链粗平面（Route C） | 几何，未验 | 半整数平移 ⟹ staircase Wilson 线；逐路径等变性未证 | 列为 next step（有限组合验证，可 Lean 化） |
| **O3** | 粗测度非 Gibbs | 解析 | 不能用 Dobrushin/Gibbs 工具；`Δ(n)` 的粗格点版本需要粗作用量的控制 | RP 不依赖 Gibbs（定理 3.1）；解析部分归主会场 |
| **O4** | **RP 不给隙、不给聚类、不给唯一性** | 原理 | 本报告**不**推进 MG | 说清楚；MG 归主会场的 `q₀≥q₁` |
| **O5** | **类闭合（class closure）** | 解析，**真难点** | RG 步进定理需要有效作用量留在可控类；RP 不给 | Balaban 小场/大场 + chessboard（§6）；主会场 |
| **O6** | 费米子/Wilson 行列式 | 若含夸克 | 行列式 RP 需另证（MP 部分覆盖，有 caveat） | 纯 YM 范围外；若要加，另起 |
| **O7** | 连续极限中的分布性 | 技术 | RP 对矩收敛封闭（定理 5.2），但 OS0–OS2/OS4 另需 | 16 输入已含大部分；OS3 由本报告补 |
| **O8** | **任何一步做规范固定 ⟹ RP 毁** | 设计约束 | MRG 路线是规范固定的，其 RP 不能用于 OS 重构 | RG 必须**全程规范不变**；本报告的设计满足 |

**最重要的一条**：O4。RP 是 OS 重构的**必要条件**，但**远不是**质量隙的充分条件（hexagonmath 的反例正是：
满足 16 输入、E4 聚类成立，却无谱隙）。本报告解决的是"OS3 会不会在 RG 中丢掉"，
**不是**"质量隙"。不要把 OS3 的免费性误读为进展。

### 10.2 Lean（可复用 OSforGFF 的词汇）

定理 3.1 的**测度论内容极小**，且几何被完全封装在假设里——这使它成为理想的形式化目标：

```lean
-- 草案：D:/Dev/math/lean/YMStatement/RPDescent.lean（尚未创建）
import Mathlib.MeasureTheory.Measure.Portmanteau

namespace YMStatement

variable {Ω Ω' : Type*} [MeasurableSpace Ω] [MeasurableSpace Ω']
variable (μ : Measure Ω) [IsProbabilityMeasure μ]
variable (θ : Ω → Ω) (hθmeas : Measurable θ)
variable (hθ : MeasurePreserving θ μ μ) (hθ2 : θ ∘ θ = id)
variable (F : Ω → Ω') (hF : Measurable F)
variable (θ' : Ω' → Ω') (hθ'2 : θ' ∘ θ' = id)
-- (B1)
variable (hB1 : ∀ x, F (θ x) = θ' (F x))
-- (B3) 细格点 RP（实值版本，代数用谓词封装）
variable (RP : (Ω → ℝ) → Prop)
variable (hRP : ∀ f, RP f → 0 ≤ ∫ x, f (θ x) * f x ∂μ)
-- (B2) 粗正时间代数 ⟹ 细正时间代数
variable (A' : Set (Ω' → ℝ)) (A : Set (Ω → ℝ))
variable (hB2 : ∀ a ∈ A', (a ∘ F) ∈ A)

/-- 定理 3.1：RP 沿等变、半空间分离的 blocking 下降。 -/
theorem rp_descends (a : Ω' → ℝ) (ha : a ∈ A') (hRP'a : RP (a ∘ F)) :
    0 ≤ ∫ y, a (θ' y) * a y ∂(μ.map F) := by
  rw [integral_map hF.aemeasurable (by fun_prop)]   -- 推出测度
  have : ∀ x, a (θ' (F x)) * a (F x) = (a ∘ F) (θ x) * (a ∘ F) x := by
    intro x; rw [← hB1 x]; rfl
  simp_rw [this]
  exact hRP (a ∘ F) hRP'a                          -- 归结为细格点 RP
end YMStatement
```

要点：
- **零几何**：`hB1`（等变性）、`hB2`（半空间）是假设；形式化的工作量在**验证它们**（有限组合）。
- 真正的形式化难点在**细格点 RP**（`hRP` 的来源）：要么引用 OS/MP（需形式化群积分与特征标展开，Mathlib 目前不够），
  要么把 OS3 作为**结构字段**（与 `Basic.lean` 的 `SatisfiesAllOS` 一致），把本定理用作"该字段沿 RG 不变"的桥。
- **建议**：先做 `rp_descends`（纯测度论，几百行，0 sorry），再单独做 Route A/B 的等变性（有限组合，几千行）。

### 10.3 形式化的诚实边界

- Mathlib 缺：紧群上的 Haar 积分与 Peter–Weyl（部分有）、特征标展开的收敛性、格点规范的层分解。
  所以 **L1（OS/MP 定理本身）短期不可形式化**。
- 但 **L2–L5 可以**，且它们正是"OS3 是否活过 RG"的全部逻辑内容。这是一个**低成本、高价值**的形式化工件：
  它把 OS3 从"输入"变成"经 blocking 设计保证的定理"，而不触碰任何未解决的解析问题。
