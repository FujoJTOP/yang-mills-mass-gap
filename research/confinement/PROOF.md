## 1. 记号

- **盒**：`Λ_{L,a} ⊂ ℤ⁴`（边长 `L`、格距 `a`；有限、单连通；`C` 取可收缩环）。顶点、边（link）`E`、面（plaquette）`P`。QCD 标度另记 `Λ := Λ_QCD`（仅 §6，与盒不冲突）。
- **通量扇区**：周期边界；若为环面，**固定平凡 't Hooft 通量 `θ=0`**（否则 Wilson 环期望依扇区而变）。
- 连接变量 `U_e ∈ G`；积测度 `dU = ∏_{e∈E} dU_e`（Haar，归一化 `∫_G dU=1`，故 `∫ dU = 1`）。
- Plaquette 积 `U_p = ∏_{e∈∂p} U_e^{σ_{p,e}}`（`σ_{p,e}=±1` 为定向边界系数，沿 `∂p` 有序积）。
- 环 `C`：`W(C) = (1/d_f) tr_f ∏_{e∈C} U_e^{σ_e}`（Lie 群，`d_f=dim f`；`SU(N)` 时 `1/N`）；对 `Z_N`：`W(C)=∏_{e∈C}U_e^{σ_e}`（`U_e∈Z_N`，乘法）。
- 作用量权重 `e^{−S_β} = ∏_{p} f_β(U_p)`，其中 `f_β(U)=e^{(β/d_f) Re tr_f U}`（Lie 群；`SU(N)` 时 `β/N`，`β=2d_f/g²`）或 `e^{β Re U}`（`Z_N`，`Re` 取实部即 `cos(2πj/N)`）。
- `Z_{Λ_{L,a}}(β)=∫ e^{−S_β} dU`，`⟨W(C)⟩ = Z_{Λ_{L,a}}(β)^{−1} ∫ W(C) e^{−S_β} dU`。
- `Area(C)`：以 `C` 为边界的 2-链的最小 plaquette 数（矩形 `L×T` 时 `=LT`）；`Perim(C)=|C|`。

注：`f_β ≥ 0`，`Z_{Λ_{L,a}}(β) ≥ (min f_β)^{|P|} > 0`，故期望良定义。

## 2. 特征标展开（Lemma 1）

**引理 1（Peter–Weyl 展开）。** 设 `G` 紧致，`f_β` 为 `G` 上的类函数（共轭不变）且在 `G` 上实解析。则
```
f_β(U) = Σ_{R ∈ Irr(G)} c_R(β) χ_R(U),   c_R(β) = ∫_G f_β(U) \overline{χ_R(U)} dU,
```
级数**绝对一致收敛**。对有限群 `G=Z_N`，`R ∈ {0,…,N−1}`，`χ_k(j)=ω^{kj}`，和为有限和。

**证明。** `f_β` 在紧 Lie 群上实解析 ⇒ 其 Fourier 系数（关于 Peter–Weyl 基）指数衰减 ⇒ 展开绝对一致收敛（标准：解析类函数的 Peter–Weyl 级数一致收敛到自身；可用 Weyl 积分公式 + 热核算子光滑化证明）。有限群时 Peter–Weyl 退化为有限正交基，恒等。∎

**引理 1′（系数性质）。**
(a) 对 `β>0`，`c_R(β)>0`（所有 `R`）。
(b) 小 `β`：`c_triv(β)=1+O(β²)`，`c_f(β)=β/(2N)+O(β²)`（`f` 为基本表示），且 `c_R(β)>0` 对所有 `R`。

**证明（`Z_N`，完全）。** `c_k = (1/N)Σ_{j=0}^{N−1} e^{β cos(2πj/N)} ω^{−kj}`。被积函数 `e^{β cos}·cos(2πkj/N)` 型；`β>0` 时 `e^{β cos θ} = Σ_m I_m(β) e^{imθ}`（`I_m>0` 修正 Bessel），Poisson 重求和给出 `c_k = Σ_{m≡k (N)} I_m(β) > 0`（各项非负，至少一项 `>0`）。`β→0` 时 `I_0→1`，`I_m→0 (m≠0)`，故 `c_0→1`，`c_k→0`。定量：`I_k(β)=(β/2)^{|k|}/|k|!·(1+O(β²))`，`|k|:=min(k,N−k)`，故 `c_k/c_0 = (β/2)^{|k|}/|k|!·(1+O(β²))`。取 `γ_c :=` 使 `c_k/c_0 ≤ (c_1/c_0)^{|k|}` 对 `β<β₀` 成立（由 `1/|k|!≤1` 与 `1+O(β²)` 一致控制）。∎

（`SU(N)` 的 (a)(b) 是标准事实，见 Seiler LNP 159 附录；(a) 用 Weyl 积分公式中被积函数非负性，(b) 用 `Münster–Weisz` 型估计。§4 只需 `c_R≥0` 与 `c_f≤Kβ`。）

## 3. 阿贝尔情形：`Z_N` 面积律的完整证明（Theorem A）

本节自包含、严格。取 `G=Z_N`（`N≥2`），`ω=e^{2πi/N}`，所有和模 `N`。

### 3.1 精确曲面表示（Lemma 2）

**引理 2。** 对任意 `Z_N` 格点规范理论，
```
⟨W(C)⟩ = Z_{Λ_{L,a}}(β)^{−1} Σ_{c ∈ C₂(Λ_{L,a};Z_N): ∂c = [C]} ∏_{p∈P} c_{c_p}(β),          (3.1)
Z_{Λ_{L,a}}(β)  =            Σ_{c ∈ C₂(Λ_{L,a};Z_N): ∂c = 0}   ∏_{p∈P} c_{c_p}(β),          (3.2)
```
其中 `c = Σ_p c_p [p]`（`c_p∈Z_N` 为 plaquette 多重数），`∂` 为模 `N` 的链边界，`[C]` 为环 `C` 的 1-链。

**证明。** 令 `j_e ∈ Z_N` 为 link 变量（`U_e=ω^{j_e}`），`j_p := Σ_{e∈∂p}σ_{p,e} j_e` 为 plaquette 变量（由 `j_e` 线性决定，`Z_N` 可加性）。由引理 1，`f_β(ω^{j_p}) = Σ_{k_p} c_{k_p} ω^{k_p j_p}`。代入：
```
∫ W(C) ∏_p f_β(U_p) dU
 = Σ_{k:P→Z_N} (∏_p c_{k_p}) ∫ ω^{Σ_{e∈C}σ_e j_e} · ω^{Σ_p k_p j_p} ∏_e dU_e
```
指数中 `Σ_p k_p j_p = Σ_p k_p Σ_{e∈∂p}σ_{p,e} j_e = Σ_e j_e (Σ_{p∋e} k_p σ_{p,e})`。故每个 link 因子为
`(1/N)Σ_{j_e} ω^{j_e m_e} = δ_{m_e≡0}`，`m_e = Σ_{p∋e} k_p σ_{p,e} + σ_e 1_{e∈C}`。
`m_e≡0 ∀e` ⇔ 2-链 `c=Σ_p k_p[p]` 满足 `∂c + [C] = 0`，即 `∂c = −[C]`。以 `[C]→[C̄]`（反向）重定向，得 `∂c=[C]`（面积不变，下文取绝对值统一处理）。`k↔c` 是双射，故得 (3.1)。`Z_{Λ_{L,a}}` 同法、无 `W(C)` 因子，得 `∂c=0`，即 (3.2)。∎

注：`c_p` 可取 `0..N−1`，天然非负；`c_{k}` 实数非负（引理 1′），故**所有项非负**。

### 3.2 曲面计数（Lemma 3）

把 2-链的**面积**记为 `|c| := Σ_{p} |c_p|`，`|c_p|:=min(c_p,N−c_p) ∈ {0,…,⌊N/2⌋}`（模 `N` 的最短代表）。

**引理 3（动物增长界）。** 存在常数 `γ=γ(4,N)<∞`，使对每个 1-链 `ℓ` 与每个 `n≥0`，
```
#{ c ∈ C₂(Λ_{L,a};Z_N) : ∂c = ℓ, |c| = n } ≤ exp(γ n).
```

**证明。** 任一满足 `|c|=n` 的链，其支撑 `supp(c) := {p: c_p≠0}` 至多 `n` 个 plaquette。支撑是 plaquette 相邻图（对偶 `ℤ⁴` 的格点图）中的连通分支之并（若不连通，`∂c` 的各分量亦分离，故对固定 `ℓ`，可根在 `ℤ⁴` 中 `ℓ` 附近；粗略地，支撑总位于 `ℓ` 的至多 `n`-邻域，计数不受影响地并入动物计数）。4D 中 plaquette 邻接图的最大度 `Δ≤8`，大小 `≤n` 的连通动物数 `≤ (eΔ)^{n}`（标准动物增长：连通子集含固定根的数目满足 `a_s ≤ λ^s`，`λ<∞`；对度 `Δ` 的图可取 `λ=eΔ`）。多重数：每个支撑 plaquette 的 `c_p` 有 `≤N` 选择（`|c_p|` 决定代表符号），共 `≤N^n=e^{n log N}` 种。故总数 `≤ (eΔ)^n · e^{n log N}· n ≤ e^{γ n}`，`γ = log(eΔ) + log N + 1`。∎

（若要求严格，把"支撑在 `ℓ` 的邻域"替换为"把每个连通分支经 `ℓ` 投影到根"，动物界仍成立；细节标准。此界对 `ℓ`、`Λ_{L,a}` 均匀。）

### 3.3 面积律（Theorem A）

**定理 A。** 设 `G=Z_N`（`N≥2`）。则存在 `β₀>0` 与 `C_β<∞`，使对所有 `β∈(0,β₀)` 及所有可收缩环 `C`，
```
|⟨W(C)⟩| ≤ C_β · exp(−σ(β)·Area(C)),      σ(β) := −log(c₁(β)/c₀(β)) − γ > 0.
```

**证明。** 由 (3.1)(3.2)（取绝对值，项非负故可逐项放缩），把 `c₀` 从每 plaquette 提出：
```
num := Σ_{∂c=C} ∏_p c_{c_p} = c₀^{|P|} · Σ_{∂c=C} ∏_{p: c_p≠0} (c_{c_p}/c₀),
den := Σ_{∂c=0} ∏_p c_{c_p} = c₀^{|P|} · Σ_{∂c=0} ∏_{p: c_p≠0} (c_{c_p}/c₀),
```
**关键（消去体积因子与闭曲面；这是周长因子可去的理由）。** 任一 `∂c=C` 的链唯一分解为 `S_C ⊔ (闭分支)`：`S_C` 是唯一携带边界（`∂S_C=C`，`C` 单环）的连通分支，其余分支闭（`∂=0`）且与 `S_C` 不相交。约化权 `∏_{p:c_p≠0}(c_{c_p}/c₀)` 对不相交分支相乘，故对固定 `S_C`：
```
num_{S_C} := Σ_{∂c=C, 边界分支=S_C} ∏_{p:c_p≠0}(c_{c_p}/c₀) = w̃(S_C)·Z_closed^{(disj)}(S_C) ≤ w̃(S_C)·den,
```
其中 `w̃(S_C):=∏_{p∈S_C}(c_{c_p}/c₀)`，`Z_closed^{(disj)}:=Σ_{闭 c', supp c'∩S_C=∅}∏(c/c₀) ⊆ den`（非负子和）。对 `S_C` 求和再除以 `den`：
```
|⟨W(C)⟩| = num/den ≤ Σ_{S_C 连通, ∂S_C=C} w̃(S_C).
```
> 若改用粗界 `den ≥ c₀^{|P|}`，会残留体积因子 `V`（闭曲面位置），得不到均匀界——本步用精确相消替代之。

**再放缩。** 关键界 `w̃(S_C) ≤ (c₁/c₀)^{|S_C|}`：由引理 1′ 的 `c_{k}/c₀ ≤ (c₁/c₀)^{|k|}`（`β<β₀`）逐 plaquette 相乘。又 `∂S_C=C` 迫使 `m:=|S_C| ≥ Area(C)`（每单位面积至多消去单位边界；标准同调论证）。于是
```
|⟨W(C)⟩| ≤ Σ_{m≥Area(C)} (c₁/c₀)^m · #{S_C 连通, ∂S_C=C, |S_C|=m}
        ≤ Σ_{m≥Area(C)} (e^γ c₁/c₀)^m                         （引理 3，连通版）
        = (e^γ c₁/c₀)^{Area} / (1 − e^γ c₁/c₀) = C_β · exp(−σ(β)·Area(C)),
```
`C_β := (1−e^γ c₁/c₀)^{−1}`，`σ(β) := −log(e^γ c₁/c₀) = −log(c₁/c₀) − γ > 0`。因 `c₁/c₀ → 0`（`β→0`），存在 `β₀>0` 使 `e^γ c₁/c₀ < 1/2`，此时 `C_β ≤ 2`。∎

**推论 A′。** `Z_2` 规范理论（Ising gauge）：`σ(β) = −log(c₁(β)/c₀(β)) − γ ≈ −log(β/2) − γ`，全 `β<β₀` 面积律。此即 Wegner 结果的强耦合侧、自包含证明。

**评注。** (i) 定理 A 对任意维数、任意可收缩环、任意有限群成立（把 `Z_N` 换成任意有限群，`c_k` 换成不可约表示的 `c_R`，计数同理）。(ii) 此处 `σ = −log(c₁/c₀) − γ` 为上界速率；真实弦张力略大，但正值已足。(iii) **周长因子与体积因子均不出现，且已证可去**（上述闭曲面/体积精确相消 + 连通动物界）；故本定理是对文献周长版 `K^{|C|}e^{−σA}` 的**严格加强**，取 `K:=max(e^γ,2)` 即得周长版（`K^{|C|}≥2≥C_β`）。一般 `C` 时 `Area(C)` 取最小 2-链面积。

## 4. 非阿贝尔情形：`SU(N)`（Theorem B，归约）

对 `SU(N)`，(3.1) 的 link 积分不再退化为 `δ`，而给出表示指标的"收缩"，其正性与精确求和由 **Cao–Park–Sheffield**（arXiv:2307.06790）严格化；面积律的界则等价于 **Seiler 簇展开**（LNP 159；Osterwalder–Seiler, Ann. Phys. 110 (1978)）。本节给出与 §3 同构的论证骨架并精确指出所引定理。

**展开。** 由引理 1，
```
e^{−S_β} = ∏_p Σ_{R_p} c_{R_p} χ_{R_p}(U_p) = Σ_{R:P→Irr(G)} (∏_p c_{R_p}) ∏_p χ_{R_p}(U_p).
```
**Link 积分 = 收缩。** 对每条 link `e`，`∫_G dU_e ∏_{p∋e} χ_{R_p}(U_p^{±1})` 由 Schur 正交性给出：只有当 `e` 处入射 plaquette 的表示在张量积中"含不变量"时才非零，且其贡献有界。这迫使 `{R_p}` 在每条 link 处"闭合"，从而整体构成以 `C` 为边界的**表示加权曲面**。

**引理 2′（CPS 2023）。** 对 `SU(N)`，存在映射 `S ↦ w_β(S)`（`S` 以 `C` 为边界的嵌入曲面，允许亏格、自交），使
```
⟨W(C)⟩ = Σ_{S: ∂S=C} w_β(S),   0 ≤ w_β(S) ≤ ∏_{p∈S} c_f(β),
```
`c_f` 为基本表示系数、`c₀ := c_triv = ∫_G f_β dU = 1+O(β²)`（`SU(N)` 中**不**恒为 1），`|S|` 为 plaquette 数。因 `∏_{p∈S}c_f = (c_f/c₀)^{|S|}·c₀^{|S|}` 且 `c₀^{|S|}=e^{O(β²)|S|}`，可并入 `γ`（故速率以 `c_f/c₀` 表述，与定理 A 一致）。*[引用：CPS 定理；任意亏格嵌入曲面的精确正权表示。]*

**定理 B（`SU(N)` 面积律；条件于引理 2′ + 引理 3）。** 存在 `β₀>0`、`C_β<∞`、`σ(β)>0`，使 `β<β₀` 时对所有可收缩 `C`，
```
|⟨W(C)⟩| ≤ C_β e^{−σ(β)Area(C)},   σ(β) = −log(c_f(β)/c₀(β)) − γ > 0.
```

**证明（与 §3.3 同构）。** 由引理 2′ 与引理 3（曲面计数与 §3.2 相同，`SU(N)` 的表示多重数并入 `γ`）：
```
|⟨W(C)⟩| ≤ Σ_{n≥Area} (e^γ c_f/c₀)^n = (e^γ c_f/c₀)^{Area}/(1 − e^γ c_f/c₀) = C_β e^{−σ Area},  σ = −log(c_f/c₀) − γ.
```
`c_f/c₀→0`（`β→0`），故 `β<β₀` 时 `C_β<∞`、`σ>0`。∎

**评注。** (i) `SU(N)` 情形**没有完全自包含的初等证明**：障碍是 link 积分非 `δ`（§3.1 的阿贝尔化失效）。两条等价路线：(a) CPS 正曲面表示（本文引理 2′）；(b) Seiler 的 Kotecký–Preiss 簇展开（直接证面积律，不需显式曲面）。二者都是已发表定理，本文不重证。(ii) **无需 CPS 也能取上界**：用 `|∫ ∏χ| ≤ ∏(d_R)^{1/2}` 之粗界会得到 `σ>0` 但常数极差；严格且最优的常数需 CPS/Seiler。(iii) 逻辑结构（展开 → 曲面 → 计数 → 面积律）与 §3 **逐字相同**，这是"可形式化核心"。

## 5. 转移矩阵与扇区分离（Prop 5, 6）

### 5.1 谱表示（Prop 5a）

**命题 5a。** 设格点规范理论满足反射正性（OS3）。则存在正自伴转移矩阵 `T=e^{−aH} ≥ 0`（`a` 为格距），且对 `T̄×L` 矩形环（时间向 `T̄`、空间向 `L`），
```
⟨W(L×T̄)⟩ = ⟨A_L, T^{T̄} A_L⟩ / ⟨1, T^{T̄} 1⟩ = Σ_{n} |a_n(L)|² e^{−E_n T̄} / Σ_n e^{−E_n T̄},
```
`A_L = W(L×{t=0})` 为时刻 0 的空间闭环（规范不变算子），`a_n(L)=⟨n|A_L|Ω⟩`，`0=E_0≤E_1≤…`。

**证明。** 反射正性给出内积 `⟨A,B⟩ := ∫ (θA)^* B dU ≥ 0` 与 `T` 的存在（Osterwalder–Seiler；指标函数化为张量积）。时间平移对称 ⇒ `T` 自伴、`T≥0`，谱 `e^{−E_n}`。把 strip `0≤t≤T̄` 的测度分解为左/右半空间 × `T^{T̄}`，得 `⟨A_L,T^{T̄}A_L⟩`。对角化 `T` 得求和。∎

**推论 5b（面积律 = 弦基态能量线性增长）。** 定义**静势**
```
V(L) := −lim_{T̄→∞} (1/T̄) log⟨W(L×T̄)⟩.
```
则 `V(L) = inf_n{E_n(L)}`（在 `a_n(L)≠0` 上），且
```
面积律（定理 A/B）  ⇔  V(L) ≥ σ·L   对所有大 L。
```

**证明。** 由 5a，`T̄→∞` 时 `−（1/T̄)log⟨W⟩ → E_0(L)=inf E_n(L)`（主导项），即 `V(L)=E_0(L)`。面积律 `⟨W⟩≤C_β e^{−σLT̄}` 取 `−（1/T̄)log` 并令 `T̄→∞` 得 `V(L)≥σL`；反之由 `V(L)≥σL` 与有限 `T̄` 的指数修正得面积律。∎

### 5.2 质量隙是另一个量

**定义（MG）。** `Δ := inf spec(H|_{(ℂΩ)^⊥}) = inf_{n≥1} E_n(0)`，其中 `E_n(0)` 为**局域**规范不变算子（`C→0` 的 Wilson 环 / `tr F²` 等）的能级。`Δ>0` 即质量隙。

**关键区分**

| | 面积律 / `V(L)` | 质量隙 `Δ` |
|---|---|---|
| 算子 | 空间 L-环 `A_L`（尺寸 L，扩展） | 局域算子（`C→0`） |
| 对象 | `V(L)=E_0(L)`，`L` 大 | `inf E_n(0)`，`L→0` |
| 含义 | 静夸克对线性势（弦张力） | 胶球质量下界 |

`V(L)` 与 `Δ` 是 `E_n(L)` 在 **大 L 端** 与 **局域端** 的取值；二者无一般不等式。

### 5.3 逻辑独立（Prop 6）

**命题 6（非蕴含，显式模型）。** 面积律与质量隙互不蕴含。

**(a) 面积律 ⇏ 质量隙。** 取乘积理论 `μ = μ_{SU(N)} ⊗ μ_{U(1),free}`（纯 `SU(N)` 强耦合 × 自由 `U(1)` Maxwell）。取 `SU(N)` 因子上的 Wilson 环 `W_{SU(N)}(C)`：
- 面积律成立（定理 B 作用于 `SU(N)` 因子；`U(1)` 因子不参与，对其积分为 1）；
- 但 `U(1)` 光子无质量，`H` 谱在 `(0,∞)` 任意小能量有态，`Δ=0`。
故面积律真而质量隙假。〔严格性：乘积测度、`U(1)` Maxwell 的转移矩阵含无质量模——标准。〕

**(b) 质量隙 ⇏ 面积律。** 规范希格斯型（屏蔽）相：规范玻色子获得质量 ⇒ `Δ>0`；基本电荷被希格斯场屏蔽 ⇒ 静势 `V(L)` 饱和（周长律/常数），面积律假。〔4D 严格版依赖 "massive vector ⇒ 无基本静电荷" 的定理；物理标准，本文标注为半严格（见 §7 缺口 G2）。〕

**推论。** 完整解 = 面积律（`σ>0`）+ 质量隙（`Δ>0`）；Clay 只要求 `Δ>0`，故面积律是**独立、额外**的目标。

## 6. 连续统：条件定理（Theorem C）与 `σ/Λ` 不变量

### 6.1 弦张量的量纲 transmutation

纯 `YM₄` 唯一维量尺度为 `Λ`（渐近自由），故任何质量/张力均为 `Λ` 的纯数倍：
```
σ = c_σ · Λ²,     √σ = c_σ^{1/2} · Λ,
```
`c_σ` 为 **scheme-无关纯数**（单圈 `β` 函数：`Λ = μ e^{−1/(2b₀g²(μ))}`，`b₀ = 11 C₂(adj)/(48π²)`，`SU(N)` 时 `=11N/(48π²)`）。`c_σ>0` 恰为面积律的连续统内容。

**方案约定（与 `A0 §1.4` 对齐）**：`Λ` 所依赖的 scheme 变换 `g'²=g²+C g⁴` 的常数 `C` **与 `A0 §1.4` 的 `RT` 取同一 RT、同一 `C`**（本文不另立方案常数；`Λ'=Λ e^{C/(2b₀)}` 的 scheme 协变随之与 A0 一致）。

### 6.2 交接判据 `(H3_σ)`（与 MG 同构）

令 `σ(μ)` 为尺度-`μ` 有效弦张力，定义**不变量**
```
P(μ) := √σ(μ)/μ = (√σ/Λ)·(Λ/μ).
```
弱侧 `μ≫Λ`：`√σ≪μ` ⇒ `P→0`（RG 展开）；IR `μ→0`：`P→∞`（`√σ>0` 固定、`μ→0`）。`P` 连续严格单调。

> **(H3_σ)**：存在弱侧有效域边界 `μ_up`（`g²(μ_up)=g_*²`）使 `P(μ_up) ≥ P_1`（强侧边界值），其中 `P_1` 为强侧分析给出的 O(1) 阈值。

由 IVT，`(H3_σ) ⇔` 弱域 `[μ_up,∞)` 与强域 `(0,μ_*]` 的并覆盖 `(0,∞)`，即**每尺度都被覆盖**。这与 `physics_handoff.md` 的 `q(μ)=m/μ`、`q₀≥q₁` **逐字同构**，唯 `m → √σ`。

### 6.3 定理 C（条件）

**定理 C。** 假设：(i) 定理 A/B（格点面积律，强域）；(ii) 弱耦合格点 RG 在 `g²≤g_*²` 给出弦张量的一致控制（`SU(N)` 弱耦合 RG 步进，见 §7 G1）；(iii) `(H3_σ)`。则连续统测度 `μ` 满足 **定理 2**：
```
σ := −lim_{L→∞}(1/L) lim_{T̄→∞}(1/T̄) log|⟨W(L×T̄)⟩_μ| = c_σ Λ² > 0,
|⟨W(C)⟩_μ| ≤ C₁ exp(−σ·Area(C) + c·Perim(C)).
```

**证明骨架。** 由 (i) 强域给 `σ(μ)` 下界；由 (ii) 弱域给 `σ(μ)` 下界；由 (iii) 两域覆盖所有尺度 ⇒ `inf_μ σ(μ) ≥ σ_* > 0`；沿 RG 传输到固定物理盒子 ⇒ 面积律在 `μ` 上一致；取格距 `a→0` 的极限（`σ_lat·a²→σ_phys`）得定理 2。周长项来自静源自能（`c` 为重整化后有限常数）。∎

**诚实说明。** (iii) 是真正未解部分，且 (ii) 本身是开放（非阿贝尔 4D 弱耦合 RG）。故定理 C 是**结构定理**：它把连续统面积律归约为**一个交接不等式**，与 MG 归约到同一类不等式。
