# L3 — does ESI's single-`L` reduction (eq. 4.1) hold for non-abelian YM?

> CPB-attack probe. Verdict: **L3 does not close.** (Primary text read directly:
> ar5iv HTML of hep-th/0305200.)

## What the paper actually says

- It **targets non-abelian** YM (gauge group `G`, `f^{abc}`, Eq. 4.7).
- But the Furry / local-commutativity vanishing argument is **abelian-only**: the paper
  states plainly *"This last argument fails for a non-abelian gauge field"* (just after
  Eq. 4.7). So `⟨FFF⟩≠0` is **not** excluded for non-abelian.
- The non-abelian exclusion rests instead on **Wightman positivity + assumption (4.1)**,
  giving `−3a′ ≤ b ≤ a′/3` (Eq. 4.5) — a coefficient constraint, not a Furry argument.
- **Explicitly not completed:** the 5-point and 6-point analyses "have not been completed"
  (the 6-point is what would fix the structure constants).
- **Without (4.1):** positivity "appears to allow for an **open set** of the 5-dimensional
  (projective) parameter space." The authors call the non-abelian identification "rather
  indirect" and "necessarily non-perturbative (if it exists at all)." The model is "not
  incompatible with N=4 SYM."

## Verdict

**L3 does not close.** The abelian vanishing fails for non-abelian; the positivity route is
incomplete (5-/6-point missing); and without (4.1) an open interacting set survives. So the
anomaly route's step (iii) is **not established** by ESI for non-abelian YM — it is an
**assumption, not a lemma**.

## Boundary

Verdict from the primary text. The earlier "needs-indecomposable" is a sub-point (a field
in an indecomposable rep appears at Eq. 4.13), **not** the main gap; the main gap is that
**(4.1) itself is unproven for non-abelian**, and the paper's own hedge admits an open
interacting region.
