## 2. GL2a — θ-协变条件期望保持 RP

### 2.1 陈述

**设定。** 细测度 `μ` 满足 Osterwalder–Seiler 反射正性：对一切 `A ∈ C_RP^{(f)}`（只依赖 `t>0` 半空间连接的函数），

```
⟨θ_f A, A⟩_μ := ∫ (θ_f A)^* A dμ ≥ 0.                                    (RP_f)
```

`F : Config_f → Config_c` 为**确定性**分块映射（群平均，§1.7）。`μ_c = F_*μ`。

**几何前提（承重，全部内容是它们）：**

- **(B1) 反射协变** `F ∘ θ_f = θ_c ∘ F`；
- **(B2) 半空间分离** 块不跨越 `t=0`：`F^{-1}{粗格 t>0 的构型} ⊆ {细格 t>0 的构型}`。

**定理 GL2a.** 若 (B1)(B2) 成立，则对一切 `A ∈ 𝒜_c` 且 `A` 只依赖 `t_c>0` 的粗变量，

```
⟨θ_c A, A⟩_{μ_c} = ⟨θ_f (A∘F), A∘F⟩_μ ≥ 0.
```

故 `μ_c` 对 `θ_c` 反射正。更强：**RP 内积形式是拉回**，
`⟨θ_c A, B⟩_{μ_c} = ⟨θ_f(A∘F), B∘F⟩_μ` 对一切 `A,B ∈ 𝒜_c`。

### 2.2 证明（5 行，含 pushforward 唯一用到的地方）

1. 对一切**块可测** `Φ`（即 `Φ = Ψ∘F`），`∫_{μ_c} Φ dμ_c = ∫_μ Φ dμ`（pushforward 定义）。
2. `(θ_c A)∘F = A∘θ_c∘F = A∘F∘θ_f = θ_f(A∘F)`（用 (B1)）。两边都是块可测的（`θ_f` 保持 `𝒜_c`：见下）。
3. 由 (B2)，`A∘F` 只依赖细格 `t>0` 变量，故 `A∘F ∈ C_RP^{(f)}`，`θ_f(A∘F) ∈ C_RP^{(f)}`。
4. `(θ_cA)^*A` 块可测 ⇒ 用第 1 步：
   `∫_{μ_c}(θ_cA)^*A = ∫_μ (θ_cA∘F)^*(A∘F) = ∫_μ (θ_f(A∘F))^*(A∘F) ≥ 0`（用第 2、3 步与 (RP_f)）。∎

**附注（为什么"θ-协变的条件期望"是自动的，且这不是内容）。** (B1) 使 `θ_f 𝒜_c ⊆ 𝒜_c`、`μ` 的 `θ`-不变性使 `E θ_f = θ_f E`（`𝒜_c`-双模投影的唯一性）。故 `E` 自动是 θ-协变条件期望。**这不是假设，是 (B1) 的推论；§8.1 说的"conditional expectation is automatic"由此得到精确形式。** 同理 `T_c := E T_f E ≥ 0`（`T_f ≥ 0` 直接推出），`λ₁(T_c)=1`（常函数 `Ω ∈ 𝒜_c` 且被 `T` 固定），`‖T_c‖≤1`。**GL2a 的净输出就是这三条 + RP 本身。**

### 2.3 可判定判据（把"轴对齐"从启发式升为推论）

设粗格 `Λ' = Bℤ⁴`（间距 `b`，可倾斜 `B = 5R`），细格 `ℤ⁴`，反射 `θ_f(x) = Ax+v`（`A∈O(4)`，`v∈ℝ⁴`）。

**命题（判据的充要形式）。** (B1) 成立 ⇒ `θ_f(Λ') = Λ'`，等价于

```
(线性部分)  AΛ' = Λ'        ⟺  A ∈ W ∩ R W R⁻¹        （当 Λ' = bRℤ⁴）
(位错部分)  v ∈ Λ'
```

**必要性证明（一行半）。** `F(x+b) = F(x)+τ(b)`（分块的平移协变性）与 (B1) 强制 `τ(Ab) = M'τ(b)` 对一切 `b∈Λ'`，故 `AΛ' ⊆ Λ'`；`A` 正交、`Λ'` 是格 ⇒ 用指数（covolume）相等得 `AΛ'=Λ'`。`A∈W` 来自 `θ_f` 须是**细格**的自同构；`A ∈ RWR⁻¹` 来自 `AΛ'=Λ'` 且 `Λ'=bRℤ⁴` ⇒ `R⁻¹AR ∈ GL₄(ℤ) = W`（因 `R⁻¹AR` 正交且整）。位错项：`θ_f(x+b) = Ax+v+Ab`，`v` 须落在 `Λ'` 才能使 `θ_f` 把格映到格。

> **对契约的小修正**：§6.2 的判据只写了 `A ∈ W ∩ R W R⁻¹`（线性部分）。**位错条件 `v ∈ Λ'` 必须一并要求**，否则"反射面落在块边界上"（§1.7 约束 1）未被判据覆盖。这是 os3 的 Route A（奇 L + 位移 `s₀=(L−1)/2`）与 Route B（site-plane）分别处理的正是同一个 `v` 条件。
>
> **充分性**还要加一条**路径级**条件：`F` 的群平均所用路径族必须**反射封闭**。这是有限组合，不是分析；os3 对线性分块逐链核验过，**对 §1.7 的"面平均 + 平行移动"分块尚未核验**（见 §2.6）。

## 3. GL2b — 隙传输：判决而非证明

> **任务的关键要求：不要重复写反的方向。** 下面把"哪个对象"钉死，然后说明为什么**需要的方向在一般情况下为假**。

### 3.1 三个必须分开的对象（混淆它们正是 R17 的根源）

| 对象 | 定义 | 备注 |
|---|---|---|
| `T_f` | 细转移矩阵，`0 ≤ T_f ≤ 1`，`λ₁=1`，`Δ_f := −(1/a)·log λ₂(T_f)` | RP ⇒ 自伴正 |
| `T_c^{comp}` | **压缩** `E T_f^b E` 限制在 `𝒜_c` 上；`μ₂ := λ₂(T_c^{comp})`；`Δ_c^{comp} := −(1/(ba))·log μ₂^b = −(1/a)·log μ₂` | 这是交错定理作用的对象 |
| `T_c^{marg}` | **精确边缘** `μ_c = F_*μ` 自身的转移矩阵 | 这是"精确 RT"的对象 |

**R17 的错误 = 把两者等同**（对 `T_c^{comp}` 引交错，却读作 `T_c^{marg}` 的结论）。下面证明：**两者给出同一个方向，而且方向不利。**

### 3.2 Lemma 1（Cauchy 交错，只给一个方向）

设 `𝒜_c ⊆ L²(μ)` 是闭子空间，`T ≥ 0` 有界自伴。用变分刻画 `λ_k(T) = sup_{dim V=k} inf_{0≠ψ∈V} ⟨ψ,Tψ⟩/‖ψ‖²`。因 `𝒜_c` 上的 `k` 维子空间是 `L²(μ)` 上子空间的**子族**：

```
μ_k := λ_k(ET^bE|_𝒜c) ≤ λ_k(T^b) = λ_k(T)^b        (T≥0 ⇒ λ_k(T^b)=λ_k(T)^b)
```

特别 `μ₂ ≤ λ₂(T)^b`，故

```
Δ_c^{comp} = −(1/(ba))·log μ₂ ≥ −(1/(ba))·log λ₂(T)^b = Δ_f.
```

（`verify.py`：4×4 对角例，`λ₂=0.5` 恒等成立，`μ₂∈{0.5,0.25,0.1} ⇒ Δ_c∈{0.693,1.386,2.303} ≥ Δ_f=0.693`。）

**这就是"粗粒化抬高隙"的精确形式。** 对需要 `Δ_f ≥ δ` 的论证，`Δ_c ≥ δ` 是**上界**，无用。

### 3.3 Prop 2（尖锐性：不等式在另一个方向无信息）

对任意 `M>0` 存在例子使 `Δ_c^{comp} − Δ_f ≥ M`：取 `H_f = ℝ³`，`T = diag(1, λ₂, 0)`，`𝒜_c = ⟨e₁,e₃⟩`。则 `μ₂ = 0`，`Δ_c^{comp} = +∞`。

**推论（判决）。** **不存在**形如 `Δ_c ≤ Δ_f + C`（任何 `C`）的普适不等式；也不存在 `Δ_c^{comp} = Δ_f`，除非加假设。**故 GL2b 需要的"下界传输"不是一个待补证明的定理，而是一个在没有额外假设时为假的命题。** 这条负结果本身就是 GL2b 的交付物：它**杀掉**一整类错误路线。

### 3.4 Prop 3（等号条件 = "精确 RT" 的精确含义）

`μ₂ = λ₂(T)^b`（即 `Δ_c = Δ_f`）**当且仅当**两个最慢模落在 `𝒜_c` 内（visibility 假设）。

- 对 `T_c^{marg}` 同理：`Δ_c^{marg}` 是**块可观测关联**的衰减率；因块可观测类 ⊆ 全类，**衰减率的 inf 只能变大**，故 `Δ_c^{marg} ≥ Δ_f`，等号需 visibility。
- **因此契约 §3.1(a) 的"精确 RT ⇒ 物理隙严格不变"必须写成**："精确 RT ⇒ **块可观测**的关联函数不变 ⇒ 其衰减率不变"；而"物理隙"（全类的最小衰减率）只有在 **visibility** 下才与块可观测的相同。**分块不是变量替换**（它是多对一的积分掉/投影），所以 (a) 的"变量替换的逆"这一措辞是 R17 措辞层面的残留。

**判决**：`Δ_coarse ≥ Δ_fine` **在所有读法下都成立**；等号是一个**可用物理判据检验的假设**（低频模在块算符上的重叠非零），不是 RG 精确性的推论。

### 3.5 Prop 4（截断误差控制**不能**翻转方向）

设截断理论给出 `T^{tr}` 且 `‖T^{tr} − T_c^{comp}‖ ≤ ε < μ₂`。Weyl 扰动 + `|log x − log y| ≤ |x−y|/min(x,y)`：

```
|Δ_c^{tr} − Δ_c^{comp}| ≤ (1/(ba)) · ε/(μ₂ − ε).
```

结合 Lemma 1：

```
Δ_c^{tr} ≥ Δ_f − (1/(ba))·ε/(μ₂ − ε).        ← 仍是上界
```

（`verify.py`：`μ₂=0.5, ε=0.1`，界 `0.25`，实际 `0.223` —— 界正确而紧。）

**结论**：**"the truncated needs error control" 若被读作"误差控制之后方向就对了"，那是错的。** 误差控制让**等号情形**（visibility 成立时）稳健，仅此而已。**没有任何 `ε` 能产生 `Δ_c ⇒ Δ_f` 的下界。**

### 3.8 GL2b′ — 具名蕴含（**已证**）

协调方要求把 `Δ_cont ≥ liminf_{a→0} Δ_a` 记成可记账的一条。给 **(a) 蕴含的证明** + **(b) 必要性反例**；后者说明输入不可省，且 **GL3 在原理上无法提供它**。

**设定（固定 L，§1.6 阶段 1）。** `T_a` 细转移矩阵，`0 ≤ T_a ≤ 1`，`T_a 1 = 1`。在 `1^⊥` 上令
```
H_a := −(1/a)·log T_a          （谱演算；log 0 := +∞）
Δ_a   := inf{ λ ∈ σ(H_a) : λ > 0 }
Δ_cont := inf{ λ ∈ σ(H)   : λ > 0 }        （H = 连续统哈密顿量）
```

**具名输入 `SPEC-RES`（谱收敛）。** 在 `1^⊥` 上 `H_a` 自伴、`≥ 0`、一致下有界，且 `H_a → H` **强预解收敛**：
`(H_a − z)^{-1}ψ → (H − z)^{-1}ψ` 对所有 `ψ`、`Im z ≠ 0`。（Trotter–Kato：等价于 `e^{−tH_a} → e^{−tH}` 强收敛，`∀t>0`。）

**定理 GL2b′（已证，4 行）。** `SPEC-RES ⟹ Δ_cont ≥ liminf_{a→0} Δ_a`。

*证明.* 强预解收敛 ⇒ `σ(H) ⊆ limsup_a σ(H_a)`（Reed–Simon I, Thm VIII.24(b)：每个 `λ ∈ σ(H)` 都是某列 `λ_a ∈ σ(H_a)` 的极限）。若 `{λ∈σ(H): λ>0}` 非空，则其下确界 `Δ_cont` 属于该（闭）集；若为空则 `Δ_cont = +∞`，结论平凡。故 ∃ `E_a ∈ σ(H_a)`，`E_a → Δ_cont`。而 `Δ_a` 是 `σ(H_a)` 正部分的下确界 ⇒ `Δ_a ≤ E_a`。取 `liminf`：`liminf Δ_a ≤ liminf E_a = Δ_cont`。∎

**是 `≥`，不是 `=`（严格性可行）。** `H = diag(1,3)`，`H_a = diag(1−ε_a, 3)`，`ε_a ∈ [0, 1/2]` 有一列 `→ 1/2`。则 `‖H_a − H‖ → 0`（强预解必成立），而 `liminf Δ_a = 1/2 < 1 = Δ_cont`。**消费者只可用 `≥`；引用"等于"即过度声称。**

**必要性（反例；同时排除 GL3 供给本引理）。** 取 `T_a = diag(1, e^{−c₁a}, e^{−c₂a})`，`0 < c₁ < c₂`。则 `‖T_a − I‖ → 0`——**任何** Schwinger 函数都平凡收敛，GL3 在此被完全满足——但 `Δ_a = c₁` 对**一切** `a`；把 `c₁` 换成 `c₁'` 得到**同一个极限** `I` 与**不同的隙**。更强：`T_a ≡ diag(1, e^{−c}, e^{−c})` 给 `Δ_a = c/a → ∞`，而 `T_a = diag(1, e^{−c'a}, e^{−c'a})` 给 `Δ_a = c'`；两者可安排成同一极限。

> **⇒ 极限（弱/分布/范数）不编码 `Δ`；编码它的是 `a=0` 处 `log T_a` 的 `O(a)` 项。** 故 **GL3（关于极限的陈述）在原理上不能推出 GL2b′**；`SPEC-RES` 是逻辑上**必需**的独立输入。它是"谱集 Hausdorff 收敛"的**弱化版**：后者（或范数预解收敛）给等号，更强也更难，不是我们需要的。

**与其他具名输入的接口（防止标签漂移）。**

| 输入 | 能否充当 `SPEC-RES` | 说明 |
|---|---|---|
| 范数预解 / 谱集 Hausdorff 收敛 | 能（更强，给 `=`） | 不必要；更难证 |
| **`E_0(n)` 收敛** | **不能单独** | `E_0(n)` 属**弦扇区**；而 `Δ = min_ρ m_ρ^{(1)}`（`mass-spectrum`）。一个参项的收敛只给 `Δ` 的**上界**方向，除非补"中性扇区 `m_ρ^{(1)}` 收敛 + `min_ρ` 的通道控制" |
| GL3（`S^{(n)}` 收敛） | **不能**（见上反例） | 是"极限"信息，不是"`O(a)` 速率"信息 |

**记账**：`SPEC-RES ⟹ GL2b′` 是 **✅-蕴含**（消费 `SPEC-RES`，不是新定理）。`SPEC-RES` 本身**不在 16 输入内**，状态开放。它与 GL2b 的关系见 §3.6：GL2b′ **替换** GL2b，且**没有 visibility 问题**（不做粗粒化，只做同一理论的 `a→0` 谱极限）。

### 4.1 陈述

### 4.2 运动学引理（**已证**，两条路线共用）

**(a) "格点对称 + 连续性"单独不够。** `W` 的旋转部分有限（阶 384）且**闭**，`\overline{⟨W⟩} = W`。故任何形如"极限继承 `⟨W⟩` 的闭包"的陈述是**同义反复**。OS2 必须有第二个、动力学性的成分。——**这是 R2 的空洞性陷阱的精确来源。**

**(b) 维数分类（定理）。** 纯 YM 中，**不存在** `H_hyp`-不变、规范不变、`O(4)`-破缺、维数 `< 6` 的算子。

*证明。* 维数 `<4` 的规范不变标量只有常数（无非各向异性）。维数 4 的候选是 `F` 的二次型：`Λ²ℝ⁴` 上二次型空间 21 维，`H_hyp = (ℤ/2)⁴ ⋊ S₄` 作用。`S₄` 的换位 `(0 1)` 把"含时间对"族 `{(01),(02),(03)}` 与"纯空间对"族 `{(12),(13),(23)}` **互换**（`verify.py` 显式给出：`{(01),(02),(03)} ↦ {(01),(12),(13)}`）。故 `S₄`-不变的二次型只能给**两族相同权重**，即 `α·Σ_{所有六对} = α·tr F²`（`O(4)`-不变）。`F\tilde F` 是 `O(4)`-不变且 `P`-奇，被 `θ=0` 排除。∎

- **(c) 路线 A**：倾斜（`5R`）正则化与轴对齐正则化外推出的连续统局域可观测**必须相等**。若相等是"自动的"（同义反复读法），则该检验**恒真而无诊断力**——这本身就是判断 A 是否有内容的元检验。
- **(d) 陈述层**：任何"极限在 `W` 的闭包下不变"的表述是空洞的（§4.2a）。**合格陈述必须点名 `O(4)` 的一个不在 `W` 中的元素**（例如 `R₁₂(3/5,4/5)`）并断言其不变性。

### 4.7 GL5 台账：一条 ✅ + 一条具名蕴含（按协调方要求拆分）

#### 4.7.1 `GL5-KIN` — **✅ 严格**，独立于任何开放问题


**两点必须记账，否则 `SYM-DIM4` 记成 ✅ 会过度覆盖：**

1. **`SYMDim4.lean` 的 scope 注释明确把 `OP-CLASS` 划在文件之外**：*"the step from 'coefficient tensor is a multiple of δ' to 'the dimension-four effective action has no anisotropy' is physics, and is deliberately NOT formalised here."* 故 `GL5-KIN` 是**两段**：第一段已 Lean；第二段（算子分类）由本 session 用 `S₄`-轨道换位补上并机器核验，**Lean-able（约 30 行）**。
2. **`SYM-DIM4` 覆盖的是 4×4（矢量表示）情形**，而 dim-4 规范不变算子需要 `Λ²ℝ⁴` 上（6 维/21 维）的二次型分类。**二者不可互推**；本文件给的是后者。

> **反证力（防止陈述层空洞化，R2 陷阱）**：若格点只保 `(ℤ/2)⁴ ⋊ S₃`（时间被区分），两族**不再互换**（`verify.py` 显式给出：`(2 3)` 作用后两族各自固定），dim-4 各向异性算子**存在**，物理实现即**各向性格点 YM**（`β₀ ≠ βᵢ`）——它有优先标架、极限非 `O(4)`-不变。**故 `S₄` 中"时间-空间换位"是承重的，`GL5-KIN` 不是空洞陈述。**

#### 4.7.2 `GL5-DYN` — **✅-蕴含**：`IN-2 (U2) ⟹ OS2`

```

```

- **平移部分是免费的**：`S^{(n)}` 在 `aℤ⁴` 平移下不变、`a→0` 时 `aℤ⁴` 稠密、`S^{(n)}` 分布连续 ⇒ `ℝ⁴` 平移不变。**唯一内容是旋转部分。**
