## 1. 共享构造的规范形式（引用 A0 §1，不重定义）

以下逐字使用 A0 §1 的记号。唯一需要显式化的是"测度只依赖哪个组合"：

```
μ_{L,a,β}  ∝  exp(−S_W(β)) ∏_e dU_e ,
S_W(β)     =  β Σ_p (1 − (1/N_c) Re tr U_p) ,      β = 2N_c/g² ,
⟹  μ_{L,a,β}  ∝  exp( (β/N_c) Σ_p Re tr U_p ) ∏_e dU_e .        (1.1)
```

归一化因子 `exp(−(β/N_c)·#P)` 与组态无关，在 `Z` 中相消。因此**进入测度的唯一参数**是

```
γ := β / N_c          （Σ_p Re tr U_p 的系数）。                  (1.2)
```

GL1 的全部数学内容就是：九个接口写出的权重，其 `γ` 是否都等于 `(1.2)`，以及不等时如何换。

> **约定（必须声明）**：本报告把 `tr` 读作**未归一化的定义表示迹**（`SU(N)` 的 `tr_f 1 = N`），`N_c := dim f`。若某 session 本意是归一化迹 `tr/N_c`，它的 `β` 就不是 A0 的 `β`。§2.3 的判定以此读法为准，并在表中注明。

## 2. GL1 — 单一测度族

### 2.1 精确陈述

**定义 GL1-shared（单一族）。** 一个接口 `I` 使用共享族，若存在 A0 §1 的数据
`(G̃, L, a, N=L/a, Λ_{L,a}, E(Λ), dU, S_W, RT(C))`，使得 `I` 的测度槽、`β`、`RT` 分别为
`μ_{L,a,β(a)}`、`β(a) = 2N_c/g²(a)`、同一条 `RT(C)`，且 `I` 中所有量都是该族的泛函。

**引理 GL1-dict（归一化字典）。** 设一个 session 写出的权重为
`exp(−S_s)`，其中 `S_s` 在 `Σ_p Re tr U_p` 上的系数为 `γ_s`（即 `−S_s = γ_s Σ Re tr + const`）。
则它的概率测度等于 `μ_{L,a,β}` 当且仅当

```
γ_s = β/N_c      ⟺      β_s = β                                   （若它用 (β/N_c)(1−χ) 形式）
                 ⟺      β_s = β/N_c                               （若它用 β_s χ 形式，χ 未归一化）.
```

**验收判据（A0 §8 C1/C2）**：九个 session 的 §1 逐条引自 A0 §1，无本地变体。本报告用**逐行 diff**执行它，而不是"显然同一测度"。

### 2.2 证明（字典引理）

`−S_s = γ_s Σ_p Re tr U_p + c_s(U)`，其中 `c_s` 与组态无关（只依赖 `β_s, #P, N_c`）。于是
`exp(−S_s) = e^{c_s} · exp(γ_s Σ Re tr)`。两个这样的权重给出同一概率测度当且仅当 `γ_s` 相同（`e^{c_s}` 在 `Z` 中相消）。对 A0 的 `(1.1)`，`γ = β/N_c`。∎

> 这一步是**平凡的**，但它是 GL1 唯一真正的"数学"；GL1 的困难不在证明而在**逐行核对**。`gl1_check.py` 用 S₃ 格点（`dim f = 2`）精确验证：`γ_s = β_s`（os3 形式）与 `γ = β_A0/2` 的权重之比**逐组态常数**（最大相对偏差 `2.05e−16`），从而归一化期望相等；而同一数值 `β_s = β_A0` 给出不同的期望（差 `0.310`）。

## 3. GL6 — 规范固定无关性

### 3.1 精确陈述

**GL6-F（有限格点，离散）。** 设 `X` 有限，`Γ` 有限群作用在 `X` 上，`μ: X → ℝ_{≥0}` 是 `Γ`-不变权重，`F` 是 `Γ`-不变函数。设 `A ⊆ X` 与每个轨道相交，`m(a) := |A ∩ Γa|`。则

```
Σ_{x∈X} F(x) μ(x)  =  Σ_{a∈A} F(a) μ(a) · |Γa| / m(a).            (3.1)
```

**GL6-C（紧群，轨道空间）。** 设 `Γ` 紧、`X` 紧度量、`μ` 为 `Γ`-不变 Borel 概率测度，`π: X → X/Γ`。则 `μ̄ := π_*μ` 是 `X/Γ` 上的概率测度，且对每个 `Γ`-不变 `F ∈ L¹(μ)`，

```
∫_X F dμ  =  ∫_{X/Γ} F̄ dμ̄ ,      F̄(ω) := F(ω 的任意代表元).        (3.2)
```

**GL6-FP（带号 FP 权重）。** 对 gauge condition `σ`（正则水平集），

```
∫_X f dμ  =  ∫_{σ=0} f · Δ_FP dμ_σ ,      Δ_FP = Σ_{copies} sign det(∂σ/∂ω) / |det(∂σ/∂ω)| .
```

**GL6-RG（RG 兼容引理）。** 设 `Φ: X_Λ → X_{Λ'}` 精确等变：存在满同态 `b: Γ_Λ → Γ_{Λ'}` 使
`Φ(g·U) = b(g)·Φ(U)`；`μ` 为 `Γ_Λ`-不变，`ν := Φ_*μ`。则：
(i) `ν` 是 `Γ_{Λ'}`-不变；
(ii) `Φ` 下降为 `Φ̄: X_Λ/Γ_Λ → X_{Λ'}/Γ_{Λ'}`，且 `ν̄ = Φ̄_* μ̄`；
(iii) 对每个粗格点规范不变 `F`，`∫ F dν = ∫ (F∘Φ) dμ`，故 `⟨F⟩_ν` 只依赖 `μ̄`；
(iv) 迭代：`μ̄_n = Φ̄_{n*} μ̄_0`，全程无规范选择；
(v) 若 `Φ` 只近似等变（缺陷 `δ(g,U) := Φ(g·U)·(b(g)Φ(U))^{-1}`），则 `ν` 的不变性缺陷满足
`|∫ f(h·V)ν(dV) − ∫ f dν| ≤ 2‖f‖_∞ sup‖δ−1‖`，轨道空间映射只在此误差内良定义。

**GL6-B（Balaban 内部固定可去）。** 若内部计算用某个 gauge-fixing `T` 计算规范不变的量，且 `T` 是 GL6-FP 意义下正确的（带号 FP 权重、对所有拷贝求和），则 `T` 的输出等于 (3.2)/(iii)；故内部固定不进入最终陈述。

### 3.2 证明

**GL6-F。** 第一步：`μ` 在轨道上常数。若 `y = g·x`，则 `μ(y) = μ(g·x) = μ(x)`（不变性）。第二步：按轨道分块。设轨道 `ω`，`h := |ω|`，`k := |A∩ω|`，取 `a₀ ∈ A∩ω`。左端 `ω` 的贡献是 `h·F(ω)·μ(a₀)`；右端是 `k·F(ω)·μ(a₀)·(h/k) = hFμ`。逐轨道相加即得 (3.1)。∎

**推论 3.1（截面无关）**：右端与 `A` 无关（都等于左端）。取 `A` 为基本域（`k=1`），权重 `|ω|` = 轨道体积 = FP 行列式。取 `A` 为多值截面（`k>1`），权重 `|ω|/k` 是"拷贝修正后的 FP 行列式"。

**推论 3.2（Gribov 错误的精确形式）**：若对多值截面丢掉 `/k`，得到 `Σ_ω F(ω)μ(ω)k(ω)`。当 `k` 在轨道间非常数时它不等于左端。**这就是"只取第一 Gribov 区 + |det|"失败的原因**：`k` 不是常数，符号/多重度必须保留。

**GL6-C。** `π` 固有（`Γ` 紧），故 `π_*μ` 是概率测度；对不变 `F`，`F = F̄∘π` `μ`-a.e.，用 pushforward 的积分公式即得 (3.2)。不需要截面。∎

**GL6-RG。** (i) 对 `h ∈ Γ_{Λ'}` 取 `g` 使 `b(g)=h`（满射），对连续有界 `f`：
`∫f(h·V)ν(dV) = ∫f(h·Φ(U))μ(dU) = ∫f(Φ(g·U))μ(dU) = ∫f(Φ(U))μ(dU) = ∫f dν`。
(ii) `π'∘Φ` 在 `Γ_Λ` 下不变，故下降；对 Borel `B ⊆ X_{Λ'}/Γ_{Λ'}`，
`ν̄(B) = ν(π'^{-1}B) = μ(Φ^{-1}π'^{-1}B) = μ(π^{-1}Φ̄^{-1}B) = μ̄(Φ̄^{-1}B)`。
(iii) 立即。(iv) 归纳。(v) 由 `|f(h·V)−f(V)| ≤ 2‖f‖_∞` 与 `δ` 的定义逐点估计。∎

**GL6-B。** 由 GL6-FP，`T` 对每个不变 `F` 给出 `∫F dν`；由 GL6-RG(iii)，这与 `∫(F∘Φ)dμ` 相同；后者不含任何规范选择。∎

## 4. GL8 — 群一致常数

### 4.1 精确陈述（按 GL9 先例拆成"组装 / 供给"）

**GL8-A（组装，无条件 ✅）。** 对群类 `𝒢` 中每个 `G`，设 `HandoffData` 成立：四常数 `q₀(G), q₁(G), δ_W(G), δ_S(G)`，单调函数 `q_G, g²_G`，`0 < q₁(G) ≤ q₀(G)`，`q_G(μ_up)=q₀`，`q_G, g²_G` 在 `(0,∞)` 严格反单调，且

```
H1(G): ∀μ>0, g²_G(μ) ≤ g²_G(μ_up)  ⟹  δ_W(G) ≤ cert_G(μ),
H2(G): ∀μ>0, q₁(G) ≤ q_G(μ)        ⟹  δ_S(G) ≤ cert_G(μ).
```

则 `∀G ∈ 𝒢, ∀μ>0, min(δ_W(G), δ_S(G)) ≤ cert_G(μ)`，且 `min(δ_W(G), δ_S(G)) > 0`。**类型：无条件定理**（只依赖 `HandoffData` 的字段，不依赖任何未证估计）。

**GL8-S（常数供给，✅-蕴含）。** 设对每个 `G ∈ 𝒢`：

```
IN-3(G): ∃λ_w(G)>0, δ_W(G)>0, ∀μ>0, λ_G(μ) ≤ λ_w(G) ⟹ cert_G(μ) ≥ δ_W(G)   （弱侧 = CPB-W）
IN-4(G): ∃q₁(G)>0,  δ_S(G)>0, ∀μ>0, q_G(μ) ≥ q₁(G)  ⟹ cert_G(μ) ≥ δ_S(G)   （强侧 = CPB-S）
```

则 `∀G ∈ 𝒢, min(δ_W(G), δ_S(G)) > 0`。**类型：✅-蕴含**——前件是命名输入 `IN-3 ∧ IN-4`（`docs/conditional-theorem.md` §3），本文件**不证明**它们；`bound` 字段正是 H1/H2。

**GL8-U（类一致）。** 存在与 `G` 无关的 `δ > 0` 使 `∀G, min(δ_W(G), δ_S(G)) ≥ δ`。

**三点澄清**：

1. **"四常数未供给"不是 GL8 的缺口，而是输入 `IN-3`/`IN-4`。** `IN-3`（弱侧类保持，含 `RB2/NPB`）与 `IN-4`（强侧 signed gas）在 `docs/conditional-theorem.md` §3.3–3.4 已命名；GL8 只做两件事：**组装**（A）与**从供给读正性**（S）。`IN-3` 是唯一的物理墙（`CPB-W`），属 `handoff-proof`，不属 glue-c。
2. **`overlap : q₁ ≤ q₀` 是 `IN-5`，不在 `IN-3/IN-4` 里。** GL8-A 的**覆盖结论**需要它；GL8-S 的 `min>0` 不需要。消费清单见 §4.2b。
3. **GL8-U 不由 GL8-A/S 推出**（反例 `δ_W = δ_S = 1/(n+1)`，逐点正、下确界 0）。它是 `IN-8` 的类一致版本，需要 `IN-3/IN-4/IN-5` 的**台账一致**，不是新的分析内容。A0 §2.6 的 `S1/S2/S3` 三强度正是这个区分。

### 4.2a 证明：GL8-A 群盲组装（无条件 ✅，Lean 已编译）

```lean
    ∀ μ, 0 < μ → min D.δW D.δS ≤ cert μ

theorem uniform_over_groups {ι : Type*} (D : ι → HandoffData) (cert : ι → ℝ → ℝ)
    (hW : ∀ (i : ι) (μ : ℝ), 0 < μ → (D i).gsq μ ≤ (D i).gsq (D i).μup → (D i).δW ≤ cert i μ)
    (hS : ∀ (i : ι) (μ : ℝ), 0 < μ → (D i).q1 ≤ (D i).q μ → (D i).δS ≤ cert i μ) :
    ∀ (i : ι) (μ : ℝ), 0 < μ → min (D i).δW (D i).δS ≤ cert i μ

theorem min_pos {a b : ℝ} (ha : 0 < a) (hb : 0 < b) : 0 < min a b

theorem class_uniform {ι : Type*} (D : ι → HandoffData) (δ : ℝ)
    (hδ : 0 < δ) (h : ∀ i, δ ≤ min (D i).δW (D i).δS) :
    ∀ i, 0 < min (D i).δW (D i).δS

/-- IN-3 / IN-4 as named inputs; `bound` is not proved here. -/
structure WeakSideInput where
  cert : ℝ → ℝ; lam : ℝ → ℝ; δW lamw : ℝ
  δW_pos : 0 < δW; lamw_pos : 0 < lamw
  bound : ∀ μ, 0 < μ → lam μ ≤ lamw → δW ≤ cert μ

structure StrongSideInput where
  cert : ℝ → ℝ; q : ℝ → ℝ; δS q1 : ℝ
  δS_pos : 0 < δS; q1_pos : 0 < q1
  bound : ∀ μ, 0 < μ → q1 ≤ q μ → δS ≤ cert μ

/-- GL8-S (✅-implication): IN-3 ∧ IN-4 supply (δW, δS) for each G. -/
theorem supply_min_pos {ι : Type*}
    (W : ι → WeakSideInput) (S : ι → StrongSideInput) :
    ∀ i, 0 < min (W i).δW (S i).δS
```

证明（手写）：对每个 `i`，若 `μ ≤ μ_up`，`q_antitone` 给 `q μ ≥ q μ_up = q₀ ≥ q₁`，由 `hS` 得 `δ_S ≤ cert μ`；若 `μ > μ_up`，`gsq_antitone` 给 `gsq μ ≤ gsq μ_up`，由 `hW` 得 `δ_W ≤ cert μ`。`min` 取两者较小，域 `(0,∞)` 被覆盖。∎（`supply_min_pos` 的证明是一行 `min_pos`，其内容不在证明而在**类型**：前件是 `IN-3/IN-4`。）

**为什么这算 GL8**：证明的**陈述**从不提及 `ι`。群只通过四个标量进入；结论 `min δ_W δ_S ≤ cert μ` 不含群数据。这就是"无隐藏 `G` 依赖"的证书（`group-uniformity` §9.2 N1）。**GL8 的内容是"组合是群盲的" + "供给读出正性"，不是"四常数逐群成立"**——后者是 `IN-3/IN-4`。

**公理足迹**：`#guard_msgs` 冻结为 `[propext, Classical.choice, Quot.sound]`（`check-glue-c.sh` 强制）。无 `sorry`。

### 4.4 常数表与数值判决

`C_RG := 24π²/11 = 21.5337…`（唯一真源；`t_up = C_RG/λ*`，`λ*_G = h^∨ g*²`）。取 `m/Λ = 8`、`q₁ = 1`：

|---|---:|---:|---:|---:|---:|---|

| `SU(3)` | 3 | 3 | 3 | 7.178 | `6.11e−3` | ❌ |

| `E7` | 18 | 56 | 18 | 1.196 | `2.42` | ✅ |
| `E8` | 30 | 248 | 30 | 0.718 | `3.90` | ✅ |

**固定 `λ*_G = 10.4`**（`q₀ ≥ 1` 的阈值，`q₁=1`）：所有群 `q₀ = 1.009` ✅，但所需裸耦合 `g*² = 10.4/h^∨` 随 `h^∨` 下降：`SU(2)` 需 `5.2`，`SU(3)` 需 `3.47`，`G2` 需 `2.60`，`F4` 需 `1.16`，`E8` 需 `0.35`。

**结论**：
1. **固定 `g*` 时小 `h^∨` 最难**（`SU(2), SU(3), G2`），与"大 `N` 最难"的直觉相反。
2. **固定 `λ*_G` 时群一致性退化为一条 `N`-无关不等式**：只需弱侧分析把类保持到 `λ* ≈ 10.4`。
3. **软肋**：`m/Λ` 无独立下界。若 `m/Λ` 随 `h^∨` 快速下降，结论反转。必须写成显式假设
   `(H_m): m/Λ ≥ c·h^{−p}`（`p` 有界），不得当作定理（A0 R6）。
4. **`CPB-W` 的圈数**：上表是**一圈**。`handoff-proof` R27 要求 `CPB-W` 给 **≥二圈** 的 `t_up` 上界；一圈在 `λ≈6` 给 `3.59`（`q₀=0.22`），三圈/数值 `≈2.0`（`q₀≈1.1`）。GL8 的表**只用于展示群依赖结构**，不是 H3 的证明。

## 附录 B：GL6 的有限格点证明（可形式化的最小版本）

```
变量：X 有限，Γ 有限群，μ : X → ℝ≥0，F : X → ℝ，A : Finset X
假设：∀ g x, μ (g•x) = μ x；∀ g x, F (g•x) = F x；∀ x, ∃ a ∈ A, ∃ g, g•x = a
定义：m a := (A.filter (fun b => ∃ g, g•a = b)).card
结论：∑ x, F x * μ x = ∑ a ∈ A, F a * μ a * ((orbitSize a : ℝ) / (m a : ℝ))
证明：μ 在轨道上常数（不变性）；按轨道分组，左端 h·F·μ，右端 k·F·μ·(h/k)。
```
